# 603816.SH 深度透视

## 因果逻辑链
- **[品类聚焦与结构突破]** -> [营收与利润双增]: 内贸聚焦功能沙发、床垫等战略品类，外贸深耕核心市场，以非均衡投入换取结构性增长，实现营收200.56亿（+8.53%），归母净利17.90亿（+26.37%）。
- **[零售转型基础设施投入期转向产出期]** -> [内贸利润显著改善]: 商品运营“假设-验证”机制、会员“订单积分化+转介绍”正循环、拉式供应链初步成型，推动内贸线下零售增长3.2%，且利润增幅远超收入。
- **[全球深化与本土化运营]** -> [外贸贡献核心增量]: 越南新基地投产、北美前端营销赋能体系构建、OBM门店在东南亚/南亚布局，外贸收入93.26亿（+11.46%），成为增长主引擎。
- **[研发投入高增与技术转化]** -> [产品力提升与结构优化]: 研发费用同比+31.19%，功能铁架、净醛技术、智能床等成果落地，中高端产品零售占比提升，支撑毛利率稳定。
- **[简政放权与利润提点制]** -> [组织活力与效率提升]: 决策权下沉至一线经营单元，打破年薪制固化约束，干部90后占比达40%，驱动全价值链运营费率优化。
- **[KBS精益体系全价值链延伸]** -> [运营效率与成本优势]: 精益改善从制造向研发、供应链拓展，全年开展改善798期，单位运营费率实现优化，构筑穿越周期的护城河。
- **[多品牌矩阵与全渠道协同]** -> [全域市场覆盖与抗风险能力]: 顾家主品牌、LAZBOY、NATUZZI、顾家乐活、CHITA等覆盖全消费层级，线上线下+海外渠道协同，内贸线上收入占比19.48%，跨境电商收入10.68亿。

## 风险警告
**核心风险在于外贸业务对国际贸易摩擦的脆弱性与内贸零售转型的不确定性。** 公司外贸收入占比近半，且美国、加拿大等市场面临高额关税压力。尽管通过越南、墨西哥等海外基地布局部分对冲，但供应链弹性与交付能力仍受挑战。若贸易摩擦进一步升级或海外基地运营效率不及预期，外贸业务的增长引擎可能失速。

**内贸零售转型尚处深水区，从“制造+批发”到“零售运营商”的跃迁需要持续投入。** 门店数量净减少（经销店净减1家，直销店净减24家），显示终端优化仍在进行。拉式供应链、TO C履约等新模式的规模化复制与盈利验证仍需时间。若转型过程中渠道管理失控或经销商体系承压，可能拖累内贸基本盘。此外，原材料价格波动与房地产行业持续低迷，仍是侵蚀利润的长期隐患。
