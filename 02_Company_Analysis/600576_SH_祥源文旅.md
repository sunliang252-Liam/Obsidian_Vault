# 600576.SH 深度透视

## 因果逻辑链
- **[稀缺资源长期经营权]** -> [业绩增长]: 百龙天梯、碧峰峡等核心资产享有39-70年特许经营权，锁定长期稳定现金流，支撑景区业务收入同比增长50.65%。
- **[“投研建运”一体化]** -> [运营效率提升]: 从资源研判到运营交付全链条可控，碧峰峡青云梯9个月建成，齐云山逍遥街1个月改造完成，实现建设降本、运营增效。
- **[新媒体营销破圈]** -> [流量转化]: 直播间及视频总曝光量43.5亿次，同比增长140%；全年核销金额超1亿元，同比增长69%，核销率提升13个百分点。
- **[轻游乐产品创新]** -> [品牌声量]: 太空天梯、飞拉达等7大项目全网播放量13.8亿次，单条视频最高点赞超300万，驱动体验升级与品牌破圈。
- **[标准化运营体系]** -> [资产价值释放]: 百龙天梯、齐云山股份2025年营收较2022年基期分别增长205%和218%，莽山五指峰收购后收入增长65%、客单价提升16%。
- **[旅游服务业务拓展]** -> [收入结构多元化]: 新增游轮及线路游业务，旅游服务收入同比增长51.34%，但毛利率仅5.54%，拉低整体盈利水平。
- **[同一控制下企业合并]** -> [财务数据追溯调整]: 收购卧龙生态旅游、金秀莲花山等，导致前期财务数据追溯调整，归母净利润同比下降21.98%。

## 风险警告
**控股股东债务危机与实控人刑事风险是最大不确定性。** 公司间接控股股东祥源控股关联平台债务风险爆发，绍兴市帮扶工作组已进驻；实际控制人俞发祥因涉嫌犯罪被绍兴市公安局采取刑事强制措施。控股股东及一致行动人股份已全部被司法冻结及轮候冻结，若后续涉及司法处置，存在控制权稳定性风险。这一系统性风险可能波及上市公司融资能力、业务拓展及品牌信誉。

**业绩承诺压力与资产减值风险并存。** 2025年业绩承诺标的公司（百龙绿色等）仅完成承诺净利润的82.38%，虽累计完成率121.98%未触发补偿，但后续2026年承诺额17,892.80万元压力巨大。同时，公司对四川广夏建设等应收款项单项计提减值4,447.61万元，成都南湖鹏程计提商誉减值1,847.79万元，资产质量隐忧显现。此外，销售费用同比增长70.04%、财务费用增长134.13%，费用侵蚀利润的趋势值得警惕。
