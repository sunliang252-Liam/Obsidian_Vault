- **[信创国产替代加速]** -> [软件产品使用授权收入增长35.21%]: 党政、金融等关键领域加速核心系统国产化，直接拉动达梦数据库软件授权收入高速增长。
- **[产品规模化落地释放利润弹性]** -> [归母净利润增长42.76%，远超营收增速]: 软件产品授权业务毛利率高达99.73%，且收入占比提升，同时三项费用率同比下降，共同推动利润高速释放。
- **[渠道销售网络优化]** -> [渠道销售收入增长33.79%]: 公司战略性优化渠道布局，渠道销售成为软件授权业务的核心增长引擎，贡献了绝大部分营收增量。
- **[高毛利业务占比提升]** -> [整体毛利率提升6.5个百分点至96.13%]: 低毛利的“数据及行业解决方案”业务因高基数而收缩，高毛利的软件授权和运维服务占比提升，结构性优化带动整体毛利率跃升。
- **[坚持原始创新与自主研发]** -> [构筑“代码根”与供应链安全壁垒]: 100%自主代码率，使公司产品不受开源社区禁用等风险影响，在信创市场中形成独特且坚固的竞争护城河。
- **[突破共享存储集群核心技术]** -> [在金融核心系统国产化中占据领先地位]: 公司率先突破该“卡脖子”技术，产品满足金融核心业务对高可靠、高性能的严苛要求，助力其登顶金融行业集中式事务型数据库国产厂商份额榜首。
- **[设立产业基金与海外子公司]** -> [布局第二增长曲线]: 通过设立海南子公司和产业基金，公司正从国内市场向海外及产业链上下游延伸，寻求新的增长空间。

## 风险警告
**核心管理层动荡风险**：报告期内，公司董事兼总经理皮宇、董事兼高级副总经理陈文被监察机关实施立案调查及留置，内部控制审计报告因此被出具带强调事项段的无保留意见。核心管理层的缺位与不确定性，可能对公司短期经营决策、客户关系及内部管理稳定性造成显著冲击，是当前最突出的治理风险。

**收入增长放缓与竞争加剧风险**：公司业绩高度依赖信创政策驱动，若未来政策力度减弱或下游行业信息化建设放缓，收入增速可能面临下滑。同时，国际巨头（Oracle、微软）与云原生数据库厂商（如阿里云、华为云）在技术、生态和资金上仍具显著优势，AI与数据库的融合趋势也可能催生新的强大竞争者，公司面临市场份额被侵蚀的风险。
