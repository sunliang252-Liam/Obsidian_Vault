# 300119.SZ 深度透视

## 因果逻辑链
- **宠物赛道“三瑞齐发”生态协同** -> 宠物供应链收入增长23.42%: 中瑞供应链覆盖1.4万+终端，与瑞派宠物医院深度绑定，渠道+产品双轮驱动放量。
- **高毛利生物制品占比提升** -> 归母净利润增长33.18%: 禽用生物制品市占率17.94%，毛利率64.14%，结构优化带动整体盈利水平。
- **mRNA疫苗技术突破** -> 全球首个食品动物用mRNA疫苗临床批件: 抢占下一代疫苗技术制高点，构筑长期技术壁垒。
- **精益管理降本超9000万元** -> 对冲行业竞争与成本压力: 全价值链降本占成本费用总额3.14%，释放利润空间。
- **国际业务增速33%** -> 打开长期成长空间: 聚焦高附加值产品出海，海外GMP认证推进，品牌与业绩双提升。
- **投资业务贡献1.10亿元收益** -> 增厚当期净利润: 产业链战略投资与金融资产处置收益，为研发与市场拓展提供资源。
- **兽医社会化服务收入增长56%** -> 开辟业务增长新赛道: 覆盖新疆、内蒙古等畜牧核心产区，累计服务农户超18万户。

## 风险警告
**应收账款高企与现金流恶化风险。** 应收账款账面价值9.84亿元，占营收近29%，且经营活动现金流净额同比骤降59.55%至2.98亿元，与净利润4.01亿元严重背离。若下游养殖客户（尤其猪企）因猪价低迷出现信用恶化，坏账风险将直接冲击利润表。

**下游养殖周期波动与市场竞争加剧的双重挤压。** 2025年猪价自9月进入亏损期，养殖端防疫费用承压，动保行业竞争已转向“高品质+全周期服务”的头部对决。公司虽通过降本对冲，但若猪周期持续低迷，禽用疫苗等核心业务增速可能放缓，毛利率面临进一步下行压力。
