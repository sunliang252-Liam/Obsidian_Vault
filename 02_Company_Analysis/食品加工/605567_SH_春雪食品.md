# 605567.SH 深度透视

## 因果逻辑链
- **[出口业务高增长]** -> [净利润大幅提升]: 出口创汇首破1亿美元，调理品出口销量同比增长15.52%，高毛利海外市场有效对冲国内价格下行压力。
- **[调理品销量增长]** -> [综合毛利率提升]: 核心产品调理品销量同比增长8.45%，毛利率同比提升4.56个百分点至17.49%，拉动综合毛利率从6.81%升至8.97%。
- **[原料成本下降]** -> [养殖成本降低]: 鸡苗和豆粕等主要饲料原料采购价格同比下降，叠加优化采购策略，有效降低了毛鸡养殖成本，改善盈利空间。
- **[产品结构优化]** -> [盈利韧性增强]: 以高附加值调理品为核心（营收占比48%），弱化对低毛利生鲜品（毛利率仅1.73%）的依赖，增强了穿越行业周期的能力。
- **[全产业链闭环]** -> [成本与品质可控]: 从饲料生产、养殖到屠宰加工的全产业链布局，保障原料稳定供应与食品安全，在行业洗牌中构筑合规竞争壁垒。
- **[行业集中度提升]** -> [市场份额向龙头集中]: 食品安全监管趋严，中小产能加速出清，公司凭借规模化、合规化运营抢占退出市场空间。
- **[数智化转型]** -> [运营效率提升]: 推进用友BIP系统建设，实现生产流程智能化、库存管控精准化，减少生产损耗与运营浪费，夯实盈利基础。

## 风险警告
**核心风险在于白羽肉鸡行业供给过剩的持续压力。** 2025年全国屠宰量达92.86亿只，同比增长6.39%，而消费增长动力不足，导致毛鸡价格连续三年下跌。公司生鲜品毛利率仅1.73%，若行业供需矛盾进一步加剧，将直接侵蚀公司基本盘盈利。尽管调理品业务提供缓冲，但生鲜品营收仍占食品营收52%，周期下行风险不可忽视。

**另一重大风险是原料成本与汇率波动的双重挤压。** 公司雏鸡全部外购，饲料成本占养殖成本比重高，玉米、豆粕价格受国际行情影响波动剧烈。同时，出口业务年创汇超1亿美元，人民币汇率波动对利润影响显著。若原料价格大幅反弹叠加人民币升值，将严重削弱公司通过降本增效和出口增长所取得的成果。
