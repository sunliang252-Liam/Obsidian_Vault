# 600073.SH 深度透视

## 因果逻辑链
- **[生猪养殖业务巨额亏损]** -> [归母净利润由盈转亏]: 2025年猪价低位震荡，公司生猪养殖业务亏损12.88亿元，叠加资产减值，导致整体净利润从盈利2.16亿转为亏损1.32亿。
- **[新西兰元汇率剧烈波动]** -> [财务费用激增416%]: 新西兰元兑人民币汇兑损失达1.26亿元，是财务费用从0.39亿飙升至2.03亿的主因，严重侵蚀利润。
- **[牛羊肉业务“量缩价增”]** -> [营收增长但利润承压]: 银蕨农场受益于全球牛肉高价，营收增长10.9%至127亿，但采购成本高企及汇率波动导致净利润仅1.19亿，盈利弹性不足。
- **[品牌休闲食品逆势增长]** -> [利润稳定器作用凸显]: 冠生园食品净利润3.22亿元，毛利率提升5.19个百分点，以不到8%的营收贡献了远超其他板块的利润，成为公司核心利润来源。
- **[全产业链协同效应有限]** -> [未能有效对冲周期风险]: 尽管生猪养殖亏损，但屠宰及深加工业务毛利率仅微增0.91个百分点，未能充分受益于低成本原料，产业链内部对冲机制效果不达预期。
- **[存货与长期资产大额减值]** -> [加剧业绩亏损]: 公司计提存货跌价准备及固定资产减值合计超8亿元，反映出对猪价前景及部分资产盈利能力的悲观预期。
- **[经营活动现金流大幅转负]** -> [资金回笼压力增大]: 经营活动现金流净额从7.89亿骤降至-1.89亿，主因营收回款放缓及采购支出增加，显示营运资金管理面临挑战。

## 风险警告
**核心风险在于生猪养殖业务的深度亏损与资产减值形成负向循环。** 光明农牧全年亏损12.88亿元，远超其他板块盈利总和，且公司已对相关资产计提大额减值。尽管行业产能正在去化，但2026年上半年猪价预计仍将低位震荡，养殖业务扭亏时间表高度不确定。若猪价复苏不及预期，公司可能面临持续的资产减值压力，进一步拖累整体业绩。

**第二大风险来自海外业务的汇率与经营双重不确定性。** 银蕨农场贡献了公司过半营收，但其利润高度依赖新西兰元汇率及全球牛羊肉供需格局。2025年汇兑损失已造成重大冲击，而2026年全球贸易保护主义抬头、地缘冲突加剧，可能进一步推高采购成本与汇率波动风险。此外，新西兰环保立法可能推高牲畜采购成本，对银蕨农场的长期盈利能力构成潜在威胁。
