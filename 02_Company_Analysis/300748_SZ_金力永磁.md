# 300748.SZ 深度透视

## 因果逻辑链
- **[稀土价格上行]** -> [毛利率大幅提升10.05个百分点]: 2025年镨钕金属均价同比上涨23.8%，公司凭借与客户的调价机制和提前采购策略，将原材料涨价有效传导至产品售价，实现毛利率从11.13%跃升至21.18%。
- **[产能规模扩张与利用率提升]** -> [产销量创历史新高]: 公司建成4万吨/年磁材产能，全年实际产能3.8万吨（利用率超90%），磁材成品销量同比增长21.25%至2.53万吨，驱动主营业务收入增长19%。
- **[新能源汽车与机器人需求放量]** -> [高增长领域收入结构优化]: 新能源汽车及汽车零部件收入增长30.31%至39.41亿元，机器人及工业伺服电机收入增长45.19%至3亿元，高附加值领域占比提升带动整体盈利质量改善。
- **[集团化运营与多基地布局]** -> [运营效率与成本控制能力增强]: 完成从单一生产基地向赣州、包头、宁波协同运营的集团化转型，实现内部资源高效配置与精细化管理，支撑产能利用率超90%的同时保障交付。
- **[晶界渗透技术大规模应用]** -> [产品竞争力与客户粘性提升]: 使用晶界渗透技术生产的磁材产品占比约90%，降低重稀土用量、优化成本结构，同时满足高端客户对性能的严苛要求，巩固与全球头部客户的长期合作。
- **[稀土回收循环体系贡献释放]** -> [原材料保障与额外利润来源]: 银海新材实现营业收入1.95亿元、净利润5,050万元，累计回收稀土原材料3,681吨，形成“生产-回收-再利用”闭环，降低原材料供应风险并贡献增量利润。
- **[H股可转债发行与MSCI纳入]** -> [资本运作灵活性与全球投资者覆盖提升]: 成功发行1.175亿美元H股可转债，A股纳入MSCI中国指数，拓展融资渠道并改善股票流动性，为产能扩张提供资金支持。

## 风险警告
**稀土价格波动与海外业务风险是核心挑战。** 公司毛利率与稀土价格高度正相关，2025年毛利率大幅提升主要得益于镨钕金属均价同比上涨23.8%。若未来稀土价格回落，公司产品售价将承压，毛利率存在显著下行风险。同时，海外业务面临地缘政治、贸易政策及汇率波动等多重不确定性，尽管公司已获出口通用许可证，但出口管制规则的持续细化仍可能影响海外订单交付节奏与成本。

**应收账款规模持续扩大与经营现金流恶化构成财务隐忧。** 随着销售规模扩张，应收账款同比增长22.1%至24.7亿元，而经营活动现金流净额同比下降30.5%至3.53亿元，与净利润7.06亿元存在较大差距。若下游客户回款周期延长或出现坏账，将直接影响公司资金周转效率与财务稳健性，需警惕“增收不增现”的潜在风险。
