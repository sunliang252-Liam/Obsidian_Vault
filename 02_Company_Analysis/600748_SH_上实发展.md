# 600748.SH 深度透视

## 因果逻辑链
- **[泉州项目大宗资产出售]** -> [营收增长35.87%，但净利润巨亏6.18亿]: 以约20.5亿元一揽子出售泉州海上海项目存量住宅及车位，大幅拉升当期营收，但同期计提资产减值损失6.91亿元，导致利润由盈转亏。
- **[房地产行业持续下行与去化压力]** -> [资产减值损失6.91亿元，吞噬利润]: 行业“止跌回稳”缓慢，公司多地项目去化速度不达预期，管理层对存货可变现净值进行重估，导致大额减值。
- **[高有息负债与利息负担]** -> [财务费用2.8亿元，侵蚀利润]: 期末有息负债总额约140亿元，整体平均融资成本2.75%，但利息费用仍高达3.02亿元，对利润形成持续压力。
- **[物业服务板块稳健增长]** -> [营收12.58亿，毛利率7.57%，成为业绩稳定器]: 跻身上海物业百强前三，非居物业面积占比提升至68%，第三方项目拓展强劲，有效对冲了开发业务的周期性下滑。
- **[自持不动产租赁承压]** -> [租金收入同比下降13.37%]: 商办租赁市场进入存量博弈，出租率与租金双降，核心资产虽优于市场平均，但下行趋势短期难改。
- **[历史遗留问题与法律风险]** -> [中小投资者虚假陈述索赔5,874万元，2025年实际赔付5,792万元]: 前期信披违规引发的诉讼赔偿，直接减少当期利润，并持续影响公司声誉与现金流。

## 风险警告
**核心风险在于资产质量与流动性。** 公司净利润已连续两年亏损，2025年亏损额扩大至6.18亿元，主要源于6.91亿元的巨额资产减值。这直接反映了公司大量存货（132亿元）和投资性房地产（41.5亿元）在当前市场环境下的贬值压力。同时，一年内到期的非流动负债激增至51亿元，而账面货币资金虽有47.4亿元，但部分受限，短期偿债压力巨大。

**治理与历史包袱风险不容忽视。** 控股股东关于解决同业竞争的承诺长期未能履行，构成公司治理的潜在隐患。此外，因前期信披违规引发的投资者索赔诉讼仍在进行中，未来仍可能产生额外赔付，持续侵蚀公司利润与股东权益。公司正处于从传统开发商向“资物管”一体化城市运营服务商转型的阵痛期，转型成效尚待验证。
