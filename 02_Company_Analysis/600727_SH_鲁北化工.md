# 600727.SH 深度透视

## 因果逻辑链
- **[钛白粉、甲烷氯化物价格下跌]** -> [营收与利润大幅下滑]: 核心产品钛白粉和甲烷氯化物市场供过于求，销售价格同比下降，导致公司营收减少11.43%，归母净利润暴跌85.34%。
- **[核心子公司金海钛业亏损]** -> [拖累整体业绩]: 受钛白粉价格低迷及原材料硫酸价格上涨影响，金海钛业全年亏损1.03亿元，成为公司利润下滑的最大拖累项。
- **[锦亿科技（甲烷氯化物）高盈利]** -> [对冲部分下行风险]: 凭借华南区域市场垄断地位（二氯甲烷市占率70%）和成本优势，锦亿科技实现净利润1.42亿元，成为公司利润的核心稳定器。
- **[溴素价格大幅上涨]** -> [利润贡献显著提升]: 受供给收缩和地缘政治影响，溴素价格全年高位运行，毛利率高达52.91%，销量同比增长35%，成为业绩亮点。
- **[在建工程大幅增加]** -> [资本开支与财务费用承压]: 6万吨氯化法钛白粉、60万吨硫磺制酸等项目集中建设，在建工程同比激增235%，导致长期借款和利息支出增加，财务费用由负转正。
- **[循环经济模式降本]** -> [成本端相对可控]: 通过废酸、废渣资源化利用（如钛石膏制水泥），公司有效降低了原材料和环保处置成本，钛白粉成本同比下降12.19%，减缓了利润下滑幅度。
- **[海外市场拓展]** -> [弥补内需不足]: 祥海科技新开发75家海外客户，在中东、非洲等市场扩大份额，一定程度上对冲了国内钛白粉需求疲软的影响。

## 风险警告
**核心风险：钛白粉业务周期性与结构性困境。** 公司第一大业务钛白粉（营收占比65%）正面临供需严重失衡的行业寒冬。国内产能过剩、下游房地产需求疲软，导致产品价格持续承压。尽管公司拥有循环经济成本优势，但金海钛业已陷入亏损，且6万吨氯化法新产能即将投产，若市场无法消化，将进一步加剧供给压力，侵蚀公司利润。印度反倾销税虽暂缓，但国际贸易壁垒风险犹存。

**财务风险：高资本开支与现金流恶化。** 公司正处于产能扩张高峰期，在建工程大幅增加，导致长期借款激增，财务费用由负转正。与此同时，经营活动现金流净额同比锐减63.94%，显示主营业务造血能力显著下降。若新项目投产后无法快速达产达效并贡献现金流，公司可能面临流动性压力，偿债能力将受到考验。
