# 603235.SH 深度透视

## 因果逻辑链
- **[维生素B1等产品价格上涨]** -> [营收增长6.18%]: 核心产品价格上行，抵消了其他维生素（如VE粉）量价齐跌的负面影响，支撑了整体收入规模。
- **[精细化工品（ABL、甲醇钠等）产销量大增]** -> [该业务收入同比+70.24%]: 产业链纵向延伸战略见效，中间体产品在自用基础上对外销售，成为收入增长的新引擎。
- **[宁夏子公司（宁夏天新）进入试运营]** -> [管理费用同比+25.49%]: 新基地开办费及前期运营成本增加，直接侵蚀了当期利润，导致净利润增速低于营收增速。
- **[美元结汇增加及汇兑收益减少]** -> [财务费用同比大幅增加]: 汇率波动导致利息收入和汇兑收益减少，财务费用从-1.1亿变为-0.25亿，对利润端形成拖累。
- **[行业供给过剩，竞争加剧]** -> [其他维生素毛利率同比-10.56个百分点]: 维生素E粉等产品价格低迷，导致该板块盈利能力显著下滑，拖累整体利润表现。
- **[B族维生素成本控制有效]** -> [该板块毛利率同比+3.96个百分点]: 通过工艺优化和产业链延伸，在原材料价格波动下实现了成本下降，巩固了核心业务的盈利护城河。
- **[募投项目持续投入]** -> [固定资产同比+42.48%]: 江西和宁夏基地的产能建设进入高峰期，资本开支巨大，资产结构从轻资产向重资产转型。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长6.18%，但净利润却下降9.16%，主要原因是新基地（宁夏天新）带来的高额开办费和管理费用，以及汇率波动导致的财务费用大幅回升。这表明公司正处于产能扩张的“阵痛期”，新产能的盈利贡献尚未能覆盖其前期投入成本，短期内利润端将持续承压。

**行业供给过剩的长期风险不容忽视。** 维生素行业产能持续扩张，同质化竞争激烈，公司其他维生素（如VE粉）毛利率已大幅下滑至7.64%。若未来B族维生素核心产品价格因新进入者或产能释放而下跌，公司将面临核心利润来源被侵蚀的风险。此外，公司外销占比高，国际贸易环境及汇率波动是持续的外部不确定性因素。
