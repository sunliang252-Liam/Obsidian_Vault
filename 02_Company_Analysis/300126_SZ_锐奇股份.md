# 300126.SZ 深度透视

## 因果逻辑链
- **[原材料价格上涨]** -> [综合毛利率降低]: 原材料成本上升直接侵蚀产品利润空间，导致主营业务盈利能力下降。
- **[管理费用、研发费用增加]** -> [营业利润亏损扩大]: 费用刚性增长叠加收入增速不足，进一步压缩利润空间。
- **[汇兑损失增加]** -> [财务费用上升]: 人民币汇率波动导致外销收入折算后价值下降，增加汇兑损失。
- **[泰国子公司投产初期费用高]** -> [净利润亏损]: 泰国锐奇处于产能爬坡期，固定成本摊销大，拖累整体业绩。
- **[理财产品到期赎回减少]** -> [投资活动现金流净额大幅转正]: 2025年购买理财产品规模减少，导致投资活动现金流入大于流出。
- **[外销收入增长]** -> [营业收入增长12.21%]: 海外市场需求回暖，带动公司整体营收规模扩大。
- **[计提信用减值损失减少]** -> [资产减值损失减少]: 应收账款回收情况改善，坏账风险降低。

## 风险警告
**核心风险在于主营业务持续亏损且依赖非经常性损益。** 2025年扣非净利润亏损7024万元，亏损额同比扩大71.81%，而净利润亏损4552万元，差额主要来自理财产品收益（2224万元）和政府补助（697万元）。若未来金融市场波动或理财产品收益下降，公司将面临更大的业绩压力。

**泰国子公司投产初期亏损严重，海外扩张存在不确定性。** 泰国锐奇2025年实现营收9104万元，但净利润亏损2088万元，主要受投产初期费用高和汇兑损失影响。海外生产基地建设尚处于投入期，短期内难以贡献正向利润，且汇率波动风险持续存在。
