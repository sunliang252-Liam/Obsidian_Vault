# 603005.SH 深度透视

## 因果逻辑链
- **[车规CIS需求爆发]** -> [营收增长30.44%]: 汽车智能化驱动单车摄像头数量增至10-13个，公司作为车规CIS封装技术领先者，直接受益于车载CIS市场21%的出货量增长。
- **[TSV-STACK工艺领先]** -> [毛利率提升4.57个百分点]: 持续优化晶圆级硅通孔封装工艺，提升量产效率与良率，在车规等高价值领域实现技术溢价。
- **[马来西亚生产基地建设]** -> [投资现金流净流出8.04亿元]: 为应对全球产业链重构，主动进行海外产能布局，导致资本开支大幅增加，短期压制自由现金流。
- **[客户集中度高]** -> [经营风险集中]: 前五大客户销售额占比75.83%，其中第一大客户占比39.29%，对核心客户依赖度极高，议价能力受限。
- **[财务费用由负转正]** -> [利润侵蚀]: 银行存款利率下降及汇率波动导致利息收入减少，财务费用从-8523万元转为+501万元，对净利润产生负面影响。
- **[研发投入持续稳定]** -> [技术护城河加深]: 研发费用率10.39%，聚焦MEMS先进封装、3D堆叠、光电融合等前沿技术，巩固技术先发优势。
- **[全球化布局推进]** -> [长期竞争力提升]: 通过马来西亚基地、以色列VisIC公司等布局，构建国际化生产、市场与投融资平台，应对贸易争端风险。

## 风险警告
**客户集中与地缘政治双重风险。** 公司前五大客户销售额占比高达75.83%，严重依赖少数头部传感器设计企业。一旦核心客户转向自建封装产能或更换供应商，将对公司营收造成毁灭性打击。同时，公司作为全球晶圆级TSV封装引领者，深度嵌入全球半导体产业链，在当前逆全球化与中美科技博弈加剧的背景下，海外生产基地建设、技术合作均面临不确定性，若全球化战略推进不及预期，将直接动摇公司市场地位。

**技术产业化与成本上升的挤压。** 公司持续开发多样化先进封装技术，但新技术从研发到规模化量产需要产业链协同，产业化存在不确定性。同时，人力成本占比较高，随着生产规模扩大，劳动力成本上升将持续侵蚀利润。此外，公司出口以美元结算为主，人民币汇率波动将直接影响营收与利润，2025年财务费用已因汇率波动由负转正，未来汇率风险不容忽视。
