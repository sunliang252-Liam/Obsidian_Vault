# 301195.SZ 深度透视

## 因果逻辑链
- **政策驱动矿山智能化建设** -> 市场需求增长: 国家及地方政策要求2025年大型煤矿实现运输系统智能化，推动智能矿山设备需求
- **矿山招工难、安全压力** -> 智能驾驶需求提升: 年轻人从业意愿低，事故率较高，矿山有减员增效、安全升级的内在诉求
- **公司研发投入与先发优势** -> 智能驾驶产品落地: 持续研发投入超1亿元，近300名研发人员，率先取得安标证并落地陕煤集团
- **智能驾驶产品落地** -> 新增长曲线形成: 智能驾驶矿卡可节省成本数十万元/年/辆，效率提升，市场需求巨大
- **非煤矿山智能化政策** -> 公司横向拓展: 非煤矿山数量多（3.2万座）、智能化起步晚，政策鼓励，公司拓展至金矿、磷矿等
- **公司软硬件一体化能力** -> 客户粘性与订单增长: 自主研发核心软硬件，产品融合度高、稳定性好，提升客户满意度
- **智能制造车间投产** -> 生产效率提升: 自动化装备（CTU机器人、AGV等）降低生产成本，提高产品质量

## 风险警告
公司面临多重风险：1）技术迭代风险：5G、AI等技术更新快，若研发落后可能失去先发优势；2）行业政策风险：煤矿智能化政策执行不及预期或补贴退坡；3）竞争加剧：传统IT企业及跨界巨头可能进入智能矿山领域；4）客户集中风险：大客户如陕煤集团订单波动影响业绩；5）智能驾驶商业化不及预期：井下环境复杂，技术落地存在不确定性；6）非煤矿山拓展缓慢：非煤矿山智能化进程可能低于预期。
