# 603882.SH 深度透视

## 因果逻辑链
- **[医保控费与DRG/DIP支付改革深化]** -> [营收下降16.12%]: 医院检验科从“利润中心”转为“成本中心”，倒逼医院加大成本管理，导致行业整体需求承压、检验项目价格下调，公司短期业务发展承压。
- **[数智化转型与精益管理降本]** -> [毛利率逆势提升1.59个百分点至34.74%]: 通过AI智能体（节约超2.1万人天）、产能中心整合（“3+N+X”布局）、供应链优化及智慧实验室建设，有效对冲了收入下滑带来的利润侵蚀。
- **[应收账款回收与信用减值损失减少]** -> [经营性现金流净额同比大增32.62%至12.02亿元]: 公司加强现金流管理，应收账款回收进度改善，同时信用减值损失同比减少40.20%，历史影响基本出清。
- **[“普惠+专病”双轮产品策略]** -> [特检业务保持韧性]: “惠民3000”系列（肿瘤、AD早筛）及“睿耐安”等独家产品，满足了基层普惠与高端精准的双重需求，在普检价格承压下维持了业务结构优化。
- **[县域医共体“五位一体”方案落地]** -> [基层市场渗透率提升]: 服务覆盖超全国53%区县的龙头医疗机构，并已服务近百个县域医共体，为未来基层业务放量奠定网络基础。
- **[AI与数据要素能力构建]** -> [从“检测服务商”向“医学智能诊断服务平台”转型]: 开发80余个AI智能体，医检可信数据空间入选国家试点，32款数据产品登陆交易所，构建了“检验+数据+AI”的差异化壁垒。
- **[共建实验室模式深化]** -> [巩固三级医院客户粘性]: 参与共建实验室超780家（其中三级医院精准医学中心超100家），通过“产学研医”合作将服务深度嵌入高端医疗流程。

## 风险警告
**核心风险在于行业政策与价格下行的持续性。** DRG/DIP支付改革已全面铺开，检验项目价格进入常态化下调通道，这并非短期波动而是行业底层逻辑的重构。公司2025年营收同比下降16.12%，连续第二年亏损，表明即便通过极致降本和数智化提效，也难以完全对冲价格与需求的双重压力。若未来价格调整幅度超预期，或基层市场业务放量节奏持续滞后，公司盈利能力的修复将面临更大挑战。

**第二大风险是应收账款与坏账的长期隐患。** 尽管2025年现金流改善明显，但期末应收账款仍高达51.86亿元，占资产总额的34.90%，坏账准备余额18.34亿元。随着县域医共体等下沉市场业务拓展，回款周期可能进一步拉长。若宏观经济环境恶化或部分医疗机构出现支付困难，大规模的信用减值损失可能再次侵蚀利润，公司需持续证明其现金流管理能力足以穿越周期。
