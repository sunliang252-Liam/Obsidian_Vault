# 000929.SZ 深度透视

## 因果逻辑链
- **[抖音线上直销爆发式增长]** -> [营收增长75.28%]: 线上广告投入1.89亿驱动抖音直销收入1.67亿，同比暴增473倍，成为营收核心引擎。
- **[线上投流成本吞噬利润]** -> [扣非净亏损扩大65.68%]: 销售费用暴增284%至2.48亿，其中线上广告费1.89亿，远超营收增幅，导致主业深度亏损。
- **[证券投资收益对冲主业亏损]** -> [归母净亏损收窄至-9094万]: 公允价值变动收益3703万及投资收益761万，合计贡献非经常性收益3855万，掩盖了主业-1.29亿的扣非亏损。
- **[果汁业务战略布局]** -> [新增第二增长曲线]: 收购吴忠黄河（浓缩苹果汁）及新建重庆黄河（NFC橙汁），报告期贡献营收2332万，但尚处产能爬坡期。
- **[麦芽业务量价齐升]** -> [营收增长190%]: 深化与核心啤酒集团合作，订单增加带动产量增长91%，但毛利率转负（-3.33%），成本增速（248%）远超收入。
- **[经销商体系剧烈调整]** -> [线下经销收入下降23%]: 为优化渠道健康度，主动清理163家低效经销商，导致线下经销网络收缩，收入下滑。
- **[经营现金流大幅恶化]** -> [净流出-2.27亿]: 线上投流及备货增加导致经营活动现金流出同比增77%，现金循环周期显著拉长。
- **[资产减值损失扩大]** -> [利润总额承压]: 计提存货跌价及固定资产减值准备3259万，反映部分资产运营效率及市场价值下降。

## 风险警告
公司正经历一场“用钱换增长”的豪赌。营收暴增75%的背后，是销售费用284%的失控式增长，其中1.89亿线上广告费几乎全部用于抖音投流。这种高度依赖单一平台、高流量成本的模式，一旦ROI下滑或平台规则变化，将直接导致营收与利润的双杀。当前扣非净亏损已扩大至-1.29亿，主业造血能力堪忧。

新进入的果汁业务虽被寄予厚望，但双基地（吴忠、重庆）刚完成布局，产能释放与市场开拓尚需验证。同时，公司面临基地市场（甘青）消费旺季短、全国化品牌认知薄弱、头部啤酒企业挤压等多重竞争压力。叠加麦芽业务毛利率转负、资产减值持续，公司短期盈利拐点尚不明朗，需警惕持续亏损带来的退市风险。
