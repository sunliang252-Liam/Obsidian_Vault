# 600543.SH 深度透视

## 因果逻辑链
- **国内葡萄酒行业深度调整，消费需求不足** -> 葡萄酒销量下降46.15%，收入下降55.57%: 行业低迷导致销量下滑，叠加固定费用分摊增加，收入降幅大于销量降幅
- **PBAT价格承压，上下游配套不完善** -> 降解材料收入下降63.73%，毛利率为负: 产品价格下降且成本端原材料采购成本较高，导致收入大幅下滑并出现亏损
- **药品市场终端需求下降，复方甘草片量价齐跌** -> 药品收入下降52.69%，毛利率下降12.73个百分点: 市场需求萎缩导致销量和价格双降，固定成本分摊上升侵蚀毛利
- **公司葡萄酒销售以甘肃省内为主，省外拓展乏力** -> 葡萄酒省外收入下降70.76%，省内仅降40.13%: 品牌区域性强，省外渠道布局不足，省外市场受行业冲击更显著
- **公司原料储备增加，预付款项大幅增长** -> 经营活动现金流净额为负-1.13亿元，同比恶化: 为应对原料价格波动，公司增加原料采购储备，导致现金流出增加
- **膜袋业务受益于地膜需求，销售网络拓展** -> 膜袋收入增长20.14%，但毛利率下降1.55个百分点: 产量大幅增长108.96%带动收入增长，但成本端原辅料价格上涨导致毛利率微降

## 风险警告
公司多业务板块（葡萄酒、降解材料、药品）均大幅下滑，仅膜袋业务增长，但毛利率为负。经营活动现金流持续恶化，短期借款增加导致财务费用上升。葡萄酒省外市场萎缩显著，降解材料处于亏损状态，药品需求走弱。公司面临主业萎缩、现金流紧张、盈利能力恶化等多重风险，需关注持续经营能力。

**公司简介（F10 原文）**

> 甘肃莫高实业发展股份有限公司成立于1995年12月,注册地:兰州高新技术产业开发区一号园区,法定代表人:张新军。股票在上海证券交易所成功上市(股票代码:600543,股票简称:莫高股份),控股股东为甘肃省农垦集团有限责任公司。公司下设六家分公司、七家全资子公司和一家控股子公司。主要有葡萄酒、环保新材料和药品三大产业,葡萄酒为主业,生产基地位于武威市凉州区,年生产能力2.5万吨。环保新材料产业,生产基地位于永昌县工业园区,年生产能力4万吨,主要产品有淀粉基吹膜母粒、片材和聚对苯二甲酸己二酸丁二醇酯(PBAT)等,产品主要用于生产生物降解塑料包装薄膜、农用地膜、一次性塑料袋和一次性塑料餐具等。药品生产基地位于酒泉市肃州区,产品以复方甘草片为主,年产销8亿片。莫高公司现为农业产业化国家重点龙头企业、甘肃省农业产业化重点龙头企业、中国葡萄酒产区龙头企业。莫高葡萄酒产业始建于1981年,多年来公司立足河西走廊自然资源优势,形成葡萄种植、酿造生产、市场销售为一体的完整产业链,在武威建成了万亩酿酒葡萄种植基地和2.5万吨生产能力的莫高庄园和生态酒堡,在兰州建成集参观、旅游、文化、体验、培训为一体的莫高国际酒庄,在北京、深圳、西安等城市建成集展示、品鉴、消费、文化等功能为一体的莫高城市酒堡。开发出干红、干白、甜型酒、冰酒、白兰地、起泡酒、贵腐葡萄酒等七大系列200多个产品,成功打造黑比诺核心产品。
