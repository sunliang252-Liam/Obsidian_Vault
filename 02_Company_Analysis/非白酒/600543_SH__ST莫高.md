# 600543.SH 深度透视

## 因果逻辑链
- **国内葡萄酒行业深度调整，消费需求不足** -> 葡萄酒销量下降46.15%，收入下降55.57%: 行业低迷导致销量下滑，叠加固定费用分摊增加，收入降幅大于销量降幅
- **PBAT价格承压，上下游配套不完善** -> 降解材料收入下降63.73%，毛利率为负: 产品价格下降且成本端原材料采购成本较高，导致收入大幅下滑并出现亏损
- **药品市场终端需求下降，复方甘草片量价齐跌** -> 药品收入下降52.69%，毛利率下降12.73个百分点: 市场需求萎缩导致销量和价格双降，固定成本分摊上升侵蚀毛利
- **公司葡萄酒销售以甘肃省内为主，省外拓展乏力** -> 葡萄酒省外收入下降70.76%，省内仅降40.13%: 品牌区域性强，省外渠道布局不足，省外市场受行业冲击更显著
- **公司原料储备增加，预付款项大幅增长** -> 经营活动现金流净额为负-1.13亿元，同比恶化: 为应对原料价格波动，公司增加原料采购储备，导致现金流出增加
- **膜袋业务受益于地膜需求，销售网络拓展** -> 膜袋收入增长20.14%，但毛利率下降1.55个百分点: 产量大幅增长108.96%带动收入增长，但成本端原辅料价格上涨导致毛利率微降

## 风险警告
公司多业务板块（葡萄酒、降解材料、药品）均大幅下滑，仅膜袋业务增长，但毛利率为负。经营活动现金流持续恶化，短期借款增加导致财务费用上升。葡萄酒省外市场萎缩显著，降解材料处于亏损状态，药品需求走弱。公司面临主业萎缩、现金流紧张、盈利能力恶化等多重风险，需关注持续经营能力。
