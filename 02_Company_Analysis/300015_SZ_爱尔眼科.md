# 300015.SZ 深度透视

## 因果逻辑链
- **[分级连锁网络扩张]** -> **门诊量与手术量增长**: 境内医院391家、门诊部272家，叠加境外179家中心，网络下沉与同城一体化推动门诊量同比+11.52%，手术量+5.77%。
- **[屈光与视光项目高增长]** -> **收入结构优化**: 屈光项目收入同比+10.26%，视光服务同比+9.64%，高附加值业务占比提升，拉动整体营收增长6.53%。
- **[AI与数字化赋能]** -> **运营效率提升**: AI眼底影像诊断、AI病历质控、远程医疗中心等应用落地，降低边际成本，支撑门诊量增长同时保持服务同质化。
- **[组织变革与区域整合]** -> **管理效能释放**: 成立湘赣、秦晋等大区管委会，推行地县一体化，精简管理层级，管理费用率得到控制，支撑规模扩张。
- **[海外业务高增长]** -> **收入多元化**: 境外收入同比+16.47%，占比提升至13.68%，欧洲、东南亚布局贡献增量，对冲国内医保控费压力。
- **[商誉与折旧摊销增加]** -> **净利润承压**: 新建医院转固及并购导致折旧摊销+21.36%，叠加商誉减值1.57亿元，归母净利润同比-8.88%，扣非净利润仅微增1.36%。

## 风险警告
**核心风险在于规模扩张的“增收不增利”陷阱。** 公司通过并购基金和新建医院快速铺开网络，但大量新院处于爬坡期，导致折旧、房租及摊销成本同比+21.36%，直接侵蚀利润。同时，商誉规模随并购持续膨胀，2025年已计提1.57亿元减值，若部分医院持续亏损，减值压力将显著拖累报表。

**医疗纠纷与品牌声誉的“黑天鹅”风险不可忽视。** 随着年手术量超168万例，医疗事故绝对数上升是必然趋势。在自媒体时代，任何个体纠纷都可能被放大为品牌危机，而公司通过并购基金授权品牌的方式，虽隔离了法律风险，但品牌声誉风险依然由上市公司承担，一旦出现重大负面事件，将对估值造成剧烈冲击。
