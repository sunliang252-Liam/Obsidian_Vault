# 601158.SH 深度透视

## 因果逻辑链
- **特许经营权及政府定价机制** -> 污水处理业务毛利率33.25%且同比提升1.14个百分点: 公司污水处理业务采用'政府特许、政府采购、企业经营'模式，结算价格每三年核定一次，以合理利润为基础，保障了盈利可持续性，使得毛利率高于自来水业务且同比提升。
- **供排水特许经营垄断地位** -> 主营业务收入区域集中度高（重庆市占83.3%）: 公司享有重庆市政府授予的特许经营权，占有重庆市主城区59%自来水市场、81%污水处理市场，导致收入高度集中于重庆地区。
- **政策推动与内部整合** -> 供排水产能扩张与市场拓展: 国家政策（如《供水条例》）支持城乡统筹供水，公司积极收购渝江水务、分质供水等，并推进项目，导致日供水设计能力新增14.81万立方米、污水处理新增67.65万立方米。
- **发行可转债及公司债（融资39亿元）** -> 资产负债率上升及财务结构变化: 公司发行19亿元可转债及20亿元公司债，导致应付债券同比增加292.39%，带动资产负债率上升至50.98%。
- **研发投入与数字化战略** -> 运营效率提升（智能水厂覆盖率25%）: 公司坚持创新驱动，投资数字化平台和AI项目，推动智能巡检、光伏+水厂等，导致智能供排水厂覆盖率达25%。
- **污水处理结算资金回收延迟** -> 经营活动现金流净额同比下降24.96%: 年报明确经营活动现金流减少主因是收到的污水处理结算资金同比减少。

## 风险警告
公司收入高度依赖重庆地区供排水特许经营，区域集中风险显著；污水处理结算资金回收延迟导致现金流恶化，需关注政府支付能力；可转债及公司债发行推高负债率，偿债压力增加；自来水毛利率仅12.96%且持续下降，成本管控面临挑战；研发投入占营收比仅0.33%，创新转化效率待观察。
