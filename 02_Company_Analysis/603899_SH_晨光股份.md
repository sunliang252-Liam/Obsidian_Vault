# 603899.SH 深度透视

## 因果逻辑链
- **[科力普集团营收突破150亿，同比增长9%]** -> [总营收增长3.45%]: 科力普作为企业采购数字化先锋，其高增长（+9%）是公司整体营收增长的核心引擎，抵消了传统核心业务的下滑。
- **[传统核心业务营收同比下降5%]** -> [归母净利润同比下降6.12%]: 传统业务（书写工具、学生文具等）量价承压，收入下滑直接导致利润端表现弱于营收端，盈利能力下降。
- **[九木杂物社门店超860家，营收增长9%]** -> [零售大店业务持续扩张]: 九木杂物社作为品牌升级桥头堡，通过门店扩张和IP运营，实现了营收增长，但净利润仍为亏损，处于投入期。
- **[IP赋能与情绪价值产品开发]** -> [产品力提升与品牌年轻化]: 公司通过自主IP孵化及与热门IP联名，推出“开关笔”等爆款，满足年轻消费者对情绪价值的需求，驱动产品结构升级。
- **[MBS精益管理体系深化]** -> [运营效率提升与成本控制]: 公司全面推行MBS体系，推动管理从“经验驱动”向“数据驱动”转变，在提质、降本、增效方面取得系统性改善。
- **[科力普集团启动分拆港股上市]** -> [优化资源配置与业务聚焦]: 分拆上市旨在利用资本市场优化资源配置，深化公司业务布局，助力科力普实现高质量、可持续发展。
- **[现金分红比例提升至70%]** -> [强化股东回报]: 公司持续提升分红比例，并注销回购股份，体现了“提质增效重回报”的行动方案，增强投资者信心。

## 风险警告
**核心风险在于传统核心业务的持续萎缩与利润承压。** 2025年传统核心业务营收同比下降5%，而公司整体利润下滑（-6.12%）主要源于此。在出生率下降、消费渠道多元化的背景下，靠数量增长的贡献减弱，公司能否通过产品升级（IP化、高端化）和渠道变革（线上、直供）成功对冲量价压力，是未来业绩的关键变量。若转型不及预期，传统业务可能成为拖累整体盈利的“失血点”。

**新业务（九木杂物社）的盈利拐点尚不明确。** 尽管九木杂物社营收增长9%且门店扩张至860家，但净利润亏损从-1,244万元扩大至-8,451万元，亏损幅度显著增加。这表明快速扩张带来的租金、人力等成本压力巨大，且尚未形成规模效应。若无法在门店扩张的同时有效控制成本、提升单店盈利模型，该业务将持续消耗公司资源，对整体利润表构成压力。
