# 688139.SH 深度透视

## 因果逻辑链
- **[海外在地化布局深化]** -> [海外收入同比增长17.9%，占比提升至36%]: 公司在18个国家建立本地化运营体系，精准服务区域用户差异化需求，推动海外收入创历史新高。
- **[新产业（智慧用药、血液技术、实验室方案）产品线丰富]** -> [新产业收入占比48.5%，同比增长8.8%]: 通过“内生+外延”双轮驱动，新产业产品矩阵持续完善，成为收入增长的核心引擎。
- **[AI+自动化技术嵌入设备与场景]** -> [AI相关收入占比达15%，场景方案订单同比增长超50%]: 公司部署17个智能体并集成至13类硬件设备，实现“感知-决策-执行”闭环，推动商业化落地。
- **[子公司新建产能爬坡与主动战略投入]** -> [归母净利润同比下滑31.6%，毛利率下降1.22个百分点]: 新工厂产能利用率不足导致制造费用扰动，叠加全球化与AI研发的主动投入，阶段性侵蚀利润。
- **[“同心圆”并购整合体系赋能]** -> [并购业务收入复合增长率达30%，对整体收入贡献超30%]: 公司通过“选/并/补/强”模式，实现技术、市场与供应链协同，并购子公司资本回报率保持双位数。
- **[低温存储技术代际领先]** -> [超低温产品在6个国家市场份额第一，蝉联美国能源之星榜首]: 自研Eco-Drive超绿技术等核心壁垒，巩固了公司在全球低温存储领域的龙头地位。
- **[国内需求恢复缓慢与竞争加剧]** -> [国内收入同比下滑5.5%]: 下游用户预算调整及行业竞争导致国内市场承压，但第四季度已实现同比增长14.5%，显示恢复迹象。

## 风险警告
**核心风险在于利润端的持续承压与战略投入的回报不确定性。** 2025年归母净利润同比下滑31.6%，主要源于新建产能爬坡带来的毛利率扰动（46.8%，同比-1.22pct）以及全球化、AI等中长期战略投入的刚性增长（销售费用同比+23.78%）。若海外市场拓展或新产业放量不及预期，利润端可能继续面临“增收不增利”的困境。此外，公司研发费用率已连续9年超过13%，高强度的资本开支能否转化为可持续的业绩增长，仍需时间验证。

**另一重大风险是地缘政治与贸易摩擦对海外业务的潜在冲击。** 公司海外收入占比已提升至36%，且目标进一步提升至50%，但全球贸易保护主义抬头、供应链区域化重构（如美国《生物安全法案》风险）可能直接冲击公司海外市场准入与订单获取。同时，公司海外收入以美元结算为主，人民币汇率波动（财务费用因利息收入下降而增加45.24%）也可能对盈利能力造成扰动。公司对海外市场的依赖度越高，其面临的宏观环境不确定性就越大。
