# 600166.SH 深度透视

## 因果逻辑链
- **[新能源销量爆发]** -> [归母净利润暴增1593%]: 新能源销量10.12万辆（+87.2%），高毛利新能源产品占比提升，直接拉动利润大幅增长。
- **[海外出口持续领先]** -> [营收增长28.4%]: 海外销量16.45万辆（+7.3%），保持中国商用车出口第一，海外业务毛利率15.44%高于国内，贡献增量利润。
- **[重卡业务翻倍增长]** -> [产品结构优化]: 重卡销量14.2万辆（+103.6%），市占率提升4.7个百分点，高单价重卡占比提升带动整体营收规模扩张。
- **[全价值链降本增效]** -> [扣非净利润扭亏为盈]: 期间费用率同比下降，采购中心整合、矩阵式管理转型，推动扣非净利润从-2.13亿转为+8.26亿。
- **[营销模式创新+后市场生态]** -> [新利润增长点]: “爱易科”生态品牌覆盖能源、租赁、二手车等，后市场业务成为利润增量来源，降低对整车销售的依赖。
- **[“以旧换新”政策红利]** -> [国内销量结构性增长]: 政策拉动重卡等品类需求，公司紧抓机会实现国内销量32.2%的营收增长，但毛利率下滑2.4个百分点。
- **[研发资本化率55%]** -> [短期利润平滑，长期技术储备]: 研发投入23.06亿，资本化12.69亿，降低当期费用压力，但未来摊销可能影响后续利润。

## 风险警告
**核心风险：母公司未弥补亏损高达38.1亿元，持续不分红。** 尽管2025年归母净利润暴增至13.64亿，但母公司未分配利润仍为-38.1亿，导致公司连续多年无法满足现金分红条件。这意味着股东无法分享业绩增长红利，公司治理层面存在历史包袱，长期价值兑现路径不清晰。

**结构性风险：国内业务毛利率持续下滑，新能源盈利尚待验证。** 2025年国内业务毛利率仅7.9%，同比下降4.72个百分点，显示国内市场竞争激烈、价格战压力大。新能源销量虽暴增87%，但子公司北京卡文新能源亏损1.96亿，新能源业务整体仍处于“增收不增利”阶段。若补贴退坡或竞争加剧，新能源板块可能拖累整体盈利。

**财务风险：担保总额占净资产96.2%，关联交易高度集中。** 公司对外担保余额高达150.25亿元，占净资产96.21%，其中为关联方（如中车信融、安鹏中融）担保占比极高。前五大客户中关联方销售占比22.21%，前五大供应商中关联方采购占比21.8%，经营独立性存疑。一旦关联方出现信用风险，公司将面临巨额代偿压力。
