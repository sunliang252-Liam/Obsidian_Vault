# 002080.SZ 深度透视

## 因果逻辑链
- **AI算力需求爆发** -> 特种纤维布量价齐升: 公司凭借低介电、低膨胀纤维布技术先发优势，全年销售1,917万米，成为利润新增长点，推动玻纤毛利率同比提升9个百分点。
- **风电行业景气度回升** -> 风电叶片销量与盈利双增: 受益于国内新增装机创历史新高（+50.4%），公司叶片销量36GW（+51%），收入125.9亿元（+47%），归母净利润6.2亿元（+81%）。
- **锂电池隔膜产能释放与结构优化** -> 收入高增但盈利承压: 全年销量33亿平米（+76%），涂覆产品占比提升至49%，但行业产能过剩导致价格竞争激烈，子公司中材锂膜仍处于亏损状态。
- **高端化战略驱动产品结构升级** -> 玻纤盈利能力大幅修复: 公司主动收缩低毛利产品，聚焦风电纱、LFT纱、特种纤维布等高附加值产品，全年玻纤销售均价同比提升14%，归母净利润同比增长187%。
- **国际化布局加速** -> 打开海外增长空间: 巴西叶片基地全面投产，中亚项目落地，匈牙利锂膜基地启动建设，海外客户销量同比增长67%，为全球份额提升奠定基础。
- **精益管理与全链条降本** -> 成本端有效对冲: 风电叶片单位成本同比下降4%，锂膜单位成本同口径下降约10%，OEE提升7个百分点，在价格压力下维持了盈利能力。

## 风险警告
**核心风险在于同业竞争承诺的反复延期与行业供需失衡。** 公司与中国巨石的同业竞争问题已多次延期至2026年12月，整合方案迟迟未落地，悬而未决的治理问题压制估值中枢。同时，锂电池隔膜行业产能严重过剩，子公司中材锂膜虽销量暴增76%但仍在亏损，若价格战持续或下游需求放缓，将拖累整体利润。

**第二重风险来自国际化进程的不确定性。** 公司三大主业均处于海外扩张期，但境外投资经验不足、地缘政治风险（如贸易壁垒）以及汇率波动（海外业务以美元结算）可能侵蚀利润。此外，玻纤和叶片业务的高增长部分依赖政策红利（如风电装机目标），若政策力度不及预期或行业竞争加剧，业绩增速可能回落。
