# 600293.SH 深度透视

## 因果逻辑链
- **[房地产下行周期]** -> [营收暴跌31.43%]: 作为房地产后周期产品，约80%玻璃用于建筑，地产需求萎缩直接导致公司产品量价齐跌。
- **[供需结构失衡]** -> [扣非净利润巨亏1.58亿]: 浮法玻璃产能过剩、库存高企，价格长期在成本线附近徘徊，主营盈利能力被彻底击穿。
- **[资产处置收益]** -> [账面净利润仅亏0.30亿]: 通过出售冷修生产线回收的锡锭及固定资产，获得1.27亿非经常性损益，掩盖了主营业务深度亏损的真相。
- **[现汇回款占比下降]** -> [经营现金流净流出2.13亿]: 营收规模大幅下降叠加营销政策调整，导致现金回收能力恶化，经营活动现金流转为巨额净流出。
- **[高额政府补助]** -> [非经常性损益占比畸高]: 计入当期损益的政府补助高达9565万元，占非经常性损益总额的75%，公司对政策性输血依赖度极高。
- **[硅砂自给率超50%]** -> [部分对冲成本压力]: 自有硅砂矿年产能50万吨，保障了核心原料供应稳定，在纯碱等大宗商品价格波动中形成相对成本优势。
- **[色玻新品开发]** -> [拓展第二增长点]: 成功推出欧洲灰、福特蓝等色玻产品，有效扭转白玻亏损态势，但体量尚小，难以对冲整体下行趋势。

## 风险警告
**核心风险在于主营业务已丧失造血能力。** 扣非净利润巨亏1.58亿元，且亏损幅度同比扩大601%，表明公司核心的浮法玻璃业务在供需失衡的市场环境下已陷入深度亏损。公司账面净利润仅亏0.30亿，完全依赖资产处置、政府补助等非经常性损益粉饰，这种“拆东墙补西墙”的盈利模式不可持续。一旦资产处置完毕或政府补贴退坡，公司将暴露真实的巨额亏损。

**财务结构恶化与历史遗留问题形成双重隐患。** 经营活动现金流净流出2.13亿元，同比骤降72,704%，显示公司已无法通过自身经营产生正向现金流，需依赖大规模新增贷款（筹资活动净流入3.48亿）来维持运营，偿债压力持续攀升。同时，公司仍面临为原子公司深圳恒波15,000万元担保的诉讼风险，一审判决公司需承担连带清偿责任，若二审维持原判，将对公司现金流和利润表造成重大冲击。母公司累计未弥补亏损高达15.73亿元，长期无法分红，股东回报前景黯淡。
