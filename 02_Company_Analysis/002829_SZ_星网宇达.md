# 002829.SZ 深度透视

## 因果逻辑链
- **[军队采购资质恢复]** -> [营收降幅收窄]: 2024年被列入禁止采购名单导致军工订单阶段性调整，2025年11月恢复资格后，营收降幅从2024年的-45.1%收窄至-10.6%。
- **[核心子公司星网卫通巨额亏损]** -> [归母净利润连续两年为负]: 星网卫通2025年净利润-1.76亿元，是公司整体亏损-1.09亿元的主要拖累，表明核心业务盈利能力严重恶化。
- **[联营企业星华智联公允价值变动收益]** -> [非经常性损益掩盖主业亏损]: 确认6,387万元投资收益，使扣非净利润-1.84亿元远大于归母净利润-1.09亿元，主业造血能力堪忧。
- **[高额应收账款与存货]** -> [现金流持续为负]: 应收账款6.86亿、存货5.31亿合计占总资产53%，导致经营活动现金流净额-9,343万元，连续三年为负。
- **[军品审价机制不确定性]** -> [收入与利润波动风险]: 部分军品价格由军方审价确定，审价周期长且最终价可能低于暂定价，导致已确认收入存在调减风险。
- **[研发投入资本化率低]** -> [技术转化效率待考]: 研发投入占营收23.66%，但资本化率仅6.22%，大量研发费用直接费用化，短期压制利润，长期转化效果不明。
- **[募投项目进度严重滞后]** -> [战略扩张受阻]: “无人机系统研究院项目”投资进度仅11.79%，完成时间延期至2028年，核心产能与研发能力建设远不及预期。

## 风险警告
公司连续两年巨额亏损，核心子公司星网卫通是亏损主源，表明其军工主业在经历采购禁令冲击后，盈利能力尚未恢复。更危险的是，扣非净利润亏损额（-1.84亿）远超归母净利润（-1.09亿），说明公司依赖非经常性损益（联营企业投资收益）粉饰报表，主业造血能力已近枯竭。应收账款与存货合计超13亿元，占净资产比例极高，且经营活动现金流连续三年为负，表明公司面临严重的资产减值与流动性危机。

公司战略转型方向（低空经济、机器人等）虽具想象力，但“无人机系统研究院”这一核心募投项目进度严重滞后，研发投入资本化率极低，表明技术成果转化与产业化落地能力存疑。在军工主业尚未企稳、现金流持续失血的背景下，新业务的投入能否转化为有效增长，存在巨大不确定性。此外，军品审价机制、人才流失等风险持续存在，公司基本面改善尚需时日。
