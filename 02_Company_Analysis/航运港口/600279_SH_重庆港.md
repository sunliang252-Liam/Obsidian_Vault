# 600279.SH 深度透视

## 因果逻辑链
- **装卸业务量增长** -> **扣非净利润扭亏为盈**: 货物吞吐量同比增长7.9%、集装箱吞吐量增长11.4%，带动装卸及客货代理业务收入增长18.73%，是主营业务盈利改善的核心驱动力。
- **商品贸易业务扩张** -> **营收规模稳定增长**: 铁矿、煤、焦炭等大宗贸易收入增长11.47%，推动总营收同比增长2.29%，但该业务毛利率仅2.24%，对利润贡献有限。
- **财务费用大幅降低** -> **利润总额超额完成计划**: 存量贷款利率下降及寸滩收储影响，财务费用同比减少43.56%，节省约4657万元，直接增厚利润。
- **寸滩港土地收储非经常性损益消退** -> **归母净利润同比大幅下降**: 2024年确认大额资产处置收益10.67亿元，而2025年仅增加0.37亿元，导致归母净利润同比下滑90.78%。
- **疆煤入渝“铁水联运”模式突破** -> **新货源增长点形成**: 开辟新疆至长江中下游多式联运新途径，疆煤量同比增长110%，铁水联运占比超95%，物流效率提升30%以上。
- **新建港口产能释放** -> **区域控制力增强**: 化工码头、江津港、珞璜港改扩建项目投产，化工码头吞吐量增长40.6%，珞璜港新增产能470万吨，巩固了区域龙头地位。
- **“无水港”网络拓展** -> **腹地货源挖掘深化**: 新设6个无水港，累计达11个，全年货运量同比增长189%，有效延伸了港口服务半径，对冲了腹地经济波动风险。

## 风险警告
**核心风险在于主营业务盈利能力依然脆弱。** 尽管扣非净利润扭亏为盈，但绝对值仅349.55万元，ROE低至0.72%。公司收入高度依赖低毛利的商品贸易业务（占比58%），而核心的装卸业务虽增长强劲，但毛利率同比下降0.78个百分点，显示行业“内卷”竞争正在侵蚀利润空间。一旦宏观经济下行或腹地产业波动导致吞吐量增速放缓，公司极易重回亏损状态。

**另一重大风险是资产处置收益的不可持续性。** 寸滩港收储补偿款已基本确认完毕，未来不再有类似大额非经常性损益支撑利润。同时，珞璜港等新建项目仍处于亏损状态（2025年净亏损5730万元），叠加公司资产负债率37.34%且存在大量受限资产（固定资产抵押11.18亿元），财务弹性有限。若新项目无法快速扭亏，公司整体盈利将面临较大压力。

> 重庆港股份有限公司(以下简称“重庆港”)系重庆物流集团有限公司重要子企业,于2000年7月31日在上海证券交易所挂牌上市(股票代码“600279”),全国5A级物流企业,中国西部地区最大的内河主枢纽港、集装箱吞吐港运营企业。重庆港拥有分公司2户、全资及控股二级企业12户、参股二级企业3户,主要经营管理重庆市内重点公共港口码头。目前已形成集装箱、件杂散货、商品车和化工等现代化、专业化码头集群,年货物吞吐能力近7000万吨、集装箱吞吐能力267万TEU;拥有果园港、万州红溪沟、江津兰家沱和珞璜港4个铁水联运港区,铁路专用线49公里,铁路年作业能力3100万吨。港口年集装箱吞吐量占全市90%以上,年铁水联运量占全市95%以上,对长江上游及西部地区具有强劲的物流集聚辐射影响力。所属果园港是国家发展改革委、交通运输部、重庆市重点规划建设的第三代现代化内河港口,是全国首批港口型国家物流枢纽,国家一类开放口岸,国家多式联运示范工程项目,是长江上游航运中心建设的标志性工程,其集装箱码头是长江上游地区首家“四星级绿色港口”。立足新时代新发展,重庆港将时刻牢记习近平总书记对港口提出的“三个好”“四个一流”“三个服务好”殷殷嘱托,紧紧围绕“一带一路”发展、长江经济带建设、成渝地区双城经济圈建设、西部陆海新通道建设、交通强国建设等国家战略,积极融入集团“六个一体化”现代物流运营体系,为重庆建设长江上游航运中心、打造内陆开放高地贡献港口力量。
