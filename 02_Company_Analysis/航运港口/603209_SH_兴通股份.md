# 603209.SH 深度透视

## 因果逻辑链
- **[外贸船队规模扩张]** -> [营收增长7.51%]: 外贸船舶增至10艘，运力16.88万载重吨，拉动境外收入增长19.05%，但高基数效应下运价下行，导致增收不增利。
- **[国内运价承压下行]** -> [净利润下降22.95%]: 2025年国内沿海化学品平均运价同比下降约12.5%，叠加下游需求偏弱，内贸毛利率减少6.69个百分点，侵蚀利润。
- **[新船交付与折旧增加]** -> [营业成本增长19.72%]: 甲醇双燃料船等高端运力集中投产，船员薪酬、船舶折旧、港口费用等刚性成本大幅增加，成本增速远超收入。
- **[期租模式锁定收益]** -> [经营稳定性提升]: 12艘船舶签订期租合同，运力占比35.47%，与荣盛控股、Petrobras等锁定固定租金，对冲市场运价波动风险。
- **[高端绿色船队壁垒]** -> [长期竞争力强化]: 化学品船平均船龄7.26年，不锈钢船占比70.59%，远优于全球平均（16.3年/39%），满足高端客户与环保合规刚需。
- **[定增募资与股权合作]** -> [资本结构优化]: 完成6.43亿元定增，引入建发股份、厦门象屿等战略伙伴，合资设立兴通链发、控股香港兴耀，实现“运力+货源”深度绑定。
- **[安全合规标杆]** -> [客户粘性与运力审批优势]: 连续8年获“安全诚信公司”，SIRE/CDI检查通过率100%，在交通运输部新增运力评审中连续七年八次获第一，巩固龙头地位。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以逆转。** 公司营收增长主要依赖外贸船队规模扩张，但国际化学品运价受全球贸易疲软、地缘政治扰动及高基数效应影响，2025年已出现下滑。同时，新造船集中交付带来的折旧、人工、港口等刚性成本大幅攀升，成本增速（19.72%）远超收入增速（7.51%），导致毛利率显著收窄。若2026年全球化学品海运需求复苏不及预期（Drewry预测仅增长2.2%），公司利润端将持续承压。

**第二大风险是国际化扩张带来的经营与财务不确定性。** 公司国际业务尚处成长期，面临北欧、新加坡等成熟船东的激烈竞争，以及地缘冲突、贸易壁垒、汇率波动等多重挑战。2025年财务费用因汇兑损失增加30.46%，境外业务毛利率仅22.09%，远低于内贸的33.91%。此外，公司资产负债率因大规模资本开支（在建船舶9艘）处于高位，担保总额占净资产42.60%，若新造船项目延期或市场下行，将放大财务杠杆风险。

**公司简介（F10 原文）**

> 兴通海运股份有限公司成立于1997年12月,主要从事全球散装液体危险货物的水上运输业务。2022年3月24日于上海证券交易所主板挂牌上市,股票代码:603209。公司是中国船东协会化工品运输专业委员会副主任单位、福建省船东协会副会长单位、泉州船东协会会长单位,是福建省三大航运领军企业之一。公司致力于成为“国际一流、国内领先的化工供应链综合服务商”。以“1+2+1”战略发展规划为指引,公司在主营业务上不断深耕,持续提质降本增效,以做大做强国内沿海液货危险品运输业务为主线,以开拓清洁能源运输和参与国际海运为两翼,以打造数字化平台为助力,向化工供应链综合服务商转型升级,实现高质量发展。经过多年积累,公司已发展成为国内沿海散装液体化学品航运业的龙头企业,在细分市场占据领先地位。在国内运输板块,公司运输航线通达全国沿海及长江、珠江中下游水系,形成了可辐射渤海湾、长三角、珠三角、北部湾等国内主要化工产业基地的运输网络体系,承运货品种类主要有对二甲苯、乙二醇、纯苯、苯酚、聚醚多元醇、液碱、甲醇、航空煤油、丁二烯、丁烷等石油化工产品。公司主要客户为中国石化、中国海油、中国石油、中国航油、荣盛石化、盛虹石化、中海壳牌、万华化学、福建联合石化等大型石化企业,公司多次荣获下游客户“安全诚信最佳物流服务商”、“优秀供应商”、“优秀服务商”等称号。在国际运输板块,公司船舶主要航行于东北亚、东南亚、中东、地中海、西北欧、南美洲等地区,主要承运货品包括乙二醇、苯酚、二甘醇、苯乙烯、棕榈油、基础油等,主要服务客户有SABIC、RELIANCE、WILMAR、CEPSA、CARGILL、ENOC、PETRONAS、SIPCHEM、SK、SAMCO、SYNERGY、PETROBRAS等。公司于2002年10月开始运行安全管理体系(SMS),于2003年5月通过福建海事局审核,取得DOC证书及船舶SMC证书,至今已持续运行23年。自2015年以来,公司累计已有56艘次船舶“零缺陷”通过海事安检。2012年至今,公司船舶接受BP、SHELL、PETRON、CNOOC、中石化、中化等国内外大石油公司以及CDI等第三方检查达100多艘次,覆盖所有船舶。经多年在沿海省际液货危险品水上运输领域的深耕,公司在安全管理水平等方面具有突出优势,于2018年被交通运输部海事局评为“安全诚信公司”,累计已有8艘船舶被中华人民共和国海事局评为“安全诚信船舶”,16位船长被评为“安全诚信船长”。其中“安全诚信公司”和“安全诚信船舶”作为航运公司和中国籍船舶安全类的重要荣誉,是展现公司综合实力的一项重要指标。公司愿景:国际一流、国内领先的化工供应链综合服务商(一流的船队,一流的服务,一流的管理,一流的团队,一流的文化)公司使命:以更安全、更高效和更可信赖的服务最大化地回报我们的客户、投资者、员工和社会公司价值观:以人为本,以新为向,创造价值,追求卓越公司发展理念:对标国际一流,实现企业高质量发展,为国家海运强国做贡献。
