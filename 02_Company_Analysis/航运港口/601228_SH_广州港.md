# 601228.SH 深度透视

## 因果逻辑链
- **公司精准把握利率下行契机，发行42亿元公司债置换存量债务** -> 财务费用增加9.47%（费用化利息支出增加）: 虽然发行债券降低了平均融资成本，但新增债券导致利息支出总额增加，且部分利息费用化而非资本化，推高了财务费用。
- **研发投入增长9.2%，实施科技项目75项，推进港口数字化智能化转型** -> 研发费用增加32.14%: 公司加大科技创新投入，新增研发项目导致研发费用同比大幅增长。
- **贸易业务收入减少22.30%** -> 营业收入减少1.99%: 贸易业务收入大降拖累整体营收，虽然装卸及物流业务收入增长，但未能完全抵消贸易业务下滑的影响。
- **贸易业务收入减少22.30%** -> 营业成本减少3.56%: 贸易业务成本随收入同步下降，且降幅小于收入降幅，导致贸易业务毛利率微降。
- **物流及港口辅助业务收入增长17.61%，成本增长13.60%** -> 物流及港口辅助业务毛利率增加2.81个百分点: 运输业务增加带来收入增长，成本增速低于收入增速，毛利率提升。
- **计提的坏账准备增加** -> 信用减值损失大幅增加（-4,061.72%）: 本期应收账款回收风险上升，导致信用减值损失计提金额远超去年同期。
- **本期收到的税费返还减少** -> 经营活动产生的现金流量净额减少6.63%: 税费返还减少直接导致经营活动现金流净额下降。
- **本期投资现金流出增加** -> 投资活动产生的现金流量净额减少10.73%: 在建工程等资本性投资支出增加，导致投资活动现金净流出扩大。
- **本期借款流入增加** -> 筹资活动产生的现金流量净额大幅增加354.86%: 公司发行债券和增加借款，带来筹资活动现金净流入显著增加。
- **在建工程投入增加（如南沙国际通用码头等）** -> 在建工程余额增长60.73%: 多个重大在建项目持续推进，资本开支增加，在建工程账面价值大幅上升。

## 风险警告
公司信用减值损失同比激增超40倍，反映应收账款回收风险显著上升，需警惕坏账对利润的侵蚀；同时财务费用因债券利息费用化而增加，债务扩张可能带来偿债压力。此外，贸易业务收入持续萎缩，毛利率微降，该板块盈利能力减弱。营业收入微降而成本降幅更大，但毛利率改善有限，整体盈利增长乏力。
