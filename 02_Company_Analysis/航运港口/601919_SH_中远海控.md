# 601919.SH 深度透视

## 因果逻辑链
- **[市场运价大幅回落]** -> [营收与利润双降]: 2025年SCFI和CCFI综合运价指数全年均值同比分别下滑37%和23%，直接导致公司集装箱航运业务收入同比下降6.74%，归母净利润同比下降37.13%至308.68亿元。
- **[运力供给增速高于需求]** -> [行业竞争加剧]: 全球集装箱船队运力同比增长约7%，而运输需求仅增长约3.5%，供需失衡是运价承压的根本原因。
- **[红海效应退坡与联盟重组]** -> [市场波动加剧]: 红海局势缓和及海洋联盟格局调整，导致运价在抢运潮后快速回调，全年波动剧烈，增加了经营不确定性。
- **[绿色船队与数字化投入]** -> [成本刚性增长]: 公司持续推进绿色甲醇船舶交付和数字化供应链建设，叠加环保合规成本，导致营业成本同比增长6.51%，侵蚀利润空间。
- **[供应链收入增长]** -> [业务结构优化]: 除海运以外的供应链收入达448.88亿元，同比增长9.64%，成为对冲传统海运收入下滑的重要缓冲。
- **[大规模股份回购与高分红]** -> [股东回报强化]: 全年回购A+H股合计65.61亿元，叠加现金分红154.12亿元，合计占归母净利润比例达57.27%，彰显公司对股东价值的重视。

## 风险警告
**核心风险在于运价持续下行与成本刚性上涨的剪刀差。** 2026年市场供需增速双双放缓，但供给增速仍大于需求，运价面临进一步下行压力。与此同时，公司船队绿色化升级（42艘甲醇双燃料船在建）、数字化投入及环保碳税成本持续攀升，成本端难以压缩。若运价跌幅超预期，公司盈利能力将显著承压，当前13.17%的ROE存在进一步下滑风险。

**地缘政治与贸易政策不确定性是最大外部变量。** 全球关税政策反复、中东局势紧张及红海复航节奏不明，均可能剧烈冲击运输需求与航线效率。公司虽通过全球化布局分散风险，但任何单一区域的重大冲突或贸易壁垒升级，都可能导致局部运营受限、货量骤降，进而影响整体业绩稳定性。
