# 001205.SZ 深度透视

## 因果逻辑链
- **[石化行业景气度下行]** -> [运价承压与收入下滑]: 下游化工客户成本传导及装置检修，导致内贸化学品运价与周转量下降，全年营收同比-3.79%。
- **[内贸油品运量爆发式增长]** -> [收入结构优化]: 依托盛航浩源运力，内贸油品运量同比+88.89%，油品运输收入同比+79.86%，部分对冲化学品运输下滑。
- **[外贸运价回调]** -> [境外收入下降]: 国际化学品市场供需变化及油价波动，导致外贸运价下调，境外收入同比-7.27%。
- **[运力规模持续扩张]** -> [成本刚性增长]: 船舶数量增至54艘，导致人工、修理费等运营成本增加，直接人工同比+8.75%。
- **[期租业务占比提升]** -> [收入模式转变]: 期租运输收入同比+55.40%，但毛利率下降9.94个百分点，反映公司主动增加稳定但利润率较低的期租业务以对冲航次运价波动。
- **[控制权变更与组织调整]** -> [非经常性损益波动]: 2025年1月控股股东变更为万达控股集团，管理层改选，叠加出售联营企业安德福能源科技股权，导致非经常性损益大幅波动。
- **[高资本开支与债务偿还]** -> [现金流压力]: 投资活动现金净流出2.98亿元，同时提前偿还借款导致筹资活动现金净流出1.79亿元，自由现金流承压。

## 风险警告
**核心风险在于石化行业景气度下行与运价持续承压。** 公司内贸化学品运输收入占比高达76.58%，但该业务受下游化工行业景气度影响显著，2025年已出现量价齐跌。若未来石化行业产能过剩加剧或需求疲软，公司核心收入来源将持续面临萎缩压力，而运力扩张带来的固定成本刚性增长将进一步侵蚀利润。

**第二大风险是控制权变更后的战略整合与客户关系稳定性。** 2025年1月公司实际控制人由创始人李桃元变更为万达控股集团，管理层发生重大更迭。新控股股东与原有核心客户（中石化、中石油等）的合作关系、以及公司“大客户”战略的延续性存在不确定性。若客户因控制权变更调整合作策略，将对公司业务稳定性造成重大冲击。
