# 001205.SZ 深度透视

## 因果逻辑链
- **[石化行业景气度下行]** -> [运价承压与收入下滑]: 下游化工客户成本传导及装置检修，导致内贸化学品运价与周转量下降，全年营收同比-3.79%。
- **[内贸油品运量爆发式增长]** -> [收入结构优化]: 依托盛航浩源运力，内贸油品运量同比+88.89%，油品运输收入同比+79.86%，部分对冲化学品运输下滑。
- **[外贸运价回调]** -> [境外收入下降]: 国际化学品市场供需变化及油价波动，导致外贸运价下调，境外收入同比-7.27%。
- **[运力规模持续扩张]** -> [成本刚性增长]: 船舶数量增至54艘，导致人工、修理费等运营成本增加，直接人工同比+8.75%。
- **[期租业务占比提升]** -> [收入模式转变]: 期租运输收入同比+55.40%，但毛利率下降9.94个百分点，反映公司主动增加稳定但利润率较低的期租业务以对冲航次运价波动。
- **[控制权变更与组织调整]** -> [非经常性损益波动]: 2025年1月控股股东变更为万达控股集团，管理层改选，叠加出售联营企业安德福能源科技股权，导致非经常性损益大幅波动。
- **[高资本开支与债务偿还]** -> [现金流压力]: 投资活动现金净流出2.98亿元，同时提前偿还借款导致筹资活动现金净流出1.79亿元，自由现金流承压。

## 风险警告
**核心风险在于石化行业景气度下行与运价持续承压。** 公司内贸化学品运输收入占比高达76.58%，但该业务受下游化工行业景气度影响显著，2025年已出现量价齐跌。若未来石化行业产能过剩加剧或需求疲软，公司核心收入来源将持续面临萎缩压力，而运力扩张带来的固定成本刚性增长将进一步侵蚀利润。

**第二大风险是控制权变更后的战略整合与客户关系稳定性。** 2025年1月公司实际控制人由创始人李桃元变更为万达控股集团，管理层发生重大更迭。新控股股东与原有核心客户（中石化、中石油等）的合作关系、以及公司“大客户”战略的延续性存在不确定性。若客户因控制权变更调整合作策略，将对公司业务稳定性造成重大冲击。

> 南京盛航海运股份有限公司(以下简称“公司”)为深圳证券交易所主板上市公司(证券简称:盛航股份;证券代码:001205)。公司成立于1994年11月,2014年10月完成企业的股份制改革并于2015年6月成功登陆“新三板”;2017年8月,公司进入A股上市辅导阶段,引进多家国内知名的战略投资机构,公司在资本市场翻开了新篇章;2021年5月13日公司首次公开发行股票并在深圳证券交易所成功上市。公司作为国内液体化学品航运龙头企业之一,深耕于危化品水路运输领域,持续为国际、国内大型化工企业提供配套物流服务,公司主要从事国内沿海、长江中下游及国际液体化学品、液化石油气、成品油水上运输业务,承运的化学品种类包括二甲苯、混合二甲苯、纯苯、甲苯、邻二甲苯、丙烯腈、苯乙烯、甲醇、乙二醇、苯酚、浓硫酸、液碱、液氨等,承运的油品包括汽油、柴油、航空煤油、石脑油、棕榈油等,覆盖了市场上有运输需求的绝大部分液体化学品及油品种类。通过十余年经营液货危险品运输业务,公司逐渐形成了以全国36个沿海主要港口、20余个长江及珠江港口为物流节点,以武汉到上海的长江航线为横轴、以环渤海湾到海南的沿海航线为纵轴的运输网络,覆盖渤海湾、长三角、珠三角、北部湾等国内主要化工生产基地。随着公司国际危化品运输业务的发展,公司运输航线已拓展至东南亚、东北亚、印度、澳大利亚等区域。公司拥有十余年聚焦液货危险品航运业务的丰富经验,通过严格的航运管理和充分利用现代化信息技术,为客户提供安全、优质的化学品航运服务。公司高度重视运输安全风险管理,建立了高标准、专业化的安全运输管控体系,成为交通运输部认定的交通运输企业安全生产标准化建设一级达标企业,被中国物流与采购联合会评定为“AAAA级物流企业”、“2024年度中国化工物流行业安全管理企业”以及“2023-2024年度化工物流TOP水运服务企业”。公司数艘船舶被中华人民共和国海事局评为“安全诚信船舶”。公司与中石化、中石油、中化集团、恒力石化、浙江石化、扬子石化-巴斯夫、盛虹炼化、埃克森美孚、日本三菱、日本出光、壳牌、沙比克、沙特阿美、道达尔、GS加德士、泰国国家石油公司、马来西亚国家石油等国内外大型石化生产企业形成了良好的合作关系,提供安全、优质、高效的水上运输服务,获得了客户的高度认可。近年来保持快速、健康的发展趋势,公司以安全管理为重点,聚焦客户需求,凭借优质、高效的物流服务,在行业内积攒了良好口碑。公司将始终秉承“诚信、安全、环保、质量、健康”的经营理念,专注于散装液体危险品运输领域,坚持创新并持续完善经营模式,不断巩固和发展优质客户并确立战略合作关系,提升公司的核心竞争力。全力打造成为备受客户信赖的、具有世界影响力的新型物流链企业集团。
