# 601326.SH 深度透视

## 因果逻辑链
- **[煤炭运输主枢纽地位]** -> [吞吐量增长]: 秦皇岛港作为“西煤东运”核心港口，通过设备更新和精准营销，煤炭吞吐量创4年新高，带动整体营收增长1.75%。
- **[降本节支措施]** -> [毛利率提升]: 公司落实降本增效，营业成本同比下降4.13%，推动毛利率同比提升3.58个百分点至41.67%。
- **[财务杠杆优化]** -> [财务费用锐减]: 持续压降借款规模和享受贷款利率下行红利，财务费用同比大幅下降73%，直接增厚利润。
- **[河北省港口资源整合]** -> [协同效应]: 控股股东整合秦、唐、沧三港资源，实现“水水中转”和多港区协同，黄骅港吞吐量同比大增8.04%。
- **[智慧港口建设]** -> [生产效率提升]: 研发投入聚焦自动化改造，全货类综合装卸效率同比提高4.6%，为吞吐量增长提供技术支撑。
- **[内退福利计提]** -> [管理费用增加]: 计提内退福利导致管理费用同比增加11.98%，部分抵消了成本管控带来的利润增量。
- **[联营企业利润波动]** -> [投资收益下降]: 主要联营企业曹妃甸实业港务净利润减少，导致公司投资收益同比下降9.64%。

## 风险警告
**核心风险在于能源结构转型与腹地竞争的双重挤压。** 公司煤炭业务贡献超50%营收，但“碳达峰、碳中和”政策正加速能源结构转型，清洁能源发电占比提升将长期压制煤炭需求。同时，进口煤冲击及周边港口（如天津港）的激烈竞争，可能导致公司煤炭吞吐量增长乏力甚至下滑，这是公司最根本的长期经营风险。

**财务层面需关注现金流与资产结构的变化。** 尽管利润增长，但经营活动现金流净额同比下降4.83%，且应收账款同比大增66.56%，显示回款压力增大。此外，货币资金大幅减少33.48%的同时，其他非流动资产（一年以上定期存款）激增96.39%，资产流动性有所下降，需警惕资金运用效率及潜在的流动性管理压力。

> 秦皇岛港股份有限公司(以下简称“秦港股份”,股票代码601326,HK03369)是河北港口集团控股子公司,全球最大大宗干散货公众码头运营商,分别于2013年,2017年在香港联交所,上海证券交易所上市,成为河北省首家布局A+H股双资本平台的国有企业。近年来,秦港股份积极融入“一带一路”建设、京津冀协同发展,坚持港产城互动,深化与大企业强强合作,统筹布局津冀港口项目,业务涵盖秦皇岛港、唐山曹妃甸港区、沧州黄骅港区三大港区,拥有煤炭、杂货矿石、油品、集装箱等现代化专业泊位,已形成包括货物装卸、堆存、仓储、运输等基础服务以及货运代理、多式联运在内的港口物流链。秦皇岛港开埠于1898年,是位于东北、华北咽喉地带的天然不冻港,为我国北方首个自开口岸。经过百余年的岁月洗礼,秦皇岛港已发展为全球最大公众煤炭码头和干散货运输港口。作为能源输出为主的多功能综合性国际贸易大港,秦皇岛港与大秦铁路无缝对接,是我国能源运输的主枢纽港,发挥着国家“煤炭价格稳定器”和“北煤南运蓄水池”作用。唐山曹妃甸港区是渤海湾内的天然良港,港口腹地覆盖了中国重要的钢铁、石化及煤炭基地,是我国北方重要的矿石中转港。沧州黄骅港区是河北省南部沿海地区重要的新兴港口,地理位置优越,是晋冀鲁豫及大西北最经济、最便捷的出海口,被誉为“亚欧大陆桥新通道”。面向未来,创造了百年传奇的秦港股份将紧紧抓住发展的历史窗口期和战略机遇期,秉承“为国家做贡献、为企业谋发展、为客户创价值、为职工尽责任”的企业价值观,进一步深化企业转型升级,全力推进智能港口、效率港口、平安港口、绿色港口、服务港口建设,进一步调整优化港口功能和货类结构,稳煤、强矿、增油,推动杂货、集装箱业务跨越式发展;加强资本运作,充分发挥A+H股的双资本平台作用,进一步拓宽资本渠道,提升公司核心竞争力;深挖港口增值服务,整合产业链上下游业务,延伸物流服务体系;坚持以效益为核心,提升自身盈利能力和可持续发展能力,努力成为治理制度完善、竞争优势强劲、经济效益领先、集码头运营和综合物流服务商、资本运营商于一体的港口产业集群经营人,以高质量发展,为建设新时代经济强省、丽河北做出新的积极贡献。
