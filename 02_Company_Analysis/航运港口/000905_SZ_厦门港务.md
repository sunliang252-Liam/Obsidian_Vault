# 000905.SZ 深度透视

## 因果逻辑链
- **[重大资产重组注入集装箱码头资产]** -> [业务结构优化]: 收购厦门集装箱码头集团70%股权，形成“集装箱+散杂货”双轮驱动，强化港口主业核心竞争力。
- **[港航贸一体化战略深化]** -> [货源引流与协同]: 以“港贸结合、以贸促港”原则，为厦门港引流散杂货吞吐量超400万吨、集装箱超6000TEU，实现业务相互赋能。
- **[“一江两湖”腹地拓展与海铁联运]** -> [货源腹地扩张]: 海铁联运业务量同比增长19.2%，通过“南昌-厦门港”等班列线路，将服务网络深入江西、湖北等内陆地区，降低对单一腹地的依赖。
- **[新能源拖轮与设备电动化]** -> [绿色低碳转型与成本优化]: 建成国内规模最大的新能源拖轮船队，纯电动拖车投用，降低燃料成本与碳排放，响应“双碳”战略并提升ESG评级。
- **[综合供应链业务聚焦核心货种]** -> [利润稳定器]: 围绕煤炭、粮食等大宗商品提供全程供应链服务，港务贸易净利润同比增长41%，成为公司新的增长曲线，平滑码头业务的周期性波动。
- **[3A主体信用评级与融资渠道拓宽]** -> [财务成本降低]: 成功获评3A主体信用等级，完成30亿元超短期融资券注册，降低融资成本，为后续资本运作和项目投资提供低成本资金支持。
- **[跨境电商与对台物流通道建设]** -> [新兴业态增长]: 跨境电商监管中心操作票数同比增长78%，对台跨境电商航线常态化运作，抓住两岸融合发展机遇，开辟新的利润增长点。

## 风险警告
**核心风险在于宏观经济与贸易政策的高度敏感性。** 公司业务与全球贸易、大宗商品价格及腹地经济景气度强相关。美国关税政策、地缘政治冲突（如俄乌、中东）及逆全球化趋势，将直接冲击港口吞吐量和综合供应链业务需求。2025年境外营业收入同比骤降85.53%，已显露出外部环境恶化的端倪。若贸易摩擦持续升级，公司港口主业及贸易业务将面临量价齐跌的风险。

**另一重大风险是资产重组后的整合与业绩兑现。** 公司刚完成对厦门集装箱码头集团70%股权的收购，虽然战略方向明确，但“集装箱+散杂货”双轮驱动的协同效应能否如期释放，以及新注入资产的盈利能力、管理整合、文化融合均存在不确定性。同时，公司部分新投产码头（如古雷港发）仍处于亏损状态，固定成本压力较大，若后续货源开拓不及预期，将持续拖累整体利润。此外，公司综合供应链业务中衍生品套保规模较大（期末衍生品投资占净资产35.10%），若大宗商品价格或汇率剧烈波动，套保失效将带来重大财务损失。
