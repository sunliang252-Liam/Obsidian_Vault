# 601022.SH 深度透视

## 因果逻辑链
- **[运力扩张与航线优化]** -> [集装箱运量增长14.04%]: 新投运8艘1000TEU船，优化东北亚、东南亚航线，加密支线班次，直接驱动箱量提升。
- **[内贸与散货市场回暖]** -> [运价回升]: 内贸PDCI指数同比回升6.24%，沿海散货CCBFI指数同比上移3.92%，带动公司整体运价水平上升。
- **[运量增长与运价回升]** -> [营收增长15.86%]: 集装箱运量585万TEU（+14.04%）、散货运量2705万吨（+4.50%）叠加运价改善，共同推动收入增长。
- **[收入增速快于成本增速]** -> [毛利率提升1.47个百分点]: 运输服务毛利率同比增加1.46个百分点，成本管控有效，利润弹性释放。
- **[绿色智能船队建设]** -> [核心竞争力与品牌溢价]: 纯电动船入选国家示范项目，31艘船获绿色认证，提升运营效率与客户认可度，支撑长期盈利能力。
- **[国际化布局加速]** -> [开辟新增长极]: 设立新加坡、日本子公司，开启外贸散货业务，拓展中东航线，降低对单一市场的依赖。
- **[汇兑损失增加]** -> [财务费用由负转正]: 财务费用从-4037万转为153万，主要因汇兑损失增加，侵蚀部分利润。

## 风险警告
**核心风险在于航运市场的强周期性与运价波动。** 2025年CCFI指数均值同比下跌约22.76%，尽管公司通过运量增长对冲了部分影响，但若全球经济衰退或贸易摩擦加剧，运价下行将直接冲击公司利润。公司营收高度依赖运价与运量，缺乏定价权，利润弹性向下同样显著。

**资本开支与资产扩张带来的财务压力不容忽视。** 公司报告期内投资活动现金净流出高达14.86亿元，主要用于新船建造。大规模资本开支将推高折旧与财务费用，若新船投产后市场运价不及预期，将导致资产回报率下降，并可能侵蚀现金流。同时，公司短期借款同比大增79.19%，需关注债务结构变化带来的流动性风险。

**公司简介（F10 原文）**

> 宁波远洋运输股份有限公司(股票简称:宁波远洋,股票代码:601022)成立于1992年,是宁波舟山港股份有限公司控股子公司。公司于2008年12月成为宁波舟山港股份有限公司全资子公司,2020年12月正式启动分拆上市计划,2021年3月完成股份制改革,顺利于2022年12月8日成功登陆沪市主板,成为国内港航企业首家“A拆A”上市公司。1.完善的航线体系优势宁波远洋成立近三十年,目前共经营集装箱班轮航线33条,周均航班132班,已建成连接南北沿海、长江沿线39个港口的内支内贸网络和遍及日本、韩国、台湾地区、东南亚地区的航线网络,以宁波地区港口为核心,打造了辐射近洋、沿海及内陆的航线体系。2.优越的区位优势宁波远洋位处宁波,所处核心港口宁波舟山港连续十二年吞吐量位于全球第一位。宁波舟山港是我国大陆重要的集装箱远洋干线港,国内重要的铁矿石中转基地和原油转运基地,是国家的主枢纽港之一,也是新时期国家“丝绸之路经济带”和“21世纪海上丝绸之路”的交汇点,“长江经济带”的重要组成部分。港口汇聚了全球一线船公司,有效保障了庞大的货源。3.与航线运力匹配的船队规模优势宁波远洋为浙江省内最大的集装箱班轮企业,截止2023年底,在中国内地集装箱班轮公司运力排名中居第5位,位列世界集装箱班轮公司百强榜前30。宁波远洋目前共经营船舶88艘,总运力136万载重吨/7.2万TEU载箱量,其中自有船舶44艘,89.4万载重吨/4.3万TEU载箱量,形成一支由3000吨至59000吨集装箱船舶梯度互补并保有一定数量(10艘)散货船舶的综合性船队。船队规模适中,与航线运力需求及发展保持高度匹配,保证了航班运营班期的稳定性。4.良好的品牌形象宁波远洋经过在行业内近三十年的精耕细作,已经在客户中积累了广泛的认知度和良好的品牌形象,并形成了一套标准完整的服务流程体系。经过近三十年的发展,与国内外知名企业建立了良好的合作伙伴关系,为客户提供全方位的服务,得到客户的认可。
