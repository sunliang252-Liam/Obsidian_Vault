# 600026.SH 深度透视

## 因果逻辑链
- **[全球油运市场景气度提升]** -> [外贸原油运输收入增长16.8%]: OPEC+增产、制裁收紧、长航线需求增长推动VLCC运价飙升，公司作为全球最大油轮船东直接受益。
- **[LNG运输船队规模扩张]** -> [LNG板块净利润增长10.4%]: 2025年接入13艘新船，63艘运营船舶均锁定长期租约，贡献稳定收益，成为业绩“安全垫”。
- **[内贸油运需求疲软]** -> [内贸油品收入下降7.3%]: 国内成品油消费下行及炼厂布局调整，导致内贸运输需求下滑，但COA覆盖90%基础货源，缓冲了冲击。
- **[美元兑人民币汇率下行]** -> [财务费用同比增加15.4%]: 汇率走势反转导致汇兑收益同比减少，侵蚀了部分利润，是利润增速低于收入增速的主因。
- **[80亿元A股定增完成]** -> [资本结构优化，净资产增长27.5%]: 引入长期投资者，降低资产负债率至46.1%，为后续船队扩张和绿色转型提供资金保障。
- **[出售5艘老旧船舶]** -> [资产处置收益6.66亿元]: 主动优化船队结构，处置非核心资产，贡献了非经常性损益，但扣非净利润同比下降16%。
- **[7艘油轮计提减值]** -> [资产减值损失4.56亿元]: 部分油轮存在减值迹象，反映了老旧船舶在环保新规下的价值压力，是扣非净利润下滑的主因之一。

## 风险警告
**核心风险在于油运市场的高度周期性与地缘政治脆弱性。** 公司利润高度依赖外贸油运，2025年VLCC运价飙升是利润核心驱动，但2026年若OPEC+增产不及预期、全球经济衰退导致需求下滑，或地缘冲突缓和导致贸易流回归，运价可能剧烈回调。公司2026年营收计划（231.7亿元）低于2025年实际值，已隐含对市场降温的预期。

**第二大风险是成本端压力与资产减值风险。** 燃油价格波动、新船交付带来的折旧增加（2025年折旧费同比增8%）、以及为应对环保新规（CII）可能产生的额外运营成本，将持续挤压利润空间。同时，全球20年以上VLCC占比近20%，公司自身船队平均船龄13.7年，未来可能面临更多老旧船舶的减值或处置压力，影响资产质量。
