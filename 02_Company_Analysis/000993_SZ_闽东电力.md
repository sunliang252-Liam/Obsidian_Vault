# 000993.SZ 深度透视

## 因果逻辑链
- **[降雨量减少]** -> [水电发电量下降5.3%]: 2025年降雨量同比减少，导致公司核心水电业务发电量和售电量下滑，直接拖累整体营收。
- **[风电风速增加及风机消缺]** -> [风电发电量增长6.6%]: 闾峡风电场三期风机性能提升及风速同比增加，推动风电板块成为业绩主要支撑。
- **[光伏装机容量扩张]** -> [光伏发电量激增121.6%]: 新增6个屋顶分布式光伏项目（9.22兆瓦），光伏业务高速增长，但体量尚小。
- **[非经常性损益大幅减少]** -> [归母净利润暴跌65.23%]: 2024年确认高额金融资产公允价值变动收益（5,022万元），2025年该收益锐减至12万元，导致利润基数骤降。
- **[计提大额资产减值]** -> [侵蚀营业利润]: 2025年计提固定资产减值及地产存货跌价准备5,840万元，同比暴增1788%，是利润下滑的核心因素之一。
- **[水资源费改税]** -> [税金及附加增加54.76%]: 自2024年12月起水资源费改为水资源税并计入税金及附加，直接推高营业成本。
- **[经营现金流稳健]** -> [支撑资本开支与分红]: 经营活动现金流净额2.43亿元，同比增长9.66%，为光伏项目投资和每股0.18元分红提供坚实基础。

## 风险警告
**核心风险在于业绩对自然气候的高度依赖与资产减值压力。** 公司水电、风电业务受降雨量、风速等不可控因素影响极大，2025年归母净利润暴跌65%已充分暴露其盈利的脆弱性。同时，公司连续两年计提大额资产减值（2025年5,840万元），尤其是对老旧风电资产和地产存货的减值，表明部分资产质量堪忧，未来仍有减值风险。

**战略转型面临不确定性。** 公司正从传统水电向“水风光”多能互补及综合能源服务转型，但区域内水电资源已近枯竭，海上风电开发权获取困难，分布式光伏竞争激烈。新业务如虚拟电厂、绿电交易尚处探索初期，短期内难以贡献实质性利润。此外，控股股东关于剥离房地产业务及注入电力资产的承诺已延期至2028/2030年，执行进度存在不确定性。
