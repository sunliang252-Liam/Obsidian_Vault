# 000049.SZ 深度透视

## 因果逻辑链
- **行业锂电池总出货量高增长** -> 公司营收增长7.38%: 行业高速增长带动公司整体营收提升，但增幅远低于行业增速，表明公司市场份额或增长动力有限。
- **储能电池出货量激增76.2%** -> 公司储能业务收入增长49.89%: 行业高速增长带动公司储能业务收入大幅增长，但增幅低于行业增速，且该业务毛利率为负，表明仍处于亏损扩张阶段。
- **智能手机类产品收入下降4.79%** -> 公司整体营收增速放缓且毛利率下降: 传统优势业务下滑拖累整体营收增速，智能手机类毛利率下降2.1个百分点，对利润贡献减少。
- **智能穿戴类产品收入增长30.81%** -> 毛利率提升5.87个百分点: 高增长产品规模效应和成本控制提升盈利水平。
- **储能业务毛利率为负且亏损** -> 归母净利润下降29.23%: 储能业务虽增长迅速但亏损严重，拖累整体利润。储能电芯子公司湖南电池净利润-2.93亿元，是利润下滑主因。
- **研发投入增长14.63%** -> 新兴业务拓展（储能、SIP）: 研发投入增加支撑储能电芯、SIP等新业务技术突破和产品开发。
- **海外制造基地投产（越南）** -> 境外收入增长9.13%，占比提升: 越南制造基地量产和产能扩张支持海外销售增长。
- **存货跌价准备2.16亿元** -> 资产减值损失占利润总额-136.49%: 存货减值主要来自储能等业务库存，反映产品价格下降或市场需求波动风险。
- **客户集中度高（前五名客户占56.47%）** -> 经营风险增加: 依赖大客户，若核心客户需求下降或减少采购，将直接冲击营收和利润。
- **财务费用增长75.86%（汇兑损失）** -> 净利润下降: 人民币汇率波动导致汇兑收益减少，增加财务费用，侵蚀利润。

## 风险警告
公司面临多重风险：1）传统消费电子业务增长乏力甚至下滑，智能手机类收入下降4.79%；2）储能业务虽高速增长但严重亏损，毛利率为负，且存货减值压力大；3）客户高度集中，对第一大客户依赖超40%；4）海外业务占比高（68.35%），汇率波动风险显著；5）行业竞争加剧，毛利率整体下降1.36个百分点。
