# 603018.SH 深度透视

## 因果逻辑链
- **[传统基建投资放缓]** -> [基础设施业务营收下降14%]: 地方财政压力与基建投资增速放缓，直接导致公司核心勘察设计业务订单减少与收入下滑。
- **[新兴业务高速增长]** -> [第二增长曲线营收占比提升至37%]: 数智及智库、低碳环保、城市更新等新兴业务营收同比增长9.3%、6.3%、6.3%，部分对冲了传统业务下滑。
- **[低空经济全产业链布局]** -> [低空经济新签订单破亿]: 通过成立华设低空科技集团、并购锐天科技，公司快速切入低空装备、适航检测等环节，形成“建-管-运”全覆盖能力。
- **[AI大模型部署与数字化管理]** -> [运营费用同比下降14%]: 本地化部署DeepSeek等大模型，推出数字员工，推动业财一体融合，实现降本增效。
- **[应收账款与合同资产高企]** -> [信用及资产减值损失合计超3亿元]: 客户主要为地方政府及平台公司，回款周期延长，导致公司计提大额坏账准备，直接侵蚀净利润。
- **[股权结构分散]** -> [无实际控制人风险]: 公司无控股股东，存在控制权变更风险，可能影响经营稳定性与长期战略执行。
- **[国际化战略推进]** -> [海外业务覆盖10余国家]: 成功中标香港、菲律宾等项目，引进国际团队，跟踪订单约10亿元，但海外经营风险与地缘政治不确定性并存。

## 风险警告
**核心风险在于传统主业失速与坏账侵蚀利润的双重挤压。** 公司基础设施业务营收同比下滑14%，而应收账款与合同资产合计超100亿元，坏账准备高达25亿元，信用及资产减值损失合计超3亿元，是净利润同比下滑28%的直接原因。地方政府财政压力短期内难以缓解，回款风险将持续压制公司盈利能力和现金流质量。

**转型阵痛与竞争加剧并存。** 公司虽在低空经济、数字化等新兴领域布局积极，但新兴业务毛利率普遍低于传统业务（数智及智库毛利率下降10.96个百分点），且面临来自央企、科技巨头及同行的激烈竞争。若新业务无法快速形成规模效应与盈利闭环，公司可能陷入“传统业务失血、新业务输血不足”的困境。此外，无实际控制人的股权结构增加了战略执行的不确定性。
