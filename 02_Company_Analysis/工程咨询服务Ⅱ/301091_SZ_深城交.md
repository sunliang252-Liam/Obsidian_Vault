# 301091.SZ 深度透视

## 因果逻辑链
- **[战略转型聚焦高毛利产品]** -> [毛利率提升8个百分点]: 公司主动收缩低毛利项目，转向自研软件平台与AI产品，营业成本同比下降19.4%，带动整体毛利率从32.5%提升至40.6%。
- **[信用减值损失激增]** -> [归母净利润下滑42%]: 基于财务稳健原则，公司对长账龄应收账款计提1.44亿元信用及资产减值损失，直接侵蚀利润，导致归母净利润仅0.61亿元。
- **[新签合同结构优化]** -> [未来收入质量提升]: 全年新签合同17.76亿元，其中大数据软件与智慧交通占比达68%，高毛利业务订单占比提升，为后续盈利改善奠定基础。
- **[省外及海外业务高速增长]** -> [市场区域多元化]: 广东省外营收同比增长34%，国际业务实现从0到1的突破（营收0.55亿元），降低了对单一深圳市场的依赖（深圳营收占比降至70%）。
- **[研发投入持续高企]** -> [技术壁垒与产品突破]: 研发投入占营收12.37%，推动TransPaaS 4.0平台迭代及具身智能装备（低空塔台、自驾小巴）从0到1研发，巩固了行业技术领先地位。
- **[投资运营业务模式成型]** -> [创造稳定现金流]: “投建运”一体化模式落地，全年完成约2.5亿元优质资产投资，运营运维类销售合同额达2.14亿元，同比增长19%，为公司贡献了可持续的运营收入。

## 风险警告
**核心风险在于盈利质量与现金流的背离。** 尽管公司战略转型初见成效，毛利率显著提升，但净利润同比暴跌42%，主因是高达1.44亿元的信用及资产减值损失。这直接反映了公司主要客户（政府及国企）付款周期延长、地方财政压力传导至回款端的严峻现实。经营活动现金流净额由正转负，流出1.26亿元，进一步印证了“增收不增现”的困境，若回款环境持续恶化，将严重侵蚀公司现金流安全垫。

**第二重风险来自战略转型的执行不确定性。** 公司正从传统项目型向产品科技型、平台运营型深度转型，并大举押注低空经济、自动驾驶等前沿赛道。这些新业务（如具身智能装备、自驾套件）尚处于研发验证或小批量试点阶段，商业化路径和规模化盈利时间表均不明确。持续的研发高投入（1.49亿元）与新产品市场推广，在主营业务利润承压的背景下，可能进一步加剧公司的财务压力，转型成效能否如期兑现存在较大变数。
