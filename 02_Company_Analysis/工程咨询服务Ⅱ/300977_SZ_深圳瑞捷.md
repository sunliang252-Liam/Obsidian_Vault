# 300977.SZ 深度透视

## 因果逻辑链
- **[客户结构优化]** -> [净利润扭亏为盈]: 传统地产客户营收占比降至38%，产业与保险新客户占比升至62%，对冲地产下行周期，收入结构韧性增强。
- **[长账龄账款回收]** -> [信用减值损失转回]: 通过法律诉讼、仲裁等多元化清收手段，冲回前期计提的信用减值损失，直接增厚当期净利润。
- **[新业务收入增长]** -> [收入结构改善]: 新保险业务（安责险增长近5倍）及产业类业务（同比增长39.6%）成为增长引擎，弥补了传统评估业务的下滑。
- **[AI与数字化产品落地]** -> [人机协同效率提升]: 科技实测业务营收突破1000万元，无人机外墙检测累计超1000栋，推动服务从“人力密集型”向“技术驱动型”转型。
- **[应收账款高企]** -> [经营性现金流承压]: 尽管净利润改善，但应收账款账面价值仍达2.24亿元，导致经营活动现金流净额同比下滑39.69%，盈利质量待提升。
- **[非经常性损益贡献]** -> [扣非净利润仍薄弱]: 归母净利润2961万元中，非经常性损益（理财收益、减值转回）贡献2427万元，扣非净利润仅555万元，主业盈利能力依然脆弱。
- **[海外业务拓展]** -> [第二增长曲线初现]: 海外项目从3个增至8个，覆盖8个国家，营收同比增长56.65%，国际化战略开始贡献增量。

## 风险警告
**核心风险在于应收账款回收与主业盈利能力的双重压力。** 公司账面应收账款高达2.24亿元，占总资产14.46%，且坏账准备计提比例高达45%。尽管2025年通过强力清收实现减值转回，但地产客户信用风险并未出清，若宏观经济或房地产政策不及预期，坏账风险可能再次爆发，侵蚀利润。

**扣非净利润仅555万元，显示公司核心业务（第三方评估与项目管理）的盈利能力依然薄弱。** 营收与上年基本持平，但毛利率下滑，且研发、销售费用持续增长。公司转型依赖“保险+产业”新业务，但新业务毛利率波动较大（如产业不动产毛利率仅27%），且尚处于投入期，能否持续放量并实现盈利，是未来业绩反转的关键。
