# 300668.SZ 深度透视

## 因果逻辑链
- **[战略性剥离亏损设计业务]** -> [净利润扭亏为盈]: 2025年出售持续亏损的室内设计业务及资产，消除亏损源，使归母净利润从-1199.55万元大幅回升至1486.34万元。
- **[聚焦大健康主业]** -> [收入结构根本性转变]: 市场商务及服务支持业务收入占比从62.44%提升至67.55%，成为公司唯一核心主业，公司从“设计+疫苗推广”双主业彻底转型为纯疫苗推广服务商。
- **[疫苗行业结构性承压]** -> [核心业务收入增长乏力]: 儿童出生率下降、成人疫苗市场培育缓慢、产品同质化竞争加剧，导致公司核心的疫苗推广服务收入仅微增1.73%，整体营收下滑5.97%。
- **[应收账款高企与坏账计提]** -> [侵蚀当期利润]: 应收账款占总资产比例高达41.68%，公司计提大额信用减值损失，虽优化了长期资产质量，但短期对利润造成显著拖累。
- **[控股股东业绩承诺补偿]** -> [非经常性收益增厚利润]: 原控股股东姜峰因设计业务未达业绩承诺，支付3448.77万元现金补偿款，直接计入当期损益，是净利润大幅增长的关键非经常性因素。
- **[实施股权激励]** -> [绑定核心人才与业绩]: 2025年授予500万股限制性股票，覆盖21名中层及骨干，解锁条件与净利润挂钩，旨在稳定团队并驱动未来业绩增长。
- **[研发投入骤减84%]** -> [战略收缩信号]: 伴随设计业务剥离，研发费用从2122万元大幅降至337万元，研发人员减少72%，公司彻底放弃设计领域的技术投入，全面转向轻资产的疫苗推广服务模式。

## 风险警告
**核心风险在于单一业务依赖与行业增长瓶颈。** 公司已完全剥离设计业务，100%依赖非免疫规划疫苗推广。然而，该行业正面临儿童疫苗市场因出生率下降而萎缩、成人疫苗市场因公众认知不足和支付体系不完善而增长缓慢的双重困境。公司核心收入增长乏力（仅1.73%），表明其已触及现有业务模式的天花板，未来增长高度依赖能否成功开拓成人疫苗蓝海或引入重磅新品，不确定性极大。

**财务健康度风险不容忽视。** 应收账款高达5.02亿元，占总资产41.68%，且回款周期有延长趋势。尽管公司已成立专项催收团队，但若下游客户（疾控中心、接种点）资金紧张，坏账风险将持续高企，对现金流和利润构成长期威胁。此外，公司连续两年不派发现金红利，也反映出其内部资金压力与对未来的谨慎预期。
