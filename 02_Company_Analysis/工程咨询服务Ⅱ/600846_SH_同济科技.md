# 600846.SH 深度透视

## 因果逻辑链
- **[房地产业务集中交付]** -> **营收增长但利润下滑**: 2025年房地产项目集中交付，带动营收增长6.44%，但上年同期非同一控制下企业合并产生高额营业外收入，导致归母净利润同比大降32.91%。
- **[主业工程咨询萎缩]** -> **收入结构失衡**: 核心主业“工程建设及咨询服务”收入同比下滑14.64%，而房地产业务收入暴增843.12%，公司正从“工程服务商”向“地产开发商”倾斜。
- **[房产项目资金回笼]** -> **经营现金流大幅改善**: 经营活动现金流净额同比大增80.94%至9.48亿元，主要系房产项目销售回款增加，缓解了此前现金流紧张的局面。
- **[收购补链强链]** -> **资质扩张与区域拓展**: 通过收购天津建联（天佑工程勘测）和设立大湾区办事处，公司快速补齐检测、测绘等资质，并切入京津冀、大湾区市场。
- **[区校合作平台]** -> **孵化“第二增长曲线”**: 依托同济大学和杨浦区资源，通过同杨基金投资数字化、绿色低碳企业，并启动“同济科技未来中心”项目，布局新兴赛道。
- **[行业减量提质]** -> **传统业务承压**: 全国建筑业总产值同比降低5.43%，公司工程建设及咨询服务业务收入与成本双降，面临市场萎缩与竞争加剧的双重压力。
- **[治理层动荡]** -> **战略执行不确定性**: 报告期内董事长、副总经理变更，且董事会对人事任命存在公开异议，反映出股东间博弈激烈，可能影响公司战略的连续性与执行效率。

## 风险警告
**核心风险在于主业衰退与治理层动荡的叠加。** 公司传统工程咨询业务收入萎缩14.64%，而支撑利润的房地产业务具有强周期性，2025年高增长难以持续。更关键的是，董事会内部对董事长选举、副总经理任命等重大事项存在公开分歧，股东间（杨浦国资 vs 量鼎资本）博弈白热化，这直接威胁公司战略的稳定执行和长期价值创造。

**财务风险不容忽视。** 尽管经营现金流改善，但公司资产负债率已升至66.70%，且存货高达45.38亿元（占总资产34.66%），主要沉淀于房地产开发项目。在房地产市场持续调整的背景下，存货减值风险是审计报告明确指出的关键审计事项。此外，公司有息负债余额增至27.34亿元，利息支出大幅增加，财务费用由负转正，侵蚀利润。
