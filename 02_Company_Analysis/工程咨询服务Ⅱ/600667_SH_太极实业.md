# 600667.SH 深度透视

## 因果逻辑链
- **[工程总包业务回款放缓]** -> [经营活动现金流暴跌79.87%]: 工程业务回款同比大幅减少，导致经营性现金流从21.75亿骤降至4.38亿，现金流质量显著恶化。
- **[十一科技所得税税率调整及补税]** -> [归母净利润同比下滑31.84%]: 子公司十一科技企业所得税税率调整，部分业务不满足税收优惠条件需补缴，导致所得税费用增加，侵蚀利润。
- **[海太半导体与SK海力士签署四期合同]** -> [半导体业务收入利润双增]: 海太半导体以“全部成本+约定收益”模式续约至2030年，封装测试产量同比增长超20%，带动半导体板块收入增长7.73%。
- **[十一科技新签合同额301亿元]** -> [工程总包收入占比76.47%]: 十一科技在电子高科技、光伏等领域EPC总包订单充足，但毛利率仅1.96%，收入规模大但盈利能力极薄。
- **[DDR5先进制程产品占比87.1%]** -> [海太半导体技术壁垒与规模效应]: 海太半导体紧跟SK海力士技术迭代，先进制程产品占比高，形成稳定现金流和差异化竞争优势。
- **[光伏电站电价全面市场化改革]** -> [光伏发电业务毛利率下降8.17个百分点]: 2025年6月起新能源上网电量全部进入电力市场交易，补贴退坡，存量电站收益承压。
- **[盛虹动能项目停工]** -> [工程总包项目减值风险暴露]: 储能电池项目停工，表明十一科技在部分非核心领域的EPC项目存在履约和回款风险。

## 风险警告
**最大风险：对单一客户SK海力士的深度依赖。** 海太半导体几乎100%收入来自SK海力士，虽已续约至2030年，但盈利模式为“成本加成”，利润空间受限于约定收益率（总投资额的10%）。一旦SK海力士技术路线变更、订单转移或地缘政治导致合作中断，公司半导体业务将遭受毁灭性打击。太极半导体虽在拓展第三方客户，但体量尚小且仍处亏损状态。

**第二大风险：工程总包业务“增收不增利”与现金流恶化。** 十一科技贡献超76%营收，但工程总包毛利率仅1.96%，且经营活动现金流净额同比暴跌79.87%，显示回款能力严重不足。在固定资产投资放缓、行业竞争加剧的背景下，大量垫资施工的EPC项目可能形成坏账，且盛虹动能项目停工已敲响警钟。公司资产负债率较高，现金流吃紧将限制其抗风险能力。

**公司简介（F10 原文）**

> 无锡市太极实业股份有限公司坐落于美丽的太湖之滨,是无锡产业发展集团有限公司下属的国有控股上市公司。公司成立于1966年,前身系无锡市合成纤维厂,1987年与无锡市第二合成纤维厂合并组建无锡市合成纤维总厂,1993年更名为无锡市太极实业股份有限公司并在上海证券交易所成功上市,成为江苏省首家上市公司(股票简称“太极实业”,股票代码600667)。经过50多年的创业发展和转型升级,太极实业已成为国内领先的半导体(集成电路)制造与服务厂商。公司下属全资子公司太极半导体(苏州)有限公司、太极微电子(苏州)有限公司、信息产业电子第十一设计研究院科技工程股份有限公司、无锡太极国际贸易有限公司,控股海太半导体(无锡)有限公司。  公司目前主营业务包括半导体业务、工程技术服务业务和光伏电站投资运营业务。半导体业务主要涉及IC芯片封装、封装测试、模组装配及测试等;工程技术业务主要服务于电子高科技与高端制造,生物医药与保健,市政与路桥,物流与民用建筑,电力,综合业务等6大业务领域;光伏电站投资运营业务已形成一定规模。  展望未来,太极实业将以打造优秀上市公司为目标,通过不断优化升级,回报股东,回报客户,回报员工,努力把公司建设成为产业高端化、经营国际化、管理现代化的世界一流企业。
