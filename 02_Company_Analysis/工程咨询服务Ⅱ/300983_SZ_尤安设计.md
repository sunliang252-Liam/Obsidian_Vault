# 300983.SZ 深度透视

## 因果逻辑链
- **[下游房地产行业深度调整]** -> [业务规模萎缩]: 房地产开发投资持续下降，导致公司建筑设计业务需求减少，2025年营收同比下降20.70%。
- **[客户回款能力恶化]** -> [信用减值损失激增]: 下游客户流动性危机导致应收账款账龄拉长，公司计提信用减值损失6,768万元，成为亏损主因。
- **[以房抵债的债务重组]** -> [资产减值损失]: 抵入的投资性房地产及购置的固定资产因房价下行出现减值迹象，计提资产减值准备2,705万元。
- **[成本控制措施见效]** -> [毛利率提升]: 公司严格成本控制，建筑设计主营业务毛利率同比上升8.94个百分点至38.53%。
- **[增值税留抵退税及成本压缩]** -> [经营现金流大幅改善]: 经营活动现金流净额同比上升124.32%至9,893万元，与净利润亏损形成背离。
- **[核心建筑师负责制与全过程咨询]** -> [差异化竞争壁垒]: 德邻公寓成为上海首个建筑师负责制下的优秀历史建筑改造项目，提升品牌价值与项目附加值。
- **[聚焦七大政策红利赛道]** -> [结构化增长新引擎]: 公司战略转向城市更新、TOD、保障性租赁住房等非地产领域，对冲传统住宅设计业务下滑风险。

## 风险警告
**核心风险在于应收账款回收的极度不确定性。** 公司应收账款余额占营收比例高达386.63%，其中账龄两年以上的占比84.77%，且高度集中于绿地控股（占应收账款余额38.34%）。尽管公司通过以房抵债等方式化解风险，但抵入房产的交付、网签备案及后续变现均存在重大不确定性，部分抵债协议因开发商资金困境无法推进，坏账风险并未根本消除。

**资产减值风险持续暴露。** 公司因债务重组持有大量投资性房地产，且已购置的固定资产（如德邻公寓）也面临减值压力。在房地产市场持续低迷的背景下，这些资产的公允价值存在进一步下跌的可能，将持续侵蚀公司利润。此外，公司研发投入同比大幅下降61.14%，研发人员减少近半，长期技术竞争力可能受损。
