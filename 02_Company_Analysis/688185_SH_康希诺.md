# 688185.SH 深度透视

## 因果逻辑链
- **[核心产品曼海欣®持续放量]** -> [营收增长26.18%]: 作为中国首款MCV4疫苗，凭借先发优势和扩龄至6岁，销售收入同比增长21.91%，成为业绩核心引擎。
- **[降本增效与资源聚焦]** -> [实现扭亏为盈]: 通过优化资源配置、管控费用，综合毛利率提升至77.51%，研发费用同比下降24.77%，推动归母净利润转正至2787万元。
- **[非经常性收益贡献]** -> [净利润转正的关键]: 报告期内确认政府补助及国际研发资金等非经常性收益约1.22亿元，是公司实现盈利的重要支撑。
- **[PCV13i优佩欣®获批上市]** -> [丰富商业化产品组合]: 2025年6月获批，与曼海欣®目标人群重合，有望形成协同效应，提升营销效率并贡献新增长点。
- **[研发管线聚焦与资本化控制]** -> [研发投入占比下降]: 研发总投入同比下降27.33%，资本化研发投入下降38.57%，显示公司更注重研发效率与现金流管理。
- **[主动缩减债务规模]** -> [财务结构优化]: 经营活动现金流转正，公司主动归还银行借款，短期借款和一年内到期非流动负债大幅下降，降低了财务风险。
- **[海外市场初步布局]** -> [国际化战略起步]: MCV4在印尼获批并实现首批发运，PCV13i和MCV4生产基地通过马来西亚PIC/S GMP检查，为未来海外收入奠定基础。

## 风险警告
**核心风险在于扣非净利润仍为负值，盈利质量存疑。** 公司2025年归母净利润转正，但扣非净利润仍亏损9413万元，盈利主要依赖政府补助、理财收益等非经常性损益。若未来核心产品曼海欣®增长放缓、竞争加剧，或政府补助政策变化，公司可能重回亏损状态。当前盈利的可持续性尚未得到主营业务内生增长的充分验证。

**另一重大风险是税收政策变化带来的成本冲击。** 根据2026年1月生效的新规，部分生物制品不再享受简易征收优惠，这将直接提升公司的税负成本。同时，公司海外业务尚处投入期，技术转移和中间品销售业务毛利率为负，且面临汇率波动风险。在研发管线仍需持续投入的背景下，这些因素将对公司未来的盈利能力构成持续压力。
