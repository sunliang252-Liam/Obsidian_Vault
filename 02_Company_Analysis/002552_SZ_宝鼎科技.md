# 002552.SZ 深度透视

## 因果逻辑链
- **[金价持续上涨]** -> [成品金业务营收与利润暴增]: 2025年国际金价全年涨幅64.56%，公司成品金营收同比增长54.74%，毛利率高达66.34%，成为利润核心支柱。
- **[电子铜箔及覆铜板业务亏损]** -> [整体净利润大幅下滑49.83%]: 覆铜板毛利率下降2.04%，铜箔毛利率下降3.01%，叠加运营成本上升，该业务归母净利润亏损3144万元，同比暴跌219.16%。
- **[上年高额非经常性损益消失]** -> [扣非净利润大增但归母净利润下滑]: 2024年收到业绩补偿款2.70亿元，2025年无此项收入，导致归母净利润从2.48亿降至1.24亿；但扣非净利润从-2528万扭转为1.25亿，主业盈利能力实际改善。
- **[金宝电子财务费用激增]** -> [侵蚀电子材料业务利润]: 财务费用同比增长34.97%，主要系金宝电子借款增加所致，直接加重了已处于亏损边缘的电子铜箔及覆铜板业务的负担。
- **[应收账款大幅增长28.76%]** -> [现金流压力与坏账风险并存]: 应收账款增至9.31亿元，占总资产19.01%，虽经营活动现金流净额转正至1.82亿，但回款压力显著增大。
- **[单一矿山经营与资源储量有限]** -> [黄金业务长期增长天花板]: 河西金矿保有金金属量仅4260kg，按当前年产540kg计算，可采年限不足8年，资源枯竭风险迫在眉睫。
- **[同业竞争承诺进入关键期]** -> [资产注入预期与不确定性并存]: 控股股东承诺5年内解决与中矿集团、新东庄金矿的同业竞争，2025年10月股权划转后承诺继续有效，但具体方案与时间表仍不明确。

## 风险警告
**核心风险在于电子材料主业的持续恶化与黄金业务的不可持续性。** 铜箔和覆铜板业务已陷入亏损，毛利率持续下滑，且面临上游铜价波动、下游需求疲软及行业产能过剩的多重挤压。金宝电子作为营收占比超80%的核心子公司，其盈利能力恶化直接拖累公司整体表现。同时，河西金矿作为利润支柱，其资源储量仅能支撑不到8年的开采，黄金采选业务的长期增长逻辑存在根本性缺陷。

**治理与财务风险不容忽视。** 公司应收账款高企且增速远超营收增速，回款压力巨大，可能引发坏账风险。此外，公司曾因一季度报告披露不准确被监管警示，暴露出内部控制和信息披露的薄弱环节。参股的小贷公司持续亏损且资产质量恶化，虽已尝试处置但未成功，构成潜在的资产减值风险。
