# 603053.SH 深度透视

## 因果逻辑链
- **[销气量下降5.67%]** -> [营收微增1.46%]: 非居民用气顺价政策落地，4月调价至4.23元/m³，部分对冲了销气量下滑对收入的负面影响。
- **[燃气接驳收入暴增53.70%]** -> [营收增长主要驱动力]: 受益于老旧小区改造及新建楼盘配套，接驳业务收入从2.96亿增至4.56亿，是营收增长的核心来源。
- **[上游气源成本下降]** -> [燃气销售毛利率微增0.58个百分点]: 尽管销气量下降，但采购成本降幅（-3.64%）大于收入降幅（-2.99%），毛差有所修复。
- **[绕城高压输储气管道投运]** -> [供气能力与调峰能力跃升]: 项目投运增加日调峰能力259万立方米，从根本上缓解了成都市的供气矛盾，为未来销气量增长奠定基础。
- **[综合能源业务增长15.04%]** -> [新业务贡献增量]: 充电网络、分布式能源等业务收入达0.94亿元，成为公司转型的重要增长点，弥补了部分传统业务下滑。
- **[研发费用骤降50.59%]** -> [短期利润平滑]: 研发投入从1813万降至896万，是净利润降幅（-1.54%）小于销气量降幅的原因之一，但可能影响长期技术竞争力。
- **[财务费用为负且减少]** -> [增厚利润]: 公司持有大量货币资金（30.1亿），利息收入（8029万）远超利息支出（8.5万），持续贡献非经营性利润。

## 风险警告
**核心风险在于“增量不增收”的困境与主业天花板。** 公司销气量同比下降5.67%，尽管通过顺价和接驳业务增长勉强维持了营收微增，但净利润已连续两年下滑。成都中心城区城市化进入存量阶段，新建住宅增速放缓，接驳业务的爆发式增长（+53.7%）难以持续，未来增长高度依赖外围区域市场拓展和存量用户挖潜，但竞争激烈且不确定性高。

**另一重大风险是气源高度依赖单一供应商与政策监管的双重挤压。** 公司61.97%的天然气采购来自中石油，议价能力极弱。虽然顺价政策在推进，但居民气价格仍受政府严格监管，购销毛差的修复空间有限且存在政策反复风险。同时，新能源替代（CNG萎缩、光伏/储能竞争）和燃气安全监管趋严带来的成本增加，将持续压制公司的盈利能力和成长空间。
