# 603311.SH 深度透视

## 因果逻辑链
- **[原材料成本下降]** -> [利润增厚]: 2025年国际油价下行，PP粒子等核心原料价格单边下跌，叠加2-3个月传导滞后期，显著释放了此前被高成本挤压的利润空间。
- **[资产处置收益]** -> [净利润虚增]: 出售诸暨及泰国闲置土地、厂房等资产，贡献非经常性损益约2575万元，是归母净利润同比增长20.69%的主要推手，掩盖了扣非净利润下滑8.80%的事实。
- **[海外订单增长]** -> [营收扩张]: 受益于东南亚、欧洲等海外空调市场需求强劲，公司国外营收同比增长11%，拉动总营收增长8.49%。
- **[收付款信用期管理优化]** -> [现金流改善]: 经营活动现金流净额同比大增68.18%，远超营收增速，表明公司加强了应收账款回收和应付账款管理，运营效率提升。
- **[研发投入阶段性调整]** -> [费用短期下降]: 研发费用同比下降10.65%，系研发方向探索调整，调研阶段项目增多、开发阶段项目减少所致，但长期可能影响技术迭代速度。
- **[募投项目变更]** -> [战略重心转移]: 将原计划在诸暨的产能项目变更为泰国项目，旨在完善全球化布局、规避贸易风险，但项目延期至2028年，短期无法贡献业绩。
- **[大飞机业务突破]** -> [打开高端市场]: 通过AS9100D认证并与商飞合作开发C909/C919空气过滤系统，成功切入航空高端供应链，但当前体量极小，尚处培育期。

## 风险警告
**核心风险在于利润质量与增长可持续性。** 2025年归母净利润看似增长20.69%，但扣非净利润实则下滑8.80%，两者严重背离。利润增长主要依赖一次性资产处置收益（约2575万元）和原材料成本下降的周期性红利，而非主营业务的量价齐升。一旦资产处置完毕或原材料价格反弹，盈利将面临显著压力。同时，公司核心客户高度集中（前五名客户销售额占比近60%），且多为格力、大金等家电巨头，议价能力受限，毛利率已连续两年微降。

**战略转型存在较大不确定性。** 公司虽在新能源汽车和大飞机领域取得突破，但当前体量极小，对业绩贡献微乎其微。原定于2025年达产的新能源汽车空气过滤器募投项目已延期并变更至泰国，新项目预计2028年才投产，期间存在海外建厂、地缘政治及客户拓展不及预期的风险。此外，研发费用在关键转型期出现下降，可能削弱长期技术竞争力。公司当前估值更多反映的是转型预期，而非现有业务的真实盈利能力。
