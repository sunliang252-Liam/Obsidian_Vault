# 002436.SZ 深度透视

## 因果逻辑链
- **[AI基础设施建设驱动PCB行业强势反弹]** -> [公司营收增长23.68%]: 全球PCB行业产值同比增长15.8%，公司受益于AI、高速网络等需求，营收创历史新高。
- **[CSP封装基板业务受益存储芯片复苏]** -> [半导体业务收入增长48.62%]: 存储芯片行业复苏及主要客户份额提升，CSP封装基板订单饱满、产能利用率逐季提升，成为半导体业务核心增长引擎。
- **[FCBGA封装基板项目拖累利润]** -> [半导体业务毛利率仍为-16.06%]: FCBGA项目尚未实现大批量生产，人工、折旧等费用投入6.62亿元，导致半导体业务整体亏损，是公司净利润绝对值偏低的主因。
- **[数字化转型提升经营效率]** -> [期间费用率同比下降2.14个百分点]: 数字化工厂建设推动管理、销售、研发费用率全面下降，在营收增长背景下有效控制费用支出。
- **[PCB业务平稳增长但毛利率承压]** -> [PCB业务毛利率下降1.70个百分点]: 传统PCB业务收入增长13.89%，但受原材料价格波动及市场竞争影响，毛利率下滑。
- **[Fineline贸易业务受地缘政治影响]** -> [净利润同比下降1.38%]: 汇兑损失及运输成本增加，导致海外贸易子公司Fineline盈利能力小幅下滑。
- **[经营活动现金流净额为负]** -> [现金流与净利润背离]: 购买商品支付款项增加及税费返还减少，导致经营性现金流净额为-6,274万元，与净利润存在较大差异。

## 风险警告
**FCBGA封装基板项目是公司当前最大的财务拖累和战略赌注。** 该项目已累计投入超28亿元，但客户认证周期长、订单增长缓慢，工厂稼动率低，2025年单项目费用投入6.62亿元，直接导致半导体业务整体亏损。若后续客户导入及量产进度不及预期，将持续侵蚀公司利润，并面临新增产能消化风险。

**公司财务结构趋于激进，债务压力显著上升。** 短期借款同比增加277%，长期借款占总资产比例达24.25%，财务费用同比增长42.25%。同时，经营活动现金流净额由正转负，应收账款和存货规模均大幅增长，占营收比例较高，存在坏账和跌价风险。高杠杆运营下，若行业景气度回落或融资环境收紧，公司将面临流动性压力。
