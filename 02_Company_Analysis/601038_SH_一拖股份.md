# 601038.SH 深度透视

## 因果逻辑链
- **主粮及经济作物价格持续低迷，叠加极端天气频发，导致用户种粮收益下滑；生产资料价格高位波动，进一步挤压利润空间** -> 农户购机需求受到明显抑制，拖拉机行业产量同比下降4.9%: 用户收益下降直接削弱购机能力和意愿，导致行业需求萎缩
- **行业需求疲软，竞争加剧，多数企业陷入低价竞争** -> 公司营业收入同比下降9.09%，营业成本同比下降9.48%: 市场整体下行导致公司销量下滑，收入减少；成本随收入同向下降
- **政策驱动（补贴倾斜高端智能农机）、技术突破（动力换挡、CVT等国产化）、土地流转促进规模化生产** -> 拖拉机行业结构性调整，动力换向智能拖拉机销量逆势增长，大型化、高端化、智能化、绿色化成为趋势: 补贴政策精准引导和技术进步推动产品结构向高端升级
- **公司研发投入持续增加（同比+6.39%），聚焦无级变速、全动力换挡、混动等关键技术** -> 公司推出多款高端智能拖拉机（如动力换向产品全面上市），巩固技术领先优势，提升产品竞争力: 研发投入转化为技术成果和产品创新，增强市场竞争力
- **公司强化全价值链成本管控，降本增效成效显著** -> 装备制造业毛利率同比提升0.37个百分点至15.15%，弥补了促销额度增加的影响: 成本控制有效抵消价格竞争压力，实现毛利率改善
- **公司加快布局海外营销网络与服务网络，推动本土化合作，提升产品适应性** -> 出口拖拉机销量首次突破万台，同比增长41%，海外收入同比增长29.04%: 国际化战略有效拓展海外市场，实现出口高速增长
- **公司实施“战略集采+灵活分采”采购体系，搭建市场价格研判平台，推进设计端降本** -> 采购成本得到有效控制，支撑毛利率提升: 精细化采购管理降低成本，增强盈利能力
- **公司拥有完整的核心零部件自制能力（发动机、车桥、齿轮等），智能制造水平持续提升** -> 产品品质和可靠性提高，形成质量优势，支撑产品竞争力: 核心零部件自制保障产品质量和匹配性，智能制造提升生产效率与一致性
- **当前国内农机市场处于存量更新与结构性增长阶段，传统产品饱和，新兴产品规模有限** -> 行业竞争加剧，跨界企业涌入，企业面临低价竞争困境，利润空间被压缩: 市场饱和导致存量竞争，新兴市场尚未成熟，加剧行业内卷

## 风险警告
公司面临多重风险：1）市场需求持续疲软，主粮价格低迷及极端天气影响用户收益，购机意愿不足，行业下行压力未减；2）竞争加剧，传统企业及跨界新进入者导致价格战，利润空间承压；3）技术升级风险，若研发方向偏差或周期过长，可能错失高端市场机遇；4）国际宏观环境不确定性，地缘政治、贸易保护及汇率波动影响海外业务盈利。毛利率虽短期改善，但长期需关注成本管控可持续性与产品结构升级能否对冲销量下滑。
