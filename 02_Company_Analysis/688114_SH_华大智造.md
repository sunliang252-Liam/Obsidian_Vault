# 688114.SH 深度透视

## 因果逻辑链
- **[国产替代窗口期]** -> [测序仪销量创历史新高]: 商务部将Illumina列入不可靠实体清单，公司抓住机会以激进价格策略抢占市场，全年测序仪销售超1470台，同比增长16.15%，但导致毛利率承压。
- **[“以价换量”战略]** -> [营收下滑但亏损收窄]: 公司主动降价扩大装机量以锁定长期耗材收入，导致主营业务收入同比降7.56%，但扣非净利润同比减亏40.20%，经营质量改善。
- **[海外地缘政治风险]** -> [海外业务增长乏力]: 美国《国防授权法案》限制条款、NIH数据库关闭等事件，导致亚太区收入同比降31%，美洲区虽增长但毛利率骤降21.21个百分点。
- **[技术出海模式升维]** -> [一次性授权收入改善现金流]: 将CoolMPS技术授权给Swiss Rockets并获得首付款，使合同负债同比暴增127.62%，经营活动现金流净额首次转正至2.19亿元。
- **[AI深度融合]** -> [研发效率提升与人员优化]: 公司通过AI智能体PrimeGen等工具替代重复性研发工作，研发人员从812人降至572人，研发费用同比降27.79%，但核心产品迭代未受影响。
- **[多组学业务爆发]** -> [第二增长曲线初现]: 时空组学收入同比增161.76%，细胞组学增79.48%，低温存储增187.99%，OMICS板块整体收入增47.83%，成为唯一正增长板块。
- **[关联交易依赖]** -> [业绩波动风险]: 前五大客户中关联方华大系占比28.34%，若关联采购下降而第三方客户拓展不及预期，将对业绩产生重大不利影响。

## 风险警告
**地缘政治与知识产权诉讼是最大不确定性。** 美国2026财年《国防授权法案》已包含针对公司的限制条款，虽尚未实施但已导致亚太客户采购延迟、海外业务承压。同时，公司在德国、英国、法国等地受和解协议约束，在澳大利亚正面临Oxford Nanopore的专利侵权诉讼，若败诉将直接限制相关区域的产品销售。这些非市场风险可能随时打断公司的全球化进程，且难以通过技术或价格手段化解。

**“以价换量”战略的可持续性存疑。** 公司为抢占国产替代窗口期大幅降价，导致全读长测序毛利率同比降4.12个百分点，美洲区毛利率更是骤降21.21个百分点。虽然装机量创新高，但单台设备的试剂消耗额能否如期提升尚未验证。若下游客户因预算收紧或技术路线切换导致耗材采购不及预期，前期牺牲的利润将无法通过后续耗材收入弥补，公司可能陷入“增收不增利”甚至“量价齐跌”的困境。
