# 300322.SZ 深度透视

## 因果逻辑链
- **[消费电子市场回暖 + 新项目订单]** -> [天线及模组业务收入增长32.88%]: 公司抓住手机、PC等终端需求复苏契机，持续获得国内主流手机厂商新项目订单，推动核心业务收入与利润倍数增长。
- **[PS5游戏机SOC散热模组量产交付]** -> [散热器件及模组收入翻倍增长126%]: 成为该品类核心供应商，2025年累计交付量突破400万套，规模效应显著，驱动该板块成为第二增长曲线。
- **[新能源汽车渗透率提升 + 核心客户份额稳增]** -> [线束及连接件收入增长53.95%]: 子公司金日工业紧跟新能源车发展，新项目、新订单交付顺畅，规模化效应与精细化管理共同提升盈利能力。
- **[越南工厂量产 + 业务结构优化]** -> [传感器智能模组收入增长86.34%]: 关闭亏损的传统指纹模组业务，集中发展传感器模组，越南工厂产能释放带动整体规模明显增长。
- **[剥离亏损指纹模组业务（安徽凯尔）]** -> [归母净利润扭亏为盈至6468万元]: 出售持续亏损的安徽凯尔80.2%股权，优化资产结构，消除负向拖累，是公司实现盈利反转的关键一步。
- **[4D毫米波雷达波导天线批量出货]** -> [车载天线业务盈利能力提升]: 成为国内首家具备波导天线塑胶金属化量产能力的公司，向头部客户出货超300万PCS，技术壁垒转化为市场优势。
- **[研发投入持续（占收入6.66%）]** -> [技术壁垒与新产品储备]: 聚焦卫星通信天线、服务器液冷板等前沿领域，在审发明专利111项，为未来在AI、商业航天等新兴领域竞争奠定基础。

## 风险警告
**核心风险在于现金流与高负债的剪刀差。** 尽管公司2025年实现扭亏为盈，但经营活动现金流净额仍为-2753万元，且连续三年为负。与此同时，公司总负债高达25.3亿元，资产负债率接近70%，短期借款近10亿元。收入增长并未有效转化为现金，反而因客户账期长、票据结算多导致“纸面富贵”，偿债压力巨大，财务费用持续侵蚀利润。

**第二增长曲线的可持续性存疑。** 散热器件业务虽翻倍增长，但毛利率仅为5.52%，且同比下滑2.74个百分点，显示出该业务以价换量的特征，盈利能力薄弱。同时，公司募投项目“汽车业务总部项目”进度仅41.85%，已多次延期，表明公司在向新业务转型过程中，资本开支效率与项目执行力面临挑战。若新兴业务（如液冷、卫通）无法快速放量并改善毛利结构，公司可能陷入增收不增利的困境。
