# 300807.SZ 深度透视

## 因果逻辑链
- **[聚焦高附加值产品与核心业务]** -> [毛利率提升4.5个百分点]: 主动调整低毛利产品线，优化收入结构，使综合毛利率从36.62%提升至41.12%。
- **[加强应收账款管理与催收]** -> [信用减值损失大幅减少]: 信用减值损失从-2051万元收窄至+1706万元（转回），直接驱动净利润减亏52.91%。
- **[严控费用支出与优化成本结构]** -> [期间费用同比下降]: 销售、管理、研发、财务四项费用合计同比减少约1000万元，降幅约9.5%。
- **[软件产品及其他收入高增]** -> [收入结构优化]: 软件产品及其他收入同比增长63.98%，占比从18.84%提升至31.57%，成为收入增长的主要驱动力。
- **[公交行业财政投入压力]** -> [传统硬件业务收入下滑]: 智能调度、收银、充电等传统硬件业务收入同比下滑9.68%至36.54%，反映下游客户预算收紧。
- **[控制权变更与业绩承诺]** -> [经营稳定性与战略方向明确]: 原实控人郭建国向启明基金转让控制权，并承诺2025年扣非净亏损不超3000万元、2026年扭亏，为短期业绩设定底线。
- **[研发投入持续高企]** -> [技术壁垒与未来竞争力]: 研发投入占营收比重达25.25%，聚焦AI大模型、智能座舱等前沿领域，但短期内对利润形成压制。

## 风险警告
**核心风险在于业绩持续亏损与主业增长乏力。** 公司连续三年亏损（2023-2025年），尽管2025年大幅减亏，但扣非净利润仍为-3324万元。传统硬件业务（智能调度、收银、充电）收入全面下滑，表明核心主业面临下游公交客户财政预算收紧、需求萎缩的严峻挑战。公司能否在2026年实现扭亏，高度依赖软件等高毛利业务的持续高增以及成本费用的进一步压缩，存在较大不确定性。

**第二大风险是控制权变更后的整合与战略落地风险。** 2026年初公司完成控制权变更，新实控人启明基金为财务投资者，其战略意图与公司原有业务协同性尚待验证。新一届董事会提出“稳健主业+高成长第二主业”的双轮驱动战略，但第二主业方向未明确，且公司体量较小、资源有限，新业务拓展可能分散精力或导致投入失败。此外，公司应收账款余额仍高达2.26亿元，占总资产37.5%，回款压力依然巨大。
