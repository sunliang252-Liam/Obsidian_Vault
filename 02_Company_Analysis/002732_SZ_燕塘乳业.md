# 002732.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡加剧]** -> [营收下降8.47%]: 乳制品行业“需求收缩与供给扩大”双重困境下，华南市场竞争白热化，公司液体乳、花式奶、乳酸菌饮料三大品类销量全面下滑。
- **[华南原奶成本劣势]** -> [毛利率承压]: 南方气候与养殖条件限制导致原奶成本高于北方同行，无法充分享受原奶降价红利，液体乳类毛利率仅14.31%，价格竞争力弱于全国性品牌。
- **[产业集群项目补贴]** -> [经营现金流大增40%]: 报告期内收到中央财政产业集群项目补贴款，推动经营活动现金流量净额达2.1亿元，显著高于净利润。
- **[在建工程大幅投入]** -> [投资活动现金流净流出-2.13亿元]: 粤东日产600吨工厂、广垦智慧物流中心等产业集群项目集中建设，投资活动现金流出同比增127.5%。
- **[淘汰生物资产损失]** -> [非经常性损益拖累净利润]: 淘汰奶牛产生的资产处置损失及营业外支出合计超2000万元，是扣非净利润同比下滑47.42%的核心原因之一。
- **[经销商网络收缩]** -> [线下渠道收入下降8.98%]: 经销商数量净减少55家（-8.5%），传统经销渠道收入萎缩，反映终端动销压力与渠道调整阵痛。
- **[新品推出与品牌升级]** -> [产品结构优化]: 推出15款新品（雪山牧场、超级乐比等），叠加“广东鲜奶销量第一”认证及全运会独家供应商身份，巩固差异化竞争壁垒。
- **[工牧一体化全产业链]** -> [成本与品质控制]: 自有牧场单产同比提升8.1%，战略合作牧场锁价采购，构建“饲草种植-奶牛养殖-加工-冷链-终端”闭环，降低外部波动冲击。

## 风险警告
**核心风险在于行业供需失衡的持续性与公司成本结构的先天劣势。** 华南地区原奶成本高企，使公司在与全国性品牌的低价促销战中处于被动，液体乳类毛利率仅14.31%，价格弹性不足。若行业“内卷”持续，公司营收与利润可能进一步承压。此外，公司对广东区域市场依赖度极高（省内收入占比超97%），外埠市场开拓面临物流半径与品牌认知的双重壁垒，增长空间受限。

**财务层面的隐忧在于利润质量与资本开支压力。** 2025年净利润同比下降43.94%，而经营现金流大增主要依赖政府补贴，扣非净利润下滑幅度更大（-47.42%）。同时，粤东工厂、智慧物流中心等在建工程总投资超18亿元，未来折旧与运营成本将显著增加，若产能利用率不及预期，可能侵蚀利润。公司当前分红率已降至每10股0.6元，反映资本开支压力下的回报收缩。
