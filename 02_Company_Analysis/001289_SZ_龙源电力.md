# 001289.SZ 深度透视

## 因果逻辑链
- **[新能源全面入市，电价市场化改革]** -> [净利润同比-28.78%]: 2025年“136号文”推动新能源电量全面进入电力市场，公司风电平均上网电价同比下降52元/兆瓦时至475元/兆瓦时，直接压缩利润空间。
- **[装机高速增长与用电需求增长不匹配]** -> [风电利用小时数下降138小时]: 全国新能源装机增速远超用电需求增速，导致部分区域供需失衡、限电比例升高，公司风电平均利用小时数降至2,052小时。
- **[平价项目增加与市场交易规模扩大]** -> [平均上网电价结构性下降]: 新增平价项目占比提升，叠加市场化交易电量规模扩大，拉低了整体平均上网电价水平。
- **[可再生电费补贴回款大幅增加]** -> [经营活动现金流净额同比+27.61%]: 报告期内可再生电费补贴回款显著改善，推动经营性现金流净额增至218.33亿元，现金流质量提升。
- **[处置火电业务，聚焦新能源]** -> [营收同比-18.60%，但新能源营收仅-3.85%]: 2024年下半年火电子公司出表导致营收口径变化，剔除火电影响后，新能源发电业务营收同比仅小幅下降。
- **[太阳能装机高速扩张]** -> [太阳能发电量同比+70.92%]: 2025年净新增太阳能控股装机3,142.5兆瓦，推动太阳能发电量大幅增长，成为增量贡献主力。
- **[绿证交易规模扩大]** -> [绿证交易量同比+59.47%]: 公司构建“一体三翼”销售体系，核发绿证1,620.7万张，交易1,632.2万张，绿色环境价值兑现能力增强。
- **[控股股东资产注入承诺延期]** -> [同业竞争问题解决时间表后移]: 国家能源集团将存续风电业务资产注入期限延期至2028年1月24日，短期资产注入预期减弱。

## 风险警告
**核心风险：电价下行与消纳困境的双重挤压。** 随着“136号文”全面落地，新能源上网电价市场化改革已进入深水区。2025年公司风电平均上网电价已降至475元/兆瓦时，同比降幅达9.9%。在电力现货市场全国覆盖加速推进的背景下，电价下行趋势难以逆转。同时，全国新能源装机高速增长导致消纳压力持续加大，2025年风电利用小时数同比下降6.3%，限电损失同比增加。量价齐跌的格局将直接侵蚀公司核心盈利能力，这是未来最根本的挑战。

**结构性风险：高资本开支与低回报率的矛盾。** 公司处于规模扩张期，2025年资本开支高达238.31亿元，但新增装机增速（11.8%）并未有效转化为利润增长。太阳能装机占比快速提升（新增3.14GW），但其平均上网电价仅318元/兆瓦时，远低于风电的475元/兆瓦时，拉低了整体资产回报率。在融资规模持续增长（全年发行债券448亿元）的背景下，若新增项目收益率持续走低，将导致ROE进一步承压（2025年已降至6.08%），并放大财务杠杆风险。
