# 300868.SZ 深度透视

## 因果逻辑链
- **[ODM/OEM核心客户订单流失]** -> [营收与毛利双降]: 国内客户业务变动及海外关税政策导致部分客户转移供应链至东南亚，ODM/OEM业务收入同比锐减25.76%，拖累整体营收下降17.33%。
- **[美元贬值导致汇兑损失激增]** -> [财务费用大幅侵蚀利润]: 外销以美元结算，报告期内美元汇率显著下降，产生的汇兑损失较上年同期增加1,028.83万元，财务费用同比飙升333.36%。
- **[自有品牌业务推广投入加大]** -> [销售费用增加但带动收入增长]: 公司为提升品牌影响力，加大业务推广费，销售费用同比增加23.58%，但成功带动自有品牌业务收入同比增长27.51%。
- **[消费电子迭代加速致存货贬值]** -> [资产减值损失扩大]: 市场迭代加快，自有品牌部分老机型库存库龄增加，导致存货可变现净值下降，计提的存货跌价准备增加，资产减值损失同比增加570.88万元。
- **[募投项目用地长期未落实]** -> [核心扩产计划严重滞后]: 核心募投项目“移动智能终端配件产品扩产项目”因公司暂未取得建设用地，进展远不及预期，已多次延期至2027年底，制约产能扩张。
- **[大客户集中度高]** -> [经营风险高度集中]: 前五大客户销售额占年度销售总额的52.69%，其中第一大客户占比高达28.93%，单一客户订单波动对公司业绩影响巨大。

## 风险警告
**核心风险在于ODM/OEM业务的结构性衰退与转型阵痛。** 公司赖以生存的ODM/OEM业务正遭受双重打击：国内核心客户订单流失，海外客户因关税与地缘政治因素加速向东南亚转移。这并非短期波动，而是全球供应链重构下的长期趋势。公司试图通过自有品牌“决色”和拓展AI眼镜、无人机结构件等新赛道来弥补，但自有品牌体量尚小（仅占营收24.4%），且新业务从研发到规模化供货仍需时日，短期内难以对冲ODM业务的下滑。

**财务层面，公司正陷入“增收不增利”甚至“减收减利”的困境。** 营收下降的同时，为维持自有品牌增长而激增的销售费用，叠加美元贬值带来的汇兑损失，导致费用率大幅攀升。更值得警惕的是，公司账面虽有大量现金（约4.8亿），但其中超7.5亿为闲置募集资金，使用受限。而核心募投项目因土地问题长期停滞，巨额资金无法有效转化为生产力，资产回报率持续走低，公司盈利能力面临严峻考验。
