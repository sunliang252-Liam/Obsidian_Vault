# 300457.SZ 深度透视

## 因果逻辑链
- **全球新能源车销量增长21.5%，动力电池使用量增长31.7%** -> 公司锂电池专用生产设备收入增长29.81%: 下游需求扩张带动上游设备采购增加
- **全球储能电池出货量增长79%** -> 公司储能领域628Ah大容量电芯Z型叠片产线量产: 储能市场快速增长，推动公司开发大容量储能电池设备
- **公司持续加大研发投入，研发费用增长15.70%** -> 推出多项尖端设备新品并获客户认可: 研发投入带动技术创新，提升产品竞争力
- **公司加速国际化人才布局与全球多地设子公司** -> 海外市场拓展，产品远销多国，锂电设备新接订单98.54亿元: 人才与本土化服务提升国际竞争力，获取海外订单
- **公司加强经营性现金流管理，优化采购支付结构** -> 经营活动现金流量净额大幅增长2899.42%: 管理改善提升回款效率，降低现金流出
- **电子烟业务以自有品牌拓展海外市场，扩充销售团队并采取多元推广** -> 境外地区收入同比下降10.00%，但电子烟业务在部分新兴市场占有率提升: 海外推广投入加大，但整体境外收入受其他因素影响下滑；电子烟业务在东南亚、中东等新兴市场取得突破

## 风险警告
公司锂电设备业务高度依赖下游动力电池及储能行业需求，若新能源车销量增长不及预期或储能行业政策变化，可能导致订单减少；海外业务拓展面临地缘政治、汇率波动及贸易壁垒风险；电子烟业务受各国监管政策影响较大，如海外市场加强控烟限制，可能冲击销售；公司生产量与库存量大幅增长（生产量+176.87%，库存量+43.02%），若订单交付延迟，存在存货减值风险；前五大客户集中度较高（54.41%），客户流失将对业绩产生重大不利影响。
