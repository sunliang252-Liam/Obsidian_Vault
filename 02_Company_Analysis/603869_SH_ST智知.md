# 603869.SH 深度透视

## 因果逻辑链
- **[聚焦聚安网平台战略]** -> [聚安网收入同比增长11.33%]: 公司主动收缩低毛利智能集成业务，将资源集中于聚安网（城市安全）和企业智能化两大核心，推动技术服务及软件收入增长28.18%，优化收入结构。
- **[主动收缩低毛利智能集成业务]** -> [整体营收仅微增2.34%，但扣非净利润扭亏]: 智能集成收入同比下降40.76%，拖累整体营收增速，但高毛利业务占比提升，使扣非净利润从-2102万转为+1222万，盈利能力实质性改善。
- **[深度绑定新奥集团产业生态]** -> [关联交易收入占营收约37%]: 公司依托新奥集团261个城燃项目及多元产业，获取稳定的业务来源和场景验证机会，但同时也导致对关联方的高度依赖。
- **[紧抓万亿国债与设备更新政策]** -> [城市生命线、燃气监管等政府端业务落地]: 政策驱动下，公司成功落地天津、开封、石家庄等标杆项目，推动聚安网业务向政府安全智能体转型。
- **[研发投入聚焦与人员结构优化]** -> [研发费用同比大幅下降44.93%]: 公司主动减少非核心业务研发，并优化研发人员结构，导致研发费用从5998万降至3303万，短期提升利润，但需关注长期技术储备。
- **[大额存单到期转投理财产品]** -> [财务费用同比增加（利息收入减少）]: 三年期大额存单于2025年2月赎回，闲置资金转向理财产品（收益计入投资收益），导致利息收入减少，财务费用从-3016万升至-1993万。
- **[算力业务规模化运营]** -> [企业智能化收入同比增长84.01%]: 公司分布式智算运营模式落地，签约盐城、武威等算力服务项目，推动该业务收入从7326万增至1.35亿，成为第二增长曲线。

## 风险警告
**核心风险在于对关联方的高度依赖与业务转型的不确定性。** 公司约37%的收入来自新奥集团关联方，且关联交易预计金额与实际发生额差异巨大（如销售类预计3.59亿，实际仅2.52亿），显示关联交易存在较大波动性和计划外调整风险。一旦新奥集团战略或资金安排变化，公司收入将受显著冲击。此外，公司虽已摘帽，但历史上因财务造假被处罚的信用污点仍在，市场信任重建需要时间。

**盈利质量与增长可持续性存疑。** 2025年扣非净利润仅1222万元，而公允价值变动收益（1274万）和政府补助（569万）等非经常性损益贡献了主要利润。核心业务聚安网毛利率同比下降12.81个百分点，显示竞争加剧或成本上升。同时，研发费用大幅削减44.93%，可能削弱长期技术护城河。公司需证明在脱离关联方输血和非经常性损益后，仍能实现内生性、可持续的盈利增长。
