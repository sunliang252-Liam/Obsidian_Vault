# 600268.SH 深度透视

## 因果逻辑链
- **[电网自动化业务稳健增长]** -> [营收增长]: 公司传统优势产业，受益于国家电网年度投资超6500亿元，变电站自动化等产品需求稳定，实现营收43.07亿元，同比增长12.55%。
- **[信息技术业务爆发式增长]** -> [营收与利润双升]: 新能源智慧生产管理平台等数字能源业务快速推广，覆盖31省、超700个场站，带动信息技术业务营收同比大增101.34%，毛利率提升7.48个百分点。
- **[毛利率提升]** -> [净利润增速远超营收]: 整体毛利率同比增加2.92个百分点，叠加营收增长6.8%，使归母净利润同比大增40.95%，利润弹性显著。
- **[研发高投入驱动技术壁垒]** -> [核心竞争力强化]: 研发费用6.85亿元，占营收7.24%，推动“华电睿”系列自主可控技术突破，巩固电力自动化行业领先地位。
- **[关联交易依赖度高]** -> [业绩稳定性风险]: 前五名客户销售额占年度销售总额67.12%，其中关联方（华电集团）销售额占44.27%，业绩高度依赖集团内部订单。
- **[系统集成业务收缩]** -> [业务结构优化]: 主动调整低毛利的风电、光伏EPC总承包业务，系统集成中心营收同比下降31.51%，但资源向高毛利的信息技术、电网自动化业务倾斜。
- **[经营活动现金流净额下降]** -> [营运资金压力]: 尽管利润大增，但经营活动现金流净额同比下降16.67%，主因购买商品、接受劳务支付的现金增加，显示回款或存货管理存在压力。

## 风险警告
**核心风险在于对控股股东华电集团的过度依赖。** 公司44.27%的销售额来自关联方，这种“背靠大树”的模式虽保障了短期业绩，但严重削弱了市场化竞争能力和议价权。一旦集团投资策略或采购政策调整，公司业绩将面临剧烈波动。此外，海外业务毛利率骤降11.22个百分点，营收萎缩38.69%，国际化拓展受阻，增长天花板明显。

**财务健康度存在隐忧。** 在归母净利润大增40.95%的背景下，经营活动现金流净额反而下降16.67%，利润的“含金量”不足。应收账款及票据高达49.69亿元，占总资产40.94%，且合同资产激增625.93%，表明公司为冲规模可能放松了信用政策或项目结算周期拉长，坏账风险与资金占用压力不容忽视。
