# 688216.SH 深度透视

## 因果逻辑链
- **[半导体行业需求复苏]** -> [营收增长15.34%]: 消费电子回暖、新能源汽车及AI算力需求爆发，带动公司订单量显著回升。
- **[产能利用率提升]** -> [毛利率改善]: 随着订单增加，折旧、摊销、人力等固定成本分摊下降，综合毛利率较上年同期上升。
- **[功率器件业务爆发]** -> [营收结构优化]: 功率器件封装测试营收同比增长207.23%，成为公司增长新引擎，毛利率提升14.56个百分点。
- **[持续战略性资本开支]** -> [财务费用激增54.61%]: 二期厂房转固及融资租赁业务增加，导致利息支出大幅上升，侵蚀利润。
- **[高额有息负债]** -> [财务风险高企]: 截至报告期末有息负债余额6.33亿元，其中个人借款1.43亿元，偿债压力巨大。
- **[经营活动现金流由负转正]** -> [经营状况边际改善]: 现金结算业务量增加及政府补助流入，使经营现金流净额从-2955万元转为6354万元。
- **[传统封装为主的技术路线]** -> [面临先进封装转型压力]: 公司产品仍以SOP、SOT、QFN/DFN等传统封装为主，在AI芯片驱动的先进封装浪潮中面临被边缘化风险。

## 风险警告
**核心风险在于高杠杆下的持续亏损与现金流脆弱性。** 公司连续三年亏损，2025年归母净利润-7538万元，而同期有息负债高达6.33亿元，其中个人借款1.43亿元，担保总额占净资产比例高达108.78%。尽管经营现金流转正，但投资活动现金流持续净流出，公司高度依赖外部融资维持运营，一旦信贷收紧或行业景气度回落，流动性危机将迅速爆发。

**技术路线与行业趋势错配是长期隐忧。** 公司核心竞争力仍集中在传统封装领域，而行业正加速向2.5D/3D、Chiplet等先进封装演进。公司在先进封装（如FCQFN、Dr.MOS）的布局尚处早期研发阶段，短期内难以贡献业绩。若不能快速实现技术突破和商业化，将在与头部封测厂及晶圆代工厂的竞争中持续处于劣势，市场份额面临被挤压的风险。
