# 300026.SZ 深度透视

## 因果逻辑链
- **[药械智慧供应链业务大幅萎缩]** -> [营业收入同比下降14.55%]: 该板块收入同比骤降67%，直接拖累整体营收规模。
- **[资产减值损失激增]** -> [归母净利润仅0.18亿元]: 计提存货、固定资产及商誉减值损失1.66亿元，严重侵蚀利润。
- **[中药配方颗粒业务承压]** -> [核心业务增长乏力]: 收入同比下降7.78%，面临集采扩面与市场竞争加剧的双重压力。
- **[血必净注射液学术价值凸显]** -> [核心产品收入逆势微增0.38%]: 凭借《柳叶刀》子刊等顶级循证证据，巩固了在脓毒症治疗领域的临床地位。
- **[医疗器械业务海外代工转移]** -> [板块收入同比暴跌47.56%]: 为应对关税政策，将订单转移至越南代工厂，导致短期收入大幅下滑。
- **[经营性现金流健康]** -> [净利润含金量高]: 经营活动现金流净额8.11亿元，远超净利润，主要得益于资产减值、折旧摊销等非现金支出及存货减少。
- **[研发投入资本化率大幅降低]** -> [研发费用对当期利润的侵蚀减弱]: 资本化比例从10.41%降至2.72%，更多研发投入费用化，但绝对值下降，显示研发节奏放缓。

## 风险警告
**核心风险在于主业增长乏力与巨额资产减值的双重打击。** 公司营收连续两年下滑，2025年降幅扩大至14.55%，主要拖累项——药械智慧供应链业务收入骤降67%，显示该板块已陷入严重困境。更令人担忧的是，公司计提了高达1.66亿元的资产减值损失，直接导致归母净利润仅剩0.18亿元，盈利能力已至冰点。中药配方颗粒作为核心业务，在集采和竞争加剧下增长停滞，未来能否稳住基本盘存在巨大不确定性。

**第二重风险来自集采政策深化与市场竞争格局恶化。** 中药配方颗粒国标推进与集采提质扩面，将持续压缩行业利润空间。公司虽在成本管控上有所动作，但面对众多对手的激烈竞争，能否维持市场份额和毛利率仍是未知数。同时，成品药业务中多个品种面临集采接续，价格压力持续存在。医疗器械业务因关税问题被迫转移产能，海外市场拓展受阻，短期难以恢复。公司整体处于“存量业务承压、增量业务不明”的困境期。
