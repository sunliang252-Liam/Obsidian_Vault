# 603988.SH 深度透视

## 因果逻辑链
- **[处置金融资产]** -> [归母净利润暴增396.75%]: 全资子公司艾斯伊西减持港股友谊时光股票，产生投资收益约1980万元，是净利润扭亏为盈的核心驱动力。
- **[原材料价格高位运行]** -> [毛利率承压]: 铜材、电磁线等主要原材料采购均价创历史新高，导致产品成本持续增加，整体毛利率同比下滑0.54个百分点。
- **[产品结构优化]** -> [直流电机毛利率大幅提升]: 公司主动调整订单结构，提高高毛利直流电机占比（营收+90.71%），其毛利率同比提升13.30个百分点，部分对冲了成本压力。
- **[海外业务扩张]** -> [出口毛利率显著改善]: 国外收入同比增长64.17%，毛利率高达61.02%，同比提升6.32个百分点，成为利润的重要稳定器。
- **[控股股东变更]** -> [战略转型双主业]: 高地资源入主后，公司战略从单一电机制造转向“电机+上游资源”双主业，新设中科电能源等子公司，开启第二增长曲线。
- **[原材料涨价与产品小型化]** -> [营收微降]: 尽管销量台数增长，但产品呈现小型化、短交期趋势，叠加价格竞争，导致全年营业收入同比微降1.17%。
- **[强化回款考核]** -> [经营性现金流大幅改善]: 公司重点考核应收账款回款，加速资金回笼，使经营活动现金流净额同比大增167.34%至7566万元。

## 风险警告
**核心风险在于主业盈利能力的持续恶化与转型的不确定性。** 公司2025年归母净利润的暴增完全依赖非经常性损益（处置金融资产），而扣非净利润同比下滑28.56%，表明电机主业在原材料成本高企和产品小型化趋势下，盈利空间正被持续压缩。若未来原材料价格继续高位运行，主业毛利率可能进一步承压。

**双主业战略尚处萌芽期，新业务拓展存在巨大风险。** 公司进军上游资源行业（矿产、新能源）与现有电机业务协同性尚不明确，且该领域投资大、周期长、价格波动剧烈，对公司的资金实力、人才储备和风险管理能力构成严峻考验。短期内，新业务难以贡献利润，反而可能增加资本开支和管理成本。
