# 600123.SH 深度透视

## 因果逻辑链
- **[主导产品价格大幅下跌]** -> [营收与利润暴跌]: 煤炭、尿素、己内酰胺销售均价分别同比下降21.76%、13.81%、19.01%，直接导致营业收入下降30.39%，归母净利润由盈转亏至-5.4亿元。
- **[高价收购探矿权]** -> [财务杠杆急剧攀升]: 斥资约74亿元竞得寺头区块探矿权，导致投资活动现金净流出76.7亿元，资产负债率从47.54%飙升至59.40%，财务费用同比大增35.31%。
- **[化工板块全面亏损]** -> [拖累整体业绩]: 尿素业务毛利下降66.75%，己内酰胺业务毛利为负（-8695万元），新材料分公司亏损3.27亿元，煤化工板块成为业绩最大拖累。
- **[新建矿井投产即亏损]** -> [侵蚀母公司利润]: 同宝、沁裕、百盛等新投产整合矿合计亏损超5.5亿元，未能贡献预期收益，反而成为现金流出血点。
- **[参股公司亚美大宁巨额亏损]** -> [投资收益大幅转负]: 参股41%的亚美大宁净利润-3.47亿元，导致公司对联营企业投资收益从+2.1亿元骤降至-1.33亿元。
- **[库存积压与现金流恶化]** -> [经营压力加大]: 煤炭库存同比激增196.43%，经营活动现金流净额由正转负至-3.42亿元，公司流动性承压。
- **[会计估计变更粉饰利润]** -> [调节当期损益]: 延长固定资产折旧年限，增加2025年利润总额3738万元，占归母净利润亏损额的6.9%，掩盖了部分经营恶化实情。

## 风险警告
**核心风险在于“高价买矿”与“主业崩塌”的致命组合。** 公司以超过70亿元现金押注未来资源，但煤炭、化工主业已陷入量价齐跌的深度衰退，新投产矿井持续巨亏，现金流由正转负。这种“用借来的钱买未来，但当下已无法造血”的财务结构极其脆弱，一旦行业景气度持续低迷，公司将面临严峻的偿债压力和资产减值风险。

**治理与法律风险不容忽视。** 参股公司亚美大宁的仲裁案（要求延长合作期至2030年）结果存在重大不确定性，可能影响公司核心资产权益。同时，控股股东兰花集团旗下的东峰煤矿等与公司存在同业竞争，虽已通过统一销售部分解决，但根本问题悬而未决，存在潜在的利益输送风险。
