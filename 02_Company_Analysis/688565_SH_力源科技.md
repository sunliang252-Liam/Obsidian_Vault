# 688565.SH 深度透视

## 因果逻辑链
- **[核电/火电凝结水精处理系统设备订单充足]** -> [营收结构稳定]: 凝结水精处理系统设备收入2.39亿元，占主营收入84.77%，是公司最核心的收入来源，但整体营收因除盐水处理项目完工减少而下降23.89%。
- **[加强应收账款回款管理]** -> [信用减值损失转回，净利润扭亏]: 报告期内信用减值损失转回4,623万元，是公司实现净利润893.86万元（同比+252%）的关键非经常性因素，掩盖了扣非净利润仍为-1,195万元的事实。
- **[优化运营效率与成本控制]** -> [毛利率同比上升]: 在营收下降的背景下，公司通过成本控制使毛利率同比提升1.2个百分点，但扣非后仍亏损，显示主营业务盈利能力依然薄弱。
- **[经营活动现金流大幅改善]** -> [缓解资金压力]: 经营活动现金流净额达1.17亿元，同比+105.74%，主要得益于回款增加和支出减少，有效缓解了行业长付款周期带来的营运资金压力。
- **[氢燃料电池业务尚处商业化初期]** -> [对业绩贡献极小]: 氢燃料电池发动机系统收入仅38.5万元，且毛利率为-319.14%，仍处于亏损投入阶段，尚未形成有效的第二增长曲线。
- **[客户集中度高]** -> [经营依赖性强]: 前五大客户销售额占年度销售总额54.09%，且客户主要为大型发电集团，公司经营业绩高度依赖少数大客户的订单和项目进度。

## 风险警告
**核心风险在于主营业务盈利能力的脆弱性。** 公司2025年净利润扭亏为盈，完全依赖于信用减值损失的大额转回（4,623万元），而扣除非经常性损益后净利润仍为-1,195万元，表明其核心的环保水处理系统集成业务并未实现根本性盈利改善。营收同比下降23.89%，进一步印证了业务增长乏力。这种依赖会计估计变动实现的“纸面盈利”不可持续，一旦应收账款回款节奏放缓或坏账计提政策变化，公司将迅速重回亏损。

**第二增长曲线氢燃料电池业务前景不明，且存在重大资金消耗风险。** 该业务目前收入极低且严重亏损，商业化进程缓慢，而公司仍需持续投入研发和市场开拓。在主营业务造血能力不足、营运资金本就紧张（客户付款周期长达2-3年）的背景下，氢能业务的持续投入将进一步加剧公司的现金流压力。若国家相关产业政策出现调整或技术路线发生转向，该业务可能成为公司业绩的重大拖累。
