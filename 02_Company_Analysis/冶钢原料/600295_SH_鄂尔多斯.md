# 600295.SH 深度透视

## 因果逻辑链
- **[硅铁、烧碱等核心产品毛利率提升]** -> [净利润同比大增27.93%]: 尽管营收下降9.37%，但电冶板块通过循环经济产业链的低成本优势，在原材料价格下行周期中，硅铁、烧碱等产品毛利率显著提升，驱动利润增长。
- **[电冶板块循环经济产业链]** -> [低成本核心竞争力]: 依托“煤-电-硅铁/氯碱化工”一体化模式，实现资源就地转化、能源梯级利用、三废循环利用，有效对冲了硅铁、PVC等产品价格下行的压力。
- **[服装板块全产业链与品牌溢价]** -> [高毛利率与稳健增长]: 羊绒服装板块凭借从牧场到商场的全产业链掌控和高端品牌定位，维持近60%的高毛利率，在消费温和复苏背景下实现营收与利润的稳健增长。
- **[财务费用大幅下降]** -> [利润增厚]: 报告期内公司主动降低有息负债规模，叠加利率下行，财务费用同比减少40.78%，直接贡献了利润弹性。
- **[资产减值损失减少]** -> [利润改善]: 本期计提的存货、固定资产及在建工程减值损失同比减少35.66%，对利润的侵蚀程度降低。
- **[高比例现金分红]** -> [股东回报稳定]: 公司拟每10股派发现金红利7元，分红比例高达归母净利润的82.92%，延续了高分红传统，对红利策略投资者有较强吸引力。
- **[新能源与智能化布局]** -> [长期生存竞争力]: 风光火储一体化项目并网、智能工厂建设、无人驾驶重卡等新质生产力布局，旨在降低长期能耗成本，构筑绿色低碳壁垒。

## 风险警告
**核心风险在于电冶板块的强周期性。** 公司近60%的营收和主要利润来源依赖硅铁、PVC、烧碱等大宗商品，其价格与宏观经济、房地产及钢铁行业景气度高度相关。2025年利润大增主要得益于成本下降速度快于产品价格下跌，若未来下游需求持续疲软或行业产能过剩加剧，产品价格可能进一步承压，利润空间将被迅速压缩。多晶硅业务已陷入巨额亏损（毛利率-377%），成为显著的拖累项。

**第二重风险来自国际贸易与政策的不确定性。** 公司羊绒制品及部分化工产品出口面临美国关税、欧盟碳边境调节机制（CBAM）等新型贸易壁垒的挑战。同时，国内能耗双控和环保政策持续趋严，电冶板块作为高耗能行业，未来可能面临更严格的产能限制和碳排放成本上升，这将直接侵蚀其赖以生存的低成本优势。
