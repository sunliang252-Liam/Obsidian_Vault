# 002936.SZ 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [营收增长乏力]: 市场利率下行及LPR重定价导致净利息收益率同比下降0.11个百分点至1.61%，利息净收入仅增4.82%，整体营收增速仅0.34%。
- **[存款结构定期化]** -> [负债成本刚性]: 个人定期存款占比从46.66%升至52.12%，推动存款平均成本率仅从2.17%微降至1.99%，负债成本降幅远小于资产收益降幅。
- **[零售转型驱动]** -> [储蓄存款高增]: 通过“四大管家”服务体系及社区/惠农站点建设，储蓄存款余额同比增长24.60%，成为存款增长14.47%的核心引擎。
- **[不良率下降但信用成本高企]** -> [利润侵蚀]: 不良贷款率降至1.71%，但全年信用减值损失仍高达72.82亿元，占营收56.4%，其中金融投资减值损失同比大增60.57%。
- **[资本内生不足]** -> [资本充足率承压]: 核心一级资本充足率降至8.45%，逼近监管红线，ROE仅3.16%，内源性资本补充能力极弱，制约资产扩张空间。
- **[非息收入下滑]** -> [收入结构恶化]: 公允价值变动损益由正转负（-3.78亿），手续费及佣金净收入同比下降13.95%，非息收入占比降至15.92%。
- **[区域经济绑定]** -> [信贷增长锚定]: 紧密对接河南省“7+28+N”产业链群，科技贷款、绿色贷款等增速超25%，但房地产及批发零售业不良率仍处高位（5.11%/3.04%）。

## 风险警告
**核心风险在于资本与盈利的恶性循环。** 核心一级资本充足率8.45%已接近监管底线，而加权平均净资产收益率仅3.16%，内源性资本补充能力极弱。在净息差持续收窄、信用成本高企的背景下，若无法通过外部融资补充资本，将严重制约信贷投放和业务扩张，形成“低盈利→低资本→低增长”的负向螺旋。

**资产质量仍是最大隐患。** 尽管不良率降至1.71%，但关注类贷款占比2.02%未改善，且个人贷款不良率从1.56%升至1.83%。更关键的是，全年核销不良贷款35.44亿元，但金融投资减值损失同比暴增60.57%，表明风险可能从表内贷款向表外投资迁移。拨备覆盖率185.81%虽达标，但面对经济下行压力，缓冲垫仍显不足。
