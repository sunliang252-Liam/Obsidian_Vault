# 601963.SH 深度透视

## 因果逻辑链
- **[资产规模突破万亿]** -> [营收利润双十增长]: 资产规模同比增20.67%至10,337亿元，带动利息净收入增22.44%，驱动营收和净利润均实现超10%的同比增长。
- **[公司贷款高速扩张]** -> [利息收入增长]: 公司贷款同比增30.95%，占贷款总额77.46%，其利息收入增24.76%，是利息收入增长的核心引擎。
- **[负债成本显著压降]** -> [净息差企稳回升]: 计息负债平均成本率下降40个基点至2.18%，远超生息资产收益率27个基点的降幅，推动净息差逆势上升4个基点至1.39%。
- **[存款结构优化]** -> [负债成本下降]: 个人定期存款占比提升至49.56%，但通过利率动态调整，个人定期存款平均成本率下降42个基点至2.75%，有效压降整体负债成本。
- **[理财手续费收入骤降]** -> [非利息收入大幅下滑]: 受低利率市场周期影响，代理理财业务收入下降49.29%，导致手续费及佣金净收入下降32.66%，拖累非利息收入。
- **[信用减值损失增加]** -> [利润增速承压]: 信用减值损失同比增20.99%至38.58亿元，主要因证券投资减值损失增加，侵蚀了部分利润增长。
- **[风险加权资产扩张]** -> [资本充足率下降]: 风险加权资产同比增20.83%，远超资本净额增速，导致核心一级资本充足率下降1.35个百分点至8.53%，逼近监管红线。
- **[零售贷款不良率上升]** -> [资产质量结构分化]: 零售贷款不良率从2.71%升至3.23%，而公司贷款不良率从0.90%降至0.71%，显示资产质量风险从对公向零售迁移。

## 风险警告
**核心风险在于资本充足率快速下滑与资产质量结构性恶化。** 2025年风险加权资产增速（20.83%）远超资本净额增速（4.89%），导致核心一级资本充足率骤降1.35个百分点至8.53%，已逼近监管最低要求。在资产规模突破万亿后，若无法有效补充核心一级资本或控制风险资产扩张速度，将严重制约未来业务发展和分红能力。同时，零售贷款不良率逆势攀升0.52个百分点至3.23%，个人按揭贷款余额下降，而个人消费贷款快速增长，需警惕在经济下行周期中消费贷风险暴露的滞后性。

**盈利增长高度依赖规模扩张，结构性问题突出。** 营收和利润的双位数增长主要依靠公司贷款和债券投资规模的高速扩张，而净息差的改善主要源于负债成本压降，可持续性存疑。非利息收入中，理财手续费收入因市场周期因素骤降近半，显示中间业务收入来源单一且脆弱。信用减值损失大幅增加，尤其是证券投资减值损失由负转正，表明资产质量压力已从信贷资产向金融投资蔓延，需关注其后续影响。
