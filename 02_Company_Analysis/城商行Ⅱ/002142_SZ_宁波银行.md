# 002142.SZ 深度透视

## 因果逻辑链
- **市场利率下行、存量业务重定价及行业竞争加剧** -> 生息资产收益率下降53BP，其中贷款收益率下降61BP: 外部环境导致资产端定价承压
- **聚焦客户结算资金、强化结算存款考核，同时存款重定价及市场利率下行** -> 存款付息率下降33BP，整体付息负债利率下降38BP: 主动负债管理与市场利率下行共同压降负债成本
- **资产端收益率下降幅度（53BP）大于负债端成本下降幅度（38BP）** -> 净息差收窄12BP至1.74%，净利差收窄15BP至1.76%: 利率传导非对称导致息差压缩
- **生息资产规模稳步增长，日均规模同比增长17.76%** -> 利息收入增长2.55%，利息净收入增长10.77%: 规模扩张部分对冲利率下行对利息收入的影响
- **大财富战略推进、低利率环境下居民财富管理需求提升及资本市场回暖** -> 手续费及佣金净收入增长30.72%，代理类业务收入增长35.68%: 财富管理及代销业务受益于市场环境和战略布局
- **坚持精细化管理，持续推进降本增效** -> 业务及管理费用同比下降0.51%，成本收入比下降2.80个百分点: 成本管控措施见效
- **贷款规模增长及风险防控** -> 信用减值损失增加43.08%，但不良率保持低位0.76%: 规模扩张导致拨备计提增加，但资产质量保持稳定
- **公司贷款大幅增长30.45%，个人贷款下降4.17%** -> 贷款结构向对公倾斜，带动生息资产收益率变化: 业务结构调整影响资产端收益
- **对公活期存款新增占比70.84%，存款付息率下降33BP** -> 负债成本有效压降，支撑净息差: 低成本活期存款占比提升优化负债结构
- **资产规模增长16.11%，贷款增长17.43%** -> 营业收入增长8.01%，净利润增长8.13%: 规模扩张驱动盈利增长

## 风险警告
深度风险总结：公司面临净息差持续收窄的压力，2025年净息差1.74%，较上年下降12BP，主要因生息资产收益率下降53BP，幅度大于负债成本下降38BP。个人贷款规模下降，消费信贷需求偏弱，同时信用减值损失同比增长43.08%，需关注资产质量变化。利率下行周期中，息差缩窄和信用风险是主要挑战。
