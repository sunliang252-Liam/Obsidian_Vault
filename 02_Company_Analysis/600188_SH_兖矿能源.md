# 600188.SH 深度透视

## 因果逻辑链
- **[煤价下行]** -> [归母净利润同比-43.61%]: 自产煤综合售价同比降19.3%（634.97→512.52元/吨），直接压缩利润空间。
- **[并购西北矿业]** -> [商品煤产量创历史新高]: 贡献商品煤3381万吨，推动总产量达1.82亿吨，同比+6.3%，以量补价。
- **[陕蒙基地高产高效]** -> [利润贡献占比达56%]: 陕蒙基地商品煤产量4666万吨（+354万吨），成为最核心的利润增长极。
- **[成本管控见效]** -> [吨煤销售成本同比-4.3%]: 实施“十个加强、十个增效”等措施，自产煤吨煤成本降至321.09元/吨，部分对冲煤价下跌。
- **[汇率波动]** -> [财务费用同比+32.24%]: 汇率变动导致汇兑损失同比增加9.67亿元，侵蚀利润。
- **[矿业权出让收益规定变化]** -> [销售费用同比-41.33%]: 冲回部分已计提采矿权出让收益，影响销售费用同比减少17.06亿元。
- **[化工品成本下降]** -> [煤化工毛利率同比+5.15个百分点]: 原料煤成本回落，化工品销售成本同比-11.99%，盈利能力改善。
- **[高比例分红政策]** -> [全年累计分红50.2亿元]: 2023-2025年度分红政策要求约60%派现率，每股0.50元，维持高股东回报。

## 风险警告
**核心风险：煤价周期性下行与成本刚性上涨的剪刀差。** 2025年归母净利润暴跌43.61%，主因是自产煤售价同比下滑19.3%，而成本仅下降0.16%，导致煤炭业务毛利率骤降8.6个百分点。公司虽以量补价，但产量增长（+6.3%）远不足以弥补价格跌幅，盈利能力对煤价高度敏感。若2026年煤价反弹不及预期，利润修复将十分脆弱。

**第二风险：巨额资本开支与债务压力。** 2026年计划资本开支198亿元，且多个在建矿井（刘三圪旦、霍林河一号等）及化工项目（80万吨烯烃）需持续投入。截至年末，有息负债达1477.76亿元，资本负债率147.1%，财务费用因汇兑损失已同比大增32%。高杠杆叠加资本开支高峰，若现金流恶化，偿债压力将显著上升。
