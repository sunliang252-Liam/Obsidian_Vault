# 920158.BJ 深度透视

## 因果逻辑链
- **[海外市场爆发]** -> [境外销售同比增长1006%，毛利率达62.45%]: 公司大力开拓海外市场，重点完成海外订单交付，高毛利海外业务占比大幅提升，拉动整体毛利率从41.11%跃升至50.52%。
- **[产品结构优化]** -> [营收下降6.16%但净利润增长10.71%]: 公司主动收缩低毛利产品（其他能源化工设备、石化助剂），聚焦高附加值的电脱设备交付，实现“减收增利”。
- **[IPO募资到账]** -> [货币资金暴增156%，总资产增长33%]: 2025年10月北交所上市，募集资金净额1.58亿元，大幅增强资本实力，资产负债率从40.44%降至28.10%。
- **[高毛利电脱设备交付增加]** -> [电脱设备毛利率同比提升57.54个百分点]: 核心产品电脱盐/脱水设备收入增长11.94%，成本仅增长12.32%，规模效应与产品升级共同推高毛利。
- **[政府补助与理财收益增加]** -> [其他收益增长333%，投资收益增长377%]: 政府补助到账及货币资金理财收益增加，合计贡献非经常性收益约365万元。
- **[新签订单下降]** -> [合同负债减少49.47%，经营活动现金流减少42%]: 期末在执行订单规模同比下降，导致预收货款减少，同时客户回款放缓，现金流承压。
- **[研发投入持续]** -> [研发费用增长7.69%，占营收5.31%]: 聚焦绿氢、海工船舶装备等新兴领域，为长期增长储备技术，但短期尚未贡献显著收入。

## 风险警告
**核心风险在于海外业务的高波动性与国内市场的收缩。** 2025年境外销售暴增10倍，但境内销售同比下降45%，显示公司对海外大客户依赖度急剧上升。海外业务受地缘政治、汇率波动、贸易壁垒影响极大，且公司新设香港、迪拜子公司运营经验尚浅，一旦海外订单节奏放缓或出现交付问题，业绩将剧烈波动。同时，合同负债（预收款）大幅下降近50%，预示未来收入增长动力不足。

**盈利质量存在隐忧。** 净利润增长10.71%的背后，是毛利率从41%跳升至50.5%的“结构性改善”，但这主要依赖高毛利海外订单的集中交付，而非国内市场的全面复苏。此外，资产减值损失同比大增213%，主要系计提预计亏损合同增加，暗示部分在手订单盈利前景不佳。若海外高毛利订单不可持续，公司盈利能力将面临快速回落的风险。
