# 000691.SZ 深度透视

## 因果逻辑链
- **[破产重整成功]** -> [净资产由负转正]: 2025年末通过重整引入投资人及现金捐赠，净资产从-6481万暴增至4.51亿元，化解退市危机。
- **[重整投资人现金注入]** -> [货币资金暴增]: 货币资金从4204万增至5.09亿元，占总资产47.56%，流动性显著改善。
- **[核心子公司临港亚诺化工盈利]** -> [母公司仍巨亏]: 子公司净利润760.87万，但母公司层面因债务重组损失、营业外支出等，归母净利润仍亏损3580万。
- **[吡啶类产品量价齐升]** -> [营收增长17.61%]: 吡啶类产品销量增10.07%，营收增19.98%，毛利率提升5.71个百分点，是收入增长主引擎。
- **[非吡啶类产品库存激增]** -> [存货周转风险]: 非吡啶类产品库存量同比暴增175.44%，远超销量增速，存在跌价风险。
- **[经营活动现金流大幅转正]** -> [造血能力改善]: 经营现金流净额从-98万增至1415万，主要系销售回款增加，但净利润仍为负，现金利润背离。
- **[原材料价格波动]** -> [成本控制压力]: 主要原材料价格下半年下降，但公司营业成本增速(13.25%)仍接近营收增速(17.61%)，毛利率改善空间有限。

## 风险警告
公司虽通过破产重整实现“财务重生”，但核心业务盈利能力依然羸弱。2025年归母净利润继续亏损3580万元，扣非后亏损2172万元，表明主营精细化工业务尚未走出亏损泥潭。高达5.09亿元的货币资金主要来自重整投资款和捐赠，而非经营积累，一旦资金消耗完毕而主业未改善，公司将再次陷入流动性危机。此外，母公司未分配利润高达-5.78亿元，历史亏损包袱沉重，未来数年难以实现现金分红。

经营层面，非吡啶类产品库存量同比暴增175%，远超销量增速，暗示产品滞销或产能错配，存在大额存货跌价风险。公司对单一原材料供应商依赖度较高（前五大供应商采购额占66%），且核心子公司临港亚诺化工的高新技术企业税收优惠存在续期不确定性，若税率恢复至25%，将进一步侵蚀微薄利润。重整后的新控股股东能否有效整合资源、提升主业竞争力，仍是最大未知数。
