- **[产能释放+海外拓展]** -> [收入增长15.51%]: 国内7大生产设施满产，美国圣地亚哥新总部启用，海外收入占比提升至19.14%，驱动整体营收稳健增长。
- **[运营效率提升+费用管控]** -> [扣非净利润增长54.79%]: 收入增长叠加产能利用率提高，规模效应显现，管理费用、销售费用增速远低于收入增速，盈利能力显著改善。
- **[经营利润增长+资金周转健康]** -> [经营性现金流暴增151.37%]: 净利润提升的同时，运营资金管理能力增强，现金流质量大幅优化，财务稳健性夯实。
- **[国内创新药景气度回升]** -> [工业客户收入增长]: 国内创新药企管线进展加速，BD交易活跃，对高附加值人源化模型及药效测试需求旺盛，公司工业客户新增560余家。
- **[海外自建渠道成熟]** -> [海外收入增长33.41%]: 海外BD团队扩至40余人，美国、韩国、日本属地化布局落地，海外工业客户收入占比超75%，出海进入加速收获期。
- **[“斑点鼠”产品化+“药筛鼠”前瞻布局]** -> [商品化小鼠模型毛利率提升3.42个百分点]: 标准化品系库规模超22,000种，产品化模式降低定制成本，高附加值人源化品系占比提升，带动整体毛利率改善。
- **[功能药效服务能力完善]** -> [功能药效收入增长32.25%]: 依托丰富的人源化及疾病模型，搭建一站式临床前评价体系，满足创新药企对体内外药效、non-GLP毒理等服务的需求，业务协同效应显著。
- **[研发投入聚焦新一代模型]** -> [野化鼠、药筛鼠等前瞻项目持续推进]: 维持11.78%的高研发投入，野化鼠品系超120个，药筛鼠品系超800个，为中长期增长储备核心资产。

## 风险警告
**核心风险在于应收账款回收压力与行业竞争加剧。** 公司科研客户（高校、医院）应收账款余额增长明显，且账期较长，一年以上应收账款占比达20.93%，若客户预算收紧或审批流程延长，坏账风险将侵蚀利润。同时，国内模式动物市场参与者增多，基础品系价格承压，定制繁育业务收入已出现下滑，若公司无法持续推出高附加值创新模型以维持溢价，毛利率存在下行风险。

**技术迭代与海外经营的不确定性构成长期隐忧。** CRISPR/Cas9基因编辑技术虽已获授权，但专利保护期内的授权可持续性及未来更优技术的出现，均可能颠覆现有技术壁垒。此外，海外业务占比提升至近20%，面临地缘政治、贸易政策及汇率波动等多重宏观风险，美国设施产能爬坡若不及预期，将拖累整体盈利。
