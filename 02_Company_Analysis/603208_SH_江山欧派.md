# 603208.SH 深度透视

## 因果逻辑链
- **[行业需求萎缩与竞争加剧]** -> [营收与利润双杀]: 房地产下行导致市场需求萎缩，叠加行业“减量零和”竞争，公司2025年营业收入同比暴跌45.85%，归母净利润由盈转亏至-1.95亿元。
- **[直营工程业务收缩]** -> [营收规模大幅下降]: 公司主动控制欠款的直营工程业务，该渠道收入同比下滑63.19%，导致整体营收规模锐减。
- **[产品价格调整与固定成本刚性]** -> [毛利率全面下滑]: 为应对激烈竞争，公司下调部分产品售价，同时收入下降导致折旧、人工等固定费用无法同比例削减，夹板模压门等核心产品毛利率下降超10个百分点。
- **[计提大额资产减值]** -> [加剧亏损]: 报告期内，公司计提信用减值损失1.19亿元、资产减值损失（含固定资产）0.95亿元，合计超2.1亿元，是导致巨额亏损的直接财务原因。
- **[业务模式转型阵痛]** -> [现金流恶化]: 公司从欠款的直营工程业务转向现金流更好的代理经销和外贸业务，但转型期间收入锐减，导致经营活动现金流净额由正转负，为-0.66亿元。
- **[外贸出口高增长]** -> [结构性亮点]: 公司坚定“走出去”战略，外贸出口渠道收入同比增长62.47%，成为唯一实现正增长的主要渠道，但毛利率因竞争和成本因素下降15.54个百分点。
- **[加盟服务费模式]** -> [高毛利稳定器]: 加盟服务渠道收入同比增长18.51%，毛利率高达95.17%，贡献了1.46亿元的高毛利收入，成为公司利润的重要缓冲垫。

## 风险警告
**核心风险：行业下行周期中的“失血”困境。** 公司正经历从“直营工程”向“代理经销+外贸”的艰难转型，但转型期收入断崖式下滑（-45.85%），而固定成本（折旧、人工）和巨额资产减值（超2.1亿）导致公司陷入深度亏损。经营活动现金流净额首次转负（-0.66亿），表明公司已无法通过主营业务“造血”，财务健康度急剧恶化。若行业需求持续低迷，公司可能面临流动性危机。

**次要风险：转型成效不确定性与资产质量风险。** 尽管外贸和加盟服务业务增长亮眼，但体量尚小，无法弥补传统工程业务萎缩的缺口。同时，公司应收账款和合同资产账面余额高达176亿元，坏账准备超100亿元，资产质量承压。此外，公司可转债（江山转债）余额5.83亿元，若股价持续低迷，将面临较大的偿债或转股压力。
