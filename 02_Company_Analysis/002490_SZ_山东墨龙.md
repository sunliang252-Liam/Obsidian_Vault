# 002490.SZ 深度透视

## 因果逻辑链
- **[海外市场扩张]** -> [营收增长29.88%]: 海外营收同比增长49.11%，占比提升至34.70%，成为收入增长核心引擎。
- **[产能利用率提升]** -> [毛利率改善5.93个百分点]: 产销量同比大增45%，固定成本摊薄，管类产品毛利率提升至10.02%。
- **[非经常性损益驱动]** -> [净利润扭亏为盈]: 扣非净利润仍为-2762万元，依靠政府补助、资产处置等非经常性收益实现归母净利润515万元。
- **[成本管控与费用压缩]** -> [管理费用大幅下降66.49%]: 实施降本增效，严控费用支出，管理费用从1.19亿降至3986万元。
- **[被动财务资助收回]** -> [经营现金流暴增630%]: 收回寿光宝隆、华融农业等被动财务资助款项，经营活动现金流净额达3.2亿元。
- **[原材料价格波动]** -> [成本端承压]: 管坯等原材料占成本近80%，价格波动直接影响产品毛利率和盈利能力。
- **[研发投入加码]** -> [高端产品突破]: 研发费用增长59.3%，成功开发超级13Cr油管、超深井套管等高端产品，推动产品结构升级。

## 风险警告
**核心风险在于盈利质量极差，扣非净利润连续三年为负。** 2025年归母净利润515万元，但扣非净利润为-2762万元，盈利完全依赖政府补助（2060万）、资产处置（390万）等非经常性损益。公司主营业务造血能力依然薄弱，一旦非经常性收益不可持续，将重回亏损。

**第二大风险是巨额被动财务资助的回收不确定性。** 截至2025年末，公司对寿光宝隆的债权余额2.92亿元，且寿光宝隆已进入破产清算程序，回收前景堪忧；对华融农业的债权余额4.52亿元，虽已部分通过债务重组收回资产，但整体回收进度和最终损失仍存在重大不确定性。这两笔款项合计超7亿元，远超公司净资产（4.98亿），一旦发生大规模坏账，将直接击穿净资产。
