# 688656.SH 深度透视

## 因果逻辑链
- **[行业政策收紧与医保控费]** -> [营收微降0.98%]: 宏观市场环境及DRG/DIP支付改革导致终端需求收缩，叠加增值税简易征收转一般征收（影响约2.75%），共同压制收入增长。
- **[仪器大规模投放与折旧激增]** -> [毛利率骤降5.94个百分点]: 为抢占市场扩大仪器投放规模，叠加新大楼启用带来的折旧摊销与运行费用，成本端压力显著超过收入增速。
- **[新业务（欧脱克）培育期投入]** -> [净利润暴跌36.96%]: 脱敏药产品在海南、粤港澳大湾区尚处市场培育阶段，临床及注册费用持续增加，但经营效益释放滞后，严重侵蚀当期利润。
- **[股权激励费用减少]** -> [管理费用同比下降4.43%]: 通过团队人员结构调整及薪酬优化，部分抵消了新大楼折旧和脱敏药临床费用增加的影响。
- **[过敏/自免试剂收入双降]** -> [核心主业承压]: 过敏试剂收入降4.44%，自免试剂收入降5.47%，两大核心产品线均受宏观环境影响出现下滑，显示公司增长引擎动力不足。
- **[国外销售增长18.99%]** -> [海外市场成为亮点]: 积极开拓中东、欧洲等海外市场，国外销售毛利率同比提升6.63个百分点，为业绩提供结构性支撑。
- **[化学发光技术替代]** -> [长期竞争格局重塑]: 公司以化学发光自免产品替代进口酶联免疫法产品，虽短期成本承压，但符合行业定量化、全自动趋势，是未来进口替代的核心驱动力。
- **[中国生物制药赋能]** -> [探索协同增长潜力]: 依托控股股东资源，在产业协同、渠道共建等方面探索合作，为业务规模突破提供潜在增长契机。

## 风险警告
**核心风险在于业绩持续下滑与战略转型的“青黄不接”。** 2025年营收微降、净利润暴跌近37%，扣非净利润更是腰斩近59%，显示公司盈利能力正遭受行业政策、成本刚性增长和新业务投入的三重挤压。过敏和自免两大核心主业收入双降，而作为未来增长点的脱敏药（欧脱克）仍处于市场培育期，短期无法贡献利润，公司正面临“老业务失速、新业务未起”的尴尬局面。

**结构性风险来自成本失控与财务压力。** 仪器大规模投放和新大楼启用导致折旧与运行费用激增，直接拉低毛利率近6个百分点。同时，存货余额高达1.07亿元（占总资产11.5%），存在有效期管理不善导致的报废风险；应收账款回收风险亦不容忽视。此外，核心原材料依赖进口，面临地缘政治和汇率波动的双重威胁，供应链稳定性存疑。公司需警惕在行业下行周期中，成本刚性增长与收入增长乏力之间的剪刀差持续扩大。
