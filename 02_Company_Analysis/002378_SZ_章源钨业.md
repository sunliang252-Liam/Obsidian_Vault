# 002378.SZ 深度透视

## 因果逻辑链
- **[钨精矿价格大幅上涨]** -> [营收增长41.62%、净利润增长68.82%]: 钨精矿均价同比涨58.47%，公司自产钨精矿全部自用，直接增厚利润。
- **[钨原料供应偏紧]** -> [公司加大外购原料力度]: 自产钨精矿无法满足中下游产能，需大量外购，导致第四季度经营现金流为-3.05亿元。
- **[下游硬质合金需求增长]** -> [赣州澳克泰扭亏为盈]: 汽车、能源、航空航天等行业推动刀具及棒材销量增长，赣州澳克泰实现净利润1,742万元。
- **[钨粉产量行业第一]** -> [中游板块量价齐升]: 钨粉产量排名第一，碳化钨粉排名第二，受益于价格上涨和销量增长，粉末产品收入增长超50%。
- **[产业链一体化协同]** -> [抵御价格波动风险]: 从采矿到精深加工的全产业链布局，使公司能灵活调配资源，在原料涨价时仍保持毛利率稳定。
- **[出口管制政策影响]** -> [外销毛利率下降5.79个百分点]: 商务部2025年第10号公告对钨物项实施出口管制，外销订单交付周期延长，成本上涨快于售价。
- **[存货规模大幅增加]** -> [经营现金流与净利润背离]: 钨原料涨价及备货增加，存货从14.35亿增至26.88亿，导致经营现金流净额仅1.59亿，远低于净利润2.9亿。

## 风险警告
**核心风险：原料价格高位波动与现金流压力。** 钨精矿价格已处历史高位（2025年均价21.6万元/吨），若未来价格回落，公司高价囤积的存货将面临减值风险。同时，为锁定原料而大幅增加采购，导致经营现金流净额同比暴跌68.55%，且第四季度为-3.05亿元，显示公司运营资金高度紧张，依赖融资维持周转。

**次要风险：出口管制与地缘政治不确定性。** 2025年钨物项出口管制政策已导致外销毛利率显著下滑，且出口管制范围可能进一步扩大。公司海外收入占比14.21%，若国际贸易摩擦升级或管制趋严，将直接冲击出口业务。此外，公司钨资源储量（WO3 7.41万吨）有限，长期资源保障存在隐忧。
