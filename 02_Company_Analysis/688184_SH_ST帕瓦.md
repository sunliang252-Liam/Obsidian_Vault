# 688184.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [营收下降27.86%，毛利率为负]: 公司主动削减亏损订单，导致销量下滑，但固定成本（折旧）高企，无法被低产量分摊，造成主营业务亏损。
- **[单晶高电压技术领先]** -> [核心产品单晶NCM毛利率提升35.86个百分点]: 公司聚焦高附加值产品，主动放弃低毛利订单，使单晶产品毛利率从-41.2%大幅改善至-5.38%。
- **[前董事长张宝职务侵占与信披违规]** -> [公司被ST，审计报告为保留意见]: 张宝通过供应商占用资金、涉嫌职务侵占，导致公司财务数据需调整，内部控制存在重大缺陷，引发监管处罚和投资者信任危机。
- **[主动优化订单结构]** -> [营收下降但亏损幅度收窄19.58%]: 公司战略性放弃亏损严重的低毛利业务，虽牺牲规模，但使净利润亏损从-8.69亿收窄至-6.98亿。
- **[产能利用率不足与资产减值]** -> [固定资产与存货大幅减值]: 产销量下降导致产能闲置，公司对固定资产、存货等计提大额减值准备，是导致巨额亏损的主要原因之一。
- **[钠电业务爆发式增长]** -> [钠电前驱体销量同比增长超80%]: 公司前瞻性布局的钠电材料业务进入快速放量期，成为对冲锂电主业下滑的重要战略支点。
- **[终止募投项目]** -> [聚焦核心资源，减少资本开支]: 公司审慎决策终止“年产1.5万吨三元前驱体项目”，将剩余募集资金专户管理，以应对行业寒冬，保存现金流。

## 风险警告
公司当前最核心的风险是**治理崩塌与信任危机**。前董事长张宝因职务侵占被立案侦查，公司因信披违规被ST，审计报告为保留意见。这不仅是财务数据的失真，更意味着公司内部控制体系已实质性失效，管理层动荡、核心人员流失，未来可能面临更多未披露的或有负债或资金黑洞。投资者对公司治理的信任一旦丧失，估值修复将极为困难。

其次，**行业性亏损与现金流枯竭风险**。三元前驱体行业产能严重过剩，加工费持续走低，公司毛利率为负，经营活动现金流净额连续两年为负（-4.56亿）。公司净资产已从27.29亿缩水至10.55亿，若行业景气度无法快速回升，公司可能面临持续亏损导致净资产为负、甚至触发退市风险警示的极端情况。
