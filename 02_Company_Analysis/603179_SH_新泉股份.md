# 603179.SH 深度透视

## 因果逻辑链
- **[客户订单持续放量]** -> [营收增长17.04%]: 核心客户（吉利、奇瑞、理想等）车型热销，带动公司仪表板、门板等核心产品销量增长。
- **[行业竞争加剧与成本刚性上涨]** -> [净利润下降16.54%]: 收入增长未能覆盖直接人工（+48.52%）和制造费用（+49.25%）的快速膨胀，毛利率承压。
- **[海外基地规模化量产]** -> [北美/欧洲收入暴增]: 墨西哥、斯洛伐克工厂产能释放，北美收入增长216.57%，欧洲收入从极低基数暴增，成为新增长极。
- **[可转债转股与提前赎回]** -> [资本公积大增，财务费用下降]: 可转债大规模转股（+54.46%），同时赎回后利息费用减少，财务费用同比下降45.75%。
- **[收购安徽瑞琪]** -> [座椅业务成为新增长点]: 切入座椅总成赛道，该业务收入同比增长317.69%，但毛利率为负，尚处亏损爬坡期。
- **[设立机器人子公司]** -> [布局第二增长曲线]: 投资1亿元成立新泉机器人，旨在将汽车精密制造能力延伸至人形机器人核心零部件。
- **[客户集中度极高]** -> [经营风险高度集中]: 前五大客户销售额占比77.91%，单一客户依赖度极高，客户流失或减产将直接冲击业绩。

## 风险警告
**核心风险在于“增收不增利”与“客户集中度”的双重夹击。** 2025年营收增长17%，但净利润却下滑16.5%，主因是人工与制造费用增速远超收入，反映公司为抢占市场份额，在产能扩张期付出了高昂的运营成本。若行业价格战持续，公司毛利率有进一步被侵蚀的风险，盈利拐点尚不明确。

**客户集中度极高是悬顶之剑。** 前五大客户贡献近八成营收，其中单一客户占比近30%。公司深度绑定吉利、奇瑞、理想等自主品牌，一旦核心客户销量波动或切换供应商，将对公司业绩造成毁灭性打击。此外，海外业务（北美、欧洲）虽增长迅猛，但面临地缘政治、关税政策及跨文化管理的巨大不确定性，海外工厂的盈利稳定性远低于国内。
