# 600925.SH 深度透视

## 因果逻辑链
- **[煤炭价格深度下行]** -> [归母净利润暴跌83.74%]: 商品煤销售均价大幅下降，导致煤炭业务毛利同比减少13.45亿元，是业绩下滑的核心原因。
- **[终止确认部分递延所得税资产]** -> [净利润进一步承压]: 因对未来盈利预期转弱，公司转回部分前期确认的递延所得税资产，加剧了净利润的下降幅度。
- **[存量有息负债规模扩大]** -> [财务费用激增43.98%]: 为支撑乌拉盖、白音华等大型电源点项目建设，公司融资余额上升，导致利息支出大幅增加。
- **[煤电一体化项目投产]** -> [电力业务毛利逆势增长55.34%]: 乌拉盖2×1000MW机组投产，叠加燃料成本下降，使电力板块成为业绩主要缓冲垫。
- **[新能源装机快速扩张]** -> [新能源发电量同比增长186.44%]: “风光网储”项目集中并网，新能源业务收入增长83.66%，成为公司转型增长极。
- **[百贯沟煤业改扩建获批]** -> [煤炭资源接续能力增强]: 产能由60万吨/年扩建至120万吨/年，为未来煤炭主业稳产增产奠定基础。
- **[在建工程转固]** -> [固定资产大幅增加40.61%]: 乌拉盖项目投产导致在建工程减少47.82%，固定资产增加，折旧压力随之上升。

## 风险警告
公司面临的核心风险是**盈利能力的剧烈波动与高资本开支带来的财务压力**。2025年归母净利润暴跌83.74%，主要源于煤炭价格下行这一外生变量，而公司对此的议价能力有限。同时，为推进“蒙电送苏”等大型项目，公司有息负债规模大幅攀升，导致财务费用激增，侵蚀了本就脆弱的利润。这种“增收不增利”甚至“量增利减”的局面，在煤价低迷周期内可能持续。

其次，**资产减值与递延所得税资产转回的风险不容忽视**。公司已因对未来盈利预期悲观而主动转回部分递延所得税资产，这直接减少了当期净利润。若煤价持续低位运行，公司可能需要对煤矿相关长期资产进行减值测试，这将进一步冲击资产负债表和利润表。尽管公司正大力发展新能源以对冲风险，但新能源业务体量尚小，短期内难以完全弥补煤炭主业的下滑。
