# 300852.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [通信设备领域营收快速增长]: 公司凭借80层以上高多层板、1.6T光模块PCB等量产能力，深度切入AI服务器与光模块产业链，成为拉动整体业绩增长的核心引擎。
- **[原材料价格大幅上涨]** -> [净利润同比下降8.67%]: 覆铜板、铜箔、金盐等关键材料采购价格同比大幅攀升，导致原材料成本显著增加，影响净利润率下降2.38个百分点。
- **[泰国工厂产能爬坡]** -> [阶段性经营亏损]: 一品电路2024年下半年投产，初期固定成本高、产能利用率不足，产生亏损，对合并报表净利润产生一定影响。
- **[深耕工控与汽车电子头部客户]** -> [营收稳健增长]: 与日立、松下、欧姆龙、安川电机等全球头部企业长期稳定合作，持续扩大采购份额，为业绩提供基本盘。
- **[PCBA业务高速增长]** -> [一站式服务增强客户黏性]: PCBA营收同比增长约167%，通过覆盖设计、制造、贴装的全流程服务，提升在客户供应链中的渗透率。
- **[可转债转股与回购注销]** -> [总股本与净资产变动]: 报告期内“富仕转债”大量转股增加股本，同时公司注销回购股份，导致总股本增至1.6亿股，净资产同比增长39.77%。
- **[资产减值损失增加]** -> [侵蚀利润]: 本期计提的存货跌价准备等资产减值损失增加，影响净利润率下降0.74个百分点。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长36.69%，但净利润却下滑8.67%，主因是上游原材料（铜、金等）价格暴涨无法完全向下游传导，叠加泰国工厂产能爬坡期的固定成本摊销。若贵金属价格维持高位或继续上涨，公司毛利率与净利率将面临进一步压缩，盈利能力改善存在较大不确定性。

**产能扩张与需求匹配的风险不容忽视。** 公司正推进六期项目（年产80万平方米电路板）及泰国工厂产能爬坡，资本开支巨大。若AI服务器、光模块等新兴领域需求增速放缓，或客户认证进度不及预期，新增产能将面临消化压力，可能导致产能利用率不足、资产减值损失扩大，对现金流和盈利造成双重冲击。
