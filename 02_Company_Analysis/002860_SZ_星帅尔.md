# 002860.SZ 深度透视

## 因果逻辑链
- **[光伏业务量价齐升]** -> [净利润增长38.86%]: 光伏组件销售量同比增38.38%，叠加行业价格回暖，带动营收与毛利率双升，是利润增长主引擎。
- **[可转债利息消除]** -> [财务费用下降70.96%]: 2025年“星帅转2”完成赎回摘牌，不再计提大额可转债利息，直接增厚净利润。
- **[家电业务结构优化]** -> [毛利率提升3.62%]: 尽管家电收入下滑6.4%，但通过产品升级与成本控制，毛利率逆势提升，稳固了利润基本盘。
- **[原材料成本控制]** -> [营业成本增速低于营收]: 光伏原材料成本增速(10.71%)低于收入增速(12.26%)，家电原材料成本下降12.75%，有效对冲了价格竞争。
- **[客户集中度高]** -> [经营风险集中]: 前五大客户销售额占比68.50%，其中单一客户占比高达45.93%，对核心客户依赖度极高。
- **[募投项目终止]** -> [资金效率提升]: 终止“年产2GW光伏组件项目”，将节余资金2.34亿元永久补充流动资金，避免了低效投资，优化了资本结构。
- **[子公司全资化]** -> [协同效应增强]: 收购富乐新能源剩余9.8%股权实现100%控股，强化了对核心光伏资产的控制与整合。
- **[研发投入持续]** -> [技术壁垒巩固]: 研发费用增长10.6%，聚焦800W+大功率组件、高效电机等，为未来产品差异化竞争奠定基础。

## 风险警告
**核心风险在于光伏业务的“增收不增利”与客户过度集中。** 光伏收入占比已超50%，但毛利率仅6.32%，远低于家电业务的32.72%。行业产能过剩、价格战持续的背景下，光伏业务对利润的贡献极其脆弱。同时，公司对单一光伏客户依赖度高达45.93%，一旦该客户订单或价格出现波动，将对整体业绩造成毁灭性打击。

**第二重风险是战略摇摆与转型阵痛。** 公司已终止核心募投的光伏扩产项目，表明对行业前景的预判出现偏差。同时，家电业务收入下滑6.4%，增长乏力。公司正处于“家电见顶、光伏承压”的尴尬期，新业务（如军工电机、光通信组件）尚在培育，短期内难以形成有效利润支撑，存在青黄不接的风险。
