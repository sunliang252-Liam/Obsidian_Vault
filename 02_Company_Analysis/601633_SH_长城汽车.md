# 601633.SH 深度透视

## 因果逻辑链
- **[海外销量创新高]** -> [营收增长10.20%]: 海外销量50.68万辆（+11.60%），带动整车销售收入增长11.60%，是营收增长的核心引擎。
- **[直营渠道与品牌投入激增]** -> [净利润下降22.07%]: 销售费用暴增43.93%至112.73亿元，远超营收增速，直接侵蚀利润，导致“增收不增利”。
- **[新能源转型加速]** -> [新能源车销量增长26%]: 新能源车销量40.60万辆，渗透率提升，但新能源车业务尚处投入期，对短期盈利贡献有限。
- **[汇兑收益增加]** -> [财务费用大幅转负]: 财务费用从+0.99亿转为-19.70亿，主要系海外业务扩张带来的汇兑收益，对利润形成正向对冲。
- **[高附加值车型放量]** -> [品牌向上与结构优化]: 坦克品牌（+54.58%新能源渗透率）、魏牌（+79.36%）等高单价车型销量增长，支撑了营收增长，但未能完全覆盖销售费用增幅。
- **[生态出海深化]** -> [海外资产与经营杠杆提升]: 巴西工厂投产，海外资产占比达23.70%，海外收入占比提升至41.5%，但地缘政治与贸易壁垒风险随之加大。
- **[研发投入持续高企]** -> [技术护城河加深]: 研发费用104.32亿元（+12.13%），推出归元平台、VLA大模型等，为长期竞争力奠基，但短期压制利润。

## 风险警告
**核心风险：利润被销售费用吞噬，增长质量存疑。** 公司2025年营收增长10.2%，但净利润却下滑22.07%，核心原因是销售费用同比暴增43.93%至112.73亿元。公司解释为“加速构建直连用户的新渠道模式，以及加大新车型、新技术的上市宣传及品牌提升”。这表明在极度内卷的国内汽车市场，长城汽车为维持销量增长和品牌声量，不得不付出高昂的渠道和营销成本。若该趋势持续，公司盈利能力将面临持续压力，需警惕“增收不增利”成为常态。

**次要风险：海外市场不确定性加剧。** 公司海外销量占比已超38%，且巴西工厂等海外资产持续扩张，海外收入占比达41.5%。年报明确提示“国际地缘冲突、贸易壁垒增多”的风险。随着全球贸易保护主义抬头，以及部分市场对中国电动车加征关税，公司海外业务的增长和利润率可能受到冲击。过度依赖海外市场对冲国内竞争，一旦海外市场遇阻，将对公司整体业绩造成双重打击。
