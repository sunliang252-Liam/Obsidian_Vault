# 300691.SZ 深度透视

## 因果逻辑链
- **[战略性研发与市场投入激增]** -> [净利润暴跌76%]: 研发、销售、管理费用分别同比增长27%+，远超营收7%的增速，直接侵蚀利润。
- **[剥离非核心亏损业务]** -> [资产处置收益暴增]: 出售毫米波雷达、机器人等非核心资产，产生约2942万元非经常性收益，掩盖了主业扣非亏损4669万元的真相。
- **[安全监控海外扩张]** -> [主业产品收入下滑6.6%]: 国内安防市场增速放缓，公司被迫转向海外，海外收入占比提升40%，但未能扭转主业产品整体收入下滑趋势。
- **[智能驾驶业务爆发]** -> [创新产品收入增长16.4%]: 车载镜头业务同比增长超100%，成为营收增长的核心引擎，但毛利率仅17.7%，低于主业产品。
- **[AR/VR光机技术突破]** -> [新业务培育期亏损]: AR光机实现小批量出货，但研发投入巨大，尚未形成规模利润，是战略性亏损的主要来源之一。
- **[收购长益光电]** -> [产业链协同预期]: 拟通过收购切入泛安防消费级市场，完善“变焦+定焦”产品矩阵，但整合风险与商誉减值风险并存。
- **[经营现金流大幅改善]** -> [利润含金量低]: 经营活动现金流净额1.21亿元，同比暴增674%，主要系延迟付款和加速回款，与净利润严重背离，盈利质量堪忧。

## 风险警告
**核心风险：盈利能力的“虚假繁荣”与“失血”并存。** 公司2025年净利润926万元，但扣非净利润为-4691万元，连续两年为负。利润主要依赖出售非核心资产的一次性收益（2942万元）和政府补助（786万元）。这表明公司主营业务（安防镜头）已陷入亏损，而智能驾驶和AR等新业务尚处于“烧钱”培育期，未能贡献正向利润。一旦资产处置收益不可持续，公司将暴露真实的亏损底牌。

**战略风险：多元化扩张的“后遗症”与“赌注”。** 公司同时押注安防、车载、AR/VR、投影等多个赛道，导致研发费用率高达13.48%，远超同行。这种“广撒网”策略虽带来技术储备，但也造成资源分散和管理成本失控。对毫米波雷达和机器人业务的剥离，是承认前期战略失误的“止损”行为。而收购长益光电的整合能否成功，以及AR光机能否从“样品”走向“爆款”，是决定公司未来能否走出泥潭的关键，但不确定性极高。
