# 002912.SZ 深度透视

## 因果逻辑链
- **[海外市场扩张]** -> [营收增长14.03%]: 海外业务收入同比大增68.88%，占总营收比例从26%跃升至38.55%，成为核心增长引擎。
- **[AI大模型赋能产品]** -> [网络内容安全产品收入暴增52.46%]: 将AI能力深度集成至内容安全、反诈、情报分析等产品，实现从规则匹配到智能研判的范式转移，驱动高毛利产品放量。
- **[收入结构变化]** -> [毛利率承压]: 高毛利的宽带网产品收入下降13.23%，而毛利率较低的“其他”类产品收入增长51.44%，导致整体营业成本增速(31.09%)显著高于营收增速。
- **[高研发投入]** -> [技术壁垒构建]: 研发投入占营收31.68%，研发人员占比53.13%，持续巩固在数据提取、AI融合分析等领域的领先地位，支撑产品迭代。
- **[政府与运营商客户]** -> [业绩季节性波动]: 客户预算与采购制度导致下半年收入占比高达69.91%，第四季度单季贡献45.02%的营收，经营现金流与利润季度间波动剧烈。
- **[非经常性损益]** -> [净利润“注水”]: 扣非净利润同比下降8.52%，而归母净利润增长15.83%，主要依赖政府补助同比大增146.64%及债务重组收益，盈利质量存疑。
- **[项目备货增加]** -> [经营现金流恶化]: 尽管销售回款增加，但项目备货导致购买商品支付现金大幅增加，经营活动现金流净额同比下降21.84%，与利润增长背离。

## 风险警告
**核心风险在于盈利质量与增长可持续性。** 公司扣非净利润已连续两年下滑（2025年同比-8.52%），而净利润增长完全依赖政府补助等非经常性损益。海外业务虽爆发式增长，但面临地缘政治、汇率波动及国际巨头直接竞争，高增长能否持续存疑。同时，研发投入资本化率为零，全部费用化处理，若未来营收增速放缓，高额研发费用将直接侵蚀利润。

**结构性风险不容忽视。** 宽带网产品作为传统基本盘，收入同比下降13.23%，显示核心业务面临增长瓶颈。公司向政企网、数据运营等新领域拓展，但数据运营产品收入同比下滑26.02%，新业务尚未形成有效支撑。此外，应收账款坏账准备计提增加44.32%，存货跌价准备持续计提，资产质量风险需警惕。
