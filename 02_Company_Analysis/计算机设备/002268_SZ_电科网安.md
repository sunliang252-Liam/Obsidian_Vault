# 002268.SZ 深度透视

## 因果逻辑链
- **[新签合同集中在Q3/Q4]** -> [营收下降8.08%]: 下半年签订的大量合同未能在年内完成验收，导致收入确认延迟，全年营收同比下滑。
- **[密码业务收入骤降27.19%]** -> [整体利润暴跌63.55%]: 作为核心高毛利业务，密码板块收入大幅萎缩，直接拖累公司整体盈利水平。
- **[网络安全业务收入增长26.18%]** -> [营收结构失衡]: 低毛利的网络安全业务占比提升，拉低了综合毛利率，侵蚀了利润空间。
- **[研发人员减少28.77%]** -> [研发费用下降10.10%]: 公司主动优化人员结构，聚焦核心密码技术，但研发投入的缩减可能影响长期技术储备。
- **[经营活动现金流净额大幅转正]** -> [经营质量改善]: 回款增加、付款减少，现金流从-4.7亿跃升至+3.14亿，表明公司加强了应收账款管理。
- **[北京房产涉诉终审胜诉]** -> [资产风险缓释]: 北京市高院终审判决解除查封，扫清了资产确权的最大法律障碍，但后续破产和解仍存不确定性。
- **[关联交易占比高]** -> [业绩独立性存疑]: 前五大客户中关联方销售额占比21.64%，公司业绩对集团内依赖度较高，市场化竞争能力待验证。

## 风险警告
**核心风险在于“增收不增利”的结构性恶化。** 公司营收仅下降8%，但净利润暴跌63.55%，扣非净利润更是下滑67.64%。根本原因是高毛利的密码业务（毛利率53%）收入锐减，而低毛利的网络安全业务（毛利率24%）收入大增，导致整体毛利率下降。这种业务结构的被动调整，反映出公司在核心密码市场的竞争力可能正在减弱，或面临激烈的价格战。

**另一个重大风险是北京房产的破产和解僵局。** 尽管2025年10月公司已获得高院终审胜诉，解除了房产查封，但开发商金丰科华仍处于破产程序，和解方案迟迟未能提交债权人会议表决。该房产账面原值高达11.63亿元，已计提减值6787万元，若最终和解失败，公司可能面临巨额资产减值损失，对利润表造成严重冲击。审计报告因此出具了带强调事项段的无保留意见，这是投资者必须警惕的“灰犀牛”。
