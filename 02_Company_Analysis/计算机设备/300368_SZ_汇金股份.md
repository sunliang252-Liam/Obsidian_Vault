# 300368.SZ 深度透视

## 因果逻辑链
- **[下游需求萎缩与竞争加剧]** -> [金融机具业务收入与毛利率双降]: 移动支付普及导致现金处理需求减少，叠加行业同质化竞争，公司核心产品量价承压。
- **[计提大额资产减值]** -> [净利润大幅亏损]: 报告期对应收账款、存货、商誉计提减值合计1.09亿元，直接侵蚀利润，是亏损主因。
- **[联营企业投资亏损]** -> [投资收益同比下降]: 被投资企业经营未达预期，权益法核算下确认投资损失，进一步拖累业绩。
- **[子公司汇金天源深度亏损]** -> [合并报表业绩恶化]: 核心子公司汇金天源净利润-7,724万元，是集团亏损的最大来源，反映数据中心业务整合失败。
- **[引入战略投资者中信金资]** -> [优化资本结构与补充现金流]: 子公司增资扩股获得2.38亿元资金，用于偿还存量有息负债，缓解短期流动性压力。
- **[撤销ST风险警示]** -> [公司治理与内控改善]: 完成内控整改，股票摘帽，恢复市场正常交易地位，为后续融资与重组扫清障碍。
- **[筹划收购库珀新能源]** -> [寻求第二增长曲线]: 拟通过现金收购+表决权委托方式控股新能源公司，试图摆脱对传统金融机具业务的依赖。

## 风险警告
**核心风险在于主业萎缩与资产质量恶化形成的负向螺旋。** 公司传统金融机具业务受移动支付不可逆冲击，收入持续下滑，而新业务（如信息化解决方案）体量小、毛利率极低（2.88%），无法弥补缺口。更严重的是，应收账款高达2.23亿元，子公司汇金天源净资产已为-1.51亿元，资不抵债，叠加连续三年巨额亏损，公司净资产已从2023年末的3.55亿元骤降至0.57亿元，濒临资不抵债边缘。

**重组与转型存在高度不确定性。** 公司计划收购库珀新能源以跨界转型，但该交易尚处于筹划阶段，存在审批、整合及业绩不达预期的重大风险。同时，公司未分配利润亏损高达-7.24亿元，意味着未来数年无法现金分红，对股东回报能力构成根本性制约。尽管引入中信金资暂时缓解了资金压力，但若新业务无法快速贡献利润，公司持续经营能力将面临严峻考验。
