## 因果逻辑链
- **[煤炭价格周期性下行]** -> [煤矿业务收入下降27.21%]: 下游客户盈利能力缩减，推迟智能化资本开支，导致公司核心煤矿产品收入从4.05亿降至2.95亿。
- **[非煤矿山政策驱动与市场拓展]** -> [非煤矿山业务收入增长95.43%]: 公司积极布局非煤矿山市场，受益于政策强制要求，该业务收入从0.59亿跃升至1.15亿，部分对冲了煤矿业务下滑。
- **[下游客户回款周期长]** -> [信用减值损失达1306万元]: 公司主要客户为大型国企，话语权较弱，应收账款余额高达4.72亿元，导致计提大额坏账准备，侵蚀利润。
- **[研发投入持续加大]** -> [研发费用增长18.99%]: 公司为保持技术领先，研发投入增至4882万元，占营收11.21%，重点投向SPG大模型、矿用机器人等前沿领域。
- **[经营性现金流大幅缩减]** -> [经营活动现金流净额下降44.77%]: 销售收入减少导致销售商品收到的现金大幅减少，现金流状况恶化，与净利润的差距扩大。
- **[财务费用显著降低]** -> [财务费用下降49.76%]: 公司陆续归还银行借款，利息费用大幅减少，对利润形成正向贡献。
- **[股权激励归属]** -> [总股本增加与核心团队绑定]: 报告期内完成多批次限制性股票归属，增加股本约332万股，同时激励了核心管理层与技术人员。

## 风险警告
公司面临的核心风险是**下游煤炭行业周期性波动带来的业绩不确定性**。2025年因煤价下行，煤矿客户推迟资本开支，导致公司核心业务收入锐减27%，净利润下滑27%。若煤炭价格持续低迷或行业景气度下行，公司业绩存在进一步下滑的风险。公司虽积极拓展非煤矿山业务，但该业务毛利率（32.78%）显著低于煤矿业务（42.52%），业务结构变化可能拉低整体盈利水平。

另一重大风险是**高企的应收账款带来的坏账风险**。公司应收账款账面价值高达4亿元，占总资产近30%，且客户多为大型国企，公司议价能力弱，回款周期长。报告期内已计提1306万元信用减值损失，且公司曾因应收账款坏账计提不准确被证监局出具监管措施。若宏观经济波动或客户信用恶化，公司将面临较大的坏账损失和现金流压力。
