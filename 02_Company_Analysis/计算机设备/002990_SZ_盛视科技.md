# 002990.SZ 深度透视

## 因果逻辑链
- **[智慧口岸业务增长]** -> [营收增长18.26%]: 智慧口岸查验系统解决方案收入同比增长25.11%，是营收增长的核心驱动力。
- **[大额信用减值损失]** -> [净利润暴跌51.22%]: 计提应收账款坏账准备1.69亿元，直接吞噬利润，是净利润腰斩的主因。
- **[新业务拓展与研发投入]** -> [毛利率下降5.27个百分点]: 拓展战略性新业务及加大机器人研发投入（研发费用增25.06%），导致主营业务毛利率下滑。
- **[股权激励费用激增]** -> [管理费用大幅增长42.52%]: 实施2024年限制性股票激励计划，确认股份支付费用3931万元，同比大增，侵蚀利润。
- **[海外市场突破]** -> [海外收入增长81.59%]: 海外口岸、交通、机场多板块业务取得突破，成为新的增长极。
- **[NAO机器人资产收购]** -> [布局人形机器人新赛道]: 成功竞购法国NAO机器人资产，加速人形机器人产业布局，但短期带来整合与投入压力。
- **[政府及国企客户]** -> [应收账款高企但回款风险较小]: 客户信用度高，但结算周期长导致应收款项余额高企，计提减值风险是常态。

## 风险警告
**核心风险在于利润端的急剧恶化与资产质量的隐忧。** 公司营收增长18.26%，但净利润却暴跌51.22%，剪刀差巨大。直接原因是高达1.69亿元的信用减值损失，这暴露出公司以政府、国企为主要客户的项目制业务模式下，回款周期长、坏账计提压力大的固有顽疾。若未来宏观经济或地方财政承压，应收账款的回收风险将进一步放大，持续侵蚀公司利润。

**新业务投入与旧业务盈利下滑的双重挤压是另一大风险。** 公司为拓展机器人等新业务，研发费用和股权激励费用大幅增加，而传统智慧口岸业务的毛利率却在下降。这种“增收不增利”的局面若无法通过新业务的规模化盈利来扭转，公司业绩将面临持续下滑的风险。同时，海外业务虽增长迅速，但国际政治经济环境复杂多变，地缘政治风险可能对海外项目的拓展和交付构成不确定性。
