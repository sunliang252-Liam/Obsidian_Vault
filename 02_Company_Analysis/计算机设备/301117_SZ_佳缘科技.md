# 301117.SZ 深度透视

## 因果逻辑链
- **[军工产品调价与市场周期]** -> [军工业务收入骤降44.74%，毛利率暴跌14.22%]: 产品调价追溯调整收入、定价普遍降低、叠加“十四五”收官期新需求释放延迟，导致核心利润来源大幅萎缩。
- **[政企AI业务爆发]** -> [政企业务收入暴增992.20%，成为最大收入来源]: 企业AI相关IT需求快速增长，公司向AI业务转型成功，弥补了军工和医疗业务的巨大缺口。
- **[医疗IT预算缩减与转型阵痛]** -> [医疗业务收入下降59.06%，毛利率降至7.59%]: 医保控费导致医院项目预算缩减、招标推迟，同时传统医疗信息化向AI医疗转型初期，新产品收入贡献有限。
- **[产品调价追溯调整]** -> [直接调减当期营业收入及净利润2,582.19万元]: 会计政策对已确认收入进行调减，是导致当期亏损的直接财务原因之一。
- **[应收账款信用减值]** -> [信用减值损失达1,110.64万元，占利润总额20.42%]: 主要客户为政府、军工单位，付款周期长，坏账计提侵蚀利润。
- **[AI算力中心建成]** -> [形成“算力+模型+应用”全栈AI能力]: 2025年初建成AI算力中心，完成大模型本地化部署，为政企AI业务爆发提供技术底座，是业务转型的关键基础设施。
- **[研发投入高企但未资本化]** -> [研发费用占营收19.49%，全部费用化]: 持续高强度的研发投入（6,234.78万元）是保持技术竞争力的必要支出，但全部费用化直接加剧了当期亏损。

## 风险警告
公司正经历痛苦的业务转型期，核心军工业务因产品调价和市场周期陷入深度衰退，毛利率腰斩，而新崛起的政企AI业务虽然增速惊人，但毛利率仅13.42%，盈利能力远不及军工业务。这种“以低毛利业务替代高毛利业务”的结构性变化，叠加医疗业务的大幅萎缩，导致公司整体陷入亏损。转型能否成功，取决于AI业务能否快速提升毛利率并实现规模化盈利，以及军工业务能否在“十五五”开局后迎来需求复苏。

财务风险不容忽视。应收账款高达3.51亿元，占总资产22.70%，且信用减值损失已超千万，回款压力巨大。同时，公司存货高达4.24亿元，占总资产27.44%，存在跌价风险。在营收下滑、持续亏损的背景下，高额的应收账款和存货占用了大量资金，对现金流构成严峻考验，尽管经营活动现金流净额有所改善，但仍为负值。
