## 因果逻辑链
- **[出售利盟（Lexmark）]** -> [营收与净利润大幅下滑]: 2025年7月完成利盟股权出售，导致合并报表范围缩小，营收同比下降37.48%，归母净利润由盈转亏至-7.18亿元。
- **[信创政策调整]** -> [奔图打印机销量短期承压]: 2025年7月新版安全可靠测评指南将主控芯片纳入测评，导致奔图信创打印机下半年销量同比下降74%，全年销量下滑17%。
- **[国产替代与自主可控]** -> [奔图国内商用市场逆势增长]: 在中国激光打印机市场整体下滑5%的背景下，奔图凭借全栈自研能力，国内商用市场销量同比增长2.72%，市占率提升。
- **[极海微聚焦“主控+驱动+传感”]** -> [非打印耗材芯片业务稳健增长]: 极海微在机器人、数字能源、汽车电子等核心赛道取得突破，非打印耗材芯片业务营收同比增长5.41%，对冲了打印芯片下滑的影响。
- **[人形机器人芯片布局]** -> [打开未来增长空间]: 极海微推出全球首款基于Arm Cortex-M52的实时控制DSP等产品，已向宇树科技、汇川技术等头部企业批量出货，单台人形机器人可用约100颗芯片。
- **[数字能源与汽车电子突破]** -> [形成新的业绩增长点]: 极海微G32R501 DSP芯片切入AI服务器电源、充电桩等场景，并与特来电战略合作；车规级芯片AK2成功定点一汽、东风等主流车企。
- **[通用耗材市场竞争激烈]** -> [盈利能力持续承压]: 通用耗材行业价格战频发，公司该业务净利润为-0.24亿元，同比下降131.91%，拖累整体业绩。
- **[公司战略升级为“打印科技为核心的多元科技产业”]** -> [品牌与业务边界重塑]: 公司拟更名为“奔图科技”，从垂直打印企业向具备平台化能力的科技公司跨越，探索具身智能、3D打印等新业务。

## 风险警告
**核心风险在于利盟出售后的业绩真空与转型阵痛。** 公司2025年营收与利润的大幅下滑直接源于利盟业务的剥离，短期内难以找到同等体量的业务填补缺口。尽管奔图与极海微在国产替代和新兴领域展现增长潜力，但其体量尚小，无法完全对冲利盟退出带来的影响。公司当前处于“旧引擎熄火，新引擎待燃”的关键过渡期，业绩波动性显著加大。

**信创政策的不确定性与通用耗材的激烈竞争构成双重压力。** 奔图信创业务受政策节奏影响极大，2025年下半年的销量骤降表明其业绩高度依赖政策驱动，稳定性不足。同时，通用耗材作为公司的传统现金牛业务，正陷入持续的价格战泥潭，盈利能力持续恶化，可能进一步侵蚀公司利润。投资者需警惕公司在新旧动能转换期间，业绩持续低于预期的风险。
