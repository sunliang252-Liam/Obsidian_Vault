# 002626.SZ 深度透视

## 因果逻辑链
- **[辅酶Q10全球龙头地位+技改扩产]** -> [成本下降、产销量增长]: 年产920吨改扩建项目完成，巩固全球最大生产商地位，通过技术迭代降低生产成本，提升市场竞争力。
- **[维生素A工厂恢复生产]** -> [维生素A系列营收增长21.64%]: 2024年因安全事故停产导致低基数，2025年恢复正常运行，产销量和均价同比回升。
- **[DHA/ARA等食品原料产销两旺]** -> [食品原料销量增长54.15%]: 配方改进与工艺优化提升品质和生产效率，成本下降推动整体产销势头提升。
- **[美国保健食品成品子公司VitaBest扭亏]** -> [经营基本面企稳向好]: 通过供应链、生产流程、工艺技术及订单管理全方位优化，顺利走出亏损困境。
- **[计提大额资产减值]** -> [净利润同比下降0.61%]: 报告期计提商誉、无形资产及存货减值1.38亿元，严重侵蚀利润，导致营收增长但净利润微降。
- **[境外销售占比76.23%+美元存款增加]** -> [财务费用大幅增加269.52%]: 汇兑损益变动导致财务费用从-1.87亿转为0.32亿，显著影响盈利水平。
- **[发行可转换公司债券]** -> [总资产增长20.68%]: 成功发行12.92亿元可转债，大幅扩充资本实力，为万吨油脂项目等新产能建设提供资金。

## 风险警告
**核心风险在于资产减值与汇率波动的双重挤压。** 公司2025年净利润几乎零增长，完全被高达1.38亿元的资产减值（商誉、存货、无形资产）所吞噬，暴露出前期并购整合效果不佳及部分产品（如阿洛酮糖、肌醇）市场供需恶化的问题。同时，境外销售占比超76%，美元资产庞大，人民币汇率波动导致财务费用剧烈反转，对利润的扰动具有高度不确定性。

**成长性面临新旧动能转换的阵痛。** 核心利润来源辅酶Q10虽保持龙头地位，但营收已现下滑（-4.51%），增长更多依赖维生素A的恢复性增长和DHA等新品的放量。然而，万吨油脂、阿洛酮糖等重大在建项目尚处投入期，短期内无法贡献利润，且阿洛酮糖项目已因市场变化面临变更风险。在行业竞争加剧、贸易环境逆全球化的背景下，公司能否顺利实现从“原料霸主”到“品牌+原料”双轮驱动的转型，存在较大不确定性。
