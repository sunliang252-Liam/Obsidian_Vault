# 000089.SZ 深度透视

## 因果逻辑链
- **[国际及地区旅客量高增]** -> [非航收入增长]: 国际旅客量同比+22.4%，带动免税、商业租赁等非航业务收入提升。
- **[货邮吞吐量突破百万吨]** -> [物流收入高增]: 国际及地区货邮量首次突破百万吨，物流收入同比+37.04%，成为营收增长核心引擎。
- **[三跑道投产运行]** -> [产能瓶颈突破]: 高峰小时容量达65架次，航班起降架次创新高，为客货运量增长提供物理基础。
- **[航线网络持续加密]** -> [旅客吞吐量增长]: 新开14条国际客运航线，国际及地区航点达61个，直接拉动旅客量同比+8.1%。
- **[跨境电商业务扩张]** -> [货运业务结构优化]: 新增3家头部电商平台，跨境电商业务量达35.4万吨，推动货运向高附加值转型。
- **[广告经营模式调整]** -> [广告收入短期承压]: 将固定费用模式改为“保底+超额分成”，导致广告收入同比-4.62%，但长期利于风险共担。
- **[人工成本刚性增长]** -> [成本端压力持续]: 人工成本同比+12.15%，占总成本41.21%，是营业成本增长的主要来源。

## 风险警告
**核心风险在于高资本开支与债务负担。** 公司资产负债率达52.8%，长期借款及租赁负债合计超100亿元，财务费用高达3.28亿元，侵蚀利润。三跑道投产后，折旧与运维成本将持续攀升，若客货运量增速放缓，盈利弹性将显著承压。

**运营风险集中于国际航线的不确定性。** 国际及地区旅客量虽高增，但地缘政治风险、国际油价波动及免签政策效果存在变数。若国际航线恢复不及预期，将直接拖累航空性收入及免税、商业等非航业务，公司业绩增长将失去重要支撑。
