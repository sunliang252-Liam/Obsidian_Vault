# 002478.SZ 深度透视

## 因果逻辑链
- **[产品结构升级]** -> [营收增长3.45%但净利润下降23.96%]: 公司主动调整产品结构，增加研发投入（+11%），同时外汇汇率波动导致财务费用大幅增加（-48.38%），侵蚀利润。
- **[外汇套保与汇率波动]** -> [公允价值变动损失1916万元]: 公司为规避汇率风险进行掉期业务，但人民币汇率波动导致衍生品公允价值大幅下降，直接拖累当期利润。
- **[特材项目投产]** -> [高端化转型基础奠定]: 热挤压线等全面进入调试试生产，成功产出高端不锈钢、耐蚀合金管材，为进入海洋工程、半导体等高附加值领域打开通道。
- **[锅炉管需求景气]** -> [锅炉管营收增长5.39%，产销创新高]: 火电保供及清洁化转型推动高性能锅炉管需求，公司作为三大锅炉厂核心供应商，充分受益。
- **[外销收入下降]** -> [营收结构向内销倾斜]: 受贸易保护主义和地缘政治影响，外销收入同比下降19.98%，公司主动调整市场策略，内销收入增长13.08%予以对冲。
- **[原材料价格波动]** -> [毛利率承压]: 营业成本增速（4.15%）略高于营收增速（3.45%），导致整体毛利率下降0.57个百分点，成本控制压力持续存在。
- **[研发投入持续增加]** -> [技术壁垒与新品储备]: 研发费用同比增长11%，聚焦万米深井C110新材料、新能源汽车精密管等，支撑未来高端市场拓展。

## 风险警告
**核心风险在于利润对汇率波动的极度敏感。** 2025年净利润下滑近24%，主因并非主业恶化，而是外汇衍生品公允价值变动及汇兑损失。公司外销占比超20%，且持有大量外币资产，若人民币汇率持续波动，套保成本及公允价值损失将持续侵蚀利润，这是公司当前最不可控的利润杀手。

**第二重风险来自新项目的不确定性。** 特材项目和汽车精密管项目尚处调试试产及市场认证阶段，距离规模化盈利仍有距离。若下游高端市场开拓不及预期，或认证周期过长，巨额资本开支（在建工程5.17亿）将无法转化为有效收益，反而拖累ROE和现金流。
