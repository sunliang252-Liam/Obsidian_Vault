# 000880.SZ 深度透视

## 因果逻辑链
- **[数据中心/通信等新兴业务爆发]** -> [发电机组收入同比+102.54%]: 受益于AI算力扩张与国产替代，数据中心、油气田等高价值细分市场订单激增，成为收入增长核心引擎。
- **[“设备更新”与内河航运绿色化政策]** -> [替代燃料发动机销量大幅增长]: 政策强制推动内河船舶向LNG/甲醇动力转型，公司率先推出WH20LNG等产品，抢占绿色船舶市场先机。
- **[收购常玻公司，整合船艇制造]** -> [打造第二增长曲线]: 通过同一控制下企业合并，将业务从动力系统延伸至高附加值船艇制造，实现“动力+船体”深度集成，强化产业链竞争力。
- **[发电机组产品结构优化]** -> [毛利率承压但收入高增]: 高毛利的发动机产品增速(7.2%)远低于低毛利的发电机组(102.5%)，导致整体毛利率下降1.11%，但收入规模大幅提升。
- **[关联交易高度集中]** -> [业绩依赖集团协同]: 前五大客户/供应商中关联方占比分别达33.2%和42.21%，公司深度嵌入山东重工集团产业链，业务独立性存疑。
- **[票据贴现等融资手段]** -> [经营现金流大幅改善]: 经营活动现金流净额同比+106.26%，远超净利润增速，主要系公司加大票据贴现力度，将应收账款转化为现金。
- **[资本公积转增股本]** -> [摊薄每股收益]: 2025年中期10转4，总股本增至4.64亿股，导致基本每股收益从0.56元降至0.52元（调整后），稀释股东权益。

## 风险警告
**核心风险在于对关联方的高度依赖与发电机组业务的低毛利陷阱。** 公司超三成收入来自山东重工体系内关联交易，且前五大供应商采购额中关联方占比超四成，这种“左手倒右手”的模式虽能快速做大营收，但掩盖了真实的市场竞争力。一旦集团内部采购策略或关联交易定价机制发生变化，公司业绩将面临剧烈波动。此外，发电机组收入翻倍增长，但毛利率仅6.41%，远低于发动机的16.02%，表明公司为抢占数据中心等热门市场，牺牲了利润空间，这种以价换量的策略能否持续存疑。

**另一大风险是收购整合与资本开支带来的财务压力。** 公司为收购常玻公司及增资财务公司，投资活动现金净流出近10亿元，导致期末现金及等价物减少3.43亿元。虽然经营现金流改善，但大量现金被用于非主业扩张和关联方增资，而非投入核心研发或回报股东。同时，常玻公司并表当期即亏损1939万元，其与现有业务的协同效应尚需时间验证，短期可能拖累整体盈利能力。在行业景气度下行时，激进的资本开支将放大财务风险。
