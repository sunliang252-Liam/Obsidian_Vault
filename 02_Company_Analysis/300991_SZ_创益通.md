# 300991.SZ 深度透视

## 因果逻辑链
- **[罗马仕客户信用暴雷]** -> [净利润由盈转亏]: 对罗马仕及其子公司应收账款单项计提信用减值损失1,572.77万元及存货跌价准备453.60万元，合计减少利润总额2,026.37万元，直接导致全年归母净利润亏损319.46万元。
- **[消费电子互连产品收入下滑]** -> [营收增长乏力]: 核心业务消费电子互连产品收入同比下降11.59%，拖累整体营收仅微增2.53%，增长主要依赖新能源和无人机新业务。
- **[惠州工业园产能利用率不足]** -> [子公司持续亏损]: 全资子公司惠州创益通因募投项目资金紧张、设备投入不足，产能远低于规划，折旧摊销压力大，全年亏损2,937.07万元，严重侵蚀母公司利润。
- **[新业务无人机板块贡献增量]** -> [营收结构多元化]: 控股子公司乐山天穹（智能无人飞行器）全年贡献营收4,162.84万元，净利润564.35万元，成为新的利润增长点，部分对冲了主业下滑和减值损失。
- **[境外业务高速增长]** -> [收入地域结构优化]: 境外收入同比增长81.52%，占比从12.08%提升至21.39%，主要得益于马来西亚孙公司量产及海外客户拓展，降低了单一市场依赖风险。
- **[高研发投入维持技术壁垒]** -> [核心竞争力巩固]: 研发费用同比增长7.93%至4,379.79万元，聚焦高速服务器连接器、32GT/s高速铜缆等前沿技术，在AI服务器和数据中心领域保持技术领先。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比增长500.43%至4,748.12万元，显著优于净利润表现，主要系销售回款增加，表明公司实际运营造血能力有所恢复。

## 风险警告
**核心风险在于客户信用集中暴雷与资产减值侵蚀利润。** 公司对单一客户罗马仕的应收账款和存货计提超2,000万元减值，直接导致全年亏损。这暴露了公司在客户信用管理和应收账款回收上的脆弱性，若未来类似事件再次发生，将对利润造成毁灭性打击。同时，惠州子公司因产能利用率低而持续大额亏损，成为吞噬利润的“黑洞”，短期难以扭转。

**成长性面临新旧动能转换的阵痛。** 传统消费电子业务持续萎缩，而新能源精密结构件毛利率仅8.35%，盈利能力薄弱；高速数据通讯产品收入下滑20.13%，尚未形成规模支撑。尽管无人机业务开局良好，但体量尚小。公司能否在AI服务器、新能源等新赛道实现突破，并有效控制新业务的风险，是未来能否走出困境的关键。
