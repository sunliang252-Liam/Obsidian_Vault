# 688510.SH 深度透视

## 因果逻辑链
- **[海外特种工艺供应链瓶颈]** -> [国际业务收入同比下降13.33%]: 北美市场部分叶片订单因外部供应链问题出现重大延期交付，直接拖累整体营收。
- **[国内“两机”自主可控需求放量]** -> [国内业务收入同比增长13.94%]: 受益于国产航空发动机及燃气轮机加速列装与国产化替代，国内订单增长弥补了部分国际业务缺口。
- **[燃机新业务投入与研发费用激增]** -> [净利润同比下降19.44%]: 公司在拓展燃气轮机等新业务时，对技术储备与客户需求的匹配研判不足，导致研发费用同比增长18.61%，侵蚀利润。
- **[产品结构变化与毛利率承压]** -> [综合毛利率下降1.50个百分点]: 低毛利产品占比提升及医疗业务制造费用因销售增加而大幅上升，导致整体盈利能力下滑。
- **[核心客户深度绑定与项目拓展]** -> [LEAP叶片份额稳定，GE9X/GENX项目转入量产]: 与赛峰、RR等国际巨头的战略协同，确保了成熟项目的市场份额，并成功导入新机型项目，为未来增长奠基。
- **[马来西亚及无锡新产能布局]** -> [长期增长空间打开]: 海外建厂（马来西亚）与国内机匣专业化产能建设同步推进，旨在提升供应链韧性与产品结构，但短期将带来资本开支压力。
- **[汇兑损失与信用减值增加]** -> [财务费用同比激增165.03%]: 人民币汇率波动导致汇兑损失增加，同时应收账款规模扩大导致信用减值损失上升，共同对净利润造成负面冲击。

## 风险警告
**核心风险在于海外业务的不确定性与新业务扩张的“阵痛”。** 公司被列入美国MEU清单，虽目前通过许可证维持运营，但地缘政治风险是悬在头顶的达摩克利斯之剑，任何中美关系的恶化都可能导致国际业务中断。同时，2025年净利润下滑已暴露公司在拓展燃机等新业务时，对技术、市场与产能匹配度的判断出现偏差，导致研发投入高增但短期回报不及预期，存在“增收不增利”的陷阱。

**财务与运营风险同样不容忽视。** 公司客户高度集中（前五大客户占航空业务收入94.74%），且对关联方中国航发集团的销售占比高达41.73%，存在单一客户依赖风险。此外，应收账款与存货规模持续增长，国内业务以商业承兑汇票结算为主，回款周期长，对现金流形成持续压力。若下游主机厂付款节奏放缓或产品无法顺利销售，将引发坏账和存货跌价风险，进一步侵蚀本已承压的利润。
