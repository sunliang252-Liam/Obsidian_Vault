# 688767.SH 深度透视

## 因果逻辑链
- **[美国加征关税与地缘政治风险]** -> [对美出口销售下滑]: 2025年上半年美国政府多次加征关税，直接引发市场重大波动，导致公司对美出口业务受挫。
- **[行业竞争加剧与传染病市场周期性波动]** -> [国内呼吸道及拉美登革热产品收入减少]: 国内呼吸道检测市场竞争白热化，同时拉美地区登革热等蚊媒类产品需求周期性回落，双重挤压下核心产品线收入同比下降。
- **[研发费用与股份支付费用增加]** -> [净利润降幅远超营收降幅]: 公司坚持创新驱动，研发投入同比增长31.31%，叠加员工持股计划产生的股份支付费用，导致期间费用率大幅攀升，利润被显著侵蚀。
- **[财务性收益减少]** -> [净利润进一步承压]: 汇率波动及金融市场存款利率下行，导致公司利息收入及汇兑收益等财务性收入同比减少，加剧了利润下滑。
- **[上期非经常性损益高基数]** -> [本期净利润同比大幅下滑]: 2024年因境外客户新冠检测订单终止，无需返还的500万美元预收款转为收入，形成高基数；2025年无此类收入，导致非经常性损益贡献锐减。
- **[境外收入占比高]** -> [业绩易受国际政治经济波动影响]: 公司境外收入占比超73%，对美出口依赖度高，使其业绩对中美贸易摩擦、汇率波动等宏观环境变化高度敏感。
- **[微流控新技术平台投入加大]** -> [长期竞争力构建但短期盈利承压]: 公司重点布局微流控等前沿技术，虽为未来增长奠定基础，但当前研发投入大、商业化进程尚在早期，对短期利润形成拖累。

## 风险警告
**核心风险在于业绩的“双杀”与转型阵痛。** 公司2025年营收下滑20%，净利润更是暴跌71%，扣非净利润降幅高达77%。这并非单一因素所致，而是“外患”与“内忧”的叠加：外部面临美国关税壁垒导致核心市场萎缩、行业竞争加剧导致产品价格与销量承压；内部则因研发投入激增、员工持股费用化以及财务收益减少，导致利润被严重挤压。公司当前正处于从“疫情红利”向“常态化竞争”转型的阵痛期，盈利能力显著恶化。

**另一重大风险是海外市场的高度依赖性与政策不确定性。** 公司超七成收入来自境外，尤其对美出口是重要收入来源。中美贸易摩擦的持续升级、欧盟CE IVDR新规的严格合规要求，均可能对公司核心市场的准入和销售构成实质性障碍。尽管公司正通过美国子公司Advin推进本地化运营，但短期内难以完全对冲关税与地缘政治风险，业绩波动性将持续高企。此外，公司2025年拟分红金额高达净利润的212%，在业绩大幅下滑的背景下，如此高的分红比例可能透支公司未来的发展资金，需警惕其可持续性。
