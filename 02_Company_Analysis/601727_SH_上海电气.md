# 601727.SH 深度透视

## 因果逻辑链
- **[煤电“三改联动”政策红利]** -> [能源装备收入增长21.5%]: 国家推动煤电节能降碳、灵活性改造，公司作为煤电设备龙头，订单与交付量显著提升。
- **[核电设备市场占有率第一]** -> [核电业务稳定增长]: 公司覆盖国内所有核电技术路线，核岛主设备市占率持续第一，受益于核电积极有序发展。
- **[新能源业务高增但盈利承压]** -> [整体毛利率微降]: 风电、储能等新能源业务规模快速扩张，但市场竞争激烈，拉低了能源装备板块毛利率1.3个百分点。
- **[电梯业务受地产下行拖累]** -> [工业装备收入下降1.5%]: 房地产行业低迷导致新梯需求萎缩，公司电梯业务收入下滑，成为工业装备板块的主要拖累。
- **[非经常性损益贡献主要利润]** -> [扣非净利润仅2亿]: 2025年归母净利润12.06亿，但扣非后仅2亿，利润高度依赖政府补助、资产处置等非主业收益。
- **[存货与合同负债大幅增长]** -> [经营现金流下降40%]: 为应对2026年交付高峰，公司大幅增加原材料备货，导致购买商品支付的现金增加，经营性现金流净额降至105亿。
- **[“风光储氢”全产业链布局]** -> [新产业风险与机遇并存]: 公司积极布局压缩空气储能、绿色甲醇、人形机器人等新赛道，但技术路线、市场拓展存在不确定性。

## 风险警告
**核心风险在于盈利质量与现金流压力。** 公司2025年归母净利润12.06亿元，但扣非净利润仅2亿元，主业盈利能力依然薄弱，利润高度依赖政府补助、资产处置等非经常性损益。同时，为应对订单增长，存货激增36.9%至473亿元，导致经营活动现金流净额同比大幅下降40%，对公司的运营资金管理构成严峻考验。

**传统业务面临结构性挑战，新业务投入期长。** 电梯业务受房地产下行周期影响，收入持续萎缩，是工业装备板块的主要拖累。公司在风电、储能、氢能等新能源领域投入巨大，但市场竞争激烈，毛利率承压，且新产业（如人形机器人、绿色甲醇）尚处于商业化早期，研发投入与市场拓展的不确定性较高，短期内难以贡献稳定利润。
