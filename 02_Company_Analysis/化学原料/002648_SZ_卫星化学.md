# 002648.SZ 深度透视

## 因果逻辑链
- **全球高成本老旧装置退出加快** -> 行业供给重心向低成本一体化区域集中: 欧洲、日韩等地区因能源高成本、碳约束、设备老旧等关停产能，减少全球供给，使得具备轻烃一体化优势的企业竞争力增强
- **轻烃路线成本、能耗、碳排优势** -> 公司经营韧性增强: 乙烷裂解乙烯收率达80%，能耗仅为石脑油1/3、煤化工1/10，成本更低，碳排更少，在行业承压时保持盈利
- **公司研发投入高（16.56亿）且聚焦卡脖子技术** -> 突破高端新材料（POE、α-烯烃等）: 持续研发投入攻克关键技术，实现高端化、差异化产品，提升附加值
- **产业链一体化（C2+C3协同）** -> 成本降低与抗周期能力: 原料互供、公用工程共享、副产品高效利用，降低综合成本；产品矩阵多样可灵活切换，抵御单一产品波动
- **海外高成本装置退出+公司海外布局** -> 出口增长与海外市占率提升: 海外竞争对手退出，公司利用成本优势扩大出口，境外收入增长39.96%
- **绿色低碳优势（轻烃路线低碳排、副产氢）** -> ESG评级提升及市场竞争力: 低碳属性符合双碳政策，转化为实际市场优势；副产高纯氢拓展绿色能源应用
- **套期保值及衍生品操作** -> 对冲原料价格波动风险: 利用纸货、远期外汇等对冲丙烷成本及汇率风险，减少价格波动对利润的影响
