# 300891.SZ 深度透视

## 因果逻辑链
- **[钛白粉价格弱势下行]** -> [净利润巨亏-6260.74万元]: 全球经济放缓及贸易壁垒加剧导致行业竞争加剧，钛白粉价格下跌，直接侵蚀公司利润。
- **[募投及技改项目转固]** -> [折旧及利息费用大增]: 前期项目陆续转固，折旧费用及可转债费用化利息同比增加，推高固定成本，加剧亏损。
- **[原材料硫磺、硫铁矿价格上涨]** -> [生产成本承压]: 硫磺采购均价同比上涨91.28%，硫铁矿上涨33.96%，直接推高钛白粉生产成本，压缩利润空间。
- **[“以量补价”策略]** -> [营收增长4.62%]: 在价格下跌背景下，公司通过扩产和销售，实现钛白粉销量同比增长16.36%，以销量增长部分抵消价格下跌对营收的冲击。
- **[循环经济产业链降本]** -> [成本控制能力提升]: “硫-钛-铁-钙”循环产业链及稀酸浓缩项目投产，实现资源回用，有效降低生产成本，缓解了原材料涨价压力。
- **[产业链纵向延伸]** -> [长期抗风险能力增强]: 向上游收购辰翔矿产控股权，向下游布局磷酸铁、聚合硫酸铁，完善产业链，旨在降低对单一产品和市场的依赖。
- **[经营活动现金流净额大增571.94%]** -> [经营质量优于账面利润]: 尽管账面亏损，但公司通过加强回款，实现经营活动现金流净额1.33亿元，表明核心业务造血能力并未恶化。

## 风险警告
**核心风险在于钛白粉行业供需失衡与成本端双重挤压。** 2025年全行业产量首次下降，产能利用率仅82.8%，供大于求格局短期难改。同时，公司主要原材料硫磺、硫铁矿价格大幅上涨，而钛白粉价格弱势下行，导致“剪刀差”持续扩大，这是公司由盈转亏的根本原因。若行业竞争加剧或原材料价格继续高位运行，公司盈利能力将面临持续挑战。

**财务风险在于高负债与资本开支带来的现金流压力。** 公司为扩产和技改，大量举债（短期借款、长期借款及可转债），导致财务费用同比大增123.56%。虽然当前经营性现金流尚可，但投资活动现金流净流出高达4.09亿元，且部分募投项目尚未达产，未来若市场环境未改善，公司可能面临偿债压力与现金流紧张的双重风险。

**公司简介（F10 原文）**

> 广东惠云钛业股份有限公司拥有一支分别来自全国各钛白粉生产厂家和各类院校化工专业和管理专业的高素质的管理人才、工程技术人才和较高操作水平的员工队伍。公司以“发展循环经济,创造绿色未来”为使命,采用清洁联产硫酸法工艺生产钛白粉,是一家具有独特循环经济优势的区域龙头钛白粉企业。公司依托当地丰富的硫铁矿资源,与云浮水泥、石材等支柱产业紧密结合,在国内首创并形成了完整的“硫-钛-铁-钙”循环经济产业链,实现了以废治废和资源综合利用,提高了经济效益和环境效益,是我国第一家“硫酸法钛白粉清洁生产和循环经济产业链示范基地”。公司先后被评为“国家高新技术企业”、“广东省清洁生产企业”“广东省省级企业技术中心”和“广东省‘硫-钛-铁-钙’产业工程技术研究中心”等。公司已建立质量、环境、职业健康安全管理体系,并通过IS09001、ISO14001、ISO45001标准认证,产品质量达到国际先进水平,主要有金红石型钛白粉:R-K95、R-666、R-668、R-18、R-2021;锐钛型钛白粉:HTA-301、HTA-201。产品具有粒度分布均匀、高稳定性、高白度、带蓝相、高亮度、高纯度、高遮盖力、高分散性等优点,受到国内外用户的高度认可。产品广泛应用于广泛应用于涂料、塑料、造纸、印刷油墨、橡胶、化纤、陶瓷、化妆品、食品、医药、电子工业、微机电、汽车和环保工业等领域,畅销全国并出口葡萄牙、俄罗斯、土耳其、巴西、墨西哥、韩国、马来西亚、菲律宾、印度、越南和新加坡等世界各地。
