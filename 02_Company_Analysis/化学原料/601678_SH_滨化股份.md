# 601678.SH 深度透视

## 因果逻辑链
- **[子公司滨华新材料C3C4装置全面投产]** -> [营收暴增45%]: 2025年MTBE/PO装置满产，甲基叔丁基醚及环氧丙烷销量大幅上升，驱动营收从102亿跃升至148亿。
- **[原材料及能源成本下降]** -> [毛利逆势扩张]: 尽管产品售价下跌，但丙烷、丁烷、原煤采购价同比分别下降4.27%、9.50%、19.98%，成本降幅大于售价降幅，支撑主营业务毛利率提升4.48个百分点。
- **[扣非净利润腰斩]** -> [盈利质量恶化]: 扣非净利润仅1.1亿，同比降49.33%，主因对联营企业（鲁北集团）投资收益大幅亏损1.83亿，核心化工主业盈利能力被非经常性损益掩盖。
- **[经营活动现金流暴增490%]** -> [现金循环改善]: 营收增长叠加存货及应收款周转加快，经营性现金流净额达28.65亿，远超净利润，显示回款能力强劲。
- **[烧碱高毛利贡献稳定利润]** -> [周期压舱石]: 烧碱毛利率高达56.23%，受益于下游氧化铝及新能源需求，产能利用率129%，为公司提供稳定的利润基本盘。
- **[MTBE出口依赖度提升]** -> [打开增长天花板]: 2025年国内MTBE出口量同比增101.8%，公司成功打通丁烷-MTBE进料加工流程，海外市场成为消化新增产能的关键。
- **[研发费用增长44%]** -> [技术壁垒构建]: 研发投入1.73亿，重点攻克“氯醇法环氧丙烷皂化工艺”及“G5级电子级氢氟酸”，旨在通过技术升级应对行业同质化竞争。

## 风险警告
**核心风险在于盈利的“虚胖”与“失血”。** 公司2025年归母净利润2.25亿，看似同比微增，但扣非净利润仅1.1亿，同比腰斩。利润的“含金量”极低，主要依赖期货公允价值变动（0.94亿）、碳排放权转让等非经常性损益。更关键的是，核心联营企业鲁北集团亏损5.16亿，导致公司投资收益从4.4亿骤降至-1.8亿，这是利润表的最大“失血点”。若剔除这些扰动，公司主业盈利能力实际上在恶化。

**其次，行业产能过剩与价格战是长期悬顶之剑。** 环氧丙烷国内产能已超900万吨，行业开工率下滑，价格低位运行。公司虽通过PO/MTBE联产工艺降本，但MTBE毛利率为-2.14%，处于亏损状态。烧碱虽为高毛利现金牛，但下游氧化铝需求增速放缓，且公司烧碱产能利用率已高达129%，进一步提产空间有限。在化工行业供需结构转型的大背景下，公司缺乏明确的差异化产品，同质化竞争将长期压制盈利中枢。
