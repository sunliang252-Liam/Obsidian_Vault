# 600075.SH 深度透视

## 因果逻辑链
- **[PVC价格创近三十年新低]** -> [归母净利润亏损5707万元]: 主营产品聚氯乙烯树脂价格持续下跌，直接导致公司营收下降6%，利润总额锐减86.57%，由盈转亏。
- **[煤炭、焦炭等原材料价格大幅下降]** -> [部分对冲产品价格下跌]: 煤炭、焦炭、兰炭采购价同比下降22%-25%，使毛利同比增加6.16亿元，成为公司维持微利的关键缓冲垫。
- **[烧碱价格逆势上涨]** -> [利润贡献增加1.69亿元]: 烧碱销售单价同比上升213.96元/吨，毛利率提升16.31个百分点至49.07%，有效弥补了PVC产品的亏损。
- **[新产业链“煤-乙醇-乙烯-PVC”打通]** -> [长期竞争力提升]: 天业汇祥22.5万吨高性能树脂项目试车成功，构建无汞化绿色新路线，降低对传统电石法依赖，但2025年仅贡献566万元净利润，尚处爬坡期。
- **[资产减值损失同比增加7200万元]** -> [侵蚀利润]: PVC价格下跌导致存货跌价准备新增3716万元，同时新增固定资产减值准备3485万元，合计对利润形成显著拖累。
- **[研发费用同比增加3994万元]** -> [短期利润承压]: 为推进高端特种树脂等新产品研发，研发费用增长10.37%，虽有利于长期发展，但加剧了当期亏损。
- **[循环经济产业链优势]** -> [成本控制能力突出]: 依托自备电厂、电石渣制水泥等一体化闭环，在行业低迷期仍能保持12.52%的综合毛利率，优于部分同行。

## 风险警告
**核心风险：主营产品PVC价格持续低迷与行业产能过剩。** 2025年PVC年均价创近三十年新低，而国内产能仍在扩张（2025年净增137万吨），供需矛盾尖锐。公司PVC树脂类产品毛利率已为-7.74%，处于亏损状态。2026年出口退税取消将进一步削弱出口竞争力，若下游房地产需求未见实质性回暖，公司主业盈利能力将面临持续严峻考验。

**财务风险：现金流恶化与资产减值压力。** 经营活动现金流净额同比大幅下降42.27%至7.88亿元，主要因PVC价格下跌及票据结算增加。同时，公司面临持续的资产减值风险（2025年新增7200万元），若产品价格继续下行，存货和固定资产减值压力将进一步加大。此外，公司为参股公司天业汇合提供41亿元银团贷款担保，若其经营恶化，将构成或有负债风险。
