# 603213.SH 深度透视

## 因果逻辑链
- **[行业供需失衡，产品价格承压]** -> [营收与利润双降]: 氯碱行业“内卷式”竞争加剧，烧碱、PVC等主要产品价格下跌，导致公司2025年营收同比下降9.45%，归母净利润同比大幅下降60.43%。
- **[成本下降滞后于售价下跌]** -> [毛利率显著收窄]: 原材料价格虽有回落，但降幅不及产品售价跌幅，导致公司整体毛利率同比下降3.71个百分点，盈利能力被严重挤压。
- **[PVC业务持续亏损]** -> [拖累整体业绩]: 作为营收占比第二大产品，PVC类产品毛利率为-26.24%，且同比恶化16.70个百分点，成为公司利润的最大“出血点”。
- **[核心产品烧碱高负荷运行]** -> [稳固经营基本盘]: 通过工艺优化，烧碱装置全年产能利用率高达110.83%，产量38.79万吨，以量补价，为公司贡献了主要利润来源。
- **[可转债利息费用增加]** -> [财务费用大幅攀升]: 募投项目转固后，可转债利息费用不再资本化，导致2025年财务费用同比激增51.39%，进一步侵蚀利润。
- **[存货跌价准备增加]** -> [资产减值损失扩大]: 受产品价格下跌影响，公司对库存商品计提的跌价准备大幅增加，资产减值损失同比扩大84.8%，反映出下游需求疲软。
- **[经营性现金流大幅改善]** -> [现金流质量提升]: 通过加强应收账款管理，经营性应收项目减少，使得经营活动现金流净额由负转正，达到3.2亿元，经营“造血”能力恢复。

## 风险警告
公司正面临严峻的行业周期下行风险。核心产品PVC持续深度亏损，且亏损幅度同比扩大，短期内看不到反转迹象。同时，烧碱、MIBK等产品价格承压，毛利率下滑，公司整体盈利能力已降至历史低位。若下游需求持续疲软，公司业绩存在进一步下滑的风险。

此外，公司正在进行被控股股东浙江沪杭甬吸收合并的重大资产重组，该事项尚需监管审核，存在不确定性。若重组失败，公司不仅将面临股价波动风险，其独立发展战略也将受到重大影响。同时，公司资产负债率已升至42.79%，财务费用因可转债利息而大幅增加，财务杠杆风险正在累积。
