# 600955.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [净利润亏损9.92亿元]: 化工行业供需失衡，主要产品价格低迷，导致公司营收下降7.91%，毛利率全面转负，最终录得上市以来首次巨额亏损。
- **[资产减值损失激增]** -> [利润总额大幅恶化]: 计提7.81亿元资产减值损失（主要为固定资产和在建工程），是导致净利润由盈转亏的直接财务原因，同比暴增11.7倍。
- **[财务费用飙升]** -> [侵蚀利润]: 利息费用同比大增206%至1.06亿元，财务费用从0.14亿激增至0.97亿元，显示公司债务负担加重，融资成本上升。
- **[“双链”布局对冲单一风险]** -> [营收下滑幅度小于利润下滑]: 新材料与新能源双产业链格局，部分抵消了传统酚酮业务的周期性下行，但新投产的新能源项目（电解液溶剂）尚未贡献利润，反而因折旧和摊销增加成本。
- **[原材料价格下降]** -> [成本端压力缓解有限]: 主要原料纯苯和丙烷价格分别下降24.63%和5.80%，但产品售价跌幅更大，导致“剪刀差”扩大，毛利率恶化。
- **[“深耕细管、降本增效”策略]** -> [经营活动现金流仍为正]: 尽管巨额亏损，但公司通过压低库存、快速周转的营销策略，经营活动现金流净额仍录得5.79亿元，显示运营效率尚可。
- **[新项目投产与产能爬坡]** -> [未来业绩弹性]: 25万吨/年电解液溶剂项目建成投产，但面临高端客户认证周期，产能释放存在不确定性，是未来能否扭亏的关键。

## 风险警告
**核心风险在于行业周期与公司财务杠杆的双重挤压。** 2025年公司录得上市以来首次巨额亏损（-9.92亿元），主要源于化工行业产能过剩导致的产品价格战，以及由此引发的7.81亿元资产减值损失。更值得警惕的是，公司财务费用同比暴增572%，利息支出高达1.06亿元，显示在行业低谷期，前期大规模资本开支形成的债务负担正成为吞噬利润的沉重枷锁。若行业景气度未能如期反转，公司可能面临“经营性亏损+财务成本高企”的恶性循环。

**新业务的不确定性是另一大风险点。** 公司寄予厚望的25万吨/年电解液溶剂项目虽已投产，但作为新能源领域的新进入者，面临激烈的市场竞争和高端客户漫长的认证周期。该项目能否在2026年实现满产满销并贡献正利润，存在重大不确定性。若新业务无法及时贡献业绩，公司“双链驱动”的战略将面临阶段性落空，业绩修复将严重依赖传统化工品价格反弹，而后者在供给过剩格局下难度较大。
