# 300927.SZ 深度透视

## 因果逻辑链
- **[收购三大雅，营收结构剧变]** -> [营收暴增125.51%]: 2025年完成对三大雅（SAP高吸水性树脂）的收购并表，SAP产品贡献超63%营收，使公司从单一工业化学品商转变为“工业+民用”双轮驱动企业。
- **[负商誉一次性收益消失]** -> [净利润暴跌93.45%]: 2024年因收购三大雅产生2.55亿元负商誉计入营业外收入，推高当年基数；2025年该非经常性收益消失，导致归母净利润从2.98亿骤降至1951万。
- **[行业竞争加剧，毛利承压]** -> [毛利率全面下滑]: 多聚甲醛等主营产品面临新增产能冲击，量价齐跌；SAP业务整合期运营效率未充分释放，整体毛利率同比下降，盈利空间被显著压缩。
- **[去库存策略见效]** -> [经营现金流暴增880%]: 公司主动加大销售力度，成功消化年初高库存，存货从2.68亿降至1.38亿，带动经营活动现金净流量从1633万飙升至1.6亿。
- **[迁建项目投产]** -> [在建工程持续高位]: “迁出长江一公里”项目一期于2025年三季度试生产，四季度全面试产，但截至年末仍处于负荷测试阶段，在建工程账面价值高达5.33亿元，占总资产25.35%。
- **[SAP业务依赖大客户]** -> [客户集中度极高]: 前五大客户销售额占比65.71%，其中单一客户A占比高达53.77%，公司对核心客户的依赖度极高，议价能力和经营稳定性面临挑战。

## 风险警告
**核心风险在于盈利能力的断崖式下滑与整合阵痛。** 2025年归母净利润同比暴跌93.45%，扣非净利润也下滑63.28%，这并非短期波动，而是公司核心盈利逻辑发生根本性转变的信号。收购三大雅带来的营收规模扩张，并未转化为利润增长，反而因行业竞争加剧、SAP业务整合初期效率低下，导致整体毛利率承压。公司当前盈利水平极低，且高度依赖一次性非经常性损益的历史已不可复制，未来能否通过深度整合释放协同价值，存在巨大不确定性。

**另一重大风险是极高的客户集中度与在建工程转固压力。** 公司超一半营收来自单一客户A，任何客户关系变动都将对经营造成毁灭性打击。同时，“迁出长江一公里”项目等重大在建工程（占总资产25%）即将转固，将带来巨额的折旧与利息费用，在现有微利基础上，可能进一步侵蚀利润，甚至导致公司陷入亏损。此外，原材料（甲醇、精丙烯酸）价格波动、海外市场拓展不及预期等风险，也将在公司脆弱的基本面上放大冲击。
