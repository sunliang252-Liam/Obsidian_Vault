# 002136.SZ 深度透视

## 因果逻辑链
- **[钛白粉价格持续下跌]** -> [营收下降10.39%]: 2025年钛白粉价格跌至近五年低点，全年经历“涨跌涨”三个阶段，但年末价格较年初下跌明显，直接拖累公司钛白粉板块收入同比下降11.25%。
- **[磷酸铁行业产能过剩]** -> [子公司巨亏8256万元]: 磷酸铁行业产能投资过热，供需矛盾突出，产品价格全年大部分时间低位运行，导致子公司纳源科技产量同比下降23.75%，净利润由盈转亏。
- **[硫酸价格大幅上涨]** -> [成本端承压]: 受国际硫磺价格走高影响，公司外购硫酸下半年采购均价较上半年增长44.18%，直接推高钛白粉生产成本，挤压利润空间。
- **[欧盟反倾销税及出口受阻]** -> [国内竞争加剧]: 欧盟对中国钛白粉实施五年反倾销税，叠加巴西、沙特等反倾销终裁，2025年出口量同比下降4.46%，出口受阻进一步加剧国内供需失衡。
- **[房地产行业持续低迷]** -> [下游需求萎靡]: 钛白粉主要下游涂料行业受房地产需求不振影响，国内表观消费量约300万吨，与去年持平，需求增速有限。
- **[万华电池成为控股股东]** -> [战略协同与组织变革]: 2024年万华电池成为控股股东，带来管理团队与万华研究院技术资源，推动公司推行“两提一降两加”战略，但协同效应尚未在业绩中体现。
- **[经营性应收项目大幅增加]** -> [现金流恶化]: 经营活动现金净流出9657万元，主要因经营性应收项目增加1.96亿元，显示回款压力增大，现金循环周期拉长。

## 风险警告
**核心风险在于双主业均陷入行业性亏损困境。** 钛白粉业务面临价格跌至五年低点、出口反倾销、国内供需失衡的三重打击；磷酸铁业务则深陷产能过剩泥潭，子公司纳源科技产能利用率仅33.84%，全年亏损8256万元。两大主业同时承压，公司2025年归母净利润亏损9258万元，扣非后亏损8053万元，经营性现金流连续两年为负，造血能力严重不足。

**财务健康度恶化信号明显。** 公司资产负债率虽不高，但短期偿债压力正在积聚：货币资金减少19.3%至3.68亿元，而应付票据及应付账款合计增加至6.78亿元。更值得警惕的是，公司计划不派发现金红利，且2026年磷酸铁产量目标（10万吨）是2025年实际产量（5.08万吨）的近两倍，在行业产能严重过剩背景下，这一激进目标能否实现存在重大不确定性。
