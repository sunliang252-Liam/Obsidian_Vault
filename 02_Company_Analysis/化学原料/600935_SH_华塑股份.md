# 600935.SH 深度透视

## 因果逻辑链
- **[PVC价格持续低迷]** -> [公司连续两年亏损]: 下游房地产需求疲软、行业产能过剩，导致PVC价格低位运行，公司核心产品PVC毛利率为-21.45%，严重拖累整体盈利。
- **[烧碱产品盈利能力稳定]** -> [亏损大幅收窄]: 烧碱毛利率高达61.82%，且成本下降，部分对冲了PVC的亏损，使2025年净利润-1.54亿元，较2024年-4.29亿元大幅减亏。
- **[原材料价格下降]** -> [生产成本降低]: 兰炭、焦粒、混煤等主要原材料采购价格同比分别下降24.19%、22.16%、15.24%，直接降低了PVC、烧碱等产品的生产成本。
- **[降本增效举措发力]** -> [经营质效改善]: 公司通过技改项目投运、关键消耗指标改善、严控七项成本等措施，营业成本降幅（-13.61%）大于收入降幅（-8.86%）。
- **[“以碱补氯”模式]** -> [维持现金流为正]: 在PVC业务亏损的情况下，高毛利的烧碱业务贡献了主要利润，使公司经营活动现金流净额仍保持2.41亿元为正。
- **[子公司无为华塑贡献主要利润]** -> [支撑公司整体业绩]: 子公司无为华塑（矿业）净利润1.68亿元，是公司唯一的利润支柱，弥补了母公司及其他业务的亏损。
- **[行业产能过剩与出口缓解]** -> [市场供需格局]: 国内PVC产能2993万吨，内需疲软，但出口量382.32万吨创历史新高，部分缓解了国内供应过剩压力。

## 风险警告
**核心风险在于PVC业务的持续亏损。** 公司核心产品PVC毛利率为-21.45%，即每卖出一吨亏损约21%，这是公司连续两年亏损的根本原因。尽管烧碱业务盈利能力强劲（毛利率61.82%），但“以碱补氯”模式只能缓解亏损，无法扭转颓势。若PVC价格长期低迷或烧碱价格出现大幅下跌，公司将面临更大的经营压力，甚至可能触及财务困境。

**另一个重大风险是公司已不具备分红能力。** 截至2025年末，母公司未分配利润为-2.75亿元，存在较大未弥补亏损。公司已连续两年不派发现金红利，且短期内无法满足分红条件。对于依赖股息收入的投资者而言，该股票缺乏吸引力。此外，公司资产负债率虽降至37.50%，但一年内到期的非流动负债激增65.16%，短期偿债压力有所上升。

**公司简介（F10 原文）**

> 安徽华塑股份有限公司成立于2009年3月,坐落于安徽省滁州市定远县。公司是长三角地区大型氯碱化工企业,国企改革“双百行动”的试点企业、“安徽省十大优秀创新企业”、“安徽省制造业综合实力50强企业”。公司大型盐化工项目是安徽省“861”行动计划重点项目、振兴皖北经济“一号工程”的重要组成部分。公司主要从事以PVC和烧碱为核心的氯碱化工产品生产与销售,建成了以PVC、烧碱为核心的“矿—煤—电—氯碱化工—‘三废’综合利用”的一体化循环经济体系,在资源、成本、技术、规模、环保等多个方面具有综合竞争优势。公司主要产品包括PVC、烧碱、灰岩、协同处置“绿色”水泥、石灰等。未来,公司经营规模将进一步扩大,综合经济实力更强,迈上发展新台阶。氯碱化工主导产业巩固提升,精细化工、化工新材料等支持产业优势彰显,形成更具有活力、更具竞争力的产业结构体系,公司生产效率达到行业一流水平,经济效益持续稳步提升。

- **2018-11-13　定远县安全生产监督管理局　公开处罚　对象：安徽华塑股份有限公司**
  - 事由：2018年8月17日省级市际互查合肥市安全生产互查组,对公司进行安全大检查时,发现公司存在液氯装车液位控制与现场操作规程不符。以及发现公司存在液氯库房门未全部设置自动关闭装置。
  - 决定：依据《安全生产违法行为行政处罚办法》(安监总局第15号令)第四十五条第一项的规定,给予公司警告,并处人民币叁万元整罚款的行政处罚。依据《危险化学品安全管理条例》(国务院令第591号令)第八十条第(五)项的规定,给予罚款人民币伍万元整罚款的行政处罚。
- **2018-01-17　定远县环境保护局　公开处罚　对象：安徽华塑股份有限公司**
  - 事由：超过大气污染物排放标准排放大气污染物,公司行为违反了《中华人民共和国大气污染防治法》第十八条的规定。
  - 决定：定远县环境保护局根据《中华人民共和国大气污染防治法》第九十九条第一款第(二)项的规定,对公司处以如下行政处罚:罚款人民币拾万元整。
