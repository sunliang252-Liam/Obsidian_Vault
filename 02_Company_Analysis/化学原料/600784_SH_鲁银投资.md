# 600784.SH 深度透视

## 因果逻辑链
- **[工业盐市场供需失衡]** -> **盐业板块利润骤降49.96%**: 下游两碱化工需求疲弱，产能过剩导致价格承压，食用盐销量下滑，共同拖累盐业整体盈利。
- **[新材料板块产销两旺]** -> **新材料净利润逆势增长37.03%**: 钢铁粉末产销量分别增长25.59%和19.58%，规模效应与“制粉-制品”协同效应释放，对冲了盐业下滑。
- **[销售费用激增48.12%]** -> **侵蚀利润空间**: 销售规模扩大导致薪酬和服务费增加，在营收基本持平的背景下，费用率上升直接压缩了净利润。
- **[增持万润股份与项目投资]** -> **投资活动现金净流出5.62亿元**: 公司大幅增持万润股份股票并推进肥城120万吨制盐项目等工程建设，导致投资性现金大幅流出。
- **[盐业产能扩张至480万吨]** -> **规模优势巩固但短期盈利承压**: 肥城项目试车成功提升产能，但新增产能的释放与市场消化需要时间，叠加行业低迷，短期未能转化为利润增长。
- **[研发投入增长5.26%]** -> **支撑长期竞争力**: 持续投入研发（1.2亿元）以推动盐业产品结构升级和新材料技术攻关，是应对行业竞争和开拓新领域的基础。

## 风险警告
**核心风险在于业绩严重依赖单一板块的周期性波动。** 公司净利润同比下降43.75%，完全由盐业板块利润腰斩（-49.96%）所致。工业盐市场供过于求、价格内卷的格局短期内难以扭转，而食用盐市场也面临中高端竞争加剧的压力。若下游化工行业景气度持续低迷，公司整体盈利将面临持续下滑风险。

**资本运作与主业扩张带来的财务压力不容忽视。** 公司为增持万润股份股票及建设新项目，大幅增加长期借款（+53.59%），导致投资活动现金净流出高达5.62亿元。虽然此举意在布局长期价值，但短期内推高了资产负债率（从39.46%升至41.97%），并增加了财务费用和偿债压力。若被投资标的或新项目回报不及预期，将加剧公司的现金流紧张状况。
