# 002386.SZ 深度透视

## 因果逻辑链
- **[出售黄磷产能指标]** -> [归母净利润扭亏为盈]: 出售2.5万吨/年黄磷产能指标获得1.78亿元非流动资产处置收益，是公司实现归母净利润8778万元的核心驱动力，扣非净利润仍为-9593万元。
- **[磷酸铁锂产能快速释放]** -> [新能源业务收入翻倍]: 磷酸铁锂正极材料产量4.94万吨（+99.19%），销量4.59万吨（+139.06%），带动新能源电池及材料行业收入同比大增100.78%至10.9亿元。
- **[氯碱产品结构优化与成本控制]** -> [氯碱板块毛利率提升]: 在烧碱产量创新高（45.7万吨）的同时，营业成本下降16.22%快于收入降幅6.62%，使氯碱产品类毛利率同比提升9.62个百分点至15.99%。
- **[氯化法钛白粉产销放量]** -> [钛化工板块收入增长]: 氯化法钛白粉产量10.82万吨（+21.98%），销量11.21万吨（+31.57%），推动钛化工产品类收入增长15.12%至14.96亿元。
- **[主动收缩低毛利贸易业务]** -> [营收结构优化]: 供应链及其他行业收入同比下降47.70%，占营收比重从23.68%降至14.65%，主动剥离低效贸易，聚焦主业。
- **[新能源业务应收账款大幅增加]** -> [经营性现金流恶化]: 经营活动现金流净额为-2.32亿元（同比-200.75%），主要因新能源业务规模扩大，期末销售形成的应收款项尚未收回。
- **[磷酸铁锂产能利用率不足]** -> [新业务盈利承压]: 磷酸铁锂设计产能20万吨，实际产能12.5万吨，产能利用率仅39.52%，导致单位固定成本较高，新能源电池材料行业毛利率仅2.97%。

## 风险警告
**核心风险在于盈利质量与现金流的双重困境。** 公司2025年归母净利润扭亏为盈，但扣非净利润仍亏损9593万元，盈利高度依赖出售黄磷产能指标等非经常性损益，主业造血能力依然薄弱。同时，新能源业务规模扩张导致应收账款激增，经营活动现金流净额由正转负至-2.32亿元，现金循环周期拉长，财务压力显著。

**新产业扩张面临产能消化与价格波动的双重考验。** 磷酸铁锂产能利用率仅39.52%，远低于行业平均水平，而公司规划“十五五”末产能达40万吨，产能消化风险巨大。锂电材料行业仍处产能出清阶段，产品价格波动剧烈，叠加碳酸锂等原材料价格波动，新业务盈利前景存在较大不确定性。
