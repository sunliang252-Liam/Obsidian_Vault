## 因果逻辑链
- **[纯碱、工业盐价格大幅下跌]** -> [归母净利润骤降74.59%]: 行业供需失衡，纯碱价格处于近年低位，直接侵蚀公司核心利润来源。
- **[煤炭采购成本下降 + 精益管理降本]** -> [营业成本降幅小于收入降幅]: 集采优势与极致降本行动部分对冲了产品价格下跌的负面影响，但未能扭转毛利率下滑趋势。
- **[控股收购美特新材（钴酸锂）]** -> [新增“新能源”业务板块]: 公司从单一盐化工向“盐+新能源”双轮驱动转型，钴酸锂量价齐升，成为新的利润增长点。
- **[纯碱产能扩张（衡碱项目）]** -> [在建工程大幅增加，资本开支压力持续]: 衡碱项目进入关键建设期，虽为未来增长奠基，但短期内占用大量资金，且面临行业产能过剩风险。
- **[下游需求疲软（玻璃冷修、甲烷氯化物减产）]** -> [纯碱、烧碱销量承压]: 核心下游行业开工率不足，导致公司主要化工产品需求萎缩，库存高企。
- **[联碱法工艺优势 + 区位布局]** -> [制碱成本相对可控]: 联碱法副产氯化铵，且生产基地贴近华南、西南消费市场，运输成本低于北方纯碱企业，形成一定成本护城河。
- **[品牌价值提升 + 中高端食盐增长]** -> [食盐业务毛利率提升]: 品牌力（184.99亿）和健康化产品（低钠盐）升级，使食盐业务在行业下行中保持韧性，毛利率逆势增长。

## 风险警告
**核心风险：纯碱行业产能严重过剩，价格持续低迷。** 2025年纯碱价格已处于近年低位，但供给端天然碱和联碱法新增产能仍在释放，而下游玻璃等行业需求疲软，供需再平衡周期可能远超预期。公司纯碱毛利率同比骤降16.55个百分点，若价格继续下行或长期低位徘徊，将直接导致公司主业持续亏损，现金流恶化。

**战略转型风险：新业务尚处培育期，短期难以对冲周期下行。** 公司通过收购美特新材切入钴酸锂赛道，虽当前量价双增，但该业务高度依赖钴原料进口（刚果金），且下游3C消费电子需求波动大。同时，衡碱项目、未来纤维研究院等重大投资尚需大量资金投入，短期内无法贡献利润，反而加剧了公司的财务压力和经营不确定性。
