# 600929.SH 深度透视

## 因果逻辑链
- **[纯碱、工业盐价格大幅下跌]** -> [归母净利润骤降74.59%]: 行业供需失衡，纯碱价格处于近年低位，直接侵蚀公司核心利润来源。
- **[煤炭采购成本下降 + 精益管理降本]** -> [营业成本降幅小于收入降幅]: 集采优势与极致降本行动部分对冲了产品价格下跌的负面影响，但未能扭转毛利率下滑趋势。
- **[控股收购美特新材（钴酸锂）]** -> [新增“新能源”业务板块]: 公司从单一盐化工向“盐+新能源”双轮驱动转型，钴酸锂量价齐升，成为新的利润增长点。
- **[纯碱产能扩张（衡碱项目）]** -> [在建工程大幅增加，资本开支压力持续]: 衡碱项目进入关键建设期，虽为未来增长奠基，但短期内占用大量资金，且面临行业产能过剩风险。
- **[下游需求疲软（玻璃冷修、甲烷氯化物减产）]** -> [纯碱、烧碱销量承压]: 核心下游行业开工率不足，导致公司主要化工产品需求萎缩，库存高企。
- **[联碱法工艺优势 + 区位布局]** -> [制碱成本相对可控]: 联碱法副产氯化铵，且生产基地贴近华南、西南消费市场，运输成本低于北方纯碱企业，形成一定成本护城河。
- **[品牌价值提升 + 中高端食盐增长]** -> [食盐业务毛利率提升]: 品牌力（184.99亿）和健康化产品（低钠盐）升级，使食盐业务在行业下行中保持韧性，毛利率逆势增长。

## 风险警告
**核心风险：纯碱行业产能严重过剩，价格持续低迷。** 2025年纯碱价格已处于近年低位，但供给端天然碱和联碱法新增产能仍在释放，而下游玻璃等行业需求疲软，供需再平衡周期可能远超预期。公司纯碱毛利率同比骤降16.55个百分点，若价格继续下行或长期低位徘徊，将直接导致公司主业持续亏损，现金流恶化。

**战略转型风险：新业务尚处培育期，短期难以对冲周期下行。** 公司通过收购美特新材切入钴酸锂赛道，虽当前量价双增，但该业务高度依赖钴原料进口（刚果金），且下游3C消费电子需求波动大。同时，衡碱项目、未来纤维研究院等重大投资尚需大量资金投入，短期内无法贡献利润，反而加剧了公司的财务压力和经营不确定性。

**公司简介（F10 原文）**

> 雪天盐业集团股份有限公司(以下简称“雪天盐业”),成立于2011年12月16日,是全国盐行业第一家产销一体、跨省联合的现代股份制公司,成立以来专注于盐及盐化工产品的研发、生产、销售。2018年3月26日,雪天盐业(股票代码:600929)在上海证券交易所挂牌上市,被誉为“中国盐改第一股”。雪天盐业拥有湘衡盐化、湘澧盐化、重庆湘渝盐化(索特盐化)、江西九二盐业、河北永大、雪天技术等6家国家食盐定点生产企业,主要产品为食用盐、工业盐、芒硝、纯碱、氯化铵、烧碱、双氧水等,总产量超800万吨/年。营销网络遍布全国并积极布局“一带一路”沿线国家和地区市场,设有6家湖南省内区域性公司、9家省外区域性分公司,产品远销东亚、东南亚、非洲等地。经过多年发展,雪天盐业形成了企业为主体、市场为导向、产学研相结合的科技创新体系,建立了一支具有创新能力的科技人才队伍,积累了深厚的技术优势,建有盐改后首家省级工程技术研究平台“湖南省井矿盐工程技术研究中心”,打造“湖南省专家工作站”“单杨院士创新团队雪天食品工作室”等技术研发平台。持续加强技术创新,“石灰烟道气二氧化碳卤水净化技术”“高效制盐专用阻垢剂的研发及推广应用”等成为国内井矿盐行业原创性核心技术。2023年,雪天盐业获评国务院国资委“双百企业”并评为优秀等级。雪天盐业以“匠心”传承优品,研发出生态井矿盐、生态海湖盐、海藻碘盐、活水盐、岩晶盐、绿色精制盐等系列中高端食盐,于2021年4月30日推出中国盐行业首个高端副品牌“松態997”,开启了中国盐行业高品质发展新时代。“雪天”入选“民族品牌”,连续多年上榜“中国品牌500强”,全国质量、服务、信誉放心承诺品牌等多项荣誉,雪天盐成为杭州亚运会官方指定食用盐、中国烹饪协会比赛指定用盐。同时,雪天盐业旗下日化盐品牌“盐家”也入选为湖南省知名品牌。雪天盐业秉承“融化自我、造福社会”的企业精神,“十四五”期间,以实现“新三大转变”为战略目标,围绕盐打造涉盐食品制造、盐矿开采和盐穴利用、纯/烧碱制造并不断延伸产业链,力争成为链主企业,建设成为国内一流盐业集团,走向国际市场,推进品牌全球化。
