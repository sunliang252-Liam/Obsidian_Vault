# 000510.SZ 深度透视

## 因果逻辑链
- **[氯碱行业产能过剩，需求疲软]** -> [营收下降18.53%]: 主导产品PVC树脂价格低位震荡，销量下滑16.88%，导致收入大幅减少。
- **[电力成本高企，成本优势丧失]** -> [主营产品毛利率恶化]: 电力综合价格逐年上涨，作为电石法PVC企业，成本端压力持续加大，PVC毛利率为-24.65%。
- **[PVC产品严重亏损]** -> [归母净利润巨亏2.3亿元]: 核心产品PVC树脂毛利率为负，叠加资产减值损失1.28亿元，导致公司陷入深度亏损。
- **[战略转型，布局矿业]** -> [投资活动现金净流出大幅增加]: 公司全力推进广西栗木矿业采选冶项目建设，导致投资活动现金净流出1.37亿元，同比增加689%。
- **[子公司金路高新停产]** -> [计提大额资产减值损失]: 子公司持续亏损停产，公司对相关固定资产、存货等计提减值准备1.28亿元，严重侵蚀利润。
- **[电石渣资源化项目投产]** -> [固废处理成本降低]: 募投项目投产，实现固废资源化利用，为公司循环经济产业链提供支撑，但短期未能扭转主业亏损。
- **[栗木矿业增资扩股]** -> [缓解项目资金压力]: 通过增资实现股权融资2.35亿元，专项用于采矿、选矿、冶炼项目建设，为转型提供资金保障。

## 风险警告
公司当前面临的核心风险是**主业持续失血与转型项目尚未贡献收益的“青黄不接”困境**。氯碱行业产能过剩、需求疲软，公司核心产品PVC树脂毛利率已跌至-24.65%，主营业务的造血能力严重不足。同时，公司正全力向矿业转型，但栗木矿业项目尚处建设期，投资金额大、回报周期长，短期内无法弥补主业的巨额亏损，导致公司连续三年亏损，净资产持续缩水。

此外，**转型项目本身存在重大不确定性**。矿业项目后续建设所需审批手续仍在办理中，且对专业技术要求高，存在建设进度不及预期的风险。矿产品价格易受宏观经济和市场供需影响而波动，项目未来收益存在较大不确定性。公司目前资产负债率已升至52.2%，若转型项目无法如期达产达效，公司的持续经营能力将面临严峻考验。
