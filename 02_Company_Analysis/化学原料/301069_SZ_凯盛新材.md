# 301069.SZ 深度透视

## 因果逻辑链
- **[下游需求复苏]** -> [营收增长10.58%]: 农药板块复苏及芳纶国产替代加速，带动公司主要产品出货量显著提升。
- **[原材料价格波动]** -> [毛利率改善]: 主要原材料价格波动，但公司凭借成本转嫁能力和工艺优势，使羧基氯化物毛利率同比提升6.48个百分点。
- **[技术补偿款]** -> [非经常性损益大增]: 收到3000万元技术补偿款，计入营业外收入，是归母净利润同比大增129.28%的关键非经常性因素。
- **[循环经济工艺]** -> [成本优势]: 二氧化硫分离循环利用技术，将下游副产物返回上游使用，降低生产成本并提升环保效益。
- **[产能利用率分化]** -> [业绩弹性受限]: 核心产品氯化亚砜产能利用率99.05%，但芳纶聚合单体仅53.50%，PEKK仅2.52%，高附加值产品产能爬坡缓慢。
- **[可转债转股]** -> [资本结构优化]: 报告期内“凯盛转债”大量转股，导致总股本增加，同时资产负债率从31.51%大幅降至12.48%。
- **[LiFSI需求增长]** -> [电池级氯化亚砜机遇]: 新型锂盐LiFSI产业快速扩张，带动高端电池级氯化亚砜需求，公司作为核心供应商受益。

## 风险警告
**核心风险在于新业务兑现不及预期。** PEKK产能利用率仅2.52%，尚处于市场开拓和产能爬坡阶段，持续亏损。同时，可转债募投的“10000吨/年锂电池用新型锂盐项目”已被暂缓实施，显示公司在新能源材料领域的战略推进受阻，未来增长引擎存在不确定性。

**周期性风险与成本压力并存。** 公司主要原材料液氯、硫磺等价格波动剧烈，报告期内原材料2采购单价同比上涨89.83%。虽然公司具备一定成本转嫁能力，但若上游价格持续高企或下游需求转弱，毛利率将面临显著压力。此外，公司安全生产费用实际使用仅占应计提额的47%，存在潜在合规与安全风险。
