# 600423.SH 深度透视

## 因果逻辑链
- **[双氧水市场价格低迷]** -> [营收与利润双降]: 2025年双氧水市场均价同比下降13.54%，公司产品售价随之下滑，导致营收同比下降16.67%，净利润由盈转亏。
- **[区域竞争加剧，区位优势减弱]** -> [运费上升，毛利率承压]: 当地造纸和新能源客户被竞争对手分流，公司被迫将销售转向贵州等偏远地区，运输距离拉长，运费上升，整体毛利率被挤压。
- **[产量下降导致单位成本上升]** -> [成本刚性，利润侵蚀]: 2025年公司27.5%双氧水产量同比下降8.25%，固定成本分摊增加，单位产品成本上升，进一步压缩了本已微薄的利润空间。
- **[计提长期经营性资产减值]** -> [利润大幅亏损]: 公司对鹿寨分公司资产组计提固定资产、在建工程等减值准备3,740.18万元，是导致全年净利润亏损2,571.25万元的核心原因之一。
- **[产品单一，依赖双氧水]** -> [业绩波动性极高]: 公司仅生产双氧水一个产品，业绩完全取决于双氧水市场的价格和供需，缺乏多元化对冲风险的能力，导致业绩随行业周期剧烈波动。
- **[氢气采购依赖单一关联方]** -> [供应链风险与成本锁定]: 公司主要原材料氢气全部向关联方广西柳化氯碱采购，受限于氢气运输特性，供应商单一，虽价格稳定，但缺乏议价能力和替代选择。
- **[资本公积与盈余公积弥补亏损]** -> [净资产结构优化，但未分配利润仍为负]: 公司使用16.52亿元资本公积和0.89亿元盈余公积弥补历史亏损，使未分配利润从-20.69亿元大幅减亏至-3.54亿元，但累计亏损依然巨大，无法分红。

## 风险警告
**核心风险：退市风险警示（*ST）已成定局。** 公司2025年营业收入仅1.37亿元，远低于3亿元红线，且净利润亏损，已触发《股票上市规则》第9.3.2条规定的退市风险警示条件。2026年若不能实现盈利或营收达标，将面临终止上市风险。公司自救措施（如技改、开拓高纯双氧水、寻找战略投资者）均存在重大不确定性，时间紧迫。

**经营风险：行业供需格局持续恶化。** 双氧水行业产能过剩，供需差值仍在扩大，价格长期承压。公司作为小型单一产品企业，在行业巨头（尤其是配套下游的己内酰胺、造纸企业）的挤压下，缺乏成本与规模优势。其区位优势正在被竞争对手侵蚀，高纯双氧水转型尚在初期，难以在短期内扭转颓势。公司账面虽有4.3亿元货币资金，但多为历史遗留，无法掩盖其主营业务造血能力已近枯竭的现实。
