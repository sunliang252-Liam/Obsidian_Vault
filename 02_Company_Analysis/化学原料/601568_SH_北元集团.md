# 601568.SH 深度透视

## 因果逻辑链
- **[PVC价格大幅下跌]** -> [营收与利润双降]: 2025年PVC平均售价同比降低14.38%，直接导致公司营收下降11.31%，归母净利润暴跌53.09%。
- **[原料成本下降]** -> [部分对冲产品跌价损失]: 主要原料电石、原煤采购价格分别下降14.07%和22.91%，使营业成本降幅（-13.55%）大于营收降幅（-11.31%），毛利率反而微增0.79个百分点。
- **[烧碱业务量价齐升]** -> [成为利润核心支柱]: 烧碱营收同比增长7.29%，毛利率高达63.84%，同比提升4.35个百分点，有效弥补了PVC业务的巨额亏损。
- **[循环产业链一体化]** -> [构筑低成本护城河]: “煤-盐-发电-电石-氯碱-水泥”的完整闭环，使公司吨PVC耗折标电石等8项关键消耗指标达到行业领先，在行业低谷期仍能维持盈利。
- **[出口规模扩大]** -> [缓解内需疲软压力]: 聚氯乙烯出口量同比增加2.38万吨，境外营收增长28.96%，但境外毛利率为负（-0.45%），显示出口以价换量。
- **[黄金租赁产生公允价值损失]** -> [侵蚀非经常性损益]: 报告期交易性金融负债（黄金租赁）公允价值变动损失4907万元，是导致扣非净利润（1.17亿）高于归母净利润（1.08亿）的主要原因。
- **[第四季度巨额亏损]** -> [全年业绩雪上加霜]: 第四季度归母净利润为-1.05亿元，表明年末产品价格或成本端出现极端不利情况，拖累全年表现。

## 风险警告
**核心风险在于PVC行业的结构性过剩与公司盈利能力的脆弱性。** 公司110万吨PVC产能利用率高达124%，但该产品毛利率为-6.76%，处于严重亏损状态。国内PVC行业产能持续扩张（2025年净增137万吨），而下游房地产需求疲软，行业开工率仅74%，大量企业亏损。公司作为电石法PVC龙头，虽有一体化成本优势，但在全行业过剩背景下，PVC业务已成为业绩的主要拖累，且短期内看不到反转迹象。

**财务风险体现在高分红与低盈利的严重背离。** 公司2025年归母净利润仅1.08亿元，却计划分红1.99亿元，分红比例高达183%。这种“吃老本”式的分红不可持续，且消耗了宝贵的现金流。同时，公司对关联方（陕煤集团体系）的采购依赖度极高，前五名供应商中关联方采购额占比达45.35%，存在供应链集中风险与潜在的关联交易定价不公允风险。此外，锦源分公司因市场低迷停产消缺，电石产能利用率仅3.47%，显示公司部分资产已实质闲置。

> 陕西北元化工集团股份有限公司(简称“北元集团”,股票代码:601568)是由陕煤集团、民营企业、自然人股东和员工持股平台共同组建的大型化工企业,致力于现代化工产品的研发与生产,构建起“煤、原盐、兰炭、电石、电、聚氯乙烯、烧碱、水泥”一体化循环产业链和“精细化工+绿色材料”的低碳、高效、绿色化工产品产业链,实现了经济效益、社会效益和环境效益的有机统一。北元集团凭借资源、规模、循环产业链、区位、体制与品牌优势,实现了高质量跨越式发展。具备110万吨/年聚氯乙烯、80万吨/年离子膜烧碱、4×125MW煤电、300兆瓦光伏发电、220万吨/年新型干法工业废渣水泥、50万吨/年电石的生产能力。持续推进“三品”战略,形成北元特色产品序列体系,产品出口网络覆盖亚洲、非洲、南美洲、欧洲等80个国家和地区。北元集团于2020年成功登陆资本市场,迎接新能源革命浪潮,围绕现有产业绿色转型、未来产业绿色发展,打造“绿色企业”,在建设美丽中国的宏伟蓝图中贡献北元力量。公司连续多年入围中国石油和化工企业500强,先后荣获全国五一劳动奖状、国务院国企改革“双百行动”优秀企业、国家循环经济标准化试点企业、全国安全文化建设示范企业、全国和谐劳动关系创建示范企业、工信部“绿色工厂”、陕西省智能制造试点示范企业、陕西省先进集体等荣誉。“北元”商标被评为“陕西省著名商标”,“北元”牌聚氯乙烯和高纯氢氧化钠被评为“陕西省名牌产品”。物华聚北,天人和元。站在高质量发展的新起点,北元集团聚焦国家“3060”双碳目标,积极贯彻新发展理念,深耕化工主业,发展新兴产业,加速资本赋能,为打造现代一流化工企业不懈奋斗。
