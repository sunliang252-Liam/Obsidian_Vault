# 600618.SH 深度透视

## 因果逻辑链
- **[双基地协同与一体化产业链]** -> [营收利润双增]: 上海基地依托化工区上下游管道输送，广西基地贴近华南及东南亚市场，两地协同实现烧碱满产满销，在行业价格波动中仍实现归母净利润9.56%增长。
- **[烧碱高毛利对冲PVC亏损]** -> [整体盈利稳定]: 烧碱毛利率高达50.45%，同比提升3.77个百分点，有效弥补了聚氯乙烯（PVC）业务-17.90%的负毛利，成为公司利润的核心压舱石。
- **[广西钦州三期项目大规模投资]** -> [在建工程激增与现金流压力]: 在建工程同比暴增257.27%至46.94亿元，主要投向HPPO及聚醚多元醇项目，导致投资活动现金净流出高达22.61亿元，远超往年。
- **[财务费用转负与利息收入大增]** -> [资金管理优化]: 财务费用从正1.83亿元转为负0.83亿元，主要得益于利息收入同比大增149%至1.24亿元，显示公司通过多元融资和资金调度有效降低了资金成本。
- **[PVC行业供需严重失衡]** -> [产品价格承压]: 国内PVC产能过剩，地产需求疲软，导致公司PVC产品营收同比下降20.6%，毛利率为负，成为拖累整体营收下滑4.45%的主因。
- **[烧碱出口大幅增长]** -> [缓解国内过剩压力]: 2025年国内烧碱出口量同比大增33.61%，公司灵活布局出口市场，有效消化了国内产能，支撑了烧碱价格和销量。
- **[关联交易与集团内部协同]** -> [稳定经营与成本控制]: 公司与上海华谊集团内企业存在大量关联交易（如向亨斯迈销售氯产品、向赛科采购乙烯），这种一体化模式保障了原料供应和产品销售，但同时也带来了关联交易风险。

## 风险警告
**核心风险在于PVC业务的持续巨亏与巨额资本开支的回报不确定性。** 公司PVC产品毛利率已跌至-17.90%，且行业供需矛盾在2026年取消出口退税后预计将进一步加剧，该业务可能持续侵蚀烧碱带来的利润。同时，广西钦州三期项目（HPPO、聚醚等）投资额巨大，在建工程已近47亿元，项目能否在2026年顺利投产并实现预期效益，是未来两年业绩的关键变量，存在投产即亏损或回报不及预期的风险。

**此外，公司面临行业周期下行与政策变动的双重压力。** 烧碱和PVC行业均处于供过于求的宽松格局，价格竞争激烈。印度对华PVC反倾销税、国内取消PVC出口退税等政策，将直接打击公司出口业务，加剧国内市场竞争。公司虽通过一体化产业链和双基地布局构建了护城河，但在行业整体下行周期中，其盈利能力的可持续性面临严峻考验。
