# 002092.SZ 深度透视

## 因果逻辑链
- **[甲醇项目全面投产]** -> [营收结构优化]: 2025年6月100万吨/年甲醇项目全面投产，新增甲醇收入5.98亿元，成为氯碱化工之外的第二增长极，对冲了PVC价格下行压力。
- **[精细化管理降本]** -> [毛利率改善]: 通过电石单耗优化、低热值煤替代、国产化离子膜等举措，氯碱化工毛利率同比提升2.13个百分点至22.75%，有效对冲了产品价格下跌。
- **[出口市场拓展]** -> [销量增长]: 依托新疆区位优势，PVC出口量同比增长12.57%，出口收入同比大增89.40%，填补了国内房地产需求下滑的缺口。
- **[资产减值与投资损失收窄]** -> [大幅减亏]: 归母净利润亏损2.89亿元，同比减亏70.43%，核心驱动是资产减值损失和联营企业投资损失同比大幅减少。
- **[粘胶纤维产销两旺]** -> [纺织业务改善]: 粘胶纤维销量同比增长35.16%，收入增长30.78%，纺织工业毛利率同比提升2.24个百分点，经营状况显著改善。
- **[以销定产模式]** -> [库存管理优化]: 建立“以销定产”机制，粘胶纱库存量同比下降14.79%，减少了资金占用和跌价风险。
- **[绿电直连与能源结构优化]** -> [成本优势巩固]: 推进绿电直连，优化能源结构，在电石法PVC成本竞争中进一步巩固了相对于乙烯法PVC的成本优势。

## 风险警告
公司虽大幅减亏，但核心主业PVC仍处于周期低谷，毛利率仅8.54%，且库存量同比暴增110.27%，显示下游需求复苏乏力。纺织业务虽改善，但粘胶纤维毛利率下滑3.21个百分点，行业供大于求格局未变。公司资产负债率高企，担保总额占净资产比例高达115.85%，财务杠杆风险突出。

更严峻的是，公司治理风险尚未完全出清。控股股东与美克化工的BDO同业竞争问题承诺于2026年解决，但方案仍在论证中，存在不确定性。同时，公司仍面临投资者索赔诉讼，历史遗留的法律纠纷可能带来额外的财务冲击。
