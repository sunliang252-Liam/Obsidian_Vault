# 000635.SZ 深度透视

## 因果逻辑链
- **[主营产品价格持续低迷]** -> [连续三年巨亏]: PVC、E-PVC价格低位运行，导致公司2025年归母净利润亏损5.54亿元，连续第三年亏损。
- **[电石法PVC成本劣势]** -> [市场竞争力下降]: 乙烯法工艺占比提升，电石法成本优势被削弱，公司26万吨/年产能低于行业平均，开工率仅74%。
- **[房地产行业需求疲软]** -> [PVC销量与价格双杀]: 下游型材、管材等建筑领域需求不振，PVC价格全年下跌约12%，公司PVC收入同比下降13%。
- **[计提大额资产减值]** -> [加剧亏损]: 报告期内计提固定资产减值准备1.5亿元，是导致亏损同比扩大的重要原因。
- **[自备电厂与产业链协同]** -> [部分对冲成本压力]: 通过“谷段深调、平峰段满发”策略降低用电成本，但无法完全抵消产品价格下跌的影响。
- **[向特定对象发行股票]** -> [缓解现金流压力]: 2025年8月完成定增，募集资金6.84亿元，用于电石技改等项目，补充流动资金。
- **[经营活动现金流持续为负]** -> [财务风险高企]: 连续三年经营性现金流净额为负，2025年为-4.54亿元，公司依赖融资维持运营。

## 风险警告
公司已连续三年巨额亏损，2025年归母净利润亏损5.54亿元，且经营活动现金流持续为负（-4.54亿元），造血能力严重不足。主营产品PVC、烧碱价格长期低位运行，叠加电石法工艺成本劣势，公司基本面短期内难以逆转。尽管通过定增获得6.84亿元资金，但若产品市场无根本性好转，现金流断裂风险依然存在。

公司面临严重的市场竞争风险。作为电石法PVC企业，产能规模（26万吨）低于行业平均，在乙烯法工艺占比持续提升的冲击下，成本优势被削弱。下游房地产需求疲软，行业供需矛盾突出，产品价格易跌难涨。公司产品结构单一，对市场波动高度敏感，缺乏有效的利润增长点。
