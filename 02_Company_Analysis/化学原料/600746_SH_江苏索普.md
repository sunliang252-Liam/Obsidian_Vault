# 600746.SH 深度透视

## 因果逻辑链
- **[醋酸行业产能扩张]** -> [产品价格下滑]: 2025年醋酸行业新增产能较多，供需失衡，公司主要产品醋酸市场售价同比大幅下滑，导致营收同比下降8.53%。
- **[原材料煤炭价格下降]** -> [成本降低]: 报告期内，公司主要原料化工煤价格同比下降17.3%，动力煤价格同比下降22.5%，有效对冲了产品售价下跌的部分影响。
- **[主要装置安排大修]** -> [产销量下降]: 报告期内公司对主要生产装置安排了大规模检修，导致醋酸及衍生品产销量同比分别下降4.94%和4.70%。
- **[技改与降本增效]** -> [成本优化]: 公司通过技术改造、优化运行管理等措施，主要产品成本较上年度下降，营业成本同比下降5.23%，但降幅小于收入降幅。
- **[醋酸毛利率大幅收窄]** -> [利润承压]: 醋酸及衍生品毛利率同比下降5.95个百分点至3.72%，是归母净利润同比大幅下降58.62%的核心原因。
- **[在建项目投入增加]** -> [资本开支扩张]: 醋酸乙烯及EVA一体化项目（一期工程）进入全面建设阶段，导致投资活动现金净流出7.89亿元，同时新增长期借款6.93亿元。
- **[碳排放配额交易]** -> [额外收益]: 公司参与全国碳市场交易，售出37万吨碳排放配额，获得一定收益，体现了碳资产管理的价值。

## 风险警告
**核心风险在于行业景气度持续下行与巨额资本开支的错配。** 醋酸行业产能快速扩张，供需失衡加剧，产品价格持续承压，公司核心产品毛利率已降至极低水平（3.72%）。与此同时，公司正全力推进总投资32.26亿元的醋酸乙烯及EVA一体化项目，2025年资本开支大幅增加，导致自由现金流为负，并大幅新增长期借款。若行业景气度未能如期回暖，新项目投产后可能面临效益不达预期的风险，进一步加重财务负担。

**原材料价格波动与安全环保风险不可忽视。** 公司主要原料煤炭价格虽在报告期内下降，但其波动性直接影响成本控制。同时，公司作为煤化工企业，面临严格的环保安全监管，碳排放权交易也增加了运营成本。任何非计划停车、安全事故或环保违规，都可能导致生产中断和巨额罚款，对经营稳定性构成直接威胁。
