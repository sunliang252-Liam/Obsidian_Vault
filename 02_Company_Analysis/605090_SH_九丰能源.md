# 605090.SH 深度透视

## 因果逻辑链
- **[“海气+陆气”双资源池战略]** -> [扣非净利润逆势增长0.89%]: 长约气锁定核心成本，陆气（含权益气）对冲现货价格波动，在营收下降8%背景下维持核心利润稳定。
- **[长约资源匹配终端客户]** -> [天然气吨毛利提升]: 长约气主要供给工业/园区终端，通过价格联动机制实现稳定顺价，毛利率同比提升4.16个百分点。
- **[LPG双库动态运营体系]** -> [华南市场领先地位巩固]: 收购华凯石油燃气后，东莞+广州双库协同，LPG销量超204万吨，单吨毛利保持稳定。
- **[商业航天特燃特气先发优势]** -> [特种气体毛利率跃升至47.53%]: 海南项目投运并连续9次保障火箭发射，高壁垒、高附加值业务成为利润新增长极。
- **[新疆庆华二期项目投资]** -> [构建“权益气+长约气+现货气”完整资源池]: 持有50%权益（年产20亿方），填补西部权益气短板，形成“西部有气，东部有海”格局。
- **[LNG重卡市场爆发]** -> [交通燃料需求驱动天然气业务增长]: 2025年天然气重卡销量创历史新高（+11.25%），公司精准卡位LNG加注环节，销量保持平稳。
- **[能源物流服务资产运营]** -> [船舶运力服务贡献稳定现金流]: 3艘大型LPG船舶对外服务，故障停航率<1%，虽受坞修影响，但仍是高毛利（30.86%）的稳定收益来源。

## 风险警告
**核心风险在于商誉减值与大型项目投资不确定性。** 截至2025年末，商誉账面价值高达15.75亿元，主要来自森泰能源、华凯石油燃气等收购。若被收购标的未来业绩不达预期，将面临大额商誉减值风险，直接冲击利润表。同时，新疆庆华二期煤制气项目（总投资巨大）处于在建阶段，存在建设周期长、审批环节多、市场需求变化等不确定性，若投资回报不及预期，将拖累整体资产回报率。

**另一重大风险是汇率波动与衍生品交易风险。** 公司大量采购以美元计价，2025年财务费用因美元贬值导致的汇兑损失同比暴增673%，对净利润形成显著侵蚀。尽管公司开展套期保值，但若国际能源价格或汇率发生超预期波动，或操作不当，衍生品头寸可能产生大额损失，直接影响盈利稳定性。此外，LPG现货销售规模下降、气电市场受气价倒挂影响收缩，也反映出公司对国际气价波动的脆弱性。
