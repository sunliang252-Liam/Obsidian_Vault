# 300727.SZ 深度透视

## 因果逻辑链
- **[原材料价格下行]** -> [毛利率提升]: 主要原料DMC、三甲单体等价格持续走低，成本降幅大于售价降幅，推动综合毛利率同比提升1.96个百分点。
- **[差异化产品结构]** -> [盈利韧性]: 聚焦电子化学品、化妆品硅油等高附加值产品，避开常规品红海竞争，化妆品硅油近三年收入CAGR达47.53%，支撑利润增速（+24.66%）远超收入增速（+6.21%）。
- **[新兴领域布局]** -> [打开成长天花板]: 浸没式冷却液、液冷算力方案、电子级MM等新品切入新能源、AI算力赛道，从传统纺织化学品向高景气领域延伸。
- **[产能扩张与爬坡]** -> [规模效应释放]: 8kt/a胶黏剂及35kt/a有机硅项目于2025年转固并进入爬坡期，新增产能为未来销量增长提供基础，但短期折旧增加压制利润。
- **[股权激励绑定]** -> [业绩目标牵引]: 2025年新推限制性股票激励，2025-2027年净利润目标分别为1.11/1.25/1.42亿元，将核心团队利益与盈利增长深度绑定。
- **[出口退税政策变化]** -> [海外业务承压]: 自2026年4月1日起，核心出口产品“初级形状聚硅氧烷”取消出口退税，若无法提价传导成本，将直接侵蚀境外业务利润（境外收入占比26%）。

## 风险警告
**核心风险在于出口退税政策突变与产能消化压力。** 2026年4月起，公司主要出口产品（占境外收入主体）将取消增值税出口退税，直接增加出口成本。若无法通过提价向下游传导，境外业务毛利率将显著承压，而境外收入占比超26%，对整体盈利影响不容忽视。同时，2025年两大募投项目刚转固，新增折旧与摊销已在报表中体现，若下游需求增速放缓或新产品市场开拓不及预期，产能利用率不足将导致固定成本吞噬利润。

**另一风险是原材料价格反弹与行业竞争加剧。** 公司2025年利润增长高度依赖原材料价格低位运行。若DMC等核心原料价格回升，而产品售价因竞争激烈无法同步上调，毛利率将面临双向挤压。此外，有机硅深加工行业常规品竞争充分，公司虽以差异化产品构建壁垒，但若竞争对手在电子化学品、化妆品硅油等细分领域突破技术瓶颈，公司的高毛利护城河可能被削弱。
