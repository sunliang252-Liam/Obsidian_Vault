# 603266.SH 深度透视

## 因果逻辑链
- **[汽车电子业务增长]** -> [营收结构优化]: 汽车电子控制类零部件收入同比增长3.90%，毛利率提升2.73个百分点，对冲了模具和电工电器业务的下滑。
- **[原材料价格下降]** -> [成本改善]: 主要塑料粒子PA、PP、PC、PBT采购价格同比下降2.51%至10.72%，直接材料成本降低，支撑扣非净利润同比增长3.23%。
- **[新项目定点放量]** -> [未来收入增长储备]: 全年获得222个新项目定点，其中185个与新能源汽车相关，涵盖IGBT模块、热管理集成式液冷水板等，为后续增长奠定基础。
- **[收购苏州豪米波]** -> [产业链延伸与战略转型]: 控股收购4D毫米波雷达公司，从精密零组件供应商向智能感知部件集成商升级，切入智能驾驶、低空经济等新赛道。
- **[泰国基地投产]** -> [全球化供应能力提升]: 泰国生产基地实现批量生产，有助于满足国际客户订单，分散地缘政治风险，开拓海外市场。
- **[研发投入聚焦]** -> [技术壁垒构建]: 研发投入占营收4.77%，成功攻克0.1mm电机定子薄壁注塑等技术，强化在IGBT功能承载模块等高复杂度嵌塑件领域的领先优势。
- **[客户集中度高]** -> [经营稳定性与议价风险并存]: 前五大客户销售额占比49.66%，与博泽、博世、日立等全球Tier1巨头深度绑定，保障订单稳定，但也面临客户降价压力和长结算周期。

## 风险警告
**核心风险在于并购整合与商誉减值。** 公司以约2.32亿元控股苏州豪米波，切入竞争激烈的4D毫米波雷达赛道。该领域技术迭代快、市场格局未定，且标的公司当前盈利能力存疑。若业务协同不及预期或下游智能驾驶需求放缓，将面临巨大的商誉减值风险，直接冲击利润表。

**传统主业增长乏力与下游压价压力。** 公司2025年营收同比下滑3.12%，归母净利润下滑3.71%，增长主要依赖扣非净利润的微增。汽车行业“内卷式”竞争导致客户持续要求降价、延长结算周期、提高票据结算比例，公司应收账款和应收票据合计占总资产比例高达31.6%，现金流压力不容忽视。电工电器业务收入同比大幅下降16.42%，显示传统业务板块承压。
