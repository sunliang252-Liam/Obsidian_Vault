# 601339.SH 深度透视

## 因果逻辑链
- **[越南产能占比78%]** -> [归母净利润增长59.96%]: 越南基地凭借区位优势和贸易便利化条件承接海外订单，规避贸易壁垒，实现净利润6.42亿元，同比增长27.38%，成为利润核心引擎。
- **[主动调整定价策略]** -> [销量同比增长7.59%]: 下半年以价换量，有效对冲下游需求疲软，实现销量环比持续增长，产能利用率维持高位。
- **[偿还高息负债，优化债务结构]** -> [财务费用同比下降47.72%]: 银行借款规模同比大幅减少，利息支出显著下降，直接增厚利润。
- **[原料采购成本下降]** -> [毛利率提升4.15个百分点]: 直接材料成本同比下降8.49%，叠加产能利用率提升摊薄单位成本，棉纺行业毛利率从9.15%提升至13.30%。
- **[研发费用缩减32.55%]** -> [扣非净利润暴增178.99%]: 公司优化研发资源配置，聚焦核心技术，非重点项目投入减少，在收入微降的情况下，成本费用端大幅改善。
- **[越南百隆贡献主要利润]** -> [国内子公司普遍亏损]: 越南百隆净利润6.42亿元，而淮安新国、淮安百隆等国内子公司合计亏损约3000万元，国内产能盈利能力承压。
- **[高比例现金分红]** -> [估值修复至每股净资产以上]: 2025年全年累计现金分红比例达91%，叠加业绩增长，推动公司股价修复至每股净资产以上，改变长期破净局面。

## 风险警告
**核心风险在于对单一海外生产基地的过度依赖与地缘政治不确定性。** 公司78%的产能集中于越南，虽然规避了中美贸易摩擦的直接冲击，但将鸡蛋放在一个篮子里。越南盾对美元汇率的大幅波动（导致其他综合收益亏损4.4亿元）、越南电价上调（燃料动力成本增长18.38%）、以及未来美国对越南加征关税的风险，都可能对公司的成本结构和盈利能力造成重大打击。一旦越南的贸易优势（如CPTPP、EVFTA）被削弱，公司将面临巨大的经营压力。

**其次，公司面临“增收不增利”的潜在困境与国内业务拖累。** 尽管归母净利润大幅增长，但营业收入同比微降1.02%，增长主要来自成本压缩和财务费用减少，而非主营业务的量价齐升。同时，国内子公司普遍亏损，显示公司在国内市场的竞争力正在减弱。若未来棉花价格反弹或下游需求持续低迷，公司通过“以价换量”和“降本”来维持利润的空间将十分有限，盈利增长的可持续性存疑。
