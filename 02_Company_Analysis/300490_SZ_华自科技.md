# 300490.SZ 深度透视

## 因果逻辑链
- **[锂电池智能装备订单爆发]** -> [营收增长28.69%]: 子公司精实机电连续斩获宁德时代、赣锋锂业等头部客户大额订单，带动该业务收入同比暴增158.27%，成为营收增长的核心引擎。
- **[行业价格内卷与毛利率承压]** -> [持续亏损]: 新能源行业竞争加剧，主营产品遭遇价格战，综合毛利率水平不高，导致公司虽减亏但未能扭亏为盈。
- **[海外项目因地缘政治延期]** -> [业绩拖累]: 国际政治、经济、军事形势复杂，部分海外项目实施进度未达预期，影响了收入确认和利润释放。
- **[应收账款减值准备激增]** -> [侵蚀利润]: 随着业务规模扩大，应收账款余额增长，计提的信用减值损失达7129万元，成为利润的主要减项之一。
- **[存货大幅增加]** -> [资金占用与跌价风险]: 存货账面价值较期初增长42.8%至19.25亿元，主要系在产品增加，占资产总额28.61%，带来较大的资金占用和存货跌价风险。
- **[经营性现金流显著改善]** -> [经营质量提升]: 经营活动现金流净额由负转正，从-4.6亿元大幅改善至4664万元，主要得益于销售回款增加和应付项目增长。
- **[研发聚焦固态电池与AI]** -> [技术壁垒构建]: 研发固态电池热压夹具、高压构网型储能变流器及“共工”水利大模型，为未来技术迭代和新兴市场布局奠定基础。

## 风险警告
公司虽实现减亏，但核心盈利能力依然薄弱。连续两年扣非净利润巨额亏损（-2.71亿、-4.19亿），且母公司未分配利润为-9658万元，表明公司尚未走出经营困境。主要风险在于：新能源行业价格内卷持续，导致综合毛利率长期低位徘徊，难以覆盖高昂的期间费用；同时，应收账款和存货合计高达31.6亿元，占总资产近47%，巨额的资金占用和潜在的减值风险是悬在利润表上的达摩克利斯之剑。

此外，海外业务虽增长迅猛（同比+393%），但地缘政治风险高企，项目执行进度存在不确定性，可能再次拖累业绩。公司高度依赖头部锂电客户（前五大客户销售占比53.48%），客户集中度风险显著。尽管在手订单充足，但能否高效转化为高质量利润，并有效管控坏账和存货跌价，是决定公司能否真正走出亏损泥潭的关键。
