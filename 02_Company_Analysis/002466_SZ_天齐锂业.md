# 002466.SZ 深度透视

## 因果逻辑链
- **[锂精矿定价机制优化]** -> [业绩扭亏为盈]: 控股子公司文菲尔德缩短化学级锂精矿定价周期，大幅减弱了与锂化工产品销售定价的时间错配，使生产成本贴近市场价，毛利空间修复。
- **[参股公司SQM业绩大增]** -> [投资收益大幅增长]: SQM 2025年度净利润同比增长，公司按21.90%持股比例确认的投资收益显著增加，成为利润核心支柱。
- **[澳元兑美元走强]** -> [汇兑收益增加]: 报告期内澳元持续走强，导致以美元计价的负债产生汇兑收益，财务费用同比大幅下降125.10%，直接增厚利润。
- **[资产减值损失减少]** -> [净利润同比改善]: 2024年公司计提了巨额资产减值损失，2025年减值规模大幅收窄，是净利润从亏损转为盈利的关键非经营性因素。
- **[锂产品价格低位运行]** -> [营收同比下降]: 尽管销量增长，但锂化合物及衍生品销售价格较上年同期下降，导致营业收入同比下滑20.80%。
- **[格林布什矿成本优势]** -> [锂矿业务高毛利]: 依托全球成本最低的锂辉石矿，锂矿业务毛利率维持在52.88%，是公司最稳定的利润来源。
- **[奎纳纳项目爬坡缓慢]** -> [海外产能释放不及预期]: 一期氢氧化锂项目目标运行效率仅稳定在50%铭牌产能，技术改造和产能爬坡进度慢于预期，持续拖累整体盈利。

## 风险警告
**核心风险在于SQM控制权丧失与税务诉讼的双重不确定性。** SQM与智利国家铜业公司（Codelco）的合伙协议已生效，自2031年起SQM将失去阿塔卡马盐湖核心锂业务的控制权，公司作为第二大股东的战略价值和投资收益面临根本性侵蚀。同时，公司就此事提起的诉讼已被智利最高法院终审驳回，维权路径基本关闭。此外，2021年IGO交易的税务审查仍在进行，澳大利亚税务局初步意见可能产生约1.7亿澳元的潜在税款，虽公司认为支付可能性低于50%，但一旦落地将对现金流和利润造成重大冲击。

**经营层面，产能爬坡与价格波动构成双重压力。** 奎纳纳一期氢氧化锂项目长期处于低效爬坡状态，江苏张家港3万吨项目也刚进入爬坡期，新增产能的效益释放存在显著不确定性。锂化工产品价格虽在2025年下半年反弹，但行业产能过剩格局未改，价格波动剧烈。公司经营活动现金流净额同比下降46.70%，显示在价格低位时造血能力有所减弱。若锂价再次下行，公司可能面临存货减值、项目收益不及预期的连锁风险。
