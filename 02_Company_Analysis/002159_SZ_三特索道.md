# 002159.SZ 深度透视

## 因果逻辑链
- **降本增效与财务结构优化** -> **归母净利润逆势增长**: 在营收下降7.81%的背景下，通过精细化运营压缩成本、将有息负债降至历史最低，有效对冲了收入下滑对利润的侵蚀。
- **核心盈利项目（梵净山、华山、珠海）贡献稳定** -> **利润基本盘稳固**: 三大索道项目合计贡献净利润约2.0亿元，占总盈利项目利润的77%，是公司穿越行业波动的压舱石。
- **亏损项目大幅减亏（崇阳项目减亏51.53%）** -> **整体利润改善**: 通过聚焦细分市场、严控成本费用及资产减值损失减少，亏损项目合计减亏约1,682万元，直接增厚了归母净利润。
- **游客消费日趋谨慎与行业竞争加剧** -> **营收同比下降7.81%**: 客单价下降、同行降价促销及极端天气频发，导致整体游客量和收入承压，尤其是华山、海南猴岛项目客流下滑明显。
- **海南猴岛项目受台风及市场遇冷双重打击** -> **业绩显著下滑**: 游客量同比减少约34万人次，营收下降14%，净利润下降31%，成为拖累公司整体表现的最大单一项目。
- **珠海索道公司通过强力营销与二消拓展** -> **净利润连续三年两位数增长**: 自营电商年售门票超40万张，强化渠道掌控力，成功实现逆势增长，验证了精细化运营与IP打造的有效性。
- **历史信息披露问题（立案调查）** -> **审计报告被出具带强调事项段的无保留意见**: 因涉嫌信披违规被证监会立案调查，虽尚未正式处罚，但已构成重大不确定性，影响市场信心与公司治理评级。

## 风险警告
**核心风险在于历史信披违规的“达摩克利斯之剑”**。公司及原实控人因涉嫌信披违规被立案调查，2026年3月已收到《行政处罚事先告知书》，拟罚款合计超2000万元。虽然罚款金额对当前利润影响有限，但此事暴露了公司过往治理的严重缺陷，且最终处罚决定尚未落地，可能引发后续的投资者索赔，对品牌声誉和再融资能力造成长期负面影响。

**经营层面，公司面临“量价齐跌”的结构性挑战**。营收连续两年下滑，核心原因并非单一，而是消费降级、行业竞争内卷、极端天气频发等多重因素叠加。华山、海南等主力项目客流下滑明显，而亏损项目虽有减亏，但尚未扭亏，资产包袱依然沉重。公司能否在行业“内卷”中通过产品创新和精细化运营持续提升“质价比”，是未来增长的关键。
