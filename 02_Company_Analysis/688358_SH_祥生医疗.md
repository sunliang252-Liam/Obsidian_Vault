# 688358.SH 深度透视

## 因果逻辑链
- **[深度全球化布局]** -> [海外收入占比极高，对冲国内集采风险]: 公司境外收入占比超90%，通过在美国、德国、新加坡等地设立子公司及海外供货基地，构建了“全球研发、全球注册、全球营销、本地服务”的四维体系，有效规避了单一市场政策波动风险。
- **[全系产品通过欧盟MDR认证]** -> [获得进入欧洲高端市场的“通行证”]: 2025年公司全系列产品一次性通过欧盟医疗器械新规MDR认证，标志着公司产品合规标准与国际巨头并轨，为渗透欧美公立医院等高端市场扫清关键准入障碍。
- **[AI技术深度嵌入产品（SonoAI + CHISONPilot）]** -> [从“卖设备”向“设备+服务”生态转型]: 公司自研SonoAI系统实现自动导航、识别、测量与辅助诊断，并推出AI伙伴CHISONPilot，将AI从设备功能延伸至服务生态，构建了“硬件+软件+服务”的闭环商业模式，提升了客户粘性与产品附加值。
- **[高研发投入（17.09%）与底层技术突破]** -> [构建“卡脖子”技术护城河]: 公司持续高强度研发，攻克了高性能探头、剪切波弹性成像、全域动态聚焦等核心技术，并累计拥有681项知识产权，形成了从材料到算法、从硬件到AI的全链路技术壁垒，尤其在掌上超声领域位列全球第一梯队。
- **[与盖茨基金会等国际组织合作]** -> [开辟中低收入国家蓝海市场]: 公司获得盖茨基金会210万美元资助，用于开发创新型产科及乳腺超声设备。此举不仅验证了公司技术实力，更打开了全球中低收入国家数亿人口的巨大市场缺口，有望成为新的增长极。
- **[经销为主的销售模式与低销售费用率]** -> [产品力强，渠道管理高效]: 公司以经销模式为主（收入占比82.22%），销售费用率仅12.51%，为同行业最低。这反映出公司产品具备强大的市场竞争力，无需高额营销投入即可实现销售，同时也体现了公司对经销商网络的优秀管控能力。
- **[汇率波动导致财务费用大幅增加]** -> [短期利润承压]: 2025年财务费用因汇兑损失增加39.08%，直接导致归母净利润同比下降17.09%。公司收入以美元结算为主，人民币汇率波动成为影响短期业绩的核心变量。

## 风险警告
**核心风险在于业绩对海外市场和美元汇率的双重依赖。** 公司境外收入占比超过90%，且以美元结算。2025年利润下滑的直接原因就是汇兑损失。若未来人民币持续升值或海外主要市场经济需求放缓，公司营收和利润将面临显著压力。虽然全球化布局是公司的核心优势，但也使其暴露于地缘政治、贸易摩擦和汇率波动的“敞口”之下。

**另一风险是AI商业化落地的不确定性。** 公司虽在AI超声领域投入巨大并取得技术领先，但AI功能（如SonoAI、CHISONPilot）目前更多是提升产品竞争力的“加分项”，尚未形成独立的、可量化的收入来源。从“设备智能化”到“服务收费化”的商业模式跃迁，需要时间验证市场接受度和付费意愿。若AI功能无法有效转化为收入和利润，高额的研发投入将侵蚀公司盈利能力。
