# 000042.SZ 深度透视

## 因果逻辑链
- **[行业深度调整与销售萎缩]** -> [营收下降39.99%]: 全国商品房销售面积同比下降8.7%，公司销售金额从151亿降至84.71亿，直接导致房地产收入锐减41.72%。
- **[存货跌价准备激增]** -> [净利润巨亏9.02亿]: 计提存货跌价准备9.84亿元，主要集中于惠州、东莞等区域项目，反映市场下行中资产价值重估压力。
- **[处置子公司获取投资收益]** -> [非经常性损益扭亏]: 出售物业子公司100%股权实现投资收益约2.07亿元，使归母净利润亏损同比收窄55.43%。
- **[预售资金回笼强劲]** -> [经营现金流净额54.4亿]: 综合回款率达93%，合同负债从72.3亿暴增至140亿，预售模式使现金流入远高于利润确认。
- **[融资规模收缩与利息支出下降]** -> [财务费用减少45.22%]: 融资净偿还规模增加，期末融资余额78.36亿，利息支出从6.99亿降至3.96亿。
- **[区域收入结构剧变]** -> [四川地区收入暴增478.76%]: 成都锦城湖岸二期项目结转，四川收入占比从3.72%跃升至35.89%，弥补广东地区收入下滑。
- **[资产减值吞噬利润]** -> [资产减值损失占利润总额101%]: 9.84亿减值准备几乎等于全年亏损总额，显示核心资产质量恶化是亏损主因。
- **[少数股东亏损扩大]** -> [合并净利润亏损加剧]: 少数股东损益-2.51亿，较上年-4.81亿有所收窄，但子公司层面亏损仍在持续。

## 风险警告
**核心风险：资产质量持续恶化与流动性压力并存。** 公司连续三年巨亏（2023-2025年累计亏损约47.7亿），净资产从57.4亿骤降至23.3亿，跌幅达59%。存货跌价准备高达52.7亿，占总存货账面余额的22.5%，惠州、东莞等非核心区域项目减值风险仍未出清。同时，控股股东中洲集团所持52.63%股份中，79.3%已质押、20.7%被冻结，实控人黄光苗为香港居民，存在控制权不稳定风险。

**融资风险：债务结构短期化与再融资压力。** 虽然短期借款为零，但一年内到期的非流动负债22.2亿，而货币资金中受限资金3205万，可用资金约63.7亿。公司融资渠道高度依赖银行贷款（100%），且融资成本区间3.8%-7.6%偏高。2025年筹资活动现金净流出29.6亿，显示外部融资环境持续收紧。公司为商品房承购人提供按揭担保余额106.65亿，若市场持续下行，或有负债风险不容忽视。
