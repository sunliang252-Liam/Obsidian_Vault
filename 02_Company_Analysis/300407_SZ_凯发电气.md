# 300407.SZ 深度透视

## 因果逻辑链
- **[德国铁路基础设施投资持续增长]** -> [境外子公司RPS营收与订单创新高]: 德国联邦政府设立5000亿欧元基础设施基金，RPS作为本土龙头，2025年新签订单3.67亿欧元（+26.5%），在手订单6亿欧元，营收增至2.41亿欧元。
- **[国内轨道交通“增量建设+存量运维”并重]** -> [国内营收稳步增长]: 高铁新线投产与既有线路设备更新改造需求释放，公司国内新增订单8.65亿元，在执行合同16.30亿元。
- **[RPS业务结构优化与成本管控]** -> [境外业务毛利率小幅提升]: 供电业务板块扭亏为盈，综合毛利率和营业利润率均有提高，支撑境外整体毛利率稳定在19.08%。
- **[国内城轨项目毛利率显著下滑]** -> [整体归母净利润同比下降25%]: 城轨业务毛利率同比下降6.24个百分点，叠加国内市场竞争加剧，导致营收增长但利润反向下滑。
- **[经营活动现金流大幅改善]** -> [现金储备充足]: 2025年经营性现金流净额5.22亿元（+107.5%），主要系货款回收大幅增加，期末货币资金12.08亿元，为研发与扩张提供资金保障。
- **[研发投入聚焦自主可控与柔性直流]** -> [巩固技术壁垒与开辟新增长点]: 研发费用1.29亿元（+18.66%），完成智能直流断路器、新一代自主可控综自系统、柔性直流供电系统等核心技术突破，并在天津津静线、北京18号线实现商业运营。
- **[战略布局新能源与智慧教育]** -> [培育第二增长曲线]: 新设凯发中特（新能源储能）和凯育智航（智慧教育），并战略投资欧力配网（配电网自动化），拓展业务边界。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化。** 尽管营收增长21.42%，但归母净利润同比下降25.03%，扣非净利润下降24.33%。主要拖累来自国内城轨业务，其毛利率骤降6.24个百分点，反映出国内市场竞争白热化导致项目盈利能力被严重侵蚀。若该趋势持续，即便营收规模扩大，公司整体利润中枢仍可能下移。

**第二大风险是境外业务对单一市场的深度依赖及潜在的人才流失。** 公司72%营收来自境外（主要为德国），且德国RPS在接触网领域市占率超30%。但报告明确指出，德国铁路为达成建设目标正从本土企业挖角核心人员，可能引发关键人才流失和薪资螺旋上涨，直接威胁项目执行与成本控制。同时，地缘政治动荡可能削减欧盟基础设施预算，构成系统性风险。
