# 601566.SH 深度透视

## 因果逻辑链
- **[加盟渠道收缩与DTC转型]** -> [营收下降6.48%]: 公司主动将45家加盟店转为直营，并关闭83家低效加盟店，导致加盟收入骤降24.63%，拖累整体营收。
- **[金融资产公允价值变动收益大增]** -> [净利润增长67.10%]: 报告期内持有的股票、基金等金融资产公允价值变动收益达1.24亿元，是净利润增长的核心驱动力，掩盖了主业扣非利润的下降。
- **[扣非净利润下降33.67%]** -> [主业盈利能力承压]: 剔除金融资产波动后，核心服装业务因营收下滑导致扣非净利润大幅减少，显示主业经营质量恶化。
- **[存货周转天数增至335天]** -> [运营效率下降]: 销售下滑导致库存消化放缓，存货周转天数同比增加19天，占用了大量营运资金，增加了跌价风险。
- **[直营店收入增长7.44%]** -> [渠道结构优化初显成效]: 通过收回加盟店和关闭低效门店，直营店收入实现增长，表明DTC转型在提升单店质量方面取得一定进展。
- **[销售费用率维持高位]** -> [品牌投入与营收增长不匹配]: 尽管营收下降，销售费用仅微降6.08%，费用率高达43.8%，显示品牌推广和渠道建设投入刚性，侵蚀利润。
- **[经营活动现金流净额大增59.98%]** -> [现金流改善源于回款管理]: 公司加强回款和费用管控，经营性现金流显著改善，但主要得益于营运资本管理，而非销售增长。
- **[商誉全额计提减值]** -> [历史并购项目风险出清]: 对FUN品牌等相关的商誉全额计提1087万元减值，表明过往的多元化并购未能带来预期回报，风险正在释放。

## 风险警告
**主业失速与金融依赖的双重风险。** 公司2025年净利润增长完全依赖于金融资产的公允价值变动，而核心服装业务营收下滑、扣非净利润大幅下降。这种“金融输血”模式不可持续，一旦资本市场波动，公司将面临利润大幅回撤的风险。同时，加盟渠道的剧烈收缩和存货周转的恶化，表明其“男裤专家”战略在渠道变革中正经历阵痛，主业增长动力不足。

**高费用与低效率的运营困境。** 在营收下降的背景下，销售费用率依然高企，品牌投入未能有效转化为销售增长，反映出营销效率低下。存货周转天数长达335天，远超行业健康水平，大量资金沉淀在库存中，不仅增加了仓储和跌价损失，也削弱了公司的现金流和抗风险能力。若不能有效提升运营效率和产品周转，公司财务状况将持续承压。
