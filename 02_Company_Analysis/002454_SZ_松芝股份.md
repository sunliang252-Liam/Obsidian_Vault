# 002454.SZ 深度透视

## 因果逻辑链
- **[新能源车渗透率提升+商用车电动化]** -> [小车热管理/电池热管理产品销量大增]: 新能源乘用车渗透率达47.9%，新能源重卡销量同比+182%，直接拉动公司冷凝器(+41%)、空调箱(+36%)、独立式电池热管理系统(+50%)等核心产品产销量大幅增长。
- **[“标配+终端”双模式销售]** -> [大中型客车市场份额提升]: 既绑定比亚迪、宇通等100多家主机厂（标配），又覆盖330多家公交/客运终端客户，完成对厦门金龙空调50%股权收购，进一步巩固龙头地位。
- **[海外市场拓展+墨西哥工厂布局]** -> [境外收入增长12.64%]: 公司已进入大众、本田、福特、北美重要新能源客户等国际车企供应链，并启动墨西哥工厂建设，为海外订单放量提供产能保障。
- **[收购厦门金龙空调50%股权]** -> [长期股权投资增加+市场占有率提升]: 2025年完成收购，增加长期股权投资约9520万元，整合后将实现市场、技术、供应链协同，强化客车热管理龙头地位。
- **[研发投入持续（5.23%营收）+技术迭代]** -> [产品竞争力提升]: 完成R744/R1234yf/R290环保制冷剂系统、多合一集成控制器、双层流空调箱等96项重点产品开发，新增63项专利，支撑高端客户（奥迪、华为智界等）项目获取。
- **[降本增效+规模效应]** -> [毛利率提升+净利润大幅增长81%]: 制造业毛利率同比+3.47pct至16.53%，扣非净利润同比+157%，规模效应与内部管理优化共同驱动盈利能力显著改善。
- **[储能行业爆发式增长]** -> [电池热管理业务新增长极]: 2025年全国新型储能装机同比+85%，公司开发60-100KW大冷量储能机组，进入宁德时代、比亚迪、远景能源等头部客户供应链，形成第二增长曲线。

## 风险警告
**客户集中度与行业竞争风险**：前五大客户销售占比高达47.09%，其中第一大客户占比12.90%，第二大客户（关联方）占比11.38%，对少数大客户依赖度较高。汽车热管理行业竞争激烈，公司面临来自国内外竞争对手的降本压力，若核心客户订单流失或价格战加剧，将显著影响营收与利润。

**海外业务与关税政策不确定性**：公司正积极拓展北美、欧洲市场，墨西哥工厂尚在建设期，海外业务面临国际贸易摩擦、关税政策变化（如中美贸易战）、汇率波动及地缘政治风险。海外项目从获取订单到量产周期较长，存在预期订单无法达成的风险，且海外运营管理复杂度高，可能拖累整体盈利。
