# 002200.SZ 深度透视

## 因果逻辑链
- **[司法重整成功]** -> [净资产由负转正]: 通过资本公积转增股本、引入重整投资人、以股抵债等措施，归母净资产从-4,275万跃升至12.86亿元，资产负债率降至50.53%。
- **[债务重组收益]** -> [净利润大幅减亏]: 报告期确认债务重组收益5,210万元，是归母净利润从-8,773万减亏至-2,487万的核心驱动力，扣非净利润仍亏损8,022万。
- **[剥离亏损子公司]** -> [资产结构优化]: 将洪尧园林、通海公司等4家亏损子公司股权剥离至信托计划，出清不良资产，减少合并报表层面的亏损拖累。
- **[控股股东业务输血]** -> [营收依赖关联交易]: 前五大客户中关联方（云南交投集团下属公司）销售额占比43.20%，公司业务高度依赖控股股东体系内的高速公路绿化及配套工程。
- **[存量合同支撑]** -> [未来营收有基本盘]: 截至报告期末，剩余合同可实施金额约20亿元，为2026年营收目标（8亿元以上）提供了较为明确的订单基础。
- **[诉讼计提预计负债]** -> [侵蚀当期利润]: 因与四川易园园林集团的股权转让纠纷案，基于谨慎性计提预计负债6,457万元，是导致公司未能实现盈利的重要原因。
- **[PPP项目长期应收款]** -> [资金占用与回款风险]: 遂宁PPP项目形成大量长期应收款（8.54亿元），虽已部分竣工，但回款周期长，对公司现金流构成持续压力。

## 风险警告
**核心风险在于“重整后遗症”与“主业造血能力不足”的双重夹击。** 公司虽通过司法重整实现财务数据“洗大澡”，净资产转正，但扣非净利润连续多年为负，表明其园林绿化主业在激烈市场竞争中缺乏核心竞争力。高达5,210万元的债务重组收益是扭亏关键，这种非经常性损益不可持续。同时，因历史诉讼计提的6,457万元预计负债，以及未决诉讼（如南充代建中心案）的潜在败诉风险，随时可能再次将公司拖入亏损泥潭。

**公司业务高度依赖控股股东云南交投集团的内部资源倾斜，独立性存疑。** 超过四成的营收来自关联交易，一旦集团内部政策或投资节奏放缓，公司将面临订单断崖式下滑的风险。此外，公司虽手握20亿在手订单，但PPP项目长期应收款规模巨大，回款周期长，且存在政府付费能力变化的风险，对现金流的管理能力是检验其能否真正“涅槃重生”的关键。
