# 300975.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长30.59%]: 公司抓住AI服务器、光模块等算力基础设施机遇，向中际旭创、新易盛等核心客户销售存储、IC等主动元器件，带动网络通信行业收入同比大增81.93%。
- **[收购立功科技]** -> [产品线补强与汽车电子布局深化]: 2025年12月收购立功科技88.79%股权，新增NXP、瑞芯微等21条车规级芯片代理线，快速切入汽车电子、机器人等高端赛道，提升一站式供应能力。
- **[主动元器件占比提升]** -> [盈利结构优化]: 主动及其他电子元器件收入占比从57.06%升至60.54%，其毛利率同比提升2.39个百分点，推动整体毛利率提升1.60个百分点，净利润同比大增327.78%。
- **[规模效应与精细化运营]** -> [成本费用有效管控]: 营收增长30.59%的同时，销售费用仅增15.30%，管理费用下降1.93%，通过数字化运营（CRM、TMS、WMS）提升效率，摊薄固定成本。
- **[存货跌价准备高企]** -> [侵蚀利润]: 报告期计提存货跌价准备1.24亿元，占利润总额31.15%，反映备货采购模式下库存管理风险，是净利润与经营现金流背离的核心原因之一。
- **[上下游账期错配]** -> [经营现金流持续为负]: 原厂信用期约30天，下游客户账期90-120天，营收快速增长导致采购付款大幅攀升，经营活动现金流净流出11.09亿元，与净利润3.03亿元严重背离。
- **[供应商集中度高]** -> [供应链依赖风险]: 前五大供应商采购额占年度采购总额55.42%，其中第一大供应商占比23.16%，若合作关系变动将直接影响货源稳定性和采购成本。

## 风险警告
**核心风险在于经营现金流与净利润的严重背离。** 公司营收高速增长（+30.59%）依赖大量备货，导致经营活动现金流净流出11.09亿元，而净利润仅3.03亿元。这种“纸面繁荣”的根源是上下游账期错配（上游30天 vs 下游90-120天），一旦下游客户回款放缓或行业景气度下行，公司将面临流动性危机，需持续依赖外部融资（报告期筹资净流入20.57亿元）维持运营，财务费用同比大增50.43%。

**第二大风险是库存与商誉的双重减值压力。** 报告期存货跌价准备高达1.24亿元，占利润总额31.15%，显示备货策略下的库存管理存在显著风险。此外，收购立功科技形成大额商誉，若未来汽车电子或机器人赛道竞争加剧、整合不及预期，商誉减值将直接冲击利润表。公司需证明其库存周转效率与并购协同效应能持续改善，否则高增长难以持续。
