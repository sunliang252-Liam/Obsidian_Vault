# 600028.SH 深度透视

## 因果逻辑链
- **[国际油价大幅下跌]** -> [归母净利润同比-36.8%]: 普氏布伦特均价同比-14.5%至69.1美元/桶，导致上游勘探及开发事业部经营收益-19.2%，并引发全产业链库存减利。
- **[新能源替代加速]** -> [成品油销量同比-4.3%]: 境内成品油消费量同比-4.1%，尤其柴油-5.6%，直接冲击营销及分销事业部经营收益-46.5%。
- **[化工产能过剩]** -> [化工事业部经营亏损146亿元]: 基础石化原料产能同比+10.2%，新增消费无法消化供应压力，化工毛利持续下降，叠加部分装置减值损失。
- **[上游增储上产]** -> [油气产量当量创历史新高]: 天然气产量同比+4.0%，天然气全产业链盈利创历史新高，部分对冲油价下跌影响。
- **[炼油副产品高价值利用]** -> [炼油事业部经营收益+40.7%]: 硫磺、石油焦等副产品毛利大幅好转，抵消了进口原油采购升水和运费高位的影响。
- **[战略投资宁德时代]** -> [其他权益工具投资+1620%]: 以约35.7亿元战略投资宁德时代股权，期末公允价值增至67.1亿元，计入其他综合收益。
- **[高比例分红与回购]** -> [年度利润分派比例达81%]: 全年现金股利0.2元/股，叠加股份回购，持续强化股东回报，但高分红比例在利润下滑时可持续性存疑。

## 风险警告
**核心风险：业绩对油价高度敏感，且下行周期中盈利弹性不足。** 2025年归母净利润同比暴跌36.8%，主因是国际油价下行导致库存减利和产品价格下跌。公司作为一体化能源化工巨头，上游受益于高油价，但中下游炼化及销售业务在油价下跌时面临巨大库存损失和价差收窄压力。当前油价不确定性加大，若油价持续低迷，公司盈利将承压。

**结构性风险：新能源替代与化工产能过剩构成长期双重挤压。** 境内成品油需求已进入下降通道（2025年同比-4.1%），新能源汽车渗透率快速提升将持续侵蚀公司核心利润来源——营销及分销业务。同时，化工行业新增产能持续释放，毛利低迷，化工事业部已连续两年亏损且亏损额扩大（从-100亿至-146亿），短期内难以扭转。公司转型至“油气氢电服”综合能源服务商仍需大量资本投入，短期回报有限。
