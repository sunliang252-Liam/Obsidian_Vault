# 920627.BJ 深度透视

## 因果逻辑链
- **[出口退税政策下调]** -> [境外收入下滑12.38%]: 2024年12月起电池出口退税率由13%下调至9%，客户价格传导接受度低，订单分流，导致境外营收减少4563万元。
- **[锂电原材料价格回升]** -> [资产减值损失减少79%]: 原材料价格上涨传导至产品端，锂电产成品售价提高，存货可变现净值上升，相应计提的跌价准备大幅减少。
- **[电子烟锂电业务突破]** -> [锂离子电池收入增长63.25%]: 深化与头部电子烟客户合作，逆势突围，锂电业务营收增加3834万元，成为年度经营亮点。
- **[人民币汇率升值]** -> [财务费用增加78.36%]: 汇率波动导致汇兑损失较上年增加675万元，远超利息收入增幅，侵蚀利润。
- **[锌锰电池出口承压]** -> [碱性/碳性电池收入分别下滑4.41%/6.60%]: 全球经济放缓、外需收缩及退税政策调整双重打击，传统核心业务增长乏力。
- **[储能与小动力业务起步]** -> [其他电池收入增长135.57%]: 新赛道布局初显成效，便携储能及小动力电池销售增长1026万元，但基数小，贡献有限。
- **[原材料成本上升]** -> [综合毛利率下降1.59个百分点]: 营业成本增速(9.06%)超过收入增速(7.06%)，成本端压力未能完全传导至下游。

## 风险警告
**核心风险在于出口业务的双重挤压。** 公司境外收入占比超42%，但面临出口退税从13%分步下调至2027年全面取消的致命打击，叠加人民币升值带来的汇兑损失，锌锰电池这一基本盘正遭受结构性侵蚀。2025年境外收入已下滑12%，而退税政策将在未来两年持续恶化，若无法通过提价或降本完全对冲，利润将进一步承压。

**应收账款高企与坏账风险不容忽视。** 应收账款账面价值2.18亿元，占总资产27.68%，且公司已对多家客户提起诉讼并全额计提坏账。在电子烟行业监管趋严、部分客户经营困难的背景下，信用减值损失可能持续扩大，对现金流和利润形成拖累。此外，锂电业务虽增长迅猛，但毛利率仅2.67%，盈利能力薄弱，且高度依赖电子烟这一政策敏感赛道，增长质量存疑。
