# 300093.SZ 深度透视

## 因果逻辑链
- **[破产重整完成]** -> [净利润扭亏为盈]: 2025年完成司法重整，确认债务重组收益8.75亿元，驱动归母净利润从-7.95亿转为+2.03亿。
- **[光伏行业产能过剩与价格低迷]** -> [核心业务持续巨亏]: 光伏电池及组件毛利率-58.91%，扣非净利润-5.71亿元，主业造血能力严重缺失。
- **[重整引入18亿投资款]** -> [净资产由负转正]: 重整投资人支付18.04亿元，归母净资产从-7.95亿跃升至+20.06亿，彻底摆脱资不抵债。
- **[光伏产能利用率提升]** -> [营收大幅增长]: 产能利用率同比提升，全年光伏产品销售量738.95MW（+287%），带动营收从1.24亿增至3.01亿（+143%）。
- **[布局算力新业务]** -> [形成第二增长曲线]: 设立子公司开展算力服务，2025年确认收入662万元，开启“光伏+算力”双轮驱动。
- **[客户高度集中]** -> [经营依赖单一市场]: 前五大客户销售占比92.18%，其中第一大客户占比76.16%，存在重大客户依赖风险。
- **[研发投入大幅缩减]** -> [技术竞争力存疑]: 研发人员从191人降至81人（-58%），研发投入仅762万元，占营收2.53%，异质结降本增效进展面临挑战。

## 风险警告
**核心主业持续失血，重整红利不可持续。** 公司2025年扣非净利润为-5.71亿元，光伏业务毛利率-58.91%，意味着每卖出一瓦电池片都在亏损。8.75亿的重整收益是一次性非经常性损益，无法掩盖光伏主业在行业价格战中的惨烈处境。若异质结技术降本无法在2026年取得突破，公司仍将面临经营性现金流持续净流出的困境。

**客户集中度极高，算力业务尚在萌芽。** 公司92%的收入来自前五大客户，其中单一南亚客户贡献超76%，一旦该客户订单波动或回款出现问题，将对公司现金流造成致命打击。算力业务虽已起步，但2025年仅贡献662万元收入，占比2.2%，远不足以对冲光伏主业的亏损，双轮驱动目前仍是“一轮独行”。
