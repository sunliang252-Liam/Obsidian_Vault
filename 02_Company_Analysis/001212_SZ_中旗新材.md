# 001212.SZ 深度透视

## 因果逻辑链
- **[下游需求萎缩]** -> [营收下降21.57%]: 房地产行业调整及装修市场低迷，直接导致人造石英石板材和台面销量大幅下滑。
- **[新业务拖累]** -> [石英砂/粉业务毛利率-441%]: 广西罗城基地投产初期，产能爬坡成本高企，导致新业务严重亏损，侵蚀整体利润。
- **[控制权变更]** -> [管理层动荡与战略调整]: 2025年6月控股股东变更为星空科技，原管理层离任，新战略聚焦高纯石英砂，但新旧业务衔接不畅。
- **[可转债利息费用化]** -> [财务费用激增241.75%]: 募投项目转固后，可转债利息不再资本化，直接计入当期损益，大幅加重财务负担。
- **[非经常性损益依赖]** -> [扣非净利润亏损扩大]: 公司依赖理财收益和政府补助掩盖主业疲软，剔除后亏损额达-4621万元，真实盈利能力堪忧。
- **[募投项目停滞]** -> [资金效率低下]: “年产1万吨高纯砂项目”暂缓，“罗城一体化项目”终止，大量募集资金闲置或用于理财，未能转化为有效产能。

## 风险警告
公司正经历“主业萎缩+新业务亏损+控制权变更”的三重阵痛。人造石英石基本盘受房地产下行周期冲击，销量与价格承压；而寄予厚望的高纯石英砂新业务，因产能爬坡、技术验证及市场开拓缓慢，短期内难以贡献利润，反而成为亏损黑洞。2025年扣非净利润巨亏，经营性现金流大幅下滑72.97%，显示公司造血能力严重恶化。

控制权变更后，新控股股东星空科技（半导体设备背景）的战略意图与公司现有业务协同性尚不明确。多个核心募投项目（高纯砂、罗城项目）被暂缓或终止，表明新管理层对原有战略的否定，公司未来发展方向存在重大不确定性。此外，可转债已触发赎回并摘牌，短期偿债压力虽缓解，但财务费用已因利息费用化而飙升，若主业无法回暖，公司将持续面临流动性压力。
