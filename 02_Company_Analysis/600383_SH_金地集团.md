# 600383.SH 深度透视

## 因果逻辑链
- **[房地产行业深度调整，销售规模大幅下滑]** -> [营业收入锐减52.41%]: 公司签约金额降至300.2亿元，可结转面积减少，导致房地产开发收入同比暴跌60.20%。
- **[结转项目毛利率大幅恶化]** -> [房地产业务毛利率降至7.93%]: 前期高价地项目进入结算期，叠加市场下行，结算毛利率同比下降6.18个百分点，严重侵蚀利润。
- **[基于谨慎性原则大规模计提减值]** -> [归母净利润巨亏132.81亿元]: 公司对存货、应收款项等计提了高达90.51亿元的资产减值及信用减值损失，是亏损的核心原因。
- **[坚持“现金流为王”策略，有序压降负债]** -> [经营现金流几近枯竭，但债务结构优化]: 销售回款大幅减少导致经营性现金流同比骤降99.88%至仅0.16亿元；同时，有息负债降至670亿，银行借款占比98.6%，融资成本降至3.92%。
- **[存量资产盘活成为核心经营策略]** -> [全年落地22个盘活项目]: 通过“土地置换、商改住、存量房收储”等方式，将低效资产转化为可售资源，是维持流动性的关键手段。
- **[代建与物业服务成为稳定器]** -> [轻资产收入贡献逆势增长]: 代建业务新增签约面积同比增长59%，物业服务营收保持3.23%的正增长，部分对冲了开发业务的下滑。
- **[投资性房地产公允价值变动]** -> [非经常性损益亏损12.47亿元]: 市场下行导致持有物业估值下降，进一步拖累当期利润。

## 风险警告
金地集团2025年录得上市以来最大亏损，核心风险在于其“存量包袱”的消化能力。公司高达2472万平方米的土地储备中，大量为前期高价获取的项目，在房价持续承压的背景下，未来仍需面临持续的存货减值风险。尽管公司通过盘活存量资产维持了流动性，但房地产开发毛利率已跌至7.93%的极低水平，主业盈利能力已基本丧失，能否通过新获取的低密优质地块（如上海、杭州项目）扭转颓势，存在巨大不确定性。

更深层的风险在于公司现金流的脆弱性。2025年经营活动现金流净额仅0.16亿元，几乎完全依赖融资活动（偿还借款减少）来维持。虽然债务结构优化（银行借款占比98.6%），但670亿元的有息负债规模依然庞大，且大量资产（约389亿元）已被用于抵押借款。一旦销售市场再度转冷或融资环境收紧，公司将面临严峻的流动性危机。此外，公司连续两年未进行现金分红，对长期投资者的回报能力已降至冰点。
