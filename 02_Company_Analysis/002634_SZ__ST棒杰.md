# 002634.SZ 深度透视

## 因果逻辑链
- **[光伏业务激进扩张]** -> [巨额亏损与债务危机]: 公司2022年跨界进入光伏行业，遭遇行业产能严重过剩、价格战，导致扬州棒杰自投产起持续巨亏，最终于2025年3月停产，并引发连锁债务违约。
- **[光伏子公司停产与重整]** -> [资产巨额减值]: 扬州棒杰停产及进入重整程序，导致公司对相关固定资产、在建工程等计提约8.14亿元资产减值损失，是2025年巨亏的主因。
- **[光伏业务拖累]** -> [净资产转负]: 连续两年巨额亏损（2024年-6.72亿，2025年-9.89亿）导致公司2025年末归属于上市公司股东的净资产为-7.21亿元，触发退市风险警示。
- **[债务违约与诉讼]** -> [流动性枯竭]: 光伏板块在金融机构累计逾期或提前到期借款约9.86亿元，引发大量诉讼、银行账户冻结及资产查封，公司现金流极度紧张。
- **[控股股东变更]** -> [战略方向调整]: 2025年7月，公司控股股东变更为上海启烁，新管理层上任，核心任务从经营转向推动公司及子公司的预重整/重整，以化解债务危机。
- **[无缝服装业务稳健]** -> [经营现金流为正]: 尽管受宏观环境影响收入下滑12%，但无缝服装业务仍保持盈利，为公司贡献了正的经营现金流，是当前唯一的“造血”来源。

## 风险警告
公司当前面临的核心风险是**退市风险**。2025年末净资产为负，根据深交所规则，年报披露后公司股票将被实施退市风险警示（*ST）。同时，公司及子公司扬州棒杰均处于预重整/重整阶段，若重整失败，公司将面临破产清算及终止上市的风险。即便重整成功，公司控股股东将变更为美年大健康，主营业务和基本面将发生根本性变化，现有股东权益存在重大不确定性。

此外，公司**流动性危机已全面爆发**。光伏板块近10亿元债务逾期，大量资产被查封，诉讼缠身。虽然无缝服装业务尚能产生正向现金流，但无法弥补光伏业务的巨大窟窿。公司能否通过重整引入投资人、化解债务、使净资产转正，是决定其生死存亡的关键，但重整过程存在协议无法履行、方案未获批准等重大不确定性。
