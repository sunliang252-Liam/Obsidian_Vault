# 300412.SZ 深度透视

## 因果逻辑链
- **下游制药行业政策驱动** -> 业绩增长: 新版GMP、一致性评价、中药振兴等政策推动药企产能扩张与智能化改造，直接拉动公司口服固体制剂设备及智能工厂业务需求。
- **智能物流系统业务爆发** -> 营收结构优化: 智能仓储物流系统及装备业务营收同比增长143.97%，成为公司第二增长曲线，弥补了传统制药装备业务的增长乏力。
- **生物及无菌制剂用水设备业务稳健** -> 利润贡献稳定: 控股子公司上海凯贤在生物制剂用水及配液系统领域具备核心技术，贡献净利润1,262.85万元，是公司利润的重要稳定器。
- **研发投入聚焦连续化与智能化** -> 技术壁垒构建: 公司持续投入连续化生产、AI制药驾驶舱等前沿技术研发，旨在提升产品附加值与市场竞争力，巩固“固体制剂智能工厂整体解决方案供应商”地位。
- **经营活动现金流大幅改善** -> 财务质量提升: 经营活动现金流净额同比增长54.47%，主要系购买商品支付现金减少，表明公司回款能力增强或采购策略优化，财务风险降低。
- **非经常性损益依赖度高** -> 盈利质量存疑: 扣非净利润同比下降58.28%，仅为归母净利润的38.7%，显示公司核心主营业务的盈利能力出现明显下滑，利润增长依赖政府补助、理财收益等非持续性项目。
- **商誉减值风险释放** -> 未来业绩压力减轻: 本期计提商誉减值准备，消化了并购迦南莱米特形成的潜在风险，为未来业绩轻装上阵创造条件。

## 风险警告
**核心风险在于盈利质量恶化与增长动力不足。** 公司2025年营收同比下降10.98%，扣非净利润更是大幅下滑58.28%，表明在行业政策红利消退后，公司核心制药装备业务的增长遭遇瓶颈。尽管智能物流业务增长迅猛，但体量尚小，难以完全对冲传统业务的下滑。利润结构严重依赖非经常性损益，显示出主营业务的造血能力正在减弱。

**另一重大风险是募投项目持续延期与整合风险。** 公司核心募投项目“制药配液系统生产中心”及“医药研发服务平台”已多次延期至2026年6月，反映出项目推进不及预期，未来新增产能的释放和效益实现存在不确定性。同时，公司通过并购扩张形成的子公司矩阵，在管理、文化、业务整合上仍面临挑战，部分子公司如比逊弥特、迦楠天津持续亏损，拖累整体业绩。
