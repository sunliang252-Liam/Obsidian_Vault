# 301509.SZ 深度透视

## 因果逻辑链
- **[非含氟类CDMO业务爆发]** -> [营收与利润大幅反弹]: 非含氟类CDMO收入同比增长81.87%，毛利率提升18.40个百分点，成为2025年业绩反转的核心驱动力。
- **[医药CDMO业务结构优化]** -> [整体毛利率显著提升]: 医药CDMO收入同比增长45.54%，毛利率提升至53.46%，高毛利业务占比提升拉动了公司整体盈利水平。
- **[海外市场需求回暖]** -> [海外收入高增长]: 其他国家和地区收入同比增长40.14%，占总收入66.64%，海外大客户订单恢复是业绩增长的重要来源。
- **[技术服务收入爆发]** -> [未来项目管线储备增加]: 技术服务收入同比增长446.27%，虽体量尚小，但为后续临床期CDMO项目提供了储备。
- **[现金管理收益贡献]** -> [非经常性损益支撑利润]: 委托理财及公允价值变动收益合计约2,359万元，占净利润22.5%，对利润有显著增厚作用。
- **[存货与固定资产减值]** -> [侵蚀部分利润]: 资产减值损失1,611万元，主要来自存货与固定资产，反映出部分产品需求或生产效益不及预期。
- **[经营活动现金流强劲]** -> [盈利质量较高]: 经营活动现金流净额1.70亿元，远超净利润1.05亿元，表明公司回款能力强，利润含金量高。

## 风险警告
**核心风险在于业绩的可持续性与客户集中度。** 2025年业绩高增主要依赖非含氟类CDMO业务的爆发，该业务收入同比增长81.87%，但含氟类核心业务仅增长3.97%，增长结构不均衡。同时，前五大客户销售占比33.49%，单一客户依赖度较高（客户1占比16.48%），大订单的波动性可能对业绩造成剧烈影响。公司整体收入规模仍偏小，抗风险能力有限。

**外部环境风险不容忽视。** 公司超66%收入来自海外，面临国际贸易政策（如关税）和汇率波动的双重压力。全球创新药融资环境的不确定性，可能导致中小创新药企调整研发管线，进而影响公司临床期项目的订单稳定性。此外，公司正加大美国生产基地投入，海外扩张的进度和成本控制存在不确定性。
