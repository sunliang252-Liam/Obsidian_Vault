# 000028.SZ 深度透视

## 因果逻辑链
- **[商誉及无形资产减值损失大幅减少]** -> [归母净利润同比增长76.80%]: 2025年计提减值同比减少6.86亿元，直接释放利润空间，是净利润暴增的核心原因。
- **[零售板块（国大药房）大规模关店调整]** -> [零售板块亏损大幅收窄80.36%]: 全年关闭直营门店1,140家，人工及租金等刚性费用成本下降，叠加减值减少，亏损从-11亿缩至-2.17亿。
- **[分销板块聚焦核心区域与品种]** -> [分销业务收入微增0.64%，利润增2.94%]: 在两广核心区域加大资源投入，抢抓国谈、集采品种增量，实现稳中向好，成为业绩压舱石。
- **[医保即时结算与下游回款延迟]** -> [经营活动现金流净额同比下降49.91%]: 应收账款回笼同比减少，导致销售商品收到的现金减少，现金流质量显著恶化。
- **[零售板块统一采购与自有品牌发力]** -> [直营门店常规业务毛利率同比提升0.6个百分点]: 统采额同比增7.8%，自有品牌销售同比增48.3%，有效对冲了行业降价压力。
- **[核药业务实现从0到1突破]** -> [打开肿瘤精准诊疗新市场]: 国控广州取得《放射性药品经营许可证》，首批碳-14核药入库，构建“产-供-销-服”新模式，培育未来增长极。
- **[“港澳药械通”业务销售额同比增长102%]** -> [打通创新药械准入至国内渠道完整通路]: 协助40个药械品规准入预审库，首次实现重点新品批件追加，强化进口特色业务壁垒。

## 风险警告
**核心风险在于利润增长的高度不可持续性与现金流的急剧恶化。** 2025年归母净利润76.80%的暴增，几乎完全依赖于商誉及无形资产减值损失的同比大幅减少（减少6.86亿元），而非主营业务的强劲增长。剔除这一非经常性因素，公司核心盈利能力改善有限：分销业务利润仅微增2.94%，零售业务虽减亏但仍亏损2.17亿元。与此同时，经营活动现金流净额同比腰斩（-49.91%），直接原因是下游医院回款延迟导致应收账款激增（占总资产比例升至43.87%），这预示着公司运营效率下降，财务风险正在累积。

**零售业务（国大药房）的“瘦身”能否真正实现“健体”仍是巨大挑战。** 虽然关闭1,140家亏损门店短期内大幅减亏，但这本质上是“止血”而非“造血”。在行业存量竞争、线上冲击、医保控费（如“无码不付”、“阴阳价格”严查）的多重压力下，剩余门店的单店盈利能力提升、会员复购率增长、以及向“健康服务综合体”的转型，均面临极大不确定性。若不能有效构建差异化竞争优势，公司可能陷入“关店-收入萎缩-再关店”的恶性循环。此外，医保基金即时结算政策可能对非集采品种产生资金虹吸效应，进一步延长公司整体应收账款账期，加剧现金流压力。
