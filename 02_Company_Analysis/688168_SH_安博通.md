# 688168.SH 深度透视

## 因果逻辑链
- **[战略转型，聚焦AI算力]** -> [营收结构剧变，利润承压]: 公司从传统网络安全厂商向“AI时代安全算力生态构建者”转型，主动收缩低毛利安全产品业务，导致传统安全产品收入下降38.28%，同时智算中心等大型项目尚未完成验收，收入确认延迟，造成整体营收下滑24.54%。
- **[贸易业务激增，拉低营收质量]** -> [营收扣除额占比飙升，核心业务萎缩]: 为拓展新增长点，公司通过香港子公司开展高性能存储模组贸易业务，该业务收入达42.99亿元，占营收比例极高，但扣除后核心业务收入仅2.24亿元，同比下降61.55%，显示公司内生增长动力不足。
- **[销售费用激增，侵蚀利润]** -> [净利润大幅亏损]: 为拓展AI算力等新业务，公司大幅增加渠道咨询费，导致销售费用同比暴增72.83%至3.84亿元，远超营收降幅，是导致公司归母净利润亏损1.54亿元的核心原因之一。
- **[研发投入缩减，人员优化]** -> [短期降本，长期竞争力存疑]: 公司研发费用同比下降28.51%，研发人员从185人锐减至94人，降幅近半。此举虽在短期内控制成本，但作为技术密集型公司，研发投入的缩减可能影响其在新兴AI安全领域的技术领先性。
- **[经营活动现金流大幅流出]** -> [资金链承压]: 因新业务拓展导致支付其他现金流增加，经营活动现金流净额由正转负，从上年净流入1.57亿元骤降至净流出2.23亿元，公司资金状况显著恶化。
- **[客户集中度极高]** -> [经营风险高度集中]: 前五大客户销售额占年度销售总额71.85%，其中单一客户（客户一）贡献了58.94%的营收，主要来自安全人工智能产品业务。公司对单一客户依赖度过高，一旦合作关系生变，将对业绩造成毁灭性打击。

## 风险警告
公司正经历一场代价高昂的战略转型。从“网络安全可视化”转向“AI安全算力生态”，导致传统业务急剧萎缩，而新业务（智算中心、算力网关）尚未形成稳定收入，造成营收与利润双杀。更危险的是，公司为抢占市场，销售费用激增72.83%，远超营收降幅，叠加研发人员大幅裁减近半，这种“烧钱换市场”且“牺牲未来”的策略，使其陷入“旧业务萎缩、新业务未立、现金流枯竭”的危险境地。

公司经营质量堪忧。营收严重依赖单一客户（占比近60%）和低毛利的存储模组贸易业务，核心网络安全与AI产品收入大幅下滑。同时，经营活动现金流由正转负，巨额流出，应收账款虽因催收有所下降，但存货因项目未验收而暴增363%，资产质量恶化。这些信号表明，公司当前的盈利模式极其脆弱，且资金链面临严峻考验，投资者需高度警惕其持续经营能力。
