# 002247.SZ 深度透视

## 因果逻辑链
- **[房地产下行周期]** -> [营收下降5.47%]: 新建商品房销售面积连续下滑，直接压制了下游装饰贴面材料的需求，导致公司订单量和产品单价双降。
- **[成本控制与产品结构优化]** -> [扣非净利润增长22.88%]: 在营收下降的背景下，通过降低营业成本（-7.55%）和提升高毛利产品（PVC装饰材料、装饰纸饰面板）的销售占比，实现了核心盈利能力的逆势增长。
- **[历史诉讼和解]** -> [净利润剧烈波动]: 2024年因与北京腾讯达成执行和解冲回损失，导致当年净利润基数极高（2.18亿）；2025年无此一次性收益，净利润同比骤降77.85%，回归至正常经营水平。
- **[投资者索赔诉讼]** -> [持续侵蚀利润]: 公司因证券虚假陈述责任纠纷，累计计提预计损失5164万元，2025年仍新增计提123万元，构成持续的营业外支出，压制净利润表现。
- **[原材料价格波动]** -> [毛利率改善]: 主要原材料（原纸、三聚氰胺）价格下行，使得公司营业成本降幅（-7.55%）大于营收降幅（-5.47%），推动整体毛利率同比提升1.76个百分点。
- **[外销业务增长]** -> [对冲内销下滑]: 内销收入受房地产影响下降7.83%，但外销收入逆势增长5.50%，且外销毛利率（31.65%）显著高于内销（19.59%），成为稳定业绩的重要支撑。
- **[研发投入聚焦EB新材料]** -> [未来增长点不确定]: 公司设立子公司研发电子束（EB）固化新材料，目前处于研发阶段，尚未产生收入，能否成功商业化并贡献业绩存在较大不确定性。

## 风险警告
**核心风险在于历史遗留问题的持续拖累与主业增长乏力并存。** 公司虽已剥离文化业务，但历史担保和证券虚假陈述引发的投资者索赔诉讼仍在持续，累计已计提超过5000万元损失，且未来仍有新增索赔的可能，这对公司本就微薄的利润构成直接且持续的侵蚀。同时，母公司报表净资产为负（-2864万元），且存在未弥补亏损，导致无法进行现金分红，资本结构脆弱。

**主业面临需求萎缩与竞争加剧的双重挤压。** 公司核心的装饰纸业务与房地产周期高度绑定，在商品房销售面积持续下滑的背景下，行业需求低迷，价格竞争激烈。尽管公司通过成本控制和产品结构优化实现了扣非净利润的增长，但营收的持续下滑表明市场蛋糕正在缩小。公司能否在行业集中度提升的过程中抢占份额，以及新布局的EB新材料业务能否成功，均是未来业绩走向的关键变量，不确定性极高。
