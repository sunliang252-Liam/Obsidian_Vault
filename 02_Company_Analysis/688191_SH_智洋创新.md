# 688191.SH 深度透视

## 因果逻辑链
- **[电力行业持续投入]** -> [营收增长21.69%]: 国家电网“十五五”投资规划增长40%，公司作为输电可视化头部企业，直接受益于电网智能化投资。
- **[水利业务快速拓展]** -> [营收增长25.68%]: 公司“四预”数字孪生方案入选水利部典型案例，成功切入万亿级水利建设市场，形成第二增长曲线。
- **[内部运营费用降低]** -> [扣非净利润增长30.91%]: 公司优化薪酬体系、降低股份支付，期间费用率从27.85%降至22.81%，利润释放弹性显著高于收入增速。
- **[应收账款大幅增加]** -> [经营性现金流下降76%]: 营收增长带动应收账款增长36.2%至7.27亿元，同时采购付款增幅(28.72%)远超销售回款增幅(10.48%)，现金流承压。
- **[输电可视化市场趋于饱和]** -> [毛利率下降2.72个百分点]: 部分省份已基本实现全覆盖，市场竞争加剧导致各行业毛利率普遍下滑，公司需通过新产品维持盈利能力。
- **[具身智能无人机产品落地]** -> [打开卫星拒止空间新市场]: 发布“智洋星隼”产品，在铁路桥梁、室内变电站等场景实现工程化应用，突破传统巡检场景天花板。
- **[“电语”工业大模型通过备案]** -> [提升AI技术壁垒]: 成为少数通过国家网信办备案的工业大模型，强化了在电力、水利等垂直领域的算法护城河。

## 风险警告
**现金流恶化与应收账款高企是最大隐患。** 公司经营性现金流净额同比暴跌76%至1753万元，而同期净利润达6226万元，利润“含金量”极低。应收账款占流动资产比例高达50.88%，且增速(36.2%)远超营收增速(21.69%)，客户主要为电网公司虽信用风险较低，但回款周期拉长将严重制约公司扩张能力，若叠加下游投资节奏放缓，可能引发流动性危机。

**核心业务天花板隐现，新业务尚需验证。** 输电可视化产品覆盖率已较高，市场竞争白热化导致毛利率持续下滑。公司虽积极布局水利、轨道交通等新领域，但合计收入占比仅15.53%，且水利业务毛利率同比骤降15.32个百分点，显示新业务尚处于“以价换量”的跑马圈地阶段。若电力主业增速放缓而新业务无法快速贡献利润，公司可能陷入“增收不增利”的困境。
