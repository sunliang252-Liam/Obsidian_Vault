# 920873.BJ 深度透视

## 因果逻辑链
- **[收入结构优化与成本严控]** -> [亏损大幅收窄]: 全过程咨询和工程检测业务收入高增（+91.73%、+61.79%），同时严控人工及采购成本，营业成本仅增1.45%，毛利率从-27.35%大幅改善至-3.66%。
- **[应收账款催收与减值计提减少]** -> [信用减值损失大幅下降]: 加大回款力度，应收账款期末余额减少3,534万元，叠加上年同期一次性单项计提因素消失，信用减值损失同比少计提2,004万元（-63.96%）。
- **[研发投入合理化调配]** -> [期间费用有效控制]: 募投项目“中设智慧云平台”结项，叠加研发项目优先级调整，研发费用同比减少565万元（-40.55%），管理费用同步压缩，期间费用总额同比下降9.90%。
- **[新签合同额高增]** -> [未来收入增长蓄力]: 报告期新签合同额1.52亿元，同比增长92.26%，其中全过程咨询（+3,467.68%）、工程检测（+100.41%）、海外业务（+325.77%）均实现突破，为后续收入确认奠定基础。
- **[海外市场突破]** -> [业务版图扩张]: 以马来西亚为核心，海外新签合同额1,678万元，同比增长325.77%，并首次承接马来西亚基础设施监控业务，实现海外检测业务零的突破。
- **[存量项目恢复推进]** -> [工程检测业务收入反弹]: 2024年因政府化债停缓建的检测项目在2025年正常推进，叠加新签合同增长，工程检测业务收入同比增长61.79%，子公司中检检测大幅减亏。
- **[传统建筑勘察设计承压]** -> [业务结构转型加速]: 受房地产下行影响，建筑勘察设计收入同比大降55.37%，公司加速向城市更新、水利水环境、全过程咨询等“存量+新兴”赛道转型。

## 风险警告
公司核心风险在于**收入规模尚未恢复至盈亏平衡点**。尽管2025年营收增长24.64%，但毛利率仍为-3.66%，人工等固定成本高企，规模效应无法释放，导致持续亏损。若新签合同转化为收入的节奏慢于预期，或成本控制力度减弱，公司可能长期陷于“增收不增利”的泥潭。

**应收账款高企与客户信用风险**是另一重大隐患。应收账款账面价值高达1.2亿元，占总资产32%，且客户多为地方政府及平台公司，财政支付周期长。公司已因工程款纠纷涉及多起诉讼，涉案金额巨大。若宏观经济下行或地方财政持续紧张，坏账风险可能再次爆发，侵蚀本就脆弱的利润表。
