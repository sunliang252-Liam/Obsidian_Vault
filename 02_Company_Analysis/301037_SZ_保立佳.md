# 301037.SZ 深度透视

## 因果逻辑链
- **[下游房地产行业深度调整]** -> [营收下降21.44%]: 建筑涂料需求萎缩，公司核心产品建筑乳液和防水乳液销量下滑，导致整体营收从21.5亿降至16.9亿。
- **[原材料价格下行]** -> [毛利率改善2.64个百分点]: 丙烯酸丁酯、苯乙烯等主要原材料价格偏弱下行，降低了生产成本，使综合毛利率从10.10%提升至12.74%。
- **[强化应收账款催收]** -> [经营现金流大幅转正]: 公司加强回款管理，经营活动现金流净额从-1.71亿大幅改善至+0.60亿，缓解了流动性压力。
- **[处置亏损子公司]** -> [非经常性收益增厚利润]: 出售烟台新材料100%股权，产生约1517万元投资收益，是公司减亏的关键因素之一。
- **[行业产能严重过剩]** -> [产品价格承压]: 丙烯酸乳液市场产能约740万吨，产量仅356万吨，供强需弱格局导致主要产品价格持续走弱，压缩盈利空间。
- **[海外产能布局加速]** -> [打开长期增长空间]: 在越南、印尼、中东等地新设子公司，推进全球化战略，旨在摆脱国内红海竞争，寻找新增长点。
- **[研发费用缩减37.70%]** -> [短期降本但长期竞争力存疑]: 公司为应对亏损，大幅削减研发投入，虽有助于当期减亏，但可能削弱未来产品迭代和技术壁垒构建能力。

## 风险警告
保立佳当前最核心的风险是**行业供需失衡与下游需求持续疲软的双重挤压**。作为丙烯酸乳液头部企业，公司高度依赖建筑涂料市场，而该市场受房地产行业深度调整影响，需求复苏缓慢。尽管公司通过降本增效和处置资产实现了减亏，但营收规模大幅萎缩21.44%，且扣非净利润连续三年为负，表明主营业务造血能力依然薄弱。若下游房地产行业无法企稳回暖，公司业绩反转将缺乏根本动力。

其次，公司面临**高负债与流动性压力**。短期借款高达10.96亿元，占总资产48.11%，而货币资金仅1.77亿元，且其中1.29亿元受限。公司营运资金高度依赖银行借款，一旦原材料价格大幅上涨或客户回款进一步恶化，极易引发流动性危机。虽然2025年经营现金流有所改善，但筹资活动现金流净流出0.9亿元，显示公司偿债压力巨大，财务风险不容忽视。
