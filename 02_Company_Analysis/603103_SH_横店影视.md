# 603103.SH 深度透视

## 因果逻辑链
- **[市场回暖与头部影片驱动]** -> [票房与观影人次大幅增长]: 2025年春节档《哪吒之魔童闹海》等头部影片引爆市场，全国票房同比增长21.95%，公司直营影院票房同比增长23.07%，观影人次增长26.91%，增幅均超全国均值。
- **[“提质增效”战略与影院网络优化]** -> [影院资产质量提升与成本控制]: 公司坚持“非优质不上”原则新开10家影院，同时对长期低效影院启动退出程序，并实施降租减租、技术节能等降本措施，刚性运营成本得到有效压缩。
- **[非票业务多元化与场景创新]** -> [非票收入有效提升]: 深化“电影+美食”模式、拓展IP衍生品（如卡牌、潮玩）、孵化XR沉浸式影厅、开展“影院+电竞/球赛”等多元活动，挖掘影院空间价值，提升坪效。
- **[内容投资审慎策略]** -> [影视投资、制作及发行业务收入下滑]: 面对电影行业投资风险加剧，公司主动采取审慎策略，减少投资出品影片数量，导致该板块收入同比下降57.72%，且部分参投影片收益不达预期。
- **[重点发力短剧赛道]** -> [培育新增长点]: 公司成立“大横小竖”短剧品牌，建立从投资、制作到变现的链路体系，并布局AI短剧、AI漫剧及海外短剧合作，寻求内容业务的结构性突破。
- **[经营杠杆与成本刚性]** -> [净利润扭亏为盈]: 收入增长16.55%的同时，营业成本仅增长2.54%，毛利率提升11.58个百分点，经营杠杆效应显著，推动归母净利润从-0.96亿元扭亏至1.59亿元。

## 风险警告
**核心风险在于对头部影片的过度依赖与内容投资的不确定性。** 2025年票房增长高度集中于《哪吒之魔童闹海》等极少数爆款，中腰部影片供给严重不足，市场结构失衡。公司影视投资业务收入大幅下滑，且部分项目收益不达预期，表明上游内容投资风险加剧。若未来优质影片供给持续匮乏，公司影院放映业务的增长将难以为继。

**另一重大风险是影院物业租赁模式带来的刚性成本与续租压力。** 公司446家直营影院均为租赁物业，租赁负债高达12.28亿元，构成沉重的固定支出。随着市场竞争加剧，商业地产租金上涨及租赁到期后无法续租或续租成本增加的风险，将持续侵蚀公司利润，尤其是在票房表现不佳的季度，财务压力尤为突出。
