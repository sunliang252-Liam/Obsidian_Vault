# 688136.SH 深度透视

## 因果逻辑链
- **[海外商业化（白蛋白紫杉醇欧盟放量）]** -> [海外收入同比增长63.25%]: 白蛋白紫杉醇在欧盟27国及英国等法规市场实现销售突破，成为营收增长核心引擎。
- **[海外收入高增长]** -> [归母净利润同比增长394.17%]: 高毛利的海外收入规模效应显现，叠加国内业务稳定，推动利润大幅扭亏为盈。
- **[非经常性损益（私募基金公允价值变动）]** -> [归母净利润与扣非净利润差异巨大]: 持有私募基金公允价值上升带来约7929万元收益，占归母净利润的51%，扣非后净利润仅5583万元。
- **[研发管线推进]** -> [研发投入同比增长26.38%]: 多个创新药（GB05、GB06、长效GC）进入III期临床，资本化研发投入增加，研发费用率维持高位（16.39%）。
- **[国内集采常态化]** -> [国内营收同比略降1.44%]: 核心产品（赛若金、依普定）面临集采降价压力，国内收入基本持平，增长依赖海外。
- **[引进产品矩阵扩充]** -> [肿瘤与免疫产品收入同比增长48.45%]: 通过引进英夫利西单抗、贝伐珠单抗等20余款产品，快速丰富产品组合，贡献增量收入。
- **[H股上市推进]** -> [资本结构优化预期]: 公司积极推进H股IPO及科创债发行，旨在拓宽融资渠道，为“创新+国际化”战略提供资金支持。

## 风险警告
**核心风险在于盈利质量高度依赖非经常性损益与海外单一产品。** 2025年归母净利润1.56亿元，但扣非净利润仅0.56亿元，其中私募基金公允价值变动贡献了0.79亿元。剔除该部分及处置子公司收益后，公司主业盈利能力依然薄弱。海外收入虽增长迅猛，但高度集中于白蛋白紫杉醇一个品种，且该产品毛利率（48.17%）远低于国内业务（69.30%），拉低了整体盈利水平。若海外市场准入、竞争格局或汇率发生不利变化，业绩波动风险极大。

**研发管线的不确定性是长期隐忧。** 公司虽布局了15个在研管线，但多数仍处于临床早期（I/II期），距离商业化尚远。核心在研项目GB05（干扰素α1b吸入溶液）虽获突破性治疗认定，但作为改良型新药，市场空间存在天花板。创新药研发周期长、投入大、失败率高，持续的研发投入（16.39%）对现金流构成压力，若核心管线临床结果不及预期，将对公司估值和长期增长逻辑造成重大打击。
