# 300726.SZ 深度透视

## 因果逻辑链
- **[高可靠行业需求复苏]** -> [营收增长18.99%]: 2025年“十四五”收官，中下游项目推进提速，高可靠产品收入同比增长12.88%。
- **[非钽业务战略推进]** -> [收入结构优化]: 非钽业务收入占比达66.07%，其中单层瓷介电容/陶瓷薄膜电路收入同比+97.99%，电源模块收入同比+27.39%。
- **[民品业务切入新赛道]** -> [民品收入高增58.86%]: 子公司宏达恒芯受益于AI算力、光通信产业爆发，民品端收入同比+95.22%，成为第二增长曲线。
- **[“创业平台型”子公司孵化模式]** -> [多品类扩张]: 通过股权激励绑定核心技术人员，成功孵化20余种产品线，构建了稳健的业务结构。
- **[降本增效与规模效应]** -> [毛利率提升0.78pct]: 在营收增长的同时，综合毛利率从57.63%提升至58.41%。
- **[下游回款滞后]** -> [经营性现金流低于净利润]: 营收增长导致应收账款增加，经营活动现金流净额（3.95亿）低于净利润（4.85亿），差额约0.9亿。
- **[高可靠客户集中度高]** -> [大客户依赖]: 前五名客户销售额占比54.35%，第一大客户占比19.64%，客户集中度风险显著。

## 风险警告
**核心风险在于应收账款与存货的双重高企。** 报告期末应收账款及应收票据合计高达22.97亿元，占总资产37.36%，且客户主要为大型高可靠集团，付款周期长，导致公司经营性现金流净额（3.95亿）显著低于净利润（4.85亿），资金回笼压力巨大。若宏观环境变化导致客户付款能力下降，将直接引发大额坏账风险。

**另一重大风险是存货规模仍处高位。** 尽管公司多措并举管控，但期末存货余额仍达8.16亿元，占总资产13.27%。高可靠产品定制化程度高，若下游需求波动或型号迭代，极易产生存货减值损失，侵蚀利润。此外，公司前五大客户销售额占比超54%，客户集中度过高，单一客户订单波动将对公司业绩产生剧烈冲击。
