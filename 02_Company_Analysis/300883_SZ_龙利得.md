# 300883.SZ 深度透视

## 因果逻辑链
- **[安徽明光文化科创园项目投产]** -> [净利润亏损扩大]: 新项目处于关键建设期，产生折旧及前期投入，导致龙利得文化子公司2025年亏损2030万元，直接拖累合并净利润。
- **[商誉减值计提]** -> [资产减值损失]: 对相关商誉资产组合进行减值测试，本期计提商誉减值准备462.5万元，进一步侵蚀利润。
- **[收入增长但利润下滑]** -> [成本费用刚性]: 营业收入增长8.46%至8.85亿元，但管理费用、研发费用、财务费用分别增长24.23%、23.60%、17.64%，吞噬了收入增长带来的利润空间。
- **[经营活动现金流大幅下降]** -> [营运资金占用增加]: 经营活动现金流净额从1.29亿元骤降至1338万元，同比下降89.59%，主要系购买商品、接受劳务支付的现金大幅增加，反映存货和应收账款占用资金。
- **[高附加值产品增长]** -> [产品结构优化]: 快消包装和彩盒包装收入分别同比增长32.43%和72.76%，显示公司向高毛利、终端消费领域转型初见成效。
- **[研发投入持续增加]** -> [技术壁垒构建]: 研发费用同比增长23.60%至4169万元，研发人员增加26.04%，旨在巩固“轻量化、高强度、绿色化”的工艺技术优势。
- **[筹资活动现金流激增]** -> [资本开支扩张]: 筹资活动现金流净额同比增长229.65%至2.48亿元，主要系为龙利得文化科创园建设借入大量银行借款，公司资产负债率上升。

## 风险警告
**核心风险在于新产能释放与盈利改善的不确定性。** 公司当前陷入“增收不增利”的困境，核心拖累是安徽明光文化科创园项目。该项目2025年亏损2030万元，且尚处于建设期，未来仍需大量资本开支（投资活动现金流出2.17亿元），短期内将持续压制利润。同时，公司资产负债率上升，财务费用同比增长17.64%，偿债压力与利息负担将考验公司现金流。

**行业竞争加剧与毛利率下滑风险并存。** 包装行业CR10不足5%，同质化低价竞争激烈。公司整体毛利率仅14.22%，且快消包装、彩盒包装等高增长产品的毛利率反而同比下降约6个百分点，显示新业务拓展是以牺牲短期利润为代价。若原材料价格持续上涨或下游客户压价，毛利率存在进一步下滑风险，公司连续三年扣非净利润为负的局面难以快速扭转。
