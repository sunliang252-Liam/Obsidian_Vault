# 601126.SH 深度透视

## 因果逻辑链
- **[新能源装机高速增长]** -> [营收增长17.87%]: 风电/光伏新增装机4.4亿千瓦，带动公司新能源自动化及电力电子设备需求旺盛。
- **[电网智能化改造深化]** -> [电网自动化业务稳增]: 特高压、配网数字化、自主可控变电站改造等投资持续，巩固公司二次设备龙头地位。
- **[“源-网-荷-储”一体化推进]** -> [储能及电力电子业务突破]: 构网型储能、SVG、调相机等产品在电源侧、电网侧多场景中标，形成新增长极。
- **[海外市场双轮驱动]** -> [国际业务毛利率提升7.32pct]: 聚焦东南亚、非洲，中标大型光储及SVG项目，高毛利产品结构优化。
- **[研发投入持续高企]** -> [技术壁垒与产品竞争力]: 8.93%研发费用率，AI赋能、自主可控DCS/PLC、构网型技术等巩固行业领先地位。
- **[全产业链服务能力]** -> [智慧用电及工业自动化扩张]: 从设备商向“资源开发-装备智造-系统集成-智慧运营”转型，中标数据中心、零碳园区等大型项目。
- **[高分红政策]** -> [股东回报与市场信心]: 连续16年分红，2025年拟分红6亿元（占净利润72%），分红融资比约250%。

## 风险警告
**应收账款与合同资产减值风险**：公司应收账款及合同资产账面余额高达44.48亿元，坏账准备7.98亿元。随着业务规模扩张，信用减值损失同比大增52.3%。若下游电网客户或新能源项目回款周期拉长，或部分中小客户出现信用风险，将直接侵蚀利润。这是审计报告明确指出的关键审计事项，需持续跟踪账龄结构与坏账计提充分性。

**毛利率下行压力**：尽管营收增长，但电网自动化、电厂及工业自动化、其他产品三大板块毛利率均出现下滑（分别下降1.49、1.57、2.22个百分点）。成本端直接材料及人工费用增速（21.14%）显著快于营收增速（17.87%），反映原材料价格波动、竞争加剧及项目结构变化对盈利能力的挤压。若成本控制不力或低价竞争持续，净利率存在进一步收窄风险。
