# 603817.SH 深度透视

## 因果逻辑链
- **[水价调整与前期服务费补差]** -> [营收增长13.24%]: 子公司获政府核定批复，确认前期服务费补差收入，直接拉动水处理业务收入增长。
- **[可转债到期兑付]** -> [财务费用下降16.55%]: 2025年4月可转债到期兑付，利息支出减少，显著降低财务费用。
- **[金融资产模式项目支出减少]** -> [经营现金流暴增266%]: 上年红庙岭渗沥液项目支出较大，本年此类支出减少，导致经营活动现金流净额大幅改善。
- **[固废业务量萎缩]** -> [固废业务营收下降45.43%]: 子公司海环海滨、海资公司业务量减少，导致固废板块收入与成本双降，且持续亏损。
- **[综合技术服务业务扩张]** -> [该板块营收增长53.75%]: 环保设备系统集成和智慧水务技术服务业务收入增加，但毛利率因成本增速更快而下降。
- **[短期借款激增]** -> [资产负债结构短期化]: 为满足日常经营周转，短期借款增加221%，导致流动负债占比上升，短期偿债压力加大。
- **[应收账款与合同资产高企]** -> [资金占用与坏账风险]: 应收账款及合同资产账面价值占总资产26.52%，回款周期长，占用大量营运资金。

## 风险警告
**核心风险在于固废业务的持续亏损与资产减值压力。** 子公司海环海滨和海资公司净资产已为负值，分别亏损5592万和3144万，固废业务整体毛利率为-8.6%。若该板块无法通过业务调整或资产盘活实现扭亏，将构成持续的利润侵蚀，并可能引发进一步的资产减值。

**财务结构风险显著。** 公司短期借款激增221%至7.34亿元，而货币资金仅2.27亿元，短期偿债压力巨大。同时，应收账款及合同资产合计高达18.39亿元，占总资产26.5%，且客户主要为地方政府，回款周期受财政预算影响，存在现金流紧张和坏账风险。尽管经营现金流大幅改善，但投资活动现金流持续为负，公司仍处于资本密集扩张期，对融资依赖度高。
