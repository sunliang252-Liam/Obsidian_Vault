# 301584.SZ 深度透视

## 因果逻辑链
- **[集采政策常态化与渠道扁平化]** -> [分销业务增长19.42%]: 集采压缩流通层级，中小经销商出清，公司凭借全国网络承接上游厂商渠道管理需求，分销业务快速放量。
- **[DRG/DIP支付改革与医院控费需求]** -> [SPD业务爆发式增长153.92%]: 医院为降本增效，对医用耗材精益管理需求激增，公司SPD业务契合政策方向，成为核心增长引擎。
- **[SPD业务深化院端服务]** -> [直销业务客户黏性增强]: SPD业务嵌入医院运营流程，强化了公司与医院的合作关系，为获取更多直销配送订单奠定基础，对冲集采对直销的冲击。
- **[创新医疗器械获批加速]** -> [公司获得新增长机会]: 国家鼓励创新器械，催生商业化渠道建设需求，公司作为专业流通商承接创新产品分销，拓展了高毛利业务来源。
- **[数智化管理系统]** -> [全国一体化管理效率提升]: 自研系统实现总部对全国96家子公司的统一运营与风控，支撑了业务规模扩张下的管理精度，降低了运营风险。
- **[经营性现金流大幅改善]** -> [财务风险降低]: 公司强化资金管理，充分利用上游商业信用，经营活动现金流净额同比增长354.96%，显著改善了财务健康状况。

## 风险警告
**核心风险在于集采政策对直销业务的持续压制。** 报告期内，公司直销业务收入仅增长0.20%，几乎停滞，而分销业务增长19.42%。这表明公司正从“赚取进销差价”的直销模式，转向“赚取渠道管理服务费”的分销模式。若集采进一步扩围至更多高值耗材品类，直销业务可能面临负增长，公司整体毛利率将持续承压。

**应收账款高企与信用减值风险不容忽视。** 公司应收账款高达79.77亿元，占总资产54.07%，且信用减值损失达4492万元。医疗器械流通行业普遍存在医院回款周期长的问题，若医保支付压力加大或医院资金紧张，坏账风险可能集中爆发，侵蚀公司利润。公司虽然现金流改善，但应收账款规模仍在扩大，需警惕“纸面利润”与“真实现金”的背离。
