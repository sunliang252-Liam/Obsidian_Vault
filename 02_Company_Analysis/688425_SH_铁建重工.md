# 688425.SH 深度透视

## 因果逻辑链
- **国家水利水电投资持续高位（2025年1.28万亿元，雅鲁藏布江等重大项目开工）** -> 隧道掘进机板块新签/中标合同额下降29.59%: 虽然水利投资高位，但隧道掘进机新签合同同比大幅下降，表明行业需求结构变化或竞争加剧，也可能受项目周期影响。
- **特种专业装备板块新签/中标合同额同比增长41.02%** -> 矿山市场机械化、智能化转型升级需求释放: 公司在矿山装备领域新品（如滚刀式岩石掘进机、掘锚一体机）技术突破，叠加政策推动煤矿智能化，带动订单高增。
- **研发投入同比下降11.91%（费用化研发投入减少12.24%）** -> 营业收入基本持平，但归母净利润略有下降: 研发投入减少可能压缩成本，但利润下降主要受所得税费用增加影响，而非研发下降直接导致。
- **海外市场收入同比下降14.46%（境内下降4.01%）** -> 公司海外业务拓展受全球竞争或地缘政治影响: 境外新签/中标合同额26.25亿元，同比-14.46%，可能因海外项目推迟、竞争加剧或汇率波动。
- **轨道交通设备板块新签/中标合同额同比增长28.19%** -> 国家铁路投资创新高（9015亿元，同比+6%）及城轨网络化运营持续: 铁路和城轨建设需求拉动轨道设备订单增长，同时公司道岔产品国际化认证（EN标准）助力海外拓展。
- **掘锚一体机首次入选国家制造业单项冠军，全断面隧道掘进机三度蝉联** -> 公司在特种专业装备和隧道掘进机领域的技术领先地位巩固: 国家级奖项认证体现了公司产品在细分市场的绝对优势，有助于品牌溢价和订单获取。

## 风险警告
海外市场收入下滑（-14.46%）及掘进机新签订单大幅萎缩（-29.59%）构成短期主要风险，需关注海外竞争加剧及国内水利水电项目周期波动。研发投入下降可能影响长期技术储备，但当前研发费用率仍达8.03%，短期风险可控。汇率波动、原材料价格及地缘政治因素可能进一步冲击海外业务。
