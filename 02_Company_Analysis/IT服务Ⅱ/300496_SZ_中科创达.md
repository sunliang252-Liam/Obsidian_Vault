# 300496.SZ 深度透视

## 因果逻辑链
- **[AIOS战略深化与端侧AI落地]** -> [智能物联网业务爆发式增长133.26%]: 公司以AIOS为核心，将“AI+软件+计算架构+智能硬件”整合为Turnkey平台，推动行业手持终端、机器人、AIPC等品类规模化出货，实现软硬一体产品收入翻倍。
- **[智能物联网业务占比跃升]** -> [整体营收增长44.45%，但毛利率承压]: 物联网业务收入占比从28.70%升至46.35%，但其毛利率仅18.91%，远低于智能汽车（46.18%）和智能软件（36.60%），拉低了综合毛利率。
- **[扣非净利润大幅增长96.43%]** -> [主营业务盈利能力显著改善]: 剔除政府补助等非经常性损益后，核心经营利润从1.75亿增至3.44亿，表明AIOS战略下的产品化转型正逐步兑现利润。
- **[高研发投入资本化]** -> [短期利润平滑，但长期资产沉淀]: 研发投入占营收22.73%，其中31.53%资本化（5.57亿元），导致无形资产增至18.5亿元，若未来产品收益不及预期，存在减值风险。
- **[欧美市场收入激增137.80%]** -> [全球化布局成效显著]: 海外营收占比从36.37%提升至45.71%，主要得益于物联网产品在欧美市场的放量，但该区域毛利率同比下降19.53个百分点，显示竞争激烈。
- **[滴水AIOS与AIBOX协同]** -> [智能汽车业务稳健增长9.91%]: 通过“软硬一体”组合，为车企提供“即插即用”的端侧AI算力升级方案，推动AI大模型规模化上车，巩固了汽车业务基本盘。
- **[应收账款与存货双高]** -> [运营效率面临挑战]: 应收账款和存货合计约40亿元，占总资产近30%，且经营活动现金流净额同比下降9.74%，表明收入增长伴随资金占用增加。

## 风险警告
**核心风险在于“增收不增利”的结构性矛盾。** 公司营收增长44.45%主要依赖低毛利的物联网硬件销售（毛利率仅18.91%），而高毛利的软件许可和技术服务增速相对缓慢。这导致整体毛利率下滑，净利润增速（10.47%）远低于营收增速。若物联网业务竞争加剧或成本控制失效，利润端将持续承压。

**研发资本化与商誉构成隐性风险。** 公司研发投入资本化率高达31.53%，累计形成18.5亿元无形资产。同时，商誉余额6.04亿元。若AIOS产品化进程不及预期，或并购标的业绩不达承诺，将面临大规模资产减值和商誉减值风险，直接冲击利润表。
