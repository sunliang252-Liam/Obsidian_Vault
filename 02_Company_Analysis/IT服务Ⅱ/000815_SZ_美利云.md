# 000815.SZ 深度透视

## 因果逻辑链
- **[造纸业务关停清算]** -> [营收骤降62.4%]: 2024年底停止造纸业务，2025年造纸收入归零，总营收从9.12亿降至3.43亿。
- **[低效资产出清与费用缩减]** -> [净利润扭亏为盈]: 造纸板块关停使销售费用降88.38%、管理费用降62.65%，叠加非经常性损失大幅减少，归母净利润从-5.48亿转为+0.67亿。
- **[数据中心业务稳定增长]** -> [核心利润来源确立]: 云业务收入3.24亿，同比增4%，毛利率提升14.16个百分点至45.58%，成为公司唯一盈利支柱。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售占比98.27%，其中中国电信宁夏分公司一家占76.04%，议价能力弱，依赖度极高。
- **[生物资产减值风险]** -> [潜在资产黑洞]: 账面存货4.9亿元主要为生物资产（林木），审计师将其列为关键审计事项，减值测试依赖重大估计，存在减值风险。
- **[控股股东重整]** -> [控制权不确定性]: 控股股东中冶纸业及兴诚旺于2026年4月被法院裁定实质合并重整，可能影响公司股权结构及治理稳定性。
- **[预计负债激增]** -> [未来现金流压力]: 预计负债从0.23亿暴增至1.15亿，主要因造纸业务关停后的环保处置、员工安置等遗留义务。

## 风险警告
**核心风险在于业务空心化与客户集中度。** 公司已完全剥离造纸业务，目前仅剩数据中心和光伏两个小体量业务。数据中心收入3.24亿，但76%来自单一客户中国电信，这种“单腿走路+单一客户”的结构极其脆弱。一旦客户流失或压价，公司将失去几乎所有收入来源。同时，账面4.9亿的生物资产（林木）变现能力存疑，审计师已将其列为关键审计事项，存在大额减值风险。

**控制权风险不容忽视。** 控股股东中冶纸业及兴诚旺已被法院裁定实质合并重整，虽然目前公司运营独立，但最终重整方案可能涉及股权变动，给公司带来治理层面的不确定性。此外，公司账面仍有1.15亿预计负债，主要来自造纸业务关停后的环保修复和员工安置，这些一次性支出将持续消耗现金流，而公司目前货币资金仅2.05亿，短期借款1.5亿，财务弹性有限。

> 中冶美利云产业投资股份有限公司(简称“美利云”)于1998年5月在深交所上市,证券代码“000815”,隶属于中国诚通控股集团有限公司。2016年,美利云通过非公开发行股票募集资金19.45亿元,其中12亿元用于宁夏誉成云创数据投资有限公司增资和数据中心项目建设。目前已完成投资约14亿元,建成6栋机房,其中3栋已完成交付客户使用,成为西部上架率最高、投运规模最大、运营最集中的大型数据中心。2018年,美利云依托本地丰富的太阳能资源,大力发展清洁能源产业,以打造绿色产业链为发展目标,投资2.09亿元,建成了50MWp光伏电站。多年来,美利云高度重视环保治理及生态建设,牢固树立和践行绿水青山就是金山银山的理念,始终坚持经济效益和生态效益同步发展。从2002年开始,历经十几年,累计投入7亿余元,沿腾格里沙漠边缘建成了17.28万亩造纸速生林基地,多次获得国家相关部门赞誉。
