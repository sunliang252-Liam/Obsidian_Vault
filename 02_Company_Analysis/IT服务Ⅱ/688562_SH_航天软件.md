# 688562.SH 深度透视

## 因果逻辑链
- **[业务结构调整，提升高毛利业务占比]** -> [毛利率提升4.02个百分点]: 公司主动压缩低毛利信息系统集成业务规模（-11.24%），同时扩大高毛利的自主软件产品（+26.17%）和信息技术服务（+29.29%）收入，带动整体毛利率从20.74%提升至24.76%。
- **[加大销售投入与市场拓展]** -> [营业收入增长4.59%]: 公司调整市场布局、加强销售力量，在航天外市场（如兵器、审计、国家部委）实现体系化突破，推动总收入增至12.16亿元。
- **[强化成本控制与费用管理]** -> [亏损大幅收窄]: 在收入仅微增4.59%的背景下，通过严控费用支出（销售费用下降17.20%）、优化流程，使归母净利润从-0.82亿元大幅减亏至-0.11亿元。
- **[持续高强度研发投入]** -> [核心产品技术迭代与竞争力维持]: 全年研发投入1.58亿元（+6.78%），支撑AVPLM、神通数据库、AI中台等核心产品完成关键版本迭代，巩固了在航天军工领域的国产替代壁垒。
- **[关联交易高度依赖]** -> [收入稳定性受制于控股股东]: 向航天科技集团及下属单位的关联销售占营收46.51%，公司业绩与集团数字化投入节奏高度绑定，外部市场拓展尚不足以改变这一格局。
- **[政府补助对利润贡献显著]** -> [扣非净利润持续为负]: 计入当期损益的政府补助达5,679.52万元，远超利润总额387.45万元，剔除补助及非经常性损益后，公司扣非净利润为-1.19亿元，主业盈利能力依然薄弱。
- **[存货与应收账款高企]** -> [现金流压力与坏账风险并存]: 存货（4.96亿）和应收账款（3.97亿）合计占总资产近30%，尽管经营性现金流净额同比改善，但-0.73亿元的净流出仍显示回款与项目验收周期较长带来的资金压力。

## 风险警告
**核心风险在于对控股股东的深度依赖与主业盈利能力不足。** 公司近半收入来自航天科技集团内部，业绩增长高度依赖集团数字化预算与政策推动，外部市场拓展尚在初期，难以形成独立增长引擎。同时，扣非净利润连续两年为负（-1.19亿元），利润总额几乎完全依赖政府补助，表明公司核心软件产品与服务的市场化变现能力严重不足，一旦集团需求减弱或补贴退坡，公司将重回深度亏损。

**财务健康度面临存货与应收账款的双重挤压。** 公司存货周转慢（1.72次），未验收项目积压风险高；应收账款规模高企（3.97亿），且客户集中于航天及党政军领域，回款周期长、坏账风险不容忽视。尽管经营性现金流有所改善，但持续为负的现金流与高企的应收/存货，将限制公司研发投入与市场扩张的财务灵活性。
