# 002065.SZ 深度透视

## 因果逻辑链
- **[算力基建项目大规模中标]** -> [营收结构恶化]: 2025年累计中标算力项目近40亿元，但系统集成收入同比下降7.18%，毛利率仅12.52%，拉低整体盈利质量。
- **[技术服务收入增长]** -> [毛利率下降]: 技术服务收入同比增长9.23%，但毛利率下降4.45个百分点至30.26%，显示高附加值服务面临成本压力。
- **[经营活动现金流暴增]** -> [财务操作而非经营改善]: 经营现金流净额同比暴增311.19%至32.6亿元，主因是提升供应链金融、福费廷等筹资工具规模，导致购买商品支付的现金减少，而非主业造血能力实质性提升。
- **[金融资产公允价值变动]** -> [利润调节器]: 其他非流动金融资产公允价值变动收益1.53亿元，占利润总额27.37%，是净利润的主要支撑，但该收益不可持续。
- **[信用减值损失扩大]** -> [资产质量恶化]: 信用减值损失1.77亿元，占利润总额-31.65%，应收账款高企（68.56亿元，占总资产26.79%），回款风险持续累积。
- **[研发投入资本化归零]** -> [研发效率存疑]: 研发投入10.23亿元，资本化比例从0.09%降至0%，全部费用化处理，虽会计处理更审慎，但巨额研发投入未转化为可量化的资产或收入增长。
- **[核心子公司贡献有限]** -> [集团协同效应弱]: 两大核心子公司神州新桥（净利润9269万元）和东华医为（净利润9766万元）合计贡献净利润约1.9亿元，仅占归母净利润的40%，其余利润依赖母公司及非经常性损益。

## 风险警告
**核心风险在于“增收不增利”与“现金流幻觉”。** 公司营收129.28亿元，同比下滑2.96%，归母净利润4.77亿元，同比下滑4.49%，扣非净利润勉强增长1.62%。表面亮眼的32.6亿元经营现金流，实则是通过供应链金融工具人为压降采购支出所致，并非主业现金回流改善。同时，应收账款高达68.56亿元，信用减值损失1.77亿元，资产质量持续承压。

**第二增长曲线尚未形成，转型依赖非经常性损益。** 公司宣称向“智能算力基建服务商+行业智能解决方案提供商”转型，但智算业务本质仍是低毛利的系统集成，2025年累计中标近40亿元项目，却未能扭转营收下滑趋势。利润增长高度依赖1.53亿元金融资产公允价值变动收益（占利润总额27.37%），该收益具有极大不确定性。研发投入超10亿元全部费用化，巨额投入尚未在财务上体现为可量化的商业回报，转型成效存疑。
