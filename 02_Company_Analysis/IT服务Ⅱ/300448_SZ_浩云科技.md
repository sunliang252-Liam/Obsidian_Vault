# 300448.SZ 深度透视

## 因果逻辑链
- **[客户需求放缓与竞争加剧]** -> [营业收入下降25.51%]: 宏观经济下行导致客户IT预算收缩，同时新进入者加剧竞争，公司业务拓展未达预期，整体业务量减少。
- **[主动压缩高垫资业务]** -> [营业收入进一步下降]: 为改善现金流和资金周转效率，公司主动放弃需大额垫资的项目，聚焦回款周期短、有保障的业务，牺牲了部分营收规模。
- **[营收下降与刚性费用并存]** -> [净利润持续亏损]: 营业收入大幅下滑，但销售、管理等部分费用支出相对刚性，未能同步缩减，导致利润空间被压缩。
- **[市场竞争导致毛利率承压]** -> [盈利能力下降]: 为争夺有限市场份额，产品和服务销售单价下行，叠加成本端压力，毛利率较去年同期下降，进一步拖累盈利表现。
- **[研发投入聚焦AI与低代码]** -> [构建技术护城河]: 持续投入研发（占营收15.09%），深化“企业AI智能体+低代码平台引擎+全域数字化技术”三位一体架构，打造差异化竞争力。
- **[战略布局智慧能源]** -> [打造未来增长极]: 联合华中科技大学设立子公司华云智慧，聚焦“AI赋能灵活智能发电”，推出新一代煤电灵活性成套解决方案，开辟新赛道。
- **[经营活动现金流由正转负]** -> [现金流压力显现]: 尽管主动压缩垫资业务，但购买商品支付的现金大幅增加，导致经营活动现金流净额由上年同期5745万转为-380万，流动性管理面临挑战。

## 风险警告
**核心风险在于营收与利润的持续双杀。** 公司已连续三年扣非净利润为负，2025年营收同比再降25.51%，且主动压缩业务规模导致收入基础进一步收窄。在客户需求疲软、竞争加剧的背景下，公司“以增量稳收入”的策略面临市场有效需求不足的严峻考验，若无法快速在智慧能源等新业务上实现规模化收入，公司可能陷入“收入萎缩-费用刚性-持续亏损”的恶性循环。

**转型期的战略执行风险不容忽视。** 公司正从传统金融物联向“AI+低代码+智慧能源”多元化转型，但新业务（如能源业务）尚处起步阶段，收入贡献有限（仅占10.96%），且研发投入资本化率大幅下降，表明技术商业化进程不及预期。同时，公司面临人才流失（研发人员减少28.8%）和管理半径扩大的双重挑战，若无法有效吸引和留住核心技术人才，并适应多业务线的管理要求，转型进程可能受阻，核心竞争力存在被削弱的风险。
