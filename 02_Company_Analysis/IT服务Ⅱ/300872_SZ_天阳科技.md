# 300872.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧与大型项目交付周期延长]** -> [毛利率下滑]: 为巩固市场地位，公司承接更多大型项目，但银行客户对交付质量与合规性要求提高，导致项目周期拉长、成本增幅超收入增幅，整体毛利率下降。
- **[战略转型与人员结构优化]** -> [短期成本费用增加]: 公司进行业务转型及人员结构优化，相关成本费用增加，直接导致当期利润下降。
- **[持续加大AI、跨境支付等研发投入]** -> [研发费用率维持高位]: 为增强核心竞争力，公司研发投入率达19.19%，资本化率39.23%，大量投入尚未转化为当期利润。
- **[海外业务及新业态处于投入期]** -> [尚未产生规模利润]: 信用卡出海、航空互联网等新业务仍处于市场开拓与模式探索阶段，前期投入大，尚未贡献正向利润。
- **[商誉减值]** -> [净利润进一步承压]: 全资子公司卡洛其经营不及预期，计提商誉减值准备2,300万元，对利润产生直接不利影响。
- **[回款改善]** -> [经营性现金流为正]: 公司加大应收账款催收力度，销售回款大幅增加，使得经营活动现金流净额达1.33亿元，与亏损的净利润形成显著差异。
- **[可转债转股及赎回]** -> [财务费用大幅下降]: 报告期内可转换公司债券转股及赎回，导致计提利息减少，财务费用同比降低92.81%。

## 风险警告
**核心风险在于盈利能力的急剧恶化与战略转型的阵痛。** 公司2025年由盈转亏，扣非净利润亏损近2亿元，主因是行业竞争白热化导致核心业务毛利率下滑，同时新业务（海外、场景运营）尚处投入期，无法贡献利润。这种“存量业务失血、增量业务输血”的局面若持续，将严重侵蚀公司净资产与股东回报。

**第二重风险是高昂的研发投入与商誉减值压力。** 公司研发投入率近20%，但资本化率接近40%，若研发成果商业化不及预期，将面临资产减值的风险。此外，账面仍有近1亿元的商誉，若宏观经济或子公司经营环境恶化，存在进一步减值的可能，对利润表构成潜在冲击。
