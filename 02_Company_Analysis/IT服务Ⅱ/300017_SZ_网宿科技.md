# 300017.SZ 深度透视

## 因果逻辑链
- **[主动剥离非核心MSP业务]** -> [营收下降5.5%]: 公司为聚焦主业，主动剥离MSP等非核心业务，导致整体营收规模收缩，但业务结构得到优化。
- **[安全及增值服务收入增长18.65%]** -> [业务结构优化，毛利率提升]: 高毛利的安全业务占比从23.59%提升至29.61%，拉动整体盈利质量改善，对冲了CDN业务下滑的影响。
- **[股权激励费用大幅增加至2.44亿元]** -> [扣非净利润下降9.72%]: 2025年新一期股权激励计划导致股份支付费用同比增加1.77亿元，是侵蚀扣非净利润的核心因素。
- **[海外业务收入下降18.68%]** -> [营收结构变化]: 境外收入下降主要系剥离MSP业务所致，但剔除该影响后，公司海外CDN及安全业务保持韧性，海外收入占比仍高达49.62%。
- **[处置子公司股权及理财产品收益]** -> [归母净利润增长18.53%]: 报告期内处置绿色云图、Cloudsway等股权产生投资收益1.33亿元，叠加理财产品收益，成为归母净利润增长的主要驱动力。
- **[全球边缘节点资源（2800+）]** -> [边缘AI与安全业务的基础]: 公司全球部署的边缘节点是发展边缘计算（AI推理）和安全（SASE）的核心资产，形成了差异化竞争壁垒。
- **[大客户自建CDN趋势]** -> [CDN业务收入下降15.58%]: 互联网大客户倾向自建CDN，导致公司传统CDN业务面临量价压力，是营收下滑的另一重要原因。

## 风险警告
**核心风险在于扣非净利润的持续下滑与增长动能的切换不确定性。** 公司2025年归母净利润增长主要依赖非经常性损益（股权处置+理财收益），而扣非净利润同比下降9.72%，且CDN主业收入下滑15.58%。这表明公司传统业务造血能力正在减弱，而新业务（边缘AI、安全）虽增长迅速，但体量尚不足以完全弥补CDN下滑的缺口，且面临高额的股权激励费用摊销压力。

**海外业务与大客户依赖构成双重脆弱性。** 公司近50%收入来自海外，但海外业务受国际政治、汇率波动及地缘冲突影响显著。同时，前五大客户销售占比高达44.48%，客户集中度高，一旦核心客户自建或切换供应商，将对营收产生重大冲击。此外，公司账面持有大量交易性金融资产（52.5亿元），市场波动可能对利润产生较大扰动。
