## 因果逻辑链
- **[国家电网“十五五”4万亿投资]** -> [公司业务增长]: 电网数字化、智能化投资大幅增加，直接拉动公司数字化基础设施、电力数字化应用等核心业务订单增长。
- **[收购亿力科技，布局大数据]** -> [完善产业链，增厚收入]: 公司通过收购亿力科技，新增大数据业务板块，实现能源全链条数据服务覆盖，2025年贡献收入3.31亿元，并带来一次性非经常性收益。
- **[核心客户高度集中]** -> [业绩高度依赖单一客户]: 前五大客户销售额占比96.86%，其中国家电网及其所属公司占比95.43%，导致公司经营业绩与国家电网投资节奏和内部政策高度绑定。
- **[研发投入高增，聚焦人工智能]** -> [培育新增长极]: 2025年研发投入11.65亿元，同比增长31.64%，重点投入人工智能、数字孪生等前沿技术，成功落地配网调度智能助手、营销2.0智能生成工具等示范项目，为未来增长蓄力。
- **[亿力科技业绩承诺未达标]** -> [商誉减值风险]: 亿力科技2025年扣非净利润仅完成承诺额的48.34%，未达预期，可能引发未来商誉减值风险，侵蚀公司利润。
- **[关联交易占比极高]** -> [治理与估值折价]: 超过95%的收入来自关联方，虽然短期保障了业务稳定性，但长期看限制了公司市场化拓展能力，并导致市场给予估值折价。
- **[限制性股票激励计划连续未达标]** -> [人才激励失效]: 2021年股权激励计划第二、三个解除限售期条件均未达成，导致大量股份被回购注销，削弱了对核心人才的长期激励效果。

## 风险警告
**核心客户单一与关联交易依赖风险。** 公司超过95%的收入来自国家电网及其附属企业，客户集中度极高。尽管国家电网“十五五”4万亿投资规划为公司提供了明确增长预期，但这也意味着公司业绩与国家电网的预算、投资节奏和内部政策高度绑定，缺乏经营自主性。同时，极高的关联交易占比是公司治理的硬伤，也是市场给予其估值折价的核心原因。公司承诺在2029年前将关联交易占比降至50%以下，但实现路径尚不清晰，短期难以改变。

**业绩承诺不达标与商誉减值风险。** 2025年收购的亿力科技首年业绩承诺完成率仅为48.34%，远低于预期。这直接反映出收购标的的盈利能力或整合效果不及预期。若后续年份业绩持续不达标，公司将面临巨大的商誉减值压力，这将直接冲击利润表，并可能引发市场对公司并购整合能力的质疑。此外，公司2025年归母净利润同比下降19.47%，扣非净利润同比下降13.73%，主业增长乏力，盈利质量下滑趋势值得警惕。
