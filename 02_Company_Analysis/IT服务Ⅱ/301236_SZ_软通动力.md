# 301236.SZ 深度透视

## 因果逻辑链
- **[收购同方计算机，切入硬件赛道]** -> [营收规模跃升]: 2025年收购同方计算机（后更名软通计算机），计算产品与智能电子业务营收158.09亿元，同比+22.36%，拉动总营收突破350亿元，但硬件低毛利（4.82%）拖累整体盈利质量。
- **[“软硬一体”战略，AI全栈布局]** -> [AI相关业务营收占比过半]: 依托软件服务（IT咨询第一）与硬件制造（信创PC第一梯队）的协同，AI相关业务营收184.66亿元，占比52.6%，但该收入口径宽泛，含大量传统IT服务与硬件销售。
- **[深度绑定华为生态]** -> [核心客户依赖度极高]: 作为华为“同舟共济”伙伴及核心供应商，来自第一大客户（某大型ICT领导企业）的营收占比高达25.42%，前五大客户合计占比47.32%，客户集中度构成重大经营风险。
- **[机械革命品牌崛起，电竞PC“御三家”]** -> [消费硬件业务高增长]: 机械革命游戏本市场份额稳居行业前三，2025年Q4跃居第二，带动智能电子业务强劲增长，并成功斩获巴基斯坦10万台笔记本大单，打开海外市场。
- **[扣非净利润持续低迷，非经常性损益支撑利润]** -> [盈利质量堪忧]: 2025年扣非净利润仅4193万元，同比-42.14%，远低于归母净利润2.06亿元，利润严重依赖政府补助（1.04亿）和金融资产公允价值变动（1.02亿）。
- **[经营性现金流大幅转负]** -> [造血能力恶化]: 2025年经营活动现金流净额为-2.42亿元，同比-132.64%，主因是硬件业务扩张导致存货和应收账款大幅增加，现金循环周期拉长。
- **[研发投入资本化率提升]** -> [利润调节空间增大]: 研发投入资本化金额占净利润比重从2023年的6.34%升至2025年的30.24%，资本化处理可美化当期利润，但增加了未来摊销压力。

## 风险警告
**盈利质量与现金流双重恶化是最大隐忧。** 公司2025年扣非净利润仅4193万元，同比暴跌42%，而经营性现金流更是由正转负，净流出2.42亿元。这意味着公司核心业务的造血能力严重不足，2.06亿元的归母净利润高度依赖政府补助和金融资产变现等非经常性损益。在营收突破350亿的体量下，如此微薄的扣非利润和负现金流，暴露了“增收不增利”的典型困境，尤其是低毛利的硬件业务占比快速提升，进一步拉低了整体盈利水平。

**客户与供应商的“双集中”风险构成经营脆弱性。** 公司对第一大客户（华为）的销售占比高达25.42%，前五大客户合计占比近半；同时，前五大供应商采购额占比高达56.89%。这种高度集中的上下游结构，使公司在议价能力和经营韧性上处于弱势。一旦核心客户调整采购策略或核心供应商出现供应问题，将对公司营收和成本造成剧烈冲击。此外，公司通过收购同方计算机切入硬件赛道，整合效果尚需时间验证，商誉减值风险不容忽视。
