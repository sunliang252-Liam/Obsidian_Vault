# 300846.SZ 深度透视

## 因果逻辑链
- **[智算转型战略]** -> [收入结构优化]: 智算云业务收入同比增长61.08%，占总收入比例从5.2%升至23.8%，成为核心增长引擎。
- **[主动收缩低毛利IDC业务]** -> [整体毛利率提升]: IDC业务收入同比下降35.51%，但公司整体毛利率从2023年的4.3%提升至2025年的13.1%。
- **[固定资产折旧与摊销高企]** -> [持续亏损]: 云平台及智算集群大规模投入导致折旧摊销费用高企，收入增速不足以覆盖，2025年归母净利润仍亏损1.70亿元。
- **[AI Token消耗量指数级爆发]** -> [算力需求刚性增长]: 中国日均Token消耗两年内暴涨1800倍，直接驱动公司智算云业务客户需求与收入高速增长。
- **[“东数西算”节点布局]** -> [算力成本优势]: 在庆阳等西部枢纽节点建设万P级智算集群，利用当地廉价电力与政策支持，降低算力运营成本。
- **[自研全栈智算产品矩阵]** -> [差异化竞争壁垒]: 构建MaaS、AI Infra、工作流平台等产品，从单一算力租赁转向“算力+模型+服务”一体化解决方案。
- **[全球云网一体化基础设施]** -> [出海业务拓展]: 依托覆盖50余国的全球网络与近100条高速专线，推出出海智算解决方案，海外收入同比增长3.67%。

## 风险警告
公司最大的风险在于**智算转型的投入产出失衡**。尽管智算云收入高速增长，但公司整体仍处于亏损状态，且未弥补亏损已超过实收股本的三分之一。大规模智算集群建设（如庆阳节点）需要持续高昂的资本开支，而折旧与资金成本将长期侵蚀利润。若AI应用商业化落地不及预期，或算力需求增速放缓，公司可能面临资产减值与现金流恶化的双重压力。

其次，**传统业务收缩带来的收入阵痛**不容忽视。公司主动压降低毛利的IDC业务导致总收入同比下降11.47%，而计算云业务收入基本持平，增长引擎完全依赖尚在培育期的智算云。在行业竞争加剧、头部云厂商（如AWS、Azure）挤压的背景下，公司作为中立第三方服务商，若无法在智算领域快速建立规模与品牌优势，可能陷入“传统业务萎缩、新业务尚未盈利”的尴尬境地。
