# 000009.SZ 深度透视

## 因果逻辑链
- **[全球新能源汽车与储能需求爆发]** -> [高新技术板块营收增长17.68%]: 贝特瑞作为全球负极材料龙头，直接受益于下游动力电池与储能电池出货量高速增长。
- **[贝特瑞海外产能落地]** -> [巩固全球市场份额与供应链韧性]: 印尼16万吨负极材料总产能投产，摩洛哥项目推进，规避贸易壁垒并贴近海外客户。
- **[财务费用激增105.41%]** -> [侵蚀扣非净利润至亏损]: 在建工程转固导致利息资本化减少，叠加汇兑损失，费用化利息支出大幅增加。
- **[非经常性损益依赖度高]** -> [归母净利润勉强增长17.62%]: 扣非净利润亏损7159.65万元，盈利高度依赖金融资产公允价值变动（+2.12亿）及政府补助（+2.07亿）。
- **[马应龙品牌护城河]** -> [生物医药板块利润稳健增长8.21%]: 肛肠治领域“中华老字号”优势稳固，大健康及眼美康等新业务拓展贡献增量。
- **[房地产行业持续承压]** -> [房地产业务收入骤降40.21%]: 全国房地产市场调整，公司“去库存”策略下销售乏力，利润总额亏损1.5亿元。
- **[资产减值损失3.93亿元]** -> [拖累整体利润表现]: 主要来自存货及商誉减值，反映部分非核业务（如古马岭金矿、大地和电气）经营困境。
- **[经营活动现金流净额下降30.13%]** -> [盈利质量与现金回收能力减弱]: 经营性现金流（11.6亿）低于净利润（13.5亿），主因税费返还减少及经营性往来款增加。

## 风险警告
中国宝安的核心风险在于**盈利高度依赖非经常性损益，主业造血能力堪忧**。扣非净利润已连续两年为负，2025年亏损额扩大至-7159万元，而利润表主要靠金融资产公允价值变动（2.12亿）和政府补助（2.07亿）粉饰。一旦资本市场波动或政策补贴退坡，归母净利润将面临断崖式下跌。此外，财务费用因资本化利息减少而翻倍，高负债率（59.78%）下的利息支出已成为吞噬利润的沉重负担。

公司多元化业务中，**非核心资产的“出血点”持续扩大**。古马岭金矿、大地和电气等子公司持续亏损，房地产业务在行业下行周期中销售艰难，低效资产处置进展滞后。管理层虽提出“清理整顿非核业务”，但历史包袱沉重，资产减值损失（3.93亿）已连续两年高企，表明这些业务短期内难以扭亏，将持续拖累集团整体业绩。
