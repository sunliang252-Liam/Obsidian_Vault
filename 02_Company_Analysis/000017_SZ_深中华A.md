# 000017.SZ 深度透视

## 因果逻辑链
- **[珠宝黄金业务收入增长27.15%]** -> [归母净利润增长144.16%]: 营收从5.8亿增至7.36亿，规模效应下利润弹性放大。
- **[黄金制品销售量增长18.82%]** -> [营收增长]: 下游品牌客户需求旺盛，公司作为B端供应商受益于黄金消费热。
- **[子公司鑫森精密贡献主要利润]** -> [整体盈利提升]: 鑫森精密净利润2121万，占归母净利润51.6%，是核心利润来源。
- **[前五大客户集中度69.42%]** -> [收入稳定性与风险并存]: 依赖少数大客户（如周六福）订单，保障了收入规模，但议价能力受限。
- **[存货大幅增加119%至1.85亿]** -> [经营现金流为负]: 为满足订单增长储备黄金等原材料，占用了大量营运资金，导致现金流净流出1952万。
- **[上海黄金交易所采购占比96.36%]** -> [成本与金价高度联动]: 黄金原料成本几乎完全市场化，公司赚取加工费与周转收益，毛利率仅10.52%。
- **[业绩承诺完成102.82%]** -> [控股股东解禁]: 万胜实业完成2025年4000万净利润承诺，其持有的1.38亿股于2025年11月解禁。

## 风险警告
**核心风险在于对单一业务（珠宝黄金）和少数大客户的深度依赖，以及金价波动对利润的侵蚀。** 公司99%以上收入来自珠宝黄金批发，前五大客户贡献近70%营收，客户集中度极高。一旦主要客户流失或压价，业绩将剧烈波动。同时，黄金原料成本占比超99%，毛利率仅10.5%，金价上涨虽能推高营收，但若金价下跌导致存货减值，将直接冲击利润。

**现金流持续为负与历史巨额亏损是财务健康度的重大隐患。** 公司连续两年经营现金流为负，且母公司未分配利润仍亏-11.72亿元，不具备分红条件。虽然当前盈利，但造血能力不足，需依赖外部融资（短期借款增加）和关联方往来维持运营。此外，控股股东万胜实业股份已全部解禁，存在减持压力。
