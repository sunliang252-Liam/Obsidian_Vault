# 002859.SZ 深度透视

## 因果逻辑链
- **[电子级薄膜材料（离型膜）放量]** -> **营收增长15.6%**: 电子级薄膜收入同比增长48.01%，成为第二增长曲线，驱动整体营收突破21亿元。
- **[自制BOPET基膜量产]** -> **离型膜毛利率改善**: 基膜二期投产实现自供，降低原材料成本，推动离型膜在韩日系大客户（三星、村田）处批量供货。
- **[纸质载带高端化与海外布局]** -> **核心业务稳健增长**: 高精密载带占比提升，菲律宾/马来西亚基地投产，电子封装材料收入同比增长10.67%。
- **[复合集流体（柔震科技）纳入合并]** -> **开辟新能源第二赛道**: 控股柔震科技，切入锂电池复合铝/铜箔领域，受益于“十五五”规划及新国标，打开长期成长空间。
- **[产能扩张与资本开支]** -> **财务费用激增129%**: 天津、广东、江西等基地建设导致长期借款增加，利息费用及汇兑损失大幅上升，侵蚀利润。
- **[员工持股计划与股权激励]** -> **管理费用增长26.45%**: 实施2025年员工持股计划，股份支付费用增加，叠加新项目投产折旧，期间费用率上升。
- **[木浆价格波动]** -> **成本控制压力**: 木浆为主要原材料（占成本约65%），价格受汇率及国际大宗商品影响，公司通过“价格敏感型”动态采购策略平滑成本。

## 风险警告
**1. 高资本开支与债务风险：** 公司正处于产能扩张高峰期（天津、广东、江西、柔震），在建工程高达17.59亿元，长期借款激增至19.73亿元，资产负债率升至56.7%。财务费用同比暴增129%，若新产能爬坡不及预期或下游需求放缓，高额的利息支出将严重侵蚀利润，现金流面临巨大压力。

**2. 新业务盈利不确定性：** 电子级薄膜材料毛利率仅8.82%，远低于传统纸质载带（38.96%），且仍处于以价换量的市场导入期。复合集流体业务（柔震科技）尚处于小批量出货阶段，报告期内仍亏损，距离规模化盈利仍有较长距离。新业务能否成功兑现增长预期，是公司估值的关键变量。
