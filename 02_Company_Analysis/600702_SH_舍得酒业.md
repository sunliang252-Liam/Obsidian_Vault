# 600702.SH 深度透视

## 因果逻辑链
- **[行业深度调整，消费动力不足]** -> [营收与利润双降]: 2025年白酒行业进入存量竞争，公司营业收入同比下降17.51%，归母净利润同比下降35.51%。
- **[中高档酒收入大幅下滑]** -> [整体毛利率承压]: 中高档酒收入同比下降23.83%，导致酒类业务毛利率减少3.26个百分点。
- **[电商渠道逆势增长]** -> [部分对冲线下颓势]: 电商销售收入同比增长35.46%，成为唯一正增长渠道，但体量较小，难以扭转整体下滑。
- **[批发代理渠道萎缩]** -> [经销商体系承压]: 批发代理收入同比下降25.19%，省外经销商净减少130家，显示渠道去库存压力巨大。
- **[销售费用率居高不下]** -> [侵蚀利润空间]: 销售费用占营收比例高达25.80%，尽管费用绝对值下降，但营收下滑更快，费用效率降低。
- **[增产扩能项目持续投入]** -> [资本开支与负债增加]: 在建工程累计投入26.66亿元，导致长期借款同比增加79.38%，财务费用由负转正。
- **[经营活动现金流持续为负]** -> [造血能力不足]: 连续两年经营性现金流为负（2025年-5.23亿），显示公司回款能力恶化，运营资金依赖外部融资。

## 风险警告
**核心风险：业绩持续恶化与现金流危机。** 公司营收、利润连续两年大幅下滑，2025年归母净利润仅2.23亿元，较2023年峰值缩水近90%。更严重的是，经营活动现金流连续两年为负，且2025年第四季度单季亏损2.49亿元，显示公司已陷入“增收不增现、旺季不旺”的困境，基本面恶化趋势未见底。

**结构性风险：渠道库存高企与费用失控。** 在行业下行周期，公司批发代理渠道收入锐减25%，经销商数量净减少，表明渠道库存压力巨大，动销不畅。同时，销售费用率高达25.8%，远超行业平均水平，但并未有效拉动销售，费用投放效率极低，存在“越促销越卖不动”的恶性循环风险。此外，增产扩能项目持续消耗大量现金，进一步加剧了财务压力。
