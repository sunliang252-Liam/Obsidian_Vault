# 000913.SZ 深度透视

## 因果逻辑链
- **[工厂搬迁资产处置]** -> [净利润暴增44.39%]: 报告期内完成工厂搬迁，处置土地及厂区房屋建筑物等资产，实现税前资产处置收益8.57亿元，构成非经常性损益主体，掩盖了主营业务恶化。
- **[国内价格战与消费放缓]** -> [扣非净利润暴跌49.20%]: 国内大排量摩托车赛道竞争白热化，叠加消费需求放缓，导致内销大排量车型销量同比下降26.01%，主营业务利润承压。
- **[海外高端化出海]** -> [外销营收逆势增长6.17%]: 大排量车型出口量同比增长23.36%，带动境外销售占比提升至53.68%，成为对冲国内下滑的核心引擎。
- **[全地形车业务突破]** -> [第二增长曲线初步成型]: 全地形车销量同比增长117.86%，收入同比增长117.01%，成功切入新赛道，但体量尚小，对整体业绩贡献有限。
- **[行业准入门槛抬高]** -> [龙头竞争优势强化]: 摩托车安全强制国标及准入新规发布，倒逼中小企业出清，公司凭借全产业链合规优势，竞争壁垒持续加固。
- **[研发投入持续高位]** -> [技术护城河加深]: 研发投入3.82亿元（强度7.06%），完成第二代AMT、ARAS等核心技术迭代，巩固大排量发动机正向研发能力。
- **[经营活动现金流恶化]** -> [盈利质量显著下降]: 经营活动现金流净额为-4.03亿元，与净利润严重背离，主因存货增加4.5亿元及经营性应收应付项目变动，显示造血能力不足。

## 风险警告
**核心风险在于盈利质量与可持续性。** 2025年净利润暴增完全依赖一次性资产处置收益（8.57亿），扣非净利润同比腰斩，揭示主营业务在国内价格战与消费放缓双重压力下已显疲态。经营活动现金流由正转负，净流出4.03亿元，与净利润严重背离，存货激增38.79%至16.25亿元，表明产品动销不畅，渠道库存压力巨大，真实经营状况远逊于利润表表现。

**成长性面临国内外双重挑战。** 国内大排量市场虽为增长最快赛道，但竞争白热化导致公司内销大排量销量下滑26%，市场份额面临春风、隆鑫等对手蚕食。海外业务虽增长，但面临地缘政治、汇率波动及本地化运营管理风险，且公司自身承认存在“市场洞察不足、产品开发效率偏低、核心爆款缺失”等短板，品牌口碑亦有下滑，若无法有效补齐，将错失行业结构性增长机遇。
