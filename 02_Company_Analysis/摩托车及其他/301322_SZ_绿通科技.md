# 301322.SZ 深度透视

## 因果逻辑链
- **[美国“双反”高额关税]** -> [美国市场营收暴跌79.89%]: 美国对华特定低速载人车辆征收反倾销税119.39%、反补贴税31.45%，直接导致公司美国市场业务几乎停滞，毛利贡献锐减4,260万元。
- **[美国客户回款恶化]** -> [计提巨额坏账准备5,138万元]: 受“双反”调查冲击，美国客户回款节奏严重不及预期，应收账款账龄拉长，迫使公司大额计提信用减值损失。
- **[收购大摩半导体]** -> [营收增长19.12%但主业萎缩]: 2025年9月并表大摩半导体带来2.35亿元半导体收入，掩盖了场地电动车业务（同比-9.39%）的持续下滑。
- **[场地电动车非美市场拓展]** -> [盈利能力承压]: 非美市场需求分散、定制化要求高，导致人工及管理成本上升，未能有效对冲美国市场损失。
- **[计提存货跌价准备2,222万元]** -> [利润进一步侵蚀]: 市场竞争加剧导致部分产品周转放缓、价格预期下降，叠加美国市场冲击，存货减值压力显著。
- **[双主业整合与管理差异]** -> [潜在协同风险]: 场地电动车（制造、成本导向）与半导体设备（技术、服务导向）在商业模式、人才结构上差异巨大，整合不力可能导致管理效率下降。
- **[大摩半导体业绩承诺达标]** -> [短期商誉减值风险暂缓]: 大摩半导体2025年实现扣非净利润7,211万元，完成当年7,000万元承诺，但未来两年业绩仍存不确定性。

## 风险警告
**核心风险：美国市场“休克”与转型阵痛。** 公司核心利润来源的场地电动车美国市场因“双反”关税已基本丧失，短期内难以恢复。尽管公司通过收购大摩半导体切入半导体赛道实现营收增长，但场地电动车主业萎缩、非美市场盈利能力不足，导致扣非净利润暴跌97.95%，主业造血能力已严重受损。

**最大隐患：高额商誉与整合失败风险。** 收购大摩半导体形成3.17亿元商誉，占净资产11.2%。半导体行业周期性强，若未来大摩半导体业绩不及预期（尤其2026、2027年承诺），将面临巨额商誉减值风险。同时，公司缺乏半导体行业管理经验，双主业在文化、运营上的巨大差异可能导致整合失败，核心人才流失，协同效应落空。
