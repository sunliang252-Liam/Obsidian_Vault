# 603969.SH 深度透视

## 因果逻辑链
- **[国家基建投资持续高位]** -> [预应力材料销量增长3.14%]: 铁路、水利、桥梁等领域需求旺盛，直接拉动钢丝等基础产品出货量。
- **[高性能产品结构优化]** -> [净利润增长54.51%]: 2200-2400MPa超高强钢绞线、桥梁缆索镀锌钢丝等高毛利产品占比提升，驱动利润增速远超收入增速。
- **[新能源领域加速放量]** -> [新能源用预应力材料销量增长105.76%]: 风电混塔、柔性光伏支架等新场景成为核心增量市场，打开第二增长曲线。
- **[轨交混凝土制品“技术+装备+材料”协同]** -> [该板块净利润增长75.36%]: 高铁轨道板、智能化装备及海外出口（哈萨克斯坦、坦桑尼亚）形成高附加值服务组合，利润贡献显著。
- **[PCCP管用钢丝深耕水利]** -> [该产品销量增长28.21%]: 受益于国家水网建设（如环北部湾、大伙房输水工程），巩固水利细分市场龙头地位。
- **[股权激励绑定核心团队]** -> [凝聚长期发展合力]: 连续推出两期限制性股票激励计划，以净利润为考核目标，确保管理层与股东利益一致。
- **[经营活动现金流由负转正]** -> [现金流质量改善]: 销售回款能力增强，经营性现金流净额达1.27亿元，扭转上年同期净流出局面。

## 风险警告
**核心风险在于宏观政策波动与原材料成本。** 公司业绩高度依赖铁路、水利等国家基建投资节奏，若“十五五”期间投资力度不及预期或项目审批放缓，将直接冲击预应力材料及轨道板订单。同时，主要原材料“盘条”价格波动对毛利率影响显著，虽然报告期内成本下降，但若钢价反弹，利润空间将被压缩。

**竞争加剧与海外业务不确定性不容忽视。** 预应力材料行业门槛较低，同质化竞争激烈，公司需持续依靠高端产品差异化突围。此外，海外业务（占比约16.9%）面临汇率波动及地缘政治风险，虽然公司已采取远期锁汇等措施，但若国际形势恶化，可能影响海外项目交付与收益。
