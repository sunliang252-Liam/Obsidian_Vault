# 603605.SH 深度透视

## 因果逻辑链
- **核心品牌珀莱雅营收下滑10.39%** -> 公司整体营收同比下降1.68%: 珀莱雅品牌贡献超72%营收，其下滑直接拖累整体业绩。
- **洗护品牌Off&Relax营收翻倍(+102.19%)** -> 部分对冲主品牌下滑: 第二增长曲线成功接力，洗护类营收占比从3.58%跃升至7.94%。
- **销售费用率持续攀升至49.63%** -> 净利率同比下降0.15个百分点至14.56%: 线上流量成本高企，形象宣传推广费增长1.39%，侵蚀利润空间。
- **毛利率提升1.87个百分点至73.26%** -> 成本管控与产品结构优化见效: 原材料价格下降及高毛利新品占比提升，驱动毛利率逆势改善。
- **经营活动现金流净额同比大增98.12%** -> 盈利质量显著增强: 销售回款增加、货款及推广费支付减少，现金流远超净利润。
- **应收账款周转率大幅提升至36.04次** -> 渠道回款效率优化: 期末应收京东款项大幅减少，资金占用降低，运营效率提升。
- **研发费用率稳定在2.05%** -> 支撑多品牌科技差异化: 持续投入IFSCC获奖研究、自研原料（双环肽）及医研共创，构建长期壁垒。
- **多品牌矩阵（彩棠+5.37%、OR+102.19%、原色波塔+125.38%）** -> 降低对单一品牌依赖: 主品牌承压时，第二、三梯队品牌接力增长，验证平台化战略有效性。

## 风险警告
**核心风险在于主品牌珀莱雅的增长失速与营销投入的持续高企。** 2025年珀莱雅品牌营收同比下降10.39%，这是公司上市以来首次出现主品牌负增长，直接导致整体营收微降。与此同时，销售费用率已攀升至49.63%的历史高位，意味着公司需花费近一半的营收来维持流量与声量。若主品牌无法在2026年恢复增长，或新品牌（OR、原色波塔）的增速放缓，公司将面临“增收不增利”甚至“营收利润双降”的困境。

**第二增长曲线的可持续性尚待验证。** 虽然Off&Relax和原色波塔增速惊人，但两者合计营收仅占10%左右，且均处于高投入孵化期。洗护赛道竞争激烈，彩妆品牌生命周期较短，这些新品牌能否持续高增长、实现盈利，存在较大不确定性。此外，公司正推进H股上市，全球化扩张将带来新的管理、文化与汇率风险，可能分散国内业务资源。
