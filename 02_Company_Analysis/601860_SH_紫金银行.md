# 601860.SH 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [营收与净利润双降]: 净息差从1.42%降至1.13%，导致利息净收入下降15.4%，是营收下滑7.72%、净利润暴跌23.35%的核心原因。
- **[贷款增速远低于存款增速]** -> [资产结构恶化]: 存款增长6.92%而贷款仅增3.21%，大量低成本资金被迫配置于低收益的债券投资，拉低整体资产收益率。
- **[信用减值损失激增32.5%]** -> [利润侵蚀加剧]: 贷款减值损失从3.95亿暴增至10.71亿，同比+171%，直接吞噬了营业利润的绝大部分增量。
- **[不良贷款率与关注类贷款双升]** -> [资产质量承压]: 不良率从1.24%升至1.35%，关注类贷款占比从1.41%升至1.75%，叠加正常类贷款迁徙率从2.91%升至3.63%，预示未来不良生成压力加大。
- **[拨备覆盖率大幅下滑]** -> [风险抵补能力削弱]: 拨备覆盖率从201.44%降至180.09%，逼近监管红线，未来计提减值损失的空间被压缩，利润调节能力减弱。
- **[中收能力增强但体量过小]** -> [收入结构改善有限]: 手续费及佣金净收入增长56.8%，但占营收比重仅6.81%，远不足以对冲净利息收入下滑带来的冲击。
- **[个人贷款规模萎缩]** -> [零售转型受阻]: 个人贷款平均余额下降9.8%，且平均收益率从4.71%骤降至3.67%，显示零售信贷需求疲软且定价能力恶化。

## 风险警告
**核心风险在于资产质量恶化与盈利能力的双重挤压。** 不良贷款率已连续三年攀升（1.16%→1.24%→1.35%），且关注类贷款和逾期贷款规模同步扩大，正常类贷款迁徙率加速上行，表明信用风险正在加速暴露。与此同时，拨备覆盖率已降至180.09%的近年低位，距离监管最低要求仅剩30个百分点的缓冲空间，未来若不良持续暴露，将被迫大幅计提减值，进一步侵蚀本已脆弱的利润。

**净息差收窄趋势难以逆转，构成系统性盈利压力。** 在LPR下行和存款定期化（定期存款占比从73%升至77%）的双重作用下，净息差已从1.59%的高点滑落至1.13%，且未见企稳迹象。贷款收益率（3.16%）与存款成本率（1.81%）之间的利差空间被极度压缩，而公司贷款增速（3.21%）远低于存款增速（6.92%），大量资金淤积于低收益的债券投资，资产端收益率下行压力将持续。在缺乏强劲的非息收入增长点的情况下，营收增长动能严重不足。
