# 301305.SZ 深度透视

## 因果逻辑链
- **全球地缘政治冲突频发，宏观经济波动，生物柴油及原料价格随国际原油、大宗商品大幅波动** -> 生物能源收入同比增长25.15%: 公司灵活调整产销量，在废弃油脂需求旺盛时直接销售原料，在生物柴油需求旺盛时加大销售，通过敏锐市场判断创造最大经济效益。
- **生物柴油产品及原料价格大幅波动，不确定性增强** -> 工程建造收入同比下降59.77%: 工程建造收入大幅下降主要因轨道交通项目完成最终竣工结算，产值核减，与价格波动无直接关联，但间接影响公司整体收入结构。
- **欧盟反倾销及国内市场转型** -> 公司生物柴油目标市场从欧盟切换至新加坡、香港船燃市场: 2024年欧盟正式对中国生物柴油行业实施反倾销，公司率先改造低硫生物柴油技术，并开拓新市场。
- **公司生物柴油目标市场切换至船燃市场** -> 生物能源收入同比增长25.15%: 船燃市场开拓成功，与海外核心燃料油加注商、国内领军船燃供应商建立长期稳定合作关系，舟山试点落地加速广州试点，推动销售增长。
- **公司中标深圳市罗湖区餐厨、果蔬垃圾收运服务项目（2156.712万元）** -> 运营服务收入同比增长9.81%: 新增项目直接贡献运营收入，巩固一线城市市场优势，提升处理量。
- **合成生物智造业务一期年产260吨项目于2025年上半年投产** -> 合成生物智造业务尚未在收入中体现，但为未来增长点: 项目已竣工投产，但HMOs产品需通过国家卫健委审批后方可销售，报告期内尚未贡献收入，但已成功完成多批次产业化生产。
- **公司持续推进碳交易业务布局** -> 未来业绩增长潜力: 碳投团队积极布局生物质废弃物减排项目与碳交易业务，可进一步挖掘生态价值，助推业绩增长。

## 风险警告
深度风险总结：1. 全球地缘政治冲突和宏观经济波动导致生物柴油及原料价格大幅波动，尽管公司通过灵活策略应对，但不确定性依然高企，可能影响未来盈利稳定性。2. 欧盟反倾销政策持续，国内生物柴油行业仍处转型恢复阶段，国际市场切换至船燃市场虽初见成效，但IMO净零框架推迟至2026年10月，政策落地节奏不及预期，可能影响船燃需求释放。3. 合成生物智造业务依赖国家卫健委审批，产品上市进度具有不确定性，且国内HMOs市场竞争加剧（已有18家企业2'-FL获批），公司需在竞争中保持技术领先。4. 工程建造收入大幅下降（-59.77%），且毛利率为负（0.23%），显示该业务盈利能力薄弱。5. 公司资产总额增长4.25%，但负债情况未披露，需关注财务杠杆风险。
