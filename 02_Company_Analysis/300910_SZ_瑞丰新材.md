# 300910.SZ 深度透视

## 因果逻辑链
- **[全球供应链重构机遇]** -> [营收增长11.11%]: 下游润滑油企业为保障供应安全，积极寻求供应链多元化，公司作为国产龙头承接了国际头部客户的转移订单。
- **[复合剂向中高端转型]** -> [盈利结构优化]: 高端复合剂销量及收入占比稳步增长，推动产品均价提升，部分对冲了原材料成本上涨对毛利率的侵蚀。
- **[客户结构向国际头部转型]** -> [海外收入占比69.19%]: 公司深耕TOP级核心客户，深化与国内外头部润滑油企业合作，外销收入同比增长9.06%，成为业绩基本盘。
- **[核心单剂自给率提升]** -> [成本控制能力增强]: 自主生产十二烷基酚、ɑ-烯烃等关键原材料，降低对外采购依赖，对冲原材料价格波动风险，稳定了毛利率。
- **[参与中国自主D1标准]** -> [技术壁垒与市场准入]: 全程参与中国首个自主D1柴油机油标准开发，在OEM端实现柴机油领域从0到1的突破，为国产替代打开新空间。
- **[产能扩张与技改]** -> [规模效应与供应保障]: 单剂产能达31.5万吨，稳居国内第一阵营，新乡基地技改及沙特合资项目推进，为未来市场拓展提供产能支撑。
- **[研发投入持续加大]** -> [产品迭代与认证突破]: 研发费用同比增长10.96%，完成多项API及OEM认证，支撑复合剂从中低端向中高端升级，提升产品竞争力。

## 风险警告
**1. 原材料价格与汇率双重波动风险。** 公司主要原材料为原油下游产品，价格易受国际油价和地缘政治影响大幅波动。同时，公司外销收入占比高达69.19%，以美元、欧元结算为主。若原材料价格持续上涨而产品售价调整滞后，叠加人民币升值带来的汇兑损失，将直接压缩公司利润空间。2025年财务费用因汇兑损失大幅增加154.24%，已敲响警钟。

**2. 产能建设与海外拓展的不确定性。** 公司正同步推进国内技改扩建及沙特合资生产基地建设，项目投资规模大、周期长。沙特项目面临当地营商环境、政策审批等不确定因素，存在延期、超支或投产后产能利用率不足的风险。若双基地供应格局未能如期落地，将制约公司全球化战略推进和客户供应保障能力。

**3. 市场竞争加剧与认证风险。** 润滑油添加剂行业国产替代加速，国内企业竞争加剧，国际巨头也可能通过价格战和技术封锁巩固份额。公司高端复合剂产品需通过API、OEM等高等级认证，研发门槛高、周期长、成本大。若高端产品研发遇瓶颈或认证未能顺利通过，将影响公司产品高端化升级和市场拓展进度，导致盈利能力下滑。
