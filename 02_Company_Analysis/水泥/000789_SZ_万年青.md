# 000789.SZ 深度透视

## 因果逻辑链
- **江西省基础设施投资逆势增长5.4%** -> 区域水泥市场韧性凸显，省内水泥产量降幅(8.39%)小于全国(6.9%): 基础设施投资是水泥需求的关键支撑，江西基建投资正增长对冲了部分需求下滑
- **大客户战略落地，入围央企集采** -> 基建市场销量占比提升，产品结构向高标号、特种水泥升级: 大型基建项目对大客户有偏好，入围央企集采带来稳定订单，推动产品结构优化
- **石灰石矿山自给、煤炭集中采购、替代燃料及自发电** -> 成本管控有效，对冲需求下行带来的成本压力: 原材料和能源自给及集中采购降低单位成本，替代燃料和自发电减少外购能源支出
- **'水泥+商砼+骨料'全产业链布局** -> 为客户提供一站式服务，提升客户黏性和市场竞争力: 全产业链布局实现产品协同和物流成本降低，增强对大客户的吸引力
- **全国水泥行业需求承压，产量同比下降6.9%** -> 公司产能利用率下降（水泥58%，商砼16%）: 行业整体需求下滑，导致公司开工不足，产能利用率降低
- **房地产投资持续走低（全国-17.2%，江西-11.6%）** -> 公司混凝土营收下降26.31%: 房地产是混凝土主要下游，地产投资下滑直接导致混凝土需求减少
- **研发投入同比下降20.27%** -> 数字化转型和技改项目数量减少: 研发投入减少可能影响技术创新和数字化项目的推进速度
- **骨料销量同比增长0.67%，毛利率同比提升14.28个百分点** -> 骨料业务成为盈利增长点，支撑整体利润: 骨料市场需求相对稳定，成本控制能力强，量价齐升带动毛利率大幅提高

## 风险警告
公司面临多重风险：1) 行业需求持续承压，全国水泥产量下降6.9%，公司水泥营收下降21.57%，混凝土营收下降26.31%；2) 产能利用率偏低（水泥58%，商砼16%），固定成本摊销压力大；3) 研发投入大幅减少20.27%，可能影响长期技术竞争力；4) 应收账款和信用减值损失风险，信用减值损失占利润总额-104.93%；5) 房地产下行周期延续，对混凝土业务构成持续压力。

> 江西万年青水泥股份有限公司是由始建于1958年的江西水泥厂作为独家发起人,于1997年9月2日创立的江西省建材行业首家上市公司,是全国较早采用国产新型干法水泥工艺线的厂家。生产的“万年青”牌系列硅酸盐水泥广泛用于机场、高楼、桥梁、隧道、高等级公路等国家大型重点工程建设中,在华东地区拥有较高的品牌知名度及客户认知度,受到了业主、工程设计者和建设者的广泛好评。“万年青”牌水泥产品获“全国建材行业用户满意产品”、“江西名牌产品”等荣誉称号。凭借上乘的质量和贴心的服务,水泥产销量以及市场占有率在江西省水泥市场中名列前茅。近年来,公司在推动水泥主业稳健发展的同时,以延伸产业链和发展相关多元经营相结合,打造新的增长极。当前,公司以习近平新时代中国特色社会主义思想为指引,大力弘扬井冈山精神,践行绿色发展理念,以提高质量和效益为核心,以改革创新为动力,加快发展高端化、绿色化、功能化建材产业,努力实现水泥传统产业向环保产业转型、向绿色建材升级,在建设富裕美丽幸福现代化江西的征途中,开创公司高质量跨越式发展新局面!
