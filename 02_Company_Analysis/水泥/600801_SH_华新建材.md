# 600801.SH 深度透视

## 因果逻辑链
- **[海外并购突破]** -> [业绩逆势增长]: 完成尼日利亚拉法基及巴西骨料项目并购，海外产能突破4000万吨，海外营收同比增长48%，成为利润增长第二曲线，对冲国内需求下滑。
- **[一体化协同优势]** -> [成本下降与盈利修复]: 依托水泥主业，协同发展骨料、混凝土业务，骨料产销量全国第一，全集团水泥单位成本同比下降3.27%，水泥毛利率同比提升9.35个百分点至32.72%。
- **[国内需求萎缩]** -> [营收增长承压]: 受房地产投资下行及基建放缓影响，国内水泥需求持续下滑，全年水泥产量同比下降6.9%，公司国内水泥及熟料销量仅4,165万吨，降幅低于全国平均但仍是拖累。
- **[极致降本与数智化转型]** -> [成本护城河]: 通过对标行业标杆、技改提效、采购竞拍、推广新能源车等措施，叠加HIAC工业智能系统覆盖28家工厂，实现全链条成本压降。
- **[碳交易与环保政策趋严]** -> [绿色竞争力壁垒]: 水泥行业全国碳交易正式启动，公司提前布局减碳，23家工厂完成碳排专项审计，13家获评国家级能效领跑者（数量业内第一），低成本合规优势凸显。
- **[高杠杆并购]** -> [财务费用与负债率攀升]: 为支付海外并购款，公司增加并购贷款及发行债券，导致财务费用同比增长21.42%，资产负债率从49.80%升至53.87%，有息债务余额同比增加33.46%。

## 风险警告
**核心风险在于高杠杆海外扩张带来的财务脆弱性。** 2025年公司为完成尼日利亚及巴西等重大并购，投资活动现金净流出高达87.5亿元，同比暴增138%，导致资产负债率突破54%，有息债务规模膨胀至242亿元。尽管海外业务高毛利（41.94%）提供了利润缓冲，但若海外项目整合不及预期或所在国发生汇率、政治风险，高额的利息支出（8.3亿元）将严重侵蚀利润，公司财务弹性已显著下降。

**国内水泥需求长期下滑趋势未改，行业“内卷”风险持续。** 尽管公司通过海外扩张和成本管控实现了业绩增长，但国内水泥熟料产能利用率已降至48%左右，供需矛盾未见根本性改善。若国内水泥价格体系修复不及预期，或公司国内业务（仍占营收60%）盈利能力持续恶化，将拖累整体现金流，并可能触发高杠杆下的债务偿付压力。

**公司简介（F10 原文）**

> 华新建材集团股份有限公司始创于1907年,被誉为中国水泥工业的摇篮。公司A股(600801)和H股(06655)分别在上海证券交易所和香港交易所上市,并与瑞士Holcim集团结为战略伙伴关系。2000年以来,华新坚持以恒心办恒业,以创新促转型,业务覆盖国内17个省/市/自治区和中亚、东南亚、非洲、中东等14个海外国家,拥有300余家分、子公司,品牌价值突破千亿元人民币,名列中国制造业500强和财富中国500强。华新秉承“全生命周期绿色低碳建筑材料”的发展理念,致力打造水泥、骨料、混凝土、环保、新型建筑材料、装备与工程制造等全产业链、一体化和在商业模式、效益业绩指标上全球领先的跨国建材集团,持续为社会、股东、员工等创造价值。
