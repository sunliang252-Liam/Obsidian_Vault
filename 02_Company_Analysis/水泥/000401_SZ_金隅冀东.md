# 000401.SZ 深度透视

## 因果逻辑链
- **成本管控与燃料替代** -> **扭亏为盈**: 通过煤炭集采、燃料替代技术（40%替代率）和精益生产，大幅压降燃料及动力成本（水泥燃料成本同比降15.53%），使毛利率提升4.04个百分点，驱动归母净利润从-9.91亿扭转为+2.19亿。
- **区域市场主导地位** -> **销量韧性**: 在京津冀市占率超50%，通过“水泥+骨料+混凝土”一体化营销和错峰生产，水泥销量仅下降2.85%，显著优于全国6.9%的降幅，稳住了基本盘。
- **战略性并购整合** -> **区域竞争力提升**: 收购恒威水泥、双鸭山新时代等，完善东北布局，新并购企业当年即贡献正收益（恒威水泥贡献2,582万），实现规模与协同效应扩张。
- **碳市场履约与减排** -> **成本分化优势**: 57家子公司纳入全国碳市场并完成履约，凭借能效领先和碳管理能力，在碳成本上升的行业趋势中，相对落后企业形成成本优势。
- **非经常性损益** -> **利润贡献**: 政府补助3.27亿、营业外收入（核销无法支付款项等）2.16亿等非经常性损益合计4.46亿，是归母净利润2.19亿的核心来源，扣非净利润仍为-2.27亿。
- **产业链延伸** -> **新增长极**: 新增骨料产能1,350万吨、混凝土产能180万立方米，特种水泥销量同比增40%，高附加值产品矩阵正逐步成为价值创造的重要增长点。

## 风险警告
**核心风险在于扣非净利润持续为负，盈利质量堪忧。** 公司2025年归母净利润2.19亿，但扣非净利润为-2.27亿，连续第三年扣非亏损。盈利主要依赖政府补助（3.27亿）和债务核销等非经常性损益，主业造血能力依然脆弱。在水泥需求总量持续萎缩（全国产量创2010年新低）的背景下，仅靠成本管控难以逆转行业性下行趋势。

**资产减值与高负债率构成双重压力。** 报告期内计提资产减值损失7.10亿元（主要为固定资产减值），显示部分产线已面临经济性淘汰。同时，公司总负债约297.6亿，资产负债率约51.9%，有息负债规模庞大（短期借款27.2亿+长期借款68.1亿），财务费用4.58亿，对利润形成持续侵蚀。在行业低谷期，资产减值和财务杠杆是悬在利润表上的两把利剑。
