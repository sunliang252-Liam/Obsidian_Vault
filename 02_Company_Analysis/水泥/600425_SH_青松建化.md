# 600425.SH 深度透视

## 因果逻辑链
- **[水泥需求总量收缩]** -> [营收与利润双降]: 房地产深度调整、基建放缓，导致水泥销量及售价同比下降，营收降10.28%，归母净利降21.85%。
- **[水泥制品结构优化]** -> [板块逆势增长]: 加气砼和商品砼销量上升，带动水泥制品收入同比增24.11%，毛利率提升6.83个百分点。
- **[尿素价格下行]** -> [化工板块利润侵蚀]: 青松化工尿素销量虽增，但价格下跌导致净利润同比减少6,290万元，拖累整体业绩。
- **[PVC价格持续低迷]** -> [化工板块减亏未达预期]: 阿拉尔化工PVC价格低迷，虽增加其他产品销售，全年仅减亏8,645万元，仍亏损1.68亿元。
- **[加强付款管理]** -> [经营现金流大幅改善]: 公司加强经营性支出控制，经营活动现金流净额同比大增41.15%至4.84亿元。
- **[天盈石化持续亏损]** -> [其他权益工具投资减值]: 参股公司天盈石化严重资不抵债，公司将其公允价值调整至0，导致其他综合收益减少2,040万元。
- **[区域产能过剩与错峰生产]** -> [行业竞争格局固化]: 新疆水泥产能过剩，错峰生产常态化，公司虽为区域龙头，但市场总量收缩下盈利承压。

## 风险警告
公司面临的核心风险是**区域市场总量收缩与成本刚性上涨的双重挤压**。新疆水泥需求“东疆强、南疆稳、北疆弱”格局固化，房地产投资下滑构成持续压力，而错峰生产常态化虽能短期维稳价格，但无法扭转需求下行趋势。同时，煤炭、电力等能源价格波动及超低排放改造投入，将持续推高生产成本，侵蚀利润空间。

**化工板块的持续亏损是重大拖累项**。阿拉尔化工（PVC）和青松化工（尿素）合计亏损严重，尤其是PVC业务受国内产能过剩和价格低迷影响，短期内难以扭亏。该板块不仅消耗公司大量现金流，还面临安全生产和环保合规的高风险，是公司整体盈利能力的最大不确定性来源。
