- **参股公司天士力出售核心资产** -> **归母净利润暴增281%**: 天士力集团向华润三九转让天士力医药28%股权，尖峰集团按权益法确认6.52亿元投资收益，直接推动净利润从1.08亿飙升至4.12亿。

- **医药工业产品收入锐减15%** -> **医药板块整体承压**: 受集采降价、市场竞争加剧影响，医药工业产品收入降至4.58亿元，毛利率同步下滑3.48个百分点。
- **扣非净利润巨亏2.51亿元** -> **主业造血能力严重恶化**: 剔除天士力股权出售等非经常性损益后，公司核心业务实际亏损，扣非净利润同比暴跌360%。
- **尖峰药业净亏损3.17亿元** -> **医药子公司成为最大拖累**: 核心子公司尖峰药业因研发投入、资产减值及市场竞争，全年亏损超3亿元，净资产仅剩496万元。
- **在建工程激增299%** -> **资本开支大幅扩张**: 尖峰大展日产4000吨熟料生产线及云南骨料项目进入建设高峰期，在建工程从0.57亿增至2.27亿，投资现金流净流出3.94亿元。
- **短期借款暴增214%** -> **财务杠杆显著提升**: 为支撑项目建设及运营，公司短期借款从1.96亿增至6.16亿，财务费用同比上升25%。
- **资产减值损失2.25亿元** -> **存量资产质量承压**: 公司对开发项目、存货等计提大额减值，其中开发支出减值及存货跌价准备是主要构成，反映部分研发项目前景不明。

## 风险警告
**主业双杀，利润高度依赖一次性收益。** 2025年归母净利润4.12亿元中，非经常性损益高达6.63亿元，核心主业（水泥+医药）实际亏损严重。水泥行业需求下行趋势短期难改，医药板块受集采和竞争加剧双重挤压，两大主业均缺乏内生增长动力。一旦失去天士力这类非经常性收益，公司盈利能力将急剧恶化。

**财务风险快速累积，现金流承压。** 公司为推进尖峰大展水泥线等项目建设，短期借款激增2倍至6.16亿元，财务费用上升25%。同时，经营活动现金流净额同比大降46%，投资活动现金净流出近4亿元，自由现金流缺口巨大。若新项目投产后无法及时贡献利润，高杠杆将带来偿债压力。
