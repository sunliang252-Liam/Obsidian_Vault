# 002487.SZ 深度透视

## 因果逻辑链
- **[欧洲海风市场高景气]** -> [出口收入暴增165%]: 欧洲能源安全需求推动海风拍卖量创历史新高，公司凭借先发优势和产能壁垒，承接大量高附加值海外订单。
- **[战略聚焦海外高附加值市场]** -> [毛利率与净利率大幅提升]: 主动收缩低毛利国内业务，出口业务毛利率达33.95%，毛利贡献占比从59%提升至81%，驱动归母净利润增长133%。
- **[自建特种运输船队]** -> [交付模式升级为DAP]: 从FOB模式转向DAP模式，掌握运输环节，将单一产品制造延伸至“制造+运输+交付”一站式服务，提升单项目价值与客户粘性。
- **[唐山曹妃甸超级工厂投产]** -> [产能壁垒与产品大型化]: 全球首创全室内建造模式，年设计产能50万吨，可生产15-25MW风机基础，满足未来十年产品大型化需求，形成难以复制的规模与工艺壁垒。
- **[欧洲港口布局]** -> [本地化总装与服务能力]: 锁定丹麦、德国、西班牙三个核心港口，解决欧洲码头稀缺瓶颈，提供存储、组装服务，增强交付可靠性与盈利水平。
- **[SBTi与EcoVadis认证]** -> [构建绿色壁垒]: 成为全球海工基础行业首家设定科学碳目标的企业，获得国际ESG评级认可，在海外市场开拓中形成差异化竞争优势。
- **[在手订单超100亿]** -> [未来2年业绩确定性高]: 累计在手海外订单金额超100亿元，主要集中在未来两年交付，为收入与利润持续增长提供坚实基础。

## 风险警告
**第一大风险是海外市场政策与地缘政治风险。** 公司收入74%来自海外，且高度集中于欧洲。欧洲海风政策（如CfD拍卖机制、补贴力度）的转向、地缘政治冲突导致的供应链中断或贸易壁垒升级，将直接冲击订单获取与交付。公司虽已布局欧洲港口，但海外基地尚未形成产能，对欧洲本土政策的依赖度极高。

**第二大风险是重资产扩张带来的财务与运营压力。** 公司正处于大规模资本开支周期（曹妃甸基地、盘锦造船基地、新能源电站），报告期投资活动现金流净流出高达26.6亿元，资产负债率从37%升至43%。若海外订单交付节奏不及预期或原材料价格剧烈波动，高额的折旧与利息费用将侵蚀利润，且大规模产能爬坡期的管理难度不容小觑。
