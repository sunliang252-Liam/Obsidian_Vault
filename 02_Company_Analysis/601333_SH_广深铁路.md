# 601333.SH 深度透视

## 因果逻辑链
- **[高铁分流普速客流]** -> [旅客发送量下降7.59%]: 梅龙、广汕等高铁新线开通，导致公司担当的广深城际及普速长途车客座率下降，旅客发送量减少。
- **[委托运输服务扩张]** -> [营收增长5.89%]: 为其他铁路公司提供的运营、乘务服务工作量增加，叠加新增货运两端接取送达服务，推动委托运输服务收入增长8.55%。
- **[货运物流化改革]** -> [货运收入增长14.89%]: 全国铁路货运物流化改革，公司将货运两端接取送达服务费纳入“货运其他收入”核算，带动整体货运收入大幅增长。
- **[路网清算单价提高]** -> [路网清算收入增长13.98%]: 铁路路网市场化清算体系改革，货运路网清算服务单价提高，直接增厚公司路网清算及其他运输服务收入。
- **[资产处置收益激增]** -> [归母净利润增长34.49%]: 报告期内固定资产处置收益达3.73亿元，同比暴增20倍，成为净利润大幅超越营收增速的核心非经常性因素。
- **[成本刚性上涨]** -> [毛利率承压]: 设备租赁费、维修费、货物装卸费因工作量增加和清算单价提高而显著增长，导致主营业务毛利率下降0.63个百分点。
- **[高铁网络分流]** -> [客运结构转型]: 普速长途车和城际列车客流下滑，但公司通过增开过港直通车和跨线动车组，推动长途车和直通车收入分别增长20.42%和11.11%，实现结构性优化。

## 风险警告
**核心风险在于高铁分流对客运基本盘的侵蚀。** 尽管公司通过增开跨线动车组部分对冲，但广深城际列车旅客发送量同比下降5.25%，普速长途车下降9.22%，显示公司核心客运业务正面临“八纵八横”高铁网络持续完善带来的结构性替代。若未来高铁分流效应加剧，公司客运收入增长将高度依赖委托运输服务等非自有线路业务，盈利稳定性存疑。

**第二大风险是利润对非经常性损益的过度依赖。** 2025年归母净利润14.26亿元中，资产处置收益和政府补助等非经常性损益贡献了3.64亿元，占比高达25.5%。扣非后净利润仅增长3.85%，与营收增速基本持平。若剔除资产处置收益，公司盈利能力改善有限，未来可持续性面临挑战。
