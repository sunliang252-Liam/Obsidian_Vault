# 603956.SH 深度透视

## 因果逻辑链
- **[TOG业务项目验收延迟]** -> [收入下滑]: 受地方财政节奏影响，项目验收进度整体延后，导致2025年营业收入同比下降6.42%。
- **[降本增效与费用管控]** -> [亏损大幅收窄]: 通过优化人员结构、压缩管理费用（-19.03%）和研发费用（-44.41%），归母净利润同比减亏约5932.83万元。
- **[应收账款清收专项]** -> [现金流根本性好转]: 将现金流管理置于核心，经营性现金流量净额由负转正，同比大幅改善23,782.12万元。
- **[可转债转股完成]** -> [财务费用锐减与股本扩张]: 可转债全部转股，财务费用同比下降63.20%，同时总股本增加13.76%。
- **[商誉减值与信用减值]** -> [利润侵蚀]: 对经营不佳的子公司计提商誉减值，并对超4年账龄的应收账款按约70%迁徙率计提坏账，拖累减亏幅度。
- **[“河图AI平台”落地]** -> [业务结构优化]: 智慧水务业务收入同比增长27.16%，新签项目毛利率提升约5个百分点，预付款比例提高超20%。
- **[智能表计产线投产]** -> [新增长极培育]: 年产30万台超声波水表产线投产，但该业务收入同比下降14.53%，尚处于市场拓展初期。

## 风险警告
**核心风险在于TOG业务依赖与应收账款质量。** 公司收入确认高度依赖地方政府项目验收，2025年收入下滑与减值激增已暴露此脆弱性。尽管现金流改善，但超4年账龄应收款约70%的迁徙率表明坏账风险仍在累积，若地方财政持续紧张，减值损失可能继续侵蚀利润。

**战略转型的阵痛与不确定性。** 公司正向高价值的智慧水务综合解决方案转型，但项目转化周期长于传统硬件，导致收入确认不及预期。同时，前期收购的子公司（如上海杰狮）出现亏损并计提商誉减值，表明外延并购的整合风险尚未完全释放。新业务（智能表计）尚处培育期，短期内难以对冲传统业务下滑。
