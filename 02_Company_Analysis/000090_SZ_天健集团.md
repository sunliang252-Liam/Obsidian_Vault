# 000090.SZ 深度透视

## 因果逻辑链
- **[地产项目竣工结转]** -> [营收增长5.36%]: 房地产收入同比+15.31%，但毛利率因成本上升（+31.99%）大幅下滑10.53个百分点，导致增收不增利。
- **[地产项目减值计提]** -> [净利润暴跌63.99%]: 资产减值损失高达9.24亿元（占利润总额-259.85%），主要源于地产项目存货跌价，直接吞噬利润。
- **[财务费用资本化减少]** -> [财务费用激增70.90%]: 地产项目竣工后，借款利息停止资本化，费用化利息大增，侵蚀当期利润。
- **[建筑施工收入萎缩]** -> [整体业绩承压]: 建筑施工收入同比-7.45%，行业处于深度调整期，新签合同额85.85亿元，在手订单193.98亿元，增长乏力。
- **[经营活动现金流锐减]** -> [现金流压力凸显]: 经营现金流净额同比-85.37%至1.67亿元，主要因地产销售回款放缓及税费支出增加，与净利润严重背离。
- **[综合开发毛利率恶化]** -> [核心盈利模式受损]: 房地产业务毛利率从27.23%降至16.69%，成本增速（+31.99%）远超收入增速（+15.31%），反映去化压力下的价格战与成本刚性。
- **[城市服务业务稳定]** -> [提供业绩缓冲]: 城市服务收入同比+2.16%，毛利率35.55%，虽体量小但盈利稳定，为集团提供一定安全垫。

## 风险警告
**核心风险：地产下行周期中的资产减值与盈利崩塌。** 公司2025年净利润暴跌64%，主因是高达9.24亿元的资产减值损失，这直接反映了其在深圳、苏州等核心城市的地产项目面临严重的去化压力和价格下跌风险。房地产业务毛利率骤降10.53个百分点，表明“以价换量”已成常态，未来若市场持续低迷，减值压力将反复出现，侵蚀股东权益。

**现金流与债务风险交织。** 经营现金流净额同比骤降85.37%，仅1.67亿元，而同期有息负债规模高达206.9亿元（含永续债），利息保障倍数从2.19倍降至1.38倍。公司虽为国企，融资成本较低（2.33%-3.98%），但地产销售回款不畅将直接考验其偿债能力，尤其是对商品房承购人提供的77.67亿元担保，构成潜在的或有负债风险。
