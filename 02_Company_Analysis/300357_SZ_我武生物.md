# 300357.SZ 深度透视

## 因果逻辑链
- **[主导产品“粉尘螨滴剂”稳健增长]** -> [营收与利润双增]: 核心产品收入同比增长11.80%，贡献93.18%营收，是业绩基本盘。
- **[第二增长曲线“黄花蒿花粉滴剂”爆发]** -> [营收结构优化]: 该产品收入同比大增101.21%，开始规模化销售，降低对单一产品的依赖。
- **[“诊断+治疗”产品线完善]** -> [点刺液收入高增85.47%]: 新获批点刺液品种放量，完善了过敏诊疗闭环，带动整体解决方案销售。
- **[高毛利率与费用控制]** -> [净利润增速超营收]: 毛利率维持95%以上，销售费用率仅增10.08%，净利润增速（19.86%）高于营收增速（14.81%）。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比大增61.25%，远超净利润增速，显示回款能力增强。
- **[研发投入聚焦升级]** -> [巩固长期壁垒]: 研发投入占营收11.57%，推进“屋尘螨膜剂”等升级产品，旨在提升患者依从性，维持技术领先。

## 风险警告
**主导产品单一风险依旧突出。** “粉尘螨滴剂”占营收超93%，尽管“黄花蒿滴剂”增长迅速，但体量尚小。任何针对该产品的政策变化（如集采、降价）、竞争格局恶化或质量问题，都将对公司业绩造成毁灭性打击。公司虽在拓展新管线，但短期内无法改变这一结构性依赖。

**新药研发与政策风险并存。** 公司研发管线中，干细胞、天然药物等新领域投入巨大但商业化前景不明，且已出现“烟曲霉点刺液”项目终止并计提减值。同时，医药行业监管趋严、招标降价压力持续，高毛利率面临侵蚀风险。公司需证明其能持续将研发投入转化为可商业化的产品，并应对日益严峻的医保控费环境。
