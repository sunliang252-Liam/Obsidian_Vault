# 601288.SH 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [利息净收入下降1.9%]: LPR下调及市场利率低位运行导致生息资产收益率下降，尽管规模增长，但利率变动拖累利息净收入减少551亿元。
- **[财富管理转型与代销业务爆发]** -> [手续费及佣金净收入增长16.6%]: 理财、代销基金收入大增，代理业务收入同比增长87.8%，成为营收增长核心驱动力。
- **[“三农”县域贷款高增]** -> [巩固息差与存款基础]: 县域贷款余额10.94万亿元，增速11.0%，高于全行平均，且县域存款成本低、稳定性强，有效对冲了整体息差下行压力。
- **[金融投资规模扩张]** -> [投资收益大幅增长]: 债券投资规模增加2.47万亿元，叠加利率下行带来的公允价值变动收益，推动其他非利息收入增长24.6%。
- **[普惠与科技贷款高速扩张]** -> [以量补价维持营收增长]: 普惠贷款增速20.9%、科技贷款增速20.1%，通过规模扩张弥补了利率下降对利息收入的负面影响。
- **[成本收入比上升]** -> [利润增速承压]: 业务及管理费增长4.4%，成本收入比升至35.18%，显示在业务扩张和科技投入背景下，成本管控面临压力。
- **[不良贷款率持续下降]** -> [信用减值损失减少]: 不良率降至1.27%，拨备覆盖率虽略降至292.55%但仍处高位，信用减值损失同比减少2.8%，反哺利润。

## 风险警告
**净息差持续收窄是核心风险。** 2025年净利息收益率降至1.28%，同比下降14个基点，且降幅有扩大趋势。在LPR下调、存量房贷重定价及存款定期化背景下，息差下行压力短期内难以逆转。尽管通过“以量补价”维持了利息收入规模，但若资产端收益率继续快速下行而负债成本降幅有限，利息净收入可能加速萎缩，直接侵蚀利润根基。

**资产质量面临结构性压力。** 虽然整体不良率下降，但关注类贷款迁徙率从18.61%升至21.30%，显示潜在风险正在积聚。个人经营类贷款（增速19.9%）和普惠贷款（增速20.9%）高速扩张，在经济下行周期中，此类零售贷款的信用风险滞后暴露可能对资产质量造成冲击。同时，房地产与地方政府债务风险化解仍在进行中，需警惕尾部风险。
