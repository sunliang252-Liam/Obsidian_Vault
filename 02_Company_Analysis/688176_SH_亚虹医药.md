# 688176.SH 深度透视

## 因果逻辑链
- **[希维她®获批上市，填补无创治疗空白]** -> [重塑CIN2治疗格局]: 全球首创光动力产品，实现“门诊即治即走”无创治疗，使近60%患者免于手术，有望从“一刀切”转向“优选无创”，开辟蓝海市场。
- **[商业化2.0升级，销售能力提升]** -> [营收同比增长37.49%]: 自营+招商双模式驱动，欧优比®、迪派特®销量增加，带动营收从2.02亿增至2.77亿，商业化能力初步验证。
- **[持续高研发投入，管线深度布局]** -> [亏损扩大至-4.16亿]: 研发费用2.83亿（占营收102%），叠加商业化推广费用，导致归母净亏损同比扩大8.4%，累计未弥补亏损达18.45亿。
- **[海克威®联合蓝光膀胱镜系统获批]** -> [开启膀胱癌蓝光诊疗新时代]: 国内首个获批的膀胱镜蓝光显影剂，可显著提高原位癌检出率，降低复发率，填补指南推荐无药可用的空白。
- **[APL-2401进入临床，获“30日通道”批准]** -> [验证TAIDD平台研发效率]: 自主研发的FGFR2/3双靶点抑制剂，22个工作日获批临床，体现公司AI驱动药物发现平台的先进性与高效。
- **[APL-1401 I期临床展现积极疗效信号]** -> [拓展自身免疫疾病新赛道]: 全新机制DBH抑制剂，在溃疡性结肠炎中观察到组织学改善率41.9%，有望成为First-in-class疗法，降低对单一肿瘤管线的依赖。
- **[欧优比®、迪派特®、欧纳琳®进入医保]** -> [提升药品可及性与市场份额]: 三款商业化产品均进入国家医保目录，通过“以价换量”策略，有望快速提升销售收入，改善现金流。

## 风险警告
**核心风险在于持续亏损与商业化变现的不确定性。** 公司2025年净亏损4.16亿元，累计未弥补亏损18.45亿元，且短期内无法盈利。虽然营收增长37%，但销售费用（2.72亿）几乎与营收（2.77亿）持平，商业化效率有待验证。若核心创新药希维她®和海克威®上市后放量不及预期，公司将面临严重的现金流压力，需持续依赖外部融资。

**研发管线高度集中且存在失败风险。** 公司核心价值在于希维她®、海克威®及APL-1202等创新管线。希维她®虽已获批，但国际市场（欧美）上市仍需时间且存在不确定性；APL-1202在MIBC新辅助治疗中虽获积极信号，但后续开发及海外合作仍存变数。任何核心管线的临床失败或商业化受阻，都将对公司估值和前景造成重大打击。
