# 300628.SZ 深度透视

## 因果逻辑链
- **[会议产品高速增长]** -> [营收结构优化]: 会议产品收入同比增长21.95%，占比提升至40.36%，成为业绩增长主引擎，对冲了桌面终端下滑。
- **[AI技术深度融合]** -> [产品竞争力提升]: 将AI降噪、智能追踪、Copilot集成嵌入会议与云办公终端，推动新品（MeetingBoard Pro、UH4x耳机）快速获市场认可。
- **[混合办公常态化]** -> [云办公终端放量]: 商务耳机等云办公终端收入增长15.99%，受益于移动与远程办公场景的刚性需求。
- **[全球化渠道与生态合作]** -> [海外市场稳健]: 与微软、Zoom深度绑定，叠加全球经销商网络，欧洲/美洲收入分别增长6.42%/6.89%，维持90%+海外收入占比。
- **[轻资产+外协生产]** -> [高利润率]: 将生产外包，聚焦研发与品牌，实现净利率43.11%，毛利率63.32%，体现极致运营效率。
- **[高研发投入深耕细分]** -> [技术护城河]: 研发投入8.78%，研发人员占比53.88%，自研音视频算法与AI引擎，构筑底层技术壁垒。
- **[助听器新业务孵化]** -> [打开第二增长曲线]: 推出AI智能验配助听器（易声品牌），通过电商渠道试水，从企业通信向消费医疗延伸。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 2025年营收增长7.33%，但净利润同比下滑1.78%，净利率从47.1%降至43.11%。更关键的是，经营性现金流净额同比骤降26.97%，远低于净利润。这源于应收账款激增67.8%（至15.47亿）和存货暴增79.9%（至14.63亿），公司解释为应对海外产能与原材料价格变化而增加备货，但若下游需求不及预期，将面临存货跌价与坏账的双重压力。

**地缘政治与汇率风险是悬顶之剑。** 公司90%以上收入来自海外，且以美元结算。若中美贸易摩擦加剧导致关税大幅提升，或人民币进入升值通道，将直接侵蚀毛利率与汇兑损益。2025年财务费用已因美元汇率变动同比大增87.87%，显示其对汇率波动的高度敏感。尽管公司布局海外产能，但短期难以完全对冲政策突变风险。
