# 301290.SZ 深度透视

## 因果逻辑链
- **[带量采购政策落地与市场竞争加剧]** -> [吻合器零部件业务毛利率大幅下滑]: 政策压价与竞争加剧导致下游客户需求放缓，上游零部件供应商议价能力减弱，毛利率同比下降16.63个百分点。
- **[子公司经营业绩不及预期]** -> [计提巨额商誉与无形资产减值]: 孜航精密、昶恒精密受行业环境影响，盈利未达预期，导致公司计提商誉减值9,971.90万元及无形资产减值562.92万元，合计超1亿元。
- **[核心吻合器业务展现韧性]** -> [整体营收下滑但核心业务稳定]: 吻合器产品收入同比增长4.72%，电动腔镜吻合器增长10.32%，成为业绩基本盘，对冲了医疗设备（-40.40%）和零部件（-28.43%）的下滑。
- **[新产品研发与取证]** -> [布局未来增长点]: 2025年新增14项医疗器械注册证（含3项III类），涉及电动吻合器、超声刀等，新产品销售额1,742.11万元，为后续增长储备动能。
- **[合成生物领域拓展]** -> [寻求第二增长曲线]: 设立东星生物，与上海交通大学合作研发重组胶原蛋白，签署800万元研发合同，探索新赛道。
- **[海外市场本地化深耕]** -> [提升全球品牌影响力]: 在俄罗斯、巴西等重点市场设立办事处，从传统代理转向品牌与学术推广，亮相多个国际医疗展会。
- **[内部降本增效]** -> [提升运营效率]: 优化工装工艺、引入自动化设备、搭建财务共享中心，子公司获评智能工厂与绿色工厂，但成本管控尚未完全对冲收入下滑与减值影响。

## 风险警告
**核心风险在于商誉减值“余震”与主营业务盈利能力的双重承压。** 截至2025年末，公司账面商誉仍高达4.34亿元，主要来自威克医疗和孜航精密。尽管2025年已计提近1亿元减值，但若吻合器带量采购政策持续深化、市场竞争进一步加剧，导致子公司经营持续低于预期，未来仍有大规模减值风险，将对利润表造成持续性冲击。

**主营业务层面，公司面临“量价齐跌”的结构性困境。** 吻合器零部件业务毛利率暴跌16.63个百分点，是盈利能力恶化的主要推手，且该业务收入占比不低，短期修复难度大。同时，医疗设备业务收入骤降40.40%，显示代理业务与自产设备均面临市场挑战。公司虽在电动吻合器等高端产品上取得增长，但体量尚小，难以完全弥补传统业务的失速。若不能快速提升高毛利新品占比并有效控制成本，公司盈利拐点将难以预期。
