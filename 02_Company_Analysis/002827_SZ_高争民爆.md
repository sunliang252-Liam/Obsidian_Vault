# 002827.SZ 深度透视

## 因果逻辑链
- **[西藏基建与矿业高景气]** -> [营收增长7.99%]: 西藏自治区“路、水、矿”等大型项目持续建设，驱动公司民爆器材与爆破服务需求稳步提升。
- **[爆破服务一体化转型]** -> [爆破业务收入9.3亿，占比50.89%]: 公司从“卖产品”转向“卖服务”，依托双一级资质构建全产业链，爆破服务成为最大收入来源。
- **[电子控制模块放量]** -> [营收增长31.87%]: 孙公司上海兴软电子雷管芯片模组业务受益于行业电子雷管渗透率提升及新客户拓展，实现高速增长。
- **[硝酸铵成本下降]** -> [毛利率改善]: 2025年硝酸铵价格同比下降约10%，有效对冲了部分成本压力，支撑了民爆器材43.38%的高毛利率。
- **[经营现金流大幅改善]** -> [现金流净额暴增714倍]: 营收增长叠加回款效率提升，经营活动现金流净额从27.7万激增至1.98亿，盈利质量显著优化。
- **[股权激励绑定核心团队]** -> [激发增长动能]: 2025年向52名激励对象授予限制性股票，将管理层利益与公司长期业绩深度绑定。
- **[区域垄断地位]** -> [高毛利率与定价权]: 作为西藏唯一民爆全产业链上市公司，在区域内占据主导地位，民爆器材毛利率高达43.38%，远超行业平均。

## 风险警告
**产能瓶颈与增长天花板。** 公司炸药产能利用率已接近100%（胶状乳化炸药100%，混装炸药94%），产能不足成为制约发展的首要瓶颈。虽然计划收购黑龙江海外民爆以缓解产能压力，但跨区域整合与管理难度巨大，且西藏市场容量有限，长期增长高度依赖区内基建与矿业投资的持续性，存在周期性波动风险。

**应收账款高企与坏账风险。** 公司应收账款高达11.03亿元，占总资产38.29%，且规模随业务扩张持续增长。主要客户虽为大型矿山企业，但工程施工业务结算周期长，若客户经营恶化或项目回款延迟，将面临较大的信用减值损失风险，对现金流和利润构成潜在冲击。
