# 000626.SZ 深度透视

## 因果逻辑链
- **[传统贸易毛利微薄]** -> [公司连续三年扣非净利润为负]: 商品贸易毛利率仅0.47%，在行业产能过剩、信息透明化趋势下，传统赚取购销价差的模式已无法覆盖运营成本。
- **[战略转型聚焦作物科学]** -> [作物科学板块毛利率高达37.11%]: 公司从低毛利贸易向高毛利的生物农药、种业转型，该板块收入增长12.58%，成为利润结构优化的核心驱动力。
- **[商誉减值侵蚀利润]** -> [2025年归母净利润仍亏损1.34亿元]: 尽管主业减亏，但计提1.47亿元商誉减值准备，直接导致公司账面净利润转负，暴露了前期并购整合的风险。
- **[种业布局尚处起步期]** -> [短期无法贡献业绩，但构筑长期壁垒]: 公司成立远大种业（甘肃）布局中药材种业，业务基础薄弱，研发与市场验证需周期，短期是成本中心，长期是价值源头。
- **[大宗商品金融化加剧]** -> [贸易业务盈利波动性增大]: 商品定价权从供需基本面转向宏观资金博弈，公司虽运用期货套保对冲，但衍生品投资仍产生亏损，增加了经营不确定性。
- **[核心原料价格大幅波动]** -> [特种油脂业务毛利率承压]: 棕榈油、椰子油等核心原料价格2025年“先扬后抑”，导致特种油脂毛利率同比下降2.82个百分点，成本管控压力显著。
- **[现金流与净利润严重背离]** -> [经营活动现金流净额为-5.82亿元]: 公司商品采购支付现金增加，导致经营现金流大幅转负，表明公司营运资金管理面临挑战，盈利质量有待提升。

## 风险警告
**核心风险在于战略转型的“青黄不接”与商誉减值“后遗症”。** 公司传统贸易业务已陷入低毛利泥潭，扣非净利润连续三年为负，造血能力严重不足。尽管作物科学和种业是未来方向，但当前规模极小（仅占收入0.43%），且种业布局尚处“从0到1”的起步阶段，研发投入大、回报周期长，短期内无法弥补贸易业务的亏损窟窿。2025年再次计提1.47亿商誉减值，表明前期并购的生物农业资产整合效果远不及预期，资产质量存在持续恶化的风险。

**财务健康度与现金流风险不容忽视。** 公司2025年经营活动现金流净额由正转负，骤降至-5.82亿元，与净利润严重背离，主要因采购支付增加，这在大宗商品价格波动剧烈的背景下极易引发流动性危机。同时，公司资产负债率高企，且大量资产（含子公司股权）已用于质押融资，财务弹性空间有限。若贸易业务持续失血，而新业务无法快速形成正向现金流，公司可能面临较大的偿债压力。

> 远大产业控股股份有限公司(以下简称“远大控股”或“公司”)成立于1994年6月,1996年10月公司在深交所成功发行上市(股票代码:000626,股票简称:远大控股)。公司将在大力发展大宗商品贸易的同时,深入推进油脂产业和作物科学战略转型,兼顾环境、社会、公司治理(ESG)三大维度,力争成为一家将贸易与产业、高科技深度融合的大型贸产一体化高科技企业。主营业务涵盖贸易、作物科学、油脂三大领域,在境外多个国家和地区设立了业务机构。作物科学领域,公司核心产品微生物源生物杀菌剂春雷霉素市场领先、中生菌素市场独家。公司以远大生物农业为作物科学领域管理和销售平台,拥有麦可罗生物、凯立生物两个研产销一体化、原药制剂一体化运行的高新技术企业。公司高度重视生物农药研发创新,建立了一支专业的研发和技术团队,通过研发创新和应用技术创新,利用独家产品形成具有市场竞争力的产品管线,结合自身研产销一体化优势为客户提供综合解决方案,秉承“以创新高效的生物技术,服务于可持续发展的现代农业”使命,致力于通过生物科学技术在农业领域的创新和应用,实现更高效率、更可持续的农业生产,满足消费者更加安全、更健康的食品需求。麦可罗生物拥有“国家企业技术中心”、“生物农药国家地方联合工程研究中心”,设立邓子新院士工作站,通过CNAS实验室认可,牵头制定了多个国家标准和行业标准。凯立生物围绕中生菌素产品形成了一系列专利技术成果,并对专利技术成果持续研发升级,成功制备出不同含量的原药和制剂产品推向市场,在农作物杀菌抑菌的基础上达到环保无残留、安全无污染的目的。  油脂业务领域,公司经营的油脂产品主要包括棕榈油、豆油、菜粕、豆粕以及食用特种油脂等,包括众多国内外知名企业。公司在油脂领域打造集资源、研发、生产和产业服务为一体的全产业链经营模式,旗下阿黛尔等品牌的特种油脂广受市场好评。公司高度重视研发创新,旗下特种油脂生产企业鸿信食品拥有广东省多元化安全健康烘焙专用油脂工程技术研发中心,及时掌握国际先进的烘焙油脂专业技术,不断寻求产品创新,深入研究不同油料特性,在风味的组合筛选、发酵技术的专研、酶解技术的应用等多方面均取得显著成绩,建立了良好的产品口碑,为客户提供从原料产品到烘焙商品的落地方案服务。公司坚持安全和质量至上,建立并实施了从原辅料到产成品的质量与食品安全管理体系,严格按照国家油制品食品卫生标准规范设计,生产重要环节实现自动调控及记录,保证产品的质量、安全及可追溯性。公司旗下远大油脂(东莞)作为中国华南地区的大型食用油脂储备企业之一,于2021年获批成为大连商品交易所棕榈油指定交割仓库,于2022年作为马来西亚境外第一家企业通过马来西亚可持续发展棕榈油供应链认证。  贸易领域,公司主要从事能源化工、金属、橡胶、农产品等大宗商品贸易和外贸进出口业务。公司在大宗商品贸易领域长期保持领先地位,公司坚持以产业为核心、以人才为导向,长期深耕贸易领域,与多家世界500强企业或行业巨头建立了战略伙伴关系,为国内上千家中小生产企业提供商品、信息、物流仓储等综合服务;公司在进出口外贸领域,通过配套跨境电商等多种形式,助力中小型外贸企业的市场拓展;经营模式从单一的渠道贸易向产业链整合、仓储物流、价格管理、产贸深度融合等新型平台式贸易综合服务商转变。   远大控股秉承“忠诚、朴实、勤奋、创新”的企业精神与“敬天、爱人、感恩、分享”的企业价值观,践行“为您创造价值”的企业使命,努力打造具有行业领先地位的国际化企业集团。
