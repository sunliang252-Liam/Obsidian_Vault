# 000906.SZ 深度透视

## 因果逻辑链
- **[营收规模高速扩张]** -> [净利润大幅下滑39.62%]: 营收增长16.64%至2355亿，但归母净利润仅2.23亿，核心原因是毛利率极低（0.91%）且扣非净利润为负，规模扩张并未带来利润同步增长。
- **[套期保值业务常态化]** -> [扣非净利润为负]: 公司运用期货等衍生品对冲价格风险，产生的公允价值变动损益及处置损益被计入非经常性损益，导致扣非净利润为-1.68亿，但加回后实际扣非净利润为0.93亿，说明主业盈利能力微薄。
- **[能源化工与新能源板块高增长]** -> [业务结构优化]: 两大板块营收合计占比达36.93%，同比提升8.3个百分点，有效对冲了传统黑色板块增速放缓的影响，成为营收增长的主要驱动力。
- **[国际化战略加速]** -> [国际业务营收大增32.5%]: 海外经营网络扩张至89个国家和地区，国际业务营收达823亿元，成为公司第二大增长引擎，但同时也带来了汇率风险和地缘政治风险。
- **[实物量高速增长]** -> [毛利率持续承压]: 经营实物量同比增长41.47%至1.5亿吨，但各主要品类毛利率均低于1.5%，显示公司以价换量，通过低毛利、高周转的贸易模式获取市场份额。
- **[高杠杆运营]** -> [财务风险积聚]: 总资产增长19.47%至417亿，但净资产仅67.7亿，资产负债率极高。担保余额占净资产比例高达222.82%，且存在重大诉讼，资金链和信用风险突出。
- **[政府补助依赖]** -> [利润质量存疑]: 计入当期损益的政府补助高达1.93亿元，占利润总额的20.56%，若剔除该非经常性收益，公司实际盈利能力更弱。

## 风险警告
**核心风险：低毛利高杠杆下的利润脆弱性与信用风险。** 公司营收2355亿，但综合毛利率不足1%，净利润率仅0.09%，盈利能力极其微薄。同时，公司资产负债率极高，对外担保余额占净资产比例高达222.82%，且存在涉及16.3亿元的未决重大诉讼（与德龙系合同纠纷）。一旦下游客户出现信用违约或大宗商品价格剧烈波动，公司将面临巨大的坏账损失和流动性危机，利润可能瞬间被侵蚀。

**次要风险：套期保值会计处理掩盖真实盈利，主业造血能力存疑。** 公司扣非净利润连续两年为负，虽然解释为套期保值业务计入非经常性损益所致，但加回后实际扣非净利润也仅为0.93亿元。这表明公司核心的供应链集成服务业务（基差贸易、产业金融等）盈利能力极弱，主要依赖政府补助和投资收益维持账面利润。若未来套保策略失效或政府补助减少，公司可能陷入实质性亏损。
