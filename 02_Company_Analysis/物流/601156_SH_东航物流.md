# 601156.SH 深度透视

## 因果逻辑链
- **[跨境电商政策冲击]** -> [综合物流解决方案收入下降14.65%]: 全球多国取消小额包裹免税政策，导致跨境电商直邮需求萎缩，公司该板块收入从124.76亿元降至106.48亿元。
- **[全货机运力扩张]** -> [航空速运收入增长20.79%]: 报告期内引进4架B777全货机，机队规模增至18架，叠加日利用率创历史新高（13.09小时），推动航空速运板块收入达109.14亿元。
- **[产地直达业务扩张]** -> [贸易成本飙升53.12%]: 公司聚焦生鲜、医药冷链，产地直达货量增长44.86%，带动贸易成本从19.34亿元激增至29.61亿元，成为成本端最大增量。
- **[客货联动深化]** -> [货邮总周转量增长11.13%]: 独家经营东航800余架客机腹舱，统筹客货航线编排，实现客机腹舱载运率提升0.94个百分点，总周转量达87.87亿吨公里。
- **[智慧货站投运]** -> [人力干预减少近50%]: 浦东西区智慧货站启用，AI判图、AGV无人搬运、立体仓储等技术应用，显著提升运营效率与安全裕度。
- **[航油价格波动]** -> [利润敏感性极高]: 航油成本占营业成本15.94%，假设均价变动100元/吨，将影响利润约5693万元，2026年地缘冲突加剧此风险。
- **[外采运力收缩]** -> [航空运费成本下降55.31%]: 公司主动调整运力结构，减少外采运力依赖，航空运费成本从41.12亿元大幅降至18.38亿元，优化了成本结构。

## 风险警告
**核心风险：地缘政治与航油成本的“双杀”效应。** 2026年美国对伊朗军事行动导致中东空域管制、霍尔木兹海峡航运中断，国际油价剧烈波动。航油是公司第二大成本项，且机队规模持续扩大，航油成本对利润的敏感性极高。若油价持续高位运行，将直接侵蚀航空速运板块的利润，甚至可能抵消运力扩张带来的收入增长。

**结构性风险：跨境电商业务的政策“断崖”。** 全球多国（包括欧盟2026年7月）取消小额包裹免税政策，已导致公司跨境电商解决方案收入同比下滑36.18%。该业务是综合物流解决方案的核心，其萎缩不仅直接拖累整体营收，更暴露出公司对单一客户（头部电商平台）和特定政策环境的过度依赖。转型“海运+海外仓”模式能否成功，存在巨大不确定性。

**财务风险：负债率攀升与资本开支压力。** 为扩张机队，公司以融资租赁方式引进飞机，导致使用权资产暴增46.66%，租赁负债增长30.27%，资产负债率从26.21%升至30.65%。同时，智慧货站、冷链基础设施等资本开支持续，若未来现金流不及预期（如跨境电商业务持续恶化），高额的租赁负债和折旧将构成财务压力。

**公司简介（F10 原文）**

> 东方航空物流股份有限公司(以下简称“东航物流”)是一家现代综合物流服务企业,总部位于上海,于2021年6月9日在上海证券交易所主板挂牌上市(股票简称:东航物流,股票代码:601156),致力于为全球客户提供安全、高效、精准、便捷的物流服务。东航物流旗下拥有中国货运航空、东航快递、东航运输、东航供应链、东航冷链等子公司及境内外多个站点及分支机构。公司在上海虹桥和浦东机场设有运营基地,具备可满足特殊性质货品仓储需求的温控货物仓库(含冷藏库、冷冻库和恒温库)、危险品仓库、贵重品仓库、活体动物仓库以及超限货物仓库等多元化特种仓储资源。同时,在北京、昆明、西安、武汉、南京、济南、青岛、兰州、合肥、太原等枢纽机场设有自营货站,覆盖了具有高网络价值和辐射带动效应的国内核心航空货运枢纽区域。依托“天地合一”的资源保障、丰富的运营资质认证、行业领先的质量管理体系和多元化的泛航空物流产品服务体系,东航物流集航空速运、货站操作、多式联运、特种仓储、供应链服务、定制化物流解决方案、跨境电商解决方案、冷链运输服务等业务功能于一体,并在运营实践中培育和形成了设计、优化、组织、实施、管理等全程物流服务和资源整合能力,能满足客户多方位的物流需求,提供“一站式”物流服务。锐意奋进中的东航物流将坚持新发展理念,持续强化战略引领和科技支撑作用,积极探索航空物流新质生产力,在强化企业治理、扩大业务合作、提升服务品质、履行企业社会责任的过程中,加快打造符合新时代要求的安全物流、绿色物流、智慧物流、民生物流,全力开启创建“世界一流”新航程,奋力开创企业可持续高质量发展新篇章。
