# 300013.SZ 深度透视

## 因果逻辑链
- **[新增国际货代业务]** -> [营收增长50.5%，但亏损]: 中欧班列、航空货运等新业务贡献2.74亿元收入，但处于起步爬坡期，规模效应未形成，导致增收不增利。
- **[3C电子存量业务萎缩]** -> [传统仓配收入下降10.78%]: 电子信息制造业客户产能外迁，叠加行业竞争加剧，公司核心存量业务规模持续下滑。
- **[控股股东赋能]** -> [融资成本大幅降低]: 引入国资控股股东后，公司融资能力恢复，财务费用同比减少68.36%，是亏损收窄的关键因素。
- **[新业务培育期]** -> [经营现金流大幅净流出2.2亿元]: 国际货代业务扩张导致采购支付增加，叠加支付诉讼赔偿款1.05亿元，现金流压力巨大。
- **[历史诉讼尘埃落定]** -> [非经常性损益改善]: 人保北京分公司诉讼终审判决，相关预计负债转出，减轻了历史包袱。
- **[业务结构转型]** -> [华中地区收入占比跃升至60.83%]: 公司从华东3C电子基地向郑州等内陆枢纽转移，中欧班列业务驱动区域收入结构剧变。
- **[数智化研发投入]** -> [技术产品化初现]: 研发WMS、TMS及智能仓储系统，形成可对外输出的技术产品，开辟轻资产技术服务收入路径。

## 风险警告
**核心风险在于新旧动能转换的“青黄不接”。** 公司营收暴增50.5%主要依赖低毛利的货运代理业务（毛利率-2.05%），而高毛利的传统3C仓储业务仍在萎缩。新业务尚处“烧钱”培育期，无法贡献利润，导致公司虽大幅减亏但仍未盈利。更严峻的是，经营现金流净流出高达2.2亿元，远超净利润亏损额，表明业务扩张严重依赖外部融资，造血能力极度脆弱。

**历史遗留问题与国际化新风险叠加。** 虽然人保诉讼案已结，但公司仍面临珠海冠宇等大额诉讼，潜在赔偿风险未完全消除。同时，公司正激进拓展中欧班列、越南等海外业务，地缘政治、汇率波动及海外管理半径扩大带来的不确定性，可能随时冲击脆弱的盈利修复进程。应收账款激增至2.5亿元，占流动资产62%，回款风险不容忽视。
