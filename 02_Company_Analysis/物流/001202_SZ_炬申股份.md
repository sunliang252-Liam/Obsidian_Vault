# 001202.SZ 深度透视

## 因果逻辑链
- **[海外驳运项目扩张]** -> [营收暴增81.65%]: 几内亚铝土矿转运业务及新设香港航运子公司，驱动运输服务收入同比大增108.76%，成为收入增长核心引擎。
- **[运输业务毛利率极低]** -> [增收不增利]: 运输服务毛利率仅2.38%，收入高增但利润贡献有限，导致净利润同比下降11.15%。
- **[业务规模快速扩张]** -> [现金流大幅恶化]: 经营性应收项目增加4.03亿元，经营活动现金流净额由正转负至-4307万元，同比暴跌127.14%。
- **[大规模资本开支]** -> [资产结构重型化]: 投资活动现金流出4.23亿元（+108.12%），主要用于驳运项目及仓储建设，总资产增长38.02%至20.33亿元。
- **[仓储业务高壁垒高毛利]** -> [利润稳定器]: 仓储综合服务毛利率高达57.30%，贡献主要利润，且拥有四大期货交易所交割库资质，护城河稳固。
- **[客户与供应商高度集中]** -> [经营风险敞口大]: 前五大客户销售占比38.98%，前五大供应商采购占比70.47%，对单一客户/供应商依赖度高。
- **[融资结构转变]** -> [财务费用激增]: 为支持扩张，新增长期借款及融资，财务费用同比上升71.97%，侵蚀利润。

## 风险警告
**核心风险在于“增收不增利”与“现金流断裂”的双重困境。** 公司营收暴增81.65%，但净利润反降11.15%，主因是低毛利的运输业务占比过高（83.44%），其2.38%的毛利率无法覆盖扩张带来的管理费用（+43.95%）和财务费用（+71.97%）的激增。更危险的是，经营活动现金流净额由正转负至-4307万元，与净利润严重背离，表明公司增长高度依赖营运资金的垫付和外部融资，造血能力严重不足。

**海外扩张与重资产投资带来的巨大不确定性。** 公司大量资金投入几内亚驳运项目及仓储建设，投资活动现金流出高达4.23亿元。海外业务面临政治、安全、汇率等多重风险，而重资产投资回报周期长，一旦项目收益不及预期或海外环境生变，将导致资产减值与流动性危机。同时，公司为子公司提供的担保余额高达78.78亿元，占净资产927.31%，或有负债风险极高。
