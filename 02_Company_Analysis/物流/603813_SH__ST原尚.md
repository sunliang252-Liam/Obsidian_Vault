# 603813.SH 深度透视

## 因果逻辑链
- **[传统燃油车市场萎缩]** -> [汽车零部件物流收入骤降33.83%]: 下游主机厂订单减少，导致公司核心业务收入大幅下滑，但仓库租金、车辆折旧等固定成本刚性，毛利率被严重侵蚀。
- **[大力拓展非汽车物流]** -> [非汽车物流收入逆势增长53.35%]: 公司主动切入电商、能源、航空等新赛道，对冲了传统主业下滑，使总营收实现5.93%的正增长。
- **[新业务“以价换量”]** -> [综合毛利率暴跌8.12个百分点至8.81%]: 为快速抢占市场，新业务初期毛利率偏低，叠加传统业务成本刚性，导致增收不增利，亏损加剧。
- **[收购和川友]** -> [开启“制造+物流”双轮驱动]: 通过同一控制下合并，将汽车零部件制造能力内化，旨在形成供应链闭环，打造第二增长曲线。
- **[氢能重资产投入]** -> [投资活动现金流大幅净流出1.04亿元]: 公司为响应“双碳”战略，采购氢燃料电池车及建设空港物流中心，导致资本开支激增，现金流承压。
- **[融资渠道收窄]** -> [财务费用激增23.6%]: 因被实施退市风险警示，公司融资成本上升，同时新项目贷款及租赁利息增加，进一步侵蚀利润。
- **[应收账款回款延迟]** -> [应收账款同比暴增97.56%]: 部分客户回款周期延长，导致资金占用增加，加剧了公司的流动性压力。

## 风险警告
**核心风险在于“转型失速”与“财务恶化”的恶性循环。** 公司正处在从传统汽车物流向综合物流的艰难转型期，新业务虽带来收入增长，但“以价换量”的扩张模式导致毛利率大幅下滑，亏损额同比扩大35%。更危险的是，公司已被实施退市风险警示（*ST），融资能力严重受限，而氢能车辆、空港物流中心等战略项目又需要巨额资本开支，这导致投资活动现金流大幅净流出，公司不得不依赖新增银行贷款维持运营，财务费用高企，进一步吞噬利润。

**第二重风险是资产减值的“灰犀牛”。** 公司账面存在高达4.82亿元的使用权资产和3.81亿元的固定资产，且审计师已将“长期资产减值”列为关键审计事项。传统燃油车业务萎缩导致部分仓储和运输资产利用率下降，若未来业务转型不及预期，可能面临大规模资产减值风险，对净资产造成重大冲击。此外，公司仍有大量历史诉讼形成的应收款项尚未收回，信用减值风险持续存在。

**公司简介（F10 原文）**

> 广东原尚物流股份有限公司依托自主车辆为主、外协车辆为辅的车辆资源优势,实行以“安全、准确、迅速”的理念,为客户提供安全高效的个性化、专业化、一体化的全程物流服务,原尚股份各类可控运输车辆达1500余台,运输量多达每天2000车次,物流网络覆盖华南、华东、华中、西南、华北、东北地区。自成立以来,公司始终坚持“安全、准确、迅速”的服务理念。凭借全程供应链一体化管理业务模式,服务的汽车品牌包括包括广汽本田、东风本田、广汽乘用车、江淮汽车、蔚来汽车、新能源龙头车企及动力电池龙头企业等。公司在中国境内10余个省、市设立了分支机构和服务网点,形成了辐射全国的物流网络系统。公司推行全程供应链管理的物流运营模式,物流服务与制造业企业深度联动,通过运用VMI、MILKRUN、直送、甩挂运输等物流管理技术,实现JIT物流配送,集成供应链的各个环节,在不同客户和零部件供应商之间实施“循环对流”运输,节约了运输总里程,提高了单车装载率,降低了车辆空驶率,帮助客户实现“零”库存管理。同时,公司通过供应链物流网络的建设和完善,不断拓展非汽车物流领域客户,与申通快递、希音(SHEIN)、白云机场、深圳机场、华润医药、南方航空等知名大型企业客户形成了稳定的战略合作关系。公司自成立以来一直重视对信息技术的开发与投入,不断将业务流程和管理流程标准化,并在仓储管理、装卸运输、配送发运等物流环节广泛应用电子数据交换(EDI)、射频识别技术(RFID)、卫星定位(GPS)和移动通信等信息技术。经过多年自主开发和持续创新,公司已构建了一套智能化的信息管理平台。凭借先进的信息管理系统和技术手段,公司能够快速响应客户的需求变化,为客户量身定做最适合的物流解决方案。个性化的物流方案既满足了客户对物流服务安全性、及时性和准确性的要求,又实现了公司运营的低成本和高效率。今后,原尚股份将继续以技术专业化、服务优质化、平台规模化和经营精细化,实现为更多的客户提供超值服务,与更多的客户结成战略伙伴关系;以机制为本创造活力,以人为本体现真诚。持续不断地提高我们的物流服务质量,将我们的“安全、准确、迅速”的供应链物流服务提供给更多的客户。
