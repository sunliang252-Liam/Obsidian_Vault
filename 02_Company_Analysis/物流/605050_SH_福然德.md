# 605050.SH 深度透视

## 因果逻辑链
- **[汽车行业景气度提升]** -> [销量与利润双增]: 2025年国内汽车产销增长9.4%，公司汽车行业销售量同比增长18.84%，带动扣非净利润增长23.66%。
- **[“多对多”供应链模式]** -> [成本优化与客户粘性]: 整合上游钢厂与下游主机厂需求，实现集中下料、合理套裁，降低产业链成本，提升客户保供能力与粘性。
- **[客户结构均衡化]** -> [抗周期能力增强]: 从依赖合资品牌转向内资品牌、造车新势力与合资品牌均衡发展，降低单一客户依赖风险，保障业务持续增长。
- **[轻量化新业务布局]** -> [第二增长曲线]: 投产一体化铝压铸、铝挤压、热成型及激光拼焊项目，切入汽车轻量化赛道，为未来利润增长提供新引擎。
- **[以销定采+动态库存管理]** -> [毛利率提升]: 2025年原材料价格走低，公司通过每周动态库存管理，减少安全库存，使加工配送业务毛利率提升0.34个百分点。
- **[全国化“临厂而建”布局]** -> [JIT供货能力]: 13个加工基地贴近主机厂，实现以小时为单位的JIT供货模式，满足客户“零库存”需求，构筑核心竞争壁垒。
- **[高分红政策]** -> [股东回报强化]: 2025年拟合计派发现金分红2.37亿元，占净利润63.25%，体现公司现金流稳健及回馈股东意愿。

## 风险警告
**新业务产能爬坡与盈利风险。** 公司2024-2025年集中投产的一体化铝压铸、热成型等轻量化项目，目前处于量产或试产初期，产能利用率较低。子公司安徽优尼科（铝压铸）2025年亏损2844万元，安徽锶科（铝挤压）亏损485万元，已拖累整体利润。若新项目良品率提升及客户订单获取不及预期，将持续产生折旧摊销压力，侵蚀公司盈利能力。

**存货与应收账款双高带来的资金压力。** 公司存货账面价值达20.86亿元，同比增长40.63%，主要因客户订货量增加备货；应收账款高达21.02亿元，占总资产21.7%。虽然公司采用以销定采模式，但存货和应收款的快速增长，导致经营活动现金流净额仅0.73亿元，远低于3.75亿元的净利润，利润含金量较低。若下游客户（尤其是新势力车企）回款恶化或钢材价格下跌，将面临坏账和跌价损失风险。
