# 600803.SH 深度透视

## 因果逻辑链
- **[总销气量增长7.6%]** -> [归母净利润增长4.19%]: 天然气零售及批发业务量增长对冲了平台交易气量下滑和整体营收微降的影响，但利润增速低于气量增速，反映行业低速复苏下盈利承压。
- **[舟山LNG接收站三期投产]** -> [基础设施运营收入增长4.95%]: 处理能力提升至1000万吨/年，支撑接卸量同比增长9.4%，并拓展保税、加注等新业务模式，强化了资源枢纽地位。
- **[财务费用同比减少57.2%]** -> [归母净利润增长]: 美元债汇兑收益增加及平均借款利率下降，大幅降低了财务成本，成为利润增长的关键支撑。
- **[高分红政策]** -> [股东回报稳定]: 2025年合计每10股派发现金红利11.40元，分红比例高达75.33%，体现了公司对股东回报的重视，并吸引红利低波指数等资金关注。
- **[衍生品公允价值变动]** -> [非经常性损益波动]: 套期保值合约到期结算导致公允价值变动收益增加，同时资产减值损失增加，共同导致非经常性损益项目波动较大。
- **[出售能源生产业务]** -> [营收结构优化]: 出售新能能源等子公司，导致煤化工业务收入大幅下降54.51%，但提升了整体资产质量和业务聚焦度。
- **[MSCI ESG评级AAA]** -> [吸引ESG资金]: 连续两年获得全球燃气公用事业行业最高评级，增强了公司在可持续发展领域的全球领先地位，吸引了大量ESG资金投资。

## 风险警告
**核心风险在于天然气价格波动与衍生品交易的复杂性。** 公司业务与国际油气指数高度挂钩，地缘政治、政策、气候等多重因素加剧了市场价格波动。尽管公司运用套期保值工具进行风险对冲，但衍生品交易本身存在市场、流动性、操作等多重风险，且报告期内衍生品公允价值变动对利润影响显著，若市场出现极端行情或风控失效，将对公司经营业绩造成重大冲击。

**另一重大风险是私有化新奥能源及H股介绍上市的进程与整合风险。** 该交易构成关联交易，涉及复杂的资本运作、监管审批及两地上市规则。交易能否顺利完成、完成后能否实现预期的协同效应、以及如何有效管理两地上市后的治理结构，均存在不确定性。此外，交易期间可能面临股价波动、监管问询等风险，对公司的战略执行和短期财务表现构成挑战。
