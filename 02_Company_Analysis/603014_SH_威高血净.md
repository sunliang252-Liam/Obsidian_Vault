# 603014.SH 深度透视

## 因果逻辑链
- **[集采政策全面落地]** -> [行业利润空间承压]: 带量采购压缩产品终端价格，倒逼企业从“营销驱动”转向“精益化创新驱动”，考验成本控制与规模效应。
- **[海外市场高速扩张]** -> [营收增长新引擎]: 海外销售收入3.29亿元，同比增长62.23%，有效对冲国内集采降价压力，打造第二增长曲线。
- **[精益生产与数字化降本]** -> [经营现金流大幅改善]: 生产数字化运营平台及能源平台二期项目上线，提升效率、管控成本，使经营活动现金流净额同比增长38.69%至7.94亿元。
- **[ESRD患者刚需扩容]** -> [行业需求持续增长]: 人口老龄化及慢性病高发，推动终末期肾病患者数量持续增加，为血液净化产品提供稳定且增长的市场基础。
- **[国产替代与渠道下沉]** -> [巩固国内市场地位]: 凭借丰富的产品线和覆盖超6000家医院的销售网络，在集采中中标，承接基层市场扩容需求，维持国内市场份额。
- **[研发投入聚焦核心膜技术]** -> [构筑技术壁垒]: 持续投入研发（1.44亿元），在生物医用膜技术平台取得突破，年内获批4张注册证，丰富产品矩阵，提升长期竞争力。
- **[关联采购高度集中]** -> [供应链依赖风险]: 前五名供应商采购额占比59.44%，其中关联方采购占50.91%，特别是向威高日机装、威高泰尔茂的采购占比达45.34%，存在供应链稳定性风险。

## 风险警告
**核心风险在于集采深化对盈利能力的持续侵蚀。** 尽管公司通过海外扩张和精益生产对冲了部分压力，但2025年耗材/制剂业务毛利率已下降1.93个百分点。随着带量采购在全国范围内进一步铺开，产品出厂价仍有下行压力，若销量增长无法完全弥补价差，公司整体利润率将面临持续考验。

**另一重大风险是高度集中的关联采购与关联担保。** 公司超过45%的采购来自关联方（威高日机装、威高泰尔茂），且为合营公司威高泰尔茂提供了超1.28亿元的担保。这种复杂的关联交易结构不仅增加了供应链的潜在风险，也放大了公司对关联方经营状况的依赖，一旦关联方出现财务问题，可能通过担保链条传导至公司。
