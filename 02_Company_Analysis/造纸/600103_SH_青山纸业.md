# 600103.SH 深度透视

## 因果逻辑链
- **[行业周期下行与产能过剩]** -> [营收与利润双降]: 2025年包装纸行业供需矛盾激化，价格全年趋势性下行，公司主导产品量价齐跌，导致营收同比下降6.98%，归母净利润同比下降35.48%。
- **[产品结构优化，新型包装纸占比突破2/3]** -> [对冲传统业务下滑]: 公司主动调整产品结构，重点发力高附加值品类，非水泥新型包装纸销量占比首次突破三分之二，成为新的业务增长支柱，部分抵消了传统纸袋纸需求萎缩的冲击。
- **[原料本土化与“以竹代木”战略]** -> [成本控制与供应链安全]: 公司依托福建丰富的毛竹资源，提升低成本竹原料使用比例，实施原料本土化策略，有效降低了采购成本，在原料价格波动中释放了盈利空间。
- **[子公司水仙药业与恒宝通业绩改善]** -> [多元化业务提供利润缓冲]: 水仙药业业绩稳定增长，深圳恒宝通实现扭亏为盈，医药和光电子板块的良好发展态势，部分弥补了浆纸主业的利润缺口。
- **[非经常性损益依赖理财收益]** -> [扣非净利润大幅下滑]: 2025年扣非净利润仅1358万元，同比下滑70.32%，而同期理财收益高达4429万元，表明公司核心主业盈利能力已十分薄弱，利润高度依赖非主业收入。
- **[资产减值损失大幅增加]** -> [侵蚀利润]: 报告期计提资产减值损失5169万元，同比大增171.65%，主要因存货跌价及固定资产减值，进一步加剧了利润下滑压力。
- **[年产20万吨竹浆技改项目推进]** -> [未来产能与成本优势]: 公司正推进该技改项目，预计2026年上半年完成，旨在进一步扩大竹浆产能，强化原料本土化优势，为未来增长奠定基础。

## 风险警告
**核心主业盈利能力已近枯竭，利润高度依赖理财。** 2025年扣非净利润仅1358万元，同比暴跌70%，而同期理财收益高达4429万元，是扣非净利润的3倍多。这意味着公司的主营业务（制浆造纸）在行业周期底部已基本不赚钱，完全依靠“金融操作”维持账面利润。一旦理财收益波动或行业景气度未能如期回升，公司将面临巨大的业绩坍塌风险。

**募投项目严重滞后，资金使用效率低下。** 核心募投项目“水仙药业风油精车间扩建及新建口固车间项目”投资进度仅0.82%，因“退城入园”无法落地而暂缓实施，导致近5亿元募集资金长期闲置。这不仅暴露了公司战略执行能力的短板，也意味着公司未来增长缺乏明确的资本开支支撑，多元化发展路径受阻。
