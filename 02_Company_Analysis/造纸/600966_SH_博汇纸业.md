# 600966.SH 深度透视

## 因果逻辑链
- **[产销量增长但价格承压]** -> [净利润下滑11.56%]: 机制纸产销量同比增7.70%/5.04%，但行业产能过剩导致纸价低迷，营收仅增1.20%，毛利率微增0.15个百分点无法覆盖费用增长。
- **[境外高增长对冲内需疲软]** -> [境外收入增36.14%，毛利率17.25%]: 海外“以纸代塑”需求旺盛，公司凭借FSC等国际认证拓展高端市场，境外业务成为核心增长引擎，有效弥补境内收入下滑6.20%的缺口。
- **[关联采购依赖度高]** -> [成本控制受制于关联方]: 前五名供应商采购额占比60.81%，其中关联方采购占比48.28%，对金光纸业体系内木浆、化工辅料等采购依赖度高，削弱了独立议价能力。
- **[经营现金流大幅改善]** -> [现金流与利润背离]: 经营活动现金流净额暴增197%至20.65亿元，主要系采购支付现金减少，而非盈利改善，反映公司通过压缩采购和应付账款管理优化现金流。
- **[在建工程大幅增加]** -> [资本开支压力持续]: 在建工程增长43.84%至21.53亿元，主因80万吨项目投入增加，预示未来折旧和财务费用将上升，短期难以贡献利润。
- **[白纸板毛利率提升]** -> [产品结构优化见效]: 白纸板毛利率同比提升1.96个百分点至11.33%，得益于高附加值食品卡、烟卡等产品占比提升及成本管控，是公司最核心的利润来源。
- **[文化纸毛利率大幅下滑]** -> [竞争加剧拖累盈利]: 文化纸毛利率同比下滑4.31个百分点至8.21%，主因新增产能持续投放导致价格竞争激烈，成本端木浆价格波动未能有效传导。

## 风险警告
公司面临的核心风险在于**行业供需失衡与成本端双重挤压**。造纸行业新产能释放尾声叠加需求复苏缓慢，纸价反弹持续性存疑，而木浆、木片等核心原料高度依赖进口，价格波动将直接侵蚀本已微薄的利润。2025年净利润已连续三年下滑，扣非净利润更是同比下降18.80%，盈利质量堪忧。

**关联交易与高负债率构成财务隐忧**。公司对金光纸业体系内的关联采购占比近半，虽保障了原料供应，但削弱了独立经营与议价能力。同时，担保总额占净资产比例高达58.78%，短期借款与长期债务合计超87亿元，财务费用同比增18.96%，高杠杆运营下，一旦行业景气度下行，偿债压力将显著放大。
