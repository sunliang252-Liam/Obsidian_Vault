# 301469.SZ 深度透视

## 因果逻辑链
- **前瞻性战略定位医疗及食品包装领域** -> 收入和净利润双位数增长: 公司自创立起聚焦医疗及食品包装特种纸这一高增长、高壁垒领域，持续深耕二十余年，构建了技术与工艺壁垒，在行业原纸价格低位运行背景下，仍实现营业收入同比增长14.24%，净利润同比增长17.32%，毛利率提升0.87个百分点。
- **以销定产与低库存策略** -> 低资产负债率与轻盈资本结构: 公司坚持以销定产维持低产成品库存，并通过客户信用管理保持稳健现金流，从而将资产负债率控制在19%的低水平，增强了财务韧性与抗周期能力。
- **新建产能投产** -> 产量与库存量增加: 年产5万吨新型包装用纸生产线及1万吨食品医疗纸制品深加工项目投产，使生产量同比增长20.49%，销售量增长19.81%，但库存量因产能爬坡和备货增加30.66%。
- **原材料木浆价格波动与采购策略** -> 经营活动现金流净额为负: 为应对海外木浆价格波动，公司在价格低位加大储备，导致采购原材料支付现金大幅增加，同时新建产能爬坡期也占用资金，致使经营活动现金流净额为-1,977.12万元，而净利润为8,031.47万元。
- **木浆价格波动与套期保值操作** -> 成本可控性与毛利率提升: 公司通过纸浆期货套期保值平滑原材料价格波动影响，同时利用现货市场低位储备策略，有效控制了直接材料成本，使医疗及食品包装原纸毛利率提升0.67个百分点，整体毛利率提升0.87个百分点。
- **EUDR合规与FSC认证** -> 境外收入大幅增长: 公司前瞻性响应欧盟反毁林法案，取得FSC认证并建立全链路追溯体系，自2025年10月起成功向欧盟出口合规产品，带动境外收入同比增长246.25%，境外收入占比从2.94%提升至8.91%。
- **研发投入与技术创新** -> 产品结构优化与市场竞争力: 公司持续研发低定量高性能医用冷封纸、无氟食品包装材料等新产品，获得多项省级工业新产品评价证书，通过产品升级提升了在医疗及食品包装领域的竞争力，支撑了收入增长和毛利率稳定。
- **行业政策推动绿色转型与消费升级** -> 医疗及食品包装原纸需求增长: 碳达峰、绿色消费政策及医疗器械新规等推动下游对高性能、环保包装材料的需求增长，公司产品定位符合趋势，带动医疗及食品包装原纸收入增长18.21%，销售量增长19.81%。
- **子公司设立与国际化布局** -> 境外业务拓展: 2025年3月设立新加坡子公司HENGCHUAN INTERNATIONAL TRADE PTE. LTD，作为拓展海外市场的平台，配合EUDR合规，助力境外收入增长。

## 风险警告
深度风险总结：1. 原材料价格波动风险：公司木浆100%进口，2025年因低位储备导致经营活动现金流为负，未来若木浆价格持续高位或期货套保失效，将压缩利润空间。2. 产能消化风险：新建产能投产使库存增长30.66%，若下游需求不及预期，可能面临库存减值压力。3. 财务费用上升风险：短期借款增加使财务费用同比增长326.77%，需关注负债水平变化及利息覆盖能力。4. 国际政策风险：EUDR等法规持续演变，若合规成本上升或出口受阻，将影响境外业务增长。5. 行业竞争加剧风险：造纸行业进入存量博弈阶段，特种纸领域技术壁垒虽高，但头部企业研发投入加大，可能压缩公司市场份额。
