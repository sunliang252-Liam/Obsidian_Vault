# 002067.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡加剧]** -> [营收增长但利润下滑]: 包装原纸行业产能持续释放，需求复苏滞后，公司“以价换量”导致营收增9.72%但归母净利润降22.18%，扣非净利润转负至-4418万元。
- **[马来西亚再生浆产能释放]** -> [再生浆业务爆发式增长]: 景兴控股（马）公司产能利用率提升至61.55%，再生浆板营收同比增403.28%，成为营收增长核心驱动力。
- **[废纸原料价格高位震荡]** -> [成本传导压力突出]: 废纸价格全年调整128次，上半年成品纸价跌幅超成本降幅，形成盈利“剪刀差”，压缩毛利空间。
- **[非经常性损益依赖]** -> [扣非净利润为负]: 处置投资性房地产贡献9544万元非经常性收益，若剔除该因素，公司主营业务实际亏损。
- **[可转债转股完成]** -> [财务结构优化]: “景兴转债”基本全部转股，减少债务压力，净资产增14.33%，但稀释每股收益至0.04元。
- **[海外项目资本开支加大]** -> [现金流承压]: 马来西亚二期60万吨箱板纸项目及5万吨再生生活用纸项目推进，投资活动现金流净流出6.66亿元，经营现金流亦转负。
- **[生活用纸成品业务放量]** -> [结构转型初现]: 代加工订单增加，生活用纸成品销量增194.12%，但该业务毛利率仅8.80%，盈利能力有限。

## 风险警告
**核心风险在于主营业务造血能力持续恶化。** 公司扣非净利润已连续两年为负（2024年1179万，2025年-4418万），2025年经营现金流净流出2625万元，表明核心造纸业务在行业产能过剩、价格战白热化背景下已陷入“增收不增利”甚至亏损的困境。公司盈利高度依赖非经常性损益（如处置资产），可持续性存疑。

**海外扩张的资本开支与运营风险不容忽视。** 马来西亚二期项目投资规模大（在建工程3.12亿+预付4.30亿），而景兴控股（马）公司2025年仍亏损3455万元，产能利用率仅61.55%。若二期项目投产后市场需求不及预期或成本控制失效，将加剧公司财务压力。此外，公司对子公司担保余额高达10.99亿元，海外地缘政治、汇率波动及贸易摩擦风险均可能冲击海外资产安全。
