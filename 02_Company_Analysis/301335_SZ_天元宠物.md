# 301335.SZ 深度透视

## 因果逻辑链
- **[境外宠物经济持续增长]** -> [境外收入增长14.33%]: 全球宠物行业规模预计2030年超5000亿美元，公司依托美国、欧洲等成熟市场客户资源，境外销售稳步提升。
- **[海外供应链布局（越南、柬埔寨）]** -> [宠物用品自产成本下降、毛利率提升1.22%]: 越南、柬埔寨工厂产能释放，客户与供应商转移平稳落地，海外生产交付效率提升，成本改善。
- **[国内“食品带动用品”协同策略]** -> [境内宠物食品收入增长3.73%，毛利率提升6.33%]: 通过进口玛氏、雀巢等国际品牌宠粮，以高频消费的食品引流，带动低频的用品销售，巩固线上渠道。
- **[线上渠道运营能力提升]** -> [零售模式收入增长39.45%]: 公司强化“优电商、强To C”战略，线上销售占比大幅提升，B2C业务增长显著。
- **[自主品牌Petstar推广]** -> [品牌影响力提升，但短期费用增加]: 通过IP联名、线下体验等方式强化品牌认知，销售费用增长37.37%，但为长期品牌价值奠定基础。
- **[外协加工为主的生产模式]** -> [产品品类快速扩展，但供应链管控风险增加]: 依托浙江轻工业配套优势，聚焦研发与客户服务，实现多品类覆盖，但对外协厂商的依赖带来质量与交付风险。
- **[宠物食品预付款项大幅增加]** -> [经营活动现金流净额下降76.60%]: 为锁定冠军品牌宠粮货源，预付采购款增加，导致经营性现金流大幅恶化，资金占用压力显著。

## 风险警告
**核心风险在于现金流恶化与供应链脆弱性。** 2025年经营活动现金流净额骤降76.6%至4130万元，主因为宠物食品预付款项激增（预付账款从1.01亿翻倍至2.10亿）。这种“以预付换货源”的模式，在品牌授权不稳定或下游需求波动时，极易引发资金链紧张与存货减值风险。同时，公司宠物用品以外协加工为主，若核心外协厂商转型为竞争者或产能不足，将直接冲击供应链稳定性。

**另一重大风险是境外市场依赖与贴牌模式。** 境外收入占比超50%，且以贴牌（OEM/ODM）为主，客户集中度较高（前五大客户占38.47%）。若中美贸易摩擦升级、关税政策突变，或主要客户（如沃尔玛、Kmart）缩减在华采购，公司将面临订单流失与利润压缩的双重打击。此外，人民币汇率波动对以美元结算的境外业务影响显著，2025年财务费用因汇兑损失大增581.71%。
