# 000890.SZ 深度透视

## 因果逻辑链
- **[地方财政压力导致政府环保项目收缩]** -> [环保业务收入下滑]: 子公司广泰源以政府类项目为主，地方财政支出放缓导致存量项目暂缓、新增项目不及预期，环保业务收入同比下降7.97%。
- **[控股股东现金捐赠8500万元]** -> [净资产大幅提升]: 2025年12月，控股股东泓昇集团无偿赠与现金8500万元，直接推动归属于母公司净资产从1.72亿元增至2.87亿元，增幅66.84%。
- **[贝卡尔特钢帘线分红]** -> [投资收益支撑利润]: 参股公司贝卡尔特钢帘线贡献投资收益1198万元，成为公司非主营业务中唯一的正向利润来源。
- **[商誉及无形资产减值]** -> [资产减值损失扩大]: 对子公司广泰源相关商誉及无形资产计提减值准备2945万元，占利润总额的34.47%，是亏损的主要来源之一。
- **[利息支出减少]** -> [财务费用下降]: 财务费用同比下降33.43%至2942万元，主要系利息支出减少，缓解了部分盈利压力。
- **[货款回笼改善]** -> [经营活动现金流净额大增]: 经营活动现金流净额同比增加188.18%至3412万元，主要得益于货款回笼与采购支付的现金净流入同比增加。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户销售占比86.18%，其中单一关联客户占比63.44%，公司经营高度依赖少数客户，议价能力和抗风险能力较弱。

## 风险警告
公司核心风险在于**环保业务的持续萎缩与资金链的脆弱性**。子公司广泰源受地方财政压力影响，政府类项目投资收缩，收入下滑且回款周期拉长，导致公司流动资金承压。同时，公司对广泰源形成的商誉及无形资产仍存在进一步减值风险，若环保业务未能通过拓展非政府类项目实现有效转型，将加剧亏损。

**财务结构极度脆弱**。公司合并报表未分配利润为-7.72亿元，母公司未分配利润为-8.98亿元，净资产仅2.87亿元，而短期借款高达7.05亿元，资产负债率高达92.2%。公司高度依赖控股股东输血（现金捐赠、关联借款）维持运营，若控股股东支持力度减弱或外部融资环境变化，公司面临严重的流动性危机。
