# 688501.SH 深度透视

## 因果逻辑链
- **[国家煤电“三改联动”政策驱动]** -> [传统主业需求提升]: 政策要求存量煤电机组进行节能、供热、灵活性改造，直接拉动了公司炉渣处理、烟气余热回收、全负荷脱硝等核心产品的市场需求。
- **[光伏项目落地并贡献收入]** -> [营收与利润高增]: 2025年新增的胶州渔光互补光伏项目实现收入4.9亿元，成为公司营收同比增长52.9%、净利润同比增长88.16%的最大增量。
- **[火电投资加速与存量改造]** -> [干式除渣系统与低温烟气余热系统增长]: 报告期内，干式除渣系统收入增长45.51%，低温烟气余热深度回收系统收入增长10.69%，受益于新建火电项目及存量机组升级。
- **[清洁能源消纳系统需求爆发]** -> [该业务收入增长415%]: 电极锅炉与蓄热器系统在火电灵活性调峰和清洁供热场景下需求激增，推动该板块收入从低基数大幅跃升。
- **[原材料价格波动与成本传导]** -> [毛利率承压]: 尽管收入大增，但钢材等原材料价格上涨及光伏项目低毛利特性，导致主营业务毛利率同比下降5.68个百分点至27.32%。
- **[应收账款规模随营收扩大]** -> [现金流压力与坏账风险]: 期末应收账款达7.4亿元，占营收36.85%，虽然经营性现金流由负转正，但回款压力仍是财务风险的核心。
- **[海外市场突破]** -> [打开第二增长曲线]: 成功签订海外首个总包合同，国外业务收入同比增长342.29%，标志着国际化战略取得实质性进展。

## 风险警告
公司业绩高度依赖国家煤电政策，尤其是“三改联动”的执行力度与持续性。若未来火电投资放缓或环保监管放松，公司传统主业将面临需求萎缩风险。同时，光伏项目虽贡献短期增量，但其毛利率（21.15%）显著低于传统主业，且项目制收入不具备持续性，未来增长动力需依赖新业务接力。

财务层面，应收账款规模庞大（7.4亿元）且周转较慢，是公司最大的财务隐患。下游客户多为大型电力集团，账期较长，若宏观经济下行导致客户付款延迟，将直接侵蚀公司现金流并增加坏账损失。此外，钢材等原材料价格波动对毛利率的冲击已在本期显现，公司缺乏有效的成本转嫁机制，盈利能力稳定性存疑。
