## 因果逻辑链
- **[清洁能源业务爆发式增长]** -> [营收同比+60.37%]: 清洁能源板块收入同比暴增802.88%，成为公司营收增长的核心引擎，但毛利率骤降8.91个百分点，显示该业务处于快速扩张但盈利能力承压的早期阶段。
- **[国际化战略加速落地]** -> [境外收入同比+170.82%]: 乌兹项目、赞比亚工业园等标杆项目成功执行，带动境外收入占比升至59.6%，但境外毛利率同比下降11.16个百分点，反映海外项目竞争激烈、成本管控难度大。
- **[营收大幅增长但利润微薄]** -> [归母净利润仅1371万元，净利率0.37%]: 营收37.27亿，但归母净利润仅1371万，主因是清洁能源业务毛利率仅9.77%，叠加高额管理费用（2.42亿）和信用/资产减值损失（合计4135万），严重侵蚀利润。
- **[财务杠杆显著提升]** -> [短期借款+794.58%，长期借款+71.72%]: 为支撑清洁能源项目扩张，公司大幅增加银行借款，短期借款从4849万飙升至4.34亿，财务费用由负转正（147万），未来利息负担将加重。
- **[经营活动现金流大幅改善]** -> [经营现金流净额由负转正至1.60亿]: 销售回款增加与采购支出减少共同作用，现金流状况显著好转，但投资活动现金净流出4.20亿，显示公司仍处于大规模资本开支周期。
- **[核心子公司分化严重]** -> [武汉建材院亏损3666万，南通万达盈利4012万]: 工程服务与装备板块内部出现明显分化，武汉院新型建材装备业务亏损，而南通万达锅炉制造业务保持盈利，反映公司业务整合与协同效率有待提升。
- **[合同资产激增163.42%]** -> [合同资产从6.06亿增至15.97亿]: 境外项目增加导致已完工未结算资产大幅膨胀，若项目回款周期拉长或业主付款能力变化，将带来较大的流动性风险和减值风险。

## 风险警告
**盈利质量极低，增收不增利的困境显著。** 公司营收暴增60%至37.27亿，但归母净利润仅1371万，净利率不足0.4%。核心原因是清洁能源业务毛利率仅9.77%，且管理费用、信用减值损失高企。这种“以量换利”的增长模式可持续性存疑，一旦项目扩张放缓或成本控制失效，极易陷入亏损。

**海外业务扩张伴随高杠杆与高波动风险。** 公司境外收入占比已近60%，但境外毛利率同比下降11.16个百分点。为支撑海外项目，公司短期借款激增近8倍，合同资产暴增163%，资产负债率升至63.1%。海外项目所在国（中亚、非洲）的政治、汇率、法律风险叠加，一旦出现项目延期、业主违约或当地货币贬值，将对公司现金流和资产质量造成重大冲击。
