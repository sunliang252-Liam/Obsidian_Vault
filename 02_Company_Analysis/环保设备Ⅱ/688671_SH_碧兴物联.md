# 688671.SH 深度透视

## 因果逻辑链
- **[行业需求萎缩与竞争加剧]** -> [营收微降、毛利率暴跌]: 宏观经济下行导致环保仪器设备需求整体收缩，市场竞争白热化，公司未能及时调整销售策略，新签订单盈利能力下滑，叠加项目退货影响，导致营收微降0.97%，但毛利率同比骤降10.78个百分点。
- **[研发投入持续加码]** -> [期间费用增加，侵蚀利润]: 为巩固技术优势并培育数字农业等新增长点，公司研发费用同比增长12.36%至4676万元，占营收比例达14.34%，叠加销售与管理费用增加，共同导致期间费用上升，进一步加剧亏损。
- **[资产减值损失增加]** -> [净利润大幅下滑]: 受市场竞争及项目退货影响，公司存货跌价准备及应收账款坏账准备计提增加，资产减值损失同比扩大，成为净利润由盈转亏（-8543万元）的关键因素之一。
- **[客户回款放缓]** -> [经营性现金流由正转负]: 受宏观经济影响，客户财政资金紧张，销售回款放缓，导致销售商品收到的现金下降；而上年同期因收回大额采购预付款（2.13亿元）导致基数较高，本期经营活动现金流净额由正转负至-4384万元。
- **[数字生态业务承压]** -> [核心业务毛利率大幅下滑]: 作为核心收入来源的数字生态（环境监测仪器及系统）业务，营收虽增长11.12%，但营业成本激增46.98%，导致毛利率从31.28%骤降至9.09%，严重拖累整体盈利。
- **[新业务尚处培育期]** -> [未能弥补传统业务下滑]: 公司重点发展的数字农业、数字水利/水务等新业务虽取得技术突破和项目落地，但体量尚小（合计营收占比不足10%），且毛利率波动较大，短期内无法对冲传统核心业务的衰退。
- **[募投项目延期]** -> [未来增长预期不确定性]: 公司核心募投项目“智慧生态环境大数据服务项目”和“智慧水务大数据溯源分析服务项目”因市场环境变化延期至2026年8月，短期内无法贡献预期收益，增加了未来业绩增长的不确定性。

## 风险警告
**核心风险在于传统主业“量价齐跌”的恶性循环。** 公司核心的数字生态业务（环境监测仪器）正面临行业需求萎缩与竞争加剧的双重打击，毛利率从31%暴跌至9%，几乎丧失盈利能力。同时，公司为转型而投入的研发费用持续高企，但新业务（数字农业、数字水务）体量过小，远不能弥补传统业务的衰退，导致公司连续第二年大幅亏损，且亏损额同比扩大121%。若行业需求复苏不及预期，公司可能陷入“越转型越亏损”的困境。

**财务健康度存在隐患。** 公司经营性现金流已由正转负，应收账款和存货规模较大，存在坏账和跌价风险。尽管账面现金储备充足，但若亏损持续，将不断消耗净资产（已同比下降7.65%）。此外，公司曾因信息披露问题多次收到监管警示，治理层面的合规风险不容忽视。募投项目的延期也表明公司对市场变化的应对能力存在短板，未来增长路径尚不明朗。
