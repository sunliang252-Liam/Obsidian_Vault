# 002286.SZ 深度透视

## 因果逻辑链
- **[减糖消费趋势与政策红利]** -> [核心产品销量与收入增长]: 年轻消费者“低糖”需求爆发，叠加全球糖税政策与国内《体重管理指导原则》等政策，直接拉动公司减糖甜味剂（+34.48%）和益生元（+20.96%）销量大幅增长。
- **[核心产品结构优化]** -> [毛利率与盈利能力提升]: 公司聚焦“小、精、灵”高附加值订单，三大核心产品（益生元、膳食纤维、减糖甜味剂）收入占比提升至61.87%，合计毛利占比达70.15%，推动整体毛利率改善1.37个百分点至13.26%。
- **[降本增效与工艺优化]** -> [核心产品毛利率显著改善]: 通过产线工艺优化、精细化管理和规模化生产，赤藓糖醇等核心产品单耗显著下降，三大核心产品毛利率同比提升3.63个百分点至19.47%。
- **[阿洛酮糖获批新食品原料]** -> [打开第二增长曲线]: 2025年7月D-阿洛酮糖获国家卫健委批准，公司作为国内最早布局企业之一，启动年产2万吨二期扩产项目，有望替代蔗糖部分市场，成为未来核心增长极。
- **[HMOs（母乳低聚糖）获批]** -> [拓展高端益生元市场]: 2'-FL作为食品营养强化剂获批，并申请扩大使用范围，公司成功布局婴幼儿营养等高附加值领域，完善益生元产品体系。
- **[全产业链与全品类优势]** -> [增强抗风险与客户粘性]: 公司拥有90多种规格产品，覆盖淀粉糖到高端功能糖，提供一站式服务，与伊利、可口可乐等2000多家客户形成深度绑定，降低单一产品周期波动风险。
- **[境外市场量价齐升]** -> [贡献重要利润增量]: 公司抓住欧洲反倾销税率最低的市场机遇，赤藓糖醇在欧洲实现量价齐升，境外收入同比增长17.66%，且境外毛利率（19.52%）显著高于境内（11.04%）。

## 风险警告
**原材料价格波动与成本传导风险。** 公司主要原料玉米、淀粉、蔗糖等为大宗商品，价格受气候、政策影响波动大。尽管公司通过套期保值、工艺降本等措施对冲，但若原材料价格大幅上涨，而产品售价调整滞后，将直接侵蚀本已微薄的毛利率（整体仅13.26%），对利润造成显著冲击。

**新增产能释放与折旧压力。** 公司正推进阿洛酮糖二期、DHA、乳果糖等多个项目，固定资产规模持续扩大。若新增产线未能快速满产达效，或下游需求不及预期，新增折旧将直接拖累利润，存在“增产不增利”的风险。2025年管理费用因股权激励和薪酬增加已同比大增72.6%，需警惕费用刚性增长。
