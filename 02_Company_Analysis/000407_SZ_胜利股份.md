# 000407.SZ 深度透视

## 因果逻辑链
- **[成本费用精准管控]** -> [归母净利润增长32.87%]: 通过调整融资结构、降低贷款规模，财务费用同比减少30.02%，直接增厚利润。
- **[投资收益增加]** -> [非经常性损益扭亏为盈]: 权益法核算的长期股权投资收益及处置股权收益合计3624万元，成为利润增长的重要补充。
- **[气源结构优化与顺价]** -> [天然气业务毛利率微升]: 多元化气源采购降低综合成本，同时推动气价顺价，使天然气及增值业务毛利率同比上升0.04个百分点。
- **[工业用户逆势增长]** -> [市场结构优化]: 聚焦工商业用户核心需求，在整体营收微降1.44%的背景下，工业用户开发数量实现逆势增长，对冲了居民用气波动风险。
- **[低效资产盘活与亏损治理]** -> [资产质量提升]: 通过注销、出售不符合战略的子公司（如青岛胜利润昊、东阿阳光），实施“一企一策”治理亏损，提升整体资产运营效率。
- **[研发投入大幅缩减]** -> [短期利润增厚，长期创新风险]: 研发费用同比减少58.37%，研发人员数量减少21.62%，虽短期内节省成本，但可能削弱未来技术竞争力。
- **[发行股份购买资产]** -> [产业布局深化]: 启动收购中油燃气旗下资产，旨在完善产业布局、深化产业协同，打造“产业+资本”双引擎驱动。

## 风险警告
**核心风险在于上游气源价格波动与顺价机制的不确定性。** 天然气采购成本是公司最大的营业成本，虽然公司通过多元化气源和推动顺价机制来对冲，但若上游价格剧烈上涨而下游顺价不畅，将直接压缩本就微薄的毛利率（19.29%），导致盈利能力大幅波动。此外，公司高达13.3亿元的商誉账面原值（已计提1.4亿减值）是悬在头顶的达摩克利斯之剑，任何被收购子公司的业绩不达预期都可能引发大规模商誉减值，对利润造成重大冲击。

**第二重风险来自公司战略转型期的执行不确定性。** 公司正从传统燃气分销商向“综合能源服务商”转型，并试图通过资本运作（发行股份购买资产）实现跨越式发展。然而，研发投入的骤降（-58.37%）与研发人员的流失，与“数智赋能”、“创新业务”的战略口号形成矛盾，可能使公司在技术迭代和新兴业务（如天然气掺氢、充换电）的竞争中落后。同时，重大资产重组能否顺利完成、整合效果如何，均存在较大不确定性。
