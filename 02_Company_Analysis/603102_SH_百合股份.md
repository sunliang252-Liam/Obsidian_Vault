# 603102.SH 深度透视

## 因果逻辑链
- **[功能饮品/软糖等新剂型爆发]** -> [营收增长13.67%]: 功能饮品(+43.42%)和软糖(新品类)等高毛利新剂型放量，抵消了传统软胶囊(-10%)和片剂(-18%)的下滑，驱动整体营收增长。
- **[合同生产模式主导]** -> [营收增长但利润承压]: 合同生产收入占比超90%且增长21%，但该模式毛利率仅34.25%，低于自主品牌(42%)，导致整体毛利率下降1.2个百分点。
- **[境外业务高增长]** -> [利润结构改善]: 境外收入同比暴增59.16%，且毛利率高达38.12%(同比+9.09pct)，成为利润的重要增量来源。
- **[收购新西兰Oranutrition]** -> [短期费用侵蚀利润]: 收购产生商誉3512万，并带来管理费用(+34.13%)和财务费用(汇兑损失)的大幅增加，导致净利润同比下降7.81%，出现“增收不增利”。
- **[研发投入高效转化]** -> [长期竞争壁垒]: 全年获批128项保健食品备案凭证，累计批文达1518个，领跑行业，为合同生产客户提供“即用型”解决方案，降低客户门槛。
- **[跨境监管趋严]** -> [行业洗牌利好龙头]: 海关总署新规提升合规门槛，大量中小品牌出清，公司凭借前瞻性合规体系，将合规能力从“成本中心”升级为“价值中心”，巩固竞争地位。
- **[自主品牌战略收缩]** -> [短期营收阵痛]: 自主品牌收入同比下降27.41%，线上销售更是腰斩(-51.7%)，显示公司在资源向合同生产倾斜时，自有品牌渠道面临调整压力。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 营收增长13.67%的同时，净利润却下滑7.81%，主因是管理费用激增34.13%（收购整合、中介费）和毛利率承压。若收购的新西兰子公司Oranutrition无法在2026年实现预期的协同效应（如国际原料导入、跨境合规赋能），高昂的整合成本将持续侵蚀利润，商誉减值风险不容忽视。

**另一重大风险是客户结构脆弱性与原材料价格波动。** 公司极度依赖合同生产模式（收入占比超90%），且客户以中小品牌为主，其经营稳定性差，一旦出现违规宣传等问题，公司品牌将受连带损害。同时，直接材料成本占总成本超73%，鱼油、明胶等大宗原料价格波动将直接冲击本已微薄的利润空间，公司缺乏有效的成本转嫁能力。
