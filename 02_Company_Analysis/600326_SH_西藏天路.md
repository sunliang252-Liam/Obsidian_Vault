# 600326.SH 深度透视

## 因果逻辑链
- **[建材板块（昌都高争）受益于川藏铁路等国家重点项目建设]** -> [水泥销量大幅增长，带动建材板块营收增加]: 川藏铁路等重大项目开工建设，直接拉动了昌都高争的水泥需求，使其销量同比增加25.39万吨，推动建材板块营收同比增长8,579.91万元。
- **[建筑板块存量项目进入施工高峰期]** -> [建筑板块营收显著增长]: 索县乡村公路、藏建·康祥项目等存量项目进入施工高峰期，确认收入增加，推动建筑板块营收同比增长32,675.53万元。
- **[出售中国电建股票]** -> [投资收益大幅增加，成为扭亏关键]: 公司通过出售2,500万股中国电建股票，确认投资收益6,072.99万元，是报告期利润减亏的核心驱动因素之一。
- **[LPR下调及有息负债规模降低]** -> [财务费用显著下降]: 报告期内LPR进一步下调，且公司主动偿还部分债务，导致财务费用同比减少33.39%，有效缓解了利润压力。
- **[建材板块（高争股份）收回前期款项并冲回坏账]** -> [净利润同比增加]: 高争股份通过收回以前年度应收款项并冲回坏账损失，使其净利润较去年同期增加，成为建材板块盈利的主要来源。
- **[重庆重交计提商誉减值]** -> [侵蚀建筑板块利润]: 因重庆重交经营不及预期，公司对其计提商誉减值合计约2,029.93万元，是导致建筑板块持续亏损的重要原因。
- **[西藏区内水泥市场竞争激烈，价格承压]** -> [建材板块利润空间被压缩]: 尽管销量增长，但区内新投产水泥线导致供给饱和，叠加国家重点项目战略采购价较低，水泥销售均价下降，抵消了部分降本增效成果。

## 风险警告
**核心风险在于主业造血能力严重不足，利润高度依赖非经常性损益。** 公司连续三年亏损，2025年归母净利润为-5,683万元，扣非后净利润更是高达-9,799万元。盈利改善主要依赖出售金融资产（中国电建股票）带来的投资收益，而非建筑、建材两大主业的实质性好转。一旦资本市场波动或可供出售的金融资产减少，公司将失去重要的利润调节工具，重回深度亏损。

**建筑与建材板块均面临严峻的经营困境。** 建筑板块因子公司重庆重交持续亏损及商誉减值，整体亏损1.53亿元；建材板块虽整体盈利，但主要依赖高争股份，昌都高争因价格战仍亏损4,423万元。公司面临区内建筑市场开放带来的竞争加剧、水泥价格下行、以及重庆地区基建市场疲软等多重压力，主业扭亏的可持续性存疑。此外，多个重大合同因业主资金问题、手续问题等被迫停工或暂缓，进一步加剧了经营风险。
