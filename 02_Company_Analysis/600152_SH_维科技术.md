# 600152.SH 维科技术 深度透视

## 因果逻辑链
- **[消费类铝壳电池市场萎缩]** -> [营收下滑7.28%]: 铝壳电池被聚合物替代，订单量不足，销量同比减少158万支，导致主营业务收入下降。
- **[储能电池产品体系更新与产线改造]** -> [储能电池销量锐减63.37%]: 从层状氧化物体系切换至聚阴离子体系，新产品验证周期长，同时产线扩建改造，导致交付量大幅下降。
- **[计提大额资产减值损失]** -> [归母净利润亏损0.97亿元]: 报告期计提存货跌价5,054万元及闲置固定资产/在建工程减值4,161万元（其中维乐闲置设备产线减值4,061万元），合计9,483万元，是亏损的核心原因。
- **[支付银行票据保证金增加]** -> [经营活动现金流净额转负]: 经营活动现金流净额由正转负（-3,332万元），主要系支付票据保证金增加，占用了营运资金。
- **[处置深圳房产取得收益]** -> [非经常性损益支撑利润]: 资产处置收益981万元（出售深圳房产）及单项应收款减值准备转回550万元，构成非经常性损益的主要来源，掩盖了主业亏损的严重程度。
- **[扣非净利润连续三年为负]** -> [核心主业造血能力持续恶化]: 2023-2025年扣非净利润分别为-1.56亿、-0.89亿、-1.16亿元，表明剔除资产处置等非经常性项目后，公司主营业务持续亏损，未见改善。
- **[维乐电池（江西）持续大额亏损]** -> [拖累合并报表业绩]: 子公司江西维乐电池有限公司2025年净利润-6,602.92万元，其闲置设备产线减值4,061万元是资产减值的主要来源，成为公司业绩的重大拖累项。

## 风险警告
**核心风险在于主业持续失血与资产质量恶化。** 公司连续三年扣非净利润为负，2025年亏损幅度再次扩大，表明消费类电池主业（尤其铝壳电池）面临结构性萎缩，而寄予厚望的钠电储能业务尚处产线切换阵痛期，销量大幅下滑，未能形成有效利润支撑。公司通过出售房产等非经常性收益勉强维持报表，但造血能力堪忧。

**资产减值风险高企，未来仍有暴雷可能。** 报告期高达9,483万元的资产减值损失（存货+固定资产）直接击穿利润表，其中维乐电池的闲置产线减值4,061万元，表明前期投资决策存在失误。存货账面余额同比大增49.87%至4.3亿元，在行业竞争加剧、产品迭代迅速的背景下，若下游需求不及预期，后续存货跌价风险依然巨大。
