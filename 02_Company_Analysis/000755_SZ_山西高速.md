# 000755.SZ 深度透视

## 因果逻辑链
- **[核心路产区位优势]** -> [通行费收入稳定]: 平榆、榆和高速是晋煤外运主通道，车流量大，单公里收费和盈利能力居省内前列，构成收入基本盘。
- **[财务费用大幅下降]** -> [利润基本持平]: 报告期归还借款本金及利率下调，财务费用同比减少25.2%（约5000万元），对冲了营收微增1%和成本上升6.87%的压力，使净利润仅微降0.44%。
- **[收购太原高速及实业集团股权]** -> [业务布局优化]: 现金收购太原高速100%股权和实业集团15%股权，整合路域资源，拓展服务区经营等非通行费收入，其他收入同比大增198.91%。
- **[车流量法摊销]** -> [利润平滑机制]: 采用车流量法摊销特许经营权，当实际车流量低于预测时按预测值摊销，避免了因短期车流量下滑导致的利润剧烈波动。
- **[高资产负债率与利息负担]** -> [财务杠杆显著]: 资产负债率54.6%，长期借款56亿元，利息费用1.55亿元，是影响净利润的核心变量，降息周期下弹性较大。
- **[关联交易集中]** -> [成本控制受制]: 前五大供应商中关联方采购占比30.93%，日常关联交易实际发生额超预算，显示公司运营对控股股东体系依赖度高。
- **[现金分红稳定]** -> [股东回报明确]: 连续两年每10股派2元，2025年分红2.93亿元，占净利润63%，体现高分红政策，但分红率受制于偿债需求。

## 风险警告
**核心风险在于收费政策与经营期限的不确定性。** 公司收入100%来自高速公路通行费，收费标准由政府制定，未来收费年限、费率调整等政策变动将直接冲击收入。同时，高铁、民航等替代交通方式的发展，可能分流车流量，导致实际车流量低于预测，进而影响摊销和利润。

**财务风险集中于高负债与关联交易。** 资产负债率54.6%，长期借款56亿元，每年利息支出超1.5亿元，对利率变动极为敏感。此外，公司日常运营高度依赖控股股东体系（采购、养护等关联交易占比高），虽有利于协同，但也削弱了成本控制的独立性，并存在潜在的利益输送风险。
