# 601318.SH 深度透视

## 因果逻辑链
- **[寿险新业务价值高增]** -> [集团营运利润增长10.3%]: 寿险NBV同比+29.3%，价值率提升5.8pct，直接驱动集团核心利润增长。
- **[银保渠道爆发式增长]** -> [渠道结构优化]: 银保NBV同比+138%，贡献占比提升，弥补代理人渠道增速放缓，实现多渠道均衡发展。
- **[医疗养老生态赋能]** -> [寿险件均保费提升]: 享有医疗/居家/高端养老权益的客户，寿险新单件均分别提升至普通客户的1.5/5.2/23.4倍，形成差异化定价能力。
- **[综合金融客户黏性]** -> [低成本获客与高留存]: 持有3类及以上产品客户留存率99%，内部获客成本比外部低35-45%，构筑成本护城河。
- **[产险综合成本率优化]** -> [承保利润翻倍]: 综合成本率96.8%，同比优化1.5pct，车险费用精细化管理及保证险扭亏，推动承保利润同比+96.2%。
- **[权益市场回暖]** -> [投资收益超预期]: 综合投资收益率6.3%，同比+0.5pct，股票及权益基金配置增加，贡献超额收益。
- **[科技降本增效]** -> [运营效率提升]: AI坐席覆盖80%客服，AI出单/理赔/风控大幅降低人工成本，产险运营成本3年降1pct，保单复效提升30%。
- **[银行业务结构调整]** -> [净息差收窄但资产质量改善]: 净息差降至1.78%，但个人贷款不良率下降0.16pct，零售净利润同比+828%，结构优化对冲息差压力。

## 风险警告
**核心风险：利率长期下行对利差损的侵蚀。** 寿险负债成本刚性，而新增固收资产收益率持续走低，净投资收益率已降至3.7%。虽然公司通过增加权益配置和浮动收益产品（分红险）对冲，但若利率持续低位，将压缩长期利差空间，并导致内含价值对利率假设高度敏感（利率降50bp，内含价值降9.6%）。

**次要风险：权益市场波动与地产敞口。** 公司保险资金股票+基金配置占比近20%，权益市场大幅下跌将直接冲击投资收益和偿付能力（权益跌10%，集团偿付能力降3.7pct）。同时，不动产投资余额仍有2022亿元（占比3.1%），虽以收租型物业为主，但商业地产估值下行风险仍需警惕。
