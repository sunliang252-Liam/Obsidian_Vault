# 603970.SH 深度透视

## 因果逻辑链
- **境外业务高增长** -> 营收增长6.09%: 境外收入同比大增30.79%，成为营收增长核心引擎，但毛利率下降1.03个百分点，显示以价换量。
- **财务费用飙升** -> 归母净利润下降15.17%: 汇率波动导致汇兑损失激增，财务费用同比暴增142.52%，直接侵蚀利润。
- **信用减值损失扩大** -> 利润承压: 信用减值损失同比增加3.6倍至5611万元，反映下游客户回款风险加剧，坏账计提压力显著上升。
- **原药价格低位震荡** -> 毛利率承压: 原药价格全年低位运行，公司农药流通综合毛利率下降0.48个百分点，盈利能力受行业周期压制。
- **经营活动现金流恶化** -> 经营质量下降: 经营性现金流净额由正转负，从3.07亿骤降至-0.78亿，主因采购付款增加，显示对上游议价能力或库存管理出现问题。
- **“一证一品”政策** -> 行业洗牌风险: 2026年新规将淘汰大量同质化产品，公司作为流通龙头有望受益于行业集中度提升，但短期面临厂商合作逻辑重构的挑战。
- **出口退税取消** -> 出口模式转型压力: 2026年4月起草铵膦等20余项原药出口退税取消，将倒逼公司从低价出口向品牌化、高附加值产品转型，短期成本压力增大。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长依赖低毛利的境外业务，但汇率波动、信用减值损失和财务费用三座大山严重侵蚀利润，导致归母净利润连续两年下滑。更危险的是，经营活动现金流净额由正转负，表明公司为维持收入增长，不得不加大采购垫资，经营质量显著恶化。若原药价格持续低迷或下游客户违约增加，公司利润和现金流将面临更大压力。

**政策与外部环境风险不容忽视。** 2026年“一证一品”政策将重塑行业格局，虽长期利好龙头，但短期可能冲击公司与部分厂商的稳定合作关系。同时，出口退税取消直接增加出口成本，而海外子公司所在国（如阿根廷、巴西）的政治政策风险（环保法规趋严、关税变动）可能进一步压缩海外业务利润。公司需证明其有能力在行业洗牌中巩固渠道优势，并有效管理汇率和信用风险，否则增长将不可持续。
