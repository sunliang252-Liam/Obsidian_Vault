# 000912.SZ 深度透视

## 因果逻辑链
- **[尿素、甲醇等产品价格震荡下行]** -> [营收下降11.34%]: 主要产品价格下跌直接导致公司营业收入从50.70亿元降至44.95亿元，尽管销量基本稳定。
- **[天然气等原料成本持续高位]** -> [盈利空间严重收窄]: 原料价格与产品价格形成倒挂，成本压力显著增大，导致扣非净利润为负（-3842.74万元）。
- **[非经常性损益大幅增加]** -> [归母净利润逆势增长50.23%]: 资产处置收益（2641万元）、政府补助（3115万元）及金融资产公允价值变动（2192万元）等非经常性损益合计7021万元，掩盖了主业亏损。
- **[甲醇产能利用率仅36.10%]** -> [资产效率低下]: 甲醇装置大量闲置，产能利用率不足四成，直接拉低整体资产回报率，是公司资产结构中的明显短板。
- **[复合肥新产能投产]** -> [化肥库存量增长32.06%]: 宁夏生态肥业新项目建成投产，导致复肥产品产量及库存量较同期增长，但市场消化能力有限，库存积压风险上升。
- **[同一控制下企业合并（收购油脂化学）]** -> [资本公积减少5928万元]: 收购四川泸天化油脂化学有限公司，因同一控制下合并导致资本公积大幅冲减，对净资产产生一次性负面影响。
- **[经营活动现金流净额下降31.83%]** -> [现金流质量恶化]: 主要商品价格下降导致收回货款减少，经营活动现金流净额从3.40亿元降至2.32亿元，与净利润的背离反映出回款压力增大。

## 风险警告
**核心风险在于主业持续亏损与现金流恶化。** 公司2025年扣非净利润为-3842.74万元，已连续两年为负，表明在尿素、甲醇等主营产品价格下行周期中，公司缺乏成本转嫁能力，盈利基础极为脆弱。同时，经营活动现金流净额同比下降31.83%，与净利润的背离进一步印证了公司回款能力减弱、营运资金压力上升的困境。

**战略转型存在巨大不确定性。** 公司提出“新农化、新材料、新能源”三新战略，并推进10万吨/年绿色精细化学品、电解制氢合成氨等重大项目，但这些项目均处于建设初期或中试阶段，距离商业化盈利尚需时日。在传统主业亏损、现金流承压的背景下，大规模资本开支（报告期投资额同比增204.83%）将加剧财务压力，若转型不及预期，公司可能面临“旧业失守、新业未立”的窘境。
