# 300575.SZ 深度透视

## 因果逻辑链
- **[产销量提升]** -> [营收增长10.59%]: 公司克服行业竞争，通过提升产销量（销售量+42.45%）推动收入增长，但未能转化为利润。
- **[产品价格大幅下降]** -> [净利润亏损1.91亿]: 核心产品价格下跌幅度超过销量增长带来的收入效应，导致毛利率大幅下滑（农药原药毛利率-12.89%）。
- **[大规模建设投入]** -> [折旧与财务费用侵蚀利润]: 安徽宁亿泰等新项目陆续转固，折旧增加，同时为项目建设增加贷款导致财务费用飙升15363.95%。
- **[研发与营销费用增加]** -> [短期利润承压]: 公司加大创制农药研发（研发费用+16.42%）及海外登记投入，当期费用化处理，直接减少净利润。
- **[行业去库存周期结束]** -> [需求回暖但竞争加剧]: 全球农药市场去库存基本结束，需求有所回暖，但国内产能重复建设导致低价竞争，公司“增收不增利”。
- **[汇率波动]** -> [财务费用激增]: 出口业务以美元结算为主，报告期内汇率波动产生较大汇兑损失，是财务费用飙升的主因之一。
- **[原材料价格波动]** -> [成本控制压力]: 农药生产依赖石油化工原料，国际原油价格波动导致成本端不确定性增加，公司未能将成本压力有效传导至下游。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长10.59%，但归母净利润巨亏1.91亿元，毛利率全面下滑。根本原因是行业产能严重过剩导致的低价竞争，公司虽以量补价，但价格下跌幅度远超成本降幅，导致主业陷入亏损。**安徽宁亿泰等大规模在建项目是最大的双刃剑**，转固后带来的折旧和财务费用已开始侵蚀利润，若未来市场环境未显著改善，新增产能无法被有效消化，公司可能面临持续的资产减值风险和更严重的亏损。

**财务风险急剧恶化。** 净利润亏损的同时，经营活动现金流净额大幅下降48.28%，显示盈利质量极差。公司为维持运营和项目建设，短期借款激增37.5%，资产负债率攀升，财务费用暴涨153倍。**公司已连续两年未进行现金分红**，且2025年利润分配预案为“不派发现金红利”，表明公司现金流已十分紧张，股东回报能力严重受损。
