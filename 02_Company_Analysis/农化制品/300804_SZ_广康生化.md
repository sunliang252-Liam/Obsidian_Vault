# 300804.SZ 深度透视

## 因果逻辑链
- **[差异化小众化产品策略]** -> [毛利率提升]: 聚焦克菌丹、灭菌丹等高壁垒小众产品，避开大宗原药价格战，杀菌剂毛利率达33.16%，带动整体盈利改善。
- **[欧盟续登与竞品退出]** -> [核心产品放量]: 克菌丹、灭菌丹获欧盟15年续期，且竞品百菌清等被禁用，公司核心杀菌剂销量突破1万吨，产能利用率提升至70.92%。
- **[关键中间体自主配套]** -> [成本与供应优势]: 自主生产全氯甲硫醇等关键中间体，降低对外依赖，保障供应链稳定，在原料价格波动中实现成本控制。
- **[制剂业务规模化跃升]** -> [第二增长曲线]: 制剂子公司融康生物覆盖省份从10个扩至21个，制剂收入同比增长47.29%，成为营收增长新引擎。
- **[募投项目延期与调整]** -> [短期资本开支压力]: 湖北晟康“年产5,500吨特种化学品项目”因环保新规延期至2027年底，在建工程同比增7.02%，短期无法贡献利润。
- **[海外市场拓展]** -> [收入结构优化]: 国外收入同比增长9.82%，毛利率高达33.89%，显著高于国内，有效对冲国内市场竞争压力。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营现金流净额同比激增464.10%，主要系应收账款回款加快，表明公司议价能力与客户信用管理改善。

## 风险警告
**核心风险在于募投项目持续延期与产能释放的不确定性。** 公司核心增长逻辑依赖湖北晟康基地的新产能投产，但该项目已多次延期至2027年底，且因环保新规需对设计方案进行系统性复核。若项目继续延期或投产初期无法达到预期效益，将严重拖累公司未来2-3年的业绩增长，并持续消耗资本开支。

**另一重大风险是产品结构单一与杀虫剂业务承压。** 公司业绩高度依赖克菌丹、灭菌丹等杀菌剂，该品类贡献了原药收入的69%。而杀虫剂（如联苯肼酯）收入同比下降16.61%，且毛利率仅11.31%，远低于杀菌剂。若杀菌剂市场出现竞争加剧或价格下行，公司将缺乏有效的利润缓冲垫。同时，原材料价格波动与汇率风险虽被提及，但公司通过远期结汇等方式进行对冲，风险相对可控。
