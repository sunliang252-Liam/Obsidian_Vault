# 300387.SZ 深度透视

## 因果逻辑链
- **[全球化肥助剂龙头地位]** -> [营收稳健增长11.87%]: 凭借“全球肥料助剂销量第一”的行业地位，公司持续深化与YARA、OCP等国际巨头合作，海外助剂业务同比增长13.58%，成为营收增长的核心引擎。
- **[生物农业战略布局]** -> [生物制品营收增长24.20%]: 通过控股康欣生物（国家生物农药工程技术研究中心共建单位）和富邦湘渝，公司快速切入生物肥料、生物农药及食品添加剂赛道，生物制品业务成为增速最快的板块。
- **[PSC综合服务模式]** -> [客户粘性增强与市场壁垒]: 公司创新性推出“产品+解决方案+承包”的PSC模式，深度嵌入客户生产流程，以成品产量为结算依据，与全球400余家大型肥料企业形成利益共同体，构筑了难以复制的竞争壁垒。
- **[非经常性损益大幅波动]** -> [归母净利润下滑36.71%]: 尽管扣非净利润同比增长15.36%，但因HNC股权转让价款延期支付利息等费用导致营业外支出高达4862万元，严重拖累归母净利润表现。
- **[研发投入持续加大]** -> [技术护城河加深]: 2025年研发投入5099万元，同比增长8.83%，聚焦绿色助剂、禾本科固氮、合成生物学等前沿领域，累计拥有150件国内授权专利及14件国际专利，为中长期增长奠定技术基础。
- **[“水肥药一体化+数字技术”模式]** -> [从“卖产品”向“卖服务”转型]: 公司整合土壤CT扫描、智能配肥、生物制剂等技术，为规模化种植户提供“提质增收”综合解决方案，推动特种肥料业务从标准化产品向定制化服务演进。
- **[海外并购整合与商誉风险]** -> [资产质量承压]: 通过并购荷兰诺唯凯、法国PST等形成的5.11亿元商誉，占总资产比重较高，若被并购企业经营不及预期，存在商誉减值风险，对资产质量构成潜在压力。

## 风险警告
**核心风险在于利润质量与现金流严重背离。** 2025年公司扣非净利润同比增长15.36%，但经营活动现金流净额却骤降74.28%至3792万元，主要系应收账款增加及HNC股权转让延期支付利息等非经常性支出所致。这种“纸面盈利”与“真实现金”的巨大落差，暴露出公司回款能力弱化及非主业投资拖累的隐患，需警惕其对公司持续经营能力的侵蚀。

**商誉减值与海外整合风险不容忽视。** 截至2025年末，公司商誉高达5.11亿元，占净资产的35%，主要来自荷兰诺唯凯和法国PST的收购。在全球地缘政治不稳定、贸易保护主义抬头的背景下，海外业务面临汇率波动、供应链中断及本地化运营挑战。若被并购标的业绩未达预期，巨额商誉减值将直接冲击公司资产负债表和利润表，这是悬在投资者头上的达摩克利斯之剑。
