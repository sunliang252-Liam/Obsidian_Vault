# 600470.SH 深度透视

## 因果逻辑链
- **[原材料成本飙升]** -> [毛利率暴跌]: 硫酸、硫磺采购价同比涨超100%，钾肥价格高企，直接推高磷肥生产成本，而产品售价受国家稳价保供政策限制，成本无法传导，导致综合毛利率从9.41%骤降至4.68%。
- **[出口管控收紧]** -> [国内供给过剩]: 化肥出口受政策管控，出口量大幅下滑（国外收入同比下降19.25%），过剩产能转向国内，加剧国内市场竞争，进一步压低国内售价。
- **[资产减值损失激增]** -> [利润巨额亏损]: 报告期计提存货跌价准备及固定资产减值准备1.58亿元，同比增加6倍以上，成为吞噬利润的关键因素之一。
- **[在建工程大幅扩张]** -> [现金流承压]: 子公司湖北徽阳新材料一体化项目投入增加，在建工程同比暴增328%，导致投资活动现金净流出13.73亿元，公司资产负债率升至73.08%。
- **[国家保供稳价政策]** -> [盈利空间被压缩]: 作为农资企业，公司承担稳价保供任务，磷肥和尿素售价无法随成本同步上涨，导致“成本推动型”亏损，体现了政策与市场的矛盾。
- **[品牌与渠道优势]** -> [收入端相对稳定]: 尽管利润巨亏，但凭借“六国”品牌和2.39万个终端网点，公司营业收入仍实现3.06%的同比增长，显示出较强的市场抗压能力。

## 风险警告
**核心风险在于成本与政策的双重挤压。** 公司主要原材料硫酸、硫磺价格受国际大宗商品市场影响剧烈，而化肥终端售价受国家“保供稳价”政策严格限制，导致公司几乎完全暴露在成本波动的风险之下，缺乏有效的价格传导机制。2025年净利润从盈利2518万元骤降至亏损4.56亿元，正是这一结构性矛盾的集中爆发。若未来原材料价格持续高位运行，而政策不放松，公司盈利能力将面临持续严峻挑战。

**财务风险急剧恶化。** 巨额亏损导致净资产收益率暴跌至-25.6%，母公司未分配利润赤字扩大至-4.85亿元，已不具备分红条件。同时，为推进湖北徽阳等重大项目，公司大幅举债，资产负债率攀升至73.08%，短期借款与一年内到期非流动负债合计超20亿元，而经营活动现金流净额仅4336万元，同比骤降89%，短期偿债压力巨大。若项目投产后的收益不及预期，公司将面临流动性危机。
