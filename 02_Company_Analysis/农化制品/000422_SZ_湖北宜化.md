# 000422.SZ 深度透视

## 因果逻辑链
- **[重大资产重组完成，新疆宜化并表]** -> [营收微增但归母净利润大降24.25%]: 新增煤炭、尿素、PVC产能，但煤炭价格下行及PVC市场承压，拖累整体盈利。
- **[煤炭产品量价齐跌]** -> [煤炭收入同比降32.64%，毛利率降6.06%]: 保供政策下供给宽松，新能源对火电挤出效应增强，冶金建材需求走弱。
- **[磷复肥量价齐升]** -> [磷复肥收入同比增69.16%]: 下游农业及新能源需求支撑，硫磺等原料价格高位运行，叠加新项目投产放量。
- **[PVC市场持续承压]** -> [PVC毛利率为-7.83%]: 社会库存高位，需求疲软，行业“碱强氯弱”格局深化，公司以碱补氯维持综合利润。
- **[沿江化工“关改搬转”完成]** -> [新项目投产推动产业升级]: 20万吨精制磷酸、65万吨磷铵、20万吨烧碱等项目投产，实现新旧动能转换。
- **[硫磺价格大幅上升]** -> [成本端压力增加]: 新能源需求重塑市场，全球供应紧张，导致公司主要原料硫磺采购成本同比大幅增长。
- **[729名核心骨干股权激励]** -> [健全激励约束长效机制]: 将员工利益与公司中长期发展深度捆绑，提升管理效能与凝聚力。

## 风险警告
**核心风险在于产品价格周期性与成本端双重挤压。** 公司尿素、PVC、煤炭等主要产品价格受宏观经济与行业供需影响显著，2025年已出现不同程度下滑。同时，硫磺、磷矿石等关键原材料价格高位运行，若下游需求持续疲软，公司毛利率存在进一步收窄风险，尤其是PVC业务已陷入亏损，短期难以逆转。

**财务风险不容忽视。** 公司资产负债率高达70.55%，且长期借款超124亿元，财务费用同比增长10.98%。尽管经营活动现金流净额达36亿元，但大规模资本开支（在建工程超40亿元）及偿债压力并存，若未来盈利下滑，可能引发流动性紧张。此外，非经常性损益（如同一控制下企业合并产生的净损益4.13亿元）对净利润贡献较大，扣非后净利润仅5.02亿元，盈利质量有待提升。
