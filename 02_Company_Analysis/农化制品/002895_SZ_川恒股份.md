# 002895.SZ 深度透视

## 因果逻辑链
- **[磷矿石资源自给+高毛利率]** -> [业绩增长]: 控股子公司福麟矿业年产334万吨磷矿石，81.10%的极高毛利率为下游磷化工产品提供低成本原料保障，是利润基石。
- **[广西鹏越项目达产]** -> [磷酸及二氢钙收入创历史新高]: “20万吨/年半水-二水湿法磷酸及精深加工”项目达标达产，带动磷酸收入同比+50.10%，饲料级磷酸二氢钙收入同比+44.89%。
- **[原材料价格上涨传导]** -> [产品售价提升]: 硫磺、硫酸等原材料价格大幅上涨，公司通过定价机制将成本压力向下游传导，推动磷酸、磷酸一铵等产品售价自年初起持续上涨。
- **[新能源材料放量]** -> [磷酸铁收入翻倍]: 磷酸铁产品收入同比+100.59%，受益于磷酸铁锂电池在动力和储能领域的双轮驱动需求爆发。
- **[国际市场需求增长]** -> [出口收入高增]: 国际销售同比+75.48%，占比提升至38.88%，主要得益于东南亚、南亚等市场对饲料级磷酸二氢钙和磷酸的需求增长。
- **[半水法技术优势]** -> [成本与环保竞争力]: 自主开发的半水湿法磷酸成套技术，硫酸消耗低2%、磷石膏结晶水含量仅5-6%，结合磷石膏充填技术，实现降本增效与固废资源化。
- **[研发投入翻倍]** -> [技术壁垒构建]: 研发投入同比+103.25%，聚焦磷矿浮选、磷酸净化、新能源材料及磷石膏高值化利用，为未来产品升级和成本优化储备技术。

## 风险警告
**核心风险在于原材料价格波动与下游需求的不确定性。** 公司主要原材料硫磺、硫酸价格在2025年大幅上涨，虽然公司通过定价机制传导成本，但若未来原材料价格持续高位或下游磷化工产品（尤其是磷酸铁）需求不及预期，将严重挤压毛利率。此外，公司经营活动现金流净额同比-25.29%，与净利润增长严重背离，主要因票据结算规模扩大，需警惕现金流对利润的支撑力度。

**另一重大风险是环保政策趋严与磷石膏处置压力。** 2026年是“新增磷石膏100%无害化处理”的关键节点，若公司半水磷石膏充填技术无法完全满足处置需求，堆存空间的限制将直接影响生产。同时，参股公司天一矿业（老虎洞磷矿）尚在建设期，公司为其提供12.74亿元连带责任担保，若其未来经营不及预期，将产生担保损失风险。
