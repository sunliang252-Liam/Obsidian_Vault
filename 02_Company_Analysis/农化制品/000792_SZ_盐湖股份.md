# 000792.SZ 深度透视

## 因果逻辑链
- **[钾肥价格回暖]** -> [归母净利润同比+81.76%]: 全球钾肥供给端寡头控量挺价，叠加国内粮食安全需求刚性，公司氯化钾售价上升，直接拉动钾肥板块毛利率提升7.37个百分点。
- **[碳酸锂成本优势]** -> [锂产品毛利率52.03%]: 依托察尔汗盐湖超高镁锂比卤水提锂技术突破，公司碳酸锂单位成本控制在行业低位，即使售价波动仍维持高毛利。
- **[央企入主整合]** -> [资源扩张与同业竞争解决]: 中国五矿成为实控人后，公司完成对五矿盐湖51%股权收购，新增一里坪盐湖资源，钾锂产能规模跃升，并消除同业竞争。
- **[4万吨锂盐项目投产]** -> [锂盐产能翻倍]: 2025年9月新建4万吨/年基础锂盐一体化项目投料试车，叠加蓝科锂业原有产能，公司碳酸锂总产能提升至约8万吨/年。
- **[阿米巴精益管理]** -> [成本显著压降]: 全面推行三级阿米巴经营体系，氯化钾、碳酸锂完全成本较预算分别下降0.71%和12.09%，吨水耗下降20%以上。
- **[高进口依存度]** -> [国产钾肥“压舱石”地位]: 国内钾肥进口依存度高达68.56%，公司作为国内最大钾肥生产商（产能530万吨），在保供稳价中享有定价话语权与政策红利。
- **[库存股注销+实控人增持]** -> [股本优化与信心强化]: 注销1.4亿股库存股，中国五矿增持2.48亿股（占总股本4.69%），直接提升每股收益并传递长期看好信号。

## 风险警告
**核心风险在于钾锂双主业的价格波动。** 氯化钾价格受国际寡头（Nutrien、Uralkali等）产量调控及地缘政治（白俄制裁、俄乌冲突）影响极大，2025年价格回暖但历史波动剧烈；碳酸锂价格虽在2025年末回升至12万元/吨，但上半年曾触及5.9万/吨历史低点，供需格局仍存不确定性。公司利润高度依赖产品售价，一旦价格下行，业绩弹性将迅速逆转。

**另一重大风险是母公司未弥补亏损的财务结构。** 截至2025年末，母公司报表未分配利润为-85.08亿元，合并报表为-19.23亿元，导致公司连续多年无法进行现金分红。虽然盈利强劲，但历史重整遗留的亏损窟窿需持续用利润填补，这限制了股东直接回报，并可能影响再融资能力。此外，公司正加速海外钾锂资源扩张，境外投资面临汇率、地缘政治及运营管理等多重挑战。
