# 600331.SH 深度透视

## 因果逻辑链
- **[硫磺价格暴涨]** -> [磷化工板块利润下滑]: 硫磺年均价同比上涨123%，成本涨幅远超产品售价涨幅，挤压毛利率。
- **[锌冶炼加工费低迷]** -> [锌冶炼业务亏损]: 锌精矿加工费虽回升但仍处低位，叠加锌价下跌2.27%，原料成本高企导致亏损。
- **[天然气制氨成本劣势]** -> [合成氨业务大幅亏损]: 煤制氨成本优势凸显，天然气制氨售价同比下降12.22%，出现成本与售价倒挂。
- **[历史遗留问题化解]** -> [资本结构根本性改善]: 金鼎锌业纠纷解决，定向增发28.53亿元到账，资产负债率从82.87%骤降至12.99%。
- **[无自有矿山]** -> [盈利能力受制于原料价格]: 磷矿、锌精矿全部外购，对上游价格波动敏感，缺乏成本缓冲垫。
- **[房地产下行]** -> [磷石膏处置成本上升]: 传统建材渠道需求下降，磷石膏综合利用率同比下降，产消平衡承压。
- **[蜀道集团战略赋能]** -> [发展定位与资源获取能力提升]: 被确定为集团重要核心子公司，在资金、资源、渠道上获得全方位支持。

## 风险警告
**核心风险在于“无矿之痛”与“成本失控”的双重夹击。** 公司磷矿、锌精矿100%依赖外购，在硫磺价格暴涨123%、锌精矿加工费低迷的2025年，成本端完全暴露于市场波动之下，导致两大主业毛利率均下滑，全年净亏损7430万元。尽管定增大幅改善了资产负债表，但并未解决上游资源缺失这一根本性短板，盈利能力依然脆弱。

**其次，历史包袱虽已卸下，但新战略的落地存在巨大不确定性。** 公司计划通过并购获取上游磷矿、铅锌矿资源，并推动多龙铜矿投产，但这些项目投资巨大、周期漫长，短期内无法贡献利润。同时，控股股东蜀道集团承诺五年内解决同业竞争问题，若整合不及预期，可能引发治理风险。在行业产能过剩、竞争加剧的背景下，公司能否将资本优势转化为资源控制力，是未来扭亏为盈的关键。
