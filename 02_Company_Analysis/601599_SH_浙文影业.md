# 601599.SH 深度透视

## 因果逻辑链
- **[纺织业务订单增长]** -> [营收增长6.22%]: 纺织板块抢抓市场机遇，订单增量明显，营收同比增加2.31亿元，成为收入增长唯一引擎。
- **[拆迁补偿收益计入非经常性损益]** -> [扣非净利润暴跌90%]: 纺织生产基地结转拆迁补偿收益1.24亿元计入非经常性损益，导致扣非净利润仅794万元，同比大降90%。
- **[资产减值损失大幅增加]** -> [侵蚀核心利润]: 报告期内对影视剧项目及纺织存货计提减值损失1.55亿元，同比增加8380万元，是扣非利润下滑的核心原因。
- **[影视业务收入萎缩]** -> [双轮驱动失衡]: 影视业务收入仅466.5万元，同比暴跌85.79%，毛利率为-102.79%，影视板块严重拖累整体盈利能力。
- **[经营活动现金流改善]** -> [财务质量提升]: 应收账款下降及银行承兑汇票保证金减少，使经营性现金流净额达3.55亿元，同比增长9.46%，现金流质量优于利润表表现。
- **[其他权益工具投资公允价值变动]** -> [净资产无实质增长]: 股权投资亏损导致其他综合收益减少1.33亿元，抵消了净利润增长，归属股东净资产几乎零增长。
- **[母公司未弥补亏损巨大]** -> [无法分红]: 母公司未分配利润为-13.28亿元，不满足分红条件，2025年度不派发现金红利。

## 风险警告
**核心风险在于影视业务的持续萎缩与资产减值压力。** 影视业务收入仅466.5万元，毛利率为-102.79%，已沦为亏损包袱。公司对影视剧项目及纺织存货计提了1.55亿元减值损失，且应收账款坏账准备高达32.4亿元（占账面余额52%），表明历史项目质量堪忧，资产“虚胖”问题严重。若影视板块无法实现精品化突破，减值风险将持续侵蚀利润。

**第二重风险来自纺织业务的“虚胖”增长与外部贸易环境。** 纺织营收增长7.73%，但扣非净利润却因减值而暴跌，增长质量存疑。公司海外收入占比31%，面临国际贸易摩擦、汇率波动及原材料价格波动的多重风险。越南、孟加拉生产基地虽已投产，但地缘政治与关税政策的不确定性，可能随时冲击海外产能的盈利稳定性。
