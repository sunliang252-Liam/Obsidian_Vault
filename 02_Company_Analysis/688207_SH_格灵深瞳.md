# 688207.SH 深度透视

## 因果逻辑链
- **[收购国科亿道]** -> [营收增长32.61%]: 2024年11月收购国科亿道，2025年全年并表，其智能终端计算设备业务贡献了主要增量收入，但拉低了整体毛利率。
- **[大客户框架合同到期]** -> [智慧金融收入骤降73.31%]: 与中国农业银行的框架合同于2025年9月到期，导致该领域收入大幅下滑，且该业务毛利率转负（-12.52%）。
- **[持续高强度研发投入]** -> [净利润持续亏损]: 研发投入占营收比例高达93.93%，尽管同比有所下降，但绝对额仍远超营收规模，是公司连续亏损的核心原因。
- **[客户结构优化]** -> [非农行客户营收占比超90%]: 公司主动拓展城市管理、政务及特种等领域，来自农行以外客户的收入同比增长近120%，降低了对单一客户的依赖。
- **[缩减办公面积与优化人员]** -> [研发费用同比下降22.72%]: 公司通过调整办公布局和优化人员结构，有效控制了研发费用中的折旧与薪酬支出。
- **[硬件业务占比提升]** -> [整体毛利率下降19个百分点]: 收购国科亿道后，低毛利的硬件产品（智慧终端、超融合一体机）收入占比大幅提升，结构性拉低了公司整体毛利率。
- **[商誉减值与坏账增加]** -> [非主营业务亏损扩大]: 报告期内计提商誉减值及应收账款坏账损失合计约2428万元，加剧了公司的亏损幅度。

## 风险警告
公司最核心的风险在于**盈利模式尚未跑通**。尽管营收增长，但亏损仍在持续，且亏损额（-1.86亿）远超营收（1.55亿）。高强度的研发投入（93.93%）是维持技术领先的必要条件，但短期内难以转化为利润，公司仍处于“烧钱换技术、换市场”的阶段。一旦融资环境收紧或资本市场信心动摇，公司现金流将面临严峻考验。

第二大风险是**大客户依赖的“断崖”效应**。虽然公司已开始多元化，但与中国农业银行的框架合同到期，导致智慧金融业务收入断崖式下滑（-73.31%），且该业务毛利率已为负值。新拓展的政务及特种业务（如国科亿道）虽然贡献了主要收入，但毛利率低，且客户集中度同样较高，能否持续增长并弥补金融业务的缺口存在巨大不确定性。公司本质上仍是一个在多个低壁垒、高竞争领域艰难探索的AI公司。
