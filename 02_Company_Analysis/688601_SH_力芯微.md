# 688601.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧与供应链成本上升]** -> [毛利率下降5.08个百分点]: 产品售价承压，同时晶圆及封装成本受贵金属价格上涨影响，导致综合毛利率从44.50%降至39.42%。
- **[研发费用激增38.25%]** -> [净利润暴跌70.54%]: 研发人员扩充38人、薪酬及材料费大幅增加，研发投入占营收比从17.85%跃升至25.29%，短期严重侵蚀利润。
- **[销售团队快速扩张]** -> [销售费用增长24.25%]: 为应对市场低迷、强化渗透，公司扩充销售队伍，导致差旅费、样品费等同步增加。
- **[信号链芯片销量暴增106.25%]** -> [产品结构恶化，毛利率骤降14.37个百分点]: 新上量的低毛利信号链产品拉低了整体盈利水平，显示产品组合正经历低端化调整。
- **[民爆行业需求乏力]** -> [子公司赛米垦拓亏损792万元]: 子公司主营的智能组网延时管理单元受下游经济环境影响，产销量下降，毛利率大幅下滑9.73个百分点。
- **[存货跌价准备高企]** -> [财务风险积聚]: 期末存货跌价准备余额达4764万元，计提比例21.31%，反映产品技术迭代快、市场竞争激烈下的库存减值压力。
- **[客户高度集中]** -> [经营脆弱性]: 前五大客户销售额占比61.92%，其中单一客户占比超31%，任何核心客户流失都将对业绩造成重大冲击。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司为应对行业下行和竞争加剧，被迫大幅增加研发和销售投入，但投入并未转化为有效的收入增长或毛利率改善，反而导致净利润暴跌70%。信号链芯片销量暴增但毛利率骤降，表明公司可能通过降价或切入低端市场来维持出货量，这种以利润换规模的策略不可持续，且可能进一步恶化品牌定位和盈利能力。

**财务健康度亮起红灯。** 经营活动现金流净额同比骤降86.87%，与净利润下滑幅度基本匹配，但存货跌价准备高达21.31%，且子公司赛米垦拓持续亏损。在消费电子需求疲软、工业及汽车领域拓展尚需时日的背景下，公司面临“高投入、低回报、高库存、弱现金流”的多重挤压，若行业景气度未能快速回升，公司可能陷入更深的盈利困境。
