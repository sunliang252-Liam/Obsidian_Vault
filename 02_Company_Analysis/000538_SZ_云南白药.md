# 000538.SZ 深度透视

## 因果逻辑链
- **[核心产品放量]** -> [药品事业群营收增长12.53%]: 气雾剂、膏贴剂等核心系列产品销售收入总额超55亿元，同比增长超18%，其中气雾剂突破25亿元，膏贴剂突破12亿元，驱动工业收入增速达10.7%。
- **[渠道模式变革]** -> [药品电商GMV增长139%]: 构建“云鼎经纬”一级经销商直供模式，实现产品从生产到药店点对点直达，同时精准锚定O2O渠道，构建全域协同矩阵，线上渠道成为增长新引擎。
- **[品牌壁垒与品类延伸]** -> [健康品事业群稳居第一]: 云南白药牙膏保持国内全渠道市场份额第一，养元青洗护产品销售收入4.6亿元，同比增长近10%，品牌溢价与品类拓展形成护城河。
- **[全产业链布局]** -> [中药资源事业群抗周期能力]: 通过“六统一”运营模式和“一品一链”路径，构建从种源到市场的全产业链闭环，有效控制原料价格波动风险，保障供应稳定。
- **[高分红政策]** -> [股东回报与市值管理]: 2025年度累计现金分红总额占归母净利润90.09%，通过持续高分红提升股东获得感，强化市场信心。
- **[研发管线推进]** -> [长期增长储备]: 研发投入4.23亿元，同比增长21.51%，核药INR101/102、中药新药附杞固本膏等进入临床后期，为未来产品梯队奠定基础。
- **[外延式并购]** -> [产业链协同补强]: 收购聚药堂，推动中药材产业链协同效率提升，带动省内资源整合和全国布局，为饮片销售和配方颗粒业务拓展奠定基础。

## 风险警告
**核心风险在于创新药研发的高投入与长周期带来的不确定性。** 公司研发投入显著增长，但核药、单抗等创新管线尚处临床早期，商业化前景不明。若研发失败或市场推广不及预期，将拖累利润并影响估值。同时，中药行业面临集采常态化、医保控费及上游药材价格波动的多重压力，行业整体增速放缓，公司药品和健康品业务的高增长能否持续存疑。

**另一重大风险是商业板块的应收账款与现金流压力。** 省医药公司营收238亿元，但商业板块毛利率仅6.69%，且应收账款高达101.6亿元，占公司总资产的18.72%。尽管公司通过信用严控和协同催收管理，但若下游医疗机构回款周期延长或出现坏账，将直接侵蚀利润并影响经营性现金流。此外，公司已退出全部二级市场股票投资，但理财投资规模扩大，需关注其收益稳定性。
