# 603032.SH 深度透视

## 因果逻辑链
- **[精密自动化业务（安徽汉普斯）高速增长]** -> [营业收入同比+53.29%]: 减速器/减速电机业务收入大幅增加，成为公司核心增长引擎，弥补了精密模具业务的下行压力。
- **[2024年计提大额商誉减值]** -> [2025年净利润扭亏为盈]: 2024年因致宏精密业绩下滑计提1.64亿商誉减值，导致巨亏；2025年无此减值，叠加新业务盈利，实现净利润4256万元。
- **[精密模具业务（致宏精密）出货量稳定]** -> [保障基本盈利空间]: 尽管面临市场压力，但作为锂电裁切模具龙头，主力产品出货量稳定，维持了整体盈利能力。
- **[安徽汉普斯业绩承诺超额完成]** -> [增强公司盈利确定性]: 2025年实现净利润3414万元，完成业绩承诺的123.7%，验证了该业务的成长性和盈利能力。
- **[客户回款票据增加及收入结构变化]** -> [经营活动现金流净额下降37.7%]: 精密模具业务回款多为2024年收入，且客户使用商业承兑汇票增多，导致现金流表现弱于利润。
- **[偿还银行借款]** -> [筹资活动现金流大幅净流出1.16亿]: 公司主动降低杠杆，偿还债务，导致筹资活动现金流显著为负，财务结构趋于稳健。
- **[传统道路客运业务萎缩]** -> [拖累整体毛利率]: 受高铁、私家车冲击，客运业务收入增长缓慢，毛利率微降，成为公司业务的“稳定器”而非增长点。

## 风险警告
**核心风险在于精密模具业务的持续下滑与商誉减值隐患。** 致宏精密所处的锂电设备行业竞争加剧，尽管2025年出货量稳定，但收入增长乏力，且2024年已计提大额商誉减值。若未来下游锂电池厂商扩产放缓或技术路线变更，致宏精密业绩可能再度承压，导致账面上高达3.66亿元的商誉面临进一步减值风险，直接冲击公司利润。

**第二重风险来自精密自动化业务的激烈竞争与客户集中度。** 安徽汉普斯虽增长迅猛，但主要聚焦于光伏跟踪支架领域，该领域参与者增多，价格战风险加剧。同时，公司前五名客户销售额占比高达51.59%，存在对少数大客户的依赖。若主要客户流失或行业政策变动，该业务的增长可持续性将面临严峻考验。
