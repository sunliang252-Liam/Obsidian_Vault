# 600703.SH 深度透视

## 因果逻辑链
- **[集成电路业务产能爬坡，固定成本高企]** -> [归母净利润亏损3.53亿元]: 碳化硅、滤波器等新业务处于产能爬坡期，折旧摊销等固定成本高，导致整体盈利能力被拖累。
- **[LED高端产品占比提升]** -> [LED外延芯片毛利率同比增加1.87个百分点]: 公司主动调整产品结构，提升Mini/Micro LED、车用LED等高毛利产品占比，对冲了传统照明市场的疲软。
- **[贵金属废料回收业务模式变更]** -> [投资收益大幅亏损2.24亿元]: 因税收政策变化，公司黄金废料回收由销售改为实物置换，导致前期按暂定价确认的收入需调整，产生大额投资损失。
- **[政府补助减少]** -> [非经常性损益同比大幅下降]: 计入当期损益的政府补助从8.17亿元降至6.02亿元，直接削弱了净利润表现。
- **[存货及固定资产减值增加]** -> [资产减值损失同比扩大58.71%]: 行业竞争加剧及技术迭代，导致公司对部分存货和固定资产计提了5.26亿元的减值准备。
- **[诉讼及仲裁事项增加]** -> [营业外支出同比激增174.63%]: 与供应商惠特科技、淮南市住建局等诉讼仲裁案件，导致公司计提了1.17亿元的预计赔偿损失。
- **[安意法合资项目进入风险量产]** -> [碳化硅业务未来增长可期]: 与意法半导体的重庆8英寸碳化硅项目已产出产品，为未来大规模放量奠定基础。

## 风险警告
公司当前面临的核心风险在于**业绩持续亏损与巨额资本开支之间的矛盾**。2025年归母净利润由盈转亏，扣非后亏损更是高达8.28亿元，而公司仍在湖南三安、重庆三安等项目上持续投入，导致短期借款同比大增42.51%至69.6亿元，财务压力显著。若集成电路业务（尤其是碳化硅）的产能爬坡和客户导入不及预期，公司可能面临“增收不增利”甚至亏损扩大的困境。

此外，**公司治理与法律风险不容忽视**。副董事长兼总经理林科闯被留置，实际控制人林秀成也被留置，核心管理层的不确定性可能影响公司战略执行。同时，公司与惠特科技、淮南市住建局等多起诉讼仲裁案件导致大额资产被冻结或查封，并计提了高额预计负债，潜在的赔偿支出和资产处置风险将对公司现金流和资产负债表构成持续威胁。
