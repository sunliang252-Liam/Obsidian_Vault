# 301116.SZ 深度透视

## 因果逻辑链
- **2024年产业链盈利刺激产能增长** -> 2025年鸭苗、养殖、屠宰等鸭产业链各环节全面亏损: 2024年产业链盈利状态刺激产能进一步增长，导致供过于求，而鸭产品消费场景开发不足导致市场需求萎缩，供需失衡引发全面亏损。
- **鸭产品消费场景开发不足** -> 鸭产业链亏损: 鸭肉消费场景开发不足导致市场需求萎缩，叠加产能过剩，加剧供需失衡，造成产业链亏损。
- **禽肉消费市场整体下行** -> 公司整体营收和利润下滑: 行业系统性下行，禽肉消费市场整体需求不振，公司核心产品价格下降，导致营收减少和亏损。
- **公司加大研发投入和产品开发** -> 调熟和羽绒业务逆势增长: 公司通过新品研发（如黑鸭煲、鸭肉丁汉堡）和产品结构升级，推动高附加值产品如调理品和羽绒业务增长，对冲传统业务下滑。

## 风险警告
公司面临行业系统性下行风险，鸭产业链全面亏损且短期难以改善，若消费市场持续低迷或产能去化缓慢，公司经营压力可能进一步加大。同时，公司资产负债率较高，短期借款增加，现金流净额大幅下滑，需关注偿债能力和流动性风险。
