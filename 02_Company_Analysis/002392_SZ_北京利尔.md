# 002392.SZ 深度透视

## 因果逻辑链
- **[全产业链布局（矿山-原料-制品-回收）]** -> [成本控制与抗风险能力提升]: 自有镁质矿山和原料产能平抑了原材料价格波动，降低了外购依赖，增强了盈利稳定性。
- **[“整体承包”商业模式]** -> [高客户粘性与收入稳定性]: 该模式提供“全程在线服务”，排他性强，合同周期长（1-5年），使公司80%以上收入具有高度确定性。
- **[下游钢铁行业产品结构升级]** -> [高附加值耐材需求增长]: 钢铁企业增加特种钢、不锈钢产量，带动了对精炼用高品质、低碳/无碳耐火材料的需求，公司技术储备契合此趋势。
- **[收购包头利尔70%股权]** -> [并表增厚收入与利润]: 2025年4月完成收购，将包头利尔纳入合并范围，直接贡献了2.1亿元收入和5516万元净利润，是营收增长的重要来源。
- **[出售民生证券股权认购国联证券股份]** -> [产生大额非经常性收益]: 该交易在2025年确认了约1.64亿元公允价值变动损益和投资收益，是归母净利润增长25.86%的主要驱动力。
- **[行业集中度提升，小企业退出]** -> [头部企业市占率上升]: 下游需求疲软和环保政策趋严加速了竞争力弱的中小企业出清，公司作为龙头凭借综合优势持续获取市场份额。
- **[研发投入聚焦低碳、环保、长寿化]** -> [巩固技术壁垒与产品竞争力]: 持续研发VOD精炼用低碳镁碳砖、环保型铁沟料等新产品，满足下游对降本增效和绿色生产的要求。

## 风险警告
**核心风险在于扣非净利润的持续下滑与经营现金流净额的恶化。** 2025年扣非净利润同比下滑15.88%，而经营现金流净额也同比下降18.87%，表明公司主营业务的盈利质量和回款能力正在承压。尽管营收增长，但应收账款和存货规模大幅增加，占用了大量营运资金，这直接反映了下游钢铁行业客户经营压力向公司传导的风险。

**另一重大风险是业绩对非经常性损益的高度依赖。** 2025年归母净利润4.01亿元中，非经常性损益高达1.63亿元，主要来自出售民生证券股权。剔除该部分后，公司实际盈利能力并未随营收同步增长。未来若缺乏此类资产处置收益，且主营业务盈利能力无法改善，公司整体利润水平将面临显著下滑压力。
