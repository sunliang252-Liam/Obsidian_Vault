# 300481.SZ 深度透视

## 因果逻辑链
- **[顺酐酸酐衍生物价格持续低位运行]** -> [净利润同比下降31.44%]: 尽管销量同比增长12.31%至9.49万吨，但产品价格持续下行，导致“增收不增利”，毛利率被显著压缩。
- **[原材料价格波动]** -> [营业成本上升2.63%]: 顺酐、丁二烯等基础化工原料价格波动，直接推高生产成本，挤压了本已微薄的利润空间。
- **[产能扩张与释放]** -> [销量增长但利润承压]: “年产1万吨顺酐酸酐衍生物改扩建项目”等新产能投产，虽支撑了销量增长，但加剧了市场竞争，导致产品价格承压。
- **[功能材料中间体项目终止]** -> [募集资金用途变更]: 鉴于市场环境变化，公司终止“功能材料中间体项目”，将剩余1.37亿元募集资金永久补充流动资金，反映该业务拓展不及预期。
- **[收购濮阳联众股权]** -> [新增长期股权投资]: 以1.15亿元收购濮阳联众47.56%股权，进入环戊烷等新型环保材料领域，旨在拓展业务版图，但短期内贡献利润有限。
- **[汇率波动]** -> [财务费用大幅增加]: 2025年人民币汇率波动导致汇兑损失增加，财务费用从-3778万元升至-972万元，对利润产生负面影响。
- **[库存大幅增加]** -> [营运资金占用加剧]: 期末库存量同比增长102.10%至7445吨，主要系根据订单备货，但增加了资金占用和存货跌价风险。

## 风险警告
**核心风险在于“量增价跌”的恶性循环。** 公司作为顺酐酸酐衍生物龙头，虽通过产能扩张实现了销量增长，但行业竞争加剧导致产品价格持续低迷，毛利率被严重侵蚀。2025年净利润同比下降31.44%，且经营性现金流净额同比下降38.41%，显示盈利质量恶化。若下游需求（风电、电气绝缘）增速放缓或新产能持续释放，价格战可能进一步加剧，公司利润空间将被压缩至极限。

**第二重风险来自战略转型的不确定性。** 公司终止了核心募投项目“功能材料中间体”，转而收购濮阳联众股权进入新领域，但新业务与主业协同效应尚待验证。同时，公司研发投入资本化率为零，且核心技术人员流失风险被明确提及，这对其长期技术竞争力构成隐患。在主营业务承压的背景下，新业务能否成为第二增长曲线存在较大不确定性。
