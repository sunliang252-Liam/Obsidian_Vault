# 688051.SH 深度透视

## 因果逻辑链
- **国家双碳政策密集出台，碳市场扩容至8个行业** -> 智慧双碳业务收入增长预期: 政策强制控排企业纳入碳市场，企业对碳管理平台需求增加，公司承接全国碳市场管理平台等核心系统，直接受益于市场扩容。
- **公司绿色低碳数字赋能平台发布及中华环保联合会专委会成立** -> 数据要素价值化与商业模式升级: 平台集成20年数据与AI大模型，形成‘带着平台做市场’新商业模式，提升数据资产变现能力。
- **国家数据基础设施与数字经济建设政策** -> 公司数据工厂技术体系拓展: 政策鼓励数据流通与数字基础设施建设，公司参与国标制定、获数字经济专项支持，强化数据治理与算力能力。
- **营业收入同比下降（2.06亿 vs 3.00亿）** -> 公司需依赖新业务增长点弥补传统业务下滑: 营业收入扣除后金额从2.99亿降至2.05亿，主要由于项目型收入波动，需通过智慧双碳与数据运营服务实现增长。
- **AI环保智能体‘环保智云’与生态环境大模型备案** -> 非现场监管与执法效能提升带来政企客户黏性: 大模型通过中央网信办备案，实现污染源智能识别、闭环管控，帮助政府精准施策，形成‘数据驱动+智能决策’模式，增强客户复购。

## 风险警告
公司营业收入同比下降超30%，传统业务面临压力；新业务（如智慧双碳、数据运营）尚需时间贡献收入，且依赖政策落地节奏，若政策执行不及预期或市场拓展受阻，公司业绩可能持续承压。此外，公司部分信息因商业秘密豁免披露，信息透明度不足可能影响投资判断。
