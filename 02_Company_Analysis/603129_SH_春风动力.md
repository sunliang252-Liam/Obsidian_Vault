# 603129.SH 深度透视

## 因果逻辑链
- **[全地形车出口龙头地位]** -> [营收增长31.30%]: 公司全地形车出口额占全国74.01%，凭借北美、欧洲市场高端化产品（如U10PRO）及渠道扩张（新增298家），驱动核心业务收入96.08亿元，同比增长33.26%。
- **[电动两轮车爆发式增长]** -> [打造第三增长曲线]: 极核电动销量55.12万台，收入19.12亿元，同比激增381.03%，通过高端定位、产品矩阵完善（AE8、AE7等）及渠道快速扩张（新增1,260家门店），成为业绩新引擎。
- **[全球化产能布局对冲贸易风险]** -> [保障供应链韧性]: 墨西哥、泰国等海外基地产能爬坡，有效对冲美国关税加征等贸易摩擦，实现北美市场收入增长53.86%，并保障订单高效交付。
- **[高端化产品结构升级]** -> [提升盈利能力]: 全地形车及大排量摩托车产品向高价值方向进阶，带动产品均价提升，在营业成本增长37.17%的情况下，仍实现归母净利润13.83%的增长。
- **[持续高研发投入]** -> [构建技术护城河]: 研发费用12.20亿元（占营收6.18%），新增专利337项（含100项发明专利），在AMT自动变速、E-clutch电子离合、MMI2.0智能交互等核心技术实现突破，支撑产品迭代。
- **[赛事营销与品牌建设]** -> [强化全球品牌势能]: 在MotoGP、W2RC等顶级赛事斩获佳绩，包揽Moto3“三冠王”，将赛场荣耀转化为品牌影响力，提升产品溢价与用户忠诚度。
- **[国内摩托车市场龙头地位]** -> [稳固基本盘]: 200CC以上跨骑摩托车市占率24.4%，仿赛品类市占率36.2%，均居行业第一，通过精品主义路线（150AURA、675NK等）巩固领先优势。
- **[财务费用由负转正]** -> [侵蚀利润]: 财务费用从-3.10亿元变为-1.53亿元，主要系汇率波动导致汇兑损失增加，对净利润产生负面影响。

## 风险警告
**核心风险在于贸易摩擦与专利诉讼的双重夹击。** 公司外贸收入占比极高，北美市场尤为关键。2025年已面临美国关税加征（成本中关税高达9.78亿元），且2026年初遭遇行业巨头Polaris发起的337调查，指控侵犯其5项美国专利，目标直指ZFORCE和UFORCE系列核心产品。若败诉，可能导致相关产品被禁止进入美国市场，对全地形车业务造成毁灭性打击。同时，公司资产负债率升至59.85%，海外产能扩张与嘉兴基地建设带来持续资本开支压力。

**成长性面临结构性挑战。** 尽管营收增长31.30%，但归母净利润增速仅13.83%，扣非净利润增速更降至9.70%，毛利率同比下降3.84个百分点。全地形车毛利率下滑4.37个百分点，电动两轮车毛利率为负（-0.03%），仍处于“烧钱换市场”阶段。汇率波动导致的汇兑损失已开始侵蚀利润，若人民币升值或贸易环境恶化，公司高增长态势的可持续性存疑。
