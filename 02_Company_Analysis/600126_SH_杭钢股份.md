# 600126.SH 深度透视

## 因果逻辑链
- **[钢铁主业大幅减亏]** -> [扭亏为盈]: 宁波钢铁通过“低成本、高效率”策略、优化生产组织、全流程降本增效，使热轧钢材毛利率从-1.05%提升至4.32%，亏损面显著收窄。
- **[剥离亏损再生资源业务]** -> [利润改善]: 将持续亏损的再生资源、再生科技置出，确认股权转让投资收益约0.89亿元，同时消除了低毛利、高营收的拖累。
- **[数字产业高速增长]** -> [利润贡献提升]: 数据中心机柜上柜率增加，数字产业营收同比增长82.32%，营业利润大幅增长，成为新的利润增长点。
- **[政府补助减少]** -> [其他收益下降]: 子公司宁波钢铁及再生资源收到的与收益相关的政府补助减少，导致其他收益同比下降47.54%。
- **[资金存放收益下降]** -> [财务费用增加]: 受外部金融市场行情影响，公司资金存放收益下降，导致财务费用同比增加。
- **[资产处置与理财收益]** -> [非经常性损益支撑]: 非流动资产处置损益及理财产品公允价值变动收益合计约1.18亿元，是公司实现归母净利润为正的关键。
- **[营收规模大幅缩水]** -> [结构优化]: 剥离再生资源业务后，营业收入同比下降17.81%，但剔除此影响，核心钢铁及数字业务收入结构更清晰，盈利能力改善。

## 风险警告
公司2025年扭亏为盈，但扣非净利润仍为-1.12亿元，主业盈利能力依然脆弱。钢铁行业供需双弱、价格承压的格局未根本改变，宁波钢铁的微利状态高度依赖成本控制，一旦原料价格波动或需求进一步下滑，极易重回亏损。数字产业虽增长迅猛，但面临全国数据中心建设热潮带来的价格竞争和客户稳定性压力，未来盈利能力存在不确定性。

此外，公司对关联方（杭钢集团）的销售和采购依赖度较高（销售占比11.29%，采购占比5.83%），关联交易定价的公允性及业务独立性需持续关注。同时，子公司宁波钢铁因安全事故被处罚，暴露出安全生产管理的薄弱环节，可能带来潜在的运营中断和赔偿风险。
