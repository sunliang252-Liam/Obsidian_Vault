# 300278.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧导致毛利率下降]** -> [净利润由盈转亏]: 为争夺市场份额降低产品价格，侵蚀利润空间，导致销售毛利率水平下降。
- **[部分订单回款延迟]** -> [信用减值损失增加]: 客户回款账期延长，导致应收账款规模扩大，进而增加信用减值损失计提。
- **[地缘政治因素与汇率波动]** -> [出口成本增加与汇兑损失]: 美国关税政策调整增加出口业务关税成本，汇率波动导致汇兑损失，多重因素叠加使净利润转亏。
- **[境外业务收入增长]** -> [营收规模扩大]: 境外收入同比增长19.65%，占总营收80.45%，是营收增长11.18%的主要驱动力。
- **[自动化输送智能装配生产线收入增长]** -> [营收结构变化]: 该产品收入同比增长34.75%，占总营收63.40%，成为公司最大收入来源。
- **[客户预收款增加]** -> [经营活动现金流大幅改善]: 经营活动产生的现金流量净额由负转正，同比增长178.04%，主要系客户预收款增加。
- **[投资支付的现金增加]** -> [投资活动现金流净额大幅减少]: 投资活动产生的现金流量净额同比减少4394.59%，主要系本期投资支付的现金增加。

## 风险警告
公司2025年净利润由盈转亏，核心原因是行业竞争加剧导致毛利率下降，以及地缘政治和汇率波动带来的额外成本。尽管营收增长11.18%，但盈利能力恶化，且母公司未分配利润为-14.7亿元，不满足现金分红条件，显示公司基本面存在较大压力。

应收账款余额高达11.5亿元，占总资产30.45%，且部分客户回款账期延长，坏账风险显著。同时，公司业务高度依赖境外市场（占比80.45%），面临美国关税政策调整和汇率波动的双重冲击，海外业务盈利空间被大幅挤压。
