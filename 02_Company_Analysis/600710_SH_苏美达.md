# 600710.SH 深度透视

## 因果逻辑链
- **[产业链利润占比提升至76%]** -> [归母净利润增长18%]: 产业链板块（船舶、柴发、清洁能源）利润增速远超供应链，成为盈利核心引擎，对冲了供应链低毛利业务的波动。
- **[船舶制造与航运利润增长82%]** -> [整体利润高增]: 船舶业务受益于高价订单兑现、精益管理降本及航运市场回暖，利润贡献从7.8亿跃升至14.2亿，是最大增量来源。
- **[柴油发电机组利润增长75%]** -> [先进制造板块结构优化]: 国内AI算力中心建设爆发，带动数据中心备用电源需求激增，柴发业务成为新的高增长极。
- **[清洁能源营收增长35%]** -> [大环保板块逆势扩张]: 在光伏行业价格低迷背景下，公司凭借“辉伦”品牌Tier 1地位和工程服务能力，实现营收高增，但毛利率因价格战下降5个百分点。
- **[供应链大宗运营量增长25%]** -> [供应链营收微降2%]: 公司主动扩大运营规模（超6100万吨），但大宗商品价格波动及贸易模式优化导致营收小幅下滑，体现了“以量换利”的转型策略。
- **[经营活动现金流净流出70亿]** -> [现金流压力显现]: 供应链业务为加速海外网络建设、增加大宗采购，导致经营性现金大幅流出，与利润增长形成背离，需关注资金周转效率。
- **[员工持股与市场化机制]** -> [长期竞争力]: 自1998年建立的骨干员工持股制度，形成了“奋斗者为本”的文化，是公司能持续吸引人才、应对市场变化的底层制度优势。

## 风险警告
**核心风险：经营现金流与利润严重背离。** 2025年归母净利润增长18%，但经营活动现金流净额由正转负，净流出70亿元。主因是供应链板块为抢占海外市场、扩大大宗运营规模，导致采购支出阶段性激增。若未来大宗商品价格下跌或下游回款放缓，可能引发流动性压力，需警惕“增收不增现”的陷阱。

**外部风险：贸易保护主义与地缘政治冲击。** 公司进出口规模超133亿美元，业务覆盖160多个国家。美国“对等关税”政策、欧盟碳关税及“一带一路”沿线国别风险，可能直接冲击公司船舶、纺织、光伏等核心业务的出口竞争力与合规成本。虽然公司通过海外产能布局对冲，但关税升级的幅度和速度仍构成重大不确定性。
