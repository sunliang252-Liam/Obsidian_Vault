# 603161.SH 深度透视

## 因果逻辑链
- **[产品结构变化]** -> [营收下降5.59%]: 单价较高的涡轮壳销量减少26.7万件，而单价较低的中间壳销量增加35万件，导致整体营收下滑。
- **[销售价格调整]** -> [扣非净利润骤降31.33%]: 为维持市场份额，公司主动调整产品售价，叠加产品结构变化，导致毛利率下降1.87个百分点，核心盈利能力显著削弱。
- **[财务费用锐减]** -> [净利润降幅收窄]: 通过优化债务结构、降低有息负债，财务费用同比大幅下降63.79%，部分对冲了主营业务利润的下滑。
- **[客户集中度极高]** -> [经营稳定性依赖大客户]: 前五大客户销售额占比高达86.24%，公司业绩与盖瑞特、博格华纳等少数核心客户的订单高度绑定。
- **[控制权变更]** -> [战略方向不确定性]: 2025年9月，公司实际控制人由陈洪民父子变更为卢红萍、涂瀚母子，新实控人背景为电子科技领域，未来战略重心存在变数。
- **[海外收入下滑]** -> [外需疲软拖累业绩]: 境外收入同比减少11.57%，主要系国外客户需求减少，涡轮壳销量减少32万件，显示全球汽车市场景气度对公司影响显著。
- **[产能利用率不足]** -> [固定成本摊销压力]: 公司铸造环节产能利用率仅为67.93%，大量固定资产折旧和人工成本无法被有效摊薄，持续侵蚀利润空间。

## 风险警告
**核心风险在于主业增长乏力与战略方向的双重不确定性。** 公司涡轮增压器壳体业务已进入存量竞争阶段，营收与扣非净利润连续下滑，且高度依赖少数大客户。更关键的是，2025年公司控制权发生变更，新实控人卢红萍、涂瀚母子旗下资产以翊腾电子等精密电子制造为主，与公司现有汽车零部件主业协同性存疑。未来公司是否会向电子领域倾斜资源，存在巨大不确定性，可能动摇现有业务根基。

**财务风险在于资产质量与现金流压力。** 尽管公司通过降负债使资产负债率降至46.97%，但应收账款和存货合计占总资产比例高达38%，且存货跌价准备计提比例较高。同时，经营活动现金流净额同比下降11.39%，显示回款能力减弱。若下游客户经营恶化或行业景气度进一步下行，公司将面临较大的资产减值风险和流动性压力。
