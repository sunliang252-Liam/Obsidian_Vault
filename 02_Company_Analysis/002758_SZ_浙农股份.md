# 002758.SZ 深度透视

## 因果逻辑链
- **[农资流通龙头地位强化]** -> [化肥销量同比增长13.42%，农业综合服务收入增长28.16%]: 公司依托供销社网络和全球采购渠道，在行业集中度提升中抢占份额，实现量价齐升。
- **[出售华通医药100%股权]** -> [归母净利润同比增长43.44%，非经常性损益贡献1.51亿元]: 剥离低效医药批零业务，聚焦农服主业，一次性投资收益显著增厚利润。
- **[科工贸一体化战略推进]** -> [自有产能投产（湖北硫铵、内蒙古硫酸钾），研发绿色肥料]: 向上游延伸降低采购成本，向下游提供差异化产品，构建成本与产品双重优势。
- **[汽车业务聚焦高端品牌]** -> [汽车商贸服务收入下降14.81%，但毛利率仅微降1.40%]: 在行业价格战与新能源冲击下，通过宝马、凯迪拉克等豪华品牌运营，维持了相对稳定的盈利水平。
- **[农业社会化服务体系深化]** -> [运营20家农事服务中心，统防统治面积125万亩次]: 从单纯卖农资转向提供全程化服务，增强客户粘性，开辟新增长点。
- **[经营活动现金流大幅改善]** -> [经营性现金流净额同比增长2163.33%至20.66亿元]: 旺季加大库存去化，销售回款增加，同时利用银行票据采购优化现金流。
- **[中药全产业链模式探索]** -> [保留中药业务，聚焦“浙八味”GAP标准化种植]: 依托农服优势，打造从种植到销售的中药全产业链，培育长期增长潜力。

## 风险警告
**核心风险在于农资与汽车两大主业均面临结构性下行压力。** 农资业务受“肥药双减”政策长期压制，传统化肥农药需求增速放缓，公司虽通过工贸一体和高端产品转型应对，但原材料价格波动和行业竞争加剧可能侵蚀利润。汽车业务则面临新能源渗透率逼近50%的颠覆性冲击，传统4S店模式承压，公司虽聚焦豪华品牌，但新车价格倒挂常态化，售后业务增长乏力，门店优化（关闭5家）显示转型阵痛。

**第二重风险来自资产剥离后的增长可持续性。** 2025年利润高增主要依赖出售华通医药的一次性收益（约1.51亿元），扣非净利润仅增长6.87%。剥离医药业务后，公司业务更加集中于竞争激烈的农资和汽车领域，缺乏新的利润增长极。同时，公司投资活动现金流净流出15.54亿元（同比扩大152%），主要用于理财和产能建设，若新项目（如开化绿色肥料项目）投产不及预期，将拖累整体回报率。
