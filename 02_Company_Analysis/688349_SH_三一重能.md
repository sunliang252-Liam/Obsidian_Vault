# 688349.SH 深度透视

## 因果逻辑链
- **[2024年国内陆上风机中标价格整体下降]** -> [2025年利润大幅下滑]: 2024年低价订单在2025年集中交付，导致风机及配件业务毛利率同比骤降6.56个百分点，直接侵蚀利润。
- **[新能源上网电价市场化改革]** -> [电站产品销售利润水平下降]: 改革重塑项目估值体系，导致电站产品销售业务毛利率同比下滑11.53个百分点，拖累整体盈利。
- **[国内风电新增装机容量同比增长49.9%]** -> [营业收入同比增长53.89%]: 行业高景气度驱动公司风机对外装机容量同比增长约61%，实现收入规模快速扩张。
- **[“自律公约”与招标规则优化]** -> [风机中标价格显著回升]: 行业竞争从“价格内卷”转向“价值竞争”，2025年新签订单价格回升，为未来盈利改善奠定基础。
- **[海外市场订单高速增长]** -> [海外收入同比增长1806.64%]: 公司全球化布局进入收获期，海外在手订单累计金额突破百亿元，成为第二增长曲线。
- **[海上风机订单实现突破]** -> [海风业务进入量产交付阶段]: 斩获石碑山、祥云岛等项目，标志公司正式进入海上风电市场，打开新的成长空间。
- **[全产业链一体化与核心部件自研自产]** -> [成本控制与产品竞争力优势]: 自研叶片、电机实现整机与零部件协同设计，有效降低制造成本，提升产品可靠性与市场竞争力。
- **[经营活动现金流净额为负]** -> [财务结构稳健性承压]: 报告期经营性现金流为-8.96亿元，主要因采购支出增加及电站项目通过融资回款未计入经营现金流，需关注资金链压力。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以根本扭转。** 2025年营收增长54%，但归母净利润却暴跌61%，主因是2024年低价订单的滞后交付。尽管2025年新签订单价格已回升，但转化为利润需要时间，2026年盈利修复的节奏和幅度存在不确定性。同时，新能源上网电价市场化改革对电站产品销售业务的冲击是结构性的，该业务毛利率已从36%降至25%，未来可能进一步承压。

**行业竞争格局与现金流压力是两大隐忧。** 风电行业“内卷式”竞争虽有所缓和，但市场集中度极高（前五名市占率73.4%），公司市占率仅11.24%，若不能持续提升技术实力和客户服务，存在份额下滑风险。此外，经营活动现金流连续两年为负，且2025年缺口扩大至-8.96亿元，尽管部分因电站项目融资方式导致，但应收账款周转率提升的同时，存货和采购支出激增，需警惕营运资金管理对财务稳健性的长期影响。
