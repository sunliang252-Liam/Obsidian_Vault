# 600161.SH 深度透视

## 因果逻辑链
- **[产品价格下行与信用政策放宽]** -> [净利润大幅下滑29.59%]: 营收微增2.26%的同时，营业成本因销量增加而上升26.75%，叠加产品售价下降、信用政策变化导致应收账款激增582.90%及减值准备增加，共同侵蚀利润。
- **[采浆量微增与产能扩张]** -> [营收增长但库存高企]: 采浆量仅增0.7%至2,801吨，而生产量增长22.78%，导致库存量飙升96.49%，反映需求增速不及供给释放。
- **[信用政策变化]** -> [经营现金流锐减58.68%]: 为应对市场压力给予渠道商更多信用支持，导致销售回款减少，同时利息收入因资金规模下降而减少。
- **[研发投入资本化率高]** -> [短期利润平滑，长期风险积聚]: 研发投入5.68亿元，资本化比例高达58.82%，大量研发支出未费用化，若项目失败将冲击未来利润。
- **[行业壁垒与央企背景]** -> [护城河稳固]: 国家自2001年起未批准新设血液制品企业，公司依托国药集团资源，拥有107家浆站和超5000吨设计产能，龙头地位难以撼动。
- **[产品结构单一与集采压力]** -> [毛利率全面下滑]: 人血白蛋白、静注人免疫球蛋白等核心产品毛利率分别下降11.73和8.94个百分点，省级集采持续压低中标价。

## 风险警告
**核心风险：利润失速与现金流恶化。** 2025年净利润同比下降近30%，而经营现金流更是暴跌58.68%，仅为净利润的31%。公司通过放宽信用政策刺激销售，导致应收账款从2.03亿飙升至13.86亿，坏账风险急剧放大。这种“以利润换收入、以现金流换市场”的策略不可持续，若终端回款持续恶化，公司将面临流动性压力。

**次要风险：供需失衡与库存积压。** 行业供应增速超过需求增速，公司库存量同比暴增96.49%。同时，省级集采常态化推进，核心产品价格持续承压，毛利率下行趋势明确。此外，公司研发投入资本化率过高（58.82%），若皮下注射人免疫球蛋白等重磅新品上市或销售不及预期，前期资本化的研发支出将面临减值风险，进一步冲击利润。
