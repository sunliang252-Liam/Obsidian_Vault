# 605162.SH 深度透视

## 因果逻辑链
- **[下游客户停产搬迁]** -> [蒸汽销量下降7.63%]: 化工园区印染企业外迁，导致公司核心产品蒸汽的销售量直接减少。
- **[煤热联动与主动让利]** -> [蒸汽价格下降11.76%]: 公司为应对下游需求疲软，采取低价策略，叠加煤价下行传导，导致蒸汽均价下滑。
- **[供热量下降与电力市场化]** -> [热电联产收入下降17.10%]: 全背压机组“以热定电”，供热量减少直接导致发电量下降；2025年起参与电力现货市场交易，容量电价未到位致电价承压。
- **[储能项目全年运行]** -> [储能电力收入增长52.59%]: 2024年7月投运的100MW/220MWh储能电站，2025年实现完整年度运营，收入显著提升。
- **[煤炭成本下降]** -> [营业成本降幅大于收入降幅]: 煤炭使用量减少及煤价下跌，使营业成本下降23.24%，高于收入降幅18.82%，毛利率提升4.16个百分点。
- **[可转债利息增加]** -> [财务费用增长76.89%]: 可转债计提利息增加及银行利息收入减少，导致财务费用大幅攀升，侵蚀利润。
- **[新项目投产在即]** -> [未来业绩反转预期]: 2号机组改造（2026年4月投产）及浦口供热管道（2026年3月完工）将显著增加供热能力，服务绍兴弗迪电池等新大用户，扭转供热量下降趋势。

## 风险警告
公司面临的核心风险在于**下游客户需求的不确定性**。报告期内，化工园区印染企业停产搬迁已导致蒸汽销量和收入双降，而公司业务高度集中于嵊州本地，区域经济波动或单一产业政策调整（如印染、纺织）将直接冲击经营业绩。尽管新用户（绍兴弗迪电池）即将投产，但新产能的消化和市场开拓仍需时间验证。

**原材料价格与电价政策风险**是利润波动的另一关键。煤炭成本占主营业务成本比重极大，尽管当前煤价下行利好，但若未来煤价反弹，而下游用户承受能力有限导致煤热联动机制传导不畅，将严重压缩毛利率。同时，电力现货市场交易已导致电价下降，若容量电价等补偿机制落地不及预期，公司电力业务盈利将持续承压。
