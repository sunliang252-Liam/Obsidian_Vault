- **[电梯后市场政策红利]** -> [更新改造订单暴增]: 超长期特别国债资金支持住宅老旧电梯更新，公司全年更新、改造订单超3500台，同比增幅超360%。
- **[“两网一战略”深化与央国企客户开拓]** -> [电梯整机逆势增长]: 在行业订单整体下滑背景下，公司成功中标中建四局、中交集团等央国企集采，电梯整机订单台量和发运台量实现逆势增长。
- **[国际化“渠道+直销+战略协同”]** -> [海外业务高速增长]: 海外订单台量同比增长56.24%，海外地区营收同比翻倍（+100.02%），成功开拓俄罗斯、墨西哥、东南亚等市场。
- **[精益管理与“四化建设”]** -> [费用率显著下降]: 管理费用同比下降20.92%，销售费用同比下降3.03%，通过基地管理车间化、财务管理中心化等措施实现“极致成本”。
- **[参股日立电梯的稳定贡献]** -> [利润基石]: 日立电梯签梯及发货台量均超12万台，在保电梯90万台，为公司贡献了稳定的投资收益，是利润的重要来源。
- **[数字化战略落地]** -> [新业务增长点]: 自主研发的广日物道平台、广日物语盒子等产品商业化，年度数智业务有效订单超5亿元，推动“制造+服务”转型。
- **[股权激励与股份回购]** -> [股东回报提升]: 2025年度合计每10股派现5.0元，并完成2亿元股份回购注销，现金分红比例达61.78%，积极回馈股东。

## 风险警告
**核心风险在于对单一客户日立电梯的过度依赖。** 公司营收中，向日立电梯及其下属公司出售商品和提供劳务的关联交易金额高达23.98亿元，占年度销售总额的33.09%。同时，公司长期股权投资中日立电梯的账面价值高达31.06亿元，占公司净资产的比例极高。日立电梯的经营波动、合作关系变化或分红政策调整，都将对广日股份的业绩和资产价值产生决定性影响。

**房地产下行周期与市场竞争加剧的风险不容忽视。** 虽然公司通过后市场业务和公建项目对冲了部分风险，但国内电梯市场需求整体放缓，价格竞争激烈。部分房地产客户仍面临流动性危机，导致公司应收账款回收承压。若宏观经济或房地产市场持续低迷，公司电梯主业增长将面临天花板，且坏账风险可能上升。
