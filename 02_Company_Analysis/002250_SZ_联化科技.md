# 002250.SZ 深度透视

## 因果逻辑链
- **[植保行业去库存周期结束]** -> [植保业务收入复苏]: 2023-2024年国际大客户去库存周期结束，2025年植保业务迎来需求回暖，但收入同比微降3.57%，主要因产品结构调整。
- **[功能化学品新能源业务放量]** -> [功能化学品收入暴增243%]: 前期布局的锂盐、电解液等新能源材料项目实现万吨级产能达产与爬坡，通过头部客户验证并获得批量订单，成为第三增长曲线。
- **[医药业务商业化项目驱动]** -> [医药收入增长26%，利润贡献显著]: 创新药注册中间体和API占比提升至三分之二以上，年内完成8个验证项目（含2个新药API），商业化阶段收入增长31%。
- **[植保业务成本优化与精益管理]** -> [植保毛利率提升8.83个百分点]: 成功实施20多个技改项目，优化10多个产品成本，叠加精益管理体系提升生产效率，在收入微降下实现毛利率大幅修复。
- **[功能化学品新能源业务初期高投入]** -> [功能化学品毛利率为-12.22%]: 新能源业务处于产能爬坡与市场导入期，材料、人工、能源成本同比大幅增长（材料成本增377%），规模效应尚未完全释放。
- **[海外基地建设与全球化布局]** -> [马来西亚基地一期推进，增强客户信心]: 马来西亚基地完成基础设施建设，7个原药产品完成登记样品制备，弥补公司原药业务政策短板，为植保业务带来新机遇。
- **[医药CRO业务协同赋能]** -> [医药前端管线储备丰富]: CRO平台向早期研发延伸，形成“从临床早期到商业化”的一体化漏斗形订单体系，临床阶段项目数量增至113个，为未来增长奠定基础。

## 风险警告
**核心风险在于功能化学品新能源业务的盈利爬坡不确定性。** 该业务收入暴增243%但毛利率为-12.22%，处于“增收不增利”阶段。产能利用率仅35.94%，远低于行业头部企业，且面临电解液行业产能结构性过剩与价格竞争。若后续客户导入不及预期或产品价格持续承压，该板块可能持续拖累整体盈利，成为公司从“植保复苏”到“全面增长”的关键瓶颈。

**第二大风险是客户集中度与地缘供应链重构压力。** 前五大客户销售占比高达58.89%，植保业务深度绑定全球前五大农化巨头。在全球贸易摩擦与供应链“去风险化”趋势下，客户要求多国注册、多地生产的压力持续加大。公司马来西亚基地尚在建设，海外产能释放节奏若慢于客户需求转移，可能导致订单流失。同时，英国基地运营成本较高，汇率波动（出口占64%）也对利润构成持续影响。
