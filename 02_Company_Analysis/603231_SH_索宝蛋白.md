# 603231.SH 深度透视

## 因果逻辑链
- **[原材料成本下降]** -> [毛利率大幅提升]: 非转基因大豆采购成本下降，直接推动主营业务毛利率同比增加4.72个百分点，成为利润暴增的核心引擎。
- **[吉林民德项目投产]** -> [非转基因大豆油产销量激增]: 20万吨全产业链项目投产，带动大豆油产量增长43.41%、销量增长20.61%，但低毛利属性拉低了整体盈利弹性。
- **[高端制造与能源优化]** -> [降本增效成果显著]: 煤粉炉智能化改造、光伏项目及节能改造落地，大幅降低蒸汽和能源成本，直接增厚利润。
- **[直销模式增长]** -> [收入结构优化]: 直销收入同比增长21.36%，远超经销模式，且毛利率更高，推动整体盈利水平上行。
- **[境外销售毛利率提升]** -> [海外市场贡献增强]: 境外销售毛利率同比提升7.98个百分点至24.68%，显著高于境内，成为利润增长的重要增量。
- **[组织化蛋白量价齐升]** -> [高附加值产品放量]: 组织化蛋白销量增长23.73%，毛利率提升9.61个百分点至35.33%，成为利润结构中最优质的板块。
- **[现金流大幅改善]** -> [经营质量提升]: 经营活动现金流净额同比增长110.65%，远超净利润增速，显示收入质量与回款能力显著增强。

## 风险警告
**核心风险在于原材料价格波动与产能消化。** 公司利润暴增的核心驱动力是非转基因大豆采购成本下降，这一外部红利具有不可持续性。一旦全球大豆供需格局逆转，成本上升将直接侵蚀当前的高毛利率。同时，吉林民德20万吨项目投产后，大豆油产量激增，但该产品毛利率仅10.71%，且库存量同比大增29.38%，若下游需求无法同步消化，将面临存货跌价与产能利用率不足的双重压力。

**募投项目延期与变更暴露战略执行风险。** “3万吨大豆组织拉丝蛋白生产线建设项目”已延期至2026年底，“5000吨大豆颗粒蛋白生产线项目”被取消并变更为新项目。这反映出公司在面对市场变化时，前期产能规划存在偏差，新项目的落地时间与收益兑现仍存不确定性。此外，公司研发投入仅占营收0.46%，在行业向高端化、功能化转型的背景下，技术储备可能成为长期发展的瓶颈。
