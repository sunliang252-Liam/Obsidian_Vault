## 因果逻辑链
- **[中美贸易摩擦加剧]** -> [营收下降15.96%]: 关税政策变动导致部分境外客户订单流失，出口业务收入同比下降24.49%。
- **[出口收入占比超50%]** -> [净利润下降42.01%]: 境外业务萎缩叠加人民币升值（汇兑收益减少），利润降幅远超营收降幅。
- **[募投项目结项转固]** -> [固定资产激增1131.67%]: “高端越野改装部件生产项目”及“研发中心建设项目”完工，在建工程转入固定资产，折旧费用增加。
- **[客户集中度高]** -> [业绩波动风险放大]: 前五大客户销售占比73.49%，其中第一大客户占42.78%，单一客户订单变动即可显著影响公司整体业绩。
- **[研发投入持续加大]** -> [期间费用率上升]: 研发费用同比增长8.75%，管理费用增长18.36%，在收入下滑背景下侵蚀利润空间。
- **[国内前装市场拓展]** -> [境内收入逆势增长5.35%]: 与国内大型主机厂战略合作深化，电动踏板供货份额提升，部分对冲了海外市场的下滑。
- **[机器人驱动关节研发]** -> [开辟第二增长曲线]: 与外部机构合作研发，已完成定性样机，计划2026年批量试制，旨在替代高成本外购件并拓展新赛道。

## 风险警告
**核心风险在于对单一海外市场和头部客户的过度依赖。** 公司出口收入占比超50%，且前五大客户集中度高达73.49%。2025年中美贸易摩擦已导致营收和利润双降，若关税壁垒进一步升级或核心客户流失，业绩将面临更大冲击。公司虽在拓展国内市场，但短期内难以完全对冲海外风险。

**募投项目转固带来的资产折旧压力是隐形成本。** 固定资产从1776万激增至2.19亿元，未来每年将产生大量折旧费用，在收入增长乏力的情况下，将持续侵蚀净利润。同时，公司已开始使用短期借款（100万元），表明现金流管理压力有所增加，需关注后续财务杠杆的变动。
