# 300698.SZ 深度透视

## 因果逻辑链
- **[车联网出海业务高增]** -> [营收增长29.24%]: 海外车联网连接量突破120万辆，带动车联网业务收入同比+49.33%，成为核心增长引擎。
- **[L4无人驾驶高阶网联方案商业化]** -> [开拓新增长极]: 针对Robotaxi/Robovan网联痛点推出5G双卡、链路聚合方案，已获百度阿波罗、哈啰等头部客户订单，实现商业化落地。
- **[车联网业务毛利率下降9.45pct]** -> [归母净利润增速(13.88%)远低于营收增速]: 海外业务扩张导致服务成本(制造费用)同比+91.49%，侵蚀利润空间。
- **[传统基柱业务向AIDC/电网转型]** -> [开辟新收入来源]: 一二次融合环网箱中标国家电网8127万元，微模块数据中心切入金融/运营商客户，对冲传统通信设备增长放缓。
- **[经营活动现金流大幅改善]** -> [现金流净额同比+781.76%]: 车联网板块回款改善，经营现金流由负转正至5641万元，财务质量显著提升。
- **[“自动驾驶云服务”项目暂缓]** -> [投资效益未达预期]: 一期投资5342万元，因市场需求分散、运维成本高导致亏损，公司决定暂缓后续投资，反映新业务探索风险。
- **[全球eSIM技术领先]** -> [构建出海竞争壁垒]: 成为全球率先实现SGP.02/22/32全系列eSIM量产交付的第三方车联网服务商，支撑“揽海”ONE SIM方案差异化优势。

## 风险警告
**核心风险在于车联网业务“增收不增利”的持续性。** 2025年车联网收入增长49.33%，但毛利率却下降9.45个百分点，主要因海外扩张导致服务成本（制造费用）激增91.49%。若竞争加剧或运营商成本持续上升，利润增速可能长期落后于收入增速，侵蚀股东回报。

**新业务投入与回报的不确定性高。** 公司暂缓“自动驾驶云服务”项目（一期投入5342万元），表明L4无人驾驶商业化仍处于早期，需求分散且盈利模式未成熟。同时，应收账款占总资产比例高达49.11%，若海外客户回款周期延长或出现坏账，将对现金流和资产质量构成压力。
