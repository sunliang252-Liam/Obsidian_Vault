# 300784.SZ 深度透视

## 因果逻辑链
- **[大客户高度集中]** -> [营收微增4.01%，但净利润下滑18.42%]: 第一大客户罗技集团贡献44.28%营收，客户议价能力极强，导致公司增收不增利，毛利率承压。
- **[精密注塑模具收入暴增168%]** -> [营收结构优化]: 模具业务高附加值，其收入占比从3.68%跃升至9.50%，但毛利率同比下降15.72%，显示竞争加剧或成本上升。
- **[制造费用上涨20.09%]** -> [利润侵蚀]: 募投项目转固导致厂房及设备折旧大幅增加，直接压缩利润空间，是净利润下滑的核心原因之一。
- **[国际销售增长15.49%]** -> [海外布局见效]: 越南基地量产，有效支撑海外客户交付，外销收入占比提升至28.72%，对冲了国内消费电子类产品2.07%的下滑。
- **[研发投入维持高位]** -> [技术壁垒构建]: 研发费用占营收5.59%，聚焦PCR再生塑料、光敏变色材料等，旨在通过技术差异化巩固“专精特新”小巨人地位。
- **[经营活动现金流净额骤降35.37%]** -> [盈利质量恶化]: 净利润减少叠加经营性资金安排（如增加备库），导致现金流与利润背离，反映运营效率下降。
- **[消费电子类产品收入下滑2.07%]** -> [核心业务承压]: 作为营收占比72.73%的基石业务，其下滑直接拖累整体增长，显示下游需求或份额出现波动。
- **[募投项目产能释放缓慢]** -> [短期业绩拖累]: 多个募投项目尚在建设或产能爬坡期，新增折旧已产生，但对应收益尚未完全体现，形成“投产即亏损”的阶段性压力。

## 风险警告
**核心风险在于对单一超级客户罗技集团的深度依赖（营收占比44.28%），以及由此带来的议价能力削弱和业绩波动风险。** 公司净利润连续两年下滑（2024年-13.1%，2025年-18.42%），而营收增速仅4.01%，已出现明显的“增收不增利”特征。同时，募投项目转固带来的折旧压力正在侵蚀利润，而新产能的效益释放存在不确定性，若下游需求或客户订单不及预期，将面临资产减值与利润持续承压的双重打击。

**另一重大风险是盈利质量的下滑。** 经营活动现金流净额同比骤降35.37%，与净利润的背离趋势加剧，表明公司回款能力或运营效率出现问题。此外，公司外销收入占比近30%，主要面向北美及东南亚，面临潜在的贸易政策风险。原材料（ABS塑料粒子等）价格波动若无法有效传导，将进一步压缩本已微薄的利润空间。公司虽在布局PCR再生塑料等新方向，但短期难以对冲核心业务的结构性风险。
