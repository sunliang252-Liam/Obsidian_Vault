# 300224.SZ 深度透视

## 因果逻辑链
- **[新能源汽车需求扩张]** -> [销量连续八年增长]: 公司产品搭载节能和新能源汽车电机超800万台套，同比增长超40%，直接拉动钕铁硼永磁材料销量同比增长21%。
- **[海外业务回暖]** -> [出口发货量显著增长]: 出口许可稳定获批及市场对无重稀土磁体接受度提高，老客户补单与新客户渗透效果显现，推动国外收入同比增长42.59%。
- **[“两减一增”精益运营]** -> [盈利质量提升]: 压降库存、缩短生产周期、提升人均效能，在营收增长27%的同时，归母净利润同比大增233%，扣非净利润增长361%。
- **[可转债转股与赎回]** -> [财务费用大幅下降]: 可转债转股后利息支出减少，叠加汇兑收益增加，财务费用同比减少64%，显著增厚利润。
- **[稀土资源平衡战略]** -> [成本优势与供应链安全]: 通过减少重稀土使用、扩大高丰度超轻稀土应用，在稀土价格波动中保持成本竞争力，无重稀土磁体产量同比增长137%。
- **[人形机器人等新兴赛道布局]** -> [未来增长潜力]: 技术体系高度匹配空心杯电机、无框力矩电机需求，已向下游多家客户小批量供货，抢占新兴市场先机。
- **[客户结构优化]** -> [收入质量提升]: 聚焦世界500强、各细分市场头部企业，实现全球汽车电气化核心品牌TOP5全覆盖，增强客户粘性与盈利稳定性。

## 风险警告
**1. 原材料价格波动与政策风险：** 公司核心原材料为稀土金属，2025年受国内开采总量管控、出口管制政策及海外供给扰动影响，价格震荡上行。若未来稀土价格剧烈波动，而公司成本联动定价机制未能完全传导，将直接冲击毛利率与资金周转。此外，出口管制政策的持续收紧可能对海外业务拓展构成不确定性。

**2. 现金流与应收账款压力：** 尽管净利润大幅增长，但经营活动现金流净额同比下降62.92%，主要因应收账款及票据结算规模增加。报告期末应收账款余额高达16.89亿元，占营收比重约24%。若下游客户（尤其是新能源汽车领域）经营状况恶化，存在坏账风险，将侵蚀利润并影响资金使用效率。

**3. 行业竞争加剧与产能过剩：** 新能源汽车市场从高速增长转向结构性竞争，人形机器人等新兴赛道尚处放量初期，行业产能扩张与集中化趋势明显。若公司不能持续保持技术领先和成本优势，可能面临市场份额波动、产品价格承压的风险。同时，南通基地原规划的6000吨新增产能已暂停，需关注未来市场消化能力。
