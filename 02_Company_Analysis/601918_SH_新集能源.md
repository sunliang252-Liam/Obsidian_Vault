# 601918.SH 深度透视

## 因果逻辑链
- **[煤炭价格中枢下移]** -> [营收下降3.51%]: 2025年动力煤均价同比下跌约18%，尽管公司以量补价（商品煤产量增3.69%），但煤炭采掘收入仍下降6.68%。
- **[煤电联营对冲煤价下行]** -> [电力收入增长1.39%]: 利辛电厂发电量增10.40%，利用小时数达4284小时，部分抵消了煤炭业务收入下滑的影响。
- **[板集电厂二期投产]** -> [发电成本激增11.87%]: 新机组投运导致折旧费增55.38%、修理费增51.85%，侵蚀电力板块毛利率，使其下降8.31个百分点。
- **[新建电厂资本开支激增]** -> [投资活动净流出72.17亿元]: 上饶、滁州、六安三大电厂同时建设，在建工程同比增244.11%，导致公司资产负债率升至63.53%。
- **[安全费用与人工成本刚性]** -> [煤炭成本降幅有限]: 尽管修理费因外修转自修下降58.24%，但安全费用增10.34%，人工成本占比近40%，煤炭采掘成本仅降1.99%。
- **[关联交易依赖度高]** -> [经营独立性风险]: 前五大客户销售额占78.81%，其中向中煤集团及关联方销售占20.43%；向中煤系采购占采购总额12.68%。
- **[控股股东同业竞争承诺即将到期]** -> [潜在资产整合窗口]: 中国中煤关于避免同业竞争的承诺将于2026年12月20日到期，可能触发资产重组或业务调整。

## 风险警告
**核心风险：煤电双杀与资本开支高峰叠加。** 2025年公司净利润同比降10.73%，主因是煤炭价格中枢下移（动力煤均价同比跌18%）与电力板块毛利率骤降8.31个百分点（受新电厂投产成本激增拖累）同时发生。更严峻的是，公司正处于历史最大资本开支期——上饶、滁州、六安三大电厂同步建设，投资活动净流出72.17亿元，导致资产负债率攀升至63.53%，财务费用虽因利率下降同比减少6.99%，但绝对额仍高达4.68亿元。在煤价承压、电价市场化竞争加剧的背景下，巨额在建工程转固后的折旧压力将长期压制利润。

**结构性风险：关联交易与同业竞争悬而未决。** 公司对控股股东中国中煤的关联交易依赖度极高（销售占20.43%、采购占12.68%），且控股股东关于避免同业竞争的承诺将于2026年12月到期。若届时无法完成资产整合，公司将长期面临与中煤旗下其他煤炭资产的同业竞争问题，可能损害中小股东利益。此外，公司煤炭业务毛利率高达60.19%，但电力业务毛利率仅11.28%，煤电一体化虽能对冲部分风险，但电力板块的盈利弹性远弱于煤炭，整体抗周期能力被高估。
