# 920367.BJ 深度透视

## 因果逻辑链
- **[原料药批文制改备案制，竞争加剧]** -> [原料药收入下降22.80%]: 新竞争对手涌入，葡萄糖酸盐系列下游需求减少，导致原料药量价齐跌。
- **[政府补助大幅减少]** -> [净利润下降34.88%]: 其他收益从1192万骤降至279万，直接削减利润近913万。
- **[研发费用激增81.46%]** -> [短期利润承压]: 为提升产品竞争力，公司加大一致性评价和新药研发投入，研发费用从880万增至1596万。
- **[VC咀嚼片需求持续增长]** -> [制剂药收入逆势增长31.22%]: 下游客户对VC咀嚼片需求旺盛，成为公司唯一增长引擎。
- **[在建工程大幅增加80.47%]** -> [投资活动现金流净流出扩大]: 中成药制剂保健品生产项目一期、二期持续投入，在建工程从8790万增至1.59亿。
- **[应收账款增长37.87%]** -> [信用减值损失扩大1341.82%]: 客户赊销增加，导致坏账准备计提大幅上升，侵蚀利润。
- **[控股子公司亏损加剧]** -> [少数股东损益减少465.47%]: 子公司众源药业等经营亏损，拖累合并报表净利润。
- **[募投项目延期]** -> [产能释放节奏放缓]: 中成药制剂保健品生产项目一期、新增口服固体制剂片剂车间项目均延期至2027年2月。

## 风险警告
**核心风险：核心业务（原料药）遭遇结构性衰退。** 公司最大收入来源（原料药占比41.6%）因批文制改备案制导致竞争格局恶化，叠加下游需求萎缩，收入与毛利率双降。这一趋势并非短期波动，而是行业竞争加剧的长期结果。公司试图通过加大研发（费用激增81%）和建设新产能（在建工程增80%）来转型，但短期内研发投入和资本开支将严重侵蚀现金流和利润，转型效果尚需时日验证。

**财务风险：盈利质量恶化，现金流吃紧。** 净利润同比下降47%，扣非净利润仅992万，真实盈利能力大幅下滑。政府补助锐减后，公司对非经常性损益的依赖度降低，但自身造血能力不足。同时，应收账款激增导致信用减值损失扩大，经营活动现金流净额同比下降54%，而投资活动现金流出却同比扩大553%，资金链面临较大压力。募投项目延期也暗示了产能建设可能不及预期。
