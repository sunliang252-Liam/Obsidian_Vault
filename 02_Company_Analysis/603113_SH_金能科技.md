# 603113.SH 深度透视

## 因果逻辑链
- **[循环经济模式]** -> [成本优势]: 独特的“丙烷脱氢-炭黑-蒸汽”等闭路循环，将副产品转化为能源和原料，年增效益超3.5亿元，构筑了同行难以复制的成本护城河。
- **[可转债到期兑付]** -> [净利润扭亏]: 2.08亿元可转债利息冲减财务费用计入非经常性损益，是归母净利润从-0.58亿扭转为+0.22亿的核心原因，掩盖了主业亏损的实质。
- **[PP出口爆发]** -> [营收增长]: 全年PP出口49.6万吨，同比增长约29倍，占中国出口总量16%，成功消化国内过剩产能，成为收入增长的主要驱动力。
- **[原材料价格下行]** -> [经营现金流改善]: 丙烷、煤炭等主要原料采购价格同比下降，购买商品支付的现金减少，使经营活动现金流净额同比大增152.86%至5.48亿元。
- **[烯烃产能释放]** -> [规模效应]: 青岛基地180万吨PDH和135万吨PP产能满负荷运行，烯烃产品产销量同比增长超37%，摊薄固定成本，但行业过剩导致毛利率仅-0.07%。
- **[焦化行业低迷]** -> [煤焦业务收缩]: 下游钢铁需求疲软，焦炭价格承压，煤焦产品收入同比下降22.3%，尽管成本降幅更大，但整体业务规模显著收缩。
- **[高额研发投入]** -> [产品高端化]: 研发投入6.8亿元（占营收4.03%），成功开发高透明瓶盖料、抗冲共聚PP等新牌号，旨在从同质化竞争中突围，提升产品附加值。

## 风险警告
**核心风险在于主业盈利能力堪忧，利润依赖非经常性损益。** 公司2025年扣非净利润为-2.64亿元，连续两年为负，表明在行业产能过剩的背景下，其循环经济成本优势尚不足以覆盖市场下行压力。净利润扭亏完全依赖可转债到期兑付带来的2.08亿元非经常性收益，这种“会计利润”不具备可持续性。若剔除该因素，公司实际经营已陷入亏损，且亏损幅度同比扩大。

**资产质量与现金流存在隐忧。** 公司总资产188亿元，但净资产已降至80.4亿元，资产负债率高达57.3%。短期借款激增60%至64亿元，而货币资金中受限资金（如票据保证金）占比高，实际可动用现金有限。同时，存货和应收账款规模庞大，且固定资产存在减值迹象（已计提3.19亿元减值准备），资产变现能力与偿债压力之间存在显著矛盾。
