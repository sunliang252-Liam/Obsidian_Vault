# 000955.SZ 深度透视

## 因果逻辑链
- **[非织造主业销量增长与成本控制]** -> [扣非净利润大幅减亏59.81%]: 纺织业销量增长17.33%，同时通过降本增效、优化工艺，使毛利率提升1.25个百分点，带动核心业务亏损收窄。
- **[医药健康业务主动收缩]** -> [营收下降48.64%]: 公司战略性调整业务结构，压缩低效医药批发分销规模，导致该板块收入腰斩，但成本同步下降46.38%。
- **[非经常性损益贡献]** -> [归母净利润扭亏为盈]: 政府补助、金融资产公允价值变动及应收款项减值转回等非经常性收益合计940万元，覆盖了扣非后-869万元的亏损，实现净利润71.8万元。
- **[产能利用率提升]** -> [固定成本摊薄]: 产能利用率从42.19%提升至49.85%，单位产品分摊的固定成本下降，是毛利率改善的关键驱动因素之一。
- **[贸易业务稳定]** -> [营收与毛利基本持平]: 天然橡胶和油品贸易业务收入11.39亿元，毛利率6.10%，为公司提供了稳定的现金流和收入规模支撑。
- **[子公司经营分化]** -> [少数股东损益亏损]: 核心子公司海南欣龙无纺盈利25.7万元，但湖南欣龙亏损418.9万元、广东聚元堂亏损422万元，拖累整体业绩，导致少数股东承担亏损191万元。
- **[研发聚焦迭代创新]** -> [差异化产品竞争力]: 研发投入1793万元，重点开发低掉屑木浆复合水刺、高吸收耐洗型擦拭材料等差异化产品，巩固高端市场地位，是维持毛利率高于行业平均水平（13.9%）的基础。

## 风险警告
**主业盈利根基脆弱，依赖非经常性损益“续命”。** 公司扣非净利润已连续三年为负（-4368万、-2161万、-869万），2025年虽大幅减亏，但归母净利润扭亏完全依赖940万非经常性收益。核心非织造业务毛利率仅9.96%，远低于行业平均13.9%，且熔纺无纺布毛利率低至1.87%，几乎无利可图。若政府补助、金融资产收益等非经常性项目减少，公司将立即重回亏损。

**行业竞争加剧与关税政策双重挤压。** 非织造布行业产能过剩、内卷严重，2025年行业营收和利润总额分别同比下降1.7%和7.1%。美国“对等关税”政策持续冲击出口业务，公司虽积极拓展东盟、欧洲市场，但短期内难以完全对冲对美出口依赖。同时，原材料价格波动和下游需求疲软，使公司面临“增收不增利”的困境，持续经营能力存在不确定性。
