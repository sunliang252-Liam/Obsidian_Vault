# 000739.SZ 深度透视

## 因果逻辑链
- **[原料药中间体业务量价齐跌]** -> [整体营收与利润双降]: 原料药中间体收入同比下降28.74%，毛利率下滑1.44个百分点，是公司整体营收下降18.62%、扣非净利润下降21.86%的核心拖累。
- **[CDMO业务逆势高增长]** -> [业务结构优化与利润缓冲]: CDMO收入同比增长16.66%，毛利率提升4.18个百分点至45.24%，成为唯一正增长且盈利最强的板块，有效对冲了原料药业务的衰退。
- **[“漏斗”项目模型持续扩容]** -> [CDMO未来收入确定性增强]: 进行中项目数同比增长32%至1311个，其中研发阶段项目增长42%，商业化在手订单超60亿元，为未来2-3年CDMO业务持续增长提供坚实储备。
- **[研发投入持续加码与资本化]** -> [长期竞争力与短期利润压力]: 研发投入同比增长2.79%至6.59亿元，且首次出现研发投入资本化（0.48亿元），表明公司正加大创新药和高端制剂投入，但短期对利润形成一定侵蚀。
- **[“四化”建设与卓越运营]** -> [成本控制与效率提升]: 通过连续化、自动化、数字化、智能化改造及内部订单模式，在原料药收入大幅下滑时，整体营业成本下降21.31%，有效减缓了利润下滑幅度。
- **[深度国际化与地缘政治风险]** -> [海外业务拓展的不确定性]: 公司在美国、欧洲、日本等地设立BD办公室，海外收入占比44.32%，但国际政治局势复杂化可能对海外业务拓展和供应链稳定性构成潜在威胁。

## 风险警告
**核心风险在于原料药业务的持续低迷。** 公司近七成收入来自原料药中间体，该业务受行业周期、需求疲软和激烈竞争影响，2025年收入与毛利均大幅下滑。若该业务无法在短期内筑底回升，将继续严重拖累公司整体盈利能力和现金流表现，这是当前最直接、最重大的业绩风险。

**其次，CDMO业务的增长能否持续对冲原料药下滑存在不确定性。** 虽然CDMO业务增长强劲，但其收入体量仅为原料药的三分之一。全球生物医药融资环境、创新药研发成功率以及客户项目推进速度，都可能影响CDMO业务的增长斜率。若CDMO增速放缓，而原料药业务未能复苏，公司将面临业绩双杀的局面。此外，汇率波动和国际化进程中的地缘政治风险，也是不可忽视的外部变量。
