# 002985.SZ 深度透视

## 因果逻辑链
- **[十四五延迟订单集中释放]** -> [营收增长70.66%]: 下游客户人事调整落地，审批效率恢复，前期积压的军品订单在2025年集中交付，推动收入规模显著回升。
- **[军品耗材属性+训练强度提升]** -> [业绩弹性大]: 刹车盘、机轮等核心产品属于消耗件，随着实战化训练强度增加，替换和维修周期缩短，为公司带来稳定的存量维修保障收入。
- **[配套层级提升至系统级]** -> [单机价值量跃升]: 公司从刹车盘、机轮等零部件供应商，向起落架着陆全系统供应商跨越，显著提升了在单个军机型号中的配套价值和议价能力。
- **[子公司京瀚禹检测业务]** -> [贡献稳定利润]: 京瀚禹作为军工电子元器件检测平台，受益于武器装备信息化和国产化趋势，2025年实现营收2.52亿元，净利润0.81亿元，成为公司重要的利润来源。
- **[降本增效与信用减值减少]** -> [净利润暴增1138%]: 公司加强内部成本控制，同时加大应收账款回款力度，信用减值损失较2024年大幅减少，叠加收入增长，利润弹性充分释放。
- **[民航市场国产替代]** -> [打开第二增长曲线]: 公司积极布局C919等国产大飞机起落架着陆系统，以及民航刹车盘替换市场，旨在打破国外巨头垄断，开辟新的增长空间。

## 风险警告
**核心风险在于军品收入的高波动性与巨额应收账款的信用风险。** 公司2025年业绩暴增主要源于十四五延迟订单的集中释放，这种“补课式”增长不具备可持续性。军品采购受军方计划、审价及人事变动影响极大，订单节奏难以预测，未来收入可能再次出现剧烈波动。同时，公司应收账款高达14.15亿元，占总资产36.68%，且账龄较长，虽然2025年减值损失有所减少，但若下游客户付款周期进一步拉长，将严重侵蚀公司利润和现金流。

**第二重风险来自商誉减值和业务多元化的整合挑战。** 公司账面商誉高达1.85亿元，主要来自收购京瀚禹。虽然京瀚禹目前表现稳健，但检测行业竞争加剧，若未来业绩不达预期，将面临商誉减值风险。此外，公司向起落架系统、民航及高铁等新领域扩张，研发投入持续增加（2025年增长32.84%），新业务从研发到批产周期长、不确定性高，可能持续消耗公司资源，拖累整体盈利水平。
