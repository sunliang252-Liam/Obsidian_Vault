# 605319.SH 深度透视

## 因果逻辑链
- **[新能源汽车客户订单放量]** -> [冲压零部件业务收入增长27.30%]: 深度绑定特斯拉、理想、小米等新能源车企，订单规模扩大直接拉动核心业务收入。
- **[原材料价格低位运行 + 规模效应]** -> [毛利率提升2.54个百分点]: 钢材等成本端压力减轻，叠加订单增长摊薄固定费用，双重因素推动盈利能力改善。
- **[上汽乘用车郑州/宁德工厂订单增加]** -> [分拼总成加工业务收入增长26.38%]: 作为核心客户的上汽乘用车产量提升，直接带动公司该业务板块增长。
- **[精密电镀技术壁垒 + 混动/增程车需求]** -> [无锡开祥业绩承诺超额完成22.60%]: 子公司作为联合电子/博世国内唯一合格供应商，受益于混动车型对高压电喷系统的持续需求。
- **[可转债发行募资5.2亿元]** -> [廊坊生产基地建设加速]: 募集资金用于廊坊项目，旨在提升华北区域属地化配套能力，支撑未来新能源客户订单。
- **[客户集中度高]** -> [前五大客户销售额占比76.66%]: 业务高度依赖上汽系及头部新能源车企，单一客户订单波动将对公司业绩产生重大影响。
- **[模具业务收入下滑38.61%]** -> [拖累整体收入增速]: 模具业务周期性波动明显，2025年收入大幅下降，部分抵消了冲压和分拼业务的增长。

## 风险警告
**客户高度集中与行业淘汰赛风险。** 公司前五大客户销售额占比高达76.66%，深度绑定上汽大众、上汽乘用车、特斯拉、理想等少数几家整车厂。当前汽车行业竞争激烈，淘汰赛加速，若核心客户市场份额下滑或订单转移，将对公司营收造成巨大冲击。公司对单一客户的依赖度极高，议价能力受限。

**原材料价格波动与毛利率侵蚀风险。** 钢材等原材料成本占主营业务成本近60%，是影响毛利率的最核心变量。尽管2025年受益于原材料价格低位，但全球地缘政治风险与通胀压力仍存，原材料价格一旦反弹，将直接压缩公司利润空间。公司对上游成本的控制能力有限，毛利率存在显著波动风险。
