# 000995.SZ 深度透视

## 因果逻辑链
- **[高端产品放量]** -> [营收结构优化]: 高端白酒收入同比增长31.76%，占比升至37%，拉动整体毛利率提升0.93个百分点，弥补了中低端产品下滑。
- **[省外市场扩张]** -> [区域结构改善]: 省外收入同比增长31.48%，占比从24.96%提升至33.33%，缓解了省内市场下滑12.51%的压力。
- **[品牌重塑与新品储备]** -> [库存激增]: 白酒成品库存同比暴增103.40%，系为奔马系列新品上市储备货源，但若动销不及预期，将带来减值风险。
- **[债务重组收益消失]** -> [净利润骤降]: 2024年因债务重组确认2100万非经常性收益，2025年该项收益降至68万，导致归母净利润同比下滑49.02%。
- **[新增借款与还债]** -> [现金流波动]: 新增5000万银行借款，同时偿还等额旧债，筹资活动现金净流出1113万，现金净增加额同比减少49.09%。
- **[计提资产减值]** -> [利润侵蚀]: 因葡萄原酒账面价值低于可变现净值，计提存货跌价准备453万元，占利润总额的28.21%，持续侵蚀主业利润。
- **[深耕根据地市场]** -> [省内根基稳固]: 武威、兰州核心市场通过本土化品牌宣传和渠道治理，构筑消费者心智护城河，省内毛利率同比提升0.99%。

## 风险警告
**核心风险在于“增收不增利”与“库存堰塞湖”。** 公司2025年扣非净利润仅1396万元，同比微增31.51%，但归母净利润却因非经常性收益锐减而腰斩，显示主业盈利能力依然脆弱。更严峻的是，白酒成品库存同比飙升103.40%，葡萄酒成品库存也大增55.78%，均为新品备货所致。若新品“奔马系列”在省外市场推广不及预期，巨量库存将直接转化为资产减值损失，进一步拖累本已微薄的利润。

**第二重风险来自财务结构的脆弱性。** 公司资产负债率高达67.3%，短期借款与长期借款并存，利息费用高达682万元，远超扣非净利润的一半。同时，公司对部分经销商放宽了账期，应收账款同比暴增231.6%，从271万升至899万。在行业缩量竞争、头部酒企挤压的背景下，这种以“赊销换增长”的策略，可能埋下坏账风险，并加剧现金流压力。
