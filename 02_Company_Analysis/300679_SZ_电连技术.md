# 300679.SZ 深度透视

## 因果逻辑链
- **[汽车连接器业务高速增长]** -> [营收增长15.99%]: 汽车连接器营收同比+40.70%，成为最大收入来源（38.02%），驱动整体营收突破54亿元。
- **[海外客户拓展与软板放量]** -> [境外收入+51.87%]: 海外头部汽车Tier1客户突破及软板业务（+30.46%）销量提升，拉动境外收入占比升至19.29%。
- **[FTDI股权投资暴雷]** -> [净利润暴跌56.68%]: 因英国政府强制出售FTDI股权，计提长期股权投资减值2.43亿元，导致归母净利润从6.22亿骤降至2.70亿。
- **[产品降价与成本上升]** -> [毛利率下降3.70个百分点]: 部分产品降价、原材料涨价及新增产能折旧增加，叠加低毛利产品占比提升，综合毛利率降至29.95%。
- **[消费电子业务承压]** -> [收入同比-4.83%]: 全球智能手机弱复苏，国内补贴边际效应递减，以手机为代表的消费电子连接器收入下滑至18.59亿元。
- **[研发持续高投入]** -> [研发费用率7.83%]: 研发投入4.23亿元，聚焦5G毫米波、高速连接器及车载以太网，虽侵蚀短期利润但为长期技术卡位。
- **[经营现金流健康]** -> [现金流+39.59%]: 经营活动现金流净额7.13亿元，显著高于净利润，显示主营业务造血能力强劲，利润下滑主因非经常性损失。

## 风险警告
**核心风险：FTDI投资暴雷的连锁反应。** 公司对东莞飞特（间接持有FTDI 80.2%股权）的2.43亿元减值计提，直接吞噬全年利润。英国政府强制出售令存在重大不确定性，若最终出售价格低于账面价值，或面临进一步投资损失。该事件暴露了公司海外并购的地缘政治风险管控短板，且可能影响后续资本运作与市场信心。

**经营风险：毛利率持续承压与行业竞争加剧。** 汽车连接器虽放量但毛利率同比下降3.96%，消费电子毛利率更是下滑6.13%，反映行业价格战激烈。原材料价格波动、新增产能爬坡期的折旧摊销，以及低毛利产品（如软板）占比提升，将持续压制盈利水平。若5G毫米波商业化不及预期，前期巨额研发投入将面临回报风险。
