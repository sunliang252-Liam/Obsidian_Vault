# 688197.SH 深度透视

## 因果逻辑链
- **[核心管线进入NDA审评阶段]** -> [亏损收窄]: SY-707与SY-5007两款核心产品NDA获受理并推进审评，叠加政府补助6,075.54万元，使2025年净亏损同比收窄39.2%至1.29亿元。
- **[严控研发费用与运营成本]** -> [现金流改善]: 研发及管理费用合计同比下降8.16%，经营活动现金流净流出同比减少19.8%至1.58亿元，在手现金7.03亿元，资产负债率仅14.04%。
- **[合作研发里程碑收入增加]** -> [营收增长119.88%]: 与正大天晴合作项目达成里程碑，确认收入866.76万元，但绝对值仍极低，无法覆盖研发投入。
- **[SY-3505完成两项注册性试验入组]** -> [管线价值提升]: 作为国产进度最快的第三代ALK抑制剂，完成经治患者关键Ⅱ期及初治患者Ⅲ期入组，有望成为覆盖一线至多线治疗的重磅品种。
- **[SY-5007关键Ⅱ期数据优异]** -> [NDA获受理]: 初治患者ORR达89.3%，经治患者ORR达81.3%，数据在ESMO公布，支撑NDA于2025年10月获受理。
- **[SY-707完成现场核查与发补]** -> [预计2026年获批]: 作为公司首款商业化产品，完成CDE全部核查与资料补充，预计2026年内获批，是公司从研发向商业化转型的关键节点。
- **[启动H股上市筹划]** -> [拓宽融资渠道]: 2025年12月公告筹划H股上市，旨在为后续研发及产业化基地建设储备资金，但存在较大不确定性。

## 风险警告
**核心风险在于“零收入”状态下的商业化兑现与持续烧钱压力。** 公司至今无自研产品上市销售，收入仅靠合作研发的零星里程碑款，2025年营收仅867万元，而研发费用高达1.97亿元。即便SY-707预计2026年获批，但ALK抑制剂赛道已有9款上市药物（8款进医保），SY-707作为后来者，若无显著差异化优势，商业化放量将面临激烈竞争与医保谈判降价的双重挤压。公司累计未弥补亏损已达11.54亿元，若核心产品上市后销售不及预期，资金链将面临严峻考验。

**研发管线高度集中于ALK/NSCLC单一赛道，存在“把鸡蛋放在一个篮子里”的结构性风险。** SY-707、SY-3505、SY-5007均聚焦非小细胞肺癌，靶点间存在替代与竞争关系。一旦ALK赛道出现颠覆性疗法（如新一代药物或联合方案），或SY-3505关键临床数据不及预期，整个管线价值将大幅缩水。此外，SY-5007虽数据亮眼，但RET抑制剂市场空间相对有限（年新发患者约2.88万例），且已有两款进口药上市并进医保，天花板较低。公司需警惕单一赛道过度集中带来的系统性风险。
