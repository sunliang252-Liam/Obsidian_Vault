# 300771.SZ 深度透视

## 因果逻辑链
- **[国内外客户订单需求增加]** -> [营业收入增长33%]: 海外收入同比增长33.87%，国内收入同比增长29.03%，共同推动总营收达6亿元。
- **[理财投资收益显著]** -> [净利润增长109.59%]: 非经常性损益中金融资产公允价值变动及处置收益达4,448万元，占归母净利润的53.8%，是利润翻倍的核心驱动力。
- **[降本增效取得成效]** -> [扣非净利润扭亏为盈]: 扣非净利润从-212万元跃升至4,067万元，研发费用同比下降12.55%，生产端通过工艺改进和结构优化降低成本。
- **[智能换电柜业务爆发]** -> [新业务增长点形成]: 智能换电柜类设备收入同比增长193.98%，成为除智能快件箱外第二大产品线，收入占比提升至9.51%。
- **[海外市场持续拓展]** -> [出口销售占比近半]: 出口销售收入2.94亿元，占总营收48.97%，南美市场实现突破，海外客户订单增长是收入增长的重要引擎。
- **[客户高度集中]** -> [经营依赖大客户]: 前五大客户销售额占比61.54%，其中第一大客户占比23.41%，公司收入高度依赖少数核心运营商。
- **[现金流大幅改善]** -> [经营质量提升]: 经营活动现金流净额从-1.84万元大幅提升至9,865万元，同比增长536,662%，显示收入增长带来实际现金回笼。

## 风险警告
**核心风险在于利润质量严重依赖非经常性损益。** 2025年归母净利润8,274万元中，非经常性损益高达4,208万元（占比50.9%），主要来自理财投资收益。扣非净利润仅4,067万元，虽扭亏为盈但绝对值仍低。若未来金融市场波动导致理财收益下降，公司实际盈利能力将大幅缩水。

**客户集中度极高且下游行业景气度存不确定性。** 前五大客户贡献超六成收入，智能快件箱业务仍占主营收入61%。若快递行业增长放缓或政策变化（如《快递市场管理办法》限制未经同意投递快件箱），主要客户缩减订单将直接冲击公司业绩。同时，公司海外收入占比过半且以美元结算，汇率波动（2025年已产生428万元汇兑损失）将持续侵蚀利润。
