# 603020.SH 深度透视

## 因果逻辑链
- **[处置子公司]** -> [营收与利润双降]: 2024年处置天舜食品，2025年处置上海盟泽，合并范围变化直接减少收入与利润，且2024年处置收益基数高，导致2025年归母净利润同比大幅下降45.47%。
- **[香精业务逆势增长]** -> [核心利润压舱石]: 凭借研发、交付、服务能力，巩固大客户并开拓中小客户，香精业务收入同比增长11.60%，毛利率维持37.91%，成为公司最稳定的利润来源。
- **[食品配料业务承压]** -> [拖累整体业绩]: 剔除处置子公司影响后，配料贸易收入虽有提升，但上海申舜工业巧克力业务因可可豆价格剧烈波动、下游需求复苏不及预期、产能利用率低，导致大幅亏损。
- **[理财收益结构变化]** -> [扣非净利润失真]: 大额存单到期后，理财收益从利息收入（财务费用减项）转为公允价值变动损益（非经常性损益），导致扣非净利润同比大降67.08%，实际经营利润被低估。
- **[原材料价格剧烈波动]** -> [毛利率承压]: 可可豆等上游原材料价格快速波动，下游客户难以完全承接成本上涨，导致食品配料业务毛利率同比下降4.75个百分点。
- **[募投项目产能爬坡缓慢]** -> [资产回报率低]: “食品配料研发制造基地”项目因客户认证周期长、消费预期偏弱等因素，产能利用率较低，子公司上海申舜亏损4375万元，拖累整体ROE。
- **[高额金融资产配置]** -> [利润波动放大器]: 公司持有近18亿元交易性金融资产、其他债权投资等，其公允价值变动对当期利润影响高达3215万元，使净利润对资本市场波动高度敏感。

## 风险警告
**核心风险在于食品配料业务的持续亏损与募投项目的不确定性。** 子公司上海申舜作为“食品配料研发制造基地”的实施主体，2025年亏损超4300万元，且项目进度已延期至2026年底。可可豆等原材料价格的高波动性、下游消费需求的疲软以及客户认证的漫长周期，使得该业务短期内扭亏难度极大，存在持续侵蚀公司利润的风险。

**第二重风险来自公司治理与业绩的“脱节”。** 公司账面持有大量现金及理财产品，但核心主业增长乏力，ROE仅2.65%。同时，控股股东在报告期末协议转让7.57%股份，虽锁定12个月，但可能引发市场对公司长期发展信心及控制权稳定性的担忧。此外，公司曾因信息披露问题被监管处罚，合规风险不容忽视。
