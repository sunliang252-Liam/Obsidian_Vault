# 600713.SH 深度透视

## 因果逻辑链
- **[资产处置收益暴增]** -> [归母净利润增长9.5%]: 子公司房产被政府征收，确认2.93亿元非经常性资产处置收益，掩盖了扣非净利润同比下滑26.78%的颓势。
- **[下游公立医院账期延长]** -> [经营性现金流暴跌95.7%]: 销售回款减少，导致经营活动现金流净额从21.36亿元骤降至0.92亿元，盈利质量严重恶化。
- **[信用减值损失激增]** -> [扣非净利润大幅下滑]: 一年以上应收账款增加，导致信用减值损失从0.42亿元飙升至1.85亿元，直接侵蚀核心利润。
- **[集采与医保控费深化]** -> [批发业务毛利率承压]: 行业政策持续挤压流通环节差价，公司批发业务毛利率同比下降0.12个百分点，增长主要靠规模驱动而非效率提升。
- **[数字化转型投入]** -> [研发费用增长52.73%]: 公司持续加码数字化中台、AI及供应链系统建设，研发投入资本化率高达46.92%，短期增加费用但旨在长期降本增效。
- **[股权激励与国企改革]** -> [管理层利益绑定]: 完成2025年限制性股票激励计划授予，将核心团队利益与公司市值及业绩增长深度绑定，激发经营活力。
- **[区域并购扩张]** -> [巩固市场份额]: 在安徽芜湖、宿州及湖北襄阳新设子公司，持续深耕优势区域，以应对行业集中度提升的竞争格局。

## 风险警告
**核心风险在于盈利质量与现金流严重背离。** 公司2025年归母净利润看似增长9.5%，但扣非净利润同比暴跌26.78%，且经营性现金流净额同比锐减95.7%至不足1亿元。这揭示出公司利润增长高度依赖非经常性资产处置，而主营业务回款能力急剧恶化，大量利润沉淀在应收账款中，财务健康度存在隐患。

**应收账款管理与信用减值风险是悬顶之剑。** 下游公立医院账期延长是行业通病，但公司一年以上应收账款激增导致信用减值损失同比暴增342%，成为侵蚀利润的最大黑洞。若未来医院端资金压力持续，坏账风险将进一步暴露，可能引发利润的剧烈波动。公司资产负债率虽微降至73.74%，但高杠杆运营下，现金流断裂风险不容忽视。
