# 920223.BJ 深度透视

## 因果逻辑链
- **[汽车类定点项目集中量产]** -> [营收增长50.84%]: 前期新能源汽车定点项目进入量产阶段，汽车类收入同比大增80.12%，成为营收增长核心引擎。
- **[液冷服务器快接头量产]** -> [开辟新增长曲线]: 服务器液冷快速接头零部件于Q2量产，成功切入AI算力散热供应链，虽当前贡献有限，但标志公司进入高景气赛道。
- **[3C行业复苏与政策红利]** -> [3C业务稳健增长]: 全球PC市场出货量增长9.2%，叠加国内“以旧换新”政策，3C类收入同比增长31.30%，巩固基本盘。
- **[产能爬坡期固定成本高企]** -> [持续亏损]: 汽车类业务尚未满产，厂房设备折旧等固定成本分摊较高，导致毛利率虽改善但仍为负值（汽车类毛利率-3.43%）。
- **[营收扩张推高应收账款]** -> [信用减值损失增加]: 汽车类客户账期较长，应收账款同比大增59.55%，导致信用减值损失同比增加263.36%，侵蚀利润。
- **[借款规模扩大]** -> [财务费用激增]: 为满足营运资金需求，公司大幅增加银行借款及股东借款，利息支出同比大增，财务费用同比增长721.46%。
- **[铜价高位波动]** -> [成本控制压力]: 铜材为主要原材料，价格与沪铜高度联动，高位震荡直接推高采购成本，若无法向下游传导，将压缩毛利率。

## 风险警告
公司虽营收高速增长，但核心矛盾在于“增收不增利”。汽车类业务毛利率为负（-3.43%），表明其仍处于“以规模换亏损”的产能爬坡期，固定成本吞噬利润。同时，营收扩张导致应收账款激增至2.22亿元，占营收51%，且汽车类客户账期长、票据结算多，现金流持续恶化（经营现金流-5965万元），存在坏账与流动性双重风险。

第二重风险来自财务杠杆的急剧攀升。资产负债率从47.35%飙升至61.95%，长期借款暴增1298%，并大量向股东借款。在持续亏损且经营现金流为负的背景下，高利息支出（财务费用+721%）进一步加重亏损，形成“借新还旧”的恶性循环。若液冷或汽车业务放量不及预期，偿债压力将急剧放大。
