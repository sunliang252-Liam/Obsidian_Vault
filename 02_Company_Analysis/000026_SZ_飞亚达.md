# 000026.SZ 深度透视

## 因果逻辑链
- **[国内手表消费市场持续承压]** -> [营收下降10.96%]: 行业规模以上企业营收同比下降9.7%，瑞士表出口中国大陆下降12.1%，直接拖累公司手表业务收入下滑11.58%。
- **[名表全面服务业务收入下降9.28%]** -> [整体业绩下滑]: 占营收75.89%的名表经销业务受消费低迷冲击最大，是营收下降的主要来源。
- **[存货减值计提大幅增加至5394万元]** -> [净利润暴跌60.37%]: 因市场需求低迷，公司对库存手表计提大额减值，资产减值损失同比增长179.61%，严重侵蚀利润。
- **[手表品牌业务收入下降20.96%]** -> [自有品牌承压]: 自有品牌“飞亚达”等销售下滑幅度远超名表经销业务，品牌手表销售量同比下降32.68%。
- **[经营活动现金流净额保持稳定]** -> [经营风险可控]: 公司通过减少存货采购、强化库存管理，在营收利润双降背景下，经营性现金流仍维持5.42亿元，与上年基本持平。
- **[精密科技业务收入增长7.08%]** -> [战略转型初见成效]: 精密科技业务逆势增长，并拟收购长空齿轮切入精密齿轮/减速器领域，成为公司未来增长新引擎。
- **[研发投入同比增长23.58%]** -> [强化核心竞争力]: 公司加大自主机心、关键零部件及航空航天材料研发，研发人员数量增长27.94%，为长期差异化竞争蓄力。

## 风险警告
**核心风险在于手表消费市场的持续低迷与存货减值压力。** 公司营收与利润双降，净利润暴跌60%，主要源于行业性需求萎缩。高达17.28亿元的存货（占总资产46.28%）面临持续减值风险，若消费市场未能回暖，未来仍有大额减值侵蚀利润的可能。公司虽通过减少采购维持了现金流，但手表品牌业务销量下降32.68%，显示核心业务基本面正在恶化。

**战略转型存在不确定性。** 公司正从传统手表业务向精密科技转型，拟收购长空齿轮。但该收购尚处早期阶段，最终方案未定，存在失败风险。同时，精密科技业务目前仅占营收4.11%，体量尚小，短期内难以对冲手表主业的下滑。在传统业务承压与新业务尚未成势的过渡期，公司面临业绩持续下行的风险。
