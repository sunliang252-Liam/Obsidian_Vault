# 688148.SH 深度透视

## 因果逻辑链
- **[产能利用率不足]** -> [上半年亏损]: 上半年产能利用率偏低，单位固定成本高企，导致综合毛利率为负，是全年亏损的主因。
- **[新技术规模化应用]** -> [下半年扭亏]: 新一代回收料分离提纯技术规模化应用，降低生产成本，叠加金属价格上涨，下半年毛利率显著提升。
- **[技术出口合作]** -> [新增利润来源]: 与日本企业签订48亿日元技术出口协议，按履约进度确认收入，成为下半年扭亏及现金流改善的关键增量。
- **[硫酸钴量价齐升]** -> [盈利能力改善]: 硫酸钴产品品质提升切入钴酸锂体系，叠加钴价上行，出货量翻番，毛利率大幅提升22.58个百分点。
- **[回收料使用比例提升]** -> [原料成本优化]: 加大废旧电池回收料采购（超1万吨），降低对原生矿依赖，有效对冲上游资源价格波动风险。
- **[存货跌价准备转销]** -> [利润修复]: 下半年金属价格回升，前期计提的存货跌价准备转销，直接减少营业成本，推动利润修复。
- **[高镍产品先发优势]** -> [前驱体恢复增长]: 8系、9系高镍及超高镍前驱体出货占比70%，NC二元前驱体受益于机器人、储能等新场景需求，出货量数倍增长。

## 风险警告
**流动性危机与高负债率是最大隐患。** 公司资产负债率高达83.77%，货币资金仅1.54亿元，而短期借款高达7.51亿元。经营活动现金流净额为-6839万元，已无法覆盖利息支出。可转债转股率极低，若触发回售条款，公司将面临巨大的兑付压力，存在资金链断裂风险。

**业绩依赖金属价格波动，可持续性存疑。** 公司2025年下半年扭亏主要得益于钴、锂等金属价格阶段性上涨及存货跌价转销，并非完全来自经营效率提升。若金属价格回落，公司毛利率将再次承压。同时，前驱体产能利用率不足、碳酸锂出货量下滑等问题尚未根本解决，业绩反转基础薄弱。
