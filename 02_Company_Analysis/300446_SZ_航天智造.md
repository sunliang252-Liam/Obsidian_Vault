# 300446.SZ 深度透视

## 因果逻辑链
- **[汽车零部件业务受益于自主品牌崛起]** -> [收入增长17.97%]: 公司精准把握新能源汽车和自主品牌加速迭代的机遇，新项目中新能源配套占比达69%，成功切入华为“界”系列等新势力供应链，驱动汽车零部件业务收入达82.61亿元。
- **[油气装备业务受“三桶油”资本开支收缩影响]** -> [收入基本持平]: 中石油、中石化2025年资本开支规划同比减少，导致公司传统油气装备收入承压，但超高孔密射孔弹等高端产品及军品收入增长63.17%，对冲了部分下滑，整体收入仅微降0.94%。
- **[火车票全面电子化冲击信息防伪材料]** -> [高性能功能材料收入下降13.16%]: 作为核心产品的热敏磁票因纸质报销凭证停用，收入同比骤降60.58%，尽管压力测试膜等电子材料增长2.70%，仍无法弥补该业务板块的整体下滑。
- **[经营活动现金流净额大幅减少36.52%]** -> [现金流与净利润背离]: 主要系公司2025年减少票据贴现，导致期末应收款项融资（已贴现未到期票据）较期初增加约10亿元，现金并未实际流入，造成经营现金流与净利润出现重大差异。
- **[汽车外饰件产销量大幅增长]** -> [规模效应显现]: 受益于新增项目带动，汽车外饰件销量同比增长40.70%，产量同步增长35.47%，规模效应有助于摊薄固定成本，但毛利率仍同比下降3.27个百分点，反映行业“内卷”压力。
- **[研发投入聚焦“内外饰+”与智能化]** -> [技术壁垒持续构建]: 公司研发投入4.40亿元，强度4.89%，重点突破智慧灯幕、第二代氛围灯、智能化分簇射孔系统等核心技术，为产品结构升级和维持行业领先地位提供支撑。

## 风险警告
**核心风险在于汽车零部件业务的“增收不增利”与油气装备业务的增长天花板。** 公司汽车零部件业务虽收入增长17.97%，但毛利率同比下降1.23个百分点，且经营活动现金流净额大幅下滑，显示在行业“内卷式”竞争下，公司为获取市场份额可能牺牲了部分利润和现金流质量。同时，油气装备业务下游“三桶油”资本开支收缩趋势明确，市场容量有限，业务规模难以实现有效突破，增长动能不足。

**高性能功能材料业务的转型阵痛与子公司亏损风险不容忽视。** 火车票全面电子化已对信息防伪材料造成致命打击，而公司新培育的压力测试膜、阻焊油墨等电子材料尚处于市场开拓期，收入规模小且盈利模式未成熟，若无法快速突破，该业务板块将持续承压甚至亏损。此外，公司产品结构升级面临挑战，主营的塑料内饰件技术附加值偏低，若不能及时向智能光电等高附加值领域迭代，现有市场竞争力将逐步弱化。
