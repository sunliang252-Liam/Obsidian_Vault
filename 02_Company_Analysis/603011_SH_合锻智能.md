# 603011.SH 深度透视

## 因果逻辑链
- **[汽车行业客户降价压力]** -> [母公司毛利率下滑]: 为稳住市场份额，母公司被迫适应客户降价要求，导致毛利同比减少7,435.60万元。
- **[毛利率持续下滑]** -> [大额资产减值计提]: 鉴于毛利率恶化，公司增加计提存货等资产减值准备，同比增加8,305.99万元，是亏损扩大的主因。
- **[母公司亏损拖累]** -> [归母净利润巨亏2.49亿]: 母公司毛利下滑与资产减值双重打击，导致整体业绩由盈转亏，亏损额同比扩大179.43%。
- **[色选机业务稳健]** -> [对冲机床业务下滑]: 子公司中科光电（色选机）贡献净利润1.54亿元，成为公司唯一盈利支柱，但无法覆盖母公司亏损。
- **[机床业务“内卷”加剧]** -> [机压机量价齐跌]: 机压机市场竞争白热化，收入同比下降16.34%，毛利率下滑11.76个百分点，成为亏损重灾区。
- **[核聚变业务战略布局]** -> [长期增长潜力]: 公司深度参与BEST项目，完成真空室首批重力支撑交付，但尚未形成规模化收入，短期无法贡献利润。
- **[经营活动现金流改善]** -> [与利润严重背离]: 经营性现金流净额同比增长55.45%至3.19亿元，主要系销售回款增加，但利润巨额亏损，显示盈利质量极差。

## 风险警告
**核心风险：主业溃败与减值“双杀”。** 公司核心的液压机与机压机业务正经历严重的“内卷”式竞争，客户降价压力导致毛利率持续下滑，已陷入“增收不增利”甚至“增收反巨亏”的困境。更危险的是，毛利率的恶化触发了大规模资产减值，形成恶性循环。公司2025年归母净利润巨亏2.49亿元，且母公司未分配利润为-2.4亿元，已不具备分红能力，基本面恶化趋势明确。

**次要风险：盈利高度依赖单一子公司，且存在历史合规污点。** 公司全部盈利几乎完全依赖子公司中科光电的色选机业务，一旦该业务受市场竞争加剧或海外地缘政治影响而下滑，公司将面临全面亏损。此外，公司近三年因业绩预告违规、会计差错更正等问题，多次受到上交所和安徽证监局的监管警示与处罚，公司治理与内控的有效性存疑，增加了投资的不确定性。
