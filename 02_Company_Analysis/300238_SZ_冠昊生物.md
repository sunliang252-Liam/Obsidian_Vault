# 300238.SZ 深度透视

## 因果逻辑链
- **本维莫德乳膏纳入常规医保药品目录** -> 药品业务收入同比增长56.40%: 医保准入扩大报销范围，促进销量增长
- **本维莫德乳膏销售收入增长** -> 公司整体营业收入同比增长2.72%: 药品业务收入占比从9.80%升至14.93%，拉动整体营收增长
- **国家集采政策持续深化** -> 医疗器械业务收入同比下降1.30%: 集采降价压力及产品结构调整导致器械收入小幅下滑
- **加大市场营销投入** -> 本维莫德销售量同比增长59.12%: 营销费用投入增加，学术推广和渠道下沉拉动销量
- **乳膏技改项目停产备货** -> 药品期末库存量同比增长1433.36%: 为应对技改停产，公司提前生产备货，导致库存激增
- **报废过期人工晶体32万片** -> 医疗器械库存量同比下降83.88%: 一次性销毁无效库存，导致库存账面大幅减少
- **干细胞政策明朗（纳入医保+重点研发）** -> 细胞业务收入同比下降19.75%: 政策利好尚未兑现为收入，研发投入增加及业务调整导致短期收入下滑
- **销售回款增加** -> 经营活动现金流净额同比增长44.23%: 加强应收账款管理，现金回收效率提升

## 风险警告
公司药品业务依赖单一品种本维莫德乳膏，面临集采降价和竞争加剧风险；医疗器械业务受集采影响增长乏力，且一次性报废人工晶体显示库存管理问题；细胞业务尚处研发阶段，短期难以贡献利润；天昊中山项目贷款增加导致财务费用大幅增长，偿债压力上升。
