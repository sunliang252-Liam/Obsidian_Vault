# 300408.SZ 深度透视

## 因果逻辑链
- **[MLCC产品放量]** -> [营收增长22.13%]: MLCC产品线覆盖0201至2220全尺寸，受益于消费电子、汽车电子需求增长，电子元件业务收入同比大增43.95%，成为核心增长引擎。
- **[AI算力基建扩张]** -> [光通信器件需求提升]: 全球云服务厂商资本开支增长，带动数据中心光器件需求，公司陶瓷插芯及配套产品销售额实现进一步增长。
- **[产品结构优化]** -> [毛利率承压]: 电子元件和电子及陶瓷材料毛利率分别下降2.07%和2.48%，主要因产品结构变化及原材料成本上升，但通信器件毛利率微增0.43%形成对冲。
- **[研发投入持续]** -> [技术壁垒巩固]: 研发费用同比增长12.07%至6.53亿元，重点突破超高容MLCC、车规级MLCC、MT插芯等高端产品，为长期竞争力奠基。
- **[全球化布局]** -> [拓宽融资渠道]: 向港交所递交H股上市申请，旨在募集资金用于海外项目建设及技术迭代，推进全球化战略。
- **[现金流强劲]** -> [盈利质量高]: 经营活动现金流净额28.78亿元，同比增长19.74%，与净利润高度匹配，显示公司回款能力及经营效率优秀。
- **[规模效应显现]** -> [成本控制有效]: 尽管原材料成本占比上升4.4%，但人工和制造费用占比下降，整体营业成本增速（23.95%）略高于营收增速，规模效应部分对冲了成本压力。

## 风险警告
**核心风险在于MLCC行业竞争加剧与产能消化。** 报告期内公司产销量同比大增近40%，库存量同步增长28.6%，显示公司正积极扩产抢占市场。然而，被动元件行业进口替代空间大，国内竞争者不断涌入，若下游需求增速放缓或公司产品认证不及预期，高额资本开支（募投项目延期至2027年）可能导致产能利用率下降，拖累资产回报率。

**技术迭代与研发方向偏差是另一重大风险。** 公司所处的电子陶瓷行业技术密集，下游产品更新换代极快。公司研发投入虽大，但若未能精准把握AI、汽车电子等前沿领域的技术路线（如更高容、更小尺寸MLCC），或研发成果产业化不及预期，现有技术优势可能被削弱，导致市场份额流失。同时，应收账款规模达21.59亿元，若客户付款能力恶化，坏账风险将侵蚀利润。
