# 601658.SH 深度透视

## 因果逻辑链
- **[“自营+代理”独特模式]** -> [低成本负债优势]: 依托邮政集团近4万个网点吸收低成本个人存款，个人存款付息率仅1.16%，为全行提供稳定、低成本的资金来源，支撑净息差保持国有大行最优水平（1.66%）。
- **[主动授信模式]** -> [零售信贷差异化增长]: 通过大数据挖掘优质客户并主动推送授信，实现“秒批秒贷”极致体验，贷款余额突破3,500亿元，不良率控制在1%以内，以低运营成本实现规模与风控的平衡。
- **[代理费主动调整]** -> [成本管控改善]: 主动调整储蓄代理费率，使储蓄代理费同比下降3.70%，有效对冲了收入端压力，推动成本收入比下降至62.10%。
- **[投研引领+交易转型]** -> [非息收入增长]: 强化债券、票据等资产交易流转，把握市场波段机会，带动投资收益及公允价值变动收益增长22.01%，成为非息收入“第二增长曲线”的核心驱动力。
- **[公司金融“1+N”体系]** -> [对公业务量级跃升]: 深化“商行+投行”联动，构建综合服务体系，推动公司贷款同比增长17.09%，FPA突破6.79万亿元，公司金融收入同比增长16.92%。
- **[财富管理体系建设]** -> [中收结构优化]: 战略性组建财富管理部，强化资产配置能力，带动理财、代理保险等业务增长，手续费及佣金净收入同比增长16.15%，其中理财业务收入增长35.99%。
- **[国家注资1300亿元]** -> [资本实力显著增强]: 获得财政部等战略注资，核心一级资本充足率提升至10.53%，为未来资产扩张和战略转型释放了空间，夯实了服务实体经济的资本根基。
- **[数智化转型]** -> [运营效率与风控能力提升]: 每年投入营收3%用于科技，自主系统占比达87%，AI赋能审贷、营销、风控全流程，实现集约化运营，提升效率并有效控制风险。

## 风险警告
**核心风险在于资产质量承压与净息差收窄的双重挤压。** 不良贷款率从2023年的0.83%升至2025年的0.95%，拨备覆盖率从347.57%大幅下降至227.94%，表明在经济下行和LPR下调的背景下，信用风险正在暴露，且风险抵补能力有所削弱。同时，净息差从2.01%持续收窄至1.66%，虽然仍为国有大行最优，但降幅明显，利息净收入已同比下降1.57%，盈利增长高度依赖非息收入，其可持续性面临考验。

**另一重大风险是“自营+代理”模式的潜在脆弱性。** 该模式虽带来低成本负债优势，但也导致储蓄代理费占业务及管理费比重超过50%，成本结构刚性。若未来代理费率调整不及预期或邮政集团战略协同出现变化，将直接冲击成本控制。此外，个人存款中定期存款占比高达77%，在利率下行周期中，存款定期化趋势可能推高负债成本，进一步压缩息差。
