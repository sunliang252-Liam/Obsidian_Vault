# 300175.SZ 深度透视

## 因果逻辑链
- **[原材料价格上涨]** -> [毛利率下降]: 原材料成本增幅(22.90%)超过收入增幅(18.88%)，导致整体毛利率同比下滑3个百分点。
- **[行政处罚罚款500万元]** -> [净利润亏损扩大]: 因2019年年报虚假记载被证监会处罚，缴纳罚款直接侵蚀利润，是导致亏损的核心非经常性因素。
- **[坚果果仁业务爆发式增长]** -> [收入结构优化]: 坚果果仁收入同比增长110.01%，成为第二增长曲线，部分对冲了果干业务增长乏力的影响。
- **[出售数据中心子公司]** -> [资产结构轻量化]: 出售太原德蓝达100%股权，剥离重资产数据中心业务，回笼资金，聚焦农副产品加工主业。
- **[外销收入增长21.90%]** -> [收入增长主引擎]: 外销收入占比58.14%，增速高于内销，是营收增长的主要驱动力，但面临印尼等市场贸易壁垒风险。
- **[存货大幅增加58.72%]** -> [营运资金压力]: 存货从1.15亿增至1.83亿，叠加经营性现金流净流出5663万元，显示公司为应对原材料涨价和旺季备货占用了大量资金。
- **[连续三年扣非净利润为负]** -> [主业盈利能力堪忧]: 2023-2025年扣非净利润持续为负，表明公司核心农副产品加工业务尚未实现稳定盈利。

## 风险警告
**核心风险在于主业盈利能力持续恶化与行政处罚带来的信誉冲击。** 公司连续三年扣非净利润为负，2025年毛利率仅8.23%，坚果果仁业务虽增长迅猛但毛利率近乎为零（0.66%），表明该业务尚处于“增收不增利”的规模扩张阶段，无法贡献有效利润。同时，因2019年年报虚假记载被证监会处罚500万元，公司股票已被实施ST，管理层信誉受损，未来融资和业务拓展可能受阻。

**财务健康度面临严峻考验。** 存货激增至1.83亿元，叠加经营性现金流净流出5663万元，公司营运资金压力巨大。母公司未分配利润为-1.16亿元，已无分红能力。虽然出售数据中心回笼部分资金，但主业造血能力不足，若原材料价格持续高位或下游需求疲软，公司可能面临流动性危机。此外，印尼等主要出口市场的贸易政策不稳定，构成外销业务的重大不确定性。
