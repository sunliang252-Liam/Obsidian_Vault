# 600644.SH 深度透视

## 因果逻辑链
- **[新兴业务（储能、虚拟电厂）高速扩张]** -> [营收结构优化]: 新兴业务收入同比增长79.94%，成为公司增长最快板块，但毛利率下降3.56个百分点，显示竞争加剧。
- **[电力业务“输配电价”模式受政策与市场冲击]** -> [盈利能力承压]: 电力业务收入同比下降2.38%，叠加外购电成本高企，传统主业增长乏力。
- **[天然气业务“购销价差”收窄与安装量萎缩]** -> [毛利大幅下滑]: 天然气业务毛利率同比下降5.07个百分点，主因上游气价上涨、工商业用气量下降及房地产影响安装量减少。
- **[定增募资2亿元专投储能项目]** -> [资本结构优化与新兴业务落地]: 龙泉驿储能电站建成转商，带来新增收益，同时货币资金增加55.69%，为转型提供资金。
- **[虚拟电厂聚合容量达53.11万千伏安]** -> [抢占新型电力系统先机]: 首批接入省级负荷中心，形成跨区域资源聚合能力，为未来参与电力市场交易奠定基础。
- **[“三网”建设持续投入与线损治理]** -> [运营效率提升]: 电力综合线损率、天然气输差率、自来水漏损率均同比下降，可控成本得到控制，经营现金流净额大增81.65%。
- **[无控股股东与无实际控制人]** -> [治理结构稳定但决策复杂]: 三大股东（乐山国投、国网四川、中环信息）持股比例接近，形成制衡，但重大战略决策需多方协调。

## 风险警告
**核心风险在于传统业务（电力、天然气、自来水）面临的结构性衰退与新兴业务（储能、虚拟电厂）盈利模式的不确定性。** 电力业务受全国统一电力市场建设和输配电价监审影响，盈利能力持续承压；天然气业务面临上游涨价、下游需求疲软和安装市场萎缩的三重挤压；自来水业务受制于市场饱和与价格调整进程缓慢。这三项传统业务贡献了绝大部分营收，但其增长动力已显著减弱。

**新兴业务虽增速迅猛，但尚处于投入期，盈利贡献有限且竞争激烈。** 储能业务依赖峰谷价差和政策补贴，随着电力现货市场落地，价差波动风险加剧；虚拟电厂仍处于平台建设和资源聚合阶段，商业化变现路径尚不清晰。公司研发投入极低（仅占营收0.03%），技术储备薄弱，可能难以支撑其在新兴赛道上的持续领先。此外，公司对国网四川电力的关联采购依赖度极高（占采购总额42.39%），存在供应链与定价风险。
