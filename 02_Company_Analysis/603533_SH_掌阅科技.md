# 603533.SH 深度透视

## 因果逻辑链
- **[短剧等衍生业务爆发式增长]** -> [营收增长25.53%]: 短剧业务收入18.55亿元，同比+139.19%，占总营收57.20%，成为第一大业务板块，拉动整体营收从25.83亿增至32.43亿。
- **[短剧业务高投入扩张]** -> [净利润巨亏1.76亿]: 销售费用20.79亿元，同比+38.55%，短剧国内外双线发展带来短期投入大幅增加，导致归母净利润从盈利0.49亿转为亏损1.76亿。
- **[数字阅读平台收入下滑]** -> [拖累整体盈利能力]: 数字阅读平台收入12.56亿元，同比-23.73%，但相关成本保持刚性，进一步加剧了公司亏损。
- **[销售费用率畸高]** -> [侵蚀利润]: 销售费用占营收比例高达64.1%，其中推广费用占销售费用的95.53%，高昂的获客成本是亏损的核心原因。
- **[AI技术赋能内容生产]** -> [提升效率与产能]: 公司推出“泡漫”AI漫剧平台，实现从剧本到分镜的一站式生成，全年上线800余部剧集，产能大幅扩张。
- **[海外市场成为第二增长曲线]** -> [战略投入加大]: 海外短剧平台iDrama覆盖多语种，核心指标看齐行业头部，但海外拓展带来的营销和本地化成本是短期亏损的重要因素。
- **[关联交易高度集中]** -> [依赖单一生态]: 前五名客户销售额占年度销售总额47.80%，其中关联方（抖音系）销售额占38.26%，公司业务高度依赖字节跳动生态的流量分发。

## 风险警告
**核心风险在于“增收不增利”的烧钱扩张模式。** 公司营收增长25.53%，但销售费用增长38.55%，导致净利润从盈利0.49亿暴跌至亏损1.76亿。短剧业务毛利率虽有提升，但高昂的推广费用（占营收64.1%）完全吞噬了毛利，且经营活动现金流净流出2.33亿元，造血能力严重不足。若流量成本持续上升或投放效率下降，亏损可能进一步扩大。

**业务结构高度依赖单一生态和关联交易。** 公司前五大客户中关联方（抖音系）销售额占比高达38.26%，短剧业务的流量获取和变现高度依赖字节跳动生态。一旦平台政策调整、分成比例变化或合作关系生变，将对公司收入造成重大冲击。同时，公司实际控制人成湘均与张凌云的一致行动协议于2025年2月到期终止，控制权结构的变化可能带来治理风险。
