# 002516.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升 + 深度绑定头部车企]** -> [汽车内饰业务收入增长10.92%]: 公司作为核心二级供应商，受益于下游新能源客户放量，高端内饰材料（合成革、超纤仿麂皮）订单增加。
- **[高端产品收入占比提升 + 产能释放]** -> [内饰业务净利润增长39.43%，远超收入增速]: 高毛利产品结构优化，叠加合成革、飞织项目产能利用率提升，单位成本下降，盈利能力显著增强。
- **[电网消纳不足 + 全面市场化交易]** -> [光伏发电收入下降19.03%，净利润骤降99.85%]: 限电率上升14.88%，发电量减少16.2%，叠加分时电价与市场化交易压低电价，存量电站盈利空间被严重挤压。
- **[国资入主]** -> [战略赋能与资本支持]: 株洲国资委成为实控人，为公司提供产业政策对接、产业链整合及资本市场工具支持，加速“大交通+大智能”战略落地。
- **[参股芯投微滤波器业务]** -> [打开第二增长曲线]: 芯投微收入同比增长46.20%，国内工厂TC/TF-SAW全线通线，进入多家头部客户供应链，虽因折旧与爬坡期利润承压，但长期国产替代潜力巨大。
- **[全产业链研发与CMF设计]** -> [构建差异化技术壁垒]: 从纤维到成品的一体化研发体系，叠加“宋式美学”等文化赋能，形成难以复制的产品附加值，提升客户粘性与议价能力。
- **[飞织项目“当年投入、当年满产”]** -> [验证高效产能转化能力]: 新项目快速达产，成为新的收入增长点，展示了公司从研发到产业化的高效执行力。

## 风险警告
**光伏业务持续失血，已成业绩拖累。** 电网消纳瓶颈与全面市场化交易是长期结构性利空，而非短期波动。2025年该业务净利润仅4.86万元，同比暴跌99.85%，且公司明确“无扩张战略”，存量资产仅能通过精细化运维与绿证交易勉强维持，未来大概率持续贡献负利润或微利，侵蚀主业增长成果。

**射频滤波器业务前景光明但兑现路径漫长。** 芯投微虽收入高增，但受制于工厂转固折旧、研发高投入及产能利用率爬坡，目前仍处于亏损状态。高端滤波器市场由国际巨头垄断，国产替代进程存在不确定性，该业务何时实现规模化盈利、能否成为真正的利润支柱，仍需持续跟踪，短期无法对冲光伏业务的颓势。
