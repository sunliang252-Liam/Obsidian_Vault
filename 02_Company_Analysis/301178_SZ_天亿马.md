# 301178.SZ 深度透视

## 因果逻辑链
- **[算力服务与新能源电力业务爆发]** -> [营收增长113.29%]: 2025年新增算力服务收入6616.57万元、新能源电力收入2129.90万元，合计占营收18.34%，成为业绩增长新引擎。
- **[智慧企业业务高速增长]** -> [营收结构优化]: 智慧企业收入1.53亿元，同比增长252.63%，超越智慧政务成为第一大收入来源，驱动整体营收规模跃升。
- **[信息系统集成业务大幅反弹]** -> [营收规模扩大]: 信息系统集成收入2.39亿元，同比增长340.82%，主要受益于算力集群等大型项目交付，是营收翻倍的核心贡献者。
- **[债务重组收益]** -> [净利润扭亏为盈]: 报告期内确认债务重组收益579.43万元，占利润总额93.61%，是公司实现归属净利润748.96万元、扭亏为盈的关键非经常性因素。
- **[经营活动现金流净额转正]** -> [现金流状况改善]: 经营活动现金流净额从-5424万元大幅转正至3218万元，主要系加强应收账款催收及销售收入回升。
- **[财务费用大幅增加]** -> [侵蚀利润]: 财务费用从-514万元增至1131万元，增幅319.85%，主要因算力服务、新能源电力等项目融资利息支出增加，对利润形成压力。
- **[并购星云开物]** -> [战略转型关键布局]: 拟发行股份及支付现金收购星云开物98.56%股权，标的公司2025年收入约5.3亿元、净利润约1.1亿元，旨在补齐生活消费场景短板，构建“全场景数字基座服务商”。

## 风险警告
**核心风险在于并购重组的高度不确定性。** 公司战略转型高度依赖收购星云开物，但该交易尚需深交所审核及证监会注册，存在被暂停、中止或取消的风险。若交易失败，公司“全场景数字基座服务商”的战略布局将受重大打击，且可能面临股价波动风险。

**盈利质量与可持续性存疑。** 2025年扭亏为盈主要依赖债务重组收益（占利润总额93.61%），扣非净利润仅363万元，主营业务盈利能力依然薄弱。同时，算力服务与新能源电力业务虽增长迅猛，但伴随大量融资，财务费用飙升，且项目回款周期长，应收账款高企（2.9亿元），现金流压力不容忽视。
