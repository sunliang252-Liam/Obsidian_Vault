# 300143.SZ 深度透视

## 因果逻辑链
- **并购整合（长沙珂信、圣诺、优尼）** -> **营收与扣非净利润双增**：通过外延并购扩大医疗服务与医疗器械规模，驱动营收增长20.93%，扣非净利润增长28.50%。
- **AI赋能（盈康大脑、AI员工）** -> **运营效率提升与费用率优化**：AI工具重塑诊疗全流程，提升效率与体验，使期间费用率优化1.2个百分点，患者NPS达93%。
- **肿瘤学科深耕与差异化服务** -> **医疗服务收入与手术量高增**：聚焦肿瘤“大专科”，强化精准放疗与中晚期照护，驱动医疗服务收入增长25.93%，手术量增长71%。
- **“设备+耗材”协同（圣诺+优尼）** -> **医疗器械板块稳健增长**：输注场景全产业链布局形成闭环，协同效应显著，圣诺与优尼业绩承诺完成率分别达127.47%和184.76%。
- **海外“一国一策”策略** -> **医疗器械海外收入高增长**：本地化运营体系加速全球布局，海外收入同比增长20.24%，占器械板块收入比重提升至27%。
- **圣诺医疗业绩达标调增对价** -> **归母净利润大幅下滑**：因圣诺达成业绩目标，交易对价调增4,600万元计入非经常性损益，导致归母净利润同比下降40.62%。
- **长沙珂信并购并表** -> **资产规模与商誉大幅扩张**：并购长沙珂信51%股权，新增商誉及资产，总资产同比增长18.54%，商誉占总资产比例升至24.13%。

## 风险警告
**核心风险在于商誉高企与并购整合的不确定性。** 报告期末商誉高达10.12亿元，占总资产24.13%，主要来自长沙珂信、圣诺医疗等并购。若被并购标的未来经营不及预期，将面临巨额商誉减值风险，直接侵蚀利润。公司虽具备整合能力，但持续并购对管理半径和资金链构成考验。

**另一重大风险是战略转型的投入产出周期与政策不确定性。** 公司正从医疗集团向“AI+主动健康”平台转型，相关AI应用尚处早期探索，短期难以贡献显著业绩。同时，医疗服务与器械行业受医保控费、集采等政策影响深远，若政策收紧，将对公司盈利能力造成冲击。
