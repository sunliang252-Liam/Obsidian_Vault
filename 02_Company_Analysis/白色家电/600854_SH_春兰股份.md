# 600854.SH 深度透视

## 因果逻辑链
- **[空调业务委托生产模式]** -> [营收微增但利润下降]: 公司暂停自产，委托关联方生产空调，虽出货量增长87.61%，但低毛利率（3.05%）导致营业成本增速（32.10%）远超营收增速（3.13%），拖累整体利润。
- **[房地产业务去化停滞]** -> [业绩支撑骤降]: 泰州房地产市场持续低迷，公司存量房销售基本停滞，房地产业务营收下降100%，净利润下降66.89%，对业绩贡献大幅减弱。
- **[投资收益依赖]** -> [利润核心来源]: 公司利润主要来源于对泰州电厂等联营企业的权益法核算投资收益（1.32亿元），占净利润比例超过100%，主业盈利能力极弱。
- **[研发投入与人力资源薄弱]** -> [主营空心化风险]: 研发费用仅230万元，研发人员仅5人且年龄老化（4人50-60岁），无法支撑产品竞争力提升，主营长期空心化风险显著。
- **[关联交易高度集中]** -> [经营独立性风险]: 空调采购几乎全部依赖关联方“江苏春兰空调设备有限公司”（占采购总额93.77%），且无偿使用控股股东“春兰”商标，经营独立性存疑。
- **[现金分红与盈利脱节]** -> [股东回报可持续性存疑]: 2025年现金分红率48.84%，但近三年累计分红率高达144.76%，远超年均净利润，分红主要依赖投资收益，而非主业造血。

## 风险警告
**核心风险：盈利空心化与主业萎缩。** 公司净利润几乎完全依赖对泰州电厂等联营企业的投资收益（1.32亿元），而空调主业毛利率仅3.05%，房地产业务已停滞。若电力市场改革导致投资收益下降，公司将失去利润支柱。同时，研发投入极低（230万元）、研发团队老化（5人，4人超50岁），空调业务委托生产模式缺乏核心竞争力，主营长期空心化风险极高。

**次要风险：经营独立性缺失与关联交易依赖。** 公司空调采购99.86%来自关联方，且无偿使用控股股东商标，经营独立性严重不足。房地产业务在泰州市场持续调整下，去化停滞，资产减值风险未充分释放。此外，公司合并报表未分配利润为负（-2.07亿元），虽母公司未分配利润为正，但分红能力受限于合并层面亏损，高分红率的可持续性存疑。
