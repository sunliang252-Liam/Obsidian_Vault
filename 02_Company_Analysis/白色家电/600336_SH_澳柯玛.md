# 600336.SH 深度透视

## 因果逻辑链
- **[国内家电市场需求收缩与价格竞争加剧]** -> [营收与利润双降]: 2025年国内家电市场零售额同比下滑4.3%，公司营收同比下降12.88%，归母净利润由盈转亏至-2.14亿元。
- **[生活电器与空调业务大幅下滑]** -> [整体业绩拖累]: 生活电器营收同比下降46.27%，空调营收同比下降32.56%，两者毛利率分别降至8.66%和5.52%，严重侵蚀利润。
- **[资产减值损失大幅增加]** -> [利润进一步恶化]: 2025年资产减值损失达1.29亿元，同比增加5.26倍，主要源于存货跌价及应收账款坏账计提，是亏损扩大的核心原因之一。
- **[智慧冷链与海外业务逆势增长]** -> [结构性亮点]: 商用展示柜收入同比增长11%，专用汽车营收增长31.93%；海外大客户战略突破，墨西哥公司营收增长超50%，印尼工厂启动建设。
- **[经营性现金流显著改善]** -> [财务质量提升]: 经营活动现金流净额达3.30亿元，同比增长58.01%，主要得益于加强应收账款管理，销售回款增加。
- **[财务费用大幅下降]** -> [成本控制成效]: 财务费用同比下降37.20%，主要因汇兑损失及利息费用减少，缓解了部分盈利压力。
- **[研发投入持续高企]** -> [长期竞争力储备]: 研发投入总额3.17亿元，占营收4.66%，资本化比例27.74%，聚焦低温制冷、节能降碳、AI智能化等核心技术。

## 风险警告
公司面临的核心风险在于国内家电市场已进入存量博弈阶段，行业竞争白热化导致价格战持续，生活电器、空调等非核心品类盈利能力脆弱，营收大幅下滑且毛利率极低，短期内难以扭转。同时，高达1.29亿元的资产减值损失暴露了公司在存货和应收账款管理上的潜在问题，若下游客户经营恶化或市场需求进一步萎缩，减值风险将持续侵蚀利润。

此外，公司海外业务虽增长强劲，但面临全球贸易保护主义抬头、关税壁垒及汇率波动的显著不确定性。印尼工厂等海外产能建设尚处早期，短期难以贡献利润，且需持续大额资本投入。公司资产负债率66.92%，短期借款与一年内到期非流动负债合计超10亿元，偿债压力不容忽视。
