# 603696.SH 深度透视

## 因果逻辑链
- **[贸易业务收入大增]** -> **营收增长但主业萎缩**: 贸易业务收入同比+21.12%至3.77亿元，拉动总营收+8.80%，但自产调味品主业收入同比-8.05%，显示增长依赖低毛利贸易，而非核心产品竞争力。
- **[销售费用激增]** -> **利润被侵蚀**: 销售费用同比+34.43%，主要用于新业务开拓、市场推广及三十周年庆典，但未能有效拉动主业增长，导致归母净利润同比-23.57%，扣非净利润同比-25.59%。
- **[原材料成本下降]** -> **主业毛利率提升**: 复合调味粉等核心产品原材料成本下降，推动食品制造业整体毛利率同比+5.20个百分点至45.06%，但销量下滑抵消了部分利润改善。
- **[在建工程持续投入]** -> **产能扩张与资产沉淀**: 永春生产基地等在建工程期末余额1.09亿元，占总资产16.85%，但募投项目“年产10,000吨利乐装调味骨汤”等尚未投产，短期无法贡献收益，形成资产沉淀。
- **[金融资产投资贡献利润]** -> **非经常性损益支撑**: 报告期公允价值变动收益+388万元，投资收益+166万元，合计贡献利润约554万元，是公司净利润的重要补充，但具有不可持续性。
- **[经营活动现金流大幅改善]** -> **回款能力增强**: 经营活动现金流净额从-247万元大幅转正至6,742万元，主因销售回款增加，但净利润与现金流背离，需关注利润质量。
- **[前五大供应商集中度极高]** -> **供应链依赖风险**: 前五大供应商采购额占年度采购总额79.98%，其中前两大供应商占比高达66.95%，公司对上游议价能力弱，且存在单一供应商依赖风险。

## 风险警告
**核心风险在于“主业空心化”与“增长依赖贸易”的结构性矛盾。** 公司营收增长完全由低毛利的贸易业务驱动（贸易收入占比高达64.3%），而核心调味品主业收入连续下滑（-8.05%），销量同步萎缩（-9.81%）。这种“增收不增利”的格局，叠加销售费用激增34.43%，导致净利润大幅下滑。公司本质上已从调味品制造商蜕变为“味精贸易商”，核心竞争力正在弱化。

**财务与治理风险不容忽视。** 公司2025年因会计差错等问题收到福建证监局责令改正及上交所监管警示，内控有效性存疑。同时，账面高达1.09亿元的在建工程长期未投产，且存在11,000万元中融信托产品逾期未收回，资产减值风险敞口较大。此外，前五大供应商采购集中度接近80%，供应链稳定性高度依赖少数几家厂商，一旦合作关系生变，将对公司经营造成重大冲击。
