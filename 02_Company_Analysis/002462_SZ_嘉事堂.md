# 002462.SZ 深度透视

## 因果逻辑链
- **[集采政策持续扩面]** -> [营收与利润双降]: 药品和器械集中带量采购提速扩面，压缩流通环节利润空间，导致公司2025年营收同比下降18.71%，归母净利润同比下降29.57%。
- **[主动剥离亏损器械子公司]** -> [短期利润承压，长期聚焦主业]: 公司年内处置6家亏损的医疗器械子公司（51%股权），产生非经常性损益，但旨在出清风险、优化资产结构。
- **[加强应收账款催收]** -> [经营性现金流大幅改善]: 公司强化回款管理，销售收款与采购付款差额扩大，叠加费用支出减少，使经营活动现金流净额同比暴增671.92%至13.92亿元。
- **[计提大额减值损失]** -> [侵蚀净利润]: 报告期内计提应收账款坏账及商誉减值等损失合计3.69亿元，同比增加1.7亿元，是导致净利润远低于经营性现金流的核心原因。
- **[营收规模收缩]** -> [期间费用率被动上升]: 尽管销售、管理、财务费用绝对值同比下降，但营收降幅更大，导致费用率上升，对盈利能力构成压力。
- **[器械业务萎缩]** -> [收入结构向药品批发集中]: 器械业务受集采冲击最大，医药物流和连锁零售收入分别下滑69.13%和40.35%，医药批发收入占比提升至96.32%。
- **[央企集团产融结合]** -> [提供战略与资源支撑]: 背靠光大集团，公司获得战略指引和产融协同机会，但集团对“做专做精特色实业”的要求也限制了其扩张边界。

## 风险警告
**核心风险在于集采政策的持续深化与公司业务转型的阵痛。** 公司两大核心业务——药品和器械批发均受集采冲击，导致营收和利润连续下滑。虽然公司通过剥离亏损子公司、加强回款来“止血”，但并未找到新的、可持续的增长引擎。器械业务的大幅萎缩和连锁零售的疲软，表明公司传统商业模式正面临根本性挑战。

**财务风险不容忽视。** 尽管经营性现金流大幅改善，但这是建立在营收收缩和费用压缩的基础上的。公司归母净利润已连续两年大幅下滑，且计提了巨额减值损失，反映出资产质量（尤其是应收账款和商誉）存在隐忧。此外，公司主动剥离子公司虽意在“风险出清”，但短期内也造成了利润损失和业务规模收缩，转型能否成功尚待观察。
