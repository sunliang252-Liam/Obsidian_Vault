# 600876.SH 深度透视

## 因果逻辑链
- **[光伏行业供需严重失衡]** -> [营收与利润双杀]: 行业名义产能超1100GW，实际需求仅约600GW，供强需弱导致光伏玻璃价格持续下行，公司营收同比下降29.40%，归母净利润亏损9.14亿元。
- **[产品售价降幅远超成本降幅]** -> [毛利率大幅恶化]: 尽管单位综合生产成本同比下降16%，但产品售价下滑更剧烈，导致主营业务毛利率降至-12.41%，同比减少7.64个百分点。
- **[客户信用风险暴露]** -> [巨额信用减值损失]: 行业深度调整导致部分客户经营困难，公司计提信用减值损失1.60亿元，同比暴增2355.89%，成为利润大幅亏损的核心原因之一。
- **[逆势扩张产能]** -> [资产负债率攀升至73.33%]: 公司坚持“停小建大”策略，收购江苏凯盛、推进北方玻璃及自贡新能源等项目，带息负债规模增至63.96亿元，资产负债率较上年末上升8.88个百分点。
- **[经营亏损加剧]** -> [经营性现金流持续净流出]: 营收规模下降与亏损加剧，导致经营活动现金流净流出7.36亿元，较上年同期净流出增加86.86%，现金流压力显著。
- **[政府补助与资产减值对冲]** -> [非经常性损益掩盖部分经营困境]: 报告期确认政府补助1.72亿元，同时计提资产减值损失0.98亿元，非经常性损益合计1.04亿元，部分缓冲了主营业务巨亏对报表的冲击。
- **[母公司未分配利润巨额亏损]** -> [丧失分红能力]: 母公司累计未分配利润为-6.48亿元，根据法规不具备利润分配条件，连续两年无法向股东分红。

## 风险警告
凯盛新能正深陷光伏行业“内卷式”价格战的泥潭。核心风险在于，公司逆势扩张产能的战略与行业严重过剩的供需格局形成尖锐矛盾。2025年营收32亿，但经营性现金流净流出7.36亿，造血能力已严重不足。更危险的是，为维持扩张，公司资产负债率已飙升至73.33%，带息负债高达64亿，财务费用持续增长，而下游客户信用风险集中爆发导致1.6亿坏账计提，表明行业寒冬已从利润表蔓延至资产负债表。

公司当前最大的隐患是“以债养亏”的恶性循环。在行业产能出清远未结束的背景下，公司大规模资本开支（在建工程33.55亿）不仅无法立刻转化为利润，反而持续消耗现金流、推高杠杆。若光伏玻璃价格无法企稳回升，公司可能面临资产减值（已计提0.68亿）与财务费用双重挤压，净资产已较上年缩水22.76%，未来存在进一步侵蚀股东权益的风险。
