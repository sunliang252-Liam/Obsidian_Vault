# 002876.SZ 深度透视

## 因果逻辑链
- **[新产能投产爬坡]** -> [营收增长42.41%但净利润下降30.85%]: 合肥二期新产线于2025年3月投产，带动销量同比增56.79%，但良率与产能利用率不足导致该子公司亏损4,975.56万元，拖累整体利润。
- **[日元汇率升值]** -> [财务费用激增184.92%]: 日元升值导致汇兑亏损，叠加新产线贷款增加利息支出，财务费用同比增加4,697万元，直接侵蚀利润。
- **[大客户订单增长]** -> [营收创历史新高]: 公司深度绑定京东方、惠科等头部面板厂，前五大客户销售占比68.17%，大客户订单持续放量驱动收入增长。
- **[原材料国产化突破]** -> [大尺寸TV市场突破]: 65吋以上TV偏光片实现全面量产，关键原材料国产化率国内领先，成本优势助力切入75/85吋超大尺寸市场。
- **[OLED偏光片放量]** -> [产品结构优化]: 柔性AMOLED圆偏光片累计出货超55KKpcs，占营收约8%，成为中小尺寸领域新增长极。
- **[存货与应收账款周转改善]** -> [经营现金流大幅转正]: 经营现金流净额同比增357.45%至1.93亿元，远超净利润，显示运营效率提升。
- **[参股公司亏损扩大]** -> [投资收益拖累]: 对湖北三利谱等联营企业按权益法计提投资亏损同比增加826万元，成为利润下滑因素之一。

## 风险警告
**核心风险在于新产能盈利兑现的不确定性。** 合肥二期作为公司进军大尺寸TV市场的战略支点，2025年投产首年即亏损近5000万元，且产能爬坡进度多次延期。若良率提升与客户导入不及预期，将持续压制公司整体利润率，形成“增收不增利”的恶性循环。同时，公司资产负债率随产能扩张攀升，短期借款达17.84亿元，财务费用压力陡增。

**另一重大风险是原材料供应高度集中与汇率波动。** 核心原材料PVA膜与TAC膜主要依赖日本供应商（可乐丽、富士胶片），虽已推进国产替代，但短期内完全替代存在技术壁垒。日元汇率升值已导致2025年汇兑亏损，若日元持续走强或中日贸易关系恶化，成本端将面临不可控冲击。此外，公司产品结构单一（偏光片收入占比98.6%），下游面板行业价格战压力将直接传导至上游，毛利率存在持续下行风险。
