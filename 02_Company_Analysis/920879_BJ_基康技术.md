# 920879.BJ 深度透视

## 因果逻辑链
- **[国家基础设施投资持续高位]** -> [营收增长14.32%]: 水利、能源、交通等领域重大工程投资维持高位，直接拉动公司智能监测终端及解决方案需求。
- **[抽水蓄能电站建设加速]** -> [能源行业业绩增长]: 公司成功签订近20个新建抽水蓄能电站供货合同，成为营收增长的核心驱动力。
- **[交通行业市场突破]** -> [交通行业新签合同额突破性增长]: 公司紧抓公路长大桥监测、数字化监测体系建设机遇，实现交通行业业绩显著增长。
- **[安全监测物联网解决方案占比提升]** -> [整体毛利率下降3.34个百分点]: 解决方案及服务收入增长31.59%，但其毛利率（27.85%）远低于智能监测终端（59.93%），拉低了综合毛利率。
- **[应收账款规模扩大]** -> [信用减值损失增加95.02%]: 应收账款净额增长27.36%至3.80亿元，导致计提的坏账准备大幅增加，侵蚀了部分利润。
- **[“有利润的营业收入”和“有现金流的利润”战略]** -> [经营现金流净额下降37.54%]: 尽管利润增长，但销售回款减少及税费、薪酬支付增加，导致经营活动现金流净额降至4151万元，与净利润（8305万元）差距扩大。
- **[研发投入持续加大]** -> [产品竞争力与国产化替代能力提升]: 研发费用增长14.09%至3509万元，推动综合数据采集仪、G云平台实现全面国产化，并成功推出全链路国产化解决方案。
- **[股权激励行权]** -> [资本公积减少与股本增加]: 2023年股权激励计划第二个行权期行权，导致资本公积减少约646.9万元，股本增加42.4万股。

## 风险警告
**核心风险在于应收账款高企与现金流恶化之间的剪刀差。** 公司2025年应收账款净额高达3.80亿元，占总资产的47.10%，且同比增长27.36%，远超营收增速。同时，信用减值损失同比近乎翻倍，经营活动现金流净额同比大降37.54%，仅为净利润的50%。这种“纸面富贵”的盈利质量，若下游客户（主要为大型国企）付款周期进一步拉长，将严重考验公司的资金周转能力，并可能引发更大的坏账风险。

**毛利率持续承压是另一大隐忧。** 公司综合毛利率已从2023年的54.47%降至2025年的52.72%。核心原因在于低毛利率的安全监测物联网解决方案业务占比快速提升，其收入增速（31.59%）显著高于高毛利率的智能监测终端（10.08%）。若该趋势延续，公司整体盈利能力可能面临持续下行压力，削弱其长期价值。
