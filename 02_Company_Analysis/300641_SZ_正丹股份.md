# 300641.SZ 深度透视

## 因果逻辑链
- **[美国TMA产能退出]** -> [2024年TMA价格飙升，2025年自高位回落]: 海外供给缺口导致2024年产品价格暴涨，2025年随着市场再平衡，价格从高位逐步回归，公司营收与利润同比大幅下滑。
- **[核心产品价格回落]** -> [2025年营收同比下降34.19%，归母净利润同比下降39.98%]: 酸酐及酯类产品均价下降，直接压缩了利润空间，导致盈利能力从2024年的历史高点回落。
- **[原材料成本下降]** -> [营业成本同比下降30.37%]: 主要原材料（偏三甲苯、辛醇、芳烃混合物）采购单价下降，部分对冲了产品价格下跌对毛利率的冲击。
- **[产品结构调整]** -> [高沸点芳烃溶剂收入同比减少58.17%]: 公司主动减少副产品加工数量，聚焦高附加值核心产品，导致该板块收入大幅下滑。
- **[新产品放量]** -> [高分子特种树脂单体收入同比增长30.47%]: 新产品完成样品检测和小批量试单，开始批量供货，成为新的收入增长点。
- **[经营活动现金流强劲]** -> [经营活动现金流净额同比增长24.52%]: 尽管收入和利润下滑，但公司通过优化采购和回款，现金流状况显著改善，现金储备大幅增加。
- **[产能扩张与技改]** -> [在建工程持续推进]: “6.5万吨/年偏苯三酸酐绿色化升级改造项目”和“1万吨/年均四甲苯装置技改项目”获得环评批复，为未来增长奠定基础。

## 风险警告
**核心风险是产品价格持续下跌的风险。** 2024年TMA价格因海外供给缺口而暴涨，但2025年已自高位回落。若未来行业产能扩张过快，或出现替代品，可能导致TMA供需关系失衡，产品价格进一步下跌，直接侵蚀公司利润。公司业绩高度依赖单一产品的价格周期，波动性极大。

**次要风险是原材料价格波动和行业竞争加剧。** 公司主要原材料为石油化工产品，价格随原油波动。若原材料价格上涨而产品价格未能及时传导，将压缩利润空间。同时，高利润吸引潜在竞争者进入，可能加剧行业竞争，进一步压低产品价格。公司需持续通过技术创新和成本控制来维持竞争优势。
