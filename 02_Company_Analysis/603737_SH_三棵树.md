# 603737.SH 深度透视

## 因果逻辑链
- **[家装墙面漆量价齐升]** -> [营收增长3.49%]: 家装墙面漆收入同比增14.67%，毛利率提升3.85个百分点，成为核心增长引擎。
- **[原材料价格下降]** -> [毛利率大幅改善]: 精细化工原材料成本下降0.25%，叠加产品结构优化，综合毛利率提升4.01个百分点。
- **[战略转型聚焦零售]** -> [利润暴增133.45%]: 公司主动调整渠道结构，降低对疲软地产工程业务的依赖，零售端高毛利产品占比提升。
- **[经营现金流大幅改善]** -> [财务韧性增强]: 经营活动现金流净额同比增85.19%至18.68亿元，主要系回款增加及采购支出减少。
- **[借款减少与利率降低]** -> [财务费用下降27.73%]: 公司主动降杠杆，财务费用从1.61亿降至1.17亿，直接增厚利润。
- **[工程业务需求疲软]** -> [防水卷材收入下滑24.52%]: 下游地产竣工面积同比下降18.1%，导致工程墙面漆和防水卷材收入承压。
- **[渠道下沉与品牌升级]** -> [零售网络持续扩张]: 仿石漆网点高速增长，艺术漆渠道延续增长，马上住服务覆盖超300城。

## 风险警告
**核心风险在于地产下行周期对工程业务的持续拖累。** 尽管公司战略转向零售，但工程墙面漆和防水卷材收入合计占比仍超35%，且下游地产竣工面积同比降18.1%，需求疲软未见拐点。公司应收账款余额高达27.97亿元，占净资产近100%，若地产客户信用恶化，坏账风险将直接冲击利润。

**原材料价格波动是另一大隐忧。** 2025年利润暴增很大程度上受益于原材料价格下降，但乳液、钛白粉等化工原料价格具有强周期性。若未来原材料价格反弹，而公司无法通过提价完全转嫁成本，毛利率将面临显著压缩，业绩高增长的可持续性存疑。
