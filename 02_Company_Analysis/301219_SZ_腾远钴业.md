# 301219.SZ 深度透视

## 因果逻辑链
- **[刚果（金）钴出口禁令与配额政策]** -> [全球钴供给收缩22.3%，钴价大幅上涨]: 政策导致原料到港滞后约3个月，国内库存持续去化，供需格局从过剩8.3万吨转为短缺0.7万吨，直接推升公司钴产品售价与毛利率。
- **[钴产品量价齐升]** -> [钴产品收入同比增长59.01%，毛利率提升20.70个百分点]: 产能释放带动产量增33.35%，叠加价格上行，钴产品成为公司最大收入来源（占比46.03%）和利润增长核心引擎。
- **[二次资源战略深化]** -> [锂产品收入暴增187.80%，废旧电池处理能力达3万吨/年]: 公司加大电池黑粉采购，锂产量增106.57%，销量增262.48%，实现从“原生矿依赖”向“原生+再生”双轨保障转型。
- **[下游延伸战略突破]** -> [腾驰新能源实现盈利，三元前驱体销售增长3816.88%]: 子公司赣州腾驰实现年产2万吨前驱体及1万吨四氧化三钴产能释放，产品获客户认可并批量销售，标志产业链闭环初步形成。
- **[铜业务稳健贡献]** -> [铜产品收入占比42.45%，毛利率29.65%]: 尽管销量微降，但沪铜价格突破10万元/吨创历史新高，铜业务为公司提供稳定现金流和利润基础。
- **[募投项目变更聚焦资源端]** -> [新增刚果（金）年产3万吨铜、2000吨钴湿法冶炼厂项目]: 因三元前驱体市场不及预期，公司将原计划投向前驱体的5.88亿元募集资金转向资源地扩产，以保障原料自给率。
- **[经营活动现金流大幅改善]** -> [经营性现金流净额同比增长371.44%至9.33亿元]: 钴价上涨带动营收和净利润增长，销售回款增加，现金流质量显著提升。

## 风险警告
**核心风险：刚果（金）政策与地缘政治风险。** 公司约48%收入来自境外，核心原料钴矿高度依赖刚果（金）供应。2025年该国出口禁令和配额政策虽短期推高钴价利好公司，但政策不确定性极高。若未来出口限制放松或政策反复，钴价可能剧烈回调；若局势恶化导致生产中断，公司将面临原料断供和成本失控的双重打击。公司境外资产占总资产39%，且未进行外汇套期保值，汇率波动风险敞口显著。

**次要风险：产品价格波动与库存减值风险。** 钴、铜、镍等金属价格受国际供需、投机情绪影响极大。报告期末公司存货高达39.37亿元（占总资产30%），钴库存量同比暴增116%。若金属价格下行，公司将面临巨额存货跌价损失（2025年已计提资产减值损失1.63亿元）。此外，三元前驱体市场不及预期导致募投项目变更，下游需求的不确定性仍是长期隐忧。
