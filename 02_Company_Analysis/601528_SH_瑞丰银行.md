# 601528.SH 深度透视

## 因果逻辑链
- **存款结构优化，定期存款占比提升且存款付息率下降37BP** -> 利息支出同比减少9.09%，对冲资产端收益率下行: 直接因果
- **负债成本管控有效，存款付息率下降** -> 净息差止跌企稳，同比持平于1.50%: 中介因果
- **净息差企稳且业务规模稳步增长（资产+9.52%，贷款+7.82%）** -> 利息净收入同比增长8.33%: 直接因果
- **大力置换低收益票据贴现资产，票据日均余额下降24.98%** -> 贷款收益率降幅边际放缓: 直接因果
- **信用减值损失同比减少13.91%** -> 营业支出同比减少6.62%，支撑利润增长: 直接因果
- **不良贷款率微升0.02个百分点至0.99%** -> 拨备覆盖率仍维持高位（326.51%），风险抵补能力充足: 弱因果（不良上升但拨备更足）
- **“四箭”区域（义乌、越城、滨海、嵊州）贷款及存款增量贡献占比38.99%和37.73%** -> 区域多元化拓展成为收入增长新引擎，义乌板块国际业务结算量占比提升至63.21%: 直接因果
- **财富管理业务规模增长（代销理财+68.03%），财富中收同比增长18.13%** -> 手续费及佣金净收入同比增长207.40%: 直接因果
- **公允价值变动损失83,802千元（交易性金融资产公允价值下降）** -> 非利息净收入同比下降16.44%: 直接因果
- **政府补助等其他收益减少（其他收益同比-37.46%）** -> 非经常性损益同比下降，扣非净利润增速（10.18%）显著高于归母净利润增速（2.30%）: 直接因果

## 风险警告
净息差虽企稳但仍处低位，未来若资产收益率持续下行或负债成本管控效果衰减，利息净收入增长承压；不良贷款率微升，需关注经济下行期小微企业及个人贷款信用风险；交易性金融资产公允价值波动较大，市场风险敞口需警惕；非利息收入依赖手续费及投资收益，公允价值变动损失反映市场波动风险。
