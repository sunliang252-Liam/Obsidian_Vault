# 600861.SH 深度透视

## 因果逻辑链
- **[业务外包服务增长]** -> [营收增长5%]: 业务外包收入同比增长10.06%，是驱动总营收增长的核心引擎，抵消了灵活用工等业务的收缩。
- **[处置非核心资产]** -> [归母净利润暴增47.82%]: 出售黄寺商厦100%股权确认约3.59亿元投资收益，叠加政府补助增加与降本增效，使净利润增速远超扣非净利润。
- **[降本增效与费用管控]** -> [扣非净利润稳健增长5%]: 销售费用、管理费用、研发费用均同比下降，人工成本优化，支撑了核心业务利润的稳定增长。
- **[回款效率提升]** -> [经营现金流暴增318.68%]: 公司加强应收账款管理，回款效率提高，使经营活动现金流净额从3.06亿跃升至12.80亿，现金流质量显著改善。
- **[灵活用工强监管]** -> [招聘及灵活用工收入下降30.23%]: 行业监管收紧导致公司主动进行合规化调整，业务规模阶段性收缩，成为拖累整体增速的主要板块。
- **[大客户战略深化]** -> [客户粘性与单客价值提升]: 新增11家千人规模以上大客户，与能源、汽车、高校等头部机构建立战略合作，巩固了高价值客户基本盘。
- **[AI技术赋能招聘]** -> [运营效率提升]: AI面试将招聘顾问时间成本降低80%以上，AI简历筛选与岗位匹配提升了招聘产能，形成差异化竞争优势。
- **[国际化布局]** -> [开辟新增长曲线]: 构建覆盖EOR、薪酬、招聘的一站式出海产品矩阵，成功开拓多家行业龙头客户，初步形成全球人力资源服务生态。

## 风险警告
**核心风险在于利润质量与业务结构失衡。** 2025年归母净利润47.82%的高增长主要由出售资产的一次性收益（约3.59亿）和政府补助（6.61亿）驱动，扣非净利润增速仅5%，表明核心业务盈利能力并未出现质的飞跃。一旦非经常性损益不可持续，利润将面临显著回落压力。同时，灵活用工业务因强监管收入锐减30%，若合规调整无法快速转化为增长动力，将长期拖累整体业绩。

**大客户集中与行业竞争是另一大隐忧。** 前五大客户销售额占比高达44.31%，核心大客户的流失或订单缩减将对公司业绩产生剧烈冲击。此外，人力资源服务行业参与者众多，价格战风险持续存在。公司虽通过全链条服务和国际化布局构建壁垒，但若无法持续提升高附加值服务的占比，仅靠低毛利的业务外包（毛利率3.17%）驱动增长，长期盈利天花板将非常明显。
