# 601880.SH 深度透视

## 因果逻辑链
- **[高毛利率业务（油品仓储、集装箱、散粮）增长]** -> [毛利大幅增长36.6%]: 油品仓储收入增加、外贸集装箱费率提升、内贸玉米吞吐量增长，有效弥补了低毛利散杂货业务下滑的缺口，并拉动整体毛利率提升7.1个百分点。
- **[深化成本管控与业务结构优化]** -> [营业成本下降6.7%]: 通过优化环渤海内支线业务结构、降低劳务及外包、能源等成本，在收入微增2.6%的情况下实现了成本的有效压降。
- **[收回客户长期欠款]** -> [经营活动现金流净额大增32.4%]: 应收账款回收成效显著，带来强劲的现金流入，现金流质量远超利润增速。
- **[合联营企业业绩下滑及上年一次性投资收益消失]** -> [投资收益同比大幅下降114.2%]: 投资收益由正转负，成为抑制净利润增速的主要负面因素，扣非净利润增速（+43%）远高于归母净利润增速（+14.2%）。
- **[集装箱业务结构优化]** -> [集装箱毛利增长26.9%]: 尽管收入因中欧班列等业务量下降而减少，但外贸集装箱业务量与费率增长、环渤海内支线优化，显著提升了该板块盈利能力。
- **[油品仓储收入增长]** -> [油品板块毛利暴增2135%]: 原油仓储业务成为利润核心增长引擎，推动该板块毛利率从3.1%跃升至42.3%。
- **[散杂货业务量下降]** -> [散杂货毛利下滑11.8%]: 受钢铁行业持续亏损影响，高费率的铁矿石业务量下降，叠加折旧增加，拖累了整体业绩表现。

## 风险警告
**核心风险在于腹地经济疲软与区域竞争加剧的双重挤压。** 公司主要腹地东北三省经济总量低于环渤海周边省份，冶金、建材等传统支柱产业持续低位运行，直接导致高毛利的铁矿石等散杂货业务量下滑。同时，河北、山东等周边港口通过环渤海中转、海铁联运等方式持续争夺货源，区域竞争格局日趋严峻，对公司核心业务增长构成长期压制。

**另一重大风险是历史遗留的法律诉讼与资产瑕疵问题。** 公司下属码头物流公司涉及多起仓储系列案件，部分案件已进入破产清算程序，潜在赔偿金额巨大，对利润和声誉构成实质性威胁。此外，控股股东关于解决同业竞争的承诺已延期至2028年底，若届时未能妥善解决，将影响公司治理的独立性与长期价值。
