# 000977.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长43.25%]: 国家“人工智能+”行动深化，AI大模型加速落地，推动智能算力需求激增，公司服务器产品销售大幅增长。
- **[推理算力需求超越训练]** -> [产品结构向高性价比推理服务器倾斜]: 公司推出元脑R1推理服务器、超节点AI服务器等，以更低token成本满足推理需求，抢占市场增量。
- **[液冷技术领先]** -> [巩固绿色数据中心竞争优势]: 连续4年蝉联中国液冷服务器市场第一，兆瓦级两相液冷方案解热能力突破3000W，满足高密度算力散热需求。
- **[开源开放生态]** -> [降低客户切换成本，扩大市场覆盖面]: 核心参编OCM设计规范，支持x86/ARM多芯架构，实现“一机多芯”，吸引多元客户。
- **[“平台+生态”元脑战略]** -> [加速AI行业落地，提升客户粘性]: 与166家EPAI种子伙伴合作，提供从算力到模型开发平台的全栈方案，打通AI落地“最后一公里”。
- **[规模效应与成本控制]** -> [毛利率承压但净利润增长]: 营收增长43.25%但毛利率下降2.03%，通过销售费用下降13.97%和研发费用仅增7.38%实现扣非净利润增长11.10%。
- **[经营活动现金流大幅改善]** -> [财务健康度提升]: 现金流净额从7.49亿飙升至54.53亿，增长7183.71%，主要系销售回款大幅增加，缓解了高存货和高应收带来的资金压力。

## 风险警告
**核心风险在于毛利率持续下滑与客户/供应商高度集中。** 2025年公司整体毛利率仅4.77%，服务器产品毛利率更是低至4.52%，且同比下降2.18个百分点。在营收暴增43.25%的背景下，净利润仅增长5.20%，显示出公司以价换量、盈利能力薄弱的困境。更需警惕的是，前五大客户销售额占比高达71.29%，前五大供应商采购额占比高达74.01%，这种“两头在外”的格局使公司议价能力极弱，利润空间极易被上下游挤压。

**供应链与地缘政治风险是悬顶之剑。** 公司明确提及“部分国家不断通过提高关税、限制产品进出口等方式进一步加强贸易壁垒”，且人工智能产业需求爆发引发关键物料供应趋紧。作为全球服务器龙头，公司核心芯片（如GPU、CPU）高度依赖进口，任何贸易摩擦升级或供应链中断都将直接冲击生产与成本，这是公司无法通过自身经营化解的系统性风险。
