# 920821.BJ 深度透视

## 因果逻辑链
- **[海外大客户订单延迟]** -> [营收增长停滞]: 部分海外大客户产品迭代，受贸易摩擦及供应链博弈影响，新产品订单导入晚于预期，导致境外收入同比下滑2.74%，整体营收仅微增0.59%。
- **[产能扩张与费用前置]** -> [净利润大幅下滑40.95%]: 为服务新客户及海外布局，新增惠州、越南、武汉等多处产线/基地，导致折旧、房产税、人员配置及研发投入等费用前置，严重侵蚀利润。
- **[产品结构变化与原材料涨价]** -> [毛利率承压]: 低毛利的国内业务收入增长24.26%，而高毛利的境外业务下滑，叠加贵金属等原材料价格上涨，综合毛利率从26.67%降至25.09%。
- **[AI眼镜与光模块新业务]** -> [未来增长引擎]: AI眼镜相关产品已实现批量订单交付，光模块产线落地武汉，有望在2026年贡献增量，成为营收增长新引擎。
- **[越南子公司设立]** -> [应对供应链风险]: 为应对国际形势扰动，成立越南孙公司星晟电子，实现海外生产基地零的突破，旨在稳定现有海外大客户并开拓新客户。
- **[单一客户高度依赖]** -> [经营风险集中]: 对第一大客户FCT的销售占比高达71.59%，其供应链策略的任何调整都将对公司业绩产生重大不利影响。
- **[子公司亏损拖累]** -> [合并报表利润承压]: 核心子公司广东则成（PCB制造）和惠州则成（EMS）均处于亏损状态，分别亏损2377万和906万，严重拖累合并净利润。

## 风险警告
**单一客户依赖与供应链博弈风险。** 公司对第一大客户FCT的销售占比高达71.59%，业绩高度绑定。当前海外大客户正进行供应链策略调整，公司需在越南等海外基地与客户博弈，若未能成功留存或开拓新客户，营收将面临断崖式下滑风险。

**新产能爬坡与费用侵蚀利润风险。** 公司正处于产能扩张期，惠州、武汉、越南等多基地同时建设，导致折旧、人工、研发等费用刚性增长。然而，新业务（如光模块、国内客户）尚处良率爬坡或小批量阶段，短期内无法贡献足够利润，导致净利润率从6.59%骤降至3.87%，盈利能力显著恶化。
