# 920571.BJ 深度透视

## 因果逻辑链
- **[绿色运力扩张与老旧船处置]** -> [毛利率提升至23.22%]: 2024-2025年集中交付6艘低碳新船（满负荷运营），同时处置3艘老旧灵便型船，优化船队结构，降低单位成本，推动毛利率同比提升2.88个百分点。
- **[内贸运价上行与运力调配]** -> [内贸收入增长66.57%]: 2025年中国沿海煤炭运价指数（CBCFI）同比上涨13.1%，公司顺势扩充内贸运力，内贸收入达5.30亿元，毛利率提升24.41个百分点，有效对冲外贸运价下行（-24.38%）的冲击。
- **[新造船项目大规模投入]** -> [在建工程激增1917.85%]: 期末4艘89000DWT甲醇双燃料预留散货船及2艘63500DWT散货船在建，在建工程账面价值从0.5亿元飙升至10.08亿元，反映公司正处于运力扩张高峰期。
- **[增值税留抵退税及保证金回收]** -> [经营活动现金流净额暴增413.80%]: 收到增值税留抵退税、出口退税及造船保证金回收等，使经营性现金流净额达4.95亿元，远超净利润（0.28亿元），现金流质量显著改善。
- **[有息负债规模扩大]** -> [财务费用增长46.10%]: 因新造船及融资租赁购入船舶，平均有息负债余额上升，利息费用增加2929万元，财务费用率达9.31%，侵蚀利润。
- **[联营公司天津国能盈利下滑]** -> [投资收益下降58.90%]: 重要参股公司天津国能海运本期盈利水平同比下滑，导致投资收益从1948万元降至800万元，拖累整体利润。
- **[员工持股计划落地]** -> [库存股清零，激励绑定]: 2025年员工持股计划完成非交易过户，81名核心员工认购536.4万股，库存股从2025万元降至0，实现管理层与股东利益深度绑定。
- **[商标侵权诉讼一审败诉]** -> [计提预计负债，营业外支出激增1525%]: 因与中国国航商标纠纷一审判决，公司计提赔偿损失及维权开支，导致营业外支出从19万元增至302万元。

## 风险警告
**高杠杆扩张下的财务脆弱性**：公司资产负债率从2023年的40.12%飙升至2025年的68.92%，有息负债规模大幅膨胀，财务费用同比增长46.10%至9284万元，利息保障倍数仅1.47倍，处于极低水平。当前运力扩张依赖债务融资，若航运市场景气度下行或利率持续高位，公司将面临严峻的偿债压力和利润侵蚀风险。流动比率仅0.37，短期偿债能力极弱，需高度关注现金流对债务的覆盖能力。

**新造船交付与市场错配风险**：公司正处于大规模资本开支周期，在建工程达10.08亿元，未来2-3年将集中交付多艘新船。然而，2026年全球干散货市场面临较大运力交付压力，若需求增长不及预期，新增运力可能导致运价承压，公司可能面临“高投入、低回报”的窘境。同时，甲醇双燃料等绿色船舶的运营经济性尚未得到充分验证，技术路线存在不确定性。

**商标诉讼与关联交易隐患**：与中国国航的商标侵权诉讼一审判决要求部分子公司更名并停止使用特定商标，虽公司称不影响日常经营，但品牌声誉受损及潜在的上诉风险不可忽视。此外，与关联方蓝梦邮乐、蓝梦邮旅的船舶管理业务产生767.5万元应收账款，虽已解除协议但回款存在不确定性，关联交易治理的规范性仍需持续关注。
