# 601811.SH 深度透视

## 因果逻辑链
- **[教育政策调整与人口结构变化]** -> [教材教辅发行收入下降10.20%]: 四川省内中小学学生人数减少及“双减”政策深化，导致教材教辅销售量同比下降7.61%，直接拖累发行分部核心收入。
- **[图书零售市场结构性调整]** -> [出版分部一般图书毛利率下降3.90个百分点]: 内容电商崛起挤压传统渠道，公司为争夺市场份额，在线上渠道采取更激进的定价策略，导致出版业务盈利能力承压。
- **[转制文化企业所得税优惠政策变化]** -> [归母净利润微增1.53%]: 2024年因政策变化转回递延所得税费用，形成高基数；2025年该影响消退，但公司通过处置北京方庄办公楼（资产处置收益7259万元）及金融资产公允价值变动（5874万元）等非经常性损益，对冲了主业下滑，维持了净利润正增长。
- **[四川省唯一中小学教科书发行资质]** -> [教育服务业务护城河稳固]: 公司作为省内教材单一来源采购供货方，与教育厅签订12.64亿元免费教科书采购合同，确保了教育服务业务的基本盘和现金流稳定性。
- **[内容电商渠道高速增长]** -> [线上销售毛利率逆势提升0.35个百分点]: 公司深耕内容电商生态矩阵，凭借“文轩网”等线上平台优势，在整体市场下行中，线上销售毛利率反而提升，部分对冲了线下渠道的萎缩。
- **[持有成都银行、皖新传媒等金融资产]** -> [其他综合收益大幅波动]: 持有的上市公司股权市值受资本市场行情影响，导致其他综合收益税后净额减少1.74亿元，成为影响净资产和股东权益的重要非经营性因素。

## 风险警告
**核心风险在于主业增长乏力与利润结构脆弱性。** 公司2025年营收同比下降4.84%，扣非净利润更是大幅下滑12.11%，表明核心出版发行业务正面临严峻挑战。教育服务业务受人口长期趋势和“双减”政策影响，教材教辅销量持续萎缩；一般图书出版则受困于渠道变革和价格战，毛利率显著下降。公司净利润的“正增长”主要依赖非经常性损益（资产处置、金融资产公允价值变动）和税收政策调整的一次性影响，这种利润结构缺乏可持续性。

**第二大风险来自巨额金融资产带来的业绩波动与估值扭曲。** 公司持有超过25亿元的以公允价值计量的金融资产（包括成都银行、皖新传媒股权及各类私募基金），其市值波动直接冲击其他综合收益和净利润。2025年其他综合收益因此减少1.74亿元，而公允价值变动收益则贡献了5874万元利润，这种“双刃剑”效应使公司业绩高度依赖资本市场表现，偏离了出版传媒主业的价值逻辑，增加了投资者判断公司真实经营状况的难度。
