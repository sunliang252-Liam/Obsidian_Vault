# 600629.SH 深度透视

## 因果逻辑链
- **[房地产开发投资持续下降]** -> [新签合同额大幅下滑]: 2025年房地产开发投资同比下降17.2%，直接导致公司新签合同74.9亿元，同比下降22.2%。
- **[新签合同额下滑与存量合同转化率下降]** -> [营业收入萎缩]: 新签合同减少及项目执行周期拉长，导致营业收入69.76亿元，同比下降17.75%。
- **[核心设计咨询业务营收与毛利率双降]** -> [归母净利润暴跌]: 设计咨询营收同比下降20.41%，毛利率下降1.38个百分点，叠加投资利润减少，归母净利润仅0.72亿元，同比大降81.71%。
- **[业主方资金紧张与付款延迟]** -> [信用减值损失高企]: 行业下行导致客户付款周期延长，公司计提信用减值损失2.31亿元，严重侵蚀当期利润。
- **[所持金融资产公允价值回调]** -> [公允价值变动收益由正转负]: 2024年因国联民生证券换股上市导致公允价值高增，2025年股价回调，产生公允价值变动损失968万元。
- **[利息收入减少]** -> [财务费用由负转正]: 受存款利率持续下调及资金安排策略变化影响，利息收入减少，财务费用从-1417万元升至993万元。
- **[城市更新业务逆势增长]** -> [结构性机会显现]: 城市更新领域新签合同10.36亿元，同比增长10.5%，成为公司唯一增长的业务板块，对冲部分传统业务下滑。

## 风险警告
**核心风险在于行业系统性下行与公司盈利能力的急剧恶化。** 公司核心主业（设计咨询）营收与毛利率双降，叠加投资利润大幅缩水，导致归母净利润暴跌81.71%至仅0.72亿元，扣非净利润更是骤降96.19%至0.11亿元。这并非短期波动，而是行业从增量时代转向存量时代、竞争加剧、设计费率进入下降螺旋的长期趋势。公司新签合同连续两年大幅下滑（2025年同比-22.2%），预示着未来营收基础将进一步被侵蚀。

**财务健康度面临严峻挑战。** 应收账款与合同资产合计高达48.96亿元，占总资产32.01%，而公司全年净利润仅0.77亿元。尽管计提了2.31亿元的信用减值损失，但在业主方资金持续紧张的背景下，坏账风险敞口依然巨大。同时，公司经营活动现金流净额同比下降11.68%至2.02亿元，远低于净利润水平，显示回款压力巨大。此外，公司已终止两个核心募投项目（全国重点区域属地化分支机构和城市数字底座），反映出对未来市场扩张的极度悲观预期，战略收缩信号明确。
