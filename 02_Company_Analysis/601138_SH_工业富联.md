# 601138.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收与利润高增]: 全球云服务商资本开支持续扩张，公司AI服务器及高速交换机订单激增，推动2025年营收同比+48.2%，净利润同比+52%。
- **[产品结构向高价值升级]** -> [盈利能力提升]: AI服务器及800G以上高速交换机等高毛利产品占比提升，带动整体毛利率改善，加权平均ROE提升5.8个百分点至21.65%。
- **[云服务商客户深度绑定]** -> [业绩确定性增强]: 公司与全球头部CSP客户战略协同，承接高价值AI数据中心订单，云服务商AI服务器营收同比增长超3倍。
- **[高速交换机技术迭代]** -> [通信业务新增长极]: 数据中心网络向800G/1.6T演进，公司800G以上高速交换机全年营收同比增幅高达13倍，市占率稳居行业第一。
- **[全球化产能布局]** -> [供应链韧性]: “全球制造、在地服务”策略下，公司在墨西哥、越南等地布局产能，有效应对地缘政治风险，保障交付能力。
- **[研发投入聚焦AI]** -> [技术壁垒巩固]: 新增专利超90%集中于AI算力基础设施、工业大数据与AI融合，直接转化为产品竞争力和利润贡献。

## 风险警告
**现金流恶化与库存高企风险。** 2025年经营活动现金流净额同比暴跌78%至52.4亿元，而同期营收增长48%，净利润增长52%。核心原因是“客户需求强劲，公司备货增加”，导致存货激增77%至1509亿元，占总资产33%。这种“增收不增现”的模式，若AI需求增速放缓或客户订单调整，将面临巨大的存货减值风险，并可能引发流动性压力。

**客户与供应商高度集中风险。** 前五大客户销售额占比高达62%，前五大供应商采购额占比58%，且公司未披露具体名称。这种高度依赖少数核心客户与供应商的商业模式，使其议价能力受限，且任何单一客户或供应商的战略调整、技术路线变更或地缘政治风险，都可能对公司经营造成重大冲击。同时，公司营收以美元结算为主，汇率波动风险显著。
