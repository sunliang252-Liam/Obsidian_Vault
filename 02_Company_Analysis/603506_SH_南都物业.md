# 603506.SH 深度透视

## 因果逻辑链
- **[安邦护卫股价上涨]** -> [归母净利润暴增353%]: 持有安邦护卫股份公允价值变动收益约3,536万元，叠加物业项目增加，使归母净利润从2,190万飙升至9,925万，但扣非净利润仅增11.36%。
- **[主动拓展江浙沪外非住业态]** -> [新签项目结构剧变]: 新签面积中商写项目占比从约38%升至60.61%，江浙沪区域占比从约92%降至76.15%，战略转向非住宅与区域分散化。
- **[降本增效与费用优化]** -> [管理费用与销售费用双降]: 管理费用同比下降13.26%，销售费用下降9.80%，在营收微增3.15%背景下，体现精细化运营成效。
- **[对外投资大幅增加]** -> [投资活动现金流净流出2.97亿]: 投资云象机器人、设立赛智助龙基金等，导致投资活动现金流由正转负，同比骤降237.68%。
- **[预收回款减少]** -> [经营性现金流下降41%]: 经营活动现金流净额从1.79亿降至1.05亿，主要系本期预收款项减少，反映回款压力加大。
- **[物业增值服务成本激增]** -> [增值服务毛利率下降5.82个百分点]: 增值服务收入增14.52%，但成本增26.43%，导致毛利率从约44%降至38.27%，盈利能力承压。
- **[应收账款高企与信用减值]** -> [利润侵蚀]: 应收账款账面余额6.85亿，计提坏账准备1.33亿，全年信用减值损失3,609万，持续吞噬经营利润。

## 风险警告
**核心风险在于利润质量极低，高度依赖非经常性损益。** 2025年归母净利润9,925万中，扣非净利润仅4,547万，占比不足46%。高达5,257万的公允价值变动收益（主要来自安邦护卫股价上涨）是利润暴增的“功臣”，但此类收益不可持续且波动剧烈。一旦安邦护卫股价回调，公司真实盈利能力将暴露无遗，扣非净利润仅微增11.36%才是公司经营的真实底色。

**第二重风险是现金流恶化与应收账款高企的“双杀”困局。** 在营收微增的背景下，经营性现金流却骤降41%，预收回款减少表明对下游客户的议价能力或回款效率正在下降。同时，应收账款账面余额高达6.85亿元，远超全年扣非净利润，且信用减值损失持续扩大。若宏观经济下行或开发商资金链问题加剧，坏账风险将集中爆发，严重冲击资产负债表。公司虽在拓展非住业态，但新业态的应收账款管理难度可能更高，风险不容小觑。
