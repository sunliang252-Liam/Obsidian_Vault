# 003021.SZ 深度透视

## 因果逻辑链
- **[“1+1+1”协同创新体系]** -> [营收增长12.52%]: 整合传动、电机、电控三大核心，从单一零部件供应商转型为集成化解决方案提供商，提升单车配套价值与客户粘性。
- **[智能汽车业务深化]** -> [精密零件营收增长27.41%]: 聚焦智能座舱、线控底盘等高附加值领域，与博世、比亚迪等头部客户深化合作，推动产品结构向功能模组升级。
- **[机器人业务战略布局]** -> [开辟第二增长曲线]: 发布A17/B06/B20系列灵巧手，实现17-20个主动自由度，率先量产并上架销售，抢占人形机器人核心部件商业化先机。
- **[苏州产业园投产]** -> [管理费用增长32.37%]: 华东生产基地建成投产，新增折旧及管理人员薪酬，短期压制利润，但为长期产能释放与区域布局奠定基础。
- **[研发高强度投入]** -> [技术壁垒持续巩固]: 研发费用1.74亿元（占营收10.16%），聚焦灵巧手、eVTOL执行器、车载智能交互等前沿领域，保持行业技术领先。
- **[全球化布局加速]** -> [境外收入下降5.52%]: 泰国、德国、美国子公司筹建中，海外产能尚未释放，短期境外收入承压，但长期有助于优化全球供应链与本地化服务。
- **[产品结构优化]** -> [微型传动系统销量下降40.15%]: 主动放弃低端、低附加值订单，转向高精度、高复杂度产品，实现“量减价升”，毛利率提升2.23个百分点。

## 风险警告
**1. 新产品商业化不及预期风险。** 公司重注机器人灵巧手业务，虽已发布多款产品并宣称量产，但该市场尚处早期，技术路线未定，商业化路径模糊。若下游需求释放不及预期或竞争对手技术突破，巨额的研发投入（1.74亿）可能无法转化为有效收入，导致资产减值与估值回调。

**2. 产能扩张与费用刚性增长风险。** 苏州产业园投产导致管理费用激增32.37%，而泰国等海外基地仍在筹建，短期产能利用率不足将压制毛利率。同时，公司持续高研发投入与人才激励，若营收增速无法覆盖费用刚性增长，将导致盈利能力下滑，净资产收益率（ROE）提升面临压力。
