# 000868.SZ 深度透视

## 因果逻辑链
- **[海外出口爆发]** -> [营收增长25.35%]: 出口销量同比大增152.68%，贡献53.77%营收，成为增长核心引擎。
- **[营收增长但毛利率下降]** -> [扣非净亏损扩大至-9784万]: 出口毛利率仅6.14%，低于内销8.31%，且原材料成本上升33.57%，侵蚀利润。
- **[非经常性损益依赖]** -> [归母净利润亏损5524万]: 依赖坏账转回、政府补助等非经常性收益（4260万）才使亏损收窄，主业造血能力弱。
- **[现金流与利润背离]** -> [经营现金流净额暴增4.36亿]: 主要系销售回款及出口退税增加，但净利润为负，反映营运资金管理改善而非盈利质量提升。
- **[高额受限资金]** -> [资金使用效率低下]: 11.35亿货币资金因承兑汇票及信用证保证金受限，占总资产26.4%，实际可动用资金有限。
- **[新能源转型与竞争]** -> [行业地位承压]: 虽新能源客车销量2604台，但行业竞争加剧，公司6米以上客车销量仅排第7，缺乏规模优势。
- **[历史包袱沉重]** -> [未弥补亏损侵蚀净资产]: 母公司未分配利润-15.03亿，导致连续不分红，净资产同比缩水6.32%。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长高度依赖低毛利的海外出口，而原材料成本刚性上涨，导致毛利率持续下滑。扣非净利润已连续三年为负，主业深陷亏损泥潭。更危险的是，公司账面11.35亿货币资金中，超10亿为受限保证金，实际流动性极其紧张，抗风险能力脆弱。

**资产质量与历史遗留问题构成双重隐患。** 应收账款高达13.73亿，坏账准备计提超5亿，且大量诉讼缠身，回款不确定性极高。母公司巨额的未弥补亏损（-15亿）不仅导致无法分红，更意味着未来数年盈利需优先用于补亏，股东回报遥遥无期。在客车行业竞争白热化的背景下，公司缺乏核心盈利能力和资本补充渠道，持续经营能力面临严峻考验。
