# 001965.SZ 深度透视

## 因果逻辑链
- **[宏观经济与货运需求韧性]** -> [通行费收入承压]: 2025年公路货运量同比+3.4%，但公司控股路段车流量同比-1.8%、通行费收入同比-3.8%，显示宏观增长红利未能完全传导至公司存量路产，部分路段受分流、改扩建及区域经济结构影响。
- **[投资运营主业成本刚性上升]** -> [毛利率下滑]: 投资运营板块收入同比+7.07%，但营业成本同比+20.78%，毛利率同比-7.44个百分点，主要因改扩建业务（成本14.02%）拉低整体毛利，存量路产养护及人工成本刚性增长。
- **[投资收益贡献巨大但波动]** -> [净利润下滑]: 归母净利润46.1亿，同比-13.38%，扣非净利润45.27亿，同比-6.81%。核心原因是2024年有亳阜REIT处置等非经常性收益（约4.65亿），而2025年此类收益大幅减少。
- **[财务费用下降]** -> [利润支撑]: 财务费用同比-15.14%（减少约2.6亿），主要得益于利率下行及债务结构优化，部分对冲了主业盈利下滑的影响。
- **[交通科技新签合同逆势增长]** -> [未来收入储备]: 交通科技板块收入同比-7.04%，但新签合同额突破41亿元，同比+10.67%，区域及新兴业务占比提升，为未来收入转化提供支撑。
- **[智能交通业务高增长]** -> [第二曲线初现]: 智能交通板块收入同比+42.24%，主要受益于“一路多方”平台推广、AI大模型应用落地及ETC相关服务拓展，但体量尚小（占收入4.65%）。
- **[改扩建项目集中投入期]** -> [短期现金流与利润承压]: 京津塘高速改扩建等重大项目进入建设期，2025年改扩建业务收入13.14亿（占收入9.84%），但前期投入大、回报周期长，对当期利润贡献有限。
- **[高分红政策]** -> [股东回报稳定]: 2025年拟每10股派3.73元，加上回购，现金分红总额约28.45亿，分红率约61.7%，维持高分红传统，吸引价值投资者。

## 风险警告
**核心风险在于存量路产盈利能力的持续下滑与巨额资本开支的错配。** 公司控股路段车流量和通行费收入已连续两年下降，且降幅扩大（2025年分别-1.8%和-3.8%），部分路段如平正高速、神佳米高速收入降幅超15%，显示路产自然增长动能衰竭。与此同时，京津塘高速改扩建等重大项目进入集中投入期，2025年资本开支约34亿，未来数年将持续消耗大量现金，导致投资活动现金流净额虽转正（0.28亿），但筹资活动现金流净流出扩大至-56.95亿，财务杠杆压力上升。

**另一重大风险是投资收益的不可持续性与估值依赖。** 公司利润高度依赖参股上市公司（如宁沪高速、皖通高速）的投资收益（占利润总额78.96%），这部分收益受宏观经济、行业政策及资本市场波动影响极大，具有高度不确定性。一旦参股公司业绩下滑或分红减少，将直接冲击公司净利润。此外，公司账面无形资产（主要为收费权）高达831亿，占总资产51.18%，且大部分已质押用于借款，若未来收费政策调整或车流量持续低迷，存在大额减值风险，将严重侵蚀净资产。
