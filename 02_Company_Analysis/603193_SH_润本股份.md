# 603193.SH 深度透视

## 因果逻辑链
- **[线上直销+非平台经销双轮驱动]** -> [营收增长17.19%]: 线上直销营收增长13.56%，非平台经销商营收暴增36.13%，两者合计贡献了主要增量，尤其是线下渠道（山姆、胖东来等）的突破打开了新增长空间。
- **[销售费用率大幅攀升]** -> [净利润增速远低于营收增速]: 销售费用同比增长28.04%，远超营收17.19%的增速，导致归母净利润仅增长4.78%，利润被营销投入严重侵蚀。
- **[婴童护理+驱蚊双核心品类增长]** -> [营收结构稳定]: 婴童护理（+17.86%）和驱蚊（+21.13%）两大品类合计贡献营收87%，驱蚊产品增速更快，显示季节性刚需品类的爆发力。
- **[非平台经销商渠道爆发]** -> [线下渠道突破]: 非平台经销商营收增长36.13%，华南、华中、西南等地区营收增速均超100%，表明公司从纯线上向全渠道转型取得实质性进展。
- **[研发投入低且增速慢]** -> [长期竞争力隐忧]: 研发费用仅占营收2.43%，增速7.19%，远低于销售费用增速，在日化行业竞争加剧背景下，产品同质化风险上升。
- **[精油系列产品衰退]** -> [品类增长分化]: 精油系列营收同比下降11.28%，库存量骤降53.15%，显示该品类需求疲软或公司主动收缩，需关注是否为新品类替代。
- **[产能利用率严重不均]** -> [产能瓶颈与闲置并存]: 浙江工厂产能利用率高达110.51%，而广州工厂仅56.46%，表明产能布局与市场需求错配，未来需关注13亿新项目建设后的消化能力。

## 风险警告
**核心风险在于利润被营销费用吞噬。** 公司营收增长17.19%，但销售费用暴增28.04%，导致净利润增速仅4.78%，增收不增利趋势明显。在日化行业线上流量红利见顶、竞争白热化的背景下，若无法有效控制获客成本，公司盈利能力将持续承压。

**人口结构变化是长期悬顶之剑。** 公司核心品类婴童护理直接受新生儿数量影响，2025年中国出生人口仅792万，较2016年高点下降55.7%。尽管公司通过拓展青少年系列（控油祛痘等）试图覆盖更大年龄层，但转型效果尚需验证，若出生率持续下滑，婴童护理基本盘将面临萎缩风险。
