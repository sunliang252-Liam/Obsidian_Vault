# 301148.SZ 深度透视

## 因果逻辑链
- **[市政业务回款攻坚]** -> [经营性现金流大增60%]: 公司主动优选高质量项目，强化应收账款全周期管理与法律催收，回款效率显著提升。
- **[膜组件及耗材自主化突破]** -> [该业务收入增长13.91%，毛利率提升至45.64%]: 耐酸碱膜、超滤膜等核心膜材料实现自主量产与性能迭代，技术壁垒转化为产品竞争力。
- **[高难度工业废水项目落地]** -> [开辟新增长极]: 连续中标放射性废水处置项目，榆横工业区浓盐水项目投产，验证了公司在高壁垒领域的硬核技术实力。
- **[海外业务模式升级]** -> [海外收入增长6.31%]: 从单纯产品销售转向“产品+服务”一体化交付，成功攻克莫桑比克海水淡化、马来西亚马国油等标杆项目。
- **[扣非净利润下滑26.11%]** -> [核心盈利能力承压]: 营业收入下降8.57%，叠加信用减值损失大幅增加至5384万元，侵蚀了主营业务的利润。
- **[信用减值损失激增]** -> [利润质量风险]: 应收账款坏账准备计提大幅增加，是导致扣非净利润下滑的核心原因，反映出下游客户回款压力。
- **[战略转型聚焦高附加值]** -> [短期业绩承压，长期结构优化]: 公司主动收缩低毛利市政项目，转向工业废水、资源循环等高壁垒赛道，导致营收短期下滑，但为未来盈利质量提升奠定基础。

## 风险警告
**核心风险在于应收账款回收与信用减值。** 公司应收账款余额高达5.96亿元，占总资产26.73%，且信用减值损失同比激增至5384万元，是导致扣非净利润大幅下滑的直接原因。尽管公司通过法律手段强化回款，但下游客户（环保工程商、公共事业单位）的资金状况若持续恶化，将严重侵蚀公司利润，甚至引发流动性风险。

**战略转型期业绩波动风险不容忽视。** 公司主动收缩市政基本盘，转向工业废水、资源循环等高壁垒但周期长、定制化强的领域。这导致膜分离装备收入骤降31.79%，整体营收下滑8.57%。新业务从技术储备到规模化贡献利润仍需时间，期间公司可能面临营收增长乏力与研发投入持续的双重压力。
