# 002206.SZ 深度透视

## 因果逻辑链
- **[越南基地满产满销]** -> [净利润增长25.28%]: 越南一期工业丝项目满产，叠加当地税收优惠，显著提升车用丝盈利能力。
- **[差异化车用丝壁垒]** -> [毛利率提升6.10%]: 安全带丝、气囊丝等高附加值产品技术壁垒高，采用成本加成定价，有效传导原料成本波动。
- **[产业链垂直一体化]** -> [抗风险能力增强]: 自产PET切片、高模低收缩丝用于帘子布，减少中间环节价格与质量波动，协同效益显著。
- **[全球化产能布局]** -> [外销收入增长2.66%]: 越南基地贴近海外客户，规避贸易壁垒，满足本地化交付需求，巩固国际市场份额。
- **[研发投入增长19.91%]** -> [新材料突破]: LCP、PPS等高性能纤维实现吨级销售，高端纺丝油剂突破进口依赖，打开新增长极。
- **[行业供给出清]** -> [盈利韧性增强]: 涤纶工业丝扩产周期结束，落后产能退出，头部企业转向差异化竞争，行业盈利稳定性提升。
- **[股权激励绑定核心团队]** -> [管理层动力]: 2025年推出限制性股票激励计划，覆盖60人，将股东、公司、员工利益深度绑定。

## 风险警告
**1. 原材料与汇率双重波动风险。** 公司主要原料PTA、MEG为石化下游产品，价格受国际油价影响巨大。尽管车用丝采用成本加成定价，但普通丝随行就市，若原料价格剧烈下跌，将导致存货减值与毛利率承压。同时，公司65%以上收入来自海外，美元/欧元结算，汇率波动直接影响利润。2025年公司外汇衍生品投资亏损4501万元，显示对冲成本与风险并存。

**2. 海外扩张与地缘政治风险。** 越南基地是公司核心增长引擎，但面临当地政策变动、劳动力效率及文化整合挑战。中美贸易摩擦及全球关税政策不确定性，可能影响公司产品出口竞争力。此外，越南二期帘子布及聚酯项目尚在建设中，若投产进度不及预期或市场环境变化，将拖累资本回报率。
