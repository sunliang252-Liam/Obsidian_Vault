# 601636.SH 深度透视

## 因果逻辑链
- **[房地产竣工持续下行]** -> [浮法玻璃需求疲软]: 2025年房屋竣工面积同比下降18.1%，直接拖累公司核心产品优质浮法玻璃收入同比下降14.03%。
- **[光伏玻璃产能主动出清与行业自律]** -> [光伏玻璃业务盈利逆势改善]: 行业低效产能退出、价格触底回升，叠加公司新产线投产放量，超白光伏玻璃收入同比增长21.03%，毛利率提升1.16个百分点。
- **[绍兴厂区资产处置完成]** -> [非经常性损益大幅增厚净利润]: 报告期确认资产处置收益4.87亿元，贡献了归母净利润6.19亿元中的绝大部分，扣非净利润仅1.03亿元，同比下滑64.3%。
- **[事业合伙人持股计划未达目标]** -> [管理费用大幅下降]: 因长期计划目标未达成，冲减前期确认费用，管理费用同比减少48.26%，直接推高账面利润。
- **[光伏玻璃新产线集中投产]** -> [财务费用与库存双升]: 新产线陆续运营导致费用化利息增加17.7%，同时光伏玻璃库存量同比大增102.64%，资金占用与财务压力加大。
- **[“旗滨转债”提前赎回与债转股]** -> [资产负债率显著优化]: 完成可转债赎回及转股，资产负债率从58.43%降至53.51%，资本结构改善，但股本扩张稀释了每股收益。
- **[海外产能布局与马币升值]** -> [境外业务高增长与汇兑收益]: 海外收入同比大增85.3%，毛利率高于国内，同时马币升值带来其他综合收益增加1.37倍，全球化布局成效显现。

## 风险警告
**核心风险在于盈利质量严重依赖非经常性损益。** 公司2025年归母净利润6.19亿元，但扣非净利润仅1.03亿元，同比暴跌64.3%。利润的主要来源是绍兴厂区资产处置（贡献约4.42亿元）和管理费用冲回（因股权激励未达标）。剔除这些一次性因素，公司主营的浮法玻璃和节能建筑玻璃业务在房地产下行周期中盈利能力持续恶化，光伏玻璃虽量增但价低，整体造血能力堪忧。

**第二大风险是行业供需失衡与高库存压力。** 浮法玻璃受地产竣工拖累，价格低位震荡；光伏玻璃虽阶段性企稳，但行业整体仍处产能过剩状态，公司光伏玻璃库存量同比翻倍（+102.64%），节能建筑玻璃库存也大增154.85%。若下游需求复苏不及预期，高库存将占用大量资金并引发跌价风险，进一步侵蚀本已脆弱的现金流和利润。公司2026年190亿营收目标能否实现，高度依赖行业景气度反转。
