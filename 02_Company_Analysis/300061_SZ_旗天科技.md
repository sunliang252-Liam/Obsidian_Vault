# 300061.SZ 深度透视

## 因果逻辑链
- **[银行客户营销预算收缩]** -> [数字生活营销收入下降27.90%]: 银行净息差持续承压，导致营销支出周期拉长、选品向低毛利数字商品偏移。
- **[主动终止商品邮购分期业务]** -> [银行卡增值营销收入下降67.51%]: 管理层为聚焦核心主业，战略性放弃低效业务板块，导致收入大幅缩减。
- **[计提坏账损失]** -> [净利润亏损加剧]: 客户回款周期拉长及部分项目落地不及预期，导致信用减值损失达1871万元，成为亏损主因。
- **[研发投入资本化率下降]** -> [当期费用增加]: 研发资本化率从41.11%降至28.62%，更多研发支出计入当期损益，短期压制利润表现。
- **[子公司欧飞优化资产配置]** -> [经营活动现金流净额增长29.86%]: 通过加强应收账款催收和内部现金流管理，四季度回款显著改善，实现正向现金流。
- **[融资规模主动收缩]** -> [筹资活动现金流净流出增加58.98%]: 公司控制整体融资规模，减少借款，导致筹资净流出扩大。
- **[无控股股东、无实际控制人状态]** -> [治理结构不确定性]: 控制权变更（七彩虹皓悦入主）尚待监管审批，期间公司处于权力真空期，战略决策效率可能受限。

## 风险警告
**核心风险：主业萎缩与客户依赖。** 公司两大核心业务——数字生活营销与银行卡增值营销——均面临收入下滑。前者受制于银行客户预算收缩与行业竞争加剧，后者已被主动终止。公司前五大客户销售额占比高达62.15%，对头部银行客户存在严重依赖，一旦核心客户进一步削减预算或更换供应商，业绩将遭受重大冲击。

**控制权变更风险悬而未决。** 公司目前处于无控股股东、无实际控制人状态，向七彩虹皓悦的定增事项尚需深交所审核及证监会注册，能否获批及何时获批存在重大不确定性。在此期间，公司战略方向、管理层稳定性及重大决策效率均可能受到影响，且定增完成后，新股东能否有效整合资源、兑现协同效应仍是未知数。

**资产质量与持续盈利能力隐忧。** 公司连续三年扣非净利润为负，未分配利润高达-20.93亿元，母公司存在未弥补亏损，暂不具备分红条件。尽管经营活动现金流有所改善，但应收账款仍高达3.34亿元，占总资产30%，且部分被用于质押借款。若下游客户信用环境恶化，坏账风险可能进一步侵蚀本已脆弱的净资产。
