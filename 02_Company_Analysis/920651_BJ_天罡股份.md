# 920651.BJ 深度透视

## 因果逻辑链
- **[政策驱动“双碳”与“旧改”]** -> [超声波水表及供热节能管理工程收入大增]: 国家节能减排、老旧管网改造及智慧供热政策持续落地，直接拉动公司核心产品需求，2025年超声波水表收入增长37.36%，供热节能管理工程收入暴增231.76%。
- **[供热节能管理工程业务扩张]** -> [整体毛利率下滑]: 低毛利的供热节能管理工程（毛利率21.22%）收入占比大幅提升，拉低公司综合毛利率从50.02%降至45.51%，侵蚀了高毛利产品带来的利润增量。
- **[应收账款高企与坏账计提]** -> [净利润增速远低于营收增速]: 营收增长17.52%，但净利润仅增3.36%。核心原因是应收账款余额达1.86亿元（占营收52.69%），导致信用减值损失445万元，叠加存货跌价损失增加，严重拖累利润。
- **[募投项目转固]** -> [固定资产大增，产能扩张]: “物联网超声仪表智能生产线项目”完工转固，固定资产同比增长52.89%，为未来产能释放和规模效应奠定基础，但短期折旧压力增加。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比增长83.65%至7298万元，显著高于净利润，主要得益于销售回款改善，表明收入增长具备现金支撑，盈利质量优于利润表表现。
- **[子公司山东天罡能源亏损]** -> [拖累合并利润]: 子公司山东天罡能源科技主营供热节能工程，营收增长但净亏损644万元，显示该业务尚处于投入期或项目毛利较低，是公司整体盈利能力承压的关键点。
- **[股份支付费用持续]** -> [侵蚀净利润]: 报告期确认股份支付费用约493万元，虽属非现金支出，但持续计入管理费用，对净利润形成稳定拖累。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长主要依赖低毛利的供热节能管理工程，导致整体毛利率显著下滑。同时，下游客户（热力公司、水务公司）回款周期长，应收账款高企（1.86亿元，占营收52.69%），信用减值损失持续侵蚀利润。若未来行业竞争加剧导致价格战，或工程业务毛利率无法改善，利润增速将持续落后于营收。

**第二重风险是业务扩张的现金流压力。** 虽然2025年经营现金流改善，但子公司山东天罡能源的亏损表明供热节能工程业务尚需大量资金投入。若该业务持续亏损或应收账款进一步恶化，可能对公司整体现金流造成压力。此外，募投项目转固后折旧增加，若产能利用率不足，将直接拖累资产回报率。
