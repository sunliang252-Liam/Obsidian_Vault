# 002821.SZ 深度透视

## 因果逻辑链
- **[新兴业务（化学大分子/生物大分子）爆发]** -> [收入结构优化]: 新兴业务收入同比增长57.30%，占比从21.13%跃升至28.92%，成为第二增长曲线，对冲小分子业务增速放缓（+3.59%）。
- **[多肽/寡核苷酸/ADC产能扩张]** -> [订单高增]: 截至报告期末在手订单总额13.85亿美元，同比+31.65%，化学大分子订单同比+127.59%，为未来业绩加速增长奠定基础。
- **[降本增效与产能利用率爬坡]** -> [利润率改善]: 新兴业务毛利率同比提升8.45个百分点至30.12%，带动整体经调整净利润同比增长56.09%，远超收入增速。
- **[全球化产能布局（Sandwich Site）]** -> [海外收入增长]: 境外收入49.21亿元，同比+14.85%，恒定汇率下+16.78%，有效应对贸易政策不确定性。
- **[技术驱动型研发平台]** -> [客户粘性与项目深度]: 与全球前20大药企中16家建立合作，服务10家超15年，临床阶段项目达515个，商业化项目59个。
- **[中小制药公司客户拓展]** -> [收入来源多元化]: 来自中小制药公司收入37.55亿元，同比+20.57%，占比提升至56.3%，降低对大客户依赖。
- **[连续化学/光电化学等核心技术突破]** -> [成本与效率优势]: 新技术应用于临床和商业化项目，提升工艺开发效率，降低生产成本，巩固小分子CDMO全球领先地位。

## 风险警告
**核心风险在于新兴业务的高增长能否持续转化为稳定盈利。** 化学大分子、生物大分子等业务虽订单爆发，但毛利率仍显著低于小分子业务（30.12% vs 46.83%），且产能扩张（多肽产能+53%，寡核苷酸+50%）带来持续的资本开支压力。若下游客户需求波动或竞争加剧导致产能利用率不及预期，将拖累整体利润率。

**另一重大风险是地缘政治与贸易环境的不确定性。** 公司约74%收入来自境外，虽已布局Sandwich Site海外产能，但全球贸易摩擦、汇率波动（报告期汇兑收益减少导致财务费用大增80%）以及国际药品监管审查（FDA等）的潜在变化，均可能冲击供应链稳定性和客户订单。此外，公司涉及多起未决诉讼/仲裁，虽已部分胜诉，但仍有案件处于审理阶段，存在潜在财务损失风险。
