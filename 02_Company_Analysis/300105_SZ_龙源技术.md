# 300105.SZ 深度透视

## 因果逻辑链
- **[综合节能改造业务收入大幅下滑]** -> [营收下降24.83%]: 该业务收入同比减少59.16%，是营收下降的核心拖累，因存量改造市场竞争加剧及项目周期波动。
- **[对特定项目应收款单项计提大额信用减值]** -> [净利润由盈转亏]: 对“寿光蔬菜废弃物”及“文水畜禽粪污”项目应收款计提约1亿元信用减值，导致信用减值损失暴增535%，是亏损主因。
- **[参股子公司投资收益锐减]** -> [净利润进一步承压]: 确认国能科环望奎新能源投资收益减少，导致投资收益同比下降94.65%，加剧了利润下滑。
- **[节油业务与低氮燃烧业务高增长]** -> [部分对冲营收下滑]: 节油业务收入增长50.84%，低氮燃烧业务增长69.51%，成为结构性亮点，但体量不足以弥补综合节能改造的缺口。
- **[在手订单同比增长18.84%]** -> [未来收入有支撑]: 期末在手订单11.88亿元，为后续收入确认提供基础，但需关注订单向收入转化的效率。
- **[经营活动现金流净额大幅改善]** -> [现金流质量优于利润]: 经营性现金流净额达2.2亿元，同比增长63.4%，主要得益于回款改善及采购支出减少，显示运营效率提升。
- **[关联交易占比极高]** -> [经营独立性风险]: 向控股股东国家能源集团及其下属单位的销售额占总营收72.18%，业务高度依赖集团内部协同，存在客户集中风险。

## 风险警告
**核心风险在于信用减值与客户依赖的双重打击。** 公司因两个非电领域的BOT项目（寿光、文水）产生巨额应收款并单项计提减值，直接导致2025年由盈转亏。这暴露了公司在向非电、非传统优势领域拓展时，项目风险评估与回款管控能力的不足。若此类项目风险持续暴露，将对公司资产质量和盈利能力构成根本性威胁。

**业务结构脆弱性显著。** 公司72%以上的营收来自国家能源集团内部关联交易，客户高度集中，议价能力受限。同时，核心业务“综合节能改造”收入骤降近60%，而增长较快的节油、低氮燃烧业务天花板明显，难以弥补缺口。公司虽在新能源、储能等方向布局，但短期内难以形成规模替代，业绩增长缺乏第二曲线支撑。
