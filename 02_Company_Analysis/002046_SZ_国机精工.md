# 002046.SZ 深度透视

## 因果逻辑链
- **[风电轴承国产替代加速]** -> [基础零部件收入+24.13%]: 公司突破大功率主轴/齿轮箱轴承核心技术，受益于风电大型化带来的国产替代窗口，风电轴承成为核心增长引擎。
- **[半导体产业需求拉动]** -> [超硬材料磨具收入+16.09%]: 半导体封装用划片刀、减薄砂轮等产品打破国外垄断，受益于国内半导体产业链自主可控需求，持续高位增长。
- **[超硬材料业务股权稀释]** -> [归母净利润-6.96%]: 2025年3月将超硬材料业务注入国机金刚石，公司持股从100%降至67%，少数股东损益增至6492万元，导致归母净利润下滑。
- **[MPCVD大单晶金刚石规模化]** -> [金刚石材料收入+69.77%]: 建成新型高功率MPCVD生产线，产能规模与技术实力国内第一梯队，功能化应用在非民用领域收入超1000万元。
- **[航天特种轴承绝对优势]** -> [特种轴承收入+25.56%]: 公司是卫星及运载火箭专用轴承核心供应商，商业航天常态化发展带来稳定增量，市占率绝对领先。
- **[供应链业务主动压降]** -> [供应链运营收入-23.11%]: 公司承诺未来不从事与主业无关的贸易业务，主动收缩低毛利供应链业务，导致该板块收入下降。
- **[定增及子公司引入战投]** -> [筹资活动现金流净额+200.51%]: 2025年完成向特定对象发行股票及子公司国机金刚石引入河南省新材料投资集团，合计筹资大幅增加。

## 风险警告
**核心风险在于归母净利润与经营现金流背离。** 2025年归母净利润2.60亿元，但经营活动现金流净额为-2.23亿元，同比由正转负（-187.57%），主因采购付款大幅增加。公司应收账款达12.74亿元，存货8.12亿元，两者合计占总资产26%，若下游风电、半导体行业景气度回落，将面临较大的减值压力。2025年资产减值损失高达1.28亿元（占利润总额36.81%），主要来自存货跌价，需警惕库存积压风险。

**超硬材料业务控制权稀释与竞争加剧风险并存。** 公司将核心盈利资产（三磨所）注入国机金刚石并让渡33%股权，虽引入战略资源，但导致归母净利润增速显著低于收入增速。同时，金刚石材料业务面临MPCVD技术路线竞争（热丝法、高温高压法）及培育钻石价格波动风险，非民用领域收入仅超1000万元，产业化进程存在不确定性。此外，公司对中浙高铁的投资已通过破产重整出清，虽一次性确认4000万元投资收益，但反映出参股公司治理风险。
