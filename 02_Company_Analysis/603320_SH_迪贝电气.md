# 603320.SH 深度透视

## 因果逻辑链
- **[可转债全部转股并赎回]** -> [净利润增长20.88%]: 可转债利息费用同比减少1478万元，直接增厚利润，是利润增速远超营收增速的核心原因。
- **[下游需求疲软，存量竞争加剧]** -> [营收下降6.95%]: 冰箱冷柜内销下滑2.7%，中央空调内销下滑7.4%，导致公司电机销量下降1.01%，产品单价亦有所下降。
- **[产品结构优化，大功率商用产品上量]** -> [综合毛利率提升0.31个百分点]: 商用压缩机电机毛利率达19.50%，高于家用电机的10.68%，其占比提升拉高了整体盈利水平。
- **[“成本加成”定价机制]** -> [规避原材料价格波动风险]: 以硅钢、漆包线等原材料价格为基础定价，将成本压力有效传导至下游客户，保障了盈利稳定性。
- **[深度绑定大客户，形成高转换成本]** -> [客户集中度极高]: 前五大客户销售额占比76.41%，其中第一大客户长虹华意占比55.37%，形成强依赖，但也构筑了稳固的供应链壁垒。
- **[“以销定产”与柔性制造体系]** -> [旺季产能创新高]: 面对客户缩短的交付时限，凭借柔性产线和数字化管理，2025年3月单月产量达172万台（套），创历史新高。
- **[可转债转股完成]** -> [净资产大幅增加，ROE被稀释]: 转股增加净资产1.95亿元，导致加权平均净资产收益率同比下降0.9个百分点至7.20%。

## 风险警告
**核心风险在于对单一客户的极度依赖与下游市场萎缩的双重挤压。** 公司超过55%的营收来自长虹华意，且前五大客户占比超76%，客户集中度极高。一旦主要客户经营波动、自建电机产能或切换供应商，将对公司业绩造成毁灭性打击。同时，冰箱冷柜与中央空调内销市场已进入存量甚至下滑阶段，行业竞争白热化，公司营收已连续下滑，增长前景堪忧。

**盈利增长主要依赖非经常性因素，可持续性存疑。** 2025年净利润20.88%的增长，核心驱动力是可转债利息费用的大幅减少，而非主营业务的强劲增长。扣除该因素后，扣非净利润增速仅为16.69%，且营收仍在下降。随着可转债赎回完成，这一利润增厚因素将不复存在，未来业绩增长需完全依赖主业，在需求疲软的背景下，挑战巨大。
