# 300759.SZ 深度透视

## 因果逻辑链
- **[全球新药研发投融资回暖]** -> [新签订单增长14%+]: 客户研发预算恢复，推动实验室服务（+15.78%）和CMC服务（+16.53%）收入双位数增长。
- **[全流程一体化平台协同效应]** -> [客户粘性极强]: 77.44%收入来自使用多板块服务的客户，95.88%收入来自老客户，交叉销售降低获客成本。
- **[海外产能与国际化布局]** -> [海外收入占比84.84%]: 中、英、美三地28个运营实体，满足客户全球申报与生产需求，海外收入同比增长14.67%。
- **[扣非净利润高增38.85%]** -> [主业盈利能力显著修复]: 剔除上年大额非经常性投资收益后，核心业务利润增速远超收入增速，经营质量提升。
- **[商业化生产里程碑突破]** -> [CMC业务价值量跃升]: 首个供应美国市场的商业化API获批，绍兴/宁波车间通过FDA现场检查，打开长期增长天花板。
- **[AI与自动化技术投入]** -> [研发效率提升]: 控股海心智惠（AI患者管理）、佰翱得（结构生物学），推进智慧实验室与无人化合成，巩固技术护城河。
- **[大分子与CGT服务仍处亏损]** -> [拖累整体毛利率]: 该板块毛利率为-40.31%，虽同比改善9.76pct，但仍是公司盈利能力的主要拖累项。

## 风险警告
**核心风险在于地缘政治与行业景气度的双重不确定性。** 公司超80%收入来自海外，其中北美客户占61.82%。若中美贸易摩擦升级或美国出台限制中国CXO行业的法案，将直接冲击核心收入来源。同时，全球生物医药投融资虽回暖但波动性仍存，若再度遇冷，客户可能缩减研发预算，导致新签订单增速放缓。

**大分子和细胞与基因治疗（CGT）业务持续亏损是财务上的重大拖累。** 该板块毛利率为-40.31%，尽管同比改善，但绝对亏损额巨大，且产能爬坡和商业化验证仍需时间。若该业务长期无法实现盈亏平衡，将持续侵蚀公司整体利润，并占用大量资本开支，影响自由现金流。
