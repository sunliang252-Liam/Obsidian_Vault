# 300237.ST 深度透视

## 因果逻辑链
- **[聚焦非轮胎橡胶主业，剥离园林亏损资产]** -> [营收微增5.54%，但净利润仍亏损4.02亿元]: 核心主业汽车配件收入增长13.92%，但园林业务收缩、刚性成本持续及大额资产减值（-1.47亿）拖累整体盈利。
- **[园林业务回款周期长、资金占用严重]** -> [计提大额资产减值损失，侵蚀当期利润]: 行业性回款困难导致应收账款和合同资产减值，是亏损主因。
- **[有息负债规模虽下降，但财务费用仍高企]** -> [财务费用1.4亿元，压制利润释放]: 尽管融资规模下降54.29%，但存量债务利息支出仍对盈利构成显著负担。
- **[非轮胎橡胶业务受益于新能源与商用车复苏]** -> [橡胶制品收入增长16.24%，减振类产品销量增长35.85%]: 新能源汽车渗透率提升及商用车市场回暖，带动核心产品需求。
- **[通过债权债务重组剥离园林资产]** -> [净资产由1192万增至5465万，改善资产负债表]: 将89.98亿元应收账款/合同资产转让给控股股东，换取债务清偿，显著增厚净资产。
- **[经营性现金流大幅转正]** -> [经营活动现金流净额2.39亿元，同比+549.85%]: 园林业务收缩减少现金支出，核心主业现金流改善。
- **[研发投入聚焦新能源与智能悬架]** -> [储备氢能管路、电控空气悬架等前沿技术]: 持续研发投入（7416万元）旨在卡位新能源热管理、智能悬架等高增长赛道。

## 风险警告
公司当前最大风险在于**园林业务剥离的不确定性**。尽管已启动赛石园林100%股权出售，但交易尚需审批，若失败，园林业务的持续亏损、高额负债及诉讼（117项未结案）将长期拖累公司，甚至引发退市风险。审计报告已对此出具带强调事项段的无保留意见，强调剥离事项的重大不确定性。

其次，**财务与合规风险交织**。公司累计未弥补亏损高达36亿元，净资产仅5465万元，且存在5,188.64万元逾期借款，偿债能力极度脆弱。同时，因2014-2018年财务造假被证监会处罚，公司股票被实施其他风险警示（ST），市场信誉受损，再融资能力受限。核心主业虽增长，但毛利率仅12.75%，难以覆盖高昂的财务费用和减值损失，盈利拐点尚未到来。
