# 300318.SZ 深度透视

## 因果逻辑链
- **[集采降价]** -> [HPV检测产品收入锐减34.74%]: 安徽省际联盟集采2025年全面执行，HPV试剂终端售价被大幅压低，直接导致该核心产品收入从1.1亿降至0.72亿。
- **[业务合作终止补偿及资产减值]** -> [净利润巨亏9192万元]: 支付合同终止补偿款，并对存货、开发支出、在建工程计提大额减值准备（合计约8029万元），是导致全年由盈转亏的直接财务原因。
- **[静注人免疫球蛋白收入下滑]** -> [生物制品板块增长停滞]: 静丙收入同比大降37.34%，抵消了人血白蛋白（+26.3%）和其他生物制品（+51.3%）的增长，导致生物制品整体收入仅微增0.65%。
- **[云南血制工厂搬迁进度滞后]** -> [血浆库存积压与产能瓶颈]: 云南新工厂的人白和静丙变更申请仍在CDE审评中，未能如期投产，导致原料血浆库存持续累积，加工能力受限。
- **[新浆站获批与采浆量微增]** -> [规模效应尚未显现]: 浆站数量增至21家，但全年采浆量仅增长2.38%至421.85吨，远低于行业龙头，规模优势未形成，单位成本居高不下。
- **[非医用质谱产品欧洲推广]** -> [检验检测业务的结构性亮点]: 小型台式质谱仪（CMS）在欧洲市场推广顺利，收入同比增长11.45%，部分对冲了国内IVD业务的下滑。
- **[经营性现金流大幅净流出]** -> [资金链承压]: 经营活动现金流净额为-1.35亿元，同比恶化249%，主因收入下降、回款减少及支付补偿款，公司造血能力严重不足。
- **[关联方借款与高额担保]** -> [财务风险敞口扩大]: 公司向关联方君正科技大额借款（期末余额约5.1亿），并为子公司提供高达18.65亿元的担保，财务杠杆和关联交易风险显著上升。

## 风险警告
**核心风险在于“集采冲击”与“产能瓶颈”的双重挤压。** HPV检测产品作为检验检测业务的利润支柱，在集采降价后收入锐减，且短期内看不到价格回升的可能，该业务已从“现金牛”变为“拖累项”。与此同时，血液制品业务的核心矛盾——云南新工厂迟迟无法投产，导致血浆加工能力受限，大量原料血浆只能以存货形式积压，无法转化为收入和利润。这两个问题不解决，公司基本面难以根本好转。

**财务风险正在加速暴露。** 公司已连续两年扣非净利润为负，2025年更是录得上市以来最大亏损。经营活动现金流大幅净流出，表明主营业务已无法自我“造血”。为维持运营，公司不得不依赖关联方借款（期末余额超5亿）和大规模银行授信，导致资产负债率攀升，财务费用高企。一旦外部融资环境收紧或关联方支持减弱，公司将面临严峻的流动性危机。
