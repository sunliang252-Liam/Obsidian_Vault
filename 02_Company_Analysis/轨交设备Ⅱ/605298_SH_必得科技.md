# 605298.SH 深度透视

## 因果逻辑链
- **[高铁动车组招标量超预期]** -> [营收增长16.24%]: 2025年国铁集团动车组累计采购278组，超过2024年全年245组，直接拉动公司动车组配套产品收入同比大增45.55%。
- **[“产品制造+维保服务”协同布局]** -> [净利润增长46.13%]: 通过收购京唐德信、合圣凯达切入维保领域，形成全生命周期服务能力，子公司合圣凯达超额完成业绩承诺（完成率126.76%），贡献显著利润增量。
- **[经营活动现金流大幅转正]** -> [现金循环效率改善]: 经营活动现金流净额从-5016万元大幅转正至1.53亿元，主因上期末未到期票据于本期到期托收到账，显著改善了现金回收节奏。
- **[客户高度集中]** -> [业绩依赖单一产业链]: 前五大客户销售额占比高达94.42%，其中中国中车系客户占73.32%，公司增长高度绑定下游整车龙头的采购节奏与招标政策。
- **[资产减值损失激增]** -> [利润质量承压]: 2025年资产减值损失达3180万元，同比大增138.5%，主要来自存货跌价准备，反映出部分产品库存面临技术迭代或订单变更带来的跌价风险。
- **[研发投入持续增长]** -> [技术壁垒加固]: 研发费用同比增长14.14%至2910万元，公司拥有百余项专利，持续投入智能撒砂、障碍物检测等系统研发，巩固“专精特新小巨人”技术护城河。
- **[股权激励与股份支付]** -> [核心团队绑定]: 2023年限制性股票激励计划第二个解除限售期条件成就，报告期内确认股份支付费用约1489.76万元，有效激励管理层与核心技术人员。

## 风险警告
**客户集中度极高，业绩受单一产业链波动影响巨大。** 公司超94%的收入来自前五大客户，其中中国中车系占比超73%。这种“抱大腿”模式在行业景气时能快速放量，但一旦国铁集团或中车调整采购策略（如联合招标、压降成本），公司将面临订单骤减和议价能力被削弱的双重打击，业绩弹性实质上是下游龙头的“影子”。

**资产减值风险显著攀升，利润含金量存疑。** 2025年资产减值损失高达3180万元，是净利润的56%，主要源于存货跌价。公司产品具有“多品种、小批量、定制化”特点，一旦客户项目变更或技术路线切换，定制化库存极易成为沉没成本。叠加应收账款高达4.31亿元（占总资产32.5%），若下游回款放缓，减值压力将进一步侵蚀利润。
