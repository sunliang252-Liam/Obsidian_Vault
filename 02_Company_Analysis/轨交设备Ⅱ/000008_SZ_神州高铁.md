# 000008.SZ 深度透视

## 因果逻辑链
- **[资产减值集中爆发]** -> [净利润巨亏8.35亿元]: 2025年计提商誉、长期股权投资等资产减值准备7.98亿元，是导致亏损的核心原因，远超营收增长带来的正面影响。
- **[运营维保服务高增长]** -> [营收结构优化]: 轨道交通运营维保服务收入同比增长72.69%，占总营收比重提升至12.68%，成为对冲装备业务下滑的新增长极。
- **[成本费用精细管控]** -> [经营效率提升]: 销售费用、管理费用、财务费用合计同比下降约12%，有效缓解了营收增长乏力对利润的侵蚀。
- **[新签合同保持稳定]** -> [未来营收基础稳固]: 2025年新签合同金额达25.53亿元，超过当年营收，为后续收入确认提供了保障。
- **[研发投入持续加大]** -> [技术壁垒构筑]: 研发投入同比增长10.05%至1.81亿元，聚焦AI、机器人等智能装备，旨在巩固行业技术领先地位。
- **[长账龄应收账款回收]** -> [资产质量改善]: 一年以上应收账款年末余额较上年减少1.71亿元，降幅11.27%，表明回款管理取得成效，降低了坏账风险。
- **[有息负债结构优化]** -> [财务风险降低]: 短期借款减少，长期借款增加，带动财务费用同比下降16.71%，优化了债务期限结构，增强了财务稳健性。

## 风险警告
公司最大的风险在于**巨额商誉与长期股权投资带来的持续减值风险**。截至2025年末，商誉账面价值仍高达17.03亿元，长期股权投资10.51亿元，合计占净资产的125%。若未来子公司经营业绩不达预期，或参股项目无法实现预期收益，将再次引发大规模资产减值，对利润表造成毁灭性打击。这已是连续第三年巨额亏损，核心原因均在于此，表明历史并购整合的“后遗症”远未消除。

其次，**公司造血能力与偿债压力存在显著矛盾**。尽管营收微增，但经营活动现金流净额同比大幅下降51.55%至1.77亿元，而公司有息负债（短期+长期+一年内到期）高达35.5亿元，且母公司未分配利润亏损高达28.6亿元，已不具备现金分红能力。在融资环境收紧或经营现金流持续恶化的背景下，公司面临较大的流动性风险和债务违约风险。
