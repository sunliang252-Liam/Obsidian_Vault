# 605001.SH 深度透视

## 因果逻辑链
- **[动车组及城轨地铁车辆配套产品订单增加]** -> [营收增长16.77%]: 国内高铁及城轨建设持续推进，公司作为核心供应商，订单量显著增加，直接拉动主营业务收入。
- **[境外高毛利产品结构占比提升及运费下降]** -> [境外毛利率增长8.74个百分点]: 公司聚焦欧盟等高端市场，获取西门子、阿尔斯通等大额订单，同时海外运费下降，共同推高境外业务盈利水平。
- **[城轨地铁车辆配套产品销售结构优化]** -> [该业务毛利率增长11.34个百分点]: 高附加值产品占比提升，使得城轨地铁配套业务在收入增长57.06%的同时，毛利率大幅改善。
- **[汇率变动导致汇兑收益增加]** -> [财务费用下降35.89%]: 人民币汇率波动产生汇兑收益，有效降低了公司的财务费用总额。
- **[新能源汽车配套产品单位固定费用分摊高]** -> [该业务毛利率为-23.05%]: 订单减少导致产能利用率不足，单位产品分摊的固定费用过高，致使该业务持续亏损。
- **[收到客户回款减少，支付税费及汇票保证金增加]** -> [经营活动现金流净额为负]: 尽管利润增长，但回款节奏放缓及保证金支出增加，导致经营性现金流大幅恶化至-2888.7万元。
- **[子公司科达电气亏损]** -> [拖累合并净利润]: 科达电气（含富氧健康舱业务）亏损4229万元，成为公司利润的主要侵蚀点，抵消了部分主业增长带来的利润。
- **[商誉减值测试]** -> [计提商誉减值2598万元]: 对收购成都畅通形成的商誉进行减值测试，基于未来现金流预测计提减值，反映了对子公司未来盈利预期的审慎调整。

## 风险警告
**核心风险在于“增收不增利”的现金流困境与新兴业务的持续失血。** 公司2025年净利润增长55%，但经营活动现金流净额却由正转负，骤降至-2888万元。这直接揭示了利润增长的“纸面化”问题：营收增长并未带来同等的现金回流，反而因回款放缓、保证金增加而加剧了资金链压力。同时，公司大力发展的富氧健康舱（子公司科达电气亏损4229万）和新能源汽车配套（毛利率-23%）两大新业务均处于严重亏损状态，持续消耗主业利润，战略转型成效堪忧。

**客户高度集中与产品降价压力构成双重挤压。** 公司超53%的营收依赖单一客户中国中车，议价能力极弱。年报明确提示下游主机厂持续要求产品降价，而公司原材料成本波动风险犹存。在“客户强势压价”与“成本刚性”的夹缝中，公司毛利率面临持续下滑风险。一旦核心客户订单或价格政策发生不利变动，公司业绩将遭受剧烈冲击。
