# 688187.SH 深度透视

## 因果逻辑链
- **[新兴装备业务高速增长]** -> **营收与利润双创新高**: 半导体、汽车、新能源等新兴装备板块收入同比增长26.35%，占总收入44.5%，成为超越传统轨交业务的增长主引擎。
- **[轨道交通牵引系统市占率绝对领先]** -> **传统主业稳盘压舱**: 城轨牵引系统市占率连续14年第一（2025年达60.92%），叠加国铁投资增长，轨交板块收入稳增7.99%，提供稳定现金流。
- **[功率半导体IDM模式全产业链优势]** -> **半导体业务爆发**: 拥有芯片-模块-装置-系统完整产业链，乘用车功率模块装机量市占率13.8%（行业第二），IGBT在轨交、电网领域国内第一，驱动半导体收入增长30.43%。
- **[SiC产线投产与第四代芯片突破]** -> **抢占下一代技术制高点**: 株洲8英寸SiC产线拉通，第四代沟槽栅SiC MOSFET芯片比导通电阻≤2毫欧平方厘米（国际领先），为新能源车、光伏等高端市场打开增长空间。
- **[“器件+系统+整机”协同效应]** -> **新兴业务全面开花**: 依托轨交领域积累的变流与控制核心技术，向光伏逆变器（中标18GW）、电驱系统（装机量行业前列）、深海ROV（全球半壁市场）等赛道成功延伸，形成六大板块均衡发展格局。
- **[海外市场突破]** -> **打开第二增长曲线**: 海外收入同比增长43.50%，中标亚洲、美洲等多个轨交项目，中车电驱印尼基地投产，海外布局加速。
- **[研发高强度投入与人才储备]** -> **技术壁垒持续加固**: 研发投入占营收11.07%，研发人员占比42.43%，拥有中国工程院院士领衔的团队，确保在永磁牵引、SiC、自动驾驶等前沿领域保持领先。

## 风险警告
**核心风险在于新兴装备业务的盈利质量与竞争烈度。** 尽管新兴板块收入增长迅猛（+26.35%），但其毛利率仅为23.78%，远低于轨交板块的41.35%，且同比下滑1.24个百分点。新能源汽车电驱、光伏逆变器等领域价格战白热化，行业“内卷”严重，公司面临“增收不增利”的困境，盈利能力承压。若价格战持续或成本控制不力，将显著侵蚀整体利润空间。

**另一重大风险是传统轨交主业增长的天花板。** 报告明确指出，国家铁路投资增速放缓，城轨建设从“增量抢夺”转向“存量博弈”，市场空间趋于饱和。公司轨交业务高度依赖国铁集团及关联方（前五大客户中关联方销售占比37.62%），若未来基建投资不及预期或关联交易政策变化，传统主业将面临增长乏力甚至下滑的风险，对公司业绩的“压舱石”作用构成挑战。
