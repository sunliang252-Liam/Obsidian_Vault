# 688009.SH 深度透视

## 因果逻辑链
- **[铁路投资维持高位]** -> [铁路板块收入增长13.67%]: 2025年全国铁路固投超9000亿元，公司作为高铁列控系统绝对龙头，直接受益于新建和改造项目订单释放。
- **[主动退出市政房建]** -> [工程总承包收入下降12.55%]: 公司战略聚焦主责主业，收缩低毛利、高风险的非核心业务，导致该板块收入持续下滑。
- **[低空经济战略布局]** -> [新签低空合同1.65亿元]: 依托轨道交通控制核心技术，向低空空域管控、无人机巡检等场景延伸，开辟第二增长曲线，但尚处早期。
- **[海外市场拓展受挫]** -> [海外新签合同下降33.9%]: 部分目标国政治不稳、财政紧张，叠加国际竞争对手整合，导致海外项目落地难度加大，收入与毛利率双降。
- **[研发投入持续加码]** -> [研发费用增长10.02%]: 公司为巩固技术护城河并布局低空、5G-R、自主化列控等前沿领域，研发投入强度提升至6.49%。
- **[客户回款放缓与供应商付款加速]** -> [经营性现金流大幅转负]: 销售商品收到的现金减少，同时积极履行央企责任加大对中小供应商支付，导致经营活动现金流净额同比暴跌124.71%。
- **[城轨新建市场趋缓]** -> [城轨新签合同逆势增长4.97%]: 面对行业投资放缓，公司凭借全产业链优势，在更新改造市场（如上海1号线改造）实现突破，以存量改造对冲新建下滑。

## 风险警告
**核心风险在于现金流恶化与应收账款高企。** 2025年经营活动现金流净额由正转负，骤降至-12.94亿元，剔除财务公司存款变动后仍同比大降71.66%。公司应收账款与合同资产合计超578亿元，占总资产近49%，且部分项目结算缓慢、回收期长，若地方政府化债不及预期，将直接侵蚀利润并引发流动性压力。

**第二增长曲线尚存不确定性。** 低空经济新签合同仅1.65亿元，占总量不足0.4%，产业成熟度低、商业模式未定型，短期内难以贡献实质性利润。同时，海外业务受地缘政治和竞争加剧影响，毛利率大幅下滑7.9个百分点，国际化战略推进面临阻力。传统主业面临新建市场萎缩与改造市场释放节奏不确定的双重挤压。
