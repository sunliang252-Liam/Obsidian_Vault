# 300196.SZ 深度透视

## 因果逻辑链
- **[新建产能完整年度释放]** -> [玻纤及制品销量同比+30.14%]: 60万吨基地一期15万吨产线于2024年投产，2025年贡献完整年度产量，推动规模效应显现。
- **[下游风电、新能源汽车需求旺盛]** -> [高附加值产品销量提升]: 风电新增装机同比+51%、新能源汽车产量+25.1%，拉动超高模量玻纤、热塑纱等高端产品需求。
- **[“制品化、高端化”战略]** -> [产品结构优化，盈利韧性增强]: 短切毡、湿法薄毡等细分龙头产品占比提升，规避传统玻纤产品同质化价格战。
- **[子公司天马集团化工业务协同]** -> [化工板块利润快速提升]: 不饱和聚酯树脂产销两旺，与玻纤主业形成“玻纤+化工”双轮驱动，对冲原材料价格波动。
- **[行业结构性复苏]** -> [公司营收/利润双增，与行业趋势匹配]: 2025年行业利润总额同比+78.4%，公司扣非净利润同比+31.05%，受益于高端产品量价齐升。
- **[集中采购与柔性制造]** -> [成本控制有效，毛利率稳定]: 规模效应与管理优势叠加，在能源价格波动背景下，玻纤及制品毛利率仅微降0.69%。
- **[可转债转股及银行借款增加]** -> [财务费用同比+1599.42%]: 利息收入减少及汇兑损失增加，叠加短期借款从0.2亿增至3.85亿，财务杠杆上升。

## 风险警告
**1. 现金流恶化与债务结构风险。** 2025年经营活动现金流净额同比骤降68.82%至1.4亿元，远低于3.26亿元的净利润，主因是定期存款增加及营运资金占用。同时，短期借款从2000万激增至3.85亿，一年内到期的非流动负债从1.93亿飙升至9.15亿（含可转债），短期偿债压力陡增。流动比率从2.07降至1.44，速动比率从1.87降至1.30，流动性安全垫显著收窄。

**2. 行业结构性分化与产品价格风险。** 行业复苏并非全面回暖，传统中碱纱、热固直接纱价格持续走低、库存积压。公司虽聚焦高端制品，但若下游风电、新能源车需求增速放缓，或高端产品研发不及预期，将面临传统产品价格承压与高端市场竞争加剧的双重挤压。此外，国际贸易摩擦（反倾销、关税）及汇率波动可能冲击海外业务（占营收20.1%）。
