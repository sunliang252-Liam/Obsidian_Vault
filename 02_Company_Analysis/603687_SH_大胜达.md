# 603687.SH 深度透视

## 因果逻辑链
- **[精品烟包业务高增长]** -> [净利润承压]: 精品烟包收入同比+42%，但计提资产减值损失增加3170万元，导致扣非净利润同比-38%。
- **[原纸价格低位震荡]** -> [毛利率改善]: 纸包装行业毛利率同比+1.44个百分点，受益于成本端压力缓解。
- **[高端装备交付验收]** -> [收入确认]: 杭州思密得交付首台商业化设备，高端装备收入同比+43%，但收入确认滞后于生产周期。
- **[环保餐具海外受阻]** -> [业务亏损]: 美国“双反”调查导致出口订单谨慎，环保餐具毛利率为-18%，子公司海南大胜达亏损2654万元。
- **[泰国基地战略投资]** -> [全球化布局]: 投资1.88亿元建设泰国纸包装基地，规避贸易壁垒并服务出海客户，预计2026年投产。
- **[数字化平台赋能]** -> [效率提升]: E-pack ET平台上线企业超1.5万家，AI设计平台“X-FUN”用户突破40万，将设计周期从15天缩短至1小时。
- **[收购四川中飞20%股权]** -> [增厚业绩]: 持股比例升至80%，四川中飞2025年扣非净利润5531万元，完成业绩承诺（4600万元）。

## 风险警告
**核心风险在于环保餐具业务的持续亏损与海外扩张的不确定性。** 美国“双反”调查导致纸浆模塑餐具出口受阻，子公司海南大胜达亏损2654万元，公司已暂停二期设备投入并将资金转向泰国项目。泰国基地作为首次海外自主建设项目，面临跨文化管理、属地合规及供应链配套等运营风险，投产进度与盈利能力存在较大不确定性。

**第二重风险来自资产减值与商誉压力。** 报告期内计提资产减值损失同比增加3170万元，是利润下滑的主因。公司通过收购形成的商誉若未来子公司（如杭州思密得）业绩未达预期，将面临进一步减值风险。此外，高端装备业务仍处投入期，杭州思密得2025年亏损4556万元，短期难以贡献利润。
