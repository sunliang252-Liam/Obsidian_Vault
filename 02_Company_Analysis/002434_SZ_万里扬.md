# 002434.SZ 深度透视

## 因果逻辑链
- **[乘用车市场新能源渗透率提升]** -> [CVT需求萎缩]: 燃油车市场被挤压，导致公司核心产品CVT自动变速器销量及收入下降，乘用车变速器业务收入同比减少3.3亿元。
- **[减持浙大网新股份及万里扬能源公司股权被动稀释]** -> [非经常性损益暴增]: 公司通过减持股票获得投资收益1.19亿元，并因丧失对万里扬能源公司控制权，按公允价值重新计量确认投资收益2.13亿元，合计贡献非经常性损益3.32亿元。
- **[扣非净利润巨亏]** -> [主业盈利能力恶化]: 剔除上述非经常性收益后，公司扣非净利润为-9175.75万元，同比下降141.67%，核心主业已陷入亏损。
- **[商誉减值]** -> [利润侵蚀]: 因乘用车变速器业务经营业绩低于预期，公司计提商誉减值准备8272.58万元，直接吞噬当期经营利润。
- **[产能搬迁与客户降价]** -> [成本上升与毛利压缩]: 商用车变速器业务搬迁至新厂区导致搬迁费用、维修费用等成本增加，叠加客户降价和原材料涨价，进一步压缩了主营业务的利润空间。
- **[商用车变速器销量增长]** -> [结构性亮点]: 轻微卡变速器销量同比增长16%，重卡智慧星AMT销量同比增长448%，部分对冲了乘用车业务的颓势。
- **[新业务开始量产]** -> [未来增长点]: 非公路车辆传/驱动系统（农机动力换挡、工程机械传动）及机器人零部件业务开始批量化交付，标志着公司多元化转型进入产业化阶段。

## 风险警告
公司2025年扣非净利润为-9175.75万元，核心主业已陷入实质性亏损。利润表上的盈利完全依赖减持金融资产和子公司股权被动稀释带来的非经常性损益，这种盈利模式不可持续。乘用车CVT业务作为公司曾经的利润支柱，正面临新能源渗透率提升带来的结构性需求萎缩，且已引发商誉减值，未来该业务板块的经营压力将持续存在。

公司正经历痛苦的业务转型期，传统业务下滑与新业务尚未形成规模效应，导致业绩出现真空。商用车业务搬迁带来的成本阵痛、新业务（非公路、机器人）的产业化初期投入，以及客户降价压力，均对短期盈利能力构成压制。若新业务放量不及预期，或传统业务下滑速度加快，公司业绩存在进一步恶化的风险。
