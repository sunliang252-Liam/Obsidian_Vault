# 002795.SZ 深度透视

## 因果逻辑链
- **[阀门管件外销收入下滑]** -> [营收下降16.70%]: 美国关税政策收紧导致订单丢失，阀门管件销售量同比下降24.03%。
- **[医疗业务大幅收缩]** -> [营收下降43.59%]: 公司主动缩减肿瘤精准放射治疗业务，挂牌转让多家医院股权，导致该板块收入锐减。
- **[长期资产减值]** -> [净利润亏损1.4亿]: 报告期内计提资产减值损失7078万元，叠加医疗业务高额折旧摊销，是亏损主因。
- **[光伏业务停摆]** -> [营收归零]: 子公司普乐科技光伏电池片业务2025年处于停业状态，产生大额亏损，公司已启动股权转让。
- **[阀门智能化转型]** -> [在建工程激增]: 芦浦新厂区智能化生产线建设接近尾声，在建工程同比增加5.3个百分点，资本开支承压。
- **[经营活动现金流改善]** -> [现金流净额转正]: 通过压缩采购支出和减少库存，经营活动现金流净额从-5073万大幅改善至1.01亿。
- **[美国市场大客户优势弱化]** -> [核心竞争力下降]: 中美贸易摩擦导致高额关税，公司明确承认美国市场大客户优势正在逐步下降。

## 风险警告
公司核心风险在于**主营业务萎缩与转型不确定性**。阀门管件外销占营收90%，但美国关税政策持续收紧，订单丢失风险加大，大客户优势正在丧失。同时，公司盲目跨界的光伏业务已完全停摆，医疗业务也在大幅收缩，多元化战略失败导致连续三年巨额亏损，净资产已从7.9亿缩水至3.8亿。

**财务风险高企**。母公司未弥补亏损高达7.05亿元，已超过实收股本三分之一，公司连续三年不满足现金分红条件。短期借款同比增加5.25个百分点，其他应付款增加3.42个百分点，叠加固定资产和长期股权投资被大量用于抵押或司法冻结，公司流动性压力与偿债风险不容忽视。
