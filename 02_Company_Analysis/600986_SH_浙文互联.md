# 600986.SH 深度透视

## 因果逻辑链
- **[收购星巢网络]** -> [归母净利润含金量提升]: 星巢网络贡献归母净利润3,572万元，占全年归母净利润的42%，成为利润核心增量来源。
- **[持有豆神教育股票]** -> [非经常性损益占比畸高]: 公允价值变动收益6,519万元，占利润总额的64%，扣非净利润仅1,655万元，主业盈利能力极弱。
- **[字节系采购依赖]** -> [毛利率承压]: 向字节系采购额43.47亿元，占年度采购总额54.52%，上游议价能力弱，数字营销业务毛利率被持续压缩。
- **[商誉高企]** -> [减值风险悬顶]: 商誉账面价值13.44亿元，占净资产26%，本期已计提减值2,654万元，若子公司业绩不达预期，减值将直接冲击利润。
- **[算力基建投入]** -> [资产结构重型化]: 固定资产从658万元激增至3.60亿元，主要系购买算力设备，公司从轻资产营销商向重资产运营商转型。
- **[财务费用激增]** -> [杠杆扩张侵蚀利润]: 财务费用从293万元飙升至2,895万元，增幅888.52%，主因银行贷款规模扩大，利息支出7,393万元吞噬利润。
- **[应收账款高企]** -> [信用减值持续拖累]: 应收账款账面余额38.51亿元，坏账准备6.96亿元，信用减值损失1.95亿元，回款压力巨大，现金流改善但应收风险未解。

## 风险警告
**主业空心化与利润结构脆弱。** 公司扣非净利润仅1,655万元，核心数字营销业务在字节系强势挤压下毛利率极低，利润严重依赖豆神教育股票的公允价值变动（6,519万元）和星巢网络并表（3,572万元）。一旦股价波动或星巢网络业绩承诺（三年累计2.4亿元）未达标，利润将大幅缩水。2025年Q4单季归母净利润亏损4,110万元，已显疲态。

**商誉与应收账款双重减值炸弹。** 13.44亿元商誉悬顶，占净资产26%，本期已开始计提减值。同时，38.51亿元应收账款中坏账准备高达6.96亿元，信用减值损失1.95亿元，表明客户回款困难。公司虽通过并购星巢网络和布局算力寻求转型，但新业务尚在培育期，旧业务风险未出清，资产质量堪忧。
