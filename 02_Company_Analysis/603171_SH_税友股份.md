# 603171.SH 深度透视

## 因果逻辑链
- **[AI产品商业化落地]** -> [数智财税业务收入增长12%]: AI产品及业务回款4.21亿元，同比增长60%，驱动收入结构向高价值服务升级。
- **[生态化平台模式创新]** -> [付费用户增长15%]: 平台付费用户达815万户，生态机构伙伴增长19%，用户黏性与付费意愿持续提升。
- **[数字政务战略转向“效益导向”]** -> [政务业务毛利率提升7个百分点]: 聚焦高价值项目、强化全流程闭环管理，盈利指标显著改善。
- **[合同负债增长21%]** -> [未来收入可持续性增强]: 数智财税业务合同负债达8.05亿元，为后续收入确认提供坚实保障。
- **[“犀友”垂域大模型技术壁垒]** -> [AI产品高价值转化]: 解决通用大模型知识缺失与AI幻觉问题，支撑财赢Agentic数智工场落地，重构服务交付机制。
- **[金税四期项目攻坚]** -> [巩固数字政务核心供应商地位]: 支撑新电局、税智撑等全国推广，持续获取高价值项目订单。
- **[销售费用增长22.31%]** -> [扣非净利润增速低于归母净利润]: 市场拓展投入加大，侵蚀部分利润，扣非净利润仅增长7.96%。

## 风险警告
**核心风险在于AI商业化兑现的不确定性。** 公司AI产品回款虽增长60%，但占数智财税业务回款仅28%，且销售费用激增22.31%远超收入增速，表明高价值服务推广仍依赖大量投入。若AI产品无法持续提升付费转化率或客户留存，高额营销投入将严重拖累利润。

**数字政务业务面临财政预算收紧与项目周期波动的双重压力。** 公司政务业务收入同比下降4.27%，且客户集中度较高（前五大客户占销售额17.85%）。国家财政预算收紧趋势下，政务项目招标规模与付款周期可能进一步恶化，导致该业务收入增长乏力甚至下滑。同时，公司研发投入占营收比高达24.89%，若政务业务无法持续获取高价值订单，高额研发支出将难以消化。
