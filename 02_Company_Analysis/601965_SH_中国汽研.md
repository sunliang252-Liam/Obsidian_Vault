# 601965.SH 深度透视

## 因果逻辑链
- **[电动化与智能化技术迭代]** -> [新能源及智能网联汽车技术服务收入增长38.59%]: 新能源渗透率提升及智驾强标落地，催生电池、智驾、信息安全等全新测评需求，公司前瞻布局能力建设，承接增量订单。
- **[“区域统筹、协同服务”营销体系重塑]** -> [技术服务收入增长10.11%]: 深化区域化改革，落实“一企一策”，提升属地化服务能力与客户响应速度，稳固并拓展了法规检测基本盘。
- **[战略投资与能力建设加速落地]** -> [总资产增长39.19%，在建工程增长138%]: 收购南方试验场、华东总部基地投入试运营，大幅扩充了智能网联与新能源测试产能，为未来增长奠定基础。
- **[强化应收账款管理]** -> [经营活动现金流净额增长144.91%]: 加强客户及应收款项管理，销售回款同比增加6.36亿元，显著改善现金流质量，盈利质量提升。
- **[装备制造业务主动收缩]** -> [装备制造收入下降34.39%]: 受燃气系统及氢能市场需求下滑影响，公司主动退出低效的专用车销售业务，聚焦高附加值测试装备，短期拖累营收但优化了业务结构。
- **[标准引领与指数生态构建]** -> [行业影响力与定价权提升]: 牵头制定多项国际及国家标准，发布安全、智能、健康指数，构建“技术创新—标准开发—产业应用”生态，巩固了行业话语权。

## 风险警告
**1. 资本开支高峰期的回报风险。** 公司正处于战略扩张期，华东总部基地、南方试验场等重大项目投资巨大，总资产同比增长39%，在建工程翻倍。这些项目从投产到满产、从收入到利润的转化存在时间差，若下游需求或技术路线发生超预期变化，可能导致产能利用率不足，资产折旧摊销压力侵蚀利润。

**2. 行业竞争加剧与价格战传导风险。** 汽车行业“内卷”加剧，车企降本压力持续向上游检测服务环节传导。虽然公司凭借资质壁垒和技术优势维持了较高毛利率，但新能源及智能网联业务毛利率同比下降4.7个百分点，显示新业务竞争激烈。若行业景气度下行或新进入者增多，技术服务价格可能承压。
