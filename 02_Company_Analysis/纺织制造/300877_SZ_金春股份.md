# 300877.SZ 深度透视

## 因果逻辑链
- **[非经常性损益（公允价值变动收益）]** -> [净利润暴增180%]: 被投资企业上市导致公允价值变动收益5,835万元，贡献了归母净利润的67%，是净利润从3,094万飙升至8,669万的核心驱动力。
- **[扣非净利润增长146%]** -> [主业盈利能力改善]: 原材料价格平稳+内部降本增效，扣非净利润从1,233万增至3,035万，显示主业经营质量实质性好转。
- **[ES纤维业务放量]** -> [营收结构优化]: ES纤维收入同比+54.73%，占总营收比从10%升至14.68%，成为第二增长曲线，对冲了非织造布收入下滑。
- **[产能利用率下降]** -> [固定资产效率承压]: 总产能从10.5万吨扩至11.625万吨，但产能利用率从90.03%降至83.71%，新增产能消化不足。
- **[产业链向下游延伸]** -> [打开新市场空间]: 收购金圣源51%股权切入车规级特种防护车衣市场，从无纺布向汽车产业链下游延伸。
- **[员工持股计划落地]** -> [管理层利益绑定]: 2025年实施员工持股计划，覆盖160人，回购366万股，管理费用中股份支付增加，短期费用化但长期激励效应显著。
- **[可降解项目产能爬坡缓慢]** -> [资本回报率承压]: 年产1.2万吨湿法可降解水刺项目投资进度仅48.49%，产能效益未能有效发挥，拖累整体ROE。

## 风险警告
**主业增长可持续性存疑。** 2025年净利润暴增主要依赖非经常性损益（公允价值变动收益5,835万元），扣非净利润仅3,035万元，对应净利率不足3%。非织造布主业收入同比-0.23%，行业供大于求格局未改，毛利率仅11.2%，主业盈利能力依然薄弱。若被投资企业股价回调，利润将大幅缩水。

**产能扩张与需求错配风险。** 公司总产能从10.5万吨扩至11.625万吨，但产能利用率从90%降至83.7%，多个募投项目（可降解、热风无纺布）效益不达预期。下游需求增速不及产能投放速度，行业竞争加剧，新增产能可能成为利润拖累而非增长引擎。
