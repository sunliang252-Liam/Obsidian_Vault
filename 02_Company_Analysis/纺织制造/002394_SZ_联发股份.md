# 002394.SZ 深度透视

## 因果逻辑链
- **[金融资产公允价值变动]** -> [净利润大增50.68%]: 2025年公允价值变动收益达6248万元（同比+1.15亿元），成为利润暴增的核心驱动力，而非主业改善。
- **[面料销量下滑18.23%]** -> [营收下降3.83%]: 核心产品面料销量从2.32亿米降至1.90亿米，量价双杀导致收入承压，但毛利率提升2.25%部分对冲。
- **[经营现金流骤降88%]** -> [盈利质量恶化]: 净利润3.04亿，但经营现金流仅0.70亿，主因购买商品支付现金增加，利润含金量极低。
- **[处置子公司获现5.39亿]** -> [投资现金流由负转正]: 出售家纺公司、棉业公司股权，一次性获得大额现金流入，掩盖了主业造血能力下滑。
- **[国内收入增长9.53%]** -> [对冲海外市场萎缩]: 欧洲(-25.34%)、美国(-48.08%)出口大幅下滑，公司转向内销，国内占比从57.9%提升至65.95%。
- **[棉纱库存激增30%]** -> [存货周转压力]: 期末棉纱库存达2.62万吨，同比增加30%，占用大量资金，增加跌价风险。
- **[服装毛利率下降7.65%]** -> [成本传导受阻]: 服装业务收入微降1.82%，但营业成本上升8.92%，成本端压力未能有效传导至终端售价。
- **[研发人员减少26.36%]** -> [创新投入收缩]: 研发人员从368人降至271人，研发费用同比下降9.56%，长期竞争力或受影响。

## 风险警告
**盈利高度依赖非经常性损益，主业增长乏力。** 2025年净利润3.04亿元中，非经常性损益高达6847万元（主要为金融资产公允价值变动+1.15亿），扣非净利润仅2.35亿元，同比+20.74%，增速远低于归母净利润的50.68%。剔除金融投资收益后，公司真实盈利能力改善有限。同时，经营现金流净额仅0.70亿元，同比骤降88%，与净利润严重背离，表明利润质量堪忧，回款能力恶化。

**海外市场萎缩与产能利用率不足构成双重压力。** 欧洲、美国两大核心出口市场收入分别下降25.34%和48.08%，海外需求疲软态势明显。与此同时，境外面料产能利用率仅59.14%，服装产能利用率81.60%，均低于境内水平，海外投资回报效率低下。公司虽通过内销增长（+9.53%）部分对冲，但内销毛利率仅17.81%，远低于欧洲的24.95%，结构恶化将压制整体盈利空间。
