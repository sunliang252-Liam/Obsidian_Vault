# 603055.SH 深度透视

## 因果逻辑链
- **[下游需求疲软与行业竞争加剧]** -> [营收与利润双降]: 2025年纺织行业终端需求偏弱，锦纶行业开工率下滑、库存高企，公司营收同比下降10.01%，归母净利润同比下降26.79%。
- **[原材料价格下跌]** -> [毛利率承压]: 主要原材料己内酰胺、锦纶切片采购价格同比下降约16%-18%，但产品售价同步下跌，导致综合毛利率下降2.25个百分点，未能受益于成本下降。
- **[非经常性损益高企]** -> [扣非净利润大幅下滑43.38%]: 报告期内计入当期损益的政府补助高达2.19亿元，占归母净利润的41.3%，剔除后核心盈利能力显著恶化。
- **[江苏淮安项目产能释放]** -> [固定资产大幅增加，在建工程转固]: 江苏织染项目完成试生产并陆续投产，在建工程减少89.59%，固定资产增加9.7%，但新增产能尚未完全转化为营收增长。
- **[越南织染项目开工建设]** -> [投资活动现金流出增加]: 全球化战略布局启动，导致投资活动现金流量净额扩大至-9.03亿元，资本开支压力持续。
- **[购买商品支付现金减少]** -> [经营性现金流大幅改善]: 经营活动现金流净额同比增长73.88%至12.28亿元，主要系采购支出减少，但需警惕此为业务收缩的被动结果。
- **[锦纶66与再生尼龙差异化优势]** -> [维持行业龙头地位]: 公司是国内少数能生产高档尼龙66、再生尼龙纱线的全产业链企业，在差异化产品领域保持领先，但短期未能对冲行业下行风险。

## 风险警告
**核心风险在于行业周期下行与公司扩张节奏的错配。** 2025年锦纶行业产能过剩、需求疲软，公司营收与利润双降，扣非净利润更是暴跌43.38%，显示核心业务盈利能力严重恶化。与此同时，江苏淮安项目刚投产、越南项目又启动建设，大规模资本开支导致投资现金流持续为负，而新增产能的消化在弱市环境下存在巨大不确定性，可能进一步拖累资产回报率。

**治理风险与财务风险并存。** 公司年内因关联交易未及时披露再次收到监管警示函，暴露出内控执行层面的薄弱环节。此外，公司担保总额占净资产比例高达92.46%，且直接或间接为资产负债率超70%的子公司提供担保金额达10.6亿元，若子公司经营不善，公司将面临较大的连带偿债风险。
