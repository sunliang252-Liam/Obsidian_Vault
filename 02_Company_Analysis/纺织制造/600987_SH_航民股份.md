# 600987.SH 深度透视

## 因果逻辑链
- **[黄金饰品“加工+批发”模式]** -> **利润稳定**：金价暴涨抑制消费量（-20.45%），但公司仅收加工费，不承担金价波动风险，且通过优化产品结构提升附加值，实现“减量不减利”，利润总额逆势增长12.79%。
- **[印染“代加工”模式]** -> **抗周期韧性**：不持有坯布库存，规避原料价格波动风险，且回款快、资金占用低。在行业营收下降10.85%、利润下降23.55%的背景下，公司印染业务仅小幅下滑，销售利润率14.36%，远超行业均值4.64%。
- **[热电、水处理、污水处理配套产业链]** -> **成本优势与循环经济**：印染配套热电，保障蒸汽供应稳定且成本可控；利用印染废水进行烟气脱硫，降低环保运行费用。产业链协同构筑了难以复制的成本护城河。
- **[深圳尚金缘并购]** -> **黄金业务版图扩张**：收购尚金缘后，公司黄金饰品年产能达80吨，服务能力覆盖全国主要品牌商，并贡献业绩承诺（2025年净利润6679.64万元，完成率102.76%），成为新的利润增长点。
- **[高分红政策]** -> **股东回报稳定**：连续多年高比例现金分红，2025年全年分红率48.62%，近三年累计现金分红及回购金额占年均净利润比例高达167.90%，是典型的红利型投资标的。
- **[研发投入与数智化转型]** -> **效率提升**：全年研发投入1.94亿元，推动“工艺参数智能配比”、“工业AI智能检测”等应用落地，提升染色一次成功率与生产效率，对冲人力成本上升压力。

## 风险警告
**核心风险在于两大主业的“量价双杀”困境。** 黄金饰品业务受金价持续高位运行及消费结构转变（金条消费首超首饰）的长期压制，销量下滑已成趋势，公司虽能保利但难以保量，成长性受限。印染业务则面临外需波动、内需疲软及行业产能过剩的激烈竞争，公司虽为龙头，但市场份额仅占全国2%，提价能力薄弱，利润增长更多依赖成本管控而非规模扩张。

**第二重风险来自财务与经营层面的潜在波动。** 公司黄金租赁业务形成巨额交易性金融负债（期末28.36亿元），金价剧烈波动将直接影响公允价值变动损益，2025年虽录得正收益，但2024年曾亏损3444万元，利润稳定性存疑。此外，公司航运业务属强周期行业，2025年营收虽因低基数暴增94.91%，但未来持续性存疑。管理层年龄结构偏大（董事长73岁，总经理69岁），二代接班与战略延续性亦是长期隐忧。
