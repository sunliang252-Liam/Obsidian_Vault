# 600845.SH 深度透视

## 因果逻辑链
- **[钢铁行业下行周期]** -> [营收与利润双降]: 2025年营收109.72亿元(-19.59%)，归母净利润13.05亿元(-42.40%)，主因钢铁客户资本开支收缩，软件开发及工程服务收入同比下滑27.71%。
- **[宝之云华北基地大规模建设]** -> [投资现金流大幅流出]: 在建工程同比+89.51%至19.12亿元，投资活动净流出12.88亿元(上年3.36亿元)，资本开支进入高峰期。
- **[关联交易依赖度极高]** -> [业绩波动与宝武集团高度绑定]: 前五大客户中关联方销售占比52.69%，核心收入来源受制于单一集团客户的IT预算周期。
- **[AI+工业软件战略投入]** -> [研发费用率维持高位]: 研发投入14.24亿元，占营收12.98%，全部费用化，短期侵蚀利润但长期构筑“钢铁行业大模型”壁垒。
- **[服务外包业务韧性凸显]** -> [收入结构优化]: 服务外包收入37.65亿元(+2.98%)，毛利率42.96%，成为营收下滑中的稳定器，IDC运营与运维服务贡献稳定现金流。
- **[应收账款与合同资产高企]** -> [信用减值风险持续]: 应收账款+合同资产合计账面余额732.55亿元，信用减值损失0.93亿元，客户信用风险随钢铁行业下行而积聚。
- **[限制性股票回购注销]** -> [股本缩减与费用冲回]: 回购注销1302.5万股，减少库存股3.66亿元，同时冲回股份支付费用，对归母净利润产生一次性正向影响。

## 风险警告
**核心风险在于“钢铁周期依赖症”的短期无解。** 公司营收与利润的剧烈下滑，本质上是其业务结构高度集中于钢铁行业（尤其是宝武集团）的必然结果。当钢铁行业进入“长周期减量调结构”阶段，客户资本开支收缩直接导致公司核心的软件开发及工程服务收入锐减27.71%。尽管公司积极布局AI、机器人、PLC等新赛道，但这些业务尚处于投入期，短期内无法对冲传统业务的失速。2025年归母净利润13.05亿元，已回落至2021年水平，ROE从20.67%骤降至11.88%，盈利能力的周期性特征暴露无遗。

**第二个风险是“AI转型的投入产出不确定性”。** 公司研发费用率高达12.98%，全部费用化，且资本化率为0，这意味着AI大模型、具身智能机器人等前沿领域的巨额投入，在可预见的未来仍将持续侵蚀利润。年报中提及的“100多个AI应用场景上线”和“1000多个智能体”，其商业化变现路径尚不清晰。在行业整体“ALL in AI”但盈利模式模糊的背景下，宝信软件面临“不投则落后，投则拖累利润”的两难困境。同时，宝之云华北基地的大规模资本开支（在建工程同比+89.51%），若后续算力需求不及预期，将形成巨大的资产减值风险。
