# 002474.SZ 深度透视

## 因果逻辑链
- **[信创与AI战略转型]** -> [亏损收窄]: 公司全面拥抱AI，设立AI事业部，推动信创政务产品迭代，但研发投入资本化率高达69.42%，掩盖了当期真实亏损压力。
- **[园区开发与运营业务增长]** -> [收入结构改善]: 园区开发收入同比增长19.50%，主要系以房产对联营企业投资，但该业务非核心，且依赖资产处置，可持续性存疑。
- **[研发投入资本化]** -> [利润调节]: 研发投入资本化金额4743万元，占研发投入总额的69.42%，显著高于行业平均水平，若资本化条件不满足，将大幅增加当期亏损。
- **[政府补助与投资收益]** -> [非经常性损益支撑]: 计入当期损益的政府补助520.67万元，加上联营企业投资成本小于公允价值产生的收益551.27万元，合计占利润总额的16.2%，掩盖了主营业务的疲软。
- **[系统集成收入下滑]** -> [核心业务承压]: 系统集成收入同比下降2.66%，软件产品及服务收入同比下降6.67%，显示传统业务增长乏力，客户信息化建设进度波动。
- **[经营活动现金流改善]** -> [运营效率提升]: 经营活动现金流净额同比增长39.12%，主要系购买商品、接受劳务支付的现金减少，但净利润仍为负，现金流向好主要依靠压缩采购支出。
- **[子公司亏损拖累]** -> [整体业绩]: 上海榕基、浙江榕基、河南榕基等多家子公司持续亏损，合计亏损超3600万元，严重侵蚀母公司利润，显示区域扩张策略效果不佳。

## 风险警告
**核心风险在于研发资本化与持续亏损的背离。** 公司连续三年扣非净利润为负（2023年-1.57亿，2024年-0.93亿，2025年-0.79亿），但研发投入资本化率高达69.42%，远超行业惯例。若审计或监管对资本化条件提出质疑，将导致巨额资产减值，直接冲击净资产。同时，公司短期借款高达5.82亿元，占总资产24%，而货币资金仅2.02亿元，短期偿债压力巨大，财务费用持续侵蚀利润。

**第二重风险是业务转型的不确定性。** 公司“全面拥抱AI”战略尚处投入期，AI事业部刚设立，尚未形成可量化的收入贡献。信创业务虽为政策风口，但市场竞争激烈，且公司核心客户为政府及事业单位，受财政预算收紧影响，项目回款周期长，应收账款周转率低。此外，园区开发业务依赖资产处置，并非可持续增长引擎，且子公司大面积亏损，显示管理半径扩张带来的整合风险。
