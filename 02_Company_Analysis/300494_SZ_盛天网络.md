# 300494.SZ 深度透视

## 因果逻辑链
- **[游戏出海《星之翼》表现亮眼]** -> [游戏运营收入增长14%]: 原创IP《星之翼》海外流水占比超80%，成为游戏业务核心增长引擎，推动整体扭亏为盈。
- **[《三国志·战略版》IP监修合同到期]** -> [IP运营收入骤降36%]: 核心IP合同于2025年9月终止，且无新IP产品上线，导致IP业务收入与毛利大幅下滑。
- **[IP合同到期引发商誉减值]** -> [净利润承压]: 因天戏互娱经营受IP合同到期影响，公司计提商誉减值5,049万元，严重拖累当期利润。
- **[端游市场复苏与线下流量回暖]** -> [广告业务收入增长8%]: 易乐游网娱平台受益于线下场景复苏，精准触达核心玩家，推动互联网广告收入提升。
- **[AI应用“给麦”与“带带电竞”迭代]** -> [增值业务探索新增长点]: 公司依托VRACE AI平台，在AI音乐、AI陪伴赛道快速迭代功能，并启动出海战略，构建未来增长潜力。
- **[研发投入资本化比例下降]** -> [研发费用减少14%]: 2025年研发投入资本化率从26.57%降至16.67%，导致当期研发费用同比减少，但长期资产积累放缓。
- **[员工持股计划减持完毕]** -> [市场抛压释放]: 报告期内员工持股计划所持全部股票已减持完毕，对二级市场股价的潜在压制因素消除。

## 风险警告
**核心风险在于IP业务断崖式下滑后的增长真空。** 公司IP运营业务因《三国志·战略版》合同到期而收入锐减36%，且短期内无新IP产品接续，导致子公司天戏互娱经营承压，并引发5,049万元的商誉减值。若《真·三国无双 天下》等新IP产品上线后表现不及预期，公司将面临IP业务长期萎缩的风险，商誉减值压力也将持续存在。

**AI与游戏出海业务的高投入与不确定性构成第二重风险。** 公司正全力押注AI应用出海和游戏全球化，但海外市场竞争激烈，AI技术迭代迅速，且面临复杂的政策与文化适配风险。当前AI业务尚处于投入期，未贡献显著利润，而《星之翼》等游戏在海外市场的成功能否持续复制，仍有待验证。若战略推进受阻，前期大量研发与推广投入将难以收回。
