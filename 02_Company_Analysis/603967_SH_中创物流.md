# 603967.SH 深度透视

## 因果逻辑链
- **[国际海运价格下跌]** -> [营收下降25.24%]: 跨境集装箱物流收入受运价下跌拖累，从108.6亿降至77.01亿，是营收下滑主因。
- **[业务结构多元化]** -> [净利润逆势增长3.22%]: 工程物流（+21.21%）和资源转运物流（+4.44%）的稳健增长，对冲了集装箱业务下滑，实现利润正增长。
- **[强化应收账款回收]** -> [经营现金流大增37.75%]: 公司严格执行账款管理办法，加快回款，经营性现金流净额达6.65亿元，创历史新高。
- **[精细化成本管控]** -> [毛利率提升1.99个百分点]: 对外采购成本下降26.85%，管理费用下降4.58%，成本降幅大于收入降幅，盈利能力改善。
- **[“物流出海”战略]** -> [海外业务成为新增长极]: 印尼煤炭过驳量达1566万吨（+3.5%），沙特子公司布局中东工程物流，海外资产占总资产9.98%。
- **[高分红政策]** -> [入选红利指数，吸引长期资金]: 连续多年高分红，2025年拟10派6.5元，股息率居前，首次纳入中证红利指数，股东结构优化。
- **[工程物流深耕高端]** -> [中标额与在手合同双增]: 聚焦核电、风电、石化超限设备运输，中标中海壳牌、上海核工院等重大项目，形成车船码头一体化壁垒。

## 风险警告
**核心风险在于业务区域高度集中与汇率波动。** 公司营收超58%来自青岛地区，一旦青岛港口的市场环境或腹地经济发生重大不利变化，将对公司经营产生直接冲击。同时，公司外币结算规模大，2025年财务费用因汇兑损失同比大增58.38%，汇率波动已成为影响利润的显著变量。

**第二重风险来自传统主业的下行压力。** 跨境集装箱物流贡献近70%毛利，但其收入与海运运价高度正相关。若全球贸易摩擦加剧或航运市场持续低迷，公司基本盘的盈利能力将面临考验。此外，资源转运物流毛利率同比骤降10.38个百分点，需警惕该板块成本失控或竞争加剧的风险。
