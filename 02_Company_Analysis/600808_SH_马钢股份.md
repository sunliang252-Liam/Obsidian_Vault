# 600808.SH 深度透视

## 因果逻辑链
- **[宝钢股份90亿元战略入股马钢有限]** -> **负债结构大幅优化，资产负债率下降9.73个百分点**: 宝钢股份以51.39亿元受让马钢有限35.42%股权，并以38.61亿元增资，公司获得资金后偿还负债，年末资产负债率降至55.67%。
- **[全工序降本增效叠加原材料价格下行]** -> **营业成本降幅（-11.12%）显著大于收入降幅（-5.25%）**: 公司推进“四大成本”管控，吨钢成本同比削减115元，同时矿石、焦煤等价格同比下降，购销差改善驱动毛利回升。
- **[马钢有限与长江钢铁双主体扭亏为盈]** -> **合并利润总额同比减亏49.70亿元**: 马钢有限利润总额0.74亿元（同比增利39.54亿元），长江钢铁利润总额2.36亿元（同比增利12.16亿元），核心经营主体实现根本性反转。
- **[深化内部改革与组织扁平化]** -> **管理效率与运营敏捷性提升**: 机关部门由15个精简为9个，长江钢铁推行“厂—作业区—班组”三级扁平化，管理者薪酬与绩效紧密挂钩，激发组织活力。
- **[产品结构向高端化、差异化转型]** -> **高盈利新产品占比提升至54.5%**: 汽车板销量增长6.3%，特钢产销量增长16%，型钢出口创历史新高（93万吨），高铁车轮实现批量商业化应用。
- **[“三压减三提升”专项行动]** -> **资产质量与资金效率同步改善**: 全年压减负债规模61亿元，“两金”周转天数同比加快5.6天，全员劳动生产率达53.39万元/人年，直供比例提升至74.7%。
- **[经营活动现金流大幅改善]** -> **内生造血能力恢复**: 经营活动现金流净额从9.61亿元跃升至41.52亿元（+332%），主要系购销差好转及采购付现减少，现金流质量显著优于利润表表现。

## 风险警告
**核心风险在于行业需求持续萎缩与公司自身盈利基础脆弱性的叠加。** 2025年粗钢表观消费量同比下降7.1%，房地产用钢需求拖累显著，而制造业用钢增量难以完全对冲。公司虽实现大幅减亏，但归属于上市公司股东的净利润仍为-2.09亿元，扣非净利润-2.29亿元，表明主营业务尚未真正走出亏损泥潭。2026年行业预计延续“减量发展、存量优化”格局，出口面临许可证制度与碳边境调节机制双重约束，国内竞争将进一步加剧。

**结构性风险来自参股企业资产损失与改革整合的不确定性。** 参股的金马能源、盛隆化工因焦化行业产能政策及价格低迷持续亏损，合计拖累投资收益。同时，马钢有限引入宝钢股份后的协同效应尚需时间验证，公司自身“特钢做强、板材做优、长材做精、轮轴做大”的战略转型仍处于投入期，新特钢二期、镀锌线等重大项目资本开支较大（2026年固定资产投资计划33亿元），若下游需求复苏不及预期，新增产能可能面临消化压力。
