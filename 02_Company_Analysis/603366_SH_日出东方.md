# 603366.SH 深度透视

## 因果逻辑链
- **[境内主营业务收入大幅下滑]** -> [营收同比下降19.53%]: 消费疲软、市场竞争加剧导致境内收入同比下滑32.12%，境外收入虽有增长但无法对冲。
- **[储能业务爆发式增长]** -> [营收同比增长175.6%]: 全球光储一体化趋势深化，公司户储与工商储产品实现批量交付，形成新增长极。
- **[西藏清洁供暖项目落地]** -> [长期借款激增157%]: 公司中标多个高海拔地区特许经营供暖项目，需大量项目贷款支撑前期建设投入。
- **[原材料价格波动与行业竞争]** -> [毛利率提升但利润下滑]: 成本管控使毛利率微增，但营收规模大幅缩减，导致利润总额同比下降29.27%。
- **[非经常性损益依赖度高]** -> [扣非净利润降幅更大]: 扣非净利润同比下降32.28%，远超归母净利润17.73%的降幅，主业盈利能力承压。
- **[商誉减值风险释放]** -> [资产减值损失同比翻倍]: 对厨电等板块计提商誉减值，导致资产减值损失从3192万增至7603万，侵蚀利润。
- **[控股股东资金占用]** -> [内控缺陷与监管处罚]: 子公司向关联方提供非经营性资金占用未及时披露，公司收到警示函，暴露内控短板。
- **[经营活动现金流大幅改善]** -> [现金流净额同比增2192%]: 主要系上年同期基数极低，本期加强回款与库存管理，现金流质量显著修复。

## 风险警告
**核心风险在于主业萎缩与增长引擎的错位。** 公司传统太阳能热水器及空气能内销业务受房地产下行、替代品冲击双重挤压，营收持续收缩，而储能、西藏供暖等新业务虽增速亮眼，但体量尚小（储能仅1.13亿），无法弥补传统业务近10亿的营收缺口。公司正处于“旧船下沉、新船未稳”的转型阵痛期，若储能及海外业务不能持续高增，整体业绩仍有进一步下滑风险。

**内控与治理风险不容忽视。** 报告期内因子公司非经营性资金占用未及时披露而遭监管警示，暴露出多基地、多子公司架构下的内控执行漏洞。此外，公司大量资金用于委托理财（未到期余额超7.8亿），而主业研发投入仅占营收4.74%，需警惕资金配置偏离核心业务、治理层对子公司管控失效的潜在风险。
