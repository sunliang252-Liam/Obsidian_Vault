# 605066.SH 深度透视

## 因果逻辑链
- **[白银等大宗原材料价格上涨]** -> [毛利率下降]: 成本端压力直接侵蚀利润，是净利润下滑的核心原因之一。
- **[高毛利率的国网仪表销售进度放慢]** -> [营收与利润双重承压]: 高价值产品收入确认延迟，拉低了整体盈利水平。
- **[传统市场周期调整]** -> [营业收入下滑3.57%]: 下游部分行业需求疲软，导致公司整体营收规模收缩。
- **[聚焦新能源、通讯/数据中心等高增长赛道]** -> [设备制造业务线同比增长超30%]: 战略转型初见成效，新业务对冲了传统市场下滑。
- **[储能领域深度参与头部客户定制化研发]** -> [储能业务实现突破性增长]: 技术绑定与客户协同，在细分领域构建了竞争壁垒。
- **[海外“走出去”战略]** -> [海外业务收入同比增长22%]: 俄罗斯及独联体市场成为增长引擎，有效分散了国内周期风险。
- **[研发投入持续（5.23%营收占比）]** -> [推出NEXTG-3系列等新产品]: 技术迭代是维持行业地位和开拓新市场的根本动力。
- **[股权激励计划因业绩未达标而回购注销]** -> [管理费用与股东权益波动]: 激励失效不仅增加当期费用，也向市场传递了增长乏力的信号。

## 风险警告
**核心风险在于盈利能力的持续恶化与增长动能的青黄不接。** 公司净利润连续两年大幅下滑（2024年-24%，2025年-24%），扣非净利润降幅更是扩大至33%。这并非单一因素所致，而是“成本上升（白银涨价）+ 传统业务萎缩（地产、电网投资放缓）+ 高毛利产品（国网仪表）交付延迟”三重压力的叠加。公司虽在新能源、数据中心等新赛道取得突破，但新业务体量尚不足以完全弥补传统业务的缺口，导致整体营收下滑，利润弹性严重不足。

**另一个显著风险是公司战略执行与市场现实的脱节。** 2023年推出的限制性股票激励计划，因2024年业绩未达标而触发大规模回购注销，这直接暴露了公司对自身增长预期的过度乐观。同时，募投项目“智能型低压电器产品扩产项目”因房地产行业低迷而可行性发生重大变化，导致大量募集资金闲置或变更用途。这表明公司在应对下游行业周期波动和进行资本配置时，缺乏足够的预见性和灵活性，未来若宏观经济或下游行业景气度持续低迷，公司可能面临更大的资产减值与战略调整压力。
