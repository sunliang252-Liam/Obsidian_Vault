# 300549.SZ 深度透视

## 因果逻辑链
- **[汽车行业价格战与利润挤压]** -> [营收与净利润双降]: 下游整车厂利润承压，价格战压力向上游传导，导致公司精密模具零部件业务收入同比下降12.62%，扣非净利润暴跌77.80%。
- **[主动优化客户结构与收紧信用政策]** -> [短期营收规模收缩]: 为强化风险管控，公司主动筛选客户并收紧信用政策，虽保障了经营安全性，但制约了短期营收扩张。
- **[自动化与医疗器械业务突破认证瓶颈]** -> [新兴业务高速放量]: 自动化设备零部件营收增长1.78%，制药模具及医疗器材零部件营收暴增140.43%，初步形成第二增长曲线，对冲传统业务下滑。
- **[原材料价格波动与成本控制]** -> [毛利率承压]: 冷作模具钢等主要原材料价格波动，叠加新兴业务尚处爬坡期、规模效应未释放，导致综合毛利率同比下降1.23个百分点至26.10%。
- **[强化应收账款管理与回款]** -> [经营性现金流大幅改善]: 公司加大回款力度，销售商品收到的现金增加，使得经营活动现金流净额同比暴增202.26%至6804.7万元，远高于净利润。
- **[坚持高研发投入]** -> [巩固技术壁垒与产品迭代]: 研发费用占营收比例达5.95%，持续投入精密模具、自动化传动及医疗器械领域，完成8款新产品开发，为高端化转型提供支撑。
- **[“精密模具+自动化+医疗”三维布局]** -> [增强抗周期能力]: 公司从单一汽车模具业务向自动化设备、医疗器械等高增长领域拓展，有效分散单一行业周期波动风险，提升增长韧性。

## 风险警告
公司面临的核心风险在于**传统主业利润持续被挤压，而新兴业务尚无法完全弥补缺口**。汽车行业价格战已导致公司精密模具零部件业务收入与毛利率双降，扣非净利润已降至极低水平（202万元），盈利能力非常脆弱。若汽车行业景气度持续低迷，公司业绩存在进一步下滑的风险。

此外，公司存在**供应商集中度偏高**的风险，对第一大供应商的采购额占总额的18.90%，一旦该供应商出现问题，将对供应链稳定性造成冲击。同时，**原材料价格波动**（冷作模具钢等）和**汇率波动**（境外采购与销售以美元、欧元结算）也是影响公司成本与利润的长期不确定因素。新兴业务（自动化、医疗）虽增长迅猛，但规模尚小，其后续市场拓展能否持续放量，仍存在不确定性。
