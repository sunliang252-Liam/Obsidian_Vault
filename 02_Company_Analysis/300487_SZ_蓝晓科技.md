# 300487.SZ 深度透视

## 因果逻辑链
- **[GLP-1多肽药物市场爆发]** -> [生命科学板块收入增长12%]: 公司作为全球市占率领先的多肽固相合成载体供应商，直接受益于司美格鲁肽、替尔泊肽等重磅药物的放量，拉动高毛利耗材销售。
- **[盐湖提锂技术产业化突破]** -> [金属资源板块收入增长23%]: 西藏国能结则茶卡项目试运行成功，验证了“零碳”直接提锂工艺的可行性，打开了西藏及南美盐湖的广阔市场空间，并带动吸附材料销售。
- **[国产替代战略窗口期]** -> [超纯水与催化树脂市占率提升]: 公司均粒树脂打破国外垄断，在电子级超纯水领域实现对存储芯片大厂的稳定供货；双酚A催化树脂在万华等头部客户实现国产化替代，打开存量市场新空间。
- **[“材料+装置”一体化解决方案]** -> [技术服务收入增长54%]: 公司独特的“材料+工艺+装置”模式，在盐湖提锂、生物医药等新兴领域为客户提供交钥匙工程，提升了客户粘性和项目价值，驱动技术服务收入高速增长。
- **[产能扩张与满产运行]** -> [吸附材料产销量双增]: 高陵、蒲城两大基地合计5万吨产能，产能利用率高达140%，规模效应摊薄成本，支撑了营收和利润的持续增长。
- **[国际化布局初见成效]** -> [海外本地化销售网络搭建]: 在欧洲、北美设立子公司并招聘本地化团队，提升了品牌影响力和客户覆盖率，但受全球贸易格局影响，海外收入同比微降3.52%。

## 风险警告
**1. 大客户项目执行与应收账款风险。** 公司与西藏珠峰签订的6.5亿元盐湖提锂大合同，目前仅确认1.13亿收入，且存在合同调整或变更的可能。此类大型系统集成项目周期长、回款慢，若后续项目执行不力或客户违约，将对公司现金流和业绩造成重大冲击。同时，随着业务扩张，应收账款规模持续增长，坏账风险不容忽视。

**2. 下游需求波动与竞争加剧风险。** 公司业绩高度依赖新能源（锂、镓）、生命科学（GLP-1）等新兴领域的景气度。若锂盐价格持续低迷、GLP-1药物市场增速放缓，或镓出口管制政策变化，将直接影响公司核心板块的收入。此外，高毛利领域（如生命科学）正吸引国内外厂商加大投入，市场竞争加剧可能导致产品价格和毛利率承压。
