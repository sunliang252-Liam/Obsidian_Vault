# 688300.SH 深度透视

## 因果逻辑链
- **[AI与高性能计算需求爆发]** -> [高性能球形粉体营收快速增长]: AI服务器、高速通信等下游需求驱动先进封装与高速基板升级，公司低介电损耗、低放射性球形二氧化硅等高性能产品精准匹配，营收占比快速提升。
- **[产品结构向高端化持续优化]** -> [毛利率提升与利润增长]: 球形无机粉体（毛利率51.92%）营收增速（18.70%）远超角形粉体（2.97%），高附加值产品占比扩大，推动整体毛利率同比增加0.22个百分点。
- **[先进封装技术迭代]** -> [LMC/UF用球形粉体进入工程化/产业化]: 2.5D/3D封装、Chiplet等新技术要求更低CUT点、更紧密填充的填料，公司亚微米球形氧化硅/氧化铝等研发项目进入产业化阶段，打开新增长空间。
- **[高性能电子电路基板升级]** -> [高速基板用球形二氧化硅销售快速增长]: 覆铜板向M8-M10及以上等级发展，对低介电损耗填料需求迫切，公司极低介电损耗球形氧化硅产品精准满足需求，实现批量交付。
- **[新能源汽车与热管理需求增长]** -> [高导热球形氧化铝导入客户核心配方]: 新能源汽车动力电池及电子元件散热需求提升，公司高导热微米/亚微米球形氧化铝产品通过行业领先客户验证并进入核心配方。
- **[产能扩张与智能化布局]** -> [支撑未来市场份额提升]: 新建年产3600吨超纯球形二氧化硅和16000吨高导热球形氧化铝项目，突破产能瓶颈，精准卡位高速基板与导热材料市场。
- **[研发投入持续聚焦前沿]** -> [巩固技术壁垒与产品先发优势]: 研发投入6417万元，聚焦Lowα、低介电损耗、液相法制备球形二氧化硅等前沿技术，技术储备二十余年的液相法产品认证加速，构建长期护城河。

## 风险警告
**核心风险在于下游需求波动与技术迭代速度。** 公司业绩高度依赖AI、高速通信、新能源汽车等下游领域的资本开支与技术创新节奏。若AI算力投资放缓、消费电子需求疲软或先进封装技术路线发生重大变化，将直接导致高性能产品订单不及预期，公司高增长逻辑可能受挫。此外，球形氧化铝、氮化物等新产品的市场验证与客户导入存在不确定性，研发失败或认证周期过长将影响产能利用率与盈利兑现。

**竞争加剧与成本压力不可忽视。** 功能性粉体材料行业景气度高，吸引新进入者，可能引发价格战，侵蚀公司毛利率。同时，公司主要成本中燃料动力占比高达26.53%，能源价格波动（如天然气、电力）将直接压缩利润空间。此外，公司境外收入占比提升，汇率波动可能造成汇兑损失，2025年财务费用因汇兑损失大幅增加已敲响警钟。
