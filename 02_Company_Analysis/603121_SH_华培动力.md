# 603121.SH 深度透视

## 因果逻辑链
- **[商誉减值]** -> [净利润由盈转亏]: 因传感器子公司业绩未达预期，计提6846万元商誉减值，直接导致全年归母净利润亏损4318万元。
- **[终端客户量产计划延期]** -> [营收与毛利率双降]: 部分客户推迟车型量产，导致公司销售收入同比下降6.33%，并拖累综合毛利率下滑3.20个百分点。
- **[动力总成业务结构分化]** -> [整体毛利率承压]: 高毛利的放气阀组件收入下滑16.34%，而低毛利的涡轮壳和中间壳收入增长28.59%，产品结构变化拉低了整体盈利水平。
- **[传感器业务整合见效]** -> [亏损幅度收窄]: 通过组织、生产、市场整合及技术路线切换，传感器业务毛利率同比提升1.59个百分点，亏损逐年收窄。
- **[对外股权投资大幅增加]** -> [货币资金减少，投资现金流净流出]: 报告期内新增对外股权投资2.12亿元，导致货币资金减少55.89%，投资活动现金流净流出2.47亿元。
- **[国外客户需求波动与原材料涨价]** -> [国外业务毛利率阶段性下降]: 国外客户需求波动叠加稀有金属原材料价格上涨，导致国外区域毛利率同比下降4.32个百分点。
- **[乘用车市场取得突破]** -> [传感器业务未来增长可期]: 获得全球新能源汽车龙头企业的温度传感器项目定点，预计2026年上半年量产，为传感器业务打开新的增长空间。

## 风险警告
**核心风险在于商誉减值与业绩承诺不达标。** 公司因收购传感器子公司形成大额商誉，2025年已计提6846万元减值，且控股股东对华培传感无锡的三年业绩承诺（累计净利润1.29亿元）已确认无法完成，未来仍存在进一步减值的风险，将持续侵蚀公司利润。

**第二重风险来自传统业务的萎缩与转型阵痛。** 全球涡轮增压器销量下滑5%，公司核心产品放气阀组件收入下降16.34%，显示传统动力总成业务面临行业天花板。同时，公司为转型传感器和执行器业务投入巨大，但新业务尚处亏损期，乘用车市场突破的放量节奏存在不确定性，短期业绩承压明显。此外，公司资产负债率由40.82%升至45.60%，短期借款增加63.17%，财务风险有所上升。
