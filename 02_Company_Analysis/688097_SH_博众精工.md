# 688097.SH 深度透视

## 因果逻辑链
- **[新能源业务订单充足]** -> [营收增长32.53%]: 新能源业务（锂电专机、换电站）订单爆发，带动整体营收规模从49.5亿跃升至65.7亿。
- **[投资收益增加]** -> [净利润增长48.94%]: 处置子公司（灵猴机器人、博众仪器）部分股权产生约2.4亿非经常性损益，显著增厚归母净利润。
- **[加强应收账款管理]** -> [经营性现金流暴增111%]: 销售规模扩大同时强化回款，经营性现金净流入从3.2亿大幅提升至6.7亿。
- **[并购上海沃典与上海栎智]** -> [总资产增长44%]: 并购汽车智能输送系统及半导体工艺介质供应系统公司，导致商誉、存货等资产大幅增加。
- **[消费电子深度绑定大客户]** -> [3C业务营收稳定]: 柔性模块化产线及AR/MR设备产线获大客户认可，3C业务营收35.3亿，占比53.76%，基本盘稳固。
- **[换电站订单爆发]** -> [新能源业务成为第二增长极]: 累计接单超1000座换电站，交付超900座，新能源业务营收23.3亿，占比35.42%。
- **[半导体设备业务放量]** -> [营收同比增长1198%]: 高精度共晶机在光模块领域获头部客户批量订单，半导体业务营收从0.13亿跃升至1.67亿。
- **[非经常性损益占比过高]** -> [扣非净利润增速仅4.36%]: 核心主业盈利能力增长有限，净利润高增长主要依赖资产处置收益，扣非净利润仅从3.19亿增至3.33亿。

## 风险警告
**核心风险在于业绩增长的高度非经常性依赖与主业盈利能力的疲软。** 2025年归母净利润暴增48.94%，但扣非净利润增速仅4.36%，两者差距高达2.6亿元，主要来自处置子公司股权的投资收益。这掩盖了公司核心自动化设备业务（尤其是消费电子）毛利率承压、盈利改善缓慢的真相。若剔除一次性收益，公司实际经营利润增长乏力，估值支撑存疑。

**另一重大风险是并购整合与商誉减值压力。** 公司年内连续收购上海沃典（汽车输送系统）和上海栎智（半导体介质系统），导致总资产膨胀44%，商誉大幅增加。两家公司均处于业务扩张期，若未来下游汽车及半导体行业景气度下行，或整合不及预期，将面临商誉减值风险，直接冲击利润表。此外，公司对核心大客户（苹果产业链）依赖度依然较高，消费电子创新周期放缓或客户转单将构成系统性风险。
