# 600366.SH 深度透视

## 因果逻辑链
- **[新能源汽车销量增长]** -> [营收增长8.39%]: 公司主驱配套市占率23.06%，受益于国内新能源乘用车销量增长28.2%，带动磁钢销量增加10.29%。
- **[磁组件业务高增长]** -> [产品结构优化]: 磁组件销售收入同比+59.69%，高附加值产品占比提升，推动整体毛利率增加3.81个百分点至18.35%。
- **[稀土原材料价格上涨]** -> [利润弹性释放]: 金属镨钕价格全年上涨约50%，公司凭借库存收益和定价传导机制，净利润同比大增248.06%。
- **[研发投入增加]** -> [技术壁垒加固]: 研发费用同比+34.19%，聚焦无重稀土、晶界扩散技术，巩固在新能源汽车和消费电子领域的同步开发能力。
- **[大客户战略深化]** -> [市场份额提升]: 新能源汽车领域新拓展十余个千万级客户，前五大客户销售占比38.87%，客户结构优化，订单稳定性增强。
- **[产能扩张与自动化]** -> [交付能力提升]: 包头15000吨智能制造项目逐步投产，总产能达26000吨/年，支撑销量增长和新兴领域（人形机器人、低空经济）布局。
- **[原材料价格波动]** -> [经营现金流承压]: 镨钕价格上涨导致购买商品支付现金增加，经营活动现金流净额同比-59.21%，但净利润含金量仍为正。

## 风险警告
**核心风险：稀土原材料价格剧烈波动与全球贸易保护主义。** 公司成本结构中直接材料占比高达67.56%，金属镨钕价格从年初49万元/吨涨至年末74万元/吨，若未来价格大幅下跌，将导致存货减值风险（报告期末存货账面价值19.4亿元，同比+38.49%）。同时，海外业务收入占比29.80%，面临美国等国家“去中国化”供应链重构及出口管制政策升级的双重压力，中长期可能侵蚀海外市场份额。

**次要风险：新兴领域商业化不及预期与现金流恶化。** 公司积极布局人形机器人、低空经济等新赛道，但相关业务尚处小批量或量产初期，短期难以贡献显著利润。此外，经营活动现金流净额大幅下降至3.49亿元，远低于净利润3.31亿元，主要因原材料采购占用大量资金。若下游客户回款周期延长或原材料价格持续高位，公司流动性管理将面临挑战。
