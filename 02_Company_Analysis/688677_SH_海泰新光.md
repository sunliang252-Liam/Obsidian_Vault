# 688677.SH 深度透视

## 因果逻辑链
- **[美国大客户深度绑定]** -> [营收高增长]: 第一大客户史赛克贡献67.58%销售额，在手订单3.01亿元，驱动医用内窥镜业务同比增长37.87%。
- **[泰国/美国海外产能布局]** -> [规避关税风险]: 提前建成泰国和美国工厂，将销美产品转移至海外生产，有效对冲2025年美国对等关税冲击，保障供应链稳定。
- **[自主品牌整机战略]** -> [费用侵蚀利润]: 加大国内自主品牌市场推广和研发投入，销售费用同比暴增96.71%，导致净利润增幅（26.15%）显著低于营收增幅（36.08%）。
- **[光学业务多元化]** -> [第二增长曲线]: 光学业务同比增长29.98%，并积极切入AI算力光器件领域，形成“医用内窥镜+光学”双轮驱动格局。
- **[产业链垂直整合]** -> [高毛利率壁垒]: 掌握从光学设计、镀膜到整机集成的全链条能力，医用内窥镜器械毛利率高达71.28%，构筑成本与品质护城河。
- **[研发投入资本化]** -> [全部费用化]: 研发投入7,274万元全部费用化，占营收12.07%，虽短期压制利润，但为下一代内窥镜系统、AI+光学等储备技术。
- **[联营企业亏损]** -> [投资收益拖累]: 参股公司国药新光亏损3,316万元，导致长期股权投资减值，对合并净利润产生负向影响。

## 风险警告
**第一大客户依赖与地缘政治风险高度叠加。** 公司近七成营收来自美国史赛克，虽已通过泰国工厂规避部分关税，但中美贸易摩擦升级、医疗产品豁免不确定性，以及客户供应链再平衡，均可能对核心业务造成系统性冲击。一旦大客户订单转移或关税成本无法转嫁，业绩将面临断崖式下滑。

**国内自主品牌转型的“烧钱”困境。** 公司正从ODM/OEM代工向自主品牌整机厂商转型，销售费用同比近乎翻倍，但国内内窥镜市场进口替代竞争激烈、品牌建设周期长。短期内，高投入与低回报的矛盾将持续侵蚀利润，若市场拓展不及预期，将陷入“增收不增利”的泥潭。
