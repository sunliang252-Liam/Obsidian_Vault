# 601997.SH 深度透视

## 因果逻辑链
- **[LPR下行与让利实体]** -> [利息净收入下降9.21亿元]: 新发放贷款利率下降及存量资产利率调降，导致生息资产收益率承压，净息差从1.75%收窄至1.58%。
- **[债券市场波动]** -> [公允价值变动收益减少18.63亿元]: 交易性金融资产公允价值由盈转亏，是营业收入同比下降12.94%的核心拖累项。
- **[加大不良处置与释放拨备]** -> [信用减值损失减少22.31亿元]: 通过批量转让、核销等方式出清风险，贷款及金融投资减值计提大幅下降，反哺利润，实现净利润正增长1.66%。
- **[储蓄存款高增与结构优化]** -> [负债成本改善]: 储蓄存款增长9.74%，占比提升至53.05%，推动存款付息率与总负债付息率下降，部分对冲了资产端利率下行压力。
- **[深耕区域战略与“五篇大文章”]** -> [信贷结构优化]: 聚焦“四化”领域、科技金融、绿色金融等，新型工业化贷款增长18.01%，绿色贷款增长11.34%，对冲了传统对公贷款增速放缓。
- **[拨备覆盖率下降]** -> [风险抵补能力边际减弱]: 拨备覆盖率从257.07%降至235.62%，虽仍高于行业平均，但下降趋势表明未来利润调节空间收窄。
- **[个人消费贷款爆发式增长]** -> [零售转型初见成效]: 个人综合消费贷款同比增长98.05%，成为零售贷款增长的主要驱动力，但需关注高增长背后的信用风险。

## 风险警告
**核心风险在于净息差持续收窄与资产质量承压的双重挤压。** 2025年净息差已降至1.58%，LPR下行趋势未改，叠加向实体经济让利，利息收入增长动能持续减弱。同时，不良贷款率微升至1.59%，个人贷款不良率上升0.26个百分点，住宿餐饮、信息技术等小行业风险暴露，拨备覆盖率下降21.45个百分点，表明信用风险压力并未缓解，未来利润增长高度依赖拨备释放，可持续性存疑。

**区域经济集中度与房地产敞口是结构性隐患。** 超95%的贷款集中于贵州省，区域经济波动对资产质量影响巨大。房地产业贷款余额较年初大增19.4%，尽管不良率下降，但在房地产市场深度调整背景下，如此集中的敞口增加了未来风险暴露的不确定性。此外，最大十家客户贷款比率高达30.26%，客户集中度风险不容忽视。
