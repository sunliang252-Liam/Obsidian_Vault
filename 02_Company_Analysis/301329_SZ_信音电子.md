# 301329.SZ 深度透视

## 因果逻辑链
- **[AI产业需求回暖+客户提前拉货]** -> [营收增长14.04%]: 全球AI产业带动电子需求回温，叠加美国关税不确定性导致客户提前备库存，推动公司合并营收增长。
- **[美系新客户智能仓储、低轨卫星产品放量]** -> [营收增长]: 公司成功导入美系品牌客户，应用于智能仓储、低轨卫星等新产品的销售贡献了营收增量。
- **[客户降价+金属原材料涨价]** -> [毛利率承压]: 下游客户要求降价，同时金属原物料价格上涨，共同压缩了产品毛利空间，毛利率同比下降0.25%。
- **[营收增长但毛利率下降+费用增加]** -> [归母净利润下降11.64%]: 尽管营收增长，但毛利率下滑，且销售、管理费用分别增长17.62%和20.35%，导致净利润不增反降。
- **[收购国联电子80%股权]** -> [商誉激增+现金大幅消耗]: 公司以超募资金2.2亿元收购国联电子，形成1.44亿元商誉，并导致货币资金减少23.47%，投资活动现金净流出增加80%。
- **[外销收入占比高+美元计价]** -> [汇率波动风险]: 公司外销收入占比44.77%，主要采用美元结算，美元兑人民币汇率波动对收入和利润影响显著。
- **[笔记本连接器业务依赖大客户]** -> [业绩波动风险]: 公司57.18%营收来自笔记本连接器，且前五大客户销售占比53.35%，下游出货量下滑或客户流失将直接冲击业绩。

## 风险警告
**核心风险在于“增收不增利”与并购整合的双重压力。** 2025年营收增长14%，但净利润反降11.64%，主因是毛利率承压（客户降价与原材料涨价）及费用膨胀。更关键的是，公司以2.2亿超募资金收购国联电子，形成了1.44亿元巨额商誉。若国联电子未来业绩不达对赌预期（2025-2027年累计净利润不低于7900万元），将面临商誉减值风险，直接侵蚀利润。

**业务结构单一与客户集中度风险突出。** 公司57%营收仍依赖传统笔记本电脑连接器，该市场增长乏力且竞争激烈。前五大客户贡献超53%营收，其中关联方SE(USA)占比9.17%，客户集中度过高。一旦主要客户（如惠普、联想、广达等）订单转移或需求萎缩，公司业绩将遭受重大冲击。此外，公司外销占比高，美元汇率波动是持续的利润侵蚀因素。
