# 603355.SH 深度透视

## 因果逻辑链
- **[美国加征关税]** -> [净利润同比下降35.04%]: 公司直接承担汽车零部件出口美国的关税，导致成本大幅增加，利润被侵蚀。
- **[海外产能转移]** -> [规避关税风险]: 2025年二季度完成家电产品生产转移至越南、泰国，消除了中国对美出口关税影响；帕捷泰国工厂年底投产，汽车零部件关税将显著下降。
- **[转移期间成本飙升]** -> [短期利润承压]: 海外新工厂面临招工难、供应链不完备等问题，外派人员支出、运输费用大幅增加，推高了生产成本。
- **[核心零部件业务增长]** -> [对冲家电业务下滑]: 电机、汽车零部件、PCBA业务销售稳中有升，获得新订单，部分抵消了关税和转移成本对整体利润的冲击。
- **[自主品牌高端化]** -> [品牌价值提升但内销承压]: 碧云泉净水机连续10年高端台式净水机销量第一，但国内消费疲软、竞争加剧导致自主品牌业务同比下降。
- **[研发持续投入]** -> [产品创新驱动长期增长]: 每年营收5%左右投入研发，推出天狼星S10 Pro、小积木G5等创新产品，巩固技术领先地位。
- **[财务费用大幅增加]** -> [侵蚀利润]: 利息收入和汇兑收益减少，同时银行借款增加导致财务费用由负转正，从-2.98亿元变为0.76亿元。

## 风险警告
**核心风险：关税与地缘政治风险。** 公司约70%收入来自境外，美国加征关税是2025年利润暴跌的直接导火索。尽管已加速向越南、泰国转移产能，但新工厂爬坡期成本高企，且全球贸易保护主义抬头，未来关税政策的不确定性仍是悬在头顶的利剑。汽车零部件业务因直接承担关税，受冲击最为严重。

**财务风险：高负债与现金流压力。** 2025年末资产负债率飙升至66.68%，短期借款同比大增90%至68.88亿元，财务费用由负转正。同时，公司宣布2025年度不进行现金分红，将利润留存用于发展，这虽是为应对不确定性，但也反映出资金链的紧张。投资活动现金净流出高达52.4亿元，主要用于购买大额存单和固定资产，需警惕投资回报率不及预期的风险。
