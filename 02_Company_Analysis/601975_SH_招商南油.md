# 601975.SH 深度透视

## 因果逻辑链
- **[成品油运价回落]** -> [净利润下降31.73%]: 国际成品油运输市场运价较2022-2024年高位回落，亚太一揽子平均收益同比下降24%，直接导致公司核心业务收入下滑。
- **[运力扩张与订单高企]** -> [市场供需格局再平衡]: 全球MR/LR2新船交付进入高峰期，订单占比高企，未来供给压力将压制运价中枢，削弱公司议价能力。
- **[地缘政治风险溢价]** -> [运价短期剧烈波动]: 红海、霍尔木兹海峡紧张局势及欧美制裁升级，推高市场风险溢价，虽短期利好运价，但增加了运营不确定性与合规成本。
- **[内外贸兼营模式]** -> [抵御单边市场风险]: 公司利用内外贸兼营资质灵活调度船位，平衡内外贸货源不均衡，在成品油外贸市场低迷时，内贸原油运输收入同比增长8.02%，形成对冲。
- **[大客户COA合同]** -> [稳定货源与收益]: 与美孚、中石油、中石化等签订长期COA合同，保障了基础货源，在现货市场波动时提供了收益稳定性，避免经营收益大幅波动。
- **[老旧船舶处置与减值]** -> [资产结构优化与短期利润侵蚀]: 报告期内处置1艘老旧船舶并计提3艘船舶减值准备，合计影响利润约2865万元，但长期看有助于优化船队结构，提升竞争力。
- **[资本公积弥补亏损]** -> [母公司未分配利润转正]: 通过使用资本公积1,570,911,748.21元弥补母公司期初未分配亏损，使母公司未分配利润由负转正，为未来分红扫清障碍。

## 风险警告
**核心风险在于行业周期下行与供给过剩的叠加。** 2025年净利润同比下滑31.73%，主因是成品油运价从历史高位回落，而全球新船交付高峰（MR订单占比14.6%，LR2订单占比33%）将持续压制未来运价中枢。公司虽通过内外贸兼营和COA合同缓冲，但无法完全对冲行业性衰退。若全球经济增速放缓或OPEC+增产不及预期，运价可能进一步承压，导致公司盈利持续恶化。

**地缘政治风险是最大的不确定性变量。** 公司业务高度依赖苏伊士以东航线，红海危机、霍尔木兹海峡紧张局势及欧美对俄伊制裁的升级，不仅威胁船舶航行安全，更可能因次级制裁导致公司被迫调整航线、放弃部分高收益业务，增加合规成本与运营限制。这种“黑天鹅”事件虽可能短期推高运价，但其不可预测性对长期经营稳定构成严重威胁。
