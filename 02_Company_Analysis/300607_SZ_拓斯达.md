# 300607.SZ 深度透视

## 因果逻辑链
- **[战略聚焦“做减法”，剥离低毛利项目类业务]** -> **营收下降但利润反转**: 主动收缩智能能源及环境管理系统业务（收入-25.55%），使整体毛利率从14.59%大幅提升至28.25%，归母净利润扭亏为盈至7,387万元。
- **[产品类业务占比提升，结构优化]** -> **盈利能力增强**: 工业机器人、注塑装备、数控机床三大核心产品营收占比提高6.67个百分点，毛利贡献达60%，成为利润增长的核心引擎。
- **[自产多关节机器人销量增长25.32%]** -> **工业机器人业务竞争力提升**: 凭借大客户策略和工艺优势，自产机器人出货量约12,000台，在轻负载及轻工业领域出货量排名国内第一。
- **[电动注塑机高增长，注塑配套设备海外放量]** -> **注塑装备毛利率提升6.98个百分点**: 精简低毛利液压机，聚焦高毛利电动注塑机，同时海外市场开拓使配套设备收入增长26.86%。
- **[人形机器人“小拓”及四足机器人“星仔”发布]** -> **具身智能商业化落地**: 成功切入具身智能赛道，发布中国首款应用于注塑场景的人形机器人，为未来增长开辟新空间。
- **[X5智能机器人控制平台研发成功]** -> **技术壁垒构建**: 实现云边端部署与感-算-控一体，打通AI大模型与机器人之间的数据隔阂，奠定全栈自研技术基础。
- **[海外收入同比增长近10%，占比达26.29%]** -> **全球化布局初显成效**: 海外销售网络覆盖超50个国家，服务近千名海外客户，成为业绩增长的重要补充。
- **[可转债摘牌，财务费用同比减少2,745.70万元]** -> **利润端直接受益**: 债务结构优化，利息支出大幅下降，直接增厚了当期净利润。

## 风险警告
**核心风险在于战略转型的阵痛与应收账款的双重压力。** 公司主动剥离智能能源及环境管理系统业务，导致营收规模短期大幅下滑（-12.59%）。虽然利润端实现反转，但新业务（尤其是具身智能）的商业化规模和盈利能力尚未得到充分验证，若下游需求复苏不及预期或新产品推广受阻，业绩增长的可持续性存疑。此外，尽管应收账款规模已从高点回落，但账面价值仍高达10.28亿元，且主要来自过往的锂电、光伏客户，其经营不确定性依然存在，潜在的坏账风险是悬在利润表上的一把利剑。

**技术迭代与人才竞争是长期隐忧。** 公司所处的工业机器人和具身智能领域技术迭代极快，竞争对手（包括国际巨头和国内新锐）实力强劲。公司虽在轻负载领域领先，但在高端多关节机器人及核心零部件（如减速器、编码器）上仍依赖外部供应链。同时，作为技术密集型企业，对复合型人才的需求极为迫切，而行业内人才争夺激烈，若不能持续提供有竞争力的薪酬和发展平台，可能导致核心技术人员流失，削弱技术护城河。
