# 603813.SH 深度透视

## 因果逻辑链
- **[传统燃油车市场萎缩]** -> [汽车零部件物流收入骤降33.83%]: 下游主机厂订单减少，导致公司核心业务收入大幅下滑，但仓库租金、车辆折旧等固定成本刚性，毛利率被严重侵蚀。
- **[大力拓展非汽车物流]** -> [非汽车物流收入逆势增长53.35%]: 公司主动切入电商、能源、航空等新赛道，对冲了传统主业下滑，使总营收实现5.93%的正增长。
- **[新业务“以价换量”]** -> [综合毛利率暴跌8.12个百分点至8.81%]: 为快速抢占市场，新业务初期毛利率偏低，叠加传统业务成本刚性，导致增收不增利，亏损加剧。
- **[收购和川友]** -> [开启“制造+物流”双轮驱动]: 通过同一控制下合并，将汽车零部件制造能力内化，旨在形成供应链闭环，打造第二增长曲线。
- **[氢能重资产投入]** -> [投资活动现金流大幅净流出1.04亿元]: 公司为响应“双碳”战略，采购氢燃料电池车及建设空港物流中心，导致资本开支激增，现金流承压。
- **[融资渠道收窄]** -> [财务费用激增23.6%]: 因被实施退市风险警示，公司融资成本上升，同时新项目贷款及租赁利息增加，进一步侵蚀利润。
- **[应收账款回款延迟]** -> [应收账款同比暴增97.56%]: 部分客户回款周期延长，导致资金占用增加，加剧了公司的流动性压力。

## 风险警告
**核心风险在于“转型失速”与“财务恶化”的恶性循环。** 公司正处在从传统汽车物流向综合物流的艰难转型期，新业务虽带来收入增长，但“以价换量”的扩张模式导致毛利率大幅下滑，亏损额同比扩大35%。更危险的是，公司已被实施退市风险警示（*ST），融资能力严重受限，而氢能车辆、空港物流中心等战略项目又需要巨额资本开支，这导致投资活动现金流大幅净流出，公司不得不依赖新增银行贷款维持运营，财务费用高企，进一步吞噬利润。

**第二重风险是资产减值的“灰犀牛”。** 公司账面存在高达4.82亿元的使用权资产和3.81亿元的固定资产，且审计师已将“长期资产减值”列为关键审计事项。传统燃油车业务萎缩导致部分仓储和运输资产利用率下降，若未来业务转型不及预期，可能面临大规模资产减值风险，对净资产造成重大冲击。此外，公司仍有大量历史诉讼形成的应收款项尚未收回，信用减值风险持续存在。
