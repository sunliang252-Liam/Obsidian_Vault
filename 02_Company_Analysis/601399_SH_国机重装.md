# 601399.SH 深度透视

## 因果逻辑链
- **[在手订单增长与产出加快]** -> [营业收入增长9.48%]: 研发与制造板块在手订单增长，公司合理组织生产，产出加快，推动收入同比增加12.01亿元。
- **[汇率波动导致汇兑损失]** -> [财务费用同比增加0.67亿元]: 汇率变动导致汇兑损失同比增加，使财务费用从-1.43亿元上升至-0.77亿元。
- **[加大生产投入与现金流出]** -> [经营活动现金流净额下降42.08%]: 公司加大生产投入，购买商品、接受劳务支付的现金流出同比增加，导致经营性现金流净额从17.27亿元降至10.00亿元。
- **[高端电站铸锻件与冶金装备订单增长]** -> [合同成交额增长23.06%]: 高端电站铸锻件订单高位增长，冶金装备和锻压设备多点开花，推动全年合同成交额达217.48亿元。
- **[全员精益与全面数智行动]** -> [运营效率大幅提升]: 开展“样板引领+提案筑基”改善活动，重点产品制造周期平均缩短18%以上，成台套产品准交率大幅提升。
- **[海外工程总包项目突破]** -> [国外业务收入增长24.92%]: 成功签订喀麦隆钢铁综合设施总承包等项目，带动国外业务收入增长，但毛利率因成本上升下降2.73个百分点。
- **[母公司累计未弥补亏损]** -> [连续多年不进行现金分红]: 截至2025年末，母公司未分配利润为-101.23亿元，根据公司章程，不进行利润分配。
- **[政府补助与资产减值损失]** -> [非经常性损益对利润影响显著]: 计入当期损益的政府补助6190万元，但资产减值损失1.94亿元和信用减值损失1.34亿元，对利润形成较大侵蚀。

## 风险警告
**核心风险在于历史包袱沉重与现金流恶化。** 母公司累计未弥补亏损高达101.23亿元，导致公司长期无法分红，严重制约股东回报。同时，2025年经营活动现金流净额同比骤降42.08%至10亿元，而同期净利润仅4.64亿元，利润的现金保障程度极低。应收账款和存货合计高达84.81亿元，占流动资产的36.3%，减值风险持续累积，2025年信用及资产减值损失合计达3.28亿元，直接吞噬了超过70%的净利润。

**市场竞争加剧与海外业务不确定性是另一大隐患。** 重型机械行业竞争激烈，价格战压缩利润空间，公司研发与制造板块毛利率同比下降1.46个百分点。海外业务虽增长迅速，但面临地缘政治、汇率波动及大宗商品价格波动等多重风险。公司持有大量外币资产，汇率变动已导致财务费用增加，且海外项目回款周期长，进一步加剧了现金流压力。
