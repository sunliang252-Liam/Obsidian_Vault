# 301083.SZ 深度透视

## 因果逻辑链
- **[核心业务收入下滑]** -> [营收下降12.75%]: 车行管理设备、系统集成收入分别下降11%和55.92%，国内市场需求疲软。
- **[非经常性损益依赖]** -> [扣非净利润暴跌61.99%]: 扣非净利润仅671.7万元，而净利润3050万元，差额主要来自应收款项减值转回（1128万）和金融资产收益（1034万）。
- **[应收账款回收改善]** -> [经营现金流大幅转正]: 收回部分上期未回款，经营现金流从-648万跃升至3995万，同比+716%。
- **[新能源充电业务布局]** -> [新增长点初现]: 中标南昌县充换电设施项目（27座站、373台终端），但当前充电设备收入仅652万，占比1.87%，尚未形成规模。
- **[募投项目大幅缩水]** -> [产能扩张预期减弱]: 智能生产基地投资从2.7亿砍至1.09亿，研发中心从3731万砍至2459万，剩余1.75亿募集资金用途未定。
- **[海外市场逆势增长]** -> [对冲国内下滑]: 海外收入增长8.44%至7099万元，占比提升至20.33%，毛利率36.73%显著高于国内。
- **[研发投入聚焦机器人]** -> [战略转型信号]: 设立机器人智能产品研发部，探索巡检机器人关节模组，但研发投入1985万全部费用化，暂无资本化成果。

## 风险警告
**核心风险在于主业萎缩与增长引擎缺失。** 公司营收连续两年下滑（2024年+3%，2025年-12.75%），核心车行管理设备收入下降11%，系统集成收入更是腰斩（-55.92%）。扣非净利润仅671.7万元，创上市以来新低，表明主营业务盈利能力已接近盈亏平衡点。公司试图通过新能源充电和机器人业务转型，但充电业务当前收入占比不足2%，机器人尚处样机测试阶段，短期内无法贡献利润。

**财务质量存在隐忧。** 公司净利润高度依赖非经常性损益（占比78%），其中应收款项减值转回1128万元具有一次性特征，不可持续。同时，募投项目大幅缩水后，剩余1.75亿募集资金用途未明确，存在资金闲置或低效使用的风险。此外，公司存货跌价损失377.9万元，显示部分产品面临滞销压力。在行业竞争加剧、原材料价格波动的背景下，公司若不能尽快找到新的业绩支撑点，盈利能力将持续承压。
