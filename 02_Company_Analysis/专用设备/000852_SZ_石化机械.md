# 000852.SZ 深度透视

## 因果逻辑链
- **[国际油价震荡下行]** -> [上游勘探投资缩减]: 油价下跌直接导致油公司缩减资本开支，减少设备采购，引发行业“量价齐跌”。
- **[国内装备市场“内卷式”价格竞争]** -> [核心产品平均售价下降]: 客户降本压力传导，公司钻修装备、压裂装备、油气钢管等产品被迫降价，直接侵蚀毛利。
- **[碳化钨、特种钢材等核心原材料价格上涨]** -> [单位成本不降反升]: 成本端刚性上涨，与售价下降形成“剪刀差”，进一步压缩利润空间。
- **[国内长输管线建设放缓]** -> [油气钢管收入下降8.87%]: 国家管网集团成立后建设节奏放缓，社会市场低价竞争，导致钢管业务量价承压。
- **[坚持“以技术守份额”战略]** -> [万米深井钻头市占率超80%]: 公司未陷入低价竞争，而是聚焦高端市场，巩固了在深地工程等领域的领先地位。
- **[海外市场“专业化、高端化、国际化”拓展]** -> [海外订货增长23%]: 高端钻机、压缩机、钢管等产品成功切入科威特、阿联酋等国际头部企业供应链。
- **[氢能产业政策落地与中石化战略部署]** -> [氢能装备营收同比增长21.86%]: 公司依托传统压缩机技术协同，在加氢站、制氢项目上取得突破，培育第二增长曲线。
- **[加大货款回收力度与现金流管理]** -> [经营现金流净额由负转正至5.9亿元]: 通过“现金流为王”的考核导向，有效改善了资金周转效率，对冲了利润下滑风险。

## 风险警告
**核心风险在于业绩对上游勘探投资的高度依赖与盈利能力的脆弱性。** 2025年营收利润双降，核心症结是“价格下行”与“成本刚性”的剪刀差扩大，导致扣非净利润亏损2629万元。公司近九成收入来自境内，且前五大客户销售占比超60%，其中关联方销售占比42.49%，客户集中度极高，议价能力受限。若国际油价持续低迷或国内勘探投资进一步缩减，公司主业将面临更大的量价压力。

**第二增长曲线尚在培育期，短期难以贡献稳定利润。** 氢能装备业务虽增长迅速，但营收仅0.7亿元，且毛利率为负（-3.49%），仍处于亏损培育阶段。氢能装备集成制造与测试项目已延期至2028年，技术路线尚未完全定型，市场化订单存在不确定性。同时，母公司未分配利润为-7.03亿元，不满足现金分红条件，公司缺乏通过分红回报股东的能力，投资回报主要依赖股价波动。
