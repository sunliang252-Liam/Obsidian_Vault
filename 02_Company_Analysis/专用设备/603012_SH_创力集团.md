# 603012.SH 深度透视

## 因果逻辑链
- **[下游煤炭行业景气度下行]** -> [公司营收与利润双降]: 2025年煤炭行业营收同比下降17.8%、利润总额同比下降41.8%，下游客户资本开支收缩，直接导致公司采煤机销量下降及成套项目收入归零。
- **[应收账款账龄迁徙与坏账计提]** -> [信用减值损失激增76%]: 下游客户回款压力加大，应收账款账龄结构恶化，公司2025年计提信用减值损失1.51亿元，同比增加0.65亿元，成为侵蚀利润的核心因素。
- **[无成套项目收入确认]** -> [营收结构性下滑]: 2024年有大型成套项目收入确认，2025年该类收入归零，叠加采煤机销量下降14.91%，导致总营收同比下滑15.84%。
- **[研发投入与数字化建设加码]** -> [管理费用与研发费用刚性增长]: 设立中央研究院、推进矿山装备大模型及ERP系统建设，研发费用同比增12.65%，管理费用增3.86%，在收入下滑背景下进一步压缩利润空间。
- **[并购贷款与租赁负债增加]** -> [财务费用大幅攀升]: 为收购中煤液压等子公司新增并购贷款，叠加子公司厂房租赁增加，财务费用同比增59.92%，侵蚀净利润。
- **[单轨吊与矿山节能减排业务高增]** -> [产品结构局部优化]: 单轨吊业务收入同比增64.46%，矿山节能减排产品收入增74.30%，部分对冲了核心采掘设备的下滑，但体量尚不足以扭转整体颓势。
- **[非经常性损益波动]** -> [归母净利润降幅大于扣非净利润]: 2024年因债务重组产生大额非经常性损失，2025年该事项消失，导致归母净利润降幅（-50.48%）小于扣非净利润降幅（-63.44%）。

## 风险警告
**核心风险在于下游煤炭行业景气度持续下行与公司应收账款质量恶化形成的负反馈循环。** 2025年煤炭行业利润总额暴跌41.8%，客户资本开支意愿和能力显著下降，直接导致公司核心产品采煤机销量下滑、成套项目停滞。更严重的是，下游回款困难已传导至公司资产负债表：2025年末应收账款高达29.73亿元，占总资产35.2%，公司为此计提了1.51亿元信用减值损失，同比暴增76%。若煤炭行业景气度未见反转，应收账款账龄继续迁徙，减值压力将持续压制利润，形成“收入降→回款难→减值增→利润崩”的恶性循环。

**战略转型的阵痛与财务杠杆的攀升构成双重压力。** 公司正从传统设备制造商向“数智化成套装备服务商”转型，研发投入（+12.65%）和数字化建设支出刚性增长，但转型成效尚未在收入端体现。同时，为支撑并购和产能扩张，公司大幅增加并购贷款和租赁负债，导致财务费用同比飙升59.92%，长期借款增长149.39%。在主营业务造血能力下降的背景下，高额的资本开支和利息支出将加剧现金流压力，2025年经营性现金流已同比下滑35.58%，财务稳健性面临考验。
