# 601717.SH 深度透视

## 因果逻辑链
- **[煤机板块成套化、智能化战略]** -> [收入稳增，利润承压]: 公司以液压支架为核心，推广成套装备解决方案，带动收入增长9.44%；但煤炭行业下行、竞争加剧，导致利润空间被压缩，净利润同比下降6.87%。
- **[汽车零部件板块新能源转型突破]** -> [板块利润大幅增长85.31%]: 高压驱动电机、热管理冷板等新业务实现从0到1的销售突破，叠加SEG降本增效，板块净利润同比大增48.63%，成为集团利润增长的核心引擎。
- **[SEG盈利能力显著提升]** -> [集团归母净利润增长9.14%]: 通过降本增效措施，SEG净利润同比增加3.4亿元，成功扭亏为盈，是集团整体利润增长的主要贡献者。
- **[战略更名与业务重组]** -> [治理架构清晰，品牌矩阵协同]: 更名为“中创智领”，并将煤机业务下沉至子公司，母公司聚焦战略管控与投资，形成煤机、汽车零部件、工业智能三大独立品牌，提升管理效率。
- **[工业智能板块整合]** -> [打造第三增长曲线]: 以恒达智控为核心，整合内部资源，聚焦智慧矿山与智能工厂，年内获取多个跨行业标杆项目，目标成为百亿级增长极。
- **[应收账款大幅增长49.79%]** -> [经营现金流恶化39.02%]: 收入增长的同时，回款速度下降，导致应收账款激增，购买商品支付的现金增加，经营活动现金流净额大幅下滑，盈利质量承压。
- **[计提商誉及资产减值]** -> [侵蚀第四季度利润]: 第四季度计提商誉减值0.88亿元（亚新科双环）及长期股权投资减值0.86亿元，导致单季净利润环比大幅下降，凸显并购整合风险。

## 风险警告
**核心风险在于盈利质量与资产减值。** 公司2025年营收与净利润双增，但经营现金流净额同比暴跌39%，应收账款激增近50%，表明利润增长并未有效转化为现金，回款压力巨大。同时，第四季度集中计提大额商誉及资产减值，暴露出过往并购（如亚新科双环）的整合效果不及预期，未来若下游客户经营恶化，减值风险将持续存在。

**另一大风险是煤机业务的周期性下行。** 尽管公司通过智能化、成套化策略维持了收入增长，但煤炭行业利润总额同比下降41.8%，行业景气度下行已传导至公司煤机板块，导致其净利润下滑。作为集团的“压舱石”，若煤炭需求持续疲软，煤机板块的利润将进一步承压，对集团整体业绩构成重大威胁。

**公司简介（F10 原文）**

> 中创智领(郑州)工业技术集团股份有限公司(以下称“中创智领”)始建于1958年,前身为郑煤机集团,是全球规模最大的煤矿综采技术和装备供应商、国际领先的汽车零部件制造企业。作为A+H股上市公司,中创智领业务涉及煤矿机械、汽车零部件、工业智能、投资等多个业务板块,拥有31个生产研发销售基地,遍布全球17个国家。2019年9月,习近平总书记莅临视察,对企业的改革发展和产业转型所取得的成果给予充分肯定。公司煤矿机械板块主要经济指标连续十余年居行业龙头,国内市场占有率保持在30%以上。煤矿综采机械产品遍布全国各大煤业集团,先后出口到美国、澳大利亚、土耳其、印度、越南等国家。郑煤机拥有国家级企业技术中心、博士后科研工作站等科研机构,先后承担了国家多项煤矿综采装备重点项目的研制开发,引领了中国煤矿综采装备的发展方向。公司汽车零部件产业板块于2016年通过并购的方式整合建立,包括汽车零部件板块和汽车电机板块。截至目前,公司汽车零部件产业板块旗下拥有德国SEG集团、亚新科集团两大品牌,SEG拥有完善的产品组合,涵盖乘用车和商用车起动机、发电机、启停电机和轻混能量回收系统(BRM),在全球有9个生产基地和研发中心,并在12个国家有销售代表处。公司全资企业芝麻街实业有限公司是投资业务板块的首个尝试,对西厂区658亩工业用地重新规划,着力发展城市更新类的产业运营地产,打造文科双创、跨界融合的空间载体与运营模式,保留城市记忆,形成多样社区,平衡环境与发展。同时在省市以及全国范围内吸引导入一大批高素质产业人才,不断培养产业人才形成新生力量,为区域注入源源不断的产业活力。
