# 603895.SH 深度透视

## 因果逻辑链
- **[锂电业务大幅收缩与人员优化]** -> [费用骤降，扭亏为盈]: 2025年公司主动收缩亏损严重的锂电智能装备业务，导致该板块收入同比大降79.24%，但同时大幅裁减相关员工，使得销售、管理、研发费用合计同比大幅下降约42%，是公司从巨亏1.78亿到盈利1839万的核心原因。
- **[核心主业发动机智能装备收入大增]** -> [营收规模恢复增长]: 作为公司传统优势业务，发动机智能装备及信息系统集成收入同比大增86.69%，贡献了总营收的67%，弥补了锂电和焊装业务的萎缩，拉动整体营收增长13.52%。
- **[大股东借款大幅增加]** -> [缓解现金流压力，但推高负债]: 报告期内，公司收到大股东借款增加，筹资活动现金净流入3453万元（上年为净流出6184万元），同时其他应付款（主要为大股东借款）从9876万暴增至2.16亿，公司资产负债率仍高达90.25%，财务风险并未根本解除。
- **[计提大额资产减值损失减少]** -> [利润改善]: 2024年公司计提了6608万元的资产减值损失，而2025年这一数字降至1249万元，同比大幅减少，对利润的侵蚀显著降低，是扭亏的重要非经营性因素。
- **[客户以承兑汇票支付货款增加]** -> [经营性现金流净额下降]: 尽管公司扭亏，但经营活动现金流净额从2329万降至1974万，同比下降15.22%，主要原因是客户使用承兑汇票结算的比例增加，导致现金回款相对减少。
- **[人形机器人业务中标]** -> [开辟新增长曲线]: 公司成功中标智元创新2026年度框架采购项目，并已获得相关订单，标志着公司正式切入人形机器人赛道，为未来业务发展提供了新的想象空间。

## 风险警告
**核心风险在于公司盈利的可持续性。** 2025年的扭亏主要依赖对亏损业务的“断臂求生”和费用端的强力压缩，而非主营业务的强劲内生增长。公司核心的发动机业务虽增长，但毛利率仅微增0.15个百分点；而曾被寄予厚望的锂电业务收入暴跌近80%，显示公司在新兴赛道的战略布局遭遇重大挫折。同时，公司合并资产负债率高达90.25%，未分配利润为-3.06亿元，存在巨大的历史亏损窟窿，财务结构极为脆弱。

**第二大风险是居高不下的应收账款与存货风险。** 公司应收账款及合同资产合计高达2.69亿元，存货账面价值3.68亿元（已计提1.38亿跌价准备），两者合计占总资产的58%。在行业竞争加剧和下游客户（尤其是新能源车企）资金链紧张的背景下，坏账风险和存货跌价风险是悬在利润表上的达摩克利斯之剑。公司虽已计提大量减值，但若下游客户经营恶化，未来仍有继续大额计提的可能，随时可能再次将公司拖入亏损。
