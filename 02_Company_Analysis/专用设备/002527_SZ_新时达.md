# 002527.SZ 深度透视

## 因果逻辑链
- **[海尔集团入主]** -> **扭亏为盈**: 海尔赋能供应链降本10%以上、导入大客户资源，叠加内部管理变革，使公司2025年归母净利润从-2.88亿转为+550万，实现关键性扭亏。
- **[电梯业务“存量+出海”转型]** -> **收入韧性**: 面对国内新梯市场下滑6%，公司通过海外业务收入增长9%及在用梯改造、智能化升级，使电梯控制产品收入仅微降1.81%，维持基本盘稳定。
- **[通用控制与驱动业务放量]** -> **收入增长主引擎**: 受益于设备更新政策及OEM市场回暖，该板块收入同比增长12.56%至17.93亿元，贡献了公司总营收增量的主要部分。
- **[机器人业务聚焦场景化]** -> **差异化突围**: 在行业竞争加剧背景下，公司推出免示教焊接工作站、高速SCARA及协作机器人，聚焦3C、汽车等场景，实现机器人收入同比增长5.97%。
- **[研发投入持续加码]** -> **技术壁垒构建**: 研发费用同比增长15.67%至2.35亿元，重点投向AI平台、具身智能机器人及“视驱控一体化”方案，为长期竞争力蓄力。
- **[财务费用大幅下降]** -> **利润改善**: 贷款规模及利率下降使财务费用同比减少43.72%，直接贡献了利润端的改善，是扭亏的重要财务因素。
- **[信用减值损失转回]** -> **利润增厚**: 公司加强应收账款管理，账龄优化，信用减值损失转回2013万元，对利润总额贡献达155%，是扭亏的关键非经常性因素。

## 风险警告
公司虽实现扭亏，但扣非净利润仍为-6037万元，盈利质量堪忧。核心风险在于：**通用控制与驱动业务（占收入51%）增长可持续性存疑**，该板块高度依赖设备更新政策及OEM市场景气度，若宏观经济波动导致下游投资放缓，收入增长将承压。同时，**机器人业务毛利率仅11.56%且同比下降**，在国产替代竞争白热化背景下，价格战可能进一步侵蚀利润。

另一重大风险是**定增落地的不确定性**。公司拟向海尔卡奥斯工业智能募资12.19亿元，目前仍在深交所审核中。若定增失败或严重延迟，公司将面临资金压力，且与海尔集团的深度协同（如供应链整合、场景落地）可能不及预期，削弱公司长期战略转型的支撑。此外，母公司未分配利润仍为-9.73亿元，短期内不具备分红能力。
