# 301128.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [AI服务器液冷散热及检测设备订单激增]: 公司凭借与老客户的深度合作关系，切入北美AI龙头及国内头部服务器厂商的液冷服务器组装线、检测设备及散热模组（maniford中央分水器）供应链。
- **[外延并购战略]** -> [业务版图扩张至机器人电机与半导体设备]: 收购旭益达（无刷电机）和深圳国瑞，分别贡献1.03亿元和1.46亿元收入，快速切入扫地机器人电机和半导体设备精密结构件等高增长赛道。
- **[苹果产业链深度绑定]** -> [移动智能终端业务稳健增长]: 作为苹果全球龙头代工厂的核心治具/设备供应商，受益于客户产线新建及更新，2025年该领域收入8.36亿元，同比增长23%。
- **[智能汽车产线放量]** -> [第二增长曲线形成]: 针对国内新能源汽车龙头厂商的车灯组装和检测线体在报告期内大量交付，智能汽车领域收入3.20亿元，同比暴增160%。
- **[核心能力复用]** -> [“工具”与“产品”双轮驱动]: 公司强大的定制化研发设计和精密加工能力，使其能无缝从“治具/设备”（工具）拓展至“精密结构件/散热模组”（产品），拓宽市场空间。
- **[天睿工业机器人项目]** -> [长期战略布局，重塑机加工行业]: 2025年启动，投入超2000万元研发，旨在实现精密加工全流程自动化闭环，打造无人化车间，未来有望成为新的收入增长极。
- **[客户集中度高]** -> [业绩高度依赖核心大客户]: 前五名客户销售额占比高达67.43%，其中第一大客户（华为系）占比18.16%，客户订单波动直接影响公司业绩。

## 风险警告
**核心风险在于客户集中度极高与毛利率持续下滑的双重压力。** 公司前五大客户贡献超67%营收，且第一大客户华为系占比近20%，任何核心客户的订单波动或供应链调整都将对公司业绩造成剧烈冲击。同时，2025年综合毛利率下降4.68个百分点至25.63%，设备类产品毛利率更是骤降11.49个百分点至18.88%，反映出新业务扩张期面临的成本上升和价格竞争压力，若无法有效控制成本，盈利能力将持续承压。

**第二重风险是激进的并购整合与高昂的研发投入带来的不确定性。** 公司通过并购快速切入新领域，但深圳国瑞、强瑞超能等新并表子公司仍处于亏损状态，整合效果尚待验证。此外，公司对“天睿工业机器人”项目投入巨大（2025年超2000万元），该项目尚处于内部测试阶段，商业化落地时间与效果均存在重大不确定性，若失败将造成大量研发沉没成本。叠加因业务扩张导致的借款增加（短期借款+长期借款超3.5亿元），财务费用同比暴增669%，财务风险显著上升。
