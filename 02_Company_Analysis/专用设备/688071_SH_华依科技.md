- **[测试服务产能扩张，固定成本刚性增长]** -> [净利润持续亏损]: 测试服务业务处于产能爬坡期，场地、设备折旧及人力等固定成本随产能扩张同步大幅增加，但收入增长尚未覆盖全部营运成本，导致利润承压。
- **[惯导业务进入规模化量产，初期成本高企]** -> [短期经营效益承压]: 惯导业务订单与收入增长，但量产阶段原材料、制造及运维成本同步上升，规模效应尚未显现，成本摊薄效应未实现。
- **[高额有息融资支撑扩张]** -> [财务费用高企，加剧利润压力]: 为满足募投项目、日常经营及量产备货资金需求，公司维持较高有息负债，产生大量财务费用，进一步侵蚀利润。
- **[动力总成测试设备业务竞争加剧]** -> [毛利率下滑]: 行业竞争加剧，公司为拓展重点客户新业务，叠加物料成本上升，导致测试设备产品毛利率下降。
- **[新能源汽车动力总成测试服务收入增长]** -> [营收持续增长]: 依托市场需求拓展，测试服务业务收入实现持续稳步上涨，带动总营收同比增长20.45%。
- **[智能驾驶业务（惯导）收入高速增长]** -> [营收结构优化]: 智能驾驶业务（含高精度惯导）收入同比增长103.85%，成为公司新的增长极，营收占比提升。
- **[研发投入持续，技术壁垒构建]** -> [核心竞争力巩固]: 公司持续研发投入，在惯导、测试设备等领域积累专利与软件著作权，形成技术护城河，支撑长期发展。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长20.45%，但净利润亏损扩大31.9%。根本原因是业务扩张（测试服务产能、惯导量产）带来的固定成本（折旧、租金、人工）和制造成本刚性增长，远超收入增速。同时，为支撑扩张而维持的高额有息负债，导致财务费用高企，进一步吞噬利润。若产能爬坡和规模效应无法在短期内兑现，亏损可能持续甚至扩大。

**另一重大风险是应收账款高企与现金流恶化。** 应收账款账面价值高达5.71亿元，占总资产24.42%，且同比增长32.78%，远超营收增速。虽然经营性现金流净额仍为正，但已同比下降26.13%。若下游客户（尤其是车企）经营状况恶化或付款周期延长，公司将面临巨大的坏账风险和现金流压力，可能被迫继续增加有息负债，形成财务上的恶性循环。
