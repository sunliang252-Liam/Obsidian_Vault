# 605286.SH 深度透视

## 因果逻辑链
- **[新能源电站项目股权转让]** -> [投资收益暴增]: 处置联营公司股权，将前期顺流交易未实现损益转回，确认约2.99亿元非经常性投资收益，是净利润的主要来源。
- **[电梯部件业务毛利率下降]** -> [扣非净利润暴跌]: 受房地产低迷及原材料波动影响，电梯部件毛利率下降1.98个百分点，导致扣非净利润同比下滑73.48%。
- **[新能源业务收入确认节奏]** -> [营收与现金流背离]: 新能源业务部分收入在往年已预收，本期收入确认减少，同时应付账款大幅下降，导致营收下降15%的同时，经营性现金流由正转负至-9003万元。
- **[储能电站项目并网与转让]** -> [新能源业务利润稳定]: 承德围场共享储能电站并网运营，贡献容量租金和电力交易收入，支撑天启鸿源净利润2.7亿元，同比微增0.76%。
- **[储能系统集成产能落地]** -> [未来增长点]: 天津4GWh储能总装工厂投产，并中标中国能建22GWh集采，为储能系统集成业务规模化奠定基础。
- **[电梯“以旧换新”政策]** -> [电梯业务结构性机会]: 国家安排189亿元国债支持老旧电梯更新，公司作为头部供应商，有望受益于存量更新需求释放，对冲新梯市场下滑。
- **[算电协同新业务探索]** -> [第二增长曲线]: 与庆阳市政府、甘肃移动等合作，布局数据中心绿色能源管理，探索“算力+储能”新模式，但尚处早期。

## 风险警告
**核心风险在于利润质量与现金流恶化。** 2025年扣非净利润仅6417万元，同比暴跌73%，而净利润1.99亿主要依赖处置电站项目的一次性投资收益（约2.99亿），可持续性存疑。同时，经营性现金流净额由正转负至-9003万元，显示公司回款能力或项目结算节奏出现重大问题，财务健康度显著下降。

**双主业均面临结构性挑战。** 电梯业务受房地产下行周期拖累，毛利率持续承压，虽有“以旧换新”政策对冲，但效果需时间验证。新能源业务虽前景广阔，但储能电站安全运行风险、电力市场机制不完善导致收益不确定，且公司大规模举债（长期借款从1800万激增至5.79亿）建设储能项目，财务杠杆快速攀升，增加了偿债压力。
