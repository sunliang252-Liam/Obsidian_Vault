## 因果逻辑链
- **[煤价下行导致客户压缩开支]** -> [营收与利润双降]: 2025年煤炭均价降低，煤企利润空间下降，客户推迟或取消非紧急维修，导致公司营收同比-9.01%，归母净利润同比-38.31%。
- **[高毛利业务收入大幅下滑]** -> [利润降幅远超营收]: 毛利率较高的备品配件供应管理（-36.38%）和专业化总包服务（-17.38%）收入下滑，拉低整体毛利，导致净利润降幅（-38.31%）显著大于营收降幅（-9.01%）。
- **[母公司内部借款坏账计提]** -> [母公司净利润为负]: 母公司以借款形式将IPO募集资金汇至子公司，因账龄增加计提坏账准备6,369.97万元，导致母公司净利润为负，拖累合并报表利润。
- **[煤企降本转向二手设备]** -> [二手设备租售业务逆势增长]: 煤企利润承压，部分煤矿选择性价比更高的二手设备，推动公司二手设备租售业务收入同比增长18.34%，成为业绩对冲项。
- **[流体连接件跨行业拓展]** -> [非煤业务抗风险能力显现]: 流体连接件业务切入盾构、农机等领域，在煤炭行业下行背景下，收入同比增长19.02%，成为公司经营的重要支撑。
- **[专业化总包项目成本冲回]** -> [该业务毛利率大幅提升]: 石圪台项目合同完结，前期预提维修成本一次性冲回，导致专业化总包服务毛利率同比提升20.46个百分点，但该收益不可持续。
- **[IPO募资与理财收益]** -> [非经常性损益增厚利润]: 公司利用闲置募集资金购买理财产品，报告期内产生公允价值变动损益1,338.52万元，占归母净利润的15.46%，掩盖了部分主业下滑的颓势。
- **[大客户集中度高]** -> [经营业绩波动风险大]: 前五大客户销售额占比59.38%，其中客户1（国家能源集团）占比30.25%，客户采购计划的波动直接对公司业绩产生重大影响。

## 风险警告
**核心风险：业绩对煤价与单一客户高度敏感，盈利质量恶化。** 公司2025年营收与利润双降，核心原因是煤价下行导致大客户（前五大客户占营收59.38%）压缩开支，高毛利的备品配件与总包业务首当其冲。这种对下游景气度的强依赖，使得公司业绩具有明显的周期性特征。更值得警惕的是，母公司因内部借款计提坏账导致亏损，暴露出IPO资金使用与内部管理上的瑕疵，且公司已因此收到监管警示函。

**成长性风险：新业务拓展尚处早期，海外布局未产生效益。** 公司寄予厚望的非煤业务（农机、石油装备）和海外业务（澳大利亚）均处于初期投入阶段，短期内难以贡献利润。在传统煤机业务承压的背景下，新增长极的培育需要时间与资金，若拓展进度不及预期，公司将面临主业下滑与投入增加的双重压力，盈利拐点尚不明确。
