# 600520.SH 深度透视

## 因果逻辑链
- **[收购众合半导体]** -> [营收增长20%，但净利润下降65%]: 收购带来7,087万元并表收入，但整合期费用（管理、销售、研发）及信用减值损失激增，侵蚀了利润。
- **[控股股东变更为合肥产投]** -> [战略定位升级为“控股型上市公司”]: 依托国资平台资源，确立“内生增长+外延并购”双轮驱动战略，为后续产业整合铺路。
- **[切入先进封装赛道]** -> [研发投入聚焦晶圆级/面板级封装设备]: 为打破TOWA、YAMADA等海外巨头垄断，公司集中资源攻关“压缩成型封装”等关键技术，以抢占国产替代窗口。
- **[海外市场拓展]** -> [成功导入ST、UNISEM等国际客户]: 通过设立东南亚销售中心、参展K展，半导体及挤出模具业务海外收入同比增长26.88%，对冲了国内需求波动。
- **[传统挤出模具业务承压]** -> [国内营收下滑10.73%]: 受国内房地产周期及下游减产影响，该板块收入萎缩，但公司通过转向高端节能门窗及海外市场维持基本盘。
- **[商誉激增]** -> [形成6,576万元商誉]: 收购众合半导体产生大额商誉，若其未来业绩不达承诺（2025年实际完成率仅13.4%），存在减值风险。
- **[母公司未弥补亏损]** -> [连续多年不分红]: 截至2025年末，母公司未弥补亏损高达3.03亿元，严重制约了分红能力，股东回报预期低迷。

## 风险警告
**核心风险：并购整合与业绩对赌失败。** 公司以1.21亿元收购众合半导体，但后者2025年业绩承诺完成率仅13.4%（实际804万 vs 承诺1,150万），首年即大幅偏离目标。若未来两年无法兑现累计6,000万元的业绩承诺，公司将面临商誉减值（6,576万元）与现金补偿纠纷的双重打击，直接冲击资产负债表和利润表。

**次要风险：盈利能力脆弱与现金流隐忧。** 尽管营收增长20%，但扣非净利润仅481万元，净利率不足1.3%。应收账款激增66.78%至2.96亿元，远超营收增速，显示回款压力加大。同时，公司为收购及运营大幅举债，长期借款从0增至9,365万元，财务费用由负转正，未来利息支出将持续侵蚀利润。
