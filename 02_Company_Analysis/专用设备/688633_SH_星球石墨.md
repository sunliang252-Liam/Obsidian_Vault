# 688633.SH 深度透视

## 因果逻辑链
- **[海外大单落地]** -> [营收与利润双增]: 印度100万吨绿色PVC项目合同交付，贡献收入约1.5亿元，直接拉动总营收增长27.47%，并有效对冲国内市场价格竞争压力。
- **[产业链向上游延伸]** -> [原材料自主可控]: 子公司内蒙古新材料石墨材料产线投产，实现核心原料自给，降低对外部供应商依赖，但该业务目前毛利率仅10.24%，尚处爬坡期。
- **[国内竞争加剧]** -> [国内业务毛利率承压]: 国内石墨设备市场竞争激烈，中低端换热器领域价格战导致国内业务毛利率同比下降7.69个百分点。
- **[海外高毛利订单]** -> [整体毛利率结构优化]: 海外业务毛利率高达66.16%，远超国内业务的38.34%，海外收入占比提升有效拉高了公司综合盈利水平。
- **[经营活动现金流改善]** -> [财务质量提升]: 应收票据到期、加大回款力度及应付票据到期支付减少，共同推动经营性现金流净额同比大增69.68%，达2.79亿元。
- **[研发投入持续]** -> [技术壁垒巩固]: 研发投入4567万元，聚焦高导热石墨材料、废酸处理装置等，维持“国家制造业单项冠军”地位，确保在高端合成炉等领域的领先优势。
- **[募投项目变更]** -> [战略方向调整]: 因市场环境变化，取消“锂电池负极材料用石墨匣钵项目”，转向“碳化硅与碳基复合防腐设备项目”，反映公司对新能源下游需求放缓的审慎判断。

## 风险警告
**国内市场竞争与毛利率下滑风险是核心隐忧。** 报告期内，国内业务毛利率骤降7.69个百分点，中低端换热器领域价格战激烈。若公司无法通过技术升级或海外扩张持续提升产品附加值，综合毛利率将面临进一步下降压力，侵蚀利润空间。

**募投项目推进缓慢且存在不确定性。** 核心募投项目“高性能石墨列管式换热器及石墨管道产业化项目”投入进度仅3.61%，公司解释为下游需求不及预期。这直接反映出公司对未来产能消化的担忧，若下游化工行业资本开支持续低迷，新增产能可能无法有效转化为收入，导致资产回报率下降。

**公司简介（F10 原文）**

> 南通星球石墨股份有限公司成立于2001年,位于如皇市九华镇是如皇市首家科创板上市企业,股票代码:688633。主营业务为石墨设备及配套系统的研发、生产、销售及维保服务,主要产品为石墨合成炉、石墨换热器、石墨塔器等各型号石墨设备及相关配件,产品主要用途为化工生产中合成、解析、换热等过程。公司为中国大型石墨设备研发生产基地是国家制造业单项冠军示范企业、国家首批专精特新小巨人企业,先后被评为高新技术企业、国家知识产权示范企业、国家火炬计划项目实施单位、江苏省服务型制造示范企业,“通球牌组合式副产蒸汽石墨氯化氢合成炉”被评为江苏省名牌产品。经中国氯碱工业协会证明,国内市场占有率达70%以上,连续三年国内排名第一,国际市场排名前三,成为国内石墨设备制造行业的领头羊。现已形成石墨合成炉、石墨换热器、石墨反应釜、石墨塔器等一系列产品及系统装置,其中高效节能石墨氯化氢合成与余热利用一体化装置填补国内空白,综合技术水平达到国际先进水平。产品及相关技术被国家工业和信息化部编入、《国家工业节能技术应用指南与室例(2019)》,属于节能技术的示范室例。公司拥有先进的研发、实验与检测装备建有江苏省防腐节能石墨设备工程技术研究中心、江苏省余热回收利用石墨系统装置工程研究中心、江苏省企业技术中心及江苏省工业设计中心等省级研发平台4个,主导、参与制定国际、国家、行业及团体标准22项,荣获江苏省科学技术二等奖、中国专利优秀奖,并多次获得行业科学技术进步奖及专利奖。主要系统装置有:HCL合成(吸收)系统、盐酸深度(常规)解吸系统、氯化氢干燥系统、MVR/多效蒸发系统、废水(废气)处理系统、硫酸浓缩、烟气处理系统等工程。主要产品有:副产蒸汽二(三、四)合一氯化氢石墨合成炉;圆块孔式石墨换热与吸收设备;列管式石墨换热与吸收设备;石墨解吸塔、精馏塔、吸收塔、急冷塔;石墨搅拌釜;树脂挤压管、沥青浸渍管等近百个品种。公司秉承“发掘石墨潜力,共创美好星球”的使命,全力推进石墨产业高质量发展。未来公司将形成石墨设备及系统为核心,石墨材料生产为基础,维修保养服务为依托,材料、设备、系统、服务相互支持、相互依赖、相互促进,形成“材料、设备、系统、服务”四位一体的产业格局,打造高效节能设备产业闭环,形成星球石墨特有的核心竞争力,不断做专、做精、做优、做强。
