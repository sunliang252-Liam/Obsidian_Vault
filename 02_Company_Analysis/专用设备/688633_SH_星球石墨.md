# 688633.SH 深度透视

## 因果逻辑链
- **[海外大单落地]** -> [营收与利润双增]: 印度100万吨绿色PVC项目合同交付，贡献收入约1.5亿元，直接拉动总营收增长27.47%，并有效对冲国内市场价格竞争压力。
- **[产业链向上游延伸]** -> [原材料自主可控]: 子公司内蒙古新材料石墨材料产线投产，实现核心原料自给，降低对外部供应商依赖，但该业务目前毛利率仅10.24%，尚处爬坡期。
- **[国内竞争加剧]** -> [国内业务毛利率承压]: 国内石墨设备市场竞争激烈，中低端换热器领域价格战导致国内业务毛利率同比下降7.69个百分点。
- **[海外高毛利订单]** -> [整体毛利率结构优化]: 海外业务毛利率高达66.16%，远超国内业务的38.34%，海外收入占比提升有效拉高了公司综合盈利水平。
- **[经营活动现金流改善]** -> [财务质量提升]: 应收票据到期、加大回款力度及应付票据到期支付减少，共同推动经营性现金流净额同比大增69.68%，达2.79亿元。
- **[研发投入持续]** -> [技术壁垒巩固]: 研发投入4567万元，聚焦高导热石墨材料、废酸处理装置等，维持“国家制造业单项冠军”地位，确保在高端合成炉等领域的领先优势。
- **[募投项目变更]** -> [战略方向调整]: 因市场环境变化，取消“锂电池负极材料用石墨匣钵项目”，转向“碳化硅与碳基复合防腐设备项目”，反映公司对新能源下游需求放缓的审慎判断。

## 风险警告
**国内市场竞争与毛利率下滑风险是核心隐忧。** 报告期内，国内业务毛利率骤降7.69个百分点，中低端换热器领域价格战激烈。若公司无法通过技术升级或海外扩张持续提升产品附加值，综合毛利率将面临进一步下降压力，侵蚀利润空间。

**募投项目推进缓慢且存在不确定性。** 核心募投项目“高性能石墨列管式换热器及石墨管道产业化项目”投入进度仅3.61%，公司解释为下游需求不及预期。这直接反映出公司对未来产能消化的担忧，若下游化工行业资本开支持续低迷，新增产能可能无法有效转化为收入，导致资产回报率下降。
