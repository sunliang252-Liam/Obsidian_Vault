# 603391.SH 深度透视

## 因果逻辑链
- **[水冷预混燃烧技术壁垒]** -> [毛利率维持39.83%]: 公司自研核心技术实现超低氮排放（<30mg/m³）与高热效率（>99%），构筑产品差异化，在激烈竞争中维持较高毛利水平。
- **[“煤改气”与“双碳”政策驱动]** -> [燃气锅炉收入占比持续提升]: 政策强制淘汰高污染燃煤锅炉，推动清洁能源替代，公司专注燃气锅炉赛道，直接受益于行业结构性增长。
- **[IPO募投项目产能扩张]** -> [固定资产同比+38.89%]: 年产500套大功率超低氮燃气锅炉等项目推进，在建工程转固，为未来收入增长提供产能基础。
- **[下游客户结构优化]** -> [维保及合同能源管理收入同比+20.54%]: 公司从设备销售向“产品+服务”转型，高粘性服务收入增长，平滑设备销售周期波动。
- **[政府补助减少]** -> [归母净利润同比-22.40%]: 2025年计入当期损益的政府补助从8615万骤降至1957万，非经常性损益大幅缩水，是利润下滑主因。
- **[应收账款激增]** -> [经营现金流质量承压]: 应收账款同比+54.02%至3.31亿元，远超营收增速（6.88%），表明公司为抢占市场放宽了信用政策，回款压力加大。
- **[钢材等原材料成本上升]** -> [营业成本增速（8.63%）>营收增速（6.88%）]: 直接材料占成本52%，钢材价格波动直接侵蚀毛利率，公司成本转嫁能力有限。
- **[股权融资摊薄效应]** -> [ROE从18.53%降至10.37%]: 2024年IPO募集资金后净资产大幅增加，但新增产能尚未完全释放利润，导致资本回报率短期显著下降。

## 风险警告
**核心风险：利润对非经常性损益依赖度过高，主业增长乏力。** 2025年归母净利润下滑22.4%，扣非净利润仅下滑5.98%，表面看主业尚稳，但利润下滑主因是政府补助从8615万骤降至1957万。剔除该影响后，公司实际盈利能力并未显著恶化，但也未展现强劲增长。更值得警惕的是，应收账款同比暴增54%，远超营收增速，表明公司可能通过放宽信用政策换取订单，这为未来坏账风险埋下隐患。

**结构性风险：产能扩张与市场需求错配。** 公司IPO募投项目正大规模扩产（固定资产+38.89%），但行业竞争激烈，产品同质化严重。若下游供热、工业蒸汽需求增速放缓，或新能源锅炉（电极、热泵）加速替代，新增产能将面临消化压力，导致资产周转率下降、折旧侵蚀利润。同时，公司核心原材料钢材价格波动风险无法完全转嫁，进一步压缩盈利空间。

**公司简介（F10 原文）**

> 浙江力聚热能装备股份有限公司的前身为杭州力聚热水机有限公司,始创1997年。公司总部位于浙江湖州,是集研发、生产、销售、服务为一体的高新技术企业。具有A级锅炉制造许可证、B级锅炉安装(含改造、修理)许可证、D级压力容器生产许可证,通过了浙江制造国际联盟认证及美国ASME认证、ISO9001、ISO14001、ISO45001管理体系认证,荣获“国家绿色工厂”、绿色供应链企业、工业产品绿色设计示范企业,制造业单项冠军、浙江省“隐形冠军”企业、2022年度浙江民营经济科技创新新锐企业、“国家专精特新小巨人”企业。年产燃气锅炉10,000蒸吨,目前已成为国内技术实力与规模领先的超低氮燃气锅炉生产企业之一。  公司成立后即专注于真空相变热水锅炉的研发生产,长期坚持“科学技术是第一生产力、专业成就大业”的经营理念,坚持研发高投入。力聚核心技术之一——WCB水冷预混超低氮燃烧技术,由力聚自行研发、具有完全自主知识产权并荣获首届锅炉科学技术奖一等奖。该技术产品在全世界范围内首次实现了单模块46MW的全预混燃气锅炉安全稳定运行,打破国外垄断,填补国内空白。WCB水冷预混燃烧技术能高效抑制氮氧化物(NOx)的合成,实现超低氮排放(NOx<20mg/m3),满足我国最严格的超低氮排放标准。公司主要产品有:水冷预混超低氮燃气相变热水锅炉、水冷预混超低氮燃气冷凝蒸汽锅炉、水冷预混超低氮燃气热管蒸汽机(免监检蒸汽锅炉)、电极相变热水及蒸汽锅炉。  力聚长期秉承“以客户为本,追求全体员工物质和精神两方面幸福,为全世界锅炉安全节能事业做贡献”的核心价值观,在全国各主要城市设有50多个直属办事处,致力于为我国民用生活及工业生产用户提供更安全、更节能、更环保、更智能的供热系统解决方案。产品远销美国、泰国、新加坡、马来西亚、哈萨克斯坦、吉尔吉斯斯坦、乌兹别克斯坦等国家。
