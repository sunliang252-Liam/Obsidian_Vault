# 603321.SH 深度透视

## 因果逻辑链
- **[房地产新开工面积持续下滑]** -> [营业收入下降16.53%]: 电梯作为房地产后周期产业，新建住宅需求萎缩直接导致公司电梯销量减少。
- **[行业竞争加剧导致产品降价]** -> [毛利率下降6.62个百分点]: 中低端市场同质化严重，公司被迫降价保份额，但成本降幅远小于收入降幅。
- **[2024年施塔德老厂房处置收益消失]** -> [归母净利润暴跌76.01%]: 2024年非经常性损益中的资产处置收益约6915万元，2025年归零，导致利润基数骤降。
- **[销售费用大幅削减44.93%]** -> [业务代理费减少]: 公司主动收缩销售代理网络，以控制成本应对收入下滑，但可能影响未来市场拓展。
- **[广西梅轮基地进入试生产]** -> [新增产能与亏损并存]: 南宁基地尚处爬坡期，2025年亏损325万元，短期拖累利润，但中长期是西南及东南亚市场支点。
- **[向特定对象发行股票募资2.38亿]** -> [资本公积增加59.24%]: 定增完成补充资金，但摊薄每股收益，且募投项目（南宁基地）尚未贡献收益。
- **[经营活动现金流由正转负]** -> [销售回款减少+票据结算方式变化]: 收入下降导致现金流入减少，同时银行承兑汇票结算减少，加剧现金流压力。

## 风险警告
**核心风险在于“增量萎缩与存量竞争的双重挤压”。** 公司2025年营收与利润双降，扣非净利润仅2219万元，同比下降59.5%，主因是房地产新开工面积持续下滑导致新增电梯需求萎缩，叠加行业价格战侵蚀毛利。尽管公司试图通过老旧电梯更新、加装梯等后市场业务转型，但该领域竞争同样激烈，且政策补贴落地节奏存在不确定性，短期内难以弥补新增业务缺口。

**财务健康度出现恶化信号。** 经营活动现金流净额由2024年的1.34亿元骤降至-3162万元，显示公司回款能力与盈利质量显著下降。同时，公司将大量货币资金（约4.65亿元）投入理财产品，而非核心主业，反映主业缺乏有效投资机会。此外，广西梅轮基地尚处亏损期，定增募投项目（南宁智能制造基地）预计2028年才达产，短期无法贡献利润，反而持续消耗资金。
