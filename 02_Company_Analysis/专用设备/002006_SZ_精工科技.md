# 002006.SZ 深度透视

## 因果逻辑链
- **[碳纤维全链装备国产化突破]** -> [碳纤维装备收入同比增长59.84%]: 公司攻克原丝、碳化、复材三大核心装备技术，实现国产替代，单线产能提升至5000吨，市占率超60%，驱动核心主业高速增长。
- **[行业周期反转与需求爆发]** -> [净利润同比增长26.24%]: 碳纤维行业经历产能出清后进入上行周期，风电、低空经济等多领域需求共振，公司作为龙头率先受益。
- **[“装备+材料+应用”一体化布局]** -> [构建全链竞争壁垒]: 从卖装备延伸至卖材料、卖解决方案，实现“原丝-碳纤维-复材制品”垂直覆盖，提升客户粘性与单客户价值。
- **[轻纺与聚酯装备业务收缩]** -> [拖累整体营收下降2.07%]: 轻纺专用设备收入同比-49.20%，聚酯循环再生装备收入同比-69.59%，传统业务下滑抵消了碳纤维业务的增长。
- **[研发投入持续高增]** -> [巩固技术护城河]: 研发费用1.33亿元，同比增长10.31%，成功研制首条高性能原丝生产线、微波预氧炉等，确保技术领先。
- **[关联交易与产能建设]** -> [短期资本开支与长期产能释放]: 与关联方签署7.29亿元大额销售合同，并投资建设武汉复材基地，短期增加负债与现金流压力，但为未来2-3年收入增长奠定基础。

## 风险警告
**1. 应收账款与现金流风险：** 公司应收账款高达10.01亿元，占总资产20.67%，且账龄集中在1年左右。尽管客户信誉度较高，但若下游碳纤维扩产节奏放缓或客户资金紧张，将面临坏账损失和现金流压力。2025年经营活动现金流净额1.4亿元，虽为正但同比下降3.01%，与净利润1.86亿元存在差距，盈利质量需关注。

**2. 关联交易与客户集中度风险：** 公司前五大客户销售占比53.30%，其中关联方（如湖北裕创）贡献显著。2025年与湖北裕创签署7.29亿元大额合同，与建信佳人、精工建设等关联方存在大量工程与销售往来。若关联交易定价不公允或关联方经营出现波动，将对公司业绩产生重大影响。此外，碳纤维装备收入高度依赖少数大客户，存在客户集中风险。
