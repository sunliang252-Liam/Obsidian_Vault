# 300837.SZ 深度透视

## 因果逻辑链
- **[下游砂石行业持续低迷]** -> [核心装备销售承压]: 砂石产量连续五年下行，导致公司破碎筛选成套生产线收入同比下降26.58%。
- **[战略转型运营管理业务]** -> [营收结构优化]: 运营管理业务收入同比增长179.37%，有效对冲了装备销售下滑，降低了单一业务依赖度。
- **[海外市场加速拓展]** -> [全球化布局见效]: 海外业务收入同比增长147.74%，有效对冲了国内市场波动带来的经营压力。
- **[运营管理业务高增长]** -> [毛利率大幅下滑]: 运营管理业务收入激增，但毛利率同比下降33.84个百分点，拖累整体毛利率从32.43%降至27.89%。
- **[下游客户回款放缓]** -> [现金流急剧恶化]: 经营活动现金流净额同比暴跌93.46%至仅3371万元，与净利润严重背离，反映回款压力巨大。
- **[非经常性损益支撑利润]** -> [扣非净利润大幅下滑]: 扣非净利润同比下降27.58%，远低于归母净利润-4.47%的降幅，显示主营业务盈利能力显著减弱。
- **[募投项目进度严重滞后]** -> [未来增长不确定性]: 两大可转债募投项目投资进度仅17.64%，因下游市场变化而延期，新增长点培育受阻。

## 风险警告
**核心风险在于“增收不增利”与现金流急剧恶化。** 公司通过运营管理和海外业务实现了营收微增，但整体毛利率从32.43%骤降至27.89%，扣非净利润更是大幅下滑27.58%。更严峻的是，经营活动现金流净额同比暴跌93.46%，与净利润严重背离，表明下游客户回款困难，公司盈利质量堪忧，财务风险显著上升。

**战略转型的阵痛与不确定性并存。** 公司从设备制造商向“装备+资源”运营商转型，虽运营管理业务收入暴增，但该业务毛利率大幅下滑，且对现金流形成巨大压力。同时，两大核心募投项目（废旧电池回收、建筑垃圾处理）因下游市场环境变化而进展缓慢，未来能否成为新的增长点存在重大疑问。此外，海外业务虽增长迅猛，但地缘政治、汇率波动及当地运营风险不容忽视。
