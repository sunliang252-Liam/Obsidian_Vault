# 688529.SH 深度透视

## 因果逻辑链
- **[海外项目交付周期拉长]** -> [营收下滑与毛利率承压]: 跨国物流、签证限制及客户需求变更导致项目验收延迟，现场人力与物料成本超支，侵蚀利润空间。
- **[下游车企资本开支收缩]** -> [新签订单不及预期与竞争加剧]: 汽车行业“以价换量”内卷，欧美电动化转型放缓，客户削减设备投资，导致订单获取难度加大、盈利空间受限。
- **[在手订单成本超支]** -> [巨额存货跌价准备]: 海外项目执行周期延长、客户增补需求增加，导致预计总成本大幅上升，触发大规模存货减值（5.02亿元）。
- **[应收账款账龄延长]** -> [大额信用减值损失]: 下游客户回款周期拉长，公司基于预期信用损失模型，计提应收账款坏账损失0.83亿元。
- **[产能集中投放与需求错配]** -> [产能过剩风险]: 首发及再融资募投项目陆续建成，但下游需求疲软，导致产能利用率不足，固定折旧摊销压力增大。
- **[向电力储能与具身智能转型]** -> [开辟新增长曲线]: 为应对汽车行业周期波动，公司利用技术积累切入储能装备与具身智能机器人赛道，报告期内新签订单破1亿元，但短期贡献有限。
- **[研发投入维持高位]** -> [巩固技术护城河]: 研发费用率8.23%，聚焦固态电池叠片机、扁线电机柔性折弯线等下一代技术，保持行业领先地位。

## 风险警告
豪森智能2025年遭遇业绩“雪崩”，归母净利润巨亏9.4亿元，核心原因在于海外项目严重“失血”。海外订单执行周期远超预期，叠加客户需求变更，导致项目成本失控，公司为此计提了高达5.02亿元的存货跌价准备，这是亏损的绝对主因。同时，下游汽车行业资本开支收缩，国内市场竞争白热化，导致新签订单下滑、毛利率被大幅压缩，公司已明确承认存在“产能过剩”风险。

更严峻的是，公司资产负债表已严重受损。净资产从20.17亿元骤降至10.88亿元，未分配利润由正转负至-7.76亿元，已不具备分红条件。尽管经营性现金流因加强回款管理而转正，但这是在牺牲利润和规模的基础上实现的。公司正试图向储能和具身智能转型，但新业务体量尚小，远不能弥补主业的下滑。在海外项目风险未完全出清、国内竞争持续加剧的背景下，公司短期盈利前景依然黯淡，投资者需警惕其持续经营能力面临的挑战。
