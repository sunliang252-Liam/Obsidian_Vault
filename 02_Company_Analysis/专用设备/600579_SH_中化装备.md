# 600579.SH 深度透视

## 因果逻辑链
- **[剥离KM集团]** -> [营收锐减83.52%]: 2024年底完成重大资产重组，将持续亏损的塑料机械主体KM集团剥离出表，导致2025年合并报表收入从96亿骤降至15.8亿。
- **[剥离KM集团]** -> [大幅减亏]: 剥离后，公司不再合并KM集团的巨额亏损（2024年KM集团净亏损约42.7亿），使2025年归母净利润从-22亿收窄至-1.18亿。
- **[天华院盈利稳定]** -> [支撑业绩基本盘]: 核心子公司天华院利润总额站稳亿元台阶，新签订单同比增长10.24%，成为公司剥离KM集团后最主要的利润来源。
- **[中化橡机持续亏损]** -> [拖累整体盈利]: 子公司中化橡机因行业竞争激烈、客户结构单一，2025年净亏损1.27亿元，是公司仍处亏损状态的核心原因。
- **[新签订单增长]** -> [未来收入储备]: 2025年公司新签订单17.52亿元，同比增长17.1%，为未来收入提供了储备，但需关注订单转化为收入的周期和毛利率。
- **[推进资产重组]** -> [解决同业竞争与注入优质资产]: 公司正在推进发行股份购买益阳橡机、北化机100%股权，旨在解决同业竞争、优化资产结构、提升盈利能力。

## 风险警告
公司虽通过剥离KM集团实现大幅减亏，但核心风险在于**子公司中化橡机的持续恶化**。该子公司2025年净亏损1.27亿元，硫化设备毛利率为-9.23%，已陷入“卖一台亏一台”的困境。尽管公司计划通过吸收合并和注入新资产来拯救橡机业务，但整合效果和扭亏时间表存在巨大不确定性，若重组失败或整合效果不佳，该业务将继续严重拖累公司整体盈利。

此外，公司**母公司层面累计未弥补亏损高达-48亿元**，导致长期无法分红。同时，公司资产负债率已升至58.08%，且一年内到期的非流动负债激增682%，短期偿债压力显著加大。重大资产重组能否顺利通过监管审核并实现预期协同效应，是决定公司能否真正“脱胎换骨”的关键，但过程充满变数。
