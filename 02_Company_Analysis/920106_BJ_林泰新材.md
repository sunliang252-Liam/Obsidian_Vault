# 920106.BJ 深度透视

## 因果逻辑链
- **[混动汽车渗透率快速提升]** -> [DHT领域收入成主要增长点]: 公司湿式纸基摩擦片是混合动力专用变速器（DHT）核心部件，受益于国内插电混动汽车销量爆发，DHT产品收入快速增长，直接拉动整体营收增长34.44%。
- **[国产替代自主可控趋势]** -> [替代外资品牌份额]: 公司是国内唯一为乘用车批量配套湿式纸基摩擦片的国产品牌，在汽车核心零部件自主可控政策驱动下，加速替代博格华纳、达耐时等外资份额，客户订单持续增长。
- **[核心客户放量]** -> [营收与利润高增]: 比亚迪、长安、万里扬、上汽、吉利五大客户贡献54.85%营收，公司深度绑定头部自主品牌，随客户车型销量增长及新项目量产，收入规模快速扩大。
- **[规模效应与毛利率提升]** -> [净利润增速远超营收]: 营收增长34.44%的同时，毛利率从43.70%提升至47.95%，叠加费用率下降，净利润增速达74.22%，盈利能力显著增强。
- **[麦格纳DCT项目量产]** -> [打开国际市场空间]: 进入全球知名Tier1麦格纳供应链并实现量产，标志公司产品获得国际顶级客户认可，为海外市场拓展奠定基础，外销收入同比增长41.81%。
- **[新应用领域拓展]** -> [打开长期成长天花板]: 公司积极布局ELSD、高端农机、飞行汽车（eVTOL/hVTOL）等新领域，已获多家定点，有望从单一乘用车市场向多领域扩张，培育第二增长曲线。

## 风险警告
**实际控制人持股比例偏低，控制权稳定性存疑。** 刘健与宋苹苹夫妇合计仅控制公司28.86%的表决权，且公司股权较为分散。较低的控制权比例可能导致公司治理有效性下降，或在面临敌意收购、重大决策时出现控制权不稳定风险，进而影响长期战略执行。

**客户集中度高且技术迭代风险不容忽视。** 前五大客户销售占比达54.85%，其中比亚迪一家即占15.11%，存在单一客户依赖风险。同时，公司产品高度依赖混动汽车（DHT）这一细分赛道，若未来纯电技术路线（如多挡变速器）普及不及预期，或竞争对手突破技术壁垒，公司市场拓展可能不及预期，业绩增速面临放缓压力。
