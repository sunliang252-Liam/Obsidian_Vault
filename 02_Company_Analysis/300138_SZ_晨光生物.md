# 300138.SZ 深度透视

## 因果逻辑链
- **[原材料成本下降]** -> [净利润同比+292%]: 2025年主要农副产品原材料采购价格下降，成本降幅（-11.46%）大于收入降幅（-6.22%），毛利率提升5.14个百分点，驱动利润大幅反弹。
- **[天然色素替代合成色素]** -> [辣椒红/辣椒精销量创历史新高]: 美国FDA宣布分阶段淘汰8种石油基合成色素，下游食品巨头加速替代，公司辣椒红销量1.19万吨（+25%）、辣椒精2910吨（+65%）。
- **[多品种发展模式]** -> [水飞蓟素成为新世界前列产品]: 公司依托低成本工业化生产能力复制大单品路径，水飞蓟素年销720吨（+66%），梯队产品规模化放量。
- **[棉籽业务扭亏]** -> [新疆晨光净利润+145%]: 子公司新疆晨光坚持采销对锁与期现结合，全年加工棉籽近100万吨，实现净利润6791万元，成功扭亏为盈。
- **[研发投入持续加大]** -> [技术壁垒与新品储备]: 研发费用同比+29.27%至1.66亿元，绿原酸、虾青素实现生产转化，甜菊糖酶改糖产品推向市场，为未来增长蓄力。
- **[全球化原料布局]** -> [成本优势与供应稳定]: 在新疆、云南、印度、赞比亚、缅甸布局种植基地，推行按含量采购，降低原材料价格波动风险，巩固低成本竞争优势。
- **[定制化产品开发]** -> [客户粘性与市占率提升]: 辣椒红定制化产品销量+76%，辣椒精定制化+171%，通过差异化场景解决方案深化客户合作，提升市场地位。

## 风险警告
**核心风险在于原材料价格波动与产品价格传导的不对称性。** 公司成本中原材料占比高达94.24%，虽然2025年受益于成本下降，但若未来气候、供需等因素导致原材料价格大幅上涨，而下游产品因市场竞争或长协订单无法及时提价，毛利率将面临显著压缩。公司虽通过全球基地布局和预售模式对冲，但无法完全消除这一周期性风险。

**另一关键风险是棉籽业务的经营波动性。** 棉籽类业务收入占比44.85%，其利润高度依赖大宗商品行情和套期保值操作。2024年该板块曾大幅亏损，2025年虽扭亏，但若豆油豆粕期货价格剧烈波动或基差判断失误，将再次拖累整体业绩。此外，公司短期借款规模同比大增17.72个百分点至43.26%，财务杠杆上升，需关注流动性管理压力。
