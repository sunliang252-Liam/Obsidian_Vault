# 603010.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [单吨毛利下降]: 2020年前后高毛利驱动行业大规模扩产，2023年起下游需求疲软，导致供过于求，公司核心产品阻燃剂盈利能力被压缩。
- **[山东潍坊基地战略调整与搬迁]** -> [巨额资产减值损失（9.64亿）]: 为规避贸易壁垒并布局全球化，公司将山东潍坊部分产能搬迁至泰国，叠加产能利用率极低（8.4%），导致该基地资产可收回金额远低于账面价值，被迫计提大额减值，直接导致全年巨亏。
- **[收购广州熵能并表]** -> [营收增长14%]: 2024年11月收购的子公司广州熵能（主营抗滴落剂、增韧剂）在2025年实现全年并表，贡献了约4.66亿营收，是收入增长的主要驱动力。
- **[核心产品销量增长]** -> [市场份额稳固]: 尽管价格承压，公司聚合物功能性助剂销量同比增长14.07%，涂料助剂销量增长18.82%，显示其作为行业龙头的市场地位和客户粘性。
- **[覆铜板阻燃剂业务突破]** -> [新增长点显现]: 新产品覆铜板阻燃剂销售收入从2024年的980万元大幅增长至2025年的约3000万元，受益于下游覆铜板行业景气周期。
- **[泰国基地建设推进]** -> [未来增长预期]: 年产3.2万吨磷酸酯阻燃剂项目主体工程基本完工，预计2026年上半年试生产，旨在规避贸易壁垒，直接服务美欧市场，是公司未来业绩反转的关键变量。
- **[原材料价格下行]** -> [成本端部分对冲]: 主要原材料苯酚、环氧丙烷、双酚A等价格同比下降超过10%，在一定程度上缓解了产品价格下跌对毛利率的冲击。

## 风险警告
公司当前面临的最大风险是**资产减值风险尚未出清**。2025年因山东潍坊基地产能搬迁和利用率低下，计提了高达9.64亿元的资产减值损失，导致净利润巨亏。尽管泰国基地投产在即，但山东基地的剩余资产、在建工程以及产能爬坡期的持续亏损，仍可能在未来年度继续产生减值压力，对公司资产负债表和利润表构成持续威胁。

其次，**行业供需格局恶化风险**依然严峻。磷系阻燃剂行业产能过剩问题短期内难以解决，激烈的价格战将持续压缩公司核心产品的单吨毛利。公司营收增长主要依赖并购并表，而非内生性盈利能力的提升。若下游需求（如建筑、传统汽车）持续低迷，或泰国基地投产不及预期，公司主营业务将面临长期微利甚至亏损的困境，业绩反转存在高度不确定性。
