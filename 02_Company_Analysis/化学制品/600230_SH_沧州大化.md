# 600230.SH 深度透视

## 因果逻辑链
- **[行业产能过剩]** -> [营收下降10%]: 2025年TDI、PC、双酚A行业均供大于求，主要产品售价同比降低，导致营收从50.7亿降至45.6亿。
- **[原材料价格下跌]** -> [毛利率微增]: 主要原料甲苯(-17.7%)、苯酚(-12.9%)、丙酮(-25.1%)价格下降，成本降幅(-10.94%)略大于收入降幅(-10.01%)，综合毛利率提升0.81个百分点。
- **[出口策略对冲内需疲软]** -> [出口收入大增53%]: 国内需求低迷，公司灵活调整销售策略，加大出口力度，出口收入从6.8亿增至10.4亿，有效缓解内销压力。
- **[双酚A结构性过剩]** -> [双酚A亏损]: 双酚A行业产能过剩严重，价格跌至近五年低位，公司该产品毛利率为-4.47%，亏损4527万元，拖累整体业绩。
- **[特种PC差异化突破]** -> [进入比亚迪供应链]: 公司完成14个牌号特种PC开发，改性PC产品成功进入比亚迪供应商体系，高端化转型初见成效。
- **[现金流大幅恶化]** -> [经营现金流降66%]: 销售回款减少及库存积压（TDI库存增146%，PC库存增41%），导致经营活动现金流净额从4.1亿骤降至1.4亿。
- **[在建工程激增]** -> [投资现金流大幅流出]: 5万吨PC粉料等项目集中建设，在建工程从0.67亿增至4.06亿（+503%），投资活动现金流由正转负，净流出2.03亿。

## 风险警告
**核心风险在于行业供需格局持续恶化与公司盈利能力的脆弱性。** 2025年TDI行业产能同比增21.9%，PC、双酚A均处于产能过剩“阵痛期”，公司主要产品价格承压。全年净利润仅3085万元，净资产收益率不足1%，ROE已降至0.77%，公司已处于微利状态。双酚A产品全年亏损，TDI和PC毛利率也仅6-7%，一旦原料价格反弹或产品价格进一步下跌，公司极易陷入亏损。

**现金流与资产质量风险不容忽视。** 经营现金流同比大降66%至1.4亿，而同期资本开支高达2.03亿，自由现金流已为负值。库存量全面激增（TDI库存+146%、PC+41%、双酚A+337%），反映下游需求疲软和销售不畅。同时，公司存在固定资产减值风险（审计报告已将其列为关键审计事项），部分停产生产线可能面临进一步减值压力。
