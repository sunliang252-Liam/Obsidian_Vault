# 002783.SZ 深度透视

## 因果逻辑链
- **[行业需求下行]** -> [营收下降3.85%]: 民爆行业整体下行，工业炸药产销量同比减少超3%，公司民爆及硝酸铵收入分别下降7.81%和8.04%。
- **[原材料价格下降]** -> [毛利率分化]: 硝酸铵价格回落，民爆产品毛利率微升0.92%，但硝酸铵及复合肥毛利率大幅下降6个百分点，因成本降幅远小于收入降幅。
- **[全流程成本管控]** -> [经营现金流大增28.34%]: 公司推行集采、直采、整合物流、严控非生产开支，在收入下滑背景下，经营性现金流逆势增至5.16亿元。
- **[横向并购扩张]** -> [产能与市场版图扩大]: 收购东神天神（51%股权），新疆产能从1.4万吨增至6.01万吨，总许可产能达28.1万吨，巩固全国前列地位。
- **[纵向一体化]** -> [成本与质量优势]: 自产硝酸铵供给工业炸药，自产合成氨供给硝酸铵，形成“合成氨-硝酸铵-炸药-爆破服务”全链条，降低生产成本并保障供应。
- **[控制权变更]** -> [战略跃迁与资源注入预期]: 长江产业集团成为实际控制人，公司纳入省级国资平台，有望获得产业协同与资本运作支持。
- **[财务费用下降]** -> [利润降幅收窄]: 银行利率下降使财务费用同比减少32.79%，部分对冲了营收下滑对净利润的冲击（归母净利润仅降3.87%）。
- **[爆破服务增长]** -> [收入结构优化]: 爆破服务收入同比增长0.41%，毛利率提升5.24个百分点，成为稳定业绩的压舱石。

## 风险警告
**最大风险：宏观经济与下游需求周期性波动。** 公司民爆、石材、硝酸铵等核心业务与煤炭、矿山开采、基建投资高度绑定。2025年行业整体下行已导致营收利润双降，若未来固定资产投资放缓或矿产价格走弱，公司盈利将面临持续压力。毛利率波动风险紧随其后，硝酸铵价格下行并未同步传导至成本端，导致复合肥等产品毛利率大幅下滑6个百分点，成本管控的边际效应可能递减。

**第二大风险：快速扩张后的整合与管理失控。** 公司近年连续收购凌河化工、山东天宝、东神天神等多家企业，产能与地域跨度急剧扩大。被收购主体多保留原管理团队，存在企业文化差异、地域隔离及历史遗留问题。若公司无法实现有效管控与协同，可能出现子公司管理失控、整合不及预期，甚至拖累整体业绩。此外，安全管理是民爆行业的生命线，任何重大安全事故都可能导致停产整顿甚至吊销资质，这是不可忽视的底线风险。
