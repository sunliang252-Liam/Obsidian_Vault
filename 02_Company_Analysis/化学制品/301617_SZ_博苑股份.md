# 301617.SZ 深度透视

## 因果逻辑链
- **[原材料价格上涨]** -> [毛利率下滑4.55个百分点]: 主要原材料碘采购均价同比上涨9.81%，直接推高营业成本，导致毛利率从24.76%降至20.21%。
- **[碘化物销量增长]** -> [营收增长10.30%]: 碘化物销量同比增长11.50%，推动核心产品收入增长16.24%，是营收增长的主要驱动力。
- **[特种功能化学品销量下滑]** -> [营收下降18.94%]: 特种功能化学品销量同比减少1.01%，叠加价格因素，导致该板块收入显著收缩。
- **[经营规模扩大与备货增加]** -> [经营性现金流净额转负]: 购买商品、接受劳务支付的现金大幅增加，导致经营活动现金流净额从1.62亿元骤降至-0.03亿元。
- **[循环经济模式]** -> [成本优势与客户黏性]: 通过回收含碘废料获取原料，降低采购成本，同时为客户提供危废处理服务，形成互利共赢的深度绑定关系。
- **[研发投入持续增加]** -> [新产品储备]: 研发费用同比增长27.44%，重点布局高纯碘化物在固态电池、钙钛矿等新能源领域的应用，为未来增长蓄力。
- **[IPO募集资金到位]** -> [产能扩张与财务结构优化]: 募资净额6.28亿元，用于贵金属催化剂、高端发光材料及碘化物扩产项目，并补充流动资金，为规模扩张提供资金保障。

## 风险警告
**核心风险在于原材料价格波动与供应安全。** 公司主要原料碘高度依赖进口，2025年采购均价已上涨近10%，直接侵蚀利润。若国际地缘政治或主要产碘国政策变动导致供应中断或价格持续攀升，公司成本控制与盈利能力将面临严峻考验。尽管公司通过回收废料部分对冲，但进口精碘仍是主要来源，供应链脆弱性不容忽视。

**另一重大风险是“增收不增利”与现金流恶化。** 营收增长10.30%，但净利润同比下降19.05%，经营性现金流更是由正转负。这反映出公司在原材料成本压力下，向下游传导价格的能力有限，同时为应对市场扩张而大量备货，占用了巨额资金。若下游需求增速放缓或回款周期拉长，公司可能面临流动性压力，需警惕财务健康度的持续下滑。
