# 300019.SZ 深度透视

## 因果逻辑链
- **[收购江苏嘉好]** -> [营收与利润双增]: 2024年7月并表后，热熔胶业务全年贡献营收10.67亿元，同比增长87.12%，成为公司第二大收入来源，直接驱动总营收增长18.75%。
- **[原材料价格低位震荡]** -> [毛利率承压但销量提升]: 上游有机硅原料价格全年大部分时间处于历史低位，公司凭借成本优势以价换量，全年销量30.73万吨，同比增长25.35%，但建筑胶毛利率微降0.39%。
- **[建筑胶龙头地位与“好房子”政策]** -> [建筑胶销量稳增]: 尽管房地产市场承压，公司凭借品牌和渠道优势，建筑胶销量同比增长12.4%，并成为唯一入选住建部“好房子”建材名录的有机硅密封胶品牌。
- **[硅碳负极技术突破与产能落地]** -> [新增长极初步形成]: 1000吨中试线及3000吨产线稳定运行，开发出比容量1800-2200mAh/g的系列产品，与多家头部锂电企业合作，销量高速增长。
- **[海外市场扩张]** -> [出口收入高增]: 整合江苏嘉好海外渠道，出口销售收入4.61亿元，同比增长57.07%，有效对冲了国内部分领域的价格竞争压力。
- **[股权激励与业绩考核调整]** -> [核心团队稳定性]: 2023年股权激励计划因2024年业绩未达标作废部分股票，但公司随即调整2025年考核目标，保留了激励对象的积极性，稳定了核心团队。

## 风险警告
**核心风险在于“增收不增利”的隐忧与硅碳负极的产业化不确定性。** 公司营收增长18.75%，但归母净利润仅增长17.25%，扣非净利润增速更低（13.09%）。这背后是建筑胶毛利率下滑、热熔胶毛利率虽提升但绝对值仍低（15.42%），以及财务费用因汇兑损失大幅增加。若上游原材料价格反弹，公司以价换量的策略将难以为继，利润端可能面临更大压力。

**硅碳负极业务是未来估值的关键，但也是最大的风险敞口。** 公司计划2026年建成7000吨硅碳负极产线，但当前行业技术路线（硅氧、硅碳）仍在快速迭代，且面临贝特瑞、杉杉等传统负极巨头的激烈竞争。若公司产品在性能、成本或客户导入上不及预期，巨额资本开支将拖累现金流和资产回报率，导致“第二增长曲线”落空。
