# 603505.SH 深度透视

## 因果逻辑链
- **[包头“选化一体”项目产能释放]** -> [营收与利润双增]: 金鄂博氟化工无水氟化氢产销量同比大增超80%，叠加包钢金石投资收益（1.58亿元），成为公司核心利润引擎，贡献净利润占比达67.41%。
- **[低品位萤石粉制备AHF技术突破]** -> [成本优势与资源盘活]: 专有技术将包钢尾矿中的低品位超细萤石粉转化为标准AHF产品，使公司摆脱对高品位单一萤石的依赖，并实现“选化一体”的轻资产扩张。
- **[单一萤石矿山成本上升与产销量下滑]** -> [基本盘利润承压]: 安全监管趋严导致安全投入增加、产销量减少，单吨制造成本上升，拉低了萤石涨价本该带来的利润，削弱了“现金牛”的盈利能力。
- **[锂电项目（六氟磷酸锂、尾泥提锂）亏损]** -> [拖累整体业绩]: 跨界锂电行业节奏踩错，叠加锂价周期下行，两项目合计亏损近6000万元，成为公司利润增长的主要拖累项。
- **[蒙古国项目产能释放慢于预期]** -> [海外扩张节奏受阻]: 对海外基础设施、政策环境估计不足，选厂建设及配套工程耗时较长，导致项目未能按计划实现当年盈利，短期价值有限。
- **[投资诺亚氟化工，切入AI液冷赛道]** -> [打开远期增长空间]: 成为液冷氟化液龙头第二大股东，布局“微笑曲线”高附加值端，与现有资源和技术形成协同，为未来增长注入新动能。
- **[经营性现金流大幅下降]** -> [盈利质量隐忧]: 期末未到期银行承兑汇票增加3.2亿元及支付包钢金石货款增加，导致经营活动现金流净额同比大降75.45%，利润的现金保障能力减弱。

## 风险警告
**核心风险在于新业务拖累与现金流压力。** 锂电项目（六氟磷酸锂、尾泥提锂）持续亏损，合计影响利润近6000万元，且面临锂价周期波动与技术转化不确定性，短期内难以成为利润贡献点。同时，公司经营性现金流净额同比暴跌75.45%，主要因大量销售回款以银行承兑汇票形式存在（期末余额8.94亿元），以及支付关联方货款增加，盈利质量显著下降，需警惕流动性风险。

**另一重大风险是安全环保与海外项目的不确定性。** 金鄂博氟化工硫酸厂发生渗水溢流事件，已移送检察院审查起诉，暴露出化工板块的环保管理短板，可能面临处罚及声誉损失。蒙古国项目受制于基础设施、政策环境等，产能释放节奏持续慢于预期，若水源、运输等关键条件无法及时满足，将导致前期投入难以转化为有效产出，成为资金“黑洞”。

**公司简介（F10 原文）**

> 金石资源集团股份有限公司是专业从事国家战略资源萤石矿的投资开发以及下游氟化工、含氟锂电材料深加工的实业集团,公司成立于2001年,于2017年5月3日在上交所主板(股票代码:603505),拥有资源、氟化工、新能源三大业务板块。上市公司总部位于杭州,下属17家全资或控股子公司,主要位于浙江、安徽、江西以及内蒙古自治区。公司目前拥有已查明保有单一萤石资源储量约2,700万吨,与包钢股份合作开发的伴共生萤石资源量1.3亿吨,是我国萤石资源储量、开采及生产加工规模遥遥领先的企业,也是我国非金属矿采选行业第一家上市公司。资源为王、技术至上。公司秉承“向善而为,共益共生”核心价值观,实施“资源+技术”两翼驱动战略。公司在产单一萤石矿山8座,拥有多家国家级绿色矿山,是《萤石》行业标准修订单位、国家矿山综合利用示范单位,在资源采选方面形成独具特色的“新型绿色矿业发展模式——金石模式”,实现“金山银山依然绿水青山”。公司与内蒙古包钢股份等在包头成立两家合资公司,分别从事伴生萤石矿的选矿加工和氟化工业务,一方面将白云鄂博矿山沉睡多年的伴共生萤石资源从稀土、铁的尾矿中提炼出来,实现资源综合利用;另一方面公司利用“低品位萤石精粉制备氢氟酸”专有技术,以“选-化一体化”方式进入下游氟化工行业,建设年产30万吨氢氟酸项目,规模全球领先。作为萤石行业的龙头企业,公司利用领先的选矿技术,横向拓展进入提锂行业。公司目前拥有锂云母及锂辉石选矿提锂专有技术,尤其在难选复杂的锂云母及锂辉石的选矿上拥有先进的专有技术。公司2022年10月在江西宜春建设尾泥提锂项目,从废弃的含锂细泥中提取锂云母精矿,该项目年处理尾泥100万吨、年产锂云母精矿10.8万吨。公司高度重视技术创新和人才培养。公司名下的多家子公司是国家高新技术企业;集团储备和引进大量新能源、新材料、精细氟化工、智能制造方面的高端人才。这些投资项目的落地,标志着公司实现了从单一的萤石资源采选业务向产业链下游精细氟化工、战略新兴材料领域的延伸,同时横向拓展至其他战略矿种的选矿利用,形成了“资源——氟化工深加工——新能源材料”的完整产业链布局。此外,作为A股主板上市公司,公司的信息披露、投资者关系、投资者保护、规范运作、社会责任等方面走在前列,近年来有近十项案例分别入选上交所、浙江辖区、中国上市公司协会等的优秀或最佳实践案例。
