# 688659.SH 深度透视

## 因果逻辑链
- **[下游行业景气度下行]** -> [利润亏损]: 钢铁、水泥、垃圾焚烧等主要客户行业景气度下降，导致市场增量放缓、竞争加剧、产品价格走低，公司连续三年亏损。
- **[竞争加剧与价格战]** -> [毛利承压]: 行业集中度低、充分竞争，产品售价持续走低，尽管营收增长10.95%，但净利润仍为-3065万元。
- **[应收账款与资金成本]** -> [财务风险]: 下游客户回款周期拉长，应收账款及合同资产占总资产25.83%，增加了资金成本和坏账风险。
- **[新业务布局投入]** -> [短期利润侵蚀]: AI智能环保岛、工业巡检机器人、高分子复合材料等新业务处于市场开拓期，研发费用同比增长20.89%，投入增加拖累当期利润。
- **[海外业务高增长]** -> [营收结构优化]: 海外事业部实现营收9381万元，同比增长41.02%，成为公司营收增长的重要驱动力，对冲国内需求放缓。
- **[AI智能环保岛落地]** -> [差异化竞争优势]: 已在钢铁、电力领域落地10余个项目，获“国际先进水平”认证，帮助客户降本30%，形成“装备+智能化”解决方案。
- **[催化剂细分市场领先]** -> [护城河]: 钢铁烧结中低温脱硝催化剂销量全国占有率22.3%（前三），省内第一，在石灰窑SCR改造实现首台套应用，技术壁垒高。

## 风险警告
**核心风险在于下游行业景气度持续低迷与公司盈利能力恶化之间的恶性循环。** 公司连续三年亏损（2023年-2538万，2024年-6086万，2025年-3065万），虽然亏损幅度收窄，但主营业务毛利率仅27.82%，在竞争加剧下仍有下滑压力。应收账款占总资产超25%，若下游钢铁、水泥行业经营状况进一步恶化，坏账风险将直接冲击利润表。

**新业务转型存在高度不确定性。** 公司押注AI智能环保岛、工业巡检机器人和碳纤维复合材料等新赛道，但这些业务尚处于商业化初期，收入贡献极小（AI智能环保岛收入仅121万元）。技术路线尚未收敛，市场接受度未知，且需要持续高额研发投入。若转型不及预期，公司可能陷入“传统业务萎缩、新业务无法接棒”的困境。同时，公司债权融资余额达2.9亿元，占总资产22%，财务杠杆较高，流动性风险不容忽视。
