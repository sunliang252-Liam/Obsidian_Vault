# 603823.SH 深度透视

## 因果逻辑链
- **[下游需求疲软，销量下滑]** -> [营收下降10.52%]: 2025年有机颜料下游油墨、涂料等行业景气度下行，公司颜料销量同比减少9.06%，直接导致主营业务收入萎缩。
- **[成本降幅大于收入降幅]** -> [扣非净利润微增0.81%]: 营业成本同比下降11.24%，降幅大于营收的10.52%，叠加先进制造业增值税加计抵减计入经常性损益，使核心盈利能力保持稳定。
- **[关键中间体自给率提升]** -> [成本控制能力增强]: 公司自产4-氯-2,5-二甲氧基苯胺、色酚等关键中间体，有效对冲了上游原料价格波动风险，保障了颜料业务毛利率同比提升1.16个百分点。
- **[高性能颜料技术突破]** -> [打开高端市场空间]: 电子化学品级高性能颜料（光刻胶用）通过客户验证并实现商业化销售，打破了国际垄断，为切入高附加值领域奠定基础。
- **[新项目投资扩张]** -> [资产结构变化]: 投资10亿元建设高性能有机颜料及配套材料产业化项目，导致在建工程增长75.94%、无形资产增长71.91%（购地），资本开支加大。
- **[票据结算占比增加]** -> [经营性现金流大幅下降38.36%]: 客户更多使用银行承兑汇票结算，导致现金回款减少，经营活动现金流净额从3.29亿降至2.03亿。
- **[金属钠业务亏损拖累]** -> [整体利润承压]: 子公司源晟制钠（金属钠）产能利用率仅49.98%，全年亏损922.78万元，成为集团利润的负向拖累。

## 风险警告
**核心风险在于下游需求持续疲软与产能扩张的错配。** 公司2025年营收和利润双降，主因是颜料销量下滑9%，而公司却在此时启动10亿元新项目，预计2027年投产。若下游油墨、涂料行业景气度未能如期复苏，新增产能将面临消化困难，导致折旧和费用侵蚀利润，资产回报率进一步走低。

**第二大风险是金属钠业务的持续失血。** 子公司源晟制钠拥有2万吨产能，但2025年产能利用率仅50%，全年亏损近千万元。全球金属钠需求仅12.65万吨，国内产能却达17.85万吨，严重过剩。该业务短期内扭亏无望，将持续拖累合并报表利润，且存在资产减值风险。
