# 300821.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡，产品价格持续走低]** -> [营收与利润双降]: 2025年有机硅DMC市场均价同比下跌约10.95%，公司营收同比下降26.80%，归母净利润由盈转亏至-1,930.92万元。
- **[7月火灾事故导致部分装置停产]** -> [产能受限与停工损失]: 合成车间三期B床火灾，停产至11月底，直接造成营收损失（占全年5.55%）及停工损失，进一步拖累全年业绩。
- **[下游需求结构分化，新兴领域崛起]** -> [产品结构被动调整]: 传统建筑领域需求收缩，光伏、AI算力等新兴领域需求放量，公司107胶营收下降39.27%，而110生胶、液体胶营收分别增长30.08%和25.56%。
- **[金属硅等原材料价格下跌]** -> [成本端压力缓解有限]: 金属硅价格下行，但产品售价跌幅更大，导致主要产品毛利率（如107胶毛利率-0.47%）承压，未能有效对冲收入下滑。
- **[行业“反内卷”自律调控]** -> [年末价格强势反弹]: 行业从低价竞争转向自律，供需格局改善，DMC价格年末强势反弹，公司经营业绩自12月起显著好转。
- **[全产业链一体化布局]** -> [成本控制与抗风险能力]: 公司具备“硅粉-单体-中间体-深加工”完整产业链，副产物综合利用，规模优势凸显，在行业寒冬中稳住经营基本盘。
- **[研发投入聚焦中高端]** -> [新产品市场化与资质突破]: 全年开发80余个新牌号，40个实现市场化；多款产品通过KTW认证，为开拓欧美高端市场奠定基础。

## 风险警告
**核心风险在于行业供需格局的脆弱性与公司自身运营的“黑天鹅”事件。** 2025年有机硅行业虽在年末出现价格反弹，但全年均价同比下跌10.95%，公司营收大幅下滑26.80%，表明行业产能过剩的深层矛盾尚未根本解决。公司虽为龙头，但在价格战中盈利空间被严重挤压，归母净利润由盈转亏。更关键的是，7月的火灾事故直接暴露了公司生产安全管理的短板，导致核心装置停产近5个月，对全年业绩造成直接冲击，这种运营中断风险是投资者必须警惕的。

**另一重大风险来自成本与政策的不确定性。** 公司主要原材料金属硅、甲醇价格受宏观经济和地缘政治（如伊朗冲突影响甲醇进口）影响波动剧烈，若上游成本大幅上涨而下游产品价格无法同步传导，将严重侵蚀利润。同时，2026年4月起取消初级形态聚硅氧烷的出口退税，将直接增加公司出口成本，打破“低价走量”模式，对海外业务占比约12%的公司构成短期利空，倒逼其向高附加值转型，但转型过程存在不确定性。

**公司简介（F10 原文）**

> 山东东岳有机硅材料股份有限公司成立于2006年,2020年3月在深交所创业板上市,股票代码:300821。公司是一家专业从事有机硅材料的研发、生产和销售的高新技术企业,产品主要包括硅橡胶、硅油、硅树脂、气相白炭黑以及有机硅中间体等。有机硅是一类性能优异、形态多样、用途广泛的高性能新材料,因其独特的结构,兼备无机材料与有机材料的性能优势,具有耐高低温、耐腐蚀、绝缘性好、良好的生物相容性、使用寿命长等优异性能,广泛应用于建筑、电子电器、电力、汽车、医疗、日用品、新能源、纺织、日化、机械加工、复合材料、化工等领域,被称作“工业维生素”。公司具备从金属硅粉加工到有机硅单体、中间体以及下游硅橡胶、硅油、硅树脂、气相白炭黑等系列深加工产品的一体化生产能力,并对相关副产物进行综合利用,形成了较为完善的产业链配套,拥有各类下游产品560多个牌号。公司是国家高新技术企业、山东省博士后创新实践基地、山东省有机硅材料技术创新中心,并与山东大学合作共建山东省先进有机硅材料与技术重点实验室,曾先后承担国家工信部“工业强基”工程、山东省科技计划项目、山东省自主创新及成果转化专项以及淄博市创新发展重点项目计划等一系列重大科研项目。公司还参与起草了《工业用二甲基二氯硅烷》《甲基二氯硅烷》《二甲基二氯硅烷水解物》《羟基封端聚二甲基硅氧烷线性体》《十甲基环五硅氧烷》《甲基低含氢硅油》《端含氢二甲基硅油》《端乙烯基硅油》《高沸硅油》等十余项国家或行业团体标准。公司已取得各类授权专利100多项,其中,发明专利“有机氯硅烷的水解方法”获山东省专利奖一等奖。公司牵头完成的“基于产业基础共性技术创新的高纯/特种有机硅材料制备与产业化”项目荣获山东省科学技术进步奖一等奖。未来,公司将以市场需求为导向,以技术创新、产品创新、应用创新为驱动,抓住我国工业转型升级和消费升级的历史性机遇,依托公司多年来在有机硅材料领域积累的规模、技术、产品、客户、管理等优势,聚焦有机硅产业链,对标国际一流企业,做大、做精、做强主业,不断向下游深加工领域延伸,将公司打造成具有国际竞争力的世界级有机硅企业。
