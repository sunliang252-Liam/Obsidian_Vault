# 001358.SZ 深度透视

## 因果逻辑链
- **[原材料价格下行]** -> [毛利率承压]: 主要原料六八哌嗪、乙二胺价格下降，导致产品售价同步回落，而成本下降存在滞后性，压缩了利润空间。
- **[募投项目转固折旧]** -> [净利润下滑]: 安徽兴欣募投项目转固，折旧费用增加，但尚未产生预期效益，直接拖累当期利润。
- **[存货跌价准备计提]** -> [资产减值损失]: 基于审慎原则，对可变现净值低于成本的原材料及产成品计提跌价准备，减少当期净利润。
- **[新产品投产与CCUS装置投运]** -> [收入结构优化]: 双吗啉基乙基醚、重金属螯合剂等新产品投产，CCUS装置进入试运行，为公司贡献新收入来源，并拓展环保化学品赛道。
- **[循环经济产业链]** -> [成本优势]: 公司以哌嗪为核心，实现多种原料相互替代，可在原料市场波动时灵活选择廉价原料生产，构筑可持续的成本护城河。
- **[电子化学品与高端应用拓展]** -> [产品附加值提升]: 公司成功开发电子级无水哌嗪、五甲基二乙烯三胺等产品，金属离子达ppb级别，切入高壁垒、高毛利的半导体和面板制程领域。
- **[多乙烯多胺项目布局]** -> [产业链纵向整合]: 在广西新设子公司，采用EDC法建设乙烯胺项目，旨在实现乙二胺等关键原料的部分自给，并利用副产品氨水，深化循环经济。

## 风险警告
**核心风险在于业绩持续下滑与成长性存疑。** 2025年公司营收微增1.37%，但归母净利润同比暴跌40.46%，扣非净利润更是下滑47.74%。利润下滑的核心原因是原材料价格下行导致产品售价承压，叠加募投项目转固带来的折旧压力，以及存货跌价准备的计提。这表明公司当前处于“增收不增利”的困境，且盈利能力尚未触底。

**第二重风险是募投项目效益不及预期与产能消化风险。** 公司多个募投项目（如8800吨哌嗪系列、14000吨环保溶剂项目）已结项或接近完工，但尚未产生显著效益。同时，主要产品如脱硫脱碳剂、无水哌嗪、六八哌嗪的产能利用率极低（分别为22.84%、25.52%、21.05%），新增产能能否被市场有效消化存在重大不确定性，若下游需求持续疲软，将导致资产回报率进一步下降。
