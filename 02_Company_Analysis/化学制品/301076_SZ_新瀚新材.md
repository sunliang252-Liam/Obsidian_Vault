# 301076.SZ 深度透视

## 因果逻辑链
- **[产销规模扩大]** -> [营收增长5.8%]: 主营产品产量突破8000吨，销量超7600吨，同比增长超20%，以量补价驱动收入增长。
- **[规模效应摊薄成本]** -> [毛利率回升3.16个百分点]: 产销规模扩大使单位产品生产成本进一步降低，综合毛利率从23.49%提升至26.65%。
- **[原材料价格下降]** -> [行业竞争加剧]: 上游原材料价格进一步下调，导致行业产品价格同步下调，业内企业经营压力依然较大。
- **[下游新兴应用拓展]** -> [PEEK需求预期增长]: 人形机器人、低空经济等新兴领域对轻量化材料的需求，为PEEK材料带来可观市场增量，拉动上游DFBP需求。
- **[化妆品安全法规趋严]** -> [HAP等新型防腐助剂需求增长]: 《化妆品监督管理条例》实施及消费者安全意识提升，推动HAP、HDO等新型功能性化妆品原料逐步替代传统防腐剂。
- **[募投项目延期]** -> [短期效益不达预期]: 年产8000吨芳香酮项目三车间延期至2026年6月投产，叠加固定成本折旧增加，导致本年度未能实现预计效益。
- **[出口业务占比下降]** -> [内销增长对冲外销风险]: 境内收入同比增长14.62%，境外收入同比下降14.06%，公司正主动调整市场结构以应对国际贸易摩擦风险。

## 风险警告
**1. 产能释放与盈利不及预期的风险。** 公司核心募投项目“年产8000吨芳香酮项目”三车间再度延期至2026年6月，且已投产部分因折旧成本高企、产品价格下行，连续两年未达预期效益。若新产能投产后市场需求或价格环境未改善，将导致固定资产折旧进一步侵蚀利润，公司盈利能力面临持续压力。

**2. 原材料成本波动与毛利率承压的风险。** 公司直接材料占营业成本比重高，原材料价格波动与产品售价调整存在滞后性。2025年虽因规模效应毛利率回升，但行业竞争加剧导致产品价格下调，若未来原材料价格上涨或下游压价，毛利率存在再次走低的风险。同时，公司经营活动现金流净额同比下降45.36%，需关注盈利质量。
