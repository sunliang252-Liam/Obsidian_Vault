# 600352.SH 深度透视

## 因果逻辑链
- **[染料行业竞争加剧，产品价格承压]** -> [营收下滑]: 行业低价竞争导致染料产品价格下行，叠加房产销售结转收入大幅减少，公司总营收同比下降16.18%。
- **[染料龙头“以量补价”，分散染料销量创历史新高]** -> [业绩韧性]: 公司凭借规模与成本优势，通过提升产量、降本增效，实现全球染料销量同比增长，分散染料销量创新高，部分对冲了价格下跌的影响。
- **[中间体业务高壁垒，竞争格局稳定]** -> [利润稳定器]: 间苯二胺、间苯二酚行业受环保安全门槛限制，新增产能释放有限，公司凭借技术、规模及一体化优势维持全球龙头地位，贡献稳定利润。
- **[房产项目“湾上”去化率高达96.40%]** -> [现金流支撑]: 上海华兴新城项目销售强劲，累计回款129.64亿元，为公司提供了重要的现金流补充，但整体房产收入因结转减少而大幅下滑。
- **[收购德司达少数股权，实现全资控股]** -> [巩固全球领导地位]: 公司完成对德司达37.57%少数股东权益的收购，德司达成为全资子公司，进一步整合全球品牌、渠道与技术资源。
- **[循环经济产业园降本增效]** -> [成本优势]: “染料-中间体-硫酸-硫酸铵”循环经济模式，叠加智能化改造，使单吨制造费用同比下降，三废处理费用下降7.5%，构筑了显著的环保与成本壁垒。
- **[非经常性损益波动大]** -> [利润波动]: 公允价值变动收益（+1.57亿）与资产处置收益（+0.24亿）等非经常性项目对利润影响较大，掩盖了主营扣非净利润同比下滑12.59%的疲软态势。

## 风险警告
**核心风险在于染料主业增长乏力与房地产板块的巨大不确定性。** 染料行业产能阶段性过剩、低价竞争持续，公司虽以量补价，但营收与扣非净利润双双下滑，显示主业盈利能力承压。同时，房地产板块收入同比骤降67.23%，尽管“湾上”项目成功，但整体房产业务的可持续性存疑，且公司持有大量投资性房地产（期末65亿），公允价值变动对利润影响显著，一旦市场下行将构成重大拖累。

**财务风险与治理风险不容忽视。** 公司资产负债率从48.27%升至56.26%，短期借款大增33.29%，有息债务规模扩大。此外，公司持有41.38亿其他非流动金融资产（私募基金、信托等），公允价值计量依赖管理层重大判断，审计师已将其列为关键审计事项，存在估值波动风险。同时，公司涉及多起国际仲裁与诉讼（如与Kiri公司的德司达股权纠纷虽已解决，但涉及金额巨大），且子公司众多、跨国经营，管理复杂度高，汇兑风险敞口亦需警惕。
