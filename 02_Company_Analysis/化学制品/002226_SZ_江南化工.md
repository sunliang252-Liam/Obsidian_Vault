# 002226.SZ 深度透视

## 因果逻辑链
- **[并购整合扩张产能]** -> [营收稳定]: 通过收购东神楚天、峨边国昌、庆华民爆等，国内工业炸药许可产能达89.2万吨（行业第一），抵消了行业下行压力，营收微增0.20%。
- **[爆破服务牵引民爆销售]** -> [内部协同率提升]: 实施“双协同、双牵引”战略，爆破服务收入53.23亿元（+4.29%），带动内部炸药、雷管使用率提升，形成良性循环。
- **[海外项目持续放量]** -> [国际收入创新高]: 深耕纳米比亚、刚果（金）等“一带一路”国家，海外营收12.93亿元（+26.43%），成为重要增长极。
- **[硝酸铵价格下降]** -> [成本压力缓解]: 主要原材料硝酸铵价格同比下降约10%，部分对冲了民爆产品售价下行和成本刚性上涨的压力。
- **[新能源电价市场化改革]** -> [盈利空间承压]: 陆上风电增值税即征即退50%政策取消，叠加电力市场化交易电价下行，新能源业务收入同比下降8.96%。
- **[并购导致资本开支激增]** -> [现金流结构变化]: 报告期投资活动现金净流出19.86亿元（+129%），主要用于并购支付，导致筹资活动现金净流入大幅增加。
- **[同业竞争承诺延期]** -> [资产注入预期延后]: 实际控制人兵器工业集团将解决同业竞争承诺延期至2030年，奥信化工等资产注入时间表不确定性增加。

## 风险警告
**核心风险在于并购整合与业绩承诺兑现。** 公司通过大规模并购实现产能扩张，但2025年新并购标的（红旗民爆、东神楚天、峨边国昌、庆华民爆）首年业绩承诺完成率分别仅为51.67%、23.60%、13.24%和30.19%，远低于预期。若后续年份无法达标，将面临大额商誉减值风险（商誉账面价值11.76亿元），直接冲击利润表。

**政策与市场双重挤压新能源业务。** 陆上风电增值税优惠取消及电力市场化改革导致电价下行，已使新能源板块收入下降8.96%。随着全国统一电力市场建设推进，电价波动风险将持续存在，该板块对公司利润的贡献可能进一步萎缩，削弱“双主业”的稳定性。
