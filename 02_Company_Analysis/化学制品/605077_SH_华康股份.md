# 605077.SH 深度透视

## 因果逻辑链
- **[舟山华康新产线投产]** -> [营收增长49.15%]: 舟山100万吨玉米精深加工项目第一阶段投产，液体糖、醇及其他产品销量暴增246.26%，拉动总营收至41.89亿元。
- **[液体产品占比大幅提升]** -> [毛利率下降6.97个百分点]: 低毛利的液体糖、醇及其他产品（毛利率仅1.43%）收入占比超过晶体糖醇，拉低整体毛利率至14.47%。
- **[可转债利息费用化]** -> [财务费用暴增1040.73%]: 2023年发行的13亿可转债利息开始计入当期损益，财务费用从0.08亿飙升至0.96亿，严重侵蚀利润。
- **[营收增长但利润下降]** -> [净利润下降25.40%]: 低毛利产品扩张叠加财务费用激增，导致“增收不增利”，归母净利润仅2.00亿元，扣非净利润下降33.50%。
- **[舟山项目转固]** -> [固定资产大增55.52%]: 舟山华康项目部分转固，固定资产从22.54亿增至35.05亿，同时在建工程下降78.62%，产能扩张进入收获期。
- **[并购豫鑫糖醇终止]** -> [战略扩张受阻]: 拟收购河南豫鑫糖醇以强化木糖醇产业链的计划终止，公司外延式扩张路径受挫，回归内生增长。
- **[晶体糖醇销量稳健]** -> [核心业务基本盘稳固]: 晶体糖醇产品销量增长12.32%，毛利率稳定在26.68%，表明公司在高毛利核心产品上仍具定价权和市场地位。

## 风险警告
**核心风险：增收不增利的盈利质量恶化。** 公司营收暴增近50%，但净利润却下滑25%，核心原因是新投产的舟山项目以低毛利的液体产品为主，严重稀释了整体盈利水平。同时，可转债利息费用化导致财务费用飙升，进一步压制利润。这种“以量换利”的增长模式可持续性存疑，若液体产品价格或成本出现不利波动，利润端将面临更大压力。

**重大风险：并购失败与反垄断诉讼。** 公司终止收购豫鑫糖醇，表明其通过外延并购快速整合行业的战略受阻。更严重的是，公司因涉嫌“滥用市场支配地位”被客户起诉并一审败诉，需赔偿约900万元。若终审维持原判，不仅带来直接经济损失，更可能动摇其作为行业龙头与客户签订长期协议的模式，对核心业务模式构成潜在冲击。
