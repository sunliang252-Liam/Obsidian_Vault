# 603125.SH 深度透视

## 因果逻辑链
- **[化工行业周期下行]** -> [营收与利润双降]: 2025年化工产品价格指数较2021年高点回落近四成，公司主要产品售价随原材料价格下降而承压，导致营收同比下降4.05%，归母净利润同比下降22.57%。
- **[募投项目及七期项目投产转固]** -> [固定资产激增与短期成本压力]: 前次募投项目（2025年6月）及七期项目（2025年12月）建成投产，固定资产同比大增327%，但新产能处于爬坡期，叠加折旧、人工等费用增加，短期拖累利润表现。
- **[新产品市场导入期遇阻]** -> [外销增量不及预期]: 国际贸易形势与化工行业景气度低迷，导致公司推出的2-乙烯基萘等新产品在海外市场推广缓慢，未能有效对冲国内竞争加剧带来的压力。
- **[原材料价格下降]** -> [成本端压力缓解但收入端承压]: 纯苯、乙烯等主要原材料采购价同比下降7%-25%，使营业成本基本持平；但产品售价同步下调，导致收入降幅大于成本降幅，毛利率下滑2.26个百分点。
- **[经营活动现金流大幅恶化]** -> [回款能力减弱]: 受收入和业绩下降影响，销售回款减少，经营活动现金流净额同比骤降76.04%至5090万元，远低于净利润水平，显示盈利质量下降。
- **[泰州基地建设与可转债融资]** -> [长期增长布局与短期资金需求]: 公司启动泰州生产基地（一期）建设，并推进不超过8亿元可转债发行，旨在向芳香族含氧特种单体领域延伸，但项目效益存在不确定性，且短期内增加资本开支压力。
- **[无酚环保助剂与高端特种单体]** -> [差异化竞争壁垒]: 公司掌握无酚亚磷酸酯等独家技术，产品可替代苯乙烯、苯酚等有害物质，在人体接触材料、高端涂料等领域具备先发优势，是抵御同质化竞争的核心护城河。

## 风险警告
**核心风险在于新产能释放与下游需求错配。** 公司2025年新增超7万吨特种单体及助剂产能，但化工行业整体产能利用率已降至73%，下游需求疲软导致募投项目投产后产能利用率仅31.89%，远未达预期效益。若行业景气度持续低迷，新增产能不仅无法贡献利润，反而会因折旧和固定成本侵蚀公司现金流，形成“投产即亏损”的困境。

**经营现金流与利润严重背离，盈利质量堪忧。** 公司净利润1.58亿元，但经营活动现金流仅0.51亿元，同比暴跌76%。这主要源于销售回款放缓及存货增加（同比+33%）。若应收账款及存货持续积压，公司可能面临坏账风险和减值压力，进一步拖累业绩。此外，公司拟发行可转债融资，若转股将摊薄现有股东权益。
