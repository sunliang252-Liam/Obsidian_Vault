# 600165.SH 深度透视

## 因果逻辑链
- **[破产重整完成]** -> [净资产暴增1582%]: 重整投资人投入资金及债务重组收益3.41亿元，使净资产从7179万元跃升至12.08亿元，彻底摆脱资不抵债。
- **[长链二元酸销量翻倍]** -> [营收增长28.72%]: 重整后产能释放，长链二元酸销量同比增103.8%，带动总营收增至4.44亿元。
- **[核心主业持续亏损]** -> [扣非净利润-3.87亿元]: 长链二元酸毛利率为-43.78%（成本高于售价），活性炭毛利率仅7.11%，主业造血能力严重不足。
- **[计提巨额资产减值]** -> [侵蚀经营利润]: 对长链二元酸及活性炭生产线分别计提减值6485万和4609万元，合计超1.1亿元，暴露资产质量风险。
- **[重整后债务结构重塑]** -> [财务费用骤降81%]: 有息债务停止计息，财务费用从1.44亿降至2742万，但长期应付款激增至8.48亿，未来偿债压力后移。
- **[经营性现金流大幅流出]** -> [现金循环断裂风险]: 经营活动现金流净额为-3.73亿元，远低于净利润，主因购买物料和清偿债权支付现金增加，营运资金极度紧张。
- **[新控股股东入主]** -> [治理结构根本性改善]: 湖南新合新成为控股股东，原实控人因信披违规被市场禁入，公司治理进入新阶段。

## 风险警告
**核心风险在于“报表修复”与“经营造血”的严重背离。** 公司通过破产重整一次性确认3.41亿元债务重组收益，使净资产由负转正，但扣非净利润仍巨亏3.87亿元，长链二元酸业务毛利率为-43.78%，意味着每卖一吨产品都在亏损。这种“会计利润”与“经营亏损”的剪刀差，是公司最根本的财务风险。若不能快速提升产能利用率、优化成本结构，重整带来的财务改善将很快被经营失血消耗殆尽。

**流动性风险与持续经营能力不确定性并存。** 尽管重整后账面货币资金增至4.6亿元，但经营活动现金流净流出高达3.73亿元，且超过12.5亿元的核心资产（固定资产、在建工程、无形资产）仍处于抵押状态。公司2026年经营计划目标营收8.41亿元，较2025年近乎翻倍，但2025年长链二元酸实际销量仅完成计划的63%，活性炭完成83.5%，历史执行率偏低。若新控股股东无法有效赋能，公司可能再次陷入“复产-亏损-停产”的恶性循环。
