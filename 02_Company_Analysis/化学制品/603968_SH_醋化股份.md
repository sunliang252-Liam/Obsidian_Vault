# 603968.SH 深度透视

## 因果逻辑链
- **[行业“内卷”式竞争加剧]** -> [主要产品价格持续低位]: 市场供过于求，公司核心产品（食品饲料添加剂、医药农药中间体等）售价承压，直接导致营收下降10.93%。
- **[营收下滑与成本刚性]** -> [连续第二年亏损]: 尽管营业成本下降14.34%，但营收降幅更大，叠加管理费用、财务费用增加，导致归母净利润为-0.59亿元。
- **[原材料价格下降]** -> [毛利率改善]: 主要原材料冰醋酸、巴豆醛等采购价格同比下降，使得化学品制造毛利率同比增加3.82个百分点，亏损幅度显著收窄。
- **[子公司宏信化工持续亏损]** -> [拖累整体业绩]: 子公司宏信化工（主营安赛蜜）净资产为负，净利润-4968.83万元，成为公司重要的亏损源。
- **[存货大幅增加]** -> [资产减值风险]: 存货较期初增加39.34%，主要系备货增加，但资产减值损失高达7511.57万元，反映产品跌价压力。
- **[终止股权激励]** -> [一次性费用与股本减少]: 终止2022年股权激励计划，产生股份支付费用冲回，并回购注销限制性股票，影响资本公积和股本。
- **[经营活动现金流净额转负]** -> [盈利质量恶化]: 经营活动现金流净额从1.78亿元骤降至-0.26亿元，主要系销售回款减少，显示公司造血能力承压。

## 风险警告
公司连续两年亏损，核心问题是行业“内卷”导致产品价格持续低迷，且短期内看不到根本性改善的迹象。虽然原材料降价带来毛利率修复，但营收下滑和子公司（宏信化工）的严重亏损正在侵蚀所有改善成果。存货激增伴随大额资产减值，表明市场去库存压力巨大，产品跌价风险尚未出清。

更值得警惕的是，公司经营活动现金流已转为净流出，表明其主营业务已无法自我“造血”。在行业竞争格局未获根本改善前，任何成本端的利好都可能被价格端的持续压力所抵消。公司未来能否扭亏，高度依赖行业供需关系的逆转或新产品的放量，但这在年报中并未看到明确的信号。
