# 603722.SH 阿科力 深度透视

## 因果逻辑链
- **[聚醚胺行业产能过剩，价格战加剧]** -> [核心业务亏损]: 国内聚醚胺竞争对手（万华化学、隆华新材等）持续扩能，导致产品价格长期低位，公司聚醚胺业务毛利率虽同比改善4.11个百分点，但整体仍处于亏损状态，拖累公司整体净利润。
- **[光学材料原材料价格上涨，成本传导不畅]** -> [毛利率大幅下滑]: 光学材料主要原材料（莰烯）价格上涨38.11%，但产品售价涨幅不及成本涨幅，导致光学材料毛利率同比下降11.16个百分点，侵蚀了该业务的利润空间。
- **[潜江基地投产初期，费用前置]** -> [短期利润承压]: 全资子公司潜江生产基地一期进入试生产阶段，新增产能尚未完全释放，但前期投入的折旧、人工及运营费用已开始计入，增加了当期成本。
- **[股权激励计提股份支付费用]** -> [管理费用与研发费用激增]: 2025年实施限制性股票激励计划，计提股份支付费用，导致管理费用和研发费用分别同比增加5.36%和41.84%，直接减少了当期净利润。
- **[COC/COP实现产业化突破]** -> [打开长期成长空间]: 高透光材料（环烯烃共聚物COC）千吨级生产线稳定运行并实现小批量销售，标志着公司成功打破国外垄断，进入高端光学及医药包装材料这一高增长、高壁垒市场。
- **[小规格聚醚胺市场开拓见效]** -> [产品结构优化]: 面对大规格聚醚胺的激烈竞争，公司积极开拓小规格聚醚胺市场，全年销售量达5518吨，同比增加约30%，部分对冲了核心产品价格下跌的影响。
- **[给予优质客户延长信用账期]** -> [经营性现金流恶化]: 为维护核心客户关系，公司延长了优质客户的信用账期，叠加支付上年代收代付补贴款及到期承兑，导致经营活动现金流净额由正转负，从+8427万元骤降至-6467万元。

## 风险警告
**核心风险在于聚醚胺主业的持续亏损与现金流恶化。** 公司核心产品聚醚胺面临行业性产能过剩，价格战短期内难以缓解，导致该业务持续亏损。同时，为维持销售，公司主动延长客户账期，导致经营性现金流大幅流出，严重侵蚀了公司的财务健康度。若聚醚胺价格无法回升或成本无法有效降低，公司主业将面临持续失血的风险。

**第二重风险是新产品COC的产业化与市场推广不及预期。** 虽然COC已实现量产并销售，但该产品技术壁垒极高，下游客户（尤其是医药、光学领域）认证周期长，市场开拓存在不确定性。同时，万华化学、拓烯科技等国内巨头也在积极布局，未来COC市场同样面临竞争加剧的风险。公司能否在窗口期内快速占领市场、实现规模效应，是扭转局面的关键，但存在较大变数。

> 无锡阿科力科技股份有限公司成立于1999年,前身为无锡阿科力化工有限公司,位于无锡市锡山区东港镇新材料产业园。2017年10月25日,公司在上海证券交易所成功挂牌上市,股票代码603722。公司自成立以来,一直专注于研发生产各类化工新材料产品,不断自主创新。公司凭借其完善的化工基础设施、自行研发的专利技术以及丰富的生产工艺流程控制经验,已成为国内较领先的规模化生产聚醚胺、(甲基)丙烯酸异冰片酯的科技型企业。其中,公司聚醚胺设计产能2万吨/年,光学材料产品(甲基)丙烯酸异冰片酯等设计产能5000吨/年。上述产品均已通过了欧盟REACH认证、美国TSCA认证、德国船级社GL认证。公司是国家级专精特新小巨人企业、中国石化行业技术创新示范企业、江苏省高新技术企业、江苏省科技小巨人企业,无锡市十佳科技创业型企业。已建成国家级博士后工作站分站、省级研究生工作站和省级工程技术研究中心。公司多次承担并完成省市科技研发项目。特别是聚醚胺产品,我公司自主合成的高活性高选择性的催化剂体系,突破了连续化生产工艺,实现了多牌号聚醚胺产品工业化生产,运行稳定。该产品生产工艺经专家鉴定达到了国际先进水平,并获得了2015年度江苏省科技进步奖三等奖及无锡市科技进步奖二等奖的表彰。公司已通过了ISO9001:2008质量管理体系、ISO45001:2008职业健康安全管理体系、ISO14001:2015环境管理体系、安全生产二级标准化认证,被评为无锡市“重合同守信用”企业。公司秉持“因为专一,所以专业”的经营理念,坚持以功能性化工新材料为主营业务,充分发挥产学研合作及博士后科研工作站的优势,加快产品开发力度,培育持续的企业核心竞争力,致力于使公司成为国内的光学镜片、风力发电、页岩气开采、环保型涂料等领域使用的特种高分子材料研发和生产基地。
