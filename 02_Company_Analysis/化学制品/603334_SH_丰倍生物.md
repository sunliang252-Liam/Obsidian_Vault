# 603334.SH 深度透视

## 因果逻辑链
- **[SAF（可持续航空燃料）需求爆发]** -> [工业级混合油销量暴增163%]: 全球航空业脱碳驱动SAF原料需求，公司凭借预处理技术优势，将废弃油脂加工成高品质工业级混合油，成为核心增长引擎。
- **[欧盟反倾销调查]** -> [业务结构战略性调整]: 为规避欧盟对生物柴油的贸易壁垒，公司主动将产能和销售重心从生物柴油转向工业级混合油及国内生物基材料，导致生物燃料收入仅增6%，而生物基材料收入翻倍。
- **[“产品+服务”PSC模式]** -> [化肥助剂客户高粘性]: 公司不仅提供防结块剂，还根据化肥企业工艺定制配方并按产量结算，深度绑定客户，形成稳定且持续增长的收入来源。
- **[废弃油脂“点多面散”]** -> [采购渠道成为核心壁垒]: 公司通过搭建全国供应网络、培训区域供应商、签订长约，锁定上游稀缺原料，保障生产稳定性和成本优势。
- **[募投项目投产]** -> [产能扩张与资产结构变化]: 2025年10月募投项目第一条生产线完工，固定资产大增190%，在建工程大降91%，为未来收入增长提供物理基础。
- **[上市融资]** -> [财务结构优化]: IPO募集资金到账，货币资金增长240%，净资产增长125%，大幅降低负债率，为公司扩张和研发提供充足资金。
- **[研发投入聚焦]** -> [差异化竞争优势]: 公司围绕“基础研究、材料开发、应用开发”，拓展生物基材料在煤泥浮选、沥青等新领域应用，并获省科技进步一等奖，构建技术护城河。

## 风险警告
**核心风险在于原材料价格与供应波动。** 废弃油脂成本占营业成本90%以上，其价格受下游生物柴油、大豆油等大宗商品价格影响巨大。若原油或植物油价格大幅下跌，公司产品售价将承压，毛利率可能进一步收窄（2025年已下降4.17个百分点）。同时，上游废弃油脂回收体系仍依赖个人供应商，供应稳定性存在隐患。

**国际贸易政策风险不容忽视。** 公司外销业务（占收入30%）主要依赖欧洲和新加坡市场。欧盟已对中国生物柴油发起反倾销调查，虽然公司通过转向工业级混合油和国内业务进行对冲，但若贸易摩擦升级或SAF相关政策变动，仍可能对出口业务造成重大冲击。此外，汇率波动（美元结算）也持续影响财务费用。
