# 688129.SH 深度透视

## 因果逻辑链
- **[汽车主机厂原厂认证先发优势]** -> [市场份额提升]: 公司获得宝马、比亚迪、华为问界等主流品牌认证，形成高壁垒准入资格，直接转化为售后修补涂料收入同比增长24.97%。
- **[国产替代需求爆发]** -> [新车内外饰件涂料增长]: 汽车供应链自主可控需求强烈，公司作为唯一中国品牌获得上汽通用、长安福特、大众汽车外饰件认证，推动该业务收入同比增长2.94%。
- **[经济型产品下沉策略]** -> [中低端市场扩张]: 针对消费降级趋势推出经济型修补涂料，借中高端品牌势能快速渗透四、五线城市，带动整体产销量增长32.93%。
- **[原材料价格下行周期]** -> [毛利率承压]: 直接材料成本占主营成本70%，报告期内树脂、溶剂等价格同比下降5%-21%，但汽车售后修补涂料毛利率仍下降5.06个百分点，反映成本传导存在时滞。
- **[非经常性损益高占比]** -> [净利润质量偏低]: 扣非净利润仅占归母净利润64.5%，主要依赖理财产品收益（3,469万元）和政府补助（754万元），核心业务盈利能力有待验证。
- **[产能建设加速]** -> [资本开支压力]: 万吨水性涂料项目主体完工，预计2026年12月投产；华南基地项目尚处筹划阶段，未来资本开支将显著增加，可能影响现金流。
- **[股权激励绑定核心团队]** -> [人才稳定性]: 2024年限制性股票激励计划覆盖293人，第一个归属期条件成就，有效绑定研发、销售等关键岗位，支撑技术迭代与市场开拓。

## 风险警告
**核心风险在于盈利质量与产能消化。** 公司扣非净利润仅占归母净利润的64.5%，非经常性损益（理财收益+政府补助）占比过高，掩盖了主业盈利能力偏弱的现实。汽车售后修补涂料毛利率同比下降5.06个百分点，显示成本传导能力不足，若原材料价格反弹，利润将承压。此外，万吨水性涂料项目延期至2026年底，华南基地尚在筹划，产能释放节奏存在不确定性，若下游需求不及预期，新增产能可能成为负担。

**行业竞争格局与政策风险不可忽视。** 汽车涂料市场被欧美日品牌垄断，公司虽为“中国力量”代表，但市场份额仍较小。巴斯夫涂料业务被收购、艾仕得与阿克苏诺贝尔合并，行业整合加速，可能挤压公司生存空间。同时，GB30981.2-2025新标准将于2026年6月实施，对VOC等有害物质限量要求更严，公司油性涂料产能占比超85%，若水性涂料替代不及预期，将面临产品淘汰风险。海外销售占比约11%，地缘政治与贸易摩擦可能影响俄罗斯拉达等海外项目持续性。
