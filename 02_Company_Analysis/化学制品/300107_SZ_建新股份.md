# 300107.SZ 深度透视

## 因果逻辑链
- **[行业需求偏弱与竞争加剧]** -> [营收与利润双降]: 下游染料、纸张、医药等行业需求疲软，叠加印度等海外竞争者冲击，导致公司主要产品销量和价格同步下滑，营收下降23.12%，净利润由盈转亏。
- **[产品价格全面下跌]** -> [毛利率承压]: 四大核心产品（染料中间体、纸张化学品、医药中间体、新材料中间体）售价同比降幅达4.83%-23.83%，远超成本降幅，导致综合毛利率从6.44%进一步恶化，部分产品（医药中间体、纸张化学品）毛利率转负。
- **[研发与技改投入加大]** -> [短期侵蚀利润]: 公司为提升长期竞争力，持续加大新产品研发和现有工艺技改投入，研发费用同比增长12.03%至3996万元，占营收比升至8.59%，对当期利润形成直接压力。
- **[“一链三体”产业链优势]** -> [结构性对冲风险]: 以间氨基苯磺酸为基础，形成染料、医药、纸张、新材料四大中间体板块，各产品既可独立销售，又可作为上下游原料相互衔接，部分抵消了单一产品下滑的冲击。
- **[复合材料和新材料中间体逆势增长]** -> [成为唯一亮点]: 受益于下游聚砜、芳纶、电子级聚酰亚胺等高端新材料需求增长，该板块营收同比增长20.14%，毛利率提升3.19个百分点至14.82%，成为公司业绩的稳定器。
- **[外销业务受汇率与关税双重冲击]** -> [出口大幅下滑]: 公司外销占比27.87%，以美元结算。人民币汇率波动及美国关税壁垒，导致公司在美国市场与印度等对手竞争中处于劣势，外销收入同比骤降39.88%。
- **[子公司建新瑞祥项目推进]** -> [未来增长点蓄势]: 公司持续向子公司建新瑞祥增资，其年产1000吨液晶高分子材料中间体项目进入试生产准备阶段，标志着公司在电子化学品领域的战略布局取得实质性突破，有望成为新的利润增长点。

## 风险警告
**核心风险在于业绩反转的确定性不足。** 公司2025年陷入亏损，主因是下游需求疲软和竞争加剧导致的量价齐跌，且这一趋势在2026年能否逆转尚不明朗。公司核心产品（染料、纸张化学品）面临全行业亏损压力，而唯一的增长点（复合材料和新材料中间体）体量尚小，难以完全对冲传统业务的颓势。若下游需求持续低迷或价格战延续，公司盈利能力可能进一步恶化。

**战略转型与投资风险并存。** 公司正大力布局电子化学品（建新瑞祥）和低空经济（参股建新飞行汽车），这些项目前期投入巨大，且面临技术、市场、审批等多重不确定性。建新瑞祥项目能否顺利达产并实现盈利，以及低空经济领域的投资能否最终兑现，均存在较大变数。若新业务不及预期，将拖累公司整体资产回报率，并可能引发投资减值风险。
