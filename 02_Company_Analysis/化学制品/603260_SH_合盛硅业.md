# 603260.SH 深度透视

## 因果逻辑链
- **[光伏业务巨亏]** -> [净利润-29.9亿元]: 多晶硅产线停产及光伏组件产能利用率低，产生大量停工损失与运营亏损，叠加存货及长期资产减值17亿元，是业绩由盈转亏的核心原因。
- **[行业供需失衡，产品价格承压]** -> [营收下降23.2%]: 工业硅、有机硅及多晶硅行业均处于阶段性供需结构调整期，主要产品价格同比大幅下降（金属硅均价降约27%，聚硅氧烷均价降约12%），导致收入萎缩。
- **[产业链协同降本]** -> [核心业务毛利率承压但仍为正]: 依托新疆能源成本优势及内部原料优先配置，工业硅毛利率16.48%，有机硅毛利率11.77%，虽同比下滑，但未出现全行业亏损。
- **[资本开支放缓]** -> [投资活动现金流净流出大幅减少]: 光伏项目建设进度放缓，支付工程设备款减少，投资活动现金流净额从-44.4亿收窄至-13.8亿。
- **[高负债率与利息费用化]** -> [财务费用激增30.7%]: 资产负债率维持高位（65%），借款费用化利息增加，财务费用达11.65亿元，侵蚀利润。
- **[资产减值风险暴露]** -> [资产减值损失17亿元]: 因产品价格低迷及光伏产线暂缓，对存货及长期资产（固定资产、在建工程）计提大额减值，占利润总额的60.6%。

## 风险警告
公司当前最大风险在于**光伏业务深度拖累与资产减值压力**。多晶硅及光伏组件产线利用率极低，已产生巨额停工损失，且在建工程（如中部合盛多晶硅项目）处于暂缓状态。若行业复苏不及预期，相关固定资产及在建工程面临进一步减值风险，将持续侵蚀公司利润和净资产。

其次，**高杠杆运营下的偿债压力**不容忽视。公司总负债543亿，资产负债率65%，且短期借款与一年内到期非流动负债合计超112亿。在经营现金流净额同比下滑11%的背景下，若产品价格持续低迷，公司流动性及再融资能力将面临严峻考验。此外，母公司未分配利润已为-35.5亿元，未来分红能力受限。
