# 600273.SH 深度透视

## 因果逻辑链
- **[脂肪醇(酸)原料价格上涨]** -> [营收增长但利润承压]: 棕榈仁油等原料采购价同比上涨41.81%，推动脂肪醇(酸)系列产品营收增长49.99%，但成本增幅(56.60%)高于收入增幅，导致毛利率下降3.83个百分点。
- **[PVC行业产能过剩与地产需求疲软]** -> [PVC业务亏损]: 聚氯乙烯(氯乙烯)产品毛利率为-11.45%，主要因地产建材需求低迷、行业开工率高，产品价格低位运行，而成本端相对刚性。
- **[热电联产循环经济模式]** -> [核心成本优势]: 以热电联产为源头，蒸汽、电力自供及氯碱、氢气等副产品内部循环利用，显著降低各产品线生产成本，是公司穿越行业周期的基本盘。
- **[烧碱供需平稳]** -> [高毛利稳定贡献]: 作为浙北唯一氯碱生产商，区域内供需稳定，烧碱(折百)毛利率高达65.20%，是公司利润的重要稳定器。
- **[套期保值与外汇期权]** -> [非经常性损益大幅增厚利润]: 公允价值变动收益同比暴增1839.18%至6471万元，主要来自期货交易及外汇期权，但该收益不可持续，掩盖了主业盈利能力下滑。
- **[股份回购与注销]** -> [每股收益维持稳定]: 报告期内注销3417万股并继续大额回购，总股本减少2.46%，在净利润下降1.99%的情况下，基本每股收益维持在0.74元。
- **[关联交易依赖度高]** -> [经营独立性风险]: 前五名客户中关联方销售占比12.19%，前五名供应商中关联方采购占比6.63%，公司深度嵌入控股股东控制的化工园区生态。

## 风险警告
**核心风险在于主业盈利能力持续下滑与对非经常性损益的过度依赖。** 扣非净利润同比下降9.57%，而公允价值变动收益（主要来自期货和外汇期权）贡献了超1.17亿元的非经常性收益，掩盖了化工主业（尤其是PVC板块）的疲软。若未来大宗商品价格波动方向不利，套保收益将难以复制，利润将面临更大压力。

**周期性风险与关联交易风险交织。** 公司核心产品脂肪醇(酸)和PVC均处于强周期行业，原料价格（棕榈仁油、乙烯）和产品价格波动剧烈。同时，公司作为园区核心企业，与控股股东旗下其他公司存在大量关联购销，交易定价的公允性和经营的独立性需持续关注，任何关联方信用或经营问题都可能传导至上市公司。
