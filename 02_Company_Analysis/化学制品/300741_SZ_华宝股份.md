# 300741.SZ 深度透视

## 因果逻辑链
- **食用香精业务收入下滑20.67%** -> **整体营收微降1.40%**: 食用香精（含烟草用）是公司最大收入来源（占50.58%），其大幅下滑拖累了整体营收表现，但被食品配料（+30.36%）和日用香精（+25.62%）的增长部分抵消。
- **食品配料业务收入增长30.36%** -> **公司扭亏为盈**: 食品配料成为核心增长极，通过并购嘉品嘉味等企业及产品创新（爆珠、果酱、天然提取物），成功弥补了传统香精业务的萎缩，推动归母净利润从-2.96亿转为+0.84亿。
- **2024年计提大额商誉减值** -> **2025年低基数下净利润大幅反弹**: 2024年因烟草用香精资产组计提5.05亿商誉减值导致巨亏，2025年无此事项，叠加业务改善，归母净利润同比大增128.28%。
- **收购嘉品嘉味集团** -> **合并范围扩大，食品配料业务增厚**: 2025年6月收购嘉品嘉味（含9家子公司），直接贡献了食品配料的收入增量，并导致食品配料库存量同比上升44.13%。
- **经营活动现金流净额下降50.72%** -> **应收账款回收减少**: 期初应收账款余额降低，导致本期回收金额减少，现金流入承压，与净利润扭亏形成反差。
- **交易性金融资产大幅增加** -> **投资活动现金流净流出**: 期末购买结构性存款增加，交易性金融资产从7.07亿激增至27.33亿，导致投资活动现金流净额为-5.29亿元。
- **终止首期股权激励并推出新激励计划** -> **管理费用和销售费用增加**: 终止确认股权激励产生一次性股份支付费用约7005万元，导致期间费用率上升，侵蚀了部分利润。

## 风险警告
**核心风险在于传统烟草香精业务的持续萎缩与高额商誉的减值威胁。** 食用香精（主要为烟草用）收入同比下降20.67%，且2024年已因此计提5.05亿商誉减值。若下游烟草行业需求继续下滑或监管政策进一步收紧，公司可能面临核心业务失速与商誉二次减值的双重打击。截至2025年末，合并报表商誉账面价值仍高达7.18亿元，减值风险远未出清。

**公司盈利质量与现金流状况存在隐忧。** 尽管2025年实现扭亏，但经营活动现金流净额同比腰斩（-50.72%），与净利润增长背离。同时，公司大量资金用于购买结构性存款（交易性金融资产增至27.33亿），投资活动现金流大幅净流出，显示公司主业造血能力减弱，且对金融投资收益的依赖度上升。此外，公司正面临与上海奕方原股东的仲裁纠纷（涉案金额6.47亿元），执行结果存在重大不确定性。
