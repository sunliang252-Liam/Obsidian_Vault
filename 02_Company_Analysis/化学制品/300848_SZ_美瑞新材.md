# 300848.SZ 深度透视

## 因果逻辑链
- **[特种异氰酸酯项目投产]** -> [收入结构质变]: 功能化工品原料收入从33万激增至1.47亿，占比从0.02%跃升至8.41%，标志公司从单一TPU供应商向产业链一体化平台转型。
- **[HDI装置全球单套最大产能爬坡]** -> [制造费用飙升62%]: 河南鹤壁基地转固及试运行，导致折旧与制造费用大幅增加，是压制当期利润的核心因素。
- **[原材料价格下降]** -> [TPU售价下调6.47%]: 公司主动让利，以价换量，实现TPU销量增长，但营收仅微增3.38%，毛利率基本持平。
- **[经营性现金流大幅转正]** -> [营运效率改善]: 现金流从-1.32亿飙升至+3.21亿，主因是购买商品支付现金减少，显示库存管理及供应链付款节奏优化。
- **[研发费用同比下降16%]** -> [短期利润平滑]: 在项目投产关键期缩减研发投入，虽保住了净利润增长，但可能影响长期技术储备的节奏。
- **[对美瑞科技增资至70.03%]** -> [归母净利润权益提升]: 增资后控股比例提升，未来美瑞科技盈利对归母净利润的贡献将显著放大。
- **[存货跌价损失1362万]** -> [新业务初期风险暴露]: 计提大额存货跌价准备，反映特种异氰酸酯等新产品在市场导入期面临的价格与库存压力。

## 风险警告
**核心风险在于新业务“投产即亏损”的财务拖累。** 美瑞科技（河南）2025年净利润为-3772万元，其HDI等特种异氰酸酯装置虽在四季度末实现长周期稳定运行，但全年仍处于试产爬坡期，巨额折旧与低负荷生产导致严重亏损。公司为此承担了高额担保（期末担保余额12.27亿，占净资产80%），财务杠杆急剧放大，若产能利用率提升不及预期，将严重侵蚀母公司利润。

**另一重大风险是TPU主业增长乏力与竞争加剧。** 公司核心产品TPU营收同比下降3.38%，售价下滑6.47%，显示在传统领域面临激烈价格战。公司寄望于通过特种异氰酸酯向下游拓展高附加值产品（如脂肪族TPU、PUD），但新产品的市场验证与放量存在高度不确定性。若“向上游突破”的产业链故事无法快速转化为“向下游渗透”的业绩，公司可能陷入主业萎缩、新业务亏损的双重困境。
