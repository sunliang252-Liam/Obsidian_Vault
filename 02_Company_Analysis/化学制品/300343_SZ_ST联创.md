# 300343.SZ 深度透视

## 因果逻辑链
- **[配额转让收入]** -> [净利润扭亏]: 2025年公司通过转让生产配额获得7851万元营业外收入，直接覆盖了主营业务亏损，是净利润实现3907万元的核心来源。
- **[含氟新材料毛利率提升]** -> [毛利改善]: 含氟新材料板块毛利率从12.13%提升至16.86%，主要受益于HFCs配额制落地后行业供给收缩、价格理性回归，以及公司PVDF产品结构优化。
- **[PVDF产能利用率分化]** -> [资产减值]: 6000吨/年PVDF项目产能利用率仅11%，远低于8000吨/年项目的78%，导致公司计提2018万元资产减值损失，拖累扣非净利润。
- **[聚氨酯板块低毛利]** -> [盈利拖累]: 聚氨酯新材料板块毛利率仅5.03%，且同比下滑2.4个百分点，在行业景气度低迷背景下，该板块对整体盈利贡献微弱。
- **[财务费用大幅增加]** -> [利润侵蚀]: 财务费用从-487万元转为158万元，主要因汇率波动导致汇兑损益变化，增加了期间费用压力。
- **[经营活动现金流改善]** -> [现金流回正]: 经营活动现金流净额从-4204万元转为1970万元，主要得益于收到配额转让款及销售回款改善，但扣非净利润仍为负，显示经营造血能力依然脆弱。

## 风险警告
**核心风险在于主营业务持续亏损，盈利高度依赖非经常性损益。** 公司扣非净利润已连续三年为负（2023年-2438万，2024年-4334万，2025年-2144万），表明核心的含氟新材料和聚氨酯业务并未形成可持续的盈利能力。2025年的盈利主要来自一次性配额转让收入，这种模式不可持续。一旦配额转让收益减少或消失，公司将重新陷入亏损。

**历史财务造假与治理风险是长期隐患。** 公司因信息披露违规被证监会行政处罚，股票被实施其他风险警示（ST），暴露出内部控制存在重大缺陷。尽管已进行会计差错更正，但投资者信任修复需要时间。同时，公司因收购上海鏊投网络遭遇合同诈骗，虽已追回部分损失，但仍有巨额资金未追回，对资产质量和现金流构成持续压力。

> 山东联创产业发展集团股份有限公司(股票代码:300343),成立于2003年1月29日,主要从事聚氨酯、氟化工产品的研发、生产和销售等业务。2012年8月1日公司在深圳创业板上市,公司致力于绿色化学品的研发、生产与推广。公司始终坚持技术创新理念,与中国兵器工业集团第四研究院、中山大学等研究院所长期合作,研发设备先进齐全,研发能力强大。公司连续多年被列为淄博市百强企业,获得2023年全球TOP20氟化工企业、中国十大氟化工上市公司、山东省民营企业创新潜力百强企业、山东省高端品牌培育企业等荣誉称号。旗下全资子公司经过多年潜心研发,拥有多项专有技术,并建有山东省企业技术中心、含氟烯烃山东省工程研究中心、山东省“一企一技术”研发中心、山东省含氟烯烃低碳环保制冷剂工程技术研究中心。为持续保持创新能力及技术领先地位奠定了基础。公司以化工环保新材料为主业,在原有的含氟聚合物、聚氨酯及聚酯等系列产品基础上,着力于发展聚氨酯新材料,第四代制冷剂,第四代发泡剂,含氟新型聚合物,精细化学品为核心产品的新材料产业链,发掘其新能源汽车、光伏发电、超级温室气体减排等领域的创新应用及其经济效应和社会效应,以抓住碳中和带来的“新能源革命”,为客户提供高效、持续、稳定的产品与服务,为社会绿色低碳发展贡献力量。
