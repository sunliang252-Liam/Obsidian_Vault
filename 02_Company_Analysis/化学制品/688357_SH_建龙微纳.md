# 688357.SH 深度透视

## 因果逻辑链
- **[产品结构优化]** -> [毛利率提升3.57个百分点]: 公司主动减少低毛利原粉外销，增加高附加值成型分子筛及生命健康板块产品比重，带动综合毛利率从28.35%提升至31.92%。
- **[生命健康板块爆发]** -> [营收增长48.60%]: 医用制氧下游库存消化后需求回归，叠加分子筛型动物饲料添加剂市场打开，该板块收入从1.26亿跃升至1.87亿，成为最大增量。
- **[国际化战略落地]** -> [外销收入首破2亿]: 泰国建龙二期产能释放，实现营收1.36亿元（+72.93%），带动公司外销收入达2.17亿元，形成国内国外双轮驱动格局。
- **[降本增效持续]** -> [扣非净利润增长55.65%]: 在营收仅增长7.94%的情况下，通过优化工艺、控制原材料成本，扣非净利润增速远超营收增速，盈利质量显著改善。
- **[“吸转催”战略推进]** -> [SAF催化剂进入工业化验证]: 公司开发的SAF异构化催化剂完成下游长周期侧线评价，标志着从传统吸附剂向高价值催化剂领域的关键跨越。
- **[布局新型储能]** -> [打开长期增长天花板]: 公司作为核心成员参与国内首个吸附压缩二氧化碳储能项目，并为青海液态空气储能示范项目供货，切入百亿级储能新赛道。
- **[参股汉兴能源]** -> [补齐“材料+工艺+装置”能力]: 收购汉兴能源40%股权，引入其制氢工程系统集成能力，推动公司从材料制造商向综合技术服务商转型。

## 风险警告
**产能消化与募投项目延期风险。** 公司总产能已达10.8万吨，但2025年分子筛材料产量9.23万吨，销量仅4.74万吨，产销率仅51.3%，库存量同比增长4.21%。可转债募投的“吸附材料产业园改扩建项目（二期）”投入进度仅15.58%，已明确存在延期风险。若下游需求增速放缓或竞争加剧，大规模产能可能无法有效消化，导致资产回报率下降。

**可转债转股压力与财务费用上升风险。** 公司存续7亿元可转债，当前转股价71.71元远高于现价，转股可能性极低。随着部分建设项目转固，利息费用化导致财务费用从-489万升至-83万，未来若无法触发下修或强赎，公司将面临持续的利息支付压力，对利润形成侵蚀。同时，资产负债率已从39.08%升至39.50%，财务杠杆有所增加。
