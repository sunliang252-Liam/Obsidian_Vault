# 301100.SZ 深度透视

## 因果逻辑链
- **[榆林工厂产能利用率提升]** -> [营收增长13.66%]: 榆林项目产能爬坡，带动总销量增长25.43%，推动收入突破11.4亿元。
- **[客户结构优化与核心客户深化]** -> [订单稳步增长]: 深化与中石油、中石化等核心客户合作黏性，订单提升，支撑收入增长。
- **[拓展海外市场]** -> [外贸销量增长约10%]: 2025年为出海元年，海外市场成为新增量，部分对冲国内竞争压力。
- **[原材料成本上涨与行业毛利率下滑]** -> [净利润持续亏损]: 国际大宗商品价格波动及行业竞争导致毛利率承压，尽管收入增长，但归母净利润仍为-4862万元。
- **[产能扩张与人员增加]** -> [运营成本高企]: 榆林项目投产带来折旧基数大、人员大幅增加，导致管理费用、销售费用等刚性支出上升，侵蚀利润。
- **[研发投入加大]** -> [新产品布局]: 研发费用增长31.75%，用于POE催化剂、茂金属催化剂等新产品开发，为未来增长蓄力。
- **[经营活动现金流净额大幅转负]** -> [营运资金压力]: 销量增加导致原材料采购量激增，经营活动现金流净额从+1440万骤降至-1.38亿，反映产能爬坡期的资金占用。
- **[收购宁夏三石博涛]** -> [拓展催化剂业务]: 通过收购控股宁夏三石博涛，布局催化剂领域，丰富产品线，培育新利润增长点。

## 风险警告
公司当前最核心的风险是**“增收不增利”的盈利困境**。尽管营收增长13.66%，但归母净利润连续两年亏损（-4862万元），且扣非净利润亏损扩大。核心矛盾在于：榆林项目产能释放带来的收入增量，被原材料成本上涨、行业毛利率下滑、以及产能扩张带来的折旧和人员成本大幅增加所吞噬。若行业周期底部持续，公司盈利能力难以在短期内修复。

其次，**经营现金流恶化与客户集中度风险**构成双重压力。经营活动现金流净额由正转负至-1.38亿元，显示公司在产能爬坡期面临严峻的营运资金压力。同时，前五大客户收入占比24.38%，主要客户为中石油、中石化等大型国企，若下游需求波动或客户流失，将对公司业绩造成重大冲击。此外，原材料价格受地缘政治影响不确定性大，进一步加剧了盈利预测的难度。
