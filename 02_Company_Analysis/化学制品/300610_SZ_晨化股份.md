# 300610.SZ 深度透视

## 因果逻辑链
- **[核心原材料价格波动]** -> **业绩承压**: 主要原料A（环氧乙烷）价格因成本推高和供不应求而上涨，直接压缩了公司主营产品的利润空间。
- **[阻燃剂车间火灾停产]** -> **阻燃剂销量下滑**: 2024年10月曹甸镇阻燃剂车间火灾导致临时停产，2025年阻燃剂销量同比下降20.60%，拖累整体营收。
- **[表面活性剂产销稳健]** -> **业绩压舱石**: 表面活性剂业务通过聚焦产品线和定制化开发，销量和毛利均有所上升，贡献了81.63%的营收，是公司最稳定的收入来源。
- **[非经常性损益依赖度高]** -> **净利润虚高**: 2025年归母净利润6598万元，但扣非净利润仅3397万元，理财收益（3744万元）等非经常性损益占比高达48.5%，主业盈利能力较弱。
- **[烷基糖苷产能扩张]** -> **未来增长点**: 子公司淮安晨化年产3.5万吨烷基糖苷扩建项目于2025年12月试生产，达产后总产能将达7万吨/年，有望抢占生物基表面活性剂市场。
- **[出口业务增长]** -> **市场拓展**: 2025年国外市场收入1.24亿元，同比增长4.33%，公司通过设立上海晨化国际子公司及欧盟REACH注册，积极开拓海外市场。
- **[财务费用由负转正]** -> **资金成本上升**: 财务费用从-73万元转为89万元，主要因汇兑损失和利息收入减少，同时短期借款大幅增加至1.36亿元，显示公司资金压力有所加大。

## 风险警告
晨化股份的核心风险在于**主业盈利能力的持续下滑与对非经常性损益的过度依赖**。2025年扣非净利润同比大幅下降37.38%，而理财收益却高达3744万元，占利润总额的42.31%。这种“理财养主业”的模式不可持续，一旦金融市场波动或理财收益下降，公司真实盈利将暴露无遗。此外，阻燃剂车间火灾后的复产进度存在不确定性，若2026年不能顺利复产，将进一步拖累业绩。

另一个重大风险是**行业竞争加剧与原材料价格波动的双重挤压**。公司主要产品阻燃剂市场供大于求，价格持续低迷；而核心原料环氧乙烷价格受制于进口依赖和成本推动，易涨难跌。公司在建工程（如烷基糖苷扩建项目）虽为未来增长点，但短期内将增加折旧和资金压力，且新产能的消化需要时间，若下游需求不及预期，将面临产能利用率不足的风险。
