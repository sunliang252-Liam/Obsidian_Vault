# 301283.SZ 深度透视

## 因果逻辑链
- **[原材料价格下降]** -> [毛利率大幅提升8.09个百分点]: 上游石油树脂等原料供过于求，价格下跌，直接降低营业成本，使净利润增速（+144.63%）远超收入增速（+7.24%）。
- **[海外收入占比57.33%]** -> [成为主要增长引擎]: 公司突破国际巨头垄断，进入全球前十大卫生用品厂商供应链，海外市场开拓是收入持续增长的核心驱动力。
- **[马来西亚基地投产]** -> [全球产能“三足鼎立”格局成型]: 中国-欧洲-东南亚三大基地协同，有效降低关税和供应链风险，增强客户信心，巩固全球竞争力。
- **[配方技术创新与国产替代]** -> [成本优化与产品性能领先]: 持续用国产原料替代进口，并开发定制化配方，在保持性能优势的同时实现降本增效，提升盈利能力。
- **[高毛利产品占比提升]** -> [产品结构优化]: 卫材热熔胶中高端产品及新业务消费品包装热熔胶的放量，推动整体毛利率结构性改善。
- **[经营活动现金流净额由负转正]** -> [资金管理成效显著]: 通过供应链融资及加强回款管理，现金流从-8426万元大幅改善至7.85亿元，财务健康度显著提升。
- **[大客户份额提升]** -> [存量深耕与增量突破]: 全球前十大卫生用品厂商合作深化，份额持续提升，为收入增长提供确定性基础。

## 风险警告
**核心风险在于海外经营与贸易摩擦的不可预测性。** 公司海外收入占比已超57%，且增长高度依赖海外市场。美国等国的关税政策频繁调整，地缘政治冲突（如俄乌局势）直接影响波兰工厂向特定区域的供货能力，导致其短期亏损。若贸易壁垒进一步加剧或全球海运成本再次飙升，将严重冲击公司海外业务的盈利能力和市场拓展节奏。

**第二重风险是原材料价格波动的双向挤压。** 公司主要原料（石油树脂、高聚物等）成本占比近88%，价格受原油及供需双重影响。2025年受益于原料降价，但若未来原料价格大幅上涨，产品价格传导存在滞后性，将直接压缩毛利率；反之若原料暴跌，下游客户可能要求降价，同样侵蚀利润。公司虽有多配方切换能力，但无法完全对冲剧烈波动。
