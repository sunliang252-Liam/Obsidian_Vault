# 688398.SH 深度透视

## 因果逻辑链
- **市场竞争加剧与产品均价下降** -> **毛利率下滑**: 真空绝热板销售均价同比下降，叠加内外销结构变化，导致产品毛利率减少5.82个百分点，直接侵蚀利润。
- **子公司维爱吉未投产** -> **管理费用激增**: 维爱吉尚未正式投产，其固定资产折旧费用计入管理费用，导致管理费用同比增长23.13%，拖累净利润。
- **可转债与银行贷款利息增加** -> **财务费用飙升**: 发行可转债计提利息及银行贷款利息增加，导致财务费用同比大增84.15%，显著压缩利润空间。
- **全球冰箱能效标准提升** -> **销量增长**: 欧盟新能效标签及中国新版冰箱能效标准（2026年实施）推动下游客户增加VIP用量，公司真空绝热板销量同比增长14.98%。
- **国内以旧换新政策** -> **内销收入增长**: 政策刺激下，国内家电市场需求回暖，公司境内销售收入同比增长19.38%，内销占比提升至63.80%。
- **保温箱业务放量** -> **收入结构优化**: 冷链业务保温箱销售收入同比增长173.44%，成为新的收入增长点，但体量尚小。
- **研发投入持续** -> **技术壁垒加固**: 公司持续投入研发（费用5.05%），在壳式四边封、金属VIP等新技术上取得进展，巩固了行业技术领先地位。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司2025年营收增长6.57%，但净利润暴跌68.66%，主因是产品降价、新产能折旧及财务费用三重压力。若未来市场竞争进一步加剧导致产品均价继续下行，或维爱吉投产进度再次延后，公司盈利能力可能进一步被压缩，甚至出现亏损。

**第二重风险是财务杠杆与现金流压力。** 公司长期借款同比大增56.64%，叠加可转债利息，财务费用已成沉重负担。同时，应收账款规模随内销占比提升而扩大，若下游客户回款放缓，可能引发现金流紧张。此外，公司约36%收入来自境外，美元汇率波动及潜在的贸易摩擦（如美国关税）是持续的外部风险。
