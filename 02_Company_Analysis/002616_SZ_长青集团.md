# 002616.SZ 深度透视

## 因果逻辑链
- **[资产出售与债务优化]** -> [资产负债率大幅下降]: 出售鱼台、中山垃圾发电等受限项目，回收现金并偿还债务，使资产负债率从73.23%降至62.35%。
- **[可转债成功转股]** -> [净资产大幅增长]: 6.04亿元可转债转换为股票，增加净资产，同时减少未来利息支出，归母净资产同比增长29.07%。
- **[国家电价补贴发放改善]** -> [经营性现金流创近年新高]: 补贴电费回收加快，经营性净现金流同比增长37.13%至8.11亿元，缓解了长期以来的资金压力。
- **[生物质项目技改与AI操控]** -> [运营指标改善]: 华中、华东项目度电燃料成本、发电小时数为近年最佳，东北区域奋起直追，整体运行效率行业领先。
- **[燃煤项目环保绩效创A级]** -> [提升综合效益]: 满城、蠡县项目通过A级验收，可自主减排不限产，并享受绿色信贷等政策红利，同时适度掺烧生物质降低碳排放。
- **[茂名项目开拓大型供热扩容]** -> [未来业绩增长点]: 成功开拓茂石化炼油厂及乙烯二期工程，有望使茂名项目营收大幅增长，成为重要业绩来源。
- **[非补贴业务拓展]** -> [降低对补贴依赖]: 12个生物质项目产生供热收入，延津供暖面积增至150万平米，滑县实现非电收入零的突破，为补贴到期后持续运营铺路。
- **[生物质材料化利用取得进展]** -> [开辟新赛道]: 与中国农业大学联合申报发明专利，探索从“燃料”向“原料”转型，布局生物质基聚氨酯等高价值产品。

## 风险警告
**核心风险在于早期项目的补贴到期与资产减值。** 公司早期投产的宁安、明水等项目面临15年补贴周期届满，报告期内已分别计提7918万和6278万元资产减值。若地方政府无法全额承接补贴，或非电收入增长不及预期，这些项目的盈利能力将面临严峻挑战，可能拖累整体业绩。

**燃料供应与价格波动是另一大经营风险。** 生物质燃料分散、收集成本高，且煤炭价格波动会直接影响燃煤供热项目的成本。虽然公司通过调价机制和燃料多元化策略对冲，但完全转嫁成本存在难度。此外，东北区域项目虽同比改善，但宁安、明水仍处于亏损状态，其扭亏进程存在不确定性。
