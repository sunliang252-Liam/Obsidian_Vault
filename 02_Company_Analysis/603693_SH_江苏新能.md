# 603693.SH 深度透视

## 因果逻辑链
- **[资产减值损失大幅减少]** -> [归母净利润同比增长21.73%]: 2024年计提2.56亿元减值准备，2025年回归正常水平，直接释放利润空间。
- **[财务费用同比下降16.12%]** -> [利润增长]: 公司优化融资结构、压降融资成本，利息支出减少约4000万元，直接增厚净利润。
- **[海上风电发电量同比下降5.29%]** -> [风电收入微降]: 受风资源波动影响，海上风电利用小时数下降，导致风电板块整体收入下滑1.61%。
- **[光伏装机同比增长36.18%]** -> [光伏发电量增长10.39%]: 新增约9万千瓦光伏项目并网，推动光伏板块收入增长1.26%，对冲风电下滑。
- **[储能项目新增并网]** -> [储能收入翻倍]: 国信溧阳100MW/200MWh储能电站投产，储能收入同比增长100.82%，成为新增长点。
- **[生物质项目全面停运]** -> [生物质发电收入归零]: 四家生物质电厂全部处于停运转型阶段，该板块收入同比减少100%，拖累整体营收。
- **[市场化交易电量占比从0.15%飙升至60.12%]** -> [电价波动风险加剧]: 新能源全面入市，公司2025年市场化交易电量达20.93亿千瓦时，电价从固定补贴转向市场竞价，盈利不确定性显著增加。
- **[控股股东先行投资155万千瓦海上风电]** -> [未来装机增量储备]: 国信集团中选大丰、东台海上风电项目，承诺后续注入上市公司，为公司“十五五”装机跨越式增长奠定基础。

## 风险警告
**电价市场化改革是最大不确定性。** 2025年公司市场化交易电量占比从0.15%飙升至60.12%，上网电价从固定补贴转向市场竞价。虽然存量项目机制电价暂按0.391元/千瓦时执行，但增量项目电价需通过竞价形成，未来电价下行压力将直接侵蚀项目收益率。公司电力市场交易经验尚浅，专业人才储备不足，在复杂多变的市场环境中可能面临“量价齐跌”的风险。

**补贴滞后与消纳压力长期存在。** 截至2025年末，公司应收账款高达34.61亿元，占营收的166%，主要系可再生能源补贴回款滞后。虽然新增项目已进入无补贴时代，但存量补贴缺口何时填平仍是未知数。同时，全国新能源装机占比已超60%，消纳压力持续加大，江苏虽为用电大省，但若未来电网调峰能力不足或外送通道受限，公司仍面临“弃风弃光”限电风险。
