# 301151.SZ 深度透视

## 因果逻辑链
- **[下游固定资产投资收缩]** -> [营收下降11.98%]: 水利管理业投资同比下降6.3%，公共设施管理业投资同比下降8.2%，直接导致阀门产品市场需求回落。
- **[行业竞争加剧]** -> [产品单价承压]: 国内阀门行业集中度低，中小企业价格战压缩利润空间，公司主动收缩高风险业务，进一步影响收入。
- **[强化回款风控]** -> [主动收缩高风险业务]: 公司提高客户回款审核标准，放弃部分高风险订单，虽保障现金流但牺牲了短期营收规模。
- **[控制阀产品结构优化]** -> [毛利率逆势提升13.92个百分点]: 控制阀营收增长24.02%，成本仅增4.23%，高附加值产品占比提升有效对冲了整体毛利率下滑压力。
- **[定期存款现金流入增加]** -> [经营现金流暴增681%]: 经营活动现金流入同比大增45.22%，主要系定期存款到期流入，而非主营业务造血能力实质性改善。
- **[总部基地项目转固]** -> [固定资产占比跃升13.81个百分点]: 智慧水务孵化基地项目达到预定可使用状态，在建工程大幅减少，资产结构从在建转向运营。
- **[外销与经销渠道扩张]** -> [对冲内销下滑]: 外销收入增长23.62%，经销收入增长18.94%，部分弥补了内销直销业务13.85%的降幅，显示渠道多元化成效。
- **[股权激励业绩未达标]** -> [回购注销限制性股票]: 第二个解除限售期业绩考核目标未达成，公司回购注销320,590股，反映短期经营压力传导至员工激励层面。

## 风险警告
公司面临的核心风险在于**下游需求的结构性萎缩与行业竞争白热化**。2025年营收与净利润双降，直接原因是水利、市政等核心下游固定资产投资收缩，且行业“内卷”导致产品单价承压。公司主动收缩高风险业务虽保障了现金流，但本质上是以牺牲规模换取安全，若宏观经济持续低迷，公司可能陷入“增收难、增利更难”的困境。此外，公司研发投入同比下降17.72%，研发人员减少，在智能化、数据中心液冷等新兴赛道竞争加剧的背景下，技术迭代速度放缓可能削弱长期竞争力。

**应收账款与存货的减值风险不容忽视**。报告期内信用减值损失达1,284万元，资产减值损失达1,005万元，合计占利润总额的30.4%，是侵蚀利润的重要因素。公司主要客户为水务集团和市政工程公司，其付款能力与地方财政状况高度绑定。若地方债务问题加剧，应收账款坏账风险可能进一步暴露。同时，存货跌价准备的计提也反映出部分产品面临市场需求变化或技术淘汰的压力。
