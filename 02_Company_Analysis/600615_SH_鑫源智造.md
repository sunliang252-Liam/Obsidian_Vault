# 600615.SH 深度透视

## 因果逻辑链
- **[并表鑫源农机]** -> [营收暴增227%，但归母净利转亏]: 2024年末收购鑫源农机51%股权，2025年全面并表带来收入从1.89亿跃升至6.17亿；但评估增值摊销、研发投入激增及全铝家居业务关停损失，导致净利润由盈转亏。
- **[鑫源农机研发投入激增]** -> [短期利润承压]: 为落实“轻量化+智能化”战略，研发人员大幅增加，研发费用占营收比达3.90%，新项目尚未产业化，导致当期费用高企。
- **[全铝家居业务关停]** -> [拖累整体业绩]: 子公司天泰荣观因房地产下行持续亏损，报告期内停止生产并产生一次性安置费用，全年亏损1237.66万元，直接侵蚀利润。
- **[镁业科技盈利改善]** -> [核心利润支柱]: 受益于镁合金价格低位及轻量化需求增长，镁业科技营收增长11.24%，毛利率提升4.67个百分点，净利润同比增长131.69%，成为公司主要利润来源。
- **[经营现金流大幅转正]** -> [回款质量改善]: 并表鑫源农机后，公司经营活动现金流净额由负转正，达1.07亿元，主要系子公司回款情况较好，显示业务造血能力增强。
- **[越南基地投产]** -> [规避贸易壁垒与同业竞争]: 投资约5000万元建设越南生产基地，旨在满足海外市场需求，同时将关联方鑫源汽车的通机业务转移至此，解决了同业竞争问题。
- **[定增融资计划]** -> [支撑镁合金产能升级]: 公司计划通过小额快速融资，将募集资金用于镁合金产线升级，旨在从单一部件供应商向全品类轻量化方案提供商转型，是未来增长的关键驱动力。

## 风险警告
**核心风险在于战略转型的“青黄不接”。** 公司通过并购鑫源农机实现了营收规模的跨越式增长，但并表带来的评估增值摊销、为智能化转型而激增的研发投入，以及关停亏损业务的一次性损失，共同导致公司陷入“增收不增利”的困境。2025年归母净利润亏损447.54万元，且母公司未分配利润为负，短期内无法分红。若新研发的智能农机、割草机器人等产品无法快速实现产业化并贡献利润，公司将持续面临盈利压力。

**另一重大风险来自原材料价格波动与市场竞争。** 公司主营业务成本中直接材料占比高达近90%，镁合金、钢材等价格波动对毛利率影响巨大。同时，农机行业同质化竞争激烈，价格战压力大；镁合金轻量化领域参与者增多。若公司不能持续保持技术、成本和渠道优势，市场份额和盈利能力可能下滑。此外，海外收入占比较高，地缘政治、贸易壁垒及汇率波动也是不可忽视的外部风险。
