# 603997.SH 深度透视

## 因果逻辑链
- **[乘用车座椅业务规模效应显现]** -> [归母净利润扭亏为盈]: 座椅业务营收增长80.68%至56.19亿元，实现归母净利润1.01亿元，规模效应叠加降本措施推动整体盈利大幅改善。
- **[格拉默全方位降本增效]** -> [海外分部扭亏]: 通过裁员、降薪、成立全球采购中心、向客户提价等措施，格拉默实现归母净利润1.78亿元（去年同期-6.25亿元），驱动集团整体利润转正。
- **[在手订单持续积累]** -> [未来收入确定性增强]: 截至2025年末，乘用车座椅累计27个定点项目，全生命周期总销售额预计超千亿元，为未来规模经济创造条件。
- **[原材料成本控制与自制率提升]** -> [毛利率创近5年新高]: 公司毛利率提升2.05个百分点至16.09%，得益于采购协同、增加零部件自制率及生产流程优化。
- **[管理费用大幅压降]** -> [费用率显著优化]: 管理费用同比下降19.06%，费用率降低1.98个百分点至7.48%，主要源于组织架构调整、精简流程及人员效率提升。
- **[经营现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额同比增长549.19%至17.50亿元，反映盈利质量改善和营运效率提升。
- **[国内收入增长与海外收入下滑]** -> [业务结构区域分化]: 国内收入同比增长24.83%，而海外收入同比下降13.12%（剔除TMD出售影响），显示增长动能主要来自中国市场。

## 风险警告
**核心风险在于乘用车座椅业务的高增长能否持续，以及格拉默海外整合的脆弱性。** 座椅业务虽已扭亏，但毛利率仅12.63%，且在手订单转化为稳定收入需依赖客户车型销量、量产节奏及成本控制，任何环节的延迟或客户销量不及预期都将冲击盈利。同时，格拉默海外业务虽扭亏，但欧洲区仍面临人力成本、工厂效率及客户提价谈判的不确定性，整合成果的可持续性有待验证。

**财务杠杆与汇率波动构成双重压力。** 公司担保总额占净资产比例高达123.03%，且长期借款55.57亿元，财务费用3.27亿元，高负债运营下利息支出对利润侵蚀显著。此外，公司超40%资产在境外，汇率波动导致的外币报表折算差异及远期外汇合约损失（报告期损失5067万元）将持续扰动财务数据稳定性。
