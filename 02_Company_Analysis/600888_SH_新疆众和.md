# 600888.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧，产品加工费承压]** -> [毛利率全面下滑]: 电子新材料、合金产品、铝制品三大业务毛利率分别下降3.46、0.68、2.37个百分点，直接导致主营业务盈利能力减弱。
- **[参股公司天池能源净利润下降]** -> [投资收益大幅减少41.15%]: 公司对联营企业投资收益从7.12亿降至4.22亿，是利润总额下降44.63%的核心拖累项。
- **[年产240万吨氧化铝项目大规模建设]** -> [投资活动现金流净流出36.03亿]: 项目建设支出导致投资现金流由正转负，同比恶化735.46%，公司进入重资本投入期。
- **[氧化铝项目投运前储备原材料]** -> [经营活动现金流净额下降45.64%]: 为项目备货铝土矿等原材料，占用了大量营运资金，导致经营现金流降至3.73亿。
- **[电极箔产品量价齐跌]** -> [电极箔营收下降18.49%，毛利率仅1.42%]: 园区废水处理标准提高导致成本上升、产量下降，叠加市场竞争加剧，该业务几乎无利可图。
- **[高纯铝、电子铝箔产能扩张]** -> [产销量逆势增长]: 高纯铝外销量增长33.94%，电子铝箔外销量增长25.78%，以量补价，支撑了营收7.83%的增长。
- **[产业链一体化战略延伸至氧化铝]** -> [资产结构剧变]: 在建工程从2.77亿飙升至37.82亿，长期借款从4.27亿增至38.65亿，公司正从铝加工向资源端重资产转型。

## 风险警告
**核心风险：氧化铝项目投产前的“双杀”困境。** 公司正处于新旧动能转换的阵痛期：老业务（电极箔、合金等）因行业竞争加剧，毛利率持续压缩，盈利能力显著下滑；新业务（年产240万吨氧化铝）尚在建设期（进度75%），不仅无法贡献利润，反而通过巨额资本开支（项目总投资67.8亿）和原材料储备，严重侵蚀了公司的现金流和资产负债表。2025年净利润腰斩、经营现金流锐减，正是这一“青黄不接”阶段的直接体现。若氧化铝项目投产后市场环境恶化或达产不及预期，公司将面临资产减值与财务费用高企的双重压力。

**次要风险：关联交易与单一客户依赖。** 公司控股股东为特变电工，前五大客户中关联方销售额占比10.21%，前五大供应商中关联方采购额占比8.42%。同时，公司投资收益高度依赖参股公司天池能源（煤炭业务），其利润波动直接传导至公司业绩。这种复杂的关联关系和利润结构，使得公司业绩的透明度和独立性存疑，外部投资者难以准确评估其真实经营质量。
