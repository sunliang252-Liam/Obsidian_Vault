# 605111.SH 深度透视

## 因果逻辑链
- **[产品结构升级与新兴市场突破]** -> [营收微增2.66%]: SGT-MOSFET（+46.3%营收占比）与IGBT（第七代量产）在AI服务器、汽车电子、机器人等高端领域放量，对冲了Trench-MOSFET在消费电子领域的激烈价格战。
- **[代工成本上涨与价格竞争加剧]** -> [净利润下滑9.42%]: 上游代工厂稼动率提升导致成本上涨，同时国内中低端产品同质化严重引发价格战，毛利率承压，利润增速远低于营收。
- **[全球化战略落地]** -> [境外收入增长25.94%]: 新加坡研发及销售中心投入运营，成功拓展东南亚、欧洲市场，海外营收占比提升，打开第二增长曲线。
- **[研发投入持续加码]** -> [技术壁垒巩固]: 研发费用增长13.69%，第七代/第八代IGBT、第三代SGT-MOSFET及SiC MOSFET平台量产或验证，产品电压覆盖12V-1700V，型号超4000款。
- **[产业链垂直整合]** -> [自主可控能力增强]: 子公司电基集成（封测）和金兰半导体（功率模块）产线建成，降低对外部封测依赖，提升产品定制化与响应速度。
- **[下游需求结构性复苏]** -> [库存加速消化]: 光伏储能、AI算力、无人机等新兴领域需求爆发，推动公司库存周转，部分产品（如Trench-MOSFET）出现供不应求。
- **[客户结构优化]** -> [头部客户深度绑定]: 成功导入比亚迪、阳光电源、宇树科技等头部Tier1及车企，车规级产品出货量突破2亿颗，品牌壁垒提升。

## 风险警告
**核心风险在于“增收不增利”的困境能否逆转。** 公司营收增长主要依赖SGT-MOSFET等高端产品放量，但国内中低端功率器件价格战激烈，叠加代工成本上涨，导致毛利率持续承压。若行业竞争进一步加剧或下游需求复苏不及预期，公司盈利能力可能继续下滑。

**供应商高度集中构成供应链脆弱性。** 公司芯片代工严重依赖华虹宏力（采购额占比超55%），若其产能紧张或合作关系生变，将直接威胁产品交付。同时，募投项目（SiC/GaN、功率模块）延期至2027年，新增固定资产折旧将侵蚀利润，若市场拓展不顺，存在资产减值风险。
