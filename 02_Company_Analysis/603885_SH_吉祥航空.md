# 603885.SH 深度透视

## 因果逻辑链
- **[国际航线大幅扩张]** -> [收入结构优化]: 国际运力(ASK)同比增长37.57%，国际客运收入同比增长39.49%，有效对冲国内运力收缩(-7.54%)带来的增长压力。
- **[航油成本下降]** -> [成本压力缓解]: 航油消耗成本同比下降5.76%，占主营业务成本比重从36.44%降至33.11%，在营收仅增1.83%背景下支撑利润增长。
- **[双品牌差异化定位]** -> [客座率提升]: 吉祥航空(全服务)与九元航空(低成本)分别锁定中高端与价格敏感客群，整体客座率提升1.01个百分点至85.63%，九元航空客座率高达90.74%。
- **[财务费用大幅下降]** -> [利润增厚]: 财务费用同比减少29.51%，主要得益于利率下行及债务结构优化，直接贡献利润增量约4.32亿元。
- **[其他权益工具投资公允价值上升]** -> [净资产增厚]: 持有的中国东航等股票公允价值上升，其他权益工具投资期末余额达75.31亿元，同比增63.96%，推动净资产增长36.46%。
- **[高分红+回购]** -> [股东回报强化]: 现金分红与回购合计占净利润85.93%，体现公司现金流改善及回馈股东意愿，增强市场信心。
- **[机队年轻化与统一机型]** -> [成本控制优势]: 平均机龄8.08年，A320/B737/B787统一机型降低维修、培训及燃油成本，单位扣油营业成本虽上升9.52%但仍具竞争力。

## 风险警告
**核心风险在于高杠杆运营下的利率与汇率双重敞口。** 公司合并口径带息债务约356亿元，其中美元债务约7.11亿美元。若人民币对美元贬值1%，净利润将减少约2,074万元；若浮动利率上升100个基点，净利润将减少约1.52亿元。在美联储降息路径不确定、人民币汇率波动加剧的背景下，财务费用存在反弹风险，可能侵蚀利润。

**航油成本波动与宏观经济下行构成业绩双杀。** 航油占主营业务成本33.11%，敏感性测算显示油价每波动5%，净利润影响约2.43亿元。2026年初地缘政治已引发油价大幅波动。同时，航空运输业与宏观经济景气度高度相关，若国内经济复苏不及预期或国际经贸关系紧张，客货运需求将承压，公司国际航线扩张的增量可能被需求萎缩抵消。
