# 000586.SZ 深度透视

## 因果逻辑链
- **电网投资高景气** -> **在线监测产品营收增长34.86%**: 国家电网、南方电网等核心客户加大新型电力系统建设投入，带动公司在线监测装置需求显著提升。
- **客户高度集中** -> **营收增长但利润承压**: 前五大客户占营收63.81%，其中国家电网一家占42.32%，议价能力弱导致毛利率提升空间有限。
- **新业务初期亏损** -> **拖累整体净利润**: 2025年7月新设子公司源丰光电（车载模组）处于起步阶段，营收1240万但毛利率-16.65%，净亏损496万。
- **信用与资产减值扩大** -> **侵蚀利润**: 应收账款随营收增长而增加，信用减值损失同比扩大265%，存货跌价准备同比增加39%，合计减值约709万元。
- **费用刚性增长** -> **利润空间被压缩**: 销售费用、管理费用同比均增长约22%，增速与营收增速基本持平，但远高于净利润改善幅度。
- **经营现金流改善** -> **但利润质量仍弱**: 经营活动现金流净额由负转正至3413万元，但净利润仍为负，主要因应收账款和存货占用资金问题尚未根本解决。
- **控制权不稳** -> **定增方案推进**: 公司无控股股东，第二大股东蕙富骐骥持股13.75%全部被司法冻结，董事长拟通过定增取得控制权，以稳定公司治理。

## 风险警告
**核心风险在于公司盈利能力的脆弱性。** 尽管营收增长21.4%，但扣非净利润仍亏损368万元，连续两年亏损。新业务车载模组毛利率为-16.65%，处于严重亏损状态，短期内难以成为利润增长点。同时，信用减值损失和资产减值损失合计超700万元，反映出下游回款压力与存货管理风险。

**公司治理与控制权风险突出。** 公司处于无控股股东、无实际控制人状态，第二大股东蕙富骐骥所持13.75%股份全部被司法冻结，后续将被拍卖，可能引发控制权动荡。董事长拟通过定增取得控制权，但方案尚需深交所审核及证监会注册，存在重大不确定性。母公司未分配利润为-1.33亿元，短期内无法现金分红。
