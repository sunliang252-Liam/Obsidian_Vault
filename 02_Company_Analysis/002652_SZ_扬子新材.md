# 002652.SZ 深度透视

## 因果逻辑链
- **[主营业务毛利率极低]** -> [净利润亏损]: 有机涂层板毛利率仅4.93%，扣非净利润连续三年为负，主业造血能力严重不足。
- **[历史资金占用与投资失败]** -> [巨额坏账与减值]: 前高管胡卫林资金占用、滨南股份投资失败，导致大额应收款计提坏账，并引发子公司苏州涧松持有的金融资产减值504万元。
- **[非经常性损益依赖消失]** -> [归母净利润由盈转亏]: 2024年靠非经常性损益（公允价值变动、坏账转回）实现盈利，2025年此类收益大幅减少，导致归母净利润暴跌504%。
- **[下游需求结构化分化]** -> [营收萎缩]: 传统建筑领域需求萎缩，公司未能充分抓住光伏、新能源、算力等新增长极，导致营收同比下降3.65%。
- **[子公司投资亏损]** -> [合并报表拖累]: 子公司苏州涧松因持有其他非流动金融资产公允价值变动，产生504万元亏损，直接侵蚀母公司利润。
- **[现金流恶化]** -> [经营风险上升]: 经营活动现金流净额同比锐减81.95%，主因销售回款减少，显示公司对下游议价能力弱，资金周转压力加大。
- **[研发投入极低]** -> [长期竞争力存疑]: 研发费用仅占营收0.34%，研发人员仅3人，缺乏新产品迭代能力，难以在高端市场建立壁垒。

## 风险警告
**核心风险在于主业羸弱与历史包袱的叠加。** 公司有机涂层板业务毛利率不足5%，处于微利甚至亏损边缘，且营收持续下滑，表明其在激烈竞争中缺乏定价权与成本控制能力。同时，前高管资金占用及滨南股份投资失败导致的巨额应收款（约3075万元）虽已仲裁胜诉，但执行存在不确定性，若无法收回将直接冲击净资产。

**第二重风险是战略迷失与治理隐患。** 公司提出“双主业”转型，但报告期内未见实质动作，研发投入极低，缺乏新增长点。控股股东中民投股权结构分散、无实际控制人，且公司多名董事、高管在中民投体系内任职，关联交易及内部人控制风险不容忽视。此外，母公司未分配利润巨额亏损（-3.24亿元），已不具备分红能力，长期股东回报堪忧。
