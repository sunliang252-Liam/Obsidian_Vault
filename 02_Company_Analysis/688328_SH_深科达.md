- **[显示面板行业复苏]** -> [平板显示模组设备收入增长81.48%]: 超声波指纹、电子纸、智能眼镜等细分需求释放，公司紧抓机遇，深化与京东方等大客户合作，订单大幅增长。
- **[半导体分选机产品获市场认可]** -> [半导体设备收入增长13.04%]: 转塔式分选机保持优势，平移式分选机实现批量销售，获得长电科技、华天科技等头部封测客户认可。
- **[聚焦优质客户与控费提效]** -> [销售费用下降7.42%，综合毛利率提升5.94个百分点]: 优化客户结构，前五大客户收入占比提升至36.56%，减少中小客户投入，实现营收增长与费用优化。
- **[强化应收账款全流程管控]** -> [信用减值损失大幅减少，经营活动现金流净额增长1128.89%]: 加强回款管理，促进长账龄应收账款回笼，直接增厚利润并改善现金流。
- **[剥离亏损子公司]** -> [合并报表范围调整，总资产下降9.22%]: 转让深极致、明测股权，减少亏损资产拖累，优化资源配置。
- **[实施股权激励计划]** -> [确认股份支付费用，短期压制净利润]: 2025年实施限制性股票激励计划，确认股份支付费用400.26万元，对当期净利润产生负面影响。
- **[收购子公司少数股权]** -> [产生超额业绩奖励与股份支付费用]: 收购深科达半导体、线马科技少数股权，确认以现金结算的股份支付及超额业绩奖励费用，合计减少净利润约856.66万元。
- **[境外市场拓展]** -> [出口业务收入增长344.04%]: 以智能眼镜设备切入北美市场，与META、西部数据建立合作，海外业务成为新增长极。

## 风险警告
**核心风险在于下游需求波动与竞争加剧。** 公司深度绑定消费电子与半导体行业，下游技术迭代快、周期性强。若宏观经济走弱或终端需求疲软，将直接导致设备订单收缩。同时，海外龙头与本土新锐企业双重夹击，若公司无法持续推出高性价比新品，市场份额与定价能力将受冲击。

**财务风险集中于应收账款与存货管理。** 报告期末应收账款与存货账面价值合计超6亿元，占总资产比重超40%。尽管公司已加强回款，但若客户经营恶化或市场需求变化，坏账与存货跌价风险将显著侵蚀利润。此外，公司为收购子公司少数股权及实施股权激励，已产生较大非经常性费用，未来若业绩承诺不达标，商誉减值风险不容忽视。
