# 603139.SH 深度透视

## 因果逻辑链
- **[控股子公司陕西友帮停产及预重整]** -> [归母净利润巨亏3.33亿元]: 陕西友帮全面停产并申请预重整，公司对其借款计提坏账及确认经营亏损，合计影响约2.41亿元，是当期亏损主因。
- **[控制权变更，新实控人入主]** -> [战略转向“医药固本、多元协同”]: 原控股股东转让22%股权给悦合智创，李红明、王雪芳夫妇成为新实控人，推动剥离亏损资产并探索智慧医疗等新业务。
- **[新建生产基地投产，老厂停产]** -> [短期运营成本高企，拖累母公司业绩]: 新建智能工厂与三个老基地同步运行，产品转移阶段导致整体运营成本占比偏高，母公司虽销量上升但收入下降约5%。
- **[医药流通业务收入大幅下滑]** -> [整体营收同比下降16.09%]: 子公司方元医药、新高新药业的药品批发配送收入减少34.78%，是营收下降的核心拖累项。
- **[中成药集采政策深化]** -> [产品价格承压，渠道结构被迫调整]: 公司主要品种虽未纳入集采，但为应对未来竞价，需控制成本并大力发展零售、基层及互联网渠道，销售策略发生转变。
- **[计提大额资产减值及信用减值]** -> [非经常性损益加剧亏损]: 报告期内计提资产减值损失1.95亿元（含固定资产、无形资产减值）及信用减值损失0.21亿元，合计超2亿元，严重侵蚀利润。
- **[研发投入聚焦院内制剂与经典名方]** -> [研发费用同比增长46.13%]: 公司加大院内制剂及中药大健康产品研发，依托“陕西省中药创新共性技术研发平台”进行技术储备，但短期难以转化为收入。

## 风险警告
公司当前最大风险在于**子公司失控与资产减值黑洞**。控股子公司陕西友帮已全面停产并申请预重整，能否重整成功存在极大不确定性，若最终破产清算，公司对其的股权投资及债权将面临全部损失的风险。同时，公司已对固定资产、无形资产及商誉计提了巨额减值，但若未来经营环境持续恶化，仍存在进一步减值的可能，这将持续侵蚀净资产。

其次，**新实控人战略转型的执行风险**不容忽视。新控股股东悦合智创及其背后的李红明夫妇，核心产业背景为数据中心与互联网（亿安天下），与公司传统中药主业协同性较弱。“医药固本、多元协同”战略中，向智慧医疗等新领域的拓展尚处早期，能否成功孵化新利润增长点、有效整合资源并化解历史包袱，存在较大不确定性。此外，公司为陕西友帮提供的担保存在连带清偿风险，若友帮预重整失败，公司需承担相应担保责任。
