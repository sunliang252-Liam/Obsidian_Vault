# 000595.SZ 深度透视

## 因果逻辑链
- **[重大资产重组完成，主业切换]** -> [归母净利润扭亏为盈]: 公司于2025年7月完成重大资产重组，置出亏损的轴承业务，置入盈利能力强的新能源发电资产（电投新能源），使主营业务从传统制造彻底转向风光储运营，实现归母净利润从-1.07亿跃升至+0.83亿。
- **[装机容量爆发式增长]** -> [发电量与营收大幅提升]: 2025年新投运214.18万千瓦新能源项目，总装机容量从67.85万千瓦激增至282.03万千瓦，直接驱动发电量同比增长106.58%，电力行业收入同比增长35.90%。
- **[光伏业务成为增长主引擎]** -> [收入结构优化]: 光伏发电业务收入同比增长112.77%，占电力收入比重从30.5%提升至47.8%，成为公司最大的收入来源，弥补了风电业务的停滞。
- **[非经常性损益贡献巨额利润]** -> [扣非净利润仍为亏损]: 公司2025年归母净利润为0.83亿，但扣非净利润为-0.70亿。盈利主要依赖资产处置收益（老厂区房产土地处置获利1.08亿）和同一控制下企业合并产生的子公司期初至合并日净损益（0.47亿），主业盈利能力尚待验证。
- **[高杠杆扩张，财务费用激增]** -> [侵蚀利润]: 为支撑大规模项目投资，公司借款大幅增加，导致财务费用从0.96亿攀升至1.33亿，同比增长38.70%，高负债运营模式对利润形成显著压力。
- **[电力市场化交易深化]** -> [平均上网电价承压]: 公司参与市场交易电量占总上网电量的94.15%，平均上网电价（含税）从2024年的26.62元/亿千瓦时下降至21.23元/亿千瓦时，电价下行风险是未来盈利能力的核心不确定因素。
- **[经营活动现金流强劲]** -> [盈利质量改善]: 经营活动现金流净额达6.28亿，同比增长221.10%，远超净利润水平，主要得益于电费补贴回收及新项目投产带来的现金流入，现金流状况显著优于账面利润。

## 风险警告
**核心风险在于盈利的“含金量”与可持续性。** 公司2025年归母净利润扭亏为盈，但扣非净利润仍为亏损，盈利高度依赖资产处置等非经常性损益。主业新能源发电虽营收增长，但平均上网电价因市场化交易深化而显著下滑，叠加财务费用因大规模举债扩张而激增，严重侵蚀了利润空间。公司本质上仍处于“增收不增利”的转型阵痛期，若电价持续下行或补贴回款滞后，现金流压力将迅速放大。

**另一重大风险是控股股东同业竞争承诺的履行与潜在的利益冲突。** 控股股东宁国运虽承诺将部分新能源项目托管或注入上市公司，但托管费用仅为100万元/年，且注入条件（如项目盈利为正、产权清晰）存在较大不确定性。这意味着大量优质新能源资产仍在体外循环，上市公司并未充分享受宁夏新能源发展的红利，且未来资产注入的定价和时机可能损害中小股东利益。
