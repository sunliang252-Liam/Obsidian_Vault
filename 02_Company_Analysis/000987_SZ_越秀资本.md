# 000987.SZ 深度透视

## 因果逻辑链
- **[新能源业务高速增长]** -> [营收结构质变]: 新能源电费收入46.44亿元（+51.3%），占总营收比升至59.21%，首次超越传统融资租赁成为第一大收入来源。
- **[战略投资中信证券]** -> [利润核心支柱]: 持有中信证券8.54%股权，按权益法确认投资收益25.20亿元，占归母净利润的71.6%，是业绩稳定器。
- **[非经常性损益大幅增厚]** -> [归母净利润暴增53.42%]: 子公司取得联营企业（北京控股、越秀地产、新天绿色能源）的投资成本小于公允价值，产生非经常性收益28.17亿元，是利润超预期增长的主因。
- **[融资成本压降]** -> [财务费用改善]: 期末融资成本较年初下降37个BP，有效对冲了新能源业务扩张带来的利息支出增加。
- **[投行化转型]** -> [广州资产扭亏为盈]: 广州资产从传统清收转向上市公司纾困、破产重整等投行业务，全年实现净利润1.41亿元，成功扭亏。
- **[户用光伏规模效应]** -> [绿色资产运营成熟]: 控股户用分布式光伏装机12.99GW，累计安装40万座，发电量136.65亿度，形成稳定且持续增长的现金牛业务。
- **[信用减值损失扩大]** -> [利润质量承压]: 信用减值损失同比激增342.5%至16.49亿元，主要来自债权投资计提，侵蚀了核心业务利润。

## 风险警告
**1. 利润结构高度依赖非经常性损益与投资收益，可持续性存疑。** 2025年归母净利润35.19亿元中，非经常性损益高达17.07亿元（主要来自联营企业股权投资成本低于公允价值的一次性收益），而核心的扣非净利润仅18.12亿元，同比增长24.19%。更关键的是，对中信证券的权益法投资收益（25.20亿元）贡献了超七成利润，一旦中信证券业绩波动或公司减持股份，利润将面临剧烈震荡。这种“投资收益+非经常性损益”的利润模式，掩盖了主营业务盈利能力的真实水平。

**2. 新能源业务“增收不增利”与信用风险双升。** 新能源业务收入虽增长51.3%，但营业成本同步增长52.87%，毛利率仅微降0.49个百分点，显示该业务尚处于“以规模换收入”阶段，盈利能力并未同步提升。同时，公司信用减值损失暴增至16.49亿元，主要来自债权投资，表明在经济下行周期中，融资租赁及不良资产处置业务的资产质量承压，坏账风险正在加速暴露。
