# 688100.SH 深度透视

## 因果逻辑链
- **[“双碳”与新型电力系统建设]** -> [电网投资持续高增]: 国家电网“十五五”4万亿投资（+40%）、南方电网投资连创新高，直接拉动公司核心产品（电监测终端、通信网关）在国/南网招标中份额领先。
- **[海外产能与市场拓展]** -> [境外收入高增34%]: 印尼工厂投产、沙特技术中心启用，叠加产品通过OIML/MID/WRAS等国际认证，推动境外收入占比升至19.06%，成为第二增长曲线。
- **[“物联网+芯片+AI”三位一体]** -> [技术壁垒与产品溢价]: 自研双模通信芯片、Wi-SUN芯片覆盖全球70%+国家AMI标准，AI相关产品收入7.37亿元（占主营24%），支撑毛利率稳定在39.88%。
- **[新签订单与在手合同高增]** -> [未来收入确定性]: 2025年新签订单37.08亿元，年末在手合同40.59亿元，为后续业绩持续增长提供坚实保障。
- **[高分红+回购注销]** -> [股东回报与估值支撑]: 2025年分红+回购合计4.18亿元，占净利润62.75%，上市以来累计回报15.29亿元（为IPO募资净额2.5倍），强化长期投资价值。
- **[智慧水务政策与市场爆发]** -> [水气热传感终端高增19.39%]: 国家2200亿“两重”投资支持供排水管网改造，叠加全球智慧水务市场CAGR 9.62%，推动公司水气热传感终端收入快速增长。

## 风险警告
**核心风险在于应收账款高企与海外经营不确定性。** 2025年末应收账款高达25.25亿元，占总资产44.38%，同比增长42.18%，远超营收增速（8.48%）。尽管客户以国/南网等央企为主，但若宏观经济下行或客户付款周期延长，将显著占用营运资金，并可能引发坏账风险，侵蚀利润。

**海外业务虽增长迅猛，但面临地缘政治、汇率波动及本地化运营挑战。** 公司境外收入占比已近20%，且印尼、沙特等新兴市场存在政策变动、文化差异及供应链管理风险。同时，人民币汇率波动已导致2025年财务费用由正转负（-438万元），未来若汇率持续不利，将直接冲击海外利润。此外，物联网行业技术迭代快，若公司AI芯片或通信技术研发落后，可能丧失先发优势。
