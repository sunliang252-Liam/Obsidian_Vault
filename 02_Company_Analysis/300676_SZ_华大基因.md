# 300676.SZ 深度透视

## 因果逻辑链
- **集采政策与价格竞争** -> **营收下滑**: 无创产前基因检测等核心产品受集采降价和市场竞争加剧影响，基础版产品价格下降，导致生育健康业务营收同比大幅下降28.06%。
- **客户回款周期延长** -> **信用减值损失激增**: 部分客户回款周期延长，导致2025年度计提的信用减值损失较上年同期大幅增长，成为亏损的重要原因。
- **战略调整与资产减值** -> **阶段性亏损**: 为优化资源配置，对部分交付中心进行战略调整并向低成本地区转移，基于谨慎性原则计提资产减值准备，导致经营业绩出现阶段性亏损。
- **样本外送监管趋严** -> **业务模式转型**: 行业政策规范检测样本外送，驱动公司从独立医学实验室（ICL）模式向院内本地化体外诊断（IVD）模式转型，推动精准医学检测综合解决方案营收同比增长19.45%。
- **智能化与本地化解决方案** -> **院内市场拓展**: SIRO高通量基因检测本地化医学解决方案和OmicsOne智能分析平台，通过“样本进、报告出”的一站式服务，降低了医院开展基因检测的门槛，成为业务增长新引擎。
- **海外本地化运营** -> **新兴市场增长**: 在泰国、沙特等“一带一路”国家通过技术转移和共建实验室深化本地化运营，拉美、南亚等新兴市场营收实现翻倍增长，有效对冲了国内市场的部分压力。
- **C端健康管理布局** -> **新增长极探索**: 发布“i99智健”多组学健康管理系统，布局从单一检测向全生命周期健康管理闭环转型，旨在开辟第二增长曲线，但目前仍处于早期投入阶段。

## 风险警告
华大基因正面临核心业务（NIPT）增长天花板与价格战的双重挤压。集采政策导致产品价格大幅下降，生育健康业务营收显著萎缩，而成本端因资产减值与信用减值损失高企，导致公司连续两年录得巨额亏损。尽管精准医学综合解决方案和海外业务增长亮眼，但尚不足以弥补主力业务的缺口，公司盈利能力恢复存在较大不确定性。

公司对关联方（华大智造）的采购依赖度极高（占采购总额31.76%），供应链自主可控性存疑。同时，基因检测行业监管政策趋严，样本外送管理规范化和集采扩面，将持续压缩公司传统服务模式的利润空间。若公司无法通过技术创新（如全基因组测序、多组学）和模式转型（如本地化解决方案、C端健康管理）快速构建新的护城河，将面临市场份额被侵蚀和持续亏损的风险。
