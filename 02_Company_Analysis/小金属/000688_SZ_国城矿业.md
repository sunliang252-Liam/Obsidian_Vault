# 000688.SZ 深度透视

## 因果逻辑链
- **[收购国城实业60%股权]** -> [归母净利润暴增138%]: 同一控制下企业合并，国城实业2025年贡献净利润11.46亿元，按60%股权计算增加归母净利润6.88亿元，是利润暴增的核心来源。
- **[出售宇邦矿业65%股权]** -> [确认投资收益7.76亿元]: 非经常性损益中的大头，直接导致扣非净利润为负（-2.57亿元），揭示了公司主业盈利能力与账面利润的巨大鸿沟。
- **[钼精矿价格高位震荡]** -> [钼精矿业务毛利率高达70.33%]: 国城实业大苏计钼矿品位高、成本相对固定，在钼价站稳3500元/吨度中枢的背景下，成为公司最稳定的利润压舱石。
- **[钛白粉市场周期性调整]** -> [钛白粉业务毛利率为-8.67%]: 国城钛业产能释放但遭遇行业价格下行，成本高于售价，导致该业务亏损，拖累整体盈利质量。
- **[国城锂业20万吨/年锂盐项目基建投入]** -> [在建工程同比增长74%]: 公司正全力押注新能源产业链，大量资金沉淀于在建工程，短期无法贡献现金流和利润，增加了财务压力。
- **[可转债转股及并购贷款增加]** -> [资产负债率飙升至69.55%]: 为收购国城实业和推进锂盐项目，公司大幅增加长期借款，财务杠杆显著提升，利息费用同比增长20.2%。
- **[扣非净利润连续两年为负]** -> [主业造血能力存疑]: 剔除资产出售和合并带来的非经常性收益后，公司有色金属采选及化工主业实际处于亏损状态，盈利高度依赖资本运作。

## 风险警告
**核心风险：盈利质量极差，主业持续失血。** 公司2025年归母净利润高达10.76亿元，但扣除非经常性损益后净亏损2.57亿元，且已连续两年为负。利润的绝大部分来自出售宇邦矿业股权（7.76亿）和同一控制下合并国城实业（6.88亿）的一次性收益。剔除这些“财技”操作，公司核心的有色金属采选（除钼矿外）及钛白粉业务均面临价格下行或成本倒挂的压力，缺乏可持续的内生增长动力。

**财务风险：高杠杆扩张，现金流紧绷。** 为收购国城实业和建设锂盐项目，公司资产负债率从55.93%骤升至69.55%，短期借款和长期借款均大幅增加。尽管经营活动现金流净额因销售增长而改善，但筹资活动现金流净流出高达15.55亿元，主要用于支付收购对价。公司正处于“大举投资-尚未回报”的阵痛期，若未来锂盐项目投产不及预期或金属价格下跌，高额债务将带来巨大的偿债压力。
