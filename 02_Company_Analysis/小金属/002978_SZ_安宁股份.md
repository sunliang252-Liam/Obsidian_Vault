# 002978.SZ 深度透视

## 因果逻辑链
- **[并购经质矿产]** -> [总资产暴增77.43%，资产负债率升至48.54%]: 以65.08亿元现金收购经质矿产100%股权，新增1.13亿吨矿石资源量，但导致总负债从9.49亿飙升至81.76亿，财务杠杆急剧放大。
- **[钛精矿价格下跌]** -> [净利润下降15.46%]: 钛精矿全年均价下跌，导致该产品收入同比降15.45%，尽管销量持平，但毛利率从75.92%降至71.53%，侵蚀利润。
- **[钒钛铁精矿量价齐升]** -> [收入增长32.83%]: 61%品位钒钛铁精矿销量增26.37%，且价格维持在700元/吨以上景气区间，毛利率提升11.10个百分点至55.12%，成为业绩核心支撑。
- **[钛材项目资本开支激增]** -> [投资活动现金流净流出69.6亿元]: “年产6万吨能源级钛（合金）材料全产业链项目”建设投入及并购支出，导致投资现金流出同比增400%，自由现金流大幅转负。
- **[银团贷款与定增]** -> [筹资活动现金流净流入39.3亿元]: 为支撑钛材项目及并购，公司通过银团长期借款（37.09亿）和定增（17.04亿）大规模融资，财务费用由负转正（利息支出增加）。
- **[综合利用产品放量]** -> [收入增长169.13%]: 2024年下半年新增的尾矿综合利用产品（TiO2品位42%）在2025年实现规模化销售，成为新的收入增长点。
- **[管理费用激增56%]** -> [侵蚀利润]: 并购经质矿产后，其尚未复产的折旧摊销、中介费用及员工薪酬计入管理费用，导致费用从1.08亿升至1.68亿。

## 风险警告
**核心风险在于“双线作战”下的现金流与债务压力。** 公司同时推进65亿并购和百亿级钛材项目，总资产虽暴增，但资产负债率从5.91%飙升至48.54%，有息负债（短期+长期）从4.16亿激增至41.84亿。2025年投资活动现金净流出高达69.6亿元，而经营活动现金流仅11.86亿，巨大的资本开支缺口完全依赖融资填补。若钛材项目投产不及预期或钛精矿价格持续低迷，公司将面临严峻的偿债压力。

**并购整合与钛材项目投产的双重不确定性。** 经质矿产（小黑箐铁矿）目前仍处于停产状态，其复工复产及产能扩建（从260万吨/年扩产）存在时间与成本风险。同时，钛材项目已延期至2026年上半年试生产，作为公司从资源端向深加工转型的关键一步，其技术消化、市场开拓及成本控制均面临挑战。若两大项目任一环节受阻，将严重拖累公司盈利能力和资产负债表修复进程。
