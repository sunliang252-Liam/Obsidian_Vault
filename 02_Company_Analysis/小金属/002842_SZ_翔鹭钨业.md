# 002842.SZ 深度透视

## 因果逻辑链
- **[钨精矿价格暴涨]** -> [业绩扭亏为盈]: 2025年钨精矿年均价同比上涨57.77%，公司作为全产业链钨制品商，成功将原材料涨价传导至下游，主要产品毛利率显著提升。
- **[硬质合金量价齐升]** -> [收入结构优化]: 硬质合金销量同比增长70.78%，收入增长93.18%，毛利率提升9.77个百分点，成为业绩增长的核心引擎。
- **[光伏钨丝产能释放]** -> [第二增长曲线]: 钨丝产量增长75.06%，销量暴增217.48%，月产能已达5亿米，正在建设年产300亿米项目，切入高景气光伏切割赛道。
- **[供给端结构性收紧]** -> [行业景气度提升]: 国家钨矿开采总量控制指标收紧，新《矿产资源法》实施，供给受限叠加战略资源价值凸显，奠定钨价高位运行基础。
- **[可转债转股完成]** -> [财务结构改善]: 2025年4月完成“翔鹭转债”提前赎回及转股，减少债务近3亿元，净资产从7.65亿跃升至12.07亿，资产负债率显著下降。
- **[预收款大幅增加]** -> [现金流显著改善]: 合同负债从355万暴增至1.83亿，预收货款模式使经营活动现金流净额达1.1亿元，同比增175.23%。
- **[原材料成本同步上涨]** -> [毛利率提升有限]: 尽管收入增长37.71%，但原材料成本占营业成本90.13%，整体毛利率仅14.36%，成本传导并非完全顺畅。

## 风险警告
**核心风险在于钨价高位不可持续与成本传导的脆弱性。** 2025年钨精矿价格年度波动幅度高达234.06%，公司业绩高度依赖价格单边上涨。一旦钨价回调，公司库存（占总资产43.08%）将面临巨额减值风险，2024年资产减值损失3128万元即为前车之鉴。同时，原材料成本占营业成本超90%，毛利率仅14.36%，价格传导存在时滞，利润对钨价波动极其敏感。

**第二增长曲线尚处培育期，存在技术替代与产能消化风险。** 光伏钨丝虽增长迅猛，但面临高碳钢丝技术反渗透的潜在威胁。年产300亿米超细钨丝项目需大量资本开支，2025年投资活动现金流净流出1.03亿元，若下游光伏需求不及预期或钨丝渗透率提升放缓，巨额产能将形成沉重负担。此外，公司研发人员数量同比减少23.49%，技术储备的持续性存疑。
