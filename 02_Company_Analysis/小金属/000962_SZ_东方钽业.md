# 000962.SZ 深度透视

## 因果逻辑链
- **[战略聚焦高附加值产品]** -> [营收与利润双增]: 公司主动调整产品结构，增加钽靶材、超导腔等高毛利产品份额，推动营收增长20.49%，净利润增长21.12%。
- **[绑定核心客户与军工市场]** -> [收入增长]: 与全球大型电容器制造商及航天科工集团建立稳定合作，前五大客户贡献42.76%营收，保障销售渠道畅通。
- **[产能扩张与技改项目落地]** -> [资产规模扩大]: 年产400支铌超导腔生产线等重大项目进入试生产或建设阶段，在建工程同比激增，总资产增长28.81%。
- **[股权激励释放管理层动能]** -> [业绩增长]: 2022年限制性股票激励计划首期解禁，核心骨干积极性提升，管理费用增长6.02%但ROE提升至9.62%。
- **[原料采购依赖关联方]** -> [供应链风险与成本压力]: 前五大供应商中关联方采购额占38.59%，原料价格波动及进口依赖压缩利润空间。
- **[研发投入聚焦“卡脖子”技术]** -> [长期竞争力]: 研发投入1.13亿元，攻克超高纯钽靶材、超导铌材等关键技术，获6项省部级科技奖，巩固技术壁垒。
- **[经营性现金流大幅转负]** -> [短期流动性压力]: 因采购支出及项目投资增加，经营活动现金流净额-3.65亿元，与净利润严重背离，需警惕资金链风险。

## 风险警告
**核心风险：现金流与利润严重背离，扩张期资金链承压。** 2025年净利润2.58亿元，但经营活动现金流净额-3.65亿元，主因是存货激增（+86%）及应收账款周转放缓。公司正处于产能扩张高峰期，在建工程同比增220%，若下游需求不及预期或回款恶化，可能引发流动性危机。

**供应链与市场双重挤压风险。** 钽铌原料高度依赖海外进口，且前五大供应商中关联方采购占比近40%，价格波动与地缘政治风险直接冲击成本。同时，行业“同质化”竞争加剧，若公司高附加值产品（如超导腔、钽靶材）放量不及预期，毛利率可能承压。

> 宁夏东方钽业股份有限公司是中色(宁夏)东方集团有限公司(以下简称“集团公司”或“中色东方”)下属控股子公司,是中国有色矿业集团有限公司成员单位。1999年4月注册成立,2000年1月在深圳证券交易所挂牌上市。东方钽业主要从事稀有金属钽、铌及合金等的研发、生产、销售和进出口业务。具有科学的管理理念、精良的工艺装备、先进的技术水平、高素质的员工队伍等综合优势,已形成钽、铌金属及其合金材料等主要产业格局。公司产品被广泛应用于电子、通讯、航空、航天、冶金、石油、化工、体育、医疗、原子能、太阳能等领域。公司行业地位稳定,具有较强的市场竞争优势。公司主导产品电容器级钽粉、钽丝在钽电容器行业有良好的质量口碑,产销量多年位居行业前列,与美国、德国、日本、韩国等国际主要钽铌电容器制造商建立了广泛的合作关系。钽、铌及其合金制品等系列产品多次荣获“对外贸易出口名牌”、“中国名牌产品”称号。公司以钽铌金属及制品的研发、生产、销售业务为核心业务,也是公司盈利能力和经济增长的主要着眼点。公司目前是国内最大的钽、铌产品生产基地、科技先导型钽、铌研究中心;是国家重点高新技术企业、国家首批创新型企业、国家863成果产业化基地、全国专利工作试点企业、博士后科研工作站和国家级企业技术中心。
