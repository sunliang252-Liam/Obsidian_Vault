# 002738.SZ 深度透视

## 因果逻辑链
- **[锂盐价格持续低迷]** -> [净利润同比大幅下降39.54%]: 2025年锂盐市场供需博弈加剧，价格中枢进一步下移并多次击穿行业边际成本线，导致公司锂电新能源原料板块虽营收微增2.22%，但整体盈利能力显著承压。
- **[自有矿山资源增储与产能扩张]** -> [保障原料自给率与成本控制]: 公司依托地勘技术优势，将Bikita矿山锂资源量从84.96万吨LCE提升至343.41万吨，并建成418万吨/年选矿产能和7.1万吨/年锂盐产能，有效对冲了外购原料价格波动风险，使锂盐业务毛利率同比提升约6个百分点。
- **[铯铷业务高毛利护城河]** -> [稳定贡献核心利润]: 公司作为全球铯铷盐龙头，控制全球主要高品质铯资源，铯铷业务毛利率高达74.07%，在锂盐周期下行期成为公司利润的“压舱石”。
- **[多金属战略布局加速]** -> [打造新增长极]: 公司收购赞比亚Kitumba铜矿（铜金属量61.40万吨）和纳米比亚Tsumeb冶炼厂（锗镓锌资源），并推进项目建设，旨在构建锂、铜、锗等多金属平台，分散单一业务周期风险。
- **[经营活动现金流大幅改善]** -> [财务结构优化]: 2025年经营活动现金流净额达16.02亿元，同比增长220.34%，主要得益于营收增长、应收账款回款加快及税收返还增加，为公司资本开支和债务偿还提供了坚实基础。
- **[套期保值业务产生较大亏损]** -> [侵蚀当期利润]: 公司为应对锂盐价格波动开展的碳酸锂期货套期保值业务，报告期内产生公允价值变动损失及投资亏损，合计对利润造成显著负面影响。
- **[管理费用激增]** -> [成本控制压力显现]: 管理费用同比大幅增长48.68%，主要因合并纳米比亚Tsumeb项目期间增加及支付较高离职补偿，显示并购整合期的管理成本上升。

## 风险警告
**核心风险在于锂盐价格持续低迷对公司盈利能力的根本性侵蚀。** 尽管公司通过自有矿山和产能扩张实现了成本优化，但2025年净利润同比暴跌近40%，表明公司业绩对锂盐价格高度敏感。若未来锂盐市场供需关系未能显著改善，价格长期在低位徘徊，公司锂电新能源板块的盈利能力将持续承压，甚至可能面临资产减值风险。

**其次，多金属战略的落地与整合存在不确定性。** 公司同时推进Kitumba铜矿、Tsumeb冶炼厂等多个大型海外项目，资本开支巨大，且面临海外运营、地缘政治、环保合规等多重挑战。项目能否按期投产、达产并实现预期收益，存在较大不确定性。同时，公司为对冲风险而进行的期货套期保值业务已产生大额亏损，暴露出公司在风险管理工具运用上的潜在风险。
