# 605007.SH 深度透视

## 因果逻辑链
- **[湖北基地产能集中释放]** -> [营收增长16.05%]: 湖北基地PM18、PM12、PM21产线投产，工业包装材料销量同比暴增236.76%，驱动总营收突破88.84亿元。
- **[成本承压与价格传导不足]** -> [净利润下滑32.36%]: 原材料成本上升叠加终端市场竞争激烈，营业成本增速（18.60%）超过营收增速（16.05%），毛利率下降1.90个百分点，利润空间被压缩。
- **[可转债利息费用化]** -> [财务费用激增36.37%]: 可转债募投项目转固后，利息由资本化转为费用化，财务费用增至1.93亿元，显著侵蚀利润。
- **[产能扩张与项目建设]** -> [投资活动现金流持续大额流出]: 60万吨化学浆、九江码头等重大项目推进，投资活动现金净流出17.96亿元，资本开支维持高位。
- **[经营现金流为负]** -> [资金链承压]: 尽管营收增长，但经营现金流净额为-0.57亿元，主要系产能扩张优化经营资金配置，但短期偿债压力（流动比率0.55）凸显。
- **[浆纸一体化战略]** -> [成本控制能力增强]: 江西基地30万吨化机浆实现食品包装纸和文化纸的浆纸平衡，有效对冲木浆价格波动，为后续60万吨化学浆项目奠定基础。
- **[研发投入与产品升级]** -> [高端化转型]: 研发人员增至545人，聚焦可降解纸基材料、高性能特种纸，适配“以纸代塑”政策，为长期盈利增长培育新动能。

## 风险警告
**核心风险在于高杠杆扩张下的现金流断裂风险。** 公司资产负债率已攀升至70.78%，流动比率仅0.55，短期偿债压力极大。2025年经营现金流为负，而资本开支（化学浆项目、码头）仍在持续，若融资环境收紧或下游回款放缓，资金链将面临严峻考验。可转债利息费用化进一步加重财务负担，侵蚀本就微薄的利润。

**行业供需失衡与价格战风险不容忽视。** 公司产能快速扩张至276万吨，但下游需求增速放缓，工业包装纸、文化纸等赛道价格竞争激烈，导致整体毛利率下滑。新增产能若无法被市场有效消化，将引发产能闲置和资产减值风险，进一步拖累盈利。公司对木浆的高依赖度（60万吨化学浆项目2027年才投产）也使其在原料价格波动中缺乏缓冲。
