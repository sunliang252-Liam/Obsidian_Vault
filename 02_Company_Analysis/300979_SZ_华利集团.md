# 300979.SZ 深度透视

## 因果逻辑链
- **新工厂投产及产能爬坡** -> 毛利率下降: 新工厂处于爬坡阶段，产能利用率较低，单位固定成本较高，拉低整体毛利率。
- **美国加征关税政策** -> 北美市场需求减少: 关税推高进口成本，最终转嫁消费者，抑制美国消费需求，导致品牌客户订单减少。
- **北美订单下滑** -> 老客户订单减少: 北美市场为主要客户所在地，关税导致需求疲软，老客户（如Nike）订单下滑。
- **新客户（Adidas、New Balance等）订单增长** -> 欧洲及其他地区收入增长: 新客户总部位于欧洲等地，其订单快速增长拉动了相应地区收入。
- **新客户订单增长** -> 收入增长（抵消老客户下滑）: 新客户订单大幅增长，弥补了老客户订单减少的影响，使总收入仍实现正增长。
- **客户多元化战略** -> 前五大客户收入占比下降: 公司主动调整客户结构，降低对单一客户依赖，新客户收入占比提升。
- **美元汇率变动** -> 财务费用增加（汇兑损失）: 汇率变动导致汇兑损益增加，财务费用同比减少幅度收窄（实际为汇兑损失增加）。
- **净利润下降** -> 绩效薪酬减少，管理费用降低: 净利润减少导致基于利润的绩效薪酬计提减少，进而降低管理费用。
- **海外新工厂投产** -> 产能利用率下降: 新工厂产能逐步释放，但订单尚未完全匹配，使得整体产能利用率下降。
- **关税政策不确定性** -> 公司增加短期借款: 为应对关税风险和资金需求，公司增加短期借款以补充流动性。

## 风险警告
深度风险总结：美国关税政策推高成本并抑制北美需求，导致核心市场收入下滑；新工厂产能爬坡拖累毛利率，叠加客户订单分化，净利润同比下降16.5%。同时，国际贸易政策不确定性高，若关税持续，可能进一步压缩订单。公司需持续优化客户结构，加速新工厂达产，并管理汇率风险。
