# 600367.SH 深度透视

## 因果逻辑链
- **[煤炭等原材料成本下降]** -> [利润总额增长19.55%]: 主要原材料煤炭采购成本下降，叠加内部降本增效，直接降低了碳酸钡、碳酸锶等核心产品的生产成本，增厚了利润。
- **[碳酸锶、硫酸钡等产品售价上涨]** -> [利润增加]: 受同行停产、下游需求变化等影响，公司适时上调部分产品售价，直接提升了产品毛利率。
- **[高附加值产品销售放量]** -> [利润结构优化]: 高纯钡盐销售量同比增加22.55%，推动了产品结构向高端化转型，提升了整体盈利水平。
- **[重庆瑞得思达6万吨/年锶盐项目投产]** -> [产能跃升与市场地位巩固]: 新项目于2026年2月试生产，将公司锶盐产能从3万吨/年提升至6万吨/年，显著增强市场议价能力和行业地位。
- **[天柱钡盐项目布局]** -> [原材料成本控制与产业链延伸]: 在贵州天柱县设立子公司，利用当地重晶石资源建设10万吨/年碳酸钡项目，旨在降低原材料采购成本，强化上游资源掌控。
- **[锰系产品需求萎缩]** -> [业绩拖累]: 下游一次电池和锰酸锂需求减弱，导致电解二氧化锰产销量同比下降27.03%，成为公司业绩的主要拖累项。
- **[资产减值损失大幅增加]** -> [侵蚀利润]: 报告期内计提固定资产减值损失4356万元，同比增加290%，主要来自对部分老旧或低效资产的减值测试，直接减少了当期利润。

## 风险警告
**核心风险在于新旧产能转换期的业绩阵痛与行业竞争加剧。** 公司当前正经历“老产能停产、新产能爬坡”的关键阶段：重庆瑞得思达新项目虽已投产，但2026年才进入试生产，短期内无法贡献利润，反而因大足红蝶停产导致锶盐业务出现空窗期。同时，锰系产品（电解二氧化锰）面临下游需求萎缩和行业“内卷”，产销量大幅下滑，短期内难以逆转。

**财务层面，公司盈利能力依然脆弱。** 尽管2025年利润总额增长，但扣非净利润仅2.3亿元，且资产减值损失高达4356万元，表明资产质量存在隐忧。此外，公司现金分红比例仅为14.70%，低于30%的常规水平，反映出管理层对未来资本开支和经营压力的审慎态度。原材料重晶石价格同比上涨31.73%，若成本压力持续，将进一步压缩利润空间。
