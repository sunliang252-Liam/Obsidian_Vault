# 688563.SH 深度透视

## 因果逻辑链
- **[行业交付节奏变化]** -> [营收下滑2.53%]: 基础材料、非航空成品件订单减少，拖累整体收入。
- **[产品结构优化]** -> [航空成品件收入增长6.84%]: 高附加值航空件需求稳定，部分对冲了基础材料下滑。
- **[利率下行与现金管理收益减少]** -> [净利润下滑8.75%]: 利息收入及理财收益减少，导致利润降幅大于营收。
- **[销售回款改善与采购支出控制]** -> [经营性现金流暴增295.81%]: 现金流大幅改善，盈利质量显著提升。
- **[收购镇江钛合金公司]** -> [提升钛合金精铸产能]: 整合关联方产能，减少关联交易，强化主业竞争力。
- **[研发投入资本化]** -> [研发费用同比下降12.14%]: 部分研发项目进入资本化阶段，短期费用压力减轻。
- **[境外市场拓展]** -> [境外收入增长18.91%]: 国际航空市场复苏，带动钛合金铸件出口订单增加。

## 风险警告
**核心风险在于业绩增长失速与盈利能力下滑。** 公司2025年营收与净利润双降，且净利润降幅（-8.75%）显著大于营收降幅（-2.53%），显示盈利能力承压。主要受行业订单交付节奏波动及非经常性收益（利息、理财）减少影响，若下游需求持续疲软或产品结构无法持续优化，业绩存在进一步下滑风险。

**另一重大风险是军品审价与客户集中度。** 公司约73%收入来自中航工业与中国航发两大集团，客户高度集中。军品定价机制存在审价不确定性，若最终审价低于暂定价，将直接冲减已确认收入。同时，国际业务面临汇率波动与地缘政治风险，可能侵蚀海外业务利润。
