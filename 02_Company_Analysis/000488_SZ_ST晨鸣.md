# 000488.SZ 深度透视

## 因果逻辑链
- **[生产基地大面积停产]** -> [营收暴跌72.78%]: 寿光、江西、吉林基地前三季度基本停产，湛江基地全年停产，机制纸产销量同比骤降77.63%。
- **[停产引发资产减值]** -> [净利润巨亏82.96亿元]: 停机导致公司对固定资产、存货等计提大额减值准备，叠加融资租赁业务坏账计提，形成巨额亏损。
- **[剥离融资租赁业务]** -> [一次性亏损29.04亿元]: 四季度出售山东晟鸣（融资租赁主体），确认大额投资损失，是当期亏损的核心来源之一。
- **[银团贷款与债务展期]** -> [筹资现金流改善96.72%]: 获得23.1亿元新增银团贷款，并与90家金融机构达成降息展期，缓解了短期流动性危机。
- **[浆纸一体化优势]** -> [化学浆业务毛利率为正]: 在机制纸毛利率为-53.85%的极端情况下，自产化学浆业务仍保持0.68%的正毛利率，体现了成本缓冲能力。
- **[财务费用压降]** -> [利息支出同比下降16.87%]: 通过债务重组与降息谈判，年节降财务费用约6亿元，是少数正向的经营亮点。
- **[非主业资产处置]** -> [补充流动性]: 出售浙江房产、剥离融资租赁资产，回笼资金用于偿还债务，聚焦制浆造纸主业。

## 风险警告
**核心风险是持续经营能力的不确定性。** 公司净资产已从年初的91.56亿元骤降至9.04亿元，资不抵债仅一步之遥。审计报告出具了带强调事项段的无保留意见，直接指向公司能否持续经营。虽然通过银团贷款和债务展期暂时避免了崩盘，但造血功能尚未恢复，2025年经营性现金流净额同比暴跌90.73%，仅2.43亿元，无法覆盖巨额债务利息。

**第二大风险是资产质量与流动性陷阱。** 公司总资产506亿元中，超过300亿元（约60%）的固定资产、无形资产和存货已被用于抵押或冻结。货币资金仅剩2.1亿元，而短期借款、应付票据及一年内到期的非流动负债合计超过百亿元。即便剥离了融资租赁业务，剩余资产的变现能力和速度仍存疑，一旦银团支持出现变数，流动性危机将立刻重现。
