# 000997.SZ 深度透视

## 因果逻辑链
- **[全球POS终端智能化升级+海外本地化深耕]** -> [智能终端集群收入同比增长18.97%]: 公司凭借全球第一的出货量地位，在欧洲、北美等高价值市场通过本地化组织建设，实现海外智能POS出货量同比增长超90%，拉动整体收入增长。
- **[支付行业合规出清+头部集中]** -> [商户运营交易规模增长近10%至2.25万亿]: 行业淘汰落后产能，公司作为持牌头部机构，凭借“支付+增值服务”生态，吸引高价值商户，月流水50万以上商户交易额同比提升超58%。
- **[AI大模型与支付场景深度融合]** -> [开辟AI token收费新商业模式]: 公司与阿里云共建支付专属大模型，实现单日调用量近6亿，以token计费，标志着公司从硬件/服务商向AI能力提供商转型。
- **[存储芯片等供应链涨价]** -> [智能终端集群毛利率下降3.31个百分点]: 上游原材料成本压力直接侵蚀硬件业务利润，尽管公司通过规模优势部分对冲，但毛利率仍承压。
- **[网商小贷发放普惠小微贷款增加]** -> [经营活动现金流净额同比大降42.82%]: 金融科技业务扩张导致资金占用增加，叠加智能终端备货，使得净利润与经营现金流产生显著背离。
- **[跨境支付牌照与本地账户体系布局]** -> [海外收单业务从0到1完成验证]: 公司获批MSB牌照，完成新加坡本土收单试点，为未来跨境支付规模化扩张奠定合规与基础设施基础。
- **[AI赋能商户营销与风控]** -> [增值服务收入达5.67亿元，AI审核接管70%人工]: 将AI产品嵌入商户核心经营流程，从“可选工具”变为“经营工具”，直接提升商户粘性与ARPU值。

## 风险警告
**核心风险在于净利润与经营现金流的严重背离。** 2025年归母净利润10.1亿，但经营现金流仅4.93亿，同比大降42.82%。主因是网商小贷公司发放普惠小微贷款增加，以及智能终端备货。这揭示公司“硬件+金融”双轮驱动模式下，金融业务扩张正在大量消耗现金，若贷款质量恶化或回收周期拉长，将直接冲击公司流动性，并可能引发信用减值损失。

**供应链成本压力与海外市场不确定性并存。** 存储芯片等关键元器件持续涨价，已导致智能终端毛利率下降3.31个百分点，且2026年影响预计持续。同时，公司海外收入占比超37%，且高度集中于拉美、中东非等新兴市场，这些地区政治经济波动、汇率风险及地缘政治冲突，可能对海外业务造成重大冲击。公司虽进行外汇衍生品对冲，但2025年衍生品投资实际损失4643.88万元，对冲效果有限。
