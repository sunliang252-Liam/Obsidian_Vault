# 688689.SH 深度透视

## 因果逻辑链
- **[新能源汽车、储能等下游需求爆发]** -> [营收增长15.46%]: 公司聚焦汽车电子、储能等高增长赛道，车规级功率器件及第三代半导体产品放量，直接拉动主营业务收入突破10亿元。
- **[IDM一体化经营模式深化]** -> [扣非净利润增长27.30%]: 整合芯片设计、晶圆制造、封测全链条，实现成本精准管控与快速响应，盈利能力显著提升，扣非净利润增速远超营收。
- **[车规级产品认证与客户突破]** -> [车载领域销售占比显著提升]: 成功进入沃尔沃亚太国产白名单，导入日本精机、天马微等优质客户，车规级产品成为核心增长引擎。
- **[第三代半导体SiC技术突破]** -> [产品结构高端化升级]: SiC MOSFET关键技术取得阶段性突破，推动公司从传统分立器件向高附加值第三代半导体领域拓展，提升市场地位。
- **[“大客户”战略深化]** -> [客户粘性与收入稳定性增强]: 前50大客户销售占比超70%，与行业龙头建立长期深度合作，保障了业绩增长的可持续性。
- **[研发投入持续高企]** -> [技术壁垒与产品迭代能力巩固]: 研发投入占营收5.88%，聚焦SiC、IPM模块等前沿领域，新增知识产权61项，为长期竞争力提供支撑。
- **[光电器件、IGBT模块产能扩张]** -> [新业务贡献增量]: 光电器件营收增长53.47%，IGBT模块项目推进，新业务逐步形成规模效益，成为新的利润增长点。

## 风险警告
**现金流恶化与资本开支压力**：2025年经营活动现金流净额同比大幅下降34.73%，主要系销售回款账期差异及生产备货增加所致。与此同时，公司计划投资3.1亿元建设高端集成电路分立器件产业化基地，资本开支激增，若未来下游需求不及预期，可能导致现金流进一步紧张，增加财务风险。

**技术迭代与市场竞争的双重挤压**：公司虽在SiC等第三代半导体领域取得突破，但与国际巨头（英飞凌、安森美等）在高端市场仍存在显著技术差距。行业技术迭代速度加快，若公司研发成果产业化滞后，或面临价格战导致毛利率下滑，现有产品存在被市场淘汰的风险。

**公司简介（F10 原文）**

> 常州银河世纪微电子股份有限公司是一家专注于半导体器件研发、芯片设计与制造、封装测试、销售及服务为一体的国家级专精特新小巨人企业。具备IDM模式下的一体化经营能力,是国内首家成为AEC国际汽车电子协会会员的半导体分立器件制造商。公司产品涵盖功率器件芯片、MOSFET、IGBT、桥式整流器、光电子器件、IPM智能模块、SiC器件、GaN器件、模拟IC等,可为客户提供适用性强、可靠性高的系列产品及技术解决方案,满足客户一站式采购需求。公司产品广泛应用于汽车电子、能源动力、工业控制、智能家居、网络通信、计算机及周边设备等领域。
