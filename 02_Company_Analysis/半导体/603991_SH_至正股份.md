# 603991.SH 深度透视

## 因果逻辑链
- **[重大资产重组完成，置入AAMI]** -> [营收暴增50.95%，总资产飙升至53.12亿元]: 通过收购全球引线框架头部企业AAMI，公司主营业务从低毛利高分子材料彻底转型为高价值半导体封装材料，资产规模和收入结构发生质变。
- **[AAMI引线框架收入跃居全球第二]** -> [半导体封装材料业务成为核心利润支柱]: AAMI凭借40余年技术积淀和全球化产能，深度绑定全球头部IDM/OSAT客户，贡献了报告期内绝大部分营收和毛利，确立了行业头部地位。
- **[置出传统线缆高分子材料业务]** -> [产生非经常性收益约4736万元，但主业亏损扩大]: 剥离低增长、低毛利资产虽带来一次性账面收益，但扣非后净利润亏损扩大至-9644万元，显示新主业AAMI在并表初期（仅1个月）的盈利能力尚不足以覆盖重组及整合成本。
- **[重组产生大额商誉（6.07亿元）及并购贷款]** -> [财务费用激增51.28%，未来面临商誉减值风险]: 收购AAMI形成巨额商誉，同时为支付对价新增并购贷款，导致利息支出大幅增加，显著侵蚀利润，且商誉占净资产比例极高，构成重大财务隐患。
- **[AAMI并表仅1个月]** -> [全年净利润仍为亏损]: 重组于2025年11月底完成，AAMI全年业绩仅并入12月单月，其全年3,943万元的净利润无法覆盖母公司全年高昂的管理费用（含重组中介费）和财务费用，导致全年整体亏损。
- **[实际控制人兼任董事长与总裁]** -> [公司治理独立性存疑]: 虽然公司声称已建立制衡机制，但实控人身兼两职，在战略转型关键期决策效率提升的同时，也增加了中小股东对内部人控制和利益输送的担忧。

## 风险警告
**核心风险在于巨额商誉减值。** 公司通过重组确认了6.07亿元商誉，占净资产的17.4%。AAMI的业绩承诺能否兑现，直接决定了这笔商誉的命运。若未来半导体行业周期下行、市场竞争加剧或AAMI经营不及预期，商誉减值将直接导致公司巨额亏损，甚至可能引发净资产大幅缩水。

**财务结构脆弱，偿债压力巨大。** 公司为完成收购背负了高额并购贷款，导致财务费用同比暴增51.28%。同时，经营活动现金流净额为-1409万元，造血能力严重不足。在巨额债务和持续亏损的双重压力下，公司流动性风险不容忽视，任何外部冲击都可能引发资金链问题。

**整合风险与治理隐患并存。** 公司从传统高分子材料企业跨界转型半导体，管理团队能否有效整合AAMI的全球化业务、留住核心人才、实现境内外协同，存在巨大不确定性。此外，实控人王强此前因未履行承诺被公开谴责，其兼任董事长与总裁的安排，也使得公司治理的独立性和规范性面临考验。
