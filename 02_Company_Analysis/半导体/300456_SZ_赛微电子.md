# 300456.SZ 深度透视

## 因果逻辑链
- **[出售瑞典Silex控制权]** -> [归母净利润暴增966.77%]: 2025年7月出售瑞典Silex控制权，产生约21.86亿元非经常性损益，掩盖了主业亏损。
- **[瑞典Silex出表]** -> [营收下降31.59%]: 瑞典Silex不再并表，直接导致MEMS代工收入及总体营收大幅下滑。
- **[北京产线产能爬坡+客户订单波动]** -> [MEMS代工收入下滑]: 北京亦庄产线仍处爬坡期，量产品类少，叠加部分原有客户订单因下游需求变化大幅波动。
- **[收购展诚科技]** -> [新增IC设计服务业务]: 2025年9月完成收购，拓展了IC设计服务及EDA工具服务，成为新的收入来源。
- **[高研发投入+刚性运营支出]** -> [扣非净利润亏损扩大79.30%]: 北京产线研发费用（占营收47.66%）及折旧摊销等刚性支出持续，导致主业亏损加剧。
- **[国际局势紧张]** -> [出售瑞典Silex控制权]: 为规避地缘政治风险，保护核心资产价值，主动放弃对瑞典Silex的控股地位。
- **[北京产线产能爬坡]** -> [产能利用率仅28.99%]: 产线仍处于工艺开发、产品验证阶段，大部分品类未进入量产，导致产能利用率极低。

## 风险警告
**核心风险在于，公司通过出售核心资产制造了巨额账面利润，但主营业务已陷入“空心化”困境。** 剥离瑞典Silex后，公司MEMS业务收入规模骤降，而北京产线仍处于高投入、低产出的产能爬坡期，产能利用率不足30%，短期内难以填补收入缺口。扣非净利润亏损大幅扩大，表明公司内生性造血能力严重不足。

**收购展诚科技带来的业务协同存在高度不确定性。** 公司试图以“MEMS+”模式整合IC设计服务，但MEMS纯代工与IC设计服务在技术体系、客户资源、运营模式上差异显著。若整合不力，不仅无法产生协同效应，反而可能因管理精力分散、文化冲突而拖累整体发展。此外，公司仍持有大量外币资产，国际局势及汇率波动将持续冲击报表业绩。
