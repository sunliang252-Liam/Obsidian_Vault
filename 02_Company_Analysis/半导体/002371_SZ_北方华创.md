# 002371.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发 + 国产替代加速]** -> [集成电路设备营收同比增长超50%]: 下游晶圆厂扩产及国产化渗透率提升，直接拉动刻蚀、薄膜沉积等核心设备批量订单。
- **[高强度研发投入（72.77亿，+34.74%）]** -> [净利润同比下降1.77%]: 研发费用同比增46.96%（+17.66亿），叠加股权激励费用增加2.74亿，侵蚀当期利润。
- **[新产品验证成本增加]** -> [毛利率从42.93%降至40.10%]: 离子注入、电镀等新品在客户端验证阶段，零部件迭代升级成本显著上升。
- **[并购芯源微、成都国泰真空]** -> [完善涂胶显影、光学镀膜产品线]: 外延并购补齐平台化短板，增强一站式解决方案能力，但产生商誉23.86亿。
- **[光伏行业产能过剩、价格战]** -> [真空新能源装备板块承压]: 下游扩产意愿收缩，设备需求萎缩，公司被迫向半导体材料、氢能等新赛道转型。
- **[员工规模扩张（+4747人）+ 多轮股权激励]** -> [管理费用增长58.67%]: 为匹配业务扩张及稳定核心团队，人力成本与激励费用大幅增加。
- **[存储芯片“超级周期”]** -> [HBM、3D NAND设备需求激增]: 存储厂商扩产向高端倾斜，带动TSV、高深宽比刻蚀等设备成为新增长点。
- **[地缘政治出口管制]** -> [核心零部件国产替代紧迫性提升]: 公司加速推进零部件本土化替代，构建多元化供应链以对冲海外供应风险。

## 风险警告
**盈利剪刀差风险**：营收高增（+30.85%）但净利润下滑（-1.77%），核心矛盾在于“研发投入+股权激励+新品验证成本”三座大山同步压顶。若未来毛利率无法随新品放量而修复，或研发费用率维持高位，利润增速将持续落后于收入增速，形成“增收不增利”的惯性。

**并购整合与商誉减值风险**：2025年密集并购（芯源微、成都国泰等）形成23.86亿商誉，且芯源微并表后管理/销售费用激增。若被并购标的业绩不及预期，或技术/文化整合失败导致核心团队流失，将面临商誉减值风险，直接冲击利润表。
