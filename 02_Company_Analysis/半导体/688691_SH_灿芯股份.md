# 688691.SH 深度透视

## 因果逻辑链
- **[下游客户需求波动]** -> [芯片量产业务收入骤降55.83%]: 部分客户因自身需求变化减少采购，导致公司核心收入来源大幅萎缩。
- **[策略性定价与收入结构恶化]** -> [综合毛利率下降9.23个百分点至15.98%]: 公司为抢占市场对部分全定制项目采取低价策略，同时高毛利的全定制量产业务占比下降，双重挤压利润空间。
- **[研发费用激增40.15%]** -> [期间费用同比增长22.67%]: 公司逆势大幅扩充研发团队（研发人员从155人增至212人），研发费用率飙升至24.73%，侵蚀了本已脆弱的盈利能力。
- **[芯片设计业务逆势增长30.69%]** -> [全年完成流片验证项目数增长44.74%]: 尽管整体营收下滑，但公司核心设计服务能力依然强劲，新项目储备充足，为未来量产业务恢复奠定基础。
- **[与中芯国际深度绑定]** -> [供应商集中度极高]: 向中芯国际的采购额占年度采购总额的60.71%，公司业务高度依赖单一晶圆代工厂，供应链风险集中。
- **[下游客户结构偏向芯片设计公司]** -> [收入波动性大]: 芯片设计公司客户收入占比高达75.40%，该类客户自身受行业周期影响大，其需求波动直接传导至公司业绩。
- **[在手订单结构预示短期业绩]** -> [芯片量产业务在手订单6.16亿元，设计业务在手订单2.85亿元]: 量产业务订单占比高，但该业务毛利率低且受客户需求影响大，未来收入质量改善存疑。

## 风险警告
**核心风险在于“增收不增利”的恶性循环被打破，直接转为“量价齐跌”。** 公司2025年营收下滑33.52%，归母净利润由盈转亏至-1.1亿元。根本原因在于，公司为维持市场份额，在量产业务萎缩时采取了策略性定价，导致毛利率大幅下滑；同时，为押注未来而大幅增加研发投入，导致费用刚性增长。这种“牺牲短期利润换长期市场”的策略，在行业下行周期中风险极高，一旦下游需求复苏不及预期，公司将面临持续的亏损压力。

**公司对单一供应商（中芯国际）的依赖度极高，构成“一荣俱荣，一损俱损”的脆弱生态。** 采购额占比超60%，且公司核心竞争力之一即“与中国大陆最领先晶圆厂战略合作”。若中芯国际产能受限、工艺迭代放缓或地缘政治因素导致合作关系生变，公司将失去核心竞争壁垒，业务连续性将受到致命打击。这种深度绑定既是护城河，也是枷锁。
