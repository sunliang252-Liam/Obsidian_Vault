# 688262.SH 深度透视

## 因果逻辑链
- **[定制芯片量产服务交付延迟]** -> [营收下降7.37%]: 2025年1-8月受外部因素影响，生产交付周期被迫延长，定制量产芯片业务收入同比减少40.31%，拖累整体营收。
- **[自主芯片及模组产品高增长]** -> [业务结构优化]: 汽车电子芯片出货量超1300万颗，自主芯片及模组收入同比增长45.74%，部分对冲定制业务下滑。
- **[高强度研发投入持续]** -> [亏损扩大]: 研发费用占营收比例高达63.23%，同比增长4.11%，叠加管理费用因折旧和股份支付增加26.34%，导致归母净利润亏损扩大至-2.54亿元。
- **[汽车电子芯片国产替代加速]** -> [核心增长引擎]: 公司在中高端汽车MCU、域控、安全气囊等12条产品线实现系列化布局，自主汽车电子芯片收入同比增长82.32%，累计出货超2500万颗。
- **[量子/抗量子密码全链条布局]** -> [抢占未来赛道]: 公司是国内少数实现“算法IP-芯片-模组-客户应用”全链条贯通的企业，抗量子金融POS芯片通过国际PCI PTS 7.0认证，先发优势显著。
- **[合同负债大幅增长]** -> [未来收入蓄水池]: 报告期末合同负债达9.27亿元，同比增长31.77%，主要由定制芯片业务预收客户货款构成，为后续收入转化提供支撑。
- **[定制芯片供应链8月底恢复]** -> [短期承压后修复]: 截至2025年8月底，定制芯片业务供应链已恢复正常，在手订单充足，预计2026年该业务将逐步恢复。

## 风险警告
**核心风险在于持续亏损与高研发投入的平衡。** 公司已连续三年亏损，2025年亏损额扩大至2.54亿元，而研发费用率高达63.23%，远超营收增速。若自主芯片及模组业务的增长无法快速弥补定制业务下滑的缺口，且高额研发投入不能及时转化为可观的商业化收入，公司现金流和盈利能力将面临持续压力。

**另一重大风险是定制芯片业务的供应链依赖与客户集中度。** 公司采用Fabless模式，前五大供应商采购占比高达85.36%，且部分晶圆代工依赖境外企业。尽管供应链已于2025年8月恢复，但国际贸易环境的不确定性仍可能再次导致生产交付延迟，对业绩造成剧烈波动。同时，实际控制人合计控制公司仅21.32%股权，存在控制权变动风险。
