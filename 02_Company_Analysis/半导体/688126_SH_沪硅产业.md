# 688126.SH 深度透视

## 因果逻辑链
- **[300mm硅片销量高增]** -> [营收增长9.69%]: 300mm硅片销量同比增长27%，拉动整体营收至37.16亿元，但价格承压导致收入增速低于销量增速。
- **[产能爬坡与固定成本高企]** -> [毛利率为负]: 产能扩张导致折旧摊销等固定成本大幅增加，营业成本增速（17.83%）远超营收增速（9.69%），综合毛利率为-17.78%。
- **[200mm及以下市场复苏不及预期]** -> [商誉减值4.1亿元]: 子公司新傲科技和Okmetic业绩未达预期，导致并购产生的商誉减值损失约4亿元，其中新傲科技商誉已全额减值。
- **[AI驱动结构性需求分化]** -> [量增价减]: AI相关先进逻辑和存储芯片需求旺盛，拉动300mm硅片出货量增长；但传统消费电子、工业应用领域需求疲软，导致产品价格承压。
- **[研发投入持续加码]** -> [侵蚀当期利润]: 研发费用同比增长32.63%至3.54亿元，占营收比例提升至9.52%，聚焦300mm高端硅片及SOI技术，短期压制利润但构筑长期壁垒。
- **[存货跌价损失扩大]** -> [资产减值损失激增]: 受价格下行及部分产品认证周期影响，存货跌价损失同比增加1.6亿元，叠加商誉减值，全年资产减值损失达6.94亿元。
- **[发行股份购买资产并募资]** -> [净资产大幅提升]: 完成配套募资20.79亿元，归母净资产较上年末增长37.61%至169.25亿元，但短期内摊薄每股收益。

## 风险警告
**核心风险在于“增收不增利”的困境持续深化。** 公司营收增长依赖300mm硅片放量，但产能爬坡带来的高昂固定成本与产品价格下行形成剪刀差，导致毛利率持续为负且亏损扩大。更严峻的是，200mm及以下业务复苏乏力，已连续两年引发大规模商誉减值（累计约7亿元），新傲科技商誉已全额计提，剩余Okmetic商誉（约4.19亿元）仍面临减值压力。

**财务杠杆与资产波动风险不容忽视。** 公司有息债务高达97.88亿元，为配合产能扩张，短期借款和长期借款均大幅增加，利息费用侵蚀利润。同时，持有的法国上市公司Soitec股票公允价值因股价波动年内减少10.74亿元，叠加存货跌价准备占比高达14.82%，资产端面临较大的价值重估风险。公司尚未实现稳定盈利，现金流持续为负，高度依赖外部融资支撑资本开支。
