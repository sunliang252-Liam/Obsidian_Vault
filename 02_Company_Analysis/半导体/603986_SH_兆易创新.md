# 603986.SH 深度透视

## 因果逻辑链
- **[存储行业周期向上，海外大厂退出利基市场]** -> [量价齐升]: 海外大厂加速退出利基型DRAM和2D NAND，造成供给缺口，公司产品价格自Q2起显著上涨，带动存储芯片营收同比增长26.41%。
- **[AI需求爆发，端侧AI渗透]** -> [定制化存储与高算力MCU新增长点]: AI手机、AIPC、机器人等需求催生定制化存储解决方案，公司控股子公司青耘科技已进入客户送样阶段；同时，高算力MCU（如GD32H7系列）受益于端侧AI推理需求。
- **[Fabless轻资产模式与供应链协同]** -> [高经营杠杆，利润弹性释放]: 公司无自建产能，营收增长25.12%的同时，固定成本相对刚性，营业成本仅增长20.65%，推动归母净利润增速（49.47%）远超营收增速。
- **[多元化产品矩阵（存储+MCU+模拟+传感）]** -> [客户粘性与抗周期能力增强]: 公司产品覆盖多领域，2025年消费、汽车、工业、存储与计算等下游均实现增长，单一市场波动对公司整体影响减弱。
- **[持续高研发投入（15.26%营收占比）]** -> [技术迭代与产品壁垒]: 率先实现45nm NOR Flash量产，推出车规级MCU GD32A7系列，累计出货超800万颗，巩固了在NOR Flash（全球第二）和32位MCU（国内第一）的领先地位。
- **[收购苏州赛芯并完成整合]** -> [模拟业务爆发式增长]: 苏州赛芯在锂电保护领域龙头地位，叠加公司渠道协同，模拟产品营收同比增长2051.82%，并完成2025年7000万元扣非净利润业绩承诺。
- **[H股上市与新加坡国际总部设立]** -> [全球化战略加速]: 构建“A+H”双资本平台，提升国际品牌形象，有助于拓展海外客户与供应链，降低单一市场风险。

## 风险警告
**核心风险在于半导体周期反转与地缘政治不确定性。** 公司2025年业绩高增高度依赖存储行业的上行周期，尤其是利基型DRAM和SLC NAND Flash的供给缺口。一旦海外大厂调整策略重返市场，或下游需求（如消费电子、汽车）复苏不及预期，将导致产品价格下跌、库存积压，公司营收和利润将面临巨大压力。此外，公司作为中国领先的IC设计公司，面临美国出口管制和技术封锁的长期风险，可能影响其先进制程芯片的代工获取和海外市场拓展。

**第二风险是外延并购整合与新产品研发的不确定性。** 公司战略高度依赖并购（如苏州赛芯）和内部孵化（如定制化存储青耘科技）来驱动增长。苏州赛芯的业绩承诺期至2026年，后续整合能否持续产生协同效应存在变数。同时，定制化存储、高算力MCU等新业务尚处投入期，研发投入巨大（2025年资本化研发投入2.87亿元），若技术路线选择失误或客户导入不及预期，将造成巨额研发沉没成本，拖累整体盈利能力。

> 兆易创新科技集团股份有限公司(GigaDevice)成立于2005年,集团总部设于中国北京,并分别在上海证券交易所(603986.SH)、香港联交所(3986.HK)上市,是一家致力于开发存储器技术、MCU、传感器和模拟产品及解决方案的领先的无晶圆厂半导体公司,在中国上海、深圳、合肥、西安、成都、苏州、香港和新竹,新加坡、韩国、日本、德国、英国、土耳其、意大利、美国、加拿大、巴西、墨西哥等多个国家和地区均设有分支机构和办事处,营销网络遍布全球,为客户提供优质便捷的本地化支持服务。公司的核心产品线为存储器(Flash、利基型DRAM)、32位通用型MCU、智能人机交互传感器、模拟产品及整体解决方案。公司产品以“高性能、低功耗”著称,技术实力备受行业认可。公司在质量管理方面有严格的标准与要求,已通过ISO26262:2018汽车功能安全最高等级ASILD体系认证、ISO/SAE21434道路车辆网络安全管理体系认证,获得IEC61508功能安全产品认证以及ISO9001、ISO14001、ISO45001等体系认证和邓白氏认证,产品检测中心还获得了CNAS(ISO/IEC17025)国家实验室认可证书。此外,公司积极推进产业整合,拓展战略布局,并与全球多家领先晶圆厂、封装测试厂达成战略合作伙伴关系,通过加强产业上下游合作、优化供应链管理,共同推进半导体领域的技术创新。
