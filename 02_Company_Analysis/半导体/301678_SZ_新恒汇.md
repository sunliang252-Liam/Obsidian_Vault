# 301678.SZ 深度透视

## 因果逻辑链
- **[贵金属原材料价格大幅上涨]** -> [净利润下降32.18%]: 黄金、白银、铜等成本快速上升，但产品售价调整存在滞后，导致毛利率被严重压缩，利润总额减少约4750万元。
- **[蚀刻引线框架产能释放与国产替代]** -> [营收增长61.61%]: 高密度QFN/DFN项目投产，LDI曝光、卷式蚀刻等核心技术整合，成功切入主流封测厂商供应链，出货量增长61.01%。
- **[智能卡业务量价齐跌]** -> [营收下降14.01%]: 国内市场需求饱和，出货量下降9.86%，叠加原材料成本压力，该传统主业成为拖累整体业绩的主要因素。
- **[物联网eSIM封测业务放量]** -> [营收增长34.47%]: 车规级eSIM通过IATF16949认证，卡位车联网赛道，出货量增长60.51%，成为新的增长极。
- **[IPO募集资金到位]** -> [资产总额增长55.41%]: 2025年6月上市募资，货币资金大幅增加至10.55亿元，为后续产能扩张和研发投入提供充足弹药。
- **[人民币汇率波动]** -> [利润总额减少约1200万元]: 公司外销占比约29%，以美元结算，人民币汇率波动对以人民币计量的收入和汇兑损益产生不利影响。
- **[套期保值业务]** -> [对冲部分原材料风险]: 公司使用期货合约对黄金、铜进行套期保值，有效管理了部分价格波动风险，但未能完全抵消成本上涨压力。

## 风险警告
**核心风险在于成本传导机制失效与盈利能力的急剧恶化。** 公司净利润同比暴跌32.18%，与营收9.62%的增长形成巨大反差，直接原因是贵金属原材料价格暴涨。公司作为中间环节，对下游客户的议价能力有限，价格调整存在明显滞后，导致毛利率全面下滑（智能卡-6.30%，蚀刻引线框架-7.65%）。若原材料价格持续高位或进一步上涨，而公司无法将成本有效转嫁，盈利能力将持续承压，甚至可能陷入增收不增利的困境。

**第二重风险是业务结构转型的阵痛与不确定性。** 公司传统智能卡业务（占营收52%）已显疲态，增长乏力。新引擎蚀刻引线框架虽高速增长，但毛利率仅6.40%，远低于智能卡的40.01%，且该领域竞争激烈，国产替代进程可能不及预期。物联网eSIM业务体量尚小（占营收7%），尚不足以支撑整体利润。公司正处于新旧动能转换的关键期，新业务的高投入与低毛利特征，叠加旧业务的萎缩，构成了业绩波动的主要来源。

**公司简介（F10 原文）**

> 新恒汇电子股份有限公司(以下简称“公司”)成立于2017年12月,集芯片封装材料的研发、生产、销售与封装测试服务于一体的集成电路企业,是国家高新技术企业、国家专精特新“小巨人”企业、山东省制造业单项冠军企业、山东省瞪羚企业。公司的主要业务包括智能卡业务、蚀刻引线框架业务以及物联网eSIM芯片封测业务。智能卡业务主要包括智能卡芯片关键封装材料柔性引线框架产品的研发、生产和销售,以及主要依靠自产的柔性引线框架向客户提供智能卡模块产品或模块封装服务,产品广泛应用于通讯、金融、交通、身份识别等智能卡领域。在蚀刻引线框架和物联网eSIM芯片封测领域,公司近几年来投入大量人力、物力开展技术攻关,目前已成功掌握了包括卷式无掩膜激光直写曝光技术、卷式连续蚀刻技术及高精准选择性电镀技术等在内的多项核心技术,并实现了产品的批量生产及销售,这两项业务已逐渐成为公司新的业绩增长点。公司致力于自主研发和产品创新,建有山东省企业技术中心,建成理化分析、可靠性、失效分析、智能卡验证四个业界领先的实验室,积累了在金属材料表面进行高精度图案刻画的技术和金属表面处理相关的关键核心技术,主持制订了集成电路(IC)卡封装框架国家标准,曾获得金融领域国产密码技术研究与应用示范科技进步一等奖。承担山东省重大科技创新专项1项,成为国内集成电路封装材料领域领军企业。公司拥有高水平的研发团队,为新产品的快速研发提供强有力的支持。研发团队对基础材料、关键工艺、未来新产品设计等提供源源不断的技术储备与前期研发,为企业长期发展提供充足动力。
