- **[产品结构优化与降本增效]** -> [毛利率连续六个季度攀升至近30%，毛利额同比增长近15%]: 公司主动调整产品结构，聚焦高毛利产品，并通过精进设计、工艺升级和供应链优化，有效降低了单位成本。
- **[新兴应用领域需求爆发]** -> [电机驱动、大功率电源、DC-DC、传感器等新品收入同比增长超80%]: AI端侧应用、数据中心、机器人等下游需求旺盛，公司新产品精准切入快充、服务器电源、工业自动化等高增长赛道。
- **[收购兴感半导体]** -> [形成“电流检测—运动感知—电源管理—电池管理—电机驱动”完整产品体系]: 通过并购，公司补强了传感器核心技术，实现了从单一芯片向系统级解决方案供应商的跨越，提升了在高成长市场的竞争力。
- **[研发投入持续高企]** -> [研发费用占营收22.54%，但研发费用同比下降12.55%]: 公司保持高强度研发投入以维持技术领先，但费用控制初见成效，研发效率有所提升，是扭亏为盈的关键因素之一。
- **[供应链现金支出减少及销售回款增加]** -> [经营活动现金流净额同比暴增1781.20%至6425万元]: 公司加强库存管理，减少现金支出，同时优化客户信用政策，加速现金回笼，经营质量显著改善。
- **[“头部效应”市场策略]** -> [产品进入众多行业头部客户供应链，形成品牌壁垒]: 公司以解决头部客户痛点为导向，获得标杆项目认可，从而带动行业其他客户导入，形成良性循环，巩固市场地位。

## 风险警告
**核心风险在于盈利的脆弱性与并购整合的不确定性。** 公司2025年虽然实现扭亏为盈，但扣除非经常性损益后净利润仍为-350万元，表明主营业务尚未真正实现稳定盈利。利润增长高度依赖产品结构优化和成本控制，而非收入规模的强劲扩张（营收同比微降0.70%），这种增长模式的可持续性存疑。一旦市场竞争加剧导致价格战，或下游需求出现波动，公司可能重新陷入亏损。

**并购兴感半导体带来的商誉与整合风险不容忽视。** 报告期末公司商誉激增至2.47亿元，占总资产14%。兴感半导体与公司的协同效应尚需时间验证，若未来业绩不及预期，将面临巨额商誉减值风险，直接侵蚀利润。此外，公司面临核心技术泄密、人才流失、产品迭代不及预期等核心竞争力风险，以及国际贸易环境变化带来的宏观风险，这些都可能对公司长期发展构成重大挑战。
