# 688012.SH 深度透视

## 因果逻辑链
- **[刻蚀设备高端化与国产替代]** -> [营收增长36.62%]: 先进逻辑和存储器件关键刻蚀工艺实现量产，CCP/ICP设备在3纳米及以下产线批量销售，推动刻蚀设备收入98.32亿元，同比增长35.12%。
- **[薄膜设备从0到1的突破]** -> [LPCVD设备爆发式增长]: 近两年新开发的LPCVD/ALD设备累计出货突破300反应台，实现收入5.06亿元，同比增长224.23%，成为第二增长曲线。
- **[高强度研发投入]** -> [技术壁垒与产品线扩张]: 研发投入37.44亿元（占营收30.23%），驱动超20款新设备开发，研发周期从3-5年缩短至2年，加速产品迭代。
- **[股权激励绑定核心团队]** -> [人才稳定性与创新动力]: 全员持股及连续多年股权激励计划，研发人员占比52.24%，确保技术领先和产品快速商业化。
- **[下游客户资本开支扩张]** -> [订单与现金流强劲]: 受益于国内晶圆厂扩产及AI需求拉动，经营活动现金流净额22.95亿元，同比增长57.39%，反映订单交付和回款良好。
- **[外延并购与投资布局]** -> [拓展产品版图]: 拟收购杭州众硅（湿法设备），填补空白；投资智微资本及多家量检测设备公司，从“干法”向“干法+湿法”整体解决方案跨越。
- **[公允价值变动收益贡献利润]** -> [非经常性损益增厚业绩]: 对外股权投资产生公允价值变动收益和投资收益合计6.61亿元，占归母净利润的31.3%，但不可持续。

## 风险警告
**核心风险在于地缘政治导致的供应链与市场准入不确定性。** 公司刻蚀设备已进入3纳米及以下国际先进产线，但少数国家持续加强对中国半导体出口管制，可能限制公司获取关键零部件、技术或海外客户订单，直接影响高端产品交付与海外市场拓展。公司虽推进零部件国产化，但短期内完全替代存在技术和产能瓶颈。

**第二风险是研发投入持续高企对利润的侵蚀。** 2025年研发费用24.75亿元，同比增长74.61%，远超营收增速。研发投入资本化率从35.89%降至27.92%，意味着更多研发支出直接计入当期损益。若新产品（如EPI、量检测设备）商业化进度不及预期，或下游客户扩产放缓，高额研发投入将长期压制扣非净利润增长，公司盈利能力面临考验。
