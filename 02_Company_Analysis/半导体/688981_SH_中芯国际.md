# 688981.SH 深度透视

## 因果逻辑链
- **[产业链在地化转换加速]** -> [收入增长16.5%]: 下游客户为规避地缘政治风险，将晶圆代工需求从海外转向本土，直接拉动公司晶圆销量同比增长20.9%。
- **[产能利用率提升至93.5%]** -> [毛利率改善至22%]: 高固定成本结构下，产能利用率同比提升8个百分点，摊薄了单位固定成本，抵消了折旧大幅增长的压力。
- **[消费电子与汽车电子需求复苏]** -> [产品组合优化]: 消费电子收入占比从37.8%升至43.2%，工业与汽车占比从7.8%升至11.0%，高附加值应用占比提升拉高了平均售价和毛利。
- **[持续巨额资本开支]** -> [折旧压力与现金流分化]: 资本开支同比增9.9%至599.5亿元，导致折旧摊销增至273.1亿元，侵蚀净利润；但经营活动现金流净额仍达200.8亿元，显示主业造血能力强劲。
- **[美国实体清单限制]** -> [供应链风险与战略聚焦]: 被列入实体清单限制了先进设备获取，迫使公司集中资源发展成熟及特色工艺（如BCD、模拟、MCU），反而在细分领域建立壁垒。
- **[研发投入聚焦特色工艺]** -> [非先进制程竞争力增强]: 研发投入55.2亿元（占收入8.2%），重点攻关28nm超低漏电、BCD、射频SOI等平台，在非最先进制程领域形成差异化优势，避开与台积电的正面竞争。
- **[国家集成电路基金支持]** -> [产能扩张的资金保障]: 大基金三期等国资背景股东持续注资，叠加银行借款，支撑了公司超大规模的产能扩建（月产能超100万片8英寸等效），缓解了资本开支对现金流的压力。

## 风险警告
**核心风险在于地缘政治枷锁下的技术天花板。** 公司被列入美国实体清单，关键设备、EDA软件及先进工艺所需材料获取受限，导致其与台积电、三星在7nm及以下先进制程的差距持续拉大。若出口管制进一步收紧，公司可能长期被困于成熟制程，无法参与AI算力芯片等最高价值市场的竞争，增长天花板清晰可见。

**财务风险源于巨额资本开支与折旧的恶性循环。** 公司为维持产能扩张，年资本开支超600亿元，导致折旧费用高达273亿元，严重侵蚀利润（净利润仅50.4亿元）。若下游需求周期性回落，产能利用率下降，高固定成本将迅速压垮毛利率，导致公司陷入“越扩产、越不赚钱”的困境。同时，有息债务总额已达886亿元，财务杠杆持续攀升。
