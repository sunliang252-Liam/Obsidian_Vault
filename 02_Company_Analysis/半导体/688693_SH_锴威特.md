# 688693.SH 深度透视

## 因果逻辑链
- **[营收高增但持续亏损]** -> [净利润-9078万元]: 营收同比+95.62%至2.55亿元，但研发费用同比+42.85%至8379万元，叠加行业价格竞争致毛利率承压，营收无法覆盖高额战略投入。
- **[研发高强度投入]** -> [构筑长期壁垒]: 研发费用占营收32.92%，聚焦SiC MOSFET、功率IC系列化及IPM模块，虽短期侵蚀利润，但形成3项国际先进、1项国内领先核心技术。
- **[功率IC业务爆发]** -> [营收结构剧变]: 功率IC及其他收入同比+184.63%至1.35亿元，占比超54%，但毛利率骤降38.97个百分点至46.42%，因新增低毛利工控/消费电子业务。
- **[并购并表驱动增长]** -> [营收与亏损同步扩大]: 控股子公司众享科技（51%股权）并表贡献营收约5029万元，但亦带来亏损-171万元，并推高管理费用与研发费用。
- **[经营现金流持续为负]** -> [造血能力承压]: 经营活动现金流净额-9524万元，较上年-5167万元恶化84.3%，主因营收增长带动采购支出及经营性支出增加，回款周期拉长。
- **[存货与应收账款双升]** -> [运营效率风险]: 存货库存量激增（功率IC成品库存同比+320%），应收账款同比+50.63%至1.19亿元，反映下游回款压力与产品滞销风险。
- **[Fabless模式依赖]** -> [供应链集中风险]: 前五大供应商采购额占比59.21%，晶圆代工与封测委外，若产能紧缺或价格波动，将直接冲击供应稳定性与盈利能力。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收翻倍增长，但净利润连续两年亏损且亏损额仍高达9078万元，经营现金流净流出扩大至9524万元。高强度的研发投入（32.92%营收占比）与并购扩张虽在构筑长期壁垒，却严重拖累短期盈利，而功率IC业务毛利率骤降38.97个百分点至46.42%，表明新增的低毛利业务正在稀释整体盈利质量。若行业价格竞争持续或下游需求不及预期，公司可能陷入“越卖越亏”的困境，盈利周期将大幅延长。

**结构性风险来自资产质量恶化与供应链脆弱性。** 功率IC成品库存同比暴增320%，应收账款同比增50.63%，存货与应收双高叠加经营现金流持续为负，公司营运资金压力巨大。同时，作为Fabless设计公司，前五大供应商采购额占比近60%，晶圆代工与封测高度集中，一旦主要供应商产能受限或价格波动，公司将面临断供或成本失控风险。此外，公司累计未弥补亏损达1.04亿元，已连续两年不进行利润分配，股东回报能力严重缺失。
