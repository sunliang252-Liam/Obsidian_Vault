# 688385.SH 深度透视

## 因果逻辑链
- **[FPGA及PSoC芯片需求旺盛]** -> [营收增长]: 受益于5G通信、卫星通信、人工智能及高可靠领域需求，FPGA/PSoC产品线营收同比增长25.19%，成为核心增长引擎。
- **[战略备货与需求错配]** -> [资产减值损失暴增]: 为保供应链安全而大量备货，但部分产品下游需求结构变化，导致存货跌价损失大幅增加，资产减值损失同比增2.71亿元至4.39亿元。
- **[研发项目撇销与高强度投入]** -> [研发费用侵蚀利润]: 因国际贸易环境变化，部分资本化研发项目未来预期收益不佳被撇销，叠加持续高研发投入，研发费用同比增1.92亿元至12.23亿元。
- **[增值税加计抵减及政府补助减少]** -> [其他收益大幅下滑]: 集成电路设计企业增值税加计抵减额及研发专项政府补助减少，导致其他收益同比减少0.91亿元。
- **[智能电表与车规MCU市场拓展]** -> [智能电表芯片营收高增]: 凭借在智能电表领域的领先地位及车规MCU在汽车电子市场的快速渗透，该产品线营收同比增长30.69%。
- **[非挥发存储器竞争加剧]** -> [存储器营收下滑]: 行业竞争激烈，非挥发存储器产品线全年营收同比下降8.30%，拖累整体业绩。
- **[高可靠产品客户结算周期长]** -> [应收账款增加]: 高可靠产品客户货款结算周期较长，叠加销售增长，导致应收账款同比增长25.65%。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长10.92%，但归母净利润却暴跌59.42%。利润被巨额资产减值损失（4.39亿）和研发费用撇销（导致研发费用增至12.23亿）严重侵蚀。这揭示了公司在供应链安全与市场需求预测之间的深刻矛盾：为应对地缘政治风险而进行的战略备货，正因下游需求结构变化而转化为沉重的财务负担。若未来市场需求持续分化，存货跌价风险将进一步恶化。

**另一重大风险是研发投入的资本化处理与后续撇销的不可预测性。** 公司研发投入占营收比高达26.88%，但部分项目因外部环境变化被撇销，直接冲击当期利润。这暴露出公司在高端芯片研发（如1xnm FinFET FPGA）中面临的技术与市场双重不确定性。一旦关键研发项目未能如期实现商业化，或国际贸易管制导致供应链中断，公司将面临巨大的资产减值和研发沉没成本风险，业绩波动性将显著加剧。
