# 300623.SZ 深度透视

## 因果逻辑链
- **[产能释放与产品结构升级]** -> [营收增长22.83%]: 南通科技等新产线进入产能爬坡期，叠加下游AI、数据中心、汽车电子需求回暖，驱动芯片及器件销量分别增长37.55%和31.93%。
- **[IDM模式下的成本刚性]** -> [毛利率下降5.41%]: 新产线投产导致固定资产折旧及制造费用大幅增加（芯片制造费用+56.08%），而产能利用率尚未达满产，单位固定成本上升侵蚀利润。
- **[研发费用资本化策略调整]** -> [研发费用率下降至5.77%]: 本年度研发活动直接形成存货的金额增加，导致计入当期损益的研发费用同比减少25.83%，但研发投入总额保持高位。
- **[非经常性损益波动]** -> [归母净利润增速远低于营收增速]: 上年同期存在出售厂房利得及大额政府补助，本报告期此类非经常性收益大幅减少，导致净利润仅微增0.77%。
- **[应收账款与存货同步增长]** -> [信用减值与资产减值损失扩大]: 营收扩张伴随应收账款增加（+23%）和存货增加（+16%），导致信用减值损失同比+74.6%，存货跌价准备计提达8116万元。
- **[资本开支与理财配置错位]** -> [投资活动现金流大幅净流出]: 公司购买结构性存款的净支出增加，同时在建工程持续投入，导致投资活动现金流净额同比减少142.27%。
- **[股权激励费用基数效应]** -> [管理费用激增48.09%]: 上年同期因回购注销限制性股票冲减了股权激励费用，导致本报告期管理费用同比增幅异常。

## 风险警告
**产能消化与资产折旧的双重压力。** 公司“高端功率半导体产业化建设项目”等重大项目已陆续转固，固定资产规模达52亿元（占总资产63%），折旧摊销刚性增长。若下游需求增速放缓或新产线良率、产能利用率爬坡不及预期，将直接侵蚀利润，这是当前最核心的财务风险。

**竞争格局恶化与国产替代的悖论。** 公司主要竞争对手为英飞凌等国际巨头，在中低压MOSFET等红海市场面临价格战。虽然国产替代是长期逻辑，但短期内公司产品结构仍以晶闸管、防护器件等传统品类为主，高端IGBT、SiC器件尚处研发或小批量阶段，业绩爆发力有限。
