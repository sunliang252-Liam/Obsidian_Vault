# 688449.SH 深度透视

## 因果逻辑链
- **[PC-OEM市场突破与PCIe 4.0/5.0产品放量]** -> [营收增长13.06%]: 公司SSD主控芯片在PC前装市场持续渗透，叠加PCIe 4.0成为主流、PCIe 5.0进入量产，带动出货量同比增长23.01%。
- **[产品结构优化与规模效应]** -> [毛利率提升至50.52%]: 高毛利的数据存储主控芯片营收占比提升（+26.47%），且成本增速（+4.10%）远低于收入增速，拉动整体毛利率同比增加3.12个百分点。
- **[扣非净利润暴增130.43%]** -> [盈利能力实质性改善]: 剔除政府补助等非经常性损益后，核心业务利润从4407万跃升至1.02亿，显示公司已摆脱对补贴的依赖，主业造血能力显著增强。
- **[AI端侧推理需求爆发]** -> [嵌入式UFS与车规芯片打开新增长极]: UFS 3.1主控进入量产并获手机厂商导入，车规级感知芯片通过AEC-Q100认证并获车企定点，为未来业绩提供第二曲线。
- **[全球独立第三方SSD主控市占率第二]** -> [行业地位稳固]: 2024年全球独立第三方SSD主控出货量占比约25%（CFM数据），2025年份额进一步提升，仅次于慧荣科技，形成寡头竞争格局。
- **[研发投入占比37.88%]** -> [技术壁垒持续加高]: 研发费用5.03亿元，同比增长18.25%，支撑PCIe 5.0/6.0、UFS 4.1/5.0等前沿技术储备，确保在高速接口与先进纠错码领域的领先性。

## 风险警告
**客户与供应商双集中风险**：前五大客户销售额占比63.37%，其中关联方海康威视占12.32%；晶圆代工供应商一采购占比高达76.21%。这种“单腿走路”的供应链结构，一旦主要客户或晶圆厂合作关系生变，将对公司经营造成重大冲击。贸易摩擦加剧背景下，晶圆代工受限的风险不容忽视。

**存货激增与AIoT业务萎缩**：存货账面价值同比暴增86.61%至5.77亿元，占总资产24.48%，主要系战略备货。若下游需求不及预期或技术迭代导致库存积压，将面临大额跌价风险。同时，AIoT信号处理及传输芯片营收同比下滑47.17%，该业务尚处起步阶段，市场竞争激烈（海外巨头垄断），若无法快速放量，前期研发投入存在沉没风险。
