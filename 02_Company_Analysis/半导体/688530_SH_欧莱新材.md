# 688530.SH 深度透视

## 因果逻辑链
- **[原材料价格大幅上涨]** -> [主营业务毛利率下滑]: 铜、铟等核心原材料成本飙升，但产品定价调整滞后，直接侵蚀利润空间。
- **[合肥、乳源募投项目产能爬坡]** -> [固定成本与期间费用激增]: 新产线投产初期，折旧、人工及运营成本刚性增加，但产能利用率不足，无法摊薄单位成本。
- **[原材料价格波动]** -> [期货套期保值产生大额亏损]: 为对冲原料风险开展的期货业务，因价格剧烈波动产生公允价值变动损失与投资损失，加剧业绩亏损。
- **[金属材料及加工件业务放量]** -> [营业收入同比增长25.04%]: 公司向产业链上下游延伸，新增铜基新材料、高纯无氧铜等业务，成功开辟第二增长曲线，拉动营收增长。
- **[核心客户深度绑定]** -> [显示靶材业务基本盘稳固]: 公司已全面导入京东方、华星光电、惠科等头部面板厂商供应链，G5-G11全世代线覆盖，形成高壁垒的客户粘性。
- **[全产业链垂直整合]** -> [成本控制与供应链安全壁垒]: 构建“超高纯金属提纯-靶材制备-废靶回收再生”闭环，降低对进口原材料的依赖，对冲价格波动风险。
- **[前沿赛道技术突破]** -> [打开长期成长天花板]: 成功研制核医疗RFQ加速腔核心部件、超导用高纯铜部件，实现国产替代，卡位高附加值未来产业。
- **[研发投入持续加码]** -> [技术护城河加深]: 聚焦半导体、光伏、核医疗等前沿领域靶材及核心部件研发，保持技术领先性，为后续高端产品放量奠定基础。

## 风险警告
**核心风险在于盈利能力的急剧恶化与短期修复的不确定性。** 2025年公司由盈转亏，净利润暴跌242%，主因是原材料价格暴涨无法有效传导至下游，叠加新产能爬坡期的刚性成本激增。公司虽已与核心客户达成调价共识，但顺价过程存在时滞，且原材料价格波动风险并未消除，期货套保业务反而成为新的亏损来源，显示公司对上游成本波动的对冲能力存在短板。

**第二增长曲线的规模化放量尚需时日，业绩支撑力不足。** 公司寄予厚望的核医疗、超导等前沿赛道业务目前仍处于小批量供货或客户验证阶段，尚未形成稳定的收入与利润贡献。同时，半导体靶材业务仍处于送样验证期，距离大规模量产并贡献利润仍有较长周期。在传统显示靶材主业毛利率承压的背景下，新业务能否及时接力成为扭转亏损的关键变量，存在较大不确定性。
