# 688110.SH 深度透视

## 因果逻辑链
- **[AI驱动存储行业上行周期]** -> [营收增长43.76%]: 人工智能带动中小容量存储芯片供需优化，公司产品量价齐升，实现营收9.21亿元。
- **[“存、算、联”一体化战略投入]** -> [净利润亏损1.95亿元]: 高额研发费用（2.16亿）及对上海砺算的投资亏损（约1.66亿）侵蚀利润，导致连续亏损。
- **[产品结构优化与成本管控]** -> [毛利率提升10.52个百分点]: NAND Flash和MCP产品量价齐升，叠加成本控制，主营业务毛利率从14%提升至24.51%。
- **[国际大厂产能退出]** -> [SLC NAND Flash国产替代机遇]: 三星等巨头退出MLC市场，公司凭借1xnm先进制程SLC NAND Flash填补供给缺口，扩大市场份额。
- **[车规级产品认证与导入]** -> [开辟汽车电子第二增长曲线]: SLC NAND、NOR及MCP产品通过AEC-Q100认证，成功进入多家整车厂及Tier1供应链，实现规模量产。
- **[Wi-Fi 7芯片研发推进]** -> [培育未来增长新动能]: 公司首款Wi-Fi 7芯片完成样片测试，切入高端无线通信赛道，旨在平滑存储行业周期波动。
- **[Fabless模式与供应商集中]** -> [供应链稳定性风险]: 前五大供应商采购额占比82.9%，晶圆代工和封测高度依赖外部，面临产能紧张和成本上升压力。

## 风险警告
**核心风险在于“存、算、联”战略的投入产出严重错配。** 公司存储主业虽已实现盈利，但高达2.16亿元的研发费用（占营收23.43%）和约1.66亿元的联营企业投资亏损（上海砺算GPU项目），导致公司连续第三年亏损且亏损额扩大至1.95亿元。这种“主业造血，副业失血”的格局，若新业务（GPU、Wi-Fi 7）产业化进程持续不及预期，将不断消耗公司现金储备，使盈利拐点遥遥无期。

**另一重大风险是存货高企与供应链依赖。** 公司存货账面价值高达10.66亿元，占总资产27.75%，且已计提7648万元跌价准备。存储芯片价格波动剧烈，若下游需求复苏不及预期，将面临巨额存货减值风险。同时，作为Fabless公司，前五大供应商采购额占比超82%，晶圆代工和封测环节高度集中，一旦上游产能紧张或价格大幅上涨，将严重挤压本已微薄的利润空间。
