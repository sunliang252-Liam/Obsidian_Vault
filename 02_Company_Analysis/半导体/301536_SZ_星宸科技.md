# 301536.SZ 深度透视

## 因果逻辑链
- **[视觉AI SoC全球领导者地位]** -> [营收与出货量双创新高]: 公司凭借41.2%的安防视觉AI SoC全球市占率，受益于端边侧AI应用爆发，全年出货量超1.8亿颗，营收同比增长26.28%。
- **[机器人业务爆发式增长]** -> [智能物联营收高增38.63%]: 机器人出货量超1000万颗，同比增长超5倍，成为公司第二增长曲线，驱动智能物联业务线成为增速最快的板块。
- **[车载前装业务突破]** -> [智能车载营收增长29.66%]: 前装出货量超百万级，同比翻倍增长，且成功打入理想、一汽大众等车企供应链，标志着公司从后装市场向高价值前装市场战略延伸。
- **[前瞻性供应链布局]** -> [下半年业绩加速增长]: 面对存储供应紧张，公司凭借“SoC+内置存储”一体化方案和战略储备，保障交付并巩固竞争优势，Q4营收环比增长5.6%，毛利率环比提升2.32%。
- **[收购富芮坤]** -> [补强“连接+低功耗”核心能力]: 收购蓝牙芯片公司富芮坤，补全“感知+计算+连接”一体化SoC平台，增强端边侧AI解决方案的交付能力，构建差异化壁垒。
- **[研发投入持续高企]** -> [新品落地与未来增长储备]: 研发费用6.52亿元，占营收21.94%，支撑了高端机器人芯片、车规级芯片、激光雷达SPAD SoC等新品研发，为未来3-5年增长奠定基础。
- **[无实际控制人结构]** -> [治理稳定性风险]: 公司无控股股东和实际控制人，尽管目前治理稳定，但未来存在因决策效率低下或股东分歧而错失业务机会的潜在风险。

## 风险警告
**1. 客户与供应链高度集中风险。** 公司前五大客户销售占比高达88.16%，前五大供应商采购占比达79.90%，且采用Fabless模式，对晶圆代工和封测产能高度依赖。一旦主要客户流失或上游产能紧张、贸易管制升级，将对公司经营的稳定性和盈利能力造成重大冲击。

**2. 技术迭代与市场竞争加剧风险。** AI SoC行业技术升级迅速，公司面临来自地平线、瑞芯微、华为海思等国内外厂商的激烈竞争。若公司技术研发方向偏离市场需求，或新产品（如激光雷达、高端车载芯片）产业化不及预期，可能导致研发投入无法收回，市场份额和毛利率面临下滑压力。
