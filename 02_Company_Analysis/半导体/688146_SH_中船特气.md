# 688146.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [电子特气需求增长]: AI驱动芯片、存储需求激增，带动上游三氟化氮、六氟化钨等核心特气销量提升，营收同比增长15.88%。
- **[三氟甲磺酸系列放量]** -> [新利润增长点形成]: 产品在固态电池、医药领域应用扩大，营收同比增长44.85%，毛利率提升10.99个百分点，成为第二增长曲线。
- **[产能扩张与转固]** -> [资产结构变化]: 呼和浩特一期7,500吨三氟化氮产能投产，在建工程转固，固定资产同比增61.51%，总资产增14.48%。
- **[并购淮安派瑞]** -> [业务版图拓展]: 收购淮安派瑞100%股权，切入电子大宗气体现场制气业务，形成“特气+大宗+前驱体+高纯金属”多业务矩阵。
- **[境外市场拓展]** -> [收入结构优化]: 境外营收同比增长20.35%，占比提升至25.38%，光刻气通过ASML子公司Cymer认证，打开高端光刻气市场。
- **[政府补助依赖]** -> [利润质量承压]: 政府补助占利润总额32.87%，扣非净利润仅占归母净利润68.8%，利润对非经常性损益依赖度较高。
- **[管理费用激增]** -> [利润侵蚀]: 管理费用同比增41.14%，主因折旧摊销及管理人员增加，侵蚀利润空间，净利率仅15.29%。

## 风险警告
**1. 利润质量与政府补助依赖风险。** 公司2025年归母净利润3.46亿元，但扣非净利润仅2.38亿元，政府补助高达1.26亿元，占利润总额32.87%。若未来补助政策变动或认定资格丧失，利润将大幅缩水。同时，管理费用同比飙升41.14%，侵蚀经营成果，需警惕成本失控风险。

**2. 产能消化与行业周期双重压力。** 公司三氟化氮产能已达18,500吨/年，呼和浩特一期新增7,500吨产能。但下游集成电路行业具有强周期性，若AI需求增速放缓或全球半导体资本开支收缩，大规模产能将面临折旧压力与价格战风险。2025年电子特气毛利率已下降2.95个百分点，竞争加剧信号明显。

**3. 海外业务地缘政治风险。** 境外收入占比超25%，主要客户包括台积电、美光、海力士等。当前中美科技博弈持续升级，若出口管制扩大或客户供应链“去中国化”，将直接冲击核心收入。公司光刻气虽获ASML认证，但高端产品放量仍需时间，短期难以对冲系统性风险。
