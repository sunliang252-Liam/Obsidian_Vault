# 688652.SH 深度透视

## 因果逻辑链
- **[半导体设备国产替代需求旺盛]** -> [营收增长38.95%]: 公司主营的温控、废气处理及传片设备打破国外垄断，受益于国内晶圆厂扩产及国产化率提升，带动核心产品销量大幅增长。
- **[研发投入大幅增加48.65%]** -> [净利润下降3.26%]: 公司为保持技术领先，持续加大研发人员薪酬及材料费投入，导致期间费用率上升，侵蚀了营收增长带来的利润空间。
- **[增值税即征即退减少]** -> [其他收益下降]: 报告期内确认的政府补助（增值税即征即退）同比减少，直接导致非经常性损益下降，是净利润下滑的另一关键因素。
- **[客户高度集中]** -> [经营风险]: 前五名客户销售额占比高达81.37%，公司业绩高度依赖少数核心晶圆厂，若主要客户资本开支放缓，将直接冲击订单稳定性。
- **[存货激增，发出商品占比高]** -> [跌价风险]: 存货账面价值达23.95亿元，占总资产55.98%，其中发出商品占64.31%。产品验收周期长，若下游客户产线进度不及预期，存在大额存货跌价风险。
- **[核心零部件依赖进口]** -> [供应链风险]: 公司部分原材料采购自美国、日本等供应商，地缘政治摩擦可能导致供应中断或成本上升，影响生产连续性和盈利能力。
- **[温控设备收入增长49.03%]** -> [产品结构优化]: 作为第一大收入来源，温控设备的高增长（远超废气处理设备7.6%的增速）表明公司在该细分领域的技术壁垒和市场份额正在快速扩大。

## 风险警告
**核心风险在于“增收不增利”与“高存货”的双重压力。** 公司营收增长近40%，但净利润却下滑，主要因研发费用激增和增值税退税减少。这种“以利润换市场”的策略能否持续，取决于研发投入能否在未来转化为更强的产品竞争力和订单溢价。同时，高达23.95亿元的存货（占总资产56%）和64.31%的发出商品占比，意味着公司业绩高度依赖下游客户的验收进度。一旦行业景气度下行或客户产线建设放缓，巨额存货将面临严重的跌价损失，直接冲击利润表。

**客户集中度过高和供应链脆弱性是结构性隐患。** 前五大客户贡献超八成营收，公司议价能力受限，且业绩波动与少数几家晶圆厂的资本开支周期深度绑定。此外，核心零部件对美、日供应商的依赖，使其在贸易摩擦升级时面临“卡脖子”风险，不仅可能推高成本，更可能威胁生产的稳定性。这两大风险共同构成了公司长期增长的“天花板”。
