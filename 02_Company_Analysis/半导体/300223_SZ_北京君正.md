# 300223.SZ 深度透视

## 因果逻辑链
- **[AI基建爆发与存储大厂产能转移]** -> [存储芯片进入“超级周期”]: 三星、美光、海力士将产能转向HBM，挤压传统DRAM（DDR4/LPDDR4）产能，导致公司利基型DRAM产品供不应求、价格持续上涨。
- **[存储超级周期传导]** -> [2025年Q4存储收入同比大增29.5%]: 行业周期滞后于消费类市场，但下半年公司DRAM产品价格上调，客户需求激增，带动Q4业绩显著加速。
- **[汽车、工业市场复苏]** -> [存储芯片全年收入同比增长12.43%]: 下游行业库存恢复至正常水平，公司车规级SRAM、DRAM、NOR Flash需求回暖，全年收入稳健增长。
- **[AI向端侧渗透与AOV市场兴起]** -> [计算芯片收入同比增长18.65%]: 公司提前布局AOV（全时录像）低功耗方案，并受益于AI在安防、智能家居等领域的普及，带动T33等新产品放量。
- **[新产品持续推出与工艺升级]** -> [存储与模拟芯片竞争力提升]: 20nm/18nm/16nm DRAM量产、2Gb车规NOR Flash量产、多款车规LED驱动芯片发布，丰富了产品矩阵，巩固了行业市场地位。
- **[全球化布局与海外客户拓展]** -> [境外收入占比82.67%，同比增长12.41%]: 公司在20多个国家设有分支机构，海外智能视觉客户导入初见成效，全球化销售网络支撑了收入增长。
- **[股权激励费用与资产增值摊销]** -> [净利润增速（+2.74%）远低于收入增速（+12.54%）]: 新增股权激励费用5455万元及收购资产增值摊销3965万元，合计近亿元的非现金成本严重侵蚀了利润弹性。

## 风险警告
**核心风险在于“存储超级周期”的不可持续性与利润率的双重挤压。** 当前业绩增长高度依赖AI基建引发的DRAM缺货涨价，这是典型的周期性红利而非结构性增长。一旦HBM产能扩张或下游需求放缓，公司面临量价齐跌的戴维斯双杀。同时，公司毛利率已同比下降2.65个百分点，上游晶圆、封测成本上涨与下游客户对涨价的接受度存在时间差，若成本压力持续而涨价空间收窄，毛利率将进一步承压。

**另一重大风险是商誉减值与研发投入的长期不确定性。** 公司账面商誉规模巨大，主要来自收购北京矽成。若存储周期逆转导致北京矽成经营恶化，将触发巨额商誉减值，直接冲击利润表。此外，3D DRAM、LPDDR5、更高算力SoC等前沿项目研发投入巨大且周期长，技术路线和商业化前景存在不确定性，若研发失败或市场不及预期，将造成资源浪费并拖累长期竞争力。
