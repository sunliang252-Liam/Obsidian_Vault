# 600360.SH 深度透视

## 因果逻辑链
- **[关联方资金占用利息收入]** -> [净利润大幅增长35.32%]: 2025年收到关联方资金占用利息约7196万元，成为非经常性损益最大来源，直接推高净利润。
- **[贷款规模下降与结构优化]** -> [财务费用由正转负]: 利息支出减少，叠加利息收入增加，财务费用从9096万降至-2080万，显著增厚利润。
- **[新能源汽车领域销售额翻倍]** -> [营收增长9.61%]: 在重卡电驱、OBC、充电桩等模组实现功率器件全面配套，成为核心增长引擎。
- **[IPM模块扩产增效]** -> [白电领域收入持续增长]: 变频空调、冰箱、洗衣机领域IPM产品产量大幅提升，与头部客户深度绑定。
- **[收回全部被占用资金及利息]** -> [投资活动现金流净额由负转正]: 收到关联方归还资金及利息合计15.67亿元，投资活动现金流净额达12.23亿元。
- **[偿还大量银行借款]** -> [筹资活动现金流大幅净流出]: 筹资活动现金流净额为-15.34亿元，主要系偿还债务支付的现金增加所致。
- **[控股股东变更为吉林省国资委]** -> [公司治理与内控根本性改善]: 原控股股东资金占用问题彻底解决，2025年内控审计报告获标准无保留意见，退市风险基本解除。

## 风险警告
**核心风险在于业绩增长的可持续性。** 2025年净利润高增长主要依赖一次性因素：关联方资金占用利息收入（约7196万元）和财务费用大幅下降（利息支出减少）。剔除这些非经常性损益后，扣非净利润仅增长11.54%，远低于归母净利润35.32%的增幅。随着资金占用问题彻底解决，未来将不再有此类利息收入，且贷款规模已大幅下降，财务费用进一步压缩空间有限，业绩增速面临显著回落压力。

**行业竞争与经营风险不容忽视。** 功率半导体行业竞争激烈，新兴资本介入加剧市场波动。公司产品毛利率同比下降1.75个百分点，且资产减值损失大幅增加至5469万元（主要为存货、固定资产减值），反映出产品价格压力与产能利用率波动风险。此外，公司客户集中度较高，前五大客户销售额占比达41.36%，对单一客户的依赖可能带来经营脆弱性。
