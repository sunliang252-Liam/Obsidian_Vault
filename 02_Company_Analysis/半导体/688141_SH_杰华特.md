# 688141.SH 杰华特 深度透视

## 因果逻辑链
- **[AI算力需求爆发 + 高端电源产品导入]** -> **营收大幅增长58.15%**: 多相控制器、DrMOS等产品成功进入主流服务器平台，推动计算与存储领域收入快速爬坡。
- **[新能源汽车智能化 + 车规级产品量产]** -> **汽车电子业务稳健增长**: 车规级DC-DC、LDO、高低边开关等产品在整车厂实现规模化量产，贡献核心增量。
- **[外延并购整合（天易合芯、领芯微等）]** -> **信号链产品线收入暴增1210%**: 通过并购引入传感器、信号链等产品，快速补全产品矩阵，带来并表收入增量。
- **[持续高强度研发投入 + 人员扩张]** -> **研发费用同比增长54.57%**: 研发人员增至1,202人（+54.9%），研发投入占营收36.06%，侵蚀当期利润。
- **[市场竞争激烈 + 产品均价承压]** -> **毛利率修复不及预期（26.37%）**: 营收高增但毛利率同比微降0.98个百分点，未能有效转化为利润。
- **[存货高企 + 计提大额减值]** -> **资产减值损失扩大**: 存货账面余额15.08亿元，跌价准备计提比例高达33.08%，严重拖累净利润。
- **[规模扩张 + 资本开支增加]** -> **经营现金流持续为负（-3.24亿）**: 研发、市场投入及存货占款导致现金流紧张，依赖外部融资（筹资净流入7.14亿）。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收虽爆发式增长58%，但毛利率仅26.37%且持续承压，同时研发、销售、管理费用因规模扩张和并购整合全面飙升，导致亏损扩大至-7.17亿元。更严峻的是，存货跌价准备高达4.99亿元（占存货余额33%），若下游需求放缓或产品迭代加速，巨额存货减值将持续吞噬利润，现金流亦因高额资本开支和营运资金占用而持续为负。

**战略扩张的财务反噬风险不容忽视。** 公司通过大规模并购（产生商誉3.63亿元）和对外投资（长期股权投资增266%）快速拓展版图，但整合效果尚待验证。高额商誉存在减值风险，且并购带来的无形资产摊销和递延所得税负债（增944%）将长期压制利润表。同时，资产负债率因借款激增（长短期借款合计增85%）而快速攀升，财务杠杆放大经营波动风险。
