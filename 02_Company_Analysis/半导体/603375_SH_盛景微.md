# 603375.SH 深度透视

## 因果逻辑链
- **[民爆行业价格战加剧]** -> [毛利率下滑]: 下游客户为抢占市场份额压低采购价，价格压力向上游传导，导致公司产品销量与单价承压，毛利率同比减少3.85个百分点。
- **[电子控制模块量升价跌]** -> [营收下降]: 尽管电子控制模块销量同比增长5.62%，但价格下降导致该产品收入同比下降8.06%，拖累整体营收。
- **[信号链芯片业务高增]** -> [收入结构优化]: 子公司上海先积放大器产品收入同比增长72.53%，占主营业务收入比例提升6.08个百分点，成为第二增长曲线。
- **[加强回款管理]** -> [经营现金流大幅转正]: 公司加强应收账款回款管理，叠加应收票据到期兑付，经营活动现金流净额由-1.07亿元大幅转正至0.68亿元。
- **[计提存货跌价损失增加]** -> [资产减值损失扩大]: 因市场需求变化及预测偏差，存货跌价损失同比增加65.37%，侵蚀当期利润。
- **[一次性资产处置收益]** -> [非经常性损益支撑利润]: 出售上海先积ASSP业务产生一次性资产处置收益594.94万元，是扣非净利润为负的情况下仍实现正净利润的关键。
- **[研发投入聚焦前沿技术]** -> [构筑长期护城河]: 研发费用占营收15.95%，集中攻坚无线电子雷管、无点火药技术，并成功应用国内首套全无线爆破系统，为未来技术迭代储备动能。

## 风险警告
**核心风险在于民爆主业的价格战未见底。** 公司2025年归母净利润暴跌55.81%，扣非净利润更是由盈转亏（-712万元），直接原因是下游客户为抢占市场份额持续压低采购价。尽管公司销量微增，但“量升价跌”的格局导致毛利率大幅下滑。在行业集中度加速提升、产能过剩的背景下，价格竞争可能持续恶化，公司盈利能力面临长期挑战。

**第二增长曲线尚在培育期，短期难以对冲主业下滑。** 信号链芯片业务虽增长迅猛，但体量尚小（放大器收入占主营收入13.6%），且子公司上海先积仍处于亏损状态（净亏损533万元）。同时，海外业务、低空经济等新布局仍处于投入期，短期内无法贡献利润。公司当前利润高度依赖非经常性损益（如资产处置收益），主业造血能力已严重受损。
