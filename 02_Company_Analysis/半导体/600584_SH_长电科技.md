# 600584.SH 深度透视

## 因果逻辑链
- **国内市场需求回暖及国产替代** -> **营收增长8.09%**: 国内工厂销售增长，拉动整体收入至388.71亿元，但境外收入占比仍高达78.6%。
- **国际贵金属价格大幅上升** -> **毛利率承压**: 原材料成本上升，叠加新建工厂产能爬坡期，导致主营业务毛利率仅13.95%，利润增速远低于营收。
- **新建工厂处于产品导入期** -> **短期利润表现承压**: 长电微电子、长电汽车电子等新工厂尚未形成大规模量产收入，报告期合计亏损超2.3亿元。
- **财务费用激增154.86%** -> **侵蚀净利润**: 主要因利息收入下降及汇兑损失，财务费用从1.43亿升至3.65亿元，是扣非净利润下滑11.51%的主因之一。
- **研发投入增长21.37%** -> **夯实先进封装技术壁垒**: 研发投入20.86亿元，聚焦2.5D/3D、CPO、Chiplet等，XDFOI®平台已量产，为未来高附加值业务奠基。
- **运算电子领域营收增长42.6%** -> **业务结构向高附加值优化**: AI、HPC需求驱动运算电子成为增长最快板块，占比提升至21.3%，对冲了传统消费电子的疲软。
- **收购晟碟半导体并表** -> **增强存储封测能力**: 完成对全球闪存封测领先者晟碟半导体的收购，贡献营收36.2亿元，但受原材料供应紧张影响，利润有所下降。

## 风险警告
**核心风险在于“增收不增利”的困境与高资本开支下的现金流压力。** 尽管营收增长8%，但扣非净利润同比下滑11.51%，主因是原材料成本飙升、新工厂爬坡亏损及财务费用激增。公司正处于大规模产能扩张期（资本开支62.98亿元），导致经营活动现金流净额下降20.26%，投资活动现金净流出高达90.56亿元，对财务稳健性构成考验。

**地缘政治与同业竞争风险不容忽视。** 公司境外收入占比近八成，国际政策不确定性可能导致设备、原材料短缺及海外订单流失。同时，实际控制人中国华润旗下存在同业竞争企业，虽已承诺五年内解决，但具体方案和时间表尚不明确，构成潜在的治理与业务整合风险。
