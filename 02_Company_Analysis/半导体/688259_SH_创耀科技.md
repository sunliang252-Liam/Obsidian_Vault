# 688259.SH 深度透视

## 因果逻辑链
- **[接入网业务营收大幅下滑]** -> [总营收下降38.89%]: 下游客户需求放缓，公司对单一大客户依赖度高，导致接入网芯片及解决方案业务收入同比骤降48.74%，拖累整体营收。
- **[研发费用固定摊销减少]** -> [归母净利润增长30.62%]: 公司实施降本增效，研发投入同比下降25.70%，叠加政府补助增加和信用减值损失转回，使净利润在营收大降时逆势增长。
- **[非经常性损益高企]** -> [扣非净利润下降40.72%]: 归母净利润增长主要依赖政府补助（5341万）等非经常性损益，剔除后核心业务盈利能力大幅恶化。
- **[电力线载波双模芯片份额提升]** -> [通信芯片毛利率增长8.25个百分点]: 国网/南网通信标准全面升级至双模，公司技术提前布局，高毛利产品占比提升，对冲了低毛利接入网业务萎缩的影响。
- **[星闪与EtherCAT芯片量产]** -> [新业务增长点初步形成]: 公司星闪芯片已应用于机顶盒、割草机等终端，EtherCAT从站芯片实现工业/医疗客户销售，但体量尚小，未能弥补主业下滑。
- **[存货增加34.94%]** -> [资产减值风险上升]: 电力线载波芯片库存同比增长38.26%，下游招投标节奏波动导致备货积压，公司已计提345.77万元资产减值损失。
- **[供应商集中度极高]** -> [供应链依赖风险]: 前五大供应商采购额占比88.28%，Fabless模式下晶圆代工和封测高度集中，若产能受限或合作关系紧张，将直接影响生产交付。

## 风险警告
**核心风险在于接入网业务的结构性衰退与盈利质量恶化。** 公司营收同比暴跌38.89%，扣非净利润更是下滑40.72%，表明核心主业已陷入深度调整。接入网业务对单一大客户依赖度过高，在海外电信运营商资本开支放缓的背景下，短期内难以找到同等体量的替代市场。虽然电力线载波双模芯片份额提升，但该业务受国网/南网采购周期影响，同样存在周期性波动风险，无法完全对冲接入网的下滑。

**公司利润高度依赖非经常性损益，可持续性存疑。** 2025年归母净利润中，政府补助高达5341万元，占净利润的67.6%。若未来政府补助政策变化或项目验收节奏调整，公司净利润将面临大幅回撤风险。同时，公司存货激增34.94%，且已出现减值迹象，若下游需求持续低迷，存货跌价损失将进一步侵蚀利润。此外，公司研发投入虽下降，但研发费用率仍高达25.55%，高额研发支出与营收下滑之间的矛盾，将长期考验公司的现金流与盈利能力。
