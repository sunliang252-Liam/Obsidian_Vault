## 因果逻辑链
- **[高性能计算电源芯片（DrMOS）突破]** -> [收入同比+122.26%]: 公司第二代DrMOS性能提升、成本下降，成功切入AI显卡/服务器供应链，带动海外客户规模出货。
- **[电机控制驱动芯片（凌鸥创芯）全资控股]** -> [收入同比+25.95%，毛利率提升2.11pct]: 完成对凌鸥创芯100%控股，在电动出行、清洁电器等中高端市场持续渗透，车规级MCU实现量产突破。
- **[第六代高压BCD-700V工艺量产]** -> [LED照明驱动芯片毛利率提升2.43pct]: 自主工艺迭代显著降低单位制造成本，在通用LED市场量价齐跌背景下，通过成本优化维持盈利韧性。
- **[“无VCC电容”专利技术壁垒]** -> [小家电AC/DC电源收入增长30.40%]: 该专利方案精简外围、降低成本，在九阳、小米等头部品牌份额提升，形成差异化竞争优势。
- **[收购易冲科技（已完成过户）]** -> [拓展无线充电与车规级产品线]: 易冲科技在无线充电、协议芯片领域与公司形成高度互补，协同效应有望在2026年释放。
- **[研发费用率维持高位（24.58%）]** -> [短期压制利润，但构筑长期技术护城河]: 高研发投入支撑多相控制器、DrMOS、车规级MCU等新品迭代，是公司从LED照明向高性能计算转型的核心驱动力。
- **[股权激励费用冲回]** -> [归母净利润扭亏为盈]: 部分激励计划业绩条件未达标及员工离职，导致股份支付费用冲回，对2025年利润表产生正向影响。

## 风险警告
**核心风险在于高性能计算电源芯片的毛利率骤降与竞争加剧。** 该业务收入虽增长122%，但毛利率从61.19%暴跌至37.04%，降幅达24.15个百分点。这反映出公司为抢占AI服务器/显卡市场，采取了激进的定价策略或面临激烈的价格战。若后续无法通过技术迭代或规模效应修复毛利率，该业务将陷入“增收不增利”的困境，无法成为真正的利润引擎。

**商誉与无形资产减值风险不容忽视。** 公司通过多次并购（凌鸥创芯、易冲科技）扩张版图，账面积累了较大规模的商誉与无形资产。若未来宏观经济下行或下游需求不及预期，导致被收购标的业绩承诺无法兑现，将面临大额减值风险，直接冲击当期利润。此外，公司对参股公司的股权投资公允价值波动（报告期内确认-3,079万元）也构成潜在的财务扰动。
