# 688213.SH 深度透视

## 因果逻辑链
- **[智能手机高端化突破]** -> [营收增长51.32%]: 基于Lofic HDR®2.0技术的5000万像素主摄产品出货量大幅上升，中高端HS系列量产出货，推动智能手机收入达46.75亿元，同比增长43.03%。
- **[汽车电子跨越式增长]** -> [第二增长曲线成型]: 应用于智能辅助驾驶（环视、周视、前视）和舱内等新一代产品出货量同比大幅上升，推动汽车电子收入达11.22亿元，同比增长113.02%。
- **[安防基本盘稳固]** -> [营收压舱石]: 蝉联全球安防CIS出货量第一，高端安防和智能家居份额持续提升，智慧安防及AIoT收入24.88亿元，同比增长52.38%。
- **[AI智视生态拓展]** -> [打开新增长空间]: 机器视觉、新消费类影像、AI眼镜等业务收入7.45亿元，同比增长38.12%，子公司飞凌微布局端侧AI ASIC，构建“视觉AI-AI互连-端侧AI ASIC”技术生态。
- **[规模效应显现]** -> [净利润暴增154.94%]: 营收大幅增长51.32%的同时，毛利率提升2.57个百分点至23.66%，带动归母净利润从3.93亿跃升至10.01亿元。
- **[应收账款激增]** -> [现金流承压]: 为拓展手机等大客户业务给予60-120天账期，导致年末应收账款同比增长235.58%至20.45亿元，经营活动现金流净额同比大降71.19%至1.08亿元。
- **[特别表决权结构]** -> [控制权高度集中]: 创始人徐辰持股13.67%，但通过5倍表决权差异安排，实际控制44.13%的表决权，对公司重大决策有决定性影响。

## 风险警告
**现金流与应收账款风险**：公司2025年净利润暴增154.94%，但经营活动现金流净额却大降71.19%至仅1.08亿元，与利润严重背离。核心原因是公司为抢占手机及汽车电子市场份额，给予大客户（小米、OPPO、比亚迪等）长达60-120天的账期，导致应收账款同比飙升235.58%至20.45亿元。尽管公司声称截至年报公布日已收回91%，但如此激进的信用政策在行业景气度下行或客户经营恶化时，将直接引发大规模坏账和流动性危机。

**供应链与客户集中度风险**：作为Fabless设计公司，前五大供应商采购额占比高达89.90%，其中前两大供应商（台积电、合肥晶合等）占比超71%，晶圆代工高度依赖少数几家厂商。同时，前五大客户销售额占比49.07%，客户集中度较高。一旦地缘政治导致供应链中断，或核心客户（如海康威视、比亚迪）自研CIS或切换供应商，公司营收将遭受重大冲击。此外，公司存在特别表决权结构，创始人徐辰以13.67%的持股控制44.13%的表决权，中小股东难以制衡，治理风险不容忽视。
