# 688766.SH 深度透视

## 因果逻辑链
- **[行业景气度回升+AI需求爆发]** -> [营收创历史新高]: 2025年受益于存储芯片市场产业趋势及AI服务器、高端手机等终端需求集中释放，公司全年营收23.20亿元，同比+28.62%。
- **[“存储+”战略推进+并购SHM]** -> [产品线扩张与市场份额提升]: MCU及模拟产品营收同比+37.91%，出货量同比+68.18%；11月并购SHM贡献约2.1亿元营收，新增SLC NAND、eMMC等产品线。
- **[市场竞争加剧+成本传导滞后]** -> [毛利率承压]: 产品价格承压，成本端未显著回落，导致整体毛利率同比减少5.19个百分点，毛利增长不及营收增速。
- **[积极备货策略+并购并表]** -> [存货高企与减值风险]: 存货账面价值12.56亿元，同比+74.92%，计提资产减值损失同比增加约6,254万元，侵蚀利润。
- **[研发高强度投入+团队扩张]** -> [期间费用大幅增长]: 研发费用同比+22.86%，销售费用+49.02%，管理费用+51.51%，合计增加约1.14亿元，显著拖累净利润。
- **[并购SHM确认非经常性收益]** -> [净利润与扣非净利润背离]: 并购产生投资收益及营业外收入约4,677万元，导致归母净利润2.08亿元（-29.03%）与扣非净利润1.65亿元（-38.67%）差距扩大。
- **[汇率波动+宏观降息]** -> [财务费用由负转正]: 利息收入及汇兑收益同比减少1,416万元，财务费用同比增加，对利润产生负面影响。

## 风险警告
公司当前面临的核心矛盾是“增收不增利”。营收创历史新高，但归母净利润同比下滑29%，扣非净利润更是下滑近39%。根源在于毛利率被侵蚀（-5.19pct）与期间费用（研发、销售、管理）的刚性膨胀，两者共同挤压了利润空间。存货激增至12.56亿元，计提大额减值，若下游需求转弱，将进一步冲击业绩。并购SHM带来的非经常性收益掩盖了主营业务的真实盈利能力，需警惕其不可持续性。

此外，公司对单一晶圆供应商（采购额占比55.37%）和基础工艺授权（SONOS授权至2038年）存在高度依赖，供应链集中风险与核心技术授权到期风险是长期隐患。MCU及模拟产品尚处起步阶段，面临国际大厂的激烈竞争，市场导入和盈利能力存在不确定性。并购后的整合风险（文化、团队、管理）亦不容忽视，若协同效应不及预期，将拖累整体表现。

**公司简介（F10 原文）**

> 普冉半导体(上海)股份有限公司成立于2016年,总部位于上海张江高科,在深圳、韩国设有销售和现场应用服务与支持中心,同时在苏州设有研发中心;在日本、英国、德国等多地拥有代表处。2021年8月,公司在上海证券交易所科创板上市,股票代码688766。公司目前主要产品包括NOR Flash和EEPROM两大非易失性存储器芯片、微控制器芯片及模拟产品。产品广泛应用于物联网、智能手机及周边、可穿戴、服务器、光模块、工业控制、汽车电子、安防等领域。公司聚焦领先的非易失性存储器芯片,凭借超低功耗和高可靠性的产品优势,积累了良好的品牌认可度,成为全球NORFlash和EEPROM的主要供应商之一。公司产品广泛应用于三星、OPPO、vivo、小米、联想、惠普、亚马逊、美的、海内外汽车客户等品牌厂商。基于存储器技术优势,公司于2021年推出“存储+”战略,积极拓展MCU及模拟芯片领域,依托公司在存储领域的技术优势和平台资源,实现向更高附加值领域和更多元化的市场拓展。与此同时,公司大力推进海外业务布局,坚定国际化战略路线,已经实现在日、韩、美等多家知名大客户导入,产品应用领域覆盖消费、工控、光伏及车载等,增强了在全球市场的影响力。公司以“普冉之芯,造福世界”的愿景,专注于产品创新,围绕非易失存储器领域,在继续完善和提升非易失性存储器产品线的同时,有效推进“存储+”战略,实现微控制器和模拟产品线的高速发展,不断满足客户对高性能芯片产品的需求,在持续经营中实现企业的技术积累,保障公司经营业务的可持续发展。
