# 688486.SH 深度透视

## 因果逻辑链
- **[国产替代加速]** -> [营收增长21.93%]: 公司作为视频桥接芯片国内龙头，受益于下游客户对国产高速混合信号芯片的采购倾斜，市场份额持续提升。
- **[车载业务放量]** -> [第二增长曲线形成]: 19颗车规级芯片通过AEC-Q100认证，车载SerDes芯片组进入全面推广阶段，带动车载高速互连业务收入占比显著提升。
- **[高研发投入构筑壁垒]** -> [扣非净利润增长29.64%]: 研发投入占营收19.93%，持续迭代ClearEdge技术平台，产品性能对标国际巨头，高附加值产品占比提升，盈利能力增强。
- **[Fabless轻资产模式]** -> [高ROE与现金流]: 专注芯片设计，将制造环节外包，资产周转率高，经营活动现金流净额1.12亿元，与净利润匹配良好，财务结构健康。
- **[“A+H”双平台布局]** -> [国际化战略提速]: 启动H股上市，旨在借助香港资本市场拓宽融资渠道、提升国际品牌影响力，为全球化运营和人才吸引提供支撑。
- **[高分红政策]** -> [股东回报明确]: 2025年拟每10股派发现金红利10.40元，现金分红比例高达80.13%，彰显公司对股东回报的重视及对未来现金流的信心。
- **[产品矩阵丰富]** -> [应用场景多元化]: 拥有超200款芯片型号，覆盖智能视觉终端、智能车载、AR/VR、AI&HPC四大核心场景，有效分散单一市场风险，拓宽增长空间。

## 风险警告
**供应链与客户集中度双高风险。** 公司采用Fabless模式，前五大供应商采购额占比高达90.59%，且晶圆代工和封测主要依赖境外厂商（Silterra、联华电子、超丰电子）。同时，前五大客户销售额占比达52.25%。这种“两头在外”的格局，使其业绩极易受到上游产能波动、贸易摩擦及下游客户采购策略变化的双重冲击，供应链韧性是未来持续增长的关键变量。

**技术迭代与市场竞争加剧风险。** 公司所处的混合信号芯片领域技术壁垒高，但竞争格局由TI、ADI等国际巨头主导。公司虽在视频桥接细分赛道取得领先，但整体规模、研发实力、客户资源与海外龙头仍有差距。若公司技术迭代速度不及预期，或本土竞争对手在细分领域实现突破，可能导致产品价格承压、毛利率下滑，进而影响市场地位和盈利能力。
