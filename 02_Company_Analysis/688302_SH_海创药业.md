# 688302.SH 深度透视

## 因果逻辑链
- **[核心产品获批上市]** -> [营业收入暴增5480%]: 首款新药氘恩扎鲁胺软胶囊（海纳安®）于2025年5月获批，报告期内实现药品销售收入2019.25万元，驱动营收从36.7万元跃升至2047万元。
- **[研发管线聚焦与优化]** -> [研发费用同比减少35.24%]: 公司主动聚焦核心产品开发，合理规划研发投入，导致研发费用从1.74亿元降至1.13亿元，亏损同比收窄31.2%。
- **[商业化前期投入]** -> [销售费用激增232%]: 为推进海纳安®上市后的市场准入、学术推广和团队扩建，销售费用从1135万元增至3769万元，导致公司短期内仍无法盈利。
- **[产品纳入国家医保]** -> [未来放量可期但短期价格承压]: 海纳安®于2025年12月纳入国家医保目录（2026年1月执行），将显著提升患者可及性，但医保谈判导致价格大幅下降，并在2025年Q4引发经销商库存价格补差，导致单季营收为负。
- **[氘代技术平台成功转化]** -> [验证研发模式可行性]: 氘恩扎鲁胺的成功上市，标志着公司“氘代药物研发平台”从技术储备到商业化落地的闭环验证成功，为后续管线（如PROTAC）提供了可复用的研发与商业化路径。
- **[PROTAC管线临床推进]** -> [构建下一代技术壁垒]: 核心PROTAC药物HP518（国内首个口服AR PROTAC）已完成中国II期入组，并获FDA快速通道认定，若成功上市，有望解决前列腺癌耐药性难题，打开新的增长空间。

## 风险警告
**核心风险在于单一产品依赖与商业化不确定性。** 公司目前仅有一款产品海纳安®上市，且处于商业化初期。尽管已纳入医保，但面临与已上市原研药（如恩扎卢胺）及未来仿制药的激烈竞争。2025年Q4因医保降价导致的经销商补差和退货，已暴露出价格政策对营收的短期冲击。若市场推广、医院准入或医生处方习惯培养不及预期，公司可能长期无法通过单一产品实现盈利，持续依赖外部融资。

**财务风险高企，现金流压力巨大。** 公司尚未盈利且累计未弥补亏损持续扩大。截至2025年末，营运资金主要依赖外部融资，经营活动现金流净额为-1.09亿元。虽然账上货币资金及金融资产合计约7.5亿元，但考虑到研发、商业化及生产基地建设的持续高投入，资金消耗速度极快。若未来融资环境恶化或产品放量不及预期，公司将面临营运资金不足、被迫削减研发项目的风险，进而动摇其长期竞争力。
