# 300030.SZ 深度透视

## 因果逻辑链
- **[收缩聚焦战略与费用管控]** -> [净利润扭亏为盈]: 公司主动收缩非核心业务、精简人员、严控费用，期间费用总额大幅削减，对冲了收入下滑的影响，实现归母净利润1,453万元（+112.32%）。
- **[参股公司公允价值变动]** -> [投资收益大幅增长]: 参股公司深圳阳和持有的伟思医疗股票公允价值变动收益增加，使公司投资收益达2,048万元（+336.75%），成为利润转正的关键非经常性因素。
- **[集采常态化与市场竞争]** -> [核心产品收入下滑]: 真空采血系统收入同比下降10.81%，试剂收入下降31.67%，主要受医用耗材集采扩围及市场竞争加剧影响，产品价格承压。
- **[主动放弃低利润集采订单]** -> [短期收入承压但维护毛利率]: 对于限价低于成本底线的集采项目，公司主动放弃，导致部分收入流失，但核心产品真空采血系统毛利率同比提升1.24%，维护了盈利底线。
- **[研发聚焦与人员精简]** -> [研发投入下降但效率提升]: 研发人员数量同比减少41.10%，研发投入同比下降25.85%，但公司集中资源于高附加值新品（如全自动血栓弹力图仪），旨在为未来集采竞争提供产品支撑。
- **[低效资产出清]** -> [资产结构优化与减亏]: 注销广州瑞达等亏损子公司，加速低效资产处置，多家子公司实现显著减亏，合并报表层面资产减值损失大幅减少。
- **[经营活动现金流改善]** -> [财务风险降低]: 经营活动现金流净额同比上升34.29%至1.1亿元，主要得益于费用支付减少，同时公司主动降低贷款规模，财务费用下降47.65%，偿债压力减轻。

## 风险警告
公司核心主业面临集采常态化下的量价双重压力。真空采血系统及试剂收入连续下滑，尽管通过策略性竞标维护了部分份额，但若集采范围进一步扩大或价格降幅超预期，公司“以价换量”策略可能失效，导致收入与毛利进一步萎缩。同时，公司净利润扭亏高度依赖参股公司公允价值变动收益，该收益具有不可持续性，主业盈利能力依然脆弱。

公司正处于战略收缩与转型期，研发人员大幅精简可能削弱长期技术储备。虽然公司计划通过并购重组切入细胞治疗等新赛道，但新业务尚处早期，存在研发失败、市场开拓不及预期等风险。此外，海外业务占比近30%，地缘政治、汇率波动及贸易保护主义抬头，可能对公司海外销售构成显著冲击。
