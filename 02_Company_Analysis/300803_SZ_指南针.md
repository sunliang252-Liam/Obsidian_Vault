# 300803.SZ 深度透视

## 因果逻辑链
- **[资本市场活跃度提升]** -> [金融信息服务收入增长27.5%]: 2025年A股成交额放大，公司付费用户规模与客单价同步提升，带动核心主业收入至15.09亿元。
- **[麦高证券经纪业务爆发]** -> [证券服务收入增长91.19%]: 公司向麦高证券导流客户，叠加市场交投活跃，经纪业务手续费净收入达4.87亿元，同比翻倍。
- **[收购先锋基金控股权]** -> [确认非经常性投资收益6554万元]: 收购后先锋基金纳入合并报表，公允价值重估产生一次性收益，是归母净利润与扣非净利润差异的核心来源。
- **[加大广告与品牌投入]** -> [销售费用增长38.09%]: 公司为抢占市场份额，大幅增加线上推广，销售费用达11.11亿元，但投产比保持健康，驱动新增用户显著增长。
- **[麦高证券客户资产扩张]** -> [代理买卖证券款增长52.72%]: 客户托管资产从66.24亿元增至101.15亿元，带动利息净收入增长32.61%，形成“资产-收入”正循环。
- **[股权激励持续实施]** -> [管理费用增长43.76%]: 2025年新推期权激励计划，叠加麦高证券业务扩张带来的人员薪酬增加，管理费用升至6.5亿元。
- **[先锋基金整合初期亏损]** -> [拖累合并报表净利润]: 先锋基金报告期内亏损2705万元，整合尚需时间，短期对整体盈利形成负贡献。

## 风险警告
**核心风险在于业绩对市场景气度的强依赖与双主业整合的不确定性。** 公司金融信息服务收入与A股成交额高度正相关，若市场转冷，付费用户转化率与客单价将同步承压，导致业绩剧烈波动。同时，麦高证券与先锋基金的整合均需持续投入，前者商誉高达12.86亿元，后者尚处亏损期，若业务协同不及预期，商誉减值与亏损扩大将直接侵蚀利润。

**此外，经营业绩分布不均衡是固有风险。** 公司采用“体验式”销售模式，中高端产品集中在少数月份销售，导致季度间利润波动极大（如2025年Q3净利润为-2656万元），单季度数据无法反映全年趋势，投资者需警惕短期业绩噪音。
