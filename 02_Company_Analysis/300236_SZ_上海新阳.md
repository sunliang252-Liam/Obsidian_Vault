# 300236.SZ 深度透视

## 因果逻辑链
- **[晶圆制造用关键工艺材料销量增长45%]** -> [半导体业务收入增长46.5%]: 下游晶圆厂产能扩张及国产替代需求旺盛，公司电镀液、清洗液、蚀刻液等核心产品订单量价齐升。
- **[蚀刻液技术突破（选择比达2000:1）]** -> [蚀刻液销售额增长超80%]: 原创开发的超高选择比氮化硅蚀刻液，精准匹配3D NAND存储芯片工艺升级需求，实现从替代到引领的跨越。
- **[清洗液产品14nm全覆盖]** -> [清洗液销售额增长超50%]: 技术节点全覆盖叠加客户验证顺利，在逻辑、模拟、存储等主流晶圆制造产线渗透率快速提升。
- **[CMP研磨液打破国外垄断]** -> [研磨材料销售额增长160%]: Poly slurry等产品进入国内主流晶圆厂产线，实现从0到1的突破，成为新的增长极。
- **[合肥新阳扩产及上海新基地建设]** -> [在建工程增长60%]: 为应对未来5年市场需求，提前布局产能，在建工程（合肥+上海）大幅增加，资本开支进入高峰期。
- **[股权激励与薪酬证券化]** -> [管理费用增长35%]: 实施多期股权激励计划，核心团队与公司利益深度绑定，但短期带来股份支付费用，推高管理费用。
- **[涂料业务受行业“内卷”影响]** -> [涂料收入下降4.5%，净利润下滑]: 传统涂料行业面临结构性调整，市场竞争加剧，公司涂料板块增长乏力，拖累整体业绩弹性。

## 风险警告
**1. 新产品研发与市场推广的双重不确定性。** 公司研发投入占营收比高达13.9%，聚焦于ArF浸没式光刻胶、先进制程蚀刻液等前沿领域。这些项目技术门槛极高，研发周期长，存在失败风险。即便研发成功，晶圆厂对材料供应商的认证周期漫长且严格，新产品能否顺利导入客户并形成规模化销售，存在重大不确定性，可能导致巨额研发投入无法转化为预期收益。

**2. 产能扩张与行业周期错配的风险。** 公司正大举投资合肥、上海等多个生产基地，资本开支显著增加。半导体行业具有周期性波动特征，若未来下游需求增速放缓或出现周期性下滑，公司新投产的产能可能面临利用率不足的风险，导致折旧等固定成本高企，侵蚀利润。此外，地缘政治博弈加剧，也可能影响下游客户的扩产节奏和采购意愿。
