# 603175.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长15.25%创历史新高]: 公司抓住AI服务器、HDI市场强劲增长机遇，产品结构优化，带动营收规模稳步增长。
- **[泰国工厂产能爬坡]** -> [净利润下降16.24%]: 泰国超颖处于产能爬坡阶段，产能利用率未达预期，生产成本高，全年亏损约2.16亿元，拖累整体盈利。
- **[原材料价格上涨]** -> [毛利率下降4.47个百分点]: 覆铜板、铜箔等主要原材料价格上行，叠加泰国厂初期成本，导致主营业务毛利率从18.87%降至14.40%。
- **[首次公开发行股票]** -> [净资产增长57.19%]: 2025年10月上市，募集资金净额约8.03亿元，大幅增厚股本和资本公积，优化资本结构。
- **[AI算力高阶PCB扩产项目]** -> [资本开支大幅增加]: 公司计划投资33.15亿元建设AI算力高阶PCB扩产项目，导致投资活动现金净流出15.11亿元，同比增加。
- **[优化债务结构]** -> [财务费用增长52.11%]: 公司增加长期借款以支持产能扩张，同时短期借款减少，利息支出增加导致财务费用上升至7229万元。
- **[高阶产品技术突破]** -> [巩固AI赛道竞争力]: 公司已完成M8、M9等级材料认证及50层以上高多层板技术储备，为承接AI服务器高端订单奠定基础。
- **[全球化产能布局]** -> [应对地缘政治风险]: 泰国工厂已量产并锁定高阶AI产品，满足欧美客户“第三地生产”要求，构建供应链韧性。

## 风险警告
**核心风险在于泰国工厂的盈利拐点不确定性。** 公司2025年净利润下滑16.24%，完全由泰国超颖的巨额亏损（-2.16亿元）导致。该工厂定位AI服务器及汽车电子高端产品，但产能爬坡速度、良率提升及客户认证进度均存在不确定性。若2026年下半年高阶AI产品量产不及预期，公司将持续面临“增收不增利”的困境，毛利率和ROE将进一步承压。

**另一重大风险是激进的资本开支与债务扩张。** 公司计划投资33.15亿元建设AI算力高阶PCB扩产项目，叠加泰国工厂仍在投入期，导致总资产增长24.19%的同时，长期借款激增199.61%至23.45亿元。财务费用已同比大增52.11%，未来若下游AI需求增速放缓或公司产能消化不力，高额的折旧与利息支出将严重侵蚀利润，现金流压力不容忽视。
