# 002307.SZ 深度透视

## 因果逻辑链
- **[新签合同额维持高位]** -> [营收增长10.79%]: 2025年新签合同额201.91亿元，支撑施工业收入同比增长12.12%，带动总营收突破113亿元。
- **[财务费用高企]** -> [持续亏损]: 财务费用高达11.76亿元，占营收10.4%，巨额利息支出侵蚀主业利润，导致归母净利润仍为-1.01亿元。
- **[资产处置与减值改善]** -> [亏损大幅收窄76%]: 通过向控股股东转让应收款项（1.2亿元）及出售河南禹亳铁路股权（2.43亿元），叠加减值损失减少，使亏损从-4.23亿缩至-1.01亿。
- **[经营性现金流大幅转正]** -> [现金流改善]: 经营活动现金流净额从-1.59亿跃升至9.34亿元，主要得益于加强回款及新项目预收款增加。
- **[高速公路运营贡献稳定]** -> [收入结构优化]: 7条高速公路中4条通车运营，累计223.16公里，贡献收费收入6.33亿元，成为稳定的经常性收入来源。
- **[多元化业务拓展]** -> [降低单一业务风险]: 成功中标矿建项目（13.65亿元）及光伏EPC项目，业务从传统路桥向新能源、矿业延伸。
- **[净资产大幅增长90.66%]** -> [资本结构改善]: 完成向特定对象发行股票，募集资金到位，净资产从30.17亿增至57.53亿元，显著降低资产负债率。

## 风险警告
公司核心风险在于**财务杠杆极高**。尽管2025年净资产因定增大幅增长，但总资产近600亿，有息负债规模庞大，财务费用超11.7亿，是持续亏损的根本原因。即便主业营收增长，利息支出仍严重侵蚀利润，公司盈利能力对利率变动极为敏感。

**主业造血能力依然薄弱**。剔除资产处置等非经常性损益后，扣非净利润为-1.12亿元，已连续两年为负。公司依赖“卖资产”和“融资”维持报表，而非依靠工程施工主业盈利。同时，高速公路运营子公司（如四川北新天曌）出现巨额亏损（-4.05亿），表明部分运营资产回报率不及预期，存在减值风险。
