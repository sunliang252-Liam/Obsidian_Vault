# 601112.SH 深度透视

## 因果逻辑链
- **[全球风电装机爆发式增长]** -> [营收同比+62.26%]: 2025年全球新增风电装机169GW创纪录，中国贡献核心增量，公司作为全球风电玻纤织物龙头（市占率>35%），直接受益于下游需求扩张。
- **[风电叶片大型化、轻量化趋势]** -> [拉挤型材销量国内前列]: 叶片长度突破80米后，拉挤型材替代传统真空灌注成为主梁核心构件，公司提前布局拉挤工艺，推动产品结构升级。
- **[光伏边框复合材料替代铝边框]** -> [光伏业务营收同比+824.15%]: 铝价上涨叠加低碳需求，复合材料边框成本低30-40%，公司获全球首张莱茵认证，产品渗透率快速提升。
- **[西班牙子公司投产并批量交付]** -> [成为首家在欧洲规模建厂的中资风电材料商]: 全球化布局从“贸易出口”升级为“产能+服务”本地化，突破贸易壁垒，直接服务维斯塔斯等欧洲客户。
- **[与中国巨石长期稳定合作]** -> [保障原材料供应与性能稳定性]: 前五大供应商采购占比66.04%，其中中国巨石占51.23%，深度绑定确保玻纤质量与成本优势，但亦构成单一供应商依赖风险。
- **[产业园全面投产与自动化改造]** -> [生产效能跃升]: 产业园单台设备日均产量提升18.7%，拉挤产线提速后人均产量+20%，光伏边框效率+30%，规模效应摊薄单位成本。
- **[碳纤维产品突破]** -> [可回收碳纤维叶片下线]: 纯碳织物、碳玻混拉挤板产销量突破2000吨，助力全球首款可回收碳纤维叶片，抢占下一代风电材料技术制高点。

## 风险警告
**核心风险在于对单一供应商的深度依赖与贸易政策的不确定性。** 公司前五大供应商采购占比超66%，其中中国巨石一家即占51.23%，且双方存在关联关系（实际控制人张健侃亦为中国巨石董事）。一旦合作关系生变或巨石产能受限，公司将面临原材料断供或价格大幅波动的系统性风险。此外，欧盟此前已对中国、埃及产玻纤织物征收反倾销税，美国关税政策反复，公司海外收入占比虽因国内爆发式增长而阶段性下降至14.7%，但西班牙、埃及等海外基地的盈利仍受地缘政治与汇率波动直接冲击。

**第二重风险来自清洁能源行业政策与需求的双重波动。** 公司超80%营收来自风电与光伏，而风电行业在2020年补贴退坡后已从政策驱动转向市场驱动，度电成本下降虽支撑长期需求，但短期装机节奏受电网消纳、特高压建设进度、储能配套等因素影响极大。2025年国内新增装机1.2亿千瓦已是历史峰值，若2026年并网瓶颈加剧或项目收益率下滑，下游客户可能推迟采购，导致公司高库存（存货同比+47.65%）与高应收账款（同比+33.11%）形成减值压力。
