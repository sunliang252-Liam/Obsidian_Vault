# 000736.SZ 深度透视

## 因果逻辑链
- **[重大资产重组（置出房地产开发业务）]** -> [公司彻底转型]: 2025年8月31日，公司将全部房地产开发业务及负债转让给控股股东，不再从事房地产开发，转型为轻资产运营公司。
- **[置出巨额亏损重资产]** -> [净资产由负转正]: 剥离亏损的房地产业务后，公司净资产从-35.79亿元跃升至12.08亿元，成功摘星脱帽。
- **[房地产业务毛利率为负]** -> [整体业绩巨亏]: 2025年房地产业务毛利率为-1.56%，导致全年归母净利润亏损17.10亿元，但亏损额同比收窄67%。
- **[轻资产业务规模扩张]** -> [营收增长但毛利率下滑]: 物业及资产管理收入同比增长43.37%至12.9亿元，但毛利率下降8.74个百分点，反映新业务尚处投入期，规模效应未释放。
- **[控股股东业绩承诺]** -> [未来利润保障]: 中交集团等承诺中交物业2025-2027年累计净利润不低于2.31亿元，为转型后的业绩提供兜底。
- **[央企信用背书与资源协同]** -> [轻资产拓展优势]: 依托中交集团“投建运管服”全产业链及信用优势，公司在获取城市运营、数据中心等非住宅物业项目上具备独特竞争力。
- **[资金储备充裕]** -> [支撑新业务投资]: 重组后公司货币资金10.58亿元，无有息负债，为轻资产业务的市场化拓展和并购提供了充足的“弹药”。

## 风险警告
**转型阵痛与业绩不确定性。** 公司从重资产开发商彻底转型为轻资产运营商，但新业务（物业、资管）尚处投入期，毛利率下滑明显，规模效应远未释放。尽管有控股股东2.31亿元的业绩承诺兜底，但若市场化拓展不及预期或成本控制失效，公司可能面临新主业盈利能力薄弱的困境，难以支撑当前市值。

**关联交易依赖与独立性风险。** 公司转型后，业务高度依赖控股股东中交房地产集团及中交集团的资源输送（如项目托管、关联交易）。虽然短期内能保障业务来源，但长期来看，若无法建立独立、市场化的业务获取能力，公司可能沦为集团内部的“服务部门”，其估值逻辑将受限于关联交易的公允性与持续性。
