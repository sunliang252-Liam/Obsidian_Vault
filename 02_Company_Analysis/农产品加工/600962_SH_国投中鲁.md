# 600962.SH 深度透视

## 因果逻辑链
- **美国关税高企** -> **外销销量下降11.95%**: 2025年中国浓缩苹果汁出口美国关税一度高达170%，虽年末降至35%但仍高于竞争产区，严重削弱价格竞争力，导致公司外销收入同比减少11.95%。
- **内销市场爆发式增长** -> **营收基本持平**: 面对外销受阻，公司大力开拓国内市场，内销收入同比暴增61.49%，成功对冲外销下滑，使总营收仅微降0.15%。
- **原料苹果价格下降** -> **毛利率提升1.25个百分点**: 原料成本同比下降12.77%，是营业成本降幅（-1.59%）大于营收降幅（-0.15%）的核心原因，直接推动主营业务毛利率从15.25%提升至16.50%。
- **远期结售汇公允价值变动** -> **非经常性损益大幅增加**: 报告期内美元远期结汇合约公允价值变动收益455万元，是导致归母净利润增速（39.88%）远超扣非净利润增速（16.65%）的关键。
- **销售回款改善** -> **经营性现金流由负转正**: 2025年销售商品收到现金22.68亿元，同比大增31.18%，使经营活动现金流净额从-2.83亿元大幅逆转至+2.42亿元，财务质量显著改善。
- **重大资产重组推进** -> **管理费用激增16.55%**: 因筹划注入国投集团电子信息产业资产，中介机构费用及员工薪酬增加，导致管理费用同比增加1546万元，侵蚀部分利润。
- **汇率波动** -> **财务费用飙升74.68%**: 人民币汇率变动导致汇兑净收益同比减少，财务费用从2302万元增至4021万元，成为利润增长的最大拖累项。

## 风险警告
**核心风险在于美国关税政策的不确定性。** 尽管关税已从170%高点回落至35%，但仍显著高于欧洲、智利等竞争对手，公司外销业务持续承压。更危险的是，中美贸易关系反复无常，关税随时可能再次上调，这直接威胁公司近15亿的国际市场收入基本盘。公司通过内销增长对冲，但内销毛利率仅10.24%，远低于外销的18.74%，以量换价策略难以持续提升盈利能力。

**重大资产重组存在整合与转型双重风险。** 公司拟注入电子信息产业资产，彻底脱离浓缩果汁主业。这既是机遇，也意味着公司将进入一个完全陌生的高科技领域。重组能否顺利获批、新业务能否与原有管理体系融合、以及新注入资产的盈利承诺能否兑现，均存在重大不确定性。若重组失败或整合不及预期，公司可能面临主业萎缩、新业务未立的尴尬境地。
