# 600251.SH 深度透视

## 因果逻辑链
- **[棉花及棉籽业务扭亏为盈]** -> [净利润大增70%]: 市场行情回暖，棉花及棉籽深加工业务利润较上年明显增长，成为利润核心增量。
- **[番茄产业量价齐跌]** -> [营收下降28.4%]: 国际贸易环境影响，番茄产品出口量及销售价格均下降，导致番茄产业营业收入大幅下滑。
- **[存货跌价准备大幅减少]** -> [利润改善]: 番茄产业市场价格跌幅放缓，大包装番茄制品产量及单位成本下降，计提的存货跌价准备较上年大幅减少。
- **[国投罗钾等战略股权贡献稳定收益]** -> [利润“稳定器”]: 参股国投罗钾（20.3%）、开都河水电（25.28%）等，投资收益稳定可观，是公司重要的利润支柱。
- **[套期保值业务对冲风险]** -> [减少价格波动影响]: 公司审慎运用商品及外汇衍生品进行套期保值，报告期内衍生品与现货盈亏相抵后净收益6595.02万元，有效对冲了原料及产品价格波动风险。
- **[销售费用激增]** -> [侵蚀利润]: 电商平台投流等宣传费增加，导致销售费用同比大增84.82%，对利润形成一定侵蚀。
- **[经营活动现金流大幅减少]** -> [现金压力]: 营收下降及收到的税收返还减少，导致经营活动现金流入减少幅度大，经营活动产生的现金流量净额同比减少79.52%。

## 风险警告
公司核心风险在于**番茄产业的持续低迷**。全球番茄制品库存高企，价格低位震荡，公司番茄产品出口量价齐跌，导致营收大幅下滑。尽管行业有减产去库存的趋势，但短期价格修复动力不足，且国内同质化竞争激烈，番茄产业盈利能力恢复存在较大不确定性。同时，公司销售费用因电商推广激增，进一步压缩了利润空间，需关注其投入产出效率。

另一重大风险是**原料供应与价格波动**。公司三大主业均依赖新疆农产品，易受极端天气、病虫害及农业政策（如棉花种植面积调减）影响，导致原料减产或成本上升。此外，棉花、白糖等大宗商品价格受全球供需、地缘政治及贸易政策影响，波动剧烈。公司虽运用套期保值工具对冲风险，但若市场出现极端行情或操作失误，仍可能对公司盈利造成重大冲击。
