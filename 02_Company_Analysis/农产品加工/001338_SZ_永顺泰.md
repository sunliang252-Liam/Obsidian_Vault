# 001338.SZ 深度透视

## 因果逻辑链
- **[产销量逆势增长]** -> [营收下降8.29%]: 尽管产量(110.44万吨)和销量(110.34万吨)均创历史新高，但麦芽销售价格随原材料大麦价格下行而降低，导致“量增价减”，营收同比下降。
- **[原材料成本下降]** -> [毛利率微增0.09个百分点]: 直接材料成本同比下降10.79%，降幅大于营收降幅，使得主营业务成本率下降，毛利率从12.60%提升至12.69%。
- **[境外市场扩张]** -> [对冲国内需求下滑]: 境外地区营收同比增长9.27%，占比提升至41.29%，有效弥补了国内华南(-19.80%)、西南(-48.40%)等区域市场的收入缺口。
- **[贸易融资安排]** -> [经营现金流与净利润背离]: 经营活动现金流净额(15.6亿)远高于净利润(2.37亿)，主因是银行贸易融资直接支付货款，该部分未计入现金流，导致现金流表现优于账面利润。
- **[高端化与定制化]** -> [巩固客户粘性与溢价能力]: 公司为百威、华润等客户提供定制化麦芽产品，并拥有结晶麦芽等特种麦芽，在啤酒高端化趋势下，维持了与头部客户的长期战略合作。
- **[产能布局优化]** -> [提升运营效率与市场覆盖]: 宝麦5万吨特制麦芽生产线项目试投产，新增高端产能，叠加沿海港口布局，强化了“以销定产、满销满产”的交付能力。
- **[外汇套期保值]** -> [控制汇率风险]: 通过远期外汇合约锁定购汇成本，虽产生公允价值损失(363万元)，但有效对冲了美元采购带来的汇率波动风险。

## 风险警告
**核心风险在于原材料价格与下游需求的剪刀差。** 公司80%的成本来自进口大麦，其价格受全球供需、地缘政治及贸易政策影响剧烈波动。2025年虽受益于原材料降价，但若未来大麦价格反弹，而下游啤酒客户因消费疲软无法接受提价，公司毛利率将面临被快速压缩的风险。此外，公司营收已连续两年下滑，国内啤酒产量见顶的长期趋势构成根本性挑战。

**另一重大风险是客户集中度与行业竞争。** 前五大客户贡献了62.39%的营收，其中第一大客户占比27.35%，议价能力极强。同时，中粮麦芽等竞争对手的产能扩张和设备升级，可能加剧行业“内卷”，削弱公司作为亚洲第一的规模优势。公司需警惕在“量增价减”的循环中，陷入增收不增利的困境。
