# 600127.SH 深度透视

## 因果逻辑链
- **[资产置换剥离贸易业务]** -> [营收骤降27.43%]: 2024年11月置出3家饲料贸易子公司（上年贡献14.87亿收入），导致2025年贸易收入同比减少76.62%，营收从46.27亿降至33.58亿。
- **[聚焦主业与费用管控]** -> [净利润增长69.28%]: 剥离低毛利贸易业务后，综合毛利率从5.75%提升至7.69%；同时优化融资渠道，财务费用同比减少42.29%，最终归母净利润从223万增至377万。
- **[休闲食品渠道革命]** -> [新中意公司成功扭亏]: 通过“产品创新+渠道革命”双轮驱动，新中意公司营收同比暴增236.35%，实现利润总额45万元，成功扭亏为盈。
- **[资产置换业绩承诺]** -> [置入资产超额完成首年目标]: 置入的裕湘食品和中南粮科院2025年实现净利润920.57万元，完成承诺额400万元的230.14%，为未来三年累计1,800万元的承诺打下坚实基础。
- **[政府补助增加]** -> [扣非净利润亏损扩大]: 2025年计入当期损益的政府补助同比增加191万元，导致扣非归母净利润从-256万扩大至-398万，主业盈利能力依然薄弱。
- **[优化经营性付款节奏]** -> [经营现金流大幅转正]: 通过合理控制采购付款，经营活动现金流净额从-4,428万元大幅转正至7,229万元，现金流状况显著改善。

## 风险警告
公司核心风险在于主业盈利能力极其脆弱。尽管通过资产置换剥离了低效贸易业务，但扣非净利润已连续两年为负（-398万），表明粮油食品加工主业在“稻强米弱”的行业格局下，利润空间被严重挤压。公司高度依赖政府补助（679万）和费用压缩来维持微薄的账面利润，这种增长模式缺乏可持续性。

此外，公司面临严峻的同业竞争问题。控股股东及间接控股股东旗下仍有大量与公司主营业务重合的资产，虽已通过托管协议进行过渡，但彻底解决的时间表已多次延期至2027年。这种复杂的关联关系和潜在的资产注入预期，既是机遇也是巨大的不确定性，可能引发利益输送或整合不及预期的风险。母公司累计未弥补亏损高达7.04亿元，长期无法分红，也反映了公司历史包袱沉重。
