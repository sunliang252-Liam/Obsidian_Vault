## 因果逻辑链
- **[房地产行业持续低迷]** -> [营收增长但利润巨亏]: 虽营收增16.65%至3.65亿，但成本增速（29.9%）远超营收，叠加资产减值损失3526万，导致净亏损7889万，亏损同比扩大107.64%。
- **[江苏菲林格尔新业务拖累]** -> [家居制造业毛利率暴跌至-15.79%]: 门及木饰面业务营收增347.77%，但成本激增452.73%，毛利率降至-29.07%，成为亏损核心来源。
- **[工程项目模式侵蚀利润]** -> [工程项目毛利率为-12.0%]: 工程项目收入增37%，但成本增73.6%，毛利率同比下滑23.6个百分点，显示低价竞争与成本失控。
- **[地板主业量增利薄]** -> [地板毛利率下滑5.32个百分点至8.08%]: 地板销量增37.59%，但单价承压，成本增速（17.39%）高于收入增速（10.59%），盈利能力持续恶化。
- **[实际控制人变更]** -> [治理结构重塑]: 2025年9月完成控制权变更，金亚伟成为实控人，新董事会改组，但历史关联交易、会计差错等遗留问题仍需消化。
- **[资产减值损失激增]** -> [利润进一步承压]: 资产减值损失从787万飙升至3526万，主要因存货跌价及金融资产公允价值变动，反映资产质量恶化。
- **[研发投入大幅削减]** -> [长期竞争力隐忧]: 研发费用同比减少32.43%至952万，研发人员仅28人，在行业转型期可能削弱产品创新与差异化能力。

## 风险警告
**核心风险在于“增量不增利”的恶性循环。** 公司营收增长依赖低毛利甚至亏损的工程项目和门木饰面业务，导致整体毛利率从正转负。江苏菲林格尔新业务尚处爬坡期，成本失控严重，若无法快速实现规模效应与成本优化，将持续侵蚀母公司现金流与利润，成为“失血点”。

**治理与合规风险是另一颗定时炸弹。** 公司连续两年因关联交易、收入确认、金融资产分类等问题被上海证监局采取监管措施，内部控制缺陷虽在整改，但历史包袱沉重。新实控人团队能否彻底解决遗留问题、建立有效内控体系，存在较大不确定性。此外，公司已连续三年亏损且未分红，若主业无法扭亏，将面临ST风险。
