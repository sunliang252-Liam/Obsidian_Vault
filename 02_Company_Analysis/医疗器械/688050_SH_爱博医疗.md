# 688050.SH 深度透视

## 因果逻辑链
- **[隐形眼镜业务资产减值]** -> [净利润同比下滑30.96%]: 因市场竞争激烈、渠道投入增加，公司对隐形眼镜业务相关商誉及固定资产计提大额减值，直接侵蚀利润。
- **[人工晶状体国家集采与医保控费]** -> [人工晶状体收入增速放缓至1.43%]: 集采降价及部分省市医保支付结构调整，导致核心产品量价承压，增长阶段性放缓。
- **[角膜塑形镜竞争加剧]** -> [角膜塑形镜收入增速放缓至4.67%]: 近视防控手段多元化（离焦镜、低浓度阿托品等）及竞品增多，分流了OK镜市场，销售单价下降。
- **[隐形眼镜渠道与品牌建设投入]** -> [销售费用同比增长29.42%]: 为拓展自有品牌（TOPPOP）和即时零售渠道，公司大幅增加市场推广与渠道建设费用，拖累短期利润。
- **[“龙晶”PR有晶体眼人工晶状体获批]** -> [开辟第二增长曲线]: 2025年1月获批上市，切入千亿级屈光手术市场，有望成为继白内障IOL后的又一重磅手术产品。
- **[硅水凝胶隐形眼镜获批]** -> [隐形眼镜业务结构升级]: 自研硅水凝胶产品获批，推动产品从低毛利水凝胶向高附加值硅水凝胶转型，提升长期竞争力。
- **[境外收入同比增长126.79%]** -> [国际化战略初见成效]: 通过收购德国OPH及产品注册，高端IOL（EDF、多焦）获海外认可，海外市场成为新增长极。
- **[研发投入资本化比重提升]** -> [短期利润调节与长期资产积累]: 多个项目进入临床试验资本化阶段，研发费用同比下降10.77%，但资本化开发支出增加，未来需关注减值风险。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以扭转。** 公司营收增长5.15%，但净利润暴跌30.96%，主因是隐形眼镜业务在激烈价格战中被迫加大渠道投入并计提巨额减值。该业务目前仍处于“烧钱换规模”阶段，若竞争持续恶化，商誉及固定资产减值风险可能进一步爆发，持续侵蚀利润。

**另一重大风险是核心主业增长失速。** 人工晶状体受集采和医保控费影响，增速已降至个位数；角膜塑形镜面临多元化近视防控手段的激烈竞争，增长乏力。两大现金牛业务增速放缓，而新业务（隐形眼镜、有晶体眼人工晶状体）尚处投入期，公司正面临青黄不接的业绩真空期，需警惕未来1-2年业绩持续承压。
