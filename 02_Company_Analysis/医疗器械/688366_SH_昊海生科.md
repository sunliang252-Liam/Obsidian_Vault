# 688366.SH 深度透视

## 因果逻辑链
- **[人工晶状体国家集采进入第二阶段]** -> [营收与利润双降]: 集采导致产品单价大幅下调，叠加国产竞品冲击和手术量下降，人工晶状体业务收入同比降27.30%，迫使公司计提商誉及无形资产减值约1.66亿元，导致归母净利润同比降40.30%。
- **[其胜生物增值税率从3%调增至13%]** -> [医美玻尿酸收入下滑]: 税率调整直接压低扣税后销售单价，叠加第一、二代玻尿酸消费需求阶段性减少，导致玻尿酸产品线收入同比降23.26%。
- **[亨泰光学角膜塑形镜独家经销协议提前终止]** -> [视光终端产品收入承压]: 因卡尔蔡司收购亨泰光学，公司获8,000万元补偿金后终止合作，导致该品牌OK镜收入大幅下降，拖累视光终端产品线收入同比降17.15%。
- **[“海魅月白”等高端玻尿酸放量]** -> [部分对冲医美板块下滑]: 第四代有机交联玻尿酸“海魅月白”上市表现不俗，与“海魅”等高端系列共同稳固了公司在玻尿酸市场的领导地位，部分抵消了低端产品及税率调整的负面影响。
- **[“康瑞胶”猪纤维蛋白粘合剂打开市场]** -> [防粘连及止血板块爆发式增长]: 该产品入选上海市“新优药械”目录后，迅速实现市场准入，贡献收入9,882万元，带动该板块收入同比大增57.66%。
- **[“EndyMedPro”黄金微针国内强劲增长]** -> [射频设备线收入持平]: 尽管海外市场需求疲软，但国内“黄金微针”销售收入同比高增，支撑射频及激光设备产品线收入与去年基本持平。
- **[研发管线进入收获期]** -> [研发费用阶段性下降]: 多个核心研发项目（如多焦点IOL、无痛玻尿酸）于报告期内完成临床试验，导致研发费用同比减少17.22%，占收入比降至8.00%。

## 风险警告
**核心风险在于人工晶状体业务的持续恶化。** 首轮国家集采进入第二年，价格压力未减，而2026年上半年第二轮集采的降价预期已迫使公司计提巨额减值。更严峻的是，国产晶体凭借成本优势对进口品牌形成挤压，叠加国内白内障手术总量下滑，公司该业务面临“量价齐跌”的困境。若无法通过高端功能型产品（如三焦点、EDOF）的快速放量来弥补集采损失，该板块将继续成为业绩的沉重拖累。

**第二大风险是医美与眼科消费业务的复苏不确定性。** 公司玻尿酸和OK镜等核心产品均遭遇消费需求疲软，前者受制于医美终端增速放缓和合规趋严，后者则面临新品密集获批和功能性框架镜分流的激烈竞争。虽然“海魅月白”和自研OK镜表现亮眼，但整体消费意愿的恢复节奏难以预测，若宏观经济持续承压，非刚性需求的医美和近视防控产品可能面临更长的增长瓶颈。
