# 301515.SZ 深度透视

## 因果逻辑链
- **[地方财政资金紧张]** -> [项目执行进度放缓、营业收入下降4.30%]: 客户（公立医院、国资公司）建设资金主要依赖政府性资金，资金到位延迟导致公司合同项目无法按期推进。
- **[回款周期延长]** -> [信用减值损失暴增753.38%至6554万元]: 客户付款能力受财政压力影响，应收账款账龄拉长，公司被迫大幅计提坏账准备，成为吞噬利润的主因。
- **[理财收益下降]** -> [财务费用由负转正，同比增加116.74%]: 市场利率下行导致闲置资金理财收益减少，叠加利息支出，财务费用从净收益变为净支出。
- **[核心业务结构失衡]** -> [医用洁净装备及系统收入下滑13.66%]: 作为占比59%的最大收入来源，该板块受大型医院基建放缓冲击最大，直接拖累整体营收。
- **[医用气体装备及系统逆势增长]** -> [收入增长13.89%]: 该板块受益于“千县工程”等基层医疗强基政策，县级医院改造需求提供了一定对冲。
- **[新设子公司与股权激励]** -> [管理费用增加14.62%]: 新设三家子公司及实施限制性股票激励计划，导致管理成本刚性上升，进一步压缩利润空间。
- **[募投项目延期]** -> [资本开支节奏放缓]: 因土地配套及外部经济环境变化，三大核心募投项目均延期，短期减少了资本消耗，但长期产能扩张受阻。

## 风险警告
**核心风险：信用与现金流的恶性循环。** 公司2025年归母净利润首次转亏（-264.5万元），但信用减值损失高达6554万元，是亏损额的24.8倍。这意味着公司实际经营（扣非净利润-1000.6万元）已陷入困境，而坏账计提尚未见顶。若地方财政持续紧张，应收账款回收周期将进一步拉长，减值准备将继续侵蚀利润，公司可能面临“越做越亏”的窘境。经营活动现金流已连续两年为负（-1109万元），造血能力堪忧。

**结构性风险：业务增长引擎失速。** 公司两大主业中，占比近六成的“医用洁净装备及系统”收入下滑13.66%，且合同数量锐减46.34%，表明大型医院新建项目需求正在萎缩。尽管“医用气体装备及系统”有所增长，但毛利率同比下滑9.57个百分点，显示竞争加剧导致盈利质量下降。公司试图通过投资AI医疗、智慧病房等新方向转型，但短期内难以贡献利润，且新设子公司已开始增加费用负担。在行业从“增量建设”转向“存量更新+基层下沉”的背景下，公司能否在低毛利、长回款周期的基层市场找到可持续的盈利模式，存在重大不确定性。
