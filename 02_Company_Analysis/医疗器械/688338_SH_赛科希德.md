# 688338.SH 深度透视

## 因果逻辑链
- **[医保控费与项目组套管理政策深化]** -> [营收下降13.94%]: 医疗机构执行“最少够用”原则压缩检验项目组套，叠加DRG/DIP支付改革，终端标本检测量减少，直接导致试剂与耗材消耗量下降。
- **[海外市场突破与产品注册]** -> [海外收入增长108.76%]: 在俄罗斯等重点市场完成凝血仪器及试剂注册，凝血分析仪获得欧盟IVDR符合性声明，打开了新的增长空间，部分对冲国内需求下滑。
- **[三级医院进口替代机遇]** -> [客户层级提升]: 公司SMART系列凝血流水线、SF-9200等高速平台性能接近国际先进水平，凭借性价比优势在三级医院装机量持续增长，为未来市场份额提升奠定基础。
- **[核心原材料自主研发]** -> [降低供应链风险与成本]: 生物原材料技术平台取得突破，成功表达D-二聚体、FDP等单克隆抗体，实现核心抗体原材料的进口替代，增强产业链自主可控能力。
- **[产品结构单一]** -> [抗风险能力弱]: 公司收入100%依赖血栓与止血体外诊断领域，当行业政策冲击该细分市场时，缺乏多元化业务缓冲，导致业绩弹性不足。
- **[研发投入维持高位]** -> [长期竞争力保障]: 在营收下滑背景下，研发费用率仍提升至7.35%，重点推进PIC、TM、TAT等化学发光法血栓标志物项目，为未来产品线扩展储备技术。

## 风险警告
**核心风险在于政策依赖与市场天花板。** 公司业绩高度绑定国内医保控费政策节奏。2025年营收与净利润双降（-13.94%/-20.71%），直接源于卫健委“最少够用”项目组套管理及DRG/DIP改革。若政策持续收紧，国内血栓与止血检测需求可能进一步萎缩，公司短期增长动力将严重受挫。海外业务虽增长迅猛，但基数极小（仅占营收9.7%），尚无法弥补国内缺口。

**竞争加剧与人才流失构成双重威胁。** 进口替代机遇吸引大量新进入者，凝血赛道竞争白热化，公司面临价格战与份额争夺压力。同时，报告期内已有两位核心技术人员离职（乐嘉敏、杨娟），高端复合型人才稀缺且争夺激烈，技术团队稳定性存疑，可能拖累在研项目（如化学发光平台）的推进速度，削弱长期竞争力。
