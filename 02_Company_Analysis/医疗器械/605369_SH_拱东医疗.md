## 因果逻辑链
- **集采精准化推进，'质量+价格'复合型评价** -> 产品价格承压，毛利率下降: 集采政策使毛利率从32.36%降至27.90%，下降4.46个百分点
- **营业成本增长9.30%** -> 净利润大幅下降69.99%: 营收仅增1.84%，成本增速远超收入增速，挤压利润空间
- **财务费用增加（利息收入及汇兑收益减少）** -> 净利润下降: 财务费用同比增加2,341.36万元，直接减少利润
- **研发费用下降14.03%** -> 长期竞争力可能受损: 减少研发投入短期节省费用，但可能影响产品创新和高端化转型
- **境内销售下降3.77%** -> 整体营收增长乏力: 境内收入下滑拖累整体增速，境外增长4.72%部分抵消
- **制造费用上升26.91%** -> 营业成本高企: 制造费用占比从24.60%升至28.88%，主要因折旧、能耗等固定成本增加
- **并购津东昇并表** -> 营业成本增加: 新增子公司带来额外成本，但贡献营收有限
- **计提商誉减值准备** -> 净利润下降: 商誉减值直接减少当期利润

## 风险警告
公司面临集采政策持续压价、成本刚性上涨（尤其制造费用和财务费用）、研发投入缩减削弱长期竞争力、境内市场萎缩及商誉减值等多重压力，净利润大幅下滑，需警惕盈利能力持续恶化的风险。
