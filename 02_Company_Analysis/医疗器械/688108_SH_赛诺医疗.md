# 688108.SH 深度透视

## 因果逻辑链
- **[集采红利持续释放]** -> [冠脉支架销量增长]: 国家二轮冠脉支架集采第三年，公司两款中选支架产品销量持续增长，带动冠脉业务收入同比增长21.92%。
- **[规模效应与工艺优化]** -> [毛利率提升4.33个百分点]: 产品销量增长25.39%的同时，单位成本因规模效应和工艺改进而下降，成本降幅大于售价降幅，盈利能力显著增强。
- **[研发投入阶段性收缩]** -> [净利润大幅扭亏]: 研发费用同比下降12.8%，叠加收入增长14.53%，费用率从43.99%降至30.95%，是利润从亏损转向盈利4,728万元的关键。
- **[棘突球囊集采中标]** -> [冠脉新增长点]: 公司棘突球囊在京津冀“3+N”联盟集采中以钝性组第一名中选，带动该产品销量和进院数量大幅提升，成为冠脉业务增长亮点。
- **[FDA与CE认证突破]** -> [国际化战略加速]: 冠脉支架获FDA附条件批准（国产首例），神经介入产品获FDA“突破性器械”认定及欧盟CE MDR认证，为海外市场拓展打开关键通道。
- **[神经介入新品上市]** -> [填补产品空白]: 涂层密网支架AUCURA上市首年即实现商业化，填补了公司在神经介入出血领域的产品空白，丰富了产品矩阵。
- **[开发支出高企]** -> [潜在减值风险]: 开发支出余额4.14亿元，占总资产30.71%，若相关研发项目未能成功获批，将面临大规模减值风险，对业绩产生重大冲击。

## 风险警告
**最大风险在于高额开发支出的减值隐患。** 公司开发支出高达4.14亿元，占总资产30.71%，是净利润的8.7倍。这些资本化的研发投入能否转化为未来收入，完全取决于后续产品能否成功获批上市。一旦关键在研项目（如自膨式颅内药物支架）注册受阻或商业化不及预期，将直接触发大规模资产减值，足以吞噬当前全部利润并导致巨额亏损。

**集采政策与市场竞争的双重挤压是持续经营的核心挑战。** 尽管公司受益于集采中标带来的销量增长，但颅内球囊等产品已面临集采降价压力，导致神经介入业务收入增速（5.3%）远低于销量增速。若未来集采范围扩大至更多核心产品，或公司未能持续中标，将面临市场份额萎缩和毛利率进一步下滑的风险。同时，神经介入领域同质化竞争加剧，公司需持续推出差异化创新产品才能维持先发优势。
