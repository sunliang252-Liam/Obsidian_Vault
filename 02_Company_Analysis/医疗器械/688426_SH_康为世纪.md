# 688426.SH 深度透视

## 因果逻辑链
- **[科技服务业务爆发式增长]** -> [营收增长53.74%]: 基因测序、基因合成等科技服务收入同比大增474%，成为拉动整体营收的核心引擎，但该业务毛利率仅12.15%，严重拉低整体盈利水平。
- **[科技服务业务规模效应尚未显现]** -> [营业成本增速远超营收]: 营业成本同比增90.43%，显著高于营收53.74%的增速，导致整体毛利率下降10.53个百分点，是公司持续亏损的主因。
- **[研发费用大幅缩减]** -> [减亏]: 研发费用同比减少22.03%，通过优化资源配置、调整人员结构，有效控制了费用支出，是归母净利润同比减亏31.68%的关键因素。
- **[核心原料酶自产]** -> [成本控制与供应链安全]: 自产分子检测核心原料酶，在“带量采购”背景下形成成本优势，并保障了中下游试剂盒和检测服务的质量与供应稳定性。
- **[消化道早筛产品先发优势]** -> [差异化竞争壁垒]: 拥有国内首张基于粪便样本的幽门螺杆菌核酸检测和耐药检测三类注册证，填补行业空白，在消化道疾病大规模筛查领域建立独特竞争地位。
- **[纳米孔测序平台全国布局]** -> [科技服务业务增长基础]: 在全国5个城市建立测序实验室，实现自动化、高通量、快速交付，为科技服务业务的高速增长提供了产能和技术支撑。
- **[营销体系扩张与客户拓展]** -> [收入增长但费用承压]: 销售费用同比增长8.62%，通过扩大直销团队、深化与爱康等头部渠道合作，驱动了收入增长，但短期内对利润形成压力。

## 风险警告
公司当前最大的风险在于**科技服务业务的“增收不增利”陷阱**。该业务收入虽爆发式增长，但毛利率仅12.15%，且成本增速远超收入，表明其尚处于高投入、低效率的爬坡期。若该业务无法在短期内实现规模效应、提升运营效率，将持续吞噬公司现金流，导致亏损进一步扩大，甚至陷入“增长性亏损”的恶性循环。

其次，**核心产品市场推广存在重大不确定性**。公司引以为傲的幽门螺杆菌粪便核酸检测等创新产品，虽填补行业空白，但分子诊断技术尚未成为该领域主流检测方法，面临市场教育成本高、医生和患者接受度低的推广困难。同时，公司应收账款坏账准备高达46.63%，回款周期长，尤其是医院和政府客户，现金流压力巨大。若新产品推广不及预期或回款持续恶化，公司财务状况将雪上加霜。
