# 300753.SZ 深度透视

## 因果逻辑链
- **[输注泵省际联盟集采政策全面执行]** -> [营收与利润双降]: 集采导致产品终端及出厂价下降，叠加渠道切换过渡期销量下滑，疼痛管理业务收入同比下降17.25%，是公司由盈转亏的核心原因。
- **[鼻腔护理业务临床准入与零售拓展受阻]** -> [第二主业增长乏力]: 院内收费落地慢于预期，药店渠道开发难度加大、价格竞争加剧，导致鼻腔及上气道业务收入同比下降8.65%，未能对冲主业下滑。
- **[新业务研发投入逆势增加]** -> [侵蚀当期利润]: 在营收下滑15.3%的背景下，研发费用同比增加21.88%至4055.77万元，主要用于ADHD行为训练系统等创新业务，进一步加剧了亏损。
- **[经营活动现金流大幅萎缩]** -> [财务压力上升]: 经营现金流净额同比下降85.12%至233万元，主要系收入下降、销售回款减少，导致公司需增加银行借款（短期借款同比增83%）以维持运营。
- **[集采后销售模式转型]** -> [渠道与价格体系重塑]: 作为集采中电子泵组需求量最大的企业，公司需从高毛利经销模式转向集采配送模式，短期内对毛利率和渠道管理构成挑战。
- **[脑机接口与AI医疗布局加速]** -> [长期增长点尚待验证]: 公司成立研究院、投资方寸医生、获得ADHD关键组件注册证，但相关业务尚处投入期，短期无法贡献利润，且商业化路径存在不确定性。

## 风险警告
**核心风险在于集采冲击的深度与持续性。** 2025年是输注泵省际联盟集采的第一个完整执行年度，公司疼痛管理业务收入骤降17.25%，直接导致全年由盈转亏。集采不仅压低了出厂价，更改变了原有的经销体系，公司需在价格下降与销量增长之间寻找平衡。若集采后销量未能实现以量补价，或渠道调整导致市场份额流失，公司业绩将面临进一步下滑风险。

**第二增长曲线尚未成型，新业务投入存在失控风险。** 鼻腔护理业务增长乏力，未能对冲主业下滑。同时，公司在脑机接口、ADHD行为治疗等创新业务上投入巨大，但相关产品尚处于市场导入初期，商业化前景不明。在主营业务承压、现金流紧张的背景下，持续的研发与投资支出若不能及时转化为收入，将加剧公司的财务困境，并可能拖累整体盈利能力的恢复。
