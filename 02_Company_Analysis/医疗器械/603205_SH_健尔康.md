# 603205.SH 深度透视

## 因果逻辑链
- **[OEM出口依赖]** -> [业绩波动]: 公司连续八年位居国内医用敷料出口第四，境外销售以OEM贴牌为主，业绩高度依赖海外品牌商订单，受全球贸易政策及汇率波动影响显著。
- **[人口老龄化与慢性病]** -> [行业需求刚性]: 全球人口老龄化加速及慢性病患病率上升，推动慢性创面护理需求激增，为医用敷料市场提供长期稳定增长基础。
- **[成本管控与产业链整合]** -> [毛利率稳定]: 公司通过自制生产为主、委外加工为辅的模式，并在产品研发、工艺改进、质量控制方面形成核心竞争力，有效控制成本。
- **[客户集中度与稳定性]** -> [收入基础]: 公司与Cardinal、Medline等国际知名医疗器械品牌商建立稳定合作关系，长期订单保障了收入的基本盘。
- **[原材料价格波动]** -> [利润侵蚀]: 棉纱、坯布、无纺布等主要原材料价格波动，直接传导至生产成本，若无法及时向下游转嫁，将压缩利润空间。
- **[IPO募投项目]** -> [产能扩张]: 公司于2025年上市，募资用于产能扩建及技术升级，预计未来产能释放将支撑收入增长，但需关注产能消化风险。
- **[汇率波动]** -> [出口业务利润]: 公司境外收入占比高，人民币汇率升值将直接导致以本币计价的销售收入和利润减少。

## 风险警告
公司核心风险在于其高度依赖OEM出口的商业模式。2025年营收与净利润双降，已暴露其增长乏力。作为全球医用敷料代工厂，公司缺乏自主品牌溢价能力，议价权弱，利润空间易受上游原材料涨价和下游客户压价的双重挤压。同时，海外贸易政策（如中美关税）及人民币汇率波动，将直接冲击其出口业务，业绩稳定性堪忧。

此外，公司客户集中度较高，前几大国际品牌商订单的变动将直接决定公司业绩走向。虽然IPO募投项目带来产能扩张预期，但若全球经济下行或主要客户采购策略调整，新增产能可能面临消化困难，导致资产回报率下降。公司需警惕从“代工出口”向“品牌+技术”转型过程中的阵痛与不确定性。
