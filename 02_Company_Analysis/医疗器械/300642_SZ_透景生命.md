# 300642.SZ 深度透视

## 因果逻辑链
- **[集采政策全面落地]** -> [营收与利润双降]: 核心产品肿瘤标志物及HPV检测全面纳入集采，导致试剂收入同比下降15.75%，归母净利润暴跌89.61%。
- **[集采降价与销量下滑]** -> [毛利率基本稳定]: 公司通过降本增效措施对冲集采降价影响，但销量下降23.46%，最终营收下滑16.70%。
- **[资产减值损失扩大]** -> [利润进一步承压]: 基于谨慎性原则，计提信用减值损失1,925.83万元及资产减值损失1,462.52万元，同比分别扩大316.57万元和346.01万元。
- **[并购康录生物]** -> [产品线扩张与商誉风险]: 现金收购分子病理龙头康录生物，快速进入FISH赛道，形成“流式荧光+PCR+FISH”多维布局，但产生大额商誉，存在减值风险。
- **[研发投入持续高企]** -> [长期竞争力与短期利润压力]: 研发费用率16.07%，高于上年同期，持续投入流式荧光、化学发光、FISH等平台，但短期内侵蚀利润。
- **[海外市场拓展加速]** -> [收入结构多元化]: 海外营收同比增长296.23%，但绝对额仅869.22万元，占比极小，尚无法对冲国内集采影响。
- **[经营性现金流健康]** -> [利润质量存疑]: 经营活动现金流净额1.43亿元，远高于净利润358.79万元，主要系折旧摊销及减值准备等非现金项目影响。

## 风险警告
**核心风险：集采政策全面冲击下的业绩断崖。** 公司两大核心产品线（肿瘤标志物、HPV）已全面纳入省际联盟集采，导致2025年营收同比下降16.70%，归母净利润暴跌89.61%。集采降价趋势不可逆，且未来可能扩围至更多品类，公司销量增长能否弥补价格下降存在重大不确定性，业绩持续承压风险极高。

**次生风险：高额商誉与资产减值隐患。** 公司以2.91亿元现金收购康录生物控股权，形成大额商誉。若被并购标的未来盈利能力不达预期，将面临商誉减值风险。同时，报告期内公司已因谨慎性原则计提大额信用及资产减值损失，反映出下游客户回款及存货管理压力，资产质量存在隐忧。
