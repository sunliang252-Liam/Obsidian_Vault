# 300595.SZ 深度透视

## 因果逻辑链
- **[高端消费持续疲软 + 功能性框架眼镜分流]** -> **核心产品角膜塑形镜销量下滑5.96%**: 消费降级环境下，低价的离焦框架镜凭借非医疗器械属性抢占市场，导致公司硬镜收入同比下降2.90%。
- **[角膜塑形镜竞争加剧 + 集采降价压力]** -> **归母净利润同比下降16.20%**: 品牌增多导致价格战，叠加公立医院降价政策，公司毛利率承压，同时销售费用因促销和人员扩张增加12.86%。
- **[公司推出DK185超高透氧角膜塑形镜和巩膜镜]** -> **巩固硬镜领域领导地位**: 通过技术升级实现产品差异化，避免同质化竞争，新品获市场认可，为未来增长提供新引擎。
- **[控股视光终端业务扩张]** -> **终端收入同比增长12.53%，占比提升至58.02%**: 通过新建和并购增加终端数量，拓展非硬镜服务（如视功能训练、干眼理疗），推动整体收入小幅增长。
- **[自产原材料比例提升]** -> **硬性接触镜材料成本下降16.89%**: 自产OVCTEK材料降低对外采购依赖，在降价压力下维持了硬镜毛利率（89.08%）的稳定。
- **[股权激励计划因业绩未达标而回购注销]** -> **管理费用同比增长17.91%**: 公司层面目标未完成导致限制性股票回购注销，相关费用增加，进一步侵蚀利润。
- **[商誉减值损失增加]** -> **资产减值损失同比增长34.11%**: 部分入股的眼视光企业因消费疲软和销售瓶颈经营不及预期，导致商誉减值，对当期损益造成负面影响。
- **[华东地区收入占比高但同比下降4.30%]** -> **区域集中风险显现**: 公司核心市场增长乏力，而华南、西南等新兴区域虽有增长，但尚不足以完全对冲华东地区的下滑。

## 风险警告
**核心风险在于主营产品角膜塑形镜面临“量价齐跌”的结构性困境。** 高端消费疲软是外部宏观压力，而功能性框架眼镜等替代品的崛起是更致命的竞争威胁，直接分流了核心用户群体。同时，集采政策虽当前影响有限，但长期降价趋势明确。公司虽推出新品应对，但新品放量速度尚无法弥补核心产品下滑的缺口，导致收入微增2.62%而净利润却大降16.20%的“增收不增利”局面。

**另一个重大风险是商誉减值与子公司管理失控的叠加风险。** 公司通过大量并购扩张视光服务终端，导致商誉激增至8.84亿元，占总资产14.12%。在消费疲软环境下，部分被并购标的经营不及预期，已引发商誉减值。随着子公司数量持续增加，公司管理半径过大，内控风险显著上升，若管理跟不上扩张速度，可能出现更多经营不善的子公司，导致商誉进一步减值，形成恶性循环。
