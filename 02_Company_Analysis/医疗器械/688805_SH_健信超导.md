# 688805.SH 深度透视

## 因果逻辑链
- **[无液氦超导磁体技术突破]** -> [营收增长36.14%]: 公司首创全固态传导冷技术，1.5T无液氦超导磁体收入同比增长165.23%，成为核心增长引擎。
- **[切入头部整机企业供应链]** -> [客户集中度高]: 前五名客户销售额占比86.42%，但无单一客户依赖，表明公司已成功进入富士、GE等顶级厂商的供应体系。
- **[全球化布局与运输专利]** -> [海外收入翻倍]: 印度、意大利交付中心及冷磁体海运专利技术，使境外收入同比增长108.10%，有效降低新兴市场交付成本。
- **[IPO募集资金到账]** -> [净资产暴增158%]: 2025年IPO净募资6.89亿元，净资产从4.73亿跃升至12.22亿，为产能扩张提供充足弹药。
- **[3.0T零挥发磁体批量销售]** -> [产品结构升级]: 3.0T产品实现批量销售（1628万元），标志着公司从1.5T向高场强领域拓展，打开第二增长曲线。
- **[原材料成本占比71.44%]** -> [毛利率承压]: 直接材料成本占比高，液氦、磁钢价格波动直接影响盈利能力，但超导产品毛利率仍同比提升1.18个百分点。
- **[按库存生产模式]** -> [存货规模较大]: 存货账面价值3.39亿元，跌价准备879.66万元，需警惕市场需求波动导致的存货减值风险。

## 风险警告
**核心风险在于客户与供应商双集中。** 前五大客户贡献86.42%营收，前五大供应商占采购额45%，且超导线、液氦、制冷机等关键原材料依赖西部超导、岩谷气体、住友重工等少数供应商。一旦主要客户切换供应商或主要供应商断供，将对公司经营造成重大冲击。此外，美国加征关税等国际贸易政策变化，可能进一步增加出口成本与供应链不确定性。

**技术替代与产能消化是长期隐忧。** 虽然公司在无液氦技术领域领先，但GPS等巨头正加速推进无液氦化（西门子计划2030年全面无液氦化），技术竞争日趋激烈。同时，IPO募投项目将大幅扩充超导产品产能，若下游MRI设备市场需求增速放缓或客户开拓不及预期，新增产能存在无法及时消化的风险，可能导致投资回报低于预期。
