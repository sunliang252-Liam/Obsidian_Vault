# 300685.SZ 深度透视

## 因果逻辑链
- **[合规壁垒提升]** -> [市场份额集中]: 监管趋严（NMPA III类注册证要求、院内检测规范）淘汰不合规小企业，公司凭借35项III类注册证和院内直销网络，获取出清红利。
- **[多技术平台布局]** -> [药企合作深化]: 公司覆盖PCR、NGS、IHC、FISH四大平台，能灵活满足不同靶点（如ADC药物IHC需求）的伴随诊断开发，成为强生、阿斯利康等药企的首选合作伙伴。
- **[院内直销网络]** -> [收入增长韧性]: 400余人销售团队覆盖500余家头部医院，在增值税税率从3%升至13%的背景下，国内销售仍实现9.79%增长，体现强客户粘性和合规优势。
- **[提质增效]** -> [利润弹性释放]: 通过组织架构优化和费用管控，销售费用率同比下降4.47个百分点，叠加研发物料成本控制，归母净利润增速（41.74%）远超收入增速（8.01%）。
- **[研发投入资本化率为0]** -> [利润质量高]: 全部研发投入（1.78亿，占收入14.83%）当期费用化，无资本化粉饰，净利润增长完全来自经营性业务改善。
- **[国际化布局调整]** -> [短期增速放缓，长期蓄力]: 主动优化国际销售架构和经销商体系，导致海外收入增速（3.85%）低于国内，但为后续在东南亚、中东等新兴市场放量奠定基础。
- **[战略投资上游测序仪]** -> [供应链自主可控]: 投资深圳赛陆医疗，布局基因测序仪上游，旨在降低NGS产品对进口仪器的依赖，为院内合规普及构建成本和技术壁垒。

## 风险警告
**核心风险在于应收账款高企与信用减值压力。** 公司应收账款达6.45亿元，占总资产27.47%，且信用减值损失高达2612万元，占利润总额6.36%。这反映出在行业竞争加剧和医保控费背景下，下游医院回款周期拉长，坏账风险持续累积，可能侵蚀公司利润。

**另一风险是产品迭代与注册的不确定性。** 体外诊断行业技术更新快，公司虽有多款产品在注册（如HRD、Master Panel），但伴随诊断产品需与药企临床试验同步，研发失败或注册延迟将导致前期投入沉没，并错失市场窗口期。此外，公司正面临一起金额达6250万元的仲裁反请求，若败诉可能对当期损益造成重大冲击。

> 厦门艾德生物医药科技股份有限公司由郑立谋教授于2008年回国创办,聚焦在肿瘤精准医疗分子诊断领域,专注于科技惠民的技术创新,致力为患者提供合规、高品质的诊断产品和服务,让患者从精准医疗中真正获益。公司拥有国家企业技术中心、博士后科研工作站、发改委基因检测技术应用示范中心、国家高新技术企业、福建省肿瘤高通量测序工程研究中心等资质,GMP标准厂房获得国家药监局(NMPA)和欧盟ISO13485资质认证;公司拥有ADx-ARMS、Super-ARMS、ddCapture、ADx-HANDLE等核心技术,核心技术获得中国、美国、欧盟、日本授权,荣获国家科学技术进步奖二等奖、中国专利奖银奖;公司产品覆盖具备精准医疗条件的各大癌种,多个产品至今尚无竞品,除了在国内三甲医院大规模应用外,部分产品在日本、韩国获批上市并进入当地医保,开创了我国肿瘤伴随诊断海外获批的先例。此外,公司下设厦门艾德医学检验所、上海厦维医学检验所,拥有医疗机构执业许可证、通过美国病理学会(CAP)认证,专业从事第三方临检服务。目前全球数十个国家和地区的客户选择了艾德产品和服务,每年有数十万肿瘤患者从中受益,有效避免了肿瘤药物的误用滥用。公司瞄准行业创新源头,以伴随诊断赋能原研药物临床,是阿斯利康、强生、安进、礼来、默克、卫材、恒瑞、百济等国内外顶级药企肿瘤药物开发的战略合作伙伴,共筑肿瘤精准医疗的未来。
