# 600645.SH 深度透视

## 因果逻辑链
- **[新生儿出生率持续下降]** -> [细胞存储业务收入下滑]: 2025年出生人口降至732万，直接导致公司核心业务“细胞检测制备及存储”收入同比下降6.09%，存储份数下降14.11%。
- **[诊断板块“设备+试剂”协同效应]** -> [精准诊断成为业绩支柱]: 自研全自动免疫组化染色机装机量提升，带动配套试剂放量，同时核心原料自产率提高降低成本，支撑了制造业板块毛利率提升0.76个百分点。
- **[研发投入高企但尚未商业化]** -> [利润表承压]: 研发费用1.49亿元（占营收11.19%），且细胞治疗管线均处于临床试验阶段，无药品销售收入，导致母公司累计未分配利润为-3.33亿元，不具备分红条件。
- **[购买结构性存款]** -> [投资活动现金流大幅流出]: 报告期购买7.12亿元结构性存款，导致投资活动现金流量净额同比减少1071.01%，货币资金减少33.94%。
- **[双轨制监管框架确立]** -> [行业竞争格局优化]: 818号令与828号令构建“技术-药品”双轨制，加速市场出清，利好具备全产业链能力和合规质控体系的头部企业，公司有望受益。
- **[飞行时间质谱试剂盒获批]** -> [分子诊断新增长点]: 子公司“人EGFR/KRAS/BRAF/ERBB2/PIK3CA基因突变检测试剂盒”于2026年2月获批，为国内首个基于该平台获批的肿瘤伴随诊断试剂盒，丰富了产品线，提升了病理诊断竞争力。

## 风险警告
**核心风险在于细胞治疗管线的高投入与商业化前景的高度不确定性。** 公司研发费用率高达11.19%，但11个IND适应症均处于早期临床阶段，距离获批上市并产生收入仍需数年。母公司及合并报表均存在巨额未弥补亏损（-3.33亿/-1.03亿），短期内无法分红，且持续亏损将侵蚀净资产。若核心管线临床试验失败或进度不及预期，前期巨额投入将无法收回，对公司盈利和估值造成重大打击。

**另一重大风险是主营业务的持续萎缩。** 新生儿出生率长期下行趋势难以逆转，导致公司传统现金牛业务“细胞存储”收入与份数双降。同时，诊断板块面临集采降价、医保控费（DRG/DIP）及检验结果互认等政策压力，营收同比下降8%。公司虽在拓展成人细胞存储和分子诊断新业务，但体量尚小，能否弥补传统业务下滑缺口存在较大不确定性。此外，董事会对年报投弃权票，暗示内部治理或关联交易存在隐忧。
