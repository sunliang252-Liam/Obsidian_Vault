# 300003.SZ 深度透视

## 因果逻辑链
- **[创新药BD授权]** -> [净利润暴增289.57%]: 子公司民为生物将MWN105海外权益授权给丹麦Sidera，确认首笔3000万美元许可款收入，直接驱动扣非净利润从2.21亿跃升至8.42亿。
- **[GLP-1三靶点药物临床数据领先]** -> [创新药管线价值重估]: MWN109注射液14周减重16.67%、口服片剂4周减重7.82%，数据均优于同类已公布结果，支撑公司从仿制药向创新药转型的估值逻辑。
- **[基础集采业务企稳]** -> [现金流与利润基石]: 仿制药恢复零售渠道发货（收入+18.36%），冠脉植介入稳健增长（+1.39%），保障经营性现金流净额达15.17亿元（+106.48%），为创新转型提供资金弹药。
- **[DBS获证开启商业化]** -> [神经调控业务从0到1]: 2025年11月取得植入式脑深部神经刺激器注册证，2026年2月完成首两例植入，标志着公司正式切入高壁垒的神经调控蓝海市场。
- **[皮肤科产品快速放量]** -> [自主定价新增长极]: 聚乳酸面部填充剂等三款产品上市后覆盖大型医美机构，报告期内实现收入1.15亿元，突破集采限制，开辟消费医疗赛道。
- **[集采常态化与DRG/DIP深化]** -> [存量业务承压]: 药物球囊、封堵器、仿制药等核心产品持续面临集采降价压力，公司通过“以价换量”和成本管控维持份额，但医疗器械板块整体收入仍同比下降2.18%。
- **[研发投入高企与管线调整]** -> [短期利润侵蚀与长期布局]: 研发投入10.89亿元（占营收16.80%），同时基于审慎评估计提资产减值1.20亿元，反映创新转型期的高投入与试错成本。

## 风险警告
**核心风险在于创新药临床与商业化不确定性。** MWN109虽早期数据亮眼，但减重市场竞争极度激烈（诺和诺德、礼来、信达等），后续III期临床结果、产能放大、定价及医保准入均存在重大变数。公司预计2026Q4才启动III期，距离商业化仍有数年，期间任何负面数据或竞品迭代都可能导致管线价值大幅缩水。此外，创新药BD收入具有偶发性，2025年利润暴增的可持续性存疑。

**存量业务面临集采与支付改革的持续挤压。** 2026年国家及省际联盟集采已覆盖药物球囊、封堵器、冠脉特殊球囊及多款仿制药，公司虽全线中标，但“以价换量”效果能否对冲降价冲击尚待观察。同时，DRG/DIP改革深化将限制医院使用自费药械，可能抑制公司创新器械的院内推广速度。医疗器械板块收入同比下降2.18%，显示存量业务已进入低增长甚至微缩阶段。
