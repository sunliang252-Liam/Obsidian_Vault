# 688273.SH 深度透视

## 因果逻辑链
- **[“脑机接口+”战略升级]** -> [产品差异化与闭环康复模式]: 将非侵入式脑机接口技术融入盆底康复、运动康复等产品，构建“感知-解码-干预-反馈”闭环，提升诊疗精准度与个体化程度，形成技术壁垒。
- **[消费医疗产品矩阵成型]** -> [第二增长曲线]: 推出超声波治疗仪、中频治疗仪等皮肤抗衰产品，切入轻医美市场，在严肃医疗之外开辟新的收入来源，对冲传统业务增长放缓风险。
- **[研发高投入与多技术平台储备]** -> [长期竞争力]: 持续15%+的研发投入，在电刺激、磁刺激、聚焦超声、AI等“声、光、电、热、磁”多技术平台形成储备，支撑产品迭代与新场景拓展。
- **[“经销为主”的销售模式]** -> [市场快速渗透与规模效应]: 依托1100余家经销商网络，产品覆盖超14000家医疗机构，实现盆底年筛查150万+人次，以轻资产模式快速扩大市场份额。
- **[盆底康复市场渗透率提升]** -> [营收稳健增长]: 受益于老龄化、女性健康意识提升及分级诊疗政策，盆底功能障碍性疾病就诊率持续提高，驱动公司核心业务收入同比增长1.66%。
- **[子公司亏损与业务聚焦]** -> [短期利润承压]: 子公司薇之澜、小肤科技等处于投入期或新品推广期，出现亏损，拖累整体净利润表现，但公司通过注销非核心子公司（如上海奥通）优化业务结构。
- **[非经常性损益贡献利润]** -> [扣非净利润下滑]: 2025年非经常性损益（理财收益、政府补助）达2224万元，占净利润21.7%，而扣非净利润同比下降1.98%，显示主营业务盈利能力增长乏力。

## 风险警告
**核心风险在于增长瓶颈与盈利质量。** 公司营收增速仅1.66%，扣非净利润同比下滑1.98%，主营业务增长乏力。高额的非经常性损益（理财收益、政府补助）掩盖了主营业务的疲软，若剔除这部分收益，公司盈利能力并未改善。同时，销售费用与管理费用增速（均超9%）远超营收增速，侵蚀利润空间，表明公司为维持现有规模需付出更高成本。

**新业务拓展与市场竞争风险不容忽视。** 公司大力布局的消费医疗（皮肤抗衰、生殖抗衰）领域竞争激烈，且子公司薇之澜、小肤科技持续亏损，新业务何时能贡献正向利润存在不确定性。此外，盆底康复领域虽市场空间大，但竞争加剧可能导致产品价格承压，运动康复产品营收已大幅下滑51.52%，显示部分新业务拓展不及预期。
