# 600272.SH 深度透视

## 因果逻辑链
- **[SPD业务高速扩张]** -> [营收增长]: SPD项目营收从2023年2.51亿增至2025年5.90亿，成为医药板块核心增长引擎，拉动整体营收增长3.52%。
- **[“两票制”与集采政策深化]** -> [毛利率压缩]: 医药流通环节利润空间被持续挤压，医药类主营业务毛利率同比下降1.76个百分点至14.47%。
- **[非经常性收益消失]** -> [净利润暴跌63%]: 2024年确认房屋征收补偿收益3295万元，2025年无此收益，导致归母净利润从3499万骤降至1294万。
- **[消费市场结构性调整]** -> [传统零售业务承压]: 消费者对高档滋补品消费趋于理性，医药零售业务营收从2023年2.30亿持续下滑至2025年1.77亿。
- **[再融资完成]** -> [资本结构优化]: 完成定增募资近1.59亿元，全部用于补充“大健康”业务流动资金，净资产较上年末增长25.49%。
- **[服装板块综合改革]** -> [降本增效]: 通过压减管理层级、优化资源配置，全年管理运营成本降低近80万元，同比下降10%，稳住经营基本盘。
- **[口腔科项目落地]** -> [填补业务空白]: 口腔科项目第一年运营即实现营收近900万元，成功开辟医疗服务新赛道，成为“大健康”转型亮点。
- **[汇率波动]** -> [财务费用剧烈波动]: 美元汇率下跌导致应收Falcon货款产生汇兑损失，财务费用从-317万转为735万，对利润造成负面影响。

## 风险警告
**核心风险在于盈利能力的结构性恶化。** 公司归母净利润暴跌63%，扣非净利润已转为-291万元，表明主营业务已无法产生可持续利润。利润严重依赖非经常性损益（政府补助、理财收益），而核心的医药流通业务受“两票制”和集采政策持续挤压，毛利率连续下滑，传统批发零售业务营收与利润双双萎缩。SPD业务虽增长迅猛，但作为低毛利的供应链服务，其规模扩张能否最终转化为利润增长存在较大不确定性。

**转型阵痛与资产质量风险并存。** 公司“大健康”转型尚处投入期，SPD、口腔科等新业务前期投入大、培育周期长，对当期利润形成拖累。同时，应收账款高达5.8亿元，占总资产33%，且周转效率未见改善，叠加医药行业资金回笼压力，存在坏账风险。此外，公司核心商圈租赁业务出现阶段性波动，进一步削弱了利润稳定性。在缺乏一次性补偿收益后，公司真实盈利能力已暴露无遗。
