# 600691.SH 深度透视

## 因果逻辑链
- **[行业景气度下行]** -> [营收与利润双降]: 化工行业“强成本支撑、弱需求拉动”，尿素等主要产品价格同比大幅下滑，导致公司营收下降9.63%，归母净利润增亏21.24%。
- **[产品价格下跌]** -> [化肥板块毛利率骤降]: 尿素价格同比下降17.2%，导致化肥板块毛利率从正转负，同比减少9.08个百分点，成为亏损主因。
- **[资产减值损失激增]** -> [利润大幅侵蚀]: 对长期亏损产品对应的生产线计提减值4.7亿元，同比增加299.36%，是导致净利润大幅低于营收降幅的核心因素。
- **[子公司平原化工关停]** -> [一次性费用与资产损失]: 政策性关停导致子公司进入破产重整，产生安置费等一次性费用，并剥离合并范围，影响当期利润与资产规模。
- **[优化债务结构]** -> [财务费用下降，但现金流承压]: 偿还借款、减少票据融资，使财务费用下降26.2%，但筹资活动现金流净流出13.66亿元，流动性压力显著。
- **[子公司化机集团回款改善]** -> [信用减值损失转回]: 加大回款力度，收回大额长账龄款项，信用减值损失转回1.08亿元，部分对冲了经营亏损。
- **[正元氢能二期项目推进]** -> [在建工程大幅增加]: 子公司正元氢能二期煤炭清洁高效利用项目投入，在建工程同比增加144.52%，为未来产能扩张奠定基础。

## 风险警告
公司核心风险在于**行业供需格局持续恶化与自身资产质量疲弱的双重打击**。尿素行业产能过剩加剧（2026年预计过剩超1000万吨），产品价格承压，公司化肥板块已陷入亏损。同时，公司对长期亏损生产线计提了巨额减值，反映出部分资产盈利能力已严重恶化，未来仍有进一步减值的风险。

财务风险同样严峻。公司**累计未分配利润为-36.5亿元，已资不抵债**，连续多年无法分红。尽管通过优化债务结构降低了财务费用，但总负债仍高达118.8亿元，资产负债率78.1%，且短期借款与一年内到期非流动负债合计超61.6亿元，短期偿债压力巨大。此外，公司曾因未披露资金占用等问题被监管处罚，治理风险不容忽视。
