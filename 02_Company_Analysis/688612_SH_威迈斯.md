# 688612.SH 深度透视

## 因果逻辑链
- **[产品结构调优]** -> [净利润增长39.51%]: 高附加值车载电源集成产品出货占比提升，带动整体毛利率增加3.21个百分点，在营收持平下实现利润大幅增长。
- **[行业渗透率提升]** -> [营收规模稳定]: 2025年中国新能源汽车渗透率达47.9%，公司作为第三方车载电源龙头（市占率21.2%），发货量随行业增长同步提升，对冲了价格竞争压力。
- **[精益化生产管控]** -> [营业成本下降4.56%]: 通过全自动化组装技术和AI质检落地，制造费用虽因产能扩张上升，但直接材料成本同比减少6.56%，有效控制成本。
- **[800V高压平台产品量产]** -> [巩固客户关系]: 800V车载电源集成产品已配套小鹏G9、理想MEGA等车型，并新增理想、长安等定点，技术领先转化为订单壁垒。
- **[全球化战略落地]** -> [境外业务毛利率提升16.35个百分点]: 境外收入虽下降33.13%，但高毛利（42.21%）的Stellantis等客户订单结构优化，显示海外市场盈利能力增强。
- **[研发投入持续增加]** -> [技术壁垒加深]: 研发费用8.10%增长至4.17亿元，第五代产品功率密度提升11%，磁集成技术获26项境外专利，支撑产品迭代与成本优化。
- **[股权激励绑定核心团队]** -> [管理稳定性]: 向21名核心人员授予87.41万股限制性股票，叠加员工持股平台，确保技术与管理团队与公司长期利益一致。

## 风险警告
**核心风险在于行业竞争加剧与技术替代。** 公司虽在第三方车载电源市场排名第一，但面临比亚迪等垂直一体化整车厂的“挤占”效应，以及传统Tier1和电子厂商的涌入。更关键的是，直流快充技术的普及可能直接冲击车载充电机（OBC）的长期需求，若公司无法在电驱多合一或液冷超充模块等新赛道建立同等优势，现有主业存在被替代风险。

**财务与运营风险不容忽视。** 公司营收增速已趋近零（-0.48%），增长主要依赖利润端的成本优化而非规模扩张，可持续性存疑。同时，电驱系统业务毛利率仅7.93%且同比下降，新业务盈利能力薄弱。此外，原材料（功率半导体）依赖进口，面临地缘政治导致的供应链波动风险；海外业务扩张也带来汇率波动和跨国管理挑战。
