# 600761.SH 深度透视

## 因果逻辑链
- **电动化转型加速** -> **产品结构优化**: 电动产品销量占比突破70%，高毛利电动叉车替代低毛利内燃叉车，提升综合毛利率。
- **海外市场扩张** -> **收入增长**: 海外收入同比增长20.17%至87.08亿元，占比提升至44%，成为营收增长核心引擎。
- **规模效应与成本控制** -> **扣非净利润微增**: 营收增长11.35%至198.19亿元，但归母净利润下降8.5%，扣非净利润仅微增0.2%，显示增收不增利。
- **智能物流业务爆发** -> **第二曲线初现**: 智能物流签单额同比增长45%，营收同比增长69%，成为未来增长新动能。
- **研发投入持续加大** -> **技术壁垒构建**: 研发费用同比增长19.75%至13.25亿元，占比6.68%，支撑高端化、智能化产品迭代。
- **现金流大幅改善** -> **经营质量提升**: 经营活动现金流净额同比增长207.93%至16.21亿元，主要系销售回款增加，财务健康状况显著改善。
- **收购江淮重工** -> **消除同业竞争**: 完成对控股股东旗下江淮重工的股权收购，整合资源，优化治理结构。

## 风险警告
**核心风险在于“增收不增利”的利润侵蚀。** 2025年营收增长11.35%，但归母净利润同比下降8.5%，扣非净利润仅微增0.2%。销售费用同比增长22.51%，研发费用增长19.75%，费用增速远超营收增速，严重侵蚀利润。若未来电动化、国际化竞争加剧导致价格战，或费用控制不力，利润端将持续承压。

**国际化与电动化转型的潜在风险不容忽视。** 海外收入占比已超40%，但海外业务面临地缘政治、汇率波动（财务费用因汇兑收益大幅下降，但波动性大）、贸易壁垒等风险。同时，电动化转型虽带来结构优化，但锂电叉车市场竞争激烈，若技术路线或成本优势被对手超越，可能影响市场份额和盈利能力。
