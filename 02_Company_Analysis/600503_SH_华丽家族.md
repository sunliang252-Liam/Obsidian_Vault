# 600503.SH 深度透视

## 因果逻辑链
- **[遵义项目集中交房]** -> [营业收入增长7.7%]: 遵义海上中心项目一批次交房，带动结转收入增加，但毛利率仅14.1%，远低于苏州项目。
- **[毛利率大幅下滑]** -> [净亏损扩大至-7338万元]: 房地产行业整体景气度下行，产品毛利率承压，毛利无法覆盖期间费用及税费，导致亏损同比扩大113%。
- **[销售佣金增加]** -> [销售费用增长36.2%]: 为加速去化存量房产，公司增加销售佣金投入，进一步压缩利润空间。
- **[存货跌价准备计提]** -> [资产减值损失增加至2755万元]: 对部分房地产项目计提存货跌价准备，直接侵蚀当期利润。
- **[厦门国际银行公允价值下降]** -> [其他综合收益减少5116万元]: 持有的厦门国际银行3.4%股权公允价值变动，导致其他综合收益大幅减少，拖累净资产。
- **[瑞力文化项目退出]** -> [投资活动现金流入7975万元]: 作为瑞力文化有限合伙人，收到项目资本金退出款，但长期股权投资相应减少。
- **[预收房款增加]** -> [经营活动现金流净额转正至9209万元]: 遵义项目预售及苏州项目销售回款改善，使经营现金流由负转正。
- **[开发贷借款减少]** -> [筹资活动现金流净额下降97.3%]: 子公司新增开发贷较上期大幅减少，融资活动对现金流的贡献显著降低。

## 风险警告
公司连续两年亏损，且亏损幅度扩大，核心原因是房地产主业毛利率持续承压。苏州项目虽保持较高毛利率（48.73%），但销售规模大幅萎缩（收入同比-47%）；遵义项目虽贡献主要收入增量，但毛利率仅14.1%，盈利能力薄弱。同时，石墨烯、机器人等多元化业务持续亏损，无法贡献利润，反而消耗资源。

资产质量存在隐忧。公司持有厦门国际银行3.4%股权，账面价值5.79亿元，但该银行已连续多年未进行现金分红，且公允价值持续下跌，2025年公允价值变动损失5116万元。此外，公司约1.96亿元资产（含存货、股权）被用于抵押或质押，流动性受限。控股股东南江集团所持股份79%已被质押，财务压力较大。
