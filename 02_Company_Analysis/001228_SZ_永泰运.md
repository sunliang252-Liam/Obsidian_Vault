# 001228.SZ 深度透视

## 因果逻辑链
- **[供应链贸易服务（汽车贸易）爆发式增长]** -> [营收暴增48.38%]: 供应链贸易服务收入同比+151.28%，占总营收比从34.60%跃升至58.60%，成为营收增长的核心引擎。
- **[汽车贸易“先款后货”与“全额付款提车”的现金流错配]** -> [经营现金流大幅恶化至-12.22亿元]: 销售端定金收款与采购端全额付款形成巨大时间差，导致经营活动现金净流出同比扩大172.75%。
- **[汽车贸易业务扩张带来的营运资金需求]** -> [短期借款激增173%]: 为支撑汽车贸易的采购垫资，短期借款从9.05亿元飙升至24.68亿元，占总资产45.33%。
- **[核心主业跨境化工物流供应链服务箱量增长]** -> [营收基本稳定]: 尽管服务箱量达28.32万TEU，但该板块营收同比微降4.67%，显示主业增长乏力，被贸易业务稀释。
- **[低毛利率的供应链贸易业务占比大幅提升]** -> [整体毛利率下滑2.88个百分点]: 贸易业务毛利率仅3.54%，其占比提升拉低了公司整体盈利质量。
- **[应收账款与存货随贸易规模同步膨胀]** -> [资产减值损失达3979.65万元]: 应收账款和存货规模大幅增长，导致按账龄计提的坏账准备及商誉减值损失增加。
- **[迪拜自贸区仓库布局]** -> [海外资产与收入占比提升]: 境外收入占比从33.47%跃升至64.17%，海外仓为汽车贸易提供交割基础，但地缘政治风险随之上升。
- **[财务报告信息披露不准确被出具警示函]** -> [内控与合规风险暴露]: 2024年因财务报告信息披露不准确等问题被宁波证监局出具警示函，反映公司治理存在瑕疵。

## 风险警告
**核心风险：汽车贸易驱动的“虚假繁荣”。** 公司营收暴增48.38%的亮眼数据背后，是低毛利率（3.54%）的供应链贸易业务（主要是汽车出口）占比从34.6%飙升至58.6%。这导致公司整体毛利率下滑，且经营活动现金流急剧恶化至-12.22亿元。这种“增收不增利、增利不增现”的模式，本质上是利用资产负债表（大幅增加借款和存货）来换取利润表上的营收增长，可持续性存疑。一旦汽车出口市场降温或海外客户回款出现问题，公司将面临巨大的流动性危机和资产减值风险。

**财务健康度急剧恶化。** 短期借款激增至24.68亿元，占总资产45.33%，而净资产几乎零增长，财务杠杆率已处于高位。同时，存货激增至10.9亿元（+327%），应收账款增至9.8亿元（+37%），两者合计已超过净资产。公司已计提近4000万元的资产减值损失，若贸易业务下游客户违约或汽车价格下跌，减值风险将进一步放大。此外，公司曾因财务信息披露不准确被监管警示，内控有效性存疑，进一步增加了财务数据的不可靠性。
