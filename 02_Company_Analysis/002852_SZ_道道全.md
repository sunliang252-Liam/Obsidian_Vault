# 002852.SZ 深度透视

## 因果逻辑链
- **[包装油销量增长]** -> [营收增长4.24%]: 包装油销量同比增长5.77%，直接拉动营收从59.4亿增至61.9亿。
- **[原材料成本上涨]** -> [毛利率下降1.24%]: 部分原料供应失衡、价格上涨，导致综合毛利率从9.57%降至8.33%。
- **[精细化费用管控]** -> [净利润增长32%]: 销售费用下降21.35%、财务费用下降91.35%，降本增效成果显著，归母净利润从1.77亿增至2.34亿。
- **[中加贸易摩擦]** -> [菜油供给收缩]: 进口菜油受阻，推高国内菜油价格，利好公司菜籽油主业。
- **[套期保值业务]** -> [对冲价格波动]: 利用衍生工具管理商品价格风险，报告期套保合计实现损益约3.04亿元，稳定经营利润。
- **[经销商网络扩张]** -> [渠道下沉深化]: 经销商数量同比增长11.49%至1455家，覆盖约87万个销售网点，支撑销量增长。
- **[茂名子公司投产]** -> [贡献核心利润]: 茂名子公司2025年实现净利润6158.6万元，成为公司重要利润增长点。
- **[品牌溢价能力]** -> [市场地位稳固]: 道道全品牌在C-BPI食用油品类排名第8，品牌力支撑产品定价与市场份额。

## 风险警告
**核心风险在于原材料价格波动与毛利率持续承压。** 公司60%以上原料依赖进口，中加贸易摩擦、国际地缘政治及汇率波动均可能推高成本。2025年综合毛利率已下降1.24个百分点至8.33%，若原料成本持续上涨而终端提价能力受限，利润空间将进一步被压缩。公司虽通过套期保值对冲风险，但套保本身存在基差风险与资金流动性风险，2025年非高度有效套保合约已产生公允价值变动亏损。

**第二大风险是行业竞争加剧与需求恢复不及预期。** 食用油行业品牌竞争白热化，公司作为菜籽油细分龙头，与中粮、益海嘉里等央企巨头在规模和品牌知名度上仍有差距。餐饮渠道需求恢复缓慢，家庭消费向高端化转型但增速有限，若公司不能有效推广品牌、拓宽渠道，市场份额可能被蚕食。此外，靖江、茂名等新产能的效益释放存在不确定性，前期已出现不及预期的情况。
