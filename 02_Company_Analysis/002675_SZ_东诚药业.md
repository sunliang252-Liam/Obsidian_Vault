# 002675.SZ 深度透视

## 因果逻辑链
- **[核药业务高增长]** -> [整体利润逆势增长]: 核药板块收入同比增长12.21%，其中18F-FDG增长18.35%，弥补了原料药收入下滑19.19%的缺口，推动归母净利润增长6.42%。
- **[肝素原料药价格销量双降]** -> [原料药收入大幅下滑]: 肝素钠销量及销售价格下降，导致原料药收入同比减少19.19%，成为拖累总营收下降4.46%的主因。
- **[蓝纳成分拆赴港上市]** -> [研发管线价值重估]: 子公司蓝纳成完成C轮融资近5亿元并递交港股上市申请，其13款诊疗一体化在研管线获得独立资本定价，为母公司带来潜在价值释放。
- **[“一堆两器”同位素平台建设]** -> [供应链自主可控]: 与国电投、Eckert & Ziegler等合作推进医用同位素反应堆及加速器项目，旨在摆脱对进口同位素的依赖，构建长期成本与供应安全壁垒。
- **[核药房网络化布局]** -> [短半衰期药品即时配送壁垒]: 已运营31个核药生产中心，覆盖93.5%人口，形成“生产-配送”闭环，满足18F-FDG等短半衰期药物的临床即时性需求，构筑高护城河。
- **[经营活动现金流大幅改善]** -> [运营效率提升]: 经营现金流净额同比增长101.93%至5.80亿元，主因是肝素粗品采购量下降，反映出公司在原料药下行周期中主动去库存、优化现金循环。
- **[财务费用激增]** -> [融资成本侵蚀利润]: 财务费用同比增长90.32%至1.47亿元，主要系子公司新增融资确认的股份回购利息，高额财务成本对净利润形成显著压制。

## 风险警告
**核心风险在于高额商誉与研发不确定性。** 截至2025年末，公司商誉账面价值高达24.91亿元，占净资产比例超过57%。这些商誉主要来自历年对云克药业、安迪科等核药公司的并购。若未来核药业务增长不及预期，或行业政策（如医保控费、集采）对核心产品价格形成冲击，将面临巨大的商誉减值风险，直接吞噬利润。

**财务杠杆与现金流压力不容忽视。** 公司长期应付款高达14.70亿元，主要系子公司融资回购义务的计提，叠加财务费用同比翻倍，表明公司正通过高杠杆融资支撑研发与产能建设。虽然经营现金流改善，但投资活动现金净流出5.55亿元，筹资活动净流入大幅减少84.12%，显示公司对外部融资的依赖度依然较高，若市场环境恶化或研发进展受阻，可能面临流动性压力。
