# 920061.BJ 深度透视

## 因果逻辑链
- **[下游锂电行业产能结构性调整]** -> [营收下降22.78%]: 下游锂电行业去库存、新建项目需求萎缩，直接导致公司磁力过滤设备新增订单大幅减少。
- **[市场需求从增量转为存量替换]** -> [磁选棒收入逆势增长15.24%]: 新建项目减少，客户转向存量设备周期性更换及技改，磁选棒作为替换部件需求增加。
- **[市场竞争加剧与产品降价]** -> [毛利率下降2.36个百分点]: 为保客户和市场份额，公司主动降价，同时固定成本摊销因产量下降而上升，双重挤压毛利。
- **[下游回款周期延长与客户经营异常]** -> [信用减值损失增加60.5%]: 应收账款坏账准备计提同比增长，侵蚀利润，是净利润暴跌77.91%的核心原因之一。
- **[政府补助减少]** -> [其他收益下降59.65%]: 上年收到专精特新“小巨人”奖励等一次性补助，本期无此项目，导致非经常性损益大幅缩水。
- **[理财产品赎回增加]** -> [投资收益上升433.31%]: 公司调整理财策略，赎回理财产品导致投资收益增加，但公允价值变动收益相应减少，对冲部分影响。
- **[对外投资与募投项目支出]** -> [货币资金减少28.73%]: 对北方招宝磁业实缴出资1250万元及募投项目持续投入，消耗了账面现金。

## 风险警告
**核心风险：下游单一行业依赖与业绩断崖式下滑。** 公司营收与利润高度绑定于锂电行业资本开支周期。2025年锂电行业产能结构性调整，导致公司营收下降22.78%，净利润更是暴跌77.91%，扣非净利润仅167万元，盈利能力已近冰点。若锂电行业复苏不及预期或持续低迷，公司业绩存在进一步恶化甚至亏损的风险。公司向化工、食品、医药等行业的拓展尚在初期，短期内难以形成有效对冲。

**次要风险：应收账款坏账与毛利率持续承压。** 下游客户回款周期延长及个别客户经营异常，已导致信用减值损失大幅增加。在行业“反内卷”和客户资本开支审慎的背景下，公司为维持份额被迫降价，叠加固定成本摊销压力，毛利率持续下滑。若行业竞争进一步加剧或原材料价格波动，毛利率可能跌破盈亏平衡点，对公司现金流和持续经营能力构成实质性威胁。
