# 002373.SZ 深度透视

## 因果逻辑链
- **[主动放弃低质量集成项目]** -> [营收与毛利率双升]: 公司主动收缩回款风险高的政府类集成项目，聚焦高毛利产品与海外业务，实现营收增长13.35%，智慧交通毛利率提升2.94个百分点。
- **[智能物联海外业务高增长]** -> [整体营收结构优化]: 海外业务毛利率高达41.97%，且增速稳健，成为利润的重要稳定器，有效对冲了国内政府项目竞争加剧的压力。
- **[金融资产公允价值变动]** -> [净利润大幅扭亏]: 2025年公允价值变动收益1.56亿元（2024年为亏损1.48亿元），是归母净利润从-11.9亿扭亏至2.68亿的核心非经常性因素。
- **[智慧交通“交通云及行业软件”收入爆发]** -> [高价值业务占比提升]: 该板块收入同比增长53.16%，毛利率提升2.91%，表明公司从集成商向软件与数据服务商的转型初见成效。
- **[经营性现金流大幅改善]** -> [经营质量实质性提升]: 经营活动现金流净额从1.43亿激增至7.76亿元，增幅441.85%，印证了公司放弃低质量项目、加强回款管理的战略执行有效。
- **[研发投入持续高企]** -> [构筑AI+交通技术壁垒]: 研发费用占营收比例达13.86%，重点投入“梧桐”大模型、车路云一体化及L4级无人重卡，为未来竞争储备核心能力。
- **[员工持股计划业绩考核连续未达标]** -> [内部激励与外部业绩脱节]: 2024及2025年业绩均未达到员工持股计划设定的考核目标，反映出公司战略转型期的阵痛与内部预期管理存在偏差。

## 风险警告
**核心风险在于战略转型的“青黄不接”与盈利质量的结构性脆弱。** 公司虽通过主动收缩低质量项目实现了报表上的扭亏为盈，但扣非净利润仅为0.89亿元，盈利高度依赖金融资产公允价值变动（1.56亿元）和政府补助（0.57亿元）等非经常性损益。智慧交通业务向“AI+运营”转型尚在投入期，而智能物联业务在国内市场承压，增长主要依赖海外，面临地缘政治与汇率波动风险。公司大力押注的干线物流无人驾驶（千曙科技）仍处于研发与试点阶段，短期内无法贡献利润，反而将持续消耗大量研发资源。

**另一重大风险是政府客户信用风险与行业竞争格局恶化。** 公司传统智慧交通业务的核心客户为地方政府及交通部门，在地方财政普遍承压的背景下，应收账款回收周期长、坏账风险高是长期顽疾。尽管公司主动放弃部分项目，但应收账款规模仍高达38.34亿元，占总资产21.12%。同时，行业集成项目主体日趋多元化，竞争激烈，公司能否在“车路云一体化”等新赛道上建立起可持续的商业模式和定价权，尚待验证。
