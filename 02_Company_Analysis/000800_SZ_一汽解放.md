## 因果逻辑链
- **[国四置换政策与老旧货车淘汰]** -> [中重卡销量增长19.02%]: 政策催生大量更新需求，直接拉动公司核心产品销量。
- **[新能源商用车免征购置税政策]** -> [新能源销量增长184.3%]: 政策与市场双重驱动，公司新能源业务实现跃迁式增长。
- **[海外市场布局与产品竞争力提升]** -> [出口销量增长5.2%]: 公司“SPRINT 2030”战略落地，海外子公司建设与多品牌运营初见成效。
- **[非经常性损益大幅波动]** -> [扣非净利润仅1.64亿元]: 政府补助、资产处置等非经常性收益是净利润的主要来源，核心盈利能力依然薄弱。
- **[材料成本占比提升]** -> [营业成本结构变化]: 材料成本占营业成本比重从88.92%升至96.58%，成本控制压力加大。
- **[经营活动现金流大幅转正]** -> [现金流改善]: 经营活动现金流净额从-58.5亿元转为26.85亿元，主要得益于销售回款增加。
- **[研发投入持续高企]** -> [技术领先优势]: 研发投入25.82亿元，占营收4.12%，支撑公司在传统、新能源、智能网联三大领域的技术突破。

## 风险警告
**核心盈利能力脆弱，高度依赖非经常性损益。** 公司2025年归母净利润7.25亿元，但扣非净利润仅1.64亿元，政府补助、资产处置等非经常性收益是利润的主要来源。这表明公司主营业务（整车销售）的盈利能力依然薄弱，在行业竞争加剧、价格战持续的背景下，公司缺乏可持续的内生性增长动力。

**新能源与海外市场转型面临巨大不确定性。** 尽管新能源销量暴增184.3%，但该业务仍处于高投入期，技术迭代快、竞争激烈，且关键材料价格波动风险大。海外市场虽增长，但面临全球经济疲软、贸易壁垒增加、地缘政治风险等挑战，海外子公司布局尚处初期，短期难以贡献稳定利润。公司能否在两大新赛道上实现从“烧钱”到“造血”的跨越，是未来最大的考验。
