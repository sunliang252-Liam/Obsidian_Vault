# 002364.SZ 深度透视

## 因果逻辑链
- **[AIDC算力基建爆发]** -> [数据中心电源收入增长16.10%]: 国内头部云厂商资本开支超万亿，公司HVDC/Panama电源产品深度绑定阿里、腾讯、字节，直接受益于智算中心规模化建设。
- **[800V直流技术路线演进]** -> [产品壁垒与毛利率优势]: 机柜功率密度跃升至200kW+，迫使供电架构向800V直流演进，公司作为HVDC国标牵头者，技术先发优势转化为订单溢价。
- **[通信运营商集采份额领先]** -> [站点能源业务增长19.13%]: 在中国铁塔、中国电信等集采中中标大份额，叠加5G/6G基站建设，模块化电源出货量同比+26.28%。
- **[电力市场化改革加速]** -> [软件业务增长7.30%]: 电力现货交易辅助决策系统、虚拟电厂SaaS平台在全国十余省份落地，推动电力数字化软件成为第二增长曲线。
- **[海外市场突破]** -> [外销收入暴增177.78%]: 通过新加坡子公司投资布局，中标沙特、德国、埃及等海外项目，从“中国本土”向“全球玩家”转变。
- **[供应链柔性化与智能制造]** -> [规模交付能力]: 富阳工厂年产100万个电源模块，SAP/PLM/MES系统实现全流程追溯，支撑AIDC大额订单的快速交付。
- **[扣非净利润增长38.73%]** -> [盈利质量显著提升]: 剔除资产处置等非经常性损益后，主业盈利能力大幅改善，核心业务造血能力增强。

## 风险警告
**现金流恶化与应收账款高企的双重挤压。** 经营活动现金流净额同比骤降48.06%至2.43亿元，远低于净利润1.26亿元，主要因购买商品支付现金大幅增加。同时应收账款高达11.23亿元，占总资产26.5%，且账龄结构复杂，若下游云厂商资本开支节奏放缓或回款周期拉长，将直接侵蚀利润并引发流动性风险。

**行业竞争加剧与毛利率下行压力。** 数据中心电源、充电桩等核心产品毛利率均出现同比下滑（-1.40%、-1.77%），行业新进入者增多，硬件同质化竞争加剧。公司虽试图通过“软硬结合”构建壁垒，但软件业务毛利率亦下降1.53%，若无法持续保持技术代差，价格战将压缩利润空间。此外，铜、锡等原材料价格波动对盈利能力构成潜在冲击。
