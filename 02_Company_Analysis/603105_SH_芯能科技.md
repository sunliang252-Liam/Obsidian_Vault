# 603105.SH 深度透视

## 因果逻辑链
- **[自持电站规模持续扩张]** -> [光伏发电收入与毛利稳步增长]: 报告期末自持电站并网容量突破1GW（1000.75MW），同比增加89MW，带动发电量增长14.44%，是营收与利润增长的核心引擎。
- **[精细化运营与光照条件改善]** -> [发电效率提升]: 光伏发电等效利用小时数同比增加63小时，对应多发电量约6,024万度，在不增加资本开支的情况下增厚了发电收入。
- **[可转债按实际利率计提利息]** -> [财务费用承压]: 8.8亿元可转债按6.62%实际利率计提利息，较同等规模银行借款（约3.00%）多计提约2,600万元，显著抬升财务费用，压制了利润弹性。
- **[地方补贴政策到期]** -> [其他收益减少]: 部分存量自持电站地方补贴到期，导致其他收益同比减少约1,000万元，但公司强调对补贴依赖度低，电费收入足以支撑良好回报。
- **[可再生能源补贴加速发放]** -> [信用减值损失冲回与现金流改善]: 2023年度国补基本收回，相应冲回信用减值损失，并同步改善经营活动现金流净额至4.02亿元。
- **[“自发自用，余电上网”商业模式]** -> [高毛利率与强现金流]: 光伏发电业务毛利率高达63.36%，且电费按月结算，形成“装机增长—现金流增强—再投资”的复合增长循环。
- **[电价市场化改革与政策规范]** -> [行业洗牌与公司竞争优势放大]: 新政推动分布式光伏回归就近消纳本质，淘汰依赖套利的低效主体，公司聚焦优质工商业客户、高自用比例的模式反而受益，巩固了区域领先地位。

## 风险警告
**核心风险在于电价下行与可转债的财务杠杆。** 公司80%存量电站采用折扣模式结算，收益与大工业电价深度绑定。在电力市场化改革深化、行政峰谷分时电价逐步取消的背景下，电价波动风险显著上升。若大工业电价持续下行或峰谷结构发生不利变化，将直接压缩公司核心业务的度电收入和毛利率。同时，8.8亿元可转债按6.62%的实际利率计提利息，远高于新增项目贷款约3.00%的利率，每年多计提约2,600万元财务费用，对利润形成持续压制。虽然公司通过负债管理实现了财务费用同比小幅下降，但可转债的利息负担是未来利润增长的一个结构性障碍。

**另一个关键风险是募投项目延期的实施不确定性。** 公司可转债募投的“分布式光伏电站建设项目”因部分屋顶资源无法及时交付，已于2025年8月进行资源置换并延长实施期限至2026年10月。在延长期内，若宏观经济、产业政策或业主规划再次发生变化，可能导致部分子项目无法达到预期收益率甚至难以实施，进而影响募集资金使用效率和公司整体装机规模扩张节奏。此外，公司已发现并整改了关联方非经营性资金占用问题，虽金额较小，但暴露了内部控制在细节执行上的瑕疵，需持续关注治理风险。
