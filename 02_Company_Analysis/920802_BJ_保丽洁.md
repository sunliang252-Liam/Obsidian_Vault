# 920802.BJ 深度透视

## 因果逻辑链
- **[海外子公司AVC并表]** -> [营收利润双增]: 新加坡AVC公司全年并表，贡献净利润1026万元，成为公司增长的核心引擎。
- **[海外市场高增长]** -> [营收结构优化]: 海外收入同比增长76%，毛利率49.42%，显著高于国内29.57%，拉高整体毛利率至36.78%。
- **[募投项目转固]** -> [资产结构变化]: 油烟净化生产建设项目完工，在建工程减少76.25%，固定资产增加34.48%，产能即将释放。
- **[加大催收力度]** -> [现金流改善]: 经营活动现金流净额同比大增53.06%至5099.5万元，信用减值损失同比减少114.55%。
- **[工业油烟设备下滑]** -> [业务结构失衡]: 工业油烟净化设备收入同比大降30.65%，而商用设备基本持平，显示工业端需求疲软。
- **[管理费用激增]** -> [利润侵蚀]: 管理费用同比大增37.70%，主因AVC并表新增878万元管理费用，吞噬部分利润增长。
- **[汇兑损失扩大]** -> [财务费用波动]: 财务费用由负转正，同比增加157.18%，主要受人民币汇率波动影响，增加经营不确定性。

## 风险警告
**核心风险在于增长对海外子公司AVC的过度依赖。** 公司2025年净利润增长9.54%，但母公司（剔除AVC）净利润仅1407万元，同比下滑25.5%。AVC贡献了合并报表超40%的净利润，其经营稳定性、海外市场政策及汇率波动，均可能对公司整体业绩造成剧烈冲击。一旦海外市场环境恶化或AVC经营不及预期，公司增长将面临失速风险。

**国内主业增长乏力，工业端需求疲软。** 商用油烟净化设备收入同比微降2.21%，而工业油烟净化设备收入同比大幅下滑30.65%，显示公司在国内核心市场的竞争力或面临挑战。尽管公司通过拓展配件及维护服务（+97.38%）进行弥补，但该业务毛利率较低，难以完全对冲主业下滑带来的利润压力。国内环保政策执行力度及原材料价格波动，仍是持续存在的经营风险。
