# 002396.SZ 深度透视

## 因果逻辑链
- **AI算力网络需求爆发** -> **企业级网络设备营收增长26.74%**: 公司发布51.2T CPO交换机、800G交换机等产品，精准卡位AI数据中心高速互联需求，驱动核心业务高速增长。
- **海外市场拓展加速** -> **境外收入增长27.36%**: 公司深化海外渠道建设与本地化合作，境外收入占比提升至22.56%，成为营收增长的重要引擎。
- **研发投入聚焦主业** -> **产品竞争力持续领先**: 研发投入占营收13.32%，在以太光网络、交换机、WLAN等多个细分市场保持IDC排名前三，构筑技术护城河。
- **子公司锐捷网络业绩强劲** -> **归母净利润微增1.05%**: 锐捷网络贡献净利润6.96亿元，是公司利润核心来源，但其他业务（如通讯产品、网络终端）下滑，拖累整体利润增速。
- **存货周转效率提升** -> **经营活动现金流净额暴增532.55%**: 公司加强存货管理，存货规模下降，叠加销售回款增加，经营性现金流大幅改善至20.9亿元。
- **“信创+AI”战略深化** -> **信创业务实现全栈布局**: 推出信创SDH媒体网关、信创AI算力一体机等产品，与昇腾、鲲鹏等生态合作，抢占国产替代市场。
- **光通信产品持续迭代** -> **FTTx全光方案规模化落地**: 推出自研信创工业PON方案、FTTR全光智慧家庭解决方案，在运营商市场实现多省规模化供货，巩固光通信基本盘。

## 风险警告
**核心风险在于利润增长与营收增长严重脱节。** 公司营收增长14.31%至191.57亿元，但归母净利润仅微增1.05%至4.09亿元，扣非净利润甚至下滑8.12%。这主要源于企业级网络设备毛利率同比下降4.26个百分点，显示在AI算力网络的高景气度下，公司可能面临激烈的价格竞争或成本压力，未能将收入增长有效转化为利润。

**第二重风险是子公司依赖与业务结构失衡。** 公司利润高度依赖子公司锐捷网络，而通讯产品、网络终端等传统业务营收均出现下滑。同时，2022年限制性股票激励计划因业绩考核未达标导致回购注销，反映出公司层面整体盈利能力未达预期。此外，核心芯片供应链风险、部分业务客户集中度高等问题，也为未来经营增添了不确定性。
