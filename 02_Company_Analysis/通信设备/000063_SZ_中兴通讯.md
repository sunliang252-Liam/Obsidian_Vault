# 000063.SZ 深度透视

## 因果逻辑链
- **[政企业务（服务器及存储）爆发式增长]** -> [营收重返增长轨道]: 政企业务收入同比翻番（+100.49%），占总营收比重从14%跃升至28%，成为拉动整体营收增长10.38%的核心引擎。
- **[低毛利算力产品占比急剧提升]** -> [整体毛利率大幅下滑7.66个百分点]: 政企业务毛利率仅10.97%，其收入占比快速提升，严重稀释了运营商网络（48.09%）的高毛利结构，导致归母净利润同比下降33.32%。
- **[国内运营商资本开支持续下降]** -> [运营商网络收入承压]: 5G建设进入成熟期，国内运营商投资延续下降态势，导致公司运营商网络收入同比减少10.62%，传统“压舱石”业务失速。
- **[研发投入聚焦与精准投放]** -> [研发费用同比下降5.31%]: 公司主动聚焦高潜和战略性项目，研发费用率从21.03%降至18.28%，但绝对额仍高达227.6亿元，维持技术护城河。
- **[存货与应付票据大幅增加]** -> [经营活动现金流净额骤降65.86%]: 为支撑算力业务扩张，存货增加至470亿元，应付票据增长39.34%，导致购买商品支付的现金大幅增加，现金流质量恶化。
- **[“连接+算力”双轮驱动战略]** -> [收入结构从单一依赖运营商转向多元化]: 公司成功从传统通信设备商向“连接+算力”综合方案商转型，政企和消费者业务合计占比已超过53%，降低了对单一市场的依赖。
- **[AI技术深度嵌入产品]** -> [提升产品竞争力与市场格局]: 从AI原生核心网(AIR Core)到智能体手机，AI赋能全产品线，在智算服务器、数据中心交换机等新赛道突破头部客户，巩固了市场地位。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化。** 2025年营收增长10.38%，但归母净利润却暴跌33.32%，扣非净利润更是腰斩（-45.45%）。根本原因是公司为了抢占智算市场，被迫以低毛利的服务器等硬件产品冲规模，导致整体毛利率从37.90%骤降至30.25%。这种以利润换规模的策略，若不能在未来通过高附加值软件、服务或芯片自研提升利润率，将陷入“规模越大，盈利越薄”的陷阱。同时，经营活动现金流净额同比大降65.86%，仅为净利润的70%，显示盈利的现金保障能力严重不足。

**另一重大风险是运营商传统业务的持续萎缩与智算新业务的不确定性。** 运营商网络作为公司曾经的利润基石，收入已连续下滑，且毛利率也在下降。而作为增长引擎的政企业务，其高增长高度依赖国内互联网巨头的资本开支，具有强周期性和客户集中度风险。智算业务的商业闭环尚在培育期，市场竞争异常激烈（华为、浪潮等），公司能否在算力领域建立起类似通信领域的护城河，存在巨大不确定性。此外，国际地缘政治风险、汇率波动以及高达65.26%的资产负债率，均为公司的稳健经营埋下隐患。
