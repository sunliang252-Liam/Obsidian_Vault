# 688027.SH 深度透视

## 因果逻辑链
- **[量子计算业务爆发]** -> [营收与净利润扭亏]: 量子计算产品收入同比+276%，带动总营收增长22.53%，归母净利润由-3184万转为+539万。
- **[国资央企控股赋能]** -> [市场渠道与订单扩张]: 成为中电信量子集团控股子公司后，深度融入中国电信“DICT+量子”体系，获取大规模量子城域网及量子计算整机订单。
- **[研发高强度投入]** -> [技术壁垒与产品迭代]: 研发费用同比+42.18%，占营收39.70%，支撑“祖冲之3号”同款量子计算机、千比特测控系统等前沿产品落地。
- **[政府补助与投资收益]** -> [非经常性损益贡献利润]: 计入当期损益的政府补助及投资收益合计约4800万元，是扣非净利润仍为负（-4355万）但归母净利润转正的关键。
- **[量子通信业务结构优化]** -> [毛利率稳定]: 量子通信产品毛利率73.07%，虽收入微降，但高毛利产品占比提升，支撑整体毛利率维持在52.05%。
- **[核心组件国产化]** -> [供应链安全与成本控制]: QKD设备完成元器件全部国产化验证，稀释制冷机等量子计算核心组件实现国产替代，降低被“实体清单”卡脖子风险。
- **[星地一体化网络建设]** -> [长期增长空间]: 支撑中国电信全国40城量子城域网建设，并实现中非12900公里星地量子通信，巩固了在量子通信基础设施领域的绝对领先地位。

## 风险警告
**核心风险在于盈利的可持续性。** 公司2025年归母净利润转正，但扣非净利润仍亏损4355万元，盈利高度依赖政府补助（3395万）和投资收益（1218万）等非经常性损益。量子计算业务虽爆发式增长，但毛利率仅38.07%，且客户集中度极高（前五大客户销售额占比63.51%，其中关联方占43.44%），一旦关联交易或补贴政策变化，业绩将剧烈波动。

**经营与财务风险不容忽视。** 公司经营活动现金流净额由正转负（-1089万），应收账款余额高企，存货周转率低，存在减值风险。同时，公司及子公司被美国列入“实体清单”，虽已实现核心组件国产化，但上游高端芯片、科学仪器等仍依赖进口，未来业务拓展可能受限。量子计算尚处早期，商业化路径不明，市场开拓不及预期的风险始终存在。
