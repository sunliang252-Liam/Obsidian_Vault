# 688668.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [通讯连接器订单激增]: AI服务器内部连接复杂度提升3倍以上，速率从56G升级至224G，直接拉动公司通讯连接器壳体CAGE等核心产品需求，2025年通讯连接器组件收入同比增长63%。
- **[224G产品量产]** -> [高毛利产品占比提升]: 公司紧跟技术迭代，112G/224G系列产品需求旺盛并实现量产，高附加值产品结构优化，带动通讯连接器组件毛利率提升3.65个百分点至35.36%。
- **[海外产能布局落地]** -> [外销收入翻倍]: 马来西亚基地进入稳健经营阶段，2025年实现营收1.19亿元、净利润1304万元，叠加海外客户订单由国内交付转为国外交付，外销收入同比大增105.39%。
- **[新能源汽车业务战略收缩]** -> [汽车业务盈利承压]: 面对铜价上涨和行业价格战，公司主动剔除亏损产品，聚焦高压/电控连接器，虽营收增长53.94%，但毛利率下降2.02个百分点至21.48%，增长质量受限。
- **[深度绑定行业龙头客户]** -> [订单稳定性与高客户集中度]: 公司与安费诺、莫仕、泰科电子、中航光电等全球连接器龙头建立长期合作，前五名客户销售额占比高达88.43%，保障了订单的持续性与稳定性。
- **[研发聚焦液冷散热]** -> [突破高速率散热瓶颈]: 针对AI服务器高功耗散热难题，公司重点研发液冷I/O连接器，已进入试产阶段，为下一代448G速率产品及光铜融合趋势储备核心技术。
- **[股权激励绑定核心团队]** -> [激发组织活力]: 2024年限制性股票激励计划覆盖58名核心人员，2025年业绩考核目标达成（净利润增长率110%），有效绑定员工与公司长期利益。

## 风险警告
**客户高度集中与单一业务依赖风险。** 公司前五大客户销售额占比高达88.43%，其中客户1和客户2合计占比超63%，且业绩增长几乎完全依赖通讯连接器业务（收入占比超65%）。一旦主要客户采购策略调整或AI算力投资周期放缓，公司将面临订单骤降、业绩剧烈波动的风险，缺乏多元化的业务缓冲垫。

**原材料成本与汽车业务盈利双重挤压。** 公司产品原材料（铜、塑胶等）成本占比高，铜价持续攀升直接侵蚀利润。同时，新能源汽车行业价格战白热化，公司汽车连接器业务毛利率已降至21.48%，且战略收缩后增长平缓。若成本无法有效向下游传导，汽车业务可能持续拖累整体盈利能力，成为业绩的“失血点”。
