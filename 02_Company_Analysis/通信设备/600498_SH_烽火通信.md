# 600498.SH 深度透视

## 因果逻辑链
- **[运营商资本开支收缩]** -> [营收下降12.72%]: 国内三大运营商投资重心由“网”向“算”倾斜，传统光网络投资大幅缩减，直接导致公司通信系统设备收入下滑16.4%。
- **[AI算力需求爆发]** -> [数据网络产品收入增长24.05%]: 互联网云厂商资本开支首次超越运营商，公司抓住智算建设机遇，服务器产品在运营商、金融、互联网客户实现规模化突破。
- **[研发聚焦与收缩]** -> [研发费用下降10.80%]: 公司主动优化研发项目结构，聚焦关键领域，适度收缩业务范围，研发投入总额占营收比例仍高达12.67%。
- **[定向增发与可转债转股]** -> [净资产增长25.71%]: 向控股股东中国信科定向增发11亿元，叠加可转债大规模转股，显著增厚了所有者权益，但摊薄了每股收益。
- **[海外产能布局落地]** -> [国际市场收入止跌企稳]: 泰国、匈牙利研发制造基地规模化投产，有效降低了贸易壁垒影响，支撑海外市场在复杂环境中实现区域份额提升。
- **[存货规模扩大]** -> [营运资金压力增加]: 存货账面价值达105.75亿元，同比增长13.35%，主要受存储类物料价格上涨及备货影响，对现金流和资产周转效率构成压力。
- **[财务费用下降]** -> [利润减亏]: 利息费用及汇兑损失下降，使财务费用同比减少23.93%，在一定程度上缓冲了营收下滑对利润的冲击。

## 风险警告
烽火通信正面临“传统业务失速，新业务尚未完全接棒”的转型阵痛期。运营商资本开支的持续收缩是核心利空，公司赖以生存的通信系统设备业务收入骤降16.4%，而高速增长的算力业务（数据网络产品）体量尚小，仅占总营收5.7%，无法完全对冲传统业务的萎缩。净利润同比暴跌38%，ROE降至3.14%，盈利能力显著恶化。

更需警惕的是，公司经营质量出现隐忧。在营收下滑12.7%的同时，销售费用和管理费用逆势增长，侵蚀利润。存货规模攀升至105.7亿元，若下游需求不及预期，将面临较大的减值风险。此外，海外子公司“武汉烽火国际技术有限责任公司”亏损2.53亿元，表明国际化扩张的盈利模式尚未跑通，全球化经营风险正在兑现。
