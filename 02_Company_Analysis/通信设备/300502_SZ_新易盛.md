# 300502.SZ 深度透视

## 因果逻辑链
- **[AI算力集群爆发式需求]** -> [营收暴增187%]: 全球大模型训练驱动十万卡级GPU集群建设，对高速光模块（800G/1.6T）产生海量需求，公司作为少数具备量产能力的厂商直接受益。
- **[1.6T光模块全球首批量产]** -> [产品结构升级与毛利率提升]: 率先交付1.6T产品，叠加800G规模化出货，高价值产品占比提升，推动整体毛利率从44.85%升至47.81%。
- **[泰国工厂二期投产]** -> [产能释放与规模效应]: 泰国二期2025年初运行，产能持续释放，支撑销量同比增82.78%，并摊薄固定成本，提升盈利能力。
- **[境外收入占比飙升至96%]** -> [深度绑定北美云巨头]: 公司客户高度集中于北美四大云厂商（前五大客户占72%），直接受益于其2025年超3600亿美元的AI资本开支。
- **[LPO/LRO/CPO等前沿技术布局]** -> [巩固行业技术领导地位]: 全球首个规模量产LPO光模块，并发布6.4T NPO、12.8T XPO等新品，构建技术护城河，确保未来竞争中的先发优势。
- **[研发投入增长74%至7亿]** -> [支撑技术迭代与产品矩阵扩展]: 研发聚焦1.6T、硅光、相干、OCS等前沿方向，虽营收占比降至2.83%，但绝对值大幅增长，为下一代产品储备核心技术。
- **[经营活动现金流净额暴增1102%]** -> [盈利质量极高]: 净利润增长236%的同时，现金流增长更快，达77亿，远超净利润，表明公司回款能力强，收入确认质量高。

## 风险警告
**第一大风险：客户高度集中与单一市场依赖。** 公司前五大客户销售占比高达72.34%，且境外收入占比96.16%，深度绑定北美云巨头。若主要客户削减AI资本开支、自研光模块或切换供应商，将对公司营收造成毁灭性打击。同时，中美贸易争端、技术出口管制等政策风险，可能直接切断公司核心收入来源。

**第二大风险：技术迭代与存货减值风险。** 光模块技术路线演进极快（如从可插拔向CPO演进），若公司在LPO/CPO等下一代技术路线上判断失误或落后，现有产品可能迅速被替代。同时，为应对客户需求，公司存货高达72.34亿元（占总资产28%），若客户订单不及预期或产品快速贬值，将面临巨额存货跌价损失，严重侵蚀利润。

**第三大风险：实控人违规与治理风险。** 公司董事长高光荣因违规减持及信息披露违法被证监会处罚，合计罚没约3200万元。这暴露了公司内部治理与实控人合规意识的薄弱，可能影响投资者信心，并增加未来监管审查的不确定性。
