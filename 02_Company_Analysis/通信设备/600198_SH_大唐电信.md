# 600198.SH 深度透视

## 因果逻辑链
- **[安全芯片业务收入增长]** -> [营收微增6.67%]: 身份识别芯片及智能卡芯片销量增加，带动集成电路业务收入增长23.43%，但特种通信业务收入下滑6.93%形成对冲。
- **[非经常性损益依赖]** -> [归母净利润亏损5,716万元]: 扣非净利润亏损2.07亿元，核心主业持续亏损，仅靠资产处置（2.1亿）和参股公司核算方法变更（1.6亿）等非经常性收益勉强维持账面利润。
- **[特种通信业务毛利率骤降]** -> [整体盈利能力恶化]: 特种通信毛利率从41.96%降至28.00%（-13.96pct），主因行业调整、客户成本控制趋严及竞争加剧，成本增速（15.44%）远超收入增速（-6.93%）。
- **[研发投入资本化率高]** -> [短期利润粉饰]: 研发投入总额2.96亿元（占营收29.42%），其中资本化比例26.58%（7,861万元），若全部费用化，扣非亏损将进一步扩大。
- **[经营现金流由负转正]** -> [现金流改善但非盈利驱动]: 经营现金流净额6,639万元（上年-1.52亿），主因加强回款催收和严控支出，而非主业盈利改善，可持续性存疑。
- **[母公司未分配利润巨额亏损]** -> [长期无法分红]: 母公司未分配利润-45.7亿元，历史亏损积重难返，持续侵蚀股东回报能力，未来多年不具备分红基础。
- **[关联交易与资金依赖]** -> [财务独立性风险]: 向关联方信科财务公司借款3.12亿元，向控股股东借款6.54亿元，融资高度依赖集团内部，外部融资能力受限。

## 风险警告
**核心主业双线承压，盈利质量堪忧。** 安全芯片业务虽收入增长，但传统证卡市场进入存量替换，单价下行；特种通信业务毛利率暴跌近14个百分点，行业深度调整叠加客户成本控制，利润空间持续收窄。扣非净利润已连续多年亏损，2025年亏损额扩大至2.07亿元，公司完全依赖资产处置和会计手段（如参股公司核算方法变更）维持账面利润，主业造血能力严重不足。

**债务结构恶化，流动性风险高企。** 一年内到期的非流动负债激增至5.69亿元（同比+748%），短期借款增至3.90亿元（+44%），而货币资金仅5.11亿元（含受限1,835万元）。公司净资产仅2.58亿元，资产负债率高达78.2%，且母公司未分配利润-45.7亿元，已无内生性偿债能力。若关联方资金支持收缩或外部融资环境变化，将面临严峻的流动性危机。
