# 688387.SH 深度透视

## 因果逻辑链
- **[国内5G资本开支进入下行期]** -> [营收下滑]: 运营商投资重心转向算力与AI，5G基站新增量连续两年下滑，公司2025年营收同比下降5.33%。
- **[高研发投入与低毛利收入错配]** -> [持续亏损]: 研发费用占营收20.86%（12.82亿元），但营收规模无法覆盖，导致归母净利润-2.70亿元，连续多年亏损。
- **[卫星互联网业务处于投入期]** -> [短期业绩拖累]: 作为增量业务，卫星互联网尚需大规模研发与市场投入，未能贡献正向利润，加剧亏损。
- **[天馈设备收入骤降35.31%]** -> [结构性收入下滑]: 运营商缩减投资直接冲击天馈设备销量，该板块收入从高位大幅回落，拖累整体营收。
- **[专利运营成为新利润增长点]** -> [非经常性收益贡献]: 与主流手机厂商达成专利许可，专利运营收入成为可持续的增量产出，部分对冲主业亏损。
- **[国际市场重启主设备业务]** -> [海外收入增长潜力]: 中标乌干达项目，突破印尼、巴西等市场，海外毛利率高达45.08%，成为未来增量来源。
- **[客户集中度极高]** -> [经营依赖风险]: 前五大客户销售额占比67.71%，其中客户一占比39.95%，公司业绩高度依赖少数运营商资本开支节奏。

## 风险警告
公司核心风险在于**“研发投入-收入”的负向循环难以打破**。国内5G建设已过高峰，运营商资本开支持续下滑，公司传统主设备、天馈业务收入承压。而卫星互联网、6G等新业务尚处投入期，无法贡献利润，导致公司营收无法覆盖每年超12亿元的研发费用，亏损成为常态。若运营商进一步压缩网络建设支出，或卫星互联网商业化不及预期，公司盈利拐点将遥遥无期。

此外，**高额应收账款与客户集中度构成双重财务风险**。应收账款（含合同资产）高达53.49亿元，占总资产38.47%，回款周期长，占用大量资金。同时，公司近70%收入来自前五大客户，尤其是对单一运营商依赖度近40%，议价能力弱，一旦客户调整采购策略，公司营收将面临剧烈波动。
