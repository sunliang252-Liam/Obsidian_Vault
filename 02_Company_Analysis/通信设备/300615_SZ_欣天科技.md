# 300615.SZ 深度透视

## 因果逻辑链
- **营收大幅增长（+70.9%）** -> **净利润仍亏损（-864.9万）**: 营收增长主要来自通信类产品（+99.2%）和新能源结构件（+57.6%），但利润被参股公司东莞鸿爱斯的巨额投资损失和减值拖累。
- **参股公司经营恶化** -> **权益法核算投资损失2000万+长期股权投资减值3853万**: 东莞鸿爱斯因材料成本上涨、生产规模缩小、固定成本分摊升高及大额资产减值，导致亏损4256万，直接侵蚀上市公司利润。
- **原材料价格上涨** -> **主营业务毛利率微降0.31%**: 直接材料成本占收入比重上升6.09%，虽通过规模效应降低制造费用占比，但未能完全抵消材料成本压力。
- **境外收入高速增长（+93.6%）** -> **境外毛利率下降5.99%**: 境外销售规模快速扩张，但成本增长更快（+109.6%），导致境外业务盈利能力显著弱于境内。
- **经营活动现金流大幅转正** -> **净利润与现金流严重背离**: 净利润亏损3107万，但经营性现金流净额1974万，主因是资产减值损失（3853万）和投资损失（1718万）等非现金项目的影响。
- **大规模资本开支** -> **在建工程激增（+698.5%）**: 公司同步推进华南和华东制造基地建设，在建工程从704万增至5620万，预示未来产能扩张但短期带来资金压力。
- **短期借款激增** -> **财务杠杆显著提升**: 短期借款从256万增至1.12亿，主要用于补充流动资金和项目建设，资产负债率从19.5%升至45.3%。

## 风险警告
**核心风险在于参股公司东莞鸿爱斯的持续恶化。** 该公司2025年亏损4256万，导致上市公司承担2000万投资损失，并计提3853万长期股权投资减值。若其经营状况无法改善，未来仍可能继续拖累公司利润，甚至面临进一步的资产减值风险。公司对该笔投资的账面价值已降至4447万，风险敞口依然较大。

**毛利率下行与成本压力并存。** 尽管营收高速增长，但原材料（铜、铝等）价格波动、境外业务毛利率下滑（-5.99%）以及人力成本上升，持续挤压盈利空间。公司产品结构向低毛利产品倾斜的趋势若延续，将削弱规模效应带来的利润弹性。此外，短期借款激增导致财务费用压力上升，需关注现金流对债务的覆盖能力。
