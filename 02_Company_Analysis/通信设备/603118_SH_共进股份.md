# 603118.SH 深度透视

## 因果逻辑链
- **[海外网通需求回暖]** -> [营收增长9.81%]: 境外主营业务收入同比大增43.08%，拉动整体营收至91.98亿元，扭转下滑趋势。
- **[费用管控与减值减少]** -> [净利润扭亏为盈]: 期间费用率同比减少1.65个百分点，长期资产减值损失大幅下降，归母净利润从-0.80亿转为+0.78亿。
- **[Wi-Fi7与PON产品升级]** -> [AP系列收入增长31.52%]: 产品代际跃迁（Wi-Fi6→7）及50GPON商用突破，推动核心网通产品量价齐升。
- **[服务器产能扩张]** -> [数通业务产销两旺]: 服务器二期扩产完成，累计产出超4万台，带动数通业务生产量同比大增56.12%。
- **[切入清洁机器人代工]** -> [开辟第二增长曲线]: 越南工厂为S客户代工扫地机器人整机，首年即实现盈利，营收超1.8亿元。
- **[汽车电子规模放量]** -> [新业务亏损收窄]: 激光雷达、车载功放出货量超270万片，动力域控项目定点，盈利能力逐步改善。
- **[控制权变更]** -> [战略资源注入预期]: 唐山国资入主成为控股股东，承诺保持独立性，可能带来新的产业协同与资金支持。
- **[美元贬值]** -> [财务费用翻倍]: 美元兑人民币汇率下降导致汇兑损失增加，财务费用同比大增100.23%，侵蚀利润。

## 风险警告
**核心风险在于盈利质量与现金流背离。** 公司2025年虽扭亏为盈，但扣非净利润仅0.60亿，且经营活动现金流净额同比大幅下降31%至1.98亿，远低于净利润。这表明利润增长主要依赖应收账款和存货的扩张（应收账款同比增66%），而非真实的现金回款，盈利含金量极低。叠加财务费用因汇率波动翻倍，公司对美元汇率高度敏感，业绩稳定性存疑。

**第二重风险来自激烈的行业竞争与地缘政治不确定性。** 国内通信市场产能过剩、价格战激烈，数通业务毛利率已下滑至3.92%。海外市场虽回暖，但中美关税博弈起伏，公司境外收入占比超70%，地缘政治风险敞口巨大。此外，公司研发费用同比大降26.69%，在技术快速迭代的通信行业，研发投入收缩可能削弱长期竞争力。
