# 300711.SZ 深度透视

## 因果逻辑链
- **[并购赛康智能]** -> [营收与净利润双增]: 收购赛康智能51%股权，新增电力数智运检业务，贡献并表收入1.4亿元，推动总营收同比增长36.68%，归母净利润同比增长29.70%。
- **[电力行业“十五五”技术体制确定]** -> [IMS调度系统业务增长]: 电力调度通信技术路线明确为“电路+IMS”双模组网，公司中标新疆、河南等全网改造项目，巩固了核心业务基本盘。
- **[国防业务承压调整]** -> [营收结构变化]: 国防行业收入同比下降5.42%，但公司通过布局新赛道（低空通信、试飞）对冲影响，整体营收仍由电力业务（+79.45%）拉动。
- **[“1133数智融合研发体系”落地]** -> [技术壁垒强化]: 公司推出云原生IMS、AI调度助手等关键成果，研发投入增长22.71%，但资本化率为0，全部费用化，短期压制利润。
- **[应收账款与信用减值激增]** -> [现金流质量承压]: 应收账款同比增长52.6%至4.55亿元，信用减值损失同比扩大68%至3438万元，侵蚀利润，经营性现金流净额虽增长但低于净利润。
- **[商誉大幅增加]** -> [未来减值风险]: 收购赛康智能形成约1.65亿元新增商誉，期末商誉总额达2.09亿元，占净资产26%，若业绩不达预期将面临减值风险。
- **[募资7.5亿元落地]** -> [资本开支加速]: 定增募资7.5亿元用于智能调度产业园及研发项目，在建工程从0增至2158万元，资本开支周期开启，短期折旧与费用压力上升。

## 风险警告
**核心风险在于应收账款高企与商誉减值压力。** 公司应收账款同比增长52.6%至4.55亿元，占营收比重高达61%，且信用减值损失同比扩大68%至3438万元，直接侵蚀净利润。国防业务回款周期延长、电力项目结算滞后是主因，若下游客户付款能力恶化，公司现金流与利润将面临双重打击。此外，收购赛康智能形成的1.65亿元新增商誉使总商誉达2.09亿元，占净资产26%，若其业绩承诺（2025年5390万元）未能兑现，商誉减值将导致利润大幅波动。

**第二重风险来自业务结构转型的不确定性。** 公司正从传统通信设备商向“数智化服务”转型，技术服务收入同比暴增538%，但该业务毛利率波动大（数智化服务毛利率59%但成本结构剧变），且高度依赖并购标的（赛康智能、易用视点）的整合效果。国防业务受行业环境影响承压，新赛道（铁路5G-R、应急通信）尚处培育期，短期内难以贡献稳定利润。研发投入全部费用化（12.45%营收占比）也表明技术变现路径尚不清晰，若新业务拓展不及预期，公司可能陷入“增收不增利”的困境。
