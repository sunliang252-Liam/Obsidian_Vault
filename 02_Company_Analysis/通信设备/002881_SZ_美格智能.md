# 002881.SZ 深度透视

## 因果逻辑链
- **[海外市场高速扩张]** -> [营收增长27.39%]: 海外营收同比大增74.47%，占比从27.30%提升至37.39%，成为核心增长引擎。
- **[产品结构变化与成本压力]** -> [毛利率下降3.47%]: 低毛利产品集中出货叠加存储芯片涨价，导致主营业务毛利率降至13.84%。
- **[智能模组/高算力模组差异化]** -> [巩固竞争壁垒]: 公司深耕安卓系统、端侧算力，在智能座舱、新零售等场景形成定制化解决方案，避免同质化竞争。
- **[智能网联车大客户依赖]** -> [国内营收增速放缓]: 2025年下半年单一大客户采购量下降，导致国内营收仅增长9.72%，拖累整体增速。
- **[汇兑损失大幅减少]** -> [财务费用骤降]: 财务费用从3254万降至246万，是净利润增速（5.27%）远低于营收增速（27.39%）但利润仍能增长的关键原因。
- **[研发投入持续高企]** -> [费用率优化]: 研发费用同比增长8.63%，但费用占营收比从12.34%降至9.77%，规模效应初显。
- **[库存大幅增加]** -> [资金占用风险]: 存货同比增长38.5%至9.01亿元，主要为存储芯片战略备货，对现金流和资产减值构成压力。

## 风险警告
**核心风险在于“增收不增利”与毛利率持续承压。** 公司营收增长27.39%，但归母净利润仅增长5.27%，扣非净利润几乎零增长。毛利率从17.31%降至13.84%，主因低毛利产品出货及存储芯片涨价。若产品结构无法优化或成本压力持续，盈利能力将进一步恶化。此外，存货激增至9.01亿元（+38.5%），若下游需求不及预期，将面临大额资产减值风险。

**客户集中度与单一客户依赖风险突出。** 前五大客户销售额占比43.68%，其中第一大客户占比高达21.77%。智能网联车领域已出现单一大客户采购量下降导致国内营收增速骤降的情况。若核心客户流失或订单波动，将对公司业绩产生重大冲击。同时，公司正筹划H股上市，可能带来额外的股权稀释和跨境监管成本。
