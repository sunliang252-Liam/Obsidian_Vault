# 002902.SZ 深度透视

## 因果逻辑链
- **[光通信产品收入大幅下滑]** -> [总营收下降2.55%]: 光通信产品收入同比骤降32.88%，拖累整体营收表现，尽管通信供电系统设备收入增长50.99%，仍无法完全对冲。
- **[资产减值与信用减值损失高企]** -> [净利润持续巨亏]: 计提资产减值损失7313万元、信用减值损失1740万元，合计超9000万元，是导致净利润-2.48亿元的核心原因之一。
- **[财务费用激增]** -> [侵蚀利润]: 财务费用同比大增92.49%至3534万元，主要因利息支出与汇兑损失增加，进一步加重亏损。
- **[收购深圳铭普电动]** -> [开辟新能源充电业务新增长点]: 收购ABB电动交通60%股权，切入全球新能源充电赛道，新增电动汽车充电业务收入3866万元，但初期仍处于亏损状态。
- **[剥离非核心资产]** -> [聚焦主业，优化资产结构]: 出售深圳铭普能源、深圳宇轩部分股权，盘活存量资产，集中资源发展光、磁、电源核心主业。
- **[研发投入资本化率为零]** -> [研发费用全部费用化]: 1.19亿元研发投入全部计入当期损益，虽体现审慎会计原则，但短期内对利润构成压力。
- **[经营活动现金流持续为负]** -> [造血能力不足]: 经营活动现金流净额-6686万元，同比恶化47.95%，显示公司主营业务回款及盈利质量面临挑战。

## 风险警告
公司连续三年巨额亏损（2023-2025年净利润分别为-2.59亿、-2.91亿、-2.48亿），且亏损幅度未见显著收窄。核心症结在于光通信产品收入断崖式下滑（-32.88%）与高额资产减值（超9000万）的双重打击。尽管公司积极布局AI算力、新能源充电等赛道，但新业务尚处投入期，短期内难以贡献利润，经营现金流持续为负，造血能力严重不足，财务风险高企。

公司资产负债率持续攀升，净资产同比缩水34.36%至6.26亿元，而短期借款与长期借款合计超6.4亿元，偿债压力巨大。同时，财务费用因利息和汇兑损失激增92.49%，进一步加重了财务负担。在主营业务尚未企稳、新业务盈利模式未明的背景下，公司面临流动性紧张与持续亏损的双重困境，投资者需高度警惕其持续经营能力。
