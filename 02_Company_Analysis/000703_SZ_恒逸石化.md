# 000703.SZ 深度透视

## 因果逻辑链
- **[文莱炼化项目区位优势]** -> [业绩核心支撑]: 地处东南亚成品油净进口市场，享受区域供需缺口红利，且原油采购不受地缘政治影响，保障满负荷运转与稳定盈利。
- **[广西新材料项目投产]** -> [开辟第二增长曲线]: 新增60万吨CPL和60万吨PA6产能，形成“BZ-CPL-PA6”完整产业链，成为锦纶行业新龙头，贡献增量收入与利润。
- **[PTA行业产能扩张尾声]** -> [盈利拐点预期]: 2026年后新产能投放显著放缓，落后产能出清，供需格局改善，具备原料保供优势的龙头企业将受益于单吨利润修复。
- **[原油价格同比下跌15%]** -> [营收下滑但利润韧性]: 全产业链产品价格随原油下行，导致营收同比下降9.51%，但扣非净利润同比大增596.59%，显示成本传导与一体化协同效果。
- **[研发投入增长16.45%]** -> [技术壁垒构建]: 钛系催化剂、无锑聚酯等核心技术突破，获浙江省科技进步一等奖，推动差别化纤维占比提升至35%，增强产品附加值。
- **[控股股东及一致行动人增持27.94亿元]** -> [信心信号与市值管理]: 大规模增持及多次股份回购注销，彰显对公司长期价值的信心，并提升股东回报（现金分红+回购占净利润308%）。
- **[文莱炼化二期项目推进]** -> [远期成长空间]: 设计产能优化至1200万吨/年，与一期形成2000万吨/年协同，资金已筹措到位，将显著提升盈利能力和海外市占率。

## 风险警告
**核心风险在于高负债率与巨额资本开支的财务压力。** 公司总资产1096亿，但短期借款高达397亿，长期借款131亿，资产负债率极高。文莱二期及广西项目持续投入，2025年投资活动现金流净流出56.46亿元，同比扩大82.83%，对经营现金流构成巨大考验。若未来行业景气度下行或融资环境收紧，公司将面临严峻的流动性风险。

**另一重大风险是PTA及聚酯板块的周期性亏损。** 尽管公司一体化优势突出，但PTA行业产能过剩导致2025年参股公司（逸盛新材料、逸盛投资）合计亏损超5亿元，严重拖累整体利润。虽然行业拐点预期出现，但若下游需求复苏不及预期或原油价格剧烈波动，PTA及涤纶产品价差可能持续低迷，公司盈利能力的改善将存在较大不确定性。
