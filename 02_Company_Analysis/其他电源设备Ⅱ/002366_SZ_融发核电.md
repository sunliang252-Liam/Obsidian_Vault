# 002366.SZ 深度透视

## 因果逻辑链
- **[行业短期政策扰动]** -> [核电收入骤降33%]: 公司核心核电产品订单及开工低于上年同期，直接导致核电行业收入从4.4亿降至2.9亿。
- **[核电主管道收入腰斩]** -> [整体营收下滑10%]: 反应堆一回路主管道收入同比降49%，从3.7亿缩至1.9亿，拖累公司总营收跌破10亿。
- **[海外市场爆发式增长]** -> [弥补部分国内缺口]: 国外地区收入同比暴增3018%至1.73亿，但基数极低，无法对冲国内核电主业26.87%的降幅。
- **[非经常性损益依赖]** -> [扣非净利润深度亏损]: 归母净利润亏损8113万，但扣非净利润亏损高达1.23亿，显示主营业务造血能力严重不足，盈利依赖债务重组利得等非经常项目。
- **[高额资产减值与信用减值]** -> [侵蚀利润核心]: 资产减值损失3158万、信用减值损失1220万，合计超4300万，是导致亏损的关键因素，反映存货和应收款质量恶化。
- **[经营现金流大幅改善但仍为负]** -> [资金压力边际缓解]: 经营现金流净额从-3.56亿大幅收窄至-1499万，主因经营性现金支出减少，但尚未转正，造血能力仍弱。
- **[高杠杆与利息负担]** -> [财务费用刚性]: 长期借款13.2亿，利息费用3096万，高负债率持续侵蚀利润，财务杠杆风险显著。

## 风险警告
**核心风险在于核电主业复苏的不确定性。** 公司营收与利润高度依赖核电主管道等核心产品，但2025年核电收入骤降33%，直接导致由盈转亏。管理层将原因归结为“行业短期政策影响”，但未给出明确复苏时间表。若核电项目审批或开工节奏持续低于预期，公司营收和利润将面临进一步下滑压力，扣非净利润已连续多年为负，主业造血能力堪忧。

**财务风险高企，资产质量存疑。** 公司资产负债率约35%，但长期借款高达13.2亿，每年利息费用超3000万，对微薄的经营利润形成巨大吞噬。同时，存货和应收账款合计超12.8亿，且持续计提大额减值，表明产品交付与回款周期长、风险高。母公司未分配利润为-2.5亿，不满足分红条件，股东回报前景黯淡。
