# 002255.SZ 深度透视

## 因果逻辑链
- **收入结构变化：锅炉收入下降36.88%，核电收入增长257.18%** -> 营业收入同比下降16.73%，但净利润同比增长10.50%: 高毛利的核电产品占比提升（从3.24%升至13.90%，毛利率36.70%），拉高整体盈利水平，弥补了低毛利产品收入下滑的影响。
- **核电产品收入大幅增长257.18%** -> 核电产品毛利率同比提升22.52个百分点至36.70%: 核电设备制造技术壁垒高，公司拥有多个首台套业绩及专利，核安全设备资质领先，行业需求受双碳政策及核电审批加速推动，量价齐升。
- **新能源电力销售（光伏）收入增长35.93%，成本下降8.05%** -> 新能源业务毛利率同比提升19.42个百分点至59.40%: 光伏电站运营稳定，成本中折旧占比大，收入增长摊薄固定成本，且绿电政策可能增厚收益。
- **公司持续研发投入（研发费用9160万元），拥有多项专利（母公司181项，格锐环境102项）** -> 核电、余热锅炉、压力容器等产品技术领先，维持高毛利率: 技术创新巩固了公司核心竞争力和市场地位，尤其在核电、余热锅炉领域的技术突破助力了高附加值订单获取。
- **库存量同比下降42.72%** -> 营业收入同比下降16.73%: 库存减少表明公司交付力度加大，但同时也反映出部分订单减少或备货谨慎，收入承压。
- **境外销售同比下降35.92%** -> 整体营业收入下降: 境外收入占比约5.9%，其大幅下滑对整体收入有负面影响，可能受国际环境或项目周期影响。

## 风险警告
收入结构依赖单一产品风险：锅炉收入下降36.88%，尽管核电产品大幅增长，但核电产品收入占比仍仅13.90%，且核电订单交付周期长、波动大。若未来核电订单不及预期，而传统锅炉业务持续下滑，将影响整体收入规模。
