## 因果逻辑链
- **增发股票及借款增加** -> 筹资活动现金流大幅增长: 筹资活动现金流净额同比增368.58%，主因增发股票收到募集资金及取得借款增加
- **收入增长带来的应收款项与合同资产账龄滚动** -> 信用减值损失与资产减值损失增加: 应收款项余额增长及账龄滚动导致按账龄组合计提的减值损失增加
- **金融业务投资净流出增加** -> 投资活动现金流大幅流出: 所属财务公司金融业务投资净流出增加导致投资活动现金流净额大幅下降
- **收入规模增长** -> 应收票据、应收账款、应收款项融资同步增长: 随收入规模增长，应收项目相应增加
- **采购付款流出增加** -> 经营活动现金流净额大幅下降: 采购付款同比增加，导致经营活动现金净流出显著扩大
- **能源装备制造收入增长** -> 营业收入整体增长: 煤电、风电、水电等能源装备制造板块收入增长，推动总收入同比增加12.80%
- **增发股票及贷款增加** -> 筹资活动现金流大幅增长: 通过增发和借款获取外部资金，支撑投资及运营
- **存货（主要在制品）余额增长** -> 占总资产比例提升: 在制品增加导致存货规模扩大，占资产比重上升
- **子公司股权处置减少** -> 投资收益同比下降: 2024年存在较大规模子公司股权处置收益，2025年减少导致投资收益同比下降45%

## 风险警告
公司当前存在多方面的风险：1）信用减值损失和资产减值损失随收入增长和账龄滚动而显著增加，提示应收账款和合同资产回收风险；2）经营活动现金流净额大幅下降，而投资活动现金净流出扩大，对外部融资依赖度上升，若融资环境变化或现金流持续承压，可能影响流动性；3）财务费用因汇兑损失和手续费增加而同比大幅上升，外汇风险敞口需关注；4）投资收益同比大幅下降，盈利来源的稳定性减弱。
