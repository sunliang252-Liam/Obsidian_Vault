# 301590.SZ 深度透视

## 因果逻辑链
- **[国内价格战加剧]** -> **内销毛利率下降6.36个百分点**: 国内充电模块销量虽增26.25%，但平均售价同比大跌22.99%，导致增收不增利。
- **[海外补贴政策退坡]** -> **外销收入骤降37.26%**: 欧美新能源补贴政策调整（如美国IRA提前终止），直接导致高毛利海外客户需求放缓。
- **[内销占比提升与回款周期拉长]** -> **应收账款激增与信用减值损失扩大45%**: 国内客户回款慢，导致应收账款显著增加，计提坏账大幅吞噬利润。
- **[持续加大研发投入]** -> **研发费用同比增长12.81%**: 为维持技术领先和布局新业务（如AI电源），公司逆势增加研发人员与投入，短期侵蚀利润。
- **[“以价换量”策略]** -> **经营现金流由正转负至-1.67亿元**: 国内降价促销虽保住了销量，但回款变差，叠加备货增加，导致经营性现金流净额同比暴跌247%。
- **[成功IPO与募投项目开工]** -> **净资产增长88.64%**: 2025年6月登陆创业板，募集资金到位，为后续产能扩张和研发升级提供资金基础。
- **[布局AI算力供电（HVDC）]** -> **培育第二增长曲线**: 成立子公司艾格数字能源，切入数据中心高压直流供电赛道，以应对单一行业周期风险。

## 风险警告
公司面临严重的“内卷”与“外冷”双重挤压。国内充电模块市场已陷入激烈的价格战，公司虽以量补价，但毛利率和净利润大幅下滑，盈利能力显著恶化。同时，海外市场作为此前的高利润来源，因欧美政策不确定性（特别是美国补贴退坡）而急剧萎缩，导致公司整体业绩失速。这种“内忧外患”的局面短期内难以逆转，是公司当前最核心的经营风险。

财务健康度急剧恶化。净利润暴跌58%的同时，经营性现金流由正转负至-1.67亿元，显示公司盈利质量极差，大量利润被应收账款和存货占用。应收账款坏账风险显著增加，若下游客户资金链出现问题，公司将面临更大的资产减值压力。尽管IPO补充了资本金，但造血能力的下降将制约公司未来的扩张和研发投入。
