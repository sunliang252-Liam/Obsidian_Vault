- **[AIDC/数据中心建设浪潮]** -> [营收增长38.44%]: 智算中心大规模建设拉动大功率高压发电机组需求，公司凭借数据中心领域先发优势，实现订单与交付量激增。
- **[海外数据中心市场拓展]** -> [海外收入增长26.44%]: 在东南亚（新加坡、马来西亚、印尼）数据中心市场实现大规模交付，并新设马来西亚子公司布局海外产能。
- **[核心部件依赖进口品牌]** -> [供应链紧张与成本压力]: 大功率发动机仍以进口/合资品牌为主，供应链扩产偏缓，叠加大宗商品涨价，导致采购成本增加，制约产能弹性。
- **[客户集中度极高]** -> [经营风险集中]: 前五大客户销售额占比59.93%，其中客户A和客户B为新增，收入高度依赖少数大客户，客户流失或采购模式变化将剧烈冲击业绩。
- **[应收账款与存货激增]** -> [现金流压力与减值风险]: 营收增长伴随应收账款增加47.65%、存货增加105.14%，导致经营性现金流净额下降22.82%，且信用减值损失同比大幅增加。
- **[投资收益与公允价值变动贡献利润]** -> [利润质量存疑]: 归母净利润5094万中，包含投资收益1171万（参股公司盈利）及公允价值变动收益1736万（非流动金融资产增值），扣非净利润仅3373万，主业盈利能力弱于表面。
- **[工程及后市场服务业务爆发]** -> [业务结构优化]: 工程业务收入同比增长769.26%，显示公司从单纯设备销售向“解决方案+长期服务”模式转型初见成效。

## 风险警告
**核心风险在于业绩的“虚胖”与现金流的“贫血”。** 公司营收暴增38%的背后，是应收账款和存货的同步膨胀，导致经营性现金流净额反而下降22.82%。更值得警惕的是，高达1736万的公允价值变动收益（来自非流动金融资产）和1171万的投资收益，合计占利润总额的50%以上，扣非净利润仅3373万。这意味着公司主业的真实造血能力和盈利质量远低于表面数字，一旦资本市场波动或参股公司业绩变脸，利润将大幅缩水。

**另一重大风险是业务和供应链的“双集中”脆弱性。** 前五大客户贡献了近60%的营收，且核心部件发动机严重依赖进口品牌。这种结构使公司极易受下游大客户采购策略变化、上游发动机厂商产能瓶颈或地缘政治导致的供应链中断的冲击。同时，公司历史上曾因未披露关联交易被监管处罚，内控合规风险仍需持续关注。
