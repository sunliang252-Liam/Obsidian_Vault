# 605138.SH 深度透视

## 因果逻辑链
- **[国内生产基地整合及NFW投资公允价值下跌]** -> [归母净利润同比下降34.90%]: 国内产能调整导致短期收入承压，同时参股植物皮革公司NFW估值大幅下降产生-2,654万元公允价值变动损失，双重挤压利润。
- **[海外业务增长强劲]** -> [境外收入同比增长3.08%，成衣销量增长5.92%]: 海外生产基地服务国际市场的双循环布局见效，越南、柬埔寨等产能支撑海外客户需求增长，抵消国内下滑。
- **[扣非净利润同比增长8.36%]** -> [经营性盈利能力改善]: 剔除NFW公允价值变动、资产处置损益等非经常性项目后，核心业务盈利能力实际提升，显示主业韧性。
- **[经营活动现金流净额6.18亿元，远超净利润]** -> [现金流质量优异]: 尽管净利润仅0.30亿元，但经营现金流高达6.18亿元，主要得益于营运资本管理优化及非现金费用（折旧摊销）的贡献。
- **[前五大客户集中度60.91%，关联方占比23.08%]** -> [大客户依赖风险]: 高度依赖伊藤忠、雅戈尔等核心客户，虽合作关系稳固，但议价能力受限，客户流失将造成重大冲击。
- **[资产负债率61.83%，担保总额占净资产116.09%]** -> [高杠杆运营]: 大量资产已抵押（19.85亿元），担保余额远超净资产，财务弹性受限，偿债压力较大。
- **[摩洛哥绿色纺织产业园项目启动]** -> [全球化布局再扩张]: 计划投资17.16亿元建设新产能，旨在规避贸易壁垒、贴近欧洲市场，但初期投入将加大资本开支和财务压力。
- **[研发投入仅占营收0.39%，研发人员占比0.81%]** -> [创新投入薄弱]: 作为技术驱动的纺织企业，研发强度偏低，长期可能削弱面料技术壁垒和产品差异化优势。

## 风险警告
**核心风险在于利润的“虚胖”与现金流的“实瘦”背离。** 公司2025年归母净利润仅3,037万元，但扣非净利润4,383万元，非经常性损益（尤其是NFW投资亏损）持续侵蚀利润表。更关键的是，公司资产负债率高达61.83%，对外担保总额达28.45亿元，占净资产116%，大量核心资产（固定资产、无形资产）已被抵押，财务杠杆已至极限。一旦下游需求或贸易政策出现不利变动，高负债结构将迅速放大经营风险。

**第二重风险来自客户集中与贸易政策的不确定性。** 前五大客户贡献超60%营收，其中关联方占23%，客户过于集中削弱了公司议价能力。同时，公司海外收入占比66.83%，且正在摩洛哥大规模投资建厂，全球贸易保护主义抬头、关税政策频繁调整，可能直接冲击公司核心的海外代工业务模式。此外，公司研发投入仅0.39%，在行业竞争加剧、消费偏好快速变化的背景下，技术护城河面临被侵蚀的风险。
