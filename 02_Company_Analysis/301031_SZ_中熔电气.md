# 301031.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升+公司产品份额扩大]** -> [营收增长52.89%]: 新能源汽车市场作为公司最大收入来源（占比65.31%），受益于行业增长及公司产品在宁德时代、比亚迪等头部客户中的份额提升，营收同比增长58.16%。
- **[激励熔断器/智能熔断器渗透率提升]** -> [第二增长曲线形成]: 针对新能源汽车主动保护需求开发的新产品，2025年营收同比增长88.05%，成为公司业绩增长的重要驱动力。
- **[储能及风光发电市场高景气]** -> [营收增长45.71%]: 受益于“双碳”战略及储能刚性需求，公司在阳光电源、华为等客户中的业务快速增长，贡献了23.40%的营收。
- **[海外市场拓展取得阶段性成果]** -> [境外营收增长71.66%]: 公司加速欧洲、北美、日韩布局，泰国工厂投产，境外营收占比提升至7.35%，毛利率高达54.15%，成为利润增长新引擎。
- **[规模效应与成本结构优化]** -> [净利润增长116.69%]: 营收高速增长摊薄固定成本，同时产线智能化升级提升效率，使得净利润增速远超营收增速，净利率大幅提升。
- **[研发投入持续加大]** -> [技术壁垒与产品迭代能力]: 研发费用增长33.79%，研发人员增长44.26%，聚焦激励熔断器、智能熔断器、继电器等新品，巩固了公司在电路保护领域的技术领先地位。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额增长254.15%至4.33亿元，与净利润规模匹配，显示公司回款能力增强，盈利质量显著改善。

## 风险警告
**客户集中度高与行业竞争加剧风险。** 公司前五大客户销售额占比43.69%，且下游新能源汽车、储能行业均为头部企业主导，议价能力强。随着行业竞争加剧，下游客户持续降本诉求将传导至上游，公司面临毛利率下降压力。同时，国际品牌在海外市场仍具规模优势，公司国际化扩张面临激烈竞争。

**应收账款与坏账风险。** 期末应收账款账面价值9.04亿元，占流动资产39.15%，且周转率仅2.71。下游客户回款周期较长，若客户经营出现不利变化，可能导致坏账损失及营运资金紧张。此外，公司业务高度依赖新能源产业政策，若政策发生重大不利变化，将对公司销售规模和盈利能力产生直接冲击。
