# 002838.SZ 深度透视

## 因果逻辑链
- **[改性塑料销量增长22.37%，产能利用率98.96%]** -> [营收增长14.25%]: 改性塑料作为第一大收入来源（占营收72.65%），以接近满产的产能利用率实现销量大幅增长，是营收创历史新高的核心驱动力。
- **[原材料价格下降]** -> [毛利率提升]: 主要原材料PP、ABS等价格下行，直接降低了营业成本，使改性塑料和热塑性弹性体毛利率分别同比提升0.15%和4.29%。
- **[收购宁波爱思开（EPDM）80%股权]** -> [产业链向上游延伸]: 收购核心原料EPDM生产商，从源头解决动态硫化平台产品的“卡脖子”问题，实现“聚合-改性-应用”全链条布局。
- **[DVA材料完成路测，技术获省级认可]** -> [打开颠覆性替代空间]: 全球唯二、国内唯一掌握DVA技术的企业，该材料有望颠覆传统轮胎气密层，市场空间广阔，是未来最大增长极。
- **[布局机器人柔性材料（SiTPV、导电TPE）]** -> [抢占新兴赛道先机]: 针对人形机器人仿真皮肤、人工肌肉等前沿需求进行技术储备，为未来在蓝海市场建立先发优势。
- **[经营活动现金流净额仍为负]** -> [利润质量存疑]: 尽管净利润增长34%，但经营现金流为-7578万元，主因是存货增加及回款中承兑汇票占比高，利润的现金保障度不足。
- **[销售费用同比增长40.17%]** -> [市场拓展力度加大]: 为应对激烈竞争和开拓新市场，公司主动加大销售投入，以费用换增长。

## 风险警告
**核心风险在于利润的现金转化效率低下与高资本开支带来的财务压力。** 公司2025年净利润增长34%，但经营活动现金流净额仍为-7578万元，连续两年为负。主因是下游回款中承兑汇票较多，而采购原材料需支付现汇，导致“纸面富贵”。同时，公司处于产能扩张期，在建工程、收购及新项目投资导致短期借款和长期借款分别增长40%和129%，财务费用虽因利率下降而减少，但债务规模扩大将增加未来利息支出和偿债压力。

**另一重大风险是原材料价格波动与下游成本传导的不确定性。** 公司主要原料PP、ABS等价格受国际油价影响，若未来油价上涨，成本压力将骤增。而公司下游客户（汽车、家电）多为强势企业，提价能力有限，利润空间可能被严重挤压。此外，募投项目（如10万吨TPU等）新增产能能否被市场消化，以及DVA等前沿技术能否顺利商业化，均存在不确定性。
