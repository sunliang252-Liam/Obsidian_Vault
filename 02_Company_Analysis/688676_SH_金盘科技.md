# 688676.SH 深度透视

## 因果逻辑链
- **[AIDC数据中心需求爆发]** -> [营收增长]: 公司紧抓AI算力基建浪潮，数据中心领域销售收入同比激增196.78%，成为业绩增长最强引擎。
- **[全球化布局与海外产能落地]** -> [外销高增]: 马来西亚工厂投产，海外本地化供给能力提升，外销收入同比增长16.01%，外销订单占比达35.74%。
- **[数字化转型降本增效]** -> [利润率提升]: 7座数字化工厂全面运营，精细化成本管控，销售毛利率同比提升1.53个百分点至25.85%，归母净利率提升0.72个百分点。
- **[客户结构优化与回款改善]** -> [现金流逆转]: 优质客户订单比例增长，加强应收账款催收，经营活动现金流净额由负转正，从-0.37亿元大幅改善至6.01亿元。
- **[非晶合金新材料自主突破]** -> [成本与竞争力优化]: 自研非晶带材产线投产成功，保障原材料供应并降低单位成本，提升非晶合金变压器产品市场竞争力。
- **[固态变压器（SST）与HVDC技术储备]** -> [抢占AIDC供电架构升级先机]: 完成SST样机设计与生产，HVDC产品点亮自有AI工厂，为下一代高功率密度数据中心供电方案奠定技术基础。
- **[储能业务技术迭代]** -> [系统集成能力增强]: 35kV高压直挂储能系统通过中国电科院构网型测试，中标中广核1.5GWh框架集采，储能业务收入同比增长18.64%。

## 风险警告
**核心风险在于国际贸易环境与地缘政治的不确定性。** 公司外销收入占比已超30%，且海外订单持续增长。全球主要经济体关税措施频繁调整，若贸易摩擦加剧或部分国家实施出口管制，将直接削弱公司产品在海外市场的价格优势，甚至导致订单获取受阻。此外，汇率大幅波动已导致2025年财务费用因汇兑损失同比大增107.94%，未来若人民币升值，将对公司出口业务利润产生持续侵蚀。

**另一重大风险是储能业务毛利率极低且竞争加剧。** 2025年公司储能系列产品毛利率仅为7.56%，同比下滑3.64个百分点，远低于电气设备系列28.17%的毛利率。储能行业技术路线尚未完全定型，政策依赖度高，且参与者众多导致价格战激烈。若公司不能通过技术迭代或规模效应快速提升储能业务的盈利能力，该板块将持续拖累整体利润水平，并可能面临存货减值风险。
