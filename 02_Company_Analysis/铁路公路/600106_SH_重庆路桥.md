# 600106.SH 深度透视

## 因果逻辑链
- **[嘉华大桥特许经营权]** -> [稳定现金流]: 年度路桥通行费收入1.95亿元全额到账，不受宏观经济波动影响，构成公司经营基本盘。
- **[持有重庆银行4.93%股权]** -> [投资收益核心]: 重庆银行资产规模突破万亿，2025年贡献分红约7,130万元，是利润的主要稳定来源。
- **[金融资产公允价值变动]** -> [利润波动放大器]: 持有的股票、基金等交易性金融资产公允价值变动收益达8,150万元，是利润总额的重要构成，但加剧了业绩波动。
- **[补缴BOT项目税款及滞纳金]** -> [净利润大幅下滑]: 因补缴长寿湖BOT项目税款4,084.74万元及滞纳金3,658.36万元，导致第四季度净利润亏损8,446.55万元，全年净利润同比下降27.59%。
- **[石门大桥资产移交停滞]** -> [资产萎缩风险]: 石门大桥收费权已于2021年底到期，但资产回购/置换工作仍在推进中，公司核心经营性资产持续减少。
- **[资产负债率低]** -> [财务稳健但增长乏力]: 资产负债率仅24.74%，财务结构安全，但主业收入固化（不足1.13亿），缺乏高回报的再投资渠道。
- **[战略转型至新质生产力]** -> [第二主业不确定性]: 公司明确向半导体等新质生产力产业投资转型，但报告期内转型进展有限，主要收益仍依赖金融投资和参股企业分红。

## 风险警告
公司最核心的风险是**资产萎缩与主业空心化**。嘉华大桥是仅存的核心收费资产，收入固化且增长空间有限；石门大桥移交悬而未决，资产规模面临持续缩水的压力。公司虽手握大量金融资产和现金，但缺乏能产生稳定、可观现金流的第二主业，导致公司更像一个“投资组合”而非实体运营企业。

其次，**业绩高度依赖金融投资收益和参股企业分红**，稳定性极差。2025年净利润下滑27.59%，主因是一次性的税务补缴，但扣非净利润也下降了13.73%。金融资产公允价值变动对利润影响巨大，且公司持有大量股票和基金，市场波动将直接冲击业绩。同时，公司无实际控制人，股权结构分散，战略转型的执行效率和方向存在较大不确定性。

**公司简介（F10 原文）**

> 重庆路桥股份有限公司是一家集城市路桥经营、城市基础设施建设、投资及房地产综合开发为一体的股份制企业。公司于1997年6月在上海证券交易所上市。公司具有建设部颁发的市政公用工程施工总承包一级资质;建筑工程施工总承包(贰级);市政设施维护甲级资质。公司成立以来,先后投资建设了茶园新区通江大道、嘉华嘉陵江大桥、西永软件园一期工程、长寿旅游专用高速公路和北山紫园等一批在重庆有影响的大型市政设施、公路工程和房地产开发建设项目,取得了良好的经济效益和社会信誉。公司投资建设并经营管理的嘉华大桥工程为市政府重点工程,该工程以其高品质的建设质量,不仅荣获了“巴渝杯优质工程奖”和“重庆市市政工程金杯奖”,而且作为全市路桥项目的唯一代表,获得了国家工程建设领域的国家级大奖-“2008年度市政金杯示范工程奖”、“2009年度国家优质工程银质奖”。2022年,为进一步提高公司资产质量,培育公司核心竞争力及持续盈利能力,公司调整了战略发展方向。在保持进一步优化提升传统主业不变的同时,增加集成电路和高科技产业投资的第二主业,力争在新的领域寻求发展机遇。未来,公司两大主业将相互促进、互为支撑。公司将在积极练好内功的基础上,努力抢抓机遇,开拓创新,推动企业高质量发展,争取为重庆市建设和社会经济发展中作出新的更大的贡献。
