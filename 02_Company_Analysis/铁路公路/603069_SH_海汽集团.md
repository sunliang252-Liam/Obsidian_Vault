# 603069.SH 深度透视

## 因果逻辑链
- **[高铁与私家车冲击传统客运]** -> [客运量下降14%，客运收入减少]: 高铁网络扩张和私家车普及分流了中长途及短途出行需求，导致公司核心班线客运业务量价齐跌。
- **[剥离低效燃油贸易业务]** -> [营业收入下降25.88%，但亏损收窄]: 转让海汽器材公司100%股权，剥离了毛利率极低的燃油销售业务，虽使营收规模大幅缩减，但优化了业务结构，减少了亏损源。
- **[定制客运与交旅融合业务增长]** -> [部分对冲传统业务下滑]: 定制客运收入同比增长27%，环岛旅游巴士等新业务模式开辟了增量市场，但体量尚小，未能扭转整体颓势。
- **[资产处置与关联交易]** -> [增加非经常性收益，改善现金流]: 出售子公司股权及收回欠款，使经营活动现金流净额由负转正至1.44亿元，并确认了约500万资产处置收益，缓解了短期资金压力。
- **[场站资源垄断优势]** -> [维持客运业务基本盘]: 公司独家运营海南省二级以上全部客运站，拥有23个三级以上车站，构成了区域性的准入壁垒，是其在客运量下滑背景下仍能维持一定收入的基础。
- **[重大资产重组（收购海旅免税）停滞]** -> [转型预期落空，估值承压]: 因标的公司业绩不及预期，收购海南旅投免税品公司的重组方案推进存在重大不确定性，公司向免税业务转型的战略愿景受阻，市场对其未来成长性的预期降低。

## 风险警告
**核心风险在于主业持续萎缩与转型失败的双重打击。** 公司传统道路客运业务受高铁、网约车和私家车的不可逆冲击，客运量和收入连年下滑，基本盘正在瓦解。尽管公司尝试发展定制客运、租车等新业务，但体量微小，无法弥补主业缺口，导致公司连续三年亏损，母公司未分配利润赤字高达2.48亿元，不具备分红能力。

**最大的不确定性来自重大资产重组的失败风险。** 公司自2022年起筹划收购海旅免税100%股权，意图跨界免税业务实现转型。然而，报告期内明确表示因免税市场竞争激烈、标的公司业绩不及预期，重组推进存在重大障碍。一旦重组最终失败，公司将失去唯一的转型抓手，回归一个持续亏损、缺乏成长性的传统交运企业，其估值逻辑将面临崩塌。
