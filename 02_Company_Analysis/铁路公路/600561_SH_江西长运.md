# 600561.SH 深度透视

## 因果逻辑链
- **[高铁、私家车、网约车持续分流]** -> [客运量下降11.17%]: 多元出行方式冲击传统道路客运，导致公司核心业务收入萎缩。
- **[政府补助大幅增加]** -> [归母净利润增长45.32%]: 计入其他收益的政府补助同比增加5564万元，是公司扭亏为盈的关键非经营性支撑。
- **[资产处置收益]** -> [扣非净利润仍为负]: 处置站场、土地等资产获得3427万元收益，掩盖了主营业务实际亏损（扣非净利润-3754万元）。
- **[高负债率与财务费用]** -> [侵蚀利润]: 73.52%的资产负债率及13.39亿元短期借款，导致每年超6600万元财务费用，严重拖累盈利能力。
- **[责任经营模式]** -> [维持客运网络但控制成本]: 90%以上班线采用责任经营，将经营风险部分转移给承包人，降低了公司直接运营成本。
- **[数智化转型与场景化运营]** -> [探索新增长点]: 开通792条定制专线（校园、文旅），试图通过差异化服务对抗行业下行，但规模尚小。
- **[母公司累计未弥补亏损]** -> [无法分红]: 母公司未分配利润为-6054万元，不满足现金分红条件，股东回报缺失。

## 风险警告
**核心风险在于主营业务已丧失造血能力，利润完全依赖外部输血和资产变现。** 公司扣非净利润连续为负，道路客运毛利率为-47%，表明每做一单客运生意都在亏损。当前盈利完全依赖政府补助（5.23亿元）和一次性资产处置收益，这种模式不可持续，一旦补助政策变动或可处置资产枯竭，公司将重回深度亏损。

**财务风险极高，偿债压力巨大。** 73.52%的资产负债率叠加13.39亿元短期借款，每年财务费用超过6600万元，如同在主营业务失血的情况下还要背负沉重利息负担。公司虽有30.9亿元经营现金流，但其中包含大量政府补助，实际经营活动产生的现金净额在扣除补助后可能为负，存在流动性风险。

**公司简介（F10 原文）**

> 江西长运股份有限公司前身是国有企业江西长途汽车运输公司,于1993年4月3日以定向募集方式设立,是一家具有道路旅客运输一级资质的企业,主要从事道路客运、客运站点建设及维护运营、物流、汽车租赁和物业管理等业务。2002年7月,公司在上海证券交易所首次公开发行股票并上市,成为中国资本市场中以道路客运为主业的上市公司。股票简称:江西长运,股票代码:600561。公司自上市以来,紧紧把握道路运输行业集约化经营、规模化发展的趋势,先后成功与景德镇、吉安、黄山、马鞍山、新余、抚州、婺源、萍乡、上饶、鄱阳、鹰潭等多家当地客运公司达成合作,并组建了新余、吉安、鹰潭、景德镇、婺源五个公交公司。通过实施跨地区合作整合客运资源,形成了具有长运特色的合作共赢发展模式,同时也积累了丰富的并购重组经验与人才。公司在扩张中兼顾规模和效益,在并购整合阶段,公司注意着力推进对合作企业管理体系、运营体系和文化建设的一体化协同,均取得良好整合成效。公司是江西省公路客运行业的龙头企业,在江西省11个地级市中已拥有除赣州和宜春外9个地级市的站场资源和班线资源。截至2022年末,公司共运营客运站场78个,拥有建制车辆8,483辆,营运班线1,399条,在江西省道路客运市场已形成规模优势、网络优势、集约化优势和一体化协同优势。多年来,公司一直致力于为人们的出行提供满意、温馨的全方位服务,在旅客中形成较广泛的品牌认知度和良好的品牌美誉度。在中国道路运输协会评选的“中国道路运输百强诚信企业(2022年)”中,公司位居第9位。
