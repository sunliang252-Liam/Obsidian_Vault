# 000429.SZ 深度透视

## 因果逻辑链
- **[核心路产改扩建与路网分流]** -> [核心路产收入分化]: 佛开高速、广珠段受深中通道等新路分流及自身施工影响，通行费收入同比下降；而惠盐高速因改扩建通车，收入同比大增22%。
- **[广佛高速收费权到期与代垫款回收]** -> [归母净利润大增15.31%]: 广佛高速2022年停止收费，但2025年政府明确资金来源，公司冲回前期计提的3.43亿元代垫管养支出坏账准备，大幅增厚非经常性损益。
- **[改扩建项目资本开支激增]** -> [资产负债率与有息负债攀升]: 广珠东、广惠高速改扩建工程投入巨大，报告期投资额同比增62.8%，长期借款增至100.36亿元，资产负债率从41.2%升至46.98%。
- **[贷款利率下降与债务结构优化]** -> [财务费用大幅缩减42.7%]: 公司利用低利率环境偿还高息中期票据并置换为低息长期借款，利息支出显著减少，直接提升利润空间。
- **[高分红政策锁定]** -> [股东回报确定性增强]: 公司承诺2024-2026年现金分红不低于归母净利润70%，2025年预案维持70%分红率，对追求稳定现金流的投资者构成核心吸引力。
- **[粤港澳大湾区经济韧性]** -> [车流量需求刚性]: 核心路产位于广东经济核心区，区域GDP超14万亿，客货运输需求以刚性为主，有效对冲了部分路产因分流导致的流量下滑。
- **[会计估计变更（折旧年限延长）]** -> [当期利润增厚]: 因广惠高速改扩建延长经营期限，公司调整相关互通立交折旧年限，减少当期营业成本5720万元，增厚归母净利润2188万元。

## 风险警告
**核心风险在于改扩建期间的“收入空窗”与“资本开支高峰”的双重挤压。** 公司核心路产（广珠东、广惠高速）正处大规模改扩建施工期，施工导致的车流量分流和通行费收入下滑（广珠段收入同比下降11.5%）已成现实。同时，改扩建项目总投资高达数百亿，导致公司有息负债和财务费用在未来数年将持续承压，资产负债率已显著攀升。若改扩建完成后车流量增长不及预期，将面临资产回报率下降的风险。

**另一重大风险是路网分流效应的长期化与不可预测性。** 深中通道、南中高速等新开通的平行或交叉路网，已对佛开高速、广珠段产生显著分流。广东省路网加密是大势所趋，未来新路开通可能持续侵蚀公司存量路产的车流量和收入，这一结构性冲击并非短期施工扰动，而是长期竞争格局的演变。此外，收费政策调整风险始终存在，公司对收费标准缺乏自主定价权。
