# 000828.SZ 深度透视

## 因果逻辑链
- **[核心路产改扩建施工及恶劣天气]** -> [通行费收入下降2.48%]: 莞深高速改扩建“边施工、边运营”叠加极端天气，导致混合车流量同比下降2.15%，拖累核心收入。
- **[宏通保理计提大额信用减值]** -> [归母净利润下降13.79%]: 宏通保理因市场环境及资产质量恶化，计提信用减值损失2.40亿元，导致其净利润为-1.93亿元，直接侵蚀合并利润。
- **[受让东莞证券7.1%股权]** -> [投资收益同比增长29.06%]: 公司增持核心金融资产，叠加资本市场行情回暖，东莞证券净利润增长34.82%，为公司贡献稳定增长的投资收益。
- **[压降类金融业务规模]** -> [经营活动现金流净额大增68.97%]: 公司主动收缩融资租赁及保理业务投放，导致经营现金流出大幅减少，现金流表现强劲。
- **[莞深高速改扩建工程持续推进]** -> [在建工程大幅增加，资本开支高企]: 改扩建项目累计投入43.22亿元，占总投资的24.58%，导致在建工程同比增长59.3%，投资活动现金流净流出9.61亿元。
- **[压降借款规模]** -> [财务费用同比下降73.74%]: 公司主动偿还债务，利息支出大幅减少，财务费用从0.44亿元降至0.11亿元。
- **[高比例现金分红承诺]** -> [股东回报预期稳定]: 公司发布《2025-2027年股东分红回报规划》，承诺每年每股分红不低于0.475元，以稳定回报吸引长期投资者。

## 风险警告
**核心风险在于宏通保理的资产质量恶化。** 报告期内，宏通保理因瑞盈酒店等保理项目逾期，计提了2.40亿元的信用减值损失，直接导致其亏损1.93亿元，成为拖累公司整体利润的最大因素。尽管公司正通过法律手段处置，但酒店市场行情低迷，债权变现存在重大不确定性，未来减值风险仍可能持续爆发，侵蚀公司利润。

**另一重大风险是莞深高速改扩建带来的经营与财务压力。** 改扩建工程总投资概算高达175.84亿元，目前仅完成24.58%，未来资本开支压力巨大，将持续消耗公司现金流并推高负债。同时，“边施工、边运营”的模式已导致车流量和通行费收入下降，若施工期拥堵加剧或出现安全事故，将对核心路产的盈利能力造成更大冲击。此外，现有收费期限至2027年6月30日，虽可申请延期，但最终获批年限存在不确定性。
