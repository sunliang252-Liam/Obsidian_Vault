# 600035.SH 深度透视

## 因果逻辑链
- **[汉宜高速改扩建项目推进]** -> [营业收入暴增49.83%]: 建造服务收入按会计准则确认，成为营收最大增量，但毛利率为零，不贡献利润。
- **[大广北高速特许经营权减值]** -> [归母净利润骤降29.67%]: 受平行路段分流及收费政策影响，大广北高速车流量及收益预期恶化，计提3.2亿元减值准备，直接吞噬利润。
- **[核心路产汉宜高速改扩建施工]** -> [通行费收入下滑5.73%]: 施工期间交通管制导致部分车辆分流至竞争性路段，核心路产短期收入承压。
- **[平行竞争性路段开通及优惠政策]** -> [大广高速全线车流分流]: 京武高速安罗段、和襄高速鸡商段等新路开通并实施货车折扣，对大广北、新县、光山段形成显著分流效应。
- **[会计估计变更（调整车流量模型）]** -> [营业成本增加1633万元]: 基于实际车流量数据调整剩余收费期限摊销模型，导致大随、黄咸等路段当期摊销额增加。
- **[债务融资结构调整]** -> [财务费用下降16.19%]: 以长期公司债、中期票据置换短期融资券，优化债务期限结构，降低短期偿债压力及利息成本。
- **[汉宜改扩建项目投资增加]** -> [投资活动现金流净流出扩大53.53%]: 项目累计投资已达118亿元，资本开支大幅增加，对现金流形成巨大压力。
- **[主体信用评级获AAA]** -> [融资成本降低]: 高信用评级支撑公司成功发行低利率债券（如1.71%的3年期中期票据），有效控制资金成本。

## 风险警告
**核心风险在于汉宜高速改扩建的“双刃剑”效应。** 该项目是当前营收增长的核心驱动力（建造服务收入），但也是现金流出的最大黑洞（累计投资118亿，导致投资活动净流出37亿）。同时，施工期间的交通管制已对汉宜高速通行费收入造成负面影响，若后续分流加剧或工期延误，将直接冲击公司最核心的利润来源。此外，高达55.39%的资产负债率及持续扩大的债务规模，使公司财务弹性受限，对利率变动敏感。

**资产减值风险是利润表的最大“暗雷”。** 2025年大广北高速3.2亿元的减值已证明，在路网分流、收费政策调整（如差异化收费优惠）及经济环境压力下，公司旗下多条路产（尤其是大随、光山等高负债率路段）面临收益不达预期的风险。若未来车流量持续低迷，可能触发更多路段特许经营权减值，对净利润造成重大冲击。
