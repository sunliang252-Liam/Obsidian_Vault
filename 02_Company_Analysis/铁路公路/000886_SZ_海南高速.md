# 000886.SZ 深度透视

## 因果逻辑链
- **回归交通主业，构建建材供应链** -> **营收暴增182%**: 公司以服务省级重点交通项目为抓手，整合碎石、沥青加工仓储网络，交通建材销售业务量激增，驱动总收入从2.33亿跃升至6.57亿。
- **增持海汽集团与联合资产** -> **投资收益成利润核心**: 对联营企业（海汽集团、联合资产）的投资收益高达3.63亿元，是净利润（1.55亿）的2.3倍，构成利润的主要来源，掩盖了主营业务的真实盈利能力。
- **嘉浪雅居项目竣工交付** -> **房地产业务收入激增722%**: 琼海嘉浪雅居项目于2025年5月竣工验收并开始销售，带动房地产业务收入从419万增至3445万，但高库存（7.3万平米）和低毛利率（35.79%）表明去化压力巨大。
- **布局“数智高速海底智算中心”** -> **培育未来增长点**: 投资建设海底智算中心，开创“海洋资源+数字产业”新模式，入选海南科技创新事件，是公司向“数智交通”转型的标志性动作，但尚未贡献利润。
- **低空经济试点应用** -> **探索降本增效新路径**: 无人机巡检覆盖280公里，成本较人工降低50%，成功识别道路病害，为后续商业化运营积累数据，但尚处探索阶段。
- **受让交控石化51%股权** -> **切入成品油产业链**: 通过重大资产重组收购交控石化，旨在打通交通产业链上下游，获取新的业务支柱和利润增长点，但整合效果尚待观察。
- **经营活动现金流持续为负** -> **盈利质量存疑**: 尽管净利润为正，但经营活动现金流净额为-1.69亿元，主要因净利润中包含大量未变现的权益法投资收益，显示公司主营业务的现金创造能力依然薄弱。

## 风险警告
**核心风险在于盈利的“虚胖”与现金流的“贫血”。** 公司2025年净利润1.55亿，但超过2.3倍（3.63亿）来自对联营企业的投资收益，扣非后净利润虽增长但基数极低。同时，经营活动现金流净额为-1.69亿，连续三年为负，表明交通建材等主营业务的扩张并未带来真金白银，而是占用了大量营运资金，盈利质量堪忧。

**转型新业务面临不确定性，存量资产去化压力大。** 公司大力布局的数智交通、低空经济等新质生产力尚处培育期，短期内无法贡献利润，且面临市场竞争激烈、经验不足的风险。同时，房地产业务库存激增（嘉浪雅居项目库存7.3万平米），在海南楼市筑底阶段，去化周期和资产减值风险不容忽视。公司计划不派发现金红利，也印证了资金链的紧张。
