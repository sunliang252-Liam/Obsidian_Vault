# 600834.SH 深度透视

## 因果逻辑链
- **[关联交易依赖]** -> [营收稳定但增长乏力]: 公司56.5%营收来自控股股东申通地铁集团，业务高度绑定，缺乏市场化扩张弹性。
- **[新能源业务高增]** -> [利润结构优化]: 光伏装机容量达67.3MWp（全国轨交第一），发电量同比+28%，带动新能源板块营收+29%、净利+53%，成为利润增长核心引擎。
- **[融资租赁业务收缩]** -> [营收结构被动调整]: 受监管压降类金融业务影响，融资租赁营收同比-32%，公司主动出售该子公司，聚焦主业。
- **[投资收益驱动利润]** -> [非经常性损益占比高]: 投资收益同比+96%（主要来自结构性存款），占归母净利润的38%，主业盈利能力被稀释。
- **[地铁物业业绩承诺达标]** -> [并购整合初显成效]: 地铁物业扣非净利1082万元，超出承诺7.4%，验证了“运维+物业”协同逻辑。
- **[财务费用大幅下降]** -> [负债结构优化]: 新能源公司归还长期借款，财务费用同比-82%，资产负债率从21%降至12%，财务风险降低。
- **[现金流恶化]** -> [类金融业务收缩的代价]: 经营现金流净额同比-29%，主因融资租赁/保理存量项目到期回收减少，短期流动性承压。

## 风险警告
**核心风险在于业务空心化与增长天花板。** 公司营收高度依赖关联交易（申通地铁集团占56.5%），市场化拓展能力薄弱。尽管新能源业务高增，但光伏装机增速已放缓（七期仅4.9MWp），且面临电价市场化冲击。融资租赁出售后，公司失去类金融利润贡献，短期需依赖投资收益（结构性存款）维持利润，可持续性存疑。

**资产出售与诉讼执行构成潜在黑天鹅。** 融资租赁公司股权转让虽已签约，但交易对手张江集团为地方国企，若后续整合不及预期，可能影响回款节奏。此外，上实保理股权诉讼虽胜诉，但执行阶段存在不确定性（对方已申请破产），1.375亿元股权回购款能否全额收回仍是未知数。
