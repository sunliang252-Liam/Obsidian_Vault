## 因果逻辑链
- **[哈大高速经营权2029年到期]** -> [主业根基动摇]: 核心路产剩余经营期仅4年，未来现金流稳定性面临根本性挑战，倒逼公司加速新产业布局。
- **[收购水运公司100%股权]** -> [清洁能源规模跃升]: 新增水力发电业务，贡献营收1.67亿元、净利润0.28亿元，占合并净利润15.85%，迅速壮大能源板块。
- **[贸易业务改用净额法核算]** -> [营收规模大幅缩水]: 龙翼投资收入确认方式变更，导致总营收同比下降23.77%，但毛利率被动提升，利润质量改善。
- **[龙翼投资支付前期沥青采购款1.8亿]** -> [经营性现金流骤降68.66%]: 大额应付账款集中清偿，叠加销售回款减少，导致经营活动现金流净额从7.97亿降至2.50亿。
- **[石墨矿200万吨采选项目获批]** -> [新材料产业进入重资产投入期]: 项目前期决策通过，后续需增资不超过4.43亿元，将显著增加资本开支与财务压力。
- **[信通地产尾盘去化]** -> [地产收入逆势增长]: 通过动态定价与租售结合，实现营收1.48亿元，同比增276.55%，成为短期业绩重要支撑。
- **[回购股份注销]** -> [每股收益与净资产提升]: 注销1040.87万股，在净利润微降背景下，每股收益仅降5.57%，每股净资产因股本减少而被动增厚。

## 风险警告
**核心风险：主业经营权到期与转型不确定性。** 哈大高速收费权将于2029年到期，仅剩4年。届时公司最稳定的现金流来源将消失，而石墨、光伏等新产业尚处投入期，远未形成可替代的盈利规模。若新产业落地不及预期，公司将面临业绩断崖式下滑的风险。

**财务风险：现金流恶化与资本开支压力。** 2025年经营性现金流净额同比暴跌68.66%，主要因贸易业务回款周期错配。同时，石墨矿项目预计需投入超4.4亿元，叠加收购水运公司已耗资1.5亿元，未来资本开支压力巨大。公司资产负债率已从12.5%升至22.55%，财务杠杆正在快速攀升。

**治理与合规风险：担保与诉讼遗留问题。** 公司收购水运公司后，承继了高达13.93亿元的对外担保（占净资产29.25%），且水运公司存在1,500万元的预计负债（涉诉案件）。这些历史遗留问题可能在未来引发或有负债，侵蚀公司利润。
