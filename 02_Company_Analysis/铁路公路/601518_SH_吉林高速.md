# 601518.SH 深度透视

## 因果逻辑链
- **[车流量减少]** -> [通行费收入下降1.56%]: 宏观经济波动及路网分流导致长平高速及绕城高速车流量下滑，直接拖累核心收入。
- **[子公司机电工程收入骤降28.83%]** -> [总营收下降7.85%]: 科维公司竣工验收项目减少，导致高毛利机电工程收入大幅萎缩，成为营收下滑主因。
- **[偿还全部超短期融资券]** -> [财务费用由正转负]: 债务清零后利息支出大幅减少，叠加定期存款利息收入，财务费用从-1292万降至-1995万，显著增厚利润。
- **[经营活动现金流净额增长4.34%]** -> [现金储备增至22.8亿]: 子公司科维工程回款改善，推动经营性现金流持续为正，货币资金占总资产比例升至33.82%。
- **[资产负债率仅8.13%]** -> [财务弹性极强]: 极低的杠杆率使公司几乎无债务风险，为未来资本运作和多元化投资提供充足空间。
- **[高分红政策延续]** -> [股东回报稳定]: 2025年拟每10股派1.3元，分红比例50.07%，近三年累计分红比例高达110.11%，体现高股息防御属性。
- **[路产剩余收费年限缩短]** -> [长期盈利可持续性承压]: 长平高速（至2040年）和绕城西北环（至2031年）收费权期限有限，核心资产价值随时间递减。

## 风险警告
**核心风险在于单一资产依赖与收费权期限。** 公司99%以上的利润来自长平高速和长春绕城高速的通行费，业务结构极度单一。长平高速收费权仅剩约15年，绕城西北环仅剩约6年，核心资产的“生命倒计时”是悬在长期估值上的达摩克利斯之剑。若无法在期限内找到新的利润增长点，公司价值将随收费权到期而大幅缩水。

**增长动力缺失与关联交易依赖。** 2025年营收与净利润双降，子公司科维工程收入大幅波动，显示公司缺乏稳定的第二增长曲线。同时，公司大量养护、工程业务依赖控股股东吉高集团，关联交易金额巨大，虽属行业常态，但削弱了经营的独立性和市场化议价能力。未来数字化转型项目（中标14.3亿）能否转化为持续利润，尚需观察。
