# 601198.SH 深度透视

## 因果逻辑链
- **[市场交易活跃度提升]** -> [财富管理收入增长18.40%]: 2025年A股日均成交额同比上涨70%，直接带动公司代理买卖证券业务净收入（含席位租赁）同比增长31.37%。
- **[IPO市场回暖]** -> [投行业务收入暴增115.49%]: 2025年A股IPO融资额同比增长95.61%，公司抓住机遇完成4单IPO，主承销家数行业排名并列第9，驱动投行业务收入大幅增长。
- **[权益市场上涨]** -> [投资交易业务贡献稳定利润]: 上证综指上涨18.41%，公司权益类投资坚持绝对收益理念，把握市场机遇，实现投资业绩显著提升，对冲了固收市场波动的影响。
- **[信用减值损失大幅减少]** -> [净利润增速远超营收增速]: 2025年信用减值损失同比减少83.35%，资产质量改善，使得净利润（+36.10%）增速显著高于营业收入（+10.25%）增速。
- **[控股股东协同优势]** -> [差异化竞争力]: 依托控股股东中国东方（AMC）的不良资产主业，公司在特殊机会投资、企业纾困、破产重整等领域形成独特优势，与集团协同发展。
- **[被中金公司吸收合并]** -> [公司未来路径根本性改变]: 中金公司换股吸收合并东兴证券，公司将于交割后终止上市并注销法人资格，股东将转换为中金公司股票。

## 风险警告
**核心风险在于吸收合并的不确定性。** 公司已公告将被中金公司换股吸收合并，该交易尚需多方审批，存在被暂停、中止或取消的风险。一旦交易完成，东兴证券将退市注销，投资者将被动成为中金公司股东，其未来收益完全取决于中金公司的股价表现和经营状况，东兴证券作为独立主体的投资逻辑将不复存在。

**其次，业绩对市场环境高度敏感。** 公司财富管理和投资交易业务收入占比近80%，与A股市场交易量、指数走势高度相关。2025年业绩高增长主要受益于市场回暖，若未来市场活跃度下降或出现大幅调整，公司营收和利润将面临显著下滑压力。同时，公司债券投资规模巨大，利率波动风险不容忽视。
