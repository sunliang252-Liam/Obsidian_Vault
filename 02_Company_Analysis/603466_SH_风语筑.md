# 603466.SH 深度透视

## 因果逻辑链
- **[文化及品牌数字化体验空间业务爆发]** -> [营收增长20.72%]: 该业务收入同比增长52.99%，成为拉动整体营收的核心引擎，弥补了城市数字化体验空间业务的大幅下滑。
- **[“现金为王”策略与付款管控]** -> [经营现金流大幅转正至1.86亿]: 公司主动减少付款，强化回款管理，使得经营活动现金流从-0.32亿大幅改善，为持续亏损下提供安全垫。
- **[高额信用减值损失]** -> [持续亏损（-1837万）]: 尽管营收增长，但高达1.52亿的信用减值损失（主要来自应收账款）严重侵蚀利润，是连续第二年亏损的直接原因。
- **[业务结构从“建设”向“运营”转型]** -> [毛利率微增0.36个百分点]: 公司战略转向长效运营和轻资产模式，推动整体毛利率从23%小幅提升至23.34%，盈利能力结构性改善。
- **[AI与具身智能技术投入]** -> [研发费用刚性支出]: 公司持续在AIGC、具身智能等前沿领域投入研发（5835万），虽短期增加成本，但旨在构建长期技术壁垒与降本增效。
- **[大股东持续减持]** -> [市场信心承压]: 控股股东李晖、辛浩鹰夫妇在报告期内通过大宗交易和集中竞价合计减持约2939.95万股，向市场传递了负面信号。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长20.72%，但净利润仍亏损1837万，根本原因是高达1.52亿的信用减值损失。这直接暴露了公司以政府及大型企业为主要客户的商业模式弊端：项目周期长、回款慢，导致应收账款高企（11.65亿），一旦客户财政紧张，坏账风险便集中爆发。尽管经营现金流改善，但这更像是“节流”而非“开源”的结果，可持续性存疑。

**另一重大风险是核心股东持续减持与行业竞争加剧。** 控股股东夫妇在报告期内大规模减持套现，严重削弱了市场对公司长期价值的信心。与此同时，数字展示行业竞争已从单一项目交付升级为“技术+内容+运营”的全方位比拼，公司不仅面临同行业竞争，还面临广告、建筑设计等领域的跨界渗透。若公司无法在AI、具身智能等新赛道上快速形成商业化闭环，其龙头地位可能被后来者侵蚀。
