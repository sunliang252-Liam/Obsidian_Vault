# 600751.SH 深度透视

## 因果逻辑链
- **[商品贸易业务规模扩张]** -> [营收增长37.99%]: 公司以玉米等农产品为核心，利用资金优势扩大贸易规模，营收从11.17亿增至15.41亿，但毛利率仅2.39%，拉低了整体盈利质量。
- **[航运业务收入下滑]** -> [归母净利润下降17.36%]: 尽管运力增至140万载重吨，但BDI指数波动及行业需求疲软，航运收入同比下降14.66%，毛利率下降4.13个百分点，拖累整体利润。
- **[使用公积金弥补亏损]** -> [实现现金分红]: 公司通过资本公积和盈余公积弥补累计亏损，使未分配利润转正，得以实施每10股派0.18元的现金分红，分红率50.74%。
- **[财务担保债务和解]** -> [非经常性损益支撑利润]: 报告期内确认财务担保合同减值转回2967万元，是扣非净利润（5953万）的重要补充，掩盖了主业盈利能力的下滑。
- **[自有船舶无融资成本]** -> [成本优势]: 10艘自有船舶均为自有资金购入，无直接融资成本，使公司在运价低迷期仍能维持一定盈利，较同业具备更强抗风险能力。
- **[“航运+贸易”双轮驱动]** -> [平滑周期波动]: 贸易业务（营收占比67.7%）与航运业务形成互补，在航运市场下行时，贸易业务规模扩张支撑了整体营收增长，降低了业绩波动性。
- **[历史担保遗留风险]** -> [现金流持续承压]: 公司仍需支付历史担保债务和解款，导致经营活动现金流净额为-2.17亿元，虽较上年改善，但现金回流能力依然薄弱。

## 风险警告
**核心风险在于历史担保包袱与主业盈利能力下滑的双重挤压。** 公司虽通过债务和解逐步化解部分担保风险，但截至报告期末，对外担保余额仍高达3.04亿元（主要为关联方担保），且部分担保已逾期。这些历史遗留问题持续消耗公司现金流（经营活动现金流连续两年为负），并可能在未来引发新的诉讼或资产冻结，对经营稳定性构成根本威胁。

**航运主业面临结构性挑战。** 公司航运收入同比下降14.66%，毛利率降至7.8%，显示其在BDI波动加剧的背景下，精细化运营未能完全对冲市场下行风险。同时，公司计划处置1-6艘老旧船舶并更新船队，该资本开支计划将加大未来现金流压力。若航运市场持续低迷，新船投入可能无法带来预期回报，反而加重资产负担。

**贸易业务增长质量存疑。** 商品贸易业务营收同比暴增90.42%，但毛利率仅为2.39%，且前五大客户和供应商集中度较高（均超30%），存在依赖少数交易对手的风险。该业务本质上是利用资金优势进行的低毛利周转，一旦市场供需失衡或信用风险暴露，可能引发库存积压和坏账损失，其可持续性和抗风险能力有待验证。
