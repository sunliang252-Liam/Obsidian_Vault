# 688211.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧与定价策略调整]** -> [毛利率持续下滑]: 为应对激烈市场竞争、保持市场份额，公司对部分产品调整定价策略，导致2025年毛利率同比下降1.68个百分点至19.50%，连续三年下滑。
- **[历史低毛利项目集中验收]** -> [营收增长但利润承压]: 2025年营收同比增长2.57%，但营业成本增速（+4.75%）快于营收，主要系以前年度低价承接的项目在本期陆续验收，侵蚀利润。
- **[应收账款规模扩大]** -> [信用减值损失激增]: 期末应收账款余额增加，导致2025年信用减值损失同比增加6,654.64万元，成为净利润亏损的主要拖累因素之一。
- **[长账龄项目验收推进]** -> [资产减值损失大幅减少]: 公司大力推进长账龄在安装项目的验收工作，资产减值损失同比减少9,880.89万元，部分对冲了信用减值损失的影响。
- **[产品结构向高增长领域倾斜]** -> [智能仓储与窄带机业务爆发]: 智能仓储系统营收同比增长480.20%，窄带机式营收同比增长204.69%，成为驱动营收增长的新引擎，但新业务毛利率尚不稳定。
- **[海外市场持续拓展]** -> [营收贡献稳定但毛利率承压]: 海外营收占比约13%，保持稳定，但海外业务毛利率同比下降6.87个百分点，反映海外市场竞争加剧及成本上升。
- **[在手订单充足]** -> [未来营收保障]: 截至2025年末，在手订单33.25亿元，其中国内占比77.35%，海外22.65%，为后续收入确认提供坚实基础。

## 风险警告
公司面临的核心风险是**盈利能力持续恶化**。营收虽保持增长，但毛利率已从2023年的22.86%下滑至2025年的19.50%，连续三年下降，且连续两年录得净亏损。这并非短期波动，而是行业竞争加剧导致定价能力削弱、历史低价订单集中消化、以及应收账款坏账风险累积的综合结果。若无法通过技术创新或成本控制扭转毛利率颓势，公司可能陷入“增收不增利”甚至“增收反亏”的困境。

另一个关键风险是**客户集中度高与应收账款回收压力**。前五大客户收入占比高达55.47%，且下游快递物流行业客户议价能力强，导致公司应收账款规模持续扩大，信用减值损失激增。一旦主要客户经营状况波动或付款周期延长，公司将面临较大的坏账风险和现金流压力。尽管在手订单充裕，但订单转化为利润和现金的效率正面临严峻考验。
