# 603659.SH 深度透视

## 因果逻辑链
- **[全球储能电池出货量爆发式增长]** -> [公司涂覆隔膜与PVDF销量大增]: 储能市场成为锂电核心增长引擎，公司作为上游材料龙头，直接受益于下游需求扩容。
- **[“材料+设备+工艺”一体化闭环]** -> [成本优势与客户粘性]: 基膜自给率提升、涂覆材料自供、设备自主集成，使公司在成本控制和技术响应上形成难以复制的综合竞争力。
- **[基膜设备自主集成突破行业瓶颈]** -> [基膜业务量利齐升]: 自研设备单线产能全球领先，投资成本与建设周期全面优于行业，推动基膜销量同比+160.5%，市占率跃升。
- **[PVDF产能规模初具优势]** -> [功能性材料盈利大幅提升]: 锂电级PVDF市占率超30%，销量同比+99.1%，规模化效应叠加客户结构优化，成为业绩增长的重要贡献点。
- **[下游客户新一轮扩产周期启动]** -> [自动化装备新接订单同比+130.9%]: 动力及储能电池厂商加大资本开支，公司凭借涂布机等优势设备，抓住机遇期实现订单爆发式增长。
- **[负极材料差异化产品策略与降本增效]** -> [负极业务毛利率改善]: 聚焦快充、长循环等高端产品，通过一体化工艺优化与石墨化技改，在出货量温和增长下实现盈利修复。
- **[极片代工CAAS业务突破]** -> [开启新增长曲线]: 依托平台型布局，探索“整卷”交付模式，8GWh产能投产并获客户认证，为未来电池标准化制造奠定基础。

## 风险警告
**核心风险在于行业产能过剩与价格战压力。** 尽管2025年需求强劲，但锂电材料全行业前期大规模扩产的产能仍在持续释放。若下游需求增速放缓，公司将面临产品售价下降与毛利率承压的双重打击，尤其是负极材料与基膜业务，竞争格局仍存变数。

**技术路线替代风险不可忽视。** 固态电池、钠离子电池等新体系电池产业化进程加速，可能对现有液态锂电材料体系构成颠覆性冲击。公司虽已布局相关研发，但若新技术商业化速度超预期，或公司技术储备未能及时转化为产品优势，现有核心业务（如隔膜、电解液相关材料）的市场空间将面临被侵蚀的风险。
