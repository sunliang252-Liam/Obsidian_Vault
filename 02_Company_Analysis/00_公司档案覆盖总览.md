## 五、怎么升级到深度档

```bash
# 单家：按 skill 的五阶段流程取数 → 写成 JSON → 合并
python scripts/note_render.py --data data/300750.json --vault "D:/Workspace/Obsidian_Vault" --merge
```

深度档用 `<!-- dossier:start -->` 单独成块，与基础档并存、互不覆盖。升级后本表“深度档”列会 +1。

## 六、已知限制

1. **基础档的沿革是「成立 → 上市 → 更名 → 主营」四条骨架 + 公司简介原文**，不是逐年大事记。改制、借壳、重大重组、海外并购的具体时间点需要读招股书或年报，属深度档。
2. **实际控制人字段直接采用 F10 口径**。国资控股写「某市国资委」这类机构名，无实控人的（如万科）写「无」。
3. **股东表取最新一期报告期**，按持股比例降序，最多 10 位。
4. **北交所 920 开头的代码**，库内文件名可能标成 `_SZ_`，F10 实际要 `.BJ`，脚本已做兼容。
5. **数据随报告期变动**。重跑 `bulk_f10.py` 即可刷新，不会产生重复块。
