# 600968.SH 深度透视

## 因果逻辑链
- **[聚焦油气生产技术服务]** -> [业绩稳健增长]: 公司聚焦海上油气生产环节，为中海油增储上产提供一体化服务，2025年归母净利润38.84亿元，同比增长6.24%，创历史新高。
- **[高客户集中度]** -> [收入高度依赖关联方]: 前五大客户销售额占年度销售总额78.73%，其中关联方中海油集团占比71.87%，业务增长高度依赖母公司资本开支。
- **[成本领先战略]** -> [毛利率提升]: 公司持续降本增效，营业成本降幅（-5.75%）高于收入降幅（-4.10%），带动毛利率同比提升1.47个百分点至16.09%。
- **[自主技术攻关]** -> [核心产品市占率提升]: 自主化电泵、永磁电机等产品规模化应用，350℃高温注采技术助力增产，推动能源技术服务毛利率提升2.19个百分点。
- **[LNG船队扩张]** -> [新兴业务增长极]: 公司运营LNG运输船14艘，8艘在建，LNG加注业务实现国际化突破，成为未来业绩增长的重要驱动力。
- **[研发投入加码]** -> [新质生产力培育]: 研发费用同比增长26.88%至12.51亿元，聚焦海洋能源新质生产力，推动智能注采、CCUS等关键技术突破。
- **[处置非核心资产]** -> [优化产业结构]: 出售冷能业务等非核心资产，回笼资金，聚焦主业，提升资产运营效率。
- **[油价波动传导]** -> [营收短期承压]: 部分商品销售价格随国际油价下跌，导致公司营业收入同比下降4.10%，但生产服务类业务受油价波动影响相对较小。

## 风险警告
**核心风险在于对单一控股股东的高度依赖。** 公司超过70%的收入来自中国海油集团，业务增长与集团资本开支计划高度绑定。若未来国际油价持续低迷，或集团调整勘探开发策略、削减资本开支，将直接冲击公司订单量和盈利能力。这种“背靠大树”的模式虽提供了业绩稳定性，但也限制了公司独立面对市场周期的能力。

**第二大风险是海外业务拓展缓慢与LNG投资回报的不确定性。** 尽管公司积极布局海外，但2025年海外收入占比仅1.47%，国际化进程远低于预期。同时，公司大规模投资LNG运输船队（总投资超百亿欧元），项目周期长、资本开支大，未来面临LNG运价波动、汇率风险以及项目延期或成本超支的风险，可能对现金流和资产回报率造成压力。
