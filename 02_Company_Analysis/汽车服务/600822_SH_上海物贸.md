# 600822.SH 深度透视

## 因果逻辑链
- **[汽车行业价格战与新能源转型]** -> [营收与利润双降]: 新车进销倒挂、合资燃油车市场收缩，导致公司新车销售额同比下降30.74%，归母净利润同比减少42.32%。
- **[收入确认方法调整（总额法转净额法）]** -> [营收规模大幅缩水]: 对部分汽车销售业务由“总额法”调整为“净额法”，追溯调整后2025年营业收入同比减少34.17%，但毛利率提升4.43个百分点。
- **[核心子公司乾通投资稳健运营]** -> [利润贡献稳定]: 乾通投资全年实现净利润2,172.46万元，完成吞吐量371万吨，是公司利润的重要稳定器。
- **[非经常性损益依赖]** -> [扣非净利润转负]: 归母净利润2,915万元，但扣非净利润为-166.88万元，核心主业盈利能力薄弱，利润高度依赖政府补助、资产处置等非经常性项目。
- **[经营场地变动与业务调整]** -> [短期业绩承压]: 共和新路动迁、经营场地调整导致人员分流、闭店处置资产，直接造成售后产值同比下降29.09%。
- **[控股股东百联集团资源赋能]** -> [资金与资产支撑]: 在百联财务公司存款余额达9.53亿元，获得低息融资与物业租赁支持，为公司转型提供安全垫。
- **[二手车市场规范化与平台优势]** -> [交易量稳居前列]: 旗下旧车市场全年交易量77,004辆，位列上海第二，标准化检测与诚信交易品牌形成差异化竞争力。

## 风险警告
**核心主业盈利能力持续恶化，扣非净利润已连续为负。** 公司2025年扣非净利润为-166.88万元，且经营性现金流净额同比暴跌96.57%至仅781万元，表明汽车经销与大宗商品贸易两大核心业务均面临严峻的“造血”危机。新车进销倒挂、售后产值下滑、仓储物流“内卷式”竞争三重压力叠加，公司若无法在新能源转型与降本增效上取得突破，将陷入“增收不增利”甚至“减收减利”的恶性循环。

**母公司存在巨额未弥补亏损，分红能力长期缺失。** 截至2025年末，母公司未弥补亏损高达-6.99亿元，导致公司连续多年无法实施现金分红，对长期价值投资者缺乏吸引力。同时，公司对部分联营企业（如上海三灵金属）的投资损失已减记至零，且该地块动迁尚未完成，存在潜在的资产减值与投资损失风险。此外，公司对前五大供应商的采购集中度极高（占比86.39%），其中对上汽集团采购占比高达64.28%，供应链议价能力弱，一旦主机厂政策变动或合作关系恶化，将对公司汽车业务造成重大冲击。
