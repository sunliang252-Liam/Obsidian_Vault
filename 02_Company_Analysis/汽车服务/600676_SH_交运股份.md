# 600676.SH 深度透视

## 因果逻辑链
- **公路货运市场竞争激烈+新业务开拓不及预期** -> 道路货运与物流服务收入下降10.94%: 市场环境恶化导致业务承压，新项目未达预期，收入下滑
- **传统燃油车消费需求持续下降+价格战** -> 乘用车销售与汽车后服务收入下降5.98%: 传统燃油车市场份额萎缩，价格战压缩收入
- **汽车零部件制造与销售服务板块客户需求回升** -> 该板块收入增长30.99%: 主要客户业务量恢复，带动零部件需求增加
- **汽车零部件制造板块结构性问题（燃油车资产专用性）** -> 资产减值损失同比增加569.98%: 燃油车零部件资产因市场结构变化，无法适配新能源车型，计提大额减值
- **地块征收、收储** -> 营业外收入同比增加5657.56%: 土地房屋征收补偿款计入营业外收入
- **地块征收、收储** -> 经营活动现金流量净额同比增加63.54%: 补偿款作为收到其他与经营活动有关的现金流入
- **新能源转型压力** -> 管理层推进资产置换，置入文体旅资产，置出传统汽销与零部件板块: 传统业务盈利困难，公司寻求战略转型，通过资产置换进入成长性行业

## 风险警告
深度风险总结: 公司2025年归母净利润为-3.30亿元，核心亏损源于传统燃油车相关业务的结构性衰退。道路货运及乘用车销售两大板块收入下滑，汽车零部件板块虽收入增长但因高昂固定成本及资产减值（同比+570%）仍为负毛利。经营现金流改善依赖非经常性的土地收储补偿款，不可持续。资产减值风险继续暴露燃油车专用资产贬值压力，公司正通过资产置换（置入文体旅、置出汽销及零部件）寻求转型，但重组存在不确定性，主业扭亏尚需时日。
