# 600386.SH 深度透视

## 因果逻辑链
- **[汽车服务业务收入下滑]** -> [归母净利润转负]: 整车销售业务收入减少7.52%，叠加新能源转型阵痛，导致汽车服务板块整体收入下降4.38%，拖累公司整体盈利。
- **[广告传媒业务收入锐减]** -> [归母净利润承压]: 广告传媒业务收入同比大幅下降30.23%，毛利率减少11.40个百分点，传统户外媒体受数字化冲击显著。
- **[新能源业务成本激增]** -> [毛利率大幅下滑]: 充电桩业务收入下降9.08%，但折旧摊销、场地租赁等成本分别增长20.92%和145.16%，导致毛利率减少17.25个百分点。
- **[非流动资产处置损失]** -> [非经常性损益恶化]: 报告期内非流动性资产处置损益为-2720万元，是导致扣非净利润（-2659万）远低于归母净利润（-1040万）的主要原因。
- **[其他权益工具投资公允价值变动]** -> [综合收益大幅亏损]: 参股企业松芝股份等公允价值变动导致其他综合收益损失-6097万元，使综合收益总额亏损达-8292万元。
- **[经营性现金流改善]** -> [经营质量提升]: 经营活动现金流净额同比增长31.75%至6.03亿元，主要得益于购买商品、接受劳务支付的现金减少，显示公司在收缩业务规模的同时加强了现金管理。
- **[会计政策变更（净额法）]** -> [收入规模虚降]: 因财政部要求充电业务收入确认由总额法改为净额法，追溯调整使2024年营业收入调减2.57亿元，2025年新能源业务收入同比名义下降9.08%。

## 风险警告
**核心风险在于传统业务（广告+燃油车销售）的加速衰退与新兴业务（新能源充电）盈利能力的持续恶化形成双重挤压。** 广告传媒业务收入暴跌30%，毛利率骤降11个百分点，显示公司在数字化浪潮中核心媒体资源的价值正在快速流失；汽车服务业务虽营收占比超84%，但毛利率仅3.98%，且子公司海依捷净资产已为-1.9亿元，处于资不抵债状态，燃油车价格战和库存压力是持续失血点。

**新能源充电业务作为公司转型的希望，正面临“增收不增利”的困境。** 尽管充电量和社会化服务规模增长，但收入确认改为净额法后，收入规模被压缩；同时，折旧摊销、场地租赁等固定成本刚性增长，导致毛利率从52.44%骤降至35.19%。若充电桩利用率提升无法覆盖成本增速，该板块可能从利润贡献者变为新的亏损源。此外，公司管理层在报告期内发生重大变动（董事长、总经理、董秘等核心岗位更换），战略执行连续性存疑。
