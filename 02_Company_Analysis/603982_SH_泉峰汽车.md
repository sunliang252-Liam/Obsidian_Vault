# 603982.SH 深度透视

## 因果逻辑链
- **[前期高额资本开支（安徽、匈牙利基地）]** -> [持续亏损]: 新建产能处于爬坡期，固定成本及折旧摊销巨大，导致2022-2025年连续四年亏损，尽管2025年亏损大幅收窄。
- **[新能源业务转型成功]** -> [收入增长]: 2025年新能源零部件收入占比超65%，带动全年营收同比增长14.31%至26.33亿元，成为核心增长引擎。
- **[降本增效措施见效]** -> [毛利率修复]: 通过工艺改进、供应链管理、良率提升，2025年毛利率同比增加4.29个百分点至4.67%，亏损幅度同比收窄36.77%。
- **[可转债转股及定增]** -> [资本结构优化]: 2025年完成“泉峰转债”提前赎回及向大股东定增2亿元，资产负债率从72.35%降至66.70%，财务费用因利息支出减少而下降25.86%。
- **[马鞍山基地产能释放]** -> [规模效应初现]: 安徽子公司2025年实现收入11.36亿元，同比增长27%，成为公司最大收入来源，但该子公司仍亏损1.05亿元，盈利拐点未至。
- **[匈牙利基地仍处投入期]** -> [拖累整体业绩]: 欧洲生产基地2025年仅实现收入167.76万欧元，仍处于部分投产和前期开发阶段，持续产生亏损，是公司海外战略的长期成本中心。
- **[客户集中度高]** -> [经营依赖性强]: 前五大客户销售额占比61.22%，主要依赖蜂巢、汇川、特斯拉等头部客户，单一客户订单波动对公司影响巨大。

## 风险警告
**核心风险在于盈利拐点的不确定性。** 公司连续四年亏损，累计亏损超10亿元，尽管2025年亏损大幅收窄，但毛利率仅4.67%，远低于正常盈利水平。马鞍山和匈牙利两大生产基地的巨额折旧与摊销（息税折旧摊销前利润虽改善但经营现金流仍为负）持续侵蚀利润。若产能爬坡速度不及预期或下游客户价格年降压力加剧，公司可能长期陷于“增收不增利”的困境。

**财务与经营风险交织。** 公司资产负债率虽降至66.70%，但短期借款同比激增132%至10.36亿元，营运资金占用上升导致经营活动现金流净额同比下降59.12%。同时，客户集中度极高（前五占61%），且面临原材料价格波动、汇率波动及行业竞争加剧等多重压力。匈牙利基地的持续亏损和海外运营风险，也是不容忽视的潜在“失血点”。
