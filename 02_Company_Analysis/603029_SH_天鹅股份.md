# 603029.SH 深度透视

## 因果逻辑链
- **[海外市场突破]** -> [国际业务收入暴增746.61%]: 中亚地区（乌兹别克斯坦）采棉机需求爆发，四行箱式采棉机从小批量试销转为规模化出口，成为营收增长核心引擎。
- **[国内存量更新需求]** -> [收获机械收入增长39.81%]: 新疆采棉机市场进入存量更新换代周期，打包采棉机替代箱式机趋势明确，公司凭借技术优势稳固市场份额。
- **[高毛利海外业务占比提升]** -> [归母净利润增速(7.66%)远低于营收增速(24.26%)]: 海外业务毛利率(37.21%)虽高，但国内竞争加剧导致收获机械毛利率下降7.25个百分点，且农事服务成本因全年折旧而大增，拖累整体盈利。
- **[采棉机按揭担保风险暴露]** -> [信用减值损失激增至4631万元]: 部分客户采收收益未达预期，公司对按揭担保业务计提大额预期信用损失，直接侵蚀利润，扣非净利润同比下降21.34%。
- **[研发投入持续高企]** -> [技术壁垒与产品迭代]: 研发费用率6.78%，聚焦增程式采棉机、智能生产线等，维持“国家制造业单项冠军”地位，但研发成果产业化周期长，短期对利润贡献有限。
- **[政府补助与拆迁补偿]** -> [非经常性损益占比过高]: 计入当期损益的政府补助等非经常性收益达3014万元，占归母净利润的40.4%，掩盖了主营业务的真实盈利能力。

## 风险警告
**核心风险在于信用风险的集中暴露。** 公司为促进采棉机销售，大规模提供按揭担保，截至报告期末担保余额高达2.78亿元，占净资产29.15%。随着行业竞争加剧及下游农户收益波动，已发生代偿并计提大额预计负债。若未来违约率持续攀升，公司将面临巨大的代偿压力和资产减值风险，这是悬在利润表上的“达摩克利斯之剑”。

**另一重大风险是盈利质量堪忧与增长可持续性存疑。** 营收增长高度依赖海外一次性爆发，国内主业（棉花加工机械）收入同比下滑8.84%。扣非净利润同比下滑21.34%，经营活动现金流净额为负，表明公司造血能力并未随营收扩张而改善。同时，与迪尔公司的专利诉讼虽一审胜诉，但对方仍可能上诉，结果存在不确定性，可能对公司核心产品（打包采棉机）的销售构成潜在法律障碍。
