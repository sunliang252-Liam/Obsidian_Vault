# 000753.SZ 深度透视

## 因果逻辑链
- **[收购信产集团与人才集团]** -> [营收结构剧变，数智科技成新主业]: 2024年末完成收购，2025年合并报表新增数智科技业务，贡献2.48亿营收，使公司从传统水务、汽贸向“数智科技+新能源+水资源”转型。
- **[政府补助与资产处置]** -> [归母净利润增长21.69%，但扣非净利润下滑10.05%]: 2025年收到政府补助3500万元及子公司退税等非经常性收益，掩盖了核心业务盈利能力下滑的真相。
- **[燃油车品牌清退]** -> [燃油车销售收入锐减30.56%]: 主动处置三明、南平等地低效燃油车品牌，导致燃油车收入从7.52亿降至5.22亿，加速业务结构“去燃油化”。
- **[光伏项目集中投产]** -> [电力销售收入翻倍，毛利率大幅提升]: 漳浦盐场100MW渔光互补等项目并网，电力销售毛利率达64.22%，成为新能源板块利润增长核心。
- **[PPP项目与工程款集中回收]** -> [经营活动现金流由负转正，大幅改善]: 收回东墩污水处理费、漳浦污水工程款等合计超6亿元，使经营现金流从-2.5亿跃升至+4.1亿。
- **[信用与资产减值损失激增]** -> [侵蚀营业利润，扣非净利润承压]: 信用减值损失1.17亿、资产减值损失0.43亿，合计1.6亿，主要来自应收账款和合同资产计提，反映回款风险。
- **[发行永续中期票据]** -> [净资产提升，但财务杠杆仍高]: 发行6亿元永续中票计入其他权益工具，使净资产增加，但总负债率仍处高位，长期借款增至26.8亿。

## 风险警告
**核心风险在于“转型阵痛”与“资产质量”的双重挤压。** 公司通过收购信产集团强行切入数智科技赛道，但该业务营收仅2.48亿，尚处培育期，难以弥补传统主业（燃油车、工程施工）的下滑。更危险的是，公司资产端埋有“暗雷”：应收账款高达18.13亿，合同资产8.03亿，合计占总资产20.5%，且2025年已计提超1.6亿减值损失。若地方政府财政紧张导致工程款、污水处理费回款持续恶化，减值压力将进一步吞噬利润。

**第二个风险是“融资驱动型增长”的可持续性存疑。** 公司2025年投资活动现金净流出5.2亿，主要靠筹资活动（发行永续债、新增借款）勉强覆盖。资产负债率仍超60%，且对外担保余额占净资产近50%。在光伏电价市场化改革、新能源补贴退坡的背景下，大规模光伏项目（如漳浦100MW）的预期收益率可能不及预期，叠加售电业务刚起步，新能源板块能否成为第二增长曲线存在较大不确定性。
