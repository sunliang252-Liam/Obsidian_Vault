# 002204.SZ 深度透视

## 因果逻辑链
- **[风电/新能源设备需求高景气]** -> [新能源设备板块收入增长21.47%]: 双碳目标下风电装机需求持续旺盛，带动公司风电齿轮箱、铸件等核心零部件订单增长。
- **[大客户战略与海外市场突破]** -> [出口订货增长16%，大客户订货占比60.4%]: 聚焦力拓、摩洛哥EPC等全球战略客户，提升订单质量与规模，对冲国内传统冶金市场下行。
- **[精益管理与供应链变革]** -> [集成供应链降本增效12.23亿元]: 通过精益二期、集采率提升21%等措施，有效控制成本，在原材料价格波动下维持毛利率稳定。
- **[产品结构向高端/智能化调整]** -> [高端化、智能化订货分别增长12.3%、9.4%]: 主动退出低端同质化竞争，聚焦高附加值产品（如3800t/h卸船机、智能堆取料机），提升盈利天花板。
- **[IPD集成产品研发变革]** -> [设计成本优化2.5亿元，标准设计周期缩短25%]: 通过CBB通用模块开发，减少重复设计，加速产品交付，提升研发投入产出效率。
- **[存量应收账款专项清理]** -> [经营性现金流净额增长33.58%至7.74亿元]: 坚持“现金为王”，通过强制诉讼机制等手段回收风险款项，改善现金流质量。
- **[传统冶金/工程总包业务收缩]** -> [冶金设备收入下降5.36%，工程总包下降19.89%]: 钢铁、焦化行业产能过剩与投资放缓，导致公司传统优势业务板块增长承压。

## 风险警告
**核心风险在于传统主业的结构性衰退与信用减值的高企。** 公司冶金设备与工程总包业务收入持续下滑，反映下游钢铁、焦化行业产能过剩、投资疲软的长期困境。更严峻的是，公司2025年信用减值损失高达1.39亿元，占利润总额的20%，表明历史遗留的应收账款风险仍在持续暴露。尽管公司通过强制诉讼等手段积极清收，但庞大的应收账款基数（64.9亿元）和部分客户（如河北盛华）的破产重整，意味着坏账风险将是未来利润的长期侵蚀项。

**第二重风险来自新能源业务的“增收不增利”与竞争加剧。** 新能源设备板块虽收入增长21.47%，但毛利率仅为10.26%，显著低于物料搬运（20.71%）和核心零部件（29%）板块。风电行业“内卷式”价格竞争激烈，公司作为零部件供应商，议价能力受限。若未来风电装机增速放缓或整机厂进一步压价，该板块的利润贡献可能远低于市场预期，无法对冲传统业务的下滑。
