# 002757.SZ 深度透视

## 因果逻辑链
- **[IDC及云计算业务收入首次超过专用设备]** -> [公司收入结构发生质变]: 2025年IDC业务收入19.66亿元（+29.79%），占比升至57.62%，成为第一大收入来源，标志着公司战略转型进入规模回报期。
- **[2024年大额商誉减值导致低基数]** -> [2025年归母净利润同比暴增168.52%]: 2024年因计提商誉减值导致亏损1.75亿元，2025年无此非经常性损失，净利润恢复至1.2亿元，但较2023年的1.73亿元仍有差距。
- **[家具智能装备业务收入下滑20.43%]** -> [传统主业承压]: 受下游家具行业新房交付减少、消费疲软影响，自动封边机、加工中心等核心产品收入均出现两位数下滑，拖累整体业绩。
- **[AI原生基础设施+战略升级]** -> [布局MaaS平台与推理算力]: 公司依托自建数据中心，部署GPU算力池并推出MaaS平台，切入高景气度的AI推理算力服务赛道，构建新增长极。
- **[唯一网络员工持股计划实施]** -> [子公司股权结构变化]: 通过增资扩股引入员工持股平台，公司持股比例降至90%，产生股份支付费用1283.72万元，旨在绑定核心团队。
- **[经营活动现金流净额4.54亿元，远超净利润1.2亿元]** -> [盈利质量高]: 差异主要来自折旧摊销（1.85亿元）及存货减少（1.43亿元），表明公司现金流状况健康，利润含金量足。

## 风险警告
**核心风险在于双主业均面临严峻挑战。** 传统家具智能装备业务收入下滑20.43%，下游房地产行业低迷及消费降级趋势短期难以逆转，该业务将持续承压。同时，IDC及云计算业务虽增长迅猛，但毛利率仅9.49%，且面临行业竞争加剧、技术迭代（AIDC转型）及客户需求波动的多重风险，盈利能力并不稳固。

**另一个关键风险是战略转型的不确定性。** 公司从传统IDC向AIDC及MaaS平台转型，需持续投入巨额资金采购GPU等算力设备，若AI推理算力需求不及预期或技术路线发生重大变化，前期投入可能面临减值风险。此外，公司对唯一网络的整合及员工持股后的管理协同，也构成潜在的管理风险。
