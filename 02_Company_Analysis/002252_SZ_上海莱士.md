# 002252.SZ 深度透视

## 因果逻辑链
- **[采浆量增长8%+南岳生物并表]** -> 原料血浆供应能力提升: 全年采浆量超2000吨，浆站增至55家，为自产血液制品销售提供原料保障。
- **[进口白蛋白代理业务量价双降]** -> 营收与利润承压: 进口白蛋白收入同比下降10.23%，且单价下调，拖累整体营收下滑10.13%。
- **[GDS投资收益贡献稳定]** -> 利润缓冲垫: 按45%持股比例确认GDS投资收益3.49亿元，对冲了主业利润下滑的影响。
- **[存货与应收账款大幅增加]** -> 经营性现金流恶化: 存货增至53.66亿元，应收账款增至18.42亿元，导致经营活动现金流净额为-3.29亿元。
- **[并购南岳生物+股份回购]** -> 投资与筹资活动现金大幅流出: 收购南岳生物及股份回购合计支出超10亿元，导致投资活动现金流净额为-22.52亿元。
- **[“脱浆”创新药SR604进入IIb期]** -> 第二增长曲线雏形初现: 全球首创血友病单抗产品研发顺利，有望突破传统血液制品业务天花板。
- **[海尔集团赋能+全价值链管理]** -> 运营效率与战略协同提升: 融入海尔“盈康一生”生态，推进数智化转型，提升浆站运营与生产管理效率。

## 风险警告
**核心风险在于业绩双杀与现金流压力。** 2025年营收与扣非净利润分别下滑10.13%和24.25%，主因是进口白蛋白代理业务量价齐跌，而自产白蛋白和静丙收入也分别下降14.9%和12.22%。更严峻的是，为应对采购与销售压力，公司存货和应收账款大幅膨胀，导致经营活动现金流净额由正转负，录得-3.29亿元，盈利质量显著恶化。若下游回款或库存消化不及预期，现金流压力将进一步加剧。

**另一重大风险是商誉减值与并购整合风险。** 公司账面商誉规模庞大，且2025年刚完成对南岳生物的并购。若南岳生物或原有子公司（郑州莱士、同路生物等）未来经营不达预期，将面临商誉减值风险，直接冲击当期利润。同时，新并购标的的整合效果、文化融合及管理输出能否达到预期，存在不确定性。此外，公司对GDS的45%股权投资（占总资产40%）高度依赖其业绩表现，基立福的业绩承诺（2024-2028年累计EBITDA不低于8.5亿美元）能否兑现，是影响公司长期价值的关键变量。
