# 600872.SH 深度透视

## 因果逻辑链
- **[主动渠道去库存]** -> [营收下降23.9%]: 公司主动控制出货节奏、优化经销商库存，导致调味品收入同比减少18.61%，但渠道库存恢复良性，为长期增长奠基。
- **[原材料成本下降]** -> [毛利率提升2.86个百分点]: 大豆、小麦等主要原材料采购单价下降，叠加降本增效措施，使调味品业务毛利率逆势提升至40.14%。
- **[非经常性损益减少]** -> [归母净利润下降39.86%]: 2024年含征地收益等非经常性损益2.22亿元，2025年大幅减少至0.01亿元，导致净利润同比大幅下滑。
- **[股权激励费用减少]** -> [管理费用下降12.09%]: 2024年股权激励费用较高，2025年因业绩未达标回购注销，相关费用减少，管理费用降至3.36亿元。
- **[销售费用逆势增长]** -> [品牌投入加大]: 在营收下降背景下，销售费用仍增长6.25%至5.36亿元，主要用于品牌代言人更换、广告宣传及渠道建设，强化品牌心智。
- **[经销商结构优化]** -> [渠道质量提升]: 净增经销商270个至2824个，但主动淘汰低效经销商，区县开发率达76.55%，渠道体系从数量扩张转向质量提升。
- **[并购切入复合调味品]** -> [打开新增长曲线]: 2026年初收购四川味滋美55%股权，战略性进入川式复合调味品赛道，补强餐饮渠道定制化能力，实现B/C端协同。

## 风险警告
**核心风险在于营收持续下滑与行业竞争加剧的双重挤压。** 公司主动去库存导致2025年营收同比大降23.9%，调味品主业收入41.3亿元，回到2021年水平。虽然渠道库存已恢复良性，但消费环境疲软、行业存量竞争激烈，若终端动销恢复不及预期，营收可能继续承压。同时，酱油、蚝油等核心品类面临海天、李锦记等头部企业的强势竞争，以及新兴品牌在细分赛道的冲击，市场份额争夺将更加白热化。

**第二重风险来自成本与费用的不确定性。** 虽然2025年原材料成本下降贡献了毛利率提升，但大豆、小麦等大宗商品价格波动剧烈，若未来成本上行，将直接侵蚀利润。与此同时，公司为品牌升级和渠道建设持续加大销售费用投入，在营收未恢复增长前，费用刚性可能进一步压缩利润空间。此外，股权激励因业绩未达标多次回购注销，对团队士气和长期激励效果构成潜在负面影响。
