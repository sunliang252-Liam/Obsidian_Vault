# 300843.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [数据通讯类连接器营收增长119.64%]: 数据中心基础设施加速升级，公司高速连接器产品通过AMD、浪潮等认证并量产交付，成为核心增量引擎。
- **[新能源汽车渗透率提升至47.9%]** -> [新能源汽车连接器营收增长38.05%]: 800V高压快充平台普及，公司高压连接器产品适配主流车型，受益于行业规模化发展。
- **[消费电子端侧AI换机周期]** -> [消费类电子连接器营收增长31.94%]: 智能手机、PC出货量回升，公司绑定富士康、立讯精密等头部代工厂，核心业务稳健增长。
- **[发行可转换债券募集资金4.5亿元]** -> [资产总额增长41.12%]: 募资用于扩产及补充流动资金，货币资金及在建工程大幅增加，支撑未来产能扩张。
- **[原材料铜材、塑胶价格波动]** -> [毛利率承压]: 直接材料成本占营业成本67.53%，原材料价格上涨无法完全转嫁，导致新能源汽车连接器毛利率下降3.71个百分点。
- **[海外市场拓展]** -> [国外营收增长56.06%]: 泰国胜蓝工业园投产，公司加速全球化布局，但国外毛利率同比下降6.98%，反映初期成本较高。
- **[股权激励计划作废]** -> [管理费用增加]: 因业绩未达考核目标，2021年第二期限制性股票激励计划第三个归属期920,000股作废，相关股份支付费用计入当期损益。

## 风险警告
**盈利质量与增长脱节风险。** 2025年营收增长35.26%，但归母净利润仅增长8.85%，净利率从7.98%降至6.43%。主要原因是销售费用激增53.11%、财务费用由负转正（汇率变动）、以及信用减值损失扩大至1527万元。营收高增未能有效转化为利润，需警惕费用失控及坏账风险。

**新能源汽车业务毛利率持续下滑风险。** 该业务毛利率仅13.64%，同比下降3.71个百分点，且远低于消费电子（23.74%）和海外业务（29.14%）。在行业价格战背景下，若原材料成本继续上涨或产品降价压力加大，该板块可能拖累整体盈利水平。
