# 301200.SZ 深度透视

## 因果逻辑链
- **[AI算力基础设施投资高增]** -> [营收增长72.68%]: AI服务器、高速交换机需求强劲，带动高多层板、HDI板等PCB扩产，公司钻孔类设备（全球市占率约50%）及检测类设备销量大幅提升。
- **[聚焦高价值AI算力PCB场景]** -> [净利润增长173.68%]: 公司主动切入技术门槛高、附加值高的高多层板、高阶HDI板及封装基板市场，产品结构优化，毛利率提升7.01个百分点。
- **[CCD六轴独立机械钻孔机等创新产品量产]** -> [钻孔类设备收入增长98.38%]: 公司针对AI服务器PCB超高背钻精度要求，推出钻测一体3D背钻技术，实现0-100μm残桩精度，助力客户量产，巩固了核心工序的护城河。
- **[“以销定产”+“安全库存”模式]** -> [存货增加104,747.58万元]: 为应对营收规模扩大、保障订单交付，公司提前备货原材料，导致期末存货大幅增长，占用了大量营运资金。
- **[行业分期收款结算模式]** -> [经营性应收款增加203,202.97万元]: 营收快速增长，但PCB设备行业普遍采用分期收款，导致收入确认与现金回款存在时间差，经营活动现金流净额（1.8亿）远低于净利润（8.2亿）。
- **[多维协同的商业模式]** -> [客户粘性增强]: 公司通过技术、供应链、设备与材料、工序等多维协同，为客户提供一站式解决方案，深度绑定全球头部PCB制造商（如胜宏科技、深南电路等）。
- **[A+H股双轨运作]** -> [品牌全球知名度提升]: 2026年成功登陆港交所，吸引GIC、Schroders等全球顶级机构投资，加速国际化运营和海外市场拓展（海外收入增长68.30%）。
- **[研发投入增长71.47%]** -> [技术护城河加深]: 公司持续加大研发，在新型激光钻孔、玻璃基板加工、高精度AOI等前沿领域布局，为下一代AI算力PCB及先进封装技术储备解决方案。

## 风险警告
**核心风险在于业绩增长与现金流严重背离。** 公司营收和净利润爆发式增长，但经营性现金流净额仅为净利润的22%，主要因行业分期收款模式导致应收账款高企（24.24亿元），以及为保交付大幅备货导致存货激增（18.93亿元）。这种“纸面富贵”的盈利质量，在AI算力投资周期放缓或客户回款出现问题时，将面临巨大的坏账和资产减值风险。

**技术迭代与市场竞争的双重挤压。** 公司虽在机械钻孔领域占据半壁江山，但面临德国Schmoll、日本三菱等老牌国际厂商的激烈竞争，同时国内新进入者也在追赶。AI算力PCB技术快速向更高层数、更小孔径、新材料（如玻璃基板）演进，若公司新型激光、先进封装等创新方案不能及时获得客户认证并形成批量订单，现有优势可能被快速替代。
