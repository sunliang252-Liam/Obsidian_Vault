# 300689.SZ 深度透视

## 因果逻辑链
- **[半导体业务高速增长]** -> [营收增长15.01%]: 半导体产品营收同比增长62.38%，成为核心增长引擎，拉动整体营收至4.14亿元。
- **[智能卡业务稳健]** -> [提供现金流基础]: 智能卡产品及服务营收2.85亿元，占比68.9%，为公司转型提供稳定的收入与现金流支撑。
- **[海外市场拓展]** -> [营收占比53.51%]: 海外销售占比过半，但同比微降1.83%，显示海外市场是基本盘，但增长动能转向国内（+43.28%）。
- **[国产替代与下游需求]** -> [半导体业务毛利率提升13.38个百分点]: 受益于新能源汽车、光伏等下游需求，半导体封装材料业务规模效应显现，毛利率从-12.12%大幅改善至1.26%。
- **[液冷散热业务起步]** -> [新增长点培育]: 液冷产品实现小批量供货（营收49.26万元），处于客户导入与验证阶段，尚未贡献显著利润。
- **[员工持股计划]** -> [管理费用增加]: 施行员工持股计划导致股份支付费用增加，管理费用同比增长32.95%，短期侵蚀利润。
- **[非经常性损益贡献]** -> [净利润增长32.83%]: 扣非净利润仅716万元，但非经常性损益（政府补助、理财收益等）达821万元，是净利润的主要来源。

## 风险警告
**核心风险在于新业务放量不及预期与主业天花板。** 公司智能卡业务已进入成熟期，增长乏力；半导体业务虽增速快，但毛利率极低（1.26%），盈利能力薄弱，且高度依赖贵金属价格波动。液冷散热业务尚处早期，客户导入、技术验证及规模化生产均存在重大不确定性，短期内无法成为利润支柱。

**客户集中度与经营现金流隐忧。** 前五大客户销售占比高达76.93%，对THALES、IDEMIA等大客户依赖度极高，一旦合作关系生变，业绩将受重创。此外，公司扣非净利润仅716万元，而经营活动现金流净额高达4879万元，两者严重背离，需警惕利润质量及应收账款回收风险。
