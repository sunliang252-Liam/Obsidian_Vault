# 000029.SZ 深度透视

## 因果逻辑链
- **[深房光明里项目集中交付结转]** -> [营收暴增264%]: 2025年光明里项目完成销售结转，贡献收入12.77亿元，占集团营收86%，是业绩扭亏为盈的核心驱动力。
- **[光明里项目高毛利结转]** -> [扣非净利润扭亏为盈]: 项目结转带动房地产毛利率同比提升34个百分点，扣非净利润从-1.98亿跃升至2.34亿元。
- **[控股子公司建邦公司出表]** -> [非经常性损益大幅亏损]: 建邦公司破产清算出表，产生非流动性资产处置损失1.52亿元，导致归母净利润（0.99亿）远低于扣非净利润。
- **[存量项目去化艰难]** -> [经营活动现金流持续为负]: 尽管营收大增，但销售回款减少，经营活动现金流净额仍为-0.95亿元，反映存量项目销售乏力。
- **[土地储备严重不足]** -> [未来增长空间受限]: 截至2025年末，公司仅剩汕头新峰大厦一个项目，剩余可开发建筑面积仅2.66万㎡，后续发展缺乏项目支撑。
- **[控股股东同业竞争承诺延期]** -> [资产整合预期升温]: 投控公司承诺在2026年11月前解决与深物业的同业竞争问题，为潜在的资产重组或注入提供了想象空间。
- **[大量资金配置于货币基金]** -> [投资收益成为利润稳定器]: 期末交易性金融资产达10.5亿元，主要为货币基金，贡献公允价值变动收益1662万元，平滑了主业波动。

## 风险警告
公司当前最大的风险在于**资源枯竭与增长断层**。土地储备仅剩一个2.66万㎡的尾盘项目，意味着光明里项目结转后，公司已无后续可售货源。2026年若无新项目落地，营收和利润将面临断崖式下滑，重回亏损状态是大概率事件。公司自身也承认“新业务拓展尚未有实质成果”，战略转型的紧迫性极高。

其次，**历史遗留风险与资产质量隐患**不容忽视。建邦公司破产清算虽已出表，但公司对其仍有大额债权待回收，最终损失金额存在不确定性。同时，公司账面其他应收款激增至7.48亿元，主要系合并层面关联方往来不再抵消所致，需警惕其回收风险。此外，汕头天悦湾二期项目累计销售率仅37%，去化压力巨大，持续面临减值风险。
