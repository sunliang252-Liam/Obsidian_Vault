# 600192.SH 深度透视

## 因果逻辑链
- **[传统中低压输配电市场萎缩]** -> [收入下降8.02%]: 开关柜、自动化装置等核心业务订单获取难度加大，收入规模不足以消化固定成本。
- **[铜、银等原材料价格高位运行]** -> [毛利率暴跌至7.85%]: 成本降幅（-3.65%）远小于收入降幅（-8.02%），盈利能力被严重挤压。
- **[行业低价恶性竞争加剧]** -> [产品价格持续低迷]: 同质化产品导致价格战，公司无法将成本上涨转嫁给客户，创利能力被持续削弱。
- **[收入规模下降叠加成本刚性]** -> [归母净利润巨亏3.48亿元]: 连续三年亏损且亏损额同比扩大54.75%，经营基本面持续恶化。
- **[应收账款居高不下与回款困难]** -> [经营现金流几乎枯竭]: 经营活动现金流净额同比骤降99.14%至54万元，资金链极度紧张。
- **[存货跌价准备大幅增加]** -> [资产减值损失暴增286%]: 对存在减值迹象的存货计提大额减值，进一步侵蚀利润。
- **[前期递延所得税资产转回]** -> [所得税费用异常增加]: 确认递延所得税费用3255万元，加剧了报表亏损幅度。

## 风险警告
**核心风险：持续亏损与资不抵债的恶性循环。** 公司已连续三年亏损，2025年归母净利润亏损3.48亿元，净资产同比缩水30.74%至8.18亿元，未分配利润为-6.06亿元。收入下滑、毛利率被原材料和价格战双重挤压、资产减值损失暴增，三者叠加导致亏损窟窿持续扩大。若无法在短期内扭转经营颓势，公司面临净资产持续消耗乃至资不抵债的风险。

**现金流枯竭与高负债风险。** 经营活动现金流净额从6300万骤降至54万，几乎丧失造血能力。公司总负债35.3亿元，资产负债率高达80.8%，且短期借款与一年内到期非流动负债合计超13亿元，而账面货币资金仅4.8亿元（其中2.08亿为受限资金），短期偿债压力巨大。公司高度依赖外部融资维持运营，财务费用高企，进一步吞噬利润。
