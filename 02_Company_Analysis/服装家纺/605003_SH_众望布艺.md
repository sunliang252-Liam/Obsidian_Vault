# 605003.SH 深度透视

## 因果逻辑链
- **[美国关税政策频繁调整]** -> [公司营收下降1.71%，毛利率下滑3.98个百分点]: 对美出口成本激增，订单承压，公司虽通过越南基地部分对冲，但整体盈利能力仍受侵蚀。
- **[越南生产基地提前布局]** -> [对冲关税风险，维持核心客户关系]: 2023年投建的越南工厂在2025年中美贸易战升级中展现战略价值，保障了对Ashley、La-z-boy等大客户的供应链稳定性。
- **[收到“未来工厂”政府补助1800万元]** -> [其他收益同比暴增372.86%]: 非经常性损益大幅增厚当期利润，掩盖了扣非净利润同比下滑27.88%的真实经营困境。
- **[“国内+越南”双生产基地模式]** -> [提升供应链效率，分散单一市场风险]: 灵活调配产能，既满足美国客户对“中国+1”的供应链要求，又开拓澳大利亚、欧洲等新市场。
- **[沃驰越南及杭州项目产能扩张]** -> [在建工程同比增长45.76%]: 公司处于资本开支高峰期，未来产能释放是收入增长的核心驱动力，但短期也带来折旧和资金压力。
- **[人民币升值及利率下降]** -> [财务费用同比上升41.04%]: 汇兑损失增加，侵蚀了以美元结算为主的海外业务利润。
- **[2024年缴纳大额拆迁所得税]** -> [2025年经营活动现金流净额同比大增65.10%]: 现金流改善并非源于经营好转，而是高基数效应下的技术性修复。

## 风险警告
**核心风险在于“增收不增利”与“非经常性损益依赖”。** 公司2025年扣非净利润同比暴跌27.88%，而营收仅微降1.71%，说明关税成本、汇兑损失等已严重侵蚀主业盈利能力。高达1800万元的政府补助掩盖了经营实质恶化，一旦补贴不可持续，利润将面临更大压力。此外，公司对美出口依赖度高，美国关税政策仍是悬在头顶的达摩克利斯之剑。

**产能扩张与市场需求的错配风险不容忽视。** 公司正大举投资越南和国内新项目，在建工程激增。然而，全球家纺行业需求疲软，布艺行业规模以上企业营收和利润均大幅下滑。若新产能投产时，海外市场需求未能同步复苏，或新市场开拓不及预期，将导致产能利用率不足，折旧压力陡增，进一步拖累ROE。当前5.03%的ROE已处于低位，下行风险大于上行空间。
