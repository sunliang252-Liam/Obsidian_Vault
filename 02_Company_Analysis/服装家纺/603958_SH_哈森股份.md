# 603958.SH 深度透视

## 因果逻辑链
- **[收购苏州郎克斯/江苏哈森工业]** -> [营收暴增77.94%至14.6亿]: 新增精密金属结构件及自动化设备业务，贡献了超70%的收入，彻底改变收入结构。
- **[皮鞋业务持续萎缩]** -> [鞋类收入同比下降11.78%]: 消费趋势转向运动休闲，传统女鞋线下渠道承压，直营店净关152家。
- **[精密金属结构件业务高增长但低毛利]** -> [整体毛利率下降，亏损收窄但仍未盈利]: 该业务营收6.39亿，但毛利率仅19.37%，且因计提大额存货跌价及商誉减值，导致归母净亏损5036万元。
- **[江苏哈森工业业绩承诺未达标]** -> [触发业绩补偿，计提商誉减值]: 2024-2025年累计净利润-583.73万元，远低于承诺的1868万元，导致公司计提商誉减值1371.85万元。
- **[大额资产减值吞噬利润]** -> [净利润持续为负]: 报告期计提资产减值准备7439万元（含存货跌价4551万、商誉减值1372万），是亏损的核心原因。
- **[并购贷款导致财务费用激增]** -> [财务费用同比暴增1708%]: 为支付收购款而增加的银行借款，使利息费用从140万升至1578万，显著侵蚀利润。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占总额52.09%，其中第一大客户比亚迪电子占11.5%，对单一产业链依赖度高。

## 风险警告
**核心风险在于并购整合的“双刃剑”效应。** 公司通过收购苏州郎克斯和江苏哈森工业实现了营收的爆发式增长，但新增业务毛利率低（金属结构件仅19.37%），且江苏哈森工业已连续两年未完成业绩承诺，导致公司计提大额商誉减值。若2026年业绩承诺仍不达标，商誉（账面余额2.5亿）存在进一步减值风险，将直接冲击本已脆弱的资产负债表。

**传统皮鞋业务与新兴精密制造业务的“双线作战”风险。** 皮鞋业务持续萎缩，线下门店收缩，存货周转困难，仍需持续投入资源。而精密制造业务面临消费电子行业周期波动、客户高度集中（前五客户占52%）以及国际贸易政策不确定性等多重挑战。公司管理层能否同时驾驭两个截然不同的行业，实现资源有效配置和协同，是未来扭亏为盈的关键。
