# 600630.SH 深度透视

## 因果逻辑链
- **[不动产动迁补偿款]** -> [净利润大幅增长]: 资产处置收益2927万元，占归母净利润的62%，是利润增长的核心非经常性来源。
- **[进出口贸易业务扩张]** -> [营收微增]: 进出口贸易收入增长30.73%，拉动总营收增长3.33%，但毛利率仅5.27%，对利润贡献有限。
- **[针织服装提质稳价]** -> [毛利率显著提升]: 针织服装类营收下降10.91%，但成本下降28.31%，毛利率提升10.76个百分点，核心品牌盈利能力改善。
- **[核心品牌线下门店收缩]** -> [自有品牌营收下降]: 针织品、家纺等自有品牌线下直营店净关69家，导致自有品牌整体营收同比下降4%。
- **[加盟渠道扩张]** -> [弥补直营下滑]: 加盟店净增27家，加盟收入同比增长37%，部分对冲了直营渠道的萎缩。
- **[研发投入削减]** -> [短期利润平滑]: 研发费用同比下降17.88%，在营收增长背景下削减研发，可能牺牲长期产品竞争力。
- **[信用减值损失扩大]** -> [侵蚀经营利润]: 信用减值损失从收益539万转为损失222万，主要因按账龄计提坏账准备增加，反映回款压力。

## 风险警告
**核心风险在于利润质量极低，严重依赖非经常性损益。** 2025年归母净利润4705万元，但扣非净利润仅1972万元，占比仅42%。高达2927万元的资产处置收益（不动产动迁补偿款）是利润的主要来源，这种一次性收益不可持续。剔除该因素后，公司主营业务盈利能力依然薄弱，经营现金流净额同比大幅下降43.35%，显示销售回款能力恶化。

**第二重风险是核心品牌业务的持续萎缩与渠道转型阵痛。** 作为立身之本的针织服装类营收同比下降10.91%，线下直营门店净关95家，自有品牌整体营收下滑。虽然加盟渠道和进出口贸易有所增长，但前者毛利率低，后者面临国际贸易格局调整与供应链风险。公司合并报表仍有高达6.06亿元的未弥补亏损，历史包袱沉重，依靠自身造血能力填补亏损仍需时日。
