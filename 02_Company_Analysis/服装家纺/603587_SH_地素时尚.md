# 603587.SH 深度透视

## 因果逻辑链
- **[消费降级与需求疲软]** -> [营收与利润双降]: 宏观经济承压导致消费者信心不足、购买力减弱，公司2025年营收同比下降3.72%，归母净利润同比下降14.20%。
- **[线上渠道高增长]** -> [弥补线下下滑]: 线上销售同比增长27.03%，营收占比提升至21.90%，有效对冲了线下渠道9.79%的下滑，成为营收的稳定器。
- **[经销渠道大幅收缩]** -> [营收结构恶化]: 经销模式收入同比下降21.93%，门店净减少122家，反映出经销商信心不足及终端市场疲软，是拖累整体业绩的核心因素。
- **[品牌力与会员运营]** -> [维持高毛利率]: 公司通过品牌升级、会员精细化运营（如首届会员节），将整体毛利率维持在75.00%的高位，抵御了价格战压力。
- **[股份支付费用减少]** -> [管理费用大幅下降]: 因股权激励业绩考核未达成，股份支付费用减少，管理费用同比下降21.30%，对利润形成正向支撑。
- **[高分红与回购]** -> [回报股东，但削弱资本]: 2025年现金分红加回购合计占净利润97.13%，体现高回报意愿，但大量现金流出也限制了公司进行大规模投资或并购的财务弹性。
- **[收购MACKAGE]** -> [开启国际化与多品牌战略]: 公司完成对加拿大高端外套品牌MACKAGE大中华及东南亚业务的收购，是外延式扩张的关键一步，但整合风险与短期财务压力并存。

## 风险警告
**核心风险在于消费复苏不及预期与渠道结构失衡。** 公司营收与利润已连续两年下滑，且下滑幅度在2025年扩大（净利润降幅14.20% vs 2024年降幅38.5%）。线下经销渠道的急剧萎缩（收入降22%，门店净减122家）是最大隐患，表明传统批发模式在疲软市场中的脆弱性。若消费信心无法快速修复，经销商的关店潮可能持续，进一步侵蚀公司基本盘。

**第二重风险来自战略转型的不确定性。** 公司正进行多品牌外延并购（收购MACKAGE）和内部组织架构调整（如研发人员从202人精简至131人）。收购后的整合、新品牌与现有体系的协同、以及组织变革带来的短期阵痛，都可能对2026年及以后的业绩造成扰动。同时，公司大量现金用于分红回购和对外投资，若新业务未能如期贡献利润，将面临“增收不增利”甚至资产减值的风险。
