# 603511.SH 深度透视

## 因果逻辑链
- **[消费结构K型分化]** -> [中端市场承压，营收下滑2.21%]: 消费者两极分化，中端市场被挤压，公司核心线下渠道客流下降，导致整体营收从31.63亿降至30.94亿。
- **[增效降本策略]** -> [经营现金流大增36.47%]: 通过优化采购、控制费用，生产采购及各项支付减少，使经营活动现金流净额从4.25亿提升至5.80亿。
- **[线上渠道增长]** -> [部分对冲线下下滑]: 线上渠道营收增长3.02%，毛利率提升1.93个百分点，成为唯一正增长渠道，弥补了线下直营（-3.61%）和加盟（-19.33%）的颓势。
- **[高比例分红]** -> [维持股东回报，但透支未来]: 2025年拟分红占净利润98.32%，连续三年高分红，虽体现回报意愿，但削弱了公司内生性增长的资金储备。
- **[海外业务扩张]** -> [营收增长22.84%，但拉低整体毛利率]: 境外业务（含低毛利代工）增长显著，但服饰加工毛利率仅11.24%，拉低了整体盈利质量。
- **[品牌重塑与创新]** -> [核心产品力提升，毛利率微增]: 爱慕“反脆弱设计”、爱美丽“微笑备忘裤”等创新营销，推动整体毛利率提升0.87个百分点至66.48%。
- **[存货管理优化]** -> [资产减值损失大幅减少]: 通过供应链提效和精准供货，存货跌价损失从2746万降至1535万，资产质量有所改善。

## 风险警告
**核心风险在于增长失速与盈利能力的持续弱化。** 营收连续两年下滑（2024年-7.7%，2025年-2.21%），净利润更是从2023年的3.06亿腰斩至2025年的1.52亿，降幅达50%。公司虽通过高比例分红（98.32%）维持股东信心，但这并非可持续的盈利增长信号。线下渠道（占总营收68.58%）客流持续下降，加盟渠道萎缩近20%，表明传统零售模式正面临结构性挑战，而线上渠道3%的微增难以弥补线下缺口。

**第二重风险来自激进的海外扩张与高昂的运营成本。** 公司正全力推进全球化，但海外业务目前以低毛利的代工为主，且地缘政治、汇率波动风险显著。同时，销售费用率高达47.8%（销售费用14.78亿/营收30.94亿），吞噬了大部分毛利，财务费用因汇兑损失同比大增112%。在营收未见明显拐点前，高昂的固定成本和海外投入将持续侵蚀利润，公司需警惕陷入“增收不增利”甚至“减收减利”的困境。
