# 600398.SH 深度透视

## 因果逻辑链
- **[“可退货为主”采购模式]** -> [低存货跌价风险]: 滞销商品可剪标退还供应商，公司不承担跌价风险，7,689,976,156.24元可退货存货未计提跌价准备。
- **[“平台+品牌”连锁经营模式]** -> [轻资产高周转]: 公司整合社会资源，供应商承担生产与部分库存风险，自身聚焦品牌管理与渠道运营，实现资源优化配置。
- **[多品牌+新业态扩张]** -> [营收增长但利润承压]: 海澜团购(+21.94%)、其他品牌(+29.18%)及海外业务(+27.70%)驱动营收增长3.19%，但新品牌培育及运动奥莱业务前期投入导致销售费用增长6.55%，净利润仅微增0.34%。
- **[经营活动现金流大幅改善]** -> [现金循环周期优化]: 经营活动现金流净额同比大增93.46%至44.82亿元，主因购买商品、接受劳务支付的现金减少，反映供应链付款节奏优化或存货采购控制加强。
- **[高比例现金分红]** -> [股东回报与再投资平衡]: 2025年拟每10股派4.10元，分红比例高达90.91%，体现公司充裕现金流及回馈股东意愿，但高分红率可能限制未来业务扩张的资本储备。
- **[H股上市推进]** -> [国际化战略加速]: 公司已启动H股上市筹备并递交申请，旨在打造多元化资本平台，深化全球化布局，但将面临国际资本市场更严格的监管与信息披露要求。
- **[存货周转天数增加]** -> [运营效率隐忧]: 存货周转天数从330天增至344天，尽管可退货模式降低跌价风险，但库存积压仍占用资金，对供应链快速反应能力提出更高要求。

## 风险警告
**核心风险在于增长失速与盈利能力的结构性下滑。** 公司营收增长高度依赖团购定制（+21.94%）和运动奥莱等新业务，而核心主品牌“海澜之家系列”营收同比下降2.40%，显示基本盘增长乏力。同时，新业务扩张导致销售费用率持续攀升，叠加其他品牌毛利率同比下滑7.23个百分点，侵蚀了整体利润空间。在消费弱复苏环境下，公司能否通过新业态实现可持续的利润增长，而非仅靠规模扩张，是最大不确定性。

**存货与商誉构成资产负债表的核心风险。** 尽管“可退货”模式缓冲了大部分存货跌价风险，但不可退货存货（约36.41亿元）中，2年以上库龄存货的跌价准备计提比例高达88.42%，显示部分产品去化困难。此外，公司账面商誉高达7.31亿元，主要来自英氏婴童及斯搏兹（阿迪达斯代理）的并购。若新品牌或代理业务表现不及预期，将面临商誉减值风险，直接冲击当期利润。
