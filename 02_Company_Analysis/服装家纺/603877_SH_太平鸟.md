# 603877.SH 深度透视

## 因果逻辑链
- **[零售额下降]** -> [营收下滑6.88%]: 终端消费疲软，直营、加盟、线上全渠道收入均同比下降，导致总营收承压。
- **[营收下滑]** -> [净利润暴跌32.57%]: 收入减少的同时，刚性费用（销售费用、财务费用）降幅有限，导致利润弹性释放为负。
- **[门店大规模净关闭375家]** -> [加盟收入下降8.18%]: 主动优化低效加盟网络，加盟店数量净减少300家，直接拖累加盟渠道收入。
- **[线上渠道收入下降14.82%]** -> [营收结构恶化]: 高毛利的线上渠道收入占比下降，拉低整体毛利率提升幅度（仅增1.6个百分点）。
- **[存货周转天数增加16天]** -> [资产减值损失扩大]: 库存去化放缓，导致存货跌价准备计提增加，资产减值损失同比扩大25.4%。
- **[可转债利息增加]** -> [财务费用上升12.09%]: 利息收入减少叠加可转债利息支出增加，侵蚀利润。
- **[供应链快反能力提升]** -> [期货准交率96%，追单周期30天]: 数字化投入提升供应链效率，但未能有效对冲需求下滑带来的库存压力。

## 风险警告
**核心风险在于需求疲软与渠道收缩的负向螺旋。** 公司营收连续两年下滑，2025年降幅虽收窄但净利润暴跌32.57%，扣非净利润更是腰斩。门店净关闭375家（-10%），尤其是加盟店净关300家，表明品牌对加盟商的吸引力下降，渠道扩张逻辑已逆转。线上渠道收入下滑14.82%，显示全渠道增长均面临瓶颈。存货周转天数增加至208天，库存积压风险加大，未来减值压力持续。

**更严峻的是，公司盈利能力正在恶化。** 在营收仅降6.88%的情况下，净利润降幅高达32.57%，主要因刚性费用（销售费用仅降0.03%）和财务费用上升。这表明公司通过控费来保利润的空间已十分有限。同时，经营性现金流净额下降11.91%，投资活动现金流因理财购买净增加而大幅流出，自由现金流承压。在行业集中度提升的背景下，太平鸟的“悦享品质时尚”品牌升级能否有效转化为销售增长，仍是巨大挑战。
