# 603808.SH 深度透视

## 因果逻辑链
- **[多品牌矩阵协同效应]** -> **国内业务可比收入增长5.6%**: 国际品牌Laurèl(+12.7%)、self-portrait(+16.2%)、IRO中国区(+14.9%)多点开花，弥补主品牌ELLASSAY的稳健表现，驱动整体增长。
- **[“降本年”费用精细化管控]** -> **销售及管理费用率合计下降约5个百分点**: 严格预算管理、流程优化、品销合一，使公司在收入微增背景下实现利润大幅修复。
- **[AI技术全链路赋能]** -> **运营效率提升与成本优化**: 从设计企划（AI生图）、供应链（闪链侠系统）到营销（数字人直播），AI应用直接贡献降本增效。
- **[线上多平台全面发展]** -> **线上销售可比增长13.3%**: 天猫、抖音、视频号等全渠道发力，线上收入占比提升至18.6%，成为增长新引擎。
- **[海外业务调改优化]** -> **IRO海外经营逐季改善**: 大力关闭16家低效门店、严控成本，虽仍亏损但亏损幅度收窄，海外业务拖累减弱。
- **[参股公司百秋尚美业绩增长]** -> **投资收益同比大增83.3%**: 百秋尚美经营稳健，贡献投资收益增加，叠加Ed Hardy亏损收窄，非经常性收益显著增厚利润。
- **[资产周转效率改善]** -> **存货周转率提升至1.21次**: 在可比口径销售增长下，存货管理优化，资产负债率降至32.2%，财务结构更健康。

## 风险警告
**核心风险在于海外业务持续亏损与商誉减值的双重压力。** 尽管IRO海外业务逐季改善，但全年仍录得显著亏损，且公司对IRO相关商誉及无形资产计提了约7800万元的减值准备。若海外业务无法在2026年实现根本性扭转，持续的减值测试将对利润表构成重大威胁。此外，欧元汇率波动带来的汇兑收益（2025年约5200万元）具有高度不确定性，一旦汇率反转，将直接侵蚀利润。

**另一风险是消费K型分化下的品牌定位挑战。** 公司主品牌ELLASSAY收入同比下滑3.8%，在高端女装存量竞争加剧的背景下，品牌升级与渠道优化效果尚需时间验证。同时，多品牌矩阵虽带来增长，但各品牌（尤其是新品牌nobis）仍处于投入期，若市场消费信心持续疲软，新品牌培育不及预期，可能导致整体增长放缓与费用率反弹。
