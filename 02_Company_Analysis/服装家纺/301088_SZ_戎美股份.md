# 301088.SZ 深度透视

## 因果逻辑链
- **[消费降级与行业承压]** -> [营收与利润双降]: 2025年服装行业整体承压，居民衣着消费趋于理性，公司全年营收同比下降13.94%，归母净利润同比下降26.96%。
- **[产品结构优化与毛利率提升]** -> [盈利能力改善]: 公司主动调整经营策略，聚焦高附加值产品，毛利率较上年同期提升3.37个百分点，主营业务持续盈利。
- **[“小单快反”柔性供应链]** -> [库存与现金流优势]: 高频上新、快速反应的业务模式使公司售罄率较高、库存冗余较低，经营活动现金流净额逆势增长7.68%。
- **[珠宝业务战略性扩张]** -> [第二增长曲线]: 珠宝收入同比增长98.57%，成为营收新亮点，开启“衣饰+珠宝”协同发展模式。
- **[大规模金融资产投资]** -> [非经常性损益贡献利润]: 公司利用闲置资金进行现金管理，2025年投资收益及公允价值变动损益合计约6,004万元，占利润总额的59.85%，成为利润的重要支撑。
- **[销售渠道高度集中]** -> [单一平台依赖风险]: 公司99%以上销售收入来自淘宝/天猫平台，渠道集中度极高，平台政策变动或合作关系变化将对公司经营产生重大不利影响。
- **[存货跌价准备大幅计提]** -> [资产减值侵蚀利润]: 2025年计提资产减值损失8,443万元，主要系存货跌价准备，对扣非净利润造成显著压力。

## 风险警告
**核心风险在于主业增长乏力与渠道单一依赖。** 公司营收连续两年下滑，2025年扣非净利润同比大降40.89%，显示核心服装业务在消费降级与行业竞争加剧下面临严峻挑战。同时，99%以上收入依赖淘宝/天猫单一平台，议价能力弱，一旦平台规则调整或流量分配变化，公司业绩将遭受系统性冲击。

**资产质量与盈利结构存在隐患。** 公司存货账面价值高达3亿元，且2025年计提了超过8,400万元的资产减值损失，库存压力与跌价风险不容忽视。更值得警惕的是，公司过半利润来自金融资产的投资收益，而非主营业务，这种盈利结构在资本市场波动时具有高度不确定性，难以支撑长期估值。
