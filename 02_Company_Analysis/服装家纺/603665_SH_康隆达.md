# 603665.SH 深度透视

## 因果逻辑链
- **[越南基地产能释放]** -> [一次性丁腈胶手套收入激增]: 越南康隆达12条丁腈手套产线投产，产能利用率大幅提高，该业务收入从无单独列示变为3.74亿元，成为核心增长引擎。
- **[出售美国GGS]** -> [归母净利润扭亏为盈]: 出售子公司产生约1.07亿元非流动资产处置收益，直接推动净利润从-4.86亿转为+0.80亿，但扣非净利润仍为-0.16亿。
- **[锂盐行业下行]** -> [锂盐业务大幅萎缩]: 碳酸锂价格低迷，公司主动收缩自营锂盐业务，锂盐产销量同比降超80%，加工业务占比被动提升，导致该板块毛利率为-55%。
- **[越南基地成本优势]** -> [手部防护毛利率提升]: 越南基地享受低廉的能源、人工及税收优惠，叠加产品结构优化，功能性手套毛利率同比提升3.70个百分点至30.45%。
- **[美国关税壁垒]** -> [加速越南基地战略地位]: 中美贸易摩擦促使公司加速将产能和订单向越南转移，以规避对等关税，越南基地成为承接海外订单的核心。
- **[锂盐加工模式转型]** -> [锂盐业务亏损收窄]: 从自购原料生产转为收取加工费模式，虽毛利率为负（-61.79%），但大幅降低了原料价格波动风险，亏损幅度较上年收窄。
- **[终止聚乙烯纤维募投项目]** -> [聚焦核心业务]: 因行业竞争加剧、产品效益不佳，终止原募投项目并将剩余资金永久补流，表明公司战略重心回归手部防护主业。

## 风险警告
**核心风险在于盈利的不可持续性与锂盐业务的深度拖累。** 公司2025年归母净利润扭亏为盈，完全依赖于出售美国GGS的一次性收益（约1.07亿元），扣非净利润仍亏损0.16亿元，表明主营业务造血能力并未恢复。锂盐业务（天成锂业、协成锂业）合计亏损超1.1亿元，且毛利率为-55%，成为吞噬现金流的无底洞。公司虽转向加工模式，但该板块产能利用率极低，短期内难以扭亏。

**第二大风险来自高企的财务杠杆与现金流压力。** 公司资产负债率高达72.7%，短期借款近9亿元，而货币资金仅1.57亿元，短期偿债压力巨大。经营活动现金流净额同比大幅下降48.44%，主要因锂盐业务萎缩及美国GGS出表。尽管越南基地带来增长，但其前期投入巨大，且公司需持续为越南基地输血（如增资1000万美元），在主营业务盈利不稳的情况下，资金链紧绷是持续威胁。
