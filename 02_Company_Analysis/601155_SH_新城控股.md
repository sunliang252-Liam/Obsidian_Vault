# 601155.SH 深度透视

## 因果逻辑链
- **[商业运营收入逆势增长]** -> [对冲地产开发收入下滑]: 2025年商业运营总收入140.90亿元（+10%），而房地产开发销售收入390亿元（-48.71%），商业板块成为利润稳定器。
- **[“吾悦经营五步法”方法论]** -> [提升运营效率与资产价值]: 通过“建好空间、组对内容、找到品牌、做高销售、分享收益”的系统化经营，实现出租率97.86%，客流增长13.31%。
- **[轻资产模式扩张]** -> [降低资本开支，扩大管理规模]: 新增30座管理输出吾悦广场，使用权资产同比+115.53%，以轻资产模式实现规模扩张，减少重资产投入。
- **[融资渠道畅通与信用优势]** -> [维持“零违约”纪录]: 成功发行近三年来民营房企首单纯信用境外债及三期中票，平均融资成本降至5.44%（-0.48pct），保障现金流安全。
- **[地产开发业务收缩]** -> [营收与利润承压]: 合同销售金额192.70亿元（-52.03%），结算收入470.24亿元（-48.71%），导致总营收下降40.44%，归母净利润下降9.61%。
- **[保交付与现金流管理]** -> [维持经营稳定性]: 完成超3.8万套物业交付，全口径资金回笼率110.41%，经营活动现金流净额14.25亿元，确保公司安全运营。
- **[消费提振政策与下沉市场]** -> [商业运营增长新引擎]: 国家提振消费、县域商业体系建设等政策利好，吾悦广场在低线城市布局优势显现，商业运营收入持续增长。

## 风险警告
**核心风险在于地产开发业务的持续萎缩与资产减值压力。** 2025年合同销售金额同比腰斩（-52.03%），导致营收大幅下滑40.44%。尽管商业运营收入增长10%至140.90亿元，但体量远不足以完全弥补地产开发收入的缺口（390亿元）。公司总资产同比减少13.53%，存货中大量在建及待开发项目面临去化压力，未来可能继续计提资产减值，侵蚀利润。

**财务风险集中于高负债与现金流压力。** 期末货币资金仅68.03亿元，同比减少33.92%，而短期借款及一年内到期的非流动负债规模庞大（年报未直接披露，但筹资活动净流出46.22亿元表明偿债压力）。公司整体平均融资成本虽降至5.44%，但应付关联方新城发展计息款项利率高达8%，显示外部融资渠道仍受限。若市场持续低迷，公司可能面临流动性紧张与再融资风险。
