# 002554.SZ 深度透视

## 因果逻辑链
- **[墨西哥天然气发电项目仲裁]** -> [归母净利润巨亏3.7亿元]: 墨电项目因重大仲裁事项导致项目停滞，公司计提大额资产减值损失（2.27亿元）及预计负债，是当期亏损的核心原因。
- **[海外项目收入确认与减值]** -> [信用减值损失转回但资产减值损失暴增]: 海外项目收入确认依赖完工百分比，审计师将其列为关键审计事项；同时，因项目风险暴露，公司对长期股权投资、固定资产等计提了高达3.06亿元的资产减值损失。
- **[汇率剧烈波动]** -> [财务费用激增144.74%]: 海外业务以美元计价为主，人民币汇率波动导致汇兑损失大幅增加，财务费用从4006万元飙升至9804万元，严重侵蚀利润。
- **[新签订单不足与项目进度滞后]** -> [油气工程及服务收入下滑11.39%]: 上半年新签订单不足，叠加部分海外重大项目进度滞后，导致核心主业收入萎缩，未能对冲减值损失。
- **[下游大客户检修]** -> [油气资源开发及利用收入下滑13.86%]: 天然气分销业务受下游大客户停产检修影响，用气量下降，导致该板块收入及利润贡献减少。
- **[经营活动现金流大幅净流出]** -> [现金流与净利润严重背离]: 尽管亏损，但经营活动现金流净流出高达5.49亿元（同比扩大185%），主要系项目收款减少而付款刚性，反映公司回款能力恶化及营运资金压力巨大。
- **[控股股东同业竞争承诺]** -> [业务整合存在不确定性]: 控股股东长沙水业承诺于2028年底前解决与公司在天然气运营等业务上的同业竞争，但具体方案及时间表仍存在不确定性，影响公司长期战略聚焦。

## 风险警告
**核心风险：墨电项目仲裁及资产减值失控。** 墨西哥天然气发电项目仲裁是2025年巨亏的直接导火索，公司已计提大额减值，但仲裁结果及后续赔偿金额仍存在重大不确定性。这暴露了公司在海外大型EPC项目中的风险管控能力严重不足，一旦类似项目出现争议，将对公司造成毁灭性打击。此外，公司对长期股权投资、固定资产等非流动资产计提了巨额减值，表明其资产质量已出现显著恶化。

**财务风险：现金流枯竭与高负债运营。** 经营活动现金流净流出5.49亿元，远超净利润亏损额，公司回款能力已严重恶化。与此同时，公司有息负债（短期借款+长期借款+一年内到期非流动负债）高达23亿元，财务费用因汇兑损失和利息支出激增。在持续亏损和现金流为负的背景下，公司偿债能力和持续经营能力面临严峻考验，依赖控股股东输血或外部融资的脆弱性极高。
