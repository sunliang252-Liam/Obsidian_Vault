# 601002.SH 深度透视

## 因果逻辑链
- **[钢材价格下行]** -> [毛利率大幅提升]: 原材料成本占生产成本约70%，钢材价格走低直接降低单位成本，使紧固件毛利率同比增加5.34个百分点，驱动净利润增长86%。
- **[高铁建设投资高位运行]** -> [铁路扣件订单充足]: 2025年全国铁路固定资产投资9015亿元，同比增长6%，公司作为唯一可生产全套时速250/350公里高铁扣件的集成供应商，持续中标重大铁路项目。
- **[直销模式占比提升]** -> [整体毛利率改善]: 直销毛利率41.39%，远高于经销模式的0.76%，直销收入同比增长8.03%，结构优化带动综合毛利率提升5.97个百分点。
- **[关联交易贡献显著]** -> [营收稳定但依赖度高]: 向关联方晋顺芯销售盘元、紧固件等达5.01亿元，占年度销售总额21.46%，是维持收入规模的关键渠道。
- **[存货减值压力释放]** -> [利润承压但可控]: 计提存货跌价准备1.27亿元，主要因紧固件库存量同比下降19%，但钢材价格低位导致可变现净值下降，减值损失同比扩大。
- **[海外市场收缩]** -> [出口业务拖累营收]: 境外收入同比下降40.87%，主要受贸易壁垒及反倾销税影响，出口毛利率仅8.51%，远低于境内27.26%。
- **[理财收益增厚利润]** -> [非经常性损益贡献]: 交易性金融资产期末余额3.49亿元，全年投资收益（含理财）约1321万元，为净利润提供额外支撑。

## 风险警告
**核心风险在于利润增长的高度脆弱性。** 2025年净利润暴增86%主要源于钢材价格下行带来的成本红利，而非业务量的实质性扩张（营收同比仅降1.4%）。一旦钢价反弹，毛利率将迅速承压。同时，公司对关联方销售依赖度高达21.46%，且境外收入因反倾销税锐减40%，海外市场开拓面临结构性障碍。

**资产质量与现金流隐忧不容忽视。** 存货账面价值12.5亿元，计提跌价准备1.27亿元，高库存与低周转并存。经营活动现金流净额同比大降40%，与净利润增长严重背离，反映回款能力恶化。此外，公司研发人员中无硕博学历，高中及以下占比47%，技术创新能力存疑，在高端紧固件国产替代竞争中可能落后。
