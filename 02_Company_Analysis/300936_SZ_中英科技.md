# 300936.SZ 深度透视

## 因果逻辑链
- **[下游通信基站建设放缓]** -> [高频覆铜板收入下降]: 5G基站建设节奏趋稳，终端客户投资减少，直接导致公司核心产品高频覆铜板订单下滑，营收同比下降17.88%。
- **[行业竞争加剧与消费景气度偏弱]** -> [扣非净利润转负]: 宏观经济影响下国内消费电子需求疲软，叠加同行扩产与新进入者涌入，产品价格承压，毛利率下降，导致扣非净利润亏损702万元。
- **[子公司辅星电子产品换代]** -> [VC散热片收入骤降]: 子公司辅星电子VC散热片产品处于升级换代期，订单暂时性减少，导致其营收同比下降57.91%，净利润亏损627万元，拖累整体业绩。
- **[计提大额信用减值损失]** -> [利润进一步侵蚀]: 基于谨慎性原则，公司对因诉讼产生的单项应收账款计提坏账准备，信用减值损失达682万元，加剧了净利润的下滑。
- **[募投项目变更与在建工程转固]** -> [固定资产大幅增加]: 原“高频塑料项目”变更为“精密金属蚀刻件项目”，同时子公司在建工程完工结转，固定资产同比增长13.32%，但新项目尚未贡献收益。
- **[购买理财产品]** -> [投资活动现金流大幅流出]: 公司利用闲置资金购买大额理财产品，导致投资活动现金流量净额由正转负，净流出3.17亿元，现金及等价物净减少3.11亿元。
- **[引线框架业务逆势增长]** -> [半导体封装材料收入提升]: 孙公司赛肯电子引线框架业务受益于下游封装需求回暖，营收同比增长13.04%，成为公司为数不多的增长亮点。

## 风险警告
公司面临的核心风险在于主营业务的双重挤压。一方面，通信材料业务（高频覆铜板+VC散热片）占营收近七成，却因5G建设周期放缓、消费电子需求疲软及行业竞争加剧而全面下滑，毛利率持续走低，这是公司业绩恶化的根本原因。另一方面，新业务拓展（储能、精密蚀刻件）尚处投入期，子公司辅星电子、嘉森能源持续亏损，新募投项目“精密金属蚀刻件”能否如期达产并消化产能存在巨大不确定性，短期内难以成为新的利润支柱。

财务风险同样不容忽视。公司应收账款规模高达1.27亿元，且已出现因诉讼计提大额坏账的情况，客户信用风险正在暴露。同时，公司净利润对非经常性损益（理财收益、资产处置收益）的依赖度极高，扣非净利润已连续亏损，若主业无法改善，公司持续盈利能力将面临严峻考验。此外，控股股东及一致行动人在报告期内多次减持，也向市场传递了负面信号。
