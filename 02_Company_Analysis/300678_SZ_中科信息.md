# 300678.SZ 深度透视

## 因果逻辑链
- **国家AI+政策推动和信创国产化要求** -> 公司新签合同额增长53%，营收增长25.9%: 国家政策加速AI应用落地和信创替代，为公司带来增量市场，公司凭借技术优势和市场地位获取更多订单，推动收入增长。
- **公司在数字会议、烟草、印钞等细分领域的技术领先和市场垄断地位** -> 公司能够持续获得高壁垒订单，保持高客户黏性: 公司在国家级会议系统、印钞检测、烟草信息化等领域具有绝对领先地位，客户依赖度高，订单来源稳定且增长。
- **持续的研发投入和技术创新（如AI大模型、机器视觉、信创产品）** -> 公司产品竞争力提升，助力客户提质增效，获得客户认可: 研发投入推动产品迭代，提升检测精度、效率与国产化能力，满足客户数字化转型需求，从而增强订单获取和收入增长。
- **市场开拓力度加大，营销体系完善，境外市场突破** -> 公司新签合同额大幅增长，业务范围扩大: 通过加强营销网络、拓展境外市场（如尼加拉瓜数字会议、俄罗斯烟草订单）等举措，直接带动新签合同额和收入增长。
- **下游行业数字化转型需求旺盛（烟草、油气、政务等）** -> 公司各业务板块收入持续增长: 下游行业（如烟草、油气）加速数字化转型，对信息化解决方案和智能化设备需求增加，直接拉动公司业务增长。

## 风险警告
公司部分业务依赖烟草、印钞等受行业景气度影响的领域，且省外市场覆盖不足，组织营销体系尚需完善。若行业政策变化或竞争加剧，可能影响收入增长。此外，信创项目推进不及预期、海外市场开拓风险也需关注。
