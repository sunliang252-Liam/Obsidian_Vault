# 002837.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [机房温控收入增长41.28%]: AI数据中心高功率密度驱动液冷与高效风冷方案加速渗透，公司作为全链条液冷龙头直接受益。
- **[储能行业需求恢复]** -> [机柜温控收入增长15.30%]: 全球储能装机持续高增，公司作为储能温控领导厂商，BattCool全链条液冷方案巩固份额。
- **[海外业务拓展与毛利率提升]** -> [境外毛利率达52.64%]: 高毛利的海外数据中心项目交付增加，带动整体盈利结构优化。
- **[股权激励费用摊销]** -> [净利润增速低于收入增速]: 2022年及2024年股权激励计划产生股份支付费用，对归母净利润影响约1168万元。
- **[商誉减值风险释放]** -> [资产减值损失达7318万元]: 对上海科泰等子公司计提商誉减值，累计减值达1.89亿元，风险进一步出清。
- **[应收账款规模扩大]** -> [信用减值损失9362万元]: 收入快速增长导致应收账款同步增加，坏账计提压力上升。
- **[研发持续高投入]** -> [技术壁垒与产品迭代]: 研发费用4.46亿元（占收入7.35%），聚焦液冷、3D-TVC、AI节能算法，巩固全链条技术领先地位。

## 风险警告
**核心风险在于应收账款与现金流的不匹配。** 公司2025年营收增长32%，但经营性现金流净额同比下降21%至1.57亿元，应收账款高达30.5亿元（占总资产39%），信用减值损失达9362万元。收入扩张伴随回款周期拉长，若下游客户（尤其是IDC和储能集成商）资金紧张，坏账风险将显著侵蚀利润。

**商誉减值风险尚未完全出清。** 虽然已累计计提1.89亿元商誉减值，但剩余商誉账面价值仍有6000万元。子公司上海科泰（轨交空调业务）收入同比下降40%，若地铁建设持续低迷，可能触发进一步减值。此外，储能行业竞争加剧导致机柜温控毛利率下降4.24个百分点，价格战若持续将压缩核心利润空间。
