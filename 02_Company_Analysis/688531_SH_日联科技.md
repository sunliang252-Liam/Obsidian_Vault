# 688531.SH 深度透视

## 因果逻辑链
- **[全谱系X射线源产业化加速]** -> [核心部件自给率提升]: 公司是国内唯一实现全谱系工业X射线源大批量产业化的企业，自产射线源渗透率提升，降低了对外采购依赖，提升了设备毛利率和供应链安全。
- **[AI垂域大模型发布]** -> [检测精度与效率量级突破]: 发布业内首款工业射线影像AI垂直大模型，构建“数据-算法-算力”闭环，使检测设备“看得清、检得快、判得准”，构筑高端智能检测设备核心技术壁垒。
- **[外延并购拓展检测技术版图]** -> [平台型公司雏形初现]: 收购珠海九源（电能变换检测）、新加坡SSTI（半导体缺陷定位与失效分析），形成X射线+电性能+激光+红外等多模态检测组合，从单一X射线龙头向工业检测平台型企业跨越。
- **[全球化“3+3”产业布局落地]** -> [海外营收高速增长]: 在新加坡、马来西亚、匈牙利、美国设立研发生产基地，海外营收同比增长106.62%，有效分散贸易摩擦风险，打开中长期增长空间。
- **[集成电路及电子制造检测需求爆发]** -> [核心业务高增长]: 受益于AI算力、先进封装、高多层PCB等新兴产业需求，该领域营收同比增长43.07%，毛利率提升3.10个百分点，成为业绩增长的核心引擎。
- **[新能源电池检测设备放量]** -> [营收规模快速扩张]: 受益于下游新能源汽车及储能行业快速发展，该领域营收同比增长67.36%，但毛利率微降1.28个百分点，显示竞争加剧。
- **[经营现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额同比增长512.23%，主要得益于回款能力更优的集成电路业务占比提升及加强应收账款管理，公司自身造血能力强劲。

## 风险警告
**核心风险在于商誉减值与整合不确定性。** 公司2025年密集收购珠海九源、新加坡SSTI等标的，形成较大商誉。若标的公司未来经营不及预期，或与集团在技术、市场、管理上的协同效应未能有效释放，将面临商誉减值风险，直接冲击当期利润。此外，多模态检测平台的搭建对跨领域管理能力提出极高要求，整合失败的风险不可忽视。

**另一重大风险是核心部件X射线源的对外采购依赖。** 尽管公司自产射线源已实现全谱系覆盖，但部分高端设备仍依赖外购。若国际供应链出现波动，或自产射线源在性能、产能上无法完全满足需求，将对公司经营造成不利影响。同时，下游新能源电池领域毛利率已出现下滑迹象，行业竞争加剧可能导致整体毛利率承压。
