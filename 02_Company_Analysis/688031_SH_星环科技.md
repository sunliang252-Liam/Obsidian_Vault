# 688031.SH 深度透视

## 因果逻辑链
- **[AI基础设施软件产品竞争力提升]** -> [软件产品及配套服务收入增长45.67%]: 公司产品向AI智能化迭代，满足客户“软件+服务”一体化需求，驱动核心业务高增长。
- **[老客户高粘性与复购]** -> [主营业务收入89.23%来自老客户]: 基础软件替换成本高，客户粘性强，存量客户扩容与增购成为收入压舱石。
- **[精细化费用管控与组织优化]** -> [销售费用同比下降21.66%，研发费用同比下降10.24%]: 通过优化人员结构、加强预算管理，在营收增长的同时实现费用收缩，亏损大幅收窄。
- **[加强应收账款全周期管理]** -> [经营活动现金流净额同比改善66.4%]: 加大回款催收力度，经营性现金流从-3.27亿大幅改善至-1.10亿，缓解资金压力。
- **[“AI×数据”全栈技术升级]** -> [推出新一代AI基础设施，明确数据平台为核心]: 将AI与数据深度融合，打造从语料到智能体的全链路工具，巩固技术领先地位。
- **[国产化替代与信创机遇]** -> [在金融、政府、能源行业收入增长]: 公司产品实现对Oracle、Teradata等国外产品的替代，受益于国产化政策，核心行业收入稳步提升。
- **[研发投入资本化]** -> [无形资产同比增长137.4%]: 部分研发项目完成资本化结项，虽短期增加摊销压力，但体现了技术成果的积累与转化。

## 风险警告
公司仍处于“增收不增利”的成长期，累计未弥补亏损高达15.6亿元，盈利拐点尚不明确。尽管2025年亏损大幅收窄，但高额的研发投入（占营收56%）和销售费用（占营收36%）是刚性支出，若收入增速放缓或费用管控失效，亏损可能再次扩大。此外，研发投入资本化形成的无形资产（同比+137%）将在未来摊销，对利润构成持续压力。

市场竞争格局严峻。公司面临来自国内外云厂商（如阿里云、华为云）、ICT巨头及开源软件的激烈竞争。尤其在AI大模型领域，技术迭代极快，若公司不能持续引领技术趋势或产品商业化不及预期，市场份额可能被侵蚀。同时，公司收入季节性极强（Q4占全年50%），且应收账款占流动资产35%，存在坏账和现金流波动的风险。海外市场尚处起步阶段，收入贡献极小，国际化战略存在不确定性。
