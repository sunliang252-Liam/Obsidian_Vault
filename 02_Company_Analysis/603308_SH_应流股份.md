# 603308.SH 深度透视

## 因果逻辑链
- **[全球燃气轮机供应链瓶颈]** -> [两机订单爆发式增长]: 全球AI数据中心建设提速，燃气轮机需求旺盛，而国际巨头交付周期延至2029-2030年，供给刚性极强，公司作为国内领先热端部件制造商，订单外溢效应显著，新签两机订单突破20亿元。
- **[国产重型燃机产业化突破]** -> [国产化替代成效显著]: 公司深度参与国内重型燃机国产化进程，突破超大、超重、超长叶片成型工艺，为东方电气、上海电气等头部企业持续供货，巩固国内重型燃气轮机市场领先地位。
- **[核能核电政策东风]** -> [核电业务规模持续扩大]: 国家大力推进新型电力系统建设，公司精准对接国家重大核电工程需求，核一级铸件市场占有率持续领先，中标国家重点工程屏蔽材料订单，金额创历史记录。
- **[“两机两业”战略聚焦]** -> [产业结构优化与毛利率提升]: 公司坚持“产业链延伸、价值链延伸”战略，重点发展航空航天、燃气轮机和核能核电领域高技术产品，高温合金产品及精密铸钢件产品毛利率提升1.32个百分点，机械装备构件收入同比增长36.75%。
- **[持续高研发投入]** -> [核心技术突破与产品升级]: 公司研发投入占营收比例达13.51%，重型燃气轮机叶片技术连续突破，大飞机发动机核心部件批量交付，商业航天产品助力朱雀巡天，形成“技术突破-产品领先-市场拓展”的正向循环。
- **[发行可转债与中期票据]** -> [资本结构优化与产能扩张]: 公司成功发行15亿元可转债和5亿元中期票据，募集资金投向“叶片机匣加工涂层项目”和“先进核能材料及关键零部件智能化升级项目”，有效补充产能扩张所需资金，为业务高质量发展提供资本支撑。
- **[全球顶级客户深度绑定]** -> [市场地位与品牌壁垒]: 公司是西门子能源F/H级重型燃气轮机透平叶片在中国的唯一供应商，与安萨尔多签署战略协议，与贝克休斯合作持续深入，产品出口40多个国家、百余家客户，形成高粘性客户壁垒。

## 风险警告
**1. 高负债率与资本开支压力：** 公司资产负债率高达58.38%，总负债76.58亿元，其中短期借款、长期借款及应付债券合计超44亿元。2025年经营活动现金流净额虽大幅改善至2.56亿元，但投资活动现金流净流出高达8.68亿元，主要用于产能扩张。公司处于资本密集投入期，若下游需求增速放缓或募投项目收益不及预期，高额利息支出（1.43亿元）将显著侵蚀利润，偿债压力不容忽视。

**2. 原材料价格波动与汇率风险：** 公司主要原材料为废钢、镍等合金材料，价格波动直接影响成本。虽然公司采用成本加成定价，但价格传导存在滞后性。同时，境外收入占比超51%，结算货币主要为美元、英镑和欧元，人民币汇率大幅波动将直接影响公司出口业务的盈利能力和汇兑损益。2025年财务费用中汇兑损益变动已构成重要影响因素。
