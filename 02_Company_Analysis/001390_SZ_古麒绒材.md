# 001390.SZ 深度透视

## 因果逻辑链
- **羽绒价格高位运行** -> **营收与利润双增**: 公司受益于羽绒市场景气度，2025年营收10.53亿元（+8.98%），归母净利润1.78亿元（+6.01%），量价齐升驱动业绩增长。
- **首发上市募资到位** -> **总资产与净资产大幅膨胀**: 2025年5月IPO募资净额5.35亿元，总资产同比+51.84%至21.44亿元，净资产同比+78.04%至16.27亿元，财务结构显著优化。
- **下游客户账期长于上游付款期** -> **经营活动现金流大幅转负**: 营收增长导致应收账款增加（4.85亿元），而采购需即时付款，经营现金流净额由正转负至-1.09亿元，盈利质量与现金流的背离加剧。
- **原材料成本占比极高** -> **毛利率承压**: 直接材料占营业成本97.16%，鹅绒类毛利率同比下降5.06个百分点至30.91%，成本传导能力受限。
- **产能扩张与客户集中** -> **新增产能消化风险**: 募投项目“年产2,800吨功能性羽绒绿色制造项目”在建，前五大客户销售占比50.92%，若大客户需求波动，新增产能消化存不确定性。
- **行业标准制定参与** -> **技术壁垒与品牌溢价**: 作为唯一参与《羽绒服装》新国标制定的羽绒生产企业，叠加CNAS认证实验室，巩固了中高端市场定位与客户粘性。
- **绿色工厂与中水回用** -> **环保合规成本优势**: 国家级“绿色工厂”及万吨级中水回用系统，在环保趋严背景下形成准入壁垒，同时降低长期用水成本。

## 风险警告
**核心风险在于盈利质量与现金流的严重背离。** 公司2025年净利润1.78亿元，但经营活动现金流净额为-1.09亿元，主要因下游品牌客户账期较长而上游采购需即时付款。这种“纸面富贵”模式在营收持续扩张时尤为危险，一旦下游需求放缓或客户回款延迟，公司将面临流动性压力，甚至需要依赖融资来维持运营。

**原材料价格波动是业绩的最大不确定性来源。** 直接材料占成本97%，羽绒价格高位运行时虽能推高营收，但若价格快速回落，公司高价储备的6.96亿元存货将面临巨额跌价准备风险。同时，鹅绒类毛利率已出现明显下滑，显示成本转嫁能力并非无限。此外，前五大客户集中度超50%，新增2000吨产能的消化高度依赖核心客户的持续采购，客户结构单一的风险不容忽视。
