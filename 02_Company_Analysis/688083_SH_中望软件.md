# 688083.SH 深度透视

## 因果逻辑链
- **[海外本地化战略深耕]** -> [境外收入增长35.32%]: 通过设立本地团队、完善渠道网络，海外市场成为公司增长核心引擎，对冲了国内教育及子公司业务下滑。
- **[教育市场政策调整与客户预算收紧]** -> [境内教育收入下降34.05%]: 政策环境变化和经费压力直接导致教育客户采购意愿和能力下降，拖累整体境内业务。
- **[子公司北京博超业务转型]** -> [计提商誉减值3,315.45万元]: 业务模式调整带来短期经营冲击，业绩下滑触发商誉减值，直接侵蚀当期利润。
- **[股权激励费用增加与自有大楼投用]** -> [管理费用同比增长10.27%]: 激励计划摊销及新办公楼开办、物业费用增加，推高了管理成本，对利润形成压制。
- **[理财产品收益减少]** -> [归母净利润下降67.57%]: 非经常性损益中理财收益同比减少2,410万元，是净利润大幅下滑的关键因素之一。
- **[加强应收账款管理]** -> [经营活动现金流净额增长509.62%]: 通过强化回款，销售商品收到的现金增加8,326万元，显著改善了现金流状况。
- **[ZW3D Wukong研发完成]** -> [为渗透中高端市场奠定基础]: 对底层参数化架构的重构，解决了复杂模型处理的稳定性问题，是未来挑战高端制造领域的关键技术突破。
- **[ZWCAD365云协同平台发布]** -> [推动商业模式向订阅制转型]: 推出“三端一体”的云平台，旨在满足协同设计需求，并为提升可持续收入占比提供产品基础。

## 风险警告
公司面临的核心风险在于**国内业务增长失速与利润持续承压**。境内教育市场受政策影响收入大幅下滑34%，子公司北京博超因战略转型计提大额商誉减值，叠加股权激励和自有物业带来的刚性费用增长，导致扣非净利润连续三年为负且亏损扩大。尽管海外业务增长强劲，但尚不足以完全弥补国内业务的缺口和利润端的侵蚀，公司盈利能力改善的拐点尚未明确。

此外，**激烈的市场竞争与知识产权纠纷**构成长期威胁。公司仍处于追赶达索、欧特克等国际巨头的阶段，在中高端市场面临直接竞争。同时，公司与欧特克在美国的诉讼及与ITC的仲裁尚未结案，结果存在重大不确定性，可能对公司海外业务拓展及财务状况产生不利影响。研发投入占比超51%的高强度模式，也意味着任何技术路线的偏差或研发失败都将带来巨大风险。
