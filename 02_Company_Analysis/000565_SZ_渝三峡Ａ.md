# 000565.SZ 深度透视

## 因果逻辑链
- **[并购蔚蓝时代]** -> [开辟第二增长曲线]: 2025年7月并表辐射制冷新材料公司，形成“涂料+新材料”双轮驱动，蔚蓝时代全年营收同比增长73.32%，并完成首年业绩承诺。
- **[减持北陆药业股票]** -> [净利润大幅增长]: 报告期减持参股公司北陆药业股票获得投资收益约1,449万元，是归母净利润从437万跃升至810万的核心非经常性损益来源。
- **[核心产品结构优化]** -> [毛利率提升]: 高毛利的环氧漆类产品销售额同比大增23.93%，带动整体毛利率同比提升3.13个百分点至25.76%。
- **[直销模式扩张]** -> [营收增长]: 直销销售额同比增长33.81%，新开发直销客户128家，推动总营收同比增长12.55%，弥补了经销商模式收入下滑。
- **[参股公司贡献稳定利润]** -> [业绩压舱石]: 联营企业新疆信汇峡（33%股权）和重庆关西贡献投资收益约3,347万元，是公司主营业务亏损下仍能盈利的关键。
- **[原材料价格下行与集中采购]** -> [成本控制]: 主要原材料二甲苯、稳定轻烃等价格同比下行，叠加公司集中采购策略，有效对冲了部分成本压力。
- **[产能利用率提升]** -> [规模效应初显]: 产能利用率从约41%提升至51.14%，生产智能化改造与工艺优化初见成效，支撑了销量增长。

## 风险警告
**核心风险在于主营业务造血能力不足，盈利高度依赖非经常性损益和投资收益。** 2025年扣非净利润为-330万元，连续两年为负，表明涂料主业在激烈竞争和需求疲软下仍处亏损状态。公司利润主要来自减持金融资产（北陆药业）和参股公司（新疆信汇峡、重庆关西）的分红，这种盈利模式不具备可持续性，一旦资本市场波动或参股公司业绩下滑，公司将面临巨大业绩压力。

**第二增长曲线尚处培育期，存在不确定性。** 蔚蓝时代虽完成首年业绩承诺，但营收规模仅2,758万元，且公司为此确认了约1,979万元的商誉。若未来辐射制冷材料市场拓展不及预期或技术迭代风险，将面临商誉减值风险，直接冲击利润表。此外，公司经营活动现金流净额为-2,428万元，连续三年为负，显示自身经营回款能力较弱，财务健康度有待改善。
