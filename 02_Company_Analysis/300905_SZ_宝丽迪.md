# 300905.SZ 深度透视

## 因果逻辑链
- **[原液着色技术契合环保趋势]** -> [营收与利润双增]: 环保政策趋严推动化纤行业绿色转型，公司核心的原液着色技术作为清洁生产工艺，需求持续增长，带动2025年营收增长8.97%，扣非净利润大增42.66%。
- **[收购厦门鹭意并表]** -> [规模与协同效应]: 收购厦门鹭意扩充了产能与客户资源，叠加多基地布局，提升了区域响应敏捷性与供应链韧性，是营收突破14.85亿的关键驱动力。
- **[股权激励费用减少]** -> [利润弹性释放]: 随着前期股权激励计划逐步落地，2025年股份支付费用较上年同期大幅减少，直接增厚了净利润，是扣非净利润增速远超营收增速的重要原因。
- **[原材料价格波动]** -> [毛利率改善]: 报告期内主要原材料（切片、炭黑等）价格有所下降，公司通过规模化采购与议价有效管控成本，推动整体毛利率同比提升3.05个百分点至21.35%。
- **[福建鹭意新产能释放]** -> [未来增长储备]: 年产4万吨色母粒新生产基地建设推进，截至报告期末已完成厂房建设及部分设备验收，新增产能正逐步释放，为未来2万吨净增产能弹性奠定基础。
- **[COFs材料吨级量产]** -> [开辟第二增长曲线]: 子公司耀科新材料实现国内COFs材料吨级量产，并规划建设200吨/年产线，切入高附加值新材料赛道，有望成为公司未来新的利润增长点。
- **[下游大型化纤企业自建产能]** -> [潜在竞争加剧]: 部分下游客户自建色母粒产能，可能对公司市场份额形成挤压，但高端定制化能力较弱的中小企业仍依赖专业供应商，为公司保留了差异化竞争空间。

## 风险警告
**核心风险在于下游客户自建产能的替代威胁与应收账款激增带来的现金流压力。** 报告显示，部分大型化纤企业正自建色母粒产能，这直接动摇了公司作为专业供应商的客户基础。尽管公司强调高端定制化能力壁垒，但若下游核心客户加速自供，将导致公司销量与市场份额承压，这是行业格局演变中最根本的长期风险。

**财务健康度方面，现金流恶化与商誉减值风险不容忽视。** 2025年经营活动现金流净额同比下降25.2%，远低于净利润增速，主因是应收账款同比大增53.3%至2.79亿元，显示公司为扩张销售放宽了信用政策，回款能力恶化。同时，账面商誉高达2.2亿元（主要来自收购厦门鹭意），若未来其业绩不达预期，将面临重大减值风险，直接冲击利润表。
