# 002114.SZ 深度透视

## 因果逻辑链
- **[自有矿山停产与产量骤降]** -> [原料自给率大幅下降]: 德荣矿业金坡铅锌矿采矿证到期停产，富乐铅锌矿安全生产许可证到期停产，导致锌精矿自产量锐减，公司被迫大幅增加外购原料比例。
- **[外购原料成本飙升]** -> [锌产品毛利被严重侵蚀]: 2025年锌精矿市场供应偏紧，外购原料采购单价上涨，叠加进口原料点价结算亏损，直接导致锌锭毛利率从正转负至-10.77%。
- **[加工费跌至历史低谷]** -> [冶炼环节盈利承压]: 国内锌冶炼加工费持续下行，叠加公司自有原料不足，冶炼环节无法通过加工费覆盖成本，进一步加剧亏损。
- **[子公司越界开采与补税]** -> [非经常性损失激增]: 贵州三家子公司因越界开采被行政处罚，罚款及补缴税款合计形成约2500万元营业外支出，直接拖累净利润。
- **[联营企业大幅亏损]** -> [投资收益由正转负]: 参股的兴义黄泥河发电公司因债务人司法重整计提大额坏账准备，导致公司确认的投资收益同比减少约1000万元。
- **[锌价全年下行趋势]** -> [产品售价承压]: 2025年锌价整体呈下行趋势，高位仅在一季度，后续逐步下调，公司销售端无法获得价格支撑。
- **[经营活动现金流净流出]** -> [财务压力加剧]: 因外购原料支出大幅增加，经营活动现金流由正转负，净流出3194万元，公司不得不增加融资规模，财务费用同比上升28.65%。

## 风险警告
罗平锌电正深陷“矿山停产-原料外购-成本失控-亏损扩大”的恶性循环。核心风险在于自有矿山复产时间高度不确定：富乐铅锌矿安全生产许可证自2024年3月到期后至今未办妥，德荣矿业金坡矿采矿证延续亦无明确进展。若矿山持续停产，公司原料自给率将长期维持在20%-30%的低位，完全暴露于外购原料价格波动与加工费低迷的双重挤压之下，亏损局面难以扭转。

此外，公司治理与合规风险显著。贵州三家子公司因越界开采被处罚，虽部分处罚因程序违法被撤销，但实质违法事实并未改变，后续仍可能面临更严厉的行政处罚或生态赔偿。公司累计未弥补亏损高达-10.97亿元，净资产已缩水至7.62亿元，资产负债率攀升至65.7%，财务弹性极弱。在锌行业产能过剩、加工费低迷的背景下，公司缺乏内生造血能力，持续经营能力面临严峻考验。
