# 688697.SH 深度透视

## 因果逻辑链
- **[产能扩张与规模效应]** -> [营收增长17.52%]: 四期项目投产释放产能，叠加产品矩阵完善，推动大型加工中心、立式数控机床销量分别增长25.44%和39.26%，带动总营收创新高。
- **[毛利率承压]** -> [净利润下降6.43%]: 四期投产带来的固定成本增加及市场竞争加剧，导致综合毛利率下降2.81个百分点，营收增长未能转化为利润增长。
- **[核心零部件进口依赖]** -> [成本与供应链风险]: 数控系统（发那科等）及导轨、丝杠等传动部件以进口为主，采购周期长、成本高，且受国际贸易摩擦影响存在断供风险。
- **[研发投入持续加码]** -> [技术壁垒与产品升级]: 研发费用同比增长22.63%，聚焦五轴联动、车铣复合、人形机器人专用机床等高端领域，支撑产品向高速度、高精度、智能化方向迭代。
- **[经销模式主导]** -> [市场渗透与渠道风险]: 经销收入占比76.78%，通过经销商网络快速覆盖国内外60多个国家，但渠道依赖度高，若核心经销商流失将冲击销售稳定性。
- **[下游需求结构变化]** -> [产品结构优化]: 新能源汽车、人形机器人等新兴行业需求崛起，公司针对性开发专用机床，立式数控机床收入增长25.33%，成为增长主力。
- **[资产周转效率下降]** -> [营运资金压力]: 应收账款和存货分别增长38.67%和32.48%，占流动资产比重超42%，回款周期延长与库存积压风险加大，侵蚀现金流质量。

## 风险警告
**核心风险在于“增收不增利”与资产质量恶化。** 营收增长17.52%的同时，净利润反降6.43%，主因是四期项目投产带来的折旧与固定成本刚性上升，叠加行业竞争加剧导致毛利率下滑。若未来产能利用率无法持续提升，或价格战进一步压缩利润空间，公司盈利能力将持续承压。更需警惕的是，应收账款和存货合计占流动资产比重已超42%，且增速远超营收，表明公司为冲规模可能放宽了信用政策或存在产品滞销，坏账与跌价风险显著上升。

**供应链“卡脖子”风险是长期隐忧。** 公司核心数控系统依赖发那科等国际供应商，导轨、丝杠等传动部件也以进口为主。在中美贸易摩擦及技术管制背景下，关键元器件存在断供或涨价风险。虽然公司正推进部分功能部件国产替代，但短期内难以完全摆脱依赖，一旦供应链受阻，将直接冲击生产交付与成本控制。
