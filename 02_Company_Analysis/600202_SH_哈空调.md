# 600202.SH 深度透视

## 因果逻辑链
- **[电站空冷订单爆发式增长]** -> [营收结构剧变]: 电站空冷收入同比+129%，占比从16%升至34%，驱动总营收增长8.25%，但石化空冷收入同比-13%，传统主业承压。
- **[国际大单突破（沙特5亿+）]** -> [现金流改善]: 收到税费返还及保函保证金增加，经营现金流由负转正至6457万元，但项目履约对资金形成刚性需求。
- **[原材料价格高位运行]** -> [利润微薄]: 尽管营收增长8%，但归母净利润仅731万元，净利率不足0.5%，毛利率仅13.28%，成本端压力巨大。
- **[信用减值损失激增]** -> [侵蚀利润]: 信用减值损失同比+88%至4074万元，主要因处置子公司及应收账款账龄恶化，直接吞噬营业利润。
- **[处置亏损子公司富山川]** -> [聚焦主业]: 转让富山川40%股权，剥离生物科技等非核心业务，优化资源配置，减少合并报表亏损。
- **[控股股东高比例质押]** -> [潜在控制权风险]: 控股股东34%持股中82%被质押，虽未影响经营，但构成股价下行时的强制平仓风险。
- **[连续两年净利润微薄]** -> [分红能力受限]: 2025年不进行股利分配，将利润用于补充流动资金及智能化改造，反映公司处于“保生存、谋转型”阶段。

## 风险警告
**核心风险在于“增收不增利”的困境持续深化。** 公司营收增长8.25%，但归母净利润仅731万元，同比几乎零增长。信用减值损失高达4074万元，是营业利润的3.8倍，表明应收账款管理存在严重问题，客户回款周期长、坏账风险高，这是公司盈利能力的最大拖累。同时，原材料价格高位运行，而下游客户议价能力强，毛利率被持续压缩，公司缺乏定价权。

**国际化转型与资金链压力并存。** 公司成功斩获沙特超5亿元大单，但国际项目执行周期长、履约标准严苛，对资金形成持续刚性需求。而公司资产负债率高达68.9%，短期借款激增110%至7.02亿元，一年内到期非流动负债虽有下降但仍达6.38亿元，偿债压力巨大。控股股东82%的股份质押进一步加剧了资本市场的脆弱性。公司处于“订单增长”与“资金紧张”的夹缝中，任何项目延期或原材料价格超预期上涨，都可能引发流动性危机。
