# 600303.SH 深度透视

## 因果逻辑链
- **[车桥销量增长28.45%]** -> [营收微增5.63%]: 车桥业务量增价稳，但整车销量暴跌40.83%，拖累整体增速。
- **[整车业务严重亏损]** -> [净利润-3.58亿]: 皮卡销量腰斩(-46.13%)，客车虽有增长但基数极低，整车毛利率为-5.36%，卖一辆亏一辆。
- **[财务费用激增41.88%]** -> [侵蚀利润]: 贷款利息支出增加，叠加短期借款暴增63.11%，债务负担加重。
- **[存货暴增139.82%]** -> [资金占用与减值风险]: 开发产品重分类导致存货激增，占流动资产近19%，加剧经营现金流恶化。
- **[经营现金流持续为负]** -> [造血能力枯竭]: 经营活动现金流净额-7462万，同比恶化，主营业务无法自给自足。
- **[短期偿债压力骤升]** -> [流动性危机]: 一年内到期的非流动负债暴增632%，达3.99亿，远超货币资金(6090万)。
- **[核心子公司巨亏]** -> [拖累集团业绩]: 丹东黄海汽车亏损2.4亿，净资产-3.99亿，已资不抵债，成为最大出血点。

## 风险警告
公司已陷入严重的财务困境与经营恶性循环。核心整车业务（皮卡、客车）销量低迷且亏损，导致整体毛利率仅1.78%，造血能力几近丧失。与此同时，短期借款和一年内到期债务合计超6.7亿，而账面货币资金仅6090万，且大部分受限，短期流动性风险极高。存货激增、经营现金流持续为负，进一步加剧了资金链断裂的风险。

公司面临的根本问题是产品竞争力不足，在新能源转型浪潮中严重掉队。尽管车桥业务有增长，但微薄的利润无法弥补整车业务的巨大窟窿。丹东黄海等核心子公司已资不抵债，若无法在短期内通过产品创新或资产重组实现根本性扭转，公司持续经营能力将面临重大挑战，退市风险不容忽视。
