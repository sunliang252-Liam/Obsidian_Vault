# 002932.SZ 深度透视

## 因果逻辑链
- **[集采降价与行业竞争加剧]** -> [营收与利润双降]: 集采导致产品价格下降，叠加行业竞争白热化，公司2025年营收同比下降24.28%，归母净利润由盈转亏至-1,646万元。
- **[终端客户回款困难]** -> [信用风险增加与坏账计提]: 客户资金紧张，信用风险上升，公司对高风险客户计提大额坏账准备，严重侵蚀利润。
- **[产能扩张后的折旧压力]** -> [固定成本高企]: 前期产能持续扩张导致固定资产规模较大，折旧费用高，在收入下滑时对利润形成刚性拖累。
- **[海外业务量利双增]** -> [核心增长引擎]: 海外营业收入同比增长82%，毛利率同比提升4.86%，成为对冲国内业务下滑的关键力量。
- **[血气诊断产品矩阵完善]** -> [进口替代与市场拓展]: 形成“PT1000+PT2000+GA1200”全场景血气解决方案，性能对标进口品牌，为国内进口替代和海外市场扩张提供核心产品支撑。
- **[急危重症信息化解决方案]** -> [提升客户粘性与导流诊断试剂]: 通过“软件+硬件+咨询”一体化方案，深度绑定医院客户，为诊断试剂和设备销售创造先发优势。
- **[非经常性损益依赖]** -> [利润波动性大]: 扣非净利润已连续三年为负，公司盈利高度依赖理财收益、政府补助及坏账转回等非经常性项目，主业造血能力不足。

## 风险警告
公司面临的核心风险是**主业盈利能力持续恶化**。扣非净利润已连续三年为负，且亏损额未见收窄，表明在集采降价和激烈竞争下，公司核心的体外诊断业务已陷入“增收不增利”甚至“减收减利”的困境。高额的固定资产折旧和坏账计提进一步放大了经营杠杆的负面效应，使得公司在收入下滑时利润端承受巨大压力。

其次，**战略转型存在巨大不确定性**。公司计划通过投资并购切入“治疗”板块作为第二增长曲线，并构建数据驱动的健康生态。然而，诊断业务基本盘尚未稳固，新业务领域（如创新药、AI医疗）的竞争壁垒极高，且外延式并购本身存在整合风险与商誉减值风险。在现金流为负、主业亏损的背景下，大规模投资并购可能进一步消耗公司宝贵的现金储备，加剧财务风险。
