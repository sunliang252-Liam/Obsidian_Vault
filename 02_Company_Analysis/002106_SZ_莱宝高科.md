# 002106.SZ 深度透视

## 因果逻辑链
- **[汇兑损失与财务费用激增]** -> [净利润暴跌34.54%]: 美元兑人民币汇率贬值导致汇兑损失，叠加MED项目含回购条款投资款利息计提，财务费用同比增加1.22亿元，直接侵蚀利润。
- **[MED项目投产前费用拖累]** -> [净利润承压]: 控股子公司莱宝显示处于建设期，人工、管理、研发等费用大幅增加，项目投产前持续亏损，拉低合并报表利润。
- **[车载盖板玻璃价格战]** -> [毛利下滑]: 车载产品销量虽增，但行业降价压力传导，产品价格下降较大，导致整体销售毛利同比减少5489万元。
- **[外挂式触摸屏被替代]** -> [长期增长天花板]: 显示面板厂商推广In Cell/On Cell嵌入式结构，对外挂式结构（OGS、OGM等）形成替代竞争，公司缺乏面板资源，市场空间受挤压。
- **[AI PC渗透率提升]** -> [触控需求结构性利好]: AI PC标配触控功能，推动笔记本电脑触控屏从“高端配置”向“AI交互入口”转变，利好公司外挂式触摸屏出货。
- **[客户高度集中]** -> [经营脆弱性]: 前五大客户销售额占比82.74%，单一客户占比43.31%，订单波动直接决定公司营收与利润稳定性。
- **[MED项目资本开支巨大]** -> [现金流与债务压力]: 计划总投资90亿元，2025年在建工程激增至50.36亿元，投资活动现金流净流出35.86亿元，长期借款与金融负债大幅增加。

## 风险警告
**核心风险在于“新旧动能转换期的利润断层”。** 公司传统主业（中大尺寸触摸屏）面临In Cell技术替代和车载价格战的双重挤压，盈利能力持续走弱；而寄予厚望的MED项目尚处建设期，2026年才逐步投产，投产前每年需承担巨额利息费用（含回购条款投资款）和运营亏损，形成显著的“利润真空期”。2025年净利润已暴跌34.54%，若MED项目量产不及预期或市场导入缓慢，业绩可能进一步恶化。

**财务风险高度集中于汇率波动与资本开支失控。** 公司出口占比近90%，美元结算为主，人民币汇率波动直接导致汇兑损益剧烈波动（2025年财务费用同比暴增170%）。同时，MED项目90亿投资中大部分为进口设备，日元/美元升值将直接推高投资预算，而公司已通过银团贷款和含回购条款的股权投资融资，资产负债率快速攀升，偿债压力与财务费用刚性增长将长期压制利润。
