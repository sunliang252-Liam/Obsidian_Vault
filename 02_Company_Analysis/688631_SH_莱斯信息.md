# 688631.SH 深度透视

## 因果逻辑链
- **[城市道路交通管理业务收入大幅下降]** -> [整体营收与净利润双降]: 该板块收入同比暴跌61.08%，直接拖累公司总营收下降20.89%，净利润下降57.18%。
- **[地方财政收紧与行业竞争加剧]** -> [交通管理业务萎缩]: 传统交管信息化项目预算收紧、回款周期拉长，公司主动收缩低效集成类业务，导致该板块收入锐减。
- **[民航空管基本盘稳固]** -> [核心业务抗周期性强]: 空管自动化系统等核心产品持续领跑，落实上海二区管等重大项目，该板块收入逆势增长3.15%，成为业绩压舱石。
- **[低空经济战略布局加速]** -> [第二增长曲线初现]: 公司“天牧”系列产品落地全国十余座重点城市，低空业务从试点向规模化迈进，成为未来核心增长极。
- **[研发投入持续加大]** -> [短期利润承压，长期技术壁垒加固]: 研发费用同比增长6.52%，占营收比例提升至12.17%，重点投向低空、车路云等前沿领域，巩固技术护城河。
- **[应收账款与经营现金流恶化]** -> [财务风险显著上升]: 应收账款占总资产比例高达41.17%，经营活动现金流净额由正转负至-2.09亿元，反映出回款困难与资金占用加剧。
- **[被列入美国“实体清单”]** -> [供应链与海外业务受限]: 对境外器件采购形成限制，虽已启动国产替代方案，但验证周期长，对研发和海外拓展构成潜在风险。

## 风险警告
公司当前最核心的风险在于**业绩高度依赖政府财政与行业周期**。城市道路交通管理业务的断崖式下滑已证明其对地方财政紧缩的脆弱性。尽管民航空管基本盘稳固，但该领域投资同样受制于国家基建节奏。低空经济作为第二增长曲线，目前仍处于政策驱动和试点阶段，其规模化落地速度、商业化变现能力均存在较大不确定性，短期内难以弥补传统业务下滑的缺口。

其次，**财务健康度亮起红灯**。应收账款规模巨大且持续增长，占总资产超四成，而经营活动现金流净额大幅转负，表明公司“纸面利润”向“真实现金”的转化能力严重不足。这种“增收不增现”甚至“减收更减现”的局面，若持续恶化，将严重制约公司研发投入和市场拓展能力，甚至引发流动性危机。叠加被美国列入“实体清单”带来的供应链与海外业务不确定性，公司正面临短期业绩压力与长期战略转型的双重考验。
