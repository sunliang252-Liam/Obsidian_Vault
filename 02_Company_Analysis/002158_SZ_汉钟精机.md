# 002158.SZ 深度透视

## 因果逻辑链
- **光伏行业产能过剩与价格竞争** -> 真空产品收入同比下降62.76%: 光伏行业产能过剩导致光伏真空泵需求下行，公司该业务收入大幅减少
- **真空产品收入大幅下降** -> 整体营业收入同比下降20.35%: 真空产品占比较高（36.63%），其大幅下滑拖累整体营收
- **商用中央空调市场整体下行** -> 压缩机（组）收入增长受限: 传统商业地产需求萎缩，但数据中心等细分领域增长支撑压缩机业务仍实现5.83%增长
- **数据中心液冷需求爆发** -> 磁悬浮/气悬浮离心压缩机增长: AI算力需求推动数据中心温控向液冷发展，公司RTM/RTA系列受益
- **海外数据中心需求强劲** -> 境外营收同比增长6.09%: 海外数据中心对制冷压缩机需求强劲，带动境外业务增长
- **半导体国产替代加速** -> 半导体真空泵批量供货: 国产化进程推动公司半导体真空泵通过认证并进入批量供应
- **整体营收下降20.35%** -> 净利润同比下降45.66%: 营收下降同时成本刚性导致利润降幅更大

## 风险警告
公司核心风险在于光伏行业产能过剩导致真空泵业务大幅下滑，短期内难以反弹；商用中央空调市场整体下行可能进一步压缩传统压缩机业务；半导体真空泵验证周期长，收入贡献有限；行业竞争加剧，价格战侵蚀利润空间。
