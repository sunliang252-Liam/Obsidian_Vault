# 300997.SZ 深度透视

## 因果逻辑链
- **[消费环境承压 & 行业竞争激烈]** -> [经销渠道收入下降26.95%]: 作为核心销售渠道（占比80.35%），经销模式受宏观消费疲软和竞争加剧冲击，导致整体营收下滑19.11%。
- **[渠道结构向低毛利渠道迁移]** -> [整体毛利率下降4.41个百分点至29.59%]: 公司主动开拓零食量贩渠道（毛利率17.81%）和椰子原料初加工业务（毛利率较低），虽带来增量收入，但拉低了综合盈利水平。
- **[核心原材料采购成本大幅上涨]** -> [净利润暴跌70.03%]: 生榨椰肉汁、黄桃等主要原材料采购单价同比涨幅超30%，直接增加生产成本约3853万元，严重侵蚀利润。
- **[零食量贩渠道高速增长]** -> [部分对冲经销渠道下滑]: 该渠道收入同比增长52.06%至1.75亿元，成为公司重要的增量来源，但低毛利率特征使其对利润贡献有限。
- **[椰子原料初加工业务开拓]** -> [其他业务收入增长50.63%]: 依托东南亚椰子加工项目，开展生榨椰肉汁销售业务，实现收入1.12亿元，但该业务尚处初期，未形成规模效应。
- **[销售费用率下降]** -> [未能阻止利润下滑]: 公司主动削减代言费、促销费等销售开支（同比下降25.53%），但成本端压力过大，费用控制无法弥补毛利损失。
- **[研发投入大幅缩减]** -> [长期产品竞争力存疑]: 研发费用同比下降53.34%，研发人员减少40%，公司在新品开发和产品迭代上的投入减弱，可能影响未来增长动力。

## 风险警告
**核心风险在于“新旧动能转换”过程中的利润塌陷。** 公司传统经销渠道（高毛利）因消费疲软而萎缩，被迫转向零食量贩和原料贸易等低毛利渠道寻求增量。这种“以量换利”的策略导致营收下降19.11%，但净利润却暴跌70.03%，利润降幅远超收入降幅。若原材料成本（尤其是椰子、黄桃）持续高位，而新渠道无法快速实现规模效应以提升毛利率，公司盈利能力将持续承压。

**另一重大风险是战略转型的不确定性。** 公司重金押注海外椰子加工项目（印尼、越南），旨在向上游延伸供应链，但该项目尚在建设初期，不仅短期内无法贡献利润，反而产生亏损（印尼项目报告期亏损91.6万元），且面临海外经营、汇率波动等复杂风险。同时，研发投入大幅削减，可能削弱公司在产品创新上的核心竞争力，使其在激烈的市场竞争中陷入被动。
