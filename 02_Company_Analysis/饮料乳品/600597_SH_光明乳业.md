# 600597.SH 深度透视

## 因果逻辑链
- **[海外子公司新莱特生产事故]** -> [归母净利润亏损1.49亿元]: 新莱特生产基地出现生产问题，导致存货报废、生产成本激增，全年亏损4.07亿元，直接拖累合并报表由盈转亏。
- **[国内消费需求疲软]** -> [营收下滑1.58%]: 乳制品行业供强需弱，液态奶全渠道消费市场规模承压，公司核心液态奶收入同比下降6.65%。
- **[原奶价格持续低位]** -> [牧业板块亏损加剧]: 生鲜乳价格年内下跌约2.9%，叠加出售犊牛亏损，牧业板块毛利率降至-9.71%，成为业绩拖累。
- **[资产处置收益不可持续]** -> [非经常性损益大幅减少]: 上年同期确认闵行地块搬迁处置收益约7.3亿元，本报告期无此大额收益，导致归母净利润同比暴跌120.67%。
- **[低效产能优化与渠道变革]** -> [毛利率承压]: 主动淘汰老旧生产线、优化产能，但经销商销售模式毛利率下降2.38个百分点，整体盈利能力未能改善。
- **[新莱特北岛资产出售]** -> [改善现金流与资本结构]: 拟以1.7亿美元出售北岛Pokeno工厂，预计2026年交割，将带来充足现金流用于偿债，降低利息成本。
- **[小西牛业绩承诺未达标]** -> [确认补偿款]: 小西牛三年累计业绩完成率93.32%，公司确认补偿款约3243万元，用于抵扣后续股权收购款。

## 风险警告
**核心风险在于海外子公司新莱特的经营失控。** 2025年新莱特因生产事故导致巨额亏损，直接导致上市公司整体亏损。尽管公司已启动北岛资产出售以缓解债务压力，但该交易尚未完成交割，且新莱特未来能否恢复稳定盈利存在重大不确定性。海外业务的高波动性是公司业绩的“定时炸弹”。

**国内主业增长乏力是另一大隐忧。** 公司核心液态奶收入连续下滑，上海大本营市场营收同比下降9.22%，显示出在激烈竞争中的守成压力。同时，牧业板块持续亏损，全产业链协同优势未能转化为利润。在行业整体需求疲软、竞争加剧的背景下，公司2026年经营计划（营收248.58亿，净利3.13亿）的实现面临巨大挑战。
