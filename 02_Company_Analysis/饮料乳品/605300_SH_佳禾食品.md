# 605300.SH 深度透视

## 因果逻辑链
- **[原材料价格上涨]** -> [净利润暴跌63.31%]: 主要原材料成本上升，直接侵蚀了公司核心利润，导致归母净利润从0.84亿骤降至0.31亿。
- **[核心产品粉末油脂销量下滑]** -> [营收下降2.36%]: 下游茶饮行业“去植脂末化”趋势导致公司第一大业务粉末油脂销量同比下降11.56%，拖累整体营收。
- **[咖啡业务高速增长]** -> [第二增长曲线显现]: 咖啡业务营收同比增长29.59%，成为公司对冲粉末油脂下滑、维持营收规模的关键力量。
- **[C端业务爆发式增长]** -> [品牌转型初见成效]: 公司C端业务营收同比增长86%，线上渠道（抖音、天猫）及“非常麦”、“金猫”等自有品牌建设取得突破。
- **[营销费用大幅增加]** -> [侵蚀利润]: 为推进C端品牌建设和市场推广，销售费用同比增长4.45%，在毛利下滑的背景下进一步压缩了利润空间。
- **[再融资完成]** -> [净资产大幅增长33.07%]: 2025年3月完成向特定对象发行股票，募集资金约7.1亿元，主要用于咖啡扩产，显著增强了资本实力。
- **[经营活动现金流净额为负]** -> [盈利质量恶化]: 经营活动现金流净额由正转负至-2638万元，主要因原材料采购支出增加，显示公司盈利的现金保障能力严重下滑。

## 风险警告
**核心风险：主业萎缩与转型阵痛并存。** 公司核心业务粉末油脂正面临下游茶饮行业“去植脂末化”的结构性冲击，销量与毛利率双降，这是利润暴跌的根本原因。尽管咖啡和C端业务增长迅猛，但体量尚小，短期内无法弥补主业的利润缺口，且C端扩张带来的高额营销费用正在持续侵蚀本已微薄的利润。公司正处于新旧动能转换的脆弱期，业绩稳定性极差。

**财务风险：盈利质量堪忧，现金流恶化。** 2025年扣非净利润仅878.8万元，同比暴跌87.54%，表明公司主营业务几乎不赚钱。经营活动现金流净额由正转负，与净利润严重背离，说明利润并未转化为现金，公司可能面临营运资金压力。同时，公司持有大量交易性金融资产（14.85亿元），投资收益对利润贡献巨大，掩盖了主营业务的真实困境，一旦市场波动，利润将面临更大风险。
