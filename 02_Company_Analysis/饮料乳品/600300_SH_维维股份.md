## 因果逻辑链
- **[主动收缩低毛利贸易业务]** -> [营收下降8.42%]: 公司战略性收缩粮油贸易等低毛利业务，导致整体营收规模阶段性下滑，但核心主业毛利率提升。
- **[核心主业毛利率提升]** -> [扣非净利润仅下降7.8%]: 固体冲调饮料（豆奶粉）毛利率提升2.84个百分点至45.70%，有效对冲了营收下滑对利润的冲击。
- **[存货大幅减少]** -> [经营现金流暴增209%]: 本期采购存货减少，购买商品支付的现金大幅下降，经营活动现金流净额从2.88亿飙升至8.93亿。
- **[上期高基数资产处置收益消失]** -> [归母净利润下降18.63%]: 2024年确认济南维维拆迁等资产处置收益1.17亿，2025年无此非经常性收益，导致归母净利润同比下滑。
- **[国资控股背景]** -> [融资成本降低与战略稳定性]: 实控人为徐州市国资委，公司财务费用由正转负（-111%），且获得长期稳定的战略资源支持。
- **[新设子公司与上海运营中心]** -> [战略转型落地]: 全资设立江苏维维食品生物科技公司，并在上海设立独立运营中心，引入职业经理人，推动品牌年轻化与渠道革新。
- **[促销费大幅增加]** -> [销售费用增长9.78%]: 为应对市场竞争和渠道下沉，促销费同比增加3439万元，侵蚀部分利润。
- **[研发投入极低]** -> [长期产品创新风险]: 研发费用仅897万元，占营收0.27%，研发人员26人（占员工总数0.89%），难以支撑“植物基营养食品”战略所需的产品迭代。

## 风险警告
**核心风险在于增长失速与战略转型的不确定性。** 公司营收连续两年下滑（2024年-9.4%，2025年-8.4%），核心的固体冲调饮料业务（豆奶粉）销量同比下降5.62%，动植物蛋白饮料销量基本持平但收入下降12%，显示传统主业已进入存量博弈阶段。公司虽提出“三大战略线”转型，但研发投入极低（0.27%），新设子公司和上海运营中心尚处于投入期，新业务能否贡献增量尚需时间验证。

**财务风险集中在资产质量与盈利可持续性。** 公司粮油初加工业务毛利率为-0.22%，处于亏损状态；粮油贸易毛利率仅3.79%，且营收占比高，拉低整体盈利水平。此外，公司货币资金大增但部分受限（保证金），且短期借款增加38%，需关注资金使用效率。高分红（50%派现率）虽回报股东，但也可能削弱公司转型所需的资本积累。
