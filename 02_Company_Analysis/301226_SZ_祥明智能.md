# 301226.SZ 深度透视

## 因果逻辑链
- **[下游房地产周期性调整]** -> [内销收入下降9.68%]: 公司主要下游应用领域为房地产相关HVACR，该行业周期性调整直接导致国内订单减少。
- **[外销市场拓展与结构优化]** -> [外销收入增长19.12%，毛利率提升5.14%]: 公司主动调整市场结构，加大海外市场开拓力度，外销高毛利产品占比提升，对冲了内销下滑。
- **[研发投入大幅增加]** -> [净利润下降43.35%]: 为布局未来产业（具身智能、医疗健康等），研发费用同比增长21.23%，短期内侵蚀了当期利润。
- **[募投项目推进导致资产报废]** -> [非经常性损失433.68万元]: 生产基地扩建项目推进过程中，对旧设备进行报废处理，产生一次性固定资产处置损失。
- **[铜材等原材料价格上涨]** -> [主营业务毛利率反升1.96%]: 尽管铜价上涨，但公司通过产品结构优化（高毛利风机、外销占比提升）成功转嫁成本压力，毛利率不降反升。
- **[经营性应收项目减少]** -> [经营活动现金流净额大增40.15%]: 公司加强回款管理，收回逾期账款，经营性现金流显著改善，与净利润大幅下滑形成反差。
- **[“电机+”产品策略]** -> [风机与直流无刷电机收入增长]: 公司将电机与电子、控制、流体等技术集成，开发出精密风机、关节模组等高附加值产品，带动核心品类增长。
- **[收购BorgRoid株式会社]** -> [布局具身智能新增长曲线]: 通过收购日本BR公司55%股权，切入机器人、智能装备等未来产业，寻求“科技+产业+资本”的转型。

## 风险警告
**核心风险在于战略转型期的“青黄不接”。** 公司正从传统的房地产相关HVACR电机业务，向具身智能、医疗健康、数据中心等新质生产力领域艰难切换。2025年净利润暴跌43.35%，主因是研发费用激增21.23%和募投项目带来的资产报废损失，这本质上是为未来“买单”的阵痛。然而，新业务（如伺服电机、微型气泵）尚处于研发或小批量阶段，短期内无法贡献显著利润，而传统业务（交流异步电机）仍在萎缩，公司面临新旧动能转换的“真空期”。

**另一个风险是“增收不增利”的持续性。** 尽管外销增长亮眼（+19.12%），但内销下滑（-9.68%）导致总收入几乎原地踏步。更关键的是，公司扣非净利润仅1,514.8万元，同比微增1.77%，说明主营业务盈利能力并未实质性改善。若未来研发投入无法快速转化为订单，或原材料价格继续上涨，公司利润可能进一步承压。此外，募投项目“电机风机扩建项目”进度严重滞后（投资进度仅49%），产能释放的不确定性也构成隐忧。
