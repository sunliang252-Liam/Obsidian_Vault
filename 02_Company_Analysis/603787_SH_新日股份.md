# 603787.SH 深度透视

## 因果逻辑链
- **[新国标政策实施]** -> [行业集中度提升]: 2024版新国标提高技术门槛，加速中小品牌出清，头部企业新日受益于市场格局优化。
- **[以旧换新政策刺激]** -> [销量增长]: 各地补贴政策直接拉动终端消费需求，公司2025年电动自行车销量同比增长29.62%。
- **[渠道下沉与终端赋能]** -> [营收增长17.15%]: 加大对三四线城市及乡镇市场布局，配合经销商培训与数字化工具，有效扩大市场覆盖。
- **[爆品战略与产品迭代]** -> [品牌竞争力提升]: 聚焦甜心、梦想系列等爆款车型，精准切入女性、年轻等细分市场，带动销量与均价提升。
- **[精益生产与供应链优化]** -> [毛利率承压但运营效率提升]: 成本管控措施部分对冲了原材料价格波动，但电动自行车毛利率仍下降0.74个百分点。
- **[非经常性损益贡献]** -> [净利润增速远超营收]: 2025年扣非净利润仅2677万，但净利润达5060万，主要依赖政府补助、金融资产收益等非经常性项目。
- **[第四季度巨额亏损]** -> [全年业绩波动剧烈]: Q4单季归母净利润亏损6516万元，显示公司经营存在显著的季节性波动或年末费用集中计提问题。

## 风险警告
**核心风险在于盈利质量极差且高度依赖非经常性损益。** 2025年扣非净利润仅2677万元，同比暴增1037%的基数极低，而净利润5060万中近一半来自政府补助、理财收益等不可持续项目。更危险的是，第四季度单季巨亏6516万元，吞噬了前三季度全部利润，表明公司主营业务盈利能力脆弱，成本控制或费用管理存在重大缺陷。

**行业竞争与政策风险双重挤压。** 电动两轮车行业已进入头部企业价格战阶段，新日市占率远低于雅迪、爱玛，在规模效应和品牌溢价上处于劣势。新国标虽利好头部，但合规改造投入巨大，且原材料价格波动直接侵蚀本已微薄的毛利率。海外印尼基地尚处建设期，短期无法贡献利润，反而持续产生亏损。
