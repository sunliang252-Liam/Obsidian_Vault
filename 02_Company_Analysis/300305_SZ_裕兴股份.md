# 300305.SZ 深度透视

## 因果逻辑链
- **光伏行业技术路线变化：N型双面组件取代单玻组件** -> 光伏用聚酯薄膜需求大幅减少: 下游光伏电池工艺技术迭代，N型电池带动双面双玻光伏组件市占率快速提升，单玻光伏组件市场缩小，配套单玻组件使用的光伏用聚酯薄膜需求大幅减少。
- **光伏用聚酯薄膜需求减少** -> 公司主动调整产品结构，重点增销电子光学用聚酯薄膜: 为应对光伏需求萎缩，公司调整产品结构，转向电子光学用聚酯薄膜。
- **公司主动调整产品结构** -> 电子光学用聚酯薄膜收入同比增长31.97%: 公司加大电子光学用聚酯薄膜的产销力度。
- **电子光学用聚酯薄膜新产品批量小、良率不高、新产线产能爬坡** -> 电子光学用聚酯薄膜生产成本较高: 新产品初期批量小、良率低，新产线调试和试生产增加成本。
- **部分产品降级销售** -> 电子光学用聚酯薄膜售价下滑: 良率不高的产品降级销售，拉低均价。
- **生产成本较高及售价下滑** -> 电子光学用聚酯薄膜毛利率同比下降11.29%: 成本上升和价格下降共同导致毛利率下降。
- **行业新增产能放缓但供需失衡依然严峻，产能利用率处于历史低位** -> 聚酯薄膜中低端产品同质化竞争激烈，价格持续下行: 产能过剩导致供大于求，竞争加剧，价格走低。
- **聚酯薄膜售价下滑及产能利用率不足** -> 公司整体盈利能力下降，陷入亏损: 量价齐跌导致收入减少，固定成本摊薄不足。
- **产能利用率不足** -> 制造费用占比上升: 产量下降导致固定折旧成本分摊增加。
- **新增产能投放中，新生产线处于调试或爬坡阶段** -> 产能利用率进一步被拉低: 新增产能未完全释放，短期内增加产能利用率压力。
- **公司建设期内生产线延期** -> 资本支出计划延后: 项目建设期延长，投资进度放缓。
- **公司坚持差异化、高附加值产品路线** -> 电子光学等高端产品收入占比提升: 公司主动调整结构，重点发展电子光学用聚酯薄膜。

## 风险警告
行业供需持续失衡，中低端产品同质化竞争激烈，价格下行压力大，公司产能利用率处于历史低位（31.54%），整体盈利能力恶化，聚酯薄膜制造毛利率为-19.40%。公司正处于产品结构调整期，电子光学用聚酯薄膜虽增长显著，但因新产品良率低、产能爬坡等因素导致毛利率为负（-16.41%），短期盈利改善存在不确定性。此外，在建生产线延期可能影响产能释放节奏，光伏需求萎缩的风险仍存。
