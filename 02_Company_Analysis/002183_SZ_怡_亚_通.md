# 002183.SZ 深度透视

## 因果逻辑链
- **[低毛利分销业务收缩]** -> [营收下降12.14%]: 主动压缩低毛利长尾业务，导致分销和营销收入同比下滑17.74%，拖累整体营收规模。
- **[跨境及物流业务爆发]** -> [营收增长53.48%]: 受益于中国企业出海浪潮与全球化布局，跨境物流业务成为核心增长引擎，营收达90.10亿元。
- **[AI算力业务高增]** -> [营收增长28.79%]: 卓优云智等主体深度绑定超聚变、华鲲振宇等大厂，受益于智算中心建设浪潮，算力业务实现10.66亿元营收。
- **[高额财务费用侵蚀利润]** -> [净利润亏损3.19亿元]: 短期借款高达183.84亿元，全年财务费用9.92亿元，严重吞噬主营业务利润，导致由盈转亏。
- **[资产减值与公允价值变动]** -> [扣非净利润亏损4.26亿元]: 第四季度集中计提大额资产减值损失及衍生品公允价值变动损失，导致全年扣非净利润深度亏损。
- **[政企集采平台扩张]** -> [营收增长27.06%]: 成功中标南方电网、国家电网等百逾个央国企项目，累计运营客户213家，驱动政企采购业务规模增长至23.24亿元。
- **[资本赋能产业协同]** -> [投资收益与生态布局]: 通过参股伟仕佳杰、联芸科技、卓怡恒通等，分享AI算力、存储芯片等赛道增长红利，并强化产业链协同。

## 风险警告
**核心风险在于高杠杆运营下的财务脆弱性。** 公司短期借款高达183.84亿元，占总资产31.68%，全年财务费用近10亿元，远超净利润。在营收下滑、利润亏损的背景下，巨额的利息支出是吞噬利润的首要因素。一旦融资环境收紧或信用评级下调，公司将面临流动性危机，偿债压力巨大。

**第二重风险是传统分销业务的持续萎缩与转型阵痛。** 公司主动收缩低毛利分销业务，导致营收连续两年下滑（2024年-17.74%，2025年-12.14%）。虽然跨境物流和AI算力业务增长迅猛，但体量尚不足以完全对冲传统业务的萎缩。同时，公司第四季度集中出现大额亏损，暴露出在业务转型期，资产减值、衍生品投资等非经常性损益对利润的冲击具有高度不确定性。
