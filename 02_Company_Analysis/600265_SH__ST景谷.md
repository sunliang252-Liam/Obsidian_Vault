# 600265.SH 深度透视

## 因果逻辑链
- **[房地产行业下行及区域竞争加剧]** -> [人造板产品销量与价格双降]: 下游需求萎缩，公司人造板业务收入同比下滑67.18%，毛利率由正转负至-16.19%。
- **[原控股子公司汇银木业原实控人民间借贷诉讼爆发]** -> [汇银木业停工停产、资产被保全]: 导致公司2025年8月起生产停滞，销售收入大幅下降，并计提大额资产减值。
- **[汇银木业原实控人违规挪用资金及存货]** -> [内部控制重大缺陷]: 王兰存绕开审批变卖存货约2125万元，崔会军、王兰存违规支取备用金90万元，暴露子公司管控失效。
- **[剥离汇银木业51%股权]** -> [确认大额非经常性投资损失]: 转让产生约1.21亿元营业外支出（含业绩补偿对价公允价值变动），是导致全年巨亏2.46亿元的核心原因。
- **[控股股东周大福投资无偿赠与博达数科51%股权]** -> [新增算力服务业务]: 博达数科2025年贡献营收4326.98万元、净利润1340.27万元，但该收入因属捐赠资产产生，依规被扣除，不计入主营业务收入。
- **[营收大幅下滑且净利润为负]** -> [触及退市风险警示]: 2025年净利润为负且营收低于3亿元，公司股票将被实施*ST，持续经营能力存在重大不确定性。

## 风险警告
公司当前最核心的风险是**退市风险**。2025年净利润为负且营业收入低于3亿元，股票已被实施*ST。审计报告更被出具了“持续经营重大不确定性段落”的无保留意见，表明公司能否持续经营存在重大疑问。虽然剥离了亏损的汇银木业，但核心林业业务（人造板）毛利率已为负，造血能力严重不足。

第二重风险是**新业务的不确定性**。公司寄予厚望的算力业务（博达数科）目前客户高度集中（前五大客户中太原时维科技贡献22%营收），且作为资本密集型行业，后续扩张需要持续大额资金投入。公司管理层在该领域缺乏经验，战略转型能否成功、何时能弥补主业亏损，均存在巨大不确定性。此外，公司治理层面，原子公司暴露的内控重大缺陷及原实控人的违规行为，也反映出对子公司管控的薄弱环节。
