# 605555.SH 深度透视

## 因果逻辑链
- **[美国关税政策及家电行业价格下行]** -> [毛利率大幅下滑]: 关税成本增加与价格竞争加剧，导致整体毛利率同比下降4.68个百分点，是利润承压的核心原因。
- **[海外新产能投产爬坡]** -> [摊销费用增加]: 越南、泰国新工厂处于投产初期，规模效应尚未释放，固定成本摊销侵蚀当期利润。
- **[美元汇率波动导致汇兑损失]** -> [财务费用大幅增加]: 本期汇兑损失约1,154万元，较上年同期减少约5,344万元，财务费用从-7,981万元变为-1,266万元，直接减少利润。
- **[备货规模扩大及存货跌价准备计提]** -> [资产减值损失增加]: 因销售规模增长及海外产量上升，本期计提存货跌价准备3,512万元，较上年同期增加2,421万元。
- **[汽车底盘电机业务高速增长]** -> [营收结构优化]: 汽车零部件业务营收同比增长49.51%，营收占比提升至13.7%，成为公司第二增长曲线。
- **[新增定点项目充足]** -> [未来增长确定性高]: 全年新增20个定点项目，全生命周期金额约25亿元，为未来2-3年业绩提供明确支撑。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比高达87.87%，对TTI、HOT、SharkNinja等核心客户依赖度极高，单一客户流失将造成重大冲击。

## 风险警告
公司2025年陷入典型的“增收不增利”困境：营收增长9.81%至44.97亿元，但归母净利润暴跌60.40%至1.63亿元。核心风险在于，作为ODM/OEM代工厂，公司对海外大客户议价能力薄弱，无法有效转嫁美国关税成本与原材料涨价压力，导致毛利率持续承压。同时，海外产能扩张带来的折旧摊销与存货减值，在规模效应释放前将持续拖累利润表。

更值得警惕的是，公司客户集中度极高（前五名占87.87%），且主要面向北美和欧洲市场。若中美贸易摩擦进一步升级或核心客户转移订单，公司将面临营收与利润的双重打击。此外，公司正从代工向“智能电机科技平台”转型，但新兴产业布局尚处初期，未产生收入，转型存在较大不确定性，短期难以对冲家电业务的下行风险。
