# 688169.SH 深度透视

## 因果逻辑链
- **[国补政策红利+产品矩阵扩张]** -> [营收增长56.51%]: 国内“以旧换新”政策刺激需求，叠加公司全价格段新品密集投放，推动智能扫地机及洗地机销量大幅提升。
- **[海外渠道深耕+品牌力提升]** -> [境外收入增长63.46%]: 通过精细化运营、全价格段覆盖及入驻Target/Costco等线下渠道，北美、欧洲、亚太市场渗透率持续攀升。
- **[激烈竞争下的战略性投入]** -> [净利润下降31.03%]: 为抢占市场份额，公司加大品牌营销、渠道建设及新品推广投入，销售费用增长64.95%，短期侵蚀利润。
- **[产品结构变化+成本上升]** -> [毛利率下降7.98个百分点]: 低毛利产品收入占比增加，叠加关税、运费及售后服务成本上升，导致整体毛利率承压。
- **[自营渠道扩张+备货增加]** -> [经营性现金流净额下降55.38%]: 为应对Q4大促及海外需求，公司大幅增加存货备货，导致现金流阶段性紧张。
- **[洗地机新品爆发]** -> [其他智能电器收入增长227.75%]: 蒸汽洗地机等新品凭借技术优势快速放量，国内市占率跃居行业第二，成为第二增长曲线。
- **[研发投入持续加码]** -> [技术壁垒巩固]: 研发费用增长46.13%至14.2亿元，推动机械臂、轮足机器人、割草机等前沿产品落地，强化全球领先地位。
- **[全球化产能布局]** -> [供应链韧性增强]: 新增越南、马来西亚代工厂，有效对冲关税风险，保障北美市场供应稳定性。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 营收增长56.51%的同时，净利润却下滑31.03%，毛利率骤降近8个百分点。公司正陷入“以利润换份额”的激烈价格战，销售费用增速（64.95%）远超营收增速，若竞争持续加剧，盈利能力可能进一步恶化，陷入规模越大、利润越薄的困境。

**现金流恶化与存货高企是财务健康的警报。** 经营性现金流净额同比腰斩（-55.38%），而存货激增78.19%至26.55亿元。若海外需求放缓或产品迭代导致库存贬值，将面临巨大的跌价损失和流动性压力。同时，公司资产负债率上升，并新增9亿元短期借款，财务杠杆风险抬头。
