# 002959.SZ 深度透视

## 因果逻辑链
- **国补政策推动中高端产品需求** -> 公司厨房小家电客单价增长及毛利率提升: 国补政策拉升行业均价，公司调整产品结构向中高端倾斜，导致客单价增长，毛利率提升2.51%
- **抖音等新兴渠道扩张** -> 公司线上销售保持增长，但增速低于线下: 行业渠道分化，抖音渠道增长9%，公司积极布局新兴电商，但传统电商增速放缓，线上销售增3.96%，低于线下28.70%
- **个护小家电业务爆发（罗曼智能收购）** -> 公司整体营收和利润大幅增长: 罗曼智能2025年并表，个护小家电营收增长79.22%，贡献增量营收约2.86亿元，推动整体营收增9.92%，利润增36.40%
- **海外市场拓展（自主品牌+ODM）** -> 国外销售和线下销售高速增长: 公司推进自主品牌出海和ODM业务，并设立海外大客户体系，导致国外销售增42.37%，线下销售增28.70%
- **原材料成本控制及规模化生产** -> 营业成本增速低于营收增速，毛利率提升: 公司通过自制核心零部件、供应链优化，使营业成本仅增7.58%，低于营收增速9.92%，毛利率提升1.38%
- **研发投入持续增长（+8.77%）** -> 产品创新与品类拓展，支撑母婴、个护等业务增长: 公司加大研发投入，推出多款新品（如无刷电吹风、智能调奶器），提升产品竞争力，带动母婴业务增12.91%，个护业务增79.22%
- **2024年火灾赔偿及侵权赔偿等营业外收入** -> 利润总额额外增加: 公司收到侵权赔偿金及湖南中仓供应链赔偿，营业外收入2108万元，占利润总额4.15%，非经常性损益增厚利润

## 风险警告
深度风险总结：公司业绩增长主要依赖罗曼智能并表及国补政策刺激，但政策效应减弱后市场可能回归调整。个护小家电高增长持续性存疑，海外业务受关税影响存在不确定性。线上渠道增速放缓，竞争加剧。存货虽下降但应收账款大增，现金流改善主因理财减少，需关注营运效率。
