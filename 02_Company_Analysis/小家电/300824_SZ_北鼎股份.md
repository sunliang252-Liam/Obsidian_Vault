## 因果逻辑链
- **[以旧换新政策红利]** -> [北鼎中国业务收入同比增长37.76%]: 国家将厨房小家电纳入补贴范围，直接刺激了公司核心品类（蒸炖锅+35.30%、多功能锅炉+134.76%）的销售放量。
- **[自主品牌业务高增长]** -> [整体营收增长26.13%，净利润增长63.35%]: 自主品牌营收占比提升至81.92%，且毛利率高达56.55%，其强劲增长是利润弹性远超收入的核心原因。

- **[海外业务战略收缩]** -> [海外自主品牌收入同比下降8.23%，但盈利能力改善]: 公司主动采取更审慎的海外经营策略，牺牲部分收入规模以换取利润质量，体现了战略聚焦。
- **[收购中山晶辉翰林]** -> [固定资产与无形资产大幅增加]: 以1.56亿元收购，获得厂房与土地使用权，为未来产能扩张和制造能力升级奠定基础。
- **[销售费用率提升]** -> [销售费用同比增长31.43%]: 为配合以旧换新政策及渠道扩张，公司加大推广力度，销售费用增速略高于营收增速，是利润释放的制约因素。
- **[产品结构优化]** -> [整体毛利率提升3.13个百分点至50.03%]: 高毛利的自主品牌业务占比提升，以及电器类产品毛利率改善（+4.72个百分点），共同驱动综合毛利率上行。

## 风险警告
**海外市场与贸易环境风险。** 公司海外自主品牌业务已因审慎策略而收缩，但全球贸易格局不确定性（关税壁垒、地缘政治）持续演化，OEM/ODM业务也面临客户需求波动风险。若海外市场进一步恶化，将拖累公司整体增长，并可能引发汇率波动损失（报告期已确认汇兑损失299万元）。

**品牌溢价与市场竞争的平衡风险。** 公司依赖“北鼎”品牌的高端定位和溢价能力。若未来消费降级趋势加剧，或竞争对手推出高性价比替代品，可能导致公司品牌吸引力下降，被迫加大促销力度，侵蚀毛利率。当前销售费用率已处于高位，进一步压缩的空间有限。
