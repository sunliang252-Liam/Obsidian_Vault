# 002240.SZ 深度透视

## 因果逻辑链
- **[锂盐价格先抑后扬，全年均价同比下跌]** -> [全年净利润亏损8.88亿元]: 2025年电池级碳酸锂均价7.55万元/吨，同比下降16.54%，上半年持续低价对全年业绩形成巨大压力，尽管下半年价格反弹，但未能扭转全年亏损局面。
- **[印尼盛拓6万吨锂盐项目产能爬坡并批量供货]** -> [锂产品销量同比增长9.75%]: 印尼项目作为海外最大矿石提锂项目，于2025年8月开始批量供货，推动全年锂产品销量达7.28万吨，但产能释放初期成本较高，对利润贡献有限。
- **[木绒锂矿大规模建设即将启动]** -> [公司未来锂资源自给率将大幅提升]: 木绒锂矿Li₂O资源量98.96万吨，平均品位1.62%，设计产能300万吨/年，建成后预计生产成本处于行业较低水平，是公司穿越周期、抵御地缘政治风险的核心资产。
- **[套期保值业务产生大额亏损]** -> [非经常性损益拖累业绩]: 报告期内商品期货和外汇套期保值合计产生实际亏损约1.39亿元，叠加公允价值变动损失，加剧了公司净利润的下滑。
- **[财务费用同比翻倍增长]** -> [侵蚀公司利润]: 财务费用从2.03亿元增至4.10亿元，增幅102.05%，主要系汇率变动产生汇兑损失增加，反映出海外业务扩张带来的财务风险。
- **[收购启成矿业及惠绒矿业股权]** -> [强化上游锂资源控制]: 公司通过收购实现对木绒锂矿100%控股，并间接控制惠绒矿业，大幅增强了国内锂矿资源保障，降低对海外矿源的依赖。
- **[与比亚迪、中创新航等签订长协]** -> [锁定未来5年销量，保障产能消化]: 公司与华友控股、中创新航分别签署2026-2030年锂盐产品合作框架协议，合计采购量超42万吨，为印尼及国内新增产能提供了稳定的销售渠道。

## 风险警告
**核心风险：锂盐价格剧烈波动与巨额资本开支带来的现金流压力。** 公司2025年亏损8.88亿元，主因是锂盐价格低迷。尽管公司通过长协锁定了部分销量，但锂盐价格受供需、政策、地缘政治等多重因素影响，波动性极高。若未来价格再次下行，公司将继续面临巨额亏损。同时，木绒锂矿（300万吨/年）及金属锂项目（2,500吨/年）等大规模资本开支即将启动，公司资产负债率已较高（约54%），且经营活动现金流净额同比下降27.86%，未来可能面临融资成本上升或资金链紧张的风险。

**次要风险：海外运营与地缘政治不确定性。** 公司核心增量产能印尼盛拓位于海外，尽管当前具备技术出口限制下的竞争优势，但面临印尼政策变化、汇率波动、当地社区关系等运营风险。此外，津巴布韦萨比星矿山虽已投产，但非洲地缘政治风险、资源民族主义抬头等因素可能影响矿山的稳定运营和利润汇回。公司外汇套期保值业务已产生大额亏损，表明其对冲海外风险的能力尚需加强。
