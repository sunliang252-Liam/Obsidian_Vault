# 300618.SZ 深度透视

## 因果逻辑链
- **[铜价上涨+铜产能释放]** -> **营收增长12.52%**: 电积铜量价齐升，贡献营收42.7亿元，同比增长26.61%，成为收入增长的核心引擎。
- **[刚果(金)钴出口配额制]** -> **钴供给收缩，价格上行**: 全球钴供应从宽松转向紧平衡，驱动钴价上涨，公司钴产品毛利率同比提升0.53%。
- **[印尼高冰镍项目大规模投入]** -> **投资活动现金流大幅净流出**: 项目持续推进，导致投资活动现金净流出16.6亿元，同比扩大310.78%。
- **[铜钴价格上涨及镍原料储备]** -> **经营活动现金流净额为负**: 采购支出和库存大幅增加，导致经营活动现金流净额为-4.6亿元，与净利润严重背离。
- **[铜钴价格上涨]** -> **存货价值回升**: 资产减值损失为-7228万元（负值表示收益），主要系存货价值回升所致。
- **[电积铜产销量增长，刚果(金)柴油发电比重上升]** -> **能源成本占比提升**: 能源成本占营业成本比重同比上升1.96%，侵蚀部分毛利。
- **[刚果(金)钴出口配额制]** -> **钴新材料项目产能未充分释放**: 原料进口受阻，导致“10000吨/年金属量钴新材料项目”未达预期效益。

## 风险警告
**核心风险在于“增收不增利”与现金流严重恶化。** 公司营收增长12.52%，但经营活动现金流净额由正转负，大幅流出4.6亿元，与净利润严重背离。这并非短期波动，而是由铜钴价格上涨导致的存货和采购支出激增所致，若价格回调，将面临巨大的存货减值风险。同时，印尼高冰镍项目尚处建设期，投资活动现金净流出16.6亿元，公司通过大量增加银行贷款（短期借款增长227%）来弥补资金缺口，财务杠杆急剧攀升。

**地缘政治与资源依赖是另一大隐患。** 公司核心原料高度依赖刚果（金）和印尼，刚果（金）的出口配额、印尼的关税与出口禁令等政策变动，可直接切断原料供应或大幅增加成本。此外，公司钴粉全球市占率前三，但下游需求结构单一，高度依赖消费电子和动力电池，若新能源行业增速放缓或技术路线变更（如无钴电池），将对公司主业造成颠覆性冲击。
