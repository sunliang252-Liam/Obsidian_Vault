# 000762.SZ 深度透视

## 因果逻辑链
- **[锂产品价格与销量双降]** -> [营收与利润大幅下滑]: 2025年锂行业经历“V型”反转，上半年价格承压，公司锂精矿销量同比降81.58%，售价同步下跌，导致采掘业收入同比降54.26%。
- **[扎布耶二期项目投产转固]** -> [折旧与运营成本激增]: 万吨电池级碳酸锂项目于2025年10月投产，固定资产从3.87亿暴增至24.76亿，折旧及摊销费用大幅增加，叠加新项目产能爬坡，导致制造业板块毛利率为负。
- **[铬铁矿销量与价格下滑]** -> [传统主业承压]: 铬铁矿销量同比降17.45%，叠加成本刚性（折旧、人工），毛利率从63.52%降至40.52%，拖累整体盈利。
- **[投资收益与公允价值变动]** -> [非经常性损益支撑利润]: 公司通过华宝信托理财获得投资收益2971万元，但公允价值变动损失53万元，资产减值损失3676万元，扣非后净亏损5991万元。
- **[西藏扎布耶子公司亏损]** -> [合并报表归母净利润转负]: 核心子公司西藏扎布耶因锂产品量价齐跌及新项目爬坡成本，净利润亏损5692万元，同比降468.33%，是公司亏损主因。
- **[经营活动现金流净额下降]** -> [回款能力减弱]: 销售商品收到的现金同比降39.6%，但经营性现金流仍为正（1.57亿），主要系非付现折旧摊销及存货销售回笼资金。
- **[研发投入极低且无专职人员]** -> [技术迭代风险高]: 研发费用仅96万元，占营收0.27%，且无专职研发人员，依赖外部资源，在盐湖提锂技术快速迭代背景下，存在工艺落后风险。

## 风险警告
**核心风险在于新项目“三达”不及预期与锂价持续低迷的双重打击。** 扎布耶二期虽已投产，但2025年仍处于产能爬坡阶段，未能贡献利润，反而因巨额折旧导致制造业板块亏损。若2026年无法实现“达产、达标、达效”，公司将持续面临成本吞噬利润的局面。同时，锂行业供需格局尚未根本逆转，若碳酸锂价格再次下行，公司锂业务将面临严重亏损。

**资源禀赋与运营环境恶化构成另一重大风险。** 罗布莎铬矿面临资源品位下降、南部矿区改扩建工程因水文地质问题进度滞后，2026年铬铁矿产能可能出现下降。西藏地区高海拔、物流困难、环保政策趋严等客观条件，持续推高项目建设和运营成本，公司对气候和自然条件的依赖度极高（如锂精矿太阳池工艺），抗风险能力脆弱。

> 西藏矿业发展股份有限公司是经西藏自治区人民政府于1997年4月10日以藏政涵【1997】23号文批准设立的股份有限公司,在深交所成功挂牌上市,成为西藏第五家上市公司。公司经营范围包括铬矿、铜矿、路矿开采、深加工。主要产品为铬铁矿石、铬铁合金、铜、铬盐产品以及锂盐产品,主要应用于特种钢材、铜制品和金属锂的加工。1984年,由于东风矿的开采已近尾声,经原冶金部和西藏自治区人民政府批准,东风矿原班人马转战西藏山南地区曲松县境内的罗布莎乡,开始了罗布莎矿的基建和开采工作。1997年4月10日经西藏自治区人民政府批准,西藏矿业发展股份有限公司在深交所成功挂牌上市,成为西藏第五家上市公司公司主要从事铬铁矿、锂矿开采及销售。
