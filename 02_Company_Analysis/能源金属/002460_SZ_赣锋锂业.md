# 002460.SZ 深度透视

## 因果逻辑链
- **[锂价触底反弹]** -> [净利润扭亏为盈]: 2025年锂价先抑后扬，下半年强势反弹超60%，公司作为锂化合物龙头，直接受益于价格回升，归母净利润从-20.74亿大幅转正至16.13亿。
- **[储能需求爆发]** -> [锂电池业务收入高增]: 储能电池出货量超预期增长，成为全年最大需求亮点，带动公司锂电池系列产品收入同比大增39.63%，占总营收比例提升至35.67%。
- **[低成本资源项目投产]** -> [成本结构优化]: 马里Goulamina锂辉石矿、阿根廷Mariana盐湖等低成本项目陆续投产，提升资源自给率，构建穿越行业周期的核心成本优势。
- **[非经常性损益贡献]** -> [归母净利润大幅高于扣非净利润]: 处置深圳易储部分股权产生投资收益13.52亿元，叠加持有PLS股价上涨带来的公允价值变动收益，合计非经常性损益19.98亿元，是扭亏的关键。
- **[垂直整合业务模式]** -> [抗周期能力增强]: 业务贯穿上中下游，锂盐、锂电池、回收板块协同，在锂价低迷时，锂电池业务增长部分对冲了锂盐利润下滑，增强了整体经营的稳定性。
- **[全球资源布局]** -> [供应链韧性提升]: 在澳洲、南美、非洲、中国等地掌控多类型锂资源，多元化供应体系保障了原材料稳定，降低了单一来源风险，支撑产能扩张。
- **[固态电池技术领先]** -> [抢占下一代技术制高点]: 400Wh/kg电池循环寿命突破1100次，500Wh/kg级产品小批量量产，并与eVTOL企业合作完成载人试飞，技术储备行业顶尖，为未来增长蓄力。

## 风险警告
**核心风险在于锂价的高度波动性。** 公司2025年扭亏高度依赖下半年锂价强势反弹，但扣非净利润仍为-3.85亿元，表明主营业务的盈利能力尚未根本性修复。若未来锂供给持续过剩（2026年预计增长27%），锂价再次承压，公司将面临业绩大幅波动的风险。公司虽通过套期保值对冲，但无法完全消除价格风险。

**海外运营与资源开发的不确定性是另一大隐患。** 公司大量资产和利润来源位于阿根廷、马里、墨西哥等政治经济环境复杂的国家，面临资源民族主义、政策变动、社区关系及地缘政治等风险。例如，马里项目虽已投产，但当地政策环境变化可能影响项目收益；阿根廷盐湖项目开发进度缓慢，成本超支风险犹存。这些海外资产的减值风险不可忽视。
