# 300767.SZ 深度透视

## 因果逻辑链
- **[《建设工程抗震管理条例》强制政策]** -> [市场扩容但竞争加剧]: 政策驱动学校、医院等公建强制采用减隔震技术，但大量新进入者导致价格战和毛利率承压。
- **[主动收紧信用与收款政策]** -> [营收增长但放弃部分项目]: 为改善现金流和风控，放弃需大额垫付或资金状况差的项目，导致收入增速低于行业整体扩容速度。
- **[计提约1.1亿元信用及资产减值损失]** -> [净利润持续亏损]: 尽管营收增长27.32%，但巨额减值吞噬利润，导致归母净利润-1.17亿元，连续第三年亏损。
- **[震振控制与核电抗震产品放量]** -> [收入结构优化与毛利率提升]: 震振控制产品收入同比+559.87%，核电抗震产品+49.12%，高毛利产品占比提升，拉动整体毛利率结构改善。
- **[经营性现金流大幅改善]** -> [财务稳健性增强]: 经营活动现金流净额同比+106.88%至1.99亿元，主要得益于销售回款加强和应收账款催收成效。
- **[控制权变更至宁花香、周建旗夫妇]** -> [战略转向“算力+减隔震”双轮驱动]: 新实控人计划将算力侧高端制造及配套产业作为第二增长曲线，并推动与现有减隔震业务在数据中心等场景的协同。
- **[原材料成本占比高且价格波动]** -> [成本控制压力持续]: 钢材、橡胶等大宗商品占营业成本45%-55%，价格波动直接压缩利润空间，公司通过锁价长单和技术降本应对。

## 风险警告
震安科技的核心风险在于**政策落地节奏与市场竞争的双重挤压**。《建设工程抗震管理条例》虽为行业提供了长期增长逻辑，但地方配套细则落地缓慢，叠加宏观经济下行导致基建投资放缓，传统减隔震市场需求释放不及预期。同时，行业门槛较低导致竞争白热化，产品价格承压，公司主动放弃低毛利项目虽改善了现金流，但也限制了营收弹性。连续三年亏损且计提大额减值，反映出下游客户资金链紧张和公司资产质量的压力。

另一重大风险是**新业务转型的不确定性**。公司控制权变更后，计划切入算力侧高端制造，这与其传统减隔震主业跨度极大。新实控人虽在通信设备领域有资源，但上市公司缺乏相关技术、人才和客户积累，第二增长曲线的落地时间、投入规模及盈利能力均存在高度不确定性。若转型不及预期，可能分散主业资源，加剧经营波动。
