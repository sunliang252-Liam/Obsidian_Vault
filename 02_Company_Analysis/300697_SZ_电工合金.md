# 300697.SZ 深度透视

## 因果逻辑链
- **国家持续加大铁路投资，高铁建设提速** -> 铁路接触网系列产品营收增长33.29%: 下游需求扩张驱动销量增长
- **新能源汽车行业高速发展，渗透率提升至47.9%** -> 新能源汽车高压连接件营收增长143.93%: 下游需求爆发式增长，公司凭借铜加工优势切入该赛道
- **新型电力系统建设提速，数据中心算力爆发** -> 铜母线及铜制零部件营收增长18.70%: 下游需求增长驱动产品销量提升
- **原材料电解铜成本占比超90%，价格波动风险** -> 公司采用套期保值模式锁定原材料成本: 为降低原材料价格波动对利润的影响，公司通过期货套保对冲风险
- **铜母线及接触网市场竞争激烈，进入壁垒高** -> 公司凭借资质优势和技术积累保持行业龙头地位: 铁路产品资质认证周期长、要求高，形成护城河

## 风险警告
原材料电解铜价格大幅波动可能影响毛利率；新能源汽车高压连接件业务处于快速增长期，若下游需求不及预期或竞争加剧，可能导致营收增速放缓；海外墨西哥基地建设存在地缘政治及经营风险；可转债发行存在审批不确定性。
