# 603966.SH 深度透视

## 因果逻辑链
- **[下游高景气赛道共振]** -> [营收与利润双创新高]: 船舶、能源、水利等下游行业投资高增，带动公司物料搬运设备需求旺盛，新签订单突破30亿元。
- **[全球化布局深化]** -> [海外业务成为新增长极]: 在欧洲、东南亚等关键区域设立超10家海外子公司，凭借高性价比方案切入全球市场，海外订单持续释放。
- **[智能制造与自动化升级]** -> [高端产品需求提速]: 下游头部企业“智改数转”加速，智能起重机、桁架式空中搬运机器人等高端装备需求快速增长，推动产品结构优化。
- **[全产业链与全生命周期服务]** -> [构建差异化竞争壁垒]: 从核心零部件到成套设备再到运维服务，形成完整产业链，提升客户粘性与后市场增长潜力。
- **[聚焦头部客户与多行业分散]** -> [平滑单一行业周期波动]: 覆盖30多个细分行业，聚焦各行业头部企业，有效抵御下游个别行业投资波动，经营韧性显著。
- **[可转债转股完成]** -> [财务费用大幅下降]: 可转债于2025年6月摘牌，利息支出减少，叠加汇兑收益增加，财务费用同比转负，直接增厚利润。
- **[管理改善与订单增长]** -> [经营性现金流大幅改善]: 主业增长叠加供应链管理优化，经营活动现金流净额同比大增137%，盈利质量扎实。

## 风险警告
**核心风险在于控制权变更带来的战略不确定性。** 报告期末，公司实际控制人陶峰华、金红萍夫妇已与无锡新投启航签署协议，拟转让控制权，无锡市新吴区人民政府将成为新实控人。这一重大变化可能导致公司既定的全球化、自动化战略在执行层面出现调整或延迟，管理层稳定性与经营连续性面临考验。

**海外业务毛利率下滑与地缘政治风险不容忽视。** 尽管海外营收增长，但毛利率同比下降5.26个百分点，显示海外市场竞争加剧或成本压力上升。同时，公司全球化布局深入，面临国际局势变化、汇率波动及贸易政策不确定性，可能对海外业务拓展与盈利水平造成冲击。此外，在手订单突破30亿元，对产能和交付能力构成挑战，若交付不及预期，可能影响客户满意度与品牌声誉。
