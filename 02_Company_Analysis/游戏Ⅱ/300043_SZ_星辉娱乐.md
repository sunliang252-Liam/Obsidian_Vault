# 300043.SZ 深度透视

## 因果逻辑链
- **[剥离亏损足球俱乐部]** -> [净利润扭亏为盈]: 出售西班牙人俱乐部99.66%股权，消除其业绩波动对整体盈利的拖累，并确认约4707万元投资收益。
- **[新游戏集中上线]** -> [游戏收入同比+93.16%]: 《冒险岛 R：进化》《仙境传说：破晓》《三国群英传：策定九州》等新品在境内外上线，带动游戏业务收入从4.72亿跃升至9.11亿。
- **[游戏推广投入激增]** -> [销售费用同比+120.94%]: 为支撑新游戏大规模获客，销售费用从2.64亿飙升至5.83亿，侵蚀了部分利润弹性。
- **[偿还借款与优化债务结构]** -> [资产负债率降至37.28%]: 带息债务从14.82亿大幅压缩至7.49亿，财务费用由正转负（汇兑收益），财务状况显著改善。
- **[聚焦“玩具+游戏”双主业]** -> [资源集中与战略清晰]: 剥离非核心体育资产后，公司明确将资源投向AI玩具、AI游戏、海外发行等高潜力赛道，提升核心竞争力。
- **[IP矩阵与全球化发行]** -> [游戏海外收入同比+94.10%]: 依托《三国群英传》《仙境传说》等IP，在日韩、东南亚等地区成功发行，海外游戏收入达3.79亿。
- **[玩具业务结构升级]** -> [净利润稳定增长]: 尽管玩具收入微降3.06%，但通过推出F1等高端授权车模、优化渠道，净利润仍实现1.23%的正增长，体现产品附加值提升。

## 风险警告
公司当前业绩高度依赖新游戏的生命周期与流水表现。2025年游戏收入爆发式增长主要系多款新品集中上线，但游戏行业竞争激烈、玩家口味变化快，后续能否持续推出爆款并延长现有产品生命周期存在较大不确定性。同时，销售费用率已攀升至27.9%，若推广效率下降，将直接侵蚀利润。

玩具业务面临外部贸易环境恶化的风险。2025年中国玩具出口总额同比下滑12.7%，公司玩具境外收入占比超80%，若主要市场（如美国）加征关税或贸易壁垒升级，将直接冲击公司出口业务与成本。尽管公司通过产品升级和IP授权提升附加值，但短期难以完全对冲系统性风险。
