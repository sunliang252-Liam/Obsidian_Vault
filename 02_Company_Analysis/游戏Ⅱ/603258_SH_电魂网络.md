# 603258.SH 深度透视

## 因果逻辑链
- **[核心老游戏《梦三国2》进入生命周期衰退期]** -> [营收下降30%，净利润由盈转亏]: 公司超60%收入依赖运营超15年的《梦三国2》端游，该游戏用户付费进入下降周期，导致整体营收大幅下滑，并因收入无法覆盖固定成本而陷入亏损。
- **[子公司游动网络业绩不达预期]** -> [计提大额商誉减值1.77亿元]: 收购的游动网络因产品市场表现不佳，导致商誉减值测试失败，公司一次性计提巨额减值，成为当期亏损的最大来源。
- **[新游戏研发投入高但回报不确定]** -> [研发费用率高达26.28%，但新品未能接棒]: 公司持续高研发投入（1.01亿元）开发《修仙时代》等新品，但报告期内无重磅新品成功上线并贡献利润，研发投入未能转化为有效收入。
- **[游戏行业“马太效应”加剧]** -> [公司市场份额被挤压]: 头部游戏公司凭借资本和流量优势垄断市场，公司在买量成本高企和用户获取困难的双重压力下，老游戏流水下滑，新游戏推广效果不佳。
- **[海外市场拓展乏力]** -> [境外收入同比大幅下降46.73%]: 报告期内无新游戏在海外上线，导致境外收入锐减，全球化战略推进受阻。
- **[财务费用因利息收入减少而大幅增加]** -> [侵蚀利润]: 公司定期存款到期减少导致利息收入下降，财务费用由负转正，进一步加剧了利润端的压力。

## 风险警告
**核心风险：单款游戏依赖与产品青黄不接。** 公司命脉系于运营超15年的《梦三国2》端游，其收入占比超60%。该游戏已无可避免地进入用户与付费下降周期，而公司寄予厚望的《修仙时代》等新品尚在研发，短期内无法贡献业绩。这种“老产品衰退、新产品断档”的困境，是公司业绩持续恶化的根本原因。

**财务风险：商誉减值与资产减值风险高企。** 报告期内，公司因收购游动网络形成的商誉几乎全额计提减值（从1.57亿降至16万），同时长期股权投资也计提了大额减值。这表明公司过往的并购整合效果极差，账面资产质量堪忧。未来若其他投资标的业绩持续不达预期，公司仍面临进一步的减值风险，对利润表造成持续冲击。
