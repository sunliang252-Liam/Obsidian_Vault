# 300533.SZ 深度透视

## 因果逻辑链
- **[销售费用大幅缩减]** -> [净利润扭亏为盈]: 2025年销售费用同比减少36.88%（约8.49亿元），远大于营收8.40%的降幅，是利润从-2.47亿跃升至4.83亿的核心驱动力。
- **[成熟产品流水自然回落]** -> [营收同比下降8.40%]: 核心产品《超能世界》《Hero Clash》等进入生命周期后期，充值流水下滑，新游戏收入增量无法完全对冲。
- **[新产品《X-Clash》全球首发]** -> [Q4销售费用环比增加]: 2025年10月SLG新品《X-Clash》在海外多国同步上线，导致第四季度推广投入显著回升。
- **[降本增效措施落地]** -> [管理费用同比下降23.44%]: 公司推行人员优化等成本控制措施，管理费用从1.37亿降至1.05亿。
- **[海外收入占比过半]** -> [境外销售毛利率高达95.36%]: 境外销售毛利率显著高于境内（90.86%），且境外收入占比达53.59%，是公司高毛利的重要支撑。
- **[买量模式依赖]** -> [经营现金流大幅改善]: 因减少买量投放，支付的信息服务费减少，经营活动现金流净额从-1.59亿转为6.75亿，但该改善可持续性存疑。
- **[SLG品类战略深耕]** -> [未来业绩增长点]: 公司明确将SLG作为重点突破品类，已储备《代号：灯塔》《代号：SC》等多款测试中产品，但商业化前景尚不确定。

## 风险警告
**买量模式依赖与产品生命周期错配风险。** 公司2025年利润暴增的核心是主动收缩买量规模，而非产品竞争力质的飞跃。一旦停止或减少买量，成熟产品流水将加速下滑。而新游戏《X-Clash》等SLG产品在Q4已开始大规模推广，若其回收效率不及预期，公司将面临“老产品下滑、新产品烧钱”的双重压力，利润可能再次剧烈波动。

**新产品开发与适销性风险。** 公司储备的多款SLG及休闲游戏尚处于测试或立项阶段，距离商业化仍有距离。游戏行业头部效应显著，腾讯、网易、米哈游等占据大部分市场份额。公司作为中小厂商，在玩法创新、用户获取成本、IP储备等方面均不占优，新产品失败概率较高，研发投入可能无法收回。
