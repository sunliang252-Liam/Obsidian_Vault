# 300467.SZ 深度透视

## 因果逻辑链
- **[B2C业务收入下滑]** -> [总营收下降3.53%]: 网络加速市场饱和与竞争加剧，导致直接面向消费者的业务收入同比减少8.30%。
- **[联营企业投资项目退出收益]** -> [归母净利润增长24.58%]: 非经常性损益（公允价值变动及处置收益）是利润增长的主要来源，掩盖了主营业务的疲软。
- **[带宽及托管费成本下降]** -> [互联网加速服务毛利率提升6.13%]: 通过优化成本结构，在收入下滑的同时实现了毛利率的改善。
- **[B2B业务收入增长18.03%]** -> [部分对冲B2C下滑]: 企业级/工业智能网络加速服务拓展顺利，成为新的收入增长点，但毛利率同比下降13.47%。
- **[移动互联网广告业务营收下降18%]** -> [拖累整体业绩]: 用户规模结构性变化及监管趋严导致广告收入短期承压，成本却因带宽及托管费增加而上升，毛利率大幅下滑21.64%。
- **[经营活动现金流净额转正]** -> [改善财务状况]: 通过控制成本费用，经营活动现金流从-1197.52万元大幅改善至943.63万元，增强了运营安全性。

## 风险警告
公司核心的B2C网游加速业务已进入存量博弈阶段，收入持续下滑，增长高度依赖非经常性损益（如投资退出收益），盈利质量堪忧。同时，移动互联网广告业务在监管和竞争双重压力下，毛利率大幅恶化，第二增长曲线尚未稳固。公司无实际控制人，股权结构分散，存在决策效率低下及被恶意并购的风险，治理结构稳定性存疑。

母公司累计未弥补亏损高达19.12亿元，导致公司不具备分红条件，股东回报前景黯淡。此外，公司对第一大客户（支付通道）依赖度极高（销售额占比51.81%），若合作关系变动将对收入产生重大冲击。
