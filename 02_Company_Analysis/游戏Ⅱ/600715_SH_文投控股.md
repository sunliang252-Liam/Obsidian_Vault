# 600715.SH 深度透视

## 因果逻辑链
- **[司法重整完成]** -> [资产负债结构显著优化]: 公司通过重整化解历史债务、剥离低效资产，财务费用从1.41亿降至63.6万，实现“轻装上阵”。
- **[影城门店数量减少]** -> [影院收入下滑但利润大幅减亏]: 在营影城从34家减至23家，收入下降11.89%，但通过精细化管理和“一店一策”策略，成本控制有效，利润同比大幅改善。
- **[存量游戏生命周期衰退]** -> [游戏业务收入与利润双降]: 《攻城三国》《攻城天下》等核心产品流水自然下滑，新游戏研发投入增加但尚未商业化，导致游戏板块阶段性承压。
- **[漫剧业务从0到1突破]** -> [开辟新增长曲线]: 公司利用AIGC工具和传统剧集经验，快速切入漫剧赛道，已投资立项近30部项目，首部作品GMV近400万元，但尚未形成规模化收入。
- **[涉诉导致货币资金冻结]** -> [经营活动现金流大幅转负]: 因诉讼导致2.04亿元货币资金被冻结，经营活动现金流净额从+1184万骤降至-1.6亿，严重制约日常运营。
- **[控股股东变更为首文科集团]** -> [获得首都文化科技产业资源支持]: 首文科集团作为北京市属文化科技平台，承诺在五年内解决同业竞争问题，为公司提供资本、IP与场景整合的潜在优势。
- **[“电影+”创新业态落地]** -> [提升非票收入与空间复用效率]: 推出“耀乐派”娃娃屋、MIRRA奇镜派对融合厅等新业态，探索“影、游、演、餐”融合模式，提高影院非高峰时段收入。

## 风险警告
**流动性冻结与经营现金流危机**：公司因涉诉导致2.04亿元货币资金被冻结，占货币资金总额的23.2%，直接导致经营活动现金流净额由正转负，骤降至-1.6亿元。这是当前最紧迫的风险，若冻结长期持续，将严重威胁公司日常运营、新店拓展及新游戏研发投入，甚至可能引发新的债务违约。

**新旧业务青黄不接，盈利拐点不确定**：公司虽通过重整大幅减亏，但核心主业仍在收缩。影城门店数量减少，存量游戏进入生命周期末期，而漫剧、VR影厅等创新业务尚处投入期，未形成规模化收入。在“老业务下滑、新业务未起”的真空期，公司能否在2026年实现扭亏为盈，高度依赖新游戏上线表现和漫剧项目的市场反响，存在较大不确定性。

**同业竞争解决与资产整合的长期博弈**：控股股东首文科集团承诺五年内解决与北京演艺集团在电影业务上的同业竞争问题，但具体方案（资产注入、业务调整等）尚未明确。同时，公司计划通过外延并购打造新增长引擎，但项目挖掘、交易谈判及整合落地均存在不确定性。若整合不及预期或方案损害中小股东利益，可能引发市场信心波动。
