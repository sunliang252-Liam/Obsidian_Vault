# 002029.SZ 深度透视

## 因果逻辑链
- **[金融资产投资]** -> [净利润增长16.91%]: 公允价值变动损益及投资收益3.74亿元，是净利润3.33亿元的核心来源，掩盖了主业亏损。
- **[服装主业收入下滑]** -> [扣非净利润暴跌86.91%]: 营业收入下降4.35%至30.04亿元，导致扣非净利润仅961.5万元，主业盈利能力极度脆弱。
- **[Karl Lagerfeld品牌亏损]** -> [拖累整体业绩]: 子公司Karl Lagerfeld净利润-6649万元，主要因计提无形资产减值8279万元，轻奢品牌整合持续承压。
- **[存货与资产减值]** -> [侵蚀利润]: 资产减值损失高达3.00亿元（主要为存货跌价及无形资产减值），是导致扣非净利润微薄的关键因素。
- **[供应链协同研发]** -> [研发费用下降44.95%]: 将研发活动前置至供应链合作伙伴，内部研发投入从5888万降至3241万，短期节省成本，但长期创新风险需关注。
- **[渠道结构优化]** -> [直营店效提升]: 直营老店平均营收同比上升1.61%，但加盟销售下滑22.26%，显示公司正从加盟扩张转向直营精细化运营。
- **[现金流改善]** -> [经营质量提升]: 经营活动现金流净额3.94亿元，同比增长60.42%，主因支付采购款减少，现金流质量优于利润表表现。

## 风险警告
**主业空心化与利润依赖金融投资的风险**：公司2025年扣非净利润仅961.5万元，而金融资产（股票、理财等）贡献了3.74亿元的非经常性损益。这意味着公司核心服装业务已接近盈亏平衡点，利润完全依赖资本市场波动。一旦市场下行，公允价值变动将直接导致净利润大幅缩水，投资者需警惕“伪增长”陷阱。

**Karl Lagerfeld品牌持续失血与减值风险**：该轻奢品牌子公司净资产为-1.60亿元，已资不抵债，2025年再次计提无形资产减值8279万元。尽管公司声称“优化调整”，但该品牌已连续多年亏损且未见扭亏拐点，存在进一步减值甚至拖累合并报表的风险。
