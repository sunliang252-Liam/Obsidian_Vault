- **[新能源汽车齿轮业务高速增长]** -> [营收与利润双增]: 新能源汽车齿轮业务营收同比增长21.72%，占公司总营收比重达45.02%，成为第一大业务板块，驱动整体营收增长3.77%，净利润增长23.21%。
- **[电驱动技术升级与主机厂外包趋势]** -> [第三方齿轮厂商机遇]: 电驱动系统对齿轮精度、降噪要求大幅提升，主机厂聚焦核心研发，齿轮外包需求显著增加，双环传动凭借高精密制造能力抢占先机。
- **[海外市场拓展成效显著]** -> [外销收入大幅增长]: 匈牙利基地建设与运营提升国际认可度，海外平台项目出货量同比大幅增长，外销收入同比增长58.88%，有效对冲国内短期波动。
- **[智能执行机构业务多元化渗透]** -> [新增长极形成]: 在eBike、扫地机、智能汽车等领域实现业务突破，营收同比增长24.17%，成为推动业绩增长的核心力量之一。
- **[机器人减速器技术领先]** -> [巩固高端市场地位]: 控股子公司环动科技入选国家专精特新重点“小巨人”企业，RV减速器国产化率稳步提升，国内市场占有率连续多年位居行业前列。
- **[运营效能提升与成本管控]** -> [毛利率改善]: 精益化管理、供应链整合及智能技术应用落地，推动综合毛利率同比提升2.33个百分点，盈利能力增强。
- **[经营活动现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流量净额同比增长42.23%，达23.91亿元，显著高于净利润，体现强劲的现金创造能力。

## 风险警告
**地缘政治与贸易壁垒风险**：公司海外业务占比已提升至22.77%，且正加速在匈牙利、越南等地建设产能。然而，全球汽车贸易保护主义持续升温，部分国家可能设置贸易壁垒或限制中国零部件进口，这将增加公司产品进入当地市场的成本，削弱价格竞争力，甚至导致海外订单流失。匈牙利基地的产能爬坡与本土化供应链建设若不及预期，也将影响海外市场拓展节奏。

**汽车行业周期与原材料价格波动风险**：公司约65%营收来自乘用车齿轮，与汽车行业景气度高度相关。若宏观经济下行或消费者偏好变化导致汽车销量下滑，将直接减少齿轮订单，造成库存积压。同时，钢材等主要原材料价格波动会直接影响毛利率，尽管公司有价格联动协议，但传导存在时滞，若原材料价格持续上涨，将压缩利润空间。
