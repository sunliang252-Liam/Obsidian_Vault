# 688036.SH 深度透视

## 因果逻辑链
- **[存储等元器件价格上涨]** -> [毛利率下降]: 核心元器件成本上升，但产品售价未能同步传导，导致手机业务毛利率下降2.19个百分点。
- **[市场竞争加剧]** -> [营收下滑]: 新兴市场手机竞争白热化，公司手机出货量同比下降16.09%，导致整体营收下降4.55%。
- **[持续加大研发与销售投入]** -> [利润大幅下滑]: 为维持产品竞争力，研发费用增长17.23%，销售费用增长7.61%，在营收下滑背景下严重侵蚀利润。
- **[非洲市场营收增长]** -> [部分对冲整体下滑]: 非洲市场营收同比增长9.90%，成为公司业绩的“压舱石”，但无法完全弥补亚洲等其他地区11.58%的下滑。
- **[扩品类业务高速增长]** -> [收入结构优化]: 数码配件、家电等扩品类业务营收同比增长42.70%，成为新的增长点，但毛利率下降4.55个百分点。
- **[汇兑损益波动]** -> [财务费用转正]: 美元等外币兑人民币汇率波动，导致财务费用从负值转为正值，增加了期间费用。
- **[高分红政策]** -> [股东回报稳定]: 2025年全年现金分红占净利润比例高达75.50%，体现了公司回馈股东的意愿，但也减少了留存收益。

## 风险警告
**核心风险：业绩断崖式下滑与盈利能力的脆弱性。** 2025年公司净利润同比暴跌53.49%，扣非净利润更是下降56.58%。根本原因在于，公司“低成本+高性价比”的商业模式在面临上游元器件涨价和下游竞争加剧时，缺乏定价权与成本转嫁能力。毛利率的微小波动即可引发利润的剧烈震荡，表明其“非洲之王”的护城河并未能有效抵御行业周期的冲击。

**关键风险：新兴市场拓展不及预期与单一市场依赖。** 公司正积极向非洲以外的南亚、东南亚、拉美等市场扩张，但亚洲等其他地区营收同比下降11.58%，显示新市场开拓面临巨大挑战。同时，非洲市场仍是利润核心来源，若该地区出现政治动荡、经济恶化或竞争格局突变，将对公司整体业绩造成毁灭性打击。新市场的“烧钱”投入与回报周期过长，是悬在利润表上的达摩克利斯之剑。
