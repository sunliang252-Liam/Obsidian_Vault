# 603456.SH 深度透视

## 因果逻辑链
- **[大客户深度绑定]** -> [收入稳健增长]: 诺华贡献54.5%营收，大客户项目渗透率提升，商业化项目持续放量，支撑总收入同比+6.74%。
- **[CDMO项目漏斗结构优化]** -> [未来业绩确定性增强]: 已上市项目39个，III期临床94个，I/II期1158个，形成可持续的漏斗型管线，为未来商业化收入转化提供坚实基础。
- **[技术平台驱动降本增效]** -> [毛利率提升]: 连续流、生物催化等绿色技术应用，优化工艺、降低成本，合同定制类毛利率同比提升2.70个百分点至41.08%。
- **[经营效率提升与费用控制]** -> [净利润增速远超收入]: 管理费用同比-5.71%，研发费用同比-18.39%，成本控制成效显著，归母净利润同比+20.46%，显著高于收入增速。
- **[现金流管理强化]** -> [经营现金流大幅改善]: 销售回款增加，经营活动现金流净额同比+83.96%至18.24亿元，远超净利润，现金流质量优异。
- **[多肽与小核酸新业务扩张]** -> [打造第二增长曲线]: 多肽商业化产能扩建，小核酸中美研发平台建成，成功斩获多项NDA项目，为中长期增长注入新动力。
- **[全球化布局深化]** -> [海外市场本地化服务能力提升]: 日本、德国公司业务推进顺利，项目导流至国内工厂，海外收入占比42.15%，有效拓展客户池。

## 风险警告
**核心客户依赖风险极高。** 公司对第一大客户诺华的销售收入占比高达54.50%，业绩高度依赖于单一客户的订单稳定性和产品生命周期。若诺华的核心产品因安全性、市场竞争或专利到期等因素导致销量下滑，将对公司营收和利润造成毁灭性打击。这种“一荣俱荣，一损俱损”的客户结构是公司最大的脆弱性。

**行业竞争加剧与地缘政治风险。** 国内CDMO新竞争者涌入，欧美及印度鼓励产业链回流，公司面临激烈的市场份额争夺和客户流失风险。同时，海外业务占比高，美元/欧元结算面临汇率波动风险，国际贸易政策的不确定性也可能影响海外订单的获取和交付，对公司外销业务构成潜在威胁。
