# 301601.SZ 深度透视

## 因果逻辑链
- **[下游化工行业投资周期下行]** -> [营收与净利润双降]: 2025年营收同比-21.47%，归母净利润同比-30.42%，主因下游化工行业固定资产投资收缩，导致设备制造和EPC业务需求减少。
- **[双氧水业务收入断崖式下滑]** -> [整体业绩承压]: 双氧水业务收入同比-60.07%，主要系印尼等海外大项目在2024年集中交付后，2025年新签大单尚未进入收入确认高峰，造成收入缺口。
- **[处置子公司元素惠通新材料]** -> [非经常性损益拖累]: 因丧失对元素惠通新材料控制权，确认处置损失约642万元，叠加信用减值损失约1200万元，进一步侵蚀利润。
- **[IPO募资到账]** -> [净资产大幅增厚]: 2025年1月上市募资净额约3.54亿元，推动净资产同比+43.64%，但短期内未能有效转化为利润增长，导致ROE从12.45%骤降至5.89%。
- **[在建工程转固]** -> [财务费用激增]: 在建工程转固后，贷款利息停止资本化，叠加利息收入下降，财务费用从-286.5万元转为+109.5万元，同比+138.22%。
- **[尼龙66国产化替代浪潮]** -> [尼龙业务毛利率逆势提升]: 受益于己二腈国产化突破，尼龙66产能扩张需求旺盛，公司尼龙业务收入虽降20%，但毛利率同比+12.33个百分点至48.62%，体现技术溢价。
- **[可降解材料业务放量]** -> [收入结构多元化]: 可降解材料业务收入同比+113.44%，成为第二大收入来源，但毛利率同比-24.31个百分点，反映行业产能过剩后的价格竞争加剧。

## 风险警告
**核心风险在于下游化工投资的强周期性与公司项目制收入的波动性。** 2025年营收与利润双降已明确揭示，公司高度依赖尼龙、双氧水等下游领域的资本开支。一旦宏观经济或产业政策导致固定资产投资进入低谷，公司订单获取和收入确认将面临显著压力。当前双氧水业务的大幅萎缩即是前车之鉴，而可降解材料业务虽放量，但毛利率快速下滑，显示其盈利能力并不稳固。

**另一重大风险是募投项目延期与产能消化不确定性。** 公司两大募投项目（高端装备智能化升级、技术研发中心）截至2025年末投资进度仅31.24%和43.67%，且已公告延期。在行业需求收缩的背景下，新增产能能否被市场有效消化存疑。同时，公司前五大客户集中度高达64.38%，且与关联方OBHE存在大量交易，客户依赖与关联交易风险不容忽视。
