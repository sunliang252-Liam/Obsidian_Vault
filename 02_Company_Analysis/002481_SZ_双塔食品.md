# 002481.SZ 深度透视

## 因果逻辑链
- **[豌豆原料价格波动]** -> [毛利率承压]: 豌豆等农产品价格受天气、市场影响大，公司无法完全转嫁成本，导致盈利水平波动。
- **[产品结构向高毛利蛋白倾斜]** -> [综合毛利率提升]: 食用蛋白毛利率47.36%，远高于粉丝(7.76%)和淀粉(-26.70%)，蛋白收入占比提升拉高整体毛利。
- **[国内市场需求疲软]** -> [营收下滑13.37%]: 国内收入同比下降20.59%，豌豆干淀粉、膳食纤维等产品国内销售大幅萎缩。
- **[资产减值损失激增]** -> [净利润暴跌65.48%]: 存货跌价准备计提1.26亿元，同比增143%，严重侵蚀利润。
- **[海外市场相对稳定]** -> [收入结构优化]: 国外收入占比从40.91%升至45.45%，且毛利率27.99%高于国内，成为利润稳定器。
- **[循环产业链降本]** -> [成本优势]: “1+N”全封闭循环模式，将豌豆吃干榨净，综合生产成本低于同行。
- **[研发投入持续加大]** -> [技术壁垒]: 掌握三种豌豆蛋白提取技术，参与行业标准制定，巩固全球最大豌豆蛋白生产商地位。

## 风险警告
**核心风险在于原料价格波动与存货减值恶性循环。** 公司主要原料豌豆依赖进口，价格受国际农产品市场、汇率、贸易政策多重影响，波动剧烈。2025年公司计提1.26亿元存货跌价准备，直接导致净利润暴跌65%，且存货账面价值高达8.32亿元，占总资产17.89%，若原料价格持续下行，减值风险将进一步放大。

**成长性面临天花板。** 公司营收连续两年下滑（2024年-0.3%，2025年-13.37%），国内传统粉丝、淀粉业务萎缩明显。虽然食用蛋白业务毛利率高，但海外市场增速仅-2.94%，且面临替代蛋白行业竞争加剧。公司2025年经营现金流净额同比骤降72%，投资活动现金净流出4.08亿元（泰国、四川扩产），资金压力显著增大。
