# 600405.SH 深度透视

## 因果逻辑链
- **[国际贸易摩擦与供应链中断]** -> [营收暴跌26.23%]: 直接出口业务受阻，海外优质半导体供应商终止合作，导致上半年订单交付不及预期。
- **[国内通信电源需求下行]** -> [通信电源收入锐减30%]: 运营商资本开支放缓，新增订单量减少，核心基本盘业务承压。
- **[现金流阶段性紧缺与银行抽贷]** -> [经营活动现金流净流出4.19亿元]: 资金调配困难，被迫出售非核心资产（科丰鼎诚）补充流动性，并转向高成本自然人借款。
- **[业务结构优化与人员精简]** -> [归母净利润减亏23.48%]: 主动放弃低利润订单，聚焦高毛利客户，大幅削减销售与研发人员薪酬，成本降幅（-28.59%）略大于收入降幅（-26.23%）。
- **[出售核心子公司（迪赛奇正）]** -> [净资产暴跌81.64%]: 以1.6亿元出售盈利资产，虽短期补充现金流，但永久性削弱了公司资产规模和持续盈利能力。
- **[高额自然人借款激增]** -> [其他应付款暴增269%至6.84亿元]: 银行授信断裂后，被迫依赖高息民间借贷，财务费用逆势增长14%，利息支出压力巨大。
- **[中标运营商集采项目]** -> [未来收入改善的微弱曙光]: 成功中标中国铁塔、中国电信集采项目（中标额超1.7亿），为后续营收提供支撑，但交付能力受制于现金流。

## 风险警告
**流动性危机与高负债率是公司当前最致命的威胁。** 公司资产负债率已飙升至95.91%，经营活动现金流净流出高达4.19亿元，而银行授信基本断裂，被迫转向年化利率极高的自然人借款（其他应付款暴增至6.84亿元）。这种“借新还旧”的财务结构极其脆弱，一旦外部融资环境恶化或债权人挤兑，公司将面临严重的偿债风险，甚至可能触发债务违约。

**核心资产持续流失，主业造血能力堪忧。** 公司为自救已连续出售科丰鼎诚、迪赛奇正等优质子公司，导致净资产从36.28亿骤降至6.66亿。虽然短期保住了现金流，但永久性丧失了重要的利润来源和资产基础。与此同时，通信电源主业需求疲软，绿色出行（车载、充换电）业务仍处于亏损烧钱阶段，新能源业务尚未形成规模，公司已陷入“卖资产续命”的恶性循环，持续经营能力存在重大不确定性。
