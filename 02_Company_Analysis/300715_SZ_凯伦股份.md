# 300715.SZ 深度透视

## 因果逻辑链
- **[收购佳智彩]** -> [扭亏为盈]: 收购佳智彩51%股权，新增显示面板检测修复设备业务，贡献收入2.98亿元、净利润3448.7万元，是公司归母净利润从-5.39亿扭转为+0.20亿的核心驱动力。
- **[主动收缩地产集采]** -> [防水收入下降]: 公司主动降低账期较长的房地产集采客户订单占比，导致防水材料销售收入同比下降14.29%，但优化了现金流和资产质量。
- **[降本增效与减值减少]** -> [扣非亏损大幅收窄]: 三项费用同比减少1.19亿元，信用及资产减值损失同比减少4.96亿元，共同推动扣非净利润从-5.69亿大幅收窄至-0.55亿。
- **[强化应收账款管理]** -> [经营现金流大幅转正]: 通过优化销售结构、加强回款催收，经营活动现金流净额从-1.40亿大幅提升至+2.66亿，经营质量显著改善。
- **[高分子防水差异化]** -> [巩固细分赛道地位]: 聚焦TPO/PVC等高分子卷材，切入工商业光伏屋面、核电等高端市场，在行业下行期维持了品牌溢价与竞争壁垒。
- **[佳智彩业绩承诺]** -> [短期业绩确定性]: 佳智彩2025年扣非净利润7035万元，超额完成5500万元的业绩承诺，为未来两年业绩提供了明确的增长锚点。

## 风险警告
**商誉减值风险是最大隐患。** 公司因收购佳智彩确认商誉36.09亿元，占净资产比例高达193.6%。若未来宏观经济下行、面板行业投资周期逆转或佳智彩业绩不达预期（2026-2027年承诺净利润分别为7500万、1.1亿），将面临巨额商誉减值，直接吞噬当期利润，甚至导致净资产大幅缩水。

**防水主业持续承压与转型阵痛。** 公司传统防水业务仍深度依赖房地产行业，2025年收入同比下降14.29%。尽管公司主动收缩风险业务，但新开拓的工商业光伏、城市更新等赛道尚处于成长期，短期内难以完全弥补地产下行缺口。同时，公司账面仍存在大量工抵房等非核心资产，其处置进度与变现价值存在不确定性，可能持续拖累资产质量与现金流。
