# 002426.SZ 深度透视

## 因果逻辑链
- **[汽车零部件业务高增长]** -> [营收增长但毛利率下降]: 车载中控屏和镁合金结构件订单大增32.86%，推动汽车零部件收入增长24.79%，但产品结构调整和竞争加剧导致毛利率从32.41%骤降至24.26%。
- **[资产减值损失]** -> [连续三年巨额亏损]: 2025年计提资产减值1.70亿元、信用减值2.63亿元，合计4.33亿元的非现金损失是导致净利润-7.11亿元的核心原因。
- **[历史并购遗留问题]** -> [持续的资金与法律负担]: 智诚光学、硕诺尔等并购标的业绩对赌失败，导致长期诉讼追偿、大额商誉减值及投资者索赔，持续侵蚀公司利润和现金流。
- **[消费电子业务增长乏力]** -> [主业缺乏弹性]: 消费电子收入仅增长0.96%，毛利率14.16%基本持平，显示公司传统精密结构件业务在行业复苏中仅能维持，缺乏增长动能。
- **[财务费用激增]** -> [侵蚀利润]: 财务费用同比上升76.23%至1.05亿元，主要受汇兑损益影响，对微薄的经营利润形成巨大压力。
- **[母公司未分配利润巨额亏损]** -> [无法分红]: 母公司未分配利润为-27.25亿元，导致公司连续无法进行现金分红，损害股东回报预期。
- **[复合集流体项目尚处早期]** -> [未来增长点不确定]: 公司重点布局的复合铜箔/铝箔项目仍处于研发优化、小批量试产阶段，尚未贡献收入，短期无法对冲主业亏损。

## 风险警告
公司最大的风险在于**资产质量持续恶化与历史包袱沉重**。连续三年巨额亏损（累计超23亿元）已导致净资产从2023年的33.85亿元腰斩至17.14亿元，而母公司未分配利润高达-27.25亿元，意味着公司几乎丧失了内生性造血和分红能力。更关键的是，每年数亿元的资产减值与信用减值（2025年合计4.33亿元）已成为常态，这并非一次性出清，而是历史并购失败（智诚光学、硕诺尔等）和应收账款质量问题的持续暴露，表明公司资产底子存在系统性风险。

其次，**主业增长质量堪忧且现金流脆弱**。虽然汽车零部件业务看似高增长，但毛利率大幅下滑8个百分点，说明其增长是以牺牲利润为代价的“增收不增利”。同时，公司经营活动现金流净额仅0.91亿元，远不足以覆盖巨额利息支出和资本开支，高度依赖外部融资（短期借款17.13亿元）维持运营。一旦融资环境收紧或客户回款出现问题，公司将面临严峻的流动性危机。
