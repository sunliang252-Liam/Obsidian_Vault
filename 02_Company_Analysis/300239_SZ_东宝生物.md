# 300239.SZ 深度透视

## 因果逻辑链
- **[明胶市场阶段性波动]** -> [营收与利润双降]: 明胶系列产品销量及售价受市场冲击，营收同比-37.65%，拖累整体营收下降15.78%，归母净利润下降36.80%。
- **[空心胶囊业务量价齐升]** -> [结构性对冲明胶下滑]: 子公司益青生物空心胶囊全线产品销量+19.92%，营收+12.31%，毛利率提升3.40%，成为业绩核心稳定器。
- **[胶原蛋白新领域突破]** -> [开辟第二增长曲线]: 电解铜箔、纺织等工业领域应用实现销量与收入双增长，胶原蛋白业务整体营收+15.35%，对冲传统业务下滑。
- **[明胶库存策略调整]** -> [库存激增与资产减值]: 为保毛利率主动控销，明胶库存量同比+51.16%，叠加价格下行，计提存货跌价准备1513万元，侵蚀利润。
- **[募投项目产能爬坡不及预期]** -> [拖累整体盈利]: “新型空心胶囊智能产业化项目”尚未达产，单位成本上升，报告期仅实现效益984万元，远低于预期。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营性现金流净额同比+53.22%至1.06亿元，显著优于净利润表现，主因销售回款增加及支出控制。
- **[海外业务收缩]** -> [国际化进程受挫]: 国外地区营收同比-61.83%，占比从9.56%降至4.33%，主要受明胶出口市场波动影响。

## 风险警告
公司当前面临的核心风险是**传统明胶业务的结构性衰退与新兴业务增长之间的时间错配**。明胶作为营收基本盘（占比35.52%），受行业阶段性波动冲击，量价齐跌导致库存高企和资产减值，短期内难以恢复。尽管空心胶囊和胶原蛋白新业务增长强劲，但其体量尚不足以完全对冲明胶下滑，导致整体业绩承压。

**募投项目产能释放不及预期**是另一重大风险。新型空心胶囊扩产项目已多次延期至2027年3月，且公司拟追加投资。若市场拓展或工艺磨合不顺，新增产能可能无法及时转化为有效产出，导致折旧和固定成本增加，进一步拖累盈利能力。同时，海外市场的大幅萎缩也暴露出公司国际化布局的脆弱性。
