# 300158.SZ 深度透视

## 因果逻辑链
- **[主动收缩非核心亏损业务]** -> [营收下降但减亏]: 公司主动剥离长期亏损的非核心业务，短期拖累营收（-6.33%），但有效减少了亏损源，推动净利润大幅减亏77.34%。
- **[上年同期非经营性亏损高基数]** -> [本期净利润大幅减亏]: 2024年因重大仲裁、信托逾期等非经营性因素产生巨额亏损，导致2025年同期基数极低，使得减亏幅度显著。
- **[中药材业务持续亏损]** -> [拖累整体营收与利润]: 中药材行业供需未改善，部分品种价格走低，公司中药材业务持续亏损，对整体营收形成拖累。
- **[核心产品销售稳定与品牌提升]** -> [对冲外部不利影响]: 尽管行业政策调整、竞争加剧，公司核心产品（如复方苦参注射液、米诺地尔搽剂）销售保持稳定，品牌影响力提升，有效对冲了部分外部压力。
- **[线上销售高速增长]** -> [弥补线下渠道下滑]: 线上销售（+43.88%）成为核心增长引擎，部分弥补了线下销售（-10.70%）的下滑，显示出渠道转型的成效。
- **[严控成本费用与经营优化]** -> [推动减亏]: 公司持续优化经营管理体系，严控各项成本费用，叠加主动收缩亏损业务，有效降低了运营成本，推动经营状况向好。
- **[研发投入资本化率提升]** -> [短期利润调节]: 研发投入资本化率从11.11%提升至19.07%，减少了当期费用化金额，对当期净利润有正向影响，但需关注未来资本化项目的转化风险。

## 风险警告
**核心风险在于持续经营能力与历史包袱。** 公司已连续三年扣非净利润为负，2025年经营活动现金流净额为-4.6亿元，造血能力严重不足。尽管通过收缩业务和低基数效应实现大幅减亏，但主营业务（尤其是中药材）仍处亏损，且母公司及合并报表未分配利润均为巨额负值（-16.89亿元），短期内不具备分红能力，股东回报堪忧。

**治理与合规风险是悬顶之剑。** 公司历史上存在控股股东非经营性资金占用、销售费用内控重要缺陷等违规事项，虽已整改，但暴露了公司治理的薄弱环节。此外，公司仍有高达2.47亿元的信托理财产品逾期未收回，资产减值风险与流动性风险并存，对财务稳健性构成持续威胁。
