# 600129.SH 深度透视

## 因果逻辑链
- **[销售结算模式变化]** -> [营收下降15.23%]: 公司主动调整渠道策略，从“压货”转向“动销”，导致账面收入大幅减少，但终端真实销售改善。
- **[集采政策与同质化竞争]** -> [工业收入骤降26.11%]: 注射用头孢唑肟钠等化药受集采冲击严重，销量与价格双杀，拖累整体工业板块表现。
- **[营销模式转型（自营+代理）]** -> [销售费用锐减49.88%]: 结算模式从“高费用高返利”转向“低费用直控终端”，费用结构优化，但短期压制收入。
- **[国药体系内整合]** -> [商业板块承压]: 与国药控股签署《股权托管协议》，商业业务处于整合过渡期，收入同比下降7.86%，但长期有望提升供应链效率。
- **[中药资源“双基地”建设]** -> [中药材板块逆势增长12.39%]: 通过GAP基地和产地加工厂建设，掌控上游资源，半夏、黄连单品销售破亿，成为业绩稳定器。
- **[核心产品循证医学突破]** -> [医疗渠道增长]: 鼻窦炎口服液、通天口服液等进入多项诊疗指南，推动院内销售分别同比增长40.5%、35.2%，弥补了OTC渠道下滑。
- **[去库存与终端动销]** -> [经营性现金流大幅转正]: 以动销为核心考核，藿香正气口服液终端销量同比增长47%，社会库存显著下降，现金流从-6.3亿改善至+5.8亿。
- **[非经常性损益贡献]** -> [归母净利润虚高增长352%]: 扣非净利润仅增长13.32%，利润总额同比下降31.72%，真实盈利能力并未改善，高增长主要源于同期补缴税款基数低。

## 风险警告
**核心风险在于“收入塌方”与“利润虚胖”的背离。** 公司营收同比下滑15.23%，利润总额更是下降31.72%，但归母净利润却因同期补缴税款的低基数而暴增352%。剔除政府补助、资产处置等非经常性损益后，扣非净利润仅微增13.32%，真实盈利能力已大幅恶化。工业板块收入骤降26%，核心产品急支糖浆、藿香正气口服液销量均出现下滑，显示公司正经历深度调整阵痛，增长动能严重不足。

**转型阵痛与整合不确定性并存。** 公司主动进行营销模式变革，从“压货”转向“动销”，虽改善了现金流和终端库存，但短期内牺牲了收入和利润。同时，与国药控股的商业整合尚处托管阶段，能否实现预期的协同效应、避免内部竞争，存在较大不确定性。此外，公司连续两年不进行现金分红，且实际控制人国药集团关于解决同业竞争的承诺再次延期五年，对中小股东利益构成潜在损害。
