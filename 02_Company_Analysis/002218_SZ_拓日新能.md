# 002218.SZ 深度透视

## 因果逻辑链
- **[光伏行业产能过剩与价格战]** -> [营收与毛利率双降]: 主产业链（组件、电池片）价格持续低位，导致公司晶体硅太阳能电池芯片及组件收入同比暴跌46.66%，毛利率由正转负至-24.12%。
- **[光伏玻璃业务成本刚性]** -> [毛利率下滑]: 光伏玻璃收入仅微降0.98%，但营业成本上升5.46%，导致毛利率下降6.67个百分点，反映原材料或能源成本压力未能向下游传导。
- **[电力市场化交易与限电]** -> [电费收入与毛利率承压]: 自持电站发电业务受市场化电价下行及限电影响，收入下降13.55%，毛利率下降10.63个百分点，核心利润来源稳定性受挑战。
- **[EPC工程收入锐减]** -> [营收结构恶化]: 工程收入同比暴跌95.27%，连带组件等关联销售减少，显示公司项目开发与建设业务陷入停滞，拖累整体营收规模。
- **[海外消费类产品逆势增长]** -> [出口业务成为亮点]: 光伏应用消费类产品收入同比增长115.04%，带动整体出口收入增长8.44%，部分对冲了国内业务的颓势。
- **[经营性现金流大幅改善]** -> [利润与现金流的背离]: 经营活动现金流净额同比增长71.68%至2.83亿元，主要得益于EPC回款和补贴到账，但利润亏损，表明现金流改善来自历史应收而非当期盈利。
- **[光储战略转型]** -> [开辟第二增长曲线]: 公司正式确立“光储融合”战略，西安储能基地已竣工，初期规划产能2GWh，旨在构建新的业绩增长点，但尚处投入期，未贡献利润。

## 风险警告
**核心风险：行业深度亏损与盈利拐点不明。** 公司2025年归母净利润亏损1.99亿元，同比暴跌1944.78%，主因是光伏全产业链产能过剩导致的“内卷式”价格战。公司核心业务——组件、光伏玻璃、电站发电——毛利率全面下滑，其中组件业务已陷入严重亏损（毛利率-24.12%）。尽管行业出清正在进行，但供需再平衡的时间表高度不确定，公司短期盈利能力面临严峻考验。

**财务风险：资产减值与债务结构压力。** 公司2025年计提资产减值准备3767.64万元，叠加经营亏损，净资产同比下降5.2%。同时，一年内到期的非流动负债从2.16亿元激增至7.23亿元，短期偿债压力显著上升。虽然公司账面现金充裕且资产负债率（38.93%）尚可，但若行业低迷持续，现金流恶化与债务到期叠加可能引发流动性风险。
