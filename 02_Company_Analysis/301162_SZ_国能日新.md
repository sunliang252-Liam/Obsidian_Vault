# 301162.SZ 深度透视

## 因果逻辑链
- **[新能源装机高景气度 + 分布式“四可”政策落地]** -> [功率预测服务电站净增1,684家，总规模达6,029家]: 政策强制要求分布式光伏具备功率预测能力，叠加新增装机创历史新高，直接拉动公司核心产品需求爆发。
- **[“旷冥”AI大模型持续迭代 + 海量场站数据壁垒]** -> [功率预测精度行业领先，蝉联南方电网竞赛第一]: 百余名AI工程师与超6000家场站实测数据形成正反馈循环，技术优势转化为客户粘性与市场地位。
- **[电力市场化改革（136号文）全面提速]** -> [电力交易产品拓展至19个省份，创新业务收入增长13.79%]: 新能源全面入市催生对交易策略、数据服务的刚性需求，公司从功率预测向交易决策延伸，打开第二增长曲线。
- **[类SaaS收费模式 + 高客户留存]** -> [功率预测服务费收入2.24亿元，同比增长15.87%]: 存量客户持续付费叠加新增客户快速导入，服务费收入构成稳定且持续增长的现金流基础。
- **[子公司日新鸿晟布局资产运营]** -> [新能源电站运营收入暴增368%，达7602万元]: 公司从纯软件服务向“数据+资产”运营模式延伸，通过投建分布式光伏、储能项目获取运营分成收益。
- **[研发投入1.08亿元，占收入15%]** -> [累计获得发明专利111项，巩固技术护城河]: 持续高研发投入确保在气象大模型、功率预测算法等核心环节保持领先，支撑产品溢价与市场扩张。

## 风险警告
**核心风险在于“政策驱动”向“市场驱动”切换过程中的不确定性。** 公司当前业绩爆发高度依赖分布式“四可”政策的强制落地与新能源抢装潮，若各省政策执行力度不及预期或存量改造节奏放缓，功率预测新增客户增速可能显著回落。同时，电力交易业务虽前景广阔，但各省市场规则差异大、开市时间不一，产品标准化与规模化复制面临挑战，创新业务收入占比仍低（约5%），短期难以完全对冲主业波动。

**财务层面，应收账款与资产扩张带来的现金流压力不容忽视。** 公司应收账款达4.53亿元，占收入比重高达63%，尽管客户多为大型国企，但回款周期拉长将侵蚀经营现金流。此外，公司通过融资租赁、长期借款等方式大举投资新能源电站资产（固定资产增至5.95亿元），导致资产负债率上升、财务费用激增784%。若电站运营收益率不及预期或融资环境收紧，将显著拖累利润表现。
