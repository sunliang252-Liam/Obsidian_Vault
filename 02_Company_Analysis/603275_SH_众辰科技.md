# 603275.SH 深度透视

## 因果逻辑链
- **[伺服系统产品放量]** -> [营收增长]: US880系列伺服产品带动伺服系统收入同比大增78.27%，成为核心增长引擎。
- **[减速机业务并表]** -> [营收结构多元化]: 收购浙江贝托、江苏三木禾，新增减速机收入4,455万元，完善“驱动+控制+执行”产业链布局。
- **[成本上升侵蚀毛利]** -> [利润下滑]: 营业成本增速（+14.02%）远超营收增速（+7.77%），导致主营业务毛利率下降3.42个百分点。
- **[费用刚性增长]** -> [净利率承压]: 管理费用（+56.12%）、研发费用（+38.13%）因规模扩张、股权激励及子公司并表大幅增加，扣非净利润同比下降19.90%。
- **[行业专机策略见效]** -> [产品结构优化]: 行业专机收入同比增长12.69%，但毛利率下降7.26个百分点，显示以价换量策略。
- **[高额理财收益]** -> [非经常性损益支撑利润]: 交易性金融资产贡献公允价值变动及处置收益3,356万元，占净利润的18.7%，掩盖了主营业务的疲软。
- **[应收账款增长]** -> [现金流压力]: 应收账款同比增长22.36%，导致经营性现金流净额同比下降23.07%，现金回收效率降低。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化。** 公司营收增长7.77%，但扣非净利润却下降19.90%，主因是成本与费用端全面承压。原材料成本上涨、新业务（减速机）尚处亏损期、股权激励费用及研发投入的刚性增长，共同侵蚀了利润空间。若此趋势延续，公司高毛利率的护城河将被持续削弱。

**第二风险是成长性的可持续性存疑。** 公司核心产品通用变频器收入同比下降7.16%，增长主要依赖高增长的伺服系统（基数低）和并购的减速机业务（尚在亏损）。同时，公司持有超过15亿元的交易性金融资产，理财收益对利润贡献巨大，主营业务的真实造血能力与增长质量需要投资者审慎评估。
