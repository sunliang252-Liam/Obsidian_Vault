# 301528.SZ 深度透视

## 因果逻辑链
- **[自动化检测系统标准化与液冷板检测突破]** -> [工业无损检测设备收入增长56.01%]: 公司水浸相控阵C扫系统等标准机型在液冷产品焊接检测领域规模化推广，解决了行业痛点，成为业绩增长核心引擎。
- **[国产化替代与宏观环境回暖]** -> [营业收入增长39.24%]: 下游特种设备、航空航天、新能源等领域国产化进程加速，叠加经济复苏，带动无损检测需求放量。
- **[海外子公司设立与全球布局]** -> [境外收入增长8.92%]: 德国、迪拜子公司的成立完善了海外营销网络，提升了客户认可度，成为营收增长的重要补充。
- **[高研发投入与技术创新]** -> [巩固行业技术壁垒]: 研发投入占营收22.21%（同比+30.47%），聚焦全聚焦成像、高频换能器、自动化系统等，支撑产品迭代与竞争力。
- **[股权激励实施]** -> [绑定核心团队与业绩增长]: 向72名激励对象授予92万股限制性股票，激发管理层与技术人员积极性，推动收入与利润双增。
- **[正式进军工业射线检测]** -> [开辟第二增长曲线]: 完成DR/CT全矩阵产品规划，计划2026年搭建核心产品矩阵，有望与超声检测形成协同，拓展市场空间。
- **[募投项目推进与产能建设]** -> [支撑长期增长]: 产业园建设有序推进，将提升自主制造能力，应对定制化与自动化需求，降低外协依赖。

## 风险警告
**毛利率持续下滑与募投项目回报不确定性。** 公司综合毛利率已从2023年的75.86%降至2025年的69.49%，且工业无损检测设备毛利率同比下降5.01%。随着行业竞争加剧、人力成本上升及募投项目新增折旧，毛利率存在进一步下降风险。同时，两大核心募投项目（智能化生产基地、总部研发中心）截至期末投资进度仅8.16%和5.73%，建设周期长，若下游需求或政策变化，项目收益可能大幅低于预期，导致净利润承压。

**新业务拓展与核心技术人员流失的双重风险。** 公司正式进入工业射线检测领域，但该领域技术壁垒高、研发周期长，存在技术方向偏差或研发失败的可能。同时，无损检测行业人才竞争激烈，公司核心技术人员（如董事纪轩荣为广东工业大学教授）存在流失风险，可能导致核心技术外泄或研发项目受阻，影响公司长期竞争力。
