# 603929.SH 深度透视

## 因果逻辑链
- **[海外市场高毛利项目放量]** -> [净利润创历史新高]: 新加坡VSMC等大额项目毛利率显著高于国内，叠加有效成本控制，推动净利润同比大增40.30%。
- **[国内业务主动收缩]** -> [营收小幅下滑]: 公司为规避低利润和风险项目，有选择地承接国内订单，导致国内收入同比下降58.15%，拖累整体营收下降8.81%。
- **[新加坡项目回款良好]** -> [经营性现金流强劲]: 海外项目回款周期优于国内，叠加公司加大催收力度，全年经营性现金流净额达16.66亿元，远超净利润。
- **[有效发包策略与成本控制]** -> [毛利率大幅提升]: 公司通过内部管理和成功采购策略，有效控制了大宗物料波动风险，综合毛利率从13.55%跃升至24.57%。
- **[客户高度集中]** -> [业绩依赖单一项目]: 前五大客户销售额占比高达92.29%，其中第一大客户占比55.30%，公司业绩高度依赖少数大客户的项目进度。
- **[海外布局深化]** -> [资产结构“出海”]: 境外资产占总资产比例高达67.43%，新加坡分公司贡献了绝大部分利润，公司正从国内龙头转向国际化工程服务商。
- **[AI与研发投入]** -> [构筑技术护城河]: 公司持续在分子污染防治、节能技术及AI设计助手等领域投入研发，以维持在高阶洁净室工程市场的领先地位。

## 风险警告
**客户集中度与单一项目依赖风险**：公司前五大客户销售额占比超92%，其中第一大客户（新加坡VSMC项目）占比高达55.30%。业绩高度绑定于少数大客户的资本开支计划，一旦主要客户建厂进度放缓或订单减少，公司营收和利润将面临剧烈波动。这种“大客户依赖”模式在项目周期结束后，若无新的大型订单接续，业绩可能出现断崖式下滑。

**海外经营与汇率波动风险**：公司境外资产占比已超67%，利润主要来自新加坡分公司。海外业务面临地缘政治、当地法律法规、劳务分包成本高企以及美元/新加坡元汇率波动的多重风险。报告期内财务费用因汇兑损失大幅增加，已显示出汇率波动的直接冲击。海外扩张虽带来高毛利，但也放大了经营的不确定性。
