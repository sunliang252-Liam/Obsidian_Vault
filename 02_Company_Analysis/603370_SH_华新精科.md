# 603370.SH 深度透视

## 因果逻辑链
- **[新能源汽车渗透率持续提升]** -> [驱动电机铁芯营收增长18.12%]: 公司核心主业受益于下游新能源车产销两旺，全年斩获34个定点项目，直接拉动收入至9.78亿元。
- **[主动优化业务结构，淘汰低效客户]** -> [电气设备铁芯营收下降18.21%]: 公司战略性收缩付款周期长、管理成本高的客户，虽短期牺牲销量，但改善了现金流质量与应收账款结构。
- **[首发上市募集资金到位]** -> [总资产与净资产大幅扩张]: 2025年9月上市募资约7.27亿元，总资产增至27.52亿元（+49.81%），净资产增至19.35亿元（+86.02%），资本实力显著增强。
- **[经营活动现金流由负转正]** -> [现金流质量改善]: 2025年经营性现金流净额达1.18亿元，扭转2024年-0.63亿元的净流出局面，主因销售回款增加及客户结构优化。
- **[模内点胶与自粘技术持续迭代]** -> [巩固高端铁芯工艺壁垒]: 第三代点胶技术进入小批量试制，第四代研发中，非晶合金等新材料工艺突破，支撑公司在高功率密度、低噪音电机领域的竞争地位。
- **[人形机器人及低空经济布局]** -> [开辟第二增长曲线]: 完成空心杯电机、无框力矩电机铁芯样品开发，并参股清泰科成立合资公司，将技术积累向新兴高附加值赛道延伸。
- **[硅钢原材料价格波动]** -> [毛利率承压]: 硅钢采购占成本90%以上，2025年新能源汽车驱动电机铁芯毛利率微降0.9个百分点，原材料价格波动是影响盈利稳定性的核心变量。

## 风险警告
**核心风险在于下游政策退坡与产能消化。** 2026年起新能源汽车购置税减半征收，且插混车型续航门槛提升至100公里，可能抑制入门级车型销量，进而传导至公司驱动电机铁芯订单增速。同时，IPO募投项目“新能源车用驱动电机铁芯扩建项目”达产后将新增100万套产能，若下游需求增长不及预期，存在产能利用率不足、折旧吞噬利润的风险。

**毛利率下行压力不可忽视。** 公司综合毛利率21.86%，同比微降，且内销毛利率仅14.11%，远低于外销的42.17%。随着行业竞争加剧及客户年降条款的普遍存在，若原材料价格反弹或人工成本上升，毛利率可能进一步收窄。此外，公司研发投入占比仅3.25%，在技术快速迭代的新兴赛道中，若研发节奏落后于客户对超薄硅钢、自粘工艺的需求，可能削弱长期竞争力。
