# 001339.SZ 深度透视

## 因果逻辑链
- **[AI算力资本开支爆发]** -> [智算业务营收增长53.39%]: 全球科技巨头AI资本开支激增，直接拉动公司算力设备销售与租赁服务需求。
- **[智算业务高毛利]** -> [净利润增长36.84%]: 智算业务毛利率高达76.62%，其营收占比提升（从7.46%至11.30%）显著优化了整体盈利结构。
- **[工业物联网切入具身智能]** -> [工业物联网营收增长66.26%]: 公司推出人形机器人控制器等新品，切入具身智能赛道，带动该板块高速增长。
- **[行业终端营收下滑]** -> [整体营收增速仅1.30%]: 占营收54.20%的行业终端业务同比下降14.70%，拖累了整体营收增长。
- **[原材料备货激增]** -> [经营性现金流大幅转负]: 为应对订单增长，公司大幅增加原材料备货，导致经营活动现金流净额从+11.48亿骤降至-6.76亿。
- **[AI推理市场布局]** -> [未来增长新引擎]: 公司战略投资LPU推理芯片，并推出AI工作站等产品，旨在抓住AI推理需求爆发的历史性机遇。
- **[信创产业政策驱动]** -> [ICT基础设施营收增长27.16%]: 信创国产化替代需求旺盛，公司服务器、网络安全设备等产品受益，实现较快增长。

## 风险警告
**现金流断裂风险是当前最核心的警报。** 公司净利润1.71亿，但经营性现金流为-6.76亿，缺口高达8.47亿。主因是存货从8.56亿暴增至17.79亿，翻了一倍多。若下游需求不及预期或客户回款放缓，巨量存货将形成巨大的减值压力，并可能引发流动性危机。公司短期借款也增至11.64亿，财务压力显著上升。

**行业终端业务的结构性衰退风险不容忽视。** 作为营收基本盘（占比54%），该板块收入同比下降14.7%，且毛利率仅10.6%，是典型的“增收不增利”甚至“减收”业务。在AIPC浪潮中，公司能否成功将传统PC升级为高附加值AI终端，并扭转下滑趋势，存在较大不确定性。若该板块持续萎缩，将严重侵蚀公司整体抗风险能力。
