# 603326.SH 深度透视

## 因果逻辑链
- **[原创设计驱动产品溢价]** -> [净利润增长43.56%]: 公司坚持中高端定位，推出“繁花”“绒花”等差异化新品，全屋定制收入增长11.99%，带动整体客单值提升，在行业承压下实现利润大幅增长。
- **[主动收缩低毛利大宗业务]** -> [零售业务占比提升，毛利额增加]: 大宗业务收入同比骤降62.53%，而高毛利的经销业务增长11.46%，直营业务持平，业务结构优化直接推升整体盈利质量。
- **[精细化费用管控]** -> [销售费用下降16.21%]: 通过精准投放营销资源、优化组织架构，在收入微增1.29%的同时，销售费用大幅压降，是扣非净利润增长73.27%的核心驱动力。
- **[经销渠道“千平大店”策略]** -> [经销业务收入增长11.46%]: 顺应卖场融合趋势，引导经销商开设厨柜与全屋定制一体化大店，提升单店产出与品牌势能，驱动零售端增长。
- **[供应链集约管理与智能排产]** -> [成本控制与交付效率提升]: 通过供应商评分挂钩订单、跨事业部联合采购、按物流线路精细排产，有效平滑原材料价格波动，保障运营稳定性。
- **[全屋定制占比提升]** -> [整体毛利率微降0.02个百分点]: 全屋定制收入占比升至81.27%，但其毛利率同比下降2.28个百分点，抵消了厨柜毛利率改善的正面影响，整体毛利率基本持平。
- **[经营活动现金流净额骤降72.55%]** -> [销售商品收到的现金减少]: 尽管利润大增，但经销和大宗业务回款放缓，导致经营性现金流大幅萎缩，盈利质量与现金流的背离值得警惕。

## 风险警告
**最大风险：应收账款信用风险高企，现金流与利润严重背离。** 截至2025年末，应收账款账面余额高达5.00亿元，占总资产24.22%，坏账准备计提4.26亿元，计提比例惊人。前期大宗业务客户违约问题未根本解决，尽管公司主动收缩大宗业务，但存量应收款的回收仍存在重大不确定性。更关键的是，在净利润增长43.56%的背景下，经营活动现金流净额却同比暴跌72.55%至1.25亿元，盈利质量堪忧，若应收账款持续恶化，将直接侵蚀公司利润并威胁流动性。

**第二大风险：行业存量博弈加剧，渠道下沉与区域失衡制约增长。** 新房交付持续收缩，存量房翻新需求释放缓慢，行业竞争已从价格战升级为品牌、渠道、供应链的全方位较量。公司在四五线城市的渠道覆盖和品牌认知仍有明显短板，且品牌影响力高度集中于华东地区，华南、西南等区域认知度差距较大。这种区域发展不均衡将严重制约公司全国化布局的纵深推进，在行业集中度提升的背景下，可能面临市场份额被更下沉的竞争对手蚕食的风险。
