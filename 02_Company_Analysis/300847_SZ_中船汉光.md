# 300847.SZ 深度透视

## 因果逻辑链
- **行业竞争加剧与产品降价** -> **净利润下滑7.68%**: 尽管营收微增0.84%，但毛利率承压，导致归母净利润从1.24亿降至1.14亿。
- **核心耗材业务（墨粉+OPC鼓）增长停滞** -> **营收增速仅0.02%**: 静电成像设备及耗材产业收入11.32亿，同比几乎无增长，显示成熟期市场饱和。
- **特种精密加工业务高增长** -> **营收增长29.40%**: 受益于军工订单（如704所项目），该业务收入从3535万增至4574万，成为新增长点。
- **经营活动现金流大幅恶化** -> **现金流净额下降45.98%**: 销售回款减少，导致经营性现金流从1.98亿骤降至1.07亿，盈利质量下降。
- **研发投入聚焦高附加值产品** -> **彩色墨粉实现市场突破**: 两种型号彩色墨粉成功推向市场，补齐产品短板，为未来增长蓄力。
- **信息安全复印机政策红利** -> **国产替代市场空间广阔**: 国家政策推动“国货国用”及设备更新，公司信息安全复印机业务有望受益。
- **募投项目多次延期与变更** -> **产能扩张节奏低于预期**: 彩色墨粉、OPC鼓等项目因市场需求审慎推进，并调整至新产业园，短期无法贡献增量。

## 风险警告
**核心风险在于主业增长乏力与现金流恶化。** 公司核心的墨粉和OPC鼓业务已进入成熟稳定期，营收增长近乎停滞，且面临激烈的市场竞争和产品降价压力。2025年净利润下滑7.68%，经营性现金流更是大幅下降46%，显示公司在产业链中的议价能力或回款效率出现问题，盈利质量显著下降。若无法通过彩色墨粉等新产品打开局面，公司可能陷入“增收不增利”的困境。

**募投项目频繁变更与延期，产能扩张存在不确定性。** 公司多个核心募投项目（彩色墨粉、激光OPC鼓、工程技术中心）均经历了多次延期和用途变更，最新计划是将资金转向新的“耗材产业园区”项目。这反映出公司对市场需求的判断和项目执行能力存在不足，新产能何时能落地并贡献效益存在较大不确定性，短期难以成为业绩驱动力。
