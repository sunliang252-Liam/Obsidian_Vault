# 688039.SH 深度透视

## 因果逻辑链
- **[车载智能座舱业务爆发]** -> [营收增长]: 智能座舱业务收入同比增长52.29%，有效对冲传媒文化业务下滑，支撑整体营收增长4.96%。
- **[投资性房地产减值]** -> [利润承压]: 受房地产市场下行影响，计提投资性房地产减值准备5185万元，是导致公司持续亏损的核心拖累因素。
- **[传媒文化业务项目延迟]** -> [收入下滑]: 部分大型项目实施周期长、验收审批流程繁琐，导致该板块收入同比下降5.67%。
- **[应收账款管理加强]** -> [经营现金流改善]: 销售回款大幅增加，经营活动现金流净额由负转正，从-2649万元增至4798万元。
- **[研发投入优化与股权激励费用下降]** -> [研发费用减少]: 部分项目进入后期、研发效率提升及股权激励费用下降，研发费用同比减少22.89%。
- **[BlackEye多模态大模型商业化]** -> [新业务突破]: 推出BlackEye Vision机器人遥操系统，实现从0到1的商业化落地，切入具身智能新赛道。
- **[原材料价格上涨]** -> [毛利率下降]: 服务器、显卡等硬件采购成本上升，导致整体毛利率同比下降3.65个百分点。

## 风险警告
公司连续三年亏损，2025年归母净利润-9131万元，且母公司未分配利润为-8047万元，不满足分红条件。核心风险在于：传媒文化基本盘增长乏力，收入同比下降5.67%，而新业务（工业与卫星、机器人）尚未形成规模化收入，整体营收增长高度依赖单一的车载智能座舱业务，存在结构性失衡风险。

财务风险不容忽视。公司短期借款同比大增61.07%至1.53亿元，而货币资金虽有改善但仍需警惕。更关键的是，公司对投资性房地产计提了5185万元大额减值，若房地产市场持续低迷，后续仍有减值风险。此外，应收账款管理虽有改善，但若客户资信恶化，坏账风险仍存。公司处于战略转型期，新业务商业化落地速度与盈利能力是决定能否扭亏的关键。
