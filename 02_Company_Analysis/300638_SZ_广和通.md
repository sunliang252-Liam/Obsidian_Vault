# 300638.SZ 深度透视

## 因果逻辑链
- **出售锐凌无线车载前装业务** -> 营业收入同比下降14.67%: 业务剥离导致收入规模缩减
- **出售锐凌无线业务及毛利率下降** -> 净利润同比下降48.05%: 核心业务被剥离，叠加产品结构变化和原材料成本波动导致毛利率下降，双重打击利润
- **产品结构向解决方案业务倾斜** -> 解决方案收入同比增长133.36%: 公司战略重点转向高附加值解决方案，带来收入结构变化
- **持续研发投入** -> 发布多款新产品及解决方案: 研发投入5.09亿元，占营收7.28%，支撑产品创新
- **端侧AI及机器人市场需求增长** -> 解决方案业务高增长: 下游需求驱动公司拓展端侧AI和机器人解决方案
- **华南地区营收下降37.45%** -> 整体营收下降: 华南作为重要区域，其收入大幅下滑拖累整体表现
- **直销收入下降19.15%** -> 整体营收下降: 主要销售模式收入下滑影响整体收入
- **分销收入增长42.27%** -> 销售模式结构调整: 公司加强渠道拓展，分销占比提升

## 风险警告
公司面临核心业务剥离后的增长动力缺失问题，传统模组业务收入下滑，毛利率承压；研发投入高但商业化尚在早期，端侧AI和机器人业务尚未形成规模利润；境外收入占比高，汇率波动风险显著；库存量同比增加38.29%，存在去化压力。
