# 600308.SH 深度透视

## 因果逻辑链
- **[70万吨化学木浆项目投产]** -> [浆产品收入暴增114.79%]: 新产能释放，但成本同步上升，毛利率改善有限。
- **[新闻纸需求持续萎缩]** -> [新闻纸收入下降19.81%]: 电子传媒冲击导致行业性衰退，公司被迫进行产品结构调整。
- **[液氯处置费用激增]** -> [销售费用同比上升48.58%]: 化工副产品液氯市场低迷，企业需支付费用处置，侵蚀利润。
- **[应收账款坏账准备计提比例提高]** -> [信用减值损失同比暴增838%]: 公司对下游客户回款风险预期恶化，大幅计提减值，直接导致净利润转负。
- **[造纸主业毛利率极低]** -> [扣非净利润连续三年为负]: 文化纸、铜版纸等核心产品毛利率仅1%-2%，主业盈利能力薄弱。
- **[化工板块贡献主要利润]** -> [化工子公司净利润1.58亿元]: 化工业务是公司唯一稳定盈利来源，对冲了造纸业务的亏损。
- **[存货库存上升]** -> [经营活动现金流净额下降48.93%]: 产成品积压占用资金，现金循环效率降低。

## 风险警告
公司核心风险在于造纸主业已陷入“增收不增利”甚至“亏损”的困境。2025年扣非净利润为-1.09亿元，连续三年为负，表明主营业务已丧失造血能力。尽管70万吨浆项目投产，但浆产品毛利率仅13.34%，且成本同步大增，难以扭转颓势。更严峻的是，公司对下游回款能力信心不足，大幅计提信用减值损失，这可能是行业性信用风险暴露的前兆。

化工业务是公司唯一的利润支柱，但其主要产品液碱、液氯价格波动剧烈，2025年液氯市场均价为负值，导致公司需支付高额处置费。若未来化工行业景气度下行，公司将失去最后的利润缓冲垫。此外，公司资产负债率攀升至42.6%，短期借款与一年内到期非流动负债合计超23亿元，而经营现金流大幅萎缩，短期偿债压力不容忽视。
