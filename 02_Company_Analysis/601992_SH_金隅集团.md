# 601992.SH 深度透视

## 因果逻辑链
- **[房地产行业深度调整]** -> [地产开发及运营板块收入暴跌64.88%]: 全国房地产开发投资同比下降17.2%，公司房屋销售结转面积腰斩51.77%，导致地产板块收入从327亿骤降至115亿。
- **[地产板块巨亏拖累整体业绩]** -> [归母净利润亏损10.09亿元]: 地产板块利润总额从盈利11.53亿转为亏损1.86亿，同比减少13.39亿元，是公司整体亏损的核心原因。
- **[资产处置与公允价值变动]** -> [非经常性损益掩盖主业亏损]: 资产处置收益20.03亿、投资性房地产公允价值变动4.01亿等非经常性损益合计25.79亿，若剔除，扣非净利润亏损高达35.88亿元。
- **[水泥业务成本改善]** -> [绿色建材板块利润扭亏为盈]: 水泥及熟料综合毛利率同比提升5.01个百分点至20.88%，主要得益于煤炭等燃料成本下降，推动板块利润从亏损6.97亿转为盈利2.18亿。
- **[大宗商品贸易业务]** -> [营收规模庞大但利润微薄]: 大宗商品贸易收入389亿，占营收43%，但毛利率仅0.24%，对利润贡献极小，且占用大量资金。
- **[融资成本优化]** -> [财务费用同比下降5.99%]: 公司累计加权融资成本降至2.8%，成功发行多期低利率债券，有效控制了利息支出。
- **[经营活动现金流大幅改善]** -> [现金流由负转正至11.86亿元]: 主要得益于国际贸易业务现金净流量同比增加，扭转了上一年-53.16亿元的巨额净流出局面。

## 风险警告
**核心风险在于地产板块的持续失血与主业盈利能力的严重不足。** 公司2025年归母净利润亏损10.09亿元，而扣非净利润亏损更是高达35.88亿元，意味着剔除资产出售、政府补贴、投资性房地产重估等非经常性收益后，公司核心经营业务（水泥+地产+贸易）处于深度亏损状态。地产板块收入暴跌65%，结转面积腰斩，叠加行业下行周期，短期内难以看到反转迹象，将持续成为公司利润的最大拖累。

**资产质量与现金流存在隐忧。** 公司总资产2636亿，但净资产仅710亿，资产负债率高达73%。尽管经营活动现金流有所改善，但公司仍背负巨额债务，担保总额占净资产比例达33%。同时，公司递延所得税资产大幅减少34.9%，显示对未来盈利预期趋于谨慎。在行业需求持续疲软、地产市场未见底的情况下，公司面临资产减值、资金周转及债务压力等多重风险。
