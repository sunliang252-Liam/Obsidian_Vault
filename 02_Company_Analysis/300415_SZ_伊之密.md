# 300415.SZ 深度透视

## 因果逻辑链
- **[行业景气度回升 + 新产品放量]** -> [营收增长19.46%]: 下游汽车、家电、医疗等行业需求回暖，叠加公司LEAP系列超大型压铸机、半固态镁合金注射成型机等新产品订单快速增长，共同驱动收入规模扩大。
- **[收入增长 + 规模化效应]** -> [净利润增长16.58%]: 营收增长带来规模效益，毛利率保持稳定，使得利润增速与收入增速基本匹配。
- **[全球化布局深化]** -> [海外收入增长29.67%]: 公司在土耳其、印尼等地设立子公司，海外服务网点达86个，本地化运营能力提升，推动海外市场成为重要增量。
- **[研发投入持续]** -> [高端产品突破]: 超亿元级研发投入和900余人研发团队，支撑了LEAP10000T超大型压铸机、FF30M微型精密注塑机等高端产品的交付，巩固技术壁垒。
- **[产能扩张]** -> [支撑未来增长]: 五沙第三工厂稳定运行，浙江南浔华东生产基地一期封顶，多基地协同布局为后续订单交付和市场份额提升提供产能保障。
- **[下游结构变化]** -> [压铸机业务高增33%]: 新能源汽车轻量化需求及半固态镁合金注射成型机订单爆发，推动压铸机业务成为增长最快的板块。
- **[数字化与精益制造]** -> [运营效率提升]: YIZUMI 4.0智能制造和精益管理体系，将设备数据转化为生产力，在收入增长的同时控制了成本，维持了毛利率稳定。

## 风险警告
**宏观经济与下游需求周期性波动风险**：公司产品与汽车、家电、3C等下游行业固定资产投资高度相关。若全球经济放缓或下游行业景气度下行，将直接导致订单减少和业绩下滑。当前高增长部分依赖于新能源汽车和医疗等特定领域的资本开支，需警惕需求集中度风险。

**市场竞争加剧与汇率波动风险**：注塑机、压铸机行业竞争激烈，面临恩格尔、海天国际等国内外强敌。若公司不能持续保持技术领先或成本优势，可能面临市场份额和毛利率被侵蚀的风险。同时，公司近30%收入来自海外，以美元结算为主，人民币升值将直接削弱出口竞争力并产生汇兑损失，对利润造成冲击。
