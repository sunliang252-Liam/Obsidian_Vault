# 300112.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧，毛利率承压]** -> [净利润亏损]: 2025年毛利率41.84%，同比减少3.55个百分点，直接导致毛利额下降，是亏损的核心原因。
- **[子公司成都安可信业绩大幅下滑]** -> [商誉减值]: 成都安可信净利润由盈转亏（-7,109万元），触发商誉减值656万元，加剧了整体亏损。
- **[研发投入高企，但短期效益未显]** -> [费用刚性]: 研发费用率维持9.53%高位（9,830万元），新产品市场化效益尚未释放，对当期利润形成压制。
- **[下游需求结构性分化]** -> [收入增长停滞]: 营业收入10.31亿元，同比仅增0.01%，传统工业领域需求疲软，新兴领域拓展尚未形成规模。
- **[信用减值损失扩大]** -> [利润侵蚀]: 2025年计提信用减值损失1,633万元，同比增加135%，反映下游客户回款压力增大。
- **[资产减值损失持续]** -> [利润侵蚀]: 除商誉外，存货跌价等资产减值损失1,422万元，进一步压缩利润空间。
- **[经营活动现金流净额下降]** -> [现金流压力]: 经营活动现金流净额1,551万元，同比下降31.72%，主因采购及人工现金支出增加超过销售回款。
- **[可转债利息费用高企]** -> [财务费用增加]: 财务费用1,655万元，同比增加64.87%，主要系可转债利息支出及利息收入减少，加重财务负担。

## 风险警告
**核心风险在于核心子公司业绩崩塌与商誉减值压力。** 全资子公司成都安可信（贡献主要营收）净利润从2024年的639万元骤降至-7,109万元，直接导致公司整体亏损。公司账面商誉仍有3,143万元，若安可信或特恩达等子公司经营持续恶化，未来仍有进一步减值风险，将直接冲击净资产。

**第二重风险是行业竞争加剧导致的盈利能力持续恶化。** 公司毛利率连续下滑，从2023年的45%以上降至2025年的41.84%，且研发、销售等费用刚性增长，导致扣非净利润连续两年亏损。若下游设备更新、国产替代等政策红利释放不及预期，公司可能陷入“增收不增利”甚至“收入利润双降”的困境。此外，公司可转债余额高达2.26亿元，利息费用对利润的侵蚀将持续存在。
