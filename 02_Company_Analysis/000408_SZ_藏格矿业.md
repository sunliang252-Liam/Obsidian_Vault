# 000408.SZ 深度透视

## 因果逻辑链
- **[紫金矿业入主赋能]** -> [治理结构升级与业绩跃升]: 紫金矿业成为控股股东后，全面导入其全球一流的矿业管理标准与运营体系，重塑“简洁、规范、高效”的管控模式，直接推动了公司治理效率、成本控制能力和资源开发节奏的显著提升。
- **[参股巨龙铜业业绩爆发]** -> [归母净利润同比大增49.32%]: 巨龙铜业二期工程投产，铜矿产量跃升至19.38万吨，贡献投资收益27.82亿元，占公司归母净利润的72.23%，成为公司利润增长的绝对核心引擎。
- **[氯化钾量价齐升与成本下降]** -> [钾肥板块收入增长33.42%]: 受益于全球钾肥供应偏紧和国内春耕需求，氯化钾全年均价同比上涨28.57%；同时公司通过技术革新和精细化管理，销售成本同比下降17.60%，实现量价利齐升。
- **[西藏麻米错盐湖获采矿证]** -> [锂板块未来增长极确立]: 麻米错盐湖成功取得《采矿许可证》，首期5万吨碳酸锂项目进入建设阶段，预计2026年下半年投产，为公司锂业务打开了从1万吨到6万吨以上的产能跃升空间。
- **[老挝钾盐矿资源储量确认]** -> [海外资源基地雏形初现]: 公司在老挝获批氯化钾资源总量达9.84亿吨，为未来200万吨/年产能规划奠定了坚实的资源基础，有望打破国内钾资源瓶颈，形成国内外产能协同。
- **[碳酸锂停产87天]** -> [锂盐产销量下滑但影响有限]: 因矿权延续手续，碳酸锂产线临时停产87天，导致全年产销量同比下降，但凭借扎实的工艺和成本优势，该板块净利润占比仅3.20%，对公司整体业绩冲击较小。
- **[主动核减产能与优化结构]** -> [氯化钾库存下降48.53%]: 面对资源品位波动，公司主动优化产能结构，全年产量103.32万吨，销量108.43万吨，实现去库存，体现了稳健的经营策略。

## 风险警告
**核心风险在于对巨龙铜业投资收益的过度依赖。** 2025年公司归母净利润38.52亿元中，来自巨龙铜业的投资收益高达27.82亿元，占比超过72%。这意味着公司业绩与单一参股公司的铜矿产量、铜价及运营状况高度绑定。若未来铜价大幅回调，或巨龙铜业三期工程推进不及预期，公司利润将面临剧烈波动，钾锂主业尚无法完全对冲此风险。

**锂业务面临价格与产能释放的双重不确定性。** 碳酸锂价格在经历2025年震荡后，行业供给仍趋于宽松，价格上行空间有限。同时，承载未来增长希望的麻米错盐湖项目地处西藏高海拔地区，建设周期、成本控制及后续运营均存在较大不确定性，能否在2026年下半年如期投产并实现盈利，是公司锂板块能否兑现增长预期的关键变量。
