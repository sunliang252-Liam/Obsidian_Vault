# 002825.SZ 纳尔股份 深度透视

## 因果逻辑链
- **[汽车功能膜业务高增长]** -> [营收结构优化]: 汽车功能膜营收同比增长26.89%，占比从24.49%提升至29.80%，成为第二增长极，拉动整体毛利率提升。
- **[海外布局与供应链整合]** -> [抵御地缘风险]: 利用泰国工厂等海外产能，对冲中美关税战影响，使海外收入占比虽降至46.46%，但境外毛利率逆势提升3.30个百分点。
- **[非经常性损益大幅波动]** -> [扣非净利润下滑]: 归母净利润增长11.56%，但扣非净利润下降15.63%，主要因非流动资产处置收益（3862万）等非经常性项目贡献了大部分利润增量。
- **[研发投入持续加码]** -> [产品向上战略]: 研发费用同比增长10.75%至1.18亿，聚焦汽车功能膜、电子光学膜等高端产品，支撑“产品向上”战略，提升高附加值产品比重。
- **[数字化与精细化管理]** -> [成本控制与效率提升]: 持续投入数字化运营系统，在行业“内卷”背景下，数码喷印材料毛利率仍提升0.70个百分点，体现成本管控成效。
- **[并购拓展第二曲线]** -> [新能源材料布局]: 收购南通亿帆（磁性材料）并控股，同时布局锂电硅碳负极材料（多孔碳），目标2028年新能源材料收入占比超20%，打开成长天花板。
- **[股权激励绑定核心团队]** -> [人才稳定性]: 2025年推出新一期限制性股票激励计划，覆盖115人，将核心管理层利益与公司长期发展绑定，支撑战略落地。

## 风险警告
**核心风险在于扣非净利润的持续下滑与海外市场的不确定性。** 2025年扣非净利润同比下降15.63%，显示公司主营业务盈利能力在行业竞争加剧背景下承压。同时，公司海外收入占比近半，中美地缘关系、关税战及汇率波动是长期悬顶之剑，虽通过海外工厂和套保工具对冲，但无法完全消除风险。

**第二曲线拓展存在执行风险。** 公司通过并购进入磁性材料、锂电负极材料等新领域，但新业务与主业协同性尚待验证，且面临技术迭代、市场竞争及整合失败的风险。特别是氢能项目自2021年布局至今尚未形成规模收入，新赛道的投入可能拖累短期财务表现。
