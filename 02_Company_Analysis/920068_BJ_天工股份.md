# 920068.BJ 深度透视

## 因果逻辑链
- **[消费电子需求阶段性减少]** -> [营收与利润双降]: 2025年公司营收同比下降21.25%，归母净利润下降18.83%，核心原因是下游消费电子领域终端客户需求萎缩，导致线材等核心产品销量下滑。
- **[EB炉二期投产与废料循环]** -> [成本优化与ESG竞争力提升]: 二号EB炉热试成功，实现生产废料全面再利用，既降低生产成本，又满足客户对绿色供应链的要求，形成差异化竞争优势。
- **[天工钛晶设立与引入战投]** -> [投资收益增厚利润]: 公司设立合资公司天工钛晶布局粉末材料，后引入战略投资者导致公司失去控制权，剩余股权按公允价值重计量产生约2025万元投资收益，成为非经常性损益的主要来源。
- **[北交所上市募资]** -> [资产结构显著优化]: 公开发行股票募集资金约2.39亿元，使货币资金大增86.28%，资产负债率降至14.99%，财务结构极为稳健，为后续产能扩张提供充足弹药。
- **[航空航天与医疗认证突破]** -> [打开高端市场空间]: 公司先后通过EN9100D、GJB9001C及ISO13485等质量体系认证，并成为GE等客户的合格供应商，为进军航空航天和医疗等高端钛合金应用领域奠定基础。
- **[原材料海绵钛价格波动]** -> [毛利率承压]: 尽管营收下降，但毛利率从30.40%降至25.71%，主要受原材料价格波动及产品结构变化影响，显示出成本传导能力存在一定压力。
- **[核心客户高度集中]** -> [经营依赖风险]: 前五大客户销售占比高达71.11%，其中前两大客户贡献近47%营收，公司经营业绩高度依赖少数核心客户的订单稳定性。

## 风险警告
公司当前最大的风险在于对消费电子单一赛道的过度依赖。2025年营收与利润的双降已清晰表明，一旦下游终端客户需求波动，公司业绩将直接承压。尽管公司在航空航天、医疗等高端领域取得认证突破，但业务从认证到规模化放量仍需较长周期，短期内难以对冲消费电子领域的下行风险。此外，前两大客户合计贡献近半营收，客户集中度极高，任何核心客户的订单流失都将对公司造成重大冲击。

其次，原材料价格波动与行业竞争加剧构成双重挤压。海绵钛价格受国际金属市场影响波动剧烈，而中低端钛材市场竞争已趋于白热化，毛利率持续走低。公司若不能持续向高附加值产品转型，将面临市场份额被侵蚀和盈利能力下滑的风险。同时，公司控股股东持股比例高达67.63%，股权高度集中，存在不当控制的风险。
