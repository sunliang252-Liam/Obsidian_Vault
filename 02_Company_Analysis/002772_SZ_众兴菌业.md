# 002772.SZ 深度透视

## 因果逻辑链
- **[行业周期回暖]** -> [净利润暴增161.63%]: 2025年下半年食用菌行业企稳回暖，产品价格回升，直接推动公司盈利能力大幅改善。
- **[双孢菇量价齐升]** -> [核心利润来源]: 湖北众兴项目满产，叠加销售价格稳中有升，双孢菇收入增长15.74%，毛利率达36.74%，成为利润主要支柱。
- **[金针菇扭亏为盈]** -> [业绩弹性释放]: 金针菇价格下半年企稳回升，全年实现盈利，成本端降本增效（营业成本下降15.21%）贡献显著。
- **[财务费用有效降低]** -> [利润增厚]: 贷款利率下降及利息资本化增加，财务费用同比减少41.68%，直接增厚净利润。
- **[产能扩张与布局]** -> [未来增长预期]: 持续投资双孢菇及冬虫夏草项目，在建工程增长46%，为未来市场份额提升和产品多元化奠定基础。
- **[产品多元化战略]** -> [抗风险能力提升]: 推进冬虫夏草生态繁育项目，新增收入2187万元，优化产业结构，降低对单一品种的依赖。

## 风险警告
**核心风险在于行业周期与产品价格的高度不确定性。** 公司2025年业绩暴增主要依赖下半年食用菌行业回暖，金针菇和双孢菇价格回升。但食用菌价格受供需、季节、替代品等多重因素影响，波动剧烈。若未来行业再次陷入产能过剩或需求疲软，公司盈利能力将面临急剧下滑风险，高增长难以持续。

**新业务拓展与产能消化存在重大不确定性。** 公司正大举投资冬虫夏草工厂化生态繁育项目，该业务受政策、技术、市场接受度等多重因素影响，存在投资回报不达预期的风险。同时，多个双孢菇基地新建或扩建，若市场增速不及产能扩张速度，可能导致产能利用率下降、折旧压力增大，侵蚀利润。
