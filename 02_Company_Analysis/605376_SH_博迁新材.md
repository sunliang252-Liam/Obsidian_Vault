# 605376.SH 深度透视

## 因果逻辑链
- **[AI服务器与高端MLCC需求爆发]** -> [镍基产品营收增长25.88%]: AI算力提升驱动MLCC向小型化、高容值升级，拉动超细镍粉需求，公司小粒径镍基产品出货量增长。
- **[光伏降本与银价飙升]** -> [铜基产品出货占比攀升]: 银价全年涨幅144.82%，光伏电池加速贱金属替代，公司更低银含量的银包铜粉出货占比持续提升。
- **[产品结构升级]** -> [毛利率大幅提升12.45个百分点]: 高附加值小粒径镍粉及铜基产品占比增加，带动金属粉体材料整体毛利率从22.96%升至35.41%。
- **[客户集中度高]** -> [前五大客户贡献78.32%营收]: 下游MLCC行业高度集中，公司深度绑定韩国、台湾等头部MLCC厂商，业绩依赖核心客户订单。
- **[产能扩张与原材料备货]** -> [经营活动现金流净额下降54.35%]: 为应对订单增长，公司大量采购镍块、铜棒等原材料，同时推进镍粉产线及厂房建设，现金流出大幅增加。
- **[镍基产品技术壁垒]** -> [主导行业标准制定]: 公司作为唯一起草单位制定电容器电极镍粉行业标准，技术护城河深厚，新进入者难以短期突破。
- **[合金粉体技术突破]** -> [合金产品营收增长255%]: AI算力设备功耗提升推动电感从铁氧体转向金属软磁粉芯，公司多款新型合金粉体通过客户验证并上量。
- **[H股上市计划]** -> [构建“A+H”双资本平台]: 公司计划2026年推进H股发行，旨在拓宽融资渠道、深化全球化布局，提升国际竞争力。

## 风险警告
**客户高度集中与下游周期性波动风险**：公司前五大客户销售额占比高达78.32%，深度绑定少数MLCC巨头。2022-2023年消费电子需求下滑曾导致公司业绩大幅亏损，若未来宏观经济波动或下游MLCC行业再次进入去库存周期，公司营收和利润将面临剧烈波动，单一客户订单减少即可对业绩造成重大冲击。

**原材料价格波动与成本传导滞后风险**：公司主要原材料镍、铜、银均为大宗商品，价格波动剧烈。2025年银价暴涨144.82%虽推动铜基产品需求，但也直接推高生产成本。公司虽调整定价模式，但历史上曾因原材料价格急剧攀升而无法及时传导成本，导致毛利率受损。若未来金属价格大幅上涨而产品售价调整滞后，将严重侵蚀利润空间。

**激进扩张带来的现金流与资产减值风险**：公司2025年经营活动现金流净额同比下降54.35%，同时短期借款激增225%、在建工程增长237%，显示公司正以高杠杆支撑产能扩张。若下游需求增速不及预期，大规模资本开支将导致产能利用率下降、存货积压，引发存货跌价和固定资产减值风险，叠加财务费用上升，可能使公司陷入“增收不增利”的困境。
