# 603041.SH 深度透视

## 因果逻辑链
- **[吉林基地产能爬坡，折旧与运营成本高企]** -> [净利润下滑11.65%]: 新投产的有机胺催化剂项目（2.5万吨/年）及二甘醇胺-吗啉装置（8000吨/年）产能利用率仅28.21%和14.87%，新增固定资产折旧及运营成本侵蚀利润，导致营收微增2.81%但归母净利润下降11.65%。
- **[原材料成本上涨，成本传导滞后]** -> [毛利率大幅下滑7.08个百分点]: 主要原材料（烯丙醇聚醚、有机硅单体等）价格波动，但产品价格向下游传导存在滞后性，导致营业成本增速（13.05%）远超营收增速（2.81%），综合毛利率从28.92%降至21.84%。
- **[“匀泡剂+催化剂”双产品协同]** -> [客户粘性增强，海外营收占比超40%]: 公司从单一匀泡剂供应商转型为综合助剂解决方案提供商，通过产品组合销售提升客户价值，海外营收达2.65亿元，占比超40%，成为唯一加入欧洲软质聚氨酯泡沫生产商协会（EUROPUR）的中国企业。
- **[硬泡助剂市场承压，软泡助剂增长强劲]** -> [产品结构分化]: 硬泡助剂营收微降0.28%，毛利率下滑10.13个百分点，受下游建筑、家电领域需求疲软及竞争加剧影响；软泡助剂营收增长17.93%，毛利率提升1.6个百分点，受益于高端床垫、汽车内饰等需求拉动。
- **[经营活动现金流大幅改善]** -> [现金流质量提升]: 经营活动现金流净额同比增长75.73%至1.37亿元，主要得益于加强资金管理、改善付款结构及收到增值税留抵退税，显示运营效率提升。
- **[吉林子公司持续亏损]** -> [拖累合并报表业绩]: 美思德（吉林）公司2025年亏损7827万元，主要因产能爬坡期折旧摊销大、固定成本高，是公司净利润下滑的核心拖累项。
- **[非经常性损益依赖度高]** -> [扣非净利润降幅更大]: 2025年非经常性损益1162.57万元（主要为理财收益），占归母净利润20.5%，扣非后净利润同比降幅达17.78%，显示主业盈利能力承压。

## 风险警告
**核心风险：吉林基地产能爬坡不及预期，持续亏损吞噬利润。** 公司吉林基地有机胺催化剂及二甘醇胺-吗啉项目产能利用率极低（28.21%/14.87%），2025年子公司亏损7827万元。若下游需求增长乏力或市场竞争加剧，产能无法有效释放，新增折旧将持续压制公司整体盈利能力，甚至导致资产减值风险。

**次要风险：原材料价格波动与毛利率持续承压。** 公司直接材料成本占比超70%，主要原材料价格波动剧烈。2025年毛利率已大幅下滑7个百分点至21.84%，若原材料价格持续上涨而产品提价能力不足，毛利率可能进一步恶化。此外，公司硬泡助剂业务毛利率仅15.59%，且仍在下降，显示该领域竞争激烈，盈利空间收窄。
