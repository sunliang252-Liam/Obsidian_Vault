# 301349.SZ 深度透视

## 因果逻辑链
- **[下游需求爆发]** -> [营收增长43.28%]: 新能源汽车快充车型与储能市场强劲增长，带动负极包覆材料出货量同比大增39.62%。
- **[原材料成本下降]** -> [毛利率改善]: 原油价格走低叠加供应链优化，乙烯焦油采购成本下降，推动负极包覆材料毛利率同比提升6.19个百分点。
- **[产能规模扩张]** -> [市占率提升]: 南北双基地合计7万吨/年产能，叠加104.5%的高产能利用率，巩固了行业龙头地位。
- **[中高端产品结构升级]** -> [盈利能力修复]: 适配“快充”“超充”的差异化产品销量增加，推动产品均价略有上升，实现扭亏为盈。
- **[副产品销量大增]** -> [收入贡献提升]: 炭黑原料油和裂解萘馏分出货量分别增长84.05%和60.80%，合计贡献超55%的营业收入。
- **[非经常性损益支撑]** -> [净利润扭亏]: 理财产品收益及政府补助合计约3,544万元，占利润总额的64.5%，是归母净利润转正的关键。
- **[存货与应收账款激增]** -> [经营现金流恶化]: 存货同比增加37.5%，应收账款同比增加33%，导致经营活动现金流净额为-2.29亿元，与净利润严重背离。

## 风险警告
**盈利质量堪忧，现金流持续失血。** 公司2025年归母净利润虽扭亏为盈，但扣非净利润仅946.66万元，盈利高度依赖理财收益等非经常性损益。更严重的是，经营活动现金流净额为-2.29亿元，同比恶化超20倍，主因是存货和应收账款大幅膨胀。这种“纸面利润”的可持续性存疑，若下游需求放缓或客户回款不力，公司将面临巨大的流动性压力。

**产能扩张与业绩承诺的双重压力。** 公司仍在通过收购福建中碳等方式继续扩张产能，但行业竞争加剧，负极包覆材料价格承压。同时，收购成都昱泰的业绩承诺（2023-2026年累计净利润不低于1.25亿元）目前完成率仅67.24%，未来两年需完成剩余约4,095万元，压力巨大。若业绩不达标，将面临大额现金补偿，进一步侵蚀公司本就脆弱的现金流。
