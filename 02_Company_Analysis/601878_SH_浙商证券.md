# 601878.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度大幅提升]** -> [经纪业务收入增长41.39%]: 2025年A股日均成交额同比上升62.7%，直接带动公司代理买卖证券佣金收入激增。
- **[并表国都证券]** -> [总资产增长45.90%，归母净利润增长24.87%]: 报告期内完成对国都证券的控股合并，新增合并资产381亿元，贡献利润6.95亿元，是公司规模与业绩跃升的核心外延驱动力。
- **[自营投资业务精准把握市场]** -> [投资收益增长92.71%]: 权益、固收及衍生品投资在A股震荡上行与债市高波动中均取得正收益，收入结构进一步优化。
- **[融资融券业务规模扩张]** -> [利息净收入增长30.74%]: 两融余额达328.27亿元，市场份额提升至1.292%，成为利息收入增长的主要来源。
- **[债券承销规模连续三年超千亿]** -> [投行业务收入增长10.91%]: 公司债承销规模位列行业第12位，债券业务是投行收入的核心压舱石。
- **[财富管理转型深化]** -> [金融产品保有量增长25.26%]: 买方投顾模式推进与“鑫管家”品牌建设，推动代销金融产品业务规模与收入稳步增长。
- **[研究业务影响力跃升]** -> [赋能全业务链协同]: 研究团队在主流评选中获奖121项，通过“四维一体”服务体系对内赋能投资、投行，对外提升机构客户覆盖。

## 风险警告
公司业绩与资本市场走势高度正相关。2025年业绩爆发式增长主要受益于A股成交额同比激增63.4%及两融余额大幅扩张。若未来市场活跃度回落，经纪、信用及自营业务收入将面临同步下滑压力，业绩波动性极大。此外，公司总资产因并购扩张至2248亿元，但负债率同步升至78.9%，杠杆水平显著提升，流动性管理压力增大。

并购整合风险不容忽视。公司并表国都证券后，商誉激增至6.82亿元，且国都证券在资管、投行等条线仍面临业务转型压力。若整合不及预期，或国都证券经营持续承压，将面临商誉减值风险，直接侵蚀利润。同时，公司业务及管理费同比增长33.25%，远超营收增速，成本控制能力面临考验。
