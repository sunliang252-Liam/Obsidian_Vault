# 000001.SZ 深度透视

## 因果逻辑链
- **[贷款利率下行与结构调整]** -> [净息差收窄至1.78%]: 市场利率下行、LPR重定价及提升优质客群占比，导致贷款收益率下降67个基点，但负债成本优化42个基点，部分对冲了息差压力。
- **[负债成本优化]** -> [净息差降幅放缓]: 通过管控高成本存款、提升活期存款占比（日均余额同比+5.8%），吸收存款平均付息率降至1.65%，有效缓解了资产端收益率下行对息差的冲击。
- **[零售贷款结构调整]** -> [个人贷款不良率下降0.16个百分点]: 主动压降信用卡及消费贷规模，提升住房按揭等抵押类贷款占比（62.9%），优化客群结构，使零售资产质量改善。
- **[对公贷款扩张与行业分化]** -> [企业贷款不良率上升0.17个百分点]: 加大对实体经济的信贷投放（一般企业贷款+9.2%），但部分存量房地产业务风险暴露，导致对公不良率小幅抬升。
- **[降本增效与减值减少]** -> [净利润降幅小于营收]: 业务及管理费同比下降5.9%，信用减值损失同比大幅下降17.9%，成本管控和风险出清有效缓冲了营收下滑对利润的冲击。
- **[科技金融与绿色金融发力]** -> [对公贷款结构优化]: 科技企业贷款（+9.8%）和绿色贷款（+12.2%）实现较好增长，成为对公业务增长的新引擎，推动资产结构向政策支持领域倾斜。
- **[综合金融与银保业务]** -> [财富管理收入增长]: 依托平安集团生态，代理个人保险收入同比大增53.3%，带动财富管理手续费收入增长15.8%，成为非息收入的重要稳定器。

## 风险警告
**核心风险在于净息差持续收窄与资产质量的结构性压力。** 尽管负债成本优化，但资产端收益率下行速度更快，净息差已降至1.78%，且未来仍有下行压力。同时，企业贷款不良率因房地产等部分行业风险暴露而上升，若宏观经济复苏不及预期，对公资产质量可能进一步承压，侵蚀利润。

**另一风险是拨备覆盖率大幅下滑。** 拨备覆盖率从250.71%降至220.88%，下降近30个百分点，虽然仍处监管要求之上，但缓冲垫明显变薄。这反映出在营收承压背景下，银行通过消耗拨备来平滑利润，若未来不良生成加速，风险抵补能力将面临考验。
