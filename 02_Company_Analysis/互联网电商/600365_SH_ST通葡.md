# 600365.SH 深度透视

## 因果逻辑链
- **[电商平台营收大幅下滑]** -> [总营收下降21.48%]: 核心子公司九润源电商业务收入同比减少26.16%，拖累整体营收从8.69亿降至6.83亿。
- **[电商业务毛利率极低]** -> [整体盈利能力恶化]: 电商平台毛利率仅8.19%，且同比下降2.53个百分点，导致公司增收不增利，扣非净利润亏损扩大至6342万元。
- **[历史违规担保计提预计负债]** -> [非经常性损失扩大]: 原实控人违规担保事项导致计提预计负债约8945万元，是造成归母净利润亏损8342万元的主要原因之一。
- **[应收账款保理业务模式]** -> [经营现金流持续为负]: 公司将应收账款进行保理融资，回款直接进入保理公司，导致经营活动现金流净额长期为负（-4.09亿），但筹资活动现金流为正。
- **[葡萄酒业务逆势增长]** -> [业务结构优化初显]: 自制葡萄酒营收同比增长12.40%，毛利率47.07%，显示核心主业在行业下滑背景下具备一定韧性。
- **[客户与供应商高度集中]** -> [经营风险显著]: 前五大客户销售额占比77.47%（京东占62.93%），前五大供应商采购额占比87.84%（贵州习酒占62.03%），对单一渠道和供应商依赖度过高。
- **[资产受限严重]** -> [财务灵活性受限]: 因保理融资、司法冻结等原因，大量应收账款、存货、固定资产及股权受限，影响公司资产周转和融资能力。

## 风险警告
公司面临的核心风险是**电商业务模式脆弱性与历史遗留问题的双重挤压**。电商平台业务（九润源）贡献了85%以上的营收，但毛利率极低（8.19%），且严重依赖京东单一渠道（占营收62.93%）。一旦与京东的合作关系或平台政策发生不利变化，公司营收将遭受毁灭性打击。同时，该业务通过保理融资维持现金流，导致经营现金流长期为负，财务结构极不稳定。

**历史违规担保的“地雷”尚未完全拆除**。公司因原实控人违规担保，已累计计提预计负债8945万元，且相关诉讼仍在进行中。虽然公司已起诉原实控人，但一审败诉，追偿前景不明。这笔巨额或有负债持续侵蚀公司净资产（已降至2.3亿元），并导致大量资产被司法冻结，严重制约了公司融资能力和业务拓展空间。公司股票简称“ST通葡”，本身就反映了其面临的严峻风险。

**公司简介（F10 原文）**

> 通化葡萄酒股份有限公司(以下简称“通葡股份”)始建于1937年,是中国最早的葡萄酒生产企业之一,坐落于吉林通化,背靠长白山主原料基地、面临鸭绿江的独特产区集安——与法国波尔多同处北纬41°黄金酿酒带。作为“中华老字号”与“中国驰名商标”企业,其地下酒窖拥有亚洲第一大橡木桶集群,2013年被列为全国重点文物保护单位,2018年入选首批中国工业遗产保护名录。通葡股份深耕山葡萄酒领域88年,依托鸭绿江河谷独特的风土条件,成就了东方葡萄酒的独特风骨。从1949年成为开国大典专用酒,到1959年被周恩来总理命名为“国庆酒”,再到尼克松、撒切尔夫人访华等重要外事场合的指定用酒,“红色国酒”底蕴贯穿共和国发展史。作为中国第一支冰酒与波特酒的诞生地,公司产品涵盖以山葡萄为原料的甜酒、冰酒、干酒、烈酒等多个类别,在IWC、Decanter等国际赛事中斩获数十项金银大奖,也曾远销30多个国家和地区。2001年1月,通化葡萄酒股份有限公司股票在上海证券交易所正式挂牌上市(股票代码:600365),成为中国第二家葡萄酒企业上市公司。通化葡萄酒作为中国最早的葡萄酒生产企业之一,拥有亚洲第一大橡木桶集群的地下酒窖。2013年,被商务部评定为”全国重点保护文物“。通化葡萄酒以岁月赋予的不可复制的传奇风情成为“红色过酒”的代表。对山葡萄酒品质的孜孜探索,让通化葡萄酒得到了社会各界最广泛的关爱与支持,成为通化葡萄酒绵延80余年不绝的成长动力。通葡股份以“做百年企业,酿中国味道,用山葡萄酒点亮世界葡萄酒新坐标”为企业愿景,以“传承山葡萄匠心技艺,以创新赋予经典新生,用每一滴醇酿连接欢聚时刻,传递自然与人文的喜悦,助力产区可持续发展”为企业使命,坚守使用中国本土山葡萄为原料优势,酿造出更适合中国消费者餐饮习惯的葡萄佳酿,打造成为世界葡萄酒版图上闪耀的明星品牌。酒以城命名,城以酒传世,品的是酒的味道,更是一座城市的品质,让甜美主义的通葡佳酿成为中国消费者幸福生活元素。
