# 300037.SZ 深度透视

## 因果逻辑链
- **[储能与动力电池需求爆发]** -> [电池化学品营收增长30.57%]: 全球储能市场从政策驱动转向市场驱动，叠加新能源汽车渗透率提升，带动锂离子电池电解液销量大幅增长。
- **[国际氟化工巨头退出]** -> [有机氟化学品业务结构优化]: 下游客户加速供应链切换，公司含氟冷却液、清洗剂等高附加值产品出货量持续增长，对冲了医药中间体竞争加剧的影响。
- **[AI与数字基建拉动]** -> [电子信息化学品营收增长29.14%]: AI服务器对高比容电容器、超低阻抗MLPC及高性能存储IC的需求提升，带动公司电容化学品和半导体化学品销量增长。
- **[产业链一体化布局]** -> [成本控制与供应安全]: 通过投资石磊氟材料（六氟磷酸锂）、自建新型锂盐和添加剂产能，构建从核心材料到电解液的全体系布局，降低综合成本。
- **[全球化生产基地扩张]** -> [海外市场就近交付能力]: 波兰、马来西亚基地建设及美国、中东项目筹建，实现本地化生产，提升对海外头部客户的响应速度与粘性。
- **[研发投入持续高增]** -> [技术壁垒与产品迭代]: 研发费用同比增长27.75%，聚焦固态电解质、钠离子电池电解液、含氟聚合物等前沿领域，巩固技术领先优势。
- **[组织架构调整]** -> [协同效应与效率提升]: 合并电容化学品与半导体化学品事业部为电子信息化学品事业部，整合资源，提升一站式解决方案输出能力。

## 风险警告
**核心风险在于电池化学品业务的周期性波动与竞争加剧。** 尽管2025年营收增长强劲，但该业务毛利率同比下降1.33个百分点，反映出行业产能扩张带来的价格战压力。若下游需求增速放缓或上游原材料价格剧烈波动，公司盈利能力可能承压。此外，海外贸易摩擦及部分国家推动关键矿产“去中国化”，可能影响公司海外市场拓展及上游锂、氟资源获取的稳定性。

**另一重大风险是PFAS（全氟和多氟烷基物质）法规的潜在冲击。** 欧洲化学品管理局已提出全面限制PFAS的提案，而公司有机氟化学品及部分电池化学品可能涉及相关物质。若该法规最终实施，将直接导致部分产品被禁售或需投入巨额成本进行替代品研发，对公司有机氟化学品业务的长期增长构成根本性威胁。公司虽已启动替代品研发，但技术路线的不确定性和客户验证周期较长，短期内难以完全对冲此风险。
