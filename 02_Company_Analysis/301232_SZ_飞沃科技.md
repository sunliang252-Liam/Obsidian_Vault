# 301232.SZ 深度透视

## 因果逻辑链
- **[国内风电新增并网装机同比大幅增长]** -> [风电紧固件销量显著提升]: 下游需求旺盛直接拉动公司核心产品出货量，实现营收43.05%的同比增长。
- **[风机招标价格企稳回升 + 与核心客户优化定价]** -> [毛利率稳步改善]: 产品售价提升叠加成本控制，风电紧固件毛利率同比提升8.90个百分点至16.85%。
- **[钢材价格下行 + 深化精益生产与智能制造]** -> [单位生产成本降低]: 原材料成本下降与内部效率提升共同作用，营业成本增速（31.02%）显著低于营收增速（43.05%）。
- **[公司扭亏为盈]** -> [净利润实现3,778.98万元]: 2024年亏损1.57亿元，2025年实现盈利，核心驱动为收入增长与毛利率改善。
- **[并购成都灌航、成都新杉等公司]** -> [非风电业务营收同比增长144.38%]: 通过外延式并购快速获取技术、产能与客户资源，第二增长曲线取得阶段性突破。
- **[越南工厂建设完成 + 海外客户准入推进]** -> [海外业务规模化拓展奠定基础]: 产能与资质准备就绪，为未来海外市场放量提供支撑。
- **[风电塔筒业务顺利投产]** -> [产业链延伸至风电结构件]: 从单一紧固件拓展至塔筒，丰富产品矩阵，增强风电领域综合竞争力。
- **[应收账款净额高达13.34亿元]** -> [经营活动现金流净额为负（-1.01亿元）]: 收入快速增长但回款滞后，导致现金流与净利润严重背离，运营资金压力大。

## 风险警告
**核心风险在于现金流与盈利的严重背离。** 公司2025年净利润虽扭亏为盈，但经营活动现金流净额仍为-1.01亿元，连续三年为负。应收账款净额高达13.34亿元，占流动资产42.11%，且账龄结构恶化（信用减值损失达-2,873万元）。这种“纸面利润”背后是巨大的坏账风险和资金链压力，一旦下游客户回款放缓或出现坏账，公司可能迅速陷入流动性危机。

**第二增长曲线尚处“烧钱”阶段，存在持续拖累主业的可能。** 公司重点拓展的航空航天、燃气轮机等非风电业务，2025年营收占比仅2.94%，且处于未盈利状态。子公司苏州飞沃、越南精艺等亏损严重（合计亏损近7,000万元）。新业务技术壁垒高、认证周期长、订单不稳定，短期内难以贡献利润，反而会持续消耗公司宝贵的现金流和资源，存在“主业输血副业”的风险。
