# 920786.BJ 深度透视

## 因果逻辑链
- **[募投项目投产，生鲜乳放量]** -> [营收增长]: 奶牛养殖项目结项，日产鲜奶提升至410吨，生鲜乳销售收入同比增长22.27%，成为营收增长核心引擎。
- **[自然灾害导致甜菜减产]** -> [糖业板块萎缩]: 2024年灾害致2025年甜菜收购量减少28万吨，白砂糖收入同比骤降37.69%，拖累整体营收增速。
- **[期货投机巨亏及监管处罚]** -> [非经常性损益波动]: 2024年期货投资亏损3779万元，2025年停止投机后投资收益转正，但导致公司被证监会立案处罚，声誉受损。
- **[生鲜乳市场价持续低位]** -> [毛利率承压]: 尽管产量增加，但行业原奶价格低迷，公司整体毛利率从16.24%微降至15.79%，盈利能力未随产量同步提升。
- **[糖业成本飙升]** -> [子公司大幅亏损]: 甜菜含糖量降低及加工成本上升，导致敕勒川糖业净利润亏损3108万元，成为公司最大利润拖累点。
- **[售牛价格回升]** -> [生物资产处置损失减少]: 市场牛价上升，售牛毛利率同比大增104.54%，资产处置收益亏损同比收窄35.53%，直接增厚利润。
- **[高杠杆运营]** -> [财务费用高企]: 资产负债率61.37%，短期借款增加27%，全年财务费用4285万元，严重侵蚀经营利润。
- **[内控缺陷暴露]** -> [治理风险凸显]: 因期货交易内控缺失、信息披露违规，公司及高管被北交所、证监局多次处罚，暴露出公司治理的重大短板。

## 风险警告
**核心风险在于公司治理与内控的严重缺陷。** 公司因期货投机巨亏未及时披露，接连被北交所纪律处分、证监会立案调查并行政处罚，暴露出内部决策流程混乱、风险控制形同虚设。董事长党涌涛作为实际控制人，其个人决策风格与公司治理的制衡机制存在根本性冲突，这是比任何经营波动都更致命的“人治”风险。投资者需警惕类似违规事件再次发生的可能性。

**经营层面，公司面临“糖业失血”与“乳业微利”的双重挤压。** 糖业子公司因原料问题陷入巨额亏损，短期内难以扭转；而核心的乳业板块虽产量增长，却受制于行业性的原奶价格低迷，毛利率持续走低。同时，公司资产负债率高达61%，短期借款激增，财务费用高企，现金流状况恶化（经营现金流同比大降61%），高杠杆运营下任何经营波动都可能引发流动性危机。
