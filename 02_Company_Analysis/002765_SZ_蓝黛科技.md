# 002765.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升]** -> [动力传动业务收入增长19.98%]: 公司新能源减速器及电驱系统零部件配套规模扩大，成为核心增长引擎。
- **[产品结构优化（车载+工控占比提升）]** -> [触控显示业务毛利率改善4.71个百分点]: 高毛利的车载触控屏和工控产品占比提升，抵消了消费类模组收入下滑的影响。
- **[马鞍山新基地产能爬坡]** -> [子公司马鞍山蓝黛机械亏损5210万元]: 新设备及产线处于爬坡期，产能未充分释放，固定成本高企导致阶段性亏损。
- **[处置低效资产（电驱总成装配业务）]** -> [聚焦核心主业，优化资产结构]: 出售给立讯精密，减少非核心业务亏损，集中资源于高精密齿轴等优势环节。
- **[控股股东变更为江东产投（马鞍山国资）]** -> [公司治理结构重塑，获得国资背书]: 实控人变更为马鞍山市政府，带来战略资源与信用背书，但管理层面临整合过渡期。
- **[研发投入增长23.14%]** -> [新产品项目立项数大幅提升，量产转化率高]: 攻克强力珩齿刀具国产替代、超精磨等工艺，为未来增长储备技术。
- **[原材料价格波动]** -> [成本控制压力持续]: 钢材、铝材及ITO膜等原材料价格波动，直接挤压利润空间，公司通过价格联动协议和降本专项组应对。

## 风险警告
**核心风险在于双主业均面临激烈的市场竞争与盈利压力。** 动力传动业务虽受益于新能源浪潮，但马鞍山新基地产能爬坡导致巨额亏损，拖累整体利润；同时，传统燃油车零部件业务面临萎缩风险。触控显示业务在消费电子疲软背景下，虽向车载转型，但行业技术迭代快、客户集中度高，毛利率提升的可持续性存疑。

**财务风险不容忽视。** 公司存货和应收账款规模庞大，合计超20亿元，占总资产比例高。存货跌价准备（-7312万元）和信用减值损失（-826万元）持续侵蚀利润。此外，海外业务扩张带来的汇率波动风险，以及因控制权变更导致的管理层动荡与战略磨合，均是未来业绩的不确定因素。
