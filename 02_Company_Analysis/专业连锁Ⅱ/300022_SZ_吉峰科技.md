# 300022.SZ 深度透视

## 因果逻辑链
- **[低空经济战略升级]** -> [低空业务收入同比+109%]: 公司依托新实控人联合飞机集团资源，从代理销售转向“地方低空生态能力建设及运营”，切入万亿级新兴赛道。
- **[传统农机行业深度调整]** -> [农机流通收入同比-3.13%]: 传统品类需求疲软、同质化竞争加剧，公司核心流通业务承压，但凭借全国化网络维持了收入基本盘。
- **[会计估计变更（提高坏账计提比例）]** -> [信用减值损失同比+246%]: 公司自2025年10月起大幅提高各账龄段预期信用损失率（如1年内从1%提至2%），导致信用减值损失激增至4003万元，是净利润亏损的主因之一。
- **[资产减值损失计提]** -> [净利润亏损]: 报告期内计提存货及商誉减值1676万元，叠加信用减值损失，共同导致归母净利润亏损3122万元。
- **[控股股东及实控人变更]** -> [确立“低空经济+农机”双轮驱动战略]: 安徽澜石（田刚印）入主，为公司注入低空产业资源，明确低空业务为第二增长曲线。
- **[吉林康达高端制造突破]** -> [农机制造收入同比+24.76%]: 子公司吉林康达成功开发多款大型高端智能免耕播种机，并开拓俄罗斯市场，毛利率34.45%，成为利润核心来源。
- **[中标枝江低空基建EPC项目]** -> [低空业务从“概念”走向“落地”]: 2026年4月中标2.89亿元低空基建项目，标志着公司低空生态建设能力获得市场验证，为后续运营收入奠定基础。

## 风险警告
**核心风险在于新旧业务“青黄不接”。** 传统农机流通业务（占收入84.82%）正面临行业深度调整，毛利率仅9.77%，且公司通过会计估计变更大幅计提坏账，暴露了其应收账款质量恶化、下游客户回款困难的现实。尽管低空业务收入翻倍，但规模尚小（占收入6%），且毛利率仅14.82%，远低于农机制造板块，短期内难以弥补传统业务的利润缺口。公司连续两年归母净利润亏损，母公司未分配利润为-1.27亿元，不具备分红条件，财务基本面承压。

**新业务落地存在高度不确定性。** 低空经济虽为政策热点，但公司“地方低空生态能力建设及运营”模式尚处起步阶段，2.89亿枝江项目能否顺利实施并转化为稳定收入、利润，仍需观察。同时，低空经济领域竞争激烈，公司面临众多新进入者的挑战，且专业化人才储备不足。此外，公司控股股东安徽澜石所持股份已100%质押，若股价大幅波动，可能引发控制权稳定性风险。
