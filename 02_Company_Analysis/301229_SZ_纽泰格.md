# 301229.SZ 深度透视

## 因果逻辑链
- **[原材料铝锭价格上涨 + 客户持续降本]** -> [毛利率下降]: 直接材料成本占营业成本比重升至65.37%，而客户年降条款压缩售价空间，导致综合毛利率从23.46%降至20.68%。
- **[新项目处于产量爬坡期 + 部分产品良率不及预期]** -> [净利润大幅下滑29.23%]: 新定点项目尚未达到规模效应，叠加工艺难度大的新产品不良率较高，拖累整体盈利。
- **[研发投入持续增加]** -> [短期利润承压]: 研发费用同比增长12.56%至6424万元，研发人员数量激增41.35%，为长期技术储备牺牲当期利润。
- **[存货减值损失扩大]** -> [侵蚀利润]: 计提存货跌价减值损失1604万元，占利润总额的-38.58%，反映部分产品需求波动或成本高于可变现净值。
- **[新能源汽车渗透率提升]** -> [结构性增长机遇]: 公司新能源汽车零部件收入达3.49亿元，占营收32.5%，成为收入增长的核心驱动力。
- **[设立德国子公司及机器人子公司]** -> [布局第二增长曲线]: 在欧洲设立研发中心，并成立机器人科技公司，意图拓展国际业务和机器人轻量化结构件新赛道。
- **[可转债完成转股 + 股本扩张]** -> [稀释每股收益]: 总股本从1.13亿股增至1.82亿股，导致基本每股收益从0.34元降至0.24元，降幅大于净利润降幅。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司营收增长10%的同时，净利润却暴跌29%，扣非净利润跌幅更深达33%。根本原因是上游原材料涨价与下游客户年降的双重挤压，叠加新项目爬坡期的低效成本，导致毛利率全面下滑。若铝锭价格维持高位或新项目良率无法快速提升，2026年利润可能继续承压，甚至出现亏损。

**资产质量风险不容忽视。** 应收账款高达4.3亿元，占总资产22.84%，且存货激增82%至2.55亿元，库存积压与回款压力并存。公司已计提大额存货减值，若下游客户（如零跑、大众等）需求进一步波动，坏账与跌价风险将集中释放。此外，可转债转股完成后，股本大幅扩张，未来若业绩无法匹配，每股收益将被持续摊薄。
