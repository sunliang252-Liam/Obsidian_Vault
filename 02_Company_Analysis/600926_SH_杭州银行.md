# 600926.SH 深度透视

## 因果逻辑链
- **[利息净收入增长]** -> [净利润增长12.05%]: 在净息差收窄5BP至1.36%的背景下，通过贷款总额增长14.33%和负债成本下降38BP，实现利息净收入同比增长12.82%，驱动整体盈利提升。
- **[个人贷款不良率上升]** -> [资产质量承压]: 个人贷款不良率从0.77%升至1.21%，主要因宏观经济影响导致个人经营贷和消费贷风险暴露，但整体不良率仍维持在0.76%的行业低位。
- **[可转债成功转股]** -> [核心一级资本充足率提升]: 150亿元杭银转债完成99.96%转股，叠加盈利积累，核心一级资本充足率从8.85%提升至9.59%，为资产扩张提供资本支撑。
- **[财富管理业务扩张]** -> [中间业务收入增长]: 杭银理财存续规模突破6000亿元（+39%），托管规模达2.09万亿元（+18.53%），带动托管及受托业务佣金收入增长，手续费及佣金净收入同比增长13.10%。
- **[存款成本管控]** -> [净息差降幅收窄]: 通过多次下调存款挂牌利率和优化负债结构，存款付息率下降37BP，有效对冲了资产端LPR下行带来的收益率压力，使净息差仅下降5BP。
- **[科创与绿色信贷高增]** -> [资产结构优化]: 制造业、科创、绿色贷款分别增长22.25%、23.44%、22.75%，实现“三个千亿”突破，推动公司类贷款增长21.88%，优化了信贷资产结构。
- **[信用减值损失减少]** -> [利润释放]: 信用减值损失同比下降25.98%至55.11亿元，主要因债权投资减值回拨，在资产质量稳定的前提下释放了利润空间。

## 风险警告
**核心风险：个人贷款资产质量恶化与净息差持续收窄的双重挤压。** 个人贷款不良率从0.77%跃升至1.21%，其中个人经营贷不良率从0.93%升至1.52%，住房按揭不良率从0.29%升至0.71%，显示零售端风险正在加速暴露。同时，净息差已从2023年的1.50%持续下滑至1.36%，在LPR下行和有效信贷需求不足的背景下，2026年息差仍将承压。若零售风险进一步蔓延而息差继续收窄，将严重侵蚀利润增长空间。

**结构性风险：贷款集中度上升与区域依赖。** 最大单一客户贷款集中度从3.47%升至5.65%，最大十家客户集中度从23.49%升至25.29%，逼近监管红线。同时，浙江省内贷款占比高达79.44%，区域经济波动将直接冲击资产质量。此外，房地产业贷款不良率仍高达6.72%，虽余额有所下降，但风险化解尚未完成，仍是潜在隐患。
