# 688377.SH 深度透视

## 因果逻辑链
- **[深海油气开采需求持续向好]** -> [高附加值深海产品订单增长]: 全球深海项目投资增加，带动公司深海采油树等核心零部件需求，此类产品技术壁垒高、毛利率显著优于陆上产品。
- **[产品结构向深海等高附加值领域集中]** -> [综合毛利率提升3.27个百分点]: 深海产品收入占比提升，叠加陆上井口及非常规油气产品量价齐跌，结构优化驱动整体盈利水平改善。
- **[收购新加坡HME公司并设立子公司]** -> [拓展国际化布局与协同效应]: 收购HME获得关键产能与客户渠道，同时设立迈凯擎布局表面涂层处理，延伸产业链，提升客户一站式服务能力。
- **[募投项目“油气装备关键零部件精密制造项目”推进]** -> [获得核心客户批量订单]: 350MN多向模锻液压机等设备通过TechnipFMC、SLB等客户审核，为后续规模化生产高端阀门及管系零部件奠定基础。
- **[强化应收账款与存货周转管控]** -> [经营性现金流净额大幅增长85.5%]: 通过全流程回款管理和优化付款节奏，现金流状况显著改善，达1.93亿元，远超净利润。
- **[人民币升值导致汇兑收益减少]** -> [财务费用由负转正]: 外销收入占比高（68%），人民币汇率波动直接侵蚀利润，财务费用从-471万元增至864万元。
- **[陆上井口及非常规油气市场量价齐降]** -> [相关业务收入与毛利率双降]: 陆上业务竞争激烈、产品单价下滑，井口装置和非常规油气专用件收入分别下降9.14%和11.6%，拖累整体业绩。

## 风险警告
**客户高度集中与地缘政治风险**：公司前五大客户销售额占比高达74.59%，且主要客户为TechnipFMC、SLB等国际油服巨头。若主要客户因油价波动、地缘冲突或自身战略调整减少订单，公司业绩将面临剧烈波动。同时，公司产品大量出口至巴西、中东等地区，全球政治格局变化可能直接导致订单取消或延迟。

**汇率波动与原材料成本压力**：公司外销收入占比约68%，以美元结算为主。人民币升值已导致2025年财务费用由负转正，若未来人民币持续单边升值，将产生显著汇兑损失。此外，特钢等原材料成本占主营业务成本约60%，尽管公司有价格调整机制，但短期原材料价格大幅上涨仍将严重挤压利润空间。
