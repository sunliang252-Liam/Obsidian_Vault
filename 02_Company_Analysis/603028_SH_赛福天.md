# 603028.SH 深度透视

## 因果逻辑链
- **国家发行超长期特别国债支持老旧电梯更新** -> 电梯钢丝绳维保及更换需求增长: 政策直接推动电梯更新改造，钢丝绳作为核心易耗部件，更换需求随之扩大。
- **电梯保有量达1200万台且早期电梯进入集中更新周期** -> 电梯钢丝绳新增配套及维保市场扩容: 存量电梯基数大，维保和更新需求持续释放。
- **工程机械行业存量更新周期（2016-2021年投放设备进入更换期）** -> 工程机械用钢丝绳需求增长: 设备更新换代直接带动钢丝绳配套需求。
- **国家将深海科技纳入战略性新兴产业并设立2000亿元产业基金** -> 海洋工程领域对高性能钢丝绳、索具需求快速增长: 政策鼓励深海装备发展，海上风电、油气开发等场景增加对耐高压、抗腐蚀钢丝绳的需求。
- **港口货物吞吐量稳步增长（183.4亿吨，同比+4.2%）** -> 港口用钢丝绳、索具更换频次加快: 吞吐量增长带动运营强度提升，易耗部件更换周期缩短。
- **光伏行业N型TOPCon技术全面替代，市占率达87.6%** -> 公司光伏电池片技术升级及产销量增长: 公司紧跟技术路线，导入先进工艺，提升电池效率并降低成本，实现产销量增长。
- **光伏行业产能过剩、供需错配，反内卷初见成效** -> 公司光伏业务毛利率仍为负但亏损收窄: 行业价格竞争激烈，公司凭借技术优势降低成本，亏损幅度收窄。
- **公司加大研发投入（同比+27.93%），推进BC、钙钛矿叠层技术储备** -> 公司长期技术竞争力提升，支撑未来高端化转型: 研发投入覆盖钢索和光伏两大领域，为产品升级和新兴赛道布局奠定基础。
- **公司深化与头部客户合作（中联重科、隆基绿能等），渠道护城河稳固** -> 客户粘性高，订单稳定，支撑收入增长: 头部客户认证周期长、替换成本高，长期合作保障持续订单。
- **光伏业务贸易收入大幅增长（同比+412.72%）** -> 营业收入整体增长37.74%: 贸易业务收入贡献增量，但毛利率较低，对利润贡献有限。

## 风险警告
深度风险总结：1）光伏业务毛利率仍为负（-2.34%），行业产能过剩尚未根本解决，若价格战持续或技术迭代不及预期，可能拖累整体盈利；2）应收账款同比大幅增加65.27%，主要系销售增长导致账期内应收款增加，需关注回款风险及坏账损失；3）在建工程同比增加189.77%，产线改造投入较大，若下游需求不及预期，新增产能可能带来折旧压力；4）财务费用同比增加16.49%，融资规模扩大，若利率上升或现金流紧张，可能加大财务负担；5）光伏业务主要依赖TOPCon技术，需警惕钙钛矿等新技术的颠覆性冲击。
