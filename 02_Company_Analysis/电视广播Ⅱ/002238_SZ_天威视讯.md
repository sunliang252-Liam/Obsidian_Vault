# 002238.SZ 深度透视

## 因果逻辑链
- **[IDC机房资产减值]** -> [归母净利润巨亏1.93亿]: 深汕、南山、龙华数据中心因租赁价格持续下行，销售未达预期，计提大额资产减值准备，直接吞噬利润。
- **[传统固网业务萎缩]** -> [营收下降6.32%]: 有线电视用户数同比降3.55%，宽带用户微降0.54%，在激烈市场竞争下，核心连接性服务收益空间持续收窄。
- **[政府补助减少]** -> [非经常性损益下降]: 与收益相关的政府补助较上年同期减少，叠加合同资产减值，进一步加剧了扣非净利润的亏损幅度（-319.92%）。
- **[收购天擎数字]** -> [拓展“文化+科技”版图]: 以8428万元收购天擎数字70%股权，切入影视特效制作与虚拟现实领域，但报告期内仅贡献22.88万元净利润，整合效果尚待观察。
- **[深汕数据中心整体出租]** -> [IDC业务关键突破]: 深汕威视数据中心（一期）成功实现一次性整体出租，为未来IDC业务收入提供了确定性，但当前仍处于亏损状态（-1.44亿）。
- **[广电5G业务增长]** -> [用户数稳步增长]: 5G 192业务用户数稳步增长，但深圳市场高度饱和，竞争激烈，且物联网卡场景适配性不足，难以成为短期利润增长点。
- **[经营成本高企]** -> [盈利空间被挤压]: 网络升级、新基建、5G等领域的持续投入带来较大成本压力，而收入端增长乏力，导致毛利率下滑（有线电视行业毛利率同比降2.77%）。

## 风险警告
**核心风险在于传统业务失速与新兴业务投入期的“青黄不接”。** 公司核心收入来源——有线电视和宽带业务，在IPTV和移动互联网冲击下用户持续流失，营收下滑已成不可逆趋势。同时，公司重金投入的IDC数据中心业务，因行业供需失衡导致租赁价格下行，不仅未能贡献利润，反而因资产减值成为2025年巨亏的直接导火索。这种“旧业务萎缩、新业务亏损”的结构性困境，是公司当前面临的最大经营压力。

**转型方向正确但落地效果存疑，且面临激烈市场竞争。** 公司试图通过政企项目（应急广播、专网）、数据中心、视觉科技（天擎数字）等新业务寻找增长点，但这些领域均面临来自三大运营商、华为、阿里云等强大对手的竞争。公司作为区域性广电运营商，在资金、技术、人才储备上均不占优势，尤其是5G、云网应用等前沿人才短缺，将严重制约其转型速度和成功率。2026年扭亏为盈的经营目标，实现难度极大。
