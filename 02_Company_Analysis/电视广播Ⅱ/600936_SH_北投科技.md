# 600936.SH 深度透视

## 因果逻辑链
- **[重大资产置换]** -> [业绩大幅减亏]: 置入盈利的交科集团（净利润2.42亿），置出亏损的广电科技，使归母净利润同比减亏3.09亿元。
- **[置出资产并表亏损]** -> [公司整体仍亏损]: 广电科技1-8月经营亏损仍纳入合并报表，是导致公司全年归母净利润-3.77亿元的直接原因。
- **[高关联交易依赖]** -> [营收结构风险]: 前五名客户销售额中关联方占比高达42.47%，公司业务高度依赖控股股东体系，独立市场拓展能力存疑。
- **[交科集团业绩承诺达标]** -> [短期盈利锚定]: 置入资产2025年实现扣非净利润2.58亿元，完成业绩承诺的113.49%，为转型初期的业绩提供了底线支撑。
- **[传统广电业务萎缩]** -> [转型必然性]: 原广电业务收入同比下滑45.12%，毛利率仅4.43%，持续亏损倒逼公司通过资产置换彻底剥离该业务。
- **[数智工程业务下滑]** -> [核心业务承压]: 数智工程收入同比下滑27.10%，毛利率下降6个百分点，反映传统机电工程市场空间收窄，业务转型压力大。
- **[研发高投入]** -> [技术壁垒构建]: 研发投入强度达4.48%，聚焦“科宝”大模型、固废利用等核心技术，旨在从工程服务向“产品+服务”转型。
- **[同业竞争承诺]** -> [未来资产注入预期]: 控股股东承诺5年内解决同业竞争，设计集团、信创集团等潜在注入标的，构成公司未来外延增长的重要期权。

## 风险警告
公司最大风险在于**对控股股东体系的深度依赖**。营收42.47%来自关联方，业务独立性极弱，一旦关联交易减少或回款政策变化，将直接冲击收入和现金流。同时，控股股东承诺的应收账款周转率不低于1.4倍，若未能兑现，公司资金链将承压。这种“输血式”增长模式，掩盖了公司真实的市场竞争力。

其次，**转型阵痛与核心业务下滑并存**。公司虽已剥离广电业务，但核心的数智工程业务收入下滑27.1%，毛利率下降，表明传统优势业务正面临市场饱和与竞争加剧的双重压力。公司战略从“工程服务”转向“产品+服务”，但新产品（如新材料、智能装备）的规模化放量尚需时日，新旧动能转换存在空窗期，业绩改善的可持续性存疑。
