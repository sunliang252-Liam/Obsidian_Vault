# 000156.SZ 深度透视

## 因果逻辑链
- **[IPTV/OTT/短视频冲击传统有线电视]** -> **数字电视收入下降9.36%**: 互联网视听分流用户，导致基本收视费与节目传输收入持续下滑。
- **[智慧城市数字化业务扩张]** -> **集团客户集成项目收入增长1.02%至28.4亿元**: 公司战略转型，聚焦“慧政”、“惠民”项目，成为收入最大来源。
- **[广电5G与宽带融合套餐推广]** -> **宽带及数据通信业务收入增长2.23%**: 通过“电视+宽带+5G+智家”全融合策略，提升用户ARPU值，对冲用户流失。
- **[AI大模型研发与场景落地]** -> **研发费用下降7.59%但AI应用加速**: 研发投入聚焦“灵鸿”、“诗画文旅”等大模型，从基础研发转向商业化应用，提升效率。
- **[应收账款与坏账风险]** -> **信用减值损失增加，扣非净利润下降19.08%**: 政企项目回款周期长，导致应收账款规模扩大，侵蚀核心利润。
- **[非经常性损益依赖]** -> **净利润降幅（-12.65%）小于扣非净利润降幅（-19.08%）**: 政府补助、金融资产公允价值变动等非主业收益，掩盖了主营业务的真实下滑幅度。
- **[全省一网运营一体化]** -> **区域协同降本增效**: 通过统一采购、管理，控制营业成本（-1.04%），在收入下滑时维持毛利率相对稳定。

## 风险警告
**核心风险在于传统有线电视业务的不可逆萎缩与新兴业务增长乏力之间的矛盾。** 数字电视、互动电视等核心收入持续双位数下滑，而作为增长引擎的智慧城市业务，虽然体量大，但毛利率极低（11.23%），且伴随严重的应收账款问题，导致经营性现金流与净利润严重背离，扣非净利润已连续两年大幅下滑。

**第二重风险来自对非经常性损益的过度依赖。** 2025年归母净利润中，非经常性损益占比高达35.3%，主要来自政府补助和金融资产处置。若剔除这些一次性收益，公司实际盈利能力已显著恶化。此外，募集资金大量闲置（超166亿元），未能有效转化为收入和利润，资产使用效率低下，长期将拖累ROE。
