# 000665.SZ 深度透视

## 因果逻辑链
- **[传统业务收入持续下滑]** -> [营收与利润双降]: 电视、宽带等核心传统业务受IPTV/OTT冲击，用户流失与ARPU值下降，导致2025年营收同比-4.58%，归母净亏损扩大至-10.95亿元。
- **[高额刚性成本无法压降]** -> [亏损加剧]: 折旧摊销（占成本36.16%）和人工成本（占14.08%）等固定成本具有刚性，收入下滑时无法同比例缩减，成本压降无法弥补利润缺口。
- **[资产减值集中爆发]** -> [利润大幅侵蚀]: 报告期内计提商誉、合同资产等减值损失3.19亿元，占利润总额的29.18%，是导致亏损扩大的直接财务冲击。
- **[商誉全额计提减值]** -> [历史并购风险出清]: 截至2025年末，商誉账面原值5.22亿元已全额计提减值准备，账面价值归零，标志着过往并购整合的资产泡沫被彻底消化。
- **[抖音渠道营销突破]** -> [用户转化效率提升]: 抖音“千人计划”构建直播矩阵，连续稳居全国电信运营商核心榜单第一，带动社会渠道到账收入同比增长122%，成为用户获取的新引擎。
- **[共建共享夯实网络底座]** -> [5G业务增长]: 与湖北移动合作开通基站18.42万站，实现5G网络全省覆盖，推动移网到达与新发展用户在全国广电排名第六，移动网络收入同比增长57.06%。
- **[内容生态与产品创新]** -> [用户活跃度提升]: “鳄鱼TV”实现头部视频全聚合，月均活跃用户达60万（同比+13.56%）；“小鳄微短剧”付费转化率高达10%，远超行业均值，形成差异化竞争力。
- **[资产负债率攀升]** -> [财务风险加剧]: 资产负债率从57.37%升至65.12%，未分配利润亏损扩大至-24.77亿元，母公司存在累计未弥补亏损，不满足现金分红条件，财务结构持续恶化。

## 风险警告
**核心风险在于传统业务失血与转型投入之间的结构性矛盾。** 公司电视、宽带等核心收入持续以10%左右的速度下滑，而5G、政企等新业务虽增长迅速但体量尚小，无法弥补传统业务萎缩带来的巨大缺口。同时，折旧、人工等刚性成本居高不下，导致公司连续三年巨额亏损，且亏损幅度逐年扩大（-6.5亿→-7.9亿→-10.9亿），盈利能力未见拐点。

**财务健康度恶化是另一重大隐患。** 资产负债率已攀升至65.12%，短期借款激增至19.4亿元，而货币资金仅3.2亿元且部分受限，短期偿债压力巨大。更值得警惕的是，5.22亿元商誉已全额计提减值，表明历史并购并未产生预期协同效应，资产质量堪忧。母公司累计未弥补亏损高达-36.66亿元，已无法进行现金分红，对股东回报能力丧失殆尽。
