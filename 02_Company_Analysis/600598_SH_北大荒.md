# 600598.SH 深度透视

## 因果逻辑链
- **[土地承包费收入稳定增长]** -> [利润增长]: 公司通过机动地竞价、超规模阶梯收费等增收措施，在耕地面积基本不变的情况下，推动土地承包费收入同比增长0.48%，成为利润核心压舱石。
- **[管理费用大幅压降]** -> [利润增长]: 受政策性因素影响，公司减少内部退养辞退福利并严格落实“过紧日子”要求，管理费用同比减少1.51亿元（-24.54%），直接增厚利润。
- **[理财策略调整导致利息收入锐减]** -> [财务费用增加]: 受理财利率下行影响，公司调整理财策略，定期存款、协定存款利息收入大幅减少，导致财务费用同比增加1.16亿元，对利润形成拖累。
- **[化肥等农业投入品价格下行]** -> [营收下滑]: 化肥、农药等农业投入品销售业务受商品价格下行及业务饱和影响，收入同比减少，导致公司总营收同比下降2.05%。
- **[农产品经营规模扩大]** -> [存货增加与现金流减少]: 部分农业分公司采购经营农产品暂未销售，导致存货同比大增108.39%，经营活动现金流净额同比下降16.96%。
- **[高比例现金分红]** -> [股东回报稳定]: 公司2025年拟每10股派发现金股利5.5元，现金分红比例高达83.84%，持续高分红策略强化了其作为红利股的属性。
- **[历史遗留问题子公司持续亏损]** -> [拖累整体业绩]: 龙垦麦芽、鑫都房地产等子公司因历史经营问题持续亏损，合计亏损超7500万元，成为公司利润的出血点。
- **[结构性存款投资规模扩大]** -> [投资收益波动]: 公司将大量货币资金转入结构性存款，交易性金融资产规模增至36.53亿元，贡献公允价值变动收益9854万元，但该收益受市场利率波动影响较大。

## 风险警告
**核心风险在于利润对非经常性损益的依赖与主业增长乏力。** 2025年归母净利润同比增长7.26%，但扣非净利润同比下降4.48%，两者背离的核心原因是公司通过将大量货币资金转为结构性存款，获得了9854万元的公允价值变动收益。剔除该非经常性收益后，公司主业（土地承包费）增长极为有限，且化肥等贸易业务收入还在下滑。未来若理财收益率持续下行，公司利润将面临失速风险。

**历史遗留问题的“灰犀牛”风险不容忽视。** 公司旗下龙垦麦芽、鑫亚经贸、鑫都房地产等多家子公司长期处于停产或亏损状态，累计亏损巨大且背负大量诉讼与应收账款。虽然公司已计提减值，但这些资产的处置和债务追偿过程漫长且充满不确定性，随时可能产生新的减值损失或法律风险，持续侵蚀母公司利润。
