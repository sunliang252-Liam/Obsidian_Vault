# 600319.SH 深度透视

## 因果逻辑链
- **[搬迁补偿款确认收益]** -> [净利润亏损收窄]: 2025年收到停产停业损失补偿款4,674万元，计入非经常性损益，使归母净利润亏损从扣非后的-2.01亿元收窄至-1.56亿元。
- **[CPE行业供过于求]** -> [核心产品毛利率下滑]: 下游房地产需求不振，行业竞争加剧，CPE销售价格低位运行，毛利率同比减少4.27个百分点。
- **[新项目集中建设]** -> [资金链承压与财务费用飙升]: 4.5万吨PVDC等新项目处于建设攻坚期，融资需求大增，财务费用同比上升16.70%至8,700万元。
- **[新项目建成试产]** -> [业绩贡献尚未释放]: PVDC、六氯环三磷腈等新项目于2025年四季度建成试产，处于产能爬坡与客户验证阶段，未对当年主营业务产生实质影响。
- **[搬迁补偿款接近尾声]** -> [非经常性收益不可持续]: 累计收到搬迁补偿款13.68亿元，尚余约6,995万元未到位，未来依赖此收益扭亏的模式将终结。
- **[双氧水行业供需矛盾突出]** -> [产品亏损加剧]: 双氧水价格连创新低，全行业盈亏线挣扎，公司双氧水业务毛利率为-37.10%，同比减少9.23个百分点。
- **[重大资产重组终止]** -> [转型路径受阻]: 拟收购山东天一化学100%股权的重组事项因核心诉求未达成一致而终止，公司外延式扩张战略受挫。

## 风险警告
**核心风险：主业持续失血，新项目远水难解近渴。** 公司核心CPE、双氧水业务深陷行业性亏损，扣非净利润已连续三年为负且亏损额扩大至-2.01亿元。寄予厚望的PVDC等新材料项目虽已建成，但产能爬坡、客户验证、市场推广均需时间，2026年能否贡献实质性利润存在重大不确定性。在搬迁补偿收益接近尾声的背景下，公司面临主业造血能力枯竭的严峻挑战。

**财务风险：高负债与现金流枯竭的双重挤压。** 公司资产负债率已攀升至86.1%，有息负债规模巨大，财务费用高企。经营活动现金流净额由正转负至-2,084万元，而投资活动现金净流出高达-4.22亿元，表明公司正依靠大规模举债（筹资活动净流入3.58亿元）来维持项目建设，这种“借新还旧、借新投建”的模式极度脆弱，一旦融资环境收紧，将面临流动性危机。
