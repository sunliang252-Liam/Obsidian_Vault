# 600118.SH 深度透视

## 因果逻辑链
- **[商业航天竞争加剧，公司被迫转向低毛利产品]** -> [营收增长18.35%，但毛利率下降2.88个百分点]: 公司为争夺市场份额，交付更多低毛利的商业航天部组件，导致收入增长的同时，盈利能力被侵蚀。
- **[子公司亏损治理见效]** -> [净利润增长27.38%至3556万元]: 通过“争订单、保履约、控成本”，航天智慧等子公司实现扭亏或减亏，推动整体利润改善。
- **[第四季度集中交付与计提大额减值]** -> [Q4利润被大幅侵蚀]: 大量项目在Q4确认收入，但同时计提6355万元存货跌价准备，导致Q4净利润仅2075万元，远低于Q3的4530万元。
- **[客户高度集中且关联交易占比大]** -> [经营受制于航天科技集团体系]: 前五大客户销售额占80.5%，其中关联方占38.69%，公司业务高度依赖集团内部订单，议价能力和经营独立性受限。
- **[研发投入资本化率高]** -> [短期利润被美化，但未来摊销压力大]: 研发投入3.78亿元，资本化率高达72.56%，大量研发支出未计入当期损益，降低了当期费用，但增加了未来摊销负担。
- **[经营现金流大幅转正]** -> [回款能力改善]: 经营活动现金流净额从-3.17亿元大幅转正至3.63亿元，表明公司加强了应收账款催收，经营质量有所提升。
- **[子公司深圳东方红与星地恒通持续亏损]** -> [拖累整体业绩]: 深圳东方红因业务转型亏损1.04亿元，星地恒通因产品换代亏损0.39亿元，合计亏损占归母净利润的400%以上，是公司盈利能力的核心拖累。

## 风险警告
**核心风险在于盈利能力的脆弱性。** 公司2025年归母净利润仅3556万元，而扣非净利润更是低至758万元，净资产收益率仅0.56%。这背后是商业航天竞争白热化导致毛利率持续下滑，以及多个子公司深陷亏损泥潭。公司本质上是在用低毛利的规模化订单和大量资本化的研发投入，勉强维持一个微利的报表，其“造血”能力严重不足。

**第二大风险是高度依赖关联交易和客户集中度。** 公司超80%的收入来自前五大客户，且近40%为关联交易。这种结构使其经营决策和定价策略受制于航天科技集团体系，缺乏市场化弹性。一旦集团采购政策或定价机制调整，公司业绩将面临剧烈波动。同时，高达72.56%的研发投入资本化率，也为未来业绩埋下了潜在的减值或摊销风险。
