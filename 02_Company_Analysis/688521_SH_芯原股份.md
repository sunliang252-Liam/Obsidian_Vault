# 688521.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [新签订单暴增103.41%至59.60亿元]: 云侧与端侧AI ASIC需求激增，公司作为“AI ASIC龙头企业”承接大量定制化芯片设计及IP授权订单。
- **[在手订单结构优化]** -> [量产业务订单超30亿元，规模效应显现]: 高价值量产业务订单占比提升，随着订单转化为收入，将摊薄固定成本，驱动未来盈利能力改善。
- **[系统厂商/互联网/车企自研芯片趋势]** -> [非芯片设计公司客户收入占比约40%]: 这类客户缺乏芯片设计资源，倾向于外包，芯原的SiPaaS一站式服务模式精准匹配其需求，形成高粘性合作。
- **[丰富的自主IP组合（NPU/GPU/VPU等）]** -> [IP授权业务收入全球第八，中国大陆第一]: 自研IP是SiPaaS模式的核心壁垒，IP复用性高，授权业务贡献高毛利，并带动芯片定制业务。
- **[高研发投入（占收入42.78%）]** -> [保持技术领先，覆盖4nm FinFET等先进工艺]: 持续高研发投入构筑竞争壁垒，确保在AI、汽车电子等前沿领域的技术代差，支撑高端项目获取。
- **[Chiplet技术布局]** -> [领跑AIGC和智驾系统赛道]: 提前布局Chiplet架构，解决大算力芯片成本与良率痛点，为公司开辟IP芯片化、芯片平台化的新增长空间。
- **[收购逐点半导体]** -> [强化端侧AI ASIC与显示处理IP竞争力]: 整合逐点半导体在图像后处理（插帧、超分）技术，与芯原前处理IP形成完整图像处理方案，提升在AI手机、AI眼镜等领域的综合竞争力。

## 风险警告
**核心风险在于持续亏损与现金流压力。** 公司2025年归母净利润为-5.28亿元，虽亏损幅度同比收窄，但已连续多年亏损，且累计未分配利润高达-29.44亿元。经营活动现金流净额为-2.22亿元，表明公司自身造血能力尚未转正，高度依赖外部融资（如定增）来支撑研发和运营。若未来收入增长不及预期，或研发投入持续高企，公司可能面临流动性风险，并长期无法进行现金分红。

**业绩兑现与客户集中度风险。** 公司2025年新签订单暴增，但收入确认存在周期，尤其是芯片设计项目周期长，从订单到收入转化存在不确定性。同时，公司约四成收入来自系统厂商、互联网等大客户，且AI算力相关订单占比超73%，若主要客户需求放缓或转向自研，将对公司业绩造成重大冲击。此外，量产业务毛利率较低，收入结构变化已导致综合毛利率下降5.68个百分点，未来盈利能力改善依赖于高毛利的IP授权业务占比提升。
