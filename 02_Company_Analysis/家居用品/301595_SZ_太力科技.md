# 301595.SZ 深度透视

## 因果逻辑链
- **[电商流量红利收窄]** -> [净利润下滑29.88%]: 平台经济下获客成本攀升，C端业务毛利承压，叠加战略性投入增加，导致利润增速远低于收入增速。
- **[B端业务战略扩张]** -> [研发费用增长7.56%+工业客户增长20.74%]: 公司加速向工业材料领域转型，加大研发与组织投入，新兴业务尚处培育期，投入与回报阶段性错配。
- **[高性能防护业务爆发]** -> [营收同比增长75.38%]: 纳米流体柔性防护材料在军警、民用市场取得突破，成为公司增长最快的业务板块。
- **[海外线上渠道扩张]** -> [外销收入同比增长29.37%]: 亚马逊渠道实现44.58%同比增长，带动整体外销占比提升至40.42%，有效对冲内销下滑。
- **[核心材料自研自产]** -> [单位成本降低90%以上]: 剪切增稠纳米流体实现全链条技术突破，打破国外垄断，构筑成本与供应链安全壁垒。
- **[航天技术民用转化]** -> [品牌溢价与市场领先]: 作为中国航天独家供应商，将航天级技术迁移至民用真空收纳、户外装备，形成差异化竞争优势。
- **[C端基本盘稳固]** -> [线上收入占比81.73%]: 真空收纳袋、垂直壁挂置物等核心品类在天猫、京东保持市占率第一，提供稳定现金流支撑转型。

## 风险警告
公司正经历从C端消费品牌向B端工业材料平台转型的阵痛期。2025年净利润同比下滑29.88%，核心原因是电商流量红利见顶导致C端毛利承压，同时B端业务（防护、涂层、机器人）尚处投入期，研发费用增长7.56%且未形成规模收入。这种“新旧动能转换”的阶段性错配，若B端业务商业化进度不及预期，将导致利润持续承压。

新兴业务（机器人防护、商业航天涂层）均处于早期验证阶段，尚未签订规模化订单。新材料产业化存在工艺不成熟、成本过高、市场接受度低等固有风险。同时，公司外销收入占比超40%且以美元结算，人民币汇率波动将直接冲击利润。此外，募投项目（武汉生产基地、研发中心）进度显著滞后，若产能建设持续延迟，将制约B端业务的规模化交付能力。
