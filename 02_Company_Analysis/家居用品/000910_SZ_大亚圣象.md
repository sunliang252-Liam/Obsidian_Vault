## 因果逻辑链
- **[房地产下行周期]** -> [营收与利润双降]: 新房销售面积同比下降8.7%，直接压制地板和人造板装修需求，导致公司营收同比减少14.49%，归母净利润暴跌90.41%。
- **[下游需求萎缩]** -> [核心子公司巨亏]: 全资子公司圣象集团（地板业务）净利润亏损1.33亿元，同比扩大825%，是拖累整体业绩的最大因素。
- **[收入下滑叠加减值]** -> [经营活动现金流由正转负]: 营收减少导致销售回款下降，同时计提资产减值损失1.16亿元，共同导致经营活动现金流净额从+7.35亿骤降至-0.35亿。
- **[行业竞争加剧与消费降级]** -> [毛利率承压]: 在需求不足、整体消费降级的背景下，行业“内卷”升级，公司产品盈利空间被压缩，整体毛利率仅微增1.57%。
- **[原材料与人工成本刚性]** -> [利润侵蚀]: 尽管营收下滑，但原材料、人工等成本下降幅度小于收入降幅，导致利润被大幅侵蚀。
- **[广西铝板带项目投入期]** -> [短期亏损与现金流压力]: 新能源材料项目处于建设与试产阶段，子公司大亚新能源材料科技亏损1692.79万元，且在建工程大幅增加，占用了大量资金。
- **[应收账款与存货高企]** -> [减值风险暴露]: 下游客户资金紧张，导致应收账款和存货周转放缓，报告期内计提信用及资产减值损失合计1.16亿元，成为吞噬利润的主要黑洞。

## 风险警告
公司当前面临的最大风险是**房地产下行周期的深度冲击**。作为与新房装修高度关联的建材企业，2025年新房销售面积持续下滑，导致公司核心业务（地板、人造板）量价齐跌，营收和利润均出现断崖式下跌。更严峻的是，下游客户资金链紧张已传导至公司资产负债表，导致应收账款和存货减值激增，经营活动现金流首次转负，显示出公司正从“利润下滑”进入“现金流危机”的深水区。

其次，**新业务转型存在巨大不确定性**。公司斥巨资投建的广西铝板带项目尚处于试产阶段，不仅未能贡献利润，反而因建设投入和初期亏损拖累整体业绩。在传统主业持续恶化、现金流吃紧的背景下，新业务能否如期达产并成为第二增长曲线，存在重大疑问。若新业务持续亏损，将进一步加剧公司的财务风险。
