# 603833.SH 深度透视

## 因果逻辑链
- **[房地产下行与消费趋紧]** -> [营收与利润双降]: 新房交付量收缩及消费者信心不足，直接导致公司2025年营收同比下降8.94%，归母净利润同比下降23.18%。
- **[“分田到户”考核机制改革]** -> [成本费用有效控制]: 将个人收入与利润强关联，驱动各单元主动降本，使营业成本降幅（-9.4%）优于营收降幅，期间费用同比下降9.5%，缓冲了利润下滑幅度。
- **[大家居战略深化（零售+整装）]** -> [客单价提升对冲客流下滑]: 通过“定装一体化”和全案解决方案，提升单客户价值，零售大家居有效门店超1250家，大家居引流成交客户数同比增长111%。
- **[全域流量体系构建（线上+旧改）]** -> [获客渠道多元化]: 构建“总部通投、区域联投、本地电商”矩阵，并推出旧改品牌“青岚小筑”布局社区店，累计上线云店13600家，本地电商成交客户数同比增长超70%。
- **[大宗业务向非房与全案转型]** -> [对冲新房业务萎缩]: 非房地产开发项目合同数量同比增长57%，门墙柜品类合同数量同比增长超100%，使大宗业务收入降幅（-13.95%）优于房地产竣工下滑幅度。
- **[海外业务稳步拓展]** -> [贡献增量收入]: 海外经销渠道业务增长超20%，东南亚/欧洲/中东地区增长超30%，推动海外整体营收同比增长9.66%。
- **[智能制造与供应链协同]** -> [毛利率稳中有升]: 通过自动化改造、PUR封边工艺升级、供应链集采降本等措施，在收入下滑背景下，主营业务毛利率同比提升0.52个百分点至36.03%。

## 风险警告
**核心风险在于市场需求的结构性萎缩与行业竞争的白热化。** 新房交付量持续下滑（2025年住宅销售面积下降9.2%），存量房翻新需求虽在释放但转化周期长，导致公司核心的经销渠道收入同比下降9.41%。同时，行业已进入存量博弈阶段，价格战与流量争夺加剧，公司销售费用虽同比下降8.23%，但整体利润下滑幅度（-23.18%）远超营收降幅，显示盈利空间正被持续压缩。

**另一重大风险是经销商体系的稳定性与转型阵痛。** 公司近80%收入依赖经销商渠道，2025年净关闭经销门店461家，经销商数量减少164家。在推动经销商从“卖产品”向“卖方案”的大家居转型过程中，部分经销商可能因能力不足、资金压力或盈利不佳而退出，导致渠道网络收缩与终端服务能力下降。此外，公司经营活动现金流净额同比大幅下降38.23%，虽与营收下滑相关，但也需警惕回款效率与资金周转压力。
