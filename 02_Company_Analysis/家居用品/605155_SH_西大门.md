# 605155.SH 深度透视

## 因果逻辑链
- **[成品业务规模化扩张]** -> [营收增长7.98%]: 遮阳成品收入同比大增42.39%，抵消了面料业务下滑15.75%的影响，成为收入增长核心引擎。
- **[电商平台高投入]** -> [销售费用激增39.5%]: 为抢占海外线上市场，公司在亚马逊、独立站等平台投入大幅增加，导致销售费用增速远超营收增速。
- **[成品毛利率提升]** -> [盈利能力结构性改善]: 成品毛利率达49.68%，高于面料业务的38.32%，业务结构向高毛利成品倾斜，但整体净利润仍下滑8.66%。
- **[外销依赖度持续攀升]** -> [汇率与贸易风险敞口扩大]: 外销收入占比从77.54%升至81.97%，汇兑损益由收益转为损失589.69万元，人民币汇率波动对利润影响显著。
- **[募投项目全面投产]** -> [产能释放与折旧压力并存]: “年产1,650万平方米遮阳新材料”等项目结项，新增产能支撑未来增长，但每年将增加约2,816万元固定资产折旧。
- **[股权激励绑定核心团队]** -> [业绩指引清晰]: 2025年新激励计划设定2026年营收复合增长率不低于14%或净利润复合增长率不低于8%的目标，彰显管理层信心。
- **[原材料价格联动]** -> [成本控制承压]: 核心原材料（聚酯纤维、PVC等）与原油价格高度联动，公司虽可调价但存在滞后性，短期压缩毛利空间。

## 风险警告
**增收不增利，费用失控侵蚀利润。** 公司营收增长7.98%，但归母净利润却下降8.66%，核心原因是销售费用同比暴增39.5%至1.98亿元，远超营收增速。这反映出公司在海外电商渠道的扩张尚处于“烧钱换规模”阶段，投入产出效率有待验证。若未来销售费用率无法有效控制，即便营收持续增长，利润端也将持续承压。

**外销依赖与汇率波动构成双重脆弱性。** 公司超80%收入来自海外，且以美元结算。2025年人民币汇率波动已导致汇兑损失589.69万元，叠加全球贸易摩擦、地缘政治风险以及出口退税政策变化，公司业绩极易受外部不可控因素冲击。此外，实际控制人柳庆华、王月红合计持股超60%，存在一股独大下的公司治理风险。
