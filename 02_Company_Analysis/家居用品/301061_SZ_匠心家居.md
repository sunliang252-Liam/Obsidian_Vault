# 301061.SZ 深度透视

## 因果逻辑链
- **[美国零售商渠道深化]** -> [营收逆势增长32.6%]: 在行业出口下滑6.1%的背景下，公司前十大客户采购额全部正增长，零售商收入占比达67.08%，渠道结构从“卖给更多客户”转向“卖给更优质客户”。
- **[越南+柬埔寨双基地布局]** -> [规避关税风险]: 越南基地已分担产能，柬埔寨项目启动建设，多区域产能布局对冲美国对华/对越加征25%关税风险。
- **[成本分担机制与客户锁定]** -> [毛利率仅微降0.06%]: 公司选择与核心客户共担关税成本，牺牲短期利润率换取长期战略地位，调整后毛利率39.29%基本持平。
- **[人民币升值2.21%]** -> [汇兑损失2,020万元]: 出口以美元计价，人民币升值导致收入折算减少8,340万元，叠加外币资产贬值，形成利润压力。
- **[核心配件高毛利]** -> [利润结构优化]: 配件业务毛利率46.91%，同比增长8.71个百分点，成为利润稳定器，对冲智能电动床收入下滑16.18%的影响。
- **[研发投入增长24.93%]** -> [产品差异化壁垒]: 研发费用1.57亿元，聚焦零重力、无级调节等创新，支撑“不可被美国本土生产替代”的客户评价。
- **[美国消费韧性]** -> [需求放缓但不消失]: 通胀高位但消费者通过调整节奏适应，家具需求延后而非消失，为公司提供持续修复空间。

## 风险警告
**关税与汇率双杀风险**：公司核心市场美国面临25%关税加征，且人民币全年升值2.21%直接侵蚀利润。虽然通过越南/柬埔寨布局对冲，但政策不确定性极高——美国最高法院虽裁定部分关税违法，但301/232条款仍可构建新壁垒。2025年汇兑损失2,020万元仅是开始，若人民币继续升值，利润弹性将显著承压。

**单一市场依赖与增长天花板**：前十大客户100%来自美国，零售渠道占比67.08%且高度集中。虽然客户粘性强，但美国房地产市场承压、利率高位将持续抑制家具消费。公司智能电动床收入已下滑16.18%，若美国经济进入衰退周期，核心客户采购增速可能骤降，公司缺乏其他市场缓冲。

**募投项目反复变更与产能错配**：原常州生产基地项目因土地规划调整终止，转向柬埔寨新建项目。但越南基地产能已可满足现有订单，柬埔寨新增产能若遇需求放缓，将导致资本回报率下降。同时，公司超募资金大量用于理财（11亿元），反映主业扩张意愿不足，资金使用效率存疑。
