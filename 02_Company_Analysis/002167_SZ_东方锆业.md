# 002167.SZ 深度透视

## 因果逻辑链
- **[矿砂贸易核算口径变更]** -> [营收大幅下降19.32%]: 2025年矿砂贸易采用净额法核算，而2024年自产矿砂采用总额法，导致营收同比减少约2.98亿元，剔除该影响后主营业务收入基本持平。
- **[锆系产品价格全面下行]** -> [扣非净利润扭亏为盈]: 主要产品氯氧化锆销售均价同比降幅接近10%，但公司通过降本增效、优化产品结构（发力高附加值产品），使扣非净利润从-1.09亿转为+0.47亿。
- **[原材料采购价格降幅小于产品售价降幅]** -> [盈利空间被挤压]: 锆英砂等原料价格下跌幅度不及锆制品售价跌幅，导致产品毛利率承压，是公司面临的核心经营挑战。
- **[财务费用大幅减少97.41%]** -> [利润改善]: 贷款规模缩减、高息贷款置换及汇率波动影响，利息费用及汇兑损失同比大幅减少，从0.74亿降至0.02亿，显著增厚净利润。
- **[关联交易高度集中]** -> [经营独立性风险]: 前五大供应商采购额占年度采购总额78.71%，其中向控股股东龙佰集团及关联方采购占比高达51.85%，公司对关联方供应链依赖度极高。
- **[新能源项目投资加速]** -> [长期增长潜力]: 公司推进年产6万吨电池级氯氧化锆及1万吨高纯复合氧化锆项目，并参股固态电池企业，布局新能源赛道，打开未来成长空间。
- **[全球锆矿供给趋紧]** -> [上游资源价值凸显]: 澳大利亚主力矿山2026-2027年进入枯竭周期，全球锆矿供需缺口预计扩大，拥有稳定锆矿来源的企业将具备成本与供应链优势。

## 风险警告
**核心风险在于对控股股东龙佰集团的深度依赖与关联交易风险。** 公司前五大供应商采购额占比高达78.71%，其中向龙佰集团及其关联方的采购占比达51.85%，且销售端关联交易占比亦不低（19.48%）。这种“左手进右手出”的商业模式，使公司经营独立性存疑，利润的真实性与可持续性需高度警惕。一旦关联交易定价不公允或控股股东战略调整，公司业绩将面临剧烈波动。

**行业周期性下行与盈利能力的脆弱性是另一大隐患。** 尽管2025年扣非净利润扭亏为盈，但这是在财务费用大幅减少97%的“助攻”下实现的，主营业务盈利能力依然薄弱。锆系产品价格持续下行，原材料成本降幅不及产品售价降幅，毛利率承压。公司资产负债率虽降至15.59%，但经营现金流净额同比下降44.97%，显示经营质量并未同步改善。若行业景气度持续低迷，公司可能重回亏损。
