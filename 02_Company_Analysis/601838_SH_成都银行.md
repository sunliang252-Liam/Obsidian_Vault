# 601838.SH 深度透视

## 因果逻辑链
- **[深耕成渝区域经济]** -> [资产规模连续五年千亿级增长]: 深度融入成渝双城经济圈建设，政务金融与产业园区信贷投放超750亿元，将区域发展红利直接转化为资产扩张动能。
- **[低息存款结构优势]** -> [净息差韧性]: 个人定期存款占比高且成本仅2.57%，活期存款成本极低，在行业息差收窄背景下，净息差仍维持在1.59%的较好水平。
- **[政务金融与储蓄存款护城河]** -> [低成本负债来源稳定]: 作为地方法人银行，政务金融市场份额领跑全市，储蓄存款新增份额全市第一，形成稳定且低成本的负债基础。
- **[精细化风控与行业研究]** -> [不良率长期低于0.7%]: 通过“名单制”精准营销和“两图一表”行业分析体系，实现前瞻性风险识别，不良贷款生成率连续五年低于千分之五。
- **[科技金融与专精特新覆盖]** -> [对公贷款高增长]: 科技型企业贷款增长24%，专精特新“小巨人”服务覆盖率超86%，驱动公司贷款余额同比增长17.5%。
- **[个人存款与理财双轮驱动]** -> [零售负债与中收增长]: 储蓄存款突破5000亿元，代销理财余额增长超130%，在稳定负债的同时贡献手续费收入。
- **[债券投资策略优化]** -> [投资收益稳定]: 全年配置低风险利率债超千亿，把握高位建仓机会，组合收益率优于市场表现，对冲了公允价值变动损失。

## 风险警告
**核心风险在于资产质量的结构性隐忧与盈利增长放缓。** 虽然整体不良率仅0.68%，但个人贷款不良率从0.78%升至1.11%，其中个人购房贷款不良率从0.78%升至1.15%，个人经营贷款不良率升至1.22%。同时，逾期贷款总额从52.16亿元增至71.98亿元，增幅38%，逾期90天以上贷款占比上升，表明潜在不良压力正在积聚。此外，拨备覆盖率从479%降至426%，风险抵补能力有所削弱。

**盈利增长动能面临多重挤压。** 营收增速仅2.7%，归母净利润增速3.31%，均为上市以来较低水平。净息差从1.81%降至1.59%，降幅明显。手续费及佣金净收入大幅下降29.59%，主要受理财及资产管理业务收入腰斩拖累。公允价值变动损益从6.92亿元骤降至0.19亿元，债券市场波动对利润表的冲击显著。在利率持续低位和市场竞争加剧的背景下，传统息差业务和中间业务的增长空间均受到明显制约。
