# 600839.SH 深度透视

## 因果逻辑链
- **[被投资企业华丰科技公允价值增加]** -> [归母净利润大增40.56%]: 非经常性损益（公允价值变动收益10.32亿元）是利润增长的核心来源，掩盖了主业盈利能力的下滑。
- **[海外地区冲突、关税政策变化、行业同质化竞争加剧]** -> [扣非净利润暴跌78.35%]: 核心家电及出口业务受宏观逆风冲击，导致经营性利润大幅萎缩，仅剩0.91亿元。
- **[国内“国补”以旧换新政策]** -> [短期提振家电需求，但效应递减]: 政策在上半年拉动空调等品类增长，但下半年需求透支，市场呈现“前高后低”，未能扭转整体颓势。
- **[ICT综合服务业务（长虹佳华）]** -> [营收增长10.19%，成为增长主引擎]: 受益于AI算力需求及“国补”对消费电子拉动，该板块贡献了集团超37%的营收，是规模增长的核心驱动力。
- **[特种业务（长虹电源）]** -> [营收增长53.96%，成为利润新亮点]: 受益于低空经济、轨道交通等新领域拓展及产品集中交付，该业务毛利率较高，有效对冲了家电业务的利润下滑。
- **[全球供应链重构与贸易壁垒]** -> [海外运营成本与风险持续攀升]: 公司海外业务占比高，面临关税、地缘冲突及物流成本波动等挑战，经营不确定性显著增加。
- **[房地产行业需求侧疲软]** -> [房地产业务收入下降23.44%]: 公司采取“收缩去库存”战略，该业务持续拖累整体业绩，且资产变现存在不确定性。

## 风险警告
**核心风险在于利润的“虚胖”与主业的“贫血”。** 2025年近10亿的归母净利润，超过90%来自非经常性损益（主要是华丰科技的公允价值变动），而扣非净利润仅0.91亿元，同比暴跌78%。这表明公司核心的家电、中间产品等业务在激烈的存量竞争和海外冲击下，盈利能力已极度脆弱，几乎不产生实质利润。投资者必须警惕这种依赖“投资收益”粉饰的业绩，一旦资本市场波动或关联公司估值回调，利润将迅速坍塌。

**海外业务面临“黑天鹅”与“灰犀牛”的双重夹击。** 公司海外营收占比约24%，且电视、空调等核心品类深度参与全球竞争。当前，中美关税战、地缘政治冲突（如俄乌、以伊局势）以及全球供应链重构，正持续推高运营成本并扰乱订单节奏。虽然公司通过“抢出口”和布局新兴市场短期对冲，但长期来看，贸易壁垒的固化与海外本土制造能力的提升，将系统性侵蚀公司出口业务的竞争优势和利润空间。
