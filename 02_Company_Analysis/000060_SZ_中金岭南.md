# 000060.SZ 深度透视

## 因果逻辑链
- **[铜冶炼产能扩张]** -> [营收增长7.17%]: 铜冶炼产品收入同比大增28.20%，成为营收增长核心引擎，抵消铅锌板块疲软。
- **[精矿加工费低位运行]** -> [净利润下滑25.89%]: 铜精矿加工费大幅下跌，压缩冶炼利润空间，导致增收不增利。
- **[汇兑净损失增加]** -> [财务费用飙升45.71%]: 海外业务受汇率波动冲击，财务费用大幅侵蚀利润。
- **[存货及固定资产减值]** -> [资产减值损失4.77亿元]: 对存货和固定资产计提大额减值，直接拖累利润总额-42.58%。
- **[经营活动现金流改善]** -> [现金流净额暴增207%]: 销售回款增加，经营质量显著提升，为资本开支提供支撑。
- **[可转债转股及赎回]** -> [净资产增长37.15%]: 可转债大规模转股并最终赎回，大幅增厚所有者权益，但摊薄每股收益。
- **[海外矿山运营承压]** -> [佩利雅公司亏损2.5亿元]: 澳大利亚子公司受资源禀赋下降和成本上升影响，成为业绩拖累。
- **[铅锌矿产量下降]** -> [精矿铅锌金属量同比减少4.21%]: 矿山资源品位自然衰减，采选量下滑，制约上游利润贡献。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长高度依赖铜冶炼板块的规模扩张，但该板块毛利率仅2.18%，且受制于铜精矿加工费（TC/RC）持续低位。2025年净利润同比大降25.89%，资产减值损失高达4.77亿元，表明公司盈利质量脆弱，对大宗商品价格和加工费波动高度敏感。一旦铜价或加工费出现不利变动，利润将面临更大压力。

**海外资产与汇率风险不容忽视。** 境外资产占净资产17.33%，但澳大利亚佩利雅公司2025年亏损2.5亿元，成为主要拖累。同时，财务费用因汇兑损失飙升45.71%，显示公司对海外运营和汇率波动的管控能力存在短板。此外，多米尼加迈蒙矿项目因基建滞后和当地条件限制，产能释放不及预期，存在持续减值风险。
