# 600403.SH 深度透视

## 因果逻辑链
- **[煤炭市场供需宽松，价格中枢大幅下移]** -> [营收与利润双杀]: 2025年商品煤平均售价同比下降124.03元/吨，导致主营业务收入同比减少16.84%，叠加成本刚性，全年净亏损20.16亿元。
- **[商品煤销量增长12.94%，但售价跌幅更深]** -> [毛利由正转负]: 煤炭采掘业务毛利率降至-10.53%，动力煤和化工煤均出现毛亏损，仅焦煤维持正毛利。
- **[财务费用同比激增38.25%]** -> [侵蚀利润]: 为维持现金流，公司新增融资贷款，利息费用增加，进一步加重亏损。
- **[母公司累计未弥补亏损达48.9亿元]** -> [无法分红]: 不满足现金分红条件，连续三年未进行利润分配，股东回报缺失。
- **[经营活动现金流净流出3.06亿元]** -> [造血能力恶化]: 煤价下跌导致销售回款减少，而刚性成本支出（职工薪酬、税费）降幅有限，现金流由正转负。
- **[固定资产减值损失1.27亿元]** -> [资产质量承压]: 审计报告将固定资产减值列为关键审计事项，反映部分矿井盈利能力下降，资产存在减值风险。
- **[平煤神马集团与河南能源战略重组]** -> [同业竞争风险]: 重组后，大有能源与平煤股份等在煤炭业务上存在重合，虽已出具避免同业竞争承诺，但整合路径尚不明确。

## 风险警告
公司已陷入深度亏损泥潭，2025年归母净利润-20.16亿元，亏损额同比扩大84.8%。核心风险在于煤炭市场供需宽松格局短期难改，而公司成本端（职工薪酬、安全费用、财务费用）刚性极强，导致“量增价跌”无法对冲利润下滑。母公司未分配利润巨额赤字，未来数年分红无望，对价值投资者缺乏吸引力。

更大的隐患在于资产质量与现金流。经营活动现金流净流出3.06亿元，表明主营业务已无法自我造血，需依赖新增融资“借新还旧”。同时，固定资产减值、子公司（孟津煤矿、义络煤业）资不抵债等问题，暗示部分矿井经济可采性存疑。平煤神马集团入主后的同业竞争解决方案，若不能有效整合或注入优质资产，公司长期价值将面临持续折价。
