# 600356.SH 恒丰纸业 深度透视

## 因果逻辑链
- **[进口木浆成本下行]** -> [毛利率提升]: 2025年进口木浆采购成本下降，直接推动营业成本同比下降0.29%，而营收增长1.77%，毛利率提升1.59个百分点。
- **[销量创历史新高]** -> [营收增长]: 国内、国际及新品贸易三大板块协同发力，机制纸销量同比增长3.15%，推动主营业务收入及机制纸销量双创历史新高。
- **[产品结构优化]** -> [利润弹性释放]: 高毛利的烟草工业用纸（毛利率27.49%）占比提升，叠加成本下降，归母净利润同比大增70.72%，远超营收增速。
- **[22号机投产转固]** -> [产能扩张与资本开支下降]: 年产4万吨绿色低定量特种涂布纸项目投产，在建工程大幅下降91.04%，投资活动现金流净流出减少，产能释放为未来增长奠基。
- **[收购锦丰纸业]** -> [管理费用增加与战略布局]: 因收购四川锦丰纸业项目，中介机构费用增加，导致管理费用同比上升13.51%，但此举旨在实现“牡丹江+成都”双基地布局，强化主业。
- **[汇率变动]** -> [财务费用下降]: 人民币汇率波动导致汇兑收益增加，财务费用同比下降17.15%，对利润形成正向贡献。
- **[研发投入持续增加]** -> [技术壁垒巩固]: 研发费用同比增长10.01%，聚焦新型烟草用纸、无铝化替代等前沿领域，维持公司在特种纸细分领域的技术领先地位。

## 风险警告
**核心风险在于原材料价格波动与市场竞争加剧的双重挤压。** 公司主要原材料木浆高度依赖进口，国际浆价波动将直接侵蚀利润。同时，卷烟直接材料用纸领域竞争格局虽相对稳定，但非本细分领域的特种纸企业可能因追逐利润进入，导致产能过剩与价格战，威胁公司核心产品的毛利率。

**另一重大风险是新型烟草技术路线的不确定性。** 公司虽深度布局HNB用纸，但全球新型烟草技术路线（如加热不燃烧、雾化电子烟）仍在快速演变，若主流技术方向发生偏移，公司前期研发投入可能无法转化为预期收益。此外，国际贸易摩擦、地缘政治风险可能影响公司海外市场拓展，尤其是东南亚市场的区域壁垒难以快速突破。
