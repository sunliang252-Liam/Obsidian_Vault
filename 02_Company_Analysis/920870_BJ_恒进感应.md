# 920870.BJ 深度透视

## 因果逻辑链
- **[研发投入激增74%]** -> [净利润下滑23.45%]: 研发费用从848万增至1,477万，远超收入增速，直接侵蚀当期利润，是增收不增利的核心原因。
- **[海外市场突破]** -> [境外收入实现从0到751万]: 子公司恒进数控建成投产并扩大境外业务，直接带动营业收入和净利润增加，成为新增长极。
- **[客户集中度高]** -> [前五大客户收入占比77.29%]: 公司深度绑定风电、工程机械、汽车制造领域龙头，收入高度依赖少数大客户，抗风险能力弱。
- **[合同负债激增60%]** -> [预收货款大幅增加]: 期末合同负债从3,412万增至5,446万，表明在手订单充足，为未来收入确认提供强支撑。
- **[经营现金流净额暴增130%]** -> [回款能力显著改善]: 经营活动现金流净额达5,436万元，远超净利润，主要得益于加强应收账款催收，现金流质量优异。
- **[毛利率持续下滑]** -> [产品结构变化与成本上升]: 毛利率从42.63%降至39.62%，主因机床设备毛利率下降3.49个百分点，以及低毛利业务占比提升。
- **[存货跌价准备激增]** -> [资产减值损失扩大143%]: 存货账面价值高于可变现净值，计提跌价准备125.85万元，反映部分产品可能面临滞销或降价风险。
- **[理财收益贡献显著]** -> [非经常性损益占比过高]: 扣非净利润仅1,014万元，占净利润的61.6%，公允价值变动及投资收益合计640万元，主业盈利能力被高估。

## 风险警告
**核心风险在于“增收不增利”与“客户集中”的双重挤压。** 公司营收增长8.25%，但净利润却下滑23.45%，主因是研发费用激增74%至1,477万元，这虽是长期布局，但短期严重侵蚀利润。同时，前五大客户收入占比高达77.29%，过度依赖少数龙头，一旦下游风电、工程机械行业景气度下行或客户采购策略变化，业绩将剧烈波动。毛利率已从49.57%连续下滑至39.62%，产品竞争力或面临挑战。

**另一个关键风险是主业盈利能力的虚高与资产减值压力。** 扣非净利润仅1,014万元，而理财收益等非经常性损益贡献了632万元，实际经营造血能力远低于账面利润。此外，存货跌价准备同比大增143%，若下游需求放缓，库存积压将进一步拖累业绩。公司规模较小（营收不足1亿），抗风险能力弱，且实际控制人持股超70%，存在不当控制风险。
