# 000157.SZ 深度透视

## 因果逻辑链
- **[海外直销体系深化]** -> [境外收入增长30.52%]: “端对端、本土化、数字化”直销模式叠加全球430+网点与6000本土员工，推动海外收入占比升至58.56%。
- **[土方机械产品矩阵完善]** -> [土方机械收入增长44.99%]: 覆盖全场景产品矩阵（微小挖至超大挖），叠加海外重点区域突破（拉美+77%、欧洲+600%），出口规模跃居国内前三。
- **[矿山机械“绿色化、大型化、智能化”]** -> [矿山机械海外收入增长超3倍]: 聚焦高端矿山装备，成功打入央国企与全球高端矿山市场，新增点亮矿山99座。
- **[新能源产品渗透率提升]** -> [搅拌车/矿卡新能源渗透率达77%/19%]: 58款新能源产品开发与关键零部件突破，直接拉动高毛利产品销量，优化产品结构。
- **[传统优势板块海外扩张]** -> [三大传统产品线出口销售规模同比增幅超20%]: 混凝土、工起、建起三大板块在稳固国内地位同时，加速海外转型，规模与效益同步提升。
- **[数字化转型与极致成本管控]** -> [经营活动现金流净额增长127.53%]: “商机驱动生产”模型与数字化存货管理平台，实现产销联动与降本控存，大幅改善现金流质量。
- **[具身智能机器人产业化落地]** -> [未来产业孵化初具规模]: 开发8款机器人样机，构建120工位训练场与数据飞轮，为第三增长曲线奠定基础。

## 风险警告
**最大风险：海外业务高增长背后的地缘政治与汇率波动风险。** 公司境外收入占比已超58%，且非洲、拉美等新兴区域增速极高（非洲+157%）。这些地区政治经济稳定性较弱，若当地政策突变、贸易摩擦升级或汇率大幅波动（如美元/新兴市场货币），将直接冲击海外收益与资产安全。年报亦明确提示“汇率波动的不确定性导致海外投资、销售存在收益下降的风险”。

**第二大风险：大宗商品价格上行与国内需求复苏不及预期。** 钢材、石油等成本占比较高，若价格持续上行将侵蚀毛利率。同时，国内工程机械市场虽呈“底部复苏”态势，但房地产投资与基建增速仍存不确定性，若国内需求复苏乏力，公司境内收入（同比下降2.29%）可能继续承压，拖累整体业绩。
