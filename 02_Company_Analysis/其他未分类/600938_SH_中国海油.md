# 600938.SH 深度透视

## 因果逻辑链
- **[国际油价震荡下行]** -> [归母净利润下降11.5%]: 2025年布伦特原油均价同比下跌约14.6%，公司实现油价降至66.47美元/桶，直接压缩利润空间。
- **[持续增储上产]** -> [净产量创历史新高]: 全年净产量达777.3百万桶油当量，同比增长7%，以量补价，部分对冲油价下跌影响。
- **[桶油成本持续优化]** -> [盈利韧性增强]: 桶油主要成本降至27.9美元/桶，桶油作业费降至7.46美元/桶，成本优势巩固，在低油价下维持强劲盈利。
- **[勘探成果丰硕]** -> [储量接替基础夯实]: 获得6个新发现，成功评价28个含油气构造，净证实储量增至77.7亿桶油当量，为未来产量增长提供资源保障。
- **[重点项目提前投产]** -> [产量增长动能强劲]: 16个新项目顺利投产，包括圭亚那Yellowtail、巴西Buzios7等海外项目，推动海外产量同比增长2.7%。
- **[天然气业务量价齐升]** -> [收入结构优化]: 天然气销量同比增长13.1%，实现气价上涨3.0%，天然气销售收入同比增长16.9%，成为业绩稳定器。
- **[高股息政策]** -> [股东回报稳定]: 2025年全年股息每股1.28港元，派息率45%，在利润下滑背景下维持高分红承诺，增强投资者信心。

## 风险警告
**核心风险：油价长期低迷与地缘政治冲击。** 公司业绩与布伦特油价高度相关，2025年归母净利润已因油价下跌而显著下滑。若全球经济衰退或OPEC+增产导致油价持续低于60美元/桶，公司盈利、现金流及资产价值将面临重大压力。同时，公司在俄罗斯Arctic LNG 2项目已受制裁影响，海外资产（尤其北美、南美）面临因地缘政治冲突、制裁升级或资源国政策变动导致的资产减值或运营中断风险。

**次要风险：成本控制与储量变现的不确定性。** 尽管当前桶油成本控制良好，但老油田自然递减、新项目开发难度加大及环保投入增加，可能推高未来成本。此外，储量评估基于技术和经济假设，若油价长期低迷或开发技术不达预期，部分未开发储量可能无法实现经济开采，导致资产减值。公司客户与供应商集中度较高，关联交易占比大，任何一方关系变动都可能影响经营稳定性。
