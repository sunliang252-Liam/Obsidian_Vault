# 000592.SZ 深度透视

## 因果逻辑链
- **[与恒大地产合作的地产项目暴雷]** -> [巨额亏损]: 合作方恒大违约，导致地产子公司债务逾期、资产减值及计提巨额延期竣工违约金，是公司连续亏损的核心原因。
- **[贸易业务规模主动收缩]** -> [营收下滑]: 公司优化业务结构，缩减贸易规模，导致2025年营业收入同比下降15.57%。
- **[地产项目计提大额减值及违约金]** -> [侵蚀利润]: 对地产存货计提减值损失9840万元，并支付营业外支出（主要为延期竣工违约金）1.08亿元，直接导致全年净亏损1.13亿元。
- **[林木主业稳健]** -> [业绩基本盘]: 林业及林产品加工业务营收合计约7.64亿元，占总营收57.89%，毛利率稳定，为公司提供稳定的现金流和经营基础。
- **[经营活动现金流大幅转正]** -> [财务风险缓解]: 通过收缩贸易业务减少采购支出，经营活动现金流净额由负转正至2.23亿元，改善了公司流动性。
- **[地产项目申请破产]** -> [风险出清预期]: 公司主动申请对中福建材城进行破产预重整、对中福置业进行破产清算，旨在剥离不良资产，聚焦主业。
- **[控股股东股权高比例质押]** -> [控制权风险]: 控股股东山田实业所持公司17.13%股份中，有3.14%被质押，存在潜在的控制权不稳定风险。

## 风险警告
**核心风险在于地产“后遗症”的持续拖累。** 与恒大合作的两个地产项目（中福建材城、中福置业）已陷入债务危机和诉讼泥潭，公司虽已申请破产预重整/清算，但过程漫长且结果不确定。2025年公司因地产项目计提了高达1.08亿元的延期竣工违约金和近亿元的资产减值，这是导致连续亏损的直接原因。即便剥离成功，前期投入的巨额资金和资源损失已成定局，短期内难以弥补。

**主业增长乏力与转型不确定性并存。** 公司核心的林木及纤维板业务虽稳健，但面临行业产能过剩、原材料价格波动和环保成本上升的压力，毛利率极低（约7-9%），增长空间有限。公司试图通过生物医药、新材料等新业务寻找增长点，但相关子公司（如达成生物）业绩承诺未达标，新设公司尚处早期，短期内无法贡献利润。公司整体盈利能力薄弱，且母公司未分配利润亏损高达-14.26亿元，未来多年将无法进行现金分红。
