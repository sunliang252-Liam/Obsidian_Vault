# 300896.SZ 深度透视

## 因果逻辑链
- **宏观消费疲软与行业竞争加剧** -> **营收与利润双降**: 居民消费意愿谨慎，叠加供给端新品激增，导致公司核心溶液类与凝胶类注射产品收入分别同比下降27.48%和26.82%，归母净利润下降34.05%。
- **收购REGEN公司并表** -> **商誉激增与国际化突破**: 以1.90亿美元收购韩国REGEN公司85%股权，新增商誉16.41亿元，同时获得AestheFill等全球知名产品及37国销售渠道，完成国际化关键布局。
- **REGEN原经销商仲裁纠纷** -> **海外业务不确定性**: 因原经销商达透公司违约，REGEN公司单方解约并提起仲裁，涉案金额高达16亿元，对REGEN未来在中国大陆的销售构成重大风险。
- **销售费用与管理费用大幅增长** -> **侵蚀利润**: 销售费用同比增长39.72%（人工、广宣、会议费增加），管理费用同比增长48.62%（并购咨询费、律师费增加），显著拖累净利润表现。
- **直销模式收入下滑，经销模式收入微增** -> **渠道结构变化**: 直销收入同比下降29.98%，而经销收入同比微增2.84%，显示公司在终端动销压力下，更依赖经销商渠道进行市场覆盖。
- **研发投入持续高增** -> **构筑长期壁垒**: 研发投入3.6亿元，占营收14.67%，聚焦司美格鲁肽、肉毒毒素等重磅产品，虽短期侵蚀利润，但为未来产品矩阵扩张奠定基础。
- **米诺地尔搽剂与A型肉毒毒素获批** -> **拓展新增长曲线**: 米诺地尔搽剂（治脱发）和注射用A型肉毒毒素（除皱）相继获批，公司从单一玻尿酸填充向“医美+大健康”综合平台转型。
- **嗗科拉（下巴填充）等新品上市** -> **丰富产品组合**: 新产品“嗗科拉”于2025年5月上市，与“嗨体”、“濡白天使”形成协同，覆盖更多适应症，但短期内尚无法弥补核心产品下滑。

## 风险警告
**核心风险在于业绩失速与高估值之间的矛盾。** 公司2025年营收和净利润双双出现上市以来首次大幅下滑，核心产品“嗨体”等面临激烈的同质化竞争和价格压力，增长引擎明显减速。同时，为应对颓势，公司大幅增加销售和管理费用，进一步侵蚀了利润空间，导致ROE从28%骤降至17%，基本面恶化趋势显著。

**国际化并购带来的整合风险与商誉减值风险不容忽视。** 公司以高溢价收购REGEN公司，形成16.4亿元巨额商誉。然而，REGEN核心产品AestheFill在中国大陆的独家经销协议已陷入高达16亿元的仲裁纠纷，未来销售存在重大不确定性。若整合失败或仲裁结果不利，不仅海外增长预期落空，还将面临巨大的商誉减值风险，对资产负债表和利润表造成双重冲击。
