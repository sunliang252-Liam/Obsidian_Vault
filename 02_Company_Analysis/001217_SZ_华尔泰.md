# 001217.SZ 深度透视

## 因果逻辑链
- **[新项目投产转固，折旧激增]** -> [净利润由盈转亏]: 合成氨节能升级改造等重大项目于2025年转固，固定资产同比暴增143%，公司采用双倍余额递减法加速计提折旧，导致制造费用同比飙升238.69%，严重侵蚀利润。
- **[大宗化学品销量增长，但价格承压]** -> [营收增长26.24%，但毛利率下滑]: 公司通过拓展市场实现基础化工产品销量增长8.7%，但部分产品价格低位运行，叠加成本上升，导致基础化工毛利率同比下降8.07个百分点。
- **[原材料价格剧烈波动]** -> [成本控制难度加大]: 核心原料硫磺价格下半年同比大涨48%，而原料煤和尿素价格下跌，成本端结构性分化，公司未能完全向下游传导成本压力。
- **[精细化工业务增长乏力]** -> [拖累整体盈利]: 精细化工收入仅微增0.28%，毛利率为负（-5.79%），其中苯二胺产能利用率仅23.5%，远未达产，成为业绩拖累。
- **[经营活动现金流大幅下降]** -> [现金流质量恶化]: 尽管营收增长，但购买原材料现金支付增加，导致经营活动现金流净额同比减少57.62%，与净利润亏损趋势一致，显示营运资金压力加大。
- **[研发投入持续增加]** -> [支撑未来技术转型]: 研发费用同比增长34.42%，主要用于合成氨、双氧水、苯二胺等工艺技术研发，旨在推动向精细化工和新材料领域转型。

## 风险警告
华尔泰2025年陷入“增收不增利”的典型困境，核心风险在于**新项目投产后的折旧吞噬利润**。合成氨制气节能环保升级改造等重大项目转固，导致固定资产账面价值从8.47亿激增至20.59亿，采用双倍余额递减法计提折旧，使得制造费用同比暴增238.69%，这是公司由盈转亏的直接原因。若新项目无法在短期内实现满产达效并提升产品溢价，高额折旧将持续压制公司盈利能力。

此外，公司面临**产品价格与成本的双重挤压**。基础化工品价格受宏观经济和行业供需影响波动剧烈，而核心原料硫磺价格大幅上涨，公司成本控制能力承压。同时，精细化工战略推进缓慢，苯二胺等新项目产能利用率极低，未能形成有效利润增长点，反而增加了运营负担。公司转型成效尚需时间验证，短期业绩改善动能不足。
