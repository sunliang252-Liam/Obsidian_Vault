# 002063.SZ 深度透视

## 因果逻辑链
- **[央企数智化转型与穿透式监管政策]** -> [业绩增长]: 国资委要求央企“十五五”末建成DRP平台，公司DAP产品直接受益，驱动营收增长8.08%。
- **[智慧能源业务爆发]** -> [收入结构优化]: 智慧能源收入同比+47.09%，成本同比+78.17%，毛利率下降15.19个百分点，显示该业务处于快速扩张但盈利承压阶段。
- **[研发投入资本化率大幅提升]** -> [利润平滑]: 研发费用同比-30.76%，资本化率从18.45%升至34.32%，短期美化利润，但无形资产摊销压力后移。
- **[应收账款账龄恶化]** -> [信用减值损失激增]: 信用减值损失同比+296.25%，反映回款周期拉长，客户付款能力或项目验收进度不及预期。
- **[国家电网深度绑定]** -> [收入确定性]: 前五大客户中关联方销售占比13.21%，国家电网智慧共享财务平台覆盖95万用户，形成高粘性收入基本盘。
- **[AI智能体产品化]** -> [新增长极]: 推出近100个智能体，AI收入同比+11.93%，但毛利率53.68%低于数字企业业务，产品标准化程度有待提升。
- **[子公司业务扩张]** -> [成本结构恶化]: 外购软硬件及服务成本同比+30.98%，智慧能源子公司业务规模扩大导致营业成本增速远超收入增速。

## 风险警告
**应收账款风险是最大隐患。** 公司应收账款占总资产39.94%，信用减值损失同比暴增296.25%，远超营收增速。软件项目验收周期长、客户付款流程复杂，若宏观经济下行或客户预算收紧，坏账风险将直接侵蚀利润。当前净利润增速（2.44%）已远低于营收增速（8.08%），减值压力是核心拖累。

**智慧能源业务“增收不增利”趋势明显。** 该板块收入增长47.09%，但成本增长78.17%，毛利率骤降15.19个百分点。子公司扩张依赖外购软硬件（成本同比+31%），若不能快速提升自研产品占比或实现规模效应，该业务将成为利润的“出血点”。同时，研发资本化率异常提升（34.32%），需警惕未来无形资产摊销对利润的持续压制。
