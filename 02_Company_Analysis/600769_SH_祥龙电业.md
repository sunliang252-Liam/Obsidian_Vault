# 600769.SH 深度透视

## 因果逻辑链
- **建筑业材料成本上涨36.76%，机械成本上涨94.47%** -> 建筑业毛利率上升7.10个百分点: 尽管材料与机械成本大幅上升，但人工成本下降20.72%，收入增速（16.50%）超过成本增速（8.73%），导致毛利率提升。
- **供水业务其他成本同比增加135.11%** -> 供水业务毛利率下降0.93个百分点: 供水成本中其他项目大幅增长，导致总成本增速（4.21%）高于收入增速（2.35%），毛利率微降。
- **建筑业业务收入增长16.50%** -> 合同资产增加52.77%: 建筑业务扩张导致未完工项目增加，进而合同资产余额上升。
- **建筑业务收入增长** -> 应付账款增加44.70%: 业务扩张带动采购和分包增加，形成更多应付账款。
- **公司购买理财产品增加** -> 交易性金融资产增加76.04%: 公司本期加大理财投资，导致交易性金融资产余额大幅上升。
- **三期工程项目施工** -> 在建工程增加343.13%: 供水三期工程投入施工，在建工程大幅增加。
- **客户集中度高，营收规模小** -> 经营风险较高: 公司营收规模小且前五名客户占销售额83.31%，客户集中度高，重点客户经营波动将显著影响公司收入。
- **建筑业务回款慢、结算周期长** -> 资金周转压力大: 建筑业务结算流程繁琐、周期长，导致现金流紧张，加剧资金周转压力。

## 风险警告
公司营收规模小，客户高度集中（前五客户占比83.31%），重点客户波动可能造成收入大幅下降；建筑业务回款周期长，现金流压力大；供水业务成本控制面临压力（其他成本激增），新产能投产存在不确定性。
