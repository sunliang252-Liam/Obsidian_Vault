# 603163.SH 深度透视

## 因果逻辑链
- **[AI算力与半导体资本开支扩张]** -> [营收与订单创历史新高]: 下游IC半导体、精密制造客户加大资本开支，公司新签订单38.31亿元（+60%），营收29.89亿元（+48.85%），净利润1.55亿元（+35.09%）。
- **[东南亚产业链转移与本土化布局]** -> [境外营收爆发式增长]: 越南、泰国子公司深耕PCB、SMT组装厂客户，境外营收12.54亿元（+85.11%），占比升至42%，成为核心增长引擎。
- **[策略性承接大型项目与市场竞争加剧]** -> [毛利率持续承压]: 为深化战略合作与巩固市场地位，公司承接部分低毛利大型项目，叠加行业竞争白热化，主营业务毛利率降至10.21%（-2.3pct）。
- **[“多客户、多产业、多区域”战略]** -> [客户结构分散，抗周期能力强]: 业务覆盖IC半导体、精密制造、光电等多领域，前五大客户销售额占比52.62%，不依赖单一客户或行业，平滑下游周期波动。
- **[EPCO全产业链服务能力]** -> [项目执行高效，客户粘性强]: 具备从设计到运维的一体化能力，累计实施超500项洁净室工程，与上百家头部企业建立长期合作，保障订单持续性与项目质量。
- **[海外子公司高增长与高税负]** -> [所得税费用显著增加]: 泰国、越南子公司利润大幅增长，但当地所得税率较高，导致整体所得税费用同比增加34.46%，侵蚀部分净利润。
- **[应收账款与合同资产随营收扩张]** -> [信用减值损失增加，营运资金承压]: 期末应收账款5.72亿元（+58%），合同资产6.28亿元（+11%），导致信用减值损失同比增加635%，公司垫资规模扩大，资金需求上升。

## 风险警告
**核心风险在于毛利率持续下滑与资金流动性压力。** 公司2025年毛利率已降至10.21%，且管理层明确表示市场竞争激烈及策略性接单将持续压制毛利。在营收高速扩张的同时，应收账款与合同资产合计超12亿元，信用减值损失激增，经营性现金流净额虽转正但远低于净利润水平，显示公司利润质量不高，垫资模式对营运资金形成巨大考验。

**海外业务扩张带来双重风险。** 一方面，境外营收占比已达42%，但当地所得税负较高，侵蚀净利润；另一方面，汇率波动（尤其是越南盾、泰铢）对财务费用和报表折算差额影响显著，2025年财务费用因汇兑收益而大幅波动，未来若人民币升值或东南亚货币贬值，将对利润产生不利冲击。此外，公司对子公司担保总额高达8.34亿元，占净资产71.35%，若海外子公司经营不善，担保风险将传导至母公司。
