# 603429.SH 深度透视

## 因果逻辑链
- **[核心客户流失与业务萎缩]** -> [营收暴跌62.64%]: 2024年处置部分印刷业务子公司，叠加市场需求疲软，导致2025年合并范围缩小、订单锐减，主营收入从4.58亿骤降至1.71亿。
- **[烟用接装纸业务归零]** -> [产品结构剧变]: 因处置子公司，核心产品烟用接装纸收入完全消失，公司被迫转向烟标、社会包装及电化铝等产品，但新业务体量远不足以弥补缺口。
- **[烟标业务毛利率转负]** -> [盈利质量恶化]: 烟标收入下降60.55%，但成本仅下降34.61%，导致毛利率从正转负至-2.96%，核心业务已陷入“卖得越多亏得越多”的困境。
- **[电化铝业务暴增但毛利骤降]** -> [虚假繁荣]: 电化铝收入暴增2293%，但成本增速（4320%）远超收入，毛利率从52.95%暴跌至13.50%，表明该增长依赖低毛利、低附加值的代工或贸易，不可持续。
- **[连续两年亏损与营收低于3亿]** -> [触发*ST退市风险警示]: 2025年扣非净利润-2360万，营收仅1.64亿（扣除后），触发了财务类退市指标，公司股票将被实施退市风险警示。
- **[控股股东股份高比例冻结]** -> [治理与信用风险]: 实控人徐善水所持60%股份被司法冻结，源于其个人担保的股权转让纠纷，虽未直接影响经营，但严重削弱了公司信用和融资能力。
- **[储能新业务尚处研发中试]** -> [转型前景高度不确定]: 公司押注固态电池关键材料，但该业务尚在建设中试基地，无任何收入贡献，且公司无相关经验，项目存在延期、中止甚至失败的风险。

## 风险警告
**核心风险是退市与主业崩塌。** 公司已因“营收低于3亿+净利润为负”触发*ST，2026年是决定生死的关键一年。然而，其赖以生存的烟标业务毛利率已为负，社会包装业务大幅萎缩，唯一增长的电化铝业务毛利率极低且不可持续。主业已丧失造血能力，仅靠变卖资产和关联交易勉强维持，若无根本性业务重组，2026年大概率继续亏损并面临终止上市。

**转型风险与治理风险叠加。** 公司试图跨界储能材料实现“救命稻草”，但该业务尚处实验室到中试的早期阶段，技术、团队、市场均存在巨大不确定性，短期内无法贡献利润。同时，控股股东超60%股份被司法冻结，不仅反映了实控人个人的债务危机，也严重限制了公司通过股权融资或并购进行自救的能力，使公司陷入“主业失血、新业未立、融资受阻”的恶性循环。
