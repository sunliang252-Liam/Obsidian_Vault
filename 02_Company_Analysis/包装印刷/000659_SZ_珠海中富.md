# 000659.SZ 深度透视

## 因果逻辑链
- **[营收下滑与客户集中]** -> [连续三年亏损]: 前五大客户贡献66.98%收入，客户自配套趋势挤压外购需求，导致营收同比-1.96%，扣非净利润连续三年为负。
- **[高财务杠杆侵蚀利润]** -> [净资产持续缩水]: 短期借款+长期借款+应付债券合计超9.8亿元，年利息费用9719万元，占营收9.8%，导致加权平均ROE为-69.67%。
- **[资产处置掩盖经营困境]** -> [非经常性损益支撑报表]: 处置新疆不动产获收益1388万元，若剔除该收益及公允价值变动，主业亏损更为严重。
- **[产能扩张与需求错配]** -> [资产减值损失加剧]: 新增瓶胚产能4万吨、无菌线产能2.2亿瓶，但下游需求疲软导致固定资产减值1864万元。
- **[现金流改善但造血能力弱]** -> [经营现金流与利润背离]: 经营活动现金流净额1.18亿元（+12.87%），但净利润亏损1.15亿元，现金流改善主要来自应付账款及预收款项增加。
- **[股权激励失效]** -> [管理层信心不足]: 2024年股票期权激励计划因业绩未达标，已注销59.7万份期权，剩余56.6万份亦将全部注销。

## 风险警告
**核心风险：资不抵债边缘与持续经营能力存疑。** 公司合并报表未分配利润-19.49亿元，归属于母公司净资产仅1.10亿元，同比腰斩50.57%。短期借款+一年内到期非流动负债合计8.86亿元，而货币资金仅1.23亿元，短期偿债压力巨大。控股股东借款3.6亿元（年息6%）虽缓解流动性，但进一步推高财务费用，形成“借新还旧”的恶性循环。

**经营风险：客户集中与行业竞争双重挤压。** 前两大客户（可口可乐、百事可乐体系）贡献超43%收入，客户自配套趋势（如减少外购PET瓶）直接冲击公司核心业务。饮料包装行业充分竞争，公司毛利率仅15.56%，且研发投入仅331万元（占营收0.34%），缺乏技术护城河。公司虽布局OEM代工转型，但代工业务毛利率仅1.20%，几乎无利润贡献。
