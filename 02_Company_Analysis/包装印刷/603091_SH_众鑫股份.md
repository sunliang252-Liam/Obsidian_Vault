# 603091.SH 深度透视

## 因果逻辑链
- **[美国“双反”终裁落地]** -> [营收与利润双降]: 美国对华纸浆模塑产品征收高额关税，直接阻断中国向美国出口，导致公司国内产量下降19.76%，归母净利润同比下滑17.79%。
- **[泰国工厂提前投产]** -> [对冲贸易风险]: 公司2023年布局的泰国基地在2025年末形成7.5万吨产能，及时承接美国客户订单，避免了营收断崖式下跌，并贡献净利润1.63亿元。
- **[收购东莞达峰]** -> [开辟第二增长曲线]: 通过收购快速切入精品工业包装（3C电子、高端礼盒），实现“餐饮具+工业包装”双轮驱动，其他环保包装收入同比增长64.14%。
- **[自主研发生产装备]** -> [构筑成本护城河]: 公司自研自动化产线，迭代速度快，泰国新工厂能耗更低、效率更高，使毛利率（32.24%）显著高于依赖外购设备的同行。
- **[“以销定产+合理库存”]** -> [经营现金流强劲]: 精准的排产与库存管理，叠加原材料采购支出减少，使经营活动现金流净额达4.17亿元，同比增长30.36%，远超净利润。
- **[全球“禁塑令”持续落地]** -> [长期需求确定]: 欧盟、加拿大、日本等主要市场持续扩大禁塑范围，为纸浆模塑产品提供广阔市场空间，行业预计2026-2033年CAGR达6.3%。
- **[甘蔗渣浆为主要原料]** -> [成本与ESG双赢]: 利用制糖业废弃物作为原料，既降低了原材料成本，又通过采购农业废弃物为农民增收5276万元，强化了绿色品牌形象。

## 风险警告
**核心风险：美国“双反”及加拿大调查的持续冲击。** 2025年美国终裁已导致公司国内产量锐减近20%，虽然泰国工厂暂时承接了部分订单，但泰国产能爬坡存在不确定性，且加拿大反倾销调查初裁结果不利。若全球贸易保护主义进一步蔓延，公司可能面临海外订单流失和产能利用率下降的双重压力。

**第二风险：海外扩张的“双刃剑”效应。** 公司正加速全球化布局（泰国扩产至10万吨、计划在美国建厂），但海外投资面临地缘政治、文化差异、汇率波动及管理半径扩大等挑战。泰国工厂的盈利能否持续，以及美国建厂的高昂成本与回报周期，是未来利润表的重要变量。
