# 002117.SZ 深度透视

## 因果逻辑链
- **[传统票证印刷市场萎缩]** -> [印刷产品收入下降13.81%]: 电子发票全面普及、纸质发票需求锐减，直接冲击公司核心印刷业务。
- **[智能卡与RFID产品爆发]** -> [该业务收入增长60.66%]: 社保卡换发高峰、RFID在零售与物流渗透率提升，驱动新业务高速增长。
- **[扣非净利润增长12%]** -> [归母净利润下降8.65%]: 主业盈利能力改善（毛利率提升），但2024年非流动资产处置收益等非经常性损益高基数，导致归母净利润下滑。
- **[销售费用增长24.06%]** -> [营收仅微增0.68%]: 为应对传统业务萎缩，公司加大市场开拓投入，但增量投入未能有效转化为收入增长，销售效率承压。
- **[技术服务业务毛利率提升3.78%]** -> [服务业收入微增1.96%]: 档案数字化与电子票证业务向高附加值服务转型，成本控制有效，但收入增长乏力，AI机器人尚未形成规模收入。
- **[无控股股东、无实际控制人]** -> [公司治理稳定但战略决策可能缺乏强力推动]: 股权结构分散，前三大股东持股比例接近，任何单一股东无法主导，决策依赖管理层共识。
- **[研发投入聚焦AI具身机器人]** -> [新业务尚未贡献收入]: 公司押注AI陪伴机器人等新赛道，但原型机刚发布，商业化路径与业绩贡献存在较大不确定性。

## 风险警告
**传统业务失速与转型青黄不接是核心风险。** 印刷产品收入同比下降13.81%，电子发票对纸质票证的替代不可逆转，公司核心现金牛业务正加速萎缩。尽管智能卡与RFID业务增长60.66%，但其收入体量（3.14亿）尚无法完全弥补印刷业务（6.53亿）的下滑缺口，且该业务毛利率仅24.39%，显著低于印刷产品（34.18%），拉低整体盈利质量。

**新业务（AI机器人）的投入产出存在巨大不确定性。** 公司研发的AI陪伴机器人原型机于2025年末发布，预计2026年春季发售，目前尚未形成任何收入。该赛道竞争激烈，技术迭代快，公司作为传统印刷企业跨界进入，缺乏品牌、渠道和算法生态积累。研发投入资本化率为0，意味着所有投入均当期费用化，若商业化失败，将直接侵蚀利润，且无法形成有效资产。
