# 002752.SZ 深度透视

## 因果逻辑链
- **[下游消费疲软]** -> [净利润下滑27.44%]: 饮料啤酒行业整体需求不振，导致公司核心产品易拉罐&铝瓶毛利率同比下降3.96个百分点，盈利能力显著承压。
- **[原材料成本高企]** -> [毛利率承压]: 直接材料占主营业务成本85.97%，铝、马口铁价格高位震荡，公司无法完全向下游转嫁成本，导致金属包装行业毛利率从14.90%降至10.99%。
- **[海外产能扩张]** -> [境外收入增长14.42%]: 柬埔寨金边工厂稳定运营，印尼工厂试生产，越南项目启动，境外业务成为对冲国内需求疲软的关键增长引擎。
- **[“贴进式”生产布局]** -> [市场份额稳中有升]: 贴近核心客户建厂，降低运输与管理成本，在行业下行期仍实现销量5.89%的增长，巩固了与养元、红牛、青啤等大客户的合作关系。
- **[精益管理与数字化]** -> [运营效率提升]: 全年完成76项制造降本项目，MOM、SRM等系统上线，在收入持平的情况下，经营活动现金流净额逆势增长6.85%至5.6亿元。
- **[高端铝瓶产品领先]** -> [差异化竞争优势]: 收购博德科技后，高端铝瓶产能与技术水平行业领先，精准卡位啤酒消费升级趋势，为未来增长储备动能。
- **[募投项目延期与未达产]** -> [资产回报率低于预期]: 云南、安徽、武汉等募投项目因市场变化及客观因素延期，产能爬坡缓慢，累计实现效益远低于承诺，拖累整体ROE。

## 风险警告
**核心风险在于下游需求持续疲软与原材料成本高企的双重挤压。** 公司2025年营收仅微增0.61%，但净利润暴跌27.44%，主因是毛利率大幅下滑。直接材料成本占比高达86%，而公司对下游大客户的议价能力有限，成本转嫁机制不畅。若2026年消费复苏不及预期，或铝、马口铁价格继续上涨，公司盈利能力将进一步恶化。

**海外扩张与募投项目存在重大不确定性。** 越南、印尼等海外项目尚处建设或爬坡期，面临地缘政治、汇率波动及当地市场拓展风险。同时，多个核心募投项目（云南、安徽、武汉）因市场变化延期，产能利用率低，累计效益远低于预期，存在持续拖累业绩及商誉减值的风险。公司需证明其海外布局和新增产能能够有效转化为利润。
