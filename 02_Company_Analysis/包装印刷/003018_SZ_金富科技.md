# 003018.SZ 深度透视

## 因果逻辑链
- **[新基地投产带来的折旧与搬迁扰动]** -> [营收与利润双降]: 2025年东莞、湖南新基地全面投产，前期折旧摊销成本增加，且设备搬迁调试导致产能短期受限，叠加下游需求波动，营收同比下降14.80%，归母净利润同比下降28.56%。
- **[全国化产能布局完成]** -> [长期成本优势与供给能力提升]: 五大生产基地（东莞、湖南、四川、河北、广西）全面投产，彻底解决产能瓶颈，为后续规模化降本、区域市场高效供应及订单承接奠定基础。
- **[核心客户高度集中]** -> [业绩稳定性与潜在风险并存]: 前五大客户销售占比高达76.00%（华润怡宝、景田等），长期稳定合作保障了业务基本盘，但单一客户需求波动将直接冲击公司业绩。
- **[原材料价格波动]** -> [利润空间受挤压]: HDPE及铝片占原材料采购总额约80%，其价格受国际油价及供需关系影响，若大幅上涨将直接侵蚀公司毛利率。
- **[收购切入液冷赛道]** -> [开启第二增长曲线]: 2026年初收购卓晖金属、联益热能各51%股权，切入AI服务器液冷散热高景气赛道，确立“包装+液冷”双轮驱动战略，旨在打造新利润增长点。
- **[经营现金流强劲]** -> [盈利质量健康]: 尽管利润下滑，但经营活动现金流净额达2.11亿元，同比增长14.88%，主要系新增固定资产折旧（非现金支出）所致，表明公司主业造血能力依然稳健。

## 风险警告
公司面临的核心风险在于**主业增长乏力与跨界整合的不确定性**。2025年营收与利润双降，暴露出传统饮料包装业务已进入成熟期，增长依赖下游大客户需求，且受原材料价格波动影响显著。公司前五大客户集中度高达76%，任何核心客户的订单流失都将对业绩造成重大打击。同时，HDPE等主要原材料价格与国际油价挂钩，成本端存在不可控风险。

更为关键的风险来自**2026年新并购的液冷业务**。公司以约5.7亿元现金收购卓晖金属和联益热能，跨界进入AI服务器液冷散热领域。该业务虽处于高景气赛道，但公司缺乏相关行业经验，面临收购整合、管理融合、技术协同等多重挑战。交易对手承诺2026年净利润不低于1.1亿元，若未能达标，将产生商誉减值风险，对公司利润表造成巨大冲击。此外，液冷行业竞争激烈，技术迭代迅速，公司能否在巨头环伺的市场中站稳脚跟，尚待验证。
