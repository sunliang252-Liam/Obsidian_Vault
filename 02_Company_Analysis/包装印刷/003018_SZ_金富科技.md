# 003018.SZ 深度透视

## 因果逻辑链
- **[新基地投产带来的折旧与搬迁扰动]** -> [营收与利润双降]: 2025年东莞、湖南新基地全面投产，前期折旧摊销成本增加，且设备搬迁调试导致产能短期受限，叠加下游需求波动，营收同比下降14.80%，归母净利润同比下降28.56%。
- **[全国化产能布局完成]** -> [长期成本优势与供给能力提升]: 五大生产基地（东莞、湖南、四川、河北、广西）全面投产，彻底解决产能瓶颈，为后续规模化降本、区域市场高效供应及订单承接奠定基础。
- **[核心客户高度集中]** -> [业绩稳定性与潜在风险并存]: 前五大客户销售占比高达76.00%（华润怡宝、景田等），长期稳定合作保障了业务基本盘，但单一客户需求波动将直接冲击公司业绩。
- **[原材料价格波动]** -> [利润空间受挤压]: HDPE及铝片占原材料采购总额约80%，其价格受国际油价及供需关系影响，若大幅上涨将直接侵蚀公司毛利率。
- **[收购切入液冷赛道]** -> [开启第二增长曲线]: 2026年初收购卓晖金属、联益热能各51%股权，切入AI服务器液冷散热高景气赛道，确立“包装+液冷”双轮驱动战略，旨在打造新利润增长点。
- **[经营现金流强劲]** -> [盈利质量健康]: 尽管利润下滑，但经营活动现金流净额达2.11亿元，同比增长14.88%，主要系新增固定资产折旧（非现金支出）所致，表明公司主业造血能力依然稳健。

## 风险警告
公司面临的核心风险在于**主业增长乏力与跨界整合的不确定性**。2025年营收与利润双降，暴露出传统饮料包装业务已进入成熟期，增长依赖下游大客户需求，且受原材料价格波动影响显著。公司前五大客户集中度高达76%，任何核心客户的订单流失都将对业绩造成重大打击。同时，HDPE等主要原材料价格与国际油价挂钩，成本端存在不可控风险。

更为关键的风险来自**2026年新并购的液冷业务**。公司以约5.7亿元现金收购卓晖金属和联益热能，跨界进入AI服务器液冷散热领域。该业务虽处于高景气赛道，但公司缺乏相关行业经验，面临收购整合、管理融合、技术协同等多重挑战。交易对手承诺2026年净利润不低于1.1亿元，若未能达标，将产生商誉减值风险，对公司利润表造成巨大冲击。此外，液冷行业竞争激烈，技术迭代迅速，公司能否在巨头环伺的市场中站稳脚跟，尚待验证。

**公司简介（F10 原文）**

> 金富科技股份有限公司成立于2001年,2020年在深圳证券交易所挂牌上市(股票简称:金富科技,股票代码:003018)。公司主要从事应用于饮料、食品等领域用的包装产品研发、设计、生产和销售。公司产品按照应用领域的不同,主要可分为应用于瓶装纯净水、矿泉水的3025盖、2925盖、T2925盖、1881盖;应用于桶装饮用水的PC桶装水盖、4.5L桶装水盖;应用于瓶装功能饮料的38盖、1881盖;应用于玻璃瓶装、铝瓶装等含气系列饮料包装新型拉环盖;应用于调味品系列(酱油、调料等)产品的塑料组合盖;应用于奶制品包装等瓶盖,应用于软包装(糖浆、果冻、食用油等)系列塑料组合盖;及应用其他领域的包装产品。公司深耕瓶盖产品市场超过二十年,得到下游知名企业华润怡宝、景田、可口可乐、燕京集团、达能的认可,成为上述企业瓶盖主要供应商之一并获得优秀供应商奖。其中,2018年获得华润怡宝颁发的十年合作贡献奖,2019年获得由达能颁发的2019年度合作共赢奖,2020年获得由广西太古可口可乐公司颁发的2020年优秀供应商奖,2023年分别获得由华润怡宝颁发的“卓越贡献奖”金奖和“长期服务奖”银奖、由可口可乐颁发的技术进步奖,公司产品被评为“广东省名牌产品”,公司荣获了“高新技术企业”、“专精特新中小企业”“中国包装饮用水行业优质配套供应商”等系列荣誉。公司通过多年的积累,已在技术研发、品牌声誉、产品品类、生产效率等方面形成了一定的优势,行业地位突出。公司现已成为国内规模较大的塑料防盗瓶盖供应商之一。作为高新技术企业,公司持续注重研发创新和科技创新,高度重视技术积累和储备。公司以“成为瓶盖行业受信赖的企业”为愿景,持续提升公司品牌价值,旨在打造一个“让客户享受优质的产品及服务”、“让员工分享企业的发展与利益”的企业,致力于成为国内饮料和食品瓶盖行业极具专业资质能力的企业之一。公司将以市场为导向,以应用于饮料和食品包装领域的瓶盖业务的研发、生产、销售和相关配套服务为主业,并逐步拓展应用于包装行业的相关产品和业务。
