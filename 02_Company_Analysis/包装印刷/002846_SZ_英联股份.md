# 002846.SZ 深度透视

## 因果逻辑链
- **[金属包装主业产能释放与降本增效]** -> [净利润扭亏为盈]: 汕头、扬州两大智能基地产能持续释放，饮料易开盖营收增长18.97%，叠加精益管理降本，综合毛利率提升，驱动归母净利润从-3967万增至3529万。
- **[饮料易开盖市场拓展]** -> [营收规模增长]: 饮料易开盖营收同比增长18.97%至7.70亿元，成为金属包装板块最大增量来源，推动总营收增长12.04%。
- **[海外市场稳步增长]** -> [出口收入提升]: 出口收入7.44亿元，同比增长10.87%，全球化布局显成效，有效分散国内市场竞争风险。
- **[复合集流体业务持续投入]** -> [战略亏损]: 子公司江苏英联仍处产业化初期，2025年亏损5090万元，拖累整体利润，但已获韩国U&S ENERGY及某新能源科技公司订单，产业化进程加速。
- **[增值税加计抵减]** -> [非经常性收益贡献]: 报告期内确认增值税加计抵减相关损益，对当期经营业绩产生正向贡献。
- **[扬州英联扭亏为盈]** -> [子公司经营改善]: 扬州英联通过优化产品结构、提升产能利用率，实现净利润1229.72万元，较上年亏损6232万元显著改善。

## 风险警告
复合集流体业务是公司第二增长曲线，但至今仍处于大规模量产前夜。2025年该板块营收仅245万元，亏损却达5090万元，且规划总投资30.89亿元，资金压力巨大。若下游客户验证周期延长、技术路线切换或量产良率不及预期，该业务将持续侵蚀主业利润，甚至引发流动性危机。

金属包装主业虽已扭亏，但原材料（铝材、马口铁）价格波动风险始终高悬。公司原材料成本占比极高，若进入上行周期，毛利率将直接承压。同时，行业竞争加剧、下游消费需求变化等风险，可能使公司重回亏损轨道。
