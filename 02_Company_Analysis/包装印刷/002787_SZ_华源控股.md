# 002787.SZ 深度透视

## 因果逻辑链
- **[财务费用大幅下降]** -> [净利润增长60%]: 可转债到期，利息支出减少，直接增厚利润。
- **[原材料成本下降]** -> [毛利率提升2.21%]: 马口铁、塑料颗粒采购成本降低，成本降幅（-8.10%）大于收入降幅（-5.63%）。
- **[经营活动现金流暴增]** -> [现金流健康度改善]: 支付的材料款和税费减少，现金流净额增长128%，远超净利润增速。
- **[高端客户群稳固]** -> [收入基本持平]: 立邦、阿克苏、壳牌等大客户订单稳定，对冲了部分市场下滑风险。
- **[并购切入半导体]** -> [开辟第二增长曲线]: 收购暖芯科技、设立致源真空，布局半导体温控设备与分子泵，寻求新利润点。
- **[回购与注销股份]** -> [增厚每股收益]: 注销635万股，总股本减少，基本每股收益从0.22元提升至0.34元。
- **[资产减值损失]** -> [侵蚀利润]: 计提存货跌价准备约2049万元，占利润总额的15.2%，是利润的主要减项。

## 风险警告
**主业增长乏力，新业务尚在襁褓。** 公司营收同比下降5.63%，金属与塑料包装两大主业销量均下滑（金属-12.37%，塑料-6.01%），显示传统包装业务已进入存量博弈阶段。虽然公司通过成本管控和财务优化实现了利润大增，但这并非来自业务的内生增长。新切入的半导体业务（暖芯科技、致源真空）尚处于起步阶段，2025年仅贡献少量并表利润，能否成为真正的第二增长曲线存在巨大不确定性。

**客户集中度极高，并购整合风险不容忽视。** 前五大客户销售额占比高达57.18%，过度依赖立邦、阿克苏等少数大客户，一旦核心客户流失或压价，将对公司业绩造成重大冲击。同时，公司连续收购半导体标的，若未来整合不力或行业景气度下行，将面临商誉减值风险，直接侵蚀来之不易的利润。公司计划不派发现金红利，也反映出其对未来资金需求的审慎态度。
