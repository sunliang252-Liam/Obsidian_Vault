# 301223.SZ 深度透视

## 因果逻辑链
- **[礼盒及外销业务高增长]** -> [营收增长13.85%]: 礼盒收入同比+57.27%，外销收入同比+60.96%，成为营收增长的核心驱动力。
- **[收购茉织华印务及淮北甲古文]** -> [营收与资产规模扩张]: 并购贡献增量收入，同时导致商誉减值风险（本期计提2368万元）。
- **[原材料成本控制与产品结构优化]** -> [毛利率提升1.71个百分点]: 直接材料成本占比下降，高毛利产品（礼盒、其他印刷品）占比提升，带动整体毛利率改善。
- **[研发投入持续增加]** -> [技术壁垒与产品创新]: 研发费用同比+18.21%，聚焦环保去塑、智能防伪等方向，支撑长期竞争力。
- **[资产减值损失扩大]** -> [净利润增速低于营收]: 计提存货跌价准备及商誉减值合计4787万元，侵蚀利润，导致净利润仅增长6.82%。
- **[经营活动现金流强劲]** -> [盈利质量良好]: 经营性现金流净额3.39亿元，远超净利润1.57亿元，主要受折旧摊销等非付现成本影响。
- **[多区域产能布局]** -> [响应客户JIT模式]: 国内华南至西南、海外越南基地协同，实现就近采购与交付，巩固大客户合作关系。

## 风险警告
**核心风险在于并购整合与商誉减值。** 公司通过收购茉织华印务、淮北甲古文等快速扩张，但淮北甲古文2025年业绩承诺完成率仅7.55%，已导致当期计提商誉减值2368万元。若后续业绩持续不达预期，将面临更大规模的减值风险，直接冲击利润表。

**第二大风险是原材料价格波动与下游需求放缓。** 公司直接材料（白板纸、白卡纸）占成本超60%，虽存在调价机制，但若上游纸价上涨或下游快消品行业需求疲软，公司毛利率将承压。此外，实际控制人黄焕然2025年曾被监视居住，虽已解除，但此类事件对管理层稳定性和公司声誉构成潜在扰动。
