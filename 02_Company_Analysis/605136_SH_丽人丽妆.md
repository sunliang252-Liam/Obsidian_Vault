# 605136.SH 深度透视

## 因果逻辑链
- **[品牌终止合作与模式转变]** -> [营收下降2.08%]: 前期与部分品牌终止合作及运营模式转变，导致同期基数较高，拖累2025年整体营收至16.92亿元。
- **[自有品牌与总代业务高毛利扩张]** -> [毛利率提升3.87个百分点]: 高毛利率的自有品牌（收入同比+35%）和总代业务（营收占比超8%）占比提升，叠加低毛利库存出清，推动整体毛利率升至39.76%。
- **[自有品牌及新业务持续投入]** -> [归母净利润亏损0.80亿元]: 自有品牌处于产品创新与经营推广期，研发及营销投入暂未产生相应经济效益，叠加资产减值损失增加，导致公司由盈转亏。
- **[对外投资公允价值大幅下降]** -> [公允价值变动损失增加]: 其他非流动金融资产（私募基金等）产生公允价值损失3180万元，是侵蚀利润的重要因素之一。
- **[控制采购规模与回款]** -> [存货与往来款项下降]: 公司主动调整运营模式，严格控制采购规模并加强回款，期末存货同比下降4.31%，往来款项同比下降26.28%，财务风险降低。
- **[供应商集中度极高]** -> [经营依赖单一品牌]: 前五名供应商采购额占年度采购总额89.04%，其中单一供应商A占比高达54.66%，存在高度依赖风险。
- **[天猫渠道持续承压]** -> [其他渠道（抖音等）高速增长]: 天猫国内收入同比下降16.13%，而其他渠道（主要为抖音）收入同比大增46.63%，渠道结构正在快速切换。
- **[日系品牌市场表现疲软]** -> [公司业绩承压]: 报告明确指出日系化妆品尚未出现明显回暖迹象，而公司主要合作品牌中包含日系品牌，对其销售构成直接冲击。

## 风险警告
**核心风险在于转型期的“青黄不接”。** 公司传统天猫经销业务因品牌终止合作和模式转变持续萎缩，而作为增长引擎的自有品牌（玉容初、蓓养乐）和总代业务仍处于高投入、低盈利的孵化阶段，2025年净亏损0.80亿元即是明证。这种新旧动能切换的阵痛期，导致公司盈利能力承压，短期内难以看到明确的业绩拐点。

**另一重大风险是极端的供应商依赖和资产减值。** 公司对单一供应商A的采购额占比超过50%，任何合作关系的变动都将对经营造成致命打击。同时，高达4.17亿元的存货和1.68亿元的其他非流动金融资产（私募基金）面临巨大的减值风险，2025年已计提5744万元资产减值损失和3634万元公允价值变动损失，未来若市场环境或品牌销售不及预期，减值压力将持续侵蚀利润。
