# 003006.SZ 深度透视

## 因果逻辑链
- **[全国化线下扩张]** -> [营收增长7.3%]: 线下外围省份收入同比+92.3%，弥补了电商渠道-11.9%的下滑，驱动总营收增至34.92亿元。
- **[产品结构高端化]** -> [毛利率提升1.1%至54.3%]: 以益生菌、有机纯棉为代表的大健康系列收入同比+36.3%，中高端产品占比提升，直接拉高综合毛利率。
- **[电商渠道阶段性承压]** -> [净利润骤降27.7%]: 受短期舆情、平台策略调整及费用效率不佳影响，电商收入下滑，但销售费用仍同比+19%，导致利润被严重侵蚀。
- **[销售费用高增]** -> [利润与现金流恶化]: 销售费用14.58亿元（+19%）远超营收增速，叠加电商亏损，导致净利润仅2.08亿，经营现金流净额同比-38.7%。
- **[核心市场深耕]** -> [线下基本盘稳固]: 在川渝云等五省地区收入同比+3.9%，毛利率高达59.23%，为公司提供稳定的利润基石和现金流。
- **[品牌力提升]** -> [市场份额跃居行业第三]: 自由点品牌全国销售额份额排名升至第三、本土品牌第二，品牌势能转化为线下渠道的快速拓展能力。
- **[新国标实施]** -> [行业壁垒提升]: 2025年7月新国标实施，构建全链条质控体系，利好具备生产管理和品质优势的头部企业，加速行业洗牌。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化。** 2025年营收增长7.3%，但净利润却大幅下滑27.7%，经营现金流净额更是暴跌38.7%。根本原因是电商渠道在遭遇舆情和平台调整后，收入下滑，但公司为维持品牌声量，销售费用仍逆势增长19%，导致费用投入产出比严重失衡。Q4单季亏损3659万元，表明问题尚未解决，若2026年电商渠道不能快速恢复盈利，将对整体利润构成持续拖累。

**另一重大风险是渠道结构失衡与全国化扩张的可持续性。** 公司线下外围省份收入暴增92.3%，但这是在高基数增长下的高增速，其持续性存疑。同时，电商渠道作为全国化的重要引擎出现熄火，公司战略重心被迫向线下倾斜。若外围市场开拓不及预期，或电商渠道持续失血，公司将面临增长动力切换失败的风险。此外，原材料（浆板、石油衍生品）价格波动是长期成本隐患，在毛利率已处高位的情况下，任何成本上涨都将直接冲击利润。
