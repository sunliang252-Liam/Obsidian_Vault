# 603338.SH 深度透视

## 因果逻辑链
- **[海外市场持续扩张]** -> [营收与利润双增]: 海外收入同比增长16.45%，占比超80%，有效对冲国内竞争加剧与价格战风险，成为业绩增长核心引擎。
- **[全产品线电动化与“油改电”服务]** -> [差异化竞争优势]: 率先实现全系列产品电动化，并推出模块化“油改电”升级服务，满足海外客户对绿色、高效设备的刚性需求，提升产品附加值与竞争力。
- **[“高空作业平台+机器人”差异化新品]** -> [拓展新应用场景]: 针对船舶、隧道等细分领域推出喷涂除锈、打孔等机器人产品，开辟新市场，避免与竞争对手在通用产品上的同质化价格战。
- **[“未来工厂”智能制造与产能扩张]** -> [规模效应与成本控制]: 年产4000台大型高位高空平台项目产能放量，2万台新能源项目2026年投产，提升生产效率与规模，部分对冲原材料及运费上涨压力。
- **[汇率波动与汇兑收益]** -> [财务费用大幅下降]: 人民币贬值带来汇兑收益增加，财务费用同比大幅减少，直接增厚当期利润。
- **[高研发投入与专利壁垒]** -> [技术护城河]: 研发投入同比增长13.75%，累计专利266项（含159项发明专利），巩固了全球行业技术领先地位，支撑产品高定价与品牌溢价。
- **[全球化渠道与本土化服务]** -> [客户粘性与抗风险能力]: 通过设立海外子公司、组建本土团队、前置仓，缩短交货周期，提升服务响应速度，增强了在贸易摩擦环境下的客户忠诚度与市场韧性。

## 风险警告
**核心风险在于海外市场的政策与贸易环境恶化。** 公司营收超80%来自海外，且已多次经历欧美“双反”调查。若主要市场（如美国、欧洲）进一步大幅提升关税或设置非关税壁垒，将直接冲击公司出口产品的价格竞争力与销量，导致营收与利润增速显著放缓甚至下滑。尽管公司通过全球布局和新兴市场开拓来对冲，但短期难以完全抵消核心市场政策突变带来的冲击。

**另一重大风险是国内市场激烈竞争与应收账款坏账。** 国内高空作业平台行业竞争白热化，租赁商价格战激烈，导致公司国内收入同比下降14.16%。为争夺市场份额，公司可能被迫放宽信用政策，导致应收账款规模持续扩大（2025年末应收账款余额达30.57亿元）。若下游租赁商经营恶化或资金链断裂，公司将面临较大的坏账损失风险，侵蚀利润。
