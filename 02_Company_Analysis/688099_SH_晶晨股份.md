# 688099.SH 深度透视

## 因果逻辑链
- **[6nm先进制程SoC大规模商用]** -> [营收与毛利率双升]: 6nm芯片2025年销量近900万颗，通过大规模商用验证，推动产品结构高端化，全年综合毛利率同比提升1.42个百分点至37.97%。
- **[端侧AI芯片出货量爆发式增长]** -> [打开新增长曲线]: 搭载自研端侧AI算力单元的芯片出货量超2,000万颗，同比增长近160%，20余款芯片覆盖多产品线，成为营收增长的核心驱动力。
- **[Wi-Fi 6芯片快速渗透]** -> [通信连接业务放量]: Wi-Fi 6芯片销量超700万颗，在W系列中占比从11%跃升至37%，推动通信与连接芯片营收同比增长67.08%。
- **[全球化多渠道市场拓展]** -> [客户基础与抗风险能力增强]: 与全球近270家运营商及多家消费电子巨头深度合作，B/C端协同发展，有效分散单一市场风险，保障营收稳健增长14.63%。
- **[前瞻性存储备货策略]** -> [对冲供应链波动风险]: 面对全球存储市场剧烈变化，公司提前备货，保障SoC产品供应，第四季度营收同比增长约34%，S、T、W系列均恢复高增长。
- **[高强度研发投入与IP自研]** -> [构建平台化技术壁垒]: 近三年累计研发费用41.87亿元，自研功能模块比例超70%，形成“技术共享-快速复制-应用拓展”的研发范式，支撑多产品线协同迭代。
- **[收购芯迈微]** -> [补齐蜂窝通信技术栈]: 收购芯迈微，整合4G/5G蜂窝通信技术，构筑“蜂窝通信+光通信+Wi-Fi”多维通信矩阵，为端侧智能解决方案提供完整连接能力。

## 风险警告
**核心风险在于经营现金流大幅恶化与存货高企。** 2025年经营活动现金流净额为-2.30亿元，同比骤降122.05%，主因是预付原材料采购款激增。同时，存货规模达25.28亿元，同比暴增79.32%，占总资产29.24%。若下游需求不及预期或存储市场转向，公司将面临巨大的存货跌价与周转率下降风险，直接侵蚀利润。

**另一重大风险是客户与供应商高度集中。** 前五大客户销售额占比63.80%，前五大供应商采购额占比79.85%，且存在股东同时为客户的情况。这种结构使公司在议价、供应链安全及关联交易方面处于被动。一旦主要客户或代工厂（晶圆/封测）出现经营波动，将对公司业绩造成剧烈冲击。此外，公司业务高度依赖海外市场（境外收入占比超90%），面临地缘政治、汇率波动及技术授权等宏观不确定性。
