# 300130.SZ 深度透视

## 因果逻辑链
- **[海外电子支付设备销售增长]** -> [营收增长1.03%]: 海外POS机出货量及本地化运营突破，带动电子支付产品收入同比+21.40%，弥补国内收单业务下滑。
- **[上年同期低基数效应]** -> [归母净利润同比+100.17%]: 2024年因涉税事项调整及商誉减值导致净利润基数极低，2025年恢复正常经营后利润大幅反弹。
- **[国内收单业务承压]** -> [扣非净利润同比-14.57%]: 收单及增值服务收入同比-7.03%，叠加对跨境支付、AI等新业务加大投入，侵蚀扣非利润。
- **[跨境支付业务爆发]** -> [新增长极初现]: 跨境支付交易金额突破24亿人民币，季度环比平均增速超100%，成为未来核心驱动力。
- **[“支付+SaaS”生态深化]** -> [商户粘性增强]: 嘉联云店累计服务10万+中小餐饮商户，咕朵云开放平台入驻176家合作机构，增值服务提升商户留存。
- **[AI赋能内部运营]** -> [降本增效]: 嘉联“AI+”平台实现智能客服、智能审核，支付业务内部运营效率提升30%，降低人力成本。
- **[海外支付硬件认证突破]** -> [高端市场准入]: 取得PCIP2PE、Common Criteria等多项国际认证，为进入欧美高端市场奠定基础。
- **[H股上市推进]** -> [资本运作与国际化]: 公司已向港交所递交H股上市申请，旨在拓宽融资渠道，提升国际品牌影响力。

## 风险警告
**1. 国内收单业务持续萎缩与合规成本高企。** 国内收单业务收入同比下降7.03%，毛利率大幅下滑9.96个百分点，显示行业竞争白热化与监管趋严的双重压力。在《非银行支付机构监督管理条例》全面执行下，合规投入持续增加，若无法通过增值服务有效提升商户价值，国内业务可能成为利润拖累。

**2. 海外业务增长的不确定性与汇率风险。** 海外营收占比已提升至36.15%，但面临地缘政治、贸易壁垒及当地监管政策变化等多重风险。同时，海外收入以美元、欧元等外币结算，汇率波动可能显著影响公司业绩。公司虽开展远期结售汇，但无法完全对冲风险。

**3. 新业务投入与商誉减值风险。** 跨境支付、AI等创新业务尚处投入期，短期内难以贡献显著利润，反而持续侵蚀当期利润。此外，公司过往并购积累的商誉仍面临减值压力，若被并购企业经营不及预期，将直接冲击净利润。
