- **[全球化本地化运营深化]** -> [国际业务收入增长14.10%]: 海外子公司本土化率超90%，新设法国、墨西哥子公司，本地化团队提升市场响应速度与服务质量，驱动海外收入占比提升至62.69%。
- **[高端新品持续放量]** -> [病人监护业务收入增长14.96%]: iV系列监护仪、i500全自动血气分析仪等战略新品凭借技术优势迅速铺开市场，成为核心增长引擎。
- **[智能制造与供应链韧性]** -> [毛利率提升0.43个百分点]: 成为深圳首家国家智能制造能力成熟度四级认证医疗器械企业，坪山二期及美国制造中心布局优化成本结构，对冲关税与汇率风险。
- **[研发投入积累进入收获期]** -> [净利润大幅增长88.54%]: 上市以来累计研发投入超30亿元，1,292项专利形成技术壁垒，高附加值产品占比提升，盈利能力显著改善。
- **[POCT一体化解决方案生态]** -> [体外诊断业务稳健增长]: i15/i20/i500血气系列+磁敏荧光免疫+智慧管理软件形成“硬件+软件+生态”闭环，打破进口垄断，提升客户粘性与定价权。
- **[智慧医疗与AI赋能]** -> [提升运营效率与品牌价值]: 推出“万象AI”大模型，赋能心电、胎监、急救等场景，同时AI工具渗透研发、生产、管理环节，实现降本增效。
- **[医疗新基建与设备更新政策]** -> [国内业务保持正向增长]: 国家推动医疗设备更新、县域医共体建设，公司心电一张网、智慧胎监等解决方案精准对接政策需求，巩固国内市场基本盘。

## 风险警告
**关税与汇率波动风险是最大外部不确定性。** 公司外销收入占比高达62.69%，且以美元结算为主。中美贸易摩擦及全球贸易保护主义抬头可能导致关税成本上升，而人民币汇率波动将直接影响产品价格竞争力与汇兑损益。尽管公司通过全球制造布局和外汇套期保值进行对冲，但若外部环境剧烈变化，仍可能对盈利能力造成显著冲击。

**新品市场竞争与研发转化风险不容忽视。** 医疗器械行业研发周期长、投入大，i500等新品虽已放量，但血气、超声等领域面临国际巨头（如雅培、西门子）的激烈竞争。若新产品未能及时获得海外注册、或市场推广不及预期，将影响公司长期增长动能。此外，公司研发投入全部费用化，若新品商业化受阻，将直接侵蚀利润。
