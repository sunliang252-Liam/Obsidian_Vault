# 920175.BJ 深度透视

## 因果逻辑链
- **[下游光伏新能源需求放缓]** -> [营收下降22.12%]: 下游客户需求萎缩，导致公司特种石墨产品销量和售价双降。
- **[产品价格持续走低]** -> [毛利率暴跌至4.01%]: 售价降幅远超成本降幅，主营业务盈利能力几近丧失。
- **[在建工程延期与资产减值]** -> [净利润巨亏1.2亿]: 募投项目“年产1.8万吨项目”延期，公司对在建工程和存货计提大额减值准备（合计约1.3亿），直接吞噬利润。
- **[行业竞争加剧]** -> [存货跌价准备大幅上升]: 市场供过于求，公司对库存商品计提大额跌价准备，进一步恶化利润表。
- **[压缩焙烧次数工艺创新]** -> [缩短生产周期]: 将焙烧次数由3次压缩至1次，旨在降低生产成本、提升周转效率，但短期尚未体现为盈利改善。
- **[募投项目延期]** -> [在建工程减值风险暴露]: 因市场环境变化，核心扩产项目两次延期至2026年底，导致在建工程计提减值3309万元。
- **[经营活动现金流净额大增]** -> [现金回笼改善]: 尽管亏损，但公司通过降低产量减少采购支出、收到增值税留抵退税，经营性现金流净额同比大增48.24%。

## 风险警告
**核心风险：行业景气度持续下行与资产减值螺旋。** 公司深度绑定光伏新能源产业链，下游需求疲软导致产品价格与毛利率持续双杀。更严峻的是，公司为应对市场而扩产的“年产1.8万吨高端特种石墨项目”已两次延期，并因此计提了巨额在建工程减值。若行业复苏不及预期，未来存货与固定资产仍面临进一步减值压力，可能持续侵蚀净资产。

**财务风险：高负债与流动性压力。** 公司资产负债率高达42.73%，短期借款与长期借款合计超2.7亿元。尽管经营性现金流因压缩开支而改善，但筹资活动现金流净流出1.16亿元，显示公司正面临偿债压力。同时，存货占总资产比例仍高达24%，若价格继续下跌，将加剧流动性风险。
