# 301138.SZ 深度透视

## 因果逻辑链
- **[境外市场爆发]** -> [营收增长4.9%]: 境外收入同比大增49.63%至3.05亿元，占比从31.55%跃升至45%，弥补了国内华南、华中、西南等区域的下滑。
- **[核心产品放量]** -> [结构优化]: 瓶坯智能成型系统收入同比+22.37%，占比升至64.5%，而高毛利的服务配件收入同比-18.24%，拉低整体盈利弹性。
- **[毛利率改善]** -> [利润逆势微降]: 核心产品毛利率+7.31pct至37.75%，但资产减值损失（-1448万）和财务费用转正（汇率波动）侵蚀利润，归母净利润同比-3.16%。
- **[在手订单充裕]** -> [存货与合同负债双增]: 存货同比+32%至4.88亿，合同负债同比+42%至3.38亿，显示订单饱满但交付周期拉长。
- **[高分红与回购]** -> [股东回报强化]: 2025年实施两次分红合计7200万元（10派6元），但年末不派息，资金优先用于新产品研发与产能保障。
- **[技术迭代]** -> [新品储备]: 成功研发瓶盖压塑成型系统及192腔超大型模具，处于市场推广阶段，有望打开新增长极。
- **[治理结构变革]** -> [内控升级]: 取消监事会，由审计委员会承接监督职能，同步修订26项制度，治理效率提升但短期存在衔接磨合风险。

## 风险警告
**核心风险在于“增收不增利”与“海外依赖症”。** 公司营收增长依赖境外市场（+49.63%），但境内核心区域华南、华中收入分别下滑26.3%和53.5%，国内需求疲软。同时，资产减值损失（-1448万）和财务费用转正（汇率波动）直接吞噬利润，导致净利润同比下滑3.16%。若海外订单增速放缓或汇率剧烈波动，业绩将面临双重压力。

**募投项目达产后的消化风险不容忽视。** 公司首发募投项目已全部结项，但“高速多腔模具扩产建设项目”因瓶盖模具仍处市场推广期，尚未产生经济效益。超募资金中仍有4.06亿元未确定投向，若后续投资决策失误或市场开拓不及预期，将导致资产回报率持续低迷。此外，高新技术企业资格将于2026年到期，若复审未通过，税率将从15%升至25%，直接冲击净利润。
