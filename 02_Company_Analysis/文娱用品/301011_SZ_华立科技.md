## 因果逻辑链
- **[国内游乐场扩张放缓]** -> [设备销售收入下降16.14%]: 下游客户因前期快速扩张进入调整期，新增需求减少，导致公司核心业务承压。
- **[海外市场拓展]** -> [境外收入增长25%]: 公司拳头产品（如雷动系列）获海外客户青睐，对冲了国内市场的下滑。
- **[动漫IP衍生品投放扩大]** -> [IP衍生产品收入增长12.97%]: 核心产品《宝可梦 明耀之星》加大投放，自研国潮卡片《三国幻战》表现良好，驱动该业务增长。
- **[动漫IP衍生品成本上升]** -> [毛利率下降2.44%]: 尽管收入增长，但成本上升更快，导致该业务盈利能力略有下滑。
- **[研发投入增加]** -> [研发费用增长32.91%]: 公司加大研发人员及投入，旨在通过技术创新（如AR、体感交互）提升产品竞争力。
- **[存货与应收账款高企]** -> [资产减值损失达2279.77万元]: 存货占流动资产比例大，市场需求变化可能导致滞销；应收账款规模大，坏账风险增加。
- **[完成简易程序定增]** -> [筹资活动现金流净额大幅增加]: 募集资金到账，为公司扩大动漫卡片设备投放及运营提供资金支持。
- **[游乐场运营成本上升]** -> [游乐场运营业务毛利率为-5.94%]: 同质化竞争加剧，成本上升速度快于收入，导致该业务亏损。

## 风险警告
**核心风险在于国内游戏游艺设备销售业务的持续萎缩与资产减值压力。** 公司2025年营收微降，但净利润下滑18.44%，主因是国内设备销售业务受下游游乐场扩张放缓影响，收入同比下降16.14%。同时，公司存货和应收账款规模庞大，合计占总资产近40%，已计提超3000万的资产及信用减值损失。若下游客户经营环境持续恶化，减值风险将进一步侵蚀利润。

**第二重风险是游乐场运营业务的亏损与行业竞争加剧。** 公司自营游乐场业务毛利率为-5.94%，处于亏损状态。报告明确指出，国内室内游乐场在快速扩张后同质化竞争加剧，叠加商业综合体人流分流，行业短期将迎来洗牌整合。公司若不能通过IP差异化或精细化运营实现扭亏，该业务将持续拖累整体业绩。
