# 002301.SZ 深度透视

## 因果逻辑链
- **聚焦央企/央管金融机构等优质大客户** -> 营收稳健增长4.98%: 深度绑定超60家央企，客户粘性高，订单内占比提升，保障了B2B集采业务的规模性增长。
- **MRO工业品业务规模化扩张** -> 成为核心收入来源: 依托办公集采的客户重叠度和可复制性，MRO业务快速拓展至能源、军工等新领域，新增多个大型项目，驱动营收结构优化。
- **AI大模型（齐心智磐）深度嵌入全链路** -> 运营效率与现金流显著改善: AI应用于商品管理、订单分配、履约核验等环节，提升自动化水平，客户回款加快，经营性现金流净额同比大增69.9%。
- **自有品牌战略转型（品牌新文具+出海）** -> 短期利润承压，长期培育增长点: 聚焦高价值产品与IP联名，但渠道覆盖与供应链产能未跟上，导致全年销售和利润下滑，成为业绩拖累。
- **SaaS业务（好视通）全面收缩** -> 亏损收窄，风险出清: 云视频业务聚焦智慧教育场景，亏损同比企稳，但子公司杭州麦苗因AI替代风险被判定为非重点业务，前景不明。
- **计提大额资产减值** -> 侵蚀当期利润: 报告期计提商誉、存货等减值合计6740.76万元，其中商誉减值约2900万元，直接减少了净利润，但出清了部分历史包袱。
- **海外业务高速发展** -> 贡献增量利润: 欧美市场营收增长12.16%，毛利率高达46.75%，成为公司重要的利润增长极，对冲了国内分销渠道的下滑。

## 风险警告
**核心风险在于“增收不增利”的商业模式困境。** 公司营收近120亿，但归母净利润仅0.81亿，净利率不足0.7%。B2B集采业务本质是低毛利的供应链服务，毛利率仅8.31%，且持续承压。公司依赖规模扩张和运营效率提升来获取微薄利润，一旦客户压价、竞争加剧或运营成本上升，利润将面临剧烈波动。第四季度归母净利润亏损近6000万，进一步暴露了盈利的脆弱性。

**第二增长曲线尚未成型，且存在资产减值隐患。** 自有品牌业务战略转型遇阻，销售与利润双下滑，未能成为利润引擎。SaaS业务虽亏损收窄，但杭州麦苗业务前景被管理层定性为“不够明朗”，存在被AI替代的风险，未来可能继续计提商誉减值。公司商誉余额虽已大幅降低，但剩余部分仍构成潜在风险。此外，控股股东高比例质押（约39%），也增加了公司治理层面的不确定性。
