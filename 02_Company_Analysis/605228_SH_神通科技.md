# 605228.SH 深度透视

## 因果逻辑链
- **[主动式油气分离器及A客户新项目订单放量]** -> [营收增长35.70%]: 新项目进入量产阶段，直接拉动动力系统零部件收入同比大增69.38%。
- **[动力系统零部件毛利率提升]** -> [整体毛利率改善]: 高毛利产品占比提升，动力系统零部件毛利率同比增加5.69个百分点，带动整体毛利率增加4.57个百分点。
- **[规模效应与成本控制]** -> [净利润扭亏为盈]: 营收大幅增长摊薄固定成本，叠加销售费用同比减少42.43%，实现归母净利润1.33亿元（上年亏损0.32亿元）。
- **[经营性现金流大幅改善]** -> [财务健康度提升]: 销售回款增加，经营活动现金流净额同比大增171.65%至3.99亿元，远超净利润水平。
- **[车规级光学业务布局]** -> [第二增长曲线初现]: 激光雷达、毫米波雷达、HUD光学镜片及光场屏业务稳步推进，为公司打开智能汽车增量市场空间。
- **[紧贴产业集群的生产基地布局]** -> [客户响应与成本优势]: 在宁波、烟台、武汉等汽车产业基地建厂，降低物流成本，实现准时化供货，巩固与一汽大众、吉利、蔚来等客户的合作关系。
- **[研发投入持续加码]** -> [技术护城河加深]: 研发费用8,935万元，拥有379项专利（含99项发明专利），支撑公司在轻量化、智能化领域的技术领先地位。

## 风险警告
**客户集中度与价格年降风险。** 公司前五大客户销售额占比高达69.06%，对主要整车厂客户依赖度极高。汽车零部件行业普遍存在年度价格下调惯例（0%-5%），若公司无法持续进入新车型供应链或有效控制成本，毛利率将面临持续压缩压力，业绩波动性显著。

**原材料成本波动与募投项目延期风险。** 塑料粒子等原材料占主营业务成本超70%，其价格波动直接冲击利润。同时，核心募投项目“光学镜片生产基地”已延期至2027年7月，若新业务（光学镜片、消费电子）产业化进度不及预期，将拖累公司向智能化转型的战略节奏，并影响市场对其成长性的估值。
