# 300121.SZ 深度透视

## 因果逻辑链
- **防焦剂CTP全球垄断地位** -> **高市场份额与定价权**: 公司防焦剂CTP产销量占全球60%以上市场份额，形成稳固的竞争壁垒，支撑核心产品盈利稳定性。
- **连续法不溶性硫磺技术突破** -> **国产替代与成本优势**: 作为全球第三家掌握该产业化技术的公司，打破国外垄断，实现高端产品国产化，降低生产成本并提升毛利率。
- **“多效蒸发+生化”废水处理技术** -> **环保合规与成本控制**: 自主开发的组合工艺有效解决橡胶助剂行业高盐、高COD废水治理难题，降低环保风险与处理成本，构筑绿色壁垒。
- **高性能橡胶助剂销量增长** -> **收入结构优化**: 报告期内高性能橡胶助剂类产品销量上涨，部分多功能橡胶助剂销售价格上涨，推动净利润同比增长。
- **可转债利息费用减少** -> **财务费用下降**: 可转债部分转股及偿还，导致利息费用同比减少30.88%，直接增厚净利润。
- **新能源汽车轮胎需求增长** -> **新产品市场拓展**: 新能源汽车对低滚阻、高性能轮胎的需求，带动公司硅烷偶联剂、白炭黑分散剂等新产品的市场推广与布局。
- **泰国生产基地建设** -> **规避贸易风险与全球化布局**: 搭建海外生产平台，可有效规避国际贸易摩擦与关税壁垒，提升全球供应链韧性。

## 风险警告
**核心风险在于行业产能过剩与价格下行压力。** 橡胶助剂行业已从高速扩张期进入平稳发展期，面临产能过剩、价格下行、效益下滑的挑战。公司2025年营收仅微增0.37%，而净利润增长主要依赖费用削减而非收入扩张，显示主业增长乏力。若行业竞争加剧导致产品价格持续走低，公司盈利能力将面临显著侵蚀。

**募投项目延期与效益不达预期是另一重大风险。** 公司“年产65,000吨高性能橡胶助剂项目”因前置手续、设备采购及市场变化等原因，已延期至2026年10月。同时，已投产的“10,000吨/年橡胶防焦剂CTP项目”因市场需求和售价低于预期，未能实现预期经济效益。大规模资本开支若无法及时转化为有效产出，将拖累公司资产回报率与现金流。
