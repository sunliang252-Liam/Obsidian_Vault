# 688049.SH 深度透视

## 因果逻辑链
- **[端侧AI产品化浪潮]** -> [营收与利润高增]: 端侧AI处理器芯片（ATS323X/ATS362X）切入头部品牌高端音箱、Party音箱及无线麦克风，带动收入倍数增长，叠加蓝牙音箱SoC份额提升，驱动2025年营收同比+41.5%，扣非净利润同比+144.7%。
- **[存内计算(CIM)技术商用]** -> [构筑差异化壁垒]: 率先将基于SRAM的存内计算NPU落地，实现6.4TOPS/W@INT8高能效比，在低功耗端侧设备中提供AI算力，形成对传统架构的竞争优势，支撑产品溢价与客户粘性。
- **[品牌客户战略深化]** -> [市场份额与毛利率双升]: 深度绑定哈曼、索尼、Bose、大疆等一线品牌，实现多品类大规模量产，客户结构向高价值演进，推动综合毛利率同比提升2.98个百分点至51.15%。
- **[私有协议音频市场卡位]** -> [开辟蓝海增长极]: 在无线麦克风、家庭影院、电竞耳机等细分赛道，凭借9ms超低延迟、4Mbps高带宽私有协议，成为大疆、RODE等头部品牌核心供应商，低延迟高音质产品线持续高增。
- **[研发高投入与规模效应]** -> [利润弹性释放]: 研发费用占营收比从33%降至26.13%，但营收增速（+41.5%）显著快于费用增速（研发+12%），规模效应下利润增速远超收入增速。
- **[AI赋能音频算法升级]** -> [产品体验代际领先]: 将智能降噪、人声分离等传统算法通过模型训练升级为专用AI中小模型，并推出ANDT工具链降低客户开发门槛，加速AI功能在端侧落地，巩固音质标杆地位。

## 风险警告
**核心风险在于技术迭代与客户集中度。** 公司高度依赖存内计算等前沿架构的领先性，若第二代CIM技术研发不及预期，或竞争对手在端侧AI芯片能效比上实现反超，公司当前的技术溢价将迅速收窄。同时，前五大客户销售额占比高达55.65%，且深度绑定哈曼等国际巨头，若主要客户因地缘政治或自身经营问题缩减采购，将对业绩造成剧烈冲击。

**另一重大风险是国际贸易摩擦与供应链安全。** 公司采用Fabless模式，晶圆制造和EDA工具高度依赖台积电、Cadence等海外供应商。若中美科技脱钩进一步升级，导致关键IP授权受限或代工产能受阻，公司将面临产品断供风险。此外，公司存货规模随备货策略增长，若下游需求增速放缓，存在存货跌价侵蚀利润的风险。
