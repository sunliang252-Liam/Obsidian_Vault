# 600662.SH 深度透视

## 因果逻辑链
- **[业务外包规模扩张]** -> [营收增长8.17%]: 业务外包服务收入同比增长9.72%，是驱动总营收增长的核心引擎，但该业务毛利率仅2.95%，拉低整体盈利水平。
- **[上年同期非经常性收益消失]** -> [归母净利润骤降39.96%]: 2024年处置子公司股权获得5.16亿元投资收益，2025年无此项目，导致归母净利润从10.86亿降至6.52亿。
- **[扣非净利润微增]** -> [主业盈利能力稳健]: 剔除一次性收益后，扣非净利润同比增长4.16%，表明核心人力资源服务业务在复杂环境下仍保持小幅增长。
- **[内资业务占比提升]** -> [客户结构优化]: 内资业务营收占比达64.8%，同比增长0.9个百分点，显示公司成功拓展国企和民企市场，降低对外资客户的依赖。
- **[区域业务贡献增强]** -> [全国化布局见效]: 区域业务营收占比达51.0%，同比增长0.5个百分点，表明公司“四大区”战略布局正逐步转化为收入增量。
- **[数字化投入持续]** -> [运营效率提升]: 研发投入1.56亿元，推出AI求职招聘智能体、行业智库等产品，业务系统上线周期缩短60%以上，支撑降本增效。
- **[国际化业务起步]** -> [新增长极初现]: 海外业务解决方案落地22个国家和地区，香港公司实现从零到一的突破，但境外收入仅2513万元，体量极小。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长主要依赖低毛利的业务外包（毛利率2.95%），而高毛利的人事管理服务（69.68%）和薪酬福利服务（27.43%）收入下滑或停滞。这种业务结构导致整体毛利率下降0.68个百分点，利润增长严重依赖规模扩张而非价值提升。若业务外包竞争加剧导致毛利率进一步压缩，公司将面临利润增速持续落后于营收增速的风险。

**第二重风险是增长动力的可持续性存疑。** 公司扣非净利润4.16%的增速远低于营收8.17%的增速，且经营性现金流同比下降20.86%。同时，国际化业务尚处萌芽阶段，境外收入占比不足0.1%；AI等数字化投入虽在提升效率，但1.56亿元的研发投入尚未转化为显著的利润增量。在宏观经济波动和行业竞争加剧的背景下，公司能否找到除业务外包之外的新增长引擎，是决定其长期价值的关键。
