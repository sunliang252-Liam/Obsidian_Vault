# 688060.SH 深度透视

## 因果逻辑链
- **[信创业务爆发式增长]** -> [营收增长26.46%]: 国产化平台通用产品收入同比激增284.99%，成为营收增长核心引擎。
- **[高研发投入持续侵蚀利润]** -> [净利润仍为负]: 研发费用占营收16.90%，虽同比略降，但绝对额仍高达6348万元，是亏损主因。
- **[存货跌价准备计提]** -> [拖累当期净利润]: 基于谨慎性原则计提存货跌价准备658.92万元，虽较去年大幅减少，但仍对利润造成显著负面影响。
- **[新能源业务从0到1]** -> [开辟第二增长曲线]: 储能、微网、虚拟电厂等产品完成开发并实现销售2822万元，验证了技术-产品-市场的转化路径。
- **[核心客户依赖度高]** -> [业绩稳定性风险]: 前五大客户销售额占比31.02%，其中国电南瑞一家占比17.51%，客户集中度较高。
- **[经营活动现金流大幅恶化]** -> [增长质量存疑]: 经营性现金流净额同比骤降73.10%至1069万元，远低于营收增速，反映信创、新能源业务回款或垫资压力大。
- **[电力行业基本盘稳固]** -> [提供业绩安全垫]: 工业安全通信网关设备收入增长13.76%，信息安全加密产品增长98.65%，传统电力业务持续放量。

## 风险警告
**核心风险在于“增收不增利”与“现金流恶化”的双重困境。** 公司营收增长26.46%，但净利润仍亏损1226万元，且经营活动现金流净额同比暴跌73.10%，仅为1069万元。这揭示出信创和新能源新业务虽然带来收入，但可能伴随更长的账期、更高的垫资成本或更低的毛利率，导致增长的“含金量”不足。若新业务无法快速改善盈利模型和现金流状况，公司将持续面临财务压力。

**第二重风险是业务转型的不确定性。** 公司从电力信息安全设备商向“信创+新能源”综合方案商转型，面临行业竞争加剧、技术迭代快、客户拓展不确定性高等挑战。信创业务依赖政策红利，新能源业务商业模式尚在验证，两者均需持续高投入。若任一方向未能如期实现规模化盈利，公司将面临研发投入沉没、增长失速的风险。此外，对国电南瑞等核心客户的过度依赖，也构成了业绩波动的潜在风险。
