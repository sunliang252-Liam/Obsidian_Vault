# 688611.SH 深度透视

## 因果逻辑链
- **[储能系统收入骤降]** -> [营收暴跌61.83%]: 2024年储能系统大额订单交付后，2025年该业务收入从3.22亿骤降至289万，直接导致总营收从5.41亿腰斩至2.07亿。
- **[钙钛矿光伏业务放量]** -> [新增长极初现]: 钙钛矿组件实现收入2557万元，毛利率为-28.14%，虽仍亏损但标志商业化订单落地，验证了产业化能力。
- **[大规模资本开支转固]** -> [利润由盈转亏]: 钙钛矿产线、储能电站、募投项目等资产在2025年集中转固，折旧大幅增加，叠加营收下滑，导致净利润从盈利7304万转为亏损305万。
- **[电网数字化感知业务稳健]** -> [核心主业承压但未崩盘]: 该业务收入1.30亿元，同比增长14.85%，毛利率65.50%，是公司当前最稳定的利润来源，对冲了储能业务的剧烈下滑。
- **[研发投入强度激增]** -> [短期侵蚀利润，长期押注未来]: 研发费用占营收比例从7.99%飙升至20.86%，绝对值维持4312万元，重点投向钙钛矿、机器人六维力传感器等新业务。
- **[客户高度集中]** -> [经营依赖单一生态]: 前五大客户销售额占比69.40%，且主要为国家电网及下属公司，议价能力弱，订单波动直接影响公司业绩。
- **[应收账款大幅下降]** -> [现金流改善信号]: 应收账款从1.84亿降至0.92亿元，降幅50.09%，经营活动现金流净额8099万元，显示回款能力增强。

## 风险警告
公司当前最大的风险在于**新旧业务青黄不接导致的业绩断层**。传统储能系统业务收入从3.22亿断崖式下跌至289万，暴露出该业务高度依赖大额订单、可持续性差的致命弱点。虽然钙钛矿光伏业务已实现商业化突破，但毛利率为-28.14%，仍处于“卖得越多亏得越多”的阶段，短期内无法接替储能成为利润支柱。公司2025年净利润已转亏，若钙钛矿业务不能快速实现盈亏平衡，业绩将持续承压。

其次，**激进的战略转型带来了巨大的资产减值与现金流压力**。公司同时押注钙钛矿、储能电站、机器人三大重资产、长周期赛道，导致固定资产从3859万暴增至5.65亿元，在建工程从4.66亿归零（全部转固）。这意味着未来每年将产生巨额折旧，而新业务尚未形成稳定盈利模式。此外，公司已启动GW级钙钛矿产线建设，后续资本开支需求巨大，若融资不畅或技术路线遇阻，将面临严重的流动性风险。
