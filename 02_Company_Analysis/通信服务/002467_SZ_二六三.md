# 002467.SZ 深度透视

## 因果逻辑链
- **[核心业务萎缩]** -> [营收下降8.12%]: VOIP/IPTV、视频直播、移动网络业务量及收入下滑，叠加上年同期出售投资性房地产的高基数效应。
- **[商誉暴雷]** -> [净利润巨亏2.84亿]: 直播业务资产组、VOIP及IPTV资产组经营恶化，计提商誉减值损失2.77亿元，直接导致全年由盈转亏。
- **[信托理财踩雷]** -> [公允价值变动损失追加]: 中融信托2亿元产品逾期未兑付，本报告期追加确认2000万元公允价值变动损失，累计损失达2亿元，账面价值归零。
- **[全球化网络逆势增长]** -> [收入结构优化]: 国际海缆、虚拟专网等全球化网络业务收入同比增长3.25%，占比提升至53.8%，成为唯一增长板块，对冲部分传统业务下滑。
- **[研发投入持续加码]** -> [AI转型蓄力]: 研发费用同比增长6.54%，重点投向AICC、数字人、SASE云平台等AI与云网融合项目，但尚未转化为显著收入增量。
- **[经营活动现金流净额下降]** -> [盈利质量恶化]: 经营性现金流净额同比减少35.76%，主要系移动网络、视频直播等业务收入下降导致现金流入减少。

## 风险警告
**核心风险在于商誉与资产减值连环暴雷。** 公司2025年计提2.77亿元商誉减值后，账面商誉仍高达2.93亿元。考虑到VOIP/IPTV业务持续被微信、Netflix等替代，直播业务竞争加剧，剩余商誉资产组仍面临进一步减值风险。同时，2亿元中融信托理财已全额计提损失，但追偿结果高度不确定，若未来无法收回，将构成永久性损失。

**第二重风险是传统业务加速衰退与AI转型的“青黄不接”。** 公司核心利润来源的智能化通信业务（邮箱、直播、智慧家居）收入同比下降8.83%，其中智慧家居业务受OTT产品替代冲击，用户活跃度持续下降。尽管公司在AI、数字人等领域投入研发，但报告期内尚未形成规模化收入，新业务无法弥补传统业务的下滑缺口，公司正处于战略转型的阵痛期。此外，控股股东李小龙年内多次减持，亦向市场传递了负面信号。
