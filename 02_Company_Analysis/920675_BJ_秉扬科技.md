# 920675.BJ 深度透视

## 因果逻辑链
- **[产品需求结构变化]** -> [营收下降]: 陶粒支撑剂销量下降22.52%，石英砂均价下降11.04%，导致总营收同比下滑13.16%。
- **[石英砂价格竞争加剧]** -> [利润承压]: 石英砂销售均价下降，虽成本同步下降，但整体销售毛利减少，拖累净利润。
- **[增值税即征即退减少]** -> [其他收益下降]: 享受退税政策的产品销售额减少，导致其他收益同比大幅下降58.43%。
- **[客户票据结算增加]** -> [信用减值损失扩大]: 客户更多采用商业承兑汇票支付，应收票据规模上升，计提的坏账准备增加88.90%。
- **[库存去化与借款增加]** -> [现金流改善]: 减少库存备货，采购支付现金减少，同时短期借款增加，使经营活动现金流净额增长24.05%。
- **[收购新疆旭辉股权]** -> [产业链延伸]: 收购新疆旭辉22%股权，旨在进一步拓展石英砂业务，提升产业链布局。
- **[研发项目资本化]** -> [研发费用骤降]: “陶粒支撑剂高性能化研发攻关”项目产出合格成品，部分研发支出转入存货成本，导致研发费用同比下降56.90%。

## 风险警告
公司面临严重的客户集中度风险，前五大客户销售占比高达99.32%，其中中石油和中石化合计占比91.35%。这种对两大国有石油巨头的深度依赖，使公司议价能力极弱，是市场价格的被动接受者。一旦主要客户采购策略调整或减少订单，公司经营业绩将遭受直接且重大的冲击。

此外，公司产品结构单一，高度依赖压裂支撑剂，且下游需求与油价及油气开采景气度强相关。若油价持续低迷，下游客户可能减产或压价，直接压缩公司利润空间。同时，陶粒与石英砂之间的产品需求结构变化已对营收产生负面影响，公司虽有布局，但应对能力尚待验证。
