# 002866.SZ 深度透视

## 因果逻辑链
- **[消费电子主业复苏+海外产能布局]** -> **营收增长9.76%，净利润扭亏为盈**: 笔记本/台式机键盘等输入设备收入增长15.66%，叠加越南工厂投产，驱动整体业绩回升。
- **[钠离子电池业务持续亏损]** -> **拖累整体利润**: 子公司传艺钠电亏损1.58亿元，新能源业务收入下降19.51%，成为公司最大利润黑洞。
- **[资产减值损失高企]** -> **侵蚀利润**: 计提存货跌价准备1.00亿元，反映钠电库存积压及消费电子部分产品跌价风险。
- **[财务费用大幅增加]** -> **压缩利润空间**: 汇兑损失增加导致财务费用同比上升172.15%，对净利润造成显著负面影响。
- **[非经常性损益贡献显著]** -> **支撑净利润**: 投资收益（理财/外汇）及政府补助合计约2774万元，占归母净利润的32.3%，掩盖了主营业务的真实盈利能力。
- **[客户集中度高]** -> **经营依赖性强**: 前五大客户销售占比58.42%，第一大客户占比25.99%，存在大客户流失风险。
- **[全球化战略落地]** -> **规避贸易摩擦风险**: 设立越南子公司并投产，旨在应对国际贸易不确定性，保障海外订单交付。

## 风险警告
**核心风险在于钠离子电池业务的持续失血与战略摇摆。** 钠电子公司净资产已为-4.06亿元，处于资不抵债状态，且公司已终止二期5.5GWh项目，聚焦现有产能降本增效。然而，铅酸电池的成本优势、行业产能过剩以及技术路线不确定性，使得钠电商业化前景高度不确定。该业务不仅未能成为第二增长曲线，反而持续消耗公司现金流与利润，是最大的财务风险点。

**消费电子主业面临增长天花板与外部冲击。** 公司营收高度依赖前五大客户（占比58.42%），且外销占比超50%，易受国际贸易摩擦、汇率波动及下游PC需求周期性波动影响。虽然AI PC概念带来换机预期，但竞争加剧与原材料价格波动可能压缩毛利率。公司2025年扣非净利润仅5809万元，盈利能力依然薄弱，主业护城河并不深厚。
