# 301667.SZ 深度透视

## 因果逻辑链
- **[动力电池液冷板销量增长]** -> [营收增长23.88%]: 动力电池液冷板销量435.37万片，同比增长23.53%，带动动力电池领域收入增长39.67%，是营收增长的核心引擎。
- **[产品尺寸增大与材料成本上升]** -> [毛利率承压]: 电池液冷板直接材料成本占比从72.63%升至80.72%，导致该产品毛利率下降3.02个百分点，利润增速（+1.28%）远低于营收增速。
- **[Q4产销规模激增与付款周期错配]** -> [经营现金流大幅转负]: 2025年Q4营收环比增长23.3%，为应对2026年Q1订单，期末存货增加1.06亿、应收增加0.99亿，导致经营现金流净额为-4734万元，同比-222%。
- **[IPO募集资金到账]** -> [净资产翻倍与财务费用下降]: 2025年12月上市募资净额5.88亿元，净资产从6.28亿增至12.82亿（+104%），同时偿还高息项目贷款，财务费用同比下降40.34%。
- **[客户高度集中]** -> [经营依赖单一客户]: 前五大客户销售占比63.6%，其中第一大客户（宁德时代）占比39.9%，公司业绩高度依赖核心客户的订单与车型销量。
- **[储能业务增长放缓]** -> [第二增长曲线尚待发力]: 储能电池领域收入仅增长5.13%，增速远低于动力电池领域（+39.67%），未能有效对冲燃油车业务（-29.33%）的下滑。
- **[海外业务布局初期]** -> [短期费用增加但长期潜力可期]: 公司在欧洲、北美、韩国设立办事处，业务开支增加，但已与多个国际客户形成深度沟通或合作备忘录，海外收入占比仍低（5.16%）。
- **[电池箱体业务起步]** -> [纵向一体化战略初现]: 电池箱体收入仅610万元，占比0.34%，但同比增长61.51%，作为与液冷板集成的产品，是提升单车价值量的关键方向。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长23.88%，但净利润仅微增1.28%，毛利率全面承压。更严重的是，经营现金流由正转负（-4734万元），主要因Q4产销激增导致的存货与应收大幅增加。这种“以现金换增长”的模式若持续，将严重考验公司的资金链管理能力，尤其是在刚上市、资本开支需求旺盛的背景下。

**客户与供应商双重高度集中构成系统性风险。** 前五大客户占比63.6%（宁德时代近40%），前五大供应商占比76.16%（第一大供应商超51%）。这种“两头在外”的格局，使公司在议价中处于弱势，利润空间易被上下游挤压。一旦核心客户（如宁德时代）切换供应商或技术路线变更，将对公司造成毁灭性打击。
