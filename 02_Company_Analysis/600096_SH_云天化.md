# 600096.SH 深度透视

## 因果逻辑链
- **[主动缩减低毛利商贸业务]** -> [营收下降21.47%，但归母净利仅降3.40%]: 公司战略性压缩大豆贸易等低毛利业务，导致营收大幅下滑，但核心化肥及磷化工业务利润保持韧性，利润降幅远小于营收。
- **[硫磺价格大幅上涨]** -> [磷肥成本承压，但价格传导部分对冲]: 主要原料硫磺采购价同比上涨84.62%，推高磷肥生产成本；但下游磷肥价格稳中略升，叠加公司战略采购优势，毛利率仅下降1.87个百分点。
- **[尿素产能过剩，价格持续低位]** -> [尿素毛利率骤降10.62个百分点]: 国内尿素新增产能集中释放，市场供过于求，尿素价格同比下跌，导致公司尿素板块盈利能力显著恶化。
- **[磷矿资源壁垒与自给优势]** -> [核心利润基石稳固]: 公司拥有近8亿吨磷矿储量，磷矿石完全自给，有效抵御了上游资源价格波动风险，是磷肥及磷化工业务维持高毛利（磷矿采选62.84%）的根本保障。
- **[财务管控优化，降杠杆成效显著]** -> [财务费用同比下降41.20%]: 公司持续优化负债结构，带息负债规模减少，综合融资成本降低，财务费用大幅下降，直接增厚了净利润。
- **[饲钙与磷化工产品价格上涨]** -> [磷化工板块毛利额提升]: 受益于原材料成本支撑和下游需求稳定，饲料级磷酸钙盐等产品价格同比上涨，推动磷化工板块毛利率提升1.91个百分点。
- **[磷酸铁产能利用率提升]** -> [新能源材料业务亏损收窄]: 公司完成磷酸铁项目连续法技术改造，产能利用率提升至73%，产销量同比大幅增长，虽仍处亏损但边际改善明显。

## 风险警告
**核心风险在于化肥主业面临的结构性下行压力。** 尿素行业产能过剩已成定局，价格持续低迷将长期压制公司氮肥业务的盈利能力。同时，磷肥业务虽受益于资源壁垒，但硫磺价格的高位波动是最大成本变量，若下游磷肥价格无法同步上涨，将直接侵蚀公司最核心的利润来源。公司营收大幅下滑，本质是主动剥离低效贸易业务，但这也意味着未来增长将更依赖化肥主业的量价表现，而该领域竞争激烈。

**第二重风险来自新产业发展的不确定性。** 公司正大力向精细磷化工、新能源材料（磷酸铁）和氟化工转型，但这些领域均面临产能过剩、技术迭代快、市场竞争激烈的局面。磷酸铁业务虽有好转，但行业整体仍处出清阶段，盈利能力薄弱。氟化工和聚甲醛的高端化转型需要持续巨额研发投入，短期难以贡献显著利润。若转型不及预期，公司可能陷入“传统业务承压、新业务亏损”的尴尬境地。此外，磷石膏综合治理带来的环保成本（预计负债同比增68.34%）是长期刚性支出。
