## 因果逻辑链
- **[防务领域“十四五”末期订单释放]** -> [电子元器件收入增长9.01%]: 下游装备采购需求恢复，直接拉动公司核心业务收入提升。
- **[全面推行精益管理，严控成本费用]** -> [归母净利润增长18.82%]: 在收入仅增4.93%的情况下，通过内部降本增效，利润增速远超收入增速。
- **[子公司宏科电子高毛利贡献]** -> [整体盈利能力提升]: 宏科电子净利润4.26亿元，占归母净利润的133%，是公司最核心的利润来源。
- **[下游客户回款周期延长]** -> [应收账款及应收票据余额高企]: 防务客户付款审批流程变长，导致应收账款同比增长30.3%，营运资金压力增大。
- **[存货减值增加]** -> [资产减值损失扩大50.87%]: 军工“多品种、小批量”特点及前瞻性备货，导致存货规模高企，计提减值损失5864万元。
- **[外销收入下滑]** -> [整体收入增速受限]: 外销收入同比下降15.38%，拖累了整体营收增速，显示海外市场需求疲软。
- **[研发投入持续加大]** -> [维持技术竞争优势]: 研发费用同比增长12.68%，聚焦MLCC、传感器等高端产品，为“十五五”规划储备技术。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户销售额占比60.66%，其中第一大客户占比19.74%，单一客户订单波动对公司影响巨大。

## 风险警告
**现金流恶化与应收账款风险**：经营活动现金流净额同比暴跌47.56%至2.9亿元，与净利润3.19亿元严重背离。核心原因是防务客户回款周期拉长，导致应收账款激增至15.69亿元，占总资产27.31%。虽然客户信用良好，但资金占用已显著影响公司流动性，若回款持续恶化，可能引发营运资金链紧张。

**存货减值与利润侵蚀风险**：公司存货规模高达9.64亿元，占总资产16.77%。军工“多品种、小批量”的生产特性导致存货周转效率低下，2025年计提存货减值损失5864万元，同比扩大50.87%。若未来下游需求调整或产品技术迭代，高额存货可能持续侵蚀利润，成为业绩的“隐形杀手”。

**客户集中与单一依赖风险**：前五大客户贡献超60%营收，其中第一大客户（苹果产业链相关）占比19.74%。精密零组件业务高度依赖苹果等消费电子巨头，面临产业链外移和订单分流风险。同时，防务领域客户采购受国家政策影响大，订单波动性强，单一客户或领域的风险暴露可能对公司业绩造成剧烈冲击。

**公司简介（F10 原文）**

> 成都宏明电子股份有限公司(国营第七一五厂)是国家“一五”时期156项重点建设工程之一,是具有60多年从事电子元器件科研生产历史的单位,是川投信息产业集团有限公司所属企业。
     公司于1994年通过了ISO9002国际质量体系认证,2002年通过了ISO9001:2000质量体系认证,系四川省高新技术认证企业、国家企业技术中心。从1987年至今已连续30多年荣获中国电子元件百强企业称号。2018年被评为“国家技术创新示范企业”(全国共68家,四川省仅4家,电子信息产业四川省唯一一家)。
     公司主要产品有:特种瓷介电容器;有机薄膜电容器;云母电容器;连接器、滤波连接器;正、负温度系数热敏电阻器;温度传感器;大功率厚膜电阻器;精密线绕电位器;精密导电塑料电位器;精密玻璃釉电位器;精密位移传感器;磁敏传感器;可变差动位移传感器;EMI抗电磁干扰滤波器;板式阵列滤波器等。同时,为客户提供电磁兼容系统解决方案及连接器互连解决方案。公司在行业领域主要为航天、航空、兵器、船舶、电子、核工业等系统的国家重点工程项目配套,产品广泛应用于通讯、汽车电子、家电、新能源等领域。
     公司下辖四家主要控股子公司:成都宏科电子科技有限公司、成都宏明双新科技股份有限公司、株洲宏明日望电子科技股份有限公司、遂宁宏明华瓷科技有限公司。
