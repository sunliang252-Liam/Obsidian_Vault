# 002025.SZ 深度透视

## 因果逻辑链
- **[营收增长但利润暴跌]** -> [增收不增利]: 营收增长15.82%至58.2亿，但归母净利润暴跌47.32%至1.83亿，主因贵金属涨价推高成本、产品降价及募投项目转固折旧增加。
- **[贵金属原材料涨价]** -> [毛利率大幅下滑]: 电子元器件制造业毛利率同比下降7.95个百分点至30.04%，原材料成本同比大增32.98%，直接侵蚀利润空间。
- **[产品价格下降]** -> [盈利承压]: 在国防客户持续强化竞争性采购机制背景下，部分产品价格下降，叠加产品结构变化，导致收入增长无法同步传导至利润。
- **[募投项目转固]** -> [折旧费用增长]: 2021年定增募投项目于2024年底转固，2025年全年承担折旧，管理费用同比增长4.26%，进一步压缩利润。
- **[订货创历史新高]** -> [现金流大幅恶化]: 为保障历史新高订单的及时交付，公司大幅增加物料采购和外协支出，导致经营活动现金流净额从-2.59亿恶化至-6.14亿。
- **[防务与战新产业双轮驱动]** -> [营收增长]: 公司加速布局新域新质装备及战略性新兴产业（AI算力、商业航天等），防务及战新领域订货、营收实现较快增长，支撑收入端表现。
- **[“2+N”产业战略]** -> [业务结构优化]: 聚焦“大互连、大电机+专精特新”战略，连接器及电机业务收入分别增长17.59%和21.65%，成为营收增长的核心驱动力。

## 风险警告
**核心风险在于“增收不增利”的恶化趋势。** 2025年营收增长15.82%，但归母净利润却暴跌47.32%，毛利率大幅下滑近8个百分点。这并非短期扰动，而是由贵金属涨价、产品降价、折旧增加三重压力叠加导致的盈利模式承压。若成本端压力无法通过提价或技术降本有效对冲，公司盈利能力将持续面临严峻挑战。

**现金流危机是另一大警报。** 经营活动现金流净额由负转巨负，从-2.59亿骤降至-6.14亿，与净利润严重背离。为保交付而大幅垫资采购，导致公司现金及等价物净减少13.2亿元，货币资金占总资产比例从23.21%腰斩至13.18%。若下游客户回款周期延长，公司可能面临流动性紧张风险，并需警惕应收账款坏账风险。
