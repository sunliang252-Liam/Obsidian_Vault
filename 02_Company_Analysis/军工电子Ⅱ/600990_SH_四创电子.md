# 600990.SH 深度透视

## 因果逻辑链
- **[研发费用激增]** -> [净利润持续巨亏]: 2025年研发投入同比暴增124.54%，达2.41亿元，直接侵蚀利润，导致归母净利润-2.88亿元，连续第三年亏损。
- **[低空经济战略投入]** -> [营收微增但亏损扩大]: 公司战略性押注低空经济，中标合肥超亿元项目，但前期研发与市场开拓成本高企，收入增长8.87%无法覆盖费用膨胀。
- **[资产减值损失高企]** -> [资产质量承压]: 2025年计提资产减值损失9657万元，叠加信用减值损失，合计近1亿元，反映存货跌价与应收账款回收风险。
- **[管理费用刚性增长]** -> [利润空间被压缩]: 管理费用同比增10.67%至2.13亿元，主要因去年同期冲回股权激励费用，但费用刚性特征明显，难以随收入同步优化。
- **[两金压降与现金流矛盾]** -> [经营现金流净额下降]: 尽管强调“两金”压降，但经营活动现金流净额同比减少25%至1.84亿元，主因其他经营活动付现增加，资金回笼压力未根本缓解。
- **[客户集中度高]** -> [经营依赖关联方]: 前五名客户销售额占比45.61%，其中关联方销售占27.49%，对中电科体系依赖度极高，议价能力受限。
- **[子公司博微长安巨亏]** -> [拖累整体业绩]: 全资子公司博微长安净利润-9545万元，成为集团最大亏损源，其警戒雷达及机动保障装备业务盈利能力严重不足。

## 风险警告
公司连续三年巨额亏损（2023-2025年累计亏损超10亿元），净资产收益率持续为负（-16.48%），且研发费用激增与资产减值损失高企并存，表明其核心业务造血能力严重不足。低空经济作为战略转型方向，虽中标标杆项目，但尚处投入期，商业化落地与盈利拐点高度不确定，存在“战略正确但财务恶化”的典型风险。

财务风险尤为突出：应收账款与存货合计超30亿元，占总资产比例超52%，且大量资产已用于质押借款（受限资产近5亿元）。客户高度集中于中电科体系，关联交易占比高，若军工订单交付或回款节奏受宏观政策影响，将直接冲击公司流动性。当前公司已连续两年未进行现金分红，股东回报能力极弱。
