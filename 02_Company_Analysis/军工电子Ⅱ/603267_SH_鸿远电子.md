## 因果逻辑链
- **[“十四五”收官年，国防装备需求集中释放]** -> [自产业务收入同比+46.64%]: 下游高可靠领域客户项目推进节奏显著提升，带动核心产品瓷介电容器需求强劲复苏。
- **[产量提升带来的规模效应 + 柔性产线改造]** -> [自产业务毛利率提升8.71个百分点至63.83%]: 产能利用率提高与交付效率优化，协同推动产品单位成本下降，盈利弹性释放。
- **[主动收缩低效益代理客户]** -> [代理业务收入同比-6.71%]: 公司战略性调整客户与产品结构，聚焦高潜力行业，导致代理业务收入阶段性承压。
- **[自产业务收入占比提升]** -> [综合毛利率大幅改善]: 高毛利自产业务占比从约50%提升至61%，产品结构优化直接拉动整体盈利水平。
- **[新业务（滤波器/微波模块/陶瓷管壳）放量]** -> [第二增长曲线初现]: 滤波器(+94.81%)、微波模块(+131.56%)、陶瓷管壳(+189.81%)均实现高速增长，多元化布局成效显著。
- **[研发投入持续加大]** -> [巩固技术壁垒与产品储备]: 研发费用1.37亿元，占自产业务收入12.63%，重点投向集成电路、瓷料等新领域，支撑长期竞争力。
- **[账期较长的自产业务增长 + 税费增加]** -> [经营性现金流同比-65.49%]: 收入增长并未同步带来现金流入，现金流质量恶化，需关注回款周期。

## 风险警告
**核心风险在于“增收不增现”与“降价压力”的双重挤压。** 公司2025年净利润大增62.54%，但经营性现金流却同比暴跌65.49%，主要因自产业务回款周期长及税费激增。这种利润与现金流的严重背离，意味着盈利质量存疑，若下游客户付款持续延迟，可能引发流动性压力。

**高可靠产品降价风险是悬在头顶的达摩克利斯之剑。** 报告明确指出，受客户成本压力影响，核心产品瓷介电容器已出现价格下滑，且降价风险持续存在。若公司无法通过推出高附加值新品或优化成本来对冲，利润增速将面临显著压制。此外，新业务（集成电路、微波模块等）仍处投入期，子公司鸿立芯、成都蓉微等持续亏损，短期将拖累整体盈利。
