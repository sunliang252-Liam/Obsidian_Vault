# 300123.SZ 深度透视

## 因果逻辑链
- **[下游客户采购计划延后、交付延期]** -> [军工电子收入下降28.12%]: 客户成本管控与审价调降导致订单释放节奏放缓，收入确认受阻。
- **[军工电子业务不及预期]** -> [计提成都亚光商誉减值8.80亿元]: 业绩未达收购预期，触发大规模商誉减值，成为全年巨亏主因。
- **[军品审价调降]** -> [报告期收入减少1.11亿元]: 结算价格下调直接冲减当期营收，压缩利润空间。
- **[船艇板块资产处置进度不及预期]** -> [折旧摊销与财务费用高企]: 闲置资产无法及时变现，固定成本与有息负债利息持续侵蚀利润。
- **[有息负债规模较大]** -> [高额财务成本]: 债务负担沉重，财务费用1.46亿元，严重拖累整体盈利能力。
- **[经营活动现金流净额转负]** -> [-49,246,220.53元]: 销售回款减少幅度大于支出缩减幅度，造血能力恶化。
- **[核心产品结构升级]** -> [中标车载超宽带相控阵天线整机项目]: 从配套产品向整机系统跨越，打开新增长空间。

## 风险警告
公司当前最核心的风险是**持续经营能力存在重大不确定性**。审计报告已明确提示，公司2025年巨亏12.36亿元，经营活动现金流为负，累计未弥补亏损高达41.35亿元，资产负债率攀升至86.60%，一年内需偿付的有息负债约14.26亿元，且部分债务已逾期。若债务展期、资产处置或融资引入等应对措施无法有效落地，公司将面临流动性危机甚至破产风险。

其次，**军工电子主业根基动摇**。作为核心利润来源的军工电子业务，因下游客户采购计划延后、审价调降等因素，收入同比下滑28.12%，毛利率更是骤降19.06个百分点。叠加高达8.80亿元的商誉减值，表明该业务已进入深度调整期，未来能否恢复增长存在巨大不确定性。船艇板块持续亏损、资产处置缓慢，进一步加剧了整体困境。
