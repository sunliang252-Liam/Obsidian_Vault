# 002214.SZ 深度透视

## 因果逻辑链
- **[民品业务增长+成本费用控制]** -> [亏损收窄]: 营收同比+26.41%，扣非净利润-2.43亿（同比+37.50%），主因民品红外产品销量+59.92%及经营效率提升。
- **[高研发投入持续]** -> [短期压制利润]: 研发费用1.50亿，占营收43.10%，虽同比持平但绝对额高企，持续侵蚀当期利润。
- **[境外市场爆发]** -> [营收结构优化]: 境外收入1.10亿，同比+165.84%，占比从15%升至32%，成为营收增长核心引擎。
- **[红外芯片双技术路线]** -> [核心竞争力壁垒]: 国内唯一量产“非晶硅+氧化钒”双路线，覆盖高分辨率与低成本场景，巩固行业领导者地位。
- **[装备业务订单落地延迟]** -> [业绩波动风险]: 部分型号装备订单进度不及预期，导致巡检机器人销量-53.24%，装备业务收入承压。
- **[存货库龄延长]** -> [资产减值损失]: 存货跌价损失-4693万，主因库龄延长，直接拖累净利润。
- **[应收账款高企]** -> [信用减值风险]: 应收账款账面余额6.85亿，坏账准备2.66亿，虽客户为央企，但回收周期长，持续计提减值。

## 风险警告
公司连续三年扣非净利润为负，2025年虽亏损收窄但仍深陷泥潭。核心风险在于**装备业务订单落地节奏不可控**，叠加**高额研发投入**与**存货/应收账款减值**的持续侵蚀，盈利拐点高度不确定。尽管民品海外市场爆发提供短期支撑，但毛利率同比下降，可持续性存疑。

**退市风险警报尚未完全解除**。公司虽已申请撤销*ST，但需深交所核准。母公司未分配利润-2.66亿，连续亏损导致净资产持续缩水（同比-14.47%）。若2026年无法实现扣非净利润转正或营收达标，将面临严峻的保壳压力。
