# 688375.SH 深度透视

## 因果逻辑链
- **[收入结构优化]** -> **净利润逆势增长**: 尽管总营收下降7.92%，但高毛利的射频芯片业务收入增长9.84%，叠加T/R组件成本降幅大于收入降幅，推动综合毛利率提升3.44个百分点，最终归母净利润增长4.72%。
- **[终端射频芯片放量]** -> **第二增长曲线形成**: 硅基氮化镓功放芯片在业内首次实现终端射频领域量产交付，带动射频芯片收入同比增长9.84%，成功开辟手机等消费电子市场，降低对单一基站市场的依赖。
- **[现金流大幅改善]** -> **经营质量提升**: 经营活动现金流净额同比暴增226.99%至8.89亿元，主要系销售回款增加及采购支出减少，表明公司应收账款回收效率显著改善，盈利质量增强。
- **[低轨卫星T/R组件批量交付]** -> **新市场突破**: 多款T/R组件产品已批量交付低轨卫星和商业航天客户，成为2025年度主要收入来源之一，成功将军用技术向商业航天领域转化。
- **[研发投入维持高位]** -> **技术壁垒加固**: 研发投入占营收比例达12.69%，重点投向5G-A/6G射频前端模组及毫米波核心技术，确保在GaN、硅基氮化镓等化合物半导体领域的技术领先地位。
- **[客户高度集中]** -> **经营依赖风险**: 前五大客户销售额占比高达80.49%，且关联方采购占比达49.78%，公司经营业绩高度依赖少数核心客户及关联方，议价能力和业务独立性受限。

## 风险警告
**核心风险在于客户与关联方的高度依赖。** 前五大客户销售额占比超80%，且第一大供应商（中国电科其他所属单位）采购额占比近50%，公司业务独立性存疑。若主要客户（如移动通信设备商）切换供应商或整机单位将T/R组件采购模式由外购转为内部配套，将对公司营收造成毁灭性打击。同时，军品审价机制导致T/R组件收入确认存在滞后性和价格不确定性，未来可能因集中审价导致毛利率大幅波动。

**技术替代与地缘政治风险不容忽视。** 公司已被列入美国“实体清单”，限制其采购美国技术及原材料，可能影响高端芯片研发与生产。此外，射频芯片领域面临Skyworks、Qorvo等国际巨头的激烈竞争，若公司在5G-A/6G、硅基氮化镓等前沿技术迭代中落后，将面临市场份额被蚕食的风险。存货激增61%也暗示下游需求可能放缓或产品验收周期拉长，需警惕存货跌价风险。
