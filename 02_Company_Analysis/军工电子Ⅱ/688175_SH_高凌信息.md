# 688175.SH 深度透视

## 因果逻辑链
- **“十四五”噪声监测建设收尾** -> **环保物联网收入骤降34.93%**: 2025年为噪声污染防治行动计划收官年，新增设备采购需求随建设高峰结束而阶段性减少，导致该板块收入大幅下滑。
- **网络内容安全业务高增49.01%** -> **部分对冲整体营收下滑**: 反诈产品（凌盾2.0）在管局、运营商、公安侧规模化应用，成为公司唯一正增长的主营业务，但毛利率因大额跨年合同集中确认而承压。
- **费用管控与信用减值减少** -> **亏损同比收窄19.82%**: 公司优化岗位、冲回未达标股份支付，同时强化催收致长账龄款回收，使扣非净利润亏损从-9017万缩至-7061万。
- **研发投入占比28.75%** -> **维持技术壁垒但侵蚀利润**: 持续高研发投入（6595万元）聚焦5G核心网、拟态防御、AI反诈等前沿领域，但短期内未能转化为收入增长，加剧亏损。
- **客户集中度高+季节性波动** -> **经营业绩不稳定**: 前五大客户占营收30.52%，且收入集中于下半年（Q4占43%），导致季度间现金流与利润剧烈波动。
- **拟态防御业务仍处市场培育期** -> **收入规模小且下降24.35%**: 该技术虽具先发优势，但工程化难点多、市场接受度有限，2025年仅贡献1405万元收入，募投项目资金投入比例低（12%-17%）。
- **军用通信业务订单未改善** -> **收入持续低位运行**: 受国防预算与采购周期影响，该板块收入同比下降21.95%，但客户需求结构优化使毛利率提升11个百分点。

## 风险警告
公司面临核心业务“青黄不接”的结构性风险。环保物联网作为过去两年的增长引擎，随着“十四五”政策红利消退，已进入量价齐跌的运维阶段，且地方政府财政吃紧进一步压制新增订单与回款。同时，军用通信业务订单未见起色，而高研发投入（占营收28.75%）持续侵蚀利润，导致公司连续两年亏损。若网络内容安全业务的高增长无法持续，公司将缺乏短期业绩支撑。

更长期的风险在于募投项目的不确定性。公司两大拟态防御募投项目资金投入比例极低（12%-17%），且公司已明确提示存在变更或终止风险。拟态防御技术虽具战略价值，但市场培育周期漫长，工程化落地困难。若该技术无法在“十五五”期间实现规模化应用，公司前期巨额的研发投入将难以回收，核心竞争力可能被新兴竞争对手追赶。
