# 603626.SH 深度透视

## 因果逻辑链
- **[消费电子需求疲软与产品结构低端化]** -> [营收与毛利率承压]: 公司31.33亿营收同比下降7.37%，核心消费电子结构件毛利率仅3.15%，低毛利产品占比过高导致整体盈利脆弱。
- **[美元汇率下跌]** -> [财务费用飙升291.7%]: 美元结算业务由汇兑收益转为汇兑损失，财务费用从0.12亿激增至0.48亿，直接侵蚀利润。
- **[资产减值损失扩大]** -> [净利润持续巨亏]: 计提固定资产减值8634.63万元及信用减值损失，资产减值损失同比暴增269%，是导致归母净利润-3.51亿的核心因素之一。
- **[出售科森医疗]** -> [短期输血与长期业务空心化]: 以9.15亿元出售盈利的医疗器械子公司，获得现金回血，但剥离了高毛利（34.85%）且增长强劲的业务，未来营收结构将更依赖低毛利消费电子。
- **[政府补助与资产处置收益]** -> [非经常性损益掩盖经营困境]: 非经常性损益达6733万元（含资产收回补偿约4800万），若扣非后净亏损高达-4.18亿，显示主营业务的造血能力严重不足。
- **[东台科森巨亏]** -> [核心子公司拖累整体业绩]: 全资子公司东台科森净亏损-3.94亿元，成为集团最大的亏损黑洞，暴露出部分生产基地产能利用率或成本控制存在严重问题。
- **[客户高度集中]** -> [经营风险敞口大]: 前五名客户销售额占比47.68%，且主要集中于消费电子领域，单一客户订单波动或流失将对公司业绩产生剧烈冲击。

## 风险警告
公司已连续三年巨额亏损（2023-2025年累计归母净亏损超11亿），且扣非净利润亏损持续扩大，表明主营业务已陷入严重的结构性困境。核心消费电子结构件业务毛利率仅3.15%，几乎处于盈亏平衡线，而公司却将唯一的高毛利、高增长业务——医疗器械（科森医疗）出售，此举虽短期获得9.15亿现金缓解流动性危机，但长期来看，公司彻底失去了一个重要的利润增长点，未来业绩将更加依赖竞争激烈、利润微薄的消费电子代工，业务空心化风险极高。

财务风险急剧恶化。公司资产负债率已攀升至64.3%，短期借款激增35.58%，而账面货币资金虽因出售资产增至8.99亿，但其中大部分已有明确用途（偿还贷款、支付货款等）。同时，公司因信息披露违规被证监会出具警示函，暴露出内部治理存在缺陷。在持续亏损、主业羸弱、治理存疑的背景下，公司转型AI、机器人、固态电池等新领域尚处早期，对当期业绩贡献有限，能否成功突围存在巨大不确定性。
