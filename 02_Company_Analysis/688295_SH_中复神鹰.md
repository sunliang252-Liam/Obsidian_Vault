# 688295.SH 深度透视

## 因果逻辑链
- **[销量增长]** -> [营收增长40.87%]: 积极拓展下游应用领域，销量同比大幅增长54.52%，驱动营收从15.57亿增至21.94亿。
- **[单位生产成本下降12%]** -> [毛利率提升3.14个百分点]: 通过技术改造、工艺优化、集中采购等降本措施，在价格承压环境下实现毛利率从13.59%升至16.73%。
- **[优化产品结构]** -> [扭亏为盈]: 高端产品（如T1100级、M系列）价格引领+低成本大丝束产品放量，双轮驱动净利润从-1.24亿转为0.96亿。
- **[产销率超110%]** -> [库存大幅下降48.9%]: 以销定产策略下，销量（2.5万吨）远超产量（2.25万吨），期末库存从5247吨降至2681吨，运营效率显著提升。
- **[“五集中”管理]** -> [管理费用下降37.89%]: 推行财务、技术、投资、人力资源、供应链集中管理，管理费用从1.77亿降至1.10亿，释放利润空间。
- **[产能规模国内第一]** -> [市占率持续提升]: 2.9万吨产能（在建3.1万吨）支撑公司在压力容器（>75%）、体育休闲（>45%）等核心领域市占率稳居龙头。
- **[风电/压力容器需求增长]** -> [新能源领域供应量增长73%]: 受益于风电大型化、氢能储运等下游景气，公司高性能碳纤维在新能源领域实现高速渗透。

## 风险警告
**产能过剩与价格战风险**：国内碳纤维行业正经历产能加速释放期，中低端领域供需失衡加剧。尽管公司通过高端产品差异化策略维持价格体系，但若下游需求增速放缓，或竞争对手在高端领域取得突破，公司可能面临毛利率进一步压缩的风险。2025年毛利率虽回升至16.73%，但仍远低于2023年水平，价格压力并未根本解除。

**原材料与能源价格波动风险**：核心原材料丙烯腈为石油衍生品，价格波动剧烈；天然气、电力等能源成本占比高。2025年经营活动现金流净额同比下降30.6%，主因即为产量增长导致原材料采购支出增加。若上游价格大幅上涨，将直接侵蚀公司本已微薄的利润空间，而公司向下游传导成本的能力受制于市场竞争格局。

**新产能建设与市场消化风险**：公司3万吨在建项目（总投资超50亿）建设周期延长至2029年，反映出对市场需求的审慎判断。当前产能利用率（2.25万吨产量/2.9万吨产能≈77.6%）仍有提升空间，但若新兴领域（低空经济、机器人）需求释放不及预期，大规模资本开支将带来折旧压力与资金占用，可能拖累未来盈利能力。
