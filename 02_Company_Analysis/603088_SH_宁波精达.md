# 603088.SH 深度透视

## 因果逻辑链
- **[并购无锡微研]** -> [营收增长但利润下降]: 2025年并表无锡微研贡献模具等新业务收入，但并购带来的管理费用（+36.11%）、销售费用（+10.42%）及研发费用（+22.44%）大幅增加，叠加精密压力机收入骤降46.24%，导致归母净利润同比下滑27.03%。
- **[精密压力机业务萎缩]** -> [整体毛利率承压]: 精密压力机系列收入同比减少46.24%，毛利率下降13.33个百分点，拖累金属成形机床制造业务整体毛利率下降6.76个百分点。
- **[换热器装备订单高增]** -> [核心主业保持韧性]: 换热器自动化装备系列收入同比增长22.82%，订单同比提高36.10%，受益于以旧换新政策、数据中心投资及海外扩产，成为公司营收增长的核心支柱。
- **[海外市场布局深化]** -> [出口业务增长但毛利率下降]: 国外市场收入同比增长3.44%，但毛利率下降6.38个百分点，反映海外竞争加剧及成本上升。
- **[并购产生商誉与整合风险]** -> [资产结构变化]: 收购无锡微研新增商誉4559万元，总资产增长42.10%，但整合协同效果尚需时间验证，存在商誉减值风险。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比增长76.69%至2.08亿元，主要得益于无锡微研并表及回款改善，现金流状况优于利润表现。
- **[资本公积大幅增加]** -> [每股收益稀释]: 发行股份收购资产及配套融资使资本公积增长691.02%，总股本增加，导致基本每股收益从0.38元降至0.25元（-34.21%）。

## 风险警告
**核心风险在于并购整合不及预期与主业结构性下滑。** 公司2025年利润下滑27%，主因并非一次性费用，而是精密压力机业务收入腰斩（-46.24%），该业务毛利率亦大幅下降13个百分点，显示下游需求疲软或竞争加剧。同时，收购无锡微研新增4559万元商誉，若未来业绩承诺（2026年净利润不低于3970万元）未能实现，将面临减值风险，进一步侵蚀利润。

**毛利率系统性下降与海外经营不确定性是长期隐忧。** 公司整体毛利率下降6.76个百分点，国内和国外市场毛利率均出现下滑，成本端压力持续。此外，海外子公司（美洲精达、精达肖拉）仍处于亏损状态，且面临高端机床控制系统进口依赖、汇率波动及地缘政治风险，海外扩张的盈利贡献尚需时日。
