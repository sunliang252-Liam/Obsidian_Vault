# 600789.SH 深度透视

## 因果逻辑链
- **[国家药品集采政策持续深化]** -> [人用药收入与毛利率双降]: 集采导致终端价格承压，公司人用药收入同比下降19.11%，毛利率减少6.6个百分点，是净利润下滑71.54%的核心原因。
- **[原料药业务量价齐跌]** -> [原料药毛利率降至1.07%]: 原料药收入同比骤降36.37%，成本降幅（-31.19%）远不及收入降幅，导致毛利率仅剩1.07%，几乎无利可图。
- **[兽用药市场需求旺盛]** -> [兽用药收入与毛利率双增]: 兽用药收入同比增长1.79%，毛利率提升3.89个百分点，成为公司业绩的稳定器，对冲了人用药的下滑。
- **[合成生物产品实现商业化]** -> [新增收入1.12亿元，毛利率34.42%]: 全球首个反式乌头酸项目投产，多个天然产物产业化，合成生物业务从0到1，成为未来增长新引擎。
- **[完成12亿元定向增发]** -> [资产负债率降至47.61%，现金流充裕]: 再融资成功大幅优化资本结构，货币资金暴增203.46%，为“十五五”战略投资提供充足弹药。
- **[研发投入持续高企]** -> [创新药管线推进，但短期侵蚀利润]: 研发费用占营收5.91%，3个1类创新药进入临床，但高额投入尚未转化为当期利润，是利润下滑的隐性因素。
- **[非经常性损益大幅减少]** -> [扣非净利润降幅小于归母净利润]: 2024年有1.53亿元资产处置收益，2025年该收益消失，导致归母净利润降幅（-71.54%）远大于扣非净利润降幅（-59.99%）。

## 风险警告
**核心风险：人用药业务遭遇集采与市场竞争的双重绞杀，盈利根基动摇。** 公司核心的原料药和制剂业务收入与毛利率双双大幅下滑，尤其是原料药毛利率已跌至1.07%的盈亏平衡线。在集采常态化、行业“分化”加剧的背景下，公司若无法通过“原料药+制剂”一体化优势进一步压缩成本，或推出高壁垒仿制药/创新药，其传统业务将面临持续失血的风险。

**次要风险：合成生物业务尚处早期，新增长曲线存在不确定性。** 尽管合成生物收入突破1.1亿元且毛利率较高，但占整体营收比例极小（约2%）。该业务从技术验证到规模化放量、从高毛利到稳定盈利，仍面临技术迭代、市场接受度和产能爬坡等多重挑战。公司能否将其打造为真正的第二增长曲线，尚需时间验证。此外，高达2.28亿元的土地收储补偿款回收进度存在不确定性，可能影响现金流。
