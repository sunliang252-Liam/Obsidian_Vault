# 688450.SH 深度透视

## 因果逻辑链
- **政府基建项目推进效率受地方财政压力传导影响** -> 行业客户需求释放递延: 宏观经济环境波动导致政府投资放缓，进而影响下游客户项目进度和需求释放
- **公司加强市场拓展力度** -> 市场拓展费用增加: 为应对复杂市场环境，公司主动增加销售投入以稳住现有优势领域并开拓新市场
- **部分应收账款账龄增加** -> 信用减值损失增加: 账龄延长导致根据信用政策计提的坏账准备增加
- **市场拓展费用增加及信用减值损失增加** -> 扣非净利润亏损扩大: 费用和减值损失增加直接侵蚀利润，导致扣非后亏损幅度扩大
- **新行业（港口、矿山）开拓取得初步成效** -> 营业收入同比增长18.18%: 新业务布局带来增量收入，部分抵消传统业务压力
- **研发投入持续高企（占营收30.18%）** -> 新产品取得认证（矿用防爆证、机器人大赛入选）: 持续高研发投入保障技术创新，推出符合新行业需求的产品并获认证

## 风险警告
尽管收入增长，但公司扣非净利润亏损扩大，主要因市场拓展费用增加和应收账款账龄延长导致的信用减值损失增加。高研发投入（30.18%）短期内侵蚀利润，但长期有助于技术壁垒构建。需关注地方财政压力对基建项目推进的持续影响，以及新行业开拓的盈利转化时间。
