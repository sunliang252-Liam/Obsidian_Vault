# 002017.SZ 深度透视

## 因果逻辑链
- **[国内智能卡市场饱和，竞争加剧]** -> [智能卡收入下降8.82%]: 传统SIM卡、金融卡等产品进入成熟期，价格竞争激烈，导致核心业务收入承压。
- **[海外市场收缩，收入骤降]** -> [国外销售收入下降29.69%]: 受国际宏观环境及区域市场波动影响，海外智能卡订单减少，拖累整体营收。
- **[数字安全与平台业务增长]** -> [创新业务收入增长10.28%]: eSIM平台、车联网、消费电子等新业务规模化落地，成为公司“第二增长曲线”。
- **[研发投入持续加大]** -> [研发费用增长7.49%，占营收11%]: 公司为巩固技术壁垒，在嵌入式OS、eSIM平台、数字身份云等领域高强度投入。
- **[财务费用大幅下降]** -> [利息收入增加，财务费用同比-79.71%]: 公司现金充裕，存款结构优化，利息收入显著增长，增厚利润。
- **[存货跌价准备高企]** -> [资产减值损失达2167万元]: 存货余额中计提了13.4亿元跌价准备（占存货19.87%），反映产品迭代快、呆滞库存风险。
- **[经营活动现金流改善]** -> [经营性现金流净额增长19.57%]: 尽管利润下滑，但公司加强回款管理，现金流质量优于利润表现。

## 风险警告
**核心风险在于传统智能卡业务的持续萎缩与创新业务能否接棒。** 公司智能卡收入同比下降8.82%，海外市场更是骤降近30%，表明其基本盘正遭受行业饱和与地缘政治的双重挤压。虽然数字安全与平台业务增长10.28%，但体量仅占营收24.6%，尚不足以完全对冲传统业务的下滑，公司正处于“青黄不接”的转型阵痛期。

**存货减值与供应链集中度是财务上的“灰犀牛”。** 公司存货跌价准备高达13.4亿元，占存货余额近20%，反映出智能卡产品生命周期短、技术迭代快的行业特性，若未来市场需求或技术路线发生突变，将面临大规模资产减值的风险。同时，前五大供应商采购额占比高达63.93%，供应链高度集中，一旦核心芯片或原材料供应受限，将直接冲击生产交付能力。
