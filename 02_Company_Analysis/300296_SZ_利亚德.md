# 300296.SZ 深度透视

## 因果逻辑链
- **海外市场扩张（境外显示营收占比升至54.32%）** -> **利润扭亏为盈（归母净利润3.07亿）**: 海外客户对价格敏感度低，高毛利订单占比提升，直接拉动整体毛利率从28.10%升至31.41%。
- **主动放弃低毛利、高风险订单（不参与价格战）** -> **营收微降1.20%但毛利率提升3.31%**: 公司战略从“规模扩张”转向“价值创造”，牺牲部分营收规模换取利润质量。
- **MicroLED技术突破（Hi-Micro发布，新签订单17亿，同比+50%）** -> **产品结构优化与高端市场卡位**: 无衬底MicroLED技术构建差异化壁垒，推动产品向高附加值领域渗透，支撑未来盈利能力。
- **强化精益管理与数字化（MOM/SRM/PLM系统上线，物料精简60%）** -> **管理费用与销售费用分别下降9.04%和5.10%**: 供应链集权管控与产品标准化直接降低运营成本，实现降本增效。
- **经营性现金流创近五年新高（10.66亿，同比+59.59%）** -> **财务结构健康度显著改善**: 加大海外回款快的渠道销售占比，同时加强国内应收款催收（“应催尽催、应诉尽诉”），资金回笼加速。
- **文旅夜游板块融合升级（成立励丰文旅集团，推行“1+2+4”战略）** -> **板块毛利率从17.79%大幅提升至27.68%**: 从工程集成商向“运营前置”的综合服务商转型，提升项目附加值与盈利能力。
- **AI与空间计算业务聚焦具身智能数据服务** -> **开辟第二增长曲线**: 从“动作捕捉技术提供商”升级为“数据服务商”，切入机器人训练数据这一高壁垒、高增长赛道，打开长期想象空间。

## 风险警告
**最大风险在于国内市场需求持续疲软与行业“内卷”加剧。** 公司2025年国内智能显示营收同比下降17.28%，境内市场“增量不增收”的困境并未缓解。若宏观经济复苏不及预期，国内政府及企业端投资持续收缩，公司国内业务可能继续承压，拖累整体增长。公司虽通过海外扩张对冲，但地缘政治与关税风险（如中美关税博弈）可能随时冲击海外业务。

**技术路线快速迭代带来的战略不确定性不容忽视。** MicroLED技术尚未完全定型，MiP与COB路线之争、面板巨头（京东方、TCL华星）的跨界入局，都可能重塑竞争格局。公司虽采取“双轨并行”策略，但若主流技术路径发生偏移，或竞争对手在成本与良率上取得突破性进展，公司现有的技术先发优势可能被削弱，前期巨额研发投入（近5年近20亿）的回报存在不确定性。
