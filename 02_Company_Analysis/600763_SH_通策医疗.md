# 600763.SH 深度透视

## 因果逻辑链
- **[种植牙集采“以价换量”]** -> [种植收入微降2.08%，但门诊量增长]: 集采压低客单价，但刚性需求释放，服务量攀升对冲单价下滑，实现收入基本稳定。
- **[正畸业务复苏]** -> [正畸收入同比增长7.63%]: 消费升级与国产品牌性价比驱动，正畸渗透率提升，成为2025年核心增长引擎。
- **[“区域总院+分院”模式]** -> [省内收入增长2.54%，省外下降8.29%]: 深耕浙江根据地，品牌与资源复用效率高；省外扩张尚处投入期，规模效应未显。
- **[人力成本占比55.32%]** -> [毛利率仅微增0.09个百分点至39%]: 口腔医疗手工业属性决定人力成本刚性，集采与消费降级下，成本优化空间有限。
- **[蒲公英分院扩张]** -> [管理费用、租赁费、折旧持续增加]: 新院区前期投入（装修、租金、人员）侵蚀利润，导致营收增速（1.37%）远低于费用增速。
- **[数字化与AI赋能]** -> [运营效率提升，销售费用率保持低位]: AI辅助诊疗与OD运营体系优化医患匹配，降低营销依赖，实现低成本获客。
- **[第四季度亏损]** -> [归母净利润-1155万元]: 季节性因素叠加年末费用集中结算，暴露公司收入确认节奏与成本刚性之间的矛盾。

## 风险警告
**增长停滞与扩张陷阱。** 公司2025年营收仅增1.37%，净利润几乎零增长，核心存量业务（种植、儿科）出现下滑。同时，蒲公英分院扩张导致管理费用、租赁负债（租赁负债高达7.39亿）持续攀升，但新院区贡献的增量收入远不足以覆盖成本，陷入“增收不增利”甚至“增支不增收”的困境。若新院区无法快速实现盈亏平衡，将严重拖累整体ROE。

**政策与消费双重挤压。** 种植牙集采已全面落地，正畸集采接踵而至，公司核心业务的定价权持续被削弱。同时，消费降级趋势下，高毛利的正畸、美学修复等消费医疗需求承压。公司试图通过“以量补价”对冲，但门诊量增速（1.14%）远低于价格降幅，量价博弈的天平正在倾斜。此外，公司连续两年因信披违规被监管处罚，治理风险不容忽视。
