# 300516.SZ 深度透视

## 因果逻辑链
- **[军品审价与阶梯降价常态化]** -> [毛利率承压]: 军品业务占比高，审价及降价政策持续压缩产品利润空间，导致增收不增利。
- **[对预计回款不确定的应收账款单项计提大额信用减值]** -> [净利润大幅下滑22%]: 基于谨慎性原则，2025年计提信用减值损失同比增加约5,300万元，直接侵蚀利润，是净利润下降的主因。
- **[装备、应用、外贸“三驾马车”战略推进]** -> [营收增长27.96%]: 在巩固传统军品基本盘的同时，积极拓展民用（如机场、卫星互联网）和外贸市场，带动总收入显著增长。
- **[红外热像仪与光学系统业务高增长]** -> [收入结构优化]: 红外热像仪收入增长36.27%，光学系统收入增长35.91%，成为营收增长的核心驱动力，弥补了激光产品增速放缓的影响。
- **[经营活动现金流净额大幅改善]** -> [财务质量提升]: 销售回款增加与采购支出减少，使经营性现金流净额同比增长41.85%，与净利润下滑形成反差，表明盈利质量有所改善。
- **[高研发投入聚焦新质生产力]** -> [技术壁垒与未来增长点]: 研发费用占营收9.57%，重点投向卫星互联网、反无系统、深海探测等新兴领域，为中长期发展储备技术动能。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比78.60%，其中关联方客户A占比35.99%，对单一客户依赖度高，议价能力和经营稳定性受制约。

## 风险警告
**核心风险在于“增收不增利”的困境与高额信用减值。** 公司营收增长近28%，但净利润却下滑22%，主因是对特定客户应收账款计提了超8000万的信用减值损失。这揭示了公司客户回款存在重大不确定性，尤其是关联方及军品客户，坏账风险是未来利润的最大侵蚀点。若回款情况持续恶化，将严重拖累公司盈利能力和现金流。

**其次，军品业务模式带来的双重风险。** 一方面，军品审价和阶梯降价常态化，持续压缩产品毛利率，公司虽有民用转型战略，但当前规模尚小，仍处于“阵痛期”。另一方面，客户高度集中（前五占78.6%），且与控股股东关联交易占比高（35.99%），导致公司议价能力弱，经营业绩易受单一客户采购计划变动和关联交易定价的影响，独立性存疑。
