# 301328.SZ 深度透视

## 因果逻辑链
- **[新能源/汽车连接器需求爆发]** -> [营收增长33.46%]: 新能源连接器营收增长41.40%，汽车连接器增长34.63%，成为核心增长引擎，拉动整体营收从5.34亿跃升至7.13亿。
- **[工业控制连接器库存周期修复]** -> [工控业务稳健增长28.11%]: 下游库存见底带来需求复苏，叠加新客户/新场景导入，工控连接器作为基本盘贡献3.30亿营收，稳固了业绩基础。
- **[昆山基地投产与泰国基地建设]** -> [产能扩张与全球化布局]: 昆山项目投产提升华东智造能力，泰国基地建设推进海外产能，为应对贸易风险和贴近客户提供战略弹性。
- **[研发投入持续高企（占营收8.96%）]** -> [技术壁垒与新产品储备]: 研发支出6389万元，支撑高速通讯连接器（PCIe 6.0、MCIO）及高频高速汽车连接器（FAKRA、Mini-FAKRA）等新品开发，为未来增长蓄力。
- **[员工持股计划与股份支付]** -> [管理费用激增56.12%]: 2024年员工持股计划在2025年摊销股份支付费用约1490万元，导致管理费用从4338万大幅增至6773万，侵蚀了部分利润。
- **[毛利率结构性承压]** -> [净利润增速远低于营收增速]: 整体毛利率微降0.82%，但汽车连接器毛利率下降3.99%，叠加费用端压力，导致归母净利润仅增长15.64%，远低于营收33.46%的增幅。
- **[绑定头部客户（前五大客户占34%）]** -> [订单稳定性与市场地位]: 深度绑定X、S、A等工控巨头及B、S、C等车企，以及M、T等通讯客户，高客户粘性保障了订单的持续性和增长确定性。

## 风险警告
**核心风险：增收不增利，盈利能力承压。** 公司营收增长33.46%，但归母净利润仅增长15.64%，扣非净利润增速更是低至7.91%。毛利率下降（汽车连接器毛利率下降3.99%）、管理费用因股份支付激增56.12%、研发费用高企，三重压力共同导致利润增速严重落后于营收。若未来毛利率持续下滑或费用控制不力，公司可能陷入“规模扩张但利润稀薄”的困境。

**战略风险：新领域拓展与全球化运营的不确定性。** 公司正积极布局AI服务器高速连接器、人形机器人等新兴赛道，并推进泰国基地建设。这些领域技术迭代快、竞争激烈，且面临地缘政治、汇率波动等全球化运营风险。若技术路线选择失误、客户导入不及预期或海外运营受阻，前期巨额投入可能无法转化为有效产出，导致资产减值与战略受挫。
