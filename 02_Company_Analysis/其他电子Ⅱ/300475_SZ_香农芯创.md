# 300475.SZ 深度透视

## 因果逻辑链
- **[AI算力驱动存储需求爆发]** -> [营收增长45.24%]: 全球AI数据中心建设拉动存储芯片需求，公司作为SK海力士核心分销商，销售额达352.51亿元。
- **[“分销+产品”双轮驱动战略]** -> [自研存储业务规模化]: 自主品牌“海普存储”企业级SSD和DRAM量产，2025年实现规模收入16.58亿元，同比增长468%。
- **[SK海力士独家代理权]** -> [高客户粘性与高市占率]: 核心代理SK海力士存储器，覆盖国内头部互联网云服务商，前五大客户销售占比79.19%。
- **[以销定采+备货采购模式]** -> [存货周转效率提升]: 基于客户订单和需求预测灵活采购，2025年存货余额同比下降9.1%，经营活动现金流净额达14.38亿元。
- **[股权激励绑定核心团队]** -> [净利润增长106%]: 2024年限制性股票激励计划首次归属，激发管理层动力，扣非净利润5.19亿元，同比增70.37%。
- **[关联采购渠道]** -> [供应链成本优势]: 通过实控人控制的关联方（无锡欣珩等）采购，2025年关联采购额105.54亿元，占营业成本10.99%，保障货源稳定。
- **[原厂授权壁垒]** -> [高客户集中度]: 获得SK海力士、AMD等原厂授权，但下游客户高度集中于互联网巨头，前五大客户销售占比79.19%，存在依赖风险。

## 风险警告
**核心风险在于对单一供应商SK海力士的深度依赖。** 公司98.6%的采购额来自前五大供应商，其中SK海力士一家占比48.41%。一旦授权取消或不能续约，公司将失去核心货源，业务将遭受毁灭性打击。尽管公司声称合作关系稳定，但存储器原厂集中度极高，议价权完全在上游，公司作为分销商利润空间被严重挤压（分销毛利率仅2.86%）。

**第二大风险是存储器价格周期性波动带来的毛利率和存货减值风险。** 存储器行业强周期、寡头垄断，价格易暴涨暴跌。2025年受益于AI需求价格上涨，但若下游需求放缓或供给过剩，公司高达25.98亿元的存货将面临巨额跌价准备，直接侵蚀利润。同时，公司客户集中度极高（前五大客户占79.19%），若核心客户流失，业绩将剧烈波动。
