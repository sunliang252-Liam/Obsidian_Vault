# 300736.SZ 深度透视

## 因果逻辑链
- **战略重心转向中小客户** -> 联盟业务收入下降36.42%: 公司主动将支持重心从批发商转向中小维修商，单笔提货量小且原厂业务增长慢，导致联盟业务收入从4.05亿骤降至2.57亿。
- **抖音等平台营销投入激增** -> 销售费用同比+111.36%: 公司加大抖音佣金、推广费及电商团队人力投入，销售费用从1055万增至2231万，是亏损扩大的直接推手。
- **关闭7家盈利不佳门店** -> 保外维修收入下降16.52%: 门店关闭导致维修订单量减少8929单，叠加保外维修单价下滑，保外维修收入同比减少801.75万元。
- **iPhone13电池鼓包召回** -> 保内维修收入增长39.43%: 苹果召回计划带动毛利率较高的保内维修订单量增长，保内收入增加574.66万元，部分对冲了保外收入下滑。
- **苹果正品屏幕销售骤降** -> 联盟业务毛利率提升至7.05%: 苹果正品屏幕收入同比下降54.52%，因其毛利率偏低，收入占比下降反而推高了联盟业务整体毛利率。
- **抖音小时达“资源机”业务** -> 商品销售收入暴增1221.59%: 2025年3月上线iPhone16资源机销售，全年贡献9890万元收入，占该类业务收入的94.45%，成为收入新支柱。
- **数字化与AI自动化建设** -> 运营效率提升: 公司实现90%以上业务流程自动化，并持续引入AI决策，支撑了联盟业务成本降幅（-38.63%）超过收入降幅（-36.42%）。

## 风险警告
**核心风险在于战略转型的“青黄不接”**。公司主动收缩高周转但低毛利的批发商业务，转向赋能中小维修商，导致联盟业务收入骤降36.42%。虽然毛利率有所改善，但新客户增长和原厂业务渗透需要更长的加速时间，短期内收入缺口难以弥补。同时，抖音等线上营销投入激增，销售费用翻倍，但能否转化为可持续的订单增长和用户复购，尚待验证。公司已连续三年亏损，净资产从2023年的1.05亿缩水至2025年的0.71亿，造血能力持续恶化。

**第二大风险是单一供应商依赖与业务结构脆弱性**。公司前五大供应商采购额占比高达86.36%，其中苹果电脑贸易（上海）有限公司一家就占61.20%。苹果授权业务是公司根基，但苹果对售后政策的调整（如召回计划、配件供应范围）会直接冲击公司收入和利润。此外，新增长的“资源机”业务虽贡献近亿收入，但本质是销售无官方保修的“特殊机型”，业务可持续性和合规性存在不确定性，且毛利率仅6.30%，盈利能力有限。
