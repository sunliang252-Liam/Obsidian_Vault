# 300650.SZ 深度透视

## 因果逻辑链
- **[半导体分销业务为核心]** -> **营收微增但利润下滑**: 半导体分销营收222.5亿元(+3.97%)，但归母净利润仅3992万元(-21.97%)，显示增收不增利，毛利率极低(5.3%)。
- **[经营活动现金流骤降93.8%]** -> **资金链承压**: 因结算第一大客户大额返利，经营活动现金流净额从3.86亿骤降至2392万，严重恶化。
- **[短期借款激增11.22个百分点]** -> **财务杠杆加大**: 为补充营运资金，短期借款从1.26亿增至3.72亿，占总资产比例从6.09%升至17.31%。
- **[半导体分销库存量暴增65.16%]** -> **存货跌价风险高企**: 因并购新增子公司，库存量大幅增长，叠加资产减值损失2085万元(-46.63%)，侵蚀利润。
- **[商业照明毛利率下滑2.95个百分点]** -> **传统业务承压**: 照明器具毛利率从27.39%降至23.80%，反映行业竞争加剧与成本上升。
- **[客户高度集中]** -> **经营依赖单一客户**: 前五大客户销售额占比56.05%，第一大客户占比23.40%，议价能力弱，返利政策直接影响现金流。
- **[商誉减值风险悬顶]** -> **并购后遗症**: 博思达资产组若业绩恶化，将引发商誉减值，对利润造成重大冲击。

## 风险警告
**核心风险在于半导体分销业务的“伪增长”与现金流枯竭。** 公司营收增长依赖低毛利的半导体分销，但该业务毛利率仅5.3%，且经营活动现金流因大客户返利而骤降93.8%，几乎无法造血。为维持运营，公司被迫大幅增加短期借款，财务杠杆急剧攀升，流动性风险一触即发。同时，并购带来的库存激增与资产减值损失，进一步暴露了其粗放扩张的隐患。

**另一重大风险是商誉减值与客户集中度双杀。** 公司商誉规模庞大，若博思达资产组经营恶化，减值将直接吞噬利润。此外，前五大客户贡献超56%营收，第一大客户占比近1/4，公司议价能力极弱，一旦客户调整采购策略或压缩返利，业绩将剧烈波动。商业照明业务虽稳健，但毛利率持续下滑，难以对冲半导体分销业务的系统性风险。
