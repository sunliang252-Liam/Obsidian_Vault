# 001333.SZ 深度透视

## 因果逻辑链
- **[原材料价格下行]** -> [营收下降但销量增长]: 2025年PTA、NPG等主要原材料价格同比下降，公司产品售价随行就市下调，导致营收同比-5.13%，但聚酯树脂销量逆势增长7.98%至18.06万吨。
- **[销量增长与毛利率承压]** -> [净利润下滑]: 销量增长未能完全抵消售价下降的影响，叠加新产能爬坡带来的固定成本增加，归母净利润同比-20.88%至1.16亿元。
- **[新产能释放]** -> [生产量增速快于销量]: “年产12万吨项目”于2023年达产，2025年产能利用率84.77%，生产量同比+15.07%，导致库存量同比+50.57%。
- **[应收账款高企与信用减值]** -> [经营现金流持续为负]: 应收账款余额高达7.52亿元，占营收46%，叠加信用减值损失277万元，导致经营活动现金流净额-3155万元，但较上年同期改善56.11%。
- **[“漆改粉”政策驱动]** -> [下游需求结构性增长]: 国家环保政策推动粉末涂料在新能源、集装箱、工程机械等新领域渗透，带动聚酯树脂需求，公司销量创历史新高。
- **[海外布局加速]** -> [外销收入增长]: 公司设立香港、新加坡、泰国子公司，外销收入同比+3.20%至3.28亿元，占比提升至20.06%。
- **[研发聚焦功能化]** -> [产品差异化竞争]: 公司研发投入5184万元，聚焦低温固化、不含TMA、石墨烯改性等高端产品，以应对行业同质化竞争。

## 风险警告
**核心风险在于“增收不增利”与现金流压力。** 公司销量增长但净利润下滑，主要因原材料价格波动导致产品售价下调，毛利率承压。更严峻的是，应收账款高达7.52亿元，占营收46%，且客户多为中小粉末涂料厂，抗风险能力弱，坏账风险与现金流压力是悬在头上的利剑。尽管经营现金流有所改善，但仍为负值，显示公司实际造血能力不足。

**产能过剩与行业竞争加剧是长期隐忧。** 公司现有产能21.9万吨，在建15万吨，而行业前十企业市占率已超60%，产能扩张迅猛。若下游“漆改粉”趋势放缓或新兴领域需求不及预期，公司可能面临产能利用率下降、价格战加剧的风险，导致盈利能力进一步恶化。
