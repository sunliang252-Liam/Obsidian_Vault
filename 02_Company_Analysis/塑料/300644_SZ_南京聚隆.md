# 300644.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升+主机厂集采战略]** -> **改性塑料销量增长30%**: 公司抓住头部主机厂材料集采机遇，深度绑定比亚迪、赛力斯、理想等新能源车企，单车配套量达80KG，推动改性塑料销量从17.6万吨增至22.9万吨。
- **[原材料价格下行+产品结构优化]** -> **毛利率提升**: 主要原材料PA66、PA6、PP等价格下半年环比下降，叠加高毛利产品（如阻燃材料、智驾材料）占比提升，改性工程塑料毛利率同比提升4.38个百分点。
- **[低空经济政策催化+技术突破]** -> **碳纤维复材业务整机交付**: 完成V1000B倾转旋翼飞行器首架机整机交付，并与零重力签订30套电动固定翼整机合同，标志着从部件制造向整机装配的跨越。
- **[具身智能赛道布局]** -> **机器人材料量产**: 已开发8款专用改性材料，5款实现量产，单项目供货规模达百公斤级，成功切入四足机器狗和人形机器人供应链。
- **[产能扩张与全球化布局]** -> **规模效应释放**: 滁州基地10万吨产能全部投产，墨西哥基地部分产线投产，南京4万吨特种材料项目启动，形成多基地协同，支撑营收增长19.82%。
- **[股权激励绑定核心团队]** -> **人才稳定性增强**: 推出两期股权激励计划，覆盖核心骨干，关键岗位人才流失率低位，研发团队新增3名博士，为技术持续突破提供保障。
- **[票据结算为主的回款模式]** -> **经营性现金流为负**: 销售回款以票据为主，采购付款以现款为主，形成“收现少、付现多”的现金流错配，导致经营活动现金流净额为-1.1亿元。

## 风险警告
**现金流与盈利严重背离是最大隐患。** 公司净利润1.32亿元，但经营性现金流为-1.1亿元，核心原因是票据回款占比过高。若下游客户信用环境恶化或票据贴现成本上升，公司将面临流动性压力。虽然公司声称贴现后现金流可转正，但这本质上是将信用风险后移，并未改善回款质量。

**原材料价格波动与下游议价能力构成双重挤压。** 公司主要原材料为石油衍生品，价格波动剧烈。虽然2025年原材料价格下行利好毛利率，但公司对下游主机厂的议价能力有限，若油价反弹，成本难以完全传导。此外，改性塑料行业竞争激烈，中低端产品同质化严重，公司毛利率长期在15%左右徘徊，盈利能力天花板明显。
