# 000973.SZ 深度透视

## 因果逻辑链
- **金力新能源收购完成** -> 锂电池隔膜纳入产品体系: 收购后金力新能源成为全资子公司，其锂电池湿法隔膜业务并入上市公司，形成以锂电池隔膜、光学薄膜等为框架的产业布局。
- **偏光膜三期项目产能未完全释放** -> 纬达光电净利润下降159.51%: 项目产能尚未达到满产，产品单位成本上升，叠加售价下降，导致毛利率降低，毛利减少。
- **华韩卫生新投产项目客户认证周期长、工艺不成熟** -> 华韩卫生持续亏损: 新项目客户认证周期长，产能未充分释放；初期工艺不成熟导致原材料损耗率高，成本分摊高，叠加市场竞争激烈，产品售价下降。
- **购买理财产品增加及汇兑净损失增加** -> 财务费用同比上升80.33%: 理财产品增加导致存款利息收入减少，同时汇兑净损失增加，共同推高财务费用。
- **固定资产投入及购买理财产品现金流出增加** -> 投资活动现金流净额同比减少128.83%: 高精度超薄电容膜三水二期、偏光膜三期等项目投入以及理财产品购买增加，导致现金净流出大幅增加。
- **塑编阻隔材料产能提升** -> 塑编阻隔材料产销量及库存量大幅增长: 产能提升后，公司根据市场需求动态调整产销节奏，导致生产量和销售量分别增长68.09%和42.40%，库存量随之增加80.97%。

## 风险警告
公司面临多重风险：1）新收购的金力新能源整合效果不确定，且锂电池隔膜行业竞争激烈；2）在建项目（偏光膜三期、电容膜项目等）产能释放不及预期，持续侵蚀利润；3）财务费用因理财和汇兑损失大幅增长，现金流紧张，投资活动现金净流出大幅增加；4）子公司华韩卫生持续亏损，拖累整体业绩；5）原材料价格波动及汇率风险可能进一步影响盈利能力。

**公司简介（F10 原文）**

> 佛山佛塑科技集团股份有限公司成立于1988年6月。2000年5月在深圳证券交易所挂牌上市(证券简称:佛塑科技证券代码:000973),是“国家火炬计划重点高新技术企业”“国家技术创新示范企业”和国务院国资委“科改示范企业”。  公司专注于高分子功能薄膜与复合材料的研发与生产,围绕新材料主业发展定位,形成以锂电池隔膜、光学薄膜、双向拉伸薄膜、渗析防护材料和塑编阻隔材料为重点的产业布局,为新能源、电工电气、光电显示、医疗卫生等战略性新兴产业提供核心功能薄膜材料,锂电池隔膜、电容薄膜、偏光膜、透气膜等核心产品突破关键技术“卡脖子”难题,具有行业引领性。  公司坚定走高质量发展之路,推进产业与科技的融合聚变。依托“国家企业技术中心”,佛塑科技搭建了国家博士后工作站、广东省塑料工程技术研究开发中心等17个国家级和省级以上技术创新平台,是全国塑料制品标准化技术委员会SC1委员,具备深厚的行业背景和技术沉淀。  未来,佛塑科技将紧紧围绕高质量发展主题,坚持制造业当家,加快形成新质生产力,主动融入新发展格局,打造国有企业原创技术策源地,以数字化转型推动高端化、智能化、绿色化发展,向新向绿向未来,成为高分子功能薄膜和复合材料产业的领军企业。
