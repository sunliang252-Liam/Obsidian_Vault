## 因果逻辑链
- **[风电装机高景气 + 海外市场突破]** -> [风电叶片用材料收入增长11.70%]: 国内2025年新增风电装机119.33GW（+50.33%），叠加公司对维斯塔斯、恩德等国际巨头供货份额扩大，海外销量同比暴增102.18%，拉动该板块营收至27.70亿元。
- **[产品结构优化，高毛利业务占比提升]** -> [净利润增速（+30.88%）远超营收增速（+7.95%）]: 新型复合材料用树脂（+34.47%）及海外风电材料等高毛利业务放量，叠加非经常性损益（政府补助、资产处置收益等）增厚利润，综合毛利率提升1.84个百分点。
- **[IPO募资 + 偿还贷款]** -> [净资产暴增44.54%，资产负债率大幅下降]: 2025年10月上市募资，叠加留存收益积累，净资产增至26.04亿元；募集资金偿还银行贷款，显著优化资本结构，降低未来财务费用。
- **[碳纤维上浆剂技术突破 + 低空经济卡位]** -> [新型复合材料用树脂成为中长期增长极]: 打通“上浆剂+树脂”材料闭环，产品已量产并形成收入；芳纶上浆剂进入下游测试，切入eVTOL等低空经济赛道，该板块营收同比增长34.47%。
- **[新能源汽车渗透率突破50% + 800V高压快充普及]** -> [车规级胶粘剂跨越验证期，进入放量阶段]: 聚氨酯、有机硅等产品在零跑、丰田、欣旺达等核心客户处量产，并与小米、宁德时代等深度合作，该板块营收同比增长9.37%，成为“第二引擎”。
- **[原材料价格波动 + 直接材料成本占比90%]** -> [毛利率对上游价格高度敏感]: 公司成本结构中直接材料占比超90%，环氧树脂、固化剂等价格受原油及供需影响，若无法有效传导，将直接挤压利润空间。
- **[客户高度集中 + 风电行业周期性强]** -> [经营业绩对核心客户依赖度较高]: 前五大客户销售额占比达76.89%，且风电行业存在季节性波动（Q1为淡季，Q4为旺季），客户采购波动或政策调整将显著影响公司营收稳定性。

## 风险警告
**核心风险在于“增收不增现”与客户集中度双高。** 2025年净利润大增30.88%，但经营性现金流净额同比暴跌79.02%至仅0.84亿元，主要系购买商品支付现金大幅增加。同时，应收账款账面价值高达10.93亿元，占营收比重超31%，若下游客户（尤其是高度集中的前五大客户）付款周期延长或出现坏账，将严重冲击公司资金链与盈利质量。

**成长性业务的兑现存在不确定性。** 公司寄予厚望的新型复合材料用树脂（碳纤维上浆剂、低空经济）和高性能电工绝缘材料目前体量尚小（合计营收占比不足15%），且电工绝缘材料面临亨斯迈、西湖化学等国际巨头垄断，国产替代验证周期极长。若新业务放量不及预期，公司将过度依赖风电单一赛道，在行业竞争加剧或装机增速放缓时面临业绩波动风险。
