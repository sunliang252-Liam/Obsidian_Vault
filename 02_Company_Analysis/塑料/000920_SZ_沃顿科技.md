# 000920.SZ 深度透视

## 因果逻辑链
- **[国产替代加速与海外市场扩张]** -> [膜产品收入增长23.38%]: 公司紧抓关键膜材料国产替代机遇，同时海外市场存量替换需求增加，推动膜产品销售收入大幅增长。
- **[“大批量、低成本”经营战略]** -> [膜产品毛利率稳定在40.82%]: 通过规模化生产和工艺优化，有效对冲了原材料价格波动和行业竞争带来的成本压力，维持了较高的盈利水平。
- **[膜分离工程与膜材料业务协同]** -> [工程业务收入增长2.81%]: 公司发挥膜材料自主生产与系统集成的一体化优势，在新能源、中水回用等高增长领域拓展标杆项目，实现双向赋能。
- **[植物纤维业务品牌与渠道优势]** -> [植物纤维制品收入增长8.82%]: 大自然作为行业开创者，凭借品牌认知度和近千家门店的渠道网络，在行业承压下仍实现稳健增长。
- **[研发投入持续转化为技术壁垒]** -> [获评国家级专精特新“小巨人”]: 公司累计拥有172件有效专利，主导多项国家标准制定，技术领先优势巩固了其在高端膜市场的竞争地位。
- **[家用膜市场竞争白热化]** -> [膜产品销量下降3.96%]: 尽管收入增长，但中低端家用膜市场同质化竞争激烈，导致产品销量出现下滑，增长主要依赖价格和产品结构升级。
- **[海外业务高增长]** -> [国外收入增长42.39%]: 公司加大海外渠道开拓和品牌推广，海外市场成为核心增长引擎，但毛利率同比下降5.09%，显示海外竞争同样激烈。

## 风险警告
**核心风险在于行业竞争加剧与应收账款坏账风险。** 膜行业参与者持续增多，中低端市场陷入价格战，公司膜产品销量已出现下滑，若无法持续向高附加值领域升级，毛利率将面临侵蚀。同时，膜分离工程业务周期长、回款慢，报告期内信用减值损失高达2473万元，同比大幅增长，若下游客户出现经营困难，坏账风险将直接冲击利润。

**其次，海外业务增长虽快，但地缘政治与汇率波动风险不容忽视。** 公司海外收入占比已提升至19.67%，但毛利率同比下降5.09%，且面临贸易壁垒和汇率波动的双重压力。此外，公司研发人员数量同比减少12.55%，在技术密集型行业，核心人才流失可能削弱长期竞争力。
