# 301591.SZ 深度透视

## 因果逻辑链
- **[密封件及组配件业务增长]** -> [营收增长4.63%]: 密封件作为核心产品收入同比增长11.64%，贡献了过半营收，是公司增长的主要引擎。
- **[耐腐蚀管件业务爆发]** -> [营收增长41.92%]: 受益于医疗器械（内镜诊疗耗材）等新领域拓展，耐腐蚀管件成为增长最快的业务板块。
- **[四氟膜业务下滑]** -> [营收下降13.95%]: 受通信设备、新能源等下游需求波动影响，四氟膜业务出现明显收缩，拖累整体增速。
- **[原材料成本上升]** -> [毛利率承压]: PTFE、PEEK等主要原材料采购价格上涨，导致主营业务成本增速（5.26%）高于营收增速（4.63%），综合毛利率微降0.23个百分点。
- **[股权转让剥离造粒料业务]** -> [净利润下降8.41%]: 2025年8月转让子公司南京润特，剥离低毛利造粒料业务，但产生非经常性损益，叠加费用刚性增长，导致归母净利润同比下降。
- **[境外业务高增长]** -> [境外收入增长24.53%]: 境外销售毛利率高达52.11%，远高于境内，境外业务的高增长有效对冲了国内市场的部分压力。
- **[研发投入持续增加]** -> [技术壁垒加固]: 研发费用同比增长7.91%，聚焦氟树脂紧衬、核电防护材料等前沿领域，巩固了公司在高端密封件、耐腐蚀管件领域的技术护城河。

## 风险警告
**核心风险在于“增收不增利”与业务结构失衡。** 公司营收增长4.63%，但净利润却下滑8.41%，主要源于原材料成本上涨、费用刚性增长以及低毛利业务（四氟膜）的拖累。同时，公司过度依赖单一产品（密封件及组配件占比54.84%），而高增长业务（耐腐蚀管件）体量尚小，四氟膜业务又面临下滑，业务结构脆弱，抗周期波动能力不足。

**应收账款回收与宏观环境是两大外部风险。** 随着业务扩张，应收账款余额持续增长，且部分客户已启动司法追偿程序，坏账风险不容忽视。此外，公司业务与宏观经济周期高度相关，若下游流体控制、通信设备、汽车等领域需求恢复不及预期，或国际贸易摩擦加剧，将直接冲击公司经营业绩。
