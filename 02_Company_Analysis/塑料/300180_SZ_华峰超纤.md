# 300180.SZ 深度透视

## 因果逻辑链
- **[下游需求放缓与主动调整销售策略]** -> [营收同比下降12.73%]: 宏观经济环境导致下游客户需求放缓、订单结构变化，公司主动调整销售策略，导致主营业务收入下降。
- **[聚焦高毛利产品，优化产品结构]** -> [绒面材料与合成革收入占比提升至62%]: 公司主动收缩低毛利超细纤维底坯业务，深耕高利润的绒面材料与合成革，实现产品结构优化。
- **[高固定成本与产能利用率不足]** -> [利润承压]: 2020年大二期扩产后，折旧等固定成本高昂，叠加市场需求增速放缓，导致公司业绩表现承压。
- **[威富通业务量下滑与研发收缩]** -> [服务业收入下降27%，研发人员减少31.89%]: 消费市场低迷导致移动支付分润业务量下降，威富通主动收缩非核心业务线研发投入以“降本增效”。
- **[非经常性损益支撑利润]** -> [扣非净利润仅1125万元，同比下降61.64%]: 归母净利润6677万元中，非经常性损益（政府补助、联营企业投资收益等）高达5551万元，核心主业盈利能力薄弱。
- **[资产减值侵蚀利润]** -> [计提资产减值损失1.05亿元]: 报告期内计提存货跌价损失6161万元、商誉减值3862万元，是导致营业利润与净利润差距巨大的主要原因。
- **[汽车业务与外贸业务增长]** -> [汽车业务销量同比增长约20%]: 公司在高端汽车内饰领域取得突破，外贸业务在3C、奢侈品包装及海外汽车市场取得积极进展，成为结构性亮点。

## 风险警告
**核心风险在于主业盈利能力薄弱且高度依赖非经常性损益。** 公司扣非净利润仅1125万元，同比大幅下降61.64%，而利润主要依靠政府补助、联营企业投资收益等非经常性项目支撑。一旦这些外部收益减少，公司将面临实质性亏损风险。同时，高达1.05亿元的资产减值损失（存货+商誉）持续侵蚀利润，反映出下游需求疲软与前期并购整合效果不佳的双重压力。

**威富通业务的持续萎缩与商誉减值风险不容忽视。** 作为公司重要转型方向的数字银行解决方案业务，2025年收入同比下降27%，研发人员大幅缩减31.89%。尽管公司已计提商誉减值，但剩余商誉账面价值仍高达11.8亿元，若未来业务持续恶化，将面临进一步减值风险，对资产负债表和利润表造成重大冲击。此外，公司董事长因短线交易被监管处罚，暴露出内部治理的薄弱环节。
