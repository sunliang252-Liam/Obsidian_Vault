# 300243.SZ 深度透视

## 因果逻辑链
- **[原材料价格下行]** -> [营收下降但毛利率稳定]: 主要石化原料价格全年下降，公司产品售价随之下调，导致营收同比-1.59%；但公司灵活的定价机制有效传导成本压力，PVC助剂毛利率仅微降0.12%。
- **[工程塑料助剂放量]** -> [利润增长核心引擎]: 工程塑料助剂营收同比+37.75%，毛利率高达25.79%，显著高于PVC助剂，成为公司利润增长的主要驱动力，推动归母净利润同比+37.40%。
- **[经营现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额从-2320万大幅转正至1.33亿（+673%），主要系公司加强采购付款管理，购买商品支付的现金减少，缓解了资金压力。
- **[PVC助剂“量增价跌”]** -> [巩固龙头地位但盈利承压]: PVC助剂销量同比+7.57%，但营收同比-4.00%，呈现“以价换量”特征，行业竞争加剧导致产品售价下降，毛利率承压。
- **[PBAT装置转产PETG]** -> [化解资产闲置风险]: 年产6万吨PBAT项目因“禁塑”政策不及预期而闲置，公司正将其技改为可生产PETG/PCTG，旨在盘活资产，避免计提大额减值。
- **[可转债利息与折旧高企]** -> [侵蚀当期利润]: PBAT项目转固后新增折旧及可转债利息摊销，导致财务费用同比+22.98%，是公司净利润率偏低（约1.5%）的重要原因。
- **[新产品布局尚处早期]** -> [短期业绩贡献有限]: 黑磷、电池粘结剂、合成生物材料等新业务均处于中试、客户导入或小批量销售阶段，短期内无法对业绩产生实质性影响，但为长期增长储备动能。

## 风险警告
**核心风险在于PBAT/PETG项目的资产减值与盈利不确定性。** 公司6万吨PBAT装置因市场需求不足已停产，目前正进行转产PETG的技改。若技改失败或转产后市场开拓不及预期，该笔巨额固定资产将面临减值风险，叠加可转债利息摊销，将持续侵蚀公司利润。这是公司当前最大的财务“灰犀牛”。

**其次，PVC助剂主业面临“增收不增利”的竞争困局。** 尽管公司通过“以价换量”维持了销量增长，但行业竞争加剧导致产品价格承压，毛利率空间被压缩。若原材料价格反弹而产品售价无法同步传导，将直接冲击公司盈利基本盘。此外，应收账款规模随业务扩张而增长，若下游客户经营恶化，坏账风险不容忽视。

> 山东瑞丰高分子材料股份有限公司创建于1994年,是国家级高新技术企业、国家级单项冠军示范企业,总部位于山东省淄博市沂源县,注册商标为“鲁山”。公司于2011年7月在深圳证券交易所创业板上市,股票代码:300243。公司属于化学原料和化学制品制造业,主要从事PVC助剂、工程塑料助剂等的研发、生产和销售。PVC助剂产品有ACR加工助剂和抗冲改性剂、MBS抗冲改性剂、MC抗冲改性剂(CPE改性),现有综合产能近20万吨,居行业领先地位,产品广泛应用于PVC管材型材、地板墙板、片材、薄膜、发泡板等下游产品的加工和改性。工程塑料助剂主要有PC/ABS增韧改性剂、ABS高胶粉、ASA高胶粉,下游主要应用于家电、电子电器、汽车、机械、建材等领域。公司下设研发中心,为博士后科研工作站、山东省认定企业技术中心、山东省PVC助剂工程技术研究中心,公司产品具有完全自主知识产权。公司注重品牌建设,注册“鲁山”商标是中国驰名商标,通过GB/T19001-2016/ISO9001:2015质量管理体系认证,产品质量稳定,技术服务水平高,可以根据客户不同需求提供不同配方,在客户中建立了较高的满意度、信任度,拥有国内客户近3000家,产品出口欧美、南亚、东南亚、东亚等60多个国家和地区。未来公司将继续夯实塑料助剂行业的龙头地位,大力发展可降解材料,同时继续研发其他化学新材料品类,致力于成为化学新材料领域知名的生产服务商。
