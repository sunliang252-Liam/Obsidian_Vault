# 601208.SH 深度透视

## 因果逻辑链
- **[AI算力与服务器需求爆发]** -> [电子材料营收+45.23%]: 高速电子树脂（双马、活性酯、碳氢、聚苯醚）深度嵌入英伟达、华为等AI服务器供应链，受益于全球AI服务器出货量+24.5%。
- **[特高压与新能源车结构性需求]** -> [电工聚丙烯薄膜量价齐升]: 特高压电网投资+25.7%、新能源车渗透率逼近48%，拉动超薄型电子聚丙烯薄膜及绝缘结构件需求。
- **[新建产能集中释放]** -> [光学膜材料营收+26.11%]: 年产2.5万吨偏光片基膜、2万吨MLCC基膜项目于2025年转固，叠加汽车装饰等新兴领域拓展，实现扭亏为盈。
- **[原材料价格下行]** -> [毛利率+1.55pct]: 主要原料聚酯切片、PTA采购价同比-14%，成本降幅（+13.5%）低于收入增幅（+15.91%），毛利同比+30.8%。
- **[高附加值产品结构优化]** -> [扣非净利润+86.56%]: 电子材料毛利率提升5.91pct至20.07%，高速电子材料营收翻倍（+125%），驱动盈利能力大幅改善。
- **[研发投入资本化率为零]** -> [短期利润承压但长期壁垒加固]: 全年研发费用1.82亿元全部费用化，聚焦低轨卫星碳氢树脂、算力服务器材料等前沿领域，为未来增长蓄力。

## 风险警告
**核心风险在于产能消化与盈利兑现的不确定性。** 2025年末光学膜材料库存同比激增86.74%，新能源材料库存亦增46.9%，显示下游需求复苏节奏偏缓。公司2026年营收目标60亿元（+15.8%），但Q4单季扣非净利润已转负（-62.6万元），若新增产能无法快速达产增效，固定资产折旧与人工成本将严重侵蚀利润。

**财务健康度隐忧不容忽视。** 经营活动现金流净额仅0.8亿元，同比-11.89%，远低于2.85亿元净利润，利润含金量低。同时，对亏损子公司山东艾蒙特提供4.76亿元借款（年化LPR+15%），若其经营持续恶化，存在坏账风险。此外，可转债已赎回，长期借款同比+39.75%，财务费用攀升至1.06亿元，偿债压力加大。
