# 002768.SZ 深度透视

## 因果逻辑链
- **[纵向一体化产业平台]** -> [毛利率提升]: 向上游延伸至苯乙烯、环氧丙烷等原料，降低采购成本，化工新材料整体毛利率同比提升2.24个百分点。
- **[绿色石化新材料放量]** -> [营收增长]: 苯乙烯联产环氧丙烷、聚苯乙烯等产能释放，该板块营收同比增长36.72%，成为最大增量来源。
- **[新能源复合材料突破]** -> [高增长]: HP-RTM巧克力超薄电池包获宁德时代、比亚迪批量供货，带动复合材料营收增长23.36%。
- **[控股东宝生物]** -> [业绩拖累]: 明胶行业阶段性波动，东宝生物净利润亏损3111万元，拖累整体盈利。
- **[扣非净利润高增]** -> [主业质量提升]: 扣非净利润同比增长55.15%，远高于营收增速，表明非经常性损益影响减弱，主业盈利能力实质性改善。
- **[研发投入持续加大]** -> [技术壁垒构建]: 研发费用6.85亿元，同比增长15.93%，聚焦PEEK、航空级PMMA、PHB可降解材料等，为未来增长储备动能。
- **[H股成功上市]** -> [资本平台升级]: 2026年2月实现“A+A+H”上市，拓宽国际融资渠道，为全球化产能扩张提供资金支持。

## 风险警告
**核心风险在于生物医疗板块的持续亏损与巨额在建工程的产能消化压力。** 子公司东宝生物因明胶市场阶段性调整，2025年净利润亏损3111万元，其库存量同比大增51%，显示销售策略趋于保守，若市场持续低迷，可能进一步拖累集团整体业绩。同时，公司在建工程高达21.67亿元，涉及108万吨绿色石化及新材料产能，项目进度多在78%-90%之间，但“100万吨/年聚苯乙烯项目”已累计亏损1.27亿元，巨额资本开支带来的折旧与财务费用压力不容忽视。

**另一重大风险是原材料价格波动与高负债运营的叠加效应。** 公司主要原材料PS、ABS、苯乙烯等均为石化产品，价格与原油高度联动，报告期内财务费用因贷款利息增加同比飙升46.45%。在营收超200亿的体量下，原材料价格每波动1%都将对利润产生巨大影响，而高企的长期借款（25.3亿元）和短期借款（16.1亿元）使得公司对利率和原料价格的双重波动极为敏感，一旦上游成本快速上涨而下游价格传导不畅，盈利将面临显著挤压。
