# 301003.SZ 深度透视

## 因果逻辑链
- **[核心客户（电动工具）需求疲软]** -> [营收与利润双降]: 第一大下游电动工具行业收入同比下滑23.64%，直接拖累公司整体营收下降15.31%，净利润下降27.66%。
- **[原材料PA6价格大幅下跌]** -> [成本下降但未能对冲量价压力]: 主要原料PA6年均采购价同比下跌约27%，虽降低了生产成本，但下游需求不振导致销量下降12.12%，最终利润降幅远超营收。
- **[外销收入大幅萎缩]** -> [业绩波动加剧]: 外销收入同比减少24.90%，占总营收比重从58.08%降至51.50%，北美市场收入更是暴跌39.34%，显示对海外单一市场依赖的风险。
- **[汽车行业收入逆势增长]** -> [结构性亮点]: 汽车行业收入同比增长30.96%，成为唯一正增长的主要下游，显示公司在新能源汽车轻量化等领域的布局初见成效。
- **[高分红政策]** -> [净资产减少]: 2024年度及2025年中期合计派发现金红利约1.75亿元，远超当年净利润，导致净资产同比下降6.07%。
- **[研发投入持续增加]** -> [技术壁垒构建]: 研发费用同比增长12.52%，聚焦“以塑代钢”、PCR再生材料等高端领域，旨在提升产品附加值，应对同质化竞争。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营性现金流净额同比增长41.59%，主要得益于应收账款回收及采购支出减少，表明公司在收入下滑期仍保持了良好的现金管理能力。

## 风险警告
**核心风险在于对单一核心客户和海外市场的过度依赖。** 公司前五大客户销售额占比高达59.01%，其中第一大客户贡献了33.93%的营收。同时，外销收入占比超过50%，北美市场收入在2025年暴跌39.34%。这种“大客户+高外销”的结构，使得公司业绩极易受到下游行业周期（如电动工具去库存）和国际贸易政策（如关税、汇率）的剧烈冲击，抗风险能力存在显著短板。

**成长性面临瓶颈，产能扩张与需求放缓的矛盾凸显。** 公司当前产能利用率仅为44.61%，而规划中尚有3万吨在建产能（预计2027年投产）。在主营业务收入已连续两年下滑的背景下，新增产能能否被市场有效消化存在巨大不确定性。若下游需求持续疲软，大规模资本开支将转化为沉重的折旧压力，进一步侵蚀本已承压的盈利能力。

**公司简介（F10 原文）**

> 江苏博云塑业股份有限公司(江苏博云,股票代码:301003)成立于2006年6月,是一家专注于技术领先的高性能材料研发、生产和销售的高新技术企业,总部位于中国江苏省苏州市张家港市。作为深圳证券交易所创业板的上市公司,江苏博云以向客户提供新材料的整体解决方案为目标,致力于在目标的细分领域深耕,满足客户需求,为客户创造价值。公司凭借深厚的技术积累和持续创新能力,已经掌握了改性塑料领域的核心技术,建立起一套完整的技术体系。江苏博云拥有国家CNAS认证实验室,并且技术中心被授予为江苏省苏州市市级技术中心。此外,公司与南京工业大学联合设立了高分子材料技术研究中心,建立了江苏省研究生工作站,同时与国内顶尖学府如中国科技大学、杭州师范大学、郑州大学、天津大学等建立了产学研联合开发关系,确保其在高分子加工领域教育与科研的最前沿保持密切沟通与协作。公司自2010年起连续被评为江苏省高新技术企业,并于2022年12月被评定为江苏省专精特新中小企业。江苏博云的产品涵盖了高性能改性尼龙、改性特种工程塑料、高性能改性聚酯、工程化聚烯烃及色母粒和功能性母粒等,广泛应用于电动工具、汽车零部件、家用电器、电子电气、家居制品、医疗器械、轨道交通(高铁)等多个行业领域。公司秉持“客户第一,成果导向”的核心价值观,已在国内改性塑料行业中建立起独特的竞争优势和品牌影响力,成为国内外众多知名企业的重要供应商。展望未来,江苏博云将持续在“聚焦客户的压力和挑战,通过材料科技的进步与创新,帮助客户取得更大的成功”的使命指引下,致力于实现“成为世界级工业客户的首选材料供应商”的愿景。在持续创新与研发的征途中,江苏博云将不断为客户创造价值,为行业发展注入活力,为实现美好的发展前景而努力。
