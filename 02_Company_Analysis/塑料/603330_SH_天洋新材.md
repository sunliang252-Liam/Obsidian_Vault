# 603330.SH 深度透视

## 因果逻辑链
- **[光伏行业产能过剩、低价竞争]** -> [公司停止光伏封装胶膜业务]: 光伏胶膜毛利率为负，持续亏损，公司为提升利润水平，主动收缩并最终停止该业务。
- **[停止光伏业务]** -> [营业收入大幅下降34.74%]: 光伏胶膜收入占主营业务收入比从49%降至23%，直接导致整体营收规模缩减。
- **[停止光伏业务及墙布业务]** -> [计提大额资产减值损失2.26亿元]: 公司基于审慎原则，对光伏和墙布业务相关长期资产进行减值测试，导致净利润大幅减少。
- **[热熔胶业务主动调整产品结构]** -> [热熔胶毛利率提升3.88个百分点]: 减少低毛利产品销售，聚焦高差异化、高毛利产品及高价值客户，实现盈利能力提升。
- **[电子胶业务成功开拓新领域]** -> [电子胶营收同比增长8.64%]: 成功进入半导体、汽车电子、储能导热三大新领域，实现规模化量产，驱动业务稳健增长。
- **[控股股东变更]** -> [公司战略重心回归胶黏剂主业]: 新控股股东百瑞兴阳入主，推动公司停止亏损的光伏业务，集中资源发展热熔胶和电子胶核心业务。
- **[墙布业务受房地产市场影响]** -> [墙布营收同比下降14.81%]: 新房交付量持续萎缩，家居建材行业整体需求缩减，导致墙布产品缺乏需求支撑。

## 风险警告
公司最大风险在于战略转型的阵痛与不确定性。2025年公司主动停止光伏胶膜业务，导致营收骤降34.74%，并计提了2.26亿元的巨额资产减值损失，连续第三年录得大额亏损。虽然此举意在“止血”，但公司能否成功将资源聚焦于热熔胶和电子胶两大核心业务，并实现盈利能力的根本性修复，尚需时间验证。新控股股东入主后的战略协同效果也存在不确定性。

其次，公司财务状况持续恶化。截至2025年末，母公司未分配利润为-4.35亿元，累计亏损严重，已不具备分红条件。同时，公司有息负债规模依然较大，短期借款和长期借款合计超3.6亿元，而货币资金已降至2.47亿元，偿债压力不容忽视。若核心业务增长不及预期，公司可能面临流动性风险。
