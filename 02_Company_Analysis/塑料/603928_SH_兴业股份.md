# 603928.SH 深度透视

## 因果逻辑链
- **[成本管控与产品结构优化]** -> [净利润暴增150.6%]: 营业成本增速(3.07%)远低于收入增速(7.49%)，叠加高毛利产品（合成树脂、涂料）占比提升，推动毛利率同比提升3.63个百分点。
- **[球形酚醛树脂产业化]** -> [新能源材料赛道突破]: 球形酚醛树脂作为CVD硅碳负极多孔碳前驱体，已实现批量供货，进入头部3C及动力电芯供应链，成为新利润增长点。
- **[出口收入增长37.64%]** -> [海外市场拓展见效]: 渗透欧洲、东南亚、澳洲、南美市场，海外业务毛利率高达38.57%，显著高于国内，有效对冲国内低端竞争压力。
- **[原材料价格波动与成本控制]** -> [盈利能力改善]: 主要原料苯酚、MDI、甲醇价格同比下降，叠加公司降本增效措施，使合成树脂单位成本下降2.02%，而售价调整幅度更小。
- **[应收账款周转效率提升]** -> [资产运营风险可控]: 应收账款周转率从2.60提升至2.73，回款质量改善，尽管余额仍较大（占流动资产45.8%），但坏账风险边际下降。
- **[泰兴项目受阻]** -> [战略扩张不确定性]: 因地块被划入“长江岸线一公里范围”，30亿投资计划面临选址调整或变更，短期资本开支压力缓解，但长期产能扩张路径受阻。

## 风险警告
**核心风险在于泰兴30亿投资项目的不确定性。** 该地块因环保新规被划入“长江岸线一公里范围”，项目面临选址调整甚至终止的可能。这不仅意味着前期投入可能沉没，更直接制约了公司未来产能扩张和战略落地，是压制估值的关键变量。

**经营层面，现金流与利润严重背离。** 2025年净利润暴增150%，但经营性现金流净额却同比大幅下降62.39%，主因是收到的票据增加。这暗示利润增长的“含金量”不足，大量利润沉淀在应收票据中，而非真金白银。若下游客户信用环境恶化，票据兑付风险将直接冲击公司流动性。
