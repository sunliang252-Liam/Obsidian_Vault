# 002127.SZ 深度透视

## 因果逻辑链
- **[子公司时间互联业务战略调整及行业广告主预算下滑]** -> [营业收入同比下降22.59%]: 移动互联网媒体投放平台业务收入缩减，是公司整体营收下降的核心拖累。
- **[公司主动进行品牌授权业务结构调整与优化]** -> [品牌综合服务业务收入同比下降39.20%]: 公司主动收缩低效授权，聚焦核心品类与优质客户，导致短期收入承压。
- **[计提商誉减值3.26亿元]** -> [归属于上市公司股东的净利润亏损2.82亿元]: 子公司时间互联盈利能力未达预期，触发商誉减值，是当期亏损的直接原因。
- **[“卡帝乐鳄鱼”品牌受诉讼影响]** -> [品牌授权服务收入下滑]: 法律纠纷导致品牌价值受损，授权业务拓展受阻，进一步拖累本部业绩。
- **[南极人自营转型“超级南极人”，聚焦线下]** -> [货品销售收入同比下降62.00%]: 线下自营门店尚处模式探索与调整期，未能形成有效收入替代。
- **[优化营销资源配置，强化KPI管理]** -> [销售费用同比大幅下降67.81%]: 公司主动削减低效线上推广投入，实现降本增效。
- **[时间互联积极开拓苹果Ads等渠道]** -> [部分抵减传统业务收入减少]: 新渠道业务增长，对冲了部分因传统媒体广告规模下滑带来的负面影响。
- **[资产负债率14.05%，资金余额充沛]** -> [经营现金流正向]: 公司财务结构稳健，为业务转型与探索提供了安全垫。

## 风险警告
**核心风险在于商誉减值与品牌诉讼的持续冲击。** 子公司时间互联计提3.26亿元商誉减值后，商誉账面价值已归零，但若其核心的移动互联网营销业务在行业竞争加剧、头部客户预算持续下滑的背景下无法实现有效复苏，未来仍面临盈利能力持续恶化的风险。同时，“卡帝乐鳄鱼”等品牌的商标侵权诉讼尚未完结，已计提预计负债775万元，若败诉或赔偿金额扩大，将进一步侵蚀品牌价值与公司利润。

**业务转型存在高度不确定性。** 公司正从轻资产的品牌授权模式向“品牌服务+自营零售”双轮驱动转型，但自营业务（“超级南极人”线下门店）尚处探索期，收入贡献有限且持续下滑。品牌授权业务的结构性调整也导致短期收入与利润承压。若新业务模式无法快速跑通并形成第二增长曲线，公司将面临传统业务萎缩、新业务青黄不接的困境，业绩复苏将缺乏明确支撑。
