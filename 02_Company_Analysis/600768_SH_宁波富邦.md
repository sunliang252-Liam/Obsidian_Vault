# 600768.SH 深度透视

## 因果逻辑链
- **[出售中华纸业股权]** -> [净利润暴增3649%]: 以3.7亿元出售参股公司2.5%股权，确认公允价值变动收益5390万元，贡献归母净利润大头。
- **[银价大幅上涨]** -> [电工合金盈利提升]: 白银作为核心原材料，价格上涨周期内产品存货增值，叠加“原材料+加工费”定价模式，推动子公司营收增26%、净利增38%。
- **[剥离铝型材低效资产]** -> [资产结构优化]: 将盈利能力弱、设备老化的铝型材业务转让给关联方，消除亏损源，聚焦电接触主业。
- **[收购电工合金并整合]** -> [核心利润增长点确立]: 2024年完成对电工合金55%股权收购，2025年实现管理融合与业务协同，成为公司唯一稳健盈利的制造主业。
- **[贸易业务毛利率极低]** -> [整体盈利质量差]: 铝铸棒贸易收入2.49亿，毛利率仅0.73%，对利润贡献微乎其微，且依赖单一供应商（洛阳万基）。
- **[经营活动现金流大幅为负]** -> [盈利质量存疑]: 归母净利润5859万，但经营现金流为-1.12亿，主因购买原材料支付现金增加，显示利润主要来自非经常性收益而非主业造血。
- **[供应商高度集中]** -> [经营风险积聚]: 前五名供应商采购额占总额92.52%，其中单一供应商上海瑜鸿占比58.67%，议价能力弱且供应链风险高。

## 风险警告
**核心风险：盈利高度依赖非经常性损益，主业造血能力薄弱。** 2025年归母净利润5859万元中，扣非净利润仅770万元，占比13%。利润暴增完全由出售中华纸业股权的一次性收益驱动，而非核心业务改善。剔除该收益后，公司实际盈利能力极弱，且经营现金流为-1.12亿元，显示主业经营入不敷出。

**供应链与业务结构风险突出。** 贸易业务毛利率不足1%，且前五名供应商采购占比超92%，单一供应商依赖度近60%，议价权缺失且易受上游价格波动冲击。同时，公司仍面临历史遗留的股东损害债权人利益诉讼，虽一审胜诉但原告再次起诉，潜在赔偿风险未完全消除。
