# 000759.SZ 深度透视

## 因果逻辑链
- **[大规模闭店止损]** -> [营收锐减20.21%]: 全年关闭414家门店（含30家大卖场），直接导致超市业务收入同比下降18.99%，营收从103.8亿骤降至82.8亿。
- **[闭店产生巨额一次性损失]** -> [净利润暴跌至-9.57亿]: 关闭门店导致的资产报废、违约赔偿等营业外支出高达2.02亿元，叠加存货跌价损失0.18亿，是亏损扩大的主因。
- **[信用减值损失激增]** -> [侵蚀利润1.25亿]: 因应收款项信用风险恶化，计提信用减值损失1.25亿元，同比暴增837%，反映出供应链上下游资金链紧张。
- **[核心子公司巨亏]** -> [集团整体亏损]: 中百仓储超市净亏损7.45亿元，中百物流净亏损1.75亿元，两大核心业务板块严重拖累集团业绩。
- **[硬折扣与便利店转型]** -> [结构性增长]: 试点“小百惠”硬折扣店，便利店加盟服务收入10.66亿元，自有品牌在便利店销售同比增长26.72%，成为少数亮点。
- **[现金流大幅萎缩]** -> [经营承压]: 经营活动现金流净额同比下降76.42%至1.3亿元，营收下降导致销售回款减少，公司资金链趋于紧张。
- **[净资产腰斩]** -> [财务风险加剧]: 归属于上市公司股东的净资产从17.88亿骤降至8.21亿，降幅54.07%，资产负债率攀升至89.84%。

## 风险警告
**核心风险在于传统大卖场业态的加速衰退与转型阵痛。** 公司营收连续三年下滑，2025年净亏损9.57亿创历史新高，核心子公司中百仓储超市净亏损7.45亿，是亏损的绝对主力。尽管公司试图通过关闭414家门店（含30家大卖场）止血，但闭店带来的资产报废、违约赔偿等一次性损失高达2.02亿元，叠加存货跌价损失，短期内严重侵蚀利润。净资产已从17.88亿腰斩至8.21亿，资产负债率逼近90%，财务安全垫极为薄弱。

**转型方向尚不明朗，新业务难以填补传统业务下滑的缺口。** 公司押注硬折扣店、便利店和线上平台，但便利店加盟收入仅10.66亿，线上销售17.8亿，体量远不足以对冲大卖场萎缩带来的损失。同时，信用减值损失激增至1.25亿，反映出供应链上下游资金链紧张，可能进一步影响供应商合作与商品供给。公司已连续三年亏损且未分红，若无法在2026年实现减亏扭亏，持续经营能力将面临严峻挑战。
