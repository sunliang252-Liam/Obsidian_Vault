# 600094.SH 深度透视

## 因果逻辑链
- **[前期充分计提资产减值]** -> [2025年扭亏为盈]: 2024年大额亏损主因计提存货减值21.6亿元，2025年减值损失大幅收窄至1.3亿元，利润包袱基本出清，实现归母净利润1.43亿元。
- **[金控板块股权投资有序退出]** -> [投资收益增厚当期业绩]: 国融证券相关间接股权投资退出贡献正向投资收益3.39亿元，成为利润修复的重要支撑。
- **[地产板块收缩聚焦现金流]** -> [经营现金流大幅改善]: 连续四年暂停新增土地投资，聚焦去库存与回款，2025年经营活动现金流净额达6.49亿元，同比暴增2804%。
- **[净负债率极低、现金短债比充裕]** -> [财务安全边际行业领先]: 净负债率仅7.28%，现金短债比2.19倍，资产负债率35.08%，为战略转型提供无需依赖外部融资的内源性资金保障。
- **[战略投资佰才邦20.45%股份]** -> [卡位6G空天地一体化赛道]: 投资7.24亿元布局6G通信技术，标的公司为IMT-2030推进组成员，聚焦卫星通信、NTN非地面网络等核心技术。
- **[设立香港名城移动通信]** -> [搭建海外通信业务平台]: 注册资本1亿港币，聚焦“一带一路”沿线4G/5G/6G通信基础设施运营，与佰才邦形成业务协同。
- **[联合设立福建城际低空机场投资公司]** -> [切入低空经济基础设施]: 持股66%，与福州新区航空城等合作，推进“低空城际智慧枢纽机场”建设，与6G、算力形成产业闭环。
- **[三次回购注销股份合计5.3亿元]** -> [提升股东回报与每股价值]: 回购金额占当年净利润的369.48%，注销后总股本减少6.07%，直接增厚每股收益与净资产。

## 风险警告
**业务转型的极高不确定性与执行风险。** 公司从传统房地产开发商向“6G通信+低空经济+算力”科技企业转型，跨度极大。新业务（佰才邦、峰飞航空）尚处早期，2025年对财报无重大影响，且面临技术路线、人才结构、行业周期、牌照获取等多重挑战。实际控制人海外资源能否成功转化为通信运营商资质牌照，是转型成败的关键变量，存在重大不确定性。

**地产主业持续萎缩与资产减值风险。** 公司已连续四年暂停新增土地投资，2025年营收同比骤降46%，可结转项目规模逐年收缩。虽然当前财务结构稳健，但若房地产市场持续低迷，存量物业去化不畅或价格进一步下跌，仍可能面临新的资产减值压力，侵蚀转型所需的现金流基础。控股股东名城控股集团存在大额诉讼（被诉支付12.3亿元），其财务稳定性值得关注。
