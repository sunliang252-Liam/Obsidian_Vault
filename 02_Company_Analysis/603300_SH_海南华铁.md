# 603300.SH 深度透视

## 因果逻辑链
- **[行业租金下行]** -> [净利润下滑12.83%]: 基建投资放缓、行业竞争加剧导致高空作业平台租金价格指数同比下降11.3%，尽管出租率提升1.68个百分点，但毛利率仍下滑2.77个百分点。
- **[建筑支护板块拖累]** -> [整体业绩承压]: 房地产开发投资同比下降17.2%，导致钢支撑、铝模板等建筑支护设备收入下降18.94%，毛利率骤降16.48个百分点，对整体盈利形成显著拖累。
- **[设备规模扩张]** -> [营收增长15.74%]: 设备保有量突破20.78万台（同比+20%），高空作业平台板块收入增长21.96%，以量补价驱动总营收达59.85亿元。
- **[算力业务转型]** -> [第二增长曲线初现]: 算力设备服务收入同比增长1684.94%，交付算力资产超16亿元，但毛利率仅25.88%，且36.9亿元大单已终止，业务可持续性存疑。
- **[国企信用优势]** -> [融资成本优化]: 依托AA+主体信用评级，成功发行多期低利率债券（票面利率2.45%-2.9%），有效拓宽融资渠道并降低债务成本。
- **[数字化运营]** -> [出租率提升]: “擎天系统2.0”实现SaaS化重构，赋能资产调拨与定价决策，推动年度平均台量出租率提升至83.35%，同比提高1.68个百分点。
- **[轻资产模式]** -> [资产规模快速扩张]: 通过引入外部资金合作采购设备，在降低自身资本开支的同时，推动总资产同比增长16.39%至271.23亿元。

## 风险警告
**核心风险在于“增收不增利”的困境与高杠杆运营的脆弱性。** 公司营收增长15.74%，但净利润却下滑12.83%，主因是行业租金价格战侵蚀利润。更关键的是，公司总负债高达204.39亿元，资产负债率75.36%，有息债务182.70亿元，财务费用7.12亿元，高额的利息支出持续吞噬利润。一旦租金价格继续下行或出租率下滑，公司将面临巨大的偿债压力。

**第二增长曲线（算力业务）存在重大不确定性。** 公司曾签署36.9亿元的算力大单，但因市场环境变化已于2025年9月终止，暴露了算力业务从采购、资金到履约的全链条风险。当前算力业务收入仅2.14亿元，毛利率仅25.88%，远低于高空作业平台业务，且面临供应商断供、资金不足等风险。该业务能否成为稳定利润来源，仍需时间验证。

**公司治理与信息披露合规性存在隐患。** 公司因重大合同信息披露不合规，于2025年12月收到证监会《行政处罚事先告知书》，内部控制审计报告也指出其在信息披露方面存在缺陷。这反映出公司在快速扩张过程中，内部控制和合规管理未能同步跟上，可能引发监管处罚和投资者信任危机。
