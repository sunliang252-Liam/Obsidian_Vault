# 002534.SZ 深度透视

## 因果逻辑链
- **[扣非净利润大幅增长78.52%]** -> [盈利能力显著提升]: 公司加强订单质量管控，提升毛利率，同时强化应收账款和存货管理，减少信用及资产减值损失，使扣非净利润从1.44亿跃升至2.56亿。
- **[可转债全部转股或赎回]** -> [净资产大幅增加32.92%]: 报告期内“西子转债”触发强制赎回，累计转股1.01亿股，导致资本公积增加，净资产从42.2亿增至56.1亿，显著优化了资本结构。
- **[杭锅工业锅炉搬迁地块产权移交]** -> [确认大额非经常性收益2.44亿元]: 子公司完成搬迁地块产权移交，确认资产处置收益，这是归母净利润维持4.37亿高位的关键非经常性因素。
- **[海外市场营收增长42.46%]** -> [业务结构优化]: 外销收入占比从9.79%提升至14.39%，表明公司“全员海外”战略见效，有效对冲了国内市场竞争加剧和营收下滑的风险。
- **[解决方案业务营收增长19.31%]** -> [业务模式转型成功]: 公司从单一设备制造商向能源利用整体解决方案供应商转型，高附加值的EPC/解决方案业务成为第一大收入来源（占比46.20%）。
- **[经营活动现金流净额增长34.15%]** -> [运营效率改善]: 通过加强发货前收款和应收账款催收，同时降低库存资金占用，经营性现金流达到7.62亿元，远超净利润，财务质量扎实。
- **[熔盐储能技术商业化落地]** -> [开辟第二增长曲线]: 国能河北龙山火电灵活性改造、绍兴绿电储能等示范项目成功运行，验证了熔盐储能在火电调峰、用户侧储能等场景的商业价值，为未来规模化复制奠定基础。

## 风险警告
**核心风险在于业绩对非经常性损益的严重依赖。** 2025年归母净利润4.37亿中，非经常性损益高达1.80亿（主要为2.44亿的搬迁资产处置收益），扣非净利润仅为2.56亿。剔除这一偶发性收益后，公司实际盈利能力虽有改善，但绝对规模仍显薄弱。未来若无类似资产处置，归母净利润将面临显著下滑压力。

**其次，传统主业余热锅炉收入同比大幅下滑37.21%，** 表明核心业务正面临市场需求萎缩或竞争加剧的挑战。虽然解决方案和海外业务增长弥补了部分缺口，但余热锅炉作为公司基本盘和行业地位的象征，其持续下滑可能动摇公司根基。此外，公司正积极向储能、核电、数据中心等新领域转型，这些业务尚处于投入期或示范阶段，技术迭代风险和商业化不及预期的风险较高，新业务能否接棒成为增长引擎存在较大不确定性。
