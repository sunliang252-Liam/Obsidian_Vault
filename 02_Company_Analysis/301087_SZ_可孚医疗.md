# 301087.SZ 深度透视

## 因果逻辑链
- **[品类聚焦与产品结构优化]** -> [综合毛利率提升1.31个百分点至53.16%]: 公司集中资源打造呼吸机、矫姿带等核心单品，高毛利产品占比提升，驱动盈利质量改善。
- **[自主研发智能网联呼吸机放量]** -> [呼吸支持板块下半年收入同比增长80.18%]: 无棉降噪、低噪23分贝以下的技术突破，叠加线上渠道精准营销，实现快速放量。
- **[海外并购与渠道拓展]** -> [境外收入同比增长405.05%至2.99亿元]: 收购上海华舟、喜曼拿获取欧美及香港渠道资源，叠加跨境电商与展会营销，海外业务成为新增长极。
- **[线上渠道精细化运营]** -> [线上收入同比增长10.37%至21.97亿元]: 深耕天猫、京东等货架电商，并布局直播电商，核心品类销量增长，稳固线上领先地位。
- **[线下渠道深化与即时零售布局]** -> [线下收入同比增长23.94%至10.55亿元]: 深化与头部连锁药房合作，并布局即时零售新业态，满足消费者便捷性需求。
- **[听力业务门店运营体系化]** -> [听力业务收入增长14.38%，利润端大幅减亏]: 建立标准化运营督导机制，推广智能零售管理系统，提升单店效益与客户转化率。
- **[与飞利浦达成战略合作]** -> [布局高端家庭健康监测市场]: 获得飞利浦品牌授权，整合其技术品牌与公司渠道制造优势，切入高端消费医疗领域，提升品牌溢价。

## 风险警告
**并购整合与商誉减值风险**：公司2025年通过收购上海华舟、喜曼拿等公司实现外延扩张，并战略参股融昕医疗。若对标的公司的业务、文化、管理体系整合不达预期，或海外市场拓展受阻，将直接影响公司盈利能力，并存在商誉减值风险，对合并报表利润造成冲击。

**行业竞争加剧与毛利率波动风险**：中国家用医疗器械市场参与者众多，产品同质化严重。公司虽通过品类聚焦提升毛利率，但医疗护理类产品毛利率同比下降5.74个百分点，显示部分品类竞争激烈。若公司不能持续保持产品、渠道、服务优势，或原材料价格波动，可能导致市场份额下降或毛利率进一步承压。
