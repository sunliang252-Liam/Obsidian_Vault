# 600538.SH 深度透视

## 因果逻辑链
- **[商誉减值]** -> [净利润巨亏]: 高盛生物业绩下滑触发商誉减值6,185.54万元，是2025年归母净利润-8,762万元的核心原因。
- **[司法IVD竞争加剧]** -> [高盛生物由盈转亏]: 市场竞争激烈导致营收下降10%、毛利率下降2.71%，高盛生物从上年盈利450万元转为亏损223万元。
- **[制药厂产线停产与渠道清理]** -> [医药制造收入锐减]: 滴眼液生产线停产至6月，叠加销售政策调整，制药厂营收同比下降31.54%，亏损扩大。
- **[实际控制人股份被司法拍卖]** -> [控制权变更风险]: 朱蓉娟、彭韬夫妇持股比例从8.37%降至4.14%，剩余1,784万股将被拍卖，可能导致实际控制人变更。
- **[华大共赢基金投资收益]** -> [非经常性损益支撑]: 公司按比例确认华大共赢一号基金投资收益1,157.37万元，部分抵消了主业亏损。
- **[医药流通精细化运营]** -> [板块逆势增长]: 钦州医药与北海医药通过优化品种、拓展渠道，实现营收增长4.10%，净利润434.79万元，成为稳定基本盘。
- **[北京香雅项目终止]** -> [额外亏损]: 提前终止宿迁影像中心合作协议，导致当期产生亏损373.25万元。

## 风险警告
公司最核心的风险在于**实际控制人变更引发的治理不确定性**。截至报告日，实际控制人朱蓉娟夫妇持股已降至4.14%，且剩余股份仍面临司法拍卖。若拍卖完成，公司可能陷入无实际控制人状态，对战略稳定性和经营连续性构成重大威胁。审计报告已因此出具带有强调事项段的无保留意见。

其次，**商誉减值风险远未出清**。截至2025年末，商誉账面价值仍有7,660万元。高盛生物在司法IVD领域面临日益激烈的市场竞争，2025年已由盈转亏，若2026年业绩继续下滑，将触发新一轮商誉减值，进一步侵蚀本已脆弱的净资产。公司连续三年亏损，母公司未分配利润亏损高达5.1亿元，自身造血能力严重不足。
