# 600130.SH 深度透视

## 因果逻辑链
- **[手机及配件业务增长]** -> [营收增长30.45%]: 公司努力开拓业务及客户需求增加，境内境外手机销售额增长，带动整体营收提升。
- **[车载模组业务放量]** -> [营收增长76%]: 国产汽车市场销量增加，下游客户需求增长，汽车中控产品及两轮车智能仪表实现批量出货。
- **[智能设备业务并表与拓展]** -> [营收增长106.65%]: 2024年底纳入合并范围的重庆子公司贡献稳定收入，同时公司积极开拓网络接入智能设备等新产品。
- **[扣非净利润持续为负]** -> [核心主业盈利能力不足]: 2025年扣非净利润为-747.81万元，虽亏损收窄，但公司主营业务仍无法实现盈利，依赖非经常性损益（理财收益等）维持账面盈利。
- **[研发与销售费用激增]** -> [侵蚀利润]: 研发费用增长46.54%，销售费用增长112.33%，主要系重庆子公司全年并表及公司加大业务开拓所致，成本增长快于收入增长。
- **[经营活动现金流净流出扩大]** -> [营运资金压力增加]: 经营活动现金流净额从-252.88万元恶化至-1,955.13万元，主要因原材料备货增加，导致购买商品支付的现金大幅上升。
- **[理财收益是利润主要来源]** -> [业绩高度依赖金融资产]: 2025年投资收益及公允价值变动收益合计约1,042.85万元，远超归母净利润525.07万元，是公司实现盈利的核心支撑。
- **[退市风险警示与申请撤销]** -> [公司处于关键转折点]: 2024年因营收低于3亿且扣非净利润为负被*ST，2025年财务指标达标并申请撤销，但能否成功取决于交易所审核，不确定性高。

## 风险警告
公司核心风险在于主营业务造血能力严重不足。尽管2025年营收增长30.45%至4.7亿元，成功跨越3亿元退市红线，但扣非净利润已连续多年为负，2025年仍亏损747.81万元。公司账面盈利完全依赖理财收益等非经常性损益，一旦金融市场波动或理财规模缩减，公司将立即陷入亏损。同时，经营活动现金流净流出大幅扩大至-1,955万元，显示营运资金压力正在加剧，业务扩张的可持续性存疑。

更深远的风险在于公司竞争力的持续衰退。管理层坦诚，手机业务原有的研发、生产和质量体系已大幅削弱，新的核心竞争力尚未形成。车载模组和智能设备业务虽增长迅速，但行业竞争激烈，公司研发及拓展能力有限，未来存在诸多不确定性。公司目前更像一个“现金管理平台”而非一个健康的制造企业，其转型能否成功、能否摆脱对理财收益的依赖，是决定长期价值的关键。此外，公司股票能否成功撤销退市风险警示，仍存在不确定性。
