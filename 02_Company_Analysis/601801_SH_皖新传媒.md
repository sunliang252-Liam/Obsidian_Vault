# 601801.SH 深度透视

## 因果逻辑链
- **供应链及物流服务业务收入下降49.32%** -> 总营业收入下降25.56%: 该业务占总收入比例较高，大幅下降直接拖累整体营收。
- **供应链业务主动压降规模** -> 供应链及物流服务业务收入下降: 管理层提及供应链业务减少，系公司主动调整业务结构。
- **一般图书及音像制品收入下降15.01%** -> 总营业成本下降27.46%: 收入下降带动采购成本同步减少。
- **人力成本下降** -> 销售费用下降26.17%: 人力成本是销售费用主要构成，其下降直接压降费用。
- **投资理财支付的现金增加** -> 投资活动现金流量净额大幅下降: 购买理财消耗现金，导致投资活动现金流出大幅增加。
- **利息收入减少** -> 财务费用同比增加（负值减小）: 利息收入减少导致财务费用绝对值下降。
- **高分红与股份回购** -> 股东回报比例达77.71%: 公司通过分红和回购积极回报股东，占比超过净利润四分之三。
- **学龄人口结构性调整风险** -> 未来教育服务业务需求下降压力: 出生率下降将导致中小学生数量拐点，影响教材教辅等业务。

## 风险警告
公司面临多重风险：供应链业务大幅收缩导致营收下滑，一般图书业务受新渠道冲击毛利率下降，学龄人口下降长期压制教育服务需求，AI技术迭代要求持续投入，此外投资活动现金流出巨大需关注资金管理效率。
