# 301022.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升]** -> [营收增长21.61%]: 新车型投放加速，带动模具及塑料件需求，新能源收入占比升至28.02%。
- **[首发募投及泰国二期产能释放]** -> [规模效应显现]: 产能瓶颈缓解，订单落地加速，单位制造成本优化，推动毛利率改善。
- **[“模塑一体化”全产业链布局]** -> [协同降本与客户粘性]: 材料、模具、零部件一站式服务，缩短开发周期，降低综合成本，提升客户依赖度。
- **[外销收入占比提升至66.32%]** -> [整体毛利率提升至21.08%]: 外销毛利率显著高于内销，外销高增长（+32.28%）拉动了综合盈利水平。
- **[可转债全部转股]** -> [财务费用大幅下降132.74%]: 利息支出减少，叠加欧元升值带来的汇兑收益，显著释放利润弹性。
- **[核心客户深度绑定]** -> [订单稳定性强]: 前五大客户占比61.47%，深度配套延锋、佛瑞亚等Tier1，项目生命周期长，收入转化率高。
- **[改性塑料业务放量]** -> [新增长点形成]: 营收同比增长407.34%，安徽基地试生产，未来有望贡献增量利润。
- **[AI+模具设计及模内喷涂技术储备]** -> [长期竞争力提升]: 布局前沿工艺，提升设计效率与差异化优势，为高端市场突破奠定基础。

## 风险警告
**核心风险在于应收账款与现金流的背离。** 2025年净利润暴增234.71%，但经营性现金流净额却同比下滑51.10%，主要系支付采购货款增加。应收账款规模达4.08亿元，占总资产18.62%，且信用减值损失持续计提。若下游客户（尤其是新能源车企）回款周期拉长或出现坏账，将严重侵蚀利润并导致资金链紧张。

**第二重风险来自业务扩张的“增收不增利”陷阱。** 塑料零部件业务收入增长15.10%，但毛利率却同比下滑10.72个百分点，主要因泰国工厂产能爬坡期成本高企。改性塑料业务虽增速惊人，但子公司海泰科新材料仍处于亏损状态（净亏损1090万元）。新业务在规模放量前，将持续拖累整体盈利质量，需警惕过度扩张带来的管理成本和折旧压力。
