# 600621.SH 深度透视

## 因果逻辑链
- **[金融科技赋能交易系统]** -> [经纪业务收入增长22.57%]: 低延时特色交易系统吸引量化私募和专业投资者，客户规模与交易量提升，带动代理买卖证券手续费净收入增长。
- **[市场交投活跃度提升]** -> [信用业务收入增长36.97%]: 2025年A股慢牛行情下，两市成交额攀升，融资融券需求旺盛，期末规模增长驱动利息收入增加。
- **[资管规模扩张与产品创新]** -> [资管业务收入增长39.04%]: 坚持“收益稳、波动低”策略，发行MOM、固收+及数据资产ABS等特色产品，管理费收入随规模扩张而增加。
- **[固收业务多资产多策略布局]** -> [其他业务收入增长30.39%]: 深化“固收+”及跨境债券配置，销售交易体系完善，固定收益类及权益类投资收益同比均增长。
- **[债券承销规模创历史新高]** -> [投行业务收入基本持平]: 城投债“资产荒”下，公司加大承销力度，但IPO强监管环境使股权融资承压，整体收入与去年持平。
- **[期货业务结构优化与扭亏为盈]** -> [期货业务收入增长33.80%]: 孵化互联网金融新引擎，打造FOF资管特色，优化业务结构，实现经营局面根本性改善。
- **[金融科技向多业务领域赋能]** -> [综合竞争力提升]: 自研“鑫i”智能投研平台上线，AI赋能合规风控、财富管理，推动运营效率与客户服务能力提升。

## 风险警告
公司业绩高度依赖市场行情，2025年A股慢牛行情是经纪、信用、自营业务增长的核心驱动力。若未来市场交投活跃度下降或出现趋势性下跌，公司收入与利润将面临显著回落风险。此外，公司资产负债率（扣除代理买卖证券款后）已升至73.25%，且应付债券规模同比大增41.55%，财务杠杆的快速提升加大了利息支出压力与流动性管理难度。

公司作为中小券商，在行业“头部集聚深化、差异化发展提速”的竞争格局下，面临来自头部机构在品牌、资本、人才等方面的全方位挤压。其金融科技特色虽形成差异化优势，但若技术迭代不及预期或竞争对手快速模仿，该优势可能被削弱。同时，公司资管、投行等业务仍处于规模扩张期，若市场环境变化或风控失效，可能导致业务增长不及预期或资产减值损失。
