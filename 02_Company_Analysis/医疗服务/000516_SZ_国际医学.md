# 000516.SZ 深度透视

## 因果逻辑链
- **[DRG/DIP医保支付改革深化]** -> [收入下降]: 按病种付费全面落地，压缩住院天数与费用，导致公司2025年医疗业收入同比下滑16.84%。
- **[两大院区全面投用但床位利用率不足]** -> [持续亏损]: 西安国际医学中心医院（万张床位）仍处爬坡期，2025年净亏损1.97亿元，拖累整体盈利。
- **[门急诊量增长但住院量下降]** -> [收入结构恶化]: 门急诊量增4.96%至270万人次，但高价值住院服务量降4.23%，导致收入增速低于服务量增速。
- **[降本增效与资产优化]** -> [经营现金流改善]: 通过全成本核算、减少资本开支，经营活动现金流净额增至12.76亿元，同比+26.49%。
- **[高额固定资产折旧与财务费用]** -> [利润侵蚀]: 固定资产折旧6.55亿元、财务费用1.44亿元，合计占营收19.6%，是连续亏损的核心原因。
- **[差异化专科布局（质子治疗、医美、辅助生殖）]** -> [未来增长点]: 西北首家质子治疗中心2026年投用，高附加值业务有望提升客单价与毛利率。
- **[股份回购注销与增资]** -> [资本结构优化]: 回购注销1.93亿股，并向西安国际医学中心增资3.8亿元，降低负债率、增强资本实力。

## 风险警告
**核心风险：持续亏损与高负债率。** 公司连续三年扣非净利润为负（2023-2025年分别为-4.99亿、-2.87亿、-3.45亿元），且2025年末资产负债率高达69.0%（合并口径），有息负债（短期+长期借款）超32亿元，财务费用高企。若住院量无法有效回升，亏损可能进一步扩大，侵蚀净资产。

**关键风险：DRG控费压力与竞争加剧。** DRG/DIP 3.0版全面落地，医保控费刚性，公司住院服务量已出现下滑。同时，公立医院扩张及同类社会办医竞争加剧，可能导致公司难以通过提价或增加高值服务来弥补收入缺口。此外，控股股东质押比例高达69.9%（4.31亿股质押），存在被动减持风险。
