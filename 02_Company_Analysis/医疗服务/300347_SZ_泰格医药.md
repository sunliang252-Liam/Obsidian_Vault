## 因果逻辑链
- **生物医药行业周期及政策环境变化** -> 国内创新药临床运营收入下滑: 早期立项管线与行业阶段不匹配，客户资金压力导致订单取消或终止，存量订单金额下降，工作量减少
- **行业竞争加剧，新签订单单价下滑** -> 国内创新药临床运营收入下滑: 新签订单单价下降导致同等工作量对应收入减少
- **中国创新药研发持续活跃，管线质量和数量提升** -> 2025年新签订单金额同比增长20.7%: 创新药IND数量、获批新药数量创新高，带动CRO服务需求复苏
- **行业供给端优化，中小CRO收缩，竞争趋于良性** -> 新签订单平均单价企稳: 存活CRO企业数量减少，价格战缓和，单价有望回升
- **中国创新药海外授权交易首付款和总金额创新高** -> 生物医药一级市场投融资回暖: 对外授权交易带来现金流，缓解客户资金压力，改善资本市场流动性
- **监管政策支持（创新药目录、商保目录等）** -> 创新药研发活力增强: 政策拓宽支付渠道、缩短审评审批时间，降低研发不确定性
- **中国临床试验数据首次在美国复制成功** -> 海外申办方在中国开展早期临床项目意愿提升: 数据质量获国际认可，增强全球药企对中国临床能力的信任
- **公司收购日本CRO Micron及扩张印度、马来西亚团队** -> 海外临床CRO业务收入和利润快速增长: 海外本地化团队扩充，提升全天候服务能力，拓展全球客户
- **AI技术应用（泰雅大模型、智能写作等）** -> 运营效率提升和成本优化: AI辅助文档生成、风险预警、中心推荐等，减少重复性工作，提升质量效率
- **归母净利润同比大幅增长119.15%，但扣非净利润同比下滑58.47%** -> 利润增长主要依赖非经常性损益（金融资产公允价值变动及投资收益）: 归母净利润包含大额非经常性收益（如金融资产公允价值变动3.5亿元），扣非净利润更能反映主业盈利能力下降

## 风险警告
尽管2025年新签订单和待执行合同金额增长良好，但公司扣非净利润大幅下滑58.47%，显示主业盈利能力显著恶化。主要风险包括：1）国内创新药临床运营收入持续下滑，存量订单消化导致短期业绩承压；2）新签订单单价虽已企稳，但回升仍需时间，后续收入增长可能滞后；3）大额非经常性损益（如金融资产公允价值变动）具有高度不确定性，未来可能波动，掩盖主业疲弱；4）海外业务扩张（如收购、增员）带来整合与成本风险，若收入增速不及预期，可能拖累整体利润率。
