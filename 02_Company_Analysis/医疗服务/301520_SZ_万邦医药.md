# 301520.SZ 深度透视

## 因果逻辑链
- **[仿制药行业竞争加剧]** -> [营收与利润双降]: 仿制药CRO市场内卷，客户需求波动，导致公司2025年营收同比下降27.67%，扣非净利润暴跌83.99%。
- **[核心业务临床研究服务萎缩]** -> [业绩下滑主因]: 临床研究服务收入同比下降28.23%，占总营收近80%，是公司业绩下滑的最大拖累项。
- **[药学研究服务收入锐减]** -> [业务结构恶化]: 药学研究服务收入同比骤降43.39%，毛利率下滑26.58个百分点，显示该板块竞争力或需求出现严重问题。
- **[研发投入大幅削减]** -> [短期利润调节，长期竞争力存疑]: 研发费用同比减少45.73%，研发人员数量减少25.73%，虽短期缓解利润压力，但可能削弱未来项目储备和技术壁垒。
- **[非经常性损益支撑利润]** -> [主业盈利能力堪忧]: 2025年扣非净利润仅893万元，而净利润为3643万元，差额主要来自理财收益（公允价值变动+投资收益约3192万元），主业造血能力极弱。
- **[经营活动现金流净流出]** -> [现金流恶化]: 经营活动现金流净额由正转负，为-792万元，同比下降116.91%，表明公司回款能力或业务质量出现问题。
- **[客户集中度低]** -> [抗风险能力弱]: 前五大客户销售额占比仅23.85%，客户分散虽降低单一依赖风险，但也反映公司缺乏深度绑定的大客户，业务稳定性差。
- **[诉讼风险与资产受限]** -> [潜在财务冲击]: 公司因未决诉讼计提预计负债500万元，且账面价值3251万元的交易性金融资产因诉讼受限，构成直接财务风险。

## 风险警告
**主业崩溃与利润空心化风险。** 公司2025年扣非净利润仅893万元，同比暴跌84%，而同期非经常性损益（主要是理财收益）高达2750万元，是净利润的主要来源。这表明公司核心的CRO业务已陷入严重困境，盈利能力名存实亡。若理财收益波动或主业持续恶化，公司将面临巨额亏损。

**行业竞争与现金流双重绞杀。** 仿制药CRO行业竞争白热化，公司两大核心业务（临床研究、药学研究）收入与毛利率双双下滑。更危险的是，经营活动现金流已转为净流出（-792万元），说明公司不仅赚不到钱，还在“失血”。在行业寒冬中，现金流断裂是中小CRO企业的最大生存威胁。
