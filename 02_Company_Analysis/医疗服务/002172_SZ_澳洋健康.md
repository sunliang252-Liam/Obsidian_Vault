# 002172.SZ 深度透视

## 因果逻辑链
- **[医康养护一体化布局]** -> [医疗服务收入稳定]: 以澳洋医院总院为核心，联动专科医院，在张家港区域构建“预防-诊疗-康复”全链条体系，抵御了行业政策波动，医疗服务收入仅小幅下降4.01%。
- **[医药流通业务受集采冲击]** -> [医药物流收入大幅下滑16.30%]: 药品集采政策持续深化，导致公司B2B配送业务量价承压，收入从9.95亿降至8.33亿，成为营收下降的主因。
- **[控股股东变更]** -> [实际控制人变更为地方国资]: 2025年11月，张家港悦升科技合伙企业受让20%股份，公司实控人由沈学如变更为张家港经济技术开发区管委会，带来信用背书与融资支持预期。
- **[控股股东股权质押承诺]** -> [缓解短期流动性压力]: 新控股股东悦升科技及原股东澳洋集团承诺，通过质押股权提供资金支持，以应对公司短期偿债需求，支撑了持续经营假设。
- **[高资产负债率与短债压力]** -> [持续经营能力存重大疑虑]: 资产负债率高达91.21%，未来12个月内到期有息负债远超未受限货币资金，审计报告将其列为关键审计事项，风险显著。
- **[信用减值损失扩大]** -> [侵蚀利润]: 2025年信用减值损失达1393万元，同比大幅增长423%，主要系应收账款坏账计提增加，反映出下游客户回款压力加大。
- **[生物科技业务起步]** -> [打造新增长点]: 成立生物科技公司，推出“贵玺”系列自主品牌，切入高端滋补品与功能性食品赛道，但规模尚小，对整体业绩贡献有限。

## 风险警告
**核心风险在于极高的财务杠杆与短期流动性危机。** 公司资产负债率高达91.21%，且未来12个月内到期的有息负债（3.68亿元）远高于未受限的货币资金及应收票据（1.97亿元）。尽管新控股股东提供了股权质押融资承诺，但这仅能缓解燃眉之急，并未根本解决公司造血能力不足与债务结构失衡的问题。一旦融资环境收紧或承诺未能及时兑现，公司将面临严重的债务违约风险。

**经营层面，公司两大主业均面临增长瓶颈。** 医疗服务收入微降，医药物流收入则大幅下滑16.30%，显示核心业务缺乏增长动力。同时，信用减值损失激增，表明下游客户（尤其是基层医疗机构）的支付能力恶化，坏账风险正在累积。公司试图通过生物科技等新业务突围，但该业务尚处培育期，短期内难以成为业绩支柱。在主营业务疲软、财务压力巨大的背景下，公司的持续经营能力存在重大不确定性。
