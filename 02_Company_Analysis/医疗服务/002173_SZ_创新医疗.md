# 002173.SZ 深度透视

## 因果逻辑链
- **[医保政策收紧]** -> [营收下降4.26%]: 当地医保对精神、康复病种支付标准调整，低保患者转向公立医院，直接冲击建华医院收入。
- **[次均费用下降趋势]** -> [扣非亏损扩大32.66%]: 行业性次均诊疗费用持续下降，医院“保量即减收”，利润空间被压缩。
- **[递延所得税资产减少]** -> [所得税费用上升]: 对短期盈利预期审慎，减少确认递延所得税资产，导致账面所得税费用同比增加。
- **[博灵脑机并表]** -> [研发费用新增310万]: 将博灵脑机纳入合并范围，带来脑机接口研发投入，短期增加费用。
- **[非经常性损益贡献]** -> [净利润减亏]: 增持博灵脑机及全诊医学处置子公司产生的投资收益约3633万元，掩盖了主营业务的真实亏损。
- **[经营现金流改善]** -> [现金净流入7593万]: 销售回款增加及收回李烨案件诉讼款，使经营性现金流由负转正，但利润质量仍差。
- **[公立医院挤压]** -> [民营医院生存空间收窄]: 公立医院诊疗人次占比持续提升，民营医院市场份额被进一步压缩，竞争加剧。

## 风险警告
**核心风险在于医保政策依赖与主业持续失血。** 公司营收高度依赖医保支付，而医保支付标准动态调整、支付方式改革及监管力度加大，直接侵蚀医院利润。建华医院（营收占比56.64%）受当地政策冲击最重，扣非亏损同比扩大260%，若政策持续收紧，公司核心资产可能陷入更严重的亏损泥潭。

**第二增长曲线尚在萌芽，短期无法对冲主业风险。** 博灵脑机产品虽具技术亮点（实时解码、闭环反馈），但2025年收入仅12万元，且尚未完成医疗器械注册，商业化路径漫长。公司账面未分配利润高达-14.3亿元，无法分红，持续亏损将消耗净资产，若主业不能止血，公司面临长期价值毁灭风险。
