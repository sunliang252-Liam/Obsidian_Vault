# 300725.SZ 深度透视

## 因果逻辑链
- **业务结构向CDMO倾斜** -> **毛利率阶段性下滑**: 公司为把握CDMO增长机遇，将资源向开发及商业化阶段倾斜，高毛利的研究阶段收入下滑，叠加“导入型”业务初期成本高企，导致整体毛利率承压。
- **国内业务快速增长** -> **整体毛利率被拉低**: 国内创新药投融资回暖驱动国内收入增长20.32%，但国内业务毛利率低于海外，其占比提升对整体毛利率构成阶段性负面影响。
- **汇率波动** -> **汇兑净损失侵蚀利润**: 人民币汇率波动导致本期产生汇兑净损失约2800万元，而上年同期为汇兑收益，同比减少利润总额。
- **强化销售回款管理** -> **经营性现金流大幅改善**: 公司加强销售回款管控，同时合理控制材料款支付节奏，经营活动现金流净额达6.67亿元，同比增长120.38%。
- **聚焦战略客户与一体化服务** -> **MNC收入与客户粘性提升**: 通过“业务铁三角”协同机制深化大客户管理，来自大型跨国制药企业收入同比增长41.35%，重点客户在CDMO收入中占比提升至75%。
- **新分子实体（OPC）业务突破** -> **开辟第二增长曲线**: 快速组建百人专业团队，在寡核苷酸、多肽、偶联药物领域取得关键进展，OPC业务收入同比增长超50%，新引入订单金额增长超100%。
- **绿色与智能技术平台赋能** -> **提升交付效率与差异化竞争力**: 连续流、酶催化等绿色技术在CDMO生产项目中的应用比例提升至30%，技术成果直接带动客户订单约2.3亿元，并助力公司连续两年获ACS绿色化学卓越奖。
- **可转债完成转股** -> **净资产大幅增加，负债结构优化**: 可转换公司债券于报告期内完成转股并摘牌，归属于上市公司股东的净资产同比大增110.88%，财务结构显著改善。

## 风险警告
**核心风险在于利润增长与收入增长严重背离。** 公司2025年营收增长16.93%，但归母净利润却下降16.31%，扣非净利润下降16.24%。利润下滑并非一次性冲击，而是由业务结构向低毛利CDMO倾斜、国内低毛利业务占比提升、汇率波动及信用减值损失增加等多重因素叠加所致。若公司无法有效提升CDMO业务的规模效应和毛利率水平，或高毛利的研究阶段业务恢复不及预期，利润端将持续承压，市场对其“增收不增利”的担忧将进一步加剧。

**另一重大风险是海外业务面临的地缘政治与汇率双重不确定性。** 公司海外收入占比高达72.66%，其中北美客户收入占比近半。在全球贸易保护主义抬头、地缘政治复杂的背景下，重要市场的产业政策、进出口管制及关税壁垒可能发生不利变化。同时，人民币汇率波动已在本期造成约2800万元的汇兑损失，若未来汇率持续大幅波动，将对公司以人民币计价的业绩产生显著影响。尽管公司已开展套期保值业务，但无法完全对冲风险。
