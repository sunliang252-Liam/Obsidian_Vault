# 301293.SZ 深度透视

## 因果逻辑链
- **[新院区集中投产]** -> [营收增长20.69%，但归母净利润下降19.85%]: 昆明、西安、北京新院区陆续开业，带来收入增量，但短期内土地摊销、设备折旧、人员薪酬等固定成本急剧攀升，收入爬坡速度远不及成本增速，导致增收不增利。
- **[并购大行广泽并表]** -> [西南地区收入暴增47.30%]: 2024年11月完成对四川大行广泽的收购，其旗下成都三博等资产在2025年全年并表，直接推动西南区域成为收入增长的核心引擎。
- **[固定资产贷款激增]** -> [财务费用飙升627.76%]: 为支持北京、昆明、西安新院区建设，公司大幅增加长期借款，导致利息支出剧增，严重侵蚀当期利润。
- **[高难度手术占比高]** -> [维持技术壁垒与品牌溢价]: 公司80%神经外科手术为四级最高难度手术，凭借顶尖专家团队（栾国明、于春江等）和“医教研”一体化平台，在民营神经专科领域构筑了难以复制的护城河。
- **[医保控费与集采]** -> [药品收入增长30.75%，但毛利率仅提升5.98%]: 药品收入增速快于医疗服务，但受集采政策影响，药品毛利率提升有限，显示收入结构变化对整体盈利能力的稀释作用。
- **[新院区爬坡期]** -> [昆明三博、西安三博合计亏损近5000万]: 两家新院区处于业务爬坡阶段，患者流量和手术量不足，无法覆盖高昂的固定成本，成为拖累集团利润的主要因素。
- **[不进行现金分红]** -> [留存资金用于新院区运营与资本开支]: 公司处于快速扩张期，为保障新院区资金需求，2025年度未进行利润分配，将利润全部留存用于未来发展。

## 风险警告
**核心风险在于“扩张性失血”。** 公司正处于自建与并购驱动的快速扩张期，昆明、西安、北京三大新院区集中投产，导致固定资产折旧、人员薪酬、利息支出等固定成本急剧膨胀。2025年归母净利润已同比下降19.85%，而财务费用更是飙升627.76%。若新院区患者流量和手术量爬坡不及预期，利润将持续承压，甚至可能陷入“增收不增利”的长期困境。

**另一重大风险是商誉与资产减值。** 公司账面商誉高达1.71亿元，主要来自并购。同时，在建工程（32.1亿）和固定资产（16.1亿）占总资产近半，且部分资产已用于抵押贷款。若宏观经济下行、行业政策收紧或并购标的（如大行广泽）经营不及预期，可能引发大规模商誉减值和资产减值损失，对净资产造成重大冲击。

**公司简介（F10 原文）**

> 三博脑科医院管理集团股份有限公司,“三博”品牌于2003年由神经医学专家栾国明、于春江、石祥恩及资深医疗管理专家张阳等人创建,经过二十年发展,探索出一套全新的医院管理模式,形成了以医疗投资、医院管理、品牌运营为主导,以“博医、博教、博研”为愿景,集“医疗、教学、科研”于一体的医疗集团。目前运营医院9家,其中神经专科三级医院6家:首都医科大学三博脑科医院、昆明三博脑科医院、福建三博脑科医院、河南三博脑科医院、洛阳伍一一三博脑科医院、西安三博脑科医院;三级综合性医院1家:成都三博东篱医院;二级综合性医院2家:重庆三博江陵医院、重庆三博长安医院;此外,还有湖南三博脑科医院正在筹建。以栾国明、于春江、石祥恩、王保国、闫长祥、吴斌、周健、张宏伟等神经医学专家为核心,汇聚和培养了一批医疗精英,已形成“老中青”三代医学专家梯队。集团以神经学科为龙头,强专科、小综合的发展模式,形成覆盖全国核心区域的医疗服务网。服务人群遍布全国各地及欧美、东南亚等国家。服务病种涵盖神经学科各类脑肿瘤、脑血管、功能神经外科、脊髓脊柱、小儿颅脑等疾病,也包括妇科、儿科、内科、外科、疼痛、全科等疾病。集团坚持“技术、品质、服务”的发展理念,以技术为本,“高端技术服务大众”。经过多年发展将旗舰医院首医大三博打造成“医教研”一体化的学院型医院,是首都医科大学十一临床医学院及神经外科学院三系,也是国家临床重点专科(神经外科)建设单位及国家卫健委全国神经外科进修与培训基地。2022年9月,医院东坝新院区项目入选本年度中国国际服务贸易交易会“两区”重大项目。作为集团疑难重症诊疗中心、人才培养输出基地和科研转化中心,首医大三博通过精湛强大的神经专科医疗技术,带动了集团各院神经学科发展和医疗能力提升。通过“医教研”综合发展平台,为专业人才提供了良好的学习机会、科研平台和成长空间,为各院发展持续输送先进技术和高端医疗人才。通过在管理、服务、运营方面的积极探索和经验积累,为集团的规模化扩张和持续发展提供保障。依托旗舰院区首医大三博的技术实力、人才输送、管理和服务经验,通过自建、合资、改制等多种方式,集团在云南、重庆、福建、河南等地区成功实现了扩张布局。2014年1月,公司自建的昆明三博开业。作为云南省三级神经专科医院,昆明三博开展了多项有典型意义的诊疗技术,极大促进了云南省神经外科发展。集团积极参与原国家卫生计生委和国务院国资委“央企主辅分离改革试点项目”,于2014年12月将重庆长安医院和重庆江陵医院改制为重庆三博长安和重庆三博江陵。通过硬件改善、人才支持、管理优化,两家医院医疗服务水平整体提升,神经专科技术显著增强,形成“大专科、强综合”的发展局面。2017年,三博脑科与福能集团出资设立福建三博,汇集一批知名神经医学专家,开业以来住院量、手术量保持高速增长,其中小儿神经医学及脑积水、帕金森治疗在省内实现了良性快速发展。2021年,河南三博在河南省郑州市投入运营,实现公司在华中地区的布局。2023年,西安三博获设置批复,洛阳伍一一三博脑科医院成功改制。集团统筹整合核心资源,对各分院在人才、技术上实行同质化管理与协同发展,制订统一的医疗质量管理制度和标准,医疗质量和医疗水平与首医大三博脑科医院同步,让当地患者享受到优质服务。同时,集团在提升技术、品质的基础上,创新管理模式,制定“360度服务体系”,为患者提供个性化诊疗和人性化服务,全方位保障“以患者为中心”的服务理念落到实处。同时,集团积极履行社会责任,于2023年12月,与天使妈妈基金会联合成立了脑病专项救助基金,并救助了一位患儿。为了谋求更高平台的发展,集团积极探索进入资本市场。2020年12月,三博集团正式向深圳证券交易所递交IPO申请,创业板受理。2021年9月,通过深交所上市委审议。同年12月,三博集团向深圳证券交易所提交IPO注册。2023年5月,三博脑科正式在深交所上市,股票代码301293。未来,三博脑科医院管理集团把首医大三博打造成神经医学中心,其他各院构建以神经医学为特色的区域医疗中心,形成覆盖全国、辐射周边国际区域的神经医学医疗服务网络,同时拓展在创新医疗产品和技术领域的业务布局,积极参与科技产品向医疗产品的转化,加强医疗科技产品在临床中的应用、拓展,将三博脑科打造成以医疗服务为核心的医疗健康科技集团,实现医疗服务、健康管理、医疗科技融合发展,打造防、治、管三位一体的新型医疗健康服务模式,最终实现让更多患者得到更好服务的发展目标。
