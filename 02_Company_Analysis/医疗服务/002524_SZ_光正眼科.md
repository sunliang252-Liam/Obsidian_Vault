# 002524.SZ 深度透视

## 因果逻辑链
- **眼科主业收入占比达85.7%，但营收微降0.86%** -> 医疗行业收入下滑2.53%，屈光项目增长4.41%未能完全对冲白内障项目下降9.37%的缺口，显示核心业务增长乏力。
- **净利润-1949.7万元，但同比大幅减亏88.84%** -> 2024年巨额亏损（-1.75亿）基数极低，2025年通过压缩销售费用（-9.26%）和管理费用（-17.76%）实现减亏，而非主业复苏。
- **经营活动现金流净额1.25亿元，同比大增80.57%** -> 现金流改善主要源于“购买商品、接受劳务支付的现金”减少，而非收入增长，反映公司主动收缩采购支出。
- **钢结构业务营收增长27.65%，但毛利率仅6.74%且同比下降** -> 低毛利钢结构业务扩张，拉低整体盈利质量，且该业务面临原材料价格波动和诉讼风险。
- **能源业务营收下降27.94%，已转为资产租赁模式** -> 公司主动剥离能源运营，将加油加气站长期出租获取稳定租金，但租赁收入仅占营收2.88%，贡献有限。
- **未弥补亏损-4.94亿元，超过实收股本1/3** -> 历史亏损积重难返，母公司层面持续亏损，导致无法分红，且净资产仅9578.8万元，财务基础薄弱。
- **高杠杆运营：短期借款2.69亿+租赁负债3.36亿，净资产仅0.96亿** -> 资产负债率畸高，大量资产为使用权资产（3.35亿），实际偿债能力极弱，财务风险突出。
- **股权激励计划首次解除限售，但第二期条件未达成需回购注销** -> 业绩考核未达标，显示公司对核心团队的激励效果有限，内部增长动力不足。

## 风险警告
**核心风险：财务脆弱性与持续经营能力存疑。** 公司净资产不足1亿元，却背负短期借款2.69亿元和租赁负债3.36亿元，资产负债率极高。未弥补亏损高达4.94亿元，远超股本，母公司持续亏损。尽管2025年现金流改善，但主要靠压缩开支实现，而非主业造血能力提升。一旦融资环境收紧或租赁到期，公司可能面临流动性危机。

**业务风险：眼科主业增长停滞，竞争加剧。** 公司核心医疗业务收入下滑，白内障项目受医保控费影响持续萎缩，屈光项目增长缓慢。在爱尔眼科、华厦眼科等头部连锁的挤压下，公司14家医院规模有限，难以形成规模效应。同时，钢结构业务毛利率极低且诉讼缠身，能源业务已实质退出，公司缺乏清晰的第二增长曲线。
