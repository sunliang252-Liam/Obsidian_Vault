# 688626.SH 深度透视

## 因果逻辑链
- **[研发投入高增]** -> [净利润下滑24%]: 研发费用同比增长15.16%至1.89亿元，叠加折旧摊销增加，侵蚀利润。
- **[康复评定设备放量]** -> [收入结构优化]: 康复评定设备收入同比增长46.67%，成为增长最快的细分品类。
- **[海外市场扩张]** -> [境外收入增长53%]: 聚焦“一带一路”沿线，CE/FDA认证推进，出口业务显著提速。
- **[脑机接口布局深化]** -> [技术壁垒提升]: 获脑电采集注册证、牵头国家级揭榜挂帅项目，构建“硬件+算法+设备”全链条优势。
- **[营销费用刚性]** -> [利润弹性受限]: 销售费用同比增长8.32%，800余人营销团队及学术推广投入持续，费用率维持高位。
- **[在建工程转固]** -> [折旧压力加大]: 在建工程同比增长61.91%，新项目陆续投产，固定资产折旧对短期业绩形成拖累。
- **[政策红利释放]** -> [行业需求扩容]: 国家密集出台康复医疗、银发经济、脑机接口等支持政策，驱动市场空间持续扩大。

## 风险警告
**盈利下滑与费用刚性风险**：公司2025年归母净利润同比下降24.08%，扣非净利润下降35.23%，核心原因是研发费用（+15.16%）和销售费用（+8.32%）持续高增，而收入仅增长3.26%。若收入增速无法显著提升，高额费用投入将持续压制利润弹性，净资产收益率面临进一步下滑压力。

**行业竞争与政策不确定性**：康复医疗器械行业市场前景广阔，吸引大量资本涌入，竞争加剧可能导致公司市场份额下降或产品价格承压。同时，若未来康复医疗器械领域全面实施集中采购政策，公司可能面临产品降价或中标价格较低的风险，对经营业绩造成不利影响。
