# 000735.SZ 深度透视

## 因果逻辑链
- **[猪周期下行，猪价中枢下移]** -> [归母净利润同比下滑36.39%]: 2025年全国活猪均价同比下降约15.20%，公司生猪养殖板块利润承压，尽管出栏量基本持平，但盈利空间被大幅压缩。
- **[房地产板块“保交付、稳去化”]** -> [商品房收入12.32亿元，毛利率提升11.57%]: 公司主动收缩地产规模，聚焦存量项目去化，通过高品质交付实现收益兑现，毛利率逆势改善，为核心主业输血。
- **[全产业链协同降本]** -> [养殖完全成本与行业前列差距快速缩窄]: 依托“饲料-动保-养殖-屠宰”闭环，潭牛饲料厂投产、同仁药业动保协同、精细化饲喂及数智化改造，有效对冲了原料价格波动和猪价下跌风险。
- **[冷链仓储利用率跃升]** -> [仓储容量利用率较上年提升30%]: 通过优化服务体系和推出“定向代采”供应链模式，冷链物流业务在海南自贸港建设背景下实现差异化竞争，跃居行业领先水平。
- **[投资性房地产公允价值变动]** -> [非经常性损益大幅亏损]: 受地产行情及出租物业空置下行影响，投资性房地产公允价值变动损益为-1.03亿元，是侵蚀净利润的重要因素。
- **[生猪存栏增加及诉讼冻结资金]** -> [经营活动现金流净额由正转负]: 生猪存栏量同比增长35.90%导致经营流出增加，叠加子公司诉讼导致资金受限，经营活动现金流净额为-0.93亿元，与净利润严重背离。
- **[屯昌黑猪新品系商业化加速]** -> [进军中高端猪肉市场]: 公司已完成屯昌黑猪新品系基础群组建，黑毛率取得突破，旨在通过差异化特色猪种提升产品附加值，摆脱同质化竞争。

## 风险警告
**核心风险在于猪周期持续探底与现金流恶化。** 2025年全国能繁母猪存栏仍高于合理保有量，供应压力未解，猪价中枢持续下移，公司养殖主业利润被大幅压缩。更严峻的是，经营活动现金流净额由正转负至-0.93亿元，与净利润严重背离，主因生猪存栏增加占用资金及诉讼冻结。若猪价持续低迷，公司可能面临流动性紧张，削弱其穿越周期的能力。

**第二重风险来自非经常性损益的不可持续性与资产减值。** 公司2025年归母净利润1.54亿元，但扣非净利润为2.45亿元，非经常性损益中投资性房地产公允价值变动亏损1.03亿元是主要拖累。此外，公司计提了0.53亿元资产减值损失，且房地产库存量同比大增53.01%，去化压力巨大。一旦地产市场持续低迷，资产减值风险将进一步暴露，侵蚀公司本就脆弱的盈利基础。
