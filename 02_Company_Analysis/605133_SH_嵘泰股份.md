# 605133.SH 深度透视

## 因果逻辑链
- **[收购中山澳多]** -> [营收增长37.2%]: 2025年9-12月并表，贡献汽车电子业务增量，推动总营收突破32亿。
- **[转向系统龙头地位]** -> [产销量创新高]: 电动转向机壳体年产量达1764万件，凭借技术、成本与规模化优势，巩固全球市场份额。
- **[定增募资8.78亿]** -> [资产规模扩张]: 资金用于新能源汽车零部件智能制造项目，导致总资产与净资产分别增长42.3%和43.32%。
- **[原材料结算方式变更]** -> [经营现金流恶化]: 主要供应商从承兑汇票改为现汇结算，导致购买商品现金支出增加，经营现金流同比下降41.1%。
- **[铝价联动机制]** -> [对冲成本波动]: 与客户约定铝价波动与售价联动，部分抵消原材料价格风险，但无法完全规避。
- **[客户集中度高]** -> [业绩依赖风险]: 前五名客户销售额占比70.42%，若主要客户流失或经营不利，将直接影响订单与收入。
- **[布局机器人第二曲线]** -> [打开长期空间]: 通过合资与自研，切入行星滚柱丝杠、机器人结构件及电机，构建“汽车+机器人”双主业格局。

## 风险警告
**核心风险在于客户高度集中与经营现金流恶化。** 前五大客户贡献超七成营收，过度依赖博世、采埃孚等Tier1巨头，一旦客户转向或行业周期下行，业绩将剧烈波动。同时，2025年经营现金流净额骤降41%，主因结算方式变更，但若持续，将削弱公司内生造血能力，增加对融资的依赖。

**第二增长曲线尚处早期，存在不确定性。** 机器人零部件业务（行星滚柱丝杠等）仍处于产能建设与客户验证阶段，短期内难以贡献实质利润。叠加收购中山澳多形成的3.07亿商誉，若汽车电子业务整合不及预期或行业竞争加剧，存在商誉减值风险，侵蚀利润。
