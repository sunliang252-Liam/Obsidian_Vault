# 600038.SH 深度透视

## 因果逻辑链
- **[最终客户交付节奏放缓]** -> [营收下降2.28%]: 受军方/最终客户付款与交付节奏影响，公司产品交付量同比下降，导致营业收入从297.66亿降至290.86亿。
- **[客户付款周期延长]** -> [经营性现金流大幅转负至-107.76亿]: 客户回款减少，同时公司维持高额采购与生产支出，导致经营活动现金净流出107.76亿元，同比由正转负。
- **[应收账款与合同资产激增]** -> [营运资金严重承压]: 因客户付款延迟，应收账款增长40.31%至126.08亿，合同资产暴增180.53%至93.08亿，大量资金被客户占用。
- **[研发投入主动收缩]** -> [短期利润增厚但长期竞争力存疑]: 自筹研发项目投入下降，研发费用同比减少30.18%至8.43亿，是利润增长的重要推手，但可能削弱未来技术储备。
- **[政府补助大幅增加]** -> [非经常性损益支撑利润]: 其他收益（主要为政府补助）同比增长88.66%至4.38亿，成为利润增长的关键外部因素。
- **[低空经济政策驱动]** -> [战略转型与市场预期]: 国家将低空经济列为战略性新兴产业，公司作为国内直升机龙头，加速布局新能源飞行器与新构型产品，打开长期想象空间。
- **[募投项目重大调整]** -> [资源配置优化与风险暴露]: 公司终止无人机研发等三个募投项目，新增供应链建设与出口型直升机项目，反映市场判断变化与研发路径调整。

## 风险警告
**核心风险是客户集中度极高与现金流断裂风险。** 公司前五名客户销售额占比高达82.41%，且主要为军方及关联方。2025年因客户付款周期延长，经营性现金流从+25.68亿骤降至-107.76亿，应收账款与合同资产合计超218亿，占流动资产的50%。这种对单一客户的极度依赖和付款节奏的不可控，使公司面临巨大的营运资金压力和潜在的坏账风险，一旦客户持续延迟付款，公司正常生产经营将受到严重冲击。

**其次，研发投入的主动收缩与募投项目的频繁变更，暴露了战略执行的摇摆与长期竞争力的隐忧。** 2025年研发费用同比大降30%，同时终止了无人机研发等前瞻性项目。虽然短期利润得以美化，但在全球直升机技术加速迭代（新能源、智能化）的背景下，这种“节流”策略可能使公司在未来竞争中掉队。此外，公司毛利率极低（航空制造仅9.33%），盈利能力脆弱，利润增长高度依赖政府补助和费用压缩，内生增长动力不足。
