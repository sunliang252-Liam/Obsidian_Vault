# 300507.SZ 深度透视

## 因果逻辑链
- **[收购博耐尔并全年并表]** -> [营收增长37.43%]: 2024年Q4控股博耐尔，2025年全年并表，新增汽车热管理系统零部件业务，贡献42%营收，是收入增长的核心驱动力。
- **[子公司低毛利率拉低整体盈利]** -> [净利润下降13.28%]: 博耐尔毛利率仅8.68%，远低于公司传统业务，其全年收入并入后结构性拉低集团整体毛利率，导致增收不增利。
- **[汽车行业年降压力传导]** -> [毛利率下降4.62个百分点]: 整车厂为应对价格战，将成本压力向上游传导，公司产品普遍面临年降，侵蚀利润空间。
- **[中创新航入主成为控股股东]** -> [战略协同与业绩承诺压力]: 引入新能源电池巨头作为实控人，推动新能源领域深度合作，但原实控人李宏庆承诺2025年归母净利润1.78亿，实际仅完成1.2亿，完成率67%，触发补偿条款。
- **[传感器国产替代突破]** -> [开辟新增长曲线]: 电涡流位置传感器、EMB力传感器、电流传感器等新品实现规模化应用或获得定点，瞄准新能源车高精度、低成本国产替代市场。
- **[AMB覆铜陶瓷基板项目推进]** -> [布局第三代半导体材料]: 项目已向多家客户送样并进入小批量阶段，为高功率电动车型提供核心支撑，是公司向半导体材料领域延伸的关键布局。
- **[传统燃油车业务承压]** -> [转型迫切性加剧]: 燃油系统附件及传感器业务收入下滑或微增，面临纯电汽车普及导致需求萎缩的长期风险，倒逼公司加速向新能源零部件转型。

## 风险警告
**核心风险：业绩承诺缺口与整合阵痛。** 原实控人李宏庆承诺2025年归母净利润1.78亿元，实际仅完成1.2亿元，完成率67.17%，已触发补偿条款。这暴露出收购博耐尔后的整合远未达预期，子公司低毛利率及大客户年降问题严重拖累集团盈利。若2026年承诺的1.95亿元净利润无法实现，将面临持续补偿压力，并可能引发商誉减值风险。

**结构性风险：增收不增利的困境与客户集中度。** 公司营收高度依赖博耐尔（贡献42%），但其毛利率极低（8.68%），导致整体盈利能力被稀释。同时，前五大客户销售占比高达52%，客户集中度极高，议价能力弱，在行业年降压力下利润空间持续承压。传统燃油车业务（传感器、燃油系统附件）增长乏力，转型新能源虽方向正确，但新业务尚处爬坡期，短期难以弥补利润缺口。
