# 688617.SH 深度透视

## 因果逻辑链
- **[PFA脉冲消融产品获批上市]** -> [电生理业务收入增长29.81%]: 公司AForcePlusTM等PFA产品于2024年底获批，2025年迅速在全国头部中心准入并完成5,900余例手术，驱动电生理板块成为核心增长引擎。
- **[冠脉通路产品线完整性与集采中标]** -> [冠脉通路业务收入增长27.35%]: 公司凭借全产品线布局（微导管、延伸导管等国产首款产品）和规模化成本优势，在集采中持续中标，加速医院覆盖与市场份额提升。
- **[外周介入产品线拓展与基层渗透]** -> [外周介入业务收入增长29.76%]: 公司通过“通路产品突破+治疗类产品跟进”策略，叠加集采放量，实现终端医院数量同比增长超20%，驱动高增长。
- **[迈瑞医疗渠道与管理赋能]** -> [国内经销模式收入增长32.86%]: 依托迈瑞医疗的全球渠道、品牌及管理经验，公司共享客户资源，加速产品入院，显著提升国内经销网络的覆盖深度与效率。
- **[持续高研发投入（占收入14.12%）]** -> [新产品密集获批，巩固技术护城河]: 报告期内研发投入3.65亿元，推动心腔内超声导管、压力感应射频消融导管等核心产品获批，强化了在电生理和血管介入领域的技术领先地位。
- **[产能扩张与智能制造]** -> [规模效应提升毛利率至73.18%]: 湖南埃普特新厂区投产，血管介入产能提升40%，自动化产线效率提升3%，在集采降价压力下仍实现毛利率同比上升0.47个百分点。
- **[国际化战略推进]** -> [境外收入增长20.25%]: 自主品牌在欧洲、亚太、独联体等区域高端医院实现入院突破，境外收入达3.37亿元，但中东非地区因地缘政治承压。

## 风险警告
**集采深化与价格下行风险**：公司核心产品（冠脉通路、电生理耗材）已纳入多省联盟集采，2026年国家集采引入“锚点价格机制”虽趋于理性，但长期价格下行压力持续。若公司无法通过产品迭代或成本优化维持毛利率，盈利能力将受冲击。当前73.18%的毛利率已处于高位，进一步压缩空间有限。

**PFA市场竞争白热化与商业化不确定性**：2025年作为PFA“元年”，国内外多家厂商产品集中获批，市场竞争已进入焦灼状态。公司虽具备“环+线”三维压力感应组合的差异化优势，但需持续投入大量资源进行市场教育与医院准入，若推广不及预期或竞争对手推出更优方案，前期研发与市场投入可能无法获得预期回报。
