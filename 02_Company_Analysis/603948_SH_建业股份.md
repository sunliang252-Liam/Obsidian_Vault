# 603948.SH 深度透视

## 因果逻辑链
- **[原材料价格下降]** -> [毛利率提升]: 主要原材料（液氨、乙醇、正丁醇等）采购价格同比大幅下降10%-25%，直接降低了营业成本，使毛利率同比增加3.33个百分点。
- **[成本降幅大于收入降幅]** -> [净利润逆势增长]: 营业收入同比下降14.07%，但营业成本下降17.88%，成本端弹性更大，使得归母净利润同比增长10.00%。
- **[核心产品低碳脂肪胺量稳利增]** -> [利润基石稳固]: 低碳脂肪胺销量仅微降2.07%，但毛利率同比大幅提升5.38个百分点，贡献了主要利润增量。
- **[财务费用大幅减少]** -> [利润增厚]: 利息收入增加，财务费用从-882万降至-2137万，同比减少142.13%，直接增厚了利润。
- **[经营活动现金流强劲]** -> [盈利质量高]: 经营活动现金流净额同比增长31.73%至3.85亿元，远超净利润，表明公司回款能力强，利润含金量高。
- **[电子化学品业务持续亏损]** -> [拖累整体业绩]: 子公司建业微电子亏损3085万元，产能利用率极低（超纯氨仅27.25%），成为公司利润的主要拖累项。
- **[高分红政策]** -> [股东回报稳定]: 拟每股派发现金红利1.00元，分红比例高达70.66%，连续多年高分红，体现了公司对股东的回报意愿和能力。

## 风险警告
公司面临的核心风险是**行业周期性与原材料价格波动**。化工行业景气度下行，产品价格震荡，公司营收已连续两年下滑。虽然2025年因原材料价格下跌实现了利润增长，但这种“成本驱动型”利润增长不可持续。一旦原材料价格反弹，而下游需求无法支撑产品提价，公司毛利率将迅速承压，利润可能大幅回吐。

另一个关键风险是**新业务（电子化学品）的持续亏损**。子公司建业微电子是公司未来增长的重要方向，但目前产能利用率极低（超纯氨仅27.25%），连续亏损且亏损额扩大（2025年亏损3085万元）。该业务能否成功导入客户、提升开工率，是公司能否打开第二增长曲线的关键。若长期无法扭亏，将不断侵蚀公司主业利润。
