# 601328.SH 深度透视

## 因果逻辑链
- **[净息差收窄压力]** -> [利息净收入微增1.91%]: 资产端收益率（贷款收益率降58bp）降幅远超负债端成本改善（存款成本率降38bp），导致净息差收窄7bp至1.20%，但规模扩张（贷款增6.64%）部分对冲了利率下行影响。
- **[1200亿定向增发]** -> [核心一级资本充足率跃升1.19pct至11.43%]: 财政部等认购的1200亿A股定增于2025年6月完成，大幅夯实资本基础，为未来信贷扩张和风险吸收提供充足“弹药”。
- **[“五篇大文章”信贷结构优化]** -> [科技/绿色/普惠贷款增速显著高于全行平均]: 科技贷款(+10.73%)、绿色贷款(+14.16%)、普惠小微贷款(+20.76%)增速均远超全行贷款平均增速6.64%，驱动资产结构向国家战略领域倾斜，提升长期增长韧性。
- **[零售信贷风险暴露]** -> [个人贷款不良率上升0.50pct至1.58%]: 受宏观经济及房地产市场下行影响，个人住房贷款、经营贷、消费贷不良率全面上升，成为资产质量主要压力点，抵消了公司类贷款不良率的改善。
- **[财富管理业务发力]** -> [手续费及佣金净收入增长3.44%]: 理财(+16.98%)、代销基金(+15.84%)等财富管理收入增长强劲，成为非息收入主要驱动力，部分弥补了投资损益下滑的影响。
- **[AI与数字化转型投入]** -> [成本收入比下降0.60pct至29.30%]: 科技投入123亿（营收占比5.78%），部署超2500个AI智能体，推动业务流程再造（如对公开户时长减半），实现降本增效。
- **[子公司利润贡献提升]** -> [集团净利润增长2.18%]: 子公司净利润同比增9.66%，占集团利润10.56%，其中交银理财(+17.32%)、交银人寿(+35.82%)表现突出，多元化经营有效反哺母行。

## 风险警告
**核心风险在于零售信贷资产质量的持续恶化。** 个人贷款不良率从1.08%飙升至1.58%，其中个人经营贷不良率从1.21%升至1.94%，消费贷从1.12%升至1.77%，住房贷款从0.58%升至1.01%。逾期贷款率上升0.08pct至1.46%，且逾期90天以上贷款余额增加209亿。这并非短期波动，而是宏观经济下行、居民收入预期疲弱及房地产市场深度调整的长期映射。若经济复苏不及预期，零售不良可能继续攀升，侵蚀拨备并压制利润。

**净息差持续收窄的长期趋势难以逆转。** 尽管2025年通过负债成本管理将降幅控制在7bp，但资产端收益率下行（贷款降58bp）远快于负债端成本改善（存款降38bp）。在LPR调降、有效信贷需求不足的背景下，资产收益率仍有下行压力，而存款定期化趋势（定期存款占比升至67.38%）限制了负债成本进一步下降的空间。净息差可能继续承压，对利息净收入这一营收基本盘构成根本性挑战。
