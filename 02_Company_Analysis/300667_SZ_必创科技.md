# 300667.SZ 深度透视

## 因果逻辑链
- **[智能传感业务主动收缩]** -> [营收下滑1.14%]: 公司主动收缩非战略方向业务，智能传感收入同比大降40.09%，拖累整体营收。
- **[产品结构向光电仪器倾斜]** -> [毛利率微升0.74%]: 高毛利的光谱仪器（+9.76%）和精密光机（+58.22%）占比提升，部分对冲了收入下滑对利润的影响。
- **[下游需求疲软与资产减值]** -> [连续第二年亏损]: 部分产品盈利能力下降，叠加各项资产减值，导致归母净利润-1.1亿元，但同比减亏22.59%。
- **[研发投入聚焦光电技术]** -> [新产品储备丰富]: 全年研发投入7108万元，推出飞秒瞬态吸收光谱仪、太阳光模拟器等新品，为未来增长蓄力。
- **[经营现金流持续为正]** -> [财务安全垫厚实]: 经营活动现金流净额7210万元，现金储备充裕，为公司在战略转型期提供稳健的财务支撑。
- **[卓立汉光为核心利润来源]** -> [子公司贡献突出]: 全资子公司卓立汉光实现净利润4532万元，是公司当前主要的盈利引擎，支撑了整体业务的基本盘。
- **[国产替代与政策红利]** -> [长期增长逻辑]: 科学仪器国产化、“十五五”规划等政策利好，为公司光电仪器业务提供了“替代+升级”的长期发展机遇。

## 风险警告
公司连续两年亏损，且母公司未分配利润为负（-7969万元），已不具备现金分红条件。核心风险在于战略转型的阵痛期：主动收缩智能传感业务导致收入承压，而大力投入的光电仪器业务尚未完全转化为规模效益，新产品推广和盈利能力验证仍需时间。若下游科研和工业市场需求复苏不及预期，或新产品市场拓展受阻，公司业绩存在进一步下滑的风险。

此外，公司账面存在因收购卓立汉光形成的大额商誉。尽管当前卓立汉光经营稳健，但若未来行业竞争加剧或技术迭代导致其业绩不达预期，将面临商誉减值的风险，对利润造成一次性冲击。同时，公司客户集中度低（前五大客户仅占8.47%），且产品面向碎片化市场，这虽然分散了风险，但也意味着市场拓展和销售管理成本较高，对公司的运营效率提出了更高要求。
