# 600984.SH 深度透视

## 因果逻辑链
- **[房地产行业持续低迷]** -> [塔机租赁业务量价齐跌]: 下游新开工面积同比下降20.4%，导致塔机利用率与租赁价格双双承压，核心子公司庞源租赁收入同比下降10.85%。
- **[租赁价格竞争加剧与成本刚性]** -> [租赁业务毛利率大幅下滑]: 租赁业务收入下降10.85%，但人工、折旧等成本仅下降2.32%，导致毛利率由负转负且恶化7.86个百分点至-14.03%。
- **[资产价值重估与减值计提]** -> [归母净利润巨亏21.97亿元]: 公司对塔机设备、工抵房、在建办公楼及庞源租赁长期股权投资进行减值测试，合计计提资产减值及长期股权投资减值损失约32.24亿元，是亏损的核心原因。
- **[下游客户回款困难]** -> [信用减值损失激增]: 应收账款规模庞大（34.37亿元），受下游资金紧张影响，本期信用减值损失达1.09亿元，同比增长350.74%。
- **[存量资产盘活与业务结构调整]** -> [经营性现金流净额逆势增长34.89%]: 公司通过压降采购支出、加大回款力度，实现经营性现金流5.42亿元，现金流状况优于利润表现。
- **[行业出清与集中度提升]** -> [龙头企业市场份额有望巩固]: 中小企业加速退出，市场存量设备减少，公司作为全球第二大塔机租赁商，品牌与规模优势在行业筑底期凸显。
- **[向集团主业靠拢]** -> [煤矿机械与智能装备成为新增长点]: 无轨胶轮车销售收入同比增长43.19%，子公司陕煤智控切入矿用智能装备赛道，依托陕煤集团内部市场实现增量。

## 风险警告
**核心风险：资产减值与流动性双重压力。** 公司2025年归母净利润巨亏21.97亿元，净资产收益率骤降至-69.06%，主要源于对核心子公司庞源租赁的长期股权投资（23.53亿元）及固定资产（5.05亿元）的大额减值。这反映出公司核心资产在行业下行周期中的价值严重缩水，且减值风险尚未出清。同时，公司资产负债率已攀升至78.30%，短期借款及一年内到期的非流动负债合计约32.16亿元，而货币资金仅10.89亿元，短期偿债压力巨大，流动性风险显著。

**经营风险：主业盈利模式承压。** 公司核心业务——塔机租赁的毛利率已为-14.03%，意味着每产生1元租赁收入，就要亏损0.14元。在房地产新开工面积持续低位、租赁价格指数未见拐点的情况下，公司“以价换量”的策略难以持续，庞源租赁的亏损状态短期内难以扭转。此外，公司通过工抵房方式回笼资金，但工抵房本身又面临减值风险（本期计提1.89亿元），形成了“应收账款风险”向“存货风险”的传导，资产质量改善路径尚不清晰。
