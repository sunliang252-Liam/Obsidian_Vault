# 603298.SH 深度透视

## 因果逻辑链
- **[电动化转型加速]** -> [营收与利润双增]: 电动叉车（尤其是锂电）渗透率提升，高附加值产品替代内燃叉车，推动毛利率提升0.86个百分点，实现营收177.39亿元（+5.90%），归母净利润21.91亿元（+8.87%）。
- **[全球化布局深化]** -> [海外收入高增]: 海外子公司增至20余家，泰国工厂即将投产，海外销售超12万台（+27%），营收占比升至43.38%，成为增长核心引擎。
- **[收购国自机器人]** -> [智能物流能力跃升]: 整合国自机器人软件算法团队，补齐智能化短板，智能物流板块营收近10亿元，形成“硬件+解决方案”双轮驱动。
- **[“未来工厂”升级]** -> [运营效率提升]: 投入亿元建设工业互联网平台，关键设备联网率95%，订单交付周期缩短40%，支撑年产40万台柔性生产能力。
- **[新能源全产业链布局]** -> [成本与性能优势]: 自研“三电”系统（电池、电驱、电控），锂电池日产能达400台，核心零部件自主可控，降低对外依赖，增强产品竞争力。
- **[租赁业务爆发]** -> [后市场收入增长]: 租赁业务营收5.8亿元（+85%），覆盖全国30省市，构建“租赁+销售+备件+服务”一体化模式，开辟第二增长曲线。
- **[研发投入持续高增]** -> [产品迭代领先]: 研发费用8.59亿元（+5.07%），推出X系列混合动力叉车等60余项新品，填补市场空白，巩固技术护城河。

## 风险警告
**核心风险在于收购国自机器人的整合与业绩兑现。** 国自机器人2025年实际净利润仅512万元，远低于承诺的1,292万元，三年累计承诺8,708万元，完成压力巨大。若整合不及预期或业绩持续不达标，将产生大额商誉减值与现金补偿风险，直接侵蚀利润。同时，公司对国自机器人原股东仇建平的业绩承诺依赖度极高，关联交易风险需警惕。

**外部环境与竞争风险同样不容忽视。** 全球贸易壁垒加剧、地缘冲突扰动，海外业务（占营收43%）面临汇率波动与关税风险。国内行业“内卷”加剧，电动化产品同质化竞争导致价格压力，若公司不能持续保持技术领先与成本优势，市场份额与盈利能力可能受冲击。此外，公司短期借款与应付票据大幅增加，资产负债率有所上升，需关注流动性管理。
