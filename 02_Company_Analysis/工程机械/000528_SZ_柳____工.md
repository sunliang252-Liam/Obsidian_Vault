# 000528.SZ 深度透视

## 因果逻辑链
- **[海外业务高增长]** -> [净利润增速远超营收]: 海外收入同比增长14.78%，占比升至47.65%，且海外毛利率（29.73%）远高于国内（15.75%），高毛利海外业务占比提升直接拉动了整体盈利能力的改善。
- **[电动化产品放量]** -> [土方机械市场份额提升]: 电动装载机全球销量增长超130%，出口占行业电装出口近50%，电动化先发优势帮助公司在国内行业增速放缓背景下，土方机械销量增速跑赢行业12个百分点。
- **[“三全战略”落地]** -> [业务结构优化与抗周期能力增强]: 从单一设备制造向“全面解决方案”转型，矿山机械、起重机等第二增长曲线发力，叠加后市场与租赁业务布局，构建了“强周期+弱周期”双元抗风险业务组合。
- **[全球化产能与渠道布局]** -> [海外业绩创历史新高]: 在印度、印尼、巴西等地设立制造基地，全球经销商网络近400家，服务网点超1000个，本地化运营能力提升支撑了海外销量、收入、利润全面突破历史峰值。
- **[研发投入持续高增]** -> [技术领先与产品竞争力]: 研发费用同比增长18.75%，在电动化（超100款产品）、智能化（无人驾驶装载机交付）、核心零部件（自研电池系统）等关键领域取得突破，为产品溢价和市场份额提升提供了技术基础。
- **[设备更新政策与更新需求]** -> [国内业务平稳增长]: 国家推行的设备更新政策有效激发了存量设备替换需求，叠加环保政策趋严，为国内工程机械市场提供了“L型”平稳增长期的核心驱动力，支撑了公司国内收入6.43%的增长。
- **[融资销售模式风险敞口]** -> [经营性现金流承压]: 公司为促进销售，大量采用融资租赁、按揭等模式，导致代垫逾期款增加（其他应收款约77亿元），叠加应收账款规模扩大，使得经营活动现金流净额同比下降23.95%，与净利润增长背离。

## 风险警告
**核心风险在于信用销售带来的现金流与坏账压力。** 公司融资租赁、按揭及保兑仓业务担保余额高达606.5亿元，远超净利润规模。报告期内因代垫逾期款产生的其他应收款达77.25亿元，导致经营性现金流净额（10.05亿元）远低于净利润（16.09亿元），且同比大幅下降23.95%。一旦宏观经济下行或终端客户违约率上升，公司将面临巨大的坏账损失和流动性压力，这是工程机械行业“以销定产”模式下的固有顽疾。

**海外市场的地缘政治与贸易壁垒风险不容忽视。** 公司海外收入占比已近半，但全球贸易保护主义持续加码，西方市场对中国工程机械产品的政策壁垒可能进一步收紧。同时，新兴市场虽增长强劲，但汇率波动、地缘冲突及当地政策不确定性，都可能对海外业务的盈利稳定性和资产安全构成冲击。公司虽通过衍生品进行套期保值，但无法完全对冲系统性风险。
