# 002839.SZ 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [利息净收入下降10.16%]: 生息资产平均收益率（3.56%→2.99%）降幅远超付息负债成本率（2.16%→1.79%），导致净息差从1.62%压缩至1.39%，核心盈利承压。
- **[投资收益与公允价值变动收益大增]** -> [净利润逆势增长5.35%]: 投资收益增长8.95%至14.06亿，公允价值变动收益从-1.04亿扭转为+1.39亿，合计贡献约2.43亿增量，对冲了利息收入下滑。
- **[“做小做散”战略与信贷结构优化]** -> [公司贷款增速（13.07%）远超个人贷款（0.45%）]: 主动调整资产结构，加大对制造业、科创、绿色等实体企业信贷投放，公司贷款占比从53.15%提升至55.63%。
- **[信用减值损失减少16.69%]** -> [利润释放]: 不良贷款率稳定在0.94%，拨备覆盖率虽降至328.87%但仍处高位，信用成本下降直接增厚利润。
- **[手续费及佣金支出大幅减少40.97%]** -> [手续费净收入暴增235%]: 代理业务手续费支出减少，使净收入从0.30亿跃升至0.99亿，成为非息收入增长的重要补充。
- **[存款成本下降与结构优化]** -> [利息支出减少13.42%]: 吸收存款平均成本率从2.13%降至1.74%，个人定期存款增长10.54%但整体付息成本得到有效控制。
- **[金融投资结构向其他债权投资倾斜]** -> [投资组合收益韧性]: 债权投资减少31.51%，其他债权投资增加21.80%，通过交易策略和久期管理应对利率下行，维持投资收益正增长。
- **[向中央银行借款增加51.92%]** -> [低成本负债来源补充]: 充分运用支农支小再贷款政策，增加低成本央行借款，部分对冲了同业负债成本压力。

## 风险警告
张家港行面临的核心风险在于净息差持续收窄的长期趋势。2025年净息差已降至1.39%，同比下降23个基点，且生息资产收益率（2.99%）已逼近付息负债成本率（1.79%），利差空间极度压缩。在当前LPR下行、让利实体经济的政策环境下，若投资收益和公允价值变动收益无法持续弥补利息收入缺口，净利润增长将面临严峻挑战。此外，关注类贷款迁徙率从25.6%升至33.94%，不良生成压力有所抬头，需警惕未来信用成本上升侵蚀利润。

另一个关键风险是经营现金流持续为负且缺口扩大。2025年经营活动现金流净额为-32.4亿元，较2024年的-4.2亿元大幅恶化，主因是卖出回购证券款净减少。虽然银行现金流波动属行业特性，但持续大额负现金流可能反映资产负债期限错配加剧或流动性管理压力。同时，拨备覆盖率已从424%的高位连续两年下降至329%，虽然仍高于监管要求，但缓冲垫正在变薄，未来资产质量波动对利润的冲击将更为直接。
