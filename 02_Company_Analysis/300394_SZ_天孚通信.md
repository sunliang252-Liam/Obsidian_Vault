# 300394.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收与净利润双创新高]: AI大模型驱动全球数据中心建设，高速光器件需求持续增长，公司2025年营收51.63亿元（+58.79%），净利润20.17亿元（+50.15%）。
- **[1.6T光引擎规模量产]** -> [有源光器件营收高增]: 成功量产1.6T光引擎并完成CPO配套光器件研发，推动有源光器件营收同比大增81.11%，成为核心增长引擎。
- **[客户高度集中]** -> [经营波动风险]: 前五大客户销售额占比89.73%，其中第一大客户Fabrinet占比63.31%，单一客户需求波动将直接冲击公司业绩。
- **[海外营收占比高]** -> [汇兑损失侵蚀利润]: 外销占比74.35%，2025年因汇率变动产生汇兑损失4752万元，财务费用同比上升66.24%，对净利润增长产生负向影响。
- **[泰国工厂投产]** -> [毛利率承压]: 泰国工厂投产初期因员工熟练度和产能利用率不足，生产成本高于国内，叠加产品降价压力，整体毛利率同比下降3.26个百分点。
- **[研发投入持续加大]** -> [技术领先与产品迭代]: 研发投入2.67亿元（+14.79%），研发人员增长40.98%，支撑1.6T、CPO等下一代技术布局，巩固行业护城河。
- **[全球化产能布局]** -> [供应链韧性与客户信任]: 形成苏州、新加坡双总部及江西、泰国双生产基地，满足客户多元化需求与供应链安全，增强客户粘性。

## 风险警告
**客户集中与单一依赖风险极高。** 公司前五大客户销售额占比高达89.73%，其中Fabrinet一家占比63.31%。这种极端的客户集中度意味着，一旦主要客户需求放缓、技术路线变更或采购政策调整，公司将面临营收断崖式下滑的风险，几乎没有缓冲余地。这是公司最脆弱的一环。

**毛利率持续下行与成本压力并存。** 光器件行业竞争激烈，产品价格面临持续降价压力。同时，泰国工厂投产初期成本高企，高速光引擎项目毛利率相对较低，叠加原材料价格波动，公司整体毛利率已出现下滑趋势。若降本增效无法对冲价格下行，盈利能力将持续承压。此外，海外高营收占比带来的汇率风险已开始实质性地侵蚀利润。
