# 920892.BJ 深度透视

## 因果逻辑链
- **[“十五五”规划窗口期 + 政策红利]** -> **工程咨询收入增长12.18%**: 公司紧抓“两重”“两新”及地方规划编制机遇，新签合同额同比增长7.2%，推动核心业务板块量价齐升。
- **[数智化转型投入]** -> **研发费用增长15.23%至3749万元**: 公司加速建设数字智库、数字采购、数字造价等平台，研发投入占营收比提升至6.36%，以技术重构业务流程。
- **[清收长账龄应收款]** -> **信用减值损失转正，增厚利润**: 报告期内信用减值损失同比减少107.06%，从-485万元转为+34万元，直接贡献利润弹性。
- **[高分红+转增股本]** -> **净资产收益率维持高位（25.37%）**: 连续两年实施“10派6元+转增”方案，在摊薄股本的同时，通过利润增长维持了高ROE水平。
- **[轻资产运营 + 无有息负债]** -> **经营活动现金流净额达1.58亿元**: 公司无短期/长期借款，现金循环健康，现金流净额/净利润比率高达1.47，盈利质量优异。
- **[货币资金占比83.14%]** -> **资产结构极度“现金化”**: 账面现金高达7.56亿元，占总资产比重超八成，反映公司业务模式为预收款+轻资产，但也暗示资金利用效率偏低。
- **[广东省内收入占比94.6%]** -> **区域集中度风险**: 公司业务高度依赖广东区域市场，省外收入同比下降17.21%，全国化布局尚未形成有效突破。

## 风险警告
**核心风险在于“现金冗余”与“增长瓶颈”的背离。** 公司账面现金超7.5亿元，占总资产83%，却无任何有息负债，资金利用效率极低。与此同时，营收增速仅5.13%，且高度依赖广东省内市场（占比94.6%），省外拓展乏力。这种“富余现金+低增长”的组合，暗示公司缺乏有效的资本配置能力或外延扩张战略，长期可能面临ROE被现金拖累的下行压力。

**第二重风险是业务结构的“天花板”与转型阵痛。** 传统工程造价业务收入同比下降0.97%，项目管理和工程监理收入更是骤降39%，显示传统基建咨询需求承压。公司虽在“十五五”规划、低空经济等新赛道积极布局，但新业务体量尚小，且数智化转型需要持续高研发投入（研发费用增长15%），若新业务无法快速形成规模收入，公司可能陷入“旧业务萎缩、新业务烧钱”的尴尬期。
