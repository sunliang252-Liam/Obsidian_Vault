# 300765.SZ 深度透视

## 因果逻辑链
- **[研发投入激增]** -> **净利润亏损2.41亿**: 研发费用10.36亿元，同比增长23%，远超营收增速，直接导致由盈转亏。
- **[创新药进入商业化放量期]** -> **生物制药收入暴增193%**: 恩舒幸®、恩益坦®两款新药2024年获批，2025年为首个完整销售年，驱动生物制药收入从0.88亿跃升至2.57亿。
- **[咖啡因主业毛利率承压]** -> **核心利润来源受损**: 受市场因素影响，咖啡因类产品毛利率同比下降4.85个百分点，削弱了传统业务的“现金牛”属性。
- **[收购巨石生物少数股权]** -> **亏损影响放大**: 对巨石生物持股比例从51%提升至80%，巨石生物当期亏损9.04亿，更大比例纳入合并报表，加剧归母净利润亏损。
- **[与阿斯利康达成授权合作]** -> **潜在巨额里程碑收入**: 2026年初签署协议，巨石生物将收取4.2亿美元首付款，有望大幅改善现金流并验证技术平台价值。
- **[研发管线密集推进]** -> **未来增长引擎蓄力**: 9款产品获中国临床试验批准，4款获FDA批准，2款ADC进入III期，乌司奴单抗、帕妥珠单抗已提交上市申请。
- **[销售费用率飙升]** -> **商业化投入期特征**: 销售费用同比增长82%，主要用于新上市生物药的学术推广和市场开拓，是创新药企从研发到销售的必经阶段。

## 风险警告
**核心风险在于“创新药转型的阵痛期”与“传统业务失速”的双重挤压。** 公司为支撑庞大的ADC、mRNA疫苗管线，研发投入已占营收近半，导致2025年巨亏。若后续核心管线（如SYS6010、DP303c）临床试验失败或商业化不及预期，高额投入将无法回收，公司可能陷入长期亏损。同时，作为利润基石的咖啡因业务毛利率持续下滑，若价格战加剧或需求疲软，将削弱公司为创新药“输血”的能力。

**另一个关键风险是关联交易与母公司依赖。** 公司作为石药集团的创新药平台，大量研发、生产、销售活动与关联方（如恩必普药业、中奇制药）深度绑定。虽然短期内能获得资金和资源支持，但长期来看，关联交易的定价公允性、业务独立性以及潜在的同业竞争问题，都可能成为公司治理和估值的隐忧。此外，与阿斯利康的授权合作虽带来巨额首付款，但后续里程碑付款的实现高度依赖研发进展，存在不确定性。
