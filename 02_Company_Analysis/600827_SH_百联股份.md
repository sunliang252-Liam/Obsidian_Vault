# 600827.SH 深度透视

## 因果逻辑链
- **[联华超市营收持续下滑]** -> [整体营收与经营现金流锐减]: 联华超市作为营收主力（占比超77%），其标准超市、大卖场业态收入同比分别下降6.91%和16.93%，直接拖累公司整体营收下降10.44%，经营活动现金流净额更是骤降71%。
- **[2024年发行消费REITs产生高基数投资收益]** -> [2025年归母净利润同比暴跌59.74%]: 2024年公司因发行华安百联消费REIT确认了巨额非经常性投资收益，导致2025年归母净利润在扣除此项后，从15.67亿骤降至6.31亿，核心盈利能力并未同步恶化。
- **[复兴岛地块收储确认大额资产处置收益]** -> [支撑当期利润]: 公司对共青路三幅地块进行收储，确认了6.01亿元的资产处置收益，成为2025年利润的重要补充，掩盖了主营业务盈利能力的疲软。
- **[奥莱业态逆势增长]** -> [成为核心增长引擎]: 在百货、超市业态普遍下滑的背景下，奥特莱斯业态营收同比增长5.67%，毛利率提升1.43个百分点，显示出强大的抗周期能力和品牌运营优势。
- **[大量现金转为定期存款]** -> [投资活动现金流大幅流出]: 公司将大量货币资金转为一年以上到期的定期存款，导致货币资金减少41.68%，其他非流动资产暴增411%，投资活动现金净流出125.6亿元。
- **[存量物业改造与资产盘活]** -> [重塑空间价值与资本结构]: 公司持续推进青浦奥莱二期、永安百货转型等存量项目升级，同时通过REITs、类REITs等资产证券化工具盘活资产，培育第二增长曲线。
- **[持有大量金融资产]** -> [利润受资本市场波动影响]: 公司持有超86.8亿元的交易性金融资产和其他权益工具投资，其公允价值变动（+6604万）和投资收益（+9426万）对当期利润有显著影响，增加了业绩的波动性。

## 风险警告
**核心风险在于主营业务的结构性衰退与利润的高度非经常化。** 联华超市作为营收基石，其大卖场和标准超市业态营收持续双位数下滑，且已陷入亏损（净利润-1.77亿元），表明传统超市业务正被社区团购、生鲜电商等新渠道加速侵蚀。公司整体营收与经营现金流的大幅萎缩，直接反映了核心零售业务的造血能力正在减弱。2025年归母净利润的“腰斩”并非偶然，而是剔除了2024年REITs发行这一不可持续收益后的必然结果，扣非净利润仅1.04亿元，真实盈利能力堪忧。

**公司利润对资产处置和金融投资收益的依赖度过高，可持续性存疑。** 2025年利润主要依赖复兴岛地块收储（6.01亿）和金融资产收益（约1.6亿），而核心业务贡献微薄。同时，公司持有大量金融资产（超86亿），其公允价值变动与市场行情高度绑定，未来若资本市场下行，将直接冲击利润表。此外，公司资产负债率高达61.23%，且存在大量受限资产（51.6亿），财务弹性受限。在消费复苏不及预期、行业竞争加剧的背景下，若资产处置和资本运作节奏放缓，公司业绩将面临巨大压力。
