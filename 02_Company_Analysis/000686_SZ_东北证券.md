# 000686.SZ 深度透视

## 因果逻辑链
- **[市场交投活跃度提升]** -> [经纪业务收入增长]: 2025年A股市场交投活跃度创历史新高，公司AB股基交易量同比增长103.65%，带动手续费及佣金净收入增长14.35%。
- **[融资融券业务规模扩张]** -> [利息净收入大幅增长]: 公司融资融券余额达184.35亿元，同比增长30.79%，推动利息净收入同比增加190.81%。
- **[衍生金融工具公允价值增加]** -> [公允价值变动收益扭亏]: 公司股指期权和收益互换投资规模增加，衍生金融资产公允价值变动收益5.2亿元，带动公允价值变动收益同比增加520.20%。
- **[权益自营业务把握结构性机会]** -> [证券投资业务贡献稳定收益]: 公司坚持红利、价值、成长等差异化策略，权益自营业务实现较好投资回报，证券投资业务营业利润率高达89.06%。
- **[私募集合资管规模创新高]** -> [资产管理业务收入增长]: 东证融汇私募集合资管规模增至521.56亿元，同比增长27.26%，推动资产管理业务收入同比增长39.28%。
- **[北交所业务优势巩固]** -> [投行业务差异化竞争]: 公司累计完成北交所首发项目10个，行业排名并列第7位，在中小创新企业投行领域形成特色品牌。
- **[做市业务行业领先]** -> [股转业务市场地位稳固]: 公司累计做市企业68家，数量位列股转系统做市商第1名，持续保持做市业务的市场竞争力。

## 风险警告
**市场与信用风险共振**：公司自营权益类证券及衍生品/净资本比例从19.89%骤升至46.42%，固定收益类证券/净资本比例高达189.11%。在2025年债券市场“低利率、高波动”环境下，利率、汇率、股票价格的任何不利变动都将直接冲击公司投资收益。同时，信用减值损失同比增加238.03%，融资类业务和债券投资的信用风险敞口正在扩大。

**流动性风险指标恶化**：流动性覆盖率从251.58%降至181.44%，净稳定资金率从183.64%降至163.21%，资本杠杆率从19.22%降至16.33%。虽然仍满足监管要求，但三项核心流动性指标同步大幅下滑，反映出公司资产负债期限错配风险上升，短期融资依赖度增加（应付短期融资款同比增长118.10%），在极端市场环境下可能面临流动性压力。
