# 601800.SH 深度透视

## 因果逻辑链
- **[国内基建投资放缓]** -> [营收下降5.29%]: 国内建筑行业增速放缓，基建建设、疏浚业务收入分别下降4.76%和8.79%，拖累整体营收。
- **[海外业务高增长]** -> [对冲国内下行风险]: 海外新签合同额同比增长9.09%，营收同比增长18.27%，占比提升至21.88%，成为核心增长引擎。
- **[毛利率下滑]** -> [利润降幅远超营收]: 综合毛利率下降0.92个百分点至11.37%，叠加信用减值损失扩大至71.92亿元，导致归母净利润暴跌36.92%。
- **[新兴业务快速扩张]** -> [结构转型初见成效]: 能源工程、农林牧渔工程新签合同额分别同比增长50.36%和135.89%，新兴业务贡献占比35%，对冲传统主业下滑。
- **[投资类项目收缩]** -> [现金流改善]: 基础设施投资类项目合同额同比下降31.57%，同时加大资产盘活，经营活动现金流净额同比增加22.60%至153.33亿元。
- **[BOT项目拖累]** -> [运营期持续亏损]: 进入运营期的35个特许经营权项目报告期净亏损23.27亿元，成为利润的重要侵蚀项。
- **[信用减值损失激增]** -> [利润质量承压]: 长账龄应收款项增加导致信用减值损失达71.92亿元，同比增长17.3%，扣非净利润降幅（-43.48%）远超净利润降幅。

## 风险警告
**核心风险在于国内基建“达峰下行”与公司高杠杆运营模式的矛盾。** 公司营收与利润双降，毛利率持续走低，而资产负债率攀升至76.83%，短期借款激增43.39%。大量BOT项目进入运营期却持续亏损（净亏损23.27亿元），叠加长账龄应收款导致的巨额信用减值，表明公司资产周转效率和盈利质量正面临严峻挑战。若国内基建投资持续疲软，公司“以量补价”的策略将难以为继。

**海外业务虽为增长亮点，但地缘政治与汇率风险不容忽视。** 公司海外业务占比已超20%，且高度集中于“一带一路”沿线国家。这些地区政治经济环境复杂，汇率波动剧烈（报告期汇兑损失已导致财务费用由净收益转为净亏损）。同时，海外业务毛利率（9.76%）低于国内（11.74%），规模扩张并未带来同等利润贡献，存在“增收不增利”的风险。
