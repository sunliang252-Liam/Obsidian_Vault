# 600284.SH 深度透视

## 因果逻辑链
- **[区域基建市场承压与竞争加剧]** -> [营收与利润双降]: 2025年公司营业收入同比下降23.35%，归母净利润同比下降40.48%，核心原因是区域市场开拓不及预期，施工工作量减少。
- **[施工主业收入下滑]** -> [整体业绩拖累]: 施工工程项目收入同比下降24.00%，占公司总营收96.41%，是导致公司整体业绩下滑的最主要因素。
- **[设计勘察业务萎缩]** -> [利润贡献减弱]: 设计勘察咨询业务收入同比下降35.35%，毛利率下降7.03个百分点，主要受离职补偿成本增加影响，进一步削弱了公司盈利能力。
- **[园区运营业务逆势增长]** -> [业绩结构优化]: 园区综合开发业务收入同比增长74.22%，毛利率大幅提升109.66个百分点，成为公司转型亮点，但体量尚小，难以对冲主业下滑。
- **[经营活动现金流大幅转正]** -> [财务风险降低]: 经营活动现金流净额由负转正，达到12.73亿元，主要得益于购买商品、接受劳务支付的现金大幅减少，改善了公司流动性。
- **[有息负债减少与利率下降]** -> [财务费用显著降低]: 财务费用同比下降60.52%，主要系公司有息负债规模减少及借款利率下降，对利润形成正向支撑。
- **[非经常性损益依赖度高]** -> [利润质量存疑]: 扣非后净利润同比下降45.72%，非经常性损益（委托理财收益等）占归母净利润比重达26.97%，核心业务盈利能力下滑更为严重。
- **[新签合同额下滑]** -> [未来收入增长承压]: 报告期内累计新签合同额139.74亿元，较上年同期有所下降，预示着未来1-2年公司收入增长动力不足。

## 风险警告
**核心风险在于主业萎缩与转型阵痛。** 公司传统施工业务受区域基建投资放缓、市场竞争加剧影响，收入与利润双双大幅下滑，且新签合同额下降，预示着未来业绩增长动力不足。公司向“科技型全产业链运营商”转型虽初见成效（园区业务增长），但体量尚小，短期内无法弥补主业缺口，转型过程存在不确定性。

**利润质量与现金流风险需警惕。** 公司扣非净利润降幅远超营收降幅，且非经常性损益（理财收益等）占比过高，表明核心业务盈利能力恶化。尽管经营性现金流大幅转正，但主要源于支出端的压缩，而非收入端的改善，可持续性存疑。同时，公司面临应收账款回收周期长、原材料价格波动等建筑行业固有风险，需持续关注。
