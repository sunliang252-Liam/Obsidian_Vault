# 002062.SZ 深度透视

## 因果逻辑链
- **[行业“国进民退”加剧]** -> [营收承压]: 头部央企市占率持续提升，民营建筑企业面临订单与利润双重挤压，公司营收同比下降2.99%。
- **[新能源业务高增长]** -> [结构优化]: 新能源开发业务收入同比大增30.87%，毛利率提升12.81个百分点，成为对冲传统基建下滑的核心增长极。
- **[经营活动现金流大幅改善]** -> [财务稳健]: 建筑主业及新能源回款增加，经营现金流净额同比暴增157.17%至11.31亿元，显著优于净利润表现。
- **[房地产去库存战略]** -> [收入骤降]: 公司近年无新增开发项目，存量房产销售接近尾声，房地产业务收入同比下滑69.94%，对整体营收形成拖累。
- **[深耕长三角区域]** -> [客户集中度风险]: 华东地区收入占比高达89.04%，区域依赖度极高，其他地区业务拓展缓慢，形成结构性风险。
- **[“建筑+新能源+科技”多矩阵布局]** -> [新增长曲线]: 公司正从单一施工总包向EPC总包、电站运营、高端制造转型，旨在构建多元化盈利模式。
- **[应收账款及合同资产高企]** -> [减值风险]: 两者合计占流动资产比例高，尽管客户为对公业务，但宏观环境变化仍可能引发信用减值损失。

## 风险警告
**核心风险在于区域与客户的高度集中。** 公司89%的收入依赖长三角地区，前五大客户贡献近半营收，且客户以地方政府及国企为主。一旦该区域基建投资增速放缓或地方财政承压，公司将面临订单萎缩和回款周期拉长的双重打击。尽管公司尝试向西藏、新疆等区域拓展，但短期内难以改变这一结构性依赖。

**转型不及预期是另一重大风险。** 公司正大力拓展新能源和科技业务，但新能源业务目前仍以EPC和电站运营为主，毛利率虽高但规模尚小；科技业务（如盾构换刀、隧道测量）目标客群受限，商业化落地存在不确定性。若新业务无法快速形成规模效应，将难以弥补传统基建下滑和房地产出清带来的利润缺口。
