# 002628.SZ 深度透视

## 因果逻辑链
- **[基建行业寒冬，新签合同激增]** -> [营收增长10.87%]: 公司2025年新签合同金额9.5亿元，同比大增161.71%，但行业整体下行，营收增长主要依赖房建施工（+448.12%）和三亚棚改项目贡献超三成产值，传统公路市政业务收入反而下降21.66%。
- **[应收账款回收困难，非现金回款增加]** -> [经营性现金流大幅恶化至-2.07亿元]: 已完工项目收款虽增长23%，但达宣项目等以非现金方式回款，叠加银行冻结资金增加，导致经营性现金流净额同比暴跌499.34%，远低于净利润水平。
- **[收购萤石矿，战略转型起步]** -> [新增矿业收入，但尚未贡献利润]: 2025年7月收购四川宇康矿业，获得西南地区单体规模较大的萤石矿（CaF₂资源量231万吨），报告期内仅实现少量萤石矿销售收入，矿山尚处建设筹备阶段，未取得安全生产许可证。
- **[投资收益大幅增长]** -> [亏损收窄]: 投资收益达1.73亿元（主要为项目投资收益），是公司亏损从-9217万收窄至-7860万的关键因素，掩盖了主业盈利能力持续恶化的现实。
- **[信用减值损失持续扩大]** -> [侵蚀利润]: 2025年信用减值损失达1.24亿元，较上年增加26.6%，主要因业主支付能力下降，应收账款坏账准备计提增加，成为亏损的核心原因之一。
- **[组织架构精简，降本增效]** -> [管理费用基本持平]: 总部职能部门从14个缩减至9个，但管理费用仍维持在1.02亿元，人均营收效率低于行业平均水平，降本效果尚未充分体现。
- **[历史遗留项目推进缓慢]** -> [资产周转效率低下]: 宜宾南溪PPP项目、达宣项目审计、遵义大道项目停滞等重大投资项目进展迟缓，长期占用资金，影响资源配置效率和资产质量。

## 风险警告
**核心风险在于现金流断裂与资产质量恶化。** 公司经营性现金流净额为-2.07亿元，已连续两年为负，且恶化速度远超亏损幅度。应收账款、合同资产及长期应收款合计占资产总额的68.73%，而信用减值损失高达1.24亿元，坏账风险仍在加速暴露。更严峻的是，公司货币资金仅1.18亿元，其中超6000万元因诉讼冻结，实际可动用现金不足6000万元，短期偿债压力巨大。

**战略转型存在重大不确定性。** 公司寄予厚望的萤石矿业务尚处建设筹备期，安全生产许可证办理时间不确定，小洞子铅锌矿采矿权已过期，续期存在风险。矿业板块短期内无法贡献利润，反而需要持续投入。同时，与优必选等合作的智能交通业务尚处早期，商业化前景不明。在传统主业持续亏损、现金流枯竭的背景下，多元化转型可能进一步加剧资金压力，而非化解风险。
