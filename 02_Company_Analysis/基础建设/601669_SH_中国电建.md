# 601669.SH 深度透视

## 因果逻辑链
- **[能源电力新签合同高增]** -> [营收微增]: 能源电力新签合同同比增长10.33%至8416亿元，但受制于传统基建收缩与行业竞争加剧，整体营收仅增长1.85%。
- **[新能源装机规模快速扩张]** -> [电力运营毛利率下滑]: 太阳能装机同比大增35.09%，但电力市场化改革与平价上网导致上网电价下降，电力投资与运营毛利率同比减少3.32个百分点。
- **[国际业务爆发式增长]** -> [利润结构优化]: 境外新签合同同比增27.84%，境外净利润同比增68.37%，贡献公司整体净利润的25.05%，成为利润增长核心引擎。
- **[战略性新兴产业崛起]** -> [第二增长曲线形成]: 战新产业新签合同占比超50%、营收贡献突破40%，在基建市场承压下行阶段，成功对冲传统业务下滑风险。
- **[财务费用大幅攀升]** -> [利润侵蚀]: 财务费用同比增15.12%，主要系汇兑净损失增加，导致归母净利润同比下降16.75%，扣非净利润同比下降24.10%。
- **[经营活动现金流改善]** -> [资金回笼能力增强]: 经营活动现金流净额同比增25.05%至306.97亿元，主要得益于公司多措并举加大资金回笼，但“两金”高企风险未根本缓解。
- **[投资规模主动收缩]** -> [负债端压力缓解]: 投资计划完成率仅67.61%，同比减少37.72%，公司主动控制投资规模、降负债、防风险，筹资活动现金流净额同比减少56.33%。

## 风险警告
**核心风险在于“增收不增利”与“现金流错配”。** 公司营收微增但归母净利润大幅下滑16.75%，扣非净利润更是下滑24.10%，主因是传统建筑业务毛利率持续压缩（工程承包毛利率降至10.24%），叠加财务费用因汇兑损失激增。尽管经营活动现金流改善，但投资活动现金净流出仍高达411亿元，且受限资产高达2504亿元，资金周转效率承压。新能源运营业务虽规模扩张，但电价下行趋势明确，毛利率已现拐点（新能源毛利率同比降9.30个百分点），未来盈利增长面临天花板。

**国际化经营与“两金”风险是潜在雷区。** 国际业务虽高增，但地缘政治冲突、贸易保护主义及汇率波动风险持续存在，境外项目融资难度与合规成本上升。同时，公司“两金”（应收账款+合同资产）规模随业务增长持续攀升，地方政府财政压力下回款不确定性增加，若不能有效压降，将严重侵蚀现金流质量与资产安全性。公司主动收缩投资规模虽有助于降杠杆，但也意味着未来增长动能可能放缓。
