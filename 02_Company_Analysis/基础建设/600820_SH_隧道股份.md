# 600820.SH 深度透视

## 因果逻辑链
- **[传统施工业务收入下滑]** -> [总营收同比下降15.82%]: 作为收入占比79%的核心主业，施工业务收入同比大幅下降20.30%，直接拖累整体营收从688亿降至579亿。
- **[营收下降叠加固定成本刚性]** -> [净利润同比下降22.07%]: 营收下降15.82%的同时，管理费用、研发费用等刚性支出降幅有限，导致利润下滑幅度（22.07%）显著大于营收降幅。
- **[施工业务毛利率微降]** -> [主业盈利能力承压]: 施工业务毛利率仅下降0.1个百分点至6.86%，但低毛利特征意味着收入波动对利润的冲击被放大。
- **[数字信息业务营收翻倍增长]** -> [新兴业务贡献增量]: 数字信息业务营收同比大增136.49%至9.49亿元，成为公司转型和增长的新亮点，但体量尚小。
- **[融资租赁业务营收增长49.24%]** -> [类金融业务提供稳定利润]: 融资租赁业务营收增长至6.8亿元，且毛利率100%，成为利润的重要稳定器。
- **[经营活动现金流净额骤降52.21%]** -> [回款压力显著加大]: 销售商品、提供劳务收到的现金大幅减少，导致经营性现金流从45.87亿降至21.92亿，反映出下游客户付款周期拉长或项目结算放缓。
- **[投资活动现金流由正转负]** -> [资本开支与对外投资增加]: 投资活动现金流净额从25.37亿净流入转为-20.55亿净流出，主要系本期投资额增加，包括认购外高桥定增等。
- **[新签订单维持千亿规模]** -> [未来收入有基础保障]: 全年新签各类订单1030.41亿元，与上年持平，为未来1-2年的收入转化提供了基础，但订单转化为收入的效率是关键。

## 风险警告
公司面临的核心风险在于传统施工业务的持续萎缩与现金流恶化。2025年营收与净利润双降，且经营性现金流净额骤降超50%，表明公司不仅面临行业增速放缓的挑战，更在项目回款上面临严峻压力。大量资产（约392亿元）因质押借款而受限，财务弹性受限，若回款问题持续，可能引发流动性风险。

此外，公司业务高度集中于上海地区（营收占比62%），区域集中度风险较高。同时，在手订单中多个重大项目（如昆明地铁、武汉两湖隧道）进度严重滞后于预期，存在项目延期、成本超支甚至坏账的风险。虽然公司积极布局数字信息等新兴业务，但体量尚小，短期内难以对冲传统主业的下滑，转型阵痛期可能较长。
