# 603955.SH 深度透视

## 因果逻辑链
- **[新业务扩张（宠物+文旅）]** -> [营收暴增217%，但净利润巨亏1.23亿]: 新业务（宠物、文旅）带来收入规模快速膨胀，但高昂的营销、管理及研发投入（销售费用增长27倍）吞噬了利润，导致增收不增利。
- **[传统生态建设业务回款恶化]** -> [经营活动现金流净流出1.78亿]: 地方政府财政支付压力导致工程款回收周期拉长，尽管营收增长，但现金流入远不及流出，现金流状况急剧恶化。
- **[宠物业务尚处投入期]** -> [子公司千宠家科技亏损6641万]: 新设宠物业务处于门店快速扩张和品牌建设阶段，前期投入巨大，尚未实现盈利，成为当期亏损的主要来源。
- **[信用减值损失激增]** -> [净利润进一步承压]: 因应收账款账龄增长及新业务应收款增加，计提信用减值损失5710万元，同比由正转负，直接侵蚀利润。
- **[控股股东全额认购定增]** -> [构建资金安全垫，彰显转型决心]: 公司启动再融资，控股股东苏州步步高拟全额认购不超过7.17亿元，为业务扩张提供资金保障，并传递积极信号。
- **[PPP项目融资收益减少]** -> [财务费用负值收窄]: 随着PPP项目进入运营期，前期确认的融资收益（利息收入）减少，导致财务费用（负值）较上年同期下降，对利润的正面贡献减弱。
- **[“工程建设+文旅运营+宠物消费”三轮驱动]** -> [业务结构发生根本性变化]: 宠物业务贡献36.97%营收，生态建设占比降至36.82%，公司从单一生态园林企业转型为多元消费服务商。

## 风险警告
**核心风险在于新业务“烧钱”扩张与现金流枯竭的赛跑。** 公司营收暴增但巨亏，经营活动现金流净流出1.78亿元，造血能力严重不足。宠物业务尚处大规模投入期，门店扩张、品牌营销、供应链建设均需持续“烧钱”，若无法在短期内实现盈亏平衡或获得外部融资（定增尚在审核），公司将面临严峻的资金链压力。同时，传统生态建设业务回款持续恶化，应收账款和长期应收款高企，信用减值风险高悬，进一步加剧了财务脆弱性。

**转型不确定性极高，新业务竞争激烈且尚未验证盈利模式。** 宠物行业虽市场广阔，但竞争已白热化，公司作为跨界新进入者，面临品牌、渠道、供应链等多重挑战。宠物业务目前毛利率仅10.99%，远低于传统文旅业务，且亏损严重。公司能否在激烈的市场竞争中跑通“线下体验+线上销售”模式，实现规模化盈利，存在巨大不确定性。一旦转型受阻，公司将陷入主业萎缩、新业务失利的双重困境。
