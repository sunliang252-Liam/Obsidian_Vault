# 601611.SH 深度透视

## 因果逻辑链
- **[核电规模化发展]** -> [核电营收增长16.96%]: 连续4年每年核准10台以上机组，公司作为唯一41年不间断核电建造商，承建36台在建机组，订单与营收双创新高。
- **[主动收缩低毛利民建]** -> [民用工程营收下降23.78%]: 公司主动优化业务结构，聚焦高附加值领域，导致整体营收下降10.24%，但毛利率微增0.42个百分点。
- **[加强现金流管控]** -> [经营现金流由负转正]: 通过强化回款管理，经营活动现金流净额从-33.4亿元改善至0.06亿元，但绝对值仍极低。
- **[子公司市场化债转股]** -> [少数股东权益暴增59.25%]: 引入外部投资者，少数股东权益从110.94亿增至176.68亿，稀释了归母净利润占比。
- **[子公司引入投资者与权益融资]** -> [归母净利润下降36.10%]: 尽管核电业务强劲，但民建收缩叠加少数股东权益稀释，导致归母净利润从20.64亿降至13.19亿。
- **[“大后方、小前方”智能建造]** -> [核岛工效提升12%]: 模块化施工与数字化管理落地，推动建造效率与品质同步提升，巩固核心竞争力。
- **[预计负债激增1504.78%]** -> [法律诉讼风险显性化]: 子公司根据诉讼结果计提预计负债，从0.17亿飙升至2.66亿，反映法律纠纷化解压力巨大。

## 风险警告
**核心风险在于盈利质量与现金流的严重背离。** 公司营收超千亿，但经营活动现金流净额仅0.06亿元，几乎为零。这揭示了建筑行业“垫资施工、回款周期长”的顽疾，叠加公司主动收缩民建业务，短期阵痛明显。更关键的是，归母净利润同比暴跌36%，而少数股东权益暴增59%，说明利润正被子公司层面的外部投资者大量稀释，上市公司股东实际获益能力在下降。

**法律与资产风险不容忽视。** 预计负债同比暴增15倍至2.66亿元，主要源于诉讼纠纷，公司也明确承认“法律纠纷案件数量与金额相对较高”。同时，公司受限资产高达347亿元，占总资产近15%，大量资产被用于质押或冻结，财务弹性受限。在行业下行周期中，这些隐性风险可能随时引爆，侵蚀本已脆弱的利润。
