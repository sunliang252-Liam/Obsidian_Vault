## 因果逻辑链
- **[新签合同执行早期]** -> [营业收入下降3.70%]: 报告期内新签合同处于执行早期，按投入法计算的履约进度偏低，导致当期确认收入减少。
- **[业主资金拨付减少]** -> [经营活动现金流骤降98.66%]: 公司收到业主拨付资金减少，同时为保障供应链稳定正常支付供应商款项，导致现金流大幅恶化。
- **[流动资金需求增加]** -> [短期借款增长42.88%]: 为满足承建项目对流动资金的需求，公司大幅增加短期借款筹资规模，期末余额达45.24亿元。
- **[省内市场守土尽责]** -> [订单结构稳定]: 全年省内订单占比稳定在60%以上，依托区域龙头优势保障核心市场份额，筑牢经营基本盘。
- **[省外市场破局见效]** -> [国内订单增长11.35%]: 主动拓展山东、新疆、河南等省外区域，落地多个亿元级项目，有效对冲区域市场波动风险。
- **[精细化管理降本]** -> [管理费用下降5.20%]: 公司开展“降本节耗、提质增效”专项行动，优化压降费用，管理费用同比减少。
- **[研发投入持续]** -> [技术实力提升]: 全年研发投入5.84亿元，占比3.32%，获得多项科技进步奖，并通过碳管理体系认证，巩固技术护城河。
- **[PPP/BOT项目集中]** -> [长期应收款与投资压力]: 公司大量参与PPP/BOT项目，导致长期股权投资和应收款规模较大，资金占用周期长，对现金流形成持续压力。

## 风险警告
**核心风险在于经营现金流与债务结构的严重错配。** 2025年经营活动现金流净额仅3538万元，同比暴跌98.66%，而短期借款却激增至45.24亿元，增幅42.88%。这意味着公司主营业务几乎无法产生净现金流入，高度依赖外部融资“借新还旧”维持运营。一旦信贷政策收紧或融资成本上升，公司将面临巨大的流动性压力，财务费用侵蚀利润的风险显著。

**区域集中与客户依赖风险不容忽视。** 公司超60%的订单集中于黑龙江省内，前五大客户销售额占比24.49%，其中关联方销售占比13.51%。这种高度依赖单一区域和关联交易的业务结构，使其业绩极易受到地方财政状况、区域基建投资节奏及关联方履约能力的影响。若地方政府偿付能力下降，将直接导致应收账款回收周期拉长和坏账风险上升。
