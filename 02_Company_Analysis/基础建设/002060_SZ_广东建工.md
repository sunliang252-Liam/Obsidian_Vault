# 002060.SZ 深度透视

## 因果逻辑链
- **[地方政府化债政策导致现金流年度间分布不均]** -> [经营活动现金流净额暴跌196.97%]: 2024年底集中收款，2025年集中支付工程款和采购款，造成现金流大幅逆转。
- **[新疆区域新能源装机增速超电网承载极限]** -> [子公司巴楚粤水电净利润亏损扩大至-1.4亿元]: 限电率攀升叠加外送通道不足，严重侵蚀清洁能源板块利润。
- **[智能装备制造业务放量]** -> [该板块收入同比暴增95.39%]: 风电塔筒、光伏支架等清洁能源装备制造产能释放，成为营收增长新引擎。
- **[工程主业营收微增0.89%]** -> [净利润反降5.07%]: 毛利率较低的工程施工收入占比仍高达88.93%，且发电业务毛利率因利用小时数下降而下滑5.54个百分点。
- **[资产负债率高位运行]** -> [制约清洁能源投资扩张]: 高负债率限制了公司通过贷款进行大规模新能源项目投资的能力，影响“双主业”战略推进。
- **[新能源上网电价市场化改革]** -> [未来电价不确定性增加]: 政策推动风电、光伏电量全部进入市场，存量项目电价面临下行风险，影响发电业务收益稳定性。
- **[研发投入资本化率极低]** -> [当期费用压力大]: 3.41%的研发投入中资本化比例仅0.42%，大部分研发支出直接计入当期损益，压制利润表现。

## 风险警告
**核心风险：现金流断裂与区域消纳危机。** 经营活动现金流净额由正转负，骤降近200%至-34.56亿元，与净利润严重背离。这并非单纯的季节性波动，而是地方政府财政紧张背景下，工程款回收周期拉长的系统性风险。同时，新疆巴楚等核心光伏基地因电网外送能力不足，已出现严重弃光限电，子公司亏损急剧扩大，表明公司重资产投入的清洁能源业务正面临“投产即亏损”的困境。

**次要风险：主业盈利天花板与高负债扩张。** 公司营收高度依赖低毛利的工程施工业务（占比近90%），在基建投资增速放缓的背景下，营收增长已显乏力。为支撑清洁能源扩张，公司资产负债率持续高企，财务费用同比增长8.86%，进一步侵蚀利润。在电价市场化改革和绿电交易价格承压的长期趋势下，公司“工程建设+清洁能源”的双轮驱动模式，正面临“工程不赚钱、能源赚不到钱”的双重挤压。
