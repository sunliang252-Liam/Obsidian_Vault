# 601390.SH 深度透视

## 因果逻辑链
- **[行业投资降速与竞争加剧]** -> [营收与利润双降]: 2025年全国建筑业总产值同比降低10.05%，新签合同额下降5.51%，公司营收同比下降5.77%，归母净利润同比下降17.91%，核心主业承压。
- **[财务费用激增与投融资收益减少]** -> [利润侵蚀]: 财务费用同比大增43.92%，主因是费用化利息支出增加及金融资产模式基础设施投资项目确认的投融资收益减少，直接压缩利润空间。
- **[“第二曲线”与海外市场扩张]** -> [结构性增长对冲]: 新兴业务（水利水电、清洁能源等）新签合同额同比增长11%，境外业务新签合同额同比增长16.5%，有效对冲了传统基建业务的下滑。
- **[大商务管理与降负债行动]** -> [现金流韧性]: 经营活动现金流净额287.72亿元，同比微增2.57%，在利润下滑背景下保持稳定，体现了“效益提升、价值创造”管理举措的成效。
- **[应收账款与合同资产高增]** -> [营运资金压力]: 应收账款同比增长17.34%，合同资产同比增长10.12%，反映业主付款滞后和已完未验项目增加，占用了大量营运资金，加剧现金流风险。
- **[长期应收款与无形资产膨胀]** -> [投资模式下的资金沉淀]: 长期应收款同比增长93.66%，无形资产同比增长18.72%，主要源于基础设施投资项目（PPP等）规模增加，导致大量资金沉淀，资产周转效率下降。
- **[资产负债率攀升]** -> [财务杠杆风险]: 资产负债率升至78.12%，同比增加0.73个百分点，长期借款同比增长14.58%，公司财务杠杆水平持续走高，偿债压力加大。

## 风险警告
**核心风险在于“增收不增利”与“现金回收恶化”的双重挤压。** 公司营收与利润双降，但更值得警惕的是财务费用激增43.92%，直接侵蚀利润。同时，应收账款和合同资产合计超6550亿元，同比大幅增长，而经营性现金流净额仅微增，表明公司大量利润沉淀在“纸面”上，实际现金回收能力严重滞后于业务规模，营运资金周转效率持续恶化。

**资产结构风险加剧，财务杠杆逼近临界点。** 长期应收款和无形资产因PPP等投资模式大幅膨胀，合计超4650亿元，占总资产近19%，这些资产流动性极差，回收周期长。公司资产负债率已攀升至78.12%，长期借款超3730亿元，在利率下行周期中财务费用仍逆势大增，一旦融资环境收紧或项目回款不及预期，公司将面临巨大的流动性压力和债务偿付风险。
