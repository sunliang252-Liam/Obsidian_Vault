# 601868.SH 深度透视

## 因果逻辑链
- **[新能源业务高速扩张]** -> [营收增长3.71%]: 新能源及综合智慧能源新签合同额5925.78亿元，同比增长6.7%，成为收入增长主引擎。
- **[财务费用激增]** -> [归母净利润骤降30.44%]: 融资需求增加及项目竣工停止资本化，财务费用同比飙升24.00%，严重侵蚀利润。
- **[境外业务高增长]** -> [盈利结构优化]: 境外营收同比+34.65%，毛利同比+46.43%，高毛利海外项目成为利润新增长极。
- **[压缩空气储能技术领跑]** -> [新质生产力落地]: “能储一号”全容量并网，创造三项世界第一，推动公司从工程承包向技术运营转型。
- **[战略性新兴产业扩张]** -> [资产结构优化]: 战新产业营收占比提升至40.81%，资产总额同比+37.9%，但短期拉低整体毛利率。
- **[PPP项目回款压力]** -> [现金流承压]: 地方政府偿债能力影响存量PPP项目资金回收，推高“两金”规模，增大短期偿债风险。
- **[火电市场份额绝对领先]** -> [传统业务护城河]: 火电设计市占率超90%，施工份额超70%，为转型提供稳定现金流基础。

## 风险警告
**核心风险在于“增收不增利”的利润陷阱。** 尽管营收增长3.71%，但归母净利润暴跌30.44%，主因是财务费用激增24%至66.7亿元。公司为支撑新能源项目大规模投资（资本支出515亿元），债务规模快速膨胀，资产负债率攀升至77.74%。若融资成本持续高企或项目回报不及预期，利润将被进一步侵蚀，ROE已从7.74%降至5.05%。

**资产质量与现金流存在隐性风险。** 应收账款与合同资产合计超1936亿元，占总资产20.6%，且PPP项目回款受地方政府化债能力制约。经营性现金流净额仅115.5亿元，远不足以覆盖515亿元的资本支出，高度依赖外部融资。房地产去化周期延长及高速公路项目经营不及预期，可能引发个别子公司债务危机，需警惕信用风险传导。
