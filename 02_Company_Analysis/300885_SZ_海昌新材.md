# 300885.SZ 深度透视

## 因果逻辑链
- **[电动工具下游需求疲软]** -> [营收下降10.22%]: 公司78.58%收入来自电动工具零部件，该业务收入同比下滑14.72%，直接拖累整体营收。
- **[MIM业务高速增长]** -> [结构优化对冲PM下滑]: 金属注射成形(MIM)收入增长29.24%，毛利率高达48.03%，成为公司新的利润增长点。
- **[收购信为通讯]** -> [切入卫星通信赛道]: 以2.346亿元收购信为通讯51%股权，2025年超额完成业绩承诺（扣非净利润4,480.85万，完成率117.92%），开启第二增长曲线。
- **[成本领先战略转向差异化战略]** -> [提升长期竞争力]: 公司战略从单纯成本控制转向产品个性化解决方案与全面领先质量，意图提升定价与议价能力。
- **[研发投入持续增长]** -> [巩固技术护城河]: 研发费用同比增长3.38%，承担江苏省前沿技术研发计划，聚焦机器人、新能源汽车用高性能齿轮合金材料。
- **[海外布局加速]** -> [规避贸易风险与贴近客户]: 设立新加坡、越南子公司，推进全球化产能布局，以应对地缘政治和贸易摩擦风险。
- **[客户高度集中]** -> [业绩波动风险敞口大]: 前五大客户收入占比69.19%，第一大客户占比36.35%，单一客户订单波动将显著影响公司业绩。

## 风险警告
**核心风险在于电动工具主业的周期性下滑与客户高度集中。** 公司近八成收入依赖电动工具零部件，而下游两大巨头史丹利百得营收下滑2%，创科实业虽增长但竞争加剧。若全球基建投资不及预期或主要客户订单减少，公司业绩将面临显著压力。前五大客户占比近70%，客户转换成本虽高，但单一客户依赖度极高，议价能力受限。

**收购整合与海外扩张的不确定性是另一大隐忧。** 公司以2.346亿元高溢价收购信为通讯，虽首年超额完成业绩承诺，但后续三年能否持续存疑，且商誉减值风险已埋下伏笔。同时，新加坡、越南子公司的设立面临海外政策、法律、劳工及地缘环境变化等挑战，初期投入大、回报周期长，可能拖累短期盈利能力。
