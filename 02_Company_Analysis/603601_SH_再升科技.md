# 603601.SH 深度透视

## 因果逻辑链
- **[下游需求波动]** -> **收入下滑**: 干净空气材料受市场需求波动影响，收入同比下降18.73%，拖累整体营收下降13.63%。
- **[产品价格下降与成本上涨]** -> **毛利率压缩**: 单位产品价格下降、能源及材料成本上涨，导致综合毛利率减少2.31个百分点，毛利额减少7,358万元。
- **[联营企业业绩下滑]** -> **投资收益锐减**: 联营企业（松下新材料、悠远环境）盈利恶化，投资收益同比减少1,625万元，是利润下滑的核心因素之一。
- **[出口退税政策调整]** -> **成本增加**: 部分产品出口退税率下降导致不退税成本增加，进一步侵蚀了出口业务的利润空间。
- **[新业务战略投入]** -> **费用前置**: 无尘空调业务大力拓展市场，销售费用同比增长22.38%，短期侵蚀利润，但为长期增长铺路。
- **[石英纤维布局]** -> **未来增长点**: 前瞻布局石英纤维等关键战略材料，报告期内尚未形成收入，但旨在突破“卡脖子”技术，培育新增长曲线。
- **[可转债转股]** -> **财务结构优化**: 报告期内“再22转债”大量转股，公司资产负债率从28.33%降至20.67%，财务风险显著降低。
- **[应收账款回收]** -> **现金流改善**: 本期收回应收账款及应收股利，信用减值损失大幅减少，经营活动现金流净额同比增长35.72%至3.04亿元。

## 风险警告
**核心风险在于业绩下滑的持续性。** 公司2025年营收和利润双降，扣非净利润仅1,503万元，同比暴跌73.27%，主业盈利能力已极度薄弱。利润高度依赖非经常性损益（政府补助、理财收益等），若剔除后，公司几乎处于盈亏平衡边缘。下游需求波动、产品价格承压、成本上涨等负面因素若无法逆转，公司基本面将面临严峻考验。

**战略转型的不确定性是另一大风险。** 公司正大力向C端无尘空调和高端石英纤维转型，但新业务尚处投入期，无尘空调虽增长12.32%，但毛利率下降3.59个百分点，且子公司再升净化亏损1,828万元。石英纤维尚未产生收入，技术壁垒高，量产和市场拓展存在巨大不确定性。同时，公司出口业务占比高（约35%），面临国际贸易摩擦和汇率波动的双重风险。
