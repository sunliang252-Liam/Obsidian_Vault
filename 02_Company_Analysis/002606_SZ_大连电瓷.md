# 002606.SZ 深度透视

## 因果逻辑链
- **[特高压建设提速]** -> [营收增长18.92%]: 国家电网特高压直流工程投资同比增长25.7%，公司紧跟甘肃-浙江、大同-天津南等重点项目，全年特高压中标超5亿元，直接拉动悬瓷绝缘子收入增长20.14%。
- **[海外市场爆发]** -> [海外收入增长50.81%]: 全球电网投资周期开启，公司新签海外订单超10亿元，沙特、韩国、意大利等市场批量交付，海外收入占比从18.58%提升至23.56%，成为第二增长极。
- **[产能扩张与三地协同]** -> [产量增长16.43%]: 江西工厂二期全面达产，大连、福建、江西三大基地协同排产，全年悬瓷绝缘子产量达11.68万吨，有效支撑订单集中交付，保障阿坝-成都东线项目提前10个月供货。
- **[绿色数智化转型]** -> [降本增效]: 超创数能推动光伏并网（大连工厂绿电占比35%，江西工厂超80%）、抽屉窑燃气消耗下降13.8%，叠加ERP/MES系统上线，运营效率提升，单位成本得到控制。
- **[原材料成本压力]** -> [毛利率微降2.12个百分点]: 直接材料成本占比从58.84%升至62.01%，氧化铝等原材料价格上涨，叠加悬瓷绝缘子毛利率下降2.73个百分点，侵蚀部分利润空间。
- **[销售费用激增]** -> [费用率上升]: 销售费用同比增长43.46%，主因海外代理费增加，反映海外市场拓展的阶段性投入成本。
- **[现金流大幅改善]** -> [经营现金流净额增长692%]: 销售回款情况显著优于上年同期，经营活动现金流净额从-8334万元跃升至4.94亿元，财务质量实质性好转。

## 风险警告
**核心风险在于宏观政策与地缘政治的双重不确定性。** 公司业绩高度依赖国家电网特高压投资节奏，“十五五”规划虽利好，但若电网投资规模或进度不及预期，将直接冲击订单获取与收入确认。同时，中东市场（沙特为核心增长极）面临美以-伊朗战争导致的航运中断风险，达曼港通行受阻已增加内陆运输成本，若冲突升级，海外订单履约与毛利率将承压。

**经营层面，原材料成本波动与竞争加剧是长期隐忧。** 氧化铝等核心原材料价格易涨难跌，直接材料成本占比持续攀升，而中低端市场受复合/玻璃绝缘子挤压，价格竞争激烈。公司虽在特高压领域有壁垒，但若无法通过技术溢价或规模效应有效传导成本压力，盈利能力将持续承压。此外，海外业务快速扩张带来的代理费激增、汇率波动及人才流失风险，亦需警惕。
