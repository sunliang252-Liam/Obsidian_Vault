# 601698.SH 深度透视

## 因果逻辑链
- **[星链等低轨星座冲击国际业务]** -> [境外收入下降10.64%，毛利率仅0.16%]: 低轨卫星星座加速部署，直接侵蚀公司传统高轨卫星的国际市场空间，导致境外业务几乎无利可图。
- **[高通量卫星（中星26等）投入运营]** -> [扣非净利润大增69.39%]: 新卫星资源带来高通量接入点等新业务增长，推动经营性利润大幅提升，弥补了传统业务下滑。
- **[传统广电业务基本盘稳定]** -> [境内收入增长8.85%，毛利率提升4.62个百分点]: 广电市场作为压舱石，叠加超高清上星等新需求，保障了境内业务的稳健增长和盈利改善。
- **[卫星折旧与摊销成本刚性]** -> [营业成本与收入同步增长，毛利率提升有限]: 卫星资产折旧是主要成本项（占67.94%），其固定成本属性限制了收入增长对利润的放大效应。
- **[购买结构性存款增加]** -> [财务费用（利息收入）减少，经营活动现金流下降25.23%]: 公司将大量现金转向理财产品，导致利息收入减少，同时经营性收款减少，共同拖累现金流表现。
- **[卫星资源建设从“天地统筹”转向“网络能力供给”]** -> [在建工程大幅减少76.36%，固定资产增加10.20%]: 中星10R、9C等卫星完成建设并转固，标志“十四五”空间资源建设主体任务收官，公司重心转向网络运营。
- **[控股股东发行可交换债券进入换股期]** -> [股东结构潜在变动，市场关注度提升]: 61亿元可交债换股期开启，控股股东持股比例存在被动稀释可能，增加了股价波动的不确定性。

## 风险警告
**核心风险：低轨卫星星座（尤其是Starlink）的降维打击。** 公司境外业务已出现量价齐跌（收入降10.64%，毛利率仅0.16%），传统高轨卫星的带宽成本和时延劣势在低轨大规模组网面前愈发明显。若国内低轨星座（如“千帆星座”）加速商业化，公司的高通量卫星业务也将面临激烈竞争，市场开拓风险极高。

**财务风险：资产重、现金流恶化、增长乏力。** 公司总资产224亿，但净资产收益率仅2.79%，资产回报效率低下。经营活动现金流净额同比大幅下降25.23%，而投资活动现金净流出高达25亿（主要用于购买理财和卫星建设），显示主业造血能力减弱，增长依赖外部投资。扣非净利润大增主要源于低基数，整体营收增速仅4.08%，增长天花板明显。
