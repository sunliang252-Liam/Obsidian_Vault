# 600879.SH 深度透视

## 因果逻辑链
- **[客户付款政策变化]** -> [经营性现金流大幅恶化]: 客户付款政策变化导致销售回款减少，同时采购支出增加，经营活动现金流净额由-4.03亿元恶化至-10.33亿元。
- **[信用及资产减值损失增加]** -> [归母净利润暴跌58.58%]: 2025年信用减值损失和资产减值损失合计达2.23亿元，较上年大幅增加，直接侵蚀利润，导致归母净利润仅2.27亿元。
- **[处置航天电工股权收益消失]** -> [非经常性损益大幅减少]: 2024年处置航天电工股权带来2.08亿元投资收益，2025年无此收益，导致利润总额同比减少57.60%。
- **[航天电工出表]** -> [营收结构变化]: 航天电工不再纳入合并范围，导致航天技术应用产品收入骤降60.27%，但剔除该因素后，公司核心业务营收实际增长13.78%。
- **[系统装备产品放量]** -> [收入结构优化]: 系统装备产品收入同比增长55.72%，成为公司第二增长曲线，但毛利率下降12.68个百分点，显示该业务仍处于以价换量的扩张期。
- **[“两金”高企]** -> [资产质量承压]: 存货和应收账款合计占总资产比例高达64.81%，且存货规模持续增长，营运资金周转压力巨大，存在存货减值风险。
- **[关联交易依赖度高]** -> [经营独立性风险]: 前五名客户销售额中关联方占比56.65%，对航天科技集团存在高度依赖，议价能力和经营自主性受限。

## 风险警告
公司面临的核心风险是**营运资金周转困境与利润质量恶化**。经营活动现金流净额为-10.33亿元，而“两金”（存货+应收账款）占总资产比例高达64.81%，存货规模达227.74亿元，应收账款达88.34亿元。客户付款政策变化导致回款困难，公司不得不依赖借款维持运营，财务费用虽同比下降但仍达1.24亿元。若回款持续恶化，公司可能面临流动性危机。

利润端同样堪忧。2025年归母净利润仅2.27亿元，同比暴跌58.58%，扣非净利润同比下滑5.31%。利润下滑并非一次性因素，而是由**信用及资产减值损失常态化增加**和**核心业务毛利率承压**共同导致。系统装备产品毛利率下降12.68个百分点，航天机电组件毛利率下降3.31个百分点，显示公司核心业务正面临成本上升和竞争加剧的双重挤压。此外，公司对航天科技集团的关联交易依赖度极高（销售占比56.65%），在军品竞争性采购改革背景下，其定价权和市场份额面临不确定性。
