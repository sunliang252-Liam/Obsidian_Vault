# 688282.SH 深度透视

## 因果逻辑链
- **[新定型产品放量订货]** -> [营收增长76.17%]: 某型惯导装置作为独家供应商，订单金额创近三年新高，带动惯性导航系统收入同比大增90.79%。
- **[收购子公司业绩不达标]** -> [净利润亏损923万元]: 宇讯电子、海为科技连续两年未完成业绩承诺，2025年计提商誉减值2,841万元，直接导致净利润由盈转亏。
- **[客户回款周期延长]** -> [信用减值损失增加]: 宇讯电子主要客户资金周转放缓，长账龄应收账款增加，计提信用减值损失829万元，侵蚀当期利润。
- **[买卖合同纠纷]** -> [单项资产减值]: 与盈想东方的诉讼判决及对方信用状况恶化，公司对应收款项和存货计提715万元单项减值准备。
- **[军工行业高壁垒]** -> [订单可持续性]: 公司是**51、**51A等型号惯导系统的唯一供应商，军方无特殊原因不得更换，保障了未来订单的稳定性。
- **[母子公司协同]** -> [市场拓展合力]: 理工导航与宇讯电子、海为科技共享客户资源与渠道，形成协同市场拓展体系，提升整体竞争力。
- **[研发投入下降]** -> [短期费用控制]: 研发费用同比减少22.48%，主要因多个项目进入调试测试阶段，领料减少，但研发投入占营收比仍达12.18%。

## 风险警告
**核心风险在于商誉减值与应收账款坏账的“双杀”**。收购的宇讯电子和海为科技连续两年未完成业绩承诺，已累计计提商誉减值3,454万元，若未来业绩持续不及预期，剩余5,349万元商誉面临进一步减值风险，将直接冲击利润表。同时，宇讯电子客户回款周期显著延长，导致应收账款高企（净额3.97亿元，占总资产24.6%），信用减值损失持续扩大，现金流已由正转负（-4,143万元），经营质量堪忧。

**单一客户依赖与军工订单波动风险**。公司第一大客户（兵器集团）收入占比高达62%，产品结构单一，高度依赖远程制导弹药配套。尽管当前新定型产品放量，但军工采购受国防预算、战略调整及产业链产能影响极大，2022-2023年曾因上游配套厂商产能短缺导致订单骤降。若未来客户需求或产业链再次波动，公司业绩将面临剧烈下滑风险。
