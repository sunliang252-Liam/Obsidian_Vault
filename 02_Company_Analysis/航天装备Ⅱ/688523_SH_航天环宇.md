# 688523.SH 深度透视

## 因果逻辑链
- **下游客户压价与产品结构变化** -> **综合毛利率下降6.9个百分点**: 宇航产品销售价格下降及高毛利产品交付减少，直接侵蚀利润空间。
- **研发费用大幅增长34.75%** -> **净利润腰斩（-53.14%）**: 公司为抢占商业航天、大飞机等新兴市场，大幅增加研发投入，但短期未能转化为收入。
- **航空产品收入增长56.75%** -> **部分弥补宇航及工装业务下滑**: 航空复材零部件形成小批量交付，成为收入增长核心引擎，但体量尚不足以对冲整体下滑。
- **航空航天工艺装备收入下降42.47%** -> **拖累整体营收**: 承接任务生产周期长，报告期内未能交付，导致该板块收入大幅萎缩。
- **经营活动现金流净额暴增213.88%** -> **盈利质量改善**: 销售回款增加，现金循环效率提升，但利润与现金流的背离显示利润下滑主要源于非现金因素（折旧、减值）及费用前置。
- **固定资产增加50.38%** -> **折旧摊销压力加大**: 长沙及自贡航空产业园项目转固，长期资产规模扩大，未来折旧将刚性侵蚀利润。
- **客户高度集中（前五大占78.29%）** -> **经营依赖性强**: 业绩高度绑定中航工业、中国商飞等央企，单一客户订单波动即可引发业绩剧烈震荡。

## 风险警告
**核心风险在于“增收不增利”与“投入产出错配”。** 公司营收仅下滑9.79%，但净利润暴跌53.14%，主因是毛利率下滑与研发费用激增。这表明公司正面临下游客户压价与自身为抢占未来市场而被迫加大投入的双重挤压。长沙、自贡产业园的转固将带来持续的折旧压力，若新业务（商业卫星、大飞机复材）的规模化量产与订单兑现不及预期，公司盈利能力将持续承压。

**另一重大风险是客户集中度极高与军工订单的不确定性。** 公司前五大客户销售额占比近80%，且部分产品采用暂定价合同，未来审价差异可能导致收入大幅波动。同时，航空产品业务高度依赖下游主机厂型号的定型批产进度，若型号延迟或客户需求变化，将直接导致公司产能空转与存货减值风险。公司虽为专精特新“小巨人”，但在军工产业链中议价能力相对有限。
