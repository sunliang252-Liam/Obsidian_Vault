# 688818.SH 深度透视

## 因果逻辑链
- **[宇航电源业务增长]** -> [营收增长5.10%]: 宇航电源收入同比增长13.63%，是公司营收增长的核心引擎，但特种电源收入大幅下滑41.59%拖累了整体增速。
- **[特种电源业务萎缩]** -> [扣非净利润下降7.32%]: 特种电源收入锐减且毛利率暴跌12.65个百分点至0.46%，严重侵蚀利润，导致增收不增利。
- **[客户高度集中]** -> [经营风险集中]: 第一大客户收入占比高达53.39%，公司业绩高度依赖单一客户，议价能力和抗风险能力弱。
- **[高研发投入]** -> [技术壁垒巩固]: 研发费用占营收6.60%，持续投入使公司在砷化镓太阳电池、空间锂离子电池等核心领域保持国际先进水平，但短期未转化为利润增长。
- **[应收账款高企]** -> [现金流压力]: 应收账款净额23.36亿元，同比增长12.26%，远超营收增速，占用大量营运资金，是经营现金流改善但仍为负值的主要原因。
- **[暂定价机制]** -> [业绩不确定性]: 部分合同以暂定价确认收入，后续审价调整可能导致收入与利润大幅波动，是潜在的重大业绩变数。
- **[商业航天机遇]** -> [未来增长点]: 公司已获得低轨通信、遥感等商业航天项目，正从“定制化科研配套”向“批量化产业配套”转型，有望打开第二增长曲线。

## 风险警告
**核心风险在于“增收不增利”与“客户过度集中”的双重挤压。** 公司营收增长5.10%，但扣非净利润却下降7.32%，主因是毛利率仅0.46%的特种电源业务大幅萎缩，拖累整体盈利质量。同时，第一大客户收入占比超53%，这种高度依赖使得公司在定价、回款等方面处于弱势，一旦客户采购策略调整，业绩将面临剧烈波动。

**财务健康度存在隐患，应收账款与存货风险不容忽视。** 应收账款规模高达23.36亿元，且增速远超营收，回款压力巨大。此外，存货跌价风险与暂定价合同带来的业绩波动风险，共同构成了公司财务层面的“灰犀牛”。公司虽在商业航天领域有所布局，但短期内难以对冲传统业务的下滑与高企的信用风险。
