# 003009.SZ 深度透视

## 因果逻辑链
- **[光伏行业产能过剩、价格战加剧]** -> [炭/炭热场材料业务巨亏]: 下游硅片厂商开工不足、需求萎缩，叠加行业竞争白热化，导致公司热场材料销量与售价双降，毛利率由正转负（-40.80%），成为全年亏损的最大拖累。
- **[军品客户交付节奏波动]** -> [军用小型固体火箭收入腰斩]: 受军贸及国内军品订单交付周期影响，该板块收入同比骤降54.04%，高毛利产品占比下降，拖累整体盈利。
- **[增雨防雹火箭需求爆发]** -> [人影业务逆势增长]: 受益于国债项目落地及地方防灾需求，人影火箭及配套装备收入同比增长39.87%，毛利率提升9.58个百分点，成为唯一正增长的核心主业。
- **[计提大额资产及信用减值]** -> [净利润由盈转亏]: 基于谨慎性原则，对炭/炭热场材料相关固定资产及存货计提减值9,209万元，叠加军贸应收账款信用减值1,227万元，合计减少净利润超1亿元，是亏损的直接财务原因。
- **[可转债利息费用化增加]** -> [财务费用飙升]: 募投项目转固后，可转债利息不再资本化，导致财务费用同比暴增1,525%，侵蚀利润。
- **[研发投入持续高企]** -> [短期利润承压但长期竞争力筑基]: 研发费用占营收比超9%，重点投向无人机、碳陶刹车盘、制导火箭等新增长极，虽短期加重亏损，但为未来业务转型储备技术。
- **[智能计重系统业务萎缩]** -> [测控业务转型阵痛]: 传统称重业务受政策调整冲击，收入同比暴跌90.82%，毛利率为-277.93%，转型至非现场执法系统尚未形成规模，拖累整体业绩。

## 风险警告
公司当前最大风险在于**炭/炭热场材料业务的深度亏损**。光伏行业产能出清周期尚未结束，产品价格持续承压，公司该板块已陷入“越卖越亏”的困境。若下游需求无法回暖或公司降本增效不及预期，该业务将持续侵蚀现金流与净资产，甚至可能触发进一步的资产减值。此外，公司对军品业务的依赖度较高，而军品订单受国防预算、国际局势及客户交付节奏影响，波动性极大，2025年军用火箭收入腰斩即为明证，业绩稳定性存疑。

第二重风险来自**财务与现金流压力**。公司可转债利息费用化导致财务费用激增，叠加经营亏损，2025年经营活动现金流净额已大幅下降76.85%。若亏损延续，公司将面临偿债能力下降与融资成本上升的双重压力。同时，公司应收账款规模庞大（4.55亿元），且军贸产品回款周期长，信用减值风险持续高企。尽管人影业务和耐烧蚀组件业务表现亮眼，但体量尚不足以对冲核心业务的系统性风险，公司整体处于“主业承压、新业务待哺”的脆弱平衡中。
