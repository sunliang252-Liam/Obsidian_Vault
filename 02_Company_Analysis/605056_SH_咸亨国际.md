# 605056.SH 深度透视

## 因果逻辑链
- **[电网“十五五”投资规划大幅增长]** -> [电网业务收入稳健]: 国家电网“十五五”投资4万亿（较“十四五”增40%），公司作为核心MRO供应商直接受益，电网基本盘稳固。
- **[复刻电网成功模式至新兴行业]** -> [五大战略行业收入高增42.62%]: 公司将电网领域的属地化服务、场景深耕能力复制到油气、发电、交通等领域，实现非电业务快速扩张。
- **[“树人”文化与利益共同体机制]** -> [非标化服务能力壁垒]: 通过股权激励、高分红、长期雇佣（司龄10年以上368人）激发员工主观能动性，形成难以复制的非标化解决方案能力。
- **[具身智能前瞻布局]** -> [开辟第二增长曲线]: 整合无人机、特种机器人成立奇点感知，聚焦“感知-决策-执行”闭环，2025年实现收入2888万元，抢占新质生产力赛道。
- **[数字化供应链与AI赋能]** -> [运营效率提升]: “数字咸亨2.0”项目及AI技术应用，优化选型报价、订单履约，支撑营收26.48%增长的同时，销售费用率下降2.32个百分点。
- **[阳光采购政策深化]** -> [央企MRO集约化加速]: 国资委政策推动央企采购向集约化、数智化转型，公司作为纵向模式代表，受益于客户从“关注价格”向“综合考量质量与服务”转变。
- **[高分红回馈股东]** -> [增强投资者信心]: 上市以来累计分红6.84亿元已超IPO募资额，2025年分红比例达61.53%，构建了稳固的股东利益共同体。

## 风险警告
**核心风险在于对单一客户（国家电网）的深度依赖与业务结构失衡。** 2025年电力输配行业收入占比仍高达35.45%，尽管其他行业收入增长69.11%，但毛利率同比下滑5.34个百分点，显示新业务拓展以牺牲利润为代价。若电网投资节奏放缓或公司中标份额下降，业绩将面临显著波动。同时，公司整体毛利率同比下降5.48个百分点，营业成本增速（36.35%）显著高于收入增速（26.48%），成本控制能力面临挑战。

**新业务扩张带来的管理风险与资金压力不容忽视。** 公司向具身智能、海外市场等非传统领域拓展，前期投入大、回报周期长（奇点感知2025年收入仅2888万元），且新领域产品毛利率偏低、应收账款风险上升。此外，公司应收账款和存货规模随收入扩张而增长，经营活动现金流虽大幅改善，但投资活动现金净流出4.49亿元（主要用于大额存单），需关注资金配置效率与潜在坏账风险。
