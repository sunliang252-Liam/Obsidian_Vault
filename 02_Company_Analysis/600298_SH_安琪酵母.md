# 600298.SH 深度透视

## 因果逻辑链
- **[海外市场高增长]** -> [净利润+16.6%]: 国外营收同比+19.88%，毛利率32.07%远高于国内19.70%，高毛利海外业务占比提升直接拉动整体盈利。
- **[酵母及深加工产品毛利率提升]** -> [核心业务利润增厚]: 酵母及深加工产品毛利率同比+2.67个百分点至32.21%，成本控制（燃料动力-12.57%）优于收入增长（+10.09%）。
- **[经营现金流暴增50.19%]** -> [财务质量改善]: 销售回款增加及应收账款催收成效显著，现金流增速远超净利润增速，盈利质量扎实。
- **[财务费用激增113.26%]** -> [侵蚀利润]: 银行利息支出大幅增加，叠加发行10亿元科创债，有息负债扩张推高融资成本。
- **[糖业持续亏损]** -> [拖累整体]: 制糖产品毛利率-4.86%，且库存量同比+53.22%，糖蜜等原材料价格波动风险持续压制该板块。
- **[食品原料业务爆发式增长]** -> [第二曲线初现]: 食品原料营收同比+54.36%，但成本增速（+58.18%）快于收入，毛利率微降，规模扩张期盈利质量待观察。
- **[收购晟通糖业]** -> [商誉激增457.84%]: 并购产生商誉2.02亿元，叠加糖业亏损，整合风险与减值压力并存。

## 风险警告
**糖业板块是最大利润黑洞。** 制糖产品毛利率为-4.86%，处于严重亏损状态，且库存量同比暴增53.22%。公司收购晟通糖业后商誉激增457.84%至2.02亿元，若糖蜜价格持续波动或下游需求不振，该板块亏损扩大将直接触发商誉减值，对合并报表利润造成重大冲击。

**财务费用失控与债务扩张的恶性循环。** 报告期内财务费用同比暴增113.26%，主要因银行利息支出增加。公司同时发行10年期科创债10亿元，有息负债规模持续膨胀。在利率下行周期中，若未来融资成本无法有效控制，高杠杆运营将严重侵蚀主业来之不易的利润增长。
