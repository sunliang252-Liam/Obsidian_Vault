# 301188.SZ 深度透视

## 因果逻辑链
- **[集采政策冲击]** -> [营收与利润双降]: 2025年药品终端市场“量价齐跌”，公司医药包装业务营收同比下降23.62%，拖累整体营收下滑9.19%，净利润下滑39.97%。
- **[原材料及能源价格上升]** -> [成本压力加剧]: 硼砂、天然气等成本上涨，而公司未能完全向下游传导，导致毛利率承压，经营活动现金流净额由正转负至-1,932.55万元。
- **[产能扩张与库存积压]** -> [现金流恶化]: 为抢占市场份额及应对未来需求，公司主动增加药用玻璃和耐热玻璃库存，导致存货同比大增67.8%，占压大量营运资金。
- **[高端化转型与新品布局]** -> [未来增长点]: 公司布局RTU（免洗免灭）产品、预灌封注射器等高附加值产品，并收购创扬股份切入塑料包材，构建“玻璃+塑料”一站式解决方案。
- **[智能制造与AI赋能]** -> [效率与壁垒提升]: 公司成为行业首个CMMM四级认证企业，通过数字孪生、AI视觉检测等系统降本增效，构筑技术壁垒，并向智能机器人领域拓展第二增长曲线。
- **[全球化战略落地]** -> [海外收入增长]: 在巴西、美国等地设立子公司，实现本地化运营，2025年境外收入同比增长16.64%，毛利率达34.17%，显著高于境内。
- **[管理层变动与战略调整]** -> [治理结构优化]: 董事长及多名高管变更，新团队以“五个元年”为战略导向，强化业绩考核，推动公司从传统制造向科技驱动转型。

## 风险警告
**核心风险在于集采政策冲击的持续性与公司转型的不确定性。** 2025年公司业绩已因集采导致“量价齐跌”，虽然第十一批集采政策转向“质量严控”，但市场恢复节奏不明。公司为应对未来需求而大幅扩产备货，导致存货激增、现金流恶化，若下游需求复苏不及预期，将面临严重的库存减值与资金周转压力。

**第二重风险来自新业务的高投入与低回报。** 公司同时推进RTU、预灌封、模制瓶等多个资本密集型项目，在建工程同比大增100.7%，且多个募投项目已延期。这些新业务尚处市场开拓期，短期内难以贡献利润，若技术路线或市场需求生变，巨额投资存在收益不达预期的风险。此外，原材料价格波动、汇率及美国关税风险也是持续存在的经营压力。
