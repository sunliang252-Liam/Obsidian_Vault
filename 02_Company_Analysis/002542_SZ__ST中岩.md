# 002542.SZ 深度透视

## 因果逻辑链
- **[基建投资放缓与市场竞争加剧]** -> [营收大幅下滑34.24%]: 公司核心工程服务业务（地基处理、市政工程）受宏观政策与行业竞争双重挤压，新签合同减少，项目毛利率下降。
- **[项目回款与结算不及预期]** -> [巨额资产减值损失3.02亿元]: 客户付款周期延长，导致应收账款、合同资产及商誉计提大额减值，成为当期亏损主因。
- **[营收下滑与减值叠加]** -> [连续第三年巨额亏损，净资产转负]: 营收萎缩与资产减值双重打击，导致归母净利润亏损9.51亿元，净资产降至-1.32亿元，资不抵债。
- **[控股股东同业竞争承诺延期]** -> [战略转型受阻]: 与控股股东成都兴城集团在市政工程领域的同业竞争问题未解决，原定资产重组方案终止，承诺延期至2027年，制约公司业务整合与聚焦。
- **[低空经济政策红利]** -> [通航业务成为唯一亮点]: 公司提前布局通用机场投资、建设与运营，安吉天子湖机场运营领先，并拓展无人机培训等新场景，形成差异化竞争优势。
- **[子公司管控效能低下]** -> [管理风险加剧]: 子公司业务跨度大、地域分散，内控体系滞后，导致部分子公司业绩下滑，成为商誉减值和整体亏损的重要来源。
- **[融资结构恶化]** -> [财务费用高企]: 为维持运营，公司大幅增加借款，导致财务费用同比增长14.49%，进一步侵蚀利润。

## 风险警告
**核心风险是资不抵债与持续经营能力存疑。** 公司2025年末净资产为-1.32亿元，已陷入技术性破产。连续三年巨额亏损，经营活动现金流由正转负，表明公司已无法通过自身经营创造价值，高度依赖外部融资（向控股股东借款）和资产处置来维持现金流，偿债能力与再融资能力面临严峻考验。

**第二大风险是战略困境与同业竞争僵局。** 公司核心工程服务业务萎缩，与控股股东的同业竞争问题悬而未决，资产重组方案已终止，承诺再次延期，导致公司无法有效整合资源、聚焦主业。虽然低空经济是亮点，但短期内体量太小，无法弥补工程业务的巨大窟窿。公司战略转型方向明确，但执行路径受阻，前景高度不确定。
