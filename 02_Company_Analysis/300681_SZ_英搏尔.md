# 300681.SZ 深度透视

## 因果逻辑链
- **[大客户战略深化 + 定点车型放量]** -> **营收增长59.45%**: 聚焦头部车企，铁三角团队深入客户现场，受益于配套车型销量增长，驱动总成出货量同比暴增144.08%。
- **[海外市场突破 + 双市场协同]** -> **综合毛利率提升**: 海外营收同比暴增516.14%，占比从4.61%跃升至17.82%，高毛利海外业务拉升整体盈利水平。
- **[可转债募投产能释放]** -> **规模效应显现**: 珠海智能工厂（三期）投产，产能与市场需求精准匹配，为营收高增长提供物理基础，同时摊薄固定成本。
- **[出售子公司股权]** -> **非经常性损益大幅增厚利润**: 处置珠海鼎元股权确认投资收益约1.09亿元，占利润总额54.1%，是归母净利润同比增161.62%的核心驱动力。
- **[“集成芯”技术平台化]** -> **产品边界拓展至低空经济**: 将乘用车动力系统技术（扁线油冷、SiC）延伸至eVTOL电推进系统，已获亿航智能等头部企业定点，开辟第二增长曲线。
- **[深化精益管理 + 组织能力提升]** -> **运营效率与盈利能力双升**: 聘请外部咨询机构，在营收增长59.45%的同时，有效控制费用率，扣非净利润同比增长121.26%。
- **[前瞻布局800V高压平台]** -> **巩固中高端车型供应链地位**: 自主掌握SiC技术，推出800V平台化六合一动力系统，精准匹配高压快充趋势，提升产品议价能力与客户粘性。

## 风险警告
**1. 扣非净利润质量与客户集中度风险。** 2025年归母净利润1.86亿元，但扣非净利润仅0.86亿元，占比不足50%。利润高增的核心驱动力来自出售子公司的一次性收益（约1.09亿元），主业盈利能力远弱于账面表现。同时，前五大客户销售额占比高达77.07%，对单一客户依赖度极高，一旦核心客户车型销量波动或切换供应商，公司业绩将面临剧烈冲击。

**2. 行业竞争加剧与技术迭代的双重挤压。** 新能源汽车动力系统行业已进入“红海”竞争，车企自研趋势与第三方供应商的挤压并存。公司虽在“集成芯”技术上领先，但800V、SiC、扁线等技术已成为行业标配，技术壁垒正在被快速填平。若公司无法在成本控制或下一代技术（如氮化镓、关节模组）上持续领先，将面临毛利率持续下滑与市场份额被蚕食的风险。
