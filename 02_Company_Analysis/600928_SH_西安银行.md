# 600928.SH 深度透视

## 因果逻辑链
- **贷款规模高速扩张（25.55%）** -> **利息净收入大幅增长（59.67%）**: 公司贷款（+34.66%）和票据贴现（+3373%）的激进投放，叠加净息差从1.36%回升至1.85%，共同驱动利息收入成为营收增长的核心引擎。
- **净息差显著回升（+49BP）** -> **营收增速远超利润增速**: 负债端存款成本下降（-51BP）和资产端贷款收益率相对刚性，使净息差修复，但信用减值损失同比大增41.96%，严重侵蚀利润弹性。
- **信用减值损失激增（41.96%）** -> **归母净利润增速仅3.57%**: 贷款规模扩张导致拨备计提大幅增加（+35.27%），同时金融投资减值损失翻倍（+104.57%），高额拨备是利润增速远低于营收增速的根本原因。
- **投资收益与公允价值变动大幅下滑** -> **非利息净收入骤降57.04%**: 债券市场波动导致公允价值变动损益由正转负（-4.76亿），投资收益同比减少31.06%，非息收入对营收的贡献度显著下降。
- **公司贷款激进扩张（+41.22%）** -> **资产结构向对公倾斜，个人贷款收缩**: 公司贷款占比升至71.48%，而个人贷款下降5.94%，显示银行主动调整信贷结构，聚焦对公业务，但零售业务增长乏力。
- **不良贷款率下降（-0.07pct）但关注类贷款迁徙率上升** -> **资产质量改善表象下的潜在压力**: 不良率降至1.65%，但关注类贷款向下迁徙率从11.73%飙升至26.27%，表明未来不良生成压力显著增大。
- **发行50亿永续债和40亿二级资本债** -> **资本充足率提升但核心一级资本充足率下降**: 资本净额大幅增加，但风险加权资产增速更快，导致核心一级资本充足率从10.07%降至9.15%，逼近监管红线，内源性资本补充能力不足。

## 风险警告
**核心风险在于资产质量“明降暗升”与资本消耗过快之间的矛盾。** 尽管不良贷款率微降，但关注类贷款迁徙率翻倍至26.27%，损失类贷款占比从0.59%升至1.03%，表明存量风险正在加速暴露。同时，贷款总额25.55%的激进扩张，导致信用减值损失同比大增42%，拨备覆盖率虽回升至214.62%，但这是以牺牲当期利润为代价换来的。更关键的是，核心一级资本充足率已降至9.15%，在资产高速扩张和利润增长乏力的双重挤压下，内源性资本补充能力已近枯竭，未来极度依赖外部融资。

**盈利增长高度依赖利息收入，非息收入贡献骤降，收入结构脆弱。** 营收增长21.68%几乎完全由利息净收入（+59.67%）驱动，而非利息净收入因市场波动骤降57.04%，公允价值变动损益由盈转亏。这种对息差修复和规模扩张的单一依赖，在利率市场化深化和宏观经济不确定性加大的背景下，可持续性存疑。一旦净息差修复趋势逆转或信贷需求放缓，营收将面临失速风险。
