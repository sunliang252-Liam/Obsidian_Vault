# 600790.SH 深度透视

## 因果逻辑链
- **[国际物流中心拆迁补偿款坏账计提]** -> [归母净利润由盈转亏]: 因拆迁尾款回收不确定性增加，公司计提1.11亿元信用减值损失，直接导致全年净利润从盈利1.41亿转为亏损0.16亿。
- **[核心市场租金收入下滑]** -> [营业收入同比下降7.59%]: 营业房批量到期续租租金减少，叠加部分市场租金下降，导致租赁业务收入同比减少4.52%。
- **[新建项目转固及折旧增加]** -> [营业成本上升12.71%]: 轻纺数字贸易港、智谷园区等项目陆续完工转固，折旧摊销成本大幅增加，侵蚀利润空间。
- **[融资规模扩大与利息收入减少]** -> [财务费用激增65.01%]: 为支持项目建设新增银行借款，同时存款利息收入减少，导致财务费用从0.44亿增至0.73亿。
- **[工银投资增资子公司]** -> [资本公积大幅减少，少数股东权益增加]: 工银投资以5亿元增资国际物流中心，该增资款被确认为金融负债，并冲减资本公积约5亿元，同时少数股东权益增加。
- **[持有金融资产公允价值变动]** -> [其他综合收益增加]: 持有的浙商银行、浦发银行等金融资产公允价值上升，贡献其他综合收益约0.6亿元，但未计入当期利润。
- **[“AI布”智能体发布与数字化投入]** -> [研发费用增长58.47%]: 公司加速数字化转型，推进“五脑合一”平台和“AI布”智能体建设，导致研发投入增加。

## 风险警告
**核心风险在于资产减值与现金流恶化。** 公司2025年由盈转亏，根本原因并非经营业务崩溃，而是高达1.11亿元的信用减值损失（来自国际物流中心拆迁补偿款坏账计提）。这笔巨额应收款的回收存在重大不确定性，已成为悬在利润表上的达摩克利斯之剑。同时，经营活动现金流净额由正转负，从5.99亿骤降至-0.73亿，显示公司主营业务的现金创造能力正在减弱，财务健康度亮起红灯。

**成长性面临结构性挑战。** 公司传统市场租赁业务收入下滑，而新建的轻纺数字贸易港、智谷园区等项目尚处于投入期，折旧和财务费用大幅增加，短期内难以贡献正向利润。尽管公司在数字化（AI布）和物流（多式联运）上积极布局，但这些新业务尚未形成有效的利润增长点，公司正处于新旧动能转换的阵痛期，盈利能力承压。
