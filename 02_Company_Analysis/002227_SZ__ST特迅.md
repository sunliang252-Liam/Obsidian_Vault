# 002227.SZ 深度透视

## 因果逻辑链
- **[核心工业电源业务收入大幅下滑]** -> [总营收下降20.21%]: 电力用直流和交流一体化不间断电源设备收入同比减少32.55%，拖累整体营收从3.48亿降至2.78亿。
- **[新能源充电业务逆势增长]** -> [结构性转型]: 充电业务收入同比增长21.17%，储能业务暴增1631%，但体量尚小，无法弥补传统业务缺口。
- **[持续亏损且亏损扩大]** -> [盈利能力恶化]: 归母净利润-6730万，扣非净利润-7653万（同比-107.61%），连续三年亏损，且亏损幅度加深。
- **[资产减值与信用减值侵蚀利润]** -> [利润质量承压]: 计提存货跌价及合同资产减值1377万，信用减值损失412万，合计约1789万，直接加剧亏损。
- **[奥特迅工业园完工转固]** -> [资产结构剧变]: 固定资产从3.87亿暴增至8.16亿（+31.98%），在建工程从3.80亿骤降至0.11亿，未来折旧压力将显著增加。
- **[经营活动现金流净额转正]** -> [现金流改善]: 经营现金流从-1897万转为+951万（+150.14%），主因销售回款及充电运营款增加，但净利润持续为负，现金质量仍需观察。
- **[营收低于3亿+净利润为负]** -> [触发退市风险警示]: 2025年扣非后营收2.65亿，低于3亿红线，且净利润为负，公司股票将被*ST，生存压力陡增。

## 风险警告
**核心风险：退市风险警示与持续经营能力存疑。** 公司2025年营收（扣除后）仅2.65亿元，低于3亿元，且连续三年亏损，已触发深交所退市风险警示（*ST）条件。若2026年无法实现营收突破3亿或扭亏为盈，将面临直接退市风险。公司当前主业萎缩、新业务尚未形成规模效应，生存是第一要务。

**结构性风险：传统业务萎缩，新业务造血能力不足。** 核心收入来源（工业电源）同比下滑32.55%，而寄予厚望的新能源充电业务虽增长21%，但毛利率为负（-10.66%），处于“增收不增利”的烧钱阶段。储能业务虽暴增但基数极低，无法对冲传统业务的衰退。公司正处于新旧动能转换的“青黄不接”期，盈利拐点遥遥无期。
