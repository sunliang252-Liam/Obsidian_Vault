# 600469.SH 深度透视

## 因果逻辑链
- **[原材料成本高企]** -> [毛利率下降2.75个百分点]: 天然橡胶价格高位运行，原材料占收入比升至64.33%，直接侵蚀利润空间。
- **[联营企业PTN亏损]** -> [投资收益损失8441万元]: 参股10%的PTN净亏损9亿元，按权益法确认大额投资损失，拖累合并净利润。
- **[海外市场渠道下沉]** -> [出口收入增长8.89%]: 通过设立6家海外子公司、直供零售商和矿山客户，提升市场把控力，但毛利率仍受成本挤压。
- **[巨胎产能扩张]** -> [在建工程激增393.86%]: 2万套巨胎扩能项目推进，资本开支大幅增加，为未来抢占高价值非公路轮胎市场奠定基础。
- **[研发费用下降45.36%]** -> [短期利润调节]: 研发环节试制品对外销售增加，导致费用化研发投入减少，但实际研发总投入（含试制品）占收入4.22%。
- **[出口退税率上调]** -> [增厚出口利润]: 自2025年11月起，22种轮胎产品出口退税率从9%上调至13%，为出口业务提供直接利润缓冲。
- **[国内配套市场突破]** -> [配套收入增长28.21%]: 工程胎配套业务有效切入，成功与多家主机厂实现测试和供货，带动国内配套收入高增。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长10.51%，但归母净利润却下滑16.14%，主因是原材料成本（天然橡胶价格高位）和联营企业PTN的持续亏损（投资收益-8441万元）双重挤压。若天然橡胶价格维持高位或PTN亏损扩大，公司盈利能力将进一步承压。

**贸易摩擦与全球化管理风险不容忽视。** 美国对中国轮胎综合关税高达89%-251%，直接出口通道基本被阻断。公司虽通过海外子公司进行渠道下沉，但全球化布局加深也带来了法律、汇率、文化等管理挑战，且存在贸易摩擦“跟随转移”的风险，即海外子公司所在国也可能被加征关税。
