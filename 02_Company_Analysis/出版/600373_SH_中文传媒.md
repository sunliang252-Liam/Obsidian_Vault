# 600373.SH 深度透视

## 因果逻辑链
- **[江西省教辅征订政策突变]** -> [营收与利润暴跌]: 2024年秋季起，江西省停止教辅材料统一征订，直接导致公司核心业务“教材教辅”营收同比下降48.06%，是业绩崩塌的根本原因。
- **[核心主业失血]** -> [扣非净利润巨亏]: 教辅业务断崖式下滑，导致公司扣除非经常性损益后净利润为-2.68亿元，同比下降138.99%，主业盈利能力已实质性崩溃。
- **[金融投资“救场”]** -> [账面净利润勉强为正]: 公司通过金融资产公允价值变动及处置收益（4.7亿元）和投资收益（3.17亿元）等非经常性损益，将归母净利润“粉饰”至2.80亿元，掩盖了主业的严重亏损。
- **[教辅发行量价齐跌]** -> [发行业务毛利率骤降]: 发行业务营收下降48.75%，毛利率从35.58%暴跌至28.20%，下降7.38个百分点，显示渠道价值与议价能力被严重削弱。
- **[整合营销业务“虚胖”]** -> [增收不增利]: 整合营销业务营收增长65.83%，但成本增长75.73%，毛利率下降4.89个百分点，高增长背后是盈利能力恶化，未能成为可靠增长极。
- **[高比例分红与回购]** -> [透支未来]: 2025年现金分红及回购合计占净利润的103.49%，在主营业务巨亏的情况下，公司仍进行超额分配，表明其缺乏内生增长动力，依赖存量资产维持股东回报。
- **[收购资产“退货”]** -> [战略失误与资源浪费]: 2024年收购的江教传媒、高校出版社因政策突变业绩不达标，2025年被迫解除协议、返还资产，暴露了公司对政策风险的预判不足和并购整合的失败。

## 风险警告
**核心风险：主业崩塌与政策依赖。** 公司业绩的“命门”完全系于江西省地方教育政策。教辅征订方式的改变已导致其最核心的“教材教辅”业务营收腰斩，且该影响具有持续性。公司目前缺乏有效的应对策略，传统出版发行主业已陷入不可逆的衰退，未来营收和利润仍将面临巨大压力。

**财务风险：盈利质量极差，现金流恶化。** 公司2025年归母净利润2.80亿元，但扣非净利润为-2.68亿元，盈利完全依赖金融投资等非经常性损益，具有高度不确定性和不可持续性。同时，经营活动现金流净额同比暴跌83.61%至0.66亿元，表明主业造血能力已严重枯竭，公司正通过消耗金融资产和融资来维持运营和分红，财务基础十分脆弱。
