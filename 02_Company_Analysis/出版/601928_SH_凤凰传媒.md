# 601928.SH 深度透视

## 因果逻辑链
- **[教材教辅发行收入下降]** -> [营收下滑9.25%]: 发行行业收入同比下降9.84%，教材教辅发行量减少19.79%，直接拖累整体营收。
- **[非经常性损益大幅波动]** -> [归母净利润与扣非净利润背离]: 2024年因税收政策调整产生6.7亿元非经常性损失，2025年该影响消失，导致归母净利润同比增12.37%，但扣非净利润实际下降24.03%。
- **[资产减值损失激增]** -> [利润质量承压]: 存货跌价准备及商誉减值损失同比增加237.70%，侵蚀核心业务利润。
- **[内容电商渠道崛起]** -> [传统渠道萎缩]: 内容电商成为图书零售第一大渠道（份额40.53%），而平台电商和实体书店持续负增长，公司传统发行渠道面临结构性冲击。
- **[智慧教育产品落地]** -> [新增长点初现]: “智羚学伴”进入109所学校试点，学科网营收增长13.23%，AI+教育布局开始贡献增量。
- **[高比例现金分红]** -> [股东回报稳定]: 连续三年平均分红比例超55%，2025年每10股派4元，股息率在行业中保持前列。
- **[出生人口下降]** -> [长期需求风险]: 新生入学人数持续下降，中小学在校生数量即将见顶，将长期压制教育出版业务的基本盘。

## 风险警告
**核心风险在于传统主业的结构性萎缩与转型成效的不确定性。** 公司营收和扣非净利润双降，核心的教材教辅发行业务量同比下降近20%，且资产减值损失暴增2.37倍，表明传统出版发行模式正遭受渠道变革和需求下行的双重挤压。虽然公司积极布局AI教育，但“智羚学伴”等产品仍处于试点阶段，尚未形成规模化收入，转型的投入与产出存在时间差。

**另一个重大风险是人口结构变化带来的长期系统性风险。** 出生率持续下降将导致中小学在校生数量在未来几年内出现拐点，直接冲击公司最核心、最稳定的教育出版和发行业务。尽管公司计划通过拓展业务范围来对冲，但在学生基数绝对减少的背景下，教育出版业务的增长天花板已经清晰可见，长期增长逻辑面临根本性挑战。

**公司简介（F10 原文）**

> 江苏凤凰出版传媒股份有限公司成立于2011年3月28日,兼有内容生产和渠道优势。2011年11月30日,公司在上海证券交易所正式挂牌,简称“凤凰传媒”,证券代码“601928”。凤凰传媒的主营业务为图书、报刊、电子出版物、音像制品的编辑出版、发行。公司是全国中小学教材第二大出版商,大众出版位列国内出版业第一阵营,发行板块主要经济指标居全国同行前列,国家级出版大奖获奖总数位居全国前列。在巩固传统业务优势的基础上,凤凰传媒持续加大转型升级力度,积极完善产业布局,在智慧教育、职业教育、云计算、大数据等产业积极拓展,形成了新旧媒体有效融合、新老业务相辅相成的产业布局,目前已初步形成一体化的产业链和多媒体、多业态的文化产业生态圈。公司构建了“大中小特”相结合的发行体系,大书城、中心门店、专业书店、特色书店、小微书店和24小时书店有序分布在江苏全省,拥有销售网点1400多个,总建筑面积超100万平方米,拥有居全国同行前列的图书物流配送中心。2021年起公司连续四年入选“全球出版50强”。在中国人民大学发布的“2018中国文化企业品牌价值TOP50”榜单中,凤凰传媒以品牌价值22.6亿元入选,列新闻出版类前列。公司控股方是凤凰出版传媒集团有限公司,产业领域主要是出版、发行、印务、影视、文化酒店、文化地产、金融投资、艺术品经营等板块。控有凤凰传媒、凤凰股份等上市公司。集团2012年被评为全国文化体制改革先进单位,连续十七届入选“全国文化企业30强”。
