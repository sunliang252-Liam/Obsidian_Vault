# 603096.SH 深度透视

## 因果逻辑链
- **[内容电商渠道变革]** -> [国内图书收入骤降26.4%]: 流量算法主导下，非刚需的文学/童书品类销售逻辑被颠覆，腰部图书自然销售急剧萎缩，公司核心品类受冲击最大。
- **[海外业务整合清理]** -> [海外亏损扩大至2281万元]: 为优化产品线，主动处置滞销库存和预付版税，产生高额当期费用，导致亏损同比增加5.63%。
- **[流量成本高企与投入产出失衡]** -> [销售费用仅降9.84%，远低于收入降幅21.24%]: 为在内容电商获取流量，营销投入刚性，无法随收入同步缩减，侵蚀利润。
- **[非经常性收益依赖]** -> [扣非净利润降幅（-42.57%）大于归母净利润降幅（-39.18%）]: 理财收益及公允价值变动收益（1361万）成为利润的重要缓冲，掩盖了主业更严重的下滑。
- **[存货与预付版税高企]** -> [经营现金流净流出3441万元]: 收入下降导致回款减少，同时大量资金沉淀在预付版税（3.04亿）和存货（1.49亿）中，现金流状况恶化。
- **[经典IP长线运营]** -> [品牌护城河与产品韧性]: 余华、东野圭吾等头部作家作品及“bibi动物园”等自有IP，为公司提供了穿越周期的内容基础和焕新可能。
- **[联营企业投资减值]** -> [资产减值损失激增至1736万元]: 对北京银河宏霞文化传媒的投资因持续亏损计提减值，显示公司对外股权投资的风险暴露。

## 风险警告
**核心风险在于主业失速与转型阵痛叠加。** 公司高度依赖的文学和童书品类，在“内容+流量”驱动的渠道变革中首当其冲，国内图书收入骤降26.4%，且未见企稳迹象。更严峻的是，为应对渠道变化而增加的营销投入并未带来有效转化，导致扣非净利润暴跌42.57%，盈利能力严重受损。海外业务作为第二增长曲线，目前仍处于清理库存、整合优化的“出血”阶段，短期内无法贡献利润，反而成为业绩拖累。

**财务健康度恶化是另一大隐患。** 经营现金流由正转负，净流出3441万元，而同期公司却将大量现金（7000万）用于购买一年期以上定期存款，这反映出主业造血能力不足，且资金运用效率存疑。同时，高达3.04亿的预付款项（主要为预付版税）和1.49亿的存货，构成了巨大的资产减值风险。若未来图书销售持续低迷，这些资产将面临大规模减值的压力，进一步冲击利润表。公司当前的高分红（120%分红率）在业绩下滑背景下，其可持续性值得高度警惕。

**公司简介（F10 原文）**

> 新经典文化股份有限公司,是以创新驱动的内容行业领先者,主要业务包括图书策划与发行、数字图书、图书零售,以及影视剧策划等版权延伸业务,于2017年4月25日在上海证券交易所正式挂牌上市(股票代码:603096)。我们持守严选态度和专业精神,致力成为国际化的“优质内容的发现者、创造者、守护者”。内容策划业务新经典是中国领先的图书策划与发行机构,已连续八年位居中国最大网络书店当当网年度供应商实销排名第一。新经典的内容团队拥有一批行业知名的资深编辑、版权专家和设计师等,拥有多位国内外知名签约作家,包括“诺贝尔文学奖”得主加西亚马尔克斯、V.S.奈保尔、托妮莫里森、川端康成、巴勃罗聂鲁达、艾丽丝门罗,以及村上春树、保罗柯艾略、东野圭吾、A.S.拜厄特、李欧李奥尼、谢尔希尔弗斯坦、路遥、王小波、张爱玲、三毛、霍达、余华、麦家、周国平、庆山(安妮宝贝)、李娟等。其中《窗边的小豆豆》《平凡的世界》《可爱的鼠小弟》发行量已超过一千万册,《百年孤独》《活着》《解忧杂货店》《1Q84》《撒哈拉的故事》《倾城之恋》《爱心树》《牧羊少年奇幻之旅》《人民的名义》等一批作品畅销逾百万册。关联品牌爱心树是新经典旗下的童书品牌,致力于“让每个孩子都成为爱书人”。爱心树作品囊括美国凯迪克奖、英国格林威奖、德国青少年文学奖、日本绘本大奖、国际安徒生奖等大奖作品,连续数年荣获“全国十佳童书”荣誉,代表作品有《窗边的小豆豆》《爱心树》《小黑鱼》《胡萝卜的种子》《可爱的鼠小弟》《第一次上街买东西》《不可思议的旅程》《西尔斯亲密育儿百科》等。新经典与北京出版集团合资成立的十月文化,与台湾皇冠出版集团、香港青马出版社合资成立的青马文化,与日本讲谈社合资成立的飓风社,也已成为中国图书策划领域的知名品牌。海外业务新经典控股的法国知名出版社菲利普毕吉耶(Editions Philippe Picquier),被誉为中国文学走向世界的桥头堡,曾出版莫言、余华、阎连科、王安忆、毕飞宇、曹文轩等一批中国作家的作品。新经典控股的美国知名童书出版社Kane Press,专注于出版生动有趣的少儿教育绘本,获得数十项美国大奖,并有100多部作品被翻译成中文、法语、西班牙文等16种语言在世界各地传播。2019年5月,进一步收购美国Highlights集团旗下童书出版社(Boyds Mills Press),致力于为儿童、青少年和所有童心未泯的读者创作优秀的图书。2018年1月,新经典在日本建立子公司株式会社新经典。
