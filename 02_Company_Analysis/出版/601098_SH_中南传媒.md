# 601098.SH 深度透视

## 因果逻辑链
- **出版业务整合优质内容资源、打造精品，获奖及入选数量创新高** -> 一般图书市场实洋占有率稳居行业第二，品牌影响力持续彰显: 正向驱动
- **发行业务主动压减低毛利大宗业务，优化结构** -> 发行业务营收同比下降5.91%，但毛利率提升0.27个百分点: 正向驱动
- **新华小纸条等数智教辅产品成功推出** -> 湖南省新华书店营收和净利润保持高位，市场化数智教辅项目开局良好: 正向驱动
- **数字化服务业务板块整合及数智产品落地** -> 数字化服务业务营收同比大幅增长302.10%: 正向驱动
- **财务公司业务结构调整，开展不可提前支取的定期存单业务** -> 经营活动现金流量净额大幅下降至-12.37亿元: 直接原因
- **财务公司业务结构调整及交易性金融投资增加** -> 投资活动现金流量净额大幅下降至-18.21亿元: 直接原因
- **马栏山视频文创产业园项目完工转固** -> 固定资产大幅增加，管理费用上升（折旧增加）: 正向驱动
- **出版业务教材教辅发行规模增长，但整体市场受学生人口减少影响** -> 发行业务营收下降，但教材教辅毛利率提升: 负向冲击
- **纸张价格持续下跌** -> 物资业务营收同比下降18.23%，毛利率提升1.10个百分点: 负向冲击

## 风险警告
公司经营活动现金流大幅转负，主要由于财务公司定期存单业务导致，需关注资金流动性风险；发行业务受学生人口减少和市场竞争影响持续下滑，虽然优化结构暂稳毛利，但长期增长承压；研发投入同比下降24.97%，研发人员占比仅1.74%，可能影响长期数字化创新能力；物资业务受纸张价格波动影响较大，营收持续下滑。
