# 600825.SH 深度透视

## 因果逻辑链
- **[教辅政策冲击]** -> [报刊及广告收入骤降30.64%]: 教育部及上海市教委教辅改革政策导致学校报刊订阅量急剧下降，直接冲击《上海学生英文报》等核心报刊业务。
- **[中润解放清算]** -> [子公司亏损扩大至-1826万元]: 广告子公司营业期届满进入清算，一次性摊销剩余装修费，导致亏损同比大幅增加，拖累整体利润。
- **[教辅政策冲击]** -> [报刊业务毛利率暴跌24.34个百分点]: 收入大幅下降的同时，成本因审计调整（编辑费、制作费重分类）反而上升，双重挤压下毛利率断崖式下滑。
- **[悦合项目破产重整推进]** -> [转回信用减值损失3489万元]: 子公司新华置城完成抵债房产过户，前期计提的坏账准备部分转回，成为当期净利润的重要支撑。
- **[金融资产重分类]** -> [交易性金融资产激增32.34%]: 汇添富绝对收益1号资管计划将于2026年到期，从“其他非流动金融资产”重分类至“交易性金融资产”，导致科目间结构性变动。
- **[教材发行刚需]** -> [教材及课外读物收入增长3.66%]: 公司作为上海地区唯一教材发行机构，受益于稳定的刚需市场，收入小幅增长，毛利率微升，构成业绩基本盘。
- **[实体门店调整]** -> [存货减少30.60%]: 公司主动关闭低效门店（莘庄、罗宾森等6家），加快库存周转与结算，导致期末在途存货显著下降。

## 风险警告
**核心风险在于主业空心化与利润结构脆弱。** 公司扣非净利润已连续两年为负（2025年-1629万，2024年-4098万），表明图书发行、报刊广告等传统主业已无法产生可持续利润。当前账面盈利高度依赖非经常性损益，如坏账转回（3489万）、金融资产处置收益（1248万）等，这些收益具有偶发性与不可持续性，一旦枯竭，公司将面临实质性亏损。

**转型前景不明，第二增长曲线尚未形成。** 公司虽提出向“K12英语学习智慧服务商”和“MR体验馆”转型，但相关业务（如“智悦通”AI工具）仍处于探索阶段，未形成规模收入。同时，中润解放清算、晨刊传媒关停等动作显示传统业务收缩加速，而新业务投入（如购买1.01亿办公用房）却未见明确回报，存在“旧船已沉，新船未造”的战略真空风险。
