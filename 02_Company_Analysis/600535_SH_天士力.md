# 600535.SH 深度透视

## 因果逻辑链
- **药品集中采购常态化及医保支付改革深化** -> 医药行业进入以创新、质量和成本控制为核心的高质量发展转型期: 政策推动和市场选择双重作用
- **公司实际控制人变更为中国华润有限公司** -> 公司开启新篇章，实施价值、业务、组织、精神重塑: 实控人变更带来资源整合与战略协同
- **集采降价及中药注射剂行业性下滑** -> 医药工业主营业务收入同比下降2.54%: 外部政策及市场环境导致销量增长但收入下降
- **公司聚焦三大核心领域，构建创新中药与先进治疗药物双轮驱动研发体系** -> 在研创新药31项，其中NDA/PreNDA阶段4项，临床II/III期17项: 研发战略驱动管线丰富度
- **普佑克获批急性缺血性脑卒中适应症，临床数据优于阿替普酶** -> 产品竞争力增强，有望带动业绩增长: 优秀临床数据支持市场推广和适应症扩展
- **公司推动产品进入医保目录、集采及临床指南** -> 核心产品销量增长，市场覆盖扩大: 准入资格扩大产品可及性
- **公司构建大生产体系，推进智能制造和精益管理** -> 降本增效，持续降低全产业链成本: 技术升级和管理优化带来效率提升
- **门诊统筹政策落地** -> 传统药店客流承压，连锁药店业务营收下降10.39%: 政策影响零售终端客流量
- **公司与华润三九业务融合，协同推广产品** -> 提升市场覆盖和销售效率: 利用双方渠道和品牌优势实现协同

## 风险警告
公司面临集采降价和中药注射剂行业下滑的持续压力，可能导致核心品种收入承压；创新药研发周期长、不确定性高，在研管线能否顺利上市存在风险；融合初期组织变革可能带来短期管理挑战；连锁药店业务受政策影响下滑，需关注零售市场恢复情况。
