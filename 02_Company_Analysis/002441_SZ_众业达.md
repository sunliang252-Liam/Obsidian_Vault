# 002441.SZ 深度透视

## 因果逻辑链
- **[收入微降但利润增长]** -> [净利润+11.25%]: 营收下降2.44%至108亿，但通过优化客户与产品结构、提升毛利率，实现了归母净利润1.88亿的同比增长。
- **[分销业务为核心基石]** -> [收入占比99.12%]: 公司作为工业电气分销商，99%以上收入来自能源、材料和机械电子设备批发，是业绩的绝对支柱。
- **[低压电气分销主导]** -> [收入占比63.91%]: 低压电气产品分销贡献最大收入（69亿），但同比微降2.15%，显示传统业务增长承压。
- **[工控产品分销逆势增长]** -> [收入+1.17%]: 在整体营收下滑背景下，工控产品分销实现29.9亿收入，同比增长1.17%，成为结构性亮点。
- **[中南与华南区域增长]** -> [区域结构优化]: 中南地区收入增长11.70%，华南增长1.04%，而华北下降10.86%，显示区域业务重心正在调整。
- **[高供应商集中度]** -> [依赖主要品牌]: 前五大供应商（施耐德、ABB、西门子等）采购额占比高达70.41%，公司深度绑定国际品牌，但也面临依赖风险。
- **[现金流大幅下降]** -> [经营质量隐忧]: 经营活动现金流净额下降30.17%至4.94亿，与净利润增长背离，主要受客户与供应商结算账期影响。
- **[高分红回报股东]** -> [股息率吸引力]: 2025年全年合计每10股派发现金红利5元（含税），分红总额约2.72亿，占归母净利润比例高，体现股东回报意愿。

## 风险警告
**核心风险在于对上游供应商的过度依赖与下游客户回款周期的双重挤压。** 公司前五大供应商采购额占比超70%，与施耐德、ABB等国际巨头深度绑定，一旦合作关系变动或销售折扣条件无法达成，将直接冲击盈利能力。同时，公司作为分销商，议价能力相对较弱，经营活动现金流净额大幅下降30%，显示在上下游账期博弈中处于不利地位，资金周转压力增大。

**宏观经济波动与行业竞争加剧是另一大威胁。** 公司下游客户覆盖电力、制造、基建等领域，与宏观经济景气度高度相关。当前制造业投资增速放缓，传统低压电气分销业务已现下滑。同时，行业竞争充分且分散，若无法通过“3+1”网络（分销、物流、技术服务+互联网）构建足够壁垒，可能面临市场份额被侵蚀、毛利率持续承压的风险。
