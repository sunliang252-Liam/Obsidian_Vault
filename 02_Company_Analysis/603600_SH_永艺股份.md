# 603600.SH 深度透视

## 因果逻辑链
- **[人民币兑美元升值]** -> [财务费用激增190.54%]: 2025年人民币升值导致汇兑损失大幅增加，财务费用从-1172万转为+1061万，直接侵蚀利润。
- **[全球贸易战升级/美国加征关税]** -> [外销收入微降0.14%]: 美国市场订单加速向越南转移，中国对美办公椅出口额同比下降21.6%，公司外销整体承压。
- **[越南/罗马尼亚海外产能布局]** -> [规避关税风险，维持大客户份额]: 公司率先在越南、罗马尼亚建厂，承接转移订单，抵消了国内出口下滑的影响，稳住外销基本盘。
- **[国内“国补”以旧换新政策]** -> [内销收入增长11.81%]: 国内消费品以旧换新政策有效刺激了家具消费，公司内销自主品牌业务实现收入增长和盈利改善。
- **[自主品牌建设与渠道拓展]** -> [线上销售毛利率提升3.07个百分点]: 公司聚焦“永艺撑腰椅”品牌心智，线上渠道精细化运营，带动高毛利自主品牌业务占比提升。
- **[原材料成本上涨]** -> [毛利率下降1.30个百分点]: 铁件、塑料、面料等原材料成本上升，而产品价格调整滞后，导致主营业务毛利率承压。
- **[大客户集中度高]** -> [经营稳定性依赖核心客户]: 前五大客户销售额占比52.24%，与大客户的深度绑定是收入基石，但也构成单一客户流失风险。

## 风险警告
**核心风险在于利润端的显著恶化与外部环境的剧烈不确定性。** 2025年公司营收微增2.79%，但归母净利润却骤降21.41%，扣非净利润降幅达26.80%。利润下滑的直接推手是人民币升值导致的汇兑损失，这暴露了公司作为出口导向型企业对汇率波动的脆弱性。更根本的挑战在于，全球贸易战加剧导致美国市场订单持续外流，公司虽通过越南产能对冲，但海外基地的运营效率（罗马尼亚基地亏损5378万元）和成本控制仍是巨大考验。

**公司面临“增收不增利”的结构性困境。** 原材料成本上涨、海外新基地爬坡成本、以及为拓展自主品牌而增加的销售费用（同比增长10.75%），共同挤压了利润空间。尽管内销和自主品牌业务增长亮眼，但其体量尚不足以完全弥补外销利润的下滑。若未来国际贸易环境持续恶化或人民币继续升值，公司盈利能力将面临进一步压缩的风险。
