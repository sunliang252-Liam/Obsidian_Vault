# 601872.SH 深度透视

## 因果逻辑链
- **[VLCC油轮运价上涨]** -> [油轮船队净利润创历史新高]: 公司VLCC船队精准把握市场机遇，TCE跑赢指数，叠加合规市场需求反转，推动油轮板块净利润同比大增59.06%。
- **[干散货船队轻资产运营规模扩大]** -> [散货船收入增长但毛利率下降]: 租入船和程租运费增加扩大了收入规模（+10.44%），但成本增速（+20.20%）更快，导致毛利率下降6.76个百分点。
- **[集装箱船队新开辟航线]** -> [量价齐升，收入增长]: 新开华东泰国、远东墨西哥等航线，全年重箱运量同比增18.4%，出口单箱收入基本持平，推动收入增长13.15%。
- **[LNG船队规模扩张与长约锁定]** -> [确立重要船东地位]: 通过卡气二期等项目，LNG船队规模增至64艘（61艘锁定长约），为未来提供稳定现金流，但短期市场运价低迷导致毛利率下降。
- **[新造船集中交付与资本开支]** -> [资产与负债规模同步扩张]: 报告期接收16艘新船，在建工程增74%，长期借款增8.57%，总资产增16.19%，公司进入船队更新提速期。
- **[处置老龄非节能型船舶]** -> [优化船队结构，产生非经常性收益]: 处置5艘老龄油轮和滚装船，带来6.77亿元非流动资产处置损益，占归母净利润的11.3%。
- **[股权激励费用冲回影响消失]** -> [管理费用同比增加]: 上年同期冲回第二期股权激励费用，本期无此事项，导致管理费用同比增19.17%。

## 风险警告
**地缘政治与贸易管制风险是当前最核心的不确定性。** 中东战局超预期发展，霍尔木兹海峡通行受阻，可能引发70年代以来最严重的石油危机，直接冲击公司核心的VLCC和LNG业务。同时，美国301调查措施若恢复，将大幅增加涉美航线成本，削弱船队竞争力。这些外部冲击的烈度和持续时间难以预测，可能导致公司经营收益剧烈波动。

**供需格局逆转风险不容忽视。** 尽管当前油轮市场因合规需求反转和供给结构变化而景气，但VLCC远期订单暴增和新兴船东的过高热情值得警惕。干散货和集装箱市场面临运力增速超过需求增速的压力，2026年集装箱运力预计增长4.5%而货量仅增2.5%，运价下行风险显著。公司多元业务组合虽能对冲部分风险，但若全球经济衰退导致海运贸易量萎缩，所有板块将同步承压。
