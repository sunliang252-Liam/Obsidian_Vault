# 002709.SZ 深度透视

## 因果逻辑链
- **[电解液销量高增44%]** -> [营收增长33%]: 核心产品电解液全年销量超72万吨，量增驱动收入规模跨越式提升。
- **[核心原材料自产+一体化布局]** -> [毛利率提升3.82个百分点]: 液体六氟磷酸锂、LiFSI等关键原料自给，成本优势显著，在价格竞争激烈的环境下实现盈利改善。
- **[碳酸锂期货套保]** -> [平抑盈利波动]: 系统性开展套期保值业务，有效对冲原材料价格剧烈波动对利润的冲击，保障经营稳定性。
- **[海外工厂投产]** -> [全球化突破]: 北美、欧洲OEM工厂顺利落地并获本土订单，实现从0到1的跨越，打开海外增量市场。
- **[储能需求爆发]** -> [第二增长曲线]: 储能领域成为与动力电池并驾齐驱的核心引擎，驱动电解液需求持续增长。
- **[日化材料销量突破12万吨]** -> [营收增长10.69%]: 通过差异化策略深耕国内、拓展国际渠道，日化业务实现规模与质量的双重突破。
- **[研发投入增长26.75%]** -> [技术壁垒加固]: 重点投入固态电池、钠离子电池等下一代材料，形成系统化专利布局，为长期竞争力奠基。

## 风险警告
**行业产能过剩与价格战风险**：尽管公司凭借一体化成本优势实现毛利率提升，但锂电池材料行业整体产能投放显著高于需求增速，各环节存在冗余。若下游需求增速放缓或行业竞争进一步加剧，产品价格可能持续承压，侵蚀公司盈利空间。公司需持续通过技术迭代和成本优化来维持护城河。

**海外项目与地缘政治不确定性**：公司正加速美国、摩洛哥等海外产能建设，但面临属地政策复杂、通胀持续、关税政策多变等挑战。海外项目从建设到投产周期长、不确定性高，若进展不及预期或遭遇贸易壁垒，将影响公司全球化战略的实施效果和海外市场拓展节奏。
