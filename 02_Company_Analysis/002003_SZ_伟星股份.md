# 002003.SZ 深度透视

## 因果逻辑链
- **[海外产能布局与国际化战略]** -> [海外业务逆势增长8.95%]: 在贸易摩擦加剧、国内服装出口承压的背景下，公司凭借孟加拉、越南等海外生产基地，承接了客户从中国转移的订单，实现了海外市场的结构性增长。
- **[“大辅料”战略与品类拓展]** -> [其他服饰辅料收入增长6.03%]: 公司突破传统钮扣、拉链业务，向织带、绳带、标牌等品类延伸，为下游客户提供一站式采购方案，开辟了新的收入增长点。
- **[“数智化”转型与精益管理]** -> [毛利率维持42.03%]: 通过“未来工厂”建设和精益生产体系，公司在原材料、人工成本上升的压力下，有效控制了制造成本，维持了较高的毛利率水平。
- **[下游品牌客户“强者恒强”]** -> [公司营收逆势增长2.69%]: 行业洗牌加速，中小辅料企业出清，公司作为龙头凭借品牌、品质和服务优势，持续获得中高端品牌客户的份额，实现了营收的稳健增长。
- **[股权激励与组织活力]** -> [凝聚核心团队，锁定长期目标]: 报告期推出第六期股权激励计划，覆盖196名核心骨干，将个人利益与公司中长期战略目标深度绑定，为持续增长提供人才保障。
- **[汇兑损失与财务费用激增]** -> [净利润下降7.96%]: 2025年人民币汇率波动导致汇兑净损失3536.92万元（上年同期为净收益1008.56万元），是侵蚀利润的核心因素，导致增收不增利。

## 风险警告
**核心风险在于利润对汇率的高度敏感性与海外产能爬坡的不确定性。** 2025年净利润下滑7.96%，几乎完全由汇兑损失驱动，表明公司利润表在美元结算体系下极为脆弱。同时，越南工厂仍处于产能爬坡期，报告期亏损近3000万元，若海外订单增长不及预期或当地运营成本超支，将持续拖累整体盈利。

**另一重大风险是宏观与贸易环境的持续恶化。** 公司2026年营收目标53亿元（增长10.4%），但下游服装行业出口量升价跌，终端消费疲弱。美国关税政策多变及全球产业链重构，不仅冲击公司国内出口业务，也可能导致海外客户要求进一步降价或转移订单，使公司陷入“增收不增利”甚至“量价齐跌”的困境。
