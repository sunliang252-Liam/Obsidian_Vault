# 002243.SZ 深度透视

## 因果逻辑链
- **[核心主业（新材料）增长]** -> [营收微增1.70%]: 新材料业务海外出口增长44.59%，弥补了国内销售下滑，但整体增长被创新基地平台服务收入下滑26.74%所抵消。
- **[非经常性损益主导利润]** -> [归母净利润下降27.95%]: 核心利润（扣非净利润）由盈转亏至-9416万元，主要因产业园区销售不及预期，而账面净利润依赖资产处置、金融资产公允价值变动等非经常性收益支撑。
- **[投资孵化业务波动]** -> [利润来源不稳定]: 公司价值实现主要依赖科技创投的公允价值变动与投资收益，该部分受资本市场波动影响大，2025年虽同比增长，但无法掩盖主业亏损。
- **[创新基地平台服务承压]** -> [收入与毛利率双降]: 产业园区销售去化困难，导致该板块收入同比大降26.74%，毛利率也下滑7.15个百分点，成为拖累整体业绩的核心因素。
- **[新材料业务出海]** -> [对冲国内下行风险]: 子公司丽星科技出口销售额同比增长44.59%，成功开拓欧洲、东南亚市场，是战略性新兴产业板块营收增长11.71%的主要驱动力。
- **[高财务杠杆与利息费用化]** -> [侵蚀利润]: 财务费用同比增长16.06%，主要因园区竣工后利息支出由资本化转为费用化，叠加公司整体负债水平较高，持续吞噬利润。
- **[商誉与资产减值]** -> [加剧利润下滑]: 报告期内计提资产减值损失5791.5万元，主要为商誉和存货跌价准备，反映出部分投资或资产质量面临压力。

## 风险警告
**核心风险在于“科创服务”模式的价值兑现困境。** 公司本质是一家“投资+园区运营”的混合体，其核心利润来源——科技创投业务，收益高度依赖资本市场退出和公允价值变动，具有极强的波动性和不可预测性。2025年扣非净利润巨亏，暴露了其“科技创新运营服务”和“创新基地平台服务”两大基础业务造血能力不足，尤其是园区载体销售严重不及预期，导致收入与毛利率双杀。这种依赖非经常性损益“美化”报表的模式，在资本市场下行周期中将面临严峻考验。

**第二大风险是沉重的财务负担与资产减值压力。** 公司总资产高达165.9亿元，但净资产仅73.16亿元，资产负债率超过55%。大量资金沉淀在园区载体（存货和投资性房地产）及长期股权投资中，变现周期长。同时，高额的长期借款（22.95亿元）导致财务费用持续高企，且随着园区竣工，利息费用化将进一步侵蚀利润。此外，商誉和存货的减值风险始终高悬，任何一次大规模减值都可能对利润表造成重大冲击。
