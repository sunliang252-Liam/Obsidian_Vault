# 603931.SH 深度透视

## 因果逻辑链
- **[下游面板厂控产保价]** -> [营收下滑4.6%]: 2025年下游面板厂为应对需求疲软，主动降低产能稼动率，导致公司显影液等核心产品销量与价格承压。
- **[新产能投放与市场竞争加剧]** -> [毛利率下降3.63个百分点]: 四川格林达等新产能逐步投产，叠加行业平均毛利率下降，导致显示面板业务盈利空间收窄。
- **[半导体业务拓展不及预期]** -> [半导体业务收入骤降28.32%]: 公司在半导体领域的客户导入和量供进程慢于预期，未能有效对冲显示面板业务的下滑。
- **[认购沐曦股份战略配售]** -> [其他权益工具投资激增至4.43亿]: 公司以自有资金参与GPU公司沐曦股份的战略配售，导致非流动资产大幅增加，资产结构发生重大变化。
- **[剥离液产品实现全链条闭环]** -> [新产品拓展取得突破]: 剥离液产品成功导入维信诺、惠科等客户，并实现生产与回收循环利用，构建了新的增长点。
- **[经营活动现金流净额下降43.38%]** -> [现金回收压力增大]: 销售回款减少，导致经营性现金流大幅萎缩，反映出下游客户付款周期延长或公司销售政策调整。
- **[四川格林达项目投产]** -> [子公司亏损拖累合并利润]: 四川格林达尚处于产能爬坡期，2025年亏损586.93万元，对合并报表净利润产生负向影响。

## 风险警告
**核心风险在于下游显示面板行业的周期性波动与公司业绩的强相关性。** 2025年营收与利润双降，直接源于面板厂为应对终端需求疲软而采取的控产保价策略。公司客户高度集中（前五名客户销售额占比77.16%），且深度绑定京东方、华星光电等头部面板厂，一旦主要客户经营波动或技术路线变更，公司业绩将遭受剧烈冲击。半导体业务虽有布局，但收入同比大幅下滑28.32%，短期内难以成为业绩稳定器。

**另一个关键风险是资产结构变化带来的不确定性。** 公司动用近8亿元自有资金认购沐曦股份战略配售，导致其他权益工具投资激增至4.43亿元，占总资产比例高达20.65%。这笔投资属于高风险的股权投资，其公允价值变动将直接影响公司净资产，且短期内无法贡献稳定现金流。同时，四川格林达等新项目仍处于亏损状态，产能利用率仅17.58%，未来能否顺利爬坡并实现盈利存在较大不确定性，若持续亏损将进一步侵蚀公司利润。
