# 300932.SZ 深度透视

## 因果逻辑链
- **[境外市场拓展]** -> [营收增长6.44%]: 境外营收同比增长29.63%，占比提升至28.86%，成为核心增量引擎。
- **[聚焦大客户战略]** -> [业绩稳健增长]: “铁三角团队”精准对接需求，提升前几大客户收入占比，增强客户粘性。
- **[继电器主业量价齐升]** -> [净利润增长14.71%]: 继电器销量增长13.02%，营收增长8.02%，规模效应摊薄固定成本。
- **[纵向一体化与自动化]** -> [成本控制与毛利率稳定]: 核心零部件自产及全自动产线降低人工成本，对冲原材料涨价，毛利率仅微降0.5个百分点。
- **[青县择明产能释放]** -> [资产结构变化]: 新厂房验收转固，固定资产占比提升7.95%，在建工程占比下降6.21%，产能进入爬坡期。
- **[研发聚焦高附加值产品]** -> [产品结构优化]: 重点研发环氧密封高压直流继电器、光伏继电器等，切入新能源、储能等高景气赛道，提升单品毛利。
- **[全球化布局深化]** -> [抗周期能力增强]: 海外子公司（韩国、北美、欧洲）及越南产能布局，分散单一市场风险，境外销售占比持续提高。

## 风险警告
**核心风险在于原材料价格波动与汇率波动。** 公司主营成本中直接材料占比超60%，银、铜、铁等大宗商品价格受国际市场影响巨大，若无法有效向下游传导成本，毛利率将承压。同时，境外业务占比近30%且持续扩大，人民币汇率双向波动将直接产生汇兑损益，影响净利润稳定性。

**另一个关键风险是产品板块集中与行业竞争加剧。** 公司继电器收入占比超83%，且国内继电器行业集中度低，竞争激烈。虽然公司排名第二，但若家电、智能电表等传统下游需求放缓，或新能源、汽车等新赛道拓展不及预期，业绩增长将面临瓶颈。此外，青县择明互感器业务营收同比下降9.75%，新产能消化存在不确定性。
