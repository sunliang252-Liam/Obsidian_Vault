# 600170.SH 深度透视

## 因果逻辑链
- **[行业需求萎缩]** -> [营收与利润双降]: 2025年建筑业总产值同比下降5.43%，房地产开发投资下降17.2%，公司新签合同额降至2,529亿元，导致营业收入同比下滑31.38%，归母净利润同比下滑42.93%。
- **[核心主业收缩]** -> [扣非净利润几近归零]: 建筑施工、建材工业、城建投资三大核心业务营收分别下滑34.64%、19.84%、27.48%，导致扣除非经常性损益后的净利润仅余6.2亿元，同比暴跌89.87%。
- **[非经常性损益支撑]** -> [账面利润失真]: 归母净利润12.37亿元中，非经常性损益高达11.75亿元（含政府补助7.06亿、资产减值转回5.29亿、金融资产收益3.16亿），剔除后主业盈利能力极弱。
- **[资产减值侵蚀]** -> [利润进一步承压]: 报告期计提资产减值损失8.95亿元，同比增加85.91%，主要来自合同资产和商誉减值，直接吞噬了本已微薄的经营利润。
- **[现金流大幅恶化]** -> [经营质量下降]: 经营活动现金流净额65.6亿元，同比减少45.93%，主因营业规模下降导致销售回款减少，反映行业资金链普遍紧张。
- **[化债政策红利]** -> [应收账款回收改善]: 公司积极把握地方化债政策窗口，期末应收账款余额较期初下降近100亿元，城建投资项目实现资金回款近80亿元，缓解了部分流动性压力。
- **[金矿业务对冲]** -> [业绩缓冲垫]: 控股的厄立特里亚科卡金矿在黄金价格高位运行下，贡献净利润1.98亿元，成为稳定业绩的显著因素，对冲了主业的周期性下滑。

## 风险警告
**核心风险在于主业盈利能力已实质性崩溃。** 2025年扣非净利润仅6.2亿元，对应近2060亿营收，扣非净利率不足0.3%。公司利润高度依赖政府补助、金融资产处置和减值转回等非经常性损益，一旦这些“调节阀”失效，账面利润将面临归零甚至亏损的风险。建筑行业需求萎缩、竞争加剧的态势短期内难以逆转，公司“力争新签订单2,500亿元、营收1,900亿元”的经营计划，本质上是承认了规模将继续收缩。

**财务风险与资产质量风险交织。** 公司担保总额高达614.62亿元，占净资产比例121.79%，其中为资产负债率超70%的子公司担保达529亿元，杠杆风险极高。同时，大量PPP项目（如眉山、青岛、珠海项目）回款进度不及预期，在建项目累计回款远低于累计投入，存在较大的长期应收款减值风险。在行业下行周期，这些表外和表内的隐性风险可能集中暴露。
