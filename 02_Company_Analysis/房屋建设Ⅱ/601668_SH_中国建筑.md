# 601668.SH 深度透视

## 因果逻辑链
- **[房地产行业深度调整]** -> [营收下降4.8%]: 房地产开发与投资业务营收同比下降7.2%，拖累整体营收从2.19万亿降至2.08万亿。
- **[主动优化业务结构]** -> [房建住宅占比下降]: 房建业务中住宅新签合同额占比降至20%，工业厂房等公共建筑占比升至33.3%，业务结构向高端制造转型。
- **[高息债务置换]** -> [财务费用下降9.4%]: 公司积极把握融资政策窗口，推动高息债务置换，平均融资成本降低，财务费用从195亿降至176亿。
- **[加强现金流管控]** -> [经营性净现金流连续6年为正]: 公司狠抓投资回款和负流项目治理，经营现金流净额达205亿，同比增长29.8%。
- **[海外高质量发展战略]** -> [境外营收增长19.4%]: 公司深耕东南亚、西亚等重点市场，境外营收达1417亿元，成为增长最快板块。
- **[“好房子”体系落地]** -> [地产毛利率提升2.9个百分点]: 公司发布“好房子”营造体系，加强精益建造和科技赋能，地产毛利率逆势提升至14.4%。
- **[能源工程高速增长]** -> [基建新签合同额增长4.1%]: 能源工程新签合同额5870亿元，同比增长17.2%，成为基建业务最大增长极，占比升至39.9%。
- **[“厉行节约”专项行动]** -> [管理费用下降2.2%]: 公司持续深化勤俭办企行动，管理费用从346亿降至339亿，成本管控成效显著。

## 风险警告
**核心风险在于利润持续下滑与地产存货去化压力。** 公司归母净利润已连续两年大幅下滑，2025年同比降幅达15.4%，扣非净利润降幅更是高达23.2%。地产板块合约销售额同比下降6.4%，期末土地储备高达6961万平方米，在行业深度调整背景下，存货减值风险与资金沉淀压力持续累积。同时，房地产开发投资回款同比下降15.7%，投资收支比降至116.4%，现金流回收效率恶化。

**第二大风险来自行业竞争加剧与盈利空间收窄。** 公司整体毛利率仅9.9%，与上年持平，但房建、基建两大核心板块毛利率均处于低位（8.4%、9.9%）。勘察设计业务新签合同额同比下降10%，显示前端业务承压。此外，PPP项目存量管理压力较大，已运营项目权益投资额达5097亿元，回款管控长效机制面临考验。海外业务毛利率仅2.8%，同比下降2.2个百分点，国际化业务盈利质量堪忧。
