# 000062.SZ 深度透视

## 因果逻辑链
- **[AI算力基建与存储需求爆发]** -> [营收创历史新高]: 公司把握AI发展机遇，服务器ODM、数据中心电源、光模块等销售规模增长，存储类产品线授权分销收入同比大幅增长，推动电子元器件交易业务高质量增长。
- **[半导体国产替代深化]** -> [本土产品线收入持续增长]: 公司发挥布局早、覆盖广、合作深等优势，海思、纳芯微等本土产品线销售收入连续两年快速增长，本土产品线出货金额占比超60%。
- **[长尾采购业务数字化系统优势]** -> [长尾采购业务收入增长]: 公司自主研发的EBS系统高效匹配客户现货采购需求，快速满足客户小批量、多样化、高频的长尾采购需求，有力推动业务增长。
- **[华强科创广场出租率提升]** -> [物业经营业绩稳健提升]: 项目依托优越地理位置和合理产业定位，总体出租率稳居深圳福田区前列，净增签约面积约2.5万平方米，为业绩贡献增量。
- **[存货减值与汇兑损失减少]** -> [净利润增速远超营收]: 公司计提资产减值准备同比减少，汇兑损失同比减少，利息支出同比减少，多重因素叠加使归母净利润同比增长117.38%。
- **[电子元器件交易行业集中度提升]** -> [龙头地位巩固]: 行业竞争格局高度分散，公司作为本土龙头，通过并购整合和内生发展，市场份额持续扩大，规模效应显著。
- **[CVC投资与昇腾生态布局]** -> [储备未来增长动能]: 公司开展CVC投资卡位半导体设计企业，并成为昇腾合作伙伴，构建AI业务基本盘，为长期可持续发展注入新动能。

## 风险警告
**核心风险在于经营活动现金流大幅恶化与应收账款激增。** 2025年公司营收增长13.46%，但经营活动现金流净额由正转负，从+14.42亿元骤降至-9.90亿元，降幅达168.67%。直接原因是业务规模扩张导致采购支出增加，同时销售回款存在账期，期末应收账款较年初增长25.7%至70.82亿元，占总资产比例高达38.52%。这种“增收不增现”的扩张模式，若下游客户信用环境恶化或回款周期进一步拉长，将严重侵蚀公司资金链，并可能引发大规模坏账风险。

**商誉减值风险是悬在头顶的达摩克利斯之剑。** 公司通过2015-2018年密集并购切入电子元器件分销领域，形成了高达16.97亿元的商誉，占净资产的25.2%。尽管被收购企业均超额完成业绩承诺，但电子元器件行业具有强周期性，若未来行业景气度下行或市场竞争加剧导致被收购企业经营效益不达预期，巨额商誉减值将直接冲击利润表，对净资产造成重大打击。
