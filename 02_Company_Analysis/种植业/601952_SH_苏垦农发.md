# 601952.SH 深度透视

## 因果逻辑链
- **[农产品价格下行]** -> [营收与利润双降]: 2025年公司营收下降7.75%，归母净利润下降24.96%，核心原因是稻麦、食用油等主要农产品市场价格低迷，导致销售规模与盈利空间同步收窄。
- **[极端自然灾害]** -> [种植成本上升，毛利率承压]: 遭遇1961年以来最严重冬春连旱及罕见秋粮灾害，虽通过全产业链调度稳产，但抗灾投入推高了种植业营业成本（+4.93%），导致种植业毛利率下降5.04个百分点。
- **[麦芽行业产能过剩]** -> [麦芽业务利润被极端挤压]: 全国麦芽产能超500万吨，远超380万吨需求，吨麦芽出厂价同比大跌超700元，公司麦芽业务虽转向高端与出口，但整体盈利仍受行业“红海”竞争严重拖累。
- **[农资贸易主动收缩]** -> [营收规模下降，但现金流改善]: 为控制经营风险，公司主动压降外采及赊销规模，农资服务与销售收入下降18.23%，但经营活动现金流净额同比大增53.93%，显示经营质量提升。
- **[稻强米弱格局持续]** -> [大米加工利润微薄]: 终端大米市场供需宽松，成本传导受阻，公司大米加工毛利率仅3.26%，处于微利状态，反映出下游消费疲软对产业链的压制。
- **[收购金太阳粮油少数股权]** -> [归母权益增厚，但少数股东权益减少]: 公司以1.78亿元收购金太阳粮油28.75%股权，持股比例升至80%，此举增厚了归属于母公司的净利润，但导致少数股东权益下降37.49%。

## 风险警告
**核心风险在于农产品价格周期与极端天气的双重夹击。** 公司业绩对稻麦、食用油等大宗农产品价格高度敏感，2025年利润大幅下滑已充分暴露此脆弱性。若未来国家粮食最低收购价政策调整或市场供需持续宽松，公司盈利将面临进一步压缩。同时，极端天气常态化趋势下，农业生产的不确定性显著增加，即便有保险覆盖，重大灾害仍可能直接冲击产量与成本。

**第二重风险来自部分子行业的激烈竞争与转型压力。** 麦芽行业严重的产能过剩导致价格战，公司高端化转型尚需时日；食用油行业CR5已达65.9%，公司作为区域品牌面临全国性巨头的挤压。此外，公司约95.5万亩核心耕地依赖与控股股东的土地承包协议，该协议到期日为2041年，但任何政策或协议条款的变动，都将动摇公司最根本的资产基础。
