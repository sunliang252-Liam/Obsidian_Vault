# 600313.SH 深度透视

## 因果逻辑链
- **[化肥贸易量价齐升]** -> [营收增长19.6%]: 华垦国际通过拓展进口渠道和客户群，化肥销量与收入同比大增25.39%，贡献了总营收的59.7%，成为业绩增长的核心引擎。
- **[农药板块大幅减亏]** -> [利润改善]: 河南农化通过工艺优化、降本增效和提升主要产品市场份额，农药业务毛利同比大增198.72%，显著减少了整体亏损。
- **[种子业务结构性分化]** -> [利润承压]: 小麦种子受连阴雨和自留种冲击，但玉米、大豆种子通过拓宽渠道和提价实现毛利提升，专用粮业务逆势增长，整体种子板块营收增长9.59%。
- **[非经常性损益高企]** -> [归母净利润虚高]: 扣非归母净利润仅0.2亿元，而归母净利润达0.84亿元，主要依赖政府补助（0.73亿）和资产处置收益（0.18亿），主业盈利能力薄弱。
- **[现金流大幅转正]** -> [经营质量改善]: 经营活动现金流净额从-0.77亿跃升至3.02亿，主要系销售回款增加，表明公司在收入增长的同时加强了现金管理。
- **[定向增发补充资金]** -> [资本结构优化]: 向控股股东及关联方定增募资4.02亿元，补充流动资金，降低了财务成本，增强了公司资金实力和业务拓展能力。
- **[研发投入聚焦生物育种]** -> [长期竞争力]: 研发投入1.27亿元（扣除贸易后占营收4.74%），重点布局转基因、基因编辑等前沿技术，35个新品种通过审定，为未来抢占生物育种市场奠定基础。

## 风险警告
**核心风险在于主业盈利能力极弱，高度依赖非经常性损益和化肥贸易。** 2025年扣非归母净利润仅0.2亿元，而政府补助和资产处置收益合计高达0.91亿元，剔除后公司主业几乎不赚钱。化肥贸易业务毛利率仅2.47%，且受国际钾肥价格、汇率及地缘政治影响巨大，业绩波动性极高，并非可持续的利润来源。

**子公司整合与业绩承诺不达标风险突出。** 农药子公司河南农化虽减亏但仍亏损0.14亿元，新设的南阳农业2025年业绩承诺完成率仅50.5%，表明公司对子公司的管控和协同效应尚未完全实现。此外，控股股东中国农垦集团所持股份存在冻结和质押情况，可能影响公司治理稳定性。
