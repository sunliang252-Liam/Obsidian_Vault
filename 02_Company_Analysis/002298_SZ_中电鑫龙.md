# 002298.SZ 深度透视

## 因果逻辑链
- **[智慧城市业务客户支付能力下降]** -> [巨额资产减值]: 部分智慧城市项目受行业周期影响，客户支付能力下降，导致公司对相关资产计提大额减值损失（含商誉减值2.46亿元），是全年巨亏4.23亿元的核心原因。
- **[子公司北京中电兴发持续亏损]** -> [拖累整体业绩]: 子公司智慧城市业务亏损2.72亿元，叠加对其计提商誉减值，直接导致合并报表层面归属于上市公司股东的净利润为负。
- **[智慧用能及新能源业务盈利]** -> [对冲部分亏损]: 智慧用能及新能源板块协同发力，实现净利润1.18亿元（归母0.94亿元），成为公司唯一盈利的板块，部分抵消了智慧城市业务的巨额亏损。
- **[非经常性损益大幅增加]** -> [改善账面净利润]: 报告期确认债务豁免等非经常性损益2.90亿元，使得归母净利润亏损额从扣非后的-7.13亿元收窄至-4.23亿元。
- **[经营活动现金流净额转正]** -> [经营质量改善]: 尽管净利润巨亏，但经营活动现金流净额为0.86亿元（同比+7.6%），主要得益于销售回款增加，显示核心业务造血能力尚存。
- **[处置子公司及资产]** -> [优化资产结构]: 公司出售伊宁县智慧城市等子公司股权，并收到出售广西联通特许经营权款项，投资活动现金流净额大幅转正至1.39亿元，旨在盘活低效资产、聚焦主业。
- **[商誉减值风险持续释放]** -> [未来财务风险降低]: 对并购北京中电兴发形成的商誉计提2.46亿元减值后，商誉账面价值大幅下降，未来因商誉减值导致业绩暴雷的风险显著降低。

## 风险警告
公司最核心的风险在于智慧城市业务板块的持续恶化。子公司北京中电兴发深陷客户支付能力下降、项目回款周期拉长的泥潭，导致应收账款和合同资产减值风险高企，并已连续多年计提巨额商誉减值。尽管公司已采取战略收缩、资产处置等措施，但该板块的经营困境尚未出现根本性扭转，未来仍可能继续侵蚀公司利润，是悬在业绩上的最大不确定性。

其次，公司盈利高度依赖非经常性损益。2025年扣非净利润亏损高达7.13亿元，而账面亏损收窄主要依靠债务豁免等一次性收益。这表明公司主营业务的盈利能力依然薄弱，尤其是智慧城市业务处于亏损状态。若未来无法有效提升核心业务的盈利水平，或非经常性损益不可持续，公司将面临持续的财务压力。
