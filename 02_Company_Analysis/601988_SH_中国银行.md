# 601988.SH 深度透视

## 因果逻辑链
- **[低利率环境下的净息差收窄]** -> [净利息收入下降1.83%]: LPR下调及外币市场利率下降导致生息资产收益率下降49BP，虽通过存款成本管控（付息率下降37BP）对冲，但净息差仍收窄14BP至1.26%。
- **[非利息收入高增长]** -> [营收增长4.28%]: 把握资本市场回暖及金融市场波动机遇，代理业务、净交易收益及贵金属销售收入大幅增长，非利息收入占比提升至33.21%，有效对冲利息收入下滑。
- **[全球化优势巩固]** -> [境外利润贡献度提升至27.99%]: 境外商行及综合经营公司资产、营收、税前利润贡献度保持高位，跨境结算客户突破40万户，跨境电商结算规模首破万亿。
- **[信贷结构优化与资产质量稳定]** -> [不良率下降0.02个百分点至1.23%]: 加大制造业、绿色、普惠等重点领域信贷投放，同时强化风险管控，新发生不良逐季改善，拨备覆盖率维持200%以上。
- **[资本补充与核心指标改善]** -> [核心一级资本充足率升至12.53%]: 完成1650亿元核心一级资本补充，核心一级资本充足率达历年最高，为业务扩张提供充足资本缓冲。
- **[综合化经营协同效应]** -> [综合经营利润贡献度领先]: 投资银行、保险、租赁等子公司联动融资项目数量显著提升，综合化服务能力增强，贡献度保持中资同业领先。
- **[科技赋能与数字化转型]** -> [运营效率提升与成本收入比下降]: 部署大模型平台，构建400余个智能化助手，个人手机银行月活客户达1.05亿户，成本收入比降至27.84%。

## 风险警告
**核心风险在于净息差持续收窄与资产质量承压的双重挤压。** 在LPR下行及低利率环境下，净息差已降至1.26%，且未来仍有进一步收窄压力。同时，房地产不良率从4.94%升至6.26%，个人消费贷款不良率从1.60%升至2.18%，资产质量结构性风险需高度关注。尽管拨备覆盖率仍超200%，但信用成本若持续上升将侵蚀利润。

**全球化优势面临地缘政治与监管不确定性。** 境外资产占比超22%，覆盖64个国家和地区，但贸易保护主义、地缘冲突及部分国家监管政策变化可能冲击跨境业务。境外不良贷款虽实现双降，但1.56%的不良率仍高于境内，且人民币国际化进程中的汇率波动风险需持续管理。
