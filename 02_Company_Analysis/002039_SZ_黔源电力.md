# 002039.SZ 深度透视

## 因果逻辑链
- **[来水大幅偏多]** -> [发电量激增71.9%]: 2025年流域来水较上年偏多45%，直接推动水电发电量同比暴增80.89%，是业绩爆发的核心驱动力。
- **[发电量增加]** -> [营收增长69.98%]: 总发电量从70.51亿千瓦时跃升至121.20亿千瓦时，带动电力销售收入同比大增70.41%。
- **[营收高增叠加固定成本摊薄]** -> [净利润暴增175%]: 水电毛利率提升6.81个百分点，归母净利润从2.18亿飙升至6.00亿，利润弹性远大于收入弹性。
- **[财务费用下降]** -> [利润增厚]: 通过存量高息贷款置换，财务费用同比减少23.37%，节省约6560万元，直接增厚净利润。
- **[折旧费刚性增长]** -> [成本结构固化]: 折旧费同比大增51.83%，占总成本57.49%，是水电企业最大的固定成本，对来水依赖度极高。
- **[光伏装机容量规范下调]** -> [光伏收入微降]: 因政策要求按交流侧容量登记，总装机从87.21万千瓦降至73.96万千瓦，光伏发电量同比减少7.19%。
- **[经营活动现金流强劲]** -> [偿债能力改善]: 经营活动现金流净额达24.34亿元，同比增长93.63%，远超净利润，为降杠杆提供充足现金。
- **[资产负债率下降]** -> [财务风险缓释]: 资产负债率从56.14%降至48.85%，同比下降约6个百分点，财务结构趋于稳健。

## 风险警告
**核心风险在于业绩对来水的高度依赖，具有极强的不可预测性。** 2025年净利润暴增175%主要源于来水偏多45%这一“天时”，而非经营能力的根本性提升。一旦来水回归正常或偏枯，发电量和利润将面临剧烈下滑。公司2026年经营计划中发电量目标仅为93.98亿千瓦时，较2025年实际值下降22.5%，利润目标11亿元也较2025年实际值下降18.3%，管理层自身已对业绩回落有明确预期。

**电价下行与政策风险是长期隐忧。** 随着电力市场化改革深化，电价已从固定定价转向市场交易决定，面临实时波动下行风险。同时，新能源补贴政策、环保监管趋严及“两个细则”考核等政策不确定性，将持续压缩公司盈利空间。公司光伏业务毛利率已同比下降11.15个百分点，显示竞争加剧。
