# 301507.SZ 深度透视

## 因果逻辑链
- **[益生菌业务并表]** -> [食品业务收入暴增102%]: 2025年1月收购民生中科（山东）55%股权并纳入合并报表，直接推动食品业务收入从1.58亿跃升至3.19亿，成为营收增长的核心增量。
- **[核心单品依赖度下降]** -> [营收结构优化]: 多维元素片（21）收入占比从68.89%降至50.79%，益生菌、治疗型用药等新业务贡献提升，产品结构单一风险有所缓解。
- **[非经常性损益驱动利润]** -> [归母净利润增速远超扣非净利润]: 归母净利润增长29.35%，但扣非净利润仅增5.54%，差异主要来自战略配售技源集团股份产生的2,380万元公允价值变动收益。
- **[线上渠道高增长]** -> [销售模式变革]: 电商及其他渠道收入同比增长129.48%，占总营收比重从12.19%升至22.94%，线上分销与即时零售成为新增长极。
- **[收购业绩承诺达标]** -> [商誉减值风险短期可控]: 民生中科（浙江）2025年扣非净利润634.51万元，完成业绩承诺的105.75%，商誉减值测试未发现减值。
- **[销售费用率维持高位]** -> [品牌投入与渠道竞争加剧]: 销售费用同比增长12.97%至2.15亿元，占营收27.54%，电商平台服务费与广告投放持续高企，反映行业获客成本上升。
- **[研发投入资本化率为零]** -> [研发成果转化周期长]: 研发费用2,608万元全部费用化，虽新增3项药品批文（戒烟、生发），但短期内难以贡献显著利润。

## 风险警告
**核心风险：产品结构单一与增长可持续性存疑。** 尽管多维元素片（21）收入占比已从81.86%降至50.79%，但仍是公司绝对支柱。食品业务102%的增长主要依赖并购并表，而非内生性增长。剔除收购影响后，药品业务收入同比下降4.43%，显示传统核心业务增长乏力。若核心单品遭遇政策冲击（如集采、OTC转处方药）或市场竞争加剧，公司业绩将面临剧烈波动。

**财务风险：非经常性损益粉饰利润，现金流质量需警惕。** 2025年归母净利润1.19亿元中，非经常性损益贡献2,675万元（占比22.5%），主要来自金融资产公允价值变动。扣非净利润增速仅5.54%，远低于营收增速21.89%，反映主营业务盈利能力并未同步提升。同时，经营性现金流净额1.77亿元虽大幅改善，但需关注应收账款周转及存货管理效率，避免因渠道扩张导致资金占用恶化。
