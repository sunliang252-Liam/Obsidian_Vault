# 600132.SH 深度透视

## 因果逻辑链
- **[产品结构高端化]** -> [毛利率提升2.32个百分点至52.03%]: 高档产品（8元以上）收入增长2.19%，占比提升，驱动整体盈利改善。
- **[成本端优化]** -> [营业成本下降3.97%]: 原料成本下降2.89%、其他成本下降10.39%，有效对冲了销售费用和管理费用的增长。
- **[非现饮渠道扩张]** -> [销量逆势增长]: 在行业产量下降1.1%的背景下，公司总销量增长，得益于O2O、电商、便利店等新兴渠道的拓展。
- **[1L装产品放量]** -> [高端化与渠道扩张的交叉点]: 1L装新品成为非现饮渠道重要增长动力，同时带动了高端产品矩阵的完善。
- **[嘉士伯集团赋能]** -> [ESG与运营效率领先]: 依托嘉士伯“嘉速扬帆”战略，公司在ESG（MSCI AA评级）、供应链效率（劳动生产率高个位数增长）和成本控制上持续获得集团支持。
- **[高分红政策]** -> [股东回报确定性高]: 2025年全年分红率高达98.30%，每股合计派息2.50元，强化了价值投资逻辑。
- **[与重庆嘉威诉讼和解]** -> [消除重大不确定性]: 与参股子公司的包销协议诉讼以调解结案，大幅减少了潜在的巨额赔偿风险，释放了估值压力。

## 风险警告
**核心风险在于行业存量竞争加剧与成本波动。** 中国啤酒行业已进入存量市场，五大巨头市场份额超90%，竞争白热化。公司在中区（核心腹地）营收同比下降1.43%，显示基地市场正面临激烈冲击。同时，原料、包材、能源及人力成本受地缘政治和气候影响，存在较大波动风险，可能侵蚀已优化的毛利率。

**第二重风险是增长引擎的可持续性。** 公司营收增速仅0.53%，几乎停滞，增长主要依赖利润端的成本优化和结构升级。高档产品销量增速（3.23%）虽快于主流（-1.95%），但整体销量增长更多依赖非现饮渠道的扩张，而非消费场景的根本性复苏。若消费升级趋势放缓或成本端压力重现，公司利润增长将面临严峻挑战。
