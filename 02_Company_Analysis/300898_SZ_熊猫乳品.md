# 300898.SZ 深度透视

## 因果逻辑链
- **[椰品业务爆发式增长]** -> [营收结构优化]: 椰品收入同比+124%，成为第二增长曲线，弥补了乳品贸易收缩带来的缺口。
- **[原材料价格上涨]** -> [毛利率承压]: 直接材料成本同比+8.18%，导致综合毛利率下降2.82个百分点，扣非净利润同比-16.85%。
- **[经销网络深化]** -> [核心市场稳固]: 经销商数量增至414家，华东、华南优势市场收入稳健增长，经销模式收入同比+6.01%。
- **[国产替代窗口期]** -> [奶油业务机遇]: 原奶价格低位+欧盟反补贴税，国产奶油性价比凸显，公司常温稀奶油技术降低冷链成本。
- **[B端定制化研发]** -> [大客户粘性增强]: 为古茗、香飘飘等提供定制化解决方案，直销收入同比+40.28%，前五大客户占比20.94%。
- **[产能扩张与诉讼拖累]** -> [募投项目延期]: 苍南年产3万吨项目因厂房沉降诉讼延期至2027年，核心产能释放受阻。
- **[并购整合]** -> [商誉与协同风险]: 收购优鲜工坊（奶酪零食）和海南椰达（植物基），新增商誉4468万元，整合效果待验证。

## 风险警告
**核心风险在于“增收不增利”与“产能瓶颈”的双重挤压。** 2025年扣非净利润同比下滑16.85%，主因原材料成本上涨侵蚀利润，而公司作为炼乳龙头，对上游奶粉、白砂糖价格波动缺乏有效对冲，毛利率持续承压。同时，核心募投项目“苍南年产3万吨”因厂房沉降诉讼一拖再拖，产能释放严重滞后，制约了公司在炼乳、稀奶油等优势品类的市场扩张。

**第二增长曲线（椰品、奶酪）的盈利质量堪忧。** 椰品毛利率仅2.91%，且库存同比翻倍，表明该业务尚处于“烧钱换规模”阶段，盈利能力远弱于浓缩乳制品。收购优鲜工坊带来的商誉（4468万元）和业绩承诺（2026-2027年净利润均值不低于540万元）构成潜在减值风险。此外，公司经营现金流同比骤降67.79%，与净利润严重背离，需警惕营运资金管理效率下降。
