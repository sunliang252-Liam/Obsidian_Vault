# 002138.SZ 深度透视

## 因果逻辑链
- **[AI服务器与数据中心需求爆发]** -> [电源管理业务营收增长19.34%]: 公司围绕GPU/CPU/ASIC芯片端供电模组实现客户全覆盖，高功率密度电感与钽电容产品受益于AI算力硬件升级。
- **[汽车电子全球化布局深化]** -> [汽车电子或储能专用业务营收增长38.10%]: 作为少数进入全球汽车电子供应链的中国磁性元件厂商，产品覆盖三电系统至智能驾驶全场景。
- **[研发投入持续加码（+22.73%）]** -> [技术壁垒与产品组合优势巩固]: 构建“应用场景→产品开发→技术平台→基础研究”闭环，支撑在高端电感、LTCC滤波器等领域的全球竞争力。
- **[分销渠道扩张（+55.39%）]** -> [营收规模突破67.45亿元]: 分销模式收入增速远超直销，表明公司正通过渠道下沉加速覆盖中小客户与新兴应用市场。
- **[规模效应与效率提升]** -> [毛利率稳定在36.64%]: 尽管原材料与人工成本上涨，公司通过扩大产能、自动化产线与工艺优化，有效消化成本压力。
- **[员工持股与超额收益激励]** -> [核心团队稳定性与创新活力]: 第五期员工持股计划覆盖701人，叠加年度超额收益激励金制度，绑定管理层与股东利益。
- **[氢燃料电池（SOFC）预研]** -> [打开中长期增长天花板]: 固体氧化物电池业务进展顺利，为公司在新能源长时储能与分布式供电领域创造新赛道。

## 风险警告
**专利诉讼与地缘政治风险交织。** 公司与全球龙头村田制作所之间专利诉讼持续升级（2025年新增5起案件），虽前期5起已撤诉，但后续案件仍在审理中，且公司已反诉对方恶意诉讼。若败诉，可能面临产品禁售或高额赔偿。同时，年报明确提示地缘政治环境风险，公司出口销售占比15.26%，全球贸易摩擦可能影响海外客户订单与供应链稳定性。

**高杠杆扩张与库存积压风险。** 公司报告期末实际担保余额占净资产比例高达146.77%，且直接或间接为资产负债率超70%的子公司提供担保余额达29.41亿元，财务杠杆处于高位。同时，电子元器件库存量同比暴增32.47%，远超营收增速（14.39%），若下游需求（尤其是消费电子）不及预期，将面临存货跌价与产能利用率下降的双重压力。
