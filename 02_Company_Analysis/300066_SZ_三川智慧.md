# 300066.SZ 深度透视

## 因果逻辑链
- **[稀土价格企稳回升 + 内部精细化运营]** -> **净利润大幅增长122.80%**: 稀土板块扭亏为盈，叠加公允价值变动收益，驱动归母净利润从0.64亿跃升至1.42亿。
- **[稀土板块主动收缩贸易业务]** -> **营业收入下降21.91%**: 公司聚焦自产，大幅削减低毛利的稀土贸易，导致营收从14.73亿降至11.51亿，但业务结构更健康。
- **[5G数智工厂投产 + 精益生产]** -> **智能水表毛利率承压但产能效率提升**: 新工厂投产初期磨合成本及原材料波动，导致智能水表毛利率下降2.82个百分点，但全链自动化率超95%，为未来降本增效奠定基础。
- **[稀土价格波动 + 存货跌价准备转回]** -> **稀土板块毛利率大幅改善**: 2025年稀土氧化物价格上涨，前期计提的存货跌价准备大额转回，推动稀土业务毛利率从-17.05%提升至3.79%。
- **[销售回款周期长 + 经营性应收应付变动]** -> **经营活动现金流净额大幅下降87.18%**: 尽管净利润增长，但销售收现减少及税费支付增加，导致经营性现金流净额仅0.17亿，与净利润严重背离。
- **[天和永磁业绩补偿款 + 理财收益]** -> **非经常性损益贡献主要利润**: 公允价值变动收益（含业绩补偿）及投资收益合计1.15亿，占利润总额的67%，扣非净利润仅0.64亿，盈利质量待考。
- **[智慧水务“一体两翼”战略 + 海外布局]** -> **海外业务收入增长8.52%**: 通过“借船出海”与投资建厂，海外市场成为对冲国内需求收缩的重要增长极。

## 风险警告
**盈利质量与现金流严重背离是最大隐忧。** 公司2025年归母净利润1.42亿，但经营活动现金流净额仅0.17亿，且扣非净利润仅0.64亿。利润主要依赖公允价值变动收益（含天和永磁业绩补偿款）及投资收益，主业造血能力并未实质性改善。若稀土价格再度下行或补偿款无法持续，业绩将面临剧烈波动。

**稀土业务依赖价格周期，可持续性存疑。** 稀土板块扭亏高度依赖产品价格上涨及存货跌价转回，而非产能或技术的根本性突破。同时，天和永磁2024年度业绩补偿款尚未执行到位，存在坏账风险。该业务受政策、供需及国际环境影响极大，周期性波动将直接冲击公司整体盈利稳定性。
