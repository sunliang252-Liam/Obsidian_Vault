# 688605.SH 深度透视

## 因果逻辑链
- **[半导体设备国产替代浪潮]** -> [营收增长8.98%]: 公司作为刻蚀和薄膜沉积设备关键零部件供应商，深度绑定北方华创、中微公司等头部客户，受益于国产替代需求持续增长。
- **[产能扩张与爬坡期]** -> [毛利率下降4.93个百分点]: 2024年起新增产能逐步启用，但产能利用率尚未完全释放，固定成本（折旧、人工）先行增加，导致成本增速（16.89%）显著快于收入增速（8.98%）。
- **[先进制程零部件需求增加]** -> [成本上升]: 为满足7nm及以下制程对洁净度、耐腐蚀性的严苛要求，公司增加洁净室、清洗工序、高端检测设备等投入，推高单位成本。
- **[员工人数快速增长]** -> [薪酬支出增加]: 2025年员工总数达1,522人，薪酬支出增加，叠加产能爬坡期效率未完全释放，进一步压缩利润空间。
- **[收购无锡至辰]** -> [表面处理业务收入增长58.76%，但毛利率下降20.23个百分点]: 新增涂层工艺丰富产品线，但无锡至辰涂层业务毛利率低于原有水平，且靖江先捷表处产线尚处爬坡期，拉低整体毛利率。
- **[客户高度集中]** -> [业绩依赖性强]: 前五大客户（北方华创、中微公司、屹唐股份、拓荆科技、中硅泰克）合计销售额占比80.78%，单一客户订单波动将直接冲击公司业绩。
- **[经营活动现金流净额增长87.84%]** -> [营运资金管理改善]: 销售收入增长且回款良好，公司加强应收账款和存货管理，现金流状况显著优于利润表现。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以扭转。** 公司营收增长8.98%，但归母净利润同比下降11.71%，主因是产能扩张带来的固定成本刚性增长与先进制程零部件的高额投入，导致毛利率从高位回落。2025年制造费用占主营业务收入比重增加约6.45个百分点，且运费因交期缩短而增加。若下游半导体设备投资增速放缓，公司新增产能将面临利用率不足的风险，进一步侵蚀利润。

**客户集中度极高且产品结构单一构成重大隐患。** 前两大客户北方华创和中微公司合计贡献62%的营收，公司产品以金属精密零部件为主，暂未涉及石英、硅/碳化硅等非金属零部件，且模组产品收入规模较小。一旦主要客户转向自研或更换供应商，或半导体行业进入周期性下行通道，公司业绩将面临断崖式下滑风险。此外，地缘政治摩擦可能影响终端晶圆厂的投资强度，间接冲击公司订单。
