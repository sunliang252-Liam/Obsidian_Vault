# 600661.SH 深度透视

## 因果逻辑链
- **[资产处置收益]** -> [净利润扭亏为盈]: 出售北松路488号不动产及Kensington Park School股权，合计产生约7,019万元非经常性收益，是归母净利润8,657万元的核心来源。
- **[预收学费增加]** -> [经营现金流改善]: 报告期预收学费增加，带动经营活动现金流净额同比增长31.06%至2.28亿元，为业务运营提供资金保障。
- **[业务规模扩大]** -> [营收增长]: 青少儿素质教育收入同比增长23.52%，驱动总营收增长11.63%至13.73亿元，但扣非净利润仅421万元，主业盈利能力仍薄弱。
- **[商誉减值计提]** -> [扣非净利润承压]: 对育伦教育形成的商誉计提2,009万元减值准备，叠加员工持股计划摊销3,141万元，严重侵蚀主业利润。
- **[AI+教育投入]** -> [研发费用资本化]: 研发投入总额1,627万元，其中94.27%资本化，导致费用化研发支出同比骤降93.07%，短期美化利润表。
- **[银发经济布局]** -> [第二曲线探索]: 孵化“快乐公社”品牌并收购上海乐游，切入“教育+文旅+康养”赛道，但2025年乐游净利润为-71.69万元，尚处投入期。
- **[校区运营提效]** -> [毛利率改善]: 通过入口班打法、校区分类分级管理等举措，教育培训业务毛利率同比提升3.45个百分点至48.24%。

## 风险警告
**盈利质量堪忧，扣非净利润极度脆弱。** 2025年归母净利润8,657万元，但扣非净利润仅421万元，非经常性损益占比高达95%。核心主业（素质教育、高中业务）虽营收增长，但利润贡献被商誉减值（2,009万元）和股份支付费用（3,141万元）大幅抵消。若未来资产处置收益不可持续，或商誉再次减值，公司将重回亏损。

**战略转型不确定性高，新业务尚需验证。** 公司押注银发经济作为第二增长曲线，但2025年收购的上海乐游首年即亏损71.69万元，且多名董事对收购议案投弃权票，质疑其与主业的协同性。同时，职业教育、国际教育板块营收同比下滑，传统业务增长乏力。新赛道能否成为利润支柱，存在重大不确定性。
