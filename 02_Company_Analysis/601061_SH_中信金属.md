# 601061.SH 深度透视

## 因果逻辑链
- **[铜价上涨叠加矿山产量创新高]** -> [投资收益大幅增长]: 参股的拉斯邦巴斯铜矿产铜41.08万吨（+27%），叠加铜价震荡上行，带动权益利润翻番。
- **[贸易业务规模突破]** -> [营收创历史新高]: 有色金属业务（铜、铌、铝）全面发力，贸易规模超120万金属吨，推动总营收突破1,418亿元（+9.57%）。
- **[扣非净利润增速远超营收]** -> [盈利能力实质性提升]: 扣非净利润增长41%，主因贸易业务盈利水平提升及投资收益增长，而非一次性收益。
- **[财务费用大幅下降]** -> [利润增厚]: 积极优化融资结构、压降贷款规模，叠加利率下行及美元贬值，财务费用同比减少71.51%。
- **[铌业务市场份额稳固]** -> [稳定现金流与护城河]: 作为巴西矿冶公司（CBMM）独家分销商，国内铌市占率超80%，持续受益于中国含铌钢产量破亿吨。
- **[“投资+贸易+科技”战略三角]** -> [长期增长逻辑重构]: 从单纯贸易商向资源投资与材料科技平台转型，设立先进材料研究院，探索第二增长曲线。
- **[衍生品套保对冲价格波动]** -> [经营稳定性增强]: 利用期货、期权等工具管理铜、铝等价格风险，公允价值变动收益2.51亿元，有效平滑业绩波动。

## 风险警告
**核心风险在于对铜价和海外矿山运营的高度依赖。** 公司利润核心驱动来自参股的拉斯邦巴斯、艾芬豪矿业等铜矿资产，铜价若因全球经济衰退或供给过剩而大幅下跌，将直接冲击投资收益。同时，海外矿山面临资源国政策变动（如秘鲁、刚果金）、社区关系、运营事故等不可控风险，任何单一矿山的停产或减产都将显著影响公司业绩。

**贸易业务现金流波动剧烈，存在流动性隐患。** 报告期内经营活动现金流净额仅为1.87亿元，同比暴跌78%，主因期末铜价上涨导致贸易业务占用的营运资金（存货、应收账款）大幅增加。公司资产负债率较高（约59.8%），且大量资产为存货和应收账款，若价格急跌或客户违约，可能引发流动性危机。此外，公司对关联方（中信财务、艾芬豪等）的采购和融资依赖度较高，关联交易风险需持续关注。
