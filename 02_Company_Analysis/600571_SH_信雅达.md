# 600571.SH 深度透视

## 因果逻辑链
- **[AI战略升级与产品落地]** -> [扣非净利润增长167.51%]: 公司从传统IT服务向金融AI产品转型，AI场景（智能审单、坐席助手）形成可复制业务抓手，带动核心业务盈利能力改善。
- **[金融科技行业政策红利]** -> [营收稳健增长4.52%]: 监管层鼓励“人工智能+金融”，银行IT投入持续扩张，公司作为近30年行业老兵，受益于行业结构性增长。
- **[战略并购金科览智]** -> [补齐AI原生能力与客户共创]: 收购AI原生团队，丰富了公司大模型和多模态产品线，增强了与头部银行的深度合作能力。
- **[环保业务扩张]** -> [经营活动现金流恶化至-1.42亿]: 环保业务增长导致购买商品、接受劳务支付的现金大幅增加，严重拖累公司整体现金流表现。
- **[非经常性损益依赖]** -> [归母净利润下降7.45%]: 扣非净利润虽大幅增长，但归母净利润下滑，主要因公允价值变动收益及投资收益同比减少，利润质量仍受金融资产波动影响。
- **[ITO业务压舱]** -> [传统业务基本盘稳固]: ITO服务事业群对整体规模、利润与大行客户基础形成有力支撑，为公司AI转型提供了稳定的现金流和客户入口。
- **[海外市场突破]** -> [打开新增长空间]: 完成东亚银行香港总行国际业务系统项目，为后续海外市场拓展提供了样板案例和信心。

## 风险警告
**利润质量与现金流严重背离是最大隐忧。** 公司扣非净利润虽大幅改善，但经营活动现金流净额却由正转负，骤降至-1.42亿元，主因是环保业务扩张导致现金大量流出。这表明公司盈利能力的改善并未转化为真实的现金流入，利润含金量极低。若环保业务不能迅速改善现金流，或金融IT业务回款不力，公司将面临流动性压力。

**对金融资产收益的依赖构成业绩波动风险。** 公司持有超10亿元的交易性金融资产和其他非流动金融资产，其公允价值变动和投资收益对当期利润影响巨大（2025年合计贡献超3900万元）。这部分收益具有高度不确定性，受资本市场波动影响显著，导致公司净利润波动剧烈，无法真实反映主营业务的经营成果。投资者需警惕市场下行时，金融资产减值对利润的冲击。
