# 301113.SZ 深度透视

## 因果逻辑链
- **[线上直销占比激增至76.05%]** -> [营收增长20.25%]: 线上渠道（Amazon/Wayfair）收入同比+111%，完全对冲线下出口订单萎缩，成为业绩核心引擎。
- **[工具房等高单价品类放量]** -> [营收增长但销量下降13.61%]: 产品结构向高单价工具房（+81.37%）、其他品类（+83.08%）倾斜，抵消了火盆、气炉销量下滑的影响。
- **[销售费用飙升74.45%]** -> [扣非净利润转负]: 为抢占线上份额，平台费用及广告投入激增，导致销售费用率从15.1%飙升至21.9%，吞噬了毛利增量。
- **[对外投资公允价值变动收益1,834.5万]** -> [净利润为正]: 参股公司“诺比侃”上市带来非经常性收益，掩盖了主营业务亏损（扣非净利润-982万）。
- **[线下客户转移采购渠道]** -> [生产量骤降45%]: 受关税政策影响，传统ODM大客户订单收缩，公司被迫从“以产定销”转向“以销定研”的线上模式。
- **[研发投入缩减34.66%]** -> [长期竞争力存疑]: 研发人员从63人降至41人，研发费用率从5.11%降至2.78%，公司战略重心从产品创新转向渠道运营。
- **[客户高度集中]** -> [经营脆弱性]: 第一大客户（亚马逊等平台）占营收71.67%，公司对单一渠道和单一市场（美国98.48%）的依赖度极高。

## 风险警告
**核心风险：盈利质量恶化与战略转型的代价。** 公司营收增长20.25%的背后，是扣非净利润从+686万骤降至-982万（-243%），主营业务已实质性亏损。线上直销虽带来规模，但高昂的平台佣金和广告费（销售费用率21.9%）严重侵蚀利润，公司陷入“增收不增利”的困境。同时，研发投入连续两年大幅缩减，可能削弱长期产品差异化能力，使公司沦为纯粹的渠道商。

**结构性风险：客户与市场高度集中。** 公司98.48%收入来自海外，其中美国市场占绝对主导，且第一大客户（亚马逊等平台）贡献超70%营收。中美贸易关税政策的不确定性、亚马逊平台规则变动或竞争加剧，都可能对公司业绩造成毁灭性打击。线下客户因关税转移采购渠道的趋势已现，若线上渠道增长放缓，公司将面临双重压力。
