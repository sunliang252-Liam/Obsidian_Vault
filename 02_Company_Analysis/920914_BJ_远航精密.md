# 920914.BJ 深度透视

## 因果逻辑链
- **[营收增长22.38%但净利润下降20.70%]** -> [增收不增利]: 政府补助大幅减少、股权激励费用增加、新业务产能爬坡亏损、镍价下行压低毛利率，四重压力叠加导致利润被侵蚀。
- **[“镍价+加工费”定价模式]** -> [毛利率承压]: 镍价下行周期中，前期高价备货成本无法完全转嫁，镍带箔毛利率下降1.22个百分点。
- **[精密结构件收入增长59.38%]** -> [产品结构变化拉低整体毛利]: 高毛利产品占比下降、低毛利产品占比上升，精密结构件毛利率下降4.08个百分点。
- **[募投项目“年产8.35亿片精密合金冲压件”投产]** -> [固定资产激增165.55%]: 项目转固带来折旧摊销压力，且产能利用率仅48.13%，短期拖累盈利。
- **[经营活动现金流净额为-5,995.73万元]** -> [现金流恶化]: 票据结算比例增加、现金回款减少，同时采购及税费支出增加，导致经营性现金流转负。
- **[储能与氢能需求爆发]** -> [下游应用边界拓宽]: 储能电池出货量同比增长76.2%，氢能电解槽用镍基材料进入小试阶段，为公司打开第二增长曲线。
- **[垂直一体化产业链布局]** -> [成本与响应优势]: 自产镍带箔降低精密结构件采购成本，边角料回炉利用率接近100%，形成对纯加工企业的竞争壁垒。

## 风险警告
**核心风险在于“增收不增利”的恶化趋势。** 公司营收增长22.38%，但归母净利润下降20.70%，毛利率从15.83%降至13.62%。这并非一次性冲击，而是多重结构性压力叠加：镍价下行周期中“镍价+加工费”定价模式导致毛利率持续承压；新投产的精密结构件项目产能利用率仅48.13%，折旧摊销将长期侵蚀利润；新业务FPCA尚处亏损爬坡期。若镍价持续低迷或下游需求增速放缓，公司盈利能力可能进一步下滑。

**现金流恶化与债务扩张构成双重隐患。** 经营活动现金流净额由正转负至-5,995.73万元，而短期借款增长62.13%、长期借款新增5,500万元，资产负债率从21.27%升至29.59%。公司正以“借新债”支撑“扩产能”和“补营运”，若募投项目效益不及预期或下游回款周期拉长，可能面临流动性压力。此外，前五大供应商采购占比高达67.94%，原材料供应集中度风险不容忽视。
