# 600157.SH 深度透视

## 因果逻辑链
- **[焦煤价格中枢下行]** -> [归母净利润暴跌86.63%]: 煤炭业务毛利率从45.54%骤降至24.78%，收入减少31.13%，是业绩崩塌的主因。
- **[动力煤采购成本下降]** -> [电力业务毛利率提升4.53个百分点]: 燃料成本同比下降14.40%，部分对冲了电价和电量下滑的影响。
- **[海则滩煤矿建设加速]** -> [在建工程同比增加34.77%]: 项目进入二期工程，四条井筒贯通，为2026年试采出煤奠定基础，是未来核心增长点。
- **[持续还本付息与股份回购]** -> [资产负债率降至51.20%，总股本减少1.80%]: 累计偿付597.70亿元，有息负债大幅下降，财务结构优化，但消耗了大量现金。
- **[信用减值损失大幅增加]** -> [利润进一步承压]: 信用减值损失从-0.41亿元扩大至-1.77亿元，显示应收账款回收风险上升。
- **[财务费用下降]** -> [部分对冲利润下滑]: 利息支出减少使财务费用同比下降13.75%，节省约2.8亿元，是少数正面因素。
- **[电力市场化竞争加剧与陪停]** -> [电力收入同比下降7.83%]: 江苏主力电厂配合线路施工陪停，叠加市场化电价压力，导致发电量和上网电价双降。

## 风险警告
**核心风险：焦煤价格持续低迷与业绩高度脆弱。** 公司2025年归母净利润仅2.09亿元，同比暴跌86.63%，几乎完全依赖焦煤价格。若2026年焦煤市场延续“相对宽松”格局，公司煤炭业务利润可能进一步压缩，甚至导致主业亏损。电力业务虽因煤价下跌受益，但无法弥补煤炭业务的巨大缺口，整体盈利对煤价波动极度敏感。

**第二大风险：巨额债务与流动性压力。** 尽管公司宣称负债率降至51.20%，但一年内到期的非流动负债高达123亿元，同比暴增82.38%，而账面货币资金仅24.57亿元。公司经营现金流虽有61.27亿元，但大部分需用于还本付息和项目建设。一旦煤价超预期下跌或融资环境收紧，公司可能面临严峻的短期偿债压力。实际控制人王广西因信息披露问题被证监会立案，也增加了公司治理和再融资的不确定性。
