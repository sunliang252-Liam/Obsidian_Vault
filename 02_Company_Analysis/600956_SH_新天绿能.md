# 600956.SH 深度透视

## 因果逻辑链
- **[风资源改善]** -> [风电利润增长]: 2025年平均风速增加，推动控股风电场利用小时数同比增加10小时至2,236小时，高于全国均值257小时，直接带动风电板块净利润同比增长11.95%。
- **[天然气需求减弱]** -> [天然气收入下滑]: 宏观经济供强需弱及暖冬影响，天然气总输/售气量同比减少10.71%，导致天然气板块营业收入同比下降11.25%，净利润同比下降25.01%。
- **[融资成本优化]** -> [财务费用下降]: 通过置换高息贷款、精准选择发债窗口（如发行利率创省内新低的15亿元绿色中票），有效节约资金成本超亿元，财务费用同比减少13.34%。
- **[资本开支激增]** -> [在建工程膨胀]: 2025年为工程基建大年，资本性支出同比暴增67.08%至106.63亿元，其中风电及太阳能板块支出增长177.48%，在建工程占总资产比例升至15.41%。
- **[新能源全面入市]** -> [电价波动风险加剧]: 国家136号文推动新能源项目全量入市，存量项目机制电价锁定（河北南网0.3644元/千瓦时），增量项目通过竞价确定，市场化交易电价波动成为核心变量。
- **[H股定增与绿债发行]** -> [资本结构优化]: 成功发行H股非公开发行募集15.14亿港元，并发行15亿元绿色中期票据（计入其他权益工具），有效降低资产负债率1.43个百分点至66.30%。
- **[光伏业务战略剥离]** -> [聚焦核心主业]: 为聚焦风电及天然气，公司决定不再单独发展光伏，报告期内已完成新疆、黑龙江、辽宁及河北部分光伏项目的剥离，降低经营风险。
- **[AI运维平台上线]** -> [运营效率提升]: 自主研发的AI运维平台“智慧小新”上线，实现故障智能分析，推动“远程集中监控、现场无人值守”管理模式，助力降本增效。

## 风险警告
**核心风险在于新能源全面入市带来的电价下行压力。** 2025年6月1日后并网的增量风电项目，机制电价需通过竞价确定（2025-2026年冀北风电竞价结果为0.3470元/千瓦时），显著低于存量项目的0.3720元/千瓦时。随着市场化交易电量占比持续攀升，公司风电业务的平均售电价格面临结构性下降风险，这将直接侵蚀利润空间，即使发电量增长也难以完全对冲。

**天然气业务面临量价双重挤压。** 一方面，宏观经济疲软及暖冬导致下游需求减弱，2025年售气量已同比下降7.47%；另一方面，国际LNG价格波动（美元结算）与国内顺价机制不完善并存，上游采购成本不确定性高。同时，国家管网公平开放后，上游气源商直接下沉竞争，公司市场拓展难度显著加大，天然气板块的利润贡献可能持续承压。
