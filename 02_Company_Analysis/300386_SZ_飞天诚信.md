# 300386.SZ 深度透视

## 因果逻辑链
- **[传统身份认证产品需求萎缩]** -> [营收持续下滑]: 银行对USB Key/OTP需求下降，导致身份认证产品收入同比减少14.80%，拖累整体营收下降2.57%。
- **[商誉减值计提完毕]** -> [净利润扭亏为盈]: 上年商誉已全额计提减值，本期减值损失减少7,023.54万元，是净利润从-7,723万转为+587万的核心原因。
- **[海外市场拓展]** -> [收入结构优化]: 海外收入同比增长4.03%，占总营收比重提升至51.25%，成为公司最大收入来源，对冲国内业务下滑。
- **[智能终端增长]** -> [业务转型初见成效]: 智能终端产品收入同比增长9.27%，占总营收38.00%，成为与身份认证并驾齐驱的第二增长曲线。
- **[研发投入缩减]** -> [短期利润改善]: 研发费用同比减少31.98%，研发人员增加但总投入下降，直接贡献了期间费用的降低，助力扭亏。
- **[存货大幅减少]** -> [经营现金流显著改善]: 存货减少7,899万元，推动经营活动现金流净额从-46万大幅转正至5,175万元，现金流状况根本性好转。
- **[期间费用控制]** -> [亏损收窄]: 销售费用下降13.29%，研发费用下降31.98%，有效控制了费用端，是扭亏为盈的另一重要因素。

## 风险警告
**核心风险在于传统业务的持续萎缩与新兴业务的增长不确定性。** 公司赖以起家的USB Key和OTP产品收入同比下滑14.80%，且银行客户需求下降趋势不可逆转。虽然智能终端和海外业务有所增长，但尚不足以完全弥补传统业务的缺口，公司整体营收已连续三年下滑。新业务（如安全芯片、智能终端）面临激烈的市场竞争和海外贸易摩擦风险，增长能否持续存疑。

**盈利质量脆弱，扭亏主要依赖非经常性因素。** 2025年净利润仅为587万元，扣非净利润仍为-361万元，表明主营业务尚未实现真正盈利。扭亏的核心驱动力是商誉减值损失的减少（非经常性）和研发费用的压缩（可持续性存疑）。公司研发投入占营收比例从12.96%降至9.05%，长期可能削弱技术竞争力。此外，海外收入占比提升带来了汇率波动风险，财务费用因汇兑收益减少而大幅增加40.18%。
