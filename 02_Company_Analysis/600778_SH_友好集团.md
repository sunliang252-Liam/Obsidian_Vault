# 600778.SH 深度透视

## 因果逻辑链
- **[体验业态扩张]** -> [营收下降但利润提升]: 公司扩大餐饮、娱乐等自收银体验业态面积，虽减少联营收入，但带动客流与整体利润增长。
- **[联营企业汇友地产补税]** -> [投资收益大幅减少]: 联营企业因补缴土地增值税产生滞纳金，导致亏损，减少公司投资收益1,713万元。
- **[核销长期挂账应付款]** -> [营业外收入增加]: 核销无法支付的应付账款1,100万元，直接增厚当期净利润。
- **[以旧换新政策与政府消费券]** -> [家电及整体销售拉动]: 政企协同发放消费券并推动家电“以旧换新”，有效刺激了相关品类销售。
- **[降本增效与租金谈判]** -> [财务费用与租金成本下降]: 通过降低融资成本、谈判降低租赁物业租金，使财务费用和合同履约成本同比减少。
- **[门店优化调整]** -> [营收结构性下滑]: 关闭库尔勒天百购物中心及3家低效超市，导致营业收入同比减少10.93%。
- **[供应链优化与西货东调]** -> [拓展新收入来源]: 推动新疆农产品进入内地市场及扩大进出口业务，培育了新的业务增长点。

## 风险警告
公司资产负债率高达92.73%，财务杠杆极高，面临巨大的偿债压力和财务风险。尽管2025年实现微利，但母公司未分配利润仍为-5.78亿元，长期不具备分红能力，且扣非净利润连续为负，主业盈利能力堪忧。若盘活资产（如出售华骏地产）降低负债率的举措未能如期完成，公司可能面临流动性危机。

公司业绩高度依赖非经常性损益（如核销应付款、资产处置）和联营企业状况。核心零售业务收入持续下滑，百货、超市业态店效均同比下降，在区域竞争加剧和消费转型背景下，公司“由传统零售商向数字智能化零售商转型”的战略能否成功落地存在重大不确定性。
