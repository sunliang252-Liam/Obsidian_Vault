# 600428.SH 深度透视

## 因果逻辑链
- **[中国先进制造出海浪潮]** -> [高附加值货源占比超40%]: 公司聚焦风电、储能、工程机械等“新三样”出口，驱动多用途船、重吊船收入增长13%-44%。
- **[运力规模激进扩张]** -> [营收增长38%，但毛利率承压]: 2025年接入50艘新船，总运力同比增48%，规模效应推高收入，但新船爬坡期及租入船成本增加导致多用途船、重吊船毛利率下滑。
- **[汽车船业务爆发]** -> [营收同比增213.59%]: 新接入13艘LNG双燃料船，航线覆盖全球6大关键市场，全年运输商品车超50万辆，成为最大增长引擎。
- **[半潜船技术壁垒]** -> [毛利率逆势提升8.3个百分点]: 深耕海工高端市场，提供“运输+安装”总包服务，发布双船DP浮托技术，巩固高附加值细分领域定价权。
- **[纸浆供应链延伸]** -> [新型多用途船货量稳增]: 签约15年期长协，建设东南亚分拨中心，进口纸浆货量同比增45%，保障了新型多用途船的基础货源。
- **[资本运作与战略协同]** -> [净资产增34%，引入战略股东]: 完成35亿元定增，引入深圳港集团，打通港航协同资本通道，为船队扩张提供资金并优化治理。

## 风险警告
**核心风险在于“以量换价”的盈利质量隐忧。** 公司2025年营收增长38%，但归母净利润仅增长16%，毛利率同比下降0.26个百分点。运力激进扩张（同比+48%）带来的折旧、租赁费及燃油成本激增，正在侵蚀利润空间。汽车船、新型多用途船等主力船型毛利率均出现下滑，表明新增运力并未完全转化为同等比例的利润增长，存在“增收不增利”的阶段性风险。

**地缘政治与关税政策是最大外部不确定性。** 公司业务高度依赖中国先进制造出海（高附加值货源占比超40%），若全球贸易保护主义加剧、关税壁垒升级，将直接冲击风电、储能、汽车等核心货种的出口需求，导致运价承压。此外，红海局势等突发事件虽短期利好运价，但长期扰动供应链稳定性，增加运营管理难度。
