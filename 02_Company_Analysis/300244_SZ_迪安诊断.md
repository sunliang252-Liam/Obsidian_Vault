# 300244.SZ 深度透视

## 因果逻辑链
- **[战略聚焦“现金流＞利润＞收入”]** -> [经营性现金流同比+68%，归母净利润扭亏为盈]: 公司主动收缩低效规模，强化应收账款回款与成本管控，以牺牲收入增速换取经营质量提升。
- **[诊断服务业务向高附加值特检升级]** -> [特检收入占诊断服务收入47.7%，三级医院收入占比50.96%]: 聚焦“3+2+N”核心疾病线，推动学科化、场景化综合服务，特检成为业绩增长核心引擎。
- **[合作共建与精准中心模式深化]** -> [累计共建实验室近900家，精准中心110家（68家已盈利）]: 通过“服务+产品+数字”整体解决方案深度绑定医疗机构，实现从单一检验外包向院内综合运营服务商转型。
- **[AI与数智化产品商业化落地]** -> [病理AI产品部署超500家医院，数据产品完成首单交易]: “灵眸”病理大模型、宫颈癌AI三类证获批、数据要素市场先发布局，构筑差异化竞争壁垒。
- **[自有产品业务增长强劲]** -> [自有产品收入3.83亿元，同比+10.55%，凯莱谱临床试剂收入+44%]: 质谱、病理、分子诊断等自有产品线持续丰富，国产替代与高壁垒技术平台驱动增长。
- **[渠道产品业务主动战略重构]** -> [渠道产品收入65.88亿元，同比-15.39%，但国产品牌收入占比提升至21.8%]: 应对集采与国产替代，优化产品结构，向IVD供应链综合服务商转型，稳定毛利率。
- **[供应链精益管理降本增效]** -> [全年累计降低采购综合成本逾25%，物资周转效率提升超30%]: 集中采购、国产替代、物流优化等举措有效对冲收入下滑带来的利润压力。

## 风险警告
**核心风险：应收账款高企与坏账风险。** 截至2025年末，公司应收账款高达59.39亿元，占总资产41.18%，虽较年初有所下降，但绝对规模依然巨大。公司扭亏为盈的关键在于经营性现金流的大幅改善，这高度依赖于应收账款的持续回收。若宏观经济下行或医疗支付环境恶化，应收账款回收周期延长或发生大额坏账，将直接侵蚀公司脆弱的利润基础，导致业绩再次承压。

**次要风险：诊断服务业务收入持续下滑。** 2025年诊断服务业务收入同比下降22.59%，渠道产品收入同比下降15.39%，整体营收下滑17.22%。公司虽通过战略收缩和成本管控实现了利润端的改善，但核心业务规模仍在萎缩。若未来无法通过精准中心、合作共建等新模式有效对冲传统业务的下滑趋势，公司可能面临增长动力不足的困境，长期发展空间受限。
