# 000790.SZ 深度透视

## 因果逻辑链
- **[核心药品挂网价下调]** -> [营收与毛利双降]: 三七通舒胶囊等核心产品中选全国中成药集采，主动降价换取市场份额，导致医药业务收入同比下降36.71%，毛利率下降4.25个百分点。
- **[山东凌凯项目转固与减值]** -> [巨额亏损]: 新建化工新材料项目转固后折旧摊销激增，叠加产品价格暴跌与技术路线劣势，计提大额资产减值，是全年净亏损3.2亿元的核心拖累。
- **[处置西藏康域股权]** -> [资产处置亏损]: 为聚焦主业、优化资产结构，挂牌出售子公司51%股权，产生处置损失，直接减少当期利润。
- **[钢结构业务主动收缩]** -> [收入与利润贡献骤降]: 公司战略聚焦医药与大健康，控制钢结构新增业务，该板块收入同比下降68.92%，毛利贡献大幅减少。
- **[商誉及长期资产减值]** -> [净利润大幅侵蚀]: 山东凌凯、海南区域资产及部分并购子公司受市场下行影响，基于谨慎性原则计提大额商誉及资产减值准备，合计约1.86亿元。
- **[经营活动现金流净额为正]** -> [现金流与净利润背离]: 尽管巨额亏损，但通过收回大量应收款项及计提大额非付现减值，经营活动现金流净额达8537万元，同比增32.82%。
- **[三七通舒胶囊获二级保护与荷兰注册]** -> [长期竞争壁垒强化]: 核心产品获批国家中药二级保护（7年）及荷兰食品补充剂注册，为拓展海外市场、巩固国内独家地位奠定基础。

## 风险警告
**核心风险在于新业务拓展的“双杀”效应**。山东凌凯项目是公司“内生+外延”战略的关键落子，但遭遇化工产品价格雪崩与技术迭代的双重打击，不仅未能贡献预期收益，反而因转固折旧和资产减值成为2025年巨亏的“罪魁祸首”。这暴露了公司作为化工行业新进入者，在技术储备、市场预判和精细化管理上的严重不足。若后续无法快速实现技术迭代或找到产品出路，该项目将持续成为业绩的“出血点”，并可能引发进一步的资产减值。

**第二重风险是核心主业增长乏力与政策挤压**。公司医药业务收入下滑36.71%，核心原因在于集采降价。虽然“以价换量”是行业常态，但公司能否通过规模扩张弥补利润缺口尚存疑问。同时，公司正剥离非核心资产（钢结构、西藏康域），若医药主业不能及时企稳回升，公司将面临“旧增长点已去、新增长点未立”的真空期。此外，互联网电商对药品价格体系的冲击，可能进一步侵蚀本就承压的利润空间。
