# 600282.SH 深度透视

## 因果逻辑链
- **[原燃料成本下降]** -> [毛利率提升]: 铁矿石、焦煤等原燃料采购价格同比下降，降幅大于钢材售价降幅，推动钢铁主业毛利率同比增加3.48个百分点。
- **[产品结构高端化]** -> [盈利韧性增强]: 先进钢铁材料销量占比提升至30.45%，其高毛利率（20.88%）贡献了钢材总毛利的48.15%，对冲了普钢价格下行压力。
- **[印尼焦炭项目全面投产]** -> [营收与亏损并存]: 650万吨焦炭项目十座焦炉全部投产，焦炭销量同比大增33%，但印尼子公司合计亏损约4.7亿元，拖累整体盈利。
- **[参股公司天工股份上市]** -> [非经常性收益大增]: 天工股份在北交所上市，公司按市场法确认公允价值变动收益5.10亿元，贡献归母净利润4.33亿元，是利润增长的重要来源。
- **[M端工序成本压降]** -> [成本竞争力提升]: 通过精益管理、合金替代及工艺优化，M端工序成本同比下降10.63亿元，有效对冲了钢材价格下跌的影响。
- **[高分红承诺]** -> [股东回报确定性]: 2025年度拟合计派发现金红利占归母净利润的55%，并承诺2026年中期分红比例不低于50%，强化了价值投资逻辑。

## 风险警告
**核心风险在于印尼焦炭项目的持续亏损与海外经营的不确定性。** 尽管焦炭销量大增，但印尼金瑞与金祥新能源合计亏损约4.7亿元，成为公司利润的最大拖累。该项目面临印尼当地政策、汇率波动、运营效率及市场供需等多重挑战，扭亏为盈的时点存在重大不确定性，若持续亏损将严重侵蚀钢铁主业利润。

**另一重大风险是行业供需格局的长期恶化与同业竞争承诺的履约压力。** 国内钢铁行业进入“存量发展”时期，供强需弱矛盾突出，房地产用钢需求持续萎缩，而高端产能竞争亦在加剧。同时，控股股东中信泰富承诺在2026年3月前解决与公司在特殊钢棒材和板材方面的同业竞争，若届时未能有效整合，可能引发市场对公司治理和利益输送的担忧。
