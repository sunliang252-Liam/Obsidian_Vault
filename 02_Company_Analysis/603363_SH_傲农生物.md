# 603363.SH 深度透视

## 因果逻辑链
- **[破产重整完成，债务规模大幅下降]** -> [财务费用同比减少78.54%]: 重整后利息支出大幅降低，是利润表改善的核心驱动力。
- **[债务重组收益大幅下降]** -> [归母净利润同比减少86.60%]: 2024年高额债务重组收益（25.6亿）不可持续，2025年降至5.2亿，导致账面净利润大幅缩水。
- **[主动关停并转非核心区域、高成本猪场]** -> [生猪出栏量同比减少16.57%]: 公司战略收缩，聚焦福建、江西优势产能，牺牲规模换取成本优化。
- **[淘汰落后产能，生产成绩改善]** -> [养殖业务毛利率同比提升6.36个百分点]: 产能优化叠加猪价稳定，养殖业务实现扭亏为盈，毛利率转正至7.09%。
- **[待复产猪场和饲料厂折旧、摊销]** -> [扣非净利润仍为-4.74亿元]: 重整后大量闲置资产仍在计提折旧，是扣非亏损的核心原因。
- **[计提往来坏账准备、资产减值损失约2.4亿元]** -> [侵蚀扣非净利润]: 历史遗留的坏账和资产减值问题持续拖累当期业绩。
- **[饲料业务恢复增长]** -> [饲料外销量同比增长7.63%]: 重整后资金链改善，猪饲料业务逐步恢复，成为稳定现金流的基石。
- **[产业投资人联合体入主]** -> [治理结构优化，风控体系加强]: 国资背景的产业投资人带来更严谨的决策机制和合规体系，降低经营风险。

## 风险警告
**核心风险：扣非净利润持续为负，造血能力尚未恢复。** 公司2025年归母净利润为正，完全依赖5.2亿元的债务重组收益。剔除该非经常性损益后，扣非净利润亏损4.74亿元。这意味着公司主营业务（饲料、养猪、食品）在剔除重整红利后，仍处于亏损状态。待复产资产的折旧摊销、历史坏账计提等“后遗症”仍在持续侵蚀利润，公司距离真正的经营拐点尚有距离。

**周期性风险与高负债率并存。** 公司核心业务生猪养殖仍面临猪价周期性波动的巨大风险。尽管公司通过收缩产能、优化成本来应对，但2026年经营计划中生猪出栏目标（240万头）较2025年（175万头）大幅增长，若猪价下行，将直接冲击公司脆弱的盈利基础。同时，公司担保总额占净资产比例高达87.94%，对外担保风险敞口巨大，尤其是对已剥离至信托平台的子公司担保，存在代偿风险。
