# 603198.SH 深度透视

## 因果逻辑链
- **[消费需求疲软]** -> [营收下降18.04%]: 行业深度调整叠加居民消费信心不足，导致白酒销量下滑，全年营收从73.44亿降至60.19亿。
- **[营收下滑但费用刚性]** -> [净利润下降23.31%，降幅大于营收]: 销售费用、管理费用同比微增或仅小幅下降，固定成本无法同步缩减，利润弹性放大。
- **[中高档白酒占比高]** -> [毛利率仅微降0.5个百分点至80.57%]: 中高档酒收入占比超82%，其价格韧性缓冲了成本压力，整体毛利率保持稳定。
- **[省外市场收缩更快]** -> [省外收入下降25.57%，远超省内16.25%]: 省外市场品牌力相对薄弱，在行业下行期首当其冲，经销商净减少33家。
- **[销售回款减少]** -> [经营现金流净额下降35.27%]: 终端动销放缓，渠道回款周期拉长，经营活动现金流入显著承压。
- **[加大理财投资]** -> [交易性金融资产增长51.44%至38.37亿]: 在手现金充裕，公司将闲置资金大量配置于银行理财和券商产品，以增厚收益。
- **[数字化循环经济产业园建设]** -> [在建工程增长127.37%至6.82亿]: 逆周期加大资本开支，推进产能升级与智能化改造，为下一轮增长蓄力。

## 风险警告
**核心风险在于需求端的持续疲软与库存去化压力。** 2025年营收、净利润、经营现金流全面下滑，且降幅逐季扩大（Q1营收尚可，Q2-Q4持续走弱），表明行业调整尚未见底。公司作为区域酒企，省外市场收缩幅度远大于省内，全国化扩张受阻，增长天花板显现。若消费复苏不及预期，公司可能面临量价齐跌的困境，高企的存货（52.27亿，占总资产37.82%）将构成重大减值风险。

**另一风险是公司治理与战略的潜在隐患。** 公司大量资金（超38亿）用于理财而非投入主业或分红，反映出在行业下行期缺乏有效投资方向。同时，董事长倪永培已74岁高龄，管理层交接班问题悬而未决。在行业存量竞争加剧的背景下，公司“生态酿造”的差异化定位能否转化为实际市场份额，存在较大不确定性。
