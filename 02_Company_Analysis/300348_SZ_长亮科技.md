# 300348.SZ 深度透视

## 因果逻辑链
- **[大型项目集中验收]** -> [营收增长12.76%]: 2023年以来中标的大型银行核心系统项目在2025年陆续完成验收，确认收入，推动营收规模增长。
- **[大客户回款改善]** -> [净利润增长10.82%]: 收回个别大客户1年以上账龄的回款，大幅减少应收账款坏账准备计提（同比降87.09%），直接增厚净利润。
- **[毛利率滑至历史低位]** -> [盈利能力承压]: 软件许可收入确认趋严、海外项目为树标杆加大投入、国内竞争及项目延期，共同导致整体毛利率同比下降7.64个百分点至25.14%。
- **[AI Native战略推进]** -> [研发资本化率提升]: 全面推进AI融入研发全链路，研发投入资本化率从47.88%升至61.98%，短期减少当期费用，但增加未来摊销压力。
- **[海外标杆项目突破]** -> [海外业务模式升级]: 继泰国后，再获新加坡头部银行核心系统合同，验证产品全球竞争力，推动从“产品出海”向“生态出海”转型。
- **[信创进入深水区]** -> [核心系统龙头地位巩固]: 银行核心系统国产化替代从试点走向规模化，公司中标多家全国性股份制银行及省级农商行核心项目，客户覆盖率超95%。
- **[存货余额高企]** -> [潜在减值风险]: 期末存货账面价值7.58亿元，主要为未验收大型项目的履约成本，若项目延期或超支，存在跌价减值风险。

## 风险警告
**核心风险在于盈利质量与增长可持续性的背离。** 公司营收增长12.76%，但毛利率却滑至历史低点25.14%，净利润仅微增10.82%至2,059万元，净利率仅约1%。利润增长主要依赖信用减值损失的转回（同比减少6,828万元），而非主营业务的实质性改善。这种“回血式”利润增长极为脆弱，一旦大客户回款节奏放缓，利润将面临剧烈波动。

**第二重风险来自高强度的研发资本化与海外扩张的“双刃剑”。** 研发投入资本化率高达61.98%，虽美化当期利润，但未来摊销压力巨大。同时，海外业务为树标杆导致毛利率骤降25.24个百分点，且海外产品仍在打磨中，交付效率与质量亟待提升。若海外标杆项目无法快速实现盈利闭环，将长期拖累整体盈利能力。此外，7.58亿元的存货余额是悬在头顶的达摩克利斯之剑，任何大型项目的验收延期都可能导致资产减值损失。
