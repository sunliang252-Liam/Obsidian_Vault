# 688233.SH 深度透视

## 因果逻辑链
- **[国产替代加速]** -> [硅零部件收入翻倍]: 中国本土存储芯片厂及刻蚀设备厂为保障供应链安全，加速国产化认证，神工作为国内极少数“材料+零部件”一体化厂商，直接受益，硅零部件收入同比增长100.15%。
- **[产品结构高端化]** -> [大直径硅材料毛利率提升]: 公司主动优化产品结构，利润率更高的16英寸以上大直径硅材料收入占比提升至56.72%，推动该业务毛利率同比增加6.02个百分点至69.87%。
- **[下游市场回暖]** -> [整体营收与利润高增]: 全球半导体市场复苏，存储芯片产能结构性短缺，带动公司订单增加，实现营业收入4.38亿元，同比增长44.68%；归母净利润1.02亿元，同比大增147.96%。
- **[上游原材料降价]** -> [成本端改善]: 原始多晶硅原料价格下降并稳定在历史价格中枢，叠加公司工艺优化，直接降低了主营业务成本，是毛利率提升的重要原因之一。
- **[“材料+零部件”一体化]** -> [构建独特竞争壁垒]: 公司具备从晶体生长到硅零部件成品的完整制造能力，自产大直径硅材料为硅零部件业务提供了稳定性、一致性和成本优势，形成难以复制的护城河。
- **[半导体大尺寸硅片业务拖累]** -> [整体盈利承压]: 8英寸轻掺低缺陷硅片业务仍处于客户认证阶段，产能利用率低，产生较大固定资产折旧和停工损失（6364.73万元），导致该业务亏损，拖累公司整体盈利能力。
- **[募投项目终止]** -> [资本开支节奏调整]: 因市场环境变化，公司审慎终止“集成电路刻蚀设备用硅材料扩产项目”，将节余募集资金永久补充流动资金，表明公司从产能扩张转向更注重资金效率和回报。

## 风险警告
**核心风险在于对单一客户的高度依赖与下游周期性波动。** 公司前五大客户销售额占比高达79.30%，其中第一大客户占比达45.92%，客户集中度极高。一旦主要客户经营或采购策略发生变化，将对公司业绩产生巨大冲击。同时，半导体行业具有强周期性，若行业景气度下行，下游客户可能减少外购，转而利用自身产能，导致公司大直径硅材料业务面临剧烈波动。

**第二增长曲线面临激烈竞争与认证不确定性。** 硅零部件业务虽增长迅猛，但该市场参与者众多，竞争激烈。公司能否持续保持技术领先和成本优势，并不断通过下游新客户的严苛认证，存在不确定性。此外，半导体大尺寸硅片业务长期处于亏损状态，前期巨额资本投入的回报周期漫长，若后续客户认证及市场开拓不及预期，将持续侵蚀公司利润，成为业绩的“失血点”。
