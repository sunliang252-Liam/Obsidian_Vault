# 002564.SZ 深度透视

## 因果逻辑链
- **[高端装备制造业务承压]** -> [营收微增3.31%]: 传统石化装备需求不足，竞争加剧，新接订单毛利下降，但国防建设业务增长18.96%及海外销售暴增153.86%对冲了压力。
- **[财务费用大幅下降]** -> [归母净利润增长95.41%]: 有息负债本金减少及融资成本降低，财务费用同比减少39.12%，直接增厚利润。
- **[海外市场突破]** -> [国外销售占比提升至10.53%]: 张化机“造船出海”战略成功，直接交付国际客户核心设备，创下行业最短交付周期纪录。
- **[国防建设业务“双轮驱动”]** -> [板块营收增长18.96%]: 红旗船厂民品船舶交付量创新高，并拓展新能源船舶等新领域，实现国防与民品业务协同增长。
- **[玉门光热项目重启]** -> [在建工程激增至3.18亿元]: 原5万千瓦光热项目变更为30万千瓦“光热+风电一体化”项目，盘活存量资产，但带来技术、资金及政策不确定性。
- **[资产减值损失转回]** -> [非经常性损益贡献利润]: 合同资产和存货减值准备转回2,035.75万元，是扣非净利润转正的关键因素之一。
- **[投资者诉讼与索赔]** -> [营业外支出增加]: 已计提预计负债3,536.64万元，应对投资者诉讼及索赔，对利润形成持续侵蚀。

## 风险警告
**核心风险在于历史包袱沉重与未来转型不确定性并存。** 母公司未分配利润高达-50.29亿元，净资产为负，虽合并报表层面净资产转正，但母公司层面已严重资不抵债。同时，玉门“光热+风电”项目总投资高达19.18亿元，远超公司当前净资产规模，资金筹措压力巨大，且技术路线变更（二次反射改一次反射）存在不确定性，一旦项目进度或收益不及预期，将严重冲击公司脆弱的资产负债表。

**第二大风险是持续的法律与合规风险。** 公司因历史财务造假、未披露关联交易等问题，已受到证监会行政处罚及深交所纪律处分，并面临大量投资者诉讼索赔（涉案金额超6,300万元）。尽管部分案件已判决，但执行困难，且后续仍可能有新增诉讼。这严重损害了公司声誉，并持续消耗公司现金流和管理精力，是悬在头顶的“达摩克利斯之剑”。
