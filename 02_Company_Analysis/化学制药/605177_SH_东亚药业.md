# 605177.SH 深度透视

## 因果逻辑链
- **[β-内酰胺类抗菌药需求骤降]** -> [营收与利润双杀]: 核心产品头孢克洛、拉氧头孢钠等中间体及原料药终端需求大幅下滑，导致公司2025年营收同比减少21.54%，归母净利润连续第二年亏损。
- **[新建产能转固与利息费用化]** -> [固定成本刚性上升]: 可转债募投项目（浙江善渊、江西善渊）陆续建成转固，固定资产同比大增51.33%，叠加银行借款利息费用化，显著侵蚀利润。
- **[“去库存”策略]** -> [经营活动现金流恶化]: 为应对需求下滑，公司年中定调优先去库存，导致生产减少、应付票据到期解付，经营活动现金流净额降至-2.69亿元。
- **[非β-内酰胺类业务韧性]** -> [部分对冲主业下滑]: 马来酸曲美布汀、皮肤用抗真菌药等非核心业务营收及毛利率实现正增长，母公司（东亚药业）净利润达3195万元，成为业绩缓冲垫。
- **[原料药+制剂一体化突破]** -> [打开长期成长空间]: 左氧氟沙星片获批首张制剂批件，富马酸伏诺拉生片等后续品种跟进，标志公司从原料药向制剂延伸的战略取得里程碑进展。
- **[停工损失激增]** -> [毛利率承压]: 因需求不足导致产能利用率下降，报告期内产生停工损失5254万元，直接拉低主营业务毛利率4.18个百分点。
- **[研发投入维持高位]** -> [为未来产品管线蓄力]: 研发投入占营收比例达11.13%，资本化比重17.08%，持续进行原料药注册与制剂开发，但短期对利润形成压力。

## 风险警告
公司当前最大风险在于核心业务β-内酰胺类抗菌药的持续萎缩。该板块营收同比暴跌39.26%，且产销量数据显示头孢美唑、头孢唑肟等中间体生产量降幅超90%，表明需求下滑并非短期波动，而是结构性冲击。若下游注射剂型需求无法恢复，东邦药业等核心子公司产能利用率将持续低迷，巨额折旧与停工损失将长期压制盈利能力。

其次，公司正处于“新旧动能转换”的阵痛期。新建产能（浙江善渊、江西善渊）虽已结项，但距离全面达产仍需批件获批、GMP认证和市场开拓，短期内无法贡献利润，反而带来显著的财务费用和折旧压力。同时，公司经营活动现金流已连续三年为负且缺口扩大至2.69亿元，表明自身造血能力严重不足，高度依赖外部融资（短期借款同比增131%）维持运营，财务风险正在积聚。
