# 688373.SH 深度透视

## 因果逻辑链
- **[单一产品商业化]** -> [营收增长缓慢]: 公司仅康替唑胺片一款产品上市，2025年营收1.42亿元，同比仅增8.83%，远不足以覆盖高昂的研发与销售费用。
- **[研发投入高企]** -> [持续巨额亏损]: 2025年研发投入2.14亿元，占营收150.90%，导致归母净利润亏损2.42亿元，但亏损额同比收窄。
- **[医保续约成功]** -> [市场准入稳定]: 康替唑胺片以原价成功续约国家医保，进入第三个协议期，为未来销量增长提供了价格和准入保障。
- **[销售模式转型]** -> [短期业绩承压]: 从自建团队转向“自建+第三方”双轮驱动模式，过渡期内第三方贡献有限，导致营收增速不及预期。
- **[MRX-4 NDA受理]** -> [打开第二增长曲线]: 注射用MRX-4的上市申请已获受理，有望成为公司第二款商业化产品，拓展静脉给药市场。
- **[国际化临床推进]** -> [长期价值驱动]: MRX-4糖尿病足感染全球III期临床入组541例，MRX-5美国IIa期获批，为未来全球商业化奠定基础。
- **[降本增效措施]** -> [亏损幅度收窄]: 通过精细化管控，销售费用同比下降18.27%，研发费用同比下降41.96%，经营活动现金流净流出减少53%。

## 风险警告
公司面临的核心风险是**单一产品依赖与商业化不及预期**。康替唑胺片是唯一收入来源，2025年营收仅1.42亿元，增速缓慢。尽管医保续约成功，但“自建+第三方”的销售模式转型尚在过渡期，第三方团队贡献有限，医院准入和放量速度存在不确定性。若后续无法快速提升市场覆盖率，公司营收将长期处于低位，无法覆盖高昂的研发与运营成本。

**财务风险与退市压力**是另一重大威胁。公司已连续多年亏损，2025年末净资产仅2.06亿元，同比骤降53.18%。研发投入占营收比例高达150.90%，现金消耗巨大。若无法通过融资或商业化实现自我造血，公司可能面临净资产为负的退市风险。此外，公司无控股股东和实际控制人，治理结构存在潜在不稳定性，可能影响重大决策效率。
