# 300705.SZ 深度透视

## 因果逻辑链
- **[核心产品集采降价]** -> [净利润下滑7.72%]: 洛索洛芬钠凝胶贴膏在第十一批全国集采降价74.25%，该产品占营收约45%，直接拉低整体毛利率与利润水平。
- **[院外渠道与新品放量]** -> [营收增长6.15%]: 院外市场持续拓展，口服制剂（+19.01%）及新上市品种贡献增量，部分对冲了核心产品降价压力。
- **[品牌建设与人才引进]** -> [管理费用激增78.28%]: 公司加大“九典镇痛先生”品牌宣传投入，并引进创新药高端人才，导致宣传费与职工薪酬大幅增加。
- **[原料药价格下行]** -> [毛利率承压]: 原料药部分品种销售价格下降，叠加产品结构转型，共同导致公司整体毛利率同比回落。
- **[创新药战略转型]** -> [研发投入维持高位]: 公司成立九典善诺并进驻上海张江，聚焦镇痛、肿瘤等管线，研发投入2.37亿元，占营收7.63%，为长期增长蓄力。
- **[“制剂+原料药+辅料”一体化]** -> [成本控制与供应链稳定]: 自产核心原料药和辅料，确保制剂品质一致性，并形成成本优势，抵御上游价格波动风险。
- **[收购与批文扩充]** -> [丰富产品管线]: 收购九典诺纳及67个药品批文，新增35个制剂批文，构建层次清晰的外用产品矩阵，降低单品依赖风险。

## 风险警告
**核心风险在于核心单品集采降价带来的业绩阵痛。** 洛索洛芬钠凝胶贴膏贡献近半营收，第十一批集采降价74.25%将直接冲击2026年营收与利润，公司面临“以价换量”能否成功的严峻考验。若销量增长无法完全弥补价格缺口，公司营收增速将显著放缓甚至负增长，盈利能力面临持续下滑压力。

**创新药转型的高投入与不确定性构成第二重风险。** 公司正从仿制药向创新药转型，研发投入高、周期长，且新药研发存在失败可能。同时，仿制药集采常态化、医保目录动态调整以及行业合规要求趋严，将持续压缩现有仿制药业务的利润空间，对公司短期业绩形成多重压制。

> 湖南九典制药股份有限公司成立于2001年,是一家集研发、生产、销售、CXO服务于一体,在化药制剂、原料药、药用辅料、中药、大健康产品等领域全方位布局的现代化上市制药企业。  公司以研发和技术为驱动力,拥有多人高素质研发技术团队,以及先进的仪器设备,建有国家企业技术中心、博士后科研工作站、新型凝胶膏剂湖南省工程研究中心、湖南省呼吸道药物工程技术研究中心、湖南省无机盐原辅料分子特性工程技术研究中心等创新平台。  公司坚持“高技术、新产品、专利药”的产品战略,以仿制药为基础,以创新药为引领,仿创结合,重点发展经皮给药和缓控释等高端制剂,致力打造特色原料药和高端药用辅料优势平台。公司主导产品均系自主研发,在消炎镇痛、心脑血管、抗感染、消化和代谢、呼吸和抗过敏、中药等领域具有特色,多种原料药、药物辅料的绿色合成技术及外用贴剂的研发生产已处于国内地位,并培育出国内经皮给药领域的黄金品种。  公司实施“制剂+原料药+药用辅料”的一体化发展战略,现已形成浏阳制剂园区、望城原料药及药用辅料园区、麓谷研发园区“三园一体”的发展布局,已建成国内的智能化、绿色化生产基地,获评国家绿色工厂、湖南省智能制造标杆企业。公司拥有60多条符合GMP标准的现代化生产线,产品覆盖全国市场,原料药和药用辅料出口到欧美等60多个国家和地区。  秉承“九转中西典诺健康”的核心理念,公司正倾力打造国内经皮给药领域龙头企业,向着中国医药行业领跑者之一的目标不断迈进,为助力健康中国建设持续奋斗。
