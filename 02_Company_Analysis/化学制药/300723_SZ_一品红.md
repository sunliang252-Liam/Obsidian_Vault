# 300723.SZ 深度透视

## 因果逻辑链
- **[集采政策冲击与营销改革]** -> [营收骤降35.72%]: 国家集采常态化导致核心产品价格承压，叠加公司主动调整营销体系，2025年销售收入从14.5亿大幅下滑至9.3亿元。
- **[创新药AR882进入III期临床]** -> [研发费用资本化率飙升]: AR882国内外III期临床全部完成入组，依据会计政策，III期后研发支出资本化，导致研发费用同比下降49.61%，资本化率从3.91%跃升至22.15%。
- **[营收大幅下滑叠加固定成本刚性]** -> [连续第二年巨额亏损]: 收入下降35.72%的同时，管理费用（含股权激励）和财务费用（利息支出）同比增加，导致归母净利润亏损3.38亿元，但较上年亏损5.4亿有所收窄。
- **[经营性现金流大幅转正]** -> [盈利质量改善]: 经营活动现金流净额从-5.5亿元大幅转正至0.46亿元，主要系减少集采退款、降低采购及人员支出，现金流状况显著优于账面利润。
- **[Arthrosi被并购]** -> [AR882大中华区权益提升至100%]: 参股公司Arthrosi被Sobi以9.5亿美元首付款收购，公司以680万美元收购少数股权后，持有AR882在中国地区100%市场权益，并获控股股东承诺无偿转让相关股权收益。
- **[瑞石原料药基地投产]** -> [全产业链布局成型]: 子公司瑞石制药取得药品生产许可证，标志公司完成“原料药+制剂”一体化布局，增强供应链稳定性与成本控制能力。
- **[儿童药与慢病药批件持续获批]** -> [产品管线丰富但短期难以对冲下滑]: 2025年至今新增28个药品注册批件，但新品放量尚需时间，无法弥补存量品种因集采导致的收入缺口。

## 风险警告
**核心风险在于创新药AR882的研发与商业化双重不确定性。** AR882是公司扭转颓势的核心资产，虽已进入III期临床且数据优异，但新药研发失败风险始终存在。即便成功上市，将面临非布司他、苯溴马隆等成熟产品的激烈竞争，以及医保谈判带来的价格压力。公司当前市值已部分隐含AR882成功预期，一旦临床或审批不及预期，股价将面临剧烈回调。

**财务风险不容忽视。** 公司连续两年巨额亏损，净资产从25.2亿缩水至13.7亿，资产负债率因长期借款大幅增加（从6.1亿增至13.68亿）而显著攀升。高额的研发投入（占营收21.67%）和财务费用（同比增67.3%）持续侵蚀现金流，若AR882商业化进程延迟，公司可能面临流动性压力。此外，营收对单一客户A的依赖度高达29.51%，存在客户集中风险。
