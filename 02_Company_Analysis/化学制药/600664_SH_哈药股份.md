# 600664.SH 深度透视

## 因果逻辑链
- **[药品集采与医保控费]** -> [医药工业营收下降8.52%]: 带量采购和医保控费政策持续深化，压缩了公司仿制药和普药的利润空间与市场份额，导致工业板块收入承压。
- **[保健品行业增速放缓与渠道转型]** -> [保健品营收下降6.93%]: 行业整体增速回落，叠加公司从传统货架电商向内容电商转型的阵痛期，新兴渠道尚未形成有效支撑，导致核心保健品销售下滑。
- **[医药商业板块结构优化]** -> [商业营收增长3.32%]: 人民同泰通过深化DTP药房布局、承接处方外流、丰富经营品种及强化厂商协同，在行业集中度提升背景下实现了逆势增长。
- **[销售费用管控优化]** -> [净利润降幅（-42.5%）大于营收降幅（-1.31%）]: 公司虽通过优化营销模式、加强费用管控使销售费用下降7.4%，但工业板块毛利率下滑及营收减少的冲击更大，导致利润弹性显著放大。
- **[研发投入持续加码]** -> [研发费用增长6.28%]: 公司为应对行业转型，加速推进仿制药一致性评价和新产品研发，研发投入增加，短期内对利润形成一定压力。
- **[应付票据集中解付]** -> [经营活动现金流净额下降44.52%]: 报告期内应付票据到期集中解付，导致经营性现金流大幅减少，与净利润的匹配度下降。

## 风险警告
**核心风险在于医药工业板块的持续失血与转型阵痛。** 公司近八成利润依赖工业板块，但该板块营收同比下降8.52%，核心产品（如葡萄糖酸锌口服溶液、复方葡萄糖酸钙口服溶液）销量下滑超20%。在集采扩面、医保控费及保健品渠道变革的三重压力下，公司“以仿为主”的产品结构面临严峻挑战，而向“以创为主”的研发转型尚需时日，短期业绩缺乏强力增长点。

**财务健康度存在隐患。** 母公司累计未分配利润仍为-20.5亿元，连续多年无法满足现金分红条件。同时，经营活动现金流净额同比骤降44.52%，与净利润的背离值得警惕。此外，控股股东存在非经营性资金占用历史，虽已整改，但公司治理层面的潜在风险仍需持续关注。
