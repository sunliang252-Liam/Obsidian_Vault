# 002793.SZ 深度透视

## 因果逻辑链
- **[核心创新药替戈拉生片放量]** -> [营收结构优化]: 替戈拉生片三大适应症全部纳入医保，全年发货量突破1000万盒（+60%），驱动消化系统类收入增长31.72%，成为公司核心增长引擎。
- **[主动剥离亏损业务]** -> [减亏效果显著]: 剥离长期亏损的中成药业务（乐康制药）、关停低效原料药产能，归母净利润同比减亏70.11%，亏损大幅收窄。
- **[优化配送商合作机制]** -> [现金流根本性改善]: 有效缓解医院回款延迟压力，经营性现金净流入2.53亿元，较上年净流出1.58亿元实现彻底扭转。
- **[集采承压与主动收缩]** -> [非专利期制剂收入下滑]: 抗生素类收入下降39.81%，呼吸类下降45.36%，叠加公司主动退出低效品种，非专利期制剂收入同比下降27.70%。
- **[原料药业务内部短板暴露]** -> [板块深度调整]: 高附加值产品储备不足、工艺升级偏慢、成本管控薄弱，原料药收入同比下降54.74%，处于战略重塑期。
- **[上药罗欣经营未达预期]** -> [一次性非经常性损益]: 导致金融负债公允价值变动损失3535万元及股权投资减值，是当期亏损的重要原因之一。

## 风险警告
公司核心风险在于创新药单一品种依赖度过高。替戈拉生片虽进入放量周期，但后续管线（注射用LX22001、普卡那肽片）尚处临床或地产化阶段，距离商业化仍有距离。一旦该品种面临竞争加剧或医保政策调整，业绩增长将失去主要支撑。

另一重大风险是原料药业务转型的不确定性。该板块已陷入“销量下滑、价格承压、产能利用率偏低”的困境，公司虽启动战略重塑，但短期内难以扭转颓势。同时，公司连续三年亏损，净资产持续缩水，若再融资或经营改善不及预期，财务压力将进一步加大。
