# 301281.SZ 深度透视

## 因果逻辑链
- **[原料药收入大幅下滑]** -> [总营收下降14.12%]: 核心原料药业务收入同比减少27.95%，是营收下滑的主因，反映出核心产品面临集采降价与市场竞争的双重压力。
- **[原料药销量与库存背离]** -> [存货增加与减值风险]: 原料药销售量下降34.29%，但库存量激增117.40%，表明下游需求疲软，公司被动累库，导致资产减值损失同比增加130.65%。
- **[管理费用激增]** -> [侵蚀净利润]: 管理人员增加及重组中介费用导致管理费用同比增加29.91%，在营收下滑背景下，刚性费用上升直接压缩了利润空间。
- **[非经常性损益波动]** -> [净利润大幅波动]: 政府补助减少、理财收益下降及未决诉讼预计损失增加，导致非经常性损益从正贡献转为负值，加剧了净利润的同比下滑。
- **[制剂业务“以价换量”]** -> [毛利率提升但收入增长有限]: 化学药品制剂收入仅微增1.85%，但毛利率高达77.16%，主要得益于集采中标带来的规模效应，但销量增长未能完全对冲价格下降的影响。
- **[在建工程大幅增加]** -> [未来折旧与资金压力]: 在建工程同比增加113.03%，主要投向智能制造项目，虽为长期竞争力，但短期内将带来折旧摊销增加和资金占用压力。
- **[经营活动现金流改善]** -> [非经营性因素驱动]: 经营性现金流净额同比大增171.83%，主要系前期涉诉冻结资金解冻，而非主营业务造血能力实质性提升。

## 风险警告
**核心风险在于原料药业务的持续萎缩与盈利能力恶化。** 公司核心原料药收入同比下滑近28%，销量下降34%，库存却翻倍，显示下游需求疲软且集采降价压力正向上游传导。资产减值损失同比翻倍，表明存货跌价风险正在兑现。若原料药业务无法企稳，公司整体业绩将失去基本盘支撑。

**另一重大风险是公司治理与经营的不确定性。** 报告期内董事长、总裁、财务总监等核心高管频繁变动，且公司因未决诉讼计提了1600余万元的预计负债，暴露出内部管理与合规风险。同时，管理费用因重组中介费激增，而重组事项最终终止，相关投入未能转化为价值，进一步损害了股东利益。
