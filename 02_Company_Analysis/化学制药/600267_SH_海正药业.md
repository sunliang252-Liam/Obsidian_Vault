# 600267.SH 深度透视

## 因果逻辑链
- **[制剂业务结构优化与学术推广]** -> [扣非净利润增长36.11%]: 聚焦创新药及品牌仿制药，深化临床价值挖掘，推动高毛利产品（赛斯美、喜美欣等）销量增长，同时优化营销体系，提升运营效率。
- **[原料药制剂一体化与降本增效]** -> [医药制造毛利率提升1.29个百分点]: 依托原料药与制剂垂直一体化优势，深化生产精细化管理，有效落实降本增效措施，抵御了部分产品价格下行压力。
- **[战略聚焦宠物药赛道]** -> [动物药营收增长22.44%]: 将业务重心转向高增长的宠物药领域，海乐妙、海乐旺等核心产品放量，宠物业务营收同比增长超50%，成为新的增长极。
- **[剥离低毛利医药经销业务]** -> [整体盈利质量改善]: 出售省医药公司100%股权，聚焦高毛利的医药工业核心优势领域，优化资源配置，提升公司整体利润率。
- **[研发投入加大与管线扩张]** -> [研发费用增长33.79%]: 为构建“仿创结合”的长期竞争力，大幅增加自主研发项目及外部合作研发投入，布局创新药、复杂制剂等前沿领域。
- **[有息负债规模与融资成本下降]** -> [财务费用减少34.83%]: 通过优化债务结构，降低有息负债规模，有效减少了利息支出，改善了财务健康状况。
- **[集采常态化下的“以价换量”]** -> [抗感染药营收下降7.25%]: 部分抗感染产品面临集采降价压力，尽管销量可能增长，但收入端承压，体现了集采对传统大品种的冲击。

## 风险警告
**核心风险在于集采深化对盈利能力的持续侵蚀与创新转型的高不确定性。** 公司制剂业务虽通过结构优化实现增长，但抗感染等核心板块已受集采降价影响，营收下滑。随着集采常态化，更多品种面临降价压力，能否持续通过“以量补价”维持利润存在疑问。同时，公司研发费用激增33.79%，但创新药管线尚处早期，HS387等核心品种仍在临床阶段，短期内难以贡献业绩，高投入与低产出之间的时间差构成财务压力。

**资产质量与合规风险不容忽视。** 公司因前期会计差错被监管处罚，暴露出内部控制和子公司管理存在漏洞。此外，在建工程大幅增长46.43%，主要投向合成生物学等新兴领域，这些项目尚处建设初期，未来能否实现预期收益存在较大不确定性，若项目失败或市场不及预期，将面临资产减值风险。剥离医药商业虽聚焦主业，但也意味着放弃了稳定的现金流来源，增加了对波动性更大的工业业务的依赖。

> 浙江海正药业股份有限公司始创于1956年,2000年发行A股上市,属于国有控股上市公司。经过60多年的发展,海正药业已成为一家集研产销全价值链、原料药与制剂垂直一体化的综合性制药企业集团。公司专注于化学药、生物药、动物药、中药及商业流通等多产业发展,加快布局大健康产业和健康美学等新兴市场,多次入选中国制造业企业500强、中国医药工业百强企业榜单,先后荣获国家技术创新示范企业、全国五一劳动奖状、浙江省政府质量奖等荣誉称号。作为国家首批创新型企业,海正药业拥有高层次、多维度的研发平台,已在台州总部、上海、杭州、美国等多地建有研发中心,拥有国家级企业技术中心、浙江省首批独立招收博士后资格的博士后科研工作站和浙江省级重点实验室等一流研发平台,具备全链条的药物研发能力。2021年公司自主研发的首个创新药海博麦布片获批上市,是国内近年来心血管领域批准的唯一1类新药,入选“第十四届健康中国年度论坛·十大新药(国内)榜单”。生物药方面,目前已在自身免疫和肿瘤治疗领域建立了丰富的产品管线,已有5个产品获批上市、10多个产品处于临床、多个产品处于临床前研究,首个胰岛素产品门冬胰岛素获批并中标国采。近年来先后承担国家重大新药创制专项课题50余项,获省部级以上科技进步奖10多项。海正药业以工匠精神打造品质好药,率先在国内创建QEHS管理体系,产品通过全球医药质量高标准体系检验,引进国内外高精尖设备,累计建成80多条国际一流的先进的制剂生产线,全程实行在线自动控制。作为国内率先实现原研药本地化生产的本土药企,海正拥有国内先进制药基础的领先CSO平台,构成了基于合规体系下的专业化学术推广、线上线下数智化立体营销、全球制药企业定制研发生产,以及支持创新药企协同发展等营销新业态。公司国际销售网络覆盖全球70多个国家和地区,药品国内入院规模过万家,现有40多个品规通过或视同通过一致性评价,10多种药物入选国家集采,大幅度降低患者的用药成本。作为一家有责任感和使命感的国企,海正积极承担国家重大战略需求,达菲、抗埃博拉药物、抗超级耐药菌替加环素、抗结核药环丝氨酸等产品帮助多国患者,彰显了海正作为民族药企的责任与担当。疫情期间,公司生产的法维拉韦片快速获批上市,驰援全球助力抗疫,相继收到国务院联防联控组、国家科技部、浙江省医疗物资保障组多封感谢信,获赞当之无愧的抗击疫情“军工厂”。60多年的发展历程积淀了海正品牌的深厚底蕴。海正药业将以病人需求为导向,以精细化管理体系为基础,以研产销一体化运营为骨架,以专业化人才梯队为能量,以持续务实创新为动力,传递世界级品质,展现海正新面貌,聚力打造民族良心制药新品牌。
