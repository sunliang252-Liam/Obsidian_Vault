# 688658.SH 深度透视

## 因果逻辑链
- **[核心产品“银杏叶提取物注射液”价格与销售策略调整]** -> [营收与利润大幅下滑]: 2024年末对核心大品种进行价格及销售策略调整，导致2025年心脑血管类产品收入同比骤降49.54%，是公司营收下降35.30%、净利润由盈转亏（-2.62亿）的直接导火索。
- **[高比例研发投入持续侵蚀利润]** -> [研发费用同比上升，净利润承压]: 研发投入占营收比例从11.16%激增至18.67%，费用化研发投入达4.41亿元，在营收大幅下滑的背景下，进一步加剧了亏损。
- **[抗感染类产品市场竞争加剧]** -> [原料药及制剂收入下滑]: 抗感染类产品收入同比下降25.32%，原料药收入下降35.74%，且原料药毛利率为负（-5.68%），显示传统业务面临激烈价格战和需求萎缩。
- **[集采政策与市场竞争双重挤压]** -> [消化系统类产品销量萎缩]: 奥美拉唑肠溶胶囊等产品受集采及市场竞争影响，销量下滑，但受益于原料成本下降，毛利率反而提升15.86个百分点。
- **[创新药管线进入密集收获期]** -> [研发费用资本化率大幅降低]: 注射用羟基红花黄色素A等三个中药1类新药进入NDA审评阶段，导致符合资本化条件的项目减少，研发投入资本化比重从11.30%骤降至3.39%。
- **[销售策略聚焦与渠道调整]** -> [销售费用大幅缩减]: 公司采取市场推广活动聚焦方案，销售费用同比下降45.93%，但未能完全对冲核心产品收入下滑的负面影响。

## 风险警告
悦康药业当前面临的核心风险是“旧引擎熄火，新引擎尚在点火”的断档期。公司最核心的利润来源——银杏叶提取物注射液——因价格和销售策略调整而收入腰斩，直接导致公司由盈转亏。尽管公司试图通过削减销售费用来止血，但效果有限。同时，抗感染、原料药等传统业务在集采和市场竞争中持续萎缩，短期内难以提供增长动力。

公司已将未来押注于庞大的创新药管线，但这是一条高投入、长周期、高风险的道路。2025年研发投入高达4.57亿元，占营收18.67%，持续侵蚀利润。虽然3个中药1类新药已提交上市申请，但后续的商业化推广、医保准入及市场竞争存在巨大不确定性。核酸药物、多肽药物等前沿管线虽进展积极，但距离商业化尚远，且面临全球技术迭代和竞争对手的挤压。在核心产品复苏前景不明、新药贡献收入尚需时日的情况下，公司短期业绩压力巨大。

**公司简介（F10 原文）**

> 悦康药业集团股份有限公司成立于2001年,总部位于北京,是一家集新药研发、药品生产、流通销售及国际贸易于一体的医药集团企业。2020年12月24日,悦康药业在上海证券交易所科创板上市,股票代码688658。悦康药业以“产品、产能、产业链”为核心,在北京组建了集团药物研究院,并以安徽、河南医药原料基地为基础,在北京、广州、合肥建立了不同的制剂生产基地。集团现为中国医药工业百强企业、医药工业研发十强、国家技术创新示范企业、全国“质量标杆”企业、国家绿色制造体系建设示范企业“绿色工厂”、国家智能制造试点示范企业、国家认定企业技术中心、中国医药研发产品线最佳工业企业,并获“全国文明单位”称号。悦康药业通过技术创新、研发创新打造了全新的创新研发布局,目前已形成核酸药物靶点发现平台、多肽药物开发平台、缓控释制剂技术平台等九大核心研发平台,涵盖核酸药、多肽药、中药创新药以及高端化药等领域,并相继组建了头孢药物晶型研究国家地方联合工程实验室、心脑血管北京市工程研究中心等,建立了悦康集团院士专家工作站、博士后科研工作站、博导工作站等完善的研发体系。2015、2016连续两年荣获国家科技进步二等奖。集团现有品规200多个,涵盖心脑血管、消化系统、抗感染、内分泌、抗肿瘤等多个治疗领域。2021年3月,悦康药业联合解放军总医院正式开展核酸抗癌药物CT102临床试验,全面切入核酸药物新赛道;2022年1月,与中国医学科学院病原生物学研究所合作开发多肽药物YKYY017,已获中国、美国、澳大利亚临床试验批准;2023年7月,完成国内首家自主知识产权LNP阳离子脂质辅料(YK-009)的备案登记,是国内外少数可规模化生产自主知识产权阳离子脂质辅料的药企。在生产制造和质量管理方面,悦康集团不断推进技术革新,实施智能制造和绿色化生产,实现药品生产体系与国际接轨。自2011年起,悦康固体片剂和胶囊剂生产线已经多次通过欧盟GMP认证。2015年,广州药厂通过日本GMP认证。“营造全球喜悦,关爱人类健康”是悦康的企业宗旨,在“合和”文化的感召下,悦康人诚信勤奋,为实现“创行业名牌,建药业航母,打造百年老店”的目标努力奋斗。
