# 688658.SH 深度透视

## 因果逻辑链
- **[核心产品“银杏叶提取物注射液”价格与销售策略调整]** -> [营收与利润大幅下滑]: 2024年末对核心大品种进行价格及销售策略调整，导致2025年心脑血管类产品收入同比骤降49.54%，是公司营收下降35.30%、净利润由盈转亏（-2.62亿）的直接导火索。
- **[高比例研发投入持续侵蚀利润]** -> [研发费用同比上升，净利润承压]: 研发投入占营收比例从11.16%激增至18.67%，费用化研发投入达4.41亿元，在营收大幅下滑的背景下，进一步加剧了亏损。
- **[抗感染类产品市场竞争加剧]** -> [原料药及制剂收入下滑]: 抗感染类产品收入同比下降25.32%，原料药收入下降35.74%，且原料药毛利率为负（-5.68%），显示传统业务面临激烈价格战和需求萎缩。
- **[集采政策与市场竞争双重挤压]** -> [消化系统类产品销量萎缩]: 奥美拉唑肠溶胶囊等产品受集采及市场竞争影响，销量下滑，但受益于原料成本下降，毛利率反而提升15.86个百分点。
- **[创新药管线进入密集收获期]** -> [研发费用资本化率大幅降低]: 注射用羟基红花黄色素A等三个中药1类新药进入NDA审评阶段，导致符合资本化条件的项目减少，研发投入资本化比重从11.30%骤降至3.39%。
- **[销售策略聚焦与渠道调整]** -> [销售费用大幅缩减]: 公司采取市场推广活动聚焦方案，销售费用同比下降45.93%，但未能完全对冲核心产品收入下滑的负面影响。

## 风险警告
悦康药业当前面临的核心风险是“旧引擎熄火，新引擎尚在点火”的断档期。公司最核心的利润来源——银杏叶提取物注射液——因价格和销售策略调整而收入腰斩，直接导致公司由盈转亏。尽管公司试图通过削减销售费用来止血，但效果有限。同时，抗感染、原料药等传统业务在集采和市场竞争中持续萎缩，短期内难以提供增长动力。

公司已将未来押注于庞大的创新药管线，但这是一条高投入、长周期、高风险的道路。2025年研发投入高达4.57亿元，占营收18.67%，持续侵蚀利润。虽然3个中药1类新药已提交上市申请，但后续的商业化推广、医保准入及市场竞争存在巨大不确定性。核酸药物、多肽药物等前沿管线虽进展积极，但距离商业化尚远，且面临全球技术迭代和竞争对手的挤压。在核心产品复苏前景不明、新药贡献收入尚需时日的情况下，公司短期业绩压力巨大。
