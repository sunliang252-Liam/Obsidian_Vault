# 002365.SZ 深度透视

## 因果逻辑链
- **[牛磺酸价格持续承压]** -> [营收与利润双降]: 行业竞争加剧，新产能释放导致牛磺酸售价低迷，公司核心产品收入同比下降22.02%，扣非净利润转负。
- **[环氧乙烷装置停产]** -> [拖累净利润]: 因原料乙烯与产品价格倒挂，公司自产环氧乙烷不经济，全年基本停产，产生停工损失882万元，占净利润39.23%。
- **[子公司凌安科技转型阵痛]** -> [亏损扩大]: 一水肌酸业务处于发展初期，工艺调试导致产量低、成本高，叠加计提固定资产减值，全年亏损2017万元，亏损额同比扩大55.18%。
- **[子公司齐安氢能源停产]** -> [持续亏损]: 化工行业不景气，公司基本停车停产，产生停工损失469万元，全年亏损751万元。
- **[保健食品业务放量]** -> [收入结构优化]: 子公司永安康健合同研发生产（CDMO）业务增长，带动保健食品收入同比大增102.60%，占总营收比例提升至26.84%。
- **[金融资产投资收益]** -> [支撑账面利润]: 报告期内证券及理财投资收益2552万元，是公司实现归母净利润2249万元的主要来源，掩盖了主业亏损。
- **[美国专利诉讼风险]** -> [潜在重大不确定性]: 牛磺酸专利诉讼虽一审胜诉，但原告已上诉，后因原告破产程序中止，案件可能重启，若败诉将影响美国市场销售。

## 风险警告
**核心风险在于主业盈利能力的持续恶化。** 公司核心产品牛磺酸面临行业产能过剩与价格战，营收与毛利率双降，导致扣非净利润已转为亏损。为应对困境，公司主动限产保价，并导致环氧乙烷装置停产，这虽短期稳住价格，但牺牲了产量与规模效应，长期竞争力存疑。同时，新业务一水肌酸与齐安氢能源均处于亏损状态，转型尚未成功，反而成为利润拖累。

**第二重风险来自外部不确定性。** 美国关税政策频繁调整，直接冲击公司占比超50%的海外销售。更关键的是，公司在美国的牛磺酸专利诉讼虽一审胜诉，但原告已上诉，案件因原告破产而中止，未来可能重启。一旦败诉，公司将失去美国这一核心市场，对业绩造成毁灭性打击。此外，公司董事长2025年曾被留置调查，虽已解除，但暴露出公司治理层面的潜在风险。
