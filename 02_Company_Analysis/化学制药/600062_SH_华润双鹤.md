# 600062.SH 深度透视

## 因果逻辑链
- **集采常态化与价格治理** -> **慢病业务收入下滑5.16%**: 核心产品0号受省采和渠道治理影响收入下滑，慢病业务整体承压，但公司通过集采中选以量换价，维持了市场份额。
- **专科业务差异化布局** -> **专科业务收入增长14.09%**: 聚焦儿科、肾科、精神/神经、抗凝等未受集采严重冲击的领域，核心产品如腹膜透析液、替尼泊苷注射液等快速增长，成为增长引擎。
- **原料药成本优化与合成生物赋能** -> **原料药毛利率提升9.17个百分点**: 通过合成生物技术改造神舟生物核心产品，实现成本下降、产量提升，在行业下行周期中稳住了业绩。
- **并购整合与产品引进** -> **外延发展拓展新增长极**: 收购中帅医药进入精麻领域，引进CAR-T产品代理权，并通过“长征计划”投后管理模式，促进被投企业业绩增长。
- **研发投入与仿创结合** -> **创新药管线进入收获期**: 研发投入7.52亿元，15个创新药项目推进，司美格鲁肽完成III期临床，巯嘌呤片(II)获批上市，为长期增长储备动力。
- **输液业务结构调整** -> **输液收入下滑16.85%**: 受终端需求变化和同质化竞争影响，基础输液价格下滑，但公司通过增加软包装占比、参与联盟采，维持了行业前三的市场份额。
- **全价值链低成本战略** -> **扣非净利润增长9.50%**: 通过物料集中采购、精益管理、原料制剂一体化，重点产品成本持续下降，节降营销费率，盈利能力提升。

## 风险警告
**集采与价格治理的持续冲击**：公司慢病业务（收入占比30%）是受带量采购影响最大的板块，核心产品0号已出现收入下滑。随着第十一批集采规则优化（引入“锚点价”机制）和全国挂网价格协同治理的深化，公司面临产品丢标或中选价格大幅下降的风险。虽然公司通过以量换价应对，但长期来看，仿制药利润空间被持续压缩是确定性趋势，慢病业务的增长动力面临根本性挑战。

**创新转型的不确定性与高投入**：公司正从“仿制药驱动”向“创新药驱动”转型，研发投入强度达6.84%，但创新药研发周期长、失败率高。目前15个创新药项目中，多数仍处于临床早期阶段，距离商业化贡献利润尚远。同时，合成生物“第二增长曲线”尚处于技术攻关和产业转化初期，能否成功兑现存在较大不确定性。若创新转型不及预期，公司可能陷入仿制药利润下滑、创新药无法接棒的困境。

**公司简介（F10 原文）**

> 华润双鹤药业股份有限公司拥有87年光辉历史,作为部队药厂于1939年诞生太行,对外称利华药厂;1949年随军迁京后新建首家国有化学制药厂,后更名北京制药厂,奠定北京现代化学制药工业基础;1997年整合优质资产成立双鹤药业,在上交所上市,通过外延扩张成为立足北京、辐射全国的跨地域集团;2010年进入世界500强企业华润集团旗下,2012年更名为华润双鹤,现为华润集团大健康领域化药业务平台。主营业务涵盖新药研发、制剂生产、药品销售、原料药生产及制药装备等方面,具有丰富的产品线和品牌优势、优质的产品质量和成本控制、强大的渠道与终端覆盖及管理能力、国际化优势、富有活力的团队优势和深厚的文化底蕴。综合实力和研发实力排名均稳居中国化药企业前列。公司旗下药品批文2000余个,在产在销产品330余个,深耕慢病、输液、儿科、肾科、精神/神经、肿瘤、女性健康等领域,在多个细分赛道具有市场领先地位,26个产品年销售收入超亿元。发展中,公司践行“仿制哺育创新,创新驱动未来”的战略思路,研发创新和外延发展双轮驱动,推进卓越运营走深走实。公司加快研发创新转型,搭建三级研发体系,形成10个研究院,聚焦六大技术平台打造差异化竞争力,近年来仿制药获批过百,创新管线初步形成。同时紧跟国家战略导向,积极布局合成生物等战新领域,打造研发、中试、产业化三级体系,承接国家重大专项任务,以双鹤所能服务国家所需。拥有国内一流的生产制造能力,24家生产基地分布在全国15个省市,构建先进的生产和质量管理体系,推动智能制造、绿色生产。积极拥抱集采,深化营销模式转型,销售网络覆盖全国33个省、直辖市、自治区和特别行政区,在华北、江浙及输液根据地市场有较强的影响力。在国际化布局方面,以原料药产品为主开展外贸业务,并与多个国家头部药厂高值客户保持良好合作。信息化、数字化覆盖全业务链,构建以信息技术为新能力、新引擎的产业发展新格局。未来,公司将秉承“为人民健康服务”的初心,加快推进高质量发展,致力成为大众信赖的、创新驱动的世界一流制药企业,为大众健康和行业发展作出更大贡献。
