# 300573.SZ 深度透视

## 因果逻辑链
- **[核心产品放量]** -> [营收/利润高增]: 0.01%硫酸阿托品滴眼液（美欧品）作为国内首个获批的近视防控药物，凭借先发优势和独家地位，在2025年进入完整销售年度，驱动滴眼剂收入同比+42.76%，带动整体营收增长27.24%，净利润增长105.84%。
- **[高毛利产品结构优化]** -> [毛利率提升]: 滴眼剂（毛利率85.12%）和凝胶剂（毛利率84.52%）等高毛利产品收入占比提升，叠加规模效应，推动医药制造业务毛利率同比提升3.45个百分点至83.70%。
- **[经销渠道深度拓展]** -> [收入增长]: 公司强化与经销商合作，经销模式收入同比+38.71%，占比提升至92.66%，表明产品市场覆盖面和终端渗透率显著扩大。
- **[学术推广驱动]** -> [品牌与市场壁垒]: 全年参与超20场重大行业会议、300余场学术教育项目，覆盖超20万人次专业人士，持续巩固在干眼和近视防控领域的专业领导地位，为产品持续放量奠定基础。
- **[研发管线储备]** -> [未来增长引擎]: 0.02%和0.04%硫酸阿托品滴眼液获批，形成梯度浓度产品矩阵；SQ-22031（神经营养性角膜炎/干眼）、SQ-129（眼底黄斑水肿）等创新药进入II期临床，为中长期增长提供动力。
- **[规模效应显现]** -> [费用率优化]: 营收高增背景下，销售费用率（30.9%）和管理费用率（7.1%）均同比下降，研发费用率（9.1%）保持稳定，利润增速显著高于收入增速。
- **[现金流强劲]** -> [经营质量健康]: 经营活动现金流净额7.53亿元，同比增长80.68%，与净利润高度匹配，反映公司回款能力和盈利质量优异。

## 风险警告
**核心风险：单一产品依赖与竞争加剧。** 公司业绩爆发高度依赖0.01%硫酸阿托品滴眼液，该产品目前国内无同类竞品，但已有多个企业处于临床或注册阶段。一旦竞品获批上市，将直接冲击公司核心收入来源，面临价格战和市场份额被侵蚀的风险。公司已披露“行业竞争加剧的风险”，需警惕产品生命周期缩短和业绩增速放缓。

**政策与研发风险：** 医保控费、带量采购政策持续深化，公司产品面临降价压力。同时，新药研发周期长、投入大，SQ-22031、SQ-129等创新药尚处临床早期，存在研发失败或进度不及预期的风险，可能导致研发成本沉没，拖累短期盈利能力。公司已明确提示“研发项目未达预期的风险”。

**公司简介（F10 原文）**

> 沈阳兴齐眼药股份有限公司是一家专业从事眼科药物研发、生产及销售的高新技术企业。2016年12月08日,公司在深圳证券交易所创业板上市,证券简称:兴齐眼药,证券代码:300573,2022年荣获第九届辽宁省省长质量奖银奖,2023年荣获第二十届全国质量奖。公司以高质量党建引领企业高质量发展,坚持“经营健康、缔造光明”的使命,以“做具有全球竞争力的眼科药物研究和制造企业”为愿景,践行“执着、创新、责任、共赢”的价值观,积极投入到人类眼健康产业。目前,公司产品包括延缓儿童近视进展药、干眼治疗药、眼用抗感染药、眼用抗炎/抗感染药、人工泪液和眼润滑剂、营养与角膜修复药、散瞳药和睫状肌麻痹药、眼用非类固醇抗炎药、缩瞳药和抗青光眼用药、手术眼内冲洗液等,覆盖十余个眼科药物细分类别,为眼科疾病治疗领域提供了高品质产品。创新是企业发展源动力。公司拥有国家企业技术中心、博士后科研工作站、辽宁省眼科药物专业技术创新中心、辽宁省儿童青少年近视防控工程研究中心,在眼科药物研发领域,打造了常规眼用制剂、即型凝胶、缓释制剂、药包材相容性、眼科药效学、药代动力学、毒理学等药物研究和评价平台,具备综合的眼科药物研发创新能力。2020年10月,公司质量检测中心,获得“中国合格评定国家认可委员会”CNAS认可,标志着“中心”具备按照认可准则开展实验检测的能力。质量源于设计,优质的产品来自对细节的不断追求。2014年,公司棋盘山工厂全面投入使用。工厂参照美国FDAcGMP和欧盟GMP标准设计,由国际一流的设计团队、设备供应商及工程公司通力合作建设完成。拥有提取生产线、单剂量滴眼剂生产线、多剂量滴眼剂生产线、眼用凝胶生产线等多条符合国内GMP标准的生产线。公司基于眼科药物研发与生产业务,以市场为导向,与国内外科研院所、医疗机构及眼科专家紧密合作,推进科研成果转化;以专业化学术推广,引领市场销售。通过完善的营销体系,与各级经销商建立合作关系,产品销售网络覆盖全国省、市、县级医疗机构。日新月异的兴齐眼药,努力为客户、员工、股东、合作伙伴及社会创造长期价值,在不断完善自身的基础上更肩负着弘扬民族医药的时代重任。兴齐人,为“做具有全球竞争力的眼科药物研究和制造企业”坚持不懈、努力奋斗!
