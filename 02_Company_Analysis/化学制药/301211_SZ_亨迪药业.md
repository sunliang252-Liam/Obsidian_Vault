# 301211.SZ 深度透视

## 因果逻辑链
- **核心产品布洛芬原料药需求波动** -> **业绩剧烈震荡**: 2022年营收5.15亿，2023年骤降至6.63亿（+28.8%），2024年又回落至5.99亿（-9.6%），完全受疫情相关用药需求周期驱动。
- **原料药价格周期** -> **毛利率剧烈波动**: 布洛芬原料药价格从2022年高位回落，导致2024年原料药毛利率从2023年的42.68%降至34.02%，直接侵蚀利润。
- **制剂业务放量** -> **收入结构优化**: 2024年制剂收入2.02亿（+28.5%），占比提升至33.8%，成为第二增长曲线，但规模仍有限。
- **出口依赖度下降** -> **收入稳定性改善**: 境外收入占比从2022年的66.1%降至2024年的48.8%，内销比例提升，降低单一市场风险。
- **研发投入资本化率低** -> **费用刚性**: 2024年研发费用0.31亿，全部费用化，占营收5.2%，持续压制利润。
- **产能扩张** -> **折旧压力前置**: “年产5000吨布洛芬原料药项目”等在建工程转固，2024年固定资产折旧0.48亿，同比增加，侵蚀利润。
- **非经常性损益依赖** -> **利润质量存疑**: 2024年扣非净利润0.83亿，但归母净利润1.21亿，差异主要来自政府补助和投资收益，主业盈利能力被高估。

## 风险警告
亨迪药业的核心风险在于其业绩对布洛芬原料药价格的极度敏感。2023年受益于疫情后补库需求，营收利润暴增，但2024年随着价格回落，营收和毛利率双双下滑，净利润从2.51亿腰斩至1.21亿。这种“过山车”式波动表明公司缺乏定价权，完全受制于上游原料价格和下游需求周期，未来若布洛芬价格持续低迷，业绩可能进一步承压。

公司正在推进制剂转型和产能扩张，但短期面临双重压力：制剂业务虽增长但基数小，尚无法对冲原料药下行；而“年产5000吨布洛芬原料药”等项目的转固，每年新增数千万折旧，在需求疲软时将成为利润的刚性侵蚀。此外，公司研发管线薄弱，2024年研发费用仅0.31亿，且全部费用化，缺乏重磅新药储备，长期增长动力不足。
