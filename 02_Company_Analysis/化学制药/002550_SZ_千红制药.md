# 002550.SZ 深度透视

## 因果逻辑链
- **人口老龄化与生活方式变化导致糖尿病患病人数增加** -> 胰激肽原酶制剂市场需求增长: 糖尿病微循环障碍患者增多，对改善微循环药物需求上升
- **胰激肽原酶制剂市场增长** -> 公司怡开系列产品销量及市占率提升: 公司产品依从指南，多科室拓展和学术推广
- **消化系统疾病发病率上升** -> 复方消化酶制剂市场扩大: 饮食不规律等因素导致消化系统疾病增加，推动助消化药需求
- **复方消化酶制剂市场扩大** -> 公司怡美系列销量提升: 公司通过医院品牌拓展与拜耳OTC合作，提升品牌竞争力
- **肝素制剂全球市场规模增长** -> 公司肝素制剂收入稳定，依诺肝素成为增长点: 全球肝素市场扩大，公司利用集采机遇快速上量
- **肝素原料药出口价格下行** -> 公司原料药系列毛利率下降: 售价下降导致毛利率降低
- **肝素原料药出口价格下行** -> 公司原料药系列收入仍增长2.95%: 以量补价，销量增长22.62%抵消价格下降影响
- **集采政策常态化** -> 公司制剂系列毛利率提升: 集采降价倒逼成本控制，同时高毛利品种占比提升
- **创新药全链条支持政策** -> 公司创新药研发管线推进: 政策优化审评审批、支付体系，加速新药上市
- **公司上游基地投产（河南千牧、湖北千红）** -> 原料供应保障增强，全产业链优势巩固: 自建上游基地确保原料质量和供给，降低成本波动风险

## 风险警告
主要风险包括：1) 肝素原料药价格持续下行风险，若销量增长无法弥补价降，原料药板块利润可能承压；2) 创新药研发不确定性，公司多个新药处于II期临床，III期及审批存在失败或延迟风险；3) 集采降价超预期风险，若更多品种纳入集采且降价幅度过大，可能挤压制剂利润；4) 海外市场汇率波动风险，财务费用因汇兑损失大幅增加；5) 上游基地产能爬坡不及预期，影响成本优势发挥。
