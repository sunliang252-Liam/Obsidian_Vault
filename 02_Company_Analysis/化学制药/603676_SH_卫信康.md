# 603676.SH 深度透视

## 因果逻辑链
- **[核心产品集采降价]** -> [营收下降12.65%]: 注射用多种维生素(12)等核心产品在多个省际联盟集采中选，执行降价，导致整体营收承压。
- **[合作销售模式依赖]** -> [营收结构单一风险]: 71.91%营收来自合作方普德药业，公司收入高度依赖单一合作生产方的销售与结算。
- **[服务性收入收缩]** -> [利润韧性优于营收]: 服务性收入（市场管理及推广）同比下降16.84%，但毛利率提升7.53个百分点，缓冲了利润下滑幅度。
- **[新品放量对冲]** -> [扣非净利润仅降4.62%]: 多种微量元素注射液（+10.56%）、小儿多种维生素注射液（+3.86%）等新品增长，部分抵消了核心老品降价影响。
- **[研发投入持续高企]** -> [长期竞争力构建]: 研发费用占营收10.84%，40+在研项目聚焦高壁垒仿制药，为未来产品迭代提供储备。
- **[经营现金流大幅缩减]** -> [回款压力显现]: 经营活动现金流净额同比骤降50.23%，主因销售额减少导致销售回款减少，反映下游回款周期拉长。
- **[高分红锁定股东回报]** -> [现金流承压下的财务平衡]: 现金分红比例高达60.71%，在营收利润双降背景下，高分红政策对现金流形成额外压力。

## 风险警告
**核心风险在于单一客户依赖与集采降价的双重挤压。** 公司超七成营收来自合作方普德药业，合作模式虽轻资产，但议价权与稳定性受制于人。同时，核心产品注射用多种维生素(12)已在全国23个省区执行集采中选价，剩余未集采区域（京沪粤等）一旦跟进，将进一步压缩利润空间。经营现金流骤降50%，显示回款能力恶化，高分红政策可持续性存疑。

**第二增长曲线尚在培育期，业绩接力存在不确定性。** 公司虽有多款新品获批，但小儿复方氨基酸、复方氨基酸(20AA)等尚处市场准入爬坡阶段，短期内难以完全对冲老品降价缺口。研发管线中改良型新药和创新药仍处早期，距离商业化贡献业绩仍需时日。若集采扩面速度超预期，而新品放量不及预期，公司可能面临“青黄不接”的业绩真空期。
