# 000931.SZ 深度透视

## 因果逻辑链
- **核心产品“元治”纳入国家集采** -> **2026年业绩承压**: 公司主要收入来源盐酸贝尼地平片（元治）2026年进入集采执标期，短期内将直接冲击营收和利润，公司预计2026年业绩与2025年持平，实际增长动力缺失。
- **养老医疗业务持续亏损** -> **拖累整体盈利**: 养老业务毛利率为-27.55%，收入同比下降27.23%，华素堂养老等子公司大幅亏损，成为公司利润的持续出血点。
- **商砼业务收入下滑** -> **传统业务增长乏力**: 商砼业务收入同比下降8.16%，毛利率下降1.87个百分点，虽涉足风电混塔转型，但短期难以弥补主业下滑。
- **研发管线聚焦仿制药一致性评价** -> **短期确定性高，但长期创新不足**: 研发投入4.4%，主要围绕现有品种的一致性评价和仿制药开发，缺乏重磅创新药储备，未来增长天花板明显。
- **经营活动现金流大幅下降67.42%** -> **盈利质量恶化**: 净利润微降但现金流腰斩，主要因政府补助、保证金等经营性现金流入减少，显示公司实际经营造血能力减弱。
- **资产受限比例高** -> **融资弹性受限**: 高达8.33亿元资产（占总资产20.8%）用于抵押担保，限制公司进一步融资和资产盘活能力。
- **控股股东国美系背景** -> **关联交易与治理风险**: 控股股东为国美控股，其自身经营困境可能间接影响上市公司融资、担保及战略稳定性。

## 风险警告
**核心风险在于核心产品“元治”集采降价与养老业务持续失血的双重挤压。** 公司2025年净利润仅4789万元，而养老业务（华素堂养老）单家子公司亏损即达5862万元，已完全吞噬生物医药业务的利润贡献。2026年“元治”集采落地后，生物医药板块利润大概率下滑，而养老业务短期内扭亏无望，公司整体盈利将面临严峻考验。

**财务健康度存在隐忧。** 经营活动现金流净额从2023年的2.18亿元骤降至2025年的0.42亿元，降幅超80%，与净利润严重背离。同时，公司超20%的资产处于受限状态，叠加控股股东国美系的信用风险，公司在行业下行期缺乏足够的财务缓冲垫，抗风险能力较弱。

> 北京中关村科技发展(控股)股份有限公司(简称中关村科技),1999年成立并在深交所挂牌上市。2015年,中关村科技的产业格局逐步从“科技地产+医药”,转型至以“医药大健康”为核心的发展经营战略。2018年8月,中关村科技得到监管部门的认可,所属行业分类由“综合”变更为“医药制造业”,战略转型初步成功。2021年8月,公司调整发展战略,进一步聚焦定位,拟建立专注医药领域的创新型医药产业集团。2024年7月,公司进一步调整发展战略,致力于成为领先的医药大健康产业服务商。通过近几年的高速发展,中关村科技已在医药、医养、健康品、投资四大板块拥有十多家理念先进、管理规范、产品过硬、极具行业竞争力的高品质企业。未来,中关村科技将以创新为驱动,以政策和需求为导向,整合内外部资源,以现有医药业务为基础,通过激活沉淀品种、产品线自研扩充,构建原料药到制剂一体化的有竞争力的生产模式,稳步提升现有业务规模,强化在心血管、口腔、消化、妇科和麻精等多个领域的市场竞争力。同时,积极探索生物制药新领域,全力推动创新型药物的发展,打造多个产品集群,更进一步地提升市场竞争力,最终成为创新型医药产业集团。
