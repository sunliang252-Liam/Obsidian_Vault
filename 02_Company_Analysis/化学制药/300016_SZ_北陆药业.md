# 300016.SZ 深度透视

## 因果逻辑链
- **[集采中标与执标]** -> [对比剂销量增长20%]: 公司积极拥抱集采，钆布醇、钆贝葡胺等产品中选，以价换量，推动对比剂收入增长15.78%。
- **[中成药板块扩张]** -> [中药制剂收入增长42.91%]: 控股天原药业后，产品矩阵扩大至59个，金莲花颗粒中选广东联盟集采，带动整体中药板块放量。
- **[原料药国际化突破]** -> [原料药收入增长55.06%]: 海昌药业碘类原料药在韩国、印度获批，沧州钆类原料药实现外销，海外注册与产能释放共同驱动增长。
- **[公允价值变动收益]** -> [归母净利润暴增579.29%]: 早期投资的产业基金及非上市公司股权（如世和基因）公允价值上升，贡献非经常性损益约6361万元。
- **[可转债转股与赎回]** -> [资本结构优化]: 北陆转债完成转股（约7.09亿股）并摘牌，负债减少，净资产增加，资产负债率从38.56%降至27.79%。
- **[海外GMP认证]** -> [海外营收增长51.23%]: 通过欧盟EU GMP及巴西ANVISA认证，对比剂全线产品出海加速，海外收入达2亿元。
- **[研发管线密集获批]** -> [产品线丰富度提升]: 2025年获批西甲硅油、碘美普尔、吡格列酮二甲双胍等多项新品，为后续增长储备弹药。

## 风险警告
**核心风险：利润质量高度依赖非经常性损益。** 2025年归母净利润9273万元，但扣非净利润仅4006万元，占比43%。高达6361万元的公允价值变动收益（来自早期股权投资）是利润暴增的主因，该收益不可持续且波动极大。若被投企业估值回调，利润将大幅缩水。

**经营风险：原料药成本高企与子公司亏损。** 碘对比剂上游原材料价格持续高位运行，直接压制控股子公司海昌药业的盈利能力，其2025年亏损1519万元。同时，公司研发费用同比大增34.88%至9339万元，若新品上市不及预期，将持续侵蚀利润。集采降价压力虽被销量对冲，但长期毛利率下行趋势未改。
