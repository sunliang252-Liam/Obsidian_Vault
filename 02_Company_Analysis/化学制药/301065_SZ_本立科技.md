# 301065.SZ 深度透视

## 因果逻辑链
- **[核心产品毛利率提升]** -> [净利润增长22%]: 在营收下降9.9%的情况下，通过成本管控和原材料价格下行，核心产品（801、1201、1501）毛利率分别提升7.92、14.32、10.36个百分点，驱动利润逆势增长。
- **[下游需求结构性萎缩]** -> [营收下降9.9%]: 喹诺酮类药物中间体市场整体需求偏弱，核心产品1501、1701销量下滑，农药中间体业务收入锐减54.8%，拖累整体营收。
- **[出口业务承压]** -> [国外收入下降27%]: 国际贸易环境不确定性及海外市场需求疲软，导致出口收入从1.88亿降至1.37亿，占比从26.6%降至21.5%。
- **[募投项目延期与产能爬坡]** -> [短期业绩贡献有限]: 诺氟沙星原料药项目虽已建成并获生产许可证，但尚未完成国内上市注册，无法立即贡献收益；多个技改项目延期，产能释放节奏慢于预期。
- **[研发投入持续加码]** -> [长期竞争力储备]: 研发费用同比增长18.3%，重点布局原料药转型及绿色合成工艺，3款高附加值中间体进入中试，为未来产品线延伸奠定基础。
- **[精益管理与降本增效]** -> [成本端改善]: 通过全流程降本增效行动，全年累计实现降本收益上千万元，有效对冲了收入下滑对利润的侵蚀。
- **[股权激励绑定核心团队]** -> [人才稳定性增强]: 2025年推出新一期限制性股票激励计划，覆盖68名核心员工，以11.46元/股授予196万股，强化长期利益绑定。

## 风险警告
公司面临的核心风险在于**下游需求的结构性萎缩与产能释放节奏错配**。核心产品1501、1701销量持续下滑，农药中间体业务大幅萎缩，显示公司主要依赖的喹诺酮类药物中间体市场可能已进入存量博弈阶段。尽管公司通过成本管控实现了利润增长，但这更多是短期成本红利，而非需求驱动的增长。若下游需求持续疲软，毛利率提升空间将收窄，利润增长将难以为继。

另一重大风险是**募投项目多次延期与变更带来的不确定性**。诺氟沙星原料药项目虽已建成，但商业化进程受制于药品注册审批，短期内无法贡献业绩。多个技改项目因市场变化而调整方案，甚至变更产品方向（如新建二氯乙酰氯产线），这反映出公司对市场趋势的判断和项目执行能力存在波动。若新项目无法如期达产或市场接受度不及预期，前期大量资本投入将面临减值风险，并拖累整体资产回报率。
