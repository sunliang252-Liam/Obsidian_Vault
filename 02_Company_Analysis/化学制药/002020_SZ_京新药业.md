# 002020.SZ 深度透视

## 因果逻辑链
- **集中采购模式下，与关键原材料及设备供应商签订长期协议** -> 供应链连续性与稳定性增强，成本可控: 长期协议确保关键物资供应稳定，降低采购风险与成本波动
- **原料药-制剂一体化产业链** -> 成本优势与市场竞争力: 原料药自产为制剂提供稳定低价原料，同时带动原料药销售，形成协同
- **创新药地达西尼纳入医保目录** -> 创新药商业化加速，销售额增长: 医保准入降低患者支付门槛，促进医院覆盖和处方量提升
- **成品药内销模式调整为经销为主（经销占比从40.87%升至66.21%）** -> 成品药收入同比下降2.11%，但扣非净利润增长10.06%: 经销模式下渠道下沉与费用管控优化，以价换量初显成效，利润弹性释放
- **研发聚焦精神神经与心脑血管领域，多管线推进** -> 创新药梯队形成，持续贡献未来收入: 前瞻布局填补临床空白，差异化品种获批/申报NDA，支撑长期增长
- **原料药板块工艺优化与成本管控** -> 原料药收入下降7.09%但毛利率提升: 通过工艺优化、成本管控应对行业下行，维持盈利水平
- **医疗器械子公司深圳巨烽通过FDA现场检查** -> 拓展国际大客户，收入稳健增长: 国际质量认证增强客户信任，深化与GE、飞利浦等合作，争取项目创新高
- **销售费用同比下降13.21%** -> 归母净利润同比增6.46%: 费用管控直接提升利润水平

## 风险警告
深度风险总结：1. 行业政策风险：带量采购深化、医保控费持续，核心仿制药面临降价压力，可能压缩利润空间。2. 研发风险：创新药研发周期长、投入大，存在临床失败或上市后销售不及预期风险。3. 环保风险：原料药生产受环保监管趋严，合规成本上升。4. 汇兑风险：财务费用中汇兑损失增加，海外业务受汇率波动影响。5. 人才风险：创新转型需要高端人才，储备不足可能制约发展。

**公司简介（F10 原文）**

> 浙江京新药业股份有限公司(证券代码:002020)成立于1990年,是一家集研发、生产、销售于一体的医药上市公司。公司遵循“做强药品主业,发展医疗器械”的经营方针,坚持“务实、创新、包容、共赢”的企业核心价值观,以“精心守护健康”为使命,致力于成为中国精神神经、心脑血管领域的领先者。公司分设新昌、杭州两个总部,于上海张江高科技园区建有上海研究院,拥有8个生产基地,分别为新昌的制剂生产基地、上虞和江西上饶的原料药生产基地、内蒙古巴彦淖尔和广东沙溪的中药生产基地、深圳、沈阳的医疗器械生产基地和云南中药原料基地,并投资筹建山东基地和京新新昌国际健康产业园。在美国、以色列、韩国等国投资合作建立公司和研发实验室。一直以来,公司秉承“京新药,精心造”质量理念,已全面通过新版GMP认证,固体制剂生产线率先于2006年通过了德国GMP认证,并于2018年通过美国FDA现场认证。公司综合经济效益快速提升,连续多年荣登“中国化学制药行业制剂出口型优秀企业品牌”、“中国医药工业百强”和“中国化学制药企业百强榜”,是第一批“中国医药企业制剂国际化先导企业”,首批国家“重大新药创制”科技重大专项优秀课题承担单位,社会知名度和美誉度日益提升。公司是国家重点高新技术企业,拥有国家企业技术中心、博士后科研工作站、省级重点企业研究院、省级院士专家工作站、省级高新技术企业研发中心,在上海张江高科技园区建有上海研究所,并长期和上海医药工业研究院、中国科学院上海有机化学研究所、浙江大学等国内外著名的科研院所、研发公司,以及著名大学保持长期良好的交流与合作关系,拥有较强的科研技术力量,研发取得了丰硕成果,拥有国家重点新产品8个,承担国家火炬计划项目9个。
