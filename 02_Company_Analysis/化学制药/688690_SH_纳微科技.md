- **[“3+2”市场策略聚焦多肽/GLP-1、双抗/ADC、血制品]** -> [色谱填料收入增长22.57%]: 精准切入高景气赛道，多肽类药物填料收入同比大增63%，成为核心增长引擎。
- **[国产替代加速与药企降本增效]** -> [生物医药客户粘性增强]: 集采政策与供应链安全诉求推动药企加速国产化验证，公司凭借性能与交期优势（2周 vs 进口数月）抢占存量市场。
- **[硅胶色谱填料UniSilRevo系列性能突破]** -> [胰岛素/GLP-1项目回收率提升]: 技术迭代直接提升产品竞争力，在头部企业验证通过，带动硅胶系列产品同步放量。
- **[收购纳信科技（膜分离）与战略投资睿纯科技]** -> [构建“层析+过滤”技术闭环]: 从单一填料供应商升级为“分离纯化整体解决方案提供商”，提升客户单产价值与竞争壁垒。
- **[海外市场拓展与印度市场突破]** -> [境外收入同比增长78%]: 抗体、血液制品、胰岛素等项目导入海外药企，印度市场实现填料订单放量，打开第二增长曲线。
- **[赛谱仪器“填料+仪器”协同整合]** -> [赛谱仪器扭亏为盈]: 集团内营销一体化，以存量仪器带动耗材/填料导入，后市场战略见效，避免商誉进一步减值。
- **[常熟软胶技改与南通新基地建设]** -> [产能储备与产品矩阵丰富]: 20余款软胶产品稳定生产，多肽固相合成载体与碳微球进入中试，为未来增长提供产能与品类支撑。

## 风险警告
**核心风险在于商业化项目转化率偏低与高研发投入的回报不确定性。** 公司色谱填料收入中，应用于药企商业化项目（含新药注册）的占比仅约23%，绝大部分收入仍来自研发与中试阶段。这意味着业绩高度依赖下游客户新药研发管线推进速度与成功率，若宏观环境导致药企研发投入收缩或新药审批放缓，公司收入增速将面临显著压力。同时，公司研发费用率高达21.29%，远超同行，若新产品（如核酸固相合成载体、耐溶剂膜）无法快速实现规模化销售，将持续侵蚀利润。

**另一重大风险来自市场竞争加剧与商誉减值隐患。** 国际巨头（Cytiva、Tosoh等）正加大中国市场投入，国内同行也加速融资扩张，公司面临品牌劣势与价格战的双重挤压。此外，账面仍存约9,311万元商誉（赛谱仪器），尽管2025年已扭亏，但若未来“仪器带耗材”战略推进不及预期，或行业竞争导致毛利率持续下滑，商誉减值风险将再次暴露，对利润造成一次性冲击。
