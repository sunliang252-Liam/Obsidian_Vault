# 688221.SH 深度透视

## 因果逻辑链
- **[小核酸药物研发突破]** -> [与GSK达成全球独家授权合作]: 公司小核酸技术平台（ACORDE递送载体）及差异化管线（IgA肾病、MASH等）获得国际顶级药企认可，实现技术价值变现。
- **[核心产品艾可宁®纳入医保]** -> [营收基本盘稳固]: 艾可宁®作为国内唯一长效抗HIV融合抑制剂，纳入国家医保常规目录，通过渠道下沉和学术推广，支撑1.23亿营收。
- **[持续高研发投入（1.42亿）]** -> [扣非净亏损3.02亿]: 研发费用占营收114.71%，主要用于小核酸等早期管线，导致公司尚未盈利，但亏损同比收窄。
- **[多元化业务布局]** -> [增强抗风险能力]: 代理产品缬康韦®、新获批远红外治疗贴（小沿易贴®）及CDMO业务贡献增量收入，降低对单一产品艾可宁®的依赖。
- **[全维度降本增效]** -> [期间费用降低]: 通过人员优化、资源配置聚焦核心业务，管理费用同比下降23.35%，推动扣非净亏损同比减少2500万元。
- **[前沿建瓴股权出售]** -> [回笼资金并聚焦主业]: 出售子公司70%股权，获得现金用于核心研发，但交易对手方付款进度不及预期，形成大额其他应收款。
- **[FB7013获批临床]** -> [小核酸管线进入新阶段]: 首款小核酸药物获国家药监局临床试验批准，标志着公司从临床前向临床阶段的跨越，验证了研发能力。

## 风险警告
公司目前仍处于“烧钱换未来”的典型创新药企阶段。核心风险在于**现金流持续失血与研发高不确定性的双重压力**。2025年经营活动现金流净额为-2.27亿元，而营收仅1.23亿元，且核心产品艾可宁®收入同比下滑7.62%。尽管与GSK的授权合作带来了首付款，但后续高达9.5亿美元的里程碑付款高度依赖临床成功，存在极大不确定性。此外，前期出售子公司形成的约1.3亿元其他应收款回收进度缓慢，进一步加剧了资金链紧张。

另一重大风险是**技术路径的竞争与商业化前景的模糊**。公司小核酸管线虽获GSK认可，但均处于极早期临床前或临床I期阶段，距离商业化至少5-10年。同时，全球小核酸领域竞争激烈，Alnylam等巨头已建立强大壁垒。公司核心产品艾可宁®面临口服长效药物的潜在替代威胁，而新布局的镇痛贴剂、仿制药等业务市场空间有限，难以快速扭转亏损局面。公司估值高度依赖于尚未验证的小核酸管线，一旦研发受挫，股价将面临剧烈波动。
