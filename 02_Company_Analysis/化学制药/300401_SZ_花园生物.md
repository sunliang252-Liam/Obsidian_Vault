# 300401.SZ 深度透视

## 因果逻辑链
- **[维生素D3全产业链成本优势]** -> [扣非净利润增长12.96%]: 公司自产NF级胆固醇用于VD3生产，成本远低于同行，在行业价格下行周期中仍能维持盈利韧性。
- **[药品集采中标]** -> [药品收入占比下降17.29%]: 缬沙坦氨氯地平片、多索茶碱注射液等核心品种面临集采到期接续，量价承压，导致医药板块收入下滑。
- **[羊毛脂衍生品放量]** -> [食品制造行业销量增长71.54%]: 胆固醇列入新饲料添加剂目录，带动羊毛脂及其衍生品销量与收入双增，成为维生素板块新增长点。
- **[可转债募投项目延期]** -> [在建工程增长31.92%]: VB6、生物素、L-丙氨酸等新项目持续投入但多次延期，资本开支高企，短期无法贡献利润。
- **[研发投入资本化率提升]** -> [开发支出增长117.64%]: 资本化研发支出占比从18.64%升至40.90%，虽减少当期费用，但增加了未来摊销压力。
- **[美元贬值]** -> [财务费用增长36.25%]: 美元对人民币汇率贬值导致汇兑损失增加，侵蚀部分利润。
- **[维生素行业供给增加]** -> [维生素产品价格承压]: 行业新增产能释放，海外厂商恢复生产，2025年维生素市场整体价格下降，公司维生素产品毛利率微降0.85%。

## 风险警告
**核心风险在于新项目投产不及预期与维生素价格持续低迷的双重挤压。** 公司可转债募投的VB6、生物素、L-丙氨酸等项目多次延期，截至2025年末在建工程高达8.72亿元，但均未进入量产阶段。若这些项目无法在2026-2027年如期投产并贡献利润，公司可能面临“老业务增长乏力、新业务青黄不接”的困境。同时，维生素D3价格受行业供给增加影响持续承压，公司核心利润来源存在下滑风险。

**药品集采政策风险不容忽视。** 公司医药板块7个产品中选国家或地方集采，但缬沙坦氨氯地平片、多索茶碱注射液等核心品种面临到期接续，续约价格可能进一步下降。若公司未能在后续集采中持续中标，或新获批的硫辛酸片、比索洛尔氨氯地平片等产品市场推广不及预期，医药板块收入可能继续萎缩。此外，公司无形资产中有1002万元因合同纠纷被法院查封，需关注后续法律风险。
