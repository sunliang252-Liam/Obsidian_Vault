# 002370.SZ 深度透视

## 因果逻辑链
- **[出售子公司兴亚药业100%股权]** -> [净利润扭亏为盈]: 出售产生约1.49亿元非经常性损益，掩盖了主业亏损，使归母净利润从0.34亿暴增至0.96亿。
- **[核心产品集采降价与竞争加剧]** -> [营收与扣非净利润双降]: 抗生素类制剂收入同比暴跌34.70%，导致总营收下降20.25%，扣非净利润亏损扩大至-0.65亿元。
- **[可转债到期兑付]** -> [财务费用激增]: 到期支付补偿利息，导致财务费用同比大增32.44%，进一步侵蚀主业利润。
- **[控制权变更]** -> [战略路径切换]: 原控股股东富邦集团退出，新实控人邱中勋入主，公司战略从“仿创结合”转向“向特定对象发行股票募资，布局改良型新药和创新药”。
- **[存货激增]** -> [资产减值风险]: 库存量同比暴增106.66%，导致存货跌价损失增加，资产减值损失达-2310万元，反映产品动销不畅。
- **[研发投入资本化率骤降]** -> [研发策略收缩]: 资本化研发投入同比减少69.94%，表明公司对仿制药一致性评价等确定性较低的研发项目投入趋于保守。
- **[业绩补偿款追索无果]** -> [历史遗留问题悬而未决]: 针对上海新高峰原股东的2.56亿元业绩补偿款诉讼虽胜诉，但执行困难，款项回收存在重大不确定性。

## 风险警告
公司2025年盈利完全依赖出售子公司的一次性收益，核心主业已陷入“营收下滑、亏损扩大”的困境。抗生素类制剂作为营收主力（占比53.41%）受集采冲击严重，且库存高企，未来资产减值风险持续存在。新实控人入主后提出的“创新药转型”战略，需要巨额且持续的资本投入，而公司当前造血能力严重不足，向特定对象发行股票能否成功及后续研发能否产出成果，均存在巨大不确定性。

历史遗留的巨额业绩补偿款（2.56亿元）追索多年无果，已成为事实上的坏账。同时，公司因可转债到期兑付导致现金流大幅净流出，账面现金虽充裕但已大幅减少。在主营业务未见拐点、新战略尚处蓝图阶段、历史包袱沉重的情况下，公司基本面改善的路径极不清晰，投资风险极高。
