# 600420.SH 深度透视

## 因果逻辑链
- **[原料药价格下行]** -> [营收与利润双降]: 核心原料药（如7-ACA、青霉素工业钾盐）销量增长，但市场产能过剩导致价格大幅下跌，板块毛利率骤降9.15个百分点，拖累整体业绩。
- **[集采常态化与营销转型]** -> [制剂收入萎缩]: 抗感染、神经系统等核心制剂受集采降价及“四同政策”冲击，收入下滑15.21%，尽管“以价换量”策略部分对冲，但整体缺口难以弥补。
- **[销售费用锐减]** -> [利润降幅小于营收降幅]: 公司主动压降销售服务费，销售费用同比大降53.95%，期间费用率下降3.57个百分点，有效缓冲了收入下滑对利润的直接冲击。
- **[“原料药+制剂”一体化]** -> [成本控制与供应链韧性]: 内部产业链协同（如抗菌药物从中间体到制剂）形成成本优势，部分对冲了原料药价格波动和制剂集采降价压力，是维持盈利能力的核心护城河。
- **[研发重心转移]** -> [短期投入下降，长期聚焦高价值]: 一致性评价项目进入尾声，研发资源转向改良型新药和高壁垒仿制药，导致研发费用同比下降23.29%，但为未来产品矩阵升级蓄力。
- **[处置亏损子公司]** -> [资产质量优化]: 出售持续亏损的国药哈森51%股权，获得投资收益，并推动国药江苏威奇达、国药一心扭亏，有效剥离非核心资产，改善整体盈利结构。
- **[国药集团内部协同]** -> [渠道与资源赋能]: 依托国药控股的渠道优势（“工商协同”）和国药医工总院的研发资源（“工研协同”），在集采准入、市场覆盖和技术创新上获得独特竞争优势。

## 风险警告
**核心风险在于“量升价跌”的恶性循环能否被打破。** 原料药板块面临严重的产能过剩，尽管销量增长，但价格持续走低已导致毛利率暴跌9个百分点。若行业供需格局无法改善，原料药业务可能从“现金牛”变为“利润黑洞”，持续侵蚀公司整体盈利能力。同时，制剂板块受集采常态化影响，核心大品种（如头孢、神经系统用药）收入持续萎缩，新获批产品尚无法完全弥补缺口，存在“青黄不接”的增长断层风险。

**政策与转型风险不容忽视。** 医药行业政策（集采、医保控费、DRG/DIP）持续高压，公司营销模式从“资源消耗型”向“效率驱动型”转型，虽短期压降了费用，但能否长期维持市场占有率存在不确定性。此外，与国药集团内国瑞药业、西南药业的同业竞争问题尚未彻底解决，虽已签署托管协议，但潜在的整合风险与利益冲突仍是悬在头上的达摩克利斯之剑。
