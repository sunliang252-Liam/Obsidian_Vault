# 688578.SH 深度透视

## 因果逻辑链
- **[核心产品伏美替尼持续放量]** -> [营收增长45.80%]: 第三代EGFR-TKI伏美替尼凭借“脑转强效、安全性佳”的差异化优势，在一线、二线治疗适应症均纳入医保后，实现销售持续放量，驱动营收从35.58亿跃升至51.87亿元。
- **[新产品戈来雷塞获批上市]** -> [贡献新增收入4,046.71万元]: 引进的KRAS G12C抑制剂戈来雷塞于2025年5月获批二线NSCLC适应症，并于年底纳入医保，成为公司第二增长曲线，报告期内实现初步商业化收入。
- **[降本增效措施]** -> [净利润增速（53.10%）高于营收增速（45.80%）]: 在营收高速增长的同时，公司通过优化成本结构、提升生产效率，使得利润弹性更大，扣非净利润同比增长48.54%。
- **[营销团队扩张至1,700人]** -> [销售费用增长46.91%]: 为支撑伏美替尼持续放量及新药戈来雷塞的市场推广，公司大幅扩充营销团队，导致销售费用增至20.76亿元，占营收比例40.02%。
- **[研发投入资本化比重下降]** -> [费用化研发投入增加31.44%]: 因2024年引进戈来雷塞的首付款等资本化支出高峰已过，2025年研发投入资本化率从34.69%降至23.41%，导致当期费用化研发投入显著增加。
- **[伏美替尼新适应症获批]** -> [拓展市场空间]: 2026年2月，伏美替尼用于EGFR 20外显子插入突变二线治疗适应症获批，进一步扩大了其适用患者群体，为未来增长提供新动力。
- **[海外临床推进]** -> [打开全球市场天花板]: 与ArriVent合作的伏美替尼针对EGFR 20外显子插入突变一线治疗的全球III期临床已完成入组，针对PACC突变的国际III期临床也已启动，海外授权收入及未来海外上市潜力巨大。

## 风险警告
**核心产品单一依赖风险**：公司当前营收几乎完全依赖伏美替尼（占比超98%）。尽管戈来雷塞已上市，但体量尚小。一旦伏美替尼面临竞争加剧（如奥希替尼降价、新一代药物出现）、医保政策调整或临床数据不利，将对公司业绩造成毁灭性打击。公司产品管线高度集中于NSCLC领域，抗风险能力较弱。

**高销售费用侵蚀利润风险**：公司销售费用率高达40%，远超行业平均水平（如翰森制药27%）。随着营销团队扩张至1,700人，费用刚性增长。若未来产品放量速度不及预期，或医保降价幅度超预期，高额的销售费用将严重侵蚀净利润，导致盈利能力下滑。
