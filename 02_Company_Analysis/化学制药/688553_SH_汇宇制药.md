# 688553.SH 深度透视

## 因果逻辑链
- **[集采降价]** -> [营收下降8.79%]: 核心产品奥沙利铂注射液、注射用培美曲塞二钠等集采中标价持续下降，导致国内收入同比下滑16.03%。
- **[持有同源康医药股价暴跌]** -> [归母净利润亏损2496万元]: 被投企业同源康医药港股股价大幅波动，确认公允价值变动损失1.67亿元，是导致公司由盈转亏的直接原因。
- **[海外业务放量]** -> [境外收入增长32.23%]: 欧洲直营团队扩张及新兴市场覆盖国家增至90个，境外产品收入同比增长53.95%，部分对冲国内集采压力。
- **[研发投入高企]** -> [侵蚀当期利润]: 研发投入占营收比例达34.51%，其中费用化研发支出3.03亿元，持续的高强度投入是扣非净利润仅8510万元的核心原因之一。
- **[原料药制剂一体化]** -> [成本控制优势]: 多个制剂产品实现原料药自主供应，在集采降价背景下，核心产品如注射用培美曲塞二钠成本同比下降58.37%，维持了毛利率。
- **[复杂注射剂进入收获期]** -> [未来增长点]: 兰瑞肽、蔗糖铁等复杂注射剂进入注册审评阶段，白蛋白紫杉醇已在9个欧洲国家获批，高壁垒产品有望贡献增量。
- **[特别表决权结构]** -> [实际控制人绝对控制]: 丁兆通过5倍表决权的A类股份，持有53.97%的表决权，对公司经营决策具有绝对控制权，存在中小股东利益潜在风险。

## 风险警告
公司当前最大的风险在于**集采降价对主营业务的持续侵蚀**。尽管海外业务高速增长，但国内收入占比仍超78%，核心大品种奥沙利铂、培美曲塞等价格下行趋势未改，导致主营业务毛利率同比下降3.65个百分点。若后续集采续约价格进一步下降或中标区域减少，公司国内收入存在继续大幅下滑的风险，而海外业务的增量尚不足以完全弥补这一缺口。

其次，**创新药研发的高投入与高风险**是另一核心风险。公司研发投入占营收比高达34.51%，但13个I类创新药项目均处于临床早期或实验室阶段，距离商业化尚远。创新药研发具有长周期、高失败率的特点，持续的研发投入将长期压制公司利润表现。同时，公司持有同源康医药等金融资产，其公允价值波动已对2025年利润造成巨大冲击，未来仍存在类似风险。
