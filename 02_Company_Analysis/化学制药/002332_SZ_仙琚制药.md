# 002332.SZ 深度透视

## 因果逻辑链
- **[集采深化压降存量制剂收入]** -> [制剂收入同比下降2%]: 黄体酮注射液、醋酸泼尼松片等普药因省际联盟集采深化，收入同比减少约0.72亿元；黄体酮胶囊、噻托溴铵粉雾剂因区域集采分别减少约0.41亿、0.34亿元。
- **[原料药市场竞争加剧]** -> [原料药收入同比下降13.5%]: 国内原料药销售受制剂集采传导，量价齐跌，同比减少34%；国际销售下半年竞争加剧，同比减少约2.7%；原料药流通贸易同比减少约0.85亿元。
- **[反垄断罚没导致扣非净利润大幅下滑]** -> [扣非净利润同比下降36.5%]: 因2021-2024年期间涉及地塞米松磷酸钠原料药垄断协议，被没收违法所得并处罚款合计1.95亿元，计入非经常性损益，导致扣非净利润从5.49亿降至3.49亿。
- **[意大利子公司保险赔付增厚非经常性损益]** -> [归母净利润同比增长13.21%]: 意大利Newchem公司收到保险赔款（累计1370万欧元），计入营业外收入，叠加罚没支出为非经常性项目，使得归母净利润在营收下滑背景下逆势增长。
- **[呼吸科新产品放量]** -> [呼吸类制剂收入同比增长7.3%]: 糠酸莫米松鼻喷雾剂增长15%，先定诺和思特珑增长超80%，新产品虽基数小但保持较快增长，部分对冲了存量品种集采下滑的影响。
- **[研发投入持续增加]** -> [研发费用同比增长14.55%]: 公司处于由“仿制”到“创新”的转型期，研发投入占营收比例提升至8.08%，重点布局呼吸、妇科、围术期等领域的复杂仿制药及改良型新药。
- **[销售费用率上升]** -> [销售费用同比增长14.19%]: 部分制剂产品处于市场拓展期，为应对集采压力，公司加大学术推广和渠道建设投入，销售费用增速显著高于营收增速。

## 风险警告
**核心风险：集采深化与原料药价格下行双重挤压，导致公司核心盈利能力的持续恶化。** 2025年公司营收同比下降6.04%，扣非净利润更是暴跌36.5%，主因是存量制剂品种（普药、黄体酮胶囊等）因集采深化持续失血，同时原料药业务面临量价齐跌的困境。更严峻的是，公司当前处于“新旧动能转换期”，新产品的放量速度尚无法弥补存量业务的萎缩，短期内业绩拐点不明确。

**重大合规与商誉风险：** 公司因原料药垄断协议被处以1.95亿元巨额罚没，暴露出内部合规管理的重大缺陷，未来可能面临更多监管审查或诉讼风险。此外，公司账面商誉高达6.36亿元（主要来自收购意大利Newchem和Effechem），若海外子公司经营业绩未达预期，存在大额商誉减值的风险，可能对利润表造成一次性冲击。
