# 600585.SH 深度透视

## 因果逻辑链
- **[需求收缩与成本压降]** -> [营收下降但利润增长]: 水泥需求下滑导致营收降9.33%，但通过燃料成本下降15.70%和精细化运营，自产品综合成本降11.12%，实现净利润逆势增长5.42%。
- **[燃料成本大幅下降]** -> [毛利率提升2.95个百分点]: 煤炭等燃料及动力成本占水泥熟料成本比重从55.41%降至52.56%，单位成本下降15.70元/吨，是利润增长的核心驱动力。
- **[海外与出口销量增长]** -> [对冲国内需求下滑]: 国内水泥熟料销量下降，但海外和出口销量增长，使总销量仅微降0.29%，优于行业平均6.9%的产量降幅。
- **[产业链延伸（骨料、商混）]** -> [创造新增长点]: 骨料产能达1.80亿吨，商混产能达7025万立方米，虽骨料毛利率下降，但商混毛利率提升，多元化收入结构缓冲了主业下行压力。
- **[集中采购与精细化管理]** -> [成本优势持续巩固]: 深化集中采购模式，优化原燃材料采购渠道，叠加替代燃料使用，系统性降本增效，使公司成本管控能力在行业下行期成为核心护城河。
- **[高分红政策]** -> [强化股东回报预期]: 2025年全年每股分红0.85元，分红比例55.29%，符合“未来三年分红不低于净利润50%”的规划，高股息率对长期投资者形成吸引力。
- **[AI大模型与数智化转型]** -> [赋能生产精细化]: 发布建材行业首个AI大模型，在质量管控、生产优化等40余个场景应用，助力降本提效减碳，提升长期运营效率。

## 风险警告
**核心风险在于行业需求长期下行与产能过剩的持续压力。** 2025年全国水泥产量同比下降6.9%，固定资产投资增速转负，房地产投资持续下滑，需求端尚未见底。公司虽通过成本压降实现利润增长，但营收已连续两年大幅下滑，若需求进一步萎缩，价格战加剧，盈利空间将被严重挤压。公司2026年销量目标2.60亿吨，较2025年实际销量2.65亿吨继续下调，表明管理层对需求前景持谨慎态度。

**第二大风险是环保与碳履约成本上升。** 水泥行业被纳入全国碳排放权交易市场，将直接增加企业碳履约成本。公司虽积极布局CCER交易和绿电项目，但超低排放改造、替代燃料使用等均需持续资本投入（2026年计划资本支出118.20亿元），可能侵蚀短期利润。此外，公司交易性金融资产激增至128.99亿元（主要为理财和结构性存款），需关注其收益波动对非经常性损益的影响。
