# 920163.BJ 深度透视

## 因果逻辑链
- **[产能释放与市场拓展]** -> [不干胶材料收入增长39.28%]: 二期项目新增5条自动化生产线投产，产能持续释放，同时公司将不干胶材料作为推广重点，国内重点开拓华南及华东区域市场，成功将产能转化为销量。
- **[内销战略转型]** -> [内销收入增长39.38%，内外销趋于平衡]: 在复杂的国际政治经济形势下，公司主动调整战略，大力开拓国内市场，使内销收入大幅增长，降低了对外销市场的依赖。
- **[华南生产基地布局]** -> [投资活动现金流净流出增加76.51%]: 2025年8月收购成立惠州子公司，筹建华南生产基地，导致购建固定资产、无形资产支付的现金大幅增加。
- **[原材料成本压力]** -> [毛利率微降0.92个百分点至15.06%]: 营业成本增速（17.64%）略高于收入增速（16.37%），主要受原材料价格波动及内销低毛利产品占比提升影响。
- **[财务费用激增]** -> [财务费用增长360.05%]: 银行贷款利息增加及汇兑收益减少，导致财务费用从-208.53万元增至542.30万元，侵蚀利润。
- **[信用减值损失扩大]** -> [净利润增速（-0.78%）远低于收入增速（16.37%）]: 公司对部分应收账款单项计提553.61万元坏账准备，导致信用减值损失同比增加122.7%，是利润未能同步增长的主要原因。
- **[经营现金流显著改善]** -> [经营活动现金流净额增长75.74%]: 营业收入增长带动货款回款增加，经营质量提升，为后续产能扩张和资本开支提供支撑。

## 风险警告
**核心风险在于“增收不增利”的困境与产能扩张后的消化压力。** 公司2025年营收增长16.37%，但归母净利润微降0.78%，主要受财务费用激增（+360%）和信用减值损失扩大（+122.7%）拖累。财务费用飙升源于贷款利息增加和汇兑收益减少，而信用减值损失则暴露了公司在快速扩张中应收账款管理风险的上升。若此趋势延续，将严重侵蚀公司盈利能力。

**产能扩张与市场消化之间的错配风险不容忽视。** 公司二期项目及惠州基地的投产将带来产能大幅提升，但下游快递物流行业增速已放缓（2026年预计快递业务量增速8%），且国内市场竞争激烈。若公司无法有效消化新增产能，可能导致存货积压、价格战加剧，进而引发存货减值风险和毛利率进一步下滑。此外，公司资产负债率已升至45.62%，短期借款和一年内到期非流动负债大幅增加，财务杠杆的上升将放大经营波动对利润的影响。
