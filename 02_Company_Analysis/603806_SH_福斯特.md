# 603806.SH 深度透视

## 因果逻辑链
- **全球光伏装机持续增长，2025年新增约580GW** -> 光伏胶膜需求维持高位，公司出货量同比基本持平: 装机增长带来封装材料需求，但组件效率提升导致单GW用量下降，抵消部分增量
- **光伏产业链产能过剩，组件价格维持低位** -> 光伏胶膜售价持续下探，公司光伏材料营收同比下降21.31%: 组件价格低位传导至上游辅材，胶膜价格随之下跌
- **公司全球市占率超50%，远超第二至第四名总和** -> 公司在行业价格战中保持盈利，而二三线企业多数亏损: 龙头地位带来规模效应、成本优势和客户粘性，增强抗风险能力
- **海外产能投产，泰国3.5亿平、越南2.5亿平** -> 海外销售占比提升至26.90%，有效规避贸易壁垒: 海外产能就近配套，降低关税和运输成本，提升竞争力
- **N型电池（TOPCon/HJT/BC）技术快速渗透** -> 公司推出转光胶膜、0BB皮肤膜等新品，绑定头部组件企业: 新型电池对封装材料提出更高要求，公司技术领先适配需求
- **美伊冲突导致霍尔木兹海峡航运受阻，全球能源危机爆发** -> 2026年全球光伏需求大幅提振，公司光伏业务受益: 地缘政治风险暴露化石能源脆弱性，光伏成为能源安全刚需
- **AI算力爆发式发展，高阶PCB需求激增** -> 感光干膜销量同比增长18.67%，国内市占率提升至15%: AI服务器PCB层数提升、高速材料需求增加，带动高端感光干膜需求
- **国产替代进程加速** -> 公司感光干膜成功打破国际垄断，进入深南电路等头部企业: 国内PCB厂商高端材料国产化意愿强，公司产品性能达国际水平
- **液态软包锂电池能量密度提升至320-360Wh/kg** -> 铝塑膜需求稳定增长，公司销量同比增长12.56%: 能量密度提升对铝塑膜阻隔性、轻量化提出更高要求
- **固态电池产业化加速，多款车型搭载半固态电池** -> 公司联合客户定制开发固态电池专用铝塑膜: 固态电池对封装材料界面稳定性、柔性要求更高，公司提前布局

## 风险警告
公司面临多重风险：1)光伏行业产能过剩持续，胶膜价格可能进一步下跌，导致毛利率承压；2)国际贸易壁垒升级，海外建厂虽缓解部分风险但资本开支增大；3)电子材料业务虽增长但规模较小，尚不能完全对冲光伏周期波动；4)原材料EVA/POE树脂价格波动可能侵蚀利润；5)全球能源危机若缓解，光伏需求增速可能放缓。
