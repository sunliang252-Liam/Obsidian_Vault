# 603706.SH 深度透视

## 因果逻辑链
- **[供热业务毛利率大幅提升]** -> [净利润逆势增长]: 供热业务成本下降11.65%，毛利率增加11.19个百分点，抵消了天然气销售和安装业务下滑的影响，推动归母净利润增长9.43%。
- **[天然气销售气量下降16.08%]** -> [营收减少7.77%]: 非居民用气量同比减少22.99%，导致天然气销售收入下降14.02%，成为营收下滑的主要拖累。
- **[成本降幅大于收入降幅]** -> [利润改善]: 营业成本下降13.43%，远超营收7.77%的降幅，成本端优化（天然气采购量减少、安装业务结构变化、热能采购及折旧减少）直接增厚利润。
- **[安装业务结构变化]** -> [毛利率大幅波动]: 天然气设施设备安装业务收入下降22.91%，但成本下降35.10%，毛利率从30.88%跃升至41.81%，显示业务重心向高毛利项目转移。
- **[气源多元化与管网互联互通]** -> [供应保障优势]: 依托新疆丰富的天然气资源，与中石油、中石化等建立稳定合作，并利用国家管网改革打通跨省串换渠道，形成多元化气源格局，降低单一依赖风险。
- **[区域特许经营壁垒]** -> [稳定现金流]: 公司在昌吉市拥有近3000公里管网，伊宁供热为当地最大热力企业，区域垄断地位带来稳定的用户基础和经营性现金流（2.7亿元）。
- **[高分红政策]** -> [股东回报]: 连续三年每10股派发现金红利9元，2025年分红比例达78.87%，高分红策略有效吸引红利型投资者，支撑股价。

## 风险警告
**核心风险在于天然气顺价机制不畅。** 上游气源成本上涨时，下游终端售价受政府管控，价格联动存在时滞甚至无法完全传导，导致天然气销售业务毛利率持续承压（2025年仅为15.29%）。若未来上游气价持续走高而政府为保民生压制调价，公司燃气业务的盈利空间将被进一步压缩。

**另一重大风险是资产减值与区域集中度。** 公司2025年对债务重组抵债资产计提了2,413万元减值准备，显示非主业投资存在回收风险。同时，公司业务高度集中于昌吉市和伊宁市，区域经济增长放缓或城市化进程停滞将直接冲击燃气和供热需求，缺乏跨区域分散风险的能力。
