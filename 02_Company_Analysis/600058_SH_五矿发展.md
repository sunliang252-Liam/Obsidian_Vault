# 600058.SH 深度透视

## 因果逻辑链
- **[下游需求持续疲软]** -> [营收与利润双降]: 房地产筑底、基建托底有限，导致钢材需求连续五年下降，公司钢材、铁矿石等主营产品量价齐跌，营收同比-21.44%，归母净利润同比-84.80%。
- **[主营商品价格低位震荡]** -> [扣非净利润持续为负]: 钢材价格指数（CSPI）全年均值同比-9.1%，铁矿石、焦煤等成本端支撑减弱，公司主营贸易业务毛利空间被严重压缩，扣非净利润-1.46亿元，连续两年亏损。
- **[制造业终端转型]** -> [钢材业务结构优化]: 公司主动收缩低毛利工程配供，聚焦汽车、新能源等28个制造领域，制造业终端销量同比+52%，带动钢材业务毛利率同比+1.58个百分点。
- **[套期保值对冲风险]** -> [经营业绩波动平滑]: 公司通过期货、期权等工具对冲现货价格波动风险，虽期货端产生-256.93万元损益，但有效锁定了部分自营业务收益，避免了更大亏损。
- **[融资结构改善]** -> [财务费用大幅下降]: 公司带息负债占用减少，叠加人民币升值带来的汇兑收益，财务费用同比-57.28%，成为利润表为数不多的亮点。
- **[关联交易依赖度较高]** -> [业绩稳定性存疑]: 前五名客户销售额中关联方占比12.53%，与五矿集团体系内公司（如中国一冶、五冶）的钢材销售是重要收入来源，业绩受集团内部需求影响较大。
- **[重大资产重组推进]** -> [业务根本性变革]: 公司正筹划重大资产置换，拟置出原有贸易业务，注入五矿矿业控股及鲁中矿业股权，交易完成后公司将转型为黑色金属矿业公司，彻底解决同业竞争问题。

## 风险警告
**核心风险在于主业盈利能力持续恶化。** 公司2025年扣非净利润已连续两年为负，主营的贸易业务毛利率仅2.80%，在行业“供强需弱”格局下，利润空间被极度压缩。归母净利润0.19亿元完全依赖政府补助（1.38亿）和应收款项减值转回（0.59亿）等非经常性损益，主业造血能力堪忧。若大宗商品价格继续低位运行，公司可能面临持续亏损风险。

**重大资产重组的不确定性是另一关键风险。** 公司拟通过资产置换转型为矿业公司，但交易尚处于审计评估阶段，最终方案、定价及能否获得监管批准均存在重大不确定性。若重组失败，公司将继续深陷低毛利贸易泥潭，且此前承诺的海外资产注入问题将再次悬而未决。此外，公司分红比例高达188.53%，远超净利润，虽体现回馈意愿，但可持续性存疑。
