# 601388.SH 深度透视

## 因果逻辑链
- **[铝合金锭售价提升，原料成本优化]** -> [净利润暴增815.58%]: 下游需求复苏推升产品售价，同时汇率波动收窄、原料成本增幅低于售价，毛利率改善驱动利润大幅反弹。
- **[美国关税政策重塑废钢市场]** -> [美国子公司原料成本下降]: 高额钢铁进口关税使美国本土废钢需求走强、出口减少，国内供给增加压低公司采购成本，叠加有色金属价格走强，废旧金属回收业务盈利提升。
- **[马来西亚新厂产能释放与老厂资产处置]** -> [资产处置收益1,119%增长]: 新建项目承接老厂生产任务后，处置YCPG土地使用权及附属固定资产，产生一次性收益，同时淘汰落后产能、降低综合运营成本。
- **[全球化采购网络与垂直整合]** -> [原料供应稳定性与成本护城河]: 覆盖美、欧、东南亚的采购体系，叠加美国20多个回收站点，有效对冲国内废铝回收体系不健全的风险，保障原料来源并获取产业链上游利润。
- **[AI与自动化技术投入]** -> [运营效率与成本控制提升]: 投资1,300万引入自动化分选设备、1,400万升级熔炼系统，提升分选效率、金属回收率，降低能耗，实现精益化用工与成本领先。
- **[经营现金流由负转正]** -> [销售策略调整见效]: 为规避市场风险，增加账期短、回款快的销售，经营活动现金流净额从-2.6亿转为+2.5亿，改善流动性。
- **[汇率波动收窄]** -> [主营业务毛利改善]: 报告期内汇率波动幅度较同期明显收窄，降低了对公司毛利的不利影响，是利润大幅增长的重要非经营性因素。

## 风险警告
**核心风险在于业绩对宏观环境与政策的极度敏感。** 公司净利润从2024年的1855万暴增至2025年的1.7亿，主要驱动力是铝合金锭售价上涨、美国关税政策带来的原料成本下降以及一次性资产处置收益。这些因素均非公司内生增长，而是外部市场与政策红利。一旦下游需求转弱、铝价回落，或美国关税政策调整导致废钢市场格局逆转，公司盈利将面临剧烈波动。2024年净利润仅1855万已充分暴露其脆弱性。

**另一重大风险是境外经营与汇率波动。** 公司88.51%的资产在境外，业务横跨中美马三国，面临地缘政治、税收政策变动及汇率三重风险。马来西亚新建65万吨项目因航运与地缘风险采取“审慎推进”策略，产能释放不及预期。同时，人民币、林吉特与美元间的汇率波动直接影响利润，2025年汇率收窄是利好，但未来若重新剧烈波动，将对业绩构成显著冲击。公司研发投入仅占营收0.04%，长期技术壁垒薄弱，增长依赖外部环境而非自身护城河。
