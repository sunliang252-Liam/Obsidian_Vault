# 600379.SH 深度透视

## 因果逻辑链
- **[核心原材料铜银价格暴涨]** -> [主营产品毛利率承压]: 铜价年内涨33%，银价涨128%，采购成本急剧上升，而产品售价传导滞后，导致真空灭弧室毛利率同比下降3个百分点。
- **[配网市场竞争加剧]** -> [终端降价压力向上游传导]: 行业短期政策影响下，配网领域价格战激烈，公司产品出厂价明显下降，进一步压缩盈利空间。
- **[储能业务战略转型]** -> [营收与利润大幅下滑]: 主动退出低毛利系统集成业务，聚焦EMS软件销售与火储调频服务，叠加火储调频资产进入设备更新周期出现阶段性亏损，储能收入同比骤降96%。
- **[收购凯赛尔科技]** -> [巩固配网市场龙头地位]: 通过股权收购及增资控股凯赛尔科技51.16%股权，实现双品牌运营，产能提升50%，销量增长33.7%，直接贡献净利润634.95万元。
- **[新产品与国际化突破]** -> [对冲主业下滑]: 新产品销售收入同比增长54.6%，销量增长120%；国际业务收入同比增长20.3%，高附加值产品占比提升有效缓解了传统业务压力。
- **[氢能业务稳健增长]** -> [形成第二增长曲线]: 宝光联悦紧扣产业发展机遇，营收同比提升25.81%，利润总额同比增长15.28%，并与陕煤合作拓展上游供应链稳定性。
- **[金属化陶瓷向新兴领域拓展]** -> [开辟新盈利增长点]: 陶瓷科技剥离传统配网业务，向医疗、高端半导体领域延伸，新兴业务销售收入占比超过10%，成为新的利润来源。

## 风险警告
**核心风险在于原材料价格波动与成本传导机制的脆弱性。** 公司主营产品真空灭弧室的核心原材料铜、银价格在2025年创历史新高，而产品售价受市场竞争制约无法及时传导，导致毛利率大幅下滑。尽管公司计划建立价格联动机制，但下游客户接受度与执行效果存在重大不确定性。若铜银价格维持高位或继续上涨，公司盈利能力将持续承压，2025年净利润同比下滑43.23%已充分暴露这一风险。

**储能业务战略转型阵痛与资产更新周期叠加，短期业绩拖累明显。** 公司主动退出低毛利系统集成业务，导致储能收入同比暴跌96%，同时火储调频资产进入设备更新周期出现阶段性亏损，子公司宝光智中全年亏损1,222.87万元。虽然公司预计后续项目交付及设备更新并网后能实现扭亏，但储能行业竞争激烈、政策变化快，转型成效与扭亏时间表存在较大不确定性，可能持续拖累整体业绩。

**控股股东同业竞争承诺尚未解决，治理结构存在潜在利益冲突。** 中国电气装备集团承诺五年内解决与公司的同业竞争问题，但截至报告期末仍未出台具体方案。随着公司直接控股股东变更为西电集团，这一历史遗留问题若不能妥善解决，可能限制公司未来在相关领域的业务拓展，或导致关联交易复杂化，对中小股东利益构成潜在威胁。
