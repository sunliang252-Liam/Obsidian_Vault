# 605167.SH 深度透视

## 因果逻辑链
- **[营收结构变化]** -> [收入下降但毛利率提升]: 2025年营收下降24.95%，但毛利率提升4个百分点至19.97%，主因低毛利的工程服务业务收缩，高毛利的工业模块业务占比被动提升。
- **[可转债发行]** -> [总资产与负债率飙升]: 发行7.5亿元可转债，叠加银行借款增加，总资产增长38.88%至46.67亿元，资产负债率从45.33%跃升至56.38%。
- **[南通基地建设]** -> [在建工程暴增与现金流恶化]: 南通利柏特重工项目投入增加，在建工程增长794.15%至9.41亿元，导致投资活动现金流净流出7.92亿元，经营现金流净额暴跌93.53%。
- **[巴斯夫大合同]** -> [业绩压舱石与收入确认风险]: 与巴斯夫签订的23.76亿元EPC合同是核心收入来源，但收入确认依赖完工百分比法，存在管理层估计偏差风险。
- **[外销业务韧性]** -> [对冲内销下滑]: 外销收入逆势增长7.24%，毛利率34.67%远高于内销的17.07%，成为利润稳定器。
- **[研发投入持续]** -> [技术护城河加固]: 研发费用增长26.66%至9839.92万元，占营收3.75%，巩固了公司在大型工业模块设计和制造领域的技术壁垒。
- **[高端客户粘性]** -> [订单稳定性]: 巴斯夫、霍尼韦尔等国际巨头客户转换成本极高，为公司提供了穿越周期的订单基础，但同时也导致客户集中度风险（前五客户占收入70.07%）。

## 风险警告
**核心风险在于扩张期的现金流与资产错配。** 公司为南通基地大规模举债和投入，导致经营现金流（仅2682万元）远不足以覆盖投资活动现金流出（7.92亿元），严重依赖融资（筹资净流入9.16亿元）。若南通基地投产不及预期或下游需求放缓，公司将面临巨大的偿债压力和资产减值风险。可转债的发行虽解了燃眉之急，但也大幅推高了财务杠杆，未来利息支出将侵蚀利润。

**另一关键风险是收入确认的复杂性与客户集中度。** 公司大量收入来自按履约进度确认的长期合同（如巴斯夫项目），管理层对总成本和完工进度的估计存在主观性，审计师已将其列为关键审计事项。同时，前五大客户贡献超70%营收，任何单一客户的订单延迟或取消，都将对公司业绩造成剧烈冲击。海外业务虽毛利率高，但汇率波动和地缘政治风险亦不容忽视。
