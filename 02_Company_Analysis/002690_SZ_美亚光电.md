# 002690.SZ 深度透视

## 因果逻辑链
- **色选机业务稳健增长+毛利率提升** -> 净利润增长10.77%: 色选机收入增长8.05%，毛利率提升4.62个百分点，是利润增长的核心引擎。
- **医疗业务收入下滑但降幅收窄** -> 整体营收仍增长4.16%: 口腔CBCT受行业低谷影响收入下降9.75%，但非口腔新产品（移动CT、骨科导航）实现销售，对冲了部分下滑。
- **AI+数智化产品升级** -> 提升产品附加值及毛利率: 推出美亚大师4.0、口腔影像智能体等，通过技术溢价和成本优化，推动主营毛利率同比提升3.49个百分点。
- **海外市场持续拓展** -> 出口收入增长9.78%: 色选机及医疗设备出口保持良好增长，海外收入占比提升至23.42%，有效弥补国内需求波动。
- **经营现金流强劲** -> 净利润含金量高: 经营活动现金流净额9.62亿元，同比增长9.62%，远超净利润，体现公司强大的回款能力和健康的商业模式。
- **高分红政策** -> 股东回报稳定: 连续多年高比例现金分红，2025年拟每10股派7元，累计分红近49亿元，强化价值投资属性。

## 风险警告
**核心风险在于口腔医疗业务的持续低迷。** 尽管公司表示坚定看好行业未来，但国内口腔行业仍处于阶段性低谷，口腔CBCT收入已连续两年下滑（2025年同比-9.75%）。若行业需求复苏不及预期，该业务将继续拖累整体营收增速，并可能引发市场对公司成长性的担忧。公司虽推出移动CT、骨科导航等新品，但规模尚小，短期内难以完全替代口腔业务的利润贡献。

**其次，市场竞争加剧与核心人才流失风险并存。** 色选机行业竞争激烈，国内对手（中科光电、泰禾智能等）及国际巨头（布勒、佐竹）持续施压，若公司不能在技术、服务上保持领先，可能面临毛利率下滑和市场份额丢失。同时，公司研发人员数量同比下降6.31%，30岁以下研发人员流失30.14%，在AI和高端医疗影像领域的人才争夺战中，核心团队稳定性面临挑战，可能削弱长期创新能力。
