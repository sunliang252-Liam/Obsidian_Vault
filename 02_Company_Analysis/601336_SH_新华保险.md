# 601336.SH 深度透视

## 因果逻辑链
- **[分红险转型成功]** -> [新业务价值飙升57.4%]: 分红险长期首年保费暴增12倍至119.33亿元，推动银保渠道新业务价值同比+110.2%，成为价值增长核心引擎。
- **[权益市场回暖 + 积极配置]** -> [总投资收益率6.6%]: 把握市场机遇，增配优质权益资产，投资资产买卖价差收益同比+1267.5%，驱动总投资收益同比+30.9%。
- **[“报行合一”政策红利]** -> [银保渠道量价齐升]: 成本结构优化下，银保长期首年保费同比+52.3%，新业务价值创历史新高，实现规模与价值双赢。
- **[个险渠道提质增效]** -> [人均产能同比+43%]: 队伍规模企稳，通过基本法改革和绩优体系建设，推动月均人均综合产能大幅提升，实现内涵式增长。
- **[“保险+服务+投资”三端协同]** -> [服务生态赋能主业]: 构建“医康养财商税法教乐文”十大服务生态，覆盖400余万客户，提升客户粘性与产品竞争力。
- **[响应中长期资金入市号召]** -> [投资收益增厚]: 出资462.5亿元设立试点基金，参与国家创投基金，构建多元化资产配置，抵御低利率挑战。
- **[业务品质持续改善]** -> [续期保费“压舱石”作用稳固]: 13个月继续率提升至97.1%，25个月继续率提升至93.3%，退保率降至1.5%，保障保费收入稳定增长。

## 风险警告
**核心风险在于利率中枢长期下移对利差损的侵蚀。** 公司净投资收益率已降至2.8%，而内含价值评估假设投资回报率为4.0%。若利率持续低位，将导致有效业务价值大幅缩水（敏感性测试显示投资回报率降50bp，有效业务价值近乎腰斩至369.65亿元），并加剧资产负债久期错配风险。

**权益市场波动是利润的放大器。** 2025年归母净利润38.3%的高增长高度依赖权益市场的公允价值变动和买卖价差收益。一旦市场转弱，投资收益将剧烈收缩，利润高增长不可持续。同时，综合投资收益率已从2024年的8.5%降至5.0%，显示市场波动已对整体收益造成冲击。
