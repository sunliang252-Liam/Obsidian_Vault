# 601898.SH 深度透视

## 因果逻辑链
- **[煤炭价格下行]** -> [营收与利润双降]: 2025年自产商品煤售价下跌77元/吨，买断贸易煤售价下跌91元/吨，直接导致煤炭业务营收减少403亿元，归母净利润下降7.3%。
- **[成本管控深化]** -> [利润降幅小于营收降幅]: 自产商品煤单位销售成本同比减少30.22元/吨（-10.7%），毛利率反而提升2.6个百分点至27.5%，有效对冲了价格下跌的冲击。
- **[煤化工产能释放]** -> [产量增长但盈利承压]: 尿素、甲醇产量分别增长14.1%和13.0%，但聚烯烃、尿素价格分别下跌9.4%和14.4%，导致煤化工毛利下降13.6%。
- **[电力业务扩张]** -> [新增长极贡献增量]: 发电量同比增加46.4亿千瓦时，电力业务利润总额同比增加7.25亿元至10.83亿元，成为对冲煤炭周期的重要缓冲。
- **[资本开支高企]** -> [投资现金流大幅流出]: 在建工程增长44.3%至262.66亿元，资本开支199.21亿元，导致投资活动现金净流出309.25亿元，同比扩大157.4%。
- **[债务结构优化]** -> [财务费用下降]: 成功发行48亿元低息科技创新债券，优化债务结构，财务费用同比减少16.2%至20.03亿元。
- **[关联交易依赖]** -> [供应链协同与风险并存]: 向控股股东采购煤炭97.71亿元（占营业成本9.1%），内部煤化工用煤自给率超80%，保障供应但存在定价与合规风险。

## 风险警告
**核心风险：煤价中枢下移与资本开支高峰的双重挤压。** 2025年营收下降21.8%，而资本支出计划仍高达213.26亿元，在建工程激增44.3%。若未来煤价持续弱势震荡，公司经营性现金流（已同比减少12.7%）可能无法覆盖庞大的投资支出，导致杠杆率攀升。煤化工业务毛利率仅14.4%，聚烯烃产能过剩压力下，新项目（榆林90万吨聚烯烃）投产后的盈利前景存在不确定性。

**次要风险：安全生产与环保合规的刚性成本。** 公司煤矿、化工业务涉及高危环节，安全与环保投入持续增加。报告期内专项储备余额下降64.8%，显示前期结余被大量使用。未来若发生重大安全事故或环保处罚，将直接冲击利润并影响产能释放。同时，控股股东关于解决同业竞争的承诺（资源发展公司和华昱公司注入）期限为7年，执行进度和定价存在不确定性。
