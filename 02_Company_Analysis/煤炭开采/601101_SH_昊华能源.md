# 601101.SH 深度透视

## 因果逻辑链
- **[煤炭价格大幅下行]** -> [净利润腰斩]: 2025年煤炭平均售价同比下降87.11元/吨，导致归母净利润5.12亿元，同比下滑50.57%，尽管产量创历史新高，仍无法对冲价格下跌。
- **[“以量补价”策略]** -> [营收降幅小于利润降幅]: 煤炭产量1,843万吨（+2.01%）、甲醇销量51.61万吨（+15.20%）均创历史纪录，部分抵消了价格下跌对收入的冲击。
- **[主力矿井成本优势]** -> [维持盈利韧性]: 高家梁、红庆梁煤矿生产成本行业领先，在煤价下行周期中，自产煤炭毛利率仍达43.33%，但同比下滑9.59个百分点。
- **[煤化工原料煤成本下降]** -> [国泰化工扭亏为盈]: 受益于原料煤价格下降及内部管控，国泰化工实现利润总额83.05万元，同比大幅减亏2.6亿元。
- **[红墩子煤业拖累]** -> [整体业绩承压]: 红墩子煤业新投产项目尚未达产，全年净亏损4.19亿元，且第四季度计提在建工程减值准备，严重拖累合并报表利润。
- **[煤炭物流业务扩张]** -> [收入结构变化]: 鑫达商贸拓展煤炭物流业务，物流收入同比增长42.63%，但毛利率仅5.71%，拉低了整体盈利水平。
- **[融资成本创新低]** -> [财务费用控制]: 公司融资成本降至2.22%，取得AAA主体信用评级，但财务费用仍同比上升9.22%，主因带息负债结构调整。

## 风险警告
**核心风险：煤炭价格持续低迷与红墩子煤业亏损的“双杀”效应。** 公司业绩高度依赖煤价，2025年净利润已腰斩。2026年经营计划中，预计归母净利润仅5.83亿元，显示管理层对煤价恢复持谨慎态度。若煤价进一步下跌或长期低位运行，公司盈利能力将面临严峻考验。同时，红墩子煤业作为未来增量来源，目前仍处于亏损状态，其达产进度和盈利能力存在重大不确定性，是拖累业绩的核心变量。

**次要风险：资产减值与历史诉讼的潜在冲击。** 报告期内已计提1.09亿元资产减值损失（含红墩子煤业在建工程减值），且预计负债因弃置费用计提同比大增109%。此外，公司仍面临多起未决诉讼（如山西中博股权纠纷、证券虚假陈述索赔），涉案金额巨大，未来可能产生额外的非经常性损失，进一步侵蚀利润。
