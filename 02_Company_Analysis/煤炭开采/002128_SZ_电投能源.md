# 002128.SZ 深度透视

## 因果逻辑链
- **[铝产品量价齐升]** -> [利润总额增长15.91%]: 铝产品销售单价及销量同比增加，直接驱动利润总额从69.25亿元增至80.28亿元。
- **[“煤-新能源-电-铝”循环经济]** -> [成本优势与绿色溢价]: 自备煤电与风光绿电协同，降低电解铝电力成本，同时满足绿电铝政策要求，形成可持续核心竞争力。
- **[新能源装机高速扩张]** -> [发电量增长31.3%]: 2025年新能源装机达674.47万千瓦（占比69.21%），新增174.46万千瓦项目投产，推动新能源发电量（不含自备）同比大增31.3%。
- **[氧化铝等原材料成本下降]** -> [电解铝毛利率提升7.45个百分点]: 电解铝营业成本同比下降7%，主要因氧化铝价格降低，使有色金属冶炼毛利率从17.64%提升至25.09%。
- **[贷款规模和利率压降]** -> [财务费用减少30.6%]: 财务费用从2.25亿元降至1.56亿元，直接增厚净利润。
- **[煤炭产销量稳定]** -> [煤炭业务利润基本持平]: 核定产能4800万吨/年满产满销，但煤价下行压力下，通过内部提质增效弥补利润缺口，吨煤完全成本同比降低。
- **[火电角色转型为调峰电源]** -> [发电量下降4.93%]: 新能源挤压发电空间，火电利用小时数承压，但容量电价机制提供稳定保底收入，盈利模式转向“电量+辅助服务+容量补偿”。
- **[扎铝二期35万吨绿电铝项目投产]** -> [2026年电解铝产能跃升至121万吨]: 项目预计2026年6月全容量投产，叠加绿电消纳比例达80%，规模与绿色优势将显著增强铝板块盈利能力。

## 风险警告
**核心风险在于铝价与原材料价格的双重波动。** 电解铝贡献超53%营收和63%营业成本，利润高度依赖铝价与氧化铝、电力成本的剪刀差。全球宏观经济放缓、地缘冲突可能引发铝价短期剧烈波动；而氧化铝价格受铝土矿资源、环保政策影响，存在供应短缺和价格飙升风险。一旦铝价下行与成本上涨同时发生，将直接侵蚀公司最大利润来源。

**新能源业务面临电价下行与消纳瓶颈的双重挤压。** 随着内蒙古等区域新能源装机激增，弃风弃光率可能进一步上升，同时全面参与电力市场交易导致电价承压。公司新能源发电量虽高速增长，但青格洱新能源净利润已同比下滑47.47%，主要受电价降低影响。若市场化电价持续走低，新能源板块将从利润增长点转为拖累项。此外，大规模基建投资（在建工程同比增146.78%）导致自由现金流大幅流出，需警惕资本开支回报率不及预期的风险。
