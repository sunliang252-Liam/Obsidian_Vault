# 601225.SH 深度透视

## 因果逻辑链
- **[煤炭售价大幅下跌]** -> [归母净利润下降25%]: 2025年自产煤售价同比下降16.59%，贸易煤售价同比下降20.17%，直接导致营收减少259.66亿元，利润大幅承压。
- **[自产煤产量微增，贸易煤销量收缩]** -> [营收结构优化但总量下滑]: 自产煤产量增2.58%，但贸易煤销量主动缩减6.34%，公司战略聚焦高毛利自产煤，但无法对冲煤价下跌影响。
- **[“四位一体”大成本管控显效]** -> [自产煤完全成本仅微降0.46%]: 尽管税费、薪酬等成本项下降，但运输费同比大增65.91%，成本控制部分对冲了煤价下跌，但效果有限。
- **[煤电一体化战略对冲风险]** -> [电力业务利润贡献提升]: 电力售价仅降0.91%，且发电成本下降1.70%，毛利率同比提升1.67个百分点，在煤价下行周期中起到“稳定器”作用。
- **[金融资产公允价值变动与投资收益]** -> [非经常性损益增厚利润]: 出售上市公司股票及私募基金清算，贡献公允价值变动收益5.28亿元和投资收益38.97亿元，合计占利润总额13.69%，成为利润的重要补充。
- **[高分红政策持续]** -> [股东回报稳定]: 2025年拟现金分红91.89亿元，占归母净利润54.81%，上市以来累计分红超904亿元，彰显公司对股东回报的重视。
- **[资本开支大幅扩张]** -> [未来增长与短期现金流压力并存]: 2026年资本开支计划167.60亿元，主要用于电力项目建设，较2025年实际开支95.53亿元大幅增长，将考验公司现金流管理能力。

## 风险警告
**核心风险在于煤价周期性波动与成本刚性上涨的剪刀差。** 2025年归母净利润下降25%，主因是煤炭售价同比下跌超18%，而自产煤完全成本仅微降0.46%，运输费、修理费等成本项逆势上涨。若2026年宏观经济复苏不及预期，煤炭价格中枢继续下移，公司盈利将面临进一步压缩。公司2026年经营计划已明确提示此不确定性。

**第二重风险来自激进的资本开支与转型不确定性。** 2026年计划资本开支高达167.60亿元，是2025年的1.75倍，主要用于大规模火电项目建设。在“双碳”目标下，火电资产面临长期政策风险，且大规模投资将推高负债率、增加财务费用，对现金流形成巨大压力。若电力项目回报不及预期，将拖累公司整体资产回报率。
