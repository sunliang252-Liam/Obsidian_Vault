# 600985.SH 深度透视

## 因果逻辑链
- **[煤炭市场供需宽松，价格中枢下移]** -> [营收与利润暴跌]: 2025年煤炭价格“V”型震荡，均价同比大幅下跌，叠加商品煤产量下降15.42%，导致煤炭业务收入锐减61.68亿元，是公司归母净利润同比暴跌68.98%的核心原因。
- **[焦炭行业“产能扩张+需求疲软”]** -> [煤化工业务亏损]: 焦炭价格同比下跌515.20元/吨，尽管销量微增，但临涣焦化全年亏损4.48亿元，严重拖累整体业绩。
- **[严格执行“降本增收稳效20条”]** -> [成本管控对冲部分风险]: 通过压降修理、外委等七大成本，吨煤销售成本同比下降78.82元，煤炭采选业成本下降25.73%，部分缓解了煤价下跌对利润的冲击。
- **[乙醇项目产能释放]** -> [化工板块结构性亮点]: 全球最大合成气法制60万吨无水乙醇装置实现“安稳长满优”运行，全年产量54.68万吨，碳鑫科技实现盈利，成为煤化工业务中唯一的利润增长点。
- **[在建项目资本开支激增]** -> [投资活动现金流大幅流出]: 陶忽图煤矿、聚能发电等重大项目集中建设，在建工程同比增加87.04%，导致投资活动现金净流出达78.53亿元，显著高于往年。
- **[精煤战略深化]** -> [产品结构优化抵御下行]: 通过开发涡北焦煤2号、3号等5种精煤新产品，提升高价值精煤产量，精煤煤质合格率100%，在需求疲软时维持了相对较高的产品溢价。
- **[安全与环保高压投入]** -> [经营成本刚性]: 全年治灾投入13.40亿元，研发投入17.73亿元，叠加环保处罚与改造，构成公司成本端的刚性支出，压缩了利润空间。

## 风险警告
**核心风险在于业绩对煤价的极度敏感性与未来需求的不确定性。** 公司约80%的煤炭储量为炼焦煤，业绩高度依赖钢铁行业景气度。2025年归母净利润暴跌近70%，已充分暴露了单一产品周期波动的巨大杀伤力。尽管公司通过成本管控和乙醇项目对冲，但焦化业务持续亏损、在建工程资本开支巨大，若2026年钢铁需求继续疲软或煤价再度下行，公司盈利将面临进一步压缩。

**第二大风险来自激进的资本开支与现金流压力。** 陶忽图煤矿、聚能发电等重大项目总投资超百亿，导致投资活动现金流净流出78.53亿元，而经营活动现金流净额同比下降40.11%至54.28亿元。公司不得不大幅增加长期借款（同比+98.72%）来弥补资金缺口，财务费用同比上升5.26%。若新项目投产后回报不及预期，或融资环境收紧，公司将面临较高的债务风险和流动性压力。
