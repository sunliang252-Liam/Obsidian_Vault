# 600121.SH 深度透视

## 因果逻辑链
- **[煤炭价格持续下行]** -> [营收与利润双杀]: 2025年煤炭市场均价低于去年，公司煤炭业务收入同比减少14.19%，毛利率骤降13.03个百分点，直接导致主营业务利润减少5.2亿元。
- **[超化煤矿停产计提减值]** -> [资产减值损失暴增]: 超化煤矿停产，公司计提固定资产减值准备3.15亿元，资产减值损失同比激增800.63%，成为亏损最大单项因素。
- **[联营企业复晟铝业盈利下滑]** -> [投资收益断崖式下跌]: 氧化铝价格大幅下滑，复晟铝业贡献的投资收益同比减少1.57亿元，叠加上年非经常性处置收益消失，投资收益同比减少86.70%。
- **[非经常性收益消失]** -> [利润表失去支撑]: 2024年上海郑煤破产处置收益2.51亿元及郑新铁路股权重估利得0.64亿元，2025年此类收益归零，扣非净利润亏损9.08亿元。
- **[成本刚性难降]** -> [毛利率承压]: 公司开采煤层属“三软不稳定煤层”，地质复杂，材料费、塌陷补偿费等成本同比大幅上升，煤炭成本仅微降0.90%，远不及收入降幅。
- **[关联交易高度依赖]** -> [经营独立性风险]: 前五大客户销售额占年度总额67.32%，其中向控股股东郑煤集团及其关联方销售占比高达45.72%，经营受关联方影响极大。

## 风险警告
公司2025年巨亏9.27亿元，净资产收益率-65.86%，未分配利润赤字高达-12.85亿元，已连续三年无法分红。核心风险在于：煤炭价格中枢下移已成趋势，而公司“三软煤层”开采成本刚性，导致毛利率在价格下行周期中加速恶化。超化煤矿停产计提大额减值，暴露出矿井老化与资源枯竭的深层危机，未来可能还有更多矿井面临类似命运。

此外，公司对控股股东郑煤集团的关联交易依赖度极高（销售占比45.72%），且控股股东所持股份超半数已被质押，实际控制人虽变更为郑州市国资委，但历史遗留的同业竞争承诺（注入优质资产）迟迟未能兑现，公司治理与资产独立性存在长期隐患。在新能源替代加速、煤价承压的背景下，公司主业造血能力羸弱，偿债压力巨大（受限资金高达21.64亿元），财务弹性极低。
