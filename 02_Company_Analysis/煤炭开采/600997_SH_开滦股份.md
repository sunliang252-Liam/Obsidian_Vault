# 600997.SH 深度透视

## 因果逻辑链
- **[煤焦价格大幅下跌]** -> [公司2025年由盈转亏]: 煤炭和焦化产品售价同比显著下降，导致营业收入减少17.87%，利润总额从盈利7.59亿元转为亏损0.39亿元。
- **[下游钢铁行业需求疲软]** -> [洗精煤量价齐跌]: 钢铁行业粗钢产量同比下降4.4%，拖累炼焦煤需求，公司洗精煤销量同比下降11.62%，收入同比下降34.92%。
- **[焦化行业产能过剩与利润承压]** -> [焦炭毛利率极低]: 尽管焦炭销量增长6.34%，但价格下跌导致冶金焦毛利率仅0.48%，行业进入存量竞争阶段，盈利能力严重下滑。
- **[煤化工子公司大面积亏损]** -> [拖累合并报表业绩]: 唐山中浩（亏损1.24亿）、林西矿业（亏损2.08亿）、承德中滦（亏损0.32亿）等主要子公司亏损，抵消了母公司盈利。
- **[经营活动现金流大幅转负]** -> [现金流压力骤增]: 销售商品收到的现金减少，导致经营活动现金流净额从净流入11.69亿元转为净流出6.77亿元，降幅达157.97%。
- **[研发投入逆势增长]** -> [长期竞争力培育]: 在亏损情况下，研发费用仍增长6.82%至5.06亿元，强度达2.91%，旨在推动煤化工高端化、绿色化转型。
- **[关联交易高度集中]** -> [经营独立性风险]: 前五大客户销售额占比57.55%，前五大供应商采购额占比58.01%，且与控股股东开滦集团存在大量关联采购（14.71%），经营受关联方影响较大。

## 风险警告
公司面临的核心风险是**煤焦价格持续低迷与下游钢铁行业需求萎缩的双重挤压**。2025年公司已由盈转亏，若宏观经济复苏不及预期，钢铁行业减产加剧，公司煤炭和焦炭产品的量价将继续承压，亏损可能进一步扩大。此外，公司经营活动现金流已大幅转负，若无法有效改善，将影响其偿债能力和日常运营。

另一个重大风险是**煤化工业务的结构性亏损**。公司多个核心子公司（如唐山中浩、林西矿业）持续大额亏损，尤其是己二酸、聚甲醛等精细化工产品面临激烈的市场竞争和价格下行压力。尽管公司试图通过产业链一体化降本，但短期内难以扭转颓势，这些“失血点”将持续侵蚀母公司利润。同时，公司对关联方（首钢、河钢、开滦集团）的销售和采购依赖度极高，议价能力和经营自主性受限。
