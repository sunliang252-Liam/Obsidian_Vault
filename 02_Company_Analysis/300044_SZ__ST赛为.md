# 300044.SZ 深度透视

## 因果逻辑链
- **[重大诉讼败诉与仲裁裁决]** -> [净利润巨亏12.64亿元]: 艾特网能诉讼及仲裁案终审败诉，公司确认应付本金8.03亿元及利息费用4.22亿元，同时对应收债权全额计提减值，导致信用减值损失高达9.32亿元。
- **[应收账款账龄恶化与回款困难]** -> [信用减值损失9.32亿元]: 3年以上应收账款余额达16.43亿元，多个数据中心项目虽胜诉但执行困难，公司基于预期信用损失模型大幅计提坏账准备。
- **[持续亏损与资不抵债]** -> [净资产为-11.35亿元，触发*ST]: 2019-2025年连续亏损，2025年末归属于母公司股东权益由正转负，触及退市风险警示红线。
- **[债权人申请预重整]** -> [公司进入司法重整程序]: 因不能清偿到期债务，债权人向法院申请重整，法院已启动预重整程序，公司已签署《预重整投资协议》。
- **[智慧城市业务收缩]** -> [营收下降8.42%至1.31亿元]: 公司主动收缩低毛利、高垫资项目，聚焦存量交付与回款，智慧城市领域收入同比下降11.75%。
- **[财务费用激增]** -> [财务费用同比大增1221%至2.62亿元]: 主要因诉讼败诉计提的逾期付款违约金及利息费用，而非正常经营融资成本。
- **[游戏业务稳定现金贡献]** -> [游戏收入占比约39%]: 北京开心人旗下《一统天下》、《三国群英传手游》等存量游戏运营稳定，成为公司为数不多的稳定现金流来源。

## 风险警告
公司已陷入严重的财务危机与退市风险。2025年末净资产为-11.35亿元，触发*ST；连续三年扣非净利润为负，且审计报告被出具“带持续经营重大不确定性段落”的意见。核心风险在于：公司已不能清偿到期债务，法院已启动预重整程序，若重整失败被裁定破产，股票将面临终止上市。投资者面临本金归零的极端风险。

资产质量极度恶化。应收账款余额18.70亿元，坏账准备高达16.38亿元，实际可回收性极低。重大诉讼败诉导致公司需承担超过12亿元的债务及违约金，而对应追偿的债权因对方经营困难、资产被冻结，已全额计提减值，形成“净损失”。公司主营的智慧城市业务萎缩，人工智能产品收入占比仅1.3%，短期内难以扭转颓势。
