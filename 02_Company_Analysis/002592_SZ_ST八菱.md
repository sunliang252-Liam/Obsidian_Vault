# 002592.SZ 深度透视

## 因果逻辑链
- **[下游汽车行业景气度上行]** -> [热交换器收入增长17.43%]: 国内汽车产销量创新高，新能源汽车渗透率突破50%，直接拉动公司核心产品需求。
- **[参股公司重庆八菱业绩高增]** -> [投资收益达5,482万元]: 重庆八菱受益于下游需求旺盛，净利润同比增长13.18%，公司按49%持股比例确认大额投资收益。
- **[股份支付费用大幅下降]** -> [扣非净利润增长87.56%]: 2025年股份支付费用较上年减少约1,914万元，显著释放利润空间。
- **[新能源产品放量]** -> [新能源业务收入占比升至46.24%]: 电池冷却器、液冷板等新产品批量供货，成为业绩增长核心驱动力。
- **[客户高度集中]** -> [前五大客户销售占比88.56%]: 深度绑定上汽通用五菱（47.92%）和奇瑞（31.32%），订单稳定性强但依赖风险极高。
- **[历史违规担保诉讼推进]** -> [股票ST状态暂难撤销]: 海南弘天诉广州银行1.46亿元案终审胜诉但款项未收回，另一1.5亿元案仍在审理，违规担保问题未彻底解决。
- **[安徽芜湖新基地建设]** -> [在建工程大幅增加至5,170万元]: 为就近配套新能源客户，产能扩张投入加大，短期增加资本开支压力。

## 风险警告
**核心风险在于客户集中度极高与历史违规担保的“双杀”效应。** 前两大客户贡献近80%营收，任何一家车企的降价、减产或更换供应商，都将直接导致公司业绩剧烈波动。同时，因原子公司海南弘天4.66亿元违规担保引发的诉讼虽部分胜诉，但回款存在重大不确定性，导致公司股票持续被ST，严重制约融资能力和市场形象。

**第二重风险来自行业竞争加剧与原材料价格波动。** 汽车零部件行业“增收不增利”现象普遍，整车厂持续压价，而铝材等主要原材料价格易涨难跌，公司成本传导能力弱，毛利率面临双重挤压。此外，历史并购标的北京弘天的业绩补偿承诺（王安祥需补偿约6.5亿元）至今未兑现，构成潜在的巨额资产减值风险。
