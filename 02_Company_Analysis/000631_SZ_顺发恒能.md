# 000631.SZ 深度透视

## 因果逻辑链
- **[收购顺发德能（天然气发电）]** -> [营收结构转型]: 收购完成后，天然气发电及供热收入占比达48.88%，成为第一大收入来源，公司从地产公司转型为清洁能源运营商。
- **[房地产销售大幅下降69.77%]** -> [营收整体下滑13.71%]: 存量地产项目交付减少，拖累整体营收，但清洁能源业务基本盘稳定，对冲了部分下滑。
- **[新能源全面入市（136号文）]** -> [电价波动风险加剧]: 政策推动新能源上网电价市场化，现货市场低电价时段可能冲击公司风电、光伏项目的盈利能力。
- **[员工持股计划与股份回购]** -> [股东与员工利益绑定]: 2024/2025年两期员工持股计划及3.82亿元股份回购，将管理层、核心员工与股东利益深度绑定，稳定市场预期。
- **[货币资金占比66.10%]** -> [财务稳健但效率待提升]: 超66%的资产为货币资金，流动性充裕，但大量资金存放于关联方财务公司，资金使用效率和潜在关联交易风险值得关注。
- **[综合能源服务收入暴增1240%]** -> [新增长极初现]: 储能、虚拟电厂等综合能源服务业务从零到一，收入增长超12倍，成为未来重要增长点。
- **[实际控制人承诺解决天然气发电同业竞争]** -> [资产注入预期]: 收购顺发德能后，实控人承诺3年内解决剩余天然气发电业务同业竞争问题，未来存在资产注入预期。

## 风险警告
**核心风险在于新能源全面入市带来的电价不确定性。** 公司风电、光伏业务将直面电力现货市场价格波动，在新能源集中出力时段可能面临极低电价，直接侵蚀项目收益。同时，公司超95%的货币资金存放于关联方万向财务公司，虽短期无虞，但资金集中度高，一旦关联方出现信用风险，将对公司流动性造成重大冲击。

**转型阵痛与增长瓶颈并存。** 公司正处于从地产向清洁能源的转型期，房地产收入断崖式下滑，而清洁能源装机规模尚小（2026年目标仅200MW），短期内难以完全弥补地产缺口。此外，公司核心天然气发电业务依赖单一供应商（前五大供应商采购额占63%），且面临气价波动风险，成本控制能力有待市场检验。
