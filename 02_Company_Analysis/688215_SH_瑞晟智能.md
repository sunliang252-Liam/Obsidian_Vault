# 688215.SH 深度透视

## 因果逻辑链
- **[“智算人”三位一体战略落地]** -> [营收与利润双增]: 公司在巩固智能工厂装备主业的同时，新增算力产品及服务业务（贡献营收1792万元），并布局机器人业务，形成第二增长曲线，驱动整体营收增长11.77%，归母净利润大增119.78%。
- **[海外市场高增长]** -> [整体毛利率提升]: 国外营收同比增长56.06%，且海外业务毛利率高达44.50%，显著高于国内，其占比提升拉动了公司综合毛利率从27.53%提升至32.40%。
- **[下游缝制行业智能化需求释放]** -> [核心产品悬挂生产系统增长]: 服装、家纺行业“小单快反”模式转型驱动自动化改造需求，公司核心产品悬挂生产系统营收同比增长22.05%，是业绩增长的基本盘。
- **[长期股权投资贡献收益]** -> [利润总额大幅增长]: 报告期内权益法核算的长期股权投资贡献投资收益466.94万元，占利润总额的12.12%，成为利润增长的重要补充。
- **[项目备货与业务扩张]** -> [经营性现金流为负]: 营收增长导致项目备货采购支出增加，叠加应收账款规模扩大（同比增长42.30%），经营活动现金流净额为-3367万元，现金循环周期拉长。
- **[新增银行贷款]** -> [筹资活动现金流激增]: 为支撑业务扩张和备货需求，公司新增银行贷款，筹资活动现金流净额达1.38亿元，同比增长315.44%，资产负债率有所上升。
- **[算力业务高毛利]** -> [利润结构优化]: 新增的算力产品及服务毛利率高达99.46%，显著拉高了公司整体盈利水平，但该业务尚处初期，规模较小（占营收4.1%）。

## 风险警告
**核心风险在于现金流恶化与应收账款高企。** 公司营收增长的同时，经营性现金流持续为负（-3367万元），应收账款激增至3.52亿元，占总资产33%，且坏账准备计提增加。这表明公司增长高度依赖垫资和赊销，若下游客户（多为服装代工厂）出现经营压力，坏账风险将直接侵蚀利润，甚至引发流动性危机。

**第二增长曲线尚处萌芽，不确定性高。** 算力业务虽毛利极高，但营收仅1792万元，且依赖国产芯片供应链稳定性，面临英伟达等巨头的生态壁垒。机器人业务同样处于小批量出货和测试阶段，尚未形成规模效应。这两项业务目前对业绩贡献有限，若市场开拓不及预期，前期投入将无法收回，公司仍高度依赖传统缝制装备主业，存在业务单一风险。
