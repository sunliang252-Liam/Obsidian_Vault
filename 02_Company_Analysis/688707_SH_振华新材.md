# 688707.SH 深度透视

## 因果逻辑链
- **[磷酸铁锂挤压三元市场]** -> [营收连续下滑]: 2025年磷酸铁锂装机占比升至81.2%，三元材料整体需求受限，公司传统5系产品份额萎缩，导致营收同比-27.16%。
- **[6系新产品导入滞后]** -> [产能利用率低位]: 新一代6系高电压材料虽完成认证但未形成大规模订单，未能弥补传统产品缺口，产能利用率持续处于低位，单位固定成本高企。
- **[原材料价格剧烈波动]** -> [毛利率持续为负]: 碳酸锂价格波动超100%，公司“成本加成”定价存在传导时滞，叠加高价库存消化，2025年毛利率为-14.29%。
- **[客户高度集中]** -> [经营依赖单一客户]: 前五大客户销售占比84.16%，其中单一客户占比67.02%，客户结构高度集中，议价能力受限且经营风险集中。
- **[研发投入逆势增长]** -> [维持技术竞争力]: 在连续亏损下仍加大研发投入（+4.56%至9424.63万元），聚焦固态电解质、钠电正极等前沿领域，以技术储备对冲行业下行。
- **[参股红星电子]** -> [构建回收闭环]: 通过参股废旧电池回收企业，实现钴、镍、锰、锂高回收率，旨在降低原材料综合采购成本，增强供应链韧性。
- **[暂缓义龙三期]** -> [审慎控制资本开支]: 面对产能过剩，公司暂停义龙三期项目，以“技改”替代“新建”实现高效扩产，避免新增产能闲置风险。

## 风险警告
**核心风险在于“结构性替代”与“新产品放量”的时间赛跑。** 磷酸铁锂对三元材料的替代趋势不可逆，公司传统5系产品市场被持续挤压，而寄予厚望的6系高电压材料在主要客户处导入节奏严重滞后，导致产能利用率长期低于45%。若6系产品无法在2026年实现大规模订单突破，公司将继续承受高昂的单位固定成本和资产减值压力，亏损局面难以扭转。

**财务风险高度集中于“高价库存”与“固定资产减值”的双重绞杀。** 公司存货账面价值7.08亿元，占资产10.78%，在原材料价格剧烈波动下，存货跌价风险如影随形。更严峻的是，固定资产账面价值24.89亿元（占总资产37.9%），低产能利用率已导致计提减值准备2293万元。若下游需求持续疲软，大规模固定资产减值将直接冲击净资产，形成“亏损-减值-净资产缩水”的恶性循环。
