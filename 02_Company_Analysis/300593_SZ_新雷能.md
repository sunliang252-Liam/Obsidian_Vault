# 300593.SZ 深度透视

## 因果逻辑链
- **[航空航天行业需求回暖]** -> [营收增长28.91%]: 航空航天客户订单增加，驱动公司整体收入规模回升至11.88亿元。
- **[高额研发与费用投入]** -> [持续亏损]: 研发费用率高达34.35%，叠加股权激励、利息支出增加，导致归母净利润仍为-1.95亿元。
- **[资产减值损失大幅收窄]** -> [减亏60.97%]: 2025年计提资产减值5300万元，较上年减少2.29亿元，是亏损大幅收窄的核心原因。
- **[数据中心业务突破]** -> [新增长极初现]: 二次电源通过ADI渠道进入国际市场，三次电源（POWER BLOCK/VPD）技术对标国际先进，打开AI算力供电市场。
- **[客户高度集中]** -> [经营依赖风险]: 前五名客户销售额占比52.76%，公司增长高度受制于少数关键客户的资本开支与需求波动。
- **[存货高企与定制化]** -> [潜在跌价风险]: 存货账面价值8.39亿元，占总资产19.77%，产品定制化程度高，技术迭代或客户订单调整易引发减值。
- **[产能扩张与转固]** -> [折旧压力增加]: 深圳、西安等新基地投产，固定资产较期初增加84.97%，未来折旧费用将侵蚀利润。

## 风险警告
公司当前最核心的风险在于**“增收不增利”的困境**。尽管营收增长近29%，但高达34.35%的研发费用率及持续的管理、财务费用扩张，使得公司仍深陷亏损泥潭。这种高投入模式若不能在未来转化为规模效应和利润释放，将严重考验公司的现金流和股东耐心。经营活动现金流净额为负（-6521万元），进一步印证了盈利质量堪忧。

其次，**客户集中度极高与存货高企**构成双重隐患。前五大客户贡献超半数营收，任何大客户订单波动都将剧烈冲击业绩。同时，近20%的资产沉淀为存货，且多为定制化产品，一旦下游需求转向或技术路线变更，将面临巨大的减值风险。公司虽在数据中心等新领域取得突破，但新业务尚处市场导入期，短期内难以对冲传统业务的结构性风险。
