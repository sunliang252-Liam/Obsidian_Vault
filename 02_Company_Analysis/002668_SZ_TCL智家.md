# 002668.SZ 深度透视

## 因果逻辑链
- **[自有品牌海外业务爆发]** -> [净利润连续4年两位数增长]: 依托TCL成为奥运合作伙伴契机，自有品牌海外收入同比暴增115%，驱动整体利润再创新高。
- **[全球化产能布局]** -> [对冲关税风险]: 泰国制造基地投产（冷柜分厂）及动工（冰箱工厂），将部分产能转移至东南亚，有效规避欧美高关税壁垒。
- **[高端化产品结构升级]** -> [毛利率提升]: 奥马280万台高端风冷冰箱项目投产，TCL双磁鲜、超级筒等旗舰新品放量，推动冰箱/洗衣机毛利率分别同比提升2.20%和3.30%。
- **[ODM龙头规模效应]** -> [成本优势]: 奥马冰箱连续17年出口第一，年出货超1400万台，通过集中采购与柔性生产，在原材料价格波动中保持成本领先。
- **[研发投入持续加码]** -> [技术壁垒]: 研发费用同比增长5.86%，分子磁鲜、微环境多效调控等国际领先技术获权威认证，构筑产品差异化护城河。
- **[TCL品牌赋能]** -> [渠道与营销协同]: 借助TCL实业全球销售网络与体育营销（谷爱凌代言），快速突破海外线下渠道，实现品牌溢价。
- **[经营现金流强劲]** -> [盈利质量扎实]: 经营活动现金净流量超25亿元，同比增长13.28%，显著高于净利润增速，体现健康的回款与运营效率。

## 风险警告
**核心风险在于地缘政治与关税的不确定性。** 公司海外收入占比高达77.73%，且北美市场受关税影响已出现20.6%的下滑。尽管泰国基地已投产，但产能爬坡与完全替代尚需时日，若欧美贸易政策进一步恶化，将对出口业务造成直接冲击。此外，原材料（压缩机、钢材）价格波动与汇率（美元/欧元）波动是长期侵蚀利润的隐患。

**次要风险来自激烈的市场竞争与内部治理摩擦。** 家电行业总量趋稳，内销市场微降0.1%，公司需在技术、资金、人才上与海尔、美的等巨头全方位竞争。同时，公司与控股子公司奥马冰箱存在章程条款争议并已诉诸法律，虽一审驳回，但暴露出内部治理协调的潜在风险，可能影响运营效率与战略执行。
