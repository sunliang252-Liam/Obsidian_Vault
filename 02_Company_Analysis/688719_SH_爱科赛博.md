# 688719.SH 深度透视

## 因果逻辑链
- **[研发投入激增]** -> [净利润由盈转亏]: 2025年研发投入同比增长24.45%至1.77亿元，占营收比例高达19.56%，远超营收降幅，直接侵蚀利润，导致归母净利润从盈利6802万转为亏损4494万。
- **[存量市场竞争加剧]** -> [综合毛利率下降]: 新能源测试、特种电源等核心业务毛利率均下滑，尤其是高端装备领域毛利率骤降14.55个百分点，反映出价格战与成本上升的双重挤压。
- **[订单确认节奏错位]** -> [营收与订单增长背离]: 2025年订单规模虽同比增长，但合同集中于下半年后期签订，导致当期营收同比减少3.48%，未能转化为当期业绩。
- **[人员扩张与薪酬提升]** -> [经营现金流大幅恶化]: 经营活动现金流净额同比减少67.14%至2299万元，主因是人员扩充、薪酬提升带来的付现支出增加，而销售回款却因市场环境而减少。
- **[新业务布局与产品迭代]** -> [研发费用持续高企]: 公司为拓展半导体射频电源、AIDC测试电源等新业务，持续加大研发投入，研发人员增至479人，薪酬同比增长19.2%，导致费用刚性增长。
- **[精密测试电源产销量增长]** -> [存货大幅攀升]: 精密测试电源生产量同比增长50.33%，库存量同比增长61.34%，显示公司为应对订单增长而主动备货，但也占用了大量营运资金。
- **[特种电源定制化属性强]** -> [毛利率大幅波动]: 特种电源业务因涉及国家重大科学工程，定制化程度高，技术攻关投入大，导致毛利率同比下滑14.62个百分点，业绩稳定性差。

## 风险警告
公司当前最核心的风险是**“增收不增利”的恶性循环**。在营收微降3.48%的情况下，研发费用激增24.45%，销售费用增长28.82%，导致期间费用率大幅攀升，直接吞噬了利润。这种高投入并未带来同比例的营收增长，反而因市场竞争加剧导致毛利率下滑，最终使公司陷入亏损。若未来研发投入无法有效转化为具有定价权的产品，或市场开拓效果不及预期，公司盈利能力将持续承压。

其次，**经营现金流恶化与应收账款高企**构成双重财务风险。经营活动现金流净额同比锐减67.14%，而应收账款余额高达5.66亿元，且3年以上账龄的应收账款仍在增加。公司为拓展市场放宽了信用期，导致回款周期拉长，营运资金周转面临巨大压力。若下游客户（尤其是新能源领域）出现资金紧张或回款延迟，公司将面临现金流断裂的风险，并可能引发大额坏账。

最后，**新业务拓展存在高度不确定性**。公司正大力布局半导体射频电源、AIDC测试电源等新领域，这些领域技术门槛高、客户验证周期长，且面临国际巨头的竞争。公司目前在这些领域尚处于“小批量生产”或“验证阶段”，短期内难以贡献利润。若技术研发失败或市场开拓受阻，前期巨大的研发投入将无法收回，对公司业绩造成重大打击。
