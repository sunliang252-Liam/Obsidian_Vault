# 001367.SZ 深度透视

## 因果逻辑链
- **[原料药业务量价齐升]** -> [营收与净利润双创新高]: 原料药销售额同比增长14.87%，销售量同比大增31.26%，是业绩增长的核心引擎。
- **[境外市场高增长]** -> [营收结构优化]: 境外销售额同比增长22.46%，占比提升至54.53%，有效对冲了国内市场的增速放缓。
- **[成本控制与供应链优化]** -> [毛利率显著提升]: 在营收增长12.88%的同时，营业成本仅增长4.92%，直接材料成本同比下降，推动综合毛利率提升4.13个百分点。
- **[股权激励计划]** -> [激发组织活力与业绩达成]: 2024年限制性股票激励计划首期业绩目标顺利达成，扣除股份支付影响后净利润同比增长22.14%，远超账面净利润增速。
- **[研发投入高增与人才引进]** -> [构筑长期产品管线]: 研发费用同比增长39.89%，研发人员数量增长31.58%，为未来3-5年的新增长点（如抗病毒、非甾体抗炎类）储备动能。
- **[新厂区建设与产能扩张]** -> [突破产能瓶颈]: 新区建设项目（一期）启动，旨在解决主导产品供不应求的局面，为中长期增长提供物理基础。
- **[数智化转型]** -> [提升运营效率与质量管控]: LIMS、U9等系统上线，实现数据互通与流程自动化，支撑了存货周转率提升29%及质量管理水平的精细化。

## 风险警告
**产品集中度与安乃近政策风险。** 公司业绩高度依赖硫糖铝、安乃近、阿托伐他汀钙和PHBA四大产品。其中，安乃近原料药业务面临境内外持续的政策限用风险，若相关限制政策进一步升级，将对公司营收和利润造成重大冲击。公司虽在优化产品结构，但短期内核心产品依赖度难以根本改变。

**募投项目与产能消化风险。** 公司正进行大规模资本开支，新厂区建设项目（一期）总投资高达5亿元。项目从建设到投产周期较长，期间可能面临产业政策、市场需求变化等不确定性。若新产能建成后，市场开拓不及预期或产品价格竞争加剧，将导致产能利用率不足，折旧摊销压力增大，侵蚀公司盈利能力。
