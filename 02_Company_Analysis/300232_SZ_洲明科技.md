# 300232.SZ 深度透视

## 因果逻辑链
- **[海外收入占比高（58%）+ 海外毛利率下滑4.1个百分点]** -> [归母净利润同比下滑36.77%]: 海外业务作为营收主力，其毛利率下降直接侵蚀利润，叠加国内业务毛利率亦承压，导致增收不增利。
- **[Mini/Micro LED营收同比增长49.1%，出货面积增长57%]** -> [营收结构高端化]: 高附加值产品放量，推动公司从低毛利硬件销售向技术壁垒更高的高端显示转型，是未来盈利改善的核心驱动力。
- **[AI及光显解决方案营收同比增长20%]** -> [商业模式从“卖硬件”向“硬件+AI订阅服务”升级]: Z.Brain智脑等AI产品落地，开辟了持续价值模式，提升客户粘性与场景复用能力，但当前体量尚小（2.88亿）。
- **[应收账款周转天数缩短至87天，存货周转天数缩短至106天]** -> [资产运营效率提升]: “双降”表明公司内部提质增效措施见效，现金流质量改善，但经营活动现金流净额仍同比下滑43.8%。
- **[COB与MIP双技术路线并行，实现P0.3间距MIP产品验证]** -> [巩固Micro LED技术领先地位]: 成为全球少数实现MIP产品线全覆盖的企业，为未来在超高清、微间距显示领域竞争奠定技术基础。
- **[设立智显机器人公司，联合智谱、元客视界]** -> [构建“算法+硬件+感知”AI生态]: 将AI具身智能提升至头号战略，旨在将显示屏从被动显示升级为主动交互的智能终端，抢占AI+显示赛道先机。
- **[海外收入同比下滑1.59%，国内收入同比增长14.62%]** -> [区域增长动能切换]: 国内业务成为营收增长核心驱动力，弥补了海外市场的阶段性疲软，但海外市场仍是营收基本盘（58%）。

## 风险警告
**核心风险在于盈利能力的持续恶化与转型阵痛。** 公司营收微增4.11%，但归母净利润却大幅下滑36.77%，扣非净利润更是暴跌85.47%。这并非一次性冲击，而是海外业务毛利率下滑（-4.1%）、大额资产减值（-1.47亿）与信用减值（-0.89亿）共同作用的结果。公司正从硬件制造商向“光显+AI”方案商转型，但新业务（AI、解决方案）体量尚小（2.88亿），短期内难以对冲传统业务利润下滑的压力，转型的“青黄不接”期是最大不确定性。

**第二重风险来自海外宏观环境与内部经营的双重挤压。** 公司58%收入来自海外，面临地缘政治、汇率波动及贸易政策（如美国关税）的显著影响。同时，公司经营活动现金流净额同比大降43.8%，表明即便应收账款和存货周转改善，但采购付款增加导致现金创造能力减弱。此外，公司分红规模大幅缩减（从每10股派2.4元降至0.2元），也侧面印证了管理层对当前盈利和现金流压力的审慎判断。
