# 603062.SH 深度透视

## 因果逻辑链
- **[新能源涂料收入大幅增长66.41%]** -> [公司净利润与上年基本持平]: 新能源板块收入占比从18.37%提升至38.21%，高毛利产品占比提升，有效对冲了集装箱涂料收入大幅下滑39.17%带来的利润冲击。
- **[集装箱行业需求2025年大幅回落]** -> [公司总营收同比下降19.99%]: 2024年红海危机催生的集装箱需求脉冲在2025年消退，公司核心收入来源集装箱涂料销量大幅减少。
- **[产品结构优化，高毛利新能源涂料占比提升]** -> [主营业务毛利率提升至23.82%]: 新能源涂料毛利率36.34%，显著高于海洋装备涂料的16.09%，其收入占比提升拉动了整体毛利率。
- **[经营活动现金流净额同比大增304.24%]** -> [现金流健康，净利润现金含量达105.92%]: 2024年高收入带来的应收账款在2025年大量收回，同时2025年下半年收入下降，应收账款规模减少。
- **[风电行业2025年新增装机量同比增49.50%]** -> [公司风电涂料收入创历史新高]: 作为国内风电叶片涂料龙头，公司充分受益于行业高景气度，并成功拓展海外市场实现批量销售。
- **[新业务（船舶、光伏、电力设备涂料）处于起步阶段]** -> [销售费用同比大增34.48%]: 为开拓新业务领域，公司加大市场推广和差旅投入，但新业务收入贡献尚小，短期侵蚀利润。
- **[珠海募投项目建成投产]** -> [固定资产同比大增211.19%]: 新增产能布局大湾区，但产能利用率仅8.43%，短期内折旧摊销增加，对资产回报率形成压力。

## 风险警告
公司面临的核心风险在于**业务结构转型期的双重压力**。一方面，传统支柱业务集装箱涂料受全球贸易和地缘政治影响，需求波动剧烈（2024年创新高后2025年大幅回落），公司虽采取理性竞争策略，但收入下滑不可避免。另一方面，新能源涂料虽增长迅猛，但高增长背后是行业竞争加剧和毛利率微降（-1.18个百分点），且新业务（船舶、光伏、电力设备）尚处客户导入期，投入大、产出小，短期内难以接力成为新的利润支柱。

此外，**原材料价格波动与客户集中度风险**不容忽视。直接材料成本占比超88%，树脂等原料与油价挂钩，2026年地缘局势可能带来成本压力，而公司对下游大客户的议价能力在行业下行期可能减弱。同时，前五大客户销售额占比高达65.74%，下游风电叶片和集装箱制造行业高度集中，若主要客户经营或采购策略生变，将对公司业绩产生重大冲击。
