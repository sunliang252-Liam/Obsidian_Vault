# 603335.SH 深度透视

## 因果逻辑链
- **[非经常性损益驱动扭亏]** -> 净利润4,848万元：通过出售子公司股权（广东威玛、绿色食品）和土地收储，合计贡献约1.8亿元非经常性收益，掩盖了扣非净利润-1.29亿元的持续亏损。
- **[主营业务海外需求萎缩]** -> 扣非净利润亏损1.29亿元：核心产品轮毂及轮胎主要销往北美，受贸易壁垒、原材料涨价及海外需求疲软影响，订单不足导致产能利用率低，生产成本上升。
- **[锂电池回收业务拖累]** -> 新材料板块毛利率-3.61%：子公司广东威玛因市场波动大、产能利用率不足，采取代工模式仍无法覆盖成本，导致该业务亏损，最终被出售控股权。
- **[资产剥离改善现金流]** -> 经营现金流净额6,023万元：通过出售子公司及土地收储回笼资金，同时加强库存管理减少采购支出，经营性现金流转正，但核心业务造血能力仍弱。
- **[海外渠道优势未转化为盈利]** -> 营收下降5.79%：尽管拥有北美成熟销售网络和品牌，但宏观环境恶化导致销量下滑，渠道优势未能抵御系统性风险，收入规模收缩。
- **[研发投入大幅削减]** -> 研发费用下降32.05%：为控制成本，公司大幅缩减研发支出，可能影响长期产品竞争力，尤其在行业向轻量化、智能化转型的背景下。
- **[高负债与担保风险]** -> 担保总额占净资产81.98%：公司为子公司及联营公司提供高额担保，且自身资产负债率高达63%，财务杠杆高企，流动性压力显著。

## 风险警告
**核心风险在于主营业务持续失血与资产出售的不可持续性。** 公司2025年净利润扭亏完全依赖出售子公司股权和土地收储等一次性收益，扣非净利润已连续三年深度亏损（-1.29亿、-1.67亿、-1.49亿）。核心汽车零部件业务受制于海外贸易摩擦和需求萎缩，产能利用率不足，毛利率仅17.26%，无法覆盖高昂的销售与管理费用。锂电池回收业务（广东威玛）已剥离控股权，但新材料板块仍处于亏损状态，新项目（古井项目）尚在建设期，短期无法贡献利润。

**财务结构脆弱，流动性风险高企。** 公司资产负债率63%，短期借款2.86亿元，而货币资金仅5,692万元，短期偿债压力巨大。同时，公司为子公司及联营公司提供的担保余额高达2.5亿元，占净资产81.98%，一旦被担保方出现违约，将直接冲击公司现金流。母公司层面存在累计未弥补亏损4,193万元，已不具备现金分红条件。公司未来盈利高度依赖剩余旧厂区土地收储的推进，若该计划延迟或失败，公司将面临严重的资金链断裂风险。
