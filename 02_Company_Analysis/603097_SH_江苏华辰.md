# 603097.SH 深度透视

## 因果逻辑链
- **[新能源箱变放量]** -> [营收增长42.73%]: 公司主动切入风、光、储赛道，箱式变电站收入同比暴增125.32%，成为营收核心引擎。
- **[行业竞争加剧与铜价上涨]** -> [毛利率下滑4.99个百分点]: 新能源领域价格战白热化，叠加主要原材料铜材价格同比上涨，双重挤压导致增收不增利。
- **[营收扩张与回款周期]** -> [经营现金流骤降69.40%]: 收入快速增长带来应收账款及票据大幅增加，占用大量营运资金，现金流与利润严重背离。
- **[可转债成功发行]** -> [资本结构优化与产能扩张]: 募资4.6亿元投入新能源电力装备基地与数字化工厂，缓解资金压力，为未来产能释放奠定基础。
- **[股权激励绑定核心团队]** -> [人才稳定性增强]: 向142名骨干授予515万股限制性股票，将员工利益与公司长期发展深度绑定，激发组织活力。
- **[研发聚焦高端与新能源]** -> [产品矩阵升级]: 研发投入增长45.01%，重点突破海上风电、大容量储能一体机等，为未来竞争储备技术弹药。
- **[海外市场布局]** -> [第二增长曲线初现]: 境外营收增长130.32%，通过与欧洲、美国等地合作推进本地化产能，海外业务成为新增长点。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收暴增42.73%，但净利润却下滑23.16%，毛利率骤降5个百分点。这并非短期波动，而是新能源行业竞争白热化、产品同质化导致的价格战，叠加铜材等关键原材料成本上涨的长期趋势。若公司无法通过技术溢价或成本管控扭转这一局面，规模扩张将反噬利润，陷入“越卖越亏”的陷阱。

**财务健康度亮起红灯。** 应收账款占资产总额高达36.67%，且经营现金流净额仅为净利润的40%，表明公司大量利润沉淀在账面上，回款能力堪忧。同时，资产负债率从56.45%飙升至65.06%，主要因可转债和产能扩张带来的债务增加。在利率上行和现金流紧张的背景下，高杠杆与高应收的双重压力，将严重削弱公司的抗风险能力和再投资弹性。
