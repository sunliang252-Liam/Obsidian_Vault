# 688621.SH 深度透视

## 因果逻辑链
- **[新业务模式（授权合作+创新药）]** -> [收入结构质变]: 创新药、改良型新药研发服务与知识产权授权收入合计3.48亿元，占主营收入28.5%，打破传统CRO增长天花板。
- **[自研创新药管线对外授权]** -> [高毛利收入爆发]: STC007、STC008完成对外授权，知识产权授权收入1亿元，毛利率100%，直接拉升整体毛利率至54.06%。
- **[新签订单20.20亿元]** -> [未来收入蓄水池]: 新签订单同比增长13.10%，为后续2-3年收入增长提供确定性支撑。
- **[降本增效措施]** -> [利润增速超收入增速]: 归母净利润增速14.91%高于收入增速13.33%，研发费用同比下降6.04%，成本管控见效。
- **[仿制药药学研究收入下滑39.41%]** -> [传统业务承压]: 受集采降价及行业竞争影响，仿制药板块收入大幅萎缩，但毛利率仅下降0.53%，显示成本控制能力。
- **[经营活动现金流净额暴增191%]** -> [回款能力改善]: 现金流从3,202万跃升至9,321万，资金管理优化效果显著，缓解了高应收账款（5.82亿）带来的流动性压力。
- **[重组朗研生命失败]** -> [战略整合受阻]: 发行股份及可转债购买朗研生命100%股权事项终止，产业链纵向整合计划受挫，未来需寻找替代路径。

## 风险警告
**核心风险在于传统业务失速与创新转型的不确定性。** 仿制药药学研究收入同比暴跌39.41%，这是公司起家业务，其萎缩直接暴露了在集采常态化下，传统CRO服务模式的脆弱性。虽然创新药授权收入填补了缺口，但该收入具有一次性特征，持续性存疑。公司自研管线多达20余项，但大部分处于早期阶段，研发失败风险极高，且研发费用资本化率为0，意味着所有投入均当期费用化，若后续管线推进不顺，将对利润造成持续压力。

**财务健康度存在隐忧。** 应收账款高达5.82亿元，占总资产25.46%，且同比增长31.55%，远超收入增速，回款压力巨大。公司无自有房产，全部经营场所均为租赁，存在续租风险。此外，公司资产负债率因短期借款增加（同比+61.33%）而攀升，财务费用同比增长32.87%，利息负担加重。重组朗研生命失败后，公司如何通过内生增长或外延并购来弥补产业链短板，是未来最大的战略不确定性。
