# 300634.SZ 深度透视

## 因果逻辑链
- **[AI全栈服务体系构建]** -> [业绩增长]: 公司以“智算+平台+应用”三层架构的Rich AI全景生态为核心，将AI能力深度嵌入协同办公、智慧渠道、智算服务三大产品线，驱动AI及算力相关收入达3.91亿元，占总营收21.4%，成为增长主引擎。
- **[深度绑定中国移动等大客户]** -> [收入稳定]: 前五大客户销售占比79.11%，其中中国移动贡献53.47%营收。长期服务超1800家央国企，客户粘性高，预算制采购模式保障了收入的持续性与可预见性。
- **[信创邮箱国产替代]** -> [协同办公壁垒]: 公司RichMail信创邮箱可全面替代微软Exchange和IBM Domino，已进入中国银行、南方航空等核心客户，在信创政策推动下，成为公司稳固的现金牛业务。
- **[智算服务规模化落地]** -> [第二增长曲线]: 自研Rich AICloud解决方案，成功建设智能驾驶智算中心、联合电信共建智算中心，智算服务与数据智能产品线收入同比增长31.10%，成为增长最快的业务板块。
- **[经营现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额达4.63亿元，同比增长1277%，远超净利润（2.85亿元），主要系加强应收账款管理及存货周转效率提升，表明盈利质量显著优化。
- **[研发投入资本化]** -> [资产沉淀]: 研发投入3.59亿元，占营收19.6%，其中11.5%资本化。持续投入形成Rich AIBox、睿驰大模型等核心无形资产，构建了长期技术护城河。

## 风险警告
**第一大客户依赖与客户集中度风险**：公司对第一大客户中国移动的销售占比高达53.47%，前五大客户合计占比79.11%。虽然合作关系稳定，但过度依赖单一客户群体，使得公司议价能力受限，且一旦客户预算缩减或合作关系生变，将对公司营收造成重大冲击。公司需加速拓展非电信行业客户，降低集中度风险。

**AI商业化落地不及预期与竞争加剧风险**：公司虽已构建全栈AI能力，但AI及算力相关收入仅占总营收21.4%，且主要来自智算基础设施建设和运营服务，高毛利的AI应用软件收入占比仍待提升。当前AI Agent赛道竞争白热化，互联网巨头和创业公司纷纷入局，若公司不能在垂直行业场景中持续保持技术领先和成本优势，其AI业务的增长速度和盈利能力可能面临挑战。
