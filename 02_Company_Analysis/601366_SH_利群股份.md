# 601366.SH 深度透视

## 因果逻辑链
- **[消费需求疲软与行业竞争加剧]** -> [营收下降9.03%]: 宏观消费复苏偏弱，线上分流及折扣业态冲击，导致公司商品零售收入承压。
- **[门店调改与低效门店关闭]** -> [短期亏损扩大]: 调改初期一次性投入叠加关闭10家门店产生的资产处置损失及补偿费用约3000万元，拖累当期利润。
- **[食品工业产能扩张与市场培育]** -> [板块持续亏损]: 薯条、豆制品等新业务销售规模增长79.92%，但前期厂房设备摊销高，仍处于亏损状态。
- **[物流供应链价格下行]** -> [毛利下降]: 个别品类商品价格下行，导致物流供应链板块毛利减少，未能对冲零售端下滑。
- **[西海岸金鼎写字楼项目]** -> [销售毛利减少约4000万元]: 写字楼销售不及预期，对整体利润造成额外拖累。
- **[计提减值与税金增加]** -> [利润进一步承压]: 报告期内计提各类减值同比增加约4400万元，税金及附加费增加约3700万元。
- **[优化库存与降本增效]** -> [经营现金流净额增长26.91%]: 通过控制采购、优化库存结构，经营活动现金流出减少，现金流状况改善。
- **[可转债到期兑付]** -> [筹资活动现金流净流出增加53.35%]: 偿还债务支付的现金增加，导致筹资活动现金流净额大幅下降。

## 风险警告
公司2025年由盈转亏，核心风险在于**存量竞争下的盈利修复能力**。营收下滑9%的同时，毛利率下降2.61个百分点，显示主业盈利能力在价格战与成本刚性双重挤压下持续恶化。食品工业虽增长迅速，但尚处投入期，短期无法贡献利润，反而成为亏损源。写字楼销售的不确定性进一步增加了业绩波动。

**债务结构风险突出**。尽管资产负债率微降至72.65%，但2025年末一年内到期的非流动负债暴增至13.93亿元（主要为可转债重分类），而公司货币资金仅9.59亿元。虽然2026年3月可转债已到期兑付，阶段性流动性压力解除，但高负债运营模式下的偿债能力仍是长期关注焦点。公司需持续证明其经营现金流足以覆盖庞大的租赁负债和利息支出。
