# 000766.SZ 深度透视

## 因果逻辑链
- **[核心产品营收下滑]** -> [净利润下降39.25%]: 生化药收入同比降13.51%，中成药收入降8.09%，导致整体营收下滑11.54%，利润弹性更大。
- **[销售费用压缩]** -> [利润承压]: 销售费用同比降16.37%至5.62亿元，但营收降幅更大，显示费用压缩未能对冲收入下滑，且销售效率有待提升。
- **[高研发资本化率]** -> [短期利润美化]: 研发投入资本化率从25.47%飙升至43.39%，资本化金额增加77.52%，此举减少当期费用，但未来摊销压力增大。
- **[高额财务费用]** -> [侵蚀利润]: 财务费用高达8086万元，占营收6.9%，主要源于长期借款15.86亿元带来的利息负担，严重拖累净利润。
- **[华东地区营收骤降]** -> [区域市场风险暴露]: 华东地区营收同比大幅下降31.6%，是整体营收下滑的最大拖累因素，显示核心市场出现波动。
- **[母公司未分配利润巨亏]** -> [分红能力丧失]: 母公司未分配利润为-5.69亿元，合并报表为-22.46亿元，导致连续不派发现金红利，影响股东回报。
- **[新药上市进程]** -> [未来核心催化剂]: 国家1类新药琥珀八氢氨吖啶片已进入上市申请最后审评阶段，若获批将打开神经系统创新药市场，是公司战略转型的关键。
- **[子公司圣泰生物]** -> [利润核心支柱]: 圣泰生物贡献净利润4805万元，远超母公司及其他子公司，是公司当前盈利的绝对主力，其经营状况决定公司基本盘。

## 风险警告
**核心风险在于新药上市的不确定性与高负债下的财务脆弱性。** 公司当前盈利高度依赖子公司圣泰生物的生化药和中成药，但核心产品营收已现下滑趋势。同时，公司背负15.86亿元长期借款，年财务费用超8000万元，严重侵蚀利润。若琥珀八氢氨吖啶片上市进程受阻或商业化不及预期，公司将面临“老产品下滑、新产品未起”的困境，叠加高额利息，利润可能进一步恶化。

**另一个重大风险是研发投入资本化率过高带来的会计风险。** 2025年研发资本化率高达43.39%，远超行业平均水平。这意味着大量研发支出被推迟确认为资产，而非当期费用。若未来研发项目失败或收益不及预期，已资本化的开发支出（账面2.2亿元）将面临巨额减值风险，对利润造成一次性重大冲击。投资者需警惕利润质量。
