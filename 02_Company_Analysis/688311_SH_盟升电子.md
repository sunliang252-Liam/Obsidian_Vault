# 688311.SH 深度透视

## 因果逻辑链
- **[特种行业订单恢复]** -> [营收暴增276.78%]: 前期暂停/暂缓项目恢复执行，下游需求释放，卫星导航收入同比增477.62%。
- **[收入规模效应摊薄固定成本]** -> [毛利率提升]: 卫星导航毛利率增4.83pct，卫星通信毛利率增11.80pct，单位产品分摊的折旧等固定费用减少。
- **[可转债大部分转股]** -> [财务费用锐减50.64%]: 利息支出减少，直接改善利润表。
- **[上期全额计提商誉减值]** -> [本期亏损大幅收窄93.97%]: 2024年对南京荧火全额计提商誉减值，2025年无此非经常性重大损失。
- **[银行账户受限解除]** -> [经营现金流暴增5.08亿]: 2024年末受限的1.52亿元账户余额在2025年1月解除，按会计准则计入经营活动现金流入。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售占比93.97%，其中航天科工集团一家占比63.68%，单一客户依赖度极高。
- **[母公司未分配利润为负]** -> [连续三年不分红]: 截至2025年末母公司未分配利润为-6328万元，不满足现金分红条件。

## 风险警告
**核心风险在于客户极度集中与盈利质量堪忧。** 前五大客户贡献93.97%营收，其中航天科工集团一家占比高达63.68%，公司业绩完全取决于少数军工集团的项目节奏。尽管2025年营收暴增277%，但扣非净利润仍亏损4113万元，盈利质量极差。更需警惕的是，经营现金流暴增主要依赖1.52亿元银行账户受限解除的一次性因素，剔除后实际经营造血能力依然薄弱。

**第二重风险是战略转型的不确定性。** 公司成立系统集成部，切入国际贸易和能源电力赛道，但报告期内尚未形成收入。同时，电子对抗、低轨卫星通信等新业务仍处于研发或小批量阶段，商业化落地周期漫长。在母公司未分配利润为负、连续三年亏损的财务压力下，新业务的高研发投入（占营收16.22%）将持续侵蚀本就脆弱的利润表，存在“旧业务刚恢复、新业务未起量”的断档风险。
