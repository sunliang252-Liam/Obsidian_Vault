# 002356.SZ 深度透视

## 因果逻辑链
- **[能源业务并表效应]** -> [营收暴增43.37%]: 2024年7月后收购的6座能源站于2025年实现全年运营，LNG销量同比+126.77%，推动能源收入占比从48.44%跃升至75.91%。
- **[非经常性损益驱动扭亏]** -> [归母净利润转正至3839万]: 处置东方科技园房产获资产处置收益7128万元，叠加债务重组收益1034万元，完全覆盖扣非后-4721万元的经营亏损。
- **[关联方气源锁定成本优势]** -> [能源业务毛利率提升4.51%]: 向关联方盛世富源采购LNG/氢气占采购总额55.02%，依托山西焦化副产气资源，实现低成本、高稳定性的气源保障。
- **[商业零售主动收缩]** -> [服饰收入同比-36.62%]: 面对线下客流分流与成本压力，公司关停低效门店，聚焦核心商圈奥莱与专营店，导致收入下滑但毛利率提升10.80%。
- **[氢能业务仍处示范期]** -> [氢气收入占比仅6.64%]: 氢能重卡市场渗透缓慢，公司仅北姚1座综合站运营氢气加注，收入3840万，尚无法形成规模盈利。
- **[风光制氢项目远未投产]** -> [短期无业绩贡献]: 沁源100MW光伏、宁城262.5MW风电制氢项目仅完成前期筹备，主体工程未开工，投资回报周期长，存在资金与审批风险。
- **[现金流显著改善]** -> [经营净现金流+139.67%]: 销售规模扩大及前期应收账款收回，使经营现金流转正至3741万元，但投资活动净现金流主要依赖理财滚动与资产处置。

## 风险警告
**核心风险在于盈利的不可持续性与关联交易依赖。** 公司2025年扭亏完全依赖非经常性损益（资产处置+债务重组），扣非净利润已连续三年为负（-4721万）。能源业务虽成支柱，但毛利率仅8.64%，且超过55%的采购来自关联方盛世富源，气源定价与供应链稳定性存在潜在利益输送风险。氢能业务作为未来故事，目前仅贡献6.64%收入，两大风光制氢项目尚处前期，巨额资本开支将考验公司脆弱的现金流。

**第二大风险是公司治理与同业竞争未解。** 控股股东时代榕光及实控人郑梓豪控制的鹏飞集团，与公司在综合能源站、制氢项目上存在明确同业竞争。尽管有注入承诺，但截至报告期末，仍有3座能源站和制氢项目因“不具备转让条件”而未解决。公司管理层中多名董事、高管同时在鹏飞集团任职，关联交易规模巨大（占采购额55%），独立性与中小股东利益保护存疑。
