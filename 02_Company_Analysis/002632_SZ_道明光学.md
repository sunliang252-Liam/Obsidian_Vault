# 002632.SZ 深度透视

## 因果逻辑链
- **[汽车“两新”政策加力扩围]** -> [车牌膜需求提升]: 国内汽车产销超预期增长，直接拉动公司行车安防领域反光材料销量。
- **[大尺寸电视与Mini LED渗透率提升]** -> [光学显示材料营收增长13%]: 高端光学膜（复合膜、量子点膜）单机价值量提升，抵消了消费电子整体增速放缓的影响。
- **[离型材料与石墨烯导热膜市场开拓]** -> [电子功能材料营收增长15%]: 新客户开发与人工石墨膜量产，推动新材料业务成为第二增长曲线。
- **[原材料成本控制与产品结构优化]** -> [综合毛利率稳定在34%]: 反光材料毛利率微增0.35%，新材料毛利率大幅提升4.9%，对冲了内销毛利率下滑。
- **[海外子公司汇率大幅波动]** -> [财务费用转负，贡献利润]: 2025年财务费用为-1139万元，同比减少141%，直接增厚净利润。
- **[经营现金流大幅改善]** -> [现金流净额增长71%]: 通过票据结算优化，经营性现金流达4.49亿元，远超净利润，盈利质量优异。
- **[资产减值损失持续高企]** -> [侵蚀利润]: 铝塑膜和石墨烯设备计提减值5329万元，占利润总额20%，显示新业务仍处投入期。

## 风险警告
**核心风险在于新业务“增收不增利”与资产减值持续侵蚀。** 新材料业务（铝塑膜、石墨烯）营收增长15%，但毛利率仍为负（-3.37%），且2025年资产减值损失高达5329万元，主要来自该板块设备与存货。这表明公司第二增长曲线尚处于“烧钱”阶段，商业化进程不及预期，若下游客户导入缓慢，减值风险将持续拖累整体利润。

**海外市场地缘政治与汇率波动是另一重大不确定性。** 公司明确提及伊朗作为关键客户业务恢复前景不明，同时俄乌战争、中美关税政策导致汇率预测难度加大。尽管公司通过新设泰国、新加坡子公司进行全球化布局，但短期海外收入已同比下降6.62%，若中东市场持续动荡，海外业务将面临受阻风险，影响整体业绩韧性。
