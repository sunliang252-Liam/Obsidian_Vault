# 603309.SH 深度透视

## 因果逻辑链
- **[泌尿外科创新产品（负压清石鞘）海外高速放量]** -> [外销收入增长15.32%]: 凭借革命性临床价值，该产品在海外市场连续3年高速增长，带动泌尿外科整体收入增长22.07%。
- **[狼和医疗（包皮环切器）业绩大幅下滑]** -> [计提商誉减值1.47亿元]: 受产品市场需求放缓及竞争激烈影响，包皮环切器收入下滑30%，导致公司对收购形成的商誉进行大额减值，归母净利润同比下降65.21%。
- **[国内医疗行业整顿]** -> [新产品进院节奏放缓]: 行业整顿导致公司麻醉、导尿等核心领域的新产品在国内医院的推广和入院受阻，内销收入仅微增0.46%。
- **[血透管路中标23省联盟集采]** -> [血透业务收入增长12.82%]: 集采中标后，产能释放，单位成本下降，以价换量策略成功，推动血透管路业务实现较快增长。
- **[海外大客户定制化业务稳定]** -> [外销收入基本盘稳固]: 与海外大客户的深度绑定和定制化项目合作，使公司外销业务受地缘政治影响较小，保持了稳定增长态势。
- **[印尼工厂投产与墨西哥工厂建设]** -> [应对地缘政治风险与关税壁垒]: 为规避日益紧张的贸易摩擦和高额关税，公司加速海外生产基地布局，构建“培训+耗材”的可持续运营闭环。
- **[研发投入持续聚焦创新产品]** -> [巩固核心技术壁垒]: 公司围绕抗结壳、导管控弯、载药等关键技术进行研发，2025年获得9款国内注册证，为未来增长储备动能。

## 风险警告
**核心风险在于商誉减值“余震”与国内集采的持续挤压。** 2025年因狼和医疗业绩暴雷，公司计提1.47亿元商誉减值，导致净利润暴跌65%。截至年末，账上仍存有1.46亿元商誉（主要来自狼和与沙工医疗），若未来这两家子公司经营业绩不达预期，公司仍面临巨大的减值风险，这将持续侵蚀利润。

**海外扩张虽为亮点，但地缘政治与汇率风险不容忽视。** 公司外销占比超57%，且正大力布局墨西哥和印尼工厂以规避关税。然而，海外工厂的建设周期、产品注册及本土化运营均存在不确定性。同时，人民币汇率波动（2025年财务费用因汇兑损失大增775%）将直接冲击公司利润，海外销售的风险敞口正在扩大。
