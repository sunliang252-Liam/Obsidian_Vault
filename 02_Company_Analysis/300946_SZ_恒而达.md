# 300946.SZ 深度透视

## 因果逻辑链
- **[收购德国SMS公司]** -> [净利润同比暴跌57.79%]: 并购产生的一次性中介费、差旅费及SMS公司并表后的运营亏损（-127万欧元），直接侵蚀当期利润。
- **[滚动功能部件战略投入加大]** -> [研发费用同比增44.65%，销售费用同比增59.21%]: 为抢占人形机器人、高端数控机床等新兴市场，公司大幅增加直线导轨、滚珠丝杠等产品的研发与市场开拓投入。
- **[滚动功能部件业务放量]** -> [营收同比增154.15%，占比升至13.43%]: 直线导轨及滑块产品产销爆发式增长（销量分别增158%、237%），成为收入增长的核心引擎。
- **[金属切削工具基本盘稳固]** -> [营收与上年持平，毛利率提升]: 重型模切工具全球市占率第一，锯切工具国内第一梯队，为战略新业务提供稳定现金流。
- **[境外市场拓展加速]** -> [境外营收同比增35.04%，占比升至16.08%]: 收购SMS后，全球资源整合初显成效，带动全产品线出海。
- **[SMS高精度螺纹磨床国产化]** -> [为行星滚柱丝杠量产提供关键装备]: 公司正将SMS技术吸收转化，旨在打破高端螺纹磨削装备进口依赖，支撑核心战略产品量产。
- **[存货规模高企]** -> [资产减值损失达1825万元]: 滚动功能部件业务高速扩张导致存货激增（滑块库存增141%），计提大额跌价准备，拖累利润。

## 风险警告
**核心风险在于并购整合与战略投入的“双杀”效应。** 收购SMS公司虽补全了高端磨床版图，但短期带来一次性费用及并表亏损，导致净利润骤降57.79%。若SMS无法快速恢复生产交付、实现盈利，或国产化进程不及预期，将持续拖累公司整体业绩。同时，滚动功能部件业务仍处“烧钱”阶段，研发与市场投入高增，且该业务毛利率为负（-11.16%），规模扩张伴随亏损扩大风险。

**另一重大风险是存货与应收账款的双重压力。** 滚动功能部件业务爆发式增长导致存货规模激增，已计提1825万元资产减值损失。若下游需求波动或竞争加剧，存货跌价风险将进一步暴露。此外，应收账款规模随业务扩张而增长，若宏观经济下行或客户经营恶化，坏账风险不容忽视。公司正处于从“工具龙头”向“高端装备综合服务商”转型的关键期，战略投入期内的利润波动与现金流压力是主要观察点。
