# 603325.SH 深度透视

## 因果逻辑链
- **[大型聚烯烃项目高市占率]** -> [业绩高增长]: 公司在煤制聚烯烃细分市场占有率近80%，大型项目（超4000万元）收入占比达83.89%，驱动营收同比增长17.05%，净利润同比增长38.09%。
- **[海外项目高毛利]** -> [整体毛利率提升]: 境外业务收入同比增长220.53%，毛利率高达39.59%，显著高于境内，拉动整体毛利率提升4.62个百分点至37.53%。
- **[欧元升值]** -> [财务费用大幅负值]: 欧元对人民币汇率升值产生较大汇兑收益，财务费用为-4713万元，直接增厚利润。
- **[在手订单充沛]** -> [未来收入确定性]: 截至2025年末，公司在手订单41.65亿元，合同负债22.86亿元，为未来2-3年业绩提供坚实保障。
- **[技术壁垒+定制化]** -> [高客户粘性]: 公司掌握气力输送核心技术，拥有覆盖数百种物料的专有动态物性数据库，能提供高度定制化解决方案，形成高进入壁垒。
- **[募投项目投产]** -> [产能瓶颈突破]: “聚烯烃气力输送成套装备项目”等募投项目于2026年2月达到预定可使用状态，将有效缓解产能压力，支撑订单交付。
- **[新行业拓展]** -> [第二增长曲线培育]: 在PGA、PMMA等新能源材料、改性工程塑料等领域取得项目业绩，虽未形成规模效应，但已完成技术积累，打开成长天花板。

## 风险警告
**收入高度集中于大型合成树脂项目，且客户集中度高。** 公司超83%的收入来自单个超4000万元的大型项目，前五大客户销售额占比高达73.26%。若下游石化、煤化工行业投资周期波动，或主要客户项目延期、取消，将直接导致公司营收和利润剧烈波动。这种“大单依赖”模式使公司业绩缺乏平滑性，季度间波动显著。

**存货与现金流风险并存。** 公司存货账面价值高达15.75亿元，占总资产27.84%，且经营活动现金流净额同比下降45.24%，远低于净利润。这反映出公司“以销定产”模式下，项目周期长、资金占用大，回款速度慢于收入确认节奏。若客户项目进度受阻，高存货可能带来减值风险，而现金流持续恶化将影响公司运营韧性。
