# 603127.SH 深度透视

## 因果逻辑链
- **[生物资产公允价值大幅回升]** -> [净利润暴增302%]: 生物资产公允价值变动带来净收益4.76亿元，成为利润表核心驱动力，掩盖了主营业务亏损。
- **[前期行业竞争激烈滞后影响]** -> [核心业务毛利率下滑8.18个百分点]: 药物非临床研究服务收入同比下降17.75%，毛利率降至21.01%，反映前期价格战与订单萎缩的滞后冲击。
- **[实验室服务业务亏损]** -> [扣非净利润极低]: 实验室服务及其他业务贡献净利润为-1.64亿元，同比下降219.61%，表明剔除生物资产波动后的经营造血能力严重恶化。
- **[创新药审评审批提速]** -> [IND申请维持高位]: 30个工作日审评通道、双目录支付机制等政策红利，推动新药临床试验申请数量保持高位，为非临床安评业务提供需求基础。
- **[投融资初步复苏]** -> [新签订单回暖]: 2025年新签订单约26亿元，在手订单约26亿元，反映下游客户融资环境改善带来的需求回暖。
- **[海外子公司市场恢复不及预期]** -> [商誉减值]: 商誉余额从1.38亿元降至0.55亿元，减幅60.38%，表明海外业务整合与盈利修复低于预期。
- **[实验模型供应产能利用率不足]** -> [该业务毛利率为-54.07%]: 啮齿类实验模型业务处于起步阶段，收入仅775万元，但成本刚性导致严重亏损。

## 风险警告
**核心风险在于主营业务盈利能力的持续恶化。** 2025年归母净利润看似暴增302%，但完全依赖生物资产公允价值变动（贡献4.76亿元净收益），而实验室服务业务实际亏损1.64亿元。药物非临床研究服务毛利率已从高位骤降至21.01%，且收入仍在下降，表明行业价格战与需求萎缩的冲击尚未出清。若未来生物资产价格回落，公司将面临利润大幅缩水的风险。

**商誉减值与海外业务整合风险不容忽视。** 海外子公司BIOMERE市场恢复不及预期，导致商誉减值超8000万元。公司国际化战略依赖海外设施与团队，但地缘政治风险、汇率波动及跨文化管理挑战可能持续拖累海外业务表现。此外，广州设施等新产能投产后的爬坡期，若订单承接不及预期，将进一步加剧资产回报率下降的压力。
