# 600903.SH 深度透视

## 因果逻辑链
- **[上游气源成本高企]** -> [归母净利润下降24.62%]: 联营企业盈利能力下滑导致投资收益减少0.20亿元，直接侵蚀利润。
- **[政府定价与成本传导不畅]** -> [毛利率承压]: 上游气价频繁调整，但下游燃气销售价格受政府严格管制，成本无法完全、及时向下游转移。
- **[房地产下行]** -> [工程安装业务萎缩]: 新房交付量减少，传统“接驳费”增长模式面临挑战，业务量持续下滑。
- **[政策推动行业整合]** -> [市场集中度提升]: “一城一企”模式加速“小散弱”主体出清，公司作为全省性龙头有望受益于区域资源整合。
- **[管网与特许经营权壁垒]** -> [区域垄断优势]: 在省内38个区域取得特许经营权，覆盖主要城市和工业园区，形成自然排他性。
- **[多气源供应格局]** -> [供应韧性增强]: 构建“三大气源为主、关联单位作补充”格局，降低对单一供应商（中石油）的依赖风险。
- **[数智化转型]** -> [运营效率提升]: “123智慧燃气”体系投入运营，推动管网巡检、客户服务等环节降本增效，提升本质安全水平。
- **[现金流改善]** -> [经营质量向好]: 经营活动现金流净额同比大增109.34%至6.23亿元，主要系销售回款增加，为资本开支提供支撑。

## 风险警告
**核心风险在于“成本-价格”剪刀差与联营企业业绩拖累。** 公司上游气源高度依赖中石油（采购额占比53.33%），在气价市场化改革中，上游涨价压力无法通过下游顺价机制完全疏导，导致毛利率持续承压。更关键的是，2025年归母净利润下滑24.62%，主因是联营企业（如国家管网贵州公司）盈利能力大幅下降，投资收益锐减75.27%，暴露出公司对非并表资产的业绩依赖风险。

**成长性风险来自传统业务模式见顶与新业务不确定性。** 房地产下行周期导致工程安装业务萎缩，而增值服务、综合能源等“第二增长曲线”尚处培育期，收入占比极低（综合能源服务毛利率仅0.58%）。同时，公司资产负债率较高，短期借款同比大增37.27%，一年内到期的非流动负债增长51.29%，财务费用压力持续存在，若新业务无法快速贡献利润，将面临“旧引擎熄火、新引擎未点火”的困境。
