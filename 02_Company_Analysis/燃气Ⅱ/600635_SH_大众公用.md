# 600635.SH 深度透视

## 因果逻辑链
- **[投资收益大幅增长]** -> [归母净利润+78%]: 权益法核算的华璨基金等联营企业收益同比增加4.82亿元，是利润暴增的核心驱动力。
- **[公允价值变动亏损]** -> [扣非净利润-12.7%]: 持有的其他非流动金融资产（私募基金、股票）公允价值波动产生-2.32亿元损失，侵蚀了核心经营利润。
- **[燃气业务区域垄断]** -> [稳定现金流]: 上海浦西南部、南通市区唯一管道燃气供应商地位，贡献主营收入51.4亿元，毛利率10.07%，提供稳定经营现金流。
- **[污水处理BOT模式]** -> [高毛利、低波动]: 与政府签订特许经营协议，9家污水处理厂总处理能力46.5万吨/日，毛利率高达61.22%，是公用事业板块的利润稳定器。
- **[关联采购高度集中]** -> [成本控制风险]: 前五名供应商采购额占总额77.43%，其中向关联方上海燃气采购占比53.61%，议价能力受限，成本传导存在滞后。
- **[融资成本下降]** -> [财务费用压力缓解]: 2025年发行多期低利率中期票据（利率1.80%-2.00%），置换高息债务，利息保障倍数从2.67提升至3.89。
- **[经营现金流大幅改善]** -> [财务安全性提升]: 经营活动现金流净额同比+168%，主因支付采购款减少，现金利息保障倍数从2.11跃升至5.96。

## 风险警告
**核心风险在于利润高度依赖投资收益与公允价值变动，主业盈利能力疲软。** 2025年归母净利润4.15亿元中，非经常性损益贡献2.35亿元（占比56.6%），扣非净利润仅1.8亿元，同比下滑12.7%。这意味着剔除金融资产波动后，公司核心公用事业（燃气、污水）及金融创投（融租）业务的盈利能力在下降。一旦资本市场下行导致公允价值损失扩大或联营企业收益减少，利润将剧烈波动。

**第二大风险是燃气业务的成本传导机制不畅与关联交易依赖。** 公司燃气采购高度集中于关联方上海燃气（占采购额53.61%），而终端售气价格受政府管制，调价滞后于市场。若上游气价上涨而下游价格疏导受限，燃气板块毛利率将进一步承压。此外，上海翔殷路隧道专营权仅剩5年，即将进入移交期，该资产未来将不再贡献稳定收益，需关注替代性资产布局。
