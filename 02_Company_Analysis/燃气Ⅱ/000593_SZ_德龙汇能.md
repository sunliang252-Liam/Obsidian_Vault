# 000593.SZ 深度透视

## 因果逻辑链
- **[城市燃气主业稳健]** -> [净利润微增6.77%]: 核心燃气业务提供稳定现金流，但销气收入因经济放缓下降13.89%，利润增长主要依赖费用压降和减值减少。
- **[LNG业务量价齐跌]** -> [苏州天泓收入骤降38.45%]: 华东区域LNG销售价格下降及销量减少，导致该子公司收入大幅下滑，拖累整体营收。
- **[盛能燃气持续亏损]** -> [业绩承诺完成率仅1.31%]: 下游工业用户需求不足叠加气源成本上涨，导致该子公司亏损1087万元，触发股权回购诉讼。
- **[联营企业巨额亏损]** -> [投资收益大幅减少]: 参股公司金石石化计提大额信用减值，亏损4979万元，按权益法核算拖累公司利润。
- **[费用管控见效]** -> [三费合计减少1175万元]: 公司加强融资利率和费用管理，销售、管理、财务费用均同比下降，部分对冲了主业下滑压力。
- **[资产减值压力缓解]** -> [减值计提同比减少3033万元]: 2025年计提减值金额较2024年大幅下降，是营业利润增长29.82%的关键因素。
- **[控制权变更]** -> [战略转型预期]: 原控股股东顶信瑞通向诺信芯材转让29.64%股份，公司实际控制人变更为孙维佳，带来业务整合与资本运作新预期。

## 风险警告
**核心风险在于资产质量恶化与法律纠纷。** 盛能燃气业绩承诺完成率仅1.31%，公司已提起诉讼要求原股东支付1.5亿元股权回购款，但案件一审尚未判决，回款存在重大不确定性。同时，子公司旌能天然气因预付2420万元采购款纠纷起诉广东广骏，该款项已全额计提坏账，回收前景堪忧。这两起诉讼若最终无法收回款项，将对公司现金流和利润造成直接冲击。

**经营层面面临双重挤压。** 一方面，宏观经济放缓导致工业用户用气需求不足，LNG业务量价齐跌，云南、江苏等核心区域收入下滑明显；另一方面，上游气源成本上涨而下游顺价机制响应滞后，阶段性挤压城燃业务盈利空间。公司虽通过费用管控维持微利，但主业增长乏力，新业务（氢能、光伏）尚处投入期，短期难以贡献利润，转型成效有待验证。
