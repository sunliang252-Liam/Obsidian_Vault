# 600917.SH 深度透视

## 因果逻辑链
- **[上游气源采购成本上升]** -> [天然气销售毛利率降至0.34%]: 上游“保量不保价”政策导致购气成本增加，而终端售价传导不畅，单方毛差被严重挤压。
- **[房地产行业持续下行]** -> [天然气接驳业务收入下降15.99%]: 新建住宅接驳需求萎缩，导致高毛利的安装业务收入及毛利大幅下滑，拖累整体利润。
- **[天然气销售与接驳毛利双降]** -> [归母净利润同比暴跌44.98%]: 核心主业盈利空间收窄，叠加新业务尚未形成规模效应，导致利润端出现断崖式下滑。
- **[应收账款与合同资产增长]** -> [信用及资产减值损失同比增加]: 工程项目应收安装款及部分应收款项回收风险上升，导致减值损失扩大，侵蚀利润。
- **[气源采购成本增加]** -> [经营活动现金流净额同比下降30.91%]: 成本端现金支出增速快于收入端现金回流，导致经营性现金流承压。
- **[短期借款及应付票据大幅增长]** -> [财务费用同比增加61.92%]: 为应对营运资金压力，公司增加短期融资，导致利息支出增加，而利息收入同比下降，进一步推高财务费用。
- **[销气量增长4.72%]** -> [营业收入微增1.41%]: 销气量的增长被上游成本上升和接驳业务下滑所抵消，呈现“增量不增利”的困境。

## 风险警告
**核心风险在于“增量不增利”的盈利模式困境。** 公司2025年销气量增长4.72%，但归母净利润却暴跌44.98%，根本原因在于上游气源成本上升与下游顺价机制不畅导致的毛差收窄，以及高毛利的接驳业务因房地产下行而持续萎缩。这种结构性矛盾短期内难以解决，若上游成本继续高企或接驳业务进一步下滑，公司盈利能力将持续承压。

**财务风险正在显性化。** 公司经营活动现金流净额大幅下降30.91%，同时短期借款和应付票据激增，导致财务费用同比大增61.92%。这表明公司为维持运营不得不增加外部融资，财务杠杆正在被动提升。若未来现金流状况未能改善，偿债压力和流动性风险将进一步加剧。
