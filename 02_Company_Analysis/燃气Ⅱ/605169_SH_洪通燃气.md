# 605169.SH 深度透视

## 因果逻辑链
- **[LNG销量大幅增长]** -> [营收增长13.61%]: 第十三师LNG工厂及巴州能源二期项目开工率提升，带动LNG产销量同比增超21%，推动总营收增至31.27亿元。
- **[气源采购成本上升 + 售价随市下降]** -> [净利润下降29.77%]: 原料气及LNG采购量增加，但销售价格随市场行情下行，毛利率被压缩4.24个百分点，归母净利润降至1.22亿元。
- **[LNG重卡市场持续渗透]** -> [交通用气需求韧性]: 2025年LNG重卡销量19.87万辆（+11.55%），保有量突破102万辆，为公司核心车用燃料业务提供需求支撑。
- **[政策补贴首次覆盖天然气货车]** -> [利好存量替换]: 2025年3月政策将天然气营运货车纳入报废更新补贴（最高11万元），降低用户购车成本，激发替换需求。
- **[上游气源高度依赖中石油]** -> [成本与供应双重风险]: 公司天然气采购绝大部分来自中石油，采购成本上升直接侵蚀利润，且单一气源依赖存在供应稳定性隐患。
- **[加气站终端持续扩张]** -> [市场占有率提升]: 报告期末运营加气站50座，在建4座，沿疆内交通干线布局，巩固区域清洁交通能源供应网络。
- **[布局新能源充电业务]** -> [多元化能源服务转型]: 在哈密、巴州等地加气站新增充电设施，向“加气+充电”综合能源服务站升级，应对新能源趋势。
- **[募投项目持续延期]** -> [资本开支效率待考]: 核心募投项目“第十三师天然气储备调峰项目”再次延期至2026年底，累计投入进度仅49.13%，产能释放节奏慢于预期。

## 风险警告
**核心风险在于“增量不增利”的盈利困境。** 公司2025年营收增长13.61%，但归母净利润却大幅下滑29.77%，主因是气源采购成本上升与LNG售价随市下降的双向挤压。这种“增收不增利”的剪刀差若持续，将严重侵蚀股东回报。公司对上游中石油气源的依赖度极高，议价能力弱，成本传导机制不畅，是利润波动的根本原因。

**成长性风险来自募投项目持续延期与新能源替代威胁。** 核心募投项目“第十三师天然气储备调峰项目”已多次延期至2026年底，累计投入进度不足50%，产能释放存在重大不确定性。同时，公司虽已布局充电业务，但面对电动重卡对LNG重卡的潜在替代，其转型速度和成效尚不明确，若天然气经济性优势收窄，现有加气站资产可能面临贬值风险。
