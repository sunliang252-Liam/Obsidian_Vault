# 603318.SH 深度透视

## 因果逻辑链
- **[LNG价格下行与需求疲软]** -> [LNG业务毛利率降至3.49%]: 2025年国内LNG出厂价格波动下行，叠加工业用气需求疲软，导致LNG生产利润空间被大幅压缩。
- **[城燃购销价差收窄]** -> [能源综合服务业务收入下降2.93%]: 上游气源价格下降未能完全传导至下游，叠加宏观经济放缓导致工业用户需求萎缩，城燃业务盈利空间受限。
- **[全球数据中心建设需求]** -> [燃气设备业务收入增长37.70%]: 数据中心电力需求增长带动燃气电厂配套建设，公司采取薄利多销策略，订单量及交货量显著增加。
- **[计提大额诉讼预计负债]** -> [归母净利润亏损0.79亿元]: 因辽宁三三工业诉讼计提预计负债4,991.11万元，叠加资产减值损失，直接导致公司由盈转亏。
- **[联营企业投资收益下降]** -> [利润总额同比下降87.09%]: 联营企业投资收益较上年同期大幅减少，是公司利润总额骤降的核心原因之一。
- **[商誉减值测试]** -> [计提商誉减值准备6,539.22万元]: 对收购子公司资产组进行减值测试，因经营业绩未达预期，确认商誉减值损失。
- **[控股股东变更与定增完成]** -> [资本结构优化与资金支撑]: 控股股东变更为水发集团，并完成5亿元定增，为公司“三东”战略（山东、蒙东、陇东）提供资金保障。

## 风险警告
**核心风险：业绩由盈转亏，盈利质量恶化。** 2025年归母净利润亏损0.79亿元，扣非净利润亏损0.34亿元，主要源于LNG与城燃主业毛利率下滑、大额诉讼计提以及商誉减值。公司连续两年未分配利润为负，已不具备分红条件，股东回报能力严重受损。此外，经营活动现金流净额同比下降38.09%，显示经营造血能力减弱。

**重大风险：诉讼与商誉“双雷”悬顶。** 辽宁三三工业诉讼二审尚未宣判，若败诉，已计提的4,991万元预计负债可能不足以覆盖最终赔偿，将造成额外损失。同时，公司商誉账面价值高达10.28亿元，占总资产22.8%，若未来被收购子公司经营持续不达预期，存在进一步大额减值的风险，可能对利润造成重大冲击。
