# 002259.SZ 深度透视

## 因果逻辑链
- **[重大诉讼和解与判决]** -> [净利润暴增998.75%]: 成都农商行、富嘉租赁等历史诉讼取得有利结果，导致前期计提的预计负债大幅转回，形成非经常性收益约9900万元，是净利润从1200万飙升至1.32亿的核心原因。
- **[LNG产销量增长]** -> [营业收入增长36.45%]: 2025年LNG销售量38.71万吨，同比增长11.30%，带动主营业务收入从7.33亿增至10.00亿。
- **[原材料成本大幅上升]** -> [毛利率下降与经营现金流恶化]: 原材料成本同比激增81.56%，远超收入增速，导致燃气行业毛利率下降7.91个百分点，经营活动现金流净额同比减少40.06%。
- **[债务清偿与财务结构优化]** -> [净资产收益率飙升]: 公司积极偿还华宝信托等有息债务，有息负债从2.62亿降至1.66亿，资产负债率从70.69%降至52.05%，推动净资产收益率从4.78%跃升至41.14%。
- **[客户与供应商高度集中]** -> [经营风险集中]: 前五大客户销售占比87.26%，前五大供应商采购占比96.20%，尤其对中石油陕西分公司单一供应商依赖度高达80.48%，议价能力弱，成本传导困难。
- **[历史违规担保与诉讼遗留]** -> [资产受限与持续经营风险]: 因原控股股东违规担保，公司仍有1.07亿元资产（货币资金、房产、股权）被司法冻结，且证券虚假陈述等诉讼仍在执行阶段，构成潜在现金流出。

## 风险警告
**核心风险在于盈利的不可持续性与脆弱的现金流。** 2025年净利润暴增完全依赖诉讼和解带来的非经常性收益（约1.03亿元），扣非净利润反而同比下滑43.30%。主营LNG业务面临上游气源成本（中石油）高企与下游售价波动的双重挤压，毛利率持续走低，导致经营活动现金流净额大幅萎缩40%。公司并未真正建立起可持续的盈利增长引擎。

**历史遗留问题的“地雷”尚未完全拆除。** 尽管债务规模有所下降，但仍有1.18亿元逾期债务，且超过1亿元的资产因历史担保问题被司法冻结。证券虚假陈述诉讼涉及金额高达1.79亿元，部分案件已进入执行程序，未来仍可能产生大额现金流出。公司治理层面的历史创伤修复仍需时日，任何诉讼进展的不利变化都可能再次冲击公司财务稳定性。

> 四川升达林业产业股份有限公司是深交所上市公司,公司以“关注环保、关爱人生、回归自然、持续发展”为基本理念,以“生态、领先、关爱”为品牌核心理念,以“建一流企业、创世界品牌”为奋斗目标,以清洁能源为公司主营业务,积极向清洁能源转型,快速推进LNG工厂、LNG加气站和城镇燃气等项目建设。     2013年起公司董事会适时调整了发展战略,积极实施发展清洁能源业务的战略转型,公司通过并购、自筹自建等方式在四川、内蒙、贵州、陕西等地成立或控股了内蒙博通中海天然气有限公司、彭山中海能源有限公司、贵州中弘达能源有限公司、榆林金源天然气有限公司、米脂绿源天然气有限公司、榆林金源物流有限公司等清洁能源企业。公司以清洁能源“上游(勘探与开采)--中游(加工与物流)--下游(应用与分销)”的整个产业链建设作为长期发展战略,并按长、中、短结合的方式初步形成了液化天然气生产与销售、城镇燃气(管道输配)、LNG物流、加气站与调峰站等四大业务板块。依照尊重客户,战略合作,互惠共赢的思想,不断推进清洁能源发展。     2016年12月30日第三次临时股东大会上以特别决议审议通过了《关于公司符合重大资产重组条件的议案》。升达林业以现金方式向控股股东四川升达林产工业集团有限公司出售相关林业资产,业务剥离完成。至此,升达林业开启了向深度转型发展的新路径。
