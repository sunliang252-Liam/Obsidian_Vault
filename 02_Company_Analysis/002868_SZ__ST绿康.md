# 002868.SZ 深度透视

## 因果逻辑链
- **[光伏胶膜业务巨亏]** -> [公司连续三年亏损，净资产为负]: 光伏胶膜行业产能过剩、价格战导致子公司毛利率为负（-63.51%），亏损占公司总亏损90%以上，拖垮整体业绩。
- **[剥离光伏胶膜资产]** -> [净资产转正，但营收大幅下滑20.45%]: 以0元剥离亏损子公司，处置差额22.2亿元计入资本公积，使净资产从-2.63亿转正至6318万；但剥离后公司失去35.62%的收入来源。
- **[动保主业毛利率改善]** -> [核心业务盈利能力提升]: 动保系列毛利率从7.56%大幅提升至20.06%，动物保健品毛利率达35.59%，显示核心主业经营质量改善。
- **[外销增长对冲内销下滑]** -> [收入结构优化]: 外销收入增长21.86%，占比从29.79%提升至45.63%，有效弥补了内销38.40%的下滑。
- **[控制权变更+新控股股东输血]** -> [短期流动性危机缓解]: 新控股股东纵腾网络提供1.5亿元借款，筹资现金流净额由负转正至1.95亿元，避免资金链断裂。
- **[业绩承诺锁定退市风险]** -> [2026-2027年盈利成为硬约束]: 前控股股东承诺2026-2027年原有业务净利润为正，否则可能触发财务类强制退市。

## 风险警告
**退市风险悬而未决。** 公司虽通过资产剥离和股东输血暂时保壳，但2025年扣非净利润仍亏损1.38亿元，且经营活动现金流净额为-2508万元。核心风险在于：前控股股东承诺2026-2027年原有业务净利润为正，若动保主业无法在行业底部实现盈利反转，公司仍面临财务类强制退市压力。

**新旧产能转换期的经营断层风险。** 2026年公司需完成南浦厂区搬迁至浦潭新基地，搬迁期间生产可能中断或效率下降。同时，新控股股东纵腾网络（跨境电商物流巨头）与公司原有兽药业务存在巨大行业跨度，管理层大换血后，战略协同与整合效果存在重大不确定性。
