# 688606.SH 深度透视

## 因果逻辑链
- **[海外渠道拓展]** -> [营收微增4.47%]: 欧美、非洲等市场销售增长，但被国内业务拖累，整体增速有限。
- **[费用激增]** -> [净利润骤降27.20%]: 销售、研发、管理及财务费用全面上涨，尤其是市场开拓、新品注册及新厂房折旧，严重侵蚀利润。
- **[美元汇率波动与利息收入减少]** -> [财务费用大幅恶化]: 汇兑损失及国内利率下调导致利息收入下降，财务费用同比增加72.09%。
- **[毒品及药物滥用检测产品]** -> [核心增长引擎]: 该品类收入同比增长23.97%，成为营收增长的主要驱动力，弥补了传染病类产品的下滑。
- **[高研发投入与产品注册]** -> [构筑长期壁垒]: 研发费用占营收12.07%，新增215项产品及多项FDA/IVDR认证，巩固技术护城河，但短期压制利润。
- **[ODM模式主导]** -> [受制于客户与法规]: ODM收入占比67.38%，业务稳定性依赖大客户，且面临欧盟IVDR新法规对合作模式的冲击风险。
- **[高比例外销]** -> [暴露于地缘与汇率风险]: 外销收入占比92.99%，以美元结算，易受中美贸易摩擦、关税壁垒及汇率波动影响。
- **[高分红与股权激励]** -> [平衡股东回报与人才留存]: 全年分红比例达70.70%，同时实施股权激励，旨在绑定核心团队，但增加了费用支出。

## 风险警告
**核心风险在于“增收不增利”的困境与外部环境的双重夹击。** 公司营收增长乏力，但费用端因市场扩张、研发投入及新产能折旧而刚性增长，导致净利润大幅下滑。更关键的是，公司极度依赖海外ODM业务（占比超67%）和美元结算，这使其暴露在中美贸易战、欧盟IVDR新规及汇率波动的多重风险之下。任何单一风险爆发，都可能对公司的收入和盈利模式造成结构性冲击。

**第二重风险是增长引擎的可持续性存疑。** 毒品检测虽是当前亮点，但市场空间有限且竞争激烈。公司寄予厚望的CGM（连续血糖监测）等新业务尚在研发阶段，短期内无法贡献利润。同时，国内业务基数低、增速虽快但体量小，难以对冲海外市场的潜在波动。若毒品检测增长放缓，而新业务未能及时接力，公司将面临增长失速的风险。
