# 600318.SH 深度透视

## 因果逻辑链
- **[德润租赁投放规模大幅增长]** -> [营收与利润双增]: 融资租赁板块投放规模同比增长43.23%，带动全年营收增长12.30%，归母净利润增长14.49%，成为业绩增长的核心引擎。
- **[融资租赁业务扩张]** -> [经营活动现金流大幅转负]: 业务投放规模增加导致客户贷款及垫款净增加额达4.86亿元，经营活动现金流净额由正转负，从+2.40亿元骤降至-2.08亿元。
- **[发行公司债融资]** -> [筹资活动现金流由负转正]: 德润租赁成功发行公司债，筹资活动现金流净额从-2.55亿元大幅转正至+2.03亿元，有效缓解了业务扩张带来的资金压力。
- **[德润租赁“压舱石”作用]** -> [集团整体盈利稳定]: 德润租赁贡献净利润9,485.56万元，占集团合并净利润的绝大部分，其稳健经营是公司业绩的基石。
- **[手付通业务转型]** -> [软件业务营收下滑但整体盈利]: 受中小银行改制影响，传统软件业务营收下降10%，但通过开辟供应链新赛道实现双轮驱动，全年营收与净利润实现双增长。
- **[信用减值损失大幅增加]** -> [侵蚀利润]: 信用减值损失从-998万元扩大至-3,251万元，资产减值损失从-716万元扩大至-2,054万元，合计损失超5,300万元，是利润增长的最大拖累项。
- **[高额担保]** -> [放大财务杠杆风险]: 公司对外担保总额占净资产比例高达75.25%，远超50%红线，过度依赖担保融资放大了财务风险。

## 风险警告
**核心风险在于资产质量恶化与现金流压力。** 公司信用及资产减值损失同比暴增近2.5倍，合计超5,300万元，直接侵蚀了本就不高的净利润。同时，为追求规模扩张，融资租赁业务大量投放导致经营活动现金流由正转负，净流出高达2.08亿元，显示公司盈利的“含金量”极低，业务扩张高度依赖外部融资输血。

**财务杠杆高企，偿债压力不容忽视。** 公司资产负债率52.32%，但对外担保总额占净资产比例高达75.25%，远超50%的警戒线。这意味着公司及子公司承担了巨大的或有负债风险。一旦被担保方出现违约，公司将面临代偿风险，可能引发连锁反应，对现金流和盈利能力造成严重冲击。
