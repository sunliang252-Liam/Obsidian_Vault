# 002647.SZ 深度透视

## 因果逻辑链
- **[破产重整完成]** -> [净资产由负转正，净利润扭亏为盈]: 通过执行重整计划，引入战略投资人并以股抵债，彻底解决历史债务，资产负债结构极大优化，确认债务重组收益5.42亿元，驱动归母净利润达3.6亿元。
- **[聚焦第三方支付主业]** -> [扣非净利润实现增长]: 剥离低效的租赁、小贷等资产，集中资源发展核心支付业务，2025年扣非净利润4265万元，同比增长129.14%，显示主业盈利能力改善。
- **[支付牌照续展中止]** -> [核心业务存在不确定性]: 因公司进入重整程序，央行对子公司合利宝的支付牌照换证续展申请中止审查，虽业务暂正常，但牌照能否顺利续展是未来持续经营的根本前提。
- **[跨境支付业务发力]** -> [成为新增长点]: 合利宝依托跨境人民币支付备案及香港MSO牌照，在跨境支付领域客户与交易规模高速增长，弥补了国内支付市场增速放缓的影响。
- **[商誉高企]** -> [减值风险持续]: 账面商誉8.94亿元，占净资产比例极高。若合利宝未来经营不及预期，大额商誉减值将直接冲击利润表。
- **[引入实力投资人]** -> [优化治理与资源整合]: 中信资本、广州资产等成为股东，公司变更为无实控人状态，新股东有望在业务资源、融资能力上提供支持，但治理结构稳定性待观察。
- **[低效资产剥离]** -> [资产结构优化]: 通过拍卖处置民盛租赁、仁东小贷等子公司，虽产生处置亏损，但使公司更聚焦支付主业，改善了资产质量和流动性。

## 风险警告
**核心命脉悬于牌照续展。** 公司所有业务根基系于子公司合利宝的《支付业务许可证》。因母公司重整，续展已被央行中止审查。若最终未能通过，公司将丧失主营业务资质，价值归零。这是当前最紧迫、最致命的“一票否决”风险，投资者需密切关注后续进展。

**财务“洗澡”与真实盈利能力的背离。** 2025年归母净利润3.6亿元，但扣非净利润仅4265万元，盈利高度依赖债务重组等非经常性损益。同时，账面商誉高达8.94亿元，远超净资产。一旦合利宝业绩波动，商誉减值将瞬间吞噬利润。此外，公司仍面临15亿元“萝卜章”担保诉讼及投资者索赔，潜在负债敞口巨大，真实资产质量远逊于报表数字。
