# 600901.SH 深度透视

## 因果逻辑链
- **[“零售+设备”产业金融模式]** -> [资产规模与盈利双增]: 聚焦中小微客户（单笔合同95万元）和直租业务（占比53%），以高周转、低风险、高利差的零售模式驱动资产规模增长17.22%至1609亿元，净利润增长10.12%至32.4亿元。
- **[“厂商租赁+区域直销”双线获客]** -> [客户数量与合同笔数激增]: 与国内外龙头厂商深度绑定，同时组建属地化团队深耕区域，实现全年新增投放合同突破10万笔，中小微客户占比超99%。
- **[AI赋能全链条（“AI in All”）]** -> [运营效率与风控能力提升]: 将AI嵌入获客、风控、运营全流程，实现标准类零售小单7×24小时秒级审批，单笔业务时间缩短近30%，不良率降至0.88%的五年新低。
- **[“3+N”多元化行业布局]** -> [资产组合风险分散]: 清洁能源、交通运输、工业装备三大百亿级板块引领，覆盖100多个细分行业，有效对冲单一行业周期波动，保持资产质量稳健。
- **[融资成本压降与结构优化]** -> [净利差逆势走阔]: 通过引入9年期保险资金、发行长期低利率金融债、扩大银行授信（同比增长16%），利息支出同比下降9.21%，推动净利差从3.62%提升至3.66%。
- **[“AI熵减”与扁平化组织]** -> [组织敏捷性提升]: 通过AI工具简并人工环节25个，构建“倒金字塔型”组织，将客户置于顶端，缩短决策链条，以对抗“组织熵增”，提升市场响应速度。
- **[紧跟产业出海与设备更新]** -> [开辟新增长极]: 服务中国制造出海（覆盖20多个国家），并抓住大规模设备更新政策机遇，拓展二手设备抵换新设备等业务，培育第二增长曲线。

## 风险警告
**核心风险在于信用减值损失激增与资产负债期限错配。** 2025年信用减值损失同比暴增42.75%至10.23亿元，远超营收增速（15.75%），表明在资产规模快速扩张的同时，潜在坏账风险正在加速暴露。尽管不良率微降，但拨备覆盖率已从高点回落至421.22%，若宏观经济下行或特定行业（如医疗健康、民生保障板块收入大幅下滑）出现系统性风险，资产质量将面临严峻考验。

**另一重大风险是利率波动与流动性管理。** 公司有息负债期限多在一年以内，而租赁项目存续期约三年，期限错配严重。在LPR下行周期中，资产端收益率调整快于负债端成本，将直接压缩净利差。同时，经营活动现金流净额由正转负（-9.63亿元），主要因租赁投放增速远超回款，高度依赖拆入资金（占总负债63.9%）维持流动性，一旦市场资金面收紧，将面临巨大的再融资压力。
