## 因果逻辑链
- **[境外清算会员资质全球化布局]** -> [境外金融服务业务高增长]: 公司已取得CME、LME等18个会员资质和15个清算席位，实现交易清算一体化，境外客户权益达233亿港币，境外业务收入同比增长15.79%，毛利率高达66.26%。
- **[“A+H”双资本平台落地]** -> [资本实力与品牌影响力跃升]: 2025年12月H股上市募资约12亿港币，全部用于增资境外子公司，净资本同比大增81.8%至27.4亿元，净资产突破55亿元，为国际化扩张提供弹药。
- **[期货市场资金总量突破2万亿]** -> [经纪业务客户权益创新高]: 行业客户权益同比增超30%，公司境内客户权益达389.82亿元，但同质化竞争导致经纪业务收入同比下降3.85%，呈现“增量不增收”。
- **[风险管理业务聚焦结构优化]** -> [基差贸易主动压缩规模]: 面对信用风险上升，公司主动收缩现货交易规模，风险管理业务收入同比下降37.51%，但通过聚焦新品种（烧碱、铂、钯）落地，毛利率微增至8.11%。
- **[南华基金合规内控问题频发]** -> [财富管理业务拖累整体]: 南华基金因内控、销售等问题被浙江证监局责令改正并暂停部分业务三个月，导致财富管理业务毛利率为-37.04%，亏损拖累集团整体表现。
- **[金融科技自研系统上线]** -> [做市业务效率提升]: 公司成功上线自研做市系统（NHTD5），提升响应速度与决策精度，在行业政策调整背景下保障做市业务稳定运行。
- **[“保险+期货”项目覆盖16省]** -> [社会责任与业务协同]: 全年入场项目超75个，提供18.81亿元风险保障，在服务乡村振兴的同时，为场外衍生品业务积累产业客户资源。

## 风险警告
**核心风险在于国际化扩张与合规内控的失衡。** 公司通过H股上市募资全力押注境外业务，但境外业务面临地缘政治冲突、汇率波动及不同司法辖区监管差异的复杂风险。同时，境内子公司南华基金因合规问题被暂停部分业务，暴露出公司在快速扩张中内控体系未能同步升级的隐患。若境外业务遭遇市场剧烈波动或监管处罚，而境内财富管理业务持续失血，将严重侵蚀公司整体盈利。

**传统经纪业务“增产不增收”的困境仍在加剧。** 行业同质化竞争导致手续费率持续下降，公司经纪业务收入同比下滑3.85%，而客户权益却大幅增长。这种“以量补价”的模式难以为继，一旦市场成交量回落，经纪业务将成为利润的拖累。此外，公司现金分红比例仅10.10%，远低于行业平均水平，对追求稳定回报的投资者吸引力有限。
