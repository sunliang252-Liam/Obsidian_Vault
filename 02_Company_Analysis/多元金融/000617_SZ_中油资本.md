# 000617.SZ 深度透视

## 因果逻辑链
- **[降息周期与息差收窄]** -> [营收下降13.39%]: 央行降息导致利息收入减少，财务公司及商业银行利息收入分别下降16.88%和10.01%。
- **[产融结合战略深化]** -> [服务主业收入占比创新高]: 围绕中国石油集团产业链需求，提供“一业一策”综合金融服务，以融促产，客户总数增长3.9%。
- **[资产规模突破万亿]** -> [综合实力保持领先]: 资产总额达1.13万亿元，存贷款、租赁、信托等业务规模较“十三五”末实现两位数增长，巩固央企金控龙头地位。
- **[信用减值损失高企]** -> [侵蚀净利润]: 2025年信用减值损失31.98亿元，虽同比略降，但仍为利润最大减项，主要源于贷款及债权投资预期信用损失计提。
- **[经营活动现金流大幅转负]** -> [流动性管理承压]: 经营活动现金流净额从+59.27亿元骤降至-182.78亿元，主因客户贷款及垫款净额同比大幅增加，资金投放节奏加快。
- **[绿色金融与数字化转型]** -> [培育新增长动能]: 绿色金融业务规模达1,032.37亿元，昆仑数智赋能油气行业数字化转型，探索轻资产与数据驱动发展模式。
- **[收购英大期货]** -> [完善金融牌照布局]: 收购期货牌照，补齐业务短板，旨在打造“产业培育-投融赋能-价值实现”的产投融协同闭环。

## 风险警告
**核心风险在于信用风险与宏观经济周期的强关联性。** 公司超38%的资产为贷款和垫款及债权投资，且高度集中于能源化工产业链。若油价持续低迷或下游需求疲软，将直接导致客户还款能力下降，信用减值损失可能进一步扩大，侵蚀本就承压的利润。尽管公司强调低风险偏好，但集中度风险难以在短期内化解。

**流动性管理面临结构性挑战。** 2025年经营活动现金流大幅净流出，主要源于贷款投放加速，而吸收存款增速相对滞后。在适度宽松的货币政策环境下，若市场利率快速反转或出现极端信用事件，公司可能面临资产负债期限错配加剧、融资成本上升的流动性压力。此外，境外业务占比近20%，汇率波动风险不容忽视。
