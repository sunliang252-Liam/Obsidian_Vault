# 002423.SZ 深度透视

## 因果逻辑链
- **[寿险业务加速转型]** -> [净利润11.33亿元，同比下降55.57%]: 中英人寿保费增速显著优于行业，但新保险合同准则追溯调整导致2024年利润基数大幅抬高，造成同比大幅下滑。
- **[中英人寿保费高增]** -> [保险业务收入增长9.11%]: 个险、经代、银保三大渠道立体化布局，经代渠道夯实行业第一品牌，新单保费同比增长34.50%。
- **[中粮信托标品转型]** -> [标品资管存续规模突破1300亿元]: 聚焦“3+1+3”业务赛道，固收、权益产品体系不断丰富，市场认可度提升，驱动规模跃升。
- **[中粮期货国际化布局]** -> [国际业务成为利润贡献主力军]: 新加坡子公司成立、香港子公司获全面结算会员资格，牌照组合价值释放，国际业务收入中利息收入占比74%。
- **[产融结合深化]** -> [中粮信托产融业务规模站上百亿台阶]: 设立农粮食品业务总部，覆盖集团产业链16个业务场景，服务模式从供应链金融向资产证券化、服务信托延伸。
- **[会计政策变更]** -> [净利润数据失真]: 2025年执行新保险合同准则及标准仓单会计处理规定，对2024年数据追溯调整，导致同比基数变化，净利润可比性下降。
- **[投资活动现金流大幅流出]** -> [投资活动现金流净额-200.29亿元，同比扩大58.48%]: 其他债权投资规模大幅增加（从528亿增至704亿），反映公司加大债券配置力度以匹配寿险长久期负债。

## 风险警告
**核心风险在于净利润的“虚假繁荣”与真实增长动力的背离。** 2025年净利润同比腰斩，主因是2024年会计政策变更追溯调整导致基数虚高，而非经营恶化。但这也暴露了公司对会计准则变更的敏感度，以及寿险业务在低利率环境下利差损风险的持续累积。中英人寿综合偿付能力充足率275.63%看似安全，但若利率持续下行，存量高成本保单的负债成本压力将侵蚀利润。

**第二重风险来自信托和期货业务的转型阵痛。** 中粮信托标品资管规模虽突破1300亿，但行业同质化竞争激烈，管理费率承压，且信托业务收入同比下降13.62%。中粮期货手续费及佣金收入仅2亿元，传统经纪业务增长乏力，高度依赖利息收入（占国际业务收入74%），若市场利率持续走低，利息收入将面临收缩。此外，中粮信托涉及多起重大诉讼，涉案金额超15亿元，虽暂未形成预计负债，但潜在风险敞口不容忽视。

**公司简介（F10 原文）**

> 中粮资本控股股份有限公司(简称“中粮资本”,002423.SZ)是中粮集团旗下运营管理金融业务的专业化公司,成员企业包括中英人寿、中粮信托、中粮期货、中怡保险经纪、大湾区和基金业务平台、龙江银行等。2017年,中粮资本获批成为国家发改委第二批混改试点企业,同年8月,公司引入弘毅、温氏、首农等战略投资者,完成混合所有制改革。2018年,中粮资本上市事项获得国务院国资委和证监会批复,于2019年初成功上市。2019年10月8日,公司股票简称变更为“中粮资本”,股票代码为“002423”,以全新形象在A股亮相。经过20余年的发展,中粮资本铸就了一条以“寿险+信托+期货+保险经纪”为主要业务,以“产业基金+金融科技+境外业务”为有益补充的金融服务链。“十四五”期间,中粮资本以数字化为发展战略,在做好现有业务的基础上,着重拓展供应链金融、农业金融和康养金融三大创新业务,产融结合、融融结合,立足中粮集团产业链,致力于成为以服务主业为特色,具有行业竞争力的综合金融平台。
