# 600390.SH 深度透视

## 因果逻辑链
- **[信托业务转型阵痛]** -> [五矿信托净利润-8.06亿元]: 公司主动压降传统非标融资业务，向标准化资产管理信托和资产服务信托转型，导致手续费及佣金收入大幅下降46.39%，叠加存量风险项目减值，信托板块由盈转亏。
- **[白银期现业务规模扩张]** -> [营业收入同比+449%]: 风险管理子公司五矿产业金融按总额法核算的白银基差贸易规模激增，导致营业收入和营业成本同步大幅膨胀，但该业务毛利率极低（-0.4%），对利润贡献有限。
- **[优先股赎回]** -> [归母净利润降幅收窄]: 公司赎回优先股，导致归属于普通股股东的净利润基数变化，使得基本每股收益同比大幅增长400%，但实际归母净利润同比下降13.82%。
- **[外贸金租优化融资结构]** -> [租赁公司利息支出同比-45%]: 公司主动压降负债规模并降低融资成本，利息支出大幅减少，推动租赁板块毛利率提升8.57个百分点至54.35%。
- **[五矿证券计提预计负债]** -> [营业外支出同比+447%]: 因广道数字事件，五矿证券计提专项基金预计负债，导致营业外支出大幅增加，拖累整体利润。
- **[五矿信托与关联方设立合资公司]** -> [交易性金融资产/负债大幅下降]: 公司将部分信托受益权及相关负债打包出资至合资公司，导致交易性金融资产和负债规模分别下降71.69%和89.78%，资产结构发生重大变化。
- **[产业金融战略深化]** -> [产融协同项目投放金额同比+241%]: 公司聚焦中国五矿金属矿业全产业链，外贸金租服务股东产业链项目投放金额达48.29亿元，同比增长超2倍，产融结合模式进入实质收获期。

## 风险警告
**核心风险在于信托板块的深度亏损与资产质量恶化。** 五矿信托全年净亏损8.06亿元，是拖累公司整体业绩的最大负向因素。在信托行业“1+N”监管体系下，公司主动压降传统业务，但新业务（资产管理信托、服务信托）尚处于投入期，盈利贡献不足，导致收入断崖式下滑。同时，存量风险项目（如成都森宇、武汉金正茂等）的处置仍在进行中，减值压力持续存在。若转型进程慢于预期或风险项目处置不及预期，信托板块可能继续侵蚀公司利润。

**市场风险与流动性风险并存。** 公司持有大量以公允价值计量的金融资产（其他权益工具投资、交易性金融资产等），2025年公允价值变动收益虽为正，但市场波动（尤其是权益市场和债券市场）将直接冲击公司利润。此外，经营活动现金流净额为-51.25亿元，主要因子公司购买交易性金融资产支出增加，显示公司对市场流动性的依赖度较高。在利率下行和资本市场波动加剧的背景下，公司自营投资业务和融资租赁业务的息差收入均面临收窄压力，流动性管理难度加大。
