# 601111.SH 深度透视

## 因果逻辑链
- **[运力投入增加与客座率提升]** -> [客运收入增长]: 运力投入（ASK）增长3.24%叠加客座率提升2.03个百分点，共同推动客运收入增加约89亿元，但被票价下降（每客公里收益-3.63%）部分抵消。
- **[航油价格下降]** -> [成本改善]: 航油成本同比减少36.79亿元（-6.85%），是营业成本增幅（2.82%）低于收入增幅（2.87%）的核心原因，直接缓解了利润端压力。
- **[国际航线快速恢复]** -> [收入结构优化]: 国际客运收入同比增长14.13%，占比提升至27.55%，有效对冲了国内市场的“内卷式”竞争和票价下行压力。
- **[人民币汇率升值]** -> [财务费用大幅下降]: 汇兑净收益3.28亿元（上年同期为净损失7.60亿元），叠加利息支出减少，推动财务费用同比下降28.27%，是亏损收窄的关键非经营性因素。
- **[国泰航空投资收益]** -> [利润贡献]: 按权益法确认的对国泰航空投资收益约30亿元，成为公司利润表的重要支撑，掩盖了主业持续亏损的现实。
- **[辅营收入与成本管控]** -> [经营质量改善]: 航空附加产品销售收入同比提升超40%，同时“集约化、协同化、精细化”成本管控见效，使扣非净利润亏损同比收窄2.16%。
- **[高杠杆与巨额债务]** -> [财务脆弱性]: 资产负债率88.56%，带息债务超2283亿元，利息支出高达55.53亿元，高财务杠杆放大了经营波动对利润的冲击。

## 风险警告
**核心风险在于主业盈利能力持续疲弱与高杠杆财务结构的双重挤压。** 尽管2025年营收增长、成本改善，但公司仍录得归母净亏损17.70亿元，且扣非净利润已连续三年为负。核心矛盾在于“以价换量”——运力增长和客座率提升带来的收入增量，被票价下降（国内每客公里收益-4.92%）所侵蚀，反映出行业“内卷式”竞争格局未根本改变。公司累计未弥补亏损高达324.87亿元，导致无法分红，股东回报能力严重受限。

**外部冲击的脆弱性极高。** 公司业绩对航油价格和人民币汇率高度敏感：航油成本占比超30%，汇率每波动1%影响净利润约1.4亿元。当前国际地缘政治风险与油价不确定性并存，若人民币贬值或油价反弹，将直接导致亏损加剧。此外，高达1089亿元的资本承诺（主要为飞机购置）意味着未来数年持续的巨额现金流出，将进一步推高负债率，考验公司的再融资能力和现金流安全边际。
