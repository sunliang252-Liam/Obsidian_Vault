# 002461.SZ 深度透视

## 因果逻辑链
- **产品结构高端化** -> **净利润增长11.54%**: 高档啤酒收入同比增长10.98%，毛利率提升2.22个百分点，直接拉动利润增速远超收入增速（2.56%）。
- **电商渠道爆发** -> **线上收入增长342%**: 电商渠道收入从0.7亿跃升至3.1亿，成为新的增长极，但基数低，对整体收入贡献仍有限（5.31%）。
- **成本管控有效** -> **毛利率提升**: 啤酒销售营业成本同比下降1.45%，主要得益于能源成本下降（占比从5.57%降至4.50%）和原材料成本控制。
- **产能扩建与升级** -> **支撑高端化与区域扩张**: 梅州、湛江、中山等子公司产能扩建，为产品结构升级和区域市场渗透提供产能基础。
- **品牌营销投入加大** -> **巩固华南市场地位**: 广告宣传费同比增长15.97%，通过赞助体育赛事、举办音乐派对等提升品牌声量，在行业产量下滑背景下实现销量逆势增长1.58%。
- **财务费用持续为负** -> **增厚利润**: 利息收入（1.92亿）远超利息支出（0.26亿），净财务收益1.65亿，直接贡献利润。
- **非经常性损益增加** -> **利润增速高于扣非增速**: 非经常性损益同比增加48.9%，主要来自资产处置收益和金融资产公允价值变动，对净利润增长有额外贡献。

## 风险警告
**核心风险在于区域市场依赖与行业天花板。** 公司95.66%收入来自华南，区域集中度极高。全国啤酒产量已连续下滑，行业进入存量博弈阶段，公司销量微增1.58%主要靠高端化提价和份额抢夺，增长空间受限。若华南市场竞争加剧或消费疲软，业绩将受重大冲击。

**第二大风险是募投项目回报不及预期。** 公司2017年定增募资43亿，截至2025年末仍有23.3亿未使用，多个项目（如琶醍文化创意园区）延期至2028年。大量资金沉淀于在建工程和理财，若园区运营、产能扩建等项目无法实现预期收益，将拖累ROE和资产周转效率。
