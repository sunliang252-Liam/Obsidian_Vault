# 300600.SZ 深度透视

## 因果逻辑链
- **行业竞争加剧与低价接单** -> **传统业务毛利率暴跌**: 为保市场份额，公司在常规船型接受低利润订单，导致船舶配电系统毛利率同比下降18.20个百分点。
- **原材料及核心部件涨价** -> **成本端刚性挤压利润**: 铜、铝等大宗商品价格高位运行，叠加核心电子元器件供应商持续提价，直接推高生产成本，侵蚀利润空间。
- **新市场开拓初期低价策略** -> **短期盈利承压**: 为切入航空航天、新能源船等高壁垒市场，公司采取竞争性定价，导致新业务初期毛利率低于成熟业务。
- **航天自动化系统收入暴增** -> **业务结构优化初见成效**: 该板块收入同比增长317.57%，成为公司收入增长的核心驱动力，对冲了传统船舶业务的萎缩。
- **经营性现金流大幅改善** -> **回款能力增强**: 经营活动现金流净额同比增长5021.04%，主要得益于销售回款情况改善，但净利润仍为负值，显示“纸面亏损”与“现金造血”背离。
- **收到原控股股东业绩补偿款** -> **资本公积大幅增加**: 报告期收到业绩补偿款2.57亿元，直接推动归属于母公司股东权益同比增长20.07%，但该收益为非经常性损益。
- **信用减值损失持续高企** -> **资产质量风险暴露**: 报告期信用减值损失达2435.5万元，主要系应收账款坏账准备计提，反映下游客户回款风险依然严峻。

## 风险警告
公司连续三年扣非净利润为负，且亏损幅度持续扩大（2025年扣非净亏损6971万元，同比扩大120.88%），表明主营业务造血能力尚未恢复。尽管经营性现金流改善，但主要依赖存量订单回款，而非盈利驱动。核心风险在于：传统船舶配套业务陷入“增收不增利”的恶性循环，而新业务（航天、新能源）尚处投入期，短期内难以贡献利润，公司正面临新旧动能转换的“青黄不接”期。

应收账款规模高达3.59亿元，占总资产24.82%，且信用减值损失持续侵蚀利润。公司虽收到大额业绩补偿款改善资产负债表，但该款项为一次性非经常性收益，不可持续。若未来原材料价格继续高位运行、行业“内卷”加剧，公司盈利能力改善将面临巨大挑战，需警惕其持续经营能力的不确定性。
