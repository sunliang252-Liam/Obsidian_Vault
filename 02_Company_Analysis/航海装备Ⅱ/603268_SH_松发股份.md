## 因果逻辑链
- **[重大资产重组完成，置入恒力重工]** -> [主营业务从陶瓷转型为船舶制造]: 公司通过资产置换及发行股份购买恒力重工100%股权，彻底剥离亏损陶瓷业务，切入高景气船舶赛道。
- **[全球船舶需求旺盛，公司产能快速释放]** -> [营收暴增274.95%至2163.92亿元]: 依托世界级船坞、龙门吊集群及节拍化生产，散货船、VLCC等主建船型批量交付，在手订单充足。
- **[发动机自主生产，产业链垂直整合]** -> [降低供应链风险，提升交付稳定性]: 公司具备年产180台、覆盖LNG/LPG/甲醇/氨双燃料发动机的能力，保障核心部件供应，优化成本结构。
- **[“大连+上海”双研发基地，技术突破]** -> [高附加值船型建造能力全面贯通]: 成功交付VLCC，开工LNG双燃料超大型集装箱船，并与法国GTT合作，成为国内第二家具备大型LNG船建造资质的民营船企。
- **[同一控制下企业合并，期初至合并日净损益计入非经常性损益]** -> [归母净利润265.46亿元，扣非净利润203.29亿元]: 两者差异主要源于置入资产恒力重工期初至合并日的当期净损益（5.23亿元）被计入非经常性损益。
- **[船舶建造行业特性，客户分期付款]** -> [合同负债大幅增长338.21%至53.54亿元]: 在手订单增加，客户按合同约定支付的进度款增加，形成大量预收款，但也推高了资产负债率。
- **[产能扩张与项目建设，资本性支出增加]** -> [投资活动现金流净额为-96.00亿元]: 为满足订单交付，公司持续投入绿色高端装备制造项目，导致投资活动现金大额流出。
- **[业务扩张，资金需求旺盛]** -> [筹资活动现金流净额164.06亿元]: 公司通过募集配套资金（39.99亿元）及增加银行借款等方式，为项目建设和日常经营提供资金保障。

## 风险警告
公司已从传统陶瓷企业彻底转型为高增长的船舶制造商，但需警惕造船行业固有的周期性与高杠杆风险。全球航运市场受地缘政治、贸易摩擦及运价波动影响显著，若行业景气度下行，公司当前饱满的订单和强劲的业绩增速可能面临拐点。同时，公司资产负债率极高，短期借款和长期借款大幅增加，叠加经营活动现金流持续为负（-145.77亿元），表明公司高度依赖外部融资维持运营，偿债压力巨大。

此外，公司业绩高度依赖恒力重工，其48亿元的三年累计业绩承诺（扣非净利润）尚在履行期，2025年仅完成257,880.48万元，后续两年能否达标存在不确定性。原材料（船用钢板）价格波动、汇率波动以及无法按时交船等经营风险，均可能对公司的盈利能力和现金流造成重大冲击。投资者需高度关注公司高负债运营下的财务健康度及行业周期逆转的风险。
