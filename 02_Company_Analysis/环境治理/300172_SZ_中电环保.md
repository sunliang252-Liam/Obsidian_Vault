# 300172.SZ 深度透视

## 因果逻辑链
- **[强化应收账款催收与现金流管理]** -> [净利润逆势增长]: 在营收下降14.44%的背景下，通过大力回收长账龄款项，使经营活动现金流净额大增60.73%，并带动信用减值损失转回，最终实现归母净利润增长10.16%。
- **[污泥耦合处理业务量价承压]** -> [营收结构恶化]: 污泥处理营收同比骤降34.95%，拖累整体营收下滑，但该业务毛利率仅15.99%，盈利能力弱，其收缩反而优化了整体盈利结构。
- **[烟气治理业务高增长]** -> [对冲主业下滑]: 烟气治理营收同比增长29.18%，成为唯一正增长的主业板块，部分弥补了水务和固废业务的收入缺口。
- **[在手订单充裕]** -> [未来收入有保障]: 期末在手合同金额高达30.35亿元（其中水处理19.97亿），为未来2-3年的收入确认提供了坚实基础。
- **[高分红率彰显股东回报]** -> [增强投资者信心]: 拟每10股派现1元，分红总额占净利润比例高达82.84%，远超往年，体现了公司回馈股东的意愿和现金流改善的底气。
- **[“一体两翼”战略深化]** -> [构建长期护城河]: 以水务、固废、烟气治理为“一体”，以国家级孵化器（左翼）和资本平台（右翼）为驱动，形成“技术+产业+资本”的闭环，强化了抗周期能力。

## 风险警告
**核心风险在于应收账款高企与回款周期拉长。** 尽管2025年现金流大幅改善，但应收账款余额仍高达6.89亿元，占总资产23.68%。公司客户主要为地方政府和大型国企，受地方财政压力影响，回款难度持续加大。一旦宏观经济下行或地方财政恶化，大额坏账风险将直接冲击利润表，并再次恶化现金流。

**另一重大风险是业务增长乏力与市场竞争加剧。** 公司核心主业“水环境治理”和“污泥耦合处理”营收均出现两位数下滑，新签合同额8.08亿元也低于往年。环保行业价格战激烈，公司虽在核电水处理等细分领域有优势，但整体市场空间释放缓慢。若不能在新兴赛道（如AI算力液冷、海外市场）取得突破，公司可能陷入增长停滞。此外，民生财富1,559.68万元私募基金逾期未兑付，也暴露了公司在非主业投资上的风控短板。
