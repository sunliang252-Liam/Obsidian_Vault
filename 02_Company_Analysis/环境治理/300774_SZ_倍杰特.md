# 300774.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧，项目成本上升]** -> [毛利率下滑]: 水处理解决方案毛利率同比下降8.85个百分点，导致整体盈利能力承压。
- **[研发投入大幅增加]** -> [净利润下滑]: 研发费用同比增长48.54%，主要用于盐湖提锂等新技术中试，直接侵蚀当期利润。
- **[收购大豪矿业55%股权]** -> [无形资产与商誉激增]: 无形资产同比暴增29.50个百分点至13.89亿元，商誉新增4520万元，资产结构发生重大变化。
- **[喀什BOT项目进入建设期]** -> [投资活动现金流大幅流出]: 投资活动现金流净额由正转负，同比减少303.88%，主要因项目建设及矿业收购支出。
- **[喀什项目贷款到账]** -> [筹资活动现金流大幅流入]: 筹资活动现金流净额同比增加179.97%，长期借款新增2.79亿元，财务杠杆显著提升。
- **[水处理解决方案收入下滑]** -> [营收整体微降]: 核心业务收入同比下降6.53%，尽管运营服务收入增长7.56%，仍无法完全对冲。
- **[非经常性损益大幅增加]** -> [归母净利润与扣非净利润差距拉大]: 非经常性损益达2386万元（主要为坏账转回），掩盖了主营业务盈利能力下滑的真相。

## 风险警告
**核心风险在于战略转型的“双刃剑”效应。** 公司从轻资产的环保技术服务商，通过大规模举债和现金收购，快速切入重资产的矿产资源开发领域。这导致资产结构急剧变化：无形资产（采矿权/探矿权）占比从8.98%飙升至38.48%，商誉新增4520万元。矿业项目从探矿到采矿、从建设到产出，周期长、投入大、不确定性高，短期内不仅无法贡献利润，反而将持续消耗公司现金流，并带来巨大的资产减值风险。

**主营业务盈利能力正在恶化。** 扣非净利润同比暴跌55.10%，核心的水处理解决方案毛利率大幅下滑8.85个百分点，表明公司在传统优势领域正面临激烈的价格战和成本压力。研发费用激增但短期内难以转化为收入，叠加应收账款高企（占总资产21.14%），公司经营质量堪忧。若矿业转型不及预期，公司将面临“主业失速、新业亏损”的双重困境。
