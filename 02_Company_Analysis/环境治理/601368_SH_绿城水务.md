# 601368.SH 深度透视

## 因果逻辑链
- **[精益管理降本增效]** -> [营业成本同比下降7.82%]: 通过优化工艺、精准投加药剂、参与电力市场化交易，直接材料、动力成本、维修维护费显著降低。
- **[LPR利率下调与负债结构优化]** -> [财务费用同比减少1.92%]: 把握低利率窗口发行低息债券，置换高息债务，有息负债综合融资成本下降。
- **[加强应收账款催收]** -> [经营活动现金流净额同比增长15.62%]: 加大污水处理服务费追收力度，回款改善，现金流质量提升。
- **[售水量与污水处理量增长]** -> [主营业务收入同比增长0.98%]: 通过“提存量、拓增量”策略，促进供排水业务量小幅增长，带动收入提升。
- **[在建工程大规模转固]** -> [折旧摊销费持续增长]: 五象水厂、石埠水厂等大型项目陆续投产，固定资产增加，折旧费用刚性上升。
- **[高资本开支与债务融资]** -> [总资产同比增长9.19%，有息债务规模扩大]: 为满足项目建设资金需求，公司持续举债，资产负债率维持高位。
- **[政府客户集中度高]** -> [单一客户销售占比57.64%]: 南宁市住建局是污水处理服务费的最大采购方，公司收入高度依赖单一政府客户。

## 风险警告
**核心风险在于高杠杆与低回报的失衡。** 公司总资产超255亿，但净资产仅48亿，资产负债率极高。为满足南宁市水务基建投资，公司持续大规模举债，导致财务费用高达4.63亿元，严重侵蚀利润。尽管2025年通过降本增效和利率下行实现了利润增长，但ROE仅2%，资产回报率极低。一旦利率环境逆转或融资渠道收紧，公司将面临巨大的偿债压力和财务风险。

**另一重大风险是收入与现金流的政策依赖性。** 公司超57%的收入来自南宁市住建局的污水处理服务费，且价格调整需经政府成本监审和漫长流程，存在调价滞后风险。同时，污水处理服务费结算周期长，导致应收账款高企，虽然2025年催收力度加大，但资金占用问题并未根本解决。公司盈利能力和现金流质量高度依赖地方政府的支付意愿和财政状况，缺乏市场化定价弹性。
