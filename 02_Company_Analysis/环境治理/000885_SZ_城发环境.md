# 000885.SZ 深度透视

## 因果逻辑链
- **战略并购与业务扩张** -> **营收结构优化，环卫业务跃升**: 收购傲蓝得环境等资产，使环境卫生服务收入同比大增79.21%，跃升为第二大收入来源，对冲了环保方案集成服务剥离带来的收入缺口。
- **存量项目精细化运营与供热改造** -> **固废处理量及供热收入增长**: 入场垃圾量同比增长3.95%，外供蒸汽量同比大增9.01%，通过热电联产转型提升了存量资产的综合收益。
- **融资结构优化与利率下行** -> **财务费用显著下降**: 成功发行低利率绿色债券及中期票据，财务费用同比减少10.15%，直接增厚了净利润空间。
- **应收账款专项攻坚** -> **经营活动现金流大幅改善**: 通过专项工作组和“一企一策”分类施策，回款效率提升，经营现金流净额同比飙升93.21%，达20.82亿元。
- **剥离低毛利环保集成业务** -> **归母净利润增长但扣非净利润下滑**: 出售沃克曼公司产生一次性非经常性收益，导致归母净利润增长8.29%，但扣非净利润同比下滑13.56%，显示核心运营利润承压。
- **“信阳模式”供排水一体化** -> **水处理业务收入与规模双增**: 供排水一体化模式在河南省内复制推广，供水量同比暴增144.45%，水处理业务收入增长33.95%。
- **高速公路车流量下滑** -> **通行费收入微降**: 受法定假期时长及雨雪天气影响，日均交通车流量同比下降5.93%，导致高速公路业务收入同比减少1.25%。

## 风险警告
**核心风险在于扣非净利润下滑与应收账款高企的双重压力。** 公司2025年归母净利润增长主要依赖出售子公司等非经常性损益，扣非净利润同比下滑13.56%，表明核心运营业务的盈利能力正在减弱。同时，应收账款高达51.49亿元，占总资产15.81%，且同比大幅增长34.2%，对经营性现金流构成持续威胁，地方财政支付能力的不确定性是主要隐患。

**行业竞争加剧与政策变动风险不容忽视。** 固废处理行业已进入存量博弈期，国补退坡、竞价上网等政策变化压缩项目利润空间。公司通过并购快速扩张，但整合效果及管理半径扩大带来的挑战尚待验证。此外，海外业务（如匈牙利项目）面临地缘政治、汇率波动及跨国合规等新风险，可能成为新的不确定性来源。
