# 300190.SZ 深度透视

## 因果逻辑链
- **[战略性收缩传统环保工程]** -> [营收下降19.89%]: 公司主动放弃低质量工程订单，导致环保工程收入同比骤降42.73%，拖累整体营收。
- **[聚焦生物能源转型]** -> [生物能源收入增长23.48%]: 生物天然气、生物燃油等新业务成为唯一增长板块，但多数项目仍处建设期，尚未贡献利润。
- **[加大回款与资产处置]** -> [经营性现金流净额增至4.29亿元]: 通过法律催收及出售敦化中能等非核心资产，有效回笼资金，现金流连续两年改善。
- **[人员优化与成本管控]** -> [亏损大幅收窄52.52%]: 尽管营收下滑，但通过降本增效，归母净利润从-7.36亿缩至-3.50亿，经营质量边际改善。
- **[可转债持续转股]** -> [股本扩张至8.16亿股]: 年内多次下修转股价至3.55元，驱动大规模转股，缓解债务压力但稀释每股收益。
- **[商誉与资产减值]** -> [持续侵蚀利润]: 历史并购形成的10.47亿商誉已计提7.12亿减值，剩余3.35亿仍面临减值风险，是亏损主因之一。
- **[应收账款高企]** -> [坏账风险累积]: 应收账款余额高达20.84亿，占总资产31.46%，坏账准备计提比例27.09%，回款周期拉长构成流动性隐患。

## 风险警告
**核心风险在于转型阵痛与历史包袱的叠加。** 公司战略性收缩传统环保工程导致营收大幅下滑，而生物天然气、生物燃油等新业务尚处投入期，短期内无法弥补缺口，业绩仍将承压。更关键的是，历史并购形成的巨额商誉（剩余3.35亿）和应收账款（超20亿）如同悬顶之剑，减值风险并未出清，随时可能再次冲击利润表。

**财务健康度面临严峻考验。** 公司已连续三年扣非净利润为负，未分配利润赤字扩大至-6.45亿，且可转债信用评级展望为“负面”。尽管现金流有所改善，但主要依赖资产处置和催收，而非主营业务造血。若新业务规模化不及预期或回款恶化，公司可能面临流动性危机与持续经营能力的质疑。
