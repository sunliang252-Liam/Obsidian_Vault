## 因果逻辑链
- **[在手订单集中交付]** -> [营业收入同比+83.47%]: 2025年公司多个在手重大项目（如深圳福田、深圳章阁、广州番禺等）进入设备供货及安装验收阶段，推动收入大幅增长。
- **[收入规模效应+精细化管理]** -> [归母净利润扭亏为盈]: 营收大幅增长摊薄固定成本，同时管理费用同比减少972.84万元，共同推动净利润由-5038万转为+1080万。
- **[收到重点项目预付款]** -> [经营性现金流净额同比+55.66%]: 白龙港等大型项目合同预付款到账，使经营活动现金流净额达1.4亿元，显著改善现金流状况。
- **[扣非净利润仍为负]** -> [盈利质量依赖非经常性损益]: 扣非净利润为-738万元，显示主营业务尚未实现稳定盈利，利润主要来自理财收益（1051万）和政府补助（952万）。
- **[绿色燃料中试突破]** -> [战略转型取得关键里程碑]: 公司牵头“沼气制绿色甲醇”项目于2026年1月打通千吨级中试全流程并获ISCC双认证，标志从环保装备向绿色能源赛道延伸取得实质性进展。
- **[高温水源热泵技术落地]** -> [节能降碳装备形成差异化竞争力]: 热泵技术已在虹桥、福田等项目规模化应用，能效比达2.85，显著降低污泥干化能耗与成本，构筑技术壁垒。
- **[海外滤板销售突破千万]** -> [全球化战略初现成效]: 依托浙江复洁制造能力，2025年海外出口销售额突破千万元，为公司打开第二增长曲线。
- **[应收账款坏账准备转回]** -> [对当期利润形成正向贡献]: 收回部分长账龄应收账款，冲回坏账准备580.16万元，直接增厚当期利润。

## 风险警告
**核心风险在于盈利的可持续性与真实性。** 公司2025年归母净利润虽扭亏为盈，但扣非净利润仍为-738万元，盈利高度依赖理财收益（1051万）和政府补助（952万）等非经常性损益。主营业务毛利率虽回升至28.71%，但绝对规模仅3.4亿元，尚不足以覆盖期间费用（管理费用+研发费用合计超9000万），主业造血能力依然薄弱。若未来非经常性收益减少，公司可能再次陷入亏损。

**应收账款与地方财政风险是长期隐患。** 公司客户以地方水务国企为主，项目规模大、结算周期长。在地方财政普遍承压的背景下，应收账款回收存在较大不确定性。虽然2025年通过收回长账龄款项改善了利润，但截至年末应收账款余额仍处高位，若未来出现重大项目回款长期滞后或客户信用恶化，将直接冲击公司现金流和利润表。此外，BOT项目初始投资大、资金占用周期长，进一步加剧了资金链压力。
