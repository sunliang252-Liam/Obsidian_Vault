# 600874.SH 深度透视

## 因果逻辑链
- **[政府支付历史欠款]** -> [经营活动现金流暴增138.95%]: 天津市水务局一次性支付19.89亿元历史应收账款，极大改善现金流，但属一次性事件。
- **[贷款置换与利率调整]** -> [财务费用下降16.43%]: 公司主动进行低成本融资置换，有效压降利息支出，提升利润空间。
- **[应收账款减值转回]** -> [信用减值损失减少36.85%]: 收回天津城投等大额欠款，导致前期计提的坏账准备转回，直接增厚利润。
- **[危废项目商誉减值已提足]** -> [资产减值损失归零]: 上年同期大额商誉减值（-1.48亿）不再发生，是本年度利润增长的重要非经常性因素。
- **[污水处理业务量价承压]** -> [营收微降1.40%]: 部分特许经营项目结算水量减少及再生水工程收入下降，拖累整体营收表现。
- **[“N维一体”战略新业务扩张]** -> [供冷供热/光伏储能收入增长]: 新能源业务（服务面积696万平米、光伏35MWp）成为第二增长曲线，但尚处培育期，对利润贡献有限。
- **[集采与精细化运营]** -> [管理费用下降2.93%]: 通过集中采购（年省1000万）和成本诊断，有效对冲了人工、能源等成本上涨压力。

## 风险警告
**核心风险在于对政府信用的高度依赖与应收账款回收的不确定性。** 公司污水处理服务费主要来源于政府财政，尽管2025年一次性收回19.89亿历史欠款，但长期应收款仍高达35.5亿元，占净资产34.6%。若地方政府财政压力加剧，服务费延期支付将直接冲击公司现金流，并可能引发财务费用攀升和坏账风险。公司“提质增效”的根基并不稳固。

**战略转型的投入产出比存在不确定性。** 公司正从传统水务向“新能源+固废+资源化”的综合环境服务商转型，但新业务（危废、新能源）毛利率波动剧烈（危废毛利率为-26%），且部分项目（如郯城危废、恩施/赤壁污水处理项目）已终止。大量资本开支（咸阳路二期投资6亿）与研发投入（1.28%营收）能否转化为可持续的利润增长，尚待验证。
