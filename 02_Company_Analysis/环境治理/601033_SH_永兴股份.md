# 601033.SH 深度透视

## 因果逻辑链
- **[广州市财政支付能力]** -> [应收账款高企]: 公司主要客户为广州市政府，业务依赖政府采购服务模式，导致应收账款达27亿元，同比增长40.6%，资金周转效率承压。
- **[垃圾处理量增长]** -> [营收增长13.88%]: 全年垃圾进厂总量1,096.43万吨，叠加存量垃圾掺烧约160万吨，直接推动项目运营收入增至42.25亿元。
- **[贷款平均利率下降]** -> [财务费用减少16.39%]: 公司通过债务结构优化，使利息费用从3.68亿元降至2.90亿元，有效对冲了业务扩张带来的融资需求。
- **[洁晋公司并表]** -> [管理费用与研发费用双增]: 收购洁晋公司90%股权后，管理费用增长9.28%，研发费用增长16.63%，反映外延扩张带来的整合成本。
- **[大额存单到期收回]** -> [投资活动现金流改善]: 收回5.45亿元大额存单本金及利息，使投资活动现金净流出从-11.71亿元大幅收窄至-5.26亿元。
- **[电价补贴政策不确定性]** -> [盈利结构脆弱]: 公司享受的环保电价补贴及税收优惠（三免三减半、高新技术企业所得税）若调整，将直接冲击净利润，当前净利润对政策依赖度高。
- **[供热业务拓展]** -> [“焚烧+”模式落地]: 报告期内对外供热约21万吨，移动储能供热项目投运，标志着公司从单一发电向热电联产综合能源服务转型，开辟新增长曲线。

## 风险警告
**核心风险：应收账款回收与政策依赖的双重挤压。** 公司应收账款高达27亿元，占营收比重63%，且主要来自单一客户（广州市政府）。若地方财政支付能力下降或结算周期拉长，将严重侵蚀现金流，甚至引发坏账风险。同时，公司利润高度依赖电价补贴、增值税即征即退及所得税“三免三减半”等优惠政策，任何政策退坡都将导致净利润大幅波动，盈利基础脆弱。

**扩张风险：外延并购整合与资本开支压力。** 公司通过收购洁晋公司等实现区域扩张，但收购后管理费用、研发费用同步攀升，且洁晋公司报告期内亏损1,305万元，整合效果尚待验证。此外，在建工程激增1,944%至4.22亿元，叠加长期借款高达92.62亿元，资产负债率55.72%，未来资本开支与偿债压力并存，若新项目产能利用率不及预期，将拖累整体ROE。
