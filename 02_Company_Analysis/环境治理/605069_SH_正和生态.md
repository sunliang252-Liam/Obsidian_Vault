# 605069.SH 深度透视

## 因果逻辑链
- **[战略转型聚焦北京生态水利]** -> [收入规模暂未释放]: 公司从全国性业务收缩至北京区域，水利项目周期长，前期投入尚未转化为当期收入，导致营收增长停滞。
- **[分包模式拉低毛利率]** -> [营业成本激增37%]: 为满足北京水利项目资质和业绩要求，采用分包模式，导致营业成本增速远超营收，综合毛利率由正转负至-19.56%。
- **[地方财政审计导致结算审减]** -> [利润承压]: 存量项目在结算过程中，受地方财政审计影响，发生收入审减，直接侵蚀当期利润。
- **[大额应收账款诉讼回款滞后]** -> [现金流改善但利润未同步]: 对唐山、太原、莆田等大额欠款启动司法程序，回款周期拉长，尽管全年回款6.83亿元，但坏账准备计提压力仍大。
- **[财务费用翻倍]** -> [侵蚀利润]: 子公司建设期利息收入未确认，叠加融资成本，财务费用同比大增107%，成为亏损扩大的重要因素。
- **[信用减值损失大幅转回]** -> [亏损收窄]: 得益于应收账款回收增加，信用减值损失同比大幅减少，是2025年亏损较2024年收窄6.33%的核心原因。
- **[智能科技业务尚处孵化期]** -> [短期无法贡献利润]: 河湖海洋大模型、水务机器人等业务仍处于试点验证阶段，研发投入增加但尚未商业化，对当期业绩无贡献。

## 风险警告
**核心风险在于战略转型的“青黄不接”与现金流黑洞。** 公司放弃全国市场，孤注一掷聚焦北京生态水利，但水利项目周期长、前期投入大，导致收入规模无法释放，毛利率急剧恶化。同时，公司严重依赖单一客户（金河水务占销售额97.55%），业务独立性存疑，且大量资产（长期应收款、应收账款）被质押用于借款，财务弹性极低。

**第二大风险是应收账款回收的“持久战”。** 公司手握大量政府及平台公司欠款，虽已启动诉讼，但司法程序漫长，且地方化债政策优先解决小额欠款，公司的大额应收账款（如唐山2.7亿、太原4.22亿）回收时间高度不确定。母公司未分配利润已巨亏-5.4亿元，持续亏损将快速消耗净资产，若回款不力，公司资金链将面临严峻考验。
