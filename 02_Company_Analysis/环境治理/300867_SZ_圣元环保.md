# 300867.SZ 深度透视

## 因果逻辑链
- **[炉渣资源化利用提价]** -> [净利润+36.30%]: 公司对旗下电厂炉渣重新招标，平均处置单价显著提升，直接转化为利润增量，是2025年业绩超预期增长的核心驱动力。
- **[应收账款清收攻坚]** -> [经营现金流+63.82%]: 成立专项催收小组，垃圾处理费回收率显著提升，叠加增值税退税增加，使经营现金流净额达8.28亿元，远超净利润。
- **[存量项目精细化运营]** -> [毛利率+3.07%]: 在营收微降1.66%的背景下，通过技改升级、AI智慧焚烧试点及成本管控，使综合毛利率逆势提升至43.32%。
- **[国补目录清单未获批]** -> [营收承压]: 截至报告期末，仍有8个已投产项目（5,450吨/日）未进入国补目录，导致相关国补收入无法确认，是营收同比下降1.66%的主因。
- **[牛磺酸大健康产业投入]** -> [销售费用激增+1340%]: 为打造第二增长曲线，公司提前布局牛磺酸终端产品市场，导致销售费用从93万飙升至1339万，但新业务尚处培育期，对当期利润贡献有限。
- **[债务结构优化]** -> [财务费用-16.57%]: 通过偿还高息贷款及置换低利率贷款，有效降低了融资成本，财务费用减少约3100万元，直接增厚了净利润。
- **[出售污水处理资产]** -> [聚焦主业与回笼资金]: 公司以3.82亿元出售圣泽环境及龙海水务100%股权，旨在盘活存量资产，为牛磺酸等新产业提供资金，但交易尚需政府批准。

## 风险警告
**核心风险在于国补政策的不确定性。** 公司仍有8个已投产项目（占运营产能近半）未进入国补目录，导致巨额国补收入无法确认。一旦未来政策收紧或申报受阻，将直接冲击公司盈利能力和现金流预期。此外，南安圣元一期国补已到期，预示着补贴退坡的长期压力正在显现。

**第二增长曲线尚处“烧钱”阶段。** 公司全力押注的牛磺酸大健康产业，年产4万吨原料项目仍在建设，下游产品市场开拓导致销售费用激增13倍，但收入贡献微乎其微。该业务面临投产不及预期、市场竞争激烈及品牌培育周期长等多重风险，短期内难以对冲主业下行压力，反而可能成为新的资金“失血点”。
