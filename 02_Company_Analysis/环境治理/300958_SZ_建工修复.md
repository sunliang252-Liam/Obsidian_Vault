# 300958.SZ 深度透视

## 因果逻辑链
- **[主动战略收缩]** -> [收入下降28.59%]: 公司主动放弃低质量项目，优先承接资金保障优、技术示范性强的项目，导致订单数量和收入暂时下滑。
- **[业主付款周期长]** -> [信用减值损失增加]: 项目体量大，业主验收及付款审批流程严格，导致收入确认与现金回笼存在时滞，基于审慎性原则计提的信用减值损失增加，阶段性侵蚀利润。
- **[强化应收账款催收]** -> [经营性现金流转正]: 公司多措并举加强收款清欠，2025年经营性净现金流成功扭转此前持续为负的局面，实现37,776,752.31元。
- **[布局新增长曲线]** -> [业务多元化格局初步形成]: 在巩固污染场地治理传统优势的同时，积极拓展固危废资源化利用、农用地健康提升等新兴业务，新业务收入占比稳步提升。
- **[固废资源化业务突破]** -> [打开第二增长曲线]: 磷石膏、赤泥、油泥等大宗固废资源化业务取得实质性进展，累计处理消纳磷石膏逾3400万吨，为公司注入新动能。
- **[研发投入持续]** -> [技术壁垒加固]: 研发投入占营收比例提升至6.02%，多项技术获省部级奖项，新授权发明专利18项，巩固行业技术领先地位。
- **[行业竞争加剧]** -> [利润空间受挤压]: 行业进入高质量发展阶段，新竞争者入局，市场竞争加剧，行业整体利润空间受到阶段性挤压。

## 风险警告
**核心风险在于应收账款回收与信用减值。** 公司客户以政府及国企为主，但项目体量大、验收付款周期长，导致应收账款高企（占总资产28.52%）。尽管2025年回款改善，但长账龄项目及历史遗留问题仍构成重大坏账风险，是影响利润的最大不确定因素。公司已启动诉讼程序，但执行效果有待观察。

**第二风险是战略转型的阵痛期。** 公司主动收缩规模、转向高质量项目，导致收入与利润短期承压（2025年亏损8418万元）。新业务（固废资源化、农田治理等）尚处培育期，收入贡献有限，未能完全弥补传统业务下滑的缺口。若新业务增长不及预期，公司可能面临业绩持续低迷的风险。
