# 601199.SH 深度透视

## 因果逻辑链
- **[工程业务收入大幅下滑]** -> [总营收同比下降4.87%]: 工程安装业务收入同比减少15.72%，是拖累整体营收的核心因素，主要因管网改造、新建小区等工程订单减少。
- **[水资源税改革推高水价]** -> [自来水业务营收逆势增长2.66%]: 尽管供水量下降1.52%，但水资源费改税导致平均综合售水单价上升，使自来水业务收入实现正增长。
- **[工程业务成本降幅大于收入]** -> [整体毛利率提升至38.23%]: 工程业务成本同比下降18.62%，降幅超过收入降幅15.72%，带动整体毛利率同比增加3.22个百分点。
- **[新签合同额爆发式增长]** -> [未来收入增长潜力巨大]: 报告期内新签合同金额累计突破10.78亿元，同比增长209.43%，为后续工程业务收入恢复提供充足订单储备。
- **[污水处理折旧大幅增加]** -> [污水处理业务毛利率骤降至0.55%]: 南闸污水厂改扩建项目竣工，折旧费用同比增加476.95万元，导致污水处理成本增速远超收入，毛利率同比大降14.42个百分点。
- **[联营企业投资收益贡献显著]** -> [扣非净利润降幅大于净利润]: 对江阴农商行按权益法核算确认投资收益1.18亿元，若剔除该影响，扣非净利润同比减少16.62%，显示主业盈利能力下滑。
- **[供排水一体化战略落地]** -> [排水业务收入同比增长17%]: 公司深化“厂网一体”改革，拓展污水厂委托运营业务，该板块收入同比大增133.95%，成为新的增长点。

## 风险警告
**核心风险在于工程业务收入持续下滑与污水处理业务盈利恶化。** 工程业务是公司第二大收入来源，但2025年收入同比大降15.72%，且公司业务高度集中于江阴本地，区域经济波动或基建投资放缓将直接冲击业绩。同时，污水处理业务因改扩建项目投产导致折旧激增，毛利率已逼近盈亏平衡点，若后续提价或产能利用率无法提升，该板块将持续拖累利润。

**财务风险在于现金流与盈利能力的背离。** 尽管净利润下降，但经营活动现金流净额仍为正，且投资活动现金流因无大额收购而大幅改善。然而，公司有息负债规模稳定（约6.68亿元），但利息保障倍数同比下降，叠加工程业务回款周期可能拉长，需警惕未来资金周转压力。此外，公司对江阴农商行的投资收益贡献巨大，若该行经营波动，将显著影响公司整体利润。
