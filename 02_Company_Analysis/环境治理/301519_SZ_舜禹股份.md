# 301519.SZ 深度透视

## 因果逻辑链
- **[地方政府支付能力减弱]** -> [营收下降11.30%]: 公司主动提高客户筛选标准，减少投资性项目承接，导致新增订单放缓，二次供水及污水处理业务收入均下滑。
- **[客户付款延期，回款周期拉长]** -> [信用减值损失激增]: 应收账款账龄延长，计提的减值损失大幅增加，成为吞噬利润的主要因素（占利润总额189%）。
- **[银行贷款增加]** -> [财务费用上升27.59%]: 为补充营运资金，公司增加银行借款，利息支出显著增长，进一步压缩利润空间。
- **[政府补助减少]** -> [非经常性损益大幅下降]: 计入当期损益的政府补助从1345万降至111万，导致归母净利润由正转负。
- **[研发持续高投入]** -> [研发费用率提升至4.95%]: 尽管营收下滑，公司仍维持研发投入强度，占营收比重上升，短期对利润形成压力。
- **[省外市场拓展]** -> [省外收入暴增264%]: 公司主动开拓省外市场，省外收入占比从9.93%跃升至40.78%，有效对冲了省内市场的下滑。
- **[污水处理项目运营收入增长]** -> [业务结构优化]: 污水处理项目运营收入同比增长40.25%，毛利率高达60.16%，成为利润的重要稳定器。

## 风险警告
公司面临的核心风险是**地方政府信用与支付能力恶化**。作为主要客户，地方政府的财政紧张直接导致公司回款周期延长、应收账款高企（18.05%的资产占比），并迫使公司主动放弃部分订单，导致营收与利润双杀。2025年归母净利润由盈转亏（-2699万元），信用减值损失高达6055万元，是亏损的主因。若地方政府资金状况无法改善，公司业绩将持续承压。

另一个关键风险是**业务转型与扩张的阵痛**。公司正从传统设备销售向“设备+运营+智慧化”综合服务商转型，省外市场拓展虽快但毛利率下降22.23个百分点，显示新市场开拓成本较高。同时，公司资产负债率上升，短期借款激增，财务费用大幅增长，若新业务（如直饮水、EOD项目）无法快速贡献利润，公司现金流和盈利能力将面临严峻考验。
