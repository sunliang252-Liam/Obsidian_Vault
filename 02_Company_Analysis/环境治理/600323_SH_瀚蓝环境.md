# 600323.SH 深度透视

## 因果逻辑链
- **[并购粤丰环保]** -> [规模与利润双增]: 2025年6月并表，贡献归母净利润约2.7亿元，垃圾焚烧总产能跃居A股首位，规模效应与协同价值开始释放。
- **[供热业务扩张]** -> [固废运营收入增长]: 对外供热205.76万吨（+38.81%），收入3.13亿元（+47.76%），成为固废业务除发电外的重要增长极。
- **[降本增效与资金管理]** -> [财务费用优化]: 通过贷款置换、集中采购、智能化改造，粤丰环保人民币融资利率从2.75%-4.75%降至2.00%-3.785%，集团整体财务费用得到控制。
- **[可再生能源补贴回收改善]** -> [现金流增强]: 报告期内收回补贴约3.26亿元，叠加粤丰并表贡献，经营活动现金流净额达40.18亿元（+22.77%）。
- **[“一体两翼”业务结构]** -> [抗风险能力]: 固废为核心，水务能源协同，各板块资源共享，有效对冲了工程业务收入下降及能源业务波动的风险。
- **[绿证与碳资产开发]** -> [新利润增长点]: 2025年绿证销售超1,317万张，有效期内可交易绿证超348万张，绿色权益变现能力增强。
- **[高分红承诺]** -> [股东回报提升]: 2025年度累计每股分红1.05元（+31.25%），并承诺2026年每股分红不低于1.155元，强化价值投资逻辑。

## 风险警告
**高杠杆与财务风险**：并购后资产负债率攀升至70.15%（+8.87个百分点），总负债规模大幅增加。尽管通过贷款置换降低了部分利率，但巨额有息负债（含约61亿并购贷）带来的财务费用压力（同比+59%）将持续侵蚀利润。若未来融资环境收紧或利率上行，财务风险将显著放大。同时，应收账款高达83.37亿元（+96.08%），政府支付周期延长问题未根本改善，对现金流构成潜在压力。

**整合与管理风险**：并购粤丰环保后，公司子公司数量超200家，管理半径急剧扩大。虽然已启动组织架构调整（设立固废事业群），但文化融合、业务协同、制度落地等深度整合尚需时间。若整合效果不及预期，规模效应无法充分释放，将导致管理成本上升、运营效率下降，甚至出现“大而不强”的局面。此外，海外业务（泰国项目）及AIDC等新业务探索均存在不确定性，可能分散管理精力。
