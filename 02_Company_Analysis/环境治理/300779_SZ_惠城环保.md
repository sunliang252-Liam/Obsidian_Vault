# 300779.SZ 深度透视

## 因果逻辑链
- **[废塑料化学循环项目（CPDCC）]** -> [净利润增长38.76%]: 全球首套20万吨/年混合废塑料资源化项目进入试生产，初步实现收益，成为利润新增长点。
- **[高硫石油焦制氢灰渣综合利用项目]** -> [稳定利润支柱]: 全国首套、技术独占性项目持续稳定运行，贡献可预期的现金流与利润，但处置单价因结算模式变化有所下降。
- **[催化剂业务海外拓展]** -> [境外收入激增606%]: 国内催化剂市场存量竞争，公司大力开拓东南亚、中东等海外市场，境外收入从1118万跃升至7898万，有效对冲国内周期波动。
- **[客户高度集中]** -> [收入依赖单一客户]: 前五大客户销售占比77.59%，其中中国石油占比60.13%，石油焦制氢灰渣业务主要依赖广东石化，存在单一客户依赖风险。
- **[大规模资本开支与项目建设]** -> [经营现金流大幅转负]: 在建工程同比增加67.8%至19.2亿，导致经营活动现金流净额从+1.57亿骤降至-1.93亿，财务费用因融资规模增长同比增加27.5%。
- **[应收账款与存货双增]** -> [营运资金压力加大]: 应收账款同比增加124%至5.98亿（客户回款延期），存货同比增加58.4%至5.96亿（新建项目储备原料），两者合计占用资金超11亿。
- **[定增募资8.5亿]** -> [优化资本结构支撑扩张]: 成功完成向特定对象发行股票，资金投向固废处理项目并补充流动资金，缓解了高资产负债率下的资金压力。

## 风险警告
**现金流断裂风险是当前最核心的威胁。** 公司正处于“烧钱”扩张期，20万吨废塑料项目、多个在建工程及募投项目同步推进，导致2025年经营活动现金流净额为-1.93亿元，而投资活动现金净流出高达-9.39亿元。尽管通过定增和借款筹资，但资产负债率已攀升至较高水平，财务费用同比大增27.5%。若新项目无法如期满产达效并产生正向现金流，公司将面临严峻的偿债和流动性压力。

**技术商业化与客户依赖构成双重不确定性。** 公司引以为傲的废塑料化学循环（CPDCC）技术虽通过性能考核，但全球尚无大规模商业化先例，技术放大、原料供应（需构建全国回收网络）及市场接受度均存在不确定性。同时，公司近八成收入来自前五大客户，其中石油焦制氢灰渣业务几乎完全依赖广东石化单一客户，任何合作模式或采购量的变化都将对业绩造成重大冲击。
