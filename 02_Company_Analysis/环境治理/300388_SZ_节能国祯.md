# 300388.SZ 深度透视

## 因果逻辑链
- **[行业进入存量运营期]** -> [营收下降]: 新建项目减少，工程建造服务收入同比下降10.11%，拖累整体营收下滑4.30%。
- **[运营服务收入增长]** -> [业绩基本盘稳固]: 运营服务收入同比增长1.82%至24.99亿元，占比提升至68.06%，成为收入核心支柱。
- **[融资成本下降]** -> [财务费用减少]: 平均融资成本下降，财务费用同比减少1303万元，部分对冲了营收下滑对利润的侵蚀。
- **[应收账款高企]** -> [资产减值损失扩大]: 受地方政府财政紧张影响，应收账款增至38.86亿元，导致资产减值损失高达1.29亿元，严重侵蚀利润。
- **[工业废水业务收缩]** -> [收入结构变化]: 工业废水处理综合服务收入同比骤降36.38%，主要因大型工业项目订单减少。
- **[设备制造业务下滑]** -> [产业链协同减弱]: 设备制造销售及服务收入同比大降47.51%，反映公司内部工程需求减少及外部市场拓展乏力。
- **[研发人员大幅减少]** -> [长期技术储备隐忧]: 研发人员数量同比减少48.78%，研发投入占营收比仅0.66%，可能影响未来技术竞争力。

## 风险警告
**最大风险是应收账款与资产减值的恶性循环。** 公司应收账款高达38.86亿元，占总资产22.27%，且仍在增长。地方政府财政紧张导致运营费回收滞后，公司不得不计提1.29亿元资产减值损失，这已成为侵蚀利润的最大黑洞。若回款环境持续恶化，减值压力将进一步加剧，直接冲击净利润。

**第二重风险是行业转型期的增长失速。** 公司传统工程建造业务持续萎缩（-10.11%），工业废水业务大幅下滑（-36.38%），而新增长点尚未形成。尽管运营业务稳健，但增速仅1.82%，难以弥补其他板块的缺口。在环保行业从“增量扩张”转向“存量优化”的背景下，公司面临业务结构调整的阵痛期，未来增长动力不足。
