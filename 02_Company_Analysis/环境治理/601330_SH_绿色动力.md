# 601330.SH 深度透视

## 因果逻辑链
- **[供汽量近翻倍增长]** -> [营收与毛利双增]: 供汽量同比+98.81%至112.05万吨，直接拉动非电收入，使营收增速(3.97%)远超成本增速(1.62%)，毛利率提升1.23个百分点。
- **[财务费用下降14.73%]** -> [利润增速高于营收]: 通过贷款置换降低利率及减少借款余额，利息费用节省约6591万元，直接增厚归母净利润，使利润增速(5.54%)高于营收增速。
- **[国补与垃圾处理费回款改善]** -> [经营性现金流大增28.32%]: 应收账款回收力度加大，叠加供热收入现金回流，经营现金流净额达18.46亿元，为净利润的2.99倍，现金流质量显著优化。
- **[无新增项目投产]** -> [运营指标内生增长]: 在运营规模不变前提下，垃圾处理量+2.41%、上网电量+2.31%，证明存量项目通过精细化运营和垃圾拓展实现了产能利用率提升。
- **[集中采购与精细化管理]** -> [成本端有效控制]: 环保耗材集中采购单价下降、柴油单耗降低，材料费同比-14.85%，部分对冲了大修费用(+61.05%)的上升压力。
- **[污泥协同处置与热电联产]** -> [多元化收入结构]: 13个项目实现污泥处置，13个项目对外供热供汽，从单一发电向综合能源服务商转型，降低对国补电价的单一依赖。
- **[葫芦岛危废项目减值]** -> [资产减值损失扩大]: 对葫芦岛危废公司计提大额减值，导致资产减值损失从1.27亿增至2.05亿，是利润表中最主要的负面拖累项。

## 风险警告
**核心风险在于国补退坡与应收账款的双重挤压。** 公司约24%的利润总额依赖税收优惠，而国补仅覆盖并网后前15年或82,500小时，存量项目正陆续进入补贴到期窗口。同时，尽管2025年回款改善，但应收账款仍高达26.23亿元（占总资产12%），且合同资产（未纳入补贴目录的国补应收）增长30%，地方政府财政压力下结算周期延长是长期隐忧。

**第二重风险来自资产减值与资本开支的错配。** 葫芦岛危废项目的减值暴露了公司多元化扩张中的风控短板。与此同时，公司资产负债率仍达60.45%，有息负债超83亿元，大量资产（约106亿元）用于质押借款，财务弹性受限。在行业从增量扩张转向存量运营的背景下，若后续并购或海外项目再遇类似减值，将对利润和资产负债表造成显著冲击。
