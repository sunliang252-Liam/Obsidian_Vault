# 301109.SZ 深度透视

## 因果逻辑链
- **[并购仁和环境]** -> [营收与利润双增]: 2024年11月完成对仁和环境的并购，全面纳入合并报表，带来餐厨垃圾处理、工业级混合油销售等新业务，驱动2025年营收同比增长13.05%，归母净利润同比增长33.62%。
- **[吨垃圾上网电量行业第一]** -> [运营效率领先]: 公司长沙黑麋峰园区2024年吨垃圾平均上网电量全国第一，通过技术研发与精细化管理提升发电效率，直接增厚垃圾焚烧发电业务利润。
- **[海外项目落地投产]** -> [打开第二增长曲线]: 吉尔吉斯比什凯克一期项目（1000吨/日）于2025年12月投运，成为中亚地区首个运营的中国固废项目，叠加奥什、伊塞克湖、阿拉木图等项目储备，海外总规划规模达9000吨/日，为公司提供长期增长空间。
- **[固废综合协同处理模式]** -> [降本增效]: 公司长沙黑麋峰园区实现垃圾焚烧、污泥、餐厨、渗滤液等协同处置，共享设施、以废治废，显著降低运营成本，提升系统稳定性与环保效益。
- **[高分红与回购]** -> [强化股东回报]: 近三年平均派息率超70%，2025年发布2-3亿元回购计划，并被纳入中证红利指数，吸引价值投资者，支撑股价与市值。
- **[研发投入持续高增]** -> [技术壁垒巩固]: 2025年研发投入8986万元（同比+40.82%），取得481项专利，在焚烧效率、飞灰资源化、餐厨提油率等关键指标上保持行业领先，构筑长期护城河。
- **[客户集中度高]** -> [经营风险集中]: 前五大客户销售额占比92.40%，其中长沙市城管局和国网湖南电力合计占比超82%，对单一区域和客户依赖度极高，议价能力与回款节奏受制于地方政府财政。

## 风险警告
**客户与区域高度集中，应收账款风险不容忽视。** 公司超92%收入来自前五大客户，其中长沙市城管局与国网湖南电力占比超82%。若地方政府财政压力加大，导致垃圾处理费或电价补贴支付延迟，将直接冲击公司现金流与利润。尽管公司回款记录良好，但这一结构性风险无法通过分散化经营在短期内化解。

**电价补贴退坡与固废处理费下调是长期隐忧。** 国内垃圾焚烧发电项目正面临竞价上网与补贴退坡的政策趋势，公司新项目将不再享受0.65元/度的标杆电价。同时，特许经营协议中的调价机制若执行滞后，或政府主动下调处理单价，将直接压缩项目盈利空间。公司虽通过技术降本对冲，但无法完全抵消政策风险。

**海外项目执行存在地缘政治与运营不确定性。** 公司在中亚地区（吉尔吉斯、哈萨克斯坦）的海外项目规模达9000吨/日，但当地政治稳定性、政策连续性、汇率波动及文化差异均构成潜在风险。比什凯克一期虽已投运，但后续项目的推进速度与盈利能力仍需持续验证，海外扩张的投入产出比存在较大不确定性。
