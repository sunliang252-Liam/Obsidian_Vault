# 000776.SZ 深度透视

## 因果逻辑链
- **[市场交投活跃度大幅提升]** -> [手续费及佣金净收入增长28.27%]: 2025年A股沪深股基成交额同比激增70.39%，直接驱动公司经纪、投行等手续费收入显著增加。
- **[债券及衍生品投资规模扩张]** -> [交易性金融资产增长49.24%]: 公司主动增加债券等金融资产投资，叠加公允价值变动收益由负转正（+53.79亿），成为利润增长的核心引擎。
- **[融资融券业务规模扩张]** -> [融出资金增长32.20%]: 市场回暖带动客户融资需求上升，公司两融余额市占率稳定在5.47%，贡献了稳定的利息收入。
- **[财富管理转型深化]** -> [代销金融产品保有规模增长42.65%]: 买方投顾转型见效，解决方案保有规模大幅增长，推动财富管理业务收入增长28.32%。
- **[国际化业务纵深推进]** -> [境外子公司收入增长99.85%]: 港股市场活跃及跨境业务布局深化，广发控股香港等境外子公司业绩大幅提升，成为新的增长点。
- **[公募基金行业规模增长]** -> [投资管理业务收入增长21.63%]: 控股的广发基金与参股的易方达基金规模持续领先，管理费收入增加，贡献稳定利润。
- **[股权融资市场回暖]** -> [投行业务收入增长14.05%]: A股IPO及再融资规模同比大幅增长，公司抓住机遇，股权承销规模提升，但整体收入贡献相对有限。

## 风险警告
**核心风险在于业绩对市场行情的高度依赖。** 2025年归母净利润42.18%的爆发式增长，主要源于市场交投活跃度（股基成交额+70%）和自营投资公允价值变动（+53.79亿）的驱动。一旦市场情绪降温、成交量萎缩或利率环境逆转，公司业绩将面临显著的下行压力，高弹性也意味着高波动。

**信用与合规风险是长期隐患。** 公司股票质押式回购业务余额虽下降23.19%，但存量风险仍需关注。同时，报告期内计提的预计负债同比暴增2280%，反映出潜在的诉讼或监管处罚风险。在“强监管”环境下，合规风险事件可能对品牌声誉和业务开展造成实质性冲击。
