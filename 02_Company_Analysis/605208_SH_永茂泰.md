# 605208.SH 深度透视

## 因果逻辑链
- **[铝液直供模式扩张]** -> [营收增长42.61%]: 宁波杭州湾项目满产、新客户拓展，铝液销量同比增80.47%，带动铝合金业务收入增长46.78%。
- **[规模效应释放]** -> [归母净利润增长79.96%]: 铝合金及零部件产销量大幅提升，摊薄固定成本，零部件毛利率同比提升2.51个百分点。
- **[新能源汽车零部件放量]** -> [零部件业务结构优化]: 新能源零部件收入同比增142.81%，有效对冲传统燃油车零部件需求萎缩风险。
- **[废铝回收与铝灰资源化]** -> [成本控制与绿色壁垒]: 上游废铝用量占比74.36%，下游铝灰处置超11,500吨，形成“资源-生产-循环”闭环，降低原材料成本。
- **[切入机器人及镁合金赛道]** -> [打开远期增长空间]: 成立机器人及镁合金事业部，已获客户定点并试制量产，构建“汽车基本盘+新兴增长极”格局。
- **[海外产能布局加速]** -> [规避贸易风险与拓展市场]: 投资墨西哥、印尼项目，实现从产品出口到海外产能布局转型，提升全球供应链韧性。
- **[客户集中度风险]** -> [经营现金流持续为负]: 对皮尔博格等大客户依赖度高，应收账款随营收增长而增加，2025年经营现金流净额为-2.70亿元。
- **[原材料价格波动]** -> [盈利稳定性承压]: 铝、硅等大宗商品价格波动直接传导至成本端，虽采用套期保值，但基差风险及价格战压力仍存。

## 风险警告
**现金流恶化与高负债扩张的剪刀差。** 公司营收暴增42.61%的背后，是经营活动现金流净额连续两年为负（-2.70亿元），且缺口同比扩大。应收账款和银行承兑汇票大幅增加，表明公司为抢占市场份额牺牲了回款质量。同时，公司资产负债率已升至54.81%，短期借款和长期借款均大幅增长，在建工程（墨西哥、印尼、重庆等项目）仍需持续投入。若下游客户账期进一步拉长或融资环境收紧，公司可能面临流动性压力。

**客户集中度过高与行业价格战的叠加冲击。** 公司对前五大客户销售额占比高达56.06%，尤其对皮尔博格等大客户的铝液直供项目依赖度极高。当前汽车行业价格战虽有所缓和，但主机厂降本压力持续向供应链传导。若主要客户因自身经营或行业竞争要求年降、月降，将直接侵蚀公司本已微薄的利润率（铝合金业务毛利率仅4.41%）。此外，公司向机器人、镁合金等新赛道的转型尚处投入期，短期难以贡献利润，传统主业若受冲击，业绩弹性将大打折扣。
