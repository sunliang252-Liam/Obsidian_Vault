# 600866.SH 深度透视

## 因果逻辑链
- **[产品价格下行]** -> [营收下降8.27%]: 氨基酸、味精等主要产品市场均价下跌，导致收入减少，尽管销量有所增长。
- **[原材料成本下降]** -> [毛利率稳定]: 玉米、煤炭等主要原材料价格下降，叠加精益生产降本，部分对冲了产品售价下跌对利润的侵蚀。
- **[销量增长]** -> [净利润微增3.79%]: 以价换量策略下，产品销量增加，弥补了部分价格下降损失，叠加2024年业绩对赌期结束无需计提超额奖励，最终实现净利润小幅增长。
- **[欧盟反倾销终裁]** -> [出口业务承压]: 2025年7月欧盟对原产于中国的赖氨酸征收47.4%-58.2%反倾销税，直接冲击公司核心产品出口，是未来最大的不确定性。
- **[大规模资本开支]** -> [现金流恶化]: 60万吨玉米深加工项目进入建设高峰期，导致投资活动现金净流出24.09亿元，经营活动现金流也因营运资金占用增加而下降46.12%。
- **[产能扩张周期]** -> [行业竞争加剧]: 国内头部企业纷纷扩产，全球新增产能主要来自中国，供给端集中释放对产品价格形成持续下行压力。
- **[玉米主产区布局]** -> [成本优势]: 生产基地分布于宁夏、内蒙、黑龙江等玉米主产区，原材料供应充足便捷，形成区位成本优势。

## 风险警告
**核心风险在于国际贸易壁垒与行业产能过剩的叠加冲击。** 欧盟已对赖氨酸征收高额反倾销税，美国、巴西也发起“双反”调查，公司近40%的出口收入面临巨大不确定性。同时，国内氨基酸行业处于产能扩张周期，供给增速远超需求，产品价格持续承压，“以价换量”策略的可持续性存疑。公司新建60万吨玉米深加工项目（投资37亿）和45万吨氨基酸项目（投资33亿）正处于集中投入期，若未来产品价格持续低迷，新增产能的投资回报率将面临严峻考验。

**财务风险正在累积。** 公司经营活动现金流净额同比大幅下降46.12%，而投资活动现金净流出高达24亿元，导致公司不得不大幅增加借款（短期借款增长189%，长期借款增长38%），资产负债率升至50.98%。在行业景气度下行周期，高额的资本开支和债务压力将显著侵蚀公司的财务稳健性，一旦产品价格或销量出现超预期下滑，可能引发流动性风险。
