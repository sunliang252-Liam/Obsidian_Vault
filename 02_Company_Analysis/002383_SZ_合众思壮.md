# 002383.SZ 深度透视

## 因果逻辑链
- **[海外市场高增长]** -> [营收逆势增长14.27%]: 海外收入同比增长21.97%，占比提升至44.97%，成为收入增长核心引擎，弥补国内部分业务下滑。
- **[计提大额减值]** -> [持续亏损]: 商誉、存货、信用减值合计约1.22亿元，直接侵蚀利润，导致归母净利润-1.58亿元，但同比减亏28.81%。
- **[剥离非核心资产]** -> [短期阵痛与长期聚焦]: 主动收缩低效业务，注销/转让多家子公司，虽导致部分业务单元收入下滑，但资源向测量测绘、精准农业等核心主业集中。
- **[降本增效与组织优化]** -> [盈利能力边际改善]: 研发费用同比下降33.76%，管理费用持平，叠加营收增长，毛利率同比提升4.85个百分点，亏损幅度收窄。
- **[关联交易依赖]** -> [经营独立性风险]: 与控股股东及关联方（天派电子、合亿信息等）的采购和销售金额巨大，占营收/成本比例高，业务独立性存疑。
- **[研发投入资本化率高]** -> [未来摊销压力]: 研发投入资本化率高达38.02%，若相关项目收益不及预期，将面临大额资产减值或摊销压力。
- **[经营活动现金流大幅改善]** -> [回款能力增强]: 经营性现金流净额同比增长153.22%，主要得益于应收账款催收及部分冻结资金解冻，现金流状况优于利润表表现。

## 风险警告
**核心风险在于持续亏损与资产减值压力。** 公司连续三年扣非净利润为负，2025年虽减亏但仍亏损1.58亿元。巨额商誉和应收账款是最大隐患，报告期内计提减值超1.2亿元，表明前期并购整合效果不佳，资产质量承压。若核心业务（测量测绘、海外）增长放缓或减值再次爆发，净资产将持续被侵蚀。

**第二大风险是严重的关联交易依赖与治理结构隐患。** 公司对关联方（尤其是天派电子、合亿信息）的采购和销售占比极高，且控股股东股权质押比例高（郭信平全部冻结，兴慧电子50%质押）。这种复杂的关联网络和股权冻结状态，增加了利益输送和公司治理失控的风险，投资者需警惕其经营独立性和潜在的资金占用问题。
