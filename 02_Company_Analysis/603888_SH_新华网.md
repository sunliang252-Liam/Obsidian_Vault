# 603888.SH 深度透视

## 因果逻辑链
- **[专项项目完工，递延收益结转]** -> [净利润大增40.74%]: 报告期部分专项项目完工，相应递延收益结转至其他收益，导致非经常性损益大幅增加，推高归母净利润至3.29亿元。
- **[企业所得税政策变化]** -> [扣非净利润下降24.62%]: 上年同期因企业所得税政策变化冲减递延所得税资产，导致非经常性损益基数极高，剔除后本报告期扣非净利润降至1.70亿元。
- **[管理费用激增46.62%]** -> [侵蚀主业利润]: 报告期内部分专项项目完工结转，导致管理费用从1.89亿元飙升至2.77亿元，是扣非净利润下滑的核心成本端因素。
- **[全媒广告服务增长停滞]** -> [传统主业承压]: 作为核心收入来源的全媒广告服务收入同比仅增0.99%，增长乏力，显示传统“注意力经济”模式面临天花板。
- **[数字及智能化业务增长7.03%]** -> [第二曲线初现]: 数字及智能化业务收入同比增长7.03%至4.52亿元，成为公司转型“新型数智化媒体”的核心驱动力。
- **[直播电商与低空经济布局]** -> [新动能探索]: 直播电商品牌建设取得突破（抖音L6级），低空经济业务实现创新突破，但尚处早期，对整体业绩贡献有限。
- **[应收账款余额8.67亿元]** -> [现金流潜在风险]: 应收账款余额巨大，虽经营活动现金流净额增长22.55%，但坏账风险仍是影响未来业绩的潜在隐患。

## 风险警告
**核心风险在于利润的“含金量”极低。** 归母净利润3.29亿元看似亮眼，但扣非净利润仅1.70亿元，同比下滑24.62%。利润增长完全依赖非经常性损益（政府补助、项目结转），主业盈利能力实际在恶化。同时，管理费用激增46.62%，传统广告业务增长停滞，表明公司正经历转型阵痛，成本控制与业务升级均面临挑战。

**第二曲线尚在培育期，不确定性高。** 公司大力布局直播电商、低空经济、AIGC等新业务，但这些业务目前体量小、竞争激烈，尚未形成稳定的利润贡献。募投项目（如全媒体信息应用服务云平台）多次延期至2026年，技术投入转化为实际收益的路径尚不清晰。若新业务无法快速规模化，公司将陷入传统业务萎缩、新业务亏损的困境。
