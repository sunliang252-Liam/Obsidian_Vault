# 603259.SH 深度透视

## 因果逻辑链
- **[CRDMO一体化模式]** -> [收入与利润高增]: 从早期药物发现（R）到商业化生产（D&M）的端到端服务，实现“跟随分子”战略，临床后期及商业化项目占比提升，驱动收入增长25.5%，毛利率提升5.5个百分点。
- **[TIDES业务爆发]** -> [化学业务核心增长极]: 寡核苷酸和多肽业务收入同比+96.0%，产能提前建成（固相合成反应釜超100,000L），在手订单同比+20.2%，成为化学业务最强引擎。
- **[出售药明合联股权]** -> [非经常性收益暴增]: 出售联营企业WuXi XDC部分股权及剥离部分业务，贡献投资收益73.1亿元，占归母净利润的38%，导致利润总额同比+107%。
- **[在手订单高增]** -> [未来收入确定性]: 截至2025年末，持续经营业务在手订单580亿元，同比+28.8%，为2026年收入指引（513-530亿元，+18%-22%）提供坚实支撑。
- **[产能扩张与效率提升]** -> [规模效应显现]: 小分子原料药反应釜总体积超4,000kL，多肽产能提前建成，叠加工艺优化，营业成本增速（+3.64%）远低于收入增速（+15.84%），毛利率同比+6.16个百分点。
- **[美国市场强劲]** -> [境外收入主导]: 来自美国客户收入312.5亿元，同比+34.3%，占持续经营收入72%，是公司收入增长的核心驱动力。
- **[研发投入聚焦]** -> [技术壁垒巩固]: 研发人员占比76.8%，持续投入多肽、寡核苷酸、PROTAC等新分子类型，维持行业领先的技术服务能力。

## 风险警告
**地缘政治与客户集中风险**：公司收入高度依赖美国市场（占比72%），且前五大客户销售额占比48.11%。中美贸易摩擦、生物安全法案等政策风险是最大不确定因素，一旦主要客户因政治因素转移订单，将对公司收入造成重大冲击。公司虽在年报中提及全球化经营风险，但并未给出具体应对方案。

**非经常性收益依赖与增长可持续性**：2025年归母净利润暴增102.65%，但其中38%来自出售药明合联股权等非经常性损益。扣非净利润增速为32.56%，与收入增速基本匹配。随着出售资产完成，2026年将面临高基数压力，利润增速可能显著放缓。公司指引2026年收入增长18%-22%，但利润增长能否持续存疑。
