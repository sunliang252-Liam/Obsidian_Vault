# 603565.SH 深度透视

## 因果逻辑链
- **国家环保政策（碳达峰、碳双控）** -> 行业‘散改集’趋势增强: 环保压力趋严，要求降低碳排放；水运碳排放强度低于公路、铁路；集装箱封闭式运输可解决粉尘污染，促进大宗商品‘散改集’，从而提升内贸集装箱物流需求。
- **国家环保政策（碳达峰、碳双控）** -> 运输结构调整（水运比重提升）: 国家明确提出以碳排放总量与强度双控为抓手，推动绿色转型；水运碳排放强度最低，因此政策鼓励以水运为核心的大宗货物中长距离运输，推动运输结构调整。
- **国家多式联运政策（‘一单制’）** -> 集装箱多式联运发展: 国家推动多式联运‘一单制’，简化流程；集装箱是最适合多式联运的载体，可实现‘一箱到底’，政策落地促进集装箱多式联运规模化运营。
- **行业运力供给放缓（无新造船订单）** -> 运价提升（PDCI指数上涨6.26%）: 内贸集装箱班轮公司自2020年以来除公司外未大规模运力更新，目前主要班轮公司均无内贸船舶建造订单，运力供给放缓，供需改善推升运价。
- **运价提升（PDCI上涨）** -> 公司归母净利润增长（+9.03%）: 尽管运输量下降13%，但运价上涨（PDCI+6.26%）导致水运业务收入基本持平，同时公司通过成本管控（如油耗优化）使营业成本下降15.02%，毛利率提升8.39个百分点，最终推动归母净利润增长。
- **公司成本管控（燃油优化等）** -> 营业成本下降（-15.02%）: 公司通过船舶纵倾优化、船壳清污、排查艉轴缠渔网等措施降低油耗，控制燃油成本；同时运输量下降减少了港口、拖车等变动成本。
- **国内竞争加剧或需求调整** -> 公司运输量下降（-13%）: 内贸运输规模较上年同期有所下降，可能由于宏观经济波动或行业竞争导致货源减少，但年报未明确具体原因，从营业收入下降推断。
- **公司外贸业务加速布局** -> 境外收入增长（境外收入占73%）: 公司通过期租模式优化船队配置，新开辟越南、印尼、印度及红海等国际航线，海外覆盖11个国家，外贸收入成为重要收入来源。
- **外贸业务扩展** -> 财务费用大幅增加（+726.65%）: 外贸业务涉及外币结算，外币汇率波动导致汇兑损失增加，从而使财务费用从-0.24亿元升至1.50亿元。

## 风险警告
深度风险总结：公司面临多重风险。首先，宏观经济波动可能抑制物流需求，导致内贸业务进一步下滑。其次，政策风险不容忽视，若外资准入限制放宽，现有行业壁垒将削弱，竞争加剧。此外，成本上涨风险（码头费、船舶租赁费、燃油价格）可能侵蚀利润。外贸业务扩张带来汇率风险（已体现在财务费用大幅增加）和经营管理风险。专业人才流失也制约发展。需重点关注2026年18艘新船建造计划的资金安排和投资回报。
