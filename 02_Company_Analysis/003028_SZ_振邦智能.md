# 003028.SZ 深度透视

## 因果逻辑链
- **[美国政策影响与客户订单波动]** -> [营收微降2.48%，净利润暴跌63.89%]: 客户因不确定性暂缓或缩减订单，叠加行业竞争加剧与产品结构调整，综合毛利率收窄，利润空间被严重挤压。
- **[新能源业务爆发式增长]** -> [营收1.83亿元，同比+229.93%]: 依托电力电子与锂电池管理技术积淀，形成从部件到整机的全链条解决方案，成为公司核心增长引擎。
- **[越南基地产能释放]** -> [越南子公司营收4.61亿元，同比+44.16%]: 越南基地扩产提升海外交付效率，有效响应欧美市场需求，成为海外拓展的重要支撑。
- **[核心客户深度绑定]** -> [前五大客户营收占比49.89%]: 与Dometic、TTI等全球知名企业形成深度合作，通过“核心客户保基本盘、细分客户拓增量”的生态，稳定基本盘。
- **[战略性产能扩张与折旧增加]** -> [毛利率承压]: 深圳振为科技园及海外基地建设陆续转固，折旧费用增加，叠加价格竞争，进一步加大毛利率下行压力。
- **[存货跌价准备大幅计提]** -> [资产减值损失1654.79万元]: 受市场需求变化及产品结构调整影响，对呆滞、残次存货计提跌价准备，侵蚀利润。
- **[研发投入聚焦机器人新赛道]** -> [布局未来增长极]: 基于清洁与割草机器人技术积累，研发多模态感知与自适应交互系统，为商业化落地储备技术。
- **[资金充裕与低负债率]** -> [财务结构稳健]: 货币资金、理财等合计超12.70亿元，占总资产47.21%，资产负债率35.14%，无长期借款，为产能扩张与股东回报提供保障。

## 风险警告
**核心风险在于盈利能力急剧恶化与毛利率持续承压。** 2025年净利润同比暴跌63.89%，主要因美国政策扰动导致客户订单波动、行业价格竞争加剧，以及战略性产能扩张（振为科技园转固）带来的折旧费用激增。公司综合毛利率已从2024年的23.57%降至16.40%，且管理层明确预警毛利率可能进一步下滑。若海外产能爬坡与降本增效措施不及预期，利润端将持续面临严峻挑战。

**第二增长曲线（新能源）的可持续性与海外扩张的不确定性是另一大风险。** 新能源业务虽实现229.93%的爆发式增长，但毛利率仅为11.53%，远低于传统智能电器控制器（17.49%），且该业务受海外市场政策标准升级、行业竞争加剧影响，募投项目“逆变器及高效智能储能系统项目”已未达预期收益。同时，越南租赁土地建厂项目仍受制于当地政府审批，存在落地不及预期的风险，可能影响海外产能释放节奏。
