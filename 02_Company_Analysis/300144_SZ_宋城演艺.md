# 300144.SZ 深度透视

## 因果逻辑链
- **[宏观经济与消费信心波动]** -> [营收与利润双降]: 2025年外部冲击导致居民出游意愿和消费能力承压，公司整体营收同比下降6.61%，归母净利润同比下降22.03%。
- **[上海、西安等新项目爬坡]** -> [结构性增长]: 上海千古情景区营收同比大增42.91%，西安千古情景区营收同比增长10.60%，成为对冲存量项目下滑的核心增量。
- **[杭州大本营筑底整固]** -> [营收基本持平]: 杭州宋城旅游区营收同比仅微降0.59%，通过产品迭代和沉浸式体验升级，守住了基本盘，但增长乏力。
- **[轻资产输出模式扩张]** -> [品牌价值变现]: 新签青岛、台州两大轻资产项目，以品牌和管理输出换取服务费，在低资本投入下放大品牌影响力并创造持续收入。
- **[AI数智化转型投入]** -> [短期成本增加，长期效率提升]: 规模化引进AI人才、搭建AI管理中台和艺术中央厨房，导致销售费用同比大增51.85%，但旨在解决跨区域管理难题，为未来降本增效奠基。
- **[收购宋城实业]** -> [突破杭州大本营发展瓶颈]: 通过收购控股股东资产，获取土地和空间资源，解决景区“土地紧缺、产品迭代受限”等痛点，为构建“演艺王国”复合型文旅集群铺路。
- **[股权激励计划]** -> [绑定核心团队]: 2023年限制性股票激励计划在报告期内多次归属与解限，有效激发管理层及核心骨干积极性，为公司战略转型提供人才保障。

## 风险警告
**核心风险在于转型阵痛与业绩下滑的叠加。** 公司2025年营收和利润双双下滑，尤其是扣非净利润同比下降近24%，表明核心盈利能力正在承压。与此同时，公司正大力投入AI数智化转型，销售费用激增51.85%，短期内将显著侵蚀利润。若新项目爬坡和AI赋能的效果不及预期，公司可能面临“旧业务失速、新投入无果”的尴尬局面。

**另一重大风险来自行业竞争加剧和宏观经济的不确定性。** 线下演艺市场同质化竞争激烈，低价策略扰乱市场秩序；线上数字娱乐（短视频、游戏等）持续分流用户时间和消费。此外，重大自然灾害、公共卫生事件等不可抗力因素，以及宏观经济波动导致居民消费意愿下降，都可能对公司的游客接待量和经营业绩造成重大冲击。
