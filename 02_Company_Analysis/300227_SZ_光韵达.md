# 300227.SZ 深度透视

## 因果逻辑链
- **[收购亿联无限与凌轩精密]** -> [营收暴增51.99%至16.03亿]: 新并购的通信终端（亿联无限8-12月贡献3.51亿）和航空零部件（凌轩精密12月并表）业务直接拉动了收入规模，但并表时间短，对全年利润贡献有限。
- **[计提大额减值与股份支付]** -> [净利润巨亏2.75亿]: 智能装备业务调整、航空零部件毛利率下滑导致计提减值准备1.89亿，叠加股权激励费用0.97亿，是亏损的核心原因。
- **[航空零部件业务“增收不增利”]** -> [毛利率下滑8.23%至19.61%]: 客户产品价格下调、前期研制项目投入大、规模效应弱，导致营收增长41%的同时，净利润反而大幅亏损。
- **[电子制造服务（核心基石）]** -> [营收微增5.53%，净利润亏损]: 激光应用服务虽稳健，但智能装备业务受行业竞争加剧、产品价格承压及人员优化等影响，导致板块整体亏损。
- **[通信终端（亿联无限）]** -> [超额完成业绩承诺]: 2025年扣非净利润5,487万元，完成率109.74%，成为公司当期少数盈利且超预期的业务板块。
- **[经营活动现金流大幅改善]** -> [净额2.22亿，同比增长159%]: 尽管净利润亏损，但通过加强回款及新并购业务贡献，现金流表现强劲，与净利润形成巨大反差。
- **[股权激励绑定核心团队]** -> [计提0.97亿费用，但锁定长期利益]: 向156名激励对象授予6,203万股，虽短期侵蚀利润，但旨在将股东、公司与核心团队利益深度绑定。

## 风险警告
**核心风险在于“增收不增利”的恶性循环与商誉减值的地雷。** 公司通过激进并购实现营收翻倍，但核心的航空零部件业务毛利率大幅下滑，智能装备业务亏损，导致整体盈利能力恶化。更危险的是，账面商誉因并购激增，若被并购标的（如通宇航空）未来业绩持续不达预期，将面临巨额商誉减值风险，进一步冲击本已脆弱的利润表。

**国际化与整合风险并存。** 公司战略转向全球化，但海外业务（通信终端）毛利率仅17.89%，且面临贸易政策、汇率波动等不确定性。同时，多起并购（亿联无限、凌轩精密、索曜科技）带来的管理整合、文化融合及协同效应能否兑现，是巨大的挑战。若整合失败，不仅无法实现“1+1>2”，反而可能拖累整体运营效率，导致管理失控。
