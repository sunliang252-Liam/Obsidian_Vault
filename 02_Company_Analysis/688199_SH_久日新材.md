# 688199.SH 深度透视

## 因果逻辑链
- **[光引发剂价格回升]** -> [扭亏为盈]: 部分主要光引发剂产品价格反弹，叠加降本增效，使整体销售毛利增加，驱动公司归母净利润从-5376万元转为2762万元。
- **[瑞武基金投资收益]** -> [非经常性损益大增]: 参股基金投资的厦门恒坤在科创板上市，导致基金净利润大幅增加，公司确认投资收益约4400万元，成为扭亏的关键非经营性支撑。
- **[半导体化学材料业务放量]** -> [电子化学品收入激增466.81%]: 光敏剂、光刻胶销量增加，推动该板块收入从263万元跃升至1494万元，但光敏剂尚未量产，毛利率为-128.55%，仍处于亏损培育期。
- **[精细化学品销量下滑]** -> [收入减少18.93%]: 受市场竞争及需求疲软影响，精细化学品（苯甲酸等）销量下降12%，导致该板块收入萎缩，但公司战略性增加库存以应对市场低位。
- **[研发投入持续高企]** -> [巩固技术护城河]: 研发费用占营收5.28%，新增12项发明专利，在光刻胶、大分子光引发剂等前沿领域形成技术储备，支撑“光固化+半导体”双轮战略。
- **[产能扩张与基地优化]** -> [提升产业链自主可控]: 弘润化工H4酮项目、宏远天呈羟基酮项目等投产，实现184产品全产业链贯通，并向上游原材料（二苯基氯化膦）延伸，降低采购成本。
- **[出口退税政策变化]** -> [外销成本承压]: 自2026年4月起，含磷光引发剂（TPO、819等）出口退税取消，将直接增加公司外销成本，对出口业务构成潜在压力。

## 风险警告
**核心风险在于半导体新业务的盈利兑现与光固化主业的周期性波动。** 公司半导体化学材料（光敏剂、光刻胶）收入虽暴增，但毛利率为-128.55%，远未达到量产盈利拐点，且核心技术人员（裵埈範）离职，增加了研发与产业化进程的不确定性。同时，光引发剂主业虽价格回升，但行业整体仍供大于求，毛利率下滑风险未消，且2026年出口退税取消将直接侵蚀含磷产品的出口利润。

**另一重大风险是宏观政策与地缘政治的双重冲击。** 美国关税政策虽短期影响有限（对美出口占营收约8%），但全球供应链重构风险持续存在。此外，公司高度依赖高新技术企业15%所得税优惠，若复审不通过将直接冲击净利润。原材料价格（受国际油价影响）波动及环保、安全生产的合规成本上升，也是长期悬在头顶的达摩克利斯之剑。
