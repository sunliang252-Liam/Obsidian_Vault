# 002492.SZ 深度透视

## 因果逻辑链
- **按信用风险特征组合计提应收款项坏账准备增加** -> 归属于上市公司股东的净利润-6,436.46万元，同比下降198.86%: 直接因果：坏账准备增加导致净利润大幅下降，是业绩亏损的主要原因。
- **恒旭达支付保理业务款产生的现金流量净流出增加29,346万元** -> 经营活动产生的现金流量净额同比下降59.52%: 直接因果：保理业务款净流出激增是经营现金流大幅下降的主要原因。
- **应收款项信用减值损失16,535万元（非现金项目）** -> 净利润与经营现金流净额差异18,958.49万元: 非现金减值损失导致净利润远低于经营现金流，是差异主因。
- **珠海恒基、扬州恒基银行理财到期赎回增加** -> 投资活动现金流量净额同比增长99.77%: 理财产品到期赎回增加现金流入，改善投资现金流。
- **银行融资增加额同比增加5,495万元，且分配现金股利减少4,053万元** -> 筹资活动现金流量净额同比增长176.73%: 增加借款、减少分红共同导致筹资净现金流由负转正。
- **主营业务-装卸/码头收入同比下降4.97%，成本同比增长12.09%** -> 主营业务-装卸/码头毛利率下降7.49个百分点: 收入下降叠加成本上升，导致毛利率显著下滑。
- **恒旭达保理业务底层资产处置后预计可收回及未来盈利预测** -> 递延所得税资产大幅增加（从1,221万增至3,968万）: 基于底层资产处置前景和未来盈利判断，确认了更多的可抵扣暂时性差异。
- **主营业务-管理服务收入同比下降29.33%** -> 整体主营业务收入增长受限: 管理服务业务收入骤降，拖累整体主营业务表现。

## 风险警告
公司深度风险在于：（1）信用减值风险：按信用风险特征组合计提的坏账准备大幅增加，导致巨额亏损，需警惕应收账款质量和保理业务底层资产的回收不确定性；（2）现金流依赖保理业务：恒旭达保理业务款支付导致经营现金流大幅波动，且该业务规模较大，一旦底层资产恶化，可能引发现金流危机；（3）核心业务毛利率下降：装卸/码头业务成本上升、收入下滑，毛利率下降7.49个百分点，表明行业竞争加剧或成本压力上升；（4）区域集中与监管风险：业务聚焦华南、华东、华中，地区性突发事件或环保政策收紧可能对经营产生重大影响。
