# 601628.SH 深度透视

## 因果逻辑链
- **[权益市场大幅上涨 + 主动加大权益投资]** -> [总投资收益同比+25.8%]: 公司把握市场机会，公开市场权益投资规模超1.2万亿元，较年初增加超4500亿元，直接驱动投资收益大幅增长。
- **[投资收益大幅增长]** -> [归母净利润同比+44.1%]: 总投资收益增加794.43亿元，是净利润在高基数上强劲增长的核心来源。
- **[浮动收益型业务转型成功]** -> [新业务负债刚性成本连续三年下降]: 分红险等浮动收益型产品在首年期交保费中占比近50%，有效降低了负债成本，提升了新业务价值率。
- **[个险渠道结构优化]** -> [个险一年新业务价值同比+25.5%]: 十年期及以上首年期交保费占比提升至58.48%，分红险占比跃升至近60%，业务结构多元均衡驱动价值增长。
- **[银保渠道“报行合一”落地]** -> [银保渠道总保费突破千亿，同比+45.5%]: 控本增效政策下，公司银保渠道实现规模与价值双升，新单保费同比+95.7%。
- **[全渠道协同发力]** -> [总保费首次突破7000亿元]: 个险稳盘、银保突破、互联网保险高速增长（+38.9%），多极驱动形成发展合力。
- **[资产负债联动深化]** -> [总投资收益率同比+59个基点至6.09%]: 围绕负债特征动态优化大类资产配置，固定收益稳固底仓，权益投资增厚收益，实现近年最好投资业绩。
- **[营销体制改革 + 优增优育]** -> [个险队伍质态改善，优增人力同比+40%]: 队伍规模稳居行业首位（58.7万人），同时新生力量不断壮大，为未来价值增长提供人力基础。

## 风险警告
**核心风险：利率持续下行与权益市场波动的双重挤压。** 公司业绩高度依赖投资收益，2025年净利润暴增主要源于权益市场的强劲表现和主动加仓。若未来市场利率长期走低，将导致固定收益资产再投资收益率下降，同时推高存量保险合同负债（9.5%的增长部分受利率变化影响）。若权益市场出现大幅回调，投资收益和净利润将面临剧烈波动，2025年的高增长基础并不稳固。

**关键风险：偿付能力充足率显著下降。** 受市场利率波动和权益类资产配置规模增长影响，公司核心偿付能力充足率从153.34%降至128.77%，综合偿付能力充足率从207.76%降至174.01%。虽然仍处于充足水平，但下降趋势明显。若偿付能力进一步承压，可能限制公司未来的业务扩张和权益投资空间，甚至影响分红能力。
