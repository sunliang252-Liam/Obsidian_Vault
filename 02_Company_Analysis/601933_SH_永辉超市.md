# 601933.SH 深度透视

## 因果逻辑链
- **[激进调改与闭店]** -> [营收暴跌20.82%，亏损扩大至25.52亿]: 公司为转型“品质零售”，主动关闭381家尾部门店并深度调改284家门店，短期导致收入锐减，并产生约8.8亿资产报废及一次性投入、约3亿毛利损失。
- **[供应链深度改革]** -> [毛利率承压，短期缺货]: 推行“裸价”和控后台策略，淘汰旧品、引入新品，导致供应链短期阵痛，商品结构切换期间毛利率下滑。
- **[门店调改效果初显]** -> [调改门店客流与销售额大幅提升]: 截至年末累计调改315家门店，通过商品结构升级、购物环境优化、服务体验提升，成功提升聚客能力，但尚未能完全对冲闭店损失。
- **[线上业务增长]** -> [线上销售额100.9亿，成为重要增长极]: 自营及第三方平台到家业务覆盖近350家门店，日均单量合计超30万单，线上渠道成为营收的重要补充。
- **[自有品牌从0到1]** -> [“品质永辉”品牌初步建立，贡献1.16亿销售额]: 开发63支单品，聚焦民生高频刚需品类，为未来差异化竞争和毛利率提升奠定基础。
- **[非主业投资拖累]** -> [公允价值变动损失-4.6亿，加剧亏损]: 持有的Advantage Solutions股票及大连万达商管股权价值持续下跌，对当期利润造成重大负面影响。
- **[资产处置收益掩盖经营恶化]** -> [扣非净利润-34.17亿，远高于归母净利润]: 通过闭店处置使用权资产等获得18.86亿非经常性收益，掩盖了主营业务深度亏损的严峻现实。

## 风险警告
**核心风险在于“调改”的成败与时间赛跑。** 公司正处于“壮士断腕”式的转型阵痛期，大规模闭店和调改导致营收、毛利、现金流全面承压。2025年经营活动现金流净额同比暴跌70.54%至6.46亿，净资产收益率（ROE）为-81.04%，财务状况极度脆弱。若调改后的门店无法在2026年及以后持续、快速地实现盈利并弥补闭店损失，公司将面临流动性危机和持续亏损的恶性循环。

**另一重大风险是巨额应收账款的回收与资产减值。** 公司出售万达商管股权尚有36.39亿元本金及违约金未收回，虽已仲裁胜诉，但被执行人尚未履行，回收存在重大不确定性。同时，公司持有大量公允价值计量的金融资产（如Advantage Solutions股票），其价格波动将直接冲击利润表。叠加诉讼缠身（大量租赁、供应商合同纠纷），潜在的资产减值与赔偿支出是悬在头上的达摩克利斯之剑。
