# 002560.SZ 深度透视

## 因果逻辑链
- **[电网投资强周期]** -> [营收增长29%]: 国家“十五五”电网投资预计达4万亿元，公司紧抓特高压与配网建设机遇，电线电缆业务营收同比增长26.78%。
- **[海外市场拓展]** -> [出口高增75.38%]: 积极响应“一带一路”，在东南亚、拉美等新兴市场持续获得订单，海外出口成为营收增长的重要引擎。
- **[航空零部件放量]** -> [子公司利润贡献显著]: 子公司成都航飞订单饱满，营收同比增长54.95%，净利润4384万元，充分受益于国产大飞机产业化与军机更新换代。
- **[铝基新材料协同]** -> [稳健经营]: 子公司通达新材料通过调整产品结构，营收29.32亿元，净利润1424万元，与电线电缆主业形成原材料协同效应。
- **[精益管理与回款优化]** -> [经营现金流暴增698%]: 公司加强应收账款回收、加速存货周转、优化供应商结算，经营活动现金流净额达7.27亿元，利润质量显著提升。
- **[研发平台升级]** -> [技术壁垒强化]: 获批“国家企业技术中心”与“博士后科研工作站”，实验室获CNAS认证，为产品高端化与全球化提供技术背书。
- **[原材料价格波动]** -> [成本压力传导]: 电线电缆成本中直接材料占比高达94.63%，铜、铝等大宗商品价格波动直接侵蚀毛利率，公司通过期货套保对冲风险。

## 风险警告
**核心风险在于原材料价格波动与低毛利业务的结构性拖累。** 公司电线电缆业务毛利率仅11.50%，铝基复合新材料业务毛利率更是低至1.53%，两者合计贡献超87%的营收。一旦铜、铝价格大幅上涨而无法向下游传导，或下游电网招标价格竞争加剧，将直接导致盈利能力剧烈波动。公司虽通过期货套保对冲，但套保本身亦存在基差与操作风险。

**第二重风险来自航空业务的不确定性及商誉减值压力。** 公司账面商誉净值仍有1.16亿元，全部来自收购成都航飞。尽管当前航空业务订单饱满，但军工与民航客户结算周期长、季节性波动大，且受国防预算与国产大飞机产业化进度影响显著。若未来订单不及预期或行业政策调整，存在商誉减值风险，将直接冲击净利润。
