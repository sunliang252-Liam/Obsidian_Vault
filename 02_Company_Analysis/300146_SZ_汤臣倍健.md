# 300146.SZ 深度透视

## 因果逻辑链
- **[线下渠道收入大幅下滑]** -> [总营收承压]: 药店零售行业持续震荡，叠加医保政策与购买力下降，导致线下渠道收入同比下降17.39%，拖累整体营收下滑8.38%。
- **[线上渠道增长乏力]** -> [错失新周期增长]: 公司在抖音、跨境等新兴高势能渠道战略缺失，线上渠道仅微增0.28%，未能弥补线下缺口，错失行业新周期开局。
- **[销售费用大幅缩减]** -> [净利润逆势增长]: 公司主动削减广告费（-25.28%）及市场推广费，在营收下滑背景下，销售费用率下降，推动归母净利润同比增长19.81%。
- **[新品密集上市]** -> [产品结构优化]: 2025年为历史新品大年，多维双层片等新品销售占比近20%，并推出首款OTC及特医食品，为未来增长储备弹药。
- **[境外业务强劲增长]** -> [对冲境内颓势]: 境外LSG业务收入同比增长16.43%（澳元口径+17.73%），成为公司唯一正增长的主要业务板块，有效缓冲了境内市场的下滑。
- **[研发费用大幅下降]** -> [短期利润调节]: 委外研发项目未达预期收到退款，叠加公司优化资源配置，研发费用同比骤降40.15%，对当期利润形成正向贡献。
- **[品牌与渠道战略缺失]** -> [核心竞争地位动摇]: 董事长承认在“跨境×抖音”等关键渠道战略缺失，导致主品牌收入下降10.38%，品牌渗透率与社媒投资总量跑输竞品。

## 风险警告
**核心风险在于“百亿营收”关卡前的战略失速与增长引擎熄火。** 公司错失2023年提出的VDS新周期开局，线下药店渠道受政策与消费降级双重冲击持续萎缩，而线上渠道在抖音、跨境等增量渠道的布局严重滞后，导致全渠道增长乏力。营收连续两年下滑，从94亿高点回撤至62.65亿，显示出公司从行业龙头向“守成者”滑落的危险趋势。若不能快速在兴趣电商和跨境渠道实现突破，公司可能陷入长期增长停滞。

**财务健康度存在隐性风险。** 尽管净利润因费用压缩而增长，但营收下滑、研发投入骤降（-40.15%）以及高达11.36亿元的商誉账面价值，构成了潜在隐患。若未来品牌推广或LSG业务不达预期，商誉减值将直接冲击利润表。同时，公司过度依赖削减广告费来维持利润，可能进一步削弱品牌心智和长期竞争力，形成“越省越弱”的负向循环。
