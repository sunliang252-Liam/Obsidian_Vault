# 688596.SH 深度透视

## 因果逻辑链
- **[下游资本开支放缓]** -> [收入与利润双降]: 部分下游行业（如泛半导体）资本开支放缓、项目延期交付，导致公司2025年营收同比下降10%，归母净利润暴跌74%。
- **[OPEX业务产能集中投产]** -> [折旧大幅增加]: 公司战略转型期，气体、材料等OPEX业务新建产能集中转固，固定资产折旧显著加大，侵蚀利润。
- **[战略并购与可转债发行]** -> [财务费用激增]: 为收购汉京半导体及建设产能，公司增加银行贷款并发行可转债，导致财务费用同比暴增238%，严重拖累当期业绩。
- **[收购汉京半导体]** -> [商誉与无形资产激增]: 非同一控制下企业合并汉京半导体，带来商誉（增801%）和无形资产（增256%）大幅增加，未来存在减值风险。
- **[业务结构优化]** -> [OPEX收入占比跃升]: 非设备类业务（零组件、气体、服务）收入占比从31%提升至42.3%，新签合同占比超50%，业务韧性增强，周期性减弱。
- **[半导体业务聚焦]** -> [收入占比显著提升]: 公司坚定聚焦半导体产业，2025年半导体业务收入占比从50%提升至60%，成为最核心的增长引擎。
- **[海外市场拓展]** -> [打开增量空间]: 公司在东南亚、中东、北美等市场出海布局初见成效，海外获单情况超预期，为后续增长开辟新市场。

## 风险警告
**核心风险在于业绩“断崖式”下滑后的修复不确定性。** 2025年归母净利润暴跌74%，主因是下游资本开支放缓、OPEX产能折旧集中释放及财务费用激增的三重压力。虽然公司强调2026年Q1新签订单同比增长58.6%，但前期低毛利订单仍在交付，2026年整体毛利率依然承压。若下游景气度复苏不及预期，公司可能面临“增收不增利”的困境。

**另一重大风险是并购整合与商誉减值。** 公司以11亿元收购汉京半导体，形成巨额商誉（6.87亿）和无形资产。汉京半导体虽具备技术优势，但其业绩贡献能否达到预期、与现有业务的协同效应能否顺利释放，均存在较大不确定性。一旦其经营恶化，商誉减值将直接冲击公司利润表。此外，公司总资产因并购扩张38%，资产负债率攀升，财务杠杆风险显著增加。
