# 688619.SH 深度透视

## 因果逻辑链
- **[客户需求延迟与项目工期拉长]** -> [营业收入未达预期]: 宏观环境及市场情况综合影响，客户需求延迟、部分项目工期较长，已完成最终用户验收的项目金额减少，导致营收仅1.53亿元，亏损扩大至-2.27亿元。
- **[部分项目应收款项账龄拉长]** -> [信用减值损失大幅增加]: 到期款项集中分布在损失率较高区间，整体预期信用损失率上升，公司足额计提信用减值损失，进一步侵蚀利润。
- **[市场环境变化及资产价值波动]** -> [资产减值损失同比增加]: 公司基于谨慎性原则对相关资产进行评估并计提减值，加剧了当期亏损。
- **[优先承接回款有保障的优质订单]** -> [经营活动现金流由负转正]: 公司坚持稳健经营策略，强化项目筛选与风险把控，报告期内经营活动现金流量净额实现16.6百万元，较上年同期的-61.1百万元显著改善。
- **[研发投入结构优化与人员数量下降]** -> [研发费用同比减少25.47%]: 公司严控研发相关支出，研发人员从103人降至72人，研发费用从2,808万元降至2,093万元，占营收比例从19.64%降至13.72%。
- **[与浪潮计算机合资布局国产化设备]** -> [开辟新业务增长点]: 整合自身软件算法优势与浪潮的硬件制造能力，在晋江落地AI产业基地，推出智算大模型一体机、国密安全芯片终端等产品，强化端侧AI部署能力。
- **[与智元创新等合资成立小鹭智能]** -> [切入机器人产业赛道]: 借助智元创新在人形机器人本体生产领域的优势，结合公司在模型算法、行业数据资源方面的优势，开发行业专用机器人产品，布局具身智能新方向。
- **[母公司累计未弥补亏损达-1.89亿元]** -> [不具备现金分红条件]: 截至2025年末，母公司期末未分配利润为-188,639,291.00元，公司2025年度拟不进行现金分红，亦不进行资本公积转增股本。

## 风险警告
**核心风险在于业绩持续亏损与资产质量恶化。** 公司已连续三年亏损（2023年-0.48亿，2024年-1.93亿，2025年-2.27亿），且亏损幅度逐年扩大。根本原因在于核心客户（政府）财政预算紧张导致项目回款周期拉长，进而引发大规模的信用减值和资产减值。2025年信用减值及资产减值损失是导致亏损远超营收规模的主因，净资产已从2023年末的11.15亿缩水至2025年末的6.67亿，降幅达40%，资产质量持续承压。

**转型前景尚不明朗，新业务贡献有限。** 公司虽积极布局国产化设备、机器人等新赛道，但报告期内1.53亿营收中，AI+安全业务仍占87%，新业务尚未形成规模效应。同时，研发投入同比缩减25%，研发人员减少30%，在AI技术快速迭代的背景下，研发投入的收缩可能削弱公司长期技术竞争力，使其在激烈的行业竞争中处于不利地位。
