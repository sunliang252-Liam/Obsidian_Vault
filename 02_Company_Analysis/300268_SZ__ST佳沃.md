# 300268.SZ 深度透视

## 因果逻辑链
- **[剥离巨亏三文鱼资产]** -> **净资产转正**: 出售持续大额亏损的子公司北京臻诚（含Australis），使净资产从-4.43亿元转正至2.75亿元，消除退市风险。
- **[狭鳕鱼原料价格飙升]** -> **毛利率承压**: 国际原料供应短缺、价格持续走高，而下游销售竞争激烈，导致狭鳕鱼业务毛利率下降3.50%。
- **[中加关税政策冲击]** -> **甜虾业务量价齐跌**: 中国对加拿大水产品加征25%关税，推高北极甜虾原料与销售价格，公司被迫采取稳健策略，销量与收入同比下滑。
- **[资产剥离导致并表范围缩小]** -> **营收大幅萎缩**: 三文鱼业务自2025年6月起不再并表，导致全年营收同比骤降51.51%，从34.18亿缩至16.57亿。
- **[关联方高息资金拆借]** -> **财务费用侵蚀利润**: 公司向控股股东及其关联方大量高息（3.61%-7.20%）借款，全年利息支出约1.93亿元，是持续亏损的重要原因。
- **[欧盟制裁与禁运]** -> **全球供应链重构**: 欧盟对俄制裁及美国禁运，导致俄罗斯狭鳕鱼原料流向改变，中国加工环节重要性凸显，但同时也面临原料成本上升和出口市场波动的双重压力。
- **[委托经营管理协议]** -> **规避同业竞争**: 出售北京臻诚后，通过签署委托经营管理协议，由上市公司继续管理该资产，既避免了与控股股东的同业竞争，又保留了潜在的管理收益。

## 风险警告
**核心风险在于“断臂求生”后的业务空心化与盈利可持续性。** 公司通过剥离三文鱼业务实现了净资产转正和摘帽，但代价是营收规模骤降超50%，核心业务仅剩狭鳕鱼和北极甜虾的加工与贸易。这两项业务均高度依赖进口原料，且面临地缘政治（美欧对俄制裁、中美/中加关税）和原材料价格波动的双重夹击，毛利率空间被严重挤压。公司当前盈利高度依赖控股股东的关联借款（高额利息）和委托管理费，自身造血能力依然脆弱。

**第二大风险是国际贸易环境的剧烈波动。** 公司业务完全嵌入全球海产品供应链，美国对俄制裁、欧盟关税调整、中加贸易摩擦等任何一项政策变化，都可能直接冲击原料采购成本、销售市场准入和汇率稳定性。2025年狭鳕鱼原料价格飙升和北极甜虾关税冲击已充分暴露了这种脆弱性。公司虽采取多元化采购和汇率对冲措施，但在系统性风险面前，应对能力有限。
