# 000978.SZ 深度透视

## 因果逻辑链
- **[收回大额历史欠款]** -> [信用减值损失转回1999万元]: 收回以前年度欠款5434万元，依据会计准则转回前期计提的坏账准备，直接增厚当期利润。
- **[剥离亏损子公司资江丹霞]** -> [确认非经常性投资收益2998万元]: 公开挂牌转让持续亏损的资江丹霞公司100%股权及债权，获得一次性资产处置收益，是扭亏为盈的核心驱动力。
- **[计提大额资产及信用减值]** -> [侵蚀扣非净利润]: 年末对桂圳公司、琴潭客运站等资产计提减值合计3687.72万元，导致扣非净利润仍为-4732万元，主业盈利能力并未实质改善。
- **[核心景区游客量微增]** -> [营收基本持平]: 银子岩、两江四湖等核心景区游客量合计增长3.79%，但客单价提升有限，整体营收仅同比增长2%，增长乏力。
- **[人工成本刚性上涨]** -> [毛利率改善空间有限]: 人工工资占营业成本比例高达38.13%，且同比仍在增长，成为成本端的主要压力，抵消了折旧、燃料等成本下降带来的利好。
- **[收购漓胜公司]** -> [完善“游船+票务”一体化布局]: 收购漓胜公司100%股权，整合漓江景区票务代理及系统维护业务，强化对核心资源的管控，但短期利润贡献有限（95.45万元）。
- **[长期借款增加]** -> [财务费用压力持续]: 报告期末长期借款增至7.13亿元，同比增加约6900万元，导致财务费用仍高达3105万元，是侵蚀利润的重要固定支出。

## 风险警告
**核心风险在于主业盈利能力的脆弱性与资产质量的持续恶化。** 公司2025年净利润扭亏为盈，完全依赖“收回欠款转回坏账”和“出售亏损子公司”两项非经常性损益，扣非净利润仍为-4732万元，表明核心旅游业务（游船、景区、酒店）在成本刚性上涨和竞争加剧下，并未实现实质性盈利改善。公司账面仍有高达-8.06亿元的未分配利润，历史包袱沉重，短期不具备分红能力。

**资产结构风险与治理风险并存。** 公司部分子公司（如丰鱼岩、罗山湖、旅游汽车公司）净资产已为负值，持续亏损，存在资产进一步减值的风险。同时，公司因前期会计差错被广西证监局出具警示函，暴露出内部控制和财务核算的薄弱环节，治理规范性有待提升。此外，控股股东及第二大股东所持股份高比例质押，也构成潜在的控制权稳定性风险。
