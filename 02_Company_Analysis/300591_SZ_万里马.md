# 300591.SZ 深度透视

## 因果逻辑链
- **[团购业务订单大幅减少]** -> [营收下降11.91%]: 团购渠道收入同比降37.52%，占总营收比例从62.86%骤降至44.04%，直接拖累整体业绩。
- **[产能利用率不足]** -> [固定成本刚性侵蚀利润]: 产能利用率从83.40%降至60.21%，折旧等固定成本分摊至更少产品，导致单位成本高企，毛利率承压。
- **[计提大额资产减值]** -> [净利润进一步恶化]: 对库龄较长存货计提跌价准备1113万元，同时因客户回款慢计提坏账准备2072万元，合计超3185万元。
- **[冲回递延所得税资产]** -> [净利润减少2312万元]: 基于对未来盈利无法覆盖可弥补亏损的谨慎判断，冲回部分递延所得税资产，直接减少当期净利润。
- **[直播电商与防弹装备业务增长]** -> [部分对冲主业下滑]: 电商业务（超琦科技、宇岛科技）和防弹防护装备出口订单实现增长，但体量不足以弥补皮具主业和团购业务的萎缩。
- **[研发投入大幅削减]** -> [长期竞争力存疑]: 研发费用同比骤降53.84%，研发人员减少44.79%，可能削弱产品创新与差异化能力。
- **[经营活动现金流大幅转负]** -> [资金链承压]: 经营活动现金流净额从+7844万元骤降至-7036万元，主因销售回款减少，显示公司造血能力严重恶化。

## 风险警告
公司已连续三年亏损，且亏损额巨大（2025年归母净利-1.51亿元），净资产已从4.9亿骤降至1.66亿，净资产收益率-63.13%，财务状况极度脆弱。核心皮具业务在行业存量竞争、需求疲软及团购客户订单减少的三重打击下持续萎缩，毛利率仅3.48%，几乎无利可图。公司虽在电商和防弹装备领域找到增长点，但体量尚小，无法扭转整体颓势。

更严峻的是，公司为“止血”大幅削减研发投入（-53.84%），并冲回递延所得税资产，这些短期“财务操作”可能以牺牲长期竞争力为代价。同时，经营活动现金流大幅转负，叠加大量资产受限（抵押、质押、冻结），公司资金链已高度紧张，持续经营能力面临重大考验。
