# 600236.SH 深度透视

## 因果逻辑链
- **[来水丰沛]** -> [水电发电量同比+35.92%]: 2025年主要水电厂流域来水同比大幅增加，直接驱动水电发电量创历史第二高位。
- **[水电发电量高增]** -> [归母净利润同比+43.63%]: 水电是公司核心利润来源（占利润总额97.4%），发电量增长直接转化为利润弹性，抵消了火电亏损和电价下行压力。
- **[火电发电量骤降]** -> [火电业务亏损扩大至-2.19亿元]: 火电发电量同比-58.89%，导致单位固定成本上升，燃料成本虽降但无法覆盖收入减少，火电成为主要拖累。
- **[新能源装机扩张]** -> [光伏发电量同比+34.43%]: 年度新增装机112.91万千瓦，驱动光伏发电量增长，但风电因来风不佳发电量微降。
- **[融资成本压降]** -> [财务费用同比-4.34%]: 通过发行低利率债券、压降高息融资，综合融资成本率行业领先，财务费用减少超2300万元，直接增厚利润。
- **[高比例分红]** -> [累计分红占净利润70.42%]: 连续3年实施年中+年度分红策略，2025年累计分红23.1亿元，强化了高股息防御属性。
- **[收购集团资产]** -> [优化西南清洁能源布局]: 收购大唐西藏公司和ZDN公司100%股权，为“十五五”新增装机目标储备优质水电和新能源资产。

## 风险警告
**核心风险在于业绩对来水的高度依赖与电价下行趋势的叠加。** 公司清洁能源装机占比超90%，水电是绝对利润支柱。2025年归母净利润暴增43.6%，几乎完全由来水偏丰驱动。一旦来水回归均值或偏枯，业绩将面临剧烈波动。同时，电力市场化改革深化，水电、新能源电价均面临下行压力（2025年水电平均电价已同比下降8.15%），量价双杀的风险不可忽视。

**新能源扩张带来的消纳与回报风险正在显现。** 公司光伏业务毛利率同比下降13.96个百分点，风电毛利率也下降6.78个百分点，反映出新能源装机快速扩张后，消纳受限、电价竞争加剧对盈利能力的侵蚀。公司虽通过“一企一策”治理亏损，但新能源亏损企业户数仍较高，未来大规模资本开支（2025年投资活动净流出40.3亿元）能否转化为预期回报存在不确定性。
