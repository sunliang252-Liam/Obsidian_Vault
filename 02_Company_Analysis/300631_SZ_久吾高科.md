# 300631.SZ 深度透视

## 因果逻辑链
- **[盐湖提锂订单交付与拓展]** -> [营收与净利润双增]: 公司完成盐湖股份4万吨/年基础锂盐项目高性能吸附剂交付，并签约新疆国投罗钾膜分离和西藏麻米措吸附剂订单，带动吸附分离业务收入增长20.70%，净利润增长38.97%。
- **[新能源服务板块持续发力]** -> [业绩增长核心引擎]: 公司凭借“吸附+膜”法盐湖提锂技术及自主锂吸附剂材料，成为国内盐湖资源企业核心供应商，新能源服务领域贡献主要增量。
- **[工业流体分离与水处理业务多点开花]** -> [收入结构多元化]: 生物发酵板块合同额创十年新高，氯碱化工碳化硅管式膜落地多个订单，水处理领域在山东、新疆取得大型订单，分散了单一行业波动风险。
- **[经营性现金流大幅改善]** -> [财务健康度提升]: 销售回款增加，经营活动现金流净额达2.16亿元，同比增长129.81%，连续三年增长，显示盈利质量与资金周转效率显著优化。
- **[高强度研发投入]** -> [技术壁垒与未来增长点]: 研发投入占营收8.48%，聚焦固态电解质（LLZO/LATP/硫化锂）、固相合成载体等新材料，已获头部电芯企业认可，为切入固态电池产业链奠定基础。
- **[锂吸附剂产能利用率低]** -> [短期成本压力]: 吸附剂设计产能6000t/a，但产能利用率仅25.55%，表明产能尚未充分释放，固定成本摊销压力较大，需依赖后续订单增长来摊薄。
- **[信用减值损失大幅增加]** -> [侵蚀利润]: 报告期内信用减值损失达4532万元，占利润总额55.30%，主要系应收账款坏账计提，反映下游客户资金紧张及回款周期延长风险。

## 风险警告
**应收账款回收与信用减值风险是当前最核心的财务隐忧。** 公司信用减值损失高达4532万元，占利润总额55.30%，远超净利润增幅。随着业务规模扩大，应收账款绝对值持续高企，部分客户受宏观经济影响资金紧张，导致回款周期延长，质保金回收困难。若下游行业景气度下行，坏账风险将进一步侵蚀公司利润，需密切关注应收账款周转率及账龄结构变化。

**下游行业波动与竞争加剧风险并存。** 公司业绩高度依赖盐湖提锂、化工、环保等下游行业的固定资产投资周期。碳酸锂价格波动可能导致盐湖提锂项目投资节奏放缓，影响吸附剂订单持续性。同时，膜分离及盐湖提锂领域竞争日趋激烈，公司部分产品毛利率已承压，若不能持续保持技术领先和成本优势，市场份额与盈利能力可能受到冲击。
