# 003015.SZ 深度透视

## 因果逻辑链
- **[调光导电膜渗透率提升]** -> [营收与利润高增]: 汽车调光天幕市场爆发，公司作为全技术路线电极层供应商，调光导电膜收入同比+190%，驱动整体营收+14.5%，净利润+55%。
- **[AR光学膜国产替代]** -> [第二增长曲线形成]: 车载显示与折叠屏需求驱动，AR膜收入同比+110%，毛利率大幅提升34.4个百分点，成为利润新引擎。
- **[ITO导电膜技术路径替代]** -> [传统业务承压]: OLED与in-cell技术挤压外挂薄膜式市场，ITO导电膜收入同比-11.6%，但公司凭借全球52%市占率守住基本盘。
- **[产业链垂直整合]** -> [成本优势与毛利率提升]: 自产IM消影膜、PET保护膜等上游材料，导电膜产品毛利率同比+1.42%，整体毛利率同比+5.83%。
- **[员工持股计划股份支付]** -> [管理费用激增]: 报告期确认股份支付费用约4075万元，导致管理费用同比+63.6%，但扣除后净利润同比+108.5%。
- **[OCA光学胶价格战]** -> [业务战略性收缩]: 市场竞争加剧，公司主动调减产量，OCA收入同比-22.8%，且仍处于亏损状态（毛利率-6.53%）。
- **[产能扩张与设备投资]** -> [资本开支大幅增加]: 年产600万平米功能性膜项目及真空磁控溅镀设备采购，投资活动现金流净流出同比-3329%。

## 风险警告
**核心风险在于传统ITO导电膜业务的持续萎缩与新兴业务增长的可持续性。** 智能手机OLED渗透率已超45%，in-cell技术良率突破至88%，外挂薄膜式方案在消费电子领域被系统性替代。公司ITO导电膜收入已连续下滑，若调光导电膜与AR膜的增长无法持续对冲，业绩将面临拐点。

**OCA光学胶业务是拖累利润的“出血点”。** 该产品毛利率为-6.53%，仍处于亏损状态，且公司主动调减产量。高端耐折叠与曲面OCA尚在客户端认证，短期内难以贡献利润。若该业务无法扭亏，将持续侵蚀整体盈利能力。此外，公司前五大客户集中度高达47%，单一客户依赖风险需警惕。
