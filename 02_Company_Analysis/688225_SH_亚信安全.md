# 688225.SH 深度透视

## 因果逻辑链
- **[并购亚信科技]** -> [营收暴增115%，但归母净利润巨亏4.46亿]: 2024年11月完成对亚信科技的控股合并，2025年首次完整并表，营收规模从35.95亿跃升至77.41亿；但并购带来的商誉减值、无形资产摊销、并购贷款利息费用，叠加参股公司公允价值变动损失，导致净利润由盈转亏。
- **[行业逻辑切换：从“合规驱动”到“业务价值驱动”]** -> [网络安全业务营收同比下降16.5%]: 客户安全投入从政策红利驱动的“可选项”转向保障业务连续性的“必须项”，需求结构化分化，公司主动放弃低效业务，聚焦核心产品，导致短期营收承压。
- **[AI XDR产品首年订单破亿]** -> [验证“数据驱动、AI原生”战略的商业化能力]: 业界首发的AI XDR联动防御系统，将误报率从62%压缩至8%，处置效率提升7.5倍，首年订单突破1亿元，标志着从“单点防御”向“AI统御”的范式跃迁获得市场认可。
- **[数智业务：运营商核心系统趋稳，智能数据运营增长超30%]** -> [数智业务归母净利润仅825万元，但经营性现金流大幅转正]: 运营商核心系统业务基本盘趋稳，智能数据运营业务同比增长逾30%，与阿里、火山等生态伙伴合作订单爆发式增长超41倍；但受运营商客户降本增效及非经营性事项影响，利润贡献有限，回款改善是亮点。
- **[安全+数智协同：云网安一体化案例落地]** -> [验证“业务场景驱动、安全能力共生”模式的可复制性]: 在某发电集团项目中，亚信科技提供大模型底座，亚信安全提供专业模型防护，实现设备诊断效率提升300%、安全事件减少72%，该模式已在3家能源企业推广。
- **[计提减值与公允价值变动损失]** -> [非经常性损益亏损1.08亿，加剧净利润亏损]: 报告期内，其他非流动金融资产公允价值变动损失1.4亿元，交易性金融资产公允价值变动损失0.2亿元，叠加信用及资产减值损失增加，是净利润大幅亏损的核心原因之一。

## 风险警告
**并购整合与商誉减值风险。** 公司2024年完成对亚信科技的并购，2025年首次完整并表即出现巨额亏损。并购形成的商誉及无形资产规模巨大，若未来亚信科技业绩不达预期（如运营商客户持续降本增效、新业务拓展不及预期），将面临大额商誉减值风险，直接侵蚀公司净资产和利润。此外，并购贷款带来的财务费用压力将持续存在，考验公司现金流管理能力。

**网络安全业务“以价换量”与竞争加剧风险。** 网络安全业务营收同比下降16.5%，虽然公司解释为主动放弃低效业务，但行业需求结构化分化、竞争加剧是不争事实。AI XDR等新产品虽订单破亿，但能否快速放量以弥补传统业务下滑，尚待验证。同时，公司毛利率从61.35%下降至55.62%，产品结构优化能否持续对冲价格压力，存在不确定性。
