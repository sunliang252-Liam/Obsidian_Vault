# 605598.SH 深度透视

## 因果逻辑链
- **[海外业务扩张]** -> [营收增长21%]: 公司持续深耕东南亚、中东市场，海外营收同比增长20.21%，拉动总营收至15.69亿元。
- **[毛利率大幅下滑]** -> [净利润下降29%]: 境外桩基项目毛利率骤降14.83个百分点，叠加营业成本增速（31.85%）远超营收增速（21.03%），严重侵蚀利润。
- **[新能源基建放量]** -> [收入结构优化]: 新能源基建业务从无到有，贡献2.45亿元收入，成为第三大收入来源，对冲了传统桩基业务的下滑。
- **[新业务培育投入]** -> [管理费用高企]: 管理费用达2.26亿元，同比增长16%，主要系拓展空间能源、钙钛矿等新业务导致管理成本增加。
- **[汇率剧烈波动]** -> [财务费用转正]: 财务费用从-1877万元升至-819万元，汇兑收益大幅减少，叠加其他综合收益中-6923万元的外币折算损失，对利润造成双重打击。
- **[应收账款与合同资产膨胀]** -> [现金流改善但风险累积]: 尽管经营性现金流净额由负转正至1.53亿元，但合同资产同比大增35%，回款压力持续存在。
- **[股权激励失效]** -> [人才激励受阻]: 因业绩未达标，公司回购注销了117.6万股限制性股票，核心团队激励效果大打折扣。

## 风险警告
**核心风险在于“增收不增利”的恶化趋势。** 公司营收增长21%，但净利润却逆势下滑29%，根本原因是境外桩基业务毛利率雪崩式下跌近15个百分点，直接拉低整体盈利水平。这表明公司在海外市场的扩张是以牺牲利润为代价的，项目质量或成本控制出现严重问题。若此趋势延续，即便营收持续增长，股东回报也将持续缩水。

**第二重风险来自新业务的“烧钱”不确定性。** 公司正大力布局空间能源系统和钙钛矿太阳能电池，虽然已获得订单和认证，但两者均处于培育期，尚未形成稳定盈利。高昂的管理费用和研发投入已对当期利润构成压力。若商业化落地不及预期，这些新业务将成为持续的利润黑洞，而非第二增长曲线。同时，高达6923万元的外币折算损失暴露了公司对汇率波动的脆弱性，海外资产占比超71%的背景下，这一风险不容忽视。
