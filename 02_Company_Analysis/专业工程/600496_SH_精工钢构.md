# 600496.SH 深度透视

## 因果逻辑链
- **新质生产力培育成效显现，高技术制造业增加值同比增长9.4%** -> 工业建筑订单突破100亿，钢结构销量同比增长27.6%: 高端制造业强劲增长催生高标准工业厂房需求，公司凭借技术和服务优势承接比亚迪、小米等龙头企业项目
- **海外订单同比增长140.1%，占比从13.7%升至29.7%** -> 归母净利润同比增长18.23%，毛利率提升: 海外订单毛利率更高、付款条件更优，高毛利业务占比提升拉动整体盈利改善
- **"好房子"政策加速落地，装配式建筑获政策支持** -> EPC及装配式业务新签EPC订单28亿元，并中标多个重点项目: 政策推动建设安全、舒适、绿色、智慧的住宅，装配式钢结构契合要求，公司自研PEC体系抢占先机
- **光伏产业快速发展，分布式光伏新增1.53亿千瓦** -> BIPV业务新签订单同比增长60.8%: 光伏装机高速增长带动建筑光伏一体化需求，公司依托工业建筑屋面资源推出'钢结构+分布式光伏'服务
- **制造业出海浪潮，中国企业海外建厂需求旺盛** -> 海外工业建筑订单同比增长41.5%: 国内龙头企业外迁带动钢结构出海，公司凭借国内客户基础延伸至海外
- **研发投入7.2亿元，获国际领先技术认证** -> 成功开拓中东等高端市场，承接沙特阿美体育场等项目: 技术创新解决海外高抗震等难题，品牌和技术优势获得国际认可
- **精益管理，期间费用率连续三年下降** -> 营业收入同比增长12.69%的同时，归母净利润增速18.23%高于收入增速: 费用管控提升盈利效率，助力利润超收入增长
- **数字化转型：MOM系统上线，业财一体化** -> 运营效率提升，成本结构优化: 数字化全链条协同降低管理成本，提升交付效率

## 风险警告
扣非净利润同比下降5.06%，主要受非经常性损益波动影响，需关注主营业务盈利可持续性。海外业务占比提升带来汇率、政治等风险，需持续跟踪地缘政治变化及项目回款情况。此外，钢结构行业毛利率下滑1.79个百分点，成本控制压力加大。
