# 002593.SZ 深度透视

## 因果逻辑链
- **[海外市场扩张]** -> [营收与利润双增]: 公司加大海外市场开拓，车轮出口订单大幅增长，带动钢制车轮产销量同比增长超30%，海外收入占比提升至59.14%，是业绩增长的核心驱动力。
- **[海外业务高毛利]** -> [整体毛利率提升]: 海外业务毛利率达21.47%，远高于国内业务的2.57%，海外收入占比提升直接拉高了公司综合毛利率，尤其是车轮业务毛利率同比提升5.73个百分点。
- **[越南产能布局]** -> [规避贸易壁垒]: 公司在越南设立生产基地，利用其CPTPP成员国关税优势，有效应对欧美反倾销调查，保障了出口业务的稳定性和竞争力。
- **[客户结构调整]** -> [钢结构业务复苏]: 公司主动调整钢结构业务客户结构，聚焦石化设备钢结构和海外工程领域，海外订单逐步回升，钢结构营收同比增长23.95%，毛利率提升约2个百分点。
- **[原材料成本控制]** -> [成本压力缓解]: 公司通过“高价位低库存、低价位高库存”的采购策略及与钢厂锁价，有效应对钢材价格波动，使得营业成本增速（9.68%）低于营收增速（17.38%），保障了利润空间。
- **[财务杠杆优化]** -> [财务费用增加]: 公司进行贷款结构调整，增加长期借款、减少短期借款，但受人民币兑美元汇率升值影响，汇兑损失增加，导致财务费用同比增长57.59%，对利润形成一定侵蚀。
- **[研发投入]** -> [产品线拓展]: 公司持续研发非公路机械钢轮等新产品，已实现部分规格量产，为未来开辟新的盈利增长点。

## 风险警告
**1. 国际贸易政策与汇率波动风险：** 公司车轮出口业务占比超过80%，且主要市场为欧美。尽管通过越南产能布局部分对冲了反倾销风险，但全球贸易保护主义抬头、地缘政治冲突加剧，以及越南本身也可能面临反规避调查，使得公司海外业务面临高度的政策不确定性。同时，美元结算为主的模式使公司利润极易受人民币汇率波动影响，2025年汇兑损失已显著增加。

**2. 应收账款与现金流风险：** 钢结构业务“长账期、高垫资”的行业特性导致公司应收账款余额较大（9.26亿元），且存在多起工程款诉讼。虽然公司已加强催收，但若宏观经济下行或下游客户资信恶化，坏账风险将显著上升。2025年经营活动现金流净额同比下降29.73%，与净利润增长背离，显示盈利质量有待提升，资金周转压力不容忽视。
