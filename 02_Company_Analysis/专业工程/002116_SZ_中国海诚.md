## 因果逻辑链
- **[工程总承包业务收入增长8.57%]** -> [营收微增1.99%]: 总承包业务收入54.78亿元，占比78.74%，是营收增长的核心驱动力，但设计、监理业务收入分别下降12.29%和16.63%，拖累整体增速。
- **[经营活动现金流净额-1.14亿元，同比-141.07%]** -> [现金流与净利润严重背离]: 项目结算周期与分包付款节奏存在阶段性错配，支付的工程款项总量增加，导致经营性现金净流出，而净利润为3.41亿元。
- **[境外新签订单20.17亿元，同比增长5.70%]** -> [海外业务版图持续扩大]: 公司聚焦“一带一路”沿线，依托优势行业率先突破，境外业务收入占比提升至16.25%，成为对冲国内周期的重要增长极。
- **[新签合同总额85.02亿元，同比下降1.32%]** -> [订单增长承压]: 传统优势行业如日用化工(-47.03%)、医药(-53.95%)新签订单大幅下滑，虽环保(+99.44%)、食品发酵(+27.67%)增长强劲，但整体订单仍显疲软。
- **[埃塞俄比亚PVC项目全面停工]** -> [重大海外项目风险暴露]: 因当地战争，该项目自2020年11月停工，累计确认收入5.55亿元，未完工部分7.01亿元，已完工未结算余额0.48亿元，存在重大减值风险。
- **[应收账款及合同资产合计19.79亿元]** -> [资产减值压力]: 应收账款和合同资产账面价值合计占净资产的71.4%，且减值测试涉及重大管理层判断，是审计关键事项，回款风险不容忽视。
- **[研发投入2.76亿元，同比增长4.68%]** -> [科技创新驱动转型]: 公司持续加大在智能制造、绿色低碳（“双碳”）、AI智能体等领域的研发投入，旨在培育新质生产力，打造未来增长支柱。
- **[“十五五”战略聚焦“数智双驱、新质生长”]** -> [战略转型方向明确]: 公司锚定生物产业、新能源、新材料、节能环保等战略新兴领域，着力从传统工程公司向“卓越的科技型工程公司”升维蜕变。

## 风险警告
**核心风险在于现金流恶化与海外项目“黑天鹅”。** 2025年经营活动现金流净额由正转负，骤降至-1.14亿元，与3.41亿元的净利润严重背离，表明公司盈利质量堪忧。更关键的是，埃塞俄比亚年产6万吨PVC树脂项目因战争长期停工，涉及未完工金额超7亿元，已完工未结算余额近0.5亿元，一旦确认损失，将对利润表造成重大冲击。这暴露了公司在高风险地区开展EPC总承包业务的脆弱性。

**第二重风险是传统业务萎缩与订单增长乏力。** 工程设计、监理两大高毛利业务收入分别下滑12.29%和16.63%，显示公司基本盘正在承压。同时，新签合同总额同比下降1.32%，其中日用化工、医药等优势行业订单大幅下滑，虽然环保和食品发酵订单增长，但难以完全弥补缺口。若不能有效巩固传统市场并加速新业务落地，公司可能面临“青黄不接”的增长困境。
