# 600970.SH 深度透视

## 因果逻辑链
- **[境外新签合同高增]** -> [收入结构优化]: 境外新签合同额同比增长24%，占比升至63%，驱动境外收入同比增长22%，有效对冲国内水泥行业需求下滑。
- **[“两外一服”装备战略]** -> [装备业务突破]: 装备业务境外合同额同比+51%，外行业合同占比升至42%，推动装备制造收入同比增长12%，打开第二增长曲线。
- **[水泥运维生产线扩张]** -> [运维收入稳健]: 在执行水泥运维生产线增至74条（境外61条），矿山运维项目326个，支撑生产运营服务收入同比增长3.78%。
- **[技改与多元化工程发力]** -> [工程服务韧性]: 水泥工程技改合同额同比+61%，多元化工程合同额同比+170%，弥补了国内整线EPC需求萎缩的影响。
- **[欧元升值]** -> [财务费用大幅下降]: 报告期欧元升值产生汇兑收益，财务费用由上年同期2.74亿元降至-1.43亿元，直接增厚利润。
- **[合肥院业绩承诺到期]** -> [短期业绩压力]: 2025年为合肥院业绩承诺最后一年，实际完成率仅88.58%，显示国内建材行业深度调整对盈利能力的侵蚀。
- **[经营活动现金流恶化]** -> [盈利质量隐忧]: 净利润同比仅降4%，但经营性现金流净额同比大降22%，盈利与现金流的匹配度显著恶化。

## 风险警告
**核心风险在于盈利质量与增长可持续性的背离。** 公司2025年净利润微降4%，但经营性现金流净额同比骤降22%，且第四季度现金流虽为正，前三季度累计为负，显示“纸面利润”向“真实现金”转化能力减弱。同时，国内水泥行业需求持续萎缩（产量同比-6.9%），公司境内收入同比下降6.44%，境内新签合同额同比-4%，境内业务基本盘承压明显。

**另一重大风险是境外经营的复杂性与合肥院整合后的业绩兑现。** 公司63%新签合同来自境外，业务遍布91国，地缘政治、汇率波动（埃镑等小币种贬值风险）、项目履约风险持续存在。此外，合肥院2025年业绩承诺完成率仅88.58%，虽累计完成，但单年未达标已敲响警钟，后续若无业绩补偿支撑，其盈利能力下滑将直接拖累合并报表。公司应收账款与存货（“两金”）压降压力巨大，是现金流恶化的直接推手。
