# 601618.SH 深度透视

## 因果逻辑链
- **[主动剥离非核心资产]** -> [归母净利润暴跌80.41%]: 2025年底出售中冶置业、有色院等资产，产生大额资产减值损失（-194.4亿）和投资损失（+181.9亿），导致利润表剧烈波动。
- **[聚焦主业“一核心两主体五特色”]** -> [冶金工程新签合同额逆势增长12.3%]: 主动收缩低效房建业务，资源向冶金、矿山等核心主业集中，巩固了全球冶金建设龙头地位。
- **[海外战略深耕]** -> [海外新签合同额首破千亿]: 新签合同额达1007亿元，同比增长6%，其中冶金矿山类占比60.5%，海外业务结构优化，成为增长新引擎。
- **[优化项目结构，放弃无效合同]** -> [营业收入同比下降17.51%]: 坚持“不要没有收入的合同”，主动放弃低质量、低利润项目，导致营收规模收缩，但工程承包毛利率微增0.33个百分点。
- **[狠抓清收与资金管理]** -> [经营性现金流净额同比大增95.25%]: 经营活动现金流净额达153.2亿元，大幅改善，表明公司回款能力增强，财务质量提升。
- **[处置资产回收现金]** -> [投资活动现金流净额由负转正]: 出售资产收回大量现金，投资活动现金流净额达237.1亿元，为公司降杠杆、偿还债务提供了充足弹药。
- **[母公司未分配利润为负]** -> [2025年度不进行现金分红]: 母公司报表累计未分配利润为-27.85亿元，不满足分红条件，直接影响了股东回报。

## 风险警告
**核心风险在于“转型阵痛”与“资产质量”的双重压力。** 公司2025年归母净利润暴跌80%，核心原因是主动剥离房地产业务和部分矿产资源，导致当期计提了高达194.4亿元的资产减值损失。这虽然是一次性“财务洗澡”，旨在轻装上阵，但短期内严重侵蚀了利润，并导致母公司报表出现巨额未弥补亏损，直接取消了年度分红。投资者需警惕，这种“甩包袱”式的资产出售，其后续的协同效应和盈利修复能力尚需时间验证。

**更深层的风险是建筑行业整体下行的系统性压力。** 尽管公司通过聚焦主业、优化结构抵御了部分风险，但国内建筑业总产值同比下降1.13%，传统房建持续萎缩。公司营收下降17.51%，新签合同额下降10.87%，表明市场蛋糕在缩小。同时，应收账款和合同资产合计高达4329亿元，占总资产比重超过51%，且信用减值损失和资产减值损失合计高达276.5亿元，反映出下游客户（尤其是地方政府和房企）的支付能力恶化，坏账风险高企。公司能否在行业“内卷”中持续提升毛利率并有效回收现金，是未来业绩能否反转的关键。
