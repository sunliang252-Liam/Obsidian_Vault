# 601068.SH 深度透视

## 因果逻辑链
- **[聚焦主业，退出低效非工业项目]** -> [营收下降3.93%]: 主动退出市政、民建等高风险低效业务，导致短期收入规模收缩，但业务结构优化。
- **[新签合同额爆发式增长51.94%，海外合同增长263.38%]** -> [未来收入增长潜力]: 新签工业类合同占比97.73%，EPC合同占比60.47%，为未来2-3年业绩释放奠定基础。
- **[强化项目全过程成本管控与“两制”管理]** -> [毛利率提升1.33个百分点至13.54%]: 减少分包层级、优化采购，创近年最高毛利率水平，盈利能力改善。
- **[科技成果转化与“技术+装备”模式落地]** -> [装备制造收入增长44.14%]: 99项核心技术成果推广，新签合同超49亿元，驱动高毛利装备业务成为增长新引擎。
- **[强化收款管理与长账龄项目清收]** -> [经营现金流由负转正至8.91亿元]: 经营活动现金流净额同比大幅改善35.86亿元，现金流风险显著降低。
- **[人民币升值导致汇兑收益减少]** -> [财务费用激增61.63%]: 尽管压降融资规模减少利息费用1亿元，但汇兑收益同比减少1.86亿元，侵蚀利润。
- **[母公司累计未弥补亏损4.75亿元]** -> [无法进行现金分红]: 受历史亏损拖累，公司目前不满足分红条件，股东回报受限。

## 风险警告
**核心风险在于“增收不增利”的潜在困境与海外业务的高波动性。** 尽管新签合同额暴增，但营收反而下降，说明订单转化为收入的周期拉长。同时，财务费用因汇兑损益大幅波动，暴露出公司对汇率风险的管控能力不足。若人民币持续升值，将严重侵蚀海外项目利润，这是公司当前最直接的财务风险。

**战略转型的执行风险不容忽视。** 公司正从传统工程承包向“科技+国际”转型，但EPC总承包业务毛利率仅10.34%，且海外项目面临地缘政治、合规标准差异等复杂挑战。若项目履约能力、供应链管理或海外风险防控跟不上业务扩张速度，可能导致大规模项目亏损，重蹈历史覆辙。母公司未弥补亏损的存在，也限制了公司通过股权融资或分红来优化资本结构的能力。
