# 600369.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度提升]** -> [经纪业务收入增长15.47%]: 2025年A股成交额突破400万亿创历史纪录，公司佣金及两融业务直接受益。
- **[“投研+投资+投行”联动模式深化]** -> [投行业务收入暴增90%]: 成功打造松发股份、至正股份等标杆并购项目，品牌溢价转化为收入。
- **[债券及理财投资规模扩张]** -> [交易性金融资产增长46%]: 公司主动加仓固收及银行理财，驱动自营业务收入增长54.17%。
- **[两融业务规模扩张]** -> [融出资金增长53.7%]: 市场风险偏好回升，客户融资需求旺盛，利息净收入增长30.64%。
- **[深耕重庆区域战略]** -> [服务成渝投融资近300亿]: 与39个区县建立战略合作，将区位优势转化为稳定的项目来源与客户粘性。
- **[60亿增资预案获批]** -> [资本实力与业务空间提升]: 作为2026年券业定增首单，为后续业务扩张和风险抵御提供资本支撑。
- **[衍生品及客需业务创新]** -> [公允价值变动收益增长62.52%]: 落地碳中和信用衍生品等创新业务，增厚非方向性投资收益。

## 风险警告
**核心风险在于业绩对市场行情的强依赖性。** 2025年营收与利润的高增长（+25%、+52%）高度依赖A股成交额创历史新高和“股强债弱”的有利格局。一旦市场活跃度回落或出现系统性下跌，经纪业务佣金、两融利息及自营投资收益将同步承压，业绩波动性极大。公司经营活动现金流净额为-46亿元，主要因金融资产和融出资金规模扩张，流动性管理压力不容忽视。

**信用与合规风险是长期隐患。** 公司信用减值损失由负转正，计提0.67亿元，主要来自融出资金及应收款。历史上涉及多起股票质押及债券违约诉讼（如新研股份、正源地产），虽以管理人身份代行权利，但暴露了项目风控的潜在漏洞。此外，投行业务收入暴增90%的可持续性存疑，若后续项目质量不达预期，可能面临监管问责或声誉风险。
