# 000779.SZ 深度透视

## 因果逻辑链
- **[行业需求萎缩与竞争加剧]** -> [营收增长乏力，利润大幅下滑]: 传统基建市场萎缩，低价竞争导致“揽活难、结算难、回款难”，公司营收仅微增4.15%，但归母净利润同比暴跌31.32%。
- **[信用减值损失激增]** -> [净利润被严重侵蚀]: 报告期信用减值损失高达1.69亿元，占利润总额的94.51%，是净利润下滑的核心原因，直接反映了行业下行导致的客户回款困难。
- **[新签合同额增长与收入确认滞后]** -> [现金流改善但利润承压]: 新签合同额同比增长10.28%，但转化为收入需要时间，导致经营活动现金流净额增长30.77%，而利润却因减值大幅下降。
- **[核心勘察设计业务萎缩]** -> [收入结构被动调整]: 作为核心的勘察设计业务收入同比下降7.73%，而毛利率更低的工程施工业务收入暴增82.18%，显示公司为保规模被迫承接低毛利项目。
- **[省外市场拓展见效]** -> [对冲省内市场压力]: 省外合同额同比增长32.98%，增速远超省内，表明公司“走出去”战略初步成功，但省外收入占比仍低（6.02%），尚无法完全弥补省内下滑。
- **[城市更新与水利政策红利]** -> [新业务增长点初现]: 公司抓住城市更新、水利建设等政策机遇，新业务合同额同比增长17.53%，成为对冲传统业务下滑的关键力量。
- **[研发投入资本化率骤降]** -> [短期利润承压，长期技术储备夯实]: 研发投入资本化率从15.55%降至2.46%，更多研发费用被当期费用化，虽拖累当期利润，但体现了更审慎的会计处理，长期利好技术积累。

## 风险警告
**核心风险是信用减值与现金流危机。** 报告期信用减值损失高达1.69亿元，是吞噬利润的“头号杀手”，直接反映了行业“回款难”的严峻现实。尽管经营性现金流净额有所改善，但应收账款仍高达14.58亿元，占总资产26.43%，且账龄结构可能恶化。若宏观经济持续低迷，客户资金链断裂，公司将面临巨大的坏账风险和流动性压力，利润表与资产负债表将同时承压。

**第二重风险是主业萎缩与竞争加剧。** 核心的勘察设计业务收入下滑7.73%，毛利率更高的传统业务正在被低毛利的工程施工业务所替代，这反映了公司为维持营收规模而牺牲盈利能力的被动局面。同时，行业需求不足、供给过剩、同质化竞争加剧的格局短期内难以改变，公司作为区域性龙头，在省外市场拓展尚处初期，面临“守不住省内，打不开省外”的双重挤压风险。
