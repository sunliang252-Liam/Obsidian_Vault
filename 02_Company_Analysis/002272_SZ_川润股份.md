# 002272.SZ 深度透视

## 因果逻辑链
- **全球能源结构转型及风电、光伏装机容量快速增长** -> 新能源流体系统业务销售收入同比增长40.80%: 下游风电、光伏等行业需求旺盛，公司凭借技术优势和市场地位获得更多订单
- **算力需求爆发与数据中心建设加速** -> 液冷系统及产品销售收入同比增长77.76%: 高发热密度的数据中心对液冷温控需求增加，公司液冷解决方案产线投产并获客户认可
- **国家对清洁能源和储能产业的政策支持** -> 储能装备及系统集成销售收入同比增长50.76%: 政策推动储能装机快速增长，公司储能液冷及系统集成业务受益
- **传统煤电改造需求及算力带来的刚性电力需求** -> 清洁能源装备及解决方案销售收入同比下降32.00%: 但下降原因未明确，可能因订单确认节奏或市场竞争，需关注
- **公司加强应收账款与存货精细化管理** -> 资产减值损失同比大幅下降，净利润同比上升78.46%: 管理优化降低坏账和存货跌价损失，改善盈利
- **公司研发投入及技术创新（如数据中心液冷技术达到国内领先）** -> 液冷业务收入快速增长及新客户开拓: 技术创新提升产品竞争力，赢得客户信赖
- **公司实施降本增效措施（DFMA等）** -> 综合毛利率同比上升0.62个百分点: 成本管控有效，提升盈利能力

## 风险警告
公司虽受益于新能源和液冷业务增长，但清洁能源装备收入下滑32%，且整体净利润仍为负（-2491万元），扣非净利润-4462万元。液冷业务尚处投入期，募投项目能否持续放量存不确定性。此外，出口收入下降55.97%，海外市场风险需关注。传统火电改造需求可能受政策节奏影响。
