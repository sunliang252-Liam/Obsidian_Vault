# 002922.SZ 深度透视

## 因果逻辑链
- **[新能源产品价格竞争加剧]** -> [毛利率下降2.55个百分点]: 部分新能源产品销售价格下降，直接侵蚀了产品利润空间，导致整体盈利能力下滑。
- **[海外市场拓展与产能建设]** -> [境外收入增长40.72%]: 公司深耕欧洲、北美市场，并推进泰国、美国、墨西哥工厂投产，海外本地化供应能力提升带动收入高增。
- **[孵化类业务放量]** -> [其他产品收入增长92.87%]: 通讯电源、车载电源等新业务快速增长，为公司开辟了新的收入增长点，但毛利率同比下降7.30%。
- **[客户回款改善]** -> [经营活动现金流净额增长256.94%]: 报告期内收到客户回款增加，使得经营性现金流大幅改善，远超净利润水平。
- **[全球产能扩张与研发投入]** -> [期间费用增长20.54%]: 运营规模扩大、研发投入增加（+25.05%）及汇兑损失、利息增加，共同推高了期间费用。
- **[数据中心需求爆发]** -> [数据中心产品收入增长58.83%]: 受益于AI算力需求，数据中心变压器产品（移相、油浸、干式）收入高速增长，成为核心增长引擎。
- **[全球化产能布局]** -> [资本开支与负债增加]: 泰国、墨西哥、美国等海外基地建设导致投资活动现金流净流出12.29亿元，同时推高了短期借款和应付票据。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 尽管营收增长13.4%，但归母净利润同比大幅下滑31.45%，主因是新能源产品价格战导致毛利率承压。公司正处于大规模资本开支扩张期，海外产能（泰国、墨西哥、美国）尚未完全释放效益，而期间费用（尤其是研发和财务费用）刚性增长，短期内利润端压力巨大。

**国际化经营与汇率波动是另一重大风险。** 公司境外收入占比已提升至36.28%，且仍在加速海外建厂。美国、墨西哥等地的地缘政治风险、贸易政策变化以及人民币汇率波动，都可能对海外业务盈利能力和资产安全造成冲击。公司虽开展套期保值，但规模有限，风险敞口较大。
