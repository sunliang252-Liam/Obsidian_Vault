# 300087.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡与同质化竞争加剧]** -> [种子价格下行、毛利率下降]: 种子行业高库存、同质化严重，导致公司种子销售价格承压，核心种业毛利率下滑。
- **[基于谨慎性原则计提大额减值]** -> [归母净利润亏损2.12亿元]: 公司对应收款项（酒粮业务）、存货（玉米种子）及商誉（新纪元）计提了约2.8亿元资产减值，是亏损主因。
- **[子公司荃优种业订单业务扩张]** -> [营收增长但亏损加剧]: 荃优种业为拓展订单粮食业务，收入同比增长28.41%，但计提信用减值及存货跌价导致净利润增亏1.5亿元。
- **[核心子公司荃丰种业品种老化]** -> [利润大幅下滑]: 核心洁田技术推广受阻，成熟品种市场增长乏力，销量与价格齐跌，导致净利润同比下降30.29%。
- **[海外业务模式升级]** -> [出口收入稳定]: 海外团队从传统贸易向“种子+技术解决方案”综合服务转型，提升了客户依存度，海外收入约4.43亿元，保持行业前列。
- **[研发投入持续加码]** -> [新品种储备丰富]: 研发投入占种子销售收入比提升至7.28%，2025年共有57个新品种通过国家审定，为未来增长储备品种。
- **[控股股东同业竞争问题]** -> [通过股权委托管理解决]: 与中种集团在境内水稻、小麦种子领域的同业竞争，通过签订《股权委托管理协议》托管中种农科100%股权的方式解决。

## 风险警告
公司当前面临的核心风险是**资产质量恶化与合规风险**。2025年因行业下行，公司对子公司（如荃优种业）的应收款、存货及商誉计提了巨额减值，直接导致上市以来首次年度亏损。更严重的是，公司因涉嫌信息披露违法违规已被证监会立案调查，这暴露出内部控制在子公司（如荃银生物）酒粮业务等非核心领域的重大缺陷，未来可能面临监管处罚及投资者索赔，对品牌声誉和融资能力构成长期威胁。

其次，**主业增长乏力与业绩承诺不达标**的风险持续存在。种子行业供大于求、同质化竞争短期难以逆转，公司核心水稻种子收入下滑12.93%，玉米种子虽增长但毛利率下降10.26%。收购的新纪元种业连续两年未完成业绩承诺，已计提商誉减值，未来若行业环境未改善，商誉减值风险仍存。公司2026年经营目标能否实现，高度依赖新品种推广效果及行业景气度回升，存在较大不确定性。
