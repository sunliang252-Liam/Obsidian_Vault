# 920021.BJ 深度透视

## 因果逻辑链
- **[核心主业战略收缩]** -> [营收大幅下降38.54%]: 为控制应收账款风险，主动缩减低效电视频道覆盖业务及受国补冲击的3C商品销售，导致收入规模显著下滑。
- **[应收账款强力回款]** -> [经营现金流暴增566%]: 通过诉讼、债务重组等手段加强催收，应收账款减少1.35亿元，经营活动现金流净额达1.36亿元，实现“瘦身健体”。
- **[剥离亏损酒业子公司]** -> [净利润扭亏为盈]: 出售四川流金酒业，产生股权处置收益及内部交易损益确认，合计贡献超3300万元非经常性损益，是净利润转正的核心驱动力。
- **[白酒库存计提大额减值]** -> [扣非净利润深度亏损]: 剥离酒业后，基于会计规定对原采购白酒计提存货跌价准备2347万元，导致扣非净利润亏损扩大至-3316万元。
- **[视界慧景AIGC平台发布]** -> [开辟第二增长曲线]: 发布音视频垂类大模型，赋能广电全链条制作，并助力打造AI短剧，标志着公司从传统渠道商向AI技术平台商转型。
- **[贡爵微半导体业务]** -> [培育新利润增长点]: 控股子公司贡爵微的微波器件业务收入稳定增长（+1.27%），产品应用于卫星、雷达等高壁垒领域，是公司科技转型的实体支撑。
- **[客户集中度高]** -> [经营波动风险大]: 前五大客户收入占比39.44%，且第一大供应商为中国广电，对单一客户/供应商依赖度高，议价能力受限，业务稳定性受制于下游预算。

## 风险警告
公司2025年净利润扭亏为盈，但核心驱动力来自剥离亏损资产和会计处理带来的非经常性损益。扣除非经常性损益后，公司实际亏损3316万元，且亏损幅度同比扩大，表明主营业务造血能力依然脆弱。核心主业电视频道覆盖业务收入下滑30.87%，视频购物业务更是萎缩96%，公司正处于传统业务收缩、新业务尚未成熟的青黄不接期。

转型方向明确但商业化路径尚不清晰。公司全力押注“视界慧景”AIGC平台和贡爵微半导体业务，但前者仍处于产品推广初期，尚未形成规模化收入；后者虽技术壁垒高，但子公司持续亏损（-600万），且军工/卫星领域客户导入周期长。此外，公司应收账款虽大幅下降，但余额仍高达3.07亿元，占流动资产34%，且部分客户（如江西风尚）已进入破产程序，坏账风险并未完全出清。
