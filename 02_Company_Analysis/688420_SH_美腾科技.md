# 688420.SH 深度透视

## 因果逻辑链
- **[煤炭行业下行周期]** -> [营收与利润双降]: 下游客户资本开支收缩，公司2025年营收同比下降6.35%，归母净利润由盈转亏至-594.55万元。
- **[应收账款持续累积与坏账计提]** -> [利润侵蚀]: 公司以预期信用损失为基础，对应收账款等金融资产计提4,588.37万元信用损失，成为利润下滑的核心拖累项。
- **[政府补助减少]** -> [非经常性损益下降]: 其他收益（主要为政府补助）较去年同期减少1,586.23万元，进一步加剧利润下滑。
- **[市场竞争加剧与产品降价]** -> [毛利率承压]: 智能干选行业竞争者涌入（近20家），公司产品售价下降，综合毛利率从39.79%降至37.24%。
- **[新产品研发高投入]** -> [短期利润无贡献]: 年均研发投入占营收超10%（2025年5,703万元），动力电池回收、行业大模型等新业务尚处培育期，未形成利润支撑。
- **[非煤矿业与海外市场拓展]** -> [收入结构优化]: 非煤矿业收入同比+111.88%，海外收入同比+260.72%，对冲煤炭主业下滑，显示第二增长曲线初步成型。
- **[加强应收账款管理]** -> [经营现金流改善]: 销售商品、提供劳务收到的现金同比增加8,612.73万元，经营活动现金流净额从-1.02亿元大幅收窄至-0.11亿元。

## 风险警告
**核心风险在于煤炭行业深度调整与公司资产质量恶化之间的负向螺旋。** 公司营收高度依赖煤炭行业（占比76.71%），而煤炭行业利润总额2025年同比下降41.8%，资本开支持续收缩。在此背景下，公司应收账款、合同资产及应收票据合计占营收比例高达110.79%，且账龄持续拉长。若下游客户经营进一步恶化，坏账计提压力将持续侵蚀利润，形成“行业下行→回款困难→减值增加→利润亏损”的恶性循环。

**第二重风险来自战略转型的“青黄不接”。** 公司正从单一煤炭分选向锂电回收、工矿业大模型、超高压压滤等新赛道转型，研发投入高但商业化进程缓慢。锂电回收产线处理能力未达预期，大模型产品尚处标杆验证阶段，新业务短期内难以贡献利润。同时，传统智能干选业务面临近20家竞争对手的价格战，毛利率持续下滑。若新业务无法在1-2年内实现规模化收入，公司可能面临“老业务失血、新业务补血不足”的困境。
