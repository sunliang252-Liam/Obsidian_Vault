# 605566.SH 深度透视

## 因果逻辑链
- **[聚焦高牢度染料]** -> [净利润增长103.74%]: 主动优化产品结构，提升高水洗、高日晒牢度染料产销规模，抵消了常规染料和滤饼销量下滑的负面影响。
- **[光伏胶膜业务停产]** -> [亏损大幅减少]: 果断终止持续亏损的非核心光伏胶膜业务，相关子公司停产歇业并处置资产，直接减少了拖累整体利润的板块亏损。
- **[原材料价格下降]** -> [毛利率提升3.59个百分点]: 主要原材料如还原物、对硝基苯胺等价格同比下跌，直接降低了主营业务成本，在收入下滑背景下仍实现毛利率改善。
- **[滤饼销量大幅下滑]** -> [营业收入下降19.66%]: 滤饼作为中间产品，销量同比下降39.81%，是导致公司整体营收规模收缩的核心原因。
- **[计提资产减值]** -> [侵蚀当期利润]: 基于谨慎性原则，对商誉、存货等资产计提减值准备1,695.97万元，对净利润造成较大负面影响。
- **[员工持股计划实施]** -> [确认股份支付费用]: 2025年实施员工持股计划，产生股份支付费用，导致管理费用增加，并影响扣非净利润口径。
- **[产业链向上游延伸]** -> [提升供应链自主可控]: “分散染料中间体建设项目”逐步落地，旨在降低上游原材料价格波动对生产成本的影响，增强长期竞争力。

## 风险警告
**核心风险在于主业增长的天花板与多元化探索的不确定性。** 公司营收下滑19.66%，核心驱动力并非来自量价齐升，而是“砍掉亏损业务+优化产品结构”带来的利润修复。高牢度染料虽占比提升，但整体染料市场充分竞争，公司规模偏小，若行业龙头大举进入中高端细分市场，公司可能因规模劣势而处于不利竞争地位。同时，上游原材料价格波动是影响盈利的长期变量，公司向上游中间体延伸的成效尚需时间验证。

**新业务布局存在较大不确定性。** 公司通过投资钛深科技和设立双曲线智能机器人公司，跨界进入柔性传感领域。这与公司染料主业关联度极低，属于典型的“第二曲线”探索。新业务尚处早期，技术商业化、市场开拓及团队整合均面临挑战，短期内难以贡献利润，反而可能分散管理资源，增加经营风险。此外，公司账面仍有2,508万元商誉，若福莱蒽特科技未来业绩不达预期，存在进一步减值风险。
