# 600031.SH 深度透视

## 因果逻辑链
- **[全球化战略深化]** -> [国际收入占比64%，同比增长15.1%]: 海外自营渠道与本土化经营推动全球市场份额提升，非洲等新兴市场增速达55.29%。
- **[新能源产品爆发]** -> [新能源产品销售额86.4亿元，同比增长115%]: 电动搅拌车、电动挖掘机等产品在政策与“机器替人”趋势下实现商业化拐点，市占率行业第一。
- **[降本增效与规模效应]** -> [净利润增速(41.2%)远超营收增速(14.7%)]: 灯塔工厂与数智化运营降低制造成本，叠加海外高毛利产品占比提升，利润弹性显著释放。
- **[经营质量优化]** -> [经营现金流199.8亿元，创历史新高]: 严格的应收账款与存货管理，以及金融业务净放款减少，使现金流增速(34.8%)高于利润增速。
- **[国内需求结构性复苏]** -> [挖掘机械国内市占率连续15年第一]: 高标准农田、水利工程及设备更新政策托底，推动核心产品市场份额稳中有升。
- **[研发投入聚焦三化]** -> [研发费用50.33亿元，占营收5.79%]: 投向全球化、数智化、低碳化技术，支撑SAC2500E7PHEV等高端产品突破，构筑技术护城河。
- **[H股上市与资本运作]** -> [净资产增长22.8%至883亿元]: 发行H股募资及回购注销，优化资本结构，为全球化扩张提供资金支持。

## 风险警告
**核心风险在于全球宏观经济与地缘政治的不确定性。** 公司国际收入占比已超64%，海外市场（尤其是非洲、东南亚）的矿业与基建投资景气度直接决定增长持续性。若全球经济增速放缓或贸易壁垒加剧（如欧美对华工程机械加征关税），海外高毛利业务将面临量价双重压力，侵蚀利润弹性。

**另一关键风险是国内市场复苏的脆弱性。** 工程机械行业与国内固定资产投资高度相关，若基建、房地产投资不及预期，或“大规模设备更新”政策效果减弱，国内需求可能再次陷入低迷。此外，公司应收账款与长期应收款合计超550亿元，占总资产28.5%，若下游客户（尤其是中小建筑商）信用恶化，减值损失可能大幅吞噬利润。
