# 603505.SH 深度透视

## 因果逻辑链
- **[包头“选化一体”项目产能释放]** -> [营收与利润双增]: 金鄂博氟化工无水氟化氢产销量同比大增超80%，叠加包钢金石投资收益（1.58亿元），成为公司核心利润引擎，贡献净利润占比达67.41%。
- **[低品位萤石粉制备AHF技术突破]** -> [成本优势与资源盘活]: 专有技术将包钢尾矿中的低品位超细萤石粉转化为标准AHF产品，使公司摆脱对高品位单一萤石的依赖，并实现“选化一体”的轻资产扩张。
- **[单一萤石矿山成本上升与产销量下滑]** -> [基本盘利润承压]: 安全监管趋严导致安全投入增加、产销量减少，单吨制造成本上升，拉低了萤石涨价本该带来的利润，削弱了“现金牛”的盈利能力。
- **[锂电项目（六氟磷酸锂、尾泥提锂）亏损]** -> [拖累整体业绩]: 跨界锂电行业节奏踩错，叠加锂价周期下行，两项目合计亏损近6000万元，成为公司利润增长的主要拖累项。
- **[蒙古国项目产能释放慢于预期]** -> [海外扩张节奏受阻]: 对海外基础设施、政策环境估计不足，选厂建设及配套工程耗时较长，导致项目未能按计划实现当年盈利，短期价值有限。
- **[投资诺亚氟化工，切入AI液冷赛道]** -> [打开远期增长空间]: 成为液冷氟化液龙头第二大股东，布局“微笑曲线”高附加值端，与现有资源和技术形成协同，为未来增长注入新动能。
- **[经营性现金流大幅下降]** -> [盈利质量隐忧]: 期末未到期银行承兑汇票增加3.2亿元及支付包钢金石货款增加，导致经营活动现金流净额同比大降75.45%，利润的现金保障能力减弱。

## 风险警告
**核心风险在于新业务拖累与现金流压力。** 锂电项目（六氟磷酸锂、尾泥提锂）持续亏损，合计影响利润近6000万元，且面临锂价周期波动与技术转化不确定性，短期内难以成为利润贡献点。同时，公司经营性现金流净额同比暴跌75.45%，主要因大量销售回款以银行承兑汇票形式存在（期末余额8.94亿元），以及支付关联方货款增加，盈利质量显著下降，需警惕流动性风险。

**另一重大风险是安全环保与海外项目的不确定性。** 金鄂博氟化工硫酸厂发生渗水溢流事件，已移送检察院审查起诉，暴露出化工板块的环保管理短板，可能面临处罚及声誉损失。蒙古国项目受制于基础设施、政策环境等，产能释放节奏持续慢于预期，若水源、运输等关键条件无法及时满足，将导致前期投入难以转化为有效产出，成为资金“黑洞”。
