# 603444.SH 深度透视

## 因果逻辑链
- **[新品爆发]** -> [营收利润双增]: 2025年上线《杖剑传说》《问剑长生》《道友来挖宝》等爆款，贡献增量收入，驱动营收同比+67.89%，归母净利润同比+89.82%。
- **[自研产品占比提升]** -> [毛利率显著改善]: 自研新品无需支付外部研发分成，游戏业务毛利率提升5.47个百分点至94.30%，成本端优化显著。
- **[新品集中上线]** -> [销售费用激增]: 多款游戏集中推广，销售费用同比+112.46%至20.83亿元，成为利润最大侵蚀项，但ROI整体可控。
- **[《问道》IP长线运营]** -> [稳定基本盘]: 《问道》端游及手游上线近20年/10年，通过版本更新、IP联动维持流水，但《问道手游》流水同比-6.55%，老产品进入成熟衰退期。
- **[境外业务放量]** -> [第二增长曲线]: 境外营收9.29亿元，同比+85.80%，《杖剑传说（境外版）》贡献核心增量，验证全球化能力。
- **[高分红政策]** -> [强化股东回报]: 2025年全年现金分红14.06亿元，占净利润78.41%，上市以来累计分红为融资净额8.25倍，显著提振持股信心。
- **[递延收入大幅增长]** -> [未来业绩蓄水池]: 尚未摊销的充值及道具余额7.67亿元，较年初+60.5%，为后续收入确认提供缓冲。

## 风险警告
**核心风险在于产品生命周期与新品断档。** 公司营收高度依赖《问道》系列及2025年新爆款《杖剑传说》，老产品流水已现下滑（《问道手游》-6.55%），而新游《九牧之野》尚处亏损期。若《杖剑传说》流水快速回落，且后续储备产品（如《失落城堡2》）无法接棒，业绩将面临剧烈波动。同时，销售费用率已飙升至33.6%，买量成本高企，一旦新品回报率不及预期，利润将遭双重挤压。

**次要风险来自汇率波动与投资减值。** 公司持有大量美元资产（境外货币资金约10.52亿元），2025年因汇率波动产生损失约4,452万元，而2024年为收益3,491万元，波动剧烈。此外，对外股权投资标的（如青瓷游戏、勇仕网络）经营受行业周期影响，2025年虽减值收窄（-1,469万元 vs -4,938万元），但长期减值风险犹存，可能持续侵蚀非经常性损益。
