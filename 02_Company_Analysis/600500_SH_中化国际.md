# 600500.SH 深度透视

## 因果逻辑链
- **[化工行业周期下行，供需失衡]** -> [营收与利润承压]: 国内化工品价格指数（CCPI）降至近五年低位，公司多数产品价格下跌，导致营收同比下降10.54%，归母净利润亏损22.23亿元。
- **[“极致降本”与产能利用率提升]** -> [基础原料及中间体业务逆势增长]: 碳三装置产能利用率提升至90%，重点产品销量同比增超20%，推动该业务营收同比增长30.62%，毛利率提升3.78个百分点。
- **[优化生产工艺与降低采购成本]** -> [高性能材料业务毛利率改善]: 环氧树脂、双酚A等产品通过降本增效，毛利率同比提升5.17个百分点，有效对冲了价格下行压力。
- **[聚焦核心主业，剥离非核心资产]** -> [亏损治理与资产结构优化]: 通过清退锂电池等低效资产（确认投资损失约1.69亿元），重点亏损企业（如瑞恒公司）减亏超4.88亿元，亏损额同比减少。
- **[强化海外营销与出口]** -> [部分产品出口销量大幅增长]: 双酚A、尼龙66、芳纶等产品出口销量同比增长34%-112%，海外客户超700家，全球化营销体系初显成效。
- **[研发投入聚焦新材料]** -> [新产品收入与核心技术突破]: 研发投入6.87亿元，实现新产品销售收入74.74亿元，高强高模对位芳纶、MIAK等关键技术取得突破，打破进口依赖。
- **[现金流管理强化]** -> [经营现金流显著改善]: 通过加强营运资金周转效率，经营活动现金流净额同比大增42.9%至16.62亿元，缓解了经营压力。

## 风险警告
公司当前面临的核心风险是**行业供需失衡持续与盈利修复的不确定性**。尽管公司通过“极致降本”和产能优化实现了部分业务的减亏，但化工行业整体仍处于周期低谷，多数产品价格承压，公司连续三年亏损，净资产收益率持续为负，盈利能力恢复高度依赖行业景气度反转。

此外，**高负债与现金流压力**是另一重大隐患。公司总负债规模巨大，资产负债率处于高位，且母公司未分配利润为负，已不具备分红条件。虽然短期经营现金流改善，但投资活动现金流持续净流出，且存在大量资产受限（如抵押固定资产超136亿元），财务弹性受限，若行业下行周期延长，可能面临债务偿付与流动性风险。
