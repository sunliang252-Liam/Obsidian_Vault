# 688105.SH 深度透视

## 因果逻辑链
- **[增值税政策调整]** -> [营收持平，利润承压]: 生物制品增值税由3%简易计税调整为13%一般计税，直接侵蚀毛利率，导致营收持平下利润仍为负。
- **[核心原料自产优势]** -> [毛利率韧性]: 酶、抗原、抗体等关键原料100%自产，有效对冲了增值税上调带来的成本压力，维持了产品竞争力。
- **[海外业务高增]** -> [整体增长新引擎]: 海外营收同比增长67.30%至1.69亿元，国际事业部实现盈亏平衡，成为对冲国内竞争与政策压力的关键驱动力。
- **[阿尔茨海默病(AD)血检产品线突破]** -> [打开第二增长曲线]: 基于化学发光平台，完成11项AD血检产品获批（多项为全国首家），并已进入130余家医院，为未来高价值增长奠定基础。
- **[研发投入持续高企]** -> [技术壁垒与产品迭代]: 研发费用率20.37%，近三年均值22.83%，支撑了高保真聚合酶、T7 RNA聚合酶等核心产品的迭代与新品推出，巩固了国产龙头地位。
- **[股份支付费用冲回]** -> [非经常性损益减亏]: 因未达成股权激励业绩目标，冲回前期已计提的股份支付费用，是归母净利润亏损大幅收窄（-1661万）的重要原因。
- **[生命科学业务成熟产品线稳定]** -> [基本盘稳固]: PCR、qPCR、NGS建库等成熟产品线收入贡献稳定，同时核酸提取、细胞蛋白等新兴产品线逐步放量，形成接力增长。

## 风险警告
公司当前最大的风险在于**国内生命科学试剂市场的价格战与竞争加剧**。尽管公司通过原料自产维持了毛利率，但增值税政策调整已对营收和盈利产生实质性冲击。若行业竞争进一步恶化，公司可能面临“增收不增利”甚至营收下滑的局面。此外，公司对**非经常性损益（如政府补助、金融资产收益）的依赖度较高**，扣非后净利润仍亏损超7800万元，核心业务的盈利能力尚未完全恢复。

另一重大风险是**新业务商业化不及预期**。阿尔茨海默病血检产品虽然技术领先，但市场教育、入院推广和医保准入周期较长，短期内难以贡献显著利润。同时，GLP-1原料、核酸药物原料等生物医药业务虽增长迅速，但面临国际巨头和国内同行的激烈竞争，且下游客户管线进展存在不确定性。若新业务无法如期放量，公司可能长期处于“高研发投入、低盈利回报”的困境。
