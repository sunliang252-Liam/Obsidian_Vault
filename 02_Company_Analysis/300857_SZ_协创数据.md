# 300857.SZ 深度透视

## 因果逻辑链
- **[智能算力基础设施建设需求爆发]** -> [智能算力产品及服务收入增长1727%]: 公司把握AI算力集群建设机遇，算力服务器及集群解决方案大规模交付，成为业绩增长核心引擎。
- **[AI驱动存储需求“超级周期”]** -> [数据存储设备收入增长28.3%]: 下游客户对存储基础设施投入提升，叠加行业供需变化带动产品价格上行，出货规模放量。
- **[服务器再制造业务体系化运营]** -> [服务器及周边再制造收入增长169%]: 北美子公司Semsotai North Inc.回收拆解+国内测试再销售模式成熟，业务规模扩大与运营效率提升。
- **[海外市场拓展与本地化深耕]** -> [境外收入增长65.16%]: 美国、日本、东南亚等重点市场突破，AIoT终端海外收入持续增长，部分区域客户增长超60%。
- **[算力基础设施大规模资本投入]** -> [投资活动现金流净流出136.8亿元]: 为布局智能算力及云计算服务，大量采购算力服务器等固定资产，导致资本性支出激增。
- **[供应链优化与智能制造]** -> [毛利率提升1.88个百分点]: 优化二级三级供应链管理推动原材料成本下降，无人工厂建设通过机器人替代人工降低制造成本。
- **[VSaaS视频云与AIGC平台商业化]** -> [云服务ARPU值稳步提升]: 视频监控即服务用户数量增长，AIGC内容生产平台实现短剧规模化、商业化量产，形成新增长点。

## 风险警告
**1. 巨额资本开支与债务风险：** 公司2025年投资活动现金净流出高达136.8亿元，主要用于算力服务器采购，导致总资产从73亿暴增至238亿，资产负债率急剧攀升。长期借款从4.1亿激增至74.8亿，财务费用从-0.89亿飙升至3.17亿。若AI算力需求增速放缓或客户回款周期延长，高杠杆运营将带来巨大的偿债压力和流动性风险。

**2. 客户与供应商集中度风险：** 前五大客户销售额占比46.75%，其中第一大客户占比高达30.81%；前五大供应商采购额占比51.89%，第一大供应商占比21.96%。公司对核心客户和供应商依赖度极高，一旦主要客户流失或供应商断供，将对公司经营产生重大冲击。同时，算力服务器采购金额巨大，供应商议价能力极强，公司利润空间易受挤压。

**3. 国际贸易与地缘政治风险：** 公司境外收入占比50.6%，且服务器再制造业务核心在北美。中美贸易战导致的关税增加、技术封锁（如GPU出口管制）以及地缘政治不确定性，可能直接推高运营成本、限制核心芯片获取，甚至影响海外子公司正常运营。公司虽采取多元化供应链策略，但根本性风险难以消除。
