# 601888.SH 深度透视

## 因果逻辑链
- **海南离岛免税新政与封关运作** -> [海南区域销售额止跌回升]: 2025年11月离岛免税新政实施（品类扩至47类、放宽岛民购买限制），叠加12月全岛封关启动，推动Q4海南离岛免税购物金额同比增长46.8%，公司海南区域销售额企稳回升。
- **核心机场免税店经营权中标** -> [巩固口岸渠道壁垒]: 成功中标上海浦东、虹桥、北京首都、广州白云等16个机场免税店项目，锁定核心枢纽流量入口，强化行业领先地位。
- **收购DFS大中华区零售业务** -> [国际化能力跃升与产业协同]: 2026年初完成对DFS大中华区零售业务的战略性收购，快速建立港澳市场优势，整合优质旅游零售网络，提升品牌影响力与供应链协同效应。
- **有税业务创新模式（兰州机场）** -> [开辟新增长曲线]: 兰州机场项目采用“低保底+阶梯分成”模式，打造“高端零售+地域文化”标杆，销售额在同级次机场有税业务中领先，形成可复制的有税商业运营模式。
- **消费趋势变化（银发经济、国潮、户外）** -> [品类结构优化与销售增量]: 敏锐布局银发经济（摄影数码、健康保健），加大3C数码、户外运动、黄金、文创等高潜品类引进，全年引入超400个新品牌，有效对冲传统香化品类增长放缓。
- **研发费用同比+352.74%** -> [数字化建设加速]: 加快星云项目等软件系统研发投入，构建客户动态行为追踪与分群体系，为精准营销和供应链效率提升提供数据支撑，但短期侵蚀利润。

## 风险警告
**核心风险在于政策红利与市场竞争的双重博弈。** 海南全岛封关后，离岛免税政策优势可能被逐步稀释，且行业已进入“有序竞争阶段”，机场、市内店经营权均通过招标/竞争性磋商确定，公司虽凭借规模优势中标核心项目，但未来租金成本及竞争烈度存在显著不确定性。同时，公司2025年营收与净利润双降（营收-4.92%，归母净利-15.96%），有税业务收入同比大幅下滑21.69%，显示传统渠道承压，新增长点尚在培育期。

**财务与运营风险不容忽视。** 商誉减值风险高企（报告期内商誉账面价值从8.23亿降至4.85亿，减值3.38亿），主要来自日上上海资产组，其净利润已转负（-2.08亿元），机场续约率及盈利能力是核心变量。此外，公司境外资产占比高达39.61%，人民币汇率波动及地缘政治风险可能通过汇兑损失及供应链稳定性影响业绩。投资活动现金流净额大幅转负（-34.8亿），主因定期存款增加，需关注资金使用效率。
