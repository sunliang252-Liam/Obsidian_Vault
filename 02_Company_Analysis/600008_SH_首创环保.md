# 600008.SH 深度透视

## 因果逻辑链
- **[处置新加坡ECO公司]** -> [归母净利润同比-49.78%]: 上年同期处置新加坡ECO公司确认约19亿投资收益，导致2025年归母净利润基数效应下大幅下滑。
- **[运营收入占比提升]** -> [扣非净利润同比+2.68%]: 运营类收入占比同比提升6.8个百分点，对冲工程业务波动，核心盈利保持稳健增长。
- **[融资成本压降]** -> [财务费用同比-9.46%]: 通过贷款置换、发行低息债券等措施，整体融资成本同比下降46BP，有效降低财务费用。
- **[水价调整与产能释放]** -> [水务业务收入增长]: 报告期内15个污水项目、3个供水项目完成调价，15个污水项目、4个供水项目转商运，推动量价齐升。
- **[焚烧运营效率提升]** -> [固废业务核心指标向好]: 垃圾焚烧处理量同比+2.9%，上网电量同比+6.88%，产能利用率提升至86%，柴油单耗等成本下降。
- **[首次实施中期分红]** -> [股东回报增强]: 2025年首次实施中期分红，全年现金分红总额占归母净利润49.71%，传递稳健经营信心。
- **[首单水务持有型ABS落地]** -> [资产盘活能力突破]: 继公募REITs后，落地全国首单水务资产持有型不动产ABS，打通“投资-运营-盘活-再投资”闭环。

## 风险警告
**核心风险在于行业转型期的增长失速与资产质量分化。** 环保行业已从“跑马圈地”进入“存量提质”阶段，公司传统工程业务收入同比-27.25%，水环境综合治理业务收入同比-25.23%，新增长极尚未完全形成规模效应。同时，公司总资产超千亿，但归母净资产仅307亿，资产负债率较高，且一年内到期的非流动负债同比+33.50%，短期偿债压力加大。

**运营风险与应收账款风险不容忽视。** 水务、固废业务受电价、药剂价格及人工成本上涨影响，而服务费调价存在滞后性，成本传导机制不畅。此外，公司客户主要为地方政府，财政支付能力波动可能导致应收账款回收周期延长，影响现金流稳定性。报告期内经营活动现金流净额同比-7.87%，需警惕回款恶化。
