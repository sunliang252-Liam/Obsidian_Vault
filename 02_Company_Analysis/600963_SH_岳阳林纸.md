# 600963.SH 深度透视

## 因果逻辑链
- **[文化纸产能集中投放，价格竞争加剧]** -> [归母净利润亏损2.35亿元]: 2025年国内文化纸产能持续扩张，市场供过于求，导致公司纸产品销售价格同比下降，毛利率被压缩，最终由盈转亏。
- **[45万吨文化纸项目转固]** -> [财务费用同比上升29.08%]: 项目投产后，原资本化的专项借款利息转为费用化支出，直接推高了财务费用，侵蚀利润。
- **[子公司诚通凯胜市政园林业务低迷]** -> [商誉计提大额减值]: 生态园林行业持续下行，诚通凯胜存量项目进入结算期，利润大幅下滑，触发商誉减值测试，导致公司对相关商誉计提减值。
- **[骏泰科技并表]** -> [营业收入结构变化]: 2024年底收购的骏泰科技在2025年全年并表，贡献了约19.2亿元的商品浆收入，使公司营收规模扩大，但未能扭转整体亏损。
- **[以公允价值计量的票据贴现业务减少]** -> [经营活动现金流净额为负]: 公司本期减少了此类票据贴现，导致经营活动产生的现金流量净额由正转负，降至-4.77亿元，现金流状况恶化。
- **[产品结构转型]** -> [工业用纸销量激增]: 公司主动调整产品结构，工业用纸销量同比增长587.50%，但该品类体量较小，尚不足以对冲文化纸的盈利下滑。
- **[原材料成本控制]** -> [商品浆毛利率保持稳定]: 尽管市场浆价波动，公司依托林浆纸一体化优势和集采能力，商品浆业务毛利率仍维持在26.20%，成为利润的重要稳定器。

## 风险警告
公司面临的核心风险是**行业性产能过剩导致的盈利持续恶化**。文化纸行业新增产能集中释放，价格竞争激烈，公司核心产品印刷用纸毛利率已降至4.66%，若未来需求进一步萎缩或浆价成本上升，主业亏损可能加剧。同时，子公司诚通凯胜的生态园林业务深陷泥潭，已计提大额商誉减值，该业务短期内难以反转，将持续拖累公司整体业绩。

财务风险方面，**现金流状况显著恶化**值得高度警惕。经营活动现金流净额由正转负，且公司资产负债率已升至62.93%，有息负债规模较大。在利润亏损和现金流紧张的双重压力下，公司2025年度已决定不进行现金分红，这反映了其财务稳健性面临挑战。投资者需关注公司后续的融资能力和债务偿还安排。
