# 600120.SH 深度透视

## 因果逻辑链
- **金融子公司业绩增长** -> 管理费用增加: 金融子公司效益提升导致业务及管理费相应增加
- **东方嘉富人寿保费收入增长** -> 经营活动现金流净额大幅增加: 保费收入现金流入增加驱动经营现金流改善
- **东方嘉富人寿投资活动支出增加** -> 投资活动现金流净流出扩大: 投资支付的现金同比大幅增加导致投资现金流净流出增加
- **东方嘉富人寿发行资本补充债** -> 筹资活动现金流净流入增加: 发行14亿元资本补充债带来筹资现金流入
- **公允价值变动收益增加** -> 利润总额同比增长: 公允价值变动收益由负转正，对利润贡献显著
- **信托业务转型与创新** -> 信托资产规模和收入大幅增长: 通过聚焦资产服务、资产管理等赛道，金融同业合作和标品业务发力，推动规模和收入增长
- **期货行业规模扩大及大地期货业务拓展** -> 大地期货利润和收入大幅增长: 受益于行业增长和自身业务拓展，经纪、风险管理等业务全面增长
- **国金租赁新增投放和融资规模扩大** -> 融资租赁收入及利润高增长: 新增投放同比增长22.31%，同时成功发行低成本ABS，推动收入和利润增长

## 风险警告
需关注东方嘉富人寿投资活动现金流持续大额流出对整体流动性的潜在压力，以及保险业务毛利率为负（-2.75%）且持续恶化（毛利率下降26.36个百分点），可能侵蚀整体盈利。此外，信托业务历史遗留风险项目虽有所减少，但仍需警惕信用风险暴露。
