# 300099.SZ 深度透视

## 因果逻辑链
- **[剥离亏损资产富华宇祺]** -> [净利润大增92.73%]: 2025年处置富华宇祺股权产生约1亿元公允价值变动收益，是归母净利润从9500万飙升至1.83亿的核心原因，但扣非净利润实际下降23.42%。
- **[煤炭行业景气下行]** -> [智慧矿山营收下降7.59%]: 2025年煤炭开采业利润总额同比下降41.8%，下游客户采购预算收紧，直接冲击公司核心主业收入。
- **[军工制导业务逆势增长]** -> [营收同比增长29.70%]: 在“备战打仗”战略牵引下，师凯科技军工产品需求稳定，成为公司唯一增长的业务板块。
- **[经营现金流骤降98.53%]** -> [销售回款恶化]: 销售商品收到的现金从5.47亿降至3.59亿，表明下游客户付款周期延长或公司销售政策放宽，盈利质量显著下滑。
- **[高分红政策持续]** -> [股东回报稳定]: 上市以来现金分红比例稳定在70%以上，2025年拟每10股派1.40元，体现公司对股东回报的重视，但高分红与现金流恶化形成矛盾。
- **[募投项目延期]** -> [产能释放不及预期]: “矿用智能单轨运输系统数字化工厂建设项目”延期至2026年9月，短期内无法通过新增产能提升市场份额。
- **[切入航天动力赛道]** -> [布局第二增长曲线]: 2026年初与深蓝航天战略合作并投资1亿元，切入液体可回收火箭发动机零部件制造，旨在打造“智慧矿山+军工+航天”三大业务格局。

## 风险警告
**核心主业承压与盈利质量恶化。** 公司2025年扣非净利润同比下降23.42%，智慧矿山业务受煤炭行业下行冲击明显，营收与毛利率双降。更值得警惕的是，经营活动现金流净额从1.91亿骤降至281.5万，降幅达98.53%，销售回款能力严重恶化，表明利润增长主要依赖非经常性损益，主业造血能力堪忧。

**新业务拓展与募投项目的不确定性。** 公司高调切入航天动力赛道，但该领域技术门槛高、验证周期长，与现有主业协同效应尚待验证，短期内难以贡献利润。同时，核心募投项目再次延期至2026年9月，若市场环境或竞争格局在此期间发生不利变化，公司将面临产能过剩或无法实现预期收益的风险。
