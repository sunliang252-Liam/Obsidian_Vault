# 688772.SH 深度透视

## 因果逻辑链
- **[消费类电池客户份额提升]** -> [营收增长24.86%]: 在笔记本、平板、手机等核心领域深化与惠普、联想、苹果等头部客户合作，手机类营收同比增长38.24%，驱动整体营收增长。
- **[动力及储能类业务聚焦高倍率赛道]** -> [营收暴增134.15%]: 战略聚焦汽车低压锂电池和无人机电池，汽车低压电池出货量约169万套，无人机电池营收同比增长293.06%，成为第二增长曲线。
- **[原材料价格剧烈波动]** -> [毛利率承压]: 核心原材料钴酸锂价格2025年末较2024年末暴涨171.66%，公司成本传导存在滞后，导致消费类电池毛利率同比下降2.88个百分点。
- **[美元兑人民币汇率持续下行]** -> [财务费用激增432.24%]: 外销收入占比超60%，以美元结算为主，人民币升值导致汇兑损失大幅增加，财务费用从3.53亿飙升至18.81亿。
- **[研发投入持续高强度]** -> [构筑技术壁垒]: 研发投入占营收12.89%，成功量产25%高硅负极电池（能量密度900Wh/L），建成全固态电池实验线，为AI终端产品迭代储备技术。
- **[动力及储能业务规模效应未显]** -> [子公司持续亏损]: 主营动力及储能的子公司浙江冠宇净利润为-2.13亿元，因产能规模较小、前期投入大，短期难以实现盈利。
- **[出口退税率下调]** -> [出口业务成本上升]: 自2026年起电池出口退税率将从9%逐步下调至取消，若无法将成本转嫁，将直接侵蚀公司外销业务的盈利能力。

## 风险警告
**核心风险在于利润表的结构性恶化。** 公司营收增长24.86%，但归母净利润仅增长9.60%，扣非净利润甚至下滑10.95%。利润被两大因素严重侵蚀：一是财务费用因人民币升值暴增432.24%，二是动力及储能业务子公司浙江冠宇亏损2.13亿元。这表明公司主业盈利能力的提升，正被汇率波动和新业务亏损所抵消，利润质量堪忧。

**另一重大风险是成本与政策双重挤压。** 核心原材料钴酸锂价格在2025年末暴涨171.66%，而公司成本传导存在时滞，毛利率已承压。更严峻的是，电池出口退税率将在2026-2027年逐步下调并最终取消，公司外销收入占比超60%，这将直接增加出口成本，若无法提价转嫁，盈利能力将面临持续冲击。
