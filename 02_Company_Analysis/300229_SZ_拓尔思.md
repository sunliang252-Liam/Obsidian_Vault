# 300229.SZ 深度透视

## 因果逻辑链
- **[下游客户IT预算收缩]** -> [营收下降34.19%]: 政府、金融等核心客户信息化投入放缓，项目推迟或缩减规模，直接导致公司主营业务收入大幅下滑。
- **[商誉减值计提1.5亿元]** -> [归母净利润亏损2.94亿元]: 子公司天行网安受行业竞争加剧影响业绩未达预期，公司计提大额商誉减值，成为当期亏损主因。
- **[主动压缩低毛利系统集成业务]** -> [收入结构优化]: 公司战略收缩传统集成业务，聚焦AI与数据服务，虽短期拖累营收，但提升了业务质量和长期竞争力。
- **[研发与销售费用刚性投入]** -> [短期亏损但构筑技术壁垒]: 在收入承压背景下，公司持续高投入AI大模型和智能体平台，导致费用率上升，但巩固了“决策智能”领域的技术护城河。
- **[公共安全业务爆发式增长]** -> [成为增长最快板块]: 特种业务（+109%）和监管安全业务（+54%）驱动公共安全板块整体增长28%，验证了AI智能体在强业务场景中的落地能力。
- **[金融消保智能体标杆项目落地]** -> [AI业务收入逆势增长]: 承揽某国有大行近2000万元消保智能体项目，推动AI软件产品及服务收入同比增长1.67%，在行业收缩中实现逆势突破。
- **[高质量数据资产价值凸显]** -> [数据价值化能力获业界认可]: 超200万亿Token语料池和百亿级知识图谱，使公司在上海数据交易所“数据价值化100强”中位居榜首，成为核心竞争壁垒。
- **[经营性现金流显著改善]** -> [经营质量提升]: 通过加大催收、优化采购和人员结构，全年经营性现金流净额达1.97亿元，同比增长185%，显示公司财务基本面稳健。

## 风险警告
**核心风险在于商誉减值与战略转型的业绩错配。** 公司剩余商誉约2.36亿元，若子公司天行网安及广拓公司经营持续恶化，未来仍有减值风险。同时，公司正从传统项目制向“智能体+数据服务”模式转型，新业务虽已落地上千个客户智能体应用，但多数处于试用培育期，尚未进入规模化变现阶段，而研发投入、算力成本等刚性支出持续发生，收入与成本错配可能导致短期亏损延续。

**下游客户依赖度与宏观环境敏感性是另一大隐患。** 公司核心客户集中于政府和金融领域，受财政预算统筹和自身经营压力影响显著。2025年政府行业收入下降16.54%，金融、制造、能源等企业客户收入更是骤降71.48%。若宏观经济持续低迷或信创政策推进不及预期，公司业绩恢复将面临较大不确定性。此外，AI技术应用成熟度风险不容忽视，若公司不能精准把握用户痛点、及时推出成熟产品，可能错失市场窗口期。
