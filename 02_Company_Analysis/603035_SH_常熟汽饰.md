# 603035.SH 深度透视

## 因果逻辑链
- **[新能源业务占比突破50%]** -> [营收增长25.46%]: 新能源客户订单放量，推动公司总营收从56.67亿增至71.10亿，新能源销售占比从39.54%跃升至52.14%，成为核心增长极。
- **[新工厂产能爬坡与研发投入增加]** -> [归母净利润下降18.63%]: 安庆、合肥、金华等新基地处于投产初期，尚未盈利，叠加研发费用同比增加26.02%（+5478万元），导致毛利率下降2.75个百分点，利润端承压。
- **[对联营/合营企业投资收益减少]** -> [扣非净利润下降22.49%]: 参股公司（长春派格、长春富晟等）贡献的投资收益同比减少5979万元，是利润下滑的另一主因，凸显公司盈利对合资平台的依赖。
- **[使用应收票据背书支付长期资产购建]** -> [经营性现金流净额骤降76.13%]: 尽管营收增长，但经营性现金流从2.63亿降至0.63亿，主要因大量应收票据用于支付资本开支，未体现在现金流表中。
- **[全球化产能扩张与国内基地投产]** -> [总资产增长15.24%]: 西班牙、匈牙利海外工厂启动建设，国内金华、芜湖江北等新基地投产，推动总资产从106.39亿增至122.61亿，长期借款增加68.90%以匹配投资周期。
- **[“回购+分红”组合拳]** -> [提升股东回报与每股收益]: 公司回购2亿元股份并注销，总股本减少3.6%，叠加现金分红，合计占净利润75.11%，有效提升了每股收益和净资产收益率。
- **[智能座舱与模块化集成转型]** -> [获取高端客户订单]: 凭借“ix-2024”智能座舱方案获海外客户认可，从单一零部件供应商向集成商转型，巩固了一汽大众、北京奔驰、理想、蔚来等核心客户关系。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长25.46%，但归母净利润却下滑18.63%，主要因新工厂产能爬坡吞噬利润、研发费用刚性增长以及联营投资收益大幅缩水。若新基地（肇庆、合肥、金华）在2026年无法如期实现盈利，且合资公司业绩持续低迷，公司盈利能力将进一步承压，ROE已从8.27%降至6.67%。

**现金流恶化与高资本开支的错配是另一大隐患。** 经营性现金流净额同比暴跌76.13%至仅0.63亿元，而公司仍在进行大规模海外建厂和国内基地扩张，导致长期借款激增68.90%。若下游客户回款周期延长或行业竞争加剧，公司可能面临流动性紧张风险，需警惕资产负债率上升和利息支出对利润的侵蚀。
