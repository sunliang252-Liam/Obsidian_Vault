# 300301.SZ 深度透视

## 因果逻辑链
- **[全球LED照明进入存量竞争，行业需求萎缩]** -> [营收下降21.48%]: 传统照明项目减少，国内外销售规模同步下滑，导致公司2025年营收从5.05亿降至3.97亿。
- **[行业价格战加剧，毛利率承压]** -> [毛利减少]: 产品同质化严重，公司移动照明产品毛利率从30.07%降至26.18%，贴片式LED毛利率为-11.82%，持续亏损。
- **[投资性房地产公允价值下跌]** -> [非经常性亏损2309万]: 公司对坪山工业园等投资性房地产按公允价值计量，报告期内公允价值变动损失2309万元，直接侵蚀利润。
- **[计提大额资产减值与信用减值]** -> [合计损失5295万]: 对存货、固定资产计提减值3865万，对应收账款计提信用减值1430万，反映资产质量恶化。
- **[股权激励产生股份支付费用]** -> [管理费用增加736万]: 2024年实施的限制性股票激励计划，本期摊销股份支付费用，进一步加重亏损。
- **[公司股票被实施其他风险警示]** -> [融资、供应链及销售受阻]: ST状态导致公司融资渠道受限、供应链合作困难、客户信心下降，形成负向循环。
- **[连续三年亏损，净资产大幅缩水]** -> [持续经营能力存疑]: 2023-2025年累计亏损超3.2亿，归母净资产从2.34亿骤降至0.91亿，审计报告出具持续经营重大不确定性段落。

## 风险警告
**流动性危机与偿债压力是最大威胁。** 公司流动负债高达6.85亿，而流动资产仅2.05亿，流动负债超出流动资产4.8亿。短期借款8292万，非金融机构借款高达3.63亿，而账面货币资金仅3775万（其中受限资金261万）。公司已连续三年亏损，经营活动现金流净额为-1149万，造血能力枯竭。虽然计划出售坪山工业园和长方大楼回血，但截至报告期末仍未找到买家，资产变现存在极大不确定性。

**历史财务造假后遗症持续发酵。** 子公司康铭盛通过销售返利不入账虚增利润，导致公司2020-2021年年报虚假记载，公司及高管被证监会处罚。原管理团队涉嫌隐匿、销毁会计凭证被刑事立案。这一系列事件导致公司被实施其他风险警示（ST），严重制约融资能力、供应链合作和客户信心。同时，康铭盛原股东业绩承诺未履行（承诺增持3.3亿元未兑现），相关承诺方涉嫌犯罪，公司追偿前景不明。
