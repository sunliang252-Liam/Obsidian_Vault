# 601009.SH 深度透视

## 因果逻辑链
- **[利息净收入大幅增长]** -> [营收增长10.48%]: 债券投资利息收入同比+29.37%，叠加贷款规模扩张，推动利息净收入同比+31.08%，成为营收增长的核心引擎。
- **[非利息收入显著下滑]** -> [营收增速受限]: 公允价值变动收益由正转负（-25.12亿），导致非利息净收入同比-12.71%，部分抵消了利息收入增长。
- **[资产规模跨越3万亿]** -> [规模效应显现]: 总资产同比+16.61%，贷款+13.37%，存款+11.67%，规模扩张带动利息收入绝对额增加。
- **[净息差持续收窄]** -> [盈利承压]: 净息差从1.94%降至1.82%，尽管规模扩张，但资产收益率下行压力持续存在。
- **[信用减值损失激增]** -> [利润增速低于营收]: 信用减值损失同比+31.91%，计提力度加大，导致归母净利润增速（8.08%）低于营收增速（10.48%）。
- **[零售AUM突破万亿]** -> [财富管理转型见效]: 零售AUM同比+21.23%，代销中收+34.90%，财富银行战略驱动中间业务收入结构优化。
- **[可转债提前转股]** -> [资本补充与股本扩张]: 200亿可转债提前两年转股，核心一级资本充足率维持9.35%，但股本扩张摊薄了每股收益（-3.83%）。

## 风险警告
**核心风险在于资产质量压力与盈利能力的结构性矛盾。** 尽管不良率维持在0.83%的低位，但逾期贷款总额同比+14.6%，关注类贷款迁徙率高达39.79%，意味着未来不良生成压力较大。同时，信用减值损失同比激增31.91%，拨备覆盖率从335.27%降至313.62%，风险抵补能力正在被侵蚀。在净息差持续收窄（1.82%）的背景下，若不良加速暴露，将形成“收入端承压+成本端上升”的双重挤压。

**另一个关键风险是市场波动对非利息收入的冲击。** 2025年公允价值变动收益由正转负，亏损25.12亿元，直接导致非利息净收入同比下滑12.71%。公司债券投资规模庞大（债券投资利息收入占比24.23%），且交易性金融资产占比高，利率市场波动将显著影响投资收益和公允价值变动，造成盈利的不稳定性。此外，房地产对公贷款不良率1.81%、个人按揭不良率0.96%，在行业调整期仍需警惕相关敞口风险。
