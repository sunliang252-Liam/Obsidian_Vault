# 601186.SH 深度透视

## 因果逻辑链
- **[行业下行与竞争加剧]** -> [营收与利润双降]: 建筑业增加值下降1.1%，传统细分领域投资回落，公司营业收入同比-3.50%，归母净利润同比-17.34%。
- **[精细化管理与费用压降]** -> [经营性现金流回正]: 开展“三金”压控三年行动，销售、管理费用合计压降8.96%，购买商品支付现金减少，使经营性现金流从-314亿转为+29.6亿。
- **[战新产业拓展]** -> [新签合同结构优化]: 矿山工程(+17.34%)、电力工程(+18.21%)、境外业务(+16.46%)新签合同额逆势高增，对冲了房建(-1.75%)、城轨(-33.16%)的下滑。
- **[财务费用激增]** -> [侵蚀利润]: 利息费用同比增长38.07%，财务费用达109.7亿元，是利润总额269.3亿元的40.7%，显著拖累盈利能力。
- **[房地产开发业务亏损]** -> [板块拖累]: 房地产板块利润总额为-34.13亿元，主要因交房减少、毛利下降及计提减值增加，成为公司最大亏损源。
- **[PPP/BOT项目投资扩张]** -> [资产结构重型化与负债攀升]: 无形资产(+45.49%)、长期借款(+42.83%)大幅增长，杠杆率从71%升至75%，资金占用与偿债压力加大。
- **[应收账款周转放缓]** -> [营运资金效率下降]: 应收账款周转天数从68天增至87天，余额增长17.71%，反映下游客户（尤其是地方政府）支付能力减弱，坏账风险上升。

## 风险警告
**核心风险在于“增收不增利”与现金流的结构性矛盾。** 公司通过精细化管理实现了经营性现金流的回正，但这是在营收下降3.5%的背景下实现的，且利润总额同比下滑17%。更关键的是，财务费用因利息支出激增而大幅膨胀，直接吞噬了利润空间。同时，房地产开发业务已陷入实质性亏损，成为拖累整体业绩的“出血点”。若市场环境持续低迷，减值计提压力将进一步加大。

**另一重大风险是资产与负债的快速膨胀。** 公司为支撑PPP/BOT等投资运营项目，无形资产和长期借款均出现超40%的增长，导致杠杆率攀升至75%。这种“重资产”模式虽然带来了未来运营收入预期，但短期内占用了大量资金，并推高了财务成本。在地方政府财政紧张、项目回款周期拉长的背景下，过高的杠杆率和资产周转效率下降，将显著增加公司的债务资金风险和流动性压力。
