# 600446.SH 深度透视

## 因果逻辑链
- **[主动收缩非核心业务]** -> **营收腰斩**: 公司主动收缩IT设备分销及数字经济业务规模，导致营业收入同比骤降48.46%，但毛利率提升15.98个百分点，表明战略聚焦初见成效。
- **[聚焦金融科技主业]** -> **亏损收窄**: 归母净利润-1.68亿元，较上年同期-2.02亿元减亏，核心在于剥离低毛利业务后，期间费用（销售、管理、研发）同比下降。
- **[信创核心交易系统突破]** -> **未来增长基石**: 连续中标头部券商新一代核心交易系统FS2.5项目，并实现全栈信创单轨运行，产品规模化迁移能力获市场验证，为后续收入增长奠定基础。
- **[下游客户IT投入保守]** -> **增长承压**: 受宏观环境影响，金融机构IT投入趋于保守，导致公司金融行业收入同比下降22.10%，尤其是银行软件业务收入骤降71.37%。
- **[数字经济业务回款恶化]** -> **资产减值损失**: 数字经济板块项目回款不确定性增加，导致计提大额资产减值损失1.23亿元，成为拖累利润的主要因素之一。
- **[投资科技产品线完善]** -> **拓展新市场**: A8新一代投资交易系统实现资管与自营业务上线，并中标券商自营固收交易平台，应用场景从大资管拓展至自营投资，打开新增长空间。
- **[AI产品落地]** -> **提升效率与竞争力**: 基于KOCA AI平台打造智能体矩阵，在投顾、营销、风控等场景应用，并开发代码大模型K-CODE，旨在提升研发效率与产品竞争力。

## 风险警告
**核心风险在于战略转型期的业绩阵痛与资产质量压力。** 公司主动收缩非核心业务导致营收大幅下滑，短期内盈利能力承压。同时，数字经济板块回款困难已引发大额资产减值，若宏观环境持续低迷，应收账款和合同资产的减值风险将进一步侵蚀利润，考验公司现金流管理能力。

**行业竞争与技术迭代风险不容忽视。** 金融IT行业竞争激烈，下游客户IT投入周期性波动明显。公司虽在信创核心交易系统取得突破，但若不能持续跟踪技术升级（如AI、云原生），或新产品推广不及预期，可能在头部券商客户争夺中丧失先发优势。此外，人力成本持续上升，若核心人才流失，将影响研发与交付能力。
