# 601059.SH 深度透视

## 因果逻辑链
- **[市场行情回暖]** -> [证券自营业务收入同比+60.86%]: 2025年A股震荡上行，沪深300上涨17.66%，公司加大高股息股票配置，债券交易业务收益显著提升。
- **[客户规模与资产双创新高]** -> [证券及期货经纪业务收入同比+23.59%]: 精准营销与精细化服务驱动客户数量与资产规模刷新历史纪录，两融日均余额市场份额持续增长。
- **[IPO市场量额齐升]** -> [投行业务收入同比-21.46%]: 尽管A股募资额同比+96.56%，但公司聚焦北交所与并购重组细分领域，整体承销规模未同步扩张。
- **[主动管理转型见效]** -> [资产管理业务收入同比-9.43%]: 资管业务全面拥抱主动管理，但受市场波动及产品结构调整影响，收入短期承压。
- **[港股IPO强势复苏]** -> [境外业务收入同比+23.08%]: 信达国际抓住港股IPO窗口期，债券承销收入同比增长，首只公募债券基金成功设立。
- **[中金公司换股吸收合并]** -> [公司面临终止上市]: 2025年12月启动重大资产重组，中金公司换股吸收合并信达证券，交割后公司将终止上市。

## 风险警告
**核心风险：吸收合并终止或条件不利。** 中金公司换股吸收合并信达证券是2025年最大变量，换股价格（19.15元/股）及换股比例（1:0.5188）已锁定，但交易需经监管批准、股东大会审议等多重程序。若合并失败或条件发生重大不利变化，公司股价可能面临剧烈波动，且独立经营前景存在不确定性。

**业务风险：自营业务高度依赖市场环境。** 2025年自营收入同比大增60.86%，主要受益于债券和权益市场双牛行情。但公司自营权益类证券及衍生品/净资本比例从4.88%飙升至29.38%，风险敞口显著扩大。若2026年市场出现大幅回调，自营业务可能成为业绩拖累。

**治理风险：管理层变动与整合不确定性。** 报告期内董事长、总经理、多名董事及监事发生变更，核心管理层稳定性存疑。同时，公司正推进与中金公司的吸收合并，整合过程中的人员、业务、文化融合难度较大，可能影响短期经营效率。
