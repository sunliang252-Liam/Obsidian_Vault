# 301629.SZ 深度透视

## 因果逻辑链
- **[下游光电客户资本开支放缓]** -> [晶粒探针台收入骤降45.28%]: 核心优势产品下游处于技术路线选型期，客户采购周期延长，订单签约节奏趋缓。
- **[12英寸晶圆探针台业务拓展加速]** -> [晶圆探针台收入基本持平]: 公司重点布局高端市场，试机验证项目增加，但新项目从验证到批量订单转化仍需时间，业绩释放滞后。
- **[分选机等新业务放量]** -> [其他设备收入增长93.84%]: 公司以探针台技术为基础，成功将分选机、AOI等新产品导入现有客户产线，形成第二增长曲线。
- **[首次公开发行募资到账]** -> [净资产大增66.40%，财务费用转负]: IPO募集资金大幅增厚资本，同时现金管理收益增加，但期间费用（销售、管理）因上市活动同步上升。
- **[研发投入持续高企]** -> [研发费用率升至15.37%]: 公司坚持高强度研发投入，聚焦12英寸探针台、分选机等前沿技术，但短期内对利润形成压制。
- **[设备验收周期长且波动]** -> [经营活动现金流净额仅150万元]: 预收结转收入及长期应收款合同确认收入，导致净利润与经营现金流严重背离，现金流质量承压。
- **[客户集中度高]** -> [前五大客户收入占比43.95%]: 下游晶圆制造和封测行业集中度高，公司业绩受主要客户采购策略变动影响显著。

## 风险警告
**核心风险在于业绩下滑与现金流恶化。** 2025年公司营收同比下降17.52%，归母净利润更是暴跌42.50%，主要源于核心产品晶粒探针台收入腰斩。更需警惕的是，经营活动现金流净额同比骤降90.13%至仅150万元，与5341万元的净利润严重背离，暴露出公司收入确认与现金回款之间存在巨大时间差，财务质量堪忧。

**成长性面临双重考验。** 一方面，公司大力押注的12英寸晶圆探针台业务虽在加速拓展，但高端市场验证周期长、客户导入慢，短期内难以弥补传统业务的下滑。另一方面，下游光电客户资本开支的阶段性放缓何时结束尚不明朗，公司业绩拐点难以预判。此外，募投项目存在不及预期的风险，若市场需求或技术路线发生不利变化，新增产能可能无法有效消化。
