# 301606.SZ 深度透视

## 因果逻辑链
- **[智能存储（NAS）爆发式增长]** -> [营收结构优化]: 智能存储收入同比+213.18%，占总营收12.92%，成为增速最快的品类，推动整体营收增长53.83%。
- **[海外市场高速扩张]** -> [营收规模跃升]: 境外收入同比+64.27%，占比提升至61.34%，亚马逊渠道收入同比+61.72%，成为增长核心引擎。
- **[研发投入持续加大]** -> [产品技术壁垒提升]: 研发费用同比+43.96%，重点突破氮化镓快充、AI NAS、Qi2.2无线快充等技术，支撑产品迭代与品类拓展。
- **[全渠道销售网络深化]** -> [市场渗透率提升]: 线上（+51.98%）与线下（+59.40%）渠道双轮驱动，成功进驻Walmart、Costco等全球头部零售商，实现渠道广度与深度并进。
- **[自主生产+外协采购双轮驱动]** -> [供应链韧性与成本控制]: 自主生产掌握价值主导权，外协采购灵活调配产能，在营收增长53.83%的同时，整体毛利率仅微降0.37%，保持稳定。
- **[品牌全球化与年轻化]** -> [用户心智占领]: 服务全球超3亿客户，拥有超3000万线上粉丝，通过明星代言、IP联名等营销举措，推动品牌从功能价值向情感价值跃迁。

## 风险警告
**现金流恶化与存货高企是最大隐忧。** 2025年营收暴增53.83%至94.91亿元，但经营活动现金流净额却由正转负，录得-3533万元（2024年为+6.24亿元）。核心原因在于存货激增62%至20亿元，占总资产40.59%，以及应收账款因京东自营货款延迟结算等原因大幅膨胀至3.46亿元。这种“纸面富贵”的盈利质量，若存货跌价或回款不及预期，将直接冲击利润表。

**海外贸易政策与汇率波动构成双重外部冲击。** 公司海外收入占比超61%，高度依赖亚马逊等平台。全球贸易保护主义抬头、关税政策调整及人民币汇率波动，均可能侵蚀公司海外业务的毛利率与竞争力。尽管公司已启动海外生产布局，但短期难以完全对冲风险，业绩存在较大不确定性。
