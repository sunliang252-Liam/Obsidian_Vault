# 000768.SZ 深度透视

## 因果逻辑链
- **[民用航空产业高速发展]** -> [民机收入创新高]: C919、A320等项目产能提升，交付架份数增长25%，收入增长率超20%，成为业绩增长核心引擎。
- **[“十四五”攻坚任务收官]** -> [军品交付稳定]: 多型机首飞、鉴定，高质量完成军机任务，保障了军品业务的稳定基本盘。
- **[产品交付与现金回流错配]** -> [经营性现金流大幅恶化]: 以前年度预收货款在本期确认收入，但销售回款未同步增加，导致经营活动现金流净额骤降至-83.5亿元。
- **[成本精细化管控]** -> [毛利率提升]: 通过技术降本、供应链降本等举措，航空制造业毛利率同比提升0.93个百分点至6.40%。
- **[关联交易高度集中]** -> [供应链风险与利润依赖]: 前五大客户销售占比99.31%，前五大供应商采购占比83.57%，其中关联方采购占比46.12%，经营独立性受挑战。
- **[股权激励与人才引进]** -> [核心团队稳定与创新活力]: 实施限制性股票激励计划，引进博士37人，激发管理层与核心骨干积极性，支撑科技创新。
- **[大飞机创新原建设]** -> [技术突破与专利增长]: 深化产学研协同，全年专利授权量同比增长81.4%，3项国际标准获批，巩固技术护城河。

## 风险警告
**现金流断裂风险是当前最突出的财务隐患。** 公司2025年经营活动现金流净额为-83.5亿元，同比恶化14,392%，与11.5亿元的净利润形成巨大反差。主要原因是以前年度预收货款在本期确认收入，但销售回款严重滞后，导致应收账款和合同资产合计增加超120亿元。这种“纸面利润、现金吃紧”的格局若持续，将显著增加公司运营资金压力，甚至可能影响正常生产周转。

**客户与供应商高度集中带来的经营脆弱性不容忽视。** 公司前五大客户销售额占比高达99.31%，其中单一客户占比86.59%；前五大供应商采购额占比83.57%，关联方采购占比46.12%。这种“背靠大树”的模式虽保障了订单稳定性，但也意味着公司议价能力弱、回款周期受制于客户，且过度依赖航空工业体系内的关联交易，一旦集团战略调整或国防采购节奏变化，公司业绩将面临剧烈波动。
