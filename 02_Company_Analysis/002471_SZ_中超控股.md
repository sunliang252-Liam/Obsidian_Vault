# 002471.SZ 深度透视

## 因果逻辑链
- **[原材料成本占比超80%]** -> [毛利率极低且波动大]: 铜铝价格波动直接侵蚀利润，公司缺乏有效对冲机制，导致盈利能力脆弱。
- **[主动调整客户结构、压缩低质订单]** -> [营收下降5.81%]: 为改善现金流和资产质量，公司主动放弃部分回款差的业务，导致短期收入规模收缩。
- **[狠抓应收账款回款]** -> [经营现金流净额暴增434%至2.83亿]: 收现比达1.12，应收账款余额下降3.08亿，现金流质量显著优于利润表现。
- **[电缆板块在手订单26.95亿]** -> [未来收入有基本盘保障]: 订单占电缆营收46.2%，为后续业绩提供一定支撑，但需关注订单转化效率。
- **[高温合金精铸业务订单翻倍增长]** -> [第二增长曲线初现]: 全年新订单7292万元，同比增142.7%，单笔最大订单5155万元，但体量尚小，对整体业绩贡献有限。
- **[压缩债务规模]** -> [资产负债率下降4.06个百分点至65.01%]: 公司主动降杠杆，负债规模下降速度快于资产，财务结构有所优化，但短期偿债能力仍待提升。
- **[连续两年扣非净利润为负]** -> [主业盈利能力堪忧]: 剔除政府补助、债务重组等非经常性损益后，公司核心电线电缆业务处于亏损状态。

## 风险警告
公司核心风险在于主业盈利能力持续恶化。连续两年扣非净利润为负，且2025年亏损幅度扩大，表明电线电缆业务在激烈竞争和原材料波动下已陷入“增收不增利”甚至“增收反亏”的困境。尽管现金流改善，但这主要源于压缩业务规模和催收旧账，并非来自经营效率的根本提升，可持续性存疑。一旦宏观经济下行或下游客户付款周期拉长，现金流将面临巨大压力。

另一重大风险是高温合金精铸业务的“远水难解近渴”。该业务虽订单爆发、技术领先，但当前收入规模极小（仅占营收约0.3%），且处于大规模投入期（定增项目总投资10亿），短期内无法扭转公司整体亏损局面。若定增募资不顺或项目达产不及预期，公司将面临主业失血、新业务烧钱的双重困境，财务风险将进一步放大。
