# 300785.SZ 深度透视

## 因果逻辑链
- **全面AI战略** -> **营收结构优化，净利润增长**: 主动收缩低效业务，聚焦AI与核心业务融合，虽营收下降15.15%，但毛利率提升2.97个百分点，净利润增长14.99%。
- **新版“什么值得买”上线** -> **用户活跃度与转化率提升**: 以AI驱动兴趣消费，App下单用户渗透率提升0.9个百分点，618期间Agent订单转化率同比增长162.6%。
- **AI产品矩阵（AIGC/AIUC/Agent）** -> **内容生产效率与质量飞跃**: AIGC内容占比达56.59%，内容发布量增长16.92%，同时内容审核时长降低87.5%，实现降本增效。
- **“海纳”MCP Server生态合作** -> **开辟全新流量入口与商业模式**: 与40余家生态伙伴合作，月输出量增长超27倍，将消费数据能力输出，探索“对话即购物”闭环。
- **运营服务费收入增长** -> **代运营业务成为增长引擎**: 抖音DP等代运营业务聚焦高净值品牌，收入同比增长30.11%，弥补了信息推广和效果营销收入的下降。
- **主动收缩非核心业务** -> **短期营收承压，长期结构优化**: 品牌营销收入同比下降77.23%，信息推广收入下降23.38%，但资源集中投向AI，为未来增长蓄力。
- **消费数据资产沉淀** -> **构建AI时代竞争壁垒**: 收录2604.9万+商品，35.7万+品牌，形成“人货场”数据体系，为训练“值得买消费大模型”提供独家燃料。

## 风险警告
公司面临的核心风险在于对电商平台（阿里、京东等）的佣金政策高度依赖，以及抖音等新兴内容平台政策频繁变动。报告期内，前五大客户销售额占比超52%，客户集中度高，任何头部平台佣金比例下调或合作模式改变，都将直接冲击公司信息推广与效果营销两大核心收入来源。同时，代运营业务虽增长迅猛，但本质是“平台打工者”，在产业链中话语权较弱，利润空间受平台规则和品牌方预算双重挤压。

另一重大风险是AI战略的执行与商业化不确定性。公司虽已构建AI产品矩阵，但AI相关收入（4.87亿）的统计口径包含AI工具赋能的服务收入，其真正的增量贡献和可持续性有待验证。新版App用户停留时长和启动次数均出现下滑，表明AI重构用户体验的同时，也可能导致部分老用户不适。此外，大模型技术迭代极快，公司前期研发投入可能因技术路线变更而沉没，且AIGC内容的质量、合规性及版权风险始终是悬在头顶的达摩克利斯之剑。
