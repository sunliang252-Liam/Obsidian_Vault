# 002686.SZ 深度透视

## 因果逻辑链
- **[风机主业承压]** -> [营收微增0.83%]: 传统中央空调风机市场下滑15%，但公司凭借客户深度与广度对冲部分下行压力。
- **[汽车零部件放量]** -> [营收增长11.34%]: 铁城信息受益于新能源汽车行业增长，营收达5.96亿元，成为核心增长引擎。
- **[非经常性损益驱动利润]** -> [归母净利润增长34.36%]: 三进科技土地征收补偿产生资产处置收益约3.88亿元，掩盖了扣非净利润亏损3426万元的事实。
- **[扣非净利润转亏]** -> [核心盈利能力恶化]: 扣非净利润从1651万骤降至-3426万，主因汽车零部件毛利率大幅下滑8.8个百分点至2.63%。
- **[汽车零部件毛利率崩塌]** -> [行业价格战传导]: 新能源市场竞争加剧，铁城信息为保规模被迫降价，成本增速（22.41%）远超收入增速（11.34%）。
- **[经营现金流骤降80%]** -> [营运资金压力凸显]: 现金支付材料款大幅增加，导致经营活动现金流净额从2.54亿降至5019万，与净利润严重背离。
- **[商誉减值风险持续]** -> [资产质量承压]: 铁城信息相关商誉账面原值4.71亿元，本期再次计提减值1536万元，累计减值已达4.46亿元。

## 风险警告
**核心风险在于主业“空心化”与盈利质量恶化。** 公司传统风机业务在行业下行中营收萎缩6.93%，而寄予厚望的新能源汽车零部件业务（铁城信息）虽营收增长16%，但毛利率已跌至2.63%的极低水平，几乎无利可图。扣非净利润由盈转亏，表明公司已丧失内生性造血能力，当前账面利润完全依赖土地征收等一次性收益，可持续性存疑。

**资产质量与现金流风险不容忽视。** 铁城信息商誉账面价值仍高达1.55亿元，若行业价格战持续，未来仍有大额减值风险。同时，经营活动现金流净额同比暴跌80%，与净利润严重背离，显示公司营运资金管理面临巨大挑战，回款压力或存货积压问题加剧。在行业淘汰赛中，公司若无法快速提升产品竞争力或成本控制能力，将面临市场份额与盈利能力的双重挤压。
