# 688068.SH 深度透视

## 因果逻辑链
- **[体外诊断集采与行业政策]** -> [营收下降20.58%]: 国内IVD集采常态化导致产品价格下降及需求减少，叠加税收政策调整，直接压缩了公司核心业务的收入规模。
- **[创新药研发投入高企]** -> [净利润持续亏损]: 控股子公司舜景医药（SGC001等）及参股公司（尧景基因、智源生物）的临床推进，导致研发投入和投资损失合计超1.5亿元，是亏损主因。
- **[“诊断+创新药”双轮驱动战略]** -> [业务结构转型]: 公司从单一IVD业务向“诊断+创新药”转型，通过增资控股舜景医药，将生物创新药正式纳入主营业务，重塑了公司价值评估逻辑。
- **[SGC001心梗抗体药临床进展]** -> [核心管线价值凸显]: 全球首款心梗急救抗体药SGC001完成I期临床，启动II期，并获得FDA快速通道认证，成为公司未来最大的价值增长点。
- **[C-GALAD肝癌诊断模型纳入指南]** -> [肝健康产品壁垒增强]: 肝癌三项（AFP/AFP-L3%/DCP）及C-GALAD模型被纳入国家卫健委推荐指引和诊疗指南，巩固了公司在肝癌早筛领域的差异化竞争优势。
- **[AI技术平台建设]** -> [研发效率提升]: 成立“X-GenAI新药发现与设计研究中心”，开发TA-SEEK靶点发现平台和AI设计平台，旨在缩短新药研发周期，降低研发成本。
- **[金融资产公允价值变动]** -> [非经常性损益波动]: 公司持有较大规模的交易性金融资产（股票、基金、理财），其公允价值变动对当期利润产生显著影响（2025年贡献约2,342万元收益）。

## 风险警告
公司当前最大的风险在于**创新药研发的高失败率与现金流持续消耗之间的矛盾**。SGC001、SGT003等核心管线虽前景广阔，但均处于临床早期，距离商业化至少需要5-10年，且面临临床结果不及预期、监管审批受阻等重大不确定性。与此同时，IVD主业受集采影响持续承压，营收和利润双降，无法为创新药研发提供充足的现金流支撑。公司2025年经营活动现金流净额为-8,336万元，而研发投入高达1.63亿元，资金缺口巨大，主要依赖金融资产变现和外部融资维持，这种“烧钱”模式不可持续。

其次，**IVD主业面临集采降价与竞争加剧的双重挤压**。化学发光领域集采已常态化，公司产品价格下行压力巨大，而罗氏、雅培等国际巨头及国内同行在高端市场的竞争依然激烈。若公司无法通过新产品（如C-GALAD模型）的快速放量或海外市场拓展来弥补国内收入下滑，IVD业务可能进一步萎缩，导致公司整体估值逻辑从“双轮驱动”退化为“单轮亏损”，加剧市场对其持续经营能力的担忧。
