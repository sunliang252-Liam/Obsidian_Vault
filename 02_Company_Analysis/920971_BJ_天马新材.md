# 920971.BJ 深度透视

## 因果逻辑链
- **[原材料价格高位运行]** -> [毛利率骤降6.47个百分点]: 2024年末工业氧化铝价格处于历史高位，导致2025年营业成本增速（+16.54%）显著快于收入增速（+7.38%），侵蚀利润空间。
- **[募投项目投产初期产能爬坡]** -> [固定成本摊销增加，压制短期盈利]: 电子陶瓷及高导热粉体两大生产基地项目于2025年结项，新产线在产能利用率爬坡阶段，基建折旧及人工成本刚性增长，拖累毛利率。
- **[与金力股份诉讼和解]** -> [非经常性损益大幅增厚净利润]: 原计提的预计负债1828万元及信用减值损失转回，贡献营业外收入约1680万元，是净利润仅微降3.09%的核心原因。
- **[扣非净利润大幅下滑38.55%]** -> [真实经营盈利能力显著恶化]: 剔除诉讼和解等非经常性损益后，核心业务利润仅2015万元，反映主业在成本压力下盈利承压。
- **[短期借款激增2992%]** -> [营运资金压力加大]: 为应对原材料采购及经营周转，公司大幅增加短期借款，期末余额达5506万元，财务费用同比增长21.63%。
- **[高压电器用粉体收入增长76.30%]** -> [传统优势领域需求爆发]: 受益于电力工程及国家电网供应链需求释放，该品类成为收入增长的核心驱动力，但毛利率转负（-2.54%），增收不增利。
- **[存货同比增长25.65%]** -> [产能释放与下游消化节奏错配]: 新产线投产后，产成品及原材料库存积压至1.27亿元，占资产总额22.10%，存在跌价风险。
- **[研发投入持续加大，聚焦高端突破]** -> [长期竞争力构建]: 研发费用1144万元，重点攻关Low-α球形氧化铝、高纯纳米氧化铝等半导体封装用高端产品，为未来国产替代储备技术。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以扭转。** 公司营收增长7.38%，但扣非净利润暴跌38.55%，毛利率从24.21%骤降至17.74%。根源是上游原材料价格高位运行叠加新产线投产带来的折旧与爬坡成本，而公司对下游客户的议价能力不足，成本传导不畅。若原材料价格持续高企或产能利用率提升不及预期，公司盈利能力将进一步承压。

**诉讼和解带来的非经常性收益掩盖了主业疲软的现实。** 2025年净利润38,164万元中，约1800万元来自金力股份诉讼结案转回的预计负债。剔除该影响及政府补助减少等因素，公司真实经营利润大幅缩水。投资者需警惕，2026年将失去这一“一次性”利润支撑，若主业无法改善，业绩存在显著下滑风险。同时，短期借款激增至5506万元，财务费用上升，现金流压力不容忽视。
