# 688268.SH 深度透视

## 因果逻辑链
- **[行业产能过剩，价格内卷]** -> [营收微增1.7%，净利润却大降26.75%]: 传统氟碳类产品价格下行，销量增长被价格下跌对冲，利润空间被严重挤压。
- **[可转债利息费用及汇兑损失]** -> [财务费用激增62.98%]: 可转债按会计准则计提利息，叠加美元汇率下跌产生汇兑损失，直接侵蚀当期利润。
- **[高毛利电子特气新品放量]** -> [半导体领域产品毛利率提升1.04%]: 乙硅烷、溴化氢等高端新产品实现成果转化，优化了产品盈利结构，部分对冲了传统产品降价压力。
- **[收购鹤壁德瑞科技]** -> [完善高端氟化气体产业链]: 获得三氟化氯、乙硼烷等高附加值产品，强化了在半导体关键材料领域的研发与生产一体化能力。
- **[国内8-12寸晶圆厂客户覆盖率超90%]** -> [稳固市场基本盘]: 深度绑定中芯国际、长江存储等头部客户，高客户粘性形成强大竞争壁垒，抵御同行低价冲击。
- **[海外直销比例提升]** -> [新加坡半导体客户增至5家]: 通过收购新加坡AIG，实现本地化仓储物流，减少中间商环节，直接服务海外终端客户，提升毛利率。
- **[研发投入聚焦14nm及以下先进制程]** -> [57款产品实现进口替代]: 持续攻坚高纯碳氢类、硅基前驱体等高端产品，突破技术封锁，构建差异化竞争壁垒。

## 风险警告
**核心风险在于“量增价减”的盈利困境。** 行业产能集中释放导致价格内卷，尤其是传统氟碳类产品价格持续下行，而高毛利新产品的增量尚无法完全对冲，导致公司2025年出现“增收不增利”的显著背离。若价格战持续加剧，公司毛利率和净利润将面临进一步压缩的风险。

**财务与运营风险不容忽视。** 可转债利息费用和汇率波动已成为利润的显著拖累项，未来若人民币持续升值或利率上行，财务费用将继续侵蚀利润。此外，公司收购形成的商誉、下游需求波动（如消费电子复苏不及预期）、以及高端原材料（如氦气）的供应稳定性，均是潜在的风险点。
