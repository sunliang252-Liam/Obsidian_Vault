# 002047.SZ 深度透视

## 因果逻辑链
- **[重大资产出售剥离亏损资产]** -> [净利润扭亏为盈]: 2024年12月完成宝鹰建设100%股权出售，剥离持续亏损主体，使2025年归母净利润转正至5920万元。
- **[出售资产获取非经常性收益]** -> [扣非净利润仍亏损]: 出售旦华复能股权及成霖工业区房地产，合计贡献约9100万元非经常性收益，但主业萎缩导致扣非净利润仍亏损3219万元。
- **[传统建筑业务大幅收缩]** -> [营收断崖式下滑]: 剥离宝鹰建设后，公司营收从21.1亿元骤降至6.59亿元，降幅68.81%，仅保留宝鹰建科及少量建筑工程业务。
- **[客户高度集中]** -> [经营依赖单一关联方]: 前五大客户销售占比85.71%，其中关联方珠光集团贡献68.97%营收，公司业务对单一客户存在严重依赖。
- **[光耦合器新业务尚处初创期]** -> [第二增长曲线未形成]: 2025年12月设立澜兴科技切入光耦产业，截至报告期末未产生营收，新业务转型存在重大不确定性。
- **[控股股东变更与定增]** -> [控制权与资本结构重塑]: 世通纽拟通过协议转让+定增成为新控股股东，募集8亿元用于补充流动资金，但定增尚需审核，存在不确定性。

## 风险警告
公司2025年净利润扭亏为盈完全依赖资产出售等非经常性损益，扣非净利润仍亏损3219万元，核心建筑装饰业务营收暴跌86.53%，主营业务造血能力已近枯竭。新切入的光耦合器业务尚处试验期，无技术、人才储备，与现有业务无协同，短期内难以形成有效利润贡献，公司面临主业空心化与转型失败的双重风险。

公司当前经营高度依赖关联方珠光集团（贡献近70%营收），且控股股东即将变更为世通纽。世通纽承诺未来三年扣非净利润合计不低于4亿元，但该承诺主要依赖尚未投产的光耦及硅基新业务，实现难度极大。若定增失败或新业务不及预期，公司净资产仅5079万元，将再次面临资不抵债的退市风险。

> 深圳市宝鹰建设控股集团股份有限公司(以下简称:宝鹰建设、公司或宝鹰)成立于1993年。2013年12月,其控股股东宝鹰股份在深圳证券交易所上市(股票代码:002047)。2020年1月,宝鹰股份在建筑装饰行业率先完成混合所有制改革,控股股东是珠海大横琴集团,实际控制人是珠海市国资委。2024年12月,根据珠海大横琴集团的战略调整规划,宝鹰股份将宝鹰建设的控股权转让给珠海大横琴集团,至此,宝鹰建设正式成为由大横琴集团直接管理的二级企业。宝鹰建设是中国建筑装饰行业领先的大型综合建筑装饰企业,是行业内拥有最全资质的企业之一,业已形成建筑装饰材料生产与销售、建筑装饰设计与施工于一体的完备产业链,且具备海外建筑综合施工能力及经验。业务范围涵盖:工程总承包、装饰装修、幕墙钢结构、集成智能化、建筑消防、机电安装、安防技术、金属门窗、展览展会和医疗设备,专业为客户提供设计、施工、安装的综合解决方案及承建管理服务。近三十年积累已形成公共文化工程、高端酒店工程、政府安居工程、交通枢纽工程、科研教育工程、医疗健康工程、办公综合体工程、商业综合体工程在内的八大重点工程。宝鹰建设连续多年入选“中国建筑业成长性100强企业”、“中国建筑业竞争力200强企业”,多年蝉联中国建筑装饰行业100强企业前三。宝鹰是中国建筑装饰行业内拥有最齐全业务资质的大型综合装饰企业之一,致力于为客户提供更完善、更优质、更系统的建筑装饰工程设计施工综合解决方案及承建管理服务。“让每一座城市烙刻上宝鹰的足印”是公司既定业务愿景。目前,宝鹰业务网络覆盖33个省级行政区(省、自治区、直辖市和特别行政区),在北京、上海、武汉、广州、济南、昆明、成都等各大城市成立了分支机构,形成公共文化工程、高端酒店工程、政府安居工程、交通枢纽工程、科研教育工程、医疗健康工程、办公综合体工程、商业综合体工程在内的八大重点工程。宝鹰建设拥有一支优秀的设计、施工技术队伍,拥有大量工程、设计、经济、会计、管理、法律、预算、造价、质检、安全等专业的职称、资格认证人员,并储备了众多“鲁班奖工程项目经理(参建)”“全国建筑装饰工程优秀项目经理”、“全国建筑幕墙工程优秀项目经理”。为确保人才的可持续发展,宝鹰与广西电力水利职业技术学院开展深度校企合作,成立“宝鹰建筑学院”,培养专业技术人才。为践行公司海外战略,宝鹰与广东外语外贸大学建立校企合作关系,共同培育选拔外语、国际贸易等专业化人才,并共同致力于“一带一路”沿线国家青年领袖的培养与交流。凭借精益求精的工匠精神,以及“工厂化生产、规范化管理、装配化施工”的标准化生产管理模式,令客户满意的设计理念、科学完善的公司经营管理,宝鹰建设相继打造出一系列精品工程,造就了公司设计施工水平在中国建筑装饰行业较为领先的竞争地位。并立足中国,走向世界。
