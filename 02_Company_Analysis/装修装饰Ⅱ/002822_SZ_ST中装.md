# 002822.SZ 深度透视

## 因果逻辑链
- **[破产重整完成]** -> [资产负债结构根本性改善]: 通过引入产业投资人上海恒涔及财务投资人，注入13.37亿元增量资金，清偿债务并剥离低效资产，化解了流动性危机和债务风险。
- **[建筑装饰业务战略性退出]** -> [营收断崖式下滑66.92%]: 报告期内建筑装饰业务收入同比骤降86.44%，该板块资产作为偿债资源剥离至信托计划，导致公司总营收从23.19亿萎缩至7.67亿。
- **[聚焦物业管理服务主业]** -> [核心业务保持稳定]: 子公司科技园物业贡献营收5.35亿元，占总收入69.70%，同比仅下降11.68%，毛利率13.07%，成为公司重整后最稳定的收入来源。
- **[债务重组产生巨额非经常性损失]** -> [归母净利润巨亏31.65亿元]: 债务重组损益高达-18.35亿元，叠加资产减值损失-3.86亿元和信用减值损失-2.41亿元，导致净利润创历史最大亏损。
- **[重整投资款到账]** -> [现金流显著改善]: 筹资活动现金净流入4.61亿元（同比+441.26%），期末货币资金增至6.03亿元，占总资产39.58%，流动性危机得到初步缓解。
- **[产业投资人入主]** -> [战略方向转向固废资源化]: 新实控人龙吉生（康恒环境董事长）入主，公司计划依托其产业背景，开拓固废处理与资源再生业务，探索第二增长曲线。

## 风险警告
**核心风险在于业务转型的不确定性。** 公司已战略性退出建筑装饰主业，营收规模从38.57亿（2023年）骤降至7.67亿（2025年），核心仅剩科技园物业（5.35亿）。新实控人龙吉生虽在固废领域有深厚积累，但“物业管理+固废资源化”的跨界协同尚未形成实际收入，第二增长曲线仍停留在战略规划层面，存在转型失败导致公司沦为“空壳”的风险。

**财务风险虽经重整缓解，但历史包袱沉重。** 公司累计未弥补亏损高达44.85亿元，母公司报表未分配利润为-44.27亿元，预计较长时间内无法分红。此外，公司因财务造假被证监会处罚，原实控人庄展诺被市场禁入，投资者诉讼风险持续存在。尽管重整解决了债务危机，但公司信用修复、业务重建仍需时日，持续经营能力仍面临严峻考验。
