# 603137.SH 深度透视

## 因果逻辑链
- **[下游需求萎缩]** -> [营收与利润双杀]: 房地产行业深度调整，公司项目建设工程量下降，导致2025年营收同比下滑31.25%，归母净利润由盈转亏至-3502万元。
- **[客户结算周期延长]** -> [资产减值损失激增]: 项目回款节奏后移，公司基于谨慎性原则，对应收账款及合同资产充分计提坏账准备，信用及资产减值损失合计达-9589万元，成为亏损主因。
- **[业务规模收缩]** -> [经营现金流持续净流出]: 收入下降导致销售回款减少，但采购付款存在刚性，2025年经营活动现金流净额为-2.98亿元，连续两年为负，资金压力加剧。
- **[核心区域依赖]** -> [业务波动风险集中]: 公司业务高度集中于长三角（华东地区收入占比超98%），该区域市场波动直接决定公司业绩，区域外市场拓展缓慢，风险敞口大。
- **[募投项目停滞]** -> [战略扩张受阻]: 核心募投项目“广东江门幕墙智能化生产基地”因华南市场变化及用地问题，累计投入为0，已暂缓实施，公司跨区域扩张战略受挫。
- **[客户高度集中]** -> [议价能力与回款风险并存]: 前五大客户销售额占比高达74.28%，主要客户为大型国企总包方，虽保障了订单来源，但也导致公司在回款周期上处于相对弱势地位。

## 风险警告
**核心风险在于行业下行周期中的资产质量恶化与现金流断裂风险。** 公司2025年由盈转亏，核心并非经营性亏损，而是基于审慎原则计提的巨额资产减值（近1亿元）。这直接揭示了其下游客户（地产及工程总包）资金链紧张的现实，导致公司应收账款和合同资产（合计超28亿元，占总资产90%）的回收存在巨大不确定性。若宏观经济持续低迷，坏账计提将进一步侵蚀利润，甚至引发流动性危机。

**战略风险在于公司对单一区域和少数大客户的过度依赖，以及募投项目的实质性停滞。** 公司业务高度集中于长三角，区域外市场开拓不力，抗风险能力弱。同时，作为未来增长引擎的江门募投项目已暂缓，不仅浪费了宝贵的募集资金，更意味着公司短期内缺乏新的增长点，在行业出清阶段可能面临市场份额被蚕食的风险。此外，公司因信息披露问题已受到监管警示，治理规范性有待提升。
