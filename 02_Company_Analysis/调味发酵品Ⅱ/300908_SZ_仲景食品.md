# 300908.SZ 深度透视

## 因果逻辑链
- **[调味配料毛利率大幅提升]** -> [净利润增长9.35%]: 超临界CO2萃取产线满产释放规模效应，叠加原料成本下降，调味配料毛利率同比提升4.76个百分点，成为利润增长核心引擎。
- **[电商渠道费用优化]** -> [扣非净利润增长11.07%]: 公司主动削减低效电商推广投入，市场推广费同比下降31.38%，在营收微降1.42%的情况下实现利润逆势增长。
- **[调味食品营收下滑]** -> [整体营收承压]: 调味食品收入同比下降3.90%，主要受上海葱油线上直销下滑12.10%拖累，但线下经销渠道保持稳定，部分对冲了收入缺口。
- **[品类开创者地位]** -> [细分市场定价权]: 仲景香菇酱在菌菇酱品类市占率达50.1%，上海葱油连续5年全国销量第一，品类领导地位赋予公司较强的成本转嫁能力和品牌溢价。
- **[制药级品控体系]** -> [食品安全零事故]: 核心团队制药背景将严苛质量理念贯穿全链路，产品在国家及地方抽检中始终保持合格，构建了难以复制的信任壁垒。
- **[连续高分红]** -> [股东回报确定性]: 上市6年累计分红5.92亿元，2025年拟每10股派10元（分红率76%），高分红政策强化了价值投资逻辑，吸引长期资金。
- **[仲景西洋参新品]** -> [第二增长曲线探索]: 依托制药研发积淀推出100mg皂苷西洋参浓缩液，是公司从调味品向健康滋补领域延伸的战略尝试，但尚处市场培育期，短期贡献有限。

## 风险警告
**核心风险在于营收增长乏力与品类天花板。** 2025年公司营收同比下滑1.42%，核心大单品调味食品（香菇酱、葱油）收入下降3.90%，线上直销更是萎缩12.10%。在消费疲软与竞争加剧的背景下，公司依赖品类开创者地位维持利润增长，但若不能有效拓展新渠道或推出新爆品，营收停滞可能成为常态，利润增长将不可持续。

**另一重大风险是原材料价格波动与新产品开发的不确定性。** 香菇、花椒等主要原料成本占主营业务成本比重极高，且受气候、供需等多因素影响。虽然公司通过战略采购对冲，但若原料价格大幅上涨，将直接侵蚀已显脆弱的利润空间。同时，仲景西洋参等新品类尚处培育期，市场接受度与投入回报存在较大不确定性，若未能如期打开市场，将拖累整体盈利能力。

**公司简介（F10 原文）**

> 仲景食品股份有限公司(简称仲景食品,证券代码:300908),围绕“高品质、好味道”的产品理念,专注于调味食品和调味配料的研发、生产与销售,代表产品有仲景香菇酱、上海葱油、鲜花椒油等调味油、黄焖炒鸡等炒菜料和香辛调味配料等,服务于个人家庭、餐饮饭店和食品生产企业。仲景食品生产总部位于中国香菇之乡——河南省南阳市西峡县,营销中心位于郑州市郑东新区;是高新技术企业、国家绿色工厂、农业产业化国家重点龙头企业、中国航天事业合作伙伴。仲景食品是国内香辛调味配料的领先供应商,拥有分子蒸馏、风味指标数据化、风味定量调配等多项核心技术,主要服务于联合利华、康师傅等国际国内知名食品企业。仲景香菇酱、仲景新型香辛料研发项目通过中国食品科学技术学会鉴评,“整体技术达到国内领先水平”。
