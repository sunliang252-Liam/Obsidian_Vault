# 603115.SH 深度透视

## 因果逻辑链
- **[下游需求景气 + 新基地产能释放]** -> [营收增长19.05%]: 下游AI服务器、新能源等领域需求旺盛，公司高效建设新生产基地，产能持续释放，带动销售数量增加。
- **[产品结构优化 + 高端产品占比提升]** -> [毛利率稳定提升0.55个百分点]: 公司主动调整产品结构，增加车载电子、AI服务器等高端产品供应，在原材料价格波动下维持了平均售价稳定。
- **[产能扩张 + 规模效应]** -> [净利润增长28.17%]: 新基地投产带来的规模效应摊薄了固定成本，叠加营收增长，利润增速显著高于营收增速。
- **[研发投入持续加码 (占营收7.15%)]** -> [技术壁垒巩固]: 持续攻关高端电极箔“卡脖子”技术，车载、AI服务器产品实现从实验室到大生产转化，强化国产替代能力。
- **[股权激励绑定核心团队]** -> [管理效率提升]: 推出新一期股权激励计划，覆盖经营管理团队和核心骨干，激发组织活力，推动人均效率提升。
- **[连续6年高比例现金分红]** -> [股东回报稳定]: 2025年拟每10股派6元，分红比例高达70.37%，体现公司对股东回报的重视和现金流状况的改善。
- **[经营活动现金流净额大增110.49%]** -> [盈利质量改善]: 销售回款增加及政府补助到账，使得经营性现金流增速远超净利润增速，表明公司盈利质量显著提升。

## 风险警告
**核心风险在于产能扩张后的需求可持续性与竞争加剧。** 公司2025年业绩高增主要依赖下游AI服务器、新能源等新兴领域的爆发式需求，以及新基地产能的快速释放。若未来宏观经济下行或下游行业景气度反转，新增产能可能面临消化压力，导致产能利用率下降、毛利率承压。同时，电极箔行业参与者众多，竞争激烈，若公司不能持续保持技术领先和客户粘性，市场份额可能被侵蚀。

**原材料与能源价格波动是侵蚀利润的潜在隐患。** 公司主要原材料电子光箔（铝）和电力成本占比较高。铝价受宏观经济和供需关系影响波动较大，电价政策也存在调整可能。虽然公司通过优化基地布局和长期合作部分对冲了风险，但若原材料或能源价格出现超预期上涨，而公司无法将成本压力完全传导至下游客户，将直接压缩利润空间。
