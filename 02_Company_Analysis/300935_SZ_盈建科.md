# 300935.SZ 深度透视

## 因果逻辑链
- **[下游行业持续低迷]** -> [营收下滑4.91%]: 建筑业和房地产业深度调整，客户采购需求延迟，导致软件销售收入同比下降17.76%。
- **[逆周期加大研发与销售投入]** -> [净利润亏损扩大至-7,867万元]: 在营收下滑背景下，公司为抢占AI与海外市场，研发费用和销售费用分别增长7.56%和15.95%，费用刚性导致亏损加剧。
- **[AI大模型技术平台化落地]** -> [产品代际升级]: 将GPT/DeepSeek等大模型集成至BIMFire平台，实现“对话即设计”，从工具软件向智能设计平台转型。
- **[海外市场突破]** -> [打开第二增长曲线]: 以香港为桥头堡，通过香港屋宇署鉴定并发布本地化版本，为东南亚等市场拓展奠定基础。
- **[高研发投入侵蚀利润]** -> [研发费用率高达67.66%]: 持续高强度的研发投入（8,610万元）是保持技术领先的必要代价，但短期内严重拖累净利润表现。
- **[销售费用率畸高]** -> [销售费用率75.4%]: 销售费用（9,600万元）远超营收，表明公司为维持市场份额和拓展新业务，付出了极高的渠道与推广成本。
- **[经营性现金流持续为负]** -> [现金流恶化80.46%]: 销售回款减少叠加人工成本增加，导致经营活动现金流净额降至-5,851万元，造血能力严重不足。

## 风险警告
**核心风险在于“增收不增利”的恶性循环与现金流枯竭。** 公司营收下滑4.91%，但销售费用却逆势增长15.95%至9,600万元，销售费用率高达75.4%，远超行业平均水平。这表明公司为维持市场份额和推广新产品（如AI、海外版），正以极高的成本进行“烧钱式”扩张。与此同时，研发费用率也攀升至67.66%，两项费用合计已超过营收，导致亏损同比扩大54.93%。更危险的是，经营性现金流净额已连续三年为负，且2025年恶化至-5,851万元，公司造血能力已近枯竭，高度依赖IPO募集资金维持运营。

**第二重风险是下游行业景气度持续低迷带来的系统性风险。** 公司核心客户为建筑设计院和地产公司，2025年全国房地产开发投资同比下降17.2%，客户预算紧缩直接导致公司核心产品“软件销售”收入下降17.76%。虽然公司押注AI和海外市场，但AI产品尚处于“技术验证走向产品化”阶段，海外收入占比几乎为零（仅8,856元），短期内难以弥补国内市场的下滑。若建筑业复苏不及预期，公司可能面临“老业务萎缩、新业务无法接棒”的困境，持续亏损将加速消耗公司净资产。
