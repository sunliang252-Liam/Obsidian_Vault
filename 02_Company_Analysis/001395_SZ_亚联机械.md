# 001395.SZ 深度透视

## 因果逻辑链
- **[收入下降但毛利率提升]** -> [净利润逆势增长]: 2025年交付验收的生产线项目毛利率较高，抵消了收入下滑7.42%的负面影响，使净利润同比增长20.93%。
- **[国内刨花板产能过剩]** -> [国内收入下滑]: 下游刨花板行业投资过热导致产能过剩，新建项目数量回落，公司国内收入同比下降21.72%。
- **[海外市场拓展]** -> [海外收入高增]: 公司凭借技术优势和性价比，积极开拓俄罗斯、东南亚等市场，海外收入同比增长62.02%，成为增长新引擎。
- **[IPO募资与理财收益]** -> [财务费用与投资收益改善]: 上市募集资金带来利息收入，同时理财投资收益增加，共同推动财务费用由正转负，投资收益大幅增长。
- **[“先款后货”模式]** -> [经营现金流与净利润背离]: 客户在验收前支付大部分款项，导致收款时间早于收入确认时点，2025年经营现金流净额同比大降91.28%，与净利润表现显著背离。
- **[连续平压技术壁垒]** -> [高市场占有率]: 公司掌握人造板连续平压核心技术，在国内纤维板和刨花板连续平压生产线市场占有率分别达38.52%和30.07%，形成稳固的竞争格局。
- **[下游需求疲软]** -> [改造项目收入锐减]: 受房地产行业调整和家具市场需求疲软影响，下游客户资本开支意愿下降，公司改造项目收入同比大幅下滑53.19%。

## 风险警告
**核心风险在于下游行业景气度下行与产能过剩的双重挤压。** 报告明确指出，刨花板产能供过于求的矛盾依然突出，房地产行业持续调整，导致下游客户经营压力巨大，新建生产线项目数量明显回落。公司国内收入已出现21.72%的下滑，若下游复苏乏力，公司可能面临订单萎缩、产能利用率下降的困境。

**国际化经营风险正在放大。** 公司海外收入占比已从17%跃升至30%，但海外市场面临地缘政治、汇率波动、贸易壁垒及文化差异等复杂挑战。同时，公司需与迪芬巴赫、辛北尔康普等国际巨头在品牌、项目总包经验上直接竞争，若国际化人才与服务体系不能及时跟上，海外业务拓展可能受阻，影响整体业绩。
