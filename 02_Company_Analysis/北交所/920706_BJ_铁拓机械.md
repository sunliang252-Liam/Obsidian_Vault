# 920706.BJ 深度透视

## 因果逻辑链
- **[俄罗斯市场萎缩]** -> [营收下降17.61%]: 俄罗斯紧缩货币政策导致当地客户融资成本升高，投资意愿降低，公司对俄销售大幅减少。
- **[主动放弃低质量订单]** -> [营收下降]: 内销市场主动放弃价格较低、付款条件较差的订单，虽保利润但牺牲规模。
- **[募投项目转固]** -> [固定资产大增83.53%]: 沥青装备智能化生产建设项目和研发中心建设完工，联合厂房等从在建工程转入固定资产。
- **[订单减少导致采购支出下降]** -> [经营现金流暴增501.70%]: 营收下降使原材料采购现金支出减少，经营活动现金流净额从1326万跃升至7981万。
- **[政府补助增加]** -> [其他收益增长177%]: 收到超长期国债补贴等政府补助，其他收益从238万增至659万。
- **[汇率波动]** -> [财务费用由负转正]: 汇兑损失增加，财务费用从-272万升至-129万，侵蚀利润。
- **[产品结构优化]** -> [毛利率微升]: 核心产品TS4020-T8等高附加值设备占比提升，整体毛利率从30.32%升至31.16%。

## 风险警告
**俄罗斯市场依赖风险**：公司外销收入占比近半，而俄罗斯市场因政治经济环境恶化（紧缩货币政策）导致需求骤降，是2025年营收下滑的主因。若俄乌冲突持续或制裁加码，该市场可能进一步萎缩，而公司短期内难以找到同等体量的替代市场。

**原材料价格波动风险**：热轧钢板、H型钢等主要原材料成本占营业成本比重高。若未来钢价大幅上涨，而公司无法通过提价或技术工艺完全消化，毛利率将承压。当前毛利率仅31%，缓冲空间有限。

**应收账款与汇率双重挤压**：公司采用分期收款销售模式，一年内到期的长期应收款大增60.55%，回款周期拉长。同时，外销业务面临卢布等货币贬值风险，2025年已出现汇兑损失，若人民币持续升值或新兴市场货币动荡，利润将进一步被侵蚀。

> 福建省铁拓机械股份有限公司是一家集研发、生产、销售和服务为一体的沥青混合料搅拌设备及其配套设备的专业生产商。铁拓机械围绕沥青混合料从生产到回收的全生命周期,建立了包括沥青混合料搅拌设备、沥青混合料厂拌热再生设备、RAP柔性破碎筛分设备、骨料制砂设备等在内的全品类、多系列产品体系。依靠20年的技术积累与丰富的定制化产品开发经验,铁拓机械已成为行业中少数掌握适用于国内外各类复杂应用场景技术解决方案的设备提供商之一。铁拓机械作为国家高新技术企业,始终将设备研发能力作为核心竞争力之一,拥有完善的研发创新机制,并与长安大学等科研院所建立了良好的合作关系,是国内沥青混合料搅拌设备行业标准化工作的重要参与者。公司还设有福建省企业技术中心、福建省沥青再生设备企业工程技术研究中心及博士后科研工作站,曾先后荣获工信部和中国工业经济联合会认定的中国制造业单项冠军培育企业、国家级专精特新“小巨人”企业、国家知识产权优势企业、福建省优秀民营企业、省级创新型企业、中国外贸出口先导指数样本企业等荣誉称号。铁拓机械也是我国较早专门针对回收沥青路面材料(RAP)的再生利用设备进行技术研发的企业,在多项关键领域实现了技术突破,其中沥青混合料厂拌热再生设备是国家级制造业单项冠军产品。沥青厂拌热再生等关键技术多次荣获福建省科学技术进步奖等荣誉。铁拓机械积极响应国家“一带一路”倡议,将沿线国际市场作为重点拓展区域,依靠多年来为国内不同地区客户提供定制化产品积累的丰富开发经验,掌握了针对沙漠、雪地、高原、潮湿等不同自然环境提供产品解决方案的能力,从而能够在较短研发周期内为不同国家标准、自然环境和经济水平要求下的客户提供具有成本和质量优势的定制化解决方案。截至目前,铁拓机械产品已销售至俄罗斯、泰国、印尼等全球60多个国家或地区,有力提高了中国沥青混合料搅拌设备在国际市场中的知名度和美誉度。
