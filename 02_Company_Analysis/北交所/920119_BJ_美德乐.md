# 920119.BJ 深度透视

## 因果逻辑链
- **[新能源电池与储能市场双重爆发]** -> [营收增长20.31%]: 2025年全球动力电池装车量增长31.7%，储能锂电池出货量增长79%，直接拉动公司核心产品需求。
- **[高精度输送系统技术领先]** -> [毛利率提升至36.09%]: 公司高精度输送系统在新能源电池领域市占率扩大，产品结构优化，带动整体毛利率同比提升2.49个百分点。
- **[深度绑定头部客户]** -> [业绩确定性高]: 前五大客户贡献57.69%营收，其中比亚迪占比33.91%，客户集中度高但订单稳定性强。
- **[产能全国化布局]** -> [交付能力提升]: 苏州工厂竣工投产、惠州新设子公司、大连总部扩租4万平米，三地联动释放产能支撑订单增长。
- **[研发驱动产品创新]** -> [构筑技术壁垒]: 研发费用增长30.47%，磁驱/混合动力输送系统进入小批量生产，填补国内外空白，技术达国际领先水平。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比增长124.5%至2.11亿元，主要得益于承兑汇票支付采购款减少现金流出。
- **[存货高企但风险可控]** -> [以销定产模式]: 存货占总资产43.79%，以发出商品为主，与合同负债（10.21亿元）高度匹配，反映在手订单充足。

## 风险警告
**客户与行业双重集中风险。** 公司营收超50%依赖前五大客户，其中比亚迪一家占比超三成；下游新能源电池领域收入占比极高。若主要客户产能扩张放缓或转向自研，或新能源行业政策补贴退坡、技术路线突变（如固态电池对产线要求改变），公司将面临订单骤降风险。尽管公司计划拓展汽车零部件、电子等领域，但短期内难以改变对新能源赛道的重度依赖。

**存货与应收款减值隐患。** 期末存货高达12.23亿元（占总资产43.79%），其中发出商品占大头；应收款项（含票据、账款、融资）合计超6.5亿元。公司采用“以销定产”模式，但若下游客户项目延期、验收受阻或经营恶化，大额存货和应收款可能集中爆发减值损失，侵蚀利润。2025年信用减值损失已同比大增202%，需警惕这一趋势延续。
