# 920689.BJ 深度透视

## 因果逻辑链
- **[下游景气度高涨]** -> [营收增长10.97%]: 集装箱船、汽车运输船、轨道交通等下游订单稳定增加，直接拉动主营业务收入增长。
- **[产品结构优化]** -> [毛利率微升至28.17%]: 高毛利的冷却系统产品（毛利率30.26%）收入增速（18.95%）快于整体，带动综合毛利率小幅改善。
- **[研发投入加大]** -> [净利润增速远低于营收]: 研发费用同比大增22.82%（至3305万），叠加财务费用因利息和汇兑损失飙升135.88%，严重侵蚀利润增量。
- **[核电业务突破]** -> [打开第二增长曲线]: 2024年实现省外核电项目签约，2025年末核电在手订单达1.64亿元，从区域配套走向全国市场。
- **[国际化布局加速]** -> [境外收入短期承压]: 墨西哥、新加坡子公司设立导致租赁负债增462.91%，但EC风机出口下滑致境外收入同比减少5.43%，短期成本先行。
- **[应收账款高企]** -> [信用减值损失扩大80.88%]: 应收账款余额增至2.33亿元（+17.42%），周转率降至2.57，坏账计提压力加大，侵蚀利润。
- **[可转债成功发行]** -> [资本结构优化]: 2026年初完成2亿元可转债发行，募资净额1.97亿元，为后续产能扩张和研发投入提供资金保障。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长10.97%，但净利润仅微增0.80%，研发费用和财务费用的大幅膨胀是主因。更值得警惕的是，经营活动现金流净额同比骤降41.19%至5465万元，远低于净利润水平，表明收入增长并未有效转化为现金，应收账款和存货的快速膨胀（存货+13.13%）正在大量占用营运资金。

**下游景气度与公司业绩的传导链条存在脆弱性。** 公司高度依赖轨道交通、海工船舶等周期性行业，且前五大客户集中度高达44.40%。若宏观经济放缓或下游产业政策调整（如铁路投资减速、风电价格战持续），将直接导致订单萎缩。同时，原材料（电机、板材）价格波动风险未消，公司议价能力受限于大客户，成本压力难以完全转嫁。
