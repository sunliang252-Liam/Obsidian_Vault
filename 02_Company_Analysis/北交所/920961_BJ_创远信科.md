# 920961.BJ 深度透视

## 因果逻辑链
- **[5G FR1建设放缓，运营商投资减少]** -> [主营收入下降12.13%]: 公司核心无线通信测试业务受下游5G基站建设周期低谷影响，订单下滑，导致收入从2.33亿降至2.04亿。
- **[研发支出资本化率高达69.70%]** -> [账面净利润为正，但扣非净利润巨亏2889万]: 公司将大量研发投入（8744万）资本化，掩盖了经营实质亏损，扣非后净利率为-14.1%。
- **[新业务（车联网、卫星互联网）仍处市场开拓期]** -> [未能形成规模化营收贡献]: 公司“1+3”战略中两个新增方向尚未进入收获期，无法弥补传统5G业务下滑的缺口。
- **[参股公司小唐科技亏损1438万]** -> [投资收益同比减少56.53万]: 权益法核算的参股公司经营不及预期，进一步拖累合并报表利润。
- **[下游客户回款周期延长]** -> [信用减值损失增加134.8万]: 应收账款坏账准备计提增加，侵蚀当期利润。
- **[总部基地落成，在建工程转固]** -> [固定资产增长104.72%，新增房产税负担]: 固定资产从1.33亿增至2.72亿，税金及附加增长339.60%，折旧和税费压力加大。
- **[拟收购微宇天导100%股权]** -> [寻求“通导一体”战略协同]: 通过重大资产重组，将通信测试与导航定位测试业务融合，打造“地面—低空—卫星”全域测试能力，是未来增长的关键变量。
- **[政府补助占净利润比重高达868%]** -> [利润高度依赖非经常性损益]: 计入当期损益的政府补助3023万，是账面净利润348万的8.68倍，主业盈利能力极弱。

## 风险警告
**核心风险：主业持续失血，利润靠“财技”与“补助”粉饰。** 公司扣非净利润已连续两年为负（2024年-1629万，2025年-2889万），且亏损幅度扩大。2025年账面净利润348万，完全依赖3023万政府补助和593万资产处置收益。高达69.70%的研发支出资本化率（8744万）更是将大量费用后置，一旦资本化项目未来收益不及预期，将面临巨额减值风险。公司实际经营造血能力堪忧，投资者需警惕“伪盈利”陷阱。

**战略风险：新业务远水难解近渴，重组整合存在不确定性。** 公司寄予厚望的车联网、卫星互联网等新业务尚处市场开拓期，短期内无法贡献规模化收入，而传统5G业务已进入投资下行周期。拟收购微宇天导虽意在打造“通导一体”协同效应，但交易作价8.86亿元，且尚处审核阶段，后续整合、业绩对赌兑现及商誉减值风险均不容忽视。在行业竞争加剧、国外巨头垄断的格局下，公司能否通过并购实现突围，存在重大不确定性。
