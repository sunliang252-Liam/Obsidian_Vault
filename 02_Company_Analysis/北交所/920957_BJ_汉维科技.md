# 920957.BJ 深度透视

## 因果逻辑链
- **[募投项目转固，折旧激增]** -> [管理费用上升20.36%]: 单甘脂等新产线转固，固定资产折旧费用增加，直接推高管理费用。
- **[单甘脂新线产能利用率低]** -> [资产减值损失暴增]: 新产线初期产能未完全释放，单位产品分摊的制造费用及折旧高，导致成本高于可变现净值，计提存货跌价准备。
- **[印尼子公司运营周期长，原材料价格下行]** -> [整体毛利率下降至9.83%]: 印尼基地从采购到交付周期长，在原料下行期间成本调整滞后，销售端价格承压，拉低整体毛利。
- **[政府补助及进项税加计抵减减少]** -> [其他收益下降55.34%]: 2024年有重大项目产业化绩效奖励，2025年无此项目，且进项税加计抵减额减少。
- **[印尼子公司产能爬坡]** -> [营收增长4.74%]: 印尼项目全年营收1.51亿元，同比增长42.58%，是公司营收增长的主要驱动力。
- **[募投项目新产品投产]** -> [丰富产品结构]: 单甘脂等新产品线投产，为公司未来规模及业绩增长提供保障，但短期拖累利润。
- **[原材料价格波动]** -> [经营业绩承压]: 硬脂酸价格受棕榈油影响，公司无法完全向下游传导成本压力，导致毛利率波动和业绩下滑。
- **[海外布局]** -> [拓展国际市场]: 设立美国孙公司Hancore Lubricant LLC，旨在开拓美国市场，提升国际品牌形象。

## 风险警告
**核心风险在于盈利能力急剧恶化。** 2025年归母净利润同比暴跌75.41%，扣非净利润下降76.99%，毛利率从11.11%降至9.83%。根本原因是募投项目转固后折旧激增，叠加新产线产能利用率低导致存货减值，以及印尼子公司因运营周期长在原料下行期严重拖累毛利。公司正处于“增收不增利”的阵痛期，新产能释放与成本消化之间的时间差是当前最大挑战。

**原材料价格波动与供应商集中风险叠加。** 公司主要原材料硬脂酸价格受棕榈油影响，且第一大供应商采购占比高达43.20%，议价能力弱。若未来原料价格大幅上涨或持续剧烈波动，公司无法及时向下游传导，将导致毛利率进一步压缩，甚至出现亏损。印尼基地的海外运营周期长，放大了这一风险。
