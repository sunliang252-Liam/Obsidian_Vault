# 920050.BJ 深度透视

## 因果逻辑链
- **[大客户Medline集团深度绑定]** -> [营收增长42.95%]: Medline集团贡献78.62%营收，同比增58.31%，是业绩核心引擎。
- **[泰国产能扩张与全球化布局]** -> [抵御贸易摩擦风险]: 在泰国设立三个生产基地，形成规模效应，承接美国市场订单转移，对冲中美贸易战影响。
- **[ODM/OEM代工模式]** -> [高客户粘性与低销售费用]: 与Medline等国际品牌商合作超3年认证周期，销售费用率仅1.27%，远低于自主品牌企业。
- **[原材料成本加成定价]** -> [毛利率稳定在22-23%]: 与客户建立临时价格协商机制，当原材料（复合膜、绒毛浆）或汇率波动时，可调整订单价格，锁定利润。
- **[在建工程与资本开支高增]** -> [短期借款与财务费用上升]: 凯普乐、默瑞医疗等新工厂建设投入，导致短期借款增108.63%，财务费用由负转正，侵蚀利润。
- **[康复护理产品放量]** -> [收入结构优化]: 康复护理产品收入增61.31%，占比超60%，成为第一大品类，增速高于手术感控产品。
- **[子公司凯普乐亏损]** -> [拖累合并净利润]: 新投产子公司凯普乐亏损2019万元，处于产能爬坡期，是净利润增速（16.57%）远低于营收增速（42.95%）的主因。

## 风险警告
**单一客户依赖风险极高。** Medline集团贡献近80%营收，且公司以ODM/OEM模式运作，无自主品牌溢价。一旦Medline因自身经营或地缘政治因素转移订单，公司业绩将遭受毁灭性打击。尽管公司布局泰国、摩洛哥分散风险，但新客户开拓周期长（3年以上），短期内无法替代核心客户。

**产能扩张与现金流错配风险。** 公司处于激进扩张期，在建工程高达3.15亿元，短期借款激增108%，导致资产负债率从27%飙升至38%，流动比率降至0.85。新工厂（凯普乐、默瑞）尚未贡献利润，反而产生大额亏损。若海外需求放缓或贸易政策突变，高额资本开支将转化为沉重的折旧与利息负担，严重侵蚀利润。
