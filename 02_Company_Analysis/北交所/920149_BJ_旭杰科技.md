# 920149.BJ 深度透视

## 因果逻辑链
- **[收购中新旭德（光伏电站运营）]** -> [业务结构剧变]: 公司从建筑装配化+光伏EPC，转型为光伏电站转售/运营+建筑装配化+海外ALC贸易，光伏业务收入占比升至49%。
- **[国内装配式建筑市场萎缩]** -> [核心业务亏损]: 子公司常州杰通停产、苏州杰通停止PC生产，导致资产减值、人员安置费用激增，是2025年净亏损3994万元的主因。
- **[澳洲建筑市场需求增长]** -> [海外业务逆势增长]: 子公司Sipo Building ALC板材销售同比增长44.58%，成为公司唯一增长引擎，贡献净利润610万元。
- **[收购中新旭德形成商誉]** -> [资产负债表膨胀]: 合并报表新增存货1.79亿、固定资产1.19亿、长期借款1.37亿，总资产增长15.2%，但资产负债率升至81.37%。
- **[应收账款高企与坏账计提]** -> [利润侵蚀]: 应收账款账面价值占总资产33.55%，2025年信用减值损失达2038万元，同比增113%，是亏损扩大的重要原因。
- **[光伏电站转售业务高周转低毛利]** -> [毛利率承压]: 新增的分布式光伏电站转售业务毛利率仅0.46%，拉低整体毛利率至13.94%，虽略高于2024年，但盈利能力脆弱。

## 风险警告
**核心风险在于业务转型的阵痛与高杠杆的脆弱性。** 公司正从传统建筑装配化向光伏电站全产业链（开发-建设-运营）艰难转型，但代价惨重：传统PC构件业务已实质破产（常州杰通进入破产清算），苏州杰通停产，导致2025年巨额资产减值和人员安置费用。同时，收购中新旭德带来的商誉（303万元）和长期借款（1.76亿元）使资产负债率飙升至81.37%，财务费用同比增27.5%，利息保障倍数为-1.53，偿债压力巨大。

**第二大风险是光伏新业务的盈利质量与客户依赖。** 公司光伏业务高度依赖关联方中新绿能（销售占比34.45%），且新增的电站转售业务毛利率极低（0.46%），本质是资金驱动的低附加值贸易。若关联交易定价不公允或下游电站资产转让不畅，将直接冲击现金流。此外，应收账款高达3亿元，坏账风险持续暴露，经营现金流净额同比骤降69.5%，造血能力严重不足。
