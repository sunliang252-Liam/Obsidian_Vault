# 920770.BJ 深度透视

## 因果逻辑链
- **[分布式光伏电站投资运营规模扩张]** -> [营收与利润双增]: 自持电站装机容量增加，带动电费收入同比增长16.21%，是公司最稳定的利润来源。
- **[石英制品业务拓展]** -> [收入高增但亏损加剧]: 石英制品收入同比增长47.32%，但子公司艾特石英全年亏损2427万元，拖累整体盈利质量。
- **[资产减值损失大幅增加]** -> [侵蚀利润]: 计提存货跌价准备及固定资产减值损失合计1884万元，同比增加112.20%，反映出资产质量承压。
- **[固定资产报废与处置损失]** -> [非经常性损益拖累]: 营业外支出同比增加276.80%，主要因固定资产报废，导致扣非净利润高于归母净利润。
- **[短期借款大幅增加]** -> [财务杠杆上升]: 短期借款同比增长53.50%，利息费用增加，财务费用上升13.95%，加大偿债压力。
- **[电价市场化改革]** -> [未来收益不确定性增强]: 新项目上网电量需参与市场化交易，电价波动将直接影响分布式电站投资回报率。
- **[高新技术企业税收优惠]** -> [有效降低税负]: 15%所得税率及公共基础设施项目“三免三减半”政策，是维持净利润率的重要支撑。

## 风险警告
**核心风险在于资产质量与盈利可持续性。** 公司固定资产占总资产65%，其中自持电站是核心资产。但2025年计提了638万元固定资产减值准备，且资产减值损失同比翻倍，暗示部分电站收益不及预期或面临技术淘汰风险。同时，石英制品业务作为第二增长曲线，收入虽增但亏损持续扩大，子公司艾特石英净资产为负，存在拖累合并报表的风险。

**电价市场化改革是悬在头顶的达摩克利斯之剑。** 公司核心收益来自“自发自用、余电上网”模式下的电费收入。2025年新政要求增量项目全面参与市场化交易，工商业电价的波动将直接冲击项目收益率。公司虽强调“严控成本”，但在电力现货市场建设加速的背景下，缺乏对冲电价下行风险的有效工具，未来新增电站的投资回报率存在显著不确定性。
