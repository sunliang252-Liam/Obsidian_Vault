# 920808.BJ 深度透视

## 因果逻辑链
- **[AI算力需求爆发与芯片功耗飙升]** -> [液冷成为数据中心“必选项”]: 芯片TDP突破风冷极限800W，液冷技术从“可选”变为“必选”，驱动公司液冷产品需求爆发。
- **[ScaleX640超节点大规模部署]** -> [浸没液冷收入暴增370.58%]: 公司全球首个单机柜640卡超节点落地，浸没相变液冷C8000产品进入大规模商业化部署阶段，成为收入增长核心引擎。
- **[冷板液冷渗透率快速提升]** -> [冷板液冷收入同比增长40.01%]: 互联网巨头（字节、阿里、腾讯等）加速采用冷板液冷，公司凭借先发优势占据行业领先份额，但市场竞争加剧导致毛利率承压。
- **[以销定产模式与四季度集中确认]** -> [应收账款与存货大幅攀升]: 收入同比增长74.29%，但四季度收入占比达68%，导致年末应收账款（+71.36%）和存货（+207.10%）激增，经营活动现金流净流出4.38亿元。
- **[高强度研发投入]** -> [巩固技术壁垒与产品迭代]: 研发投入同比增长47.16%，占收入11.08%，推动C8000-V3.0（单机柜功率超900kW）及相变冷板液冷等新品研发，维持全球领先身位。
- **[市场竞争加剧与项目结构变化]** -> [综合毛利率下降4.45个百分点]: 冷板液冷市场导入期竞争激烈，叠加低毛利委托开发项目占比提升，导致整体毛利率从30.10%降至25.65%。
- **[关联交易占比高]** -> [收入依赖关联方风险]: 对关联方（中科曙光体系）销售占比46.98%，第一大客户占比42.56%，客户集中度高，关联关系变化可能对收入产生重大影响。

## 风险警告
**现金流与资产质量风险**：公司2025年经营活动现金流净流出高达4.38亿元，远超净利润。收入爆发式增长背后，是应收账款（7.09亿，+71%）和存货（3.70亿，+207%）的急剧膨胀，且四季度收入占比68%导致回款滞后。这种“增收不增现”的模式，叠加短期借款激增17倍至4.06亿元，使公司面临较大的流动性压力和坏账风险。若下游客户回款周期延长或项目验收延迟，可能引发资金链紧张。

**盈利质量与竞争格局恶化风险**：尽管收入增长74%，但净利润同比下降39.93%，扣非净利润仅增长52.52%且基数极低。核心问题是毛利率从30.10%骤降至25.65%，冷板液冷产品毛利率仅10.36%，浸没液冷毛利率也下降13.52个百分点。这反映出行业竞争加剧、产品价格承压以及低毛利项目结构变化。公司以“市场份额为主要销售目标”的战略，可能导致盈利能力持续下滑，陷入“增收不增利”的困境。
