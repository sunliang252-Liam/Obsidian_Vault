# 920556.BJ 深度透视

## 因果逻辑链
- **[营收微增但利润下滑]** -> [净利润下降7.37%]: 公司深化营销体系改革与加大研发投入，导致销售费用（+17.58%）和研发费用（+1.27%）刚性增长，侵蚀了利润空间。
- **[销售费用大幅增长]** -> [净利润承压]: 公司落地全新销售管理制度与激励机制，从严推进销售队伍管理与大客户战略，导致销售费用同比增加415万元，是利润下滑的核心拖累项。
- **[研发投入聚焦微电网+]** -> [长期竞争力构建]: 公司紧扣“微电网+”核心赛道，推进虚拟电厂、智能配电系统等核心技术攻关，研发费用占营收比达9.01%，为未来产品迭代与市场拓展蓄力。
- **[经营活动现金流大幅改善]** -> [现金流质量提升]: 公司采购业务更多采用票据结算，导致购买商品支付的现金减少，经营活动现金流净额同比大增35.03%至4675万元，远高于净利润。
- **[应收账款高企与减值风险]** -> [财务稳健性隐忧]: 期末应收账款账面余额1.35亿元，占营收42.04%，虽较期初下降，但公司基于谨慎性原则补提信用减值损失，导致业绩快报与年报出现15.88%的净利润差异。
- **[核心赛道深耕数据中心]** -> [需求驱动增长]: 公司产品广泛应用于数据中心、通信基站等新基建领域，受益于AIDC（人工智能数据中心）建设浪潮，电力测控产品需求持续增长，支撑营收基本盘。
- **[新设子公司布局海外与光储充]** -> [第二增长曲线探索]: 公司新设深圳雅正通达（海外贸易）和惠州雅达皓航（光储充一体化），旨在拓展海外市场与新能源微电网业务，但短期内对业绩贡献有限。

## 风险警告
**核心风险在于“增收不增利”的困境与应收账款高企的财务压力。** 公司2025年营收仅微增0.61%，但净利润却下滑7.37%，主要源于销售费用和研发费用的刚性增长。这种“以利润换空间”的战略能否在未来转化为有效订单和收入增长，存在较大不确定性。更需警惕的是，公司应收账款账面余额高达1.35亿元，占营收的42%，且因补提坏账导致业绩快报与年报出现15.88%的重大差异，反映出下游客户回款压力与信用风险正在加剧。

**另一重大风险是市场竞争加剧与毛利率下滑的长期隐忧。** 智能电力测控行业技术壁垒相对不高，随着越来越多企业涌入，市场竞争日趋激烈。公司2025年毛利率虽微升至32.04%，但仍远低于2023年的34.80%。若公司不能持续保持技术领先或有效控制成本，毛利率存在进一步下滑风险。此外，公司实际控制人持股比例仅26.32%，股权结构较为分散，存在控制权转移的潜在风险，可能影响公司经营稳定性。
