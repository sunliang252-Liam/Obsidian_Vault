# 920056.BJ 深度透视

## 因果逻辑链
- **[核心产品国产替代]** -> [业绩稳定]: 公司作为相容剂国产化先驱，核心产品技术指标对标进口，在改性塑料、线缆等领域替代进口，支撑了营收与利润的稳定，即便在营收微降2.11%时，扣非净利润仅下降0.12%。
- **[下游应用领域拓展]** -> [增长空间]: 公司产品从传统汽车、线缆向光伏、新能源电池、低空经济等高增长领域延伸，为未来增长开辟了新赛道，是公司“成长业务”战略的核心。
- **[北交所上市募资]** -> [资本实力增强]: 2025年成功IPO，募集资金净额约1.02亿元，使总资产增长31.92%，净资产增长41.33%，资产负债率降至11.35%，为公司产能扩张和研发投入提供了坚实的资金基础。
- **[原材料价格波动]** -> [成本控制压力]: 公司主要原材料为PP、PE、POE等化工原料，其价格波动直接影响生产成本和毛利率，是公司面临的首要风险，需通过优化采购和提升产品附加值来对冲。
- **[高强度研发投入]** -> [技术壁垒构建]: 公司持续投入研发（研发费用增长14.03%），聚焦接枝改性、超临界流体等核心技术，并成功开发光伏助交联母粒、固态电池粘结剂等新产品，巩固了“专精特新”小巨人的技术护城河。
- **[客户结构优化]** -> [市场地位巩固]: 公司绑定金发科技、LG化学、巴斯夫等国内外头部客户，并荣获金发科技“优秀供应商”，证明了其产品品质和服务能力，有助于稳定订单并提升品牌溢价。
- **[赣州基地产能扩张]** -> [区域协同效应]: 对赣州子公司增资8000万元，推进产能爬坡，完善了华东、华南的产能布局，降低了物流成本，提升了对华南及中西部市场的本地化服务能力。

## 风险警告
**核心风险在于原材料价格波动与下游需求放缓的双重挤压。** 公司成本结构中直接材料占比极高，PP、PE等大宗化工原料价格受宏观经济和供需影响巨大。若原材料价格持续上涨，而公司无法将成本完全转嫁给下游客户，将直接侵蚀本已不高的毛利率（17.66%）。同时，公司营收已出现小幅下滑（-2.11%），若宏观经济下行导致改性塑料、汽车等传统下游需求进一步萎缩，公司业绩将面临更大压力。

**其次，应收账款信用风险不容忽视。** 公司应收账款账面价值高达1.07亿元，占总资产17.75%。尽管客户多为行业龙头，但若部分客户经营状况恶化或付款能力下降，可能导致坏账风险，对公司现金流和利润造成冲击。此外，公司研发投入虽高，但新产品（如固态电池粘结剂）从研发到产业化存在不确定性，若技术路线或市场推广不及预期，将影响公司长期增长潜力。
