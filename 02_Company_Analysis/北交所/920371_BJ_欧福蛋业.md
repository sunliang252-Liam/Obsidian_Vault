# 920371.BJ 深度透视

## 因果逻辑链
- **[原料成本红利]** -> [净利润+89.79%]: 2025年鸡蛋均价同比下跌23.06%，直接材料成本占营收80%，成本下降驱动毛利率从16.56%跃升至23.79%，利润弹性极大释放。
- **[全国产能布局成型]** -> [固定资产+62.26%]: 四川资阳基地投产，形成华东、华南、华北、西南四大区域协同，缩短配送半径，降低物流成本，为未来收入增长奠定产能基础。
- **[高附加值产品突破]** -> [境外收入+66.22%]: 天津溶菌酶产线投产并成功出口，蛋粉出口+133.73%，产品结构从基础蛋液向生物科技延伸，打开第二增长曲线。
- **[行业标准制定者地位]** -> [竞争壁垒加固]: 作为《蛋液质量通则》《蛋粉质量通则》第一起草人，新国标全面落地加速中小产能出清，龙头市占率有望持续提升。
- **[下游需求结构升级]** -> [B端+C端双轮驱动]: 烘焙/餐饮连锁化驱动B端需求稳定增长，小包装蛋液、即饮蛋白饮料等C端产品快速起量，打开家庭消费增量空间。
- **[应收账款管控有效]** -> [信用减值损失-89.14%]: 加强回款管理，经营现金流净额+67.56%至1.2亿元，盈利质量显著改善，财务结构更加健康。
- **[规模化养殖趋势]** -> [原料供应稳定性增强]: 规模化养殖场产能占比提升至48%以上，平滑蛋价周期波动，行业盈利稳定性持续增强，公司抗风险能力提升。

## 风险警告
**核心风险：原料价格剧烈波动的周期性冲击。** 鸡蛋成本占比约80%，2025年受益于蛋价低位运行，毛利率大幅提升。但蛋鸡养殖具有3-4年周期，若2026年进入蛋价上行周期，公司毛利率将面临显著压缩。尽管公司通过议价能力部分传导成本，但短期盈利波动仍难以完全对冲。

**次要风险：行业竞争加剧与产能消化不确定性。** 正大集团等头部企业加速布局蛋品加工，区域性中小企业以低价抢占中低端市场。公司四川基地刚投产，产能利用率爬坡存在不确定性；同时，C端品牌化运营尚处早期，若市场拓展不及预期，新增产能可能面临闲置风险。

**公司简介（F10 原文）**

> 苏州欧福蛋业股份有限公司源自北欧丹麦,是享誉全球80余载的鸡蛋制品供应商。欧福蛋业于2023年登陆北交所,成为中国“蛋品第一股”。欧福蛋业的主要产品品类包括巴氏杀菌蛋液、蛋粉、预制蛋品、功能性蛋品及非笼养鸡蛋、鸡蛋蛋白饮料等。欧福蛋业作为第一起草人参与了《蛋液质量通则》及《蛋粉质量通则》两项国家标准的制定。欧福蛋业目前在中国已有苏州、广东、天津和四川四家生产基地,实现“东、北、南、西”布局。未来,欧福蛋业将持续用自身积累的优势不断致力于为广大客户及消费者提供更安全、更优质、价格更有竞争力的鸡蛋制品。这不仅是欧福。蛋业不变的初心,更是我们持续前行的动力。
