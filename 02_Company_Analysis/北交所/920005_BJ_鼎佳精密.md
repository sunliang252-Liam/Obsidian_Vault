# 920005.BJ 深度透视

## 因果逻辑链
- **[下游消费电子品牌集中度高]** -> [客户高度集中]: 前五大客户（仁宝、巨腾、和硕、台达、神基）贡献48.10%营收，公司业绩与核心大客户订单深度绑定。
- **[“以销定产”+直销模式]** -> [高存货周转率]: 存货周转率11.04次，精准匹配客户订单，避免库存积压，运营效率优于行业平均。
- **[功能性产品技术壁垒]** -> [高毛利率]: 功能性产品毛利率34.24%，显著高于防护性产品（18.20%），是公司利润的核心来源。
- **[越南、马鞍山等新基地产能释放]** -> [子公司减亏]: 越南鼎佳、马鞍山鼎佳亏损大幅收窄，海外及新产能布局开始贡献增量，打开成长天花板。
- **[MIM精密结构件业务突破]** -> [飞博特利润高增]: 控股子公司飞博特净利润同比增长57.64%，成功切入智能穿戴及医疗新赛道，成为新增长极。
- **[IPO募资到账]** -> [货币资金暴增]: 货币资金同比+93.45%至4.97亿元，资产负债表大幅优化，为内生增长与外延并购提供充足“弹药”。
- **[人民币汇率波动]** -> [财务费用大幅增加]: 财务费用同比+67.69%，持有的美元资产产生汇兑损失，侵蚀部分利润。

## 风险警告
**客户集中与下游需求波动风险**：公司前五大客户销售占比近半，且终端品牌高度集中于戴尔、惠普、联想等。若主要客户因行业周期、供应链调整或竞争失势而减少采购，公司业绩将面临剧烈波动。2025年营收增速已放缓至10.67%，净利润几乎零增长，显示增长动能边际减弱。

**汇率与应收账款双重挤压**：外销占比约44%，以美元结算，人民币汇率波动直接冲击利润表。同时，应收账款占营收比例高企（约48%），且2025年信用减值损失同比暴增179.30%，表明部分客户回款出现恶化。若海外经济下行或客户信用风险暴露，坏账风险将显著放大，进一步压缩本已承压的利润空间。
