## 因果逻辑链
- **[负极材料销量增长37.45%]** -> [营收增长19.29%]: 负极材料销量超60万吨，带动负极材料收入同比增长26.40%，是营收增长的核心引擎。
- **[在建工程转固与产能扩张]** -> [固定资产增长26.65%，财务费用激增253.55%]: 印尼二期、国内技改等项目投产，固定资产增至150.5亿，同时利息资本化减少，费用化利息及汇兑损失增加。
- **[原材料成本与产品价格压力]** -> [毛利率下降2.3个百分点]: 负极材料成本增速(34.38%)快于收入增速(26.40%)，导致负极材料毛利率下降4.55个百分点，拖累整体毛利率。
- **[存货备货增加]** -> [经营活动现金流净额下降63.80%]: 为保障供应，存货增加47.59%至49.4亿，支付采购货款增加，导致经营现金流仅4.54亿，远低于净利润。
- **[海外基地投产与布局]** -> [海外收入与资产占比提升]: 印尼基地贡献20.1亿收入及3.1亿净利润，摩洛哥项目推进，海外资产占净资产12.68%，成为新增长极。
- **[固态电池材料技术突破]** -> [抢占下一代电池技术先机]: 发布固态电池整体解决方案，氧化物电解质获百吨级订单，CVD硅碳实现批量供应，构建技术壁垒。
- **[非经常性损益波动]** -> [归母净利润下降5.93%]: 扣非净利润下降24.93%，主要因公允价值变动收益(1.5亿)和政府补助(1.7亿)等非经常性损益贡献了1.9亿利润，掩盖了主业盈利下滑。
- **[SK on与亿纬锂能深度绑定]** -> [大客户集中度提升]: 前两大客户SK on(关联方)和亿纬锂能合计销售占比36.13%，形成强绑定但也带来单一客户依赖风险。

## 风险警告
**盈利质量与现金流严重背离是核心风险。** 公司营收增长19%，但扣非净利润同比下滑25%，且经营活动现金流净额骤降64%至4.5亿元，远低于8.75亿元的归母净利润。存货激增48%至49.4亿，应收账款增长12%至46.7亿，表明公司为抢占市场份额，在行业价格战背景下，大量垫资备货并给予客户信用期，盈利的现金转化效率极低，存在坏账与存货跌价风险。

**行业竞争加剧与原材料价格波动双重挤压利润。** 负极材料毛利率已下降4.55个百分点至23.21%，正极材料毛利率仅10.46%。随着人造石墨一体化产能大规模释放，行业产能过剩风险加剧，产品价格仍有下行压力。同时，焦类、锂盐等原材料价格波动剧烈，若成本无法有效传导，公司盈利能力将持续承压。此外，董事长贺雪琴因内幕交易被证监会行政处罚，对管理层信誉构成负面影响。
