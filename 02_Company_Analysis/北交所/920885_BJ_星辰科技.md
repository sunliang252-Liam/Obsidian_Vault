# 920885.BJ 深度透视

## 因果逻辑链
- **[新能源风电业务爆发]** -> [营收增长34.26%]: 依托“双碳”政策红利，风电变桨伺服系统凭借成本与性能优势，市场份额快速扩张，新能源板块收入同比大增112.38%，成为业绩核心引擎。
- **[长期应收账款回款]** -> [信用减值损失大幅转回]: 专项团队推进回款，多家长期未结清客户货款到账，信用减值损失从-712.8万元转为+473.9万元，直接增厚利润。
- **[规模效应与成本管控]** -> [净利润增长110.82%]: 营收增长摊薄固定成本，期间费用未同步攀升，叠加信用减值损失转回和存货跌价准备减少，盈利能力显著提升。
- **[产品配套层级升级]** -> [军工业务平稳增长]: 从“部件级”向“总成级”转型，提升产品附加值，在国防预算稳定增长背景下，军工板块收入同比增长7.64%。
- **[全资控股深圳星辰]** -> [少数股东损益归零]: 收购子公司剩余股权，实现100%控股，整合资源并消除少数股东损益，提升归母净利润。
- **[股权激励费用摊销]** -> [短期利润承压]: 2025年限制性股票激励计划需摊销383万元费用，虽计入成本但长期绑定核心团队，2025年扣除股份支付影响后净利润增长134.65%。

## 风险警告
**核心风险在于军工业务波动与应收账款质量。** 公司军工客户采购具有强计划性，受国防政策与订单节奏影响，存在订单延迟或取消导致业绩剧烈波动的风险。同时，应收账款余额高达1.75亿元，占总资产28.79%，尽管本期回款改善，但长账龄款项的回收仍具不确定性，一旦宏观环境或客户信用恶化，将再次引发大额减值。

**新能源业务的高增长可持续性存疑。** 风电变桨市场竞争激烈，公司业绩爆发部分源于成本优化和份额扩张，但行业价格战风险犹存。若未来风电装机增速放缓或竞争对手推出更具性价比方案，公司新能源板块的高增长态势可能难以维系，毛利率面临下行压力。
