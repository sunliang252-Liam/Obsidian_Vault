# 920946.BJ 深度透视

## 因果逻辑链
- **[海外注册与认证突破]** -> [外销收入增长9.34%]: 丙硫氧嘧啶获欧盟CEP、利托那韦获国内上市批准、巴西ANVISA审计通过，直接拉动原料药出口订单执行额首破千万美元。
- **[产品结构优化（原料药占比>50%）]** -> [毛利率提升至46.60%]: 高毛利原料药收入占比稳定，叠加医药中间体、含氧杂环类毛利率同步增长，带动整体毛利率同比提升3.02个百分点。
- **[降本增效与精细化管理]** -> [扣非净利润增长9.56%]: 在营收仅增2.87%背景下，通过优化工艺、降低能耗、控制费用，实现利润增速显著高于收入增速。
- **[募投项目投产与新品放量]** -> [利托那韦原料药获批]: 年产40吨利托那韦项目建成转固并获CDE审评通过，为未来贡献增量收入。
- **[汇率波动与利息收入减少]** -> [财务费用同比增加51.12%]: 美元汇率变动导致汇兑损失增加433.70万元，叠加存款利率下降使利息收入减少976.20万元，侵蚀部分利润。
- **[环保处罚与诉讼结案]** -> [营业外支出大幅下降83.19%]: 上期宁夏森萱环保罚款及环境修复损失计提完毕，本期无新增重大处罚，非经常性损益影响减弱。
- **[行业合规壁垒提升]** -> [结构性竞争优势凸显]: 新版药典实施、国际认证要求趋严，公司凭借已有6个欧盟CEP、多个FDA DMF号，在行业洗牌中占据有利位置。

## 风险警告
**核心风险在于国际化进程中的汇率波动与贸易摩擦。** 公司外销收入占比超30%且持续增长，但人民币汇率波动已导致2025年汇兑损失显著增加。同时，中美贸易摩擦、印度PLI计划推动原料药本地化、欧盟《关键药物法案》减少外部依赖，均可能冲击公司海外市场拓展节奏与盈利能力。

**另一重大风险是子公司宁夏森萱的环保合规隐患。** 2025年宁夏森萱因2024年污水倾倒案被判罚金50万元，暴露出子公司层面的环境管理漏洞。公司及多家子公司均为重点排污单位，环保投入持续高企，未来若监管进一步趋严或发生新的环保事故，将带来额外的财务与声誉损失。
