# 920128.BJ 深度透视

## 因果逻辑链
- **[主动优化低盈利订单]** -> [营收与利润双降]: 面对新能源领域激烈价格战，公司主动放弃低毛利率订单，导致销售规模阶段性收缩，营收同比下降13.05%，净利润暴跌61.19%。
- **[铜铝锌锡等原材料涨价]** -> [毛利率承压]: 核心原材料价格普遍上涨，直接推高生产成本，公司毛利率从24.50%降至22.55%，盈利能力被压缩。
- **[家电行业周期波动+贸易政策不确定性]** -> [传统业务收入下滑]: 家电领域作为公司基本盘，受行业周期及国际贸易摩擦影响，收入与盈利面临阶段性压力。
- **[销售费用与财务费用刚性增长]** -> [侵蚀利润]: 销售代理费、职工薪酬及汇兑损失增加，导致销售费用和财务费用分别同比增长17.96%和20.30%，进一步压缩利润空间。
- **[经营活动现金流大幅转负]** -> [短期偿债压力上升]: 因兑付到期银行承兑汇票金额增加，经营性现金流净额从+1139万骤降至-2876万，公司不得不增加短期借款（+37.47%）以补充营运资金。
- **[国产化技术突破]** -> [打开高端市场空间]: 公司“全国产化直流干式电容器”通过南方电网挂网考核，“干式金属化阻尼吸收电容”实现国产化首次应用，为未来在高压柔直等高端领域替代进口奠定基础。
- **[垂直一体化布局]** -> [构建长期成本壁垒]: 公司推进“基膜→金属化薄膜→电容”全链条布局，并收购华佳新材51.02%股权，旨在从源头实现核心原材料自主可控，增强成本韧性与盈利稳定性。

## 风险警告
公司当前面临的核心风险是**业绩断崖式下滑与现金流恶化**。2025年净利润同比暴跌61.19%，经营性现金流由正转负至-2876万元，而短期借款却逆势增长37.47%。这表明公司在主动收缩低效订单的同时，并未能有效控制费用刚性增长，导致盈利能力和财务健康度同步恶化。若原材料价格持续高位或下游需求复苏不及预期，公司可能面临“增收不增利”甚至亏损的风险。

另一个关键风险在于**战略转型的阵痛期**。公司主动放弃新能源领域低毛利订单，并大力押注高压柔直、轨道交通等高端国产化市场，虽然方向正确，但新市场的认证周期长（2年以上）、放量缓慢，短期内难以弥补传统业务下滑带来的缺口。同时，泰国基地二期、新产业园建设及并购整合均需大量资金投入，在现金流紧张的背景下，若融资渠道不畅或项目回报不及预期，将给公司带来沉重的财务负担。
