# 920017.BJ 深度透视

## 因果逻辑链
- **[复方消化酶胶囊中标省际联盟集采]** -> [营收增长]: 集采中标扩大医院终端覆盖，叠加专业化学术推广，推动消化道和代谢类药物收入同比增长24.62%，成为营收核心驱动力。
- **[吡拉西坦注射液中标国采但价格大幅下降]** -> [神经系统药物收入萎缩]: 中标第九批国采后价格大幅下降，叠加被列入重点监控目录，导致该品类收入同比下滑33.24%。
- **[部分产品未中标集采及挂网价格调整]** -> [心血管系统药物收入下降]: 注射用胰激肽原酶等产品因集采失利和价格降低，销量下滑，导致该品类收入同比减少34.03%。
- **[销售费用与管理费用同比下降]** -> [净利润增长]: 在营收基本持平（+0.32%）的情况下，销售费用（-1.56%）和管理费用（-10.06%）的缩减直接增厚了利润，净利润同比增长26.23%。
- **[经营现金流大幅改善]** -> [财务稳健性提升]: 经营活动现金流净额同比增长109.91%至1.74亿元，主要得益于支付其他与经营活动有关的现金减少，增强了公司内生造血能力。
- **[南京盈诺生产基地项目持续投入]** -> [在建工程大幅增加]: 子公司南京盈诺“高端药物制剂研发及生产基地项目”增加投入，导致在建工程同比增长137.79%，为未来产能扩张奠定基础。
- **[多西他赛注射液获FDA批准]** -> [国际化战略突破]: 子公司产品获得美国FDA批准，标志着公司制剂出口能力取得实质性进展，为未来海外市场拓展打开空间。
- **[股权激励行权与分红减少]** -> [筹资活动现金流由负转正]: 报告期内股权激励行权吸收投资款3311.85万元，叠加分红支出同比减少，使筹资活动现金流净额由-4642万元转为1902万元。

## 风险警告
**核心风险在于集采与价格治理的持续冲击。** 公司虽然凭借复方消化酶胶囊集采中标实现了核心品类增长，但神经系统药物（吡拉西坦注射液）和心血管系统药物已因集采价格下降或未中标而出现收入大幅萎缩。随着国家集采扩围和价格治理政策深化，公司其他在售品种面临持续降价压力，仿制药“以价换量”的模式能否持续覆盖成本并维持利润增长存在重大不确定性。公司毛利率已从2023年的74.13%降至2025年的70.02%，未来仍有进一步下滑风险。

**另一重大风险是资产减值与投资损失。** 报告期内，公司对参股公司广东迈德珐的长期股权投资全额计提减值，同时其他权益工具投资（北京崇德英盛创投）因所投企业估值下降产生公允价值变动损失。这暴露了公司对外投资的风险敞口。此外，公司账面仍有3000万元的预计负债（源于2024年冻结资金事项），虽诉讼已胜诉，但资金解冻进度和最终财务影响仍存不确定性。研发投入资本化率为0，全部费用化处理，若未来研发项目失败或商业化不及预期，将持续侵蚀利润。
