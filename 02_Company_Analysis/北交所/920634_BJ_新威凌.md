# 920634.BJ 深度透视

## 因果逻辑链
- **[集装箱行业周期性回落]** -> [营收与利润双降]: 2024年集装箱产量创历史新高，2025年需求阶段性回落，导致公司锌粉销量下降，营收同比-13.16%，净利润同比-36.31%。
- **[“原材料价格+加工费”定价模式]** -> [毛利率承压]: 锌锭价格波动直接影响收入和成本，叠加拓展大客户时加工费较低，毛利率从8.34%微降至7.91%。
- **[股权激励费用大幅增加]** -> [侵蚀净利润]: 2025年确认股份支付金额较上年大幅增加，是净利润降幅（-36.31%）远超营收降幅（-13.16%）的核心原因之一。
- **[停止片状锌粉受托加工业务]** -> [利润来源减少]: 公司战略调整，2025年初停止该业务，导致受托加工利润消失，进一步拖累整体盈利。
- **[下游需求结构分化]** -> [业绩依赖单一赛道]: 营收高度依赖集装箱涂料行业（2024年贡献主要增量），其他应用领域（风电、船舶、化工）收入持平，未能对冲集装箱周期下行风险。
- **[经营性现金流为负]** -> [营运资金压力增大]: 经营性现金流净额-6505万元，远低于净利润，主因是上下游结算账期错配（上游现结、下游账期长），导致应收项目大幅增加。
- **[锌锭价格波动]** -> [公允价值变动收益波动]: 采用延迟定价结算，锌价波动导致跨期订单的公允价值变动收益达169万元，成为非经常性损益的重要来源，增加了利润的不可预测性。
- **[片状锌粉国产替代战略]** -> [第二增长曲线尚在培育]: 公司正推进高端片状锌粉国产化，以打破国外垄断，但该业务目前体量小（营收占比1.68%），短期内难以成为业绩支柱。

## 风险警告
公司面临高度集中的下游周期风险。2024年业绩爆发式增长主要依赖集装箱行业的异常繁荣，2025年该行业需求回落直接导致营收和利润双降。公司其他应用领域（风电、船舶、化工）增长乏力，未能形成有效对冲，业绩波动性极大。若集装箱行业景气度无法在2026年恢复，公司营收和利润可能继续承压。

盈利质量与现金流严重背离是另一核心风险。尽管公司账面盈利，但经营活动现金流净额为负，主因是上游采购需现结，下游客户回款周期长，导致营运资金持续被占用。这种“纸面富贵”的商业模式，在收入下滑周期中，可能加剧公司的流动性压力，并限制其进行产能扩张和研发投入的能力。

**公司简介（F10 原文）**

> 湖南新威凌金属新材料科技股份有限公司(股票简称“新威凌”,股票代码920634)成立于2002年11月,是一家专业化从事球状锌粉、片状锌粉等锌基新材料产品的研发、生产、销售的企业。公司于2017年6月在全国中小企业股份转让系统(新三板)成功挂牌,于2022年11月24日在北京证券交易所成功上市,成为北交所锌粉第一股。公司旗下拥有三大生产基地——湖南新威凌新材料有限公司、四川新威凌金属新材料有限公司、新威凌金属新材料(南通)有限公司。湖南生产基地年生产能力为2.55万吨,四川生产基地年生产能力为3.2万吨,江苏生产基地的年生产能力为2.5万吨(在建),总产能将为8.25万吨/年(含在建)。公司主营产品中的球状锌粉广泛应用于富锌防腐涂料、粉末镀锌、化工、医药、有色冶金、摩擦材料、粉末冶金等领域,片状锌粉主要应用于储能储氢配套行业、军工配件行业及达克罗涂层行业等领域。新威凌始终将卓越的研发创新能力植根于生产与经营的各个环节之中,拥有了一系列核心技术,参与编制了《GB/T43884—2024钢铁制件的金属覆盖层锌扩散层-渗锌技术要求》国家标准、《HG/T3668-2020富锌底漆》行业标准、《T/CSEA17-2021锌铝涂层涂装安全生产作业规程》行业标准,并获得了“湖南省著名商标”“国家级专精特新‘小巨人’企业(全资子公司湖南新威凌新材料有限公司获得)”“国家高新技术企业(全资子公司湖南新威凌新材料有限公司获得)”“湖南制造业单项冠军产品——锌基料(全资子公司湖南新威凌新材料有限公司获得)”“改革开放四十年中国涂料行业发展贡献企业”等近100项荣誉及资质。
