# 920089.BJ 深度透视

## 因果逻辑链
- **[产品结构升级与原材料成本下降]** -> [毛利率提升2.22个百分点]: 公司主动缩减低毛利通用料，聚焦高性能、高附加值产品，叠加2025年下半年主要原材料价格持续低位，直接推动毛利率从16.27%升至18.49%。
- **[新能源汽车与家电需求增长]** -> [营收增长22.07%]: 下游新能源汽车单车改性塑料用量较燃油车提升35%-40%，叠加家电高端化趋势，公司核心产品改性聚丙烯营收同比增长26.33%。
- **[新工厂产能释放]** -> [区域收入结构优化]: 陕西、湖南等新生产基地产能完全释放，华中、西南、西北地区营收分别增长148.49%、146.39%、77.19%，有效覆盖全国市场，降低对单一区域的依赖。
- **[研发投入持续加大]** -> [产品议价能力增强]: 研发费用同比增长24.22%至8488万元，聚焦低VOC、轻量化、生物基等方向，技术溢价使客户粘性提升，直接支撑营收与利润双增长。
- **[客户结构优化]** -> [订单稳定性与回款质量改善]: 核心大客户营收贡献占比持续提高，前五大客户销售占比达40.62%，战略合作深度加深，降低了订单波动与坏账风险。
- **[精益生产与供应链管控]** -> [成本效率提升]: 通过自动化产线、智能管理系统及多渠道采购体系，在营收增长22.07%的同时，营业成本仅增长18.84%，实现降本增效。
- **[海外市场拓展]** -> [外销高增长]: 设立新加坡及泰国子公司，外销收入同比增长45.92%，毛利率高达34.68%，成为新的利润增长点。

## 风险警告
**首要风险是应收账款与信用减值急剧恶化。** 2025年信用减值损失高达1911万元，同比暴增171.88%，主要因部分客户（如长沙市银宝山新、江苏科博车业）单项计提坏账。应收账款账面余额达9.38亿元，占总资产40.37%，且周转率仅2.19次，回款周期长。若下游汽车、家电行业景气度下行或客户资金链断裂，大规模坏账将直接侵蚀利润，甚至引发现金流危机。

**其次，经营现金流持续为负且缺口扩大。** 2025年经营活动现金流净额为-1.44亿元，较上年-1.17亿元进一步恶化，已连续三年为负。尽管净利润增长37.52%，但利润质量堪忧，主要因应收账款和存货占用大量资金。公司依赖银行借款和票据贴现维持运营，短期借款同比激增64.12%至1.88亿元，财务杠杆快速上升，若融资环境收紧，流动性风险将显著暴露。
