# 920002.BJ 深度透视

## 因果逻辑链
- **[叉车行业景气度提升]** -> [营收稳健增长]: 2025年国内叉车销量同比+12.9%，公司作为核心配套商，营收增长2.16%至3.53亿元。
- **[政府补助与理财收益增厚]** -> [净利润增速远超营收]: 其他收益同比+89.26%（政府补助418万），投资收益+35.89%，共同推动净利润增长8.87%至6268万元。
- **[原材料成本控制与产品结构优化]** -> [毛利率微升]: 钢材等直接材料占比68.41%，通过低位采购与调价机制，毛利率从32.55%提升至32.68%。
- **[高附加值回转支承放量]** -> [产品结构改善]: 回转支承营收同比+16.47%，毛利率高达46.63%，显著高于叉车轴承的32.19%，成为利润增长新引擎。
- **[客户高度集中]** -> [经营稳定性与风险并存]: 前五大客户（杭叉、合力、中力等）销售占比51.97%，深度绑定龙头带来稳定订单，但单一市场依赖度高。
- **[研发投入聚焦新赛道]** -> [打开成长天花板]: 研发费用同比+5.99%，重点布局机器人减速器轴承、新能源汽车电驱桥轴承，为切入高增长领域储备技术。
- **[现金流强劲]** -> [财务健康度高]: 经营活动现金流净额6924万元，同比+23.18%，远超净利润，且资产负债率仅9.86%，几乎无有息负债。

## 风险警告
**核心风险在于成长天花板与客户集中度。** 公司主营叉车轴承，属于轴承行业的细分小品类，市场规模有限。尽管在叉车前装市场占据领先地位，但后市场渗透率低，且前五大客户（杭叉、合力、中力等）销售占比超50%，任何主要客户的流失或压价都将对业绩造成重大冲击。公司向工业机器人、新能源汽车等新赛道的拓展尚处于样件研制阶段，短期内难以贡献显著增量，成长性受限。

**原材料价格波动与汇率风险不容忽视。** 钢材等直接材料占主营业务成本近70%，若钢价大幅上涨而产品调价滞后，将直接侵蚀利润。同时，境外收入占比8.53%，2025年财务费用因汇兑损益增加而大幅上升，显示公司对汇率波动较为敏感，外销业务的稳定性面临挑战。
