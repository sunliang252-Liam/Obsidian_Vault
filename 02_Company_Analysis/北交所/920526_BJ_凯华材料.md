# 920526.BJ 深度透视

## 因果逻辑链
- **[市场竞争加剧，产品售价承压]** -> [毛利率下降]: 2025年毛利率从29.55%降至27.80%，主要因下游客户竞争激烈，公司被迫降价保份额。
- **[2024年高额非经常性政府补助消退]** -> [净利润暴跌38.23%]: 2024年计入营业外收入的890万元政府补助在2025年消失，导致归母净利润从2332万骤降至1441万。
- **[募投项目大规模建设投入]** -> [在建工程激增63.47%]: 募投项目“电子专用材料生产基地”投入8058万元，导致货币资金减少34.57%，在建工程占总资产比例升至30.83%。
- **[环氧粉末包封料收入占比超95%]** -> [业务结构高度集中]: 环氧粉末包封料收入1.09亿元，占总营收95.1%，而环氧塑封料虽增长81.26%但绝对规模仅425万元，新增长点尚未形成。
- **[原材料价格波动与成本传导滞后]** -> [毛利率承压]: 直接材料占主营业务成本比例高，2025年营业成本增速（2.17%）超过营收增速（-0.29%），成本压力未能及时向下游传导。
- **[研发投入聚焦高附加值产品]** -> [未来增长储备]: 研发费用605万元（占营收5.28%），重点开发高温循安规电容包封料、高导热塑封料等，旨在拓展新能源、车规等高增长领域。
- **[募投项目延期至2026年9月]** -> [短期产能扩张受限]: 募投项目原计划2025年投产，现延期至2026年9月，期间公司产能利用率（86.87%）已接近饱和，制约短期营收增长。

## 风险警告
**核心风险在于业绩增长的双重瓶颈。** 一方面，公司核心产品环氧粉末包封料收入占比超95%，且所处细分市场空间偏小，竞争加剧导致毛利率持续下滑（从2023年30.23%降至2025年27.80%）。另一方面，被寄予厚望的环氧塑封料业务规模极小（仅425万元），且产能利用率仅25.70%，短期内难以成为第二增长曲线。募投项目延期至2026年9月，进一步推迟了产能释放和业绩改善的时间窗口。

**财务风险不容忽视。** 净利润暴跌38.23%并非完全由经营恶化导致，但剔除2024年890万元一次性政府补助后，扣非净利润仍下降9.51%，显示主营业务盈利能力确实在走弱。同时，募投项目大规模投入（在建工程8058万元）导致货币资金锐减34.57%，且项目投产后将带来固定资产折旧大幅增加，若市场需求不及预期，存在“增收不增利”甚至拖累整体盈利的风险。此外，公司实际控制人持股68.54%，股权高度集中，治理风险需持续关注。
