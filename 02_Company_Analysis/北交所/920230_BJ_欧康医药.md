# 920230.BJ 深度透视

## 因果逻辑链
- **[募投项目转固，折旧大幅增加]** -> [净利润暴跌48.79%]: 2025年新产线折旧费用增加1024万元，直接侵蚀利润，是利润下滑的核心原因。
- **[新产线投产初期，工艺磨合导致成本高企]** -> [毛利率下降至16.42%]: 新设备与工艺尚在优化，产品收率受影响，叠加调试费用，导致单位成本上升，拉低整体毛利。
- **[国际贸易环境恶化，行业竞争加剧]** -> [核心产品被迫降价]: 为稳固市场份额，对槲皮素等核心产品降价，且售价降幅大于原料成本降幅，进一步压缩利润空间。
- **[股权激励与研发折旧等期间费用增加]** -> [净利润进一步承压]: 2025年全年摊销股份支付费用同比增加198万元，管理及研发折旧费用同比增加240万元，直接减少净利润。
- **[综合系列（黄连素）新客户开发成功]** -> [收入结构性增长]: 黄连素销量同比暴增173.95%，带动综合系列收入同比上升134.74%，部分对冲了槐米、枳实系列的营收下滑。
- **[内销业务拓展，地奥司明原料药放量]** -> [内销收入逆势增长8.21%]: 地奥司明原料药国内销售增加，叠加黄连素内销增长，使内销业务成为收入增长的主要驱动力。
- **[募投项目产业链延伸，实现原料自给]** -> [提升供应链稳定性与成本控制能力]: 公司向上游延伸，直接采购柚果、槐米等农产品，构建从原料到高附加值产品的一体化产业链，降低外部依赖。

## 风险警告
**核心风险在于“增收不增利”的困境加剧。** 公司营收仅微增6.92%，但净利润却腰斩。根本原因是募投项目投产带来的巨额折旧与产能爬坡期的低效成本，叠加行业价格战，导致毛利率大幅下滑。若新产线无法快速实现满产满销、产品收率无法提升，折旧压力将持续压制利润，公司可能陷入“越生产越亏损”的陷阱。

**第二大风险是国际贸易环境与市场竞争的持续恶化。** 公司外销占比依然较高，且核心产品槲皮素面临巴西芸香豆路线的替代威胁。在行业集中度提升、价格战激烈的背景下，公司为保住市场份额而被动降价，但原材料成本下降幅度有限，导致盈利空间被严重挤压。若未来贸易摩擦加剧或新兴市场开拓不及预期，公司业绩存在进一步下滑的风险。
