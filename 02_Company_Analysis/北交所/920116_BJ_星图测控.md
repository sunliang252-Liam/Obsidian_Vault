# 920116.BJ 深度透视

## 因果逻辑链
- **[商业航天市场爆发]** -> [商业航天收入占比提升至39.06%]: 低轨星座加速组网（GW/千帆）直接拉动公司测运控服务需求，商业航天收入同比增长62.2%，成为增长主引擎。
- **[特种航天领域深耕]** -> [特种航天收入占比60.94%]: 依托中科院背景与洞察者产品，深度绑定特种客户，实现从“需求响应”向“需求引领”转型，夯实基本盘。
- **[政府补助与税收优惠]** -> [扣非净利润仅增5.92%]: 2025年非经常性损益高达3695万元（政府补助4091万+重点软件企业10%税率），掩盖了核心业务盈利能力增速放缓的现实。
- **[存货与在建工程激增]** -> [资产结构向“重”转型]: 存货增156%（储备项目投入）、在建工程增58%（测控站网建设），表明公司正从纯软件向“软件+硬件基础设施”模式扩张，资本开支压力加大。
- **[应收账款周转率下降]** -> [现金流压力持续]: 应收账款周转率从1.19降至1.10，尽管信用减值损失减少，但经营现金流仅1.23亿，与1.01亿净利润不匹配，回款周期长是行业通病。
- **[研发投入资本化]** -> [利润质量被稀释]: 研发费用增长24.75%，且首次出现297.7万元资本化（占比5.61%），若剔除资本化影响，实际研发投入对利润的侵蚀更大。
- **[子公司业绩分化]** -> [集团化运营初见成效]: 中科洞察（净利润1177万，+4167%）和中科天通（净利润603万，+107.6%）成为新增长极，但新设子公司仍处亏损状态。

## 风险警告
**核心风险在于“增收不增利”与“现金流陷阱”。** 公司2025年营收增长11.41%，但扣非净利润仅增长5.92%，增速显著落后。利润增长高度依赖政府补助（4091万）和重点软件企业10%的所得税优惠（正常税率25%），一旦政策红利消退，业绩将面临巨大压力。同时，应收账款周转率持续下降（1.10），经营现金流净额仅1.23亿，远低于净利润1.01亿，表明大量利润沉淀在应收账款和存货中，实际现金回收能力堪忧。

**战略扩张带来的资产“由轻转重”风险不容忽视。** 公司正大规模投资测控站网建设（在建工程+58%）、购置土地和设备（固定资产+1241%），存货因项目储备激增156%。这种从纯软件向“软件+硬件+基建”的转型，将大幅增加折旧摊销和资金占用，若下游商业航天客户（如星座运营商）出现资金链问题或发射计划延迟，公司可能面临资产减值与流动性双重压力。此外，研发投入首次资本化（297.7万），存在平滑利润的嫌疑，需警惕后续研发资本化比例提升对利润质量的稀释。
