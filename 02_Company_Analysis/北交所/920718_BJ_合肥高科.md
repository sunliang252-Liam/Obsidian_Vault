# 920718.BJ 深度透视

## 因果逻辑链
- **[下游家电行业竞争加剧]** -> [毛利率下降2.4个百分点]: 2025年家电以旧换新政策拉动力度减弱，行业零售规模同比下滑4.3%，公司被迫降价保份额，导致盈利能力承压。
- **[募投项目投产但未达产]** -> [折旧摊销等成本费用增加]: 家电结构件及精密制造生产基地等项目进入爬坡阶段，固定资产同比大增78.86%，但产能利用率不足，刚性成本侵蚀利润。
- **[先进制造业增值税加计抵减减少]** -> [其他收益同比减少697万元]: 政策红利退坡直接削减利润，是净利润下滑48.83%的重要推手之一。
- **[对海尔集团单一客户依赖度高达75.05%]** -> [经营风险高度集中]: 海尔同时是第一大客户和第一大供应商，公司议价能力弱，业绩随海尔采购节奏波动，且存在客户与供应商重合的潜在利益冲突。
- **[装饰面板业务收入骤降38.19%]** -> [核心产品结构恶化]: 下游客户订单量减少，该高毛利业务萎缩，拖累整体毛利率和收入规模。
- **[子公司安徽嘉荣、安徽道金大幅亏损]** -> [新业务拖累整体业绩]: 募投项目相关子公司尚处爬坡期或市场开发阶段，合计亏损超1200万元，成为利润黑洞。
- **[应收账款与应收票据合计占流动资产47.28%]** -> [现金流压力与坏账风险并存]: 尽管经营性现金流净额增长20%，但大量收入以票据形式存在，实际回款质量存疑，且客户信用风险可能集中爆发。

## 风险警告
**核心风险在于对海尔集团的极端依赖与下游家电行业景气度下行形成的双重挤压。** 公司75%的收入来自海尔，且海尔同时是最大供应商，这种“既当裁判又当运动员”的关系使公司在定价、结算周期上处于弱势。当家电行业整体承压时，海尔必然优先压缩供应商利润，公司毛利率从13.52%骤降至10.07%即为明证。一旦海尔调整采购策略或引入新供应商，公司业绩将面临断崖式下跌。

**募投项目产能爬坡不及预期，正从增长引擎变为利润拖累。** 固定资产同比暴增78.86%，但收入反而下降4.54%，说明新增产能未能有效转化为销售。子公司安徽嘉荣、安徽道金合计亏损超1200万元，且安徽道金至今零收入。若2026年仍无法实现规模化出货，这些资产的折旧摊销将持续侵蚀利润，甚至引发资产减值风险。公司试图向新能源、服务器滑轨等新领域拓展，但尚处小批试制阶段，短期内难以形成有效替代。
