# 920249.BJ 深度透视

## 因果逻辑链
- **[物联网模组及系统解决方案业务高增]** -> [营收增长24.18%]: 公司多年研发投入形成技术壁垒，5G RedCap、Cat.1、LoRa等核心模组产品竞争力提升，带动该板块收入同比大增45.79%，成为业绩反转核心引擎。
- **[IC增值分销业务回暖]** -> [营收增长16.38%]: 国内芯片市场逐步回暖，公司去库存、拓渠道措施见效，叠加AI、汽车电子等下游需求拉动，分销业务恢复增长。
- **[毛利率提升]** -> [净利润扭亏为盈]: 整体毛利率从14.56%提升至16.28%，其中高毛利的物联网模组业务占比提升，叠加IC分销毛利率微增，共同推动盈利改善。
- **[处置灵朔科技部分股权]** -> [非经常性收益增厚利润]: 公司溢价转让参股公司灵朔科技10.53%股权，获得约1,562万元资产处置收益，是净利润扭亏的重要非经常性因素。
- **[存货减值损失大幅减少]** -> [利润改善]: 公司加强库存管理，存货跌价准备计提同比减少59.95%，从5,066万元降至2,029万元，显著减轻利润压力。
- **[应收账款激增]** -> [信用减值损失扩大]: 营收增长带动应收账款同比增加27.84%至7.47亿元，导致信用减值损失同比增加1,433%，反映回款压力加大。
- **[经营活动现金流显著改善]** -> [财务健康度提升]: 销售回款增加，经营现金流净额从5,758万元大幅提升至1.32亿元，为后续研发投入和业务扩张提供资金保障。

## 风险警告
**核心风险在于监管不确定性。** 公司于2026年3月因涉嫌信息披露违法违规被证监会立案调查，审计报告因此被出具带强调事项段的无保留意见。截至年报披露日，调查尚未有结论，若最终被认定违规，可能面临行政处罚、投资者索赔等重大不利影响，对公司声誉和融资能力构成直接冲击。

**财务风险集中于高应收账款和高存货。** 应收账款占总资产37.28%，且增速远超营收，坏账风险随信用减值损失扩大而上升。存货虽有所下降但仍占总资产26.97%，电子元器件价格波动快、生命周期短，若下游需求或技术路线变化，可能引发新一轮大规模减值。此外，公司资产负债率高达61.71%，短期借款超4亿元，偿债压力不容忽视。
