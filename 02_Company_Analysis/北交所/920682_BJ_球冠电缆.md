# 920682.BJ 深度透视

## 因果逻辑链
- **[铜价大幅上涨 + 行业竞争加剧]** -> [毛利率下降]: 原材料成本占比超80%，铜价上涨直接推高营业成本，而中标价格因竞争难以同步提升，导致毛利率从10.86%降至10.30%。
- **[增值税加计抵减政策红利消退]** -> [其他收益锐减]: 2025年其他收益同比减少33.10%，主要系进项税加计抵减金额减少995.60万元，直接侵蚀利润。
- **[“两网”市场中标创新高]** -> [营收稳健增长]: 国家电网、南方电网集中招标中标28.52亿元创历史新高，驱动全年营收同比增长6.35%至38.12亿元。
- **[销售回款账期延长]** -> [经营现金流恶化]: 营收增长但回款滞后，导致经营活动现金流净额由正转负，从+3,418万元骤降至-2,778万元。
- **[应收账款高企 + 质保金账龄拉长]** -> [资产减值损失激增]: 应收账款占总资产51.36%，长账龄质保金增加导致资产减值损失同比暴增1,399%。
- **[“料重工轻”商业模式]** -> [利润对铜价高度敏感]: 铜材占成本80%以上，公司虽采用远期合约锁定成本，但铜价大幅波动仍导致成本管理难度剧增，利润弹性远大于收入弹性。
- **[行业集中度提升趋势]** -> [头部企业受益]: 政策监管趋严、技术升级压力下，低端产能出清，公司作为行业排名第26位的头部企业，在“两网”招标中份额持续扩大。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长6.35%，但净利润却暴跌27.31%，主因是铜价上涨与行业“内卷”导致毛利率下滑，叠加增值税政策红利消退。这种成本端与收入端的双重挤压，若铜价持续高位或行业竞争进一步加剧，公司盈利能力可能继续承压。

**现金流与资产质量风险不容忽视。** 经营现金流由正转负至-2,778万元，应收账款占总资产比例超51%，且账龄结构恶化导致坏账准备激增。公司高度依赖银行借款维持运营（短期借款+一年内到期非流动负债合计超11.9亿元），若回款持续不畅，财务费用上升与流动性压力将形成恶性循环。
