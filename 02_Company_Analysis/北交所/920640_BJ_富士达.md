# 920640.BJ 深度透视

## 因果逻辑链
- **[防务与民用市场协同拓展]** -> [营收增长15.51%]: 公司强化防务与民用市场协同，积极开拓新业务新场景，推动市场增量与战略合作深度融合，整体收入实现增长。
- **[射频同轴电缆组件销量爆发]** -> [营收结构优化]: 电缆组件收入同比增长53.11%，成为最大收入来源（占比54.3%），弥补了连接器收入下滑的影响。
- **[高毛利连接器占比下降]** -> [毛利率提升受限]: 射频同轴连接器收入下降10.89%，但其毛利率高达37.01%，其占比下降导致整体毛利率仅微增0.73个百分点至33.43%。
- **[客户集中度极高]** -> [经营风险集中]: 前五大客户营收占比达74.31%，其中关联方客户C占比10.82%，大客户订单波动将直接导致业绩大幅下滑。
- **[应收账款高企与减值激增]** -> [利润侵蚀]: 应收账款净额达6.62亿元（占总资产41.52%），信用减值损失同比增加38.79%至3247万元，严重侵蚀利润。
- **[经营性现金流大幅下降]** -> [资金链压力]: 经营活动现金流净额同比下降38.30%至6653万元，远低于净利润8800万元，主要因支付供应商货款增加，存在“纸面利润”风险。
- **[HTCC产线建成]** -> [新增长极培育]: 高温共烧陶瓷（HTCC）生产线已进入小批量生产阶段，累计投入3007万元，预计收益8550万元，为公司开辟了先进陶瓷新赛道。
- **[研发投入聚焦高频化与集成化]** -> [技术壁垒构建]: 研发费用8103万元（占营收9.20%），重点攻关毫米波、低轨卫星、HTCC等前沿技术，巩固IEC国际标准制定者地位。

## 风险警告
**客户集中与应收账款双杀风险。** 公司前五大客户营收占比高达74.31%，对华为、RFS及关联方客户C依赖极重。同时，应收账款净额高达6.62亿元，占总资产41.52%，且信用减值损失同比暴增38.79%。一旦大客户订单减少或付款周期延长，公司将面临营收下滑与坏账激增的双重打击，利润可能急剧萎缩。

**现金流恶化与盈利质量隐忧。** 2025年净利润同比增长49.12%至8800万元，但经营性现金流净额却同比下降38.30%至6653万元，两者严重背离。公司为维持增长大量垫付采购款，导致“纸面富贵”。若现金流持续恶化，可能引发营运资金短缺，甚至影响正常生产经营与偿债能力。
