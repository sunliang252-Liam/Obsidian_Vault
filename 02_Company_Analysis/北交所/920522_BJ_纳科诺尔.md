# 920522.BJ 深度透视

## 因果逻辑链
- **[行业产能短期供过于求]** -> [营收下降7.14%]: 下游电池企业扩产放缓，设备需求及验收节奏承压，导致公司2025年营业收入同比下滑。
- **[营收下降叠加费用刚性增长]** -> [净利润暴跌59.27%]: 收入减少的同时，销售费用（+62.76%）和研发费用（+136.08%）大幅增加，严重侵蚀利润。
- **[下游客户扩产节奏放缓]** -> [存货高企至12.4亿元，占总资产50%]: 以销定产模式下，客户验收延迟导致发出商品和产成品积压，资金占用严重。
- **[存货与应收账款规模庞大]** -> [资产减值损失达3239万元]: 对积压存货和长账龄应收账款计提大额减值，是利润下滑的另一核心因素。
- **[海外市场拓展初期]** -> [境外收入骤降79.64%]: 部分出口产品尚未完成验收，海外收入确认存在较大不确定性，全球化战略尚未贡献实质利润。
- **[固态电池设备研发投入加大]** -> [研发费用激增136%]: 公司战略性押注固态电池、干法电极等下一代技术，导致当期研发费用大幅攀升，但商业化尚需时日。
- **[客户集中度高]** -> [经营依赖头部客户]: 前五大客户销售占比60.45%，公司业绩高度依赖宁德时代、比亚迪等少数核心客户的资本开支节奏。

## 风险警告
**核心风险在于行业周期与公司扩张节奏的错配。** 2025年锂电池行业产能过剩，下游客户资本开支收缩，直接导致公司营收下滑。然而，公司为抢占固态电池等未来市场，逆势大幅增加研发和销售投入，叠加存货和应收账款减值，导致净利润暴跌近60%。这种“增收不增利”乃至“减收更减利”的局面，暴露了公司在行业下行期成本刚性、资产周转效率低下的脆弱性。

**存货与应收账款的双重积压是悬在头上的达摩克利斯之剑。** 存货占总资产比重超过50%，且周转率极低（0.66次），一旦下游需求持续低迷或技术路线变更，将面临巨额跌价风险。同时，应收账款规模庞大且账龄可能拉长，信用减值损失已由正转负，未来坏账风险不容忽视。公司经营活动现金流虽为正，但远不足以覆盖如此庞大的营运资金占用，财务健康度面临严峻考验。
