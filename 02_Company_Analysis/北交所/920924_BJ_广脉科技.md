# 920924.BJ 深度透视

## 因果逻辑链
- **[5G新基建与高铁信息化中标金额大幅增长]** -> [在手订单增至8.97亿元]: 全年中标7.44亿元（+37.75%），为未来收入转化奠定基础，但当期利润尚未体现。
- **[募投项目“广脉大厦”转固投入使用]** -> [净利润同比下降36.26%]: 新增折旧、贷款利息、房产税及运营费用大幅增加，短期利润承压。
- **[应收账款随收入增长而扩大]** -> [信用减值损失同比增加82.59%]: 收入增长20.2%的同时，应收账款增至3.54亿元，坏账计提压力加大。
- **[算力业务从基建向AI应用延伸]** -> [构建“算力基建+运营+AI应用”生态闭环]: 中标高校AI教学平台，成立广脉智算子公司，布局国产算力，打造第二增长曲线。
- **[高铁项目大量处于实施阶段]** -> [高铁业务收入增速（+3.47%）远低于开工额增速（+69.21%）]: 收入确认滞后于项目投入，导致当期业绩被低估。
- **[资产运营服务计价规则下调]** -> [资产运营服务毛利率下降10.89个百分点]: 通信站址业务受铁塔计价规则影响，收入核减，盈利能力下滑。
- **[ICT行业应用业务恢复性增长]** -> [该业务收入同比大增49.08%]: 上年因政府财政缩减导致基数较低，本期有所恢复。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长20.2%，但净利润却下滑36.26%，主因是广脉大厦转固带来的折旧摊销、利息费用及房产税等刚性成本激增。这种成本结构变化是长期的，若未来收入增速无法覆盖新增成本，盈利能力将持续承压。此外，应收账款高达3.54亿元，占营收73%，且信用减值损失同比大增82.59%，客户回款周期长、坏账风险高，严重侵蚀现金流质量。

**战略转型期的“时间错配”风险突出。** 公司大力押注高铁信息化和算力业务，但这两个板块均存在“投入大、周期长、见效慢”的特点。高铁业务开工额增长69%，但收入仅微增3.47%，大量资金沉淀在存货（+33.24%）和在建项目中。算力业务尚处布局初期，子公司广脉智算已产生亏损。公司资产负债率已升至65.95%，短期借款大增43.8%，若新业务不能如期转化为收入和现金流，财务杠杆风险将显著放大。
