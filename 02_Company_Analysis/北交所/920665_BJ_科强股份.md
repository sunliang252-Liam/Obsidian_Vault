# 920665.BJ 深度透视

## 因果逻辑链
- **[光伏行业产能过剩与价格战]** -> [硅胶板毛利率大幅下滑]: 下游组件企业为降本低价中标，导致公司硅胶板售价持续下降，毛利率同比减少7.39个百分点。
- **[以低价策略拓展中石化业务]** -> [橡胶密封制品收入增长但毛利率下降]: 为获取支柱密封件订单，公司以较低中标价格合作，叠加现场安装费及配套金属件成本大增，毛利率同比减少9.10个百分点。
- **[人民币汇率上升]** -> [汇兑损失增加，财务费用由负转正]: 汇率变动导致汇兑收益同比减少390.34%，叠加存款利率下行，财务费用同比增加103.20%。
- **[参股公司科悦新材亏损扩大]** -> [投资收益大幅下降]: 科悦新材新产品推广未达预期，亏损扩大至683.92万元，导致公司按权益法确认的投资收益为-206.66万元。
- **[存货跌价准备计提增加]** -> [资产减值损失扩大]: 硅胶战略备货、订单取消及轨道交通项目暂缓导致长库龄存货增加，存货跌价损失同比上升56.46%。
- **[上年同期收到大额上市奖励]** -> [营业外收入基数高，加剧净利润下滑]: 本期无此类非经常性收益，导致营业外收入同比减少99.85%，进一步拉低净利润。
- **[应收账款余额高企与坏账计提增加]** -> [信用减值损失持续侵蚀利润]: 期末应收账款账面余额2.06亿元，坏账准备达3,574万元，信用减值损失-533万元，持续影响利润。

## 风险警告
**核心风险在于盈利能力的急剧恶化。** 公司2025年净利润同比暴跌47.75%，主因是核心产品硅胶板受光伏行业“内卷”影响，毛利率大幅下滑。同时，为抢占石化市场份额而采取的“以价换量”策略，导致橡胶密封制品毛利率同步下降。这种“增收不增利”甚至“增收反减利”的趋势，若下游行业景气度无法回暖，公司毛利率可能进一步承压。

**资产质量风险不容忽视。** 公司应收账款余额高达2.06亿元，占净资产28.5%，且坏账准备持续增加。存货跌价准备占存货余额比例已升至17.22%，反映出部分产品滞销或订单取消的风险。此外，参股公司科悦新材持续大额亏损，表明公司在新业务拓展上的投入尚未见到回报，存在拖累整体业绩的可能。
