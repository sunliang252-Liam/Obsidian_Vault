# 920943.BJ 深度透视

## 因果逻辑链
- **[航空零部件产能释放]** -> [收入增长23.88%]: 航空零部件智能制造基地完工+比扬精密全年并表，推动航空零部件收入达1.14亿元，成为核心增长引擎。
- **[液压系统泰国工厂投产]** -> [收入增长12.51%]: 优机泰国2025年全面投产，液压系统零部件收入增至1.23亿元，海外产能布局初显成效。
- **[油气化工产品交付延迟]** -> [收入下降10.36%]: 高端阀门生产线技术瓶颈导致生产周期延长，叠加第三方检验环节，油气化工收入下滑至2.85亿元，拖累整体增速。
- **[可转债募资1.2亿元]** -> [资本开支大幅扩张]: 发行可转债用于阀门智能产线及高端铸造改扩建，投资活动现金净流出2.15亿元，同比增加140.55%。
- **[新市场/新客户开拓]** -> [收入微增1.89%]: 新增16国31家国际客户及17家国内客户，但增量被油气化工下滑部分抵消，整体营收仅增长1.89%。
- **[销售费用与财务费用双升]** -> [净利润下降6.64%]: 销售费用增33.37%（人员薪酬+投标平台费），财务费用增75.81%（借款利息增加），侵蚀利润空间。
- **[应收账款周转放缓]** -> [经营现金流下降30.13%]: 应收账款周转率从2.37降至2.22，叠加存货增加19.91%，导致经营活动现金流净额降至7558万元。

## 风险警告
**核心风险在于油气化工业务的结构性下滑与产能瓶颈。** 该板块收入同比下降10.36%，主因是现有生产线无法满足高端阀门自动化、高难度的制造要求，导致交付周期延长。公司虽已启动可转债募投的阀门智能柔性生产线项目，但截至报告期末仅投入10.32%，项目落地与产能释放存在显著时间差，短期内油气化工业务仍将持续承压，拖累整体盈利弹性。

**财务风险方面，资产负债率攀升至52.60%，利息保障倍数从21.31骤降至11.53。** 公司为扩张产能大幅举债（长期借款增24.39%，应付债券新增1.09亿元），叠加应收账款与存货双高（合计约6亿元），营运资金压力加大。若下游回款周期进一步延长或募投项目效益不及预期，公司可能面临流动性收紧与财务费用侵蚀利润的双重困境。

**公司简介（F10 原文）**

> 四川优机实业股份有限公司成立于2001年,位于成都高新区(西区)。公司于2015年10月在全国中小企业股份转让系统挂牌,于2022年6月24日在北交所上市(股票代码920943)。优机股份是一家先进制造与现代服务深度融合的高新技术企业,专业从事定制化设备及零部件的研发、设计、制造和销售,凭借对产品研发与设计、材料与工艺创新、先进制造和检验检测等核心技术的掌握,利用自主生产和协同制造能力,满足不同行业客户多品种、多应用场景的定制需求。目前公司已形成服务于油气化工、工程矿山机械、通用机械、液压系统等领域的设备及零部件定制和航空零部件精密定制五大业务体系,覆盖上万种规格型号的产品,通过快速反应和精准高效服务为全球市场包括中国在内40多个国家和地区的客户提供高品质定制化设备及零部件。优机股份以开发国际、国内两大市场,满足客户对设备及零部件定制需求为目标,以“先进制造”和“深度服务”为内在驱动,采取“自主生产+协同制造”的柔性制造模式,形成了以产品研发、材料及工艺创新技术为基础的先进制造能力,以及面向客户和协同制造商的技术服务、供应链管理、全过程质量控制和物流运输为核心的深度服务体系。优机股份拥有质量检测和计量服务机构,配备了专业质量控制团队,母公司及控股子公司通过了ISO9001:2015、AS9100D:2016和APIQ1等国内外专业领域质量管理体系认证。子公司生产的产品获得了CE、API6D、ATEX、PED/AD2000等国内外权威认证。良好的全流程质量管理文化、完善的质量控制体系以及切实可行的控制流程,使得公司自制产品和协同制造产品质量均得到有效管控。经过二十年的发展与沉淀,优机股份已成为技术先进、工艺成熟、模式创新、管理规范的综合性定制化设备及零部件制造和服务商,为国际、国内的设备制造商、工程承包商、油气化工等设备使用企业、工程及销售服务商提供涉及石油、化工、天然气、航空、电力、船舶、采矿、建筑、农业、水处理等多个工业系统和领域的定制设备及零部件产品。
