# 920504.BJ 深度透视

## 因果逻辑链
- **[下游需求收缩与竞争加剧]** -> [营收与净利润双降]: 宏观经济承压，下游客户采购意愿减弱，行业竞争白热化，导致公司2025年营收同比-1.92%，归母净利润同比-5.67%。
- **[聚焦高校设备更新政策]** -> [稳住基本盘]: 公司针对性推出“高教款”产品，重组高校经销商体系，深度把握《推动大规模设备更新和消费品以旧换新行动方案》政策机遇，减缓了营收下滑幅度。
- **[加大研发投入与新品迭代]** -> [构建技术壁垒与增长新极]: 全年新增5项发明专利，布局细胞培养、样本前处理等新赛道（如摇床、研磨仪），形成“传统优势+新兴增长”双轮驱动，为中长期增长奠基。
- **[募投项目持续推进]** -> [产能扩张与资产结构变化]: 生命科学仪器及实验室设备扩产项目投入增加，在建工程同比+42.96%，为未来产能释放做准备，但短期内增加了资本开支。
- **[强化应收账款催收]** -> [现金流稳健与资产质量优化]: 年末加大催收力度，应收账款同比-38.85%，经营活动现金流净额同比+3.90%至2055万元，经营质量稳健。
- **[境外业务高速增长]** -> [开辟第二增长曲线]: 积极拓展外贸，境外营收同比+52.08%，毛利率高达46.68%，成为公司业绩的重要增量来源。
- **[原材料与存货减值压力]** -> [侵蚀利润]: 库龄较长原材料增加，叠加新品推出加速，基于谨慎性原则计提存货跌价准备，资产减值损失同比+159.23%，对净利润造成拖累。

## 风险警告
公司面临的核心风险在于**成长性不足与竞争加剧**。营收已连续两年下滑（2024年-14.14%，2025年-1.92%），净利润降幅更大（2024年-40.72%，2025年-5.67%），表明公司尚未找到有效的增长引擎。尽管境外业务和高校设备更新政策带来亮点，但体量尚小，难以对冲国内传统业务的下行压力。同时，存货跌价准备的激增（+159%）暗示产品迭代压力与库存管理风险。

另一重大风险是**高度集中的股权结构与治理风险**。实际控制人吕明杰持股超60%，家族成员合计持股近70%，形成绝对控制。虽然公司已建立内控制度，但“一股独大”的治理结构下，关联交易（如向实控人租赁房屋）的定价公允性、中小股东利益保护等始终是潜在隐患。公司取消监事会的治理变革，进一步将监督职能集中于董事会审计委员会，其独立性有待长期观察。
