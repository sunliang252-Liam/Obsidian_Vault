# 920124.BJ 深度透视

## 因果逻辑链
- **[下游空调压缩机行业高景气度]** -> [营收增长6.16%]: 下游客户（美的、格力等）需求旺盛，带动公司精密件订单量增加，收入稳步增长。
- **[安徽中特铸造产能投放]** -> [自产铸件能力增强，外购铸件及加工服务减少]: 新产能投产使公司优先满足内部精密件生产，导致金属铸件对外销售和加工服务收入分别下降27.55%和40.18%。
- **[“原材料+加工费”定价模式]** -> [毛利率稳定在22.72%]: 产品价格随原材料价格波动调整，有效传导成本压力，使毛利率同比仅微增0.07个百分点。
- **[产能扩张与设备购置]** -> [固定资产大增70.75%，财务费用激增61.97%]: 为匹配订单增长，公司大规模购建固定资产，导致融资租赁及银行借款利息费用显著增加。
- **[IPO募集资金到账]** -> [货币资金暴增939.21%，净资产增长57.63%]: 2025年11月北交所上市，募集资金净额2.84亿元，大幅改善公司资产结构和现金流。
- **[客户高度集中]** -> [前五大客户销售占比93.55%]: 公司深度绑定美的集团（51.47%）和格力电器（34.40%），业绩高度依赖核心客户，议价能力受制。
- **[经营活动现金流净额为负]** -> [现金流与净利润严重背离]: 因大量使用银行承兑汇票背书支付设备款，导致经营性现金流入减少，报告期经营现金流为-8367万元。
- **[积极布局新业务]** -> [开拓机器人领域客户]: 公司已与苏州卓誉签订战略合作协议，部分产品送样合格并小批量供货，旨在打开新的增长空间。

## 风险警告
**核心风险在于客户与产品结构的双重集中。** 公司前五大客户销售占比高达93.55%，其中仅美的集团一家就贡献了51.47%的营收。这种深度绑定意味着公司业绩与下游空调压缩机行业的景气度及核心客户的经营战略高度挂钩。一旦主要客户需求下滑、更换供应商或自身经营出现问题，公司将面临收入断崖式下跌的风险，几乎没有缓冲余地。同时，公司产品高度集中于压缩机零部件，尽管在拓展汽车和机器人领域，但短期内难以改变单一产品结构。

**扩张带来的财务压力不容忽视。** 公司正处于产能快速扩张期，固定资产同比大增70.75%，导致财务费用激增61.97%，且经营活动现金流净额由正转负，为-8367万元。这表明公司的高速增长严重依赖外部融资（借款、融资租赁）来支撑资本开支。若未来下游需求增速放缓或募投项目收益不及预期，高额的利息支出和偿债压力将直接侵蚀利润，并可能引发流动性风险。

**公司简介（F10 原文）**

> 珠海市南特金属科技股份有限公司是一家主要从事精密机械零部件研发、生产和销售的高新技术企业,自成立以来,公司一直专注于精密机械零部件制造领域。经过多年的发展创新与技术积淀,公司已形成从模具设计、熔炼铸造到精密加工的全套生产工艺,形成了一套以高性能精密机械零部件产品制备为核心的全流程生产体系,产品可应用于空调零部件、汽车零部件等细分领域。在空调零部件领域,公司依靠高水平的加工工艺、微米级(μ级)的加工精度、就近及快速响应客户需求,获得了多家下游客户的高度认可。公司已与空调压缩机的前五强中的四家建立了稳定的合作关系,包括美的集团、格力电器、海立股份、松下电器等国内外知名厂商。公司先后获得美的集团“优秀供应商”、格力电器“最佳协作奖”、松下电器“优秀供应商”等荣誉,公司良好的企业声誉和品牌影响力获得客户的高度认可。在汽车零部件领域,随着下游需求的蓬勃发展,近年来公司积极进行产品迭代升级,拓展产品在汽车领域的应用。目前,公司的压盘、前盖、卡钳等产品已陆续实现对客户送样或量产。
