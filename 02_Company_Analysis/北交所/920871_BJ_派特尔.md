# 920871.BJ 深度透视

## 因果逻辑链
- **[新厂房及设备投入使用，折旧费用大幅增加]** -> [净利润暴跌65.37%]: 固定资产折旧费用显著上升，直接侵蚀利润，是利润下滑的核心原因之一。
- **[股权激励计划实施，产生股份支付费用317.30万元]** -> [管理费用激增60.01%]: 股权激励费用计入管理费用，导致管理费用率从5.66%飙升至9.11%，严重拖累当期利润。
- **[对外投资回购义务方违约，计提大额信用减值]** -> [信用减值损失同比扩大820%]: 基于谨慎性原则，对无法收回的投资款计提坏账，导致信用减值损失从48万激增至443万，成为利润的又一重大减项。
- **[市场竞争加剧，产品毛利率下降]** -> [营业成本增速远超收入]: 营业收入同比微降0.59%，但营业成本同比增长6.97%，导致毛利率从32.44%下滑至27.30%，盈利能力显著恶化。
- **[下游工程机械与汽车行业持续复苏]** -> [核心业务收入保持韧性]: 受益于下游景气度，公司树脂软管及总成、改性工程塑料等主力产品收入基本持平，未出现大幅下滑。
- **[新设控股子公司斯达犇科技处于亏损状态]** -> [合并报表净利润进一步承压]: 新设立的电子散热业务子公司尚在投入期，报告期内亏损152万元，对整体利润形成拖累。
- **[新建大楼投入使用，长期待摊费用激增427%]** -> [未来期间费用压力持续]: 厂房装修款大幅增加，将在未来数年内摊销，持续影响管理费用和销售费用。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以扭转。** 公司2025年营收基本持平，但净利润暴跌65.58%，主因是产能扩张带来的折旧、股权激励费用、坏账计提等一次性或阶段性成本集中爆发。这些成本在2026年仍将持续，若营收无法实现同步增长，利润将继续承压。此外，公司毛利率已从32.44%降至27.30%，反映行业竞争加剧导致产品定价能力减弱，这是更长期的结构性风险。

**财务健康度存在隐忧。** 公司对外投资回购义务方违约，已计提大额坏账，暴露了公司投资风控能力的短板。同时，应收账款周转率下降，且占资产比重高达21.46%，若下游客户（如工程机械行业）景气度回落，坏账风险可能进一步扩大。新设立的斯达犇科技尚在亏损，短期无法贡献利润，反而消耗资源。
