# 920098.BJ 深度透视

## 因果逻辑链
- **[下游客户降本增效]** -> [橡塑新材料产品收入下降14.44%]: 煤炭市场持续低价，下游客户实施“降本增效”政策，导致核心密封、胶管产品需求萎缩。
- **[产品结构向低毛利业务倾斜]** -> [整体毛利率从41.26%骤降至34.45%]: 公司为对冲橡塑产品下滑，主动增加支架搬运车整车、配件销售及租赁业务，后者毛利率显著低于橡塑产品，拉低整体盈利水平。
- **[煤矿辅助运输设备收入增长16.03%]** -> [营业收入勉强持平]: 整车及配件业务增长有效对冲了橡塑新材料产品的下滑，使总营收仅微增0.18%。
- **[应收账款激增28.89%至4.08亿元]** -> [信用减值损失同比扩大82%]: 新增整车客户多为招投标产生，回款周期长，导致应收账款余额大幅增加，计提坏账准备随之攀升。
- **[研发投入持续加码]** -> [巩固技术壁垒与拓展新赛道]: 研发费用占营收5.95%，重点投向军工、液冷、电动化装备等新领域，为长期增长储备技术。
- **[募投项目推进]** -> [在建工程同比激增261.56%]: 募投项目（军民两用新型合成材料液压管生产线、研发中心、数字化工厂）进入实质建设阶段。
- **[经营活动现金流净额3,122万元]** -> [净利润含金量低]: 净利润5,881万元，但经营性现金流仅3,122万元，主要受应收账款大幅增加拖累，盈利质量承压。

## 风险警告
**核心风险在于“增收不增利”的恶化趋势。** 公司2025年净利润同比暴跌32.33%，根本原因是产品结构向低毛利的整车及配件业务倾斜，导致整体毛利率骤降近7个百分点。若煤炭行业持续低迷，下游“降本增效”压力不减，橡塑新材料这一高毛利基本盘可能继续萎缩，而公司被迫依赖低毛利业务维持营收规模，盈利能力将持续承压。

**应收账款高企与信用风险是另一大隐患。** 应收账款账面价值高达4.08亿元，占总资产33.88%，且增速远超营收增速。新增整车业务客户回款周期长，导致信用减值损失同比扩大82%。若宏观经济下行或部分客户经营恶化，公司将面临较大的坏账风险，进一步侵蚀利润。

> 陕西科隆新材料科技股份有限公司成立于1996年,前身是咸阳科隆橡胶制品研究所,是一家集研发、生产、销售于一体的高新技术企业,主营产品三大类:军、民两用组合密封制品、高压胶管及总成、煤矿支架搬运车,所生产的产品已广泛应用到军工、煤矿综采、航空航天、高铁、工程机械、风电等多个领域,优质的产品和一流的服务倍受国内外客户的信赖。公司以液压密封件和液压软管等橡塑新材料产品业务起家,经过多年发展逐步形成“一体两翼”协同发展的经营模式。其中,“一体”是指以橡塑材料研发为核心、以橡塑产品设计和生产为驱动,向煤炭行业客户提供定制化产品的核心业务方向;“两翼”分别是指以煤矿辅助运输设备、维修和其他矿用配件等业务为突破纵向深耕煤炭行业,和以定制化橡塑产品为突破横向拓展军工等下游应用行业的两个战略发展方向。“两翼”作为公司核心业务和技术的延伸,各自发展又相互补充,公司在“一体”核心业务主线稳固发展的同时,通过“两翼”业务不断拓展业务领域、优化产品结构,带动公司在“专业化”和“多元化”的发展道路上不断前行。近年来,公司积极响应国家政策号召,实行战略转型,将发展重心从面向民品煤机、工程机械领域关键零部件配套,转向面向军工、航空航天领域关键零部件配套。截止目前,已形成军工装备运输车用高压胶管及密封、航空航天液压软管、船只密封及发动机减震、高温耐烧蚀材料四大类产品实现国产化替代、填补行业空白的拳头系列产品。此外,公司还探索联合国内高校等外部资源进行“产、学、研”合作,共同探索橡塑新材料产品前沿应用领域,提高产品的应用水平,公司已与西安交通大学、西安科技大学、西北工业大学、长安大学等多所国内著名高校建立了合作关系。公司深耕煤炭行业二十余年,主要客户为大型煤矿和煤机企业。已与陕煤集团、郑煤机、北煤机、平煤机、中国神华、山东能源等煤炭或煤机行业头部公司及其下属企业建立长期稳定的合作关系。在不断巩固挖掘既有业务板块的同时,公司凭借橡塑新材料核心技术研发能力,积极开拓橡塑新材料产品行业应用新场景,为军工、高铁等行业客户研发并生产橡塑新材料产品,从单一煤机密封产品供应商转变为向不同行业客户提供多品类橡塑新材料产品的综合服务提供商。目前,公司在国内细分领域行业稳居前列,主要产品国内市场占有率处于国内领先水平。科隆新材将围绕科技创新、不断通过提升产品科技含量,使企业技术工艺、产品始终走在行业前沿。
