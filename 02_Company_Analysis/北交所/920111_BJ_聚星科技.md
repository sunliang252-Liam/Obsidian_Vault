# 920111.BJ 深度透视

## 因果逻辑链
- **[银铜原材料价格上涨]** -> [营收增长23.26%]: 公司采用“原材料价格+加工费”定价模式，银铜价格上涨直接推高产品销售单价，驱动收入增长。
- **[下游新能源、智能电网需求扩张]** -> [电接触元件收入增长28.33%]: 新能源汽车、充电桩、储能等新兴领域拉动高性能电接触元件需求，产品结构向高附加值元件化延伸。
- **[客户集中度高]** -> [前五大客户贡献33.88%营收]: 公司深度绑定低压电器行业头部客户，形成强粘性，但同时也面临单一客户订单波动风险。
- **[存货与应收账款高企]** -> [经营现金流仅751.6万元]: 存货（+43.52%）和应收账款（+18.90%）大幅增长，占用大量营运资金，导致净利润与现金流严重背离。
- **[短期借款激增404.77%]** -> [补充营运资金缺口]: 为应对业务扩张带来的资金压力，公司大幅增加短期债务融资，资产负债率从28.40%升至39.05%。
- **[研发投入持续加码]** -> [新增8项发明专利]: 聚焦环保化（AgSnO2替代AgCdO）、低银化、高性能化材料研发，巩固技术壁垒，支撑产品升级。
- **[原材料价格波动]** -> [毛利率下降2.91个百分点]: 银铜价格上涨未能完全通过定价机制向下游传导，导致成本增速（27.83%）高于收入增速（23.26%），毛利率承压。

## 风险警告
**核心风险：盈利质量与现金流严重不匹配。** 公司2025年净利润近1.2亿元，但经营活动现金流净额仅为751.6万元，且同比虽扭正但绝对值极低。主因是存货（+1.18亿）和应收账款（+0.66亿）大幅膨胀，占用了大量营运资金。这种“纸面富贵”的盈利模式，一旦下游客户回款放缓或银价下跌导致存货减值，将直接冲击公司流动性，甚至引发债务偿付风险。

**关键风险：原材料价格波动与毛利率持续承压。** 公司核心原材料银、铜价格受国际政治经济形势影响剧烈波动。尽管采用“原材料+加工费”定价，但价格传导存在滞后，2025年毛利率已从21.66%降至18.75%。若未来银价高位回落，公司高价库存将面临跌价损失；若银价继续上涨，则可能进一步挤压下游客户利润空间，导致订单流失。公司对前五大供应商采购占比高达71.57%，供应链集中风险亦不容忽视。
