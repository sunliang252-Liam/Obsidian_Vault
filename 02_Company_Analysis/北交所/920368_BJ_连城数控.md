# 920368.BJ 深度透视

## 因果逻辑链
- **[下游光伏行业产能过剩、扩产需求疲软]** -> [营收暴跌61.44%]: 下游客户资本开支大幅缩减，公司设备验收数量锐减，导致晶体生长及加工设备收入下降60.15%。
- **[客户集中度极高，关联交易占比大]** -> [业绩高度依赖单一客户]: 前五大客户销售占比72.77%，其中关联方隆基绿能贡献39.79%营收，客户集中风险显著。
- **[行业价格战与产能出清]** -> [毛利率逆势提升至29.95%]: 公司通过精简组织、降本增效，在收入下滑时仍将毛利率提升1.23个百分点，体现成本管控能力。
- **[应收账款与存货高企]** -> [资产减值风险持续]: 应收账款账面价值20.11亿元（占流动资产30.42%），存货18.77亿元（占流动资产28.40%），虽计提减值准备，但下游客户财务恶化可能引发坏账。
- **[海外市场拓展见效]** -> [境外收入逆势增长56.72%]: 公司积极布局北美、东南亚，海外收入占比提升至14.20%，部分对冲国内需求下滑。
- **[半导体设备突破]** -> [第二增长曲线初现]: 8/12英寸MCZ硅单晶炉、碳化硅电阻炉等实现批量出货或获海外订单，技术达国际领先水平。
- **[研发投入持续高企]** -> [技术壁垒加固]: 研发费用1.54亿元（占营收7.06%），累计专利997项，在AI拉晶、碳化硅外延炉等前沿领域形成储备。
- **[子公司经营分化严重]** -> [整体盈利承压]: 核心子公司连城凯克斯净利润9401万元，但釜川股份亏损4170万元、连科半导体亏损2709万元，拖累合并业绩。

## 风险警告
**核心风险在于光伏行业深度调整的持续性与客户集中度。** 公司营收与利润高度绑定于隆基绿能等头部客户，2025年关联交易占比近40%。若下游产能出清慢于预期，或隆基绿能自身经营恶化，公司订单与回款将面临断崖式风险。当前应收账款与存货合计占流动资产近60%，减值计提压力巨大，是悬在利润表上的达摩克利斯之剑。

**第二曲线尚在培育期，短期难以对冲主业下滑。** 半导体设备虽技术突破，但收入体量仍小，且碳化硅衬底价格年内暴跌超40%，可能抑制设备需求。公司海外收入仅占14%，全球化布局尚处早期。在行业“内卷”加剧、落后产能加速退出的背景下，公司需警惕技术迭代失败与核心人才流失的双重打击。

**公司简介（F10 原文）**

> 大连连城数控机器股份有限公司(连城数控920368.BJ)成立于2007年,系国家级高新技术企业、行业标准起草单位。连城数控在辽宁大连、江苏无锡、美国罗切斯特、越南海防设立了四大研发制造基地,布局光伏与半导体装备领域全产业链,致力于持续为客户提供可靠、增值的产品和服务。经过多年发展,现已成为具备行业影响力的专业化、集团化公司。连城数控为填补市场空白而生。成立之初就自主研制成功国际领先的多线切割机产品,全面替代进口;率先推出金刚线切片机,为光伏产业单晶取代多晶的技术变革做出重大贡献。2013年,并购美国500强公司斯必克(SPX)旗下单晶炉事业部,获得凯克斯(KAYEX)全部知识产权、商标和18项专利技术,实现硅单晶生长装备和技术完全国产化,并且不断引领大直径、高拉速技术升级,推动了光伏行业快速降本增效。目前,公司业务领域涉及半导体与光伏两大赛道。产品主要包括硅、锗、碳化硅和蓝宝石等晶体生长、晶体加工设备,光伏电池清洗、制绒、刻蚀设备,原子层沉积镀膜设备,光伏组件串焊机等自动化设备,以及硅料微波破碎设备等。公司整合大连连智和无锡釜川等控股公司优势产品,提供工业4.0背景下的光伏智能制造、智慧工厂全产业链装备和自动化整体解决方案。公司秉承“可靠、增值、阳光”的企业理念,倡导“反应迅速、乐于沟通、信守承诺、追求结果”的工作作风,业务模式由单一设备供应向整线交付方案快速转型,致力于成为全球领先的光伏及半导体装备集成服务商。
