# 920304.BJ 深度透视

## 因果逻辑链
- **[硝酸钾装置“三化”改造停产]** -> [硝酸钾产销量大幅下降]: 年产5万吨硝酸钾装置停产改造，导致硝酸钾收入同比暴跌61.48%，是营收和利润下滑的核心原因。
- **[熔盐储能项目（一期）建成投产]** -> [熔盐产品规模化收入]: 年产20万吨熔盐项目于2025年9月转固，熔盐产品贡献收入1.95亿元，占营收26.98%，成为新的收入支柱。
- **[原材料氯化钾采购价同比上涨28.90%]** -> [硝酸钾毛利率骤降20.60个百分点]: 主要原材料价格上涨，而产品售价支撑不足，导致硝酸钾毛利率从25.25%降至4.65%，严重侵蚀利润。
- **[熔盐业务订单集中备货]** -> [存货激增89.47%，经营现金流大幅转负]: 为满足大额熔盐订单，公司集中采购原料备货，导致存货增至1.11亿元，经营活动现金流净流出3534万元。
- **[收购润禾钾盐100%股权]** -> [合并成本小于可辨认净资产公允价值，形成营业外收入]: 非同一控制下企业合并产生651.74万元营业外收入，是净利润的重要非经常性损益来源。
- **[熔盐客户付款周期较长]** -> [应收账款激增211.31%]: 熔盐业务按合同节点付款，期末尚在信用期内，导致应收账款从2153万元增至6704万元，信用减值损失增加。
- **[年产20万吨熔盐项目（一期）及收购润禾钾盐]** -> [固定资产和无形资产大幅增长]: 项目转固及合并报表范围增加，固定资产增长71.73%，无形资产增长221.81%。
- **[新增银行借款及票据贴现]** -> [筹资活动现金流净额大幅转正]: 为支持项目建设及运营，公司新增短期借款3302万元和长期借款4994万元，筹资活动净流入7075万元。

## 风险警告
**核心风险在于新旧动能转换期的业绩阵痛。** 公司传统支柱产品硝酸钾因装置改造停产，叠加原材料成本高企，导致收入和毛利率双杀，净利润同比下滑32.21%。虽然熔盐业务已开始规模化贡献收入，但该业务具有“大订单、长周期、集中交付”的特点，导致存货和应收账款激增，经营活动现金流由正转负，对公司的营运资金管理构成严峻考验。若熔盐订单回款不及预期，或新项目产能爬坡不顺，公司现金流压力将进一步加大。

**另一重大风险是原材料价格波动与产品售价传导不畅。** 公司主要原材料液氨、氯化钾价格波动频繁，而下游化工产品市场竞争激烈，价格传导机制存在时滞。报告期内氯化钾采购均价同比上涨近30%，而硝酸钾售价未能同步提升，导致毛利率大幅收窄。未来若原材料价格继续高位运行或剧烈波动，而公司无法通过提价或成本优化有效对冲，盈利能力将持续承压。此外，公司研发投入极低（仅占营收0.12%），技术储备和产品升级的长期竞争力存疑。
