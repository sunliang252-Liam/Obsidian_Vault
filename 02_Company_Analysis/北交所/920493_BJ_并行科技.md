# 920493.BJ 深度透视

## 因果逻辑链
- **[AI大模型需求爆发]** -> [算力服务收入高速增长66.31%]: 生成式AI驱动大规模训练与推理需求，公司智算云业务成为核心增长引擎。
- **[自有算力池扩张（共建集群+采购）]** -> [固定资产与在建工程大增，资产负债率升至79.30%]: 公司通过银行贷款和融资租赁大规模采购GPU服务器，资产结构显著重型化。
- **[后付费客户占比提升]** -> [应收账款激增169.62%，信用减值损失扩大306.59%]: 企业客户（尤其AI客户）采用后付费模式，导致回款周期拉长，坏账风险显著上升。
- **[规模效应初显]** -> [经营活动现金流净额翻倍至2.45亿元]: 收入高速增长带来强劲的现金流入，但利润端受折旧、利息和坏账拖累，净利润仅微增1.34%。
- **[毛利率大幅下滑]** -> [综合毛利率从32.87%降至24.23%]: 外采算力成本与自有设备折旧快速攀升，而算力服务价格竞争加剧，导致盈利能力承压。
- **[研发聚焦AI平台]** -> [研发费用增长44.31%]: 重点投入AI云平台、MaaS基础设施及大模型调度网关，旨在构建技术壁垒，但短期侵蚀利润。
- **[实际控制人高比例担保]** -> [财务费用增长110.21%]: 公司大量贷款依赖实控人夫妇个人连带担保，融资结构单一，财务杠杆高企。

## 风险警告
**核心风险在于“增收不增利”与资产质量恶化。** 公司营收增长69.56%，但扣非净利润几乎归零（-7.5万元），主因是毛利率骤降8.6个百分点至24.23%，同时信用减值损失激增至2397万元。这揭示出公司在AI算力军备竞赛中，为抢占市场份额而牺牲定价权，且对后付费大客户的信用管理存在明显短板。应收账款周转率从8.25次降至5.71次，坏账风险正在快速累积。

**高杠杆扩张模式下的财务脆弱性不容忽视。** 资产负债率已达79.30%，长期借款和租赁负债同比大增超70%，利息保障倍数仅1.46倍，逼近警戒线。公司大量固定资产已用于抵押（占总资产22.69%），且几乎所有银行贷款均由实控人夫妇提供个人无限连带担保。一旦算力需求增速放缓或融资环境收紧，公司将面临巨大的流动性压力和再融资风险。
