# 920007.BJ 深度透视

## 因果逻辑链
- **[全球光伏装机高增长 + 跟踪支架渗透率提升]** -> [营收增长41.47%]: 下游客户需求旺盛，公司作为跟踪支架核心零部件供应商，订单量随行业扩容而大幅增加。
- **[客户高度集中（前五大客户占95%）]** -> [营收高增长但利润增速极低（+1.51%）]: 对单一大客户A（占比62%）依赖极强，议价能力弱，收入增长未能有效转化为利润增长。
- **[外销收入占比88% + 人民币升值]** -> [财务费用由负转正，同比+91.43%]: 汇兑收益大幅减少，侵蚀了部分利润空间，是利润增速远低于营收增速的核心原因之一。
- **[原材料（钢材）成本上涨 + 成本传导时滞]** -> [毛利率从18.42%降至15.16%]: 营业成本增速（+47.12%）显著高于营收增速（+41.47%），成本压力未能及时、充分向下游传导。
- **[营收大幅增长 + 信用政策放宽]** -> [应收账款增长66.31%，信用减值损失暴增508.6%]: 为维持高增长，公司可能放宽了回款条件，导致坏账风险显著上升，进一步拖累利润。
- **[北交所上市募资2.79亿元]** -> [货币资金暴增617.78%，净资产翻倍]: 上市极大改善了资产负债表，为后续产能扩张和全球化布局提供了资金弹药。
- **[股权激励（35.97元/股）]** -> [管理费用增长41.98%]: 股份支付费用计入管理费用，是管理费用增速远高于营收增速的重要原因，短期压制了利润表现。
- **[子公司安徽寅天贡献主要利润]** -> [合并净利润结构单一]: 安徽寅天净利润约1,435万元，是合并报表利润的重要来源，其经营状况对整体业绩影响较大。

## 风险警告
**核心风险：增收不增利的“虚假繁荣”。** 公司营收增长41.47%，但扣非净利润同比下滑0.53%，毛利率大幅下滑3.26个百分点。这背后是客户集中度极高（前五大客户占95%，单一大客户A占62%）、原材料成本传导不畅、人民币升值侵蚀利润、以及信用减值损失暴增等多重负面因素的叠加。公司本质上是一个“代工”角色，缺乏定价权，规模扩张并未带来相应的利润增长，反而放大了经营杠杆的负面效应。

**关键风险：单一大客户依赖与汇率波动。** 对客户A的依赖度超过60%，任何合作关系变动都将对公司造成毁灭性打击。同时，公司88%的收入来自境外，以美元计价，人民币升值将直接导致汇兑损失和产品竞争力下降。尽管公司使用外汇期权进行套保，但2025年财务费用的大幅转正已表明，套保效果有限，汇率风险是悬在利润头上的达摩克利斯之剑。

**公司简介（F10 原文）**

> 江苏酉立智能装备股份有限公司自设立以来深耕光伏支架领域,聚焦光伏支架核心零部件的研发、生产和销售。公司主营产品包括光伏支架主体支撑扭矩管(TTU)、光伏支架轴承组件(BHA)、光伏组件安装结构件(URA)以及檩条(RAIL)等光伏支架核心零部件产品。公司主营产品经组装后,可形成光伏电站之“骨骼”——光伏支架,包括跟踪支架及固定支架,其中跟踪支架与配套的电控设计、驱动设计共同构成光伏跟踪支架系统。光伏支架是光伏电站中用于安装、摆放、承载、固定及调整光伏组件的特殊支架,其与光伏组件、汇流箱、逆变器等核心设备共同构成光伏发电系统。固定支架指光伏阵列不会跟随太阳入射角的变化而变动,仅以固定的角度来接受太阳辐射,是目前中国最主流的光伏支架形式;跟踪支架指能够根据太阳光入射角的变化而对光伏组件的空间角度进行调整,进而增加太阳光照射到组件上的辐射量以提高发电量的光伏支架。光伏支架在光伏发电系统中起到支撑光伏发电组件的作用,其稳定性与否是决定光伏电站寿命长短的关键因素。并且光伏电站整体收益的实现依靠结构设计,而结构设计核心就是光伏支架机械设计,科学合理的机械结构不仅能够延长电站整体寿命,还能够提高发电效益,减少后期维护成本。公司根据客户的光伏支架机械结构需求,协助优化产品设计,确认最终机械设计方案后,生产相关光伏支架核心零部件,并最终组装成光伏支架。公司秉承―碳致中和、跟踪未来‖的发展理念,在光伏支架领域多年的经营过程中,积累了丰富的生产经验及工艺技术,在产品结构设计、规模化生产、产品质量控制、成本控制等方面积累了丰富的行业经验。凭借成熟的技术工艺、质量优秀可靠的产品、高效稳定的规模化产品交付能力等竞争优势,公司立足于国际市场并逐步开拓国内市场,在国内外光伏支架行业,建立了较高的知名度,积累了包括NEXTracker(NASDAQ:NXT)等国际知名光伏支架企业在内的优质客户资源,产品远销北美、澳洲、巴西、智利、欧洲等国家和地区。公司是经江苏省科学技术厅、江苏省财政厅、国家税务总局江苏省税务局联合认定的高新技术企业。2022年12月,公司经江苏省工业和信息化厅认定为江苏省专精特新中小企业;2023年7月,公司经国家工业和信息化部认定为国家级专精特新―小巨人企业。并通过了质量管理体系ISO9001、欧盟钢结构产品EN1090的认证,与国内外知名光伏支架企业如NEXTracker(NASDAQ:NXT)、OptimumTracker、GonvarriIndustries、天合光能、安泰新能源等建立了良好的合作关系。
