# 920491.BJ 深度透视

## 因果逻辑链
- **[智能驾驶渗透率提升]** -> [传感器业务收入增长19.76%]: 智能汽车APA/AVP系统标装率提升，带动AKII车载超声波传感器大批量交付。
- **[服务机器人市场爆发]** -> [机器人传感器收入超1.1亿元]: 公司为扫地机器人、割草机器人等提供超声波测距、避障模组，切入高增长赛道。
- **[IDM垂直整合模式]** -> [毛利率稳定在34.82%]: 自研核心材料、换能芯片与精密制造全链条覆盖，有效对冲原材料价格波动。
- **[海外安防终端需求萎缩]** -> [执行器收入下降29.29%]: 传统电声类执行器订单减少，而新一代压电执行器尚未形成规模收入，出现结构性缺口。
- **[高性能传感器基地动工]** -> [在建工程激增342.57%]: 广州番禺新基地建设投入，为未来产能扩张与产品升级奠定物理基础。
- **[H股上市筹备启动]** -> [海外投资与双循环布局加速]: 设立香港控股及马来西亚子公司，旨在打通境外融资渠道并构建海外供应链枢纽。
- **[无铅压电材料研发突破]** -> [发布无铅压电射流风扇/触觉执行器]: 抢占环保法规趋严下的技术制高点，有望进入食品、医疗等新领域。

## 风险警告
**核心风险在于执行器业务的断崖式下滑与新品接续的严重滞后。** 海外安防市场萎缩导致执行器收入同比骤降29.29%，而公司寄予厚望的压电敲击开关、触觉反馈执行器等新品仍处于市场导入期，未能形成有效收入填补。若消费电子及智能终端领域的客户验证周期长于预期，执行器板块将持续拖累整体业绩，并导致产能利用率（仅39.45%）进一步恶化。

**另一重大风险是海外扩张与H股上市带来的复合不确定性。** 公司同时推进马来西亚建厂与H股上市，面临汇率波动、地缘政治、海外合规及文化整合等多重挑战。此外，贵金属（银、金）价格波动对成本端的挤压已明确列为新增风险，而公司目前仅采取战略储备应对，缺乏有效的套期保值工具，若原材料价格持续飙升，将直接侵蚀本已承压的盈利能力。
