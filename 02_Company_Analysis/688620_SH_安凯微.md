# 688620.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧导致产品价格承压]** -> [毛利率下滑]: 物联网摄像机芯片价格持续下降，导致2025年毛利率同比减少4.70个百分点，是利润亏损的核心原因。
- **[高强度研发投入持续]** -> [研发费用增加]: 2025年研发费用1.51亿元，同比增长13.66%，占营收28.16%，为维持技术竞争力而持续加码，但短期侵蚀利润。
- **[新产品量产导入市场]** -> [营收稳中有升]: 2025年新增8个光罩项目进入量产，芯片出货超1700万颗，推动营收同比微增1.87%，对冲了部分价格下行压力。
- **[美元汇率波动及利息收入减少]** -> [财务费用增加]: 汇兑损失增加及现金管理利息收入减少，导致财务费用同比变动-56.61%，进一步加剧亏损。
- **[资产减值损失计提增加]** -> [净利润大幅下降]: 基于审慎原则对存货和光罩计提减值，资产减值损失同比增加，是净利润亏损扩大的重要因素。
- **[收购思澈科技]** -> [完善产品矩阵与市场拓展]: 收购思澈科技补齐蓝牙通信、超低功耗及图形引擎技术，将业务边界延伸至智能穿戴等增量市场，寻求协同效应。
- **[AI端侧应用需求增长]** -> [新产品出货放量]: AI眼镜、智能门锁等新场景的SoC芯片实现量产出货，为公司未来增长提供新动能，但当前体量尚不足以扭转整体颓势。

## 风险警告
公司当前面临的核心风险是**“增收不增利”的盈利困境**。尽管营收微增，但行业竞争导致产品价格持续承压，毛利率显著下滑，叠加高昂的研发投入和资产减值损失，导致2025年归母净利润亏损扩大至-1.4亿元。若市场竞争进一步加剧，新产品放量速度不及预期，公司业绩存在持续下滑或亏损扩大的风险。

此外，**并购整合与商誉减值风险**不容忽视。公司收购思澈科技形成大额商誉，且标的公司目前处于亏损状态。若双方在技术、市场及供应链的整合协同效应未能如期释放，或核心团队流失，将面临商誉减值风险，对当期损益造成重大冲击。同时，公司客户与供应商集中度较高，前五大客户销售额占比超75%，前五大供应商采购额占比超84%，任何单一环节的波动都可能对经营产生显著影响。
