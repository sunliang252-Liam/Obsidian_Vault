# 002572.SZ 深度透视

## 因果逻辑链
- **[新房交付持续缩水，存量房改造成为核心主战场]** -> [收入承压]: 2025年住宅竣工面积同比降20.2%，公司营收同比降10.74%至93.67亿元，新房驱动的旧增长逻辑失效。
- **[国补政策退坡导致预收合同负债大幅减少]** -> [经营性现金流急剧恶化]: 2024年四季度国补推高合同负债至22.82亿元，2025年国补订单减少，合同负债降至6.26亿元，导致经营活动现金流净额由正转负至-3.21亿元。
- **[持有国联民生股票公允价值大幅下跌]** -> [净利润大幅下滑]: 国联民生股价变动导致公允价值变动损失1.49亿元，叠加其他非经常性损益，归母净利润同比降34.26%至9.01亿元。
- **[流量碎片化与消费习惯深刻改变]** -> [经销商渠道收入下滑]: 传统自然客流持续缩减，经销商渠道收入同比降13.58%至73.65亿元，倒逼公司构建“1+N+X”全域立体服务网络。
- **[“多品牌、全品类、全渠道”战略深化]** -> [品牌矩阵协同效应显现]: 索菲亚主品牌稳住基本盘（收入84.57亿），米兰纳、司米、华鹤差异化定位覆盖年轻、高端、中式细分市场，米兰纳收入3.94亿，客单价17,763元。
- **[全案定制战略升级与5A标准推行]** -> [产品竞争力提升]: 从“产品组合”升级为“空间解决方案”，推出5A级柜体标准，衣柜及配套产品毛利率同比提升1.14个百分点至38.87%。
- **[AI赋能与数智化运营平台]** -> [运营效率提升]: DIY Home系统打通设计到生产全流程，工厂对经销商平均交货周期保持7~12天，支撑柔性生产与规模化定制。
- **[海外渠道稳步拓展]** -> [第二增长曲线初现]: 业务覆盖近30个国家与地区，出口收入同比增12.78%至0.85亿元，新签约28家海外经销商。

## 风险警告
**核心风险：经营现金流断裂与地产链信用风险。** 2025年经营活动现金流净额由正转负至-3.21亿元，主因国补退坡后合同负债骤降，但更深层是存量房时代流量获取成本攀升与回款周期拉长。同时，大宗业务应收账款及票据余额仍高达12亿元以上，若地产客户信用恶化，减值风险将直接冲击利润表。

**第二风险：金融资产公允价值波动与战略投资失误。** 公司持有国联民生股票公允价值变动损失1.49亿元，直接导致净利润大幅下滑34%。此类非主业金融投资暴露了公司在资本配置上的风险敞口，若市场持续低迷，将对净资产和利润形成持续拖累。
