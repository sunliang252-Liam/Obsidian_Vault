# 002715.SZ 深度透视

## 因果逻辑链
- **[金矿业务出表]** -> [净利润暴跌406%]: 2025年9月剥离亏损金矿子公司，产生处置损失及剩余股权公允价值调整，合计约-963万元，直接导致归母净利润由盈转亏。
- **[气门主业收入增长但毛利承压]** -> [扣非净利润亏损]: 气门收入同比+16.63%，但毛利率微降0.18%，叠加销售、研发费用增加，扣非净利润亏损1014万元。
- **[出口收入激增]** -> [汇兑损失扩大]: 出口收入同比+31.96%，占比提升至48.82%，导致财务费用中汇兑损失增加，财务费用同比+8.01%。
- **[控股股东股份全数冻结]** -> [控制权不稳]: 控股股东益科瑞海所持23.04%股份全部被司法冻结及轮候冻结，存在控制权变更的重大风险。
- **[违规担保暴露内控缺陷]** -> [监管处罚]: 公司为孙公司3400万元贷款提供担保未经董事会审议，被广东证监局出具警示函，内控有效性受质疑。
- **[金矿业务萎缩]** -> [资产规模收缩]: 金矿出表及产量下降，总资产同比-19.50%，合质金收入同比-64.73%。
- **[研发投入持续]** -> [技术壁垒加固]: 研发费用同比+15%，聚焦镍基合金、粉末冶金等前沿工艺，巩固气门行业技术领先地位。

## 风险警告
**核心风险：控制权不稳与内控失效的双重危机。** 控股股东益科瑞海所持全部股份被司法冻结，一旦被强制执行，公司实际控制人将发生变更，可能引发管理层动荡与战略摇摆。同时，公司2025年因违规担保（未履行董事会审议程序）被监管处罚，暴露出内部控制存在重大缺陷，合规风险显著上升。

**经营风险：主业增收不增利，金矿剥离后遗症显现。** 气门主业虽收入增长，但毛利率下滑，且出口占比过高导致汇兑损失侵蚀利润。剥离金矿业务虽短期止血，但产生了近千万元的一次性处置损失，导致全年业绩由盈转亏。公司正处海外建厂（泰国）的投入期，资金需求大，而盈利能力恶化将加剧现金流压力。
