# 000702.SZ 深度透视

## 因果逻辑链
- **[主动压缩生猪养殖规模]** -> [营收下降9.13%]: 公司主动减少生猪存出栏量以降低经营风险，导致饲养行业收入同比大幅下降40.86%，拖累整体营收。
- **[饲料销量逆势增长25.61%]** -> [饲料主业收入增长37.59%]: 公司聚焦“提质上量”策略，饲料销量大幅增长，部分对冲了养殖业务收缩和原料贸易萎缩带来的收入缺口。
- **[原料贸易业务大幅萎缩]** -> [营收结构剧变]: 饲料原料销售同比骤降76.45%，上海分部收入暴跌95.67%，表明公司正主动剥离低毛利、高风险的贸易业务，回归饲料主业。
- **[应收账款激增与经营性现金流恶化]** -> [盈利质量承压]: 为扩大饲料销售放宽信用政策，导致应收账款增加6.19个百分点，经营活动现金流由正转负至-3137万元，净利润含金量低。
- **[持续亏损与母公司未弥补亏损]** -> [无法分红]: 母公司未分配利润高达-6.2亿元，公司连续三年扣非净利润为负，不具备现金分红条件，股东回报缺失。
- **[压缩养殖规模与淘汰低效母猪]** -> [生物资产减值]: 生猪存栏量增加61.45%的同时，计提消耗性生物资产减值628万元，反映公司在猪价低迷周期中主动出清低效产能。
- **[组织架构扁平化改革]** -> [管理费用下降11.48%]: 取消片区管理模式，整合为两大中心、三大事业部，提升了决策效率并降低了管理成本。

## 风险警告
**核心风险在于公司深陷“增收不增利”与现金流枯竭的恶性循环。** 尽管饲料主业销量增长，但激烈的行业竞争导致毛利率仅7.4%，无法覆盖高昂的管理与财务费用。公司为冲销量而放宽信用政策，导致应收账款激增、经营性现金流大幅净流出，造血能力严重不足。母公司高达6.2亿元的未弥补亏损，意味着公司短期内无法通过分红回报股东，资本市场的融资功能也基本丧失。

**另一重大风险是生猪养殖业务的持续拖累与资产减值压力。** 公司虽主动压缩养殖规模，但猪价周期性波动、重大疫病风险以及饲料原料价格波动，随时可能再次引发巨额亏损。报告期内已计提生物资产减值，若猪价持续低迷，公司账面高达4.6亿元的生物资产及固定资产将面临更大的减值风险，进一步侵蚀本已脆弱的净资产。
