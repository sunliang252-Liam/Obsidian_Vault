# 300673.SZ 深度透视

## 因果逻辑链
- **[美国关税冲击]** -> [海外收入下滑15.08%]: 高额关税导致美国客户下单谨慎，公司海外ODM业务收入承压，是营收下滑12.67%的主因。
- **[自主品牌战略投入]** -> [净利润下滑36.52%]: 公司坚定投入自主品牌（爵宴等）和新西兰主粮产线，前期费用（佩蒂智创亏损4000万、新西兰天然纯亏损6622万）侵蚀短期利润。
- **[全球化产能布局]** -> [综合毛利率逆势提升8.51个百分点至31.86%]: 越南、柬埔寨等低成本基地运营效率提升，叠加精细化运营，有效对冲了收入下滑对盈利能力的冲击。
- **[新西兰主粮产线商业化]** -> [管理费用同比增加17.39%]: 年产4万吨主粮项目进入商业化运营，新增大量折旧摊销及高薪管理人员，推高了管理费用。
- **[人民币汇率波动]** -> [财务费用同比增加346.26%]: 汇兑收益同比减少1311.89万元，占净利润的11.34%，成为利润下滑的重要非经营性因素。
- **[爵宴品牌爆发]** -> [国内直销收入同比增长49.22%]: 爵宴在618、双十一等大促中斩获多项第一，带动国内直销模式收入快速增长，成为公司新的增长极。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售占比高达70.66%，其中第一大客户占比41.61%，对单一市场及大客户依赖度极高，抗风险能力脆弱。

## 风险警告
**核心风险在于对单一市场和客户的深度依赖。** 公司海外收入占比超80%，且前五大客户销售额占比高达70.66%，其中第一大客户占比超40%。这种结构使得公司业绩极易受到美国关税政策、主要客户经营状况及国际地缘政治冲突的冲击。2025年营收下滑12.67%已直接印证此风险，未来若贸易环境进一步恶化或核心客户流失，公司业绩将面临剧烈波动。

**战略转型期的投入产出错配风险不容忽视。** 公司正全力押注自主品牌和新西兰主粮业务，但这两大板块目前均处于大幅亏损阶段（合计亏损超1亿元），严重拖累整体利润。主粮产能（新西兰4万吨、国内5万吨项目）尚未完全释放，品牌建设仍需持续高额投入。若国内市场开拓不及预期或新品市场认可度低，前期巨大的资本开支和运营费用将无法收回，导致公司陷入“增收不增利”甚至亏损的困境。
