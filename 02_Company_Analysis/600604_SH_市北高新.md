# 600604.SH 深度透视

## 因果逻辑链
- **[住宅项目售罄]** -> [营收断崖式下降57.4%]: 2024年市北华庭项目基本售罄并确认收入，2025年仅剩少量尾盘交付，导致主营业务收入从25.8亿骤降至11亿。
- **[新竣工载体摊销成本激增]** -> [净利润由盈转亏至-3.15亿]: 静安国际科创社区等新项目竣工，产业载体摊销成本同比大幅增加，叠加收入锐减，导致利润总额从+1.5亿暴跌至-3.13亿。
- **[上海区域产业载体销售停滞]** -> [房地产业务毛利率下滑]: 2025年上海区域未实现产业载体销售，仅靠南通、无锡少量销售，导致房地产业务收入同比下降85.66%。
- **[租赁业务成本刚性上涨]** -> [租赁业务毛利率大幅下降19.74个百分点]: 园区产业载体租赁收入微降0.11%，但折旧摊销等成本上升13.07%，导致租赁业务毛利率从约32%降至12.28%。
- **[产业投资公允价值变动]** -> [加剧亏损]: 持有的交易性金融资产和其他非流动金融资产公允价值变动损失3456万元，直接侵蚀利润。
- **[聚焦“云数智链”产业生态]** -> [园区招商逆势增长]: 全年新引进数智企业超150家，累计超900家，数通链谷引进区块链企业53家，维持了园区产业密度。
- **[经营性现金流由负转正]** -> [财务结构改善]: 经营活动现金流净额从-3.09亿转为+0.51亿，主要得益于销售回款与购地支出的时间差，以及债务结构的优化。

## 风险警告
**核心风险在于业绩的不可持续性与资产减值压力。** 公司2025年巨亏的根本原因是“住宅销售断档+新载体成本刚性释放”的双重打击。市北华庭项目作为一次性收入来源已基本耗尽，而上海区域产业载体销售停滞，未来营收高度依赖租金收入。但租赁业务毛利率已因新项目摊销成本激增而大幅下滑，若招商去化速度不及预期，租金收入无法覆盖新增折旧，亏损将成为常态。此外，公司存货（开发产品及成本）高达41亿元，其中38亿已用于抵押，若市场下行导致可变现净值低于成本，将面临大规模资产减值风险。

**财务杠杆高企，偿债压力不容忽视。** 公司总负债123亿，资产负债率60.67%，有息负债超100亿。虽然整体平均融资成本仅2.51%，但一年内到期的非流动负债高达21.9亿元，短期偿债压力巨大。公司已通过长期借款置换短期借款优化债务结构，但经营活动现金流净额仅0.51亿，远不足以覆盖短期债务。若融资环境收紧或销售回款持续低迷，公司将面临流动性风险。同时，公司持有的10.26亿金融资产（股票、基金）公允价值波动剧烈，进一步增加了利润的不确定性。
