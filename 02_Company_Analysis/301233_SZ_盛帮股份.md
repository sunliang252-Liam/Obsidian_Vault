# 301233.SZ 深度透视

## 因果逻辑链
- **[新工厂投产与产能释放]** -> [汽车类产品销量增长42%]: 新工厂于2025年初投用，规模化生产交付能力提升，直接支撑了用于比亚迪刀片电池的橡胶钉等产品量产落地，带动汽车类产品销量与收入双增。
- **[聚焦高端与剥离低效资产]** -> [净利润增速远低于营收增速]: 公司剥离了低附加值的四川贝特尔（其他类收入下降60.54%），但核心业务（汽车、电气、航空）毛利率均出现下滑，成本端压力（原材料、人工、制造费用）侵蚀了利润空间。
- **[下游市场需求结构性分化]** -> [航空类产品收入增长27.47%]: 受益于“十四五”收官年国防装备集中交付及国产大飞机项目推进，航空类产品需求显著提升，成为增长最快的业务板块。
- **[电网投资持续高景气]** -> [电气类产品收入增长15.14%]: 国家电网投资规模屡创新高，直接拉动了对中高压开关柜配套绝缘和密封产品的需求，电气类业务保持稳健增长。
- **[研发投入聚焦“新能源”与“国产化替代”]** -> [技术壁垒与客户黏性增强]: 公司围绕新能源汽车电池密封、大飞机燃油阀等方向进行技术攻关，成功开发新产品并突破核心技术，巩固了与比亚迪、中航工业等核心客户的合作关系。
- **[原材料价格波动与成本控制]** -> [毛利率承压]: 电缆附件配件受铜、银价格上涨影响显著，同时汽车类产品存在年降惯例，导致公司综合毛利率从40.15%下降至37.32%，盈利能力面临挑战。
- **[经营活动现金流大幅改善]** -> [财务质量提升]: 公司强化营运资金管理，加快资金回笼，经营活动现金流净额同比增长269.37%，显著改善了现金流状况，为后续投资提供了保障。

## 风险警告
**核心风险在于盈利能力的持续下滑。** 尽管营收增长9%，但净利润几乎原地踏步（+0.15%），毛利率从40.15%降至37.32%。这背后是多重压力：原材料（尤其是铜、银）价格上涨、汽车行业年降惯例、以及新工厂投产带来的折旧与制造费用增加。若公司不能通过产品结构升级或成本控制有效对冲，利润增长将持续落后于收入增长，甚至出现增收不增利的困境。

**另一重大风险是业务转型的不确定性。** 公司正从传统燃油车向新能源、从低端标准品向高端定制化转型。虽然剥离低效资产（四川贝特尔）是正确一步，但新能源车业务（如电池密封圈）目前仍处于量产验证初期，且面临氢能源等新技术路线的不确定性。同时，航空与核防护业务虽增长迅速，但体量尚小（合计占收入不足9%），短期内难以成为业绩支柱。转型过程中的研发投入与市场开拓成本，将持续考验公司的现金流与战略定力。
