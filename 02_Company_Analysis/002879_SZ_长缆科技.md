# 002879.SZ 深度透视

## 因果逻辑链
- **[变压器绝缘油业务并表及放量]** -> [营收增长15.97%]: 控股子公司双江能源全年并表，变压器绝缘油收入同比大增69.53%，贡献34.41%营收，成为第二增长曲线。
- **[员工持股计划终止，冲回前期费用]** -> [净利润暴增79.11%]: 报告期内终止员工持股计划，冲回前期已计提的股份支付费用约1.15亿元，直接导致销售、管理、研发费用率大幅下降，释放利润。
- **[超高压电缆附件技术壁垒与国产替代]** -> [巩固行业领先地位]: 750kV产品通过预鉴定试验，500kV产品在海上风电项目成功交付，实现国产替代，支撑高电压等级产品收入增长25.47%。
- **[营销体系改革，区域分公司模式]** -> [提升市场响应与中标率]: 撤销销售子公司，设立6大区域分公司及50余支销售团队，中标中广核新能源框架采购项目，实现向业主方市场拓展。
- **[国家电网集采份额领先]** -> [稳定基本盘]: 在国家电网35-220kV电缆附件采购中，中标量保持行业第一，确保电缆附件业务收入基本稳定（-0.52%）。
- **[应收账款催收力度加大]** -> [经营性现金流改善]: 报告期内应收账款余额较期初减少，经营活动现金流净额同比增长9.96%，与净利润增长匹配度提升。

## 风险警告
**核心风险在于利润高增长的可持续性。** 2025年净利润暴增79%，主要驱动力是员工持股计划终止带来的约1.15亿元非经常性费用冲回。剔除该影响后，公司扣非净利润增速（88.32%）虽高，但主要依赖低毛利的变压器绝缘油业务放量（毛利率仅16.03%），而核心的电缆附件业务收入同比下滑0.52%，毛利率也下降近5个百分点。主业增长乏力，新业务盈利质量不高，利润高增的成色需要警惕。

**应收账款与商誉风险不容忽视。** 公司应收账款及合同资产账面价值高达6.73亿元，占总资产近25%，尽管催收力度加大，但高额应收仍是现金流和资产质量的潜在压力。此外，收购双江能源形成的商誉高达6050万元，若未来变压器绝缘油业务竞争加剧或下游需求不及预期，存在商誉减值风险，将对利润造成直接冲击。
