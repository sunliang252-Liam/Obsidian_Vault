# 002181.SZ 深度透视

## 因果逻辑链
- **香榭丽诉讼案执行回款** -> **净利润暴增207%**: 2025年收到法院划转的被执行人履行判决款项约7,260万元，计入营业外收入，是归母净利润从3000万跃升至9200万的核心驱动力。
- **传统报刊广告及发行业务持续萎缩** -> **营收增长停滞**: 该板块收入同比下降5.47%，拖累整体营收同比微降0.48%，基本盘仍在收缩。
- **物业运营（粤传媒大厦）出租率提升** -> **租赁收入增长16.67%**: 大厦出租率达96.2%，商业部分满租，带动物业运营板块收入及毛利率显著提升，成为业绩稳定器。
- **商品销售业务放量** -> **营收结构变化**: 商品销售收入同比大增74.6%，但成本同步增长82.73%，毛利率极低，显示该业务处于规模扩张期，盈利能力有限。
- **AI视频与微短剧布局** -> **新业务探索**: G视频团队获奖并切入微短剧赛道，但研发投入仅244万元，尚处于早期投入阶段，未对当期利润产生实质贡献。
- **德粤基金投资收益稳定** -> **非经常性收益支撑**: 参股的德粤基金贡献投资收益约5,650万元，是公司除诉讼回款外的重要利润来源，但依赖被投项目公允价值变动。
- **财务费用下降** -> **利润增厚**: 提前偿还粤传媒大厦专项贷款，导致利息支出减少，财务费用同比下降21%，直接增厚利润。

## 风险警告
**核心风险在于利润的“一次性”与“不可持续”**。2025年净利润暴增207%，几乎完全依赖香榭丽诉讼案执行回款（约7,260万元）这一非经常性损益。剔除该笔收入后，扣非净利润仅增长12.94%至2,955万元，显示公司主营业务的盈利能力并未发生根本性改善。传统报刊广告与发行业务仍在萎缩，而新布局的AI视频、微短剧、数字营销等业务尚处于投入期，短期内难以弥补传统业务的下滑。

**第二重风险来自历史并购遗留的“黑洞”**。公司因收购香榭丽引发的证券虚假陈述责任纠纷诉讼仍在持续，截至报告期末已审结550个案件，但仍有大量潜在索赔。此外，与东方证券等中介机构的服务合同纠纷、侵权责任纠纷等诉讼金额合计超2.7亿元，这些未决诉讼可能在未来持续侵蚀公司利润。同时，子公司广报教育培训中心因计提大额信用减值导致亏损加剧，也暴露出部分业务单元的经营风险。
