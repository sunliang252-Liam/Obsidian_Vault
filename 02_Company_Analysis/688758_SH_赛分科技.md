# 688758.SH 深度透视

## 因果逻辑链
- **[工业纯化业务高速增长]** -> [营收与利润双升]: 工业纯化收入同比+45%，占比升至67.4%，成为核心营收支柱，驱动整体营收+27.7%、归母净利+48.6%。
- **[国产替代加速 + 客户项目落地]** -> [工业纯化订单爆发]: 抗体领域收入+136%，胰岛素/GLP-1领域+78%，得益于存量项目复购及新增29个临床III期/商业化项目。
- **[规模效应显现 + 费用管控]** -> [净利率显著提升]: 营收增长摊薄固定成本，管理费用仅+3.9%，归母净利率从27%提升至31.4%。
- **[核心技术壁垒 + 全流程服务]** -> [客户粘性增强]: 提供从填料筛选到工艺验证的全链条服务，核心客户收入占比88.8%，且替换成本高，客户不易流失。
- **[扬州二期 + 美国基地布局]** -> [产能储备优势]: 扬州二期预计新增20万升产能，美国基地规划5万升，形成“中国+美国”全球供应链，支撑出海与国产替代需求。
- **[分析色谱稳健增长]** -> [现金流与品牌基石]: 分析色谱收入+2.7%，全球客户超5000家，与Agilent、Thermo Fisher等长期合作，提供稳定现金流与品牌背书。
- **[研发投入持续高增]** -> [产品迭代与壁垒加固]: 研发费用+28.5%，推出耐碱亲和填料、核壳复合介质等新品，在ADC、双抗、核酸等前沿领域建立技术优势。

## 风险警告
**核心风险在于下游生物药研发与商业化进程的不确定性。** 公司业绩高度依赖客户项目的推进，若药企研发失败、临床进度延迟或商业化不及预期，将直接导致色谱耗材采购减少。尽管当前项目储备丰富（新增216个项目），但药物开发本身的高失败率与长周期是固有风险，尤其创新药企融资环境波动可能进一步抑制研发投入。

**竞争格局与供应链风险不容忽视。** 全球市场仍由Cytiva、Thermo Fisher等国际巨头主导，其品牌、规模及全产业链优势显著。公司虽在国产替代中占据先机，但若国际巨头降价反击或国内同行技术突破，将面临激烈价格战。此外，公司境外收入占比约22%，需警惕贸易摩擦、汇率波动及地缘政治对海外业务（尤其是美国生产基地建设）的潜在冲击。
