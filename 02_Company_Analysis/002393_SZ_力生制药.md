# 002393.SZ 深度透视

## 因果逻辑链
- **[投资收益大幅增长]** -> [净利润暴增125.59%]: 天士力分红款3亿元计入投资收益，贡献利润总额71.28%，是净利润从1.85亿跃升至4.16亿的核心驱动力。
- **[集采政策深化与原料制剂一体化]** -> [核心产品寿比山销量逆势增长32%]: 公司重构价值链、搭建分销体系，叠加原料自产的成本优势，在集采降价压力下实现量效齐升。
- **[精益生产与供应链优化]** -> [采购成本压降超5000万元]: 集中谈判、供应商优化、战略合作等举措，使采购成本压降率达12%，有效对冲了原料药价格上涨风险。
- **[研发投入聚焦缓控释技术]** -> [高端仿制药管线持续丰富]: 研发投入占营收8.28%，重点布局缓控释平台，氯化钾缓释片等产品获批，为未来集采中标储备品种。
- **[资本运作与资产盘活]** -> [产业布局与现金流改善]: 新设5亿元医药健康专项基金，盘活天士力股权收回分红款3亿元，经营活动现金流净额同比增长180.41%。
- **[子公司分类管控与协同]** -> [中央药业、生化制药利润增长]: 中央药业头孢地尼分散片销量增长23%，生化制药尿激酶收入增长31%，集团内资源协同效应显现。
- **[股权激励与人才激励]** -> [核心团队稳定性与积极性提升]: 2022年、2024年两期限制性股票激励计划落地，覆盖核心管理层与骨干，绑定长期利益。

## 风险警告
**核心风险在于利润结构高度依赖非经常性损益。** 2025年归母净利润4.16亿元中，非经常性损益高达2.48亿元（占比59.6%），其中天士力分红贡献了绝大部分。剔除该影响后，扣非净利润仅1.69亿元，同比增长63.62%，虽表现不俗，但远低于报表利润增速。一旦天士力分红政策变化或公司减持股权，利润将面临大幅回撤风险。

**集采扩围与药品价格持续下降是长期经营压力。** 公司核心产品寿比山虽通过营销改革实现增长，但片剂整体销量同比下降3.22%，胶囊、针剂等品类也面临量价承压。子公司昆仑制药持续亏损，显示部分业务板块竞争力不足。此外，子公司中央药业与凯安瑞医药的销售代理合同纠纷虽终审判决，但前期资产冻结及诉讼费用仍对经营造成扰动，合规与渠道管理风险犹存。
