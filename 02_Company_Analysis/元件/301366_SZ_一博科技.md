# 301366.SZ 深度透视

## 因果逻辑链
- **[新建工厂产能爬坡]** -> [净利润暴跌67%]: 珠海PCB工厂和天津PCBA工厂于2024年下半年试生产，2025年产能未有效释放，亏损额同比增加约4500万元，直接吞噬利润。
- **[PCB设计服务为基石]** -> [营收增长27%]: 公司以PCB设计服务为核心，与客户建立信任后延伸至PCBA制造，带动整体营收从8.88亿增至11.27亿。
- **[AI算力需求爆发]** -> [高端PCB业务增长]: 受益于AI算力投入竞赛，HDI、高多层等高端PCB需求快速增长，公司网络通信、人工智能领域收入分别增长33%和34%。
- **[规模化工程师团队]** -> [技术壁垒]: 拥有超900人的PCB设计工程师团队，人均经验6年以上，年设计超16,500款PCB，形成难以复制的规模优势。
- **[一站式服务模式]** -> [客户粘性]: 从设计、制板、元器件采购到PCBA焊接组装的全链条服务，满足客户研发阶段痛点，累计服务超9000家客户。
- **[人民币升值]** -> [汇兑损失增加]: 报告期末人民币升值导致美元、日元汇率下降，汇兑损失同比增加约450万元，侵蚀利润。
- **[非经常性损益下降]** -> [利润进一步承压]: 政府补助及银行理财收益同比减少约950万元，加剧了净利润的下滑幅度。

## 风险警告
**核心风险在于产能扩张与利润释放的严重错配。** 公司投资新建的珠海PCB工厂和天津PCBA工厂正处于产能爬坡期，2025年亏损额同比增加约4500万元，是净利润暴跌67%的首要原因。虽然公司声称“短期资本性支出为长期增长奠定基础”，但产能利用率何时达到盈亏平衡点、新增折旧摊销对利润的持续压制，是未来1-2年内最大的不确定性。若下游需求增速放缓或竞争加剧，新增产能可能成为沉重的财务负担。

**毛利率持续下滑与现金流恶化是第二重警报。** 公司综合毛利率同比下降4.78个百分点至28.54%，PCBA制造服务毛利率更是下降6.08个百分点，主要受人工成本上升和产能利用率不足拖累。同时，经营活动现金流净额同比骤降70%至4105万元，远低于净利润，反映出随着业务扩张，应收账款和存货占用了大量资金。这种“增收不增利、增利不增现”的态势，若不能通过产能爬坡和运营效率提升来扭转，将严重考验公司的财务健康度。
