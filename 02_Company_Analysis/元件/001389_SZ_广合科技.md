# 001389.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长46.89%]: 公司深度绑定全球前10大服务器制造商中的8家，AI服务器、高速交换机PCB需求激增，直接拉动营收从37.34亿跃升至54.85亿。
- **[产品结构向高端演进]** -> [毛利率提升至29.88%]: 公司聚焦高层数、高精度、高密度PCB（如OAM、UBB、800G交换机板），高毛利产品占比提升，抵消了原材料涨价压力，毛利率同比提升0.96个百分点。
- **[泰国工厂投产即盈利]** -> [海外产能释放]: 泰国广合2025年6月投产，12月即实现月度盈利，当年投产当年盈利，成为公司算力PCB销售的第二增长引擎，有效对冲贸易摩擦风险。
- **[研发投入加码56.14%]** -> [技术壁垒巩固]: 研发费用增至2.80亿元，完成PCIe 6.0、224G交换机板等前沿工艺认证，确保产品迭代与算力芯片同步，维持“制造业单项冠军”技术护城河。
- **[股权激励绑定核心团队]** -> [管理费用激增60.34%]: 2025年实施新一轮股权激励，确认股份支付及专业服务费增加，导致管理费用从1.32亿升至2.12亿，短期压制利润，但长期绑定人才。
- **[汇率波动与外汇对冲]** -> [财务费用大幅波动]: 外销占比约七成，人民币汇率波动导致汇兑损益变化，财务费用从-0.49亿（收益）转为0.29亿（支出），公司通过远期锁汇操作平滑风险。
- **[黄石广合扭亏为盈]** -> [子公司盈利能力改善]: 黄石广合通过成本管控和产品结构调整，2025年实现净利润9669万元，成功扭亏，成为公司利润的重要补充。

## 风险警告
**核心风险：客户高度集中与AI资本开支周期性。** 前五大客户销售占比高达60.74%，且深度绑定AI服务器赛道。一旦全球云厂商资本开支增速放缓或AI技术路线发生重大变化（如算力芯片迭代不及预期），公司订单量和盈利能力将面临剧烈波动。公司营收增速（46.89%）已显著高于行业平均（15.4%），高增长可持续性存疑。

**次要风险：汇率波动与贸易摩擦的叠加冲击。** 公司约七成收入来自境外且以美元计价，人民币升值将直接侵蚀利润。同时，中美科技博弈加剧，若美国进一步扩大对华PCB关税或技术封锁，公司海外业务（尤其是通过泰国工厂的转口贸易）可能面临合规与成本双重压力。此外，原材料（铜、黄金）价格波动对成本端的影响不容忽视。
