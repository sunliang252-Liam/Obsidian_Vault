# 600601.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长41.87%]: AI服务器、高速交换机、光模块等算力硬件需求激增，直接拉动公司PCB业务销量与结构升级。
- **[产品结构向高端化迁移]** -> [毛利率提升4.05个百分点]: 高多层板、HDI板等高附加值产品占比提升，带动PCB业务整体盈利能力增强。
- **[产能扩张与资本开支]** -> [在建工程/其他非流动资产翻倍]: 珠海、重庆、泰国三大基地同步扩建，资本开支大幅增加，为未来高端产能释放奠定基础。
- **[股权激励绑定核心团队]** -> [管理费用增长43.62%]: 实施限制性股票激励计划，确认股份支付费用，短期推高管理费用，但长期利于稳定核心团队。
- **[原材料成本上涨]** -> [PCB业务成本中原材料占比升至57.42%]: 覆铜板、铜球等大宗商品价格波动，直接推高生产成本，考验公司成本传导能力。
- **[海外产能布局]** -> [境外资产占比18.52%]: 泰国工厂进入产能爬坡，提升全球交付能力，同时增加海外运营与汇率波动风险。
- **[母公司未分配利润仍为负]** -> [无法进行现金分红]: 历史亏损累计高达-41.36亿元，尽管当期盈利，但分红能力仍受严重制约。

## 风险警告
**1. 巨额历史亏损与分红能力缺失：** 母公司未分配利润仍为-41.36亿元，尽管2025年净利润大增83.46%，但累计亏损窟窿巨大，导致公司连续多年无法进行现金分红。这严重制约了股东回报，并可能影响市场对公司的估值逻辑。

**2. 激进扩张下的现金流与盈利压力：** 公司同时推进珠海、重庆、泰国三大基地建设，总投资规模超40亿元，导致投资活动现金净流出高达17.56亿元。大规模资本开支叠加原材料成本上涨、海外工厂爬坡期的不确定性，若下游AI需求增速放缓或产能释放不及预期，公司可能面临现金流紧张与资产减值风险。

**3. 客户集中度与行业竞争加剧：** 前五大客户销售额占比高达53.90%，存在大客户依赖风险。同时，PCB行业“高端集中、中低端分散”格局下，头部企业扩产提速，若公司无法在技术迭代（如FVS、UHD）和成本管控上持续领先，市场份额可能被挤压，盈利空间收窄。
