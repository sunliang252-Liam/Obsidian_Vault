# 000636.SZ 深度透视

## 因果逻辑链
- **[营收创历史新高]** -> [规模效应]: 全年营收57.56亿元，同比增长16.54%，主营产品产销量均创历史新高，规模扩张驱动收入增长。
- **[毛利率承压]** -> [利润下滑]: 归母净利润2.83亿元，同比下降16.02%，主因金属材料价格翻倍、新增固定资产折旧及汇率波动，成本端压力侵蚀利润。
- **[极致降本对冲]** -> [盈利韧性]: 通过P1-P10公司级项目极致降本与精益生产，有效对冲了原材料涨价和转固高峰对利润的较大影响，体现运营韧性。
- **[高端市场突破]** -> [结构优化]: 汽车电子、通讯、工控板块销售额分别同比增长16%、25%、16%，前十大客户销售额增长20.03%，高端市场占有率稳步提升。
- **[研发投入加码]** -> [技术壁垒]: 研发投入2.84亿元，同比增长18.13%，关键材料（纳米晶瓷粉、超细镍浆）与核心工艺取得突破，高端车规MLCC、精密厚膜电阻等产品完成客户认证。
- **[新兴赛道布局]** -> [增长引擎]: 超级电容器销售额同比增长46.08%，AI算力、储能、低空经济等新兴市场向40余家标杆客户导入500余款产品，新品类贡献增量。
- **[现金流承压]** -> [资本开支]: 经营活动现金流净额4.26亿元，同比下降5.99%；投资活动现金流净额-7.41亿元，同比大幅流出173.33%，主因采购机器设备及购买大额存单，资本开支处于高峰期。

## 风险警告
**成本与利润剪刀差风险**：公司营收创历史新高，但归母净利润同比下降16.02%，扣非净利润降幅达19.87%。核心矛盾在于原材料（金属材料价格翻倍）和折旧（转固高峰）等成本端刚性上涨，而产品提价能力尚不足以完全覆盖。若成本压力持续而毛利率提升不及预期，公司可能陷入“增收不增利”的困境，盈利修复节奏将慢于市场预期。

**高端化转型不及预期风险**：公司战略核心是向高端市场（车规、AI算力等）转型，但当前毛利率仅17.75%，且同比下滑1.43个百分点，说明高端产品放量尚未形成规模效应以拉高整体盈利水平。同时，高端产品量产爬坡有待加速，研产协同仍有短板。若技术突破无法快速转化为规模效益和客户订单，公司可能面临“高投入、低回报”的转型阵痛期，估值逻辑难以重塑。
