# 600563.SH 深度透视

## 因果逻辑链
- **[新能源市场增长]** -> [营收与利润双增]: 新能源汽车、光伏、储能等下游需求拉动，2025年营收53.27亿元(+11.64%)，归母净利11.92亿元(+14.72%)。
- **[内销增速远超外销]** -> [收入结构优化]: 内销收入41.38亿元(+13.60%)，外销10.36亿元(+2.97%)，内销占比提升，对冲出口市场波动风险。
- **[原材料成本上升]** -> [毛利率承压]: 聚丙烯膜、有色金属等主要原材料价格上涨，导致主营业务毛利率下降1.67个百分点至30.53%。
- **[研发投入持续]** -> [技术壁垒巩固]: 研发费用1.87亿元(+12.06%)，聚焦新能源、数据中心等领域，成功中标国家柔直工程干式电容器国产化首批项目。
- **[规模效应与自动化]** -> [成本控制]: 年产28.60亿只薄膜电容，通过提升设备自动化水平、精益生产，在成本上升背景下维持了较强的盈利能力。
- **[高比例现金分红]** -> [股东回报稳定]: 2025年拟每10股派23元，分红5.175亿元，占归母净利润43.41%，上市以来累计分红43.8亿元。
- **[金融资产收益增厚]** -> [非经常性损益贡献]: 交易性金融资产公允价值变动收益4984万元，叠加理财收益，非经常性损益达6385万元，增厚利润。

## 风险警告
**核心风险在于原材料价格波动与毛利率下行趋势。** 公司主要原材料聚丙烯膜、聚酯膜和有色金属占生产成本比重较大，2025年已导致毛利率下降1.67个百分点。若未来原材料价格持续上涨或高位运行，将进一步压缩利润空间，侵蚀公司核心盈利能力。

**出口市场面临地缘政治与汇率双重不确定性。** 公司外销收入占比约20%，地缘政治局势变化、贸易保护政策抬头，以及人民币汇率波动，均可能对出口业务造成冲击。2025年外销增速已显著低于内销，显示外部环境压力。
