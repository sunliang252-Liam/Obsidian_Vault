# 300903.SZ 深度透视

## 因果逻辑链
- **[产能爬坡与折旧高企]** -> [连续三年亏损]: 江西、赣州等新基地产能利用率不足，固定摊销成本吞噬利润，2025年归母净亏损2.46亿元。
- **[产品结构低端化]** -> [PCB业务毛利率为负]: 传统单双面板及低层板陷入价格战，PCB制造毛利率为-2.17%，收入增长9.56%但无法覆盖成本。
- **[研发聚焦高端转型]** -> [亏损收窄28.32%]: 研发投入2.11亿元（占营收5.67%），重点突破AI服务器、高阶HDI、光模块技术，带动亏损幅度同比收窄。
- **[专业化工厂定位]** -> [提升制造效率]: 将各工厂按产品线（光模块、HDI、电源板、陶瓷基板）重新定位，实现设备与工艺的精准匹配，降低单位成本。
- **[客户生态深度绑定]** -> [收入增长9.56%]: 前五大客户销售占比29.23%，与比亚迪、华勤技术等核心客户形成长期合作，为专业化转型提供“种子业务”。
- **[经营现金流大幅转正]** -> [盈利质量改善]: 经营活动现金流净额从-0.27亿元跃升至1.61亿元，主要得益于销售回款增加，但净利润仍为负。
- **[融资租赁与债务扩张]** -> [财务费用激增39.44%]: 为产能扩张大量采用融资租赁和银行借款，利息支出及汇兑损失增加，财务费用达0.48亿元。

## 风险警告
**核心风险在于产能爬坡与盈利拐点的不确定性。** 公司连续三年亏损，2025年归母净利润-2.46亿元，PCB主业毛利率为负（-2.17%）。尽管营收增长9.56%，但主要依赖低毛利产品放量，高附加值产品（AI服务器、高阶HDI）尚未形成规模利润。江西科翔、赣州科翔二厂等新基地仍处于亏损状态，产能利用率不足导致折旧摊销持续侵蚀利润。若高端转型不及预期，亏损可能进一步扩大。

**财务风险高企，流动性承压。** 公司资产负债率较高，短期借款12.18亿元，长期借款1.77亿元，且大量资产用于融资抵押（受限资产8.46亿元）。财务费用同比增长39.44%，利息支出吞噬利润。同时，公司存在多起未决诉讼及资产冻结情况，资金链紧绷。若融资环境收紧或客户回款放缓，可能引发流动性危机。
