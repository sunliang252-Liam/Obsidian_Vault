# 300476.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收与利润高速增长]: 公司精准把握AI算力技术革新与数据中心升级浪潮，深度绑定国际头部客户，多款高端AI算力卡、数据中心UBB及交换机产品实现大规模量产，推动营收同比增长79.77%，净利润同比增长273.52%。
- **[产品结构向高端化升级]** -> [盈利能力大幅提升]: 公司聚焦高多层板、高阶HDI等高端产品，AI相关产品占比显著提升，带动产品均价与毛利率上行，使净利润增速（+273.52%）远超营收增速（+79.77%）。
- **[全球化“中国+N”布局]** -> [海外收入占比跃升]: 公司通过收购MFS集团及在泰国、越南、马来西亚建厂，构建全球交付网络，直接出口收入同比增长126.88%，占总营收比重从60.88%提升至76.83%。
- **[智慧工厂与数字化转型]** -> [降本增效与人均产值提升]: 公司建成PCB行业领先的智慧工厂，通过MES+ERP+AI等系统实现生产流程高度自动化，有效降低能耗与人力成本，人均产值屡创新高。
- **[高强度研发投入]** -> [构筑技术护城河]: 2025年研发投入7.78亿元，同比增长72.88%，聚焦高阶HDI、超高多层板、信号完整性等前沿技术，率先突破100层以上高多层板及10阶30层HDI技术，巩固全球PCB供应商第6名地位。
- **[持有方正科技股权]** -> [公允价值变动增厚利润]: 公司持有方正科技（600601）等上市公司股权，报告期内公允价值变动损益及计入权益的累计公允价值变动合计超17亿元，对净利润及净资产产生显著正面影响。
- **[并购整合MFS集团]** -> [产品线拓展至FPC]: 2023年完成对MFS集团的收购，使公司产品从刚性电路板拓展至柔性电路板（FPC）全系列，形成全品类PCB产品组合，增强了客户一站式服务能力。

## 风险警告
**1. 客户集中度与AI需求周期性风险**：公司前五大客户销售额占比高达41.98%，且业绩增长高度依赖AI算力相关需求。若主要客户流失或AI资本开支周期出现下行，公司营收与利润可能面临剧烈波动。此外，公司持有大量方正科技股权，其股价波动会直接影响公司当期利润，增加了业绩的不确定性。

**2. 海外运营与汇率波动风险**：公司海外收入占比已超76%，且正大规模投资泰国、越南等海外生产基地。东南亚地区在法律、供应链、文化及人力资源方面与国内存在显著差异，海外工厂建设及运营面临管理、合规及效率风险。同时，大量美元结算收入使公司面临显著的汇率风险，报告期内财务费用因汇兑损失同比大增467.07%，侵蚀了部分利润。

**公司简介（F10 原文）**

> 胜宏科技(惠州)股份有限公司于2006年7月落户广东省惠州市惠阳区淡水街道行诚科技园,在职员工1万人(全球约1.6万人)。2015年6月在深交所创业板上市,股票代码:300476。公司是全球领先的人工智能及高性能计算PCB供应商,专注于高阶HDI、高多层PCB的研发、生产和销售,产品广泛应用于人工智能、新能源汽车、高速网络通信等高增长领域。凭借前瞻性的战略布局及卓越的技术转化能力,不断突破PCB前沿技术、打造了多元化产品组合,构建了覆盖单层及双层PCB、高多层PCB、高阶HDI及FPC的全品类产品组合,服务超过350家需求庞大的全球客户。公司是CPCA副理事长单位,行业标准的制定单位之一,拥有省级工程技术研发中心和省级企业技术中心,拥有线路板领域有效专利,连续四年获“中国专利优秀奖”。先后通过ISO9001、QC080000、IATF16949、UL2799及ISO27001等多项体系认证,获评“国家高新技术企业”、“国家知识产权优势企业”、“国家级绿色工厂”、“广东省创新型企业”、“优秀民族品牌企业”等荣誉称号。公司通过实施智慧工厂、绿色制造、高技术/高品质/高质量服务的“三大战略”,推进观念、科技、人才和资本“四个创新”,成功打造同行业中国第一家新一代工业互联网智慧工厂。公司积极参与客户产品预研,深化与全球头部科技行业客户战略合作。凭借战略优势、技术优势和品质优势,已成为众多海外及中国头部科技企业的核心合作伙伴,在AI算力、AI机器人、无人驾驶、虚拟现实等领域取得领先优势,在行业内树立了标杆地位。
