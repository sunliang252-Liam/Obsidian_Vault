# 603328.SH 深度透视

## 因果逻辑链
- **[聚焦汽车电子与计算通信]** -> [营收增长14.80%]: 坚定执行大客户战略，在汽车电子、计算与通信领域提升份额，带动10层以上高层板、HDI板等中高端产品销售额快速增长。
- **[产品结构向高端化调整]** -> [毛利率承压]: 原材料价格持续攀升，叠加下游市场竞争加剧，导致主营业务毛利率同比减少1.26个百分点。
- **[内销市场高速增长]** -> [优化收入结构]: 紧抓新能源汽车与智能驾驶机遇，与比亚迪、零跑等战略客户合作规模显著提升，内销收入同比增长40.09%，有效对冲外销增长放缓。
- **[研发投入持续加大]** -> [技术壁垒提升]: 研发费用同比增长16.53%，在ADAS域控制器、毫米波雷达、服务器平台等关键技术领域取得突破，为高端产品导入奠定基础。
- **[泰国工厂建设推进]** -> [全球化产能布局]: 泰国生产基地完成厂房建设，规划产能50万平方米/年，旨在承接海外订单，降低地缘政治风险，拓展国际一线客户。
- **[销售回款大幅增加]** -> [现金流显著改善]: 经营活动现金流量净额同比增长130.55%，达到8.39亿元，反映出公司销售回款能力增强，财务健康状况良好。
- **[财务费用由负转正]** -> [汇兑损失侵蚀利润]: 因美元兑人民币汇率波动，本期产生汇兑损失，导致财务费用从-5395万元大幅增加至1201万元，对净利润增长构成拖累。

## 风险警告
**核心风险在于汇率波动与成本侵蚀。** 公司外销收入占比超60%，主要以美元结算，而成本端以人民币计价。2025年财务费用因汇兑损失由负转正，直接侵蚀了利润增长。若人民币进入升值通道，将对公司盈利能力造成显著压力。同时，上游覆铜板、铜箔等原材料价格持续攀升，而下游竞争激烈导致产品提价空间有限，毛利率已出现下滑，成本管控能力面临严峻考验。

**第二重风险来自新产能爬坡与市场拓展的不确定性。** 泰国生产基地将于2026年一季度试产，初期面临设备调试、良率提升、客户认证等挑战，产能释放节奏存在不确定性。此外，公司虽聚焦AI、算力等高增长领域，但高端PCB市场竞争激烈，技术迭代迅速，若新产品（如AI服务器板）开发或客户导入不及预期，将影响公司百亿营收目标的实现。
