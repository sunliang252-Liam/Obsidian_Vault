# 301176.SZ 深度透视

## 因果逻辑链
- **[铜箔行业产能过剩，加工费低位]** -> [公司亏损]: 前期新建产能持续释放，行业竞争加剧，铜箔加工费全年处于相对低位，压制盈利水平。
- **[PCB业务处于产能爬坡期]** -> [亏损扩大]: 投产年限短、客户积累不足，产能利用率未达预期，导致PCB业务整体亏损，拖累公司整体利润。
- **[新增产能释放，资产规模扩大]** -> [资产减值损失增加]: 铜箔募投项目投产，应收账款和存货相应增长，公司依规计提资产减值准备（含信用减值损失），侵蚀利润。
- **[AI与新能源驱动下游需求]** -> [营收增长]: 2025年AI与新能源双轮驱动，电子电路铜箔和PCB销售收入分别同比增长22.27%和20.01%。
- **[研发投入持续加大]** -> [产品结构优化]: 成功研发105-210μm超厚铜箔、9-12μm HDI用铜箔等高端产品，推动产品向高附加值方向升级。
- **[垂直产业链布局]** -> [协同效应]: 自产铜箔用于PCB生产，实现材料与PCB串联研发，降低成本并提升客户响应效率。
- **[高端产品进口替代空间广阔]** -> [未来增长潜力]: 国内高端电子电路铜箔（如HVLP）依赖进口，公司HVLP铜箔研发与认证推进，有望切入AI算力供应链。

## 风险警告
公司连续三年亏损且亏损额扩大，核心症结在于铜箔主业深陷“增收不增利”困境。尽管营收增长近20%，但行业产能过剩导致加工费持续低迷，毛利率仅3.25%，叠加PCB新业务尚处爬坡期、资产减值损失高企，盈利能力被严重侵蚀。若铜箔行业供需格局无法改善，或PCB业务不能快速实现盈利，公司经营风险将持续暴露。

财务风险显著攀升。应收账款与存货随营收扩张而激增，合计占资产比例超34%，且已计提大额减值准备。同时，短期借款翻倍至3.84亿元，财务费用同比激增98%，现金流持续为负，公司营运资金高度依赖外部融资，流动性压力不容忽视。
