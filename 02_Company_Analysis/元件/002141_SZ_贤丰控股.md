# 002141.SZ 深度透视

## 因果逻辑链
- **[覆铜板业务规模扩张]** -> [营收暴增162%]: 2024年末新增的覆铜板业务在2025年全年运营，贡献7.49亿收入，成为营收绝对主力。
- **[处置非核心资产]** -> [净利润扭亏为盈]: 出售珠海厂房土地确认非经常性损益4447万元，直接覆盖了主业亏损，使归母净利润转正至1569万元。
- **[饲料业务终止]** -> [营收结构剧变]: 2025年9月终止饲料业务，该业务全年贡献3.21亿收入，但毛利率仅0.1%，对利润贡献微乎其微。
- **[应收账款与固定资产减值]** -> [扣非净利润仍为负]: 覆铜板业务扩张导致应收账款激增，计提信用减值2090万元；史纪生物计提固定资产减值2671万元，合计侵蚀利润，扣非净利润仍亏损2182万元。
- **[兽用疫苗业务毛利率提升]** -> [核心业务盈利能力改善]: 史纪生物通过降本增效和产品结构优化，毛利率从40.75%提升至43.52%，但收入规模仍较小（4880万元），未能扭转整体亏损。
- **[控股股东破产清算]** -> [控制权稳定性风险]: 控股股东贤丰集团已被裁定破产清算，其持有的11.05%股份全部被质押/冻结，公司控制权存在不确定性。
- **[新股东放弃表决权]** -> [治理结构特殊]: 第一大股东安盛致和（持股19.18%）承诺放弃全部表决权至2026年10月，导致公司处于无实际控制人状态，决策机制依赖现有管理层。

## 风险警告
公司最大的风险在于**控股股东贤丰集团的破产清算**。其持有的全部股份已被质押冻结，未来可能被司法拍卖，导致公司控制权发生根本性变更。尽管新股东安盛致和放弃了表决权，但公司治理结构处于非常规状态，管理层稳定性与战略连续性存疑。

其次，**主业盈利能力堪忧**。营收暴增主要依赖低毛利的覆铜板业务（毛利率仅5.72%），且该业务扩张伴随大量应收账款，坏账风险高。核心的兽用疫苗业务虽有技术储备，但收入规模小，在行业价格战中难以突围。公司扣非净利润连续三年为负，表明自身造血能力严重不足，扭亏完全依赖非经常性损益。
