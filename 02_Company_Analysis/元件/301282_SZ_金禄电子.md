# 301282.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升]** -> [营收增长28.74%]: 公司深度绑定国内头部动力电池及BMS厂商，受益于新能源汽车产销两旺，BMS用PCB需求持续放量。
- **[多层板收入占比提升]** -> [产品结构优化]: 多层板收入同比增长36.32%，占PCB收入比重升至79.69%，高附加值产品占比提升带动整体营收规模扩张。
- **[铜价与金价大幅上涨]** -> [毛利率承压]: 原材料成本占营业成本66%，铜、金价格上行直接推高覆铜板、金盐采购成本，PCB业务毛利率下降2.61个百分点。
- **[清远PCB扩建项目延期]** -> [短期产能受限]: 因AI算力产线适配及高端设备交付延迟，项目进度不及预期，新增面向AI/算力的高端产能释放推迟至2026年下半年。
- **[子公司百芳电子亏损]** -> [拖累整体利润]: 特种PCB子公司尚处起步阶段，产能利用率低，全年亏损1755万元，对合并净利润形成负向影响。
- **[研发投入增长29.25%]** -> [技术升级铺垫]: 重点研发AI服务器PCB、高阶HDI、900V电驱PCB等，为切入算力、商业航天等新赛道储备技术能力。
- **[经营活动现金流大增202%]** -> [盈利质量改善]: 净利润提升、客户回款加快及收到大额政府补助，使经营性现金流净额达1.5亿元，显著高于净利润。

## 风险警告
**核心风险在于原材料成本侵蚀与新兴赛道拓展的不确定性。** 铜、金价格持续上行，直接推高覆铜板、金盐等核心原材料成本，而公司向下游客户传导价格的能力有限，2026年一季度已对盈利能力产生重大不利影响。若全年铜金维持高位，公司毛利率将面临进一步压缩，利润增长可能显著落后于营收增速。

**第二增长曲线尚未成型，算力与商业航天业务存在较大不确定性。** 公司在20层以上刚性板、高阶HDI等算力主流PCB领域技术积淀不足，且缺乏海外算力客户基础，清远新产能的AI适配进度已明显滞后。商业航天业务收入不足千万，子公司仍处亏损，客户验证周期长、订单规模小，短期内难以形成量级贡献。公司过度依赖汽车电子单一赛道，若新能源汽车增速放缓或竞争加剧，业绩弹性将受限。
