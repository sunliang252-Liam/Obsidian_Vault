## 因果逻辑链
- **[商业航天高景气]** -> [营收增长17.32%]: 受益于商业火箭密集发射（朱雀三号首飞），航天传感器配套业务放量，带动整体营收增长。
- **[扣非净利润下降38.37%]** -> [盈利能力承压]: 成本上升（客户要求提高）、研发费用增加、信用减值损失扩大、股权激励费用确认，多重因素侵蚀核心利润。
- **[研发高投入]** -> [技术壁垒构筑]: 研发费用占营收18.38%，聚焦MEMS芯片、传感器网络系统，支撑“芯片+器件+系统”一体化转型。
- **[政府补助依赖]** -> [利润结构脆弱]: 计入当期损益的政府补助占营业利润41.44%，扣除此类非经常性损益后，真实盈利能力大幅缩水。
- **[应收账款高企]** -> [现金流压力]: 应收账款账面价值4.69亿元，占总资产23.25%，军品客户回款慢，导致经营性现金流虽有改善但仍显紧张。
- **[股权激励落地]** -> [绑定核心团队]: 2025年首次股权激励授予75名核心人员，以营收增长为考核指标，激发内部动力，但短期增加费用负担。
- **[传感器网络系统放量]** -> [第二增长曲线]: 该业务收入同比增长76.15%，主要受益于冶金行业智能化改造需求，成为除传统传感器外的新增长点。
- **[军品暂定价风险]** -> [业绩不确定性]: 28.09%的收入以暂定价确认，军方审价周期长，未来价格调整可能导致收入及利润大幅波动。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长17.32%，但扣非净利润却大幅下滑38.37%，显示其核心业务的盈利能力正在恶化。成本端，客户对高性能产品的需求推高了营业成本；费用端，持续的研发高投入和股权激励费用侵蚀利润；资产端，应收账款和存货高企带来减值风险。这种“虚胖”的增长模式，若不能通过规模效应或产品提价来消化，将严重损害股东价值。

**另一重大风险是业绩对政府补助和投资收益的过度依赖。** 公司非经常性损益高达3388万元，占净利润的56.5%，其中政府补助和理财收益是主要来源。剔除这些一次性收益后，公司真实盈利能力非常薄弱。一旦政策变化或市场波动导致这部分收益减少，公司净利润将面临断崖式下跌。投资者需警惕其商业模式的可持续性，而非被表面的净利润数字所迷惑。
