# 301041.SZ 深度透视

## 因果逻辑链
- **原材料价格上涨（金盐、铜球、锡条等）** -> 毛利率承压: 国际贵金属价格高位运行，直接推升中高端PCB产品成本，导致整体毛利率同比下降2.43个百分点。
- **战略投入前置（数字化平台、AI、人才）** -> 短期利润侵蚀: 公司处于“制造+服务+平台”模式升级关键期，PCB、IPM、造物数科等板块的基建与研发投入尚未形成规模化利润贡献。
- **PCB业务高端化转型（AI服务器、800G光模块）** -> 营收稳健增长: 聚焦高多层、高可靠性产品，PCB业务收入同比增长6.14%，成为营收增长的压舱石。
- **汽车电子与医疗电子赛道突破** -> 结构优化: 汽车电子收入同比+97.77%，医疗电子+14.08%，高附加值领域增长有效对冲了消费电子需求疲软。
- **经营活动现金流大幅改善** -> 运营质量提升: 销售回款增加与采购付款减少共同作用，经营性现金流净额同比+84.27%，远超净利润增速。
- **国际化布局（香港、新加坡）** -> 打开成长天花板: 境外销售占比提升至21.07%，海外AI硬件与高端工业客户拓展成为中长期增长极。
- **AI赋能工程平台（造物数科）** -> 效率提升: 日均订单吞吐量从140款提升至220款，智能化手段解决300余项自动化痛点，工程服务效率显著改善。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收微增2.62%，但归母净利润暴跌48.39%，扣非净利润更是骤降80.35%。根本原因在于原材料成本刚性上涨与战略投入前置的双重挤压，而下游价格竞争加剧导致成本传导不畅。若金盐、铜球等关键原材料价格持续高位，或新业务（数字化、科创服务）商业化进程慢于预期，利润端可能进一步承压，甚至出现亏损。

**另一重大风险是战略转型的“时间差”与“规模兑现”不确定性。** 公司正从传统PCB制造向“制造+服务+平台”模式迁移，但数字化平台（造物数科）、科创服务（云创硬见）等新业务仍处于投入培育期，尚未形成规模化利润贡献。若AI终端中试平台、产业互联网等新增长点无法在1-2年内实现商业闭环，公司可能面临“旧业务利润被侵蚀、新业务造血不足”的困境，导致估值逻辑难以重塑。

> 深圳市金百泽电子科技股份有限公司专注电子产品研发和硬件创新领域,聚焦电子互联技术,致力成为特色的电子设计和制造的集成服务商,主营印制电路板、电子制造服务和电子设计服务。公司不断强化印制电路板样板业务广受业内认可的地位,并以样板制造为入口,满足客户的产品研发对电子制造和电子设计的需求。公司具备样板和中小批量的柔性制造和快速交付能力,通过开展方案设计、高速电路板设计、印制电路板制造、电子装联、元器件齐套和检测等全价值链服务,为客户的产品研发和硬件创新提供垂直整合的一站式解决方案。公司成立于1997年,总部设在深圳,研发和生产分布在深圳、北京、惠州、西安、杭州等城市。经过二十余年的业务积累,公司建立了适应多品种、小批量的设计、生产和服务的柔性化平台,培养了一批电子电路产业链的复合型团队,形成了具有优势的技术链和供应链。凭借高效、高质、高速的研发服务,公司已经与来自全球的超过15,000家客户建立了良好的合作关系。
