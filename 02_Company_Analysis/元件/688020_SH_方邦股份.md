# 688020.SH 深度透视

## 因果逻辑链
- **[电磁屏蔽膜量价承压]** -> **营收增长乏力**: 全球智能手机需求放缓及行业竞争加剧，导致屏蔽膜销量下滑、售价承压，拖累整体营收增速仅3.79%。
- **[高端产品结构优化]** -> **亏损收窄**: 高端屏蔽膜、RTF铜箔（+339.45%）、FCCL（+71.21%）及电阻薄膜等高毛利产品放量，部分对冲了普通产品下滑及铜箔业务亏损。
- **[铜箔业务持续亏损]** -> **资产减值与投资损失**: 铜箔生产成本高于行业均值，导致相关固定资产组计提减值2,498.72万元；同时参股公司因实控人违规担保计提公允价值变动损失1,500万元。
- **[可剥铜国产替代突破]** -> **新增长极初现**: 可剥铜通过头部芯片终端量产认证并获小批量订单，销售额持续增长，同时专项受托开发项目结项贡献利润929.25万元。
- **[高强度研发投入]** -> **技术壁垒构建**: 研发费用占营收17.38%，持续投入四大基础技术平台，为可剥铜、FCCL、电阻薄膜等新产品提供底层技术支撑。
- **[原材料自研自产战略]** -> **长期成本优势与短期认证阵痛**: 自产铜箔+自产PI/TPI生产FCCL的策略，虽延长了客户认证周期，但旨在打破国外供应链依赖，建立核心成本壁垒。

## 风险警告
**核心风险在于铜箔业务的“失血”与新产品放量的“赛跑”。** 公司连续三年亏损，核心拖累是铜箔业务，其生产成本高于行业平均，导致毛利率为负（-1.24%），并引发持续的固定资产减值。若可剥铜、自产原材料FCCL等新产品不能快速通过认证并实现规模化订单，铜箔业务的亏损将难以扭转，公司业绩存在继续亏损甚至进一步减值的风险。

**另一重大风险来自外部投资“暴雷”与行业竞争加剧。** 公司对江苏上达半导体的投资因对方实控人违规担保而计提大额损失，暴露了对外投资的风控短板。同时，屏蔽膜基本盘受制于消费电子存量竞争和终端降本压力，毛利率持续承压。公司能否在“老产品”利润被侵蚀前，依靠“新产品”建立起足够体量的第二增长曲线，是决定其能否扭亏为盈的关键。

> 广州方邦电子股份有限公司(以下简称“公司”)是国内首批、广州市第一家科创板上市企业,证券名称:“方邦股份”,证券代码:“688020”,同时为国家首批专精特新“小巨人”企业。公司位于广州开发区,成立于2010年12月,是集研发、生产、销售和服务于一体的稀缺高端电子专用材料平台型企业,目前主要产品有:电磁屏蔽膜、极薄挠性覆铜板、薄膜电阻、超薄可剥离铜箔等,产品广泛应用于5G通讯、芯片封装、汽车电子以及AI服务器等领域,终端应用客户包括三星、华为、OPPO、VIVO、小米等国内外知名品牌。其中在2012年推出的电磁屏蔽膜,打破了日本企业在该领域的技术垄断,目前电磁屏蔽膜产品的市场占有率已位居国内第一、全球第二位,产品性能国际领先。公司始终将技术创新作为企业发展的根本动力,产品的主要生产工艺及核心生产设备均系自主研发设计,全部产品拥有自主知识产权。公司是国家高新技术企业,同时获得了广东省工程技术中心、广东省创新型企业、广东省优秀品牌示范企业、广州市企业技术中心,广州市独角兽创新企业等资质和荣誉。公司深耕高端电子材料行业10余年,已构建了真空技术、精密涂布技术、合成技术、电解技术等四大技术平台,可实现横向多技术协调组合创新、纵向单项技术深度延伸的良好研发局面,形成强大的高端电子材料开发能力,致力于成为世界级的高端电子材料制造商,解决方案的提供者。
