# 603336.SH 深度透视

## 因果逻辑链
- **[消费疲软与行业供给过剩]** -> [果蔬主业收入下滑17.08%]: 居民消费意愿下降，水果作为可选消费品需求被挤压，同时国内产量与进口量攀升导致市场供过于求，公司主动控制存货规模。
- **[新业务投入期与资产转固]** -> [扣非净利润暴跌44.68%]: 广东宏辉食品等新项目处于运营初期，团队搭建、市场拓展费用高企，叠加项目转固增加折旧摊销，侵蚀核心利润。
- **[控制权变更与战略调整]** -> [资产剥离与治理重构]: 新控股股东申泽瑞泰入主，推动出售烟台、福建两家低效子公司，盘活资产，并引入苏州资管集团资源，开启战略升级。
- **[可转债转股与赎回]** -> [资本结构优化]: 报告期内大量可转债转股，股本增加，同时偿还债务，导致资产负债率从39.53%大幅降至19.78%，财务风险显著降低。
- **[肉类贸易业务爆发]** -> [营收结构多元化]: 新增出口业务，精准把握市场走势，肉类贸易收入同比大增121.02%，成为公司营收增长的主要驱动力，弥补了果蔬主业的下滑。
- **[新业务品牌力不足]** -> [食品与食用油板块承压]: 速冻食品和食用油作为后进入者，面临头部品牌挤压，品牌认知度低，产品同质化，导致收入分别下滑2.97%和12.47%。
- **[经营活动现金流大幅改善]** -> [运营效率提升]: 通过加强回款和优化采购支付，经营活动现金流净额从3539万元飙升至2.05亿元，表明公司现金流管理能力增强。

## 风险警告
**主业萎缩与新业务亏损的双重挤压。** 公司核心果蔬业务受宏观消费疲软和行业供给过剩冲击，收入下滑17%，而作为第二增长曲线的速冻食品和食用油业务，因品牌力薄弱和市场竞争激烈，不仅未能贡献利润，反而持续亏损，拖累整体盈利能力。公司正处于新旧动能转换的阵痛期，若果蔬主业无法企稳，新业务无法快速突破，业绩将持续承压。

**控制权变更后的整合风险。** 新控股股东申泽瑞泰及其背后的苏州资管集团，与公司原有业务体系存在较大差异。新管理层团队多来自医药和金融领域，其对果蔬、食品等消费行业的运营能力尚待验证。同时，公司已成立医药技术子公司，存在跨界探索的不确定性。若战略协同无法有效落地，或新老团队融合不畅，将带来管理风险和经营波动。
