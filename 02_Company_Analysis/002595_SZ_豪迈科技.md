# 002595.SZ 深度透视

- **[全球燃气轮机需求爆发（AI数据中心+煤电替代）]** -> [大型零部件业务收入增长18.97%]: 燃气轮机巨头产能售罄至2028年，公司作为核心供应商订单饱满，产线满负荷运转。
- **[新能源汽车渗透率提升驱动轮胎迭代]** -> [轮胎模具业务收入增长18.44%]: 轮胎企业为提升差异化竞争力，加速花纹设计迭代，带动模具更新替换与增量需求。
- **[机床自制技术积累转向对外销售]** -> [数控机床业务收入暴增142.59%]: 基于20多年自用研发经验，公司机床产品性能达国内领先，2022年对外销售后快速放量。
- **[铸造加工一体化一站式服务]** -> [绑定GE、西门子等世界500强客户]: 从毛坯到成品的整体解决方案能力，降低客户供应链复杂度，形成长期战略合作关系。
- **[产线中机床自制率接近80%]** -> [成本控制与快速响应能力]: 核心生产设备自主可控，降低资本开支，同时能快速调整产线满足紧急订单，构筑护城河。
- **[全球化生产服务体系（亚洲、欧洲、南北美洲）]** -> [外销收入增长17.62%]: 海外设厂实现近距离服务，规避贸易壁垒，提升客户粘性，外销毛利率达39.96%。
- **[持续高研发投入（5.94%营收）]** -> [技术工艺全面性（电火花、雕刻、精铸铝、3D打印）]: 研发费用增长41.58%，推动高效节能模具、电加热硫化机等新产品，巩固中高端市场定位。

## 风险警告
**大型零部件业务毛利率显著承压。** 2025年该业务毛利率同比下滑4.09个百分点至21.58%，主因项目扩建投入增多及员工数量增加。当前铸造产能扩张至30余万吨，若下游风电或燃气轮机需求增速放缓，新增产能的折旧与人工成本将严重侵蚀利润，这是公司当前最核心的盈利质量风险。

**机床业务的高增长可持续性存疑。** 数控机床收入虽暴增142.59%，但行业整体仅实现1.6%的微增，且供强需弱的矛盾尚未根本缓解。公司机床产品主要依赖“自用转外销”的路径，在外部竞争激烈的机床市场中，能否持续获得客户认可并维持高增速，存在较大不确定性。同时，该业务库存量同比激增121.33%，需警惕渠道积压风险。
