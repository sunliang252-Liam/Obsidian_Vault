# 688660.SH 深度透视

## 因果逻辑链
- **[新接订单大幅增长]** -> [营收增长31.07%]: 2024-2025年新增风机订单量显著提升，直接驱动2025年风机销售收入大幅增长。
- **[风机销售价格持续低位]** -> [毛利率下降2.12个百分点]: 海上风电市场竞争加剧，产品售价同比下降，而供应链降本不及预期，导致主营业务毛利率承压。
- **[亏损合同计提增加]** -> [资产减值损失扩大]: 部分亏损合同的存货跌价准备计提增加，导致资产减值损失同比增加19,726万元，进一步拖累利润。
- **[电力市场化改革深化]** -> [行业盈利逻辑重塑]: 发改价格〔2025〕136号文推动新能源全面参与电力市场交易，风场转让收益反哺制造主业的模式难度骤增，整机商回归设备制造本源。
- **[海外业务拓展]** -> [海外毛利率显著高于国内]: 海外市场中标突破百万千瓦，海外业务毛利率达41.19%，成为利润增长核心引擎，有效对冲国内低价竞争压力。
- **[经营活动现金流改善]** -> [现金流净额大幅转正]: 新接订单增加带动销售商品收到的现金增加，经营活动现金流净额从0.43亿元大幅提升至5.98亿元，财务状况有所好转。
- **[海上风电领先地位]** -> [品牌护城河与订单基础]: 公司连续11年海上风电累计装机量全国第一，深厚的海上风电样本库与品牌口碑，为获取优质订单提供了坚实基础。

## 风险警告
公司连续三年亏损，2025年归母净利润为-9.89亿元，亏损额较上年扩大。核心风险在于国内风机价格战持续，尽管行业已形成“反内卷”共识，但价格仍处于低位，叠加海上风电项目交付延期，导致毛利率持续下滑。此外，应收账款及合同资产合计高达117.9亿元，占总资产34.13%，下游客户回款压力巨大，信用减值风险不容忽视。

行业层面，电力市场化改革（136号文）是根本性冲击，风电项目收益模式从固定电价转向市场竞价，不确定性陡增。公司虽以“两海+服务”作为利润增长引擎，但海外业务规模尚小，服务业务毛利率亦在下滑，短期内难以完全弥补整机业务的亏损。若原材料价格（铜、稀土等）持续上涨，将进一步挤压本已微薄的利润空间。
