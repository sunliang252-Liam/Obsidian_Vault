# 301456.SZ 深度透视

## 因果逻辑链
- **[风电行业高景气]** -> [营收与净利润双增33%]: 2025年国内风电新增装机1.2亿千瓦（+51%），直接拉动公司风电润滑系统及液压系统订单大幅增加。
- **[产品多元化战略落地]** -> [润滑系统营收增长34.74%]: 在稳固集中润滑系统市占率（>60%）的同时，齿轮箱润滑系统等液压新品实现批量供货，成为核心增长极。
- **[收购众城石化]** -> [完成润滑产业链纵向延伸]: 2025年12月取得控制权，将业务从专用设备拓展至润滑油脂耗材，打造“设备+油脂”一体化解决方案，切入高端国产替代赛道。
- **[核心元件自研自制]** -> [构筑成本与品质护城河]: 泵芯、分配器、阀组等关键部件自主生产，有效控制成本、保障质量，并快速响应客户定制化需求，提升毛利率稳定性。
- **[非风电市场拓展]** -> [降低单一行业依赖风险]: 集中润滑系统成功切入工程机械、矿山机械等领域，非风电业务收入贡献持续提升，与风电主业形成互补。
- **[海外产能布局]** -> [规避贸易壁垒并提升响应速度]: 泰国智造中心开工建设，构建“中国+泰国”双基地模式，旨在缩短海外交付周期、降低物流成本，应对全球供应链风险。
- **[研发持续投入]** -> [技术迭代与新品储备]: 研发费用4066.53万元（+16.02%），上海研发中心投用，聚焦大兆瓦风机联轴器、液压变桨系统等，为未来增长提供技术支撑。

## 风险警告
**核心风险在于收购整合与商誉减值。** 公司于2025年末收购众城石化，形成约2705万元商誉。若双方在业务、文化、管理上的协同不及预期，或众城石化后续经营业绩不达目标，公司将面临商誉减值风险，直接冲击当期利润。此外，公司经营活动现金流净额为-2964万元，与净利润严重背离，主因客户大量使用承兑汇票等非现金结算及存货增加，需警惕收入质量与营运资金压力。

**另一重大风险是毛利率下行与产能消化。** 风电整机厂持续降本，压力向上游传导，公司液压系统毛利率已同比下降4.45个百分点。同时，募投项目二期扩产及泰国基地在建，若市场开拓或行业景气度不及预期，新增产能将面临无法消化的风险。此外，海外市场开拓经验不足，可能制约全球化战略的推进速度。
