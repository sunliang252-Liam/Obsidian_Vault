# 300772.SZ 深度透视

## 因果逻辑链
- **[风电装机规模高速增长]** -> [营收增长32.45%]: 2025年对外销售容量18.16GW，同比+56.29%，推动风电机组收入达264.34亿元。
- **[大型化趋势加速]** -> [产品结构升级]: 6MW及以上机组销售容量占比从61.5%提升至82.3%，成为绝对主力，带动单机功率提升。
- **[“增收不增利”困境]** -> [净利润下滑26.87%]: 营收大增但净利润仅3.40亿元，主因行业价格战导致毛利率极低（风电机组仅6.43%），且费用（研发+38%）与减值侵蚀利润。
- **[经营活动现金流恶化]** -> [现金流与利润背离]: 经营性现金流净额5.59亿元，同比-72.6%，远低于净利润，反映行业回款周期长、垫资压力大。
- **[新能源电站投资扩张]** -> [资产结构重型化]: 在建工程同比+91.8%至35.40亿元，固定资产+48.6%至49.17亿元，公司正从轻资产制造向重资产运营转型。
- **[海外市场突破]** -> [第二增长曲线初现]: 海外收入14.67亿元，同比+425.27%，占比从1.26%提升至4.99%，成为重要增量。
- **[储能与综合能源布局]** -> [培育新增长极]: 储能业务实现央国企集采入围和海外市场突破，综合能源服务向“数智+绿色”转型，但体量尚小。

## 风险警告
**核心风险：行业“内卷”导致的盈利恶化。** 公司营收增长56%但净利润下滑27%，风电机组毛利率仅6.43%，处于微利甚至亏损边缘。在全面市场化定价（136号文）背景下，价格战短期难以缓解，公司面临“增收不增利”的持续压力。若无法通过技术降本或差异化产品提升溢价，利润可能进一步被压缩。

**财务风险：现金流压力与高负债扩张。** 经营性现金流净额同比骤降72.6%，仅为净利润的1.6倍，远低于健康水平。同时，公司为扩张新能源电站和储能业务，大量举债（长期借款+106%），导致资产负债率攀升。这种“投资性现金流大幅流出、经营性现金流吃紧”的结构，在利率上行或融资收紧时，可能引发流动性危机。
