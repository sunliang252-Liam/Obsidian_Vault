# 002202.SZ 深度透视

## 因果逻辑链
- **[风机大型化与“两海”战略]** -> [营收与利润双增]: 6MW及以上机组销售容量同比增超137%，海外业务收入同比增50.59%，海上风电市场份额跃居国内第一，驱动总营收增长28.79%，净利润增长49.12%。
- **[在手订单高增]** -> [未来收入确定性增强]: 截至2025年末，外部在手订单达50.49GW，同比增长13.35%，为后续营收增长提供坚实储备。
- **[风电场投资与开发]** -> [稳定现金流与利润贡献]: 自营风电场发电量183.30亿kWh，国内利用小时数超全国均值311小时，风电场开发收入86.94亿元，贡献稳定收益。
- **[风电服务与后市场]** -> [收入结构优化]: 后服务收入同比增长13.63%，在运项目容量超50GW，从设备销售向全生命周期服务延伸，提升客户粘性与盈利稳定性。
- **[多元化业务布局]** -> [打造新增长极]: 绿色甲醇在手订单超75万吨，混塔市占率行业第一，储能、能碳业务规模化突破，降低对单一风机业务的依赖。
- **[成本控制与毛利率改善]** -> [盈利能力提升]: 风机及零部件销售毛利率同比提升3.90个百分点，国际销售毛利率提升10.45个百分点，带动整体毛利率改善。
- **[经营性现金流大幅改善]** -> [财务健康度增强]: 经营活动现金流净额35.43亿元，同比增长53.01%，显示销售回款能力增强，盈利质量提升。

## 风险警告
**电价市场化改革与竞争加剧风险。** 136号文推动新能源上网电价全面市场化，存量项目补贴退坡，增量项目收益预期面临不确定性。同时，风电整机行业竞争白热化，尽管2025年价格战有所缓解，但若未来行业自律失效或新进入者冲击，风机价格可能再度承压，侵蚀公司毛利率。

**海外业务与汇率风险。** 公司国际业务收入占比已提升至24.76%，业务覆盖49个国家，面临地缘政治冲突、贸易壁垒及汇率波动等多重风险。海外在手订单9.27GW，若主要结算货币（美元、澳元等）大幅贬值，将产生显著汇兑损失。此外，部分海外项目（如阿根廷）存在政治与法律风险，诉讼事项涉案金额较大，可能影响资产安全。
