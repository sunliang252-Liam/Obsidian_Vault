# 002531.SZ 深度透视

## 因果逻辑链
- **[“陆转海”战略转型]** -> [净利润巨亏2.35亿元]: 公司主动收缩低毛利陆上风电装备业务，淘汰落后产能并计提大额资产减值损失（3.22亿元），导致上市以来首次年度亏损。
- **[海工装备业务爆发]** -> [营收增长220%]: 海工装备收入从4.29亿飙升至13.74亿，成为营收增长的核心引擎，但该板块仍处于亏损状态（净利润-3387万元）。
- **[零碳实业提供稳定现金流]** -> [经营活动现金流净额增长40%]: 1.8GW并网风电场贡献13.17亿发电收入，售电量增长6.76%，为公司转型期提供了8.37亿元的经营性现金净流入。
- **[产能扩张与基地建设]** -> [投资活动现金流出暴增69%]: 阳江、德国海工基地及多个风电场项目同步推进，导致资本开支大幅增加至27.13亿元，自由现金流承压。
- **[财务杠杆高企]** -> [财务费用侵蚀利润]: 长期借款增至76.25亿元，全年利息费用高达3.2亿元，成为吞噬利润的主要固定成本之一。
- **[陆上装备业务收缩]** -> [营收下降15.68%]: 主动退出低效产能，陆上风塔及叶片交付量下滑，导致该板块营收从29.1亿降至24.54亿，毛利率仅1.61%。
- **[电力市场化交易深化]** -> [平均电价承压]: 2025年参与市场化交易电量占总上网电量的64.7%，新并网无补贴项目拉低整体平均电价，影响发电业务收入增速。

## 风险警告
**核心风险在于战略转型期的“青黄不接”。** 公司正经历从陆上风电装备向海上风电装备的艰难切换，旧业务（陆上装备）主动收缩导致营收和利润双杀，新业务（海工装备）虽营收暴增但尚未盈利，叠加高达3.22亿元的资产减值损失，导致2025年巨亏。这种“以利润换空间”的战略能否成功，取决于海工业务何时能跨越盈亏平衡点。

**财务风险高企，偿债压力巨大。** 公司总负债高达172.8亿元，资产负债率63.8%，有息负债规模庞大（短期借款24.4亿+长期借款76.3亿）。全年利息支出3.2亿元，远超净利润。同时，公司对外担保余额占净资产比例高达143.82%，存在或有负债风险。在投资活动现金净流出高达24.6亿元的背景下，公司高度依赖筹资活动（净流入15.3亿）维持现金流平衡，财务脆弱性显著。
