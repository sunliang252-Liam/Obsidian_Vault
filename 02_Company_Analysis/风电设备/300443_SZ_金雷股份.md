# 300443.SZ 深度透视

## 因果逻辑链
- **[铸造产能释放]** -> [业绩高速增长]: 海上风电核心部件项目产能爬坡，铸造产品量价齐升，带动营收增长26.54%，净利润增长81.97%。
- **[行业反内卷与大型化]** -> [盈利修复]: 下游整机价格企稳，叠加公司大型化产品结构优化，风电轴类毛利率同比提升6.24个百分点。
- **[“锻铸协同”全产业链]** -> [竞争壁垒]: 锻造与铸造双技术路线并行，全流程自主可控，深度绑定全球头部整机商，保障供应链安全与交付效率。
- **[研发投入加码]** -> [技术储备]: 研发费用同比增37.15%，聚焦大型化、轻量化、滑动轴承等前沿方向，为海上风电及新市场拓展奠定基础。
- **[多元化业务拓展]** -> [第二增长曲线]: 其他精密轴类（船舶、矿山等）发货量显著增长，新投1.5万吨压机，向重型机械、海工装备领域延伸。
- **[子公司获高新认定]** -> [未来税负优化]: 金雷重装2025年起享15%所得税优惠税率，将显著提升未来税后净利润。
- **[员工持股计划落地]** -> [激励机制绑定]: 完成2025年员工持股计划，覆盖核心管理层，激发团队积极性，但短期摊销费用对净利润有影响。
- **[新定增预案启动]** -> [产能扩张预期]: 拟募资15.5亿元投向高端传动装备科创产业园等项目，预示公司对未来大型铸锻件需求的乐观判断。

## 风险警告
**1. 现金流恶化与产能消化风险。** 2025年经营活动现金流净额为-1.9亿元，同比由正转负，主因装配业务采购增加及项目支出。同时，“海上风电核心部件项目”累计仍亏损，且“高端传动装备科创产业园”等新项目在建，未来折旧费用将持续攀升。若下游需求或市场开拓不及预期，产能利用率不足将严重侵蚀利润，现金流压力可能加剧。

**2. 客户集中与贸易政策风险。** 前五大客户销售额占比56.85%，客户集中度高，议价能力受制。公司外销占比25.75%，海外业务面临地缘政治、贸易壁垒（如碳边境调节机制）及汇率波动的多重冲击。尽管公司推进“全球布局”，但单一市场或客户订单波动仍可能对经营造成显著影响。
