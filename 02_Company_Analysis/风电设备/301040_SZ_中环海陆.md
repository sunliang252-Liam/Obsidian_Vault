# 301040.SZ 深度透视

## 因果逻辑链
- **[风电行业竞争加剧]** -> [产品毛利率大幅下滑]: 风电整机招标价格持续走低，导致供应链降价压力传导至上游锻件环节，公司产能利用率不足，叠加新建项目转固后折旧费用提升，产品毛利率被严重挤压。
- **[“抢装潮”退去后的供需失衡]** -> [产能利用率未达预期]: 国家风电补贴政策退出后，市场短期需求波动，公司前期扩产项目产能无法充分释放，固定成本摊薄效应消失。
- **[可转债利息暂停资本化]** -> [财务费用增加]: 募投项目陆续转固后，可转债利息不再资本化，直接计入当期损益，加重了报告期的财务负担。
- **[客户回款周期延长]** -> [信用减值损失增加]: 行业竞争加剧导致下游客户资金紧张，回款速度放缓，公司计提的应收账款坏账准备增加，侵蚀利润。
- **[原材料成本占比高]** -> [利润对钢价波动敏感]: 直接材料占营业成本近60%，钢材价格波动无法完全通过“原材料成本+加工费”定价模式向下游传导，导致利润承压。
- **[境外收入占比高]** -> [营收增长但利润未同步]: 境外收入同比增长9.48%，但境外毛利率仅8.85%，且境内业务毛利率为负（-6.38%），整体增收不增利。
- **[募投项目延期]** -> [资本开支效率低于预期]: 配套精加工、研发中心、高温合金热处理等核心募投项目均延期，资金投入进度缓慢，未能及时形成新的利润增长点。

## 风险警告
公司当前最核心的风险在于**风电行业景气度下行与自身产能扩张错配**。在“抢装潮”退去、整机价格持续下探的背景下，公司逆势扩产导致折旧激增，而产能利用率不足，直接引发毛利率崩塌式下滑。更严峻的是，公司产品高度集中于风电领域（收入占比84%），单一行业依赖度极高，一旦风电行业需求波动或价格战加剧，公司几乎没有缓冲地带。

其次，**财务风险正在累积**。公司已连续两年亏损，且亏损额巨大（2025年归母净亏损7844万元）。可转债利息费用化、信用减值损失扩大、存货跌价损失（占利润总额21.78%）等多重因素叠加，持续侵蚀净资产。同时，公司固定资产成新率较低，部分房屋建筑物未取得产权证书，资产质量存在隐患。若行业竞争格局无法改善，公司可能面临持续“失血”的风险。
