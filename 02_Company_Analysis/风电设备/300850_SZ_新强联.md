# 300850.SZ 深度透视

## 因果逻辑链
- **[风电行业高景气+国产替代加速]** -> [营收增长57.11%]: 2025年作为“十四五”收官年，风电装机需求旺盛，公司风电类产品营收同比增长72.69%，成为业绩增长的核心引擎。
- **[高附加值产品占比提升]** -> [毛利率大幅改善]: 公司持续优化产品结构，提高风电主轴轴承等高毛利产品比重，带动整体毛利率从29.97%提升至38.85%，盈利能力显著增强。
- **[产业链垂直整合]** -> [成本优势与供应稳定]: 子公司圣久锻件、海普森自供锻件和滚动体，将加工环节利润留存内部，同时缩短供应链距离，降低物流与时间成本。
- **[无软带感应淬火技术突破]** -> [产品竞争力提升]: 自主研发的无软带淬火技术打破外资垄断，在效率提升和成本控制上具备显著优势，使产品在市场竞争中更具性价比。
- **[大兆瓦产品布局]** -> [市场份额扩大]: 公司成功研发12MW海上抗台风型主轴轴承等大兆瓦产品，适配风机大型化趋势，进一步扩大市场份额。
- **[客户集中度高]** -> [订单稳定性强]: 前五大客户销售占比达74.80%，与明阳智能等头部整机商建立长期稳定合作关系，保障了订单的持续获取。
- **[可转债转股完成]** -> [财务结构优化]: 报告期内“强联转债”大量转股，应付债券减少11.09亿元，净资产大幅增加36.93%，显著降低财务杠杆。

## 风险警告
**经营现金流与净利润严重背离**：2025年净利润8.18亿元，但经营活动现金流净额仅为0.18亿元，同比下降95.86%。主要系存货及应收账款大幅增加所致。在营收高速增长的同时，公司对下游客户的议价能力或显不足，回款周期拉长，若客户经营恶化，将面临较大的坏账损失风险。这种“纸面富贵”的盈利质量，是公司最核心的财务隐忧。

**政策与价格双重挤压风险**：公司风电类产品收入占比高达77.36%，业绩高度依赖风电行业景气度。2025年新能源上网电价市场化改革政策，可能引发风电项目收益率下降，进而导致投资规模缩减，对公司产品销量和售价形成不利影响。同时，下游整机价格持续下降，价格压力向上游传导，公司产品存在降价风险，可能侵蚀利润空间。
