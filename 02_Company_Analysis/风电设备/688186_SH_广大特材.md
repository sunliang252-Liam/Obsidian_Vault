# 688186.SH 深度透视

## 因果逻辑链
- **[风电行业高景气度]** -> [营收增长22.62%]: 下游风电装机需求持续向好，公司风电铸件、主轴、齿轮箱零部件等核心产品订单增加，驱动整体收入规模扩大。
- **[产能释放与规模效应]** -> [毛利率提升0.9个百分点]: 齿轮箱零部件及海上风电铸件项目产能利用率大幅提升，摊薄单位固定成本，叠加工艺降本，推动主营业务盈利能力改善。
- **[产品结构优化]** -> [扣非净利润增长176.37%]: 公司主动调整产品组合，向高附加值、高毛利率的风电机械部件倾斜，同时内部管理提效，期间费用率下降，利润弹性显著高于收入增速。
- **[全产业链一体化布局]** -> [成本与交付优势]: 公司具备从材料熔炼到精加工的全流程能力，实现关键零部件全工序自主可控，降低对外协依赖，提升客户“一站式”交付响应速度。
- **[技术壁垒与客户认证]** -> [高客户粘性]: 在风电齿轮钢、大型铸件等领域掌握64项核心技术，并通过国际知名企业认证，形成较高的进入门槛，保障订单稳定性。
- **[可转债转股]** -> [净资产增长30.11%]: 报告期内可转债大规模转股，直接增加资本公积和股本，显著优化了资本结构，降低了财务杠杆。
- **[研发投入放缓]** -> [短期技术储备风险]: 报告期内研发费用同比下降7.38%，公司解释为主机厂产品方向未定导致新品研发放缓，可能影响未来技术迭代速度。

## 风险警告
**现金流与盈利质量的严重背离是最大隐忧。** 公司净利润同比增长79.6%至2.06亿元，但经营活动现金流净额为-8.69亿元，较上年同期的-2.61亿元大幅恶化。核心原因在于客户大量使用票据结算（应收款项融资暴增214%），而公司采购、薪酬等支出需现金支付，导致“纸面富贵”。剔除票据贴现影响后，经营性现金流虽转正至1.75亿元，但依然无法覆盖净利润，盈利质量堪忧。

**高资本开支与产能消化风险并存。** 公司固定资产折旧规模持续扩大，且募投项目“宏茂海上风电高端装备研发制造一期项目”2025年效益未达预期。若未来风电行业降本压力持续传导，或公司新客户开发不利，导致产能利用率下降，高额的折旧费用将直接侵蚀利润，形成“增收不增利”甚至利润下滑的局面。此外，存货高达26.6亿元，占流动资产40%，若原材料价格下跌，存在较大减值风险。
