# 002692.SZ 深度透视

## 因果逻辑链
- **[原材料价格波动与成本传导]** -> [毛利率承压]: 铜、铝等原材料占成本超90%，2025年铜价宽幅震荡，公司未能完全向下游传导成本压力，导致电线电缆整体毛利率同比下降1.59个百分点。
- **[市场竞争加剧与产品结构变化]** -> [扣非净利润转负]: 行业集中度低、同质化竞争严重，公司特种电缆收入同比下降5.80%，电气装备用线缆收入骤降37.32%，高毛利产品占比下滑，导致扣非净利润亏损2312万元。
- **[应收账款高企与信用减值]** -> [侵蚀利润]: 应收账款账面余额16.68亿元，占总资产47%，2025年计提信用减值损失4521万元，是导致净利润大幅萎缩的核心因素之一。
- **[子公司亏损与破产清算]** -> [拖累合并业绩]: 全资子公司远程复材亏损1467万元，孙公司北京远路进入破产清算程序，减少归母净利润1832万元，合计侵蚀利润超3000万元。
- **[研发投入持续加大]** -> [短期费用压力]: 研发费用同比增长15.47%至9021万元，主要用于高压、新能源、轨道交通等特种电缆新品开发，虽提升长期竞争力，但短期内压缩了利润空间。
- **[销售费用优化]** -> [部分对冲利润下滑]: 公司严控市场投入，销售费用同比下降35.98%至1.22亿元，在一定程度上缓解了毛利下滑对利润的冲击。
- **[现金流改善但仍为负]** -> [经营质量待提升]: 经营活动现金流净额-1587万元，较上年-5959万元显著改善，但净利润与现金流持续背离，主因经营性应收项目大幅增加。

## 风险警告
**核心风险在于盈利能力的急剧恶化与资产质量的隐忧。** 公司2025年扣非净利润亏损2312万元，同比骤降142.59%，表明主营业务已陷入实质性亏损。更值得警惕的是，应收账款高达14.43亿元，占总资产近半，且信用减值损失持续扩大，若下游客户（尤其是中小型工程商）回款进一步恶化，将引发更大规模的坏账风险，直接冲击净资产。

**战略转型与资本运作存在高度不确定性。** 公司正推进“智能电网用中高压特种电缆制造项目”（投资4.5亿元）及向特定对象发行股票（募资2.45亿元），但主业盈利能力下滑、现金流紧张，大规模资本开支将进一步加剧财务压力。同时，控股股东苏新投资及其一致行动人背景为地方AMC，公司治理与业务协同效果尚待验证，若定增失败或项目投产不及预期，公司可能陷入“主业亏损+债务扩张”的双重困境。
