# 300001.SZ 深度透视

## 因果逻辑链
- **海外业务爆发式增长** -> 净利润增长35.62%: 海外中标额同比增长超50%，高压预制舱变电站等高毛利产品出口拉动整体盈利水平。
- **高压预制舱变电站量价齐升** -> 电力设备板块利润增长41.89%: 该产品收入增长16.60%，毛利率稳定在27.38%，成为利润核心引擎。
- **充电网规模效应显现** -> 充电业务利润增长13.94%: 运营公共充电终端约90万台（全国第一），充电量约196亿度，固定成本摊薄，毛利率提升至34.00%。
- **经营活动现金流大幅改善** -> 现金流净额增长77.61%: 销售回款能力增强，现金流质量显著优于净利润增速，财务健康度提升。
- **虚拟电厂与增值服务** -> 开辟第二增长曲线: 聚合超10,000座可调度充电站，参与调峰辅助服务，将充电负荷转化为可交易的能源资产。
- **数据中心与AI算力需求** -> 驱动电力设备升级: 成功切入字节跳动、阿里巴巴等头部客户，数据中心领域合同额超4亿元，打开新市场空间。
- **“光储充放”一体化微电网** -> 提升充电网运营价值: 累计布局超1,300个微电网电站，实现绿电消纳与峰谷套利，降低运营成本。

## 风险警告
**应收账款高企与坏账风险**：公司应收账款高达91.53亿元，占总资产35.56%，远超净利润规模。尽管客户多为国央企，但电力行业项目周期长、结算慢，若宏观经济下行或客户信用恶化，大规模坏账将直接侵蚀利润。

**充电业务盈利依赖补贴与规模**：充电网运营服务收入同比下降2.19%，且充电设备毛利率下滑2.59个百分点。当前盈利高度依赖充电量规模增长和政府补助（2.4亿元），若新能源车增速放缓或补贴退坡，充电业务可能陷入增收不增利的困境。
