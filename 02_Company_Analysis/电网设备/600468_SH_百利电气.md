# 600468.SH 深度透视

## 因果逻辑链
- **[商誉减值风险出清]** -> [扭亏为盈]: 2024年因对荣信兴业计提2.17亿元商誉减值导致巨亏，2025年无此影响，归母净利润恢复至8906万元。
- **[电磁线产品量价齐升]** -> [营收增长]: 苏州贯龙公司受益于风电、核电等下游需求旺盛，电磁线收入同比增长23.78%，拉动总营收增长12.97%。
- **[海外市场拓展]** -> [盈利结构优化]: 荣信兴业等子公司斩获拉美、一带一路订单，海外收入占比提升至7.53%，且毛利率高达34.38%，显著高于国内。
- **[原材料成本压力]** -> [毛利率承压]: 铜等主要原材料价格上涨，导致电磁线产品毛利率下降3.30个百分点，整体主营业务毛利率下降3.39个百分点。
- **[“源网荷储”新赛道布局]** -> [战略转型]: 投资设立百利智慧能源公司，整合微网控制器、电能质量治理等产品，切入零碳微网新赛道。
- **[两金压降与资产盘活]** -> [现金流改善]: 通过月度督导催收逾期账款、处置闲置资产，经营活动现金流净额同比增长24.49%至2.37亿元。
- **[子公司发展不均衡]** -> [整体盈利依赖少数]: 苏州贯龙、成都瑞联贡献主要利润，而泵业集团收入下滑10%，百利有限公司持续亏损，拖累整体表现。

## 风险警告
公司核心风险在于盈利能力的脆弱性与原材料成本的双重挤压。2025年扭亏主要依赖商誉减值“后遗症”消退，而非经营面的根本性改善。电磁线、高中低压电器等核心产品毛利率全面下滑，铜价波动直接侵蚀利润，公司对上游议价能力较弱。同时，泵业集团收入下滑10%，百利有限公司持续亏损，子公司间发展严重失衡，整体盈利高度依赖苏州贯龙和成都瑞联两家子公司，抗风险能力不足。

另一重大风险是战略转型的不确定性。公司高调布局“源网荷储+零碳微网”新赛道，并投资建设多个数字化工厂项目，但新业务尚处起步阶段，短期内难以贡献利润。大规模资本开支（如天津瑞联新工厂、泵业集团研发中心）已导致投资活动现金流净流出近6000万元，若新项目回报不及预期，将加剧公司资金压力并拖累整体资产回报率。
