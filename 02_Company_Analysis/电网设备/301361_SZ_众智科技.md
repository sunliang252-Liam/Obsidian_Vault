# 301361.SZ 深度透视

## 因果逻辑链
- **[智算中心(AIDC)建设爆发]** -> [控制器类产品营收增长13.31%]: 数据中心备用电源需求激增，带动公司核心控制器产品销量与结构升级。
- **[组件类产品放量]** -> [组件类营收增长42.38%]: 电气控制柜、加热器等配套产品随控制器销售同步增长，且增速显著高于控制器，成为第二增长曲线。
- **[精益运营与国产替代]** -> [毛利率提升0.79个百分点至57.91%]: 通过六西格玛管理和关键零部件国产化，在原材料成本上升背景下有效控制成本。
- **[海外市场拓展]** -> [境外营收增长15.95%]: 设立土耳其子公司，推进本地化运营，海外品牌影响力提升，出口成为重要增长极。
- **[研发投入持续高企]** -> [研发费用占营收9.75%]: 持续投入船用、新能源、数字调压板等新品研发，为未来增长储备技术势能。
- **[现金流质量优异]** -> [经营活动现金流净额增长47.14%至9449万]: 销售回款效率提升，现金流增速远超净利润增速，盈利质量高。
- **[募投项目延期]** -> [智能控制器生产建设项目进度仅80.2%]: 因市场环境变化，公司主动放缓产能扩张节奏，导致项目未按期达产。

## 风险警告
**核心业务增长天花板与竞争加剧风险。** 控制器类产品营收占比超60%，是公司绝对支柱。虽然智算中心带来结构性机会，但该市场高度依赖下游数据中心资本开支周期，一旦增速放缓，公司核心业务将面临增长乏力。同时，公司直面行业头部跨国企业竞争，在业务规模和高端人才储备上仍有差距，若对手加大中国市场投入，公司市场份额可能承压。

**募投项目延期与产能瓶颈风险。** 核心募投项目“智能控制器生产建设项目”进度仅80.2%，已延期至2027年4月。在组件类产品需求爆发（+42.38%）的背景下，产能扩张滞后可能成为制约公司承接大额订单、抢占市场份额的瓶颈。若未来市场需求持续超预期，公司可能面临“有单不能产”的窘境。
