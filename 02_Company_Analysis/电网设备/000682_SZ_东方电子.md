# 000682.SZ 深度透视

## 因果逻辑链
- **[“十五五”电网投资高景气]** -> [营收增长11.04%]: 国网4万亿、南网1800亿年度投资规划，直接拉动公司电网核心业务（输变电自动化+37.1%）及配用电业务（+8.48%）订单放量。
- **[海外市场加速拓展]** -> [海外收入暴增84.63%]: 公司推动调度主站、配用电、储能全产业链出海，新市场合同额占比超30%，海外成为第二增长极。
- **[非经常性损益大幅增厚]** -> [归母净利润增速(33.35%)远超扣非增速(12.69%)]: 公允价值变动收益1.79亿元（主要系南网数字战略配售等金融资产增值），贡献了利润增量的主要部分。
- **[储能及新能源业务放量]** -> [新能源及储能收入+14.8%，但毛利率骤降11.71pct]: 中标大型储能EPC项目（如5.37亿洛阳、10.65亿甘肃华亭），收入规模扩张但竞争加剧导致盈利能力承压。
- **[子公司威思顿稳健增长]** -> [智能配用电业务收入+8.48%]: 威思顿作为核心子公司营收34.33亿元（+24.47%），在国南网电表集中招标中份额领先，高端智能电表销量创新高。
- **[子公司海颐软件业绩大幅下滑]** -> [拖累整体利润弹性]: 海颐软件受市场竞争加剧、业务转型影响，营收-12.92%，净利润-69.52%，成为公司内生增长的减分项。
- **[研发投入持续高增]** -> [技术壁垒构筑]: 研发投入6.91亿元（+9.07%），聚焦AI+电力、自主可控、构网型储能等前沿技术，支撑调度云化、虚拟电厂等长期竞争力。

## 风险警告
**1. 利润质量与可持续性风险。** 2025年归母净利润9.12亿元中，公允价值变动收益高达1.79亿元（主要来自南网数字战略配售），占利润总额的17.4%。剔除该非经常性损益后，扣非净利润增速仅12.69%，与营收增速基本持平。若未来金融资产公允价值波动，将直接冲击利润表。同时，核心子公司海颐软件净利润同比暴跌69.52%，显示部分业务单元面临严峻的竞争与转型压力。

**2. 储能业务“增收不增利”与现金流恶化风险。** 新能源及储能业务收入增长14.8%，但毛利率同比骤降11.71个百分点至13.95%，远低于公司整体毛利率。公司通过低价竞标大型EPC项目（如10.65亿元华亭项目）换取规模，但盈利能力堪忧。此外，经营活动现金流净额同比减少22.29%，而投资活动现金净流出同比扩大203.64%（主要用于战略投资），自由现金流承压，需警惕业务扩张对现金流的持续消耗。

**公司简介（F10 原文）**

> 东方电子股份有限公司为深交所上市公司(股票代码:000682,A股简称:东方电子),是国家重点扶持企业、火炬计划重点高新技术企业和山东省重点企业。历经半个世纪的发展与变迁,东方电子传承电力行业的领先优势,追随技术的不断进步与创新,拓展更加广泛的业务领域。作为奥运电力设备及国家智能电网的设备供应商,东方电子已发展成为集科研开发、生产经营、技术服务、系统集成于一体的大型高新技术企业,是中国能源管理系统解决方案的主要供应商之一,参加IEC(国际电工委员会)国际标准制定。公司国内市场占有率始终在中国电力自动化行业名列前茅。产品遍及东南亚、南亚、中东、非洲及欧洲等多个国家和地区,顺利入围印度国家“十二五”配电网改造计划,成为唯一一家印度国家电网指定的中国电网设备供应商。公司以“珍爱环境,节约资源”为愿景,把环保、节能、安全、智能融入业务流程中,在智能电网、环保节能等领域为电力、大型厂矿企业、政府部门、居民小区等提供能源管理和节能服务系统解决方案。
