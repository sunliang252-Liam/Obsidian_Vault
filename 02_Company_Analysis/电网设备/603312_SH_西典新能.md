# 603312.SH 深度透视

## 因果逻辑链
- **[下游新能源需求爆发]** -> [电池连接系统收入增长38.73%]: 新能源汽车销量增长、单车带电量提升及储能市场高速扩张，直接拉动公司核心产品出货量同比增长41.34%。
- **[FFC/薄膜/直焊新技术量产]** -> [成本优势与产品竞争力提升]: 自研FFC替代FPC、直焊省去镍片、薄膜降低材料成本，三项技术实现批量供货，构筑了相对于同行的成本护城河。
- **[关键设备自主设计制造]** -> [快速响应客户迭代与降本]: 公司自研热压、焊接、检测等核心设备，能根据客户设计变更快速改造产线，同时降低设备采购成本，形成柔性生产壁垒。
- **[深度绑定宁德时代]** -> [营收高增长但议价能力受限]: 对宁德时代销售额占比高达69.37%，公司随下游龙头扩张而增长，但客户集中度极高，导致毛利率承压（电池连接系统毛利率下降1.56个百分点）。
- **[储能业务放量]** -> [第二增长曲线形成]: 储能出货量逐年提升，与头部企业建立紧密合作，预计未来储能产品出货金额占比持续提升，降低对单一动力电池市场的依赖。
- **[海外工厂布局泰国]** -> [全球化战略启动]: 首个海外工厂落户泰国春武里府，以租赁厂房快速投产，为响应海外客户及拓展东南亚、欧洲、北美市场奠定基础。
- **[产业链延伸（FFC独立）]** -> [规模化效应与成本管控]: 将FFC信号采集组件车间独立至子公司，通过规模化生产降低成本，进一步提升电池连接系统的整体成本优势。

## 风险警告
**核心风险：对单一客户宁德时代的极度依赖（营收占比69.37%）。** 这导致公司在定价、回款周期、技术路线选择上均缺乏主动权。2025年电池连接系统毛利率已同比下降1.56个百分点，反映出下游整车厂降价压力正沿产业链向上游传导。一旦宁德时代切换供应商或自研替代，将对公司营收造成毁灭性打击。

**第二风险：行业竞争加剧与价格战。** 新能源车终端降价潮已扩散至全产业链，公司产品售价面临持续降低压力。同时，电连接行业门槛相对不高，大量资本涌入将导致产能过剩，公司若不能在FFC、薄膜等新技术上持续领先并快速降本，市场份额和盈利能力将受到双重挤压。此外，新能源汽车行业“洗牌”风险不容忽视，若下游客户出现经营困难，将直接形成坏账。
