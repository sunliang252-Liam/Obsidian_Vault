- **[全球电网投资与新型电力系统建设]** -> [营收与利润双增]: 全球能源转型推动电网扩张，公司作为新材料外绝缘龙头，受益于行业需求增长，2025年营收17.21亿元（+27.94%），净利润4.32亿元（+38.92%）。
- **[海外市场突破与全球化布局]** -> [海外收入高增]: 公司中标沙特柔直项目，打破中东市场壁垒，海外合同收入10.12亿元（+36.40%），推动境外收入增长41.42%，成为核心增长引擎。
- **[核心客户深度绑定]** -> [订单增长]: 与Hitachi Energy、Siemens Energy、GE等国际巨头形成扎实合作基础，国内绑定国网、南网，2025年新增订单19.48亿元（+27.47%），在手订单充足。
- **[产品性能与全生命周期成本优势]** -> [高毛利率]: 复合外绝缘产品防爆、抗震、免维护，全生命周期成本低于传统瓷绝缘子，变电站复合外绝缘毛利率48.67%（+1.69pct），橡胶密封件毛利率54.16%（+7.30pct）。
- **[事业部制改革与精益管理]** -> [盈利能力提升]: 推行“客户为中心”的事业部经营模式，独立核算、自负盈亏，叠加数字化工厂建设，降本增效，净利润增速（38.92%）显著高于营收增速（27.94%）。
- **[股权激励绑定核心团队]** -> [人才与战略协同]: 2025年推出股票期权激励计划，覆盖核心管理及技术骨干，实现“共担、共创、共享”，激发组织活力，支撑长期战略落地。
- **[越南/美国工厂建设]** -> [产能全球化]: 在越南、美国布局产能，贴近海外客户，规避贸易壁垒，为未来海外订单持续增长提供产能保障。

## 风险警告
**1. 应收账款与现金流错配风险。** 公司主要客户为国家电网、南方电网及大型电力设备商，付款审批流程长，导致应收账款高达8.17亿元（+37.11%），占营收47.5%。尽管净利润4.32亿元，但经营性现金流仅1.17亿元（-26.79%），利润质量偏低。若宏观经济下行或客户付款延迟，将面临坏账损失及资金周转压力。

**2. 原材料价格波动与汇率风险。** 公司主要原材料（缠绕纱、硅橡胶、铝锭）价格波动直接影响毛利率。同时，海外收入占比达46%，若人民币升值或海外外汇政策变化，将侵蚀出口利润。公司虽提及套期保值，但实际效果存不确定性，利润对汇率敏感度较高。
