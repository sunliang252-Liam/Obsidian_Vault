# 002882.SZ 深度透视

## 因果逻辑链
- **[铜价持续攀升]** -> [营收增长26.54%]: 铜作为主要原材料，价格上涨直接推高产品售价，带动营业收入从36.75亿增至46.51亿。
- **[线缆市场竞争加剧]** -> [毛利率承压]: 民用类、特种电缆等核心产品毛利率全面下滑1.6-3.3个百分点，导致增收不增利。
- **[固态电池项目投入]** -> [净利润下降23.65%]: 研发费用同比大增72.9%（至7369万），叠加产能建设资本开支，侵蚀传统业务利润。
- **[客户回款方式转变]** -> [经营性现金流恶化至-7.48亿]: 客户大量使用电子债权凭证及银行承兑汇票结算，导致经营活动回款减少，与净利润1.07亿严重背离。
- **[海外市场拓展]** -> [外贸类收入暴增224.6%]: 境外收入从1.24亿跃升至4.03亿，成为营收增长的第二大引擎。
- **[原材料采购高度集中]** -> [供应链风险敞口大]: 前五大供应商采购额占比91.88%，其中江西铜业一家占比69.2%，议价能力弱。
- **[信用减值损失扩大]** -> [侵蚀利润]: 计提应收账款等信用减值损失5028万元，占利润总额的35.8%，反映下游客户回款风险加剧。

## 风险警告
**核心风险在于“增收不增利”与“现金流枯竭”的双重挤压。** 公司营收增长主要依赖铜价上涨和海外市场开拓，但核心线缆业务毛利率全面下滑，固态电池业务尚处投入期，导致净利润同比下降23.65%。更严峻的是，经营活动现金流净额由负转正至-7.48亿元，与净利润严重背离，主要因客户大量使用电子债权凭证结算，公司被迫通过票据贴现等筹资方式回笼资金，财务费用随之大增49.7%。

**第二大风险是固态电池业务的“烧钱”不确定性。** 公司计划总投资24亿元建设固态电池材料及2GWh量产线项目，但该业务目前仅实现101万元收入，亏损5577万元。行业仍处产业化初期，技术路线、成本、市场接受度均存在巨大不确定性。若产业化进程不及预期，前期巨额研发及资本开支将无法收回，进一步拖累公司现金流和盈利能力。
