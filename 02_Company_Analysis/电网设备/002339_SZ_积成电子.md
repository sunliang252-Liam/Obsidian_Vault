## 因果逻辑链
- **[电网投资高景气]** -> [营收增长18.66%]: 国网、南网“十四五”收官年投资加码，公司电力自动化业务（营收+28.13%）直接受益于电网建设加速。
- **[行业竞争加剧导致毛利率承压]** -> [净利润下滑36.20%]: 电力自动化、公用事业自动化毛利率均下降超3.5个百分点，收入增长未能转化为利润增长。
- **[子公司分化严重]** -> [整体盈利被拖累]: 卓识网安（信息安全）净利润7040万（+11%），但青岛积成（公用事业）亏损1396万（-202%），业绩冰火两重天。
- **[研发投入持续高企]** -> [短期压制利润]: 研发费用2.34亿元（占营收7.07%），资本化率仅0.57%，大量研发投入当期费用化侵蚀利润。
- **[应收账款高企与信用减值]** -> [侵蚀现金流与利润]: 应收账款16.3亿元（占总资产36.7%），信用减值损失2615万元，回款压力与坏账风险并存。
- **[筹资活动现金流大幅流出]** -> [现金储备减少]: 筹资活动净现金流-2.51亿元（同比-488%），主因偿还借款多于新借款，导致期末现金及等价物减少1.76亿元。
- **[无实控人治理结构]** -> [战略稳定性存疑]: 股权分散，无控股股东和实际控制人，重大决策依赖董事会博弈，长期战略执行存在不确定性。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长近19%，但归母净利润反降36%，扣非净利润更是腰斩（-55%）。根本原因是行业竞争白热化导致综合毛利率持续下滑，而高昂的研发费用和坏账计提又进一步吞噬利润。这种“以价换量”的模式若无法扭转，公司盈利能力将持续恶化。

**资产质量与现金流是另一大隐患。** 应收账款高达16.3亿元，占总资产37%，且信用减值损失持续扩大。尽管账面有7.2亿货币资金，但筹资活动净流出巨大，实际可动用现金正在快速消耗。子公司青岛积成由盈转亏，若其经营状况不能改善，可能引发商誉减值风险。公司虽提出2026年净利润目标5538万元，但在当前竞争格局下，实现难度极大。
