# 300265.SZ 深度透视

## 因果逻辑链
- **[输电线缆业务收入下滑]** -> [整体营收微降1.9%]: 输电线缆作为第一大收入来源（占比51.93%），收入同比下降7.57%，直接拖累总营收。
- **[高端海洋装备项目转固]** -> [子公司通光海洋大幅亏损]: 募投项目“高端海洋装备能源系统项目（一期）”投资转固，导致固定资产折旧增加，成本费用激增，通光海洋净利润亏损3650万元。
- **[原材料成本控制与套保]** -> [毛利率基本稳定]: 尽管营收下滑，但通过套期保值工具锁定成本，营业成本下降1.73%，使得综合毛利率仅微降0.15个百分点。
- **[应收账款高企与减值]** -> [净利润大幅下滑31.37%]: 应收账款占营收比例高达46.55%，叠加计提资产减值损失4679.56万元，严重侵蚀利润。
- **[政府补助减少]** -> [非经常性损益下降]: 计入当期损益的政府补助从1488.51万元降至737.84万元，导致扣非净利润降幅（-33.92%）大于净利润降幅。
- **[装备线缆业务增长]** -> [产品结构优化]: 装备线缆收入同比增长23.92%，毛利率高达29.58%，成为公司利润的重要稳定器，对冲了传统业务的疲软。
- **[经营活动现金流改善]** -> [回款能力增强]: 经营活动现金流净额同比大增43.92%，主要得益于销售商品收到的现金增加，显示公司在加强应收账款催收方面取得成效。

## 风险警告
**核心风险在于“增收不增利”与资产质量恶化。** 公司营收微降，但净利润暴跌31.37%，主因是巨额资产减值（-4679.56万元）吞噬利润。应收账款常年占营收近半壁江山，回款风险是悬在头顶的达摩克利斯之剑。一旦下游电网或通信客户付款周期拉长或出现坏账，将对本已脆弱的盈利造成致命打击。

**战略投入的“失血”效应正在显现。** 公司重金投入的“高端海洋装备能源系统项目”转固后，非但没有贡献预期收益，反而因折旧导致子公司通光海洋巨亏3650万元，成为业绩的最大拖累。该项目产能释放缓慢，短期内难以扭亏，将持续消耗公司资源。同时，光纤光缆和输电线缆两大传统主业均出现量增价跌或量价齐跌的态势，行业竞争加剧，毛利率承压。
