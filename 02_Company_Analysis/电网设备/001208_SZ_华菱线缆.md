# 001208.SZ 深度透视

## 因果逻辑链
- **[特种电缆高壁垒与国产替代]** -> **营收增长8.39%**: 公司深耕航空航天、矿山、新能源等特种电缆细分市场，凭借技术壁垒和国产替代需求，实现特种电缆收入增长10.96%，成为核心增长引擎。
- **[定增募资12.15亿与债务优化]** -> **财务费用下降35.62%**: 2025年完成定向增发，补充流动资金并提前归还高息项目贷款，显著优化资本结构，降低融资成本。
- **[收购三竹科技（70%股权）]** -> **切入机器人/连接器赛道**: 通过现金+可转债收购，从单一线缆供应商向“线缆+连接器”系统解决方案商转型，打造第二增长曲线。
- **[国家电网/南方电网中标突破]** -> **电力电缆收入增长7.52%**: 国网中标省份从2个扩至16个，南网中标4.1亿元，两网订单放量，驱动电力电缆业务稳健增长。
- **[铜铝套期保值与供应链管理]** -> **毛利率稳定（10.94%）**: 面对铜铝价格波动，公司通过期货套保和优化采购结算，有效对冲原材料成本风险，维持毛利率基本稳定。
- **[“两金”管控与票据结算]** -> **经营性现金流大增60.13%**: 通过加快订单结算、优化账期并增加票据融资，经营活动现金流净额达4.19亿元，远超净利润，现金流质量显著改善。
- **[研发投入聚焦“卡脖子”技术]** -> **巩固特种电缆护城河**: 研发投入1.44亿元，重点突破氟材料、聚酰亚胺等国产化，完成深海脐带缆、机场助航灯电缆等新品，强化技术壁垒。

## 风险警告
**核心风险在于原材料价格波动与市场竞争加剧。** 公司产品“料重工轻”，铜铝成本占比极高。尽管有套期保值，但极端价格波动仍可能侵蚀利润。同时，国内线缆行业集中度低，中低端市场同质化竞争激烈，若公司不能持续向高附加值特种电缆转型，毛利率存在下行压力。

**并购整合与商誉减值风险不容忽视。** 公司以1.83亿元收购三竹科技70%股权，形成较大商誉。三竹科技主营连接器与线束，与公司主业协同性有待验证。若未来机器人、工业自动化等下游需求不及预期，或整合效果不佳，将面临商誉减值风险，直接冲击利润表。
