# 002121.SZ 深度透视

## 因果逻辑链
- **[储能业务爆发式增长]** -> [营收大增42.41%]: 储能系统出货量同比增387%，带动总营收从44.3亿跃升至63.1亿，储能收入占比从33%升至60%。
- **[储能价格战与成本压力]** -> [毛利率下滑]: 储能业务毛利率同比下降6.87个百分点至17.03%，直接材料成本同比增58%，侵蚀利润空间。
- **[递延所得税资产冲回]** -> [巨额非现金亏损]: 因对未来盈利预期谨慎，冲回约1.6亿元递延所得税资产，是导致全年净亏损1.56亿元的核心原因之一。
- **[南方电网市场禁入]** -> [智能电网业务萎缩]: 2024年7月起被南方电网禁入18个月，导致2025年智能电网收入同比下滑14.34%，电气产品销量下降28%。
- **[美的集团赋能]** -> [全球化与供应链优化]: 依托美的全球渠道和供应链，海外营收同比增86.54%，并推出“科陆+美的”双品牌战略，加速海外市场渗透。
- **[新签合同高增]** -> [未来收入储备]: 2025年新签储能项目总容量约11.6GWh，为未来1-2年收入增长提供强力支撑，但需关注订单转化率和毛利率。
- **[高额诉讼与赔偿]** -> [营业外支出激增]: 与南海工程的工程合同纠纷一审判决计提约6221万元预计诉讼支出，严重拖累当期利润。

## 风险警告
**核心风险在于持续亏损与脆弱的资产负债表。** 公司连续三年扣非净利润为负，2025年归母净资产已降至3.56亿元，同比再缩水28.59%。巨额的未弥补亏损（合并报表-39.6亿元）和极低的净资产，使公司面临巨大的财务压力，任何经营波动都可能触发流动性危机。虽然营收因储能业务暴增，但增收不增利，毛利率下滑和巨额非经常性损失（如递延所得税冲回）表明盈利质量极差。

**第二大风险是储能业务的“内卷”与订单转化不确定性。** 储能行业价格战激烈，公司储能毛利率已降至17%，且经营活动现金流净额同比大降82%，显示收入增长并未带来等比例的现金流入，反而因采购预付款增加导致资金紧张。新签的11.6GWh订单能否在保持合理利润的前提下顺利交付并转化为现金，是未来能否扭亏的关键，但当前行业竞争格局和公司自身资金状况使这一前景充满挑战。此外，与美的集团的同业竞争承诺（5年解决）尚未落地，构成潜在治理风险。
