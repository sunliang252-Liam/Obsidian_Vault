# 301295.SZ 深度透视

## 因果逻辑链
- **[收入增长但利润下滑]** -> [增收不增利]: 营收增长11.49%至7.06亿，但归母净利润下降17.38%至2255万，主因研发费用大增22.53%及毛利率承压。
- **[大客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比59.94%，其中第一大客户美的集团占比38.78%，公司业绩高度依赖单一客户。
- **[家电领域深耕]** -> [收入基本盘稳固]: 通用继电器收入增长10.37%，流体电磁阀增长23.97%，受益于家电行业头部客户（美的、奥克斯等）的稳定需求。
- **[研发投入加大]** -> [长期竞争力铺垫]: 研发费用同比增长22.53%至3778万，聚焦小型化、大功率、新能源继电器，为产品升级和新兴领域拓展蓄力。
- **[现金流大幅改善]** -> [经营质量提升]: 经营活动现金流净额由负转正，从-5621万增至1885万，主要系销售回款增加，显示经营效率改善。
- **[新能源业务拓展]** -> [第二增长曲线]: 公司正积极开发新能源、储能、智能电表等领域客户，磁保持/新能源继电器成为战略重点，但尚未贡献显著利润。
- **[原材料价格波动]** -> [毛利率承压]: 继电器毛利率同比下降1.58个百分点，主因银、铜等大宗商品价格波动导致触点、漆包线等原材料成本上升。

## 风险警告
**核心风险在于客户集中度过高与盈利能力的持续下滑。** 公司近六成收入来自前五大客户，其中美的集团一家占比近四成，这种“单一大客户依赖”格局使其议价能力受限，且业绩极易受下游家电行业景气度波动及客户自身供应链调整的冲击。2025年营收增长但利润反降，已初步暴露了成本传导不畅与竞争加剧的问题。

**第二增长曲线尚未成型，转型存在不确定性。** 公司虽积极布局新能源、储能等新兴领域，但相关业务收入占比仍极低，且面临技术认证壁垒和激烈的市场竞争。募投项目“继电器及水阀生产线扩建项目”投资进度仅24.88%，产能释放节奏缓慢，若新业务拓展不及预期，公司将长期困于低增长、低利润的家电配套赛道。
