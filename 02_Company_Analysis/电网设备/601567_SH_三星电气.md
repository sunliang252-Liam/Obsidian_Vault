# 601567.SH 深度透视

## 因果逻辑链
- **[国内电网招标价格波动 & 医保政策深化]** -> [归母净利润同比-43.62%]: 智能配用电毛利率因招标价下行下降7.73pct，医疗服务收入因医保改革下降8.67%，双重挤压导致利润大幅下滑。
- **[海外配电业务高速扩张]** -> [海外在手订单同比+41.39%]: 聚焦欧洲、中东、拉美核心市场，新增匈牙利、罗马尼亚等首单，海外配电成为业绩增长核心引擎。
- **[商誉减值损失3.56亿元]** -> [非经常性损益大幅侵蚀利润]: 因部分康复医院业绩未达预期（余姚、嘉兴、衢州明州未完成对赌），计提大额商誉减值，扣非净利润同比-57.75%。
- **[研发投入持续加码]** -> [产品竞争力与市场准入壁垒提升]: 研发费用同比+16.04%，新增190余项海外产品认证，支撑美国、埃及等高端市场首单突破。
- **[前湾基地投产 & 数字化改造]** -> [制造效率与成本控制优化]: 新基地自动化率超80%，入选国家级数字经济重点工程，支撑“高品质、高效率、低成本”战略落地。
- **[全球智能电表销量连续5年第一]** -> [品牌与渠道壁垒强化]: 沙利文认证巩固行业龙头地位，40余个销售中心、10大生产基地支撑全球化运营，客户粘性增强。
- **[康复医院连锁扩张但部分对赌失败]** -> [医疗服务板块盈利承压]: 旗下38家医院（32家康复）形成规模，但余姚、嘉兴、衢州三家医院未完成三年累计业绩承诺，需进行现金补偿。

## 风险警告
**核心风险：利润断崖式下滑与商誉减值风险。** 2025年归母净利润同比暴跌43.62%，扣非净利润更是腰斩（-57.75%），主因是国内智能配用电招标价格下行导致毛利率大幅收窄，以及医疗服务板块受医保改革冲击收入下降。更严重的是，公司计提了3.56亿元商誉减值损失，且余姚、嘉兴、衢州三家康复医院对赌失败，表明前期并购整合效果不佳，未来仍有减值隐患。

**次要风险：海外扩张的投入产出不确定性。** 海外配电业务虽在手订单高增（+41.39%），但海外整体毛利率同比下降10.94个百分点，说明新市场首单突破阶段毛利率较低，且前期销售费用（+10.46%）和研发投入（+16.04%）持续增加，短期可能继续侵蚀利润。此外，海外本地化生产基地建设（巴西在建）和销售公司扩张，带来管理复杂度和投资风险。
