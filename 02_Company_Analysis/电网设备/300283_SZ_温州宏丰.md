# 300283.SZ 深度透视

## 因果逻辑链
- **[原材料价格单边上涨]** -> [业绩扭亏为盈]: 白银、铜、钨等主要原材料价格大幅上涨，直接推高产品售价与毛利率，使归母净利润从-7367万大幅转正至2517万。
- **[电接触及功能复合材料板块发力]** -> [核心利润贡献]: 该板块营收增长19.93%，归母净利润暴增125.12%，是公司整体扭亏的绝对主力。
- **[硬质合金板块高增长]** -> [第二增长曲线]: 受益于钨价高位及高端产品国产替代，该板块营收增长59.68%，归母净利润增长396.77%，成为重要利润增量。
- **[铜箔板块持续亏损]** -> [拖累整体盈利]: 锂电铜箔业务营收仅增长15.82%，毛利率为-20.95%，归母净利润亏损8063万元，是公司合并报表层面最大的失血点。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户销售占比高达51.98%，其中对正泰电器及其子公司的依赖度达30.53%，单一客户变动即可对公司业绩产生重大冲击。
- **[白银租赁公允价值变动]** -> [非经常性损益波动]: 报告期内白银租赁产生公允价值变动损失2868万元，是导致非经常性损益为负的主要原因，加剧了利润的波动性。
- **[可转债转股完成]** -> [资本结构优化]: 可转债成功转股，增加股本5969万股，减少应付债券2.5亿元，显著降低了财务杠杆和利息支出压力。

## 风险警告
**核心风险在于铜箔业务的持续失血与客户集中度过高。** 铜箔板块毛利率为-20.95%，亏损8063万元，严重侵蚀了传统主业电接触材料与硬质合金的利润。若铜箔行业产能过剩、价格战加剧，或公司无法快速实现规模化降本，该业务将成为长期拖累，甚至可能再次将公司拖入亏损泥潭。

**另一重大风险是原材料价格反转与客户依赖。** 公司2025年业绩暴增高度依赖白银、铜、钨等大宗商品价格单边上涨。若未来原材料价格大幅下跌，公司将面临巨大的存货跌价风险，利润将迅速回吐。同时，对正泰电器超30%的营收依赖，使得公司议价能力受限，一旦核心客户调整采购策略，将对公司经营造成毁灭性打击。
