# 600869.SH 深度透视

## 因果逻辑链
- **[智能缆网业务稳健增长]** -> [营收创历史新高]: 智能缆网营收239.03亿元，同比增长5.28%，贡献了公司85%的营收，是业绩的压舱石。
- **[智能电池业务大幅减亏]** -> [归母净利润扭亏为盈]: 智能电池净利润-3.46亿元，同比减亏3.45亿元，是公司从亏损转向盈利的核心驱动力。
- **[算力AI业务爆发式增长]** -> [开辟第二增长曲线]: 算力、AI和机器人新兴市场营收12.90亿元，同比增长76.50%，成为公司未来增长的核心引擎。

- **[“算电协同”战略落地]** -> [构建差异化竞争优势]: 公司将电力与算力深度融合，布局高速铜缆、液冷、光纤等，切入AI算力基础设施赛道，形成独特竞争壁垒。
- **[海缆业务投产并中标大单]** -> [打开海洋经济新空间]: 远东海缆一期投产，成功中标海南万宁漂浮式风电等标杆项目，标志着公司成功切入高壁垒、高增长的海缆市场。

## 风险警告
公司2025年归母净利润仅为0.59亿元，而扣非净利润为0.41亿元，盈利能力依然非常薄弱。智能电池业务虽大幅减亏，但依然亏损3.46亿元，且子公司如江苏远东电池净资产为-8.37亿元，已资不抵债，电池业务的持续亏损是公司最大的财务风险。此外，公司总负债高达169.11亿元，资产负债率80.17%，担保总额占净资产比例高达258.24%，财务杠杆极高，偿债压力巨大。

公司业务高度依赖铜、铝等大宗商品原材料，价格波动风险显著。同时，智能电池、算力AI等新业务面临激烈的市场竞争和快速的技术迭代，若公司技术路线选择失误或市场拓展不及预期，新业务可能无法成为有效的增长点，反而持续拖累整体业绩。此外，公司研发费用同比减少20.10%，在需要大量投入的新兴领域，研发投入的缩减可能影响长期竞争力。
