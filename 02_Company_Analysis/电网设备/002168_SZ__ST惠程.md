# 002168.SZ 深度透视

## 因果逻辑链
- **[收购锐恩医药]** -> [营收暴增87%，归母净资产转正]: 2025年1月并表锐恩医药，新增医药业务贡献59%营收，叠加债权人豁免1.3亿债务及投资人捐赠3000万，使净资产从-5482万转正至1599万，避免退市。
- **[核心主业持续亏损]** -> [扣非净利润仍为-8737万]: 剔除医药并表及债务豁免等非经常性损益后，传统输配电、充电桩、光伏EPC业务全面萎缩，电力行业收入降25%，充电桩收入降80%，主业造血能力严重不足。
- **[预重整与重整投资人引入]** -> [化解债务危机与潜在控制权变更]: 债权人申请预重整，引入植恩生物作为重整投资人，拟以1.735元/股取得2.32亿股（20.04%），若重整成功，控股股东将变更为植恩生物，实控人变更为黄山。
- **[高销售费用吞噬利润]** -> [医药业务高毛利但净利贡献有限]: 医药业务毛利率高达80.7%，但为推广产品，销售费用暴增459%至1.02亿，远超医药业务贡献的净利润，导致整体仍亏损。
- **[资产减值与公允价值损失]** -> [持续侵蚀利润]: 对存货、固定资产等计提减值2748万，叠加投资性房地产及股权资产公允价值变动损失1857万，合计非现金损失超4600万，暴露历史资产质量低下。
- **[高负债率与流动性压力]** -> [财务风险高企]: 资产负债率高达92.71%，短期借款1.58亿，长期借款及一年内到期非流动负债合计1.93亿，而货币资金仅6790万，偿债压力巨大。

## 风险警告
公司当前的核心风险在于**重整失败导致的退市与破产**。2025年财报虽因债务豁免和医药并表使净资产转正，但审计报告仍被出具“持续经营重大不确定性”意见。若重整计划未获法院批准或执行失败，公司将面临破产清算，股票直接退市。此外，重整投资人植恩生物同时也是公司第一大供应商（采购额占26%）和业绩承诺方，存在严重的关联交易和利益输送风险。

其次，**主业空心化与盈利不可持续**是另一大隐患。公司扣非净利润已连续三年为负，传统电气和充电桩业务大幅萎缩，新注入的医药业务高度依赖关联方植恩生物的委托生产和渠道销售，其高毛利背后是巨额的销售费用。扣除债务豁免等一次性收益后，公司并无可持续的盈利能力，一旦重整完成后的业绩对赌期结束，公司可能重回亏损泥潭。
