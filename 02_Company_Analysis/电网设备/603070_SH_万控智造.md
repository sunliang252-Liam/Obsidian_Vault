# 603070.SH 深度透视

## 因果逻辑链
- **[下游需求结构性收缩]** -> [营收下降6.93%]: 房地产调整、基建放缓、部分制造业产能复苏不及预期，导致电气机柜销量同比下滑24.92%，价格承压。
- **[电气机柜存量市场竞争加剧]** -> [毛利率持续下滑]: 2023-2025年综合毛利率从25.44%降至21.11%，核心基本盘业务盈利空间被压缩。
- **[气体绝缘开关设备放量]** -> [营收增长13.49%]: 环保气体开关契合“双碳”趋势，海外市场拓展（沙特设厂）及国网中标推动该业务成为第二增长极。
- **[原材料成本占比高]** -> [毛利率承压]: 钢板、铜排等大宗商品价格波动直接侵蚀利润，成本中原材料占比高达77.53%。
- **[销售费用大幅压降29.01%]** -> [扣非净利润降幅小于营收降幅]: 公司主动实施降本控费，部分对冲了收入下滑对利润的冲击。
- **[募投项目延期]** -> [资本开支节奏放缓]: 智能化气体绝缘环网柜扩产项目延期至2026年10月，产能释放节奏慢于预期，短期折旧压力可控。
- **[海外布局加速]** -> [境外营收增长36.91%]: 沙特孙公司产线落地，MXGN系列获中东、北非认可，海外毛利率高达40.46%，成为利润新引擎。

## 风险警告
**核心风险在于电气机柜基本盘的持续萎缩与毛利率的长期下行趋势。** 公司核心业务电气机柜营收同比下降11.90%，且毛利率同步下滑1.34个百分点。下游房地产与基建需求疲软是结构性问题，短期内难以逆转。同时，气体绝缘开关设备虽增长较快，但C-GIS产品市场竞争加剧，其毛利率也下降了2.10个百分点，新业务的增量利润尚不足以完全对冲传统业务的失血。

**第二大风险是应收款项的回收压力与潜在的坏账风险。** 截至2025年末，公司应收款项余额高达10.75亿元，占营业收入的56.95%。下游客户回款周期长，且部分客户受宏观经济影响经营承压，若出现大额坏账，将对利润表造成显著冲击。此外，公司实际控制人之一木信德已将其直接持有的99.99%股份质押，虽整体质押比例不高，但需关注其个人层面的流动性风险。
