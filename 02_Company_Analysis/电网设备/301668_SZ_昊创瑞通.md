# 301668.SZ 深度透视

## 因果逻辑链
- **[“十五五”电网投资高增]** -> [行业景气度提升]: 国家电网“十五五”固定资产投资4万亿元（较“十四五”增长40%），配电网智能化升级成为重点，直接拉动公司主营产品需求。
- **[国家电网中标领先]** -> [收入增长与市场地位]: 公司智能环网柜、柱上开关等产品在国家电网融合类产品联合招标中中标金额位居前列，支撑2025年营收同比增长3.25%至8.95亿元。
- **[智能柱上开关销量下滑]** -> [利润承压]: 核心产品智能柱上开关收入同比下降13.69%，且毛利率下滑11.93个百分点，是导致归母净利润同比下降5.64%的主要原因。
- **[IPO募集资金到账]** -> [资产结构剧变]: 2025年9月上市募资净额5.16亿元，导致货币资金暴增28.9个百分点至68.17%，总资产增长77.85%，净资产增长130.28%。
- **[“以销定产”模式]** -> [存货大幅下降]: 因订单增加、生产规模扩大，存货同比下降16.81个百分点，库存量减少25.41%，显示产销衔接良好。
- **[研发投入持续增长]** -> [技术壁垒构建]: 研发投入同比增长8.94%至3521.67万元，聚焦环保开关、深度融合柱上开关等方向，巩固国家级专精特新“小巨人”技术优势。
- **[客户高度集中]** -> [经营风险暴露]: 主要客户为国家电网、南方电网，前五名客户销售占比29.12%，若“两网”投资或招标变化，将对公司业绩产生重大不利影响。

## 风险警告
**核心风险在于客户高度集中与盈利能力下滑。** 公司收入几乎完全依赖国家电网和南方电网，尽管“十五五”投资规划利好，但若招标政策、技术标准或竞争格局变化，公司议价能力将受严重挤压。2025年归母净利润已同比下滑5.64%，智能柱上开关毛利率大幅下降11.93个百分点，显示核心产品竞争力或面临挑战，盈利拐点尚未到来。

**规模扩张后的管理风险与原材料价格波动风险不容忽视。** 上市后资产规模急剧膨胀，募投项目（智能环网柜、柱上开关生产建设等）尚处建设期，产能释放与市场消化存在不确定性。同时，原材料（电气组件、金属件）成本占营业成本超90%，价格波动将直接侵蚀本已承压的毛利率，公司虽采取锁价、集中采购等措施，但效果有待验证。
