# 002546.SZ 深度透视

## 因果逻辑链
- **[金融资产公允价值变动]** -> [净利润暴增116.86%]: 公司持有大量交易性金融资产，2025年资本市场回暖，公允价值变动收益3.31亿元，是归母净利润5.78亿元的核心来源。
- **[主业营收下滑]** -> [扣非净利润仅微增0.05%]: 核心电力产品收入同比下降9.79%，数据服务收入下降13.01%，导致扣非净利润仅1.34亿元，与净利润暴增形成鲜明对比。
- **[国家电网集中招标]** -> [主业收入基本盘稳定]: 公司深耕用电信息采集业务，持续中标国网集采，保障了主营业务的营收规模，但中标地区结构变化导致收入波动。
- **[虚拟电厂政策红利]** -> [战略转型“用户侧系统集成平台”]: 国家明确虚拟电厂市场主体地位，公司依托数据采集优势，将募投资金转向用户侧系统集成平台，布局虚拟电厂、能碳管理等新业务。
- **[募投项目多次延期与变更]** -> [资金使用效率低下]: 原“智能用电云服务项目”因市场环境变化进展缓慢，最终终止并变更为“用户侧系统集成平台”，大量募集资金（10.76亿元）仍闲置在专户。
- **[高额金融资产配置]** -> [业绩高度依赖资本市场]: 公司持有31.08亿元交易性金融资产（占总资产75%），投资收益和公允价值变动成为利润最大来源，主业盈利能力被严重稀释。
- **[出售子公司与房产]** -> [优化资产结构]: 公司出售云南耀邦达股权和部分闲置房产给关联方，回笼资金并减少非核心业务，聚焦主业与战略转型。

## 风险警告
**主业增长乏力，业绩高度依赖“炒股”收益。** 公司2025年扣非净利润仅1.34亿元，同比微增0.05%，而净利润暴增完全依赖3.31亿元的公允价值变动收益。这种利润结构极不稳定，一旦资本市场转弱，公司业绩将面临断崖式下跌风险。投资者需警惕其“金融公司”属性远超“电力设备公司”的实质。

**战略转型不确定性高，巨额资金闲置。** 公司原募投项目“智能用电云服务”因市场不及预期而终止，新项目“用户侧系统集成平台”尚在建设初期，能否在虚拟电厂等新赛道成功尚存疑问。同时，超过10亿元的募集资金长期闲置，反映出公司缺乏优质产业投资机会，资金使用效率低下，战略执行力存疑。
