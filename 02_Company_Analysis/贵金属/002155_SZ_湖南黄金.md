# 002155.SZ 深度透视

## 因果逻辑链
- **[金价大幅上涨]** -> [营收与利润暴增]: 2025年国际金价同比上涨超60%，公司黄金销售收入占比93.67%，直接驱动营收增长80.26%、归母净利润增长75.77%。
- **[外购非标金业务扩张]** -> [营收规模膨胀但毛利率承压]: 外购非标金业务收入占比从82.26%升至88.38%，该业务毛利率仅0.08%，拉低整体毛利率1.71个百分点。
- **[锑钨价格同步上涨]** -> [锑钨业务利润贡献提升]: 锑锭均价同比上涨40.84%，钨精矿均价同比上涨59.25%，推动锑品、钨品毛利率分别提升6.64和36.64个百分点。
- **[自产金产量下滑]** -> [资源瓶颈显现]: 黄金自产3,431千克，同比减少7.40%，自产锑亦减少6.71%，显示现有矿山产量增长乏力。
- **[套期保值业务亏损]** -> [非经常性损益拖累]: 黄金套期保值产生公允价值变动损失及投资收益亏损合计约-2,477万元，导致非经常性损益为负。
- **[探矿增储投入持续]** -> [资源接续压力]: 全年掘进支出5.37亿元，但保有资源量金137吨、锑34.7万吨，规模有限，资源保障能力面临挑战。
- **[关联交易与资产整合]** -> [治理结构优化]: 启动发行股份购买控股股东旗下黄金天岳及中南冶炼100%股权，旨在解决同业竞争并注入成熟资产。

## 风险警告
**核心风险在于业绩对金价的极度依赖与资源瓶颈的尖锐矛盾。** 公司2025年营收暴增80%，但88%的收入来自毛利率极低的外购非标金业务，本质是“以量换价”的贸易扩张，而非矿山盈利能力的提升。一旦金价回调，营收和利润将面临双杀。同时，自产金、锑产量连续下滑，保有资源量有限，探矿增储投入虽大但短期难以转化为产量，资源“生命线”承压。

**套期保值业务的潜在损失与资产整合的不确定性构成第二重风险。** 公司持有大量黄金衍生品头寸，2025年已产生显著公允价值变动亏损，若金价剧烈波动，套保策略可能放大亏损。此外，发行股份购买控股股东资产的交易尚在推进，标的资产（黄金天岳、中南冶炼）的盈利能力、整合效果及对中小股东的摊薄影响，均存在较大不确定性。
