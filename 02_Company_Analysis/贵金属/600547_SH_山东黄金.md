# 600547.SH 深度透视

## 因果逻辑链
- **[金价创历史新高]** -> [营收利润暴增]: 2025年国际金价同比上涨约65%，直接推动公司自产金销售收入同比增长53.42%，毛利率提升3.52个百分点至50.57%。
- **[境外矿山放量]** -> [产量结构优化]: 境外矿山产金12.58吨，同比大增60.20%，占总产量比例提升至25.7%，有效对冲国内矿山产量持平的压力。
- **[外购金业务扩张]** -> [营收规模膨胀但利润稀薄]: 外购金收入431.93亿元，占营收41.4%，但毛利率仅0.80%，是营收高增但利润弹性低于金价涨幅的核心原因。
- **[套保与金融资产亏损]** -> [侵蚀主业利润]: 公允价值变动损失14.96亿元（主要为其他非流动金融资产减值），投资收益亏损5.70亿元（黄金期货及T+D业务），合计拖累税前利润超20亿元。
- **[资源并购与项目建设]** -> [资本开支高企]: 投资活动现金净流出136.09亿元，主要用于焦家、新城金矿整合工程及纳米比亚Osino项目建设，支撑远期产能扩张。
- **[降本增效与融资优化]** -> [财务费用下降]: 平均融资成本同比下降0.21个百分点，财务费用减少16.54%至19.10亿元，对冲了管理费用和研发费用的增长。
- **[探矿增储]** -> [资源接续保障]: 全年探矿投入8.1亿元，新增金资源量81吨，超过当年生产消耗量，截至年末保有黄金资源量1979.33吨，为长期开采提供基础。

## 风险警告
**核心风险在于金价高位回落与成本刚性上涨的剪刀差。** 公司2025年业绩暴增高度依赖金价创历史新高的外部环境（国际金价同比+65%）。若未来美联储货币政策转向、地缘政治缓和或全球经济衰退导致金价大幅回调，公司自产金毛利率（50.57%）将迅速收窄，而外购金业务（毛利率仅0.80%）无法提供缓冲，业绩将面临戴维斯双杀。同时，随着矿山开采深度增加和外委施工转自营，克金成本存在刚性上涨压力。

**第二重风险来自海外运营与资本开支的失控可能。** 境外资产占总资产16.21%，且境外矿山产量同比大增60%，但阿根廷、加纳、纳米比亚等国的政治风险、资源民族主义、劳工纠纷及汇率波动（外币报表折算导致其他综合收益亏损2亿元）均可能冲击海外利润。此外，公司仍有大量在建工程（焦家、新城、Osino等项目），总投资超百亿，若项目延期、超支或达产不及预期，将拖累现金流并增加减值风险。
