# 001337.SZ 深度透视

## 因果逻辑链
- **[金价单边大幅上涨]** -> [营收增长60.38%]: 2025年上海黄金交易所Au9999收盘价同比上涨58.78%，公司产品结算价以金交所金价为基准，直接拉动收入跨越式增长。
- **[金价上行叠加成本相对刚性]** -> [净利润增长87.69%]: 黄金矿山现金生产成本（采矿、人工、折旧等）增幅远低于金价涨幅，毛利率同比提升6.2个百分点至62.81%，利润弹性显著放大。
- **[地下开采工程竣工投产]** -> [原矿供应保障增强]: 梭罗沟金矿实现露天与地下联合开采，2025年生产金精矿32,645.59吨，同比增长18.83%，为产量提升奠定基础。
- **[2000t/d选厂技改完成]** -> [产能瓶颈突破]: 选矿能力提升，支撑金精矿产量增长，同时库存量同比大增79.63%，反映生产端放量但销售节奏未完全同步。
- **[预收销货款及销售收入增加]** -> [经营现金流净额增长93.94%]: 客户预付款项大幅增加，合同负债从1.2亿元升至2.73亿元，经营活动现金流达6.45亿元，盈利质量极高。
- **[新增银行贷款]** -> [筹资活动现金流转正]: 报告期内取得5亿元长期借款，筹资活动净流入3.92亿元，为新疆探矿权购置及矿山工程建设提供资金支持。
- **[竞得新疆库格孜-觉北金矿探矿权]** -> [资源储备外延扩张]: 投入5.1亿元获取中天山成矿带探矿权，打破单一矿山依赖，为未来增储上产打开新空间。
- **[客户高度集中]** -> [销售依赖风险]: 前五大客户销售额占比87.68%，其中关联方贵州紫金占比20.83%，单一客户变动可能对业绩产生短期冲击。

## 风险警告
**核心风险在于单一矿山经营与资源枯竭的长期隐患。** 公司99.96%的收入来自梭罗沟金矿，一旦该矿发生安全事故、环保处罚或资源储量下降，将直接导致业绩断崖式下跌。尽管已竞得新疆探矿权，但距离形成实际产能仍需数年，短期无法改变“一矿独大”的脆弱结构。同时，梭罗沟金矿保有储量76,340千克，按当前年产量约1.7吨计算，服务年限有限，资源接续压力巨大。

**金价波动是业绩的最大短期变量。** 2025年业绩暴增的核心驱动力是金价单边上涨58.78%，而非产量大幅提升（金精矿销售量仅增8.58%）。若未来金价回调，公司成本端（采矿成本同比增120.61%、折旧摊销增94.45%）刚性上升的趋势将迅速侵蚀利润，业绩存在大幅回撤风险。此外，客户高度集中（前五占87.68%）和关联交易占比高（20.83%），也增加了经营中的非市场化风险。
