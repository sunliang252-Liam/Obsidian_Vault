# 600988.SH 深度透视

## 因果逻辑链
- **[金价持续上涨]** -> [营收与净利润创历史新高]: 2025年伦敦现货黄金定盘价上涨62.90%，公司矿产金销售均价同步提升，驱动营收增长40.03%、归母净利润增长74.70%。
- **[港股上市融资]** -> [资产负债率大幅下降]: 2025年3月H股上市募集约31亿港元，叠加经营现金流强劲，有息负债余额下降67.45%，资产负债率从47.25%降至33.91%。
- **[老挝塞班SND项目突破]** -> [核心资产资源量显著增厚]: 以极低勘探投入发现大规模斑岩型金铜矿体，首次报告资源量（金当量106.9吨），延长矿山服务年限，为长期价值增长提供支撑。
- **[加纳瓦萨金矿资源模型更新]** -> [黄金资源量同比大增41%]: 因金价上调降低边界品位，叠加深部钻探升级资源级别，黄金资源量从255吨增至360吨，储量从17.1吨增至43.06吨。
- **[国内高品位矿山精细化运营]** -> [成本优势与利润压舱石]: 国内金矿全维持成本仅277.83元/克，远低于海外矿山，在行业成本普遍上行背景下，持续贡献稳定利润与现金流。
- **[境外矿山成本显著上升]** -> [利润空间受挤压]: 加纳瓦萨金矿全维持成本同比上升51.25%至1,972.98美元/盎司，主因资源税税率上调、新增采矿作业单元及入选品位下降。
- **[电解铜业务亏损扩大]** -> [拖累整体盈利]: 电解铜毛利率为-30.90%，同比恶化41.43个百分点，主因铜价下跌叠加成本刚性上涨，成为公司主要亏损业务单元。

## 风险警告
**核心风险在于海外运营成本失控与资源接续的不确定性。** 加纳瓦萨金矿全维持成本同比飙升51%，主因资源税税率从1%上调至3%、新增采矿单元及品位下降，若金价回调，该矿可能迅速从利润贡献者变为亏损源。同时，老挝塞班铜矿业务持续亏损（电解铜毛利率-30.9%），铜价波动将直接冲击整体盈利稳定性。

**第二重风险来自金价依赖与增长可持续性。** 公司净利润增长74.7%，但矿产金产量同比下降4.27%，增长几乎完全依赖金价上涨。若金价进入调整周期，公司内生增长成色将面临严峻考验。此外，海外矿山采掘衔接紧张、部分矿山技改停产，资源接续与产能释放进度若不及预期，将削弱长期增长逻辑。
