# 603019.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长13.81%]: 智能算力规模同比增96%，公司超节点、万卡超集群产品精准匹配大模型训练需求，驱动IT设备及技术服务收入增长。
- **[产品结构优化]** -> [扣非净利润增长33.97%]: 高毛利的软件开发、系统集成及技术服务收入增长75.34%（毛利率47.25%），显著拉升整体盈利质量。
- **[联营企业利润增长]** -> [投资收益增21.22%]: 海光信息等产业链布局企业业绩向好，贡献6.84亿元投资收益，成为利润重要增量。
- **[液冷技术商业化]** -> [绿色算力壁垒]: 子公司曙光数创推出相变冷板液冷方案，PUE管控趋严下，液冷渗透率要求提升，巩固数据中心节能解决方案领先地位。
- **[国产化替代深化]** -> [信创市场扩容]: 党政、金融等关键领域国产化率提升，公司自主可控全栈能力（芯-端-云-算）受益于供应链本土化趋势。
- **[委托开发项目资金错期]** -> [经营性现金流下降51.75%]: 上年收到大额委托开发款项，本期按进度支付，叠加购置大额存单，导致现金流短期波动，非经营恶化。
- **[80亿可转债募资]** -> [加码AI算力集群]: 计划投向先进算力集群、AI训推一体机、国产化存储，强化算力基础设施全产业链布局。

## 风险警告
**1. 重大资产重组终止与战略不确定性。** 海光信息换股吸收合并中科曙光的交易因“市场环境变化”终止，暴露出公司核心战略路径的摇摆。作为持有海光信息重要股权的母公司，此次重组失败意味着两者协同效应无法通过股权整合最大化，未来如何平衡独立发展与生态协同，存在战略模糊风险。

**2. 供应链与技术双重依赖。** 公司坦言“仍需要使用国外先进部件”，在国产芯片性能追赶期，核心部件供应紧张或价格波动将直接冲击成本与交付。同时，AI算力技术迭代极快，若超节点、万卡集群等新品商业化不及预期，或国产加速卡生态适配进度落后，可能丧失技术窗口期，导致巨额研发投入无法有效转化。
