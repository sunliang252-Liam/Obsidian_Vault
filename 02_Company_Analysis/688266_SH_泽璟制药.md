# 688266.SH 深度透视

## 因果逻辑链
- **[四款已上市创新药组合]** -> [营收增长52%]: 多纳非尼、重组人凝血酶、吉卡昔替尼、人促甲状腺素β四款药物形成商业化矩阵，重组人凝血酶纳入医保后放量，吉卡昔替尼年中上市，共同驱动收入从5.33亿增至8.10亿。
- **[销售费用激增71%]** -> [亏损扩大]: 重组人凝血酶纳入医保后需向CSO支付高额推广服务费，叠加吉卡昔替尼新品早期市场拓展费用，销售费用从2.71亿飙升至4.65亿，远超营收增速，导致扣非净亏损扩大至1.98亿。
- **[ZG006与艾伯维达成全球合作]** -> [验证全球创新价值]: 全球首款DLL3/DLL3/CD3三特异性抗体获艾伯维认可，首付款1亿美元，潜在里程碑最高10.75亿美元，标志着公司从本土Biotech向全球创新药企转型。
- **[吉卡昔替尼纳入医保]** -> [骨髓纤维化市场准入突破]: 作为首个国产JAK抑制剂，2026年1月纳入医保，被CSCO指南推荐为一线治疗，为后续放量奠定基础。
- **[研发投入占比53%]** -> [管线持续深化]: 4.3亿研发投入聚焦ZG006、ZG005等双/三特异性抗体，ZG006已启动关键临床，ZG005多项联合疗法获批，维持技术领先地位。
- **[经营活动现金流为负]** -> [资金压力持续]: 经营性现金流净流出2878万元，主要因市场推广授权款分期到账节奏差异，公司仍依赖外部融资支撑运营。
- **[累计未弥补亏损25亿]** -> [无法分红]: 母公司累计未分配利润-25亿，短期内无法满足分红条件，股东回报依赖股价增值。

## 风险警告
**核心风险在于商业化变现效率与持续亏损的剪刀差。** 公司虽拥有四款上市药物，但销售费用率高达57%，远超同行（百济神州33%、信达生物46%），主要因重组人凝血酶依赖CSO模式支付高额推广费，以及吉卡昔替尼新品推广投入巨大。若后续产品放量不及预期，亏损可能进一步扩大，营运资金将面临更大压力。

**研发管线高度依赖ZG006和ZG005的临床成败。** 这两款双/三特异性抗体是公司未来价值核心，但均处于早期临床阶段，全球尚无同类药物获批。若关键临床试验数据不佳或监管审批受阻，将严重打击公司估值，且前期巨额研发投入无法回收。同时，公司营运资金仍部分依赖外部融资，若融资环境恶化，可能被迫削减研发项目。
