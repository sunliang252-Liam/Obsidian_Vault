# 300677.SZ 深度透视

## 因果逻辑链
- **[美国关税壁垒升级]** -> [净利润下降31.03%]: 美国对中国一次性丁腈手套加征110%关税，直接冲击核心市场，导致扣非净利润同比大幅下滑66%。
- **[行业供需再平衡]** -> [营收微增4.23%]: 2025年行业产能出清效果显现，供需关系逐步回归平衡，公司凭借龙头地位实现销量增长11.14%，但产品售价仍处低位，营收仅小幅增长。
- **[非美市场拓展与国内增长]** -> [境内收入增长21.65%]: 公司迅速调整策略，加大欧洲、亚洲及国内市场投入，境内收入实现双位数增长，有效对冲了美国市场冲击。
- **[产能扩张与资本开支]** -> [资产总额增长15.77%]: 安徽安庆基地投产，年化产能达1,030亿只，同时推进海外项目建设，导致固定资产和在建工程增加，资产规模扩大。
- **[财务杠杆运用]** -> [筹资活动现金流净额增长488%]: 为支撑产能扩张和日常运营，公司大幅增加银行贷款，短期借款占总资产比例升至40.88%。
- **[非经常性损益贡献]** -> [归母净利润远高于扣非净利润]: 报告期内公允价值变动损益及投资收益合计约6.98亿元，成为利润的主要来源，掩盖了主营业务盈利能力的下滑。
- **[原材料自供与成本控制]** -> [毛利率保持稳定]: 控股丁腈胶乳生产企业、推进热电联产项目，有效控制了原材料和能源成本，使个人防护类产品毛利率维持在24.28%。

## 风险警告
**核心风险在于关税壁垒的持续升级与主营业务盈利能力的实质性恶化。** 美国对中国一次性医疗级丁腈手套加征110%关税，这直接侵蚀了公司最核心的利润来源。尽管公司通过拓展非美市场实现了营收微增，但扣非净利润同比暴跌66%，表明主营业务在剔除金融资产收益后已陷入严重困境。若关税政策无法缓解，公司海外产能（越南、马来西亚）的建设进度和成本控制将成为决定生死的关键。

**财务风险在于高杠杆运营与现金流压力。** 公司短期借款高达163.9亿元，占总资产40.88%，且大量资产（货币资金、金融资产）已被质押用于借款。虽然经营性现金流净额同比增长74.69%，但投资活动现金流净流出高达114.5亿元，筹资活动现金净流入83.8亿元，表明公司正通过“借新还旧”和“借新投新”的模式维持运营和扩张。一旦市场环境恶化或融资渠道收紧，公司将面临巨大的流动性风险。
