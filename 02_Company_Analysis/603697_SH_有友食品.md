# 603697.SH 深度透视

## 因果逻辑链
- **[渠道变革（四轮驱动）]** -> [营收增长34.39%]: 传统渠道、会员商超、零食量贩、线上电商协同发力，尤其是东南区域营收暴增90.43%，驱动整体规模跨越式增长。
- **[原材料成本控制与规模效应]** -> [毛利率下降3.45个百分点]: 营收增长34.39%的同时，营业成本增长40.51%，成本增速快于收入，主要因禽类制品原材料成本大幅上升，侵蚀了部分利润空间。
- **[销售回款改善与采购付款优化]** -> [经营现金流净额暴增75.47%]: 销售商品收到的现金增加，同时使用商业汇票支付货款（应付票据增306%），有效减少了现金支出，现金流质量显著提升。
- **[核心大单品禽类制品放量]** -> [营收增长41.14%]: 以泡椒凤爪为代表的禽类制品仍是绝对主力，销量增长25.32%，是营收增长的核心引擎。
- **[东南区域渠道深耕]** -> [区域收入暴增90.43%]: 公司在东南区域（华东等）的渠道拓展和零食量贩等新渠道布局见效，成为增长最快的区域市场。
- **[高比例现金分红]** -> [净资产微降0.15%]: 近三年累计分红占净利润超90%，2025年分红率高达96.81%，大量利润分配导致净资产未能随盈利增长而增加。
- **[金融资产公允价值变动]** -> [非经常性损益贡献利润]: 持有大量理财产品（期末10.8亿），公允价值变动收益2793万元，成为利润的重要补充，但具有不确定性。

## 风险警告
**核心风险在于成本失控与单一品类依赖。** 公司原材料成本占比超80%，2025年禽类制品成本增速（48.49%）显著快于收入增速（41.14%），导致核心品类毛利率下滑3.72个百分点。若鸡爪等主要原材料价格持续上涨，公司缺乏有效的成本转嫁机制，盈利能力将面临严重侵蚀。同时，禽类制品收入占比高达87.5%，产品结构极度单一，一旦消费趋势变化或出现食品安全事件，公司将遭受毁灭性打击。

**增长可持续性存疑。** 2025年营收34.39%的高增长，部分得益于东南区域渠道的爆发式增长（+90.43%），但这种高基数下的高速增长难以持续。零食量贩等新渠道的红利期过后，增长动能可能迅速衰减。此外，公司研发投入仅占营收0.3%，研发人员仅26人，缺乏打造第二增长曲线的技术储备，长期增长动力不足。
