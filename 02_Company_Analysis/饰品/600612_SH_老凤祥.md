# 600612.SH 深度透视

## 因果逻辑链
- **[金价持续攀升与消费结构转变]** -> [营收与利润双降]: 2025年国际金价暴涨超60%，导致黄金首饰消费量同比骤降31.61%，而投资性金条消费量首次超越首饰，公司核心珠宝首饰业务营收下降9.22%，拖累整体业绩。
- **[消费疲软与渠道优化调整]** -> [门店数量净减少]: 面对内需不足，公司主动关闭低效门店，全年净减少483家加盟店，但直营店净增16家，体现“提质增效”的战略转型。
- **[黄金交易业务增长]** -> [部分对冲主业下滑]: 黄金交易业务营收逆势增长4.37%，毛利率稳定，成为营收结构中少数增长的板块，部分弥补了珠宝首饰销售的缺口。
- **[经营性现金流大幅改善]** -> [营运效率提升]: 经营活动现金流净额同比大增102.9%，主要因销售回款降幅小于采购支付降幅，表明公司在高金价环境下加强了库存与资金管理。
- **[管理费用与研发费用缩减]** -> [短期利润的支撑]: 管理费用同比下降19.15%，研发费用下降40.83%，通过压缩非核心开支，在一定程度上缓解了营收下滑对利润的冲击。
- **[财务费用因汇兑损失增加]** -> [侵蚀利润]: 香港子公司因汇率波动产生汇兑损失，导致财务费用同比增加35.77%，对净利润形成额外压力。
- **[产业链延伸与智能制造投入]** -> [长期竞争力构建]: 公司设立精炼厂、启动旧金回收业务、推进“工业上楼”项目，旨在完善产业链闭环，为未来降本增效和高端化发展奠定基础。

## 风险警告
**核心风险在于黄金消费结构的根本性转变。** 金价持续高企已导致黄金首饰消费量首次被金条投资超越，这对以珠宝首饰为核心收入来源的老凤祥构成结构性威胁。公司营收与利润已连续两年下滑，若金价维持高位或继续上涨，首饰消费可能进一步萎缩，而毛利率极低的黄金交易业务无法弥补利润缺口，公司可能面临“增收不增利”甚至“量价齐跌”的困境。

**渠道收缩与品牌老化的双重压力。** 尽管公司主动优化门店，但加盟店一年内净减少近500家，反映出终端动销疲软和经销商信心不足。同时，公司研发投入极低（仅占营收0.03%），产品创新依赖IP联名，在年轻消费群体中的品牌吸引力面临挑战。若无法有效提升产品附加值或开辟新的增长曲线（如高端定制、海外市场），公司可能陷入增长瓶颈。
