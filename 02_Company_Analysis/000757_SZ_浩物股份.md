# 000757.SZ 深度透视

## 因果逻辑链
- **[汽车销售业务关停低效门店]** -> [营收下降22.31%]: 主动关停退网低效4S店，叠加市场内卷致整车售价下降，导致汽车服务收入同比减少26.50%。
- **[新能源曲轴销量占比提升至54.46%]** -> [零部件业务利润增长7.79%]: 抓住自主品牌及新能源渗透率提升机遇，成为比亚迪、理想、赛力斯等头部车企主要供应商，对冲了传统燃油车曲轴销量下滑。
- **[汽车后市场服务毛利率提升]** -> [整体扭亏为盈]: 整车销售毛利率同比+0.95%，后市场服务毛利率同比+0.55%，服务业务的结构优化是利润修复的核心。
- **[2024年低效门店关停的结构调整红利]** -> [2025年汽车服务业务扭亏]: 2024年完成低效门店出清后，2025年汽车服务业务净利润同比大幅增长109.97%，轻装上阵。
- **[“两新”政策加力扩围]** -> [激活终端需求]: 以旧换新补贴政策刺激消费，公司所经销的上汽大众、东风日产等品牌在天津市场占有率保持头部。
- **[金鸿曲轴智能化产线投产]** -> [制造成本与效率优化]: 自主完成桁架改造，建成2条智能化产线，日均产量提升9.8%，支撑了制造业毛利率稳定。
- **[投资性房地产公允价值变动]** -> [非经常性损益波动]: 报告期公允价值变动损失592万元，是利润总额的重要减项，但非核心业务。

## 风险警告
公司核心风险在于汽车经销业务的持续萎缩。2025年整车销量同比下降21.04%，收入同比大降29.38%，且所有门店均为租赁物业，无自有土地，在行业下行周期中经营杠杆极高。尽管通过关停低效店实现扭亏，但天津区域市场容量有限，新能源品牌（小米、阿维塔）的增量能否完全对冲合资品牌（上汽大众、一汽大众）的持续下滑，存在较大不确定性。

第二风险是零部件业务的客户集中度与行业技术迭代。曲轴业务虽受益于新能源混动/增程路线，但客户高度集中于奇瑞、比亚迪、理想等少数头部主机厂，议价能力受限。同时，若纯电平台进一步压缩混动/增程市场空间，或主机厂自研曲轴，将对公司核心制造业务构成颠覆性冲击。此外，公司研发投入占营收比仅1.25%，在智能化转型中技术储备相对薄弱。
