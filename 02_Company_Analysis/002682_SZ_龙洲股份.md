# 002682.SZ 深度透视

## 因果逻辑链
- **[沥青供应链毛利率改善]** -> [兆华集团减亏58.75%]: 沥青业务毛利率同比提升1.23个百分点，叠加成本控制，核心亏损收窄。
- **[中汽宏远停工停产及诉讼]** -> [巨额亏损-24,801.90万元]: 新能源客车业务无订单，计提停运损失、退车损失及电池售后费用14,826.90万元，叠加多起买卖合同纠纷诉讼。
- **[武夷股份土地收储]** -> [净利润暴增2610%至8,676.23万元]: 考亭片区土地房屋收储产生非经常性收益9,669.05万元，掩盖了客运主业的下滑。
- **[商誉减值集中爆发]** -> [资产减值损失8,555.25万元]: 对兆华集团、安徽中桩物流、中汽宏远等子公司计提商誉减值，直接侵蚀利润。
- **[汽车制造业务需求萎缩]** -> [营收暴跌78.28%，毛利率-86.26%]: 电网保供能力提升、柴油价格高位、国六排放标准趋严，导致移动电源车需求断崖式下滑。
- **[应收账款与合同资产高企]** -> [坏账风险与资金占用]: 应收账款达10.73亿元，合同资产5.81亿元，合计占总资产近30%，回款压力巨大。
- **[无控股股东治理结构]** -> [管理风险上升]: 2024年3月变更为无控股股东状态，业务扩张与多板块协同面临更大的管理挑战。

## 风险警告
**核心风险在于“资产黑洞”与“主业失血”的双重挤压。** 中汽宏远已资不抵债（净资产-6.85亿元），停工停产且深陷多起重大诉讼，计提的预计负债和资产减值损失持续吞噬利润，是公司最大的亏损源。同时，沥青供应链（兆华集团）虽减亏但毛利率仅1.84%，港口码头业务（安徽中桩物流）受基建放缓影响持续亏损，两大核心物流板块造血能力严重不足。

**财务风险高企，偿债能力堪忧。** 公司净资产已从15.12亿元骤降至6.05亿元，资产负债率极高。短期借款14.98亿元，长期借款8.84亿元，而货币资金仅3.14亿元，短期偿债压力巨大。经营活动现金流净额同比大幅下降60.52%，显示主营业务回款能力恶化。叠加高额的应收账款和合同资产减值风险，公司已陷入“亏损-资产减值-现金流恶化”的恶性循环，持续经营能力面临严峻考验。
