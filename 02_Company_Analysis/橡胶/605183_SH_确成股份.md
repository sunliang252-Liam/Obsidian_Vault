# 605183.SH 深度透视

## 因果逻辑链
- **[绿色轮胎需求增长]** -> [二氧化硅销量创历史新高]: 新能源汽车与绿色轮胎法规推动高分散二氧化硅用量提升，公司作为核心供应商受益。
- **[IPO募投产能释放]** -> [营收微增1.04%]: 新增产能转化为销量增长4.59%，但纯碱等原材料降价导致产品均价下降，抵消了部分收入增量。
- **[硫磺价格飙升]** -> [成本端承压]: 子公司硫酸收入虽增，但自产硫酸成本急剧上涨，叠加汇兑损失，导致净利润同比下降8.10%。
- **[人民币/泰铢升值]** -> [财务费用大幅增加]: 境外销售占比高，汇率波动产生约2300万元汇兑损失，是利润下滑的核心原因之一。
- **[全产业链布局]** -> [成本控制与原料保障]: 自产硅酸钠、硫酸及余热发电，平抑原材料价格波动，保障供应稳定，形成成本优势。
- **[生物质（稻壳）二氧化硅技术]** -> [绿色竞争力提升]: 获得ISCC PLUS认证，契合下游客户减碳需求，成为差异化竞争优势，推动高附加值产品销售。
- **[产品结构优化]** -> [毛利率提升]: 高分散二氧化硅、牙膏用二氧化硅等高附加值产品占比增加，推动二氧化硅产品毛利率同比提升1.14个百分点。
- **[客户认证壁垒]** -> [稳固的客户关系]: 国际轮胎巨头认证周期长达2-4年，公司已获主流客户认证，形成深厚护城河，保障长期订单稳定性。

## 风险警告
**核心风险在于汇率波动与原材料成本失控。** 公司境外收入占比超47%，2025年因人民币和泰铢对美元升值，产生约2300万元汇兑损失，直接吞噬利润。若未来汇率持续不利波动，将对盈利能力造成显著冲击。同时，硫磺价格在新能源需求驱动下飙升至历史高位，作为核心原材料，其价格剧烈波动将直接推高生产成本，公司虽有全产业链布局，但难以完全对冲。

**成长性隐忧在于营收增速放缓与产能消化压力。** 2025年营收仅增长1.04%，远低于销量增速，显示产品均价承压。尽管泰国二期、盐城生物质项目等新产能即将投产，但若下游绿色轮胎需求增速放缓或行业竞争加剧导致价格战，新增产能可能无法被有效消化，导致资产回报率下降。此外，公司实际控制人持股高度集中，存在不当控制风险。
