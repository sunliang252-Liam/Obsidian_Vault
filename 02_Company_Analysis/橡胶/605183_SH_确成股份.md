# 605183.SH 深度透视

## 因果逻辑链
- **[绿色轮胎需求增长]** -> [二氧化硅销量创历史新高]: 新能源汽车与绿色轮胎法规推动高分散二氧化硅用量提升，公司作为核心供应商受益。
- **[IPO募投产能释放]** -> [营收微增1.04%]: 新增产能转化为销量增长4.59%，但纯碱等原材料降价导致产品均价下降，抵消了部分收入增量。
- **[硫磺价格飙升]** -> [成本端承压]: 子公司硫酸收入虽增，但自产硫酸成本急剧上涨，叠加汇兑损失，导致净利润同比下降8.10%。
- **[人民币/泰铢升值]** -> [财务费用大幅增加]: 境外销售占比高，汇率波动产生约2300万元汇兑损失，是利润下滑的核心原因之一。
- **[全产业链布局]** -> [成本控制与原料保障]: 自产硅酸钠、硫酸及余热发电，平抑原材料价格波动，保障供应稳定，形成成本优势。
- **[生物质（稻壳）二氧化硅技术]** -> [绿色竞争力提升]: 获得ISCC PLUS认证，契合下游客户减碳需求，成为差异化竞争优势，推动高附加值产品销售。
- **[产品结构优化]** -> [毛利率提升]: 高分散二氧化硅、牙膏用二氧化硅等高附加值产品占比增加，推动二氧化硅产品毛利率同比提升1.14个百分点。
- **[客户认证壁垒]** -> [稳固的客户关系]: 国际轮胎巨头认证周期长达2-4年，公司已获主流客户认证，形成深厚护城河，保障长期订单稳定性。

## 风险警告
**核心风险在于汇率波动与原材料成本失控。** 公司境外收入占比超47%，2025年因人民币和泰铢对美元升值，产生约2300万元汇兑损失，直接吞噬利润。若未来汇率持续不利波动，将对盈利能力造成显著冲击。同时，硫磺价格在新能源需求驱动下飙升至历史高位，作为核心原材料，其价格剧烈波动将直接推高生产成本，公司虽有全产业链布局，但难以完全对冲。

**成长性隐忧在于营收增速放缓与产能消化压力。** 2025年营收仅增长1.04%，远低于销量增速，显示产品均价承压。尽管泰国二期、盐城生物质项目等新产能即将投产，但若下游绿色轮胎需求增速放缓或行业竞争加剧导致价格战，新增产能可能无法被有效消化，导致资产回报率下降。此外，公司实际控制人持股高度集中，存在不当控制风险。

> 确成硅化学股份有限公司成立于2003年,总部位于江苏无锡,是一家致力于全球化生产和运营的专业绿色新材料供应商,拥有从原材料硫酸、硅酸钠到最终产品沉淀法二氧化硅的完整产业链。2020年12月在上海证券交易所主板挂牌上市。公司拥有国际化的研发和管理团队,由全球著名行业专家担任首席科学家,致力于提升企业的研发创新能力。公司多年深耕主业,在二氧化硅行业积累了强大的技术优势。公司核心产品高分散二氧化硅生产技术获得中国石油和化学工业联合会颁发的科技进步二等奖。公司荣获国家工信部“专精特新‘小巨人’企业”、“江苏省隐形企业冠军”、“江苏省五一劳动奖状”、“中国石油和化工行业技术创新示范企业”等多项荣誉,是中国二氧化硅产品行业标准起草单位、中国硅化物(无锡)产业基地、江苏省高新技术企业、江苏省无机硅化物工程技术研究中心、江苏省博士后创新实践基地,并已通过REACH、FDA、FAMI-QS、ISO、CNAS等多项权威认证。公司秉承“把最优质的产品以最有竞争力的价格及时地交付给客户”的经营理念,诚信立企,获得了较高的行业认可度,拥有优异的客户结构,涵盖了多家国际轮胎巨头、高速发展的中国优质轮胎企业以及世界维生素E行业巨头。高客户粘性、技术创新优势、高行业壁垒助力公司持续成长。公司坚持“产品领先、技术与效率驱动、全球化经营”的发展战略,致力于打造绿色工厂、智能工厂、美丽工厂。目前下属六个子公司和一个分支机构,分别位于江苏无锡、安徽凤阳、福建沙县、香港、上海以及泰国罗勇。同时,公司欧洲研发中心和生产基地正在积极进行前期筹备,这一举措将有利于公司贴近前沿技术发展,吸引行业顶尖人才,更好地满足高端客户需求。公司重视人才培养,重视企业文化建设,着力打造企业组织能力,提升员工认同感、归属感,提升企业软实力。公司积极参与社会公益事业,承担企业社会责任,以最大诚意努力回报社会。
