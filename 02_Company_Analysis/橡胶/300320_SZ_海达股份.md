## 因果逻辑链
- **[汽车整车密封业务规模化放量]** -> [汽车用产品收入增长14%，毛利率提升2.08%]: 前期同步开发的整车密封条项目进入量产阶段，叠加“V530项目”切入高端供应链，实现规模效应与成本优化。
- **[轨道交通业务订单高景气]** -> [轨道交通用产品收入增长16%，毛利率提升2.01%]: 盾构隧道止水密封件受益于城市管网建设与重大工程（如川藏铁路）需求，订单承接能力保持高位。
- **[经营活动现金流大幅改善]** -> [经营活动现金流净额增长277%至3.58亿元]: 公司加大收款力度，销售回款显著增加，应收账款周转效率提升。
- **[原材料价格高位波动]** -> [资产减值损失扩大249%至7856万元]: 主要受EPDM等原材料价格跳涨影响，公司计提存货跌价准备及商誉减值损失。
- **[轻量化铝制品业务稳健]** -> [铝制产品收入增长10.5%，毛利率稳定在7.86%]: 科诺精工凭借天窗导轨龙头地位，成功拓展新能源汽车电池冷凝管等新客户，维持增长。
- **[航运业务收入下滑]** -> [航运用产品收入下降22.28%]: 行业整体低迷，公司虽经营表现超预期，但收入规模仍受市场环境压制。
- **[光伏辅材业务从0到1]** -> [其他橡胶件收入下降2.43%，但卡扣短边框产品形成小批量订单]: 与隆基绿能合作开发全面屏边框产品，处于市场导入期，尚未贡献显著收入。
- **[海外布局取得进展]** -> [罗马尼亚工厂通过IATF16949认证，提升海外项目竞争力]: 海外工厂独立运营能力增强，为承接国际天窗密封件订单奠定基础。

## 风险警告
**核心风险在于原材料价格暴涨与商誉减值压力。** 报告期内，受地缘政治冲突影响，EPDM等核心原材料价格跳涨，直接导致公司资产减值损失同比扩大249%，侵蚀利润。若国际油价持续高位或供应链紧张加剧，公司成本管控将面临严峻挑战，尤其是轨道交通长周期订单的毛利率存在被压缩风险。此外，子公司科诺精工经营未达预期，已触发商誉减值，未来若其盈利能力未能改善，将进一步拖累业绩。

**应收账款高企与下游需求不确定性并存。** 公司应收账款占销售收入比重仍较大，且下游轨道交通、建筑等领域客户资金紧张，回款周期较长。虽然公司加大催收力度，但若宏观经济增速放缓或下游行业景气度下行，坏账风险可能上升。同时，汽车领域新项目（如V530）的量产进度、光伏卡扣边框的市场推广均存在不确定性，新业务放量节奏可能低于预期。
