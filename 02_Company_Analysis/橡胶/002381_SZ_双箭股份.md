# 002381.SZ 深度透视

## 因果逻辑链
- **[下游需求疲软 + 行业竞争白热化]** -> [营收微降1.4%]: 国内煤炭、钢铁、建材等下游行业需求不振，中低端输送带市场供过于求，价格承压，导致公司整体收入小幅下滑。
- **[原材料价格回落]** -> [成本压力缓解]: 2025年天然橡胶等主要原材料价格整体回落，降低了公司采购成本，但未能完全对冲产品售价下调及竞争加剧的影响。
- **[资产减值损失激增]** -> [净利润暴跌57.48%]: 报告期内计提资产减值损失4986万元（同比+146%），是吞噬利润的核心因素，主要源于应收账款坏账准备及存货跌价准备。
- **[台升科技新产能爬坡]** -> [短期拖累利润]: 子公司台升科技“年产6000万平米智能型输送带项目”一期投产，但处于产能爬坡期，尚未实现盈利，报告期亏损3871万元，显著拉低合并净利润。
- **[精细化管理 + 降本增效]** -> [经营性现金流大幅改善]: 通过优化供应链、控制库存、减少采购现金支出，经营活动现金流净额从7524万元飙升至2.62亿元，同比增长248%。
- **[高端产品 + 海外市场]** -> [结构性增长]: 高强力、高耐磨、低滚阻的高端输送带需求旺盛，海外业务收入同比增长0.8%，毛利率达24.59%，成为利润的重要稳定器。
- **[养老业务减亏]** -> [多元化探索]: 养老服务收入增长23.55%至7778万元，亏损收窄，居家养老业务实现跨越式发展，但整体仍处于培育期，对主业贡献有限。

## 风险警告
**核心风险在于利润质量急剧恶化。** 公司营收仅微降1.4%，但净利润却暴跌57.48%，根本原因并非经营亏损，而是高达4986万元的资产减值损失。这暴露出公司在行业下行周期中，下游客户回款能力恶化，存货积压风险上升。若宏观经济持续疲软，应收账款和存货的减值压力可能进一步加大，侵蚀公司本就脆弱的利润基础。

**产能扩张与市场需求错配的风险不容忽视。** 公司正全力推进“年产6000万平米智能型输送带项目”，产能目标突破1.5亿平米。然而，当前下游传统行业需求不振，普通输送带供大于求。新产能的释放若不能有效转化为高端产品订单或海外市场份额，将导致产能利用率下降、折旧成本高企，子公司台升科技的亏损可能成为常态，进一步拖累整体盈利能力。
