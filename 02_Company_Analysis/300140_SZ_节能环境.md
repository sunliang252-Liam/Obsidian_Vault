# 300140.SZ 深度透视

## 因果逻辑链
- **[固废综合处理业务规模领先]** -> [营收稳定]: 公司拥有47家垃圾焚烧项目公司，年处理量1924.67万吨，市场占有率约8.76%，规模优势构筑了稳定的收入基本盘。
- **[精细化管理与成本管控]** -> [净利润大幅增长43.89%]: 通过“五位一体”生产定额管理、集中采购等降本增效措施，在营收仅增长1.15%的情况下，推动归母净利润从6.05亿跃升至8.71亿。
- **[应收账款及合同资产回收]** -> [经营现金流强劲]: 尽管应收账款高达50.2亿，但公司加大清收力度，叠加地方政府化债资金到位，经营活动现金流净额达22.0亿元，同比增长17.46%。
- **[财务费用下降]** -> [利润增厚]: 报告期内偿还借款减少，财务费用同比下降21.96%，直接贡献了利润弹性。
- **[研发投入阶段性缩减]** -> [短期费用节省]: 前期国家重大科技项目结题，2025年研发费用同比减少50.63%，节省了当期费用，但可能影响长期技术储备。
- **[环保装备业务亏损]** -> [拖累整体盈利]: 环保装备业务毛利率为-29.42%，收入同比腰斩，成为公司业绩的明显拖累项。
- **[电工装备业务增长]** -> [多元化贡献]: 电工装备业务收入同比增长18.23%，海外市场拓展顺利，为公司提供了除固废主业外的增长点。

## 风险警告
**核心风险在于巨额应收账款与合同资产的回收不确定性。** 截至2025年末，公司应收账款高达50.2亿元，占营收比重超80%，对手方主要为地方政府和电网公司，虽违约概率低，但回款周期不可控。尽管当期经营现金流强劲，但信用减值损失高达1.48亿元，若地方财政持续紧张或补贴政策生变，坏账风险将直接侵蚀利润。

**同业竞争解决与资产注入进度不及预期。** 控股股东承诺在2028年前解决同业竞争问题，但目前仅通过托管方式管理相关资产，尚未启动实质性注入。若资产注入方案、定价或时间表低于市场预期，将影响公司估值逻辑和长期增长空间。同时，环保装备业务持续亏损，海外市场拓展面临地缘政治和汇率波动风险，新业务培育尚需时日。
