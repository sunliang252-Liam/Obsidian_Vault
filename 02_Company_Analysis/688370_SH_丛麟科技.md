# 688370.SH 深度透视

## 因果逻辑链
- **[行业产能过剩，竞争加剧]** -> [营收与利润双降]: 危废处置价格较峰值跌幅超60%，公司2025年营收同比下降11.59%，归母净利润暴跌74.27%，扣非净利润转负。
- **[处置单价与处置量双降]** -> [主营业务毛利率大幅下滑]: 危废处置业务毛利率从34.85%降至25.31%，其中无害化处置毛利率下降11.2个百分点，直接侵蚀核心盈利能力。
- **[营收收缩，成本刚性]** -> [扣非净利润亏损]: 营收下降11.59%，但营业成本仅微降1.68%，折旧、人工等固定成本无法同步压缩，导致扣非净利润为-868万元。
- **[非经常性损益依赖]** -> [账面净利润为正]: 公司通过理财收益（2665万元）及政府补助等非经常性损益，掩盖了主业亏损的实质，扣非净利润已为负值。
- **[子公司大面积亏损]** -> [拖累合并报表]: 山东环沃（-3427万）、夏县众为（-1439万）、蓬莱蓝天（-260万）等子公司严重亏损，抵消了核心子公司上海天汉（7174万）的利润贡献。
- **[高分红与低盈利背离]** -> [透支未来现金流]: 在净利润仅2317万元的情况下，公司拟分红2868万元，分红率高达123.79%，远超盈利水平，可能影响资本开支与偿债能力。
- **[战略转型生物柴油]** -> [培育新增长点]: 公司投资6800万元布局生物柴油（UCOME）赛道，一期20万吨/年产能已于2026年2月投产，旨在对冲危废主业下行风险。

## 风险警告
**核心风险在于主业已陷入“量价齐跌”的恶性循环，且短期内看不到拐点。** 危废行业产能利用率不足40%，处置价格较峰值腰斩，公司扣非净利润已转负，表明其经营活动已无法覆盖成本。更危险的是，公司通过高额理财收益和超比例分红来粉饰报表，一旦金融市场波动或监管收紧，财务面具将被撕破。

**第二重风险来自资产质量与子公司失控。** 公司固定资产占总资产近30%，折旧压力巨大。同时，山东环沃、夏县众为等子公司持续巨额亏损，净资产已为负值，存在资产减值与商誉暴雷的隐患。公司试图通过投资生物柴油转型，但新业务尚处投产初期，面临原料供应、价格波动及市场认证等多重不确定性，短期内难以成为利润支柱。
