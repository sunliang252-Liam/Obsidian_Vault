# 300110.SZ 深度透视

## 因果逻辑链
- **[商誉减值]** -> [净利润巨亏4.63亿元]: 子公司安徽恒星制药和广西裕源药业经营未达预期，计提商誉减值5.25亿元，直接导致全年由盈转亏。
- **[集采降价]** -> [基础输液收入下滑23.32%]: 药品价格政策持续施压，公司主动收缩基础输液业务，导致该板块收入大幅下降，但毛利率基本持平。
- **[产品结构升级]** -> [治疗制剂与腹透液收入高增]: 公司聚焦高附加值领域，治疗制剂收入增24%、腹透液收入增32%，成功对冲基础输液下滑，营收仅微降2.34%。
- **[原料+制剂一体化]** -> [精麻科管线壁垒增强]: 恒星制药新增7个原料药和2个制剂批件，实现原料自主可控，为喷他佐辛等精麻药品构筑竞争护城河。
- **[集采中标]** -> [市场份额扩张]: 腹透液、血滤液、喷他佐辛等多产品中标浙江、河北等省级集采，带动销量增长，腹透液销量同比增40%。
- **[营销体系改革]** -> [直销占比提升5.51个百分点]: 新设营销中心、实行省区垂直化管理，推动直销模式转型，增强终端掌控力与客户粘性。
- **[现金流改善]** -> [经营质量优于利润]: 严控成本费用，经营活动现金流净额同比增21%至3.9亿元，与巨额亏损形成鲜明对比，显示主业造血能力尚可。

## 风险警告
**核心风险在于商誉“地雷”尚未排清。** 尽管2025年已计提5.25亿元减值，但截至年末商誉账面价值仍高达2.08亿元，主要对应恒星制药与裕源药业。若这两家子公司未来盈利能力持续受集采降价或竞争加剧影响，存在进一步减值风险，可能继续侵蚀利润。此外，公司因收购恒星制药引发的股权转让纠纷诉讼涉案金额巨大（原告索赔2.56亿元，公司反诉要求返还5.44亿元），结果存在重大不确定性，可能带来巨额或有负债。

**经营层面，集采降价压力是长期悬顶之剑。** 公司核心产品腹透液、血滤液及多索茶碱等虽中标集采，但价格普遍下降（如腹透液中标价14.83元/袋），导致腹透液毛利率同比下滑1.71个百分点。随着集采范围扩大至更多品种，公司面临“以价换量”的持续考验，若销量增长无法完全弥补价格损失，整体盈利空间将被进一步压缩。同时，公司对国药药材的应收款项债务化解方案尚未执行完毕，存在坏账风险。
