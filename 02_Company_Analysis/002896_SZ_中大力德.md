# 002896.SZ 深度透视

## 因果逻辑链
- **工业机器人产量增长、人形机器人原型机批量落地、新能源领域设备更新需求** -> 精密减速器营收增长4.04%: 下游需求拉动精密减速器销售，但增速低于行业平均，可能受竞争加剧影响。
- **市场需求稳中有升、集成化转型加速、国产替代节奏加快** -> 减速电机营收增长8.14%: 多下游需求共振推动减速电机增长，且竞争格局相对有利。
- **行业竞争激烈、机械产品价格连续35个月下降** -> 精密减速器毛利率下降1.82个百分点: 供需矛盾导致价格战，原材料和制造成本上升进一步挤压毛利。
- **公司构建减速器+电机+驱动一体化产品架构** -> 智能执行单元营收增长5.80%: 一体化产品满足下游模组化需求，带动集成产品销量。
- **公司积极开拓海外市场，境外经销商网络初步建立** -> 境外营收增长35.02%: 海外市场拓展见效，境外销售增速远超境内。
- **经销模式收入增长27.48%，直销下降7.59%** -> 销售费用增长19.41%: 经销模式下公司需承担更多销售支持费用，且渠道拓展投入增加。
- **研发投入减少1.40%** -> 管理费用增长22.73%: 管理费用中工资及折旧摊销增加，研发投入略有缩减，但总体费用结构变化可能反映公司侧重短期销售而非长期研发。
- **人形机器人、工业机器人对精密减速器需求爆发** -> 公司立项多项机器人相关减速器研发项目: 下游新兴需求驱动公司加速研发，以抢占市场先机。
- **国内通用设备行业供强需弱矛盾突出** -> 行业利润率下滑至5.14%: 产能过剩导致价格竞争，压缩行业利润空间。

## 风险警告
核心风险在于行业供需结构性矛盾导致的价格战持续，公司精密减速器毛利率已受侵蚀；应收账款回收难度加大（行业账款回收难问题凸显）；境外市场开拓虽有成效，但国际形势紧张，贸易环境不确定性增加；公司研发投入减少可能影响长期竞争力，而管理费用高增需关注费用控制。
