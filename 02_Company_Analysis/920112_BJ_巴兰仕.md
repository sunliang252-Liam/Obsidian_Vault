# 920112.BJ 深度透视

## 因果逻辑链
- **[外销占比高+汇率波动]** -> [财务费用大幅波动]: 外销收入占比约75%，以美元结算为主，2025年汇率波动频繁导致汇兑收益减少，财务费用同比上升88.80%。
- **[钢材等原材料价格下降]** -> [毛利率提升]: 直接材料成本占比大，钢材价格下行直接降低单位成本，2025年毛利率同比提升1.48个百分点至30.03%。
- **[汽车保有量增长+车龄老化]** -> [收入稳健增长]: 国内汽车保有量3.66亿辆、平均车龄7年，叠加新能源车渗透率提升，驱动维保设备需求增加，2025年营收同比增长5.98%。
- **[规模效应+成本优化]** -> [净利润增速超营收]: 营收增长叠加毛利率提升，2025年归母净利润同比增长13.05%，增速显著高于营收增速。
- **[北交所上市募资]** -> [资产规模与现金流大幅扩张]: 2025年8月上市，募集资金净额约2.99亿元，总资产同比增长61.35%，筹资活动现金流净额同比转正至2.57亿元。
- **[产能利用率超100%]** -> [募投项目扩产紧迫]: 主要产品产能利用率已超100%，募投项目“智能化改造及扩产”和“举升设备智能化工厂”旨在突破产能瓶颈。
- **[收购宝合智能工具类业务]** -> [丰富产品线+拓展工业领域]: 收购智能工具柜、绝缘工具等业务，将业务从汽保设备拓展至铁路、航空、电力等工业领域，完善一站式解决方案。
- **[专利诉讼风险]** -> [潜在经营不确定性]: 报告期内存在2起专利诉讼，虽部分已撤诉或专利被宣告无效，但仍有涉案金额合计1000万元的案件在审理中。

## 风险警告
**核心风险在于专利诉讼的尾部不确定性。** 尽管营口大力案已撤诉，奈克希文案中一项专利被宣告全部无效，但仍有涉案金额合计1000万元的两项部分无效专利诉讼在审理中。若最终败诉，可能面临赔偿及产品禁售风险，对公司核心产品（如举升机、拆胎机）的海外销售构成潜在冲击。

**外销依赖与汇率波动的双重脆弱性。** 公司外销收入占比约75%，以美元结算为主。2025年财务费用因汇兑收益减少而大幅上升，已暴露汇率风险。若人民币进入升值通道，不仅将直接产生汇兑损失，还会削弱产品在海外市场的价格竞争力，对盈利能力形成持续压制。公司目前未采取有效对冲措施，风险敞口较大。
