# 600510.SH 深度透视

## 因果逻辑链
- **[房地产项目交付周期与毛利率双降]** -> [归母净利润暴跌44.66%]: 地产收入同比-37.79%，毛利率骤降26.75个百分点，导致利润大幅缩水。
- **[施工业务爆发式增长]** -> [建筑收入同比+50.40%]: 龙江路高架北延等大型市政工程集中确认收入，成为业绩核心支撑。
- **[销售费用激增与财务费用反转]** -> [侵蚀利润空间]: 销售费用同比+41.53%（去化推广），财务费用因利息收入减少同比+45.46%，双重挤压净利润。
- **[房地产项目周期导致现金流恶化]** -> [经营现金流净流出1.46亿]: 销售回款减少叠加土地款支出，同比由净流入5.62亿转为净流出。
- **[越南生产基地投产在即]** -> [海外产能布局关键突破]: 基建进度90%，一期设备安装调试完成，为规避贸易壁垒、承接海外订单奠定基础。
- **[参股赛迈科上市辅导获受理]** -> [潜在投资收益弹性]: 持股8.20%的特种石墨“小巨人”企业推进IPO，若成功上市将带来可观公允价值变动收益。
- **[联营企业无锡绿鸿坏账风险持续暴露]** -> [资产减值损失压力]: 对其借款计提坏账准备2.29亿元，账面价值仅剩3.0亿元，回收存在重大不确定性。
- **[存货高企与去化压力并存]** -> [资产减值风险]: 存货账面余额86.64亿元，已计提跌价准备11.71亿元，房地产市场调整下仍有减值风险。

## 风险警告
**核心风险在于房地产板块的深度调整与现金流压力。** 公司归母净利润同比腰斩，主因地产收入下滑及毛利率断崖式下跌，且经营现金流由正转负，显示销售回款不畅。尽管施工业务增长强劲，但难以完全对冲地产板块的拖累。存货规模庞大（74.93亿），在行业下行周期中，去化速度和资产减值压力是持续威胁。

**另一重大风险来自对外投资的信用敞口。** 对参股公司无锡绿鸿的借款（本金4.34亿）已计提2.29亿坏账，回收前景堪忧。同时，公司持有大量江苏银行股票（14.87亿），其公允价值波动将直接影响利润表。此外，越南纺织基地投产初期面临产能爬坡、海外管理及贸易政策不确定性，短期可能拖累业绩。
