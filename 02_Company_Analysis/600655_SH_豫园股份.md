# 600655.SH 深度透视

## 因果逻辑链
- **[房地产行业深度下行]** -> [巨额资产减值]: 对存在减值迹象的房地产项目计提大额资产减值准备，直接侵蚀利润。
- **[国际金价高位震荡]** -> [珠宝时尚收入下滑]: 金价剧烈波动抑制终端消费需求，叠加消费结构调整，导致核心珠宝业务收入同比下降24.16%。
- **[处置非核心资产收益锐减]** -> [净利润断崖式下跌]: 2024年依赖出售资产维持利润，2025年此类投资收益大幅减少，叠加主业亏损，归母净利润暴跌4009%。
- **[消费市场结构性调整]** -> [餐饮连锁大规模关店]: 宏观经济承压，文化饮食板块正餐盈利能力受损，公司主动关停103家低效门店，拖累整体效益。
- **[物业开发销售回款减少]** -> [经营性现金流恶化]: 房地产销售回款同比下降，导致经营活动现金流净额减少42.38%，现金创造能力显著削弱。
- **[投资性房地产公允价值变动]** -> [非经常性亏损]: 以公允价值计量的投资性房地产产生7.68亿元公允价值变动损失，成为非经常性亏损的主要来源。
- **[“瘦身健体”战略执行]** -> [资产规模收缩]: 持续出售非核心资产、退出低效业务，导致总资产同比下降4.8%，净资产下降15.57%。

## 风险警告
**核心风险在于房地产板块的“失血”与珠宝主业“造血”能力下滑的双重打击。** 公司2025年巨亏48.97亿元，主因是房地产行业深度调整下的大额资产减值，以及此前依赖的资产出售收益模式不可持续。珠宝时尚作为核心主业，虽毛利率微增，但收入规模大幅萎缩，且门店净减少663家，显示终端需求疲软与渠道收缩压力。公司整体处于“瘦身”阵痛期，资产质量与盈利能力均面临严峻考验。

**财务风险与战略风险交织。** 公司总负债规模依然庞大，虽通过处置资产回笼资金，但经营性现金流大幅下降，偿债压力不容忽视。同时，公司战略从“买买买”转向“卖卖卖”，虽然方向正确，但核心主业增长乏力，新增长点（如海外业务、AI赋能）尚在培育期，短期内难以弥补地产和珠宝下滑的缺口。若房地产市场持续低迷或金价出现极端波动，公司可能面临更大的流动性危机和资产减值风险。
