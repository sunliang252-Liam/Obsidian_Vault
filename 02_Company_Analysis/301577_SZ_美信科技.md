# 301577.SZ 深度透视

## 因果逻辑链
- **[功率类磁性元器件策略性定价与产能爬坡]** -> [功率类毛利率下滑15.37%]: 为抢占AI服务器电源、储能等高增长赛道份额，公司主动降价，但新品类尚处产能爬坡阶段，单位成本高企，导致毛利率大幅下降。
- **[信号类磁性元器件稳健增长]** -> [营收同比增长9.26%]: 依托2.5G/万兆网络变压器、片式绕线电感等核心产品在通信、数据中心领域的稳定需求，信号类业务成为公司营收的“压舱石”。
- **[资产减值损失激增]** -> [净利润由盈转亏]: 基于会计谨慎性原则，对存货等存在减值迹象的资产计提1,331.8万元减值准备，是当期亏损的直接财务原因之一。
- **[新厂启用与子公司筹建]** -> [期间费用显著上升]: 湾区总部园区投产、泰国及深圳子公司筹备，叠加研发与市场投入增加，导致管理费用、销售费用及财务费用（受美元汇率波动影响）同比上升。
- **[“信号类+功率类”双轮驱动战略]** -> [业务结构优化，但短期承压]: 信号类业务稳定基本盘，功率类业务切入高增长赛道，但后者尚处投入期，导致公司整体营收微降2.1%，净利润出现亏损。
- **[全球化产能布局推进]** -> [长期增长潜力蓄能]: 湾区总部投产、泰国工厂即将投产，为公司未来承接海外订单、提升全球服务能力奠定产能基础，但短期带来折旧与运营成本压力。
- **[核心客户认证突破]** -> [高端市场准入壁垒建立]: 功率类产品通过国际知名企业验证，成功切入AI服务器电源、兆瓦闪充充电桩等高端领域，为后续规模化放量提供客户基础。

## 风险警告
公司当前最核心的风险在于**功率类业务的盈利拐点高度不确定**。该业务为抢占市场份额而采取的策略性定价，叠加产能爬坡期的低效成本，导致毛利率大幅转负（-8.18%）。若下游AI服务器、新能源汽车等需求增速放缓，或公司产能利用率提升不及预期，该业务将持续拖累整体利润，存在“增收不增利”甚至持续亏损的风险。

其次，**新产能释放带来的短期财务压力**不容忽视。湾区总部园区于2025年底投产，泰国工厂尚在筹建，短期内将产生大量折旧、摊销及运营费用，而新产能的满产需要时间。若新客户导入与订单获取速度低于预期，公司将面临固定资产折旧侵蚀利润、现金流承压的双重困境。
