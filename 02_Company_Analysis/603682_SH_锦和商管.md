# 603682.SH 深度透视

## 因果逻辑链
- **[商办市场租金下行]** -> [营收与利润双降]: 市场供大于求，公司“以价换量”虽稳住出租率，但边际租金单价持续下跌，导致主营业务毛利率下滑，净利润承压。
- **[租金下行引发资产减值]** -> [巨额亏损]: 基于谨慎性原则，公司对部分存在减值迹象的承租运营项目计提大额使用权资产减值准备（2.38亿），是导致归母净利润由盈转亏（-1.19亿）的核心原因。
- **[聚焦高效益项目]** -> [在管规模收缩]: 公司主动盘整项目组合，退出部分低效项目，导致在管面积和营业收入同比下降6.09%。
- **[成本管控与降本增效]** -> [费用显著下降]: 销售费用（-20.42%）和管理费用（-31.92%）大幅削减，部分对冲了收入下滑对利润的侵蚀。
- **[高财务杠杆]** -> [侵蚀利润]: 承租运营模式产生大量租赁负债，导致每年约1.6亿元的利息费用，是公司沉重的固定成本，严重压缩利润空间。
- **[关联方补偿款]** -> [非经常性损益支撑]: 来自广电浦东的越界创意园房屋拆除补偿款（约5374万元）是营业外收入的主要来源，掩盖了主营业务的真实亏损程度。
- **[北京子公司持续亏损]** -> [拖累整体业绩]: 北京新荟园壹等子公司仍处于爬坡期，成本刚性，出租率虽有提升但毛利率仍为负，成为业绩的主要拖累项。

## 风险警告
**核心风险在于商办市场租金下行的趋势尚未见底，公司“以价换量”策略的边际效应递减。** 尽管出租率企稳，但租金单价持续走低，导致公司核心的承租运营模式盈利模型承压。2025年计提的2.38亿使用权资产减值损失，直接反映了管理层对未来现金流预期的悲观，若市场持续低迷，未来仍有进一步减值的风险。

**公司面临严重的现金流与偿债压力。** 高额的租赁负债（约30亿）和财务费用（1.6亿）是刚性支出，而经营活动现金流净额（6.45亿）虽为正，但同比下降11.38%，且部分受托运营项目回款周期拉长。同时，控股股东高比例质押（22.44%）及关联方补偿款（广电浦东）的回收不确定性，进一步加剧了公司的财务脆弱性。
