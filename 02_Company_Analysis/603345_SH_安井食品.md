# 603345.SH 深度透视

## 因果逻辑链
- **[固定资产折旧及小龙虾原料成本增加]** -> [毛利率下降]: 营业成本增速(9.41%)超过收入增速(7.05%)，直接压缩利润空间，导致归母净利润下滑8.46%。
- **[美元兑人民币汇率持续下行]** -> [财务费用由负转正]: 汇兑损失大幅增加，财务费用从-7121万转为+136万，侵蚀利润。
- **[商誉减值损失增加]** -> [资产减值损失扩大]: 资产减值损失从-5220万扩大至-2.14亿，成为净利润下滑的核心拖累项之一。
- **[H股上市募资]** -> [筹资活动现金流大幅转正]: 筹资活动现金流净额从-11.98亿跃升至+14.88亿，显著改善资产负债表，总资产增长19.52%。
- **[收购鼎味泰，切入冷冻烘焙]** -> [新增收入增长点]: 烘焙食品贡献6796万元收入，并表后带来增量，但毛利率仅13.46%，低于传统主业。
- **[新零售及电商渠道扩张]** -> [渠道收入结构优化]: 新零售及电商收入同比增长31.76%，毛利率28.29%，成为增速最快且盈利性较好的渠道。
- **[“销地产”产能布局与产能利用率下降]** -> [规模效应与成本压力并存]: 产能利用率从高位降至90.37%，新基地投产带来折旧压力，但“销地产”模式长期有助于降低物流成本。
- **[速冻菜肴制品库存激增]** -> [营运资金占用增加]: 小龙虾相关产品库存导致菜肴制品库存量同比大增54.84%，存货总额增至36.47亿，增加资金占用和跌价风险。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 2025年营收增长7.05%，但归母净利润却下滑8.46%，扣非净利润下滑8.49%。利润下滑并非一次性冲击，而是由固定资产折旧增加、小龙虾原料成本上涨、汇兑损失和商誉减值等多重结构性因素叠加导致。若成本端压力无法有效传导至下游，或新业务（冷冻烘焙、清真食品）未能快速贡献利润，公司盈利能力可能进一步承压。

**第二重风险来自资产质量与现金流隐忧。** 速冻菜肴制品库存同比暴增54.84%，主要系小龙虾产品积压，存货总额高达36.47亿元，面临较大的跌价风险。同时，商誉账面价值高达7.55亿元，且本年度已发生大额减值，若被收购标的（如新柳伍已亏损）业绩持续不及预期，后续减值风险不可忽视。此外，短期借款同比激增701.52%，财务杠杆快速上升，需警惕偿债压力。
