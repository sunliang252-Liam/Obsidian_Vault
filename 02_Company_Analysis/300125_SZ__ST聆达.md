# 300125.SZ 深度透视

## 因果逻辑链
- **[重整计划执行完毕]** -> [净利润扭亏为盈]: 通过债务重组获得约1.83亿元收益，并冲回前期计提的预计负债，使归母净利润从-9.5亿转为+0.2亿。
- **[光伏电池片业务全面停产]** -> [营收结构剧变]: 太阳能电池业务收入归零，公司营收从8.39亿骤降至1.25亿，但EPC工程业务增长265.85%成为新支柱。
- **[重整投资人注入资金]** -> [货币资金暴增]: 收到重整投资人投资款，货币资金从0.2亿飙升至10.04亿，占总资产58%，彻底解决流动性危机。
- **[债务清偿与资产抵债]** -> [资产负债率大幅下降]: 通过清偿债务和以物抵债，负债总额从15.4亿降至6.76亿，净资产由负转正至10.53亿。
- **[光伏电站技改启动]** -> [发电业务毛利率飙升]: 二期50MW技改项目启动，叠加折旧摊销减少，光伏发电毛利率从-31.53%大幅提升至60.75%。
- **[核心子公司停产与重整]** -> [资产减值损失巨大]: 金寨嘉悦电池片业务停产，导致在建工程和固定资产计提减值准备1.57亿元，严重拖累扣非净利润。
- **[EPC业务扩张]** -> [营收增长但盈利微薄]: EPC工程收入增长265.85%，但毛利率仅1.23%，显示该业务规模扩张但盈利能力极弱。

## 风险警告
**核心风险在于“旧伤未愈，新路未明”。** 公司2025年净利润扭亏完全依赖债务重组等非经常性损益（约2.74亿元），扣非净利润仍巨亏2.54亿元，主营业务造血能力并未恢复。光伏电池片业务已彻底停产，EPC业务毛利率仅1.23%，难以支撑公司持续经营。公司虽手握10亿现金，但其中2.57亿被冻结，且大量资产处于抵押或用于偿债状态，实际可自由支配资金有限。

**战略转型面临巨大不确定性。** 公司计划从光伏EPC向半导体设备关键零部件国产替代等先进智造领域转型，但该业务目前仅处于“接洽阶段”，核心团队尚未完全到位，且面临技术积累、客户认证、行业竞争格局固化等严峻挑战。新业务从培育到产生稳定盈利需要漫长周期，期间任何不及预期都可能导致公司再次陷入困境。公司已申请撤销退市风险警示，但能否获批及转型能否成功，仍是悬而未决的最大风险。
