# 300900.SZ 深度透视

## 因果逻辑链
- **[下游客户采购节奏放缓与项目审批周期延长]** -> [营收下滑3.33%]: 公司航空航天零部件及无人机业务处于爬坡期，订单落地不及预期，导致收入未能同比增长。
- **[产能扩张带来的固定成本摊销加大]** -> [毛利率大幅下降11.53个百分点]: 设备折旧、人员成本等固定成本持续增加，而收入端未能同步增长，成本增速（+12.35%）远超收入增速（-3.33%）。
- **[存货规模增长与减值计提增加]** -> [净利润亏损扩大至1.02亿元]: 为保障交付增加备货，但受技术迭代与订单调整影响，存货跌价准备同比增加，直接侵蚀当期利润。
- **[融资规模扩大与“广联转债”利息计提]** -> [财务费用同比增长24.44%]: 银行借款增加及可转债利息费用持续计提，导致财务费用达9906万元，对利润形成阶段性压制。
- **[航空工装业务竞争加剧与价格承压]** -> [传统优势业务收入下滑7.34%]: 行业同质化竞争导致订单价格下调，公司主动避开低端价格竞争，但收入规模仍受冲击。
- **[经营活动现金流净额大幅增长102.44%]** -> [现金流与净利润严重背离]: 公司加强资金预算管理与支出管控，回款改善，但净利润因非现金减值与利息费用而亏损。
- **[核心子公司盈利稳定]** -> [整体业绩的“压舱石”]: 成都航新、西安中捷飞等子公司持续贡献利润，部分对冲了新兴业务与工装业务的亏损。

## 风险警告
公司当前面临的核心风险是**“增收不增利”与“高杠杆扩张”的双重困境**。营收仅微降3.33%，但净利润却由盈转亏，亏损高达1.02亿元，主因是产能扩张带来的折旧、存货减值以及高额财务费用（9906万元）的集中释放。公司资产负债率高达74.4%，且大量固定资产、在建工程已用于抵押借款，财务杠杆已处于高位，偿债压力与利息负担将持续压制未来盈利弹性。

此外，公司对前五大客户的依赖度高达85.82%，客户集中度极高，且董事长王增夺于报告期内被实施留置，给公司治理与核心客户关系带来重大不确定性。无人机、商业航天等新兴业务尚处于爬坡期，短期内难以贡献利润，而传统航空工装业务正面临价格战，公司正处于新旧动能转换的“青黄不接”阶段，业绩反转仍需时间验证。
