# 002906.SZ 深度透视

## 因果逻辑链
- **[汽车智能化渗透率提升]** -> [汽车电子营收增长27.25%]: HUD、座舱域控、电子后视镜等高附加值产品放量，驱动汽车电子业务收入达96.75亿元。
- **[汽车轻量化趋势与AI硬件需求]** -> [精密压铸营收增长38.47%]: 铝合金、锌合金零部件受益于新能源汽车三电系统及AI高速连接器需求爆发，收入达28.59亿元。
- **[产品市占率领先]** -> [规模效应与客户粘性增强]: HUD国内市占率第一、车载无线充电全球第二，头部地位带来持续订单与议价能力。
- **[研发投入持续加码]** -> [技术迭代与产品线扩展]: 研发费用9.91亿元（+19.21%），推动AI BOX、PHUD、舱驾一体域控等新品量产，构筑竞争壁垒。
- **[客户结构优化]** -> [单一客户依赖度降低]: 新势力（小米、小鹏）及国际品牌（STELLANTIS、大众）营收大幅增长，前五大客户占比44.07%，风险分散。
- **[产能扩张与海外布局]** -> [支撑未来增长]: 惠州、长兴、泰国等多基地建设，产能规模创历史新高，为订单交付提供保障。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额10.57亿元（+79.27%），显著高于净利润，回款能力增强。

## 风险警告
**毛利率承压与成本传导风险**：汽车电子毛利率同比下降2.61个百分点至16.59%，精密压铸毛利率下降1.78个百分点至23.89%。在整车厂持续压价、存储芯片等原材料价格波动的背景下，公司成本转嫁能力面临考验。若上游涨价或下游降价压力持续，盈利能力可能进一步收窄。

**应收账款与信用减值风险**：应收账款高达48.32亿元，占总资产33.59%，且信用减值损失计提5778万元（同比大幅增加）。汽车行业竞争加剧导致部分客户经营恶化，回款周期延长或坏账风险上升，可能对现金流和利润造成冲击。
