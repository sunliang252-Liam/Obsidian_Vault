# 600749.SH 深度透视

## 因果逻辑链
- **[印度香客入境游恢复]** -> [投资收益暴增13,847%]: 公司与西藏旅投合作承接印度香客接待业务，以投资收益形式确认业绩，贡献净利润约2,877万元，成为利润核心增量。
- **[林芝片区市场整顿与项目建设]** -> [旅游景区收入下滑17%]: 区域内文旅市场整顿治理及国道G318改造等重大项目施工，导致核心景区游客接待量下降，直接拖累整体营收。
- **[剥离亏损子公司江西新绎]** -> [优化资产结构，增加非经常性收益]: 出售江西新绎80%股权，剥离异地旅游商业亏损业务，增加投资收益约950万元，改善资产质量。
- **[阿里片区基础设施升级]** -> [景区业绩扭亏为盈]: 持续投入冈仁波齐-玛旁雍错景区5A创建，完善救援、医疗等保障设施，抓住入境游机遇，实现经营业绩扭亏为盈且盈利持续性增强。
- **[传统旅行社业务受冲击]** -> [旅游服务收入增长但毛利率承压]: 低价团市场受冲击，公司转向高增长的出入境游，出入境商旅服务收入增长94%，但整体旅游服务毛利率仅提升5个百分点。
- **[“乐游西藏”平台迭代]** -> [驱动运营效率与客源转化]: 平台升级为AI行程规划、智能伴游的“智慧旅游中枢”，整合本地资源并与OTA共建专区，成为进藏重要入口，提升流量转化效率。
- **[母公司未弥补亏损]** -> [连续多年不进行利润分配]: 截至2025年末母公司未弥补亏损达-6,970.65万元，导致公司无法分红，影响股东回报预期。

## 风险警告
**核心风险在于业绩对非经常性损益的严重依赖与主营业务的脆弱性。** 2025年归母净利润2,327万元中，非经常性损益高达1,275万元（占比55%），其中印度香客接待业务贡献的投资收益2,877万元是利润支柱。而核心的旅游景区业务收入同比下降17%，毛利率骤降14个百分点，林芝片区受外部因素冲击后尚未恢复。这种“非主业输血”的盈利模式可持续性存疑，一旦中印关系或政策变动导致香客业务萎缩，公司盈利能力将面临断崖式下跌。

**区域政策与市场治理的双重不确定性是长期隐患。** 公司景区多位于边境地区，受客流管控、外籍审批等政策影响极大，且易受国际形势冲击。同时，西藏自治区对旅游市场的综合治理（如打击低价团）在短期内已对传统业务造成阵痛，未来政策力度和方向的不确定性，可能持续压制公司林芝等核心片区的客流恢复。此外，募投项目因区域重大项目建设进度滞后，投资回报不确定性增加，进一步削弱了公司未来的增长预期。
