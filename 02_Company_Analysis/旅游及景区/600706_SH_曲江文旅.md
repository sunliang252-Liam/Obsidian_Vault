# 600706.SH 深度透视

## 因果逻辑链
- **[新旧动能动态调整，核心景区收入下滑]** -> [营收下降22.83%]: 景区运营管理收入同比大降32.58%，拖累整体营收从12.53亿降至9.67亿。
- **[主动剥离亏损子公司]** -> [非经常性收益增厚利润]: 转让雁荡山公司38%股权及无锡汇跑55%股权，合计产生约2244万元处置收益，掩盖了主业亏损的严重程度。
- **[精细化成本管控]** -> [固定成本下降18%]: 通过网格化、一体化管理，人工、劳务、能源、租赁等成本全面压缩，但未能抵消收入下滑的冲击。
- **[转回递延所得税资产]** -> [归母净利润大幅亏损]: 因未来盈利预期转弱，公司转回递延所得税资产，导致所得税费用激增至7965万元，是归母净利润从-1.31亿扩大至-1.96亿的核心原因。
- **[应收账款重分类至长期应收款]** -> [短期流动性压力缓解]: 将约4.9亿应收账款重分类至长期应收款，短期坏账计提压力减轻，但暴露了回款周期拉长、信用风险后移的实质。
- **[控股股东高比例质押与冻结]** -> [控制权稳定性风险]: 控股股东旅游投资集团所持股份几乎全部被质押或冻结，且年内被动减持超3000万股，股权结构极度脆弱。
- **[市场竞争类业务占比提升至92.55%]** -> [市场化转型加速]: 公司主动去化低毛利的公建物业管理业务，聚焦景区、酒店、演艺等市场化业务，但盈利能力尚未体现。

## 风险警告
**核心风险在于资产质量的持续恶化与现金流的枯竭。** 公司2025年归母净利润亏损1.96亿元，连续第三年亏损，且亏损额同比扩大49.4%。更严峻的是，经营性现金流净额同比骤降46.27%至1.1亿元，而期末现金及现金等价物余额仅剩7117万元，创近年新低。与此同时，公司总负债19.96亿元，资产负债率高达81.3%，短期借款与一年内到期的非流动负债合计3.85亿元，短期偿债压力巨大。母公司未分配利润为-5.2亿元，已不具备分红条件，股东回报遥遥无期。

**应收账款与长期应收款是悬在头顶的达摩克利斯之剑。** 尽管公司将部分应收账款重分类至长期应收款，但两者合计余额仍高达8.02亿元，占总资产的32.6%。其中，对曲江新区管委会下属事业单位的应收款项是主要构成，其回款高度依赖地方财政状况。审计报告已将其列为关键审计事项，坏账准备计提是否充分存在重大不确定性。一旦地方政府支付能力下降，将引发大规模资产减值，对利润表造成毁灭性打击。
