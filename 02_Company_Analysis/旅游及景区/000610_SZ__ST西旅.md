## 因果逻辑链
- **[行业“量升价跌”]** -> [酒店板块收入下滑15.26%]: 旅游人次增长但消费降级，导致入住率及平均房价双降，直接压缩营收空间。
- **[扎尕那项目开发成本无法资本化]** -> [财务费用增加18.36%]: 项目停滞导致相关借款利息从资本化转为费用化，推高财务成本。
- **[参股公司奥特莱斯公允价值下跌]** -> [公允价值变动损失3218万元]: 市场下行导致公司持有的16%股权评估价值大幅缩水，侵蚀利润。
- **[扎尕那项目及酒店资产减值]** -> [资产减值损失9535万元]: 行业下行及项目停滞，导致存货、长期资产出现减值迹象，计提大额减值准备。
- **[旅行社业务毛利率极低]** -> [主业“增收不增利”]: 旅行社收入占比66.57%，但毛利率仅5.28%，高营收无法覆盖刚性成本，持续亏损。
- **[净资产为负]** -> [触发退市风险警示]: 连续亏损导致归母净资产降至-5454万元，触及*ST红线，公司面临生存危机。
- **[控股股东资金支持承诺]** -> [短期偿债能力保障]: 控股股东承诺提供资金支持，是公司维持持续经营假设、避免债务违约的关键外部支撑。

## 风险警告
**核心风险是净资产为负引发的退市危机。** 公司2025年末归母净资产为-5454万元，已触发*ST条件。若2026年无法通过资产处置、定增或主业扭亏实现净资产转正，将面临直接退市。这不仅是财务数字问题，更会切断融资渠道、引发供应商挤兑，形成恶性循环。

**经营层面，公司陷入“增收不增利”的泥潭。** 旅行社业务毛利率仅5.28%，酒店业务毛利率为-17.95%（即亏损经营），核心主业缺乏造血能力。同时，扎尕那项目停滞导致大额资产减值（9535万元）和利息费用化，叠加参股公司公允价值波动，公司利润被多重非经营性因素持续侵蚀，短期内看不到盈利拐点。
