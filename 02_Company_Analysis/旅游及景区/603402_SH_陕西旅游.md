# 603402.SH 深度透视

## 因果逻辑链
- **核心景区客流下滑** -> 营收与利润双降: 2025年公司游客接待量减少，导致营业收入同比下降18.45%，归母净利润同比下降24.91%。
- **《长恨歌》演艺IP依赖** -> 业绩高度集中: 子公司长恨歌演艺贡献净利润3.51亿元，占公司归母净利润的91.4%，单一产品风险极高。
- **IPO募资到账** -> 资产规模暴增: 2025年完成IPO，募集资金净额15.22亿元到账，总资产较期初增长106.76%，货币资金占比升至72.05%。
- **收购少华山索道** -> 主业版图扩张: 报告期内完成少华山奥吉沟索道资产组收购（7655万元），扩大旅游索道业务版图，但短期拖累投资现金流。
- **华山西峰索道高乘索率** -> 运营效率领先: 年度乘索率超107%，表明在华山景区内具备极强的客流转化能力和资源利用效率。
- **旅游餐饮持续亏损** -> 拖累整体盈利: 子公司唐乐宫净利润为-1568万元，旅游餐饮业务毛利率为负（-7.18%），成为公司业绩的明显短板。
- **泰安文旅项目尚在培育期** -> 短期亏损扩大: 子公司泰安文旅净利润为-2512万元，新项目《泰山烽火》及配套设施尚处于投入期，未到盈利阶段。

## 风险警告
**核心风险在于对单一IP《长恨歌》的过度依赖。** 该演艺贡献了公司绝大部分利润，且演出场地（华清宫）的经营权归属于第三方（华清宫公司），协议期限至2050年。一旦合作关系生变或场地使用权受限，将对公司业绩造成毁灭性打击。同时，该剧已运营近20年，面临观众审美疲劳和市场竞争加剧的持续创新风险。

**另一重大风险是特许经营权的不确定性。** 公司核心资产华山西峰索道及华威滑道的特许经营权分别于2047年和2046年到期，存在到期无法续期的风险。此外，华山风景名胜区资源有偿使用费标准尚未出台，公司虽已按收入10%计提，但未来实际征收标准若高于此，将直接侵蚀利润。募投项目（如泰山秀城、少华山索道）的收益释放需要时间，短期内无法弥补核心业务的下滑。
