# 600250.SH 深度透视

## 因果逻辑链
- **核心利润支柱（秦淮风光游船业务）** -> 归母净利润884万元: 子公司秦淮风光贡献净利润9443.82万元，是公司盈利的绝对核心，但母公司层面因历史亏损导致未分配利润为负，无法分红。
- **非经常性损益基数效应** -> 归母净利润同比暴跌80.63%: 2024年因子公司破产清算及诉讼胜诉冲回坏账形成大额非经常性损益（约3998万元），2025年此类收益消失，导致归母净利润从4564万元骤降至884万元。
- **扣非净利润增长** -> 主业盈利能力改善: 扣非归母净利润同比增长29.21%至730.70万元，显示剔除一次性因素后，公司核心业务（游船、贸易）的盈利能力在提升。
- **销售费用激增** -> 跨境电商业务扩张: 销售费用同比大增40.43%，主要系跨境电商业务平台费用增加，表明公司正积极投入资源培育新增长点，但该业务目前仍处于亏损状态（商旅跨境净亏损637.73万元）。
- **重组终止** -> 酒店业务拓展受阻: 收购控股股东旗下黄埔酒店100%股权的重大资产重组于2025年12月终止，公司酒店业务布局从“资产注入”转向“委托管理”，扩张路径放缓。
- **控股股东重组** -> 资源整合平台升级: 南京市国资委将文投集团、体育集团股权注入控股股东，组建“南京文旅集团”，公司作为集团旗下唯一上市平台，未来有望获得更丰富的文体旅资源注入。
- **现金流健康** -> 经营质量稳健: 经营活动现金流净额1.21亿元，远超归母净利润，且同比增长2.87%，表明公司主营业务的现金回收能力强，利润质量高。

## 风险警告
**核心风险在于业绩高度依赖单一子公司（秦淮风光）及新业务培育的不确定性。** 秦淮风光贡献了公司绝大部分利润，其20年特许经营权虽构成护城河，但也意味着公司增长高度绑定于夫子庙-秦淮风光带的客流与消费。一旦景区客流受宏观经济、极端天气或竞争分流影响，公司业绩将面临剧烈波动。同时，公司重金投入的跨境电商、科技文旅（MR、低空经济）等新业务均处于亏损或培育期，短期内难以贡献利润，反而持续消耗现金流，转型能否成功尚需时间验证。

**母公司层面财务结构脆弱，分红能力缺失。** 母公司未分配利润高达-4.63亿元，尽管合并报表层面有1.89亿元未分配利润，但受制于分红条件，公司已连续多年无法进行现金分红。这严重削弱了对价值投资者的吸引力。虽然公司计划通过强化子公司分红来推动母公司未分配利润转正，但过程漫长且存在不确定性。此外，公司资产负债率54.73%，且新发行了3亿元中期票据，债务压力不容忽视。

**公司简介（F10 原文）**

> 南京商贸旅游股份有限公司成立于1978年,1988年取得进出口自营权,1994年改制为股份有限公司,2001年3月于上海证券交易所上市(股票代码600250)。南京旅游集团为公司控股股东。公司项下控参股南京南纺、经纬电气、秦淮风光、南商运营、香港新达、朗诗地产、国展中心和金旅融租等十余家企业。公司坚持“旅游+商贸”双主业经营战略,持续探索发展路径,打造高质量旅游资产证券化平台及运营平台。南纺股份围绕“严控风险、稳健经营、转型发展”的战略方针,充分发挥四十余年国际进出口贸易积累的丰富资源优势和外贸人才优势,在严控风险基础上稳健开展外贸主业,提升业务质量和效益。目前公司主营进出口贸易和国内贸易,出口产品包括纺织服装、机电设备等,进口产品包括化工原料等;市场覆盖欧盟、美加、日本和东南亚等近百个国家和地区以及国内市场。2019年,公司成功收购优质旅游企业秦淮风光51%股权,文旅转型取得实质性进展。依托于夫子庙-秦淮风光带的优质旅游资源,秦淮风光的水上游船成为了古都金陵的旅游名片。2020年,公司收购商业零售企业南商运营51%股权,着手布局南京旅游商业,开启全域旅游新阶段,自此,“旅游+商贸”双主业经营模式初步构建。南纺股份将坚持长三角区域优质文商旅资源运营主体的战略定位,加快文商旅全产业链布局延伸,打造成具有较高美誉度、市场影响力和区域代表性的国内一流文旅企业。“为顾客赢取价值;为股东增加回报;为员工提供机遇;为社会创造财富”,南纺股份愿与各界朋友真诚合作,共同创造辉煌!
