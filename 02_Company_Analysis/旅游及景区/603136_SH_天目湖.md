# 603136.SH 深度透视

## 因果逻辑链
- **[消费理性化与客单价承压]** -> [营收与利润双降]: 2025年消费者更注重“情绪价值”和性价比，导致景区门票、酒店等核心业务客单价下滑，公司营收同比下降5.25%，归母净利润同比下降8.92%。
- **[“一站式”产品复合模式]** -> [抗风险与客源协同]: 公司拥有景区、温泉、酒店、旅行社等多元业态，通过“酒景联动”和精细化运营，以出租率提升对冲房价波动，并实现客源内部转化，增强了经营的稳定性。
- **[文体旅融合与精准营销]** -> [流量破局与品牌跃升]: 公司借势“苏超”赛事、打造“夜游”IP、推出“泰狂欢”等活动，并四度登上央视，有效提升了品牌声量，在淡季通过惠民政策带动门票收入激增。
- **[细分赛道布局]** -> [培育第二增长曲线]: 公司深耕疗休养、旅居、宠物友好等新兴细分市场，其中旅居业务营收实现快速增长，疗休养业务实现从零到一的突破，为未来增长开辟新路径。
- **[组织提效与成本管控]** -> [利润韧性]: 通过组织架构扁平化、推行零基预算和划小核算单元，有效控制了成本，在营收下滑5.25%的情况下，营业成本仅下降1.09%，减缓了利润下滑幅度。
- **[轻资产输出管理]** -> [未来利润增长点]: 公司基于成熟运营经验，已初步构建标准化输出管理体系，并进入实践阶段，有望在不依赖重资产投入的情况下，为公司贡献新的利润来源。
- **[与国资强强联合]** -> [外延发展助力]: 溧阳城发成为第一大股东后，为公司提供了资金、资源和政策支持，有助于公司未来进行产业布局和项目扩张，但同时也需关注关联交易和决策效率。

## 风险警告
**核心风险在于消费降级趋势的持续性与公司项目扩张的不确定性。** 公司营收和利润已连续两年下滑，表明其依赖的“一站式”模式在消费者更趋理性的环境下，面临客单价提升乏力的困境。若宏观经济持续疲软，长三角地区旅游竞争加剧，公司可能陷入“增收不增利”甚至量价齐跌的窘境。

**其次，公司战略项目推进受阻，资本开支存在减值风险。** 报告期内，动物王国项目因外部政策调整终止，导致公司计提了在建工程减值损失，并终止了相关增资计划。这暴露了公司在大型重资产项目上的投资风险。未来南山小寨二期、御水温泉改造等在建项目能否如期落地并达到预期效益，是影响公司估值的关键变量。
