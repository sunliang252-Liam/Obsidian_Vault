# 920855.BJ 深度透视

## 因果逻辑链
- **[外销ODM/OEM模式]** -> [营收微增2.09%]: 公司80%以上为国际知名企业贴牌生产，依赖大客户订单，外销收入占比67%，但外销收入同比下降1.85%，拖累整体增速。
- **[美元兑人民币汇率波动]** -> [净利润下降11.39%]: 财务费用同比增加46.91%，主因利息收入减少260.81万元及汇兑收益减少287.16万元，直接侵蚀利润。
- **[原材料价格波动]** -> [毛利率下降0.77个百分点至30.03%]: 铜、铁、铝等金属成本占比高，原材料价格波动导致营业成本增速（3.23%）高于营收增速（2.09%），压缩盈利空间。
- **[子公司大农机器业务增长]** -> [经营活动现金流净额大增141.24%]: 子公司业务增长及前期款项回收，销售商品收到的现金增加2,778.80万元，现金流显著改善。
- **[第四季度收入季节性下滑]** -> [信用减值损失减少127.69%]: 第四季度收入同比减少12.43%，应收账款余额减少12.44%，导致坏账计提减少，反向增厚利润。
- **[长期呆滞物料增加]** -> [资产减值损失增加66.18%]: 子公司3年以上呆滞物料增加58.60万元，导致存货跌价准备计提增加，侵蚀利润。
- **[高新技术企业税收优惠]** -> [有效税率维持15%]: 公司及子公司均获高新技术企业认定，按15%税率计缴企业所得税，减轻税负压力。
- **[内销收入增长11.23%]** -> [内销毛利率下降6.05个百分点]: 内销收入增长但成本增速更快（22.47%），反映国内市场竞争加剧或产品结构变化，拉低整体毛利率。

## 风险警告
**核心风险在于外销依赖与汇率波动。** 公司80%以上收入来自ODM/OEM贴牌出口，前五大客户集中度约30%，且以美元结算。2025年净利润下降11.39%，主因就是汇兑收益减少和利息收入下降。若人民币持续升值或主要客户所在国贸易政策生变，公司盈利能力将面临更大压力。公司虽提及开拓内销市场，但内销毛利率反而下降6个百分点，显示转型效果不佳。

**存货与原材料风险不容忽视。** 存货占总资产11.48%，且3年以上呆滞物料增加导致资产减值损失扩大66.18%。铜、铁等原材料价格波动直接冲击毛利率，公司虽采取锁单等措施，但成本控制能力有限。此外，公司无控股股东，实际控制人王靖、应云琴持股合计仅39.02%，股权结构分散可能影响重大决策效率。
