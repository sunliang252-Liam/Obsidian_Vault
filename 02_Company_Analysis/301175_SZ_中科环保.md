# 301175.SZ 深度透视

## 因果逻辑链
- **[供热规模化与高供热比]** -> [业绩稳健增长]: 供热比稳居40%以上，供热业务规模化发展（浙江、河北、四川、广西四大绿能中心），直接提升热能利用效率与蒸汽销售收入，是利润增长的核心引擎。
- **[AICC智能燃烧控制系统投运]** -> [运营效率与毛利提升]: 以慈溪项目为例，AICC投运后产汽稳定性提升28%、主蒸汽流量提升1.2%，单项目年毛利贡献约300-400万元，显著降本增效。
- **[并购整合（晋州、贵港、平南项目）]** -> [规模扩张与区域协同]: 晋州项目交割后首月扭亏，与石家庄项目形成河北片区协同；贵港、平南项目有序推进，快速扩大产能与市场覆盖。
- **[新建项目投产（玉溪项目）]** -> [量增驱动收入]: 玉溪项目投产当月即盈利，叠加在建项目（衡阳、藤县）推进，直接贡献垃圾处理量、上网电量与供热量的增长。
- **[绿色能源多元化（绿证交易、绿色生物天然气）]** -> [开辟第二增长曲线]: 完成国内首单绿色生物天然气“气证合一”交易，累计核发绿证311.98万张，实现价值转化，降低对单一电价补贴的依赖。
- **[研发成果产业化（烟气余热利用、催化滤袋）]** -> [技术壁垒与成本优势]: 烟气余热利用技术提升发电量约5%，催化滤袋可大幅降低NOx排放及运行成本，技术成果转化形成长期竞争护城河。
- **[精细化与标准化管理]** -> [存量项目提质增效]: 通过“三重效益”技改评估、区域采购中心集采降本、小指标竞赛等，推动主要运营指标显著提升5%，实现存量业务的持续挖潜。

## 风险警告
**核心风险在于电价补贴退坡与项目竞价的不确定性。** 自2022年起，新建垃圾发电项目上网电价按燃煤基准价结算，中央补贴逐步退出。若未来各地竞价政策趋严或电价受市场供需波动下行，将直接侵蚀新建项目的盈利空间。公司虽通过拓展供热、绿证交易等方式对冲，但供热市场的开拓与价格传导存在滞后性，短期内难以完全弥补电价损失。

**另一重大风险是并购整合与资本开支压力。** 公司“中期靠并购做大”战略依赖持续的资金投入，2025年投资活动现金净流出同比扩大33.16%，且并购标的（如贵港、平南项目）的供热改造、运营标准化及扭亏需要时间。若并购后整合不及预期，或资本开支超出计划，将导致负债率上升、现金流承压，并拖累整体资产回报率。
