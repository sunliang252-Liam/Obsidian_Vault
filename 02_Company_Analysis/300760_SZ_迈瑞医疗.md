# 300760.SZ 深度透视

## 因果逻辑链
- **[国内医疗政策收紧]** -> [营收下降9.38%]: DRG/DIP支付改革、集采、检验结果互认等多重政策导致国内体外诊断行业进入调整收缩期，试剂用量和价格均下滑，国内收入同比下降22.97%。
- **[数智化生态建设]** -> [国际业务逆势增长7.40%]: “设备+IT+AI”数智医疗生态系统（启元生态）提升产品竞争力与客户粘性，助力突破近90家国际重点战略客户，欧洲市场实现17%增长。
- **[新兴业务放量]** -> [营收占比提升至16%]: 微创外科、微创介入（惠泰医疗）及动物医疗等新兴业务同比增长38.85%，成为公司长期重要增长引擎，国内新兴业务收入占国内营收比重超20%。
- **[高端客户突破]** -> [品牌力与市占率提升]: 超高端超声ResonaA20、MT8000全实验室流水线等产品进入欧美顶尖医院，带动6类产品市占率全球前三，9类产品中国第一。
- **[流水型业务占比提升]** -> [收入结构优化]: IVD试剂、微创耗材等流水型业务收入约占整体40%，其高频次、高粘性特征为公司提供可持续增长基础，且国内化学发光市占率仅10%，提升空间巨大。
- **[AI大模型落地]** -> [临床价值与客户粘性增强]: 启元重症、检验、围术期等大模型在多家顶级医院部署，实现病历书写效率提升70%、错误报告趋零等显著效果，推动从产品交付转向长期价值共创。
- **[海外本地化布局]** -> [供应链韧性增强]: 在14个国家规划本地化生产项目（11个已启动），海外员工90%以上为本地人，有效对冲逆全球化风险，保障国际业务稳定供应。

## 风险警告
**国内政策与行业调整风险**：2025年国内营收同比下降22.97%，净利润下降30.28%，主要受DRG/DIP支付改革、集采降价、检验结果互认等政策叠加冲击。体外诊断行业进入调整收缩期，试剂用量和价格均下滑。虽然公司市占率逆势提升，但若政策持续收紧或医院采购预算进一步缩减，国内业务复苏可能慢于预期，短期业绩仍承压。

**国际化经营与地缘政治风险**：公司国际收入占比已超53%，但部分发展中国家因高息滞胀和本地货币贬值导致采购放缓，地缘冲突也为局部业务拓展增添挑战。逆全球化趋势下，贸易壁垒与标准藩篱日趋森严，若海外市场准入受限或本地化生产推进不及预期，可能影响国际业务增长节奏。
