# 600261.SH 深度透视

## 因果逻辑链
- **[美国对华照明产品加征关税]** -> [北美营收下降19.18%]: 公司对美出口面临高额关税，导致北美市场销售收入大幅下滑，成为营收下降的主要拖累。
- **[泰国工厂投产与越南合作]** -> [规避贸易壁垒，保障北美供应]: 通过海外产能布局，形成“泰国制造+越南合作”的供应体系，有效对冲美国关税风险，维持了北美市场的交付能力。
- **[灯具业务占比提升至80.59%]** -> [毛利率提升0.64个百分点]: 公司主动从低毛利的“光源替代”向高附加值的“灯具解决方案”转型，产品结构优化直接带动了整体盈利能力的改善。
- **[自主品牌占比提升]** -> [海外市场议价能力增强]: 自主品牌销售增长，减少了对OEM代工的依赖，增强了公司在海外市场的品牌溢价和客户粘性，部分对冲了价格下行压力。
- **[金融资产公允价值变动收益1.1亿元]** -> [净利润仅下降7.12%]: 在扣非净利润同比大跌56.43%的背景下，公司通过私募基金等金融资产的投资收益，掩盖了主营业务的真实盈利困境。
- **[库存与应收账款双降]** -> [经营现金流保持健康]: 库存总量同比下降9.89%，应收账款总额下降10.14%，表明公司运营质量改善，资金回笼效率提升，为现金流提供了支撑。
- **[AEM电解槽技术突破]** -> [开辟第二增长曲线]: 公司前瞻性布局氢能装备，AEM电解槽实现销售突破，技术指标领先，有望在绿氢产业规模化发展中获得新的增长动力。

## 风险警告
**核心风险在于主营业务盈利能力急剧恶化。** 2025年扣非净利润同比暴跌56.43%，仅为6423万元，而同期非经常性损益高达1.24亿元，其中金融资产公允价值变动收益贡献了1.1亿元。这意味着公司真实经营已陷入困境，利润严重依赖投资理财收益，具有极大的不可持续性和波动性。一旦资本市场环境逆转，公司将面临巨大的业绩变脸风险。

**第二增长曲线尚在萌芽，短期无法弥补主业下滑。** 氢能装备业务虽技术领先，但2025年营收仅6.09万元，净利润亏损83.98万元，仍处于商业化早期。从“照明专家”到“绿色能源解决方案提供商”的战略转型，需要巨额持续投入和漫长的市场培育期，短期内无法对冲照明主业面临的关税壁垒、价格战和需求萎缩等多重压力。
