# 600758.SH 深度透视

## 因果逻辑链
- **[煤炭价格中枢大幅下移]** -> [归母净利润亏损2.74亿元]: 2025年煤炭市场供需宽松，煤价下跌导致煤炭业务毛利率骤降19.49个百分点，收入同比下降23.82%，是公司由盈转亏的核心原因。
- **[煤炭销量下滑与库存积压]** -> [营收与现金流承压]: 商品煤销量同比下降5.56%，库存量同比增加25.58%，显示下游需求疲软，销售不畅。
- **[电力业务成本下降与收入增长]** -> [对冲部分煤炭亏损]: 电力行业收入同比增长6.20%，燃料成本下降6.2%，毛利率提升11.45个百分点，成为公司唯一的业绩缓冲垫。
- **[资产减值损失大幅增加]** -> [加剧利润下滑]: 2025年资产减值损失达9226万元，较上年增加近3倍，进一步侵蚀了本已脆弱的利润。
- **[长期借款激增与债务结构优化]** -> [短期偿债压力后移]: 长期借款同比暴增342.46%，一年内到期的非流动负债激增1196.64%，公司正通过借新还旧、延长债务期限来缓解短期流动性压力。
- **[控股股东同业竞争承诺延期]** -> [资产注入预期落空]: 控股股东辽能产控集团将解决同业竞争的承诺延期至2030年，短期内缺乏资产注入带来的业绩增量想象空间。

## 风险警告
公司核心风险在于对煤炭价格的极度敏感性与行业景气度的深度绑定。2025年煤价中枢下移直接导致公司从盈利2亿元转为亏损2.74亿元，煤炭毛利率从35%暴跌至15.5%，且库存高企、销量下滑，显示需求端未见明显改善。即便电力业务成本下降形成对冲，也无法扭转整体颓势。公司预计2026年煤价中枢稳中有升，但若宏观经济复苏不及预期或新能源替代加速，公司业绩将面临持续亏损风险。

财务结构风险不容忽视。公司担保总额占净资产比例高达71.33%，且存在一笔1996年遗留的400万元逾期担保。同时，公司通过大幅增加长期借款（+342%）来偿还短期债务，导致一年内到期非流动负债激增，短期偿债压力被后移但并未消除。母公司未分配利润已转为负值，连续亏损将导致公司无法进行现金分红，对看重股息回报的投资者缺乏吸引力。
