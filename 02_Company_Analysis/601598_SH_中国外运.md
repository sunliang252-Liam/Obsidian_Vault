# 601598.SH 深度透视

## 因果逻辑链
- **[运价下行与成本管控]** -> [营收降8.34%，归母净利反增2.66%]: 运价下跌导致收入下滑，但公司通过集约化采购、低效业务治理等成本管控，使营业成本降幅（8.77%）高于收入降幅，保住了利润基本盘。
- **[资产盘活与REITs发行]** -> [非经常性损益暴增，扣非净利暴跌46.95%]: 出售路凯国际25%股权及发行国内首单央企仓储物流REITs，带来21.78亿非流动资产处置收益，掩盖了空运、陆运业务受关税冲击及合联营投资收益下滑导致的经常性业务恶化。
- **[美国关税与市场需求萎缩]** -> [空运、陆运业务量及利润大幅下滑]: 美国关税政策及取消低值免税条款，直接冲击跨境电商物流（业务量降66%）和空运代理（分部利润转负），成为扣非净利下滑的核心拖累。
- **[海外业务扩张]** -> [海外收入与利润逆势增长]: 在东南亚、中东、非洲等区域，通过合同物流和项目物流带动，海外业务收入增7.3%，利润总额增39.3%，成为对冲国内及美线业务下滑的关键引擎。
- **[商誉减值风险暴露]** -> [资产减值损失翻倍]: 因欧洲KLG及国内物流子公司利润率不及预期，计提商誉减值5.61亿元，导致全年资产减值损失达10.55亿元，同比大幅增加，侵蚀了经常性利润。
- **[战略营销与产品化]** -> [核心直客收入增长6.5%]: 通过组建行业穿透型虚拟团队，聚焦重点行业解决方案和标准化产品（如东南亚捷运通），优化客户结构，提升了对大客户的粘性和收入稳定性。
- **[集约化运营与财务优化]** -> [有息负债率降至20.39%]: 通过集中采购仓库资源、优化债务结构，降低了财务费用和负债水平，财务结构更趋稳健，增强了抗风险能力。

## 风险警告
**核心风险在于扣非净利润的断崖式下滑与资产盘活收益的不可持续性。** 2025年归母净利润看似微增，但扣非净利润暴跌46.95%，仅16.78亿元。这揭示出公司核心的代理及电商业务正遭受美国关税政策和全球贸易格局重构的剧烈冲击，空运、跨境电商物流等板块已出现亏损。当前利润主要依赖出售路凯国际股权和发行REITs等一次性资产处置收益，这种“卖资产”维持利润的模式不具备可持续性，一旦资产处置节奏放缓，业绩将面临巨大压力。

**海外扩张与商誉减值风险并存，增长质量存疑。** 尽管海外业务增长亮眼，但欧洲子公司KLG的商誉减值（约4.9亿人民币）表明，海外并购整合并非一帆风顺，地缘政治、当地市场竞争和运营成本刚性都可能侵蚀海外利润。同时，国内合同物流、化工物流等传统优势板块也面临竞争加剧、利润下滑的困境。公司需证明其海外增长是可持续的内生性增长，而非依赖短期项目或资源投入，否则高增长背后潜藏着资产质量和盈利能力的双重隐忧。
