# 000859.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡加剧]** -> [连续三年亏损]: 中低端薄膜产能持续释放，价格竞争白热化，公司传统BOPP/BOPET产品毛利率承压，扣非净利润连续三年为负。
- **[原材料价格波动]** -> [成本控制压力]: PP料、PET料等主要原料价格下半年环比下降，但公司未能完全对冲市场波动，营业成本降幅（-7.03%）小于收入降幅（-6.16%）。
- **[新项目密集投产]** -> [折旧与费用侵蚀利润]: 年产3.8万吨高端功能性薄膜等项目进入产能爬坡期，固定资产同比大增6.91%，新增折旧导致制造费用增加，子公司国风先基因折旧亏损2369万元。
- **[新能源汽车配套业务萎缩]** -> [营收结构恶化]: 老车型订单大幅减少，新客户尚未放量，该板块销量同比下降41.86%，营收下滑21.41%，拖累整体业绩。
- **[研发投入资本化率为零]** -> [当期利润压力]: 公司研发投入全部费用化（9081万元），虽有利于长期技术积累，但短期直接加剧了亏损。
- **[并购重组预期]** -> [估值支撑逻辑]: 公司推进收购金张科技，旨在延链补链、优化光学膜结构，市场给予转型溢价，但交易尚未完成，协同效应未兑现。
- **[经营性现金流为正]** -> [财务安全垫]: 尽管亏损，经营活动现金流净额9340万元，主要得益于应收账款和存货管理，为公司维持运营和资本开支提供缓冲。

## 风险警告
**核心风险在于“新旧动能转换真空期”的持续失血。** 公司传统薄膜业务深陷行业周期低谷，产能过剩导致价格战无休止，而寄予厚望的聚酰亚胺膜、光学基膜等新项目尚处产能爬坡或调试阶段，巨额资本开支带来的折旧压力已提前显现，但高附加值产品放量远未达到盈亏平衡点。2025年亏损额进一步扩大至-7247万元，且连续三年扣非亏损，表明主营业务造血能力已严重受损。

**另一重大风险是并购整合的不确定性。** 公司拟收购金张科技，虽战略方向明确，但交易尚处审核阶段，存在失败或整合不及预期的风险。若并购受阻，公司将失去短期内的核心催化剂，而自身新项目又无法快速贡献利润，股价将面临估值与业绩双杀。此外，新能源汽车配套业务断崖式下滑（-41.86%），暴露出公司对单一客户和车型的过度依赖，转型阵痛远未结束。
