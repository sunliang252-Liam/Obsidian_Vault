# 603045.SH 深度透视

## 因果逻辑链
- **[白银价格上涨]** -> [营收与利润高增]: 白银兼具工业与金融属性，价格上涨直接推高产品售价（“原材料价格+加工费”模式），并带来库存白银的账面收益，驱动营收增长30.85%，归母净利润增长136.80%。
- **[高端客户突破]** -> [海外及中高端业务占比提升]: 成功切入施耐德、ABB等国际巨头供应链，打破海外垄断，海外及中高端业务收入同比增长39%，占比提升至16%，驱动公司从“规模导向”向“价值导向”转型。
- **[新丝材产线投产]** -> [高端产品供应能力突破]: 年产600吨环保型丝材智能制造产线投产，解决了新能源、5G等领域的高端产品“卡脖子”技术难题，为抢占高附加值市场提供了产能保障。
- **[费用管控加强]** -> [扣非净利润暴增]: 在营收增长30.85%的同时，通过精益管理有效控制费用，使得扣非净利润同比暴增849.16%，盈利能力显著改善。
- **[布局新能源高压连接系统]** -> [开辟第二增长曲线]: 设立福力达，切入800V-1000V高压直流接触器组件市场，产品已应用于超充桩、换电站等，有望在2026年实现从“新入局者”到“核心供应商”的跨越。
- **[成立福达研究院]** -> [强化技术壁垒]: 成立行业首家研究院，聚焦贵金属节约型材料、AI赋能研发等前沿方向，旨在打通从实验室到产业应用的“最后一公里”，巩固长期技术护城河。
- **[行业集中度加剧]** -> [龙头地位巩固]: 白银价格暴涨导致资金门槛提升，挤出中小竞争者，推动加工费提升和回款周期缩短，作为国内龙头，公司市场份额和议价能力进一步增强。

## 风险警告
**核心风险在于白银价格剧烈波动的双向冲击。** 公司定价模式为“原材料价格+加工费”，在银价平稳或上涨时，风险可传导至下游并享受库存收益。但若银价持续或短期内急剧下跌，由于传导机制存在滞后性，公司将面临利润大幅下滑和存货跌价的双重压力。2025年业绩高增很大程度上受益于银价上涨，投资者需警惕银价拐点带来的业绩反转风险。

**经营现金流持续为负与高杠杆扩张并存。** 尽管利润大幅增长，但2025年经营活动现金流净额为-2.96亿元，已连续多年为负，主要因营收扩张带来的营运资金占用。同时，公司短期借款激增52%，担保总额占净资产比例高达140.69%，财务杠杆高企。这种“纸面富贵”的盈利模式，在信贷收紧或银价下跌时，可能引发流动性危机。
