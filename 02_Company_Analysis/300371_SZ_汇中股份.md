# 300371.SZ 深度透视

## 因果逻辑链
- **[海外市场高价值订单放量]** -> [营收与利润双增]: 澳大利亚墨尔本项目等海外订单稳定交付，海外营收同比增217.49%，占总营收比重首破30%，成为拉动整体业绩增长的核心引擎。
- **[国内“两重”“两新”政策托底]** -> [国内市场营收稳定]: 超长期特别国债与专项债为供水供热管网改造提供资金，缓解地方财政压力，对冲了房地产下行与行业“内卷”带来的需求收缩。
- **[超声水表渗透率提升与结构优化]** -> [产品毛利率改善]: 高附加值超声水表及系统营收同比增41.49%，毛利率提升3.44个百分点，带动整体盈利能力改善。
- **[强化现金流管理]** -> [经营质量显著提升]: 销售回款增加、原材料采购付款减少，经营活动现金流净额达1.56亿元，同比增87.02%，创上市以来新高。
- **[代理模式放量]** -> [海外市场快速扩张]: 代理模式营收同比增111.72%，通过海外优质代理商（如意大利、安富利）实现市场快速渗透与订单获取。
- **[技术输出与智能制造]** -> [新增长点培育]: 控股子公司汇中科技向非超声企业输出核心组件与智能产线，全年实现7台套自研装备交付与盈利，开辟第二增长曲线。
- **[AI与智慧水务/供热融合]** -> [提升解决方案竞争力]: 接入DeepSeek等大模型，自研行业智能体，打造“AI+智慧水务/供热”平台，增强客户粘性与项目获取能力。

## 风险警告
**核心风险在于国内市场的“内卷”与海外市场的“双刃剑”效应。** 国内供水供热行业竞争白热化，价格战导致部分产品毛利率承压（如超声热量表毛利率同比下降9.35个百分点），且国内营收同比下滑（华北地区-26.31%）。公司虽通过海外高增长对冲，但海外业务占比已超35%，一旦主要市场（澳洲、欧洲）需求回落、贸易壁垒升级或汇率剧烈波动，将对公司业绩造成重大冲击。

**第二重风险来自政策依赖与技术迭代的不确定性。** 公司业绩高度依赖“两重”“两新”等财政政策落地节奏，若地方财政持续紧张或政策力度减弱，国内需求可能再次萎缩。同时，超声测流技术正面临AI、物联网等新技术融合的快速迭代，若公司研发方向偏离市场需求或产品转化不及预期（如超声燃气表尚在研发阶段），可能被竞争对手赶超。此外，税收优惠与政府补贴占利润比重较高，政策变化将直接侵蚀净利润。
