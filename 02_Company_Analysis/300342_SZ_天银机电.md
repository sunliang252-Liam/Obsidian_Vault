# 300342.SZ 深度透视

## 因果逻辑链
- **[家电行业“量稳价跌”]** -> [冰箱零配件收入下降21%]: 政策红利从总量驱动转向结构升级，行业供过于求，价格竞争加剧，公司传统产品销量承压。
- **[军工项目验收滞后]** -> [雷达航天板块收入下降23%]: 华清瑞达、讯析科技等子公司受客户审价审计、项目推进节奏调整影响，收入确认延迟。
- **[商业航天星座组网加速]** -> [天银星际净利润增长114%]: “千帆星座”等国家项目进入密集组网阶段，恒星敏感器需求爆发，公司凭借先发优势份额稳升。
- **[军工客户降本压力传导]** -> [华清瑞达净利润下降88%]: 招投标竞争激烈，客户对报价合规性要求趋严，压缩利润空间，回款周期拉长。
- **[行业库存压力凸显]** -> [经营活动现金流净额为负]: 年末压缩机库存同比增长6.9%，公司销售回款减少，导致经营性现金流转负。
- **[原材料与人工成本刚性]** -> [雷达航天板块毛利率提升5%]: 业务量下滑但人工、运营费用中固定成本占比高，材料成本降幅大于收入降幅，毛利率被动改善。
- **[研发投入持续加大]** -> [研发费用占营收比升至10.14%]: 公司为应对技术迭代，在变频控制、超宽带信号分析、星敏感器等领域保持高强度研发。

## 风险警告
**核心风险在于军工业务“增收不增利”与现金流恶化。** 华清瑞达、讯析科技等子公司受制于军工客户审价趋严和项目验收延迟，2025年收入与利润大幅下滑，且经营活动现金流净额由正转负（-6038万元），显示回款能力严重恶化。若“十五五”规划初期军工采购节奏持续低迷，该板块可能继续拖累整体业绩。

**冰箱零配件业务面临结构性衰退风险。** 行业已进入“存量竞争”阶段，政策刺激效果边际递减，下游客户降本压力持续传导。公司传统起动器、消音器产品销量下滑9.89%，而变频控制系统等高附加值新品尚未形成足够规模，短期内难以对冲传统业务萎缩。若原材料价格波动或海外关税政策进一步恶化，公司盈利能力可能继续承压。
