# 301097.SZ 深度透视

## 因果逻辑链
- **[国际化战略激进扩张]** -> [净利润巨亏2080%]: 收购日机装CRRT业务首年整合阵痛，联营企业宁波天辉益亏损9496万元，按权益法确认大额投资损失，直接吞噬上市公司利润。
- **[海外基地建设与人员扩张]** -> [销售与管理费用激增]: 泰国工厂建设及海外团队扩充导致薪酬、折旧、中介咨询费大幅增长，销售费用同比+59.9%，管理费用同比+23.9%。
- **[美元汇率波动]** -> [财务费用由负转正]: 外销以美元结算为主，2025年汇兑损失增加，财务费用从-1325万暴增至+1206万，同比+191%。
- **[集采降价压力]** -> [传统透析类毛利率承压]: 二十三省联盟集采中选，传统血透产品出厂价下降，透析类毛利率仅23.15%，同比仅提升4.7个百分点。
- **[行政处罚计提]** -> [营业外支出骤增]: 因涉嫌未按注册技术要求生产，被宁波市监局拟处罚，基于谨慎性原则计提大额预计负债，进一步拖累利润。
- **[重症类产品爆发]** -> [收入结构优化]: CRRT管路及滤器业务并表，重症类收入同比+249%，收入占比从8%跃升至20%，成为第二增长曲线。
- **[经营现金流强劲]** -> [盈利质量背离]: 营收+37.4%，经营现金流净额+61.6%至9512万元，显示主业造血能力并未恶化，亏损主因是非经常性及战略性投入。

## 风险警告
**核心风险在于国际化整合的“吞金兽”效应。** 公司2025年巨亏的直接导火索是联营企业宁波天辉益（持有日机装CRRT业务）首年亏损9496万元。该业务尚处整合培育期，供应链、人员、信息系统调整远未结束，后续注入上市公司前将持续侵蚀利润。同时，泰国基地超4亿元投资尚未投产，产能爬坡期将带来持续的折旧与费用压力，短期内难以贡献正向收益。

**合规与集采双重利剑高悬。** 公司因生产合规问题被行政处罚，暴露了快速扩张中内控体系的漏洞，虽已整改但品牌信誉受损。此外，传统透析类产品已纳入多省联盟集采，价格下行趋势明确；若未来CRRT等高值耗材也纳入集采，将直接冲击公司寄予厚望的第二增长曲线。在“增收不增利”的困境下，公司需证明其战略投入能转化为可持续的盈利增长，而非持续的亏损黑洞。
