# 301090.SZ 深度透视

## 因果逻辑链
- **[行业产能严重过剩]** -> [归母净利润亏损0.86亿元]: 2023-2024年国内瓶级PET产能集中释放，加工价差持续处于低位，公司虽大幅减亏84.88%，但主业仍无法盈利。
- **[主动减产与优化业务结构]** -> [营业收入同比下降27.62%]: 公司响应“反内卷”号召主动减产13.70%，并减少低毛利原料贸易业务，导致营收从180亿降至130亿。
- **[rPET与差异化产品放量]** -> [减亏4.83亿元]: rPET销量同比翻番至3.4万吨，差异化聚酯销量增长30%，高附加值产品结构优化是减亏的核心驱动力。
- **[PETG业务利润创新高]** -> [打造第二增长曲线]: PETG稳居国产日化包材领先地位，3D打印专用料销售增长近三倍，成为公司少数盈利且增长的业务板块。
- **[组织精健化改革]** -> [短期费用增加但长期效率提升]: 总部职能部门优化、直管干部精简超三分之一，产生阶段性人员优化成本，但为后续降本增效奠定组织基础。
- **[原材料成本控制]** -> [毛利率同比改善2.03个百分点]: 通过“精细采购”策略，灵活运用套保工具，在PTA/MEG价格下行周期中有效控制成本，聚酯行业毛利率回升至1.21%。
- **[出口依赖与贸易风险]** -> [境外收入占比33.29%]: 公司出口至东南亚、南美、欧洲等地，但面临反倾销、汇率波动及地缘政治风险，出口业务稳定性存疑。

## 风险警告
**核心风险在于行业供需格局的长期恶化。** 聚酯瓶片行业产能过剩是结构性而非周期性的，2025年社会库存同比暴增110万吨至339万吨，加工差同比下滑22.2%。公司210万吨产能利用率虽达95.26%，但这是在主动降价抢单下的结果，并非需求真实回暖。若行业自律减产无法持续或低效产能出清慢于预期，公司可能面临长期微利甚至亏损的困境。

**第二重风险来自战略转型的阵痛与不确定性。** 公司正从单一聚酯瓶片向新材料平台转型，但研发投入仅占营收0.19%，且研发人员中博士数量同比减少44.44%。PETG二期5万吨产线计划2026年中启动，新材料业务尚处培育期，短期内难以对冲主业亏损。此外，公司账面仍有119亿闲置募集资金，资金使用效率低下，若投资并购决策失误，将加剧财务风险。
