# 300606.SZ 深度透视

## 因果逻辑链
- **产业链一体化布局（材料+设备+工艺）** -> 智能装备收入同比增长202.73%: 公司凭借全产业链优势，推出五轴六工位磨抛机等新品，精准满足自动化需求，推动智能装备快速放量。
- **智能装备收入高增** -> 消费电子行业收入同比增长33.19%: 智能装备主要面向消费电子客户，设备销售带动耗材及服务，推动消费电子业务增长。
- **消费电子行业收入增长** -> 整体营收同比增长10.62%: 消费电子行业收入高增（33.19%）贡献了主要增量，带动整体营收上升。
- **产品结构优化（低附加值项目减少）** -> 毛利率提升（消费电子毛利率同比+10.99%）: 公司战略性缩减低附加值智能手机项目，聚焦高附加值加工（AI硬件、机器人等），驱动毛利改善。
- **产能建设与产线自动化升级** -> 存货下降36.11%: 新建产线投产、自动化改造提升生产效率，加快库存周转。
- **研发投入（5.18%营收）与技术创新** -> 新型抛光材料及智能装备竞争力增强: 持续研发投入带来专利积累（48项发明专利），支撑新产品开发，如弹性抛光砂膜、五轴设备等，巩固市场地位。
- **半导体抛光材料业务突破（参股领航电子）** -> 长期增长潜力: 领航电子实现CMP抛光液全面国产化，年产万吨级产能，为切入半导体供应链奠定基础，但短期尚未贡献显著收入。
- **下游需求景气（新能源汽车、AI硬件、机器人）** -> 公司业务增长: 下游市场扩张（新能源汽车渗透率47.9%、AI硬件超万亿、人形机器人出货增508%）直接拉动公司抛光材料、装备及结构件需求。

## 风险警告
公司面临三大核心风险：1）智能装备及精密结构件毛利率仅1.15%，虽同比提升但盈利水平极低，若规模效应未能快速释放，可能拖累整体利润；2）精密结构件业务订单大幅下滑（销售量同比-71.13%），存在客户流失或产品转型失败风险；3）债务结构恶化，短期借款减少但长期借款增加，财务费用同比增长175%，偿债压力加大。
