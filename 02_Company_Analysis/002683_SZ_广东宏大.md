# 002683.SZ 深度透视

## 因果逻辑链
- **[并购雪峰科技]** -> [营收暴增49.20%]: 雪峰科技并表贡献51.58亿营收，新增能化业务板块，但仅持股21%，归母净利润仅增6.62%。
- **[矿服“大客户、大项目”战略]** -> [矿服营收144.37亿创新高]: 聚焦新疆、西藏等富矿带，在手订单超380亿，新疆矿服营收同比大增73.38%。
- **[民爆产能扩张与布局优化]** -> [民爆营收增长29.63%]: 完成雪峰科技、南部永生并购，总产能达70.15万吨，混装占比57.8%，巩固西部市场优势。
- **[防务装备产业链延伸]** -> [防务营收增长31.64%]: 收购长之琳切入航空零部件，设立国科宏惯布局制导领域，产品谱系与收入规模双提升。
- **[矿服民爆一体化协同]** -> [提升客户粘性与毛利率]: 混装产能40.55万吨，从民爆生产到爆破服务全链条覆盖，降低交易成本，增强议价能力。
- **[海外“矿服+民爆”双轮驱动]** -> [海外营收增长12.41%]: 收购秘鲁炸药厂、建设赞比亚工厂，新开拓塞拉利昂市场，海外业务规模持续扩大。
- **[硝酸铵等原材料价格回落]** -> [民爆业务毛利率提升]: 2025年硝酸铵价格同比下降超10%，直接降低工业炸药生产成本，利好利润空间。

## 风险警告
**核心风险在于并购整合与商誉减值。** 公司2025年总资产暴增72.68%，主要系并购雪峰科技、长之琳等所致，商誉已达34.42亿元。雪峰科技仅持股21%，控制力有限，且能化板块受天然气价格与化工品周期双重挤压，若其业绩不达预期，巨额商誉减值将直接冲击利润表。同时，矿服业务应收账款及合同资产合计超60亿，客户经营波动可能引发信用减值。

**另一重大风险是防务装备板块的转型不确定性。** 高端军品研发投入大、周期长、技术难度高，且受国家政策调整影响。公司虽通过并购快速切入航空零部件等领域，但核心智能武器系统的商业化进程仍存较大不确定性，前期巨额研发投入若无法转化为订单，将长期拖累整体盈利能力。
