# 601298.SH 深度透视

## 因果逻辑链
- **[集装箱业务量增长及商务政策优化]** -> [集装箱板块收入同比+60.9%，分部业绩同比+32.1%]: 新增20条航线、5个内陆港，叠加费率优化，量价齐升驱动高增长。
- **[液体散货板块受炼厂开工率低及外部因素影响]** -> [液体散货分部业绩同比-22.8%]: 下游炼化需求疲软，原油中转量减少，导致该板块收入与利润双降。
- **[干散杂货板块粮食、煤炭业务量减少]** -> [干散杂货分部业绩同比-29.1%]: 尽管铁矿石、纸浆等优势货种保持领先，但粮食、煤炭等货种下滑拖累整体表现。
- **[物流及增值服务板块代理业务收入减少]** -> [物流及港口增值服务收入同比-6.4%]: 代理业务规模收缩，但场站、仓储等核心业务增长，使分部业绩微增+1.4%。
- **[投资活动现金净流出大幅增加]** -> [投资活动现金流净额同比-7,987%]: 主要因三个月以上定期存款净流出12.7亿，以及购建固定资产支出增加3.78亿。
- **[山东港口一体化改革与战略规划]** -> [公司获政策支持，明确“世界一流强港”目标]: 《青岛港总体规划（2035年）》获批，为公司长期产能扩张与枢纽地位提升提供确定性。
- **[高分红承诺与股东回报]** -> [2025年分红总额22.4亿，占可用于分配利润45%]: 公司制定2025-2027年分红规划，承诺每年现金分红不低于可用于分配利润的40%，强化价值投资逻辑。

## 风险警告
**核心风险在于液体散货与干散杂货板块的持续承压。** 液体散货分部业绩同比下滑22.8%，主要受下游炼厂开工率低及外部因素影响，该趋势若延续，将直接侵蚀公司利润。干散杂货板块同样面临粮食、煤炭等货种业务量减少的困境，分部业绩同比下滑29.1%，显示传统大宗商品吞吐量增长乏力。这两大板块的疲软是公司整体营收微降（-0.7%）的主要原因。

**另一重大风险来自山东港口集团内部的同业竞争整合不确定性。** 山东港口集团承诺在5年内解决与青岛港的同业竞争问题，但2025年公司已终止收购日照港油品码头及日照实华原油码头股权，表明整合进程可能不及预期。未来若整合方案发生重大变化或延迟，可能影响公司资产范围与盈利能力，并带来关联交易复杂性。此外，港口费率调整政策及宏观贸易环境波动也是长期潜在风险。
