# 301237.SZ 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [公司毛利率承压]: 聚酯薄膜中低端产能集中释放，同质化竞争加剧，导致产品售价下滑，挤压盈利空间。
- **[聚酯薄膜新产线投产]** -> [营收增长但利润亏损]: 2024年11.5万吨产能建成，2025年销量同比增32.45%，但高额折旧与低价竞争导致毛利无法覆盖固定成本。
- **[碳纤维项目大规模资本开支]** -> [财务费用激增与资产减值]: 9.92亿元碳纤维项目在建，长期借款从0.68亿增至3.70亿，利息支出与试生产阶段资产减值（1.68亿）共同拖累利润。
- **[原材料价格波动]** -> [毛利率不稳定]: 聚酯切片（占成本70%）价格受原油影响，2025年价格下降虽降低采购成本，但成品售价降幅更大，未能有效传导。
- **[高端产品国产替代空间]** -> [公司战略转型方向]: 光学膜、MLCC离型膜等高端膜仍依赖进口，公司聚焦有色光电基膜等差异化产品，但短期难以对冲中低端亏损。
- **[碳纤维项目尚处试生产]** -> [业绩不确定性]: 项目未形成规模化销售，技术路线、客户认证、良品率均需验证，短期内无法贡献利润，反而持续消耗现金。

## 风险警告
**核心风险在于双主业均陷入“投入期陷阱”。** 聚酯薄膜主业虽营收增长，但行业产能过剩导致价格战，新产线带来的高折旧与资产减值（1.68亿）直接吞噬利润，公司已连续两年亏损且未弥补亏损扩大。碳纤维项目作为第二增长曲线，尚处试生产阶段，9.92亿投资已导致负债率攀升，未来若技术或市场拓展不及预期，将加剧现金流压力。

**财务风险与治理风险叠加。** 公司2025年经营活动现金流虽转正，但投资活动现金净流出2.46亿，主要靠新增贷款维持。母公司未分配利润为-1.07亿，已触发无法现金分红条件。此外，公司因信息披露问题被浙江证监局出具警示函，暴露出内部治理与合规管控的薄弱环节，在行业下行期可能放大经营风险。
