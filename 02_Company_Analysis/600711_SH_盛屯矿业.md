# 600711.SH 深度透视

## 因果逻辑链
- **BMS二期扩建产能提升至12万金属吨，全年产量10.63万金属吨** -> 铜产品产量同比增长17.48%: 产能扩张直接带动产量提升
- **铜价维持高位且产量提升** -> 铜产品收入同比增长34.20%: 量价齐升推动收入增长
- **刚果(金)钴出口配额制度导致原料极度紧缺** -> 钴产品产量同比下降30.58%，收入同比下降30.64%: 原料短缺制约生产与销售
- **钴原料紧缺，科立鑫精准把控生产出货节奏** -> 钴产品毛利率同比增加10.21个百分点至53.76%: 原料稀缺提升产品议价能力，毛利率提升
- **镍供需过剩格局下价格震荡下行** -> 镍产品毛利率同比减少3.25个百分点至0.32%: 价格下跌压缩利润空间
- **铜钴镍等能源金属需求受新能源、AI、电网升级拉动** -> 公司能源金属业务营收同比增长29.91%: 下游需求增长带动营收
- **美元信用弱化、地缘政治风险加剧、全球央行购金** -> 黄金价格创历史新高，SHFE黄金年度涨幅57.20%: 避险需求推动金价上涨
- **期货套期保值浮亏增加** -> 衍生金融负债期末余额同比增加1078.81%: 套保亏损导致负债增加
- **期货套期保值投资增加及购建固定资产增加** -> 投资活动现金流量净额同比减少102.04%: 投资支出大幅增加
- **融资增加** -> 筹资活动现金流量净额同比由负转正: 外部融资补充现金流

## 风险警告
公司面临镍价持续低迷风险，镍产品毛利率极低（0.32%），且套保浮亏导致衍生金融负债激增。钴业务受刚果（金）出口政策扰动，原料供应不稳定。尽管铜业务量价齐升，但能源金属业务整体毛利率下滑，需关注价格波动和地缘政治风险。
