# 300889.SZ 深度透视

## 因果逻辑链
- **传统景观照明行业需求收缩** -> LED行业收入同比下降17.37%: 下游市场需求收缩，批量大单减少，小单碎片化导致规模效应减弱
- **新能源板块战略并购与整合** -> 新能源业务收入占比超过50%: 2025年完成无锡曙光并表，启动东莞硅翔收购，新能源板块收入（材料+充电桩+汽车配件+光伏风电）合计占比约54%
- **永创翔亿管理层优化与成本控制** -> 新能源电子材料毛利率同比上升2.83%: 新管理层提升质量与交付，减员10%，优化胶水配方使母卷成本下降10%以上，人效和产能同步提升
- **下游光伏电站建设需求集中释放** -> 光伏风电收入同比增长24.95%: 国家'十四五'可再生能源规划及'双碳'目标推动下游需求，施工订单量大幅增加
- **行业竞争激烈及原材料价格波动** -> 光伏风电毛利率同比下降0.86%: 竞争加剧和原材料价格波动使成本增幅略高于收入增幅
- **新能源汽车渗透率突破60%及政策支持** -> 充电桩业务收入同比增长111.59%: 新能源车保有量增长及'三年倍增'政策推动充电设施需求，技术升级（大功率快充）助力
- **无锡曙光并表（2025年4月）** -> 汽车配件业务新增收入2.77亿元: 并表后4-12月贡献收入，毛利率20.75%，成为公司第二大收入来源

## 风险警告
传统LED照明业务持续萎缩（收入-17.37%），且新能源板块整合存在不确定性：无锡曙光并表及东莞硅翔收购后的协同效应尚未完全释放，商誉减值风险需关注；新能源材料毛利率仍偏低（13.19%），光伏风电受原材料价格波动影响毛利率下滑；公司整体净利润为负（-7723万元），虽同比改善28.12%，但盈利能力仍待验证。此外，新能源车行业竞争加剧及技术迭代可能影响子公司市场地位。
