# 000725.SZ 深度透视

## 因果逻辑链
- **[LCD/OLED出货量全球第一]** -> [营收微增3.13%]: 规模优势稳固，但价格竞争激烈，导致营收增速远低于出货量增速。
- **[物联网创新业务增长15.14%]** -> [营收结构优化]: 高增长业务（如智慧终端）占比提升，部分对冲了显示器件业务增速放缓的影响。
- **[研发投入持续超130亿]** -> [技术壁垒与产品升级]: 高研发投入支撑了UBCell、Tandem OLED等高端技术量产，维持了产品溢价能力。
- **[资产减值损失40亿]** -> [侵蚀利润]: 存货跌价准备大幅计提，直接导致净利润（58.6亿）远低于经营现金流（488亿），反映行业价格波动风险。
- **[经营现金流净额488亿]** -> [高资本开支支撑]: 强劲的现金流为成都8.6代线、北京医院等重大项目投资提供了资金保障，但投资活动现金流净流出409亿。
- **[政府补助11.6亿]** -> [非经常性损益依赖]: 扣非净利润（42.3亿）占净利润（58.6亿）的72%，政府补助是利润的重要补充。
- **[18条产线获评国家级绿色工厂]** -> [可持续发展壁垒]: 绿色制造成为行业标准，提升了长期竞争力，并可能获得政策倾斜。

## 风险警告
**核心风险在于面板行业的强周期性。** 尽管公司通过“屏之物联”战略试图平滑周期，但显示器件业务（营收占比81%）仍是绝对主力。2025年资产减值损失高达40亿，直接表明行业供需失衡、价格波动对利润的冲击依然剧烈。若全球经济下行或下游需求不及预期，公司可能再次陷入“增收不增利”甚至亏损的困境。

**第二重风险来自高昂的资本开支与债务压力。** 公司总资产4364亿，但固定资产+在建工程占比高达55%，且长期借款超1015亿。持续的高强度投资（如8.6代AMOLED线）虽然布局未来，但也导致财务费用（18.4亿）高企，并侵蚀自由现金流。一旦融资环境收紧或项目回报不及预期，将显著影响公司财务稳健性。
