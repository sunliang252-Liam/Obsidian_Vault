# 301106.SZ 深度透视

## 因果逻辑链
- **[产品结构向模组化升级]** -> [营收增长但毛利率下降]: 单色液晶显示模组和彩色液晶显示模组收入分别增长29.03%和28.23%，但模组产品毛利率较低，叠加原材料成本上升，导致整体毛利率下降3.05个百分点。
- **[收购新通达40%股权]** -> [投资收益增加，但非经常性损益占比提升]: 收购新通达产生约556万元的投资成本小于公允价值收益，并贡献1126万元投资收益，是净利润未随营收同步增长的关键原因。
- **[美元汇率下降]** -> [财务费用大幅增加]: 汇率波动导致汇兑损失增加，财务费用从-1803万元转为520万元，同比变动128.84%，直接侵蚀利润。
- **[境外业务扩张]** -> [境外收入高增长]: 境外收入同比增长30.86%，占总收入比重提升至23.80%，成为营收增长的主要驱动力之一。
- **[车载大尺寸VA型液晶显示屏量产]** -> [汽车电子领域突破]: 公司凭借高精度彩膜贴附、息屏一体黑等技术，成功切入车载显示市场，为未来增长奠定基础。
- **[马来西亚生产基地即将投产]** -> [海外产能布局]: 马来西亚孙公司生产基地预计2026年投入使用，旨在规避贸易风险并贴近海外客户，是公司国际化战略的关键一步。
- **[股权激励归属]** -> [管理费用波动]: 2025年完成第二个归属期股份登记，管理费用同比下降12.98%，但股权激励费用仍对利润有一定影响。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长10.33%，但归母净利润和扣非净利润分别下滑4.64%和12.15%，主因是产品结构向低毛利的模组产品倾斜，叠加汇率波动和原材料成本上升。若公司无法通过技术升级或规模效应提升模组产品毛利率，利润将持续承压。

**成长性风险与技术替代风险并存。** 公司核心优势在单色液晶显示领域，但该市场已成熟且竞争激烈。同时，OLED等新型显示技术在智能家电、消费电子领域对单色液晶的替代效应日益显现。若公司不能成功将车载VA屏等新产品规模化并持续开拓新应用场景，将面临增长瓶颈。此外，境外销售占比高，国际贸易环境的不确定性是长期隐患。
