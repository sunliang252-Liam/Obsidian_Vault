# 688299.SH 深度透视

## 因果逻辑链
- **[锂电隔膜/胶膜/光学基膜行业产能过剩、竞争加剧]** -> [核心业务收缩与停产]: 公司主动收缩低毛利、竞争激烈的非核心业务（锂电隔膜、胶膜），相关产线停产，导致营收同比下降18.13%。
- **[非核心业务产线停产]** -> [巨额资产减值损失]: 对停产产线相关的固定资产及在建工程计提大额减值，是导致公司由盈转亏、净利润亏损1.44亿元的核心原因。
- **[反射膜业务盈利稳定]** -> [业绩基本盘支撑]: 反射膜作为核心产品，出货面积全球第一，毛利率同比提升2.03个百分点，为公司提供了稳定的利润来源，避免了更大亏损。
- **[财务费用与管理费用增加]** -> [侵蚀利润]: 汇兑损失导致财务费用同比激增181%，管理费用也同比增长14.16%，进一步加剧了公司的亏损。
- **[干法隔膜产品客诉]** -> [潜在信用与赔偿风险]: 因客户投诉，公司对相关应收账款全额计提信用减值，且尚未达成和解协议，存在未来客户索赔的风险。
- **[固态电池电解质复合膜基膜获订单]** -> [未来增长点]: 公司前瞻布局的固态/半固态电池用基膜产品已获头部客户小批量订单，是未来重要的战略增长点，但短期内对业绩贡献有限。
- **[光学基膜中高端产品占比提升]** -> [产品结构优化]: 光学基膜业务虽整体亏损，但OCA离型膜基膜等中高端产品占比稳步提升，为未来毛利率改善奠定基础。

## 风险警告
**核心风险在于多元化扩张失败导致的资产减值与业务收缩。** 公司为寻求增长，大举进入锂电隔膜、胶膜等竞争激烈的红海市场，但遭遇行业产能严重过剩，导致相关产线被迫停产，并计提了巨额资产减值，这是2025年巨亏的直接原因。目前相关产线仍处停产状态，若市场环境持续恶化或设备处置不及时，公司面临继续计提减值、资产进一步贬值的风险，对业绩构成持续压制。

**另一重大风险是潜在的客户索赔与经营不确定性。** 公司干法隔膜产品存在客诉，虽已全额计提信用减值，但尚未与客户达成正式和解，不排除未来发生大额赔偿的可能。同时，公司收缩非核心业务后，未来增长高度依赖反射膜基本盘的稳固以及固态电池等新业务的商业化进程，而新业务尚处早期，存在技术、市场及客户认证不达预期的风险。
