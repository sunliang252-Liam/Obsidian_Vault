# 300269.SZ 深度透视

## 因果逻辑链
- **[行业价格战与内需疲软]** -> [营收下降23.09%]: 国内LED显示屏市场萎缩4%，企业“增量不增收”，公司被迫降价抢单，导致收入从6.65亿降至5.12亿。
- **[海外市场成为增长引擎]** -> [出口占比提升至58.84%]: 拉美、东南亚等新兴市场基建需求旺盛，公司海外营收虽下降16.78%，但占比逆势提升，成为收入核心支柱。
- **[聚焦大客户与经销模式转型]** -> [经销收入暴增59.91%]: 公司主动调整销售结构，从依赖直销转向渠道经销，以扩大市场覆盖，但代价是直销收入腰斩（-49.69%）。
- **[精细化成本管控]** -> [三大费用合计下降19.54%]: 通过精简人员、优化流程、降低财务费用（利息支出减少），在收入下滑背景下，费用从1.34亿压缩至1.08亿。
- **[非经常性损益“救场”]** -> [扣非净利润仍为负]: 依靠收回业绩补偿款（约730万）和应收款减值转回（约906万），勉强实现归母净利润853万，但主业实际亏损863万。
- **[经营现金流大幅恶化]** -> [经营性现金流净流出4085万]: 收入下降叠加银行承兑汇票保证金结算方式变化，导致现金回款能力急剧恶化，与净利润严重背离。
- **[历史并购后遗症持续]** -> [资产减值与诉讼缠身]: 计提存货及房产减值2046万，且仍深陷与何吉伦等多起并购业绩补偿诉讼，历史包袱沉重。

## 风险警告
**核心风险：主业持续亏损，造血能力衰竭。** 公司扣非净利润已连续三年为负，2025年经营现金流由正转负，净流出4085万元。这意味着公司主营业务已无法产生正向现金流，完全依赖非经常性损益（如追讨历史业绩补偿款）和外部融资维持表面盈利。一旦诉讼回款不及预期或融资环境收紧，公司将面临严重的流动性危机。

**历史并购“毒资产”反噬。** 公司仍深陷多起金额巨大的并购业绩补偿诉讼（如诉何吉伦1.42亿、诉力玛网络2.34亿等），且大量资产（货币资金、固定资产、投资性房地产）因借款抵押或司法冻结而受限（受限资产合计2.54亿）。这严重制约了公司的财务灵活性，并持续消耗管理层精力。技术迭代（MicroLED/MIP）与价格战的双重压力下，公司若无法在海外市场或新场景（如XR虚拟拍摄）实现突破，将面临被边缘化的风险。
