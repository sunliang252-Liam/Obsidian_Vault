# 688307.SH 深度透视

## 因果逻辑链
- **[收购戴斯光电]** -> [营收增长44.75%]: 2025年收购戴斯光电51%股权，切入精密光学元件领域，贡献新增收入，推动总营收从4.55亿跃升至6.58亿元。
- **[下游需求景气度提升]** -> [核心业务增长]: 特种安防、无人机、智能驾驶等下游领域需求旺盛，带动公司光学镜头及元器件产品销量与收入全面增长。
- **[“光学镜头+光学元件”双轮驱动]** -> [业务结构优化]: 收购戴斯光电后，公司从单一镜头业务拓展至上游核心光学元件，形成产业链协同，增强了整体解决方案能力。
- **[高研发投入]** -> [技术壁垒与产品迭代]: 研发投入占营收11.02%，持续在超高清、大倍率变焦、轻量化等领域突破，巩固了在高端安防、无人机等细分市场的技术领先地位。
- **[股权激励落地]** -> [核心团队稳定]: 2024年限制性股票激励计划首个归属期完成，绑定95名核心骨干，激发组织活力，支撑公司长期战略执行。
- **[平湖生产基地投产]** -> [产能瓶颈突破]: 募投项目“高端光学镜头智能制造项目”全面达产，提升了规模化交付能力，为订单增长提供产能保障。
- **[润扬基金产业投资]** -> [前瞻性技术布局]: 通过产业基金投资蓝星光域（空间光通信）、三石园（光纤器件）等，布局未来高增长赛道，构建产业生态。

## 风险警告
**核心风险在于商誉减值与高额存货。** 公司2025年收购戴斯光电形成约5600万元商誉，若未来宏观经济或下游激光、半导体行业景气度下行，戴斯光电业绩不达预期，将面临商誉减值风险，直接冲击当期利润。同时，公司存货账面价值高达1.79亿元，占流动资产21.53%，且计提了3466万元跌价准备。光学产品技术迭代快，若客户需求变化或产品滞销，存货跌价风险将持续侵蚀利润。

**盈利质量与现金流存在隐忧。** 尽管营收增长44.75%，但扣非净利润仅增长2.85%，远低于营收增速，主要受毛利率下滑（光学镜头毛利率下降3.06个百分点）及管理费用、研发费用大幅增长（分别+46.39%、+48.81%）拖累。此外，经营活动现金流净额同比下降37.08%，与利润增长背离，主要因扩大生产导致材料、人工支出增加及票据结算增多，需关注其回款能力与运营效率。
