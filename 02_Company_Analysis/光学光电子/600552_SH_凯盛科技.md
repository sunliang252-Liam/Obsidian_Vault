# 600552.SH 深度透视

## 因果逻辑链
- **[显示材料业务扩张]** -> [营收增长20.15%]: 显示材料收入同比+31.4%，国际化业务及UTG、3A盖板、车载模组等新产品放量，拉动整体营收至58.8亿元。
- **[高毛利新品占比提升]** -> [扣非净利润大幅扭亏]: 扣非归母净利润从-24万跃升至9,132万元，主因UTG独供旗舰手机、高附加值产品结构优化，抵消了传统业务毛利率压力。
- **[政府补助锐减]** -> [利润总额同比下降16.41%]: 其他收益从1.88亿骤降至5,972万元（-68.19%），非经常性损益大幅缩水，导致归母净利润下滑8.2%。
- **[现金流管理强化]** -> [经营性现金流暴增229.59%]: 通过“现金流改善”攻坚战，销售回款增加，全年经营性净现金流达4.76亿元，财务质量显著改善。
- **[UTG二期产能爬坡]** -> [资本开支放缓]: 购建固定资产支付现金同比减少61.88%，UTG二期主体产线已建成，资本开支高峰已过，进入产能释放期。
- **[财务费用激增]** -> [侵蚀利润]: 财务费用同比+54.15%至1.2亿元，主因汇率波动及利息支出增加，对净利润形成显著拖累。
- **[应用材料承压]** -> [板块收入下滑2.16%]: 锆系产品销量持平，但高纯石英砂受光伏行业周期影响，业绩承诺未达标，拖累整体应用材料板块表现。

## 风险警告
**核心风险在于业绩对政府补助的隐性依赖与主业盈利能力的脆弱平衡。** 尽管扣非净利润大幅改善，但利润总额仍同比下滑16.41%，主因政府补助从1.88亿骤降至5,972万元。若剔除补助，公司实际经营利润对补贴的敏感度极高，未来补贴政策的不确定性将直接冲击利润表。同时，财务费用因汇率和利息支出激增54%，高负债运营（短期借款+长期借款超34亿）的利息负担是持续失血点。

**第二重风险来自并购标的业绩暴雷与产能消化不确定性。** 太湖石英和凯盛基材连续三年未完成业绩承诺，合计亏损超千万，高纯石英砂业务受光伏行业产能出清拖累，短期难以改善。UTG二期项目虽已建成，但剩余产线仍在调试，且产品独供单一头部终端，若下游折叠屏需求不及预期或技术路线切换（如UFG），巨额资本开支将面临产能利用率不足的风险。
