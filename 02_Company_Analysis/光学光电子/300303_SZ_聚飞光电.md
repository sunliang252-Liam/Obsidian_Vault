# 300303.SZ 深度透视

## 因果逻辑链
- **[Mini LED背光技术渗透率提升]** -> [营收增长12.97%]: 公司作为国内背光LED龙头，受益于Mini LED在高端电视、车载等领域的标配化趋势，带动LED产品销售收入同比增长12.70%。
- **[车用LED业务进入全球供应链]** -> [开辟第二增长曲线]: 公司车用LED产品已跻身全球前十，成功进入丰田、大众、比亚迪等主机厂及Tier1供应链，车用显示与照明业务成为重要增长极。
- **[境外市场拓展与份额提升]** -> [境外收入激增53.73%]: 凭借高性价比产品和快速响应服务，公司境外销售收入占比从14.58%提升至19.85%，成为营收增长的核心驱动力。
- **[贵金属等原材料涨价]** -> [综合毛利率下降5.09%]: 金、铝、铜等大宗商品价格波动加剧，直接推高LED产品直接材料成本（占营业成本79.27%），导致公司“增收不增利”。
- **[新业务爬坡与费用增加]** -> [净利润同比下降10.20%]: 新开拓业务（如光耦、光模块）尚处爬坡期，叠加总部大厦启用折旧、人力资源投入增加及汇兑损失，侵蚀了利润空间。
- **[经营活动现金流大幅改善]** -> [现金流同比增长90.70%]: 收入增加及未到期票据贴现，使销售回款显著改善，经营活动现金流净额达6.12亿元，远超净利润，财务质量稳健。
- **[行业集中度提升]** -> [龙头地位巩固]: LED行业进入成熟期，资源向头部企业倾斜，公司凭借技术、质量和客户优势，在存量市场竞争中持续扩大份额。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长12.97%，但归母净利润却下滑10.20%，主因是上游原材料（金、铝、铜）涨价导致成本增速（20.62%）远超收入增速（12.70%），直接压缩了LED主业的毛利率。若大宗商品价格持续高位运行，公司盈利能力将继续承压，这是当前最直接的业绩杀手。

**第二重风险来自新业务的不确定性与竞争加剧。** 公司正大力拓展光耦、光模块、光学膜等新赛道，但这些业务尚处投入期，短期内难以贡献利润。同时，国内LED市场竞争白热化，产品单价持续下降，若公司不能通过技术迭代持续推出高性价比产品，或新业务拓展不及预期，将面临市场份额被侵蚀和增长动力不足的双重压力。
