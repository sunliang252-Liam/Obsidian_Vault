# 688502.SH 茂莱光学 深度透视

## 因果逻辑链
- **[半导体领域需求爆发]** -> [营收增长37.42%]: 受益于AI驱动芯片扩产及国产化替代，半导体领域收入同比增长71.47%，成为核心增长引擎。
- **[AR/VR检测业务放量]** -> [营收增长152.31%]: 客户需求从研发阶段进入小批量生产，产品需求量显著提升，交付效率提高。
- **[可转债成功发行]** -> [筹资现金流激增1884.75%]: 2025年发行可转债，募集资金用于超精密光学生产及研发，大幅改善现金流并支撑未来产能扩张。
- **[募投项目转固]** -> [毛利率承压]: 首发募投项目结项，固定资产折旧增加，叠加境外产能未充分释放，导致光学器件毛利率下降4.97个百分点。
- **[定制化深度绑定客户]** -> [高客户黏性]: 在客户产品概念阶段即介入，提供光机电算一体化解决方案，前五大客户销售额占比43.25%，合作关系稳固。
- **[研发投入持续加码]** -> [技术壁垒巩固]: 研发费用同比增长16.77%，在深紫外光学、高精度非球面、量子光学等领域取得突破，维持“专精特新”小巨人地位。
- **[全球化布局]** -> [分散贸易风险]: 在泰国、美国、英国设立子公司，境外收入占比43.01%，有效应对国际贸易摩擦，保障供应链稳定。

## 风险警告
**核心风险在于毛利率持续下滑与可转债带来的财务压力。** 2025年综合毛利率下降1.71个百分点，主要因募投项目转固导致固定成本激增，以及境外生产基地产能爬坡不及预期。若未来半导体或AR/VR检测领域需求增速放缓，高额的折旧摊销将严重侵蚀利润。同时，2025年发行的可转债将产生大额利息费用（财务费用同比暴增13390.97%），若股价低迷导致转股失败，公司将面临巨大的本息兑付压力。

**另一重大风险是客户集中度高与下游需求波动。** 前五大客户贡献超四成营收，且公司深度绑定少数头部客户。无人驾驶领域收入已因客户技术升级而骤降43.71%，显示出单一领域或客户订单结构变化的脆弱性。若半导体或AR/VR检测领域出现技术路线变更或客户自研，公司业绩可能剧烈波动。此外，境外业务占比高，汇率波动和地缘政治风险（如关税）是持续存在的隐患。
