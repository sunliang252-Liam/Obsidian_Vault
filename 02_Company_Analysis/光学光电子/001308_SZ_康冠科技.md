# 001308.SZ 深度透视

## 因果逻辑链
- **[全球贸易战冲击]** -> [智能电视收入下降17.37%]: 美国关税政策导致美洲客户订单谨慎、提货延迟，公司被迫采用第三方国家转口模式，进一步延后收入确认时点。
- **[客户回款能力恶化]** -> [计提信用减值损失3.47亿元]: 地缘政治风险加剧，部分海外客户应收账款逾期风险上升，导致公司净利润同比大幅下降39.35%。
- **[自有品牌出海扩张]** -> [创新类显示产品收入增长31.85%]: “KTC”“皓丽”“FPD”三大品牌依托亚马逊等海外电商平台，在北美、日本、欧洲实现规模扩张，出货量同比增长38.18%。
- **[AI技术深度赋能]** -> [产品矩阵升级与场景拓展]: 公司成立AI开发部，将大模型技术融入电子白板、移动屏、医疗AI一体机等产品，构建“AI+办公/教育/医疗/娱乐”全场景生态。
- **[MTO模式与属地化生产]** -> [供应链韧性提升]: 通过半散件/散件出口至海外委托加工厂，实现就近交付，规避关税壁垒，同时提高周转效率并降低物流成本。
- **[原材料价格波动与传导]** -> [综合毛利率稳定在13.94%]: 公司采用“以销定产、以产定购”模式，并动态调整销售价格，有效对冲了液晶面板等核心原材料的价格波动风险。
- **[高分红政策]** -> [股东回报与市场信心]: 2025年拟每10股派发现金红利6.00元，分红比例高达83.58%，体现了公司在业绩承压下的现金流管理能力和回馈股东的意愿。

## 风险警告
**核心风险在于全球贸易政策的不确定性与客户信用风险的双重打击。** 2025年，美国发起的全球贸易战直接导致公司核心业务——智能电视收入萎缩17.37%，而地缘政治动荡引发的客户回款能力恶化，更是迫使公司计提了高达3.47亿元的信用减值损失，直接吞噬了全年近四成的净利润。这表明公司对海外市场（尤其是美洲）的依赖度极高，且客户信用管理在外部环境剧变时显得尤为脆弱。

**其次，公司经营现金流与净利润严重背离，盈利质量堪忧。** 尽管全年归母净利润为5.05亿元，但经营活动现金流净额仅为0.89亿元，同比下降62.72%。这主要是由于公司为应对海外业务模式转变（转向委托加工）和自有品牌备货，导致存货激增8.63亿元。这种“以现金换增长”的模式，若未来市场需求不及预期，将面临巨大的存货跌价风险，进一步侵蚀利润。
