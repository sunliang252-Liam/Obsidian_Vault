# 300708.SZ 深度透视

## 因果逻辑链
- **GaAs基红黄光项目量产** -> **营收与利润创新高**: 2025年1月项目通线，单月产量突破5万片，直接推动公司营业收入31.27亿元、净利润2.05亿元均创历史新高，成功打造第二增长曲线。
- **精细运营与满产满销** -> **现金流强劲与高资产周转**: 2020-2025年产能利用率均值98.03%、产销率99.69%，叠加严格的回款管理，使销售回款比高达118.47%，经营活动现金流净额5.28亿元，远超净利润。
- **产品结构向高端升级** -> **毛利率稳定与盈利韧性**: 在通用照明市场承压背景下，公司重点发力Mini LED、车载照明、植物照明等高端芯片，使LED芯片及外延片毛利率维持在24.49%，支撑了净利润的正增长。
- **黄金废料回收业务** -> **营收规模虚高与可持续性风险**: 2025年“其他业务”（主要为黄金废料回收）收入17.35亿元，占总营收55.48%，同比增长22.25%，但其毛利率仅5.93%，且受税收政策调整影响，未来可持续性存疑。
- **研发投入聚焦前沿** -> **技术壁垒与未来增长储备**: 研发费用1.32亿元，重点投向Micro LED、Mini直显、车规级芯片等，已获IATF16949等车规认证，为抢占高价值细分市场奠定技术基础。
- **客户高度集中** -> **经营依赖与议价权风险**: 前五大客户销售额占比68.36%，其中第一大客户占比34.74%，公司对核心客户依赖度高，存在客户流失或压价风险。
- **存货激增** -> **潜在的资产减值压力**: 因红黄光项目产能释放及贵金属涨价，存货账面价值从2.40亿元飙升至6.26亿元，增长161.3%，若市场需求不及预期或金价下跌，将面临较大跌价风险。

## 风险警告
**核心风险在于营收质量与增长可持续性。** 公司2025年营收31.27亿元中，超过55%来自毛利率仅5.93%的黄金废料回收业务，而非核心的LED芯片销售。该业务受黄金价格波动及2025年11月新税收政策（进项扣除率从13%降至6%）影响，未来收入规模与利润贡献均存在重大不确定性，剔除该业务后，公司真实的主营业务增长（3.88%）远低于表面增速（13.33%）。

**第二增长曲线尚在培育期，且面临存货与客户集中双重压力。** 红黄光项目虽已量产，但尚未贡献显著利润，且导致存货激增161%至6.26亿元，若下游需求不及预期，将面临大规模资产减值。同时，公司前五大客户集中度高达68.36%，对单一客户依赖严重，在行业竞争加剧的背景下，议价能力与经营稳定性均面临挑战。
