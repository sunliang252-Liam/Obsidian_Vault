# 300752.SZ 深度透视

## 因果逻辑链
- **[OLED渗透挤压传统LED市场]** -> [消费电子业务下滑]: 智能手机等终端OLED渗透率提升，导致公司传统LED背光模组需求萎缩，公司主动收缩该业务。
- **[产品结构调整（向车载/LIPO倾斜）]** -> [毛利率下降2.26%]: 新业务（车载Mini-LED、LIPO封装）处于量产爬坡期，成本较高，拉低了整体毛利率。
- **[LIPO新型封装技术量产]** -> [“第二增长极”业务快速增长]: 该技术实现从0到1的突破，成功切入小米、vivo等品牌供应链，成为新的收入驱动力。
- **[Mini-LED车载显示技术先发优势]** -> [智能驾驶终端业务快速增长]: 凭借10年技术积累，公司从单一显示向“显示+电子电路+结构+光学”整体方案转型，获得奔驰、宝马、蔚来等客户认可。
- **[研发投入增加24.46%]** -> [短期利润承压]: 公司加大在Micro-LED、量子计算、具身智能等前沿领域的研发投入，导致研发费用上升。
- **[战略性投资量旋科技]** -> [切入量子计算生态]: 公司于2025年底投资量子计算企业，意图从传统精密制造商转型为量子计算核心供应链伙伴。
- **[支付供应商款项及职工薪酬增加]** -> [经营活动现金流净额骤降86.35%]: 尽管收入增长，但经营性现金流大幅恶化，显示营运资金压力增大。

## 风险警告
**核心风险在于新旧动能转换期的“利润断层”。** 公司传统LED背光业务正被OLED技术加速替代，虽主动收缩，但该业务下滑带来的收入缺口，短期内难以被车载和LIPO等新业务的增长完全弥补。2025年净利润同比下滑42.77%，毛利率下降，正是这一转型阵痛的直接体现。若新业务放量速度不及预期或成本下降缓慢，公司盈利能力将持续承压。

**财务健康度出现隐忧。** 在营收增长18.72%的背景下，经营活动现金流净额却大幅下降86.35%至4746万元，远低于净利润。同时，公司计提了高达2813万元的资产减值损失（主要为存货跌价），并战略性投资量子计算等高风险前沿领域。这暗示公司可能面临库存积压、回款放缓及投资回报不确定等多重财务压力。
