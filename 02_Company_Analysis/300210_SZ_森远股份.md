# 300210.SZ 深度透视

## 因果逻辑链
- **[设备更新与安全应急政策]** -> [营收增长44.33%]: 政策释放存量替换空间，除雪应急装备等被纳入城市基础设施更新改造范围，直接拉动销售收入。
- **[除雪设备销售放量]** -> [营收结构优化]: 除雪设备收入2.41亿元，同比增长46.48%，占制造业收入81%，成为核心增长引擎。
- **[沥青路面再生设备爆发]** -> [高毛利产品占比提升]: 再生设备收入同比增长231.79%，但毛利率下降58.26个百分点，显示以价换量策略。
- **[信用及资产减值计提增加]** -> [净利润持续亏损]: 尽管营收大增，但信用减值损失404万、资产减值损失373万，合计拖累利润，导致净亏损1823万元。
- **[经营活动现金流大幅转正]** -> [经营质量改善]: 经营性现金流净额5666万元（上年为-8449万元），销售回款增加，现金循环效率显著提升。
- **[控股股东借款展期与算力合同]** -> [转型资金与业务支撑]: 向中科信控借款1亿元展期，并签订2678万元算力集群集成合同，支撑“智慧交通+算力”双轮战略落地。
- **[子公司剥离与注销]** -> [聚焦主业]: 处置阿克苏中科智算、山东新醇动力等非核心子公司，减少资源分散，集中资源于公路养护设备主业。

## 风险警告
公司虽营收大增，但净利润连续三年亏损，核心问题在于资产减值与信用减值持续侵蚀利润。应收账款占资产总额14.55%，且账龄结构恶化，若回款不力，坏账风险将直接冲击利润表。此外，公司无实际控制人，控股股东中科信控股权结构分散，战略决策效率与稳定性存疑，可能影响“算力+具身智能”第二增长曲线的落地节奏。

公司转型依赖关联方借款（1亿元展期）与关联交易（算力合同），资金与业务独立性面临挑战。若关联方支持力度减弱或关联交易定价不公允，将加剧公司流动性压力与经营风险。同时，除雪设备季节性明显，再生设备毛利率骤降，主业盈利基础尚不稳固，扭亏为盈目标存在较大不确定性。
