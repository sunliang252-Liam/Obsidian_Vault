# 002693.SZ 深度透视

## 因果逻辑链
- **[注射用紫杉醇（白蛋白结合型）美国获批上市]** -> [营收暴增58.87%，扭亏为盈]: 该复杂制剂ANDA获FDA批准后迅速在美国市场销售，贡献全年50.98%的营收（1.41亿元），成为业绩反转的核心引擎。
- **[海外市场收入激增448.76%]** -> [摆脱国内集采与价格下行压力]: 公司国际化战略见效，海外收入占比从19.65%跃升至67.88%，有效对冲了国内多肽产品因集采导致的销售费用下降39.89%和营收萎缩。
- **[降本增效与人员优化]** -> [管理费用与研发费用双降]: 公司收缩非核心研发、优化人员结构（研发人员减少16.42%），管理费用下降14.65%，研发费用下降37.21%，直接改善了利润表。
- **[宁波双成亏损大幅收窄63.21%]** -> [子公司拖累减轻]: 宁波双成承接注射用紫杉醇（白蛋白结合型）受托生产业务，产能利用率提升，亏损从-5724万元收窄至-2108万元。
- **[主导产品高度集中]** -> [经营脆弱性加剧]: 注射用紫杉醇（白蛋白结合型）单一产品贡献超50%营收，胸腺法新占比13.27%，一旦该产品遭遇美国市场政策、竞争或供应链问题，公司将面临巨大冲击。
- **[高额开发支出资本化]** -> [未来减值风险积聚]: 研发投入资本化率高达76.88%，开发支出余额达8445万元，若在研项目（如SC-C139等）注册或商业化不及预期，将面临大规模资产减值。

## 风险警告
**核心风险在于业绩对单一海外爆款的过度依赖。** 公司2025年扭亏为盈，几乎完全系于注射用紫杉醇（白蛋白结合型）在美国市场的成功。该产品收入占比过半，且海外销售模式为“利润分成”，收入确认与回款节奏受制于合作伙伴。一旦美国市场出现竞争加剧、价格下降、供应链中断或地缘政治风险，公司业绩将迅速逆转。此外，公司仍有5000万元中融信托产品逾期未收回，财务稳健性存疑。

**资产质量与持续盈利能力面临双重考验。** 公司合并报表未分配利润仍为-4.06亿元，母公司未分配利润-1.66亿元，历史亏损包袱沉重。同时，高达8445万元的开发支出和1.05亿元的无形资产（多为资本化的研发投入）构成了巨大的减值隐患。宁波双成虽亏损收窄，但净资产仅为2492万元，仍处于资不抵债边缘。公司能否在2026年维持盈利，完全取决于海外单一品种的销售能否持续放量，而非建立了多元化的盈利基础。
