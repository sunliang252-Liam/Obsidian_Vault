# 000570.SZ 深度透视

## 因果逻辑链
- **[非经常性损益（资产处置+政府补助）]** -> [归母净利润暴增174.86%]: 总部沿街商铺征收贡献资产处置收益3619万元，政府补助1544万元，掩盖了扣非净利润同比下滑61.15%的颓势。
- **[传统农机市场承压（粮价低迷+极端天气）]** -> [国内营收下滑1.61%]: 用户作业收益下降导致存量更新需求疲软，公司核心的国内柴油机市场增长乏力。
- **[海外市场拓展]** -> [国外营收增长26.26%]: 公司主动优化海外产品技术路线，中坚市场和新兴市场增长强劲，成为营收增长的主要驱动力。
- **[产业链协同（自建铸造+加工）]** -> [构筑差异化壁垒]: 自建铸件制造和加工厂，减少外部采购依赖，提升质量把控与生产效率，形成成本与品质的正反馈循环。
- **[金融资产公允价值波动]** -> [利润剧烈波动]: 持有的联测科技、凯龙高科股票价格上升，但厚生新能源股权公允价值下降，合计产生-1994万元公允价值变动损失，是扣非净利润下滑的主因。
- **[存货管理优化]** -> [经营活动现金流净额大幅转正至2.9亿]: 报告期内压降库存、加大货款回笼，使经营性现金流从-1.54亿大幅改善，远超净利润。
- **[产品结构升级（混动+大马力）]** -> [切入新市场]: 完成120-140马力拖拉机增程式混动系统构型设计，多款大马力柴油机切入收获机械主流市场，为未来增长蓄力。

## 风险警告
**核心风险在于盈利的不可持续性与主业疲软。** 2025年归母净利润暴增174.86%，完全依赖总部商铺征收（3619万）和政府补助（1544万）等非经常性损益。剔除这些后，扣非净利润同比下滑61.15%，表明公司核心的柴油机业务在传统农机市场下行周期中，盈利能力并未改善，反而因金融资产公允价值波动（-1994万）和存货减值（-2362万）而大幅恶化。

**行业转型与竞争加剧是长期隐患。** 农机行业正加速向高端化、智能化、新能源化转型，而公司传统单缸机市场虽占有率高，但面临存量萎缩和新能源动力替代的双重挤压。若公司在混动、氢内燃机等新技术的研发和产业化上落后于竞争对手，或无法将研发投入转化为有效订单，将面临被供应链边缘化的风险。同时，原材料价格波动和外贸地缘政治风险也对公司经营构成持续压力。
