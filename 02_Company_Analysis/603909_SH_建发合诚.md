# 603909.SH 深度透视

## 因果逻辑链
- **[深度绑定建发集团]** -> [营收76.35亿，同比+15.53%]: 89.60%营收来自建发集团及所属单位，建筑施工业务（占营收87.42%）完全依赖关联方项目，规模随建发房开扩张而被动增长。
- **[建筑施工低毛利扩张]** -> [净利润率仅1.43%]: 建筑施工毛利率仅2.05%，省外项目毛利更低，导致营收增长15.53%但净利润仅增14.21%，增收不增利。
- **[“工程医院”一体化服务]** -> [新签合同3.7亿，同比+115%]: 整合检测-诊断-设计-施工-运维闭环，切入城市更新与在役工程市场，形成差异化竞争壁垒。
- **[“合诚数智云”平台落地]** -> [智慧监测业务从0到1]: 桥梁、边坡智能预警系统首次在厦漳18座桥梁群及4处高边坡应用，将一次性工程转化为持续性技术服务。
- **[新签合同额115.16亿，同比+107%]** -> [未来2-3年收入确定性增强]: 在手订单160.47亿，为2026年营收目标（增长10-30%）提供充足储备。
- **[收购幕墙资质企业]** -> [铝合金幕墙业务“零突破”]: 通过收购快速补齐资质短板，切入新细分赛道，新增合同额超3500万。
- **[研发投入3800万+授权专利18项]** -> [技术护城河加固]: 聚焦“工程医院”核心技术，获福建省科技进步奖，支撑差异化竞争。

## 风险警告
**核心风险：对单一关联方（建发集团）的极度依赖。** 公司89.60%的营收来自建发集团及所属单位，本质上是建发房地产产业链的内部配套商。一旦建发集团房开业务收缩、内部协同政策调整或关联交易定价不公允，公司营收和利润将遭受毁灭性打击。这种“寄生式”增长模式缺乏独立市场竞争力，客户集中度风险极高。

**第二大风险：建筑施工业务“虚胖”且盈利脆弱。** 该业务贡献87.42%营收，但毛利率仅2.05%，净利润率不足1%。低毛利意味着对成本波动、项目延期、坏账计提极度敏感。应收账款+合同资产占总资产65.80%，且回款周期受制于关联方结算节奏，经营现金流净额已同比下滑10.55%，若关联方付款延迟，公司将面临流动性压力。
