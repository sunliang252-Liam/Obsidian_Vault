# 002774.SZ 深度透视

## 因果逻辑链
- **[房地产新梯需求萎缩]** -> [营收下滑7.72%]: 国内新装电梯市场受房地产调控影响，直梯收入同比大降13.70%，拖累整体营收。
- **[扶梯业务爆发式增长]** -> [结构性对冲直梯下滑]: 扶梯收入同比大增121.54%，受益于轨道交通（如东莞地铁1号线）等基建项目交付，成为短期增长极。
- **[经营现金流大幅改善]** -> [净利润含金量提升]: 经营活动现金流净额同比暴增160.70%至1.20亿元，远超净利润，主因支付其他经营现金减少，回款质量改善。
- **[非经常性损益依赖度高]** -> [净利润质量偏弱]: 扣非净利润同比大降49.57%，归母净利润中非经常性损益占比高达27.4%，核心盈利能力承压。
- **[旧梯更新与加装政策红利]** -> [后市场成为战略增长点]: 国家超长期特别国债支持12.6万台老旧电梯更新，公司安装维保收入逆势微增0.30%，毛利率提升5.79个百分点。
- **[海外市场毛利率优势]** -> [国际化战略对冲国内风险]: 海外业务毛利率高达37.73%，远超国内19.78%，成为利润稳定器，但收入同比微降4.46%。
- **[新工厂搬迁与产能升级]** -> [短期成本扰动与长期效率提升]: 东莞新厂搬迁完成，固定资产大增，但短期拖累产能释放；南北双工厂模式有望降低物流成本，提升交付效率。

## 风险警告
**核心风险在于业绩对房地产周期的深度依赖与盈利质量的下滑。** 公司营收与利润双降，扣非净利润腰斩，表明其核心电梯销售业务正遭受房地产新开工持续低迷的严重冲击。尽管扶梯业务因基建项目偶有亮点，但难以对冲直梯基本盘的萎缩。更值得警惕的是，公司净利润高度依赖理财收益等非经常性损益，一旦资本市场波动，盈利将面临更大压力。

**第二重风险来自激烈的市场竞争与原材料价格波动。** 电梯行业已进入存量博弈阶段，价格战压缩利润空间。公司直梯毛利率同比下降3.57个百分点，印证了竞争加剧。同时，钢材等原材料价格波动直接侵蚀制造成本，公司虽推进精益生产，但成本控制能力仍面临考验。此外，海外业务虽毛利率高，但汇率波动与地缘政治风险（如俄罗斯子公司）可能侵蚀海外利润。
