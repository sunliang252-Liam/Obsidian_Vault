# 002843.SZ 深度透视

## 因果逻辑链
- **[电源业务收入大幅下滑]** -> [公司整体营收下降11.74%]: 消费电子电源业务受行业竞争加剧及项目量产延迟影响，收入下降24.39%；大功率电源业务主动收缩低毛利订单，收入下降19.03%。
- **[电源板块巨额资产减值]** -> [归母净利润由盈转亏，亏损3725万元]: 对铂泰电子计提商誉减值3995万元、雅达能源计提长期资产减值1678万元，并冲回递延所得税资产3299万元，合计影响净利润8972万元。
- **[锯切业务逆势增长]** -> [核心主业提供稳定现金流]: 锯切业务营收同比增长5.91%至7.09亿元，毛利率维持40%+，是公司当期唯一的利润来源和现金流支柱。
- **[海外扩张与新品布局增加成本]** -> [短期侵蚀锯切业务利润]: 新设德国销售公司、建设泰国基地、布局合金钢带和圆锯片项目，新增成本费用影响净利润1423万元。
- **[电源业务客户高度集中]** -> [经营风险显著]: 前两大客户销售额占电源业务收入比重极高，客户订单波动直接导致电源业务收入剧烈下滑。
- **[智能手机市场预期衰退]** -> [电源业务未来前景承压]: IDC预测2026年全球智能手机出货量将同比下降12.9%，作为公司电源业务核心下游，将加剧消费电子电源业务的经营困难。
- **[光伏行业进入调整期]** -> [大功率电源业务增长受阻]: 2026年全球光伏新增装机预计出现负增长或增速放缓，公司主动收缩该业务，导致订单量大幅减少。

## 风险警告
公司2025年由盈转亏的核心原因是电源业务板块的全面溃败。消费电子电源业务受制于下游智能手机市场饱和与竞争加剧，收入持续萎缩；大功率电源业务则因光伏行业进入调整期而主动收缩。更严重的是，电源业务资产质量恶化，导致巨额商誉和资产减值，并被迫冲回前期确认的递延所得税资产，这表明管理层此前对电源业务整合与盈利前景的预期已彻底落空。电源业务已从“第二增长曲线”沦为业绩拖累，其能否在2026年实现减亏扭亏，是公司整体盈利恢复的关键。

公司面临的核心风险是电源业务收入持续下降及客户高度集中。电源业务前两大客户贡献了绝大部分收入，一旦核心客户调整采购策略或自身经营出现问题，电源业务将遭受致命打击。同时，IDC预测2026年全球智能手机出货量将出现十余年来最大降幅，这直接威胁公司消费电子电源业务的基本盘。尽管锯切业务表现稳健，但其利润增量难以弥补电源板块的巨额亏损和减值，公司短期内缺乏明确的业绩反转驱动力。
