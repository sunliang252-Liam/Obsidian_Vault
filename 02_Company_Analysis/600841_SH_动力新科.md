# 600841.SH 深度透视

## 因果逻辑链
- **[上汽红岩破产重整出表]** -> [归母净利润扭亏为盈]: 子公司上汽红岩因资不抵债被法院裁定重整，自2025年12月起不再纳入合并报表，产生一次性股权处置收益35.32亿元，直接驱动归母净利润从-19.99亿元跃升至28.72亿元。
- **[发动机业务量价齐升]** -> [核心主业稳健增长]: 全年发动机销量17.83万台，同比增长22.32%，跑赢行业大盘，带动发动机业务收入增长18.94%，成为公司剔除一次性收益后的主要利润来源。
- **[重卡业务大幅萎缩]** -> [营收规模持续下滑]: 上汽红岩重整期间经营几近停滞，全年仅销售整车899辆，同比下降83.60%，导致公司合并口径营业收入同比下滑11.25%。
- **[上汽红岩出表剥离巨额亏损]** -> [资产质量显著改善]: 出表后，公司剥离了重卡业务带来的巨额信用减值损失（-5.99亿）和资产减值损失（-4.82亿），归属于母公司净资产从35.18亿元大幅提升至63.81亿元。
- **[参与重整并继续出资]** -> [形成新的长期股权投资]: 公司出资6.66亿元参与上汽红岩重整，预计取得重整后14.66%股权，上汽红岩由全资子公司变为参股公司，公司从“并表亏损”转为“权益法核算”。
- **[发动机业务结构优化]** -> [提升抗周期能力]: 业外市场（工程机械、船电、数据中心等）销售收入占比达68.4%，且工程机械配套市场同比增长39.3%，降低了对单一商用车市场的依赖。

## 风险警告
公司2025年净利润的扭亏为盈完全依赖于子公司上汽红岩破产重整出表产生的一次性股权处置收益（35.32亿元），扣除非经常性损益后，公司实际亏损高达8.49亿元。核心主业发动机业务虽实现增长，但毛利率同比微降，盈利能力尚不足以覆盖庞大的费用开支，公司经营层面的造血能力依然薄弱。

上汽红岩虽已出表，但公司仍作为重整投资人出资6.66亿元持有其14.66%股权。重整后的上汽红岩能否恢复持续经营能力、实现预期效益存在重大不确定性，该笔投资面临减值风险。同时，母公司及合并报表层面未分配利润仍为巨额负数（-19.23亿和-24.45亿），未来数年无法进行现金分红，股东回报严重受限。
