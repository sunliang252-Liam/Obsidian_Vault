# 688069.SH 深度透视

## 因果逻辑链
- **[深潜式高压灭藻成套装备规模化交付]** -> [营收增长28%]: 核心产品成功验收13套，直接驱动主营业务收入大幅提升，验证了技术商业化能力。
- **[星云湖项目诉讼胜诉]** -> [利润大幅转正]: 二审判决冲回2024年计提的4,807.95万元预计负债，并调增当期营收，是净利润由亏转盈的关键偶发因素。
- **[客户结算周期延长]** -> [经营性现金流大幅转负]: 政府及国企客户预算与审计流程严格，导致回款延迟，经营活动现金流净额由正转负至-8610万元。
- **[研发重心从攻关转向优化]** -> [研发费用率下降]: 前期高投入的关键技术研发基本完成，当期聚焦工艺优化与量产适配，研发投入结构更高效，费用率降至3.32%。
- **[政策红利密集释放]** -> [市场空间确定性增强]: 《美丽河湖保护与建设行动方案》等政策将湖库富营养化治理列为刚性任务，为公司核心业务提供了明确的增量市场。
- **[“湖泊生态医院”模式深化]** -> [商业模式升级]: 从单一装备销售转向“监测-诊断-治理-运维”全周期服务，通过“美人鱼”AI平台和“湖泥-蚯蚓”循环经济构建差异化壁垒。
- **[产品结构向高毛利核心装备集中]** -> [毛利率大幅提升28.67个百分点]: 本期收入高度集中于“深潜式高压灭藻成套装备”，而上年同期项目包含大量低毛利配套设施，导致成本结构优化。

## 风险警告
**核心风险在于经营现金流与利润的严重背离。** 公司2025年净利润近亿元，但经营性现金流净额为-8610万元，同比骤降196%。这直接暴露了公司对政府及国企客户的强依赖——项目验收后，资金受制于地方财政预算、审计流程及专项债拨付节奏，回款周期不可控。应收账款余额已飙升至6.29亿元，占总资产36.5%，若地方财政持续收紧，坏账风险将显著侵蚀利润。

**业绩增长的可持续性存疑。** 2025年利润大幅转正，核心驱动力之一是星云湖项目诉讼胜诉带来的近5000万元非经常性损益。剔除该偶发因素及股份支付影响后，调整后净利润仅为4779.7万元。同时，公司研发投入大幅缩减，重心从技术攻关转向工艺优化，虽然短期降本，但可能削弱长期技术护城河。在蓝藻治理行业竞争加剧、技术路线迭代的背景下，公司能否持续依靠核心装备放量维持高增长，仍需观察。
