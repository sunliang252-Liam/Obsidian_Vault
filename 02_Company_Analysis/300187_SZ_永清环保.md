# 300187.SZ 深度透视

## 因果逻辑链
- **[垃圾焚烧发电稳定运营]** -> [业绩压舱石]: 衡阳、新余两厂全年处理垃圾超90万吨，发电3亿多度，贡献稳定现金流与核心利润，是公司盈利基本盘。
- **[非经常性损益高企]** -> [扣非净利润失真]: 2025年归母净利润1.12亿元，但扣非净利润仅0.31亿元，非经常性损益（业绩补偿、金融资产公允价值变动）占比高达73%，掩盖了主营业务的真实盈利水平。
- **[危废处置业务承压]** -> [业绩补偿依赖]: 子公司江苏永之清连续三年未完成业绩承诺（2025年完成率仅15.59%），公司利润严重依赖实际控制人刘正军夫妇的现金补偿，可持续性存疑。
- **[新能源业务扩张]** -> [现金流恶化]: 经营活动现金流净额同比骤降58%至1.19亿元，主因是支付工程项目款增加，表明新能源EPC及投资建设业务快速扩张导致资金占用加剧。
- **[应收账款与合同资产高企]** -> [回款风险]: 应收账款+合同资产合计9.26亿元，占总资产26.3%，客户以政府及国企为主，回款周期长，对现金流形成持续压力。
- **[AI+能源战略布局]** -> [未来增长点]: 设立凌境智能，聚焦虚拟电厂AI调度、智慧微电网，抢抓“算电协同”政策机遇，试图构建“数字电力资产”新赛道。
- **[参股公司分红贡献]** -> [利润调节器]: 参股浦湘生物能源（长沙垃圾发电项目）2025年贡献分红2600万元，是公司稳定的投资收益来源，平滑了主业波动。

## 风险警告
**核心风险在于盈利质量与可持续性。** 公司归母净利润看似增长14%，但扣非净利润仅0.31亿元，同比暴增1469%的基数极低。高达8177万元的非经常性损益（占利润总额65%）主要来自业绩补偿款和金融资产公允价值变动，其中子公司江苏永之清连续三年未达标，2025年完成率仅15.59%，业绩补偿依赖实际控制人个人信用，一旦履约能力下降，利润将大幅缩水。同时，经营活动现金流净额同比腰斩至1.19亿元，与净利润严重背离，表明公司“纸面富贵”，实际造血能力堪忧。

**第二大风险是资产质量与资金压力。** 应收账款与合同资产合计超9.26亿元，占总资产26%，且客户多为政府及平台公司，化债进度直接影响回款。公司短期借款激增至5.54亿元，资产负债率持续高位，新能源项目扩张对资金需求巨大，若融资渠道受阻或回款不及预期，可能引发流动性危机。此外，危废处置行业产能过剩、单价承压，公司危废业务虽扭亏但盈利薄弱，资源化转型尚在初期，短期难以成为新增长极。
