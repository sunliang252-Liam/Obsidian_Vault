# 300703.SZ 深度透视

## 因果逻辑链
- **[跨境电商业务高速增长]** -> [营收增长10.55%]: 睿特菲等子公司通过亚马逊及官网销售，运动健康类收入同比大增53%，贡献了当期营收增长额的131.94%。
- **[期间费用大幅攀升]** -> [净利润下降43.73%]: 跨境电商扩张导致销售费用增39.8%，叠加汇兑收益减少，期间费用总额同比增35.15%，严重侵蚀利润。
- **[越南产能释放]** -> [海外供应韧性增强]: 越南创源营收5.28亿元，同比增58.19%，成为国际文创板块增长核心，并有效对冲中美关税风险。
- **[“IP+科技”战略落地]** -> [国内文创市场破局]: 与天络行等合作布局IP文创、祈福文创，并成立智能玩具独立实体，构建“双循环”市场体系。
- **[品牌化转型加速]** -> [OBM模式占比提升]: OBM收入占比从29.74%提升至38.48%，自主品牌（如RITFIT）定价权增强，毛利率达44.42%。
- **[股份回购与分红]** -> [股东回报显著]: 耗资1.1亿元回购股份，叠加现金分红，年度现金回报总额占净利润比例高达204.45%。
- **[董事长被留置]** -> [治理风险凸显]: 董事长陈刚因被监察机关留置无法正常履职，未悉知年报内容，对公司治理稳定性构成重大不确定性。

## 风险警告
**核心风险在于“增收不增利”的恶性循环与治理层动荡。** 公司营收增长主要依赖跨境电商的高投入扩张，但销售费用、管理费用及汇兑损失激增，导致净利润暴跌超四成。这种以牺牲利润换规模的模式若无法通过品牌溢价或规模效应扭转，将严重侵蚀股东价值。同时，董事长陈刚被留置这一重大治理事件，直接导致年报披露存在瑕疵，暴露出公司内部控制和决策链条的脆弱性，对投资者信心构成根本性打击。

**外部环境风险高度集中。** 公司近87%收入依赖北美市场，中美贸易关税政策调整、汇率双向宽幅波动是悬在头顶的达摩克利斯之剑。尽管公司通过越南产能和海外办事处进行对冲，但地缘政治博弈和客户供应链多元化需求，可能随时冲击其核心业务基本盘。原材料价格波动与应收账款回收风险，在宏观不确定性加剧的背景下，将进一步放大经营脆弱性。
