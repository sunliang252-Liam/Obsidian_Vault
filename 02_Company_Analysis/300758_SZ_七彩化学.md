# 300758.SZ 深度透视

## 因果逻辑链
- **环保政策趋严** -> 中小落后产能出清: 环保监管长效机制加速不达标中小企业退出市场
- **铅铬颜料全球禁用政策** -> 高性能有机颜料需求增长: 禁令创造刚性替代需求，推动下游客户转向高性能环保产品
- **下游高端化转型** -> 定制化高性能颜料需求提升: 油墨、涂料、塑料行业向高端化发展，对颜料性能要求更高，且要求定制化解决方案
- **技术研发投入与核心中间体自产** -> 产品质量和成本优势: 自产中间体可控制品质、降低成本、提升供应链稳定性，技术积累保障产品性能领先
- **全产业链一体化布局** -> 供应链稳定性与性价比优势: 从原料到单体到新材料的一体化生产，减少对外依赖，降低综合成本
- **氨氧化核心技术** -> 三大业务协同发展: 氨氧化技术是连接有机颜料、材料单体、特种新材料的纽带，实现技术共享和原料互供
- **海外客户长周期认证** -> PPDI聚氨酯弹性体出口增长: 长周期认证建立信任，推动出口业务
- **MXD6产品性能优异** -> 获得BOPA膜头部客户订单: 阻隔性、加工性等优势满足高端包装需求
- **非经常性损益波动** -> 净利润波动: 非经常性损益在2023年正贡献1250万，2025年变为-1257万，影响利润稳定性
- **原材料价格波动** -> 生产成本不确定性: 国际原油价格宽幅波动导致基础化工品价格阶段性涨跌，影响成本控制

## 风险警告
公司面临以下深度风险：1）非经常性损益波动大，2025年出现较大负值，可能持续影响净利润；2）原材料成本受国际油价影响，控制存在不确定性；3）海外环保技术壁垒（如REACH法规）可能阻碍高端市场拓展；4）全球经济复苏放缓，终端需求疲软可能传导至上游；5）贸易摩擦及地缘政治不确定性。
