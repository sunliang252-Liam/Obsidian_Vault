# 600930.SH 深度透视

## 因果逻辑链
- **[装机规模高速扩张]** -> [营收增长14.76%]: 新增装机2876万千瓦，发电量同比增长29.64%，驱动收入增至389.80亿元。
- **[电价全面市场化下行]** -> [归母净利润下降17.76%]: 风电、光伏上网电价分别同比下降11.36%和12.32%，抵消了电量增长带来的收入增量。
- **[折旧与运营成本刚性增长]** -> [毛利率承压]: 新增装机导致固定资产折旧及运维费用增加，营业成本增速（28.58%）显著高于收入增速（14.76%）。
- **[老旧机组更新改造]** -> [资产减值损失激增]: 对拟更新拆除的老旧风电机组计提减值准备7.69亿元，是资产减值损失同比增加6.59亿元的主因。
- **[“沙戈荒”大基地战略]** -> [资源储备与装机结构优化]: 牵头开发近6000万千瓦大基地项目，新疆天山北麓基地建成投产，巩固了西北区域资源与装机领先地位。
- **[补贴款集中回收]** -> [经营性现金流大幅改善]: 经营活动现金流净额同比增长31.73%至318.31亿元，主要得益于电费回收增加及补贴款集中到账。
- **[IPO与债券融资]** -> [资本结构优化]: 2025年7月IPO募资约179亿元，并发行多期可续期公司债，推动净资产增长29.70%，资产负债率降至70.35%。

## 风险警告
**核心风险在于电价与消纳的双重挤压。** 随着新能源全面参与电力市场，公司综合平均电价已出现明确下行趋势（风电、光伏电价同比降幅均超11%）。同时，全国风光装机容量已提前超额完成2030年目标，西北等主力区域消纳压力持续增大，利用小时数下滑（风电降130小时，光伏降81小时）。这种“量增价跌”的剪刀差正在侵蚀公司的盈利空间，2025年归母净利润同比下降17.76%即为明证。

**另一个关键风险是资本开支与回报的错配。** 公司处于高速扩张期，2025年基建投资高达698亿元，导致投资活动现金流净流出近760亿元。虽然IPO和债券融资缓解了部分压力，但大规模资本开支带来的折旧和财务费用刚性增长，在电价下行周期中，新项目的投资回报率可能不及预期，存在资产减值风险（2025年已计提8.24亿元）。若未来电价持续低迷，高杠杆扩张模式将面临严峻考验。
