# 601117.SH 深度透视

## 因果逻辑链
- **[新签合同额突破4000亿]** -> [收入增长]: 市场开拓力度加大，带动新签合同额同比增长10.01%，为未来收入增长奠定基础。
- **[“T+EPC”模式深化]** -> [EPC合同占比提升]: 技术创新驱动工程总承包模式升级，EPC合同占比首年超过60%，提升项目附加值。
- **[境外收入高增]** -> [利润结构优化]: 境外收入同比增长19.03%，毛利率高于境内，有效对冲了境内收入下滑的影响。
- **[精益化管理与提质增效]** -> [净利润增速远超收入]: 通过“三张计划表”和“九个专项行动”强化成本管控，净利润增速（13.15%）显著高于收入增速（1.97%）。
- **[实业项目投产转固]** -> [实业收入增长]: 天辰公司、华陆公司等实业项目收入增长11.47%，成为新的利润增长点。
- **[研发投入持续高企]** -> [技术壁垒加固]: 研发投入占营收3.54%，在己二腈、POE等“卡脖子”技术领域取得突破，巩固了化学工程领域的技术护城河。
- **[财务公司资金拆借减少]** -> [经营性现金流大幅下滑]: 经营活动现金流净额同比下滑83.45%，主要系财务公司资金拆出业务净流入减少，而非主业经营恶化。

## 风险警告
**现金流与“两金”压力是核心风险。** 尽管净利润创历史新高，但经营性现金流净额仅14.43亿元，同比骤降83.45%，与利润严重背离。公司应收账款和合同资产（“两金”）规模庞大，上游结算难、收款难问题突出，下游刚性支付压力不减，若经济下行或客户资信恶化，将直接冲击公司现金流安全，甚至引发坏账风险。

**海外经营与项目执行风险不容忽视。** 公司境外业务占比超30%，且深度参与“一带一路”沿线高风险国家项目。地缘政治冲突、汇率波动、合同履约争议等风险持续存在。同时，化工项目施工周期长、主体多，项目进度、成本超支及结算纠纷是常态，对公司的项目管理能力和风险控制体系构成严峻考验。
