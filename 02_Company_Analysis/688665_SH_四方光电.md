# 688665.SH 深度透视

## 因果逻辑链
- **[北美温室减排政策与低GWP制冷剂替代]** -> [冷媒泄漏监测传感器收入高增]: 政策强制推动新型制冷剂应用，催生对冷媒泄漏监测传感器的刚性需求，公司作为核心供应商直接受益。
- **[外延并购（诺普热能、精鼎电器）]** -> [低碳热工业务收入快速增长]: 并购带来技术、客户与渠道的协同效应，快速切入并扩大在冷凝壁挂炉等低碳热工领域的市场份额。
- **[产品结构优化（高毛利新品占比提升）]** -> [整体毛利率稳中有进]: 公司主动调整销售策略，聚焦高附加值产品（如冷媒传感器、气体分析仪），带动综合盈利能力改善。
- **[加强应收账款管理]** -> [经营性现金流同比暴增996%]: 在收入增长的同时，通过强化回款考核与催收力度，显著提升现金回收效率，改善现金流质量。
- **[“传感器+执行器+控制器”系统能力]** -> [客户粘性与竞争壁垒提升]: 从单一硬件销售转向提供成套化解决方案，增加客户转换成本，构建差异化竞争优势。
- **[全球化布局（匈牙利工厂、美国/韩国子公司）]** -> [海外市场拓展与供应链韧性增强]: 通过设立海外实体和工厂，贴近客户、规避贸易壁垒，提升全球交付能力与品牌影响力。
- **[核心零部件自研（红外光源、探测器等）]** -> [成本控制与供应链安全]: 垂直整合模式降低对外部供应商依赖，实现“高技术、低成本、量产化”，保障产品竞争力与交付稳定性。

## 风险警告
**核心风险在于下游需求波动与市场竞争加剧。** 公司业绩高度依赖“双碳”政策驱动的冷媒监测、储能安全等新兴场景，若政策推进不及预期或技术路线发生替代，高增长业务可能面临失速。同时，全球传感器市场由国际巨头主导，国内中低端市场同质化竞争激烈，公司向高端领域突破时，将面临技术、品牌和客户认证的多重挤压，存在市场份额被侵蚀或价格战导致毛利率下滑的风险。

**财务风险集中于汇率波动与应收账款压力。** 公司海外业务占比超30%，以美元、欧元结算，人民币汇率升值将直接侵蚀出口利润。尽管2025年现金流大幅改善，但应收账款随销售规模扩大而增长，若主要客户（尤其是汽车、工业领域）出现经营困难或回款周期延长，将给公司营运资金带来压力，并可能增加坏账损失。
