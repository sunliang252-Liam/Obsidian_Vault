# 000607.SZ 深度透视

## 因果逻辑链
- **[传统媒体广告收入下滑]** -> [整体营收下降12.88%]: 广告及策划、报刊发行等核心业务受数字化转型冲击，客户预算缩减，收入持续萎缩。
- **[重大诉讼计提预计负债]** -> [营业外支出暴增]: 因南华大学船山学院转设纠纷，计提预计负债6500万元，直接吞噬当期利润。
- **[教育子公司业绩不达预期]** -> [巨额商誉减值]: 中教未来等教育业务受政策与市场环境影响，未达预期，计提商誉减值，是净利润巨亏的核心原因之一。
- **[应收账款及长期股权投资减值]** -> [信用及资产减值损失扩大]: 对余杭时报、布朗等项目计提长期股权投资减值，并增加信用减值损失，进一步加剧亏损。
- **[发行5.25亿中期票据]** -> [资产负债率上升至57.11%]: 为补充流动资金和偿还有息负债，新增债券融资，导致财务杠杆率显著提高。
- **[母公司未分配利润为负]** -> [无法进行现金分红]: 截至报告期末，母公司未分配利润为-1.62亿元，不满足分红条件，投资者回报预期落空。
- **[“媒体+政务服务商务”模式深化]** -> [部分抵消传统业务下滑]: 通过全案策划、会展活动等增值服务，稳固政企客户，减缓了广告收入断崖式下跌。

## 风险警告
公司2025年业绩暴雷，归母净利润巨亏3.58亿元，核心风险在于**资产减值与或有负债的集中爆发**。教育子公司中教未来商誉减值、长期股权投资减值以及因诉讼计提的预计负债，合计超过2.3亿元，直接击穿了本已脆弱的盈利能力。这暴露了公司前期并购整合效果不佳，以及部分投资项目存在重大不确定性。

此外，公司传统传媒主业（广告、报刊、印刷）收入全面下滑，毛利率持续走低，显示其核心业务正被数字化浪潮不可逆地侵蚀。虽然公司尝试通过“媒体+”、会展、教育等转型，但新业务体量尚小，且教育板块自身也面临政策与竞争压力。公司资产负债率已升至57.11%，并发行了5.25亿中期票据，财务压力加大。母公司未弥补亏损导致无法分红，对长期投资者信心构成打击。
