# 000721.SZ 深度透视

## 因果逻辑链
- **[餐饮主业收入下滑]** -> [营收同比下降15.49%]: 餐饮服务收入18.53%的降幅是总营收下滑的主因，反映消费疲软与行业竞争加剧。
- **[成本刚性难降]** -> [毛利率恶化]: 餐饮服务毛利率为-9.71%，营业成本降幅（-15.37%）远低于收入降幅（-18.53%），导致亏损扩大。
- **[人工成本压降]** -> [总人工成本降幅达15.97%]: 通过“KPI+赛道”考核与组织精简，部分对冲了收入下滑对利润的侵蚀。
- **[资产减值损失激增]** -> [净利润进一步承压]: 2025年计提存货、固定资产等减值损失1463万元，同比暴增218倍，成为亏损扩大的重要推手。
- **[子公司破产出表]** -> [产生非经常性收益]: 控股子公司西饮品牌运营管理公司破产清算，带来278万元投资收益，但掩盖了主业持续失血的事实。
- **[食品工业线上增长]** -> [第二曲线初现]: 食品板块线上收入同比增长28.72%，但体量较小（仅占营收16.75%），尚无法弥补餐饮主业的巨大缺口。
- **[现金流大幅恶化]** -> [偿债风险加剧]: 经营活动现金流净额同比骤降68.71%，而短期借款高达4.19亿元，现金缺口扩大，流动性压力显著。

## 风险警告
**核心风险：主业持续失血与高负债下的流动性危机。** 公司已连续三年亏损，且亏损幅度逐年扩大（2023年-1.18亿→2024年-1.28亿→2025年-1.46亿）。餐饮服务毛利率为负（-9.71%），意味着每卖出一份餐食都在亏钱。与此同时，公司资产负债率高达86.36%，短期借款4.19亿元远超账面货币资金0.41亿元，经营活动现金流净额仅0.31亿元，偿债能力极度脆弱。母公司未分配利润为-4.81亿元，已不具备分红能力。

**第二风险：品牌老化与转型不确定性。** 公司虽拥有12个“中华老字号”品牌，但核心餐饮业务收入持续萎缩，表明品牌价值未能有效转化为市场竞争力。公司提出的“轻资产”扩张、数字化升级等转型措施尚处早期，效果未在财务数据中体现。子公司破产、资产减值频发，反映出内部管理和资产质量存在较大隐患。在餐饮行业竞争白热化的背景下，老字号若不能实现根本性的模式创新和效率提升，将面临被市场边缘化的风险。
