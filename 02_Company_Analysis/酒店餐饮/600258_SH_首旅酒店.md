# 600258.SH 深度透视

## 因果逻辑链
- **[行业价格承压]** -> [RevPAR同比下降2.7%]: 2025年行业整体“弱恢复”，平均房价(ADR)同比下降1.3%，导致不含轻管理酒店的全部酒店RevPAR降至163元。
- **[直营门店数量下降]** -> [酒店运营收入下降7.54%]: 直营店数量减少及RevPAR降低，导致酒店运营收入同比减少3.82亿元。
- **[特许加盟店数量增加]** -> [酒店管理收入上升11.14%]: 公司重点发展轻资产的特许加盟模式，管理费收入同比增加2.41亿元，部分对冲了直营收入下滑。
- **[销售佣金及会员费增加]** -> [销售费用增长15.23%]: 为争夺客源，OTA订单及营销投入增加，导致销售佣金同比增加8183万元，侵蚀利润。
- **[租赁负债利息减少]** -> [财务费用下降21.47%]: 租赁负债产生的利息费用同比减少7388万元，是利润稳定的重要支撑。
- **[标准管理酒店新开店增长17.2%]** -> [储备店结构优化]: 标准管理酒店新开店832家，储备店中标准管理酒店占比提升至74.6%，为未来收入结构升级奠定基础。
- **[中高端酒店房间量占比提升]** -> [产品结构持续升级]: 中高端酒店房间量占比提升至42.3%，有助于提升整体平均房价和品牌溢价。

## 风险警告
首旅酒店面临的核心风险在于行业价格战与成本刚性上涨的双重挤压。2025年行业RevPAR持续下滑，而公司为维持市场份额，销售费用（尤其是OTA佣金）大幅增长15.23%，直接侵蚀了利润空间。若宏观经济复苏不及预期，商务出行需求持续疲软，公司可能陷入“增收不增利”的困境，盈利能力将面临严峻考验。

此外，公司高达46.9亿元的商誉及商标权资产是悬在头顶的达摩克利斯之剑。历史收购形成的巨额商誉，一旦被收购标的（如如家酒店集团）经营状况不及预期，将面临大规模减值风险，对当期利润造成毁灭性打击。同时，公司以特许加盟为主的扩张模式（占比92.9%），虽能快速扩张，但也带来了加盟店管理标准不一、品牌声誉受损的潜在风险。
