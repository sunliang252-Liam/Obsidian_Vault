# 002186.SZ 深度透视

## 因果逻辑链
- **[消费疲软与竞争加剧]** -> [营收下降10.52%]: 餐饮行业结构性调整，消费者需求分化，导致公司餐饮和商品销售业务收入均出现两位数下滑。
- **[营收下滑叠加刚性成本]** -> [净利润暴跌77.29%]: 收入减少1.48亿，而营业成本、管理费用等刚性支出降幅远小于收入降幅，导致利润被大幅侵蚀。
- **[核心门店场景焕新]** -> [假日经济拉动营收]: 和平门店“空中四合院”、王府井店“宫囍龙凤呈祥”等主题空间，在国庆等假期实现单日营收破百万，验证了场景创新对客流和客单价的拉动作用。
- **[“餐饮+食品”双轮驱动]** -> [团膳业务成为增长亮点]: 团膳业务收入同比增长38%，利润同比增长76%，成为公司多元化发展和业绩的重要支撑。
- **[品牌年轻化与全域营销]** -> [线上渠道与私域增长]: 抖音渠道排名区域前6%，线上收入占比7.3%，私域商城“全记货铺”销售3110万元，数字化营销有效触达年轻客群。
- **[非遗技艺与老字号品牌]** -> [文化溢价与政府支持]: 四大品牌均为老字号，拥有多项非遗技艺，为公司带来品牌溢价和稳定的政府补助（748.7万元），是抵御市场波动的核心资产。
- **[投资活动现金流大幅流出]** -> [在建工程激增]: 全聚德大兴旧宫镇危房翻建项目投入增加，导致在建工程同比增长821%，投资活动现金流净额由负转正大幅流出，短期占用大量资金。
- **[子公司经营不善]** -> [商誉减值与清算]: 武汉时上集业绩承诺完成率仅42.93%，计提商誉减值74.21万元；同时清算长沙、大连等亏损子公司，表明公司正在主动剥离不良资产。

## 风险警告
**核心风险在于业绩持续下滑与盈利能力脆弱。** 公司2025年营收和净利润双双大幅下滑，扣非净利润已转为亏损（-622万元），表明主营业务已失去内生造血能力。尽管公司通过场景创新和团膳业务寻找增量，但餐饮主业受消费疲软和竞争加剧影响，复苏前景不明。若2026年消费环境未见明显好转，公司可能面临持续亏损的风险。

**扩张与转型的投入产出比存在不确定性。** 公司正大力投资于门店改造（大兴翻建项目）和国际化布局（纽约、洛杉矶店），导致投资活动现金流大幅流出。这些投入能否在未来转化为有效的营收和利润增长，存在较大不确定性。同时，食品业务新品（如酱酒、休闲食品）的市场表现和盈利贡献尚待验证，存在投资回报不达预期的风险。
