# 605108.SH 深度透视

## 因果逻辑链
- **“双春年”婚宴需求集中释放** -> **营收增长6.17%**: 2025年农历“双春年”带动婚宴市场景气，公司凭借宴会龙头地位承接需求，驱动餐饮主业收入增长。
- **门店高速扩张带来的折旧与财务费用激增** -> **利润增速远低于营收（+2.04%）**: 2025年新增5家门店（16.19万平米），折旧摊销同比增加5750万元，叠加财务费用增长20.72%，严重侵蚀利润。
- **“餐饮+宾馆”三轮驱动模式** -> **经营现金流强劲增长48.08%**: 富茂酒店以餐饮为核心（收入占比70%+），提升资产利用率，带来充沛的预收款和经营性现金流入，现金流与利润背离。
- **食品业务四年培育后首年盈利** -> **第二增长曲线初步验证**: 食品收入达3.03亿元，净利润实现历史性首盈，名厨粽、小笼包等大单品及抖音渠道（+168.1%）成为核心驱动力。
- **“大店模式+宴会刚需”定位** -> **构筑中小餐饮难以复制的盈利壁垒**: 聚焦家庭聚餐与宴会（十大喜宴），大店在黄道吉日承接集中化需求，规模效应显著，形成稳定盈利来源。
- **数字化系统（CRM、灵活用工）赋能** -> **运营效率与成本管控提升**: 自研CRM提升宴会转化率，灵活用工平台注册超10万人，有效控制人力成本，助力膳食毛利率同比提升1.52个百分点。
- **新店爬坡期亏损与老店改造投入** -> **短期利润承压**: 新开门店及新增客房处于市场培育期，营收尚未覆盖开办费及折旧，叠加9家老店升级改造，导致利润阶段性承压。
- **开店策略由“快速扩张”转向“稳步拓店”** -> **未来利润释放预期**: 公司主动放缓扩张节奏，重点推动现有门店运营爬坡，预计折旧摊销压力边际递减，利润弹性有望逐步显现。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长6.17%，但净利润仅微增2.04%，主因是过去几年激进扩张（门店面积从2019年24.5万平飙升至2025年约93.5万平）带来的巨额折旧摊销（2025年较2023年增加1.37亿）和财务费用（+20.72%）的刚性压力。若新店爬坡速度不及预期，或宏观消费环境再度疲软，利润端将持续承压，甚至出现下滑。此外，董事韦小五未签署年报确认意见，其声称“被剥夺运营系统登录权限”，暴露了公司内部治理存在潜在摩擦与信息不对称风险，可能影响决策效率与团队稳定性。

**另一重大风险是宏观政策与消费趋势的不可控性。** 报告明确指出“新禁酒令”等宏观环境导致6-7月营收明显下滑，显示公司业绩对政策变化高度敏感。同时，餐饮行业竞争白热化，人力、租金、原料成本持续上涨，公司虽具备供应链优势，但若无法持续通过提价或效率提升来消化成本，毛利率将面临侵蚀。此外，食品安全作为餐饮业的生命线，任何突发事件都可能对百年老字号的品牌声誉造成不可逆的打击。
