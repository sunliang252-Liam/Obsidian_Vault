# 688543.SH 深度透视

## 因果逻辑链
- **公司持续高研发投入，突破低成本发动机设计技术** -> 军贸业务实现历史性突破，签订4.66亿元装药合同: 低成本技术使产品在军贸中具备价格竞争优势，从而获得大额订单
- **军贸业务突破和军品需求增长** -> 动力模块产能提升30%: 订单激增倒逼产能扩张，公司主动实施改造优化
- **弹药装备产品在军方竞标中连续中标** -> 弹药装备业务稳定增长: 竞标成功直接转化为批产订单，保障收入
- **股权激励计划确认股份支付费用3613.51万元** -> 扣除股份支付影响后净利润同比增长41.92%: 股份支付费用作为非经常性损益剔除后，更能反映主营业务盈利能力

## 风险警告
公司军贸业务占比快速提升，但国际地缘政治波动和军贸政策变化可能带来订单不确定性；同时，军工行业高度依赖军方采购计划，若国防预算调整或装备列装进度放缓，可能影响公司收入。此外，产能扩张需大量资本投入，若订单不及预期，可能导致产能闲置和资产减值风险。
