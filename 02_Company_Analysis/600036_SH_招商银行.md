# 600036.SH 深度透视

## 因果逻辑链
- **[低利率环境下负债成本管控]** -> [净息差保持行业领先]: 通过优化存款结构、压降高成本负债，使计息负债成本率同比下降38bp，有效对冲资产收益率下行压力。
- **[零售AUM突破17万亿]** -> [财富管理收入增长21.39%]: 管理零售客户总资产同比增长14.44%，带动代销理财、基金、信托等手续费收入大幅增长。
- **[AI技术全面渗透]** -> [运营效率与客户体验提升]: 落地856个AI场景应用，日均Tokens吞吐增长10.1倍，节约人工1,556万小时，驱动“人+数智化”服务模式。
- **[国际化布局深化]** -> [境外机构营收增长33.80%]: 境外机构总资产增长12.88%，在港机构营收增长36.40%，跨境金融成为新增长极。
- **[零售贷款不良率上升]** -> [资产质量承压]: 零售贷款不良率从0.96%升至1.06%，小微贷款不良率从0.79%升至1.22%，消费信贷风险暴露增加。
- **[拨备覆盖率下降]** -> [风险抵补能力边际减弱]: 拨备覆盖率从411.98%降至391.79%，贷款拨备率从3.92%降至3.68%，信用成本虽降但安全垫变薄。
- **[资本充足率下降]** -> [资本内生增长承压]: 高级法下核心一级资本充足率从14.86%降至14.16%，受中期分红和OCI减少影响，资本缓冲有所消耗。

## 风险警告
**核心风险在于零售信贷资产质量恶化趋势。** 零售贷款不良率连续上升，小微贷款不良率从0.79%跳升至1.22%，个人住房贷款关注率从1.28%升至1.57%。在居民收入预期偏弱、消费复苏乏力的宏观背景下，零售信贷风险可能进一步暴露，侵蚀利润。虽然公司拨备覆盖率仍处高位，但已连续两年下降，安全垫正在变薄。

**净息差持续收窄是长期结构性压力。** 尽管公司通过负债成本管控维持了行业领先的净息差，但资产端LPR下调、有效信贷需求不足的压制仍在，负债端存款定期化趋势未见拐点。2026年净息差预计仍将承压，若资产收益率下降速度快于负债成本改善，将直接压缩核心盈利空间。同时，资本充足率下降也限制了风险加权资产的扩张能力。
