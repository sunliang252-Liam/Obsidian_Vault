# 600653.SH 深度透视

## 因果逻辑链
- **[新能源汽车渗透率快速提升，冲击传统豪华车市场]** -> [宝马品牌销量下滑，新车销售价格倒挂加剧]: 新能源车对传统燃油车形成替代效应，宝马品牌在中国市场销量同比下滑12.5%，公司作为经销商，新车销售毛利为负，核心业务承压。
- **[主机厂（宝马）持续向经销商转移降价压力]** -> [公司汽车销售业务毛利率为负（-1.62%）]: 整车制造企业为保市场份额不断降价，将成本压力传导至下游经销商，导致公司卖车亏损，主营业务盈利能力恶化。
- **[上年同期通过转让非主业子公司获得大额投资收益及债权受偿]** -> [本年度归母净利润同比大幅下滑561.98%]: 2024年公司通过资产处置获得非经常性收益，而2025年无此类一次性收益，导致利润基数效应显著，扣非后净利润下滑幅度（44.31%）远小于归母净利润。
- **[申华金融大厦（上海核心地段甲级写字楼）维持高出租率]** -> [为公司提供稳定现金流和利润支撑，对冲主业周期波动]: 在办公楼市场低迷期，核心区位优质物业展现出抗风险能力，成为公司经营的“稳定器”。
- **[公司完成贷款整体置换，实现两次降息]** -> [预计每年减少利息支出约1400万元，减轻财务负担]: 主动优化融资结构，降低综合融资成本，直接改善利润表，增强财务弹性。
- **[汽车行业价格战持续升级，消费意愿走弱]** -> [公司计提大额资产减值损失（-4585万元）]: 市场价格倒挂及库存车辆价值下降，导致公司需对存货等资产计提减值，进一步侵蚀利润。
- **[公司清理“两非两资”企业及历史清欠]** -> [优化资产结构，回笼资金约1900万元]: 通过处置低效资产和追讨历史欠款，盘活沉淀资源，为战略转型储备资金。

## 风险警告
**核心风险在于主营业务的结构性崩塌。** 公司约96%的采购额来自宝马（荷兰）控股公司，业务与单一品牌深度绑定。在新能源汽车渗透率超50%的背景下，传统豪华车经销商模式正面临价值重估。新车销售价格持续倒挂（毛利率-1.62%），表明卖车本身已无利可图，公司盈利严重依赖售后服务和物业租金，但若新车销量持续萎缩，售后基盘将随之动摇，形成恶性循环。公司2025年归母净利润巨亏1.78亿元，扣非后亏损1.91亿元，主业造血能力已近枯竭。

**转型探索存在高度不确定性，且财务基础薄弱。** 公司虽已布局工业预测性运维（申维探索）和产业投资基金，但这些新业务尚处于起步阶段，短期内无法贡献利润。同时，公司净资产仅6.48亿元，但总负债20.81亿元，资产负债率高达73.5%，且母公司未分配利润亏损高达-18.86亿元，已无分红能力。在主营业务持续失血、新业务尚未成型、财务杠杆高企的三重压力下，公司抵御行业下行周期的能力极为脆弱，任何转型失败或市场进一步恶化都可能引发流动性危机。
