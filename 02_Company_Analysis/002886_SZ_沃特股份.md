# 002886.SZ 深度透视

## 因果逻辑链
- **[特种高分子材料平台化战略]** -> [营收增长8.17%]: 公司聚焦LCP、PPA、聚砜等特种材料，2025年特种高分子材料收入同比增长9.92%，占比提升至49.37%，成为核心增长引擎。
- **[重庆基地产能释放]** -> [LCP产能全球领先]: 年产20,000吨LCP树脂项目一期、二期投产，公司有望成为全球最大LCP供应商，迅速响应下游高频通讯、服务器散热需求。
- **[PTFE氟材料双基地布局]** -> [半导体材料突破]: 收购沃特华本半导体及密封件公司，实现PTFE薄膜、精密零部件在半导体清洗、封装、高纯储运领域的头部客户认证与量产。
- **[下游新兴场景拓展]** -> [高附加值订单落地]: 成功开发服务器风冷散热材料（覆盖5万转以上规格）、手机主动散热风扇材料、机器人电机定子包胶材料，切入高增长赛道。
- **[经营效率提升]** -> [现金流大幅改善]: 经营活动现金流净额2.21亿元，同比增长135.90%，主要得益于销售回款增加及存货周转率提升。
- **[非经常性损益贡献]** -> [净利润高增长]: 归母净利润同比增长75.97%，其中收购沃特华本密封件产生的营业外收入约1,700万元，显著增厚当期利润。
- **[原材料国产化突破]** -> [供应链安全]: LCP关键原料联苯二酚（BP）实现国产规模化稳定供应，彻底解决上游“卡脖子”问题，保障产能释放。

## 风险警告
公司当前利润高增长高度依赖非经常性损益（收购收益），扣非净利润增速（38.70%）远低于归母净利润增速（75.97%），且毛利率因原材料成本上升及产品结构变动而下滑1.28个百分点。若剔除一次性收益，内生盈利能力改善有限。

特种高分子材料行业竞争激烈，公司面临比利时索尔维、美国塞拉尼斯等国际巨头的直接竞争，以及国内同行产能扩张的压力。同时，下游电子、汽车等行业景气度波动可能影响需求，原材料价格受国际油价影响，成本传导存在时滞，业绩波动风险不可忽视。
