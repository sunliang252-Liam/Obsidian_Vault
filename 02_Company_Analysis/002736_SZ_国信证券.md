# 002736.SZ 深度透视

## 因果逻辑链
- **[市场成交活跃]** -> [经纪业务收入大增]: 2025年A股成交额同比增62.6%，公司财富管理与机构业务收入同比增40.97%，成为业绩增长主引擎。
- **[收购万和证券]** -> [规模与区域布局扩张]: 发行股份收购万和证券96.08%股权，总资产突破5700亿，深化粤港澳大湾区与海南自贸港联动。
- **[融资融券规模扩张]** -> [利息净收入增长]: 两融余额达940亿元（同比+34%），推动利息净收入同比增26.38%。
- **[自营投资把握结构性机会]** -> [投资收益稳健]: 权益与固收投资业务动态优化资产结构，投资收益同比增27.13%，贡献营收43.44%。
- **[金融科技赋能]** -> [运营效率与客户体验提升]: “慧芯”智能体平台、新一代核心交易系统等落地，支撑客户数增长17%、托管资产增长30.5%。
- **[投行业务结构转型]** -> [收入短期承压]: 股权承销向再融资倾斜（再融资额同比+161%），但IPO承销家数下降，投行业务收入同比降8.56%。
- **[资管业务专业化运营]** -> [规模结构调整]: 资管子公司开业，集合资管规模下降56%，但单一及专项资管增长，整体规模收缩14.38%。

## 风险警告
**市场周期与业务波动风险**：公司业绩高度依赖资本市场活跃度。2025年营收与利润创十年新高，主要受益于A股成交额同比大增62.6%及指数上行。若未来市场交投萎缩、指数回调，经纪、两融、自营等核心业务收入将面临同步下滑压力，业绩波动性显著。

**并购整合与信用风险**：收购万和证券后，需面对组织文化融合、业务协同及管理半径扩大的挑战。同时，信用减值损失虽同比大幅减少，但融出资金规模同比增36%，股票质押业务风险敞口仍存。若宏观经济下行或信用事件爆发，减值损失可能回升，侵蚀利润。
