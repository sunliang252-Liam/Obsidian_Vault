# 002372.SZ 深度透视

## 因果逻辑链
- **[房地产下行周期]** -> [营收下降14.12%]: 房地产开发投资同比降17.2%，新房开工/竣工面积双降超18%，直接压制管道需求。
- **[零售高端品牌定位]** -> [毛利率韧性]: PPR系列毛利率54.92%，虽降1.55个百分点，但远高于PE/PVC，证明品牌溢价护城河有效。
- **[“星管家”服务体系]** -> [零售市占率提升]: 在行业总量下行中，通过服务差异化实现“稳中有升”，形成良性市场生态。
- **[原材料价格低位震荡]** -> [成本端缓冲]: PP/PE/PVC价格低位运行，直接材料成本下降14.81%，部分对冲了营收下滑对利润的冲击。
- **[管理费用刚性]** -> [利润降幅大于营收]: 管理费用仅降3.26%，远低于营收降幅14.12%，固定运营成本无法同比例缩减，侵蚀利润。
- **[利息收入下降]** -> [财务费用大幅转正]: 银行利率下行导致利息收入从4966万降至1624万，财务费用同比增77.71%，直接拖累净利润。
- **[工程业务“风险控制第一”]** -> [经营现金流健康]: 主动收缩高风险工程，聚焦优质客户，经营性现金流净额11.78亿，同比增2.7%，远超净利润。
- **[同心圆业务培育]** -> [新增长极尚在途中]: 防水、净水等新业务虽在推进，但尚未形成规模效应，未能弥补管道主业下滑缺口。

## 风险警告
**核心风险在于宏观与地产的深度绑定。** 公司营收与房地产新开工、竣工面积高度正相关。2025年房地产开发投资下降17.2%，直接导致公司营收下滑14.12%。若2026年地产市场持续低迷或居民装修意愿不足，公司57亿营收目标将面临巨大挑战。尽管零售业务有品牌护城河，但总量萎缩的背景下，“份额提升”难以完全对冲“蛋糕缩小”。

**利润端的双重挤压不可忽视。** 一是管理费用等固定开支的刚性，导致利润降幅（-22.24%）显著大于营收降幅（-14.12%）；二是利息收入随利率下行而锐减，进一步削弱了净利润。更需警惕的是，公司2025年分红率高达95.49%，几乎将全部利润分掉。在业绩下滑期维持如此高的分红，虽回报股东，但也削弱了公司应对行业寒冬的财务弹性，一旦行业复苏不及预期，高分红或难以为继。
