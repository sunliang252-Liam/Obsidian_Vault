# 300374.SZ 深度透视

## 因果逻辑链
- **[核心业务毛利率下降]** -> [净亏损扩大至1.21亿元]: 装配式建筑产品及服务毛利率同比下降3.36个百分点，直接侵蚀利润。
- **[终止确认递延所得税资产]** -> [亏损加剧]: 部分子公司预计无法在税法年限内弥补亏损，导致递延所得税资产转回，增加所得税费用约2.34亿元。
- **[装配式建筑产品收入大增59.28%]** -> [营收持平]: 产品收入增长对冲了建筑服务收入下降9.38%的影响，使总营收保持稳定。
- **[经营活动现金流净额增长63.42%]** -> [现金流与净利润背离]: 通过压降应收账款存量、提升回款率及使用供应链金融，实现正向现金流，但利润受非现金项目拖累。
- **[前五大客户关联交易占比51.34%]** -> [业务依赖系统内市场]: 公司高度依赖中国中铁体系内项目，关联交易占比过半，市场拓展独立性受限。
- **[应收账款占总资产42.83%]** -> [资金周转风险]: 应收账款规模庞大且回款周期长，是公司运营能力下降的核心风险源。
- **[研发投入增长18.22%]** -> [技术壁垒构建]: 持续投入研发以维持装配式建筑技术领先，但全部费用化，短期无直接利润贡献。
- **[孙志强减持并放弃表决权]** -> [控制权稳定]: 创始人孙志强持续减持并放弃表决权，中铁建工集团以26.51%持股成为控股股东，治理结构趋于稳定。

## 风险警告
**核心风险在于应收账款高企与经营持续亏损的恶性循环。** 公司应收账款占总资产比例高达42.83%，且客户多为建设方，回款周期漫长。尽管2025年通过强力催收实现了经营性现金流转正，但净亏损1.21亿元表明造血能力严重不足。若未来应收账款无法及时收回，将直接冲击资金链，导致运营能力进一步恶化。

**第二大风险是业务高度依赖关联交易与行业周期。** 公司前五大客户中关联交易占比超50%，业务增长严重依赖中国中铁体系内项目，独立市场拓展能力薄弱。同时，建筑行业整体处于下行周期，公司毛利率持续承压，若无法有效拓展外部市场并提升盈利能力，将面临持续亏损甚至资产减值的风险。母公司未分配利润已亏损3.73亿元，短期无法分红。
