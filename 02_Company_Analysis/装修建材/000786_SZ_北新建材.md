# 000786.SZ 深度透视

## 因果逻辑链
- **房地产投资下降17.2%，房屋竣工面积下降18.1%** -> 石膏板销量下降1.1%，营业收入下降8.73%: 下游需求萎缩
- **存量房翻新及城市更新政策推动** -> 涂料业务收入增长23.10%，防水业务收入增长3.33%: 政策引导需求结构转变
- **公司推进‘一体两翼’战略，协同渠道资源** -> 涂料、防水业务逆势增长: 内部协同效应
- **实施‘一毛钱’成本节约计划及供应链优化** -> 经营净现金流下降18.12%但降幅小于利润降幅: 成本控制部分对冲收入下滑
- **房地产下行导致石膏板需求疲软** -> 石膏板产能利用率60.36%，低于行业均值: 需求不足影响产能利用
- **研发投入保持稳定（4.13%营收），拓展新产品** -> 涂料及防水业务毛利率提升: 产品创新提升附加值
- **宏观政策支持好房子、绿色建材** -> 公司未来增长预期: 政策红利推动长期需求

## 风险警告
房地产持续下行导致石膏板主业收入及利润双降，产能利用率偏低（60%），若需求恢复不及预期，可能进一步侵蚀盈利能力。同时，新业务（涂料、防水）虽增长但体量较小，尚不足以完全对冲传统业务下滑。
