# 000619.SZ 深度透视

## 因果逻辑链
- **[房地产下行拖累核心主业]** -> [塑料型材收入-26.05%，铝型材收入-11.16%]: 房地产市场持续调整，新建商品房销售面积下降8.7%，直接导致公司核心建材产品需求萎缩。
- **[环保材料并购扩张对冲下滑]** -> [环保材料收入+40.78%，销量+35.41%]: 收购康宁特环保及工程公司，打通SCR脱硝催化剂全生命周期产业链，产能跃居行业第一梯队，成为唯一增长引擎。
- **[资产出售掩盖经营亏损]** -> [扣非净利润-1.82亿元，但归母净利润仅-0.86亿元]: 出售芜湖本部部分土地房产获资产处置收益0.74亿元，非经常性损益合计0.96亿元，掩盖了主营业务深度亏损的真相。
- **[原材料成本下降但毛利恶化]** -> [绿色建材毛利率-0.93pct至6.20%，铝型材毛利率-1.02pct至4.71%]: 尽管PVC等原材料价格平稳，但产品售价降幅更大，成本传导机制失效，盈利空间被持续压缩。
- **[存货与预付账款大幅压降]** -> [经营活动现金流净额+151.37%至2.71亿元]: 公司强化“产供销财”联动，存货减少1.02亿元、预付账款减少1.07亿元，现金流改善主要来自营运资金压缩，而非盈利改善。
- **[新产业布局加速但短期难见效益]** -> [投资活动现金流净额-125.29%至-1.74亿元]: 年内完成对康宁特环保、华北塑料等多项并购及海外门窗项目投资，资本开支大幅增加，新项目尚处整合期，收益贡献有限。
- **[连续三年扣非亏损]** -> [2023-2025年扣非净利润分别为-0.44亿、-1.21亿、-1.82亿]: 核心主业竞争力持续弱化，转型新产业尚未形成有效利润支撑，公司陷入“主业萎缩-转型投入-短期亏损扩大”的恶性循环。

## 风险警告
**核心风险：主业崩塌与转型失速的双重困境。** 公司传统塑料型材业务收入已从2023年的约14.3亿骤降至2025年的10.6亿，两年缩水26%，且毛利率仅7.76%，已沦为微利甚至亏损业务。铝型材虽营收占比超50%，但毛利率仅4.71%，在光伏行业供需失衡、价格战持续的背景下，该板块同样面临利润被侵蚀的风险。公司试图通过并购环保材料（SCR脱硝催化剂）和功能性新材料（高分子托辊）实现转型，但环保材料毛利率也同比下降1.75pct至19.05%，且新并购的康宁特环保、华北塑料尚处整合初期，能否实现预期收益存在重大不确定性。

**财务风险：资产质量恶化与偿债压力并存。** 公司连续三年扣非亏损，2025年扣非净亏损扩大至1.82亿元，且应收账款高达9.33亿元（占总资产17.47%），同比增长13%，坏账风险持续累积。短期借款10.31亿元，而货币资金仅6.88亿元（其中受限资金0.11亿元），短期偿债压力较大。公司计划不派发现金红利，反映出资金链紧张的现实。若转型新产业无法快速贡献利润，公司可能面临“主业失血、新业不济、债务承压”的三重困境。

**公司简介（F10 原文）**

> 海螺(安徽)节能环保新材料股份有限公司(简称“海螺新材”),是海螺集团“一基五业”发展的重要板块之一。公司始建于1995年,总部设在安徽芜湖,在国内外拥有30余家子公司,分布13个省市和泰国、缅甸、印尼、乌兹别克斯坦等境外国家。经过近年来的快速发展,海螺新材逐步构建了绿色建材、环保材料、功能性新材料多元驱动的发展格局。绿色建材板块拥有塑料型材、铝材、生态家居等产业。海螺塑料型材被誉为“欧式塑料门窗在中国的典型代表”,产销规模稳居行业前列。海螺铝材涵盖工业铝材、建筑铝材、太阳能光伏边框支架等不同产品类别,在河南登封、广东英德、四川成都、山东东营、海外泰国建有铝材生产基地,掌握熔铸、挤压、氧化、电泳、喷涂全套生产工艺,年铝合金加工能力20余万吨。海螺生态家居提供“天地墙门窗柜”一站式产品解决方案,系统集成节能系统门窗、生态门、生态地板、生态墙板、生态家具等多个系列产品,产品零甲醛、免油漆、强度高、耐老化,防火防水、防潮防霉,抗菌耐腐蚀,材料可回收再利用,广泛应用于医院、学校、酒店及家装等领域。环保材料板块主要从事SCR脱硝催化剂的生产研发和销售,公司在河北保定、广西来宾、安徽芜湖、河南新密建有生产基地,拥有生产、再生、回收处置、工程服务一体化产业链条,催化剂年产能8.4万m3,废旧催化剂循环处理能力超过8万吨,产能规模和综合实力位居行业前列。海螺蜂窝、平板式催化剂覆盖160-420℃全温度区间,具有脱硝活性高、化学寿命长、耐磨防堵等优势,广泛应用于火电、钢铁、水泥、焦化、垃圾焚烧等行业,可有效减少氮氧化物排放,助力“美丽中国”建设。功能性新材料板块目前主要生产超高分子托辊、耐磨板、管材等产品,海螺超高分子托辊应用于水泥建材、港口物流、矿山开采、化工、电力钢厂等五大应用场景,与金属托辊相比具有使用寿命长、节能环保、运维成本低等显著特点,市场应用空间广阔。海螺新材是国家科技部认定的高新技术企业,拥有国家级技术研发中心、中国轻工业联合会重点实验室、CNAS认证实验室,建有博士后工作站和新材料研究院,拥有300余项国家专利。展望未来,海螺新材将秉持“为人类创造未来的生活空间”的经营理念,坚持创新引领、数字赋能、绿色转型,加强新兴产业技术研究和产业布局,积极培育和发展新质生产力,奋力实现企业更高质量发展。
