# 300737.SZ 深度透视

## 因果逻辑链
- **[地产客户信用恶化]** -> **巨额信用减值损失**: 部分地产客户经营恶化，导致以前年度应收账款回收困难，公司单项计提或提高坏账比例，合计计提信用减值损失6.03亿元，是当期巨亏的核心原因。
- **[主动收缩风险客户]** -> **营收下滑**: 基于应收风险管控，公司主动收缩部分地产客户的供应份额，叠加下游需求整体疲软，导致主营业务收入同比下降11.49%。
- **[“反内卷”调价与结构优化]** -> **毛利率提升**: 公司率先发布调价函，并持续优化客户与产品结构，向高毛利的中高端市场、零售及海外业务倾斜，使销售毛利率同比提升2.43个百分点至24.20%。
- **[零售与海外业务放量]** -> **结构性增长**: 民建零售业务（“科顺好工长”会员超118万人）和海外业务（马来西亚基地投产）实现快速增长，有效对冲了地产下行带来的压力，成为业绩增长新引擎。
- **[经营现金流持续为正]** -> **财务安全垫**: 尽管净利润巨亏，但公司加强回款考核，收现比达116.91%，经营活动现金流净额连续多年为正（3.20亿元），保障了公司基本运营和偿债能力。
- **[防水新规与行业出清]** -> **头部集中利好**: 防水新规强制落地，提升行业门槛，加速低质产能出清，市场份额向具备品牌、技术、渠道优势的头部企业（如科顺）集中，长期竞争格局优化。
- **[计提资产减值损失]** -> **利润总额双重打击**: 除信用减值外，公司对存货、合同资产、抵债房产等计提资产减值损失1.84亿元，与信用减值合计减少利润总额7.87亿元，是导致亏损的直接财务表现。

## 风险警告
**核心风险在于应收账款这颗“定时炸弹”。** 公司2025年巨亏5.35亿元，几乎完全由高达6.03亿元的信用减值损失和1.84亿元的资产减值损失造成。这并非经营层面的突然崩溃，而是过去地产行业泡沫破裂后，历史遗留问题的集中爆发。尽管公司已主动收缩风险客户，但存量应收款的回收仍高度依赖地产客户的经营状况，未来若部分大型房企再次出现信用危机，公司可能面临新一轮的大额减值，持续侵蚀净资产。

**第二重风险是行业需求的结构性萎缩。** 虽然公司通过零售、修缮、海外等业务进行对冲，但核心的工建防水业务仍与地产开工、基建投资高度相关。当前地产行业虽有政策托底，但真正企稳复苏仍需时日，基建投资增速也在放缓。若宏观经济复苏不及预期，公司主营业务收入“止跌回稳”的目标将面临挑战，而新业务的增长能否完全弥补传统业务的缺口，仍存在不确定性。此外，原材料（沥青等）价格波动是长期悬在盈利能力上的利剑。
