# 002596.SZ 深度透视

## 因果逻辑链
- **[海南自贸港封关运作]** -> [混凝土销量降幅收窄]: 封关后基建项目密集落地，对冲了房地产投资下滑对混凝土需求的冲击，使公司销量仅下降2.52%。
- **[市政环卫市场竞争加剧与国企入局]** -> [环卫业务收入锐减29.62%]: 资金实力和资源背景更强的国企、央企跨界竞争，导致公司新项目中标减少、存量合同续签率走低。
- **[下游客户资金紧张与地方财政压力]** -> [应收账款高企与减值风险]: 混凝土施工周期长、回款慢，叠加地方财政紧张导致环卫项目付款周期延长，期末应收账款余额高达24.7亿元。
- **[PPP项目融资与垫资需求]** -> [流动性风险与债务逾期]: 高额的债务性融资和持续的垫资需求，导致子公司PPP项目融资出现本金及利息逾期，资金链承压。
- **[原材料成本传导不畅]** -> [混凝土毛利率下降3.27个百分点]: 水泥等核心原材料采购成本与商品混凝土市场售价未能同步下调，成本压力无法有效转嫁，压缩了盈利空间。
- **[园林绿化业务萎缩与结算调整]** -> [其他业务收入为负]: 园林板块市场竞争力持续弱化，主要围绕存量项目结算，2025年因完工结算调整减少营收6298.88万元。
- **[大股东高比例质押与司法冻结]** -> [控制权稳定性风险]: 实际控制人及其一致行动人股份质押率极高，已出现多笔质押逾期、司法冻结及被拍卖的情况，威胁公司控制权稳定。

## 风险警告
公司面临的核心风险是**流动性危机与资产减值螺旋**。混凝土和环卫业务均存在严重的垫资和回款周期长问题，导致应收账款高达24.7亿元，占总资产近一半。同时，PPP项目的高额债务已出现逾期，公司资金链极度紧张。为缓解流动性，公司可能被迫低价处置资产或加大借款，进一步侵蚀本就微薄的利润，形成恶性循环。

第二大风险是**主业竞争力的持续下滑**。混凝土业务受制于成本传导不畅和房地产下行，毛利率持续走低；而环卫业务在国企、央企的挤压下，市场份额和收入均出现断崖式下滑。两大核心主业均面临“量价齐跌”的困境，公司缺乏清晰的第二增长曲线，未来盈利能力堪忧。此外，大股东高比例质押带来的控制权不稳，也为公司经营增添了巨大的不确定性。
