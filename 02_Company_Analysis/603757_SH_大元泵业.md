# 603757.SH 深度透视

## 因果逻辑链
- **[新兴业务快速放量]** -> [商用类产品营收增长20.26%]: 液冷泵、新能源车液冷泵、储能液冷泵等新兴业务客户拓展取得重要进展，成为营收增长新动能。
- **[原材料价格波动与成本刚性上升]** -> [毛利率下降3.77个百分点]: 核心原材料价格波动、新厂房投产后折旧增加、员工待遇提高及搬迁费用，共同推高营业成本，侵蚀利润空间。
- **[研发与销售费用持续加大]** -> [扣非净利润下滑38.52%]: 为巩固传统业务技术优势并加快新兴业务布局，公司逆势加大研发和销售投入，导致期间费用率上升。
- **[欧洲热泵市场复苏]** -> [节能型家用屏蔽泵外销企稳]: 欧洲市场库存积压缓解及热泵市场改善，带动以出口为主的节能型产品销售回升，支撑民用类业务收入稳定。
- **[国内化工项目投资收缩]** -> [工业类产品营收下滑19.32%]: 下游新增化工项目投资减少，导致配套用泵需求承压，但售后服务及配件收入成为重要补充。
- **[可转债完成转股与赎回]** -> [资本公积大幅增加，资产负债率下降]: 可转债持有人集中转股，导致公司总股本增加、资本公积跃升，同时负债减少，资产负债率从41.68%降至26.27%。
- **[液冷产业处于初始阶段]** -> [算力服务领域实现从0到1突破]: 公司37KW CDU核心主泵通过国内及北美G客户审验，为后续在北美算力链中放量奠定基础。

## 风险警告
**核心风险在于利润端的急剧恶化与新兴业务的高投入不确定性。** 2025年公司营收微增1.01%，但扣非净利润却暴跌38.52%，毛利率全面下滑。这并非一次性冲击，而是原材料涨价、产能扩张带来的折旧与搬迁费用、以及为抢占液冷等新赛道而持续加大的研发销售投入共同作用的结果。若新兴业务放量不及预期，或原材料成本持续高企，公司盈利能力将面临进一步压缩。

**另一重大风险是地缘政治与贸易冲突对海外业务的冲击。** 公司外销收入占比约32%，且欧洲是家用屏蔽泵的核心市场。2026年爆发的伊朗战争已对中东这一全球石油化工核心区域造成冲击，可能影响供应链稳定性与贸易成本。同时，全球贸易保护主义抬头，若主要出口目的地国政策发生不利变化，将直接威胁公司外销收入的稳定性。此外，公司正积极布局海外产能，但新设的泰国子公司尚在初期，短期难以对冲潜在风险。
