# 002557.SZ 深度透视

## 因果逻辑链
- **[葵花籽原料成本飙升]** -> [净利润暴跌62.51%]: 2024年9月内蒙葵花籽收获期连续阴雨导致霉变率提升，符合公司标准的原料产量减少，采购价格大幅上升，直接侵蚀毛利率。
- **[核心坚果原料价格上涨]** -> [坚果类毛利率下降7.55%]: 巴旦木受供需关系影响、腰果受行业周期及天气影响，采购价格均上涨，导致坚果品类盈利能力显著下滑。
- **[传统渠道客流持续下滑]** -> [经销渠道收入下降19.38%]: 大卖场、超市等传统渠道客流下滑，而公司在该渠道销售占比较大，导致整体销售业绩承压。
- **[渠道结构主动调整]** -> [直营渠道收入增长36.98%]: 公司加大对量贩零食连锁、会员店等新兴渠道的资源投入，直营模式收入大幅增长，但该渠道毛利率较低，拉低了整体盈利水平。
- **[春节错期影响]** -> [一季度收入承压]: 2025年春节时间较早，导致部分节前销售高峰落入2024年，对2025年一季度收入确认产生负面影响。
- **[新品研发与渠道费用投入加大]** -> [销售费用增长3.57%]: 为应对市场变化，公司主动加大新品研发和势能渠道的费用投入，进一步压缩了利润空间。
- **[借款利息及可转债利息摊销增加]** -> [财务费用暴增228.63%]: 公司有息负债增加及可转债利息摊销导致财务费用大幅上升，对净利润形成拖累。
- **[新采购季原料价格回落]** -> [成本压力有望缓解]: 2025年新采购季，公司优化采购模式、加大直采比例，葵花籽采购价格较前期有所下降，为未来盈利修复奠定基础。

## 风险警告
**核心风险在于原料成本波动与渠道变革的双重挤压。** 公司业绩高度依赖葵花籽和坚果等农产品的采购价格，气候异常或供需失衡导致的原料价格剧烈波动，是公司利润最核心的不可控变量。2025年净利润暴跌62.51%，根源即在于此。尽管新采购季成本有所回落，但原料价格的中长期走势仍存在巨大不确定性，公司盈利能力修复的持续性存疑。

**渠道结构转型的阵痛远未结束。** 传统商超渠道的衰落是结构性趋势，公司虽积极转向量贩零食、会员店等新渠道，但直营渠道毛利率显著低于经销渠道（19.91% vs 24.94%），且新渠道的竞争更为激烈。这种“以价换量”的转型模式，在原料成本高企的背景下，可能导致公司陷入“增收不增利”甚至“量价齐跌”的困境。同时，海外业务面临复杂的国际贸易环境和汇率波动风险，增长前景亦不明朗。
