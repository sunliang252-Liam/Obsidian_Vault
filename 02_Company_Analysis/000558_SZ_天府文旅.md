# 000558.SZ 深度透视

## 因果逻辑链
- **影视业务收入爆发式增长** -> 营收同比+29.68%: 影视业务收入同比+51.27%至3.28亿元，占总营收61.26%，成为核心增长引擎，但毛利率仅10.12%，利润贡献有限。
- **财务费用激增** -> 归母净利润持续亏损: 贷款增加导致财务费用同比+404.41%至2782万元，严重侵蚀利润，扣非净利润-2811万元，主业造血能力不足。
- **西岭雪山景区四季运营升级** -> 文旅业务稳健增长: 非雪季新增亲水、山地项目，夏季游客量同比+46.5%，推动文旅收入同比+3.95%，但增速远低于影视业务。
- **影旅融合全川网络搭建** -> 影视业务规模扩张: 与四川省21个市州签署战略协议，构建“拍在四川”服务体系，为影视制作服务规模化奠定基础。
- **存量资产租赁收入下滑** -> 传统业务收缩: 存量资产租赁收入同比-8.26%，整体出租率约80%，资产盘活与去化压力持续。
- **经营活动现金流大幅流出** -> 资金链承压: 影视项目制作费支出导致经营活动现金流净额-2.68亿元，同比恶化66.90%，依赖筹资活动（+3.65亿元）维持流动性。
- **间接控股股东担保获取贷款** -> 融资能力增强: 成都文旅集团提供全额担保，公司年内新增多笔银行贷款，总借款余额增至7.96亿元，支撑影视业务扩张。

## 风险警告
**核心风险在于“增收不增利”与现金流枯竭的双重困境。** 公司营收增长近30%至5.35亿元，但归母净利润仍亏损2078万元，扣非净利润亏损扩大至2811万元。影视业务收入占比超六成，但毛利率仅10.12%，且项目制作费导致经营活动现金流净流出2.68亿元，同比恶化66.90%。公司完全依赖筹资活动（净流入3.65亿元）维持现金平衡，长期借款增至7.96亿元，财务费用同比飙升404%，若影视项目回款不及预期，偿债压力将急剧放大。

**战略扩张与资产质量存在显著错配。** 公司全力推进“影旅融合”战略，与全川21个市州签约，并拟收购毕棚沟景区股权，但新设子公司光影天府首年亏损329万元，影视业务尚未形成稳定盈利模式。同时，存量资产（写字楼、商铺）出租率仅80%，体育业务毛利率为-42.17%，持续拖累整体盈利。公司核心资产西岭雪山景区虽具稀缺性，但文旅收入增速仅3.95%，增长乏力。在扣非净利润连续三年为负的背景下，任何战略失误都可能引发流动性危机。
