# 688505.SH 深度透视

## 因果逻辑链
- **[里葆多®未中选第十批国家集采]** -> [2025年净利润由盈转亏，亏损1.57亿元]: 核心产品被迫大幅降价并调整销售策略，导致利润贡献同比减少约1亿元，叠加研发费用增加，直接导致业绩巨亏。
- **[里葆多®降价后销量增长]** -> [抗肿瘤产品营业成本同比增加36.18%]: 为应对集采失标，公司采取“以价换量”策略，销量增长26.49%，但成本增速远超收入，毛利率下降5.2个百分点。
- **[加大学术推广力度]** -> [销售费用同比激增31.99%至3.95亿元]: 为维持里葆多®市场份额，公司大幅增加市场及学术推广费，销售费用率飙升至57.61%，严重侵蚀利润。
- **[研发投入持续增加]** -> [研发费用同比增长13.93%至3.58亿元，占营收52.19%]: 公司坚持推进ADC及光动力等创新管线临床研究，高研发投入在集采冲击下加剧了短期亏损。
- **[艾拉®与复美达®收入微降]** -> [皮肤科产品毛利率稳定在92.78%]: 作为光动力领域龙头产品，未受集采直接影响，收入仅小幅下降3.48%，构成公司利润的稳定基本盘。
- **[抗Trop2 ADC项目III期入组完成]** -> [未来2-3年有望成为新增长极]: 核心ADC管线（FDA018）进度领先，若成功上市，将打破公司对现有三大产品的依赖，重塑增长曲线。
- **[无实际控制人]** -> [公司治理决策效率存在不确定性]: 股权结构分散，第一大股东上海医药持股仅20.27%，缺乏单一控制方，可能影响重大战略决策的推进效率。

## 风险警告
**核心风险：单一产品集采失标引发的业绩断崖式下跌。** 公司过度依赖里葆多®（抗肿瘤产品），该产品在2024年首次被纳入国家集采后失标，导致2025年被迫大幅降价，利润贡献骤降约1亿元，直接使公司从盈利近4000万转为亏损1.57亿。这暴露了公司产品管线单一、抗政策风险能力极弱的致命缺陷。在集采常态化背景下，若未来艾拉®或复美达®也面临类似政策冲击，公司将承受毁灭性打击。

**次生风险：高研发投入与低盈利能力的持续错配。** 公司研发费用率高达52.19%，远超行业平均水平，但研发管线（尤其是ADC）尚处于临床中后期，短期内无法贡献收入。在里葆多®利润大幅缩水后，公司已无足够利润支撑如此高强度的研发。若后续融资环境收紧或核心管线研发失败，公司将面临现金流紧张与研发项目停滞的双重困境，陷入“不投入等死，投入找死”的恶性循环。
