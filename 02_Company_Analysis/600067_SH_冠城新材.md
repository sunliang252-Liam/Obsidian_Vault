# 600067.SH 深度透视

## 因果逻辑链
- **[土地一级开发项目集中结算]** -> **扭亏为盈**: 西北旺新村D1地块清算补偿（15.94亿）和太阳宫D区地块收储（17.06亿）贡献约35.6亿收入，是公司从亏损6.67亿转为盈利0.75亿的核心驱动力。
- **[电磁线“扁线+变频线+N”战略]** -> **产销创新高**: 聚焦新能源汽车扁线等高附加值产品，2025年扁线销量2.13万吨（+47.92%），带动电磁线总销量9.37万吨（+6.84%），实现量价齐升。
- **[铜价高位震荡]** -> **营收增长但成本承压**: 电磁线定价“基准铜价+加工费”，铜价上涨推高营收，但成本同步增加，电磁线毛利率仅微增0.22个百分点，盈利能力受挤压。
- **[房地产行业持续低迷]** -> **战略收缩与资产剥离**: 公司已无新增土储，在建项目仅剩3个，并计划将地产资产剥离至控股股东，聚焦电磁线主业。
- **[电解液添加剂行业产能过剩]** -> **“以量补价”守份额**: 行业价格战持续，公司销量增长40.17%但收入下降5.66%，通过扩大销量维持市场份额，等待行业景气度修复。
- **[计提资产减值损失大幅减少]** -> **利润修复**: 2024年计提5.09亿资产减值损失，2025年降至0.66亿，是净利润大幅改善的另一关键因素。
- **[经营活动现金流大幅改善]** -> **资金回笼强劲**: 经营现金流净额15.43亿（+99.49%），主要得益于房地产项目回款增加及电磁线销售回款增长，财务风险降低。

## 风险警告
公司盈利高度依赖非经常性的土地一级开发项目结算，可持续性存疑。2025年净利润0.75亿，但剔除土地清算补偿等非经常性损益后，扣非净利润仅为0.07亿，核心主业（电磁线+电解液添加剂）盈利能力依然薄弱。一旦土地开发项目红利消退，公司可能重回亏损。

房地产业务剥离进程存在不确定性。虽然公司计划将地产资产出售给控股股东，但交易仍在推进中，尚未完成。若剥离受阻，公司仍将承担房地产下行周期带来的存货减值风险和资金沉淀压力。同时，控股股东股权高比例质押（超50%）及司法冻结，也增加了公司治理层面的潜在风险。
