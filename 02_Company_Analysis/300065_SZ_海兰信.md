# 300065.SZ 深度透视

## 因果逻辑链
- **[海洋观探测业务爆发]** -> [营收增长86.57%]: 中标4.03亿三亚崖州湾海洋科学观测网项目，带动该板块收入同比暴增519.80%，成为业绩核心驱动力。
- **[智能航海业务稳健增长]** -> [利润结构优化]: 固态雷达批量出货、海外市场拓展，推动智能船舶板块毛利率提升7.55个百分点至45.52%，贡献核心利润。
- **[应收账款催收见效]** -> [经营性现金流改善]: 公司加强长账龄应收账款催收，经营性现金流净额达1.28亿元，同比增长36.74%，实现扭亏为盈。
- **[海底数据中心商业化突破]** -> [未来增长引擎确立]: 海南、上海双项目投运，PUE低至1.1，验证“海上风电+UDC”模式，为全国复制奠定基础。
- **[非经常性损益贡献利润]** -> [扣非净利润仍薄弱]: 归母净利润4028万元，但扣非净利润仅1169万元，投资收益及公允价值变动损益占利润总额67%，主业盈利能力待验证。
- **[研发资本化率下降]** -> [研发质量提升]: 研发投入资本化率从36.90%降至20.17%，表明更多研发费用被当期费用化，财务处理更审慎。

## 风险警告
**新业务转型与商业化风险**：海底数据中心（UDC）虽已实现海南、上海双项目落地，但海域环境复杂、多系统集成挑战大，且受海洋气象等不可抗力影响。当前UDC项目尚未达到预期效益，募投项目“海底数据中心一期”效益未达标，商业化规模化复制仍存不确定性。公司作为行业先行者，需持续投入大量资金进行技术迭代和市场开拓，若市场开拓滞后或客户需求转向，新增产能可能无法及时消化。

**应收账款与客户集中度风险**：尽管公司2025年加强应收账款催收效果显著，但未来经营规模扩大将导致应收账款余额进一步提高。更关键的是，公司前五大客户销售占比高达57.94%，其中第一大客户贡献42.01%营收，客户高度集中。若主要客户生产经营发生不利变化，或海洋观探测项目验收、回款节奏波动，将直接冲击公司现金流和利润稳定性。
