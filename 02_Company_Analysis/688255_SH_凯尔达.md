# 688255.SH 深度透视

## 因果逻辑链
- **[营收增长但利润下滑]** -> 净利润同比下降16.22%: 营收增长16.62%至6.5亿，但为应对市场竞争加大研发与销售投入，叠加综合毛利率下降及财务费用增加，导致增收不增利。
- **[工业机器人销量驱动营收]** -> 工业机器人收入同比增长19.77%: 销量达4,962台（+25.15%），其中自产机器人销量1,835台（+25%），成为营收增长的核心引擎。
- **[外购机器人整机依赖]** -> 关联采购占比高达59.08%: 公司63.02%的工业机器人使用外购整机，其中62.76%来自第二大股东安川电机，构成重大供应链依赖。
- **[伺服焊接技术壁垒]** -> 产品使用成本优势: 自主研发的伺服焊接设备及基于工业计算机的机器人控制器，显著降低客户硬件与保护气体成本，形成对国际品牌的性价比竞争优势。
- **[MEMS传感器战略布局]** -> 人形机器人产业作为战略方向: 通过子公司凯维力传感，聚焦MEMS六维力传感器研发，旨在切入具身智能与人形机器人供应链，但产品仍处研发阶段。
- **[经营活动现金流大幅改善]** -> 现金流净额同比暴增4,774%: 主要系本期购买商品、接受劳务支付的现金同比减少，显示公司在供应链付款节奏上进行了主动管理。
- **[股权激励费用侵蚀利润]** -> 扣除股份支付后净利润下降31.85%: 报告期确认股份支付费用约502万元，是导致归母净利润下滑的重要因素之一。

## 风险警告
**核心风险在于对单一供应商安川电机的深度依赖。** 公司外购机器人整机超六成来自安川，关联采购占货物采购总额近60%。一旦合作关系生变或安川提价，将直接冲击公司成本结构与供应链安全。尽管公司力推自产机器人，但推广进度存在不确定性，短期内难以摆脱依赖。

**增收不增利的困境短期难解。** 在工业机器人市场竞争加剧的背景下，公司为保份额被迫加大投入，导致毛利率承压。同时，公司战略布局的传感器业务尚处研发烧钱阶段，子公司凯维力传感报告期内亏损超600万，短期内无法贡献利润，反而持续消耗现金流。
