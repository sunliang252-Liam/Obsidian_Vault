# 603165.SH 深度透视

## 因果逻辑链
- **[废纸采购成本上升，原纸售价提振有限]** -> [毛利率下滑，净利润下降21.86%]: 上游废纸价格波动推高成本，下游包装纸市场因供需宽松难以提价，导致“原纸-废纸”价差收窄，直接压缩主营业务盈利空间。
- **[金融资产配置从银行存款转向基金信托]** -> [扣非净利润骤降48.39%]: 理财结构调整使利息收入从经常性损益转为公允价值变动收益（计入非经常性损益），导致扣非净利润口径失真，实际经营利润下滑约25.70%。
- **[废纸供应商由法人转为个人]** -> [经营活动现金流净额巨亏5.6亿元]: 付款方式由承兑汇票转为现汇，叠加上期应付票据到期兑付，导致经营性现金流出大幅增加，现金流表现严重恶化。
- **[原材料成本压力与下游需求疲软]** -> [纸板及纸箱子公司亏损]: 嘉兴荣晟包装、安徽荣晟包装等子公司均出现亏损，反映产业链下游环节在成本传导不畅的环境下盈利能力脆弱。
- **[可转债募投项目延期]** -> [产能释放节奏低于预期]: 年产5亿平方绿色智能包装产业园项目（一期）及零土地技改项目延期至2026年底，短期无法贡献增量业绩。
- **[高比例现金分红与股份回购]** -> [净资产减少7.39%]: 2025年合计分红及回购金额约6.98亿元，远超当年净利润，虽回报股东但消耗了大量账面现金与净资产。
- **[控股股东冯荣华被采取强制措施]** -> [公司治理稳定性受考验]: 创始人因个人原因被公安机关调查，虽已离职，但事件本身对市场信心和公司长期治理结构构成潜在风险。

## 风险警告
**核心风险在于主业盈利能力的持续恶化与现金流危机。** 公司净利润下滑的核心并非一次性因素，而是“废纸成本上升+原纸价格承压”这一结构性矛盾。在行业供给宽松、需求温和复苏的背景下，这一价差收窄趋势短期难以逆转。更危险的是，经营活动现金流净额从正1.11亿元骤降至负5.6亿元，即便还原票据贴现影响后仍下降11.32%，表明公司造血能力已实质性削弱，对短期借款和理财收益的依赖度急剧上升。

**治理风险与财务激进策略形成共振。** 创始人冯荣华被采取强制措施，虽已离职，但暴露出家族式企业的治理短板。与此同时，公司2025年分红及回购总额高达净利润的3倍以上，几乎耗尽账面现金，导致货币资金从16亿元骤降至0.32亿元，而交易性金融资产却膨胀至28亿元。这种“借钱分红、理财套利”的财务操作，在主营业务承压的背景下，本质上是将股东回报建立在金融市场的波动之上，一旦理财收益不及预期或融资环境收紧，公司将面临严重的流动性风险。
