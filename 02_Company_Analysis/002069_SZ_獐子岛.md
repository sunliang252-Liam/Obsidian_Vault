# 002069.SZ 深度透视

## 因果逻辑链
- **[水产贸易业务大幅收缩]** -> [营收下降19.25%]: 子公司香港公司停止贸易业务，导致水产贸易收入骤降45.54%，拖累整体营收。
- **[非经常性资产处置收益]** -> [净利润减亏50.91%]: 通过向国资股东转让海域使用权、子公司股权等，获得非经常性收益5,735万元，掩盖了主营业务亏损。
- **[国资股东持续输血与资产承接]** -> [资产结构优化]: 控股股东累计承接超2亿元资产与债权，协助公司剥离低效资产、回笼资金，缓解流动性压力。
- **[海参产品量价齐升]** -> [养殖业务毛利率改善]: 海参收入增长10.11%，但成本上升23.56%，导致毛利率下降6.5个百分点，显示成本压力。
- **[财务费用高企]** -> [侵蚀利润]: 尽管短期借款置换为长期借款，但财务费用仍高达5,800万元，是扣非后亏损的主要来源之一。
- **[存货规模居高不下]** -> [资金占用与减值风险]: 存货占总资产33.01%，且计提了存货跌价准备，反映养殖周期长、资金周转慢的行业特性。
- **[新《渔业法》修订]** -> [行业准入门槛提升]: 2025年修订的《渔业法》将于2026年实施，对养殖方式、成本结构产生深远影响，利好拥有确权海域的龙头企业。

## 风险警告
公司核心风险在于**持续经营能力高度依赖非经常性损益与国资输血**。扣非净利润已连续两年大额亏损（-6,210万元），主营业务造血能力严重不足。净资产仅剩3,717万元，资产负债率畸高，财务费用对利润形成持续侵蚀。一旦资产处置节奏放缓或国资支持力度减弱，公司将面临巨大的流动性危机。

另一个重大风险是**海洋牧场养殖的固有不确定性**。公司底播增殖模式受海洋环境、气候变化（如冷水团、厄尔尼诺）影响极大，历史上曾多次发生“扇贝跑路”等重大风险事件。尽管公司声称已加强监测，但该模式本质上仍属“看天吃饭”，业绩波动风险极高，投资者难以对养殖存货进行有效估值。
