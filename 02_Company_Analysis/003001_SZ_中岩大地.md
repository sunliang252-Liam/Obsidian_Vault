# 003001.SZ 深度透视

## 因果逻辑链
- **部分项目前期工作周期拉长，业务转化产值进度放缓** -> 营业收入同比下降21.82%: 项目推进延迟导致收入确认减少
- **在建项目实施要求提升、建设周期延长** -> 成本上升，毛利率下降: 现场管理、人工及机械投入增加推高成本
- **基于谨慎性原则计提资产减值准备** -> 净利润同比下降77.84%: 资产减值损失直接减少利润
- **强化应收账款催收、加快项目回款，优化付款结算方式、压缩现金支出** -> 经营活动现金流量净额同比增长41.70%: 回款改善与支出控制提升现金净流入
- **新签订单合同金额10.62亿元，在手订单同比增加28.87%** -> 未来收入有望恢复增长: 订单储备为未来收入提供基础
- **聚焦核电、水利水电、港口等国家战略领域，签署战略合作协议，获得中核集团合格供应商资质** -> 核心材料在核电领域首个集约化采购合同落地: 战略布局与资质认证促进业务突破
- **研发投入同比增长12.79%，新增专利12项（其中发明专利10项），主编参编多部标准** -> 巩固技术领先优势，支撑未来项目获取: 技术创新提升竞争力与行业地位
- **产品销售营业收入同比减少64.08%，环境修复营业收入同比减少71.85%** -> 整体营收下降: 非岩土工程业务大幅萎缩拖累总收入

## 风险警告
深度风险总结：公司当前面临营收与利润双降压力，主要因项目前期周期拉长、实施要求提升导致收入确认放缓及成本上升，同时计提减值准备进一步侵蚀利润。非岩土工程业务（产品销售、环境修复）大幅下滑，显示业务结构单一化风险。此外，投资活动现金净流出大幅增加（购买理财及金融资产），需关注资金配置效率与流动性风险。尽管经营活动现金流改善，但净利润与现金流持续背离，盈利质量存疑。客户集中度较高（前五大客户占比74.15%），存在依赖风险。
