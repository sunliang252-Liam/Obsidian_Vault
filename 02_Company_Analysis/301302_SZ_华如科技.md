# 301302.SZ 深度透视

## 因果逻辑链
- **[军队采购网禁令]** -> [新签订单下降]: 公司被禁止参加全军物资工程服务采购活动，导致2025年新签订单金额降至3.66亿元，较2024年略有下降。
- **[“十四五”末期项目集中交付]** -> [营收增长]: 尽管新签订单减少，但“十四五”末期部分项目交付周期集中，完成验收项目增加，推动2025年营业收入同比增长21.38%。
- **[降本增效措施]** -> [费用控制与减亏]: 公司优化组织架构和人员配置，销售、管理、研发费用均同比下降，推动归属于上市公司股东的净利润同比减亏33.39%。
- **[战略转型至军事智能]** -> [业务结构重塑]: 公司从军事仿真升级为以XSim®军事智能体系为核心的“一核引领、全栈支撑”战略，业务划分为智能决策、虚拟训练等五大领域。
- **[游戏及文旅业务拓展]** -> [新收入来源]: 培育“小如文化”子品牌，游戏及文旅业务贡献营收4768.57万元，占营收比重15.76%，成为对冲军工周期的重要补充。
- **[研发投入高企]** -> [持续亏损]: 研发费用占营收比例高达60.53%，虽同比下降，但高额投入叠加订单受限，导致公司连续三年扣非净利润为负。
- **[应收账款回款困难]** -> [现金流恶化]: 经营活动现金流净额为-1.77亿元，同比减少87.81%，主要系项目回款金额减少，应收账款余额较大且回款比例低。
- **[客户集中度高]** -> [经营依赖风险]: 前五名客户销售额占年度销售总额55.67%，其中第一大客户占比25.64%，对单一客户依赖度较高。

## 风险警告
公司面临的核心风险是**军队采购网禁令**。自2023年11月至2026年11月，公司被禁止参加全军物资工程服务采购活动，这直接限制了其获取订单的核心渠道。尽管公司可通过其他渠道获取订单，但新签订单已出现下滑，且后续处罚（2025年7月、2026年3月）表明合规风险并未完全解除。若禁令持续或扩大，公司营收增长将不可持续，甚至面临进一步萎缩的风险。

财务层面，公司已连续三年亏损，且**现金流持续恶化**。2025年经营活动现金流净额为-1.77亿元，应收账款余额高达4.33亿元，回款困难导致资金链承压。同时，研发费用占营收比例超过60%，高投入与低回报的矛盾突出。若无法有效改善回款或控制成本，公司可能面临流动性危机，持续经营能力存在不确定性。
