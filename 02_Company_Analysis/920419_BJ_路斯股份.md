# 920419.BJ 深度透视

## 因果逻辑链
- **[柬埔寨子公司投产放量]** -> [营收增长但利润承压]: 柬埔寨路恒2024年10月投产后，2025年产能利用率提升，贡献了肉干和罐头产品的境外收入增量，但其毛利率偏低且处于亏损状态，拖累整体净利润同比下降22.85%。
- **[人民币汇率升值]** -> [出口毛利率下降]: 报告期内人民币兑美元汇率升值，直接压缩了以美元结算的境外销售收入，导致外销毛利率同比下降3.16个百分点。
- **[肉粉产品价格低迷]** -> [整体毛利率承压]: 受市场供需影响，肉粉产品销售价格偏低，导致其毛利率同比下降4.57个百分点，进一步拉低了公司整体毛利率。
- **[双品牌战略落地]** -> [内销主粮增长]: 公司推出高性价比“妙冠”品牌，与“路斯”品牌形成双轮驱动，主粮产品境内线上渠道收入增长显著，带动内销收入同比增长6.67%。
- **[境外大客户订单增长]** -> [罐头产品爆发]: 来自俄罗斯、美国等市场的订单明显增长，推动罐头产品境外收入同比大增91.25%，成为营收增长的重要引擎。
- **[柬埔寨子公司运营亏损]** -> [少数股东损益大幅转负]: 柬埔寨路恒本期经营亏损，导致归属于少数股东的损益从上年盈利17.86万元转为亏损368.47万元，对合并净利润形成拖累。
- **[存货与应收账款激增]** -> [经营活动现金流恶化]: 柬埔寨子公司投产备货及应收货款增加，导致存货同比增长34.79%，应收账款同比增长42.62%，经营活动现金流净额同比大幅下降66.52%。

## 风险警告
**核心风险在于“增收不增利”的困境加剧。** 公司营收增长10.46%，但归母净利润却下滑22.85%，主因是低毛利的柬埔寨产能放量稀释了整体盈利能力，同时人民币升值和肉粉价格低迷进一步压缩利润空间。若柬埔寨工厂无法在短期内实现扭亏，或汇率持续不利，公司利润端将持续承压。

**海外经营与客户集中风险不容忽视。** 境外收入占比超63%，且前五大客户销售占比达30.74%，对俄罗斯、美国等大客户依赖度高。柬埔寨工厂面临地缘政治、法律差异及经营经验不足等挑战，一旦主要客户流失或海外市场出现贸易摩擦，将对公司营收造成重大冲击。
