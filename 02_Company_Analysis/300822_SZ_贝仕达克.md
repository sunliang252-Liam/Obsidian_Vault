# 300822.SZ 深度透视

## 因果逻辑链
- **[资产减值计提增加]** -> [净利润暴跌77.97%]: 对经济效益低于预期的无形资产、应收账款、存货等计提大额减值准备，直接侵蚀当期利润。
- **[期间费用率上升]** -> [盈利水平承压]: 研发投入增加、汇兑收益减少（财务费用上升）、在建工程转固后折旧增加，三项费用叠加压缩利润空间。
- **[综合毛利率下降]** -> [盈利基础弱化]: 高毛利的智能控制器业务收入占比下降（-13.8%），而低毛利的智能产品业务占比提升（+47.74%），业务结构变化拖累整体毛利率。
- **[智能产品业务高增长]** -> [收入结构转型]: 智能产品收入同比增长47.74%，占比从16.50%提升至24.75%，成为公司第二增长曲线，但盈利能力尚待规模效应释放。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售占比83.05%，其中第一大客户创科实业占比53.18%，单一客户依赖度极高，合作关系变动将直接冲击业绩。
- **[苏州柯姆破产清算]** -> [剥离低效资产]: 长期亏损的控股子公司进入破产程序，公司主动化解历史经营包袱，但对应收账款及其他应收款（约3995万元）存在全额损失风险。
- **[研发投入持续增长]** -> [技术创新储备]: 研发费用同比增长14.68%，聚焦AI视觉、智能割草机器人、动物行为监测等前沿领域，为长期竞争力蓄力。

## 风险警告
**核心风险在于业绩“失速”与客户“绑架”的双重困境。** 2025年净利润暴跌78%，根源并非一次性冲击，而是结构性恶化：高毛利的智能控制器业务萎缩，低毛利的智能产品业务虽增长但无法弥补利润缺口。更危险的是，公司83%的收入依赖前五大客户，其中创科实业一家占比超53%，这种“单腿走路”的客户结构意味着任何订单波动都将直接引发业绩剧烈震荡。苏州柯姆破产清算导致的近4000万元应收款损失，只是冰山一角。

**战略转型的“青黄不接”是另一大隐忧。** 公司正从智能控制器向智能产品（照明、汽配、宠养）转型，新业务收入增长47.74%看似亮眼，但毛利率仅16.99%，远低于智能控制器的29.83%，且成本增速（51.14%）超过收入增速（47.74%），说明新业务仍处于“烧钱换规模”阶段。同时，两大核心募投项目（新一代智能控制器产业基地、研发中心）因市场变化和战略调整被终止，剩余募集资金将永久补充流动资金，这暴露了公司对行业趋势的判断失误和战略定力的缺失。在旧业务下滑、新业务未盈利、核心项目烂尾的背景下，公司短期盈利能力修复前景黯淡。
