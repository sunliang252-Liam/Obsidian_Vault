# 000151.SZ 深度透视

## 因果逻辑链
- **[土地收储收益]** -> [净利润扭亏为盈]: 公司通过处置天津北辰区土地，确认资产处置收益4.04亿元，直接驱动归母净利润从-3.06亿元跃升至3.60亿元，实现报表层面扭亏。
- **[核心业务收入结构变化]** -> [营收下滑但毛利率提升]: 高毛利的成套设备出口业务收入增长33.48%，而低毛利的环保科技业务收入骤降52.53%，导致总营收下降7.9%，但综合毛利率从-4.99%提升至15.33%。
- **[海外工程承包业务扩张]** -> [成套设备出口收入增长]: 巴巴多斯道路修复、科特迪瓦旱港、阿塞拜疆光伏等项目稳步推进，带动该板块收入同比增长33.48%至7.82亿元。
- **[子公司破产出表]** -> [环境科技业务收缩]: 亚德比利时、马来西亚亚德环境公司因资不抵债进入破产清算，不再纳入合并范围，导致环境科技收入同比腰斩。
- **[资产减值与信用减值]** -> [扣非净利润持续亏损]: 报告期内计提资产减值及信用减值损失合计7451万元，导致扣非净利润仍为-5744万元，主业造血能力尚未恢复。
- **[关联方财务公司借款]** -> [财务费用激增]: 向通用技术集团财务公司借款导致利息支出增加，财务费用同比上升194.47%至2123万元。
- **[发行股份购买中技江苏]** -> [布局用户侧储能新赛道]: 2026年3月完成资产交割，新增工商业用户侧储能投建营业务，旨在优化收入结构并提升长期抗风险能力。

## 风险警告
**盈利质量极差，扭亏完全依赖非经常性损益。** 公司2025年归母净利润3.60亿元，但扣非净利润为-5744万元，连续三年为负。核心利润来源是4.04亿元的土地收储收益，该收益不具有可持续性。剔除该笔收益后，公司主业（成套设备出口、环境科技、复合材料）均处于亏损或微利状态，经营活动现金流净额为-2.49亿元，显示主业造血能力严重不足。

**海外业务与子公司经营风险高企。** 公司业务高度集中于海外（收入占比83.61%），面临地缘政治、汇率波动、项目所在国政策变动等多重风险。同时，子公司亚德比利时已申请破产，马来西亚子公司亦进入破产清算，反映出公司在跨国并购后的整合与管理能力存在重大缺陷，环境科技板块的持续经营能力存疑。
