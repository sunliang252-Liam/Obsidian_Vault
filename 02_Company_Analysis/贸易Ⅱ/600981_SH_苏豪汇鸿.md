# 600981.SH 深度透视

## 因果逻辑链
- **[金融资产公允价值变动]** -> [归母净利润虚高]: 2025年归母净利润仅1583万元，但非经常性损益高达4.83亿元，核心利润（扣非净利润）实际巨亏-4.67亿元，金融资产炒作掩盖了主营业务的严重亏损。
- **[大宗业务收入增长但毛利率极低]** -> [增收不增利]: 大宗业务收入同比增24%，但毛利率仅1.44%，且同比下降，表明公司以低毛利、高资金占用的方式换取规模，对利润贡献微乎其微。
- **[计提巨额资产减值损失]** -> [核心利润大幅恶化]: 2025年计提资产减值损失同比暴增28.88亿元（原文为28,881.07万元，疑为笔误，应为2.89亿元），是扣非净利润巨亏的直接原因，显示公司资产质量存在严重问题。
- **[纺织服装出口业务萎缩]** -> [传统优势板块承压]: 纺织服装收入同比骤降31.65%，毛利率下降1.41个百分点，受全球贸易摩擦和需求疲软冲击，传统业务转型乏力。
- **[金融投资业务贡献主要利润]** -> [盈利模式高度依赖资本市场]: 金融资产公允价值变动及处置收益高达6.27亿元，是公司账面盈利的唯一支柱，但该收益极不稳定，存在巨大波动风险。
- **[经营活动现金流改善]** -> [短期流动性压力缓解]: 经营活动现金流净额同比上升47.91%，主要系加强回款，但筹资活动现金流净额由负转正，显示公司仍需大量外部融资维持运营。
- **[同业竞争解决方案推进]** -> [资产结构优化预期]: 控股股东承诺通过资产置换解决同业竞争，公司正置入紫金财险等股权，旨在聚焦大宗商品主业，但进程缓慢，存在不确定性。

## 风险警告
**核心风险在于主营业务已丧失造血能力，盈利完全依赖金融资产炒作。** 公司扣非净利润连续多年为负，2025年更是巨亏-4.67亿元，而同期金融资产公允价值变动收益高达6.27亿元，这种“金融输血”模式极度脆弱。一旦资本市场下行或公司持有的弘业期货、中泰证券等股票价格大幅波动，公司将立即陷入深度亏损，且巨额资产减值损失表明其供应链运营资产质量堪忧。

**另一重大风险是极高的财务杠杆与资金占用。** 公司短期借款高达91亿元，同比激增34.5%，占总资产32.43%，而供应链运营业务（尤其大宗业务）毛利率极低（约1-2%），微薄的毛利根本无法覆盖高昂的利息支出和运营成本。公司实质上是在用高杠杆、低毛利的贸易规模来维持现金流，一旦融资环境收紧或大宗商品价格剧烈波动，将面临严重的流动性危机和信用风险。
