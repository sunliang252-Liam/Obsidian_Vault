# 002091.SZ 深度透视

## 因果逻辑链
- **全球化供应链布局（海外工厂）** -> **贸易业务韧性增强**: 在贸易摩擦和关税不确定性背景下，公司在缅甸、越南、柬埔寨等“一带一路”国家的生产基地，有效对冲了单一市场风险，保障了出口规模同比增长5.1%。
- **“贸、工、技”一体化服务模式** -> **客户粘性与毛利率提升**: 公司从单纯贸易商转型为提供设计、采购、生产全流程服务的供应链组织商，深度绑定客户，使得纺织服装出口贸易毛利率同比提升1.29个百分点至17.23%。
- **化工新能源行业产能过剩** -> **扣非净利润下滑**: 锂离子电池电解液及添加剂行业供大于求，竞争激烈，导致化工业务收入下降2.42%，毛利率下滑2.04个百分点，拖累公司扣非净利润同比下降2.70%。
- **非流动资产处置收益** -> **归母净利润大幅增长**: 报告期内处置股权等资产产生4.47亿元非经常性损益，是归母净利润同比增长17.02%的主要驱动，掩盖了主营业务的盈利压力。
- **汇率波动与利息收入下降** -> **财务费用激增**: 受人民币汇率波动及利息收入减少影响，财务费用从-1.74亿元大幅增至2.66亿元，同比变动252.55%，对利润形成显著侵蚀。
- **核心客户深度绑定** -> **化工业务收入基本盘稳定**: 瑞泰新材与宁德时代、LG新能源等头部电池厂建立长期战略合作，尽管行业价格战激烈，但凭借客户粘性，化工业务收入仅小幅下降2.42%，未出现崩塌式下滑。
- **海外生产基地精细化管理** -> **成本控制与效率提升**: 公司对海外各生产基地实施精细化管理，加强成本控制，使得贸易业务营业成本同比下降0.39%，在收入增长的同时实现了成本优化。

## 风险警告
**核心风险在于化工新能源业务的“增收不增利”与产能过剩困境。** 报告期内，化工业务收入下滑2.42%，毛利率下降2.04个百分点，且产能利用率仅为10.04%，显示行业严重供过于求。瑞泰新材虽与头部客户绑定，但价格战压力持续，在建工程转固后折旧增加，若下游需求增速放缓，将面临巨大的资产减值风险。公司扣非净利润已连续两年下滑，主业盈利能力堪忧。

**另一重大风险是外部贸易环境的剧烈波动。** 公司84.31%的收入来自海外，且主要市场美国、欧盟的关税政策不确定性极高。虽然公司通过全球化布局分散风险，但若主要市场实施极端关税或地缘政治冲突升级，将直接冲击订单和利润。同时，汇率波动已导致财务费用激增，未来若人民币汇率剧烈波动，将对公司业绩造成不可预测的冲击。
