# 600287.SH 深度透视

## 因果逻辑链
- **[证监会行政处罚导致业务资质受损]** -> [营收下降23.88%]: 援外和核电钢材业务资质受损，直接削弱订单承接能力，非服装类业务大幅下滑。
- **[持有华安证券等金融资产公允价值变动收益减少]** -> [归母净利润下降48.69%]: 交易性金融资产出清，公允价值变动收益同比减少约2900万元，导致利润总额与归母净利润大幅缩水。
- **[欧盟反倾销政策与消费需求变动]** -> [木制品出口收入暴跌44.05%]: 外部贸易政策冲击叠加市场需求疲软，木制品业务成为营收下滑的主要拖累项之一。
- **[海外产能与营销网络布局加速]** -> [国际化战略深化]: 设立孟加拉代表处、开工埃及工厂、成立纽约办事处，构建“研发在中国、生产在亚非、市场在全球”的跨国经营格局。
- **[数字化转型与AI技术赋能]** -> [研发创新能力提升]: 苏豪智尚云平台、智慧版房二期、AI 3D服装设计等成果落地，推动传统服装业务向价值链高端迈进。
- **[控股股东承诺解决同业竞争]** -> [重大资产重组启动]: 拟与控股股东进行资产置换，置入服装相关资产，置出化工仓储及期货股权，聚焦主业。
- **[投资者诉讼预计赔偿增加]** -> [营业外支出增长130.69%]: 历史遗留的通讯器材风险事项持续发酵，计提的投资者诉讼赔偿增加，侵蚀当期利润。

## 风险警告
**核心风险在于主营业务增长乏力与外部冲击的叠加。** 公司营收连续两年下滑，2025年降幅扩大至23.88%，主要因证监会处罚导致核电钢材、援外等招标类业务资质受限，以及欧盟反倾销政策对木制品出口的打击。扣非净利润虽基本持平，但主营业务缺乏内生增长动力，新培育的海外产能和数字化平台尚未形成有效支撑，新旧动能转换存在明显空窗期。

**财务风险集中于金融资产波动与历史遗留问题。** 公司利润对持有的华安证券、南京聚隆等金融资产公允价值变动高度敏感，2025年归母净利润腰斩即源于此，盈利稳定性差。同时，母公司未分配利润仍为-2.74亿元，无法分红，且因通讯器材风险事项引发的投资者诉讼仍在持续，预计负债大幅增加，未来仍可能产生非经常性损失，拖累公司财务表现。
