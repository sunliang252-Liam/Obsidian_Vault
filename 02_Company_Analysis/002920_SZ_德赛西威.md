# 002920.SZ 深度透视

## 因果逻辑链
- **[汽车智能化渗透率提升]** -> [营收与利润双增]: 智能座舱与智能驾驶产品渗透率提升，带动单车价值量增长，推动营收同比增长17.88%，归母净利润同比增长22.38%。
- **[全栈技术能力与客户拓展]** -> [新项目订单高增]: 公司具备从域控、传感器到算法的全栈交付能力，成功突破VW、TOYOTA、HONDA等国际客户，新项目订单年化销售额突破350亿元。
- **[AI技术赋能研发与产品]** -> [研发效率与产品竞争力提升]: 自建算力中心，AI工具覆盖研发全流程，开发效率提升20%-30%，并推出第五代智能座舱平台与舱驾融合方案，巩固技术壁垒。
- **[全球化产能与生态布局]** -> [海外业务高速增长]: 西班牙、墨西哥工厂建设推进，海外营收同比增长41.12%，并突破RENAULT等白点客户，实现从“全球布局”向“价值共生”跨越。
- **[高研发投入与人才储备]** -> [技术领先地位持续巩固]: 研发投入26.37亿元（占营收8.10%），硕博人才同比提升38%，累计专利超4100项，主导/参与超120项技术标准。
- **[新业务拓展（无人车/机器人）]** -> [开辟第二增长曲线]: 发布“川行致远”低速无人车与机器人智能基座AI Cube，复用汽车智能化技术，切入无人物流与具身智能新赛道。

## 风险警告
**1. 客户集中度与行业竞争加剧风险。** 公司前五大客户销售额占比高达55.53%，对核心车企客户依赖度较高。随着汽车智能化进入“规模竞赛”阶段，华为、地平线等科技巨头及传统Tier1厂商竞争白热化，公司面临产品降价与市场份额被侵蚀的双重压力。

**2. 全球化运营与供应链管理风险。** 海外业务快速扩张（营收增41.12%）伴随西班牙、墨西哥等新工厂投产，面临地缘政治、汇率波动（财务费用因汇兑损失减少但衍生品公允价值变动损失仍存）、跨文化管理及供应链稳定性挑战。同时，存货激增69.59%（备货增加），若下游需求不及预期，将带来较大资产减值风险。
