# 601958.SH 深度透视

## 因果逻辑链
- **[钼价高位震荡]** -> [营收利润双增]: 2025年钼精矿均价同比上涨6.9%，公司精准把握高价窗口“应销尽销、高价多销”，推动归母净利润创上市以来新高。
- **[资源禀赋与全产业链]** -> [成本优势与供应稳定]: 掌控227万吨钼金属量资源，拥有采矿至深加工全链条，自有矿山成本仅2.8亿元，构筑了抵御价格波动的核心护城河。
- **[国内需求强于外供]** -> [内销占比提升]: 新能源、特钢等新兴领域拉动内需，公司国内市场份额提升至28%，对冲了国际贸易风险，成为业绩增长的主引擎。
- **[出口管制政策]** -> [产业链安全溢价]: 2025年2月起钼相关物项实施出口管制，强化了国内钼资源战略地位，公司作为龙头受益于供给端约束带来的价格支撑。
- **[高端产品突破]** -> [盈利结构优化]: 钼合金顶头、精密零部件等战新产品实现“零的突破”，钼金属板块毛利率逆势提升2.84个百分点，推动产品向价值链高端攀升。
- **[资源扩张战略]** -> [长期增长潜力]: 成功收购金沙钼业24%股权，将世界最大单体钼矿权益提升至34%，为未来产量增长和资源储备奠定基础。
- **[研发投入加码]** -> [技术壁垒强化]: 研发投入强度达3.05%，超细钼粉技术达国际领先水平，两项国家科技重大专项获中央财政支持，巩固了行业技术引领地位。

## 风险警告
**核心风险在于钼价周期性波动与经营现金流严重背离。** 公司业绩高度依赖钼产品价格，2025年虽受益于高位震荡，但经营活动现金流净额同比骤降56.21%至16.28亿元，主因是购买原料增加及票据贴现减少。这种“利润增、现金降”的背离，揭示了公司在价格高位时被动增加营运资金占用的脆弱性。一旦钼价进入下行周期，高库存和应收账款将迅速侵蚀利润，现金流可能进一步恶化。

**地缘政治与贸易保护主义是悬在头顶的达摩克利斯之剑。** 公司作为全球钼市场份额约13%的国际化企业，深度嵌入全球供应链。国际地缘政治纷争、贸易争端以及人民币汇率波动，均可能直接冲击出口业务（2025年国外收入占比约10%）。虽然出口管制政策短期利好国内价格，但长期可能引发海外客户转向替代供应商，削弱公司全球竞争力。此外，主要矿山位于秦岭腹地，环保政策持续收紧，任何偶发安全环保事件都可能导致生产停顿，带来不可预见的损失。
