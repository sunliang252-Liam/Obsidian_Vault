# 001215.SZ 深度透视

## 因果逻辑链
- **[餐饮行业“增收不增利”压力传导]** -> [归母净利润同比下滑24.04%]: 餐饮企业普遍降价引流，向供应链端压低采购价格，侵蚀公司盈利空间。
- **[经销渠道承压，直营渠道增长]** -> [营收结构分化]: 经销模式收入同比下滑6.19%，而直营模式收入同比增长11.08%，显示传统中小餐饮客户需求疲软，但头部连锁客户合作深化。
- **[烘焙甜品类与冷冻调理菜肴类高增长]** -> [产品结构优化]: 烘焙甜品类收入同比增长15.64%，冷冻调理菜肴类收入同比增长18.09%，成为对冲主食类（-2.82%）和小食类（-7.38%）下滑的核心增量。
- **[KA商超与会员店自有品牌定制化需求爆发]** -> [新渠道增量]: 山姆、盒马等会员商超加速自有品牌布局，公司凭借定制化研发与柔性生产能力，切入高毛利代工赛道，客户四（+279.40%）和客户五（+93.55%）销售额激增。
- **[线上渠道高增长]** -> [C端业务突破]: 线上销售主营收入同比增长76.29%，抖音、京东等平台成为家庭便捷消费场景的新增长极。
- **[产能扩张与折旧增加]** -> [利润侵蚀]: 鹤壁百顺源等新基地部分投产，固定资产同比增加6.73%，折旧费用8,525.87万元，叠加产能利用率不足，拖累短期利润。
- **[委托加工转自主生产]** -> [成本结构变化]: 委托加工产量同比减少40.82%，外采成本同比增加30.52%，运输费用同比增加38.34%，显示生产模式调整与渠道下沉带来的物流成本上升。

## 风险警告
**核心风险在于“增收不增利”的困境加剧。** 公司营收仅微增1.64%，但归母净利润却暴跌24.04%，ROE从4.80%骤降至3.39%。餐饮行业K型分化下，下游客户持续压价，而公司为抢占新渠道（如会员店、电商）投入大量市场推广费（同比+59.75%），叠加新产能投产带来的折旧与运输费用刚性增长，导致利润被严重侵蚀。若餐饮行业复苏不及预期，公司可能陷入“以价换量”的恶性循环，盈利能力持续承压。

**第二大风险是传统经销渠道的萎缩与竞争格局恶化。** 经销模式收入同比下滑6.19%，经销商数量净减少，显示中小餐饮客户生存艰难。同时，三全、安井等C端巨头加速布局B端市场，行业竞争从价格战升级为综合实力战。公司若不能有效提升经销商赋能与渠道下沉效率，核心基本盘可能进一步松动。此外，新乡千味三期、味宝食品等募投项目效益远不及预期（分别仅达预期效益的34.35%和41.59%），巨额资本开支的回报率存在重大不确定性。
