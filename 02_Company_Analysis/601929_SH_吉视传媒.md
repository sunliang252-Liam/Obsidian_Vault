# 601929.SH 深度透视

## 因果逻辑链
- **[集客业务成本激增]** -> [毛利率大幅下滑]: 信息服务（集客业务）成本同比增长48.36%，远超收入增速，导致整体毛利率从18.01%骤降至11.13%。
- **[非经常性损益依赖]** -> [扣非净利润巨亏]: 2025年扣非净利润-6.28亿元，亏损同比扩大21%，公司盈利高度依赖资产处置等非经常性收益。
- **[高额折旧与摊销]** -> [持续侵蚀利润]: 固定资产折旧及机顶盒摊销合计超7.7亿元，占营业成本比重超43%，构成刚性成本压力。
- **[债务规模高企]** -> [财务费用沉重]: 短期借款同比近乎翻倍，有息负债总额超50亿元，年财务费用1.79亿元，严重拖累利润。
- **[传统业务用户流失]** -> [收入增长停滞]: 面对IPTV和移动视频竞争，传统有线电视及宽带业务增长乏力，营收同比仅微增0.06%。
- **[处置金融资产]** -> [缓解账面亏损]: 处置农商行股权等金融资产，贡献约1.4亿元非流动资产处置损益，是避免亏损扩大的关键。
- **[经营性现金流改善]** -> [但造血能力存疑]: 经营活动现金流净额同比增长37%至4.32亿元，主要系销售回款增加，但扣非净利润持续恶化，现金流向利润转化效率低。

## 风险警告
公司连续三年巨额亏损，2025年归母净利润-4.6亿元，累计未分配利润已亏至-9.52亿元，净资产持续缩水。核心风险在于：传统有线电视业务在IPTV和移动互联网冲击下用户流失不可逆，而新布局的政企信息化、数据要素等业务尚处投入期，成本高企且竞争激烈，短期内难以弥补主业下滑缺口。公司已陷入“增收不增利”的困境，扣非净利润亏损持续扩大，盈利能力堪忧。

财务风险极为突出。公司资产负债率已攀升至60%，短期借款翻倍至8亿元，一年内到期的非流动负债高达11.5亿元，短期偿债压力巨大。尽管账面经营性现金流为正，但利润表持续巨亏，表明公司经营活动无法覆盖折旧摊销和利息支出，现金流质量堪忧。公司已连续多年不进行现金分红，且因业绩预告不准确多次受到监管处罚，治理层面存在瑕疵。若转型业务无法快速实现盈利，公司面临流动性危机和持续经营能力恶化的双重风险。
