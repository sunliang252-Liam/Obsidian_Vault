# 603112.SH 深度透视

## 因果逻辑链
- **[汽车零部件合资项目落地]** -> [汽车零部件收入同比+53.88%]: 与华域汽车合资公司正式运营，圣德曼产线迁移并完成“产品专线”改造，产能快速爬坡，成为核心增长引擎。
- **[可转债转股及赎回]** -> [财务费用同比-56.37%]: 报告期内完成“华翔转债”提前赎回及摘牌，累计转股6859万股，大幅降低利息支出，优化资本结构。
- **[产品专线升级与组织架构调整]** -> [精密件毛利率微降0.93%但收入增11.87%]: 搬迁扩建白色家电产业园，设立活塞、机座、曲轴专线工厂，提升生产效率，但汽车件放量初期拉低整体毛利率。
- **[工程机械行业周期低迷]** -> [工程机械件收入同比-21.70%]: 受国际贸易争端及下游去库存影响，客户订单下降，产销量均下滑，拖累整体营收增速。
- **[生铁新产品开发]** -> [生铁及可再生资源收入同比+98.91%]: 深化“短流程联铸”工艺，新增消失模精密铸造线，生铁产销量大幅上升，贡献增量收入。
- **[经营活动现金流净额骤降]** -> [现金流净额同比-91.52%]: 主要系缴纳各项税费增加及购买材料支付的现金增加，与营收增长及存货备货节奏不匹配。
- **[布局机器人减速器结构件]** -> [培育第二增长曲线]: 与多家头部减速器厂商建立联系，完成送样验证，引进高精度进口机床，为未来批量供货奠定基础。

## 风险警告
**现金流恶化与存货激增风险。** 2025年经营活动现金流净额仅3663万元，同比暴跌91.52%，而存货同比大增46.27%至10.19亿元。营收增长并未转化为现金，大量资金沉淀在存货和应收账款中，若下游需求放缓或客户回款周期拉长，公司可能面临流动性压力。

**汽车业务整合与盈利爬坡风险。** 汽车零部件收入虽大增53.88%，但精密件整体毛利率反而下降0.93个百分点，表明合资项目初期产能利用率不足、折旧摊销及整合成本较高。若后续订单不及预期或产能爬坡受阻，该业务可能持续侵蚀利润，而非成为稳定增长点。
