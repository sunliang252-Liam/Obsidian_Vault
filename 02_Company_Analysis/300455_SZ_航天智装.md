# 300455.SZ 深度透视

## 因果逻辑链
- **[核工业专项工程价格审核]** -> **营收与利润暴跌**: 产品暂定价与最终审核价差导致当期营收大幅调减，核工业板块毛利率骤降至-33.81%，直接造成全年归母净亏损1.80亿元。
- **[客户资金周转放缓]** -> **信用减值损失激增**: 应收账款回款进度放缓、账龄延长，导致信用减值损失达4,926万元，同比翻倍，进一步侵蚀利润。
- **[客户项目需求调整]** -> **新签订单减少**: 核工业及特殊环境自动化装备业务受客户自身计划调整影响，新签订单减少，板块收入同比下降24.03%。
- **[航天产业高景气]** -> **智能测试仿真业务承压**: 尽管商业航天高速发展，但公司该板块收入仍同比下降13.95%，显示市场竞争加剧或订单交付节奏问题。
- **[处置子公司杭州轩宇]** -> **优化产业布局**: 公开挂牌转让全资子公司，盘活存量资产，获得投资收益200万元，但核工业主业仍由轩宇智能承接。
- **[经营活动现金流改善]** -> **与净利润严重背离**: 经营活动现金流净额同比+42.86%至1.55亿元，主要系年末资金回笼，与-1.80亿元净利润形成巨大反差，反映利润亏损主因是会计调整而非现金流失。
- **[研发投入持续]** -> **巩固技术壁垒**: 研发费用占营收比提升至7.20%，重点攻关高精度模数转换器、空天高性能处理器芯片等，旨在维持航天、核工业领域技术领先地位。

## 风险警告
**核心风险在于核工业业务的“价格剪刀差”与客户依赖。** 公司最大亏损源——核工业专项工程的价格审核机制，本质上是将历史成本与未来定价的错配风险集中释放于单一年度，具有不可预测性和一次性冲击特征。同时，公司超60%营收来自航天科技集团系统内单位，客户高度集中且关联交易占比极高，议价能力与经营自主性受限，一旦集团内部采购政策或定价规则调整，业绩将剧烈波动。

**其次，资产质量与盈利可持续性存疑。** 存货占总资产37%，其中在产品占比超75%，长周期项目占款严重，若后续项目验收或价格审核再次不及预期，减值风险不容忽视。此外，公司2025年归母净利润为-1.80亿元，而扣非净利润更是低至-2.00亿元，剔除一次性价格调整影响后，主业盈利能力是否真正触底回升，仍需观察2026年新签订单与价格确认情况。
