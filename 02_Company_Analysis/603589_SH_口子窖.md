# 603589.SH 深度透视

## 因果逻辑链
- **[宏观经济下行与消费疲软]** -> [高档白酒收入锐减35.08%]: 行业整体承压，消费者购买力下降，直接冲击公司核心高档产品销量与价格体系。
- **[高档产品收入大幅下滑]** -> [总营收同比下降33.65%]: 高档白酒是公司绝对收入支柱（占比94.5%），其下滑是营收萎缩的直接原因。
- **[营收锐减与费用刚性]** -> [净利润暴跌59.32%]: 收入下降幅度（-33.65%）远大于成本费用降幅（-19.34%），导致利润被大幅侵蚀。
- **[经销商去库存与回款放缓]** -> [经营活动现金流净额为-2.16亿元]: 终端动销不畅，经销商回款减少，导致公司经营性现金流由正转负，造血能力严重受损。
- **[合同负债大幅下降40.26%]** -> [未来收入增长乏力]: 预收经销商货款减少，表明渠道打款意愿降低，预示着未来几个季度的收入动力不足。
- **[安徽省内市场收入下滑34.51%]** -> [大本营市场承压]: 作为核心收入来源（占比83.17%），省内市场深度下滑，显示公司基本盘受到严重冲击。
- **[终止股权激励计划]** -> [核心团队激励缺失]: 公司回购注销全部限制性股票，表明业绩未达预期，可能影响管理层及核心员工的积极性与稳定性。

## 风险警告
口子窖2025年遭遇了严重的业绩“戴维斯双杀”。营收与净利润双双大幅下滑，核心高档产品销量萎缩，经营性现金流更是罕见地转为大额净流出，表明公司已陷入“收入下降-回款困难-现金流枯竭”的恶性循环。合同负债的骤降预示着未来收入增长动力严重不足，公司正面临自上市以来最严峻的挑战。

公司过度依赖安徽省内市场（收入占比超83%），在区域竞争加剧和消费疲软的双重打击下，大本营市场出现深度下滑，而省外市场拓展效果尚不明确。同时，公司终止了股权激励计划，可能动摇核心团队的信心与稳定性。在行业整体进入调整期、名酒竞争加剧的背景下，口子窖的品牌力、产品力及渠道掌控力均面临严峻考验，业绩反转的确定性较低。
