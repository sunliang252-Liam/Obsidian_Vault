# 002276.SZ 深度透视

## 因果逻辑链
- **[电网投资高增+新能源装机爆发]** -> [电力电缆收入增长11.76%]: 国家电网投资突破6500亿，海上风电新增装机同比增51%，直接拉动公司高压、风电电缆需求。
- **[高分子材料产销规模行业第一+高端产品国产替代]** -> [高分子材料收入增长4.07%，毛利率提升1.19%]: 220kV超高压绝缘料等高端产品突破“卡脖子”技术，实现国产化替代，优化产品结构提升盈利。
- **[充电桩行业政策红利+大功率产品落地]** -> [新能源充电量同比增长27%]: “三年倍增”行动方案出台，公司800KW液冷超充产品转产，精准匹配快充趋势，驱动充电量增长。
- **[铜价单边上涨+套期保值对冲]** -> [电力电缆毛利率逆势提升1.02%]: 公司通过每日跟踪铜价、远期订单动态管理及套保，有效锁定毛利，对冲原材料成本压力。
- **[海外市场拓展+EAC认证突破]** -> [海外业务发出量同比增长66%]: 公司重点布局“一带一路”市场，取得EAC认证进入中亚，联合研发欧标防火电缆通过DEKRA认证。
- **[机器人/具身智能线缆切入新赛道]** -> [装备线缆板块打开增长空间]: 机器人电缆实现从互联集成向本体线缆延伸，并成功切入人形机器人、机械狗等具身智能领域，实现批量交付。
- **[现金流管理优化]** -> [经营活动现金流净额同比大增201.34%]: 公司优化采购付款方式，增加票据支付，同时销售回款增加，显著改善现金流。

## 风险警告
**核心风险：增收不增利，盈利质量承压。** 公司营收增长8.33%，但归母净利润仅微增1.74%，扣非净利润甚至下滑2.47%。第四季度单季亏损6460万元，拖累全年表现。资产减值损失（1.41亿）和信用减值损失（0.80亿）合计高达2.21亿元，是侵蚀利润的主要黑洞，主要来自商誉减值（万马特缆）和应收账款坏账计提，反映出部分子公司经营不善及下游回款压力。

**结构性风险：新业务亏损扩大，传统业务依赖铜价套保。** 新能源产业集团亏损同比增加，主因是固定资产减值及运营场站到期处置损失增加，充电桩业务盈利模式尚未跑通。同时，公司利润对铜价套期保值的依赖度较高，公允价值变动损益波动剧烈（本期-929万），若铜价走势与套保方向背离，将直接冲击业绩。此外，应收账款占流动资产比重超33%，规模达55.3亿元，客户信用风险不容忽视。
