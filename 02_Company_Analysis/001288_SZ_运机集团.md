# 001288.SZ 深度透视

## 因果逻辑链
- **[海外大单驱动]** -> [营收增长16.29%]: 成功签订几内亚银谷4.06亿美元EPC合同，海外收入占比超56%，成为业绩主引擎。
- **[非经常性损益暴增]** -> [净利润增长24.42%但扣非净利润下降39.31%]: 公允价值变动收益（主要来自参股基金持有的必得科技股票）高达7,717万元，掩盖了主营盈利能力的下滑。
- **[经营现金流大幅恶化]** -> [净利润与现金流严重背离]: 经营活动现金流净额为-3.06亿元，同比暴跌226%，主要系购买商品、支付其他经营活动现金大幅增加，显示回款压力与营运资金占用加剧。
- **[智能化转型与华为合作]** -> [开辟新增长曲线]: 联合开发矿山智能巡检机器人V1.0并落地非洲，从单一设备商向“设备+智能运维服务”转型，提升产品附加值。
- **[并购整合欧瑞安]** -> [产品结构多元化]: 收购永磁电机公司欧瑞安，永磁电机滚筒等收入同比增长502%，完善了核心部件布局，增强了系统集成能力。
- **[原材料与运输成本飙升]** -> [毛利率承压]: 运输成本同比暴增277.67%，叠加材料成本上升，输送机设备整机毛利率下降4.93个百分点，侵蚀主业利润。
- **[可转债与借款增加]** -> [财务杠杆提升]: 长期借款同比大增271.7%，总负债增长21.66%，财务费用因利息收入增加而下降，但未来偿债压力与利息支出风险上升。

## 风险警告
**核心风险在于盈利质量与现金流的严重背离。** 公司2025年净利润增长主要依赖参股基金持有的上市公司股票（必得科技）公允价值变动带来的7,717万元非经常性收益，而扣非净利润同比下滑39.31%，显示主业盈利能力实际在恶化。更严峻的是，经营活动现金流净额为-3.06亿元，与净利润形成巨大剪刀差，主要因海外大项目垫资、提前备货及回款周期长，导致营运资金被大量占用。这种“纸面富贵”的盈利模式不可持续，一旦资本市场波动导致公允价值收益回吐，公司将面临业绩与现金流的双重压力。

**海外业务扩张带来的地缘政治与汇率风险不容忽视。** 公司海外收入占比已超56%，且在手订单高度集中于非洲几内亚等政治经济不稳定的地区。几内亚银谷4.06亿美元大单虽彰显实力，但合同履行周期长、结算货币为美元，面临汇率大幅波动、当地政策变动、项目延期或违约等风险。公司虽开展外汇套期保值，但规模有限，若人民币升值或项目所在国出现动荡，将对公司收入和利润造成重大冲击。
