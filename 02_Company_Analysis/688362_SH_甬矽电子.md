# 688362.SH 深度透视

## 因果逻辑链
- **[海外大客户突破及原有核心客户群高速成长]** -> [营收创历史新高]: 地缘政治推动全球龙头设计公司“China for China”布局，公司抢抓机遇，海外客户营收占比达23.29%，同比增长61.40%，叠加原有AIoT客户群稳固，共同驱动全年营收43.98亿元，同比增长21.87%。
- **[营收规模跨过盈亏平衡点，规模效应显现]** -> [盈利能力显著改善]: 营收增长摊薄固定成本，期间费用率下降（管理费用率从7.38%降至6.21%，财务费用率从5.53%降至5.04%），整体毛利率达16.64%，归母净利润同比增长23.22%至8172.86万元。
- **[持续高研发投入，布局2.5D/3D等前沿封装]** -> [技术储备与未来增长极]: 研发投入同比增长34.55%至2.92亿元，重点布局Fan-out、2.5D/3D封装，相关产品线已通线并实现客户送样，为未来抢占AI与高性能计算市场奠定技术基础。
- **[晶圆级封测产品线放量]** -> [贡献新营收增长点]: “Bumping+CP+FC+FT”一站式交付能力提升，晶圆级封测产品营收同比增长84.22%至1.95亿元，有效客户群持续扩大，量产规模稳步爬升。
- **[二期项目产能逐步释放]** -> [支撑营收持续增长]: 公司总规划投资111亿元的二期项目产能逐步释放，为承接更多订单、扩大市场份额提供了产能保障。
- **[实施股权激励，绑定核心团队]** -> [增强组织稳定性]: 报告期内完成两期限制性股票激励计划归属，向核心管理及技术人员授予股份，提升团队积极性与稳定性，保障长期战略执行。

## 风险警告
**核心风险：扣非净利润持续为负，盈利质量堪忧。** 尽管归母净利润转正，但扣除非经常性损益后的净利润为-4694万元，且亏损额较上年同期扩大。利润主要依赖政府补助（1.49亿元）等非经常性损益，主营业务自身造血能力依然薄弱。高额的固定资产折旧（因收购子公司及二期项目转固）和持续增长的研发费用是侵蚀主业利润的主要原因，若营收增速放缓或毛利率承压，公司可能重回亏损。

**结构性风险：高资本开支与高负债率下的现金流压力。** 公司处于产能扩张期，投资活动现金流净额为-29.19亿元，远超经营活动现金流净额（16.89亿元）。总资产151.9亿元中，固定资产高达94.53亿元，且长期借款与应付债券合计超56.95亿元，资产负债率处于高位。若下游需求波动或融资环境收紧，公司将面临较大的偿债压力和财务费用负担，侵蚀本就微薄的利润。
