# 600666.SH 深度透视

## 因果逻辑链
- **[处置亏损子公司]** -> [净利润扭亏为盈]: 转让秋冠光电、郑州奥瑞德股权及七台河奥瑞德破产清算，合计确认投资收益约3.04亿元，是归母净利润1.41亿元的核心来源。
- **[算力业务扩张]** -> [营收增长27%]: 算力综合服务收入2.28亿元，同比大增97.45%，成为营收增长的主要驱动力，弥补了蓝宝石业务的萎缩。
- **[蓝宝石业务承压]** -> [扣非净利润持续为负]: 蓝宝石晶片毛利率为-1.02%，灯具系列毛利率-6.09%，制造业整体毛利率仅0.83%，导致扣非净利润亏损1.53亿元。
- **[低效资产出清]** -> [资产负债表修复]: 处置子公司及破产清算，使预计负债从3.47亿降至12万，固定资产、无形资产等大幅减少，资产结构显著优化。
- **[租赁算力资源]** -> [资产结构重大变化]: 确认使用权资产4.87亿元（同比+3675%）及相应租赁负债3.65亿元，反映公司从重资产自建转向轻资产租赁的算力运营模式。
- **[历史业绩补偿推进]** -> [股本减少]: 完成对7名业绩承诺方的股份回购注销（1206.5万股），但原实控人左洪波、褚淑霞的补偿义务因股份冻结而悬而未决。

## 风险警告
**盈利质量极差，扭亏完全依赖非经常性损益。** 公司2025年归母净利润1.41亿元，但扣非净利润为-1.53亿元。盈利的核心是“卖子求生”——通过处置亏损子公司和子公司破产清算确认了约3.04亿元的投资收益。剔除这一锤子买卖，公司主营业务（蓝宝石+算力）依然深陷亏损泥潭，蓝宝石业务毛利率微薄甚至为负，算力业务毛利率也因成本飙升而大幅下滑至15.59%。这种盈利模式不可持续，2026年若无新的资产处置，公司将重回亏损。

**蓝宝石主业积重难返，算力业务面临激烈竞争与高额负债。** 蓝宝石业务虽在剥离低效资产，但核心产品晶片毛利率为负，行业竞争激烈，成本控制压力巨大。算力业务虽增长迅猛，但行业竞争格局未定，服务价格存在下行风险。更关键的是，公司为扩张算力业务大规模租赁服务器，导致使用权资产和租赁负债暴增，未来每年将面临数亿元的租金和利息支出，对现金流构成巨大压力。公司1.58亿的应收账款也存在坏账风险，经营现金流净额仅为3465万元，远不足以覆盖未来的偿债压力。
