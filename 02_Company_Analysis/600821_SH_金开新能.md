# 600821.SH 深度透视

## 因果逻辑链
- **[电力市场化改革深化]** -> [归母净利润暴跌87.39%]: 136号文推动新能源全面入市，叠加限电加剧，平均上网电价同比大幅下降，直接侵蚀核心利润。
- **[税收政策调整与资产减值]** -> [扣非净利润转负]: 陆上风电增值税即征即退政策取消，叠加电价下行触发长期资产减值测试，计提固定资产减值4.77亿元、商誉减值2.19亿元，导致扣非净亏损3.36亿元。
- **[装机规模扩张与量价背离]** -> [营收下降4.44%]: 并网装机增至5.85GW，发电量增长6.66%，但电价下行与限电损失抵消了增量，呈现“增量不增收”。
- **[补贴回款改善]** -> [经营现金流增长15.35%]: 可再生能源补贴资金回收15.77亿元，同比大增147.4%，有效对冲了盈利下滑对现金流的冲击。
- **[战略转型“三条曲线”]** -> [布局低碳产品与算电协同]: 为应对单一风光电源的波动风险，主动切入绿电+金属冶炼和智算中心业务，新疆伊吾智算中心首期已投运。
- **[高杠杆运营]** -> [财务费用压力巨大]: 有息负债规模庞大，尽管通过低息置换将财务费用微降1.9%，但8.04亿元的利息支出仍是利润的最大侵蚀项。
- **[绿证交易爆发式增长]** -> [补充电价收益]: 2025年绿证交易量达205.96万张，同比增长248.64%，成为应对电价下行的重要对冲手段。

## 风险警告
**核心风险在于电价与资产减值的负向螺旋。** 随着136号文全面落地，新能源电价从“政策定价”转向“市场竞价”，公司主力光伏板块毛利率骤降10.86个百分点至38.76%。电价下行直接导致发电资产未来现金流预期恶化，触发大规模资产减值（合计近7亿元），而减值又进一步压低了当期利润和净资产，形成恶性循环。这一趋势在电力供需宽松、消纳瓶颈未解的背景下，短期内难以逆转。

**财务结构脆弱性显著。** 公司资产负债率高达72.42%，有息负债超230亿元，每年利息支出超过8亿元，是净利润的8倍。尽管经营现金流因补贴回款尚可，但筹资活动现金流净流出4.36亿元，表明公司正进入“还债高峰期”。若电价持续低迷导致现金流恶化，高杠杆将放大财务风险，偿债能力面临严峻考验。
