# 600502.SH 深度透视

## 因果逻辑链
- **[“投资+施工”双轮驱动战略]** -> [利润逆势增长]: 在行业营收下滑13.79%的背景下，公司通过加大高速公路BOT等高毛利投资业务，推动利润总额增长16.01%，实现以投资拉动盈利的结构性改善。
- **[高速公路BOT项目集中通车]** -> [无形资产暴增]: 徐淮阜高速等路段通车运营，导致无形资产从8.14亿激增至97.17亿元（+1094%），标志着公司从施工方转型为长期资产运营商。
- **[会计估计变更（车流量法）]** -> [利润增厚]: 将收费公路摊销方法从年限平均法改为车流量法，当期减少营业成本1.17亿元，直接增厚了净利润，是利润增长的技术性因素。
- **[新签合同额逆势增长]** -> [未来收入保障]: 在行业新签合同额下降5.51%的背景下，公司新签合同额增长4.86%至1626亿元，为未来2-3年的营收提供了缓冲垫。
- **[永续债与债券融资]** -> [权益扩张与负债率控制]: 发行70亿元永续债计入权益，使净资产增长23.65%，有效控制了资产负债率，为大规模基建投资提供了资本空间。
- **[债权清收与诉讼]** -> [非经常性损益贡献]: 通过加大债权清收力度，单独减值测试的应收款项减值准备转回1.05亿元，成为非经常性损益的主要来源，掩盖了主营业务的真实盈利压力。
- **[房地产业务收缩]** -> [存货下降]: 房地产项目交付减少，导致存货下降31.47%，反映了公司主动收缩地产业务、向基建投资转型的战略意图。

## 风险警告
**核心风险在于“投资换增长”模式下的现金流与债务压力。** 公司利润增长主要依赖高速公路BOT等重资产投资，导致投资活动现金净流出高达131亿元（+32%），远超经营活动产生的12.88亿元净流入。这种“长周期、高杠杆”的商业模式，使公司高度依赖外部融资（筹资净流入137亿），一旦融资环境收紧或项目回报不及预期，将面临严峻的流动性危机。总负债已高达2283亿元，有息债务742亿元，财务费用18.2亿元，利息负担沉重。

**另一大风险是资产质量与法律纠纷。** 公司诉讼案件激增，多为工程款拖欠纠纷，涉案金额巨大，反映出下游客户（尤其是房地产及地方政府）的支付能力恶化。虽然公司通过诉讼收回部分款项，但大量胜诉案件的执行困难以及潜在的坏账风险，可能侵蚀公司利润。此外，公司大量资产（如高速公路收费权）已用于融资抵押，资产弹性空间有限。
