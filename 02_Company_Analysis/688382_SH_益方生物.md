# 688382.SH 深度透视

## 因果逻辑链
- **[高研发投入]** -> [持续亏损]: 公司核心产品处于关键临床阶段，研发投入维持高位，而技术授权收入波动大，无法覆盖成本，导致2025年净亏损3.17亿元。
- **[对外授权模式]** -> [收入波动]: 公司收入主要依赖贝福替尼、格索雷塞的里程碑付款，此类收入具有偶发性，2025年收入同比骤降77.91%，缺乏稳定现金流。
- **[D-2570 II期数据优异]** -> [价值重估]: D-2570治疗银屑病II期数据显示疗效优于同类TYK2抑制剂，媲美生物药，具备“同类最佳”潜力，是公司未来核心价值驱动力。
- **[格索雷塞纳入医保]** -> [销售放量预期]: 格索雷塞于2025年12月纳入国家医保，有望通过以价换量实现快速放量，为公司带来持续销售分成，改善财务状况。
- **[D-0502 注册III期推进]** -> [乳腺癌市场卡位]: 口服SERD靶向药D-0502是国内进度第一梯队的注册III期产品，若成功上市，将切入ER+/HER2-乳腺癌百亿级市场。
- **[管线多元化]** -> [分散风险]: 公司管线覆盖肿瘤（EGFR、KRAS、SERD）、代谢（URAT1）及自免（TYK2），单一靶点或适应症失败风险被分散。
- **[累计未弥补亏损28.6亿]** -> [财务压力]: 巨额累计亏损意味着公司短期内无法分红，且对再融资能力构成潜在制约，需持续依靠外部输血或里程碑收入维持运营。

## 风险警告
**核心风险在于商业化变现的不确定性。** 公司目前仅有两款对外授权产品上市，自身尚无商业化团队和经验。格索雷塞虽已纳入医保，但面临安进、Mirati等同类竞品的激烈竞争，实际销售放量速度和规模存在巨大不确定性。D-0502的注册III期临床试验若失败，将直接摧毁公司最大的价值支柱，导致股价剧烈下跌。

**财务风险同样严峻。** 公司营收高度依赖偶发性的技术授权收入，2025年已大幅下滑，而研发投入仍维持在3.26亿元高位，导致净亏损扩大至3.17亿元。截至2025年末，公司累计未弥补亏损高达28.6亿元，净资产已降至15.36亿元。若未来2-3年内无新药获批上市或产生稳定现金流，公司可能面临流动性压力，需通过增发或合作融资来维持运营，这将稀释现有股东权益。
