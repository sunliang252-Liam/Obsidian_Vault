# 002126.SZ 深度透视

## 因果逻辑链
- **[新能源车渗透率提升]** -> [乘用车业务营收增长18.27%]: 公司作为新能源热管理核心供应商，受益于国内新能源车销量突破1600万辆，带动电池、空调及热泵系统等产品需求。
- **[数字能源领域布局]** -> [数字与能源业务营收增长42.89%]: 储能、数据中心液冷、发电机组等新赛道需求爆发，公司以不锈钢板式换热器等零部件切入，实现高速增长。
- **[全球化产能与客户突破]** -> [海外营收占比提升]: 北美、欧洲、东南亚属地化工厂产能爬坡，成功进入国际主流客户配套体系，非道路空调箱等产品实现海外配套突破。
- **[技术引领与研发投入]** -> [产品竞争力增强]: 持续投入研发（3.88%营收占比），在智驾芯片冷板、车载冰箱、R290冷媒系统等新品类实现从0到1的突破，拓宽增长空间。
- **[新项目定点储备]** -> [未来收入增长确定性]: 全年累计获得455个项目，生命周期内预计新增年销售收入约103.66亿元，为后续业绩提供坚实支撑。
- **[精益管理与降本增效]** -> [盈利能力改善]: 通过卓越制造系统（YPS）、战略集采、VAVE等举措，在原材料价格波动下，扣非净利润增速（31.51%）高于营收增速（23.43%）。
- **[商用车业务基本盘稳固]** -> [营收稳健增长23.94%]: 传统商用车热管理产品（EGR、油冷器等）受益于天然气重卡销量增长及海外市场拓展，保持稳健增长。

## 风险警告
**关税与贸易壁垒风险是当前最核心的挑战。** 公司北美业务营收占比约13.74%，且墨西哥、美国等海外基地是全球化战略的关键支点。中美贸易摩擦、USMCA原产地规则变化及潜在关税加征，将直接推高出口成本，削弱价格竞争力，甚至导致订单转移。公司虽已布局东南亚供应链，但短期难以完全对冲政策不确定性。

**原材料价格波动与汇率风险持续侵蚀利润。** 铝、钢、铜等金属占主营业务成本超80%，价格上行将直接压缩毛利率（乘用车业务毛利率已同比下降2.09%）。同时，公司海外业务以美元、欧元结算，人民币汇率大幅升值将产生汇兑损失，影响海外利润。此外，数字能源等新业务尚处成长期，若竞争加剧或客户拓展不及预期，可能拖累整体盈利。
