# 600064.SH 深度透视

## 因果逻辑链
- **[增持南京银行股份]** -> [营业外收入暴增11739%]: 出资16.84亿元增持南京银行至10%持股，投资成本小于应享有可辨认净资产公允价值，产生4.69亿元非经常性收益。
- **[存量商品房项目集中结转]** -> [营收增长72.76%]: 紫尧星院、紫麟景院等项目加速交付，房地产开发销售收入同比大增270.65%，拉动整体营收大幅攀升。
- **[荣境东院项目计提大额减值]** -> [资产减值损失6.39亿元]: 基于市场环境变化，对荣境东院项目计提存货跌价准备6.38亿元，直接侵蚀核心利润。
- **[股权投资公允价值波动]** -> [公允价值变动损失2.11亿元]: 持有的其他非流动金融资产（未上市股权）经营不及预期，全年确认公允价值变动损失，拖累业绩。
- **[以价换量、精准营销]** -> [销售费用激增158.61%]: 为加速去化存量房产，加大营销投入，销售费用从0.79亿元飙升至2.04亿元。
- **[晨牌药业全年并表]** -> [药品销售收入翻倍]: 2024年仅并表下半年，2025年实现全年并表，药品销售收入同比大增103.54%，成为营收新支柱。
- **[融资成本持续优化]** -> [财务费用下降7.69%]: 成功发行低利率中票和短融，整体平均融资成本降至2.44%，利息支出压力有所缓解。

## 风险警告
**核心风险在于房地产“去库存”与股权投资“退出难”的双重挤压。** 公司虽明确“退出房地产业务”战略，但当前市场量稳价跌，去化高度依赖“以价换量”和巨额营销投入，导致毛利率下滑6.24个百分点。同时，荣境东院项目6.38亿元的减值计提表明，存量项目价值仍在承压，未来可能面临更多减值风险。

**第二重风险来自股权投资业务的业绩波动性。** 公司超230亿元的投资权益中，公允价值变动收益对资本市场和未上市企业估值高度敏感。2025年已确认2.11亿元公允价值变动损失，且A股IPO复苏力度有限，项目退出渠道仍不通畅。若市场持续低迷，投资收益的收缩将直接冲击公司净利润的稳定性。
