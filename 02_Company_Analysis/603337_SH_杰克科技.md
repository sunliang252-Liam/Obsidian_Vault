# 603337.SH 深度透视

## 因果逻辑链
- **[海外市场突破]** -> [外销收入增长24.40%]: 全球鞋服产业转移与补库周期下，公司加速海外本地化运营，外销增速显著超越行业出口增速(16.42%)，成为核心增长引擎。
- **[AI+人形机器人战略投入]** -> [研发费用增长13.39%]: 公司为构建“硬件+软件+AI+机器人”壁垒，持续加大AI、数字化成套及人形机器人研发，研发费用率达8.40%。
- **[SKU精简与爆品策略]** -> [毛利率提升1.43个百分点]: 聚焦爆品、精简SKU至1,100个，叠加高附加值产品（如AI缝纫机）销售占比提升，推动主营毛利率改善。
- **[国内需求疲软]** -> [内销收入下降7.36%]: 行业“内冷外热”，国内缝制设备内销总量同比下滑29.7%，公司内销表现优于行业但依然承压。
- **[大客户联合创新]** -> [大客户销售达7.8亿元]: 通过“铁三角”团队与全球TOP客户深度合作，打造标杆工厂，成功转化订单，驱动成套解决方案业务增长。
- **[全球化人才与组织变革]** -> [海外本地销服人员占比超80%]: 推行“海外战区总+本地人员”配置，缩短决策链条，提升服务响应效率，支撑海外业务高速扩张。
- **[零缺陷质量管理]** -> [客户满意度提升至91.8%]: 全面落地零缺陷质量文化，优化全流程PONC机制，以极致品质支撑高端化与全球化战略。

## 风险警告
**核心风险在于国内市场的持续萎缩与海外增长的不确定性。** 2025年内销已跌至历史低位，且行业预计2026年仍将“缓慢走低”。公司内销收入同比下降7.36%，若国内服装产业“精益竞争”未能有效转化为设备升级需求，内销业务可能持续拖累整体营收。同时，海外市场2025年高增长部分受“抢出口”和补库透支，2026年出口增速预计将明显放缓，公司外销高增长的可持续性面临挑战。

**战略转型期的投入与回报错配风险不容忽视。** 公司正全力押注AI、人形机器人及数字化成套产线，研发费用率高达8.40%，且销售费用因市场拓展同比激增28.79%。这些长期投入在短期内将压制利润增速（净利润仅增5.38%），且人形机器人等前沿技术商业化路径尚不清晰（预计2026年9月发布），若下游客户接受度或技术落地不及预期，高额投入可能无法转化为有效回报，导致资产回报率下降。
