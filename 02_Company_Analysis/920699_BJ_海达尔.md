# 920699.BJ 深度透视

## 因果逻辑链
- **[家电高端化升级]** -> [滑轨配套价值提升]: 家电向高端、嵌入式转型，对滑轨的静音、承重、耐腐蚀要求提高，推动单台价值与技术门槛提升。
- **[服务器市场增长]** -> [服务器滑轨成为新增长极]: 数据中心建设扩容，高密度机柜、液冷服务器普及，对滑轨承重、抗震、阻燃等性能要求严苛，为具备定制化能力的本土企业打开增量空间。
- **[客户集中度高]** -> [业绩波动风险]: 前五大客户销售占比58.02%，若主要客户经营或合作关系生变，将对公司业绩产生重大不利影响。
- **[募投项目启动]** -> [在建工程大幅增加]: 精密滑轨自动化生产基地和研发中心建设项目启动，在建工程同比增长935,246.02%，资本开支进入高峰期。
- **[供应链票据支付增加]** -> [应付账款上升]: 公司使用供应链票据支付供应商货款，未到期票据不得终止确认，导致应付账款同比增长42.54%。
- **[偿还银行贷款]** -> [财务费用下降]: 报告期内偿还部分银行贷款，短期借款减少61.89%，利息支出下降，财务费用同比减少72.41%。
- **[研发投入持续]** -> [技术壁垒构建]: 研发费用同比增长10.34%，拥有132项有效专利，获国家级专精特新“小巨人”称号，强化产品定制化与高端化能力。

## 风险警告
**客户集中与收入下滑双重压力。** 公司前五大客户销售占比高达58.02%，且2025年营业收入同比下降11.17%，净利润同比下降22.09%。核心客户如BSH、海尔、伊莱克斯等均为全球家电巨头，若下游需求放缓或客户切换供应商，公司业绩将面临显著冲击。收入下滑叠加募投项目资本开支，短期盈利承压。

**募投项目投产与产能消化风险。** 公司自有土地上的“精密滑轨自动化生产基地建设项目”已启动，累计投入27,863,655.68元，进度34.30%。项目投产后将大幅增加固定资产折旧与运营成本。若服务器滑轨等新业务拓展不及预期，或家电滑轨市场需求未能同步增长，新增产能可能面临消化困难，导致资产回报率下降。
