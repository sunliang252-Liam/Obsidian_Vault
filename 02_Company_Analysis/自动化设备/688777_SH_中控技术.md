# 688777.SH 深度透视

## 因果逻辑链
- **[宏观经济放缓与下游需求疲软]** -> [营收与利润双降]: 2025年营收同比下降11.66%，归母净利润同比暴跌60.48%，核心原因是下游化工、石化等客户资本开支收缩，项目交付放缓。
- **[非经常性收益减少与汇兑损失]** -> [利润降幅远超营收]: 银行理财收益减少及人民币汇率波动导致的汇兑损失，加剧了利润端的下滑，扣非净利润降幅达68.12%。
- **[DCS市占率持续第一]** -> [核心业务护城河稳固]: 核心产品DCS以45.1%市占率连续15年蝉联国内第一，在化工、石化领域市占率分别提升至68.5%和59.4%，巩固了基本盘。
- **[工业AI战略转型（TPT+UCS）]** -> [开辟第二增长曲线]: 推出时间序列大模型TPT和通用控制系统UCS，构建AOP自主运行工厂，从“卖产品”向“卖服务（MaaS/RaaS）”转型，是未来增长核心。
- **[海外市场高端突破]** -> [打开全球成长空间]: 控制系统首次入围全球前20强石油公司（阿尔及利亚国家石油），DCS/SIS通过沙特阿美测试，海外本地化团队近300人，国际化进入收获期。
- **[研发投入持续高企]** -> [短期利润承压，长期技术壁垒加深]: 研发费用占营收比例提升至11.79%，研发人员占比37.77%，高投入是维持工业AI领先地位的必要代价。
- **[发出商品账面价值高]** -> [占用营运资金，影响现金流]: 发出商品账面价值21.23亿元，占总资产11.28%，项目投运周期长导致资金占用，是经营现金流改善的潜在拖累。

## 风险警告
**核心风险在于业绩失速与转型阵痛。** 2025年营收和利润双双大幅下滑，暴露出公司对下游周期性行业的高度依赖。在宏观经济承压、客户资本开支收缩的背景下，传统自动化业务增长乏力。同时，公司全力押注工业AI战略，研发投入高企，但新业务（MaaS/RaaS）尚处于规模化落地初期，短期内难以完全对冲传统业务的下滑，导致利润端出现“青黄不接”的断档期。

**国际化与AI转型均面临不确定性。** 海外市场拓展虽取得突破，但地缘政治风险、汇率波动及本地化运营挑战不容忽视。工业AI产品（TPT、UCS）的客户接受度和付费意愿仍需市场验证，从“项目制”向“订阅制”的商业模式转型存在客户习惯和收入确认节奏的磨合风险。若AI产品不能快速形成规模收入，公司可能面临“增收不增利”甚至“不增收”的困境。
