# 300747.SZ 深度透视

## 因果逻辑链
- **[高功率激光器技术突破]** -> [营收增长8.43%]: 220kW全球最高功率工业激光器及万瓦以上激光器销量同比增长26%，推动连续光纤激光器收入增长12.38%，成为核心增长引擎。
- **[产品结构向高端迁移]** -> [扣非净利润暴增181.42%]: 超快激光器（+35.24%）、连续光纤激光器（+12.38%）等高毛利产品占比提升，叠加整体成本降幅超20%，盈利能力显著修复。
- **[手持焊市场渗透加速]** -> [焊接市场占有率提升]: 手持焊出货量同比增长66.22%，极致系列一站式解决方案获批量订单，推动公司从切割向焊接应用场景拓展。
- **[新兴应用领域突破]** -> [打开第二增长曲线]: 在汽车制造（比亚迪、理想等）、新能源（宁德时代）、医疗（掺铥激光器）、安防（破拆激光器）等领域实现从0到1的突破，形成多元化增长点。
- **[海外高端市场开拓]** -> [国际化布局实质性推进]: 完成韩国头部电池企业、德国Bosch等国际客户交付，设立四大海外办事处，海外高端市场渗透率提升。
- **[IPD改革与精益管理]** -> [运营效率提升]: 深化集成产品开发（IPD）改革，优化研发流程，推动产品成本降幅超20%，存货周转率改善，人均营收增幅约20%。
- **[全产业链垂直整合]** -> [成本与供应链优势]: 从特种光纤、泵浦源到整机的垂直集成能力，核心器件全国产化，有效对冲原材料价格波动，保障供应链安全。

## 风险警告
**核心风险在于行业价格战与盈利能力的脆弱性。** 尽管扣非净利润大幅增长，但公司2025年归母净利润中政府补助等非经常性损益占比高达48%，扣非后净利率仅2.4%，盈利能力依然薄弱。激光器行业传统中低功率领域价格竞争虽有所缓和，但并未消失，公司需持续通过技术降本维持毛利率，一旦技术迭代放缓或成本控制失效，盈利将面临巨大压力。

**第二风险是存货与现金流压力。** 公司存货账面价值6.57亿元，已计提跌价准备1.47亿元，且库存量同比暴增42.72%，显示备货与市场需求匹配存在风险。同时，经营活动现金流净额同比大幅下降56.07%，主要因第四季度加大供应商付款，但这也暴露出公司在产业链中的资金占用压力，若下游回款放缓，现金流可能进一步恶化。
