# 688290.SH 深度透视

## 因果逻辑链
- **[项目验收减少与审价调减]** -> [营收与利润双降]: 核工业及军工项目验收数量减少，叠加个别项目审价结果调减当期收入，导致2025年营收同比-27.57%，归母净利润由盈转亏至-3198万元。
- **[研发投入激增]** -> [短期利润承压]: 公司聚焦“AI+具身智能”及微堆/SMR等前沿技术，研发费用同比+47.81%至4496万元，研发费用率升至22.51%，直接侵蚀当期利润。
- **[高客户集中度]** -> [业绩波动风险]: 对中核集团下属单位收入占比高达69.68%，单一客户依赖度高，其采购节奏与项目审价直接决定公司业绩波动。
- **[在手订单充裕]** -> [未来业绩修复基础]: 截至2025年末，公司在手订单约5.8亿元，为后续收入确认和业绩反转提供了坚实支撑。
- **[军工业务突破]** -> [第二增长曲线初现]: 智能保障系统装备通过军方鉴定并进入定型阶段，有望实现批产，非核领域营收同比+11.96%，业务结构优化。
- **[经营性现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额同比+300.41%至1.17亿元，主要系销售回款增加，表明公司虽亏损但造血能力增强。

## 风险警告
公司当前最大的风险在于**业绩高度依赖核工业大客户的交付节奏与审价结果**。2025年营收与利润双降已充分暴露了这一脆弱性。若未来核心订单交付再次延迟，或审价结果持续不利，公司业绩将面临剧烈波动，甚至可能连续亏损。此外，**研发投入的持续高企**（研发费用率超22%）在短期内无法转化为收入，将持续压制利润表现，考验公司的现金流管理能力。

其次，**民品市场拓展与前沿技术商业化存在巨大不确定性**。公司正积极布局核技术应用、军工及海外市场，并大力投入AI具身智能、微堆/SMR等前沿领域。这些新业务面临品牌认知重塑、市场竞争激烈、技术路线不确定等挑战，前期大量投入若无法有效转化为订单，将导致资源浪费，拖累整体盈利能力的恢复。
