# 688646.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧与产品降价]** -> [毛利率下滑]: 锂电行业下行周期内，市场竞争白热化，公司锂电设备产品价格承压，导致主营业务毛利率同比下降6.64个百分点。
- **[资产减值损失大幅增加]** -> [净利润由盈转亏]: 基于谨慎性原则，公司对存货和应收账款计提大额减值准备，叠加毛利率下滑，导致2025年归母净利润亏损4894.84万元，同比下降292.49%。
- **[在手订单创新高]** -> [未来收入增长潜力]: 截至2025年末，公司在手订单规模达21.11亿元，同比增长59.12%，为未来营收增长提供了坚实基础。
- **[研发投入持续高增]** -> [巩固技术护城河]: 研发费用达1.11亿元，同比增长20.21%，占营收13.87%，重点投向固态电池、钙钛矿、半导体AMHS等前沿领域，以技术领先驱动长期竞争力。
- **[海外市场拓展加速]** -> [全球化布局初显成效]: 在新加坡、韩国等地设立子公司，海外新增订单实现翻倍式增长，成功进入英国、德国、日本等高端市场，降低对单一国内市场的依赖。
- **[子公司新聚力并表]** -> [智慧物流业务成为新增长极]: 控股子公司新聚力贡献智慧物流集成系统收入2.47亿元，同比增长91.85%，成为公司第二大收入来源，并成功切入半导体AMHS国产替代赛道。
- **[新业务拓展导致费用激增]** -> [短期利润承压]: 公司加速向固态电池、钙钛矿、人形机器人等新兴领域布局，导致管理费用（+44.12%）和研发费用（+20.21%）显著增加，侵蚀了当期利润。

## 风险警告
公司当前面临的核心风险是“增收不增利”的困境。尽管在手订单和营收均实现增长，但锂电设备行业竞争加剧导致毛利率持续下滑，叠加公司为抢占未来赛道而进行的战略性投入（研发、管理、新业务拓展），短期内利润端压力巨大。2025年归母净利润已由盈转亏，若行业竞争态势未能缓解，公司盈利能力可能持续承压。

另一个重大风险是财务健康度恶化。公司应收账款和存货规模庞大，合计占总资产比例超40%，且经营性现金流连续两年为负。大额资产减值准备的计提已对利润造成严重冲击，若下游客户经营状况恶化或项目验收延迟，坏账和存货跌价风险将进一步放大，可能引发流动性危机。此外，公司因内控问题被出具警示函并实施ST，治理层面的修复仍需时间验证。
