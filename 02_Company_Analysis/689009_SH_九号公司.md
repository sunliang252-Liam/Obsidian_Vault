# 689009.SH 深度透视

## 因果逻辑链
- **[电动两轮车销量爆发]** -> [营收增长49.89%]: 电动两轮车销量409万台，收入118.59亿元，同比增长64.45%，成为营收增长的核心引擎。
- **[服务机器人全球化放量]** -> [第二曲线成型]: 割草机器人Navimow全球销量第一，服务机器人收入20.02亿元，同比翻倍增长104.26%，开辟新增长极。
- **[产品结构升级与规模效应]** -> [毛利率提升1.39个百分点]: 高端化、智能化产品占比提升，叠加采购与生产规模效应，推动整体毛利率从28.24%升至29.63%。
- **[渠道深度与广度拓展]** -> [销售费用率上升]: 线下门店超万家，线上多平台布局，全球化KA卖场入驻，导致销售费用同比增长70.71%，侵蚀部分利润。
- **[研发持续高投入]** -> [技术壁垒加固]: 研发费用12.5亿元，同比增长51.27%，凌波OS、EFLS2.0等核心技术迭代，巩固“智能化”标签。
- **[现金流强劲]** -> [经营质量优异]: 经营活动现金流净额44.44亿元，同比增长32.51%，远超净利润，体现强大的现金创造能力和供应链议价权。
- **[高分红与回购]** -> [股东回报显著]: 现金分红+回购合计占净利润77.18%，彰显管理层对股东回报的重视及对未来发展的信心。

## 风险警告
**核心风险在于特殊投票权结构下的治理风险与国际化经营的不确定性。** 公司采用AB股结构，创始人高禄峰与王野合计控制57.73%的投票权，中小股东决策影响力有限。同时，公司通过VIE架构运营增值电信业务，若相关法律法规发生变化，可能对业务稳定性造成冲击。此外，海外业务占比高，面临地缘政治、贸易摩擦及汇率波动的多重风险。

**另一重大风险是行业竞争加剧与政策变化。** 电动两轮车行业已进入“存量优化”阶段，新国标推动行业洗牌，但价格战风险犹存。电动滑板车在部分国家面临路权限制或更严格的认证要求（如荷兰RDW认证），若主要市场政策收紧，将对公司核心产品销量构成直接打击。公司需持续投入以维持技术领先和品牌优势，否则可能面临市场份额被侵蚀的风险。
