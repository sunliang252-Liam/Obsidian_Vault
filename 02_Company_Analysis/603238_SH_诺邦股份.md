# 603238.SH 深度透视

## 因果逻辑链
- **[子公司杭州国光营收高增]** -> [公司总营收增长28.50%]: 杭州国光（合并）营收同比增长40.81%至19.61亿元，占公司总营收的68%，是核心增长引擎。
- **[关税冲击下市场战略调整]** -> [母公司卷材业务稳住基本盘]: 面对美国关税壁垒，公司将重心切换至国内及非美市场，推出性价比更高的可冲散材料，与恒安、金红叶等客户建立合作，对冲了美标订单下滑风险。
- **[内部降本增效与数字化升级]** -> [毛利率保持稳定]: 通过数字化智能工厂建设与全员降本，在行业“量稳价弱”背景下，母公司水刺非织造材料毛利率同比提升2.78个百分点。
- **[海外非美市场与国内商超渠道爆发]** -> [子公司杭州国光业绩超预期]: 海外业务巩固沃尔玛、金佰利等核心客户，切入智利、新西兰等新兴市场；国内业务抓住山姆、胖东来等品质商超机遇，双轮驱动增长。
- **[研发投入高增37.11%]** -> [差异化产品矩阵丰富]: 研发费用达1.07亿元，推出适配非美市场的可冲散系列、湿法低掉屑材料等新品，并正式立项SP高端工业擦拭材料，打造第二增长曲线。
- **[马来西亚工厂投产]** -> [全球化产能布局初成]: 2025年6月正式运营马来西亚工厂，保障海外订单及时交付，并为拓展“一带一路”沿线市场提供支撑，有效规避单一市场风险。
- **[自有品牌小植家高增]** -> [产业链延伸初见成效]: 小植家全渠道销售额同比增长54.92%至4625万元，核心品类湿厕纸、洗脸巾增速超121%，从材料到制品的完整产业链价值开始释放。

## 风险警告
**贸易保护主义与地缘政治风险是最大不确定性。** 公司对美出口业务在2025年一季度占比达15%，虽已通过市场切换对冲，但美国关税政策反复无常，2026年仍可能对公司经营稳定性构成直接冲击。同时，国际地缘冲突加剧导致原油价格短期剧烈上涨，公司面临原材料成本上升与产成品提价受限的双重挤压，盈利能力承压。

**行业“内卷”加剧，结构性过剩持续。** 国内非织造布行业产能过快增长，供给端增量超过需求端，价格竞争恶化。公司虽为水刺龙头，但面临低价湿法厂商的恶性竞争。若不能持续通过产品创新和降本增效维持技术壁垒，市场份额和行业地位将受到挑战。此外，公司超50%收入来自境外，汇率与海运费的剧烈波动将持续侵蚀利润。
