# 688721.SH 龙图光罩 深度透视

## 因果逻辑链
- **[行业竞争加剧，策略性降价]** -> [深圳工厂收入及毛利率下降]: 130nm及以上制程产品进入国产替代后期，公司为巩固市场份额进行降价，导致成熟产品盈利能力承压。
- **[珠海工厂投产，产能爬坡]** -> [净利润大幅下滑38.92%]: 新工厂固定资产折旧成本高，规模效应未释放，产品毛利率为负，叠加存货减值，严重拖累整体利润。
- **[高端制程研发投入增加]** -> [研发费用同比增长18.76%]: 公司重点布局90nm/65nm/40nm等高端节点，研发投入持续加大，短期侵蚀利润，但为长期技术突破奠定基础。
- **[石英掩模版销量增长14.02%]** -> [产品结构向高端化倾斜]: 公司将产能、研发资源向石英掩模版集中，珠海新产线亦聚焦石英产品，推动收入结构优化。
- **[珠海工厂通过多家头部客户认证]** -> [未来收入增长潜力打开]: 成功通过华虹宏力、意法半导体等客户审厂，为后续高端订单导入和收入增长奠定客户基础。
- **[原材料和设备依赖进口]** -> [供应链安全风险突出]: 石英基板、光学膜及光刻机等核心物料设备高度集中于日本、中国台湾等少数供应商，地缘政治风险加剧。
- **[珠海工厂亏损及存货减值]** -> [资产减值损失增加]: 基于审慎性原则，对珠海工厂部分可变现净值低于成本的存货计提减值，进一步压低当期利润。

## 风险警告
公司当前面临的核心风险是“新旧动能转换期的业绩阵痛”。深圳工厂成熟产品因竞争加剧被迫降价，盈利能力下滑；而承载未来增长的珠海工厂正处于产能爬坡关键期，高额折旧与低利用率导致亏损，严重拖累整体利润。2025年净利润同比下滑38.92%，且第四季度净利润仅429.95万元，显示盈利压力在持续加大。若珠海工厂产能释放及客户导入不及预期，公司可能面临较长时期的业绩低迷。

另一重大风险在于供应链的“卡脖子”隐患。公司核心原材料（石英基板、光学膜）及关键设备（光刻机）高度依赖日本、中国台湾等境外供应商，前五大供应商采购额占比超61%。在全球半导体贸易保护主义抬头的背景下，若地缘政治冲突导致供应中断或成本飙升，将对公司生产经营的连续性与稳定性构成致命打击。
