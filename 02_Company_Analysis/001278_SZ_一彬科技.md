# 001278.SZ 深度透视

## 因果逻辑链
- **[客户结构调整，从高毛利日系转向竞争激烈的国内品牌]** -> [综合毛利率大幅下降]: 公司主动开拓国内新能源车企，但国内零部件行业价格竞争激烈，导致产品售价承压，毛利率从20.15%降至13.66%。
- **[新设子公司及新项目前期投入巨大]** -> [亏损扩大]: 莆田、湖州、河北、芜湖、盐城等新基地处于产能爬坡期，客户销量未达预期，厂房设备折旧及运营成本刚性，导致严重亏损。
- **[应收账款增加及回款账期拉长]** -> [信用减值损失激增]: 开拓国内客户导致应收账款规模扩大，同时客户回款周期变长，公司计提的信用减值损失大幅增加。
- **[银行贷款增加]** -> [财务费用同比大增97.73%]: 为弥补营运资金缺口，公司增加银行贷款，导致利息支出从1159万增至2292万，严重侵蚀利润。
- **[新能源业务（一彬新能源）尚处投入期]** -> [拖累整体业绩]: 铜排、高压电缆等新能源产品研发及固定资产投入高，但销售规模小，未形成规模效应，导致亏损。
- **[核心产品塑料件毛利率下滑]** -> [盈利基础动摇]: 塑料件收入增长8.89%，但成本增长17.95%，导致毛利率从15.16%降至8.10%，是利润下滑的核心原因。
- **[研发投入资本化率为零]** -> [当期费用压力大]: 公司研发投入1.16亿元全部费用化，未进行资本化，对当期利润构成直接压力。

## 风险警告
公司正经历痛苦的战略转型期，从高毛利的合资品牌（日系）市场转向竞争白热化的国内新能源车企。这一过程导致客户结构恶化、毛利率大幅下滑、应收账款激增，并引发信用减值与财务费用的双重打击。2025年公司由盈转亏，亏损7402万元，且亏损逐季扩大，显示经营困境仍在加剧。

新设子公司（湖州、河北、芜湖、盐城等）及新能源业务（一彬新能源）的产能爬坡是当前最大的财务“出血点”。这些项目前期投入巨大，但客户销量远不及预期，导致固定资产折旧和运营成本无法被有效覆盖，持续产生亏损。若未来客户订单无法快速放量，公司可能面临更严重的资产减值风险和现金流压力。
