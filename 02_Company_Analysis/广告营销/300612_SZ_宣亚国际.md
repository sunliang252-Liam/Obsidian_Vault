# 300612.SZ 深度透视

## 因果逻辑链
- **[主动收缩低毛利数字广告业务]** -> [营收腰斩]: 公司主动优化业务结构，大幅收缩毛利率低、垫资重的数字广告服务，导致总营收同比下降48.83%。
- **[数字广告业务毛利率大幅提升]** -> [业务质量改善]: 在收入骤降62%的同时，数字广告毛利率同比提升20.99个百分点，表明公司从追求规模转向追求利润。
- **[子公司商誉暴雷]** -> [巨额亏损]: 全资子公司天津星言云汇业务转型不及预期，导致计提商誉减值3,204.18万元，是当期净亏损的核心来源。
- **[股份支付费用激增]** -> [管理费用失控]: 2024年实施的限制性股票激励计划导致报告期内管理费用同比暴增49.77%，剔除该影响后管理费用实则下降19.1%。
- **[经营性现金流大幅转正]** -> [造血能力改善]: 在营收腰斩、净利润亏损的背景下，经营活动现金流净额由负转正至1.15亿元，主要系业务调整后支付媒体款项减少。
- **[客户与供应商高度集中]** -> [经营脆弱性]: 前五大客户收入占比61.75%，前五大供应商采购占比68.47%（其中单一供应商占比56.81%），对汽车行业和字节跳动系媒体平台依赖度极高。
- **[AI技术投入聚焦降本]** -> [效率提升]: 自研“AI视频创作平台”将剪辑效率提升90%，“智能广告投放数据分析平台”将报表生成时间从天级缩短至分钟级，技术提效成为核心竞争壁垒。

## 风险警告
公司当前最大的风险在于**战略收缩期的业绩阵痛**。主动放弃低毛利业务虽改善了现金流和毛利率，但导致营收断崖式下跌，且新业务（如AI营销、本地生活）尚未形成规模收入，公司正处于新旧动能转换的“青黄不接”阶段。若新业务增长无法填补传统业务萎缩的缺口，公司将持续面临亏损压力。

其次，**资产质量风险不容忽视**。子公司商誉已全额计提减值，但应收账款和存货合计占总资产比例高达36.3%，且客户集中度极高（汽车行业占比77.66%）。若下游汽车行业景气度下行或主要客户削减预算，公司将面临严重的坏账风险和收入波动。此外，公司对单一供应商（字节跳动系）的采购依赖度超过56%，媒体平台政策变动将直接冲击公司核心业务的稳定性。
