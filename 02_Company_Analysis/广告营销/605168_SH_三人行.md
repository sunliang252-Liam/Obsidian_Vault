# 605168.SH 深度透视

## 因果逻辑链
- **[AI赋能降本增效]** -> [净利润增长54%]: 公司利用AI技术优化全链路营销，在收入下降12.9%的情况下，实现利润总额增长76.8%，净利率提升至5.18%。
- **[强化回款管理]** -> [经营现金流暴增345%]: 公司加大应收账款催收力度，期末应收账款同比下降27%，带动经营活动现金流净额达5.43亿元，财务结构显著优化。
- **[客户预算收缩]** -> [营收下滑12.9%]: 汽车等行业个别大客户调整营销预算，导致公司数字营销服务收入同比下降11.4%，整体营收承压。
- **[战略投资退出]** -> [贡献非经常性收益]: 公司退出北交所上市公司瑞华化工，投资收益率超70%，体现了公司精准的项目筛选与资本运作能力。
- **[布局低空经济]** -> [培育未来增长点]: 公司战略投资的华鹰众行大型无人运输机项目获民航局适航审定受理，标志着公司在先进装备制造领域取得阶段性成果。
- **[高比例现金分红]** -> [强化股东回报]: 公司2025年拟每10股派发现金股利7.2元，分红比例达归母净利润的79.92%，上市以来累计分红超11亿元，派息融资比达109.65%。
- **[股权投资收益波动]** -> [扣非净利润下降16.4%]: 公司持有的非流动金融资产公允价值变动损益为-2914万元，导致扣非净利润（1.97亿元）低于归母净利润（1.90亿元），且同比下滑。

## 风险警告
**核心风险在于营收增长乏力与客户集中度过高。** 公司2025年营收同比下降12.9%，主要系汽车等行业个别大客户预算调整所致。公司前五大客户销售额占比高达45.37%，客户集中度高，若核心客户营销预算持续收缩或流失，将对公司业绩产生重大冲击。公司虽在拓展新客户，但短期内难以完全对冲大客户波动的影响。

**其次，公司盈利质量对投资收益依赖度较高。** 2025年归母净利润同比增长54%，但扣非净利润同比下降16.4%，两者背离主要源于非经常性损益（尤其是股权投资公允价值变动）。公司持有8.6亿元的其他非流动金融资产，其公允价值波动对利润表影响显著，增加了业绩的不确定性。此外，媒体资源采购价格上涨风险与AI技术迭代带来的市场竞争加剧风险，也构成中长期隐忧。
