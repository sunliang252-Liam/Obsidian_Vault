# 600358.SH 深度透视

## 因果逻辑链
- **[游戏行业头部客户深化合作]** -> [互联网营销收入增长10.25%]: 子公司新线中视聚焦腾讯等头部游戏客户，提供全生命周期营销服务，驱动核心收入增长。
- **[跨境电商渠道扩张与品牌引入]** -> [电商业务收入暴增60.08%]: 海际购公司拓展抖音、菜鸟等新渠道，引入博朗等热销品牌，实现销售规模快速扩张。
- **[历史债权化解与资产处置]** -> [非经常性收益大幅减亏]: 向控股股东转让业绩补偿款债权（获3724万元）及重庆颐尚土地收储款（获2310.56万元），合计冲回坏账准备超2000万元，是净利润亏损收窄的主因。
- **[旅游目的地业务战略收缩]** -> [板块亏损大幅收窄]: 公司主动剥离景区投资运营业务（出售国贵文旅），压缩团队规模，实现降本增效。
- **[重大资产重组启动（润田实业）]** -> [公司战略转型预期]: 拟注入盈利能力强的包装饮用水龙头润田实业，构建“水为龙头、营销与跨境为两翼”的新格局，是未来核心看点。
- **[互联网营销行业利润承压]** -> [新线中视持续亏损]: 游戏买量成本高企、同质化竞争激烈、流量红利衰减，导致子公司虽收入增长但利润空间被严重挤压。
- **[跨境电商行业竞争加剧]** -> [海际购亏损面扩大]: 国内消费疲软、流量成本高企、销售回款账期拉长，导致该业务盈利能力恶化。

## 风险警告
公司当前最大的风险是**持续经营能力高度依赖尚未完成的重大资产重组**。2025年公司扣非净利润亏损5881万元，经营活动现金流净流出7499万元，净资产仅剩5416万元，且已因信息披露违规被ST。核心主业（互联网营销与跨境电商）均处于增收不增利甚至亏损扩大的困境，若重组润田实业失败或长期停滞，公司可能面临严重的流动性危机与退市风险。

其次，**历史遗留问题的“止血”效果具有一次性特征**。2025年减亏主要依赖向控股股东出售债权、土地收储等非经常性收益，而非主营业务的根本性好转。同时，公司仍面临大量历史诉讼（如粉丝科技、南京淳璞等案件）的执行风险，应收账款回收压力巨大，且子公司新线中视存在客户与供应商高度集中的结构性风险，一旦核心客户流失，业绩将剧烈波动。

> 国旅文化投资集团股份有限公司成立于1998年12月,经中国证监会批准,于2000年9月22日在上海证券交易所上市挂牌交易(股票简称:国旅联合;股票代码:600358),是较早的一批旅游上市企业。国旅联合作为我省第一家旅游类上市公司,承担着江旅集团贯彻落实省委、省政府旅游强省战略、整合全省旅游资源提升全省文旅产业发展打造“全民旅游时代价值创造引领者”的光荣使命。截至目前,公司主营业务包括以下三个方面:(一)互联网数字营销业务互联网数字营销业务是公司当前主要的收入来源。公司子公司新线中视是互联网营销业务的经营主体,主要模式为根据客户的品牌传播需求制定具体的传播计划并实施或根据客户的推广需求通过策划、设计相关广告内容进行精准的投放为客户带来增量。主要客户为游戏行业客户及文旅客户,投放的主要媒体为B站、抖音、快手等互联网媒体。(二)旅游目的地运营业务旅游目的地业务,作为国旅联合回归文旅消费主业的业务板块,主要围绕“目的地项目、合作资源圈、运营服务商”三方面的拓展,助推上市公司实现高质量发展。该业务的主要模式为依托专业投资开发、运营能力,与地方政府、景区、企业围绕乡村振兴、主题乐园、旅游目的地的策划、规划、建设、运营展开深度合作,为旅游项目提供整体解决方案。(三)“跨境购”业务2024年1月,公司完成了现金收购江西省海际购进出口有限公司100%股权。海际购公司是一家保税商品进出口供应链品牌生态公司,主营跨境新零售及跨境电商运营业务。公司专注于将全球优质品牌引入中国市场,帮助国内优质品牌走向全球,实现在中国“买全球”。
