# 301171.SZ 深度透视

## 因果逻辑链
- **[AI技术深度渗透]** -> [营收增长50.39%]: AI驱动全链路自动化（AI Drive 2.0、zMaticoo SDK&DSP 2.0）提升广告投放效率与ROI，吸引更多广告主预算，推动营收从25.47亿跃升至38.30亿。
- **[电商出海爆发]** -> [电商收入增长122.80%]: 跨境电商成为外贸增长新引擎，公司作为头部出海营销服务商，承接大量电商客户广告需求，电商收入占比从20.14%提升至29.83%。
- **[程序化广告平台升级]** -> [广告平台业务增长48.92%]: zMaticoo完成DeepSeek-R1大模型私有化部署及双端升级，通过IAB Tech Lab认证，技术壁垒提升，驱动广告平台业务收入增长。
- **[规模扩张与成本错配]** -> [归母净利润下降31.80%]: 营收高增50.39%，但营业成本同步增长（整合营销服务成本+53.27%，广告平台成本+61.48%），叠加研发/销售/管理费用大幅增长（研发费用+74.28%），导致毛利率承压，利润不增反降。
- **[非经常性损益扰动]** -> [扣非净利润暴跌63.97%]: 核心盈利能力下滑，扣非净利润仅7817万，而2024年为2.17亿。利润主要依赖公允价值变动收益（8060万）和政府补助（2028万），主业盈利质量堪忧。
- **[信用减值损失激增]** -> [利润总额被侵蚀]: 信用减值损失达8792万元（占利润总额48.99%），主要系应收账款和其他应收款坏账计提，反映客户回款风险上升。
- **[现金流恶化]** -> [经营现金流净额下降65.87%]: 尽管营收增长，但经营现金流净额从4.73亿降至1.61亿，表明公司为维持高增长垫付了大量资金，或面临客户账期拉长、预付款增加的压力。

## 风险警告
**核心风险：增收不增利，盈利质量堪忧。** 营收增长50.39%的亮眼数据背后，是归母净利润下降31.80%、扣非净利润暴跌63.97%的残酷现实。公司利润高度依赖非经常性损益（公允价值变动收益8060万），而主业盈利能力显著下滑。同时，信用减值损失高达8792万元，占利润总额近一半，表明客户回款风险正在快速暴露，坏账侵蚀利润。

**增长可持续性风险：成本失控与现金流恶化。** 营收增长主要由成本驱动，营业成本增速（整合营销+53.27%，广告平台+61.48%）全面超越营收增速（+49.35%，+48.92%），毛利率全面下滑。经营现金流净额同比大降65.87%，与营收高增严重背离，公司为维持增长垫付了大量资金，若客户账期进一步拉长或坏账持续增加，现金流可能断裂。此外，前五大供应商采购额占比高达82.31%，对头部媒体（Google、Meta等）的依赖度极高，一旦合作关系或政策生变，业务将遭受重大冲击。
