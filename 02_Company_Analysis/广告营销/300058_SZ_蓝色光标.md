# 300058.SZ 深度透视

## 因果逻辑链
- **[出海业务高增长]** -> [营收规模突破686亿]: 出海广告投放收入同比增长16.89%，占总营收82.25%，成为绝对收入支柱。
- **[营收增长但毛利率极低]** -> [净利润仅2.25亿]: 出海业务毛利率仅1.56%，收入规模虽大但利润贡献微薄，整体盈利能力脆弱。
- **[All in AI战略落地]** -> [人效提升与费用优化]: 员工人数减少，研发费用增长76.52%用于AI工具开发，管理费用下降11.46%，驱动运营效率提升。
- **[经营性现金流大幅改善]** -> [净利润含金量提升]: 经营活动现金流净额同比增长604.35%至6.32亿，主要得益于应收账款回款加强，扭转了此前“增收不增现”的局面。
- **[商誉与信用减值风险释放]** -> [利润表压力减轻]: 2024年大额计提减值后，2025年信用及资产减值损失合计降至1.18亿，同比大幅减少，为扭亏为盈创造条件。
- **[客户与媒体集中度高]** -> [议价能力受限]: 前五大供应商采购额占年度采购总额91.34%，公司对头部媒体平台依赖极深，利润空间被严重挤压。
- **[无实控人状态]** -> [治理结构稳定]: 赵文权与孙陶然一致行动关系解除后，公司无控股股东及实控人，股权分散，管理层主导经营。

## 风险警告
**核心风险在于“规模不经济”的商业模式。** 公司营收686亿，但净利润仅2.25亿，净利率不足0.33%。出海业务作为绝对主力，毛利率仅1.56%，本质上是在为Meta、Google等媒体平台“打工”，赚取微薄的代理费或返点。这种高营收、低利润、高资金占用的模式，对现金流管理要求极高，一旦客户回款周期拉长或媒体政策变动，利润将迅速被侵蚀。

**第二大风险是客户与供应商的双重集中。** 前五大供应商采购额占比超91%，意味着公司对头部媒体平台几乎没有议价权，任何返点政策的调整都会直接冲击利润。同时，客户集中度虽不高，但游戏、电商行业受政策、经济周期影响大，客户预算波动会直接传导至公司收入。此外，公司仍有17.6亿商誉悬顶，尽管2025年减值压力减轻，但若被投公司业绩不达预期，仍存在暴雷可能。
