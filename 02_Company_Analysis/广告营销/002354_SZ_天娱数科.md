- **[数据流量业务规模扩张]** -> [营收增长31.57%]: 数据流量业务收入20.49亿元，同比增长33.36%，是营收增长的核心引擎，但毛利率仅24.46%，增长质量有限。
- **[AI降本增效与高毛利业务占比提升]** -> [毛利率提升2.41个百分点]: 公司通过AI工具优化内容生产、投放和运营效率，推动毛利率从22.90%提升至25.31%，经营效率改善。
- **[计提商誉及长期股权投资减值]** -> [归母净利润仍为负]: 对业绩未达预期的控股及参股公司计提合计7080.63万元减值，导致归母净利润-4885万元，但同比减亏58.58%。
- **[债务重组收益]** -> [非经常性损益支撑利润]: 与入园企业签署协议终止确认应付账款，产生债务重组收益8468.90万元，是公司扭亏为盈的关键非经常性因素。
- **[短期借款委托支付]** -> [经营活动现金流净额大幅转正]: 通过第三方金融公司直接向供应商付款，减少采购现金流出，使经营性现金流净额达1.16亿元，与净利润严重背离。
- **[海外AI营销服务出海]** -> [海外业务收入爆发式增长]: 海外业务收入5737万元，同比增长568%，主要得益于在东南亚建立AI营销基地并取得TikTok等服务商资质。
- **[智慧能源业务快速拓展]** -> [新增长极初步形成]: 签约电量7.53亿千瓦时，客户超500家，依托智慧能源大模型切入AI售电与算电协同，但规模尚小，对整体业绩贡献有限。
- **[无控股股东与历史遗留诉讼]** -> [治理风险与资产减值隐患]: 公司无实际控制人，且存在大量历史并购业绩对赌诉讼（如DotC、王玉辉等），持续带来资产减值与法律风险。

## 风险警告
**核心风险在于盈利质量与资产安全。** 公司2025年净利润仍为负，且盈利高度依赖债务重组等非经常性损益（8469万元），扣非后净亏损高达1.17亿元。同时，经营活动现金流净额1.16亿元与净利润严重背离，系通过短期借款委托支付供应商所致，现金流改善的可持续性存疑。此外，公司账面商誉高达4.99亿元，长期股权投资减值准备余额高达252.75亿元，历史并购后遗症（如DotC、幻想悦游等业绩对赌失败）引发的诉讼和减值风险远未出清。

**业务转型的确定性与竞争壁垒不足。** 公司宣称聚焦AI营销、智慧能源等赛道，但核心收入仍依赖传统数据流量业务（占比98.67%），该业务毛利率低（24.46%），且前五大供应商采购额占比高达92.68%，对上游（如字节跳动）依赖度极高。AI营销、空间智能等新业务尚处于投入验证期，商业化规模有限，在行业巨头（如字节、腾讯）的挤压下，公司缺乏独特的护城河，技术迭代与市场竞争风险显著。
