# 002712.SZ 深度透视

## 因果逻辑链
- **[数字营销行业竞争加剧]** -> [毛利率持续下滑]: 为稳固客户黏性，公司适度提高客户服务折扣，叠加上游媒体采购成本走高，上下游盈利空间同步承压，导致整体毛利率逐年下滑。
- **[营收增长但净利润亏损扩大]** -> [增收不增利]: 2025年营收同比增长24.28%至76.76亿元，但归母净利润亏损扩大70.85%至-5,827万元，主要因低毛利数字营销业务占比超90%，且文旅新业务尚未形成规模利润。
- **[影视内容行业景气度偏弱]** -> [资产减值损失]: 受市场观影及内容播出需求不及预期影响，公司对存量影视剧投资计提资产减值损失449.47万元。
- **[版权资产运营效益偏弱]** -> [无形资产减值]: 版权市场化授权流转不理想，基于谨慎性原则，计提版权相关无形资产减值795.35万元。
- **[经营性现金流显著改善]** -> [应收账款精细化管理]: 公司持续加强应收账款管理，推动周转效率提升、账期缩短，2025年经营活动现金流净额较上年增长96.04%，但仍为负值。
- **[新传媒+新文旅双轮驱动]** -> [战略转型]: 公司正从传统营销服务商向“传媒+科技+文旅”融合发展模式转型，但文旅业务尚处前期布局阶段，收入占比极低，暂未形成业绩支撑。
- **[控股股东四川旅投赋能]** -> [资源协同]: 依托四川省旅游投资集团的文旅产业资源，公司加速布局西部文旅市场，但新业务落地存在周期长、资源整合要求高的风险。

## 风险警告
**核心风险：增收不增利的盈利困境。** 公司营收规模持续扩大，但净利润连续三年亏损且亏损额扩大。根本原因在于数字营销业务（占营收99.76%）毛利率被行业价格战和上游媒体成本持续挤压，而高毛利的文旅、影视内容等新业务尚处培育期，无法弥补主业的利润缺口。公司面临“规模越大，亏损越多”的恶性循环风险，若不能有效提升核心业务毛利率或加速新业务盈利，财务状况将持续恶化。

**关键风险：战略转型的不确定性。** 公司押注“传媒+文旅”第二增长曲线，但文旅业务从项目型向可持续营收型转变需要较长的市场培育周期和资源整合过程。同时，AIGC技术正深刻重构广告营销行业，若公司在AI营销工具研发、智能化服务能力构建上落后于竞争对手，将面临核心竞争力弱化、市场份额被挤压的风险。此外，公司未弥补亏损金额巨大（合并报表层面-9.34亿元），可能导致较长时间内无法实施现金分红。
