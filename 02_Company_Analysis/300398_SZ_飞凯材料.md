# 300398.SZ 深度透视

## 因果逻辑链
- **[AI算力与数据中心需求爆发]** -> [半导体材料业绩显著提升]: 下游HPC、存储芯片需求驱动先进封装材料出货量增长，公司深度切入2.5D/3D及HBM封装环节。
- **[收购JNC液晶业务]** -> [屏幕显示材料营收增长17.33%]: 并购捷恩智液晶材料及专利资产，补齐中小尺寸产品线，与大尺寸业务形成协同，市场份额扩大。
- **[光纤光缆行业景气度回升]** -> [紫外固化材料销量同步增长]: AI数据中心对低时延、高密度光纤需求激增，带动上游光纤涂覆材料用量，公司作为全球主要供应商受益。
- **[出售大瑞科技股权]** -> [获得较高投资收益]: 剥离非核心资产，聚焦国内锡球业务，资产优化贡献非经常性损益，增厚净利润。
- **[自主研发光引发剂TMO]** -> [有机合成材料竞争力提升]: 作为TPO的环保替代品，TMO拥有全球独家专利及欧盟REACH认证，受益于环保政策驱动的替代周期。
- **[可转债转股完成]** -> [资产负债率降至健康水平]: 财务结构优化，为后续“保现金流、精投资”战略提供安全边际，降低财务风险。
- **[持续研发投入与专利积累]** -> [巩固技术护城河]: 研发费用同比增长14.83%，累计拥有1142项专利（发明专利占比97%+），支撑多产品线技术领先。
- **[精细化运营与降本增效]** -> [费用控制成效明显]: 优化采销及生产流程，在营收增长10.56%的同时，有效控制成本，提升盈利水平。

## 风险警告
**核心风险在于下游需求周期性波动与产能消化压力。** 公司半导体及显示材料业务高度依赖AI算力投资、消费电子换机周期及面板行业景气度。若AI资本开支放缓或下游需求不及预期，可能导致订单减少、竞争加剧。同时，公司正推进多个大型在建项目（如年产3万吨半导体材料项目），若市场开拓不力或产品验证周期延长，新增产能无法有效消化，将面临投资回报不达预期的风险。

**另一关键风险是原材料价格波动与行业竞争加剧。** 公司主要原材料为基础化工原料及精细化学品，价格受国际油价、环保政策等影响较大，波动剧烈，直接冲击成本控制。此外，电子化学品行业国产替代加速，现有厂商扩产及国际同行进入使竞争日趋激烈。若公司不能持续技术创新、降低成本或精准把握客户需求，可能在价格战与技术封锁中面临市场份额下滑、盈利能力降低的风险。
