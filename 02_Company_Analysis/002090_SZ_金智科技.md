# 002090.SZ 深度透视

## 因果逻辑链
- **[智慧能源业务高增长]** -> [营收结构优化]: 智慧能源收入同比+16.25%，占比从53.57%升至70.75%，成为公司核心增长引擎，弥补了智慧城市业务的下滑。
- **[智慧城市业务大幅收缩]** -> [整体营收下滑]: 智慧城市收入同比-44.59%，主要因合并报表范围变更及行业环境影响，导致公司总营收同比下降11.97%。
- **[配用电自动化产品爆发]** -> [智慧能源增长主因]: 配用电自动化装置及系统收入同比+31.77%，受益于国家电网配电网投资及公司产品在区域集采中的高份额。
- **[应收账款高企与减值]** -> [利润侵蚀]: 应收账款余额8.11亿元，坏账准备1.87亿元，信用减值损失960万元，是扣非净利润下滑16.14%的主要原因之一。
- **[控制权变更]** -> [战略不确定性]: 2025年10月控股股东变更为南京智迪，公司由无实控人变为赵丹、肖明实控，新管理层战略落地效果待观察。
- **[经营活动现金流大幅下降]** -> [盈利质量隐忧]: 经营活动现金流净额同比-56.66%，远低于净利润，主要因购买商品支付现金增加及政府补助减少，显示回款压力。
- **[研发投入维持高位]** -> [技术护城河]: 研发费用1.45亿元，占营收9.27%，聚焦新型电力系统、AI应用等前沿领域，支撑长期竞争力。
- **[非经常性损益依赖]** -> [利润含金量低]: 归母净利润6602万元中，非经常性损益达2118万元（占比32%），主要来自金融资产公允价值变动及理财收益，主业盈利能力偏弱。

## 风险警告
**核心风险在于智慧城市业务的大幅萎缩与应收账款的高企。** 智慧城市收入腰斩（-44.59%），且公司主动控制该业务规模，表明该板块面临系统性压力。同时，应收账款余额高达8.11亿元，坏账准备计提比例超23%，经营活动现金流净额同比骤降56.66%，远低于净利润，显示公司回款能力恶化，盈利质量堪忧。若下游客户（尤其是地方政府）支付能力持续疲弱，坏账风险将进一步侵蚀利润。

**另一重大风险是新控股股东的战略不确定性。** 2025年10月公司控制权变更，新实控人赵丹、肖明背景与公司传统电力自动化主业关联度不高。新管理层提出的“聚焦电力电子新赛道”等战略能否有效落地，以及是否会进行大规模资产重组或并购，存在较大不确定性。此外，公司约7.27亿元的委托理财余额（占总资产23%），在利率下行环境下，其收益可持续性及本金安全也需警惕。
