# 300174.SZ 深度透视

## 因果逻辑链
- **[活性炭产销规模持续扩大]** -> [营收微增1.13%]: 活性炭销量15.18万吨创新高，但硅化物业务收入下滑13.07%，拖累整体增速。
- **[硅化物业务毛利率大幅下降]** -> [归母净利润同比下降19.78%]: 硅酸钠毛利率从17.95%降至11.10%，硅胶、白炭黑新产线尚处爬坡期，利润贡献不足。
- **[研发投入增长21.36%]** -> [新能源碳材料（超级电容炭、多孔碳）产业化加速]: 多孔碳产线建设推进，但短期增加费用，压制当期利润。
- **[增值税即征即退90%政策]** -> [其他收益4311万元]: 资源综合利用税收优惠是公司稳定的利润来源，占利润总额17.25%。
- **[“碳&硅”循环经济产业园建设]** -> [产业链协同降本]: 活性炭、硅酸钠、硅胶、白炭黑产线通过热、水、气循环利用，降低综合生产成本。
- **[募投项目产能释放滞后]** -> [在建工程1.61亿元，产能利用率96.36%]: 活性炭产能接近饱和，但新产能建设周期长，短期无法贡献增量。
- **[出口以美元结算]** -> [汇率波动影响业绩]: 境外收入占比15.59%，人民币兑美元升值将压缩出口利润。

## 风险警告
**核心风险在于“增收不增利”的困境。** 公司活性炭龙头地位稳固，但硅化物业务（硅酸钠、硅胶、白炭黑）面临原材料价格波动和激烈竞争，毛利率持续承压。新培育的新能源碳材料（多孔碳、硬碳）尚处产业化初期，研发投入高但短期难以贡献显著利润，导致整体盈利能力下滑。

**产能扩张与市场消化存在错配风险。** 公司通过可转债募资大规模扩产，但下游需求增速能否匹配新增产能存在不确定性。若宏观经济下行或环保政策执行力度不及预期，新增产能可能无法快速实现有效产出和批量销售，导致资产回报率下降。同时，国际贸易保护主义抬头和汇率波动，对海外业务构成潜在威胁。
