# 002664.SZ 深度透视

## 因果逻辑链
- **[新能源汽车驱动电机业务放量]** -> [净利润暴增534%]: 公司成功转型，新能源驱动电机定转子成为核心增长引擎，带动整体盈利能力大幅修复。
- **[电动车零部件业务量价齐升]** -> [营收增长22%]: 电动自行车轮毂电机等产品销量增加，成为收入增长的重要驱动力，弥补了传统汽车零部件业务的微降。
- **[传统汽车零部件业务承压]** -> [营收微降0.75%]: 行业进入存量竞争阶段，传统燃油车相关零部件业务增长乏力，但公司通过绑定头部客户维持了基本盘。
- **[人形机器人及低空经济布局]** -> [打造第二增长曲线]: 成立机器人公司，产品进入头部企业测试阶段；与大疆合作切入无人机电机领域，前瞻性布局新兴赛道。
- **[全球化产能扩张]** -> [资本开支与负债增加]: 投资建设泰国、匈牙利等海外基地，导致在建工程和长期借款增加，短期对现金流形成压力。
- **[资产减值损失大幅增加]** -> [侵蚀利润]: 报告期计提存货跌价准备8109万元，是利润总额的53.47%，反映出部分产品面临价格或需求下滑风险。
- **[财务费用激增]** -> [侵蚀利润]: 利息收入减少导致财务费用同比大增499%，对净利润产生负面影响。

## 风险警告
**核心风险在于新兴业务商业化不及预期与高额资本开支带来的财务压力。** 公司净利润暴增主要源于低基数效应，而非主营业务的强劲增长。人形机器人、低空经济等新业务尚处早期，商业化周期长、不确定性高，短期内难以贡献实质性利润。同时，公司为全球化布局（泰国、匈牙利建厂）持续进行大规模资本开支，导致长期借款高企、财务费用激增，若新业务无法如期贡献现金流，将加剧偿债风险。

**另一重大风险是传统主业增长乏力与资产减值压力。** 公司核心的汽车零部件业务营收微降，电动车零部件虽增长但毛利率为负，显示出“增收不增利”的困境。高达8109万元的存货跌价准备表明部分产品面临市场压力，若下游需求进一步放缓或原材料价格波动，公司可能面临更大的资产减值风险，持续侵蚀利润。
