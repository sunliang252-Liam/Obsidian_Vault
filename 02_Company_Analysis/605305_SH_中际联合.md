# 605305.SH 深度透视

## 因果逻辑链
- **[全球风电装机高景气]** -> [营收增长44.64%]: 2025年全球风电新增装机创历史新高，公司作为细分市场龙头，直接受益于下游需求爆发。
- **[外销收入占比突破50%]** -> [整体毛利率提升至47%]: 高毛利的外销业务（毛利率58.87%）占比提升至52%，拉动了公司整体盈利水平。
- **[产品结构升级（大载荷/齿轮齿条升降机）]** -> [高空安全升降设备毛利率提升1.96个百分点]: 顺应风机大型化趋势，高附加值产品占比提升，优化了产品盈利结构。
- **[销售费用率下降]** -> [净利润增速（+68.47%）远超营收增速]: 业务结构优化与销售团队整合，使销售费用同比下降10.88%，费用管控成效显著。
- **[研发投入聚焦与标准化]** -> [降本增效]: 通过材质创新和结构简化，在保证性能前提下降低单机成本，实现了毛利率的回升。
- **[“产品+服务”协同]** -> [客户粘性增强]: 完善的全球服务网络提供全生命周期服务，巩固了市场领先地位，并创造了持续的服务收入。
- **[非风电领域拓展]** -> [打造第二增长曲线]: 产品已拓展至电网、通信、消防等17个行业，能源安全系统解决方案等新品开始贡献收入，降低单一行业依赖。

## 风险警告
**核心风险在于对单一下游行业的深度依赖与国际贸易摩擦的叠加。** 公司97.85%的收入来自风电行业，业绩与全球风电政策、装机节奏高度绑定。尽管公司正努力拓展非风电领域，但短期内难以改变这一结构。同时，外销收入占比已超52%，中美贸易冲突、地缘政治风险及汇率波动，将直接冲击公司海外业务的盈利能力与市场拓展。

**其次，行业竞争加剧与客户集中度风险不容忽视。** 公司虽为细分市场龙头，但高毛利吸引新进入者，价格战可能侵蚀利润。此外，风电行业客户集中度较高，若主要客户减少采购或转向自研，将对公司经营产生重大不利影响。公司需持续通过技术创新和产品差异化来维持护城河。
