# 600566.SH 深度透视

## 因果逻辑链
- **[核心产品收入下滑]** -> [营收与利润双降]: 蒲地蓝消炎口服液、小儿豉翘清热颗粒受终端市场需求变化，销售收入同比减少，叠加雷贝拉唑钠肠溶胶囊受集采影响，导致2025年营收同比下降22.43%，归母净利润同比下降29.77%。
- **[产品结构高度集中]** -> [经营脆弱性加剧]: 蒲地蓝消炎口服液及小儿豉翘清热颗粒合计销售收入占主营业务收入约55.70%，单一产品波动即可显著影响公司整体盈利稳定性。
- **[集采政策深化]** -> [存量品种承压]: 国家集采常态化，雷贝拉唑钠肠溶胶囊等品种价格下行，公司消化类产品收入同比下降17.22%，显示存量品种面临持续的价格与市场挤压。
- **[研发管线推进]** -> [未来增长引擎]: 首个1类创新中药“小儿便通颗粒”提交上市申请，合作1类创新药“济可舒”获批，自主研发化药FH001进入临床，为中长期发展注入新动能，但短期无法贡献业绩。
- **[销售费用率维持高位]** -> [盈利空间受挤压]: 销售费用占营收比例高达33.94%，尽管同比下降28.55%，但绝对值仍超21亿元，高额推广投入是维持现有市场份额的必要成本，也限制了利润弹性。
- **[现金流大幅萎缩]** -> [财务稳健性下降]: 经营活动现金流净额同比下降44.94%，主要因销售回笼减少及应收保理、票据贴现现金流归集至筹资活动，显示收入质量与回款效率出现恶化。
- **[高分红政策]** -> [股东回报与再投资平衡]: 2025年拟每10股派发现金红利17.40元，现金分红比例高达89.94%，体现公司回馈股东意愿，但高分红也限制了用于研发与并购的内部资金积累。

## 风险警告
**核心产品依赖与集采冲击的双重绞杀。** 公司超过一半的收入来自蒲地蓝消炎口服液和小儿豉翘清热颗粒两个大单品，产品结构极度集中。在医保控费、集采扩围（尤其是中成药集采深化）的大背景下，这两个核心品种面临量价齐跌的长期风险。2025年业绩下滑已证实这一趋势，若核心品种市场地位被侵蚀，公司缺乏足够的第二增长曲线来对冲，业绩将面临持续下行压力。

**创新转型的“时间差”与高投入风险。** 公司正从传统中药企业向“中药+化药”创新转型，但创新药研发周期长、投入大、成功率低。当前在研管线中，多数项目仍处于临床早期或申报阶段，距离商业化放量尚有数年。在此期间，公司需持续承担高昂的研发费用（2025年研发投入3.93亿元），同时存量业务承压，若新药上市后市场推广不及预期或遭遇更激烈的竞争，将导致研发投入无法转化为有效回报，陷入“青黄不接”的困境。
