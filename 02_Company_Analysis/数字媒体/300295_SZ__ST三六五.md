# 300295.SZ 深度透视

## 因果逻辑链
- **[房地产市场深度调整]** -> [营收下滑12%]: 新房市场萎缩导致公司淘房业务收入承压，金服业务因利率下行和放贷规模缩减收入下降23.5%。
- **[房地产价格持续下跌]** -> [资产减值与公允价值损失]: 报告期末对在手房产和投资性房地产计提减值及公允价值变动损失合计约3357万元，是导致亏损的核心原因。
- **[金服业务放贷规模缩减]** -> [利息收入减少]: 公司主动压降与房产交易相关的贷款规模，叠加LPR下行，导致金服业务收入同比大幅下滑。
- **[AI技术投入与存量房转型]** -> [淘房业务扭亏为盈]: 通过AI Agent系统提升运营效率，并拓展存量房市场（如合肥乐屋试点），成功扭转了淘房业务的下滑趋势。
- **[金服业务风险暴露]** -> [信用减值损失]: 部分贷款对象违约逾期，导致公司计提信用减值损失约162万元，并引发多起诉讼。
- **[营收规模萎缩与费用刚性]** -> [持续亏损]: 尽管公司通过裁员和费用控制使管理费用下降19%，但营收下滑12%且资产减值损失巨大，导致净利润仍为负值。
- **[无控股股东结构]** -> [决策分散]: 第一大股东持股仅15%，公司无实际控制人，董事会决策由多方博弈形成，可能影响战略执行的效率与稳定性。

## 风险警告
公司面临的核心风险是**房地产市场的持续低迷**。公司业务高度依赖新房和存量房交易，若市场筑底时间超预期，其淘房和金服两大主业将同时承压。更关键的是，公司持有大量房产和投资性房地产，房价的进一步下跌将直接通过资产减值和公允价值变动侵蚀利润，这是当前亏损的最大来源，且短期内难以逆转。

其次，**金服业务的资产质量风险**不容忽视。公司发放贷款及垫款余额高达8.86亿元，但已计提减值准备1.19亿元。在宏观经济承压和行业监管趋严的背景下，贷款逾期和违约风险可能进一步暴露，导致信用减值损失持续扩大。同时，小贷行业监管新规出台，可能限制公司未来业务拓展空间。
