# 300987.SZ 深度透视

## 因果逻辑链
- **[独家地铁广告资源运营]** -> [营收增长7.2%]: 公司独家运营成都17条地铁线路广告资源，以场景运营为突破口，推动新媒体整合营销收入同比大增27.87%，成为营收增长的核心引擎。
- **[新旧动能转换期战略性投入增加]** -> [净利润下降13.33%]: 为构筑长期竞争力，公司加大研发（+115.56%）及新业务投入，导致期间费用上升，而新业务尚处成长期，利润贡献不足以覆盖投入及原有业务收缩的缺口。
- **[手机报业务受电信运营商依赖及行业变迁]** -> [移动信息服务收入下滑13.12%]: 手机报业务依赖运营商推广，且行业全面转向新媒体化、短视频化，导致付费用户数及收入持续萎缩。
- **[互动电视业务依赖单一运营商]** -> [互动电视收入骤降36.50%]: 业务主要与四川电信合作，受运营商市场政策变化及竞争加剧影响，收入大幅下滑。
- **[政府采购服务依赖]** -> [业绩存在不确定性]: 公司主要客户为四川省内党政机关及国企，政府采购服务的持续性是收入基本盘，但若政策或预算变化，将对业绩产生不确定性影响。
- **[募集资金项目屡次变更与终止]** -> [技术投入与战略落地滞后]: 因市场环境和技术迭代，公司已终止两个核心募投项目，仅剩的“川网云”项目进度缓慢（14.62%），反映公司技术转型与战略执行面临挑战。
- **[经营区域高度集中]** -> [增长天花板明显]: 公司100%收入来自四川地区，业务区域集中，限制了全国化扩张和抵御区域性风险的能力。

## 风险警告
**核心风险在于“新旧动能转换的阵痛期”过长。** 公司传统手机报和互动电视业务因行业变迁和运营商依赖而持续萎缩，虽通过独家地铁广告资源实现了营收增长，但该业务毛利率较低（25.11%），且需支付高昂的租赁费（年租金超1.6亿），对利润贡献有限。同时，公司为转型投入的研发和新业务尚未形成有效利润，导致“增收不增利”的局面短期难以扭转。

**战略执行风险突出。** 公司上市募投项目屡次变更，核心的“川网云”技术平台建设进度严重滞后，表明公司在技术迭代和战略落地方面能力不足。此外，公司业务高度集中于四川地区的党政客户，客户性质单一，若政府采购政策或预算发生变动，将对公司经营产生重大冲击。

**公司简介（F10 原文）**

> 四川新闻网传媒(集团)股份有限公司,是依托全国重点新闻网站四川新闻网组建的国有股份制企业,是四川省省级重点文化传媒产业集团,是以互联网技术和移动通信技术为支撑的新媒体企业,主营业务为信息传播服务业务。公司作为国务院新闻办批准的拥有网站登载新闻业务资质的互联网新闻信息服务单位,依托四川省内新闻资源,自主生产新闻内容,并通过PC终端、移动终端等全媒体渠道向用户提供新闻资讯。四川新闻网(www.newssc.org)由中共四川省委宣传部主管主办,于1999年1月正式上线,系全国首批省级重点新闻单位,四川省级主流媒体。网站已发展成为四川省最具影响力的综合性门户网站和重点新闻门户网站,在全省21个市州设立地方频道,提供最权威、最快捷、最全面的四川新闻和四川资讯,成为国内各大网站转载四川新闻的主要核心新闻源。2009年9月,中央外宣办确定四川新闻网为全国首批十家重点新闻网站转企改制试点单位之一,互联网信息传播业务发展获得新的动力;近年来,四川新闻网网站传播力一直处于省级新闻网站前列,在全国省级新闻网站综合传播力榜上排名持续位居全国前十,稳居四川省第一。
