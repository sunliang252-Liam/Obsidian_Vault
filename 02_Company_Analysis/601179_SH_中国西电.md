# 601179.SH 深度透视

## 因果逻辑链
- **[特高压及电网投资高景气]** -> [营收与利润双增]: 国家电网“十五五”投资规划大幅增长，公司作为特高压设备龙头，订单饱满，推动营收增长7.13%，利润总额创历史新高。
- **[变压器产品结构优化与成本管控]** -> [毛利率显著提升]: 变压器业务通过优化客户结构、强化集采和工艺改进，毛利率同比增加4.08个百分点，成为利润增长的核心引擎。
- **[海外市场大额订单交付]** -> [境外收入爆发式增长]: 公司系统重塑国际业务体系，推动智利Kilo等EPC项目履约，境外营收同比增长54.04%，成为第二增长曲线。
- **[研发投入高强度转化]** -> [技术壁垒与产品竞争力增强]: 研发费用同比增长48.39%，成功研制国际首套大容量800kV GIS等产品，巩固了行业技术领先地位和定价权。
- **[智慧产业基地投产]** -> [资产结构与生产效率优化]: 西电西安智慧产业基地落成，27条产线达L3级智能制造水平，固定资产大增48.81%，为未来降本增效奠定基础。
- **[财务费用大幅下降]** -> [利润增厚]: 受益于汇率变动及资金管理，财务费用由正转负，同比减少1.16亿元，直接贡献利润增量。

## 风险警告
**核心风险在于应收账款与信托投资的双重减值压力。** 公司应收账款原值超百亿，坏账准备7.75亿元，且信用减值损失同比激增至2亿元，反映出下游客户（尤其是电力工程类）回款周期拉长或信用风险暴露。更需警惕的是，早年投资的“海航系”信托产品6.9亿元本金至今仅账面价值2.29亿元，回收高度依赖重整计划执行，构成重大潜在损失敞口。

**第二重风险来自经营现金流恶化与海外业务的不确定性。** 尽管利润创新高，但经营活动现金流净额同比下滑21.68%，主因是采购付款增加，显示利润增长并未同步转化为现金，盈利质量需关注。同时，境外业务虽增长迅猛，但毛利率低于境内且同比下降，叠加汇率波动（衍生品对冲亏损0.37亿）及埃及子公司持续亏损（-1.66亿），海外扩张的盈利稳定性存疑。
