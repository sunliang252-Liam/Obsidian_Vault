# 300083.SZ 深度透视

## 因果逻辑链
- **[3C消费电子需求扩张]** -> [钻铣加工中心销量增长13.45%]: 公司拳头产品受益于下游手机、穿戴设备等结构件加工需求稳步提升，市场占有率稳居行业前列。
- **[新兴经济产业（AI液冷、机器人）爆发]** -> [通用领域业务多点开花]: 公司针对具身机器人、AI液冷等赛道推出定制化加工方案，切入高成长性赛道，有效拓展市场份额。
- **[存量设备更新周期与政策双轮驱动]** -> [营收增长15.53%]: 大量存量机床进入更新替换窗口，叠加大规模设备更新政策，形成“存量刚需托底、政策提速放量”格局。
- **[海外产能与渠道布局加速]** -> [海外业务收入增长88.26%]: 越南生产基地投产，实现从“产品出海”到“产能出海”的跨越，海外营收占比提升至7.34%。
- **[高强度研发投入]** -> [五轴高端机床实现批量交付]: 全年研发投入增长27.57%，围绕核心部件自主可控及整机性能优化，夯实高端市场技术壁垒。
- **[非经常性损益大幅波动]** -> [归母净利润下降39.63%]: 计提约3.72亿元诉讼赔偿款，导致净利润短期承压，但扣非净利润同比增长114.27%，主业盈利质量显著提升。

## 风险警告
**核心风险：重大诉讼执行风险。** 公司与北京精雕的知识产权纠纷案二审判决赔偿3.816亿元，目前案件已进入执行阶段，子公司部分银行账户及股权已被冻结。执行金额巨大且过程复杂，若无法妥善解决，将对公司现金流、正常经营及品牌声誉造成严重冲击，是当前最突出的不确定性因素。

**结构性风险：下游景气度波动与市场竞争加剧。** 公司业绩高度依赖3C消费电子及新能源汽车等下游行业的资本开支，若宏观经济下行或行业增速放缓，设备采购需求将大幅下降。同时，高端市场仍被海外品牌主导，中低端市场竞争白热化，公司若不能在技术迭代或成本控制上持续领先，市场份额与利润空间将面临双重挤压。此外，母公司及合并报表层面均存在巨额未弥补亏损，短期不具备现金分红能力。
