# 603789.SH 深度透视

## 因果逻辑链
- **[收购苏州电中、中城汽车，构建双主业]** -> [营收增长40.7%，但扣非净利仍巨亏]: 通过收购快速切入燃油喷射系统与专用车业务，扩大收入规模以规避退市，但新业务整合初期毛利率低，叠加农机主业亏损，导致营收增长未能转化为盈利。
- **[农事服务业务收入确认违规，被证监会立案]** -> [财务数据追溯调整，面临退市风险]: 2023年农事服务业务存在资金回流、无商业实质的收入，导致前期会计差错更正，公司被立案调查并收到《行政处罚决定书》，严重损害公司信誉与合规性。
- **[连续8年扣非净利润为负，经营性现金流持续流出]** -> [持续经营能力存在重大不确定性]: 核心主业盈利能力枯竭，无法通过自身经营产生正向现金流，依赖关联方借款和资产出售维持运营，审计报告因此出具“与持续经营相关的重大不确定性”段落。
- **[高额应收账款与存货减值]** -> [资产减值损失侵蚀利润]: 应收账款坏账准备与存货跌价准备合计超4400万元，反映出下游客户信用恶化及产品滞销，是导致亏损的重要因素。
- **[关联交易依赖与同业竞争承诺]** -> [业务独立性存疑，潜在利益输送风险]: 前五大客户/供应商中关联方占比高（如中城工业），且收购中城汽车后存在同业竞争问题，虽有关注入承诺，但执行过程与公允性需持续关注。
- **[资产负债率高达79.61%，净资产大幅缩水]** -> [财务杠杆高企，偿债压力巨大]: 净资产从2023年的4.14亿骤降至2025年的1.37亿，资产负债率逼近80%，叠加融资能力受限，公司面临严峻的流动性危机。

## 风险警告
**核心风险在于持续经营能力。** 公司扣非净利润已连续8年为负，2025年经营活动现金流净流出9232万元，造血功能基本丧失。当前生存完全依赖关联方借款（期末关联方资金拆入余额8635.8万元）和资产处置收益（2025年非流动资产处置收益7800万元）。一旦外部输血中断或资产处置受阻，公司将立即面临资金链断裂风险。审计报告已明确提示“持续经营重大不确定性”，这是最根本的警报。

**合规与退市风险是悬顶之剑。** 公司因财务造假被证监会立案并处罚，内控审计报告被出具带强调事项段的无保留意见。虽然2025年营收勉强超过3亿元红线，但若未来监管认定其收入确认仍存在问题，或再次触发财务类退市指标，退市将不可避免。此外，新收购的专用车业务与控股股东存在同业竞争，若5年内无法妥善解决，也将成为重大隐患。投资者需警惕其“保壳”动作背后的真实业务质量。
