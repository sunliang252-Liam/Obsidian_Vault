# 000932.SZ 深度透视

## 因果逻辑链
- **[原燃料成本大幅下降]** -> [净利润逆势增长28.49%]: 炼焦煤、焦炭采购成本同比暴跌超28%，远大于钢价9%的跌幅，释放了巨大的利润空间。
- **[品种钢占比提升至68.5%]** -> [毛利率显著改善]: 高端产品（如汽车板、硅钢、海工钢）占比持续提升，推动板材毛利率同比大增4.18个百分点，对冲了销量下滑的影响。
- **[汽车板公司（VAMA）高盈利]** -> [核心利润贡献]: VAMA净利润达19.7亿元，占公司总净利润的50%以上，成为业绩的“压舱石”，受益于高端汽车轻量化需求。
- **[资产负债率降至53.46%]** -> [财务费用大幅降低62.77%]: 持续降杠杆使有息债务规模下降，财务费用仅3266万元，为历史低位，显著增厚了利润。
- **[自发电量创新高]** -> [能源成本持续优化]: 全年自发电量达100亿kWh，同比增加3.33亿kWh，有效对冲了外购能源价格波动，降低了吨钢生产成本。
- **[非主流矿使用比例提升至55.6%]** -> [采购成本竞争力增强]: 拓展多元化铁矿石资源渠道，降低了对主流高价矿的依赖，在矿价波动中获得了成本优势。

## 风险警告
**核心风险在于行业供需格局的持续恶化与公司盈利能力的脆弱性。** 尽管2025年利润大增，但营收同比下降15.94%，钢材销量下降10.58%，表明增长完全依赖成本改善而非需求扩张。一旦上游原燃料价格反弹，或下游造船、能源等高景气领域需求转弱，公司利润将面临巨大压力。此外，公司补缴环保税滞纳金等非经常性损失，暗示环保合规成本可能超预期。

**另一重大风险是贸易保护主义与出口环境恶化。** 公司出口业务占比8.3%，且面临“量增价跌”态势。欧盟碳边境调节机制（CBAM）及全球贸易摩擦加剧，将直接冲击公司钢材出口的竞争力和利润空间。同时，公司高达14.42%的关联采购比例，也隐含了关联交易定价不公允及治理风险。
