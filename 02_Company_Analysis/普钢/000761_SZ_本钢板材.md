# 000761.SZ 深度透视

## 因果逻辑链
- **[行业需求萎缩与价格下行]** -> [连续三年巨额亏损]: 钢铁行业进入减量提质周期，国内粗钢表观消费量同比下降7.1%，钢材价格指数(CSPI)全年平均值同比下降9.1%，公司营收同比下降9.51%，导致归母净利润亏损39.4亿元。
- **[毛利率持续为负]** -> [主营业务造血能力枯竭]: 公司整体毛利率为-4.42%，钢板产品毛利率为-4.56%，产品售价已低于生产成本，每卖一吨钢都在亏损。
- **[经营活动现金流大幅转负]** -> [现金流危机加剧]: 经营活动现金流量净额从2024年的+11亿元骤降至2025年的-17.9亿元，降幅达262.58%，表明公司已无法通过主营业务产生正向现金流。
- **[高额财务费用侵蚀利润]** -> [债务负担沉重]: 财务费用同比暴增78.09%至4.28亿元，主要受汇兑损失影响，叠加有息负债规模庞大，资产负债率持续攀升。
- **[关联交易依赖度高]** -> [盈利能力受制于集团内部定价]: 前五名供应商采购额中关联方采购额占比高达40.56%，前五大客户中关联方销售占比6.51%，公司经营自主性和利润空间受集团内部交易影响显著。
- **[资产减值损失持续扩大]** -> [资产质量恶化]: 报告期内计提资产减值损失3.04亿元，主要为存货跌价准备，反映下游需求疲软导致产品库存贬值。
- **[净资产大幅缩水]** -> [偿债能力与股东权益受损]: 归属于上市公司股东的净资产同比下降33.24%至79.36亿元，母公司累计未分配利润为-114.39亿元，已严重侵蚀股东权益。

## 风险警告
本钢板材已陷入深度经营危机。连续三年巨额亏损，2025年归母净利润亏损39.4亿元，且亏损幅度虽有收窄但绝对值仍巨大。核心问题是主营业务毛利率为负（-4.42%），意味着公司每生产销售一吨钢材都在亏损，完全丧失自我造血能力。更危险的是，经营活动现金流净额由正转负，从2024年的11亿元骤降至-17.9亿元，表明公司已无法通过经营产生现金，必须依赖外部融资维持生存。

财务风险已逼近临界点。净资产一年内缩水三分之一，母公司未分配利润亏损高达114亿元，资产负债率持续攀升。财务费用因汇兑损失暴增78%，进一步加重了本已沉重的债务负担。公司对鞍钢集团体系内的关联交易依赖度极高（采购端关联方占比超40%），在集团内部资源调配中处于弱势地位，盈利能力受制于人。若钢铁行业需求持续低迷，公司面临流动性枯竭和债务违约的极端风险。
