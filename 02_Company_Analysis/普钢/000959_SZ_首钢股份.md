# 000959.SZ 深度透视

## 因果逻辑链
- **原燃料成本下降** -> **利润大幅修复**: 铁矿石、焦煤等采购成本同比显著下降，对冲了钢材价格下跌，使归母净利润同比大增107.68%。
- **高端产品结构优化** -> **盈利韧性增强**: 电工钢、汽车板、镀锡板三大战略产品产量同比增长约11%，高附加值产品占比提升，有效抵御了普钢价格下行压力。
- **财务费用压降** -> **利润增厚**: 通过压降有息负债规模及利率下行，财务费用同比减少33%，直接贡献了利润弹性。
- **行业自律与供给收缩** -> **供需格局改善**: 国内粗钢产量同比下降4.4%，行业恶性竞争缓解，重点钢企利润总额同比增长1.4倍，公司受益于行业整体盈利修复。
- **下游需求结构分化** -> **高端制造拉动**: 新能源汽车、风电等新质生产力领域快速发展，带动公司电工钢（新能源汽车用产品产量+28%）、汽车板（新能源车用产品+34%）等高端产品需求旺盛。
- **极致能效与降本增效** -> **成本竞争力提升**: 铁水温降、配煤配矿等全流程降本措施持续见效，铁、钢工序成本持续降低，在行业低谷期维持了毛利率的稳定。
- **绿色低碳与ESG领先** -> **品牌溢价与客户粘性**: 全流程超低排放、低碳产品价格体系及高ESG评级（华证AAA），帮助公司获得头部车企“绿钢”订单，形成差异化竞争优势。

## 风险警告
**核心风险在于行业供需格局的长期脆弱性。** 尽管2025年利润大幅反弹，但驱动因素主要来自成本端的周期性回落，而非需求端的根本性好转。国内粗钢产能依然庞大，下游房地产、基建用钢需求持续偏弱，钢材价格指数（CSPI）同比下降9.05%，表明行业“供强需弱”的底色未变。一旦上游原燃料价格反弹，公司利润将被迅速侵蚀，盈利可持续性存疑。

**另一重大风险是关联交易与同业竞争的历史包袱。** 公司与控股股东首钢集团存在大量关联采购与销售（前五大供应商中关联方采购额占比高达62.36%），且集团层面仍存在未注入上市公司的钢铁资产，同业竞争承诺的履行进度缓慢。这种复杂的利益格局不仅增加了公司治理的透明度风险，也限制了公司通过市场化并购整合实现外延式增长的空间。
