# 600307.SH 深度透视

## 因果逻辑链
- **[行业需求萎缩与钢价下行]** -> [营收与利润双降]: 2025年国内房地产用钢需求持续探底，基建托底有限，CSPI钢材价格指数同比下降9.1%，公司营收同比下滑12.25%，归母净利润亏损19.98亿元。
- **[自有矿山低成本优势]** -> [部分对冲成本压力]: 镜铁山矿输出铁矿石972.55万吨，在进口矿价高企背景下，自有矿源有效降低了生铁成本，使钢铁产品毛利率同比提升3.88个百分点。
- **[大规模资本开支与产能升级]** -> [资产结构重型化与债务攀升]: 炼轧厂、焦炉、烧结机等“三化”改造项目集中转固，固定资产同比大增30.28%，同时长期借款增加32.32%，财务费用因带息负债总额增加而上升3.28%。
- **[关联方依赖与资金占用]** -> [现金流承压]: 前五名供应商采购额中关联方占比48.37%，为保证原燃料供应增加现汇付款比例，导致经营活动现金流净额由正转负，为-4.3亿元。
- **[产品结构向高端调整]** -> [品种钢盈利能力改善]: 风电板、核电用钢、因瓦合金等高端产品销量增长，板带材毛利率同比提升8.99个百分点至10.86%，部分弥补了建材类产品的亏损。
- **[环保与碳约束趋严]** -> [持续资本投入]: 公司推进超低排放改造，本部及榆钢完成清洁运输评估公示，环保投入增加，递延收益（政府补助）同比增加106.75%，但长期运营成本承压。

## 风险警告
**核心风险在于持续亏损侵蚀净资产与高负债率下的流动性压力。** 公司已连续三年大额亏损（2023-2025年累计亏损超56亿元），未分配利润赤字高达-89.25亿元，净资产从2023年的101.4亿元骤降至54.67亿元，降幅达46%。与此同时，总负债攀升至454.19亿元，资产负债率高达89.26%，短期借款与一年内到期非流动负债合计超134亿元，而货币资金仅24.22亿元（其中受限资金12.6亿元），短期偿债能力极度脆弱。

**经营层面，公司面临“需求萎缩与成本刚性”的双重挤压。** 西北地区基建与地产投资放缓，建筑用钢（线棒材）占公司产量比重高达65%，结构性风险突出。尽管自有矿山提供一定成本缓冲，但铁矿石、焦煤等核心原料价格受海外供给影响波动剧烈，公司对关联方采购依赖度高（占采购总额48.37%），议价能力受限。此外，与日本制铁的专利诉讼虽已终审胜诉，但后续仍存在其他潜在知识产权纠纷风险。
