# 600307.SH 深度透视

## 因果逻辑链
- **[行业需求萎缩与钢价下行]** -> [营收与利润双降]: 2025年国内房地产用钢需求持续探底，基建托底有限，CSPI钢材价格指数同比下降9.1%，公司营收同比下滑12.25%，归母净利润亏损19.98亿元。
- **[自有矿山低成本优势]** -> [部分对冲成本压力]: 镜铁山矿输出铁矿石972.55万吨，在进口矿价高企背景下，自有矿源有效降低了生铁成本，使钢铁产品毛利率同比提升3.88个百分点。
- **[大规模资本开支与产能升级]** -> [资产结构重型化与债务攀升]: 炼轧厂、焦炉、烧结机等“三化”改造项目集中转固，固定资产同比大增30.28%，同时长期借款增加32.32%，财务费用因带息负债总额增加而上升3.28%。
- **[关联方依赖与资金占用]** -> [现金流承压]: 前五名供应商采购额中关联方占比48.37%，为保证原燃料供应增加现汇付款比例，导致经营活动现金流净额由正转负，为-4.3亿元。
- **[产品结构向高端调整]** -> [品种钢盈利能力改善]: 风电板、核电用钢、因瓦合金等高端产品销量增长，板带材毛利率同比提升8.99个百分点至10.86%，部分弥补了建材类产品的亏损。
- **[环保与碳约束趋严]** -> [持续资本投入]: 公司推进超低排放改造，本部及榆钢完成清洁运输评估公示，环保投入增加，递延收益（政府补助）同比增加106.75%，但长期运营成本承压。

## 风险警告
**核心风险在于持续亏损侵蚀净资产与高负债率下的流动性压力。** 公司已连续三年大额亏损（2023-2025年累计亏损超56亿元），未分配利润赤字高达-89.25亿元，净资产从2023年的101.4亿元骤降至54.67亿元，降幅达46%。与此同时，总负债攀升至454.19亿元，资产负债率高达89.26%，短期借款与一年内到期非流动负债合计超134亿元，而货币资金仅24.22亿元（其中受限资金12.6亿元），短期偿债能力极度脆弱。

**经营层面，公司面临“需求萎缩与成本刚性”的双重挤压。** 西北地区基建与地产投资放缓，建筑用钢（线棒材）占公司产量比重高达65%，结构性风险突出。尽管自有矿山提供一定成本缓冲，但铁矿石、焦煤等核心原料价格受海外供给影响波动剧烈，公司对关联方采购依赖度高（占采购总额48.37%），议价能力受限。此外，与日本制铁的专利诉讼虽已终审胜诉，但后续仍存在其他潜在知识产权纠纷风险。

> 甘肃酒钢集团宏兴钢铁股份有限公司位于甘肃省嘉峪关市,始建于1958年,是新中国规划建设的第四个钢铁工业基地,也是我国在西北地区建设最早、规模最大、黑色与有色并举的多元化现代企业集团。历经60多年发展,酒钢集团已构建起以钢铁、有色和电力能源为主业,现代农业、生产生活服务业辅助的多元化协同发展格局。钢铁产业具备年产粗钢1047.5万吨的生产能力;有色产业形成年产电解铝170万吨、铝板带材71万吨的生产能力;电力能源产业形成6158MW的自备发电容量。钢铁产业拥有镜铁山矿和西沟石灰石矿两座矿山,形成了从采、选、烧、焦到铁、钢、轧完整配套的碳钢和不锈钢现代化工艺生产线,主要装备达到国内先进和西北领先水平。主要产品有碳钢系列的中厚板、热轧卷板、冷轧板、镀锌板、合金镀层板以及不锈钢系列的热轧卷板、冷轧薄板、中厚板等400多个品种。高附加值产品供应新能源、石油石化、核工业、航空航天、家电、汽车、电子等中高端领域。有色产业拥有嘉峪关、定西两个电解铝生产基地,嘉宇新材料、嘉信新材料两个铝材精深加工基地,牙买加阿尔帕特氧化铝生产基地,建有240kA、400kA、500kA多条大型电解铝生产线,是甘肃省最大的铝冶炼加工企业。同时,自备矿山保有铜矿石资源量1003万吨,年产铜精矿1.8万吨。电力能源产业拥有42台(套)自备火力及余能回收发电机组,159座6kV到330kV变电站、输配电网及相应的电力传导设施,总装机容量达6158MW,其中新能源装机容量2476MW,占比40%,初步形成风光火余能余压多能互补和源网荷一体化的新型电力系统,为集团公司钢铁、有色等产业提供电力支撑,同时承担了嘉峪关市2100万平方米和酒泉肃州区800万平方米冬季供热。现代农业建立了20万亩稳定的制种基地和国内一流的大型种子加工生产线,具备完善的种子质量控制体系,拥有以玉米杂交种为主的各类农作物种子的研发、繁育、加工(6万吨/年)和销售能力,牵头组建甘肃省玉米种业研究院,建成“一院六站”商业化育种体系,建立了覆盖全国不同生态区的市场营销网络。生产生活服务业主要包括装备制造、物流商贸、工程技术、循环经济、金融服务、酒业乳业、房产物业、酒店餐饮、医疗卫生、教育培训等在酒钢60多年发展历程中逐步形成的业态。其中物流公司管理运营铁路线路总延长856公里(嘉策铁路全长552公里);祁牧乳业公司被国务院国资委确定为全国“科改示范企业”;酒钢医院获评“三级甲等”综合医院。在酒钢60余年的发展历程中,形成了“艰苦创业、坚韧不拔、勇于献身、开拓前进”的“铁山精神”,被原冶金部列为全国冶金系统树立和推广的六大企业精神之一。以“铁山精神”为核心,形成了以“世界一流绿色新材料企业”为愿景、“服务国家战略,推动区域发展”为使命、“奋斗创造美好”为价值观的企业文化。
