# 601686.SH 深度透视

## 因果逻辑链
- **[行业龙头地位与规模效应]** -> [逆势增长]: 在行业需求萎缩、价格下跌背景下，公司凭借2000万吨级产能和全国布局，产销量基本持平，市场份额逆势提升，龙头地位强化。
- **[成本加成定价与原材料价格下跌]** -> [毛利率提升]: 钢材价格下跌导致产品售价下降，但成本降幅更大（-7.82% vs -7.57%），叠加成本加成模式，毛利率同比增加1.02个百分点。
- **[非经常性损益（投资沐曦股份）]** -> [净利润大幅增长60%]: 通过基金间接投资沐曦股份，确认公允价值变动收益约1.19亿元，是归母净利润从4.24亿跃升至6.80亿的核心增量。
- **[财务费用大幅下降]** -> [利润增厚]: 银行借款减少及保证金利息增加，财务费用同比减少83.17%，直接贡献利润约5800万元。
- **[并购扩张与全国布局]** -> [未来增长潜力]: 收购吉林华明（补东北）、河北海乾威（进油气管道），在建3个基地，产能布局完善，为未来销量和品类扩张奠定基础。
- **[高周转与低库存策略]** -> [经营风险控制]: 面对价格波动，公司控制原料和产品库存，加快周转，并利用期货套保对冲风险，稳定赚取加工利润，避免价格暴跌带来的存货减值风险。
- **[“军团”模式与终端深耕]** -> [营销转型]: 针对水利、建筑、钢结构等细分行业建立专业团队，推动直销增长（+8.43%），提升终端服务能力，对冲传统经销渠道下滑。

## 风险警告
**核心风险在于利润质量高度依赖非经常性损益。** 2025年归母净利润6.80亿中，非经常性损益高达2.04亿，其中投资沐曦股份的公允价值变动收益约1.19亿元，占净利润的17.5%。剔除该影响后，扣非净利润仅4.76亿，同比增长48.6%，但仍低于表观增速。若沐曦股份股价回调，将直接冲击公司利润，投资者需警惕“一次性收益”的不可持续性。

**行业需求持续萎缩与原材料价格波动是长期经营隐患。** 公司主营焊接钢管，下游房地产、基建需求疲软，2025年全国焊管产量和表观消费量双降，行业处于存量竞争。虽然公司凭借龙头地位实现份额提升，但若宏观经济进一步下行，需求收缩将压制销量和加工利润。同时，原材料（带钢、锌锭）成本占比超90%，价格剧烈波动会考验公司的成本传导和库存管理能力，套期保值也无法完全消除风险。
