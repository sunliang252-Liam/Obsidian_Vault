# 000717.SZ 深度透视

## 因果逻辑链
- **[行业需求萎缩]** -> [营收下降16.18%]: 房地产用钢需求持续下行，基建及制造业增长难以完全对冲，导致公司钢材销量同比下降7.9%，营收降至261.31亿元。
- **[成本端改善]** -> [亏损幅度收窄4.17%]: 煤炭等原料价格下行，叠加公司“算账经营”降本增效，营业成本同比下降19%，使净亏损从-12.04亿收窄至-11.54亿。
- **[产品结构优化]** -> [盈利能力韧性]: 优种钢、板材占比提升，高端产品销量同比增长39.6%和68.2%，部分对冲了普钢价格下跌对利润的侵蚀。
- **[资产减值损失]** -> [巨额亏损]: 计提资产减值准备10.77亿元，占利润总额的98.12%，是导致公司连续第二年大额亏损的直接原因。
- **[经营现金流改善]** -> [财务稳健]: 经营活动现金流净额14.96亿元，同比增长14.62%，与净利润-11.54亿元形成巨大反差，主要源于大额折旧和减值等非现金支出。
- **[区位与协同优势]** -> [市场地位]: 作为广东省本土钢厂，依托宝武生态圈，建材、工业线材、中厚板在广东地区市占率分别达19.2%、19.0%、18.7%，具备区域品牌护城河。
- **[出口激增]** -> [对冲内需疲软]: 海外渠道建设成效显著，坯材直接出口量突破36.4万吨，国外收入同比增长371.77%，成为消化国内过剩产能的关键渠道。

## 风险警告
公司连续两年大额亏损，净资产收益率-15.74%，盈利能力已严重恶化。核心风险在于行业供需矛盾长期尖锐，房地产用钢需求未见底，而公司产品同质化严重、成本劣势明显（全国煤炭采购物流费用最高之一），在“减量发展”趋势下，建材产能压缩将导致轧线负荷下降，进一步推高单位成本。10.77亿的资产减值损失暴露了公司资产质量承压，未来若钢价持续低迷，减值风险仍存。

公司对宝武集团生态圈依赖度极高，前五名供应商采购额中关联方占比36.17%，前五名客户销售额中关联方占比21.50%。这种深度绑定虽带来协同效应，但也削弱了公司经营的独立性。同时，公司已连续两年未进行现金分红，且2026年经营目标（营收256亿）较2025年继续下滑，表明管理层对行业前景持悲观预期，投资者回报前景黯淡。
