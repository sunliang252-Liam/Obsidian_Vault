# 000717.SZ 深度透视

## 因果逻辑链
- **[行业需求萎缩]** -> [营收下降16.18%]: 房地产用钢需求持续下行，基建及制造业增长难以完全对冲，导致公司钢材销量同比下降7.9%，营收降至261.31亿元。
- **[成本端改善]** -> [亏损幅度收窄4.17%]: 煤炭等原料价格下行，叠加公司“算账经营”降本增效，营业成本同比下降19%，使净亏损从-12.04亿收窄至-11.54亿。
- **[产品结构优化]** -> [盈利能力韧性]: 优种钢、板材占比提升，高端产品销量同比增长39.6%和68.2%，部分对冲了普钢价格下跌对利润的侵蚀。
- **[资产减值损失]** -> [巨额亏损]: 计提资产减值准备10.77亿元，占利润总额的98.12%，是导致公司连续第二年大额亏损的直接原因。
- **[经营现金流改善]** -> [财务稳健]: 经营活动现金流净额14.96亿元，同比增长14.62%，与净利润-11.54亿元形成巨大反差，主要源于大额折旧和减值等非现金支出。
- **[区位与协同优势]** -> [市场地位]: 作为广东省本土钢厂，依托宝武生态圈，建材、工业线材、中厚板在广东地区市占率分别达19.2%、19.0%、18.7%，具备区域品牌护城河。
- **[出口激增]** -> [对冲内需疲软]: 海外渠道建设成效显著，坯材直接出口量突破36.4万吨，国外收入同比增长371.77%，成为消化国内过剩产能的关键渠道。

## 风险警告
公司连续两年大额亏损，净资产收益率-15.74%，盈利能力已严重恶化。核心风险在于行业供需矛盾长期尖锐，房地产用钢需求未见底，而公司产品同质化严重、成本劣势明显（全国煤炭采购物流费用最高之一），在“减量发展”趋势下，建材产能压缩将导致轧线负荷下降，进一步推高单位成本。10.77亿的资产减值损失暴露了公司资产质量承压，未来若钢价持续低迷，减值风险仍存。

公司对宝武集团生态圈依赖度极高，前五名供应商采购额中关联方占比36.17%，前五名客户销售额中关联方占比21.50%。这种深度绑定虽带来协同效应，但也削弱了公司经营的独立性。同时，公司已连续两年未进行现金分红，且2026年经营目标（营收256亿）较2025年继续下滑，表明管理层对行业前景持悲观预期，投资者回报前景黯淡。

**公司简介（F10 原文）**

> 广东中南钢铁股份有限公司(2022年10月22日由韶钢松山更名,以下简称“中南股份”或“公司”)是宝武集团中南钢铁有限公司控股子公司,位于广东省韶关市曲江区。公司于1997年在深圳证券交易所挂牌上市,是中国宝武集团在广东省重要的钢铁制造基地之一。产品主要包括特棒、工业线材、建筑材、板材,广泛应用于汽车、机械制造、能源交通、航天航空、核电等行业。公司先后获评国家工信部“绿色工厂”、国家3A级旅游景区和广东省知识产权示范企业称号,被认定为国家高新技术企业,拥有省级企业技术中心和省级重点工程技术研究开发中心,设立了国家级博士后科研工作站和广东省博士工作站。近年来,公司坚持以习近平新时代中国特色社会主义思想为指导,深入贯彻落实习近平总书记关于做强做优做大国有企业的重要指示精神,坚决贯彻落实习近平总书记考察调研中国宝武和广东省重要讲话和指示批示精神,坚持走“高端化、智能化、绿色化、高效化”高质量发展之路。立足新发展阶段,贯彻新发展理念,构建新发展格局,公司深入推进“三高两化”,坚持宝武集团“四化”“四有”经营方针,强化算账经营和精益运营,构建极致高效、极致成本、绿色低碳、创新引领的钢铁基地。持续深化改革创新,发挥钢铁产业链链长优势,不断提升制造体系能力,全面开创转型升级高质量发展新局面。品牌介绍“韶钢牌”注册于1981年,其产品以其钢质纯净、化学成分稳定、外形尺寸精确、力学及工艺性能良好、表面光洁等特点获得了广大用户和社会的充分认可,在广东省及周边地区、港澳地区和东南亚市场上享有良好声誉,是广大用户心中的首选品牌,具有明显的品牌效益,多次获得全国冶金产品实物质量“金杯奖”、广东省名牌产品、全国用户满意产品等称号,并先后通过了北京中冶检测认证公司冶金产品认证(中冶MC认证)等专业认证。产品广泛用于高层建筑、桥梁、高速公路、地铁、管桩、隧道、核电等项目,为广州东塔、港珠澳大桥、广乐高速、汕昆高速、龙怀高速、深圳地铁、阳江核电、太平岭核电等许多大型工程建设提供产品供应,用户使用评价很高。
