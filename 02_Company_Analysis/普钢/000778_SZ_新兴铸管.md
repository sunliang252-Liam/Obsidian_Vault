# 000778.SZ 深度透视

## 因果逻辑链
- **[成本端改善]** -> [净利润暴增466%]: 铁矿石、煤焦等原燃料价格大幅下跌，成本降幅（-5.7%）大于收入降幅（-4.7%），毛利率从5.40%提升至7.69%。
- **[产品结构升级]** -> [优特钢销量增长25%]: 主动调整产品结构，优特钢销量占比从25%提升至28%，高利润钢种占比提升至61.5%，对冲普钢需求下滑。
- **[铸管龙头地位]** -> [销量逆势增长5.88%]: 全球最大球墨铸铁管生产商，凭借技术壁垒和品牌优势，在基建投资放缓背景下，国内公开市场中标率提升1.6个百分点。
- **[国际化布局]** -> [出口铸管增长7.8%]: 埃及25万吨项目投产，开创“技术输出+本地化运营”模式，巩固国内出口铸管70%份额，打开中东、非洲增量市场。
- **[精细化管控]** -> [物流费用压降13元/吨]: 组建两级算账专班，拉通“产供销运”全链条算账，铁水、螺纹钢成本站稳行业第一阵营，实现降本增效。
- **[现金流改善]** -> [经营现金流净额增长394%]: 净利润大幅增长叠加营运资金管理优化，销售商品收到的现金增加，经营活动现金流净额达35.3亿元。
- **[资产减值收窄]** -> [利润修复]: 2024年计提大额资产减值损失3.77亿元，2025年减值损失降至0.3亿元，同比减少92%，显著增厚利润。

## 风险警告
**核心风险在于钢铁主业需求的结构性萎缩。** 公司近半收入仍来自普钢和优特钢，而建筑和房地产行业深度调整，新开工面积持续双位数下降，普钢销量同比下滑8.65%。虽然优特钢增长部分对冲，但若制造业用钢需求转弱，公司盈利将面临巨大压力。此外，公司持有际华集团（601718）股票，2025年公允价值变动损失高达9.8亿元，直接侵蚀净资产，金融资产波动风险不容忽视。

**国际化与转型的不确定性。** 埃及项目虽已投产，但海外经营面临地缘政治、汇率波动及当地政策变化等风险，达产达效仍需时间。公司向“管网综合服务商”转型，智慧水务、储能等新业务尚处培育期，短期内难以贡献实质性利润，转型投入可能持续拖累现金流。同时，公司资产负债率44%，有息债务规模较大，利息费用超3.2亿元，若利率上行将加重财务负担。
