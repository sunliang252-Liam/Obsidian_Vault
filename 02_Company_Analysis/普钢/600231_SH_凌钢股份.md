# 600231.SH 深度透视

## 因果逻辑链
- **[行业供需失衡，钢价持续下行]** -> [营收与毛利承压]: 2025年钢材综合价格指数同比下降5.6%，公司营业收入同比下降13.46%，主营业务毛利率为-6.66%，陷入全面亏损。
- **[“去螺增优”战略，产品结构优化]** -> [优特钢占比提升]: 公司彻底停产螺纹钢，全年优特钢材占比提升至69.3%，圆钢、带钢实现双增优，以高附加值产品对冲普钢需求下滑。
- **[鞍凌重组协同，采购降本显著]** -> [成本管控改善]: 通过优化配矿结构、调整运输渠道，吨钢综合采购价格比上年降低231元，生铁成本分位值从30分位提升至最高77分位。
- **[高炉装备升级，产能置换完成]** -> [长期竞争力提升]: 新建2290m³高炉于2025年5月投产，淘汰落后产能，为未来高效、低成本生产奠定基础。
- **[财务费用激增，现金流恶化]** -> [资金链承压]: 为满足经营和投资需求增加借款，财务费用同比大增111.96%；经营活动现金流净额为-1.63亿元，连续两年为负。
- **[资产负债率攀升，净资产大幅缩水]** -> [财务风险加剧]: 资产负债率从63.11%升至73.98%，归属于上市公司股东的净资产同比减少28.57%，未分配利润由正转负，侵蚀股东权益。
- **[关联交易高度集中]** -> [经营独立性存疑]: 前五名供应商采购额占比60.52%，其中关联方采购额占比高达47.60%，对控股股东凌钢集团及鞍钢体系依赖度极高。

## 风险警告
**核心风险在于持续亏损导致的资产负债表恶化与现金流枯竭。** 公司已连续三年巨亏，2025年归母净利润-15.57亿元，导致未分配利润由正转负（-35.12亿元），净资产收益率-32.24%。资产负债率已飙升至73.98%，短期借款与一年内到期的非流动负债合计超219亿元，而货币资金有限，短期偿债压力巨大。若行业需求无法回暖，公司可能面临流动性危机。

**经营层面，公司对关联方依赖度过高，且面临严峻的行业竞争。** 公司近半采购来自鞍钢集团及凌钢集团等关联方，定价机制虽称市场化，但存在利益输送或成本不透明的风险。同时，钢铁行业“供强需弱”格局未变，公司虽在推进产品高端化，但转型成效尚需时间验证，且面临龙头企业的激烈竞争。此外，环保政策持续加码，超低排放改造等投入将刚性增加成本，进一步挤压本已微薄的利润空间。
