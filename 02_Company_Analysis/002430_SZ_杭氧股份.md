# 002430.SZ 深度透视

## 因果逻辑链
- **[气体业务规模扩张]** -> [营收增长9.96%]: 气体业务收入92.07亿元，同比增长13.66%，成为营收增长主引擎，液体销量超360万吨，同比增长27.66%。
- **[设备业务稳健支撑]** -> [毛利率微增0.15%]: 设备销售业务收入54.41亿元，同比增长7.43%，毛利率27.86%，在空分市场需求有限背景下保持韧性。
- **[高附加值气体突破]** -> [氦气销量同比+129%]: 氦气供应链体系建立，产品渗透半导体、医疗、航天领域，推动气体业务向高附加值转型。
- **[国际化战略落地]** -> [外贸合同额8.09亿元]: 实现非洲大型空分设备“零突破”，海外营收同比增长29.95%，加速从本土制造商向全球解决方案提供商转型。
- **[新质生产力布局]** -> [培育第二成长曲线]: 中标核聚变项目、建成LNG冷能交换中心、布局氢能一体化，前瞻性开拓清洁能源与深低温新赛道。
- **[数字化转型深化]** -> [运营效率提升]: 部署16套智能空分系统，自研AI助手“喜氧氧”落地，行业首个垂直AI大模型启动建设，驱动精益管理与成本控制。
- **[全产业链协同]** -> [穿越周期抗风险能力]: “设备制造+气体运营”双轮驱动，制造反哺运营、运营牵引制造，形成难以复制的系统性优势。

## 风险警告
**气体价格波动与下游景气度风险**：零售气体价格受上游原材料、能源成本及区域供需影响高频波动，直接冲击短期盈利能力。同时，钢铁、化工等传统下游行业景气度下行，可能对公司设备和气体业务产生传导性影响，构成业绩最大不确定性。

**多业态集团化管控风险**：随着气体投资版图扩张至18个省市区，异地子公司数量持续增加，集团化管控难度、安全运营风险、质量合规风险随之提升。报告期内已出现业绩承诺方（原芯公司、杨利、倪幼红）超期未履行业绩补偿义务的情况，暴露出并购整合与投后管理的潜在风险。

**技术竞争与国际化挑战**：跨国巨头持续强化技术壁垒，本土企业加速扩张，中低端市场碎片化竞争加剧。公司国际化战略尚处起步阶段，海外本地化运营能力、地缘政治风险及汇率波动均可能影响海外业务拓展成效。
