# 301286.SZ 深度透视

## 因果逻辑链
- **[规模化生产与低成本水电]** -> [毛利率提升]: 公司拥有西南地区最大全液态空分产能，且汶川基地享受低成本水电，规模化效应显著降低单位能耗，使2025年主营业务毛利率同比提升2.69个百分点至34.89%。
- **[下游新能源/半导体客户需求增长]** -> [营收稳定增长]: 公司深耕川渝，核心客户涵盖通威股份、宁德时代、士兰微等，受益于新能源、半导体产业扩张，2025年营收同比增长5.24%至10.77亿元。
- **[财务费用大幅下降]** -> [净利润弹性释放]: 报告期内归还部分贷款本金且贷款利率降低，财务费用同比减少83.14%，直接增厚利润，是净利润增速（+55.80%）远超营收增速的关键因素。
- **[政府补助与理财收益增加]** -> [非经常性损益贡献]: 其他收益（政府补助）同比增长135.03%，投资收益（理财）同比增长759.80%，合计贡献约1423万元非经常性收益，占净利润增量的17%。
- **[高分红与股权激励]** -> [股东回报与治理绑定]: 2025年拟每10股派发现金红利4.56元，分红率高达77.8%；同时实施限制性股票激励计划，将管理层利益与2025-2027年净利润目标（2.3亿→6.8亿）深度绑定。
- **[产能扩张与项目延期]** -> [资本开支与短期不确定性]: 金堂三期、德阳项目等在建工程持续投入，但成都巴莫科技项目因客户缓建而顺延，导致部分新增产能释放节奏低于预期。
- **[电力成本占比高]** -> [成本结构刚性]: 电力成本占自产气体营业成本的79.5%，是最大单一成本项，电价波动对盈利能力有显著影响。

## 风险警告
**1. 单一客户依赖与项目延期风险。** 前五大客户销售占比达41.46%，其中第一大客户（闽光钢铁）占比18.74%，对单一客户的管道气依赖度较高。同时，与成都巴莫科技签署的重大合同（合计约30亿元）因客户项目缓建而顺延，若后续无法恢复或新客户开拓不及预期，将导致在建产能利用率不足，资产减值风险持续存在（2025年资产减值损失仍达1545万元）。

**2. 成本结构单一与电价波动风险。** 电力成本占营业成本近80%，公司虽享有汶川水电成本优势，但若未来电价政策调整或水电供应不稳定，将直接侵蚀利润。此外，公司研发投入极低（仅占营收0.03%），技术护城河主要依赖规模与成本，而非高附加值产品，在电子特气等高毛利领域的转型尚未形成实质贡献。
