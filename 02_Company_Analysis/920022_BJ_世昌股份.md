# 920022.BJ 深度透视

## 因果逻辑链
- **[高压燃油箱量产放量]** -> [营收增长29.57%]: 多个高压塑料燃油箱定点项目批量供货，高压油箱收入同比大增137.43%，成为收入增长核心引擎。
- **[客户集中度极高]** -> [经营风险集中]: 前五大客户销售占比90.94%，其中客户A和客户B合计占比76.77%，公司业绩高度依赖少数核心整车厂。
- **[营收增长但利润持平]** -> [毛利率承压]: 营收增长29.57%，但归母净利润仅微降0.53%，主因毛利率从25.48%降至22.33%，受客户年降及销售返利影响。
- **[IPO募资改善财务结构]** -> [资产负债率下降]: 上市募资后，货币资金暴增279.78%，资产负债率从50.31%降至42.58%，财务结构显著优化。
- **[应收账款高企]** -> [现金流恶化]: 营收增长导致应收账款同比增33.81%至2.56亿元，占流动资产47.78%，经营活动现金流净额由正转负至-718.96万元。
- **[热管理业务起步]** -> [第二增长曲线初现]: 子公司九昌新能源亏损收窄50.36%，电导率传感器实现出口，产品获法国彼欧认可，但收入规模仍小。
- **[产能扩张进行中]** -> [未来增长有支撑]: 浙江星昌募投项目（二期）预计2026年上半年投产，将新增60万台高压油箱产能，为后续增长提供产能基础。

## 风险警告
**客户集中度与应收账款双杀风险。** 公司前两大客户贡献近77%收入，任何单一客户订单流失或降价压力都将直接冲击业绩。同时，应收账款占流动资产近半，且增速（33.81%）远超营收增速（29.57%），叠加经营活动现金流已转负，若客户回款周期进一步拉长，公司可能面临流动性压力，需警惕“增收不增现”的恶性循环。

**毛利率持续下行与新能源替代风险。** 公司核心产品塑料燃油箱毛利率已连续两年下滑（从25.97%降至22.33%），主因客户年降和竞争加剧。更长期的风险在于，纯电动汽车渗透率已突破50%，若插电混动车型增速放缓或技术路线转向，公司赖以增长的高压油箱业务将面临需求天花板，而目前热管理新业务体量尚小，难以对冲主业风险。
