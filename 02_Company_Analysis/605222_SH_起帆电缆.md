# 605222.SH 深度透视

## 因果逻辑链
- **[主动收缩低毛利订单]** -> [营收下降5.19%，但净利润增长26.03%]: 公司放弃高风险、低毛利的传统基建项目，聚焦电网、新能源等高附加值客户，以量换价，提升综合毛利率。
- **[海缆业务突破]** -> [连续中标大型海上风电项目]: 宜昌+平潭双基地产能释放，获得±535kV直流海缆型式试验报告，具备深远海项目全周期服务能力，切入高壁垒市场。
- **[出口业务高增]** -> [出口金额同比增长37.26%]: 受益于“一带一路”沿线国家基建与能源转型需求，公司凭借多品类优势拓展东南亚、中东市场，成为增长新引擎。
- **[铜价高位震荡]** -> [成本压力持续，但套保对冲部分风险]: 原材料占成本95%以上，铜价波动是核心风险；公司通过期货套期保值锁定成本，但公允价值变动损益仍产生-1070万元亏损。
- **[应收账款管理强化]** -> [经营活动现金流净额骤降88.91%]: 尽管加强回款，但销售商品收到的现金减少，导致现金流与利润严重背离，显示回款压力依然巨大。
- **[研发投入聚焦特种电缆]** -> [技术壁垒构筑核心竞争力]: 研发机器人电缆（耐弯折8000万次）、eVTOL电缆、超高压海缆等，切入人形机器人、低空经济等未来高增长赛道。
- **[五大基地协同]** -> [提升交付效率，降低运输成本]: 上海、池州、宜昌、平潭基地“区域派单、就近生产”，海陆产能互补，支撑“海陆并进”战略落地。

## 风险警告
**核心风险在于“增收不增现”与高负债率。** 公司净利润增长26%，但经营性现金流净额暴跌88.91%至仅5520万元，与17亿净利润严重背离。这表明公司销售回款能力恶化，大量利润沉淀在应收账款和存货中。同时，资产负债率从66.6%攀升至68.41%，总负债超103亿元，财务费用高达2.1亿元，利息负担沉重。若下游客户（尤其是基建类）资金链进一步紧张，公司将面临坏账损失和流动性压力。

**另一重大风险是原材料价格波动与行业“内卷”。** 铜材占成本超70%，2025年铜价高位震荡，公司虽进行套期保值，但期货端仍产生亏损。更严峻的是，线缆行业集中度极低（前十企业市占率仅12%），中低端市场“价格战”激烈。公司主动收缩低毛利订单虽短期提升利润率，但营收持续下滑可能削弱规模效应和市场份额，若高毛利业务（海缆、特种电缆）拓展不及预期，公司将陷入“量价齐跌”的困境。
