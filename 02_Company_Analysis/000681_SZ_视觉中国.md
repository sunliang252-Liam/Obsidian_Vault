# 000681.SZ 深度透视

## 因果逻辑链
- **[宏观经济承压，广告客户缩减预算]** -> [传统版权授权业务规模下降]: 广告营销类客户订单量同比缩减，导致公司核心收入来源萎缩。
- **[AI 战略投入增加，设立新子公司及投资]** -> [短期利润承压]: 新设大象视觉等AI实施主体及战略投资MiniMax、生数科技，导致管理费用和投资支出增加，拖累当期净利润。
- **[内容定制业务采用AIGC技术]** -> [定制服务收入同比增长超18%]: 生成式AI缩短交付流程、降低成本，使公司能快速响应客户个性化需求，实现差异化竞争。
- **[AI赋能内容审核与智能标注]** -> [运营效率提升与成本优化]: AI技术使视频、图片审核效率分别提升4.4倍和7.4倍，并实现内容自动标签化，降低人工成本。
- **[结构化多维数据资产成为AI训练核心原料]** -> [数据授权业务成为新增长极]: 公司拥有超7亿版权合规、专家标注的多模态数据，已与阿里、腾讯、微软等签署训练数据合作协议。
- **[战略投资稀宇科技(MiniMax)并确认公允价值变动]** -> [非经常性损益大幅增加]: 报告期内因投资MiniMax股权产生公允价值变动收益约1,592万元，掩盖了主营业务的真实下滑。
- **[境外业务拓展与汇率波动]** -> [境外收入增长但财务费用增加]: 境外收入同比增长37.45%，但汇率波动导致汇兑损益增加，部分抵消了海外扩张的正面效应。

## 风险警告
**核心风险在于主营业务失速与AI转型的“青黄不接”。** 2025年公司营收同比下降4.03%，扣非净利润更是暴跌43.02%，传统版权授权业务在宏观经济压力下持续萎缩。尽管公司大力押注AI数据授权与AIGC定制服务，但新业务尚处商业化早期，收入贡献远不能弥补传统业务的缺口。当前利润主要依赖投资MiniMax等产生的非经常性损益，盈利质量堪忧。

**版权合规与技术变革的双重挑战不容忽视。** 随着AIGC内容爆发，公司面临“未经授权使用”的版权保护难题，以及AI生成内容是否构成作品的法律界定风险。同时，AI技术迭代极快，公司若不能持续保持技术领先，其“可商用+可溯源”的合规壁垒可能被开源模型或竞争对手突破。此外，公司商誉高达13.5亿元，占总资产31%，若光厂创意等子公司业绩不达预期，存在大额减值风险。
