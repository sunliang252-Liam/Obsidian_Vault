# 300690.SZ 深度透视

## 因果逻辑链
- **[风电行业装机增长+海外新客户拓展]** -> 风电配套类收入同比+40.02%: 国内大兆瓦订单放量及海外老客户新型号产品批量交付，驱动核心业务强劲反弹。
- **[风电叶片模具交付周期错位]** -> 非金属模具类收入同比-24.90%: 2024年集中交付2025年装机所需模具，导致2025年订单量阶段性下滑，库存因四季度新订单增加而上升70.40%。
- **[新能源车+商用车轻量化需求]** -> 车辆部件类收入同比+26.11%: 电池箱盖、新能源大巴内外饰件及低空飞行器部件订单持续增长，推动产销量大幅提升。
- **[海外市场开拓+汇率有利]** -> 境外销售收入同比+57.41%: 公司深度绑定Vestas、Siemens Gamesa等国际客户，海外风电配套及模具订单显著增长，同时受益于人民币汇率波动。
- **[产品结构优化+成本控制]** -> 综合毛利率同比+3.57个百分点: 高毛利的海外业务占比提升，叠加原材料成本管控及生产工艺创新，盈利能力显著改善。
- **[公允价值变动收益+信用减值转回]** -> 归母净利润同比+85.80%: 交易性金融资产公允价值变动收益约1,782万元，叠加信用减值损失转回约1,114万元，大幅增厚利润。
- **[绑定头部客户+定制化服务]** -> 客户粘性与订单稳定性: 与Vestas、金风科技、卡特彼勒等全球龙头建立长期合作，客户更换成本高，形成天然护城河。

## 风险警告
**核心风险在于风电行业政策波动与模具订单的周期性错配。** 公司收入结构中风电领域产品占比仍较大（风电配套+非金属模具合计约79%），风电制造景气度直接影响下游投资热情。非金属模具作为风电产业链上游，订单交付存在明显的“抢装-空窗”周期，2025年模具收入下滑24.9%即为明证，这种波动性将导致公司业绩在不同年度间剧烈摇摆。

**多元化扩张带来的管理挑战与人才流失风险不容忽视。** 公司业务已延伸至游艇、低空飞行器、碳纤维部件等领域，并收购澳洲子公司推进国际化。若质量管理、资源整合、海外团队建设不能及时跟上，可能拖累整体运营效率。同时，高素质技术人才是保持复合材料工艺领先的关键，行业竞争加剧下的人才流失将直接削弱核心竞争力。
