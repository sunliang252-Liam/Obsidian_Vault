# 688293.SH 深度透视

## 因果逻辑链
- **[培养基产品管线持续扩张]** -> [营收增长19.40%]: 截至2025年末，使用公司培养基的已确定中试工艺管线达327个，同比净增80个，商业化项目增幅达87.50%，直接驱动产品业务收入增长23.03%。
- **[高毛利产品业务占比提升]** -> [归母净利润增长98.07%]: 产品业务毛利率69.30%，收入占比持续扩大，叠加CDMO成本结构优化，利润增速远超收入增速。
- **[高新技术企业认定]** -> [所得税费用减少约1100万元]: 公司及子公司获高新认定，所得税税率由25%降至15%，直接增厚净利润，是扣非净利润增长216.57%的关键非经营性因素。
- **[CDMO商业化平台投产初期]** -> [服务业务毛利率为-51.40%]: D3工厂折旧及运营费用全额计入成本，产能利用率处于爬坡阶段，导致服务业务成本增幅(24.12%)远超收入增幅(2.71%)，严重拖累整体盈利。
- **[境外市场拓展与品牌建设]** -> [境外收入增长15.94%]: 美国子公司研发中心投入运营，推动境外收入达1.1亿元，且境外毛利率高达75.20%，成为利润增长的重要来源。
- **[研发投入持续加大]** -> [研发费用增长41.50%]: 美国研发中心运营及新一代培养基、工艺技术升级投入增加，研发费用占营收比例提升至13.63%，为长期竞争力奠定基础。
- **[D3工厂通过QP审计]** -> [具备商业化生产能力]: 证明公司已具备从基因到BLA的全流程服务能力，为承接后期及商业化项目扫清障碍，但产能释放进度仍慢于预期。

## 风险警告
**核心风险在于CDMO业务“失血”与资产减值压力。** 服务业务毛利率为-51.40%，D3商业化平台产能利用率持续低位，导致2025年计提长期资产减值损失约1290万元。若下游客户项目向后期转化进度持续慢于预期，该平台将面临更大减值风险，持续侵蚀利润。公司虽高比例分红（分红+回购占净利润251.74%），但这建立在产品业务盈利和税收优惠之上，CDMO业务的亏损本质并未改变。

**另一重大风险是收购整合与商誉减值。** 公司已完成对澎立生物（临床前CRO）的收购，旨在打造“培养基+CRDMO”模式。但收购带来的商誉、整合管控难度及业绩承诺实现风险不容忽视。独立董事曾对并购必要性投出反对票，暗示内部对战略方向存在分歧。若协同效应不及预期，或澎立生物业绩不达标，将面临商誉减值风险，对资产负债表和利润表造成双重冲击。
