# 000037.SZ 深度透视

## 因果逻辑链
- **[子公司土地收储确认收益]** -> [净利润暴增635%]: 深南电中山公司B地块完成收储移交，确认资产处置收益2.84亿元，是归母净利润1.61亿元的核心来源，扣非净利润仍为-8089万元。
- **[战略转型综合能源服务]** -> [收入结构质变]: 综合能源服务收入同比增247%至1.37亿元，占比从8.89%跃升至34%，储能电站投运成为新增长引擎，对冲传统发电收入下滑。
- **[市场化交易策略调整]** -> [发电量大幅萎缩]: 为追求综合收益最大化，动态调整现货出清策略，主动减少发电量，导致发电量、上网电量同比降幅超44%，电力生产销售收入降33.44%。
- **[并购补齐工程能力]** -> [“投建运管维”闭环成型]: 收购四川锐南（后更名能源科技公司），补齐EPC能力，中标2.23亿元储能电站项目，实现从投资、建设到运维的全链条覆盖。
- **[中山独立储能电站投运]** -> [储能业务规模化破局]: 一期项目于2025年6月商运，累计充放电量超8000万千瓦时，参与调频服务，成为公司战略转型的标志性落地项目。
- **[存量资产盘活]** -> [现金流与资产结构优化]: 完成中山机组设备挂牌转让（回款7225万元）及土地收储，同时协孚公司物业出租率100%，有效盘活低效资产，改善资产负债表。
- **[天然气成本压力与气源单一]** -> [主业持续承压]: 尽管发电量减少，燃料成本仍占营业成本58.74%，且气源单一化对供气稳定性和经济性构成长期制约，是扣非净利润持续为负的根本原因。

## 风险警告
**核心风险在于主业造血能力不足与转型的不确定性。** 公司2025年扣非净利润已连续三年为负（-8089万元），传统9E燃机发电业务在气价高企、电价市场化竞争加剧的背景下，已丧失盈利基础。净利润的暴增完全依赖一次性土地收储收益，不具备可持续性。若综合能源服务业务（储能、EPC、运维）无法在2026年实现规模化盈利，公司将重回亏损泥潭。

**另一重大风险是南山热电厂土地收储的悬而未决。** 深圳市2026年度土地整备计划仍包含该厂土地，尽管公司持续沟通，但土地被收储的预期始终存在。一旦实施，将直接导致公司核心发电资产灭失，彻底切断传统业务根基，迫使公司完全依赖尚在培育期的综合能源服务业务，转型压力将骤然升级。同时，中东地缘冲突导致天然气价格短期上涨，进一步加剧了主营业务的成本压力。
