# 300920.SZ 深度透视

## 因果逻辑链
- **[境外收入增长]** -> [营收增长3.78%]: 境外地区收入同比大增42.95%，弥补境内收入27.93%的下滑，成为唯一增长引擎。
- **[主要原材料价格下降]** -> [净利润增长6.01%]: 在营收仅微增背景下，原材料成本下降直接提升毛利率，驱动利润增速超越营收。
- **[下游客户产能外迁至东南亚]** -> [募投项目变更与产能布局调整]: 为规避贸易摩擦，下游PVC地板客户在泰国建厂，迫使公司终止湖州扩产，转投泰国基地。
- **[投资傅利叶智能3亿元]** -> [资产结构重大变化]: 公司以投前80亿估值，将3亿现金投入人形机器人赛道，导致投资活动现金净流出暴增至-4.49亿元。
- **[资产减值损失1416万元]** -> [侵蚀利润]: 计提存货和固定资产减值损失占利润总额的-79.20%，成为利润表最大拖累项。
- **[短期借款激增至2.9亿元]** -> [财务费用由负转正]: 为支撑海外建厂和股权投资，公司大幅增加银行借款，利息支出增加导致财务费用同比上升35.64%。
- **[出售空气盒子股权]** -> [聚焦主业]: 剥离亏损的控股子公司，产生109万元投资亏损，但优化了资产结构，减少非核心业务对资源的消耗。

## 风险警告
**核心风险在于战略扩张与主业疲软之间的巨大鸿沟。** 公司主业IXPE仅微增3.78%，且完全依赖境外收入（+42.95%）拉动，境内收入大幅下滑27.93%，显示国内市场需求萎缩。与此同时，公司激进投资3亿元于尚未盈利的人形机器人公司傅利叶智能，并大举借贷2.9亿元用于泰国建厂，导致投资活动现金净流出高达4.49亿元。这种“主业增长乏力、副业大额烧钱”的模式，将严重考验公司的现金流和债务偿还能力。

**另一重大风险是产能消化与贸易政策的不确定性。** 泰国基地刚于2026年2月结项，新增产能释放恰逢全球贸易摩擦加剧。公司下游客户高度依赖北美市场，若美国关税政策进一步升级，将直接冲击公司境外收入这一唯一增长支柱。此外，公司前五大客户集中度高达51.91%，且原材料成本占比56%，任何客户流失或原材料价格反弹，都将对脆弱的盈利能力造成致命打击。
