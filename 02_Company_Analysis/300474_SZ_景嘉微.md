# 300474.SZ 深度透视

## 因果逻辑链
- **[图形显控产品放量]** -> [营收增长54.41%]: 图形显控领域产品收入同比大增83.90%，是营收增长的核心驱动力。
- **[高研发投入侵蚀利润]** -> [连续两年亏损]: 研发费用占营收59.39%（4.28亿元），远超营收增速，是净利润为负的主因。
- **[控股诚恒微并表]** -> [亏损扩大]: 诚恒微尚处发展期，研发投入大，报告期亏损2.1亿元，拖累合并净利润。
- **[应收账款规模与账龄恶化]** -> [信用减值损失高企]: 应收账款达6.36亿元，信用减值损失6339万元，对盈利构成显著压力。
- **[“高性能GPU+边端侧AI SoC”双轮驱动]** -> [战略转型深化]: 从专用市场向“专用+通用”转型，构建“云-边-端”算力闭环。
- **[JM11系列芯片量产]** -> [打开云端市场]: 支持云桌面、云渲染，在电力调度系统实现32路vGPU虚拟化应用，标志产品从“能用”到“好用”。
- **[客户高度集中]** -> [经营依赖性强]: 前五大客户销售额占比64.53%，主要集中于航空工业，存在单一客户依赖风险。
- **[经营活动现金流由正转负]** -> [盈利质量承压]: 经营活动现金流净额为-5098万元，同比大降182%，与营收增长背离。

## 风险警告
公司连续两年亏损，核心矛盾在于“增收不增利”。营收高增（+54%）背后，是研发费用（+52%）和信用减值损失（6339万）的同步膨胀，导致净利润仍为-1.65亿。这种以巨额投入换取市场份额的模式，在通用市场尚未形成规模收入前，将持续考验公司的现金流和股东耐心。

应收账款规模达6.36亿元，且账龄结构恶化，导致信用减值损失高企。同时，客户高度集中于航空工业（前五客户占64.5%），议价能力弱，回款周期长。若下游客户付款能力或意愿发生变化，将直接冲击公司本就脆弱的盈利质量。
