# 601825.SH 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [营收承压]: LPR下调、存量按揭重定价及有效信贷需求不足，导致生息资产收益率下降45BPs，净利息收益率降至1.37%，拖累营收同比下降2.89%。
- **[负债成本主动压降]** -> [利润韧性]: 通过优化存款期限结构、压降高成本存款，计息负债成本率下降33BPs，对冲了部分资产端收益下行压力，归母净利润微增0.20%。
- **[“做小做散”战略]** -> [信贷结构优化]: 聚焦普惠、科创、绿色等“五篇大文章”，普惠小微贷款三年复合增长率13.13%，科技贷款突破1200亿元，对冲了传统对公贷款增长乏力。
- **[财富管理转型]** -> [非息收入稳定]: 代销理财、保险等财富业务增长，代理业务手续费收入同比增1.03%，推动非利息净收入占比提升至25.33%，部分弥补利息收入下滑。
- **[不良率低位稳定]** -> [风险抵补能力强劲]: 不良贷款率0.96%，连续多年低于1%，拨备覆盖率329%，为利润释放和资产扩张提供了充足的安全垫。
- **[资本充足率高位]** -> [业务扩张空间]: 核心一级资本充足率14.44%，远高于监管要求，为未来信贷投放、分红及应对风险提供了坚实的资本缓冲。
- **[区域深耕优势]** -> [低成本负债来源]: 扎根上海，网点覆盖全市乡镇，养老金代发量居前，带来稳定的个人定期存款（占比46.42%），但高成本也构成负债成本压降的挑战。

## 风险警告
**核心风险在于净息差持续收窄对盈利能力的侵蚀。** 尽管2025年负债端成本压降部分对冲了资产收益下行，但净利息收益率仍同比下降13BPs至1.37%。展望2026年，LPR重定价及有效信贷需求不足的延续效应，将使资产收益率继续承压。若负债成本压降空间收窄，净息差可能进一步下滑，直接威胁营收增长和利润稳定性。

**资产质量面临结构性压力，关注类贷款迁徙风险上升。** 不良率虽稳，但关注类贷款占比从1.28%升至1.79%，重组贷款占比从0.35%跃升至1.12%，显示潜在风险正在积聚。个人贷款不良率从1.32%升至1.56%，上海以外地区不良率从1.51%升至1.99%，均需警惕。若宏观经济复苏不及预期，这些领域的风险可能加速暴露，导致拨备计提增加，侵蚀利润。
