# 601128.SH 深度透视

## 因果逻辑链
- **[深耕小微金融，差异化定位]** -> [高息差与低不良]: 专注“三农两小”市场，以“常银微金”模式服务长尾客群，个人经营性贷款占比36.81%，户均贷款仅43.67万元，实现净息差2.53%（行业领先），不良率仅0.76%。
- **[“常银+村银”双轮驱动]** -> [规模与营收双增]: 常银深耕江苏县域，村银（兴福村镇）布局“三南一北”，总资产突破4000亿，营收超110亿，常熟以外地区贡献70%营收，证明跨区域复制能力。
- **[AI与科技赋能]** -> [降本增效与模式创新]: 部署GPU算力池，上线46个智能体，覆盖营销、风控、运营全流程，推动成本收入比降至35.66%，并打造“即时零售+滴滴”特色银行模式。
- **[财富管理“一号工程”]** -> [非息收入爆发]: 发力财富管理、代理保险、贵金属业务，手续费及佣金净收入同比暴增332%，非利息净收入占比提升至19.36%，有效对冲息差下行压力。
- **[主动负债管理]** -> [净息差韧性]: 通过调优存款结构，压降三年期及以上高息存款占比2.71个百分点，存款平均成本率从2.20%降至1.88%，在资产端利率下行背景下维持了息差韧性。
- **[村镇银行改革化险]** -> [资产质量改善]: 完成7家体系外村镇银行吸收兼并，推动“村改支”，改革机构扭亏为盈，村镇银行不良率降至1.03%，拨备覆盖率提升至353.60%，化解历史包袱。
- **[“常银微创投”科技金融]** -> [培育新增长极]: 专注初早期科创企业，服务超2300户，余额156亿，超50%为首贷银行，并构建“政银园投”生态，为未来增长储备优质资产。

## 风险警告
**核心风险在于净息差持续收窄与资产质量边际承压。** 尽管公司通过负债管理维持了息差韧性，但净息差已从2023年的2.86%降至2025年的2.53%，降幅达33BP。在LPR下调、让利实体经济的宏观背景下，资产端收益率下行趋势难以逆转，而负债端成本压降空间有限，未来息差可能进一步收窄，侵蚀核心盈利能力。同时，关注类贷款迁徙率从21.48%升至17.27%，不良生成压力仍在。

**另一重大风险是村镇银行整合与跨区域扩张的潜在不确定性。** 公司通过兼并重组快速扩张，但村镇银行不良率（1.03%）仍高于母行（0.76%），且分布在河南、云南等经济相对薄弱地区。若当地经济下行或管理能力跟不上扩张速度，可能引发资产质量恶化。此外，公司资本充足率（12.89%）已较上年下降1.3个百分点，快速扩张对资本的消耗需持续关注。

**公司简介（F10 原文）**

> 江苏常熟农村商业银行股份有限公司(以下简称“常熟农商银行”)改制成立于2001年11月28日,是全国首批组建的股份制农村金融机构,2016年9月30日于上海证券交易所上市(股票代码:601128)。秉承“敢闯、敢试、敢为”的探索精神,在全国农村中小金融机构中首批改制成立,率先引进国有大行交通银行作为战略投资者并成为第一大股东,并参股7家农村金融机构。2009年组建事业部制的小微贷款专营机构,打造专业化、可复制、业内领先的微贷核心技术,服务贷款客户超43万户。全部贷款中,超六成的信贷资金用于支持小微企业,超七成的信贷资金投向涉农领域,近八成的信贷资金服务于实体经济。受益于差异化市场定位,微贷特色银行受投资者青睐,股票估值水平跻身行业前列,在上市农商行中首家发行可转债并成功转股。连续六年蝉联“陀螺”评价体系县域农商行第一,连续六年获评上交所信息披露评价A级。立足普惠金融探索与实践,依托发起设立村镇银行复制推广“常农商微贷模式”。2019年9月在海南省海口市发起设立全国首家投资管理型村镇银行,集约化管理云南、湖北、江苏、河南、海南、广东六省的32家兴福村镇银行。常熟银行品牌影响力不断提升,连续六年跻身英国《银行家》杂志“全球银行1000强”榜单前500强,2024年排名第385位,“2024年中国银行业100强”第76位。展望未来,初心如磐、使命在肩。常熟农商银行将不忘“支农支小”初心,牢记“普惠金融、责任银行”使命,全力打造特色鲜明的一流上市农商银行!
