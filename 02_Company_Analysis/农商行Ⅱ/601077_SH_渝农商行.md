# 601077.SH 深度透视

## 因果逻辑链
- **[存款成本管控]** -> [净息差稳定]: 通过降低存款付息率（1.73%→1.45%）和优化负债结构，缓冲了资产端利率下行对净息差的冲击，使净息差仅降1BP至1.60%。
- **[信贷规模扩张]** -> [利息净收入增长]: 贷款余额同比增长11.62%，驱动利息净收入增长7.85%，成为营收增长的核心引擎。
- **[公司贷款高增]** -> [资产结构优化]: 公司贷款同比增长21.46%，占总贷款比重提升至54.55%，推动贷款占总资产比重提升0.71个百分点，优化了生息资产结构。
- **[不良率持续下降]** -> [信用成本降低]: 不良贷款率连续5年下降至1.08%，信用减值损失同比减少8.61%，直接增厚利润。
- **[县域存款优势]** -> [低成本负债基础]: 县域存款占比73.30%，个人定期存款付息率仅1.83%，为全行提供了稳定且低成本的资金来源。
- **[非息收入下滑]** -> [营收增速受限]: 受市场波动影响，投资收益及公允价值变动损益减少，导致非息收入同比下降23.92%，拖累整体营收增速仅1.37%。
- **[资本消耗加速]** -> [资本充足率承压]: 风险加权资产增速（16.53%）远超资本净额增速（4.52%），导致核心一级资本充足率下降1.57个百分点至12.67%。

## 风险警告
**核心风险在于零售贷款资产质量恶化与资本充足率快速下降的双重压力。** 零售贷款不良率从1.60%攀升至2.07%，个人经营贷、按揭贷、消费贷不良率全面上行，反映出宏观经济下行对居民偿债能力的冲击。同时，信贷高速扩张导致风险加权资产增速（16.53%）远超资本内生积累速度，核心一级资本充足率一年内骤降1.57个百分点，逼近监管红线，未来可能面临外源性资本补充压力。

**盈利结构单一且脆弱。** 利息净收入占比高达84.7%，非息收入受市场行情影响大幅下滑23.92%，手续费及佣金净收入占比仅4.52%。过度依赖息差收入的模式在利率下行周期中缺乏韧性，而财富管理、投行等中间业务尚未形成有效支撑，盈利多元化转型任重道远。
