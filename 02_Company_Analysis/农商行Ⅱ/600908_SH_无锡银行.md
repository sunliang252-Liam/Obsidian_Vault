# 600908.SH 深度透视

## 因果逻辑链
- **[存款结构优化，付息率压降]** -> [利息净收入微增]: 全年存款付息率压降0.34个百分点，有效对冲了净息差收窄（1.51%→1.35%）对利息收入的侵蚀，使利息净收入同比仅微增0.21%。
- **[投资收益大幅增长]** -> [非利息收入成利润支柱]: 处置债权投资等投资收益同比+25.5%（9.98亿→12.53亿），贡献了非利息净收入增长的绝大部分，是营收增长的主要驱动力。
- **[拨备计提力度加大]** -> [利润增速受限]: 信用减值损失同比+8.85%（7.38亿→8.04亿），拨备覆盖率虽仍处高位（414.91%）但同比大幅下降42.69个百分点，侵蚀了营收增长带来的利润弹性。
- **[资产规模扩张]** -> [营收增长基础]: 总资产同比+9.28%至2806亿，贷款总额同比+8.94%，规模扩张是利息净收入维持正增长的根本前提。
- **[社保卡客群优势]** -> [低成本存款来源]: 超542万张社保卡带来持续稳定的代发资金流，是活期存款和低成本存款的重要来源，支撑了存款结构的优化。
- **[区域经济赋能]** -> [信贷需求稳定]: 无锡GDP同比增长5.1%，良好的经济基本面为银行信贷投放和资产质量提供了坚实的外部环境。
- **[信用贷款占比提升]** -> [潜在信用风险敞口扩大]: 信用贷款占比从8.90%升至11.37%，在资产扩张的同时，无抵押贷款的增加意味着风险敞口扩大，对风控能力提出更高要求。

## 风险警告
**核心风险在于净息差持续收窄与信用成本上升的双重挤压。** 净息差已从2023年的1.64%降至2025年的1.35%，降幅达29BP，且降速未见明显放缓。在LPR下行和存款定期化趋势下，即使通过压降存款付息率也难以完全对冲，利息净收入增长乏力将成为常态。同时，拨备覆盖率从522.57%的高位快速回落至414.91%，虽然仍属充裕，但下降趋势表明信用成本正在侵蚀利润缓冲垫，未来若经济下行压力加大，资产质量可能面临考验。

**资产扩张依赖投资业务，市场风险敞口扩大。** 债权投资同比大增16.85%至483.9亿，占总资产比例升至17.25%。在利率下行周期，大量配置固定收益资产面临利率风险和再投资风险。同时，其他综合收益因债券公允价值变动而大幅减少2.81亿，表明利率波动已对净资产产生实质性冲击。此外，信用贷款占比快速提升至11.37%，在经济复苏基础尚不稳固的背景下，需警惕信用风险滞后暴露的可能。
