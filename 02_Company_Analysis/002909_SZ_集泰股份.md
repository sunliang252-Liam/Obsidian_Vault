# 002909.SZ 深度透视

## 因果逻辑链
- **[传统主业（建筑胶、集装箱涂料）周期性下行]** -> [营收下降15.5%]: 建筑工程开工不足与集装箱新造市场进入运力消化期，导致两大核心业务收入同步萎缩。
- **[战略转型聚焦新能源/家装]** -> [第二曲线高增长]: 新能源汽车用胶（+73%）、储能业务（+177%）、家装胶（+32.5%）高速增长，对冲传统业务下滑。
- **[计提大额资产减值]** -> [净利润由盈转亏（-2773万）]: 对部分产线效益与寿命进行严谨评估，计提固定资产减值准备，是导致亏损的直接财务原因。
- **[原材料价格下降]** -> [毛利率微增0.29%]: 主要原料聚硅氧烷价格下行，成本降幅（-15.83%）略大于收入降幅（-15.5%），维持了整体毛利率稳定。
- **[下游行业“量增价跌”]** -> [集装箱业务收入骤降37.6%]: 全球运力提前释放导致新造箱需求阶段性饱和，公司在该领域的收入与产量同步大幅下滑。
- **[研发投入缩减与人员优化]** -> [研发费用下降16.76%]: 为应对业绩压力，公司优化资源配置，减少研发人员数量与薪酬支出，可能影响长期技术储备。
- **[非经常性损益贡献利润]** -> [扣非净利润亏损更深（-3995万）]: 持有格莱利股权的公允价值变动收益（1258万）是当期利润的主要支撑，掩盖了主营业务的真实亏损程度。

## 风险警告
**核心风险在于传统主业与新兴业务的“青黄不接”。** 建筑胶和集装箱涂料作为公司的基本盘，正遭受房地产下行与海运周期波动的双重打击，短期内难以逆转。虽然新能源车、储能等新业务增速惊人，但绝对体量（合计仅约3600万）尚无法弥补传统业务数亿元的缺口。公司正处于痛苦的转型阵痛期，业绩拐点取决于新业务能否从“高增长”跨越到“大规模”。

**财务健康度面临严峻考验。** 2025年经营性现金流净额同比骤降61.7%，显示回款能力恶化。同时，公司背负大量有息负债（短期借款4.2亿+长期借款2.1亿），而货币资金仅1.27亿，偿债压力巨大。在持续亏损的背景下，若应收账款风险进一步暴露或融资环境收紧，公司的流动性风险将显著上升。
