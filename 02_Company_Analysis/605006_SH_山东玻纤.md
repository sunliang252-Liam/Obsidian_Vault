# 605006.SH 深度透视

## 因果逻辑链
- **[新产能释放与销量增长]** -> [营收增长23.87%]: 17万吨、8万吨等项目投产，玻纤纱产量同比+17.8%，销量同比+18.91%，以量补价驱动营收增长。
- **[产品结构优化与降本措施]** -> [毛利率改善6.89个百分点]: 削减低附加值产品，推进工艺、采购、管理降本，玻纤产品毛利率从6.81%提升至13.70%。
- **[行业高端化趋势与公司转型滞后]** -> [扣非净利润仍为负]: 行业利润增长点集中于高模、热塑、低介电等高端产品，公司传统产品占比高，转型周期长，新增高附加值产能尚处释放中期，未能充分受益。
- **[财务费用激增]** -> [侵蚀利润]: 利息费用增加导致财务费用同比+49.05%，达7917万元，显著加重经营负担。
- **[应收账款激增]** -> [现金流恶化]: 风电纱等新业务账期延长，应收账款同比+217.57%，导致经营活动现金流净额由正转负，为-5802万元。
- **[新项目集中转固]** -> [折旧压力加大]: 在建工程同比-94.94%，大量项目转固，固定资产同比+23.4%，未来折旧摊销将持续增加，压制利润。
- **[热电业务收缩]** -> [收入结构变化]: 关停1号发电机组，电力产量同比-20.86%，热电业务收入同比-15.88%，但受益于煤价平稳，毛利率提升9.67个百分点。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长23.87%，但扣非净利润仍亏损2414万元，且经营活动现金流净额由正转负至-5802万元，表明增长质量堪忧。应收账款同比暴增217.57%，主要因风电纱业务账期拉长，若下游客户回款持续恶化，将引发坏账风险并进一步抽紧资金链。

**转型阵痛与财务杠杆双重压力。** 公司正从传统玻纤向风电、电子纱等高端领域转型，但新产能爬坡、产品结构优化需要时间，短期内难以贡献足够利润。同时，大规模资本开支导致负债率攀升至66.18%，财务费用同比大增49.05%，叠加新项目转固后的折旧压力，公司盈利弹性被高额固定成本严重压制。若行业景气度回落，公司将面临更大的经营风险。
