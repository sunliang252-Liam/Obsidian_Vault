# 688712.SH 深度透视

## 因果逻辑链
- **精准PCI产品（IVUS/FFR）国产替代加速** -> [营收增长71.22%]: 公司作为国产IVUS和FFR市占率第一的品牌，受益于临床指南最高等级推荐和国产替代政策，产品入院数量超1800家，驱动核心业务高速放量。
- **复杂PCI产品线协同放量** -> [复杂PCI收入增长172.77%]: 单/双腔微导管、延长导管等产品凭借差异化性能，与精准PCI产品形成“诊疗一体化”方案，在复杂病变手术中快速渗透，成为第二增长曲线。
- **规模效应与费用率优化** -> [实现扭亏为盈]: 营收大幅增长的同时，销售费用率和管理费用率分别下降约9.32和8.38个百分点，经营杠杆释放，带动净利润从-4359万跃升至8001万。
- **海外市场突破** -> [境外收入增长135.45%]: 产品进入60多个国家，IVUS获欧盟MDR认证，在德国、波兰等发达国家实现首台商业植入，海外成为重要增量市场。
- **研发投入聚焦资本化阶段** -> [研发费用率下降15.68个百分点]: 脉冲电场消融（PFA）系统等核心在研项目进入资本化阶段，当期费用化研发投入减少，但研发总投入仍维持高位，管线储备深厚。
- **经营现金流大幅转正** -> [经营活动现金流净额增长386%]: 销售回款强劲，现金流入增速快于流出，公司实现内生“造血”，财务健康度显著提升。

## 风险警告
**集采政策与市场竞争的双重挤压风险。** 公司核心产品IVUS导管和微导管已纳入省级联盟集采，未来若集采范围扩大至FFR等产品，或公司未能中标/以价换量效果不佳，将直接冲击营收和毛利率。同时，国际巨头（如波士顿科学、飞利浦）和国内新兴竞争者正加速布局精准PCI领域，公司需持续保持技术迭代和成本优势，否则市场份额可能被蚕食。

**研发管线高度集中与商业化不确定性。** 公司未来增长高度依赖PFA电生理系统、外周IVUS等重磅在研产品的获批与商业化。PFA领域竞争已白热化，国内外多家企业产品已上市或处于注册阶段，公司产品若上市进度落后或临床优势未能转化为市场优势，前期巨额研发投入（PFA项目累计投入超1亿元）可能面临减值风险。此外，新产品的市场教育、入院和放量周期存在较大不确定性。
