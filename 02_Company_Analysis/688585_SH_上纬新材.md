# 688585.SH 深度透视

## 因果逻辑链
- **[风电行业高景气度]** -> [营收增长20.29%]: 风电新增装机创历史新高，带动公司风电叶片用材料销量同比大增54.85%，成为营收增长的核心引擎。
- **[循环经济材料放量]** -> [营收暴增259.20%]: 可回收树脂获西门子歌美飒、金风科技等头部客户认可并进入产业化应用，出货量同比激增200.91%。
- **[新业务高额研发投入]** -> [净利润下滑53.67%]: 为布局消费级具身智能机器人，新增研发投入2123.85万元，叠加新材料研发投入增加，研发费用率从2.03%升至2.87%。
- **[参股公司美佳新材亏损]** -> [确认投资损失2210.11万元]: 受行业竞争及政策变化影响，美佳新材经营下滑，关键项目未能投产，拖累公司净利润。
- **[客户TPI破产重组]** -> [单项计提信用减值损失1119.88万元]: 下游客户经营恶化导致坏账，直接侵蚀当期利润。
- **[原材料价格波动]** -> [毛利率承压]: 风电叶片用材料毛利率下降3.90个百分点，循环经济材料毛利率下降4.48个百分点，成本涨幅超过营收涨幅。
- **[汇率波动]** -> [财务费用大幅增加]: 汇兑损失增加导致财务费用从-1331万元转为699万元，同比变动-152.48%。

## 风险警告
公司面临“新旧业务双线作战”的财务风险。新材料主业虽营收增长，但毛利率下滑，且参股公司亏损和客户坏账持续侵蚀利润。同时，消费级具身智能机器人业务尚处研发阶段，无任何收入，高额投入将长期压制公司整体盈利能力，存在前期投入无法收回的风险。

消费级具身智能机器人业务面临极高的商业化不确定性。行业技术迭代快、供应链不成熟、消费者认知模糊，且公司缺乏相关渠道和售后网络。若产品研发、量产或市场拓展不及预期，将导致公司现金流压力剧增，并对整体经营产生重大不利影响。
