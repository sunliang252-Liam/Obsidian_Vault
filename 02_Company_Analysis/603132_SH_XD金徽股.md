# 603132.SH 深度透视

## 因果逻辑链
- **[银价大幅上涨]** -> [营收与利润双增]: 伴生银销售均价同比上涨34.89%，直接拉动营收增长12%，是利润增长的核心引擎。
- **[江洛矿区资源整合完成]** -> [产能扩张与资源储备提升]: 完成对豪森矿业100%控股，矿权统一至西成矿业，为未来300万吨/年选矿项目奠定资源基础。
- **[新建150万吨/年浮选厂联动试车]** -> [规模化生产能力增强]: 谢家沟浮选厂进入试车阶段，将显著提升公司整体矿石处理能力，支撑产量增长。
- **[新增探明资源量]** -> [矿山服务年限延长]: 新增铅锌矿石量132.06万吨，银金属量33.58吨，有效对冲资源消耗，保障长期可持续发展。
- **[财务费用大幅增长54.57%]** -> [侵蚀利润空间]: 银行贷款增加导致利息支出上升，在营收增长12%的情况下，财务费用增速远超营收增速，对净利润形成压制。
- **[高比例现金分红]** -> [股东回报与再投资平衡]: 2025年拟每10股派2.30元，分红总额占净利润77.55%，体现公司现金流充裕，但高分红可能限制未来资本开支灵活性。
- **[关联交易采购占比高]** -> [成本控制与独立性风险]: 前五名供应商中关联方采购额占年度采购总额19.51%，尤其是工程施工关联交易金额大，存在成本不透明风险。

## 风险警告
**核心风险在于产品价格波动与高财务杠杆的双重挤压。** 公司业绩高度依赖铅、锌、银价格，2025年银价大涨是利润增长主因，但锌、铅销售均价同比下跌。若未来银价回落或铅锌价格持续低迷，公司盈利能力将急剧恶化。同时，公司资产负债率已升至60.5%，长期借款同比暴增85%，财务费用增速远超营收，高利息支出将持续侵蚀利润，并限制公司应对价格下行的财务弹性。

**资源接续与项目投产存在不确定性。** 公司未来增长高度依赖江洛矿区300万吨/年选矿项目及杨家山等矿权的“探转采”进度。矿山建设周期长、审批复杂，若项目延期或资源储量不及预期，将导致产能扩张计划落空。此外，公司大量资产（固定资产、无形资产）已用于借款抵押，资产受限比例高，进一步融资空间受限，可能影响后续项目建设资金。
