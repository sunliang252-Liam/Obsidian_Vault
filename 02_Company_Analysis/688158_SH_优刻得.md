# 688158.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长13.07%]: 公司抓住AIGC浪潮，智算产品收入同比增长超40%，带动整体营收从15.03亿增至16.99亿。
- **[自建智算中心投产]** -> [毛利率提升4.85个百分点]: 乌兰察布和青浦数据中心投产，优化成本结构，云计算业务毛利率从20.57%提升至25.42%。
- **[参股公司会计核算变更]** -> [非经常性收益6,380万元]: 对海马云的投资由权益法转为公允价值计量，确认一次性投资收益，是全年大幅减亏的核心非经营性因素。
- **[海外节点扩张与产品优化]** -> [境外收入增长30.86%]: 全球32个可用区布局及GPU裸金属集群部署，驱动海外业务收入达3.48亿元，占比提升至20.47%。
- **[“中立”市场定位]** -> [头部AI大模型客户粘性]: 不与客户业务竞争，成为多家头部AI公司的第一或第二大供应商，在电商、社交等竞争性行业形成差异化优势。
- **[混合云“全栈式”升级]** -> [混合云毛利率大增12.79个百分点]: 推出智算混合云托管及统一管理平台UCMP，优化服务结构，毛利率从20.61%跃升至33.40%。
- **[经营现金流改善]** -> [现金流净额增长98.64%]: 销售回款增加，经营活动现金流净额从1.22亿提升至2.43亿，表明主营业务造血能力增强。
- **[股权激励与业绩补偿]** -> [净资产微增0.9%]: 收到行权出资及实控人业绩补偿款，抵消了持续亏损对净资产的侵蚀，维持净资产在24.16亿。

## 风险警告
公司虽在2025年Q4实现单季盈利，但全年仍亏损7,355万元，累计未弥补亏损高达20.64亿元。核心盈利能力的可持续性存疑：扣非净利润仍为-1.52亿，且投资收益贡献了绝大部分减亏幅度，剔除后主营业务改善有限。此外，公司面临激烈的市场竞争，巨头规模效应显著，产品价格长期承压，而AI带来的涨价趋势能否持续尚待观察。

治理结构存在重大隐患。共同实际控制人莫显峰、华琨已辞任董事并转让5.13%股份，其持有的特别表决权股份已转换为普通股，导致创始人团队表决权比例从45.63%降至42.08%。核心创始人的持续减持与退出，可能动摇公司“中立”定位的战略稳定性，并引发市场对管理层长期承诺的担忧。同时，高端GPU受美国出口管制，供应链风险是悬在AI算力业务头上的达摩克利斯之剑。
