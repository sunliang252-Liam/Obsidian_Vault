# 002612.SZ 深度透视

## 因果逻辑链
- **[处置若羽臣股权]** -> [归母净利润暴增283%]: 2025年出售若羽臣部分股权并改按公允价值计量，确认非经常性投资收益约8.89亿元，导致归母净利润从2.6亿飙升至9.99亿。
- **[线上渠道高速增长]** -> [女装业务收入增长3.85%]: 线上收入同比+24.78%，全渠道支付金额35.9亿（+35%），对冲了线下自营门店收缩带来的下滑。
- **[医美业务结构转向轻医美]** -> [毛利率提升至55.80%]: 非手术类医美收入占比从85.23%升至88.18%，手术类收入下降17.35%，高毛利轻医美占比提升拉动整体毛利率。
- **[外延并购持续扩张]** -> [医美收入规模增长3.27%]: 2025年收购重庆米兰、成都润美等机构，医美机构总数增至43家，但新并表机构贡献有限，增速放缓。
- **[核心医美机构增长分化]** -> [区域头部效应显现]: 昆明韩辰（+20.16%）、高新米兰（+16.25%）增长强劲，而四川米兰（-4.43%）、武汉五洲（-7.87%）出现下滑。
- **[经营性现金流净额下降23%]** -> [盈利质量承压]: 尽管净利润暴增，但经营活动现金流净额仅4.45亿，同比下降23%，主要系销售费用及存货增加所致。
- **[高分红回馈股东]** -> [股息率提升]: 拟每10股派12元（含税），分红总额5.31亿元，占归母净利润的53%，体现公司回报股东意愿。

## 风险警告
**核心风险：利润质量极低，依赖一次性收益。** 2025年归母净利润9.99亿中，非经常性损益高达7.3亿（主要为处置若羽臣股权），扣非净利润仅2.69亿，同比增长23.77%。剔除投资收益后，公司主业盈利能力改善有限，且经营性现金流净额同比下降23%，显示主业造血能力并未同步提升。

**医美业务增长放缓，并购整合风险凸显。** 医美收入增速从2024年的7.3%降至3.27%，手术类收入持续萎缩（-17.35%），部分核心机构如四川米兰、武汉五洲出现负增长。公司通过并购快速扩张，但新机构盈利爬坡期较长，商誉高达19.19亿元（占总资产22.38%），若并购标的业绩不达预期，存在大额商誉减值风险。同时，医美行业监管趋严、竞争加剧，人才流失风险持续存在。
