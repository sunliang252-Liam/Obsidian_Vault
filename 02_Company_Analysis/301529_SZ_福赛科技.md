# 301529.SZ 深度透视

## 因果逻辑链
- **[海外业务高增长]** -> [营收与利润双增]: 境外内饰件收入同比+91.79%，占总营收34.11%，成为核心增长引擎，驱动总营收+29.59%，扣非净利润+49.99%。
- **[墨西哥工厂产能利用率提升至90%]** -> [海外业务放量]: 墨西哥福赛2025年营收5.38亿元，净利润1,507万元，成功切入北美大客户供应链，实现本地化交付。
- **[新能源客户深度绑定]** -> [产品结构优化]: 与北美大客户、比亚迪、理想等头部新能源车企合作深化，带动高附加值装饰件收入同比+62.39%，毛利率提升3个百分点。
- **[精益制造与数字化转型]** -> [经营效率改善]: 年产400万套智能化工厂投产，MES系统覆盖全流程，经营活动现金流净额由负转正至3.4亿元，同比+453%。
- **[原材料成本管控]** -> [毛利率稳定]: 尽管原材料价格波动，但通过规模化采购和工艺优化，整体毛利率维持在25.70%，同比基本持平。
- **[研发投入聚焦电动化]** -> [技术壁垒构建]: 研发费用7,667万元，占营收4.44%，重点攻关电动出风口、智能表面、三电嵌件等，累计获235项专利，支撑产品升级。
- **[全球化产能布局]** -> [供应链韧性增强]: 国内六大产业集群+墨西哥第三工厂试生产+规划泰国基地，实现“全球布局、本地服务”，降低单一市场风险。

## 风险警告
**客户集中度与年降压力**：前五大客户销售额占比高达75.79%，其中单一客户占比36.99%，存在大客户依赖风险。汽车零部件行业普遍存在年降惯例，若公司无法通过规模化生产和工艺创新持续消化降价压力，将导致单品利润下滑，尤其在新能源主机厂持续压降供应链成本的背景下，利润空间可能被进一步压缩。

**海外运营与汇率波动风险**：海外业务占比已提升至34.11%，墨西哥工厂虽产能利用率高，但面临地缘政治、贸易政策（如关税壁垒）、当地法律法规及劳工管理等不确定性。同时，公司财务费用因汇率变动大幅下降84.90%，但未来汇率双向波动可能带来汇兑损失，对海外业务利润产生显著影响。

**新业务拓展的不确定性**：公司计划将产品线延伸至机器人零部件领域，目前仅处于研发和小批量试制阶段，尚未形成正式订单。该业务商业化落地存在较大不确定性，且需持续投入研发资源，短期内可能对盈利能力造成拖累，能否成功开辟“第二增长曲线”尚待验证。
