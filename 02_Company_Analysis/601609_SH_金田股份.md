# 601609.SH 深度透视

## 因果逻辑链
- **[产品客户双升级策略]** -> [净利润增长56%]: 聚焦新能源汽车、AI算力等高附加值领域，优化产品结构，提升毛利率，带动盈利大幅改善。
- **[海外市场扩张]** -> [境外收入增长28%]: 在泰国、越南等地布局产能，拓展全球客户，海外销量同比增长20%，有效对冲国内竞争压力。
- **[再生铜全产业链闭环]** -> [绿色产品销量增长54%]: 构建“回收-提纯-再制造”闭环，满足头部客户减碳需求，形成差异化竞争壁垒和绿色溢价。
- **[高压电磁扁线技术领先]** -> [市占率持续提升]: 800V及以上高压扁线出货量同比增长50%，深度绑定比亚迪、博世等头部客户，巩固新能源领域核心供应商地位。
- **[AI算力散热需求爆发]** -> [算力散热铜材销量增长55%]: 高精密无氧铜排等产品切入全球顶级GPU散热方案，驱动铜基材料向高附加值转型。
- **[稀土永磁高端化]** -> [磁材毛利率提升4.25个百分点]: 无重稀土高性能产品取得突破，切入人形机器人、液冷部件等新兴领域，产品结构持续优化。
- **[铜价上涨]** -> [营收微增但利润大增]: 铜价上涨虽未直接贡献加工利润，但提升了存货价值，并加速行业出清，利好龙头企业议价能力。

## 风险警告
**核心风险在于铜价波动与套保失效。** 公司利润主要来自“加工费”，但营收高度依赖铜价。2025年铜价上涨虽带来存货增值，但若铜价急跌，将导致存货减值及套期保值头寸亏损，直接冲击利润。公司交易性金融负债（套保工具）期末余额达4.95亿元，公允价值变动风险敞口巨大。

**国际化与产能扩张的双刃剑。** 公司加速在泰国、越南等地建厂，海外收入占比提升至13.4%，但面临地缘政治、汇率波动及当地管理整合风险。同时，大规模资本开支（投资现金流净流出33亿元）推高负债率，若下游需求不及预期，新增产能将面临消化压力，侵蚀盈利能力。
