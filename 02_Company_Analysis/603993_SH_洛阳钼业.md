# 603993.SH 深度透视

## 因果逻辑链
- **[铜钴量价齐升]** -> [归母净利润203亿元，同比+50.30%]: 铜产量74.11万吨（+13.99%）叠加LME铜均价同比+8.73%，以及钴价因刚果（金）出口禁令同比+42.81%，核心产品量价共振驱动利润爆发。
- **[“矿山+贸易”双轮协同]** -> [矿山端毛利率提升至52.85%]: 矿山产品通过IXM销售，获取市场情报优化定价，铜、钴、铌等产品毛利率分别提升4.9、29.31、6.98个百分点。
- **[逆周期并购与低成本开发]** -> [铜钴产量持续创新高]: 在行业底部收购的TFM、KFM世界级矿山，凭借低成本运营能力，铜产量位列全球前十，KFM二期预计2027年新增10万吨铜产能。
- **[“铜金双极”战略布局]** -> [开辟黄金新增长极]: 2025年完成厄瓜多尔奥丁金矿及巴西4座在产金矿收购，2026年预计产金6-8吨，黄金将成为继铜钴后的第三大利润引擎。
- **[刚果（金）钴出口政策变动]** -> [钴库存同比激增156.75%]: 2025年2月刚果（金）颁布钴出口禁令，公司钴销售量同比-53.06%，导致库存积压，但钴价上涨使毛利率仍高达63.62%。
- **[IXM期现结合模式]** -> [贸易业务毛利率提升至2.11%]: 通过期货对冲现货价格波动，在现货市场下行时期货端盈利弥补亏损，实现稳定盈利，2025年效益再创佳绩。
- **[组织升级与平台化建设]** -> [管理费用同比+31.91%]: 为打造全球平台型公司，引进国际化管理团队，管理人员工资奖金增加，短期费用上升但长期提升全球运营效能。
- **[ESG领先与铜标志认证]** -> [获得Wind ESG AAA评级]: TFM通过铜标志再审审计，KFM启动认证，高标准ESG管理成为全球资源获取与融资的竞争壁垒。

## 风险警告
**核心风险在于刚果（金）地缘政治与政策不确定性。** 公司超90%资产在境外，其中刚果（金）贡献矿山端主要利润。钴出口禁令虽推高价格，但导致库存积压156.75%，且配额政策（2026-2027年每年9.66万吨）可能限制未来销量。此外，刚果（金）政府换届、资源民族主义抬头或社区冲突，均可能直接冲击TFM和KFM的生产运营。

**大宗商品价格波动与贸易业务衍生品风险不可忽视。** 公司利润高度依赖铜、钴、金等价格，若全球经济衰退或新能源需求不及预期，铜价下跌将直接侵蚀利润。同时，IXM贸易业务持有大量衍生品（衍生金融负债达104.26亿元），公允价值变动收益为-76.88亿元，市场剧烈波动可能导致巨额公允价值损失。
