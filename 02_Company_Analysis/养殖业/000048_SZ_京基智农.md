# 000048.SZ 深度透视

## 因果逻辑链
- **生猪价格大幅下跌** -> **净利润暴跌78.59%**: 2025年生猪均价13.8元/kg，同比大幅下滑，直接导致公司核心主业盈利能力急剧萎缩。
- **房地产进入尾盘去化** -> **营收结构剧变**: 商品房销售收入同比骤降81.45%，从20.70%的营收占比降至4.70%，公司彻底转型为纯生猪养殖企业。
- **饲料原料价格上涨** -> **养殖成本承压**: 玉米全年涨10.78%，豆粕波动剧烈，尽管公司通过配方优化对冲，但养殖业毛利率仍同比下降10.44个百分点。
- **“楼宇聚落式+6750”模式** -> **成本控制与防疫优势**: 标准化、集约化养殖模式实现全进全出，有效阻隔疫病，并降低管理难度，是公司在猪价低谷期仍能盈利的核心基础。
- **粤港澳大湾区区位布局** -> **区域价格溢价**: 公司聚焦广东及周边，利用当地超2000万头生猪供给缺口，享受高于全国均价的销售价格，部分对冲了行业下行风险。
- **产能利用率提升与精细化管理** -> **成本持续优化**: 报告期内通过提升养殖健康度、优化饲喂方案等措施，生猪养殖全成本持续下降，年末头部企业成本已降至12-12.5元/公斤区间。
- **存量地产项目销售** -> **现金流重要补充**: 山海公馆项目报告期内销售约2.16亿元，为公司提供了宝贵的现金流，缓解了养殖业务周期低谷的资金压力。

## 风险警告
**核心风险在于猪周期深度磨底与公司盈利能力的脆弱性。** 2025年净利润暴跌近八成，且第四季度单季亏损1.45亿元，表明公司已进入盈亏平衡甚至亏损区间。公司虽通过精细化管理降本，但无法完全对冲猪价持续低迷的冲击。若2026年猪价继续低位震荡，公司将面临持续的现金流压力与资产减值风险。

**转型阵痛与多元化风险不容忽视。** 公司正从“养殖+地产”双主业彻底转向纯养殖企业，地产尾盘去化后，公司将失去重要的利润和现金流缓冲垫。同时，公司新设多家文化科技公司，并拟收购机器人公司，这些跨界尝试尚处早期，存在巨大的不确定性，可能分散主业资源并带来新的经营风险。
