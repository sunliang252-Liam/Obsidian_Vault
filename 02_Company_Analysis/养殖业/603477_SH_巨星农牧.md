# 603477.SH 深度透视

## 因果逻辑链
- **生猪出栏量大幅增长66.26%** -> [营收增长31.62%]: 以量补价，但生猪价格下跌导致增收不增利。
- **生猪销售价格同比下降** -> [毛利率骤降13.80个百分点]: 成本降幅远不及猪价跌幅，养殖业务盈利空间被严重压缩。
- **PSY提升至29以上** -> [种猪效率行业领先]: 高健康种群优势转化为更低的仔猪成本，是成本控制的核心基础。
- **“公司+农户”模式扩张** -> [委托养殖费用同比增76.91%]: 轻资产扩张带来快速上量，但也推高了养殖成本中的代养费。
- **饲料原料成本高企** -> [养殖成本中饲料原料占比69.43%]: 玉米、豆粕价格波动直接侵蚀利润，成本控制高度依赖原料采购与配方优化。
- **皮革业务调整策略** -> [皮革业务毛利率提升35.29个百分点]: 主动切入高价值客户与产品，实现扭亏为盈，但体量较小。
- **经营活动现金流净额12.18亿元** -> [净利润仅0.30亿元]: 现金流远超净利润，主要因折旧摊销及生物资产公允价值变动等非现金项目影响，经营质量尚可。
- **资产负债率67.29%** -> [财务费用1.98亿元]: 高杠杆运营，利息支出沉重，侵蚀利润。

## 风险警告
巨星农牧2025年陷入典型的“增量不增利”困境。生猪出栏量暴增66%，但猪价下跌导致净利润暴跌94%，毛利率从19%骤降至7%。公司核心风险在于对猪周期的高度依赖——即便PSY、料肉比等生产指标行业领先，也无法对冲猪价大幅下行的冲击。当前资产负债率已高达67%，短期借款和应付票据激增，财务费用接近2亿元，高杠杆在猪价低迷期是致命隐患。

另一个关键风险是成本控制的不确定性。虽然公司强调“增效降本”，但“公司+农户”模式下的委托养殖费用同比大增77%，饲料原料成本占比近70%，这两项刚性成本在猪价下跌时难以快速压缩。此外，公司因信息披露问题被监管出具警示函，暴露出内部治理与财务披露的潜在瑕疵，需警惕合规风险。
