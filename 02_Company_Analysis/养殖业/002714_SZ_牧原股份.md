# 002714.SZ 深度透视

## 因果逻辑链
- **[生猪价格周期下行]** -> [净利润同比下降13.39%]: 2025年全年活猪均价同比下降9.2%，尽管出栏量增长19.1%，但价格下跌幅度超过销量增长，导致盈利空间收窄。
- **[完全成本大幅下降]** -> [全年仍实现净利润158.12亿元]: 养殖完全成本约12元/kg，较上年降低约2元/kg，成本端改善有效对冲了猪价下跌对利润的侵蚀。
- **[屠宰肉食产能利用率提升]** -> [屠宰业务首次实现年度盈利]: 屠宰量同比增长128.9%，产能利用率达98.8%，规模效应显现，带动该板块从亏损转向盈利。
- **[资产负债率下降]** -> [财务结构优化]: 年末负债总额较年初下降171亿元，资产负债率下降4.53个百分点，财务费用同比减少17.4%，降低了经营杠杆风险。
- **[智能化与技术创新]** -> [生产效率提升与成本下降]: 智能环控、空气过滤猪舍、猪病净化“天网工程”等技术应用，提升了猪群健康水平和成活率，直接驱动成本降低。
- **[海外战略合作]** -> [开辟新增长空间]: 与越南BAF、泰国正大集团达成合作，并完成港股上市，为技术输出和全球市场拓展奠定基础。
- **[饲料成本占比高]** -> [原材料价格波动是核心风险]: 饲料成本占营业成本55%-65%，玉米、豆粕等大宗商品价格波动直接影响公司盈利稳定性。

## 风险警告
**核心风险在于猪价周期的不可预测性。** 2025年净利润同比下降13.39%，直接原因是生猪价格创2019年来新低。公司作为行业龙头，出栏量巨大，对猪价高度敏感。若未来猪价持续低迷或再次进入下行周期，即便成本控制优秀，也难以完全抵消价格下跌带来的盈利压力，业绩可能出现大幅波动甚至亏损。

**疫病防控是经营的“灰犀牛”。** 公司虽构建了“天网工程”等先进防控体系，但非洲猪瘟等重大疫病仍是行业性威胁。一旦发生大规模疫情，将直接导致生猪死亡、产量骤降，并可能引发消费者恐慌，造成价格与销量的双重打击，对公司现金流和盈利能力构成毁灭性冲击。
