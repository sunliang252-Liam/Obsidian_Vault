# 002299.SZ 深度透视

## 因果逻辑链
- **[全产业链闭环管理]** -> [成本领先优势]: 自繁自养全配套模式消除中间交易成本，叠加“圣泽901plus”种源料肉比优化，2025年综合造肉成本同比下行超5%，驱动扣非净利润增长22.27%。
- **[并购安徽太阳谷]** -> [规模与协同效应]: 全资收购太阳谷（年产能6500万羽、深加工9万吨），并表后贡献净利润1.11亿元，并完善长三角布局，推动深加工销量同比大增41.25%。
- **[全渠道制胜策略]** -> [高价值渠道增长]: B端深化与百胜、麦当劳合作，C端覆盖会员店、零食店等高增长渠道，C端收入同比增超60%，直销模式收入增长15.73%，优化产品结构。
- **[自有种源自主可控]** -> [供应安全与性能提升]: 打破国外种源垄断，“圣泽901”对外销售500余万套，市占率国产第一，且产蛋率、抗病性等指标达国际领先，保障生产计划稳定与成本持续优化。
- **[出口业务爆发]** -> [海外市场拓展]: 抓住中国成为鸡肉净出口国机遇，出口收入同比增41.60%，延续日本市场份额第一，并开拓中亚、东南亚市场，打开新增长空间。
- **[经营性现金流强劲]** -> [财务健康与扩张底气]: 经营活动现金流净额40.32亿元，同比增32.25%，叠加低融资成本，为公司并购整合、产能扩张及高比例分红提供坚实资金基础。

## 风险警告
**1. 鸡肉价格周期性波动风险。** 白羽肉鸡行业具有强周期性，2025年行业屠宰量增长7.49%，供给持续增加。若下游需求增速放缓或发生禽流感等疫情，鸡肉价格可能大幅下跌，直接冲击公司养殖板块利润。尽管全产业链能部分熨平周期，但生食鸡肉收入占比仍超50%，价格波动仍是业绩最大不确定因素。

**2. 并购整合与商誉减值风险。** 公司通过并购太阳谷、圣越农牧快速扩张，截至2025年末商誉余额达10.16亿元，占总资产4.38%。若被并购标的未来经营不及预期（如区域竞争加剧、管理融合不畅），将面临商誉减值风险，直接侵蚀利润。此外，大规模并购后的管理半径扩大、文化融合及供应链协同均存在挑战。
