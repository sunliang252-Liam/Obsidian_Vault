# 605296.SH 深度透视

## 因果逻辑链
- **[猪价下行周期]** -> [净利润同比暴跌50.65%]: 2025年生猪全年均价13.8元/公斤，同比下跌21.5%，尽管公司出栏量增长35.34%至307.42万头，但量增无法完全对冲价跌，导致营收下降4.16%，净利润从6.87亿骤降至3.39亿。
- **[极致成本管控]** -> [逆周期盈利核心护城河]: 公司通过优化种猪基因（PSY提升至29.5头）、降低料肉比（2.45-2.48）、提升智能化水平，将完全成本降至12.3元/公斤（12月单月12.1元），远低于行业平均亏损线，是公司在全行业亏损面超85%背景下仍能盈利的根本原因。
- **[全产业链一体化]** -> [平抑周期波动与保障食品安全]: 从饲料自产（年产160万吨）、生猪养殖到屠宰加工（194.18万头）的闭环，减少了外部交易成本，实现了从原料到终端的全程可追溯，增强了抵御猪价波动和疫病风险的能力。
- **[高健康度猪群与生物安全]** -> [降低养殖风险与长期成本]: 公司坚持“以健康为中心”理念，通过PIC千点评分选址、空气过滤系统、重大疫病净化（已通过6个国家级无疫病厂区评估），有效防控非洲猪瘟等疫病，降低了死淘率和动保费用，为低成本扩张奠定基础。
- **[产能逆势扩张]** -> [以量补价，抢占市场份额]: 在行业去产能阶段，公司2025年资本开支仍达7.74亿元，广西崇左等大型猪场项目建成投产，生猪出栏量同比增长35.34%，市占率快速提升，体现了逆周期扩张的战略定力。
- **[食品深加工业务]** -> [打造第二增长曲线]: 依托“神农放心肉”原料优势，开发云南特色预制菜、休闲肉制品，并拓展东南亚市场，虽尚处培育期，但为未来提升产品附加值、平滑周期波动提供了战略储备。

## 风险警告
**核心风险在于猪价持续低迷与产能快速扩张带来的现金流压力。** 2025年公司经营活动现金流净额同比大幅下降47.19%至8.1亿元，而同期资本开支高达7.74亿元，叠加2025年半年度分红2.05亿元，导致年末现金及现金等价物净减少3.28亿元。若2026年猪价继续低位运行，公司激进的产能扩张（2026年出栏目标预计更高）将严重考验其现金流平衡能力，存在被迫放缓扩张或增加有息负债的风险。

**其次，动物疫病风险是悬在头顶的达摩克利斯之剑。** 公司虽已建立完善的生物安全体系，但非洲猪瘟等重大疫病仍是行业最大不确定性。一旦发生大规模疫情，将直接导致生猪死亡、扑杀，造成生物资产重大损失，并可能引发恐慌性出栏和消费萎缩，彻底打破公司基于高健康度猪群的成本优势假设，导致业绩剧烈波动甚至巨额亏损。
