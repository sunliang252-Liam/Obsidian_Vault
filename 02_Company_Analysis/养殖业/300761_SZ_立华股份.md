# 300761.SZ 深度透视

## 因果逻辑链
- **[鸡猪双主业“双轮驱动”]** -> 平滑周期波动: 2025年鸡价低迷、猪价回落，但生猪业务盈利首次超越养鸡板块，两大板块盈亏互补，有效对冲了单一品种周期下行对整体利润的冲击。
- **[生猪出栏量大幅增长+成本显著下降]** -> 养猪板块利润逆势上升: 全年出栏211.16万头（+62.68%），规模效应释放；同时斤猪完全成本降至12元/公斤（同比降16.5%），量价齐升推动经营性利润同比增长。
- **[黄羽鸡出栏量增长但售价下跌]** -> 养鸡板块盈利承压: 全年销售肉鸡5.67亿只（+9.90%），但销售均价11.40元/公斤（同比降11.90%），收入仅微增0.66%，完全成本虽降6%仍无法完全对冲价格下跌，导致板块利润大幅下滑。
- **[饲料原料价格回落]** -> 养殖成本改善: 玉米、豆粕等主要原料价格下行，叠加公司优化配方，推动肉鸡和生猪完全成本分别同比下降约6%和16.5%，是抵御产品价格下跌的核心缓冲垫。
- **[屠宰产能扩张与品牌化]** -> 产业链延伸创造新增长点: 屠宰产能达1.5亿只，屠宰量近9000万只，与盒马战略合作，“立华鲜”品牌覆盖一线城市，湘潭工厂获供港资质，为未来提升附加值、平抑周期风险奠定基础。
- **[“公司+合作社/基地+农户”模式]** -> 轻资产快速扩张与成本控制: 公司负责核心环节（育种、饲料、销售），农户负责饲养，实现快速异地扩张、降低资本开支，同时通过“美丽牧场”模式吸收社会资金，保障了出栏量增长和成本领先。
- **[研发投入聚焦育种与健康管理]** -> 构筑长期竞争壁垒: 自主研发品种增至24个，推进基因组选育、抗病育种，持续优化生产效率与肉质，为未来产品差异化和成本优势提供技术支撑。

## 风险警告
**核心风险在于畜禽价格的“非典型”周期波动。** 2025年公司净利润同比暴跌62%，直接原因是鸡、猪两大主营产品价格均同比显著回落。黄羽鸡和生猪价格受供给、消费、政策等多重因素影响，波动剧烈且难以预测。若未来行业产能去化不及预期或消费持续疲软，价格可能长期低迷，将严重侵蚀公司盈利，甚至导致亏损。公司虽通过“双轮驱动”和成本管控对冲，但无法完全消除价格风险。

**第二大风险是成本端的不确定性。** 公司饲料原料（玉米、豆粕）主要依赖外部采购，其价格受全球供应链、气候、国家粮食政策等影响巨大。2025年成本下降部分得益于原料价格回落，但若未来原料价格大幅上涨，将直接推高养殖成本，压缩利润空间。此外，动物疫病（如禽流感、非洲猪瘟）是养殖业的“黑天鹅”，一旦爆发，不仅导致产量损失和防疫成本激增，更会严重冲击消费者信心，造成销售价格暴跌，对公司经营造成毁灭性打击。

**公司简介（F10 原文）**

> 江苏立华食品集团股份有限公司成立于1997年6月,是一家集科研、生产、贸易于一身、以优质畜禽养殖为主导产业的一体化农业企业,是农业产业化国家重点龙头企业、国家农业标准化示范区。下设全资子公司范围覆盖江苏、安徽、浙江、山东、广东、河南、四川、湖南、贵州、江西、云南、广西等十余个省份。公司与多家科研院所、高校合作,2004年共建江苏省优质禽工程技术研究中心,2007年成立江苏省农科院立华家禽研究所,2012年获得江苏省博士后创新实践基地授牌,2021年成立了立华南京农业产业研究院有限公司,2023年获评农业农村部华东优质禽育种重点实验室。2019年2月18日,公司正式在深交所挂牌上市,股票简称“立华股份”,股票代码“300761”,成为江苏省首家上市的畜禽养殖企业、常州市首家上市的农业企业。公司自主培育的当代草鸡优良品种“雪山鸡”于1999年投放市场,先后通过了江苏省畜牧品种审定委员会和国家畜禽遗传资源委员会审定,成为畜禽新品种(配套系)中的一员,是畜牧业优良推广品种。2018年通过了“江南白鹅”新品种(配套系)的审定,2021年又通过了“花山鸡”新品种(配套系)的审定。公司自创建以来,始终坚持“诚信、合作、创新、规范”的经营理念,倡导“精诚合作,共同富裕”的企业精神。从2000年开始实行“公司+农户”的运行模式,2002年组建合作社,并异地创办子公司,大力推行“公司+合作社+农户”的发展模式,带动广大农民致富。
