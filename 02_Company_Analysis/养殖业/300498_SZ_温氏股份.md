# 300498.SZ 深度透视

## 因果逻辑链
- **紧密型‘公司+农户’模式** -> 轻资产扩张与成本优势: 公司负责技术密集的前端（育种、饲料等），农户负责劳动密集的后端育肥，减少资本开支和人力成本，实现轻资产扩张，同时通过‘五统一’流程管控降低成本。
- **双主业与全国布局** -> 抗周期波动与业绩稳定: 鸡猪周期不同步，双主业可对冲部分周期风险；全国布局分散区域价格差异，形成风险对冲，提升整体经营稳健性。
- **行业供过于求与价格下行** -> 2025年业绩下滑: 2025年肉鸡出栏量增长5.9%，生猪出栏增长2.4%，供给充足，导致毛鸡均价同比下降9.80%，毛猪均价同比下降17.95%，进而压缩利润。
- **成本管控与技术优势** -> 逆势获得合理利润: 通过育种、营养、健康养殖等技术持续降本，肉猪养殖综合成本同比降约1.1元/斤，毛鸡成本保持稳定，部分对冲价格下跌影响，使公司在行业低谷仍获利润。
- **‘公司+农户’模式与农户利益绑定** -> 养殖规模稳定与扩张: 通过合理的委托养殖费用结算和稳定的合作收益，保障合作农户积极性，报告期内合作农户总数4.49万户，养殖面积净增加。
- **研发投入与技术领先** -> 成本下降与竞争力提升: 持续研发投入（8.15亿元）在育种、营养、健康养殖等领域取得成果，如国产固相猪基因育种芯片降低检测成本，精准营养配方优化饲料成本，推动养殖成本下降。
- **政策支持与行业趋势** -> 长期利好公司模式: 中央一号文件多次强调‘公司+农户’模式、生猪产能调控、种业振兴，公司模式契合政策导向，有利于长期发展。

## 风险警告
主要风险：1）生猪和肉鸡价格持续低迷若叠加原材料价格上涨，可能侵蚀利润；2）行业产能出清缓慢，若供给过剩延续，公司利润将进一步承压；3）养殖疫病爆发风险，尽管公司防控体系完善，但重大疫情仍可能造成损失；4）‘公司+农户’模式下农户违约或合作稳定性下降可能影响养殖规模扩张。
