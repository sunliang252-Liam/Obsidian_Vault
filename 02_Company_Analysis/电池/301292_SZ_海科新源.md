# 301292.SZ 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [连续两年亏损]: 核心产品碳酸酯系列售价长期低位，毛利率仅1.78%，导致2025年归母净利润-1.8亿元，虽同比减亏32%，但盈利能力依然脆弱。
- **[子公司新装置投产]** -> [固定费用激增]: 湖北、江苏新基地转固，折旧、运维等刚性成本增加，叠加产能爬坡期，阶段性摊薄综合盈利。
- **[原材料价格波动与传导时滞]** -> [毛利空间被挤压]: 上游环氧丙烷等价格频繁波动，而下游电解液客户定价存在时滞，公司无法及时转嫁成本。
- **[下游需求结构性分化]** -> [营收增长但亏损]: 储能电池需求爆发（全球出货量+79%），带动公司营收增长39.64%，但动力电池竞争激烈，价格传导不畅，增收不增利。
- **[Q4价格反弹但订单周期错配]** -> [全年扭亏失败]: 2025年Q4核心产品碳酸亚乙烯酯价格大幅上行，但受年末客户订单周期影响，无法在年内兑现为利润。
- **[研发与财务费用刚性增长]** -> [侵蚀利润]: 研发费用同比+24.16%，财务费用同比+59.49%（利息支出增加），刚性支出进一步压缩本已微薄的利润空间。
- **[经营活动现金流大幅转负]** -> [资金链承压]: 经营现金流净额-4.07亿元（同比-358%），主因销售规模增长导致应收账款大幅增加，回款周期拉长。

## 风险警告
**核心风险在于行业供需格局的持续恶化。** 公司作为电解液溶剂龙头，虽凭借规模与客户壁垒实现营收高增，但碳酸酯系列毛利率已跌至1.78%，接近盈亏平衡线。若下游动力电池需求增速放缓或储能需求释放不及预期，行业产能过剩将再度加剧，公司可能陷入“增收更亏”的困境。此外，经营现金流大幅转负，显示公司对下游客户的议价能力正在削弱，资金链压力显著上升。

**第二增长曲线尚在培育期，短期难以贡献利润。** 公司布局的添加剂（VC/FEC）、固态电解质、生物基1,3-丁二醇等新产品，目前仍处于客户导入或产能爬坡阶段，且面临万华化学等巨头的激烈竞争。在主营业务盈利薄弱的情况下，新业务若无法快速放量，将无法对冲溶剂业务的周期性风险，公司可能长期处于微利或亏损状态。
