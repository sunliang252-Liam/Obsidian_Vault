# 001301.SZ 深度透视

## 因果逻辑链
- **[下游需求爆发]** -> [营收增长51.9%]: 动力电池（出货1.1TWh，+41%）与储能电池（出货630GWh，+85%）双轮驱动，负极材料行业出货量同比+39%，公司销量34.35万吨，同比+58.63%。
- **[北苏二期10万吨产能达产]** -> [产销规模跨越式增长]: 2025Q1新基地满产，新增优质产能迅速转化为销量，但自有产能仍无法满足需求，需外协加工补充。
- **[全工序一体化生产]** -> [成本控制与品质保障]: 自建石墨化产能，自供率行业领先，减少毛利流出；各工序紧凑布局，降低运输与能耗成本，形成综合成本优势。
- **[深度绑定宁德时代]** -> [高客户集中度风险]: 对第一大客户宁德时代销售额占比70.48%，依赖度极高，若订单流失将对业绩产生重大冲击。
- **[原材料价格波动+外协加工扩大]** -> [毛利率承压]: 石油焦等焦类原料价格高位波动，且自有产能不足需扩大外协加工，导致营业成本增幅（+61.13%）高于营收增幅，毛利率同比下降4.51个百分点。
- **[研发驱动产品升级]** -> [结构优化缓释成本压力]: 持续投入快充、高容量、低膨胀等差异化产品，提升产品附加值，部分对冲原材料及外协带来的成本上涨。
- **[硅碳负极产业化落地]** -> [布局下一代增长点]: 已建成超500吨/年硅碳负极产能并实现批量出货，为未来高能量密度电池市场奠定基础。
- **[产能扩张与全球化布局]** -> [资本开支大幅增加]: 山西四期（20万吨）、山西五期（20万吨）、马来西亚项目（5万吨）同步推进，导致投资活动现金流净流出22.9亿元，财务费用因借款增加同比+84.47%。

## 风险警告
**客户集中度极高，单一客户依赖构成最大经营脆弱性。** 2025年对宁德时代的销售额占比高达70.48%，远超行业平均水平。尽管深度绑定带来稳定订单，但也意味着公司议价能力受限，且一旦宁德时代切换供应商或减少采购量，公司业绩将遭受毁灭性打击。客户结构多元化是当务之急，但短期内难以改变。

**产能扩张与盈利能力的矛盾正在加剧。** 公司正同时推进三个大型产能项目（合计45万吨），资本开支巨大，导致财务费用飙升（+84.47%）和投资现金流持续为负。与此同时，原材料涨价和外协加工扩大已侵蚀毛利率（-4.51pct）。若未来行业需求增速放缓或竞争加剧导致产品降价，大规模新增产能可能无法被有效消化，将引发资产减值风险和偿债压力。
