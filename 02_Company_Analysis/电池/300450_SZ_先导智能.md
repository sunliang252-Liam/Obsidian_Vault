# 300450.SZ 深度透视

## 因果逻辑链
- **[下游需求复苏]** -> [营收与利润高增]: 2025年全球动力电池市场回暖、储能需求强劲，头部电池企业扩产加速，公司订单交付与项目验收提速，营收同比增长21.83%，净利润同比暴增446.58%。
- **[经营性现金流大幅改善]** -> [盈利质量优化]: 公司加强应收账款催收，经营性应收项目收回增加，经营性应付项目规模上升，经营活动现金流净额达49.57亿元，同比由负转正（-15.67亿→+49.57亿），显著优于净利润水平。
- **[海外业务高毛利]** -> [整体盈利结构优化]: 海外业务收入31.29亿元，毛利率达40.75%，高于国内业务，其持续增长有效拉动了公司整体盈利能力的提升。
- **[平台化战略见效]** -> [非锂电业务成为新增长极]: 汽车智能产线业务营收同比增长615.55%，光伏智能装备营收增长29.48%，平台化布局有效分散了单一锂电行业的周期风险，贡献了多元增长曲线。
- **[固态电池装备前瞻布局]** -> [抢占下一代技术制高点]: 公司打通全固态电池量产全流程工艺，核心设备性能领先，已进入国内外头部电池企业及车企供应链并获重复订单，为未来产业爆发储备了核心装备竞争力。
- **[研发高投入]** -> [构筑核心技术壁垒]: 研发投入占营收比例超10%，在固态电池、钠离子电池、光伏前沿装备等领域实现关键突破，累计获得国家授权专利3592项，巩固了全球唯一拥有完整自主知识产权的锂电整线解决方案提供商的地位。
- **[存货与应收账款高企]** -> [潜在资产减值与资金占用风险]: 存货余额149.57亿元（占总资产38.28%），应收账款67.10亿元，两者合计占资产总额过半，虽本期减值计提3.48亿元，但高基数下仍对资金效率和资产质量构成持续压力。

## 风险警告
**核心风险在于下游需求周期性波动与资产质量压力。** 公司业绩高度依赖锂电池、光伏等下游行业的产能扩张周期，若宏观经济或产业政策发生不利变化，导致客户资本开支放缓，公司订单与营收将面临剧烈波动。2024年净利润同比下滑83.9%即为前车之鉴，凸显其强周期属性。

**财务健康度存在隐忧。** 公司存货与应收账款合计超216亿元，占总资产比例高达55%，且发出商品调试验收周期长，周转速度慢。尽管本期现金流大幅改善，但高额的营运资金占用和潜在的坏账、跌价风险，仍是悬在盈利质量上的达摩克利斯之剑。此外，财务费用因借款利息增加而同比大幅增长617.76%，需关注其杠杆水平。
