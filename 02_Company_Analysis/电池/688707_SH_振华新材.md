# 688707.SH 深度透视

## 因果逻辑链
- **[磷酸铁锂挤压三元市场]** -> [营收连续下滑]: 2025年磷酸铁锂装机占比升至81.2%，三元材料整体需求受限，公司传统5系产品份额萎缩，导致营收同比-27.16%。
- **[6系新产品导入滞后]** -> [产能利用率低位]: 新一代6系高电压材料虽完成认证但未形成大规模订单，未能弥补传统产品缺口，产能利用率持续处于低位，单位固定成本高企。
- **[原材料价格剧烈波动]** -> [毛利率持续为负]: 碳酸锂价格波动超100%，公司“成本加成”定价存在传导时滞，叠加高价库存消化，2025年毛利率为-14.29%。
- **[客户高度集中]** -> [经营依赖单一客户]: 前五大客户销售占比84.16%，其中单一客户占比67.02%，客户结构高度集中，议价能力受限且经营风险集中。
- **[研发投入逆势增长]** -> [维持技术竞争力]: 在连续亏损下仍加大研发投入（+4.56%至9424.63万元），聚焦固态电解质、钠电正极等前沿领域，以技术储备对冲行业下行。
- **[参股红星电子]** -> [构建回收闭环]: 通过参股废旧电池回收企业，实现钴、镍、锰、锂高回收率，旨在降低原材料综合采购成本，增强供应链韧性。
- **[暂缓义龙三期]** -> [审慎控制资本开支]: 面对产能过剩，公司暂停义龙三期项目，以“技改”替代“新建”实现高效扩产，避免新增产能闲置风险。

## 风险警告
**核心风险在于“结构性替代”与“新产品放量”的时间赛跑。** 磷酸铁锂对三元材料的替代趋势不可逆，公司传统5系产品市场被持续挤压，而寄予厚望的6系高电压材料在主要客户处导入节奏严重滞后，导致产能利用率长期低于45%。若6系产品无法在2026年实现大规模订单突破，公司将继续承受高昂的单位固定成本和资产减值压力，亏损局面难以扭转。

**财务风险高度集中于“高价库存”与“固定资产减值”的双重绞杀。** 公司存货账面价值7.08亿元，占资产10.78%，在原材料价格剧烈波动下，存货跌价风险如影随形。更严峻的是，固定资产账面价值24.89亿元（占总资产37.9%），低产能利用率已导致计提减值准备2293万元。若下游需求持续疲软，大规模固定资产减值将直接冲击净资产，形成“亏损-减值-净资产缩水”的恶性循环。

**公司简介（F10 原文）**

> 贵州振华新材料股份有限公司(以下简称“振华新材”或“公司”)成立于2004年4月,2018年由深圳市整体迁移至贵州省贵阳市,控股股东为中国振华电子集团有限公司,实际控制人为中国电子信息产业集团有限公司。公司于2021年9月14日在上交所科创板挂牌上市(股票简称:振华新材;股票代码:688707)。公司现有两个生产基地,分别位于贵阳国家高新区和黔西南州安龙经济开发区(原义龙新区)。截至2025年上半年,公司已建成年产8.2万吨正极材料生产线。公司自设立以来始终专注于锂离子电池正极材料的研发、生产及销售,产品主要应用于新能源汽车、3C消费电子等领域。其中,核心竞争产品一次颗粒大单晶镍钴锰酸锂三元正极材料(NCM)覆盖中镍、中高镍及高镍等多种型号,消费电子用正极材料主要包括高电压钴酸锂、复合三元材料及一次颗粒大单晶三元材料。自2009年起,公司在国内外较早完成镍钴锰酸锂三元正极材料一次颗粒大单晶材料的研发及生产,积累了多项具备自主知识产权的核心技术,主要包括:一次颗粒大单晶三元材料合成技术、无钴层状镍锰二元材料合成技术、高电压钴酸锂技术、多晶三元材料技术、尖晶石结构改性技术、掺杂与表面改性技术、钠离子电池正极材料技术,以及半固态/固态电池关键材料合成技术,相关成果已获多项国内外发明专利授权。在前沿材料领域,公司层状氧化物钠离子电池正极材料已完成多代产品迭代并成功装车,聚阴离子材料百吨级中试线正处于全面评估与验证阶段。针对半固态/凝聚态/固态电池等高能量密度场景,公司自主开发的固体电解质氧化物及其改性三元材料与富锂锰基正极材料已送样下游头部客户,复合固体电解质已实现吨级稳定制备,并与多家国内主流电池企业合作推进验证及百吨级中试线建设。面向低空经济领域,公司开发出兼具高能量密度、高功率、长循环与高安全特性的正极材料,并已实现百吨级产销。未来,公司将持续深化锂离子电池三元正极材料全系产品的性能提升,加快推进钠离子电池材料、固态电池关键材料及磷酸锰铁锂等新体系的产业化进程,围绕固态电池、低空经济等领域所需材料加大研发力度,通过持续降本增效与开发高附加值产品,不断提升企业核心竞争力。
