# 688388.SH 深度透视

## 因果逻辑链
- **[下游需求复苏 + 产能释放]** -> [营收增长47.85%]: 2025年锂电池行业回暖，公司锂电铜箔产能达13.5万吨，产销量同比增超46%，量价齐升驱动营收创新高。
- **[产品结构优化 + 降本增效]** -> [扭亏为盈]: 高附加值极薄铜箔占比提升推动平均加工费上涨，叠加产能利用率提升与成本管控，毛利率上升，归母净利润从-2.39亿转为+0.57亿。
- **[绑定核心大客户]** -> [高客户集中度]: 前五大客户销售占比83.07%，其中宁德时代系列占70.03%，深度绑定保障订单稳定性，但也带来单一客户依赖风险。
- **[研发投入高增]** -> [技术壁垒加固]: 研发费用同比增70.22%至4.66亿元，聚焦极薄化、HVLP、固态电池铜箔等高端产品，巩固行业第一梯队技术护城河。
- **[产能激进扩张]** -> [折旧与资金压力]: 产能从2024年底快速扩至13.5万吨，规划总产能25万吨，在建工程与固定资产占比高，折旧增加侵蚀利润，且对流动资金需求大。
- **[多元化投资布局]** -> [寻求新增长极]: 投资5亿元入股光模块企业恩达通（13.59%股权），切入AI算力赛道，同时布局固态电池锂负极材料，但新业务协同与盈利贡献尚需验证。
- **[“铜价+加工费”定价模式]** -> [毛利率波动风险]: 铜价波动无法完全传导至下游，且行业竞争加剧导致加工费承压，毛利率仅5.02%，盈利空间薄且脆弱。

## 风险警告
**核心风险在于盈利质量极低与单一客户依赖。** 公司2025年归母净利润仅0.57亿元，扣非净利润0.12亿元，对应近100亿营收，净利率不足0.6%。剔除政府补助、增值税加计抵减等非经常性损益后，主业几乎不赚钱。同时，对宁德时代系列客户销售额占比高达70.03%，议价能力弱，一旦客户压价或切换供应商，业绩将剧烈波动。

**产能过剩与巨额折旧是长期隐患。** 公司总资产147亿，固定资产+在建工程占比超41%，产能利用率虽提升但仍面临行业整体产能过剩风险。若下游需求增速放缓，巨额折旧将直接导致利润下滑甚至亏损。此外，公司经营活动现金流净额为-1.16亿元，造血能力不足，持续扩张依赖外部融资，财务费用同比增40.62%，债务风险在累积。

**公司简介（F10 原文）**

> 广东嘉元科技股份有限公司成立于2001年9月,是一家专注于从事研究、制造、销售高性能电解铜箔、复合铜箔、高性能高精度铜合金丝线材以及“风光储”投资、建设、服务的综合科技型集团化企业,铜箔作为主营产品主要应用于锂离子电池、覆铜板和印制线路板行业,最终应用在新能源汽车动力电池、储能电池、固态电池、AI算力、人形机器人、多层线路板及3C数码类电子产品等领域。公司于2019年7月登陆上海证券交易所科创板(SH:688388)。嘉元科技先后被认定为国家企业技术中心、国家技术创新示范企业、国家知识产权示范企业、高新技术企业、博士后科研工作站,2023年入选广东省首批省级制造业单项冠军企业。公司目前的极薄铜箔生产技术达到行业领先水平,多项技术填补了国内空白,实现了3.5μm-18μm各种极薄高端铜箔、高延高强铜箔产业化,整体技术水平居国际领先。目前是国内高性能锂电铜箔行业领先企业之一,已与国内主要大型锂离子电池制造厂商建立了长期合作关系。公司积极推进产品研发创新,在微孔铜箔、单晶铜箔、高阶RTF铜箔(反转铜箔)、HTE(高温高延伸铜箔)、HVLP(极低轮廓铜箔)、IC封装极薄铜箔和高密度互连电路(HDI)、复合铜箔、超薄载体铜箔等新产品研发中取得突破,推动了高端铜箔的国产替代进程。公司瞄准新能源行业崛起带来的铜箔产业发展机遇,以时不我待的意识抓好项目建设。目前铜箔年产能超过13.5万吨,铜合金丝线材产能超2万吨。嘉元科技将坚持以习近平新时代中国特色社会主义思想为指导,全面贯彻党的二十大精神和中央经济工作会议精神,以实体经济为本,坚持制造业当家,坚定发展信心,着力提高自主创新能力,推动企业高质量发展。持之以恒加强党的全面领导,坚持开拓创新,勇担社会责任,为推动苏区融湾振兴发展,助力广东在全面建设社会主义现代化国家新征程中走在全国前列、创造新的辉煌贡献嘉元力量。
