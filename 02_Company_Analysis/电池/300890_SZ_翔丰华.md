# 300890.SZ 深度透视

## 因果逻辑链
- **[下游需求增长]** -> [营收增长20.66%]: 新能源汽车“以旧换新”政策及储能市场爆发，带动负极材料出货量增长，公司销量同比+21.84%。
- **[大客户依赖加剧]** -> [应收账款激增51.58%]: 国轩高科销售占比升至64.35%，其信用账期较长，导致公司应收账款增至10.54亿元，经营现金流净额为-1.43亿元。
- **[产能扩张与利用率矛盾]** -> [毛利率承压]: 公司产能利用率仅72.76%，但上海、四川基地仍在扩产，固定成本摊销增加，导致石墨负极材料毛利率同比下降6.43个百分点至16.16%。
- **[原材料价格波动]** -> [成本控制压力]: 焦类原料价格波动，公司直接人工和制造费用同比大增149.5%和163.69%，成本增速（+30.71%）显著快于营收增速（+20.68%）。
- **[研发投入聚焦下一代技术]** -> [长期竞争力储备]: 研发费用占营收3.40%，重点投向气相沉积硅碳（比容量1800-2000mAh/g）和硬碳负极，为钠离子电池和高端动力电池市场做准备。
- **[国际化客户突破]** -> [打开增长天花板]: 获得德国PowerCo项目供应商正式提名（预计2027年供货），并积极开拓SK On、松下等国际客户，有望优化客户结构并改善回款。

## 风险警告
**核心风险：现金流恶化与客户集中度双杀。** 公司2025年经营现金流净额为-1.43亿元，同比下降663%，主因是最大客户国轩高科（占营收64.35%）账期长、回款慢。若下游动力电池行业竞争加剧或国轩高科经营承压，公司将面临坏账损失和流动性紧张的双重冲击。当前资产负债率已升至55.86%，短期借款同比+91.43%，财务费用高企，偿债压力显著。

**成长性风险：产能过剩与价格战。** 负极材料行业2025年出货量增长38%，但公司产能利用率仅72.76%，且在建工程（+138%）和长期借款（+117%）大幅增加，上海碳峰科创中心等项目尚在建设期。若未来下游需求增速放缓或新技术路线（如钠离子电池、固态电池）对石墨负极形成替代，公司新增产能可能无法充分消化，导致资产减值风险。
