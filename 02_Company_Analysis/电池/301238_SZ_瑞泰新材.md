# 301238.SZ 深度透视

## 因果逻辑链
- **[行业产能过剩与竞争加剧]** -> [核心业务亏损]: 锂电材料产能大量释放，供大于求格局未扭转，导致公司核心电解液业务毛利率下滑，扣非净利润亏损7464万元。
- **[减持天际股份股票]** -> [归母净利润虚增]: 2025年12月减持天际股份股票，取得税前投资收益约3.9亿元，使归母净利润同比大增162.85%，掩盖了主业亏损的实质。
- **[产能爬坡不及预期]** -> [巨额资产减值]: 宁德华荣、超威新能、衢州瑞泰、自贡华荣四个基地产能利用率低、持续亏损，公司计提固定资产减值准备2.32亿元，直接侵蚀利润。
- **[原材料价格波动]** -> [成本与盈利承压]: 六氟磷酸锂等核心原材料价格在四季度大幅上涨，而电解液价格传导滞后，导致公司营业成本难以有效控制，毛利率同比下降。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售占比高达71.25%，对宁德时代、LG新能源等头部电池厂依赖度极高，议价能力受限，且单一客户订单波动将剧烈影响业绩。
- **[海外布局扩张]** -> [管理成本与汇兑风险]: 波兰、韩国、马来西亚等地子公司尚处爬坡期，固定成本高，波兰华荣虽减亏但仍亏损，同时人民币汇率波动带来汇兑损益风险。

## 风险警告
**核心风险在于主业已陷入实质性亏损，盈利完全依赖非经常性损益。** 公司2025年扣非净利润为-7464万元，同比暴跌191.37%，表明在行业产能过剩、竞争白热化的背景下，电解液及添加剂业务已无法创造利润。公司通过减持天际股份股票获得的3.9亿元投资收益是当期盈利的唯一来源，这种“卖资产保利润”的模式不可持续，一旦减持完毕，公司将暴露真实的亏损面貌。

**产能过剩与资产减值风险是悬在头顶的达摩克利斯之剑。** 公司电子化学品产能利用率仅10.04%，大量新建产能（如衢州、自贡、波兰项目）处于爬坡期，持续产生亏损。2025年已计提2.32亿元固定资产减值，若行业需求复苏不及预期，未来仍有进一步减值的巨大压力，将直接冲击净资产和利润表。此外，客户高度集中（前五大客户占收入71%）和原材料价格剧烈波动，进一步放大了公司经营的脆弱性。
