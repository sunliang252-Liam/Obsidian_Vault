# 603026.SH 深度透视

## 因果逻辑链
- **[电解液销量翻倍，跻身行业前五]** -> [营收增长22.75%]: 公司电解液销量同比增长117.9%，对宁德时代销量增长139.7%，带动锂离子电池相关材料收入增长41.03%，成为营收增长的核心引擎。
- **[产业链一体化自供95%以上原材料]** -> [成本控制与盈利韧性]: 公司自产五大碳酸酯溶剂、六氟磷酸锂及添加剂，大幅降低采购成本并避免品质波动，在行业价格战中维持了锂电材料7.99%的毛利率。
- **[四季度碳酸酯溶剂价格筑底反弹]** -> [全年扭亏为盈]: 2025年下半年电解液原材料价格上涨，带动公司核心产品碳酸酯系列价格回升，叠加产能增速放缓，四季度实现归母净利润7810万元，覆盖前三季度亏损。
- **[定增募资9.82亿元]** -> [资本结构优化与抗风险能力提升]: 成功完成向特定对象发行股票，募集资金净额9.82亿元，显著降低资金成本，资产负债率下降1.81个百分点至53.38%。
- **[经营性现金流大幅净流出12.9亿元]** -> [营运资金压力剧增]: 营收增长导致应收账款激增66.73%至23.16亿元，同时应付票据到期减少，经营性现金流净额同比恶化188.3%，显示销售回款与采购支付存在严重时间错配。
- **[多基地布局与Tank罐运输]** -> [物流成本降低与客户响应提速]: 武汉基地产能爬坡，叠加“不锈钢桶+Tank罐”双轨运输体系，有效降低运输成本，缩短交付周期，支撑电解液销量翻倍。
- **[丙二醇价格重心下移]** -> [拖累PO酯交换法工艺盈利]: 丙二醇行业供需失衡持续，价格下跌，对采用环氧丙烷酯交换法生产碳酸二甲酯的工艺形成盈利拖累，导致碳酸二甲酯系列毛利率下降2.32个百分点。

## 风险警告
**核心风险在于“增收不增利”与现金流急剧恶化。** 公司营收增长22.75%，但归母净利润仅1589万元，同比下滑3.17%，扣非净利润虽增长150%但绝对值仅1350万元，盈利极其微薄。更严重的是，经营活动现金流净流出高达12.9亿元，是净利润的81倍，应收账款激增66.73%至23.16亿元，表明公司为抢占市场份额，大幅放宽信用政策，导致营运资金被严重占用，财务风险显著上升。

**产能过剩与行业竞争加剧是长期隐忧。** 尽管电解液行业需求增长，但产能结构性过剩问题依然严峻，中小厂家亏损停工，行业集中度持续提升。公司虽跻身行业前五，但六氟磷酸锂产能利用率仅22%，大量在建项目（如硅基负极、液态锂盐）转固后折旧压力巨大。同时，MTBE等传统业务受汽油消费下滑影响，盈利空间持续收窄，多元化业务尚未形成有效利润支撑。

> 石大胜华新材料集团股份有限公司(简称:石大胜华,股票代码:603026)原名山东石大胜华化工集团股份有限公司,前身是国家“双一流”学科建设高校—中国石油大学(华东)的校属企业,是能够同时提供锂离子电池电解液溶剂、溶质、添加剂产品的全产业链公司。自2002年成立以来,石大胜华围绕碳酸酯类产品,聚焦新能源、新材料领域,打造立体化完整产业链,纵向延伸精细化工品业务,横向开拓锂电新材料产品,形成锂电池溶剂、电解液、高端新材料三大业务板块。目前,公司在全球碳酸酯高端溶剂市场份额已超过40%,下游客户覆盖了全球范围内电解液龙头厂商。电解液产品方面,石大胜华具有全面的材料一体化优势,在东营、武汉等基地布局,覆盖了全国主要的锂电池生产基地,与国内主要的锂电池龙头企业建立了长期稳定的战略合作关系。石大胜华重视基础科学研究与变革性技术开发,拥有小试、中试、量产平台,配备专职研发和实验团队,具有深厚的研究积累和产业化经验。公司是碳酸酯行业的国家及行业标准制定者。公司下属5家子公司获得国家高新技术企业认证,拥有“高纯电解液山东省工程研究中心”“省级企业技术中心”“市级重点实验室”等技术研发服务平台。公司依托北京、青岛、东营、泉州、济宁、武汉、眉山等研发生产基地,以及在东亚、欧洲建立的海外销售网络,实现了全球化布局,能为锂离子电池企业提供一站式解决方案。形成了以碳酸酯类溶剂、锂盐、添加剂及硅基负极等锂电材料产品为核心,以锂电池电解液、高端新材料等新业务为增长点的一体化、立体化的完整网状产业链格局。石大胜华坚持在新能源、新材料领域深耕,致力于向全球持续提供新能源、新材料优质产品和最佳解决方案,为推动新能源行业的发展贡献智慧和力量,为人类提供更加绿色、环保的生活环境。
