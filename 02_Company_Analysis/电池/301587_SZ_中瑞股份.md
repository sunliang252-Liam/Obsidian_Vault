# 301587.SZ 深度透视

## 因果逻辑链
- **[组合盖帽销量增长29.62%]** -> [营收增长8.65%]: 下游新能源车及圆柱电池市场需求旺盛，带动核心产品组合盖帽销量大幅提升，但为维护大客户关系主动降价，导致营收增速远低于销量增速。
- **[对成熟产品主动降价]** -> [归母净利润下降31.79%]: 为深化与LG新能源等核心客户的战略合作，公司牺牲短期利润换取市场份额，叠加新增产能爬坡期固定成本承压，盈利能力显著下滑。
- **[大圆柱结构件销量下降]** -> [该产品营收下降29.94%]: 海外需求波动及外部环境影响，导致大圆柱结构件出货量阶段性萎缩，产能利用率降低。
- **[新增产能投产爬坡]** -> [单位固定成本短期承压]: 募投项目“动力锂电池精密结构件项目”处于建设及投产初期，规模效应尚未释放，折旧及人工成本增加侵蚀利润。
- **[原材料价格及用工成本上升]** -> [营业成本增长13.10%]: 铝、钢等大宗商品价格波动及一线员工薪酬福利提升，直接推高制造成本，毛利率同比下降2.97个百分点。
- **[研发投入持续高企]** -> [巩固技术护城河]: 研发费用占营收8.60%，重点攻关46系列大圆柱结构件及轻量化、高安全性产品，为未来大圆柱电池放量储备技术。
- **[客户集中度极高]** -> [经营风险高度集中]: 前五大客户销售占比76.98%，其中单一客户LG新能源占比46.27%，公司议价能力受限，业绩高度依赖核心客户订单稳定性。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司为绑定LG新能源、特斯拉等头部客户，主动下调成熟产品售价，导致营收增长8.65%的同时，净利润暴跌31.79%。这种以价换量的策略在产能爬坡期尤为危险——新增固定资产折旧、原材料涨价、人工成本上升三重压力叠加，毛利率持续承压。若未来核心客户进一步压价或订单转移，公司将面临盈利能力持续恶化的风险。

**大圆柱结构件业务前景不明。** 公司重金押注46系列大圆柱结构件，但2025年该产品营收同比下降29.94%，海外子公司中瑞韩国仍处于亏损状态。大圆柱电池量产进度不及预期，且特斯拉等客户可能自研结构件或引入其他供应商，公司先发优势存在被稀释的风险。募投项目已延期至2026年底，若市场放量再次推迟，巨额资本开支将转化为沉重的折旧负担。
