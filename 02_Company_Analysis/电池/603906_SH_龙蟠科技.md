# 603906.SH 深度透视

## 因果逻辑链
- **[磷酸铁锂出货量增长]** -> [营收增长16.42%]: 正极材料销量同比增长13.57%，带动营收增至89.38亿元，但行业产能过剩导致价格承压。
- **[碳酸锂等原料价格下行]** -> [毛利率改善]: 磷酸铁锂正极材料毛利率同比提升6.73个百分点至9.24%，成本降幅大于售价降幅。
- **[海外客户长期协议锁定]** -> [海外收入暴增1554%]: 与LGES、BlueOval等签订长协，印尼工厂投产，海外收入达12.19亿元。
- **[子公司引入战略投资者]** -> [筹资活动现金流大幅转正]: 锂源亚太、锂源印尼引入LGES等战投，筹资净额12.13亿元，缓解资金压力。
- **[收购山东美多]** -> [构建产业闭环]: 打通“碳酸锂—磷酸铁锂—锂电回收”链条，增强原材料自给与抗风险能力。
- **[非经常性损益大幅波动]** -> [扣非净利润大幅减亏]: 扣非净利润从-6.99亿收窄至-0.39亿，但归母净利润仍亏损1.73亿，主因少数股东回购义务等非经常性损失。
- **[产能利用率不足]** -> [固定成本摊销压力大]: 磷酸铁锂产能利用率76.27%，车用尿素仅31.83%，导致折旧与制造费用占比上升，侵蚀利润。

## 风险警告
**核心风险在于行业产能过剩与价格战持续。** 磷酸铁锂行业产能扩张远超需求增速，公司虽出货量增长，但毛利率仅9.24%，盈利能力脆弱。若碳酸锂价格反弹或下游需求不及预期，公司可能重回深度亏损。此外，公司总资产186.72亿，净资产仅28.28亿，资产负债率高达84.8%，财务杠杆极高，利息支出对利润形成巨大压力。

**海外扩张与垂直一体化存在不确定性。** 印尼二期等海外项目需大量资本开支，且面临地缘政治与本地化运营挑战。收购山东美多虽构建闭环，但电池回收业务尚处亏损初期，短期难以贡献利润。若海外客户订单执行不及预期或回收业务爬坡缓慢，将加剧现金流紧张状况。
