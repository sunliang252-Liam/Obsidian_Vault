# 301327.SZ 深度透视

## 因果逻辑链
- **[全球M2C直销模式深化]** -> [营收增长14.87%]: 品牌官网独立站营收同比增长27.14%，线下零售营收同比增长22.47%，全渠道渗透力增强。
- **[主动加大品牌推广与战略性备货]** -> [净利润暴跌92.84%至1715万元]: 为应对海外旺季需求，大幅增加销售费用和存货储备，严重侵蚀利润。
- **[地缘政治与贸易政策波动]** -> [核心子公司Jackery Inc.亏损]: 美国子公司受外部环境影响，销售毛利率下降，导致净利润同比大幅下滑，拖累合并报表。
- **[欧洲市场突破]** -> [营收同比增长115.72%]: 欧洲市场成为增长最快区域，验证了公司全球化布局在新兴市场的拓展能力。
- **[存货激增]** -> [经营活动现金流净额转负至-7.5亿元]: 库存量同比增长60.78%，大量资金被占用，导致经营性现金流大幅恶化。
- **[非经常性损益依赖]** -> [扣非净利润为-6849万元]: 核心业务盈利能力不足，净利润主要依赖现金管理产品投资收益（1.01亿元），主业实际亏损。
- **[研发投入资本化率为零]** -> [技术投入全部费用化]: 研发费用1.78亿元全部计入当期损益，未形成无形资产，短期压制利润但长期构筑技术壁垒。

## 风险警告
**核心风险在于“增收不增利”与现金流急剧恶化。** 公司营收增长14.87%，但归母净利润暴跌92.84%，扣非净利润更是亏损6849万元。盈利能力的断崖式下滑并非短期波动，而是源于主动加大促销、战略性备货及外部环境冲击的综合结果。更危险的是，经营活动现金流净额从2024年的+7.63亿元骤降至-7.5亿元，存货同比暴增60.78%，表明公司正以牺牲现金流和利润为代价换取市场份额，这种模式的可持续性存疑。

**第二重风险是业绩对非经常性损益的严重依赖。** 2025年净利润仅1715万元，而投资收益（主要来自现金管理产品）高达1.01亿元，这意味着剔除理财收益后，公司主营业务实际处于深度亏损状态。若未来市场利率下行或理财产品收益波动，公司将失去利润的最后遮羞布。同时，海外子公司Jackery Inc.的亏损、地缘政治及汇率波动等外部风险持续存在，公司并未展现出有效的对冲能力。
