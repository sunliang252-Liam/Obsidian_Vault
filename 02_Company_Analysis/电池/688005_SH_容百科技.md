# 688005.SH 深度透视

## 因果逻辑链
- **[产品结构升级滞后于市场需求]** -> [营收与利润双降]: 公司长期依赖高镍三元，而市场主流转向性价比更高的中镍高电压和磷酸铁锂，导致销量承压、毛利率下滑，全年归母净利润亏损1.87亿元。
- **[美国《大而美法案》限制]** -> [韩国子公司北美市场受阻]: 中国背景主体持股超25%的企业被认定为“被禁止外国实体”，导致公司韩国全资子公司面临北美客户流失和产能闲置风险，需进行股权架构调整。
- **[“一步法”工艺切入磷酸铁锂]** -> [开辟新增长曲线]: 公司通过并购和自研，以极简工艺（工序从15道压缩至6道，成本降低40%）快速进入磷酸铁锂赛道，并与宁德时代签订长期采购协议，为未来放量奠定基础。
- **[钠电正极与宁德时代深度绑定]** -> [确立战略增长引擎]: 公司自研的钠电正极材料获宁德时代认可，被指定为“第一供应商”，锁定不低于其总采购量60%的份额，为钠电业务提供确定性订单。
- **[磷酸锰铁锂满产满销]** -> [细分领域龙头地位巩固]: 公司磷酸锰铁锂产品连续三年销量翻番，在动力电池领域市占率第一，并于2025年Q4实现单季度盈利，成为稳定的利润贡献点。
- **[全球化布局与地缘政治风险并存]** -> [海外资产面临不确定性]: 韩国基地受法案影响需调整，波兰基地仍在建设中，海外业务短期贡献有限，且面临合规、汇率及运营成本等多重挑战。

## 风险警告
**核心风险在于地缘政治与合规危机。** 美国《大而美法案》直接冲击公司韩国子公司的北美市场，迫使公司进行复杂的股权架构调整（持股比例降至24.9%），若调整失败或海外融资受阻，将导致7万吨产能闲置和客户流失，对海外战略造成重大打击。此外，公司与LG化学的专利纠纷仍在持续，临时禁令申请可能影响韩国产线运营，构成长期法律隐患。

**业绩层面，公司正处于“青黄不接”的转型阵痛期。** 传统高镍三元业务受市场结构变化冲击，销量与毛利率双降，导致全年亏损。新业务（磷酸铁锂、钠电）虽已取得突破，但尚未进入大规模放量盈利阶段，短期内无法完全弥补传统业务的利润缺口。同时，公司因重大合同公告涉嫌误导性陈述被证监会立案调查，面临潜在的行政处罚和声誉风险，进一步加剧了经营不确定性。
