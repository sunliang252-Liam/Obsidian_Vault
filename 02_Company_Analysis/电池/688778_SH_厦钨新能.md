# 688778.SH 深度透视

## 因果逻辑链
- **[AI手机换机潮与钴出口管控]** -> [钴酸锂量价齐升]: 3C消费电子AI化带动换机需求，叠加刚果（金）钴出口管控引发下游提前备货，公司高电压钴酸锂销量同比增长41.31%，营收增长78.90%。
- **[差异化水热法磷酸铁锂]** -> [磷酸铁锂销量爆发式增长]: 公司凭借水热法技术解决低温性能痛点，聚焦快充动力与军工特种领域，实现销量同比增长2170.77%，从零到一打开市场。
- **[“主要原料成本+加工费”定价模式]** -> [毛利率基本稳定]: 公司采用成本加成定价，在原材料价格大幅波动时，能有效向下游传导成本压力，2025年整体毛利率仅微降0.09个百分点。
- **[大客户战略与深度绑定]** -> [营收高增长但客户集中度高]: 前五大客户销售额占比78.34%，其中第一大客户占比38.28%，确保了订单稳定性，但也带来了客户依赖风险。
- **[收购赣州豪鹏与设立循环科技]** -> [完善电池回收闭环]: 公司通过收购和设立子公司，打通“退役电池—资源回收—前驱体—正极材料”产业链，向上游资源延伸，增强原材料自给能力。
- **[法国基地与国内多基地扩产]** -> [全球化与产能扩张并行]: 法国4万吨三元材料项目、宁德7万吨正极材料项目等同步推进，旨在贴近海外客户并扩大规模，但新增产能消化存在不确定性。
- **[NL结构材料与补锂剂等前沿研发]** -> [构建未来技术护城河]: 公司持续高研发投入（5.45亿元），在NL结构、固态电池、补锂剂等下一代技术领域取得突破，为中长期增长储备动能。

## 风险警告
**核心风险在于行业产能过剩与客户集中度过高。** 2025年国内磷酸铁锂产量同比增长61.5%，三元材料产量同比增长25.4%，行业整体供过于求，价格战持续。公司虽凭借技术优势维持了毛利率稳定，但三元材料业务增速（+7.89%）远低于行业平均，市场份额面临被挤压风险。同时，前五大客户销售额占比高达78.34%，对单一客户的依赖度极高，一旦核心客户转向或自研材料，将对公司营收造成重大冲击。

**另一重大风险是原材料价格与地缘政治波动。** 公司成本中材料费用占比近90%，钴、镍、锂等金属价格受资源国政策（如刚果金钴出口管制、印尼镍新规）及地缘冲突影响极大。2025年钴价大幅上涨虽短期推高了营收，但也导致存货价值激增（存货占总资产31.07%）。若未来金属价格快速下跌，公司将面临巨大的存货减值风险，直接侵蚀利润。此外，海外《通胀削减法案》等政策壁垒，可能阻碍公司法国基地的客户拓展与盈利。
