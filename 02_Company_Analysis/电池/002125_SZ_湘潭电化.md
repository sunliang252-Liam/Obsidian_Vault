# 002125.SZ 深度透视

## 因果逻辑链
- **[原材料成本上涨]** -> [净利润下降28.43%]: 碳酸锂、进口氧化锰矿等原材料价格同比上涨，直接推高锰酸锂和电解二氧化锰生产成本，压缩利润空间。
- **[锰酸锂销量增长但毛利下滑]** -> [广西立劲亏损扩大]: 销量同比增长29.85%，但原材料成本涨幅远超售价涨幅，导致产品毛利率由正转负（-9.13%），子公司亏损加剧。
- **[EMD行业需求放缓]** -> [电解二氧化锰收入微降4.38%]: 下游一次电池出口量下降及去库存周期影响，但公司凭借大客户战略和高性能产品，稳住了市场份额和盈利基本盘。
- **[投资收益贡献显著]** -> [净利润降幅小于营业利润降幅]: 参股公司湖南裕能（磷酸铁锂龙头）净利润同比大增115%，贡献权益法投资收益约1.01亿元，成为利润的重要缓冲垫。
- **[可转债发行成功]** -> [资本结构优化与产能扩张]: 募集4.87亿元用于年产3万吨锰酸锂项目，短期增加财务费用，长期为产能扩张和产业链延伸提供资金支持。
- **[信用减值损失增加]** -> [侵蚀当期利润]: 应收账款坏账准备计提增加，导致信用减值损失同比扩大，对净利润产生负面影响。
- **[污水处理业务稳定]** -> [提供稳定现金流]: 采用“政府特许、政府采购”模式，业务稳定，但正面临市场化转型和按效付费机制改革的不确定性。

## 风险警告
**核心风险在于锰酸锂业务的持续亏损与原材料价格波动的高度耦合。** 公司锰酸锂业务虽销量增长，但受制于碳酸锂价格剧烈波动，产品毛利率已跌至-9.13%，子公司广西立劲亏损超8000万元。若未来原材料成本无法有效向下游传导，或下游需求增速放缓，该业务将成为公司利润的持续拖累，而非增长引擎。

**第二重风险来自行业竞争加剧与下游需求结构变化。** 电解二氧化锰（EMD）行业已进入存量博弈阶段，下游一次电池出口下滑，且面临锰酸锂专用型EMD被其他原料替代的压力。同时，新能源电池材料行业产能扩张迅速，锰酸锂市场竞争白热化，公司虽为头部企业，但盈利空间被严重挤压。此外，污水处理业务面临“按效付费”改革，未来收益存在不确定性。
