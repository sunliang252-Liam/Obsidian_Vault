# 300207.SZ 深度透视

## 因果逻辑链
- **[诉讼和解巨额赔偿]** -> [归母净利润同比-28%]: 威睿诉讼案和解导致2025年计提5-8亿元损失，直接侵蚀利润，扣非净利润同比-66.8%。
- **[动力电池出货量高增]** -> [营收增长12.9%]: 电动汽车类电池出货量42.72GWh（+68.9%），带动该板块收入189亿（+24.9%），成为营收增长核心引擎。
- **[储能业务爆发式增长]** -> [第二曲线初现]: 储能系统装机量25.6GWh（+188%），收入23.1亿（+22.4%），受益于全球AIDC储能需求及大容量电芯技术突破。
- **[消费电芯自供率提升]** -> [消费电池毛利率改善]: 消费类电池收入314亿（+3.3%），毛利率19.4%（+1.1pct），电芯自供比例扩大提升产品附加值。
- **[研发投入持续加大]** -> [技术壁垒与产品迭代]: 研发费用43.8亿（+31.5%），占营收6.9%，支撑固态电池、闪充4.0、大容量储能电芯等前沿产品落地。
- **[海外产能布局加速]** -> [应对地缘风险与贴近客户]: 越南消费电芯基地开工、泰国动力电池一期投产，强化区域供应链韧性，降低贸易摩擦风险。
- **[财务费用激增]** -> [侵蚀利润]: 财务费用6.5亿（+125.1%），主因汇兑收益减少及利息费用增加，反映海外业务扩张带来的资金成本与汇率波动压力。

## 风险警告
**核心风险：诉讼与资产减值的不确定性。** 2025年威睿诉讼和解已造成5-8亿利润损失，但公司仍有多个建设工程分包合同纠纷、买卖合同纠纷等未决诉讼，涉案金额合计超4亿元。若后续判决不利，将进一步冲击利润表。同时，动力电池业务毛利率仅4.86%（同比-3.94pct），行业价格战持续，存货跌价准备（资产减值3.7亿）压力不减。

**成长性风险：动力电池“增收不增利”困境。** 动力电池出货量虽高增68.9%，但收入增速仅24.9%，单价承压明显。该板块净利率极低，且子公司（如南昌欣旺达、南京欣旺达）仍处亏损状态。在行业产能过剩、竞争白热化背景下，公司需持续巨额资本开支（投资活动净流出93亿），若客户订单不及预期或技术路线切换，前期投入存在减值风险。
