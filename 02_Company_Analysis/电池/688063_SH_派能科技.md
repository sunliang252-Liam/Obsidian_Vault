# 688063.SH 深度透视

## 因果逻辑链
- **[国际储能市场需求回暖]** -> [营收增长57.81%]: 欧洲家储去库结束，新兴市场发货量攀升，直接拉动收入规模显著提升。
- **[国内储能及轻型动力市场攀升]** -> [销量增长178.24%]: 工商业储能、共享换电、钠电启停等新业务放量，推动总销售量达4,232MWh。
- **[行业竞争加剧导致产品价格承压]** -> [毛利率下降11.65个百分点]: 价格战与出口退税政策变动共同侵蚀利润空间，主营业务毛利率降至16.96%。
- **[出口退税政策变动]** -> [营业成本增速(82.92%)远超营收增速(57.81%)]: 成本端压力陡增，是利润总额下滑71.71%的核心原因之一。
- **[确认子公司可抵扣亏损递延所得税资产]** -> [归母净利润增长106.12%]: 非经常性损益（理财收益+政府补助）及税务处理共同推动净利润大幅转正，但扣非净利润仍为负。
- **[轻型动力业务爆发]** -> [营收增长16.1倍]: 共享换电(787MWh)和钠电启停(164MWh)成为第二增长曲线，但毛利率仅5.12%，盈利能力弱。
- **[加大营销与研发投入]** -> [销售费用增长106.25%]: 为抢占市场份额，公司积极扩充销售团队和广告投入，但研发费用同比减少7.29%。
- **[产销规模增长导致备货增加]** -> [存货增长120.31%]: 存货账面价值达15.86亿元，占总资产11.98%，带来显著的存货跌价风险。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收和销量虽大幅增长，但毛利率暴跌11.65个百分点，扣非净利润仍为负值。这揭示出公司在行业价格战中缺乏定价权，成本传导能力弱，盈利质量堪忧。若行业竞争进一步加剧或原材料价格反弹，公司可能陷入“卖得越多，亏得越狠”的恶性循环。

**第二重风险是资产质量恶化与现金流压力。** 存货激增120%至15.86亿元，应收账款增至10.77亿元，两者合计占总资产20%以上。同时，公司计提了5528万元的信用减值损失和3722万元的资产减值损失。若下游客户回款放缓或产品跌价，将直接冲击本已脆弱的利润表。此外，募投项目延期（10GWh基地延至2026年底，总部项目延至2028年），新增产能消化存在重大不确定性，未来折旧摊销压力巨大。
