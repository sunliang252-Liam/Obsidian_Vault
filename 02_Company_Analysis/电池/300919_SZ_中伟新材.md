# 300919.SZ 深度透视

## 因果逻辑链
- **[全球新能源市场增长 + 一体化产能释放]** -> **营收增长19.68%**: 下游新能源汽车、储能市场持续扩张，叠加公司印尼镍冶炼、摩洛哥基地等新产能投产，推动电池材料总销量超42万吨，营收达481.4亿元。
- **[镍系材料龙头地位 + 钴系材料高端化]** -> **核心业务基本盘稳固**: 三元前驱体市占率24%连续6年第一，钴系前驱体连续6年全球销量第一，高镍、超高镍及高电压产品技术领先，保障了核心业务的收入与利润。
- **[磷系材料后发优势 + 外销市场第一]** -> **打造第二增长曲线**: 磷酸铁出货量扣除自供后外销市场第一，营收同比增长130.3%，磷矿资源（9844万吨）已开工建设，正从“增量”向“提质”转变，成为重要利润增长极。
- **[印尼镍资源闭环 + 阿根廷锂矿布局]** -> **构筑成本与供应链安全护城河**: 锁定超6亿湿吨红土镍矿及20万金吨冶炼产能，实现镍原料自供；低成本获取超1000万吨LCE锂资源，有效对冲上游原材料价格波动风险。
- **[深度全球化布局 + 海外基地投产]** -> **打开欧美高端市场**: 摩洛哥基地一期投产，韩国LFP合资项目启动，境外收入占比提升至49.90%，成功规避单一市场风险，并贴近海外客户需求。
- **[H股上市 + A+H双平台]** -> **打通全球资本通道**: 2025年11月成功登陆港交所，成为新能源材料行业“A+H”第一股，募集资金约34.3亿港元，为全球化扩张提供长效资本支持。
- **[MSCI评级跃升至AA + 清洁能源占比62%]** -> **ESG成为全球竞争新壁垒**: 碳排放下降52%，ESG评级从BBB跃升至AA，跻身全球领导者行列，增强了国际客户与投资者的信任。

## 风险警告
**1. 现金流恶化与高杠杆扩张的背离风险。** 2025年公司营收增长19.68%，但经营活动现金流净额同比骤降65.16%至13.7亿元，远低于净利润。主要原因是采购付款大幅增加，反映出在行业价格战和原材料价格波动背景下，公司对上游议价能力可能减弱，营运资金占用加剧。同时，公司资产负债率仍处高位（总资产816亿，净资产241亿），在建工程和海外项目持续投入，若下游需求增速放缓或金属价格下跌，可能引发流动性压力。

**2. 地缘政治与资源民族主义的系统性风险。** 公司核心资源（印尼镍矿、阿根廷锂矿）及海外产能（摩洛哥、韩国）高度依赖海外。印尼政府已出台“控量提价、本土优先”的紧缩政策，未来可能进一步加征出口税或限制冶炼产能；阿根廷锂资源国有化风险亦不可忽视。任何海外运营地的政策突变、贸易壁垒或地缘冲突，都可能直接冲击公司供应链安全与盈利能力，这是公司全球化战略中最大的“灰犀牛”。

**公司简介（F10 原文）**

> 中伟新材料股份有限公司(中伟新材300919.SZ;中伟新材02579.HK)成立于2014年9月,是全球知名的新能源材料企业。公司被认定为国家企业技术中心、博士后科研工作站、国家高新技术企业、国家技术创新示范企业,获得“国家智能制造工厂”、“绿色制造工厂”等称号,已连续多年跻身《财富》中国500强、中国民营企业500强、中国制造业企业500强等榜单。中伟新材以技术创新为第一驱动力,聚焦镍、钴、磷、钠、锰、锂等新能源材料及前沿技术,并持续迭代,打造多样化、定制化、快速开发与量产的技术服务能力及产业化应用能力,助推行业技术发展。公司自主研发的新能源材料进入中国、欧美、日韩地区多家世界500强企业高端供应链,被广泛应用于3C、动力及储能领域。核心产品三元前驱体、四氧化三钴连续多年出货量稳居全球首位,磷酸铁材料跻身行业第一阵营。在国内,中伟新材已建立铜仁(上市主体)产业基地、宁乡产业基地、钦州产业基地、开阳产业基地,在海外,公司建有印尼四大产业基地,摩洛哥材料一体化基地,并规划在韩国等地建设海外基地,构建国内国际双循环格局,形成“资源开发—材料智造—全球循环”的新能源材料产业生态,整合全球资源、服务全球客户。秉承“材料至善科技致伟”的企业使命,中伟新材将以推动能源转型为己任,为全球可持续发展贡献力量,立志成为全球领先的新材料科学公司。
