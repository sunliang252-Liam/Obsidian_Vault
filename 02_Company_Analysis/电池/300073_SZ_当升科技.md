## 因果逻辑链
- **全球新能源汽车销量增长29.1%，特别是中国占比70.3%、欧洲增速30.5%** -> 公司锂电材料业务收入增长37.12%，销量增长47.87%: 下游需求拉动
- **公司高镍、超高镍、中镍高电压多元材料技术领先，并进入LGES、SK on、三星SDI等国际供应链** -> 多元材料收入20.66%增长，境外收入77.49%高增: 技术优势转化为客户订单，尤其海外市场突破
- **磷酸（锰）铁锂业务产能释放（攀枝花一期12万吨投产），产品压实密度迭代（2.58→2.68→2.75g/cm³）** -> 磷酸铁锂收入增长61.77%，毛利率提升5.56个百分点: 产能扩张叠加产品升级，量利齐升
- **钴价上行（刚果金出口管制）及高电压钴酸锂产品突破（4.55V量产）** -> 钴酸锂收入增长121.35%，毛利率提升10.41个百分点: 涨价叠加高端产品放量
- **芬兰基地6万吨高镍项目2025年上半年开工，预计2026年下半年投产** -> 支撑未来欧洲客户本土化供应，巩固国际业务优势: 海外产能布局响应客户本土化需求，增强竞争壁垒
- **全固态正极材料批量供货20吨级以上，固态电解质进入头部客户验证；钠电正极、富锂锰基小批量出货** -> 下一代电池材料储备形成先发优势，培育新增长极: 前瞻性研发转化为产业化能力，打开未来成长空间
- **控股股东矿冶集团现金全额认购10亿元定增，管理层与核心骨干股权增持计划** -> 增强资金实力，提振市场信心，助力穿越行业周期: 资本运作强化抗风险能力与激励机制
- **智能装备业务中，AI视觉检测系统（小样本深度学习平台）上线，缺陷检测时间减少50%，匣钵全生命周期管理** -> 智能装备收入增长11.06%，与锂电材料业务形成协同: 智能化升级提升竞争力，协同效应显现

## 风险警告
深度风险总结：1. 原材料价格波动风险：锂、镍、钴、磷等大宗原料价格波动可能压缩利润空间，公司虽有多元采购策略但无法完全对冲；2. 海外经营风险：芬兰基地面临欧洲政策变化、地缘政治及汇率波动，可能影响项目进度和盈利能力；3. 产能消化风险：攀枝花及芬兰新增产能若下游订单不及预期，可能导致产能利用率下降、折旧增加；4. 技术迭代风险：固态电池、钠电等下一代技术路线尚未大规模产业化，若技术路线切换不及预期或竞争对手突破，可能削弱先发优势；5. 客户集中度风险：公司深度绑定LGES、SK on等国际大客户，若客户需求波动或合作关系变化，将对业绩产生较大影响。
