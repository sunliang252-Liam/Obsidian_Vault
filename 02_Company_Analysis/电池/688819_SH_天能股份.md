# 688819.SH 深度透视

## 因果逻辑链
- **[铅蓄电池基本盘稳固]** -> [营收微增1.67%]: 铅蓄电池营收415.66亿，同比微降0.64%，但凭借超40万终端网点的渠道壁垒和以旧换新政策，稳住了基本盘，贡献了超90%的收入。
- **[锂电池业务爆发式增长]** -> [营收增长218.36%]: 锂电池营收15.71亿，同比大增218.36%，主要得益于储能市场突破（如温州龙湖100MW/200MWh项目）和通信储能头部客户（中兴S级供方）的深度合作。
- **[新国标与以旧换新政策红利]** -> [铅蓄电池需求结构性优化]: 新国标将铅酸车重限值提至63公斤，叠加以旧换新补贴，加速了低端产能出清，推动行业竞争从“价格战”转向“价值战”，利好龙头。
- **[海外业务高速扩张]** -> [境外收入增长80.54%]: 越南基地投产、东南亚及非洲市场开拓，境外收入达5.35亿元，成为增长最快的板块，但占总营收比例仍仅1.2%。
- **[原材料成本控制与锂电减亏]** -> [扣非净利润仅增0.17%]: 尽管营收增长，但铅价波动及锂电业务虽大幅减亏（毛利率从-30.7%升至-4.09%），仍拖累整体盈利，扣非净利润几乎原地踏步。
- **[高额政府补助与投资收益]** -> [归母净利润增长2.38%]: 非经常性损益达4.92亿元（其中政府补助4.71亿），是归母净利润（15.91亿）的重要支撑，掩盖了主营业务的盈利压力。
- **[研发投入维持高位]** -> [技术储备领先]: 研发费用18.57亿，占营收4.05%，重点投向固态电池（400Wh/kg）、钠电启停电池及氢燃料电池，为未来增长储备技术势能。

## 风险警告
**核心风险在于“现金牛”业务增长乏力与“增长引擎”尚未盈利的矛盾。** 铅蓄电池作为绝对主业（占营收90%+），营收已现微降，且受制于铅价波动（成本占比超70%）和消费税（4%），利润空间承压。锂电池业务虽增速惊人（+218%），但毛利率仍为负（-4.09%），意味着每卖一块锂电都在亏钱，尚未实现自我造血，高度依赖铅蓄电池的利润输血。

**财务结构存在短期流动性压力与关联交易依赖。** 公司资产负债率高达60.99%，且流动负债占比92.10%，短期偿债压力较大。同时，前五大供应商中关联方采购额占比高达29.46%，前五大客户中关联方销售额占比3.88%，存在一定的关联交易风险。此外，高达4.71亿元的政府补助对净利润贡献显著，若政策退坡，将直接冲击利润表。
