# 301487.SZ 深度透视

## 因果逻辑链
- **[钴酸锂产品量价齐升]** -> [营收增长29.38%，扭亏为盈]: 钴酸锂营收增长37.93%，毛利率提升5.89个百分点，成为利润核心支柱。
- **[NCA系列出货量激增435.5%]** -> [三元材料收入增长29.95%]: 小动力、具身智能等新兴场景需求爆发，推动高附加值NCA产品放量。
- **[原材料价格上涨传导至产品定价]** -> [钴酸锂均价上涨48.78%]: 公司采用“原材料成本+加工费”定价模式，成功将上游四氧化三钴、碳酸锂涨价向下游传导。
- **[研发投入增长53.33%]** -> [高电压钴酸锂及NCA产品迭代加速]: 4.53V钴酸锂进入批量阶段，第二代NCA实现百吨级出货，技术壁垒持续构筑。
- **[“成本管理年”精益化运营]** -> [钴酸锂生产成本下降10%，三元成本下降15%]: 通过工艺革新、设备升级和全要素成本地图，有效对冲原材料涨价压力。
- **[募投项目产能尚未完全释放]** -> [三元材料毛利率仅2.06%，且项目未达预期收益]: 三元市场竞争激烈，新产能爬坡期导致固定成本摊销较高，盈利承压。
- **[应收账款账龄结构改善]** -> [经营活动现金流净额大增201.41%]: 回款效率提升，经营性现金流远超净利润，财务质量显著优化。

## 风险警告
**核心风险在于三元材料业务盈利能力薄弱。** 尽管公司整体扭亏，但三元材料毛利率仅2.06%，远低于钴酸锂的14.61%。募投项目（年产1万吨正极材料）虽已投产，但截至报告期末累计实现收益为-1789万元，远低于预期3177万元。三元材料行业产能过剩、竞争白热化，若公司无法通过NCA等高附加值产品快速提升产能利用率和毛利率，该业务将持续拖累整体盈利。

**另一重大风险是原材料价格剧烈波动与客户集中度双高。** 公司前五大客户销售占比68.38%，前五大供应商采购占比70.24%，上下游均高度集中。钴、锂等核心原材料价格在2025年大幅上涨（钴酸锂均价涨48.78%），虽然公司通过定价模式传导成本，但若未来价格急跌，将面临存货减值风险（2025年存货同比大增80.8%至8.09亿元，已计提减值2055万元）。同时，对单一客户的过度依赖（客户一占营收30.8%）削弱了议价能力。
