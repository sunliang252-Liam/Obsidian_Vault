# 688733.SH 深度透视

## 因果逻辑链
- **[下游需求爆发]** -> [营收增长24.89%]: 新能源汽车及储能市场快速增长，带动锂电池涂覆材料（勃姆石）销量显著提升。
- **[研发投入激增]** -> [净利润由盈转亏]: 人工合成高纯石英砂、固体氧化物燃料电池等战略级项目研发支出同比大增40%，叠加管理变革费用及新增股份支付，侵蚀利润。
- **[全球龙头地位]** -> [市场份额持续提升]: 公司勃姆石出货量连续多年全球第一，2025年市占率进一步提升，主导行业节奏，国产替代加速。
- **[产品结构升级]** -> [小粒径勃姆石放量]: 契合隔膜轻薄化趋势，可将涂层减薄至1μm以下，出货增长明显，成为新增长点。
- **[第二增长曲线培育]** -> [高纯石英砂产业化在即]: 新型制备工艺突破“卡脖子”技术，已完成技术优化，预计2026年实现小批量出货，有望打开新市场。
- **[前瞻性战略布局]** -> [SOC全栈自研能力]: 实现从原料到系统的全产业链自主研发，示范工程进入调试阶段，发电效率超60%，但产业化周期长。
- **[管理变革与激励]** -> [期间费用大幅增加]: 实施新一期员工持股计划（新增股份支付），并推动组织架构升级，导致管理费用同比增幅较大。

## 风险警告
公司当前面临的核心风险是**“增收不增利”的困境与战略投入的持续性矛盾**。营收增长24.89%的同时，净利润却由盈转亏，主要系研发、管理及股份支付费用激增。若高纯石英砂、SOC等战略级新业务的产业化进度或市场推广不及预期，将无法及时弥补当前的利润缺口，导致公司长期处于“烧钱”状态，侵蚀股东价值。

其次，**客户与供应商的高度集中构成经营脆弱性**。前五大客户销售额占比48.39%，前五大供应商采购额占比高达78.41%，其中单一供应商A占比超70%。这种结构使公司对下游议价能力受限，且极易受上游原材料价格波动（氢氧化铝、氧化铝）及单一供应商供应中断的冲击，一旦核心客户或供应商出现重大不利变化，公司业绩将剧烈波动。
