# 301511.SZ 深度透视

## 因果逻辑链
- **[下游需求回暖+产能利用率提升]** -> [营收增长59.33%]: 新能源汽车与储能市场高景气，带动锂电铜箔出货量同比增长51.99%，规模效应摊薄固定成本。
- **[产品结构高端化]** -> [毛利率改善]: 极薄锂电铜箔（5μm及以下）与高端电子电路铜箔（HVLP、RTF、载体铜箔）出货占比提升，推动平均加工费上涨，锂电铜箔毛利率同比提升3.81个百分点。
- **[阴极铜成本占比高]** -> [利润对铜价波动敏感]: 原材料成本占营业成本85%左右，公司采用“铜价+加工费”定价，但传导存在时滞，短期铜价剧烈波动仍可能侵蚀利润。
- **[研发投入聚焦下一代技术]** -> [构筑长期竞争壁垒]: 研发费用2亿元，重点突破固态电池集流体（芯箔、PCF多孔铜箔）、AI服务器用HVLP5铜箔等，抢占未来市场先机。
- **[客户高度集中]** -> [经营依赖大客户]: 前五大客户销售额占比64.36%，其中宁德时代一家占36.20%，单一客户订单波动将显著影响公司业绩。
- **[经营活动现金流持续为负]** -> [盈利质量存疑]: 净利润1.13亿元，但经营现金流净额为-3.81亿元，主因大量票据贴现计入筹资活动，实际回款能力弱于账面利润。
- **[产能扩张与资本开支]** -> [财务杠杆高企]: 琥珀新材料等项目持续投入，短期借款增至64.70亿元，财务费用同比增40.63%，高负债运营加大财务风险。

## 风险警告
**核心风险在于盈利质量与现金流严重背离。** 公司2025年实现扭亏为盈，净利润1.13亿元，但经营活动现金流净额仍为-3.81亿元，连续三年为负。这主要源于销售回款中大量银行承兑汇票被贴现或背书转让，会计处理上未计入经营活动现金流入。这种“纸面利润”与“真实现金”的脱节，意味着公司实际造血能力远弱于报表表现，一旦融资环境收紧或下游客户付款周期拉长，可能引发流动性危机。

**客户集中度过高与行业产能过剩构成双重压制。** 公司对宁德时代的销售占比高达36.20%，前五大客户合计占比64.36%，议价能力受制于下游巨头。同时，电解铜箔行业综合产能利用率仅65%-70%，尽管头部企业满产，但行业整体供过于求格局未变。若下游需求增速放缓或加工费再次下行，公司高杠杆扩张的产能将面临减值风险，2025年已计提资产减值1656万元。
