# 002812.SZ 深度透视

## 因果逻辑链
- **[行业供需格局改善]** -> [隔膜价格企稳回升]: 2023年以来行业深度洗牌，落后产能出清，订单向头部集中，2025年下半年供需结构改善，推动产品价格逐步回升。
- **[公司市场份额持续第一]** -> [销量大幅增长45.50%]: 凭借全球最大产能规模与优质客户群，在行业集中度提升中受益，实现以量补价，销量达128.40亿平方米。
- **[涂布膜等高附加值产品占比提升]** -> [毛利率同比增长10.62个百分点]: 优化产品结构，提升涂布膜等高毛利产品占比，叠加成本控制，隔膜业务毛利率显著改善至18.01%。
- **[全球化布局与海外客户深度绑定]** -> [境外收入稳中有升]: 与LGES、ACC等国际客户签订长期协议，匈牙利基地投产，境外收入达22.89亿元，占比16.79%。
- **[规模效应与工艺优化]** -> [综合成本优势突出]: 全球最大产能带来集中采购优势，单线产能行业领先，辅料回收利用率高，有效摊薄单位折旧、能耗及人工成本。
- **[研发投入持续高强度]** -> [新产品迭代与前瞻技术储备]: 研发费用6.90亿元，推出高安全基膜X系列、5μm超薄基膜等新品，硫化物固态电解质十吨级中试线贯通。
- **[存货周转优化与去库存]** -> [经营活动现金流显著高于净利润]: 净现比高，主要因重资产行业折旧摊销大，同时公司加大去库存力度，资金回笼成效明显。

## 风险警告
**行业竞争与价格风险**：尽管2025年供需格局有所改善，但锂电池隔膜行业产能过剩的长期压力并未根本消除。若下游需求增速放缓或新增产能再次集中释放，隔膜价格可能再度承压，公司毛利率改善的可持续性存疑。公司当前净利润仅1.43亿元，盈利基础仍十分薄弱，对价格波动高度敏感。

**全球化与地缘政治风险**：公司正加速海外产能布局（匈牙利、美国），但海外基地（如美国恩捷）仍处于建设期，尚未贡献正收益。欧美贸易保护主义抬头、本土化制造政策要求及汇率波动，可能显著增加海外运营成本与不确定性，导致海外项目投资回报不及预期，甚至拖累整体业绩。
