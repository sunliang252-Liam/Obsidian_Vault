# 000695.SZ 深度透视

## 因果逻辑链
- **[产能快速扩张与下游需求增长]** -> [营收增长但亏损扩大]: 负极材料产销量同比增46%，营收增37%，但产能爬坡期固定成本高、原料价格波动，导致毛利率仅0.2%，净利润亏损扩大至-8814万元。
- **[一体化产能建设与源网荷储绿电项目]** -> [资本开支激增与现金流恶化]: 在建工程从1.6亿飙升至10.6亿，经营活动现金流净额从+30万骤降至-3.39亿，公司处于大规模投资扩张的“失血”阶段。
- **[控股股东大额借款与担保]** -> [财务杠杆急剧攀升]: 筹资活动现金流净额+4.55亿，主要来自控股股东借款，有息负债增加导致财务费用同比增55.6%，总负债达26.6亿，资产负债率94.2%。
- **[客户集中度高与关联采购依赖]** -> [经营独立性风险]: 前五大客户销售占比64.7%，前五大供应商采购占比68.4%，其中关联方采购占36.9%，公司对上下游均存在较高依赖。
- **[原材料价格波动与电价成本]** -> [成本控制压力]: 石油焦价格呈“M”型走势，石墨化耗电量大，虽然内蒙古有电价优势，但成本端仍面临双重压力，导致毛利率极低。
- **[硅碳负极新材料布局]** -> [未来增长点但短期无贡献]: 收购邢台新能源、筹建包头硅碳项目，打通硅基负极一体化路径，但尚处研发与中试阶段，短期内无法贡献利润。
- **[连续三年扣非净利润为负]** -> [持续盈利能力存疑]: 2023-2025年扣非净利润分别为-3739万、-3260万、-8545万，公司尚未证明其核心业务的盈利模式。

## 风险警告
**核心风险在于“增收不增利”与现金流枯竭的恶性循环。** 公司营收增长依赖产能扩张，但毛利率仅0.2%，几乎处于盈亏平衡点以下。大规模资本开支导致经营活动现金流净流出3.39亿元，完全依赖控股股东借款和融资租赁“输血”。若下游需求放缓或产品价格继续承压，公司将面临严重的流动性危机。

**第二大风险是高度依赖关联方与单一客户。** 前五大客户销售占比超64%，前五大供应商中关联方采购占比高达36.9%。这种结构不仅削弱了公司的议价能力，更将经营风险与控股股东旭阳控股深度绑定。一旦关联交易或客户关系出现变化，公司业务将遭受重大冲击。
