# 300953.SZ 深度透视

## 因果逻辑链
- **[储能电池需求爆发]** -> [锂电池结构件收入快速增长]: 2025年中国储能电池出货量同比增长85%，公司作为宁德时代、亿纬锂能等头部客户的核心供应商，直接受益于下游扩产，带动精密结构件收入同比增长37.67%。
- **[规模效应与精细化管理]** -> [净利润增速远超营收增速]: 营收增长36.58%的同时，归母净利润增长101.98%。收入规模扩大摊薄固定成本，叠加自动化产线升级、视觉检测全面铺开，有效降低单位成本，毛利率提升2.25个百分点。
- **[粘胶铁芯技术突破]** -> [电机铁芯盈利能力提升]: 公司自研的模内点胶工艺（粘胶铁芯）逐步被下游客户认可，收入占比显著提升。该技术减少涡流损耗、降低噪音，属于高附加值产品，带动电机铁芯整体毛利率改善。
- **[模具技术外溢]** -> [切入人形机器人赛道]: 公司以精密级进冲压模具技术为根基，将超精密机械加工能力延伸至反向式行星滚柱丝杠、线性执行器、灵巧手零部件，已获国内外头部本体客户验证并小批量供货，开辟第二增长曲线。
- **[大客户深度绑定]** -> [收入确定性高]: 前五大客户销售占比66.65%，其中第一大客户（推测为宁德时代）占比39.48%。客户认证周期长、替代成本高，形成长期稳固合作关系，保障订单稳定。
- **[海外产能布局]** -> [规避贸易壁垒风险]: 塞尔维亚工厂已顺利投产，匈牙利、塞尔维亚子公司设立，实现电机铁芯海外本地化生产，降低北美关税冲击，并为拓展欧洲客户奠定基础。
- **[研发投入持续加码]** -> [保持技术领先]: 研发费用3.84亿元，同比增长30.30%，聚焦0.2mm超薄材料冲压、非晶材料模具、人形机器人精密传动等前沿领域，确保在模具和结构件领域的技术护城河。

## 风险警告
**第一大客户依赖与应收账款高企风险。** 公司对第一大客户（宁德时代）销售额占比高达39.48%，客户集中度极高。同时，应收账款期末余额达42.37亿元，占总资产32.48%，且同比增长39.6%，远超营收增速。若核心客户调整采购策略或出现财务问题，将对公司现金流和资产减值造成重大冲击。

**人形机器人业务尚处早期，投入产出不确定性大。** 公司虽已切入人形机器人赛道，但该业务收入占比仅0.15%，且需在技术研发、设备选型、产线建设上进行大规模前期投资。行业尚处“0-1”阶段，商业化路径、量产规模、客户需求均存在极大不确定性，短期难以贡献实质利润，存在投资回报不及预期的风险。
