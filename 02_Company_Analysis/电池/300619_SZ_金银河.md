# 300619.SZ 深度透视

## 因果逻辑链
- **[固态电池/干法电极设备突破]** -> [业绩扭亏为盈]: 公司“黄金龙”干法成膜复合固态机组实现销售，切入下一代电池技术赛道，成为2025年扭亏的核心增量。
- **[储能电池设备需求爆发]** -> [锂电池设备收入增长53.75%]: 储能电池扩产拉动公司定制化智能产线订单，该业务板块收入与订单规模同比快速增长。
- **[锂云母全元素提取项目达产]** -> [铷铯盐等高附加值产品形成销售]: 子公司金德锂“低温硫酸法”项目实现铷铯盐规模化生产，从单一碳酸锂销售升级为多产品矩阵，提升综合盈利能力。
- **[低温硫酸法技术颠覆传统]** -> [解决锂渣环保痛点，重塑成本模型]: 公司独创工艺将每吨碳酸锂固渣从30吨降至0.3吨，且综合提锂成本低于锂辉石，构筑了核心竞争壁垒。
- **[有机硅装备龙头地位]** -> [设备业务毛利率提升4.36个百分点]: 公司凭借连续法全自动生产线全覆盖优势，在行业产能出清周期中，通过产品结构优化和成本管控实现毛利率修复。
- **[研发投入持续高增]** -> [技术护城河加深]: 研发费用同比增长29.12%，聚焦固态电池、高纯金属铷铯、钙钛矿材料等前沿领域，为未来增长储备技术势能。
- **[经营活动现金流大幅转正]** -> [经营质量改善]: 现金流从-4.6亿元大幅转正至+1.9亿元，主要系销售回款增加，表明公司收入质量与运营效率显著提升。

## 风险警告
**核心风险在于高额应收账款与信用减值。** 公司应收账款占总资产比例高达26.83%，且2025年信用减值损失高达3500万元，占利润总额的-236%。下游电池行业产能过剩与客户付款周期延长，可能导致坏账风险持续侵蚀利润，这是公司盈利质量的最大隐患。

**另一风险是新技术产业化不及预期。** 公司未来增长高度依赖固态电池设备、铷铯盐等高附加值业务的放量。若固态电池产业化进程慢于预期，或铷铯盐市场开拓受阻，公司可能面临研发投入无法转化为收入的困境，重回亏损。此外，公司资产负债率较高，短期借款超10亿元，财务费用压力较大，对利率变动敏感。
