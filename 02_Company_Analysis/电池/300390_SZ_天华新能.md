# 300390.SZ 深度透视

## 因果逻辑链
- **[锂盐价格回暖]** -> [营收增长14.23%]: 2025年锂价“先稳再跌后涨”，年底回升至10万元/吨，带动公司锂电材料业务收入同比增长12.93%。
- **[锂电材料毛利率暴跌]** -> [净利润腰斩]: 锂电材料毛利率从2024年的21.10%骤降至13.62%，导致归母净利润同比大幅下降51.77%。
- **[锂矿采购支出激增]** -> [经营现金流大幅转负]: 报告期锂电购矿款增加，导致经营活动现金流出同比大增51.18%，经营性现金流净额由正转负至-3.22亿元。
- **[下游需求结构性分化]** -> [储能成新增长极]: 2025年储能电池销量同比增101.3%，占比提升至29.4%，对冲了动力电池增速放缓的影响。
- **[上游资源布局加速]** -> [资本开支与负债双升]: 公司收购天华时代、竞拍锂矿探矿权，导致长期借款同比暴增258%，资产负债率上升。
- **[防静电业务稳健增长]** -> [多元化对冲锂电波动]: 防静电超净技术产品收入同比增长35.95%，毛利率稳定，有效缓冲了锂电业务的下滑冲击。
- **[套期保值平抑风险]** -> [非经常性损益贡献利润]: 公司利用碳酸锂期货套保，报告期实现投资收益2.06亿元，成为利润的重要补充。

## 风险警告
**核心风险在于锂电材料业务的盈利修复高度不确定。** 尽管2025年营收增长，但锂电材料毛利率已从2021年的60%+跌至13.62%，逼近盈亏平衡线。公司通过大量举债（短期借款+长期借款合计58亿元）扩张上游资源，若锂价再次下行，将面临“高库存减值+高利息支出”的双重挤压，经营现金流已转负，财务韧性承压。

**第二重风险来自资源自给战略的兑现难度。** 公司全球布局锂矿（非洲、南美、四川），但海外项目面临地缘政治、当地政策变动及开发周期长等不确定性。报告期内，公司通过并购和竞拍获取矿权，但尚未形成大规模量产贡献，上游成本优势尚未建立。若锂精矿价格波动或供应中断，公司“一体化”战略将面临严峻考验。
