# 300674.SZ 深度透视

## 因果逻辑链
- **[AI原生改造核心系统]** -> [毛利率提升3.08%]: 将信贷审批、风控等模块从“规则驱动”升级为“模型驱动”，降低人工成本，提升高附加值平台化输出占比。
- **[创新运营业务规模化]** -> [收入增长38.26%]: 零售信贷转型、场景金融（普惠/汽车金融）及海外联合运营模式成熟，从项目制转向持续性运营分成。
- **[海外市场梯次突破]** -> [海外收入增长102.83%]: 港澳深耕、东南亚布局、欧洲标杆落地（伦敦分行数据平台），将国内信创全栈能力产品化输出。
- **[AI Agent落地信贷场景]** -> [巩固信贷市场领导地位]: 智能尽调、审批等产品在30余家金融机构上线，深度嵌入高频场景，提升客户粘性与复购率。
- **[监管合规政策驱动]** -> [监管业务线中标额创新高]: “一表通”、可信区等项目受政策强制推动，公司凭借全链路模型能力持续获取订单。
- **[研发投入资本化]** -> [短期利润平滑]: 将大模型场景平台等研发支出资本化（1.86%），在保持高强度研发（10.09%）的同时，避免对当期利润造成过大冲击。
- **[H股上市筹划]** -> [资本与战略协同]: 为全球化布局和AI/Web3技术投入储备资金，提升国际品牌形象，支撑长期战略落地。

## 风险警告
**核心风险在于“AI+全球化”战略的高投入与收入结构转型的不确定性。** 公司营收同比下降8.46%，主要受传统银行IT解决方案收入下滑8.35%拖累，而高增长的创新运营业务（+38.26%）和海外业务（+102.83%）体量尚小（合计仅占5.17%）。AI原生改造和海外扩张均需持续大额资本开支（投资活动净流出同比暴增5524%），若新业务增速不及预期，将面临现金流压力与利润侵蚀。

**客户集中度与季节性波动是固有顽疾。** 银行业客户收入占比超85%，前五大客户贡献41.36%营收，客户IT预算波动将直接冲击业绩。同时，第四季度收入占比高达39.65%，这种高度集中的收入确认节奏，使得公司全年经营现金流管理难度极大，任何项目验收延迟都可能导致全年业绩不达预期。
