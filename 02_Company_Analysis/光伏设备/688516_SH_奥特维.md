# 688516.SH 深度透视

## 因果逻辑链
- **[光伏行业产能严重过剩]** -> [营收与利润双降]: 下游客户扩产放缓、验收周期拉长，导致公司2025年营收同比下滑30.60%，归母净利润同比下滑64.64%。
- **[核心产品串焊机市占率超60%]** -> [业绩韧性]: 尽管行业低迷，公司凭借串焊机等核心产品的绝对优势地位，仍保有98.77亿元在手订单，维持了基本盘。
- **[锂电/储能及半导体业务高速增长]** -> [结构性对冲]: 锂电/储能设备新签订单增长69.64%，半导体设备新签订单增长107%，有效对冲了光伏主业的下滑，成为第二增长曲线。
- **[海外市场拓展]** -> [收入结构优化]: 境外销售收入同比增长13.82%，占比提升至29.23%，部分弥补了境内市场因行业调整带来的收入缺口。
- **[研发投入持续加大]** -> [技术壁垒与新品储备]: 研发费用同比增长6.18%，重点布局0BB、BC、钙钛矿叠层及半导体封测设备，为下一轮技术迭代储备竞争力。
- **[应收账款与存货高企]** -> [现金流与减值风险]: 应收账款同比增长22.30%，存货占总资产30.49%，客户经营恶化导致回款放缓及减值计提增加，是利润下滑的直接财务原因。
- **[客户集中度高]** -> [经营脆弱性]: 前五大客户销售占比45.80%，且部分客户出现亏损，单一客户经营风险易传导至公司，增加了业绩波动性。

## 风险警告
**核心风险在于光伏行业深度调整的持续性与传导效应。** 公司超70%收入仍依赖光伏设备，当前行业产能出清进度低于预期，客户普遍亏损，导致公司产品验收周期拉长、应收账款逾期增加、存货跌价风险上升。2025年业绩已出现断崖式下滑，若行业景气度未见底，公司可能面临在手订单取消或延缓执行、资产减值进一步扩大的恶性循环。

**第二增长曲线的成长性与不确定性并存。** 锂电/储能和半导体业务虽增速亮眼，但绝对体量尚小，短期内无法完全弥补光伏主业的下滑。半导体设备毛利率同比下降7.06个百分点，显示新业务尚处于“以价换量”的竞争阶段。此外，美国“对等关税”等贸易政策对海外订单的潜在冲击，以及技术路线快速迭代（如BC、钙钛矿）带来的研发失败风险，均是公司未来经营中的重大不确定性因素。
