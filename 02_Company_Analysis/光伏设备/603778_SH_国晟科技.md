# 603778.SH 深度透视

## 因果逻辑链
- **光伏行业产能过剩、竞争激烈** -> 公司光伏组件及电池业务毛利率大幅下降: 行业供大于求导致组件价格下跌，公司组件及电池毛利率从-0.82%下降至-20.99%（减少20.17个百分点）。
- **光伏组件及电池毛利率大幅下降** -> 公司营业收入大幅下降61.97%: 毛利率下降和订单减少共同导致收入下滑。
- **营业收入大幅下降** -> 归属于母公司净利润大幅亏损（-57,316.71万元）: 收入下降而成本、费用相对刚性，导致亏损扩大。
- **园林生态业务竣工结算审减** -> 园林生态业务毛利率极低（-786.95%）: 东方市福民公园景观EPC工程和经河、荥河县城段河道治理PPP工程项目竣工结算，甲方审减冲减当期营业收入1,367.41万元，导致毛利率大幅为负。
- **光伏行业产能过剩** -> 公司光伏电池产量大幅下降96.91%，销量下降94.44%: 公司战略性放弃部分非优质订单，以及产线开工率不足，导致产量和销量大幅下降。
- **产线开工率不足** -> 管理费用中闲置固定资产折旧摊销增加: 产线闲置导致相关固定资产折旧计入管理费用，推高管理费用。
- **光伏组件价格下跌及订单减少** -> 经营活动现金流净额下降39.20%: 销售收入减少，同时支付光伏组件采购款较多，导致经营现金流下降。
- **行业政策鼓励分布式光伏和绿证** -> 公司光伏电站EPC业务收入下降80.85%: 公司战略放弃非优质订单，聚焦优质订单，导致EPC业务收缩。

## 风险警告
公司面临多重风险：光伏行业产能过剩导致产品价格持续下跌，毛利率转负，叠加产线开工率不足，固定成本高企，亏损持续扩大。园林生态业务因结算审减，收入确认不确定性高。同时，研发投入大幅减少65.47%，可能影响长期技术竞争力。财务费用因借款增加而上升，现金流状况恶化。
