# 300118.SZ 深度透视

## 因果逻辑链
- **[光伏行业供需严重错配]** -> [组件价格持续低位运行]: 产业链各环节产能集中释放，导致组件价格大幅下跌，公司太阳能电池及组件业务毛利率为-7.41%，陷入亏损。
- **[组件销量与价格双降]** -> [营业收入同比骤降37.82%]: 太阳能组件销售量同比下降45.62%，叠加价格下跌，导致营收从202亿元缩水至126亿元。
- **[计提大额资产减值损失]** -> [归母净利润巨亏28.27亿元]: 基于谨慎性原则，对固定资产、存货等计提减值损失9.39亿元，是导致巨额亏损的核心因素之一。
- **[电站EPC业务爆发式增长]** -> [部分对冲组件业务下滑]: 电站EPC与转让收入同比大增81.03%，营收占比从9.17%提升至26.68%，成为公司重要的收入来源。
- **[收缩户用电站投资]** -> [经营性现金流大幅转正]: 减少户用光伏电站的投入，支付的材料款、施工款大幅减少，经营活动现金流净额从-43.23亿元转为+14.10亿元。
- **[HJT技术领先]** -> [伏曦组件出货量翻倍]: 凭借0BB、超薄硅片等核心技术，HJT组件出货量增幅超100%，在技术迭代中抢占先机，但尚未转化为盈利。
- **[全球化布局与贸易壁垒]** -> [海外业务承压]: 境外销售同比下降39.23%，面临关税壁垒、反规避调查等风险，海外业务稳定性与盈利能力受到挑战。

## 风险警告
**核心风险：行业供需失衡导致的持续亏损与资产减值。** 公司已连续两年巨亏（2024年-34.36亿，2025年-28.27亿），核心组件业务毛利率为负。在行业产能出清完成前，产品价格可能持续低位运行，公司盈利能力难以根本性改善。同时，高达9.39亿的资产减值损失表明公司大量固定资产和存货面临贬值风险，若行业景气度继续下行，未来仍有大额减值压力。

**次要风险：高负债与流动性压力。** 公司资产负债率较高，短期借款高达65.41亿元，而货币资金仅31.58亿元（其中16.41亿为受限保证金）。尽管经营性现金流有所改善，但筹资活动现金流净流出23.45亿元，显示公司偿债压力巨大。此外，公司因信息披露违规被监管处罚，暴露出内部治理与合规风险，可能影响投资者信心。
