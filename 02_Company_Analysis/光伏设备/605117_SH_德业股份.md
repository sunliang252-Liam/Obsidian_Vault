## 因果逻辑链
- **[全球光储需求爆发 + 产品矩阵协同]** -> **储能电池包营收增长56.34%**: 户用及工商业储能需求旺盛，公司逆变器与电池包深度融合，形成“光储一体”解决方案，带动电池包销量与收入高速增长。
- **[欧洲、中东、非洲等新兴市场开拓]** -> **外销收入增长22.65%**: 公司抓住欧洲补贴政策、中东能源转型及乌克兰战后重建等机遇，在波兰、伊拉克、南非等市场实现突破，海外收入占比提升至80%。
- **[低压储能逆变器技术领先 + 差异化竞争]** -> **全球户用储能逆变器收入排名第一**: 公司率先推广16kW单相/20kW三相低压逆变器，兼顾安全、成本与效率，在5-20kW细分市场连续三年出货量全球第一。
- **[垂直整合供应链 + 核心元器件国产化]** -> **维持高毛利率水平**: 公司自产机箱等结构件，并率先批量采购国产IGBT，将本地制造组件占比提升至约90%，有效对冲原材料价格波动，逆变器毛利率仍超47%。
- **[“立体营销+品牌出海+深度本地化”]** -> **全球渠道护城河**: 公司在20余国建立售后服务中心，通过OEM/ODM快速切入新市场，再以自主品牌深耕，构建了难以复制的本地化服务与品牌优势。
- **[环境电器业务下滑]** -> **整体营收增速放缓至9.08%**: 受“回南天”缩短、国补减弱及地产低迷影响，除湿机营收下滑16.91%，拖累整体增速，但新能源业务仍为绝对增长引擎。

## 风险警告
**1. 贸易政策与地缘政治风险**：公司外销收入占比超80%，高度依赖海外市场。美国301调查已将光伏逆变器纳入征税范围，欧盟、印度等地也存在贸易保护主义倾向。马来西亚生产基地尚在建设，短期无法完全对冲关税风险。若主要市场出台不利的贸易政策，将对公司出口业务造成重大冲击。

**2. 技术迭代与竞争加剧风险**：逆变器行业技术更新快，若公司在转换效率、功率密度等关键指标上落后于革命性技术路线（如碳化硅器件），或未能及时满足电网对主动支撑能力等新要求，可能丧失技术优势。同时，行业同质化竞争日趋内卷，价格战可能侵蚀公司高毛利水平。

**3. 产能扩张与H股上市的不确定性**：公司正大规模投资马来西亚及国内工商储产线，若市场需求不及预期或产能爬坡不顺，将导致资产收益率下滑。此外，筹划H股上市虽能拓宽融资渠道，但面临国际资本市场波动、汇率风险及两地监管合规成本增加等挑战。
