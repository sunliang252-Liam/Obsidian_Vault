# 300827.SZ 深度透视

## 因果逻辑链
- **[海外光储业务高速扩张]** -> [营收增长17.95%]: 海外收入同比暴增78.14%，成为核心增长引擎，弥补国内收入微降的缺口。
- **[海外市场高毛利]** -> [毛利率稳定]: 海外毛利率32.32%，虽略降0.42%，但高毛利业务占比提升，对冲国内竞争压力。
- **[全球光伏逆变器出货量第四]** -> [品牌壁垒与客户粘性]: 连续两年蝉联全球第四，与国电投、TATA等顶级客户深度绑定，构筑护城河。
- **[研发投入持续高增]** -> [技术迭代与产品领先]: 研发费用3.28亿（+13%），布局大组串、液冷PCS、制氢电源，巩固技术优势。
- **[定向增发募资16.4亿]** -> [资本结构优化与产能扩张]: 募资净额16.38亿，用于25GW组串式逆变器及15GW储能变流器项目，支撑未来增长。
- **[储能PCS出货量国内前二]** -> [第二增长曲线确立]: 连续五年稳居国内前二，储能业务收入20.37亿，成为与光伏并驾齐驱的主营业务。
- **[财务费用激增390.88%]** -> [侵蚀利润]: 汇兑损失及融资费用增加，导致财务费用从0.2亿飙升至1.0亿，是利润增速低于营收增速的主因。

## 风险警告
**1. 现金流与利润严重背离，经营质量存疑。** 净利润4.63亿，但经营性现金流仅0.77亿，同比大降36.42%。公司解释为“回款减少”及“支付到期款项”，这揭示了在营收高速增长背后，应收账款和存货占用了大量资金，盈利质量堪忧。若回款持续恶化，可能引发流动性危机。

**2. 海外业务面临地缘政治与汇率双重冲击。** 海外收入占比已升至36.82%，但全球贸易保护主义抬头（如美国关税）、地缘冲突（中东、欧洲）以及人民币汇率波动，均可能直接冲击公司海外订单和利润。公司虽提及套期保值，但财务费用已因汇兑损失暴增，风险敞口巨大。

**3. 行业竞争白热化，价格战与产能过剩风险高悬。** 光伏和储能行业新进入者众多，产能过剩导致价格战持续。公司国内业务毛利率已出现下滑（-1.24%），若竞争进一步加剧，将严重压缩利润空间。同时，公司大规模扩产（25GW+15GW项目）若遇行业需求放缓，将面临产能利用率不足和资产减值的风险。
