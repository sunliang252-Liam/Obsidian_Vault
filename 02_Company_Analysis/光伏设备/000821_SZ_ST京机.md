# 000821.SZ 深度透视

## 因果逻辑链
- **[光伏行业产能过剩，下游客户扩产放缓]** -> [光伏设备营收下降33.41%]: 下游组件企业开工率波动、设备采购需求收缩，直接冲击公司最大收入来源。
- **[锂电行业景气回升，头部客户扩产]** -> [锂电设备营收增长101.57%]: 动力及储能电池需求回暖，公司新签订单超20亿元，成为核心增长引擎。
- **[光伏设备营收大幅下滑]** -> [归母净利润下降53.91%]: 高毛利主业收入萎缩，叠加信用减值损失1.52亿元，利润被严重侵蚀。
- **[下游客户经营承压，回款困难]** -> [信用减值损失1.52亿元]: 光伏行业调整导致应收账款逾期比例上升，资产质量恶化。
- **[海外业务受贸易摩擦及汇率波动影响]** -> [国外营收下降46.68%]: 欧美市场增速放缓，人民币汇率双向波动，海外项目收益承压。
- **[包装装备智能化升级需求释放]** -> [包装设备营收增长2.19%]: 数码印刷与智慧工厂业务成为增长亮点，但传统业务增长乏力。
- **[公司加强现金流管控]** -> [经营活动现金流净额由负转正，达2.09亿元]: 通过减少采购支出、优化交付节奏，现金流状况显著改善。

## 风险警告
公司当前最大风险在于光伏主业深度承压。光伏行业产能过剩导致下游客户资本开支谨慎，设备验收周期延长，公司光伏设备营收同比下滑33.41%，直接拖累整体利润。更严峻的是，客户经营恶化已引发大规模信用减值（1.52亿元），若行业调整持续，应收账款和存货减值风险将进一步侵蚀利润，现金流可能再度承压。

锂电装备虽高速增长，但客户集中度极高，单笔合同超10亿元，存在单一客户依赖风险。若该客户经营或扩产节奏变化，将对锂电业务造成重大冲击。此外，海外业务受贸易摩擦和汇率波动影响显著，国外营收下降46.68%，全球化战略面临结构性挑战。公司需在光伏主业复苏前，尽快培育锂电和包装新增长极，以对冲周期波动。
