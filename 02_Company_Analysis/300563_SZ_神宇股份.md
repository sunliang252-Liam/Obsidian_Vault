# 300563.SZ 深度透视

## 因果逻辑链
- **主动收缩低毛利黄金拉丝业务** -> **营收下降但扣非净利润大增93.83%**: 公司战略性放弃毛利率极低的黄金拉丝业务（收入同比-69.06%），虽拖累总营收下降3.70%，但显著优化了利润结构，使扣非净利润从0.38亿跃升至0.74亿。
- **核心主业同轴电缆量价齐升** -> **通信设备业务收入增长14.43%**: 受益于消费电子回暖、AI算力基建及汽车智能化，公司核心射频同轴电缆产品销量与单价同步提升，成为利润增长的核心引擎。
- **下游多领域需求爆发** -> **产品结构向高附加值领域迁移**: 航空航天（卫星通信）、高端医疗（一次性内窥镜）、高速数据线（PCIE5.0/6.0/7.0）等新兴领域订单放量，推动产品组合向高毛利、高技术壁垒方向升级。
- **成功发行5亿元可转债** -> **资产负债表扩张与产能建设启动**: 2025年底完成可转债发行，募集资金净额4.93亿元，专项用于“智能领域数据线建设项目”，货币资金暴增20.69个百分点至40.95%，为未来产能扩张奠定资金基础。
- **股权激励费用摊销** -> **短期压制账面净利润**: 报告期内计提股权激励管理费用1,497.04万元，直接侵蚀当期利润，但旨在绑定核心团队，驱动长期价值创造。
- **经营活动现金流净额暴增146.81%** -> **盈利质量显著改善**: 现金流从0.94亿飙升至2.33亿，远超净利润，主因是主营业务利润增加、应付票据/账款增加及应收票据减少，表明公司回款能力与产业链议价权增强。
- **主动剥离低效资产** -> **聚焦射频同轴电缆主业**: 公司通过减少黄金拉丝业务、处置非核心资产，将资源集中于高成长性的通信设备主业，实现战略聚焦。

## 风险警告
**第一，原材料价格波动与市场竞争加剧的双重挤压风险。** 公司核心原材料铜材价格与国际市场高度联动，若铜价持续高位运行，将直接推高生产成本。同时，射频同轴电缆市场面临跨国巨头（如Belden、Gore）与国内新兴企业的激烈竞争，部分厂商采取价格战策略，公司利润空间可能被进一步压缩。尽管公司通过套期保值与价格联动机制对冲，但效果存在不确定性。

**第二，技术迭代与可转债摊薄的双重压力。** 通信技术（如5G-A、6G）迭代加速，若公司未能同步跟进高频化、低损耗等新标准，现有产品存在被替代风险。此外，2025年发行的5亿元可转债若未来大量转股，将显著摊薄现有股东权益，且募投项目（智能数据线）尚处建设期，短期无法贡献利润，存在投入产出不及预期的风险。
