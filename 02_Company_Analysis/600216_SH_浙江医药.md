# 600216.SH 深度透视

## 因果逻辑链
- **[维生素价格下跌]** -> [营收与利润双降]: 生命营养品板块收入同比-7.75%，毛利率骤降10.18个百分点，是净利润下滑24.74%的主因。
- **[行业产能过剩与去库存]** -> [竞争加剧]: 全球维生素E/A市场供需失衡，新产能释放与头部企业复产导致价格持续下跌，公司以量补价策略效果有限。
- **[汇兑收益大幅增加]** -> [财务费用转负]: 财务费用从-0.05亿骤降至-0.73亿，同比-1371.81%，显著对冲了主营业务的利润下滑。
- **[经营性现金流大幅改善]** -> [回款与退税增加]: 经营活动现金流净额同比+54.15%至18.86亿，主要得益于应收账款回款增加及税费返还，显示运营效率提升。
- **[原料药制剂一体化]** -> [成本护城河]: 在集采降价背景下，公司凭借原料药自供优势，抗感染类药品成本仅-4.23%，毛利率虽降但仍维持高位。
- **[创新药管线推进]** -> [未来增长点]: ARX788（ADC）乳腺癌项目完成III期临床，即将申报上市，是公司从仿制药向创新药转型的关键变量。
- **[新昌制药厂去功能化]** -> [一次性费用与资产处置]: 涉危产能搬迁已基本完成，但尚未签订补偿协议，已计提预计负债8219.71万元，未来补偿款或成非经常性收益。

## 风险警告
**核心风险在于生命营养品板块的周期性衰退。** 维生素行业正经历严重的供需失衡，全球产能过剩与去库存周期叠加，导致产品价格持续下跌。公司生命营养品收入占比近半，其毛利率骤降已严重侵蚀利润，若价格战持续，2026年业绩存在进一步下滑风险。公司虽试图通过“以量补价”巩固份额，但销量增长难以完全对冲价格下跌，该板块作为“压舱石”的稳定性正在动摇。

**新业务投资回报存在高度不确定性。** 公司重金投入的创新生物、昌海制药等子公司持续亏损（创新生物亏损1.3亿），新码生物（ADC）虽研发推进但尚未商业化。创新药研发周期长、失败风险高，且海外市场注册严格，短期内难以贡献利润。同时，公司正筹划分拆新码生物赴港上市，若市场环境不佳或研发受挫，将面临投资回报周期延长甚至资产减值的风险。
