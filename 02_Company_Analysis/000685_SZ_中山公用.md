# 000685.SZ 深度透视

## 因果逻辑链
- **[收购小榄水务、中部垃圾发电等资产]** -> [营收结构优化]: 环境治理收入增长27.36%，垃圾处理能力跃升至6120吨/日，区域垄断地位巩固。
- **[广发证券权益法投资收益]** -> [净利润暴增56.77%]: 投资收益18.1亿元占利润总额92.67%，是公司利润的核心来源，掩盖了主业经营波动。
- **[工程业务大幅收缩]** -> [总营收下降18.78%]: 城市服务板块收入下降38.34%，工程安装业务收入骤降49.62%，拖累整体营收表现。
- **[供水一盘棋整合+厂网一体化拓展]** -> [水务规模与效率双升]: 中山本地售水量增长14.8%，供水覆盖率达94%，污水处理规模超50%，现金流底盘加固。
- **[虚拟电厂资质获取+分布式光伏扩张]** -> [能源运营模式转型]: 成功从传统能源投资方跨越至能源运营服务商，装机容量超310MW，开辟第二增长曲线。
- **[财务共享中心上线+组织变革]** -> [管理效率提升]: 总部架构精简27%，业财融合标准化，为规模扩张后的成本控制与风险防范提供制度保障。
- **[高分红政策+市值管理]** -> [股东回报与估值修复]: 每10股派3.85元，分红比例约30%，叠加资产注入与ESG评级提升，推动股价与市值回归。

## 风险警告
**核心风险在于利润结构严重依赖广发证券投资收益（占比超92%），主业盈利能力被严重稀释。** 公司2025年归母净利润暴增56.77%至18.79亿元，但扣非净利润增速（50.42%）与营收下滑（-18.78%）形成巨大反差，表明增长并非来自经营改善，而是金融资产公允价值波动。一旦广发证券业绩或资本市场环境恶化，公司利润将面临断崖式下跌，投资者需警惕“伪增长”陷阱。

**工程业务大幅萎缩（-49.62%）与经营性现金流改善（+219.7%）的矛盾值得深究。** 工程板块毛利率仅6.63%，且大量项目需垫资，其收缩虽短期改善现金流，但长期将削弱公司整体收入规模与客户粘性。同时，公司通过大规模并购（新增12家子公司）和举债（长期借款增43%）实现扩张，若整合不及预期或债务成本上升，将显著侵蚀本已微薄的主业利润。
