# 002939.SZ 深度透视

## 因果逻辑链
- **市场行情回暖与日均成交额大增** -> 经纪业务收入增长: 2025年A股日均成交额同比增61.9%，直接拉动公司财富管理业务手续费及佣金收入。
- **债券承销规模爆发式增长** -> 投资银行业务收入提升: 公司获得银行间债市独立主承销资格，银行间产品承销规模同比增246.69%，带动投行收入增25.14%。
- **自营投资精准把握权益与债市节奏** -> 投资收益与公允价值变动收益大增: 固定收益业务优化持仓结构，权益投资实现超额收益，共同驱动投资收益及公允价值变动收益增19.19%。
- **融资融券余额增长** -> 利息净收入扭亏为盈: 报告期末两融余额同比增18%，叠加其他债权投资利息收入增加及债券利息支出减少，利息净收入同比增264.28%。
- **聚焦电力能源产业金融战略** -> 差异化竞争优势形成: 深耕华能集团等股东资源，在绿色债券、科创债等特色领域取得突破，提升投行业务排名与品牌影响力。
- **参股基金公司管理规模创新高** -> 投资收益贡献稳定: 景顺长城与长城基金管理规模均创新高，为公司贡献稳定且可观的长期股权投资收益。
- **金融科技赋能与数字化转型** -> 运营效率与获客能力提升: “1+6+N”金融科技战略推进，长城炼金术等平台升级，助力新增客户同比增51%，提升财富管理转型效率。

## 风险警告
公司业绩高度依赖市场行情，具有强周期性。2025年净利润暴增48.86%主要得益于A股市场回暖、日均成交额大增及债券牛市。一旦市场转弱，交易量萎缩或利率反转，经纪、自营、信用业务收入将同步承压，业绩存在大幅波动的固有风险。

公司重资本业务（自营、两融）占比高，对利率、信用及流动性风险敏感。虽然当前风控指标达标，但信用减值损失已同比增加，且自营权益类证券及衍生品占净资本比例下降，需警惕市场剧烈波动下资产减值与流动性收紧的连锁反应。
