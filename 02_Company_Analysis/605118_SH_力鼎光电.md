# 605118.SH 深度透视

## 因果逻辑链
- **[低空经济与无人物流项目放量]** -> [营收与利润高增]: 前期与头部客户联合开发的无人机、无人物流光学镜头在2025年进入规模化量产，成为业绩增长核心引擎。
- **[新兴领域产品结构优化]** -> [毛利率大幅提升]: 高毛利的专业消费类（无人机、机器视觉）产品占比提升，推动主营业务毛利率同比增加5.74个百分点至48.88%。
- **[研发投入持续加码]** -> [构筑技术护城河]: 研发费用同比增长40.38%，聚焦低空经济、AI机器视觉等前沿领域，为中长期增长储备核心技术。
- **[股权激励绑定核心团队]** -> [激发内生动力]: 向282名员工授予限制性股票，构建股东、公司与员工的价值共同体，稳定核心人才，驱动创新。
- **[募投项目结项与海外产能建设]** -> [保障未来交付]: 募投项目全部结项，马来西亚生产基地建设顺利，增强了玻塑、红外等核心工艺的自主生产能力，为全球化布局奠定基础。
- **[高比例现金分红]** -> [强化股东回报]: 2025年全年预计现金分红占净利润的94.83%，连续三年高分红，积极回馈投资者，提升市场信心。

## 风险警告
**出口业务与汇率风险**：公司境外收入占比高达75.40%，主要结算货币为美元。全球贸易政策（尤其是美国关税）的不确定性，以及美元汇率的剧烈波动，是公司业绩最大的外部风险。2025年已产生汇兑损失1001万元，且直接出口北美收入同比下降14.39%，未来若贸易摩擦升级或人民币升值，将对公司盈利造成显著冲击。

**下游需求与技术迭代风险**：公司业绩高度依赖低空经济、AI等新兴领域的爆发，若下游行业景气度下行或技术路线发生颠覆性变化（如算法替代部分光学功能），公司前期研发投入可能无法转化为预期收益。同时，光学镜头市场竞争激烈，若公司不能持续推出高性价比产品，可能面临市场份额丢失和毛利率下滑的风险。
