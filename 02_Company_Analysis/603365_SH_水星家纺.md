# 603365.SH 深度透视

## 因果逻辑链
- **[线上渠道扩张]** -> [营收增长7.99%]: 电商收入同比增长15.47%，成为核心增长引擎，拉动整体营收突破45亿元。
- **[大单品战略与产品结构升级]** -> [毛利率提升3.57个百分点]: 聚焦科技睡眠大单品（如雪糕被、人体工学枕），带动枕芯、被芯等高毛利品类快速增长，优化产品结构。
- **[销售费用高增]** -> [侵蚀利润空间]: 广告宣传费、推广费同比增长23.75%，远超营收增速，导致扣非净利润增速（6.29%）显著低于营收增速。
- **[研发驱动产品创新]** -> [巩固品牌护城河]: 持续投入新材料、新技术研发（如PCM相变材料、仿生羽绒），形成技术壁垒，支撑大单品溢价能力。
- **[全渠道协同与数据打通]** -> [提升运营效率]: 线上爆款引流、线下体验转化、全域会员沉淀，实现线上线下联动，提升复购率与客单价。
- **[供应链数智化转型]** -> [成本控制与交付保障]: 建设数字化工厂、智能仓储，推行柔性快反机制，在原材料价格波动下维持成本稳定。
- **[高分红政策]** -> [增强股东回报]: 2025年现金分红总额占净利润63.62%，持续高分红传递积极信号，吸引价值投资者。

## 风险警告
**核心风险在于销售费用失控与行业竞争加剧的双重挤压。** 销售费用增速（23.75%）是营收增速（7.99%）的近3倍，表明公司为维持线上领先地位和线下门店客流，正陷入“烧钱换增长”的困境。若流量成本持续攀升或竞品加大营销投入，公司利润空间将被进一步蚕食，扣非净利润增速放缓趋势可能延续。

**另一风险是消费需求波动与产品同质化。** 家纺行业格局分散，新锐品牌和白牌产品通过低价策略抢占市场。公司虽通过科技大单品构建差异化，但若消费者对“睡眠科技”的付费意愿下降，或技术被快速模仿，产品溢价能力将削弱。此外，原材料价格波动（如羽绒、棉花）可能直接冲击成本端，而公司多源供应体系的实际对冲效果有待验证。
