# 688195.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [光通信业务收入增长33.89%]: 高速光模块无源元组件、OCS光交换机大尺寸纯钒酸钇晶体量产规模提升，直接受益于AI数据中心建设。
- **[半导体设备国产替代]** -> [新兴应用领域收入增长57.48%]: 攻克高精度光学模组工艺，订单交付量大幅提升，成为第二增长曲线。
- **[研发高强度投入]** -> [短期利润承压，长期技术壁垒加固]: 研发费用同比增长47.18%至6950万元，重点布局AI光互联、AR近眼显示，但新增股份支付844.76万元侵蚀当期利润。
- **[垂直整合+全球化布局]** -> [增强供应链韧性与客户粘性]: 上游合肥晶体材料基地、下游北美光测试仪器子公司协同，泰国工厂投产，形成“晶体-元件-模组-仪器”全链条能力。
- **[光纤激光行业回暖]** -> [高激光损伤阈值元器件业务稳步增长]: 下游需求复苏，公司聚焦高附加值产品，实现17.55%的收入增长。
- **[收购GouMax并整合]** -> [光测试仪器业务成为新增长点]: 收入同比增长117.78%，毛利率高达52.28%，且实现境内独立生产能力，协同效应显现。
- **[员工持股计划激励]** -> [核心团队稳定性与创造力提升]: 2025年实施员工持股计划，覆盖45人，将股东、公司、员工利益绑定，但新增股份支付费用。

## 风险警告
**核心风险在于“增收不增利”与高研发投入的短期博弈。** 公司营收增长31.54%，但归母净利润仅微增1.80%，主要因研发费用激增47.18%及新增股份支付费用。若未来AI算力投资增速放缓或光模块技术路线切换（如CPO对传统无源器件需求变化），公司高额研发投入可能无法及时转化为订单，导致利润持续承压。

**另一重大风险是跨国经营与地缘政治不确定性。** 公司在美国、泰国设有子公司，境外收入占比28.6%且同比增长67.25%。中美贸易摩擦、关税政策调整或地缘冲突升级，可能增加采购成本、影响交付效率或产生汇兑损失。此外，公司收购GouMax形成商誉，若整合不及预期或北美市场环境恶化，存在商誉减值风险，直接冲击当期利润。
