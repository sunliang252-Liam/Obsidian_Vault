# 002590.SZ 深度透视

## 因果逻辑链
- **[新能源客户订单放量]** -> [副车架销量同比+56%]: 新能源客户订单增加直接拉动副车架产销量大幅增长，成为营收核心增量。
- **[液压制动系统配套扩张]** -> [液压制动营收同比+35.78%]: 铝合金定钳、EPB等产品切入小米、零跑、吉利等新供应体系，带动液压制动系统收入快速增长。
- **[商用车电控产品渗透]** -> [AEBS/ESC/EBS获主流车企定点]: 商用车AEB规模化量产、ABS+ESC等核心产品获解放、东风、陕汽定点，巩固商用车市场地位。
- **[轻量化与模块化战略]** -> [底盘副车架切入大众/奇瑞体系]: 铝合金轻量化底盘模块化产品成功进入上海大众、一汽大众、奇瑞等合资及自主品牌供应体系。
- **[海外产能布局]** -> [墨西哥/摩洛哥合资公司设立]: 联动华纬科技在墨西哥、摩洛哥设立合资公司，推进全球化产能配套，应对国际贸易风险。
- **[研发投入聚焦智能化]** -> [商用车EMB进入C样阶段]: 持续研发投入（3.67%营收占比）推动电制动EMB、重载EPS等前沿技术进入样品验证阶段。
- **[非经常性损益减少]** -> [扣非净利润增速（+21.49%）高于归母净利润增速（+15.33%）]: 2023年高基数非经常性损益（2.36亿）消退，扣非利润更能反映主业真实增长。

## 风险警告
**核心风险在于毛利率持续承压与现金流恶化。** 2025年综合毛利率16.37%，同比下降0.92个百分点，其中液压制动系统毛利率下降3.09个百分点，显示在新能源客户放量的同时，产品定价与成本压力并存。经营活动现金流净额2.43亿元，同比下降5.15%，且远低于净利润2.18亿元，现金回收质量堪忧。筹资活动现金流净额由正转负（-3.15亿元），主因上期定增吸收投资的高基数效应消退，公司面临再融资压力。

**另一重大风险是资产减值与信用损失高企。** 2025年资产减值损失4367万元（主要为存货跌价）、信用减值损失1672万元（应收账款坏账），合计6039万元，占营业利润的26.2%。应收账款余额16.2亿元，占总资产25.8%，账期拉长风险显著。此外，公司存货跌价准备余额7553万元，库龄较长存货的变现能力存在不确定性，若下游整车厂降价压力传导，减值风险将进一步暴露。
