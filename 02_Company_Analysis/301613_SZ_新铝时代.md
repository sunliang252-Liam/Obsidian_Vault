# 301613.SZ 深度透视

## 因果逻辑链
- **[新能源汽车行业高景气度]** -> [营收增长60.59%]: 2025年国内新能源汽车销量同比增28.2%，渗透率达47.9%，直接拉动电池盒箱体“一车一配”需求。
- **[电动重卡市场爆发]** -> [电池盒箱体销量增39.75%]: 新能源重卡销量同比增182%，公司电动重卡电池盒箱体销售超26万台，成为增量主力。
- **[客户结构优化，降低单一大客户依赖]** -> [营收规模扩大]: 在巩固比亚迪（64.8%）的同时，拓展宁德时代、吉利等客户，前五客户集中度94.32%。
- **[全产业链闭环优势]** -> [成本控制与交付效率]: 覆盖“铸棒-模具-挤压-焊接-表面处理-余料回收”全工序，保障品质一致性与规模效应。
- **[研发投入聚焦新赛道]** -> [技术壁垒构筑]: 研发费用增44.4%，重点布局机器人精密结构件、一体化热管理等，培育新增长点。
- **[现金流模式切换]** -> [经营活动现金流净额暴增231.88%]: 将未到期债权凭证“迪链”通过现金折扣变现，使现金流从-4.58亿转正至6.04亿。
- **[原材料价格波动]** -> [毛利率承压]: 铝棒采购均价同比上涨6.9%，直接材料占成本71%，导致电池盒箱体毛利率下降5.02个百分点。

## 风险警告
**第一大客户依赖与价格上限条款的双重风险。** 公司对比亚迪的销售占比高达64.80%，且与比亚迪、吉利、宁德时代等主要客户签订的长期供货协议中均包含价格上限条款。一旦下游客户利用强势地位压低价格，或公司因违反价格上限条款面临赔偿，将直接冲击盈利能力和客户开拓空间。尽管公司声称“一车一配”的定制化属性构成技术壁垒，但该风险在行业竞争加剧时可能集中爆发。

**原材料成本高企与毛利率持续下滑的盈利风险。** 铝棒采购均价已从2023年的17,296元/吨升至2025年的20,572元/吨，直接材料成本占比超70%。在价格上限条款约束下，公司难以完全向下游传导成本压力，导致电池盒箱体毛利率连续下滑（2025年同比降5.02个百分点）。若铝价维持高位或继续上涨，公司盈利能力将进一步被侵蚀，且公司未采用套期保值等金融工具对冲，风险敞口较大。
