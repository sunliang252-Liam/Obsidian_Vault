# 300050.SZ 深度透视

## 因果逻辑链
- **剥离非核心资产（新能源、低效业务）** -> 扭亏为盈: 通过出售巨鼎储能等亏损子公司，减少并表亏损，使归母净利润从-7440万转为+1550万。
- **聚焦通信主业，深挖存量市场** -> 无线通信服务收入增长36%: 成功中标中国移动等运营商网优服务项目，扩大市场份额，稳固基本盘。
- **职业教育业务“品质交付”** -> 职业教育服务收入增长51%: 以学校需求为导向，提升交付质量与合作粘性，带动项目效益提升。
- **布局低空经济与基站储能新场景** -> 培育新增长点: 研发低空安全测试综测仪并落地应用，中标广东、海南基站储能项目，实现新业务初步落地。
- **实施精细化管理，严控成本费用** -> 销售费用与管理费用大幅下降: 销售费用下降38%，管理费用下降29%，运营效率显著提升。
- **实际控制人变更为吴晨明、刘春斌** -> 引入新资源与战略: 新实控人带来资源与动能，启动3亿元定增计划，为后续发展奠定基础。
- **信用减值损失转回** -> 增厚当期利润: 报告期内应收款项坏账准备转回1015万元，对扭亏为盈产生积极影响。

## 风险警告
公司虽实现扭亏，但盈利能力依然脆弱。扣非净利润仅463万元，且主要依赖信用减值转回等非经常性损益。核心通信业务毛利率仅17.49%，职业教育业务虽毛利率高但收入规模小，整体抗风险能力不足。应收账款高达1.65亿元，占总资产27%，回收风险仍是悬顶之剑。

新实控人入主后，公司战略转向低空经济、基站储能等新领域，但这些业务尚处起步阶段，能否规模化放量存在重大不确定性。同时，职业教育行业竞争加剧，公司需持续投入以维持合作院校关系，若新业务拓展不及预期或老业务下滑，公司可能重回亏损轨道。
