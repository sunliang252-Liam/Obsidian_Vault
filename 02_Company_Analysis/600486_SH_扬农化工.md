# 600486.SH 深度透视

## 因果逻辑链
- **辽宁优创项目提前达产** -> 原药产量同比增长17.4%: 新产能释放推动销量增长，以量补价，对冲了2.78亿元的产品价格损失。
- **“以量补价”策略成功** -> 营收同比增长13.76%: 在行业价格指数同比下跌2.03%的背景下，依靠原药销量大幅增长13.62%，实现了收入逆势增长。
- **国内国际市场双轮驱动** -> 境外收入同比增长15.02%，境内收入同比增长11.55%: 内外销同步增长，分散了单一市场风险，共同支撑了营收大盘。
- **成本控制与降本增效** -> 降本节支成效显著，全年实现降本9105万元: 通过工艺优化、能源管理（吨产品水、蒸汽用量下降）和集采策略，部分抵消了原材料价格波动和行业微利周期的压力。
- **研发投入持续加大** -> 研发费用同比增长9.69%: 坚持“专利药与非专利药双轮驱动”，两个创制品种获ISO通用名，为中长期增长储备新动能。
- **子公司江苏优嘉贡献核心利润** -> 净利润7.87亿元，占归母净利润的61%: 作为核心生产基地，其卓越运营和成本控制能力是公司利润的压舱石。
- **贸易业务增长** -> 贸易收入同比增长23.53%: 子公司中化农化国际贸易业务扩张，贡献了营收增量，但毛利率极低（7.27%），拉低了整体盈利水平。

## 风险警告
**核心风险在于行业供需失衡的持续性与价格战的深化。** 2025年农药行业产能严重过剩（国内产量首破400万吨，同比+12%），产品价格指数持续走低，72%的产品价格同比下跌。公司虽以量补价实现增长，但毛利率已开始下滑（农药业务毛利率同比减少1.26个百分点）。若未来行业“内卷”加剧，价格战进一步侵蚀利润，公司“以量换价”的策略将难以为继，盈利空间可能被大幅压缩。

**第二大风险是应收账款激增带来的信用减值风险。** 报告期末应收账款同比暴增47.46%至28.48亿元，远超营收增速（13.76%），且信用减值损失由正转负，计提了4627万元的损失。这表明公司在激烈竞争中可能放宽了销售信用政策以抢占市场，若下游客户经营恶化，坏账风险将显著上升，直接冲击利润表。
