# 920299.BJ 深度透视

## 因果逻辑链
- **[“十五五”电网投资高增长]** -> [营收增长8.05%]: 国家电网“十五五”投资4万亿，带动电能质量监测装置订单扩大，商品销售收入同比增长10.93%。
- **[子公司佑友软件营收激增]** -> [合并净利润微增1.80%]: 佑友软件营收同比增长45.16%，贡献净利润1702.8万元，成为利润增长的核心引擎，但母公司毛利率下滑拖累整体增速。
- **[商品销售竞争加剧]** -> [毛利率下降3.09个百分点]: 行业竞争导致商品销售毛利率从49.72%降至46.63%，虽营收增长，但利润空间被压缩。
- **[技术服务毛利率提升]** -> [盈利结构优化]: 技术服务毛利率提升4.82个百分点至63.52%，高毛利业务占比提升，对冲了商品销售毛利率下滑的影响。
- **[存货规模增长]** -> [经营性现金流下降36.38%]: 为应对元器件供应波动，公司主动备货及发出商品增加，导致购买商品支付现金增加，经营活动现金流净额降至2379万元。
- **[资金配置调整]** -> [财务费用同比增加80.26%]: 公司将更多闲置资金投向结构性存款，导致传统银行存款利息收入减少，财务费用从-289万升至-57万。
- **[政策驱动转向主动预防]** -> [行业需求扩容]: 国家能源局《电能质量管理办法》等政策推动电能质量管理从“被动治理”转向“主动预防”，电网及用户侧监测需求从主网向配网末端延伸。

## 风险警告
**核心风险在于毛利率持续下行与现金流恶化。** 商品销售毛利率已连续两年下滑（2023年53.98%→2024年52.80%→2025年46.63%），行业竞争加剧导致价格承压。同时，为应对供应链不确定性而主动备货，导致存货增长23.29%，经营活动现金流净额骤降36.38%至2379万元，盈利质量显著下降。若竞争态势延续，公司可能陷入“增收不增利”的困境。

**客户集中度过高与政策依赖风险并存。** 公司对前两大客户国家电网（43.98%）和南方电网（4.76%）的合计销售占比达48.74%，业绩高度依赖电网投资节奏。虽然“十五五”电网投资规划宏大，但若电网公司投资进度不及预期，或电能质量政策执行力度减弱，公司营收将面临直接冲击。此外，公司及子公司享受高新技术企业15%所得税及软件产品增值税即征即退优惠，若政策变化，将直接侵蚀利润。
