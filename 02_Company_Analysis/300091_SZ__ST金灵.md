# 300091.SZ 深度透视

## 因果逻辑链
- **[流动性危机+破产重整不确定性]** -> [营业收入暴跌46.85%]: 资金紧张与重整前景不明导致市场拓展受阻、存量项目推进放缓，核心业务全面萎缩。
- **[特别代表人诉讼判决赔偿7.75亿]** -> [计提损失4.88亿]: 公司因财务造假被判决向4.3万名投资者赔偿，当期计提巨额预计负债，直接导致净利润大幅亏损。
- **[子公司经营不及预期]** -> [计提商誉减值1.60亿]: 对业绩下滑的子公司进行减值测试，确认商誉减值损失，进一步侵蚀利润。
- **[资产全面减值测试]** -> [计提减值4.42亿]: 基于谨慎性原则，对存货、长期资产等计提大额减值准备，反映资产质量恶化。
- **[破产重整引入投资人23.79亿]** -> [化解流动性危机]: 成功引入产业投资人汇通达及13家财务投资人，获得巨额资金，使重整计划得以执行完毕，公司得以续命。
- **[净资产由正转负至-6.80亿]** -> [触发财务类退市风险警示]: 连续巨额亏损导致2025年末净资产为负，公司股票被*ST，面临退市风险。
- **[欺诈发行证券罪判决]** -> [判处罚金800万]: 公司因在定增文件中造假被追究刑事责任，严重损害公司信誉与市场形象。

## 风险警告
公司当前最核心的风险是**退市风险**。2025年末净资产为负值，已被实施财务类退市风险警示（*ST）。尽管重整计划已执行完毕，净资产转正，但若2026年未能实现盈利或再次触及退市标准，将面临强制退市。这直接决定了公司的存亡，是压倒一切的首要矛盾。

其次，**法律与信誉风险**依然高悬。公司因财务造假已背负欺诈发行证券罪的刑事判决和近7.75亿元的民事赔偿判决。虽然重整资金解决了赔付问题，但公司信誉已严重受损，未来市场拓展、融资能力均受到根本性制约。新控股股东汇通达能否彻底重塑公司治理、重建市场信任，存在巨大不确定性。
