# 603350.SH 深度透视

## 因果逻辑链
- **[国内“以旧换新”政策与新国标实施]** -> [营收增长31.14%]: 政策驱动国内电动自行车销量增长16.6%，公司作为核心供应商，直驱轮毂电机销量随之大幅提升。
- **[轮毂电机销量增长39.40%]** -> [营收增长核心引擎]: 轮毂电机贡献了公司绝大部分营收，其销量在核心客户（雅迪、台铃等）中的份额提升，是营收增长的主要驱动力。
- **[营收增长但利润增速仅4.62%]** -> [毛利率承压]: 营业成本增速（34.49%）超过营收增速（31.14%），主要因原材料成本上升及产品结构变化，导致利润增速远低于收入增速。
- **[经营活动现金流净额转负]** -> [营运资金压力]: 营收增长导致备货和应收账款增加，同时减少票据贴现及到期兑付增多，使得经营性现金流入不敷出，同比骤降101.33%。
- **[新兴领域收入突破1.26亿元]** -> [第二增长曲线初现]: 公司成功将电机产品拓展至智能滑板车、割草机器人等新领域，验证了“电机+”平台化战略，开辟了新的增长空间。
- **[与TG0战略合作]** -> [技术护城河加深]: 获得全球两轮车领域AI智能触控技术的独家合作权，推动产品从“动力解决方案”向“动力与智能交互一体化解决方案”升级。
- **[越南、广东工厂投产]** -> [全球化产能布局]: 海外产能的落地，有助于公司规避贸易风险、贴近客户，并满足东南亚本土化交付需求，提升全球供应链韧性。

## 风险警告
**增收不增利与现金流恶化是核心风险。** 公司营收增长31%，但净利润仅增长4.6%，毛利率承压，且经营活动现金流由正转负，净流出145.5万元。这表明公司在快速扩张期，面临成本控制、营运资金管理及利润转化效率的严峻挑战。若此趋势延续，将严重侵蚀股东回报。

**客户高度集中与市场竞争白热化构成双重威胁。** 前五大客户收入占比高达78.65%，对雅迪、台铃等大客户依赖度极高，任何核心客户的流失都将对公司业绩造成重大冲击。同时，国内市场已进入存量竞争，价格战压力持续；海外市场则面临博世、禧玛诺等国际巨头的直接竞争，公司市场份额与议价能力存在不确定性。
