# 002001.SZ 深度透视

## 因果逻辑链
- **[蛋氨酸产能扩张与量价齐升]** -> [净利润增长15.26%]: 18万吨液体蛋氨酸项目投产，固体蛋氨酸产能提升至37万吨/年，规模效应叠加市场需求增长，驱动营养品板块毛利率提升4.59个百分点。
- **[维生素市场阶段性机遇]** -> [外销收入增长7.28%]: 巴斯夫VA、VE产能断供，公司抓住出口窗口期，外销毛利率提升5.29个百分点，弥补内销下滑。
- **[新材料产销两旺]** -> [新材料收入增长26.17%]: PPS、PPA等特种工程塑料受益于新能源汽车、AI等下游需求爆发，产能利用率提升，成为第二增长曲线。
- **[成本控制与工艺优化]** -> [营养品成本下降9.73%]: 连续化工艺装备、绿色生物制造等技术研发投入，实现降本增效，抵消产品价格波动影响。
- **[全球化布局深化]** -> [海外子公司投运]: 越南、土耳其销售子公司及新加坡海外仓启用，本地化运营能力提升，支撑外销增长。
- **[研发投入持续高企]** -> [技术壁垒巩固]: 研发费用11亿元，占营收4.94%，聚焦连续化工艺、生物合成等核心技术，支撑新产品（如生物基PPS）和工艺改进。
- **[现金流强劲]** -> [经营现金流增长24.38%]: 销售收入增加带动货款回笼，现金流净额87.97亿元，远超净利润，体现产业链议价能力。

## 风险警告
**核心风险：产品价格与原材料成本的双重挤压。** 公司主要产品维生素、蛋氨酸等价格受全球供需、竞争对手产能投放（如国内蛋氨酸新产能）影响显著，2025年已呈现前高后低趋势。同时，原材料成本占总成本比例高，原油、化工原料价格波动将直接侵蚀利润。尽管公司通过工艺优化降本，但若价格下行周期超预期，毛利率仍有收缩风险。

**第二风险：国际化与地缘政治不确定性。** 公司外销占比58.11%，且正加速海外建厂。全球贸易政策（如关税壁垒）、地缘政治冲突（如中东、欧洲局势）可能影响供应链稳定和出口竞争力。此外，汇率波动虽通过套期保值对冲，但衍生品公允价值变动已产生损失，若汇率大幅波动，仍可能冲击业绩。
