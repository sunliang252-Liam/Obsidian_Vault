# 920045.BJ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长68.5%]: AI数据中心后端网络（Scale-out）光互联需求激增，直接拉动无源光器件产品量价齐升。
- **[北美云厂商资本开支高增]** -> [境外收入占比91.22%]: 公司深度绑定北美大型云服务商数据中心建设周期，境外收入同比增长75.42%，成为业绩核心引擎。
- **[产品向高密度/高速率迭代]** -> [毛利率稳定在26.48%]: 超大芯数布线（3456芯量产）、800G/1.6T光模块内连器件等高附加值产品规模化交付，抵消了原材料成本上升对毛利的侵蚀。
- **[客户集中度极高]** -> [对单一客户H依赖度55.81%]: 前五大客户销售占比78.34%，其中客户H一家贡献超半壁江山，业绩弹性与风险均高度集中。
- **[全球化产能布局]** -> [越南/泰国基地扩产]: 海外生产基地（阿成新越、泰国衡东光）产能释放，支撑境外订单交付，同时规避部分贸易摩擦风险。
- **[IPO募资到位]** -> [净资产翻倍至10.8亿]: 2025年末上市募资2.78亿元，货币资金暴增140.7%，资产负债率从62.49%降至45.05%，财务结构显著优化。
- **[研发投入加码46.2%]** -> [技术卡位CPO/ELSFP]: 研发费用增至7697万元，重点布局CPO、ELSFP保偏等下一代光连接技术，为1.6T/3.2T时代储备竞争力。

## 风险警告
**单一客户依赖与AI资本开支周期性风险**：公司对客户H的销售占比高达55.81%，前五大客户合计78.34%。一旦该客户因AI投资回报不及预期、技术路线切换（如CPO普及减少光纤连接需求）或地缘政治因素削减订单，公司营收将面临断崖式下滑。AI数据中心资本开支已连续两年高增，市场对2026年增速放缓的担忧正在加剧。

**汇率与贸易摩擦双重夹击**：境外收入占比超91%且以美元结算，2025年人民币汇率波动已导致财务费用从-311万骤增至1967万（汇兑损失）。若人民币进入升值通道，将直接侵蚀净利润。同时，中美科技博弈升级可能将公司卷入供应链限制，越南产能虽能部分对冲，但若美国对东南亚转口贸易加征关税，则全球化布局优势将大打折扣。
