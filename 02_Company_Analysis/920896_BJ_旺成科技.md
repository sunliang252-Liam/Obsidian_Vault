# 920896.BJ 深度透视

## 因果逻辑链
- **[新能源汽车齿轮销量大增]** -> [齿轮业务收入增长34.53%]: 公司成功切入蜂巢传动等新能源客户供应链，汽车齿轮成为核心增长引擎。
- **[高毛利产品占比提升]** -> [综合毛利率从21.49%升至25.73%]: 产品结构向高精度、高附加值齿轮倾斜，直接驱动盈利能力跃升。
- **[规模效应与成本管控]** -> [净利润增长73.21%，远超收入增速28.40%]: 收入增长摊薄固定成本，叠加毛利率改善，利润弹性显著放大。
- **[客户高度集中]** -> [前五大客户贡献67.72%营收]: 深度绑定本田、雅马哈、蜂巢传动等巨头，订单稳定但议价空间受限。
- **[纸基摩擦材料技术壁垒]** -> [离合器业务毛利率提升2.69个百分点]: 公司是少数掌握该核心技术的企业，构筑了差异化竞争优势。
- **[西部大开发15%所得税优惠]** -> [有效税率维持低位]: 政策红利持续增厚净利润，是利润高增长的重要支撑。
- **[研发投入聚焦机器人/新能源]** -> [布局关节机器人减速机齿轮等新赛道]: 前瞻性研发为未来增长储备动能，但短期转化存在不确定性。

## 风险警告
**客户集中与单一客户依赖风险**：公司前五大客户销售占比高达67.72%，其中对ATLAS（本田关联方）和新大洲本田的合计销售占比超过42%。尽管深度绑定全球一流客户是护城河，但任何单一客户的订单波动或供应链调整，都将对公司营收和利润产生剧烈冲击。这种“大客户依赖症”是公司估值折价的核心因素。

**汇率波动与国际贸易摩擦风险**：公司境外收入占比约41.6%，主要以美元结算。2025年财务费用因汇兑损失（64.2万元）而大幅转正，侵蚀了部分利润。在全球贸易保护主义抬头、人民币汇率双向波动加剧的背景下，公司缺乏有效的对冲工具，汇兑损益将持续成为业绩的“干扰项”。同时，若主要出口市场（如东南亚、欧洲）出现贸易壁垒，将直接威胁海外收入增长。
