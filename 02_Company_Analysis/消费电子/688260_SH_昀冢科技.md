# 688260.SH 深度透视

## 因果逻辑链
- **[MLCC项目重资产投入与产能爬坡]** -> [公司连续三年大额亏损]: 子公司池州昀冢的MLCC项目前期厂房、设备投入巨大，转固后折旧费用高企，而产能规模尚小，导致收入无法覆盖固定成本，是公司2025年归母净利润亏损1.9亿元的核心原因。
- **[消费电子核心产品CMI件销量与毛利率双降]** -> [主营业务毛利率大幅下滑10.98个百分点]: 受市场竞争加剧及公司主动优化订单影响，CMI件收入同比大降41.71%，且毛利率由正转负至-4.48%，严重拖累整体盈利。
- **[电子陶瓷业务爆发式增长]** -> [营收结构显著优化，但尚未盈利]: 电子陶瓷（MLCC+DPC）收入同比暴增310.69%至1.65亿元，成为第二大收入来源，但受制于高额折旧与成本，该业务毛利率为-8.68%，仍处于亏损状态。
- **[经营活动现金流净额断崖式下跌]** -> [流动性风险急剧升高]: 经营现金流净额从2024年的9007万元骤降至2025年的270万元，降幅达97%，主要因税费返还减少及采购支出增加，公司造血能力严重恶化。
- **[高杠杆扩张与偿债压力]** -> [财务风险加剧]: 短期借款3.22亿元、长期借款4.60亿元，资产负债率高企，而净资产已缩水至仅1.24亿元，公司面临巨大的偿债压力和再融资风险。
- **[客户与终端用户高度集中]** -> [经营依赖风险]: 前五大客户销售额占比达52.89%，终端用户集中于华为、小米等头部手机品牌，任何主要客户流失或终端需求波动都将对公司业绩产生重大冲击。

## 风险警告
**核心风险在于“烧钱”扩张与主业失速的双重夹击。** 公司为培育第二增长曲线，重金投入MLCC项目，导致固定资产规模庞大（占总资产54.58%），折旧压力沉重。然而，作为现金牛的消费电子核心产品CMI件却遭遇量价齐跌，毛利率转负，导致公司整体造血能力急剧恶化，经营活动现金流近乎枯竭。这种“新业务尚未盈利、老业务加速下滑”的局面，使公司陷入严重的财务困境。

**流动性危机是当前最紧迫的威胁。** 公司净资产仅1.24亿元，而短期有息负债高达3.22亿元，经营现金流仅270万元，偿债能力极度脆弱。公司已通过股东借款、引入地方国资等方式“输血”，但若MLCC业务无法快速实现规模效应和盈利，或外部融资环境生变，公司将面临资金链断裂的生存风险。此外，客户高度集中、产品价格持续下降等经营风险，进一步放大了公司的不确定性。
