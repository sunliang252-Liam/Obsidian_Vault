# 300951.SZ 深度透视

## 因果逻辑链
- **[境外业务高速扩张]** -> [营收增长但毛利率下降]: 境外收入同比大增80.81%，但境外毛利率同比下降11.07个百分点，拉低整体毛利率3.19个百分点。
- **[直接材料成本飙升]** -> [利润承压]: 直接材料成本同比大增31.42%，远超营收7.20%的增速，侵蚀利润空间。
- **[汇兑损失激增]** -> [财务费用大幅转正]: 财务费用从-2707万转为+779万，同比变动128.76%，主要系汇兑损失所致。
- **[股权激励费用摊销]** -> [净利润进一步下滑]: 扣除股份支付影响后净利润同比降26.46%，略好于归母净利润31.91%的降幅，表明激励成本加重了利润压力。
- **[研发投入持续加码]** -> [布局新兴赛道]: 研发费用同比增13.66%至1.05亿元，重点投向AR/VR、低空经济（无人机）等AI端侧硬件领域，为未来增长蓄力。
- **[募投项目延期]** -> [产能释放不及预期]: 电子产品精密功能件生产建设项目延期至2026年6月，短期无法贡献增量产能与效益。
- **[智能自动化装备增长]** -> [结构优化]: 智能自动化装备收入同比增17.17%，占比提升至20.97%，成为营收增长的重要驱动力。

## 风险警告
**核心风险在于“增收不增利”的困境加剧。** 2025年营收增长7.2%，但归母净利润却暴跌31.91%，扣非净利润更是下降35.70%。利润下滑的直接原因是境外业务扩张带来的毛利率大幅下降（境外毛利率同比降11.07个百分点）以及直接材料成本失控（同比增31.42%）。这表明公司在快速拓展海外市场时，并未能有效控制成本，定价能力或供应链管理存在显著短板。

**另一个重大风险是募投项目持续延期与巨额现金管理的低效。** 核心募投项目“电子产品精密功能件生产建设项目”再次延期，导致产能释放遥遥无期。与此同时，公司账上趴着近10亿货币资金和4.5亿交易性金融资产，却大量用于购买低收益的理财产品，而非投入主业建设。这种“有钱花不出去”或“有钱不想花”的状态，严重拖累了资本回报率，也反映出公司战略执行能力存疑。
