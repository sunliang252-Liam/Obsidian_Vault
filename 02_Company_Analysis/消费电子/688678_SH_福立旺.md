# 688678.SH 深度透视

## 因果逻辑链
- **[3C精密零部件大客户订单放量]** -> [营收增长53.46%]: 与北美大客户深度合作，可穿戴业务精密零件持续放量，新一代耳机项目满产供货，全年出货约5.5亿元，驱动3C业务收入同比+72.80%。
- **[子公司亏损与资产减值侵蚀利润]** -> [净利润仅增1.26%]: 南通福立旺产能爬坡亏损2567万元，强芯科技受光伏行业低迷亏损3124万元，全年计提资产/信用减值7535万元，三者合计拖累利润超1.3亿元。
- **[营收高增但经营现金流锐减]** -> [现金流同比-78.82%]: 营收增长53.46%的同时，应收账款增加至8.83亿元（+64.19%），大量销售款尚未到期回笼，导致经营活动现金流净额仅1143万元。
- **[可转债转股与股东借款增加]** -> [筹资现金流+645%]: 可转换债券转股及股东借款增加，使筹资活动现金流净额达2.86亿元，有效支撑了产能扩张期的资金需求。
- **[光伏行业下行拖累子公司]** -> [强芯科技全年亏损3124万元]: 光伏行业产能加速出清、市场行情持续低迷，导致强芯科技经营不及预期，商誉累计减值1765万元，存在继续减值风险。
- **[具身智能机器人业务突破]** -> [开辟第二增长曲线]: 成功研发微型行星滚柱丝杠，灵巧手及关节零部件已批量出货，与杭州五八智能签订战略合作协议，从送样阶段迈入小批量订单交付阶段。
- **[原材料成本上升与毛利率承压]** -> [综合毛利率下滑]: 直接材料成本占主营成本49.4%，受大宗商品价格走高影响，3C业务毛利率下降2.02pct，汽车/电动工具业务毛利率分别下降12.84pct和13.63pct。

## 风险警告
**核心风险在于“增收不增利”的结构性矛盾。** 公司营收暴增53.46%至19.72亿元，但净利润仅微增1.26%至5521万元，主因是子公司强芯科技（光伏）和南通福立旺（产能爬坡）合计亏损约5691万元，叠加7535万元的大额资产减值。这种“主业赚钱、副业拖累”的格局若持续，将严重侵蚀股东回报。尤其强芯科技所处的光伏行业仍处出清周期，商誉减值风险未消，是最大的利润黑洞。

**现金流恶化与应收账款高企构成财务隐忧。** 经营现金流同比骤降78.82%至1143万元，而应收账款激增64.19%至8.83亿元，说明公司为换取营收高增长，在信用政策上做出了较大让步。若下游客户回款周期进一步拉长，或出现坏账，公司将面临流动性压力。此外，汽车和电动工具业务毛利率分别骤降12.84和13.63个百分点，已逼近盈亏平衡线，传统业务的盈利能力正在快速恶化。
