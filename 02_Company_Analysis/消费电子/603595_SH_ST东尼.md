# 603595.SH 深度透视

## 因果逻辑链
- **[新能源业务（FPC/CCS）规模化放量]** -> [营收与毛利大幅增长]: 子公司东尼新能源通过持续交付下游定点项目，叠加内部工艺改进与精益管理，实现营收同比增长78.74%，毛利率提升11.56个百分点，成为公司核心增长引擎。
- **[碳化硅业务战略性收缩与价格承压]** -> [半导体板块巨额亏损]: 面对衬底价格持续走低，公司主动收缩生产规模，但固定成本高企，导致营收同比骤降88.21%，毛利率为-400.17%，并计提1.24亿元存货跌价损失，严重拖累整体利润。
- **[金刚线业务受光伏周期拖累]** -> [营收与毛利双降]: 光伏行业供需失衡格局延续，公司主动收缩传统细线业务，导致营收同比下降52.35%，单位固定成本上升，毛利率下滑至3.43%。
- **[非经常性损益大幅减少]** -> [归母净利润由盈转亏]: 2024年因资产处置等产生高额非经常性收益，而2025年此类收益大幅缩减，导致归母净利润从盈利1,152万元转为亏损6,379万元，扣非净利润虽减亏但主业仍陷亏损。
- **[研发投入维持高位]** -> [夯实技术护城河]: 公司研发费用占营收比例达10.13%，重点投向碳化硅晶体生长与缺陷控制，旨在提升良率与产品竞争力，为长期技术突围蓄力。
- **[客户集中度极高]** -> [经营依赖核心客户]: 前五大客户销售额占比高达62.03%，其中立讯精密一家占比35.87%，对单一客户的依赖构成显著的经营风险。
- **[高负债率与现金流恶化]** -> [偿债压力凸显]: 资产负债率升至66.63%，短期借款及一年内到期负债合计超13亿元，而经营活动现金流净额同比大幅下降59.53%，对债务的保障能力薄弱。

## 风险警告
**核心风险在于碳化硅业务的持续失血与高企的财务杠杆。** 公司半导体板块毛利率为-400.17%，已沦为纯粹的成本中心，巨额存货跌价准备表明该业务短期内难以扭亏。同时，公司资产负债率高达66.63%，短期偿债压力巨大，而经营活动现金流净额同比腰斩，造血能力显著恶化，存在流动性危机。

**治理与合规风险是另一重大隐患。** 公司因信息披露违规被证监会处罚，控股股东股权质押比例高达79.35%，存在平仓与控制权变更风险。此外，客户集中度极高，过度依赖立讯精密等少数大客户，一旦合作关系生变，将对公司营收造成毁灭性打击。
