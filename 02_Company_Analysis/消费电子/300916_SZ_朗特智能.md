# 300916.SZ 深度透视

## 因果逻辑链
- **[储能业务爆发]** -> [营收微增0.75%]: 储能产品收入同比+103.19%，拉动智能产品板块收入+66.50%，对冲了智能控制器业务-36.42%的下滑。
- **[产品结构恶化]** -> [毛利率下降1.2%]: 低毛利率的储能产品（11.99%）和消费类电子（13.56%）营收占比合计达68.65%，拉低了整体盈利水平。
- **[美元贬值]** -> [净利润率下降1.32%]: 外销占比53.25%，美元兑人民币贬值产生汇兑损失2119.45万元，直接侵蚀利润。
- **[雾化控制器订单骤降]** -> [消费类电子收入-47.06%]: 核心客户受海外地缘法规收紧影响，订单大幅下滑，导致智能控制器板块整体承压。
- **[泰国工厂投产与国内扩产]** -> [管理费用+40.59%]: 海外基地建设及国内事业部独立核算，导致折旧、人工等阶段性投入增加，短期压制利润。
- **[大客户战略深化]** -> [储能业务翻倍]: 与下游战略大客户深度绑定，受益于其在目标市场的强劲放量，公司作为核心供应商实现订单交付与质量稳定。
- **[研发投入维持高位]** -> [技术平台化]: 研发费用占营收4.33%，成功构建雾化控制器和低压BLDC控制器平台，形成多产品线协同，增强长期竞争力。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收增长几乎完全依赖低毛利的储能业务，而高毛利的智能控制器（尤其是消费类电子）业务因客户地缘风险大幅萎缩。这种此消彼长导致整体毛利率下滑，叠加美元贬值的汇兑损失，净利润同比暴跌33.45%。公司正处于“以量换利”的阶段，盈利能力改善取决于储能业务能否提升毛利率，以及智能控制器业务能否找到新的增长点。

**客户集中与地缘政治风险高度叠加。** 前五大客户销售占比高达60.45%，其中第一大客户贡献42.59%的营收，且储能业务的爆发高度依赖单一战略大客户。同时，雾化控制器业务已因海外法规收紧而遭受重创，表明公司对单一客户和特定市场的依赖度极高，一旦客户需求或海外政策发生不利变化，业绩将面临剧烈波动。泰国工厂的投产虽能对冲部分关税风险，但短期内的产能爬坡和管理磨合仍在增加成本。
