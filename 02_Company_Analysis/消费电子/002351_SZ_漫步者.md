# 002351.SZ 深度透视

## 因果逻辑链
- **耳机业务收入下滑18.34%** -> 整体营收下降4.97%: 耳机作为第一大品类（占营收53.74%）的显著萎缩，直接拖累公司整体收入表现。
- **音响业务逆势增长18.48%** -> 部分对冲耳机下滑: 公司通过推出时尚设计音箱、监听音箱及“新物种”潮流音箱，成功开辟新增长点，弥补了耳机业务的缺口。
- **海外出口收入大增29.94%** -> 弥补内销下滑14.50%: 公司加大海外自营业务投入，优化海外市场体系，使出口销售成为2025年唯一正增长的区域引擎。
- **原材料成本压力与产品结构变化** -> 毛利率微增0.28%: 尽管面临内存、闪存等核心零部件涨价，但公司通过产品高端化及成本控制，维持了整体毛利率的稳定。
- **研发投入聚焦AI与场景化** -> 产品差异化竞争力: 公司持续投入AI语音助手、会议速记、开放式OWS耳机等研发，旨在将音频产品从“听”的工具升级为AI交互入口。
- **销售费用减少4.29%** -> 利润降幅小于营收降幅: 广告费用的削减有效控制了期间费用，使得净利润下降幅度（-4.06%）略低于营收下降幅度。
- **员工持股计划费用冲回** -> 管理费用减少: 因股权激励业绩未达标，冲回前期确认的股权激励费用，对当期利润形成正向贡献。

## 风险警告
**核心风险在于耳机业务的持续萎缩与行业竞争加剧。** 公司第一大收入来源耳机系列（尤其是TWS）营收同比下降18.34%，销量下滑9.8%，显示出在存量竞争市场中，公司核心产品正面临来自苹果、小米及众多新兴品牌的激烈挤压。若不能通过AI功能、开放式OWS等新品有效扭转颓势，公司增长将失去主要引擎。

**成本与汇率风险不容忽视。** 全球DDR5内存价格涨幅超230%，NAND闪存涨幅突破300%，核心零部件成本压力持续向下传导。同时，公司出口业务全部以美元计价，若人民币升值，将直接侵蚀海外营收的利润空间。虽然公司通过精细化管理部分对冲，但成本端的不确定性仍是影响未来盈利能力的关键变量。
