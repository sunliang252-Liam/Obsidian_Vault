# 600203.SH 深度透视

## 因果逻辑链
- **[核心客户订单增长]** -> [营收大幅增长30.52%]: 子公司中诺通讯聚焦优质大客户，智能终端业务订单同比增长40.03%，驱动整体收入规模扩张。
- **[智能终端毛利率提升]** -> [亏损大幅收窄]: 智能终端业务毛利率同比提升1.86个百分点，叠加营收规模效应，使归母净利润从-3.84亿大幅减亏至-0.49亿。
- **[产品结构向中高端转型]** -> [盈利能力改善]: 公司主动减少低附加值LED封装订单，提升高附加值产品比例，LED光电板块毛利率提升3.23个百分点。
- **[经营活动现金流由负转正]** -> [经营质量改善]: 销售商品收到现金增加，经营活动现金流净额从-3.67亿大幅转正至4.17亿，表明营收增长具备现金支撑。
- **[财务费用大幅增长53.27%]** -> [侵蚀利润]: 利息支出增加及汇率波动导致汇兑损失，财务费用从0.91亿增至1.39亿，对微利状态形成显著压力。
- **[信用及资产减值损失高企]** -> [持续拖累利润]: 全年信用减值损失2.10亿、资产减值损失1.93亿，合计4.03亿，远超当期归母净利润，反映历史包袱沉重。
- **[应收账款激增57%]** -> [营运资金占用加剧]: 四季度营收大幅增长导致应收账款从19.45亿增至30.53亿，显著高于营收增速，回款压力增大。

## 风险警告
公司虽实现营收高增与大幅减亏，但核心盈利质量依然脆弱。归母净利润仍为-4850万，且扣非净利润-7431万，表明主营业务尚未实现根本性扭亏。高达4.03亿的信用及资产减值损失持续侵蚀利润，叠加应收账款激增57%至30.53亿，资产质量与现金流管理面临严峻挑战。母公司未分配利润为-1.96亿，已连续多年无法分红。

公司面临多重外部风险：消费电子行业周期波动、国际贸易摩擦加剧（关税壁垒）、以及ODM行业竞争白热化（头部EMS厂商与关键零部件制造商跨界竞争）。同时，AI算力投资挤压通用存储芯片产能，导致原材料价格波动，可能进一步压缩中低端产品利润空间。公司虽布局越南产能，但海外业务拓展效果尚待验证。
