# 002855.SZ 深度透视

## 因果逻辑链
- **[营收增长但毛利率恶化]** -> [巨额亏损]: 2025年营收增长23.32%至16.73亿，但毛利率仅4.45%，同比大幅下降4.94个百分点，收入增长无法覆盖成本，导致毛利空间被严重挤压。
- **[资产减值集中爆发]** -> [利润崩塌]: 计提资产减值损失1.59亿元（占利润总额31.81%），叠加信用减值损失0.08亿元，合计1.67亿元的非现金损失直接吞噬了本已微薄的利润。
- **[“降本增效”引发高额辞退福利]** -> [管理费用激增]: 管理费用同比飙升27.14%至2.65亿元，主要系人员优化导致的辞退福利增加，短期“降本”行为反而加剧了当期亏损。
- **[财务费用翻倍]** -> [侵蚀利润]: 财务费用同比暴增104.87%至0.45亿元，源于汇兑损失和利息支出增加，高负债运营的财务成本成为沉重负担。
- **[精密结构件业务量增利薄]** -> [核心业务失血]: 精密结构件销量增长48.02%，但毛利率仅为0.66%，同比大降6.49个百分点，表明公司核心业务陷入“增收不增利”甚至“增产即亏损”的困境。
- **[客户高度集中]** -> [经营脆弱性]: 前五大客户销售额占比40.40%，公司对头部客户议价能力弱，一旦客户压价或缩减订单，业绩将遭受重大冲击。
- **[控股股东巨额财务资助]** -> [资金链承压]: 控股股东捷荣集团向公司提供财务资助余额高达2.52亿元，且短期借款激增11.88个百分点至3.67亿元，显示公司自有资金严重不足，依赖关联方输血维持运营。

## 风险警告
**核心风险：持续经营能力存疑与财务造假调查。** 公司连续三年巨额亏损（-1.19亿、-2.98亿、-4.90亿），净资产从9.06亿暴跌至1.21亿，已严重资不抵债。更致命的是，公司因“涉嫌信息披露违法违规”被证监会立案调查，审计报告被出具带强调事项段的无保留意见，内部控制审计报告同样被出具带强调事项段的无保留意见。这不仅是财务危机，更是严重的合规与信任危机，可能引发退市风险。

**业务与财务风险：核心业务失血与高杠杆运营。** 精密结构件业务毛利率已趋近于零，完全丧失造血能力。公司通过大幅增加短期借款（+134.68%）和依赖控股股东财务资助来维持现金流，资产负债率高达94.9%。这种高杠杆、低毛利、负利润的经营模式不可持续，任何外部融资环境的收紧或关联方支持的减少，都将导致资金链断裂。
