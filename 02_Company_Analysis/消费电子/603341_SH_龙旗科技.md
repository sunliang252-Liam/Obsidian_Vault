# 603341.SH 深度透视

## 因果逻辑链
- **存储芯片等原材料价格上涨** -> 智能手机出货量下滑至1.52亿台: 上游成本上升导致公司收缩出货规模，同时优化客户结构
- **存储芯片价格上涨** -> 智能手机业务毛利率提升2.99个百分点: 公司通过优化客户结构和产品升级，推高单价产品占比，使毛利率在成本压力下逆势提升
- **AI眼镜市场爆发（同比+322%）** -> AIoT业务收入同比大增41.19%: 公司抓住AI眼镜产业机遇，深化头部客户合作，实现多品类出货放量
- **国内消费补贴政策及换机需求** -> 平板电脑出货量突破1100万台，收入同比+12.35%: 政策刺激和终端换机需求拉动，叠加教育行业批量采购
- **新业务（AIPC、汽车电子）研发投入增加** -> 研发费用同比+30.53%，期间费用率上升: 公司为培育AIPC、汽车电子等新增长点，大幅增加研发人员薪酬和投入
- **外汇衍生品公允价值变动及处置金融资产** -> 非经常性损益大幅增加至2.62亿元: 公司通过外汇套保和理财投资获取收益，但核心扣非净利润下滑
- **汇兑净损失增加** -> 财务费用由负转正（-0.78亿→-0.31亿）: 人民币汇率波动导致汇兑损失增加，财务费用上升
- **存货周转压力及备货增加** -> 经营活动现金流净额同比+10.85%，但低于净利润: 存货及应收款占用资金，经营现金流虽改善但仍存在压力

## 风险警告
深度风险：1) 存储芯片供需偏紧延续至2026年，智能手机出货量可能进一步下滑（IDC预测全球-12.9%），公司核心主业承压；2) 新业务AIPC和汽车电子仍处投入期，研发费用高增侵蚀利润，若市场拓展不及预期将拖累整体盈利；3) 扣非净利润同比-15.91%，非经常性损益占比过高，盈利质量堪忧；4) 短期借款大幅增加（+77.47%），财务杠杆上升，需关注流动性风险；5) 客户集中度高（前五客户占比80.38%），依赖小米、三星等大客户，议价能力受限。
