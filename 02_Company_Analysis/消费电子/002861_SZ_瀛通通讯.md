# 002861.SZ 深度透视

## 因果逻辑链
- **[收入增长但规模效应不足]** -> [持续亏损]: 营收增长3.4%至8.43亿，但固定成本高企，单位收入分摊的折旧、管理费用上升，导致净利润亏损7029万元。
- **[大客户集中度高]** -> [业绩波动风险]: 前五大客户销售占比53.98%，客户结构高度集中，若核心客户订单波动，将直接冲击公司营收和利润。
- **[海外产能布局与贸易转移]** -> [国内募投项目终止]: 贸易摩擦导致客户需求向东南亚转移，公司越南/印度产能可承接，国内“智能无线电声产品生产基地”项目终止，剩余募集资金永久补流。
- **[声学产品收入下滑]** -> [结构转型压力]: 核心产品声学产品及精密零组件收入同比下降5.29%，而电源数据传输产品增长16.93%，产品结构正在被动调整。
- **[大健康业务尚处培育期]** -> [新增长点未形成]: 助听器、助眠仪等健康产品收入规模极小，短期内无法贡献利润，战略转型仍需时间验证。
- **[资产减值与折旧侵蚀利润]** -> [账面亏损]: 计提资产减值2085万元，叠加在建工程转固导致折旧增加，非付现成本合计9069万元，是净利润为负的核心原因。
- **[经营活动现金流为正]** -> [造血能力尚存]: 尽管亏损，但经营活动现金流净额达4681万元，主要得益于销售回款增加和采购支出减少，表明主业仍具一定现金生成能力。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收虽温和增长，但规模效应始终无法显现，固定成本（折旧、管理费用）持续攀升，导致连续亏损。更关键的是，核心声学业务收入下滑，而增长较快的电源数据传输业务毛利率也在下降，说明公司缺乏高毛利、高壁垒的增长引擎。大健康业务尚在萌芽期，远水难解近渴。

**客户集中与贸易环境双重夹击。** 前五大客户贡献超半数营收，任何核心客户的流失或砍单都将造成致命打击。同时，公司外销占比近六成，面临汇率波动和贸易争端风险，越南、印度等海外基地虽能分散部分风险，但也带来了境外经营的不确定性。在行业竞争加剧、技术迭代迅速的背景下，公司若不能快速提升盈利能力和客户粘性，将面临持续失血的风险。
