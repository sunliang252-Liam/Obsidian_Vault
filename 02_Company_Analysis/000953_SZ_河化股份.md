# 000953.SZ 深度透视

## 因果逻辑链
- **[传统医药中间体需求旺盛]** -> [传统产品收入增长35%]: 下游市场拉动，氯喹侧链等核心产品销量同比显著提升，贡献稳定现金流。
- **[上年出售尿素产能指标]** -> [归母净利润同比暴跌91.77%]: 2024年非经常性收益（约8495万元）消失，导致2025年净利润基数大幅降低，剔除该因素后净利润实际增长27.73%。
- **[广西严重旱情]** -> [尿素业务营收下降38.83%]: 2025年上半年罕见秋冬春连旱，农业用肥需求大幅萎缩，尿素销量与价格双降。
- **[CDMO业务尚处培育期]** -> [战略增长引擎当期亏损287万元]: 国内行业竞争加剧、定制订单缩减，叠加前期研发投入增加，该板块尚未形成盈利贡献。
- **[控股股东变更为中哲集团]** -> [公司战略与治理结构重塑]: 2025年12月完成控制权变更，新实控人杨和荣携管理团队入场，为公司注入新动力与方向。
- **[化工业务竞争加剧]** -> [化工产品收入下降34.24%]: 行业需求偏弱、定价承压，老客户订单减少，新业务报价偏低，产能未达预期。
- **[归还关联方债务]** -> [筹资活动现金净流出大幅增加]: 报告期内归还银亿控股等关联方借款约7763万元，导致筹资活动现金流净额为-7763万元。

## 风险警告
**核心风险在于新旧动能转换的阵痛。** 公司净利润的“高增长”完全依赖2024年出售尿素产能指标的一次性收益，2025年剔除该因素后，扣非净利润仅618万元，主业盈利能力依然薄弱。传统医药中间体虽增长稳健，但氯喹侧链面临疟原虫耐药性导致订单萎缩的长期风险；而寄予厚望的CDMO和化工新业务，目前均处于亏损或大幅下滑状态，短期内难以成为利润支柱。

**财务结构脆弱，现金流高度依赖关联方。** 公司累计未弥补亏损高达7.33亿元，长期无法分红。虽然经营活动现金流净额转正至5193万元，但筹资活动因偿还关联方借款导致现金净流出7763万元，期末货币资金较年初大幅减少33%。新控股股东中哲集团虽通过借款提供支持，但公司对关联方资金的依赖度极高，一旦外部融资环境变化，流动性风险将显著上升。
