# 688103.SH 深度透视

## 因果逻辑链
- **[新能源汽车及充电设施领域需求增长]** -> [直流接触器销量同比+73.53%]: 公司核心产品直流接触器受益于新能源车渗透率提升及客户订单增加，成为营收增长66.98%的主要驱动力。
- **[特种业务控制盒持续稳定交付]** -> [真空继电器营收同比+69.22%]: 军工及特种领域定制化产品（控制盒）批量交付，带动高毛利真空继电器业务放量。
- **[产品结构向低毛利直流接触器倾斜]** -> [整体毛利率下降4.29个百分点]: 直流接触器收入占比提升（毛利率仅16.14%），拉低综合毛利率，反映规模扩张伴随盈利质量承压。
- **[原材料成本上升及行业价格战]** -> [直流接触器毛利率下降3.36个百分点]: 铜、银等金属价格上涨叠加整车厂降本压力传导，导致营业成本增幅（+104.72%）高于收入增幅（+96.51%）。
- **[研发投入持续高企]** -> [研发费用1.01亿元，占营收7.63%]: 公司维持高研发强度，聚焦P波段速调管、半导体真空电容器等前沿领域，支撑技术壁垒但短期侵蚀利润。
- **[加强应收账款回款管理]** -> [经营活动现金流净额同比+254.01%]: 营收增长叠加回款改善，现金流大幅好转至1.27亿元，盈利质量显著提升。
- **[可转债募投项目转固及利息支出增加]** -> [财务费用同比+44.33%]: 可转债计息及募投项目转固后折旧增加，财务费用上升至2043万元，对利润形成压制。
- **[半导体设备国产化替代加速]** -> [真空电容器及继电器获头部客户认证]: 公司产品进入北方华创、中微公司供应链，半导体方向成为中长期增长极，但认证周期长、放量缓慢。

## 风险警告
**核心风险在于新能源汽车业务“增收不增利”的恶性循环。** 直流接触器收入同比+96.51%，但毛利率仅16.14%且持续下滑，行业价格战导致公司议价能力薄弱。若新能源车渗透率增速放缓或整车厂进一步压价，该业务可能陷入亏损，拖累整体盈利。同时，公司对前五大客户依赖度高达50.66%，其中客户一占比24.54%，集中度风险显著。

**第二重风险来自高负债扩张与现金流错配。** 总资产增长21%至26.79亿元，但净资产仅微增0.33%，资产负债率攀升。应付票据及账款合计8.41亿元，远超经营性现金流1.27亿元，表明公司大量占用供应商资金维持运营。若下游回款恶化或融资环境收紧，可能引发流动性危机。此外，可转债转股压力及募投项目产能消化不及预期，将进一步加剧财务风险。
