# 920208.BJ 深度透视

## 因果逻辑链
- **[投资结构优化，聚焦能源化工与先进制造]** -> [业绩稳健增长]: 在固投总量下降背景下，公司紧抓抽水蓄能、高端制造等热点领域，期末在手订单余额增长超10%，支撑营收微增0.83%至9.67亿元。
- **[深化战略客户合作，覆盖85家央企]** -> [客户粘性与订单质量提升]: 成功入围国家管网、南方电网等多家战略客户库，承接多晶硅、核电等国家级重大项目，保障了业务履历与品牌影响力。
- **[工程争议化解业务突破]** -> [高附加值业务增长]: 将造价与法律结合，2025年该业务规模近2000万元，成为新的利润增长点，体现了专业壁垒的变现能力。
- **[科技产品与咨询业务融合]** -> [核心竞争力提升]: 发布“三维零代码平台”、“AI智慧工程审计平台”，落地标杆项目，推动业务从“计量计价”向“数据服务”转型。
- **[优化人员结构，控制规模]** -> [人效提升]: 员工数量下降4.55%，但持证技术人员增长26.44%，本科以上占比达88.39%，在控制成本的同时提升了专业服务能力。
- **[经营性现金流大幅改善]** -> [财务质量优化]: 经营活动现金流净额1.79亿元，同比增长47.53%，主要系回款增加，显著改善了公司的现金循环与抗风险能力。
- **[行业集中度提升趋势]** -> [头部企业优势扩大]: 行业CR20仅7.81%，政策推动行业出清，公司作为连续十余年稳居前三的领军企业，有望通过并购整合扩大市场份额。

## 风险警告
**核心风险在于应收账款与合同资产的减值压力。** 公司2025年末应收账款及合同资产账面余额合计高达85.89亿元，计提坏账准备合计19.68亿元，且资产减值损失同比大幅增长51.35%（主要系商誉减值）。尽管客户以央国企为主，但在地方财政紧张、固投增速放缓的背景下，回款周期拉长和坏账风险是悬在利润之上的达摩克利斯之剑。

**第二重风险来自科技转型的不确定性。** 公司研发费用同比骤降52.90%，研发人员数量腰斩，这与公司宣称的“ABCD科技创新战略”形成矛盾。虽然公司解释为利用AI提升研发效率，但研发投入的急剧收缩可能削弱其在数字化、智能化领域的先发优势，导致在行业技术革新浪潮中掉队。同时，子公司青矩译筑进行产品客户结构转换，导致工程管理科技服务收入下降21.23%，科技业务的商业化落地仍面临挑战。
