# 001872.SZ 深度透视

## 因果逻辑链
- **全球港口网络扩张与运营优化** -> 集装箱吞吐量突破2.06亿TEU: 通过全球26国51个港口的布局，叠加精益运营（COE、PMO），实现规模效应与成本领先，驱动营收增长6.92%。
- **投资收益（联营公司）** -> 归母净利润增长2.10%: 核心利润来源为上港集团、宁波港等联营公司贡献的投资收益（占利润总额61.89%），其业绩增长直接拉动公司整体盈利。
- **海外项目产能释放与效率提升** -> 海外营收增长18.16%: 巴西TCP、多哥LCT、土耳其Kumport等海外控股码头通过突破产能瓶颈、锁定长期合约，实现吞吐量创新高，带动海外业务高增长。
- **“招商芯”CTOS系统技术出海** -> 海外运营效率与竞争力提升: 自主研发的码头操作系统成功落地巴西、土耳其等海外项目，替代国外系统，降低对外依赖，提升运营自主性与效率。
- **成本领先与精益运营（COE机制）** -> 毛利率提升0.92个百分点: 通过全链条降本增效、商务统筹与集中采购，在收入增长的同时有效控制成本，港口业务毛利率提升至44.61%。
- **ESG评级提升（Wind AAA级）** -> 品牌价值与资本市场认可度增强: 获得行业最高ESG评级，有助于吸引ESG导向的长期资本，降低融资成本，提升公司估值。
- **资本运作（引入战投、回购注销）** -> 每股收益提升与市场信心增强: 引入浙江海港集团、增持上港集团、完成股份回购并注销，优化了股东结构并提升了每股收益，增强投资者回报。

## 风险警告
**1. 宏观经济与贸易政策波动风险**：公司业绩高度依赖全球贸易量。美国关税政策、地缘政治冲突（如红海危机）及全球供应链重构，可能导致港口吞吐量区域性波动，直接影响公司核心业务收入与投资收益。公司虽通过全球布局分散风险，但无法完全对冲系统性贸易萎缩。

**2. 投资收益依赖与资产结构风险**：公司归母净利润中超过60%来自对联营公司（如上港集团、宁波港）的投资收益。这意味着公司盈利对参股公司的经营状况高度敏感，自身主控码头的利润贡献相对有限。若参股公司业绩下滑，将直接冲击公司整体利润，而公司对此缺乏直接管控能力。
