# 688331.SH 深度透视

## 因果逻辑链
- **[核心产品放量 + 技术授权收入]** -> **营收暴增89%**: 泰它西普、维迪西妥单抗国内销售快速增长，同时授予Vor Bio泰它西普海外权益带来8.95亿技术授权收入，驱动总营收从17亿跃升至32.5亿。
- **[营收规模效应 + 研发费用收缩]** -> **扭亏为盈**: 营收大幅增长摊薄固定成本，同时优化研发管线、减少研发投入20.85%，叠加毛利率提升，使归母净利润从-14.68亿转为+7.10亿。
- **[技术授权收款 + 销售回款改善]** -> **经营现金流转正**: 收到Vor Bio技术授权首付款及产品销售收入增加，使经营活动现金流净额从-11.14亿转为+0.53亿，实现历史性转正。
- **[H股配售 + 盈利积累]** -> **净资产增厚82%**: 2025年5月完成H股配售融资，叠加扭亏为盈带来的未分配利润改善，归属上市公司股东净资产从19.86亿增至36.09亿。
- **[泰它西普适应症持续获批]** -> **市场空间指数级扩大**: 继SLE后，MG适应症于2025年5月获批上市，干燥综合征、IgA肾病NDA已获受理，单一产品向多适应症平台演进。
- **[维迪西妥单抗前线治疗突破]** -> **巩固ADC龙头地位**: 一线UC III期临床PFS/OS双终点阳性，数据远超化疗；HER2低表达乳腺癌获批，拓展了患者人群边界。
- **[RC148/RC28对外授权]** -> **全球化价值兑现**: 继维迪西妥单抗授权Seagen/Pfizer后，2025年将泰它西普授权Vor Bio，2026年初将RC148授权艾伯维，验证平台技术全球竞争力。

## 风险警告
**盈利质量高度依赖非经常性损益。** 2025年扣非净利润仅0.68亿元，而归母净利润高达7.10亿元，差额6.42亿元主要来自交易性金融资产公允价值变动（Vor Bio认股权证）。若剔除该一次性收益，公司主业盈利能力依然薄弱，核心产品商业化尚未能覆盖高昂的销售费用（11.11亿）和研发费用（12.19亿）。

**核心产品面临医保降价与竞争加剧的双重压力。** 泰它西普和维迪西妥单抗均已纳入医保，未来续约谈判存在降价风险。同时，自身免疫和ADC赛道竞争白热化，多个同类竞品已上市或处于后期临床，可能侵蚀公司市场份额和定价能力。公司销售费用率仍高达34%，商业化效率有待验证。
