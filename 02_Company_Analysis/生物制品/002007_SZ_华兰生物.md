# 002007.SZ 深度透视

## 因果逻辑链
- **[采浆量稳步提升]** -> [营收增长4.93%]: 2025年采浆1669.49吨（+5.24%），为血液制品业务提供原料保障，推动营收微增。
- **[血浆成本上升与竞争加剧]** -> [净利润下降13.55%]: 献浆员营养费提高推升成本，血液制品毛利率下降4.24个百分点，叠加疫苗固定成本无法摊薄，侵蚀利润。
- **[疫苗库存去化]** -> [疫苗制品库存量下降69.41%]: 公司优化批签发与供应安排，主动消化库存，导致生产量同比下降26.65%，但销售量仅降10.09%。
- **[疫苗固定成本刚性]** -> [疫苗毛利率下降3.55个百分点]: 生产量下降导致折旧、人工等固定成本无法有效摊薄，单位成本上升。
- **[高比例现金分红]** -> [筹资活动现金流净额下降155.89%]: 2025年半年度及年度合计分红超18亿元，叠加偿还借款，导致筹资现金大幅流出。
- **[研发管线推进]** -> [长期增长动能储备]: 静丙新规格、人凝血因子Ⅸ、Exendin-4-FC融合蛋白等处于临床后期或审评阶段，为未来产品梯队奠基。
- **[参股公司贝伐珠单抗上市]** -> [贡献新收入来源]: 华兰安康贝伐珠单抗2025年实现销售收入1.96亿元，初步验证创新药布局的商业化能力。

## 风险警告
**核心风险在于“增收不增利”的利润侵蚀趋势。** 尽管采浆量持续增长（+5.24%）推动营收微增4.93%，但归母净利润却下降13.55%，主因是血浆成本上升导致血液制品毛利率下滑，以及疫苗生产量下降导致固定成本无法摊薄。若成本端压力持续而产品价格无法提升，公司盈利能力可能进一步承压。

**第二重风险是疫苗业务的周期性波动与竞争加剧。** 流感疫苗是公司疫苗板块的绝对主力，但该业务受流感季节强度、民众接种意愿及竞争对手增多影响极大。2025年疫苗库存量骤降69.41%虽为主动去化，但也反映出终端动销压力。若未来流感季需求不及预期或价格战加剧，疫苗板块可能继续拖累整体业绩。

**公司简介（F10 原文）**

> 华兰生物工程股份有限公司始建于1992年,是一家从事血液制品、疫苗、重组蛋白等生物制品研发、生产和销售的国家级高新技术企业、国家创新型试点企业。血液制品领域拥有人血白蛋白、静注人免疫球蛋白、人免疫球蛋白、人凝血酶原复合物、外科用冻干人纤维蛋白胶等众多以“华兰”为品牌的血液制品。是我国血液制品行业中血浆综合利用率高、品种多、规格全的企业之一。在疫苗领域,公司建有国内规模较大的疫苗产业化平台及应急研发体系,能快速反应、有效应对新发传染病。目前已上市的疫苗产品有9种,是我国首家获批生产的四价流感疫苗企业。在重组蛋白领域,公司积极布局单抗的研发,目前华兰多个单克隆抗体药物已进入临床试验阶段。“感恩、服务、爱心回报”,华兰生物长期捐助福利院、敬老院、血友病患者、贫困大学生,面对突发重大灾害、疫情,无论从药品还是资金都积极投入救助,以实际行动践行着企业的社会责任,被民政部授予中华慈善奖。
