# 000518.SZ 深度透视

## 因果逻辑链
- **[苗木战略合作大单]** -> [营收暴增69%，但净利仍亏]: 子公司晨薇生态园与鑫港发贸易签订1.28亿元苗木购销合同，拉动绿化业务收入同比暴增37倍，但该业务毛利率极低（仅7.51%），无法扭转医药主业下滑带来的亏损。
- **[医药主业集采承压]** -> [医药收入下降6.73%]: 核心产品白介素、G-CSF销量分别下滑19.92%和6.28%，EPO虽量增但价跌，集采降价压力持续侵蚀收入。
- **[苗木业务毛利率极低]** -> [整体毛利率被严重拖累]: 绿化业务毛利率仅7.51%，远低于医药的63.11%，其收入占比从2%飙升至46%，导致综合毛利率从62.7%骤降至37.3%。
- **[苗木销售回款强劲]** -> [经营现金流暴增5245%]: 晨薇生态园销售苗木回款1.28亿元，使经营性现金净额从146万跃升至7812万，极大改善公司资金状况。
- **[控股股东变更]** -> [管理层大换血，战略重心转向]: 碧水投资成为控股股东，邱为碧成为实控人，原董事长、总经理、财务总监等核心高管悉数离任，新管理层推动苗木及矿山工程业务扩张。
- **[连续三年亏损]** -> [未弥补亏损达7.69亿，远超股本]: 公司连续三年净利润为负，累计未弥补亏损已占股本的74.7%，母公司层面无法分红，持续经营能力存疑。
- **[存货占比畸高]** -> [减值风险巨大]: 存货占总资产44.3%，其中苗木资产种类繁多、分散种植，审计师将其列为关键审计事项，2025年已计提存货跌价准备4591万元。
- **[证券虚假陈述诉讼缠身]** -> [预计负债高企]: 公司因虚假陈述面临多起投资者诉讼，涉案金额合计约6497万元，已计提预计负债1341万元，构成重大或有负债。

## 风险警告
**核心风险：主业空心化与苗木业务可持续性存疑。** 公司医药主业在集采压力下持续萎缩，收入、销量双降，而作为营收增长引擎的苗木业务，其1.28亿大单高度依赖单一客户（鑫港发贸易），且毛利率极低，本质上是“以量换现金流”的生意。一旦战略合作协议终止或客户需求变化，公司营收将面临断崖式下跌，重回亏损深渊。

**财务风险：巨额未弥补亏损与高额存货减值。** 公司连续三年亏损，未弥补亏损高达7.69亿元，远超股本，已触发退市风险警示（*ST）。同时，占总资产44%的苗木存货（2.19亿）存在巨大的减值风险，审计师已将其列为关键审计事项。若苗木市场价格下跌或销售不畅，将进一步侵蚀本已脆弱的净资产，加剧退市风险。
