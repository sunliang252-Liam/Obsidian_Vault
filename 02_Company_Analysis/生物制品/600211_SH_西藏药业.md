# 600211.SH 深度透视

## 因果逻辑链
- **[新活素销量增长]** -> [营收增长6.23%]: 新活素作为核心产品，销售收入占86.02%，其销量增长直接拉动整体营收。
- **[政府补助大幅减少]** -> [归母净利润下降10.78%]: 本期确认的其他收益同比减少1.76亿元，导致利润增速远低于营收增速。
- **[研发投入激增156%]** -> [研发费用大幅增加]: 控股Accuredit Therapeutics Limited并纳入合并报表，基因编辑等前沿项目研发支出显著上升。
- **[控股基因编辑公司]** -> [商誉与无形资产暴增]: 收购Accuredit产生商誉增加846.37%，无形资产增加63.39%，为未来业绩埋下潜在减值风险。
- **[新增短期借款5.28亿]** -> [货币资金增长41.21%]: 为支持对外投资及日常运营，公司大幅增加短期借款，推高了账面现金。
- **[对康哲药业采购依赖]** -> [供应商集中度极高]: 向关联方西藏康哲药业发展有限公司的采购额占年度采购总额的80.07%，存在单一供应商依赖风险。
- **[新活素纳入常规医保目录]** -> [稳定核心收入基本盘]: 新活素从医保谈判目录调整至常规目录，消除了续约降价的不确定性，保障了未来收入的稳定性。
- **[佐利替尼获批上市]** -> [构建第二增长曲线]: 公司成为全球首款针对EGFR突变伴CNS转移NSCLC药物的独家总代理商，有望开辟新的利润增长点。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化与巨额投资带来的不确定性。** 2025年归母净利润同比下降10.78%，完全由非经常性损益（政府补助减少）驱动，扣非净利润仅微增1.48%，显示主业增长乏力。同时，公司以6000万美元控股尚处研发阶段的基因编辑公司，导致商誉和无形资产暴增，未来若研发失败或商业化不及预期，将面临巨大的资产减值风险，直接侵蚀利润。

**另一重大风险是极端的关联交易依赖与高企的销售费用。** 公司对关联方康哲药业的采购额占比超过80%，且核心产品新活素、依姆多的推广完全依赖康哲药业，经营独立性存疑。此外，销售费用占营收比例高达55.15%，其中市场费用占比98.95%，这种高费用驱动的增长模式在医保控费、集采扩面的大环境下，可持续性面临严峻挑战。
