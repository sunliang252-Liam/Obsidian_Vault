# 300485.SZ 深度透视

## 因果逻辑链
- **[核心产品结构失衡]** -> [营收下滑2.82%]: 心脑血管用药（-20.51%）和免疫系统用药（-19.78%）两大支柱收入大幅萎缩，仅靠神经系统用药（+135.56%）的爆发式增长无法完全对冲，导致整体营收承压。
- **[非经常性损益驱动扭亏]** -> [净利润转正至1457万]: 扣非净利润亏损2699万，但依靠金融资产公允价值变动及处置收益（+2063万）和联营企业投资收益（+895万）等非经常性项目，实现账面盈利。
- **[研发投入激进资本化]** -> [资本化率高达51.63%]: 研发投入1.44亿（占营收35.51%），其中7420万资本化，显著降低当期费用压力，但将风险后置，若K11等项目失败将面临巨额减值。
- **[子公司赛升药业（香港）暴雷]** -> [资产减值损失1777万]: 对加拿大Curiato公司的160万美元投资因对方经营困难全额计提减值，暴露了海外投资风控的薄弱环节。
- **[GM1市场份额提升]** -> [神经系统用药收入翻倍]: 凭借《药品补充申请批准通知书》的政策红利，GM1注射液市场份额提升，成为公司唯一增长引擎，但毛利率仅39.42%，盈利能力弱于其他核心产品。
- **[现金流大幅恶化]** -> [经营现金流净额骤降80%]: 收入端回款尚可，但支付原材料采购、税费及研发费用大幅增加，导致经营活动现金流出增长47.41%，造血能力显著削弱。
- **[K11进入临床后期]** -> [研发管线进入关键节点]: 作为核心在研项目，K11（抗VEGF单抗）已完成全部638例患者入组，进入申报生产准备阶段，是未来2-3年最大的业绩变量。

## 风险警告
**核心风险在于“虚假繁荣”的利润结构。** 公司2025年扣非净利润亏损2699万元，账面盈利完全依赖金融资产（持有天广实、康乐卫士、绿竹生物等上市公司股票）的公允价值变动和处置收益。一旦资本市场波动或参股公司股价下跌，公司将立即重回亏损。这种“主业亏损、炒股盈利”的模式不可持续，且管理层已明确将金融资产收益作为利润调节工具，投资者需警惕其业绩的脆弱性。

**研发管线的高风险与高资本化率构成双重隐患。** 公司研发投入资本化率高达51.63%，将大量研发支出推迟至未来摊销。核心在研项目K11虽已进入III期临床，但作为生物类似药，面临激烈的市场竞争和价格压力。同时，子公司香港赛升对Curiato的投资已全额计提减值，表明公司海外投资及新药研发的风险控制能力存在严重缺陷。若K11上市后销售不及预期，前期资本化的巨额开发支出将面临集中减值风险，对利润表造成重大冲击。
