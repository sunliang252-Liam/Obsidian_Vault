# 000661.SZ 深度透视

## 因果逻辑链
- **[核心产品纳入医保并降价]** -> [营收与利润双降]: 长效生长激素等产品为进入2025年国家医保目录，主动调整定价与销售政策，导致第四季度收入确认节奏放缓，全年营收同比下降10.27%，归母净利润骤降94%。
- **[研发投入持续高增]** -> [侵蚀当期利润]: 研发投入29.36亿元，同比增长9.16%，占营收比例升至24.30%，大量在研管线进入临床阶段，费用化支出增加，直接拖累净利润表现。
- **[金赛药业战略调整与人员优化]** -> [管理费用激增]: 子公司金赛药业为聚焦核心业务、提升组织效率，实施阶段性人员优化，产生大额离职补偿金，叠加新业务布局带来的薪酬及折旧增加，管理费用同比增长24.75%。
- **[新产品上市推广投入加大]** -> [销售费用率上升]: 为加速金蓓欣（IL-1β单抗）、美适亚等新产品市场导入，并巩固生长激素市场地位，公司加大市场推广与医院准入投入，销售费用同比增长14.68%，进一步压缩利润空间。
- **[百克生物疫苗业务遭遇逆风]** -> [子公司大幅亏损]: 受市场竞争加剧、接种意愿下降及带状疱疹疫苗退货影响，百克生物营收腰斩（-50.77%），并录得上市以来首次亏损（-2.63亿元），成为集团业绩最大拖累项。
- **[GenSci098海外授权里程碑]** -> [验证研发价值并获取现金流]: 子公司金赛药业将自主研发的TSHR拮抗剂（GenSci098）海外权益授权给Yarrow公司，获得1.2亿美元首付款及近期里程碑款项，验证了公司创新管线的全球价值，并补充了研发资金。
- **[长效生长激素纳入医保]** -> [以价换量，巩固市场领导地位]: 核心产品金赛增（全球首支长效生长激素）成功纳入医保，虽短期承压，但有望通过提升临床可及性与患者渗透率，在长期巩固其在国内生长激素市场的绝对领先地位。

## 风险警告
**核心风险：业绩断崖式下跌与转型阵痛。** 2025年归母净利润同比暴跌94%，核心子公司金赛药业利润下滑82%，疫苗子公司百克生物陷入亏损。这并非单一因素所致，而是医保降价、研发高投入、新产品推广、组织调整与外部市场环境恶化等多重压力的集中爆发。公司正处于从“生长激素单一依赖”向“多领域创新药平台”转型的关键阵痛期，短期盈利能力面临严峻考验。

**关键风险：研发管线的高投入与商业化不确定性。** 公司研发投入占营收比已超24%，近80条管线中多数仍处于临床早期。尽管GenSci098的海外授权验证了部分价值，但肿瘤、自免等领域的创新药研发风险极高，后续管线能否成功上市并实现商业化放量，存在巨大不确定性。若核心管线失败或进度不及预期，高额的研发投入将难以回收，持续侵蚀公司利润。
