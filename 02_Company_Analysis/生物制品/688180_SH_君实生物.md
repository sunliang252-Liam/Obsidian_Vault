# 688180.SH 深度透视

## 因果逻辑链
- **[核心产品特瑞普利单抗适应症持续获批并纳入医保]** -> [药品销售收入增长40.32%]: 12项适应症全部纳入国家医保，覆盖肺癌、肝癌、乳腺癌等大瘤种，驱动国内销售20.68亿元，同比增长37.72%。
- **[国际化合作网络扩张至80+国家]** -> [海外收入翻倍增长102.37%]: 与Coherus、Hikma等伙伴合作，特瑞普利单抗在美欧、中东、东南亚等40+国家获批，海外商业化贡献增量。
- **[研发管线聚焦与“提质增效”费用管控]** -> [亏损同比收窄31.7%]: 研发投入占比从65.45%降至53.72%，管理费用下降5.5%，销售费用增速低于收入增速，经营现金流净流出减少64%。
- **[港股配售募资10.26亿港元]** -> [资金储备充足支撑研发]: 期末货币资金+交易性金融资产达32.15亿元，为JS207、JS212等早期管线临床推进提供弹药。
- **[PD-1/VEGF双抗JS207进入II期临床]** -> [下一代重磅产品蓄力]: 在PD-L1阳性NSCLC中ORR达56.3%-60.0%，有望重塑一线治疗格局，是未来增长的核心驱动力。
- **[BTLA单抗tifcemalimab全球III期入组超560人]** -> [全球首创靶点进入确证性研究]: 作为first-in-class药物，若成功将开辟全新免疫治疗赛道，但研发风险极高。
- **[JS001sc皮下注射剂上市申请获受理]** -> [提升患者依从性，扩大市场]: 12项适应症一次性申报，有望替代静脉注射，降低给药成本，增强特瑞普利单抗生命周期价值。

## 风险警告
**持续亏损与商业化依赖单一产品风险**：公司连续多年亏损，2025年归母净利-8.75亿元，累计未弥补亏损达66.5亿元。核心收入高度依赖特瑞普利单抗（占药品销售约90%），虽然适应症持续扩展，但PD-1市场竞争白热化（信达、恒瑞、百济等），医保降价压力持续，若销量增长不及预期，亏损可能再次扩大。

**研发管线高投入与失败风险**：研发费用13.42亿元，占营收53.72%，且全部费用化。JS207、tifcemalimab等核心管线虽数据亮眼，但均处于II/III期临床，存在失败或延迟风险。特别是tifcemalimab作为全球首个BTLA靶点药物，无先例可循，III期结果不确定性极高。同时，公司对Coherus等合作伙伴的海外商业化依赖度增加，地缘政治及合作变动可能影响海外收入。
