# 688739.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧+渠道去库存+新规调整]** -> [境内收入下降22.42%]: 国内狂犬病疫苗市场供过于求，12家企业竞争白热化，叠加2023版暴露处置规范落地，导致公司核心产品境内销售承压。
- **[境外出口规模创历史新高]** -> [境外收入增长23.37%]: 公司深化“一带一路”沿线市场布局，成功获得印尼准入资质，人用狂犬病疫苗出口331万人份，同比增长39%，部分对冲国内下滑。
- **[核心产品毛利率下降]** -> [整体毛利率下滑3.57个百分点至79.37%]: 外销收入占比提升，但外销毛利率仅38.38%，远低于内销的88.01%，拉低了综合盈利水平。
- **[hib疫苗等6个研发项目终止]** -> [计提资产减值损失8066.60万元]: 公司对研发管线进行结构性优化，终止了hib疫苗等低效项目，直接导致当期开发支出减值，严重侵蚀利润。
- **[公允价值变动收益增加]** -> [部分对冲净利润下滑]: 公司投资的创新药行业私募基金估值修复，导致基金评估增值6372.42万元，成为非经常性损益的主要来源。
- **[销售回款减少]** -> [经营活动现金流净额下降31.96%]: 境内销售下滑导致应收账款回收放缓，经营性现金流净额降至3.41亿元，现金创造能力减弱。
- **[韶关高腾入主]** -> [公司治理结构优化]: 控股股东辽宁成大董事会换届，公司实际控制人由辽宁省国资委变更为无实际控制人，治理机制灵活度提升，为市场化运营赋能。
- **[人用二倍体狂犬疫苗获批上市]** -> [产品矩阵完善]: 2026年2月获批，与现有Vero细胞疫苗形成高低搭配，覆盖不同消费层级，巩固狂犬病疫苗龙头地位。

## 风险警告
**核心风险在于业绩断崖式下滑与主业增长动能枯竭。** 2025年扣非净利润同比暴跌87.59%，仅剩4017万元，核心原因是国内狂犬病疫苗市场已进入存量博弈的“红海”。12家企业竞争导致价格战与渠道库存积压，而公司过度依赖单一产品（人用狂犬病疫苗收入占比超93%），境内收入下滑22.42%直接击穿了利润底线。尽管海外出口增长39%创历史新高，但外销毛利率仅38.38%，远低于内销，无法弥补国内市场的量价齐跌，公司已陷入“增收不增利”的困境。

**第二增长曲线尚在襁褓，研发投入转化效率存疑。** 公司研发投入占营收比高达30.38%，但大量资金沉淀在临床前及早期临床项目（如20价肺炎、RSV疫苗），短期内无法贡献收入。同时，公司终止了hib疫苗等6个研发项目，累计投入超1.6亿元的hib疫苗项目直接“打水漂”，暴露出研发管线管理存在重大不确定性。新获批的二倍体狂犬疫苗和待上市的流感疫苗能否在红海中突围，以及创新药投资并购能否成功，均是巨大的未知数。

> 辽宁成大生物股份有限公司成立于2002年,以“提供优质生物制品,呵护人类生命健康”为企业使命,秉承“正直诚信、仁爱和谐、担当合作”的核心价值观,坚持“面对生命,只有责任”的企业理念,致力于成为国际级优秀的生物制药企业。公司目前在售的产品包括人用狂犬病疫苗和人用乙脑灭活疫苗,人用狂犬病疫苗全球累计安全使用超过5亿剂次;乙脑灭活疫苗适用人群更加广泛,更加纯净安全。公司在沈阳、北京、本溪三地设有研发中心,拥有超过200人的研发团队,在研产品管线覆盖15价HPV、B群流脑、20价肺炎、重组带状疱疹等多项创新品种。公司拥有专业化的推广团队,营销网络已覆盖国内2000余家区县级疾控中心,同时为来自全球30多个国家和地区的客户提供产品服务,产品具备较高的品牌知名度和美誉度。
