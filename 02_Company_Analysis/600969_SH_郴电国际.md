# 600969.SH 深度透视

## 因果逻辑链
- **财务费用压降** -> **扭亏为盈**: 公司通过借入低利率短期借款置换高息存量贷款，财务费用同比减少8101万元（-27.15%），是归母净利润从-3627万扭转为7639万的核心驱动力。
- **信用减值损失大幅减少** -> **利润修复**: 信用减值损失从上年-1.09亿收窄至-1892万，主要系上年对农网还贷资金计提大额坏账，本年无此事项，直接增厚利润。
- **供电主业量增利薄** -> **盈利天花板**: 售电量同比增2.07%至57.41亿千瓦时，但购电成本上升7.6%侵蚀毛利，供电毛利率仅6.68%，主业盈利能力受制于上游成本刚性。
- **工业气体业务萎缩** -> **利润结构失衡**: 供气收入同比骤降47.58%，主要子公司唐山中邦因前期结算价格争议收入已在上年确认，导致本期贡献大幅缩水，利润来源更依赖供电主业。
- **东江引水工程折旧与减值** -> **供水业务持续承压**: 自来水公司净亏损1.36亿元，主因东江引水工程投资折旧刚性（折旧占总成本50%）及2025年计提减值2052万元，水价调整尚未落地。
- **新能源转型加速** -> **长期增长点**: 在建光伏、风电项目稳步推进，海外项目突破，新能源发电占比提升，旨在降低外购电成本，但短期贡献有限，尚处投入期。
- **资金集中管理与司库系统** -> **现金流管理优化**: 建成司库管理系统，实现资金集中管理，在融资环境宽松背景下，有效降低融资成本，支撑了投资与债务化解。

## 风险警告
**核心风险在于电价政策不确定性与刚性成本侵蚀。** 湖南省第四监管周期输配电价政策尚未明确，公司供电主业经营模式面临从“趸售模式”向“输配电价模式”转型的冲击，盈利稳定性存疑。同时，东江引水工程每年带来巨额折旧（年折旧约1.6亿）和利息支出，而水价调整方案迟迟未落地，导致供水业务持续巨亏，资产减值风险犹存。

**第二重风险来自工业气体业务的剧烈波动与新能源转型的短期阵痛。** 工业气体收入因大额一次性收入确认后大幅下滑，暴露了该业务依赖大客户和价格争议的脆弱性。公司大力布局新能源，但光伏、风电项目投资回报周期长，且面临新型电力系统对电网调节能力的高要求，短期内难以对冲主业压力，反而可能推高资本开支和负债率。
