# 603889.SH 深度透视

## 因果逻辑链
- **[羊绒业务量价齐升]** -> [营收与利润双创新高]: 子公司新澳羊绒依托原产地优势与精细化管理，产能利用率提升，销量同比增长19.37%，带动羊绒业务营收增长19.26%，成为第二增长曲线。
- **[毛精纺主业毛利率提升]** -> [盈利韧性增强]: 尽管销量微降1.74%，但通过产品结构优化与成本控制，毛精纺纱线毛利率提升0.60个百分点至27.38%，稳固了基本盘。
- **[越南基地产能逐步释放]** -> [海外供应链保障能力增强]: 新澳越南一期20,000锭项目投产并平稳过渡，有效支撑境外市场业务拓展，境外营收同比增长21.17%。
- **[英国邓肯引入战略投资者]** -> [优化资本结构并强化高端定位]: 引入BARRIE KNITWEAR LIMITED投入1.82亿元，增厚资金实力，推动高端羊绒产线升级，巩固奢侈端市场地位。
- **[宽带战略驱动品类扩容]** -> [构建一站式天然纤维解决方案]: 从羊毛向羊绒、花式纱、户外运动纱线等多元化产品矩阵拓展，满足多场景需求，提升全球纺织价值链综合竞争力。
- **[持续高比例现金分红]** -> [传递长期投资价值]: 近五年现金分红比例均超50%，累计分红16.28亿元已超募资总额，体现对股东回报的重视。
- **[数字化与智能制造升级]** -> [运营效率与质量稳定性提升]: 推进MES、ERP等系统建设，获评“浙江省先进级智能工厂”，有效应对小批量、多品种的快速反应市场需求。

## 风险警告
**核心风险在于原材料价格剧烈波动与海外地缘政治不确定性。** 公司主要原料澳毛与羊绒价格受气候、汇率、国际供需等多重因素影响，短期内大幅波动将直接冲击存货价值与生产成本，考验公司库存管理与成本转嫁能力。尽管公司采取稳健采购策略，但无法完全对冲系统性价格风险。

**海外业务扩张面临双重压力。** 一方面，越南基地的运营需应对当地法律、文化差异及管理挑战；另一方面，全球贸易保护主义抬头，尤其是美国关税政策频繁调整，对公司出口业务构成直接威胁。2025年公司对美出口市场份额已出现下滑，若贸易摩擦加剧，将显著影响境外营收增长。
