# 600729.SH 深度透视

## 因果逻辑链
- **[消费动能疲软]** -> [营收下降14.24%]: 2025年整体消费意愿未恢复，公司各业态（百货、电器、汽贸）成交客流下降，导致营业收入同比减少。
- **[汽贸业态主动收缩]** -> [营收下降23.43%]: 公司加速燃油车向新能源转型，通过关停并转、控量提质，主动收缩低效燃油车业务，拖累整体营收。
- **[供应链变革与毛利率提升]** -> [主营业务毛利率提升2.31个百分点至22.60%]: 超市垂直供应链建设（直采基地、自有品牌）、百货品牌矩阵优化，有效对冲了收入下滑对利润的侵蚀。
- **[投资收益下降]** -> [净利润下降20.48%]: 参股公司马上消费金融受外部环境影响利润同比下降，导致公司投资收益同比减少15.34%，加剧了利润下滑幅度。
- **[线上渠道与B端业务增长]** -> [对冲线下下滑]: 线上销售超20亿元，B端实物类销售近23亿元（同比增长约20%），成为弥补线下客流损失的关键增量。
- **[AI与数智化降本]** -> [经营费用同比下降]: 多点AI出清、智能补货等系统落地，叠加组织优化，销售费用、人工费用、租赁费用均同比下降，支撑了利润韧性。
- **[高分红与股东回报]** -> [入选“中证红利指数”]: 2025年中期分红+年度分红合计4.18亿元，分红率40.02%，上市以来累计分红73.43亿元，强化了高股息价值标杆定位。

## 风险警告
**核心风险在于消费复苏不及预期与汽贸转型阵痛。** 公司营收与利润双降，根本原因是宏观消费动能疲软，且短期内难以逆转。汽贸业态作为第二大收入来源，正处于燃油车收缩、新能源扩张的“青黄不接”期，2025年汽贸净亏损6830万元，是拖累业绩的最大板块。若新能源转型无法快速弥补燃油车退出带来的利润缺口，公司整体盈利将持续承压。

**另一重大风险是投资收益的脆弱性。** 公司约57%的净利润来自参股公司马上消费金融的投资收益。马上消费金融作为消费金融公司，其业绩高度依赖宏观经济、利率环境及监管政策。一旦其经营环境恶化或利润下滑，将直接导致公司净利润大幅波动，削弱公司主业改善带来的积极影响。
