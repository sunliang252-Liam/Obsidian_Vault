# 688352.SH 深度透视

## 因果逻辑链
- **[显示驱动芯片封测龙头地位]** -> [营收增长11.78%]: 受益于产业转移与境内客户需求增加，公司作为境内最大显示驱动芯片封测企业，主营业务收入同比增长13.05%。
- **[产品结构向AMOLED优化]** -> [毛利率承压]: AMOLED营收占比超20%且持续上升，但新产线（合肥基地）折旧及股权激励费用增加，导致主营业务毛利率下降2.60个百分点至28.56%。
- **[多元化芯片业务规模不足]** -> [利润下滑15.16%]: 多元化芯片封测营收仅1.52亿元，且毛利率同比大降7.60个百分点至21.60%，未能形成有效利润增长点，叠加研发费用增长26.57%，导致归母净利润下滑。
- **[可转债发行成功]** -> [资产结构变化]: 发行8.5亿元可转债，货币资金大增77.29%至17.45亿元，同时应付债券增加8.31亿元，总资产增长14.45%。
- **[高额股东回报]** -> [现金流压力]: 现金分红与回购合计占净利润82.18%，但经营活动现金流净额下降11.49%，显示高分红与资本开支之间存在潜在矛盾。
- **[研发投入持续加大]** -> [技术壁垒巩固]: 研发投入增长26.57%至1.96亿元，在28nm制程显示驱动芯片封测、铜镍金凸块等领域保持领先，但短期侵蚀利润。
- **[客户集中度高]** -> [经营风险]: 前五大客户销售额占比54.64%，其中第一大客户为关联方（占比15.60%），对单一客户依赖度较高。

## 风险警告
**核心风险在于“增收不增利”与多元化转型的困境。** 公司营收增长依赖显示驱动芯片封测主业，但该业务毛利率因新产能折旧和成本上升而持续下滑。多元化芯片业务规模小、毛利率低，且产销量大幅下降（-38.67%），未能成为第二增长曲线，反而拖累整体盈利。研发费用和股权激励费用的刚性增长进一步压缩利润空间，导致净利润与营收走势背离。

**财务与市场风险不容忽视。** 公司账面商誉高达8.87亿元（来自收购苏州颀中），若下游面板行业周期下行或竞争加剧，存在减值风险。此外，公司境外收入占比29.13%，汇率波动可能造成较大汇兑损失（2025年财务费用已由负转正）。可转债的发行虽补充了资金，但也增加了财务杠杆和未来转股摊薄的风险。
