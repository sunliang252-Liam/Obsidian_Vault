# 688249.SH 深度透视

## 因果逻辑链
- **[产能利用率高位运行]** -> [营收增长17.69%]: 半导体景气回升，公司订单饱满，产能利用率维持高位，规模效应显现，推动收入规模持续增长。
- **[产品结构优化（CIS/PMIC占比提升）]** -> [营收结构改善]: DDIC营收占比从67.50%降至58.06%，CIS和PMIC占比提升，降低了对单一产品的依赖，增强了抗风险能力。
- **[持续高研发投入（13.35%）]** -> [先进制程突破]: 研发费用14.53亿元，驱动28nm逻辑平台完成开发、40nm OLED及55nm CIS实现量产，为未来增长打开新空间。
- **[转让光罩技术]** -> [非经常性损益大增]: 确认收益2.77亿元，占归母净利润39.38%，是净利润增长32.16%的主要推手，但掩盖了扣非净利润下滑48.77%的真相。
- **[固定资产折旧及股权激励成本增加]** -> [扣非净利润大幅下滑]: 产能扩张导致资产转固折旧增加，叠加股权激励费用，管理成本上升，严重侵蚀了主营业务的盈利能力。
- **[客户集中度高]** -> [经营风险集中]: 前五大客户销售占比55.69%，对主要客户的依赖度高，若客户调整采购策略，将对公司业绩产生重大不利影响。
- **[库存量激增128.78%]** -> [存货跌价风险上升]: 公司主动备货导致库存大幅增加，存货跌价准备计提比例从2.59%升至5.81%，未来若市场需求不及预期，将面临资产减值压力。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化。** 公司营收增长17.69%，但扣非净利润却暴跌48.77%，表明主营业务盈利能力严重下滑。利润的“增长”主要依赖转让光罩技术的一次性收益（占净利润39.38%）和政府补助，这种盈利结构极其脆弱。高额的固定资产折旧和股权激励成本正在持续侵蚀利润，未来若产能利用率或产品价格承压，公司可能陷入亏损。

**结构性风险来自客户集中与库存高企的双重压力。** 前五大客户贡献超55%营收，任何单一客户的流失都将造成剧烈冲击。同时，公司主动将库存量提升128.78%，远超销量增速（18.88%），导致存货跌价准备比例翻倍。这反映出公司在需求预测上可能存在偏差，一旦下游市场降温，将面临巨大的存货减值风险，进一步恶化现金流和利润表。
