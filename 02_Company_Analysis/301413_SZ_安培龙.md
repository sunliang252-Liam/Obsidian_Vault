# 301413.SZ 深度透视

## 因果逻辑链
- **[压力传感器业务高速增长]** -> [营收增长25.88%]: 陶瓷电容式压力传感器营收突破6亿元（+34.78%），MEMS压力传感器营收5828万元（+433.57%），成为核心增长引擎。
- **[车规级压力传感器国产替代]** -> [市场份额提升]: 公司实现低、中、高压全压力量程覆盖，进入比亚迪、Stellantis、北美知名新能源车企等供应链，替代进口。
- **[研发投入激增56.24%]** -> [新产品储备与长期竞争力]: 研发费用9783万元，重点投向力传感器（六维力、EMB刹车力）、IC芯片设计、MEMS技术，为未来增长蓄力。
- **[下游汽车行业景气]** -> [订单增长]: 2025年中国汽车产销量突破3400万辆，新能源汽车渗透率达47.9%，直接拉动公司车规级传感器需求。
- **[垂直产业链整合]** -> [成本与性能优势]: 掌握从陶瓷材料配方到传感器模组的全链条工艺，形成技术壁垒，支撑产品竞争力。
- **[全球化布局]** -> [海外市场拓展]: 设立德国、泰国子公司，推进“海外市场销售、服务及技术本地化”，外销收入增长18.21%。
- **[力传感器业务突破]** -> [打开新增长极]: EMB刹车力传感器获国内头部车企定点并建设专用产线，六维力传感器进入客户送样阶段，布局机器人赛道。

## 风险警告
**毛利率持续承压与产能消化风险。** 2025年公司综合毛利率29.02%，同比下降3.18个百分点，主因压力传感器业务快速扩张中成本增速（+49.06%）高于收入增速（+44.08%），以及热敏电阻等成熟产品价格竞争加剧。同时，公司正大规模扩产（定增募资5.44亿元用于压力传感器、力传感器产线），若下游汽车、机器人需求不及预期，新增产能将面临消化压力，拖累资产回报率。

**新业务商业化存在重大不确定性。** 力传感器（六维力、扭矩传感器）和氧传感器/氮氧传感器仍处于客户验证、小批量试产阶段，2025年相关收入占比极低，对当期业绩无实质贡献。EMB力传感器虽获定点，但距大规模量产仍有距离。这些高研发投入的新业务能否成功实现规模化销售和盈利，是公司中长期估值的关键变量，但短期风险极高。
