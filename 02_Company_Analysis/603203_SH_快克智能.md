# 603203.SH 深度透视

## 因果逻辑链
- **[AI算力爆发驱动光通信设备需求]** -> [精密焊接装联设备收入增长12.24%]: AI数据中心建设提速，带动高速连接器与光模块对高精度焊接装联设备需求快速扩容，公司设备进入安费诺、莫仕等头部企业产线。
- **[半导体先进封装设备量产]** -> [固晶键合封装设备收入暴增89.41%]: 公司自主研发的高速高精固晶机、微纳银烧结设备等步入量产阶段，在功率半导体和碳化硅封装领域实现批量出货。
- **[机器视觉检测技术升级]** -> [视觉检测制程设备收入增长18.28%]: 公司开发的光模块专用AOI、六面检AOI等设备，精准适配高速光模块和AI服务器连接器检测需求，实现规模化突破。
- **[全球化布局与头部客户深度绑定]** -> [智能制造成套装备海外交付突破]: 公司成功交付匈牙利Forvia中控系统ECU自动化生产线，并持续为博世、联合汽车电子等客户交付域控制器、热管理等产线。
- **[子公司补缴历史税款]** -> [归母净利润同比减少34.78%]: 因子公司补缴2024年度及以前年度企业所得税，导致净利润大幅下滑，若剔除该影响，扣非归母净利润同比增长21.00%。
- **[收款能力增强]** -> [经营活动现金流净额同比大增110.68%]: 报告期内客户回款增加，经营活动现金流净额达2.96亿元，显著改善现金流状况。
- **[研发投入持续高企]** -> [先进封装TCB热压键合设备研发完成]: 公司研发费用占营收比例达12.91%，成功突破TCB热压键合设备核心技术，样机已进入客户打样验证阶段。

## 风险警告
**核心风险：归母净利润因子公司补缴历史税款而大幅下滑34.78%，暴露出公司税务合规管理存在漏洞。** 尽管剔除该影响后扣非净利润增长21%，但一次性补缴事件严重侵蚀了当期利润，并可能引发市场对公司财务内控的质疑。此外，公司综合毛利率同比微降，固晶键合封装设备毛利率下降3.43个百分点，显示新业务在放量初期面临成本压力。

**竞争与技术迭代风险：** 公司所处的智能装备领域竞争激烈，尤其在光通信和半导体封装设备赛道，国际巨头与国内新进入者并存。公司研发投入虽高，但TCB热压键合设备等前沿产品尚处于客户验证阶段，能否成功产业化并获取订单存在不确定性。若技术迭代不及预期，公司将面临市场份额被蚕食的风险。
