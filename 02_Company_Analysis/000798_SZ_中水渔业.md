# 000798.SZ 深度透视

## 因果逻辑链
- **[核心捕捞业务量价齐升]** -> [扭亏为盈]: 2025年捕捞产量同比+9.39%，销售均价同步提升，推动捕捞收入同比+29.38%，毛利率从3.04%跃升至12.62%，成为利润核心来源。
- **[鱿鱼资源显著恢复]** -> [利润结构优化]: 鱿鱼捕捞收入同比+35.49%，毛利率高达20.77%，有效对冲了金枪鱼业务（毛利率-6.96%）的亏损，改善了整体盈利结构。
- **[零售及加工贸易业务大幅收缩]** -> [营收规模下降]: 该板块收入同比-67.09%，导致总营收下降11.98%，但因其毛利率低（4.10%），收缩反而减轻了亏损负担，是主动“瘦身健体”的结果。
- **[资产减值损失高企]** -> [侵蚀利润]: 2025年信用减值及资产减值损失合计约8360万元，占利润总额的55.29%，主要来自应收款项和存货计提，是利润的主要“出血点”。
- **[政府补助贡献显著]** -> [增厚利润]: 2025年其他收益（含政府补助）达2.79亿元，是利润总额的1.85倍，表明公司对非经常性收益依赖度极高，主业盈利能力仍显脆弱。
- **[中渔环球与舟山远洋为核心利润支柱]** -> [业绩分化]: 两大子公司合计贡献净利润约3.28亿元，而深蓝食品、舟渔制品等加工贸易子公司合计亏损约4549万元，显示“捕强贸弱”格局。
- **[航运项目资产占比高]** -> [财务杠杆风险]: 航运项目（中渔环球）净资产占公司净资产的67.04%，其资产规模大、负债率高，是公司整体财务杠杆和利息费用的主要来源。

## 风险警告
公司2025年虽实现扭亏，但盈利质量堪忧。核心风险在于：**主业盈利能力严重依赖政府补助和资源波动**。剔除约2.79亿元的其他收益（主要为政府补助），公司营业利润将转为亏损。同时，鱿鱼资源恢复是2025年盈利改善的关键，但渔业资源受气候变化影响具有高度不确定性，若资源再度恶化，业绩将剧烈波动。

**财务结构风险突出**。公司资产负债率高达72.88%，有息负债（短期+长期借款）约23.83亿元，年利息费用近9000万元，财务费用对利润形成巨大压力。此外，资产减值损失持续高企（8360万元），反映出公司在存货管理和应收账款回收方面存在系统性风险，尤其是金枪鱼业务持续亏损（毛利率-6.96%），资产质量堪忧。
