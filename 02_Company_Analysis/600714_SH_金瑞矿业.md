# 600714.SH 深度透视

## 因果逻辑链
- **[碳酸锶价格上半年大涨，下半年回落]** -> [全年营收微降3.06%，净利润下降12.70%]: 上半年受益于落后产能出清，碳酸锶价格同比显著上涨，但下半年行业产能集中释放导致价格明显回落，全年盈利空间受挤压。
- **[碳酸锶销售均价同比上涨33.73%]** -> [锶盐产品毛利率大幅提升18.33个百分点至37.62%]: 尽管销量下降8.35%，但均价上涨覆盖了成本，使核心产品盈利能力显著改善。
- **[金属锶及铝锶合金产销量大幅下滑]** -> [拖累整体业绩]: 金属锶产量/销量同比降30%，铝锶合金销量降15.52%，主要因下游需求疲软及竞争加剧，导致该板块收入萎缩。
- **[主要原材料天青石、白煤采购价格下降]** -> [营业成本同比下降8.71%，毛利率提升4.88个百分点]: 成本端改善部分对冲了产品价格下行压力，是维持盈利的重要支撑。
- **[管理费用同比上升22.01%]** -> [侵蚀利润]: 主要因职工薪酬、社保普涨及管理优化投入增加，费用刚性增长对净利润形成压制。
- **[经营活动现金流净额同比大幅下降48.08%]** -> [现金流质量恶化]: 主要因银行承兑汇票结算比例增加，导致销售回款中现金占比下降，同时职工薪酬和税金支出增加。
- **[贵州红星6万吨/年锶盐产能项目建成投产]** -> [行业供给格局剧变，竞争加剧]: 头部企业大规模产能释放，预计将加剧市场竞争，对公司市场份额和盈利空间形成长期压力。

## 风险警告
**核心风险在于行业供给格局的剧烈变化。** 报告期末，贵州红星6万吨/年碳酸锶项目投产，直接打破了原有供需平衡。公司作为年产2万吨的中型玩家，将面临市场份额被挤压、产品价格持续承压的严峻挑战。2025年下半年价格已明显回落，2026年这一趋势可能加剧，公司盈利能力面临重大不确定性。

**公司战略扩张存在较大执行风险。** 公司计划新建30万吨天青石精选及4.5万吨碳酸锶项目，总投资额巨大。在行业产能已显过剩、竞争加剧的背景下，大规模资本开支可能带来产能消化困难、投资回报率不及预期的风险。同时，项目尚处于前期阶段，资金需求将对公司现金流构成压力。
