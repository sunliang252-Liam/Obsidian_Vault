# 600159.SH 深度透视

## 因果逻辑链
- **[行业深度调整与区域市场萎缩]** -> [收入与利润双降]: 全国房地产投资下降17.2%，公司核心区域顺义区销售面积下降35.5%，导致公司营收下滑11.54%，归属净利润亏损扩大至-2.54亿元。
- **[存货与应收账款大规模减值]** -> [巨额资产减值损失]: 计提存货跌价准备和信用减值损失合计约2.63亿元，是导致净利润大幅亏损的直接财务原因。
- **[建筑施工业务收入下滑]** -> [主业承压]: 建筑施工收入同比下降24.31%，占公司总收入72.45%的核心业务萎缩，直接拖累整体营收和利润。
- **[房地产开发业务毛利率恶化]** -> [盈利能力削弱]: 房地产开发毛利率同比下降11.83个百分点至24.71%，成本增速（79.76%）远超收入增速（51.52%），项目盈利空间被严重挤压。
- **[高客户集中度与关联交易依赖]** -> [经营独立性风险]: 前五名客户销售额占比58.10%，其中关联方销售额占比高达44.88%，公司对单一关联客户（北京天房银地）存在重大依赖。
- **[区域市场竞争力不足]** -> [去化困难]: 在顺义区市场份额仅0.06%，满洲里项目销售几乎停滞（全年仅售144.84平方米），核心区域去化能力极弱。
- **[经营活动现金流净流出]** -> [资金链紧张]: 经营活动现金流由正转负，净流出700万元，叠加筹资活动净流出5077万元（偿还借款），公司内生造血能力不足。

## 风险警告
**核心风险在于资产质量持续恶化与主业萎缩的恶性循环。** 公司连续三年巨亏，2025年归属净利润-2.54亿元，核心原因是计提了高达2.63亿元的存货和信用减值损失。这反映出公司在顺义、中山、满洲里等地的房地产项目面临严重的去化困难和价格下跌压力，资产价值持续缩水。同时，占收入大头的建筑施工业务收入萎缩24%，进一步削弱了公司的盈利基础。这种“主业萎缩+资产减值”的双重打击，使公司陷入经营困境。

**另一个重大风险是经营独立性和客户集中度风险。** 公司近45%的收入来自单一关联方客户（北京天房银地房地产开发有限公司），这种高度依赖关联交易的业务模式，不仅使公司业绩受制于关联方的经营状况和付款节奏，也引发了市场对公司经营独立性的担忧。一旦关联交易出现不利变化，将对公司现金流和收入造成毁灭性打击。此外，公司在满洲里等非核心区域的存量项目几乎丧失流动性，成为难以变现的“死库存”，持续吞噬公司资源。
