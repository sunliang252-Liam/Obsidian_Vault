# 600880.SH 深度透视

## 因果逻辑链
- **智慧教育业务（生学教育）收入锐减52.24%** -> [整体营收下滑23.42%]: 作为核心增长引擎，生学教育系统集成业务大幅萎缩，直接拖累公司总收入从5.79亿降至4.56亿。
- **生学教育大额亏损（-2817万）** -> [归母净利润由盈转亏（-1504万）]: 子公司巨额亏损叠加其他板块利润下滑，导致公司整体陷入亏损，归母净利润同比暴跌179.92%。
- **研发费用缩减36.87%** -> [短期利润压力缓解，但长期竞争力存疑]: 公司通过调整研发结构、减少人员来压缩成本，虽在当期减轻了费用压力，但可能削弱未来产品创新与市场拓展能力。
- **经营活动现金流净额大幅流出（-1.64亿）** -> [现金流恶化，经营风险加剧]: 购买商品、接受劳务支付的现金大幅增加，导致经营性现金流净额同比恶化297.10%，表明业务回款或项目垫资压力巨大。
- **收购每经科技51%股权** -> [切入智能传媒科技赛道]: 公司以6649万元收购AI应用企业，旨在构建“媒体+产业”新格局，是向数字化、智能化转型的关键布局。
- **游戏出海业务稳步发展** -> [海外市场成为稳定收入来源]: “全民主公”IP系列产品全球总流水近3亿元，海外业务成为游戏板块的重要支撑，对冲了国内游戏收入下滑的风险。
- **文交所平台年交易额突破37亿元** -> [新业务平台孵化初见成效]: 成都文交所旗下多个平台运营稳定，交易属性逐步显现，为公司开辟了新的收入增长点，但尚未贡献显著利润。
- **媒体业务收入增长27.18%，但成本增长48.50%** -> [增收不增利，毛利率承压]: 博瑞眼界等媒体业务规模扩张，但成本增速远超收入，导致毛利率下滑11.80个百分点，盈利能力恶化。

## 风险警告
**核心风险在于核心子公司生学教育的持续恶化与巨额商誉减值隐患。** 生学教育作为公司“智慧管理”战略的核心载体，2025年收入腰斩、亏损近3000万，其业务模式（系统集成）受宏观经济和行业竞争影响巨大，项目推进与回款严重滞后，导致公司整体业绩由盈转亏。更危险的是，收购生学教育形成的1.82亿元商誉，以及游戏板块的2.23亿元商誉，合计超过4.2亿元，占净资产比例极高。若生学教育或游戏业务未来经营持续不及预期，将面临巨大的商誉减值风险，可能一次性吞噬公司多年利润。

**公司转型战略尚处投入期，新业务盈利能力未得到验证，现金流持续失血。** 公司正从传统媒体向“数字文创新经济”转型，但新收购的每经科技、孵化的文交所平台等均处于早期阶段，尚未贡献实质性利润。同时，传统媒体业务（如广告代理）陷入“增收不增利”的困境，而智慧教育业务又需要大量垫资，导致经营活动现金流净额大幅流出至-1.64亿元。这种“新旧动能转换”过程中的现金流压力，若不能得到有效缓解，将严重制约公司的持续投入和抗风险能力。
