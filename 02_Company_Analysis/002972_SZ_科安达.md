# 002972.SZ 深度透视

## 因果逻辑链
- **[系统集成业务爆发]** -> [营收增长18.78%]: 系统集成收入同比增11.80%至2.47亿元，成为最大收入来源，拉动整体营收从3.19亿升至3.79亿。
- **[防雷及智能诊断高增]** -> [产品结构优化]: 防雷及智能诊断收入同比增51.39%至1.16亿元，毛利率高达59.95%，显著提升整体盈利质量。
- **[境外业务突破]** -> [打开新增长空间]: 境外收入同比暴增521.66%至939.8万元，核心产品获欧盟NOBO、DEBO、MAV认证，实现从产品出口到标准对接的跨越。
- **[计轴系统隐形冠军地位]** -> [高客户粘性与复购]: 计轴系统在超200条地铁线路应用，市占率领先，存量项目更新改造需求持续，为公司提供稳定收入来源。
- **[研发投入持续高企]** -> [技术壁垒加固]: 研发费用占营收9.88%，拥有139项专利（含59项发明专利），核心产品获SIL4最高安全认证，构筑护城河。
- **[现金流大幅改善]** -> [经营质量提升]: 经营活动现金流净额达1.93亿元，同比增长7.46%，远超净利润，显示回款能力强劲，财务健康度优异。
- **[财务费用大幅转负]** -> [汇率变动受益]: 财务费用从284万降至-829万，主要系本期汇率变动所致，表明公司持有外币资产或负债，受益于人民币贬值。

## 风险警告
**核心风险在于应收账款高企与信用减值损失激增。** 报告期末应收账款高达3.66亿元，占总资产25.74%，且当期信用减值损失高达3293万元，同比由正转负，吞噬了相当比例的营业利润。这表明下游客户（主要为铁路局、地铁公司）付款周期长、回款压力大，坏账风险显著上升，是影响公司未来利润稳定性的最大隐患。

**其次，募投项目多次延期，产能释放不及预期。** “自动化生产基地建设项目”和“产品试验中心建设项目”已多次延期至2026年底，“新一代计轴智能传感器开发项目”延期至2027年底。项目进度严重滞后，不仅占用大量募集资金，更意味着公司核心产能扩张和新产品产业化进程受阻，可能错失市场机遇，影响长期成长性。
