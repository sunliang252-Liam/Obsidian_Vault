# 603392.SH 深度透视

## 因果逻辑链
- **[九价HPV疫苗上市但未放量]** -> [业绩亏损]: 九价疫苗处于市场准入初期，尚未形成规模化利润，无法对冲二价疫苗因集采降价和库存减值带来的业绩冲击。
- **[二价HPV疫苗纳入国家免疫规划]** -> [收入结构承压]: 纳入EPI后政府采购价大幅下降，虽获得稳定需求，但显著拉低了疫苗业务的整体毛利率（同比-43.18个百分点）。
- **[国内疫苗集采政策与行业竞争加剧]** -> [收入下滑]: 国内疫苗市场整体承压，二类疫苗价格战激烈，导致公司疫苗收入同比下降24.63%。
- **[诊断试剂集采降价与医保控费]** -> [诊断业务利润压缩]: 尽管特色检测和流水线装机增长，但常规生化、免疫诊断产品面临持续价格下行压力，诊断试剂毛利率同比下降4.95个百分点。
- **[九价HPV疫苗研发转产完成]** -> [研发费用大幅下降]: 九价疫苗研发项目从费用化阶段转入资本化，导致研发费用同比减少36.71%，但资本化金额增加，未来将形成摊销压力。
- **[疫苗产销量增加]** -> [营业成本上升]: 为应对九价上市和二价EPI供应，疫苗生产量同比大增130.27%，导致营业成本同比上升21.45%，进一步侵蚀利润。
- **[海外市场拓展加速]** -> [境外收入高增长]: 二价HPV疫苗海外销售收入实现倍数级增长，境外收入同比+90.85%，成为公司重要的增长缓冲垫。

## 风险警告
**核心风险在于新旧产品交替的“青黄不接”期。** 九价HPV疫苗虽已上市，但市场准入和终端放量需要时间，短期内无法弥补二价疫苗因纳入国家免疫规划（EPI）导致的政府采购价大幅下降和利润损失。公司2025年归母净利润由盈转亏至-3.98亿元，扣非净利润亏损扩大至-6.23亿元，显示主营业务造血能力已严重受损。若九价疫苗放量速度不及预期，公司将持续面临亏损压力。

**另一重大风险是资产减值与研发资本化带来的财务隐患。** 公司存货高达7.02亿元，疫苗产销量大增但毛利率骤降，存在进一步计提存货跌价准备的风险。同时，研发投入资本化比例高达34.78%，开发支出余额1.66亿元，若在研管线（如冻干水痘、20价肺炎疫苗）临床失败或商业化不及预期，将面临大额资产减值损失。此外，应收账款16.16亿元，客户主要为财政拨款的疾控中心，回款周期存在不确定性，可能持续占用现金流。
