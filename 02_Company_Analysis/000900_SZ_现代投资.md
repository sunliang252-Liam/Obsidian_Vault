## 因果逻辑链
- **[大宗商品贸易规模扩张]** -> [营收增长6.41%，但毛利率极低]: 子公司上海夯石贸易业务规模大幅增长，拉动总营收，但该业务毛利率仅-0.58%，对利润贡献微薄。
- **[存量债务利率压降]** -> [财务费用下降17.49%]: 公司主动管理债务结构，综合融资成本从2.97%降至2.66%，有效对冲了利息支出压力。
- **[子公司破产出表]** -> [非经常性损益大幅亏损，但扣非净利润大增57.42%]: 剥离大安生物质发电公司，产生-1.34亿元非经常性损失，但剔除此包袱后，主业盈利能力显著改善。
- **[高速公路车流量稳定增长]** -> [通行费收入基本盘稳固]: 核心路产（如湘衡高速）通行费收入微增，为公司提供稳定现金流，支撑“一体两翼”战略。
- **[“交能融合”政策驱动]** -> [新能源业务成为新增长极]: 作为湖南省高速场景新能源唯一实施企业，光伏、储能业务规模化推进，抢占交通能源融合新赛道。
- **[数智化转型降本增效]** -> [运营效率与通行效率双提升]: 智慧收费站、潮汐车道等改造使车道资源利用率提升30%-50%，高峰通行时间缩短40%以上。
- **[金融板块（银行、期货）稳健]** -> [贡献稳定利润，对冲环保业务亏损]: 岳阳巴陵农商行、大有期货持续盈利，弥补了现代环境因处理遗留问题导致的亏损。

## 风险警告
**核心风险在于高杠杆与担保敞口。** 公司资产负债率高达76.06%，长期借款占总资产32.18%。更严峻的是，对子公司（如怀芷高速、大安星旗）的担保余额达33亿元，其中怀芷高速、大安星旗等项目已出现阶段性偿债压力或司法重整，或有连带清偿风险巨大，可能侵蚀公司利润。

**第二重风险是业务结构脆弱性。** 占营收44.91%的大宗商品贸易毛利率为负，本质是“赔本赚吆喝”，对利润贡献极低，且占用大量营运资金。同时，环保板块（现代环境）虽因剥离不良资产而改善，但垃圾焚烧、危废处置行业竞争加剧，客户支付能力下降，未来盈利持续性存疑。
