# 600125.SH 深度透视

## 因果逻辑链
- **[特种箱资产规模扩张与结构优化]** -> [净利润+37.48%]: 三年规划收官，特种箱保有量达15.3万只，发送量+19.33%，高毛利业务占比提升至72.21%，驱动利润大幅增长。
- **[沙鲅铁路货运筑底回升]** -> [到发总量+8.25%]: 主动适应货运市场化改革，深挖“公转铁”潜力，成功扭转连续两年下滑势头，稳住货运基本盘。
- **[供应链管理业务主动压降规模]** -> [营收-18.88%]: 为控制经营风险，主动收缩钢材等大宗贸易规模，导致营收下降，但毛利率稳定，风险可控。
- **[房地产业务去化加速]** -> [毛利+90.91%]: 存量产品去化加速，新项目高质量交付，带动该板块毛利大幅增长，但整体贡献仍有限。
- **[冷链子公司持续亏损]** -> [拖累整体利润]: 中铁铁龙冷链发展有限公司净亏损9351万元，成为公司主要的利润出血点，中小板块治理进入深水区。
- **[发行新债置换旧债]** -> [财务结构优化]: 发行5亿元“25铁龙01”债券，置换到期旧债，资产负债率降至25.96%，利息保障倍数提升至37.83倍，财务风险降低。

## 风险警告
**核心风险在于供应链管理业务对单一客户的严重依赖。** 报告显示，前五大客户销售额占比高达70.84%，其中仅吉林鑫达钢铁有限公司一家就贡献了62.79%的营收。这种高度集中的客户结构，使得公司经营极易受到该客户所在钢铁行业周期波动及自身经营状况的冲击，一旦合作关系或客户需求发生重大不利变化，将对公司营收和现金流产生毁灭性打击。

**另一重大风险是中小板块的持续亏损与资产减值压力。** 冷链子公司亏损近亿元，新型材料、酒店等其他业务也处于亏损状态。同时，公司持有大量房地产存货（占总资产14%），在房地产行业深度调整的背景下，存在进一步的减值风险。这些“失血点”不仅侵蚀核心业务利润，也考验着管理层的治理能力和资产处置决心。
