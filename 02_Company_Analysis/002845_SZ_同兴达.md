# 002845.SZ 深度透视

## 因果逻辑链
- **[客户结构优化与成本管控]** -> [毛利率提升]: 公司聚焦核心大客户（华为、OPPO、传音、三星等），优化客户结构，同时严控成本与费用，推动综合毛利率同比上升1.15个百分点，成为净利润增长28.44%的核心驱动力。
- **[摄像类产品放量]** -> [收入结构改善]: 摄像类产品收入同比增长27.64%，营收占比从29.50%提升至36.10%，有效对冲了传统液晶显示模组业务收入下滑7.51%的影响，支撑总收入增长4.30%。
- **[半导体封测产能爬坡]** -> [第二增长曲线成型]: 子公司昆山日月同芯的显示驱动芯片封测项目月产量接近满产，2025年实现营收2.37亿元，标志着公司从模组制造向半导体先进封测的战略延伸取得阶段性成果。
- **[经营活动现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额同比增长53.72%至4.70亿元，主要系销售规模增长及到期应收款项现金增加，现金流质量显著优于净利润表现。
- **[股份回购与员工持股]** -> [股东利益绑定]: 公司耗资3.27亿元回购7.16%股份，并全部用于员工持股计划，将核心员工利益与公司长期价值深度绑定，有助于稳定管理层和核心团队。
- **[车载摄像头业务布局]** -> [打开新增长空间]: 子公司南昌汽车电子与Sony、地平线、德赛西威等国际知名厂商合作加强，多项项目落地，为未来切入高壁垒、高增长的车载光学市场奠定基础。
- **[研发投入聚焦前沿技术]** -> [维持技术护城河]: 研发费用2.74亿元，重点投向MiniLED背光、柔性OLED、裸眼3D、铜镍金凸块等前沿技术，确保公司在显示模组和封测领域的技术领先地位。

## 风险警告
同兴达面临的核心风险在于**传统主业增长乏力与新兴业务盈利不确定性**。液晶显示模组收入同比下降7.51%，显示行业已进入存量竞争时代，智能手机换机周期拉长，公司若不能持续通过技术升级和客户拓展提升份额，将面临增长天花板。同时，半导体封测业务虽产能接近满产，但子公司昆山日月同芯2025年仍亏损约8569万元，何时实现扭亏为盈是市场关注的焦点。

此外，公司财务结构存在**高杠杆与高存货风险**。资产负债率高达72.57%，短期借款和应付票据合计超31亿元，财务费用因汇兑损失和融资成本增加同比暴增159.55%。存货账面价值15.35亿元，占资产总额16.06%，若下游需求不及预期或原材料价格剧烈波动，存货跌价风险将显著侵蚀利润。公司前五大客户销售占比53.91%，客户集中度较高，单一客户订单波动可能对经营造成较大冲击。
