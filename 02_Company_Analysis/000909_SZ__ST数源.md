# 000909.SZ 深度透视

## 因果逻辑链
- **[联营房企（黑龙江新绿洲）开发成本大幅减值]** -> [巨额投资亏损]: 公司持股49%的参股公司因房地产项目减值产生大额亏损，导致公司按权益法确认投资损失约1.33亿元，成为亏损主因。
- **[其他非流动金融资产公允价值下跌]** -> [公允价值变动损失]: 公司持有的金融资产（如基金、信托等）公允价值下降，产生约5362万元损失，进一步拖累业绩。
- **[房地产下行导致智慧社区业务萎缩]** -> [电子信息业务收入腰斩]: 智能门锁等产品受房地产市场持续下行及公租房建设体量缩小影响，销售收入大幅下降，导致该板块收入同比减少49.07%。
- **[宏观经济下行与终端消费收缩]** -> [园区产业收入下滑]: 经济疲软导致园区招商困难、租金下调，园区产业类业务收入同比下降16.12%。
- **[历史遗留诉讼与担保事项]** -> [大额营业外支出]: 公司因参股公司合同纠纷等诉讼事项计提预计负债，导致营业外支出高达7654万元。
- **[联营企业亏损及资产减值]** -> [净利润大幅亏损]: 投资收益（-1.42亿）、公允价值变动（-0.54亿）、信用及资产减值（-1.07亿）合计侵蚀利润超3亿元，导致全年净亏损4.37亿元。
- **[营收萎缩与持续亏损]** -> [触发退市风险警示]: 2025年扣除后营收低于3亿元且净利润为负，公司股票被叠加实施退市风险警示（*ST）。

## 风险警告
公司当前面临的核心风险是**退市风险**。2025年扣除后营业收入仅2.56亿元，且净利润、利润总额均为负值，已触发财务类退市指标。公司虽提出聚焦主业、加速房地产去化等自救措施，但电子信息业务收入腰斩、园区业务下滑，短期内实现营收突破3亿元并扭亏为盈的难度极大，若2026年未能改善，将面临强制退市。

此外，**资产质量与法律诉讼风险**同样严峻。公司对参股房企（如黑龙江新绿洲）的长期股权投资已计提大额减值，且仍面临多起重大诉讼（如与龙鼎集团、宋都集团的纠纷），潜在担保责任和预计负债规模巨大。这些历史包袱不仅持续侵蚀利润，也严重制约了公司融资能力和业务转型空间。
