# 301086.SZ 深度透视

## 因果逻辑链
- **[消费电子行业复苏]** -> [营收增长11.28%]: 下游AI手机、AIPC等终端需求回暖，带动精密功能性器件出货量增长28.58%，核心主业收入同比增长13.75%。
- **[核心主业毛利率下滑]** -> [净利润下降7.52%]: 消费电子产品功能性器件毛利率同比下降3.43个百分点，成本增速(20.26%)显著快于收入增速(13.75%)，侵蚀利润空间。
- **[散热业务收入萎缩]** -> [第二增长曲线承压]: 散热产品收入同比下降11.77%，毛利率仅14.49%，远低于主业，未能有效对冲主业盈利下滑。
- **[光伏储能业务尚处萌芽]** -> [对业绩贡献微乎其微]: 光伏储能产品收入仅占0.73%，且子公司深圳富智、东莞捷风合计亏损超2500万元，新业务尚需大量投入。
- **[大规模海外投资启动]** -> [资产负债率飙升]: 为推进KAMOA光伏储能电站项目(总投资14.1亿)，公司大幅举债，长期借款激增至8.57亿元，总资产增长45.79%，财务费用同比暴增962.92%。
- **[管理费用与研发费用激增]** -> [侵蚀净利润]: 管理费用同比增长34.16%，研发费用同比增长27.76%，人员扩张与项目投入导致刚性支出大幅增加。
- **[核心客户高度集中]** -> [经营依赖风险]: 前五大客户销售额占比高达67.67%，其中单一客户占比32.99%，公司业绩高度依赖少数头部客户订单。

## 风险警告
**核心风险在于“增收不增利”与“新旧动能转换阵痛”。** 公司2025年营收增长11.28%，但净利润反降7.52%，主因是核心主业毛利率下滑，而新培育的散热业务收入萎缩、光伏储能业务尚在巨额亏损。同时，为押注海外光伏储能项目，公司资产负债率急剧攀升，财务费用暴增962.92%，大规模资本开支已对当期利润形成显著拖累。

**更严峻的挑战在于战略转型的高度不确定性。** 公司计划投资14.1亿元建设刚果金光伏储能电站，项目资金主要依赖举债，且面临海外政治、建设、运营等多重风险。该业务目前收入占比不足1%，短期内难以贡献利润，反而可能因资金占用和财务成本高企，持续挤压传统主业的盈利空间，导致公司陷入“旧业务失速、新业务失血”的困境。
