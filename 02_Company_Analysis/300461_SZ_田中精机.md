# 300461.SZ 深度透视

## 因果逻辑链
- **[销售订单增长]** -> [营业收入同比+39.90%]: 公司聚焦主业，在汽车、工业控制领域电机品类订单显著增长，带动非标机收入+32.98%，特殊机收入+620.02%。
- **[非经常性损益大幅增加]** -> [归母净利润扭亏为盈]: 报告期非经常性损益达4219万元（含处置合营企业及原子公司收益），覆盖了扣非后-2649万元的亏损，实现净利润1571万元。
- **[子公司破产出表]** -> [存货与合同负债大幅减少]: 原子公司深圳佑富宣告破产，其存货和合同负债不再纳入合并报表，导致存货占总资产比例从23.20%降至14.29%。
- **[经营战略聚焦]** -> [内销收入占比提升至88%]: 公司深耕国内消费电子、汽车、工业控制三大领域，内销收入同比增长60.46%，而外销收入因战略调整下降27.99%。
- **[研发投入资本化率为0]** -> [研发费用全部费用化]: 公司研发投入1976万元，占营收6.25%，全部计入当期费用，未进行资本化，体现了审慎的会计处理。
- **[股权激励计划实施]** -> [总股本增加]: 2025年7月完成限制性股票首次授予登记，总股本由1.557亿股增至1.571亿股，增加核心团队稳定性。
- **[历史业绩补偿仲裁未执行]** -> [潜在坏账风险]: 针对远洋翔瑞的2.13亿元业绩补偿款，法院已终结本次执行程序，公司尚未收到款项，存在较大回收不确定性。

## 风险警告
公司核心风险在于盈利质量极差。2025年归母净利润虽扭亏为盈，但扣非净利润仍为-2649万元，连续两年为负。盈利主要依赖非经常性损益（处置资产、政府补助等），主业造血能力尚未恢复。同时，公司综合毛利率同比下降8.82个百分点至29.74%，非标机毛利率更是大幅下滑14.44个百分点，显示核心业务面临激烈的价格竞争和成本压力。

另一重大风险是历史遗留问题的资产减值与法律纠纷。子公司深圳佑富已宣告破产，公司对其债权回收存在重大不确定性。此外，针对远洋翔瑞原股东的2.13亿元业绩补偿款，法院已两次终结执行程序，回收前景渺茫。这些事项不仅可能引发进一步的资产减值损失，也持续消耗公司管理资源，拖累主业发展。
