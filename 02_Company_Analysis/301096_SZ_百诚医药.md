# 301096.SZ 深度透视

## 因果逻辑链
- **[集采与MAH政策冲击仿制药业务]** -> [营收下降15.45%]: 公司核心CRO业务（仿制药研发）受政策影响，客户需求萎缩，导致临床前药学研究、临床服务收入分别下降37%和36%。
- **[自主立项研发投入大幅削减]** -> [研发费用下降40%]: 为应对收入下滑，公司主动减少自主立项项目研发投入，研发费用从3.18亿降至1.90亿。
- **[商业化生产产能释放但成本高企]** -> [毛利率承压]: 子公司赛默制药商业化生产收入增长143%，但产线转固导致折旧成本激增，该业务毛利率为-31.61%，拖累整体盈利。
- **[股权激励费用冲回效应消失]** -> [管理费用激增48%]: 2024年因考核未达标冲回股份支付费用，2025年无此冲回，导致管理费用同比增加约3800万元。
- **[应收账款与合同资产减值]** -> [信用+资产减值损失超3300万]: 客户回款困难，公司计提大额坏账准备，进一步侵蚀利润。
- **[募集资金消耗+银行借款增加]** -> [财务费用飙升329%]: 利息收入减少，利息支出增加，财务费用从420万升至1803万。
- **[投资损失与债务重组损失]** -> [非经常性损益拖累]: 对合伙企业投资损失1470万，债务重组损失244万，加剧亏损。
- **[创新药管线尚处早期]** -> [短期无法贡献业绩]: 虽已获4个I类新药IND批件，但均处于临床或临床前阶段，研发投入大且回报周期长。

## 风险警告
**核心风险：仿制药CRO业务遭遇结构性衰退。** 公司营收与利润的核心来源——仿制药受托研发与成果转化，正受到集采深化和MAH制度调整的双重冲击。客户（尤其是中小MAH企业）研发意愿与支付能力下降，导致公司订单减少、项目延期、回款困难，进而引发大规模资产减值。这一趋势并非短期波动，而是行业生态的深刻变化，公司能否通过向创新药、CDMO和国际化转型弥补缺口，存在巨大不确定性。

**财务风险：现金流持续失血与高额固定成本形成恶性循环。** 公司经营活动现金流已连续两年为负（2025年-1.55亿），而赛默制药的巨额固定资产（46.32%总资产）带来持续的折旧与维护成本。在收入下滑的背景下，高固定成本结构使得利润对收入波动极度敏感。同时，公司研发投入虽主动削减，但创新药管线仍需大量资金，若收入端无法企稳，公司可能面临流动性压力。
