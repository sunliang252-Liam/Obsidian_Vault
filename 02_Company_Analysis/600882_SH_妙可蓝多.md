# 600882.SH 深度透视

## 因果逻辑链
- **[奶酪业务高增长]** -> [营收增长16.29%]: 奶酪收入同比增长22.84%，占主营收入比例提升至82.37%，成为核心增长引擎。
- **[扣非净利润暴增]** -> [盈利能力改善]: 扣非净利润同比大增235.94%，主因是主营业务盈利提升及非经常性损益（如金融资产公允价值变动）影响减弱。
- **[直营模式扩张]** -> [收入结构变化]: 直营收入同比增长113.27%，占主营收入比例提升，但毛利率下降2.14个百分点，显示渠道变革的短期成本。
- **[原材料储备增加]** -> [存货与现金流压力]: 存货同比大增62.61%，导致经营活动现金流净额下降13.46%，反映公司为应对原料价格波动和备货而增加资金占用。
- **[并购基金减值]** -> [非经常性损益波动]: 其他非流动金融资产（并购基金）公允价值变动损失1.62亿元，是导致归母净利润与扣非净利润差异的核心因素。
- **[蒙牛奶酪整合]** -> [协同效应释放]: 收购蒙牛奶酪后，双品牌（妙可蓝多+爱氏晨曦）在B端和C端协同，推动餐饮工业渠道和零售渠道增长。
- **[国产替代政策红利]** -> [行业竞争格局优化]: 对欧盟乳制品反补贴税政策落地，为国产奶酪释放进口替代空间，利好公司原制奶酪等核心品类发展。

## 风险警告
**核心风险在于并购基金减值与创始人承诺履行问题。** 公司对上海祥民并购基金的1.62亿元公允价值变动损失，直接侵蚀了当期利润，且该基金存续期已届满进入清算，后续回收金额存在重大不确定性。更关键的是，创始人柴琇未能履行对并购基金事项的足额补偿承诺，导致公司对其不予发放2025年年度目标奖金，这暴露了公司治理中核心人物的潜在信用风险，可能影响投资者信心。

**经营层面，存货高企与现金流压力不容忽视。** 公司为应对原料价格波动和业务增长，大幅增加原材料储备，导致存货同比飙升62.61%至9.33亿元，同时经营活动现金流净额同比下降13.46%。若未来市场需求不及预期或原料价格下跌，公司将面临较大的存货减值风险。此外，公司短期借款同比大增53.49%，财务费用因利息净收入减少而上升，财务杠杆和资金成本压力正在加大。
