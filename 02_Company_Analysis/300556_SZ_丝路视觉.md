# 300556.SZ 深度透视

## 因果逻辑链
- **[处置瑞云科技股权]** -> [净利润大幅减亏]: 处置部分股权确认1.14亿非流动资产处置损益，使归母净利润从-3.64亿收窄至-0.61亿。
- **[数字化展览展示业务增长]** -> [营收企稳]: 该业务收入同比增长12.09%至5.12亿，带动总营收微增3.39%，扭转了此前下滑趋势。
- **[严控成本与费用]** -> [经营性现金流大幅回正]: 通过缩减人员、优化项目管理，经营活动现金流净额从-1.42亿大幅转正至0.94亿。
- **[应收账款及合同资产减值改善]** -> [亏损收窄]: 加强项目结算与回款，减值准备计提较上年同期明显改善，是减亏的关键内因。
- **[展览展示场景构建毛利率为负]** -> [核心业务盈利能力承压]: 该业务收入占比53.13%，但毛利率为-21.46%，严重拖累整体盈利。
- **[G端/B端客户预算收紧]** -> [业绩短期承压]: 下游政府及企业客户受经济环境影响，导致公司近两年收入规模出现阶段性调整。
- **[AI与VR大空间等新业务布局]** -> [未来增长点]: 推出《平行的文明》等C端产品，探索从B端向C端市场延伸，培育新利润增长点。

## 风险警告
**核心风险在于主业盈利能力严重不足。** 公司营收占比超半数的“展览展示场景构建”业务毛利率为-21.46%，处于严重亏损状态。尽管公司通过处置资产和压缩成本实现了账面减亏，但扣非净利润仍亏损1.67亿，表明核心业务造血能力尚未恢复。若下游政府及企业客户预算持续收紧，主业亏损可能进一步扩大。

**应收账款坏账风险是财务健康的另一大隐患。** 公司应收账款规模高达3.64亿元，占净资产比例近88%。虽然客户以政府及大型企业为主，但项目验收及决算周期长，回款不确定性高。若宏观经济下行或客户出现支付困难，大规模的坏账计提将再次冲击利润表，并可能引发流动性危机。
