# 001230.SZ 深度透视

## 因果逻辑链
- **[“一芯双核”战略驱动]** -> [营收增长8.53%，净利润增长20.33%]: 公司以数字化、智能化、无人化为核心，构建“智慧运营+智能制造+数字平台+先进机器人”四位一体生态，运营与装备业务协同赋能，推动收入与利润双增。
- **[设备制造与销售业务爆发]** -> [该板块营收同比增长98.97%]: 公司全品类环卫装备布局（新能源、无人驾驶等）及核心技术自主化，叠加市场需求释放，驱动装备业务高速增长。
- **[智慧运营业务稳健扩张]** -> [该板块营收同比增长2.82%，贡献88.93%营收]: 公司以特许经营和政府购买服务模式深耕城乡环卫，中标年化额全国第5，在管项目年化额全国第9，规模与质量同步提升。
- **[无人化环卫商业化落地]** -> [降本增效，提升竞争力]: 公司无人驾驶清扫设备在合肥、深圳等地交付，从效率、质量、安全维度赋能环卫作业，为后续规模化推广奠定基础。
- **[智慧环卫云平台赋能]** -> [提升运营效率，降低管理成本]: 自研劲威智慧环卫3.0云平台实现“一网统管”，对人员、车辆、设施进行智能化管控，优化资源配置，巩固行业壁垒。
- **[研发投入持续加码]** -> [技术壁垒与产品竞争力增强]: 研发费用同比增长19.18%，聚焦新能源、无人驾驶、AI大模型，新增发明专利2项，推动产品迭代与核心技术自主可控。
- **[省外市场拓展加速]** -> [省外营收同比增长13.10%，占比提升至42.77%]: 公司突破区域限制，服务网络辐射全国，省外市场成为重要增长极，分散了单一区域依赖风险。

## 风险警告
**应收账款高企与回款风险。** 报告期末应收账款高达13.32亿元，占总资产39.48%，同比大幅增长。公司客户以地方政府及国资平台为主，受地方财政预算、资金拨付节奏影响，回款周期存在不确定性。若回款持续延迟，将直接侵蚀公司现金流，增加坏账计提压力，对资产质量和盈利能力构成显著威胁。

**人工成本上升与政策依赖风险。** 智慧运营业务人工成本占营业成本比重高达61.87%，是公司最大的成本项。随着社会薪酬水平上涨，若项目服务费调整滞后，将直接压缩利润空间。同时，公司收入高度依赖政府财政预算支出，若未来环保政策调整或地方财政缩减环卫预算，将对公司业务规模和营收增速造成不利影响。
