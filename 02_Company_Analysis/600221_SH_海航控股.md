# 600221.SH 深度透视

## 因果逻辑链
- **[国际航线运力大幅扩张]** -> [国际收入增长36.51%]: 国际可用座位公里同比增38.83%，驱动国际及地区收入达138.35亿元，成为收入增长核心引擎。
- **[财务费用大幅下降]** -> [净利润扭亏为盈]: 财务费用同比降55.37%，主要因确认汇兑收益15.1亿元，直接推动归母净利润从-9.21亿转为+19.80亿。
- **[航油成本占比高但微降]** -> [毛利率小幅改善]: 航油成本占营业成本31.78%，同比下降2.43个百分点，叠加收入增长，毛利率微增0.12个百分点。
- **[精细化管理与日成本管控]** -> [经营现金流稳健增长]: 日成本系统实现自动化监控，经营活动现金流净额达160.5亿元，同比增13.57%，支撑运营。
- **[海南自贸港封关红利]** -> [辅业与维修业务爆发]: 吉耐斯发动机维修产值增147%，海航技术承接进境维修业务增128%，受益于零关税政策。
- **[关联方应收款持续累积]** -> [信用减值风险高企]: 应收关联方款项余额超111亿元，虽计提坏账准备，但关联方还款承诺屡次延期，回收不确定性大。
- **[资产负债率仍处高位]** -> [财务杠杆极高]: 资产负债率96.47%，虽较上年下降2.47个百分点，但净资产仅52.65亿元，债务压力巨大。

## 风险警告
**核心风险在于资产负债表的脆弱性与关联方资金占用。** 公司资产负债率高达96.47%，净资产仅52.65亿元，而总负债近1470亿元。一年内到期的非流动负债激增47.48%至182.68亿元，短期偿债压力巨大。同时，应收关联方款项（含其他应收款）超111亿元，关联方还款承诺已多次延期，实际回收进度远低于预期，若关联方经营恶化，将引发大规模信用减值，直接侵蚀本已微薄的净资产。

**盈利高度依赖汇率与油价等外部变量，缺乏内生稳定性。** 2025年扭亏为盈的核心驱动力是15.1亿元的汇兑收益，而非主营业务的强劲增长。公司美元负债敞口巨大，人民币对美元每贬值1%，税前利润将减少约6.47亿元。同时，航油成本占营业成本31.78%，油价每上涨5%，营业成本将增加10亿元。汇率与油价的任何不利波动，都可能使公司迅速重返亏损。母公司累计未弥补亏损高达558亿元，长期不具备分红能力。
