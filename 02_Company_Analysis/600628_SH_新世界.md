# 600628.SH 深度透视

## 因果逻辑链
- **宏观促消费政策及商圈活动联动** -> 百货客流增长3%至1500万人次: 公司积极对接市、区促消费活动，与会展、赛会、旅行社联动，直接拉动客流增长。
- **内容营销驱动与销售冠军品牌数量增加** -> 百货商场竞争优势提升: 通过营销活动产生54家“销售冠军”品牌，体现商场对品牌的吸引力和销售能力。
- **新媒体布局与直播创新** -> 私域流量转化及互动增长: 构建“品牌曝光-用户互动-场景转化”链路，新媒体营销成为新亮点，实现流量转化。
- **境外消费服务优化及免签政策刺激** -> 退税销售大幅增长75.67%: 提供“即买即退”及多语种服务，境外顾客消费成为新亮点，退税笔数增加。
- **免签政策及入境旅游回暖** -> 酒店境外客户占比超75%，客房营收同比增长15%: 入境旅游回暖及免签政策吸引境外客源，导致酒店入住率和房价提升。
- **徐重道饮片基地建设稳步推进** -> 未来医药板块核心竞争力提升: 以“智慧工厂”为目标，打造现代化饮片生产基地，为2026年投产奠定基础。
- **中药饮片集采政策影响** -> 医药销售营业收入减少2.93%: 集采挤压价格，导致医药销售收入略有下降。
- **百货零售市场供给过剩、同质化竞争加剧** -> 百货商场营业收入减少6.32%: 商业供给过剩，竞争激烈，导致百货收入下滑。
- **信用卡及货款回款金额减少，政府补助减少** -> 经营活动现金流量净额下降47.22%: 回款减少和政府补助减少直接导致现金流下降。
- **结构性存款持有规模下降及累计赎回小于购买** -> 投资活动现金流量净额大幅下降694.74%: 结构性存款操作导致投资活动现金流出增加。

## 风险警告
公司整体营收受百货零售业和医药业双板块下滑拖累，其中百货面临供给过剩与同质化竞争，医药受中药集采价格挤压。经营现金流大幅下降，且投资活动现金流因结构性存款操作出现大幅流出，需关注流动性管理。酒店虽表现亮眼但规模有限，难以完全对冲主业下滑。
