# 603237.SH 深度透视

## 因果逻辑链
- **[粽类产品结构升级与高端化]** -> [营收基本持平]: 通过有机粽、大师系列等高端产品提升价值，抵消了销量波动，但成本上升导致毛利率下降4.38个百分点。
- **[月饼业务自产替代委外]** -> [毛利率逆势增长4.37%]: 嘉兴烘焙车间投产，实现自主生产，成本结构优化，叠加健康化差异化产品（轻甜米月饼）提升溢价。
- **[大客户代工与渠道定制]** -> [新业务增长点]: 深化与山姆、人民大会堂等头部客户合作，落地高价值礼盒项目，实现可观盈利并提升供应链服务能力。
- **[餐饮门店“粽子餐饮化”创新]** -> [餐饮品类销售额增长11.71%]: 推出脆皮炸粽、芝士焗粽等新吃法，拓宽消费场景，带动餐饮销售显著增长。
- **[渠道结构调整与经销商优化]** -> [经销商数量减少14.8%]: 对经销商做减法、质量做加法，强化渠道管理，导致经销商渠道收入下降4.20%，但商超渠道收入增长14.46%。
- **[成都基地投产与产能提升]** -> [粽子产能提升31%]: 成都基地募投项目竣工投产，当年粽子产能提升至9200万只，并通过工艺改进实现生产端有效降本。
- **[食品安全管理提升至战略高度]** -> [构建核心竞争力基石]: 重塑管理体系，引入数字化追溯，建立全链条品控能力，修复并强化品牌信任。

## 风险警告
五芳斋面临的核心风险在于**高度依赖节令消费的季节性波动**。公司营收与利润高度集中于端午节和中秋节前后，导致季度业绩剧烈波动（Q2净利润2.4亿，Q4亏损0.53亿）。一旦节令消费不及预期或出现突发事件，将对全年业绩造成重大冲击。同时，**粽类产品毛利率下降4.38个百分点**，显示成本压力正在侵蚀核心品类的盈利能力，而原材料（糯米、猪肉）价格波动风险持续存在。

此外，**品牌被仿冒与市场竞争加剧**是长期威胁。作为“中华老字号”，五芳斋在粽子细分领域是绝对龙头，但行业竞争激烈，消费趋势向“极致质价比”分化。若公司不能持续通过产品创新和品牌建设维持溢价能力，或渠道变革（如经销商数量减少）导致市场份额流失，将面临盈利能力进一步下滑的风险。**2025年扣非净利润同比下降20.61%**，已敲响警钟。
