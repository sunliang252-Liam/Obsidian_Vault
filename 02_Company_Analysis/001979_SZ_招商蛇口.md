# 001979.SZ 深度透视

## 因果逻辑链
- **[开发业务结转规模大幅下降]** -> [营收同比-13.53%]: 2025年结转面积同比-24.42%，直接导致开发业务收入同比-16.33%，拖累整体营收。
- **[投资收益同比减少]** -> [归母净利润同比-74.65%]: 非经常性损益中的资产处置收益及金融资产公允价值变动收益大幅缩水，叠加主业利润下滑，导致净利润骤降。
- **[销售回款减少 + 购地支出增加]** -> [经营现金流净额同比-69.67%]: 签约销售面积同比-23.48%导致回款减少，同时新增土储支出增加，双重挤压经营性现金流。
- **[聚焦核心城市、以销定投]** -> [销售排名升至行业第四]: 精准投资策略下，一线城市投资占比达63%，核心10城贡献近90%投资，支撑销售规模与市占率。
- **[存量永续债全面清零 + 优化债务结构]** -> [综合资金成本降至2.74%]: 完成120亿永续债偿还，并落地141亿经营性物业贷，融资结构优化推动成本同比下降25BP。
- **[REITs扩募打通“投融建管退”]** -> [资产运营收入同比+2.2%]: 博时蛇口产园REIT扩募推进，为持有物业提供资本退出通道，支撑集中商业、公寓等业态收入增长。
- **[“好房子”技术体系落地]** -> [产品力排名升至行业第四]: 7大维度、485项技术细节的标准化体系在20余个标杆项目落地，提升去化率与品牌溢价。
- **[物业服务外延式扩张]** -> [招商积余营收同比+12.23%]: 第三方新签合同额同比+13%，非住宅业态（航空、高校、IFM）及市场化住宅业务均实现高速增长。

## 风险警告
**核心风险在于开发业务利润率的持续恶化与资产减值的潜在压力。** 2025年开发业务毛利率仅15.33%，且同比下降0.25个百分点，在行业深度调整、房价承压的背景下，存量项目结转利润空间被进一步压缩。同时，公司存货规模高达3623亿元，占总资产43.37%，若市场持续低迷，存货跌价准备计提将直接侵蚀利润。

**第二重风险来自现金流与债务结构的脆弱平衡。** 尽管“三道红线”保持绿档，但经营现金流净额同比骤降近70%至96.9亿元，而短期债务（含一年内到期非流动负债）合计达618.8亿元，现金短债比仅1.19，安全边际较薄。此外，公司为购房客户提供的按揭担保余额高达262.46亿元，若市场下行导致断供率上升，将触发或有负债风险。
