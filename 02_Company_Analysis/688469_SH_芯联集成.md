# 688469.SH 深度透视

## 因果逻辑链
- **[一站式系统代工模式]** -> [营收高增25.67%]: 公司整合设计、晶圆制造、模组封装等环节，深度绑定客户，推动营收达81.80亿元。
- **[碳化硅（SiC）业务放量]** -> [毛利率提升至5.51%]: 高附加值SiC MOSFET芯片及模组进入规模量产，优化产品结构，带动毛利率同比提升4.48个百分点。
- **[产能利用率提升与规模效应]** -> [归母净利润大幅减亏38.17%]: 晶圆年产量增长24.68%，固定成本（折旧）被有效摊薄，亏损收窄至-5.95亿元。
- **[车载领域为核心增长引擎]** -> [收入结构稳定]: 车规级产品渗透国内90%以上新能源车企，贡献45.43%营收，是公司收入的核心支柱。
- **[AI领域布局初见成效]** -> [开辟第二增长曲线]: AI服务器电源、数据中心光通信等产品导入客户，AI领域收入占比快速提升至8.02%。
- **[高额研发投入]** -> [技术壁垒持续巩固]: 研发投入占营收23.76%，在SiC、BCD、MCU等关键平台取得突破，维持国内领先地位。
- **[并购整合芯联越州]** -> [强化协同效应]: 实现对子公司全资控股，整合8英寸硅基与碳化硅产能，提升运营效率与核心竞争力。

## 风险警告
**核心风险在于持续亏损与高资本开支的剪刀差。** 公司虽大幅减亏，但归母净利润仍为-5.95亿元，且经营活动现金流净额（21.35亿元）远低于投资活动现金流出（-50.06亿元），表明公司仍处于“烧钱换增长”阶段，对持续融资依赖度极高。若下游需求或融资环境恶化，现金流断裂风险不可忽视。

**技术迭代与市场竞争风险同样严峻。** 半导体行业技术路线变化快，公司虽在SiC领域领先，但面临国际巨头（如英飞凌、意法半导体）和国内同行的激烈竞争。若下一代产品（如8英寸SiC、沟槽栅SiC）研发或量产不及预期，可能导致市场份额被侵蚀，前期巨额投入无法收回。
