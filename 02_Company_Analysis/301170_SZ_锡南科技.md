# 301170.SZ 深度透视

## 因果逻辑链
- **[全球涡轮增压渗透率提升+公司产能扩张]** -> [营收增长5.37%]: 公司作为涡轮增压器压气机壳全球主要供应商，受益于汽车节能减排趋势，2025年销量926.45万件，同比增长4.42%，带动营收增至11.23亿元。
- **[产品结构优化与海外高毛利业务扩张]** -> [毛利率提升]: 国外销售毛利率25.95%，远高于国内11.85%，且国外销售占比提升至49.69%，拉动整体毛利率同比上升0.42个百分点。
- **[原材料成本控制与规模效应]** -> [扣非净利润基本持平]: 尽管营收增长，但直接材料与人工成本同步上升，叠加运输仓储费大增35.24%，导致扣非净利润仅微降0.07%，盈利能力承压。
- **[人民币升值导致汇兑损失]** -> [财务费用大幅增加]: 财务费用从-883万元增至-242万元，同比增加72.59%，侵蚀利润，是净利润下滑7.58%的核心原因之一。
- **[非经常性损益减少]** -> [净利润下滑7.58%]: 2025年非经常性损益898万元，较2024年的1724万元大幅减少，主要系政府补助及金融资产公允价值变动收益下降，导致归母净利润降至1.01亿元。
- **[泰国工厂与电力系统新业务投资]** -> [投资活动现金流大幅流出]: 公司投资6800万美元建设泰国工厂及无锡电力系统工厂，在建工程从350万激增至1.49亿，导致投资活动净现金流由正转负，为-2.56亿元。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比高达87.65%，其中第一大客户占比37.66%，公司对核心客户依赖度极高，议价能力受限，存在订单波动风险。

## 风险警告
**核心风险在于客户与业务的“双集中”困境。** 公司87.65%的收入来自前五大客户，且产品高度集中于涡轮增压器压气机壳（占营收87.81%）。这种结构使公司业绩与全球汽车燃油车及混动市场景气度深度绑定。随着新能源汽车渗透率持续攀升，纯电车型对涡轮增压器的需求为零，公司面临长期赛道萎缩的威胁。尽管公司已布局新能源电机壳体、电力系统零部件，但2025年非压气机壳收入仅占0.99%，转型尚处萌芽期，新业务放量存在巨大不确定性。

**财务层面，盈利质量与资本开支存在显著矛盾。** 公司净利润下滑7.58%，扣非净利润原地踏步，而投资活动现金净流出高达2.56亿元，主要用于泰国和电力系统工厂建设。这意味着公司正以牺牲短期现金流和利润为代价进行战略扩张。若新工厂产能爬坡不及预期，或海外市场开拓受地缘政治影响受阻，高额的资本开支将转化为沉重的折旧与摊销压力，进一步拖累净资产收益率（已从7.75%降至5.75%）。此外，人民币汇率波动导致的汇兑损失已成为常态化的利润侵蚀因素。
