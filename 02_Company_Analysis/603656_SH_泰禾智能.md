# 603656.SH 深度透视

## 因果逻辑链
- **[收购阳光优储，切入储能赛道]** -> [营收增长9.27%]: 2025年6月收购阳光优储，新增储能服务收入4088.65万元，直接拉动总营收增长。
- **[海外市场高增长]** -> [境外营收增长27.23%]: 海外市场毛利率高达50.89%，境外收入占比提升至44.9%，成为利润增长的核心引擎。
- **[销售费用管控见效]** -> [扣非净利润暴增183%]: 销售费用同比下降11.87%，叠加营收增长，使扣非净利润从842万跃升至2383万。
- **[原实控人业绩承诺兜底]** -> [主业利润稳定]: 原实控人许大红承诺现有业务2024-2026年每年净利润不低于2000万元，2025年实际完成2439.91万元，为转型期提供安全垫。
- **[研发费用缩减]** -> [短期利润增厚]: 研发费用同比下降19.4%至4578万元，占营收比降至7.43%，直接贡献了利润弹性。
- **[阳光优储并表]** -> [资产结构重型化]: 合并阳光优储带来储能电站等固定资产，总资产增长26.5%，固定资产暴增91.19%，公司从轻资产转向重资产运营。
- **[募投项目变更]** -> [战略重心转移]: 终止“智能煤炭干选机产业化项目”，将剩余2.2亿募集资金转向“120MW/240MWh用户侧储能项目”，彻底拥抱新能源。

## 风险警告
**储能业务依赖电价政策，盈利模式脆弱。** 公司新收购的阳光优储主营工商业用户侧储能，其经济性高度依赖峰谷电价差。一旦电力市场化改革导致价差收窄，或地方政府调整分时电价政策，储能项目的投资回报率将急剧恶化。公司为此支付了4580万元对价并承担了业绩承诺（4年累计扣非净利不低于1800万），若政策转向，将面临商誉减值与业绩补偿的双重打击。

**主业增长乏力，新业务尚未证明盈利能力。** 剔除储能业务后，公司传统智能分选装备收入仅增长2.84%，智能包装装备收入甚至下滑4.84%。核心子公司卓海智能（煤炭干选机）连续亏损，2025年净亏损2648万元，导致公司不得不终止其募投项目。储能业务虽贡献营收，但毛利率38.17%低于传统分选业务，且高度依赖关联方阳光电源的设备采购与运维，独立盈利能力存疑。
