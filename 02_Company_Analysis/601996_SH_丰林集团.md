# 601996.SH 深度透视

## 因果逻辑链
- **[行业供需失衡]** -> [净利润亏损1.28亿元]: 刨花板产能过剩叠加下游需求疲软，产品价格承压，导致公司连续第二年亏损。
- **[刨花板业务拖累]** -> [刨花板毛利率-7.02%]: 刨花板产能阶段性投资过热，供需失衡加剧，产品售价无法覆盖成本，成为亏损主因。
- **[“以销定产”策略]** -> [经营性现金流净额3.17亿元]: 公司主动压缩产量、优化库存管理，存货资金占用大幅减少，实现经营性现金流转正。
- **[海外市场拓展]** -> [对冲国内需求下滑]: 公司战略性出海，通过外贸合作拓展东南亚、中东市场，优化客户结构，降低对单一市场的依赖。
- **[环保标准升级]** -> [结构性机遇]: GB18580-2025新国标将E0级设为强制门槛，加速落后产能出清，公司凭借无醛添加技术先发优势，有望在行业洗牌中受益。
- **[平陆运河通航]** -> [物流成本下降]: 2026年底平陆运河通航将大幅缩短广西基地至北部湾港的运输距离，降低物流成本，强化对东盟市场的渗透能力。
- **[AI赋能降本]** -> [运营效率提升]: 公司通过AI智能体优化采购、生产、销售全流程，实现木柴采购自动结算、生产消耗精准核算，有效控制成本。

## 风险警告
**核心风险在于行业供需失衡的持续恶化。** 刨花板产能过剩是公司连续两年亏损的直接原因，且短期内难以缓解。2025年刨花板产量同比增长12.6%，而下游需求疲软，库存压力攀升，产品价格面临持续下行压力。公司虽通过“以销定产”策略改善现金流，但若行业供需格局无法逆转，盈利改善将缺乏根本支撑。

**第二重风险来自成本端的双重挤压。** 一方面，天然林禁伐政策导致国内木材供应趋紧，原料价格易涨难跌；另一方面，2026年新国标实施将推动全行业环保升级，上游化工原料（如无醛胶黏剂）需求增加，可能进一步推高采购成本。公司虽具备环保先发优势，但成本控制仍面临阶段性压力。此外，国际贸易保护主义抬头，反倾销税及技术性贸易措施可能阻碍海外市场拓展节奏。
