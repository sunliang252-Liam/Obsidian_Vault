# 300435.SZ 深度透视

## 因果逻辑链
- **[海外订单爆发式增长]** -> [深冷设备板块利润大幅增长99%]: 公司海外订单连续三年创历史新高，中亚、中东、北美等地区订单进入交付周期，带动设备板块营收增长21.69%，毛利率提升17.73个百分点。
- **[核心制造能力突破]** -> [产能利用率持续提升]: 全球领先的大型真空钎焊炉投产，突破超大尺寸、超高压换热器制造瓶颈，为承接国内外大型项目提供产能保障。
- **[技术壁垒与业绩壁垒]** -> [高端客户粘性增强]: 公司板翅式换热器已出口54国，为法液空、空气化工、沙特阿美等国际巨头供货，新领域（航天液氧过冷器、氦提纯装置）持续突破。
- **[城燃板块需求企稳]** -> [燃气运营利润小幅下滑3.77%]: 民用气价格倒挂有所缓解，但下游工业需求不振导致用气量下滑，营收下降15.86%，利润仅微降。
- **[商誉减值风险释放]** -> [净利润同比扭亏为盈]: 2024年计提商誉减值3.24亿元导致巨亏，2025年无新增大额减值，叠加主业利润大增，归母净利润从-0.78亿跃升至4.50亿。
- **[设备销售毛利率大幅提升]** -> [成本控制与订单结构优化]: 设备销售毛利率从32.12%提升至49.86%，主要得益于高毛利海外订单占比提升及原材料成本管控。
- **[经营活动现金流净额增长50%]** -> [设备销售回款改善]: 设备板块经营净流入增加，现金流质量显著优于净利润增速，显示盈利质量扎实。

## 风险警告
**核心风险在于城燃板块的持续拖累与商誉减值隐患。** 山东中邑燃气2025年净利润仅4807万元，同比下滑3.77%，营收更是下降15.86%。上游天然气采购价格受国际油气联动影响，下游销售价格受物价局调控难以实时顺价，利润空间持续承压。目前商誉账面价值仍有1.25亿元，若未来下游需求持续萎靡或顺价机制不畅，存在继续计提减值风险，将直接侵蚀利润。

**海外业务扩张带来的地缘政治与汇率风险不容忽视。** 截至2026年3月底，公司在手订单中海外占比已超40%，且新签订单连续三年创新高。但中东冲突、俄乌战争等地缘政治不确定性，可能影响订单交付、物流及收付款。同时，人民币汇率波动将直接造成利润波动，公司未披露有效对冲手段。此外，应收账款余额7.73亿元中，账龄超过一年的占比高达54.84%，回收风险需持续关注。
