# 300907.SZ 深度透视

## 因果逻辑链
- **美国“对等关税”及行业竞争加剧** -> **营收下滑10.68%**: 全球供应链波动与终端品牌商优化库存，导致公司订单减少。
- **营收下滑叠加汇兑损失** -> **归母净利润暴跌43.77%**: 收入下降直接侵蚀利润，同时美元兑人民币走弱导致财务费用激增472.93%。
- **并购凌臣采集** -> **资产总额暴增63.03%**: 非同一控制下合并带来约1.51亿元商誉及大量资产，但仅于12月31日并表，对当年业绩贡献极小。
- **越南及韩国生产基地布局完成** -> **境外营收占比超50%**: 国际化布局有效对冲了部分关税风险，但未能完全抵消需求下滑。
- **客户高度集中** -> **经营风险集中**: 前五大客户销售占比84.26%，其中百得集团一家占比55.26%，公司议价能力受限，业绩高度依赖大客户。
- **铜价持续走高** -> **毛利率承压**: 主要原材料铜价上涨，而公司未能完全向下游传导成本，导致电动工具整机毛利率同比下降4.43个百分点。
- **成功开拓LIDL等整机客户** -> **整机业务基本盘扩大**: 整机研产销能力成熟，为未来增长奠定基础，但短期内未能弥补传统电机业务的收入缺口。

## 风险警告
**核心风险在于业绩的剧烈下滑与高额商誉的“双杀”隐患。** 2025年营收和净利润分别下降10.68%和43.77%，盈利能力显著恶化。更关键的是，公司为收购凌臣采集形成了高达1.51亿元的商誉，占净资产的19%。若未来工控行业竞争加剧或整合不及预期，将面临巨大的商誉减值风险，直接冲击当期利润。

**公司经营高度依赖少数大客户和海外市场，抗风险能力脆弱。** 前五大客户贡献超84%的收入，尤其是对百得集团的依赖度超过55%，任何客户订单的波动都将对公司业绩产生颠覆性影响。同时，90%以上的收入来自海外，美元汇率、美国“对等关税”等国际贸易政策的不确定性，将持续对公司利润造成扰动。
