# 920075.BJ 深度透视

## 因果逻辑链
- **[内需消费疲软]** -> [营收下降12.99%]: 下游酒类、化妆品客户新品投放放缓，导致产品包装与设计业务收入分别同比减少14.50%和35.22%。
- **[外销业务高增长]** -> [营收结构优化]: 外销收入同比增长18.16%，占比提升至40.72%，部分对冲内销下滑26.33%的冲击，成为公司核心增长引擎。
- **[惠州工厂产能爬坡与折旧]** -> [利润大幅下滑47.42%]: 惠州募投项目2024年7月转固，新增折旧与利息费用合计约463万元，叠加内销收入下降，导致净利润从4123万骤降至2168万。
- **[信用减值损失大幅减少]** -> [利润减亏]: 公司加强应收账款管理，信用减值损失从-1390万收窄至+89万，同比改善1479万元，是利润降幅小于营收降幅的关键原因。
- **[文创业务从0到1]** -> [第二增长曲线初现]: 龙衍文创推出“独眼星球”AI毛绒玩具及NIDOO盲盒，实现营收31.55万元，虽体量极小，但标志着公司从B端向C端创意消费场景的战略延伸。
- **[海外子公司设立]** -> [全球化布局加速]: 报告期内新设香港、新加坡、意大利子公司，旨在搭建本地化销售服务中心，提升海外市场响应速度与本土化服务能力。
- **[其他业务收入暴增]** -> [服务模式延伸]: 因外销客户对出口货运服务需求增加，其他业务收入同比增长429.53%至1958万元，显示公司正从单一包装交付向综合供应链服务拓展。

## 风险警告
**核心风险在于内需持续低迷与产能扩张的错配。** 公司内销收入同比下降26.33%，而惠州工厂的固定资产折旧与借款利息已成为刚性成本，导致利润对收入波动的弹性极低。若下游酒类、化妆品消费持续疲软，公司可能面临“增收不增利”甚至亏损的风险。此外，短期借款从0激增至2011万元，财务费用同比暴增1280%，债务压力正在快速累积。

**新业务与海外布局尚处培育期，短期难以贡献利润。** 文创潮玩业务（龙衍文创）及香港、新加坡、意大利子公司均处于初创阶段，报告期内合计亏损约87万元。这些业务需要持续的资本投入与市场验证，若商业化不及预期，将拖累公司整体盈利能力。同时，外销业务占比提升也放大了汇率波动风险，报告期已产生141.51万元汇兑损失。
