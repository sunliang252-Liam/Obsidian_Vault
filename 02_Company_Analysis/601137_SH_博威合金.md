# 601137.SH 深度透视

## 因果逻辑链
- **[美国对越南光伏产品征收307.78%高额双反关税]** -> [新能源业务崩溃]: 越南3GW电池片产线试产后无法销往美国市场，导致该业务板块销量同比下降13.04%，净利润同比减少142.42%。
- **[美国《大而美法案》限制中国实体持股及经营权]** -> [美国子公司资产减值与被迫出售]: 公司美国子公司无法享受行业同等联邦政策，被迫计提在建工程、存货等资产减值准备，并启动资产出售程序。
- **[新能源业务巨额资产减值与合同损失]** -> [归母净利润暴跌90.77%]: 报告期内计提资产减值损失10.28亿元，导致归母净利润从13.54亿元骤降至1.25亿元。
- **[数字化与AI赋能新材料业务]** -> [新材料业务逆势增长]: 通过AI多智能体系统优化研发、制造和营销，新材料业务销量同比增长7.39%，净利润同比增长18.02%。
- **[铜价上涨及销量增长]** -> [营运资金大幅占用]: 原材料价格上涨及销量增加导致流动资金占用及期货保证金增加，经营活动现金流净额由正转负，为-8.87亿元。
- **[战略收缩新能源，聚焦新材料]** -> [公司战略重心转移]: 鉴于国际贸易政策剧变，公司战略调整为“新材料为核心、新能源收缩”，并计划将3万吨带材募投项目从中国迁至摩洛哥。

## 风险警告
**核心风险在于新能源业务的地缘政治“黑天鹅”事件已造成毁灭性打击。** 美国对越南征收的307.78%高额双反关税，以及《大而美法案》对中国实体的限制，直接导致公司越南和美国两大新能源基地的资产价值归零。报告期内计提的10.28亿元资产减值损失仅是开始，后续美国子公司的股权出售价格、越南产线剩余资产的处置，以及潜在的合同违约诉讼，都可能带来进一步的财务冲击。公司新能源业务已从利润支柱变为巨额亏损黑洞，其恢复前景完全取决于地缘政治博弈，具有极高不确定性。

**第二大风险来自新材料业务扩张的海外执行风险。** 公司将核心募投项目“3万吨带材项目”从中国迁至摩洛哥，虽然规避了贸易壁垒，但摩洛哥在基础设施、产业链配套、文化融合及管理效率方面均存在显著挑战。项目投产时间已延期至2028年底，期间可能面临建设成本超支、产能爬坡缓慢、当地政策变动等风险。若海外基地无法顺利达产并实现盈利，公司将失去核心增长引擎，同时面临巨大的资本开支压力。
