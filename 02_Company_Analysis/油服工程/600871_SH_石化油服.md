# 600871.SH 深度透视

## 因果逻辑链
- **[新签合同额创历史新高]** -> [营收微降0.5%]: 新签合同额956亿元（+4.8%），但收入端受上游资本开支优化及部分项目收尾影响，未能完全转化为当期收入。
- **[毛利率提升0.3个百分点]** -> [净利润增长4.3%]: 通过强化科技创新、深化内部资源优化（如劳务输出、优化外委）等措施，在收入下降背景下实现成本降幅（-0.8%）大于收入降幅（-0.5%）。
- **[经营活动现金流大增114.3%]** -> [财务稳健性增强]: 加大应收款项清收及开展供应商反向保理，使销售回款增加、经营付现减少，现金流净额达66.5亿元。
- **[海外市场收入增长10.5%]** -> [业务结构优化]: 海外收入占比提升至25.2%，高附加值业务（如旋转导向、高温测井）收入达8.6亿元，成为利润增长的重要引擎。
- **[难动用储量合作开发]** -> [盘活存量资产]: 合作开发新建产能255.4万吨，盘活105支钻井队，带动钻井进尺235万米，提升了队伍动用率和资产周转效率。
- **[技术自给率提升]** -> [成本控制与竞争力增强]: 高温测井、高温定向等高端仪器内部自给率提升至80.3%，减少对外依赖，降低采购成本，并支撑了高端市场拓展。
- **[资产负债率持续下降]** -> [财务风险降低]: 资产负债率从2021年的89.29%降至2025年的88.01%，连续五年下降，抗风险能力增强。

## 风险警告
**核心风险在于对控股股东中国石化集团的高度依赖与关联交易集中度。** 公司57.3%的收入来自中国石化集团，前五大客户中关联方占比高达64.4%。这种依赖关系虽提供了稳定的业务基本盘，但也限制了公司独立议价能力和市场化拓展空间，一旦集团资本开支收缩或关联交易政策调整，将直接冲击公司营收与利润。

**财务风险集中在高负债率与持续亏损的母公司层面。** 尽管合并报表盈利，但母公司未分配利润仍为-18.1亿元，导致连续多年无法进行现金分红。公司资产负债率高达88%，有息债务规模庞大（短期借款283亿元），财务费用因汇兑损失同比大增21%，对利润形成持续侵蚀。高杠杆运营下，利率或汇率波动将显著放大盈利波动性。
