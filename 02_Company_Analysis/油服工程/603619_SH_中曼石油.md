# 603619.SH 深度透视

## 因果逻辑链
- **[国际油价全年均价下跌约15%]** -> [净利润同比下滑29.8%]: 布伦特原油均价从约80美元/桶跌至68美元/桶，直接压缩了公司核心的勘探开发业务利润空间。
- **[坚戈油田产量同比大增35.3%]** -> [油气总产量创历史新高（112.39万吨油当量）]: 哈萨克斯坦坚戈项目进入开发提速阶段，通过优化开采方案实现产量跃升，部分对冲了油价下跌影响。
- **[勘探开发毛利率下降7.13个百分点]** -> [整体毛利率下滑1.81个百分点]: 油价下跌叠加油气资产折耗成本（同比+48.63%）和油田作业成本上升，导致核心业务盈利能力显著削弱。
- **[钻完井工程板块收入同比增长8.44%]** -> [工程服务毛利率提升6.94个百分点]: 海外高端市场（如伊拉克大包井）技术突破与效率提升，带动业务量价齐升，成为利润的重要稳定器。
- **[财务费用同比减少46.09%]** -> [净利润降幅小于毛利降幅]: 主要因汇兑损益减少，有效缓解了油价下跌对利润表的冲击。
- **[营业外支出同比暴增624.94%]** -> [非经常性损益拖累净利润]: 报告期内计提大额诉讼赔偿，导致非经常性损益由正转负，进一步放大了利润下滑幅度。
- **[收购昕华夏迪拜49%股权]** -> [间接持有坚戈区块100%权益]: 公司以约7932万美元完成对坚戈油田少数股权的收购，强化了对核心海外资产的掌控力，为未来产量增长扫清障碍。

## 风险警告
**核心风险在于油价依赖与成本刚性上涨的矛盾。** 公司2025年净利润对国际油价高度敏感，布伦特原油均价下跌约15%即导致归母净利润下滑近30%。与此同时，勘探开发板块的油气资产折耗成本同比飙升近49%，油田作业成本亦同步上升，显示出在产量增长的同时，单位成本控制面临挑战。若油价持续低迷，公司盈利能力和现金流将承受更大压力。

**海外扩张带来的资本开支与地缘政治风险不容忽视。** 公司正处于伊拉克、阿尔及利亚等高风险地区的大规模投资期，2025年投资活动现金流净流出高达14.67亿元，主要用于海外油田建设。这些项目从投入到产出周期长，且面临资源国政策变动、合同执行及安全局势等不确定性。此外，公司资产负债率较高，受限资产规模庞大（约37.68亿元），财务杠杆的运用在油价下行周期中会放大经营风险。
