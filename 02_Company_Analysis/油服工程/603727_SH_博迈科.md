# 603727.SH 深度透视

## 因果逻辑链
- **[全球FPSO市场高景气]** -> [新签订单创历史新高]: 公司精准把握南美核心区域项目机遇，与MODEC、SBM等头部总包商签署苏里南、圭亚那FPSO上部模块大额合同，合同金额区间达21-27亿元，其中圭亚那项目刷新公司单条FPSO上部模块合同记录。
- **[项目工作量减少]** -> [营收同比下降28%]: 2025年完成的项目工作量减少，导致营业收入从26.4亿元降至19.0亿元，是业绩下滑的直接原因。
- **[成本精细管控]** -> [毛利率逆势提升]: 尽管营收下滑，但海洋油气开发模块业务毛利率同比提升2.86个百分点至19.41%，主要得益于对项目成本的精细化管控。
- **[汇率波动]** -> [财务费用大幅转负]: 财务费用从-191万元降至-5,676万元，主要系汇率波动带来的汇兑收益，对利润形成正面贡献。
- **[合同资产减值计提增加]** -> [资产减值损失扩大]: 资产减值损失从-2,947万元扩大至-10,969万元，主要系计提合同资产减值增加，侵蚀了部分利润。
- **[客户高度集中]** -> [经营依赖单一客户]: 前五名客户销售额占比高达99.68%，其中单一客户Offshore Frontier Solutions Pte. Ltd.占比53.74%，存在严重的客户依赖风险。
- **[能源转型与化石能源博弈]** -> [行业结构性机遇]: 全球能源转型速度不及预期，传统油气投资再现活力，LNG项目密集开展，为模块化建造服务商提供了结构性机遇。
- **[海工产业向中国转移]** -> [竞争格局分化]: 全球海工产业持续向中国转移，国内企业呈现总包转型与分包深耕并行的分化态势，公司坚守分包路线，竞争优势愈发明显。

## 风险警告
**客户集中度极高与订单波动风险。** 公司前五名客户销售额占比高达99.68%，其中单一客户占比超53%，对核心总包商MODEC、SBM存在严重依赖。一旦主要客户需求变化、项目推进缓慢或油价出现重大波动，新签订单可能不及预期，将直接导致公司收入锐减。2025年营收已因项目工作量减少而同比下降28%，印证了订单波动对业绩的直接影响。

**资产减值与汇兑损益的双重不确定性。** 公司2025年计提合同资产减值损失高达1.1亿元，同比扩大272%，显示项目执行过程中存在较大的预算超支或回款风险。同时，公司海外业务以美元结算，财务费用因汇率波动从-191万骤降至-5,676万元，贡献了巨额非经常性收益，但汇率双向波动下，未来可能转为重大损失。这两项因素均具有高度不确定性，可能对利润造成剧烈冲击。
