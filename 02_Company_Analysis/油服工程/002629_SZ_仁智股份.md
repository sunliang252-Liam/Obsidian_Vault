# 002629.SZ 深度透视

## 因果逻辑链
- **公司战略聚焦新能源，抓住光伏储能行业高速发展机遇** -> 新能源电力工程收入同比增长13.51%，占比升至74.89%: 公司顺应行业趋势，优化业务布局，使得新能源业务成为主要收入来源。
- **新能源收入增长但毛利率略降（-0.14个百分点）** -> 整体毛利率仅提升0.60个百分点至14.23%: 新能源业务毛利率微降，拉低了整体毛利率改善幅度。
- **油气田技术服务收入同比下降19.15%，毛利率下降7.24个百分点** -> 石油和天然气开采业板块收入同比降18.41%: 油气田技术服务收入下滑且毛利率大幅下降，导致该行业板块收入减少。
- **新材料及石化产品销售同比剧降75.91%，毛利率仅2.76%** -> 有机化学原料制造行业收入同比降75.91%: 该业务收入大幅萎缩且毛利率极低，直接造成该行业板块收入骤降。
- **低毛利的新材料业务收入占比从16.37%降至4.29%** -> 整体毛利率从13.63%小幅提升至14.23%: 低毛利业务占比下降，结构性变化使得整体毛利率略有上升。
- **管理费用同比增加101.05%** -> 净利润同比下降34.89%: 管理费用大幅上升侵蚀利润，导致净利润显著下滑。
- **应收账款同比增加74.13%至1.36亿元** -> 经营活动现金流量净额为负（-601.84万元）: 收入增长但回款慢，应收账款大幅增加，导致经营现金流为负。
- **应收账款和合同资产合计占总资产72.08%** -> 信用减值损失和资产减值损失合计约253.53万元: 高额的应收账款和合同资产面临坏账和减值风险，导致计提减值损失。
- **公司注销四川清源智创、新设四川安捷绿能** -> 新能源业务持续拓展，收入增长: 通过子公司调整，聚焦新能源业务，推动该板块收入增长。
- **行业政策支持光伏储能，但原材料行业竞争激烈** -> 公司决定逐步减少低毛利新材料产品销售: 面对行业困境，公司主动调整产品结构，收缩低毛利业务。

## 风险警告
公司深度风险：1. 主业依赖新能源单一板块（收入占比74.89%），且该业务毛利率仅15.62%，盈利能力有限；2. 应收账款和合同资产合计占总资产72%，回款风险高，已导致经营现金流为负；3. 管理费用同比翻倍，侵蚀利润；4. 低毛利的新材料和油气田业务持续萎缩，未来需持续投入转型，存在转型不及预期风险。
