# 300164.SZ 深度透视

## 因果逻辑链
- **油价下行与行业竞争加剧** -> **归母净利润同比下滑34.19%**: 2025年布伦特原油价格从79美元/桶跌至63美元/桶，油公司放缓钻探活动，压裂车组数量同比减少47部，导致射孔业务竞争加剧、盈利承压。
- **北美业务聚焦大客户与深化合作** -> **北美收入保持稳定（8.72亿元）**: 美国子公司将产能向雪佛龙等核心客户倾斜，并与压裂公司联合开拓市场，对冲了行业景气度回落的影响。
- **天然气回收处理业务规模扩张** -> **战略业务增长与海外市场突破**: 国内累计投产14口井，并成功中标阿尔及利亚1.26亿美元EPF和天然气压缩机项目，为未来业绩增长奠定基础。
- **CCUS业务高速增长** -> **第二增长曲线初现**: 二氧化碳注入量同比增长168%至31.8万吨，业务规模稳步提升，成为公司新的增长点。
- **强化现金流管理** -> **经营现金流净额达净利润3.76倍**: 通过加强回款、去库存等方式，实现经营活动现金流净额1.38亿元，同比增长11.63%，现金流韧性显著增强。
- **降本控费措施落地** -> **费用管控与采购优化**: 严控非必要支出、优化供应商管理、推进库存复用，有效对冲了收入下滑对利润的侵蚀。
- **一龙恒业业绩补偿股权入账** -> **非经常性损益大幅增厚利润**: 因原股东未完成业绩承诺，公司通过强制执行获得一龙恒业14.55%股权，确认营业外收入约2,850.75万元，是归母净利润的主要来源。

## 风险警告
**核心风险在于主业盈利能力的持续恶化。** 公司2025年扣非净利润仅1,246万元，同比暴跌72.68%，显示在油价低迷、行业竞争加剧的背景下，射孔主业已进入微利甚至盈亏平衡边缘。北美市场虽通过聚焦大客户稳住收入，但毛利率同比下降3.12个百分点；国内市场收入下滑15.87%，两大核心业务均面临量价齐跌的压力。若油价持续低位运行，公司主业可能陷入亏损。

**另一重大风险来自海外新项目的执行不确定性。** 阿尔及利亚1.26亿美元合同尚未正式签署，且项目周期长达4年，面临地缘政治、业主筹资、项目管理等多重挑战。同时，公司因一龙恒业业绩补偿确认了约3,286万元的预计负债（可能需返还部分股权），且商誉账面价值仍高达1.98亿元，若被并购企业经营恶化，存在减值风险。公司未分配利润为-5.7亿元，长期无法分红，股东回报能力严重受限。
