# 600971.SH 深度透视

## 因果逻辑链
- **[煤炭价格大幅下跌]** -> [公司出现近10年来首次亏损]: 煤炭综合售价同比下降22.04%（191.68元/吨），导致营业收入下降20.65%，归母净利润由盈转亏至-1.92亿元。
- **[新能源替代加速与房地产基建走弱]** -> [煤炭需求端承压]: 火电发电量首次负增长，钢铁、建材用煤需求大幅下滑，仅化工用煤增长，但体量不足以对冲整体需求疲软。
- **[收购张掖宏能煤业及昌盛能源]** -> [资产规模与负债大幅扩张]: 总资产增长26.59%至259.95亿元，同时长期借款增长422.71%，长期应付款增长139.25%，财务杠杆显著提升。
- **[新增采矿权摊销及弃置费用摊销]** -> [管理费用与财务费用激增]: 管理费用增长12.22%，财务费用由负转正至1.31亿元（同比增加1.45亿元），直接侵蚀利润。
- **[产销量增加但价格下跌]** -> [量价背离导致毛利骤降]: 商品煤销量同比增加1.81%，但收入减少20.63%，煤炭毛利率从37.26%骤降至19.72%，减少17.54个百分点。
- **[非同一控制下企业合并]** -> [固定资产与无形资产大幅增加]: 固定资产增长109.69%，无形资产增长53.57%，主要系收购子公司带来的资产并入。
- **[计提资产减值与信用减值]** -> [进一步拖累利润]: 资产减值损失8993万元，信用减值损失1261万元，合计超1亿元，加剧了亏损幅度。

## 风险警告
**核心风险在于煤炭价格持续低迷与高杠杆扩张的叠加效应。** 公司2025年出现近10年首次亏损，直接原因是煤炭综合售价同比暴跌22%。在新能源替代加速、火电需求下滑、钢铁建材行业疲软的大背景下，煤炭行业已进入“温和微利”阶段，价格中枢难以回到此前高位。公司对煤价高度敏感，一旦价格继续承压，盈利能力将面临严峻考验。

**财务风险急剧上升。** 公司为收购宏能煤业等资产，大幅举债，导致长期借款激增422%，长期应付款增长139%，财务费用由负转正至1.31亿元。同时，新增采矿权摊销和弃置费用摊销将持续推高管理费用。在利润为负的情况下，高额的固定成本与利息支出将形成巨大的财务压力，可能进一步侵蚀现金流，甚至影响分红能力。
