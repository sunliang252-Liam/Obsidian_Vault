# 600830.SH 深度透视

## 因果逻辑链
- **[融资租赁业务规模高速扩张]** -> [营收与利润双增]: 新增投放超29亿元（+46%），期末应收融资租赁款41亿元（+45%），驱动总营收增长15.28%，归母净利润增长51.03%。
- **[会计估计变更，提高减值计提比例]** -> [信用减值损失增加，但资产质量指标改善]: 主动提高正常及关注类资产拨备率，导致信用减值损失达4275万元，但整体不良率、逾期率同比下降，风险抵补能力增强。
- **[担保业务受基建与地产下行冲击]** -> [收入骤降，成为业绩拖累]: 传统工程保函业务发生额同比-86%，收入占比骤降至不足1%，迫使公司寻求新业务场景转型。
- **[典当业务结构调整]** -> [收入微降，但资产结构优化]: 房产典当收缩（-18%），大额财产权利典当扩张（+1.5倍），占比升至55%，业务韧性增强，但综合费率持续下行。
- **[特殊资产业务遇上行压力]** -> [收入同比下降29.86%]: 受市场供给与处置周期影响，期末账面余额同比下降9.87%，公司转向“服务赋能、风险共担”的合作模式。
- **[贸易业务“第二曲线”分化]** -> [酒类承压，水类增长]: 酒类收入-25%，受行业调整与价格倒挂影响；水类收入+48%，受益于渠道扩张与OEM代工，但整体利润贡献仍小。
- **[融资租赁保理融资规模同步扩张]** -> [财务杠杆与流动性风险上升]: 为支撑租赁业务扩张，保理融资借款大幅增加，导致筹资活动现金流净额8.87亿元，资产负债率升至52.17%。

## 风险警告
**核心风险在于融资租赁业务的信用风险与流动性风险的共振。** 公司生息资产规模达48.91亿元，其中融资租赁占比超80%，且区域集中于山东、安徽等省份（占比超65%），客户以大中型国企为主。在化债政策与城投平台转型背景下，若特定区域或行业信用风险集中暴露，将直接冲击资产质量。同时，公司为支撑业务扩张，大量依赖保理融资（期末保理借款余额超29亿元），资产与负债期限错配，经营活动现金流净额为-10.07亿元，流动性高度依赖再融资，一旦融资环境收紧，可能引发偿付压力。

**存量不良资产清收与股权投资减值风险不容忽视。** 报告期末，公司仍有大量历史遗留的诉讼与仲裁案件，债权本金余额合计超3.5亿元，减值准备余额2.87亿元，清收进展缓慢。此外，公司参与的多个私募股权基金（如珠海千意汇桐、杭州昶链麦迪森）底层项目经营不及预期，已出现公允价值损失，部分基金面临全额退出困难，未来可能继续侵蚀利润。
