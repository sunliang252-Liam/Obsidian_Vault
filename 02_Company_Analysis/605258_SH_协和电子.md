# 605258.SH 深度透视

## 因果逻辑链
- **[下游汽车电子与高频通讯需求增长]** -> [营收增长10.4%]: 受益于新能源汽车渗透率提升及5G基站建设，公司核心赛道订单稳定增长，带动PCB销量同比+5.3%。
- **[市场竞争激烈与原材料成本上升]** -> [毛利率下降1.84个百分点]: 覆铜板等主要原材料价格波动及行业价格战，导致主营业务成本增速（+12.58%）超过收入增速（+10.10%），侵蚀利润空间。
- **[研发投入持续加大]** -> [研发费用同比+22.99%]: 公司为巩固技术优势，加大高端PCB及SMT工艺研发，费用增长快于营收，短期压制净利润。
- **[营收增长与销售回款改善]** -> [经营性现金流净额同比+34.37%]: 收入规模扩大带动销售商品收到的现金增加，现金流质量显著优于净利润表现。
- **[高比例现金分红]** -> [筹资活动现金流净流出扩大]: 2025年派发2024年度现金红利6160万元（占归母净利润86.43%），叠加借款偿还，导致筹资现金流净额-6307万元。
- **[新设香港子公司与注销南京子公司]** -> [优化全球布局与精简架构]: 设立香港子公司拓展海外业务，同时注销南京子公司以整合资源，反映公司战略聚焦与效率提升。
- **[控股子公司协创智联持续亏损]** -> [拖累合并净利润]: 协创智联（电池连接系统业务）2025年净亏损361万元，显示新业务拓展尚处投入期，未贡献正向利润。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司营收增长10.4%，但归母净利润同比下滑6.4%，扣非净利润更是下降12.25%。毛利率连续下滑，主因是PCB行业竞争白热化导致产品价格承压，同时覆铜板等原材料成本上升。若此趋势延续，公司盈利能力将进一步被压缩，ROE已从6%降至5.5%，资本回报效率堪忧。

**新业务拓展与客户集中度构成双重隐忧。** 控股子公司协创智联（新能源FPC/CCS业务）持续亏损，表明公司向新能源领域的转型尚未形成有效盈利支撑。同时，前五大客户销售额占比高达50.39%，客户集中度较高，一旦核心客户订单波动，将对公司业绩产生重大冲击。此外，实际控制人合计控制54.17%表决权，存在不当控制风险。
