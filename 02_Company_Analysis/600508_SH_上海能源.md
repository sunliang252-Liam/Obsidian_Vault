# 600508.SH 深度透视

## 因果逻辑链
- **[煤炭价格下行]** -> [营收与利润双降]: 2025年煤炭市场“供强需弱”，公司原煤、洗煤销售收入同比下降28.18%，直接导致总营收下滑19.09%，归母净利润暴跌69.20%。
- **[降本增效措施]** -> [部分对冲利润下滑]: 公司通过掺烧劣质煤、修旧利废等手段，实现原煤生产成本较预算下降40元/吨，一定程度上缓解了煤价下跌对利润的冲击。
- **[新能源转型加速]** -> [形成新增长点]: 龙东光伏项目全容量并网，新能源装机达47.39万千瓦，新能源公司净利润贡献9,322万元，成为公司转型的关键增量。
- **[新疆基地建设]** -> [资本开支与潜在风险]: 苇子沟煤矿项目进入三期施工，累计投资30.85亿元，但子公司天山煤电亏损1.27亿元，且存在重大诉讼，拖累整体业绩。
- **[煤电一体化协同]** -> [稳定电力板块盈利]: 公司实现精煤外运、劣煤转化、发电、售电产业链经营，电力板块毛利率提升4.56个百分点，有效对冲了煤炭主业的下滑。
- **[关联交易依赖]** -> [成本控制受制]: 前五名供应商中关联方采购额占比37.73%，对控股股东中国中煤的采购依赖，限制了公司成本优化的自主空间。
- **[高分红政策]** -> [回馈股东但透支利润]: 2025年拟每10股派发现金红利2.1元并送红股3股，现金分红占净利润比例高达98.36%，在利润大幅下滑背景下，分红可持续性存疑。

## 风险警告
**核心风险在于煤炭主业景气度下行与转型阵痛期的叠加。** 公司2025年归母净利润同比暴跌69.2%，经营活动现金流净额下降60.76%，核心盈利能力的恶化趋势明显。尽管新能源业务有所起色，但体量尚小，无法弥补煤炭价格下跌带来的巨大缺口。同时，新疆基地的苇子沟煤矿项目投资巨大（累计30.85亿），且子公司天山煤电持续亏损，叠加重大诉讼（涉案金额2.19亿元），构成了显著的资产减值与资金占用风险。

**财务健康度与分红可持续性面临严峻考验。** 在利润大幅下滑的背景下，公司仍维持高比例分红（98.36%），这直接导致未分配利润减少，并可能削弱未来应对行业下行周期的财务缓冲能力。此外，公司对控股股东的关联采购依赖度高（37.73%），在行业不景气时，这种依赖可能限制其通过供应链优化来降本的空间。长期来看，本部矿区可采储量有限，若新疆基地不能尽快贡献利润，公司将面临“青黄不接”的困境。
