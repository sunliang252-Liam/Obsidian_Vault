# 688055.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格竞争]** -> [营收与毛利率双降]: 中小尺寸显示面板行业产能持续释放，竞争加剧，导致公司2025年营收同比下滑26.79%，主营业务毛利率降至5.90%。
- **[境外直销业务萎缩]** -> [收入结构剧变]: 受国际贸易政策不确定性与地缘政治影响，公司主动调整产品结构，境外市场营收同比骤降54.61%，占比从高位回落至33.88%。
- **[差异化技术布局]** -> [扣非净利润亏损收窄]: 尽管营收下滑，但公司凭借动态隐私防窥、全彩电子纸等差异化产品，扣非净利润亏损同比改善14.61%，显示产品结构优化成效。
- **[高研发投入维持]** -> [技术护城河巩固]: 研发投入占营收7.35%，累计授权专利3,212件，全彩电子纸等新技术实现量产，为未来增长储备动能。
- **[海外产能建设]** -> [全球化布局推进]: 稳步推进越南生产基地产能爬坡，旨在贴近海外客户、规避贸易风险，但短期增加了资本开支与运营成本。
- **[财务费用激增]** -> [利润侵蚀]: 利息收入减少导致财务费用同比大增232.17%，对已处于亏损状态的利润表形成额外压力。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户销售额占比高达63.52%，其中单一客户占比24.58%，对核心客户的依赖度极高，议价能力受限。

## 风险警告
龙腾光电当前最核心的风险在于**行业周期性与结构性衰退的叠加**。公司主营的a-Si TFT-LCD技术虽成熟，但在OLED、MiniLED等新技术渗透率提升的背景下，面临被替代的长期风险。2025年营收与毛利率双降，且连续三年亏损，表明公司尚未找到穿越行业低谷的有效路径。尽管扣非亏损有所收窄，但主要依赖产品结构调整而非规模效应，可持续性存疑。

其次，**财务与运营风险不容忽视**。公司客户高度集中，前五大客户贡献超六成收入，一旦核心客户流失或压价，业绩将遭受重创。同时，财务费用因利息收入减少而激增，叠加存货跌价与应收账款回收风险，公司现金流虽为正但已大幅下滑。海外产能建设虽为长远布局，但短期将增加资本开支与运营复杂性，在亏损状态下进一步考验公司的资金链与成本控制能力。
