# 688028.SH 深度透视

## 因果逻辑链
- **[原材料价格上涨]** -> [毛利率下降]: 硬质合金刀具原材料（钨钢棒材）价格大幅上涨，成本传导滞后，导致该业务毛利率同比下滑7.01个百分点。
- **[金刚石微钻业务突破]** -> [营收高增]: 半导体硬脆材料微孔加工领域取得成果，金刚石微钻实现营收1,519.77万元，同比大增208.69%，进入增长通道。
- **[消费电子需求疲软]** -> [子公司盈利能力承压]: 子公司鑫金泉受下游压价、原材料涨价及人力成本上升三重冲击，盈利能力短期承压。
- **[全球化战略推进]** -> [海外营收增长]: “国际业务团队+海外子公司”协同，欧洲沃尔德营收同比增长49.14%，墨西哥生产基地建成，海外营收占比提升。
- **[金刚石功能材料产业化]** -> [新增长极初现]: BDD电极及模组产品在标杆项目落地，营收596.48万元，同比增长170.89%，CVD钻石声学振膜获行业认可。
- **[研发投入持续加大]** -> [技术壁垒巩固]: 研发费用同比增长12.47%，在行星滚柱丝杠刀具、金刚石微钻、12英寸钻石散热晶圆等领域取得关键技术突破。
- **[集团化管理深化]** -> [运营效率改善]: 重构财务体系、推进ERP平台、增设运营管理部，嘉硬公司实现净利润大幅减亏，惠州鑫金泉盈利能力改善。

## 风险警告
**核心风险在于商誉减值与子公司盈利波动。** 公司因收购鑫金泉形成3.91亿元商誉，占总资产16.86%。若消费电子行业持续低迷或原材料成本压力无法传导，鑫金泉业绩不达预期，将直接引发商誉减值，对当期利润造成重大冲击。这是公司资产负债表上最大的潜在“地雷”。

**第二重风险是“增收不增利”的困境。** 营收增长11.08%，但归母净利润下降4.71%，毛利率下滑3.74个百分点。硬质合金刀具和超硬材料业务毛利率均出现显著下滑，反映出成本压力与竞争加剧。若公司无法通过产品升级或提价转嫁成本，盈利能力将持续承压。此外，金刚石功能材料业务仍处于投入期，短期难以贡献利润，存在研发失败或市场拓展不及预期的风险。
