# 600138.SH 深度透视

## 因果逻辑链
- **[低毛利业务（IT分销、旅游服务）收入高增]** -> [营收增长13.86%但归母净利润下降47.95%]: IT产品销售与技术服务收入增长36.55%，旅游产品服务收入增长4.97%，两者毛利率极低（3.54%、15.29%），拉低整体盈利质量，导致“增收不增利”。
- **[核心景区古北水镇遭遇暴雨灾害]** -> [参股公司净利润-2.17亿元，拖累归母净利润-8367万元]: 古北水镇接待游客下降13.60%，营收下降26.97%，固定折旧摊销成本刚性，亏损扩大，成为利润最大拖累项。
- **[乌镇景区房产去化不及预期]** -> [乌镇公司整体净利润同比下降17.26%]: 乌镇景区经营净利润虽同比增长，但房地产销售业务规模同比回落56.06%，且毛利率为-80.48%，严重侵蚀景区利润。
- **[行业竞争加剧导致毛利率承压]** -> [旅游产品服务毛利率下降0.93个百分点，整合营销净利润同比下降]: 旅行社深陷价格战，整合营销市场有效需求不足，企业营销投放谨慎，各板块盈利空间被压缩。
- **[资产减值损失与公允价值变动损失]** -> [合计影响归母净利润-8770万元]: 公司对存货、应收款项、商誉等计提减值损失6038万元，同时其他非流动金融资产公允价值变动损失1525万元，双重打击利润。
- **[IT分销业务回款节奏改善]** -> [经营活动现金流净额大幅增长231.61%]: 经营性现金流从2.83亿元飙升至9.37亿元，主要系IT产品销售与技术服务业务回款节奏所致，现金流质量改善但非持续性盈利改善。
- **[策略性业务（IT分销+大厦租赁）成为利润稳定器]** -> [创格科技贡献净利润5280万元，大厦出租率稳定]: 在核心景区和整合营销利润承压时，低毛利的IT分销业务和稳定的物业租赁为公司提供了基础利润支撑。

## 风险警告
**核心景区经营风险集中爆发。** 古北水镇受极端天气冲击，营收骤降27%，亏损扩大，暴露了单一景区对不可抗力的脆弱性。乌镇虽经营韧性较强，但房产去化困难（毛利率-80%）持续拖累利润，表明其“景区+地产”模式在行业下行周期中面临严峻挑战。两大核心景区的利润贡献能力正在系统性下降，而公司缺乏同等体量的新增长极来对冲。

**盈利结构恶化，增长质量堪忧。** 公司营收增长主要依赖毛利率仅3.54%的IT分销业务（占营收47.6%），而高毛利的景区经营（毛利率76.32%）收入却在萎缩。这种“低毛利业务冲量、高毛利业务承压”的结构，导致净利润率仅0.74%，远低于行业平均水平。若核心景区无法快速企稳，公司可能陷入“增收不增利”的长期困境，且资产减值风险（存货、商誉）将持续侵蚀净资产。
