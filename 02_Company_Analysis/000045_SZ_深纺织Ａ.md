# 000045.SZ 深度透视

## 因果逻辑链
- **[偏光片行业竞争加剧，产品“量增价减”]** -> [归母净利润下降23.44%]: 偏光片销量增长2.08%，但售价承压，导致营收下降2.82%，利润降幅远大于营收。
- **[产品结构向高附加值倾斜]** -> [MNT、OLED手机偏光片销售额大增]: 公司主动调整产品结构，提升高毛利产品占比，部分对冲了价格下行压力。
- **[7号线2500mm超宽幅产线优势]** -> [85吋及以上超大尺寸偏光片销量同比大幅提升]: 该产线匹配高世代面板线，在超大尺寸市场具备成本与效率优势，驱动结构性增长。
- **[原材料成本控制与精益管理]** -> [偏光片毛利率仅下降1.39个百分点]: 通过降低材料损耗、提升良率，有效控制了成本，减缓了价格战对盈利的侵蚀。
- **[资产减值损失激增]** -> [侵蚀利润1.38亿元]: 计提大额存货跌价准备，是导致净利润大幅下滑的核心因素之一，反映下游需求波动与库存压力。
- **[经营活动现金流净额大增50.39%]** -> [现金流状况显著改善]: 主要得益于购买商品支付的现金减少，显示公司在供应链管理和营运资金周转上取得成效。
- **[8号线项目启动投资]** -> [在建工程激增，投资活动现金流由正转负]: 为突破中高端产能瓶颈，公司启动13.34亿元新产线建设，短期资本开支压力增大。
- **[境外收入同比增长127.91%]** -> [海外市场拓展取得突破]: 境外收入占比从4.86%跃升至11.40%，成为新的增长点，但汇率波动风险随之增加。

## 风险警告
公司面临的核心风险是**行业竞争加剧导致的盈利能力持续承压**。尽管销量增长，但产品“量增价减”趋势明显，叠加高达1.38亿元的资产减值损失，归母净利润已连续两年下滑。若下游面板需求复苏不及预期，或公司无法在OLED、车载等高端市场取得突破，毛利率可能进一步收窄，业绩存在继续恶化的风险。

其次，**关键原材料高度依赖日本供应商**（如PVA膜、TAC膜），构成供应链安全和成本控制的重大隐患。原材料价格受日元汇率、供应商产能等多重因素影响，一旦价格上涨或供应受限，将直接冲击公司生产成本和盈利稳定性。此外，公司正大规模投资建设8号线，资本开支压力巨大，若项目投产后的产能消化或效益不及预期，将加剧财务风险。
