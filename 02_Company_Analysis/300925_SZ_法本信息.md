# 300925.SZ 深度透视

## 因果逻辑链
- **[金融与汽车行业高增长]** -> **收入结构优化**: 金融（+33.24%）和汽车（+35.63%）行业收入高速增长，驱动数字化创新技术服务收入同比大增35.76%，占总收入比重提升至23.54%。
- **[“开跑道、放将军”机制]** -> **组织活力释放**: 通过区域裂变和授权，成功孵化武汉代表处、昆仑大客户部等新增长极，支撑了18.26%的营收增长。
- **[鸿蒙生态深度绑定]** -> **信创业务突破**: 作为鸿蒙钻石服务商，完成超100个头部应用鸿蒙化改造，交付超60万次测试，成为国产化替代浪潮中的核心受益者。
- **[全球化布局加速]** -> **海外市场实质性突破**: 新加坡签约第二家数字银行，菲律宾落地BPO业务，海外交付人数破百，从“借船出海”向构建本地化交付能力转变。
- **[FarAI平台产品化]** -> **AI赋能业务提效**: 自研FarAI GPTCoder、GPTBrain等工具实现商业化落地，服务50余家客户，推动交付模式从“人力驱动”向“AI+人协同”演进。
- **[营收增长与利润背离]** -> **成本侵蚀利润**: 营收增长18.26%至51.10亿元，但归母净利润下降20.29%至1.04亿元，主因是人工成本增速（+19.85%）超过收入增速，导致毛利率下降2.33个百分点。
- **[现金流与利润背离]** -> **运营效率承压**: 经营活动现金流净额下降24.01%至1.16亿元，与净利润1.04亿元基本持平，但Q4集中回款特征明显，前三季度均为净流出，反映回款周期拉长。

## 风险警告
**核心风险在于“增收不增利”的困境持续深化。** 公司营收突破50亿大关，但净利润却同比下滑20%，毛利率从19.79%降至17.46%。根本原因是作为人力密集型服务商，人工成本增速（+19.85%）持续高于收入增速（+18.26%），且高毛利的数字化创新技术服务（16.76%）毛利率甚至低于传统通用技术服务（17.63%），表明新业务尚未形成有效的利润护城河。若无法通过AI工具或业务转型显著提升人效，规模扩张将反噬利润。

**海外业务与战略转型存在高度不确定性。** 公司战略聚焦“国际争先”和“业务转型”（从H1向H2/H3），但当前海外收入占比极低，且新设海外子公司（如马来西亚、印尼）尚处于亏损投入期。同时，向高价值的产品与解决方案（H2）转型需要大量研发投入和客户验证周期，短期内难以贡献利润。若海外拓展不及预期或转型受阻，公司将面临国内红海市场竞争加剧与新增投入的双重压力。
