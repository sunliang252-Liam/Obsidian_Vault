# 002539.SZ 深度透视

## 因果逻辑链
- **[磷复肥销量增长10.10%]** -> [营收增长5.01%]: 核心主业磷复肥量价齐升，带动整体营收增长，对冲了纯碱、贸易等业务的收入下滑。
- **[70万吨合成氨项目建成投产]** -> [氮肥原料自给率提升，成本下降]: 补齐尿素产能空白，降低复合肥生产成本，强化氮产业链一体化优势。
- **[黄磷成本下降]** -> [黄磷毛利率提升12.94个百分点]: 自有磷矿建设稳步推进，降低黄磷生产成本，盈利能力显著增强。
- **[磷酸铁销量增长15.25%]** -> [磷酸铁营收增长19.30%]: 受益于新能源动力及储能需求增长，磷酸铁业务量价齐升，成为新增长点。
- **[纯碱价格下行]** -> [纯碱营收下降34.15%]: 行业供给宽松，纯碱价格承压，拖累化工板块整体收入。
- **[经营现金流净额增长99.36%]** -> [现金及等价物净增加额大幅增长]: 销售回款增加及票据到期兑付收回保证金，现金流状况显著改善。
- **[在建工程大幅增长]** -> [总资产增长16.60%]: 70万吨合成氨、磷矿采选等重大项目持续投入，在建工程规模扩大，推动总资产增长。

## 风险警告
**1. 产能扩张与市场消化风险。** 公司磷复肥年产能已超940万吨，且仍有在建项目。若下游农业需求不及预期或市场竞争加剧，可能导致产能利用率下降、产品价格承压，新增产能无法被市场有效消化，进而影响公司盈利能力和资产回报率。

**2. 原材料价格波动与产业链协同风险。** 公司复合肥成本中原材料占比超80%，尽管向上游延伸布局，但氯化钾、尿素等关键原料仍需外采。若主要原材料价格大幅波动，而公司无法通过产品提价或产业链协同完全对冲，将直接挤压利润空间。此外，磷矿、合成氨等在建项目能否按期达产并实现成本优势，存在不确定性。
