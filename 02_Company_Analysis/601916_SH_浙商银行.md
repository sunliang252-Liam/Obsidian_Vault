# 601916.SH 深度透视

## 因果逻辑链
- **[净息差持续收窄]** -> [营收与利润双降]: 生息资产收益率下降46BP，付息负债成本率仅下降40BP，净息差收窄11BP至1.60%，导致利息净收入下降1.55%。
- **[债市收益率上行]** -> [非利息净收入大幅下滑]: 交易性金融资产公允价值变动由正转负，从+35.16亿转为-12.55亿，导致其他非利息净收入下降20.57%。
- **[个人贷款不良率飙升]** -> [资产质量结构性恶化]: 个人贷款不良率从1.78%升至2.45%，不良余额增加28.80亿，抵消了公司贷款不良率下降0.26个百分点的改善效果。
- **[拨备覆盖率大幅下降]** -> [风险抵补能力削弱]: 拨备覆盖率从178.67%骤降至155.37%，逼近140%监管红线，贷款拨备率降至2.11%，已触及监管底线。
- **[深耕浙江战略]** -> [区域市场地位提升]: 省内存款突破6,300亿元居12家股份行首位，新增信贷2/3投向省内，融资服务总量近1.2万亿元，连续10年获评支持浙江一等奖。
- **[个人存款高增长]** -> [负债结构优化]: 个人存款增长29.92%，占比提升3.52个百分点，带动存款付息率下降32BP，有效缓解息差收窄压力。
- **[减值损失减少]** -> [利润缓冲]: 减值损失同比下降13.53%至243.80亿，减少38.15亿，部分对冲了营收下滑对利润的冲击。

## 风险警告
**核心风险在于拨备覆盖率已逼近监管红线。** 155.37%的拨备覆盖率距离140%的监管底线仅15个百分点，且贷款拨备率2.11%已触及2.1%的最低要求。在营收和利润双降的背景下，若不良贷款继续暴露，银行将面临补充拨备的巨大压力，进一步侵蚀利润。个人贷款不良率从1.78%飙升至2.45%，信用卡和消费贷风险加速暴露，是当前资产质量最大的隐患。

**资本充足率持续承压。** 核心一级资本充足率仅8.40%，虽勉强满足监管要求，但在利润下滑14.85%、分红压力下，内生资本补充能力严重不足。12.12%的资本充足率在同业中处于偏低水平，限制了风险加权资产的扩张空间，可能制约未来业务发展和规模增长。
