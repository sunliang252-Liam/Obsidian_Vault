## 因果逻辑链
- **[核心品种振源胶囊集采放量]** -> [营收结构依赖加剧]: 振源胶囊贡献营收2.21亿元，占主营业务比重较大，但整体营收同比下降4.23%，显示单一品种依赖风险。
- **[全国中成药集采中标]** -> [市场渗透率提升]: 振源胶囊凭借“日均治疗费用低”等优势中选，成功进驻7171家医疗机构，但以价换量导致利润承压。
- **[人参战略储备与存货高企]** -> [资产结构僵化与减值风险]: 存货账面价值15.81亿元，占总资产53.42%，高额人参储备占用大量资金，且面临市场价格波动导致的跌价风险。
- **[销售费用高企]** -> [利润侵蚀]: 销售费用3.17亿元，占营收49.6%，高强度的学术推广和渠道维护成本严重压缩净利润空间。
- **[非经常性损益依赖]** -> [扣非净利润大幅下滑]: 扣非净利润仅1188万元，同比下滑56.12%，政府补助和理财收益等非经常性损益对净利润贡献显著，主业盈利能力薄弱。
- **[健康食品与化妆品板块增长乏力]** -> [多元化战略效果不佳]: 健康食品收入增长15.91%，但化妆品收入下降11.21%，两大非药板块未能有效对冲药品主业的下滑。
- **[研发投入资本化率为零]** -> [创新成果转化缓慢]: 研发投入2087万元，全部费用化，且主要项目处于临床或备案阶段，短期内难以贡献新的业绩增长点。

## 风险警告
**核心风险在于“人参全产业链”战略下的资产僵化与盈利质量恶化。** 公司存货占总资产超53%，其中大量为人参战略储备，不仅占用巨额资金，更面临市场价格波动的跌价风险。同时，公司净利润高度依赖政府补助和理财收益，扣非净利润已连续两年大幅下滑，主业盈利能力堪忧。在医保控费与集采降价的大背景下，核心品种振源胶囊的“以价换量”策略能否持续，是未来业绩的关键变量。

**次要风险来自高昂的销售费用与薄弱的研发转化。** 销售费用率接近50%，远超行业平均水平，反映出公司对渠道和学术推广的严重依赖，一旦政策或竞争格局变化，费用刚性将严重侵蚀利润。与此同时，研发投入全部费用化，且缺乏重磅在研管线，公司长期增长缺乏技术驱动力。化妆品和健康食品等多元化业务体量尚小，难以成为第二增长曲线，公司整体抗风险能力较弱。
