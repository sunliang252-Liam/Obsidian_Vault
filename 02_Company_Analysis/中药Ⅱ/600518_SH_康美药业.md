# 600518.SH 深度透视

## 因果逻辑链
- **[中药饮片集采中标与智慧药房扩张]** -> [营收微增1.22%]: 集采中标扩大医院覆盖，智慧药房新增签约18家公立医院，驱动中药板块收入增长3.22%，但西药贸易收缩5.43%拖累整体增速。
- **[债务重组收益大幅减少]** -> [扣非净利润巨亏2.94亿]: 2025年债务重组收益2.62亿，较2024年3.62亿下降27.6%，导致扣非净利润从-5.33亿收窄至-2.94亿，但主业仍深度亏损。
- **[商誉减值计提增加]** -> [资产减值损失扩大]: 对包含商誉的资产组减值测试，计提商誉减值损失1.84亿，同比增加29.1%，侵蚀利润。
- **[强化“两金”管理]** -> [经营现金流由负转正]: 通过提升营业收现率和减少税费支出，经营活动现金流净额从-4.28亿大幅改善至+1.11亿，但可持续性存疑。
- **[销售费用激增26.24%]** -> [侵蚀利润空间]: 销售费用达5.26亿，其中销售推广服务费1.39亿，同比增长显著，反映市场竞争加剧下的获客成本上升。
- **[母公司未分配利润-210亿]** -> [连续三年不分配]: 巨额历史亏损导致2025年利润分配预案为不分配，严重制约股东回报能力。
- **[中药饮片毛利率提升6.97个百分点]** -> [成本控制见效]: 中药饮片毛利率从14.18%提升至21.15%，主要得益于营业成本下降5.16%，但需关注成本下降的可持续性。

## 风险警告
**核心风险：主业盈利能力脆弱，依赖非经常性损益。** 2025年扣非净利润为-2.94亿元，连续第三年亏损，表明中药饮片、智慧药房等核心业务尚未形成稳定盈利。公司盈利高度依赖债务重组收益（2.62亿）等非经常性项目，一旦重组进程放缓或结束，业绩将面临断崖式下滑。

**重大风险：历史包袱沉重，财务结构脆弱。** 母公司未分配利润高达-210亿元，彻底丧失分红能力。总资产132亿，但净资产仅73亿，资产负债率约45%。商誉余额仍有3690万，存在进一步减值风险。此外，历史涉诉工程债务的解决导致投资活动现金净流出1.77亿，资金压力持续。

**行业风险：集采降价与原料价格波动双重挤压。** 中药饮片带量采购全面落地，公司虽中标但面临价格下行压力。中药材价格受气候、政策等多重因素影响波动剧烈，公司虽布局GAP种植基地，但2025年原材料成本下降5.16%的可持续性存疑，未来成本控制面临挑战。
