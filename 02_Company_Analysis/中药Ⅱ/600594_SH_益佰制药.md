# 600594.SH 深度透视

## 因果逻辑链
- **[中成药集采降价与行业需求疲软]** -> [营收与利润双降]: 第三批中成药集采平均降幅68%，叠加终端需求疲软，导致公司2025年营业收入同比下降14.31%，归母净利润亏损3.3亿元。
- **[核心产品销量下滑]** -> [医药工业板块承压]: 注射用洛铂、银杏达莫注射液等核心产品销量同比分别下降11.45%和16.69%，直接拖累抗肿瘤和心脑血管两大核心业务收入。
- **[商誉与资产减值损失激增]** -> [净利润大幅亏损]: 报告期内计提商誉减值等资产减值损失1.59亿元，是导致净利润由盈转亏的核心因素，反映出前期并购整合效果不佳。
- **[医疗服务板块毛利率骤降]** -> [拖累整体盈利能力]: 医疗服务板块毛利率同比下降7.89个百分点至13.99%，主要因绵阳富临医院亏损扩大及博雅眼科医院业务终止，板块盈利能力显著恶化。
- **[销售费用率维持高位]** -> [侵蚀利润空间]: 尽管销售费用同比下降24.97%，但占营收比例仍高达44.17%，高额的学术推广与市场费用持续挤压利润空间。
- **[研发投入聚焦仿制药与改良]** -> [创新管线薄弱]: 研发投入占营收4.52%，但全部费用化且无资本化，主要项目为仿制药（阿扎胞苷）和改良型新药（YBR-8002），缺乏重磅创新药储备。
- **[经营活动现金流大幅改善]** -> [运营效率提升]: 经营活动现金流净额同比增长195.49%至2.57亿元，主要得益于成本费用支出的有效控制，显示公司在收缩期加强了现金管理。

## 风险警告
公司面临的核心风险在于**存量业务萎缩与资产质量恶化**的双重打击。中成药集采常态化及医保控费持续挤压核心产品利润，导致营收连续两年下滑。更严重的是，前期并购形成的商誉在2025年全额计提减值，表明外延式扩张战略失败，资产质量存在隐患。医疗服务板块的持续亏损进一步加重了财务负担。

此外，公司**研发管线薄弱，缺乏增长新引擎**。研发投入全部费用化，且集中于仿制药和改良型新药，在创新药竞争白热化的行业背景下，公司未来产品线面临青黄不接的风险。同时，母公司未分配利润为负，已不具备分红能力，对长期投资者的回报预期构成重大压制。
