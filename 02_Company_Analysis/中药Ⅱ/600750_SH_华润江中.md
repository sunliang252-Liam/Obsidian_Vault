# 600750.SH 深度透视

## 因果逻辑链
- **[品牌护城河与渠道控制]** -> **营收承压但利润增长**: 公司通过强化“江中”品牌心智和优化渠道结构，在OTC营收下滑8.39%的背景下，实现了归母净利润15.03%的增长。
- **[精细化费用管控]** -> **盈利能力提升**: 销售费用同比下降12.94%，期间费用率从40.11%降至38.06%，是利润增长的核心驱动力。
- **[健康消费品自营能力建设]** -> **第二增长曲线形成**: 健康消费品业务营收同比增长43.19%，通过自建兴趣电商团队和优化产品矩阵，成功开辟了新的增长点。
- **[研发投入与成果转化]** -> **长期竞争力筑基**: 研发投入强度首次突破5%，2个经典名方获受理，为未来产品梯队和差异化竞争储备动能。
- **[智能制造与供应链韧性]** -> **成本与质量优势**: 中药生产数控化率超95%，GAP基地建设实现突破，有效对冲了原材料价格波动和集采降价压力。
- **[高分红与股权激励]** -> **股东价值与组织活力**: 年度现金分红比例高达96.71%，并落地第二期股权激励，实现了股东回报与核心团队激励的深度绑定。

## 风险警告
**核心风险在于OTC基本盘的持续承压与渠道变革的不确定性。** 报告期内，公司核心的OTC业务营收同比下降8.39%，主要产品如健胃消食片、多维元素片等销量均出现下滑。这并非短期波动，而是反映了在集采扩围、药价治理深化以及零售药店渠道结构性调整的多重压力下，公司传统优势业务的增长动能正在减弱。下游渠道的剧烈变革（线下药店整合、线上分流）对公司的渠道管理和终端动销能力提出了前所未有的挑战。

**另一重大风险是外延并购的整合效果与研发投入的转化效率。** 公司通过并购精诚徽药等企业来补充产品线，但并购后的整合、文化融合及协同效应能否达到预期存在不确定性。同时，研发投入强度虽已超过5%，但资本化比例高达27.70%，且新药研发周期长、风险高，若核心研发管线（如经典名方、创新药）未能如期获批或商业化不及预期，高额的研发投入将侵蚀利润。此外，公司部分委托贷款已逾期，需关注其潜在的信用减值风险。
