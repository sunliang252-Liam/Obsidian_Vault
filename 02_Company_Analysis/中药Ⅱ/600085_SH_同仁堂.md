# 600085.SH 深度透视

## 因果逻辑链
- **[市场需求放缓与行业竞争加剧]** -> [营业收入下降7.21%]: 宏观经济调整与消费需求分化，导致公司核心中成药及商业零售收入同步下滑。
- **[深化营销改革与精准费用管控]** -> [销售费用仅下降1.76%]: 在收入下滑背景下，公司通过优化营销策略、控制人力成本，实现了费用率的相对稳定，但未能扭转收入颓势。
- **[购买商品支付现金大幅减少]** -> [经营活动现金流净额暴增253.87%]: 公司通过优化采购策略、减少存货采购支出，使经营性现金流显著改善，但这是收缩性策略，非盈利增长驱动。
- **[核心大品种销售下滑]** -> [医药工业收入下降10.03%]: 安宫牛黄系列、同仁牛黄清心系列等前五大品种销售承压，心脑血管类收入同比大幅下降20.46%，拖累工业板块整体表现。
- **[原材料价格波动与成本管控]** -> [工业毛利率微降0.52个百分点]: 尽管原材料价格有所下降，但产量减少导致单位固定成本上升，毛利率仍小幅下滑，盈利能力承压。
- **[子公司投资收益减少]** -> [归母净利润下降22.07%]: 上年同期子公司出售股权确认大额投资收益，本期无此事项，叠加主营业务下滑，导致净利润降幅大于收入降幅。
- **[存货跌价准备计提增加]** -> [资产减值损失同比增加49.8%]: 因部分产品成本高于可变现净值，公司计提了更多存货跌价准备，反映出部分品种面临市场价值下降的风险。

## 风险警告
**核心风险在于“量价双杀”下的盈利恶化。** 2025年营收与净利润双降，且净利润降幅（-22.07%）远超营收降幅（-7.21%），表明公司盈利能力正在加速下滑。核心大品种（如安宫牛黄系列）销售遇冷，同时存货跌价准备大幅增加，暗示部分产品市场价值正在缩水。若市场需求持续疲软，公司可能面临更严重的库存积压和利润侵蚀。

**结构性风险来自“增收不增利”的海外业务与高企的销售费用。** 境外业务毛利率同比大幅下降5.65个百分点，而销售费用率仍维持在20.47%的高位，远超部分同行。在收入下滑时，高额销售费用对利润的挤压效应更为显著。此外，控股股东关于解决同业竞争的承诺（天津同仁堂）尚未有实质性进展，潜在的关联交易和利益冲突仍是长期不确定性因素。
