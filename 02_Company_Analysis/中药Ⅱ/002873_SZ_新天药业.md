# 002873.SZ 深度透视

## 因果逻辑链
- **[院端市场萎缩]** -> [营收下降12.57%]: 处方药产品覆盖医院端受市场环境影响，妇科类(-8.95%)、泌尿系统类(-20.81%)、清热解毒类(-20.53%)全线下滑，导致整体收入承压。
- **[原材料价格上涨]** -> [毛利率下降]: 直接材料成本占营业成本52.27%，部分中药材价格上涨侵蚀利润空间，主营业务毛利率同比下降1.77个百分点。
- **[销售费用刚性]** -> [利润弹性极低]: 销售费用率高达43.86%，收入下降时费用未能同比例压缩，导致净利润降幅(82.59%)远超营收降幅。
- **[研发投入资本化率骤降]** -> [当期费用增加]: 资本化研发投入占比从32.11%降至14.78%，更多研发支出费用化处理，直接拖累当期利润。
- **[参股汇伦医药]** -> [长期战略布局]: 以4000万元增资并受让股权，累计持股15.46%，前瞻性布局小分子化药领域，旨在构建“中药+化药”协同产业生态。
- **[OTC渠道与线上营销]** -> [对冲院端下滑]: 院外市场及小红书、抖音等线上渠道增长，对院内市场回落形成业务补充，体现渠道多元化价值。
- **[保健食品新赛道]** -> [未来增长点]: 基于复方配伍保健食品备案试点，已完成多个处方制定，计划2026年提交备案，有望开辟第二增长曲线。

## 风险警告
公司面临的核心风险是**业绩断崖式下滑后的持续盈利能力**。2025年净利润同比暴跌82.59%至仅911万元，扣非净利润更是下滑84.81%，而销售费用率仍高达43.86%，费用刚性极强。在院端市场持续承压、原材料成本上涨的背景下，公司缺乏有效的利润缓冲垫，若收入端无法快速企稳回升，利润可能进一步被侵蚀甚至转为亏损。

此外，**研发管线的不确定性**是另一重大风险。公司多个1.1类新药尚处临床早期或工艺研究阶段，距离商业化仍有漫长周期。研发投入资本化率从32.11%骤降至14.78%，暗示部分项目推进不及预期。同时，公司通过参股汇伦医药布局化药领域，但汇伦医药尚未贡献投资收益，且化药产线建设需投入不超过2.5亿元，短期将加大资本开支压力，长期回报存在较大不确定性。
