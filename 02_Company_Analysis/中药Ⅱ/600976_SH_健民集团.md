# 600976.SH 深度透视

## 因果逻辑链
- **主动收缩低效商业业务** -> **营收下降3.85%，但净利润基本持平**: 公司主动削减低毛利的医药商业规模（收入-23.37%），聚焦高毛利的医药工业（收入+15.92%），工业毛利率提升4.59个百分点至80.95%，成功对冲了商业收入下滑对利润的冲击。
- **中药材价格下行** -> **工业成本下降与现金流改善**: 2025年中药材价格指数下跌14.05%，公司工业营业成本同比下降6.57%，同时采购付款减少，带动经营活动现金流净额同比增长17.19%。
- **“双轮驱动”品牌战略深化** -> **核心OTC与处方药产品放量**: 便通胶囊（+29%）、健脾生血片/颗粒（+20%）等核心品种在“院内+院外”模式下实现高增长；处方线整体收入增长21%，其中创新药七蕊胃舒胶囊（+39%）和小儿紫贝宣肺糖浆（首年销售超7000万）表现亮眼。
- **研发管线持续产出** -> **构建未来增长产品梯队**: 2025年获批3个药品注册证书（含1个中药1.1类新药小儿牛黄退热贴膏），5个新药处于临床阶段，研发实力位列中药行业第12名，为中长期发展提供产品储备。
- **智能制造与绿色工厂建设** -> **降本增效与产能提升**: 武汉、随州基地获评“国家5G工厂”和“国家绿色工厂”，综合制剂车间等投产，人效提升11%，有效控制了生产成本。
- **参股公司健民大鹏贡献稳定收益** -> **平滑主业利润波动**: 参股公司健民大鹏（体外培育牛黄）2025年净利润3.19亿元，为公司贡献了稳定的投资收益，部分抵消了主业因营销投入增加带来的利润压力。

## 风险警告
**核心风险在于高销售费用侵蚀利润与新品推广的不确定性。** 公司销售费用率高达43.09%，远超行业平均水平（如马应龙25.13%），且同比增长18.22%，是利润增速远低于收入增速的主要原因。若未来品牌推广或学术营销效率下降，将直接压缩利润空间。同时，新上市的小儿紫贝宣肺糖浆、小儿牛黄退热贴膏等创新药尚处市场培育期，面临集采降价、医保谈判及竞品挤压等多重挑战，销售放量存在不确定性。

**另一风险来自政策与原材料波动。** 中成药集采已扩围至OTC品种，公司核心产品龙牡壮骨颗粒虽暂未纳入，但政策风险持续存在。此外，尽管2025年中药材价格下行利好成本，但其价格受气候、产地等因素影响波动剧烈，若未来原材料价格大幅反弹，将直接冲击公司80%以上的工业毛利率。

**公司简介（F10 原文）**

> 健民药业集团股份有限公司,始创于明崇祯十年(1637年),原名“叶开泰”,解放前便享有“初清三杰”、“中国四大药号”的美誉。1953年,叶开泰号制药部分被改造为“武汉市健民制药厂”,2004年在上海证券交易所上市(A股代码600976)。健民集团以发展中医药为核心,以儿科产品为特色,已成为全国重点中药企业和小儿用药生产基地,并设有国家企业技术中心、企业博士后科研工作站和儿童药物研究院,具备完善的自主研发能力。公司为中华老字号企业,拥有“健民”、“龙牡”、“叶开泰”三大品牌。公司入选“中国最有价值品牌500强”,综合实力跻身全国医药企业百强之列。集团产品资源丰富,品类结构完善。钻石单品“龙牡壮骨颗粒”,是治疗儿童不爱吃饭、发育迟缓、夜惊多汗和儿童补钙的品种,上市30多年来,创造了累积销售300亿袋,健康三代人的奇迹。
