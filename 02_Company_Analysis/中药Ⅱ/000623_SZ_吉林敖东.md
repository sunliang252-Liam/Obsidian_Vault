# 000623.SZ 深度透视

## 因果逻辑链
- **[广发证券投资收益大幅增长]** -> [归母净利润同比+54.39%]: 公司持有广发证券20.11%股权，采用权益法核算，广发证券2025年净利润同比大增，贡献投资收益25.63亿元，占利润总额106.89%，是业绩暴增的核心引擎。
- **[中药板块收入下滑]** -> [整体营收同比-10.55%]: 中药收入占营收60.99%，同比下降11.29%，拖累整体营收表现，核心品种安神补脑液等销量平稳但未能对冲行业下行压力。
- **[化药板块逆势增长]** -> [营收结构优化]: 化药收入同比+6.46%，占比提升至12.62%，新获批8个化药文号及原料药，产品矩阵韧性增强，部分对冲中药下滑。
- **[营销改革与渠道整合]** -> [销售费用率上升]: 销售费用同比+13.21%，主因营销体系融合转型、组建医疗与零售事业群，短期内费用前置，但为长期全渠道营销格局奠定基础。
- **[金融资产公允价值变动]** -> [非经常性损益大幅转正]: 交易性金融资产公允价值变动收益1.74亿元（上年为-1.09亿元），叠加证券投资收益，非经常性损益从-0.22亿转为+1.95亿，显著增厚利润。
- **[股份回购与现金分红]** -> [股东回报提升]: 2020-2025年累计回购11.4亿元，2025年中期+年度合计分红5.86亿元，叠加回购视同分红，总回报占净利润29.48%，强化市值管理。
- **[研发投入持续加码]** -> [长期竞争力储备]: 研发费用同比+23.98%，安神补脑液获抗AD、抗衰老专利，配方颗粒备案达535个，经典名方与化药仿制药管线丰富，为未来增长蓄力。

## 风险警告
**核心风险在于业绩对广发证券的过度依赖。** 公司76.12%的总资产为长期股权投资（主要为广发证券），投资收益占利润总额106.89%，剔除金融收益后，医药主业实际盈利能力有限。一旦资本市场下行或广发证券业绩波动，公司净利润将剧烈震荡，2024年公允价值变动亏损导致扣非净利润下滑即为前车之鉴。这种“金融反哺实业”的模式虽稳健，但本质是披着医药外衣的券商影子股，估值逻辑需按金融控股而非纯药企重估。

**医药主业面临集采扩围与竞争加剧的双重挤压。** 中药收入同比下降11.29%，化学药品虽增长但体量较小，且部分产品因集采暂停挂网。公司630个批文中仅2个过亿品种，产品梯队薄弱。同时，原料成本波动（道地药材涨价）、行业监管趋严（全链条追溯、中药生产新规）将持续压缩利润空间。若金融投资收益无法持续高增长，医药主业难以独立支撑当前估值。
