# 000989.SZ 深度透视

## 因果逻辑链
- **[OTC产品收入下滑22.67%]** -> [营收下降5.99%]: 公司核心OTC产品（六味地黄丸、驴胶补血颗粒等）受渠道调整和控价策略影响，收入大幅缩减，拖累整体营收。
- **[销售费用压缩16.73%]** -> [净利润微增2.96%]: 在营收下滑背景下，公司通过严格控费，使归母净利润实现小幅正增长，体现了“降本增效”的成果。
- **[收购吉象隆并表]** -> [新增多肽原料药业务]: 公司以3.1亿元控股吉象隆（51.67%），切入多肽赛道，贡献了约2035万元归母净利润，成为新的利润增长点。
- **[经营现金流大增114.25%]** -> [现金循环效率提升]: 通过优化库存和加强回款，购买商品支付的现金大幅减少，经营活动现金流净额远超净利润，财务质量显著改善。
- **[代理模式收入增长6.05%]** -> [渠道结构变化]: 自营模式收入下降16.53%，而代理模式收入增长，表明公司正将部分销售职能外包，以降低自营成本。
- **[控制权变更为黑龙江省国资委]** -> [治理结构重塑]: 原实控人李振国转让股份，辰能创投成为控股股东，公司从民营转为地方国企，战略稳定性与资源获取能力或增强。

## 风险警告
**核心风险在于传统OTC业务的持续萎缩与创新药研发的高不确定性。** 公司营收最大来源OTC板块收入同比下降22.67%，主要受渠道库存清理和价格管控影响，若终端动销未能有效恢复，该趋势可能延续。同时，公司大力投入的干细胞（北京美科）及创新药（YB209/YB211）项目均处于临床早期，距离商业化尚远，且研发失败风险较高，短期内无法贡献业绩。

**另一重大风险是商誉减值与业绩承诺压力。** 公司因收购吉象隆新增约1.39亿元商誉，总商誉达3.4亿元。吉象隆2025年业绩承诺完成率仅为58.58%（三年累计承诺1.65亿，首年完成0.97亿），若后续两年无法达标，将面临商誉减值风险，直接冲击利润表。此外，公司对并购基金（雍和启航）的投资持续亏损，参股的北京美科等创新药公司亦处于亏损状态，长期股权投资存在减值隐患。
