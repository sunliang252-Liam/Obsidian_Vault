## 因果逻辑链
- **[核心产品宣肺止嗽合剂销量下滑]** -> [营收下降14.92%]: 合剂类收入同比降28.59%，拖累整体营收，但滴丸剂增长31.86%部分对冲。
- **[销售费用大幅压降25.97%]** -> [扣非净利润增长7.96%]: 在营收下滑背景下，通过控费实现利润正增长，但经营活动现金流净额转负。
- **[普安制药业绩承诺超额完成216%]** -> [归母净利润大增79.56%]: 子公司普安制药贡献净利润6201万元，远超承诺3102万元，是利润增长的核心引擎。
- **[宣肺止嗽合剂产能扩张（二期投产）]** -> [库存量激增89.06%]: 新生产线投产，但市场消化不及预期，导致合剂库存积压，现金流恶化。
- **[收购创新研究院70%股权]** -> [研发能力与检验检测业务拓展]: 整合研发平台，新增检验检测收入220万元，但短期对业绩贡献有限。
- **[血液透析浓缩液获证]** -> [医疗器械业务起步]: 成为西北首家获证企业，开辟新增长点，但尚未贡献规模化收入。
- **[滴丸剂销量增长35.34%]** -> [滴丸剂收入增长31.86%]: 元胡止痛滴丸市场开拓见效，成为营收下滑中的稳定器。
- **[营业外支出1785万元]** -> [侵蚀利润]: 主要为捐赠、滞纳金等，对利润总额影响达22%，削弱了主业盈利的含金量。

## 风险警告
**核心风险：营收与现金流双杀，增长质量存疑。** 公司营收同比下降14.92%，核心产品宣肺止嗽合剂销量下滑22.92%，导致库存激增89%。更严重的是，经营活动现金流净额由正转负，为-653.7万元，与净利润严重背离。这表明利润增长主要依赖子公司业绩承诺兑现和费用压缩，而非主业销售回款的改善，盈利质量堪忧。

**结构性风险：单品依赖与集采悬剑。** 宣肺止嗽合剂和元胡止痛滴丸合计贡献超90%的药品收入，产品结构高度集中。宣肺止嗽合剂面临中药保护期到期后的市场竞争风险，而元胡止痛滴丸保护期已过。同时，中成药集采常态化，公司重点产品虽暂未纳入，但降价压力始终存在，一旦集采，将对价格体系造成冲击。

**治理与关联交易风险：同业竞争承诺悬而未决。** 实际控制人甘肃国投集团旗下佛慈制药与公司存在同业竞争，虽承诺5年内解决，但报告期内未见实质性进展。此外，公司与控股股东及其关联方存在大量日常关联交易（采购、销售、租赁等），交易公允性及对公司独立性的潜在影响需持续关注。
