# 603998.SH 深度透视

## 因果逻辑链
- **[核心产品放量]** -> [净利润增长20%]: 玄七健骨片销量同比+60%，依折麦布片销量同比+61%，高毛利品种占比提升驱动扣非净利润增长28.7%。
- **[集采中标红利]** -> [心脑血管板块收入+19%]: 依折麦布片、厄贝沙坦氢氯噻嗪片等集采品种借助“三进”政策，市场份额快速扩大。
- **[中药创新药获批]** -> [新增长极形成]: 养血祛风止痛颗粒获批上市并纳入2025年医保，成为国内首个频发性紧张型头痛中药创新药。
- **[降本增效]** -> [经营现金流+97%]: 集中采购降低原料成本，销售费用同比-14%，采购付款及营销支出减少，现金流大幅改善。
- **[业务结构优化]** -> [毛利率提升]: 剥离低毛利医药商业业务，聚焦高毛利医药制造（毛利率74.5%），盈利能力持续增强。
- **[研发投入加码]** -> [管线储备丰富]: 研发费用1.54亿（+11%），香芩解热颗粒、紫英颗粒等获临床批件，化药1类创新药IMM-H024引入。
- **[人口老龄化驱动]** -> [骨科用药稳健增长]: 骨质疏松患病率随年龄上升，藤黄健骨片终端覆盖破万家，龙血竭散收入逼近千万。
- **[高分红政策]** -> [股东回报强化]: 全年三次分红合计每股0.45元，分红率64.5%，增强投资者信心。

## 风险警告
**核心风险在于集采降价与新品放量不及预期的双重挤压。** 公司心脑血管板块增长高度依赖集采中标品种，随着集采扩围和价格联动深化，后续续约降价压力将持续侵蚀利润空间。同时，呼吸系统用药受流感周期影响收入骤降47%，暴露了产品组合对季节性波动的脆弱性。

**研发管线的高投入与长周期构成另一重大风险。** 公司研发费用率近9%且全部费用化，但中药创新药从临床到商业化存在巨大不确定性。养血祛风止痛颗粒作为新获批品种，市场培育周期长，短期内难以贡献显著利润。若后续在研品种（如健胃祛痛丸、香芩解热颗粒）临床或审批受阻，前期投入将难以收回，拖累整体业绩。
