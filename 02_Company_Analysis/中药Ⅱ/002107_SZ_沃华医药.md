# 002107.SZ 深度透视

## 因果逻辑链
- **人口老龄化加剧** -> 心脑血管及骨科慢性病用药需求增长: 60岁以上人口占比21.1%，老年人慢性病患病率超78%，推动相关药品需求增长。
- **沃华心可舒片集采降价约39%** -> 以价换量，终端覆盖大幅提升: 降价后进入更多基层和院外市场，终端覆盖数显著增加。
- **以价换量，终端覆盖提升** -> 心脑血管系统药品收入同比增长12.31%: 覆盖增加驱动销量增长，抵消降价影响，实现收入增长。
- **坚持学术推广，四大品种获96项指南共识** -> 临床医生认可度高，处方稳定性强: 学术证据充分，提升医生处方信心，稳定并扩大处方量。
- **四大独家医保支柱产品学术品牌建设** -> 院内市场销售稳定，成为业绩压舱石: 品牌效应巩固院内市场份额，保障基础收入。
- **院内品牌与学术优势向院外延伸** -> 院外市场收入达1.03亿元，电商销售同比增长113%: 借助院内积累的品牌信任度，有效拓展零售和线上渠道。
- **公司推行“一降三增”精细化管理** -> 成本费用有效控制，净利润大幅增长162.93%: 降本增效措施直接提升盈利能力。
- **荷丹片/胶囊切入减肥赛道** -> 电商渠道销售增长115%，有望成为新增长点: 产品调脂减重双重功效契合国家体重管理政策，线上营销高效转化。
- **公司无实际控制人，但董事会治理独立稳定** -> 公司经营决策不受外部强制干扰，保障战略执行: 董事会中心主义确保治理稳定性，支撑长期战略落地。
