# 600671.SH 深度透视

## 因果逻辑链
- **[保健品新品放量]** -> [营收结构优化]: 参类、冬虫夏草等高毛利新品首次创收，推动保健品板块营收增长33.50%，毛利率达82.99%，成为核心利润支柱。
- **[中成药技改提效]** -> [量价齐升]: 黄山天目技改扩能叠加代理商调整提价，六味地黄口服液营收增长52.77%，毛利率提升22.28个百分点，带动中成药板块整体盈利改善。
- **[销售渠道重构]** -> [经销模式爆发]: 新设子公司嘉合医药搭建专业营销团队，核心产品接入经销商网络，经销模式营收同比增长366.95%，毛利率提升18.40个百分点。
- **[风险警示撤销]** -> [治理结构优化]: 公司于2025年5月撤销ST，结束近五年风险警示状态，并取消监事会，形成“两会一层”精简治理架构，为后续融资与业务拓展扫清障碍。
- **[研发项目空窗]** -> [费用结构变化]: 阿莫西林克拉维酸钾片一致性评价完成后，新研发项目尚未启动，研发费用降至零，但管理费用因新增子公司及薪酬增加而上升17.91%。
- **[应收账款激增]** -> [现金流压力]: 为拓展销售渠道，应收账款同比增长48.95%至1.44亿元，虽经营活动现金流净额转正，但回款风险显著上升。
- **[化药产品亏损]** -> [产品结构失衡]: 核心化药阿莫西林克拉维酸钾片因售价下降与成本上升，毛利率为-12.37%，出现亏损，拖累整体盈利能力。

## 风险警告
**核心风险在于应收账款激增与化药板块持续亏损的双重挤压。** 公司为扩张市场导致应收账款同比暴增近50%至1.44亿元，远超营收增速，若下游客户回款不力，将直接侵蚀本已微薄的利润。同时，核心化药产品阿莫西林克拉维酸钾片毛利率为负，显示该业务缺乏竞争力，持续亏损将消耗公司现金流。

**公司造血能力依然脆弱，高度依赖保健品新品放量。** 虽然保健品板块毛利率高达82.99%，但营收增长主要依赖参类、冬虫夏草等新品类，其市场可持续性与竞争壁垒尚待验证。此外，公司研发投入降至零，缺乏后续产品管线，长期增长动力不足。母公司未分配利润仍为-2.08亿元，无法分红，股东回报遥遥无期。
