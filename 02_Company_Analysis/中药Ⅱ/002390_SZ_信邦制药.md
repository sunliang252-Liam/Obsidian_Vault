# 002390.SZ 深度透视

## 因果逻辑链
- **集采政策推行** -> 中成药收入下降26.33%: 集采中选药品价格大幅下降，直接导致中成药收入减少
- **中药饮片业务增长** -> 医药制造收入增长7.64%: 中药饮片业务收入同比增长22.4%，拉动整体医药制造收入增长
- **资信管理加强** -> 医药流通收入下降11.20%: 加强对客户资信管理，对超长账期客户停货清收，影响批发业务规模
- **营业外支出减少** -> 归母净利润增长18.65%: 营业外支出事项较上年度减少，且综合毛利率略有上升，共同推动净利润增长
- **集中带量采购常态化** -> 医药流通利润空间压缩: 集采品种规模增加导致原合作生产厂家未中标而中断产品线，同时配送利润空间被压缩
- **人口老龄化与健康需求增长** -> 医疗服务市场规模扩大: 人口老龄化加深和居民健康意识提升，推动医疗需求持续增长
- **中药饮片集采中选** -> 中药饮片销售增长: 中选集采带来新客户和市场拓展，推动销量增长

## 风险警告
公司面临集采降价压力持续压缩中成药和医药流通利润空间；医药流通业务因资信管理收紧导致收入下滑，需关注应收账款回收风险；医疗服务收入受医保控费影响增长乏力，需警惕床位使用率下降风险。
