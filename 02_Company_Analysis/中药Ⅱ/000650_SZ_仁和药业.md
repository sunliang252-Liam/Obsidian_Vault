# 000650.SZ 深度透视

## 因果逻辑链
- **[营业收入下滑13.21%]** -> [净利润下降18.41%]: 核心OTC药品及大健康产品终端需求疲软，叠加渠道去库存，导致量价齐跌，收入与利润同步承压。
- **[销售费用缩减25.32%]** -> [扣非净利润下降25.51%]: 公司主动压缩渠道推广与营销投入，虽短期节省费用，但直接削弱了市场动销能力，加剧了收入下滑，导致扣非利润降幅大于收入。
- **[资产减值损失1.29亿]** -> [利润总额减少19.43%]: 对药都药业、金衡康等子公司计提大额商誉减值，叠加存货、在建工程减值，一次性侵蚀利润，暴露了前期并购整合与产能规划的低效。
- **[经营活动现金流净额增长52.77%]** -> [现金流与净利润背离]: 主要系支付税费大幅减少，而非经营改善。公司通过压缩采购、减少税负支出优化现金流，但掩盖了真实盈利能力的恶化。
- **[非经常性损益占比高]** -> [利润质量脆弱]: 政府补助（8933万）与金融资产公允价值变动（1.12亿）合计贡献了归母净利润的51%，剔除后主业盈利能力显著下滑，利润结构高度依赖外部输血与投资浮盈。
- **[研发投入仅占营收1.34%]** -> [长期增长动力不足]: 研发费用率远低于行业平均水平，且资本化率下降。新品获批多为仿制药，缺乏创新药布局，在行业向创新驱动转型中面临掉队风险。
- **[募投项目频繁终止/变更]** -> [战略执行力存疑]: 工业大麻、消毒抑菌、女性健康等多个募投项目因市场变化或产能消化风险而终止或结项，大量募集资金永久补流，反映公司对市场趋势判断与投资决策能力不足。

## 风险警告
**核心风险在于主业衰退与利润空心化。** 公司营收与扣非净利润连续两年双降，且降幅扩大，表明其依赖的OTC与大健康基本盘正遭受集采压力、市场竞争加剧及需求疲软的多重冲击。更危险的是，2025年归母净利润中超过一半来自政府补助和炒股收益，主业盈利能力已严重萎缩。一旦外部补贴政策变动或资本市场波动，利润将面临断崖式下跌。

**战略混乱与资产减值风险高企。** 公司多个重大募投项目（工业大麻、消毒抑菌、女性健康）因市场误判而终止或结项，导致大量资金闲置并最终永久补充流动资金，暴露出管理层在产业趋势判断与资本配置上的严重缺陷。同时，高达1.29亿的资产减值损失（主要为商誉）表明，过往并购整合效果不佳，未来若经营环境持续恶化，可能引发更多减值，进一步侵蚀净资产。
