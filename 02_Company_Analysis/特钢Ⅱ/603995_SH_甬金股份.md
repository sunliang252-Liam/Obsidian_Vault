# 603995.SH 深度透视

## 因果逻辑链
- **不锈钢行业供需失衡，价格低迷** -> 归母净利润同比下降32.31%: 2025年300系不锈钢价格持续运行于五年低位，行业供给宽松，传统建筑领域需求疲软，导致公司虽销量增长7.67%但毛利率下降0.76个百分点，利润大幅下滑。
- **产能扩张与新产品投产** -> 销量同比增长，但利润被低价侵蚀: 靖江甬金、越南新越等项目投产使公司冷轧不锈钢产量同比增长8.86%，销量增长7.67%，但产品价格低迷导致增收不增利。
- **财务费用增长（融资增加及汇率波动）** -> 净利润减少: 本期财务费用同比增加26.13%，主因融资总额增加及越南盾贬值汇兑损失，直接侵蚀利润。
- **越南盾贬值** -> 财务费用增加，境外业务利润率下降: 越南盾贬值导致汇兑损失增加，同时境外销售毛利率同比下降5.42个百分点（从8.79%降至3.37%），双重打击利润。
- **存货增加** -> 经营活动现金流净额减少: 存货增加占用资金，导致经营活动现金流净额同比下降4.77%，尽管净利润下降但现金流降幅小于利润降幅。
- **应收账款融资及衍生金融负债公允价值变动** -> 非经常性损益影响利润: 衍生金融负债公允价值变动损失6,712,208.20元，应收款项融资减值1,629,428.95元，合计减少非经常性损益。
- **非流动性资产处置收益大幅减少** -> 非经常性损益下降，拖累净利润: 2025年非流动性资产处置损益仅-2,763,012.39元，而2024年为126,923,908.38元，减少约1.3亿元，导致归母净利润降幅大于扣非净利润降幅。
- **钛材及复合材料业务增长，但利润贡献有限** -> 整体毛利率下降: 其他产品（钛材等）营收增长49.52%，毛利率12.51%高于不锈钢，但占比小（约6%），不足以抵消不锈钢毛利率下滑带来的整体毛利率下降。

## 风险警告
公司面临多重风险：不锈钢行业产能过剩导致价格持续低迷，盈利能力承压；海外业务受汇率波动（特别是越南盾贬值）和贸易摩擦影响，境外毛利率大幅下降；新增产能（靖江、越南）虽释放产量但未带来利润增长，可能存在产能消化风险；财务费用因融资扩张持续上升，进一步挤压利润空间。
