# 600507.SH 深度透视

## 因果逻辑链
- **原料成本跌幅大于钢价跌幅** -> **净利润暴增280%**: 2025年原燃料价格大幅下降，成本端释放的红利远超钢材价格下跌对收入的侵蚀，导致毛利率从3.24%大幅提升至7.24%。
- **弹簧扁钢战略优势凸显** -> **产品结构优化与利润支撑**: 弹簧扁钢销量同比增长22%，毛利率从12.16%跃升至17.67%，成为公司抵御建筑用钢需求下滑、稳定盈利的核心产品。
- **信托产品公允价值变动** -> **非经常性损益大幅增厚利润**: 持有的阳光保险H股相关信托产品净值回升，贡献公允价值变动收益8188万元，而去年同期为亏损1.17亿元，是利润大幅波动的重要非主营因素。
- **建筑用钢需求持续萎缩** -> **螺纹钢量价齐跌**: 全国钢筋产量下降，公司螺纹钢销量同比减少3.61%，收入下降12.16%，反映出房地产行业调整对传统长材产品的持续压制。
- **精细化管理与“赛马”机制** -> **成本竞争力行业领先**: 通过全流程对标、日成本动态管控和全员降本，公司非合金方坯、三级钢筋成本均排名行业前列，在行业下行期有效保护了利润。
- **商用车市场温和复苏** -> **汽车板簧需求回暖**: 2025年重卡销量同比增长27%，带动公司汽车板簧销量增长11.29%，毛利率提升2.27个百分点，为弹簧扁钢下游需求提供了有力支撑。
- **经营活动现金流大幅下降** -> **盈利质量与现金流的背离**: 尽管净利润暴增，但经营性现金流净额同比减少47%，主要系销售商品收到的现金减少，显示利润增长更多依赖成本节约和公允价值变动，而非销售回款的同步改善。

## 风险警告
**核心风险在于盈利的可持续性。** 2025年净利润暴增280%主要得益于原料成本端的大幅让利和金融资产公允价值变动的“天时”，而非自身产品销量或价格的显著提升。一旦铁矿石、焦煤等原料价格反弹，或阳光保险H股股价回调，公司利润将面临巨大压力。公司2026年经营计划中钢材产销量目标（402万吨）低于2025年实际产量（425.92万吨），也暗示管理层对需求前景并不乐观。

**另一重大风险是长期悬而未决的同业竞争问题。** 控股股东方大钢铁承诺将江西萍钢和达州钢铁注入上市公司，但均因条件不满足而一再延期。这两大块资产体量巨大，若最终无法注入或注入条件苛刻，不仅将长期压制公司估值，还可能引发关联交易和利益输送的担忧。此外，公司大量货币资金（28.88%的总资产）被票据保证金等受限，实际可动用现金远低于账面数字，流动性管理需保持警惕。
