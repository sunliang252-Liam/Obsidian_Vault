# 600460.SH 深度透视

## 因果逻辑链
- **[IDM模式产能满载]** -> [营收与利润双增]: 5/6/8/12吋产线满负荷运转，规模效应摊薄固定成本，推动营收增长16.32%，归母净利润大增81.27%。
- **[IPM模块放量]** -> [集成电路业务增长20%]: 白电客户大量采用士兰IPM模块（出货量超2.5亿颗，同比+47%），成为集成电路收入的核心驱动力。
- **[汽车与新能源市场突破]** -> [分立器件增长17%]: 车规级IGBT/SiC模块及器件收入32.73亿元（+43%），成功切入汽车主驱和光伏市场，对冲了低端器件下滑。
- **[SiC产能爬坡]** -> [短期亏损拖累整体利润]: 士兰明镓6吋SiC产线处于爬坡期，高折旧与降价压力导致大额亏损，成为公司盈利的主要拖累项。
- **[高研发投入]** -> [产品结构持续优化]: 8.98%的研发投入占比，支撑车规级模拟电路、32位MCU、MEMS传感器等新品推出，加速向高门槛市场转型。
- **[国产替代加速]** -> [高门槛市场收入占比超80%]: 抓住国内客户导入国产芯片窗口，来自汽车、工业、白电、通讯等市场的收入占比显著提升，增强了客户粘性。
- **[资本开支扩张]** -> [债务与现金流压力]: 为新建12吋模拟线、8吋SiC线等，长期借款激增119.95%，经营活动现金流虽改善，但投资活动现金净流出持续高位。

## 风险警告
**产能扩张与盈利兑现的错配风险。** 公司正同时推进12吋模拟线、8吋SiC线等多个大型资本开支项目，总投资额超百亿。这些项目在建设期和爬坡期将产生巨额折旧与费用，而市场（尤其是SiC）价格竞争激烈，可能导致新产线在短期内难以贡献正利润，甚至加剧亏损，对资产负债表和利润表构成持续压力。

**SiC业务的不确定性。** 士兰明镓的SiC产线是公司未来增长的关键，但目前仍处于亏损状态。SiC芯片市场价格下降幅度较大，而公司成本控制尚在爬坡。若下游新能源汽车、AI算力电源等需求不及预期，或技术迭代落后于竞争对手，SiC业务可能长期无法实现盈利，成为公司的“价值陷阱”。
