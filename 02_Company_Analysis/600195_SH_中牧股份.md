# 600195.SH 深度透视

## 因果逻辑链
- **化药板块量价齐升** -> 营收增长3.11%: 化药板块营收同比+31.33%，7个产品年销破亿，泰妙菌素市占率国内前列，成为收入增长核心引擎。
- **非经常性损益驱动利润暴增** -> 归母净利润同比+141.68%: 持有可转债公允价值变动收益1.10亿元，叠加丧失中普生物控制权确认投资收益0.79亿元，掩盖了主业盈利恶化。
- **扣非净利润大幅下滑** -> 扣非净利润同比-67.42%: 费用及减值同比增加，显示核心经营能力承压，盈利质量显著下降。
- **国际业务强势扩张** -> 国外营收同比+25.98%: 海外市场认可度提升，新市场数量和出口业绩双丰收，成为新增长极。
- **亏损治理成效显著** -> 亏损额同比压降50%以上: 通过“一企一策”精准诊断，强化考核，盘活闲置资产，有效改善资产质量。
- **现金流大幅改善** -> 经营活动现金流净额同比+175.89%: 销售回款增加，应收账款期末余额较期初下降34.42%，运营效率提升。
- **生药板块份额回升** -> 口蹄疫、禽流感疫苗份额重回市场前列: 大单品策略和差异化发展举措见效，扭转了前期下滑趋势。

## 风险警告
**核心风险在于盈利质量与可持续性。** 2025年归母净利润暴增141.68%，但扣非净利润却同比下滑67.42%，两者严重背离。利润增长高度依赖可转债公允价值变动（1.10亿）和资产处置收益（0.76亿）等非经常性损益，主业盈利能力实则疲软。若剔除这些一次性收益，公司实际经营已陷入困境，投资者需警惕“虚胖”的利润表。

**行业竞争与下游景气度风险不容忽视。** 兽药行业头部竞争加剧，公司生物制品板块营收同比下滑9.25%，毛利率亦下降2.69个百分点。同时，下游养殖业价格波动（2025年农产品生产者价格总水平下降3.7%）直接影响公司产品需求和定价能力。若猪周期下行或疫情反复，公司化药和饲料板块的高增长恐难持续，业绩波动风险较大。
