# 300586.SZ 深度透视

## 因果逻辑链
- **[核心产品三聚氯氰量价齐跌]** -> [归母净利润亏损7042万元]: 市场竞争激烈导致销量同比下降9.14%、售价同比下降19.18%，毛利率大幅下滑23.28%，是业绩由盈转亏的根本原因。
- **[计提大额资产减值]** -> [净利润进一步承压]: 基于谨慎性原则，全年计提各项减值准备5585万元（含存货跌价3380万、商誉减值1564万），直接侵蚀利润。
- **[电池隔膜业务放量但亏损]** -> [未能贡献正利润]: 安徽美芯营收同比增长154%，但因销售单价低，仍处于亏损状态，拖累整体业绩。
- **[色母粒业务“增收不增利”]** -> [主业增长乏力]: 销量增长12%，但售价下降9.22%，毛利率微降1.69%，未能对冲精细化工板块的下滑。
- **[财务费用激增]** -> [侵蚀利润]: 因湿法隔膜项目暂缓建设，相关利息费用停止资本化，财务费用同比大增89.52%。
- **[四川美联项目持续投入]** -> [现金流承压]: 新能源及高分子材料产业化项目处于建设期，导致投资活动现金净流出4.29亿元，同比扩大62%。
- **[普鲁士蓝正极材料尚未放量]** -> [新增长点缺失]: 辉虹科技虽建成1000吨/年产能，但尚未实现批量销售，未能形成新的利润支柱。

## 风险警告
**核心风险在于精细化工主业（三聚氯氰）的持续恶化。** 该产品贡献近30%营收，但2025年毛利率暴跌23.28%至-4.2%，已陷入“卖得越多亏得越多”的困境。行业竞争加剧、下游需求疲软，若价格战持续，该业务将成为公司最大的亏损黑洞，并可能引发进一步的商誉减值（营创三征账面商誉7011万元）。

**新能源转型的“双刃剑”风险。** 公司重金押注的电池隔膜（安徽美芯）和普鲁士蓝正极材料（辉虹科技）均处于“增收不增利”或“有产能无订单”的尴尬阶段。四川美联项目（30万吨色母粒）仍在建设，巨额资本开支已导致自由现金流大幅为负。若新能源业务无法在2026年实现盈利突破，公司可能面临传统业务萎缩、新业务持续失血的“青黄不接”局面。
