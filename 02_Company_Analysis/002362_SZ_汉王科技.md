# 002362.SZ 深度透视

## 因果逻辑链
- **[高研发投入与资本化]** -> [持续亏损]: 研发投入占营收16.39%，其中30.56%资本化，但技术成果转化不及预期，导致净利润-1.96亿元，亏损同比扩大77.87%。
- **[AI终端业务增长但毛利率下降]** -> [增收不增利]: AI终端收入增长19.23%，但成本增长24.74%，毛利率下降2.83个百分点，规模效应尚未显现。
- **[多模态大数据业务萎缩]** -> [核心业务承压]: 该业务收入同比下降13.81%，毛利率下降1.13个百分点，显示传统B/G端业务面临竞争加剧和需求疲软。
- **[海外收入增长但汇率风险加剧]** -> [财务费用激增]: 海外收入占比48.44%且增长11.27%，但汇兑收益大幅减少，导致财务费用从-2129万激增至893万，同比增141.94%。
- **[资产减值损失大幅增加]** -> [利润侵蚀]: 资产减值损失从-975万扩大至-4300万，主要是存货跌价准备计提增加，反映产品更新换代快、库存管理压力大。
- **[经营活动现金流由正转负]** -> [造血能力恶化]: 经营现金流净额从3186万转为-3754万，同比下降217.82%，表明公司盈利质量差，运营效率下降。
- **[短期借款大幅增加]** -> [财务杠杆上升]: 短期借款从1.43亿增至2.87亿，增长100%，公司依赖借贷维持运营，财务风险显著上升。

## 风险警告
公司连续三年亏损且亏损额持续扩大，2025年净利润-1.96亿元，经营活动现金流净流出3754万元，造血能力严重不足。核心问题在于高额的研发投入（3.1亿）和销售费用（5亿）未能有效转化为收入和利润，AI终端业务虽增长但毛利率下滑，多模态大数据业务萎缩，传统优势业务面临天花板。公司依赖短期借款维持现金流，财务杠杆急剧上升，偿债压力加大。

技术商业化风险尤为突出。公司研发投入资本化率高达30.56%，若未来技术成果转化持续不及预期，将面临大额资产减值风险。同时，存货跌价准备大幅增加至3328万元，显示产品迭代快、库存管理压力大。海外业务占比近半，汇率波动和地缘政治风险（如关税冲突）将直接冲击公司盈利能力。公司目前不满足现金分红条件，股东回报前景黯淡。
