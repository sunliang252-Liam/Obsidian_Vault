# 002947.SZ 深度透视

## 因果逻辑链
- **[AI终端创新浪潮]** -> [精密柔性结构件收入增长16.30%]: AI手机/PC对散热、电磁屏蔽、轻薄化要求提升，公司精密模切技术精准匹配新需求，推动核心产品量价齐升。
- **[AI算力基础设施扩张]** -> [精密金属结构件收入增长9.38%]: 全球AI服务器出货量高速增长，公司为头部客户提供机柜、液冷等精密金属件，受益于数据中心资本开支扩张。
- **[“以销定产”+高效供应链]** -> [经营活动现金流暴增153.15%]: 公司根据订单安排生产，强化应收款回收，叠加收入增长，现金循环效率显著提升，现金流质量远超净利润。
- **[多元化战略布局]** -> [客户集中度高达77.29%]: 公司聚焦智能终端、数通、新能源三大领域，但前五大客户销售额占比极高，业绩高度依赖少数头部品牌客户。
- **[研发投入持续加码]** -> [技术壁垒与产品附加值提升]: 研发费用增长16.12%，聚焦无气泡贴膜、高折射率OCA、自动化检测等工艺，巩固了在高端精密结构件领域的技术护城河。
- **[惠州智能制造基地建设]** -> [资本开支与产能扩张]: 募投项目持续推进，在建工程转固，长期借款增加，为未来数通与新能源业务放量储备产能，但短期带来折旧与财务费用压力。
- **[汇率波动]** -> [财务费用由负转正]: 2025年财务费用同比暴增101.68%，主因外币汇率波动导致汇兑损失，对以美元结算为主的境外业务（占收入64.88%）构成直接冲击。

## 风险警告
**客户高度集中与单一供应商依赖风险。** 公司前五大客户销售占比高达77.29%，其中第一大客户占比36.30%，且前五大供应商中第一大供应商采购占比高达33.98%。这种“大客户+大供应商”的双重集中格局，使公司议价能力受限，任何核心客户流失或供应商断供都将对经营造成毁灭性打击。

**汇率波动与财务费用失控风险。** 公司境外收入占比高达64.88%，主要以美元结算。2025年财务费用因汇率波动从-5290万元骤增至887万元，波动幅度超100%。在美联储降息预期反复、地缘政治复杂的背景下，若人民币汇率出现不利变动，将直接侵蚀公司本就微薄的利润空间（净利率约18.6%）。

**募投项目不及预期与产能消化风险。** 公司正大规模投资“惠州恒铭达智能制造基地”，但项目尚未投产，且下游AI硬件和新能源行业竞争激烈、技术迭代极快。若项目投产延迟，或市场需求增速放缓，新增产能将面临无法充分消化的风险，导致资产回报率下降。
