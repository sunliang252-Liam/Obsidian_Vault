# 920273.BJ 深度透视

## 因果逻辑链
- **[魔芋原料价格大幅上涨]** -> [毛利率骤降6.66个百分点]: 成本增速(30.80%)远超收入增速(19.91%)，直接侵蚀利润空间，导致增收不增利。
- **[魔芋粉单价提升 & 魔芋食品销量增长]** -> [营收增长19.91%]: 有效的市场推广策略提升了客户对魔芋健康价值的认知，驱动了量价齐升。
- **[原材料采购策略调整（降低采购量）]** -> [存货减少28.69%，经营现金流大幅转正]: 主动应对原料涨价，减少资金占用，叠加销售回款增加，使经营现金流从-6868万飙升至1.97亿。
- **[子公司一致嘉纤由盈转亏]** -> [拖累合并净利润]: 原料成本冲击与下游竞争加剧，导致核心子公司亏损322.77万元，成为利润下滑的重要构成。
- **[魔芋美妆业务关停]** -> [剥离亏损业务，聚焦主业]: 因市场变化持续亏损，公司果断关停魔芋绵车间，减少不确定性，集中资源于魔芋粉和食品核心业务。
- **[股权激励费用摊销]** -> [管理费用增加]: 2024年启动的股权激励计划在2025年产生股份支付费用，推高了管理费用，对净利润形成额外压力。
- **[境外收入占比30%]** -> [面临汇率与贸易政策双重风险]: 外销以美元/欧元结算，汇率波动及美国等市场关税壁垒提升，构成海外业务的不确定性。
- **[产品结构单一（魔芋粉收入占比69.65%）]** -> [经营风险集中]: 公司业绩高度依赖魔芋粉，若市场偏好变化或出现替代品，将对经营造成重大冲击。

## 风险警告
**核心风险是“成本失控”与“利润压缩”。** 魔芋原料价格大幅上涨是2025年业绩变脸的根本原因。公司作为中间加工商，对上游原料价格缺乏有效对冲手段，成本增速显著快于收入增速，导致毛利率从26.65%骤降至19.99%，净利润同比下降23.05%。若原料价格持续高位或波动加剧，公司盈利能力将面临持续侵蚀。

**第二重风险是“产品单一”与“子公司亏损”的结构性困境。** 魔芋粉收入占比近70%，业务高度集中，抗风险能力弱。同时，核心子公司一致嘉纤由盈转亏，表明公司在产业链不同环节的布局并未有效分散风险，反而在成本冲击下形成共振。此外，魔芋美妆业务的关停也暴露了公司在新业务拓展上的试错成本。
