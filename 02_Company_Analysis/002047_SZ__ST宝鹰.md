# 002047.SZ 深度透视

## 因果逻辑链
- **[重大资产出售剥离亏损资产]** -> [净利润扭亏为盈]: 2024年12月完成宝鹰建设100%股权出售，剥离持续亏损主体，使2025年归母净利润转正至5920万元。
- **[出售资产获取非经常性收益]** -> [扣非净利润仍亏损]: 出售旦华复能股权及成霖工业区房地产，合计贡献约9100万元非经常性收益，但主业萎缩导致扣非净利润仍亏损3219万元。
- **[传统建筑业务大幅收缩]** -> [营收断崖式下滑]: 剥离宝鹰建设后，公司营收从21.1亿元骤降至6.59亿元，降幅68.81%，仅保留宝鹰建科及少量建筑工程业务。
- **[客户高度集中]** -> [经营依赖单一关联方]: 前五大客户销售占比85.71%，其中关联方珠光集团贡献68.97%营收，公司业务对单一客户存在严重依赖。
- **[光耦合器新业务尚处初创期]** -> [第二增长曲线未形成]: 2025年12月设立澜兴科技切入光耦产业，截至报告期末未产生营收，新业务转型存在重大不确定性。
- **[控股股东变更与定增]** -> [控制权与资本结构重塑]: 世通纽拟通过协议转让+定增成为新控股股东，募集8亿元用于补充流动资金，但定增尚需审核，存在不确定性。

## 风险警告
公司2025年净利润扭亏为盈完全依赖资产出售等非经常性损益，扣非净利润仍亏损3219万元，核心建筑装饰业务营收暴跌86.53%，主营业务造血能力已近枯竭。新切入的光耦合器业务尚处试验期，无技术、人才储备，与现有业务无协同，短期内难以形成有效利润贡献，公司面临主业空心化与转型失败的双重风险。

公司当前经营高度依赖关联方珠光集团（贡献近70%营收），且控股股东即将变更为世通纽。世通纽承诺未来三年扣非净利润合计不低于4亿元，但该承诺主要依赖尚未投产的光耦及硅基新业务，实现难度极大。若定增失败或新业务不及预期，公司净资产仅5079万元，将再次面临资不抵债的退市风险。
