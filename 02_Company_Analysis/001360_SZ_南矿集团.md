# 001360.SZ 深度透视

## 因果逻辑链
- **[金属价格上行]** -> [矿山资本开支增加]: 金、铜等金属价格大幅上涨（金价涨超70%，铜价涨超40%），直接带动全球矿业资本开支同比提升18%以上，推动下游矿企扩产与新建项目加速落地，从而拉动破碎筛分设备需求。
- **[“三转一优”战略转型]** -> [矿山与海外订单高速增长]: 公司主动从砂石骨料市场转向金属矿山和海外市场，2025年矿山订单同比增长94.4%至4.86亿元，海外订单同比增长119.9%至2.82亿元，有效对冲了国内砂石骨料市场萎缩（订单下降57.8%）带来的负面影响。
- **[后市场业务拓展]** -> [收入结构优化与客户粘性增强]: 后市场订单三年复合增长9.01%，配件销售和运维服务收入合计占比提升至29.16%，参考美卓53.53%的运维收入占比，公司后市场业务仍有巨大增长空间，且能提升客户全生命周期价值。
- **[大型集成设备与海外业务放量]** -> [营收增长但利润承压]: 大型集成设备收入同比大增99.51%，境外收入同比大增105.48%，驱动总营收增长6.76%。但高增长业务毛利率偏低（境外毛利率下降7.96个百分点），叠加资产减值损失（-1958万元，其中特定项目存货减值1776万元），导致归母净利润同比下降15.49%。
- **[下游砂石骨料市场持续萎缩]** -> [倒逼公司战略转型]: 全国砂石需求量从2015年176.94亿吨降至2025年126.99亿吨，公司砂石骨料订单从2023年4.76亿降至2025年2.01亿，迫使公司主动转向矿山和海外市场，并优化骨料订单结构（工程骨料占比从12.11%提升至37.13%）。
- **[子公司江西智矿贡献显著利润]** -> [集团整体盈利的重要支撑]: 江西智矿（电气设备）2025年实现净利润2296万元，占集团归母净利润的45.9%，成为公司重要的利润来源，体现了公司在自动化领域的布局成效。

## 风险警告
**现金流恶化与应收账款高企是核心风险。** 2025年经营活动现金流净额仅752.6万元，同比骤降84.26%，而同期归母净利润为4997万元，利润与现金流的严重背离揭示出回款压力巨大。应收账款高达5.28亿元，占总资产22.15%，且公司已明确将“应收账款管理”提升至“现金流生命线”的高度，侧面印证了该问题的严峻性。若下游客户（尤其是大型国企和海外客户）付款周期进一步拉长或出现坏账，将直接冲击公司流动性，甚至可能引发债务偿付风险。

**战略转型期的“增收不增利”与资产减值风险并存。** 公司向矿山和海外市场转型虽带来订单高增，但新业务毛利率尚不稳定（境外毛利率下降7.96个百分点），且大型集成设备等新业务模式可能伴随更高的履约成本和交付风险。更值得警惕的是，报告期内资产减值损失高达1958万元，其中因特定项目客户原因无法履行合同，导致存货计提减值1776万元，公司已就此提起诉讼。这暴露了公司在项目风险评估和合同管理上的潜在漏洞，若未来类似事件频发，将持续侵蚀公司利润。
