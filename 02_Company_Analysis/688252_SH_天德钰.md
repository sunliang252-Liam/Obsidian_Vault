# 688252.SH 深度透视

## 因果逻辑链
- **[电子价签驱动芯片全球市占率第一]** -> [营收结构优化]: 电子价签、摄像头音圈及快充协议芯片收入同比大增52.90%，占总营收比重提升，弥补了显示驱动芯片收入下滑(-10.32%)的影响。
- **[四色电子价签规模化量产]** -> [市场份额提升]: 公司率先实现四色电子纸驱动芯片量产，成为全球市场重要提供者，驱动ESL芯片市场份额全球第一。
- **[显示驱动芯片价格竞争加剧]** -> [净利润下滑15.05%]: 尽管营收微增4.17%，但显示驱动芯片业务收入下滑，叠加销售费用（特许权使用费）大增88.20%，导致归母净利润同比下降。
- **[光罩会计估计变更（费用化）]** -> [利润减少]: 公司将光罩由资本化改为费用化处理，导致2025年净利润减少约1,424.72万元，体现了技术迭代加速下会计政策的审慎调整。
- **[外销收入高增32.52%]** -> [经营现金流改善]: 外销收入大幅增长，销售商品收到的现金增加，带动经营活动现金流净额同比大增105.11%至2.81亿元。
- **[Fabless模式依赖上游]** -> [供应链风险]: 公司采用无晶圆厂模式，晶圆制造和封装测试依赖外部供应商，前五大供应商采购额占比高达86.80%，存在供应链集中风险。
- **[研发投入持续增长17.14%]** -> [技术护城河]: 研发费用同比增长17.14%至2.06亿元，重点投向AMOLED、多色电子价签及快充协议芯片，为未来产品迭代和竞争力提供支撑。

## 风险警告
**核心风险在于显示驱动芯片业务的持续承压与盈利能力的下滑。** 尽管公司电子价签业务表现亮眼，但占营收大头的移动智能终端显示驱动芯片收入同比下降10.32%，且行业竞争加剧导致产品价格承压。同时，销售费用因特许权使用费激增88.20%，严重侵蚀利润，导致公司“增收不增利”，净利润同比下滑15.05%。若显示驱动芯片市场景气度未能回升，公司整体盈利水平将面临持续挑战。

**另一重大风险来自供应链高度集中与汇率波动。** 公司采用Fabless模式，前五大供应商采购额占比高达86.80%，晶圆产能的周期性波动或供应中断将直接影响公司经营稳定性。此外，公司超75%的收入来自外销，以美元结算为主，人民币汇率的大幅波动将带来显著的汇兑损失风险，对利润稳定性构成威胁。
