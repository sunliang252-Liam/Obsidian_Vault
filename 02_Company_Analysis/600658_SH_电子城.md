# 600658.SH 深度透视

## 因果逻辑链
- **[产业园区市场持续调整，地产销售承压]** -> [营业收入同比-44.76%]: 地产销售业务收入同比暴跌77.18%，是营收大幅下滑的直接原因。
- **[地产销售毛利率大幅下滑]** -> [整体毛利率恶化]: 地产销售毛利率从52.48%骤降至21.91%，导致整体毛利率下降25.6个百分点。
- **[基于谨慎性原则计提大额资产减值]** -> [净利润巨亏-18.49亿]: 全年资产减值损失高达12.52亿元，是亏损的最主要来源。
- **[融资成本下降]** -> [财务费用同比-5.91%]: 公司通过发行低息债券置换存量债务，有效降低了利息支出。
- **[支付税费减少及收回保证金]** -> [经营性现金流大幅转正]: 经营活动现金流净额从-6.04亿大幅转正至+2.58亿，现金流状况改善。
- **[其他权益工具投资公允价值上升]** -> [其他综合收益大幅增加]: 持有的燕东微等上市公司股权公允价值上升，贡献了2.08亿元的其他综合收益。
- **[终止天津西青募投项目]** -> [募集资金永久补流]: 公司终止三个天津募投项目，将8.73亿元剩余募集资金永久补充流动资金，反映区域市场风险。
- **[科技服务转型投入增加]** -> [管理费用维持高位]: 尽管营收下滑，管理费用仅下降9.57%，显示公司为转型持续投入资源。

## 风险警告
公司当前最核心的风险是**资产价值持续缩水与巨额减值**。2025年资产减值损失高达12.52亿元，是导致-18.49亿巨亏的直接原因。在产业园区市场持续下行、空置率高企、租金承压的背景下，公司大量存货（开发产品）和投资性房地产面临进一步减值的风险。资产负债率已攀升至70.48%，净资产因连续两年巨亏而大幅缩水28.24%，财务安全垫正在被快速侵蚀。

其次，**主营业务造血能力严重不足**。地产销售业务收入暴跌77%，毛利率腰斩，表明公司核心的“卖房”模式已难以为继。虽然公司正全力向“科技服务”转型，但新型科技服务业务毛利率仅5.92%，且收入规模尚无法弥补地产销售的缺口。公司连续两年亏损，且母公司未分配利润已转负，未来分红能力基本丧失，对长期投资者的回报预期构成重大打击。
