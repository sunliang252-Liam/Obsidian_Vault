# 002600.SZ 深度透视

## 因果逻辑链
- **[AI硬件需求爆发]** -> [营收增长16.20%]: 公司作为全球AI终端高精密功能件龙头，受益于AI手机、折叠屏、AI服务器等下游需求增长，带动核心零部件及模组出货量提升。
- **[人形机器人赛道卡位]** -> [打造第N增长曲线]: 公司战略定位全球TOP3具身智能硬件制造商，已为多家头部企业完成数千套硬件/整机组装，并取得世界人形机器人运动会“两金一铜”，抢占先发优势。
- **[外延并购切入高价值领域]** -> [汽车业务从Tier2升级为Tier1]: 收购浙江向隆（传动系统）和江苏科达（内外饰），新增高价值零部件产品，汽车业务收入同比增长39.56%，毛利率提升7.9个百分点。
- **[收购立敏达(Readore)]** -> [切入北美算力核心供应链]: 快速获得AI服务器液冷（液冷板、快接头、分水器）及电源（母线排）等核心产品，成为北美算力头部客户核心供应商，打开千亿级市场空间。
- **[海外工厂盈利能力改善]** -> [境外销售增长18.95%]: 海外工厂收入大幅增长，境外销售毛利率提升0.2个百分点，成为整体利润增长的重要驱动力。
- **[精益生产“9883”专项]** -> [综合良率提升约3.2%]: 通过数据驱动的精益管理，确立98%良率目标，落地改善项目8,281件，节省工时约884万小时，有效降低制造成本，提升盈利能力。
- **[研发投入持续加大]** -> [技术壁垒加固]: 研发费用同比增长19.65%，在车铣复合、五轴加工、3D打印等机器人前沿工艺上实现多场景落地，累计获得专利2,004项，巩固行业领先地位。

## 风险警告
**核心风险在于新业务放量节奏与盈利能力的不确定性。** 公司人形机器人、AI服务器液冷等新业务尚处商业化早期，收入贡献有限，且面临技术路线迭代快、客户认证周期长、竞争对手涌入等挑战。若新业务订单不及预期或毛利率持续承压，将拖累整体估值与利润表现。

**财务风险不容忽视。** 公司2025年财务费用同比暴增1,272.48%，主要系汇率波动导致的汇兑损失增加，暴露出海外业务占比高（73.43%）带来的汇率敞口风险。同时，投资活动现金净流出同比扩大120.62%，主要因并购及资本开支增加，若并购标的整合不及预期或产能利用率不足，将导致资产减值风险（2025年资产减值损失已达5.07亿元）。此外，短期借款同比大幅增长，需关注债务结构及流动性压力。
