# 688696.SH 深度透视

## 因果逻辑链
- **[产品结构优化与成本管控]** -> [毛利率提升]: 公司推进研发创新和供应链提质增效，长焦投影毛利率同比增加6.75个百分点，带动整体毛利率提升。
- **[精细化运营降费]** -> [净利润增长19.40%]: 全面强化精细化运营，销售费用同比下降13.84%，在营收微增1.85%的情况下，扣非净利润增长23.99%。
- **[车载光学业务量产交付]** -> [创新产品收入爆发]: 车载产品并入创新产品线，收入同比大增107.86%，但尚处产能爬坡期，导致该品类毛利率仅4.45%。
- **[B端业务拓展与结算模式]** -> [经营现金流大幅转负]: B端业务逐步交付产生收入，但受行业客户结算惯例影响，销售回款周期延长，导致经营现金流净额同比-141.30%。
- **[海外市场拓展]** -> [境外收入增长]: 坚定实施品牌出海，海外线上亚马逊、独立站渠道收入快速增长，境外收入同比增长2.53%，毛利率达42.60%。
- **[核心零部件依赖]** -> [供应链风险]: 公司全部采用TI生产的DMD器件，若半导体供应紧张或价格不利调整，将对生产经营产生重大不利影响。
- **[股权激励费用]** -> [管理费用增加]: 股份支付费用增加导致管理费用同比增长28.99%，但扣除股份支付影响后的净利润同比增长126.94%。

## 风险警告
**核心风险在于经营现金流急剧恶化与B端业务盈利能力的矛盾。** 公司2025年经营现金流净额由正转负，骤降至-0.95亿元，主因是B端业务（车载、行业显示）回款周期长。虽然车载业务已实现从0到1的量产交付，但创新产品毛利率仅4.45%，远低于传统长焦投影的32.87%。这意味着公司在用低毛利、长账期的业务换取增长，若后续无法快速提升规模效应和回款效率，将严重侵蚀公司现金储备。

**另一重大风险是核心零部件依赖与行业竞争加剧的双重挤压。** 公司DLP投影核心成像器件DMD完全依赖美国德州仪器（TI），地缘政治或供应链波动可直接导致停产。同时，智能投影市场竞争白热化，平板电视大屏化持续冲击，公司若不能持续推出差异化高端产品，将面临市场份额下降和产品降价的风险。此外，公司存货账面价值高达9.14亿元，占总资产16%，若市场需求不及预期，存货减值风险不容忽视。
