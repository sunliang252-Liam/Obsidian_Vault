# 600292.SH 深度透视

## 因果逻辑链
- **[重大资产重组落地]** -> [归母净利润同比大增1379.91%]: 2025年10月完成水电资产注入，五凌电力与长洲水电成为核心盈利来源，但追溯调整后同比下降34.07%，因重组剥离了湖南省外新能源资产。
- **[沅水流域来水偏枯]** -> [水电发电量同比下降1.60%]: 来水整体偏枯且分布不均，导致水电发电量144.46亿千瓦时，但通过优化调度水能利用率提升8%，部分对冲了来水不足的影响。
- **[电力市场化改革深化]** -> [上网电价下行压力持续]: 新能源全面参与市场交易，现货市场全覆盖，水电、新能源电价处于下行趋势，盈利模式面临重构。
- **[环保板块工程业务亏损]** -> [环保业务利润总额同比减少90.09%]: 环保工程业务产值下滑，叠加鲲鹏项目及装备公司应收款项计提减值准备，导致环保板块盈利大幅萎缩。
- **[重组过程中剥离湖南省外新能源资产]** -> [营业收入同比下降15.90%]: 置出资产导致收入规模缩减，同时财务费用因剥离高息负债而下降33.43%。
- **[国家电投集团承诺注入其他水电资产]** -> [未来资产规模与盈利增长预期]: 承诺在交易完成后3年内，将集团下属其他水电资产陆续注入上市公司，打开长期成长空间。
- **[长洲水利枢纽来水偏丰]** -> [发电量同比增长10.35%]: 广西区域来水偏丰及上游调度影响，长洲水电发电利用小时达5276.93小时，成为利润“稳定器”。

## 风险警告
**核心风险在于来水不确定性叠加电价下行。** 公司水电业务高度依赖沅水流域来水，2025年来水偏枯已导致发电量下降，而电力市场化改革深化使水电、新能源上网电价持续承压。若来水持续偏枯与电价下行叠加，将直接侵蚀公司核心利润。同时，环保板块传统业务竞争激烈、盈利薄弱，新兴业务尚未形成稳定贡献，整体抗周期能力有限。

**整合与转型风险不容忽视。** 重大资产重组后，电力与环保两大板块在管理体系、人员配置上的深度融合需持续推进，存在短期整合不及预期的风险。此外，公司“三步走”战略（2026年打基础、2028年大提升、2030年创一流）依赖集团资产持续注入与新能源项目顺利开发，若项目收益不及预期或合规手续滞后，战略落地将面临挑战。
