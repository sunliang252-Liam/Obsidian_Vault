# 000591.SZ 深度透视

## 因果逻辑链
- **[电力市场化改革深化，电价下行]** -> [营收与利润双降]: 新能源全面入市，公司平均售电含税均价同比下降17.1%，叠加限电率升至15.91%，导致光伏发电板块收入下滑1.4%，拖累整体业绩。
- **[光伏制造行业产能过剩与价格战]** -> [制造板块营收暴跌63.72%]: 组件、电池片销量与单价同步大幅下滑，镇江子公司亏损1.02亿元，成为利润最大拖累项。
- **[国补回收大幅增加]** -> [经营性现金流暴增118.72%]: 报告期内收回电费补贴33.18亿元（同比+142.9%），推动经营现金流净额达41.33亿元，远超净利润，改善财务质量。
- **[运营装机规模持续扩张]** -> [发电量增长20.14%]: 运营电站规模同比增长18.01%至7.17GW，带动总售电量增至83.69亿千瓦时，部分对冲了电价下跌的影响。
- **[可转债成功发行]** -> [资本结构优化与项目资金保障]: 募资29.5亿元，为在建及拟建项目（如察布查尔1GW光伏项目）提供资金，同时降低短期偿债压力。
- **[非技术成本高企与资产减值]** -> [侵蚀利润]: 土地费用等非技术成本上升，叠加制造端技术迭代，公司计提固定资产及存货减值损失2.2亿元，占利润总额19.65%。
- **[绿证与绿电交易增长]** -> [环境价值变现渠道拓宽]: 绿证销售量142.7万张，平均售价同比增长52.76%，绿电交易电量5.69亿千瓦时，成为新的收入增长点。

## 风险警告
**核心风险在于电价下行与消纳困境的长期化。** 随着新能源全面入市，公司平均电价已降至0.583元/千瓦时（含税），市场化交易电价更是低至0.2345元/度。限电率攀升至15.91%，且未来电力供需失衡可能进一步加剧。公司2025年营收与利润目标完成率分别仅为94.24%和62.67%，显示经营环境恶化速度远超预期，盈利能力的结构性下滑趋势尚未见底。

**制造业务的持续失血是第二大风险。** 光伏行业产能过剩与技术迭代（N型替代P型）导致公司制造板块营收暴跌63.72%，毛利率仅剩2.09%，子公司镇江公司亏损超1亿元。公司虽提出向“轻资产运营”转型，但在行业出清完成前，该板块将持续拖累整体业绩，并面临存货与固定资产进一步减值的风险。
