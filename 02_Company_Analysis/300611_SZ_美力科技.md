# 300611.SZ 深度透视

## 因果逻辑链
- **[悬架系统弹簧订单放量]** -> [营收增长25.48%]: 悬架弹簧及稳定杆作为核心产品，受益于客户新平台项目量产，销量同比增长32.15%，带动营收突破20亿元。
- **[产品结构优化与精益制造]** -> [毛利率提升3.21个百分点]: 高附加值产品占比提升，叠加自动化产线、供应链协同等精益改善措施，有效控制综合制造成本。
- **[德国AHLE资产整合]** -> [海外业务收入暴增117.26%]: 依托德国美力本地化运营及AHLE的技术与渠道，实现海外业务高效协同，海外收入占比从9.54%跃升至16.51%。
- **[供应链管理强化]** -> [经营性现金流净额增长125.53%]: 通过优化供应商管理、更多采用票据背书支付，运营周转效率提升，现金流达3.01亿元，远超净利润。
- **[ACPS并购签署]** -> [拓宽业务边界与客户协同]: 收购汽车牵引与保护系统隐形冠军ACPS，切入大众、奔驰、宝马等全球头部车企供应链，实现“弹簧+ACPS”双轮驱动。
- **[战略投资普畅、迅铂]** -> [布局空气悬架与具身机器人]: 通过投资强化空气悬架研发一体化，并前瞻布局精密弹性元件在具身机器人领域的应用，培育未来增长点。
- **[墨西哥基地建设推进]** -> [完善全球化供应体系]: 在北美核心市场布局生产基地，贴近客户提升交付效率，为2026年降本增效及开拓北美市场奠定基础。

## 风险警告
**核心风险在于ACPS跨境并购后的整合与协同不及预期。** 公司2026年营收目标（50亿元）较2025年（20.12亿元）翻倍有余，几乎完全依赖ACPS的并表贡献。然而，跨境并购在业务衔接、文化融合、关键人才稳定及供应链整合方面存在巨大挑战。若整合节奏失当或协同效应无法释放，不仅目标落空，还将拖累现有主业，导致商誉减值风险。

**其次，原材料价格波动与行业竞争加剧是持续威胁。** 弹簧钢材成本占比高，若价格大幅上涨而无法向下游传导，将直接侵蚀毛利率。同时，汽车零部件行业价格竞争激烈，若公司不能在技术、成本和服务上持续领先，可能面临市场份额丢失和项目盈利水平下降的压力。此外，多基地运营（国内+德国+墨西哥）对集团化管控能力提出极高要求，管理半径扩大带来的内控风险不容忽视。
