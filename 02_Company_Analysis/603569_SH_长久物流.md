# 603569.SH 深度透视

## 因果逻辑链
- **整车运输运价持续承压** -> 整车业务毛利率下降4.10个百分点: 运价未回归合理区间，导致收入增速低于成本增速，毛利率下降
- **国际业务受地缘政治和政策变动影响** -> 国际业务收入下降24.48%: 外部环境不确定性导致业务量和价格下降
- **新能源业务拓展不及预期且前期成本偏高** -> 新能源业务盈利能力受冲击: 市场拓展进度慢，电芯等原材料采购成本偏高，导致利润贡献有限
- **行业竞争加剧且运价承压** -> 公司净利润亏损8,737万元: 核心业务毛利率下降，叠加新能源亏损和国际业务下滑，导致整体亏损
- **政府收储及处置船舶** -> 投资活动现金流净额大幅增加236.89%: 资产处置带来现金流入
- **计提事故损失增加** -> 预计负债余额增加125.64%: 安全事故导致预计负债计提增加

## 风险警告
1. 整车运价持续低迷及行业竞争加剧，可能导致核心业务毛利进一步压缩。2. 国际业务受地缘政治和政策变动影响较大，存在不确定性。3. 新能源业务拓展不及预期，前期投入成本高，可能继续拖累利润。4. 负债率50.80%，短期借款和应付账款增加，流动性压力需关注。
