# 600572.SH 深度透视

## 因果逻辑链
- **[核心大单品肠炎宁系列放量增长]** -> [营收韧性]: 肠炎宁全年销售收入达10.8亿元，同比增长20%，抵消了其他药品制剂收入下降的影响，使总营收仅微降0.64%。
- **[药品制剂收入下降及资产减值计提]** -> [利润大幅下滑]: 药品制剂营收同比下降4.28%，叠加计提资产减值准备6519.80万元（含珍视明等长期股权投资减值），导致归母净利润同比下降23.79%。
- **[所持亿腾嘉和股票公允价值变动]** -> [非经常性损益波动]: 报告期持有亿腾嘉和股票产生浮盈6402.33万元，同比增加3375.48万元，成为利润的重要调节项。
- **[销售费用率维持高位]** -> [利润侵蚀]: 销售费用20.23亿元，同比增长5.60%，占营收比例高达31.25%，高强度的市场推广投入持续压缩利润空间。
- **[特色健康消费品与原料药业务增长]** -> [业务结构优化]: 健康消费品收入7.2亿元（+10%），原料药盐酸大观霉素出口额同比增长127%，成为对冲传统药品下滑的新增长极。
- **[中药材饮片业务稳健增长]** -> [全产业链优势]: 中药材饮片业务实现收入11.67亿元，同比增长4%，在浙江省内医院终端市场保持较高份额，体现了从种植到终端的全链条管控能力。
- **[研发投入聚焦中药创新与仿制药]** -> [产品管线储备]: 研发投入2.69亿元（占营收4.15%），获批中药新药2个、仿制药8个，为未来产品迭代和市场竞争提供支撑。

## 风险警告
**核心风险在于利润端的持续承压与增长动力的单一化。** 公司2025年归母净利润同比大降23.79%，扣非净利润更是下滑27.67%，主要源于药品制剂收入下降和一次性资产减值。尽管肠炎宁大单品表现亮眼，但公司整体营收已连续两年下滑，过度依赖单一产品（肠炎宁占营收近17%）的格局并未改变，一旦该产品遭遇集采或竞争加剧，业绩将面临巨大冲击。

**政策与市场双重压力不容忽视。** 医药行业集采常态化、医保控费及价格治理持续深化，公司化学药板块收入已同比下降7.90%，毛利率亦在下滑。同时，高达31.25%的销售费用率在行业政策趋严（如合规监管）的背景下，存在进一步压缩利润或面临合规风险的可能。此外，公司持有的金融资产（如亿腾嘉和股票）公允价值变动对利润影响显著，增加了业绩的不可预测性。
