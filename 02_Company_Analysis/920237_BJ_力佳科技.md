# 920237.BJ 深度透视

## 因果逻辑链
- **[出口退税率下调]** -> [毛利率下降3.81个百分点]: 2024年12月起出口退税率由13%降至9%，直接压缩境外销售毛利空间，境外毛利率同比下降6.68个百分点。
- **[市场竞争加剧]** -> [营收下降8.54%]: 境内销售同比下滑27.55%，拖累整体营收，境外销售虽有增长但未能完全弥补。
- **[募投项目转固]** -> [折旧增加，成本刚性上升]: 新一代高性能锂原电池产业化项目建成转固，固定资产增加，折旧费用推高营业成本。
- **[政府补助减少]** -> [净利润额外承压]: 其他收益（主要为政府补助）同比减少1041万元，占净利润降幅的34.7%。
- **[汇率波动与理财结构调整]** -> [财务费用大幅减少]: 新增持有至到期大额存单利息收入增加，叠加汇兑损失扩大，财务费用同比减少94.72%。
- **[存货跌价准备增加]** -> [资产减值损失扩大90%]: 结合库龄及可变现净值，计提存货跌价准备增加，侵蚀利润。
- **[控股子公司资产毁损]** -> [营业外支出激增388.91%]: 常州力泰非流动资产及存货毁损报废，导致营业外支出增加135万元。

## 风险警告
**核心风险：出口退税完全取消的毁灭性冲击。** 公司境外收入占比高达66%，是利润的主要来源。根据政策，电池产品出口退税率将在2027年1月1日从当前的9%降至0%。这意味着，若无法将成本完全转嫁给客户，公司境外业务的毛利率将直接损失约9个百分点，对净利润的冲击将是灾难性的。公司当前毛利率仅29%，退税取消后，境外业务可能陷入盈亏边缘。

**次要风险：业绩下滑趋势尚未见底。** 2025年营收、净利润双双下滑，且净利润降幅（-42.6%）远超营收降幅（-8.5%），显示盈利能力正在加速恶化。境内市场萎缩、政府补助退坡、存货减值压力增大，多重负面因素叠加。公司虽提及拓展高毛利市场，但短期难以对冲退税取消和竞争加剧的双重打击，2026年业绩大概率继续承压。
