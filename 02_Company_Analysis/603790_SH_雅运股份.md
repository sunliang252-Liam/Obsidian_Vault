# 603790.SH 深度透视

## 因果逻辑链
- **[海外业务扩张]** -> [营收结构优化]: 海外营收同比增长超10%，占比近25%，成为核心增长点，弥补了国内营收下滑。
- **[差异化竞争策略]** -> [毛利率提升]: 聚焦中高端细分品类和头部客户，通过技术服务带动产品销售，毛利率同比提升3.05个百分点。
- **[产品结构优化]** -> [盈利能力增强]: 主动削减低毛利助剂产品，聚焦高竞争力核心产品，助剂毛利率同比提升4.02个百分点。
- **[成本控制与供应链管理]** -> [营业成本下降]: 营业成本同比下降7.61%，降幅大于营收降幅，主要得益于原材料成本下降及生产运营效率提升。
- **[汇率波动]** -> [财务费用激增]: 人民币汇率下降导致汇兑损失增加，财务费用同比上升80.50%，侵蚀部分利润。
- **[蒙克科技产品落地]** -> [新增长点培育]: 智染通、智染云SaaS实现规模化落地，构建标杆客户群，为未来业绩增长奠定基础。
- **[产能利用率不足]** -> [资产效率风险]: 主要生产基地产能利用率普遍偏低（科法曼染料62%，震东新材料37%），存在资产闲置和折旧压力。

## 风险警告
**核心风险在于国内需求疲软与产能利用率低下的双重挤压。** 公司营收同比下降3.37%，主要源于国内华东、华南等核心市场收入下滑，而海外业务的增长尚不足以完全对冲。同时，主要生产基地产能利用率普遍偏低（如震东新材料仅37%），大量固定资产无法产生足额收益，持续产生折旧压力，是资产回报率偏低的核心原因。

**财务风险方面，存货激增与汇率波动是两大隐患。** 存货账面价值同比大增24%至4.65亿元，占总资产26%，且公司已计提1663万元资产减值损失。若下游需求持续不振或原材料价格下跌，存货跌价风险将进一步暴露。此外，财务费用因汇兑损失同比暴增80.5%，显示公司对汇率风险的对冲能力不足，在人民币波动加剧的背景下，利润稳定性面临挑战。
