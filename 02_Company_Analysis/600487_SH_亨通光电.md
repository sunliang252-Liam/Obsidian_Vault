# 600487.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [光纤光缆量价齐升]: AI数据中心对高带宽光纤（G.654.E、多模、空芯）需求激增，叠加光棒产能受限，推动光纤价格自2025年末起大幅上涨，公司作为光棒-光纤-光缆全产业链龙头直接受益。
- **[全球海上风电加速]** -> [海洋能源订单高增]: 欧洲、亚洲海上风电装机目标大幅上调，公司凭借海缆、风机安装、运维全产业链能力，持续中标国内外项目，在手订单约200亿元，驱动海洋能源业务增长。
- **[深海科技国家战略]** -> [海洋通信业务壁垒强化]: 公司是全球仅有的四家具备跨洋海缆系统集成能力的企业之一，受益于全球海缆更新换代及AI跨洋算力传输需求，在手订单约70亿元，技术壁垒极高。
- **[全球电网投资周期]** -> [智能电网与特高压业务增长]: 欧美电网老化改造及新兴市场电网建设启动，叠加国内“十五五”特高压投资规划，公司特高压导线、高压电缆等产品海外市场突破，国内份额稳固。
- **[铜导体产能扩张]** -> [营收规模大幅增长]: 公司能源传输材料铜导体产能提升，带动该业务收入同比增长33.83%，成为营收增长的主要驱动力之一，但毛利率极低（1.45%），对利润贡献有限。
- **[股份支付费用增加]** -> [净利润短期承压]: 2025年公司实施股权激励和员工持股计划，股份支付费用同比增加1.42亿元（+127%），导致归母净利润同比微降3.2%，但扣非净利润基本持平，显示主业盈利能力稳定。
- **[全球化产能布局]** -> [海外收入快速增长]: 公司在欧洲、东南亚、南美等地拥有12个海外产业基地，海外收入同比增长29.85%，有效对冲国内市场竞争，并提升品牌全球影响力。

## 风险警告
**核心风险在于海洋业务订单交付的不确定性及原材料价格波动。** 公司海洋能源与通信业务在手订单合计约270亿元，但项目周期长、涉及跨国施工，受地缘政治、海上天气、工程进度等因素影响大，收入确认节奏可能不及预期。同时，铜、铝等大宗商品价格波动剧烈，尽管公司使用套期保值工具，但极端行情仍可能侵蚀智能电网、铜导体等业务的微薄利润。

**另一风险是光通信行业周期性及技术迭代风险。** 当前光纤涨价周期由AI需求驱动，但若AI资本开支放缓或光棒产能快速释放，供需格局可能逆转。此外，公司在空芯光纤、CPO等前沿技术领域虽已布局，但商业化进程和市场竞争格局尚不明朗，若技术路线切换不及预期，可能影响长期竞争力。公司资产负债率较高，且经营活动现金流净额同比下降13.93%，需关注其财务稳健性。
