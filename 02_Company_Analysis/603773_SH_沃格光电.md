# 603773.SH 深度透视

## 因果逻辑链
- **[传统显示业务稳健增长]** -> [营收增长14.88%]: 光电玻璃精加工业务收入同比增长28.49%，显示器件业务增长7.10%，共同驱动总营收达25.51亿元。
- **[新兴业务战略投入期]** -> [净利润亏损1.58亿元]: 玻璃基MiniLED和TGV泛半导体业务处于产能爬坡与客户验证阶段，新增折旧摊销及研发费用高企，导致持续亏损。
- **[在建项目转固与折旧]** -> [管理费用增长24.36%]: 江西德虹、湖北通格微等项目陆续转固，新增设备及厂房折旧摊销费用大幅增加，侵蚀利润。
- **[资产减值损失扩大]** -> [净利润进一步承压]: 报告期计提资产减值损失6,944万元，同比增加71.65%，主要系存货跌价及长期股权投资减值，加剧亏损。
- **[经营性现金流改善]** -> [现金流净额增长67.10%]: 经营活动现金流净额达2.12亿元，主要得益于政府补助、火灾理赔款及保证金收回，现金流质量优于利润表现。
- **[玻璃基MiniLED量产突破]** -> [产品供货海信、追觅]: 玻璃基MiniLED背光产品在MNT显示器实现批量商用，并与海信、追觅等品牌合作，验证技术产业化能力。
- **[TGV技术送样验证]** -> [泛半导体业务尚处早期]: 湖北通格微在光模块/CPO、先进封装等领域处于批量送样阶段，营收规模极小，尚未贡献利润。

## 风险警告
公司面临的核心风险在于**新兴业务产业化进程严重不及预期**。玻璃基MiniLED和TGV泛半导体业务虽已取得技术突破和客户验证，但营收贡献极低，且持续产生巨额折旧与研发费用。若下游客户导入周期延长或市场需求释放缓慢，公司将持续面临“增收不增利”甚至亏损扩大的困境，对现金流和资产负债表构成长期压力。

此外，**财务风险不容忽视**。公司资产负债率较高，担保总额占净资产比例达75.79%，且一年内到期的非流动负债同比增加54.25%，短期偿债压力较大。同时，公司因信息披露问题多次受到监管警示，暴露出内部治理与合规管理存在短板，可能影响市场信心与再融资能力。
