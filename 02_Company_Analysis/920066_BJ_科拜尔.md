# 920066.BJ 深度透视

## 因果逻辑链
- **[下游家电行业需求承压]** -> [营收增长停滞]: 2025年营收仅增0.09%，与上年基本持平，核心下游家电市场国内外双承压，增量空间受限。
- **[市场竞争加剧导致产品售价下降]** -> [毛利率下滑]: 毛利率从17.41%降至15.59%，公司为保住市场份额主动降价，但原材料成本传导滞后，利润空间被压缩。
- **[募投项目转固及数字化改造]** -> [管理费用激增55%]: 年产5万吨项目厂房转固、管理及制造系统数字化改造服务费增加，叠加管理人员扩充，管理费用从944万升至1463万。
- **[研发与人才持续投入]** -> [研发费用增长13.43%]: 研发费用增至1981万元，重点投向汽车用新材料、功能色母料等，但短期未能转化为利润增量。
- **[票据贴现减少]** -> [经营性现金流大幅转负]: 经营活动现金流净额从2595万降至-1937万，主因货币资金充裕后减少票据贴现，导致现金流入减少。
- **[客户高度集中]** -> [议价能力受限]: 前五大客户（长虹、双鹿上菱、惠而浦、美的、TCL）贡献72.21%营收，下游巨头强势，公司成本传导存在滞后周期。
- **[CPP产品市场渗透定价]** -> [长期毛利率偏低]: 为解决冰箱“胆裂”痛点开发的CPP产品，采取低价渗透策略，虽提升市占率但拉低了整体毛利率水平。

## 风险警告
**核心风险：增收不增利，盈利质量恶化。** 2025年营收持平，但净利润暴跌41.7%，ROE从20.11%骤降至7.27%。毛利率下滑、管理费用与研发费用刚性增长、信用减值损失扩大三重压力叠加，表明公司正处于“以价换量”的被动阶段，盈利能力已出现实质性滑坡。若下游家电需求持续疲软或原材料价格进一步上涨，利润可能继续承压。

**结构性风险：客户集中度过高，议价权薄弱。** 前五大客户占比超72%，且均为美的、TCL等家电巨头。公司作为上游材料商，在激烈竞争中缺乏定价话语权，成本无法有效传导。同时，公司高度依赖家电单一行业，汽车等新领域拓展尚处“试料”阶段，短期难以形成第二增长曲线，业务结构脆弱性显著。
