# 002670.SZ 深度透视

## 因果逻辑链
- **[吸收合并完成，聚焦证券主业]** -> [净利润同比增长63.05%]: 公司吸收合并国盛证券，财务报表口径转为金融企业，证券主业盈利能力直接体现，归母净利润从1.67亿增至2.73亿。
- **[市场交投活跃，经纪业务量价齐升]** -> [手续费及佣金净收入增长24.10%]: 2025年A股市场回暖（上证+18.41%），公司经纪业务手续费净收入同比增长22.42%，成为收入增长核心引擎。
- **[融资融券规模扩张]** -> [信用业务收入增长36.68%]: 两融余额同比增长27.92%，带动利息净收入增长27.29%，信用业务成为第二大利润贡献板块。
- **[研究所品牌优势巩固]** -> [研究业务收入与利润双增]: 在公募降费背景下，研究所凭借行业领先的投研能力（建筑团队16年第一、计算机5年第一），实现逆势增长。
- **[投资收益大幅下滑]** -> [拖累整体营收增速]: 金融工具投资收益减少及趣店股权核算方式变更，导致投资收益同比下降42.31%，是营业总收入仅增长2.29%的主因。
- **[公允价值变动亏损扩大]** -> [侵蚀利润]: 交易性金融工具公允价值变动收益由-0.44亿扩大至-1.26亿，对净利润形成显著负向冲击。
- **[信用减值损失转回]** -> [增厚利润]: 金融资产减值转回1.89亿元（去年同期计提0.95亿），是净利润增速远超营收增速的关键因素。
- **[国资股东持续赋能]** -> [资本实力与融资能力增强]: 控股股东江西交投提供次级债务及融资担保，公司净资本达90.37亿元，风险覆盖率322.11%，为业务扩张提供安全垫。

## 风险警告
**核心风险在于业绩对市场行情的过度依赖与投资收益的剧烈波动。** 公司经纪、信用、自营业务均与A股市场高度相关，2025年净利润大增主要受益于市场回暖，但投资收益同比骤降42.31%、公允价值变动亏损扩大至1.26亿元，暴露出自营业务在震荡市中抗风险能力不足。一旦市场转弱，业绩将面临双重挤压。

**历史遗留问题与合规风险不容忽视。** 雪松信托业绩补偿承诺至今未履行，公司虽已申请强制执行但进展缓慢，涉及金额巨大。同时，报告期内多家营业部因合规问题被监管警示，反映出内部管理存在薄弱环节。此外，公司商誉高达29.79亿元，占净资产26.3%，若未来业绩不达预期，存在减值风险。
