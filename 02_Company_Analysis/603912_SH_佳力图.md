# 603912.SH 深度透视

## 因果逻辑链
- **[上游原材料涨价+市场竞争加剧]** -> [毛利率下滑]: 铜管、钢材等核心原材料及机电部件采购成本上升，叠加行业竞争，挤压了精密空调等主营产品的盈利空间。
- **[销售及研发投入持续增加]** -> [费用侵蚀利润]: 为拓展数据中心客户和市场，销售费用增加；为布局液冷、高效散热等新技术，研发费用同比增长10.45%，当期投入尚未完全转化为收入。
- **[楷德数据中心项目转固]** -> [阶段性亏损]: 子公司楷德悠云数据中心项目部分资产转固，前期运营费用已发生但客户尚未完全进驻，导致项目出现阶段性亏损，拖累合并报表。
- **[财务费用大幅增长]** -> [利润进一步承压]: 楷德数据中心项目转固后，借款利息由资本化转为费用化，导致财务费用同比暴增402.80%，直接侵蚀净利润。
- **[客户集中度高]** -> [业绩依赖通信运营商]: 公司主要客户为中国电信、中国移动、中国联通，若其投资周期变化或招标策略调整，公司业绩将受较大影响。
- **[产品结构变化]** -> [综合毛利率下降]: 毛利率较低的机房环境一体化产品收入下降38.15%，而毛利率较高的代维服务成本上升23.90%，产品结构变化拖累整体盈利水平。
- **[经营活动现金流净额为负]** -> [资金压力显现]: 报告期内经营活动现金流净额为-9211万元，主要系票据兑付所致，显示公司回款或支付压力增大。

## 风险警告
公司2025年由盈转亏，核心风险在于“增收不增利”的困境加剧。上游原材料涨价与下游运营商集采压价的双重挤压，导致主营业务毛利率持续下滑。同时，公司为抢占智算中心液冷等新赛道，大幅增加销售与研发投入，但投入产出周期较长，短期内难以对冲成本压力。更关键的是，楷德数据中心项目转固后，利息费用化导致财务费用飙升，叠加项目自身处于培育期，形成“亏损+费用”的双重打击，现金流也由正转负，财务健康度显著恶化。

此外，公司客户高度集中于三大电信运营商，议价能力受限，且面临维谛、世图兹等国际品牌以及国内同行的激烈竞争。公司在液冷、风墙等新产品的市场拓展尚处于初期，能否成功转化为订单并实现盈利，存在较大不确定性。若宏观经济下行导致下游IDC投资放缓，或原材料价格持续高位，公司业绩将面临进一步下滑风险。
