# 300976.SZ 深度透视

## 因果逻辑链
- **[新能源业务爆发]** -> [业绩增长引擎]: 新能源结构与功能性组件业务收入同比增长57.39%，规模效应释放，成为公司营收和利润增长的核心驱动力。
- **[消费电子业务稳健]** -> [基本盘稳固]: 消费电子业务收入同比增长11.43%，通过深化大客户战略和“老客户新产品”策略，有效对冲了个别客户需求波动。
- **[战略并购维斯德]** -> [轻量化材料布局]: 通过收购碳纤维企业维斯德，快速构建“玻纤-碳纤”一体化解决方案，精准切入端侧AI轻量化结构件市场，打开未来增长空间。
- **[大客户战略深化]** -> [客户份额提升]: 紧密围绕Apple、Meta、宁德时代、比亚迪等头部客户需求，实现核心项目量产和新品突破，客户份额持续提升。
- **[智能制造与精益管控]** -> [成本效率优化]: 依托ERP、MES等系统构建数据驱动的成本管控体系，提升生产效率和原材料利用率，对冲原材料价格波动和行业竞争压力。
- **[研发投入与技术创新]** -> [技术壁垒构筑]: 研发费用同比增长16.86%，累计拥有380项知识产权，聚焦材料创新和工艺突破，保障产品技术领先性。
- **[全球化产能布局]** -> [应对产业转移风险]: 设立泰国和香港子公司，推进全球化产能布局，服务客户东南亚本地化配套需求，增强风险抵御能力。

## 风险警告
**核心风险在于新能源业务的高增长能否持续，以及消费电子业务的复苏力度。** 公司新能源业务收入占比已超43%，且增速高达57.39%，但该业务毛利率（17.66%）显著低于消费电子业务（27.23%），且面临动力电池行业价格竞争加剧和原材料价格波动的双重压力。若新能源业务增长放缓或盈利能力下降，将对公司整体业绩造成重大冲击。同时，消费电子行业虽呈复苏态势，但3C智能装配自动化设备业务收入同比大幅下降42.27%，显示该细分市场需求疲软，公司需警惕消费电子业务增长动能不足的风险。

**客户集中度高及贸易摩擦风险不容忽视。** 公司前五大客户销售占比接近50%，且深度嵌入全球头部供应链，对Apple、Meta、宁德时代等核心客户依赖度较高。若主要客户经营状况或业务结构发生重大变化，或国际贸易摩擦进一步加剧导致客户转移供应链，将对公司经营产生重大不利影响。公司虽已布局海外产能，但全球产业转移的节奏和效果仍存在不确定性。
