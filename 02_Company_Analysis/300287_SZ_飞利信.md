# 300287.SZ 深度透视

## 因果逻辑链
- **[客户预算收缩与项目延期]** -> [营收暴跌40.52%]: 政府及企事业单位客户财政紧张，导致项目招标减少、在建项目交付及验收延迟，直接冲击收入确认。
- **[主动收缩高风险项目]** -> [物联网与智能化业务收入骤降54.08%]: 公司为控制履约风险，主动放弃部分回款周期长、毛利率低的系统集成项目，导致该板块收入腰斩。
- **[降本增效与人员优化]** -> [期间费用大幅缩减]: 销售费用(-41.60%)、研发费用(-32.00%)、管理费用(-18.05%)同步下降，但降幅远小于收入降幅，未能扭转亏损局面。
- **[持续大额资产减值]** -> [净利润连续三年为负]: 报告期计提资产减值及信用减值损失合计约4468万元，叠加营收萎缩，导致归母净利润亏损1.57亿元，连续第三年亏损。
- **[现金流持续净流出]** -> [经营活动现金流恶化]: 经营性现金流净额为-2233万元，同比恶化44.47%，反映回款能力弱于成本支出，运营资金压力加剧。
- **[应收账款高企与诉讼缠身]** -> [资金链承压]: 应收账款高达4.23亿元，且多起大额合同纠纷诉讼处于执行或破产清算阶段，回款不确定性极高，部分银行存款被冻结。
- **[研发聚焦AI与新产品]** -> [产品化转型初见端倪]: 研发投入聚焦“利智方”、AI降噪模组、低空经济等新方向，旨在从项目型向产品平台化转型，但短期尚未贡献显著营收。

## 风险警告
公司正深陷“营收萎缩-持续亏损-现金流枯竭”的恶性循环。2025年营收同比暴跌40.52%，连续第三年巨额亏损，且经营性现金流净流出扩大至-2233万元。核心业务“物联网与智能化”收入腰斩，暴露出公司主动收缩项目后，尚未找到足以支撑规模的新增长点。更严峻的是，高达4.23亿元的应收账款回收困难，多起重大诉讼涉及破产清算方，叠加超6000万元银行存款被冻结，公司资产质量和流动性风险极高。

转型前景高度不确定。公司虽积极布局AI、低空经济等热门赛道，但研发投入大幅削减32%，且研发人员流失超三分之一（-35.66%），核心人才储备出现裂痕。新业务从技术研发到规模化营收仍需时日，而旧有业务持续失血，公司面临“青黄不接”的断档风险。若应收账款无法有效回收、新业务无法快速贡献利润，公司持续经营能力将面临严峻考验。
