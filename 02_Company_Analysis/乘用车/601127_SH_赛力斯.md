# 601127.SH 深度透视

## 因果逻辑链
- **[高端化产品结构优化]** -> [毛利率提升与利润总额增长50.86%]: 问界品牌成交均价提升至39.1万元，高端车型（M9、M8）热销，带动新能源汽车毛利率同比增加2.55个百分点，在研发与销售费用大幅增长背景下仍实现利润总额74.7亿元。
- **[研发高强度投入与平台化开发]** -> [大单品持续成功]: 研发费用79.5亿元（+42.4%），依托魔方技术平台2.0，实现问界M9、M8、M7、M5 Ultra四款车型快速迭代上市，在50万、40万、30万元级SUV市场均获销量冠军，验证了体系化大单品打造能力。
- **[“产业大脑+超级工厂”数智制造]** -> [资产运营效率显著优于传统车企]: 资产周转率达1.38，远超传统车企（0.5-0.73），以AI赋能的智能制造体系支撑了高端车型的规模化敏捷交付（单月最高超5万辆）与质量一致性。
- **[发行股份购买龙盛新能源与H股上市]** -> [财务结构根本性改善]: 归母净资产从122.6亿元跃升至409.2亿元（+233.64%），资产负债率从87.38%降至70.91%，货币资金增至872.9亿元，实现从“租赁经营”到“资产自持”的跃升，并打通国际融资通道。
- **[与华为深度协同的“1+2+N”生态]** -> [智能化技术领先与品牌势能确立]: 联合开发ADS 4.0智驾系统与鸿蒙座舱，问界品牌NPS值蝉联行业第一，高端新能源SUV市场份额超20%，将技术优势转化为品牌认知与市场壁垒。
- **[增程器市场份额第一]** -> [传统动力技术向新能源高效迁移]: 自研第五代超级增程系统，增程器市场份额达37.5%，将传统燃油车时代的动力技术积累转化为新能源领域的核心成本与性能优势。
- **[销售费用高投入与专属专营渠道建设]** -> [品牌价值与用户价值双提升]: 销售费用241.9亿元（+26.1%），建成380家用户中心覆盖218城，实现从“被动服务”到“智慧服务”的转变，支撑了高端品牌形象的持续巩固。

## 风险警告
**核心风险在于行业竞争白热化与盈利可持续性的双重压力。** 尽管公司2025年利润总额增长50.86%，但归母净利润同比仅微增0.18%，扣非净利润甚至下滑7.84%。这揭示了在研发（+42.4%）和销售费用（+26.1%）大幅扩张的背景下，公司盈利能力的实际增长远低于营收增速。当前高端新能源市场尚未形成稳定格局，问界面临来自外资品牌（如外资A）和自主品牌（如自主A、B）的激烈份额争夺，任何产品迭代节奏的放缓或营销投入的边际效用递减，都可能迅速侵蚀利润空间。

**供应链高度集中与海外业务脆弱性是结构性隐患。** 前五名供应商采购额占比高达58.31%，其中对华为（深圳引望）的关联采购额达223.35亿元，占年度采购总额13.46%。这种深度绑定在带来技术优势的同时，也构成了极高的单一依赖风险。同时，公司海外业务营收同比下降43.32%，毛利率仅16.26%，远低于国内业务，且面临地缘政治、关税壁垒等不确定性，全球化战略的落地效果尚待验证。
