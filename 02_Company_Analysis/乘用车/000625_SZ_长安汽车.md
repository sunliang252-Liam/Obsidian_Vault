# 000625.SZ 深度透视

## 因果逻辑链
- **[新能源销量爆发式增长]** -> [营收微增2.67%]: 新能源销量突破111万辆（+51.1%），但燃油车基盘承压，整体营收仅小幅增长。
- **[行业价格战与营销投入激增]** -> [归母净利润暴跌44.34%]: 销售费用同比大增32.56%，侵蚀利润，导致扣非净利润仅增8.03%时，归母净利润却大幅下滑。
- **[缩短供应商账期]** -> [经营性现金流腰斩62.15%]: 为贯彻国家政策，加速支付供应商款项，导致经营活动现金净额从48.5亿骤降至18.4亿。
- **[合资板块利润贡献萎缩]** -> [投资收益大幅下滑]: 长安福特因销量下滑利润减少，联营企业投资收益下降，成为拖累整体利润的关键因素。
- **[研发投入资本化率提升]** -> [短期利润调节]: 研发投入资本化比例从35.96%升至43.08%，资本化金额增长48.29%，在一定程度上平滑了当期利润。
- **[海外工厂投产与渠道扩张]** -> [海外销量增长18.85%]: 泰国罗勇工厂投产，海外渠道网点新增750余家，支撑出口量达63.7万辆。
- **[L3级自动驾驶准入]** -> [智能化品牌溢价]: 获中国首块L3级自动驾驶专用号牌，推动“天枢智能”品牌落地，为高端车型（如阿维塔）提供技术背书。
- **[深蓝汽车持续亏损]** -> [拖累合并报表]: 核心新能源子公司深蓝汽车全年亏损8.99亿元，尽管销量增长44.4%，但尚未实现盈利，持续消耗母公司资源。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司新能源转型初见成效，销量突破百万，但代价是销售费用率飙升和价格战下的利润侵蚀。归母净利润暴跌44%至40.75亿，而扣非净利润仅微增8%，表明主业盈利能力并未随规模同步提升。更严峻的是，经营性现金流大幅萎缩62%，反映出供应链资金压力加剧，财务健康度亮起红灯。

**第二重风险来自合资板块的持续失血与新兴业务的巨额投入。** 长安福特利润贡献下滑，传统利润支柱动摇。同时，深蓝汽车年亏近9亿，阿维塔虽销量破12万但仍需持续输血。公司计划2026年投资144.7亿元，其中长期股权投资高达100亿，主要用于新能源品牌和电池产能建设。这种“以燃油车利润补贴新能源亏损”的模式，在行业竞争白热化阶段，一旦燃油车基盘失守，将引发严重的现金流危机。
