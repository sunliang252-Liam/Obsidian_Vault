# 601238.SH 深度透视

## 因果逻辑链
- **[自主品牌销量大幅下滑]** -> [营收与毛利承压]: 自主品牌（传祺、埃安）全年销量60.92万辆，同比下滑22.83%，直接导致整车制造业务收入下降12.57%，毛利率由正转负至-7.35%。
- **[合资品牌利润贡献骤降]** -> [投资收益腰斩]: 广汽本田因新能源转型计提产线减值及人员优化，叠加合资企业整体销量下滑，全年投资收益仅32.67亿元，同比减少55.36%。
- **[价格战与销售投入加大]** -> [费用率恶化]: 为应对激烈市场竞争，公司加大新车型上市及国际化广告宣传、物流仓储投入，销售费用同比增长8.75%，进一步侵蚀利润。
- **[资产减值计提增加]** -> [净利润由盈转亏]: 因销量不及预期及产品结构调整，公司对无形资产和存货计提大额减值，叠加广汽本田产线减值，导致全年归母净利润巨亏87.84亿元。
- **[经营活动现金流大幅转负]** -> [财务弹性恶化]: 销量下降导致经营性现金流入锐减，全年经营活动现金流净流出150.26亿元，较上年同期减少259.45亿元，现金及等价物减少151.33亿元。
- **[研发投入资本化率高]** -> [未来摊销压力]: 全年研发投入77.07亿元，资本化率高达85.05%，大量开发支出转为无形资产，未来摊销将长期压制利润表。
- **[海外业务高速增长]** -> [第二曲线初现]: 自主品牌海外终端销量约12.5万辆，同比增长48%，境外收入增长44.99%，成为对冲国内下滑的重要增量。

## 风险警告
广汽集团正经历“合资利润崩塌”与“自主造血不足”的双重打击。核心风险在于，合资品牌（广汽本田、广汽丰田）作为过去利润支柱，正加速被中国品牌挤压，其转型阵痛（产线减值、人员优化）仍在持续，投资收益短期内难以恢复。同时，自主品牌（传祺、埃安）在极度内卷的市场中未能实现规模与利润的正向循环，销量下滑导致固定成本无法摊薄，毛利率转负，造血能力严重不足。

更严峻的挑战在于现金流与资产质量的恶化。经营活动现金流净流出150亿元，表明公司已无法通过主营业务创造现金，需依赖融资（短期借款增加47%）和减少分红来维持运营。此外，高达85%的研发投入资本化率，以及因产品迭代加速而持续计提的资产减值，均预示着未来利润表将持续承压。公司虽提出“番禺行动”等变革计划，但能否在2026年扭转颓势，仍面临巨大的市场不确定性。
