# 300984.SZ 深度透视

## 因果逻辑链
- **[全球轴承巨头供应链外包]** -> [营收增长8.70%]: 舍弗勒、斯凯孚等国际客户将核心工序外包，公司承接更多加工工序，推动轴承套圈收入增长8.36%。
- **[新产线投产未达产，折旧高企]** -> [毛利率承压]: 高速锻件智能制造项目2025年4月竣工，但尚未完全达产，制造费用同比增加36.67%，导致主营业务毛利率仅14.20%。
- **[股份支付费用激增]** -> [管理费用大增39%]: 2024年限制性股票激励计划在本报告期确认大额股份支付费用，叠加职工薪酬和折旧摊销增加，管理费用从4908万升至6822万。
- **[可转债利息减少+汇兑收益]** -> [财务费用骤降87%]: 可转债转股或到期导致利息支出减少，叠加人民币汇率波动带来的汇兑收益，财务费用从1454万降至187万。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比87.75%，其中单舍弗勒一家占比47.85%，任何主要客户订单波动都将对业绩产生重大影响。
- **[新业务布局（丝杠/绝缘轴承）]** -> [未来增长点但具不确定性]: 公司利用轴承套圈技术积累，布局行星滚柱丝杠、绝缘轴承套圈等新产品，但报告期内收入占比极小，尚处验证或小批量阶段。
- **[向特定对象发行A股]** -> [摊薄即期回报]: 公司2025年度向特定对象发行A股已获注册，发行完成后将摊薄每股收益，公司为此暂不进行2025年度利润分配。

## 风险警告
**客户集中度与毛利率双重挤压风险。** 公司对前五大客户（尤其是舍弗勒）的依赖度极高（87.75%），单一客户订单的波动即可引发业绩剧烈震荡。同时，新产线投产后折旧高企，导致主营业务毛利率长期处于14%的低位，若产能利用率无法快速提升或原材料价格无法有效传导，毛利率存在进一步下滑风险，侵蚀本已微薄的利润空间。

**新业务拓展的不确定性风险。** 公司积极布局的丝杠零部件和绝缘轴承套圈业务，目前收入占比极小，且绝缘轴承套圈尚未形成收入。这些新业务的技术路线、市场接受度及客户验证周期均存在重大不确定性。公司为此暂停2025年度分红以推进再融资，若新业务发展不及预期，将无法弥补对股东回报的短期缺失，并可能拖累公司整体估值。
