# 600756.SH 深度透视

## 因果逻辑链
- **[客户端资金紧张与项目延期]** -> [营收暴跌38.2%]: 地方政府财政预算收紧，导致项目招标延期、交付验收延迟，直接造成数字政府收入下降55.2亿元。
- **[营收大幅下滑]** -> [净利润巨亏2.67亿]: 收入从18.7亿骤降至11.6亿，但管理费用、研发费用等刚性支出仅微降，成本刚性导致利润由盈转亏。
- **[营收下滑幅度大于成本]** -> [毛利率恶化]: 营收下降38.2%，而营业成本仅下降34.0%，导致综合毛利率下降4.15个百分点，侵蚀利润空间。
- **[销售费用逆势增长]** -> [侵蚀利润]: 在营收大幅下滑背景下，销售费用反增17.3%，主要系人力费用增加，显示公司为维持市场地位被迫加大投入。
- **[存货激增82.6%]** -> [资金占用加剧]: 项目未达验收节点导致存货从2.6亿飙升至4.8亿，大量资金沉淀在未完工项目中，加剧现金流压力。
- **[合同负债增长49.7%]** -> [未来收入蓄水池]: 回款但未完工项目增加，合同负债从3.9亿增至5.8亿，预示部分收入将在未来确认，但同时也反映交付能力滞后。
- **[向特定对象发行股票]** -> [筹资现金流大幅转正]: 成功募资2.73亿元，使筹资现金流从-946万跃升至3.22亿，缓解了经营现金流为负的燃眉之急。
- **[经营活动现金流改善]** -> [回款管理见效]: 尽管仍为净流出4660万，但较上年同期-2.88亿大幅改善83.8%，表明公司加强应收账款催收取得一定成效。

## 风险警告
**核心风险在于政府客户支付能力与意愿的持续恶化。** 公司营收高度依赖地方政府财政投入，2025年“客户端资金紧张”已导致营收暴跌38%、由盈转亏。若地方财政持续承压，项目招标、验收、回款周期将进一步拉长，公司可能陷入“收入萎缩-现金流紧张-被迫削减研发/销售投入-竞争力下降”的恶性循环。存货和合同负债的同步激增，正是这一风险的直接体现。

**第二重风险是“增收不增利”的结构性困境。** 公司在营收腰斩的情况下，管理费用和研发费用仅微降4%-7%，销售费用甚至逆势增长17%，反映出人力成本、研发投入等刚性支出难以快速调整。这种成本结构使得公司对收入波动的容忍度极低，一旦收入无法恢复增长，亏损将成为常态。此外，应收账款高达9.3亿，信用减值损失仍达4300万，坏账风险不容忽视。
