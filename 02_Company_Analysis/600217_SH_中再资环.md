# 600217.SH 深度透视

## 因果逻辑链
- **[废电处理补贴政策大幅缩减]** -> [2025年归母净利润巨亏5.85亿元]: 2025年国家废电处理专项资金总额从上年75亿骤降至50亿，公司2024年确认的专项资金收入与实际分配金额存在巨大差异，该差额计入2025年，直接导致业绩由盈转亏。
- **[废电拆解业务毛利率骤降25个百分点]** -> [核心业务盈利能力崩溃]: 废电拆解物业务收入同比下降26.34%，但成本仅下降5.99%，导致毛利率从正转负（-16.63%），补贴减少叠加成本刚性，业务陷入亏损。
- **[应收账款占总资产61.45%]** -> [现金流高度依赖补贴回款]: 尽管经营活动现金流净额大增251.79%至12.27亿元，但主要系收到历史欠款，公司运营资金仍被巨额应收账款严重占用，流动性持续紧张。
- **[工业废弃物及深加工业务量萎缩57%]** -> [第二增长曲线未能对冲主业下滑]: 该业务产销量大幅下降，收入同比减少6%，毛利率仅3.74%，无法弥补废电拆解业务的巨大亏损。
- **[商誉减值计提2535万元]** -> [前期并购资产价值缩水]: 因部分子公司经营恶化，公司计提商誉减值准备，进一步侵蚀利润。
- **[资产负债率仍高达50.8%]** -> [财务杠杆风险未消]: 尽管偿还了大量短期借款，但长期借款增加，整体负债率仍处高位，财务费用虽下降但仍达7370万元。

## 风险警告
公司当前最大风险是**政策依赖症与补贴断崖**。废电处理补贴是公司生命线，但2025年专项资金总额骤降，且未来年度预算（2026年47.5亿元）仍为上年执行数的95%，补贴大幅缩减已成定局。公司核心的废电拆解业务毛利率已跌至-16.63%，完全丧失造血能力，若补贴无法恢复或公司无法找到新的盈利模式，持续亏损将不可避免。

其次，**巨额应收账款回收存在高度不确定性**。截至2025年末，应收账款高达35.78亿元，占总资产61.45%，且部分补贴资金尚未拨付到位。虽然当期现金流改善，但这只是历史欠款的“回光返照”。一旦补贴拨付节奏放缓或出现坏账，公司将面临严重的流动性危机，甚至可能触发债务违约。公司已明确表示“流动资金持续紧缺”，并因此取消分红。
