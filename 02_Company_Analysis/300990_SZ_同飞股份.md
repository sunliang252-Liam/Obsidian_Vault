# 300990.SZ 深度透视

## 因果逻辑链
- **储能温控业务爆发** -> 营收与利润高增: 储能领域营收约16.86亿元，同比增长约43%，成为核心增长引擎，驱动整体营收增长32.75%，净利润增长64.84%。
- **电力电子装置温控产品放量** -> 收入结构优化: 该板块收入19.77亿元，同比增长36.22%，占总营收68.94%，成为第一大收入来源，拉动整体毛利率稳定。
- **海外业务加速布局** -> 境外收入激增: 境外收入2.76亿元，同比增长269.92%，泰国生产基地设立，提升全球客户响应速度与品牌影响力。
- **研发投入持续加大** -> 技术壁垒与产品迭代: 研发费用1.22亿元，同比增长24.02%，聚焦液冷、半导体温控等高精度领域，巩固差异化竞争优势。
- **股权激励绑定核心人才** -> 激发团队活力: 两期限制性股票激励计划有序归属，增强员工凝聚力，保障战略执行与经营目标实现。
- **原材料价格波动** -> 成本端压力: 直接材料占营业成本86.13%，铜、铝等大宗商品价格波动直接影响毛利率，但公司通过供应链优化与技术降本部分对冲。
- **客户集中度较高** -> 经营依赖风险: 前五大客户销售占比42.03%，第一大客户占比16.76%，若主要客户需求波动，将对业绩产生显著影响。

## 风险警告
**储能业务依赖与客户集中风险**：公司业绩增长高度依赖储能温控业务（营收占比近59%），该领域受政策补贴退坡、行业竞争加剧及下游客户（如宁德时代、比亚迪）议价能力影响较大。前五大客户销售占比超42%，单一客户依赖度高，若核心客户订单减少或转向竞争对手，将直接冲击公司营收与利润稳定性。

**原材料成本与毛利率承压风险**：公司直接材料成本占比高达86%，压缩机、铜、铝等核心原材料价格与国际大宗商品市场高度联动。尽管2025年整体毛利率稳定在22.31%，但液体恒温设备毛利率同比下降1.84个百分点，显示成本传导能力存在瓶颈。若未来原材料价格持续上涨，而公司无法通过提价或技术降本完全消化，毛利率存在进一步下滑风险。
