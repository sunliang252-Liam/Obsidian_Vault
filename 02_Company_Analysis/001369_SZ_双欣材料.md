# 001369.SZ 深度透视

## 因果逻辑链
- **[循环经济产业链一体化]** -> [成本优势与抗风险能力]: 公司拥有“石灰石—电石—醋酸乙烯—聚乙烯醇—特种纤维/PVB膜/PVA光学膜”全产业链，自产电石等关键原料，有效抵御上游原材料价格波动，降低综合生产成本。
- **[行业产能出清与需求升级]** -> [PVA行业景气度提升]: 国内PVA行业落后产能退出，供给格局优化，同时下游高端应用（光学膜、PVB膜）需求增长，推动公司核心产品PVA产销两旺，产能利用率达88.38%。
- **[新材料项目投产放量]** -> [收入结构优化与增长新引擎]: 2025年DMC、PVA光学膜、PVB树脂及功能性膜等项目陆续进入试生产或投产，新材料行业收入同比大增124.44%，成为公司第二增长曲线。
- **[低成本资源禀赋]** -> [盈利护城河]: 公司地处内蒙古，煤炭、石灰石、电力资源丰富且价格低廉，叠加自备矿山和循环经济，使公司电石、PVA等产品综合能耗达到国内先进水平，构筑了显著的盈利护城河。
- **[高端产品国产替代]** -> [毛利率提升空间]: 公司持续研发印钞纸专用PVA、光学膜专用PVA等高端产品，逐步替代进口，高附加值产品占比提升，推动整体毛利率结构优化。
- **[研发驱动与产学研合作]** -> [技术壁垒]: 公司拥有双欣研究院、光谱创新中心等研发平台，与清华大学等高校合作，在PVA光学膜、EVOH树脂等前沿领域布局，形成技术领先优势。

## 风险警告
**核心风险在于新项目产能消化与盈利兑现的不确定性。** 2025年公司资本开支大幅增长，DMC、PVA光学膜、PVB树脂等多个项目集中进入试生产或投产期，但新材料行业毛利率同比下降6.70个百分点，且PVB树脂子公司仍处于亏损状态。若下游需求不及预期或产品价格竞争加剧，大规模新增产能可能无法被市场有效消化，导致折旧摊销压力侵蚀利润，投资回报率存在显著风险。

**另一重大风险是原材料价格波动与宏观经济周期性下行。** 公司主要产品电石、PVA下游与建材、纺织、汽车等周期性行业高度关联。报告期内，电石和PVA售价均呈震荡下行趋势，且核心原材料醋酸、兰炭价格波动剧烈。若宏观经济走弱导致下游需求萎缩，或上游煤炭、电力成本上升，公司“低成本”优势可能被削弱，业绩将面临双重挤压。
