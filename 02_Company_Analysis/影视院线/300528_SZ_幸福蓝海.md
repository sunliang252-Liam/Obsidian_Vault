# 300528.SZ 深度透视

## 因果逻辑链
- **[电影市场整体复苏]** -> [院线收入增长]: 2025年票房518.32亿元（+21.95%），带动公司电影及衍生收入同比+14.79%，院线全国排名第六。
- **[影城固定运营成本高企]** -> [持续亏损]: 尽管收入增长27.18%，但影城租金、折旧等刚性成本无法摊薄，导致净利润仍为-1.45亿元。
- **[电视剧业务收入暴增]** -> [低基数下的波动]: 电视剧收入7189万元（+7389%），主要因《反人类暴行》等剧集播出，但该业务体量小、波动大，对整体盈利贡献有限。
- **[信用减值损失大幅增加]** -> [侵蚀利润]: 计提信用减值损失5900万元（占利润总额-41.26%），主要来自应收款项坏账准备，反映下游回款风险。
- **[经营活动现金流显著改善]** -> [与净利润背离]: 经营现金流净额1.88亿元（+126.37%），主要因预收票款及收回前期应收款，但净利润为负，显示收入质量改善但盈利模式未变。
- **[微短剧与AI剧集布局]** -> [新增长点探索]: 推出《神兽河行纪》《苏小游之星河遨游录》等微短剧/AI剧集，顺应行业精品化趋势，但收入贡献尚小。
- **[合并报表未分配利润-8.82亿元]** -> [分红能力缺失]: 连续亏损导致累计未分配利润为负，公司连续两年不派发现金红利，股东回报受限。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司院线业务虽受益于市场复苏，但133家直营影城的固定租金、折旧及人工成本构成刚性支出，导致毛利率仅为5.89%，远不足以覆盖管理费用（1.52亿元）和巨额减值损失（信用+资产减值合计约8800万元）。只要影城运营成本无法通过非票收入或规模效应有效摊薄，公司就难以摆脱亏损泥潭。

**第二大风险是资产质量恶化与法律纠纷的持续拖累。** 公司信用减值损失高达5900万元，且涉及多起合同纠纷诉讼（如与傅晓阳等3.8亿元股权转让纠纷），部分被告已进入破产程序，回款前景不明。此外，商誉已全额计提减值，存货与长期股权投资亦存在减值风险，资产负债表修复需要时间。
