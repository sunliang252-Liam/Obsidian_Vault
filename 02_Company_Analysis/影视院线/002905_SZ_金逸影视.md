# 002905.SZ 深度透视

## 因果逻辑链
- **行业票房回暖（春节档/暑期档/贺岁档梯次发力）** -> [营收增长13.56%]: 2025年全国总票房同比增长21.95%，公司直营影院票房同比增长13.80%，直接拉动放映收入增长14.02%。
- **非票业务（卖品/广告）深度挖潜** -> [盈利结构优化]: 卖品收入同比增长26.30%，阵地广告收入同比增长67.92%，非票收入占比提升，降低了对单一票房收入的依赖。
- **资产处置收益（非经常性损益）** -> [净利润扭亏为盈]: 报告期内非流动性资产处置损益达7390万元，是归母净利润（2952万元）的核心来源，掩盖了扣非后仍亏损9072万元的经营现实。
- **降本增效（租金谈判/人力优化）** -> [经营现金流大幅改善]: 差旅费、人力成本分别同比下降25.67%、20.85%，叠加营收增长，经营活动现金流净额同比大增114.25%至3.35亿元。
- **“影院+”业态创新（电竞赛事/脱口秀）** -> [提升闲时利用率]: 全年举办非影活动超252场，同比增长8.85%，有效激活影厅闲时价值，为影院空间多元化变现探路。
- **会员生态体系优化** -> [提升用户粘性与复购]: 积分商城升级与异业合作驱动新增会员70.42万，线上会员充值同比增长24%，为未来收入提供稳定蓄水池。
- **优质影视项目投资** -> [产业链协同收益]: 参投《唐探1900》斩获36.12亿票房，验证了“终端+投资”的协同模式，但影视剧收入同比下降40.33%，显示投资节奏与收益的不稳定性。
- **高额租赁负债与财务费用** -> [侵蚀主业利润]: 使用权资产高达9.7亿元，占总资产40.82%，租赁负债13.3亿元，导致财务费用8520万元，是扣非净利润持续为负的核心压制因素。

## 风险警告
**核心风险在于盈利的“虚假繁荣”与沉重的资产结构。** 公司2025年归母净利润扭亏为盈，但扣非净利润仍亏损9072万元，盈利高度依赖资产处置（7390万元）和政府补助（2492万元）等非经常性损益。这表明公司核心放映业务在扣除高昂的租赁成本（财务费用8520万元）后，依然无法实现可持续盈利。高达13.3亿元的租赁负债和40.82%的使用权资产占比，构成了巨大的固定成本压力，任何票房波动都可能导致公司重新陷入深度亏损。

**行业竞争与内容依赖的双重挤压是长期隐患。** 全国银幕数已接近10万块，单银幕产出持续被稀释，行业竞争白热化。公司作为放映终端，业绩高度依赖上游制片方能否持续输出优质内容。2025年票房高度集中于《哪吒之魔童闹海》单片（占比近30%），腰部影片缺失，这种“爆款依赖症”使得公司业绩波动剧烈。同时，短视频等碎片化娱乐对线下观影时间的持续分流，正在侵蚀行业长期增长的基础。
