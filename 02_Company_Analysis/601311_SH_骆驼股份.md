# 601311.SH 深度透视

## 因果逻辑链
- **[铅酸电池销量稳增+结构优化]** -> [营收增长4.56%]: 铅酸电池销量同比+1.43%，AGM/驻车空调等高毛利产品增速更快，拉动整体营收。
- **[低压锂电池定点项目放量]** -> [锂电池收入同比+97.82%]: 60个新项目定点，39个项目量产，销量同比+200%，成为第二增长曲线。
- **[非经常性损益大幅增加]** -> [归母净利润同比+36.46%]: 债务重组收益+创新基金公允价值变动收益合计约2.76亿元，是利润暴增的主因。
- **[扣非净利润同比-5.42%]** -> [核心盈利能力承压]: 剔除一次性收益后，主业利润下滑，反映再生铅业务亏损及费用刚性。
- **[再生铅业务毛利率为负]** -> [拖累整体盈利]: 再生铅毛利率-2.46%，废旧电池采购价高企，行业“内卷”导致该板块亏损。
- **[海外市场销量同比+7.51%]** -> [国际化战略见效]: 马来西亚、非洲、印尼等市场增长强劲，但受中东反倾销和北美关税影响，增速受限。
- **[经营活动现金流净额同比+33.88%]** -> [现金流质量改善]: 购买商品支付现金减少，回款能力增强，为资本开支提供支撑。
- **[投资活动现金流净流出大幅增加]** -> [产能扩张加速]: 低碳产业园、欧洲PACK工厂等项目建设，资本开支加大，短期压制自由现金流。

## 风险警告
**核心风险在于再生铅业务的持续亏损与行业“内卷”。** 再生铅毛利率为-2.46%，废旧电池采购价高企、不规范回收竞争激烈，该板块已成为利润的“出血点”。若行业格局无法改善，再生铅将持续侵蚀铅酸电池主业的利润，并拖累整体ROE。公司虽具备循环产业链优势，但短期难以转化为盈利。

**第二风险是低压锂电池业务的高投入与低盈利矛盾。** 锂电池收入虽增长近一倍，但毛利率仅15.56%，且研发费用、产能建设投入巨大。当前定点项目多处于量产初期，规模效应尚未显现，若后续订单不及预期或价格战加剧，该业务可能长期处于“增收不增利”状态，无法成为真正的利润支柱。
