# 920931.BJ 深度透视

## 因果逻辑链
- **[下游石化行业需求放缓]** -> [营收下降22.30%]: 国内石化行业新建项目减少，客户需求萎缩，导致公司订单量下降，收入从4.01亿降至3.12亿。
- **[高毛利产品销量骤减]** -> [毛利率大幅下滑4.59个百分点]: 核心高毛利产品“油浆蒸汽发生器”销售金额同比大幅下降，拉低了整体盈利水平，毛利率从22.70%降至18.11%。
- **[募投项目转固，折旧激增]** -> [侵蚀利润，并导致存货减值]: 子公司江苏鼎邦厂房于2025年11月竣工转固，大额固定资产折旧导致固定费用增加，并使得部分在产品成本高于可变现净值，计提了存货跌价准备。
- **[客户设备开车延后]** -> [应收账款激增34%，现金流恶化]: 部分客户设备调试时间推迟，导致设备运行款支付延后，应收账款增至2.37亿，经营性现金流由正转负，净流出3626万元。
- **[原材料采购与在产品增加]** -> [应付账款与存货双升]: 为执行中海壳牌等大额订单，公司增加原材料采购，导致应付账款增长46.34%，在产品存货增长74.25%，占用了大量营运资金。
- **[国内业务萎缩]** -> [加速海外市场拓展]: 国内收入下降22.99%，倒逼公司加速国际化，已进入壳牌、沙特阿美、美孚等国际巨头供应链，海外业务成为新增长极。
- **[子公司尚处投产初期]** -> [拖累合并净利润]: 控股子公司江苏鼎邦2025年尚未产生收入，净亏损274万元，对合并报表净利润造成负面影响。

## 风险警告
**核心风险：业绩“戴维斯双杀”与现金流断裂风险。** 公司2025年遭遇营收与利润的“双杀”，净利润暴跌73.72%，扣非净利润暴跌78.41%。更严峻的是，经营性现金流净额由正转负，大幅流出3626万元，与净利润严重背离。这并非简单的周期波动，而是“需求萎缩+产能扩张折旧”双重压力下的结构性困境。若下游石化行业景气度持续低迷，公司可能面临“增收不增利”甚至“减收减利”的恶性循环，现金流压力将直接威胁日常运营。

**关键风险：应收账款高企与坏账风险。** 应收账款占总资产比例高达28.97%，且1-2年账龄的应收账款同比激增6114万元，回款周期显著拉长。公司主要客户虽为“三桶油”等大型国企，信用风险较低，但账期拉长已严重影响资金周转。若未来宏观经济波动或客户付款政策变化，大规模坏账计提将是对利润表的二次重创。当前信用减值损失已达455万元，且仍有上升趋势。
