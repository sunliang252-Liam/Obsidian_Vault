# 688607.SH 深度透视

## 因果逻辑链
- **[工业/安检业务爆发]** -> [营收增长7.63%]: 工业/安检收入同比大增52.49%，弥补了医疗业务下滑7.35%的缺口，成为营收增长的核心引擎。
- **[原材料囤货与汇兑损失]** -> [净利润转亏]: 为应对关税风险增加原材料采购，叠加美元波动导致汇兑损失，共同侵蚀利润，使归母净利润从盈利1765万转为亏损667万。
- **[新设子公司与研发优化]** -> [管理费用升、研发费用降]: 新设康众医能等子公司导致管理费用增37.59%；同时为降本增效优化研发团队，研发费用降26.69%。
- **[境外业务扩张]** -> [境外收入增长23.80%]: 积极拓展南美、亚太、中东等新兴市场，境外收入占比提升，毛利率高达45.97%，显著高于境内29.54%。
- **[“AI+基层医疗”战略布局]** -> [开辟第二增长曲线]: 设立康众医能，构建“设备+AI+运营”一体化方案，并战略投资医疗数字服务企业，旨在通过耗材、AI服务形成多元收益。
- **[产品线向高端与多元化延伸]** -> [动态产品收入增长11.72%]: 无线高速动态板、智能DR解决方案、口腔CBCT等新产品市场推广顺利，推动动态产品线收入增长。
- **[存货激增与现金流恶化]** -> [经营现金流大幅转负]: 存货同比暴增76.52%至1.52亿元，导致经营活动现金流净额从2262万骤降至-7262万，资金周转压力显著增大。

## 风险警告
**核心风险在于盈利能力的急剧恶化与现金流的巨大黑洞。** 公司在营收增长7.63%的情况下，归母净利润却由盈转亏，亏损667万元，扣非净利润更是亏损1692万元。这并非一次性因素，而是由“为应对关税而大规模囤货”与“美元汇率波动导致汇兑损失”共同引发的结构性困境。存货同比暴增76.52%至1.52亿元，直接导致经营活动现金流净额从净流入2262万骤降至净流出7262万，表明公司为维持供应链安全付出了高昂的流动性代价，若未来需求不及预期，将面临巨大的存货减值风险。

**其次，公司战略转型的投入期风险不容忽视。** 公司正从单一的平板探测器制造商向“设备+AI+运营”的综合解决方案商转型，新设子公司康众医能、战略投资曼荼罗软件等举措，已导致管理费用同比大增37.59%。这些新业务尚处于投入期，短期内难以贡献利润，反而会持续消耗公司资源。同时，医疗主业境内收入同比下降4.88%，显示传统基本盘面临增长瓶颈，新业务的成功与否将直接决定公司未来的成长空间，但不确定性极高。
