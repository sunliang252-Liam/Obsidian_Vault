# 688526.SH 深度透视

## 因果逻辑链
- **[猪用疫苗龙头地位稳固]** -> [业绩稳健]: 公司在非强免猪用生物制品市场连续多年排名第一，核心产品（伪狂犬、圆环、腹泻等）市占率领先，支撑了营收和利润的稳定增长。
- **[成本管控与工艺升级]** -> [毛利率提升]: 兽用生物制品营业成本同比下降16.54%，主要得益于公司强化内部成本管控、推进降本增效与工艺升级，使毛利率提升5.6个百分点至70.66%。
- **[研发投入持续高增]** -> [产品储备丰富]: 研发投入同比增长11.95%，占营收10.15%，2025年获得7项新兽药注册证书（含2项一类新药），为未来增长储备了牛支原体活疫苗、猪塞内卡病毒病灭活疫苗等重磅产品。
- **[非经常性损益贡献利润]** -> [净利润增速高于营收]: 2025年归母净利润同比增长9.51%，远超营收0.83%的增速，主要得益于计入当期损益的政府补助及金融资产公允价值变动收益等非经常性损益。
- **[下游养殖规模化趋势]** -> [直销模式占比提升]: 针对大型养殖集团执行精准服务策略，直销模式收入占比达68.6%，有助于绑定大客户，提升客户粘性和销售稳定性。
- **[新业务布局（黑水虻）]** -> [探索第二增长曲线]: 启动鸡粪转化为昆虫蛋白的示范基地并实现满产，参与制定行业标准，旨在打造以县域为单位的现代循环农业经济模式，开辟新增长点。

## 风险警告
**核心风险在于下游生猪养殖业的周期性波动与疫病冲击。** 公司约95%收入来自猪用疫苗，业绩与生猪存栏量高度相关。猪价低迷期，养殖户补栏意愿和疫苗采购意愿可能下降；非洲猪瘟等重大疫病若反复爆发，将直接导致生猪存栏锐减，对公司经营造成重大打击。尽管公司产品线丰富，但单一依赖猪用疫苗的格局使其业绩弹性与猪周期深度绑定。

**另一重大风险是公司与华中农业大学的深度绑定关系。** 公司核心研发团队多位教授来自华中农大，大量共有专利和合作研发项目依赖此关系。若未来合作关系终止、核心人员离职或华中农大许可第三方使用共有技术成果，将严重削弱公司的技术壁垒和产品竞争力。此外，公司实际控制人之一吴美洲已辞任董事，治理结构变动也需关注。
