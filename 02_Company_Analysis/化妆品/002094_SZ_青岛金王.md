# 002094.SZ 深度透视

## 因果逻辑链
- **[核心主业收入下滑]** -> [归母净利润下降39.66%]: 新材料蜡烛与香薰业务收入同比降11.16%，化妆品业务收入同比降10.98%，导致整体营收萎缩6.25%，利润承压。
- **[非经常性损益大幅波动]** -> [扣非净利润逆势增长99.61%]: 2025年公允价值变动损失2569万元（主要为其他非流动金融资产减值），而2024年同期为收益，导致归母净利润与扣非净利润严重背离。
- **[金融资产公允价值变动]** -> [侵蚀利润]: 其他非流动金融资产公允价值变动损失2597万元，是归母净利润下滑的核心拖累项。
- **[原材料价格波动]** -> [毛利率承压]: 主要原材料石蜡价格波动，公司虽建立价格联动机制，但新材料蜡烛业务毛利率仍同比下降0.82个百分点。
- **[人民币汇率波动]** -> [财务费用激增]: 财务费用同比增加27.90%，主要因汇兑损失增加，公司出口业务以美元结算，汇率风险敞口较大。
- **[化妆品业务渠道调整]** -> [收入下滑但毛利率改善]: 化妆品业务收入下降10.98%，但毛利率同比提升0.30个百分点，显示公司主动优化品牌与渠道结构，聚焦高毛利产品。
- **[经营活动现金流显著改善]** -> [经营质量提升]: 经营活动现金流净额由负转正，从-2162万元增至8724万元，主要得益于存货减少及应付账款管理优化。

## 风险警告
**核心主业双杀与金融资产暴雷风险。** 公司两大主业——新材料蜡烛与化妆品收入均出现两位数下滑，且蜡烛业务毛利率持续走低，显示核心盈利能力正在恶化。同时，公司持有大量其他非流动金融资产（余额5933万元），2025年公允价值变动损失高达2597万元，对利润造成巨大冲击。这类资产透明度低、波动性大，未来可能继续成为利润的“定时炸弹”。

**高负债与资金链压力。** 公司短期借款高达11.23亿元，占总资产35.87%，而货币资金仅6.09亿元（其中受限保证金6709万元），短期偿债压力巨大。此外，控股股东青岛金王国际运输有限公司所持股份质押比例高达90.8%，若股价下跌或经营恶化，可能触发控制权变更风险。公司连续三年未分红，且合并报表未分配利润为-4.23亿元，股东回报前景黯淡。
