# 600315.SH 深度透视

## 因果逻辑链
- **聚焦核心品牌与亿元单品战略** -> 扭亏为盈: 成功培育佰草集大白泥、玉泽干敏霜、六神驱蚊蛋三大亿元单品，高毛利美妆品类收入同比大增53.70%，驱动整体毛利率提升5个百分点至62.59%。
- **线上渠道精细化运营** -> 营收增长: 线上业务（同口径）收入同比增长21.89%，成为核心增长引擎，抵消了线下渠道的调整压力。
- **投资收益与公允价值变动** -> 净利润大幅改善: 持有的私募基金及银行理财等金融资产贡献公允价值变动收益1.07亿元及投资收益0.41亿元，合计占归母净利润的55.4%，是扭亏的关键非经营性因素。
- **供应链降本增效** -> 毛利率提升: 通过精简SKU、推进外协转内产、优化物流网络，在原材料成本下降的背景下，营业成本同比下降1.86%，显著增厚毛利。
- **上年度商誉减值基数效应** -> 归母净利润同比大幅增长: 2024年计提大额商誉减值导致巨额亏损，2025年无此影响，使得利润表在主营业务改善基础上实现反转。
- **加强应收账款管理** -> 经营现金流大幅改善: 期末应收账款同比下降26.5%，经营活动现金流净额同比飙升193.3%至8.0亿元，经营质量显著提升。

## 风险警告
**核心利润高度依赖非经常性损益，主营业务盈利能力依然薄弱。** 2025年归母净利润2.68亿元中，扣非净利润仅为0.45亿元，占比不足17%。高达2.23亿元的非经常性收益主要来自金融资产公允价值变动和投资收益，这部分收益具有高度不确定性和不可持续性。若剔除该影响，公司主营业务仅实现微利，表明其核心品牌和渠道的盈利能力尚未得到根本性修复。

**战略转型仍处深水区，增长可持续性面临考验。** 公司虽成功打造亿元单品，但销售费用同比增长14.36%，远超营收11.25%的增速，营销投入产出效率有待验证。同时，海外业务（汤美星）仍处于亏损状态（净利润-1624万元），且面临关税等外部风险。公司2026年目标为营收两位数增长，在当前消费复苏不确定、行业竞争加剧的背景下，实现该目标需要品牌力、产品力和渠道效率的持续突破，存在战略执行不达预期的风险。
