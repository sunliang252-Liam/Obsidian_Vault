# 603983.SH 深度透视

## 因果逻辑链
- **[线上流量成本高企]** -> [净利润下降27.63%]: 销售费用同比增长25.8%至20.57亿元，远超营收16.48%的增速，直接侵蚀利润。
- **[丸美大厦落成]** -> [管理费用激增48.36%]: 新办公大楼折旧及摊销费用增加，导致管理费用达1.61亿元，是利润下滑的第二大推手。
- **[丸美品牌线上增长]** -> [营收增长16.48%]: 丸美品牌营收25.47亿元，同比+23.94%，是公司整体营收增长的核心引擎。
- **[PL恋火品牌增长停滞]** -> [营收增速受限]: PL恋火品牌营收9.06亿元，同比基本持平，未能贡献增量，拖累整体增速。
- **[聚焦大单品策略]** -> [产销量下降但营收增长]: 生产量-23.69%，销售量-11.28%，但通过聚焦高单价大单品（如小红笔眼霜、小金针系列），实现了营收增长。
- **[研发投入持续]** -> [构建技术壁垒]: 研发费用同比增长16.08%，成功构建重组功能蛋白平台，新增13款自研原料，为长期产品力奠基。
- **[线下渠道承压]** -> [渠道结构失衡加剧]: 线下营收同比下降7.46%，占比降至11.44%，公司对线上渠道的依赖度进一步加深。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长16.48%，但净利润却暴跌27.63%。根本原因是线上流量成本失控，销售费用率高达59.5%，吞噬了所有利润增量。这并非短期波动，而是行业竞争白热化下的结构性困境。若无法有效降低获客成本或提升转化效率，公司可能陷入“为平台打工”的窘境，盈利能力将持续承压。

**第二重风险是品牌增长引擎单一且后继乏力。** 增长完全依赖“丸美”主品牌，而第二增长曲线“PL恋火”已陷入停滞。同时，公司正推进H股上市，但募投项目“营销升级及运营总部建设”和“数字营运中心建设”均大幅延期，表明公司战略执行能力存疑。在美妆行业快速迭代的背景下，品牌老化与战略失焦的风险不容忽视。
