# 300955.SZ 深度透视

## 因果逻辑链
- **[新业务扩张与湖州基地投产]** -> [营收增长23.28%但净亏损扩大56.83%]: 新客户订单带动收入，但湖州嘉亨新增折旧摊销、人工及利息支出等固定成本刚性增长，叠加产品结构变动导致毛利率下降，增收不增利。
- **[湖州嘉亨产能爬坡与固定成本错配]** -> [子公司湖州嘉亨亏损5,870.66万元]: 化妆品产能利用率仅44.18%，家庭护理产品产能利用率34.81%，大量在建工程转固后折旧摊销无法被低利用率覆盖，成为亏损核心来源。
- **[客户集中度高达62.70%]** -> [业绩依赖前五大客户]: 公司为科赴、上海家化、贝泰妮等头部品牌代工，订单稳定性强但议价空间受限，单一客户流失将直接冲击营收。
- **[原材料价格波动与成本传导滞后]** -> [毛利率同比下降3.01个百分点]: PE、PP等合成树脂及表面活性剂价格受原油影响波动，公司无法完全向下游转嫁成本，挤压盈利空间。
- **[财务费用激增114.27%]** -> [侵蚀利润]: 银行借款规模扩大及利息资本化减少，导致利息支出从1,050万跃升至2,251万元，直接拖累净利润。
- **[研发投入资本化率为零]** -> [当期费用化压力]: 3,397.69万元研发费用全部计入当期损益，未形成无形资产，短期内无法通过摊销平滑利润。
- **[存货与应收账款双增]** -> [营运资金占用加剧]: 存货增长34.93%至2.14亿元，应收账款增长21.83%至3.08亿元，合计占流动资产超50%，现金流承压。

## 风险警告
**核心风险在于产能扩张与需求错配导致的持续亏损。** 湖州嘉亨基地投资超9.28亿元，但化妆品及家庭护理产品产能利用率均不足45%，折旧摊销等固定成本刚性增长，而新客户订单毛利率偏低，导致公司连续两年亏损且亏损额扩大。若下游品牌客户需求放缓或公司无法快速提升产能利用率，亏损可能进一步加剧，净资产已连续两年缩水（-6.99%）。

**财务风险与治理风险并存。** 公司资产负债率从2023年末的41.3%升至2025年末的53.1%，有息负债（短期+长期+一年内到期）高达6.67亿元，财务费用同比翻倍。同时，控股股东曾本生已签署协议转让29.70%股份，公司控制权即将变更，新实控人徐意（杭州拼便宜）的产业整合能力及后续经营战略存在不确定性，可能引发管理层动荡或业务方向调整风险。
