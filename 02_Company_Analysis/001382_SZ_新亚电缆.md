# 001382.SZ 深度透视

## 因果逻辑链
- **[铜铝等原材料价格持续高位运行]** -> [毛利率承压]: 公司“料重工轻”，原材料成本占比超94%，铜价上涨直接侵蚀利润空间，导致综合毛利率下降0.41个百分点。
- **[市场竞争加剧及下游客户采购意愿减弱]** -> [净利润下滑25.57%]: 宏观经济波动叠加行业竞争白热化，公司被迫让利保份额，叠加费用刚性增长，归母净利润从1.35亿降至1.00亿。
- **[国家电网市场取得突破性进展]** -> [华东地区收入暴增515.71%]: 公司成功中标国网上海、江苏、浙江等公司项目，中标金额（含税）达17.46亿元，驱动华东区域收入从0.67亿跃升至4.16亿。
- **[应收账款规模扩大]** -> [信用减值损失大幅增加]: 为抢占市场份额，公司放宽信用政策，应收账款增至7.74亿元，导致信用减值损失计提增加，直接吞噬利润。
- **[IPO上市募集资金到账]** -> [筹资活动现金流净额转正]: 2025年3月上市，募集资金净额约4亿元，使筹资活动现金流从-0.98亿大幅转正至3.94亿，缓解了资金压力。
- **[经营性应收项目大幅增加]** -> [经营活动现金流净额恶化至-2.43亿]: 收入增长但回款滞后，应收账款、应收票据等大幅增加，导致经营性现金流净额同比下滑460%，远低于净利润。
- **[销售区域高度集中于华南]** -> [区域依赖风险]: 华南地区收入占比66.53%，尽管华东地区爆发式增长，但公司整体仍严重依赖单一区域市场，抗风险能力较弱。

## 风险警告
**核心风险在于“增收不增利”与“现金流恶化”的双重挤压。** 公司2025年营收微增4%，但净利润却暴跌25.57%，主因是原材料成本高企与市场竞争加剧导致毛利率下滑，同时为抢占国网市场导致应收账款激增，信用减值损失大幅吞噬利润。更危险的是，经营活动现金流净额从-0.43亿骤降至-2.43亿，与1.00亿的净利润严重背离，表明公司利润质量极低，回款能力堪忧，存在流动性隐患。

**客户集中度与区域依赖风险极高。** 前两大客户（南方电网、国家电网）合计贡献近50%营收，华南地区收入占比超66%。一旦电网投资节奏放缓、招标政策变化，或公司在核心市场的份额被蚕食，业绩将面临断崖式下滑。此外，公司募投项目（绿色环保电缆、智能制造等）尚处建设期，短期内无法贡献效益，而铜铝价格波动风险始终高悬，公司缺乏有效的套期保值工具对冲，盈利稳定性存疑。
