# 601065.SH 深度透视

## 因果逻辑链
- **[纯碱价格大幅下跌]** -> [净利润下降45.60%]: 纯碱行业产能扩张、下游需求疲软，导致纯碱收入同比下降22.56%，毛利率骤降16.50个百分点，成为业绩下滑主因。
- **[工业盐价格下行]** -> [盐类业务毛利率下降3.02个百分点]: 市场供需失衡，工业盐收入同比下降14.97%，成本降幅不及收入降幅，拖累整体盐类业务盈利。
- **[煤炭、焦炭等原材料采购均价下降]** -> [营业成本仅下降5.36%]: 尽管主要能源成本同比大幅下降（煤炭-16.92%，焦炭-42.93%），但产品价格下跌幅度更大，成本红利未能完全对冲收入下滑。
- **[产能利用率提升与降本增效]** -> [经营现金流净额增长8.21%]: 盐钙产量同比增长6.7%，纯碱产量增长9.2%，叠加精细化管理，在利润下滑背景下仍实现经营性现金流改善。
- **[高端盐产品销量增长69.29%]** -> [产品结构优化]: 公司通过品牌升级，高端盐利润贡献率提升，部分对冲了工业盐和纯碱价格下跌的负面影响。
- **[资产处置收益大幅增加]** -> [非经常性损益支撑利润]: 子公司收到搬迁补偿款，确认资产处置收益6072万元，使扣非净利润降幅（-58.26%）远大于归母净利润降幅（-45.60%）。
- **[省外市场收入下降24.10%]** -> [区域竞争加剧]: 省外销售受行业竞争和价格战影响，收入下滑幅度远超省内（-4.73%），显示公司在核心市场外的议价能力较弱。

## 风险警告
**核心风险在于纯碱业务的周期性崩塌。** 公司约42%的收入来自纯碱，但2025年纯碱毛利率从38.55%骤降至22.05%，降幅高达16.5个百分点。随着内蒙古天然碱项目二期投产，低成本产能持续释放，纯碱行业供给过剩格局短期难以逆转，公司纯碱业务盈利能力可能进一步承压，这是业绩最大的不确定性来源。

**第二重风险是增长引擎的缺失与转型阵痛。** 公司钙产品业务毛利率仅0.88%，且成本逆势上升18.91%，新投产的高强硫酸钙项目仍处于试生产阶段，尚未贡献利润。同时，公司核心管理层在报告期内发生重大变动（董事长、总经理、财务总监、董事会秘书均离任），战略执行的连续性和稳定性面临考验。
