# 300558.SZ 深度透视

## 因果逻辑链
- **[九款上市产品矩阵协同放量]** -> [营收增长24.81%]: 凯美纳稳定贡献基石收入，贝美纳、赛美纳、伏美纳等新药借助医保准入和差异化临床数据快速放量，叠加康美纳、安瑞泽等新品启动销售，形成多产品驱动格局。
- **[贝美纳全球化落地]** -> [海外收入增量释放]: 贝美纳获美国FDA、澳门ISAF批准上市并开出首张处方，欧洲上市申请获EMA受理，从授权出海转向自主商业化，打开海外市场天花板。
- **[核心产品纳入医保]** -> [市场准入与销量提升]: 凯美纳、贝美纳、赛美纳、伏美纳四款创新药成功续约国家医保目录，降低患者支付门槛，加速医院准入和处方放量。
- **[研发投入聚焦重点项目]** -> [管线推进效率提升]: 研发投入5.74亿元（占营收15.89%），资源聚焦恩沙替尼术后辅助NDA、MCLA-129临床、DURAVYU全球III期等关键项目，推动注册与临床进程提速。
- **[创新生态圈协同效应释放]** -> [产品管线与营收来源拓宽]: 与博锐生物合作获得安瑞泽、贝泽汀权益，投资禾元生物获奥福民独家经销权，生态圈孵化成果转化为商业化产品，贡献新增量。
- **[经营性现金流强劲]** -> [盈利质量高]: 经营活动现金流净额9.11亿元，净利润现金含量近300%，显示销售回款优异，盈利转化为现金的能力极强。
- **[管理费用与财务费用大幅增加]** -> [归母净利润同比下降24.15%]: 无形资产摊销、股份支付费用增加导致管理费用增长78.70%；工程项目转固后利息停止资本化，财务费用增长138.69%，侵蚀利润。

## 风险警告
**核心风险在于利润增速与营收增速的严重背离。** 公司营收增长24.81%至36.09亿元，但归母净利润却下降24.15%至3.05亿元。利润下滑的主因并非经营恶化，而是管理费用（+78.70%）和财务费用（+138.69%）的急剧膨胀，前者源于无形资产摊销和股权激励，后者因工程转固停止利息资本化。这种“增收不增利”的财务结构若持续，将压制估值修复空间，投资者需警惕费用端对利润的长期侵蚀。

**另一重大风险是核心产品面临激烈的市场竞争与专利到期压力。** 凯美纳（一代EGFR-TKI）作为基石产品，其化合物专利已于2023年到期，虽受晶型等外围专利保护至2029-2034年，但仿制药冲击风险持续存在。同时，EGFR-TKI和ALK抑制剂赛道竞争白热化，赛美纳、贝美纳需持续证明其相对于同类产品的差异化优势（如PFS数据），否则市场份额可能被侵蚀。此外，贝安汀作为贝伐珠单抗生物类似药，面临原研药和众多同类产品的双重挤压。
