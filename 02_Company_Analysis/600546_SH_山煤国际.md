# 600546.SH 深度透视

## 因果逻辑链
- **[煤价大幅下跌]** -> [归母净利润暴跌48.58%]: 自产煤销售均价同比下降18.57%至525.93元/吨，直接侵蚀利润空间，即便产量增长6.4%也无法对冲。
- **[贸易业务量价齐跌]** -> [营收骤降30.75%]: 贸易煤销量同比大降39.87%，售价同比下跌25.97%，导致贸易业务收入腰斩（-55.48%），成为营收下滑最大拖累。
- **[成本管控对冲部分风险]** -> [自产煤毛利率仅降4.01个百分点]: 公司推行作业成本法，自产煤吨煤成本同比下降8.35%，部分抵消了煤价下跌对生产端利润的冲击。
- **[产量增长但利润不增]** -> [以量补价策略失效]: 原煤产量同比增6.4%至3509万吨，但售价跌幅远超产量增幅，显示在供过于求市场中，增产无法弥补价格损失。
- **[非经常性损益放大亏损]** -> [扣非净利润优于归母净利润]: 非经常性损失达-8621万元（主要为营业外支出），导致归母净利润降幅（-48.58%）略大于扣非净利润降幅（-48.75%）。
- **[现金流韧性优于利润]** -> [经营现金流仅降10.29%]: 尽管利润腰斩，但经营现金流净额仍达33.56亿元，主要得益于贸易业务规模收缩带来的采购支出大幅减少。
- **[分红比例维持高位]** -> [60.34%现金分红率]: 在利润大幅下滑背景下，公司仍维持较高分红比例，体现对股东回报的重视，但绝对分红金额同比下降48.6%。

## 风险警告
**核心风险：煤价持续低迷与需求结构性萎缩。** 2025年归母净利润已暴跌至11.66亿元，ROE从14.12%骤降至7.17%。公司业绩高度依赖煤价，而下游钢铁、建材需求疲软（粗钢产量-4.4%，水泥产量-6.9%），叠加新能源对火电的挤压，煤价中枢下移风险未消。公司2026年产量目标仅维持3500万吨，未见增长，暗示管理层对市场前景谨慎。

**次生风险：资产质量与现金流隐患。** 受限资金高达28.13亿元（主要为矿山环境治理基金），占总货币资金的46.4%，严重限制资金使用灵活性。同时，多家子公司亏损（铺龙湾、韩家洼、宏远、鹿台山、东古城、鑫顺煤业合计亏损超11亿元），显示部分矿井在低煤价下已丧失盈利能力，存在资产减值风险。此外，其他综合收益因权益工具公允价值变动亏损1.65亿元，侵蚀净资产。
