# 002232.SZ 深度透视

## 因果逻辑链
- **[营收下滑但利润暴增]** -> [净利润+698%]: 收入下降11.88%至7.74亿，但通过大幅压降成本（营业成本-18.55%，管理费用-26%），实现扣非净利润从-432万跃升至2658万。
- **[深度绑定一汽集团]** -> [客户集中度极高]: 前五名客户销售占比89.58%，其中中国一汽集团占比74.49%，公司业务高度依赖单一控股股东。
- **[研发投入资本化率飙升]** -> [利润调节空间]: 研发投入资本化率从50.09%升至63.35%，资本化金额增加49.27%，显著降低了当期费用，是利润改善的重要会计手段。
- **[经营现金流大幅改善]** -> [回款能力增强]: 经营活动现金流净额1.15亿，同比增长175.92%，远超净利润，主要系成本端现金支出降低及收回代收代付款增加。
- **[从项目制向产品化转型]** -> [毛利率提升]: 聚焦“七星云”等平台化产品，管理软件及服务毛利率提升2.53%，集成服务毛利率提升8.40%，整体毛利率从21.5%提升至27.43%。
- **[AI及信创投入加码]** -> [构筑长期壁垒]: 研发人员数量暴增34.41%至961人，重点投入大模型、信创适配、车路云一体化，旨在摆脱低端集成，向高价值技术服务商转型。

## 风险警告
**核心风险在于对控股股东中国一汽的极度依赖。** 公司74.49%的收入来自一汽集团，客户集中度畸高，本质上是一汽的“内部IT部门”。一旦集团战略调整、自建IT能力或压缩IT预算，公司营收将面临断崖式风险。2025年营收已下滑11.88%，显示集团需求正在收缩。

**利润增长的可持续性存疑。** 2025年净利润暴增主要依赖成本削减和研发费用资本化（资本化率高达63.35%），而非核心业务的强劲增长。这种“省出来的利润”和“会计手段调节的利润”难以持续。若未来研发项目失败或资本化政策收紧，利润将面临巨大回撤压力。
