# 301358.SZ 深度透视

## 因果逻辑链
- **[动力与储能双轮驱动]** -> [销量增长60%]: 新能源汽车渗透率超50%与储能电池出货量同比+85%，带动磷酸铁锂需求爆发，公司销量达113.71万吨。
- **[高压实差异化产品放量]** -> [产品结构优化]: CN-5、YN-9等高压实系列销量占比提升至约51%，精准契合行业技术升级方向，成为业绩增长核心驱动力。
- **[一体化降本战略]** -> [毛利率提升]: 磷酸铁全部自供、黄家坡磷矿出矿、碳酸锂加工产能达7万吨/年，产业链协同降低综合成本，毛利率同比+1.26pct。
- **[客户全覆盖与深度绑定]** -> [收入高增长]: 覆盖宁德时代、比亚迪等国内主流电池厂，前五大客户销售占比71.38%，其中宁德时代关联交易占比约30%。
- **[行业产能出清与头部集中]** -> [市占率巩固]: 落后产能加速出清，公司连续六年出货量行业第一，规模优势与客户粘性形成正反馈。
- **[储能占比提升]** -> [收入结构优化]: 储能领域产品占比提升至约45%，抓住储能爆发式增长机遇，平滑动力电池周期波动。

## 风险警告
**1. 现金流与盈利质量的背离风险。** 2025年净利润12.77亿元，但经营活动现金流净额为-15.46亿元，连续两年为负。主因是下游客户大量使用承兑汇票付款，而公司需现金采购碳酸锂等原材料，上下游信用周期错配导致“纸面富贵”。若票据贴现成本上升或回款周期拉长，可能引发流动性压力。

**2. 原材料价格波动与库存减值风险。** 碳酸锂等核心原材料成本占比超75%，价格剧烈波动直接冲击毛利率。2025年公司公允价值变动损失1.6亿元、资产减值损失1.04亿元，主要源于材料后点价结算及存货跌价。若未来锂价持续下行，高价库存将侵蚀利润。

**3. 技术路线替代与竞争加剧风险。** 固态电池、钠离子电池等新技术路线正加速产业化，若公司未能及时推出适配产品，可能面临市场份额被蚕食的风险。同时，行业产能过剩背景下，价格战可能进一步压缩盈利空间。
