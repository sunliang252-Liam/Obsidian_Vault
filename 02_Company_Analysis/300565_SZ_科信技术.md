# 300565.SZ 深度透视

## 因果逻辑链
- **[海外市场扩张]** -> [营收增长6.15%]: 国外收入同比+31.64%，占比升至49.27%，弥补国内收入下滑，但整体毛利率仅微升至22.30%，未能扭亏。
- **[5G投资周期见顶]** -> [国内收入下滑10.65%]: 运营商资本开支从网络覆盖转向算力，传统基站建设增速放缓，公司国内无线网络能源产品需求承压。
- **[子公司停产与资产盘活]** -> [亏损收窄52.59%]: 控股子公司科信聚力停产，并通过对外投资盘活存量资产（设备、专利），减少持续亏损对合并报表的拖累。
- **[5G产业园折旧与运营费用]** -> [持续侵蚀利润]: 子公司5G智能产业园项目投产后，折旧及运营费用成为固定成本，在营收未达预期时严重拖累盈利。
- **[储能业务转型]** -> [数据中心产品爆发式增长94.36%]: 公司从通信储能转向数据中心能源，该产品线营收从0.32亿增至0.62亿，成为第二增长曲线，但基数尚小。
- **[研发投入资本化率为零]** -> [利润表压力]: 研发费用全部费用化（占营收10.85%），虽体现会计谨慎性，但在亏损期进一步加重了当期利润表的负担。
- **[经营现金流持续为负]** -> [造血能力不足]: 尽管亏损收窄，经营活动现金流净额仍为-4040万元，显示公司尚未实现内生性现金流的正向循环。

## 风险警告
公司连续三年巨额亏损（-2.24亿、-2.06亿、-0.98亿），且母公司存在累计未弥补亏损，无法分红。核心风险在于，公司营收增长高度依赖海外市场（+31.64%），但国内传统主业（-10.65%）持续萎缩，而新增长极“数据中心产品”体量尚小，无法对冲整体亏损。更关键的是，经营现金流持续为负，表明公司尚未建立起健康的盈利模式，扭亏依赖于海外订单的持续放量和成本控制的有效性。

另一个重大隐患是资产质量。公司大量固定资产（45.58%）和无形资产被用于抵押借款，且应收账款和存货规模高企。子公司科信聚力停产后的资产盘活（对外投资）虽短期减亏，但本质是“以资抵债”，其长期投资价值存疑。同时，募集资金用途从“储能锂电池”变更为“数据中心”，暴露了公司战略摇摆和原项目市场环境的恶化，新项目能否如期达产并产生效益存在巨大不确定性。
