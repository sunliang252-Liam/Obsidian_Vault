# 688379.SH 深度透视

## 因果逻辑链
- **[拆迁收益确认]** -> **净利润暴增133%**: 2025年2月完成良渚厂区搬迁，一次性确认税后资产处置收益约7551.57万元，贡献了归母净利润的40%以上。
- **[新兴赛道放量]** -> **营收增长33%**: 电子领域营收同比增长超110%，AI液冷领域实现批量供货并贡献超5%营收，成为第二增长曲线核心引擎。
- **[原材料价格上涨]** -> **营收与成本同步攀升**: 白银、铜、锡等大宗商品价格上涨，公司“原材料成本+加工费”定价模式传导至售价，但成本增速(34.64%)略高于营收增速(33.27%)。
- **[锡基钎料爆发]** -> **电子业务翻倍增长**: 锡基钎料收入同比增长超130%，成为电子领域核心增长极，推动电子行业整体营收同比增长117.36%。
- **[传统领域稳盘]** -> **基本盘提供安全垫**: 制冷暖通及电力电气领域营收同比增长均超15%，原有客户供货比例稳步提升，为新兴业务拓展提供现金流支撑。
- **[现金流结构恶化]** -> **经营现金流持续为负**: 供应商现款结算与客户票据结算的时间错配，导致经营活动现金流净额为-8496万元，但通过增加信用证结算已较上年大幅改善。
- **[泰国工厂投建]** -> **海外布局加速**: 泰国一期1000吨产能产线已投产，海外营收增长近40%，但初期投入导致投资活动现金流净流出9301万元。

## 风险警告
**核心风险在于利润质量与现金流的结构性矛盾。** 2025年净利润暴增133%，但超过40%来自一次性拆迁收益，扣非净利润增速仅44%。更关键的是，公司“现款采购、票据销售”的商业模式导致经营现金流持续为负，即便通过信用证优化，净流出仍高达8496万元。这种利润与现金流的背离，意味着公司实际造血能力远弱于账面利润，需依赖筹资活动（净流入1.74亿元）维持运营，财务费用同比增16.48%，债务压力持续累积。

**原材料价格波动与存货减值风险不容忽视。** 白银、铜、锡等大宗商品价格波动频繁，公司虽有定价传导机制，但存在时间滞后。2025年存货规模随业务扩张而增长，若原材料价格出现持续或急剧下跌，公司将面临计提大额存货跌价准备的风险，直接冲击盈利能力。此外，应收账款及票据规模较大，若下游客户信用状况恶化，坏账风险将加剧现金流紧张局面。
