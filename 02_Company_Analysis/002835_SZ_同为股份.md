# 002835.SZ 深度透视

## 因果逻辑链
- **[研发投入高增]** -> [净利润下滑30.49%]: 研发费用同比增长10.17%至2.18亿元，占营收19.58%，侵蚀利润空间。
- **[境外收入占比97%]** -> [营收下降4.10%]: 高度依赖欧美市场，受国际贸易摩擦与地缘政治影响，境外收入同比减少4.31%。
- **[汇率剧烈波动]** -> [财务费用激增183.54%]: 美元兑人民币汇率大幅波动，导致汇兑损失，财务费用从-1095万升至915万。
- **[AI大模型产品化]** -> [构建差异化竞争壁垒]: 率先实现大模型在嵌入式终端规模化落地，推出文搜NVR、大模型摄像机，提升产品溢价与客户粘性。
- **[海外生产基地量产]** -> [供应链韧性增强]: 越南工厂规模化量产，形成国内外双制造基地，降低单一产地风险，保障交付稳定性。
- **[存货大幅增加]** -> [经营现金流锐减55.60%]: 存货从1.89亿增至2.61亿，占用大量营运资金，导致经营活动现金流净额从2.57亿降至1.14亿。
- **[持续高研发投入]** -> [技术领先地位巩固]: 研发投入连续多年超营收10%，在AI ISP、多光谱融合、云平台等核心技术形成局部领先优势。

## 风险警告
**核心风险在于营收与利润的双重承压。** 公司97%收入来自境外，高度依赖欧美市场，面临地缘政治、贸易保护及汇率波动的三重冲击。2025年营收同比下降4.10%，净利润更是骤降30.49%，显示盈利能力显著恶化。研发费用激增虽为长期布局，但短期严重侵蚀利润，若新产品无法快速转化为收入，利润将持续承压。

**运营效率恶化是另一重大隐患。** 存货同比大增37.9%至2.61亿元，导致经营活动现金流净额腰斩（-55.60%），表明公司对市场需求预判或库存管理出现偏差。同时，管理费用增长23.21%，远超营收降幅，显示费用控制能力不足。若不能有效去库存并优化费用结构，公司财务健康度将进一步下滑。
