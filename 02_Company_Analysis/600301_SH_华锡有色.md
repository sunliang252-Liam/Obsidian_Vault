# 600301.SH 深度透视

## 因果逻辑链
- **[锡、锑、铟等战略金属价格持续走高]** -> [营收与利润双增]: 核心产品（锡锭、铅锑精矿、锑锭）量价齐升，驱动2025年营收增长25.31%，归母净利润增长21.75%。
- **[外购锡原料规模大幅增加]** -> [锡锭毛利率承压]: 为满足下游需求，公司加大外购原料采购，导致锡锭生产成本上升，毛利率同比下降6.77个百分点。
- **[锑产品价格飙升]** -> [锑锭业务利润爆发]: 锑锭收入同比激增3318倍，毛利率高达52.73%，成为利润增长的核心引擎。
- **[矿山资源增储与产能扩张]** -> [长期发展根基加固]: 佛子冲铅锌矿增储528万吨，铜坑矿证载规模提升至350万吨/年，为未来产量增长奠定资源基础。
- **[高毛利率的铅锑精矿销售占比提升]** -> [整体盈利结构优化]: 铅锑精矿毛利率高达80%，其收入增长48.21%，有效对冲了锌、锡等产品毛利率下滑的影响。
- **[安全环保投入与采矿权出让金补缴]** -> [生产成本刚性上升]: 采矿成本同比增加12.30%，选矿成本增加6.23%，侵蚀了部分产品利润空间。
- **[降本增效项目落地]** -> [管理费用得到有效控制]: 全年推进56项降本增效项目，实现降本3047万元，管理费用增幅（7.29%）远低于营收增幅（25.31%）。

## 风险警告
**核心风险在于业绩对金属价格的极度敏感与成本刚性上涨的矛盾。** 公司利润高度依赖锡、锑、铟等战略金属价格，2025年业绩爆发主要受益于锑价飙升和锡价高位。然而，这种价格红利具有不可持续性，一旦全球供需格局逆转或宏观经济下行导致金属价格回落，公司盈利能力将面临断崖式下滑。同时，外购原料成本、安全环保投入及采矿权出让金等成本项呈刚性上涨趋势，进一步压缩了利润安全垫。

**资源接续与产能释放存在不确定性。** 尽管公司资源储量大幅增长，但核心募投项目“铜坑矿区锡锌矿矿产资源开发项目”因外部审批问题进度滞后，投产时间不确定。高峰公司采矿权将于2027年到期，续期及扩界工作存在变数。若新产能无法按期释放，公司未来增长将受限于现有矿山的产量天花板，难以持续支撑业绩高增长。
