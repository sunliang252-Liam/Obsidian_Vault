# 920599.BJ 深度透视

## 因果逻辑链
- **[新能源产品放量]** -> [毛利率提升至22.99%]: 新能源矿卡（如DTE145、TLE120）单价高、毛利好，拉动整体毛利率同比提升1.54个百分点。
- **[海外市场拓展]** -> [营收逆势增长3.98%]: 国内煤价下跌、开工率不足，但海外市场（紫金矿业、洛阳钼业、西芒杜铁矿等）订单放量，弥补内需缺口。
- **[产品大型化、高端化]** -> [单车运能提升，客户价值增加]: 推出TED136电传动刚性矿卡，突破大吨位技术壁垒，以更高效率替代传统车型，巩固市场地位。
- **[无人驾驶商业化落地]** -> [抢占智能化矿山赛道]: 与易控智驾联合发布EQ100E无人矿卡，投资头部智驾公司，无人驾驶车辆效能已达有人驾驶90%，加速市场渗透。
- **[存货大幅增加30.45%]** -> [发出商品积压，现金流承压]: 发出商品增加2.94亿元，导致存货激增，经营活动现金流净额同比锐减73.24%。
- **[应收账款规模高企]** -> [信用减值损失扩大]: 应收账款余额21.1亿元，占总资产27.23%，商业承兑汇票增加导致信用减值损失同比增112.36%。
- **[无实际控制人]** -> [治理结构分散，决策效率风险]: 股权分散，无单一股东可支配30%以上表决权，存在治理不稳定、贻误发展机遇的风险。

## 风险警告
**现金流恶化与应收账款高企是最大隐患。** 2025年经营活动现金流净额仅3.93亿元，同比暴跌73.24%，而同期净利润8.39亿元，净现比不足0.5。应收账款余额21.1亿元，占总资产27%，账龄虽短但规模庞大，若下游矿业客户因煤价下跌或融资收紧出现回款困难，将直接冲击公司资金链，并引发大规模信用减值。

**海外扩张的国别风险与竞争加剧。** 公司海外收入占比约16.5%，但目标市场集中在刚果（金）、秘鲁、几内亚等政治经济不稳定地区，国别风险高。同时，海外市场面临卡特彼勒、小松等国际巨头以及国内同行的激烈竞争，若“代工”模式或本地化服务能力不及预期，海外增长可能受阻。此外，国内非煤市场（有色金属）虽增长，但整体行业企稳下行，存量替代竞争白热化，价格“内卷”可能侵蚀利润。
