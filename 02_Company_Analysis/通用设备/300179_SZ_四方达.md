# 300179.SZ 深度透视

## 因果逻辑链
- **CVD金刚石业务（河南天璇）处于产能爬坡与亏损期** -> **归母净利润下降20.77%**: 子公司河南天璇2025年营收虽暴增764%至6289万元，但前期高成本、低开机率导致净亏损1.22亿元，严重拖累合并报表利润。
- **核心主业（资源开采/精密加工）收入下滑** -> **扣非净利润骤降46.68%**: 公司传统优势产品“资源开采/工程施工类”和“精密加工类”收入分别同比下降5.69%和4.90%，显示成熟业务增长乏力。
- **营业成本增速（+34.46%）远超营收增速（+7.98%）** -> **毛利率大幅下滑11.55个百分点**: 成本端压力主要来自CVD新业务的高投入期以及原材料成本上升，侵蚀了传统业务的盈利空间。
- **非经常性损益（公允价值变动+政府补助）贡献巨额利润** -> **掩盖主业疲软**: 2025年非经常性损益高达4229万元（同比+90.8%），主要来自其他非流动金融资产公允价值变动（+2582万）和政府补助（+1695万），是维持净利润为正的关键。
- **经营活动现金流净额由正转负（-4729万元）** -> **盈利质量恶化**: 现金流大幅流出主因是供应链融资到期及子公司采购付款增加，与净利润严重背离，表明公司运营资金压力巨大。
- **存货激增至4.75亿元（+53.5%）** -> **资产减值风险高企**: 存货增长主要来自子公司原材料及产成品备货，叠加CVD产品价格波动，导致2025年计提资产减值损失6397万元，成为利润最大侵蚀项。
- **长期借款激增至3.53亿元（+240%）** -> **财务杠杆显著提升**: 子公司天璇新材料为CVD项目大额举债，导致公司利息支出同比暴增310%至880万元，财务费用由负转正。

## 风险警告
**核心风险在于CVD金刚石业务的“烧钱”模式与主业失速的叠加。** 子公司河南天璇虽营收暴增，但巨额亏损（-1.22亿）和持续扩大的资本开支（长期借款增2.4倍）正在严重消耗母公司现金流。若CVD产品价格持续低迷或良率提升不及预期，该业务将成为吞噬利润的无底洞，并引发债务违约风险。

**传统主业竞争力下滑与资产减值风险不容忽视。** 资源开采和精密加工两大核心业务收入双双下滑，表明公司在传统领域的市场份额正被侵蚀。同时，存货激增至4.75亿元，已计提6397万减值，若下游需求进一步疲软，大规模存货跌价将直接冲击利润表。公司2025年高达155%的现金分红率（基于归母净利润）也加剧了财务上的脆弱性。
