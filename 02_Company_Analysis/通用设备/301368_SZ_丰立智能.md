# 301368.SZ 深度透视

## 因果逻辑链
- **[产能扩张与折旧激增]** -> [净利润由盈转亏]: 首发募投项目于2025年12月结项，大量资产转固导致折旧费用大幅增加，叠加人员扩张带来的薪资成本上升，直接侵蚀利润。
- **[传统主业下滑]** -> [营收增长停滞]: 受国际贸易政策变化和地缘政治影响，传统电动工具领域业务下滑，导致公司整体营收同比微降0.54%，失去增长引擎。
- **[新业务投入期]** -> [短期盈利承压]: 新能源汽车传动齿轮、机器人减速器等新业务处于量产初期，研发投入、模具夹具及开办费用高企，尚未形成规模效应以覆盖成本。
- **[财务费用激增]** -> [利润进一步压缩]: 为追加项目投资而增加融资，导致利息支出大幅增加；同时人民币升值产生汇兑损失，财务费用同比暴增186.36%。
- **[存货减值风险暴露]** -> [资产减值损失扩大]: 根据会计政策计提存货减值约1,716万元，占利润总额的51.64%，反映出新业务产品迭代和市场不确定性带来的库存风险。
- **[海外布局初期]** -> [拖累当期业绩]: 越南、马来西亚子公司于2025年底进入小批生产状态，开办费用直接计入当期损益，对利润形成额外拖累。
- **[新能源传动高增长]** -> [结构优化初现]: 新能源传动行业收入同比增长80.31%，成为唯一高增长板块，但毛利率为-38.53%，仍处于“增收不增利”的亏损阶段。

## 风险警告
**核心风险在于新旧动能转换期的“青黄不接”。** 公司传统电动工具主业受宏观逆风影响持续萎缩，而寄予厚望的新能源汽车传动和机器人业务尚处于大规模投入期，产能利用率不足导致毛利率为负，叠加巨额折旧和财务费用，公司2025年已陷入全面亏损。若新业务放量不及预期，公司可能面临持续的盈利压力。

**财务风险显著恶化。** 公司短期借款同比激增8.85个百分点至占总资产13.48%，财务费用由负转正，现金流净额大幅下降39%。同时，高达1,716万元的存货减值计提揭示了新业务库存管理的脆弱性。在营收停滞、亏损扩大的背景下，高杠杆扩张策略的可持续性存疑，需警惕流动性风险。
