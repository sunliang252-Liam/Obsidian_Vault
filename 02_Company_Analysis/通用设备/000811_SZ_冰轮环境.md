# 000811.SZ 深度透视

## 因果逻辑链
- **[海外市场突破]** -> [营收增长6.28%]: 海外业务收入同比增长17.62%，占比提升至33.01%，成为抵消国内需求放缓的核心驱动力。
- **[工程施工业务爆发]** -> [营收结构变化]: 工程施工收入同比大增77.66%，占比从9.14%跃升至15.28%，但毛利率仅20.35%，拉低整体盈利质量。
- **[工业产品销售承压]** -> [扣非净利润微降0.75%]: 核心主业工业产品销售同比微降0.29%，毛利率下滑1.23个百分点，导致主业盈利能力停滞。
- **[非经常性损益锐减]** -> [归母净利润下降10.14%]: 公允价值变动收益及政府补助等非经常性损益同比减少约6000万元，是净利润下滑的主因。
- **[数据中心与核电赛道]** -> [新兴业务增长点]: 数据中心液冷装备和核电冷却系统成为高景气赛道，子公司顿汉布什IDC专版磁悬浮系列产品开始大批量供货。
- **[经营活动现金流强劲]** -> [财务健康度提升]: 经营性现金流净额达8.21亿元，同比增长13.89%，显著高于净利润，反映回款能力与运营效率改善。
- **[研发投入持续加码]** -> [技术壁垒构筑]: 研发费用同比增长9.11%，成立中央研究院，在CO₂跨临界、工业热泵、氦气压缩机等前沿领域取得突破，巩固技术护城河。

## 风险警告
**核心风险在于主业增长乏力与盈利质量下降。** 公司2025年营收增长主要依赖低毛利的工程施工业务（毛利率20.35%）和海外市场，而作为“压舱石”的工业产品销售（毛利率26.89%）出现量价齐跌，扣非净利润同比微降。这表明公司核心制冷设备在国内市场的竞争加剧，存量替换和节能改造需求未能有效转化为利润增长。若海外市场增速放缓或工程施工业务回款出现问题，公司整体盈利能力将面临更大压力。

**应收账款与存货高企构成潜在减值风险。** 公司应收账款账面价值18.33亿元，占总资产14.11%，且信用减值损失仍为负值。同时，存货账面价值17.54亿元，同比增长20.9%。在宏观经济波动和下游客户经营承压的背景下，大额应收款和存货的减值风险不容忽视。尽管公司现金流表现优异，但资产质量的下行趋势需要持续关注，尤其是海外业务和工程项目的回款周期。
