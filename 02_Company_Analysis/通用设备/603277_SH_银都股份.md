# 603277.SH 深度透视

## 因果逻辑链
- **[海外仓网络与自主品牌]** -> [营收韧性]: 43个海外仓（18个自营）构建近场交付能力，叠加“ATOSA”品牌溢价，使北美市场在关税压力下收入保持平稳，欧洲自主品牌营收实现正向增长。
- **[“双擎”产能布局]** -> [供应链韧性]: 杭州+泰国双基地具备全品类制造能力，可灵活调配产能，有效对冲中美贸易摩擦及关税波动对出口成本的影响。
- **[销售费用与研发费用高增]** -> [利润承压]: 销售费用（+13.83%）因仓库费、市场推广增加，研发费用（+23.63%）因人力成本投入加大，共同导致扣非净利润同比下降17.29%。
- **[OBM模式主导]** -> [品牌溢价与高毛利]: OBM收入占比77.2%，毛利率达46.99%，显著高于ODM模式（28.31%），是公司维持整体42.73%毛利率的核心驱动力。
- **[海外仓备货模式]** -> [存货与现金流压力]: 为保障交付效率，产成品存货规模较大，导致经营活动现金流净额同比下降31.52%，且面临存货减值风险。
- **[连锁化趋势]** -> [内销增长]: 国内连锁客户采购增加，驱动内销收入同比增长43.30%，成为公司新的增长极。
- **[非经常性损益依赖]** -> [利润波动]: 2025年非经常性损益（主要为金融资产公允价值变动及投资收益）高达7,485万元，占净利润15.4%，掩盖了主营业务的疲软。

## 风险警告
**核心风险在于利润质量与增长动能的背离。** 公司2025年扣非净利润同比下降17.29%，而净利润仅下降10.04%，主要依赖高达7,485万元的非经常性损益（理财收益、衍生品交易等）进行粉饰。在营收几乎停滞（-0.84%）的背景下，销售费用和研发费用的刚性增长正在持续侵蚀主营利润，表明公司正面临“增收不增利”甚至“不增收更不增利”的困境。

**海外仓重资产模式与地缘政治风险叠加，构成财务脆弱性。** 公司存货高达10.75亿元，且海外仓备货模式导致现金流大幅恶化（经营现金流同比-31.52%）。同时，境外资产占总资产67.69%，高度依赖北美市场。若美国关税政策进一步升级或出现极端需求波动，公司将面临存货大幅减值、现金流断裂及海外业务合规性等多重冲击。
