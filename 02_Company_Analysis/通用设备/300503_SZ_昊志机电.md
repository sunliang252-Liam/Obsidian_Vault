## 因果逻辑链
- **[AI算力与消费电子需求爆发]** -> [PCB专用设备主轴销售大幅增长]: AI服务器、高速交换机及消费电子升级驱动PCB产业结构性增长，公司PCB钻孔/成型机电主轴作为核心部件直接受益，销售收入同比大幅提升。
- **[国产替代加速与产品技术升级]** -> [加工中心主轴及雕铣机主轴收入增长]: 国内制造业向高端化转型，叠加公司自研拉刀机构、超级电机等核心技术突破，产品性能对标国际先进，推动加工中心及雕铣机主轴销量提升。
- **[主轴业务量价齐升]** -> [公司整体营收与毛利率双增]: 主轴作为核心收入来源（占主营66.77%），收入同比增长33.40%，叠加成本管控优化，带动综合毛利率提升3.61个百分点至38.11%。
- **[欧洲制造业持续疲软]** -> [Infranor集团运动控制产品收入下滑]: 欧元区能源价格上涨、通胀高企、PMI长期收缩，导致客户投资意愿减弱，Infranor集团伺服电机、驱动及控制器销售收入同比下降9.11%。
- **[机器人产业“量产元年”]** -> [谐波减速器、关节模组等新业务拓展]: 2025年被视为智能机器人量产元年，公司“N+1+3”布局（核心零部件+协作机器人+三大场景）受益，已与多家头部企业建立合作，形成新增长点。
- **[供应链整合与成本控制]** -> [Infranor集团经营改善]: 公司推动全球采购协同与资源整合，有效控制原材料成本，Infranor产品价格竞争力回升，经营活力逐步释放，为后续业绩恢复奠定基础。
- **[研发投入持续高企]** -> [技术壁垒与产品线拓宽]: 研发投入占营收8.84%，聚焦电主轴、机器人、氢燃料电池空压机等前沿领域，新增多项专利，巩固了“核心部件-运动平台-控制系统”全链路国产化解决方案的领先地位。

## 风险警告
公司面临显著的短期偿债压力与流动性风险。截至2025年末，资产负债率高达57.13%，短期借款及一年内到期非流动负债合计超6亿元，而货币资金仅1.38亿元，资金缺口巨大。尽管公司称与金融机构合作正常，但若经营现金流恶化或信贷环境收紧，可能引发债务偿付危机。

海外业务整合与商誉减值风险是另一核心隐患。Infranor集团受欧洲宏观经济拖累持续亏损，已累计计提商誉减值超2,500万瑞士法郎，剩余商誉仍面临减值压力。同时，公司缺乏成熟的境外整合经验，若无法有效实现技术、渠道与文化的协同，将拖累整体盈利能力。

应收账款与存货高企构成双重风险。应收账款账面原值超9亿元，占资产总额28%，其中对第一大欠款客户已全额计提坏账，但其余应收款回收仍存不确定性。存货账面价值5.59亿元，若下游需求波动或产品迭代，将面临跌价风险，进一步侵蚀利润。
