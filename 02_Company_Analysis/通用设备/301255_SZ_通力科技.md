# 301255.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧导致产品降价]** -> [净利润下降15.96%]: 公司为保住市场份额，在激烈竞争中被迫下调部分产品价格，导致毛利率下降，侵蚀了利润空间。
- **[智造园区转固增加折旧]** -> [管理费用增长43.82%]: 新建的“通力智能装备（杭州）有限公司高端传动装备智造项目”等固定资产转固，计提的折旧费用大幅增加，直接推高了管理费用。
- **[募集资金及自有资金利息收入减少]** -> [财务费用大幅上升89.84%]: 随着IPO募集资金逐步投入使用，以及自有资金理财规模下降，导致利息收入同比减少，财务费用由负转正，对净利润造成拖累。
- **[下游需求缓步复苏]** -> [营业收入小幅增长4.08%]: 冶金、化工等传统下游行业需求呈现温和复苏态势，公司凭借品牌和客户基础，实现了订单规模的微幅增长。
- **[直销模式增长优于经销]** -> [经销收入下降11.02%]: 公司加大直销渠道开拓力度，直销收入增长7.37%，而经销商渠道收入则出现下滑，显示公司销售策略重心正在向直销倾斜。
- **[原材料价格波动]** -> [成本控制承压]: 钢材、铸锻件等主要原材料价格波动，直接影响了产品生产成本，公司虽有一定转嫁能力，但成本压力依然存在。
- **[研发投入持续增加]** -> [产品技术升级]: 公司持续投入研发（占营收5.20%），重点攻克新能源锂电行业“禁铜锌”等特殊要求，开发高附加值产品，为未来市场拓展奠定技术基础。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司2025年营收微增4.08%，但扣非净利润却大幅下滑24.58%，主要源于产品降价、折旧增加和利息收入减少三重压力。这表明公司在激烈的市场竞争中缺乏定价权，同时重资产投入带来的折旧负担正在加速侵蚀利润，盈利能力已进入下行通道。若行业竞争进一步加剧或下游需求复苏不及预期，公司业绩存在进一步下滑的风险。

**另一重大风险是产能消化与资产减值。** 公司“高端传动装备智造项目”等大规模投资已陆续转固，但新产能的释放和市场需求能否匹配存在不确定性。若下游需求增长乏力，新增产能可能面临闲置，导致固定资产减值风险。同时，公司存货（1.14亿元）和应收账款（0.76亿元）规模较大，若下游客户经营恶化，可能引发存货跌价和坏账风险。
