# 002903.SZ 深度透视

## 因果逻辑链
- **[消费电子大客户订单结构变化]** -> [毛利率承压]: 2025年消费电子行业收入微增0.92%，但营业成本激增32.03%，导致该板块毛利率从42.59%骤降至24.90%，拖累整体盈利。
- **[主动放弃低毛利项目]** -> [智能装备收入锐减]: 子公司宇环智能战略性放弃毛利率低、周期长的能源电力项目，导致智能装备系列收入同比暴跌70.23%，是营收下滑的主因。
- **[产品结构向高毛利拉床倾斜]** -> [拉床业务爆发]: 拉床产品收入同比增长70.18%，毛利率提升15.20个百分点至35.91%，成为公司利润的核心支撑点。
- **[子公司宇环精密与南方机床盈利改善]** -> [对冲母公司亏损]: 宇环精密（净利润+211%）和南方机床（净利润+3%）业绩强劲，部分抵消了母公司及宇环智能的亏损。
- **[大客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比54.29%，其中蓝思科技（26.91%）和比亚迪（15.02%）贡献近半营收，客户依赖度高。
- **[存货大幅增加]** -> [资产减值风险]: 存货账面价值同比增加28.8%至2.73亿元，导致本期计提存货跌价损失1,272万元，成为利润亏损的重要来源。
- **[研发投入维持高位]** -> [长期竞争力构建]: 研发费用占营收比例达11.14%，成功开发出填补国内空白的榫槽拉床等高端产品，为未来进口替代奠定基础。

## 风险警告
公司2025年陷入亏损，核心风险在于**消费电子大客户订单的盈利质量急剧恶化**。虽然来自蓝思科技等头部客户的收入保持稳定，但该板块毛利率暴跌近18个百分点，表明公司为维持市场份额牺牲了定价权，陷入了“增收不增利”的困境。这种依赖少数大客户的低毛利模式，在消费电子行业技术迭代和成本压力传导下，极易导致公司盈利能力持续承压。

此外，**存货激增与资产减值风险**不容忽视。存货规模攀升至2.73亿元，远超营收降幅，并已引发1,272万元的跌价损失。这反映出公司对市场需求预判可能过于乐观，或产品交付验收周期拉长。若下游需求进一步放缓，公司将面临更大的存货减值压力和现金流占用风险，可能引发业绩的进一步下滑。
