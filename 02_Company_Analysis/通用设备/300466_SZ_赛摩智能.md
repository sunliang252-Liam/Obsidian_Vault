# 300466.SZ 深度透视

## 因果逻辑链
- **业务结构优化与亏损子公司出清** -> **大幅减亏50.39%**: 公司主动剥离低效资产（如上海赛摩电气出表）、强化回款管理，使信用减值损失和资产减值损失同比显著下降，归母净利润从-8662万收窄至-4297万。
- **核心计量产品技术壁垒** -> **计量检测产品收入逆势增长12.59%**: 电子皮带秤智能诊断系统、高稳定性皮带秤等创新产品获国际领先鉴定，巩固了在电力、矿山等领域的龙头地位，对冲了其他业务下滑。
- **循环经济赛道切入** -> **电网退役物资拆解新签合同2600余万元**: 与国家电网合作落地自动化拆解产线，从发电侧延伸至电网业务，开辟了“技术-产品-订单”闭环的新增长极。
- **AI与工业软件深度融合** -> **信息化项目收入增长16.96%**: 将AI工具引入MOM/MES等工业软件开发，实现降本增效，并成功签约海外项目（曼德罗马尼亚），推动软件业务出海。
- **低空经济前瞻布局** -> **新设子公司抢占战略先机**: 成立赛摩科创及中赛航空，依托军工院所技术聚焦无人机侦测反制，虽尚未形成收入，但卡位未来赛道。
- **强化回款与成本管控** -> **经营活动现金流净额维持正值（6522万）**: 尽管营收下滑，但通过压降应收账款和严控费用，经营性现金流连续两年为正，显著优于净利润表现。
- **子公司经营分化** -> **整体盈利被亏损子公司拖累**: 核心子公司南京三埃（净利3218万）和武汉博晟（净利198万）盈利，但合肥雄鹰（-1192万）和上海赛摩物流（-1745万）等持续亏损，侵蚀整体利润。

## 风险警告
**核心风险在于“新旧动能转换期的盈利断层”。** 公司虽通过剥离亏损资产和严控成本实现大幅减亏，但营收同比下滑14.31%，传统自动化项目收入骤降69.20%，表明存量业务正在萎缩。而新培育的低空经济、机器人等业务尚处投入期，未形成实质性收入贡献，公司正处于旧业务收缩、新业务未起飞的“青黄不接”阶段，盈利能力基础依然脆弱。

**资产质量风险不容忽视。** 应收账款账面余额高达5.53亿元，坏账准备计提比例达42.14%，且存在多起合同纠纷导致的资金冻结（约808万元）。存货跌价准备也达2044万元。尽管减值损失同比减少，但高额的应收和存货仍对利润表构成持续压力，若下游客户（尤其是电力、煤炭行业）回款进一步恶化，可能再次引发大额减值。母公司未分配利润为-6919万元，已不满足现金分红条件。
