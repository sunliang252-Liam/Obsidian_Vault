# 300402.SZ 深度透视

## 因果逻辑链
- **[下游化工/新能源行业投资放缓]** -> [营收下降18.80%]: 传统优势业务（PTA、PDH等）需求阶段性收缩，高附加值特材产品占比下降，导致整体营收下滑。
- **[产品结构向低附加值倾斜]** -> [扣非净利润暴跌71.69%]: 非经常性损益（政府补助4244万）占比极高，核心盈利能力大幅恶化，主营利润贡献锐减。
- **[原材料采购现金支出激增]** -> [经营性现金流由正转负，净流出1.33亿]: 为后续订单备料导致预付款和存货增加，但回款周期长，现金循环严重吃紧。
- **[应收账款与合同资产大幅增长]** -> [信用减值损失3712万，侵蚀利润]: 客户按合同节点付款延迟，导致应收账款激增34.5%，坏账计提压力巨大，成为利润最大拖累项。
- **[海外订单占比显著提升]** -> [国际业务收入却下降62.83%]: 新签订单结构优化，但收入确认滞后，当期交付的海外项目减少，形成订单与收入的短期错配。
- **[研发投入聚焦深海/高端装备]** -> [技术壁垒与未来增长点]: 在深海钛合金、超纯硅反应器等“卡脖子”领域取得突破，为长期竞争力奠基，但短期无法贡献业绩。
- **[募投项目延期]** -> [产能扩张节奏放缓]: “高端特材装备智能制造项目”因市场变化和方案优化而延期，短期无法通过规模效应降低成本或承接更多订单。

## 风险警告
**核心风险在于“增收不增利”与现金流急剧恶化。** 公司营收下滑18.8%，但扣非净利润暴跌71.69%，表明主营业务盈利能力已严重受损。更危险的是，经营性现金流从净流入3亿骤降至净流出1.33亿，主要因原材料采购支出激增和应收账款回收困难。这种“纸面利润”与“真实现金”的巨大背离，若持续将导致公司运营资金链紧绷，甚至影响正常生产周转。

**应收账款高企与信用减值风险是悬在头顶的利剑。** 应收账款占总资产比例高达34.52%，且同比大幅增长，导致公司计提了3712万元的信用减值损失，这已成为吞噬利润的最大黑洞。下游客户多为大型化工企业，若其因行业周期下行或自身经营问题出现付款延迟甚至坏账，将对公司业绩和资产质量造成毁灭性打击。公司虽采取清收措施，但行业特性决定回款周期难以根本性缩短。
