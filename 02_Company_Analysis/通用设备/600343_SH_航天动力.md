## 因果逻辑链
- **[聚焦主业，收缩非优势业务]** -> [营收下降11%]: 主动收缩电机及低毛利输油化工泵业务，导致新签合同减少，收入承压。
- **[水利项目延期]** -> [水利用泵收入下降48%]: 地方财政压力导致部分水利新建项目暂缓或延期，直接冲击核心产品订单。
- **[乘用车变矩器规模化效益释放]** -> [液力变矩器毛利率飙升27.48个百分点]: 产能提升、规模效应显现，成本大幅下降，盈利能力显著改善。
- **[计提大额资产减值]** -> [净利润亏损扩大]: 存货因产品转型及客户订单变更减值，设备及专利因新标准出台减值，合计计提4355.60万元。
- **[投资者诉讼计提预计负债]** -> [非经常性损益大幅侵蚀利润]: 因信息披露违法被罚，引发中小投资者索赔，计提预计负债2288.71万元，直接加剧亏损。
- **[联营企业航力公司经营恶化]** -> [确认投资亏损2051万元]: 参股公司航力科技经营不及预期，按权益法确认大额投资损失，拖累合并利润。
- **[子公司航天元新引入战投]** -> [筹资活动现金流净额暴增2942%]: 引入外部资本3亿元，极大改善公司现金流状况，为液力传动产业发展提供资金。
- **[液氢装备取得突破]** -> [培育未来增长极]: 40尺液氢罐箱、车载液氢气瓶交付并通过测试，氢能板块从研发走向产业化，为“十五五”布局。

## 风险警告
公司连续三年巨额亏损，2025年归母净利润-1.93亿元，且母公司未分配利润为-6.68亿元，不具备分红条件。核心风险在于**存量业务萎缩与增量业务尚未形成有效替代**。泵及泵系统作为基本盘，因水利项目延期和主动收缩非优势业务，收入持续下滑；而氢能等新业务仍处于能力建设和市场开拓初期，短期内无法贡献利润，公司面临青黄不接的阵痛期。

最大的财务风险来自**资产减值与诉讼赔偿的持续冲击**。公司因产品转型、客户订单变更及新标准出台，连续大额计提存货和资产减值。同时，因历史信息披露违法引发的投资者诉讼仍在进行中，剩余410件案件未开庭，潜在赔偿金额约3171万元，未来仍可能继续侵蚀利润。此外，参股公司航力科技经营持续恶化，投资亏损风险高企。
