# 605100.SH 深度透视

## 因果逻辑链
- **[新能源重卡渗透率提升]** -> [核心零部件收入下滑]: 公司未布局新能源重卡零部件业务，新能源重卡销量暴增（+173%）未能转化为公司收入，反而侵蚀了传统燃油/燃气重卡市场份额。
- **[天然气发动机客户机型变更]** -> [零部件收入与利润双重承压]: 公司为适配新机型进行生产线技改，2025年上半年处于调试验证期，下半年才进入产能爬坡，导致全年天然气重卡零部件交付量减少，且产能利用率不足推高了单位制造成本。
- **[印度子公司业务萎缩]** -> [运维服务收入与利润大幅下滑]: 受印度重要客户战略调整及签证政策限制，公司员工无法赴印开展业务，导致运维收入同比减少38.14%，净利润同比减少89.85%。
- **[海外通信基站发电机组需求增长]** -> [发电机组业务毛利率提升]: 海外订单增加带动柴油发动机及发电机组收入增长5.11%，且出口产品毛利率较高，推动该板块毛利率同比提升3.55个百分点。
- **[产能利用率下降与固定成本刚性]** -> [净利润降幅远超营收降幅]: 营收下降13.42%，但固定资产折旧等固定成本不随产量同比例变动，导致净利润暴跌69.04%，经营杠杆负面效应显著。
- **[客户高度集中]** -> [经营风险高度依赖单一客户]: 对第一大客户潍柴动力的销售额占比高达82.72%，同时向其采购额占比72.47%，公司经营业绩与潍柴动力的需求高度绑定。
- **[固态电池与数据中心AI电源新业务布局]** -> [战略转型但短期无贡献]: 公司积极投资固态电池、SOFC、数据中心电源等新赛道，但这些业务尚处于早期研发或市场开拓阶段，短期内无法贡献利润，且存在较大不确定性。

## 风险警告
**核心风险在于传统主业的结构性衰退与转型的极度不确定性。** 公司核心零部件业务高度依赖重卡市场，尤其是潍柴动力。然而，新能源重卡渗透率已从2021年的不足1%飙升至2025年的28%，且仍在加速，这直接侵蚀了公司传统燃油/燃气发动机零部件的市场空间。公司虽已意识到风险并布局固态电池、数据中心AI电源等新业务，但这些业务尚处于研发或市场开拓初期，距离规模化盈利遥远，且面临技术路线、市场竞争等多重挑战。新旧动能转换的“青黄不接”是公司当前最根本的困境。

**财务层面，公司盈利能力与现金流已出现显著恶化。** 2025年净利润暴跌69%，经营活动现金流净额更是骤降86.93%，显示出收入下滑已严重冲击公司造血能力。同时，公司对单一客户潍柴动力的依赖度极高（销售占比超82%），且与其存在大额关联采购，议价能力薄弱。此外，公司已终止核心募投项目“新型轻量化发动机核心零部件智能制造项目”二期工程，表明其对传统重卡零部件市场的未来增长已失去信心，这进一步印证了公司转型的紧迫性与被动性。
