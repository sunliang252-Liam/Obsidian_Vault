# 300354.SZ 深度透视

## 因果逻辑链
- **国产替代政策红利** -> 营收增长5.72%: 国家政策明确要求国家级创新平台采购国产仪器，叠加国防、新能源等下游需求扩张，驱动公司结构力学测试系统等核心产品收入稳步增长。
- **回款能力大幅改善** -> 经营现金流暴增388.83%: 公司加强应收账款管理，销售回款显著增加，使得经营活动现金净额从3842万跃升至1.88亿元，远超净利润，财务质量显著提升。
- **PHM与数字孪生系统渗透** -> 高毛利业务结构稳定: 基于PHM的数字孪生系统平台收入增长14.10%，与结构力学测试系统共同维持66%以上的高毛利率，证明公司从卖硬件向卖“硬件+软件+服务”解决方案转型成功。
- **研发投入聚焦新兴赛道** -> 产品线拓展至机器人/低空经济: 公司研发费用率维持在11.86%，重点布局力矩自适应智能关节模组、自定义测控系统等，切入人形机器人、低空经济等前沿领域，打开第二增长曲线。
- **客户集中度极低** -> 经营风险分散: 前五大客户销售额仅占营收9.20%，客户覆盖航空航天、高校、基建等多领域，单一客户依赖风险极低，业绩稳定性强。
- **电化学工作站需求爆发** -> 新能源电池检测业务增长: 受益于锂电池、燃料电池等新能源行业对电化学测试的旺盛需求，电化学工作站收入增长7.97%，成为公司第三大收入来源。
- **“小巨人”品牌壁垒** -> 高客户粘性与议价权: 作为国家级专精特新“小巨人”企业，公司在结构力学测试领域积累深厚口碑，客户粘性强，支撑其维持高毛利率和稳定的直销模式。

## 风险警告
**核心风险在于应收账款高企与坏账计提压力。** 尽管2025年回款大幅改善，但应收账款账面价值仍高达3.2亿元，占总资产32.96%。公司按组合计提坏账准备，若宏观经济下行或下游客户（特别是军工、基建类）付款周期延长，将面临较大的信用减值损失，侵蚀利润。

**第二增长曲线的不确定性。** 公司大力布局的人形机器人关节模组、自定义测控系统等新业务，尚处于市场推广初期，面临技术成熟度、市场接受度及国际巨头（如NI、西门子）竞争的多重挑战。新产品投入产出比存在较大不确定性，若推广不及预期，将拖累整体盈利能力和研发投入回报率。
