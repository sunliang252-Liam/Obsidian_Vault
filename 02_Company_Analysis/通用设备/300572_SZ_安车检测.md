# 300572.SZ 深度透视

## 因果逻辑链
- **[机动车检测政策放宽]** -> [检测频次断崖式下滑]: 2020年及2022年两次政策将十年内新车检测频次降至1次，直接导致检测需求大幅萎缩。
- **[汽车以旧换新补贴]** -> [老旧车辆加速淘汰]: 2024年政策推动老旧车报废，进一步削减了存量车辆的检测基数。
- **[检测量下降]** -> [并购检测站业绩集体暴雷]: 12家并购标的2025年业绩承诺全部未达标，合计亏损远超预期。
- **[并购标的业绩不达预期]** -> [巨额商誉减值]: 商誉账面价值从1.82亿元骤降至0.40亿元，减值1.42亿元，成为亏损主因。
- **[主业萎缩+商誉减值]** -> [连续第三年亏损]: 归母净利润-1.78亿元，扣非净利润-2.18亿元，经营基本面持续恶化。
- **[原实控人出让控制权]** -> [引入矽睿科技]: 原实控人贺宪宁转让股份，矽睿科技成为控股股东，公司战略转向MEMS传感器。
- **[新战略“双轮驱动”]** -> [业务重心彻底转移]: 未来增长引擎从机动车检测转向MEMS传感器及智能终端，传统主业降为“稳定基石”。

## 风险警告
**核心风险在于传统主业已陷入结构性衰退，而新业务转型尚处“画饼”阶段。** 机动车检测政策宽松与以旧换新双重打击并非短期扰动，而是根本性地改变了行业需求曲线。公司连续三年亏损，12个并购标的业绩承诺全部落空，商誉减值风险虽已部分释放，但剩余0.4亿元商誉及大量长期股权投资仍存在进一步减值可能。公司经营活动现金流虽为正，但主要靠压缩营运资金维持，难以掩盖主业造血能力持续弱化的本质。

**最大的不确定性来自新控股股东矽睿科技带来的MEMS传感器业务整合。** 公司从设备制造商向半导体传感器企业转型，跨度极大，技术、市场、管理团队均需重建。MEMS行业技术壁垒高、竞争激烈，公司能否在短期内实现“第二增长曲线”存在巨大疑问。此外，原实控人贺宪宁的股份协议转让已完成，新老管理层交替过程中的战略执行与团队融合风险不容忽视。
