# 301160.SZ 深度透视

## 因果逻辑链
- **[国产替代加速]** -> [营收增长]: 汽车行业竞争加剧，下游客户为降本加速采购国产精冲材料，公司凭借价格与响应优势替代进口，驱动营收增长1.74%。
- **[产能扩张与结构优化]** -> [利润稳定]: 安徽工厂4万吨产能于2025年10月投产，同时公司主动优化订单结构提升高毛利产品占比，对冲了毛利率下滑1.72%的影响，净利润微增0.62%。
- **[下游新能源汽车渗透率提升]** -> [需求增长]: 2025年新能源汽车渗透率达54.2%，公司产品间接配套特斯拉、比亚迪等主流品牌，受益于新能源车销量增长28.2%带来的精冲材料需求。
- **[客户认证壁垒]** -> [高客户粘性]: 公司已进入舍弗勒、慕贝尔等全球知名Tier1供应商体系，客户认证周期长、转换成本高，形成了稳定的收入基本盘。
- **[研发投入与工艺积累]** -> [技术护城河]: 持续研发投入（占营收4.21%），掌握晶间氧化物控制等核心技术，在谐波减速器柔轮材料等高端领域实现突破，为未来增长奠基。
- **[安徽工厂产能爬坡]** -> [未来增长引擎]: 安徽新厂2025年投产，2026年目标产能翻倍至8万吨，聚焦轴承与机器人材料，是公司从“汽车材料商”转型为“高端工业材料商”的关键。
- **[收购远昌智能]** -> [布局人形机器人]: 通过控股远昌智能切入人形机器人整机及核心部件领域，形成“材料-部件-整机”全链条布局，抢占未来产业先机。

## 风险警告
**核心风险在于新业务放量不及预期与毛利率持续承压。** 公司2026年经营计划高度依赖安徽工厂产能翻倍（从4万吨到8万吨）以及轴承、机器人新材料的客户认证与放量。若产能爬坡不顺、高端轴承或机器人材料认证周期过长，或下游需求波动，将导致新增产能无法及时消化，造成资产折旧压力与利润侵蚀。同时，公司整体毛利率已同比下降1.72%，汽车零部件精冲材料毛利率下降2.31%，显示行业竞争加剧或成本端压力上升。

**另一重大风险是客户与供应商的高度集中。** 公司前五大客户销售额占比27.62%，前五大供应商采购额占比高达76.90%（其中单一供应商占比53.19%）。这种结构意味着公司对核心客户和单一原材料供应商存在较大依赖。若主要客户流失或主要供应商（如宝钢）提价、断供，将直接冲击公司经营的稳定性与盈利能力。此外，公司经营活动现金流净额（1.3亿）持续低于净利润（2.08亿），反映出“先款后货”的采购模式与“赊销”的销售模式带来的资金占用压力，需关注其现金流改善情况。

**公司简介（F10 原文）**

> 苏州翔楼新材料股份有限公司(简称“翔楼新材”)成立于2005年12月8日。翔楼新材主要从事定制化精密冲压特殊钢材料的研发、生产和销售,产品包括碳素结构钢、合金结构钢等特种结构钢及弹簧钢、轴承钢、工具钢等特种用途钢。公司产品主要用于各类汽车精冲零部件,应用范围覆盖汽车发动机系统、变速器与离合器系统、座椅系统、内饰系统等结构件及功能件。此外,公司部分产品亦用于精密刀具、电气零部件等领域。公司产品需结合下游客户产品的功能特性、使用环境、加工工艺等进行定向研发识别,经试制后确定差异化的工艺路线与技术参数,并进行批量生产、销售。公司作为专注于定制化精密冲压特殊钢材料领域高新技术企业,注重工艺积累与技术创新。公司技术中心先后被认定为苏州市企业技术中心、苏州市工程技术研究中心、江苏省企业技术中心、江苏省工程技术研究中心,并获“江苏省民营科技企业”、“吴江区领军人才企业”等称号。公司65Mn精冲特殊钢材料被评为苏州市名牌产品,“低屈强比汽车飞轮盘冷轧优质碳素钢带S50C”、“汽车离合器膜片合金弹簧冷轧钢带51CrV4”、“变速箱、分动箱壳体专用冷轧钢带S355MC”等产品列入江苏省重点推广应用的新技术新产品目录。公司与宝钢股份建立了联合工作室,共同开展汽车零部件精冲材料应用技术研究。公司已与慕贝尔、麦格纳、佛吉亚、法雷奥、普思信、法因图尔、新坐标等多家国内外知名汽车零部件供应商建立了长期稳定合作关系。
