## 因果逻辑链
- **[泵业核心主业聚焦]** -> [营收增长4.38%]: 通用设备制造板块收入占比88.37%，同比增长5.57%，是公司整体营收增长的主要驱动力。
- **[成套变频供水设备放量]** -> [产品结构优化]: 该产品收入同比增长39.44%，增速远超传统水泵（1.67%），推动公司从单一设备商向系统解决方案商转型。
- **[液冷泵前瞻布局]** -> [新增长极培育]: 公司已形成覆盖全系列液冷泵与CDU的完整解决方案，切入数据中心液冷高增长赛道，抢占未来市场先机。
- **[融资成本显著下降]** -> [财务结构优化]: 全年平均融资成本率降至2.29%，同比下降73个基点，叠加带息负债余额减少，有效增厚利润。
- **[海外市场持续拓展]** -> [第二增长曲线]: 海外营收9.18亿元，同比增长5.66%，占比提升至17.41%，成为公司重要增长引擎。
- **[环保业务“瘦身健体”]** -> [资产结构优化]: 通过处置亏损子公司、盘活低效资产，环保板块减负增效，但整体盈利水平仍有待提升。
- **[研发高强度投入]** -> [技术护城河加固]: 研发投入2.44亿元，占营收4.62%，新增发明专利12项，CDM(F)系列获新国标首张1级能效认证，巩固行业领先地位。

## 风险警告
**核心风险在于环保业务的历史包袱与应收账款回收压力。** 公司环保板块（废弃资源综合利用、环保咨询与工程）毛利率为负或极低，且存在大量历史诉讼与未决纠纷，持续拖累整体盈利能力。同时，公司应收账款余额高达16.25亿元，占总资产19.42%，信用减值损失达9268万元，对净利润形成显著侵蚀。尽管公司积极通过法律手段催收，但部分客户经营困难，回款风险依然高企。

**另一重大风险是原材料价格波动对毛利率的冲击。** 公司泵类产品核心原材料（电机、不锈钢、铸件）成本占比高达72.45%，其价格深受铜、钢材等大宗商品行情影响。在全球地缘政治不确定性加剧的背景下，原材料价格若持续上涨，将直接压缩公司本已承压的毛利率（通用设备制造板块毛利率同比下降1.69个百分点），对经营效益造成不利影响。
