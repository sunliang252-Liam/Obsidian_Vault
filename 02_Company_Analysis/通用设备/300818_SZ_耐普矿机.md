# 300818.SZ 深度透视

## 因果逻辑链
- **[高基数EPC项目退出]** -> [营收与利润双降]: 2024年额尔登特EPC项目贡献2亿元收入，2025年该项目结束，直接导致总营收同比下滑10%，归母净利润同比下滑33%。
- **[海外生产基地扩张]** -> [资本开支激增，负债率攀升]: 智利、秘鲁等海外工厂建设导致投资活动现金净流出4.56亿元，公司通过增加金融机构借款（短期借款+长期借款）筹资，资产负债率升至44.74%。
- **[汇率剧烈波动]** -> [财务费用大幅侵蚀利润]: 2025年汇率损失1,336.93万元，导致财务费用从-96万元飙升至1,574万元，成为净利润下滑的核心拖累项之一。
- **[全球首创锻造复合衬板]** -> [开辟第二增长曲线]: 新产品成功落地16家矿山企业，斩获1.05亿元订单，性能达金属衬板1.5-2倍寿命，填补了公司在磨机筒体市场的空白。
- **[海外订单高速增长]** -> [收入结构向海外倾斜]: 俄语区(+83.5%)、拉美区(+81.3%)、亚太中东区(+54.6%)订单高速增长，海外收入占比达60.37%，但受汇率及项目结构影响，海外收入总额同比下降19.66%。
- **[高分子复合新材料替代]** -> [核心产品毛利率维持高位]: 矿用橡胶耐磨备件收入增长13.69%，毛利率42.51%，凭借耐磨、轻量化、环保优势持续替代传统金属备件，构成公司利润基本盘。
- **[员工持股计划股份支付]** -> [短期管理费用增加]: 实施员工持股计划产生股份支付费用319.49万元，叠加研发投入增长22%，对当期利润形成额外压力。

## 风险警告
**核心风险在于海外扩张的“双刃剑”效应。** 公司正处于全球化产能建设的高投入期，智利、秘鲁工厂尚未投产，资本开支巨大导致负债率快速攀升（44.74%），且海外工厂投产时间存在不确定性（智利工厂预计2026年底）。若海外项目投产不及预期或当地政治、经济环境发生不利变化，将导致资产减值与现金流压力。同时，公司海外收入占比已超60%，汇率波动（2025年损失1,337万元）已成为常态化利润侵蚀因素，公司缺乏有效的对冲机制。

**成长性面临阶段性瓶颈。** 2025年利润下滑的核心原因是高毛利EPC项目收入归零，而新产品的放量（锻造衬板1.05亿订单）尚不足以完全弥补缺口。公司核心增长逻辑依赖于“设备+备件”的海外市场渗透，但当前海外收入总额同比下降近20%，表明新市场开拓的订单转化为收入存在时滞。此外，公司前五大客户集中度高达46.49%，且客户ZJ、ED等均为大型矿企，若主要客户资本开支放缓，将对公司业绩产生重大冲击。
