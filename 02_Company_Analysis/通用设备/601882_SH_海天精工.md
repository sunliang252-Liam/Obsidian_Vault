# 601882.SH 深度透视

## 因果逻辑链
- **[海外市场高增长]** -> [净利润下降]: 海外收入同比+50%，但国内收入同比-5.94%，国内传统领域需求不足拖累整体盈利。
- **[毛利率承压]** -> [净利润下降]: 整体毛利率下降1.58个百分点，主要因国内经销渠道毛利率下滑3.63个百分点，成本上升快于收入。
- **[销售费用激增]** -> [净利润下降]: 销售费用同比+27.34%，远超收入增速（+0.48%），侵蚀利润空间，反映海外扩张及市场开拓成本上升。
- **[产品结构分化]** -> [业绩波动]: 数控卧式加工中心收入同比-30.25%，而龙门/立式加工中心增长，产品需求结构向特定高端领域倾斜。
- **[经营性现金流改善]** -> [财务健康]: 经营活动现金流净额同比+138.51%，主因材料款支付减少，显示回款能力增强及营运资金管理优化。
- **[海外布局加速]** -> [收入增长]: 海外收入占比提升至16.9%，巴西子公司筹建，海外产能布局成为未来增长新引擎。

## 风险警告
**核心风险在于国内需求疲软与竞争加剧的双重挤压。** 2025年公司净利润同比下降18%，主要源于国内下游传统领域有效需求不足，叠加中低端机床“内卷式”恶性竞争，导致国内收入下滑、毛利率承压。尽管海外市场高增长（+50%）提供了缓冲，但若国内需求持续低迷，公司整体盈利能力将面临进一步考验。

**海外扩张的不确定性是另一重大风险。** 国际地缘政治冲突、贸易保护主义抬头，可能冲击海外市场拓展及产能布局计划。同时，海外销售费用激增（+27.34%），若新市场开拓不及预期，将导致投入产出效率下降，拖累整体利润。此外，公司对经销渠道依赖度高（收入占比73.78%），渠道管理及经销商信用风险需持续关注。
