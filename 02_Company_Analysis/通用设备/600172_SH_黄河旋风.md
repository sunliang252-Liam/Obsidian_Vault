# 600172.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [连续三年巨额亏损]: 行业产能集中释放导致供需失衡，产品价格持续下行，公司2023-2025年累计亏损超27亿元。
- **[高额财务费用侵蚀利润]** -> [盈利能力持续恶化]: 财务费用3.51亿元（同比+16%），占营收比重高达25.9%，利息支出3.14亿元是吞噬利润的主要黑洞。
- **[经营活动现金流由正转负]** -> [造血能力严重衰竭]: 经营现金流净额-1.51亿元（同比-465%），主要因购买商品支付现金大幅增加，公司已无法通过主业产生正向现金流。

- **[净资产大幅缩水]** -> [偿债能力濒临崩溃]: 归属于母公司净资产从24.9亿元骤降至5.6亿元（-62.9%），资产负债率高达91.4%，已处于资不抵债边缘。

## 风险警告
黄河旋风已陷入严重的财务困境。公司连续三年巨亏，2025年净资产仅剩5.6亿元，而短期借款高达23.4亿元，流动负债超过流动资产43亿元，短期偿债能力极度脆弱。经营现金流由正转负，表明公司已丧失自我造血能力，完全依赖外部融资（筹资现金流+2.4亿元）维持运转，一旦融资环境收紧，将面临流动性断裂风险。

核心风险在于行业供需格局的持续恶化。培育钻石价格暴跌、工业金刚石产能过剩，公司作为行业龙头却无法通过技术或规模优势实现盈利，毛利率已降至负值（超硬材料毛利率-5.89%）。同时，高达3.5亿元的财务费用和3.6亿元的资产减值损失形成“双重绞杀”，公司若无法在短期内实现产品结构升级或行业出清，退市风险将急剧上升。
