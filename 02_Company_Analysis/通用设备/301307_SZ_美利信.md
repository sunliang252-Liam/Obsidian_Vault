# 301307.SZ 深度透视

## 因果逻辑链
- **[产能爬坡与规模扩张]** -> [毛利率大幅下滑]: 安徽及美国新工厂投产初期产能利用率低，固定成本摊销高，叠加客户降价压力，导致整体毛利率从9.67%骤降至4.15%。
- **[原材料价格上涨]** -> [成本侵蚀利润]: 铝锭等主要原材料价格上行，直接推高营业成本增速（+12.61%），远超收入增速（+6.13%），是毛利率恶化的核心因素之一。
- **[客户降价压力]** -> [盈利能力承压]: 汽车及通信行业竞争加剧，下游客户持续要求降价，公司议价能力受限，产品售价未能同步覆盖成本上涨。
- **[管理费用与研发投入增加]** -> [期间费用率上升]: 规模扩张导致管理费用增长15.30%，持续加大研发投入（+10.80%），进一步压缩了利润空间。
- **[资产减值损失激增]** -> [净利润大幅亏损]: 计提存货跌价准备及固定资产等减值损失2.09亿元，是导致归母净利润亏损5.67亿元的关键非经营性因素。
- **[财务费用大幅增长]** -> [利息负担加重]: 借款增加导致利息支出同比大幅增长72.15%，财务费用率上升，侵蚀了本就微薄的利润。
- **[汽车业务增长放缓]** -> [收入结构依赖度下降]: 汽车类零部件收入仅增长3.70%，增速远低于行业平均水平，表明公司在该领域的增长动能减弱，未能充分受益于新能源汽车的爆发。
- **[海外收入下滑]** -> [全球化战略受挫]: 海外地区收入同比下降17.27%，主要受美国关税政策及新工厂产能爬坡影响，全球化布局短期承压。

## 风险警告
**核心风险：盈利能力急剧恶化与债务压力攀升的恶性循环。** 公司2025年归母净利润巨亏5.67亿元，毛利率从9.67%暴跌至4.15%，经营现金流同比锐减79.77%。与此同时，为支撑产能扩张，公司有息负债大幅增加，资产负债率上升，财务费用激增72.15%。在盈利未见改善、现金流持续恶化的背景下，公司偿债能力显著削弱，存在流动性风险。

**次要风险：产能扩张效益不及预期与客户集中度风险。** 安徽、美国等新工厂仍处于产能爬坡期，短期内将持续拖累整体盈利。公司前五大客户销售额占比高达52.50%，对头部客户依赖度较高，一旦主要客户订单波动或持续压价，将对公司经营产生重大冲击。此外，母公司报表存在未弥补亏损，已不具备现金分红条件，短期股东回报预期极低。
