# 000837.SZ 秦川机床 深度透视

## 因果逻辑链
- **[产品结构升级与市场拓展]** -> [营收增长5.96%]: 机床类（+6.02%）和零部件类（+7.14%）收入增长，抵消了贸易类收入下降的负面影响。
- **[非经常性损益依赖]** -> [扣非净利润为负（-7167万）]: 核心主业盈利能力不足，净利润主要依赖资产处置收益（8166万）和政府补助（6918万）等非经常性项目。
- **[资产减值侵蚀利润]** -> [利润总额承压]: 报告期计提资产减值损失1.03亿元，占利润总额的-149.62%，严重拖累当期业绩。
- **[经营现金流大幅改善]** -> [现金流与净利润背离]: 经营活动现金流净额增长103%至3.17亿元，主要系回款增加，表明营运效率有所提升，但未转化为净利润。
- **[股权激励费用影响]** -> [剔除激励后净利润增长32.42%]: 实施首期限制性股票激励计划，产生股份支付费用，若剔除该影响，公司实际经营利润有所改善。
- **[新能源与机器人赛道驱动]** -> [高端产品需求增长]: 新能源磨齿机销量连续两年增长超50%，工业机器人关节减速器产品线丰富，成为核心增长引擎。
- **[“宝汉天”集群建设]** -> [产业链协同效应]: 作为“链主”企业牵头国家级先进制造业集群，通过整合资源、协同创新，提升区域产业生态主导能力。

## 风险警告
**核心风险在于盈利质量极差，高度依赖非经常性损益。** 公司扣非净利润已连续三年为负，2025年亏损额扩大至-7167万元。利润表上的微薄净利润（5289万）完全由资产处置（卖地收益8166万）和政府补助（6918万）支撑，一旦这些非持续性收益减少，公司将立即陷入亏损。这暴露了公司主营业务的造血能力严重不足，机床主业在激烈竞争中尚未建立起可持续的盈利模式。

**第二大风险是资产减值压力巨大，且存货风险高企。** 报告期计提1.03亿元资产减值损失，占利润总额比例极高。同时，零部件类产品库存量同比暴增107.5%，显示下游需求或销售渠道可能出现阻滞，大量积压的存货未来可能面临进一步的跌价风险，持续侵蚀公司利润。此外，子公司汉江机床亏损3609万元，也反映出内部经营分化严重。
