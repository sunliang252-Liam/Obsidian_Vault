# 301616.SZ 深度透视

## 因果逻辑链
- **[下游注塑机行业景气度复苏]** -> [营收增长8.77%]: 下游主要客户（海天国际、伊之密等）经营业绩同比增长，带动公司螺杆、机筒等核心零部件订单增加。
- **[非经常性资产处置收益]** -> [净利润暴增111.78%]: 子公司宁波华业处置土地及房屋，确认资产处置收益约1.45亿元，是归母净利润从0.93亿跃升至1.97亿的核心原因。
- **[扣非净利润仅增长2.87%]** -> [核心盈利能力增长平缓]: 剔除资产处置等非经常性损益后，公司主营业务的盈利能力并未出现爆发式增长，增长幅度远低于营收增速。
- **[原材料成本与制造费用上升]** -> [毛利率承压]: 螺杆机筒和哥林柱产品毛利率均出现下滑（分别下降1.25%和0.39%），主要受直接材料、人工及制造费用（尤其是折旧）增加影响。
- **[上市募集资金与偿还债务]** -> [财务费用大幅下降71.08%]: 2025年3月IPO上市，募集资金用于偿还部分短期借款，导致利息支出减少，同时现金管理增加利息收入。
- **[管理费用激增38.52%]** -> [上市相关费用拖累当期利润]: 管理费用增加主要系支付上市相关的信息咨询费、服务费等，对当期扣非净利润形成直接压力。
- **[经营活动现金流净额下降55.58%]** -> [利润与现金流的严重背离]: 净利润大增但经营现金流锐减，主因是子公司土地处置收益产生大量应交税费（支付税费同比增74.94%），导致现金流出大幅增加。

## 风险警告
**核心风险在于业绩的“一次性”与“可持续性”之间的巨大鸿沟。** 2025年净利润暴增111.78%的辉煌，几乎完全由子公司土地处置带来的1.45亿非经常性收益所驱动。剔除这一因素后，扣非净利润仅微增2.87%，与8.77%的营收增速严重不匹配，揭示出公司核心业务的盈利能力增长乏力，甚至出现增收不增利的隐忧。投资者必须清醒认识到，这种高增长不具备可持续性，2026年业绩将面临高基数的巨大压力。

**经营层面的风险同样不容忽视。** 公司毛利率下滑、管理费用因上市费用激增，均侵蚀了主营业务的利润空间。此外，经营活动现金流净额同比腰斩，表明利润质量不高，现金回收能力减弱。公司作为典型的制造业企业，还面临原材料（钢材）价格波动、安全生产事故（报告期内已发生并受罚）以及核心技术人员流失等多重风险，这些都可能对未来的稳定经营构成实质性威胁。
