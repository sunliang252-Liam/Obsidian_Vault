# 300257.SZ 深度透视

## 因果逻辑链
- **[地热电站“边建设、边发电”模式]** -> [现金流与项目滚动开发]: 独创的井口模块电站技术将地热开发从“一次性重资产投入”转变为“分期滚动开发”，实现早期发电收益反哺后续建设，降低资金压力并加速项目扩张。
- **[全球地热资产组合与长期PPA]** -> [稳定且可预测的境外现金流]: 在印尼、肯尼亚、美国等地持有运营中及在建地热电站，签署15-32年美元/欧元计价的“照付不议”购电协议，形成抗周期、高确定性的“现金奶牛”型收入，支撑公司战略转型。
- **[压缩机业务向高端与氢能转型]** -> [传统业务“稳定器”作用与第二增长曲线]: 从低端空压机向干式无油螺杆、离心压缩机、氢压缩机等高端产品升级，160kW以上大功率机组销量增长46.67%，同时氢压缩机在氢冶金、加氢站等场景取得突破，为传统业务注入新动力。
- **[地热+绿氢氨醇一体化项目落地]** -> [商业模式从设备销售向长期运营跨越]: 肯尼亚Olkaria年产20万吨绿氨项目（全球首座地热制绿氨工厂）启动，标志着公司从“卖设备/建电站”升级为“绿电-绿氢-绿氨”系统解决方案提供商，盈利模式转向长达25-30年的稳定运营现金流。
- **[全球多基地制造与销售网络]** -> [对冲贸易壁垒与地缘风险]: 通过在美国、奥地利、土耳其、印度等地设立制造基地和销售公司，构建本地化供应链，有效应对中美关税、欧盟碳税等贸易壁垒，同时实现全球市场全覆盖。
- **[EGS（增强型地热系统）技术合作]** -> [打开地热资源天花板]: 与美国Power Planet公司合作开发EGS项目，突破传统地热对天然高渗透储层的依赖，将地热资源潜力从“小众”提升至“主流”，为公司北美市场扩张提供巨大想象空间。

## 风险警告
**核心风险在于地热项目开发进度不及预期与高资本开支压力。** 公司地热电站建设周期长、前期勘探和钻井风险高，且在美国等市场面临严格的环评审批和电网并网拥堵（全美排队并网项目超2,000吉瓦），导致项目从立项到COD的周期可能远超预期，拖累EBITDA增长和现金流回报。同时，公司资产负债率较高，持续的大规模资本开支（如肯尼亚绿氨项目8.3亿美元投资）对融资能力和财务稳健性构成考验。

**另一重大风险是海外业务的地缘政治与汇率波动。** 公司约47%收入来自境外，且地热PPA多以美元/欧元计价。若项目所在国（如印尼、肯尼亚、土耳其）出现政策变动、货币大幅贬值或外汇管制，将直接影响电费收入的实际价值与汇回能力。此外，中美贸易摩擦及欧盟碳边境调节机制（CBAM）可能推高公司产品进入欧美市场的成本，削弱压缩机业务的竞争力。
