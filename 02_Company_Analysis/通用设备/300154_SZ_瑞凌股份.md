# 300154.SZ 深度透视

## 因果逻辑链
- **[主营业务收入下滑]** -> [净利润大幅下降30.55%]: 营业收入同比降11.89%至8.94亿元，核心产品逆变焊割设备、焊接材料及海外销售均出现显著下滑，导致利润端承压。
- **[非经常性损益依赖]** -> [扣非净利润仅占归母净利润45%]: 2025年归母净利润1.04亿元，但扣非净利润仅0.47亿元，非经常性损益（主要是理财收益）贡献过半，主业盈利能力弱化。
- **[海外市场收缩]** -> [国外销售收入同比降28.29%]: 受国际形势复杂、贸易保护主义及美国关税政策多变影响，海外业务收入从1.95亿降至1.40亿，成为营收下滑的最大拖累。
- **[焊接材料业务骤降]** -> [该产品收入同比降50.84%]: 焊接材料类产品收入从1.18亿腰斩至0.58亿，是分产品中降幅最大的品类，反映下游需求或渠道结构发生重大变化。
- **[经营现金流大幅改善]** -> [经营活动现金流净额同比增257.94%]: 尽管利润下滑，但公司通过加强销售回款和管控库存，实现经营现金流1.38亿元，现金质量显著优于利润表现。
- **[高端制造产业园投入]** -> [在建工程同比增694%]: 公司正推进顺德高端装备智能制造产业园建设，在建工程从0.21亿增至1.64亿，预示未来资本开支和折旧压力将显著增加。
- **[金融资产投资贡献大]** -> [投资收益与公允价值变动合计占利润总额50.19%]: 公司利用闲置资金进行证券及理财产品投资，报告期产生约0.59亿元收益，成为利润的重要支撑，但具有高度不确定性。

## 风险警告
**核心风险在于主业增长乏力与对金融投资收益的过度依赖。** 公司营收连续两年下滑（2024年-11.8%，2025年-11.9%），核心的逆变焊割设备及焊接材料业务均出现萎缩，海外市场受地缘政治冲击大幅收缩。而公司归母净利润中超过一半来自理财和证券投资收益，这部分收益波动性极大，2024年曾高达1.14亿元，2025年已降至0.50亿元，若未来市场环境恶化，利润将面临巨大回撤风险。

**另一重大风险是激进的资本开支与产能消化不确定性。** 公司正在建设的高端装备智能制造产业园项目投资总额预计不超过4.3亿元，报告期末在建工程已大幅增加。在主营业务收入持续下滑的背景下，大规模扩产可能导致产能利用率不足、折旧摊销激增，进一步侵蚀本已脆弱的盈利能力。同时，公司存货余额同比增加18.9%，若下游需求持续疲软，存货跌价风险将加剧。
