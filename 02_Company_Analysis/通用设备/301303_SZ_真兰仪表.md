# 301303.SZ 深度透视

## 因果逻辑链
- **[政策驱动存量替换]** -> [营收增长18.75%]: 国家推动城镇燃气管道老化更新与城市生命线安全工程，直接拉动智能燃气表、水表的存量替换需求，公司核心仪表业务收入增长17.39%。
- **[全产业链自制降本]** -> [毛利率维持高位]: 公司拥有模具、注塑、SMT、整机装配的全产业链能力，核心零部件自主生产，有效控制成本，仪表业务毛利率稳定在41.11%。
- **[水表业务快速放量]** -> [第二增长曲线成型]: 依托德国ZENNER品牌与技术复用，智能水表产品快速切入水务集团集采体系，水表基地项目启动，成为新的营收增长点。
- **[海外市场稳健拓展]** -> [外销收入持平]: 产品通过多项国际认证，远销60余国，但受全球贸易保护主义及地缘政治影响，外销收入仅微增0.19%，增长承压。
- **[研发投入聚焦国产替代]** -> [超声波表核心模组自研]: 持续高研发投入（占营收6.36%），自研超声波计量模组实现国产替代，成功供货上海燃气、华润燃气等大型客户，提升产品竞争力。
- **[经营现金流大幅改善]** -> [现金流与净利润匹配度提升]: 销售收入增加及回款改善，经营活动现金流净额同比增长97.97%至3.28亿元，显著高于净利润增速，盈利质量提升。
- **[汽车零部件业务拓展]** -> [多元化布局初显]: 依托精密制造能力切入新能源汽车外饰件领域，收入增长28.54%，但毛利率仅9.54%，尚处培育期，对整体利润贡献有限。

## 风险警告
**1. 应收账款高企与坏账风险。** 公司应收账款余额高达11.90亿元，占总资产24.78%，且增速（17.4%）接近营收增速（18.75%）。尽管客户多为国企背景，但若下游燃气、水务运营商资金紧张或回款周期延长，将导致公司现金流承压，并可能引发大额信用减值损失，侵蚀利润。

**2. 增量市场放缓与竞争加剧。** 房地产行业不景气直接影响燃气表、水表的新装增量市场。存量市场竞争日趋激烈，公司面临来自同行及上下游延伸企业的双重挤压。若公司不能在价格、服务或技术上持续保持优势，市场份额和毛利率存在下滑风险。
