# 002347.SZ 深度透视

## 因果逻辑链
- **[激光业务规模效应不足]** -> [整体毛利率大幅下滑5.84个百分点]: 激光业务处于市场拓展期，订单未形成规模，前期投入的设备及人工等固定成本高企，严重拖累整体盈利。
- **[基金投资收益锐减]** -> [净利润暴跌750.71%]: 2025年投资收益仅53.6万元，较上年同期减少3456万元，是导致归母净利润由盈转亏的核心因素之一。
- **[核心设备收入萎缩]** -> [营收增长乏力]: 核心设备收入同比下降27.95%，抵消了核心备件、总包服务等业务的增长，导致总营收仅微增1.49%。
- **[子公司泰尔激光巨额亏损]** -> [合并报表净利润承压]: 泰尔激光全年亏损6798万元，是公司亏损的最大单一来源，反映出新业务孵化期的巨大财务压力。
- **[加强应收账款管理]** -> [经营现金流大幅改善]: 经营活动现金流净额从-279万元跃升至7248万元，主要得益于销售回款效率提升，但利润与现金流的背离凸显盈利质量隐患。
- **[存货跌价损失扩大]** -> [资产减值损失增加]: 2025年资产减值损失达2619万元，主要为存货跌价损失，反映下游需求波动及产品迭代带来的库存风险。
- **[债务重组损失]** -> [非经常性损益恶化]: 2025年产生债务重组损失597万元，而上年同期为收益1797万元，加剧了净利润的下滑。

## 风险警告
**核心风险在于新业务“失血”与主业“失速”的双重困境。** 公司寄予厚望的激光业务（泰尔激光）全年亏损近6800万元，且未见规模效应拐点，持续吞噬传统主业利润。同时，核心设备收入同比大幅下滑28%，传统优势产品增长乏力，公司面临新旧动能转换期的“青黄不接”。若激光业务不能快速实现订单放量与成本摊薄，公司盈利能力将持续承压。

**财务风险不容忽视。** 尽管经营现金流因加强回款管理而改善，但公司净利润已连续两年为负（2023年、2025年），且2025年扣非后亏损高达1.05亿元，主业造血能力堪忧。此外，应收账款规模高达7.22亿元，占总资产30%，客户集中于钢铁行业，在行业下行周期中坏账风险敞口较大。公司已连续两年未进行现金分红，投资者回报预期薄弱。
