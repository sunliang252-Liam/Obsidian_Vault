# 300906.SZ 深度透视

## 因果逻辑链
- **[国铁集团客户高度集中]** -> [营收增长但利润下滑]: 对国铁集团销售收入占比超50%，客户集中度极高，导致2025年归母净利润同比下降23.85%，主要因非经常性损益（政府补助、减值转回）大幅减少。
- **[核心产品“轨道几何状态检测系统”稳健]** -> [营收基本盘稳固]: 该产品营收1.02亿元，同比增长2.98%，毛利率高达71.91%，是公司最稳定的利润来源。
- **[“轨道工机具系统及服务”高增长]** -> [业务结构优化]: 该板块营收6655万元，同比增长18.40%，显示公司从卖设备向“设备+服务”模式转型取得成效。
- **[研发投入持续高企]** -> [技术壁垒巩固]: 研发费用占营收9.66%，新增9项发明专利，维持了“专精特新小巨人”地位，但研发成果转化为大规模营收尚需时间。
- **[应收账款高企与坏账风险]** -> [现金流承压]: 应收账款余额高达2.43亿元，坏账准备7055万元，导致经营活动现金流净额同比大降47.89%，盈利质量堪忧。
- **[超募资金大量闲置]** -> [资本效率低下]: 上市募集资金净额4.82亿元，截至2025年末仍有2.47亿元未使用，大量资金用于理财，而非投入主业扩张。
- **[“十五五”铁路投资规划]** -> [长期需求确定]: 国铁集团规划到2030年全国铁路营业里程达18万公里，高铁6万公里，为公司轨道检测设备及服务提供了长期稳定的市场空间。

## 风险警告
**核心风险在于客户高度集中与应收账款恶化。** 公司超50%收入来自国铁集团，议价能力弱，回款周期长。2025年应收账款余额高达2.43亿元，坏账准备超7000万元，导致经营性现金流同比暴跌47.89%，盈利质量与账面利润严重背离。若国铁集团投资放缓或付款政策收紧，公司将面临现金流断裂与大规模坏账的双重打击。

**成长性不足与资本效率低下是另一隐忧。** 公司营收仅增长6.17%，扣非净利润增长3.97%，远低于行业增速。上市募集的近5亿元资金中，超2.4亿元闲置，大量用于购买理财而非投入研发或并购，表明公司缺乏清晰、高效的资本扩张路径。在行业竞争加剧的背景下，仅靠现有产品线难以实现突破性增长。
