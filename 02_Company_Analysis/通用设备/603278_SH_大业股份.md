# 603278.SH 深度透视

## 因果逻辑链
- **[原材料成本下降]** -> [毛利率提升]: 主要原材料盘条采购单价下降，使营业成本降幅（-4.88%）显著大于收入降幅（-1.40%），推动综合毛利率增加3.30个百分点。
- **[产品销量增长]** -> [收入稳定]: 尽管产品售价随原材料降价而下调，但胎圈钢丝、钢帘线销量分别增长2.97%和6.23%，以量补价，使营收仅小幅下滑1.40%。
- **[行业竞争加剧]** -> [增产不增利]: 行业产能集中释放，市场竞争白热化，公司虽销量创历史新高，但归母净利润仍为负值（-1,347万元），仅实现大幅减亏。
- **[绿色能源项目投资]** -> [现金流恶化]: 200MW风电、生物质热电联产等新能源项目大规模建设，在建工程同比暴增112.76%，导致经营活动现金流净额由正转负，为-1.18亿元。
- **[海外基地筹建]** -> [资本开支增加]: 摩洛哥生产基地进入筹备阶段，叠加国内新能源项目，长期应付款（融资租赁）同比激增200.60%，推高财务杠杆。
- **[高端产品结构优化]** -> [盈利改善]: 推动胎圈钢丝向超高强度升级，扩大工程胎及新能源车配套钢帘线产能，产品附加值提升，是毛利率改善的核心驱动力之一。
- **[收购整合效应]** -> [子公司分化]: 收购的胜通钢帘线实现净利润4,026万元，成为主要利润来源；而新材料子公司亏损6,791万元，拖累整体业绩。

## 风险警告
**核心风险在于“增收不增利”与现金流危机并存。** 公司虽通过降本增效实现大幅减亏，但归母净利润仍为负，且经营活动现金流净额由2024年的4.87亿元骤降至-1.18亿元，恶化124.22%。这主要源于大规模新能源项目（风电、生物质）的资本开支，导致公司对融资租赁和借款的依赖度急剧上升，长期应付款和一年内到期非流动负债合计暴增，财务费用高企（1.2亿元），侵蚀了本已微薄的利润空间。

**第二大风险是行业竞争格局恶化与海外扩张的不确定性。** 骨架材料行业已进入成熟期，头部企业扩产、上游企业延伸产业链，导致产能过剩、价格承压。公司虽计划通过摩洛哥基地“走出去”规避贸易摩擦，但海外项目前期投入巨大，且面临地缘政治、当地政策及管理整合等不确定性，短期内将加剧公司的资金压力和管理负担，能否成功转化为利润增长点尚需观察。
