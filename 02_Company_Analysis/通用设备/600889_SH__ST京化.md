# 600889.SH 深度透视

## 因果逻辑链
- **[重大资产重组完成]** -> [主营业务彻底转型]: 2026年3月置出全部亏损化纤资产，置入滚动功能部件龙头南京工艺，公司从化学纤维制造商变身高端装备核心零部件供应商。
- **[原有化纤业务持续巨亏]** -> [触发退市风险警示]: 2025年扣非净利润-1.83亿元，营收扣除后仅2.64亿元，触及“净利润为负+营收低于3亿元”的退市风险警示红线。
- **[莱赛尔纤维项目试车失败]** -> [资产减值与收入归零]: 设备故障导致试运行中断，全年无自产销量，直接拖累营收同比大降54.64%，并引发大额资产减值损失。
- **[粘胶短纤主动停产检修]** -> [短期减亏但丧失市场份额]: 为优化经营结果动态调整生产计划，销量同比骤降66.21%，虽减少亏损但导致营收规模大幅萎缩。
- **[政府征收补偿款]** -> [非经常性收益支撑报表]: 报告期内收到土地征收补偿款8172.5万元，是公司实现归母净利润-9994万元而非更差的关键非经常性损益来源。
- **[向控股股东大额借款]** -> [缓解流动性危机]: 向新工集团借款3亿元，利率2.7%，其他应付款同比暴增121.91%，显示公司原有业务已无法自我造血。
- **[南京工艺注入]** -> [基本面根本性改善]: 南京工艺为制造业单项冠军，国产替代空间广阔（高端市场国产化率仅约5%），置入后公司盈利能力和资产质量将彻底改观。

## 风险警告
**退市风险警示已触发，新旧业务断层期存在巨大不确定性。** 公司2025年年报披露后因财务指标触及红线将被实施*ST，虽然重大资产重组已在2026年3月完成交割，但新旧业务切换的“真空期”内，若市场对公司重组后的持续经营能力产生质疑，股价可能面临剧烈波动。投资者需警惕重组后业绩承诺不达预期、整合不及预期的风险。

**南京工艺面临的市场竞争与技术迭代风险不容忽视。** 虽然国产替代空间广阔，但中高端市场长期被德国、日本企业垄断，公司需在“高速、精密、重载、复合、智能”等方向持续突破。若未来不能紧跟下游数控机床、半导体设备等行业的技术升级需求，或在行星滚柱丝杠等新产品研发上落后于竞争对手，将面临市场份额被侵蚀的风险。此外，下游制造业周期波动将直接影响公司业绩稳定性。
