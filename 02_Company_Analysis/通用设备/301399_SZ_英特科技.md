# 301399.SZ 深度透视

## 因果逻辑链
- **[下游需求疲软与行业竞争加剧]** -> [营收与利润双降]: 2025年营收同比下滑10.83%，归母净利润同比下滑45.48%，主因下游热泵行业销售额整体下滑2.8%，以及客户持续降价压力。
- **[原材料成本刚性]** -> [毛利率承压]: 直接材料占营业成本76.73%，铜材等价格波动无法完全通过定价机制转嫁，导致换热器毛利率同比下降1.81个百分点。
- **[核心产品收入萎缩]** -> [业绩基本盘动摇]: 换热器产品收入同比减少15.56%，而分配器及其他产品虽增长28.26%，但毛利率仅5.21%，无法弥补核心业务下滑。
- **[募投项目产能释放不及预期]** -> [资产回报率下降]: 年产17万套高效换热器项目于2024年结项，2025年实现收益1855.77万元，未达预期，加权平均净资产收益率从4.52%降至2.45%。
- **[大客户集中度高]** -> [议价能力受限]: 前五大客户销售额占比48.24%，其中客户一占比26.10%，公司对头部客户依赖度高，在降价谈判中处于相对弱势。
- **[研发投入持续但转化滞后]** -> [短期业绩贡献有限]: 研发费用同比增长4.70%至2595万元，聚焦R32环保冷媒、液冷散热等新品，但尚处研发阶段，未形成规模化收入。
- **[对外投资扩张]** -> [现金流承压]: 投资活动现金流净额同比减少57.99%，主要系新增对外投资（如参股艾弗洛）及在建工程投入（蒸发式冷凝器项目），短期内无法贡献正向现金流。

## 风险警告
**核心风险在于业绩下滑趋势尚未见底。** 2025年营收、净利润、经营现金流全面下滑，且降幅逐季扩大（Q4净利润仅1038万，为全年最低）。公司核心产品换热器收入萎缩15.56%，而新业务（分配器及其他）毛利率极低，无法形成有效替代。更关键的是，公司承认“持续的降价压力给公司今年的业绩带来了冲击和挑战”，这意味着价格战可能成为常态，而非短期波动。

**募投项目效益不达预期与产能过剩风险并存。** 年产17万套高效换热器项目已结项，但2025年实现收益仅1855万元，远低于预期。同时，年产1000套蒸发式冷凝器项目仍在建设，若下游需求持续疲软，新增产能可能进一步拉低资产周转率，导致ROE持续走低。此外，公司存货同比增加20.82%，库存积压风险正在累积。
