# 300828.SZ 深度透视

## 因果逻辑链
- **[市场竞争加剧+原材料成本上涨]** -> [毛利率全面承压]: 电力电子散热器毛利率下降2.66%，汽车轻量化部件毛利率骤降5.91%，直接导致净利润暴跌41%。
- **[废料处理方式变更]** -> [其他业务收入锐减27.69%]: 废料由对外销售转为委托加工，减少约3900万元收入，拖累整体营收下降4.46%。
- **[汽车轻量化部件订单结构变化]** -> [产量激增但利润稀薄]: 电池箱体配件等小件订单增加，产量+59.89%，但毛利率仅9.60%，增收不增利。
- **[实际控制人变更为黄山国资]** -> [治理结构重塑]: 2025年8月完成控制权变更，董事会换届、取消监事会，引入国资管理团队，战略方向面临调整。
- **[泰国基地投产]** -> [海外产能落地]: 锐新泰国基本达产，为规避关税风险、拓展海外市场提供产能基础，但短期尚未贡献显著利润。
- **[研发投入持续加码]** -> [技术储备深化]: 研发费用+6.38%，完成锻压针柱铜散热器全流程工艺开发，但尚未转化为业绩增长。
- **[汇兑损失增加]** -> [财务费用飙升157.57%]: 人民币汇率波动导致财务费用从-189万转为118万，侵蚀利润。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 汽车轻量化部件产量暴增59.89%，但毛利率仅9.60%，且同比下滑5.91个百分点，说明公司为争夺市场份额，承接了大量低毛利、低附加值的订单。这种以牺牲利润换取收入的策略不可持续，一旦原材料铝价继续上涨或客户进一步压价，该业务可能陷入亏损。同时，电力电子散热器作为传统优势业务，毛利率也在下滑，显示核心护城河正在被侵蚀。

**另一个重大风险是国资入主后的整合不确定性。** 2025年8月公司实际控制人变更为黄山市国资委，原创始团队核心人物国占昌、刘建、刘国才等相继离任关键管理岗位。新管理层（凌沧桑、张旭等）来自国资体系，缺乏精密制造行业经验。新旧管理团队的磨合、战略方向的调整（如拟收购芜湖德恒汽车装备）能否产生协同效应，存在巨大变数。若整合失败，可能导致核心客户流失、管理效率下降。
