# 603339.SH 深度透视

## 因果逻辑链
- **[下游化工行业周期性低谷]** -> [罐式集装箱业务量价齐跌]: 下游化工需求萎缩导致罐箱销量下降3.83%，毛利率骤降8.63个百分点，是公司整体利润下滑34.89%的主因。
- **[罐箱业务毛利率大幅下滑]** -> [公司整体盈利能力恶化]: 罐箱业务占营收55.73%，其毛利率从20.9%降至12.27%，直接拖累综合毛利率和净利润。
- **[冷链设备出口强劲增长]** -> [部分对冲罐箱下滑]: 冷链设备外销保持增长，毛利率逆势提升3.42个百分点，成为业绩的稳定器。
- **[经营活动现金流大幅转正]** -> [营运效率显著改善]: 经营现金流从-8086万飙升至5.59亿，主因是购买商品支付的现金减少，反映公司在行业低谷期主动控制采购和库存。
- **[合同负债大幅增长40.97%]** -> [在手订单充足]: 预收货款从4.91亿增至6.92亿，预示未来收入有较强支撑，但需关注订单转化为收入的节奏。
- **[在建工程翻倍增长]** -> [产能扩张投入期]: 在建工程从1.97亿增至4.17亿，主要为LNG绝热材料和特种罐箱项目，是未来增长点，但短期增加折旧和资金压力。
- **[研发投入维持高位]** -> [技术壁垒构筑]: 研发费用率4.49%，新增18项发明专利，在特种罐箱（溴素、T75液氮）和冷链（3D流场速冻、CO2制冷）上取得突破，巩固行业领先地位。

## 风险警告
公司当前最大风险是罐式集装箱业务的周期性依赖。2025年业绩大幅下滑直接源于下游化工行业低谷，而罐箱业务贡献超半壁江山，导致公司盈利对单一行业景气度高度敏感。尽管冷链设备出口强劲，但体量尚不足以完全对冲罐箱下行风险。若化工行业复苏不及预期，公司业绩将持续承压。

其次，公司正处于产能扩张期（在建工程翻倍），LNG绝热材料项目尚在认证阶段，特种罐箱项目也需市场验证。大规模资本开支将带来折旧增加和现金流压力，若新项目投产后的市场拓展或技术认证受阻，可能形成资产减值风险。此外，原材料（不锈钢）价格波动和汇率风险也是持续存在的经营变量。
