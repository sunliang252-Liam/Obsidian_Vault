## 因果逻辑链
- **[新增订单高增长]** -> [收入增长24.39%]: 全年新增订单22.32亿元（+45.22%），为未来收入确认奠定基础，但当期收入增速低于订单增速，反映项目交付周期长。
- **[海外市场爆发]** -> [海外收入增长364.94%]: 海外项目落地3.55亿元（+47.92%），直接面向国外客户签约南非、西班牙等项目，培育新增长极。
- **[行业竞争加剧]** -> [毛利率下降4.81个百分点]: 智能制造业务受特殊行业充分竞争影响，综合盈利性下降，导致营收增长但净利润下滑2.32%。
- **[研发高投入]** -> [技术壁垒与新品迭代]: 研发投入1.45亿元（占营收9.63%），推出锤头鲨装卸车机器人、料箱四向穿梭车等新品，维持软硬件自研自产的核心优势。
- **[大客户集中]** -> [业绩波动风险]: 前五大客户销售额占比41.63%，其中比亚迪、宁德时代合计占比29.09%，单一客户订单波动对业绩影响显著。
- **[项目周期长]** -> [营运资金占用]: 大项目从签约到验收通常需1年以上，导致存货（+45.30%）和合同负债（+87.82%）大幅增加，占用公司营运资金。
- **[RaaS代运营模式]** -> [收入结构优化]: 代运营服务收入下降48.97%，但运营维护服务收入增长17.16%，公司正从一次性系统销售向持续性服务收入转型。
- **[应收账款及合同资产增长]** -> [坏账风险]: 质保期在1年以上的质保金（其他非流动资产）增长70.91%，应收账款及合同资产余额可能进一步增加。

## 风险警告
**核心风险在于“增收不增利”与“大客户依赖”的双重挤压。** 2025年营收增长24.39%，但净利润反降2.32%，毛利率下滑4.81个百分点，直接原因是新能源等特殊行业竞争加剧导致项目盈利性下降。若该趋势延续，公司可能陷入“以价换量”的恶性循环，侵蚀长期盈利能力。同时，前两大客户（比亚迪、宁德时代）贡献近三成收入，单一客户订单波动或行业周期下行将直接冲击业绩稳定性。

**项目交付周期长与营运资金压力是另一重大隐患。** 公司存货和合同负债均大幅增长，反映在手订单充足但交付周期长（通常超1年），大量资金沉淀于项目执行中。若客户修改方案或宏观经济波动导致项目延期，将加剧运营成本并影响利润率。此外，海外业务虽增长迅猛，但海外子公司（兰剑德国、美国、匈牙利）均处于亏损状态，国际化扩张的短期盈利贡献有限。
