# 688628.SH 深度透视

## 因果逻辑链
- **[越南基地投产与产能爬坡]** -> [毛利率下降1.85个百分点]: 越南工厂前期未形成规模产出，制造成本高企，拉低了整体毛利率。
- **[持续高强度研发投入]** -> [研发费用同比+24.61%，占营收11.95%]: 公司聚焦高端示波器、射频仪器及AI+示波器，研发人员增至383人，费用达1.46亿元。
- **[股权激励费用确认]** -> [净利润减少约1258万元]: 2022年及2024年两期限制性股票激励计划，对当期归属股东净利润产生较大冲击。
- **[专业仪表与测试仪器增长]** -> [营收同比增长7.99%至12.21亿元]: 专业仪表（+21.26%）和测试仪器（+16.85%）成为核心增长引擎，弥补了通用仪表增速放缓。
- **[ODM业务毛利率大幅下滑]** -> [ODM毛利率同比下降7.06个百分点至36.44%]: 越南产能爬坡及上游材料价格降幅收窄，对ODM业务的成本端冲击最为显著。
- **[经营活动现金流净额骤降74%]** -> [现金流仅5051万元]: 支付货款增加、员工薪酬增长及存货备料增加，导致经营性现金流大幅恶化。
- **[示波器前端芯片自主流片]** -> [关键器件自主可控]: VG500、FG10、FD10三款芯片流片成功，降低供应链风险，为高端示波器持续升级提供保障。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长7.99%，但归母净利润却下滑17.54%，扣非净利润下滑15.83%。核心拖累项是越南基地投产带来的短期成本阵痛，以及持续高强度的研发与销售费用投入。更值得警惕的是，经营活动现金流净额同比暴跌74%至仅5051万元，远低于净利润水平，表明利润质量堪忧，且存货激增29.73%至4.8亿元，存在潜在的减值风险。

**竞争与市场风险不容忽视。** 公司虽在示波器、射频仪器等高端领域取得突破，但面临福迪威、是德科技等国际巨头的品牌与技术压制。ODM业务毛利率骤降7个百分点，显示代工业务议价能力减弱。此外，海外业务以美元结算，汇率波动风险持续存在，而宏观地缘政治风险也可能对境外销售造成冲击。公司能否在高端化转型中持续扩大市场份额，并有效消化越南产能的初期成本，是未来业绩能否反转的关键。
