# 605011.SH 深度透视

## 因果逻辑链
- **[煤炭价格下行]** -> [营收与成本双降]: 2025年煤炭原材料价格下降，直接导致煤炭贸易收入同比-12.11%，同时蒸汽销售单价随之下调，热电联产收入同比-5.83%，但成本下降幅度更大，毛利率基本稳定。
- **[电力市场化改革]** -> [售电单价下降]: 浙江省自2025年起将非统调煤电全面纳入电力交易市场，导致公司电力产品收入同比-7.7%，成为营收下滑的核心因素之一。
- **[原材料价格联动机制]** -> [蒸汽收入被动调整]: 蒸汽价格执行煤（气）热价格联动机制，随煤炭、天然气价格下降而下调，导致蒸汽收入同比-5.47%，但成本下降幅度略低，毛利率微降。
- **[下游需求疲软]** -> [自产蒸汽与电力销量下滑]: 受宏观经济影响，下游客户生产需求下降，导致自产蒸汽销售量同比-2.64%，电力销售量同比-1.23%，量价齐跌压制主业增长。
- **[工程业务收缩]** -> [其他业务收入下降]: 报告期工程安装业务承接量减少，进一步拖累整体营收表现。
- **[绿色转型项目投产]** -> [新增利润增长点]: 安吉天子湖燃煤耦合项目和临江资源综合利用项目投入运行，贡献固废处置等新业务收入，部分对冲了传统业务下滑。
- **[参股公司贡献稳定]** -> [投资收益成利润支柱]: 对联营企业（如上虞杭协）的投资收益达8086.78万元，占归母净利润的43.4%，成为公司利润的重要稳定器。
- **[煤炭采购高度集中]** -> [供应链风险与议价能力并存]: 前五大供应商采购额占比83.32%，其中向伊泰申浦一家采购占比63.71%，依赖度极高，但长期合同也锁定了成本优势。

## 风险警告
**核心风险在于“量价双杀”与政策依赖。** 公司营收与利润双降，根本原因是电力市场化改革导致电价下跌，叠加宏观经济疲软导致下游热负荷需求不足。这两大因素短期内难以逆转，将持续压制公司核心热电业务的盈利空间。此外，煤炭贸易毛利率极低（1.99%），且收入占比近半，该业务对煤价波动高度敏感，一旦煤价反弹，将直接侵蚀利润。

**供应链与转型风险不容忽视。** 公司煤炭采购高度集中于单一供应商（伊泰申浦），虽然保障了供应，但也带来了巨大的供应链中断和议价能力失衡风险。同时，公司正大力向综合能源服务商转型，但湖北滨江等新项目尚处于建设期，短期内无法贡献利润，且面临投资回报不及预期的风险。若转型不及预期，公司可能陷入传统业务萎缩、新业务尚未成熟的“青黄不接”困境。
