# 301007.SZ 深度透视

## 因果逻辑链
- **[下游客户订单减少]** -> [营收下滑6.76%]: 2025年汽车行业竞争加剧，合资车企转型阵痛，公司主要客户订单减少，导致收入承压。
- **[原材料成本下降与产品结构优化]** -> [毛利率提升1.23%]: 钢材等原材料价格下行，叠加动力系统零部件等高毛利产品占比提升，成本降幅（-8.21%）大于收入降幅。
- **[持续研发投入与新品量产]** -> [技术壁垒巩固]: 丝杠、丝杆、EMB刹车系统等新产品量产，行星滚柱丝杠等前沿技术储备，支撑未来增长。
- **[“阿米巴”与数字化转型]** -> [运营效率提升]: 阿米巴经营模式细化成本核算，金蝶ERP+MES系统实现业财一体化，有效对冲了订单下滑对利润的侵蚀。
- **[股票回购与对外投资]** -> [现金流大幅净流出]: 回购股份及参与产业基金，导致筹资活动现金净流出7200万元，现金及等价物净减少109.43%。
- **[新客户开拓与产品应用拓展]** -> [第二增长曲线初现]: 新开拓12家客户，产品延伸至E-bike、智能底盘、机器人等领域，降低对传统燃油车业务的依赖。

## 风险警告
**核心风险在于下游需求波动与客户集中度。** 公司近50%营收来自前五大客户，且高度依赖博世、电装等全球Tier1巨头。2025年营收已因订单减少而下滑6.76%，若全球汽车产销（尤其是合资品牌）持续低迷，或主要客户切换供应商，公司业绩将面临显著下行压力。此外，动力系统零部件库存量同比激增30.91%，需警惕下游需求不及预期导致的存货减值风险。

**另一重大风险是实际控制人变更后的整合与商誉减值。** 2025年9月公司实际控制人由何建平变更为潘异，管理层发生重大调整，新团队的经营理念与战略执行存在不确定性。同时，公司账面商誉高达5077万元，主要来自收购金华德。若新管理层无法有效提升金华德的运营效率，或行业景气度下行，商誉减值将直接冲击利润表。
