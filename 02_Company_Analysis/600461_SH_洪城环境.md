# 600461.SH 深度透视

## 因果逻辑链
- **[会计估计变更（延长管网折旧年限）]** -> [归母净利润微增0.27%]: 自来水管网折旧年限从15年延长至35年，天然气管网从30年延长至40年，直接减少营业成本约7222万元，对冲了收入下滑对利润的侵蚀。
- **[燃气销售收入下降9.61%]** -> [总营收下降9%]: 燃气销售是公司第二大收入来源（占比24%），售气量下降5.63%叠加价格因素，导致收入减少，是营收下滑的主因。
- **[污水环境工程收入骤降50.85%]** -> [工程业务收入大幅萎缩]: 公司从“投资驱动”向“运营驱动”转型，主动收缩低毛利、高资金占用的工程业务，导致该板块收入腰斩。
- **[污水处理量增长10.85%]** -> [污水处理服务收入增长4.63%]: 作为核心运营业务，处理量提升直接驱动收入增长，且毛利率提升1.82个百分点，显示运营效率改善。
- **[固废处置业务收入下降2.76%]** -> [热电联产发电量下降48.48%]: 宏泽热电发电量大幅下滑，拖累固废板块整体表现，但垃圾焚烧量增长5.26%，显示核心焚烧业务仍稳健。
- **[“厂网一体”模式累计投资超50亿元]** -> [长期应收款新增11.42亿元]: 公司大力拓展污水管网一体化项目，将建设投入确认为长期应收款，资产结构从无形资产向金融资产倾斜。
- **[一年内到期的非流动负债增长180.83%]** -> [筹资活动现金流净流出12.47亿元]: 大量长期借款和应付债券即将到期，导致公司偿还债务的现金支出大幅增加，筹资活动现金流由正转负。

## 风险警告
**核心风险是“增长失速”与“债务到期”的双重挤压。** 公司营收连续两年下滑（2025年-9%），主要依赖会计估计变更和成本压缩才勉强维持利润增长。同时，一年内到期的非流动负债激增至17.3亿元，而经营性现金流净额仅19.1亿元且同比下降，短期偿债压力巨大。若无法有效拓展增量业务或顺利再融资，财务风险将显著上升。

**另一关键风险是“价格机制改革”的长期不确定性。** 公司污水处理和供水业务高度依赖政府定价与财政补贴。报告明确指出，随着运营标准提高，地方财政支出与污水处理收费的差距将越来越大。若未来价格调整机制无法覆盖成本上升，将直接侵蚀公司最核心的运营利润，影响特许经营权项目的长期回报率。
