# 300098.SZ 深度透视

## 因果逻辑链
- **[车载终端业务强劲增长]** -> [营收增长40.39%]: 汽车终端产品收入同比增长58.34%，成为核心增长引擎，带动整体营收规模跃升至19.89亿元。
- **[业务结构优化，聚焦产品型业务]** -> [毛利率提升1.99个百分点]: 公司主动压缩低毛利集成项目，提升高毛利车载终端及产品型业务占比，综合毛利率从31.11%提升至33.10%。
- **[内部管理提效与费用管控]** -> [净利润大幅减亏86.36%]: 通过推进运营提效、成本及费用管控，费效比大幅下降，扣非净利润亏损从-3.03亿收窄至-0.59亿。
- **[海外市场拓展]** -> [海外收入增长62%]: 车载终端、公共安全业务出海成效显著，海外收入占比提升至17.80%，成为新的增长极。
- **[历史应收账款回收]** -> [经营性现金流净额大增164.78%]: 针对长账龄款项制定专项回款举措，成效显著，经营性现金流净额达1.57亿元，远超净利润表现。
- **[供应链成本压力与高研发投入]** -> [公司仍未能实现盈利]: 存储芯片涨价挤占毛利，车载终端为保持竞争力需持续高研发投入，叠加历史应收账款减值，导致全年仍亏损3231万元。
- **[轨交终端业务稳健]** -> [贡献高毛利与稳定利润]: 轨交终端产品毛利率高达58.97%，子公司高新兴创联实现净利润8849万元，是公司利润的重要稳定器。

## 风险警告
**核心风险在于盈利能力的脆弱性与历史包袱。** 尽管营收大增，但公司仍处于亏损状态，主要受制于供应链成本压力（存储芯片涨价）、高强度的研发投入以及历史应收账款带来的减值风险。公司尚未证明其具备可持续的、规模化的盈利能力，扣非净利润虽大幅减亏但仍为负值。

**应收账款与长期应收款余额巨大（合计超19亿元），是悬在头上的达摩克利斯之剑。** 尽管回款改善，但存量风险依然高企。若宏观经济下行或部分客户（尤其是政府类客户）财务状况恶化，将导致大规模坏账，严重侵蚀利润。同时，母公司未分配利润为-15.58亿元，长期无法分红，制约了资本运作空间。
