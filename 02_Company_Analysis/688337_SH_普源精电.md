# 688337.SH 深度透视

## 因果逻辑链
- **[自研核心技术平台产品占比提升]** -> [营收增长16.04%]: 搭载自研平台产品收入同比+18.61%，占比达52.76%，成为营收增长的核心引擎。
- **[高分辨率数字示波器放量]** -> [产品结构升级]: MHO/DHO系列（12bit）销售收入同比+27.61%，推动公司在高端市场渗透。
- **[解决方案业务爆发]** -> [打开新增长极]: 解决方案收入同比+37.58%，其中SPQ阵列测控系统收入同比+910.26%，从“卖仪器”向“卖方案”转型。
- **[大客户战略见效]** -> [客户粘性增强]: 大客户销售收入同比+54.98%，光通信领域核心大客户收入同比+70.45%，验证高端客户突破能力。
- **[马来西亚产能爬坡与产品结构变化]** -> [毛利率承压]: 整体毛利率55.08%，同比-4.06pct，主因是解决方案中低毛利教育类项目占比提升及海外新工厂成本偏高。
- **[所得税费用激增]** -> [扣非净利润下滑34%]: 利润总额增长，但子公司税收优惠到期及递延所得税资产确认，导致所得税费用同比+2045万元，侵蚀利润。
- **[非经常性损益依赖度高]** -> [盈利质量存疑]: 扣非净利润仅3848万元，占归母净利润44.7%，核心盈利能力被理财收益（5057万元）等非经常性项目掩盖。
- **[H股上市推进]** -> [全球化资本平台构建]: 已递交香港上市申请，拟发行不超过2480万股H股，募资用于研发、产能扩张及海外并购，加速国际化。

## 风险警告
**核心风险在于盈利质量与增长可持续性的背离。** 公司营收增长16%至9亿元，但扣非净利润却逆势下滑34%至3848万元，主因是所得税费用激增及毛利率下滑。更关键的是，非经常性损益（理财收益等）占归母净利润比重高达55%，剔除后公司实际盈利能力极为薄弱。若未来理财收益波动或税收优惠进一步收紧，利润表将面临巨大压力。

**战略转型期的“双刃剑”效应不可忽视。** 公司正从“卖仪器”向“卖解决方案”转型，解决方案收入虽暴增37.58%，但毛利率同比骤降10.09个百分点，且马来西亚生产基地仍处产能爬坡期，持续拖累制造成本。这种“增收不增利”的扩张模式，叠加研发费用率仍高达25%，短期内费用刚性增长与毛利率下行将形成剪刀差，对现金流和股东回报构成持续挑战。
