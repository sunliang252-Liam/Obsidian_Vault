- **[全工序一体化“铸造+精加工”能力]** -> [毛利率提升至36.40%]: 全链条自主可控，减少外协依赖，实现成本优化与质量一致性，直接增厚利润空间。
- **[工程机械部件需求爆发]** -> [该板块收入同比增长40.38%]: 受益于全球基建投资与设备更新周期，公司作为卡特彼勒等龙头供应商，订单量大幅增加。
- **[海外业务逆势增长]** -> [境外收入同比增长22.19%]: 凭借供应链韧性和客户信任，在贸易摩擦背景下，成功扩大北美市场份额，对冲国内竞争压力。
- **[墨西哥工厂建设推进]** -> [在建工程同比增长167.25%]: 贴近北美市场布局产能，旨在规避关税壁垒，提升本地化交付能力，为未来海外增长奠定基础。
- **[明德工厂产能爬坡与技改]** -> [规模效应显现，单位成本优化]: 新工厂投产及现有基地设备升级，扩大了产能规模，摊薄固定成本，提升整体生产效率。
- **[液压业务整合进入效益释放期]** -> [力源金河实现稳定盈利]: 前期技改投入与市场拓展成果显现，从亏损转为利润贡献点，成为公司新的增长引擎。
- **[集团化采购与工艺革新]** -> [营业成本增速(10.81%)低于收入增速(14.19%)]: 通过集中采购和精益生产，有效控制了原材料及制造成本，提升了盈利能力。
- **[AI数据中心温控需求爆发]** -> [压缩机部件业务稳定增长]: 公司产品通过下游客户应用于数据中心冷水机组，深度契合高景气赛道，为收入提供稳定基本盘。

## 风险警告
**核心风险在于客户高度集中与中美贸易摩擦的叠加效应。** 公司前五大客户销售额占比高达68.57%，且深度绑定江森自控、卡特彼勒等全球巨头。虽然合作关系稳固，但任何单一客户的战略调整或需求下滑，都将对公司业绩产生剧烈冲击。同时，公司海外收入占比超50%，且主要面向美国市场，当前已面临15%的临时关税，若中美贸易关系再度恶化，关税成本上升或订单波动将直接侵蚀利润。

**次要风险来自原材料价格与汇率波动。** 公司采用“成本加成”定价模式，虽有一定转嫁能力，但若生铁、废钢等大宗商品价格出现超预期上涨，利润空间仍将被压缩。此外，公司海外销售以美元结算，人民币升值不仅会削弱产品价格竞争力，还会产生汇兑损失。2025年财务费用变动已显示汇兑收益减少，未来汇率的不利波动将持续构成财务压力。
