# 688799.SH 深度透视

## 因果逻辑链
- **[致根医药出表确认投资收益]** -> [净利润大增45%]: 致根医药不再纳入合并报表，确认投资收益约8822万元，是归母净利润从1.64亿跃升至2.38亿的核心非经常性因素。
- **[扣非净利润下滑3.1%]** -> [核心主业增长乏力]: 剔除投资收益后，扣非净利润1.34亿，同比下降，表明主营业务的盈利能力并未同步改善。
- **[原料药制剂一体化成本优势]** -> [应对集采降价]: 自供原料药（如胶体果胶铋、磷霉素氨丁三醇）使公司对制剂成本有更强控制力，在集采中维持毛利率稳定（制剂毛利率69.99%）。
- **[高销售费用率侵蚀利润]** -> [推广模式依赖]: 销售费用占营收33.01%（4.97亿），其中市场推广费占90.18%，高额推广投入是维持现有营收规模的必要成本，也是扣非利润承压的主因。
- **[研发投入资本化率提升]** -> [短期利润调节]: 研发投入资本化比重从0%升至9.71%（1396万），乾清颗粒等项目进入资本化阶段，减少了当期费用化研发支出，对利润有正向影响。
- **[新建产能即将投产]** -> [未来增长预期]: 高端制剂产研基地和年产3000吨原料药基地预计2026年6月试生产，为未来规模化、国际化提供产能基础，但短期带来较大资本开支和折旧压力。
- **[吸入用乙酰半胱氨酸溶液量价齐跌]** -> [核心产品承压]: 该产品销量同比降16%，库存降57%，市场竞争激烈，导致呼吸道类制剂收入同比大降30%，是制剂板块增长的主要拖累项。

## 风险警告
**核心风险在于利润质量与主业增长的双重背离。** 2025年归母净利润45%的增长主要由致根医药出表带来的非经常性投资收益驱动，而扣非净利润已出现3.1%的下滑。这表明公司核心的制剂与原料药业务并未实现同步增长，高额的销售费用（占营收33%）持续侵蚀利润，市场推广效率存疑。若未来无法有效控制销售费用或提升产品竞争力，主业盈利能力将持续承压。

**集采深化与新品放量不及预期的风险。** 公司多个核心产品（如吸入用乙酰半胱氨酸溶液、琥珀酸亚铁片）已纳入集采，面临价格下行压力。同时，公司大量在研仿制药和创新药（如乾清颗粒、ZG系列）仍处于临床或审评阶段，研发周期长、失败风险高。新建产能（高端制剂基地、原料药基地）预计2026年投产，若市场开拓或产能利用率不及预期，将导致折旧成本增加，进一步拖累业绩。
