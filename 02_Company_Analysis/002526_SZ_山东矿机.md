# 002526.SZ 深度透视

## 因果逻辑链
- **[煤炭行业智能化转型]** -> [净利润增长8.07%]: 公司抓住煤矿智能化建设提速机遇，推动电液控、智能输送等高端产品需求，对冲了传统煤机收入下滑的影响。
- **[配件战略深化]** -> [核心子公司盈利稳健]: 成通锻造、山东信川等配件子公司通过核心工艺创新和自动化改造，实现净利润3760万、2407万，成为利润稳定器。
- **[非经常性损益高企]** -> [扣非净利润骤降41.09%]: 2025年非经常性损益达7044万元（主要来自委托理财收益和营业外收入），掩盖了主营业务盈利能力的实质性恶化。
- **[大额分期收款销售]** -> [经营活动现金流净额为负]: 销售规模下降叠加分期收款订单增加，导致销售商品收到的现金减少，经营现金流净流出7234万元，与净利润严重背离。
- **[海外市场突破]** -> [国外收入增长56.77%]: 公司加速国际化布局，海外营收占比从2.98%提升至5.22%，成为收入增长的新引擎。
- **[研发聚焦复杂煤层]** -> [构筑技术壁垒]: 针对薄煤层、大倾角等复杂地质条件研发智能化开采装备，有望在细分市场形成差异化竞争优势。
- **[员工持股计划解锁失败]** -> [管理层激励失效]: 2024年员工持股计划第一个解锁期因业绩考核未达标而无法解锁，可能影响核心团队积极性。

## 风险警告
**核心风险：主业增长乏力与现金流恶化。** 公司营收同比下降10.57%，扣非净利润更是暴跌41.09%，表明传统煤机业务（煤炭机械设备收入下降14.58%）面临需求收缩压力。更严重的是，经营活动现金流净额由正转负（-7234万元），与净利润（1.23亿元）严重背离，反映出公司回款能力恶化或销售政策过于激进，盈利质量堪忧。

**次要风险：应收账款与坏账风险。** 应收账款余额高达14.07亿元，占总资产20.91%，且坏账准备计提达3.04亿元。在行业竞争加剧、客户结构向头部集中的背景下，若下游煤炭企业盈利承压，公司可能面临大额坏账损失，进一步侵蚀利润。此外，公司过度依赖非经常性损益（委托理财收益、营业外收入）来粉饰报表，主业盈利能力薄弱，长期发展动力不足。
