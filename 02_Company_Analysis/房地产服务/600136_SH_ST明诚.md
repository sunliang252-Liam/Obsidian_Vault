# 600136.SH 深度透视

## 因果逻辑链
- **[破产重整后国资入主]** -> [公司控制权与治理结构根本性重塑]: 湖北联投城运成为控股股东，湖北省国资委成为实控人，彻底终结了原民营股东违规担保、资金占用的混乱局面，为公司提供了信用背书与资源支持。
- **[“影视传媒+智慧空间”双主业战略]** -> [收入结构多元化与抗风险能力提升]: 影视传媒（内容）与智慧空间（运营）形成“内容创造空间价值，空间承载文化体验”的协同闭环，2025年两大板块收入分别增长26.73%和10.58%，有效对冲单一业务波动风险。
- **[聚焦精品微短剧与演艺新空间]** -> [影视传媒板块毛利率提升5.91个百分点]: 公司主动调整业务结构，从高投入、长周期的传统长剧转向成本可控、周转更快的微短剧，并拓展沉浸式演艺空间，提升了内容资产的变现效率。
- **[收购清碧智慧运营并整合联投系资源]** -> [智慧空间板块规模与利润双增]: 依托国资股东背景，公司智慧空间服务管理面积突破604万平米，并切入城市更新、医疗康养等新赛道，实现了稳健的内生增长。
- **[历史违规担保诉讼取得有利终审裁决]** -> [重大或有负债风险实质性化解]: 针对雨石矿业、游建鸣、众视盛纳等违规担保案件，法院终审判决公司不承担保证责任，消除了悬在资产负债表上的最大“地雷”。
- **[连续两年亏损但亏损额大幅收窄]** -> [经营基本面企稳向好]: 2025年归母净利润-1,579.89万元，较2024年减亏8,522万元，扣非净利润亦大幅减亏，显示公司已走出破产重整后的阵痛期，核心业务造血能力正在恢复。
- **[母公司未分配利润巨额亏损(-48.69亿)]** -> [长期无法进行现金分红]: 历史遗留的巨额亏损导致公司不满足分红条件，短期内无法通过分红回报股东，资本公积转增股本亦受限制，投资者回报主要依赖股价波动。

## 风险警告
**核心风险在于历史包袱的长期压制与双主业协同的不确定性。** 尽管违规担保诉讼取得阶段性胜利，但母公司高达48.69亿元的未弥补亏损，意味着公司未来数年都无法进行现金分红，对价值投资者缺乏吸引力。同时，公司股票因历史信息披露违规被继续实施其他风险警示（ST），需满12个月后方可申请撤销，这期间的市场情绪和流动性风险不容忽视。

**业务层面，双主业均面临激烈竞争。** 影视传媒板块高度依赖爆款内容，微短剧赛道虽热但竞争白热化，公司能否持续产出《正当防卫》级别的精品存在不确定性；智慧空间板块则面临房地产下行周期传导的应收账款回收压力，以及行业价格战对利润率的侵蚀。此外，控股股东关于解决同业竞争的承诺（2028年底前）若执行不力，可能引发新的关联交易风险。
