# 600724.SH 深度透视

## 因果逻辑链
- **[水泥行业需求萎缩与产能过剩]** -> [水泥板块亏损0.89亿元]: 房地产投资大幅下滑、基建投资增速转负，叠加错峰生产执行不力，导致水泥价格低迷、全行业陷入价格战，公司水泥业务虽销量增长5.06%，但利润仍为负值。
- **[天一广场核心地段优势与品牌升级]** -> [商业地产利润增长12.60%]: 作为宁波核心商圈，通过空间焕新、引进109个新品牌（含69家首店）、强化会员运营，在消费承压背景下实现租金收入增长8.79%，出租率维持93.83%。
- **[参股公司产能指标减值]** -> [计提长期股权投资减值5241万元]: 因国家产能置换政策收紧，参股的上峰科环4500T/D熟料线项目无法按期投产，公司对其长期股权投资计提大额减值，直接侵蚀利润。
- **[燃料油业务剥离]** -> [营业收入同比下降13.12%]: 2024年处置燃料油板块，导致2025年合并报表中减少约2.47亿元收入，但剔除该不可比因素后，主业收入同比微增1.66%。
- **[高分红政策]** -> [2025年度现金分红率94.58%]: 公司坚持持续高比例现金分红，2025年中期+末期合计派发1.73亿元，近三年累计分红比例达285.19%，体现对股东回报的重视。
- **[可转让大额存单及定期存款利息]** -> [投资收益贡献约4000万元]: 公司将大量现金配置于可转让大额存单和定期存款，利息收入重分类至投资收益，成为利润的重要补充来源。
- **[水泥业务降本增效与绿色技改]** -> [新平公司减亏近2000万元]: 通过工艺革新、数智化改造、布局光伏储能等措施，云南区域水泥子公司成本改善，亏损幅度大幅收窄。

## 风险警告
**核心风险在于水泥业务的持续亏损与资产减值压力。** 水泥板块2025年亏损0.89亿元，且参股公司上峰科环因产能置换政策变化已计提减值准备合计约7240万元，后续注销清算可能带来进一步损失。水泥行业需求下行趋势未改，公司虽通过降本增效减亏，但若行业价格战持续，水泥业务可能继续拖累整体业绩。

**转型不确定性风险突出。** 公司明确表示商业地产和水泥建材面临增长瓶颈，正积极寻求向新材料、新能源等新质生产力领域并购转型。但2025年重大资产重组已终止，新产业拓展尚未取得实质突破。跨界并购面临认知风险、定价风险及整合风险，转型路径和节奏存在较大不确定性。

**公司简介（F10 原文）**

> 宁波富达股份有限公司(以下简称“宁波富达”)创建于1989年,1996年在上海证券交易所上市,股票代码600724。公司是一家从事城市商业地产运营管理、水泥建材生产的国有控股上市公司。公司旗下有宁波城市广场开发经营有限公司、富达新型建材(蒙自)有限公司等两家一级子公司、四家二级子公司和六家三级以上子公司。  商业地产拥有天一广场统一产权,除天一广场商业租赁业务之外,还自营国际购物中心、GUGO酷购商城两家主力店,并托管经营和义大道购物中心、月湖盛园项目,经营业态涵盖奢侈品购物中心、高端精品百货店、时尚潮流品牌商城和城市时尚休闲商业综合体、历史街区等。水泥建材拥有年产普通水泥和特种水泥490万吨能力,在云南蒙自、新平各建有一条日产2000吨的新型干法水泥生产线。  宁波富达积极依托股东支持,始终秉持“追求卓越,创造价值”的经营理念,致力于成为管理科学、业绩卓越、具备核心竞争能力和持续发展动力的优秀上市公司。
