# 000560.SZ 深度透视

## 因果逻辑链
- **[二手房价格持续下跌]** -> [经纪业务收入下降11.4%]: 核心城市房价下行导致交易金额（GTV）同比-13.7%，直接压缩佣金收入。
- **[新房市场持续低迷]** -> [新房业务收入下降21.8%]: 行业销售规模与价格双降，公司主动收缩规模、严控风险，导致收入下滑。
- **[投资性房地产公允价值变动]** -> [净利润亏损9663万元]: 基于谨慎性原则，自持物业评估减值约5349万元，直接侵蚀利润。
- **[应收账款减值准备计提]** -> [净利润亏损加剧]: 新房业务客户回款风险增加，计提减值约4172万元，反映行业信用风险传导。
- **[总部大楼折旧增加]** -> [净利润亏损]: 2024年装修完工转入固定资产，2025年新增折旧约3251万元，为一次性会计成本增加。
- **[资产管理业务“净额法”核算]** -> [资管收入下降18.2%]: 新产品“相寓优选”采用净额法确认收入，导致表观收入大幅缩水，但经调整毛利率实则提升至14.9%。
- **[二手房市场“以价换量”]** -> [经纪业务毛利率下降4.23个百分点]: 交易量稳定但佣金费率承压，收入增速慢于成本，盈利能力受损。

## 风险警告
公司2025年由盈转亏，核心风险在于**资产价值持续缩水**。投资性房地产公允价值变动与应收账款减值合计近亿元，直接吞噬利润。这并非一次性冲击，而是房地产市场深度调整下，公司持有的大量自持物业与新房业务债权面临的持续减值压力。若房价继续下行，资产减值损失将成为常态，严重拖累报表利润。

另一重大风险是**主营业务收入与盈利能力双降**。经纪、新房、资管三大核心业务收入均出现两位数下滑，经纪业务毛利率更是下降超4个百分点。尽管公司通过成本管控维持了正向经营现金流，但收入端的萎缩若无法被市场复苏扭转，将导致公司陷入“增收不增利”甚至“减收减利”的困境，长期来看会削弱其市场地位与抗风险能力。
