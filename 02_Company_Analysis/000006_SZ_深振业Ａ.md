# 000006.SZ 深度透视

## 因果逻辑链
- **[结转规模大幅缩减]** -> [营收下降56.83%]: 2025年房产销售收入仅23.98亿元，较上年59.01亿元大幅下滑，核心原因是可结转项目减少，业绩释放节奏断档。
- **[计提存货跌价准备1.39亿元]** -> [归母净利润亏损0.42亿元]: 尽管亏损额同比收窄97.31%，但资产减值损失仍是侵蚀利润的主因，反映存量项目去化压力与市场价值下行。
- **[经营活动现金流净额下降83.04%]** -> [现金流安全承压]: 从11.15亿元骤降至1.89亿元，主因支付的各项税费增加，显示在销售回款不畅时，刚性支出对现金流的挤压效应。
- **[资产负债率降至62.54%]** -> [财务结构优化]: 较上年末下降4.43个百分点，主要得益于偿还债务及利息支出减少，但偿债压力并未实质性缓解，长期借款与应付债券合计超20亿元。
- **[深圳城中村改造业务拓展]** -> [新增长极初现]: 全年签订5个服务合同，金额近3100万元，并成为深圳首个发放房票的改造项目，显示公司正从传统开发向城市更新服务转型。
- **[新增土地储备（天境云玺）]** -> [未来可售资源补充]: 以19.94亿元获取深圳光明区地块，权益比例40%，但当前在建项目多，新项目短期内无法贡献业绩，资金占用压力大。
- **[商业运营租赁收入约1.3亿元]** -> [稳定现金流来源]: 虽仅占营收5.01%，但毛利率达40.24%，且出租率稳定，成为公司抵御开发业务波动的“压舱石”。
- **[连续三年扣非净利润为负]** -> [主业盈利能力堪忧]: 2023-2025年扣非净利润分别为-8.05亿、-15.70亿、-0.53亿元，表明剔除非经常性损益后，公司核心开发业务持续亏损。

## 风险警告
**核心风险在于“存量去化”与“增量投入”的双重资金压力。** 公司营收高度依赖房产销售（占比91.6%），但结转规模大幅下滑，且存货中仍有大量未售项目（存货占总资产65.46%）。尽管2025年亏损大幅收窄，但连续三年扣非净利润为负，表明主业造血能力严重不足。同时，公司以19.94亿元联合拿地（天境云玺），叠加在建项目持续投入，对现金流形成巨大考验。经营活动现金流净额骤降83.04%，若销售回款持续不畅，流动性缺口风险将显著上升。

**另一重大风险是资产减值与财务杠杆的脆弱平衡。** 公司2025年计提存货跌价准备1.39亿元，虽较上年大幅减少，但存货账面余额高达125.09亿元，跌价准备余额仍有17.89亿元。在房地产市场筑底修复缓慢、低能级城市去化压力大的背景下，未来仍有进一步减值风险。此外，公司有息负债余额44.55亿元，其中一年内到期的非流动负债高达24.98亿元，短期偿债压力较大。尽管资产负债率有所下降，但若融资渠道收紧或债务集中到期，财务风险将快速暴露。
