# 002026.SZ 深度透视

## 因果逻辑链
- **[新能源业务（换电站）客户订单波动]** -> [营收与利润双降]: 新能源业务收入同比下降32.63%，是导致公司整体营收下滑13.46%、净利润下降15.95%的核心拖累。
- **[电动工具配件主业稳健]** -> [核心业务韧性]: 电动工具配件业务收入同比增长0.71%，毛利率虽下滑4.2个百分点，但凭借龙头地位和客户粘性，守住了基本盘。
- **[越南工厂产能释放]** -> [海外增长引擎]: 威达（越南）营收同比增长80.01%，净利润增长102.41%，有效对冲了国内及墨西哥工厂的初期压力，成为利润增量来源。
- **[贸易战与宏观不确定性]** -> [客户暂缓订单]: 报告明确指出，部分客户因贸易战和宏观经济不确定性暂缓或缩减订单，导致短期订单波动，是业绩下滑的直接外部原因。
- **[产品结构调整与竞争加剧]** -> [综合毛利率承压]: 电动工具配件毛利率下降4.2个百分点，新能源业务虽毛利率提升但收入大幅萎缩，整体盈利空间受到挤压。
- **[投资艾利特机器人]** -> [布局新增长极]: 公司投资协作机器人企业艾利特，构建“自研+投资+协同”的机器人业务战略，旨在为长期发展寻找第二曲线。
- **[股份回购与分红]** -> [强化股东回报]: 公司完成约6000万元股份回购（注销）及两次现金分红，合计超9000万元，积极维护市值和投资者信心。

## 风险警告
**核心风险在于新能源业务的剧烈波动与对单一客户的过度依赖。** 公司新能源业务（主要为蔚来汽车换电站）收入骤降32.63%，是业绩下滑的元凶。虽然公司强调“以销定产”，但换电站业务高度依赖下游客户（蔚来）的资本开支节奏和战略规划，一旦客户放缓建站速度，公司该板块将直接面临订单萎缩和产能闲置风险，且该业务库存量同比大增63.43%，预示需求疲软。

**另一重大风险是贸易战及宏观环境的不确定性。** 公司海外收入占比近40%，且客户集中于TTI、史丹利百得等欧美巨头。报告明确提及贸易战导致客户暂缓订单。若未来关税壁垒进一步升级或全球经济衰退，公司将面临订单减少、毛利率下滑及汇兑损失的三重压力。虽然越南工厂提供了缓冲，但墨西哥工厂尚处投产初期，全球化布局的短期效益有限。
