# 000050.SZ 深度透视

## 因果逻辑链
- **公司坚持“2+1+N”战略，核心业务为车载显示和手机显示** -> 车载显示营收同比增长18%，专业显示营收同比增长22%: 战略聚焦带动资源倾斜，核心业务增长强劲
- **车载显示需求增长（智能座舱、新能源车渗透率提升）** -> 车载业务营收创新高，LTPS车载出货量跃升至全球第二: 下游需求拉动公司产品出货和技术升级
- **公司持续加大研发投入，推出高端技术品牌“天工屏”“天轩屏”** -> 柔性AMOLED手机显示出货量国内第二、全球第三，旗舰产品出货量跨越式增长: 技术创新提升产品竞争力，带动高端市场份额
- **公司推进降本增效，成本费用率同比下降4.25个百分点** -> 归属净利润同比增加83,595.51万元，扭亏为盈: 成本控制直接改善盈利能力
- **经营活动现金流净额同比增加21.49%** -> 总资产减少5.47%，筹资活动现金流净额减少: 经营现金流改善，偿债能力增强，减少负债
- **Micro-LED产线贯通并实现产品交付** -> Micro-LED业务在PID、车载领域商业化突破: 技术成熟推动产品落地
- **全球中小尺寸显示行业弱复苏，高端机型拉动市场** -> 公司OLED业务增长强劲，LCD业务通过策略调整保持韧性: 下游分化导致公司不同技术产品表现分化

## 风险警告
行业竞争激烈，显示技术迭代快，公司需持续高研发投入；下游需求波动，部分细分市场短期承压；存储芯片等元器件涨价可能影响成本；公司资产负债率仍较高，财务费用压力大。
