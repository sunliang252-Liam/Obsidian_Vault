# 600235.SH 深度透视

## 因果逻辑链
- **[新老产能转换阵痛]** -> **营收与利润双降**: 南湖老厂区产线关停，海盐新厂区二期项目尚处产能爬坡期，叠加行业竞争加剧，导致2025年营收同比-17.44%，归母净利润同比-77.38%。
- **[行业供需失衡加剧]** -> **产品价格承压**: 造纸行业产能持续释放，特种纸价格下行，公司核心产品工业配套纸（含啤酒标签纸）销量同比-37.84%，拖累整体业绩。
- **[财务费用激增]** -> **侵蚀利润**: 新项目建设期借款利息费用化，2025年财务费用同比+109.84%，达2497万元，显著压缩盈利空间。
- **[南湖厂区征收补偿]** -> **现金流改善与利润缓冲**: 与政府签署约10.79亿元征收补偿协议，2025年收到首期1.3亿元，使经营活动现金流净额达2.72亿元，并为未来利润提供潜在支撑。
- **[非经常性损益依赖]** -> **扣非净利润极低**: 2025年扣非净利润仅522万元，同比-92.71%，主要依赖政府补助（1256万元）等非经常性项目，主业盈利能力薄弱。
- **[卷烟纸业务逆势增长]** -> **结构性亮点**: 受益于新产线投产及HNB等新赛道需求，卷烟纸销量同比+13.73%，营收同比+14%，成为公司唯一增长的支柱产品。
- **[描图纸毛利率骤降]** -> **成本压力凸显**: 新产线投产初期，描图纸成本同比+38.16%，导致该产品毛利率由正转负至-2.09%，盈利能力严重恶化。

## 风险警告
**核心风险在于新旧产能转换的“青黄不接”与行业下行周期的叠加。** 公司二期项目（年产7万吨特种涂布纸）于2025年6月投产，但截至年底仍未达产，产能利用率及运营效率低下，直接导致工业配套纸销量大幅下滑。同时，新项目带来的折旧与财务费用激增，在行业价格战背景下，公司面临“增量不增利”甚至亏损扩大的困境。扣非净利润仅522万元，主业已处于盈亏平衡边缘，抗风险能力极弱。

**另一重大风险是盈利高度依赖非经常性损益与资产处置。** 2025年利润主要来自南湖厂区征收补偿相关的政府补助及资产处置收益。若剔除这些一次性收益，公司实际经营已陷入微利甚至亏损。未来补偿款的确认节奏存在不确定性，且公司需将补偿款用于新厂区运营及债务偿还，无法持续转化为股东回报。在行业“高集中、微盈利”的长期趋势下，公司作为外购浆比例高、产品同质化的中型纸企，生存空间正被头部企业持续挤压。
