# 600918.SH 深度透视

## 因果逻辑链
- **[市场交易量激增]** -> [财富管理收入增长28.5%]: 2025年A股日均交易量同比暴增71%，公司作为山东省龙头券商，经纪业务手续费净收入随之大幅提升。
- **[买方投顾转型与产品矩阵]** -> [代销金融产品保有量增长25.5%]: 推出“中泰财富30”品牌，从“产品销售”向“资产配置”转型，驱动保有规模从481.7亿增至604.76亿元。
- **[科创板IPO承销优势]** -> [投行差异化竞争力]: 科创板IPO承销单数、规模分列行业第5、第7，打造新型储能首单IPO等标杆项目，在头部垄断格局中撕开缺口。
- **[定增募资60亿]** -> [资本实力与业务空间提升]: 完成上市以来首次股权再融资，净资本增至335.45亿元，为自营、信用等重资本业务扩张提供弹药。
- **[万家基金规模扩张]** -> [资管业务收入增长14.09%]: 控股子公司万家基金管理规模突破5954.93亿元（+19.13%），货币基金规模大增，驱动管理费收入提升。
- **[机构交易业务爆发]** -> [机构客户资产规模翻倍]: 存量资产规模从772.78亿飙升至1526.33亿元（+97.51%），XTP Pro极速交易平台成为核心获客利器。
- **[信用减值损失激增80%]** -> [利润侵蚀]: 债权投资及融出资金计提减值损失5.02亿元，同比大增，显示资产质量承压，尤其国际业务债权投资风险暴露。
- **[国际业务亏损扩大]** -> [拖累整体业绩]: 中泰国际因债权投资减值及公允价值变动，全年亏损8.31亿元，成为公司最大的利润出血点。

## 风险警告
**最大风险在于国际业务失控与信用风险共振。** 中泰国际全年亏损8.31亿元，主要源于债权投资信用减值损失激增，且交易性金融资产公允价值变动收益减少。这暴露了公司在境外业务风控上的短板，若海外信用环境恶化或资产价格持续波动，该亏损黑洞可能进一步扩大，直接侵蚀母公司利润。

**信用减值损失同比飙升80%至5.02亿元，资产质量恶化信号明确。** 尽管公司整体营收增长，但信用风险正在累积，尤其是在债权投资和融出资金领域。若宏观经济下行或市场信用事件频发，公司可能面临更大的资产减值压力，导致利润增速远不及营收增速，甚至出现增收不增利的局面。
