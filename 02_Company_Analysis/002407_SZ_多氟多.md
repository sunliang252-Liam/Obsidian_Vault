# 002407.SZ 深度透视

## 因果逻辑链
- **[行业产能出清，头部集中]** -> [六氟磷酸锂价格修复]: 低端产能退出后，有效产能向头部集中，供需格局改善，产品价格理性回升，带动毛利显著增长。
- **[新能源电池需求爆发]** -> [新能源电池营收增长76.84%]: 新能源汽车及储能市场高景气，公司大圆柱电池产品凭借结构设计优势，在供不应求的市场中实现销量大幅提升。
- **[六氟磷酸锂产销量提升]** -> [新能源材料营收增长20.86%]: 作为核心产品，六氟磷酸锂产销量随下游电解液需求增长而提升，巩固了公司在全球电解质行业的领先地位。
- **[执行低价长协订单]** -> [压制当期盈利水平]: 公司坚守契约精神，按约定执行部分长期协议中的低价订单，对本期盈利水平造成一定拖累。
- **[新能源电池产能扩张]** -> [固定资产增长34.13%]: 公司新建大圆柱电池生产线顺利达产，产能达20GWH，导致固定资产规模显著增加。
- **[磷肥副产氟硅资源利用]** -> [成本优势与资源循环]: 公司利用磷肥副产氟硅酸生产氢氟酸，降低了对萤石资源的依赖，实现了资源循环利用和成本优化。
- **[半导体产业链国产化]** -> [电子级氢氟酸等产品突破]: 抓住半导体产业链国产化机遇，公司半导体级氢氟酸、电子级硅烷等产品成功导入高端客户供应链，实现技术突破。

## 风险警告
**1. 长期协议执行风险与盈利波动性**：公司虽受益于行业景气度回升，但2025年因执行低价长协订单，显著压制了当期盈利。若未来产品价格持续上涨，长协订单将构成机会成本；若价格下跌，则可能面临客户违约或重新谈判风险。公司盈利对产品价格高度敏感，周期性波动风险显著。

**2. 产能扩张与资本开支压力**：公司处于大规模产能扩张期，在建工程高达32.88亿元，固定资产同比增长34.13%。新能源电池产能利用率仅50%-60%，电子级氢氟酸产能利用率仅30%-40%，存在产能消化不及预期的风险。同时，大规模资本开支导致筹资活动现金流净额下降57.12%，财务费用因汇兑损失增加98.43%，财务压力持续加大。
