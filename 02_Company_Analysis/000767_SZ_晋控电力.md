# 000767.SZ 深度透视

## 因果逻辑链
- **[煤价低位运行]** -> [火电成本改善]: 2025年煤价整体低位，直接降低火电燃料成本，燃料费同比下降15.80%，是净利润扭亏为盈的核心驱动力。
- **[市场化交易策略]** -> [综合电价提升]: 公司实施“中长期锁利、现货增盈”策略，省间现货、容量电费等指标全省领先，平均上网电价同比提升6.12%，对冲了发电量下降的影响。
- **[发电量下降]** -> [营收减少]: 全年发电量383.82亿千瓦时，同比降低11.65%，导致营业收入同比下降7.24%，但成本降幅更大，利润仍实现增长。
- **[财务费用压降]** -> [利润增厚]: 财务费用同比减少13.17%，主要得益于利息费用减少及归还永续债，直接增厚了净利润。
- **[关联交易依赖]** -> [成本控制双刃剑]: 向关联方晋能控股集团采购燃料占同类交易93.80%，虽保障供应稳定，但也限制了采购端议价空间和成本优化弹性。
- **[新能源装机扩张]** -> [结构优化]: 新能源装机213.58万千瓦（占比19.3%），风电/光伏毛利率（48.81%/27.43%）显著高于火电（15.69%），成为利润增长的重要补充。

## 风险警告
**核心风险在于盈利对煤价的单向依赖与火电转型压力。** 公司2025年扭亏几乎完全依赖煤价低位运行，但火电毛利率仅15.69%，远低于新能源。一旦煤价反弹，成本端将迅速承压，而电价端受市场化竞争及“双碳”政策下火电向调节性电源转型影响，上涨空间有限，盈利稳定性极差。

**财务风险与治理风险交织。** 公司资产负债率高企，担保余额占净资产比例高达121.05%，且大量担保对象为关联方（晋能控股煤业集团），存在或有负债风险。同时，母公司未分配利润为-15.74亿元，连续多年无法分红，且存在多起未决诉讼（涉案金额超10亿元），资金链与法律风险不容忽视。
