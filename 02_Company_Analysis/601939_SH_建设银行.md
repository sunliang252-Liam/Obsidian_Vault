# 601939.SH 深度透视

## 因果逻辑链
- **[LPR下行与市场利率低位运行]** -> [净息差收窄至1.34%]: 资产端收益率下降幅度大于负债端成本率降幅，导致利息净收入同比减少2.90%。
- **[加大国债、地方债投资力度]** -> [金融投资规模增长20.72%]: 积极支持积极财政政策，债券投资大幅增加，带动金融投资占比提升至28.26%。
- **[财富管理与投行资管业务发力]** -> [手续费及佣金净收入增长5.13%]: 理财产品、基金管理和债券承销等收入增长，抵消了传统业务下滑，推动中间业务收入回升。
- **[向财政部定向增发A股]** -> [核心一级资本充足率提升至14.63%]: 成功募集1050亿元，有效补充核心资本，为资产扩张提供支撑，资本充足率保持19.69%。
- **[科技、绿色、普惠贷款高速增长]** -> [信贷结构优化，资产质量稳定]: 金融“五篇大文章”领域贷款增速均超12%，不良贷款率下降0.03个百分点至1.31%，实现结构优化与风险可控。
- **[存款定期化趋势延续]** -> [负债成本刚性]: 个人定期存款占比提升，尽管存款利率下调，但整体存款付息率降幅有限，未能完全对冲资产端收益率下行压力。
- **[债券投资收益增加]** -> [其他非利息收入大幅增长49.48%]: 受市场波动影响，债券和权益投资处置收益同比增加，成为营收增长的重要驱动力。
- **[普惠零售信贷集约化运营]** -> [信用减值损失增加10.45%]: 加大了对普惠、零售等领域的风险暴露计提，贷款减值损失同比增加292.18亿元，侵蚀部分利润。

## 风险警告
**核心风险在于净息差持续收窄与资产质量承压的双重挤压。** 在LPR下行和市场竞争加剧的背景下，净息差已降至1.34%的历史低位，且短期内难以逆转。同时，尽管不良率微降，但信用减值损失同比增加10.45%，显示在经济结构性调整中，对公（特别是房地产、地方平台）及零售（信用卡、经营贷）领域的潜在风险暴露正在增加，拨备覆盖率略有下降至233.15%，风险抵补能力边际减弱。

**另一关键风险是负债成本管控的挑战。** 存款定期化趋势明显，个人定期存款占比持续上升，导致负债成本刚性。尽管存款利率下调，但效果被结构变化部分抵消。在资产端收益率持续下行的环境下，若无法有效控制负债成本，净息差将进一步承压，对盈利能力构成根本性威胁。此外，金融投资规模快速扩张，市场利率波动带来的公允价值变动风险亦需关注。
