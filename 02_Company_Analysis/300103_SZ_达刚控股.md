# 300103.SZ 深度透视

## 因果逻辑链
- **[新能源业务（恩科星）高速增长]** -> [营收结构转型]: 新能源业务收入同比+93.16%，占比从20.37%跃升至39.67%，成为公司最大收入来源，弥补了传统业务下滑。
- **[加大应收账款催收]** -> [净利润亏损大幅收窄]: 归母净利润亏损从-1.15亿缩至-0.61亿（同比减亏47.47%），主因是回款改善及收回众德环保股权转让尾款。
- **[城市道路智慧运维业务收缩]** -> [营收下滑]: 该板块收入同比-56.70%，毛利率仅4.44%，公司主动处置亏损孙公司、聚焦催收，导致业务规模大幅缩减。
- **[计提大额资产减值]** -> [持续侵蚀利润]: 资产减值损失-1893万元（主要为固定资产及存货跌价），信用减值损失-968万元，合计-2861万元，是亏损的核心来源之一。
- **[实际控制人变更]** -> [治理风险暴露]: 2025年8月陈可成为实控人，但年内即发生其未经审批与子公司客户资金拆借的违规事件，内部控制被出具带强调事项段审计意见。
- **[传统筑养路机械业务停滞]** -> [主业增长乏力]: 高端路面装备研制业务收入同比仅-0.72%，基本持平，行业竞争激烈，产品售价承压，公司聚焦降本增效而非扩张。
- **[现金流由负转正]** -> [经营质量边际改善]: 经营活动现金流净额从-3422万转为+768万（+122.45%），主要得益于销售回款增加，但净利润仍为负，现金流转正可持续性存疑。

## 风险警告
**核心风险在于新业务（新能源充电桩）的可持续性与传统业务的失血。** 恩科星虽贡献了93%的收入增长，但高度依赖关联方交易（关联销售占同类交易99.09%），且单一大客户开拓未达预期，毛利率已现下滑压力。若关联交易减少或市场竞争加剧，新能源业务的高增长将难以维系，公司可能失去唯一的增长引擎。

**内部控制与治理风险是另一颗定时炸弹。** 新任实控人陈可上任当年即发生违规资金拆借，导致内控审计被出具带强调事项段意见。这表明公司治理体系对实控人的约束力薄弱，后续可能再次出现关联交易非关联化、资金占用等风险。同时，母公司对子公司（尤其是恩科星）的管理控制能力存疑，整合风险高企。
