# 300922.SZ 深度透视

## 因果逻辑链
- **[国防装备列装与升级]** -> [营收微增0.72%]: 公司核心产品（专用防护装置）受益于下游弹药及装备的持续列装与换代需求，但增速受制于装备采购的强计划性与审价周期。
- **[客户高度集中]** -> [前五大客户占比94.41%]: 公司深度绑定中国兵器集团（64.45%）和中国兵装集团（17.79%），订单稳定性强，但议价能力和业务拓展空间受限。
- **[产品结构向高附加值倾斜]** -> [专用防护装置收入增长9.28%]: 公司主动聚焦核心主业，压缩低毛利的装备零部件业务（-72.85%），推动整体毛利率微升至34.97%。
- **[研发投入加大]** -> [研发费用增长45.88%]: 公司为抢占储运发一体、大型复合材料包装等未来方向，大幅增加研发投入，短期压制利润，但为长期增长储备技术。
- **[在建工程持续投入]** -> [在建工程占总资产31%]: 新型军用防护装置制造升级项目及新厂区建设进入收尾阶段，资本开支高峰期已过，未来将转化为产能与折旧。
- **[股权激励落地]** -> [管理费用增长6.37%]: 2024年限制性股票激励计划首次归属，产生股份支付费用，推高管理费用，但有效绑定核心团队。
- **[现金流健康]** -> [经营现金流净额7678万元]: 净利润现金含量高（约1.8倍），显示公司回款能力较强，财务结构稳健，为持续投入提供保障。

## 风险警告
**客户与订单的“双集中”风险是最大隐忧。** 公司收入高度依赖两大军工集团，前五大客户占比超94%。虽然军工业务壁垒高、粘性强，但单一客户的采购节奏、预算调整或型号换代延迟，都可能导致公司业绩剧烈波动。公司正试图拓展民用及新型号，但短期难以改变这一结构性依赖。

**募投项目转固后的盈利摊薄风险。** 公司“新型军用防护装置制造升级建设项目”已完工，在建工程高达3.5亿元，即将转入固定资产。这将带来显著的折旧压力，而新产能的利用率爬坡和订单消化需要时间，若下游需求不及预期，将直接侵蚀公司净利润，导致ROE进一步下滑。
