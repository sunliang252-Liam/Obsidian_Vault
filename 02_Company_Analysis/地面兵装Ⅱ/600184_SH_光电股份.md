# 600184.SH 深度透视

## 因果逻辑链
- **[防务产品交付恢复]** -> [营收与利润大幅反弹]: 2024年防务产品交付减少导致亏损，2025年交付回升，营收同比增长88.2%，归母净利润扭亏为盈至5108万元。
- **[光电材料与元器件高附加值产品放量]** -> [板块利润大幅增长]: 新华光公司高附加值红外产品销量增加，带动该板块净利润同比增长174.98%，成为利润稳定器。
- **[10.2亿元定增完成]** -> [资本结构优化与产能扩张]: 2025年7月完成向特定对象发行股票，募集资金用于“高性能光学材料及先进元件项目”和“精确制导产品数字化研发制造能力建设项目”，净资产增加10.09亿元。
- **[控股股东增持1亿元]** -> [市场信心提振]: 光电集团及中兵投资完成1亿元增持计划，向市场传递对公司发展前景的坚定信心。
- **[生产任务增加导致现金流恶化]** -> [经营现金流大幅净流出]: 防务产品交付增加带动物资采购和税金支出大幅增长，经营活动现金流净额由正转负，净流出3.66亿元。
- **[关联交易高度集中]** -> [业绩依赖集团内部订单]: 前五名客户销售额中关联方占比46.53%，前五名供应商采购额中关联方占比11.39%，业务独立性存疑。
- **[应收账款坏账风险暴露]** -> [信用减值损失增加]: 西光防务因回款预计减少，采用个别认定法确认坏账准备645万元，导致信用减值损失同比增加554万元。

## 风险警告
**核心风险在于经营现金流与利润的严重背离。** 2025年公司扭亏为盈，但经营活动现金流净额却由正转负，大幅净流出3.66亿元。这直接源于防务产品交付增加带来的采购和税金支出激增，暴露出公司“增收不增现”的脆弱性。若下游客户回款持续滞后，公司将面临巨大的流动性压力，2026年28.55亿元的营收目标能否转化为真金白银存在重大不确定性。

**另一重大风险是业绩对关联方的高度依赖与应收账款坏账风险。** 公司近半营收来自兵器集团体系内的关联交易，业务独立性较弱。同时，防务业务客户回款周期长、不确定性高，2025年已出现因回款预计减少而计提大额坏账的情况。若关联方付款能力或意愿发生变化，将直接冲击公司利润表与资产负债表，扭亏成果可能难以持续。
