# 600435.SH 深度透视

## 因果逻辑链
- **[军品交付放量]** -> [营收增长52.56%]: 2025年公司主要军品交付量较上年同期大幅增加，直接驱动营业收入从27.48亿跃升至41.92亿。
- **[营收规模效应]** -> [归母净利润翻倍]: 营收大幅增长52.56%，而管理费用、销售费用等固定成本增幅有限，利润弹性释放，归母净利润同比增长104.30%。
- **[高客户集中度]** -> [业绩高度依赖单一客户]: 前五名客户销售额占年度总额87.40%，其中关联方（兵器集团系统内）占比82.46%，公司经营与集团采购计划深度绑定。
- **[成本增速超收入]** -> [毛利率显著下滑]: 营业成本同比增长66.28%，远超营收52.56%的增速，导致制造业毛利率从22.22%下降至15.23%，下降近7个百分点。
- **[子公司分化严重]** -> [整体盈利受拖累]: 子公司中兵通信亏损5560万元，而衡阳光电和中兵航联合计盈利超1亿元，子公司间经营质量差异巨大，拖累合并报表表现。
- **[研发投入持续加码]** -> [技术壁垒构筑]: 研发费用同比增长18.22%至2.35亿元，围绕“8+3”技术体系持续投入，战略新兴产业收入占比达85%，为长期竞争力奠基。
- **[经营活动现金流为负]** -> [收入质量存疑]: 尽管营收大增，但经营活动现金流净额为-1.65亿元，表明销售回款与收入确认存在时间差，利润的现金保障度较低。

## 风险警告
**核心风险在于对单一客户的深度依赖与毛利率的持续压缩。** 公司82.46%的销售来自兵器集团系统内关联方，客户集中度极高，订单波动直接决定公司业绩。同时，成本增速持续高于收入增速，毛利率已从2023年的约22%降至2025年的15.23%，成本管控能力面临严峻考验，若军品定价机制或原材料成本进一步不利变动，盈利能力可能继续恶化。

**子公司中兵通信的巨额亏损是另一重大隐患。** 作为核心子公司，中兵通信2025年亏损5560万元，且营收同比下降8.35%，与母公司营收翻倍形成鲜明反差。这暴露出公司在不同业务板块间的协同与管控存在短板，通信业务板块的转型困境若不能扭转，将持续侵蚀上市公司整体利润。此外，经营活动现金流持续为负，显示公司“纸面富贵”特征明显，需警惕应收账款回收风险。
