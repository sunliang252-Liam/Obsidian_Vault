# 300263.SZ 深度透视

## 因果逻辑链
- **[电子新材料业务高增长]** -> [营收与利润双增]: 靶材国产替代加速，银合金靶材出货量翻倍，成功导入三星供应链，海外收入增长47%，驱动电子新材料板块收入增长21.07%。
- **[经营现金流大幅转正]** -> [财务质量显著改善]: 公司加大应收账款清收力度，销售回款大幅增加，经营活动现金流净额从-4483万跃升至4.42亿元，同比暴增1085%。
- **[兆恒科技PMI泡沫放量]** -> [高分子复合材料板块盈利贡献突出]: 航空、航天领域PMI泡沫需求旺盛，EPMI吸波泡沫获评“国际先进”，兆恒科技净利润6906万，成为核心利润引擎。
- **[三诺新材萃取剂项目投产]** -> [节能环保板块新增长点]: 年产6万吨高性能萃取剂项目投产，柔性产线可灵活调节，首个金属锂萃取EPC项目落地，为板块注入新动能。
- **[可转债转股与债务结构优化]** -> [净资产大幅提升]: 可转债转股增加股本1.3亿股，同时短期借款减少，长期借款增加，资产负债率从51%降至42.7%，财务结构更稳健。
- **[研发投入持续高企]** -> [技术壁垒持续加固]: 研发费用1.38亿元，占营收4.5%，聚焦G8.6 AMOLED银合金管靶、HITO靶材等前沿技术，巩固“研发-中试-量产”创新链条。

## 风险警告
**商誉减值风险高悬。** 公司账面商誉高达4.49亿元，占净资产10.9%，主要来自过往收购。尽管2025年未计提减值，但若兆恒科技、丰联科光电等核心子公司未来业绩不及预期，将面临大规模商誉减值风险，直接冲击利润表。这是公司资产负债表上最大的潜在“暗雷”。

**电子新材料业务毛利率承压。** 尽管该板块收入增长21%，但毛利率同比下降3.03个百分点至19.09%。原材料成本上升、产品结构变化及行业竞争加剧是主因。若毛利率持续下滑，将侵蚀公司核心利润增长的质量，显示“增收不增利”的隐忧。
