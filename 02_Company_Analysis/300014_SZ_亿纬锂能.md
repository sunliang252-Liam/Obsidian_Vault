# 300014.SZ 深度透视

## 因果逻辑链
- **[储能电池出货量全球前二]** -> [营收增长26.44%]: 储能电池出货71.05GWh，同比增长40.84%，成为营收最大增量来源。
- **[大圆柱电池量产领先]** -> [动力电池出货量增长65.56%]: 作为国内首家量产交付大圆柱电池企业，已装车超9万台，获国际头部车企下一代车型定点。
- **[消费电池三项国家级单项冠军]** -> [消费电池业务稳健增长7.29%]: 锂原电池连续9年国内销售额第一，在机器人、医疗等新兴领域率先卡位。
- **[CLS全球合作经营模式落地]** -> [轻资产扩张与利润增长]: 通过技术授权与服务支持，实现北美、欧洲项目落地，构建“技术输出-利润共享”生态。
- **[全产业链闭环布局]** -> [成本控制与供应链安全]: 从镍钴锂资源到电池回收的全产业链覆盖，对冲原材料价格波动风险。
- **[研发投入5.59%营收]** -> [技术路线多元化领先]: 固态电池、钠离子电池、超高功率电池等前沿技术同步推进，为未来增长储备动能。
- **[全球制造基地扩张]** -> [海外交付能力提升]: 马来西亚工厂投产，匈牙利工厂推进，支撑海外营收22.82%增长。

## 风险警告
**1. 毛利率持续承压与产能过剩风险。** 2025年公司整体毛利率16.17%，同比下降1.24个百分点，其中储能电池毛利率仅12.28%，同比下降2.44个百分点。行业产能过剩导致价格战持续，公司规划新增约260GWh大铁锂产能，若下游需求不及预期，将面临产能利用率下降和资产减值风险。

**2. 高资本开支与债务杠杆压力。** 公司2025年投资活动现金净流出126.16亿元，同比增长72.57%，在建工程175.21亿元，同比增长88.2%。长期借款205.32亿元，占总资产16.35%。大规模资本开支叠加行业周期下行，若现金流回款不及预期，将加大财务费用和偿债压力。

**3. 海外经营与地缘政治风险。** 公司海外营收占比23.56%，马来西亚、匈牙利工厂建设及CLS北美合作项目面临贸易壁垒、政策变动及地缘政治不确定性。同时，汇率波动已导致财务费用同比增长59.57%，海外业务盈利稳定性存疑。
