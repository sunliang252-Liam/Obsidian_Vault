# 000933.SZ 深度透视

## 因果逻辑链
- **[电解铝量价齐升]** -> [净利润40.05亿，同比-7%]: 电解铝满产且售价上涨，利润总额同比+48.66%，但被煤炭价格下行和资产减值损失（合计12.56亿）大幅抵消。
- **[煤炭售价下行]** -> [煤炭板块利润骤降]: 煤炭业务毛利率从16.67%暴跌至7.61%，导致新龙、兴隆等子公司净利润同比减少85%-95%。
- **[资产减值计提]** -> [侵蚀利润12.56亿]: 因和成煤矿停建、大磨岭煤矿停产等，对相关煤矿资产计提大额减值，是净利润下滑的核心非经营性因素。
- **[新疆/云南低成本产能]** -> [电解铝高毛利30.06%]: 新疆煤电（自备电+低煤价）与云南神火（水电+低物流成本）构成成本护城河，是盈利基石。
- **[绿电铝低碳优势]** -> [差异化竞争力]: 云南神火获全国首批绿电铝认证，新疆风电项目并网，满足下游碳关税与绿色消费需求，提升产品溢价能力。
- **[铝箔产能扩张]** -> [营收增长18.25%]: 电池铝箔产量全国第二，神火新材11.5万吨产能释放，但行业竞争加剧导致净利润同比-26.22%。
- **[经营性现金流强劲]** -> [现金分红17.87亿]: 经营活动现金流净额87.43亿，同比+13.28%，支撑高分红（每10股派8元），回报股东。
- **[氧化铝外购依赖]** -> [成本波动风险]: 主要原材料氧化铝全部外购，价格波动直接影响电解铝生产成本，是盈利稳定性的关键变量。

## 风险警告
**核心风险在于煤炭业务的持续恶化与资产减值的不确定性。** 2025年煤炭板块毛利率已降至7.61%，且公司对多个煤矿计提了巨额减值，显示部分矿井经济性已严重恶化。若2026年煤炭价格继续承压，或矿井开采条件进一步复杂化，可能引发新一轮减值，对利润造成持续冲击。

**第二大风险是云南水电的限电与电价调整风险。** 云南神火90万吨电解铝完全依赖网电，电力成本占比高。云南水电来水的不确定性可能导致限产，而电价上调将直接侵蚀利润。同时，公司氧化铝全部外购，上游价格波动无法完全对冲，成本控制存在天然短板。
