# 600623.SH 深度透视

## 因果逻辑链
- **[化工行业周期性下行]** -> [归母净利润同比-47.68%]: 主要产品销售价格下跌，叠加行业供需宽松，导致盈利空间被大幅压缩。
- **[吴泾基地关停]** -> [利润总额减少]: 落实政府产业调整要求，永久性关停老装置，产生一次性费用并减少未来收入来源。
- **[CMA公司反倾销诉讼损失]** -> [利润总额减少]: 确认美国反倾销诉讼损失，直接侵蚀当期利润。
- **[收购三爱富60%股权]** -> [资本公积减少36.41%]: 同一控制下企业合并，支付对价与净资产差额冲减资本公积，导致所有者权益结构变化。
- **[财务公司吸收存款减少]** -> [经营活动现金流净额-54.46%]: 合并报表外成员企业存款减少，导致现金流大幅波动，与主业经营关联度低。
- **[钦州基地项目持续推进]** -> [在建工程+47.36%]: 三期项目按计划建设，资本开支增加，为未来产能释放奠定基础。
- **[原材料价格下跌]** -> [成本端压力缓解]: 化工煤、丙烷等主要原料价格同比下降，部分对冲了产品售价下跌的负面影响。
- **[轮胎业务量增价稳]** -> [收入+3.75%]: 海外需求提升及国内商用车市场回暖，带动轮胎销量增长，成为少数正增长板块。

## 风险警告
**核心风险在于化工行业周期底部的不确定性。** 公司主要产品（醋酸、丙烯酸等）价格与宏观经济及下游需求高度相关，当前行业供需矛盾突出，若需求复苏不及预期，产品价格可能持续低迷，导致公司盈利能力进一步承压。2025年归母净利润已大幅下滑47.68%，扣非净利润仅3.17亿元，主业盈利基础薄弱。

**公司正经历“新旧产能切换”的阵痛期。** 吴泾基地关停、广西钦州基地等新项目尚处建设或爬坡期，短期内资本开支巨大（在建工程超100亿），且新项目面临投产初期折旧摊销高、市场开拓难等问题。同时，子公司广西新材料亏损4.28亿元，三爱富亏损0.8亿元，新收购资产尚未贡献利润，整合风险不容忽视。此外，与阿克马公司的4.3亿元专利诉讼悬而未决，构成潜在的重大或有负债。
