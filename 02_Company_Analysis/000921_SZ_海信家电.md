# 000921.SZ 深度透视

## 因果逻辑链
- **[中央空调业务（海信日立）的领先地位]** -> [公司利润核心支柱]: 海信日立贡献净利润29.3亿元，占归母净利润的92%，其多联机市场份额超23%，是公司最稳定的利润来源。
- **[海外自主品牌逆势增长]** -> [对冲内销下滑]: 境外收入同比增长6.44%至379亿元，欧洲、北美、东盟等区域白电收入均实现两位数增长，有效弥补了国内收入5.38%的下滑。
- **[“技术立企”与高端化战略]** -> [产品结构升级与毛利率稳定]: 新风空调、真空冰箱、热泵洗烘一体机等高端产品拉动中高端份额提升，使整体毛利率维持在22%，抵御了原材料成本上涨的压力。
- **[AI与数智化转型]** -> [运营效率提升]: 星海大模型使设备响应提速40%，订单履约周期改善22%，全球工厂制造效率同比提升21%，有效降低了运营成本。
- **[全球化体育营销]** -> [品牌资产提升]: 赞助FIFA世俱杯并官宣成为2026世界杯官方赞助商，品牌资产指数同比提升4%，为海外市场扩张提供了品牌势能。
- **[“以旧换新”政策红利]** -> [内销高端产品放量]: 国家“两新”政策驱动下，璀璨高端套系收入同比增长24%，新风空调安装量同比增长49%，加速了产品结构向高端化转型。
- **[供应链全球化布局]** -> [应对贸易壁垒]: 墨西哥、泰国等海外制造基地投产，海外资源池覆盖率超90%，有效缓解了关税政策波动带来的风险，保障了海外供应链韧性。

## 风险警告
**核心风险在于国内家电市场整体需求萎缩与价格战加剧。** 2025年公司营收同比下降5.19%，国内收入下滑5.38%，中央空调和家用空调市场均面临量价齐跌的困境。尽管公司通过高端化策略维持了毛利率，但若宏观经济持续低迷，消费降级趋势深化，公司的高端产品溢价能力将面临严峻挑战，利润增长将失去国内市场的支撑。

**第二大风险是海外业务的不确定性。** 虽然海外收入增长强劲，但公司明确承认对关税政策波动的“敏捷应对能力尚显不足”。美国关税政策、地缘政治风险以及海外渠道库存高企，都可能随时冲击海外业务的增长势头和盈利能力。此外，海外业务毛利率（12.59%）远低于国内（29.85%），其快速增长会拉低公司整体盈利水平，存在“增收不增利”的风险。
