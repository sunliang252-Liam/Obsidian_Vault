# 002762.SZ 深度透视

## 因果逻辑链
- **[出生率持续下滑]** -> [母婴主业承压]: 2025年出生人口792万（同比-16.98%），0-3岁存量市场萎缩，倒逼公司向4-16岁及全家可用领域拓展。
- **[产品线向大龄段延伸]** -> [营收增长71.86%]: 将目标客群从0-3岁扩展至0-16岁及全家，叠加线上渠道扩张（+123.19%），推动总收入增至3.86亿元。
- **[并购珠海/中山韩妃并表]** -> [医美贡献正向利润]: 2024年末控股两家医美机构，2025年医美收入6862.5万元（占比17.77%），毛利率50.89%，成为第二增长极。
- **[韩妃投资业绩对赌失败]** -> [巨额公允价值变动损失]: 韩妃投资2023-2024年累计承诺利润1.63亿元，实际完成-5329万元（完成率-32.7%），触发回购仲裁，确认公允价值变动损失-6496.5万元。
- **[计提长期股权投资减值]** -> [资产减值损失暴增]: 对韩妃投资计提减值准备5581.21万元，叠加存货跌价损失，全年资产减值损失达-7755.6万元。
- **[线上渠道激进扩张]** -> [毛利率大幅下滑]: 线上销售占比从37.7%升至48.96%，但线上毛利率仅26.55%，拉低母婴消费品整体毛利率至35.12%（同比-13.96pct）。
- **[经营活动现金流恶化]** -> [造血能力承压]: 经营现金流净额-3741.8万元（同比-475.99%），主因采购支付及职工薪酬增加，与净利润大幅亏损形成共振。

## 风险警告
**核心风险：韩妃投资业绩对赌失败引发的连锁财务冲击。** 公司2021年以2.376亿元收购韩妃投资36%股权，承诺方未完成2023-2024年合计1.63亿元利润目标，仲裁已裁定回购，但承诺方未按期履行，公司已申请强制执行。该事项导致2025年确认公允价值变动损失6496.5万元、长期股权投资减值5581.2万元，合计拖累利润超1.2亿元，是全年巨亏1.87亿元的主因。若执行款项无法及时收回，将进一步侵蚀资产负债表。

**第二风险：母婴主业“增收不增利”的结构性困境。** 营收增长71.86%主要靠线上渠道低价冲量（线上毛利率仅26.55%），母婴消费品毛利率同比下滑13.96个百分点。同时，出生率持续下行（2025年出生人口792万，同比-16.98%）导致存量竞争加剧，公司直营/加盟门店分别净关10家/39家，线下渠道收缩趋势未改。在“少子精养”趋势下，公司向大龄段延伸的战略能否转化为可持续的利润增长，尚待验证。
