# 688609.SH 深度透视

## 因果逻辑链
- **[中国移动集采单价下降+出货放缓]** -> **智能终端收入下滑**: 公司第一大客户中国移动集采项目智能网络机顶盒中标单价下降，市场出货需求整体放缓，导致智能终端产品销售收入同比减少5.31%。
- **[存储芯片价格持续上涨]** -> **毛利率承压**: 2025年AI需求驱动存储芯片价格持续上涨且供应偏紧，公司原材料成本上升，但运营商采购价格调整滞后，导致整体毛利率仅10.17%，同比下降1.03个百分点。
- **[新业务研发投入高+尚未规模化]** -> **持续亏损**: 鸿蒙生态、机器人、新能源等新业务处于生态建设与孵化阶段，研发投入较高但营收占比仍较低，叠加传统业务利润下滑，导致归母净利润-2.11亿元，亏损同比扩大48.60%。
- **[智慧城市项目交付规模减少]** -> **运营服务收入下降**: 报告期交付并验收的智慧城市项目规模较上年同期下降，导致运营服务收入同比减少31.22%，毛利率下降11.83个百分点。
- **[海外市场拓展+通信模块增长]** -> **收入结构优化**: 海外销售收入同比增长47.93%，通信模块及行业应用解决方案收入同比增长21.49%，一定程度上对冲了国内智能终端收入下滑的影响。
- **[经营现金流大幅改善]** -> **回款能力增强**: 经营活动现金流净额4.30亿元，同比增长442.57%，主要系销售回款增加及税费返还增加，显示公司运营效率有所提升。
- **[三期工程转固+新购土地]** -> **资产结构变化**: 固定资产同比增长71.62%（三期工程转固），无形资产同比增长88.29%（新购土地），在建工程减少99.97%，表明公司产能扩张进入新阶段。

## 风险警告
**核心风险：对中国移动的过度依赖与低毛利代工模式的双重挤压。** 公司对中国移动的销售收入占比高达58.42%，存在重大客户依赖风险。同时，面向运营商市场的智能终端产品多采用运营商品牌（代工模式），导致整体毛利率仅10.17%，议价能力薄弱。在存储芯片等核心原材料价格持续上涨的背景下，运营商采购价格调整滞后，公司利润空间被进一步压缩，连续三年亏损且亏损额扩大。

**成长性风险：新业务尚处孵化期，短期难以贡献利润。** 公司重点布局的鸿蒙生态、新能源、军工等新业务虽已取得阶段性进展，但营收占比仍较低，整体处于生态建设与业务孵化阶段，研发投入持续高企。若新业务产业化进展不及预期，公司将继续面临“传统业务利润下滑、新业务无法接棒”的困境，经营业绩存在继续亏损的风险。
