# 000426.SZ 深度透视

## 因果逻辑链
- **银锡价格大幅上涨** -> 营业收入同比增长30.09%: 银锡产品收入占比68.86%，价格上行直接拉动收入增长
- **合并宇邦矿业** -> 矿产银产量增长31.50%: 宇邦矿业银资源量2.09万吨，2025年纳入合并范围增加白银产出
- **锡价格高位宽幅震荡** -> 矿产锡产量下降24.97%: 锡价高企但产量下降，可能受品位或计划调整影响
- **银漫矿业技术攻关提高锡回收率** -> 银漫矿业锡金属回收率提升超20%: 选矿工艺优化使资源利用效率提升
- **绿色矿山政策趋严** -> 公司加大环保及尾矿治理投入: 政策推动常态化监管，公司需增加相关投入以维持合规运营
- **美联储降息及美元信用体系受挑战** -> 白银价格屡创新高: 降息周期提升流动性，避险需求推高贵金属价格

## 风险警告
公司业绩高度依赖银、锡价格波动，虽产量增加但锡产量下降，且成本上升毛利率下滑，需警惕价格回调及成本管控风险。此外，海外业务如摩洛哥锡矿存在政治及运营风险。
