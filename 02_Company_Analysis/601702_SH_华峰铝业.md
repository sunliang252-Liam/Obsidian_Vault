# 601702.SH 深度透视

## 因果逻辑链
- **[新能源汽车/储能高景气]** -> [销量增长14.79%]: 下游新能源车渗透率突破50%，储能液冷散热需求爆发，拉动铝热传输材料销量达48.78万吨，创历史新高。
- **[“铝锭价+加工费”定价模式]** -> [营收增14.79%，但毛利率降2.3pct]: 铝价攀升推高营收，但行业产能过剩、内卷加剧导致加工费承压，成本传导不畅，利润空间被挤压。
- **[热轧瓶颈工序产能不足]** -> [净利润微降1.32%]: 现有热轧产能成为瓶颈，导致热轧成本攀升，对冲了规模扩大带来的利润提升，出现“增收不增利”。
- **[出口退税取消+贸易壁垒]** -> [外销收入同比降2.64%]: 欧盟、美国等反倾销及关税壁垒，叠加出口退税优惠取消，导致海外出口总量下滑，公司外销业务承压。
- **[重庆45万吨项目投资扩张]** -> [在建工程增518%，短期借款增88%]: 为突破热轧瓶颈，公司大幅扩产，导致资本开支激增，同时为补充流动资金，短期借款大幅增加。
- **[收购毗邻资产华峰普恩]** -> [拓展冲压件业务，延伸产业链]: 收购停业状态的毗邻工厂，利用其场地进行冲压件生产，从铝材供应商向下游结构件延伸，提升附加值。
- **[研发投入占比4.78%]** -> [巩固技术护城河]: 持续投入预埋钎剂、无钎剂材料、高强耐蚀水冷板等高端新品研发，参与国标制定，维持高端客户粘性与行业领先地位。

## 风险警告
**核心风险在于“增收不增利”的困境可能持续。** 公司营收和销量创历史新高，但净利润却微降，主因是行业加工费下行和自身热轧产能瓶颈。虽然重庆45万吨项目旨在解决瓶颈，但巨额投资（26.19亿）导致短期借款激增88%，财务费用飙升1110%，且项目投产前，热轧成本压力将持续侵蚀利润。若行业竞争进一步加剧，加工费继续下滑，公司盈利可能继续承压。

**另一重大风险是国际贸易摩擦与汇率波动。** 公司外销占比约30%，面临欧美反倾销、关税壁垒及出口退税取消的多重打击，外销收入已出现下滑。同时，公司以美元/欧元结算为主，人民币汇率波动将直接导致汇兑损益，2025年财务费用飙升主因就是汇兑收益下降。尽管公司使用衍生品对冲，但无法完全消除风险，海外市场的不确定性是长期隐忧。
