# 688372.SH 深度透视

## 因果逻辑链
- **[AI与智驾芯片需求爆发]** -> [营收与利润创历史新高]: 下游AI、智驾等新兴领域对高端芯片测试需求激增，公司作为独立第三方测试龙头，直接受益于高价值量、长测试时间的订单增长。
- **[前瞻性高端产能扩张]** -> [锁定结构性增长机遇]: 公司提前布局无锡、南京等高端测试基地，购入爱德万V93000等稀缺设备，形成国内领先的高端测试产能规模，成功承接了AI、高性能计算等领域的爆发式需求。
- **[产品结构向高端测试优化]** -> [毛利率提升]: 高算力、高可靠性芯片测试单价高、技术壁垒高，其业务占比提升带动整体毛利率同比增加1.53个百分点，盈利能力显著增强。
- **[国产替代加速]** -> [客户结构优化与市场渗透]: 国内芯片设计公司为保障供应链安全，将测试订单从境外转向境内，公司凭借技术实力和产能规模，成为紫光展锐、地平线等200余家客户的核心供应商。
- **[规模效应与运营效率提升]** -> [扣非净利润增速远超营收]: 营收增长46.22%的同时，扣非净利润增长110.18%，表明固定成本（折旧）被有效摊薄，经营杠杆效应显现。
- **[可转债成功发行]** -> [资本结构优化与产能建设加速]: 2025年完成11.75亿元可转债发行，为无锡、南京项目及上海总部基地建设提供充足资金，总资产同比增长57.07%，为未来增长奠定基础。

## 风险警告
**核心风险在于产能消化与设备依赖的双重压力。** 公司正处于激进扩张期，总资产暴增57%，在建工程与固定资产合计占总资产74%。若下游AI、智驾需求增速放缓或市场竞争加剧，巨额折旧与刚性成本将严重侵蚀利润。同时，公司核心测试设备高度依赖爱德万、泰瑞达等海外供应商，中美贸易摩擦升级可能导致设备进口受限，直接威胁产能扩张计划与日常运营。

**财务风险不容忽视。** 应收账款同比增长49.28%至5.27亿元，占营收比例达33.5%，且信用减值损失大幅增加，回款压力随营收高速增长而加剧。此外，公司资产负债率因大规模举债扩张而显著攀升，短期借款与长期借款合计超24亿元，财务费用同比增长75%，高杠杆运营下，利率波动或现金流紧张将放大财务风险。
