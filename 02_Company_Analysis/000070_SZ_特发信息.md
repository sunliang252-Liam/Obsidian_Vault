# 000070.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [线缆板块收入增长20.17%]: 互联网商数据中心机房业务爆发，带动光纤光缆、高端MPO连接器需求。
- **[国内光通信产能过剩]** -> [行业竞争加剧，毛利率承压]: 普通光缆产品同质化严重，价格战持续，成本控制成为核心竞争要素。
- **[智慧城市项目财政预算收紧]** -> [智慧服务板块收入下降49.79%]: 集成业务需求受制于经济形势，区域外市场拓展困难。
- **[融合行业审价机制]** -> [融合板块毛利率下降12.25%]: 产品结算价格与初步报价存在差异，需在当期调整确认，导致毛利波动。
- **[前期并购商誉及资产减值]** -> [归母净利润亏损4.96亿元]: 对智慧城市创展基地项目、并购形成的商誉等计提大额减值准备，是亏损主因。
- **[海外算力中心投资热潮]** -> [国外收入同比增长96.92%]: 越南基地产能扩张，高端连接器批量生产，海外订单大幅增长。
- **[陈传荣业绩承诺违约]** -> [剩余7000万元补偿款未偿付]: 特发东智2019、2020年未完成承诺业绩，原股东补偿义务履行存在重大不确定性。

## 风险警告
公司连续三年扣非净利润为负，2025年归母净利润亏损扩大至4.96亿元，主要源于对智慧城市创展基地、并购商誉等资产的大额减值计提。核心子公司特发东智业绩承诺违约，剩余7000万元补偿款追讨困难，叠加智慧服务板块收入腰斩，公司基本面持续承压，盈利能力未见改善迹象。

光通信国内市场竞争白热化，普通产品产能过剩导致价格战，毛利率持续被压缩。融合业务受制于下游客户审价机制和成本管控，毛利率大幅下滑。公司虽受益于AI算力带来的海外需求增长，但海外业务占比仍较低，且面临贸易壁垒风险。物业租赁市场空置率上升，租金下行压力显著。
