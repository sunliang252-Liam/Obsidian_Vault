# 920261.BJ 深度透视

## 因果逻辑链
- **[聚氨酯双产业链规模优势]** -> [营收增长9.37%]: 公司凭借聚醚、聚酯双产业链协同，在行业供大于求背景下，实现收入75亿元，规模效应摊薄成本。
- **[差异化、高附加值产品开发]** -> [毛利率微增至6.41%]: 聚焦高性能、功能化产品，有效对冲大宗原材料价格波动，毛利率逆势提升0.07个百分点。
- **[“先款后货”严格信用政策]** -> [经营现金流大幅下降60.2%]: 应收账款增加7110万元（+44.57%），主要因出口信用证结算增加，但现金流仍为正，风险可控。
- **[在建工程大幅投入]** -> [资产结构向长期资产倾斜]: “30万吨/年EO/PO下游衍生物项目”等在建工程增加2.32亿元（+183%），总资产增长13.56%，预示未来产能释放。
- **[高新技术企业税收优惠]** -> [净利润增速（5.73%）高于营收增速（9.37%）]: 15%所得税率及研发费用加计扣除持续贡献利润弹性。
- **[海外市场拓展与汇率波动]** -> [财务费用由负转正]: 出口收入增长10.61%，但人民币汇率波动导致汇兑损失增加，财务费用同比增加1511万元。
- **[研发投入持续高企]** -> [技术壁垒与产品迭代]: 研发支出占营收4.25%，获发明专利57件，支撑在CPU、TPU等细分领域保持“单项冠军”地位。

## 风险警告
**核心风险在于行业供需失衡与原材料价格波动。** 聚氨酯行业产能过剩，下游需求复苏乏力，公司毛利率长期在6%左右低位徘徊，盈利空间极度压缩。主要原料TDI、MDI、EO、PO价格波动频繁，公司虽能部分传导，但若上游成本大幅上涨或下游需求持续疲软，盈利能力将面临显著冲击。

**第二大风险是产能扩张后的消化与现金流压力。** 公司正同时推进多个大型项目（总投资超30万吨），在建工程激增183%，导致投资活动现金流净流出1.03亿元。若项目达产后市场需求不及预期，或新增产能导致行业竞争进一步加剧，将面临产能利用率下降、资产减值及现金流恶化的风险。此外，应收账款因出口业务大增而显著上升，需警惕坏账风险。
