# 000088.SZ 深度透视

## 因果逻辑链
- **[参股盐田国际及西港区码头吞吐量上涨]** -> [投资收益高增]: 参股企业盐田国际（一、二期）和西港区码头净利润分别增长5.10%和10.24%，是公司利润的核心来源。
- **[惠盐高速改扩建主线八车道贯通]** -> [高速公路收入与车流量大增]: 改扩建完工后，道路通行能力大幅提升，收费车流量同比增长25.54%，带动高速公路业务收入增长22.02%。
- **[小漠港引战投中远海运特运]** -> [提升“航运+港口+物流”一体化能力]: 补齐运力与航线资源短板，增强汽车滚装等核心业务竞争力，为未来增长奠定基础。
- **[黄石新港创新多式联运模式]** -> [业务量与营收创历史新高]: 创新“散改集”、“公转铁”等模式，推动多式联运业务增长，但受建筑行业低迷影响，总吞吐量下降12.63%。
- **[惠州荃湾煤炭港创新铁路总包及联合营销模式]** -> [吞吐量逆势增长18.44%]: 通过模式创新强化与电厂客户粘性，推动业务量增长，成为散货业务亮点。
- **[常德港创新商务联盟合作模式]** -> [吞吐量大幅增长40.96%]: 通过减少区域竞争，推动砂石等业务量提升，实现营收双增长。
- **[公司首次启动中期分红]** -> [加大投资者回报]: 全年派息11.33亿元，提升分红频次，有效提振投资者信心，体现公司对股东回报的重视。

## 风险警告
**核心风险在于业绩对投资收益的高度依赖与自营业务的脆弱性。** 公司2025年利润总额中，投资收益占比高达89.14%，主要来自参股的盐田国际、西港区码头等。一旦全球贸易波动、航运联盟格局变化或区域竞争加剧，导致参股港口吞吐量下滑，公司利润将面临剧烈波动。同时，自营港口业务表现分化严重，黄石新港因建筑行业低迷吞吐量下降12.63%，显示公司对宏观经济周期和特定行业风险的敞口较大。

**第二大风险是重大在建工程的投资回报不确定性。** 公司正同时推进惠盐高速改扩建、小漠港二期、黄石新港三期等多个大型项目，总投资规模巨大。这些项目投资回收期长，且面临政策变化（如高速公路收费政策）、区域竞争加剧、建设成本超支等风险。特别是惠盐高速改扩建项目投资规模已从29.2亿元大幅调整至158.59亿元，其未来车流量能否持续高增长以覆盖巨额投资，存在较大不确定性。
