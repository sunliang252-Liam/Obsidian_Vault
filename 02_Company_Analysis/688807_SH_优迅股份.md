# 688807.SH 深度透视

## 因果逻辑链
- **[FTTR与千兆光网政策红利]** -> [接入网业务收入稳健增长]: 国内运营商持续推广FTTR，带动公司10G及以下速率PON芯片需求提升，构成营收基本盘。
- **[25G-100G高速电芯片客户导入成功]** -> [数据中心及无线接入业务打开新增长空间]: 高端产品完成对主流设备商和模块厂商的认证，切入高价值市场，优化收入结构。
- **[IPO募集资金到位]** -> [总资产与净资产大幅增长]: 2025年成功上市，募集资金使总资产同比增长128.82%，净资产增长143.53%，资本实力飞跃。
- **[销售回款增加与战略性采购减少]** -> [经营活动现金流净额暴增3645.6%]: 营收增长带动收款，叠加上年同期为支持扩张而大量采购的基数效应，现金流显著改善。
- **[50G PON全系列产品布局]** -> [巩固下一代固网接入市场先发优势]: 完成对称/非对称、OLT/ONU全场景芯片方案，研发进度与国际主流同步，为万兆光网商用储备产品。
- **[400G/800G及1.6T芯片研发突破]** -> [抢占AI算力时代高速互联制高点]: 单波100G PAM4平台搭建完成并向客户送样，1.6T项目启动，技术能力从追赶到并跑。
- **[车载光通信与激光雷达芯片获客户认可]** -> [开辟终端侧第二增长曲线]: 成功绑定头部车企及Tier1，激光雷达芯片获政策支持，业务边界从通信向车载、传感延伸。
- **[Fabless模式与供应链多元化]** -> [保障供应链安全与弹性]: 晶圆代工双工艺平台、封测全部本土化，降低对单一供应商依赖，应对地缘政治风险。

## 风险警告
**核心风险在于高端市场突破的不确定性。** 公司当前营收与利润仍高度依赖10G及以下速率产品，25G-100G产品虽已导入客户，但尚未形成规模化收入贡献。400G/800G及1.6T芯片仍处于送样或研发阶段，距离大规模量产并贡献利润尚有较长周期。若AI算力需求增速放缓、技术路线变更（如LPO/CPO方案对电芯片需求结构改变），或国际竞争对手（Macom、Semtech）在高速领域发起价格战，公司的高端化战略可能不及预期，导致营收增速放缓、毛利率承压。

**供应链集中与经营规模偏小构成双重脆弱性。** 公司前五大供应商采购占比高达84.41%，晶圆代工高度依赖少数几家厂商，地缘政治风险（如美国对华半导体设备/EDA出口管制升级）可能导致产能中断或成本飙升。同时，公司年营收不足5亿元，产品结构相对单一，抗行业周期波动能力远弱于国际巨头。若下游电信运营商资本开支收缩或数据中心客户削减采购，公司业绩可能出现大幅波动。此外，子公司武汉芯智光联仍处于亏损状态，新业务培育期的投入将持续侵蚀利润。
