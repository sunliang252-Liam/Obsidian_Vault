# 002723.SZ 深度透视

## 因果逻辑链
- **[家电主业承压]** -> [营收利润双降]: 传统照明、风扇业务受市场竞争加剧和价格战影响，订单量与毛利率同步下滑，导致家电业务收入同比下降28.23%。
- **[施工工程业务剥离]** -> [营收规模骤减]: 公司于2025年12月出售国海建设51%股权，导致工程施工业务收入同比腰斩（-52.53%），并丧失并表资格，总营收下降34.27%。
- **[资产与信用减值集中爆发]** -> [巨额亏损]: 报告期内对应收账款、存货、商誉及合同资产合计计提减值损失超1.3亿元，是导致净利润亏损2.52亿元的核心原因。
- **[电子烟业务不及预期]** -> [利润侵蚀]: 电子烟业务营收持平但毛利率下降，且因逾期应收账款单项计提坏账及长库龄产品折价计提跌价准备，对当期利润造成较大负面影响。
- **[热泵业务未达承诺]** -> [商誉减值]: 热泵产品市场不及预期，未能完成业绩承诺，导致公司对收购普希电器形成的商誉计提减值798.57万元。
- **[出售国海建设]** -> [回笼资金与确认投资收益]: 以1.5亿元出售国海建设51%股权，回笼资金并确认处置收益约2,742.78万元，但剩余49%股权按公允价值调整产生损失，整体对利润影响有限。
- **[控股股东高比例质押]** -> [控制权变更风险]: 控股股东华欣创力所持股份质押率高达96.90%，且已与嘉晟时代签署股份转让协议，若交易完成，公司实际控制人将发生变更。

## 风险警告
公司当前面临的核心风险是**主业竞争力持续下滑与资产质量恶化**。家电业务（照明、风扇）在激烈市场竞争中量价齐跌，毛利率全面下滑，而新布局的电子烟、热泵业务均未达预期，导致公司缺乏新的利润增长点。同时，巨额应收账款与合同资产的信用减值风险高企，叠加商誉减值，已连续两年大额亏损，盈利能力堪忧。

**控制权不稳定与高额对外担保**是另一重大隐患。控股股东股份质押比例极高，且已启动控制权转让，未来公司战略方向存在不确定性。此外，公司对已剥离的参股公司国海建设仍存在高达4.46亿元的对外担保余额，若其经营恶化，公司将承担连带清偿责任，构成潜在的巨大财务风险敞口。
