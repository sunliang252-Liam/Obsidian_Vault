# 600628.SH 深度透视

## 因果逻辑链
- **宏观促消费政策及商圈活动联动** -> 百货客流增长3%至1500万人次: 公司积极对接市、区促消费活动，与会展、赛会、旅行社联动，直接拉动客流增长。
- **内容营销驱动与销售冠军品牌数量增加** -> 百货商场竞争优势提升: 通过营销活动产生54家“销售冠军”品牌，体现商场对品牌的吸引力和销售能力。
- **新媒体布局与直播创新** -> 私域流量转化及互动增长: 构建“品牌曝光-用户互动-场景转化”链路，新媒体营销成为新亮点，实现流量转化。
- **境外消费服务优化及免签政策刺激** -> 退税销售大幅增长75.67%: 提供“即买即退”及多语种服务，境外顾客消费成为新亮点，退税笔数增加。
- **免签政策及入境旅游回暖** -> 酒店境外客户占比超75%，客房营收同比增长15%: 入境旅游回暖及免签政策吸引境外客源，导致酒店入住率和房价提升。
- **徐重道饮片基地建设稳步推进** -> 未来医药板块核心竞争力提升: 以“智慧工厂”为目标，打造现代化饮片生产基地，为2026年投产奠定基础。
- **中药饮片集采政策影响** -> 医药销售营业收入减少2.93%: 集采挤压价格，导致医药销售收入略有下降。
- **百货零售市场供给过剩、同质化竞争加剧** -> 百货商场营业收入减少6.32%: 商业供给过剩，竞争激烈，导致百货收入下滑。
- **信用卡及货款回款金额减少，政府补助减少** -> 经营活动现金流量净额下降47.22%: 回款减少和政府补助减少直接导致现金流下降。
- **结构性存款持有规模下降及累计赎回小于购买** -> 投资活动现金流量净额大幅下降694.74%: 结构性存款操作导致投资活动现金流出增加。

## 风险警告
公司整体营收受百货零售业和医药业双板块下滑拖累，其中百货面临供给过剩与同质化竞争，医药受中药集采价格挤压。经营现金流大幅下降，且投资活动现金流因结构性存款操作出现大幅流出，需关注流动性管理。酒店虽表现亮眼但规模有限，难以完全对冲主业下滑。

> 上海新世界股份有限公司是一家有着百年历史的中华老字号企业,又是一家沐浴着改革开放春风不断发展、壮大的上市公司和中国商业名牌企业。“新世界”前身是1915年创建的“新世界游乐场”,1958年,合并组建“新世界百货商场”。1988年8月,公司由全民企业改制成为南京路上的商业股份制企业;1992年5月获准向社会公开募股;1993年1月19日在上海证券交易所挂牌上市,“新世界”从此跨入全国商业十强行列。     公司拥有上海新世界城有限公司、新世界丽笙大酒店有限公司、上海蔡同德药业有限公司等10多家全资或控股子公司。改制二十多年来,企业得到了长足的发展:今日的新世界与1988年改制之初相比,销售、利润和税收均增长了200多倍,净资产增长了近3000倍;新世界十多年来创造了商业零售300多个亿,创造税利30多个亿,创造商业不动产100个亿。企业三个文明建设更是硕果累累:曾先后荣获“全国文明单位”、“全国精神文明建设先进单位”、“全国思想政治工作优秀企业”、“全国五一劳动奖状”、“全国诚信单位”、“全国商业质量奖”、“全国质量奖”等市级以上荣誉160余项。     公司投资兴建的新世界城位于南京路步行街西段起点,距上海市人民政府、上海博物馆、上海城市规划馆、上海美术馆、国际饭店咫尺之遥。地下一层有两条通道连接地铁一号线、二号线、八号线等地铁换乘站,地面有18路、23路、46路、隧道三线等数十条公交线路站点。     新世界城总建筑面积20多万平方米,是一座集购物、娱乐、宾馆、餐饮、休闲于一体的生活茂,由新世界购物广场、新世界娱乐广场、新世界丽笙大酒店、新世界美食休闲广场、新世界立体停车场五个板块组成。其中:购物占35%,主要经营国内外知名品牌;宾馆占28%,五星级的新世界丽笙大酒店拥有45F旋转餐厅和47F星空酒吧;文化和娱乐占15%,包括全球第6家、大陆首家的英国杜莎夫人蜡像馆---上海杜莎夫人蜡像馆(新世界城)、上海第一家室内真冰溜冰场---新世界真冰溜冰场、新世界上影华威影城和上海歌城;餐饮占8.5%,主要经营港澳台品牌的时尚餐饮;商务办公及辅助设施占13.5%。     “新世界”的目标定位是打造成为上海乃至全国一流的精品百货,并引领南京路成为著名品牌的集聚地、流行品牌的发祥地,成为世界著名商业街和消费者的购物天堂。
