# 600697.SH 深度透视

## 因果逻辑链
- **[消费市场下行与租赁服务收入减少]** -> [营收下降3.67%]: 市场环境疲软导致商品销售和租赁服务收入同步收缩，直接拖累整体营收。
- **[存货及投资性房地产计提资产减值]** -> [归母净利润亏损5179万元]: 资产减值损失5827万元是侵蚀利润的核心因素，导致归母净利润由正转负。
- **[非同一控制下企业合并带来的公允价值重估收益]** -> [非经常性损益大幅增加]: 合并济南欧亚大观园和欧亚长青，产生4638万元投资收益，掩盖了主业亏损的严重程度。
- **[高比例自持物业与高有息负债]** -> [财务费用高企]: 自持物业模式占用大量资金，导致有息负债规模庞大，财务费用3.84亿元，严重吞噬利润。
- **[门店调改与品牌调整]** -> [运营效率提升]: 全年调整品牌1500余个、调改面积30万平米，部分调改门店客流与销售回暖，但整体效果尚未在利润端体现。
- **[自采自营与供应链整合]** -> [毛利率微增]: 通过“集团采”、“系列采”及河北高碑店集采中心，生鲜损耗率下降，商品流通行业毛利率提升0.45个百分点。
- **[降本增效与智慧物联平台]** -> [费用管控见效]: 能源成本显著下降，销售费用、管理费用、财务费用同比均有所减少，但降幅不足以对冲收入下滑和资产减值的影响。

## 风险警告
**核心风险在于资产减值与财务杠杆的双重挤压。** 公司归母净利润已连续两年亏损，且亏损额同比扩大86%，主因是高达5827万元的资产减值损失（存货、投资性房地产）。同时，公司总资产192.5亿元，但净资产仅41.76亿元，资产负债率高达78.3%，有息负债规模巨大，每年3.84亿元的财务费用是利润的沉重负担。这种“重资产、高杠杆”模式在消费下行周期中极为脆弱，一旦资产价值继续缩水或融资环境收紧，将面临严峻的流动性压力。

**第二重风险是主业增长乏力与转型不确定性。** 公司营收连续下滑，核心的购物中心（百货店）和连锁超市业态收入均呈负增长。尽管公司大力进行门店调改、发展自采自营和数字化，但这些举措尚处于投入期，未能扭转利润下滑趋势。在线上零售和新兴商业体持续冲击下，传统实体零售的客流与坪效面临长期挑战，公司能否通过调改实现有效复苏存在较大不确定性。
