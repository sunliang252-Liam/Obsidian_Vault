# 600828.SH 深度透视

## 因果逻辑链
- **[投资性房地产公允价值变动]** -> [归母净利润巨亏2.46亿]: 公司采用公允价值模式计量投资性房地产，2025年市场下行导致公允价值变动损失1.98亿元，是净利润由盈转亏的核心原因。
- **[消费市场疲软与竞争加剧]** -> [营业收入同比下降12.84%]: 实体零售受线上冲击及消费需求理性化影响，公司23家门店收入全面下滑，尤其百货业态收入同比下降18.10%。
- **[联营转租赁战略深化]** -> [联营收入骤降32.10%，租赁收入仅降13.48%]: 公司主动将传统联营模式转为租赁模式，虽短期冲击联营收入，但租赁模式毛利率100%，有助于稳定整体盈利结构。
- **[经营现金流大幅萎缩63%]** -> [偿债与再投资能力承压]: 销售回款减少导致经营活动现金流净额从10.53亿降至3.89亿，在财务费用高达2.79亿的背景下，公司流动性压力显著增大。
- **[高额财务费用侵蚀利润]** -> [扣非净利润持续为负]: 财务费用2.79亿元，占营业收入的11.8%，远超扣非净利润-0.87亿元，高负债运营是公司长期盈利能力受损的根本原因。
- **[自有物业占比超60%]** -> [构筑成本护城河与资产增值潜力]: 大部分门店位于核心商圈且为自有，有效抵御租金上涨风险，但同时也将公司业绩与商业地产估值深度绑定，放大了公允价值波动风险。
- **[商管业务启航]** -> [开辟轻资产新增长极]: 设立茂业商管并成功承接深圳大型商业综合体项目，标志着公司从重资产运营向轻资产输出转型，有望贡献新的利润来源。

## 风险警告
公司当前最大的风险在于**资产价值重估与经营现金流恶化的双重挤压**。投资性房地产公允价值变动直接导致巨额亏损，而经营现金流的大幅萎缩（-63%）则削弱了公司应对债务和维持运营的能力。在财务费用居高不下（2.79亿）的背景下，若商业地产市场持续低迷或消费复苏不及预期，公司可能面临资产减值与流动性危机的螺旋式下降。

其次，**历史并购形成的同业竞争与商誉减值风险悬而未决**。控股股东关于解决同业竞争的承诺多次延期，虽已委托管理，但资产注入或剥离的实质性进展缓慢。同时，公司持续对前期并购门店进行调改，若效果不达预期，将引发商誉减值，进一步冲击本已脆弱的利润表。此外，公司连续两年扣非净利润为负，主业盈利能力堪忧。
