# 603708.SH 深度透视

## 因果逻辑链
- **[门店调改与运营优化]** -> [归母净利润同比+52.09%]: 关闭低效尾部门店，对44家门店进行大改，提升单店运营质量与盈利能力，在收入微降1.64%的情况下实现利润大幅增长。
- **[自有品牌与定制商品开发]** -> [毛利率提升0.80个百分点]: 自有品牌及定制商品销售占比提升至15.59%，通过“好东西不贵”的差异化商品策略，增强了定价自主权与盈利能力。
- **[供应链效率提升与库存优化]** -> [经营现金流净额同比+38.41%]: 物流成本同比下降，存货周转加快，叠加利润增长，共同驱动经营活动现金流显著改善。
- **[线上渠道深耕即时零售]** -> [线上销售同比增长29.2%]: 融合“家家悦优鲜”及第三方平台，深耕即时零售精细化运营，线上业务保持盈利，成为业绩增长新引擎。
- **[区域深耕与业态创新]** -> [省外地区收入同比增长2.78%]: 聚焦重点城市稳步拓展，创新推出都市小型生活便利店和自营烘焙店，多业态联动增强了区域市场渗透力。
- **[财务费用大幅下降]** -> [财务费用同比-28.31%]: 利息收入增加及租赁利息同比减少，有效降低了财务成本，直接增厚了净利润。
- **[高比例现金分红]** -> [分红总额占净利润95.60%]: 公司2025年拟派发现金红利总额1.92亿元，叠加股份回购，合计分红比例高达145%，彰显回馈股东意愿。

## 风险警告
**核心风险在于可转债到期偿付压力与区域扩张的不确定性。** 公司“家悦转债”将于2026年6月到期，期末余额高达6.45亿元，而一年内到期的非流动负债激增至12.49亿元，短期偿债压力巨大。尽管公司账面货币资金充裕，但若股价持续低迷导致转股不畅，将面临集中兑付风险，对现金流造成重大冲击。

**盈利增长可持续性存疑。** 2025年利润高增长主要依赖存量门店调改和成本管控，而非收入扩张。在消费信心不足、行业竞争加剧的背景下，同店增长能否持续、新业态（如折扣店、零食店）能否快速盈利尚待验证。此外，公司省外扩张仍处投入期，新区域培育成本可能侵蚀整体利润。
