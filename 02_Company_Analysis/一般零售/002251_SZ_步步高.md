# 002251.SZ 深度透视

## 因果逻辑链
- **[“胖东来”调改策略深化]** -> [超市营收增长50.38%]: 学习胖东来模式，系统性重构商品品质、服务与组织，恢复顾客信任，驱动超市业态收入大幅增长。
- **[关闭低效门店，聚焦核心]** -> [销售费用下降17.38%]: 主动关闭6家经营未达预期的门店，集中资源于53家优势门店，显著降低租金、水电等运营成本。
- **[2024年重整完成，确认大额重整收益]** -> [2025年净利润同比暴跌90.69%]: 2024年因重整计划确认28.79亿元非经常性损益，基数极高；2025年该收益大幅减少，导致净利润同比骤降。
- **[经营业绩改善与重整前欠款支付完毕]** -> [经营活动现金流由负转正，达6.5亿元]: 超市调改见效提升收入，叠加2024年支付重整前欠缴社保、税金的基数效应消失，经营性现金流大幅改善。
- **[引入重整投资人，优化治理结构]** -> [组织效率提升，管理费用下降7.66%]: 新董事会与高管团队实施轮值总裁制，组织架构扁平化，后台共享，降低管理与沟通成本。
- **[聚焦湖南市场，双业态协同]** -> [主营业务收入增长40.84%]: 集中资源深耕湖南，发挥超市（高频）与百货（高质）的流量互通与价值共生，提升单店产出。
- **[留债摊销与利息费用增加]** -> [财务费用增长33.52%]: 重整后留债开始摊销，且上年重整期间无需计提利息，导致本期财务费用同比增加。

## 风险警告
公司核心风险在于**扣非净利润持续为负**。尽管营收增长22.71%，但扣非净利润仍亏损1.63亿元，表明主营业务尚未实现真正盈利。盈利主要依赖债务重组收益等非经常性损益，经营造血能力依然脆弱。若调改效果无法持续转化为利润，公司可能再次陷入财务困境。

**品牌信誉修复与组织变革存在不确定性**。公司曾经历破产重整，品牌信誉受损。虽然“胖东来”调改初见成效，但重建消费者信任需要长期投入。同时，新文化理念植入、新团队磨合需要时间，短期内可能影响执行力，导致经营改善不及预期。此外，高达141.58亿元的投资性房地产采用公允价值计量，其价值波动对利润影响巨大，构成潜在风险。
