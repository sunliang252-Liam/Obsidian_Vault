# 002697.SZ 深度透视

## 因果逻辑链
- **[门店结构优化与低效门店清理]** -> [营收下降5.61%]: 公司主动剥离低效尾部门店，放弃无利润贡献的收入，导致销售总额下降，但优化了资产质量。
- **[供应链效率提升与费用管控]** -> [营业利润增长10.75%]: 通过优化供应链全链路运营效率、严控管理成本，销售费用和管理费用同比大幅压降，有效对冲了营收下滑对利润的负面影响。
- **[参股新网银行投资收益增长]** -> [营业利润增长]: 新网银行经营效益良好，带动公司投资收益相应增长，成为利润增长的重要补充。
- **[“商品+服务”差异化竞争策略]** -> [抵御行业竞争]: 通过提供80多项便民服务、联合品牌开发差异化商品，构建了区别于零食折扣店和即时零售的竞争壁垒，维持了客户粘性。
- **[24小时云值守门店推广]** -> [拓宽经营时段与提升坪效]: 以数字化值守替代人工，实现门店24小时营业，填补夜间服务空白，计划2027年全覆盖，是提升单店营收的关键举措。
- **[抖音等社交电商渠道拓展]** -> [线上引流与销售增长]: 抖音平台销售额突破11亿元，“线上销售+线下核销”模式有效带动客流与复购，拓宽了获客渠道。
- **[控股股东变更为四川商投]** -> [治理结构优化与资源协同]: 实际控制人变更为四川省国资委，为公司带来国企资源背书，并在关联交易、战略布局上产生协同效应。

## 风险警告
**核心风险在于营收持续下滑与行业竞争加剧。** 公司2025年营收同比下降5.61%，且扣非净利润连续两年下滑。便利店行业面临零食折扣店分流、即时零售挤压、客流减少三重压力，公司虽通过费用管控维持了利润，但增长动能不足，单店营收下滑趋势尚未扭转。若宏观经济持续低迷，居民消费信心不足，公司营收可能进一步承压。

**运营成本刚性上涨与门店扩张的不确定性。** 商业物业租赁成本、人员工资等费用支出呈上涨趋势，公司虽通过精细化管理压降费用，但空间有限。同时，公司计划向川南地区辐射并加速24小时门店覆盖，新店培育期的成本投入和区域市场的不确定性可能对短期利润造成压力。此外，业绩承诺期（2024-2026年）结束后，公司能否维持当前利润水平存在不确定性。
