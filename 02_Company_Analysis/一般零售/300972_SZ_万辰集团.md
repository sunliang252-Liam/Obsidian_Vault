# 300972.SZ 深度透视

## 因果逻辑链
- **品牌整合统一为“好想来”并纳入“老婆大人”** -> 品牌优势形成，成为首个门店破万家的量贩零食品牌: 通过资源整合和供应链统一，提升了品牌知名度和市场认可度
- **门店数量超1.8万家，全国布局扩张** -> 规模效应显现，采购议价能力增强，费比优化: 门店增加带来集采规模，降低采购成本，摊薄固定费用
- **供应链优化（直采、48个常温仓、T+1配送）** -> 成本降低与效率提升，支撑高质价比和高毛利: 直采减少中间环节，仓储配送网络保障周转速度，减少库存损耗
- **商品力提升（12大品类、近2000SKU、月度上新、自有品牌）** -> 吸引客流，提升客单价和复购率: 丰富SKU和快速上新满足多样化需求，自有品牌提升毛利
- **营销投入（明星代言、节日营销、IP联动）** -> 品牌声量和客流增长: 营销活动扩大品牌曝光，吸引新客进店
- **食用菌行业企稳回暖，主要产品价格回升** -> 食用菌业务营收增长11.81%，扭亏为盈: 价格回升直接提升收入，产能利用率提高带来规模效应
- **食用菌工厂化生产与多品种布局（金针菇/真姬菇/鹿茸菇）** -> 成本优势与抗风险能力: 工厂化生产提高产量和品质稳定性，多品种分散单一产品价格风险
- **消费趋势向“多快好省”迁移** -> 量贩零食业态高速增长，公司营收增长59.98%: 消费者追求高性价比，量贩零食满足需求，市场空间大

## 风险警告
量贩零食业务高度依赖门店扩张速度，若开店不及预期或竞争加剧，可能导致收入增速放缓；同时，公司管理费用同比增长53.44%，需关注费用控制；食用菌业务受价格波动影响较大，且行业回暖能否持续存在不确定性。
