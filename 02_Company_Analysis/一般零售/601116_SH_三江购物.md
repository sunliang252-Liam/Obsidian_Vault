# 601116.SH 深度透视

## 因果逻辑链
- **非经常性损益大幅增加** -> **归母净利润增长31.48%**: 资产处置收益（拆迁补偿）和政府补助合计贡献约9790万元，是净利润增长的核心来源，扣非净利润反而下降11.09%。
- **生鲜品类销售增长8.99%** -> **主营业务收入微增1.14%**: 生鲜作为核心品类，通过源头直采和品质管控实现逆势增长，但被食品、百货等品类下滑所抵消，整体增长乏力。
- **门店网络优化（关11家、开3家）** -> **坪效提升9.61%**: 关闭低效门店、调整商场布局，使单位面积产出效率显著改善，但总门店数净减少8家至183家。
- **员工收入提升（调改门店+10.53%）** -> **销售费用下降5.78%**: 通过组织效率提升和部分折旧到期，在提高员工薪酬的同时，整体费用反而下降，体现“以人为本”转型的初步成效。
- **线上销售增长11.62%** -> **主营业务收入占比提升至17.78%**: 即时零售和线上履约能力提升，成为收入增长的重要驱动力，但线上渗透率仍低于行业平均水平。
- **安鲜冷链集配中心建设投入** -> **在建工程增长492.56%**: 募投项目进入竣工收尾阶段，预计2026年上半年投入运营，是公司未来打造冷链物流新增长极的关键资产。
- **存款利率下降及定期存款减少** -> **财务费用增加58.58%**: 利息收入大幅减少，导致财务费用由负转正，对利润形成拖累。

## 风险警告
**核心风险在于盈利质量严重依赖非经常性损益。** 2025年归母净利润1.87亿元中，非经常性损益高达8508万元（占比45.4%），主要来自拆迁补偿和政府补助。扣非净利润同比下滑11.09%，表明主营业务盈利能力并未改善，反而在竞争加剧中承压。若未来此类一次性收益不可持续，公司真实盈利将大幅缩水。

**行业竞争加剧与转型不确定性构成双重压力。** 即时零售、折扣店、会员店在江浙沪区域快速扩张，持续分流传统商超客流。公司虽提出“以人为本”转型，但门店调改、商品力提升、冷链物流建设等举措尚处早期，效果有待验证。在营收增长停滞、毛利率下滑1.13个百分点的背景下，转型能否成功并转化为可持续的业绩增长，存在较大不确定性。

**公司简介（F10 原文）**

> 三江购物俱乐部股份有限公司是浙江省大型商贸流通企业,中国连锁经营百强企业。公司成立30年来,一直坚守创业以来的公司使命、公司核心价值观,以顾客为中心、为员工谋发展,在满足居民日常生活所需、食品安全、合理膳食、应急保供等方面做出了自己应有的贡献。2020年被国家奖励办公室、中国商业联合会评选为全国商贸流通服务业先进集体。公司董事长、创始人为十三五浙江省商贸行业优秀企业家。公司主要经营社区生鲜超市、盒马鲜生、安鲜生活等三种业态,每天有几十万顾客在公司线上平台和线下门店消费。公司在宁波和杭州各建有一个物流加工配送基地,其中生鲜加工配送中心一座,中央厨房一个,常温物流配送中心二座,一支大型冷链运输车队。2011年公司股票在上交所挂牌上市以来,通过大力吸引优秀人才,主动跟大型电商公司合作,吸收互联网巨头入股,积极探索传统企业在数字时代转型升级。在反复研究、多年准备基础上,公司从2019年开始实施“快速转型,三年升级”新零售1.0门店战略,已按计划基本完成全公司门店从传统的社区平价超市转型升级为新零售1.0的社区生鲜超市。2022年公司开始实施第二个三年发展战略,决心实现“全公司数字化1.0”,通过数字化、智能化,不断提升顾客体验,提高运行效率,降低运行成本,努力成为一家数智时代优秀的商贸流通企业。
