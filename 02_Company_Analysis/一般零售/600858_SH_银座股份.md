# 600858.SH 深度透视

## 因果逻辑链
- **[消费降级与行业竞争加剧]** -> [营收与利润双降]: 消费者趋于理性，线上平台及新兴业态分流客流，导致公司2025年营业收入同比下降2.52%，归母净利润同比下降12.42%。
- **[非经常性损益依赖度高]** -> [扣非净利润大幅下滑45.6%]: 核心盈利能力疲弱，2025年扣非净利润仅6997万元，主要依赖托管费（3340万）和资产处置收益（1425万）等非经常性项目维持盈利。
- **[供应链改革与数智化转型]** -> [经营现金流显著改善]: 通过“去中间化”直采、上线自动补货系统（ROC系统）等措施，优化库存周转与损耗控制，经营活动现金流净额同比大增20.68%至10.12亿元。
- **[高财务杠杆与利息负担]** -> [侵蚀主业利润]: 短期借款高达23.73亿元，财务费用2.53亿元，占营业收入的4.8%，沉重的利息支出是压制净利润的核心因素之一。
- **[百货业态萎缩，超市业态增长]** -> [业态结构分化]: 百货商场收入同比下滑14.14%，而大型综合超市收入同比增长5.70%，显示公司正从传统百货向民生超市业态艰难转型。
- **[关联交易与同业竞争问题]** -> [盈利质量存疑]: 前五大供应商采购额中，关联方采购占比高达31.69%，且公司受托管理大股东旗下58家门店，关联交易规模巨大，影响业绩独立性与透明度。
- **[资产减值与信用减值损失]** -> [资产质量承压]: 报告期确认资产减值损失1433万元、信用减值损失776万元，反映出部分门店经营不善及应收账款回收风险。

## 风险警告
**核心风险在于主业盈利能力羸弱与高财务杠杆的恶性循环。** 公司扣非净利润仅6997万元，而财务费用高达2.53亿元，利息支出是净利润的3.6倍，表明其商业运营产生的现金流几乎全部用于偿还债务，股东回报极度依赖非经常性损益。若未来资产处置收益减少或托管费收入波动，公司将面临实质性亏损风险。

**关联交易与同业竞争是悬在头上的达摩克利斯之剑。** 公司超过30%的采购来自控股股东关联方，且核心利润来源之一的托管费（3340万元）也来自关联方。这种复杂的利益输送格局，不仅使公司业绩独立性存疑，更可能掩盖了其真实的市场竞争力和资产质量。控股股东关于解决同业竞争的承诺长期悬而未决，是公司估值难以提升的根本障碍。
