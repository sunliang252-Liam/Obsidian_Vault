# 600712.SH 深度透视

## 因果逻辑链
- **[消费市场整体承压]** -> [营业收入下降23.66%]: 居民收入增速放缓、就业压力加大，消费行为更趋理性，叠加国家补贴政策调整，导致家电类商品销售明显下滑。
- **[文化宫店租赁合同违约]** -> [计提大额使用权资产减值损失约3805万元]: 承租方南宁嘉芬违约，公司收回物业自营后，因空置面积大且长年亏损，出现减值迹象，导致资产减值损失同比暴增7984%。
- **[部分国有建设用地使用权被政府收回]** -> [确认资产处置收益2358万元]: 钦州地块被收回，公司获得补偿款3940万元，扣除账面价值和税费后形成非经常性收益，掩盖了主业亏损的严重程度。
- **[扣非净利润连续五年为负]** -> [公司持续经营能力存疑]: 2025年扣非净利润-7514万元，自2021年以来持续亏损，表明主营业务造血能力严重不足，依赖非经常性损益维持账面。
- **[家电业态收入占比58.84%但下滑严重]** -> [公司业绩高度依赖单一政策驱动]: 家电业务是收入支柱，但增长严重依赖“国补”政策，政策调整或暂停直接导致收入大幅波动，缺乏内生增长动力。
- **[超市业态关停长期亏损门店]** -> [止住经营出血点但规模萎缩]: 关停邕宁店、天等店等，虽减少了亏损，但导致超市业态收入同比下降34.66%，业务规模持续收缩。
- **[存货同比增加73.13%]** -> [销售下滑导致库存积压]: 营业收入下降而存货大幅增加，反映商品周转效率降低，未来可能面临进一步的跌价风险。

## 风险警告
**核心风险：主业持续失血，依赖“卖地”续命。** 公司扣非净利润已连续五年为负，2025年亏损额扩大至-7514万元。主营业务（百货、家电、超市、汽车）全面下滑，家电业务受政策波动影响巨大，超市业务被迫收缩。公司盈利完全依赖非经常性损益（如土地处置收益），这种“拆东墙补西墙”的模式不可持续，一旦资产处置受阻，公司将面临巨额亏损。

**重大风险：文化宫店资产减值“地雷”已爆，未来仍有隐患。** 文化宫店收回自营后，高达1.24亿元的使用权资产已计提3800万减值。该店空置面积大、长期亏损，未来若经营状况无法根本改善，可能面临进一步的减值风险，持续侵蚀公司利润。同时，公司流动负债高于流动资产1.76亿元，短期偿债压力巨大，流动性风险不容忽视。
