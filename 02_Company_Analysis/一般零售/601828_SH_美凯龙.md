# 601828.SH 深度透视

## 因果逻辑链
- **[投资性房地产公允价值重估]** -> [归母净利润巨亏237.2亿]: 市场租金预期大幅下调，导致公司以公允价值计量的投资性房地产价值暴跌204亿，成为亏损主因。
- **[行业需求下滑与稳商策略]** -> [营业收入下降15.85%]: 地产不景气、家居需求减弱，公司通过减免租金和提供优惠条件稳商留商，直接导致租金及管理收入下滑。
- **[资产减值连锁反应]** -> [资产减值损失增加至30亿]: 投资性房地产价值下降及市场环境恶化，引发对长期股权投资、商誉、其他非流动资产等历史投资的减值计提。
- **[以旧换新政策红利]** -> [经营现金流大幅改善至8.2亿]: 公司深度参与国家以旧换新政策，拉动销售并提升商户信心，经营活动现金流净额同比增长277%。
- **[“人车家”生态跨界融合]** -> [汽车业态经营面积翻倍]: 引入新能源汽车等高频业态，将家居卖场升级为综合生活场域，创造新流量并提升坪效。
- **[数字化与全域流量运营]** -> [线上流量获取6.3亿]: 整合抖音、天猫、小程序等多平台，实现线上引流线下核销，会员消费占比提升至47.7%。
- **[委管商场网络收缩]** -> [委托经营管理收入下降18.4%]: 受经济环境影响，大量委管商场合同到期或提前解约，导致委管商场数量减少，相关收入下滑。

## 风险警告
公司最大的风险在于**投资性房地产公允价值持续下滑的“堰塞湖”效应**。2025年因市场租金预期转变，公司计提了234.4亿的公允价值变动损失，直接导致净资产腰斩。若宏观经济或家居行业景气度未能如期复苏，未来租金预期可能进一步下调，将引发新一轮的资产减值，对净资产和利润造成毁灭性打击。公司采用公允价值计量，与同行成本模式缺乏可比性，加剧了业绩的极端波动性。

其次，**主业造血能力与资产规模严重不匹配**。尽管经营现金流有所改善，但65.8亿的营业收入难以支撑近873亿的总资产规模。公司正通过减免租金维持出租率，这本质上是“以价换量”，若市场持续低迷，租金收入可能进一步承压，而庞大的有息负债和固定成本将导致财务风险持续暴露。同时，原控股股东红星控股已进入破产重整，其相关承诺的履行存在重大不确定性，可能对公司历史遗留问题的解决构成障碍。
