# 688004.SH 深度透视

## 因果逻辑链
- **[宏观经济复苏偏缓]** -> [营收小幅下滑]: 下游客户采购计划推迟，项目交付验收滞后，导致2025年营收同比下降1.05%。
- **[聚焦高毛利产品]** -> [毛利率提升]: 优化产品结构，核心高毛利产品收入占比增加，综合毛利率同比提升3.51个百分点。
- **[强化费用管控]** -> [亏损大幅收窄]: 通过优化研发流程、提升运营效率，期间费用有效管控，归母净利润亏损同比减少41.4%。
- **[加大回款力度]** -> [信用减值损失减少]: 历史应收款项回收成效显著，信用减值损失较上年同期大幅下降，直接改善利润表。
- **[“AI+视听”战略]** -> [产品智能化升级]: 依托“慧视”、“学道”大模型，对传媒安全、智慧教育业务进行AI重构，提升产品竞争力。
- **[研发人员优化]** -> [研发费用下降]: 推进研发流程优化及智能化工具应用，研发效能提升，研发人员数量减少，研发费用同比下降9.61%。
- **[供应商结算账期影响]** -> [经营性现金流大幅下降]: 本期“购买商品、接受劳务支付的现金”显著增加，导致经营活动现金流净额同比减少76.56%。

## 风险警告
公司已连续三年亏损，2025年归母净利润为-2253万元，虽亏损幅度收窄，但盈利能力尚未恢复。核心风险在于下游客户（政府、广电、教育）预算受宏观经济影响持续收紧，导致订单获取和项目验收存在不确定性，营收增长乏力。此外，公司经营活动现金流净额同比大幅下降76.56%至304万元，现金流状况恶化，需警惕其对公司日常运营和研发投入的潜在制约。

公司面临激烈的市场竞争和技术迭代风险。作为技术密集型公司，若不能持续保持技术领先，尤其是在AI大模型应用上的领先优势，可能被竞争对手超越。同时，公司存在人才流失风险，核心技术人员是公司竞争力的关键。此外，公司曾因收入确认和内控问题被北京证监局采取行政监管措施，内部控制的有效性仍需持续关注。
