# 920429.BJ 深度透视

## 因果逻辑链
- **[进口乳清蛋白采购价格大幅上涨]** -> [毛利率骤降6.57个百分点]: 核心原料成本飙升直接侵蚀利润空间，导致营业成本增速(23.47%)远超收入增速(11.40%)。
- **[军需业务应收账款期末集中挂账]** -> [经营性现金流暴跌81.88%]: 军队客户8,991.93万元应收账款因合同条款未在年底回款，导致现金流与净利润严重背离。
- **[固安运动营养生产基地二期建设]** -> [在建工程激增357.19%]: 产能扩张的资本开支大幅增加，导致投资活动现金流净流出扩大至-9,680万元。
- **[聚焦健身乳清蛋白爆品与线上渠道]** -> [蛋白增肌产品收入增长28.42%]: 通过“千人千店”线下计划与抖音、京东等平台深度运营，成功拉动核心品类增长。
- **[军需市场科研项目与成果转化]** -> [健康营养食品收入增长56.02%]: 凭借技术领先性，军需业务实现收入2.1亿元，成为第二大增长引擎。
- **[品牌营销与赛事合作]** -> [销售费用增长7.44%]: 为维持品类第一的市场地位，公司持续投入电商平台推广及450余场马拉松等赛事合作，费用刚性增长。
- **[信用期内应收账款增加]** -> [信用减值损失扩大207.57%]: 军需客户回款周期长于常规客户，导致坏账计提大幅增加，进一步拖累净利润。

## 风险警告
**核心风险在于“增收不增利”的困境加剧。** 公司2025年营收增长11.4%，但归母净利润却暴跌55.85%，扣非净利润更是下降57.34%。根本原因是核心原料乳清蛋白价格持续高位运行，而公司在激烈的市场竞争中未能有效将成本压力传导至终端，导致毛利率从39.41%骤降至32.84%。若原料价格持续高企或公司无法通过产品升级、品牌溢价来消化成本，盈利能力将进一步承压。

**现金流与利润的严重背离是第二大风险。** 经营性现金流净额同比大降81.88%，主要系军需业务应收账款期末集中挂账。虽然该款项已于期后收回，但暴露出公司对单一客户（军队）的依赖度较高（前两大客户合计占比34.58%），且其回款周期具有不确定性。同时，公司正进行大规模产能建设（在建工程增长357%），投资活动现金流出巨大，若未来市场增速放缓或竞争加剧，可能导致产能利用率不足，形成资产减值风险。
