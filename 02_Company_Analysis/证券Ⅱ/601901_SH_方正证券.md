# 601901.SH 深度透视

## 因果逻辑链
- **[市场交易活跃度大幅提升]** -> [经纪业务收入增长38.19%]: 2025年A股日均成交额同比增61.9%，直接驱动公司代理买卖证券业务净收入44.65亿元，同比增长43.95%。
- **[客户资产突破万亿]** -> [财富管理收入增长36.72%]: 客户总数近1700万户，客户资产同比增32.63%，带动代销金融产品收入增长70.94%，两融规模突破545亿元。
- **[出售瑞信证券股权]** -> [投资收益减少54.19%]: 2025年出售瑞信证券49%股权，导致长期股权投资归零，投资收益基数效应显著，但一次性回笼资金8.85亿元。
- **[债券投资策略调整]** -> [公允价值变动收益转正]: 从2024年亏损19.2亿元转为盈利5.98亿元，主要系公司拓展“固收+”及中性策略，平滑债市低位震荡影响。
- **[信用减值损失大幅转回]** -> [净利润弹性放大]: 信用减值损失从2024年计提3.51亿元转为转回0.68亿元，叠加收回抵债资产，直接增厚利润约4.2亿元。
- **[公募基金规模持续增长]** -> [资管业务收入增长307.54%]: 方正富邦基金公募规模年均复合增长超30%至872亿元，驱动资管业务收入从13.4亿元跃升至54.7亿元。
- **[融资成本下降与杠杆提升]** -> [利息净收入增长28.22%]: 利息支出同比减少13.72%，同时两融及债券投资规模扩大，利息收入稳定，净息差改善。

## 风险警告
**核心风险在于对市场交易量的高度依赖与投资收益的不可持续性。** 公司2025年净利润暴增79.85%，主要驱动力是A股日均成交额同比暴增61.9%带来的经纪业务爆发，以及信用减值损失的转回。一旦市场活跃度回落，经纪业务收入将面临巨大压力，而信用减值转回属于一次性因素，无法持续。此外，公司投资收益同比下降54.19%，显示核心自营能力并未同步提升，利润增长质量存疑。

**第二大风险是平安证券同业竞争问题的悬而未决。** 中国平安通过新方正集团间接控股公司，同时控股平安证券，构成实质性同业竞争。尽管平安出具了解决承诺，但至今未有明确方案和时间表。这一不确定性将持续压制公司估值，并可能在未来的整合中带来业务、人员、文化的剧烈变动，对中小股东利益构成潜在威胁。
