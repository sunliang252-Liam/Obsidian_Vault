# 601236.SH 深度透视

## 因果逻辑链
- **[自营投资非方向化转型深化]** -> [业绩大幅增长]: 公司坚持非方向性投资策略，有效抵御市场波动，金融资产公允价值变动收益和投资收益之和同比增加5.66亿元，成为利润增长的核心引擎。
- **[市场交投活跃度提升]** -> [财富管理收入增长]: 2025年A股日均成交额同比增长62%，带动公司证券经纪业务手续费收入增加，财富管理业务收入同比增长70.35%。
- **[投行聚焦优势产品]** -> [手续费收入增加]: 公司聚焦可交换公司债券等优势领域，成功发行多支科技创新及绿色可交债，投资银行业务收入增加，推动手续费及佣金净收入同比增长45.25%。
- **[信用减值损失转回]** -> [营业成本下降]: 股票质押式回购业务风险项目处置收回，以及收回前期已全额计提坏账准备的应收垫付款项，信用减值损失同比减少0.73亿元，降幅228.31%。
- **[高比例现金分红]** -> [股东回报增强]: 2025年度现金分红和回购金额合计占归母净利润的92.84%，积极落实“一年多次分红”号召，切实增强投资者获得感。
- **[其他权益工具投资规模增加]** -> [资产结构变化]: 其他权益工具投资规模增加44.96%，显示公司加大了对非交易性权益资产的配置，以获取长期稳定收益。
- **[应付债券及短期融资款增加]** -> [杠杆水平提升]: 应付债券和短期融资款分别增长25.64%和48.57%，公司通过债务融资扩大业务规模，但扣除代理买卖证券款后资产负债率升至54.18%。

## 风险警告
红塔证券的核心风险在于其业绩高度依赖自营投资业务，尤其是非方向性投资策略的有效性。2025年，自营投资业务收入占营业收入的71.8%，而该业务与资本市场走势高度相关。尽管公司强调“非方向化”，但若市场出现极端波动或策略失效，投资收益和公允价值变动收益可能大幅缩水，直接冲击利润。此外，公司资产负债率有所上升，应付债券和短期融资款规模显著增加，若市场流动性收紧或融资成本上升，将面临一定的流动性压力和利息支出压力。

公司财富管理业务转型尚在初期，买方投顾体系仍在建设，对市场交易量的依赖度较高。同时，子公司红塔红土基金、红正均方等业务规模有限，尚未形成稳定的利润贡献，整体盈利结构仍显单一。若自营投资业务表现不佳，公司缺乏其他强有力的业绩支撑点。此外，公司作为烟草系背景券商，其业务拓展和战略决策可能受到控股股东合和集团的影响，需关注关联交易及公司治理的独立性。
