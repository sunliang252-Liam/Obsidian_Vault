# 601375.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度提升]** -> [财富管理业务收入增长29.59%]: 2025年A股日均成交量和两融余额创历史新高，公司经纪及信用业务直接受益。
- **[两融规模突破百亿]** -> [利息净收入增长68.31%]: 融资融券业务规模扩大，带动利息收入显著增加，成为利润增长的核心引擎。
- **[权益市场指数型上涨]** -> [自营业务扭亏为盈]: 公司把握科技成长主线，优化权益投资组合，公允价值变动损失大幅收窄，实现正收益。
- **[“三投联动”战略深化]** -> [服务河南实体经济融资117.53亿元]: 投行、投资、投研协同，通过并购重组大会、债券发行等服务区域经济，强化“河南资本市场战略性载体”定位。
- **[信用减值损失大幅增加]** -> [侵蚀利润]: 存量风险项目处置及价值变化导致信用减值损失同比增307.66%，对净利润形成拖累。
- **[投行业务收入锐减]** -> [拖累整体业绩]: 受监管周期及项目储备不足影响，证券承销业务收入同比下滑56.85%，成为主要减分项。
- **[计提预计负债]** -> [营业外支出激增]: 因合同纠纷计提预计负债4645万元，导致营业外支出同比增809.58%，非经常性损益为负。

## 风险警告
**核心风险在于信用风险敞口与减值损失的持续性。** 报告期内信用减值损失激增307.66%，主要源于应收账款及债权投资减值准备增加，叠加存量风险项目处置进展不及预期。这反映出公司在股票质押、融资融券等信用业务上的资产质量承压，若市场环境转弱或个别大额风险项目恶化，减值损失可能继续侵蚀利润，成为业绩最大不确定性。

**业务结构脆弱性显著。** 公司业绩高度依赖市场行情驱动的经纪、两融和自营业务，而投行、资管等轻资产、抗周期业务能力薄弱（投行收入同比降56.85%）。这种“靠天吃饭”的盈利模式导致业绩波动剧烈，一旦市场活跃度回落，利润将面临大幅回撤风险。同时，境外业务持续亏损，子公司中州国际净利润为-0.72亿元，成为集团业绩的拖累。
