# 600030.SH 深度透视

## 因果逻辑链
- **[市场活跃度提升]** -> [经纪与财富管理收入增长25.55%]: 2025年A股日均成交量和成交额同比显著提升，带动证券及期货经纪业务、代销金融产品等收入增加。
- **[IPO与再融资规模扩张]** -> [投行业务收入增长50.12%]: A股股权融资发行规模同比大增245.42%，公司作为市场第一的承销商，承销收入随之大幅提升。
- **[自营投资策略优化]** -> [证券投资业务收入增长14.83%]: 公司通过多资产配置与多策略迭代，在权益、固收及衍生品市场取得较好收益，公允价值变动收益由负转正。
- **[资管规模与费率提升]** -> [资产管理业务收入增长24.59%]: 私募资管业务市场份额行业第一，集合与单一资管计划规模及管理费收入双增，驱动整体收入增长。
- **[国际化战略深化]** -> [境外业务收入贡献创新高]: 香港市场IPO保荐规模第二、中资离岸债承销规模第一，东南亚、欧洲等市场布局见效，境外收入同比增长41.75%。
- **[信用减值损失增加]** -> [侵蚀部分利润]: 买入返售金融资产及融出资金计提信用减值损失8.37亿元，同比由负转正，对利润形成一定拖累。
- **[汇兑损失扩大]** -> [非主营业务拖累]: 汇率变动及汇率衍生工具产生损失15.69亿元，同比由正转负，对整体业绩产生负面影响。

## 风险警告
**核心风险在于市场与信用双重暴露。** 公司业绩高度依赖中国及全球资本市场活跃度与走势。2025年业绩创历史新高，主要受益于A股和港股的显著上涨及交易量放大。一旦市场情绪逆转、流动性收紧或宏观经济出现超预期下行，经纪、投行、自营等核心业务收入将面临同步下滑的风险，业绩波动性极大。

**信用风险正在显性化。** 报告期内信用减值损失由负转正，达到8.37亿元，主要来自买入返售金融资产（股票质押）和融出资金（融资融券）。尽管当前维持担保比例和履约保障比例较高，但在经济弱复苏、部分行业深度调整的背景下，若客户违约风险集中暴露，将直接冲击公司利润表。此外，公司庞大的债券投资组合（境内超3100亿、境外超1200亿）也面临信用利差走阔或违约风险。
