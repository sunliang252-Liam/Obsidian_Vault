# 600109.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度提升]** -> [财富管理收入增长33.56%]: 2025年A股日均股基交易量同比大增，带动公司经纪、两融及金融产品代销收入全面增长。
- **[债券承销规模扩张]** -> [投行业务收入增长11.78%]: 公司债主承销金额1,074亿元（+4.63%），叠加银行间债务融资工具业务首次开展，驱动投行收入逆势增长。
- **[自营投资规模扩大]** -> [投资收益增长29.71%]: 交易性金融资产规模同比增61.45%至389亿元，权益与固收投资均把握市场机会，实现稳健收益。
- **[北交所做市业务领先]** -> [做市业务竞争力提升]: 北交所做市股票数量排名第1，科创板做市排名第7，做市业务成为差异化竞争优势。
- **[资管业务结构优化]** -> [资产管理收入增长35.43%]: 国金资管“多资产管理专家”定位深化，资产支持证券发行规模同比增86.7%，公募基金规模突破879亿元。
- **[境外业务突破]** -> [国际化收入增长]: 国金香港完成2个港股IPO及36单中资境外债，资管规模同比增36.9%，境外业务成为新增长极。
- **[客户资产与交易额增长]** -> [信用业务收入提升]: 客户资产总额增38.22%，两融余额增7.71%至326.49亿元，融资融券利息收入增17.52%。

## 风险警告
**核心风险在于市场依赖与杠杆扩张。** 公司业绩高度依赖A股市场活跃度，2025年营收增长26.9%主要受益于日均万亿成交额，若市场转冷，财富管理、自营投资及信用业务收入将同步承压。同时，公司主动加杠杆扩张资产负债表，总负债增31.31%至1,131亿元，资产负债率升至64.98%，交易性金融资产与卖出回购金融资产款均大幅增长，流动性覆盖率从401.75%降至286.45%，财务弹性有所削弱。

**信用风险与监管合规压力不容忽视。** 公司股票质押式回购业务规模94.88亿元，虽维持担保比率较高，但若市场大幅下跌，信用减值风险可能暴露。此外，投行业务在IPO审核趋严背景下，保荐项目质量与合规风险持续存在，2025年虽未受处罚，但需警惕监管政策变化对项目储备及收入确认的影响。
