# 601211.SH 深度透视

## 因果逻辑链
- **[吸收合并海通证券]** -> [资产规模与业绩创历史新高]: 完成中国资本市场史上最大规模A+H吸收合并，期末总资产超2.1万亿、归母净利278亿，均跃居行业首位，初步实现“1+1>2”。
- **[负商誉计入营业外收入]** -> [归母净利润大幅增长113.52%]: 非同一控制下企业合并产生负商誉88.27亿元，计入营业外收入，成为当期利润暴增的核心非经常性因素。
- **[市场交投活跃度大幅提升]** -> [经纪业务收入行业第一]: 沪深两市股基日均交易额同比增长71.1%，公司股基交易市场份额8.56%，经纪业务手续费净收入151.38亿元，同比增93.01%。
- **[客需驱动的FICC与衍生品业务转型]** -> [投资收益增长但公允价值变动亏损]: 投资收益同比增105.07%至267亿元，但衍生金融工具公允价值变动导致整体公允价值变动损益为-1.43亿元，显示客需业务规模扩大伴随对冲成本。
- **[融资租赁业务并表]** -> [利息净收入与信用减值损失同步激增]: 吸收合并海通证券新增融资租赁业务，利息净收入同比增251.2%至82.78亿元，同时信用减值损失同比增1445.5%至38.63亿元。
- **[“All in AI”战略与系统整合]** -> [客户迁移与数智化转型行业领先]: 完成超2000万客户迁移，发布全AI智能APP“灵犀”2.0，行业首家获批大模型面客服务，核心交易体系承载近4000万客户。
- **[“投资+投行+投研”联动深化]** -> [IPO与再融资承销领先]: IPO主承销19家、在审44家均行业第一，再融资主承销金额1291.53亿元，市场份额大幅提升至16.40%。

## 风险警告
**整合风险与信用减值压力是最大隐忧。** 吸收合并海通证券虽带来规模跃升，但整合涉及超700项制度更新、上百套IT系统切换及超2000万客户迁移，管理复杂度与运营风险极高。同时，合并后信用减值损失激增14倍至38.63亿元，主要来自新增的融资租赁业务及合并会计准则下的计提，若宏观经济下行或租赁资产质量恶化，减值压力将持续侵蚀利润。

**市场依赖性与非经常性损益的可持续性存疑。** 公司业绩高度依赖2025年市场交投活跃度（股基交易额同比增71%）及合并产生的88.27亿元负商誉。若市场活跃度回落，经纪、两融及投资收益将同步承压。扣除负商誉后，扣非归母净利润为213.88亿元，同比仅增71.93%，显示核心盈利增长仍受市场周期与整合成本制约。
