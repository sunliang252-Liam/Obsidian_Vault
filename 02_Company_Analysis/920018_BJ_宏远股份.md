# 920018.BJ 深度透视

## 因果逻辑链
- **行业需求增长** -> 营业收入同比增长30.41%: 下游电力行业清洁转型、电网投资增长带动变压器需求，进而拉动电磁线产品销量增加。
- **原材料铜价上涨** -> 营业收入同比增长30.41%: 铜价上涨导致产品销售价格相应提升，推动收入增长。
- **营业收入增长** -> 净利润同比增长5.74%: 收入增长带动利润增加，但毛利率下降（7.15%→7.97%）及费用增长（销售费用增68.23%、研发费用增25.18%、财务费用增314.11%）削弱了利润弹性。
- **营业收入增长** -> 应收账款同比增长48.82%: 销售规模扩大，且四季度收入占比高，导致期末未回款增加。
- **营业收入增长** -> 经营活动现金流净额同比减少99.01%: 收入增长导致采购原材料现金支出增加，同时应收账款增加使得回款滞后，经营现金流大幅下降。
- **市场需求旺盛** -> 合同负债同比暴涨10,797.17%: 下游需求强劲，客户预付款增加。
- **套期保值规模扩大** -> 交易性金融资产同比增长171,404.86%: 为对冲铜价上涨风险，公司增加期货持仓，期末浮动盈利增加。
- **IPO募集资金到位** -> 货币资金同比增长68.77%: 公开发行股票募集资金及保证金增加。
- **IPO募集资金到位** -> 资本公积同比增长172.31%: 发行股票产生股本溢价。
- **原材料价格波动风险** -> 公司开展期货套期保值业务: 为管理铜价波动对成本的影响，公司通过期货进行套期保值。

## 风险警告
尽管营收增长30%，但净利润增速仅5.74%，毛利率下降（7.97%→7.15%），销售费用（+68.23%）、研发费用（+25.18%）及财务费用（+314.11%）大幅侵蚀利润。经营性现金流接近零（28万元），应收账款（+48.82%）和存货（+18.69%）占压资金，现金流紧张。客户集中度高（前五大客户67.6%），且原材料铜价上涨风险通过期货对冲但可能带来衍生品风险。IPO后总资产增长65%，但固定资产仅增12%，资金大量以货币资金（32.63%）和存货（19.92%）形式存在，资产利用效率待提升。
