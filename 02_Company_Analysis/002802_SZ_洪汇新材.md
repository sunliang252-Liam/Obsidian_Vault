# 002802.SZ 深度透视

## 因果逻辑链
- **[原材料价格波动与下游需求疲软]** -> [营收与利润双降]: 主要原材料VCM、VAc价格下行，叠加国内外市场需求偏弱，导致产品售价承压，公司2025年营收同比下降13.64%，归母净利润同比下降30.45%。
- **[水性乳液（树脂）业务大幅萎缩]** -> [业绩下滑核心拖累]: 作为重点发展方向的水性乳液产品营收同比骤降37.68%，毛利率下降8.40个百分点，未能形成新的增长点，反而成为业绩主要拖累。
- **[控股股东变更为地方国资]** -> [战略与治理结构重塑]: 2025年6月，锡山区国资通过协议受让成为控股股东，公司实际控制人变更，旨在整合当地新材料产业，并借助国资平台资源进行后续资本运作。
- **[原实控人项洪伟业绩承诺压力巨大]** -> [未来补偿风险高悬]: 项洪伟承诺2025-2027年累计扣非净利润不低于1.3125亿元，但2025年仅完成承诺额的28.30%，若后续两年无法大幅改善，将触发现金补偿义务。
- **[技改项目推进缓慢]** -> [产能升级与市场拓展受限]: 年产6万吨水性涂料基料及10万吨氯醋树脂技改项目虽已通过安全审查，但环评等关键审批仍在推进中，项目进度滞后，限制了公司产品结构优化和规模扩张。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 尽管利润下滑，但公司经营活动现金流净额同比大增215.78%至8588万元，主要得益于销售回款增加，表明公司现金流管理能力增强，盈利质量优于账面利润。
- **[研发投入缩减]** -> [长期竞争力隐忧]: 研发费用同比下降35.01%，研发人员数量减少16%，在行业向水性化、高端化转型的关键期，研发投入的缩减可能影响公司未来新产品储备和技术领先优势。

## 风险警告
**业绩承诺与经营基本面严重背离的风险。** 原实控人项洪伟承诺2025-2027年累计扣非净利润不低于1.3125亿元，但2025年仅实现3714万元，完成率仅28.30%。在核心产品水性乳液营收大幅下滑、下游需求未见明显复苏的背景下，未来两年需实现近9500万元净利润才能避免补偿，压力极大。若业绩持续不达预期，不仅将触发大额现金补偿，更会严重打击市场信心。

**战略转型与经营能力的双重不确定性。** 公司新控股股东为地方国资，虽带来资源整合预期，但管理层已全面更迭，新团队的战略执行力和业务整合能力尚待验证。同时，公司核心增长引擎“水性乳液”业务遭遇滑铁卢，而作为未来关键的技改项目推进缓慢，短期内难以贡献增量。在行业竞争加剧、环保政策趋严的背景下，公司能否在国资赋能下扭转颓势，存在重大不确定性。
