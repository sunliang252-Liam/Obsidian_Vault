# 601777.SH 深度透视

## 因果逻辑链
- **[“AI+车”战略转型与生态构建]** -> [营收增长42%，净利润增长111%]: 公司从传统制造向“AI+车”转型，引入印奇团队、整合吉利/奔驰等产业资源，带动汽车销量增长，实现营收99.99亿元，归母净利润0.84亿元。
- **[科技业务高研发投入]** -> [扣非净利润亏损2.55亿元]: 为布局智能驾驶、智能座舱、Robotaxi，研发费用同比翻倍至9.85亿元（占营收9.85%），叠加资产减值损失增加，导致扣非后深度亏损。
- **[政府补助与资产处置]** -> [非经常性损益贡献3.4亿元利润]: 计入当期损益的政府补助3.99亿元及资产处置收益0.53亿元，是公司实现账面盈利的核心支撑，掩盖了主业盈利能力薄弱的事实。
- **[关联交易依赖]** -> [前五大客户/供应商关联交易占比高]: 前五大客户销售额中关联方占29.26%，前五大供应商采购额中关联方占30.76%，业务独立性存疑，利润空间受制于关联方。
- **[乘用车销量结构变化]** -> [燃油车销量暴增118.5%，新能源车仅增37%]: 燃油车销量7.27万辆，新能源车3.36万辆，燃油车仍是收入主力，新能源转型速度慢于行业平均。
- **[科技业务并表]** -> [总资产暴增36%，无形资产激增287%]: 合并千里智驾带来无形资产（非专利技术）大幅增加，但该子公司净利润为-1.63亿元，短期内拖累整体盈利。
- **[现金流改善]** -> [经营现金流净额增长306%至21.35亿元]: 收入增长、回款增加及利用存单质押开票支付货款，使经营性现金流大幅改善，但部分源于票据贴现等融资手段。

## 风险警告
**核心风险：战略转型的“烧钱”黑洞与盈利能力的根本性脱节。** 公司以“AI+车”为名，研发费用飙升至9.85亿元，但科技业务（智能驾驶）收入仅3.5亿元，且子公司千里智驾亏损1.63亿元。扣非净利润连续三年为负（-2.55亿元），账面盈利完全依赖政府补助（3.99亿元）和资产处置等非经常性损益。这种“增收不增利、主业靠补贴”的模式不可持续，一旦补贴退坡或关联交易条件变化，公司将面临巨大的业绩变脸风险。

**关联交易依赖与治理风险。** 公司前五大客户/供应商中关联方占比均超30%，与吉利体系深度绑定。这种“左手倒右手”的业务模式，使其利润的真实性和独立性存疑。同时，母公司累计未弥补亏损高达-9.48亿元，连续三年不进行分红，中小股东利益被严重忽视。此外，高达95.22亿元的资产受限（占总资产32%），财务弹性极低，一旦资金链紧张，风险将迅速暴露。
