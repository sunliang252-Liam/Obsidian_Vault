# 300055.SZ 深度透视

## 因果逻辑链
- **[危固废行业深度调整]** -> [固废业务营收同比-15.24%，毛利率-17.20%]: 行业量价齐跌，叠加固定成本高企，亏损幅度扩大。
- **[乌兰察布委托贷款及政府欠款]** -> [计提信用减值损失1.90亿元]: 基于谨慎性原则，对地方财政依赖的应收款项进行大额减值，直接侵蚀利润。
- **[广东伊斯科揭阳项目投产]** -> [石油化工营收同比+1.20%，但毛利率仅+3.62%]: 新产能释放带来收入增量，但行业低景气与原料价格波动压制盈利空间。
- **[化工行业整体低景气]** -> [核心产品（间戊二烯、双环戊二烯、碳五树脂）价格承压下行]: 下游需求疲软与产能过剩导致产品价格下跌，影响整体盈利。
- **[应收账款规模居高不下]** -> [经营活动现金流净额-1.20亿元，同比-178.80%]: 回款困难导致现金流恶化，与净利润严重背离。
- **[公司战略转型至化工新材料]** -> [石油化工收入占比升至86.95%]: 业务重心从环保服务转向重资产化工，对资金需求和管理能力提出更高要求。
- **[TPE生态革技术产业化]** -> [与奇瑞合作建厂，形成新增长点]: 新材料业务从研发走向量产，开辟汽车内饰等高端市场，但短期贡献有限。

## 风险警告
万邦达的核心风险在于**资产质量恶化与现金流断裂的恶性循环**。公司因乌兰察布地区大额应收款项计提1.9亿减值，直接导致全年巨亏2.55亿。这并非一次性事件，而是地方财政风险向上市公司传导的持续威胁。若回款无实质进展，未来仍需计提减值，将持续侵蚀净资产，并加剧本已紧张的现金流（经营现金流为-1.2亿），严重制约新业务投入与债务偿还能力。

其次，**化工新材料业务面临“增收不增利”的困境**。尽管广东伊斯科项目投产带来收入增长，但行业整体产能过剩、竞争激烈，核心产品价格承压，导致毛利率改善有限。公司重资产转型后，折旧与财务费用高企，若下游需求持续疲软，新产能无法满负荷运行，将面临巨大的资产减值与盈利压力。环保业务（危固废）的持续萎缩，进一步削弱了公司的业绩安全垫。
