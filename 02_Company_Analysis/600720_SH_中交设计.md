# 600720.SH 深度透视

## 因果逻辑链
- **[基建行业周期性下行与地方财政收紧]** -> [营收与利润双降]: 行业投资放缓、项目回款周期拉长，导致公司2025年营收同比下降11.05%，归母净利润同比下降16.91%。
- **[主动剥离低毛利工程总承包业务]** -> [营收结构优化，毛利率提升]: 收缩低附加值EPC业务，聚焦高毛利的勘察设计核心主业，使主营业务毛利率提升至30%，勘察设计毛利率达33.37%。
- **[业绩承诺期最后一年，六院超额完成]** -> [消除市场对资产质量的疑虑]: 2023-2025年累计实现扣非归母净利润48.76亿元，全面完成业绩承诺，验证了注入资产的盈利能力和管理层执行力。
- **[研发投入强度持续加大至4.45%]** -> [构筑新兴业务技术壁垒]: 重点投向低空经济、AI设计、深地空间、交能融合等前沿领域，为“第二增长曲线”储备核心技术。
- **[“设计出海”战略深化]** -> [海外业务逆势增长]: 海外营收同比增长4.52%至7.65亿元，占比提升至7%，在东南亚、中东、非洲等区域实现新突破，对冲国内下行风险。
- **[经营性现金流大幅转正]** -> [经营质量实质性改善]: 经营活动现金流净额从-3.06亿元大幅转正至3.53亿元，主要得益于政府化债政策下的销售回款加速和成本管控强化。
- **[前瞻布局低空经济与数字智慧]** -> [抢占未来万亿级市场先机]: 已形成低空经济规划、AI大模型应用、智慧水务等解决方案，并在9个地市开展低空业务，成为交通运输部低空无人机试点唯一技术支撑单位。

## 风险警告
**核心风险在于传统基建市场的长期萎缩与公司转型成效的不确定性。** 公司营收与利润双降，直接反映了国内基建投资达峰、行业“僧多粥少”的残酷现实。尽管公司通过剥离低效EPC业务、提升毛利率来优化报表，但这本质上是“做减法”，而非创造增量。若宏观经济持续疲软，地方政府财政压力不减，公司核心的勘察设计业务（占营收77%）仍面临量价齐跌的风险，2026年业绩能否企稳存疑。

**第二增长曲线的培育尚需时日，且面临激烈竞争。** 公司布局的低空经济、AI、新能源等新兴业务，虽然方向正确，但目前仍处于投入期和示范阶段，尚未形成规模化收入贡献。这些领域已是巨头和初创企业竞相涌入的红海，公司作为传统设计院，在市场化竞争、技术迭代速度和商业模式创新上能否突围，存在较大不确定性。此外，海外业务虽增长，但地缘政治风险、汇率波动及项目合规风险不容忽视，可能侵蚀来之不易的海外利润。
