# 688787.SH 深度透视

## 因果逻辑链
- **[全球AI产业从“技术突破”迈向“规模化落地”]** -> [营收增长59%]: 多模态大模型、智能体、垂类应用爆发，带动训练数据需求激增。
- **[定制化服务收入占比提升]** -> [毛利率下降18.38个百分点]: 高毛利的标准化产品收入占比被压缩，低毛利的定制服务成为收入主力，成本增速（+146%）远超收入增速（+59%）。
- **[海外业务扩张与东南亚交付基地成熟]** -> [境外收入增长38.68%]: 东南亚基地打开海外定制化服务市场，但前期运营资金投入导致经营性现金流大幅下降93.83%。
- **[政府与国央企入局共建AI生态]** -> [境内业务收入增长77.72%]: 公司参与国家级数据标注基地建设，为地方政府和运营商提供高质量数据集及AI解决方案，开辟新增长极。
- **[视觉大模型与文生视频模型突破]** -> [计算机视觉业务收入增长217.66%]: 高精度、场景化视觉数据及视频关联文本处理需求爆发，成为公司增长最快的业务板块。
- **[大模型从“规模驱动”转向“推理驱动”]** -> [CoT（思维链）数据成为新增长点]: DeepSeek R1验证了CoT技术的有效性，公司需构建专家标注体系以抓住大模型下一阶段竞争的关键。
- **[数据安全法规密集落地]** -> [合规能力成为核心竞争壁垒]: 公司拥有的ISO27001、ISO27701等认证及参与国家标准制定，使其在客户选择中具备差异化优势。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 营收增长59%的背后，是毛利率从66.46%骤降至48.08%，营业成本增速（146.12%）远超收入增速。这主要因为高毛利的标准化产品收入占比下降，而低毛利的定制化服务成为增长主力。同时，为支撑海外扩张，经营性现金流净额暴跌93.83%至仅177万元，资金链紧绷。若定制化业务持续挤压标准化产品空间，公司盈利能力将面临持续压力。

**另一重大风险是客户集中度与业务依赖。** 前五大客户贡献了46.20%的营收，且收入高度依赖老客户（占比78.62%）。公司业务发展与下游AI行业景气度高度绑定，若主要客户（如客户1，占比18.99%）削减采购或AI行业进入调整期，将对公司业绩造成剧烈冲击。此外，新业务（如具身智能、AI Agent数据）尚处早期，能否快速规模化并弥补传统业务增速放缓的风险，存在较大不确定性。
