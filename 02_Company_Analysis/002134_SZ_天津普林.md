# 002134.SZ 深度透视

## 因果逻辑链
- **[珠海新工厂投产，产能释放]** -> [营收增长22.20%]: 华南基地珠海新工厂A线投产，新增产能直接推动收入规模扩大。
- **[铜价等大宗商品价格上涨]** -> [毛利率下降2.27%]: 上游原材料成本系统性抬升，直接侵蚀产品利润空间，导致毛利率承压。
- **[珠海B线建设，固定成本增加]** -> [净利润暴跌85.93%]: 新工厂B线处于建设期，尚未贡献收入，但折旧、人工等固定费用已开始计入，严重拖累当期利润。
- **[托管高瀚电路业务失败]** -> [产生795.31万元亏损]: 拓展高端特种快板业务的尝试未达预期，托管协议解除，确认大额亏损，直接减少当期净利润。
- **[销售回款增加]** -> [经营现金流净额增长241.56%]: 公司加强应收账款管理，销售商品收到的现金大幅增加，现金流状况显著改善。
- **[贷款利息支出增加]** -> [财务费用增长65.42%]: 为支持珠海新工厂建设，公司增加长期借款，导致利息支出大幅上升。
- **[珠海工厂研发投入增加]** -> [研发费用增长42.39%]: 为配合新产线技术适配与产品升级，研发投入显著加大，短期增加费用压力。

## 风险警告
公司面临的核心风险是**“增收不增利”的剪刀差困境**。营收增长22.20%的背后，是净利润暴跌85.93%的残酷现实。利润被上游原材料涨价、新工厂建设期的固定成本以及一次性的托管失败亏损三重挤压。这种“量增利减”的局面若持续，将严重侵蚀股东回报，并考验公司对成本与产能爬坡节奏的管控能力。

另一个重大风险是**商誉减值与高杠杆运营**。公司账面商誉高达1.31亿元，全部来自对泰和电路的并购。若未来宏观经济或下游需求不及预期，导致泰和电路经营恶化，将面临巨额商誉减值风险。同时，公司总负债率高达65.9%，长期借款从4.33亿激增至5.99亿，财务费用同比大增65.42%，高杠杆下的利息负担正在成为利润的沉重枷锁。
