# 002457.SZ 深度透视

## 因果逻辑链
- **[水利投资高位回落]** -> [营收下滑6.84%]: 2025年水利投资1.28万亿同比降5%，公司订单驱动型业务直接承压。
- **[新签合同金额锐减]** -> [未来收入增长乏力]: 管道业务新签合同23.4亿元，同比减少27.68%，在手订单结转至23.6亿元，同比减少17.49%。
- **[信用减值损失扩大]** -> [净利润腰斩51.58%]: 信用减值损失3866万元，同比增9.3%，侵蚀利润，是净利润降幅远超营收降幅的主因。
- **[经营活动现金流暴增]** -> [回款能力显著改善]: 经营性现金流净额5.65亿元，同比增346.72%，主因是加强应收账款催收，销售回款大幅增加。
- **[原材料成本上升]** -> [毛利率承压]: 非金属矿物制品业毛利率29.31%，同比下降4.27个百分点，主因原材料、人工及制造费用成本上升。
- **[设计咨询业务萎缩]** -> [拖累整体业绩]: 设计咨询收入3.1亿元，同比降28.29%，是营收下滑的重要拖累项。
- **[华南地区收入翻倍]** -> [区域拓展见效]: 华南地区收入3.54亿元，同比增119.34%，显示公司跨区域市场开拓取得突破。

## 风险警告
**核心风险：业绩增长失速与订单质量恶化。** 公司2025年净利润同比腰斩，核心驱动因素——新签合同金额大幅下滑27.68%，预示着未来1-2年收入增长动力不足。同时，公司主动“把控订单质量”，对合同资金来源和付款条件严格审查，虽有利于长期健康，但短期会进一步压制订单规模，形成“量价双杀”的局面。

**重大风险：高额应收账款与信用减值风险。** 公司应收账款高达14.3亿元，占总资产30.52%，且信用减值损失高达3866万元，是利润的最大侵蚀项。尽管现金流改善，但庞大的应收账款基数意味着坏账风险始终高悬。若下游水利项目资金到位不及预期，减值损失可能进一步扩大，对利润造成持续冲击。
