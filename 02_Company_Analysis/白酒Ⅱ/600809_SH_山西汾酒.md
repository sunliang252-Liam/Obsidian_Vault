# 600809.SH 深度透视

## 因果逻辑链
- **[全国化扩张]** -> [省外收入增长12.64%]: 长江以南核心市场显著增长，省外收入占比提升至65.30%，成为营收增长主引擎。
- **[品牌矩阵巩固]** -> [青花20、玻汾百亿级产品地位夯实]: 高端与大众价位带双轮驱动，稳固“一体两翼”品牌根基，支撑汾酒产品收入增长7.72%。
- **[高分红政策]** -> [2025年拟每10股派65.60元，分红率65.35%]: 高额现金分红回馈股东，强化价值投资逻辑，但亦反映资本开支高峰下现金流压力。
- **[产能扩张投入]** -> [在建工程增长42.20%]: 2030技改项目、汾青基地项目稳步实施，为未来原酒产能与储能提升奠定基础，但短期推高资本开支。
- **[经营现金流恶化]** -> [经营活动现金流净额下降25.95%]: 销售回款减少叠加税费、采购支出增加，现金流与净利润背离，需关注渠道库存与回款节奏。
- **[成本结构变化]** -> [毛利率下降1.35个百分点]: 原料成本上升20.88%，制造费用增长28.58%，成本端压力侵蚀盈利空间，省外市场毛利率降幅更大。
- **[年轻化与国际化]** -> [“侏罗纪”概念汾酒获认可，海外体验中心建成]: 布局未来增量市场，但短期对业绩贡献有限，需长期培育。

## 风险警告
**核心风险：增长失速与现金流恶化。** 2025年营收增速仅7.52%，净利润增速近乎停滞（+0.03%），远低于历史水平。更关键的是，经营活动现金流净额同比大幅下降25.95%，与净利润严重背离，表明销售回款放缓或渠道库存积压。在行业“马太效应”加剧的存量竞争下，公司若无法有效拓展市场、加速回款，将面临增长瓶颈与流动性压力。

**次要风险：成本侵蚀与竞争加剧。** 原料成本与制造费用双升导致毛利率下滑，尤其是省外市场毛利率降幅更大，显示全国化扩张伴随更高的成本代价。同时，白酒行业竞争白热化，名优酒企纷纷加码，公司需持续投入巨额销售费用（+10.07%）以维持品牌声量，若费用投入产出效率下降，将直接拖累利润。此外，2030技改等重大项目投资额巨大，若未来产能消化不及预期，将形成资产减值风险。
