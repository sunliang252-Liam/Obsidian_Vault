# 920422.BJ 深度透视

## 因果逻辑链
- **[优化产品结构，提升高毛利钙盐占比]** -> [净利润逆势增长22.74%]: 在营收下降4.33%的背景下，公司主动调整产品结构，增加毛利率达19.71%的钙盐产品销售，带动整体毛利率从10.14%提升至12.31%，实现扣非净利润增长39.52%。
- **[境外销售占比66.17%，人民币汇率波动]** -> [财务费用大幅增加57.91%]: 公司外销收入占比高，2025年人民币汇率变动导致汇兑收益减少，财务费用从-464万元升至-195万元，对利润形成侵蚀。
- **[行业产能过剩，市场竞争加剧]** -> [钠盐产品价格下跌，营收下降16.48%]: 受国内外经济下行及行业产能增加影响，公司钠盐类产品内外贸市场价格均出现下跌，导致该品类收入显著下滑。
- **[主要原材料价格波动]** -> [存货增加27.11%，计提减值风险]: 公司为应对成本波动进行备货，期末存货增至6708万元，同时因产品价格下跌，对固定资产计提减值437万元，资产减值损失同比增加21.64%。
- **[供应商集中度高]** -> [经营依赖性强，议价能力受限]: 前五大供应商采购额占比高达56.94%，公司对主要原材料供应商存在依赖，若供应商经营变动，短期内将影响原材料供应稳定性和成本控制。
- **[研发投入聚焦降本增效]** -> [成本控制能力提升，毛利率改善]: 公司持续进行丙酸钙绿色合成、山梨酸钾烘干工艺等研发，旨在降低能耗和生产成本，这是毛利率提升的重要内因。
- **[员工持股计划绑定核心团队]** -> [管理层与股东利益一致]: 公司通过汇贤企管实施员工持股，覆盖董事、高管及核心员工，有助于稳定团队，激励管理层聚焦长期价值创造。

## 风险警告
**核心风险在于行业竞争加剧与成本波动双重挤压下的盈利脆弱性。** 公司营收连续两年下滑（-4.33%），钠盐产品价格持续下跌，显示行业产能过剩问题严峻。虽然通过产品结构优化实现了净利润增长，但钙盐产品能否持续维持高毛利并扩大份额存在不确定性。一旦原材料价格（丙酸、丁烯醛等）大幅上涨，或主要产品价格继续下行，公司微薄的利润空间将被迅速吞噬。

**财务风险信号值得警惕。** 公司资产负债率从14.45%升至19.15%，短期借款激增9900%，应付票据增加52.49%，显示公司运营资金压力加大，更多依赖债务融资。同时，境外收入占比高（66.17%），汇率波动对财务费用的影响显著，2025年汇兑收益减少已导致财务费用大幅增加。此外，存货和应收账款合计占总资产23%，若下游客户回款放缓或产品跌价，减值风险不容忽视。
