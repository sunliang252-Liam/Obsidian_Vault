# 600812.SH 深度透视

## 因果逻辑链
- **[降本增效与费用管控]** -> [净利润同比增长44.15%]: 通过扩大集采、战略采购降低采购成本1.19亿元，推行精益管理降低期间费用，财务费用同比减少7970万元，驱动利润显著增长。
- **[国采中选品种增量增收]** -> [稳定收入基本盘]: 积极抓好国采中选品种的协议采购量超额完成，注射用美罗培南等10个产品销量实现两位数增长，对冲了整体收入下滑6.36%的压力。
- **[生物药板块高毛利护盘]** -> [贡献核心利润]: 生物制剂业务毛利率高达81.39%，其中乙肝疫苗稳居全国销量首位，金坦公司净利润4.65亿元，成为公司最稳定的利润来源。
- **[研发投入资本化率高]** -> [平滑当期利润，积累未来资产]: 研发投入9.77亿元，资本化比例高达65.09%，大量研发支出未计入当期损益，减轻了利润压力，同时增加了开发支出（19.87亿元）等无形资产储备。
- **[医药中间体量升价跌]** -> [拖累整体收入与毛利率]: 医药中间体收入同比下降37.55%，主要因售价和直接采购成本大幅下降，尽管销量略有增长，但严重拖累了公司整体营收表现。
- **[物流贸易业务扩张]** -> [补充收入但利润微薄]: 医药及其他物流贸易收入同比增长39.08%，但毛利率仅为2.40%，属于低利润率的规模扩张，对整体盈利贡献有限。

## 风险警告
**核心风险在于高负债与低盈利能力的结构性矛盾。** 公司资产负债率高达67.81%，短期借款62.42亿元，一年内到期的非流动负债高达29.72亿元，短期偿债压力巨大。尽管2025年利润改善，但扣非后净资产收益率仅为3.04%，盈利能力远不足以覆盖如此高的财务杠杆，财务费用（3.46亿元）仍是侵蚀利润的主要因素。公司依赖融资（发行债券）和关联方财务公司贷款维持流动性，一旦融资环境收紧，将面临严峻的现金流危机。

**另一重大风险是历史遗留问题的潜在冲击。** 公司为石家庄焦化集团提供的9000万元担保已逾期，虽声称风险较小，但法律义务并未解除。同时，公司账面仍有高达12.79亿元的搬迁停工损失（其他应收款），其回收完全依赖于政府土地收储出让进度，存在极大的时间不确定性和减值风险。此外，公司历史上曾因关联交易违规受罚，治理层面的合规风险仍需警惕。
