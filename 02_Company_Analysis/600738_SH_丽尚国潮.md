# 600738.SH 深度透视

## 因果逻辑链
- **战略性剥离亏损子公司** -> **归母净利润同比+126%**: 通过解除对丽尚美链等亏损子公司的控制权，将其移出合并报表，直接消除了亏损业务对利润的拖累。
- **专业市场预收租金增加及新零售回款改善** -> **经营现金流净额同比+136%**: 核心业务（专业市场）的预收模式带来稳定现金流入，同时新零售业务收回前期货款，共同推动现金流大幅改善。
- **亚欧国际城际酒店开业** -> **商业及酒店管理业务收入同比+20%**: 与华住集团合作的高端酒店投入运营，直接贡献了新的收入增长点，并提升了该板块毛利率。
- **亚欧商厦联营模式转租赁** -> **商贸百货零售业务收入同比+5.15%**: 经营模式调整，从联营转向租赁，提高了收入确认的稳定性和毛利率（+6.78个百分点）。
- **实施员工持股计划确认股份支付费用** -> **管理费用同比+5.12%**: 为建立长效激励机制，公司启动员工持股计划，导致当期管理费用增加，但旨在绑定核心团队利益。
- **偿还银行借款及合并范围减少** -> **财务费用同比-34%**: 主动降低有息负债规模，叠加亏损子公司出表，利息支出显著减少，财务结构优化。
- **控股股东持续增持** -> **市场信心与股价支撑**: 元明控股在报告期内及期后多次增持，并获专项贷款支持，向市场传递了对公司长期价值的信心。

## 风险警告
**核心风险在于增长的真实性与可持续性。** 2025年净利润暴增126%，主要驱动力是“做减法”——剥离亏损子公司和减少减值损失，而非主营业务的强劲内生增长。公司营业收入同比下滑4.84%，专业市场管理收入微降0.19%，核心业务增长乏力。若未来无法通过投资并购或新业务孵化找到新的增长点，利润增长将难以为继。

**公司治理与战略执行风险不容忽视。** 报告期内，公司因控股股东越权参与日常经营被证监局责令整改，暴露出公司治理独立性存在缺陷。同时，向特定对象发行股票因股东大会未通过而终止，显示控股股东与部分董事、中小股东之间存在战略分歧。此外，副总经理鄢克亚曾有被证监会处罚的记录，管理层稳定性与合规性存疑。这些因素都可能影响公司未来战略的顺利推进。
