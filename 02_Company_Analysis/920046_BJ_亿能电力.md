# 920046.BJ 深度透视

## 因果逻辑链
- **[核心产品变压器收入增长21.85%]** -> [营收增长16.55%]: 变压器作为营收主力（占比65.62%），其增长直接拉动整体收入规模扩大。
- **[应收账款激增38.83%至2.0亿]** -> [信用减值损失暴增417.68%]: 营收增长伴随回款周期拉长，导致坏账计提大幅增加，侵蚀利润。
- **[存货飙升96.62%至7321万]** -> [经营活动现金流净额由正转负至-6231万]: 以销定产模式下，备货规模急剧扩张，大量现金沉淀在存货，造成现金流严重失血。
- **[短期借款翻倍至7556万]** -> [财务费用增长67.99%]: 为应对营运资金缺口，公司大幅增加银行借款，利息支出显著上升。
- **[新建厂房投入3231万]** -> [在建工程暴增260%]: 公司处于产能扩张期，资本开支大幅增加，但尚未转化为实际产能和收入。
- **[新增境外销售802万]** -> [打开第二增长曲线]: 产品首次直销马来西亚，标志着公司成功突破海外市场，分散单一国内市场风险。
- **[合同负债暴增353%至2092万]** -> [预示未来收入增长]: 预收货款大幅增加，表明在手订单充足，为后续营收提供较强保障。
- **[毛利率下降1.52个百分点至25.30%]** -> [盈利能力承压]: 原材料成本上升及产品结构变化导致毛利率下滑，叠加费用增长，净利润增速（5.38%）远低于营收增速。

## 风险警告
**核心风险在于“增收不增利”与“现金流枯竭”的双重困境。** 公司营收增长16.55%，但净利润仅微增5.38%，主因是应收账款和存货的急剧膨胀。应收账款占资产总额的43.70%，且坏账计提同比暴增417.68%，若下游客户（如国网、铁路系统）付款进一步延迟，将直接导致巨额坏账，严重冲击利润表。同时，经营活动现金流净额由正转负，流出高达6231万元，公司不得不依赖短期借款（同比+120%）来维持运营，财务费用随之飙升，形成了“借钱-囤货-等回款”的恶性循环。

**产能扩张的节奏与市场需求匹配度存在不确定性。** 公司在建工程同比暴增260%，主要用于新建厂房，表明管理层对未来市场持乐观态度。然而，当前存货已高企，若下游需求增速放缓或竞争加剧导致订单不及预期，新增产能将面临闲置风险，进一步加剧资产减值压力。此外，公司实际控制人持股比例高达60%，治理结构虽合规，但决策集中度较高，需警惕战略误判风险。
