# 000728.SZ 深度透视

## 因果逻辑链
- **[市场交投活跃]** -> [财富信用业务收入增长36.64%]: 2025年A股日均成交额同比增64.44%，带动代理买卖手续费、融资融券利息收入大幅提升。
- **[自营权益投资扩张]** -> [其他权益工具投资暴增175.80%]: 公司新增低波红利证券投资，权益类投资规模从55.76亿增至99.65亿元，但固收类投资收缩16.27%。
- **[债券投资规模收缩]** -> [自营业务收入同比下降8.33%]: 交易性债券结转投资收益减少，公允价值变动收益由正转负（-1.16亿元），拖累整体自营业绩。
- **[衍生品业务爆发]** -> [衍生金融工具投资收益增长380.40%]: 场外衍生品名义本金同比增232.88%，收益互换、期权等业务贡献显著增量。
- **[客户保证金大幅流入]** -> [经营活动现金流净额暴增207.41%]: 客户交易结算资金净流入增加，叠加债券投资规模收缩，共同推动经营现金流创历史新高。
- **[投行转型承压]** -> [投行业务亏损6,958万元]: IPO、再融资项目数量有限，保荐收入下降82.28%，投行仍在向科创产业投行转型的阵痛期。
- **[国元创新利润暴增]** -> [另类投资子公司净利润增长1176.85%]: 新增投资20.12亿元，股权投资、PIPE及金融产品投资协同发力，成为集团利润新增长极。
- **[国元期货利润腰斩]** -> [期货子公司净利润下降54.52%]: 行业竞争加剧、市场波动及收入结构变化，导致期货业务阶段性承压。

## 风险警告
**核心风险在于业绩对市场行情的强依赖性与业务结构的不均衡。** 财富信用业务收入占比从28.99%跃升至37.08%，经纪与两融收入与A股成交额高度正相关。一旦市场转弱，成交量萎缩，公司将面临收入大幅回撤的风险。同时，自营业务中权益类投资规模激增78.73%，市场下行将直接冲击利润表，公允价值变动损益的波动性显著放大。

**投行业务持续亏损与资管业务增长乏力构成第二重隐忧。** 投行全年亏损近7000万元，保荐收入同比骤降82%，在IPO审核趋严、行业集中度提升的背景下，公司作为区域券商在项目储备和承销能力上存在短板。资管业务收入同比下降2.78%，主动管理转型尚未形成有效突破，在行业马太效应加剧的格局中，公司面临被头部机构挤压市场份额的长期压力。
