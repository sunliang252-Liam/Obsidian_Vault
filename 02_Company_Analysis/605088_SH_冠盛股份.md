# 605088.SH 深度透视

## 因果逻辑链
- **[北美大客户突破]** -> [营收增长10.67%]: 成功开拓北美关键客户，轮毂轴承与转角模块进入供应体系，带动传动轴总成等传统品类稳健增长。
- **[海外后市场经销模式]** -> [毛利率稳定在24.89%]: 以经销模式为主（占收入98.4%），通过GSP品牌溢价和一站式采购服务，有效抵御原材料成本上涨压力。
- **[全球仓网与本土化运营]** -> [海外收入占比超90%]: 在德、美、墨等国建立本土团队与仓储，实现快速配送，缩短与终端用户距离，降低中间费用。
- **[柔性生产与多品种小批量]** -> [客户粘性高]: 较低的起订量和快速交付能力，降低客户库存与采购门槛，提升客户满意度和经营效率。
- **[固液混合电池与机器人关节臂]** -> [第二增长曲线布局]: 冠盛东驰电池厂封顶、设备进厂；极艾斯聚焦等速万向节式智能仿生关节臂，前瞻布局新能源与机器人赛道。
- **[可转债转股与股权激励]** -> [股本扩张与费用摊薄]: 冠盛转债触发强赎并全部转股，总股本增加20.7百万股；股权激励费用导致归母净利润同比微降0.93%。
- **[供应链结算方式优化]** -> [经营性现金流大幅改善]: 采用信用证结算比例提升，优化供应商现金流管理，经营活动现金流净额同比大增99.91%至6.28亿元。

## 风险警告
**核心风险在于新业务（电池、机器人）的产业化不确定性。** 固液混合电池量产线尚未正式下线，产能释放与订单落地存在较大不确定性；机器人关节臂产品无订单且未产生营收，距离量产“还有很长一段距离”。这两项业务目前处于纯投入阶段，2025年冠盛东驰亏损2387万元，若后续产业化不及预期，将持续侵蚀主业利润，并可能引发市场对“第二增长曲线”的估值泡沫担忧。

**另一重大风险是海外宏观环境与汇率波动。** 公司出口收入占比超90%，主要结算货币为美元。2025年财务费用因汇兑收益减少而暴增1870%，若人民币短期内大幅升值，将直接产生大额汇兑损失。同时，全球关税战（如美国加征关税）和贸易政策变化，可能冲击公司产品在主要进口国的竞争力，导致业绩下滑。此外，OEM智能工厂建设项目因前装市场开发缓慢，投入进度仅17.15%，存在停滞或终止风险。
