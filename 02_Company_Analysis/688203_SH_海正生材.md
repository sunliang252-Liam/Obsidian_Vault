# 688203.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [归母净利润暴跌72.21%]: 聚乳酸行业产能快速释放，需求增速不匹配，产品售价持续下探，压缩毛利率，导致利润大幅下滑。
- **[3D打印行业爆发]** -> [境内销量增长14.40%]: 公司紧抓FDM 3D打印耗材需求高速增长机遇，与头部企业深化合作，3D打印领域销量同比增幅约88.60%，成为核心增长引擎。
- **[美国“对等关税”冲击]** -> [境外营收下降24.75%]: 国际贸易政策导致部分境外订单丢失，境外业务毛利率仅0.36%，严重拖累整体业绩。
- **[募投项目转固]** -> [管理费用增加21.86%]: 子公司海创达年产15万吨聚乳酸一期项目部分转固，新增折旧费用，直接侵蚀当期利润。
- **[利息及汇兑收益减少]** -> [财务费用由负转正]: 报告期内利息收入和汇兑收益同比减少，导致财务费用从-666.86万元增至251.08万元，进一步压缩盈利空间。
- **[“限塑禁塑”政策执行不及预期]** -> [传统应用领域增长缓慢]: 政策推动力减弱，聚乳酸在传统一次性餐具、塑料袋等领域的市场拓展受阻，需求萎缩。
- **[高光纯乳酸供应商集中]** -> [原材料供应与成本风险]: 公司主要原材料高光纯乳酸供应商集中，若供应紧张或价格上涨，将直接影响生产成本和产能释放。

## 风险警告
**核心风险是“增收不增利”的持续恶化。** 公司2025年营收微增0.77%，但归母净利润却暴跌72.21%至986.53万元，扣非净利润更是下降79.22%。根本原因在于行业产能过剩引发的价格战，以及新项目投产带来的折旧压力。若2026年聚乳酸价格继续低位运行，而公司年产7.5万吨新项目正式投产后折旧、摊销等固定成本进一步增加，公司极有可能陷入亏损。

**第二重风险来自外部环境的双重挤压。** 一方面，美国“对等关税”等贸易政策导致境外业务几乎无利可图（境外毛利率仅0.36%），且订单丢失风险持续；另一方面，国内“限塑禁塑”政策执行力度不及预期，传统需求增长乏力。公司过度依赖3D打印这一单一增长引擎，若该领域需求增速放缓或竞争加剧，公司将面临业绩断崖式下滑的风险。
