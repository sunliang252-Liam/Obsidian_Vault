# 300787.SZ 深度透视

## 因果逻辑链
- **[新能源业务爆发]** -> [营收结构优化]: 新能源收入同比+277.58%，占比从2.89%跃升至7.42%，成为第二增长曲线。
- **[消费电子复苏+欧盟接口强制替换]** -> [营收高增47.30%]: 核心业务受益于AI终端换机潮与Type-C统一接口政策，信号线束/适配器需求激增。
- **[全球化制造布局]** -> [外销主导+产能弹性]: 越南、江西、东莞三地产能协同，外销占比82.80%，有效分散关税风险并贴近客户。
- **[研发投入维持高位]** -> [技术壁垒巩固]: 研发费用2.02亿（占营收6.21%），量产雷电5、GaN 300W等前沿产品，锁定高端客户。
- **[原材料成本上涨]** -> [毛利率承压]: 消费电子毛利率同比下降6.62pct，铜材、芯片等大宗商品涨价未能完全传导至终端。
- **[规模效应显现]** -> [净利润增速低于营收]: 营收+47.30%，但归母净利润仅+23.47%，主因成本上升、费用扩张及资产减值损失（-4126万）。
- **[财务费用激增]** -> [汇兑损益波动]: 财务费用同比+360.72%，人民币汇率波动对以外销为主的盈利模式造成显著冲击。

## 风险警告
**1. 增收不增利的盈利质量风险。** 营收增长47.30%，但扣非净利润仅微增0.68%，毛利率下滑5.72个百分点。核心矛盾在于原材料成本（铜、芯片）上涨无法完全转嫁，叠加新能源业务尚处放量初期、毛利率虽高但体量小，难以对冲消费电子利润率的侵蚀。若原材料价格持续高位，公司盈利弹性将远低于营收弹性。

**2. 高杠杆与现金流压力。** 资产负债率升至60.43%，短期借款激增6.69个百分点至14.85%，且货币资金中受限资金（保证金）占比高达35.3%。经营活动现金流净额1.12亿，远低于净利润，主要因存货（+46.3%）和应收账款占款增加。若下游客户回款放缓或融资环境收紧，公司偿债与资本开支（越南海阳项目持续投入）将面临双重压力。
