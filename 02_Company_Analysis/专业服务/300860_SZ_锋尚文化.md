# 300860.SZ 深度透视

## 因果逻辑链
- **[大型文化演艺项目周期波动]** -> [营收与利润大幅下滑]: 2025年国家级重大项目（如亚冬会）集中交付后，新项目尚处执行期，完工项目数量锐减，导致营收同比下降58.77%，净利润由盈转亏。
- **[文旅演艺业务向C端运营转型]** -> [短期收入承压，长期模式重塑]: 公司从B端项目制向C端常态化运营（如《如梦大同》《湘湖·雅韵》）转型，项目确认周期拉长，且新项目尚处投入期，导致文旅演艺收入同比下降59.49%。
- **[金融资产投资收益依赖]** -> [扣非净利润深度亏损]: 2025年扣非净利润为-5336万元，而金融资产（理财、股票）贡献4432万元收益，掩盖了主营业务的真实亏损状况，盈利质量堪忧。
- **[在手订单结构变化]** -> [未来收入确定性增强]: 截至2025年末在手订单3.25亿元，其中文旅演艺订单占比86%（2.79亿元），表明公司业务重心已明确转向文旅运营，但订单转化为收入仍需时间。
- **[文化出海战略突破]** -> [打开第二增长曲线]: 2026年Q1成功落地沙特“西班牙超级杯”盛典，标志着公司正式进入中东高端文体市场，有望复制国内大型活动经验，开辟海外增量空间。
- **[研发投入占比提升]** -> [技术壁垒构建]: 研发费用占营收比例从5.71%升至12.67%，聚焦AI、VR/AR、无人机编队等技术，旨在提升内容生产效率与沉浸式体验，巩固“文化+科技”护城河。
- **[客户集中度极高]** -> [经营风险高度集中]: 前两大客户（亚冬会组委会、如梦大同）贡献了67.87%的营收，单一项目依赖度极高，一旦核心客户项目延期或终止，将对公司业绩造成毁灭性打击。

## 风险警告
**核心风险在于主营业务造血能力严重不足，盈利高度依赖非经常性损益。** 2025年扣非净利润亏损5336万元，而金融资产投资收益高达4432万元，这意味着剔除理财收益后，公司核心的创意设计及制作业务已陷入深度亏损。这种“理财养主业”的模式不可持续，一旦金融市场波动或理财收益下降，公司将面临巨大的业绩压力。同时，营收同比下降58.77%，经营性现金流净流出3047万元，显示公司已进入业务收缩与现金消耗期。

**另一重大风险是客户集中度过高与项目制业务的不稳定性。** 前两大客户贡献近七成营收，且业务高度依赖大型活动（如亚冬会）的周期性交付。这种“三年不开张，开张吃三年”的模式导致业绩剧烈波动。虽然公司正积极向C端文旅运营转型，但新业务尚处投入期，盈利模式尚未成熟，短期内难以弥补大型活动业务的缺口。此外，应收账款余额高达1.73亿元，若回款不畅，将进一步加剧现金流紧张局面。
