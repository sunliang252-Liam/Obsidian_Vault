# 601866.SH 深度透视

## 因果逻辑链
- **[集装箱制造营收下滑]** -> [整体营收下降8.78%]: 全球贸易格局调整导致新箱价格下行，尽管销量稳定，但营收规模缩减。
- **[金融资产公允价值上升]** -> [利润总额逆势增长17.37%]: 资本市场波动带来公允价值变动收益3.67亿元，对冲了主业营收下滑对利润的冲击。
- **[集装箱租赁业务扩张]** -> [营收增长6.02%]: 主动布局南美、东南亚等新兴市场，箱队规模突破410万TEU，出租量同比上升。
- **[融资租赁船队规模缩减]** -> [航运租赁营收下降10.19%]: 融资租赁船舶到期或处置，导致该板块收入减少，但经营性租赁资产保持稳定。
- **[绿色低碳转型投入]** -> [构建长期竞争壁垒]: 投资建造甲醇/氨预留散货船、LNG船等绿色船舶，发行绿色债券，抢占航运业绿色转型先机。
- **[关联交易依赖]** -> [业绩稳定性受集团影响]: 前五大客户销售额中关联方占比35.04%，与中远海运集团的协同是优势，但也构成业绩依赖风险。
- **[高负债率运营]** -> [财务费用高企]: 净负债率高达263.52%，2025年财务费用35.34亿元，高杠杆运营侵蚀利润，对利率变动敏感。

## 风险警告
**核心风险在于高杠杆与主业周期性的双重压力。** 公司净负债率超260%，财务费用高达35亿元，对利率和汇率波动极为敏感。同时，集装箱制造业务营收下滑6.46%，显示其核心主业正面临全球贸易格局调整带来的周期性压力，利润增长严重依赖非经常性的金融资产公允价值变动，可持续性存疑。

**另一重大风险是对关联方的高度依赖。** 公司前五大客户中关联方销售占比超过35%，与中远海运集团的协同虽带来业务稳定性，但也削弱了其独立面对市场波动的能力。一旦集团战略或关联交易政策发生变化，将对公司营收和利润产生重大冲击。
