# 002064.SZ 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [营收与净利润双降]: 2025年化工行业景气度低位，氨纶、己二酸等主要产品价格承压，导致公司营收同比下降10.15%，净利润同比下降16.32%。
- **[全球第一的规模优势]** -> [成本控制与市场份额]: 公司氨纶、聚氨酯原液、己二酸产量均为全球第一，规模效应显著，能有效降低单位固定成本，提升对上游议价能力，巩固行业龙头地位。
- **[重庆基地的成本红利]** -> [相对盈利韧性]: 重庆涪陵生产基地在能源、人工、运输成本上具备显著优势，在行业普遍亏损的压力下，公司仍能维持正向盈利，体现成本护城河。
- **[产业链一体化布局]** -> [抗周期波动能力]: 公司形成“己二酸-聚酯多元醇-氨纶/聚氨酯原液”的垂直一体化体系，重要原料自给，有效缓解外购原料价格波动对生产经营的冲击。
- **[下游需求结构性增长]** -> [销量逆势提升]: 尽管产品价格下跌，但氨纶、聚氨酯原液、己二酸的销量分别同比增长7.65%、11.12%、1.73%，显示下游应用领域（如纺织、鞋材）需求仍在扩张。
- **[研发投入聚焦高端化]** -> [差异化产品溢价]: 公司持续投入研发（2.64%营收占比），开发耐光老化氨纶、生物基氨纶、高物性聚氨酯等高端产品，旨在提升产品附加值，避开低端价格战。
- **[募投项目延期与缩减]** -> [资本开支审慎]: 基于行业供过于求现状，公司将30万吨氨纶项目缩减至25万吨并延期至2026年底，避免大额固定资产投资占用资金，保证现金流安全。

## 风险警告
**核心风险在于行业供需失衡的持续恶化。** 2025年氨纶产能增速高达13.1%，处于近五年高位，而需求增速仅9.6%，导致产品价差被持续压缩，多数企业亏损。公司虽凭借规模与成本优势维持盈利，但基础化工产品（己二酸）毛利率已骤降至3.92%，同比下滑6.89个百分点，显示核心利润来源正被侵蚀。若下游需求复苏不及预期或新增产能继续释放，公司盈利空间将进一步收窄。

**第二大风险是原材料价格波动与宏观经济不确定性。** 公司主要原料纯苯、PTMG、MDI均为大宗化学品，价格受国际油价及供需影响巨大。2025年纯苯采购价已下跌17.31%，若未来原材料价格大幅上涨而产品价格无法同步传导，将直接冲击利润。同时，全球经济增速放缓、地缘政治及贸易摩擦等宏观风险，可能抑制下游纺织、鞋材等终端消费，导致公司“量价齐跌”的局面加剧。

> 华峰化学股份有限公司成立于1999年12月,是华峰集团控股子公司。公司始终专注于氨纶纤维、聚氨酯原液和精己二酸等产品的研发、生产与销售,是全球聚氨酯制品材料行业龙头企业,拥有韩国、土耳其等境外子公司,在国内建有浙江和重庆两个生产基地。公司涉足金融银行、热电联产和对外贸易等产业领域多元化发展。2006年,公司成功实现A股上市(股票代码002064),成为温州首家国内上市民营企业和全国首家主营氨纶业务上市公司。公司“千禧”牌氨纶产品实现10D-2500D规格全品类覆盖,可满足机织、经编和纬编等不同用户需求,生产规模居全球前列、国内第一;“聚峰”牌聚氨酯原液系列产品是行业知名品牌产品,该系列产品被广泛应用于制鞋、汽车、建筑和军工等领域;“华峰”牌精己二酸主要用于生产聚氨酯原液系列产品、聚酰胺尼龙66系列产品和TPU产品等,广泛应用于工业和医药业。    公司自成立以来,坚持走“创新发展、科学发展”之路,大胆突破传统民营企业发展模式,不断推进技术创新和管理创新,坚持清洁生产和节能减排,承诺并践行责任关怀。公司荣获“全国纺织行业质量奖”、“全国制造业单项冠军产品(氨纶、精己二酸)”、“全国制造业单项冠军示范企业(华峰新材料)”和国家级“绿色工厂”等荣誉,连续三次获得“中国工业行业履行社会责任五星级企业”荣誉,是全国首批“资源节约型和环境友好型”试点企业。
