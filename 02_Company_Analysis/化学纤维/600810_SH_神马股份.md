# 600810.SH 深度透视

## 因果逻辑链
- **[行业产能过剩与价格战]** -> [归母净利润亏损2.17亿元]: 国内尼龙66总产能超150万吨/年，但消费量仅约80万吨，供需严重失衡导致产品价格持续下行，公司毛利率全面下滑。
- **[原材料己二腈供应集中]** -> [成本控制与盈利承压]: 全球仅英威达等少数公司对外出售己二腈，公司虽自建5万吨/年项目，但短期内采购依赖度高，价格波动直接侵蚀利润。
- **[在建工程转固不及时]** -> [财务数据失真与内控缺陷]: 公司存在未及时转固少提折旧、将不符合资本化条件支出计入在建工程的情况，导致2024年及2025年财务数据被追溯更正，内控审计报告被出具带强调事项段的无保留意见。
- **[关联交易频繁且信披违规]** -> [监管处罚与治理风险]: 公司未按规定及时履行关联交易审议程序和信息披露义务，被河南证监局出具警示函，暴露出公司治理与内控流程的薄弱环节。
- **[新产能投放与折旧增加]** -> [短期盈利压力加大]: 尼龙6切片二期、氢氨项目等在建工程陆续转固，导致固定资产折旧同比大幅增加（如尼龙化工折旧增43.66%），在收入下滑时进一步拖累利润。
- **[海外布局与全球化战略]** -> [对冲国内竞争与贸易壁垒]: 泰国2万吨差异化纤维项目试生产、宁东项目开工，旨在规避贸易摩擦、开拓国际市场，但短期贡献有限，且面临海外运营风险。
- **[研发投入聚焦高端化]** -> [长期竞争力构建]: 成功研发11克旦超高强尼龙66工业丝（国际先进水平），布局高温尼龙6T、生物基尼龙等，旨在从“规模竞争”转向“技术制高点”，但商业化落地尚需时日。

## 风险警告
**核心风险在于行业供需格局的持续恶化与公司自身治理缺陷的叠加。** 国内尼龙66产能严重过剩（利用率低于60%），价格战已导致公司2025年由盈转亏，且短期内看不到供需反转的迹象。更严重的是，公司内控存在重大漏洞：在建工程转固不及时、关联交易信披违规，已被监管警示并导致财务数据追溯更正，这严重损害了财务信息的可信度，并可能引发后续的监管处罚或投资者诉讼。

**财务风险同样不容忽视。** 公司总负债规模庞大，担保总额占净资产比例高达55.98%，且存在控股股东关联方非经营性资金占用（虽已归还，但暴露出资金管理风险）。同时，公司2025年不进行分红，且经营活动现金流净额虽大幅改善（+408.88%），但主要得益于销售回款和税费返还，而非核心盈利能力的提升。在行业寒冬中，高负债、弱内控、低盈利的“三杀”局面，使公司面临严峻的生存考验。
