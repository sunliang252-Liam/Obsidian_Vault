# 000782.SZ 深度透视

## 因果逻辑链
- **[行业供需失衡，价格深度下跌]** -> [营收与毛利率双降]: 锦纶6切片及纤维市场产能集中释放，下游需求疲软，产品售价下跌，导致公司2025年营收同比下降24.48%，切片与锦纶丝毛利率分别仅为3.37%和0.33%。
- **[原材料己内酰胺价格波动]** -> [成本控制压力与库存贬值]: 己内酰胺价格震荡下行，公司虽通过采购端协同降本，但产品售价跌幅更大，且导致存货跌价准备增加，资产减值损失达7,089.91万元。
- **[资产减值与公允价值变动]** -> [加剧经营亏损]: 对子公司常德美华等计提固定资产及长期股权投资减值准备，叠加银行股权和投资性房地产公允价值下调，合计对利润总额产生约1.13亿元的负面影响。
- **[出口量增长对冲内需疲软]** -> [境外收入占比提升]: 公司加大切片出口力度，全年切片出口量同比增加27%，境外收入占比从18.69%提升至22.98%，部分缓解了国内市场竞争压力。
- **[在建项目大规模投入]** -> [投资活动现金流大幅流出]: “高性能聚酰胺差异化纤维智能制造项目”投资额不超过29亿元，2025年进入建设高峰期，导致投资活动现金净流出8.23亿元，同比由正转负。
- **[管理费用与财务费用下降]** -> [运营效率改善]: 通过精细化管理，管理费用同比下降15.72%，财务费用同比下降26.45%，但降本幅度不足以扭转主营业务的亏损局面。

## 风险警告
公司当前面临的核心风险是行业性供需失衡导致的持续亏损。锦纶6切片及民用丝市场产能集中释放，表观消费量增速显著放缓，产品加工费被大幅压缩，公司核心产品毛利率已降至极低水平（切片3.37%，锦纶丝0.33%）。若下游需求持续疲软或新增产能进一步释放，公司主营业务盈利能力可能继续恶化，净资产将持续被侵蚀。

此外，公司正处于大规模资本开支周期，“高性能聚酰胺差异化纤维智能制造项目”投资额高达29亿元，已导致2025年投资活动现金流大幅净流出8.23亿元。该项目能否按计划投产并实现高端化转型目标，存在较大不确定性。同时，公司机器设备整体成新率较低，现有产能面临老化风险，而新项目达产前，公司需同时承担旧设备维护与新项目折旧的双重成本压力。
