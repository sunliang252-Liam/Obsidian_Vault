# 300876.SZ 深度透视

## 因果逻辑链
- **[新产能投产但产销率不饱和]** -> [单位固定成本上升]: 新产能落地后，因下游需求疲软和市场竞争，产销率仅65.07%，导致固定成本无法摊薄，毛利率下滑。
- **[碳纤维项目大规模投入]** -> [费用高企]: 广东、甘肃两大碳纤维项目同时推进，投入大量资金、人力、管理资源，叠加可转债利息摊销，财务费用显著增加。
- **[商誉减值]** -> [净利润进一步承压]: 非同一控制下企业合并形成的商誉，经评估后计提减值，直接侵蚀当期利润。
- **[原材料聚丙烯价格波动]** -> [成本控制风险]: 聚丙烯占采购总额85.95%，价格受原油影响波动大，公司缺乏定价权，若无法及时传导成本，将压缩利润空间。
- **[丙纶行业龙头地位]** -> [市场份额稳定]: 连续7年国内丙纶长丝产量、市占率第一，品牌效应和客户积累形成护城河，支撑营收逆势增长5.08%。
- **[差别化产品研发]** -> [高附加值溢价]: 持续开发细旦、抗菌、阻燃等差别化纤维，提升产品附加值，部分对冲常规产品价格竞争压力。
- **[境外市场拓展]** -> [收入多元化]: 境外收入占比13.18%，通过参展和客户开发，在海外市场实现稳定增长，降低单一市场依赖。

## 风险警告
**核心风险：新产能爬坡与碳纤维项目双重失血。** 公司丙纶主业新产能利用率仅65%，单位固定成本高企，短期内难以扭亏。同时，碳纤维项目投资巨大（报告期投入3.08亿元），尚处于建设期，未来技术迭代、市场消化及资金回笼均存在重大不确定性，将持续消耗公司现金流和利润。

**次要风险：原材料价格波动与行业竞争加剧。** 聚丙烯价格波动直接影响成本，公司缺乏定价权。丙纶行业“大行业、小企业”格局下，常规产品价格竞争激烈，若公司无法持续通过差别化产品维持溢价，市场份额和盈利能力将面临双重挤压。
