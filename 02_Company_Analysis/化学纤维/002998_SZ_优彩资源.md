# 002998.SZ 深度透视

## 因果逻辑链
- **[低熔点涤纶短纤维销量激增]** -> [营收增长15.39%]: 低熔点纤维销量29.07%的增长，叠加产能利用率高达103.36%，是收入增长的核心引擎。
- **[低熔点纤维毛利率下滑]** -> [净利润暴跌37.86%]: 尽管收入增长，但低熔点纤维毛利率下降2.56个百分点，叠加财务费用因可转债利息飙升738.84%，严重侵蚀利润。
- **[可转债利息费用化]** -> [财务费用暴增739%]: 2025年可转债利息费用大幅增加，是导致净利润与营收严重背离的关键财务因素。
- **[库存大幅下降]** -> [经营现金流由负转正]: 存货减少5.51个百分点，推动经营活动现金流净额从-1.15亿大幅转正至2.57亿，改善现金状况。
- **[境外业务高速增长]** -> [营收结构优化]: 境外收入同比增长53.66%，占比提升至28.09%，有效对冲了境内市场的增速放缓。
- **[废旧PET回收技术优势]** -> [成本控制能力]: 掌握泡料均质、除杂、增粘核心技术，提高低成本泡料使用比例，在原材料价格波动中维持竞争力。
- **[研发投入持续增加]** -> [产品多元化]: 研发费用增长13.17%，推动氨纶涤纶混纺隔音板纤维、超细旦低熔点长丝等新产品研发，为未来增长蓄力。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司营收增长15.39%，但归母净利润却暴跌37.86%，扣非净利润降幅更大达41.42%。主要原因是低熔点纤维毛利率下滑及可转债利息费用化导致财务费用激增739%。若原材料价格持续上涨或下游需求转弱，公司盈利能力可能进一步承压。

**另一个重大风险是募投项目进展缓慢且效益未达预期。** “年产8万吨功能性复合型特种纤维技改项目”已延期，且报告期内累计实现效益为负（-162.25万元）。“废旧纺织品综合利用8万吨/年（二期）项目”同样延期，截至期末投资进度仅0.17%。这两个核心募投项目若不能尽快投产并贡献利润，将严重影响公司未来成长性和估值逻辑。
