# 000683.SZ 深度透视

## 因果逻辑链
- **[纯碱、小苏打价格下跌]** -> [营收与利润双降]: 主导产品纯碱、小苏打市场均价同比下滑，导致碱业板块营收下降11.42%，毛利率大幅收窄12.98个百分点。
- **[阿拉善天然碱项目二期投产]** -> [产量创历史新高]: 2025年底二期280万吨/年纯碱装置投料试车，推动全年总产量首次突破千万吨，达1,074万吨。
- **[联营企业蒙大矿业贡献巨额利润]** -> [支撑归母净利润]: 确认蒙大矿业投资收益4.73亿元，占公司归母净利润的50%，成为利润核心支柱。
- **[计提资产减值与公允价值变动]** -> [侵蚀利润]: 子公司长期资产减值及金融资产公允价值变动损失合计约5.18亿元，是净利润同比下滑48%的关键非经营性拖累。
- **[蒙大矿业仲裁裁决]** -> [增加营业外支出]: 仲裁裁决公司需支付探矿权价款差额等约12.3亿元，计入营业外支出，对当期损益产生重大冲击。
- **[天然碱法成本优势]** -> [维持较高毛利率]: 天然碱法制纯碱、小苏打凭借资源禀赋和短流程工艺，在行业价格下行周期中仍保持34%-39%的毛利率，显著优于合成法。
- **[产销分离与物流优化]** -> [提升运营效率]: 通过优化运输结构、争取铁路运价下浮，有效降低了长距离运输的物流成本，实现产销高效协同。

## 风险警告
**核心风险在于纯碱行业供需格局持续恶化。** 2025年纯碱市场已呈现供应宽松、价格承压的格局，而公司阿拉善天然碱项目二期280万吨/年产能正处于爬坡期，2026年行业新增产能将继续释放。若下游浮法玻璃、光伏玻璃需求持续疲软，公司可能面临“量增价跌”的困境，导致营收增长无法覆盖利润下滑，天然碱法的成本优势将被进一步侵蚀。

**重大法律与财务风险不可忽视。** 蒙大矿业仲裁案裁决公司需支付约18.9亿元探矿权价款差额，虽已达成和解协议，但巨额资金支付将显著增加公司财务压力，并可能影响后续资本开支计划。此外，公司资产负债率已升至55.98%，长期借款因项目投资大幅增长，财务费用虽因低息置换有所下降，但债务规模的持续扩大仍是潜在风险点。
