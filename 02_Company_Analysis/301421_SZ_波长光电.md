# 301421.SZ 深度透视

## 因果逻辑链
- **[半导体及泛半导体业务放量]** -> [营收增长11.71%]: 半导体设备国产替代加速，公司PCB精密微加工镜头、光刻系统等产品订单爆发，该板块收入同比大增48.71%，成为核心增长引擎。
- **[红外硫系玻璃材料替代锗]** -> [红外业务收入增长38.02%]: 公司突破低成本、轻量化红外材料工艺，推动非制冷红外镜头在民用消费电子、车载等场景规模化突破，带动红外板块显著修复。
- **[消费级AR/VR产品规模化交付]** -> [消费级光学收入增长71.99%]: 子公司江苏波长产线成熟，AR光机模组、Pancake VR模组向国内主流厂商批量供货，成为新增长点。
- **[境外收入受贸易摩擦冲击]** -> [境外营收下降25.57%]: 全球贸易环境变化导致海外客户采购收缩或转移，公司境外收入占比从30.66%降至20.43%，拖累整体增速。
- **[人员扩张与资产折旧增加]** -> [净利润下滑3.97%]: 为布局半导体、大客户服务等新业务，员工规模扩增8.10%，叠加新产线折旧及咨询费增加，期间费用合计增长约1979万元，侵蚀利润。
- **[存货跌价准备计提]** -> [资产减值损失771.78万元]: 公司产品定制化程度高，为应对订单备货，期末存货达1.83亿元，基于谨慎性原则计提跌价准备，直接减少当期利润。
- **[新加坡子公司贡献主要海外利润]** -> [境外业务韧性]: 新加坡子公司营收8703万元，净利润925万元，是公司海外利润的核心来源，并作为马来西亚新产能布局的“前店”，对冲贸易风险。

## 风险警告
**核心风险在于“增收不增利”的困境能否打破。** 公司营收增长11.71%，但净利润反降3.97%，主因是人员扩张、折旧摊销等刚性费用大幅增加，以及存货跌价准备的侵蚀。这表明公司在半导体等新赛道的高投入尚未转化为利润，若新业务规模化放量不及预期，费用率将持续压制盈利能力，导致ROE进一步下滑。

**贸易摩擦与境外业务的不确定性是另一大隐患。** 境外收入同比大降25.57%，占营收比重已降至20.43%。虽然公司在马来西亚设厂试图规避风险，但产能落地尚需时间，且全球供应链重构背景下，海外客户流失或订单转移的风险并未消除。若境外业务持续萎缩，将严重制约公司“境内+境外”双轮驱动战略的实现。
