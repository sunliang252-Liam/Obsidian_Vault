# 603099.SH 深度透视

## 因果逻辑链
- **[独家景区客运经营权]** -> [收入增长]: 拥有长白山北、西、南景区交通运营线路独家经营权，是公司最核心的收入来源和流量入口。
- **[沈白高铁开通]** -> [客流增长]: 2025年沈白高铁等重大交通基础设施通车，直接拉动长白山景区全年接待游客367.73万人次，同比增长7.9%。
- **[恩都里商旅社区开业]** -> [收入增长]: 新增恩都里营业板块，成为公司2025年营业收入增长5.98%的主要驱动力。
- **[成本刚性上涨]** -> [利润下滑]: 营业成本增长13.60%（薪资社保调整、新业务成本），远超收入增速5.98%，导致归母净利润同比下降10.33%。
- **[再融资成功]** -> [资本结构优化]: 完成上市以来首次再融资，募资2.29亿元，使货币资金增长53.10%，资产负债率从19.68%降至18.04%。
- **[季节性客流波动]** -> [业绩波动]: 第三季度（7-9月）贡献了全年50.9%的营业收入和117.1%的净利润，公司业绩高度依赖暑期旺季。
- **[景城一体化战略]** -> [非门票收入增长]: 通过“云顶市集”、“麓角村”等新业态，将游客从“一日游”向“多日度假”转化，拓展了收入来源。

## 风险警告
**核心风险在于客运经营权的“达摩克利斯之剑”。** 公司赖以生存的景区内旅游客运独家经营权将于2030年8月到期。虽然目前有合同保障，但到期后能否续约、许可费是否会大幅上升，是悬在公司未来盈利能力上的最大不确定性。一旦经营权旁落，公司将失去最核心的护城河。

**成本失控与增长瓶颈的双重挤压。** 2025年“增收不增利”的困境已十分明显：收入增长5.98%，但营业成本、管理费用、销售费用分别增长13.60%、22.81%和15.88%，侵蚀了全部利润增量。公司正从轻资产的客运模式向重资产的酒店、商业综合体模式转型，这必然带来折旧、摊销和运营成本的持续攀升。若客流增速无法持续跑赢成本增速，利润率将进一步承压。
