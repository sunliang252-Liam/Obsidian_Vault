# 002290.SZ 深度透视

## 因果逻辑链
- **[家电以旧换新政策红利]** -> [净利润增长66.86%]: 政策驱动下游家电需求稳定，公司作为头部复合材料供应商，产销量提升叠加毛利率改善（家电复合材料毛利率14.47%，同比+4.44pct），利润弹性远大于收入弹性。
- **[原材料成本下降]** -> [毛利率显著提升]: 钢板基材等主要原材料价格下行，营业成本同比下降5.19%，而收入仅微降0.27%，成本端改善直接增厚利润。
- **[高端智能化产线投产]** -> [产品结构优化]: 合肥禾盛高端智能化复合材料生产线投产，提升面向高端家电的个性化定制能力，推动产品附加值提升。
- **[出口业务韧性]** -> [收入结构优化]: 在北美关税摩擦背景下，出口收入仍增长7.17%，且毛利率提升7.34pct，显示公司通过拓展东盟、中东等新兴市场有效对冲风险。
- **[人工智能业务起步]** -> [新增收入来源]: 控股子公司海曦技术贡献收入3453万元，虽体量尚小，但标志着公司从传统制造向AI算力领域的战略延伸。
- **[财务费用大幅增加]** -> [侵蚀部分利润]: 汇兑损失增加导致财务费用从-455万升至306万，同比变动167%，对净利润产生负面影响。
- **[资产减值损失扩大]** -> [拖累业绩]: 资产减值损失从1275万增至2303万，主要系应收账款及存货减值，反映下游回款压力及库存管理挑战。

## 风险警告
**核心风险在于新旧业务的双重不确定性。** 传统家电复合材料主业虽受益于政策红利，但收入增速仅1.14%，已显疲态。行业竞争加剧、原材料价格波动及汇率风险（出口以美元结算）将持续压制利润空间。更关键的是，公司2025年净利润暴增主要依赖成本下降和毛利率修复，而非量价齐升的可持续增长。

**新业务人工智能板块尚处萌芽期，风险极高。** 海曦技术虽贡献收入，但净利润为负（-1229万），且面临技术迭代快、研发投入大、市场竞争激烈等挑战。公司以2500万元投资熠知电子（芯片设计），跨界布局存在整合风险。此外，前实际控制人遗留的子公司资产被冻结、账户被划扣等历史问题仍未彻底解决，构成潜在的财务和法律隐患。
