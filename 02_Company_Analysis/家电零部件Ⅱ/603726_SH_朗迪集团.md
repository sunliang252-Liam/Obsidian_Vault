# 603726.SH 深度透视

## 因果逻辑链
- **[主业承压，营收下滑]** -> [扣非净利润下降16.13%]: 家用空调风叶收入同比下降7.03%，机械风机收入同比下降3.53%，导致整体营收下滑3.74%，主业盈利能力减弱。
- **[金融资产公允价值变动]** -> [归母净利润逆势增长3%]: 认购“甬矽转债”产生公允价值变动收益5502万元，叠加其他金融资产收益，非经常性损益合计4929万元，掩盖了主业下滑的颓势。
- **[追加投资聚嘉科技]** -> [长期股权投资激增52.71%]: 以1.21亿元受让聚嘉科技20.17%股权，持股比例升至22.03%，会计核算方法变更，导致长期股权投资账面价值从2.62亿跃升至4.01亿。
- **[客户高度集中]** -> [经营风险集中]: 前五名客户销售额占比高达67.96%，公司业绩高度依赖格力、美的、海尔等核心空调厂商，议价能力受限，客户流失风险巨大。
- **[原材料价格波动]** -> [毛利率承压]: 主要原材料为石油衍生品，价格波动频繁。虽与客户有价格联动机制，但调整存在滞后性，导致复合材料毛利率同比下降2.03个百分点。
- **[季节性备货]** -> [存货余额高企]: 为应对旺季需求，公司需提前备货，导致期末存货余额达3.39亿元，若旺季销售不及预期，将面临存货跌价风险。
- **[泰国基地建设]** -> [资本开支增加]: 泰国生产基地处于设计规划阶段，报告期内投入2482万元，叠加对聚嘉科技的投资，导致投资活动现金净流出2.14亿元。

## 风险警告
**核心主业增长乏力，利润依赖非经常性损益。** 公司2025年扣非净利润同比下降16.13%，而归母净利润却增长3%，主要靠认购关联方“甬矽转债”带来的5502万元公允价值变动收益支撑。这种依赖金融资产“输血”的盈利模式不可持续，一旦市场波动或处置相关资产，利润将面临大幅回撤风险。公司已公告于2026年1月出售全部甬矽转债，这意味着2026年将失去这一重要利润来源。

**客户集中度极高，下游需求疲软传导风险。** 公司前五大客户销售额占比近68%，深度绑定格力、美的等空调巨头。2025年国内空调产量同比下降3.1%，行业已进入存量竞争阶段。若下游客户因房地产市场调整或“以旧换新”政策效应减弱而压缩采购量，公司将直接面临订单减少、产能利用率下降的风险。此外，1.21亿元投资的聚嘉科技尚处于业绩对赌期（2026年扣非净利润目标仅1000万元），其LCP材料业务的商业化前景存在较大不确定性，投资回报风险不容忽视。
