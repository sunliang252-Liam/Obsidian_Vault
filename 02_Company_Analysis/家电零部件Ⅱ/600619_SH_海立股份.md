## 因果逻辑链
- **[家电“以旧换新”政策拉动]** -> [空调压缩机销量逆势增长29%]: 政策刺激内需，公司作为全球领先转子式压缩机供应商，销量达4818万台，显著优于行业-2.8%的增速。
- **[海外市场突破]** -> [压缩机出口销量首次突破千万台]: 凭借全球化布局和产品竞争力，海外销量同比增长57.3%，成为业绩增长新引擎。
- **[汽车零部件业务大幅减亏]** -> [归母净利润同比翻倍增长112%]: 海立马瑞利通过全球运营优化和降本增效，净利润同比大幅减亏，叠加冷暖主业利润增长，共同驱动盈利改善。
- **[非家用及轻型商用压缩机（NRAC/PAC）增长]** -> [产品结构优化提升毛利率]: 高附加值产品销量同比增长19.5%，推动制造业整体毛利率提升0.76个百分点。
- **[新能源车用电动压缩机销量翻倍]** -> [汽车零部件业务收入增长7.91%]: 受益于新能源汽车行业快速发展，海立新能源电动压缩机销量同比增长126%，但产品竞争加剧导致售价下降。
- **[子公司清算与资产处置损失]** -> [非经常性损益大幅减少]: 报告期内清算子公司及处置固定资产形成损失，导致非经常性损益从盈利7689万降至362万，扣非净利润更能反映主业改善。
- **[汇兑收益增加]** -> [财务费用同比下降35.27%]: 人民币汇率波动带来汇兑收益，有效降低了财务成本。

## 风险警告
**盈利能力与商誉减值风险**：尽管2025年归母净利润同比大增112%，但净资产收益率仅为1.17%，仍处于低位。公司账面商誉高达7.31亿元，主要来自收购杭州富生和海立马瑞利。若未来汽车零部件业务或电机业务业绩不达预期，将面临巨额商誉减值风险，直接冲击利润表。

**行业环境与诉讼风险**：2026年空调行业面临“以旧换新”政策退坡和房地产调整压力，需求可能承压。同时，子公司海立马瑞利的参股股东已申请破产保护，可能影响治理与交易。此外，子公司绵阳海立因股东间历史交易分歧面临诉讼，若败诉将产生赔偿损失。
