# 300160.SZ 深度透视

## 因果逻辑链
- **[下游需求分化与客户新品导入]** -> [营收增长5.12%]: 存量竞争下，公司聚焦海尔、惠而浦等核心客户，通过协同开发和快速响应获取订单，支撑收入增长。
- **[行业竞争加剧与产品价格承压]** -> [毛利率下降3.09个百分点]: 下游客户成本压力传导，部分产品价格下滑，导致毛利空间收窄，是利润下滑的核心原因。
- **[美元汇率走低]** -> [财务费用同比增加161.87%]: 外销收入占比高，外币货币性项目折算产生汇兑损失，直接侵蚀利润。
- **[销量增长与成本刚性]** -> [净利润同比下降11.98%]: 销量增长15.92%未能抵消毛利率下滑和汇兑损失，增收不增利。
- **[泰国生产基地建设]** -> [提升国际化配套能力]: 为分散贸易风险、服务核心客户海外工厂，推进泰国项目，目前处于试生产阶段。
- **[募投项目延期]** -> [资本开支节奏放缓]: 因BIPV市场增量未达预期，审慎推进“智能玻璃”和“BIPV”产线项目，达产日期延至2027年。
- **[客户高度集中]** -> [经营依赖大客户]: 前五大客户（海尔、惠而浦、伊莱克斯、美的、海信）销售额占比65.67%，议价能力受限，订单波动风险大。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司营收增长依赖销量驱动，但行业竞争加剧导致产品价格承压，毛利率已连续下滑。同时，外销占比高（41.76%）使利润对美元汇率高度敏感，2025年汇兑损失激增是利润下滑的直接推手。若价格竞争与汇率不利趋势延续，公司盈利修复将面临巨大挑战。

**成长性面临双重不确定性。** 一方面，传统家电玻璃业务已进入存量博弈，大客户集中度高，公司议价能力受限。另一方面，公司寄予厚望的BIPV（光伏建筑一体化）新业务市场增量远不及预期，导致核心募投项目两度延期至2027年，新增长极迟迟未能贡献业绩。泰国工厂尚处试产阶段，其产能消化与盈利贡献仍需时间验证。
