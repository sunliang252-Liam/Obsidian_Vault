# 601956.SH 深度透视

## 因果逻辑链
- **[原材料成本压力与产品降价]** -> [毛利率下滑]: 钢材、铜、铝等原材料价格波动，叠加市场竞争导致产品售价承压，压缩机业务毛利率同比下降3.95个百分点，拖累整体盈利。
- **[汇兑损失激增]** -> [财务费用暴涨]: 人民币汇率波动导致汇兑损失同比大幅增加，财务费用从207万飙升至2034万，同比增长879.56%，直接侵蚀利润。
- **[核心子公司亏损]** -> [归母净利润腰斩]: 核心子公司黄石东贝压缩机有限公司净利润亏损7198万元，贸易子公司湖北东贝贸易亏损9221万元，是归母净利润同比下降40.24%的主因。
- **[政府补助与信用减值对冲]** -> [非经常性损益支撑利润]: 政府补助4889万元及应收款项坏账准备转回2720万元，合计占利润总额84%，掩盖了主营业务盈利能力的真实下滑。
- **[铸件业务量价齐升]** -> [结构性增长亮点]: 铸造汽车零配件销量同比增长15%，营收增长26.48%，成为公司少数逆势增长的板块，对冲了压缩机业务的疲软。
- **[研发投入高企但转化滞后]** -> [短期利润承压]: 研发费用2.63亿元，占营收4.29%，虽在扁平化变频压缩机等新品上取得突破，但高额投入尚未转化为当期利润，加剧了业绩压力。
- **[高分红比例]** -> [股东回报信号]: 在净利润大幅下滑的背景下，公司仍计划81.01%的归母净利润用于现金分红，彰显了维持股东回报的决心，但也可能影响未来资本开支。

## 风险警告
**核心风险在于盈利能力的结构性恶化。** 公司2025年归母净利润同比暴跌40.24%，扣非净利润更是下滑67.22%，核心压缩机业务毛利率大幅下降。利润严重依赖政府补助和信用减值转回等非经常性损益，主营业务造血能力堪忧。核心子公司压缩机公司和贸易公司双双巨额亏损，表明公司核心产品竞争力与成本控制能力均面临严峻挑战，增长引擎失速。

**外部风险同样不容忽视。** 原材料价格波动、汇率风险（财务费用暴涨879%）以及下游冰箱冷柜内需疲软（内销同比下滑2.7%）将持续施压。公司虽在铸件业务和扁平化压缩机新品上取得突破，但新业务体量尚小，短期内难以弥补主业下滑的缺口。高额研发投入与高分红并存，若未来业绩无法改善，财务稳健性将面临考验。
