# 001268.SZ 深度透视

## 因果逻辑链
- **[客户高度集中]** -> [业绩依赖]: 前五大客户销售占比92.12%，其中美的集团占比66.60%，单一客户依赖度极高，公司业绩与美的集团经营状况深度绑定。
- **[产品结构升级]** -> [毛利率承压]: 精密件收入增长8.96%，但毛利率下降2.26个百分点，反映高附加值产品面临成本上升和竞争加剧的双重压力。
- **[原材料价格联动]** -> [利润缓冲]: 采用“价格联动”定价机制，将废钢等主要原材料价格波动部分传导至下游，但无法完全对冲成本上涨，导致净利润下滑25.94%。
- **[产能扩张投入]** -> [资产结构变化]: 在建工程同比增长58.5%，固定资产增长19.6%，资本开支加大，但尚未转化为规模效应，总资产收益率下降。
- **[研发投入增加]** -> [技术储备]: 研发费用同比增长30.79%，研发人员增长34.56%，聚焦压缩机核心零部件工艺改进，为未来产品升级和成本控制奠定基础。
- **[经营现金流改善]** -> [财务健康]: 经营活动现金流净额同比增长52.99%，显著高于净利润增速，表明回款能力增强，盈利质量改善。
- **[新业务拓展]** -> [增长点探索]: 收购成都迈特航空51%股权，设立投资公司，向航空航天、低空经济等领域延伸，试图降低对单一行业和客户的依赖。

## 风险警告
公司面临的核心风险是**客户集中度极高**。前五大客户销售占比超过92%，其中对美的集团单一客户依赖度高达66.60%。这种结构意味着任何来自主要客户的订单波动、价格调整或供应链策略变化，都将直接且剧烈地冲击公司业绩。公司虽在拓展新客户和新领域，但短期内难以改变这一根本性脆弱点。

其次，**盈利能力持续下滑**是另一个关键警示。在营收微增1.79%的情况下，归母净利润却大幅下降25.94%，扣非净利润下降29.54%。毛利率全面承压，叠加管理费用、财务费用和研发费用的大幅增长（分别增长21.90%、296.73%、30.79%），显示公司正面临成本上升、费用膨胀与竞争加剧的多重挤压，盈利改善前景不明朗。
