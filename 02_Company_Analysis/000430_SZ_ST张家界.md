# 000430.SZ 深度透视

## 因果逻辑链
- **[司法重整完成]** -> [资产负债率从86.12%降至54.35%]: 引入15.86亿重整投资款，彻底化解历史债务与诉讼纠纷，资本结构实现质的飞跃。
- **[大庸古城巨额减值]** -> [净利润巨亏5.49亿元]: 大庸古城项目经营远低于预期，计提资产减值损失4.59亿元，是当期亏损的核心来源。
- **[杨家界索道客流大增]** -> [净利润同比上升74.59%]: 购票人数同比增长40.66%，高毛利率（63.09%）的索道业务成为利润核心支柱。
- **[环保客运客流下滑]** -> [净利润同比下降20.58%]: 核心景区环保客运购票人数下降4.12%，收入与利润同步承压，拖累整体业绩。
- **[旅行社收入激增]** -> [收入同比增长45.39%]: 旅行社服务收入大幅增长，但毛利率极低（7.92%），对利润贡献有限，更多体现为规模扩张。
- **[重整后现金流充裕]** -> [货币资金增至12.01亿元]: 筹资活动现金净流入12.22亿元，期末现金及等价物余额达11.99亿元，短期流动性风险解除。
- **[引入战略股东]** -> [治理结构优化与资源协同]: 引入湖南广电系（电广传媒、芒果超媒）及凯撒旅游等战投，在IP、客源、渠道上获得赋能。

## 风险警告
**核心风险在于大庸古城资产的持续减值与运营困境。** 报告期内大庸古城计提4.59亿元减值，是其巨亏的根本原因。尽管公司已通过重整剥离债务，但该资产组（账面净值仍超18亿）的盈利能力并未恢复，未来若运营合作（与芒果文旅）不及预期，可能面临进一步的资产减值压力，持续侵蚀净资产。

**经营层面的“增收不增利”与核心业务分化值得警惕。** 公司整体营收微增6.26%，但扣非净利润仍亏损5.3亿元。核心利润来源——环保客运的客流与利润双降，而高增长的旅行社业务毛利率极低，无法弥补核心业务的疲软。公司2026年营收目标增长32.57%，但实现路径高度依赖大庸古城盘活与杨家界索道的持续高增长，存在较大不确定性。
