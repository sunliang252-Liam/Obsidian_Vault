# 688166.SH 深度透视

## 因果逻辑链
- **[核心产品奥司他韦需求与价格下滑]** -> [抗病毒类原料药收入同比减少60.04%]: 受流感趋势变化及竞争格局恶化影响，核心大单品量价齐跌，直接拖累整体营收与利润。
- **[抗真菌类原料药客户需求波动]** -> [原料药-抗真菌类收入同比减少21.39%]: 去年同期客户临时性需求旺盛形成高基数，叠加本年度客户阶段性商业需求波动及产品价格波动，导致高毛利品种收入减少。
- **[在建工程转固与研发投入激增]** -> [归母净利润同比减少71.18%]: 固定资产折旧增加叠加创新药（BGM0504等）研发费用大幅增长（研发投入占营收48.49%），严重侵蚀利润。
- **[BGM0504注射液进入临床III期]** -> [研发投入资本化比重达48.61%]: 核心创新药管线进入关键后期临床阶段，大量研发投入符合资本化条件，导致资本化率同比大幅提升。
- **[与华润三九签署合作研发协议]** -> [经营活动现金流净额同比增长32.43%]: 收到华润三九针对BGM0504的合作预付款，显著改善了当期经营性现金流。
- **[原料药-制剂一体化战略]** -> [制剂产品收入同比增长9.33%]: 依托原料药成本与质量优势，向下游制剂延伸，磺达肝癸钠等制剂产品实现销售增长，部分对冲原料药下滑风险。
- **[免疫抑制类产品受商业化需求拉动]** -> [原料药-免疫抑制类收入同比增长27.79%]: 依维莫司等产品市场需求稳定增长，成为原料药业务中为数不多的亮点。

## 风险警告
公司当前面临的核心风险是**业绩断崖式下滑与巨额研发投入之间的尖锐矛盾**。2025年归母净利润暴跌71%，扣非净利润更是锐减85.55%，主要源于奥司他韦等成熟品种的竞争加剧和价格下行，而公司为押注BGM0504等创新药管线，研发投入占营收比例飙升至48.49%，其中资本化比例接近一半。这种“以短期利润换长期管线”的策略，在核心产品失速的背景下，使公司盈利能力和现金流面临巨大压力。

更深层的风险在于**创新药管线的极高不确定性与财务杠杆的叠加**。BGM0504虽已进入临床III期，但GLP-1赛道竞争已白热化，且其在美国的后续临床计划仍具不确定性。同时，公司总负债规模庞大，长期借款与应付债券合计超13.8亿元，财务费用同比增长27.66%。若核心创新药研发失败或商业化不及预期，高额的资本化研发投入将面临减值风险，叠加沉重的债务负担，可能对公司资产负债表造成重大冲击。
