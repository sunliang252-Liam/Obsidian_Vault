# 002823.SZ 深度透视

## 因果逻辑链
- **[产品结构优化与成本控制]** -> [归母净利润同比+37.32%]: 营收微降3.98%背景下，通过毛利率提升（精密零组件毛利率+3.21pct）和费用管控（财务费用-65.75%），实现利润大幅增长。
- **[新能源汽车连接器业务突破]** -> [连接器及集成组件毛利率+3.91pct]: 成功进入国内头部新能源客户供应链，高附加值产品占比提升，带动该业务板块盈利能力显著改善。
- **[财务费用大幅下降]** -> [利息费用减少及汇兑收益]: 报告期内利息费用同比减少近3000万元，叠加汇率变动产生汇兑收益，财务费用从6980万降至2390万。
- **[经营活动现金流强劲]** -> [现金流净额4.68亿元，净利润覆盖倍数2.0]: 运营效率提升和回款改善，经营活动现金流净额同比增长21.27%，远超净利润增速，盈利质量高。
- **[境外收入结构变化]** -> [境内收入占比提升至51%]: 境外收入同比下降9.9%，境内收入增长2.49%，反映公司主动调整市场结构，降低对单一海外市场的依赖。
- **[研发投入持续加码]** -> [研发费用+8.12%]: 聚焦800V高压平台连接器、动力电池轻量化母排等前沿项目，为未来增长储备技术能力。
- **[全球化布局加速]** -> [新设新加坡、泰国子公司]: 推进海外生产基地建设，强化本地化服务能力，以应对国际贸易环境变化和客户需求。

## 风险警告
**核心风险在于营收增长停滞与客户集中度。** 2025年营收同比下降3.98%，主要产品线（换向器-5.18%、通信及消费-9.03%）均出现下滑，仅连接器业务基本持平。公司前五大客户集中度高达37.73%，且第一大客户占比14.84%，任何核心客户订单波动都将对业绩产生重大冲击。在新能源汽车竞争白热化的背景下，新客户拓展能否弥补传统业务下滑尚存不确定性。

**汇率与国际贸易环境风险不容忽视。** 公司境外收入占比仍高达49%，结算币种多元（美元、欧元、日元）。尽管公司通过套期保值对冲，但2025年衍生品投资实际损益为-104.69万元，显示对冲效果有限。当前全球贸易政策不确定性加剧，若主要出口市场关税壁垒提高或供应链格局发生重大变化，将直接冲击公司海外业务的盈利能力与稳定性。
