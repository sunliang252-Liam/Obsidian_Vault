# 000869.SZ 深度透视

## 因果逻辑链
- **[国内葡萄酒消费持续低迷]** -> [营收下降8.81%]: 行业复苏迹象未显现，公司核心葡萄酒产品销量下滑9.25%，拖累整体收入。
- **[销量下降导致规模效应减弱]** -> [毛利率下降3.48个百分点至55.50%]: 固定成本分摊增加，叠加白兰地成本上升，侵蚀盈利空间。
- **[非经常性收益大幅减少]** -> [归母净利润暴跌76.64%]: 2024年有1.32亿资产处置收益，2025年降至135万，导致利润基数骤降。
- **[销售费用投入缩减]** -> [营收降幅收窄]: 公司主动减少市场营销投入，销售费用同比下降6.58%，但未能扭转销量下滑趋势。
- **[白兰地业务逆势增长]** -> [营收增长2.55%]: 聚焦“可雅”高端品牌，创新渠道布局，成为唯一正增长的核心品类。
- **[汇兑收益及贷款减少]** -> [财务费用转负]: 财务费用从1284万收益转为-1535万，直接增厚利润，但不可持续。
- **[B股回购注销]** -> [每股收益稀释效应减弱]: 回购注销1243万股B股，部分对冲了净利润下滑对每股收益的冲击。
- **[限制性股票激励未达标]** -> [回购注销股份]: 因业绩未达标，回购注销215万股限制性股票，反映激励计划与市场现实脱节。

## 风险警告
**核心风险在于行业需求的结构性萎缩。** 公司营收连续两年下滑，2025年归母净利润仅7129万元，创近年新低。葡萄酒消费复苏迹象未显现，公司“三聚焦”战略在存量竞争市场效果有限，白兰地虽增长但体量小（占营收25%），难以弥补葡萄酒12.25%的降幅。若行业持续低迷，公司可能面临营收跌破30亿、利润进一步承压的困境。

**第二风险是高昂的固定成本与资产减值压力。** 公司总资产120.5亿中，固定资产和存货合计占比高达67.6%。在销量下滑背景下，产能利用率不足将导致折旧摊销持续侵蚀利润。同时，海外子公司（如澳大利亚歌浓酒庄亏损343万）和部分投资项目存在减值风险，2025年已计提802万资产减值损失，未来可能进一步扩大。公司2026年经营计划中“主营业务成本及三项期间费用控制在27亿元以下”的目标，若营收不达30亿，盈利空间将极为有限。
