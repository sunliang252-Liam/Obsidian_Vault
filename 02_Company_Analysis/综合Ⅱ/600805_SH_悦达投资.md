# 600805.SH 深度透视

## 因果逻辑链
- **[新能源项目集中并网]** -> [电力收入暴增426%]: 灌东一期150MW渔光互补、东台弶港100MW/200MWh储能等项目投运，电力热力业务营收从4.3亿跃升至2.28亿。
- **[土地收储一次性收益]** -> [归母净利润虚增]: 智能农装公司土地被征收，贡献资产处置收益8421万元，是当期归母净利润3687万元的2.28倍，核心盈利能力仍为负。
- **[扣非净利润仍为负]** -> [主业造血能力不足]: 扣非净利润-204万元，连续多年亏损，表明纺织、农装、专用车等传统制造主业尚未实现根本性盈利。
- **[悦达智行出表]** -> [营收规模收缩15.89%]: 剥离汽车销售业务，导致合并报表营业收入从30.39亿降至25.56亿，但优化了资产结构。
- **[金融资产公允价值下跌]** -> [侵蚀利润]: 交易性金融资产（股票）公允价值变动损失1422万元，其他权益工具投资（帝亚一维）公允价值下降1.68亿元，拖累综合收益。
- **[联营企业贡献核心利润]** -> [投资收益成利润支柱]: 京沪高速、陈家港电厂、悦达融资租赁等联营企业贡献投资收益1.15亿元，是归母净利润的3.1倍，公司本质是“持股平台”。
- **[财务费用激增38.88%]** -> [重资产扩张的代价]: 新能源项目大规模建设导致贷款规模增加及在建工程转固，利息费用从7851万升至1.03亿元，侵蚀利润。

## 风险警告
**核心风险：主业持续失血，利润依赖非经常性损益与联营企业分红。** 扣非净利润连续多年为负，纺织、农装、专用车等传统制造板块毛利率低且竞争激烈，无法贡献稳定利润。公司盈利高度依赖土地收储等一次性收益（8421万）以及京沪高速、陈家港电厂等联营企业的投资收益（1.15亿），自身造血能力严重不足，一旦联营企业业绩波动或资产处置完毕，利润将大幅下滑。

**扩张风险：新能源转型带来沉重的财务与现金流压力。** 公司大举投资光伏、储能项目，导致固定资产暴增53.78%，长期借款激增54.8%，财务费用同比上升38.88%。虽然经营性现金流有所改善，但投资活动现金流净流出高达7.89亿元，自由现金流缺口巨大。若新能源项目收益率不及预期或电力市场交易价格下行，高杠杆扩张将引发流动性危机。
