# 000833.SZ 深度透视

## 因果逻辑链
- **[硫铁矿价格高位运行]** -> [采矿业毛利激增]: 旺盛市场需求叠加硫磺价格上涨带来的替代效应，推动硫精矿价格高企，公司精准研判、稳量提价，采矿业毛利率同比提升7.47个百分点。
- **[核心子公司云硫矿业业绩爆发]** -> [归母净利润同比+72.30%]: 云硫矿业净利润5.91亿元，占公司归母净利润的123%，是业绩增长绝对主力，其营业利润同比增加2.81亿元。
- **[新能源材料业务从0到1]** -> [营收结构多元化]: 银粉、石英矿等新业务进入爬坡期，新能源材料板块营收同比激增6403%，虽尚未盈利，但已打开第二增长曲线。
- **[糖浆纸板块降本增效]** -> [传统业务扭亏巩固]: 贵糖集团通过创新管理模式、灵活销售节奏，在糖价下行周期中实现制糖“提量提质”，制浆厂高产满销，板块整体扭亏成果持续巩固。
- **[产业链纵向延伸]** -> [化工品附加值提升]: 依托自有硫铁矿资源，向下游延伸至氨基磺酸、精制磷酸等高附加值产品，化工业毛利率同比提升9.46个百分点。
- **[资本开支大幅增加]** -> [在建工程激增]: 10万吨湿法磷酸、碎磨系统改造、石英矿等项目集中投入，在建工程同比增长281%，投资活动现金净流出同比扩大90.4%。

## 风险警告
**核心风险在于新业务投入期与现金流压力。** 公司正处于传统业务（硫铁矿）贡献利润、新业务（银粉、磷酸、石英矿）大规模资本开支的“青黄不接”阶段。2025年投资活动现金净流出高达10.45亿元，而经营性现金流净额仅5.74亿元，自由现金流缺口巨大。若新项目投产进度不及预期或市场环境恶化，公司可能面临流动性压力，需依赖新增借款维持投资节奏。

**另一风险是传统业务的周期性波动与搬迁补偿款的不确定性。** 硫铁矿价格已处历史高位，未来若下游需求回落或国际硫磺价格暴跌，将直接冲击公司最核心的利润来源。同时，贵糖集团高达11.87亿元的搬迁补偿款长期未按协议到位，不仅影响现金流，更可能引发与协议方的法律纠纷，构成潜在的资产减值风险。
