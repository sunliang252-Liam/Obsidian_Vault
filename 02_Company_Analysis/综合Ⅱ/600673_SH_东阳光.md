# 600673.SH 深度透视

## 因果逻辑链
- **[第三代制冷剂配额制落地]** -> **化工新材料毛利率飙升17.22个百分点**: 供给端配额冻结，需求端空调、新能源车增长，供需逆转推动R32等价格从4.3万/吨涨至超6万/吨，公司作为第一梯队（约6万吨配额）充分受益。
- **[股权激励费用与金融资产公允价值变动]** -> **归母净利润同比下降26.54%**: 确认股权激励费用15,775.72万元，持有东阳光药及立敦股票公允价值变动损失52,155.91万元，合计拖累利润约6.8亿元，掩盖了主业扣非净利润同比大增116.86%的强劲表现。
- **[收购秦淮数据股权]** -> **构建“硬件制造+算力服务”AI全产业链**: 出资34.5亿元参股，并拟发行股份实现100%控股，旨在切入数据中心赛道，与液冷、电子元器件、具身智能业务形成深度协同，打造“电-算-产”一体化布局。
- **[液冷与具身智能新业务布局]** -> **开辟第二、第三增长曲线**: 与中际旭创成立合资公司深度智冷，并购大图热控补齐冷板技术；联合智元、北大武智院成立光谷东智，建成湖北首座人形机器人量产工厂（年产300台），抢占AI基础设施与终端应用高地。
- **[高端铝箔差异化战略]** -> **核心产品放量但毛利率承压**: MB翅片、涂碳箔、电池箔等差异化产品销量大增，深度绑定比亚迪、松下等头部客户，但行业竞争激烈，高端铝箔毛利率仅4.12%，同比下降0.45个百分点。
- **[蓝恒达并表与氯碱产业链延伸]** -> **化工板块规模与协同效应增强**: 通过破产重整纳入蓝恒达，液碱产销量增长超50%，完善“盐矿-氯碱-制冷剂-氟精细化工”一体化布局，提升区域与成本优势。
- **[经营活动现金流大幅改善]** -> **主业造血能力显著增强**: 经营活动现金流净额13.09亿元，同比大增130.42%，主要系销售商品收到的现金增加，与扣非净利润高增长相匹配，盈利质量提升。

## 风险警告
**核心风险在于新业务投入巨大且短期难以盈利，叠加高负债率与金融资产波动。** 公司资产负债率高达66.07%，财务费用同比大增57.11%，主要因项目贷款和融资租赁增加。同时，液冷、具身智能、超级电容器等新业务均处于投入期，产能爬坡与市场开拓需要持续资金支持，对现金流构成压力。此外，公司持有东阳光药及立敦股票公允价值高达26.82亿元，其股价波动对利润表冲击巨大（2025年因此损失5.22亿元），构成显著的业绩不稳定因素。

**另一重大风险是收购整合与业务协同的不确定性。** 公司拟通过发行股份收购秦淮数据100%股权，交易金额巨大，整合过程存在管理、文化、业务协同不及预期的风险。虽然战略上旨在打造“电-算-产”闭环，但数据中心行业竞争激烈、资本开支巨大，且与公司现有业务的协同效应尚需时间验证。若整合失败或协同效应无法释放，将拖累公司整体盈利能力和资产负债表。
