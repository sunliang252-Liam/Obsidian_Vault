# 600051.SH 深度透视

## 因果逻辑链
- **[房地产业务存量去化]** -> [经营活动现金流大幅转正]: 子公司温州银联及和晟公司销售存量房，回笼资金偿还借款，使经营现金流从-4197万增至4.43亿。
- **[进口煤炭业务收缩]** -> [营收大幅下滑29%]: 子公司进出口公司煤炭销售量下降，导致批发业收入骤降76%，拖累整体营收从17.87亿降至12.68亿。
- **[财务费用锐减]** -> [归母净利润微增4%]: 存量房销售回款偿还借款，利息支出减少，财务费用下降67.6%，对冲了主业收入下滑对利润的冲击。
- **[联营企业投资收益下降]** -> [利润总额下滑21%]: 合营企业温州和欣公司商品房交付获利下降，导致投资收益减少，是利润总额下降的主因。
- **[政府土地收储]** -> [非经常性收益增厚利润]: 嵊泗长滩公司被政府有偿收回土地，确认收益1925万元，成为归母净利润的主要贡献来源之一。
- **[热电业务量价齐跌]** -> [净利润下滑24%]: 区域用热需求减弱，售热量下降5.6%，叠加煤汽价格联动低位，导致热电业务收入与利润双降。
- **[存量房销售增加]** -> [房地产业务收入增长45%]: 子公司温州银联及和晟公司加大存量房销售，使房地产业务收入逆势增长，但毛利率因降价促销而下降14个百分点。

## 风险警告
**核心风险在于主业空心化与资产变现的不可持续性。** 公司营收严重依赖高波动性的煤炭贸易，该业务大幅萎缩后，热电与房地产两大主业均面临增长瓶颈。热电受制于区域产业规划与环保政策，量价承压；房地产则依赖去化历史存量房，新项目储备不足（在建面积为零），且文旅地产去化缓慢，未来收入来源缺乏稳定支撑。

**财务风险集中于资产质量与关联交易。** 公司大量资产沉淀于投资性房地产（10亿）和存货（11亿），变现能力受市场波动影响大。同时，公司通过子公司为关联方金通融资租赁提供大量担保（余额2.8亿），且存在未解决的同业竞争问题，增加了潜在的财务与治理风险。扣非净利润已连续两年下滑，真实盈利能力堪忧。
