# 301095.SZ 深度透视

## 因果逻辑链
- **[晶圆厂扩产与先进制程研发]** -> [测试设备与软件需求放量]: 晶圆厂产能扩张直接催生WAT测试设备、EDA软件及良率提升服务的刚性需求，公司测试设备销量同比增长21.11%，软件开发及授权收入同比增长75.13%。
- **[软硬件一体化全流程覆盖]** -> [客户粘性与生态壁垒]: 公司提供“EDA软件+测试设备+数据分析”闭环方案，客户替换成本高，形成强粘性；单一产品进入后，降低其他产品认证难度，实现生态化发展。
- **[国产替代浪潮]** -> [市场份额与先发优势]: 国内晶圆厂为保障供应链安全，优先采用国产工具，公司作为国内最早进入量产线的国产WAT测试机供应商，在先进工艺项目中市占率遥遥领先。
- **[产品品类扩张（DFM/DFT/PDA）]** -> [业绩增长新引擎]: 公司从传统良率提升EDA拓展至DFM、DFT及硅光PDA领域，2025年DFM产品初具规模，DFT诊断平台获头部晶圆厂订单，并购LUCEDA切入硅光赛道，拓宽业务边界。
- **[AI与LLM大模型融合]** -> [产品智能化升级]: 公司推出SemiMind半导体大模型平台，将AI技术融入DE-G、INF-AI等核心产品，提升数据分析精准度与效率，增强产品竞争力。
- **[高研发投入（营收占比41.19%）]** -> [技术壁垒与产品领先]: 持续高研发投入（3.02亿元）保障了可寻址测试芯片、超高密度测试、快速电性测试等核心技术的领先性，形成较高技术壁垒。
- **[收入季节性波动]** -> [现金流压力]: 客户采购审批流程导致第四季度收入占比高，3-4季度含税收入超5亿元但回款滞后，叠加采购备货增加，导致2025年经营活动现金流净额为-1.22亿元。

## 风险警告
**核心风险：客户集中度极高与经营现金流恶化。** 2025年前五大客户销售额占比高达72.37%，对单一头部晶圆厂依赖度达36.66%。一旦主要客户采购策略调整或自身经营波动，将对公司业绩造成重大冲击。同时，公司经营活动现金流净额由正转负，从2024年的+4690万元骤降至2025年的-1.22亿元，主要系收入季节性回款滞后与采购备货大幅增加所致。若下游扩产节奏放缓或回款周期进一步拉长，可能引发流动性压力。

**次要风险：并购整合与商誉减值风险。** 公司2025年完成对LUCEDA NV的收购，确认商誉2.97亿元，占总资产7.99%。硅光PDA业务尚处商业化早期，若技术路线或市场拓展不及预期，存在商誉减值风险。此外，公司研发费用率高达41.19%，扣非净利润同比下降25.30%，表明高投入尚未有效转化为利润增长，需关注研发投入产出效率。
