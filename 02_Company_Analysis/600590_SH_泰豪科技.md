# 600590.SH 深度透视

## 因果逻辑链
- **[智算数据中心建设爆发]** -> [应急电源业务增长]: 大功率柴油发电机组需求随AI算力投资激增，公司作为国内品牌领先者直接受益。
- **[国家电网/南方电网投资增加]** -> [应急特种车辆业务提升]: 电网投资超6300亿元，带动电源车、排水车等招投标金额增加，公司市占率稳居前列。
- **[军工行业复苏企稳]** -> [军工装备收入增长8.17%]: 十四五规划攻坚之年，装备更新列装节奏加快，公司车载通信、导航等产品交付加速。
- **[剥离非主业资产/清理存量业务]** -> [管理费用/销售费用下降]: 合并范围减少上海博辕等，叠加控费措施，管理费用同比下降16.67%。
- **[有息负债规模及利率下降]** -> [财务费用减少22.68%]: 优化债务结构，降低融资成本，直接增厚当期利润。
- **[收回应收款项/优化结算]** -> [经营性现金流暴增1442.87%]: 加强回款管理，现金流从0.31亿跃升至4.86亿，抗风险能力显著增强。
- **[减持国科军工股票]** -> [投资收益与公允价值变动]: 报告期内减持国科军工，获得现金回流，但其他非流动金融资产公允价值变动损失-3608万元。
- **[回购上海红生少数股权]** -> [筹资活动现金净流出增加]: 支付2.31亿元回购款，导致筹资活动现金流净额-8.37亿元。

## 风险警告
**核心风险在于盈利质量与资产结构。** 公司2025年归母净利润仅6054万元，但扣非净利润为6279万元，盈利主要依赖主业改善而非一次性收益。然而，高达8.72亿元的应收账款余额（占总资产7.6%）和5.74亿元的商誉账面原值（已计提2.58亿减值）构成巨大隐患。军工业务回款周期长，客户集中度高，一旦下游付款延迟，将直接冲击本已脆弱的现金流。

**第二重风险是主业增长的不确定性。** 应急电源业务高度依赖智算中心建设景气度，若AI资本开支放缓，公司最大增长引擎将熄火。军工业务虽复苏，但毛利率下滑1.88个百分点，且面临军民融合政策下民企与央企集团的双重竞争。此外，公司无控股股东、无实际控制人的治理结构，在重大战略决策（如终止发行股份购买资产）上可能缺乏效率，增加经营变数。
