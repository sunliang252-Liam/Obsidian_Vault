# 000915.SZ 深度透视

## 因果逻辑链
- **[“伊可新”品牌统治力]** -> [营收增长4.4%]: 核心单品维生素AD滴剂市占率第一，品牌价值49.82亿元，驱动医药主业收入21.94亿元，占营收98%。
- **[高毛利+费用控制]** -> [净利率46.16%]: 医药产品毛利率85.45%，期间费用率虽增11.7%，但成本下降3.86%，维持极强盈利能力。
- **[经营现金流飙升36.78%]** -> [经营质量优异]: 现金流净额12.72亿元远超净利润，无有息负债，资产负债率仅13%，财务风险极低。
- **[研发管线丰富]** -> [未来增长储备]: 获2项药品注册证（丙戊酸钠、可乐定缓释片），5项在研获临床批件，引入国内首款儿童睡眠障碍药，丰富神经精神类产品线。
- **[营养健康品高速增长]** -> [第二增长曲线]: 借助“伊可新”品牌延伸DHA、益生菌等，形成药品+营养品协同，成为业绩新引擎。
- **[出生人口下降+终端承压]** -> [市场天花板隐现]: 2025年出生人口792万创新低，药店关店潮加剧，对婴幼儿市场规模构成长期压制。
- **[非主业清理]** -> [聚焦核心]: 完成华特信息注销，推进知新材料清算，集中资源发展儿童医药主业，提升运营效率。

## 风险警告
**核心风险在于“伊可新”单一产品依赖与人口结构性下行。** 公司98%收入来自医药业务，而医药业务高度依赖“伊可新”这一超级单品。尽管品牌壁垒深厚，但出生人口持续下滑（2025年792万）直接压缩了婴幼儿目标市场总容量。同时，医药零售终端面临关店潮，线下渠道压力增大，若未来出现替代性竞品或政策变动（如集采扩围至儿童药），业绩将面临剧烈波动。

**第二风险是研发投入转化与多元化困境。** 公司研发费用同比下降10.19%，资本化率仅6.38%，表明新药研发周期长、风险高。虽然管线丰富，但短期内难以形成对“伊可新”的有效替代。此外，非主业资产（如卧龙学校纠纷、知新材料清算）的处置仍存在不确定性，可能带来一次性损失或法律风险，分散管理层精力。
