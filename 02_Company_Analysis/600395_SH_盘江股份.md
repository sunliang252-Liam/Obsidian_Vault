# 600395.SH 深度透视

## 因果逻辑链
- **[精煤价格大幅下跌]** -> [煤炭业务收入锐减]: 精煤平均售价同比下降494.55元/吨，导致煤炭板块收入减少86,225.88万元，尽管销量增加，仍无法对冲价格下行冲击。
- **[电力项目集中投运]** -> [电力业务收入爆发式增长]: 新光、普定等燃煤及新能源机组陆续转固，发电量同比增82.1%，电力收入增175,090.04万元，成为营收增长核心引擎。
- **[在建工程转固与贷款增加]** -> [财务费用飙升]: 电力项目转固后利息停止资本化，叠加流动资金贷款增加，费用化利息支出同比增24,563.17万元，财务费用增幅达65.34%。
- **[煤炭板块降本增效]** -> [煤炭成本显著节支]: 通过使用安全生产费列支材料、降低绩效薪酬、推广节能设备，煤炭营业成本同比节支91,056.58万元，降幅18.67%。
- **[电力业务规模扩张]** -> [电力成本大幅攀升]: 燃料煤采购、职工薪酬、折旧及检修费全面增加，电力营业成本同比增97.91%，侵蚀了电力收入增长带来的利润空间。
- **[煤炭价格低位与成本管控]** -> [扣非净利润扭亏为盈]: 尽管煤价承压，但通过煤炭成本大幅节支及电力业务增量，扣非净利润从-2,814万元大幅转正至26,830万元。
- **[控股股东资产注入承诺临近到期]** -> [潜在资产注入不确定性]: 控股股东关于煤炭业务资产注入的五年承诺将于2026年6月到期，公司已公告预计无法按期完成，构成重大预期差。

## 风险警告
**核心风险在于煤炭主业盈利能力的持续恶化与巨额资本开支带来的财务压力。** 2025年公司净利润的改善主要依赖电力板块的规模扩张和煤炭成本端的压缩，但精煤价格中枢下移的趋势并未逆转。同时，为支撑煤电一体化战略，公司总资产已膨胀至473亿元，有息负债（短期借款+长期借款+一年内到期非流动负债）高达255亿元，财务费用同比激增65%，对利润形成严重侵蚀。若未来煤价继续低迷或电力市场化交易电价下行，公司盈利将面临巨大考验。

**资产注入承诺的违约风险是另一重大隐患。** 控股股东关于解决同业竞争的五年承诺即将到期，且公司已明确表示预计无法按期完成。这不仅意味着潜在的资产注入预期落空，更可能引发市场对公司治理和控股股东诚信的担忧。此外，公司所属矿井多为煤与瓦斯突出矿井，安全生产风险始终是悬在头顶的达摩克利斯之剑，任何重大安全事故都可能对生产经营和现金流造成毁灭性打击。
