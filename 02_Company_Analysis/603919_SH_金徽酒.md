# 603919.SH 深度透视

## 因果逻辑链
- **[行业深度调整与消费降级]** -> [营收与利润双降]: 白酒行业政策管控及消费结构转型，导致公司整体销量下降，营业收入同比-3.40%，归母净利润同比-8.70%。
- **[产品结构高端化升级]** -> [300元以上产品量价齐升]: 公司主动优化产品结构，聚焦金徽28等高端产品，300元以上产品营收同比+25.21%，销量同比+37.52%，成为核心增长引擎。
- **[低端产品需求萎缩]** -> [100元以下产品大幅下滑]: 消费疲软环境下，低端产品受冲击最大，100元以下产品营收同比-36.88%，销量同比-33.56%，拖累整体业绩。
- **[营销投入逆势加码]** -> [销售费用侵蚀利润]: 为应对竞争、增强消费者互动及互联网平台推广，销售费用同比+5.76%，在营收下滑背景下进一步压缩利润空间。
- **[互联网渠道高速增长]** -> [打造第三增长曲线]: 互联网销售模式营收同比+40.26%，成为公司全国化布局和品牌赋能的重要突破口，有效弥补线下市场空白。
- **[省外市场毛利率显著提升]** -> [省外扩张质量改善]: 省外市场营收基本持平，但毛利率同比+8.86个百分点，表明公司在省外市场通过产品结构优化实现了盈利能力的提升。
- **[产能扩张与资本开支增加]** -> [资产结构变化]: 启动金徽生态智慧产业园建设，导致在建工程、无形资产（土地使用权）增加，同时新增银行借款，资产负债率上升。

## 风险警告
**核心风险在于行业深度调整期的持续性与公司逆势扩张的财务压力。** 白酒行业“政策调控、消费转型、存量竞争”三期叠加，行业产量同比-12.10%，公司省内基本盘营收同比-5.34%，显示出基地市场也面临压力。在营收下滑的背景下，公司销售费用仍同比增长5.76%，且为推进产业园建设新增大量银行借款（短期+长期借款合计约2.93亿元），财务费用由负转正（利息收入减少），未来若行业复苏不及预期，高额的资本开支和费用投入将加剧利润端的波动。

**产品结构转型与渠道库存风险并存。** 虽然300元以上高端产品增长亮眼，但低端产品（100元以下）销量暴跌33.56%，显示公司正经历痛苦的“换挡期”。同时，经销商数量净减少60家（省外净减少91家），表明渠道调整仍在进行中。合同负债（预收货款）同比+28.39%至8.2亿元，虽为积极信号，但需警惕经销商打款意愿与实际动销的背离，若终端动销不畅，高企的合同负债可能转化为未来的退货或费用补贴风险。
