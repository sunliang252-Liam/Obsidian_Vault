# 688350.SH 深度透视

## 因果逻辑链
- **[主动剥离低毛利业务]** -> [营收下降11.26%，但毛利率提升4.12个百分点]: 公司主动放弃低利润化学品内销，聚焦高附加值产品，牺牲规模换取盈利质量。
- **[外销业务高速增长]** -> [弥补内销下滑，实现扭亏为盈]: 海外市场收入同比增长63.02%，成为利润核心增量来源，对冲国内需求疲软。
- **[管理费用大幅压降]** -> [净利润扭亏为盈]: 管理费用同比下降17.72%，通过控费增效直接改善利润表，是扭亏的关键财务操作。
- **[安庆基地一期投产]** -> [新增产能释放，支撑未来增长]: 新基地进入试生产，为油田化学品和高端造纸化学品提供产能基础，是第二增长曲线的物理载体。
- **[控股股东变更为永卓控股]** -> [获取钢铁/化工领域新业务机会]: 新股东产业资源（钢铁、矿山）为公司水处理业务带来协同效应，打开新市场空间。
- **[研发投入持续增长]** -> [突破高端PAM和特种膜技术壁垒]: 研发费用同比增长4.44%，聚焦耐温抗盐型压裂液、提锂纳滤膜等，支撑产品高端化转型。
- **[经营现金流大幅改善]** -> [财务基础更坚实]: 经营活动现金流净额同比增长108.40%，主要源于采购和薪酬支出减少，资金状况显著优化。

## 风险警告
公司面临的核心风险在于**战略转型的阵痛与执行不确定性**。主动剥离低毛利业务导致营收连续两年下滑，安庆基地产能爬坡及市场消化进度若不及预期，将拖累短期业绩。同时，新控股股东和管理团队（具备跨国企业背景）的磨合期，可能带来战略执行层面的短期波动。

此外，**原材料价格波动与行业竞争加剧**是长期威胁。公司主要原材料（丙烯腈等）与原油价格强相关，成本传导存在滞后性。在低端PAM市场，国内产能过剩导致价格战持续；在高端市场，需直面爱森、索理思等国际巨头的技术封锁与品牌压制。水处理膜业务尚处亏损阶段（子公司富淼膜科技亏损4576万元），新业务拓展能否突破规模化瓶颈，仍需时间验证。
