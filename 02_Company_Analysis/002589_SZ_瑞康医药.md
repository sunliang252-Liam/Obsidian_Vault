# 002589.SZ 深度透视

## 因果逻辑链
- **[主动清退低效业务]** -> [营收下降8.42%]: 公司主动优化业务结构，收缩低质低效、长账期业务，导致药品器械收入同比下降8.48%。
- **[集采常态化与医保控费]** -> [毛利率承压]: 带量采购及DRG/DIP改革持续压缩流通环节利润空间，药品器械毛利率仅10.49%，同比微降0.20个百分点。
- **[下游客户回款周期延长]** -> [经营现金流骤降91.44%]: 受DRG/DIP改革及医保穿透式监管影响，公立医院回款周期延长，经营活动现金流净额从1.61亿降至1376万。
- **[非经常性损益驱动盈利]** -> [扣非净利润持续为负]: 2025年扣非净利润-6410万元，连续三年为负，归母净利润1607万主要依赖资产处置收益（7026万）等非经常性项目。
- **[中医药板块成为增长极]** -> [马鞍山子公司贡献核心利润]: 马鞍山同兴药业净利润8632万元，成为公司最核心的利润来源，验证了向中医药全产业链转型的战略成效。
- **[处置子公司与资产回笼]** -> [投资收益支撑利润]: 报告期内处置多家子公司及资产，产生投资收益8481万元，是弥补主业亏损的关键手段。
- **[高杠杆运营与财务压力]** -> [短期借款占比高]: 短期借款42亿元，占总资产29.23%，虽较上年下降，但高负债率（62.3%）仍是财务脆弱性的核心来源。

## 风险警告
**主业造血能力持续恶化，盈利质量堪忧。** 公司扣非净利润已连续三年为负（2023年-2.18亿，2024年-1.37亿，2025年-0.64亿），表面盈利完全依赖非经常性损益（资产处置、政府补助等）。更危险的是，经营活动现金流净额从2024年的1.61亿骤降至2025年的1376万，降幅达91.44%，表明核心药械流通业务的现金回收能力正在加速恶化。若剔除资产处置收益，公司实际经营已陷入亏损，这种“卖资产保壳”的模式不可持续。

**应收账款与高负债构成双重流动性陷阱。** 公司应收账款高达37.1亿元，占总资产25.8%，而行业平均回款周期已延长至154天。在DRG/DIP改革深化和医保基金穿透式监管下，公立医院回款压力将进一步传导至流通企业。与此同时，公司资产负债率62.3%，短期借款42亿元，货币资金虽表面充裕（37.4亿），但其中大量为受限资金或用于票据质押，实际可动用现金有限。一旦应收账款坏账集中爆发，公司将面临严重的流动性危机。
