# 300054.SZ 深度透视

## 因果逻辑链
- **[半导体业务收入高增]** -> [整体营收与利润双升]: 半导体材料及芯片业务收入同比增长37.27%，占总营收57%，成为核心盈利支柱，驱动归母净利润同比增长38.32%。
- **[CMP抛光垫国产替代深化]** -> [半导体材料核心增长极]: 抛光垫收入10.91亿元，同比+52.34%，首次实现单月销量破4万片，确立国产供应龙头地位，规模效应释放利润。
- **[显示材料（YPI/PSPI）放量]** -> [半导体显示业务持续增长]: YPI、PSPI成为国内主流面板客户第一供应商，PSPI月出货量创新高，带动显示材料收入5.44亿元，同比+35.47%。
- **[高端晶圆光刻胶突破]** -> [打开远期成长空间]: 建成国内首条全流程量产线，3款产品进入稳定批量供应，商业化进程加速，但尚处投入期，短期拖累利润。
- **[降本控费与精益运营]** -> [盈利能力提升]: 全流程精细化管控有效降低运营成本，叠加产能利用率提升，半导体业务保持较强盈利能力。
- **[传统耗材业务主动收缩]** -> [短期营收承压，但质量改善]: 主动调整低毛利客户与产品，收入同比-12.97%，但应收账款与存货规模下降，运营风险降低。
- **[高研发投入]** -> [平台化技术壁垒]: 研发投入5.19亿元，占营收14.19%，构建七大核心技术平台，支撑CMP、光刻胶、显示材料等多品类拓展。

## 风险警告
**1. 新业务盈利节奏与高资本开支的错配风险。** 高端晶圆光刻胶、先进封装材料业务尚处放量初期，持续亏损；同时，仙桃、潜江等产业园新建产线陆续转固，固定资产折旧增加。若下游客户需求短期调整导致产能利用率不及预期，将对短期净利润形成压力。

**2. 传统耗材业务持续萎缩与商誉减值风险。** 打印复印通用耗材业务收入同比-12.97%，行业竞争激烈，产品单价承压。公司虽主动优化结构，但该板块营收占比仍超40%，且旗下绩迅科技、旗捷科技等子公司存在商誉，若经营持续恶化，存在商誉减值风险，拖累整体业绩。
