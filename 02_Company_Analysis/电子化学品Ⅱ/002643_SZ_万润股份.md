## 因果逻辑链
- **[生命科学与医药业务增长]** -> [归母净利润增长15.51%]: 生命科学与医药产品收入同比增长18.91%，毛利率虽微降，但高增长拉动整体利润，抵消了功能性材料收入下滑的影响。
- **[功能性材料收入下滑]** -> [整体营收仅微增0.63%]: 核心业务功能性材料收入同比下降3.57%，拖累整体营收增长，但生命科学与医药业务的增长部分弥补了这一缺口。
- **[资产减值损失高企]** -> [利润总额同比下降5.06%]: 报告期计提存货跌价准备及商誉减值准备1.16亿元，占利润总额29.43%，严重侵蚀利润，导致利润总额下滑。
- **[下游需求变化与主动去库存]** -> [生产量与库存量大幅下降]: 公司根据订单变动及下游需求，谨慎安排生产及采购，导致生产量同比下降26.02%，库存量同比下降36.97%。
- **[汇率波动]** -> [财务费用由收益转为损失]: 受汇率变动影响，本期发生汇兑损失，财务费用同比增加222.75%，对净利润产生负面影响。
- **[新产能逐步投产]** -> [为未来增长蓄力]: 蓬莱新材料一期项目（半导体材料、PEI材料）及九目化学、三月科技新项目进入试生产，为未来功能性材料业务增长提供产能基础。
- **[研发持续高投入]** -> [巩固技术护城河]: 研发投入占营收11.57%，持续布局光刻胶、聚酰亚胺、新能源材料等前沿领域，为长期竞争力奠定基础。

## 风险警告
**核心风险在于业绩增长对非核心业务的依赖性与资产减值的不确定性。** 公司2025年归母净利润增长15.51%，主要驱动力来自生命科学与医药业务（+18.91%），而核心主业功能性材料收入下滑3.57%。这种增长结构并不稳固。同时，高达1.16亿元的资产减值损失（占利润总额29.43%）表明公司面临下游需求疲软或产品迭代带来的存货与商誉减值风险，未来若核心业务未能回暖，减值压力将持续。

**另一重大风险是汇率波动与外部贸易环境。** 公司境外收入占比高达77.97%，以出口为主，汇率波动已导致财务费用由正转负，侵蚀利润。此外，中美贸易摩擦及出口退税政策变化是公司明确列出的风险因素。尽管公司采取多币种结算、远期结售汇等措施，但在全球贸易保护主义抬头的背景下，外部环境的不确定性仍是悬在业绩上的达摩克利斯之剑。
