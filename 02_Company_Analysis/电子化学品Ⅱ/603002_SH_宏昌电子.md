# 603002.SH 深度透视

## 因果逻辑链
- **[珠海二期项目投产，销量大增]** -> [营收增长43.46%]: 液态环氧树脂销量同比增156.56%，拉动总营收至30.76亿元，但增量不增利。
- **[下游需求疲软，行业产能过剩]** -> [毛利率下降]: 环氧树脂毛利率仅4.37%，覆铜板毛利率5.21%，均同比下滑，利润空间被严重压缩。
- **[新项目投产，折旧与费用激增]** -> [净利润下滑30.10%]: 固定资产同比增135%，管理费用增40.71%，折旧与摊销侵蚀利润，归母净利润仅3537万元。
- **[募投项目集中转固]** -> [资产负债率飙升]: 资产负债率从25.23%跳升至39.39%，短期借款增1207%，财务费用由负转正，财务杠杆急剧放大。
- **[覆铜板业务切入AI算力赛道]** -> [高端产品认证突破]: GA-686/688系列进入Intel、AMD材料库，并获国内服务器厂商量产订单，产品结构向高端迁移。
- **[环氧树脂“以量换价”]** -> [经营现金流恶化]: 经营活动现金流净额仅1863万元，同比降72.65%，应收账款增76.8%，存货增170%，营运资金被大量占用。
- **[半导体封装新材料布局]** -> [开辟第二增长曲线]: 投资6000万元建设ABF载板用增层膜材项目，瞄准半导体先进封装国产替代，但尚处早期。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收暴增43.46%，但净利润反降30.10%，毛利率已跌至5.68%的微利水平。根本原因是环氧树脂行业产能严重过剩，公司新投产的14万吨液态环氧项目被迫以低价策略抢占市场，导致“卖得越多，赚得越少”。同时，三大募投项目集中转固，固定资产暴增135%，每年将带来巨额折旧，在需求疲软背景下，利润下滑风险极高。

**财务健康度急剧恶化。** 资产负债率一年内从25%飙升至39%，短期借款暴增12倍，应收账款与存货同步激增，经营现金流几近枯竭。公司正陷入“为维持产能利用率而牺牲现金流”的困境。此外，覆铜板业务客户高度集中，且面临东南亚产业转移的长期挑战；新布局的半导体增层膜项目技术壁垒高、认证周期长，短期难以贡献利润。
