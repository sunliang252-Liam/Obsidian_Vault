# 603500.SH 深度透视

## 因果逻辑链
- **[轨道交通业务爆发]** -> [营收利润创历史新高]: 公司参与广湛、西十等国家级铁路项目，轨道交通产品收入同比大增50.93%，带动整体营收增长25.01%，归母净利润暴增78.31%。
- **[高分子改性材料产能释放]** -> [量利齐升]: 祥丰年产1.8万吨新产线投产，高分子改性材料销量同比增51.68%，收入增长9.52%，毛利率提升2.42个百分点。
- **[电子元器件配件稳健增长]** -> [贡献稳定现金流]: 受益于新能源汽车、光伏等下游需求，电子元器件配件收入增长6.32%，毛利率提升2.61个百分点，与贵弥功、艾华集团等头部客户合作稳固。
- **[无人机配套产品从0到1]** -> [开辟新增长极]: 无人机配件收入同比暴增1141.71%，虽基数小，但标志着公司成功切入低空经济赛道，产品竞争力初步验证。
- **[研发聚焦智能检测]** -> [培育未来增长点]: 铁路轨道综合检查仪获多铁路局认可，2026年计划打开销售局面，有望成为继扣件后的第二增长曲线。
- **[成本控制与规模效应]** -> [毛利率显著提升]: 整体毛利率同比提升4.66个百分点至32.14%，主要得益于轨道交通产品规模效应及高分子材料成本优化。
- **[股份回购与高分红]** -> [强化股东回报]: 公司累计回购注销896万股，2025年拟分红7321万元，近三年累计分红回购占年均净利润比例高达229.34%，彰显回馈股东意愿。

## 风险警告
**1. 铁路投资周期与维保市场的不确定性。** 公司近半营收依赖轨道交通业务，高度受制于国铁集团投资节奏。若未来铁路建设放缓或维保市场释放不及预期，公司业绩将面临显著波动。当前高增长部分源于重大项目集中交付，持续性存疑。

**2. 原材料价格波动与竞争加剧风险。** 改性尼龙、橡胶等主要原材料价格受宏观经济影响大，若成本上涨无法有效传导，将侵蚀利润。同时，高铁扣件高毛利吸引潜在竞争者，若市场准入门槛降低，公司毛利率存在下行压力。
