# 300836.SZ 深度透视

## 因果逻辑链
- **[火工品及含能材料智能制造订单爆发]** -> [营收暴增113.66%]: 公司攻克防爆、防静电等核心技术壁垒，为北化集团、西北工业等军工客户提供“人、机、黑”整体解决方案，打破国外垄断，实现国产替代，驱动高价值大型产线订单集中交付。
- **[消费电子与新能源汽车产线升级需求]** -> [智能组装设备收入增长113.06%]: 受益于AI赋能消费电子精密组装（如手机马达、摄像头）及新能源汽车充电枪、传感器等核心组件产线扩张，公司模块化、柔性化产线契合客户智改数转需求。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比高达91.23%，其中第一大客户占比56.38%，公司经营业绩高度依赖少数核心客户的订单持续性，存在重大客户依赖风险。
- **[营收确认与现金回款错配]** -> [经营性现金流大幅净流出1.53亿元]: 上期预收货款在本期确认收入，而本期新增大额订单的现金流入滞后，导致净利润近1亿元与经营活动现金流严重背离，现金循环周期拉长。
- **[应收账款随营收激增]** -> [信用减值损失扩大]: 营收翻倍带动应收账款余额增至4.79亿元（占总资产35.31%），导致本期信用减值损失达1,272万元，侵蚀利润，回款压力显著。
- **[产品结构向高价值产线集中]** -> [销量下降但营收增长]: 销售量同比下降40.9%，但营收增长113.66%，表明公司订单从“小批量、多品种”向“大型、高价值、定制化”产线转移，项目制特征强化。
- **[研发投入聚焦AI与特种机器人]** -> [构建技术护城河]: 研发费用增长21.23%，重点投向高速贴装、含能材料制造、防爆机器人及AI算力线缆（224G高速通信线），形成差异化竞争壁垒，支撑新赛道拓展。

## 风险警告
**客户集中度与现金流风险是核心矛盾。** 公司前五大客户销售额占比超91%，第一大客户贡献过半营收，这种“大客户依赖”模式使其议价能力受限，且一旦主要客户采购战略调整或自身经营波动，公司将面临业绩断崖式下滑的风险。更值得警惕的是，净利润暴增264%的同时，经营性现金流却大幅净流出1.53亿元，营收确认与现金回款的严重错配表明公司正以牺牲现金流为代价换取账面利润增长，应收账款和存货的持续膨胀将加剧资金链压力。

**高增长背后的资产质量隐忧不容忽视。** 应收账款占总资产比例已攀升至35.31%，且信用减值损失同比大幅增加，若下游客户（尤其是军工及大客户）付款周期进一步延长，坏账风险将集中暴露。同时，存货余额高达3.76亿元，跌价准备计提压力持续存在。公司虽在火工品、AI算力线缆等赛道具备技术先发优势，但当前财务结构显示其增长质量有待验证，需密切关注回款进度与客户集中度的变化。
