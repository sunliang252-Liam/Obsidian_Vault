# 300967.SZ 深度透视

## 因果逻辑链
- **2024年新增引种祖代蛋种鸡及繁育父母代蛋种鸡全面满产达效** -> 商品代雏鸡产能释放，销量增长21.08%: 产能建设前置是销量增长的基础，引种扩繁至满产直接支撑供给能力。
- **上半年蛋鸡养殖连续四年盈利，养殖户补栏积极性提升** -> 商品代鸡苗需求旺盛，量价齐升: 下游盈利驱动补栏需求，供需阶段性紧张推动价格上涨。
- **下半年蛋鸡养殖由盈转亏，养殖户补栏积极性减弱** -> 鸡苗订单量减少且价格承压: 盈利下行抑制补栏意愿，需求减弱导致价格下滑。
- **成本管控持续增强：生产端‘零用药’、采购端科学把控原料** -> 营业成本增幅（17.47%）低于营收增幅（25.82%），毛利率提升5.54个百分点: 多维度成本优化使成本增速慢于收入增速，直接扩大盈利空间。
- **全产业链布局：成立食品子公司、育成鸡销量翻倍** -> 培育新利润增长点，提升抗周期波动能力: 向下游延伸提高附加值，多元化业务分散单一鸡苗业务周期风险。
- **ESG管理与科技研发投入** -> 强化品牌形象与竞争优势，获多项行业荣誉: 绿色养殖和研发投入提升产品质量与市场认可度，形成竞争壁垒。
- **2024-2025年蛋鸡养殖高盈利周期驱动补栏，在产蛋鸡存栏创五年新高** -> 供给压力加大，下半年蛋价下跌，行业由盈转亏: 前期高盈利刺激过度补栏，导致存栏过剩，供大于求使价格下行。
- **新政策法规（种畜禽许可审查规范、蛋制品生产许可细则等）** -> 加速落后产能出清，利好合规规模化头部企业: 政策提高行业准入门槛和监管力度，资金技术薄弱的中小养殖户退出，优势企业市场份额扩大。

## 风险警告
行业产能阶段性过剩，在产蛋鸡存栏高位运行，鸡蛋价格预计低位震荡，饲料成本可能上涨挤压利润；公司业绩高度依赖下游补栏情绪和蛋价走势，若亏损周期延长，鸡苗销量和价格将持续承压；境外禽流感影响引种，种源替代风险需关注。
