# 002122.SZ 深度透视

## 因果逻辑链
- **[高端装备制造业务增长]** -> [营收增长14.58%]: 机床业务收入95.02亿元，同比增长13.87%，受益于下游能源、航空航天需求拉动及上海壹亘并表。
- **[债务重组收益]** -> [净利润扭亏为盈]: 与欣豪润成债务重组产生4,980万元收益，是归母净利润4,591万元的核心来源。
- **[创投业务公允价值变动]** -> [非经常性损益贡献]: 交易性金融资产公允价值变动及处置收益1.14亿元，被界定为经常性损益，掩盖了扣非净利润-3,210万元的经营亏损。
- **[大模型数据服务高增长]** -> [第二曲线初现]: 热热数据营收8,949万元，同比增长74.1%，但毛利率下降8.51个百分点，竞争加剧。
- **[资产减值损失]** -> [利润侵蚀]: 计提长期股权投资减值1.17亿元，占利润总额的-344.7%，反映创投项目退出风险。
- **[经营活动现金流为负]** -> [盈利质量差]: 经营性现金流净额-5,282万元，与净利润24,432万元严重背离，主因投资收益和债务重组收益不产生现金。
- **[传媒业务剥离]** -> [战略聚焦]: 报告期内完成中科华世股权转让，图书收入下降37.91%，公司聚焦高端装备和数据服务双主业。
- **[行政处罚与ST风险]** -> [合规成本高企]: 因2019-2020年年报虚假记载被罚500万元，股票被实施其他风险警示（ST），影响融资与市场信心。

## 风险警告
**核心风险在于盈利的不可持续性与现金流枯竭。** 公司2025年扣非净利润为-3,210万元，连续两年为负。账面盈利完全依赖债务重组收益（4,980万元）和创投业务公允价值变动（1.14亿元）等非现金、非经常性项目。经营活动现金流净额-5,282万元，表明主营业务造血能力严重不足，机床业务虽增长但回款困难，大模型数据服务尚处烧钱扩张阶段。

**历史包袱与治理风险是长期隐患。** 公司因财务造假被证监会处罚，股票被ST，声誉受损。母公司未弥补亏损高达-11.73亿元，长期无法分红。创投业务持有的长期股权投资已计提1.17亿元减值，未来仍有减值压力。关联方资金拆借（欣豪润成2,708万元、海南齐机6,972万元）回收存在不确定性，可能进一步侵蚀资产质量。
