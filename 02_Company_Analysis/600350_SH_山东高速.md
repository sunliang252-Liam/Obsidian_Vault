# 600350.SH 深度透视

## 因果逻辑链
- **济菏高速改扩建通车** -> 通行费收入同比大增152.68%: 2024年底全线恢复双向通行，2025年全年贡献增量收入，成为路桥运营核心增长极。
- **出售粤高速A股权** -> 非经常性损益大幅增加: 转让9.68%股权获得约7.5亿元处置收益，直接推高归母净利润至32.06亿元，但掩盖了主业增速放缓的事实。
- **建造服务收入锐减** -> 营业收入同比下降16.03%: 部分高速公路改扩建项目完工，导致高毛利的路桥建造服务收入大幅减少，收入结构回归通行费主业。
- **产业投资板块发力** -> 投资收益同比增长32.86%: 轨道交通、信息集团等子公司利润稳健增长，叠加股权处置收益，有效对冲了主业收入下滑的影响。
- **绿色低碳板块起步** -> 培育新增长极: 落地邯郸450MW风电、万华余热管线等项目，从“由小到大、由参到控”原则出发，布局绿色电源、水源、热源和再生资源。
- **高比例现金分红** -> 维持股东回报预期: 2025年拟每10股派4.20元，股利支付率63.34%，叠加股份回购，合计分红比例达69.58%，强化了高股息防御属性。
- **财务费用同比增加** -> 侵蚀利润空间: 因上期收到资金占用费导致基数较高，本期无此收入，财务费用同比上升7.24%，对净利润产生一定负面影响。

## 风险警告
**核心风险在于路产分流与收费政策的不确定性。** 京台高速因相交路段封闭施工导致通行费收入下降10.02%，德上、莘南高速受国道路域优化及济菏高速通车分流影响，收入分别下降19.76%和22.15%。路网完善带来的分流效应持续显现，而新的《收费公路管理条例》尚未出台，收费期限、价格调整等政策风险悬而未决，直接威胁公司最核心的通行费收入稳定性。

**第二大风险是多元化扩张带来的资产质量与现金流压力。** 公司通过并购（如毅康科技）快速切入环保、新能源等领域，但子公司毅康科技存在大量对外担保（余额约26.99亿元），且报告期内计提了较大额度的商誉减值准备（商誉余额从3.61亿降至1.04亿）。同时，公司总负债中一年内到期的非流动负债激增37.73%，筹资活动现金流净额由负转正（-4.93亿），显示短期偿债压力加大，需警惕激进投资带来的财务杠杆风险。
