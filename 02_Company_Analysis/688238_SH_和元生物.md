- **CDMO业务搬迁导致转移成本损失** -> 上年同期归属于母公司所有者的净利润亏损更高: 上期因搬迁产生一次性成本损失，增加了亏损金额
- **上年同期计提各项减值准备及预计负债较高** -> 上年同期归属于母公司所有者的净利润亏损更高: 上期减值准备和预计负债计提较多，增加了亏损
- **主营业务收入稳步增长** -> 盈利能力有所回升（亏损减少）: 收入增长有助于改善利润
- **公司积极采取降本增效措施** -> 各项运营成本费用降低: 降本增效措施直接导致成本费用下降
- **各项运营成本费用降低** -> 盈利能力有所回升（亏损减少）: 成本费用降低直接减少亏损
- **上年同期收到增值税留抵退税8,653.82万元** -> 上年同期经营活动现金流量净流出较少: 退税增加现金流入，减少净流出
- **归属于母公司所有者的净利润较上年同期减亏** -> 基本每股收益和扣非后基本每股收益较上年同期增长: 净利润减亏导致每股收益指标同比改善
- **股权回购导致净资产减少** -> 加权平均净资产收益率上升（亏损率下降）: 净资产减少，在亏损额减小的共同作用下，净资产收益率改善
- **非经常性损益减少** -> 扣非后加权平均净资产收益率上升: 非经常性损益减少使扣非后净资产收益率更接近经营实际

## 风险警告
公司仍处于亏损状态，尽管亏损幅度收窄，但经营现金流持续为负且净流出扩大，去除增值税留抵退税影响后现金流并未改善，表明公司自身造血能力仍不足。行业竞争激烈，订单价格修复仍需时间，且投融资回暖转化为业务收入存在时滞。公司净资产因股权回购减少，财务杠杆可能上升。
