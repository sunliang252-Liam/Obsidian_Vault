# 000531.SZ 深度透视

## 因果逻辑链
- **[投资收益大幅增长]** -> [净利润飙升81.54%]: 对联营企业越秀资本、广东电网能源的投资收益大幅增加，成为利润核心驱动力。
- **[引入上游战略投资者]** -> [保障气源与稳定气价]: 向中海油出售白云、东区气电公司股权，绑定天然气供应商，降低燃料成本波动风险。
- **[燃煤价格同比下降]** -> [电力业务毛利率提升1.57%]: 燃料成本下降直接改善燃煤机组盈利能力，部分对冲了电价下行的影响。
- **[电力现货市场冲击]** -> [平均上网电价承压]: 广东电力市场交易均价同比降低14.2%，导致燃煤机组含税电价从4791元/万千瓦时降至4247元。
- **[新能源项目集中投产]** -> [光伏发电量同比大增69.4%]: 汕头550MW渔光互补项目全容量并网，推动光伏发电量从6.02亿千瓦时增至10.20亿千瓦时。
- **[台风灾害导致资产损失]** -> [非经常性损益大幅波动]: 台山海宴光伏项目因台风“桦加沙”遭受约1.7亿元资产损失，但保险理赔及诉讼进展带来约1.67亿元营业外收入。
- **[剥离白云气电控股权]** -> [合并报表范围变化]: 出售白云气电51%股权后，其不再纳入合并报表，导致总资产和营业收入同比下降。

## 风险警告
**核心风险在于电力市场化改革对盈利模式的根本性冲击。** 广东电力现货市场交易均价持续走低，公司燃煤、燃气机组的平均上网电价均面临下行压力。尽管通过引入中海油作为战略投资者来稳定气价，但燃料成本与电价的双重波动，使得传统发电业务的利润空间被持续压缩，盈利稳定性存疑。

**另一重大风险是新能源项目的运营与财务压力。** 公司光伏装机规模快速扩张至1.05GW，但新投产的汕头项目因市场电价低于预期，效益未达募投项目预期。同时，台山海宴项目遭受台风重创，暴露了新能源资产面临的自然灾害风险。此外，公司资产负债率虽有所下降，但长期借款高达76.86亿元，且大量资产（如应收账款、固定资产）已用于质押或抵押，财务杠杆和资产受限程度较高。
