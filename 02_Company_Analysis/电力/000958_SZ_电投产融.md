# 000958.SZ 深度透视

## 因果逻辑链
- **[重大资产重组完成]** -> [主营业务彻底转型]: 置出金融业务，置入电投核能100%股权，公司从“能源+金融”双主业转变为以核能发电为核心、非核清洁能源为补充的纯能源平台，成为国家电投集团核能发电唯一上市平台。
- **[核电资产注入]** -> [归母净利润大幅增长]: 2025年归母净利润32.93亿元，其中同一控制下企业合并产生的子公司期初至合并日净损益高达25.07亿元，是利润的主要来源，扣非后净利润仅7.65亿元，同比下降8.07%。
- **[海阳核电运营卓越]** -> [WANO综合指数满分]: 海阳1、2号机组WANO综合指数均保持100分，多项业绩指标达国际卓越水平，机组可靠性与运营效率行业领先，为稳定发电和盈利提供保障。
- **[在建工程大幅增加]** -> [未来装机容量增长潜力]: 在建工程从年初355.15亿元增至年末456.51亿元，增长28.5%，主要系山东核电二期、三期和莱阳核电一期基建投入增加，4台核准在建机组（500万千瓦）为未来业绩增长奠定基础。
- **[电力市场化改革深化]** -> [电价波动风险加剧]: 2025年核电市场交易电量占比28.37%，非核能源市场交易电量占比73.55%。随着全国统一电力市场建成，市场化交易比例提升，电价波动风险成为影响公司盈利能力的关键变量。
- **[关联交易与同业竞争承诺]** -> [未来资产注入预期]: 控股股东国家核电及实控人国家电投承诺，将在相关核电项目正式商运后三年内，通过股权收购等方式将相关核电资产逐步注入上市公司，为公司提供长期增长空间。
- **[金融业务置出]** -> [经营现金流结构变化]: 经营活动现金流净额同比下降46.11%，主要系置出的资本控股子公司百瑞信托清算自然人信托导致交易性金融资产净增加，体现为现金净流出，剥离后公司现金流结构将更趋稳定。

## 风险警告
**核心风险：扣非净利润下滑与高额非经常性损益依赖。** 2025年扣非净利润仅7.65亿元，同比下降8.07%，而归母净利润高达32.93亿元，其中25.07亿元来自同一控制下企业合并产生的非经常性损益。剔除重组影响后，公司真实盈利能力并未显著提升，且非核能源业务（热电联产、新能源）毛利率承压，风电毛利率同比下降2.91个百分点。投资者需警惕重组红利消退后，公司业绩对核电主业盈利能力的真实依赖度。

**关键风险：电力市场化改革带来的电价下行压力。** 核电作为基荷电源，其“计划+市场”的电价模式正面临市场化交易比例持续扩大的冲击。2025年核电市场交易电量占比已达28.37%，随着全国统一电力市场体系在2030年基本建成，核电参与市场竞争的深度和广度将进一步增加，可能导致平均上网电价承压，直接影响公司核心收入。同时，在建核电项目投资巨大（在建工程456.51亿元），建设周期长，存在工期延误、造价超支等风险，将影响未来项目的投资回报率。
