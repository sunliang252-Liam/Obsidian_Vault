# 001896.SZ 深度透视

## 因果逻辑链
- **[煤炭价格大幅下降]** -> [营业成本显著降低]: 燃料成本同比下降19.42%，是公司扭亏为盈的核心驱动力。
- **[燃料成本下降传导至毛利率提升]** -> [火电业务毛利率提升6.90个百分点]: 在营收下降4.79%的情况下，成本降幅更大（-11.89%），直接改善了盈利空间。
- **[财务费用减少]** -> [净利润增加]: 借款利率下降使财务费用同比减少23.70%，节省约1.8亿元，直接增厚利润。
- **[火电业务收入占比超92%]** -> [业绩高度依赖煤价]: 公司核心业务为火力发电及供热，其盈利弹性完全由燃料成本决定，煤价是业绩的“总开关”。
- **[新能源装机规模有限]** -> [对业绩贡献微弱]: 在运新能源装机仅736.71MW，风电和光伏收入合计占比仅3.21%，尚不足以对冲火电周期波动。
- **[高负债率下的财务杠杆]** -> [利润对利率敏感]: 资产负债率高达86.80%，庞大的有息负债规模使得利率的微小变动都能对净利润产生显著影响。
- **[控股股东同业竞争承诺]** -> [资产注入预期]: 控股股东承诺将公司作为电力板块整合唯一平台，并托管其全部发电资产，构成潜在的外延增长期权。

## 风险警告
**核心风险在于业绩对煤价的单一依赖。** 2025年的扭亏为盈完全建立在燃料成本大幅下降的基础上，而非公司自身经营能力的根本性改善。一旦动力煤价格反弹，公司盈利将迅速承压，重回亏损状态。公司火电业务收入占比超过92%，缺乏多元化的利润缓冲垫。

**财务风险高企，资产负债表脆弱。** 公司资产负债率接近87%，长期借款超169亿元，每年利息支出高达5.8亿元。尽管2025年利润转正，但母公司报表仍存在近3亿元的未弥补亏损，导致无法分红。高杠杆运营模式下，任何利率上行或盈利下滑都可能引发流动性危机，偿债压力巨大。
