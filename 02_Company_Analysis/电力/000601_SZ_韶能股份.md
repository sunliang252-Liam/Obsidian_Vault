# 000601.SZ 深度透视

## 因果逻辑链
- **生物质能发电量同比大增（+82%）** -> **生物质能售电收入同比+85.41%**: 公司采取“以价换量”策略大幅增加燃料采购量（+56.48%），显著提升机组开机率，驱动生物质板块利润翻倍增长。
- **来水量同比骤降42.87%** -> **水电售电收入同比-23.55%**: 水电站所在地区降雨量严重不足，导致水电发电量及收入大幅下滑，拖累整体经营现金流。
- **新能源变速箱及零部件销量高增（+104%、+40%）** -> **精密制造收入同比+19.65%**: 宏大公司抓住新能源汽车市场机遇，新能源业务营收占比提升至67.37%，成为制造业核心增长引擎。
- **国外贸易政策变化** -> **生态纸餐具销量同比-14.65%**: 出口订单下滑，导致纸餐具收入同比-21.23%，公司被迫加速海外建厂及非美市场拓展。
- **应收账款回款大幅减少（2024年收8.35亿→2025年收1.67亿）** -> **经营活动现金流净额同比-76.44%**: 生物质能补贴及电费应收账款的集中回收具有偶发性，导致现金流剧烈波动。
- **实施首次股权激励及事业部制改革** -> **激发内生动力与专业化运营**: 公司通过组织变革和激励机制改革，旨在提升管理效率与资源配置，为长期发展奠定制度基础。
- **被指定为韶关数据中心集群源网荷储一体化实施主体** -> **开辟绿电与算力协同新赛道**: 依托现有能源运营经验，切入算电融合业务，有望为未来创造新的增长极。

## 风险警告
**核心风险在于水电业务的天然来水不确定性及生物质能补贴的应收账款风险。** 2025年水电收入因来水量骤降而大幅下滑，而生物质能发电虽量价齐升，但高达21.44亿元的应收账款（占资产16.76%）中，大部分为电价补贴，回款进度严重依赖国家财政拨付节奏，导致经营活动现金流极不稳定。2025年经营现金流净额同比暴跌76.44%，正是这一风险的直接体现。

**其次，生态纸餐具业务面临严峻的海外市场政策风险。** 公司纸餐具出口受国外贸易政策变化冲击，销量与收入双降，而国内禁塑政策执行效果不理想，市场开拓缓慢。公司虽已启动海外建厂战略，但短期内难以弥补订单缺口，该板块盈利能力持续承压。此外，公司无控股股东、股权分散的治理结构，叠加高额有息负债（长期借款51.3亿），财务杠杆较高，在利率波动环境下对利润的侵蚀不容忽视。
