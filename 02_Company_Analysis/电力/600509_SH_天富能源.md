# 600509.SH 深度透视

## 因果逻辑链
- **[大工业客户用电需求减少]** -> [供电量下降7.12%]: 受市场因素影响，部分大工业客户用电需求减少，导致公司供电量同比降低15.12亿千瓦时。
- **[外购电成本及燃料成本减少]** -> [营业成本下降14.35%]: 外购电成本及煤炭成本减少，使得营业成本降幅（14.35%）大于营业收入降幅（9.56%），毛利率提升。
- **[天然气业务增供扩销]** -> [天然气收入增长29.11%]: 车用气量增加及液化工厂二期投运，推动天然气供气量同比增长23.63%，成为公司主要增长引擎。
- **[光伏项目大规模投产]** -> [在建工程大幅减少65.88%]: 多个GW级光伏项目年内并网试运行，从在建工程转入固定资产，导致在建工程余额显著下降。
- **[发行类REITs盘活资产]** -> [资产负债率下降7.25个百分点]: 成功发行兵团首单类REITs产品（20.91亿元），有效优化资产负债结构，年末资产负债率降至65.17%。
- **[计提资产减值准备]** -> [净利润承压]: 公司针对相关资产计提减值准备5.12亿元，显著侵蚀了主营业务的盈利成果。
- **[电费差额追缴诉讼]** -> [经营现金流改善潜力]: 公司对天山铝业、合盛硅业等大客户提起电费差额诉讼，涉及金额巨大，若胜诉将大幅改善现金流和利润。
- **[新能源装机占比提升至41.89%]** -> [电力结构绿色转型]: 光伏装机规模达2,680兆瓦，占比46.20%，初步建成城市级源网荷储一体化示范区，但新能源消纳风险随之增加。

## 风险警告
公司面临的核心风险在于**大客户依赖与电费回收**。供电业务是公司收入支柱，但报告期内大工业客户用电需求减少导致供电量下降，同时公司与天山铝业、合盛硅业等多家大客户存在巨额电费差额诉讼（涉及金额超10亿元），虽然部分已达成和解，但诉讼结果及后续回款进度存在重大不确定性，对公司现金流和利润构成直接威胁。

其次，**新能源消纳与电价市场化风险**不容忽视。公司光伏装机规模激增，但光伏发电的波动性对电网安全运行构成挑战，弃光风险客观存在。同时，随着新能源上网电价全面市场化，绿电交易价格波动将直接影响公司新能源业务的收益稳定性，公司需持续投入电网改造和储能建设以应对这一结构性变化。
