# 600744.SH 深度透视

## 因果逻辑链
- **[燃料成本大幅下降]** -> [净利润扭亏为盈]: 发电标准煤单价下降136.92元/吨，直接减少燃料成本8.62亿元，是利润由-1.13亿转为+0.82亿的核心驱动力。
- **[清洁能源装机快速扩张]** -> [对冲火电收入下滑]: 新能源装机占比提升至31.81%，光伏/风电发电量同比+33%/+21%，贡献了稳定的增量收入和利润，部分弥补了火电电价下跌的损失。
- **[平均上网电价同比下降]** -> [营业收入减少2.84亿]: 含税电价下降13.46元/兆瓦时，即使发电量基本持平，仍导致电力销售收入减少，是收入端的主要拖累。
- **[财务费用率显著降低]** -> [利润改善]: 通过压降融资规模和降低融资成本（平均融资成本率降至2.33%），财务费用同比减少16.32%，直接增厚利润。
- **[高额资本开支与债务扩张]** -> [资产负债率维持高位]: 为推进株洲百万煤电及新能源项目，投资活动现金净流出52.12亿，导致总资产扩张至306亿，但资产负债率仍高达93.25%。
- **[长协煤与市场煤价倒挂风险]** -> [未来成本控制不确定性]: 报告指出，若市场煤价快速下行低于长协价，长协煤的保供作用与控价效益将产生矛盾，可能侵蚀成本优势。
- **[电力市场化改革深化]** -> [电价波动风险加剧]: 新能源全面入市及现货市场建设，导致公司平均上网电价承压，未来盈利稳定性面临挑战。

## 风险警告
**核心风险在于极高的财务杠杆与脆弱的盈利能力。** 公司资产负债率高达93.25%，归属于母公司所有者权益仅16.36亿元，而总负债高达285亿元。尽管2025年实现扭亏，但微薄的0.82亿净利润相对于庞大的债务规模而言杯水车薪。公司未分配利润仍为-61.88亿元，意味着多年内无法进行现金分红，股东回报严重缺失。任何燃料成本、电价或利率的微小不利波动，都可能将公司重新推向亏损深渊。

**转型期的结构性风险不容忽视。** 公司正从传统火电向清洁能源转型，但火电仍占主导地位。一方面，火电面临电价下行、利用小时数下降和调节性功能转变的压力；另一方面，大规模新能源投资（2025年投资现金流出52亿）导致现金流持续为负，高度依赖外部融资。若未来电价政策或市场环境发生不利变化，公司可能面临“旧业务盈利下滑、新业务回报不及预期”的双重打击，进一步加剧财务困境。
