# 600116.SH 深度透视

## 因果逻辑链
- **[来水改善，自发电量提升]** -> [电力业务利润增加]: 重庆区域来水较好，自有水电发电量同比+12.66%，替代高价外购电，直接增厚电力业务利润。
- **[电解锰市场回暖]** -> [锰业及贸易业务大幅减亏]: 电解锰市场价格同比上涨，叠加矿石开采量和产量增加，推动该板块同比减亏约7892万元。
- **[处置天泰能源股权]** -> [非经常性收益大增]: 全资子公司长兴电力转让天泰能源全部股权，在合并报表层面确认投资收益1.68亿元，成为当期利润增长的核心驱动之一。
- **[综合能源项目陆续投产]** -> [新业务利润贡献提升]: 本钢板材余气发电、两江龙盛储能二期等项目投运，综合能源业务营业利润达1.36亿元，占总营业利润20%以上，成为第二增长曲线。
- **[金融资产公允价值变动]** -> [增厚当期利润]: 子公司电力投资公司持有的私募基金等金融资产公允价值上升，贡献收益4930万元，对利润形成补充。
- **[计提大额资产及信用减值]** -> [扣非净利润下滑]: 对长兴电力商誉、乌江实业锰业资产组计提减值，叠加部分农网补助未到账，导致扣非净利润同比-15.45%，显示主业盈利质量承压。
- **[融资结构调整]** -> [财务费用下降]: 公司提前归还短期借款，增加长期借款，优化债务结构，财务费用同比-6.62%，减轻了财务负担。

## 风险警告
**核心风险在于主业盈利能力的脆弱性与资产减值的不确定性。** 公司扣非净利润同比下滑15.45%，表明剔除一次性收益（股权处置、公允价值变动）后，核心电力及综合能源业务的造血能力并未同步提升。高达1.49亿元的资产减值损失（商誉+锰业资产）和0.74亿元的信用减值损失，持续侵蚀利润，反映出历史并购整合效果不佳及部分业务（如锰业）的经营困境。

**政策与市场双重挤压下的转型阵痛。** 随着电力市场化改革深化，公司依赖购售电价差的传统配售电模式面临挑战。同时，综合能源、储能等新业务虽已布局，但面临竞争激烈、技术储备不足、商业模式尚未完全跑通的问题，短期内难以成为业绩的稳定支撑。此外，涉锰业务受行业周期影响巨大，对公司业绩构成持续扰动，其处置或剥离进程存在不确定性。
