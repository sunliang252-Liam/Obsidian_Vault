# 000722.SZ 深度透视

## 因果逻辑链
- **[2025年湖南省来水严重偏枯]** -> [水电发电量同比下降10.87%]: 年平均降雨量较常年偏少14.1%，导致株洲航电、蟒电公司入库水量分别减少43.33%和31.31%。
- **[砂石销售量同比大增113.88%]** -> [自然资源业务收入增长63.51%]: 东堤拐采区砂石品质优良，公司聚焦重点市场与核心客户，科学制定销售策略，实现以量补价。
- **[重大资产重组获证监会注册批复]** -> [水电装机容量及发电量将显著提升]: 拟收购高滩、铜湾、清水塘、筱溪四家水电站控股权，进一步聚焦能源主责主业。
- **[光伏业务加速布局]** -> [新能源装机容量同比增长4.5%]: 新设两家全资子公司，娄星、常德、果子熟了、湘科大厦等分布式光伏项目陆续并网。
- **[资产负债率仅10.09%]** -> [财务状况稳健，具备扩张潜力]: 低杠杆水平为公司后续大规模能源项目投资及并购提供了充足的财务空间。
- **[经营性现金流净额同比增长33.34%]** -> [净利润现金含量极高]: 销售回款良好，全年经营性现金流2.47亿元，远超净利润0.72亿元，盈利质量优异。
- **[砂石业务毛利率为负（-9.19%）]** -> [自然资源板块整体亏损]: 受房地产下行及基建投资放缓影响，砂石行业量价齐跌，公司砂石销售成本高于收入。

## 风险警告
**核心风险在于水电业务的“靠天吃饭”属性。** 2025年湖南省遭遇极端干旱天气，来水大幅减少直接导致公司核心利润来源——水电发电量同比下降超10%。尽管公司通过精准调度提升了水能利用率，但气候变化带来的不确定性是长期且不可控的，未来若持续遭遇枯水年，将对公司业绩造成显著冲击。

**砂石业务面临行业性供需失衡的严峻挑战。** 2025年全国砂石行业延续量价齐跌，公司砂石业务毛利率已为负值（-9.19%），处于亏损状态。尽管销售量因策略调整而大增，但这是在牺牲利润换市场，若下游房地产和基建需求持续疲软，该业务恐将长期拖累公司整体盈利能力。此外，青海光伏项目高达3.57亿元的合作意向金长期挂账，项目推进缓慢，存在一定的资金回收风险。
