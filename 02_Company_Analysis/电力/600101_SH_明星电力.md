# 600101.SH 深度透视

## 因果逻辑链
- **售电量增长** -> **营收增长**: 供区内工业企业用电需求增加，推动售电量同比增长7.87%，带动营业收入增长6.29%。
- **购电成本增加** -> **净利润下滑**: 售电量增长导致外购电成本增加，叠加自来水业务模式转变（自产转趸购）推高购水成本，归母净利润同比下降12.02%。
- **投资收益减少** -> **利润承压**: 合营企业华润万通利润下降，叠加上年同期子公司清算确认投资收益的高基数，投资收益同比减少55.94%。
- **信用减值损失扩大** -> **利润侵蚀**: 报告期预计无法收回款项单项计提增加，信用减值损失同比增加1,149.21万元。
- **所得税费用激增** -> **净利润失真**: 上年同期子公司破产清算损失允许税前扣除，导致当期所得税费用同比大增267.31%，进一步压低净利润。
- **自来水经营模式转变** -> **毛利率下降**: 落实水源地保护政策，自来水厂停产，由“自产+外购”转为“趸购销售”，购水成本增加56.61%，自来水业务毛利率下降8.32个百分点。
- **市场化售电业务扩张** -> **营收结构优化**: 新能源公司签约客户及售电量增长，市场化售电服务营收同比增长88.93%，但成本增速（115.78%）高于收入，毛利率微降。
- **经营活动现金流恶化** -> **财务压力**: 售电量增长导致支付购电费增加，经营活动现金流净额同比减少32.39%，现金创造能力减弱。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长依赖外购电量的被动扩张，而自有水电装机容量仅11.558万千瓦，无法满足区域用电需求，导致外购电成本占比高达58.49%。同时，自来水业务因水源地保护被迫转为纯趸购模式，成本刚性上涨而水价受民生管制调整滞后，毛利率大幅下滑。这种“量增利薄”的结构性困境，叠加投资收益的不可持续性和信用减值损失的扩大，使公司净利润对成本波动的敏感度极高。

**另一重大风险是2026年发电量的确定性下滑。** 非本公司所属的唐家渡电站投运及三星船闸工程实施，将导致公司下属4座电站发电量下降，且唐家渡电站的影响具有持续性。公司2026年自发上网电量计划仅为3.9亿千瓦时，较2025年实际值5.53亿千瓦时下降29.5%。这将直接减少低成本的自发电量，迫使公司进一步依赖高价外购电，严重压缩电力业务的利润空间。

> 四川明星电力股份有限公司(以下简称“公司”)是一家主营电力、自来水生产与供应,产业涉及新能源开发建设和运营、燃气、电力与自来水工程设计与建设、酒店服务和矿产资源开发等的国有控股上市公司。公司源于1926年官绅合办的明星电灯公司,1959年建成遂宁县龙凤水电站,1962年8月成立遂宁县龙凤水电厂,1984更名为遂宁县电力公司,1988年3月经四川省人民政府批准进行股份制试点,1988年4月29日注册成立遂宁电力股份有限公司,注册地为四川省遂宁市。1993年2月更名为四川明星电力股份有限公司。1997年6月27日,经中国证监会批准,在上海证券交易所上市流通(证券简称:明星电力,证券代码:600101)。控股股东为国网四川省电力公司。公司共设16个职能部室和5个业务支撑中心,下辖5个分公司和7个全资子公司,1个合营公司。公司供电区域为遂宁市船山区、安居区、经开区、河东新区、高新区,2025年上半年售电量24.58亿千瓦时。公司供区内拥有水力发电站4座、机组15台,装机容量11.558万千瓦,年均发电能力约5.4亿千瓦时,2025年上半年实现自发上网电量1.59亿千瓦时。公司供水区域为遂宁市城区,拥有自来水厂1座、加压站4座,最大供水能力22.5万吨/日,2025年上半年售水量2389.76万吨。
