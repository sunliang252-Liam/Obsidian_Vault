# 000875.SZ 深度透视

## 因果逻辑链
- **[新能源全面入市，电价下行]** -> [归母净利润同比暴跌53.17%]: 2025年新能源全面进入现货市场，市场化电价改革深化，导致平均上网电价同比下降，直接侵蚀利润。
- **[大安绿氨项目投产，获全球首张认证]** -> [确立绿色氢基能源先发优势]: 全球最大一次性投产绿氨项目试运行，获得ISCC EU RFNBO认证，打通国际销售渠道，开辟第二增长曲线。
- **[清洁能源装机占比提升至79.78%]** -> [提升长期盈利能力与抗周期能力]: 装机结构持续优化，降低对火电及燃料成本的依赖，增强可持续发展能力。
- **[火电资产减值与热力业务亏损]** -> [拖累整体盈利]: 对松花江及四平热电5号机组计提减值，热力产品毛利率为-33.71%，成为利润主要出血点。
- **[经营活动现金流净额增长28.53%]** -> [现金流与利润严重背离]: 尽管利润大幅下滑，但现金流改善，主要得益于成本控制和补贴回收，显示运营质量尚可。
- **[财务费用下降14.13%]** -> [部分对冲利润下滑]: 通过债务优化和低利率融资，有效降低利息支出，缓解了电价下跌带来的部分压力。
- **[前五大客户集中度高达69.63%]** -> [收入依赖单一电网公司]: 对国网吉林省电力有限公司的销售额占比45.54%，客户高度集中，议价能力弱，存在区域政策风险。

## 风险警告
**核心风险在于电价下行与资产减值双杀。** 2025年归母净利润腰斩，主因是新能源全面入市导致电价承压，叠加火电资产减值。公司虽通过降本增效和财务优化部分对冲，但盈利能力的根本性恶化趋势尚未扭转。若电价持续走低，公司“新能源+”赛道的增量投资回报将面临严峻挑战。

**战略转型的“双刃剑”效应显现。** 公司全力押注绿色氢基能源，大安项目虽具标杆意义，但投资规模巨大（梨树甲醇项目总投资49.2亿元），且商业化路径尚在探索。同时，公司逆势投资白城二期2×66万千瓦煤电项目（总投资56.98亿元），在电力市场化改革深化、煤电定位转变的背景下，该投资可能成为新的资产减值风险点。
