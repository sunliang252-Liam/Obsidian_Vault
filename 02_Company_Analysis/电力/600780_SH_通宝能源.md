# 600780.SH 深度透视

## 因果逻辑链
- **市场交易电价上行 + 燃料成本下降** -> 火电业务毛利率大增7.9个百分点: 电价上涨叠加燃料采购综合成本同比下降，直接扭转了火电板块的盈利颓势。
- **配电区域用户用电量增加** -> 售电量突破200亿千瓦时，同比增长5.48%: 所辖区域部分能源企业产能提升及增容，直接拉动了配电业务的收入增长。
- **清洁能源项目投产** -> 新增绿色发电量0.68亿千瓦时: 宁武、平鲁风电项目首批机组并网，标志着公司从纯火电向“煤电+新能源”转型迈出实质性一步。
- **参股煤企（宁武榆树坡）贡献高额收益** -> 对联营企业投资收益达1.56亿元: 参股的煤炭企业盈利能力强劲，成为公司利润的重要稳定器，对冲了火电主业的部分波动。
- **资产处置收益减少 + 营业外支出增加** -> 非经常性损益同比下降44.95%: 扣非净利润增速（30.98%）显著高于归母净利润增速（26.43%），核心主业盈利改善更为扎实。
- **在建工程大幅增加** -> 投资活动现金流净流出扩大至-11.28亿元: 风电、光伏项目集中开工建设，资本开支进入高峰期，对自由现金流形成阶段性压力。

## 风险警告
**核心风险在于火电业务的长期结构性衰退与新能源转型的短期不确定性。** 公司火电装机占比仍高达94.9%，尽管2025年因电价上行和煤价下跌实现盈利修复，但全国火电利用小时数持续下滑（同比降232小时），且容量电价新政下收益与调峰能力挂钩，火电从“主力电源”向“调节性电源”的转变将长期压制其盈利空间。同时，公司新能源项目尚处建设初期，已投产风电利用小时仅1353小时，远低于行业均值，项目运营效率和收益兑现能力有待验证。

**财务风险方面，资本开支高峰与关联交易集中度值得警惕。** 公司投资活动现金流净流出同比扩大106%，在建工程激增114%，而主要依赖项目贷款（长期借款同比增273%）和自有资金，未来若项目回报不及预期，将推高杠杆并侵蚀现金流。此外，公司对单一供应商（国网山西省电力）的采购额占比高达67.85%，关联交易（燃料采购、金融服务）规模庞大，存在定价公允性及资金被占用的潜在风险，需持续关注其治理独立性。
