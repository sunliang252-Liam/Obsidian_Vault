# 601991.SH 深度透视

## 因果逻辑链
- **[燃料成本大幅下降]** -> [净利润创历史新高]: 2025年煤机入炉标煤单价同比下降14.80%，直接驱动火电板块利润总额同比暴增119.08%，成为业绩爆发的核心引擎。
- **[上网电价同比下降]** -> [营业收入微降]: 尽管发电量微增1.33%，但电力市场化交易导致平均上网电价承压，电力销售收入同比下降2.33%，收入端增长乏力。
- **[清洁能源装机持续扩张]** -> [利润结构优化]: 2025年新增清洁能源装机5,120.854兆瓦，风电、光伏利润总额分别同比增长38.52%和9.80%，对冲了火电电价下行风险。
- **[综合融资成本压降]** -> [财务费用显著减少]: 综合融资成本降至2.33%（同比压降30个BP），财务费用同比下降16.21%，直接增厚了利润。
- **[“大经营”格局深化]** -> [经营现金流大幅改善]: 以市场为导向优化经营策略，叠加燃料成本下降，经营活动现金流净额同比大增44.84%，达378.36亿元。
- **[煤电利用小时数承压]** -> [火电发电量受限]: 全国火电利用小时数同比降低232小时，公司煤机利用小时数下降322小时，限制了火电板块的产出弹性。
- **[新能源全面入市]** -> [电价波动风险加剧]: 136号文后新能源电价全部市场化，绿电交易价格波动加剧，可能影响新能源项目未来的收益稳定性。

## 风险警告
**核心风险在于电价下行与燃料成本反弹的“剪刀差”挤压。** 2025年业绩爆发高度依赖煤价大跌（入炉标煤单价降14.80%），但2026年煤炭市场供需转向紧平衡，价格波动加剧，燃料成本控制难度陡增。与此同时，电力市场化改革深化，长协电价逼近低位，新能源大量入市进一步拉低整体电价水平。一旦煤价反弹而电价持续承压，公司盈利将面临剧烈收缩。

**第二大风险是资产质量与巨额资本开支的长期压力。** 公司资产负债率仍高达70.15%，且每年需投入超250亿元进行新能源转型和煤电改造，投资活动现金流持续大额净流出。同时，部分子公司（如四川金康电力）持续亏损，且存在子公司破产清算导致的委托贷款逾期（逾期未收回余额6.4亿元），资产减值风险不容忽视。此外，控股股东同业竞争问题长期悬而未决，资产注入承诺屡次延期，存在治理隐患。
