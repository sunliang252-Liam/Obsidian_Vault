# 600011.SH 深度透视

## 因果逻辑链
- **[燃料成本大幅下降]** -> [火电利润暴增]: 2025年煤炭采购均价同比降12.5%，境内火电厂单位售电燃料成本降11.13%，直接推动燃煤板块利润总额同比大增86%至132.70亿元。
- **[电价与电量双降]** -> [营收承压]: 境内上网电价同比降3.48%，上网电量同比降3.39%，导致电力热力收入减少约136亿元，营业收入同比下降6.62%。
- **[新能源装机扩张]** -> [电量结构优化]: 低碳清洁能源装机占比提升至41.01%，风电/光伏发电量同比增10.85%/43.61%，部分对冲了火电电量下滑的影响。
- **[煤机利用小时骤降]** -> [火电资产效率承压]: 新能源挤占发电空间，煤机利用小时同比下降326小时至3,959小时，火电资产利用率持续走低。
- **[低成本融资]** -> [财务费用缩减]: 全年累计落实债务融资超1,800亿元，综合资金成本下降，财务费用同比减少9.23%，增厚利润。
- **[碳配额收紧]** -> [未来履约成本上升]: 第四履约期配额分配进一步收紧，公司虽完成清缴，但后续有偿分配机制将增加火电碳排放履约成本。

## 风险警告
**核心风险：电价下行与电量萎缩的双重挤压。** 随着全国统一电力市场加速建设及新能源全面入市，电力现货市场已基本实现全覆盖，竞争加剧导致电能量价格呈下行趋势。同时，新能源装机持续高增（2025年新增占全社会新增装机超八成），大幅挤占煤机发电空间，公司煤机利用小时数已降至3,959小时。量价齐跌将直接侵蚀公司最核心的燃煤发电收入，而火电仍是公司利润的主要来源。

**次要风险：燃料成本与碳成本的双重不确定性。** 尽管2025年煤炭价格中枢下移，但2026年煤炭市场预计呈现“供需基本平衡、价格波动加剧”的特点，进口煤受地缘政治影响存在不确定性，燃料成本管控难度加大。同时，碳市场配额发放持续收严并转向有偿分配，单位火电电量的碳排放履约成本将持续增加，成为压制火电利润的长期结构性因素。
