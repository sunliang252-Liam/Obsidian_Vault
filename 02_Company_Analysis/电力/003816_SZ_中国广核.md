## 因果逻辑链
- **[电力市场化交易电价下降]** -> [营收与利润下滑]: 2025年市场化交易电量占比升至56.2%，平均市场电价同比下降约8.8%，导致营业收入下降4.11%，归母净利润下降9.90%。
- **[换料大修安排优化]** -> [发电量提升]: 2025年换料大修总天数减少，在运机组平均能力因子从91.91%提升至92.65%，推动上网电量同比增长2.36%。
- **[在建项目大规模投入]** -> [资本开支与负债扩张]: 管理20台在建机组，在建工程同比增加33.9%，投资活动现金流出增长16.16%，总资产增长7.24%至5056亿元。
- **[收购惠州核电等资产]** -> [装机规模与在建项目扩容]: 完成惠州核电等五家公司股权收购，在建核电机组从8台增至16台，在建容量从9,738兆瓦增至19,376兆瓦。
- **[债务结构优化与低利率环境]** -> [财务费用下降]: 增加短期借款、减少长期借款，利用低利率环境进行贷款置换，财务费用同比下降11.88%。
- **[乏燃料处置金计提增加]** -> [营业成本上升]: 阳江6号、台山2号机组商运满五年开始计提乏燃料处置金，计提金额同比增长7.85%，推高电力销售成本。
- **[核电新项目核准]** -> [长期增长确定性]: 台山二期、防城港三期项目于2025年4月获核准，连续第四年核准5个核电项目，巩固公司作为中广核核能发电唯一平台的战略地位。

## 风险警告
**核心风险在于电价下行侵蚀盈利。** 2025年归母净利润同比下降9.90%，主因是电力市场化交易电价同比下降约8.8%。随着全国统一电力市场加速建成，核电参与市场化交易的比例将持续提升，电价下行压力可能长期存在。公司平均上网电价已从2024年的416元/千千瓦时降至380元/千千瓦时，若电价持续走低，将直接压缩利润空间，甚至可能影响在建项目的投资回报率。

**第二重风险是巨额资本开支与债务压力。** 公司管理20台在建机组，在建工程高达1139亿元，占总资产22.53%。2025年投资活动现金净流出323亿元，经营活动现金流净额已同比下降20.09%至299.7亿元，自由现金流缺口持续扩大。资产负债率65.15%，短期借款同比激增137.7%至421.5亿元，债务结构短期化趋势明显。若在建项目投产进度不及预期或电价持续低迷，可能引发流动性压力。
