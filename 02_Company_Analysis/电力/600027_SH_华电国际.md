# 600027.SH 深度透视

## 因果逻辑链
- **[燃料成本下降]** -> [净利润增长]: 入炉煤折标煤单价同比下降15.18%，燃料成本减少约15.92%，直接对冲了电价下行和发电量减少对利润的侵蚀。
- **[资产注入（同一控制下企业合并）]** -> [装机规模与收入扩张]: 完成收购华电江苏等8家单位，新增控股装机约1,606万千瓦，强化了常规能源资产整合平台地位，但并表导致营收因追溯调整而下降。
- **[发电量下降]** -> [营收减少]: 发电量同比下降7.15%，上网电量下降7.09%，叠加平均上网电价下降2.83%，导致营业收入同比减少10.95%。
- **[财务费用降低]** -> [利润改善]: 通过加大资金运作和融资成本降低，财务费用同比下降16.37%，为利润增长提供了正向贡献。
- **[市场化交易电价承压]** -> [收入结构变化]: 市场化交易电量占比高达87.24%，新能源全面入市冲击中长期市场价格，火电企业面临保量稳价压力，电价下行趋势明显。
- **[资本运作（公募REITs）]** -> [资产盘活]: 成功发行央企首单燃机公募REITs，开辟了清洁能源基础设施资产证券化新路径，优化了资产结构。
- **[供热业务亏损]** -> [整体毛利拖累]: 售热业务毛利率为-6.8%，虽同比改善8.8个百分点，但仍处于亏损状态，持续拖累公司整体盈利能力。

## 风险警告
**核心风险在于电价下行与发电量萎缩的双重挤压。** 尽管2025年因煤价大幅下跌实现了利润微增，但营收同比下降10.95%，表明公司“量价齐跌”的困境并未根本缓解。随着新能源装机持续增长并全面入市，其低边际成本对电力市场价格的冲击将长期存在，火电利用小时数（同比下降378小时）和上网电价（同比下降2.83%）均面临持续下行压力，公司盈利能力高度依赖燃料成本的下降，这一逻辑的可持续性存疑。

**第二大风险来自高额的资本开支与债务压力。** 2026年计划资本开支约190亿元，主要用于电源项目建设和技改，而2025年经营活动现金流净额272亿元，投资活动现金净流出143亿元，自由现金流缺口巨大。公司资产负债率虽有所控制，但财务费用仍高达31.62亿元，且大量资产（电费、热费收费权及发电机组）已被用于质押借款。在电价下行周期中，高额的折旧和财务费用将严重侵蚀利润，若未来煤价反弹，公司将面临利润大幅下滑的风险。
