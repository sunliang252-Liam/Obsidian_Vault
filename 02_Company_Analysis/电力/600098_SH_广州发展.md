# 600098.SH 深度透视

## 因果逻辑链
- **[土地交储确认大额非经常性收益]** -> [归母净利润大增33.93%]: 确认罗冲围发电厂地块征收补偿收益17.89亿元，是净利润创历史新高的核心驱动力。
- **[新能源装机规模高速扩张]** -> [新能源发电量及利润增长]: 光伏装机同比增51.4%，风电装机同比增5.7%，带动新能源发电量增长26.55%，成为利润增长的第二引擎。
- **[煤炭及油品贸易量大幅增长]** -> [能源物流营收增长但利润承压]: 煤炭销量同比增20.9%，油品销量同比增232.46%，但毛利率极低（1.1%），且能源物流集团净亏损1.74亿元。
- **[天然气全产业链贯通与资源池多元化]** -> [燃气业务量利双增]: 供气量58.5亿立方米，同比增长，通过长协锁定低价气源（如摩科瑞），实现异地售气量增长33%。
- **[火电发电量受替代关停及供需宽松影响下降]** -> [火电业务收入及利润下滑]: 火电发电量同比下降7.87%，燃煤发电毛利率下降2.93个百分点，天然气发电毛利率下降0.92个百分点。
- **[融资利率下降及债务结构优化]** -> [财务费用同比下降5.67%]: 发行低利率债券（如1.78%超短融），有效降低融资成本，对冲了投资扩张带来的资金需求。
- **[计提大额资产减值损失]** -> [扣非净利润大幅下滑35.28%]: 计提固定资产减值、存货跌价准备及商誉减值合计5.05亿元，严重侵蚀了主营业务的真实盈利能力。

## 风险警告
**核心风险在于利润的“含金量”极低。** 2025年归母净利润23.19亿元创历史新高，但扣非净利润仅10.54亿元，同比暴跌35.28%。高达12.65亿元的非经常性损益（主要是土地交储收益）是利润表的核心支撑。剔除这一偶发因素，公司主营业务（尤其是火电和能源物流）盈利能力在恶化，能源物流集团净亏损1.74亿元，火电发电量下滑，资产减值损失激增，表明公司核心业务的造血能力正在减弱。

**第二大风险是激进的资本开支与日益攀升的负债率。** 公司正处于新能源、储能、气电等项目的投资高峰期，2025年投资活动现金净流出高达77.4亿元，是去年的3倍。这导致公司资产负债率从61.76%攀升至63.39%，有息债务余额增至397.74亿元。若未来电价下行、新能源利用小时数下降或项目回报不及预期，高额的折旧和财务费用将严重侵蚀利润，并带来流动性压力。
