# 000862.SZ 深度透视

## 因果逻辑链
- **[新能源全面入市，电价承压]** -> [净利润暴跌48.84%]: 2025年新能源上网电量原则上全部进入电力市场，交易电价下降（含税均价从4.93分/千瓦时降至4.23分/千瓦时），直接侵蚀发电主业利润。
- **[“以大代小”技改计提巨额减值]** -> [资产减值损失2.52亿元]: 太阳山三四期等老旧风电场技改项目，对拟拆除风机计提大额固定资产减值准备，是导致净利润腰斩的直接原因。
- **[可再生能源补贴电费回款大增]** -> [经营现金流暴增128%]: 当期收到历史拖欠的补贴电费大幅增加，使经营活动现金净流入达12.22亿元，远超净利润，但属一次性回款，不可持续。
- **[背靠中铝集团，获取绿电项目]** -> [装机容量持续扩张]: 依托中铝集团千亿级用电负荷，积极开发分布式光伏和绿电直连项目，2025年新增装机27.45万千瓦，总装机达208.46万千瓦。
- **[发电量增长难抵电价下跌]** -> [营收仅微增3.47%]: 发电量同比增长11.44%至35.36亿千瓦时，但平均上网电价下降约14.3%，量增价跌导致发电收入仅增1.44%。
- **[财务费用下降]** -> [部分对冲利润下滑]: 因借款余额和利率下降，财务费用同比减少15.62%至1.15亿元，在一定程度上缓解了利润端的压力。
- **[控股股东承诺资产注入]** -> [未来业绩增长预期]: 控股股东承诺24个月内将定边能源49%股权及光伏资产注入上市公司，若兑现将显著增厚公司盈利能力和装机规模。

## 风险警告
**核心风险在于电价市场化改革带来的盈利模式颠覆。** 2025年新能源全面入市，公司平均上网电价同比暴跌14.3%，直接导致“量增价跌”的尴尬局面。随着电力现货市场推进，电价波动将常态化，公司过往依赖补贴和固定电价的稳定盈利逻辑已被打破，未来盈利能力面临持续且不可预测的冲击。第四季度净利润巨亏1.93亿元，已敲响警钟。

**资产减值风险与现金流陷阱并存。** 公司为提升发电效率进行“以大代小”技改，但由此产生的巨额资产减值（2.52亿元）已严重侵蚀利润。未来仍有大量老旧机组面临改造，减值风险将持续暴露。同时，2025年经营现金流暴增主要依赖历史补贴电费的一次性回笼，并非主业造血能力提升。一旦补贴回款节奏放缓，公司高负债运营（资产负债率49.3%）下的资金链压力将迅速凸显。母公司层面未分配利润仍为-3.5亿元，不具备分红能力，股东回报前景黯淡。
