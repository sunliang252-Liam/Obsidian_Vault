# 600505.SH 深度透视

## 因果逻辑链
- **[精益管理降本增效]** -> [财务费用同比下降19.88%]: 严控带息负债规模，强化全面预算管理，有效压降非生产性开支，直接提升利润。
- **[售电量增长]** -> [供电环节收入同比增长1.64%]: 通过提升优质服务、增供促销，售电量同比增长5.96%，驱动核心收入增长。
- **[自有发电量增长]** -> [发电收入提升]: 加强发电运维管理和技术改造，网内自有及控股电站发电量同比增长5.89%，降低外购电成本。
- **[购售电结构变化]** -> [利润波动]: 深度参与电力市场化交易，购售电结构变化对利润产生综合影响，是业绩改善的关键变量。
- **[农网统贷统还资金违约金]** -> [非经常性损益]: 四川省水电集团投入的农网统贷统还资金形成的借款本金暂计违约金1,277.50万元，计入非经常性损益，拖累归母净利润。
- **[子公司固增公司亏损]** -> [少数股东损益为负]: 控股子公司木里县固增水电开发有限责任公司亏损4,331万元，导致少数股东损益为-937.87万元，侵蚀归母净利润。
- **[经营性现金流大幅改善]** -> [现金流健康度提升]: 经营活动现金流净额同比增长57.79%，主要得益于销售商品、提供劳务收到的现金增加，表明主业造血能力增强。

## 风险警告
**核心风险在于电价政策调整与市场化竞争的双重挤压。** 输配电价改革首次试点覆盖地方电网，公司经营逻辑被迫向“精益管理”转型，未来电价存在下行压力。同时，电力市场化改革加速，现货交易与新能源全面入市，售电市场竞争加剧，公司作为区域电网企业，其购售电价差面临收窄风险，直接影响盈利能力。

**财务风险集中于高负债率与子公司持续亏损。** 公司总资产39.65亿元，但负债合计26.07亿元，资产负债率高达65.7%，且大部分固定资产（20.67亿元）已用于借款抵押。控股子公司固增公司（康坞水电站）亏损4,331万元，西源电力、丰光新能源等亦处于亏损状态，这些“失血点”持续拖累合并报表利润，若无法扭亏，将长期侵蚀股东回报。
