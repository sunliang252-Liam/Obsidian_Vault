# 600310.SH 深度透视

## 因果逻辑链
- **[广西电力交易市场电价下行]** -> [电网板块毛利骤降]: 市场化竞争导致售电价格下降，直接侵蚀了公司核心电网业务的利润空间。
- **[贺江、桂江流域来水偏枯]** -> [水电自发电量减少，外购电成本上升]: 来水减少导致低成本水电出力不足，公司被迫高价外购电力填补缺口，进一步压缩电网板块利润。
- **[火电“量价齐跌”]** -> [火电板块巨额亏损]: 新能源装机挤压火电利用小时数（同比下降56.52%），叠加电价下行，导致火电业务边际贡献收窄，成为业绩最大拖累。
- **[新能源装机快速增长]** -> [结构性替代效应]: 风电、光伏等新能源发电量同比大增151%，虽优化了电源结构，但加剧了火电的挤出效应，并导致水电、风电分摊不平衡电费。
- **[计提大额资产减值]** -> [归母净利润大幅下滑]: 报告期内计提商誉、长期股权投资及固定资产减值损失1.70亿元，是导致归母净利润由盈转亏的直接原因之一。
- **[非经常性损益波动]** -> [业绩剧烈波动]: 公允价值变动收益（持有国海证券等股票）同比大幅减少86.59%，叠加股权置换收益，导致非经常性损益对利润的贡献极不稳定。
- **[“厂网合一”模式]** -> [风险对冲与成本传导]: 公司拥有自有电网，能通过外购电和自发电的调配来保障供电，但来水偏枯时，低成本自发电不足，导致购电成本刚性上升，模式优势减弱。

## 风险警告
**核心风险在于“量价齐跌”的行业性困境与公司自身资产质量的恶化。** 广西电力市场化交易导致电价持续下行，叠加新能源对火电的挤出效应，公司火电业务已陷入严重亏损。同时，来水的不确定性导致水电出力波动，公司无法通过低成本自发电对冲外购电成本上升，电网板块盈利能力被双重挤压。这种结构性矛盾短期内难以逆转，公司2026年经营计划中0.5亿元的净利润目标，实现难度极大。

**财务风险集中体现在资产减值和巨额有息负债上。** 公司2025年计提了1.7亿元资产减值，商誉余额仍有1.69亿元，未来仍有减值风险。公司资产负债率高达77.88%，有息债务超154亿元，财务费用高达4.44亿元，沉重的利息负担持续侵蚀利润。尽管经营活动现金流净额为正，但巨额投资支出（新能源项目）和偿债压力，使公司现金流高度紧张，融资能力成为未来发展的关键瓶颈。
