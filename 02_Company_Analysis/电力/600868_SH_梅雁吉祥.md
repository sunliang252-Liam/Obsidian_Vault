# 600868.SH 深度透视

## 因果逻辑链
- **[降雨量锐减]** -> [水电收入骤降29%]: 梅州地区降雨量减少导致全年发电量35,488万度，同比减少31%，直接拖累核心主业收入。
- **[并购上海新积域]** -> [新增BPO业务收入8,500万元]: 2025年8月完成对BPO公司65%股权收购，快速切入数字服务赛道，形成第二增长曲线。
- **[应收账款坏账激增]** -> [信用减值损失7,197万元]: 子公司广州国测地理信息业务回款周期拉长，按账龄补充计提大额坏账准备，严重侵蚀利润。
- **[旋窑水泥产能退出]** -> [资产减值损失6,469万元]: 关停并拆除水泥窑炉等主体设备，叠加无形资产减值，导致非经常性重大损失。
- **[股份回购与借款]** -> [财务费用激增161%]: 为回购股份新增银行专项贷款，利息支出大幅增加至2,062万元，加重财务负担。
- **[锑银矿储量备案]** -> [长期价值锚点确立]: 嵩溪锑银矿资源储量核实报告获自然资源部备案，为未来资源变现奠定基础。
- **[无实控人结构]** -> [治理风险与战略摇摆]: 股权分散，无控股股东，决策易受短期利益影响，战略转型的连续性与执行力存疑。

## 风险警告
**核心风险在于“新旧动能转换期的业绩断层”。** 传统水电主业因天气波动剧烈（2025年发电量骤降31%），盈利能力极不稳定；新并购的BPO业务虽有政策支持，但尚处规模化初期，2025年仅贡献8,500万收入，远不足以弥补主业下滑及巨额减值带来的亏损（归母净亏损9,709万元）。公司试图通过并购和资产处置实现转型，但短期内“失血”速度远超“造血”能力。

**财务健康度恶化是另一大隐患。** 公司应收账款高达3.09亿元，且持续计提大额信用减值，回款风险高企。同时，为回购股份背负大量有息负债，导致财务费用飙升，进一步压缩利润空间。母公司未分配利润虽为正，但合并报表未分配利润已为-2.72亿元，表明子公司层面亏损严重，整体资产质量承压。公司虽无退市风险，但持续亏损将严重侵蚀净资产，长期价值面临挑战。

> 广东梅雁吉祥水电股份有限公司(以下简称“梅雁吉祥”)成立于1993年1月,1994年9月在上海证券交易所上市,证券代码为“600868”。自上市以来,公司积极致力于清洁能源的建设和转型,经多年运营和发展,公司在稳固水电主业的同时,稳步向大数据与地理信息等数字信息、铜箔新材料产业化项目、氢能源产业、储能项目、有机废弃物处置与沼气综合利用等国家鼓励的新型能源业务领域延伸发展,形成了集水力发电、地理测绘信息、大数据应用、智慧城市、民办教育、矿产资源、新型能源为一体的业务板块。公司创办的民办全日制完全中学梅州市梅雁中学,地处梅江河畔,城市中心区。学校于2002年按省一级标准投资兴建,拥有20多年办学经验。自2016年以来,更是累计投资4000多万元打造花园式的校园环境和先进完备的设备设施,实行全封闭寄宿管理;梅雁中学致力于打造特色教育品牌,以“创建民办粤东名校”为目标,开办复读班二十余年,专门设立复读生年级,独栋教学楼上课,选科组合齐全,培优促中补偏的备考体系成熟完备,复读考取本科的学生超过九成,持续促进了学校教育的高质量发展,正朝着办成粤东名校的目标不断迈进。公司秉承“立足绿色产业,谋划新型能源,融合数据信息,实现智慧管理”的中长期发展规划,聚焦国家“碳达峰、碳中和”政策,围绕可再生能源、地理测绘信息、矿产资源等领域,朝做大做深做强的方向推动企业高质量发展,努力创造更好的经济效益和社会效益回报股东、回报社会。
