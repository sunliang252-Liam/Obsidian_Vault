# 000027.SZ 深度透视

## 因果逻辑链
- **清洁能源装机占比提升至76.48%** -> **营收增长5.38%**: 气电、风电、光伏等新机组投产，推动总发电量同比+12.67%，抵消了煤电收入下滑。
- **环保公司引入50亿战略投资者** -> **筹资现金流大幅改善**: 增资扩股使筹资活动净现金流由-20.27亿转为+54.73亿，现金及等价物净增73.64亿。
- **燃料成本控制与电价结构变化** -> **扣非净利润增长11.03%**: 煤电燃料成本下降，高毛利的气电（毛利率+4.92pct）收入占比提升，有效对冲了电价下行压力。
- **电力市场化交易电量占比升至71.37%** -> **平均上网电价承压**: 市场化电量同比+20.42%，导致综合平均电价从0.55元/千瓦时降至0.52元/千瓦时，压缩了发电利润空间。
- **应收账款高企（142亿）** -> **现金流质量隐忧**: 应收账款占总资产8.26%，主要受新能源补贴回款不确定影响，是经营现金流与净利润差异的重要原因。
- **资产减值损失5.42亿** -> **利润侵蚀**: 对水电等固定资产及商誉计提大额减值，是导致归母净利润增速（4.9%）低于扣非净利润增速（11.03%）的主因。
- **燃气板块销售气量增长19.85%** -> **营收贡献稳定**: 全产业链布局（城燃+贸易+LNG接收站）协同效应显现，气量增长但毛利率仅9.36%，竞争激烈。

## 风险警告
**核心风险：电力市场化改革与新能源全面入市带来的电价下行风险。** 公司71%的电量已参与市场化交易，随着现货市场全覆盖，火电收益面临冲击，新能源电价持续承压。2025年平均电价已从0.55元降至0.52元，未来若容量电价和机制电价体系重构不及预期，将直接侵蚀公司核心利润。

**关键风险：高额应收账款与资产减值压力。** 应收账款高达142亿元，占总资产8.26%，主要来自新能源补贴拖欠，回款时间不确定，严重占用营运资金。同时，公司对水电等资产计提了5.42亿减值，显示部分传统资产盈利能力恶化，未来可能面临持续的资产减值风险。

**结构性风险：燃料价格波动与海外投资环境不确定性。** 天然气采购依赖“三桶油”，价格波动直接影响气电利润（气电是最大利润来源）。海外项目（如加纳）面临地缘政治、政策变动及汇率风险，而公司正加速海外扩张，风险敞口随之扩大。
