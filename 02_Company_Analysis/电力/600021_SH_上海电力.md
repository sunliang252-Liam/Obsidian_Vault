# 600021.SH 深度透视

## 因果逻辑链
- **[燃料成本下降]** -> [归母净利润+35.26%]: 入炉标煤单价同比下降13.10%，直接驱动营业成本下降4.97%，在电价承压背景下实现利润大幅增长。
- **[清洁能源装机扩张]** -> [发电量+1.41%]: 风电(+19.05%)和光伏(+23.58%)发电量高速增长，对冲了火电发电量下滑(-3.71%)，推动总发电量逆势上升。
- **[财务费用压降]** -> [利润总额+24.78%]: 通过债务优化，综合资金成本降至2.51%，财务费用同比减少20.76%，显著增厚利润。
- **[电价下行]** -> [营业收入-2.05%]: 电力市场化交易导致平均电价下降，尽管发电量增长，但收入端承压，凸显“量增价减”的行业困境。
- **[境外业务爆发]** -> [利润贡献提升]: 境外业务利润总额16.68亿元，同比+110.61%，土耳其EMBA等核心资产成为利润增长的重要引擎。
- **[在建工程高投入]** -> [未来增长蓄力]: 在建工程同比+31.68%，六台百万煤电机组及大量新能源项目在建，为2026年后产能释放奠定基础。
- **[永续债融资]** -> [权益结构优化]: 通过永续信托融资补充资本，在降低资产负债率的同时，也导致归母净利润需扣减永续债利息，影响每股收益计算。

## 风险警告
**核心风险在于电价下行与高资本开支的错配。** 电力市场化改革深化，新能源全面入市，公司平均电价持续承压。与此同时，公司正处于大规模基建投资期（在建工程840万千瓦），资本性支出高达205亿元，导致投资活动现金流净流出168.7亿元。若未来电价持续低迷，新增产能的回报率可能不及预期，将侵蚀公司盈利能力。

**海外地缘政治与汇率风险不容忽视。** 公司境外资产占比13%，且集中于土耳其、匈牙利等新兴市场。土耳其里拉等货币的剧烈波动以及地缘政治不确定性，可能对境外资产价值和利润产生重大冲击。公司虽开展套期保值，但无法完全对冲风险。此外，巴基斯坦KE项目终止也暴露了海外投资的潜在风险。
