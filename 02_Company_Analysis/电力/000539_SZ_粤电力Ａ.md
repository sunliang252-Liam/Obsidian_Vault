# 000539.SZ 深度透视

## 因果逻辑链
- **[上网电价同比大幅下降11.60%]** -> [营收下降9.83%]: 电力市场竞争加剧及政策变动，导致含税售电均价从533.16元/千千瓦时降至471.30元/千千瓦时，直接侵蚀收入。
- **[燃料成本同比下降10.20%]** -> [部分对冲电价下行压力]: 燃煤单价同比下降15.81%，燃料成本减少38.28亿元，但未能完全抵消电价下跌对利润的冲击。
- **[新机组集中投产]** -> [折旧与运营成本增加]: 2025年新增装机465.36万千瓦（煤电306万千瓦、光伏99.36万千瓦），固定资产折旧同比增加6.46亿元，拉低整体毛利率。
- **[新能源业务成本上升11.75%]** -> [可再生能源毛利率下降7.13个百分点]: 新投产项目带来折旧和人工成本增加，导致可再生能源发电毛利率从46%降至38.87%。
- **[研发费用归集标准严格化]** -> [研发费用同比骤降55.92%]: 公司对研发费用归集标准进一步严格化和量化，导致研发投入从12.87亿元降至5.67亿元。
- **[高比例长协电价大幅降低]** -> [2026年营收预期承压]: 2026年年度双边协商成交均价372.14元/千千瓦时，同比再降19.73元/千千瓦时，预示未来电价压力持续。
- **[资产负债率77.71%]** -> [财务费用高企]: 高杠杆运营下，尽管融资结构优化，财务费用仍达21.86亿元，对净利润形成显著侵蚀。

## 风险警告
**核心风险：电价下行趋势不可逆，利润空间持续收窄。** 公司营收高度依赖广东省内电力市场，2025年上网电价同比大降11.6%，且2026年年度长协电价进一步下跌5%，表明电价已进入结构性下行通道。公司煤电装机占比仍高达52.34%，在新能源装机超越煤电成为省内第一大电源的背景下，传统火电的定价权和利用小时数均面临长期压制。尽管燃料成本同步下降，但降幅远不及电价跌幅，导致归母净利润同比暴跌37.78%，盈利能力显著恶化。

**财务风险：高负债率与资本开支压力并存。** 公司资产负债率高达77.71%，总负债超1446亿元，财务费用超21亿元。与此同时，在建项目计划装机容量仍达952.1万千瓦，2026年计划投资103.33亿元，持续的大规模资本开支将进一步推高债务规模。在电价下行、利润承压的背景下，高杠杆运营的脆弱性凸显，若燃料价格出现反弹，公司将面临现金流与偿债能力的双重考验。

**公司简介（F10 原文）**

> 广东电力发展股份有限公司(简称:粤电力)于1992年9月8日经广东省人民政府粤府函[1992]20号文及广东省企业股份制试点联审小组、广东省经济体制改革委员会粤股审[1992]54号文批准,由原广东省电力工业总公司、中国建设银行、广东省信托投资公司、广东省电力开发公司、广东国际信托投资公司和广东发展银行发起成立。公司在1993年、1995年分别发行A股、B股,现今为一家同时拥有A、B股的大型电力上市公司。公司主要经营范围是电力项目的投资、建设和经营管理,电力的生产和销售,电力行业技术咨询和服务。公司自成立以来,一直坚持“取资于民,用资于电,惠之于众”的经营宗旨和“办电为主,多元发展”的经营方针,充分发挥证券市场的融资功能,致力于广东省的电力建设。公司专注于电力主业,电源结构呈多元化发展,除从事大型燃煤电厂的开发、建设和运营外,还拥有LNG发电、风力发电和水力发电等清洁能源项目。公司秉承“厚德善能,益邦惠民”的企业文化,经营稳健、运作规范,以优良的业绩给予股东丰厚的回报,在资本市场上树立了良好的企业形象,得到了社会各界的赞誉和认可:自2001年起多次被《财富》杂志评为“中国上市公司100强”;2007年、2008年连续入选“广东上市公司最具成长性10强”;2008年被和讯评为“中国财经风云榜-最佳投资者关系上市公司”。同时,公司还连续多次入选“沪深300”、“深证100”、“中证红利“等重要指数样本股。公司经过持续、快速发展,已成为目前广东省内最大的电力上市公司。
