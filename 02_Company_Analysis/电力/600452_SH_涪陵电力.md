# 600452.SH 深度透视

## 因果逻辑链
- **[节能项目运营期满退出，新建项目增速缓慢]** -> 节能业务收入同比下降10.86%: 前期收购的节能项目陆续到期，而新项目（安徽、周口）尚在建设期，导致节能服务收入从112.7亿降至100.5亿。
- **[节能效益款回收减少]** -> 经营活动现金流净额同比下降41.57%: 节能业务回款周期拉长，导致经营性现金流入大幅减少，从15.9亿降至9.29亿。
- **[计提应收账款信用减值损失同比增加]** -> 信用减值损失从+5159万转为-4299万: 上年同期收回长账龄款项冲回减值，本期无此利好，导致利润进一步承压。
- **[售电量同比增长1.75%，但电价受政策约束]** -> 电力销售收入仅微增0.14%: 区域经济平稳带动电量微增，但电价受国家管控，收入增长空间极为有限。
- **[配电网节能业务采用“共同投资”新模式]** -> 在安徽、河南周口实现项目落地: 公司从单一自有投资转向“共同投资”模式，降低资本压力，探索可复制的业务拓展路径。
- **[国家电网“十五五”规划4万亿投资]** -> 配电网节能改造迎来政策窗口期: 特高压、智能配网投资加码，配电网作为新能源消纳核心载体，节能改造需求升级。
- **[参股企业新嘉南建材经营正常]** -> 按持股比例确认投资收益460.08万元: 非主业股权投资贡献稳定收益，但体量较小，对整体业绩影响有限。

## 风险警告
**核心风险在于业绩双杀：主业增长见顶与节能业务青黄不接。** 电网运营受限于区域垄断和电价管制，售电量增长仅1.75%，收入天花板明显。更严峻的是，配电网节能业务正经历“老项目退出、新项目未成”的断档期，收入同比下降10.86%，直接拖累整体利润下滑23.56%。公司2026年营收计划27.42亿元，较2025年实际值再降8.5%，表明管理层对短期业绩继续承压已有明确预期。

**现金流恶化与信用风险上升构成双重隐患。** 经营活动现金流净额骤降41.57%，主因节能效益款回收困难，这直接导致公司计提了4299万元的信用减值损失。若节能项目回款持续恶化，将进一步侵蚀利润并影响新项目投资能力。同时，公司对关联方（国家电网所属企业）的采购依赖度高达65.24%，关联交易集中度高，存在定价与合规风险。
