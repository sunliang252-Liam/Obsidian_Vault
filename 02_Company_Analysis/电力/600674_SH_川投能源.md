# 600674.SH 深度透视

## 因果逻辑链
- **雅砻江水电投资收益** -> 净利润增长: 持股48%的雅砻江水电贡献投资收益44.25亿元，占利润总额89.89%，是公司最核心的利润来源。
- **银江水电站全面投产** -> 营收与成本双增: 银江电站2-6号机组2025年全面投产，新增控股装机39万千瓦，推动公司发电量增长13.85%，营业收入增长3.65%，但同时也导致营业成本、管理费用和财务费用增加。
- **电力市场化交易占比提升** -> 电价承压: 市场化交易电量占比从76.79%升至84.77%，在电力供大于求背景下，中小水电上网空间被挤压，电价面临下行风险。
- **新能源项目调峰限电** -> 利润下滑: 光伏项目弃光率升高，参股新能源项目出现“增量不增利”现象，对公司盈利造成负面影响。
- **债务结构优化与融资** -> 财务费用控制: 母公司通过发行低利率公司债和中期票据（如1.76%的25川投能源MTN003）置换高息债务，有效控制了财务费用增长。
- **参控股总装机增长** -> 规模优势: 参控股总装机达4071万千瓦，权益装机1898万千瓦，同比增长10.68%，资产规模和装机水平在省属电力上市公司中名列前茅。
- **控股股东重组** -> 治理结构变化: 川投集团与能投集团新设合并成立四川能源发展集团，公司控股股东变更，并出具了避免同业竞争等承诺。

## 风险警告
**核心风险在于对雅砻江水电的过度依赖。** 公司约90%的利润来自持股48%的雅砻江水电一家联营企业，业绩高度集中于单一资产，缺乏分散性。雅砻江的来水情况、电力市场政策、电价波动或任何经营异常，都将直接且剧烈地传导至川投能源的利润表，投资者需警惕这种“一荣俱荣，一损俱损”的集中度风险。

**电力市场化改革与新能源冲击是长期隐忧。** 随着电力市场化交易比例持续攀升（已达84.77%），以及风电、光伏等新能源装机爆发式增长，传统水电的发电空间和上网电价均面临持续挤压。公司已明确提到“现货价格和中长期衔接交易价格持续走低”，且新能源项目“增量不增利”，这一趋势若延续，将侵蚀公司未来的盈利增长潜力。
