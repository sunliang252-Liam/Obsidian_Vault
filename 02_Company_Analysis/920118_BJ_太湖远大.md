# 920118.BJ 深度透视

## 因果逻辑链
- **[行业竞争加剧]** -> [毛利率骤降]: 行业产能扩张导致价格战，公司综合毛利率从9.15%暴跌至6.78%，直接吞噬利润。
- **[募投项目转固]** -> [折旧成本激增]: 数智厂区及超高压项目竣工转固，新增固定资产折旧及运营成本约1,238万元/年，侵蚀利润。
- **[政府补助减少]** -> [其他收益腰斩]: 计入当期损益的政府补助同比减少699万元，叠加先进制造业加计抵减减少349万元，其他收益下降58%。
- **[外销高增长]** -> [对冲内销下滑]: 海外市场开拓成效显著，外销收入同比增长34.4%至2.38亿元，部分弥补了国内市场的价格战损失。
- **[原材料价格下跌]** -> [产品售价承压]: 上游PE、EVA等原材料价格下行，公司产品售价随之调降，导致营收持平但毛利率下滑。
- **[高压产品量产]** -> [打开成长天花板]: 110kV高压绝缘料推向市场，220kV产品检验合格，打破海外垄断，为未来高端化转型奠定基础。
- **[研发投入持续]** -> [产品矩阵完善]: 新增6项发明专利，B1级阻燃、新能源车内高压线等新产品研发成功，拓宽了应用领域。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收15.92亿基本持平，但净利润暴跌63.5%至2572万元，主因是行业价格战导致毛利率从9.15%压缩至6.78%。更严峻的是，募投项目转固后每年新增超1200万元折旧，而高压新产品（110kV/220kV）尚处市场开拓期，短期内难以贡献利润，导致固定成本刚性上升与产品价格下行形成“剪刀差”，盈利能力面临持续压缩。

**现金流与资产质量风险不容忽视。** 公司经营活动现金流净额为-1.81亿元，虽较上年有所改善，但剔除票据贴现后仍为负值。应收账款与应收票据合计占营收比重高达47%，且存货同比大增62.5%。在行业竞争加剧、下游客户回款放缓的背景下，高额的应收类款项和存货面临减值风险，可能进一步侵蚀本已脆弱的利润。
