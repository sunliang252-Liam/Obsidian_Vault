# 600650.SH 深度透视

## 因果逻辑链
- **[宏观环境恶化]** -> [营收与利润双降]: 国际地缘政治紧张导致外资撤离上海，网约车冲击及消费预期转弱，共同压制了公司核心的客运和汽车销售业务。
- **[主动收缩低毛利业务]** -> [扣非净利润降幅远小于营收]: 公司主动减少燃油车销售等低毛利业务规模，牺牲营收以换取利润稳定，体现了“提质增效”的经营策略。
- **[锦海捷亚国际货代业务结构优化]** -> [对冲美线波动]: 通过大力发展欧洲、中东等非美航线（箱量增幅超40%）及空运业务（货量增超15%），有效对冲了美线运输的不确定性，巩固了主业优势。
- **[食品供应链业务增长]** -> [成为新增长点]: 依托“锦大师”品牌和集团餐饮积淀，食品销售业务在福利市场、线上C端等场景实现规模增长，部分弥补了传统业务的萎缩。
- **[持有大量优质金融资产]** -> [提供稳定收益与安全垫]: 公司持有国泰君安、农业银行等大市值上市公司股票，每年贡献稳定分红，并可通过公允价值变动调节利润，是公司财务稳健的重要基石。
- **[参股浦东机场货运站]** -> [获得稳定投资回报]: 作为机场仅有的两个公共货运站之一的股东，每年获得稳定的投资收益（2025年对联营企业投资收益8938万元），是利润的重要来源。
- **[成本控制与费用压缩]** -> [缓解利润下滑压力]: 销售费用同比下降34.24%，管理费用同比下降22.37%，通过业务结构调整和精细化管理，有效对冲了收入下滑对利润的侵蚀。

## 风险警告
公司面临的核心风险在于其传统主业正遭受结构性冲击。客运业务（出租车、商务车）受网约车和外资撤离的双重挤压，搁车率上升，增长空间受限；汽车销售业务则被新能源车替代和价格战所困，公司只能被动收缩。这些核心业务的萎缩趋势短期内难以逆转，构成了公司基本面的最大挑战。

此外，公司利润对投资收益和金融资产公允价值变动依赖度较高。2025年扣非净利润1.32亿，而投资收益高达1.39亿，其中参股的浦东机场货运站贡献了主要部分。一旦机场货运业务或资本市场出现波动，公司利润将面临显著下滑风险。同时，公司持有的巨额金融资产（如国泰君安股票）虽提供安全垫，但其价值波动也直接冲击净资产和利润。
