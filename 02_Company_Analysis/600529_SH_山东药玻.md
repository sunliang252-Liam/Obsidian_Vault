# 600529.SH 深度透视

## 因果逻辑链
- **[下游集采降价压力传导]** -> [营收与利润双降]: 医改集采深化，下游药企控制成本，将降价压力向上游药包材转移，导致公司2025年营收同比下降8.78%，归母净利润同比下降26.87%。
- **[供强需弱，行业竞争加剧]** -> [核心产品销量下滑]: 模制瓶、棕色瓶等核心产品面临同行业产能扩张和激烈竞争，导致模制瓶系列销量同比下降11.79%，棕色瓶系列销量同比下降4.43%。
- **[下游需求疲软与库存积压]** -> [存货大幅增加，资产减值损失激增]: 收入下降导致库存商品积压，存货较年初增加32.61%，同时计提存货跌价损失及在建工程减值损失，使资产减值损失同比增加156.54%。
- **[原材料及能源成本下降]** -> [毛利率基本稳定]: 主要原材料石英砂、纯碱、煤炭价格下降，部分对冲了收入下滑的影响，使公司整体毛利率同比增加0.16个百分点，核心产品模制瓶毛利率提升1.15个百分点。
- **[海外市场拓展与品牌优势]** -> [出口业务逆势增长]: 凭借产品质量、规模及配套优势，积极开拓海外化妆品、营养补充剂包装等新兴品类，实现国外营收同比增长1.98%，成为业绩的重要支撑。
- **[精益管理与成本控制]** -> [经营韧性增强]: 通过“十四种采购方法”、精益生产、自动化升级等措施，有效控制成本，在行业下行周期中保持了盈利能力和现金流的基本稳定。
- **[关联审评与政策壁垒]** -> [客户粘性高，渠道优势稳固]: 药包材与药品关联审评审批制度下，客户更换供应商成本高，公司凭借与众多大型药企的长期合作关系，构筑了稳固的护城河。

## 风险警告
**核心风险在于下游需求持续萎缩与行业竞争加剧的双重挤压。** 公司2025年营收和利润双双大幅下滑，核心产品销量全面下降，存货激增，资产减值损失飙升，表明行业已进入供过于求的激烈竞争阶段。若下游医药行业景气度持续低迷，集采降价压力进一步传导，公司可能面临销量与价格的双杀，盈利能力存在进一步恶化的风险。

**另一个关键风险是公司增长动能的缺失。** 尽管出口业务有所增长，但体量尚不足以完全对冲国内市场的下滑。公司寄予厚望的“中硼硅模制瓶”和“预灌封注射器”等新增长点，面临同行业企业（如力诺药包）的激烈竞争，产能释放和市场拓展存在不确定性。同时，公司研发投入虽增加，但研发人员结构以高中及以下学历为主，高端人才储备不足，可能制约长期技术升级和产品迭代。
