# 600831.SH 深度透视

## 因果逻辑链
- **[传统有线电视用户加速流失]** -> [营业收入同比下滑28.68%]: 用户向IPTV、移动互联网迁移，导致收视费、数据业务等核心收入持续萎缩。
- **[应收账款信用减值损失激增]** -> [净利润巨亏14.99亿元]: 因政企客户回款周期长、资金紧张，计提应收账款坏账准备6.65亿元，同比翻倍，成为亏损主因。
- **[刚性成本费用居高不下]** -> [有线电视业务毛利率转负]: 固定资产折旧、人工成本等固定支出降幅远小于收入降幅，导致传统业务出现-3.46%的毛利率。
- **[广电5G用户规模突破百万]** -> [新业务收入稳步增长]: 5G业务成为唯一增长亮点，但收入体量尚小，无法弥补传统业务下滑缺口。
- **[主动压降回款周期长的项目]** -> [商品销售、工程施工收入大幅萎缩]: 为控制资金风险，公司主动收缩高风险、低效益的集客项目，导致收入结构被动调整。
- **[“清网行动”与降本增效]** -> [经营活动现金流净额同比改善12.89%]: 通过回收设备、压降电费、优化融资成本，在收入下滑背景下实现了正向现金流的增长。
- **[子公司“关停并转”]** -> [少数股东损益亏损减少]: 对亏损子公司进行注销、停运，减少了合并报表层面的亏损拖累。

## 风险警告
公司正陷入“传统业务失血、新业务造血不足”的恶性循环。核心风险在于，有线电视用户流失是结构性、不可逆的，而广电5G、云网等新业务在激烈竞争中尚未形成规模效应和盈利模式，新旧动能转换出现“断档”。2025年巨亏14.99亿元，净资产已从20.73亿骤降至5.42亿，资产负债率高达94.5%，财务安全垫极其薄弱。

第二大风险是资产质量恶化。应收账款余额高达29.87亿元，坏账准备计提12.38亿元，但清收难度极大，且政企项目回款周期长、定制化要求高，未来仍有大规模减值风险。同时，公司背负超过29亿元的一年内到期非流动负债，短期偿债压力巨大。在盈利能力未恢复前，任何融资渠道的收紧都可能引发流动性危机。
