# 600728.SH 深度透视

## 因果逻辑链
- **[“鸿蒙+AI”双核技术驱动]** -> [营收增长27.42%]: 发布交通行业首个国产操作系统“交通佳鸿”，迭代知行交通大模型3.0，技术产品化推动智慧交通解决方案规模化落地，带动营收突破百亿。
- **[战略投资补齐产业链短板]** -> [归母净利润扭亏为盈]: 通过投资佳都微联（信号系统）、凯发电气（供电系统）等，补全轨道交通核心环节，形成全产业链闭环，提升一体化解决方案竞争力，驱动主业盈利改善。
- **[对外投资市值回升]** -> [非经常性损益贡献1.15亿]: 持有的人工智能上市企业（云从科技）股价上涨，形成公允价值变动收益，成为净利润扭亏的关键非经营性因素。
- **[企业数智化升级业务扩张]** -> [营收结构向低毛利分销倾斜]: 该业务收入71.85亿元（+31.57%），但毛利率仅3.91%，拉低整体毛利率，显示公司为扩大规模而主动承接低利润分销业务。
- **[为锁定货源加大采购]** -> [经营性现金流大幅转负]: 为保障ICT产品供应，大幅增加采购预付款，同时适度调整客户结算安排，导致经营活动现金流净额-5.12亿元，现金循环周期拉长。
- **[属地化经营网络深化]** -> [智慧城市交通管理业务高增]: 聚焦大湾区等根据地市场，IDPS城市交通大脑及信控产品成功落地，该业务收入同比增长71.89%，毛利率提升12.92个百分点。
- **[研发投入资本化率高]** -> [短期利润平滑，长期摊销压力]: 研发投入2.99亿元，资本化比例高达63.87%，此举虽减少当期费用，但未来将形成较大摊销，影响后续利润表现。

## 风险警告
**核心风险在于盈利质量与现金流严重背离。** 公司2025年归母净利润1.74亿元，但扣非净利润仅0.28亿元，且经营性现金流净流出5.12亿元。利润主要依赖对外投资（云从科技）的公允价值变动，主业盈利能力依然薄弱。同时，为支撑低毛利的数智化分销业务扩张，公司大幅增加采购垫资，导致现金流急剧恶化，这种“增收不增利、增利不增现”的模式不可持续，一旦市场环境或客户回款节奏变化，将引发流动性危机。

**另一重大风险是供应商集中度极高与募投项目持续延期。** 前五大供应商采购额占比高达75.91%，其中单一供应商占比65.25%，存在供应链中断或议价能力被削弱的隐患。同时，公司核心募投项目（数字孪生、新一代轨交系统等）进度严重滞后，投入进度仅21%-29%，并再次延期至2027年底。这反映出公司技术研发与产业化落地效率低于预期，若不能有效突破，将削弱其在“鸿蒙+AI”赛道上的先发优势，并面临募集资金使用效率低下的监管压力。
