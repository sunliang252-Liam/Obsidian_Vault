# 600463.SH 深度透视

## 因果逻辑链
- **[建筑施工业务持续亏损]** -> [公司整体净利润为负]: 子公司天源建筑因行业下行、竞争加剧，2025年亏损1.05亿元，是公司亏损的最大拖累。
- **[收购天利动力供热业务]** -> [新增收入与利润增长点]: 2025年1月并表，贡献收入1.77亿元，净利润261万元，部分对冲了建筑施工业务的亏损。
- **[建筑施工收入大幅下降]** -> [营业收入同比减少15.69%]: 开复工面积小于同期，导致该板块收入同比下滑31.71%，是总收入下降的主因。
- **[产业载体出租率维持70%]** -> [租赁业务收入稳定]: 可出租面积约23.93万平米，出租率稳定，租赁收入同比微增1.05%，毛利率50.31%。
- **[公允价值变动损失]** -> [侵蚀利润]: 持有的私募基金公允价值变动损失842.71万元，直接计入当期损益，加剧了净利润的亏损。
- **[信用减值损失高企]** -> [利润进一步承压]: 计提信用减值损失4040万元，主要来自建筑施工板块应收款项回收风险，是除主业亏损外的第二大利润侵蚀因素。
- **[筹划出售天源建筑80%股权]** -> [战略收缩与资产优化]: 拟剥离亏损核心资产，聚焦园区运营与供热服务，但交易因核心条款未达成一致而延期。

## 风险警告
**核心风险在于建筑施工业务的持续失血与资产剥离的不确定性。** 子公司天源建筑已资不抵债（净资产-8245万元），且2025年亏损超1亿元，是公司连续亏损的根源。公司虽已筹划将其出售给控股股东，但交易因核心条款未达成一致而延期，若最终失败，公司将继续背负这一沉重包袱，现金流与盈利能力将持续恶化。

**流动性风险与关联方依赖度极高。** 公司经营活动现金流净额为-3546万元，回款能力恶化。为维持运营，公司大量依赖控股股东空港开发的关联借款（天源建筑借款余额达4.94亿元），并频繁为子公司提供担保。这种高度依赖关联方的融资模式，一旦控股股东支持意愿或能力发生变化，公司将面临严峻的资金链断裂风险。
