# 605179.SH 深度透视

## 因果逻辑链
- **[大客户战略与OEM转型]** -> [营收增长5.55%]: 直销渠道（+23.78%）和线上销售（+36.30%）成为主要增量引擎，B端大客户定制化业务（如盒马、认养一头牛）贡献显著。
- **[精益生产与IPS节拍制]** -> [净利润增长76.87%]: 生产效率提升10%、不良率下降30%，叠加管理费用压缩14.77%，成本端优化直接增厚利润。
- **[“新鲜配”当日配送模式]** -> [短保产品竞争力]: 核心产品实现“当天生产、当天到店”，强化了“新鲜健康”品牌定位，支撑了高复购率。
- **[场景化营销与大单品策略]** -> [门店客流与客单价提升]: 聚焦“营养早餐”等四大场景，成功孵化A2牛乳、见轻酸奶等爆品，带动用户增长与连带消费。
- **[加盟为主、直营补充的扩张模式]** -> [门店网络稳健扩张]: 加盟店净增94家至1565家，直营店优化至444家，以轻资产模式实现市场下沉，同时控制资本开支。
- **[电商与即时零售渠道拓展]** -> [线上业绩增长36.3%]: 抖音本地生活、京东外卖等新渠道合作，以及私域流量运营，为线下门店引流并开辟第二增长曲线。
- **[供应链市场化OEM转型]** -> [大客户粘性增强]: 实现大客户新品开发参与度100%，新品上市周期大幅缩短，从内部保供单元转变为外部价值创造中心。

## 风险警告
**核心风险在于毛利率持续承压与区域市场依赖。** 2025年主营业务毛利率下降2.69个百分点，其中烘焙品类毛利率下滑3.44个百分点，其他食品（米制鲜食等）毛利率更是骤降9.77个百分点。这反映出原材料成本上涨（外购成本同比+58.96%）与产品结构变化（低毛利品类占比提升）的双重挤压。公司营收高度集中于华东地区（占比95%），跨区域扩张（安徽、江西）仍处于培育期，若该区域消费疲软或竞争加剧，业绩将受重大冲击。

**食品安全与消费趋势变化是长期悬顶之剑。** 公司产品以短保食品为主，全链条品控（从奶源到门店）的任何疏漏都可能导致品牌声誉的毁灭性打击。同时，消费升级与降级并存，若公司未能持续推出符合“质价比”趋势的新品，或未能及时适应渠道变革（如即时零售的进一步渗透），现有爆品红利可能快速消退，导致库存积压和门店亏损。
