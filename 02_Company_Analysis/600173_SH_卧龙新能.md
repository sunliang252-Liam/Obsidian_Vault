# 600173.SH 深度透视

## 因果逻辑链
- **国家政策推动新能源发展（136号文、能源法）** -> 公司战略转型聚焦风光储氢: 政策明确支持新型储能纳入容量电价、氢能纳入能源管理，公司顺势加大新能源投入
- **公司战略转型聚焦风光储氢** -> 新能源业务收入增长但储能毛利率下降: 转型带来新能源收入整体增加，但储能业务国内竞争激烈导致毛利率下滑
- **房地产市场深度调整** -> 房地产业务收入及毛利率双降: 行业整体下行，销售面积和金额同比下降，公司加快去库存但盈利承压
- **出售上海矿业股权** -> 矿产贸易业务收入和成本大幅减少: 置出上海矿业后不再从事铜精矿贸易，导致营收和成本同步下降
- **同一控制下企业合并收购新能源子公司** -> 资产负债表科目大幅变动（在建工程、长期借款增加）: 收购龙能电力、卧龙储能等公司导致合并范围扩大，项目投资增加
- **国补资金及时下发** -> 光伏业务现金流改善，毛利率提升: 太阳能发电补贴资金到位，改善电站运营现金状况，提升盈利能力
- **氢能技术突破和海外市场拓展** -> 氢能产品营收和毛利率大幅增长: AEM制氢设备实现兆瓦级交付，海外收入占比高，推动业绩爆发
- **储能业务国内竞争加剧** -> 储能业务营业收入大幅下降: 国内市场竞争激烈，公司主动收缩国内业务，海外订单尚在储备期
- **出售上海矿业产生投资收益** -> 投资收益大幅增加: 出售子公司股权确认一次性投资收益
- **长期股权投资减值（君海网络）** -> 资产减值损失大幅增加，净利润亏损: 君海网络经营下滑导致计提减值准备，叠加其他减值，拖累利润

## 风险警告
公司面临多重风险：1）房地产深度调整持续，去库存压力大，相关子公司亏损严重（两湖置业、耀江神马亏损超8000万）；2）新能源业务中储能竞争白热化，毛利率仅8.71%，且库存激增332%，存在进一步减值风险；3）氢能虽爆发但基数小，海外依赖度高，地缘政治或影响订单；4）资产负债率上升，长期借款和应付票据大幅增加，偿债压力加大；5）联营企业君海网络持续下滑，存在进一步减值可能；6）公司整体净利润亏损1.87亿，依赖非经常性收益（出售矿产）扭亏不可持续。
