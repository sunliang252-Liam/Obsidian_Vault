# 600362.SH 深度透视

## 因果逻辑链
- **全球铜矿供给减少，加工费TC为负** -> 铜价高位运行，年均价上涨7.52%: 铜矿供给短缺导致冶炼加工费TC降至负值，反映原料紧张，支撑铜价上涨。
- **铜价高位运行** -> 存货及期货保证金大幅增加: 铜价上涨导致存货价值增加，同时套期保值等衍生品交易需缴纳更多保证金。
- **铜价高位运行及存货增加** -> 经营活动现金流大幅净流出: 存货资金占用增加导致经营活动现金流出大于流入。
- **铜价高位运行及跨市套利** -> 公允价值变动损益大幅亏损: 铜价波动及期现价差变化导致衍生品头寸公允价值变动产生损失。
- **自产铜精矿含铜产量增加** -> 工业及其他非贸易收入毛利率提升: 自有矿山产量增加降低了对外部高价原料的依赖，从而提升盈利。
- **研发投入及项目增加** -> 研发费用同比增长26.56%: 公司加大科技创新投入，研发活动增加导致费用上升。
- **铜加工行业竞争加剧及铜价高位** -> 铜杆线产量下降，加工产品毛利率偏低: 传统铜加工产能过剩，铜价高位挤压加工利润，导致部分产品减产。

## 风险警告
公司面临多重风险：1）公允价值变动损益大幅亏损（-25亿元），反映套期保值及衍生品交易风险较高；2）经营活动现金流由正转负（-69亿元），存货和保证金占用资金压力大；3）铜加工业务毛利率普遍偏低，产能过剩和竞争加剧可能进一步压缩利润；4）铜价高位导致下游需求受抑制，库存累积（阴极铜库存增加49.73%），未来价格回调可能带来存货减值风险；5）衍生金融负债大幅增加（1,104.76%），表明投机或套保头寸风险敞口扩大。
