# 300740.SZ 深度透视

## 因果逻辑链
- **双业务多品牌布局与高端化战略聚焦** -> 自有品牌收入同比增长26.97%，毛利率78.20%: 公司聚焦高端品牌建设，EDB、RV、PA等高奢品牌势能放大，带动自有品牌营收及毛利率提升
- **研发赋能品牌（全球研发网络、原料创新、配方技术）** -> 高端品牌产品力提升，大单品持续热销: 五大研发中心、新原料备案、专利技术等支撑高端品牌产品升级，如EDB超级面膜、RV多肽等，增强产品竞争力
- **数字赋能组织（数字化系统、AI应用）** -> 运营效率提升与销售增长: 数字化覆盖全链路，AI重构内容创作、客服等场景，提升投放效率和舆情响应速度，降低决策成本
- **行业K型分化与消费修复** -> 公司高端品牌受益，大众品牌增长稳定: 高端护肤扩容更快，公司高奢品牌（EDB、RV等）契合趋势，大众品牌（御泥坊、小迷糊）通过差异化维持增长
- **全球化布局（品牌、研发、供应链、渠道）** -> 境外收入同比增长25.90%，占比提升: EDB全球网点拓展，RV北美线下、电商高增，PA海外回温，推动境外业务快速增长
- **销售费用增长24.12%** -> 线上渠道收入增长（抖音自营+21.70%）: 加大推广投放，尤其在抖音等平台，驱动线上自营渠道收入增长
- **CP品牌矩阵布局（3LAB、Sarah Chapman、AMOUAGE等）** -> 品牌管理服务收入同比增长7.35%: CP品牌通过水羊国际平台运营，贡献品牌管理服务收入
- **研发费用增长34.52%** -> 新原料与技术创新成果（雪莲愈伤组织、黑参精粹等）: 持续增加研发投入，推动新原料备案、专利和学术成果

## 风险警告
行业竞争激烈，流量与价格战持续；销售费用率较高，若收入增长不及预期可能侵蚀利润；原材料成本上涨及汇率波动风险；CP品牌代理业务依赖供应商稳定性；线上渠道集中度高，平台政策变化可能影响业绩。
