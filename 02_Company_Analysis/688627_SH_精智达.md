# 688627.SH 深度透视

## 因果逻辑链
- **[半导体存储测试设备业务高速增长]** -> [营收增长40.46%]: 存储测试设备收入同比增长151.31%，首次超越AMOLED检测业务，成为业绩核心引擎。
- **[9Gbps高速FT测试机交付]** -> [技术壁垒突破]: 首台自主研发高速FT测试机交付客户，标志公司在高端存储测试领域实现从0到1的突破，为后续18Gbps产品及高端市场渗透奠定基础。
- **[股份支付费用大幅增加]** -> [归母净利润同比下降18.39%]: 营收高增但利润下滑，主因是股权激励及员工持股计划产生的股份支付费用，剔除该影响后净利润同比增长4.75%。
- **[研发投入持续高增（+66.94%）]** -> [长期护城河构建]: 研发费用占营收比达16.23%，聚焦HBM、算力芯片、18Gbps高速测试等前沿领域，以高投入换取未来高端市场的竞争位势。
- **[客户集中度极高（前五大客户占93.19%）]** -> [经营风险高度集中]: 业绩高度依赖少数头部客户（如第一大客户占比超50%），单一客户订单波动或合作关系变化将直接冲击公司营收与利润。
- **[海外XR检测业务突破]** -> [第二增长曲线显现]: XR检测相关产品海外收入首次大幅增长，成功切入海外头部AR/VR终端供应链，开辟了除存储和显示之外的新增量市场。
- **[存货跌价准备占比较高（9.82%）]** -> [资产减值风险]: 存货规模随业务扩张而增长，若下游客户验收延迟或产品技术迭代导致存货呆滞，将面临持续的资产减值压力。

## 风险警告
**客户极度集中与盈利质量的双重风险。** 前五大客户销售额占比高达93.19%，其中单一客户占比超50%，公司业绩与少数头部存储及面板厂商的资本开支计划深度绑定。一旦主要客户产线投资放缓或转向其他供应商，公司营收将面临断崖式下跌。同时，归母净利润同比下降18.39%，而剔除股份支付影响后仅微增4.75%，表明公司真实盈利能力并未随营收高增而同步提升，高增长背后是高昂的激励成本与潜在的盈利瓶颈。

**技术迭代与市场竞争的“红海”风险。** 公司所处的半导体测试设备高端市场由爱德万、泰瑞达等国际巨头垄断（合计市占率约80%），公司虽在部分环节实现突破，但整体仍处于追赶阶段。为维持竞争力，公司需持续高强度研发投入（研发费用率16.23%），若18Gbps高速测试机、HBM测试设备等关键产品研发或客户验证不及预期，前期巨额投入将难以收回。此外，国内竞争对手也在快速成长，市场竞争加剧可能导致产品毛利率承压，侵蚀公司本就微薄的利润空间。
