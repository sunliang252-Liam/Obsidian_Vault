# 002695.SZ 深度透视

## 因果逻辑链
- **[鸭副产品原料价格低位]** -> [毛利率提升]: 鸭脖、鸭翅等核心原料采购价同比大幅下降（鸭颈-45.37%），直接降低酱卤制品直接材料成本，支撑毛利率稳定。
- **[费用端强力收缩]** -> [净利润翻倍]: 销售费用同比-30.19%（人工、促销费缩减），管理费用同比-15.94%（股权激励费用冲回），费用率大幅下降，利润弹性释放。
- **[并购福建立兴]** -> [新增利润增长极]: 2025年8月收购冻干龙头立兴食品51%股权，9-12月并表贡献营收1.76亿、归母净利润1,443万元，成为利润增长新引擎。
- **[酱卤主业量价承压]** -> [营收微降]: 酱卤制品销量-16.59%、收入-17.40%，核心主业收缩拖累整体营收同比-3.19%。
- **[门店扩张放缓与单店下滑]** -> [加盟收入萎缩]: 加盟模式收入同比-17.88%，反映终端门店客流承压、单店产出下降。
- **[米制品业务稳健]** -> [收入基本持平]: 米制品收入同比-0.73%，销量+4.54%，在酱卤主业下滑时起到稳定器作用。
- **[数字化与智能制造投入]** -> [长期效率提升]: 推进无人卤煮、AGV、营销中台等项目，旨在提升生产与运营效率，但短期尚未完全释放效益。

## 风险警告
**核心风险在于酱卤主业增长乏力。** 报告期酱卤制品销量、收入双位数下滑，加盟渠道收入萎缩近18%，显示终端动销疲软。公司虽通过成本红利和费用压缩实现利润翻倍，但这种“降本增效”的利润增长模式可持续性存疑，一旦原料价格回升或费用刚性反弹，利润将面临巨大压力。

**并购整合与商誉减值风险不容忽视。** 公司以近5亿元收购福建立兴，形成大额商誉。立兴食品虽首年完成业绩承诺（扣非净利润7,749万元），但后续三年业绩承诺能否持续兑现存在不确定性。若整合不及预期或行业竞争加剧，商誉减值将直接冲击利润表。同时，新业务与原有卤味渠道的融合（如产品陈列、消费者画像错位）仍在探索中，协同效应释放尚需时日。
