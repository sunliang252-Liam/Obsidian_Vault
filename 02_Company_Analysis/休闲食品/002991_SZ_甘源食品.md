# 002991.SZ 深度透视

## 因果逻辑链
- **[经销渠道收入大幅下滑]** -> [总营收下降7.15%]: 经销模式收入同比-17.74%，占总营收75.62%，是营收下滑的主因，核心产品综合果仁及豆果系列销量同比-27.41%。
- **[销售费用激增]** -> [净利润暴跌44.59%]: 销售费用同比+29.51%，其中促销推广费+55.86%、广告费新增793.6万元，但未能有效拉动收入，导致利润被严重侵蚀。
- **[电商渠道高增长]** -> [结构性对冲经销下滑]: 电商模式收入同比+35.77%，毛利率提升至43.37%，成为唯一增长引擎，但体量仅占15.49%，无法完全弥补经销渠道的萎缩。
- **[员工持股计划解锁失败]** -> [费用确认减少]: 因2024年业绩考核未达标，员工持股计划解锁条件未成就，导致股份支付费用同比减少216.8万元，对利润有微弱的正面影响。
- **[研发人员先行扩张]** -> [短期费用滞后，长期蓄力]: 研发人员同比+40.52%，但研发费用仅-5.70%，呈现“人员增长先行、费用投入滞后”特征，为新品开发储备人力。
- **[原材料成本下降]** -> [毛利率相对稳定]: 直接材料成本同比-9.30%，部分对冲了收入下滑对毛利的影响，使整体毛利率仅微降0.87个百分点。
- **[募投项目变更]** -> [产能扩张节奏调整]: 将“营销网络升级及品牌推广项目”部分资金（1.01亿）变更用于“第六期生产建设项目”，显示公司战略重心从渠道投入转向产能建设。

## 风险警告
**核心风险在于“增收不增利”的恶化趋势。** 2025年营收仅下滑7.15%，但净利润却暴跌44.59%，主要原因是销售费用率从12.7%飙升至17.7%。公司为应对渠道竞争（尤其是零食量贩店等新兴渠道）大幅增加促销推广和品牌广告投入，但投入产出比极低，未能有效阻止经销渠道的萎缩。若该趋势持续，公司将陷入“不投入则份额丢失，投入则利润承压”的两难境地。

**第二大风险是核心产品线的衰退。** 占营收27.37%的“综合果仁及豆果系列”销量同比下滑27.41%，生产量更是下滑31.99%，表明该品类面临严重的需求萎缩或竞争替代。同时，公司2022年员工持股计划因业绩不达标而全部解锁失败，反映出内部增长预期与现实的巨大落差，可能影响核心团队的稳定性与积极性。
