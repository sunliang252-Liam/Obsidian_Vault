# 002847.SZ 深度透视

## 因果逻辑链
- **[魔芋品类爆发]** -> [营收增长107%]: 大魔王品牌与六必居联名、王一博代言，叠加健康零食需求爆发，魔芋零食成为第一增长极。
- **[全渠道精耕]** -> [线下渠道营收增长16.79%]: 经销商数量扩张22%，量贩渠道（鸣鸣很忙）与会员店（山姆）双线渗透，渠道宽度转化为份额深度。
- **[主动收缩低毛利电商]** -> [线上营收下降20.5%，但毛利率提升0.94%]: 战略性放弃低效SKU，回归“供应链电商”本质，盈利质量改善。
- **[核心原料自产化]** -> [成本优势与品质壁垒]: 蛋皇纪鹌鹑养殖基地、魔芋精粉产线、马铃薯全粉基地向上游延伸，对冲原料价格波动。
- **[股权激励绑定]** -> [人效与业绩共振]: 多期限制性股票激励计划覆盖核心团队，2025年管理费用下降12.93%，销售费用下降8.71%。
- **[海外布局起步]** -> [海外营收增长172%]: 泰国、越南子公司设立，魔芋品类以自有品牌“Mowon”进入东南亚，为全球化奠基。
- **[烘焙品类收缩]** -> [营收下降22.43%]: 主动调整产品结构，资源向高增长魔芋、蛋制品倾斜，烘焙品类进入存量优化期。

## 风险警告
**核心风险：魔芋单品依赖与原料价格波动。** 魔芋零食营收占比从15.81%飙升至30.15%，成为绝对增长引擎。但魔芋精粉采购均价同比上涨超30%，虽因期初库存缓冲了当期成本，若原料价格持续高位或供给端气候扰动，将直接侵蚀毛利率。大魔王品牌成功高度依赖营销投入（王一博代言、联名六必居），若消费者偏好转移或竞品模仿，单品势能可能快速衰减。

**渠道结构失衡与食品安全隐患。** 前五大客户销售占比42.81%，其中客户一（推测为鸣鸣很忙）占比30.85%，对单一量贩渠道依赖度极高。量贩渠道议价能力强，若合作条件恶化或渠道自身经营波动，将冲击收入稳定性。此外，休闲食品行业集中度低，若行业爆发重大食品安全事故（如原料污染、添加剂违规），将波及公司品牌声誉，尽管公司自建检测体系，但全链条风险难以完全规避。
