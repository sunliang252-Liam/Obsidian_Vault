# 002847.SZ 深度透视

## 因果逻辑链
- **[魔芋品类爆发]** -> [营收增长107%]: 大魔王品牌与六必居联名、王一博代言，叠加健康零食需求爆发，魔芋零食成为第一增长极。
- **[全渠道精耕]** -> [线下渠道营收增长16.79%]: 经销商数量扩张22%，量贩渠道（鸣鸣很忙）与会员店（山姆）双线渗透，渠道宽度转化为份额深度。
- **[主动收缩低毛利电商]** -> [线上营收下降20.5%，但毛利率提升0.94%]: 战略性放弃低效SKU，回归“供应链电商”本质，盈利质量改善。
- **[核心原料自产化]** -> [成本优势与品质壁垒]: 蛋皇纪鹌鹑养殖基地、魔芋精粉产线、马铃薯全粉基地向上游延伸，对冲原料价格波动。
- **[股权激励绑定]** -> [人效与业绩共振]: 多期限制性股票激励计划覆盖核心团队，2025年管理费用下降12.93%，销售费用下降8.71%。
- **[海外布局起步]** -> [海外营收增长172%]: 泰国、越南子公司设立，魔芋品类以自有品牌“Mowon”进入东南亚，为全球化奠基。
- **[烘焙品类收缩]** -> [营收下降22.43%]: 主动调整产品结构，资源向高增长魔芋、蛋制品倾斜，烘焙品类进入存量优化期。

## 风险警告
**核心风险：魔芋单品依赖与原料价格波动。** 魔芋零食营收占比从15.81%飙升至30.15%，成为绝对增长引擎。但魔芋精粉采购均价同比上涨超30%，虽因期初库存缓冲了当期成本，若原料价格持续高位或供给端气候扰动，将直接侵蚀毛利率。大魔王品牌成功高度依赖营销投入（王一博代言、联名六必居），若消费者偏好转移或竞品模仿，单品势能可能快速衰减。

**渠道结构失衡与食品安全隐患。** 前五大客户销售占比42.81%，其中客户一（推测为鸣鸣很忙）占比30.85%，对单一量贩渠道依赖度极高。量贩渠道议价能力强，若合作条件恶化或渠道自身经营波动，将冲击收入稳定性。此外，休闲食品行业集中度低，若行业爆发重大食品安全事故（如原料污染、添加剂违规），将波及公司品牌声誉，尽管公司自建检测体系，但全链条风险难以完全规避。

> 盐津铺子食品股份有限公司(以下简称“公司”)成立于2005年,是一家从事食品研发、生产、销售于一体的集团公司,旗下拥有湖南盐津铺子食品有限公司、江西盐津铺子食品有限公司、广西盐津铺子食品有限公司、湖南盐津铺子电子商务有限公司等全资、控股子公司。公司秉承“匠心传承,创新引领,成就卓越”的企业精神,聚焦食品主业,诚信经营,持续耕耘,在产品研发、生产制造、品质保障、渠道精耕、品牌传播等方面达到了行业领先水平,是中国休闲食品领域、农产品加工领域的知名龙头企业。2017年2月8日,公司在深圳证券交易所A股中小企业板上市(证券代码:002847,证券简称:盐津铺子),被媒体誉为“休闲零食自主制造第一股”。公司遵循“绿色、健康、美味”的产品理念,创建了产学研深度融合的技术创新体系和“实验室+工厂”的研发机制,以具有地方特色的凉果蜜饯产品发轫,推陈出新,主动引领休闲食品升级,形成四大产品体系,即:以鱼豆腐、豆干、蜜饯炒货、素食、薯片为代表的“休闲零食”类产品;以面包、蛋糕为代表的“休闲短保烘焙”类产品;无人工防腐剂添加的高端休闲面制品“辣条”类产品;以东南亚优质水果为原料的果干、冻干系列产品。健康的产品配方和工艺,口感出众的产品特性,丰富的产品线结构,铸造了产品的品牌和影响力,产品行销全国市场。“盐津铺子”商标被国家工商总局认定为“中国驰名商标”。公司秉持“好零食,盐津造”的品牌理念,持续不断推进企业的工艺、设备、管理升级,不断完善“研发、供应、生产、销售”产业链,实现了食品智能制造转型,形成了四大基地争相辉映的发展格局。湖南盐津铺子浏阳生产基地生产休闲零食、休闲短保烘焙两大系列产品,烘焙生产中心拥有10条智能化的烘焙生产线,年产能达4万多吨;江西盐津铺子修水生产基地主产休闲零食鱼豆腐、豆干、辣条系列产品;广西盐津铺子凭祥生产基地依托东南亚优质水果原料优势,生产芒果干、榴莲冻肉、冻干系列产品;2019年,河南盐津铺子漯河生产基地休闲短保烘焙项目正式启动。公司恪守“品质、信誉、服务”的经营理念,建成了覆盖全国的全渠道营销体系。线下渠道以“做品牌零食终端方案解决者”为己任,以“直营商超主导、经销商跟随,新零售覆盖”理念搭建网络,在全国建有50多个办事处及物流分仓,与沃尔玛、大润发、麦德龙等2000余家国际国内大型连锁商超卖场的进行直营合作,强大的经销商网络和新零售平台,形成了多层次、广覆盖、高效率的立体营销网络;电商渠道通过天猫、京东、唯品会等众多电商平台,与消费者建立了紧密的互动,在细分品类取得领导地位;电商新零售呈现迅猛发展态势,活跃粉丝近千万,“盐津铺子”产品深受广大消费者喜爱。未来,盐津铺子公司将以“人才战略”为基石,全力推进“品牌营销”战略、“研发创新”战略、“智能制造升级”战略,计划通过三年时间,成为休闲零食、休闲短保烘焙行业领导者!致力于成为中国卓越的食品制造企业,盐津铺子任重道远、大有可为!
