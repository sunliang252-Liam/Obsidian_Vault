- **消费市场呈现“K型分化”，消费者追求性价比** -> 卤味行业同质化竞争加剧，新零售渠道冲击传统卤味渠道: 外部环境导致行业竞争格局恶化

- **公司卤制食品销售收入下降** -> 公司整体营业收入下降12.62%: 卤制食品销售是公司最主要收入来源
- **营业收入下降** -> 毛利率同比下降0.7个百分点: 收入下降导致固定成本分摊上升，成本费用率提高
- **营业收入下降** -> 经营活动现金流量净额下降29.72%: 经营利润减少导致经营现金流缩减

- **门店调改及渠道协同投入** -> 研发费用增加2.96%: 数字化与新产品开发投入增加
- **市场竞争激烈，广告宣传效率下降** -> 销售费用减少18.06%: 公司主动削减广告宣传支出以控制费用
- **公司回购股份并注销2亿元** -> 优化资本结构，维持市场信心: 回购注销提升每股收益，传递积极信号
- **商誉减值及其他资产减值损失** -> 净利润亏损扩大: 资产减值损失大幅增加，直接侵蚀利润

## 风险警告
公司当前处于转型调整期，面临消费需求分化、行业竞争加剧、新零售渠道冲击等多重压力。营业收入和毛利率持续下滑，导致2025年出现亏损。尽管公司通过控制广告费用、优化门店模型、加强供应链等措施应对，但转型效果尚需时间验证。商誉及资产减值风险较高，短期经营现金流承压。若消费环境未见明显改善或转型不及预期，公司业绩可能继续恶化。
