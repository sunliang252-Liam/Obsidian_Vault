# 603719.SH 深度透视

## 因果逻辑链
- **[门店结构优化，淘汰低效门店]** -> [营收下降23.38%]: 主动关闭719家低效门店，直营与加盟门店净减少597家，直接导致线下销售收入大幅下滑。
- **[产品售价下调及结构优化]** -> [毛利率下降1.28个百分点]: 为应对市场竞争，部分产品降价，同时产品结构调整，共同压缩了利润空间。
- **[线上流量下滑与竞争加剧]** -> [电商业务收入下降26.05%]: 平台电商与社交电商渠道受行业流量红利消退及价格战影响，线上营收显著承压。
- **[加强费用管控与组织优化]** -> [管理费用下降34.79%]: 通过人员调整、运用新技术提升人效，并因无股份支付费用，有效控制了管理费用。
- **[政府补助及理财收益减少]** -> [净利润亏损扩大至1.48亿]: 非经常性损益（政府补助、理财收益）同比大幅减少，进一步加剧了由主营业务下滑导致的亏损。
- **[“一品一链”与核心产区溯源]** -> [打造差异化爆款，强化品牌价值]: 通过深入原料产地、集中供应降低成本，成功打造“澳洲安格斯牛肉脆”等月销千万级爆品，巩固“好原料”品牌形象。
- **[全渠道库存共享与智能补货]** -> [经营现金流净额大增7037%]: 通过优化库存管理和支付节奏，在营收下滑背景下，经营活动现金流净额从577万大幅提升至4.12亿。

## 风险警告
公司正面临“量价齐跌”的严峻挑战。营收与毛利率双降，导致2025年归母净利润亏损1.48亿元，较2024年亏损额扩大3倍。核心风险在于，为应对量贩零食等新业态的价格冲击，公司主动降价并优化门店，但此举尚未能有效止住收入下滑趋势，反而侵蚀了利润。线上渠道流量下滑加剧了这一困境，公司未来能否通过“一品一链”的差异化产品策略成功提价或提升复购，是扭亏的关键。

此外，公司治理层面存在重大隐患。控股股东宁波汉意因股份减持违规被监管处罚，且其与一致行动人正面临多起诉讼，所持股份被冻结、标记，并曾尝试转让控制权但最终失败。实际控制人亦收到法院执行通知书。这些事件不仅反映了控股股东层面的财务压力，也为公司未来的战略稳定性和经营连续性蒙上了阴影，是投资者需要高度警惕的“灰犀牛”风险。
