# 605339.SH 深度透视

## 因果逻辑链
- **[原材料成本飙升]** -> [毛利率全面承压]: 棕榈油、椰子油等主要原料价格创历史新高，公司无法向下游有效传导成本，导致烘焙应用油脂、淡奶油、乳制品毛利率分别下降0.85、8.68、8.21个百分点。
- **[高毛利产品占比下降]** -> [整体盈利能力恶化]: 毛利率最高的烘焙应用油脂（25.21%）收入同比下滑8.86%，而低毛利的预制烘焙品（6.80%）收入增长26.49%，产品结构恶化拖累综合毛利率下降4.98个百分点。
- **[终端消费弱复苏+行业竞争加剧]** -> [提价能力受限]: 下游客户价格敏感度显著提升，价格竞争激烈，公司产品提价幅度远低于成本涨幅，且存在滞后性，导致净利润暴跌79.81%。
- **[预制烘焙品销量增长]** -> [收入结构性支撑]: 预制烘焙品收入同比增长26.49%，成为唯一正增长的主要品类，部分对冲了传统油脂业务的收入下滑，但该品类毛利率仅6.80%，盈利能力薄弱。
- **[经销商渠道下沉]** -> [市场覆盖扩大但效率待考]: 经销商数量净增58家至539家，同比增长12.06%，但经销商渠道收入同比下降4.03%，显示新增经销商尚未有效转化为收入增量。
- **[海外业务拓展]** -> [第二增长曲线初现]: 境外收入同比增长13.41%，泰国子公司实现预制烘焙品在地化生产，东南亚市场成为未来重要增长极，但当前收入占比仍极低。
- **[重庆工厂建设投入]** -> [资本开支增加，现金流承压]: 在建工程同比增加132.36%，主要系重庆淡奶油生产基地持续投入，导致投资活动现金流出增加，经营活动现金流净额同比减少77.14%。

## 风险警告
**核心风险在于成本端失控与需求端疲软的双重挤压。** 公司主要原材料（棕榈油、椰子油）价格持续高位运行，而下游消费复苏乏力，行业竞争白热化，导致公司完全丧失定价权，无法将成本压力转嫁给客户。2025年净利润暴跌80%已充分暴露其商业模式在通胀环境下的脆弱性。若原材料价格维持高位或进一步上涨，公司盈利能力可能继续恶化，甚至面临亏损风险。

**战略转型的阵痛与不确定性。** 公司正从高毛利的烘焙油脂主业向低毛利的预制烘焙品和淡奶油业务倾斜，以迎合市场趋势。然而，预制烘焙品毛利率仅6.80%，且新品产能爬坡、产品结构变动导致成本控制困难。同时，重庆工厂等大规模资本开支正在消耗公司宝贵的现金流，若新业务无法快速实现规模效应和盈利改善，将加剧公司的财务压力。
