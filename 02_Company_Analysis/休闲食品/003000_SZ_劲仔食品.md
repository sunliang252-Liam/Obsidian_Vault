# 003000.SZ 深度透视

## 因果逻辑链
- **[核心大单品“深海鳀鱼”收入超16亿]** -> [总营收微增1.28%]: 尽管禽类制品、豆制品收入下滑，但鱼制品凭借7.33%的增长稳住了营收大盘，成为业绩的“压舱石”。
- **[直营模式收入暴增47.79%]** -> [整体毛利率下降1.18%]: 直营模式（尤其是线上及零食专营渠道）毛利率低于经销模式，其占比快速提升拉低了综合毛利率，导致“增收不增利”。
- **[品牌推广费激增25.50%]** -> [销售费用率上升]: 为应对竞争、强化“好吃又健康”品牌心智，公司大幅增加广告和综艺赞助投入，侵蚀了部分利润空间。
- **[禽类制品销量下滑20.69%]** -> [品类收入下降11.91%]: 鹌鹑蛋品类价格竞争激烈，公司主动调整策略，导致该品类销量和收入双降，成为拖累业绩的主要因素。
- **[新工厂投产与产线调整]** -> [管理费用增长19.91%]: 报告期内启用新工厂、进行产线调整，导致职工薪酬和折旧摊销增加，推高了管理成本。
- **[“先款后货”经销模式]** -> [经营性现金流优于净利润]: 公司对经销商采用先款后货的结算方式，叠加折旧等非付现成本，使得经营性现金流（3.69亿）远高于净利润（2.43亿）。
- **[全渠道布局与零食专营合作]** -> [线下销售增长3.80%]: 与超100家零食系统、覆盖4.5万家终端合作，有效对冲了线上销售下滑（-11.77%）的影响，稳固了线下基本盘。

## 风险警告
**增长失速与盈利承压。** 公司2025年营收增速骤降至1.28%，归母净利润更是同比下滑16.68%，扣非净利润下滑22.78%，呈现典型的“增收不增利”困境。核心品类禽类制品和豆制品收入均出现负增长，显示公司第二增长曲线乏力，过度依赖“深海鳀鱼”单一超级大单品。在消费复苏不及预期的背景下，公司通过加大品牌推广费和渠道投入来维持增长，但效果边际递减，盈利能力持续恶化。

**品类竞争加剧与渠道变革风险。** 鹌鹑蛋品类价格战激烈，公司虽以“七个博士”子品牌进行差异化竞争，但销量仍大幅下滑，品类价值挖掘面临挑战。同时，公司销售模式正从高毛利的经销模式向低毛利的直营模式（尤其是零食专营渠道）快速切换，虽然带来了收入增量，但持续拉低整体毛利率。若无法在零食专营渠道中建立更强的品牌溢价或成本优势，公司利润空间将进一步被压缩。
