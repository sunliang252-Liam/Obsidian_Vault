# 002320.SZ 深度透视

## 因果逻辑链
- **[收购中远海运客运]** -> [净利润暴跌44.13%]: 2025年6月完成25.15亿元现金收购，带来一次性整合成本及财务费用激增，导致归母净利润从3.1亿骤降至1.73亿。
- **[烟大航线运力退役]** -> [营收同比下降16.19%]: “棒槌岛”轮退役导致渤海湾运力减少，车运量同比下降10%，拖累整体营收。
- **[北海航线运力升级]** -> [营收暴增302.63%]: 投入大型客滚船实现双向对开，航次、车客运量大幅增长，但成本同步激增，毛利率为-186.84%，仍处亏损培育期。
- **[财务费用激增69.95%]** -> [侵蚀利润]: 收购中远海运客运产生延期付款利息，叠加存量资金减少导致利息收入下降，财务费用从4250万增至7224万。
- **[新海客运枢纽投运]** -> [港口效率提升]: 配合自贸港封关，推行“精准查验”模式，港口车运量同比增长3.0%，但客运量因旅游结构变化小幅下降2.0%。
- **[琼州海峡与渤海湾淡旺季互补]** -> [协同效应初显]: 南北航线在运输淡旺季上形成天然互补，有利于资源优化配置和提升运营效率，但整合效益尚未充分释放。
- **[“长乐公主”轮计提减值]** -> [资产减值损失4203万]: 因船舶运营效益不佳，计提船舶减值准备，直接减少利润总额。

## 风险警告
**核心风险在于收购整合不及预期与盈利能力持续恶化。** 公司以25.15亿元现金收购中远海运客运，导致资产负债率飙升，财务费用同比激增70%。同时，渤海湾业务因运力退役营收下滑16%，新收购资产尚未贡献正向利润，反而拖累整体ROE从4.91%降至3.34%。若南北航线协同效应无法在2026年兑现，公司可能面临“增收不增利”甚至利润继续下滑的困境。

**第二重风险来自新航线培育的持续亏损与市场竞争加剧。** 北海航线虽营收暴增302%，但毛利率为-186.84%，仍处于严重亏损状态；防城港、南沙等新航线亦处于市场培育期。同时，粤海铁路轮渡的潜在竞争加剧，可能侵蚀公司在琼州海峡的核心市场份额。公司2026年营收目标仅增长1.3%，显示管理层对短期增长持谨慎态度。
