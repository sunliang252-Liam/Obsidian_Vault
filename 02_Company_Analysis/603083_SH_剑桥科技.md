# 603083.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [高速光模块营收暴增241%]: 全球数据中心建设提速，800G光模块规模化量产，直接拉动公司核心增长引擎。
- **[800G/1.6T硅光产品量产]** -> [毛利率提升10.27个百分点]: 高毛利高速率产品占比提升，产品结构优化，盈利能力显著增强。
- **[全球化产能布局]** -> [规避美国关税风险]: 马来西亚工厂承接输美产品，北美本地工厂试产，有效对冲地缘政治与贸易政策不确定性。
- **[港股上市融资]** -> [总资产暴增129%，净资产增222%]: 募集资金补充流动性，为产能扩张与技术研发提供充足弹药。
- **[10G/25G PON产品升级]** -> [宽带业务营收近20亿]: 产品结构向高附加值迁移，25G PON率先批量发货，巩固北美市场份额。
- **[Wi-Fi 7产品规模化商用]** -> [无线业务稳定增长]: 北美市场Wi-Fi 7交付节奏加快，自研软件占比超70%，提升产品竞争力。
- **[战略物料储备与供应链垂直整合]** -> [保障订单交付]: 预付款锁定关键物料产能，有效应对核心元器件供应紧张，支撑业绩增长。
- **[美元/港元汇率下跌]** -> [产生8462万元汇兑损失]: 海外业务占比极高（超90%），汇率波动对净利润造成账面冲击，但未改变整体增长态势。

## 风险警告
公司业绩高度依赖AI算力投资周期与北美核心客户。前五大客户销售额占比高达86.10%，客户集中度极高，若主要客户削减采购或合作关系生变，将直接导致营收断崖式下滑。同时，LightCounting预计2026年下半年行业将面临更激烈的价格战，800G产品单价下行压力巨大，可能侵蚀当前高毛利。

地缘政治与汇率风险是悬在头顶的达摩克利斯之剑。美国关税政策频繁变动，虽通过马来西亚产能规避，但政策不确定性持续存在。公司海外收入占比超90%，美元/港元汇率波动导致2025年产生8462万元汇兑损失，若人民币持续升值，将进一步压缩利润空间。此外，经营活动现金流净额为-4.7亿元，由正转负，主要系采购支出激增，需警惕高速扩张下的现金流压力。
