# 002884.SZ 深度透视

## 因果逻辑链
- **[国内卫浴泵需求复苏+欧洲订单转移]** -> [国内销售增长17.57%]: 2024年客户库存消化后采购回归正常，叠加欧洲采购转向中国，公司卫浴泵订单显著增加。
- **[国内销售增长17.57%]** -> [总营收增长8.17%]: 国内销售增速远超出口（0%），成为拉动整体营收增长的核心引擎，弥补了海外市场的疲软。
- **[坚持扁平化销售层级]** -> [国内市场竞争中保持份额]: 减少中间费用，降低客户采购成本，以高性价比和技术服务型销售在降价促销的激烈竞争中获胜。
- **[塑料卫浴泵国内龙头地位+适配性设计能力]** -> [卫浴泵规模与客户粘性]: 凭借适配性设计、产品齐全、质量稳定、规模化生产，与全球知名卫浴厂商形成长期深度绑定。
- **[不锈钢泵技术升级+品类扩张]** -> [不锈钢泵站上国内第一梯队]: 向大口径、大流量、大功率产品拓展，市场覆盖面扩大，产品性能与价格竞争力增强。
- **[海外贸易政策不确定性]** -> [出口销售承压，保持平稳]: 美国市场受关税影响明显，公司通过大力拓展亚洲（中亚、东南亚、中东）市场，新增百余名客户，对冲了美洲市场的下滑。
- **[持续研发投入+新品上市]** -> [创造业绩新增长点]: 报告期内13项新品（PLURI、SCT等）投入市场，扩大了产品覆盖面，成为业绩增量来源。
- **[高分红政策]** -> [股东回报稳定]: 连续多年每10股派发现金红利10元，分红总额3.58亿元，占当年净利润近80%，体现成熟期企业特征。

## 风险警告
**海外市场高度依赖与贸易政策风险。** 公司近50%收入来自境外，其中美国市场是塑料卫浴泵的核心终端。2025年出口在关税影响下勉强持平，但2026年国际贸易政策不确定性加剧，若关税进一步升级或海外需求萎缩，将对公司营收和利润造成直接冲击。公司虽积极开拓亚洲市场，但新市场体量尚小，短期内难以完全替代欧美市场。

**原材料价格波动与成本传导压力。** 公司主要原材料（硅钢片、漆包线、不锈钢、塑料、铝锭等）均为大宗商品，2026年原材料价格已出现大幅上涨。由于公司产品定价以高性价比为核心竞争力，且下游客户多为长期合作，成本上涨难以完全转嫁。2025年毛利率已出现小幅下滑（-0.86%），若原材料持续高位，将严重侵蚀公司盈利能力。
