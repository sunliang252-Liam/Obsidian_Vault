# 002961.SZ 深度透视

## 因果逻辑链
- **[期货市场交投活跃度显著提升]** -> [经纪业务收入增长15.70%]: 2025年全国期货市场成交量、成交额创历史新高，客户权益突破2万亿元，直接带动公司手续费及保证金利息收入增加。
- **[资管产品规模扩大与业绩优异]** -> [资管业务收入暴增81.34%]: 公司坚持主动管理，CTA策略产品业绩突出，资管规模达46.29亿元（同比+97.40%），管理费及业绩报酬大幅增长。
- **[做市业务品种与交易量行业领先]** -> [风险管理业务稳健增长14.19%]: 子公司瑞达新控参与85个做市品种，期权做市成交量行业第2，获得交易所手续费减收及价差收入。
- **[可转债大量转股及利润留存]** -> [净资产增长26.14%]: 2025年“瑞达转债”大量转股（增加1902万股），叠加净利润高增，推动净资产从28.9亿增至36.5亿元。
- **[机构客户占比提升与保证金增长]** -> [利息收入与客户粘性增强]: 母公司口径客户保证金达200.25亿元，其中机构客户占73.39%，高净值机构客户贡献稳定保证金利息及手续费。
- **[香港子公司牌照齐全与跨境需求增长]** -> [境外业务收入增长51.87%]: 境外子公司持多类牌照，受益于中资企业出海避险需求及QFII/RQFII扩容，经纪与资管业务同步增长。
- **[公募基金子公司差异化布局]** -> [证券投资基金业务起步]: 瑞达基金旗下产品业绩优于基准，先进制造混合基金年化收益率46.56%，为财富管理板块奠定基础。

## 风险警告
**核心风险在于业绩对市场交易活跃度的高度依赖。** 公司经纪业务（占营收59%）和资管业务（占营收17%）均与期货市场成交量、客户保证金规模强相关。若宏观经济下行、大宗商品价格波动趋缓或监管收紧导致市场交投萎缩，公司手续费及利息收入将面临显著下滑压力。2025年行业高景气度是业绩暴增的核心驱动力，但周期性波动不可忽视。

**另一重大风险是风险管理业务中的信用与操作风险。** 子公司瑞达新控开展的大宗商品贸易、场外衍生品及做市业务，涉及大量资金占用和复杂对冲策略。报告期内衍生金融资产/负债大幅增长（+281%/+115%），且短期借款新增1.09亿元。若发生客户违约、基差剧烈波动或对冲失效，可能导致大额信用减值或交易亏损，侵蚀公司利润。
