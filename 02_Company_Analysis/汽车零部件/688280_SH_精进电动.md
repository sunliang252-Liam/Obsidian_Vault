# 688280.SH 深度透视

## 因果逻辑链
- **[核心客户车型放量]** -> [营收暴增109%]: 2024年下半年投产的国内乘用车项目（主要为北汽集团）在2025年快速放量，拉动乘用车电驱动系统收入增长163.85%，成为营收翻倍的核心引擎。
- **[规模效应与费用管控]** -> [首次扭亏为盈]: 营收大幅增长摊薄固定成本，同时公司主动精简研发团队、控制管理费用，叠加政府补助增加，共同推动归母净利润从-4.36亿跃升至+1.50亿。
- **[寄售模式占比飙升]** -> [收入确认与现金流改善]: 寄售收入占比从46.86%升至72.84%，客户按需领用后确认收入，加速了销售回款，使经营活动现金流净额暴增4572%至5.79亿元。
- **[技术领先与产品创新]** -> [高价值订单获取]: 单档高扭矩碳化硅电驱系统、直磁型机械差速锁等核心技术突破，助力公司获得国际头部车企（欧洲乘用车平台）及北美新兴车企的定点项目，为未来收入增长储备动能。
- **[欧洲市场突破]** -> [海外业务结构优化]: 向大众商用车集团旗下曼恩、斯堪尼亚批量供应碳化硅控制器，并与OP Mobility建立合作，使境外业务毛利率大幅提升29.79个百分点至31.95%，显著改善整体盈利质量。
- **[制造基地整合]** -> [成本优化]: 将国内生产制造业务全面集中至菏泽基地，提升规模效应，有效降低了运营成本，是毛利率改善12.20个百分点的重要支撑。

## 风险警告
**客户与产品高度集中风险**：公司对北汽集团的销售额占比高达54.43%，前五大客户合计占比79.10%，客户集中度极高。一旦北汽集团相关车型销量下滑、引入竞争性供应商或合作关系生变，公司营收将面临断崖式下跌。同时，公司盈利高度依赖少数几款2024年下半年投产的新车型，产品生命周期风险集中。

**盈利基础脆弱与治理风险**：尽管2025年实现扭亏，但扣非净利润仅3176万元，盈利规模极小。公司累计未分配利润仍高达-24.8亿元，历史亏损包袱沉重。此外，公司存在表决权差异安排，实际控制人余平通过仅11.81%的股份控制了59.29%的表决权，对股东大会拥有绝对控制力，中小股东利益保护机制的有效性存疑，治理风险突出。
