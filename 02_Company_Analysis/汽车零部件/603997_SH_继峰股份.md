# 603997.SH 深度透视

## 因果逻辑链
- **[乘用车座椅业务规模效应显现]** -> [归母净利润扭亏为盈]: 座椅业务营收增长80.68%至56.19亿元，实现归母净利润1.01亿元，规模效应叠加降本措施推动整体盈利大幅改善。
- **[格拉默全方位降本增效]** -> [海外分部扭亏]: 通过裁员、降薪、成立全球采购中心、向客户提价等措施，格拉默实现归母净利润1.78亿元（去年同期-6.25亿元），驱动集团整体利润转正。
- **[在手订单持续积累]** -> [未来收入确定性增强]: 截至2025年末，乘用车座椅累计27个定点项目，全生命周期总销售额预计超千亿元，为未来规模经济创造条件。
- **[原材料成本控制与自制率提升]** -> [毛利率创近5年新高]: 公司毛利率提升2.05个百分点至16.09%，得益于采购协同、增加零部件自制率及生产流程优化。
- **[管理费用大幅压降]** -> [费用率显著优化]: 管理费用同比下降19.06%，费用率降低1.98个百分点至7.48%，主要源于组织架构调整、精简流程及人员效率提升。
- **[经营现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流净额同比增长549.19%至17.50亿元，反映盈利质量改善和营运效率提升。
- **[国内收入增长与海外收入下滑]** -> [业务结构区域分化]: 国内收入同比增长24.83%，而海外收入同比下降13.12%（剔除TMD出售影响），显示增长动能主要来自中国市场。

## 风险警告
**核心风险在于乘用车座椅业务的高增长能否持续，以及格拉默海外整合的脆弱性。** 座椅业务虽已扭亏，但毛利率仅12.63%，且在手订单转化为稳定收入需依赖客户车型销量、量产节奏及成本控制，任何环节的延迟或客户销量不及预期都将冲击盈利。同时，格拉默海外业务虽扭亏，但欧洲区仍面临人力成本、工厂效率及客户提价谈判的不确定性，整合成果的可持续性有待验证。

**财务杠杆与汇率波动构成双重压力。** 公司担保总额占净资产比例高达123.03%，且长期借款55.57亿元，财务费用3.27亿元，高负债运营下利息支出对利润侵蚀显著。此外，公司超40%资产在境外，汇率波动导致的外币报表折算差异及远期外汇合约损失（报告期损失5067万元）将持续扰动财务数据稳定性。

> 宁波继峰汽车零部件股份有限公司成立于1996年,是全球领先的座舱内饰件供应商。2015年公司在上交所上市交易(股票简称:继峰股份;股票代码:603997)。2019年公司收购德国百年汽车内饰巨头格拉默,通过企业创新升级,实现全球化的战略布局。公司产品涵盖乘用车和商用车两大领域。在乘用车领域,公司主要产品为乘用车座椅、座椅头枕、座椅扶手、中控系统、隐藏式电动出风口、内饰部件等;在商用车领域,公司的主要产品为卡车座椅、非道路车辆座椅部件(牵引机、建设机械和叉车)以及火车、公共汽车座椅等。公司凭借先进的创新设计、生产制造、品质管理及优秀服务,发展成为少数能同时为欧系、美系、日系、自主品牌等整车生产厂家提供配套的汽车零部件供应商,客户包括奥迪、宝马、菲亚特克莱斯勒、戴姆勒、捷豹路虎、保时捷、大众、斯柯达、沃尔沃、通用、福特、凯迪拉克、特斯拉、本田、丰田、日产等国外主流厂商,以及一汽、上汽、东风、长城、红旗、比亚迪、吉利汽车、小鹏、蔚来、理想等国内优势汽车企业。为更好地服务客户,公司在全球20个国家拥有超过90家控股子公司,形成了全球生产、物流和营销网络。公司坚持自主创新,拥有专业的研发团队、先进的测试设备、有效的质量控制体系及强大的生产能力,收购格拉默后,通过整合格拉默优秀的研发资源,进一步提升了公司的研发实力。目前,公司是浙江省专利示范企业及国家知识产权优势企业。2004年,公司通过了法国BVQI的ISO/TS16949:2002认证,2009年通过了ISO14001国际环境体系认证。公司的测试中心通过了ISO/IEC17025:2005实验室认可,同时还获得大众汽车、宝马、福特、神龙、吉利等国内外多家主机厂的实验检测资质认可。公司先后荣获“全国机械工业先进集团”、“浙江省技术创新能力百强企业”、“浙江省汽车工业百强”、“浙江省高新技术企业创新能力百强”、“2020年财富中国500强”、“2020中国汽车零部件企业百强”等多项重要荣誉称号。我们始终在座舱内饰件领域持续深耕做强,不断提升专业能力,构建具备竞争力的技术储备与国际化运营能力。面对汽车行业电动化、智能化的快速发展,以及驾乘人员对座舱舒适性需求的日益提升,公司积极升级并拓展车内功能,挖掘业务中长期发展空间,为提升座舱内部舒适体验创造核心价值。展望未来,我们将继续秉持“简单、务实、高效”的核心价值观,坚守“为客户提供高性价比产品及解决方案,助力全球汽车制造业蓬勃发展”的使命,持续推进并落实以乘用车座椅为核心的智能座舱战略,力争成为中国及全球汽车零部件行业的领军企业,向着“百年继峰”的愿景稳步迈进。
