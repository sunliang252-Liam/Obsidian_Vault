# 300258.SZ 深度透视

## 因果逻辑链
- **[行业价格战传导]** -> [毛利率下滑]: 整车厂降价压力向上游零部件供应链传导，导致公司综合毛利率同比下降0.54个百分点，扣非净利润同比大幅下降36.14%。
- **[新能源转型结构性机遇]** -> [新能源车业务增长]: 公司为新能源车配套产品销售额占比提升至29.25%，同比增长8.52%，成为收入增长的核心驱动力。
- **[海外产能布局滞后]** -> [泰国工厂初期亏损]: 泰国公司一期产能虽已建成投产，但处于产能爬坡期，2025年仍处于亏损状态，拖累整体盈利。
- **[新项目产能爬坡]** -> [天津/重庆工厂盈利承压]: 天津公司营收同比下降6.97%，差速器总成等新项目出产不及预期；重庆公司虽营收增长13.64%，但产能利用率仍有待提升。
- **[研发投入资本化率为零]** -> [当期利润被费用侵蚀]: 公司研发投入全部费用化，2025年研发费用1.14亿元，占营收5.60%，对当期净利润形成直接压力。
- **[可转债转股完成]** -> [财务结构优化]: 2025年“精锻转债”基本完成转股，应付债券减少9.08亿元，资产负债率从46.39%大幅降至35.74%，显著降低财务风险。
- **[人形机器人业务布局]** -> [培育第二增长曲线]: 公司已完成摆线针轮减速器、行星减速器、行星滚柱丝杠等样品开发，并采购核心设备，但尚处于试验验证阶段，短期无法贡献业绩。

## 风险警告
公司面临的核心风险是**“量增利压”的行业困境与高昂的资本开支之间的矛盾**。2025年营收仅微增0.66%，但扣非净利润却暴跌36.14%，显示公司传统主业已进入存量博弈阶段，盈利能力持续恶化。与此同时，公司仍在天津、重庆、泰国等地进行大规模产能投资，固定资产同比大增19.6%至34.78亿元，这些新增产能的爬坡和盈利兑现存在极大不确定性，尤其是泰国工厂的亏损状态短期内难以扭转，将持续侵蚀公司利润。

另一个关键风险在于**新业务（人形机器人）的投入节奏与回报周期不匹配**。公司明确将人形机器人作为第二增长曲线，并已进行设备采购和产能规划，但该业务尚处于样品开发阶段，市场需求和技术路径均存在高度不确定性。在传统主业盈利下滑的背景下，公司同时面临海外建厂（泰国二期、摩洛哥）、新业务研发及国内产能扩张的多重资金压力，投资活动现金流净流出高达10.72亿元，若新业务不及预期，将导致公司陷入“主业失血、新业务烧钱”的困境。
