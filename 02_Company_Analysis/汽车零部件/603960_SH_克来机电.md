# 603960.SH 深度透视

## 因果逻辑链
- **[下游汽车行业竞争加剧]** -> [营收与利润双降]: 2025年营收4.98亿(-15.06%)，归母净利润0.28亿(-49.91%)，主因汽车零部件单价下降及智能装备订单减少。
- **[客户增加票据结算比例]** -> [经营性现金流大幅恶化]: 经营活动现金流净额0.74亿(-47.56%)，远低于净利润，反映回款质量显著下降。
- **[汽车零部件量价齐跌]** -> [毛利率承压]: 汽车零部件收入降17.67%，毛利率降3.99个百分点，主因燃油分配器、冷却水管等传统产品销量与单价同步下滑。
- **[智能装备新签订单减少]** -> [收入确认滞后]: 2025年新签订单2.36亿（同比略减），且部分非汽车行业订单尚未验收，导致智能装备收入降11.67%。
- **[R744二氧化碳空调管放量]** -> [新能源转型亮点]: 该产品销量16.94万件(+3.71%)，已获大众MEB认证并批量供货，成为唯一国产指定供应商，是未来增长核心。
- **[厢式货车自动装车机器人进入推广期]** -> [新业务突破]: 产品从验证阶段进入批量推广，已在烟草行业落地，并向食品、酒类拓展，有望开辟第二增长曲线。
- **[前五大客户收入占比89.05%]** -> [客户集中度极高]: 严重依赖联合汽车电子、博世系、大众系等少数核心客户，单一客户流失将导致业绩剧烈波动。
- **[募投项目未达预期]** -> [资本开支效率低]: “智能制造生产线扩建项目”2025年仅实现效益119.6万元，远不及预期，主因产能爬坡及市场竞争激烈。

## 风险警告
**核心风险在于盈利能力的持续恶化与现金流的背离。** 公司2025年归母净利润腰斩，综合毛利率从21.41%降至19.43%，且经营性现金流净额降幅(47.56%)远超营收降幅(15.06%)，表明公司不仅面临价格战压力，更在客户结算条件上处于弱势，回款周期拉长。汽车零部件业务作为利润基石，正遭受传统燃油车需求萎缩与新能源车价格战传导的双重挤压，量价齐跌趋势短期难以逆转。

**客户与行业高度集中构成结构性脆弱。** 前五大客户贡献近九成收入，且约90%收入来自汽车行业。公司虽在R744空调管和自动装车机器人等新领域取得突破，但前者仍处放量初期，后者市场拓展存在不确定性。一旦核心客户（如大众系）因自身销量下滑或采购策略调整而减少订单，公司缺乏足够的客户缓冲带，业绩将面临断崖式下跌。此外，智能装备业务面临国内外巨头竞争，公司资本实力与品牌影响力处于劣势，市场份额有被挤压风险。
