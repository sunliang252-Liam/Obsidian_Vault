# 603009.SH 深度透视

## 因果逻辑链
- **[空调压缩机业务爆发]** -> [净利润增长67%]: 新能源电动压缩机及集成式热管理系统在乘用车、电动重卡领域取得突破，带动该板块收入增长36%，毛利率提升4.55个百分点。
- **[铝合金轻量化业务放量]** -> [收入增长50%]: 客户与产品多元化战略见效，控制臂等产品配套比亚迪、采埃孚等头部客户，规模效应下毛利率提升1.81个百分点。
- **[底盘零部件稳中求进]** -> [收入增长4%]: 转向器齿条、减振器活塞杆在细分市场保持主导地位，销量达9,639万件，但增速放缓，显示传统业务天花板。
- **[规模效应与降本增效]** -> [毛利率提升1.73个百分点]: 收入增长14.79%快于成本增长12.42%，叠加供应链优化与工艺改进，盈利能力显著改善。
- **[丝杠业务布局加速]** -> [尚未贡献业绩]: 配合客户开发行星滚柱丝杠等产品，江苏昆山及泰国基地在建，但下游技术方案与量产时间不确定，短期无实质收入。
- **[再融资完成]** -> [泰国基地建设启动]: 以简易程序募资2.94亿元，全部投入泰国丝杠生产基地，旨在拓展海外市场并规避贸易壁垒。
- **[商誉减值风险持续]** -> [账面价值降至4,873万元]: 子公司上海光裕（空调压缩机）2025年亏损2,680万元，未来若经营不及预期，商誉减值将进一步侵蚀利润。

## 风险警告
**核心风险在于商誉减值与丝杠业务的不确定性。** 子公司上海光裕（空调压缩机业务主体）2025年亏损2,680万元，其对应的商誉账面价值仍有4,873万元。若该业务无法在新能源转型中实现盈利反转，商誉减值将直接冲击利润表。此外，公司重金押注的丝杠业务（昆山+泰国基地总投资超18.5亿元）仍处于早期阶段，下游客户技术方案未定、量产时间不明，短期内无法贡献业绩，存在投资回报不达预期的风险。

**行业竞争与成本压力不容忽视。** 整车价格战持续向零部件企业传导，公司面临配套降价压力。同时，钢材、铝材等原材料价格波动直接影响生产成本。虽然公司通过降本增效部分对冲，但若原材料大幅上涨或整车厂进一步压价，毛利率可能承压。此外，空调压缩机业务产能利用率仅43%，存在产能闲置风险。
