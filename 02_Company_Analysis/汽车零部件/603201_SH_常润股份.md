# 603201.SH 深度透视

## 因果逻辑链
- **[泰国生产基地投产上量]** -> [对冲美国关税风险]: 泰国工厂承接美国客户订单，保障对美出口业务稳定，避免营收大幅下滑。
- **[跨境电商业务高速增长]** -> [营收增量与销售费用激增]: Amazon SC账户销售增长超80%，但平台推广费大幅增加，导致销售费用同比+68.72%，侵蚀利润。
- **[美国“对等关税”政策冲击]** -> [净利润同比下降12.05%]: 关税成本上升及贸易不确定性，叠加销售费用扩张，导致归母净利润从2.45亿降至2.16亿。
- **[原材料价格波动与成本控制]** -> [毛利率提升]: 钢材等直接材料成本同比下降，叠加产品结构优化，通用设备制造业毛利率同比提升4.34个百分点。
- **[收购柯钧新材（充气泵/补胎液）]** -> [拓展新能源OEM产品线]: 切入快速补胎工具赛道，与赛力斯、东风等新能源车企建立合作，提升单车配套价值。
- **[全球汽车保有量与车龄增长]** -> [AM市场需求刚性]: 美国平均车龄升至14.5年，中国升至7.3年，为后市场维保设备提供持续稳定的需求基础。
- **[前装市场新项目定点]** -> [优化产品结构]: 成为宝马拖车工具供应商，并拓展CCB（仪表板横梁）等车身结构件，从千斤顶向高附加值品类延伸。

## 风险警告
**核心风险在于美国关税政策的不确定性。** 公司对美出口收入占比超40%，虽然已通过泰国基地转移部分产能，但泰国同样面临10%的临时关税（且有上调风险）。若关税进一步升级或中美贸易摩擦长期化，公司海外布局的成本优势将被削弱，利润端将持续承压。此外，公司2025年净利润下滑12%，主要源于销售费用激增（+68.72%）和税金及附加（关税）增长（+73.76%），成本端压力已显性化。

**第二重风险来自跨境电商业务的“增收不增利”。** 虽然电商销售增长迅猛（SC账户+80%），但平台推广费、海外仓运营成本同步攀升，导致销售费用率大幅提高。若未来平台竞争加剧或流量成本继续上升，该业务的盈利能力可能进一步恶化。同时，公司研发投入占比仅1.09%，在新能源维保设备等新领域的技术储备相对薄弱，长期竞争力存疑。
