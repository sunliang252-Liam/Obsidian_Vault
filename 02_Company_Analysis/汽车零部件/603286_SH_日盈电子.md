# 603286.SH 深度透视

## 因果逻辑链
- **[行业竞争加剧与客户年降]** -> [毛利率大幅下滑]: 汽车零部件行业普遍存在年度降价惯例，叠加新能源车价格战传导，公司产品售价持续下降，导致车用零部件毛利率同比下降4.45个百分点。
- **[新厂房与产线投产]** -> [折旧摊销激增]: 5G智能化汽车零部件制造项目于2024年投产，2025年进入首个完整折旧年度，车用零部件制造费用同比增加36.03%，短交通零部件制造费用同比增加53.15%。
- **[股权激励费用增加]** -> [管理费用攀升]: 2024年实施的限制性股票与股票期权激励计划在2025年进入费用摊销期，叠加新管理层入职，管理费用同比增加22.54%。
- **[原材料铜价上涨]** -> [成本端承压]: 主要原材料铜丝、铜带等大宗商品价格上涨，直接材料成本占主营业务成本约74%，成本上涨无法完全通过提价转嫁。
- **[研发投入持续加大]** -> [短期利润侵蚀]: 公司为布局智能驾驶传感器、高速传输线束等新产品，研发费用同比增加31.51%，研发费用率维持在5.00%的高位。
- **[北美工厂投产]** -> [产能出海与全球化布局]: 美国密歇根州工厂投入使用，从“产品出口”升级为“产能出海”，实现客户本土化供应，规避贸易摩擦风险，并拓展北美具身智能客户。
- **[收购惠昌传感器剩余股权]** -> [强化核心传感器能力]: 以6372.64万元收购子公司惠昌传感器剩余20%股权，实现100%控股，巩固热敏电阻等核心传感元件的自主研发与生产能力。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司2025年营收增长7.29%至10.41亿元，但归母净利润由盈转亏，巨亏5242万元。根本原因是行业竞争白热化导致的产品价格持续下降（客户年降），叠加新产能投产带来的折旧摊销激增，以及原材料铜价上涨，三重压力共同挤压利润空间。公司毛利率从2024年的18.57%骤降至2025年的14.77%，降幅达3.8个百分点，且短期内看不到价格企稳的迹象。

**现金流恶化与高负债运营构成双重隐患。** 经营活动现金流净额同比大幅下降41.82%至3710万元，远低于净利润亏损额，显示公司回款能力或营运效率出现问题。同时，公司总负债高达10.62亿元，资产负债率56.7%，短期借款4.59亿元，财务费用同比增长41.77%。在盈利能力下滑的背景下，高额的利息支出将进一步侵蚀利润，若行业景气度持续低迷，公司可能面临流动性压力。
