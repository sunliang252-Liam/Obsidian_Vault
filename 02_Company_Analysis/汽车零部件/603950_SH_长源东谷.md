# 603950.SH 深度透视

## 因果逻辑链
- **国内新能源汽车渗透率突破50%，混动车型成为重要增长极** -> 新能源混动缸体缸盖业务收入增长，成为公司新增长极: 行业趋势驱动公司业务拓展，混动汽车零部件需求增加，公司凭借技术优势获得比亚迪、赛力斯等客户订单，并新获奇瑞、吉利定点，带动收入增长。
- **商用车市场复苏，核心客户需求回暖** -> 传统商用车业务收入稳步增长: 商用车市场整体回暖，公司主要客户如东风康明斯、福田康明斯等需求增加，公司作为核心供应商受益，缸体、连杆等产品销量上升。
- **公司深化自动化升级与精益管理** -> 毛利率提升，成本端优化，费用率下降: 自动化升级提高生产效率，规模效应摊薄固定成本；精益管理降低直接材料、制造费用占比，带动毛利率提升。毛利率从23.29%升至27.20%，营业成本增幅低于收入增幅。
- **新客户拓展（奇瑞、吉利）及产能建设** -> 研发费用、资本开支及筹资活动现金净额增加: 为匹配新客户需求，公司加大研发投入（同比增长26.74%）及生产线建设，导致投资活动现金流出增加，同时通过增加设备贴息贷款（筹资活动现金净额增长86.88%）支持扩张。

## 风险警告
公司客户集中度高（前五名客户销售额占比84.88%），且收入高度依赖商用车与新能源混动领域，若主要客户（如比亚迪、福田康明斯）订单波动或行业政策转向（如补贴退坡、混动技术路线被纯电替代），将对公司业绩造成重大冲击。此外，公司库存量激增（缸体库存同比增长304.93%），若下游需求不及预期，可能面临存货减值风险。
