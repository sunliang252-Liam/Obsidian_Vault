# 002965.SZ 深度透视

## 因果逻辑链
- **[收入增长但毛利率下降]** -> [净利润暴跌56.88%]: 营收增长17.54%至79.27亿，但成本增速（20.87%）远超收入增速，导致综合毛利率下降，叠加信用减值损失激增至4785万，利润被严重侵蚀。
- **[研发投入激增44.67%]** -> [短期利润承压]: 研发费用达3.52亿元，占营收4.44%，主要用于新能源汽车、机器人等新业务技术储备，虽提升长期竞争力，但直接拖累当期利润。
- **[应收账款与存货双高]** -> [经营现金流恶化90.55%]: 应收账款激增40%至23.4亿，存货增加18.7%至22.5亿，大量营运资金被客户占款和库存积压，导致经营性现金流仅2779万，与净利润严重背离。
- **[新能源汽车业务扩张]** -> [收入增长但盈利承压]: 新能源汽车精密结构件收入增长20.68%至46亿，但该板块毛利率同比下降3.86个百分点至9.35%，反映行业价格战激烈，增量不增利。
- **[全球化布局加速]** -> [海外业务亏损]: 墨西哥子公司亏损2811万，泰国新设子公司尚处投入期，海外产能爬坡期的高投入与低产出，对整体盈利形成拖累。
- **[信用减值损失激增]** -> [利润质量下降]: 信用减值损失从621万暴增至4785万，主要系应收账款坏账准备计提大幅增加，显示下游客户回款压力增大，利润含金量低。
- **[募投项目频繁延期]** -> [产能释放不及预期]: 宁波、东莞等核心募投项目因市场变化多次延期至2026年底，产能扩张节奏放缓，制约了规模效应的释放和盈利能力的提升。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长17.54%，但净利润暴跌56.88%，毛利率全面下滑，核心原因是成本端（原材料、人工、制造费用）增速远超收入端，且信用减值损失激增，表明公司在产业链中议价能力弱，无法将成本压力向下游传导，同时客户回款风险显著上升。这种“流血扩张”模式若持续，将严重侵蚀股东价值。

**现金流危机是另一大警报。** 经营活动现金流净额同比暴跌90.55%至仅2779万元，而同期净利润高达1.55亿元，利润与现金流的巨大剪刀差意味着公司盈利质量极差。应收账款和存货合计超45亿元，占流动资产的64%，营运资金周转效率低下。若下游客户（尤其是新能源车企）出现信用风险，公司将面临巨大的坏账和流动性压力。
