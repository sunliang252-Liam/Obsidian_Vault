# 603007.SH 深度透视

## 因果逻辑链
- **[收购尼威动力控股权]** -> [营收暴增347.62%]: 2025年8月完成对尼威动力50.11%股权的收购，其高压燃油箱业务自9月起并表，贡献了报告期内约78%的营业收入，是营收从0.9亿跃升至4.1亿的核心驱动力。
- **[债务重组收益]** -> [净利润减亏]: 报告期内确认债务重组收益9704万元，是归母净利润-2.28亿元远优于扣非净利润-3.59亿元的关键原因，掩盖了主营业务的持续亏损。
- **[原主业持续萎缩与资产减值]** -> [扣非净利润仍巨亏]: 剔除尼威动力并表贡献后，原建筑业务收入仅约0.9亿，且因历史项目回款困难、资产减值（如一年内到期非流动资产计提减值）导致扣非净利润仍亏损3.59亿，显示旧业务“失血”严重。
- **[商誉激增]** -> [未来利润最大“暗雷”]: 收购尼威动力形成商誉4.81亿元，占净资产比例高达167%。若尼威动力未来三年累计净利润未达3.2亿的业绩承诺，将面临巨额商誉减值风险，直接吞噬利润。
- **[新业务布局与产能扩张]** -> [长期增长逻辑]: 公司通过设立合资公司切入传感器赛道，并投建西南地区高压燃油箱生产基地，旨在构建“新能源核心部件+传感器+新基建”的业务矩阵，为未来增长铺路。
- **[现金流持续为负]** -> [经营造血能力不足]: 经营活动现金流净额为-7208万元，虽营收大增，但购买商品支付现金增加，且原建筑业务回款困难，表明公司整体经营造血能力尚未根本改善。

## 风险警告
公司最大的风险在于高达4.81亿元的商誉。尼威动力2025年实现净利润1.02亿元，虽完成首年业绩承诺的31.76%，但未来两年需累计完成约2.18亿元净利润，压力巨大。一旦行业竞争加剧或客户订单不及预期，商誉减值将导致公司再次陷入巨亏，这是悬在股价上方的“达摩克利斯之剑”。

其次，公司经营基本面依然脆弱。扣非净利润连续三年为负，经营活动现金流持续净流出，表明公司自身造血能力严重不足。尽管通过收购实现了营收规模跃升，但新收购的制造业业务能否持续盈利并产生正向现金流，以及原建筑业务的历史坏账问题能否解决，仍是未知数。公司目前仍处于“输血”向“造血”转型的关键期，任何环节的失误都可能使转型功亏一篑。
