# 601689.SH 深度透视

## 因果逻辑链
- **[Tier0.5级商业模式]** -> [单车配套金额提升]: 公司深度参与客户研发，提供一站式系统级产品，单车配套金额约3万元，远超传统零部件供应商。
- **[产品平台化战略]** -> [收入增长与客户粘性]: 拥有NVH、底盘、热管理、汽车电子等8大产品线，客户可一站式采购，提升配套深度与客户转换成本。
- **[汽车电子量产放量]** -> [第二增长曲线形成]: 空气悬架、线控制动IBS、线控转向EPS等产品订单持续放量，汽车电子业务收入同比大增52.11%，成为核心增长引擎。
- **[机器人业务布局]** -> [开辟远期增长空间]: 依托IBS技术积累，切入机器人执行器、灵巧手等核心部件，单机价值数万元，市场空间百万亿级，打造新增长曲线。
- **[全球化产能扩张]** -> [对冲贸易风险与获取海外订单]: 墨西哥、波兰、泰国等地建厂，服务国际车企及中国车企出海，以海外产能应对关税变动，获取本土化订单。
- **[研发高投入]** -> [技术壁垒与产品拓展]: 研发费用14.96亿元（占收入5.06%），支撑从材料到电控、软件的全栈自研能力，持续拓展产品线，构建技术护城河。
- **[新建工厂爬坡成本]** -> [短期利润承压]: 每年新建工厂较多，生产爬坡期管理费、制造费高昂，单个工厂平均数千万元，导致管理费用增23.75%，拖累当期净利润。
- **[收购芜湖长鹏]** -> [提升内饰市占率与盈利能力]: 收购整合后，凭借公司管理经验与产业链垂直整合能力，显著增强标的盈利能力，巩固行业领先地位。

## 风险警告
**利润增速与收入增速背离，增收不增利风险显著。** 2025年公司营收增长11.21%，但归母净利润却下降7.38%，毛利率同比下滑1.38个百分点。核心原因在于：新建工厂爬坡成本、研发费用（+22.20%）及管理费用（+23.75%）的快速膨胀，侵蚀了利润空间。若新项目量产进度不及预期或客户年降压力加大，利润端将持续承压，投资者需警惕“规模不经济”的阶段性陷阱。

**全球化扩张与资本开支带来的财务与经营风险。** 公司正处于大规模资本开支周期，2025年购建固定资产等长期资产支出34.97亿元，资产负债率升至45.07%。海外工厂（墨西哥、泰国）面临地缘政治、汇率波动、当地供应链不成熟及管理文化差异等挑战，墨西哥子公司目前仍处于亏损状态。若海外订单释放不及预期，巨额投资将面临减值风险，并可能推高财务费用。
