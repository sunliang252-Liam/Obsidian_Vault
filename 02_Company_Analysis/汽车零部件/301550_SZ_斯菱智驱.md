# 301550.SZ 深度透视

## 因果逻辑链
- **全球汽车保有量增长与售后市场深耕** -> **营收稳健增长**: 公司凭借覆盖北美、欧洲、亚洲的成熟销售网络，受益于全球汽车保有量提升带来的售后零部件更换需求，实现营收1.79%的同比增长。
- **产品结构优化与高附加值型号量产** -> **毛利率微增**: 公司成功研发并量产高附加值轮毂轴承单元等产品，推动销售毛利率同比提升约0.16%，部分抵消了成本压力。
- **泰国及美国工厂产能扩张** -> **资本开支大幅增加**: 为应对新增市场需求和规避贸易摩擦，公司加速泰国三期及美国密歇根工厂建设，导致投资活动现金净流出同比扩大31.74%。
- **收购银球科技股权** -> **长期股权投资激增**: 公司以3.69亿元收购宁波银球科技24.34%股权，切入精密轴承赛道，导致长期股权投资从0增至占总资产14.62%。
- **汇兑损益波动** -> **财务费用大幅变动**: 报告期内人民币汇率波动导致汇兑损失增加，财务费用同比上升49.56%，对净利润产生负面影响。
- **研发投入持续** -> **新业务布局初现**: 公司研发费用保持稳定，重点投向谐波减速器、执行器模组等高精密零部件，报告期末已实现谐波减速器投产，为未来增长蓄力。
- **境外收入占比高** -> **业绩受汇率与贸易政策影响**: 公司外销收入占比超70%，以美元结算为主，业绩对人民币汇率及中美贸易政策高度敏感。

## 风险警告
**核心风险在于新业务投入与主业盈利能力的阶段性背离。** 公司2025年归母净利润同比下降9.17%，而同期资本开支（泰国、美国工厂及银球科技投资）大幅增加，导致投资活动现金净流出扩大至3.56亿元。在主营业务增长放缓的背景下，大规模资本开支能否如期转化为新增长极，存在不确定性。

**另一重大风险是外部环境的双重压力。** 公司超70%收入来自境外，且以美元结算，人民币汇率波动直接侵蚀利润（报告期汇兑损失740万元）。同时，美国作为主要市场，其贸易保护主义和制造业回流政策（公司已因此在美国设厂）可能持续增加运营成本和不确定性。此外，原材料（钢材）价格波动若无法有效传导至下游，将进一步压缩本已承压的利润空间。

> 浙江斯菱智能驱动集团股份有限公司(简称斯菱智驱)是一家专业生产汽车轴承的汽车零部件制造企业,主营业务为汽车轴承的研发、制造和销售。所研发的产品涉及轮毂轴承、轮毂轴承单元、圆锥轴承、离合器、涨紧轮及惰轮轴承等多个产品系列。公司自2004年成立以来,一直秉承“创新、务实”的企业经营理念,以市场需求为导向、客户体验为基石、技术创新为动力,在汽车轴承领域积累了多年的售后市场及主机配套市场经验,致力于打造全球领先的汽车轴承民族品牌,成为具有全球竞争力的汽车轴承制造商。公司建立了包括车加工、热处理、磨加工、装配等轴承加工全产业链的先进智造系统,运用自动化、智能化制造提高产品品质和运营效率。公司的技术中心被认定为浙江省省级企业技术中心、浙江省省级企业研究院,公司主持或参与起草了2项轴承行业国家标准和2项行业标准。
