# 300695.SZ 深度透视

## 因果逻辑链
- **基金公允价值变动** -> 归母净利润暴增150.9%: 公司投资的青岛火眼瑞祥一号基金因奇瑞汽车港股上市，公允价值大幅上升2.65亿元，贡献了绝大部分利润增量。
- **国内主机市场开拓** -> 主机产品销量增长20%+: 公司大力拓展国内OEM配套业务，新获零跑、一汽奔腾等定点项目，带动境内收入增长30.86%。
- **“由机向电”战略** -> 电控产品实现小批量供货: 机电协同发展规划落地，新能源车载电控业务从研发进入量产阶段，形成新增长点。
- **布局具身智能** -> 丝杠产品进入小批量试制: 公司前瞻性布局人形机器人及汽车智驾精密部件，多款丝杠产品通过客户性能测试，产业化进程加速。
- **原材料价格下降** -> 营业成本结构优化: 直接材料成本占营业成本比重下降4.28个百分点，部分对冲了主机市场毛利率较低的影响。
- **境外收入下滑** -> 整体营收增速放缓至6.01%: 境外地区收入同比下降20.54%，主要受汇率波动及海外市场结构调整影响，拖累整体营收增速。
- **募投项目延期** -> 产能释放节奏放缓: 年产3000万只精密锻车件项目及新能源车载电控项目均延期至2026年底，短期产能扩张不及预期。

## 风险警告
**核心风险在于利润质量与主业增长脱节。** 2025年归母净利润暴增150.9%，但扣非净利润同比下降22.25%，两者严重背离。利润增长几乎完全依赖非经常性的基金公允价值变动（2.7亿元），该收益不可持续且具有高度不确定性。一旦所投基金估值回调，利润将面临剧烈波动。同时，经营活动现金流净额同比下降44.85%，与净利润严重不匹配，盈利的现金保障度极低。

**主业增长面临“增收不增利”与市场结构转型的双重压力。** 公司境内主机业务虽增长30.86%，但毛利率仅为19.64%，远低于境外售后市场43.15%的毛利率。随着主机业务占比提升，整体毛利率存在持续下滑风险。此外，境外收入下滑20.54%，传统优势市场增长乏力。公司正从高毛利的售后市场向低毛利的主机市场切换，这一战略转型将长期考验其成本控制与盈利能力。
