# 603109.SH 深度透视

## 因果逻辑链
- **[收入创历史新高，但毛利率下滑]** -> [净利润同比下降30.94%]: 营收增长6.88%至29.28亿元，但营业成本增速(10.19%)远超收入增速，叠加管理费用(+25.72%)和研发费用(+28.49%)大幅增加，导致利润被严重侵蚀。
- **[全产业链布局与规模效应]** -> [成本控制与抗风险能力]: 公司具备小型发电机、通用汽油机等核心部件自产能力，理论上可提升利润空间，但2025年成本增速仍快于收入，表明该优势未能完全对冲原材料涨价及产能扩张带来的成本压力。
- **[海外产能转移应对贸易风险]** -> [越南基地产能强化]: 为应对中美贸易摩擦，公司将北美订单全部转产至越南，越南神驰净利润达9626.52万元，成为利润核心支柱，有效规避了关税壁垒。
- **[研发投入增加与产品升级]** -> [技术壁垒与市场准入优势]: 研发费用增长28.49%，成功开发出内转子永磁变频电机、18kw多燃料静音变频机组等新品，并取得满足加州四阶段排放标准的产品认证，巩固了北美等高端市场准入。
- **[自主品牌进入北美主流渠道]** -> [品牌溢价与客户粘性]: 自主品牌产品已进入COSTCO、HOME DEPOT等美国主流商超，草坪机首次进入北美商超渠道，降低了单纯OEM模式的风险，提升了长期客户价值。
- **[国内收入高增，海外收入下滑]** -> [市场结构变化]: 国内收入同比增长28.53%，而国外收入同比下降2.87%，显示公司正积极拓展内需市场，但海外核心市场（北美）增长乏力，对整体盈利贡献减弱。
- **[存货与应收账款高企]** -> [现金流压力]: 存货同比增长8.96%，应收账款维持高位，导致经营活动现金流净额同比下降40.73%，表明公司营运资金占用增加，盈利质量有所下降。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 尽管营收创下新高，但毛利率下滑（终端类产品毛利率下降7.95个百分点）和费用刚性增长（管理费用、研发费用合计增加超6700万元）已导致净利润连续两年大幅下滑。若原材料价格（钢材、铜材）继续上涨或人民币升值，公司盈利能力将进一步承压。此外，经营活动现金流大幅萎缩，显示利润的现金含量不足，需警惕营运资金周转风险。

**地缘政治与贸易政策风险高度集中。** 公司海外收入占比超60%，其中美国市场为最大单一市场。虽然已通过越南产能转移部分对冲关税风险，但全球贸易保护主义抬头、中美关系不确定性依然存在。若美国进一步加征关税或实施更严格的非关税壁垒，公司出口业务将遭受直接冲击。同时，公司美国子公司（神驰动力美国）持续亏损（-2630万元），海外运营效率亟待提升。
