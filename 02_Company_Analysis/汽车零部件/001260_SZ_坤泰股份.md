# 001260.SZ 深度透视

## 因果逻辑链
- **[市场竞争加剧]** -> [营收下降3.95%]: 行业“内卷”导致公司簇绒地毯等核心产品销量与单价承压，收入规模缩减。
- **[海外业务前期投入]** -> [净利润下降14.74%]: 墨西哥等海外基地处于建设与爬坡期，前期费用（折旧、人工）增加，侵蚀当期利润。
- **[原材料自产BCF纤维]** -> [毛利率稳定]: 向上游延伸实现BCF纤维自供，有效对冲了PA6切片等石化原材料价格波动，保障了核心产品盈利空间。
- **[新能源汽车渗透率提升]** -> [产品结构变化]: 新能源车对针刺地毯需求增加，公司顺势扩大针刺地毯产能与销售，部分对冲了簇绒地毯下滑。
- **[海外布局（墨西哥、摩洛哥）]** -> [非付现成本高企]: 海外工厂建设导致固定资产折旧与摊销大幅增加，使得经营活动现金流净额（8419万）远高于净利润（4118万）。
- **[汽车行业“年降”惯例]** -> [产品单价承压]: 整车厂逐年要求零部件降价，公司面临持续的定价压力，若新项目承接不足，将导致平均售价下降。
- **[汇率波动]** -> [财务费用大幅减少]: 人民币汇率变动带来汇兑收益，使财务费用从正转负，对利润形成正向贡献。

## 风险警告
公司面临的核心风险是**“增收不增利”的结构性困境**。营收下滑3.95%的同时，净利润下滑14.74%，显示盈利能力正在被侵蚀。海外业务（墨西哥、摩洛哥）的扩张是未来增长点，但当前处于投入期，前期费用高企，且海外运营面临地缘政治、贸易摩擦及管理半径拉长等不确定性，短期将持续拖累利润表现。

另一重大风险是**汽车行业“年降”惯例与原材料价格波动的双重挤压**。公司产品单价逐年下降是行业常态，而主要原材料（PA6切片等）属于石化下游，价格波动剧烈。尽管BCF自产部分对冲了风险，但若原材料价格大幅上涨，而产品降价压力不减，公司毛利率将面临显著下滑风险。同时，公司客户集中度较高，前五大客户占营收38%，若主要客户订单转移，将对业绩造成重大冲击。
