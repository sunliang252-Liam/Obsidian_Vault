# 301539.SZ 深度透视

## 因果逻辑链
- **[美国加征关税]** -> [外销毛利率骤降]: 高毛利客户被迫接受降价，境外毛利率从约23%降至16.07%，直接侵蚀利润。
- **[泰国及新厂区大规模转固]** -> [折旧费用激增]: 2025年折旧摊销同比增加1,474万元（+27.29%），刚性成本上升，利润承压。
- **[铝棒采购均价上涨3.15%]** -> [单位成本上升]: 主要原材料价格上涨，但产品调价存在滞后，成本无法完全转嫁。
- **[乘用车车轮销量增长25.34%]** -> [收入结构优化]: 乘用车业务成为增长主力，收入占比提升至41.14%，对冲商用车市场波动。
- **[泰国子公司产能受限]** -> [订单回流国内]: 第四季度因泰国产能不足，部分订单由国内高关税工厂生产，导致毛利率进一步下滑。
- **[存货大幅增加1.57亿元]** -> [经营活动现金流恶化]: 为配合销售增长备货，存货占压大量资金，导致经营性现金流由正转负至-7,992万元。
- **[境外收入增长15.13%]** -> [汇率波动风险加大]: 境外收入占比提升至40.35%，汇兑损失增加，财务费用同比上升188.49%。
- **[研发投入聚焦轻量化与高端工艺]** -> [技术壁垒加固]: 持续投入锻造工艺、旋压技术及飞行器壳体研发，巩固细分领域先发优势。

## 风险警告
**核心风险：利润被“剪刀差”吞噬。** 公司正处于“增收不增利”的困境：收入增长4.29%，但净利润暴跌44.93%。主要原因在于成本端（折旧、原材料）和收入端（关税导致降价）的双重挤压。美国关税政策是最大变量，直接导致外销高毛利客户降价，而泰国新工厂产能爬坡不及预期，无法完全承接订单转移，导致公司被迫用高成本国内产能应对出口，形成“双重打击”。

**财务风险：现金流急剧恶化，扩张节奏需警惕。** 经营活动现金流净额从+1亿骤降至-7,992万元，与净利润严重背离。公司正处于资本开支高峰期（泰国二期、国内新厂），投资活动现金净流出3.14亿元，主要依赖新增借款（长期借款从2,847万激增至2.59亿）维持。若后续盈利无法改善，高负债扩张将带来流动性压力。同时，前五大供应商采购占比高达88.76%，存在供应链集中风险。

**公司简介（F10 原文）**

> 浙江宏鑫科技股份有限公司创立于2006年,主营业务为汽车锻造铝合金车轮的研发、设计、制造和销售,是国内较早开始应用锻造工艺生产汽车铝合金车轮的高新技术企业,在我国商用车市场成功打破国外品牌对锻造铝合金车轮垄断的局面。公司主要产品为汽车锻造铝合金车轮,包括商用车车轮和乘用车车轮。公司产品已经通过各国专业检测认证,如美国SMITHERS检测、德国FRAUNHOFERLBF检测和巴西INMETRO产品认证等,获得了客户的广泛认同,在全球汽车铝合金车轮市场中占据一席之地。凭借优质的产品,公司荣获了“优质锻件奖”、“最佳客车零部件奖”、“最佳环保科技产品奖”、“瞪羚企业”等多项荣誉奖项,宏鑫牌产品被评为“浙江省名牌产品”。历经十余年坚持不懈的努力,公司在汽车铝合金车轮的生产工艺、产品轻量化等方面取得较大的技术突破。截至2021年12月31日,公司拥有浙江省省级高新技术企业研究开发中心、台州市市级企业技术中心、台州市博士后创新实践基地等。公司产品远销美国、澳洲、加拿大等数十个国家和地区。在汽车整车配套市场,公司产品已直接配套豪梅特、东风柳汽、陕西重汽、比亚迪、中车时代等国内整车制造商或一级供应商,同时,公司积极开拓海外市场,目前已通过J.T.Morton、Superior分别配套美国新能源汽车制造商Rivian、Lucid,并进入Paccar(美国)的供应链。公司秉承“求实、创新、稳健、发展”的经营理念,致力于成为全球锻造铝合金车轮在乘用车市场的最大供应商和在商用车市场的主要供应商,成为世界一流的汽车锻造铝合金车轮专业生产企业。
