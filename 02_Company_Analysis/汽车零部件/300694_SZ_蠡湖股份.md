# 300694.SZ 深度透视

## 因果逻辑链
- **[华庄工厂拆迁补偿确认]** -> [净利润暴增121%]: 报告期内确认资产处置收益1.44亿元，使归母净利润从0.56亿跃升至1.23亿，但扣非净利润同比大降73.25%，显示主业盈利严重恶化。
- **[涡轮壳销量萎缩22%]** -> [营收下滑7.4%]: 传统燃油车涡轮壳销量同比减少19.55%，收入降至5.42亿元，直接拖累整体营收从15.22亿降至14.09亿。
- **[插电混动对冲纯电冲击]** -> [压气机壳逆势增长2.5%]: 混动车型同样需要涡轮增压器，压气机壳销量增长5.49%，收入增至6.97亿元，延缓了纯燃油车市场萎缩的冲击。
- **[人民币升值导致汇兑损失]** -> [财务费用由负转正]: 人民币对美元汇率升值，财务费用从-722.6万元骤增至520.1万元，同比变动-171.98%，侵蚀利润。
- **[大宗商品价格波动]** -> [毛利率承压]: 主要原材料（铝合金、镍板）价格剧烈波动，叠加竞争白热化，压气机壳毛利率下降1.98个百分点，新能源零部件毛利率下降2.44个百分点。
- **[业务重组与工厂搬迁]** -> [短期运营效率受损]: 华庄工厂搬迁导致人员流失，劳务外包费用同比增加33%，同时产能利用率（涡轮壳仅58.18%）偏低，固定成本摊销压力大。
- **[盖瑞特单一客户依赖]** -> [经营风险高度集中]: 第一大客户盖瑞特贡献营收7.21亿元，占比51.14%，且结算币种从美元转为人民币，议价能力受制于单一客户。

## 风险警告
**主业盈利急剧恶化，拆迁收益不可持续。** 公司2025年归母净利润1.23亿元看似亮眼，但扣除非经常性损益后仅0.15亿元，同比暴跌73.25%。核心利润来源是华庄工厂拆迁补偿确认的1.44亿元资产处置收益，属于一次性非经常性损益。剔除该收益后，公司主营业务已陷入微利甚至亏损边缘，经营现金流净额也同比下降15.65%，造血能力显著下滑。

**传统业务萎缩与转型不确定性并存。** 核心产品涡轮壳销量同比下滑近20%，产能利用率仅58%，反映传统燃油车零部件市场正加速萎缩。公司虽布局机器人零部件、氢能船舶等新赛道，但报告期内机器人业务尚未量产，氢能子公司海大清能仍亏损462.87万元，新业务贡献尚需时日。同时，对第一大客户盖瑞特超50%的收入依赖，以及人民币升值带来的汇兑风险，使公司短期经营面临多重压力。
