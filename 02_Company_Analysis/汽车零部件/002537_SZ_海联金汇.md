# 002537.SZ 深度透视

## 因果逻辑链
- **[主动收缩低毛利业务]** -> [营收下降8.05%]: 公司主动控制钢板加工配送等低毛利业务规模，导致总营收下滑，但核心的汽车零部件业务营收逆势增长2.33%。
- **[汽车零部件业务结构优化]** -> [归母净利润暴增511%]: 聚焦高附加值产品（仪表板横梁、热成型门环），叠加非经常性损益（理财收益、政府补助）大幅增加，推动净利润从0.49亿跃升至3.00亿。
- **[第三方支付业务战略性剥离]** -> [营收结构改善]: 拟出售联动支付100%股权，该业务营收同比下降44.22%，占比从21.36%降至12.96%，公司资源加速向智能制造主业集中。
- **[经营现金流大幅转正]** -> [盈利质量提升]: 经营活动现金流净额从-1.21亿大幅转正至6.52亿，主要得益于购买商品支付的现金减少12.82亿元，显示对上游议价能力增强及库存管理优化。
- **[股权激励绑定核心团队]** -> [长期增长动力]: 向高管及核心骨干授予481.7万股限制性股票，设定2025-2027年净利润考核目标（2.5亿/3.25亿/4.225亿），将管理层利益与股东深度绑定。
- **[AI技术赋能运营]** -> [管理效率提升]: 在合同评审、办公协同、数据分析等环节落地AI应用，合同评审效率提升近40%，推动“数智化”转型，降低管理费用。
- **[海外业务孵化取得实质进展]** -> [打开第二增长曲线]: 与海外供应商签署战略协议，孵化KD零件出海业务；为非洲南部国家电信运营商搭建数字支付系统，验证技术出海能力。

## 风险警告
**核心风险在于第三方支付业务剥离的不确定性。** 公司于2024年4月签署协议拟出售联动支付，但该交易尚需央行核准，且协议已满24个月有效期。若审批失败或交易终止，公司将重新背负一个营收萎缩、竞争激烈的支付业务，不仅无法回笼资金，还可能面临监管合规的持续压力，打乱聚焦主业的战略节奏。

**汽车零部件业务面临行业价格战与原材料波动的双重挤压。** 虽然公司通过产品结构优化实现了利润增长，但汽车行业“价格战”持续，主机厂成本压力向上游传导不可避免。同时，钢材、铝材等大宗商品价格波动剧烈，若成本无法完全转嫁，将直接侵蚀公司本已微薄的毛利率（汽车零部件毛利率仅14.58%）。此外，公司计提了1.12亿元的资产减值损失，暗示部分资产或存货面临贬值风险，需警惕后续减值压力。
