# 600960.SH 深度透视

## 因果逻辑链
- **[德国子公司破产出表]** -> [净利润转正]: 渤海国际和BTAH申请破产后不再纳入合并范围，其“超额亏损”转回形成约2.5亿元非经常性投资收益，是公司2025年扭亏为盈的核心原因。
- **[德国子公司破产出表]** -> [营收大幅下滑]: 剔除BTAH合并报表后，公司2025年营业收入同比下降26.31%，主营业务规模显著收缩。
- **[活塞业务受益于数据中心需求]** -> [核心主业盈利]: 子公司活塞有限受益于数据中心发电机组需求增加，大缸径活塞销量同比增长，实现净利润7,280万元，成为公司利润的压舱石。
- **[轻量化与轮毂业务持续亏损]** -> [扣非净利润为负]: 子公司滨州轻量化和泰安启程报告期亏损，导致公司扣除非经常性损益后的净利润为-9,948万元，主业造血能力依然薄弱。
- **[履行境外担保责任]** -> [现金流大幅流出]: 公司为破产的德国子公司履行银行担保代偿责任，导致筹资活动现金净流出3.02亿元，货币资金较期初减少近50%。
- **[推进重大资产重组]** -> [战略转型预期]: 公司拟收购控股股东旗下北汽模塑、廊坊莱尼线束等优质资产，旨在丰富产品矩阵，加速在乘用车和新能源零部件领域的布局。
- **[母公司未弥补亏损]** -> [无法分红]: 截至2025年末，母公司累计未分配利润为-12.22亿元，不满足现金分红条件，公司拟通过公积金弥补亏损以恢复分红能力。

## 风险警告
**核心风险在于盈利的“一次性”与主业的“持续性”背离。** 2025年净利润转正完全依赖于德国子公司破产出表带来的非经常性收益，而扣非净利润仍为巨额亏损。这意味着，剔除会计处理的影响，公司核心的活塞、轻量化、轮毂等业务并未实现根本性好转，尤其是滨州轻量化和泰安启程持续亏损，正在侵蚀活塞业务的利润成果。

**财务风险与经营风险叠加。** 为德国子公司担保代偿导致公司现金大幅消耗，货币资金锐减，同时负债率攀升。公司虽在推进重大资产重组，但重组能否成功、注入资产能否有效整合并扭转亏损局面，均存在重大不确定性。若重组失败或整合效果不佳，公司可能面临“主业失血+财务承压”的双重困境。
