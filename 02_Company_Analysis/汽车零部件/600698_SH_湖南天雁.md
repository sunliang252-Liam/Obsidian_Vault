# 600698.SH 深度透视

## 因果逻辑链
- **[营收增长但利润巨亏]** -> [净利润-3131万元]: 营收增长19.3%至5.16亿，但行业价格战导致毛利率仅8.57%，规模不足以覆盖固定成本，叠加2024年有资产收储收益而2025年无此非经常性收益，导致由盈转亏。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比76.78%，其中第一大客户长安汽车占比高达52.86%，公司业绩高度依赖单一客户订单。
- **[研发投入资本化率高]** -> [未来摊销压力]: 研发投入总额5469万元，资本化比例高达68.96%，大量研发支出未费用化，未来将转为无形资产摊销，持续侵蚀利润。
- **[存货激增]** -> [资金占用与跌价风险]: 存货同比增加51.58%至1.29亿元，远超营收增速，库存增压器同比暴增62.74%，存在跌价风险。
- **[经营性现金流改善]** -> [造血能力弱化]: 经营活动现金流净额4696万元，同比大幅改善，但主要依赖现款流入增加，利润端持续亏损，造血能力本质脆弱。
- **[传统业务萎缩]** -> [转型压力]: 气门销量同比减少20.59%，传统内燃机业务受新能源替代冲击，而新业务电子水泵等尚处批量配套初期，规模效应未显。
- **[累计未分配利润巨额亏损]** -> [分红能力丧失]: 累计未分配利润-9.4亿元，公司长期无法分红，股东回报缺失。

## 风险警告
**核心风险在于“增收不增利”的结构性困境与客户依赖。** 公司营收增长19.3%，但净利润由盈转亏至-3131万元，主因是汽车行业价格战导致毛利率极低（8.57%），规模无法覆盖成本。更关键的是，公司对第一大客户长安汽车的销售占比高达52.86%，业绩高度绑定单一客户，议价能力弱，一旦客户压价或订单转移，公司将遭受致命打击。

**研发资本化与存货激增是隐藏的财务风险。** 公司研发投入资本化率高达68.96%，大量研发支出未计入当期费用，粉饰了利润表，但未来将形成无形资产摊销，持续压制利润。同时，存货同比暴增51.58%，其中增压器库存量同比飙升62.74%，远超销量增速，表明公司可能面临产品滞销和跌价损失，进一步恶化现金流与利润。

**公司简介（F10 原文）**

> 湖南天雁机械股份有限公司隶属于中国兵器装备集团有限公司,是其旗下中国长安汽车集团有限公司的控股子公司。专注涡轮增压器、高性能气门、冷却风机等发动机零部件及高铁动车冷却风机的研发、生产和销售。公司位于湖南省衡阳市石鼓区合江套,交通便利,区位优势明显。是国家火炬计划重点高新技术企业、全国内燃机标准化技术委员会涡轮增压器工作组组长单位,建有国家认定企业技术中心、博士后科研工作站和湖南省车用涡轮增压器工程技术中心。公司始建于1950年,始称衡阳市大利工矿药品厂,1966年更名为向阳机械厂。1991年三线调迁,原红远机械厂(怀化溆浦县)、红灵机械厂(怀化辰溪县)搬迁至衡阳,与向阳机械厂合并组建湖南江雁机械厂。2003年改制重组,成立湖南天雁机械有限责任公司。2012年借壳,2014年完成工商变更,组建湖南天雁机械股份有限公司,同年5月恢复交易,股票名称湖南天雁,A股代码600698。公司产品覆盖发动机功率范围30KW-2000KW,排量0.8L-30L。广泛应用于工程机械、车用机械、农用机械、船用机械及高铁动车等领域,与国内长安汽车、东安动力、潍柴、锡柴、玉柴、大柴、全柴等国内知名企业建立了稳定的配套和战略合作关系,产品远销往欧美、东南亚等国家和地区。
