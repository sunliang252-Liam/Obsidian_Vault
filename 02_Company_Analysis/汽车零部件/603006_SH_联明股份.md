# 603006.SH 深度透视

## 因果逻辑链
- **[减资退出亏损子公司骏和实业]** -> [归母净利润大增46.56%]: 剥离骏和实业（51%股权）获得处置收益792万元，同时不再合并其亏损，显著增厚归母净利润。
- **[汽车行业产销超预期增长]** -> [营收增长10.32%]: 2025年乘用车产销同比增长9.2%，公司车身零部件业务受益于行业景气，收入增长13.77%。
- **[采购支出减少]** -> [经营现金流暴增111.85%]: 报告期内采购支出大幅减少，使得经营活动现金流净额从0.95亿跃升至2.02亿，现金流质量显著改善。
- **[车身零部件业务成本上升]** -> [毛利率下滑1.19个百分点]: 直接人工（+66.21%）和制造费用（+31.14%）大幅增加，侵蚀了收入增长带来的利润空间。
- **[金融资产公允价值变动]** -> [非经常性损益波动]: 理财产品及私募基金公允价值变动损失1194万元，成为利润的负向扰动项。
- **[客户高度集中]** -> [经营稳定性依赖大客户]: 前五名客户销售额占比74.96%，主要依赖上汽通用、上汽大众，订单波动直接影响公司业绩。
- **[存货与固定资产减值]** -> [资产减值损失扩大]: 计提存货跌价损失及固定资产减值准备3116万元，同比大增140%，反映部分资产运营效率或盈利能力下降。

## 风险警告
**核心风险在于客户集中度过高与成本侵蚀利润。** 公司近75%收入来自上汽通用、上汽大众两大客户，任何订单转移或车型销量下滑都将直接冲击经营。同时，车身零部件业务直接人工和制造费用大幅攀升，导致毛利率持续下滑，收入增长并未有效转化为利润增长。

**资产质量与投资回报存在隐忧。** 公司大量资金用于购买理财产品（期末余额4.72亿），但金融资产公允价值变动已产生亏损。同时，三家汽车零部件子公司（烟台万事达、沈阳联明、武汉联明）合计亏损超2200万元，资产减值损失同比翻倍，显示部分业务单元经营承压，资产回报效率有待提升。

**公司简介（F10 原文）**

> 上海联明机械股份有限公司一直致力于汽车零部件业务的发展,主营业务为汽车冲压及焊接总成零部件的开发、生产与销售,公司经过多年发展和研发积累,掌握了冲压与焊接的核心生产工工艺,是一家专业的汽车零部件制造商,为上汽通用、上汽大众的一级供应商。目前汽车零部件业务已经完成全国“四地五厂”的产能布局,即在上海金桥、上海空港、山东烟台、辽宁沈阳、湖北武汉建设有五大生产基地,为公司汽车零部件业务的持续发展奠定了坚实的基础。2015年,公司通过收购上海联明晨通物流有限公司,进入物流领域,提供供应链管理的第三方物流服务。目前公司物流业务的主要客户分布在汽车行业内,汽车行业供应链管理服务是其核心竞争力之一,这将提升公司为汽车制造商提供综合服务的能力,制造与物流将形成良好的协同发展效应,有利于提升公司综合竞争力。2021完成了联明包装的收购,由此公司在物流领域形成覆盖包装器具规划、设计和制造、物流供应链管理的服务能力,打通了物流产业链的上下游。随着公司的不断发展壮大,公司在技术开发、生产设备、质量保证和公司管理等各方面的投入和实力均在不断提高。公司将继续秉承“以超值的产品和周到的服务赢得顾客的首选”的质量方针,倾力打造行业领先的汽车零部件制造商和物流服务供应商。
