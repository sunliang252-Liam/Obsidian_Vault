# 605018.SH 深度透视

## 因果逻辑链
- **[冲焊件销量增加但收入下降]** -> [整体营收下滑]: 产品结构向低价值小件倾斜，大件产品销量减少，导致冲焊件收入同比下降12.38%，拖累总营收下降2.34%。
- **[紧固件业务量价齐升]** -> [利润稳定器]: 紧固件营收同比增长9.34%，毛利率高达24.74%，成为公司最稳定的利润来源，对冲了冲焊件业务的疲软。
- **[新能源定点项目爆发]** -> [未来增长蓄力]: 2025年新增超亿元定点项目累计超40亿元，其中新能源产品占比82.86%，为未来2-3年业绩增长奠定坚实基础。
- **[新设四大事业部]** -> [开辟第二增长曲线]: 设立制动、机器人、轻量化、航空事业部，碳陶刹车盘已量产，行星滚柱丝杠已送样，低空经济产品获定点，多元化布局初见成效。
- **[武汉长源及广东长华亏损]** -> [侵蚀集团利润]: 受日系客户销量下滑及新产能爬坡影响，武汉长源和广东长华分别亏损1724万和1676万，是净利润下滑16.22%的主要原因。
- **[原材料价格波动风险]** -> [毛利率承压]: 钢材为主要原材料，价格波动直接影响成本，尽管紧固件毛利率稳定，但冲焊件毛利率已下降1.22个百分点。
- **[客户集中度高]** -> [经营依赖风险]: 前五大客户销售额占比52.85%，若主要客户经营恶化或流失，将对公司业绩产生重大不利影响。

## 风险警告
**核心风险在于传统业务失速与新业务兑现的不确定性。** 公司2025年营收与净利润双降，核心原因是冲焊件业务量增价减，且两大子公司（武汉长源、广东长华）持续亏损，侵蚀了紧固件业务的利润。这表明公司传统汽车金属结构件业务正面临激烈的市场竞争和产品结构升级压力，增长动能减弱。

**新业务（碳陶刹车、人形机器人、低空经济）虽前景广阔，但均处于早期阶段。** 行星滚柱丝杠尚未获得客户定点，碳陶刹车市场渗透率极低，低空经济政策落地尚需时日。这些业务短期内无法贡献实质性利润，且研发投入和产能建设将持续消耗现金流。若新业务拓展不及预期，公司将陷入“传统业务萎缩、新业务青黄不接”的困境，业绩可能进一步下滑。
