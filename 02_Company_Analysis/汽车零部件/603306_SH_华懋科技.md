# 603306.SH 深度透视

## 因果逻辑链
- **[汽车行业景气度提升]** -> [营收创历史新高]: 2025年国内汽车产销量同比增长超9%，公司作为被动安全龙头，受益于行业增长，全年营收25.03亿元，同比增长13.12%。
- **[执行员工持股计划]** -> [净利润下滑21.51%]: 本期确认股份支付费用9,924.72万元，较上年增加9,370.82万元，直接侵蚀利润，是归母净利润同比下降的核心原因。
- **[越南新基地产能爬坡]** -> [越南子公司亏损]: 新生产基地折旧摊销费用增加，导致越南子公司净利润亏损1,025.19万元，同比下降127.38%，拖累整体业绩。
- **[可转债利息费用化]** -> [财务费用激增]: 因厂房投入使用，可转债利息全额费用化，叠加新增贷款利息，财务费用同比增加4,907.83万元，增幅达29,314.48%。
- **[票据结算占比提升]** -> [经营性现金流减少]: 报告期内货款以票据结算占比上升，导致销售商品收到的现金减少，经营活动现金流净额同比下降36.53%。
- **[战略入股富创优越]** -> [切入光通信EMS赛道]: 公司出资3.95亿元持有富创优越42.16%股权，并启动对其剩余股权的收购，旨在切入高速光模块等电子制造服务领域，打造第二增长曲线。
- **[收购东阳华芯]** -> [布局新材料上游]: 公司收购东阳华芯控股权，计划建设车规级有机硅、改性TPU等产线，旨在向上游核心材料延伸，保障供应链安全并挖掘新增长点。

## 风险警告
**核心风险在于“增收不增利”的困境与多元化转型的不确定性。** 公司主业虽稳健增长，但利润被股份支付、越南产能爬坡及财务费用三重因素严重侵蚀，导致净利润与营收严重背离。剔除股份支付和可转债利息后，公司扣非净利润虽有增长，但真实盈利能力仍受制于高昂的激励成本和财务负担。此外，公司通过并购大举进入光通信EMS和新材料领域，但新业务与主业协同效应尚待验证，且面临整合风险与业绩承诺压力。

**重大资产重组与参股公司业绩风险不容忽视。** 公司对富创优越的收购尚需监管审批，存在不确定性。同时，参股的徐州博康（光刻胶业务）连续巨额亏损，三年累计净利润远未达业绩承诺，公司虽计划择机处置，但该笔投资已形成重大减值风险，对长期股权投资价值构成潜在威胁。越南基地的产能利用率能否快速提升，也是决定海外战略成败的关键。
