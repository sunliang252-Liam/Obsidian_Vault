# 300893.SZ 深度透视

## 因果逻辑链
- **[国产替代与客户拓展]** -> [业绩高速增长]: 公司抓住国产替代机遇，新获奇瑞、吉利、大众等207个新项目，带动安全带、气囊、方向盘三大产品销量分别增长21%、67%、147%，驱动营收增长35.88%。
- **[全产业链垂直一体化]** -> [成本优势与供应链安全]: 公司自建织带、气囊布、气体发生器等核心零部件自制能力，形成“松原模式”，在降本增效的同时保障供应链自主可控，支撑毛利率稳定在28.49%。
- **[气囊与方向盘业务放量]** -> [产品结构优化]: 气囊和方向盘收入分别增长49.67%和163.83%，占总营收比例从30.75%提升至39.46%，成为第二增长曲线，降低对安全带单一产品的依赖。
- **[产能扩张与基地建设]** -> [规模效应与客户响应]: 巢湖、马来西亚、西安等基地陆续投产，实现就近配套，提升客户响应速度，为承接更多订单提供产能基础。
- **[C-NCAP 2024法规升级]** -> [产品技术升级]: 更严格的碰撞测试标准（如提高碰撞速度、增加远端乘员评价）推动公司开发零重力座椅安全带、遮阳板气囊、远端气囊等高端产品，提升单车价值量。
- **[研发投入高强度]** -> [技术壁垒构建]: 研发费用同比增长70.25%至1.67亿元，聚焦小型化卷收器、PET气袋、健康监测方向盘等前沿技术，巩固与外资巨头竞争的技术护城河。
- **[马来西亚基地量产]** -> [全球化经营起步]: 马来西亚基地于2025年Q3量产，并进入Perodua供应商名录，标志着公司从国内走向全球的战略落地，打开海外市场空间。

## 风险警告
**客户集中度与应收账款风险**：公司前五大客户销售占比高达73.63%，其中客户一和客户二合计占比超53%。虽然与主要客户合作关系稳定，但过度依赖少数大客户，一旦核心客户需求波动或出现经营困难（如合众汽车重整导致3379万元应收账款全额计提坏账），将对公司业绩和现金流产生重大冲击。报告期内应收账款达11.3亿元，同比增长11.5%，且经营活动现金流净额同比大幅下滑81.22%，需警惕回款压力。

**产能扩张与现金流错配风险**：公司正处于大规模产能建设期（巢湖、西安、星盾等基地），资本开支巨大，导致投资活动现金流净流出4.63亿元。尽管营收和利润高速增长，但经营活动现金流仅2619万元，与3.66亿净利润严重背离，主要系存货和应收款增加。若下游需求增速放缓或客户付款周期延长，公司可能面临流动性压力，需依赖外部融资维持扩张节奏。
