# 603013.SH 深度透视

## 因果逻辑链
- **[混动汽车高压燃油系统需求爆发]** -> [燃油箱销量与营收创历史新高]: 插混/增程式车型销量增长，直接拉动公司核心产品混动高压燃油系统订单大幅超越传统燃油系统。
- **[收购赢双科技，切入旋转变压器赛道]** -> [新增业务增长极与协同效应]: 控股收购国内旋变龙头，实现“储能系统+新能源核心部件集成”战略落地，并贡献并表利润。
- **[海外市场营收高速增长]** -> [全球化布局对冲国内价格战风险]: 海外营收同比增长27.95%，印度、捷克、墨西哥等基地供货量两位数增长，有效分散单一市场风险。
- **[精细化管理与降本增效]** -> [毛利率保持稳定]: 在整车厂持续压价背景下，通过智能制造、数字化和成本控制，主营业务毛利率同比提升0.21个百分点。
- **[新业务（热管理、电池包壳体）项目定点突破]** -> [构建第二增长曲线]: 热管理核心零部件多通水阀实现“从0到1”定点，电池包壳体获新项目并批量供货，为未来收入结构转型奠基。
- **[研发投入持续高企]** -> [技术壁垒与产品迭代能力]: 研发费用3.38亿元，获23件发明专利，取得氢能特种设备制造许可证，支撑储氢、热管理等前沿技术储备。
- **[大比例现金分红与股份回购]** -> [股东回报意愿强烈]: 全年现金分红加回购合计占归母净利润57.45%，彰显公司对股东价值的重视及对未来现金流的信心。

## 风险警告
**核心风险在于传统燃油车业务的长期萎缩与新能源转型的节奏错配。** 尽管混动系统短期对冲了部分下滑，但纯电动化趋势不可逆，公司传统燃油系统业务面临被逐步替代的根本性挑战。新业务（热管理、电池包、储氢）目前营收占比极低，尚处于投入期，能否快速放量并形成规模利润存在重大不确定性。

**国际化运营与并购整合风险不容忽视。** 海外业务虽增长强劲，但毛利率（11.27%）显著低于国内（17.10%），且面临地缘政治、贸易壁垒及汇率波动等复杂挑战。同时，对赢双科技的高溢价收购（形成2.3亿元商誉）存在减值风险，若未来业绩不达预期，将直接冲击利润表。
