# 603202.SH 深度透视

## 因果逻辑链
- **[海外出口收入下滑]** -> [营收与利润双降]: 双联屏仪表海外销量同比下降33.78%，导致整体营收下降10.46%，净利润下降18.88%。
- **[研发投入大幅增加]** -> [侵蚀短期利润]: 研发费用同比增长43.41%至2.35亿元，研发人员增加411人，是利润下滑的核心费用驱动因素。
- **[IPO募资到账]** -> [净资产与总资产暴增]: 首发上市募集资金，使净资产增长136.22%，总资产增长75.65%，显著摊薄了加权平均净资产收益率。
- **[客户高度集中]** -> [经营依赖单一客户]: 前五大客户销售额占比78.57%，其中单一客户占比高达49.27%，存在重大客户依赖风险。
- **[绥化基地成本优势]** -> [高毛利率护城河]: 依托黑龙江绥化低成本土地与人工，以及高比例自制零部件，实现国外业务毛利率47.92%，远超国内。
- **[全球化产能布局]** -> [对冲贸易政策风险]: 墨西哥工厂投产、摩洛哥子公司设立、拟收购德国克莱默，构建北美、欧洲、亚洲三角产能网络。
- **[两轮车市场拓展]** -> [打造第二增长曲线]: 已与雅迪、爱玛等头部两轮车企业建立合作，开辟新赛道以对冲汽车仪表市场波动。

## 风险警告
**核心风险在于对单一客户的极度依赖与海外收入的不确定性。** 公司近50%营收来自单一客户（推测为现代起亚集团），且海外收入占比近半。2025年双联屏仪表海外销量骤降33.78%，直接导致营收利润双杀。若该客户订单持续萎缩或地缘政治导致贸易壁垒升级，公司业绩将面临断崖式下跌风险。

**第二重风险是盈利能力的可持续性。** 公司上市后ROE从49.40%骤降至16.23%，净资产被巨额募资大幅摊薄。同时，研发费用激增43%虽为长远布局，但短期内严重侵蚀利润。若新业务（两轮车、智能座舱）拓展不及预期，高昂的研发投入将无法转化为有效产出，公司可能陷入“增收不增利”甚至“减收减利”的困境。
