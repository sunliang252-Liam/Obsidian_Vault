# 301581.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧，产品价格下降]** -> [净利润同比下滑50.83%]: 尽管营收增长17.03%，但激烈的市场竞争导致核心产品铜针式散热基板毛利率下降12.85个百分点，叠加原材料铜价上涨，利润被严重侵蚀。
- **[原材料铜价大幅上涨]** -> [营业成本增速远超营收]: 铜排、铜板为主要原材料，2025年铜价处于历史高位，导致营业成本同比增长32.81%，远高于营收17.03%的增速。
- **[核心产品铜针式散热基板销量增长27.86%]** -> [营收增长17.03%]: 通过“保份额”策略，以价换量，销量增长部分抵消了单价下降对营收的负面影响。
- **[内销收入增长31.71%，外销下降45.78%]** -> [营收结构向国内倾斜]: 公司策略性聚焦国内市场，内销占比从81.06%提升至91.23%，但海外市场拓展受挫。
- **[募投项目第一期投产]** -> [新增25万片/月产能]: 产能提升项目逐步落地，为未来业务规模扩大提供保障，但短期内增加了折旧和固定成本。
- **[存货大幅增长68.22%]** -> [经营活动现金流净额为负]: 为保障订单交付而增加库存备货，占用了大量营运资金，导致经营活动现金流净额由正转负。
- **[与英飞凌、博世等头部客户深度绑定]** -> [维持48.89%的前五大客户集中度]: 高客户壁垒和同步研发能力是公司抵御竞争、维持市场份额的核心护城河。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 公司营收增长17%的同时，净利润腰斩，毛利率大幅下滑，表明其在产业链中的议价能力正在被削弱。原材料铜价高位运行与产品降价的双重挤压是短期无法缓解的结构性矛盾，若价格传导机制无法完全覆盖成本上涨，盈利能力将持续承压。此外，经营活动现金流由正转负，显示公司营运资金管理面临挑战，财务健康度下降。

**第二重风险来自行业竞争格局的恶化。** 新能源汽车市场增速放缓，下游整车厂降本压力向上游传导，散热基板行业新进入者增多，价格战可能成为常态。公司过度依赖单一产品（铜针式散热基板占营收70%）和国内市场（占营收91%），若技术路线发生变革（如SiC对散热需求变化）或海外市场拓展不及预期，业绩将面临较大波动甚至亏损风险。
