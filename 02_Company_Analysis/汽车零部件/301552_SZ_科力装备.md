# 301552.SZ 深度透视

## 因果逻辑链
- **[新能源汽车爆发式增长]** -> [营收增长10.7%]: 2025年国内新能源汽车产销量同比增超28%，带动公司风挡玻璃安装组件等核心产品需求。
- **[深度绑定福耀玻璃等全球前四大汽车玻璃厂商]** -> [客户高度集中，前五客户占比93.26%]: 公司凭借同步开发能力进入全球供应链，福耀玻璃一家贡献65.64%营收，形成强依赖。
- **[“汽车零部件+纳米涂装新材料”双轮驱动战略]** -> [布局第二增长曲线]: 新设微纳新材、控股北京银合汇，切入抗VOC污染吸光涂层等新材料赛道，旨在突破单一主业天花板。
- **[募投项目产能逐步释放]** -> [固定资产同比大增112.6%]: 房屋建筑物及机器设备增加，在建工程部分转固，为后续规模化生产奠定基础。
- **[研发投入持续增长10.3%]** -> [巩固技术壁垒]: 研发人员增至205人，聚焦摄像头支架、轻量化材料等前沿技术，维持“国内规模最大”的细分龙头地位。
- **[经营活动现金流净额同比骤降57.09%]** -> [现金流压力显现]: 主要系上期开具的承兑汇票本期集中兑付，导致现金流出大幅增加，盈利质量有所下降。
- **[非经常性损益贡献利润]** -> [扣非净利润同比下滑1.62%]: 2025年非经常性损益达1192万元（主要为理财收益），掩盖了主业盈利能力的微弱下滑。

## 风险警告
**客户极度集中与单一客户依赖风险。** 公司前五大客户销售额占比高达93.26%，其中对福耀玻璃的依赖度高达65.64%。这种“一荣俱荣”的格局意味着，一旦福耀玻璃调整采购策略、自身经营波动或转向竞争对手，公司将面临营收断崖式下跌的风险，议价能力也受到严重制约。

**盈利质量恶化与增长放缓风险。** 尽管营收增长10.7%，但扣非净利润同比下滑1.62%，且经营活动现金流净额腰斩（-57.09%），显示主业增长乏力且回款能力恶化。公司毛利率同比下降3.18个百分点，成本端压力（直接材料成本上涨27.23%）正在侵蚀利润空间。高额理财收益掩盖了主业的真实盈利状况，可持续性存疑。
