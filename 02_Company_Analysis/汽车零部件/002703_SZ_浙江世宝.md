# 002703.SZ 深度透视

## 因果逻辑链
- **[中国品牌乘用车市占率提升]** -> [营收增长31.76%]: 公司深度绑定吉利、奇瑞等自主品牌，受益于其销量增长，转向系统出货量同比大增36.21%。
- **[电动化、智能化转向系统放量]** -> [产品结构升级]: R-EPS等高端产品量产，带动公司从传统机械转向向高附加值电动转向转型，支撑营收规模跨越35亿。
- **[产品售价承压]** -> [毛利率下降2.4个百分点]: 下游整车厂价格战压力向上游传导，公司议价能力相对弱势，导致主营业务毛利率从19.82%降至17.42%。
- **[研发高强度投入]** -> [技术护城河]: 研发费用同比增35.05%至2.16亿，聚焦线控转向、后轮转向等前沿技术，为高阶自动驾驶商业化储备核心能力。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户贡献70%营收，其中吉利与奇瑞合计占比超57%，单一客户订单波动将剧烈影响公司业绩。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额从116万激增至2.34亿，表明收入增长伴随回款效率改善，利润含金量显著提高。
- **[募投项目延期]** -> [产能释放节奏放缓]: 三大核心募投项目均延期至2026年，短期内新增产能对业绩的贡献存在不确定性，需关注后续投产进度。

## 风险警告
**核心风险在于“增收不增利”的剪刀差持续扩大。** 公司营收增长31.76%，但归母净利润仅增长21.05%，核心原因是毛利率下滑。在整车厂持续降本的压力下，公司作为Tier 1供应商的议价能力被持续削弱。若产品售价下行趋势无法逆转，即便销量增长，利润增速也将持续跑输营收，侵蚀股东回报。

**客户集中度过高与海外市场收缩构成双重脆弱性。** 吉利、奇瑞两大客户贡献超57%营收，任何一家客户的销量波动或供应链调整都将对公司造成重大冲击。同时，境外收入同比骤降52.95%，显示海外市场拓展遭遇瓶颈，公司增长过度依赖国内自主品牌，缺乏风险对冲。
