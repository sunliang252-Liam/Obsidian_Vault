# 001311.SZ 深度透视

## 因果逻辑链
- **[下游客户价格压力与年降机制]** -> [毛利率暴跌7.10个百分点至13.98%]: 整车厂价格战向上游传导，叠加“一品一点”模式下的年降条款，直接侵蚀公司利润空间。
- **[一体化压铸业务产能爬坡]** -> [净利润同比下降44.84%]: 新业务虽进入规模化量产期，但前期高昂的管理费、制造费及资产折旧摊销尚未被收入覆盖，形成“增收不增利”的典型困境。
- **[原材料成本大幅上升]** -> [营业成本增速(27.24%)远超营收增速(16.73%)]: 直接材料占成本比重超82%，钢材、铝材价格波动直接冲击主营业务毛利率。
- **[新能源客户收入占比超80%]** -> [营收逆势增长16.73%]: 成功绑定特斯拉、理想、蔚来等头部新能源车企，对冲了传统燃油车客户销量波动风险。
- **[资本开支与产能扩张]** -> [在建工程同比激增276%]: 常州、金华、上海临港及西班牙基地同步建设，固定资产折旧压力将持续压制短期利润。
- **[“一品一点”配套模式]** -> [前五大客户集中度高达83.42%]: 深度绑定核心客户，但单一车型销量波动将直接导致公司订单剧烈震荡。
- **[机器人零部件业务布局]** -> [新增亏损源与战略期权]: 设立达亚智能布局新赛道，但当前处于投入期，短期内无法贡献利润，且存在产业化失败风险。

## 风险警告
**核心风险：利润断崖式下跌与现金流恶化。** 2025年净利润同比暴跌44.84%，而经营性现金流净额也下滑16.89%。更严峻的是，公司宣布2025年度不进行现金分红，理由是为一体化压铸、西班牙基地及机器人新业务储备资金。这直接暴露了公司当前盈利能力的脆弱性——新业务不仅未能贡献利润，反而成为吞噬现金流的“黑洞”。若一体化压铸业务无法在2026年如期实现盈亏平衡，公司将面临“增收不增利”长期化的困境。

**结构性风险：客户集中度与单一车型依赖。** 前五大客户贡献超83%营收，且“一品一点”模式意味着公司命运与特定车型销量深度绑定。2025年部分客户车型更新换代已导致公司产品销售量同比下降7.58%。在新能源汽车竞争白热化的背景下，任何核心客户的车型销量不及预期或切换供应商，都将对公司造成毁灭性打击。同时，公司因募集资金使用违规被监管警示，暴露出内部治理在高速扩张期的潜在漏洞。
