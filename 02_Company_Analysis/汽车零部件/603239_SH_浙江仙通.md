# 603239.SH 深度透视

## 因果逻辑链
- **[下游客户销量增长]** -> [营收创新高]: 2025年汽车产销再创新高，公司作为本土密封条龙头，核心客户（吉利、长安、奇瑞、上汽大众等）销量增长，直接拉动公司营收同比增长24.31%至15.22亿元。
- **[无框车门渗透率提升]** -> [高端产品放量]: 无边框车门成为新能源车主流配置，公司同步开发的无框密封条（如上汽大众CS41等）进入量产，带动橡胶密封条收入同比增长26.23%，产品结构升级。
- **[工装模具自制率超90%]** -> [成本控制优势]: 公司90%以上模具自行研发制造，相比委外加工大幅降低成本，同时通过岛区化生产、优化采购流程，在主机厂年降压力下维持28.19%的高毛利率。
- **[研发投入与同步开发能力]** -> [客户粘性增强]: 公司具备与整车厂同步开发能力，研发费用投入5525万元，全年承接127个产品项目，深度绑定一汽大众、上汽大众、吉利等头部客户，形成封闭生态壁垒。
- **[国资控股背景]** -> [治理与资源赋能]: 实控人为台州市国资委，控股股东台州五城及间接控股股东台州科创集团提供国资平台资源，助力公司规范治理、产能扩张及机器人产业落地。
- **[主动布局机器人产业]** -> [第二增长曲线]: 公司投资4000万元入股浩海星空（10%），并合资设立台州浩海仙通，切入人形机器人整机生产，2026年已获1.2亿元委托生产框架协议及1000台防爆机器人订单，开辟新主业。
- **[高分红政策]** -> [股东回报稳定]: 上市以来年均分红比例达70%，2025年拟每10股派3元，合计派现8122万元，持续高分红策略有效维护市值稳定并回馈投资者。

## 风险警告
**核心风险在于汽车行业“内卷式”竞争向供应链的传导。** 主机厂价格战常态化，持续向供应商施压年降要求，公司虽具备成本优势，但毛利率已出现微降（汽车零部件业务毛利率同比减少0.30个百分点）。若行业价格战进一步加剧，或原材料价格大幅上涨，公司盈利能力将面临侵蚀。此外，公司前五大客户销售额占比高达85.96%，客户集中度极高，单一客户订单波动将对业绩产生重大影响。

**第二增长曲线（机器人业务）存在高度不确定性。** 公司跨界进入人形机器人领域，虽已获得初步订单，但该行业尚处早期，技术路线、商业化落地、市场竞争格局均未定型。公司能否将汽车精密制造能力有效迁移至机器人整机生产，以及合资公司能否持续获取订单并实现盈利，均需长期验证。初期投入4000万元股权投资及合资公司运营成本，若业务不及预期，将拖累整体财务表现。
