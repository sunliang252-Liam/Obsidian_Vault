# 603352.SH 深度透视

## 因果逻辑链
- **[新能源渗透率提升]** -> [收入增长31.25%]: 公司紧跟新能源汽车市场结构性调整，2025年新能源车型收入占比升至79.04%，驱动整体营收规模大幅提升。
- **[客户结构优化]** -> [前五大客户集中度65.28%]: 深度绑定长安、吉利、蔚来、理想、比亚迪等头部自主及新势力品牌，客户质量高且合作稳定，但存在依赖风险。
- **[产能扩张与资本开支]** -> [投资现金流净流出9.73亿元]: 为匹配新车型订单，公司大规模投资宜宾、金华等新基地及现有产线技改，在建工程同比暴增260%，资本开支压力巨大。
- **[规模效应与成本控制]** -> [毛利率微降0.88个百分点]: 尽管收入增长31.25%，但营业成本增速（35.60%）高于收入，直接材料及人工成本上升侵蚀了部分利润空间。
- **[研发投入与模具自制]** -> [模具业务毛利率提升7.92个百分点]: 子公司大江至信强化模具开发能力，实现“开发多投入，量产效率高”，模具自供降低了综合成本并提升了产品开发效率。
- **[智能制造与自动化]** -> [机器人业务收入增长156.48%]: 子公司衍数自动化提供产线集成方案，超1800台焊接机器人工作站提升了生产柔性和效率，成为新的增长点。
- **[票据贴现与现金流管理]** -> [经营性现金流净额下降44.43%]: 期末大量应收票据及应收款项融资已贴现但未到期，导致经营性现金流与净利润严重背离，需关注回款质量。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长31.25%至40.53亿，但归母净利润仅增长11.52%，毛利率下滑0.88个百分点，显示成本压力（原材料、人工）和行业年降压力正在侵蚀利润。更严峻的是，经营性现金流净额同比暴跌44.43%至2.33亿，远低于净利润，主因是大量票据贴现未到期。这反映出公司为扩张业务，在客户回款上做出了较大让步，现金流质量堪忧。

**其次，高资本开支与高负债率带来的财务风险不容忽视。** 公司为匹配新能源客户需求，正进行大规模产能扩张（在建工程增260%），导致投资性现金流净流出近10亿，并推高有息负债（短期借款+长期借款合计超17亿）。公司资产负债率已升至65.86%，且存在42.82%的净资产担保比例。若下游客户销量不及预期或行业竞争加剧导致产能利用率下降，公司将面临巨大的折旧摊销压力和偿债风险。
