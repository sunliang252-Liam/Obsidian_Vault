# 002766.SZ 深度透视

## 因果逻辑链
- **[核心大项目（三菱重工OBU）执行完毕]** -> [营收骤降47.38%]: 2025年OBU项目基本执行完毕，导致汽车电子业务收入同比腰斩，是营收从14亿降至7.36亿的直接原因。
- **[新项目尚处孵化期，未形成规模收入]** -> [净利润由盈转亏]: 智能舱驾、5G TBOX等新业务虽取得突破，但尚未量产放量，无法弥补主力项目退坡带来的收入缺口，导致归母净亏损5506万元。
- **[收到控股股东3.18亿业绩补偿款]** -> [筹资现金流大幅改善]: 汤和控股因未完成2022-2024年累计4.2亿净利润的业绩承诺，支付3.18亿现金补偿，使筹资活动净现金流达3.53亿元。
- **[海外IOT业务突破，越南量产交付北美运营商]** -> [消费电子业务增长113%]: 成功进入美国高端市场，消费电子收入从2908万增至6201万，成为公司新的增长点。
- **[研发投入持续高企，资本化率大幅降低]** -> [侵蚀当期利润]: 研发费用1.04亿，同比增长16.89%，而研发投入资本化率从34.26%骤降至12.81%，更多研发支出费用化，直接拖累利润表现。
- **[客户集中度极高]** -> [经营风险高度集中]: 前五大客户销售占比高达85.48%，其中第一大客户占比42.79%，公司业绩高度依赖少数核心客户，订单波动风险极大。
- **[母公司未弥补亏损巨大]** -> [长期无法现金分红]: 合并报表未分配利润为-27.25亿元，母公司层面为-22.78亿元，巨额历史亏损使公司在可预见的未来不具备分红能力。

## 风险警告
**核心风险：业绩断崖式下跌与新旧动能转换的“青黄不接”。** 公司2025年营收腰斩、由盈转亏的根本原因在于，支撑过去两年业绩的OBU大项目已执行完毕，而公司寄予厚望的智能舱驾、5G通信等新业务尚处于“小批量量产”或“开发中”阶段，远未形成足以替代旧项目的收入规模。这种“青黄不接”的态势若持续，公司2026年业绩将面临巨大压力，甚至可能继续恶化。

**重大隐忧：极高的客户依赖与羸弱的造血能力。** 前五大客户贡献超85%的收入，单一客户流失即可导致业绩剧烈波动。同时，公司经营活动现金流净额为-3375万元，显示主营业务自身造血能力不足，盈利质量堪忧。尽管收到3.18亿业绩补偿款暂时充实了现金，但这属于一次性非经常性收益，无法掩盖公司核心业务竞争力下滑、增长乏力的本质。
