# 300100.SZ 深度透视

## 因果逻辑链
- **[汽车座椅水平驱动器（HDM）产销量突破3000万件]** -> [营收稳健增长]: 作为国内HDM龙头，规模效应与客户粘性（佛瑞亚、李尔等）保障了核心业务的收入底盘。
- **[新能源电驱动与轮毂轴承切入主流车企]** -> [传动驱动智能业务增长14.83%]: 成功配套比亚迪、蔚来、赛力斯等，受益于新能源汽车渗透率超50%的行业红利。
- **[收购科之鑫，实现丝杠磨床设备自主可控]** -> [人形机器人丝杠产业化突破]: 解决了“卡脖子”设备环节，大幅降低采购成本与周期，首条10万套量产线具备能力。
- **[与清华大学合作分布式电驱动角模块]** -> [开辟智能底盘第二增长曲线]: 首个落地项目“240吨级无人矿卡”已试运营，标志着技术从实验室走向商业化。
- **[泰国工厂投产并获原产地认证]** -> [全球化从“产品出海”深化为“产能出海”]: 规避贸易壁垒，直接服务东南亚新能源车企，提升海外市场响应效率。
- **[研发投入同比增长30.71%]** -> [扣非净利润增长36.63%]: 高强度研发（人形机器人丝杠、角模块、飞行器电驱）转化为高附加值产品，驱动盈利质量显著提升。
- **[组织架构调整，新增创新孵化中心等]** -> [战略转型加速]: 从传统零部件制造商向“智能传动驱动解决方案提供商”的组织保障，支撑新业务落地。

## 风险警告
**核心风险在于新业务（人形机器人、角模块）的产业化不及预期。** 年报明确提示，人形机器人用丝杠及关节模组“尚未获得正式定点”，首条10万套量产线计划2026年6月投产，但客户验证与订单落地存在重大不确定性。角模块虽已试运营，但商业化初期面临技术成熟度、成本控制及市场接受度的挑战，短期内难以贡献实质性利润。

**传统主业面临双重挤压风险。** 一方面，汽车行业价格战持续，整车厂将降价压力向上游传导，公司零部件产品价格承压；另一方面，塑料、钢材等原材料价格波动直接影响制造成本。此外，美国加征关税等国际贸易摩擦可能增加出口成本或导致供应链重构，对公司海外业务（泰国、北美）构成潜在威胁。
