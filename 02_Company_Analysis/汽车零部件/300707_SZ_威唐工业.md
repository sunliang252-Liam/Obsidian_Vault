# 300707.SZ 深度透视

## 因果逻辑链
- **下游新能源汽车客户产销量大幅下降** -> 公司新能源汽车零部件（电池箱体、PHEV冲焊件）产销量大幅下滑: 下游需求减少直接导致公司相关产品订单下降
- **新能源汽车零部件产销量大幅下滑** -> 汽车零部件业务收入下降19.10%，拖累总营收下降5.49%: 新能源汽车零部件收入占比大，其下滑导致整体营收下降
- **原材料采购支出减少** -> 经营活动现金流大幅增长137.03%: 采购现金流出减少，经营活动现金流净额增加
- **汽车冲压模具及检具业务增长6.96%** -> 专用设备行业收入增长7.41%，对冲总营收下滑: 模具业务作为核心业务增长，部分抵消了零部件业务下滑
- **模具业务毛利率提升3.13个百分点** -> 公司整体毛利率提升2.08个百分点，净利润增长40.21%: 高毛利模具业务占比提升且毛利率改善，推动净利大幅增长
- **研发投入下降8.16%且研发人员减少** -> 公司技术优势可能面临削弱风险: 研发投入减少可能影响长期技术竞争力

## 风险警告
公司新能源汽车零部件业务严重依赖下游客户产销量，面临下游需求波动风险；同时研发投入下降和研发人员流失可能削弱长期技术优势，需关注客户集中度过高（前五大客户占营收59.41%）及新能源汽车政策变化风险。
