# 603048.SH 深度透视

## 因果逻辑链
- **[营收创新高但利润骤降]** -> [归母净利润同比-41.61%]: 营收增长12.75%至7.27亿，但资产减值损失激增至3006万元（同比+115.7%），叠加销售费用暴增121.35%至1907万元，导致利润大幅下滑。
- **[新兴事业部量产爬坡]** -> [资产减值损失扩大]: 缸内制动、电控等新事业部产能利用率极低（3%-10%），量产初期成本折旧高于收入，公司对相关存货及闲置设备计提大额减值。
- **[销售网络激进扩张]** -> [销售费用率飙升]: 设立8个办事处、大力开拓市场，销售费用同比+121.35%，远超营收增速，侵蚀利润。
- **[成熟业务稳健造血]** -> [经营性现金流稳定]: 精密成型与喷嘴两大成熟事业部贡献95%营收，近三年年均提供约1亿元经营性现金净流入，支撑公司战略转型。
- **[高分红透支利润]** -> [分红率131.27%]: 2025年拟分红4089.9万元，远超当年归母净利润3115.6万元，动用未分配利润弥补缺口，可持续性存疑。
- **[产品结构升级]** -> [单车价值跃升]: 新产品最高开票单价近3000元，从几十元零件向千元级部件跨越，为未来收入增长打开空间。
- **[海外市场突破]** -> [首次获保时捷定点]: 拓展北美、欧洲渠道，获得豪华品牌认可，但当前境外收入同比下降17.94%，海外贡献尚小。

## 风险警告
**核心风险在于“新旧动能断档”导致的盈利塌陷。** 公司营收创新高，但利润却腰斩，根源在于新业务（缸内制动、电控、空气泵等）尚处巨额投入期，产能利用率极低（最低仅3%），不仅无法贡献利润，反而通过资产减值和费用侵蚀成熟业务利润。若新业务量产爬坡不及预期，减值压力将持续，公司可能陷入“增收不增利”的困境。

**财务稳健性面临双重考验。** 一方面，公司分红率高达131%，远超净利润，实质是在消耗历史积累的未分配利润来维持高分红，这在利润下滑期不可持续。另一方面，公司固定资产中3.06亿元已用于抵押，占总资产19%，若盈利能力持续恶化，再融资能力将受限。此外，销售费用暴增121%但尚未转化为有效订单，需警惕费用失控风险。
