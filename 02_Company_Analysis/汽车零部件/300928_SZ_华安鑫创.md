# 300928.SZ 深度透视

## 因果逻辑链
- **[业务模式战略升级]** -> [营收结构剧变]: 公司从“间接供货”转向“直接供货”，导致核心器件定制业务收入腰斩（-51.25%），而智能座舱终端业务爆发式增长（+129.38%），但后者毛利率为负（-7.86%），拖累整体盈利。
- **[产能前置投入与规模不经济]** -> [固定成本吞噬利润]: 南通智能制造基地厂房设备转固，但产能利用率未达盈亏平衡，导致固定成本分摊效率不足，并产生1230万元闲置成本。
- **[联营企业培育期亏损]** -> [投资收益侵蚀]: 联营企业江苏天华仍处研发投入期，按权益法确认的投资亏损是公司利润总额的9.56%，加剧了整体亏损。
- **[行业竞争加剧与降本压力]** -> [毛利率承压]: 整车厂降本压力向上游传导，叠加公司新业务放量不足，导致综合毛利率阶段性低于行业平均水平。
- **[客户集中度极高]** -> [经营依赖风险]: 前五大客户销售额占比73.57%，且第一大供应商深天马采购额占比高达78.60%，供应链和销售端均高度集中。
- **[研发投入收缩]** -> [长期竞争力隐忧]: 研发费用同比下降28.69%，研发人员数量减少23.08%，在技术快速迭代的智能座舱行业，可能削弱未来技术壁垒。

## 风险警告
公司正处于痛苦的“战略转型阵痛期”。核心风险在于**新旧业务衔接断裂**：传统核心器件定制业务大幅萎缩，而寄予厚望的智能座舱终端业务虽营收暴增，但毛利率为-7.86%，处于“卖得越多亏得越多”的尴尬境地。产能已大规模前置，但订单释放节奏远不及预期，导致巨额固定成本无法消化，这是亏损持续扩大的直接原因。

更深层的风险是**供应链与客户的双重依赖**。公司对单一供应商深天马的采购依赖度接近80%，对前五大客户的销售依赖度超过73%，议价能力极弱。在整车厂持续降价的背景下，公司缺乏将成本压力向上游传导的能力，利润空间被严重挤压。联营企业的持续亏损如同一个“资金黑洞”，短期内看不到盈利拐点。若新业务无法快速实现规模效应并扭亏为盈，公司现金流将持续承压。
