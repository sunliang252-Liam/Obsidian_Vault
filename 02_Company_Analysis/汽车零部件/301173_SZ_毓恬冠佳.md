# 301173.SZ 深度透视

## 因果逻辑链
- **[国产替代龙头地位]** -> [市场份额稳固]: 作为2023年中国汽车天窗市场第二大供应商（市占率16%），且是前五名中唯一本土企业，受益于国产替代趋势，在合资与自主品牌客户中持续渗透。
- **[全景天窗产品结构变化]** -> [营收结构性下滑]: 全景天窗收入同比下降16.98%，导致总营收下滑5.28%，但小天窗（+3.08%）和其他业务（+56.77%）的增长部分对冲了影响。
- **[IPO募集资金到账]** -> [净资产大幅扩张]: 2025年3月上市募资净额5.54亿元，归母净资产从8.17亿跃升至15.29亿，同比增长87.10%，资产负债率从63.86%降至42.44%。
- **[客户集中度高]** -> [业绩依赖核心客户]: 前五大客户销售占比71.20%，其中长安汽车、一汽集团、吉利汽车等头部客户订单波动直接决定公司营收基本盘。
- **[“以销定产”模式]** -> [库存与现金流管理高效]: 2025年经营活动现金流净额达3.35亿元，同比暴增278.08%，主要得益于票据结算方式优化及存货周转改善，净利润现金含量极高。
- **[研发投入聚焦新品类]** -> [第二增长曲线初现]: 电动尾翼产品已量产，其他业务收入同比增长56.77%，显示公司正从天窗向电动尾翼、门模块等汽车运动部件拓展。
- **[新能源天窗占比提升]** -> [顺应行业电动化趋势]: 新能源天窗产品销量134.2万台，贡献营收11.8亿元，占总营收比例超50%，成功绑定广汽埃安、零跑等新能源品牌。

## 风险警告
**核心风险在于客户集中度与行业周期共振。** 公司前五大客户销售占比超70%，且主要客户为长安、一汽、吉利等传统车企。若国内汽车消费市场因宏观经济下行而持续疲软，或主要客户因竞争加剧而减产，公司将面临订单萎缩与价格承压的双重打击。2025年营收已同比下滑5.28%，需警惕这一趋势的延续。

**技术迭代与产品替代风险不可忽视。** 汽车天窗行业正快速向“轻量化、超薄化、智能化”演进，且全景天幕等新形态可能部分替代传统天窗。公司研发投入占营收比仅2.55%，若不能持续保持技术领先，或电动尾翼等新业务拓展不及预期，现有市场份额可能被竞争对手侵蚀，导致增长天花板提前到来。
