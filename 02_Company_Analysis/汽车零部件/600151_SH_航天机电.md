# 600151.SH 深度透视

## 因果逻辑链
- **[光伏行业产能过剩与价格战]** -> [营收与利润双降]: 光伏组件价格跌破成本，公司组件业务收入同比降48.84%，叠加电站限电与电价下跌，光伏板块整体亏损严重。
- **[汽车热系统客户需求萎缩]** -> [核心子公司亏损]: 爱斯达克（SDAAC）受合资品牌客户销量下滑影响，营收降23.53%，利润由盈转亏；埃斯创韩国（ESTRA Auto）因客户车型需求减少，营收降16.71%，持续亏损。
- **[资产减值损失激增]** -> [净利润大幅恶化]: 因电站运营效益下滑及光伏制造端亏损，公司对部分电站及连云港神舟新能源的长期资产计提大额减值准备，资产减值损失达4.42亿元，是2024年的9倍。
- **[处置非核心资产与业务收缩]** -> [营收规模缩减]: 埃斯创卢森堡和航天土耳其公司不再纳入合并报表，叠加光伏与汽配主业收入下降，导致总营收同比下滑32.6%。
- **[汇率波动与债务规模下降]** -> [财务费用转负]: 本期产生汇兑收益，且贷款规模下降导致利息费用减少，财务费用由正转负，同比减少135%，对利润形成正向贡献。
- **[战略聚焦“止血、治亏、瘦身”]** -> [经营现金流改善]: 通过减少应付票据承兑、增加光伏补贴回收及剥离亏损子公司，经营活动现金流净额由负转正，达到5.73亿元。
- **[国内光伏电站补贴回款滞后与限电加剧]** -> [电站运营资金链承压]: 甘肃、新疆、云南等区域电站结算电量与交易电价双降，部分项目公司运营资金紧张，债务风险逐步显现。

## 风险警告
公司当前面临的核心风险是**主业双杀下的持续亏损与资产质量恶化**。光伏产业深陷产能过剩泥潭，价格与成本持续倒挂，公司作为规模较小的参与者议价能力极弱，亏损已成常态；汽车热系统业务则受制于下游整车市场“内卷”及客户结构失衡（单一客户占比高），新订单获取困难，在手订单被切换风险高，两大主业均未看到明确的盈利拐点。更严峻的是，公司已连续三年大额亏损，累计未分配利润高达-21.1亿元，彻底丧失了分红能力，且资产减值损失（尤其是光伏电站）的“黑洞”仍在扩大，严重侵蚀净资产。

此外，**战略收缩的执行与资金回笼存在重大不确定性**。公司计划“适时有序退出境外汽车热系统”，但埃斯创韩国70%股权的转让尚处前期接洽阶段，意向方未明；光伏电站资产优化也因市场环境变化而搁置。这些资产处置若无法顺利推进，不仅无法回收宝贵资金，反而可能因持续“失血”进一步拖累母公司。同时，国内光伏电站补贴核查结果悬而未决，叠加限电与电价下行，电站运营的现金流与偿债能力正面临严峻考验，可能引发连锁债务风险。
