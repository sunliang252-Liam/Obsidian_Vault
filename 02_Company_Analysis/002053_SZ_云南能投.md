# 002053.SZ 深度透视

## 因果逻辑链
- **[来风减少与弃风弃光加剧]** -> [发电量与收入双降]: 2025年云南降水量为1961年以来第二高，导致风电场平均风速下降0.86m/s，叠加省内新能源装机激增带来的弃风弃光率上升，公司新能源装机虽增64.8万千瓦，但发电量反降4.55亿度，电力收入同比减少24.47%。
- **[市场化电价下行]** -> [新能源盈利承压]: 增量项目执行机制电价+市场化交易电价，存量项目国补到期后也转为市场化结算，公司综合平均售电价从0.3827元/千瓦时降至0.3129元/千瓦时，叠加新增转固折旧增加，电力毛利率骤降29.08个百分点。
- **[天然气业务出表]** -> [营收规模收缩]: 公司以天然气公司股权向页岩气公司增资，天然气自2025年4月30日起不再并表，导致营业收入同比减少约6.13亿元，总资产下降14.74%。
- **[下游两碱行业景气度低迷]** -> [盐业利润下滑]: 工业盐下游的烧碱、纯碱行业需求疲软，工业盐销售价格同比下降，导致化工板块收入下降16.64%，毛利率下滑9.39个百分点。
- **[可再生能源补贴回款]** -> [现金流质量优异]: 报告期内收到可再生能源电价附加资金补助6.66亿元，叠加折旧等非付现成本高企，经营活动现金流净额达14.61亿元，现金收益比高达6.42，盈利质量极佳。
- **[装机规模快速扩张]** -> [在建工程与投资支出激增]: 公司推进通泉、永宁等67万千瓦风电扩建项目，在建工程同比增长6.08个百分点，投资活动现金净流出同比扩大69.53%，资本开支压力显著。
- **[压缩空气储能项目开工]** -> [新增长极培育]: 昆明安宁350MW压缩空气储能示范项目于2025年10月开工，是西南首个高海拔盐穴储能项目，有望填补长时物理储能技术空白，成为未来新增长点。

## 风险警告
**核心风险在于新能源业绩的“量价双杀”趋势。** 2025年公司归母净利润同比暴跌64.99%，主因并非一次性因素，而是结构性恶化：来风减少（气候风险）、弃风弃光加剧（消纳瓶颈）、市场化电价下行（政策趋势）三重压力叠加。随着云南省新能源装机持续高速增长，电力市场供过于求的局面短期难以逆转，公司综合电价仍有下行空间，而新增装机带来的折旧刚性增长将进一步侵蚀利润。

**盐业板块面临“内卷”加剧与成本刚性上升的双重挤压。** 省外食盐品牌加大云南市场布局，工业盐受下游两碱行业周期波动影响，价格持续承压。同时，公司为推进绿色转型（如MVR技改）需持续资本投入，若产品结构升级和品牌溢价未能有效对冲成本，盐业板块的利润贡献可能进一步萎缩。此外，天然气业务出表虽聚焦主业，但也意味着失去了一个潜在的利润缓冲垫。
