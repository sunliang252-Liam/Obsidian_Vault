# 000031.SZ 深度透视

## 因果逻辑链
- **[行业下行与结算规模收缩]** -> [营业收入同比下降13.69%]: 房地产市场筑底，公司销售型业务结算规模减少，导致营收从357.9亿降至308.9亿。
- **[高毛利项目集中结算]** -> [综合毛利率大幅提升至31.80%]: 本期结算项目结构优化，高毛利项目占比增加，推动毛利率同比上升10.04个百分点。
- **[计提大额资产减值]** -> [归母净利润持续亏损23.50亿元]: 为应对市场变化调整量价策略，部分项目计提减值准备，侵蚀利润。
- **[商业运营能力突出]** -> [购物中心销售额逆势增长15.5%]: 坚持“年轻力”品牌定位，通过精细化运营和IP活动，实现客流与销售额双增长。
- **[REITs打通资产闭环]** -> [成功发行消费基础设施REITs]: 以成都大悦城为底层资产，实现“投、融、建、管、退”闭环，回流资金用于新项目投资。
- **[销售回款减少]** -> [经营活动现金流净额大幅下降54.32%]: 市场销售承压，导致全年经营性现金净流入从66.2亿降至30.2亿。
- **[债务结构优化]** -> [综合融资成本降至3.54%]: 通过发行私募债、永续中票等低成本融资工具，有效降低利息支出。
- **[大悦城地产私有化]** -> [理顺资本架构，提升治理效能]: 完成对上市子公司大悦城地产的私有化，简化股权结构，提升资产价值和管理效率。

## 风险警告
公司核心风险在于**开发业务持续拖累整体业绩**。尽管商业运营表现亮眼，但占营收75%以上的商品房销售业务收入同比下降18%，且公司连续三年扣非净利润为负，2025年仍亏损24.7亿元。在行业筑底阶段，存货减值风险（存货占总资产38.5%）和销售回款压力将持续压制盈利修复。

**现金流与债务压力不容忽视**。经营活动现金流净额同比腰斩，筹资活动现金流净流出高达93.7亿元，表明公司仍处于“失血”状态。虽然融资成本下降，但总负债规模依然庞大，且大量资产（存货、投资性房地产等）已被用于借款抵押（受限资产达477亿元），财务弹性受限。
