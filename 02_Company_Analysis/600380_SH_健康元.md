# 600380.SH 深度透视

## 因果逻辑链
- **首款1类创新药玛帕西沙韦获批** -> **创新转型里程碑**: 标志着公司打通从研发到商业化的全链条闭环，创新药业务进入收获期，为后续品种商业化奠定基础。
- **集采政策持续冲击化学制剂板块** -> **营收阶段性下滑**: 呼吸领域产品受集采影响销售额下滑，但创新药收入占比超25%，产品结构优化，对冲部分集采压力。
- **保健品板块营收同比增长37%** -> **业绩重要支撑**: 品牌驱动与精细化运营转型成功，在去年高基数上实现快速增长，彰显业务多元化布局的积极效应。
- **原料药及中间体板块稳健运行** -> **经营基本盘支撑**: 通过工艺改进、精益管理降本增效，深化与辉瑞、礼来等全球MNC药企合作，抵消部分产品价格波动影响。
- **收购越南IMP公司** -> **国际化战略关键一步**: 整合其EU-GMP认证产线与本土渠道，打造东南亚本土化运营核心支点，实现从产品出口向实体化运营的转变。
- **AI技术深度嵌入研发与生产** -> **提升效率与降低成本**: 在靶点发现、分子设计、工艺优化等环节应用AI，如COPD先导化合物发现周期缩至6个月，亚胺培南中间体收率提升超5个百分点。
- **研发投入14.29亿元，占营收9.39%** -> **构建可持续创新生态**: 形成“上市一代、临床一代、储备一代”的管线梯队，TSLP单抗、Nav1.8抑制剂等核心品种进入II/III期临床，保障长期增长动力。

## 风险警告
**核心风险在于创新药商业化不及预期与集采政策的持续压力。** 首款创新药玛帕西沙韦刚获批上市，其后续的医保准入、挂网进度、渠道拓展及医生认知等商业化进程存在不确定性，短期内难以弥补化学制剂板块因集采造成的营收缺口。同时，第十一批国家集采规则优化，虽意在“反内卷”，但降价压力依然存在，公司核心产品如艾普拉唑等面临进一步降价风险，可能持续侵蚀利润。

**另一重大风险是研发管线的高投入与高不确定性。** 公司研发投入持续高位，但新药研发周期长、失败率高，TSLP单抗、Nav1.8抑制剂等核心管线虽进度领先，但最终能否成功上市并达到销售预期存在巨大变数。此外，原料药业务受全球大宗商品价格波动、地缘政治及环保政策影响，其价格与供应稳定性是潜在风险点。国际化布局（如越南收购）亦面临海外政策、文化及运营整合的挑战。
