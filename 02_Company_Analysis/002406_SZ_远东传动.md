# 002406.SZ 深度透视

## 因果逻辑链
- **[商用车行业复苏]** -> [营收增长22.90%]: 重卡销量同比增27%，公司作为非等速传动轴龙头，充分享受行业回暖红利。
- **[新能源渗透率提升]** -> [等速驱动轴放量]: 新能源商用车渗透率达26.9%，公司新能源传动轴新品形成新增长点。
- **[核心零部件自研自制]** -> [毛利率提升3.63个百分点]: 万向节实现全面自研，打破外购依赖，优化成本结构。
- **[智能制造升级]** -> [生产效率提升与成本下降]: 智能化改造缩短新品投产周期，降低不良率，增强市场响应速度。
- **[客户资源壁垒]** -> [订单稳定性与高转换成本]: 与福田、陕汽等头部主机厂长期配套，客户粘性高，构筑竞争壁垒。
- **[产业链垂直整合]** -> [抗风险与成本控制能力增强]: 子公司中兴锻造提供毛坯件，制管厂利用废料，降低生产成本。
- **[研发投入增加31.58%]** -> [产品技术竞争力提升]: 聚焦新能源传动轴适配、轻量化技术，巩固行业标准制定者地位。
- **[国内营收增长30.74%]** -> [海外营收下降38.08%]: 战略重心转向内需市场，海外业务受贸易政策及竞争影响收缩。

## 风险警告
**核心风险在于下游周期性与原材料价格波动。** 公司业绩高度依赖商用车与工程机械行业景气度，重卡市场虽短期回暖，但长期受宏观经济波动影响显著，存在周期性下行风险。同时，钢材等原材料成本占营业成本超60%，价格大幅波动将直接侵蚀利润，公司议价能力有限，成本传导存在滞后。

**募投项目产能消化与盈利不及预期是另一重大隐患。** “年产200万套高端驱动轴智能制造生产线”项目进度仅59.75%，已延期至2027年，且至今未产生任何收益。等速驱动轴市场竞争激烈，若市场开拓不力，新增产能将面临闲置风险，叠加固定资产折旧增加，可能拖累未来盈利能力。
