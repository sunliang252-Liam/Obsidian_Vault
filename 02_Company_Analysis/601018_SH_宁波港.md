# 601018.SH 深度透视

## 因果逻辑链
- **集装箱吞吐量增长11.2%** -> **营业收入增长7.41%**: 集装箱装卸及相关业务收入同比增长13.40%，是营收增长的核心驱动力。
- **外钓油品并表** -> **原油业务收入增长44.32%**: 2024年9月纳入合并范围，带来同比增量，并提升该板块毛利率7.8个百分点。
- **财务公司吸收存款大幅增加** -> **经营活动现金流净额暴增97.15%**: 吸收存款净增加额同比增加59.46亿元，是现金流改善的主因。
- **智慧码头建设（“2+1”示范工程）** -> **运营效率提升，成本控制见效**: 全港集装箱船平均在泊效率提升9.6%，超额完成1.8亿元年度降本目标。
- **南北两翼港口（温州、台州、嘉兴）发力** -> **区域一体化效应释放**: 嘉兴港务集装箱吞吐量同比增长15.9%，成为新的增长极。
- **非同一控制下企业合并收益** -> **非经常性损益增厚利润**: 收购宁波远东码头等公司产生5.75亿元收益，占归母净利润的11.1%。
- **利息支出同比减少** -> **财务费用下降48.03%**: 有效降低期间费用，对利润增长形成正向贡献。

## 风险警告
**核心风险在于宏观经济与航运周期的双重压力。** 公司业绩高度依赖全球贸易量，当前地缘政治冲突、贸易保护主义抬头以及全球经济增速放缓，直接威胁港口吞吐量的增长。同时，航运业运力供需不平衡导致的周期性波动，可能引发船公司航线调整，进而影响公司集装箱业务的稳定性。公司2026年经营计划（吞吐量12.5亿吨、营收325亿元）的实现，高度依赖外部宏观环境的稳定。

**区域竞争与政策变动构成长期隐忧。** 公司所处的东北亚港口群存在同质化竞争，周边港口（如上港集团）的产能扩张将加剧揽货难度。此外，国内港口产能过剩的结构性矛盾、日趋收紧的环保政策，以及国家对港口收费的管制，都可能压缩公司的盈利空间。尽管公司通过智慧化、绿色化转型提升竞争力，但短期内难以完全对冲外部竞争和政策风险。
