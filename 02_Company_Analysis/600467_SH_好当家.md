# 600467.SH 深度透视

## 因果逻辑链
- **[鲜海参价格大幅下跌]** -> [营收与利润双降]: 2025年鲜海参平均售价92.08元/公斤，同比下跌26.43%，导致营收下降25.76%，归母净利润下降31.21%。
- **[产量增长难抵价格下跌]** -> [增收不增利]: 鲜海参捕捞量同比增长21.90%至7,448.36吨，但价格跌幅远超产量增幅，量价背离导致盈利恶化。
- **[扣非净利润转负]** -> [主业盈利能力堪忧]: 扣非净利润为-207.37万元，表明公司核心经营业务已陷入亏损，利润依赖非经常性损益。
- **[高比例股权质押]** -> [控股股东资金压力]: 控股股东好当家集团质押3.56亿股，占其持股的64.04%，高质押率隐含控制权风险。
- **[低分红与低ROE]** -> [股东回报薄弱]: 每10股派0.0614元，分红率30.03%但绝对额极低；加权平均ROE仅0.88%，资本回报效率低下。
- **[第四季度经营现金流异常高]** -> [季节性回款或财务调节]: 第四季度营收仅1.15亿元，但经营现金流净额高达3.21亿元，远超其他季度，需关注回款节奏与真实性。
- **[行业竞争加剧与消费疲软]** -> [价格承压长期化]: 海参养殖行业供给增加，叠加消费端对高价有机海参需求放缓，价格下行趋势短期难逆转。

## 风险警告
核心风险在于**海参价格持续低迷**。公司营收与利润高度依赖鲜海参销售，2025年价格同比暴跌26.43%是业绩恶化的直接原因。若未来海参市场供给过剩或消费需求进一步萎缩，公司主营收入与利润将面临持续压缩，扣非净利润已转负，主业造血能力堪忧。

**控股股东高比例股权质押**是另一重大隐患。好当家集团质押比例高达64.04%，若股价持续下跌，可能触发质押平仓风险，进而导致控制权不稳。此外，公司ROE不足1%，资本回报极低，且第四季度经营现金流与营收严重背离，需警惕财务数据质量及潜在的资金占用或调节风险。
