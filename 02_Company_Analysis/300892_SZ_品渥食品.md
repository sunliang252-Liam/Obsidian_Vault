# 300892.SZ 深度透视

## 因果逻辑链
- **[核心品牌德亚乳品收入下滑]** -> [总营收下降9.72%]: 德亚乳品作为营收占比74.49%的核心品牌，收入同比下降12.09%，直接拖累整体业绩。
- **[供应商高度集中]** -> [供应链风险敞口大]: 前五大供应商采购额占比79.67%，其中第一大供应商Hochwald Foods GmbH占比53.07%，单一依赖度高。
- **[国内自有产能落地]** -> [成本结构优化与新品拓展]: 上海奶酪工厂量产、食用油分装车间投产，实现“海外原料+国内分装”，提升毛利率与供应链响应速度。
- **[内容电商（抖音）突破]** -> [线上自营交易额增长13.17%]: 抖音自播与达人矩阵发力，线上自营交易额从18,751万元增至21,221万元，成为增长亮点。
- **[澳新采购额同比增长112%]** -> [产品竞争力与成本优势强化]: 利用中新、中澳零关税政策，增加澳大利亚、新西兰乳制品供应，对冲欧洲单一供应风险。
- **[促销费同比增加38.71%]** -> [销售费用结构变化]: 平台投流费用大幅增加，而广告设计费减少85.55%，营销重心从品牌广告转向效果投放。
- **[经营活动现金流净额下降73.09%]** -> [盈利质量承压]: 净利润仅502万元，但经营现金流从9,754万元骤降至2,625万元，主要因销售回款减少。

## 风险警告
**核心风险在于营收持续萎缩与盈利微薄的双重困境。** 公司营收已连续两年下滑（2024年-22%，2025年-9.72%），净利润仅502万元，扣非后净利润虽转正但绝对值极低（399万元）。核心品牌德亚乳品面临国内奶源过剩与进口替代的双重挤压，市场份额与定价权持续承压。同时，供应商集中度畸高（第一大供应商占采购额53%），地缘政治或供应链中断将直接威胁公司命脉。

**财务健康度存在隐患。** 经营活动现金流净额同比暴跌73%，与微薄利润严重背离，表明销售回款能力或渠道库存压力加大。公司存货账面价值1.87亿元，占总资产14.64%，若消费需求进一步疲软，存货跌价风险将直接侵蚀利润。此外，公司研发投入极低（仅占营收0.09%），长期产品创新与差异化能力存疑，在“价值竞争”加剧的食品行业中，品牌护城河面临挑战。
