# 600528.SH 深度透视

## 因果逻辑链
- **[钢结构制造与安装业务新签合同额下降]** -> [交通运输装备业务收入下降10.34%]: 前期新签订单减少，导致当期可确认收入规模收缩。
- **[道岔业务新签合同额下降21.31%]** -> [道岔业务收入下降2.62%]: 市场需求下降，新签订单不足，直接拖累当期营收。
- **[隧道施工装备业务新签合同额增长6.98%]** -> [专用工程机械装备业务收入微增1.39%]: 订单增长但生产周期长，部分订单未达收入确认时点，收入转化滞后。
- **[海外市场拓展加速]** -> [海外营业收入同比增长96.17%]: 海外新签合同额稳定增长，叠加前期订单集中交付，海外收入大幅提升。
- **[持续加大清收回款力度]** -> [经营活动现金流净额同比增长70.41%]: 强化应收账款管理，资金回笼效率显著改善，经营性现金流大幅改善。
- **[“第二曲线”市场拓展]** -> [隧道掘进机在水利/矿山领域市占率领先]: 在水利水电（市占率超60%）、抽水蓄能（约80%）、矿山（85%）等非传统领域建立绝对优势，对冲传统城轨市场放缓风险。
- **[研发投入聚焦“四化”]** -> [巩固技术领先地位与产品竞争力]: 持续高研发投入（占营收6.26%），在超大直径、可变径盾构机等高端装备上取得突破，维持制造业单项冠军地位。

## 风险警告
**核心风险在于收入与利润的双重下滑。** 2025年公司新签合同额同比下降7.79%，导致营业收入下降4.53%，归母净利润更是大幅下滑22.78%。这主要源于核心业务“交通运输装备”（道岔、钢结构）新签订单的显著萎缩，显示出下游铁路、桥梁建设需求可能进入阶段性放缓周期。若此趋势延续，未来1-2年的收入增长将面临持续压力。

**第二大风险是居高不下的应收账款与合同资产。** 公司应收账款高达174.8亿元，占总资产26.86%；合同资产因业主计价滞后激增149.63%至33.1亿元。尽管经营性现金流因清收努力有所改善，但庞大的应收款项和存货（207亿元）仍构成巨大的坏账风险和资金占用压力，对资产质量和盈利能力的侵蚀不容忽视。
