# 601998.SH 深度透视

## 因果逻辑链
- **[“量价平衡”管理策略]** -> [净息差降幅优于行业]: 在LPR下行和让利实体的压力下，通过主动优化资产负债结构（压降高成本存款、压降低收益票据），使负债成本降幅（-41bps）有效对冲了资产收益率降幅（-52bps），净息差仅降14bps至1.63%，绝对值仍高于行业均值21bps。
- **[“五篇大文章”信贷扩张]** -> [对公贷款高增与结构优化]: 将信贷资源精准投向科技、绿色、普惠等国家战略领域，推动人民币一般对公贷款增量创历史新高，同时制造业、绿色信贷等重点领域增速超10%，实现了规模增长与政策导向的深度绑定。
- **[“五个领先”战略驱动]** -> [非息收入逆势增长]: 财富管理（理财+代销）、投行（债券承销）、交易结算（信用证）等战略业务能力提升，拉动手续费及佣金净收入同比增长5.58%，有效弥补了利息收入下滑，收入结构持续优化。
- **[“控新清旧”风控体系]** -> [资产质量持续改善]: 坚持“五策合一”和主动贷后管理，在个人贷款不良生成有所增加的背景下，通过加大清收、核销和不良资产证券化力度，使不良贷款率连续七年下降至1.15%，逾期贷款率也同比下降。
- **[“中信协同”生态赋能]** -> [综合融资能力跃升]: 依托中信集团“金融+实业”优势，通过“商行+投行+协同+撮合”模式，联合融资规模同比增长15%，为上市公司、地方政府等提供一站式服务，驱动综合融资余额突破15万亿元。
- **[“银河”系统群投产]** -> [对公业务效率与风控重塑]: 历时三年完成史上最大规模系统群建设，实现对公授信全流程数字化重塑，显著提升客户营销、审批及贷后管理效率，为业务扩张和风险防控提供了坚实的科技底座。
- **[负债成本管控]** -> [成本竞争优势累积]: 通过优化存款结构（压降高息结构性存款、提升低成本活期占比）和落实利率自律机制，使存款成本率降至1.52%，已达到国有大行同等水平，为稳定息差和提升盈利能力创造了核心优势。

## 风险警告
**核心风险在于净息差持续收窄对盈利能力的侵蚀。** 尽管2025年通过“量价平衡”策略跑赢大市，但LPR下调、存量按揭重定价及信贷需求不足的冲击仍在持续。若未来资产收益率下行速度持续快于负债成本优化，利息净收入可能进一步承压，进而影响净利润增长的可持续性。当前净息差已降至1.63%，进一步压缩空间有限。

**零售信贷资产质量面临结构性压力。** 受宏观经济和居民收入预期偏弱影响，个人消费贷不良率上升0.66个百分点至2.80%，信用卡不良率也微升至2.62%。虽然整体不良率稳定，但零售端风险暴露的滞后性及规模增长放缓，可能在未来持续消耗拨备，对利润形成拖累。房地产及地方融资平台风险虽整体可控，但局部领域的波动仍需警惕。
