# 601818.SH 深度透视

## 因果逻辑链
- **利率下行周期** -> 净利息收益率下降: 资产收益率下降幅度大于负债成本降幅，导致净息差收窄
- **净利息收益率下降** -> 利息净收入减少: 息差收窄使利息收入降幅大于利息支出降幅
- **净利息收益率下降** -> 营业收入下降: 利息净收入占营业收入72.92%，其下降直接拖累营收
- **资产规模增长** -> 服务实体经济: 通过扩大贷款投放支持重点领域
- **中间业务发展** -> 营业收入结构优化: 手续费及佣金净收入增长，部分对冲利息收入下滑
- **不良贷款率上升** -> 拨备覆盖率下降: 不良贷款余额增加导致拨备消耗
- **风险管控措施** -> 资产质量稳定: 加强不良处置和风险预警，使资产质量总体可控
- **数字化转型** -> 经营效率提升: 科技赋能业务，降低成本收入比

## 风险警告
盈利可持续性风险：净息差持续收窄对核心盈利构成压力，不良贷款率小幅上升及拨备覆盖率下降需关注信用风险。经济下行期贷款需求疲弱，叠加利率市场化，净利息收入可能继续承压；手续费收入增长能否持续存疑。资本充足率虽满足监管，但低于行业平均，补充资本需求迫切。
