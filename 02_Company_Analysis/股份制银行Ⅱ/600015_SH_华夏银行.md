# 600015.SH 深度透视

## 因果逻辑链
- **战略转型与‘五篇大文章’落地** -> 科技金融与绿色金融贷款高速增长: 银行将科技金融和绿色金融定为核心战略，设立专营体系、强化考核激励，推动信贷资源倾斜，导致科技型企业贷款增长53.74%，绿色贷款增长30.99%。
- **客户分层经营与‘客户倍增计划’** -> 对公存款增长及结构优化: 通过分类经营体系和结算服务活客黏客，强化低成本存款营销，导致对公存款增长11.43%，定期存款成本率下降。
- **降本增效与费用精细化管理** -> 业务及管理费下降2.84%: 银行严控成本，坚持费用精细化管理，压缩业务费用和职工薪酬，从而减少管理费支出。
- **资产质量管控与风险问责** -> 不良贷款率下降0.05个百分点: 强化全面风险管理，建立不良资产快速经济处罚机制和经营主责任人机制，优化审批和派驻制管理，使得不良率连续五年下降。
- **LPR下行及市场利率走低** -> 净息差收窄至1.56%: 生息资产收益率下降幅度（3.76%→3.36%）大于计息负债成本率下降幅度（2.15%→1.73%），导致净息差从1.59%降至1.56%。
- **资本市场波动** -> 公允价值变动损益大幅下降: 债券和基金投资的公允价值因市场利率上行而下降，导致公允价值变动损益从78.38亿元降至-35.35亿元。
- **代理业务与财富管理发展** -> 手续费及佣金净收入增长2.44%: 代理业务手续费增长24.14%，得益于财富管理、私人银行和理财销售规模扩大，推动中收增长。

## 风险警告
净息差持续收窄风险：生息资产收益率下行速度快于负债成本下降，净息差下降0.03个百分点，未来若市场利率继续走低，净息差可能进一步承压，影响利息净收入增长。信用风险：拨备覆盖率下降18.59个百分点至143.30%，接近监管红线，不良贷款率虽降但拨备缓冲减弱，需关注经济下行期资产质量恶化可能。盈利结构脆弱性：非利息收入受资本市场波动影响大，公允价值变动收益大幅转负，导致营收负增长，依赖利息收入需警惕利率风险。
