# 688351.SH 深度透视

## 因果逻辑链
- **海外市场高速扩张** -> 境外营收同比增长46.54%: 公司凭借Columbus®三维标测系统及FireMagic®压力导管等核心产品，成功打入英国、墨西哥等高潜市场，带动境外收入占比提升至36.4%。
- **扣非净利润大幅扭亏** -> 扣非净利润同比增长364.36%: 在营收增长12.43%的同时，公司通过国产原材料替代、优化工艺流程等降本增效措施，使主营业务盈利能力显著改善。
- **脉冲电场消融（PFA）产品获批** -> 完成“电、火、冰、磁”全技术路径布局: 压力监测脉冲电场消融导管及参股公司商阳医疗的PFA系统相继获NMPA批准，使公司成为国内少数能提供房颤全场景治疗方案的厂商。
- **带量采购“提质扩面”** -> 新产品获集采中选资格: 2025年PFA导管首次被纳入集采，公司双弯压力导管等4款新产品中选，为后续规模化推广奠定价格与资质基础。
- **研发投入资本化率提升** -> 研发费用同比下降17.21%: 超声成像系统等项目进入资本化阶段，使费用化研发投入减少，但研发总投入仅微降1.18%，公司仍在持续投入前沿技术。
- **经营活动现金流显著改善** -> 经营性现金流净额同比增长35%: 收入规模增长叠加采购付款账期优化，使公司造血能力增强，现金流状况优于净利润表现。
- **冷冻消融系列获CE认证** -> 海外商业化应用落地: IceMagic®冷冻系列全套产品获CE认证，并在德国、巴西、土耳其等国实现首例商业应用，标志着公司全球化产品矩阵进一步完善。

## 风险警告
**核心风险在于外资巨头主导下的激烈市场竞争与集采降价压力。** 强生、雅培、美敦力等外资品牌仍占据国内约80%以上市场份额，且已培育了深厚的临床使用习惯。尽管公司凭借三维标测系统在国产厂商中排名第一，但全面替代外资仍需长期的市场教育与渠道渗透。同时，带量采购已从传统射频消融导管扩展至PFA导管等前沿品类，虽然公司新产品中选，但集采带来的降价压力将持续压缩毛利率空间，2025年导管类产品毛利率已微降0.47个百分点。

**另一重大风险是技术迭代与研发失败的不确定性。** 心脏电生理行业正处于从“热能时代”向“非热能时代”的快速切换期，PFA技术虽前景广阔，但国内外厂商产品不存在显著代差，竞争格局尚未稳定。公司同时在研肾动脉射频消融系统、心腔内超声导管等多个前沿项目，若相关技术出现突破性进展或公司产品研发进度不及预期，现有在研产品可能面临被市场淘汰的风险。此外，公司研发人员数量同比下降10.9%，核心技术人才的流失可能削弱长期创新动力。
