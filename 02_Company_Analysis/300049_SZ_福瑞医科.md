# 300049.SZ 深度透视

## 因果逻辑链
- **[全球肝病无创诊断龙头Echosens业绩高增]** -> [归母净利润+36%]: 子公司Echosens营收11.34亿(+23.48%)，净利润2.5亿(+31.34%)，是公司核心增长引擎。
- **[FibroScan®设备销售与按次收费模式双轮驱动]** -> [器械收入结构优化]: 设备销售6.25亿(55.16%)，按次收费/租赁5.09亿(44.84%)，后者提升客户粘性与收入稳定性。
- **[代谢相关脂肪性肝病(MAFLD)市场爆发]** -> [诊断需求扩容]: MAFLD患病率持续上升，FibroScan®作为WHO/EASL等权威指南推荐的无创诊断金标准，直接受益于筛查与监测需求增长。
- **[软肝片品牌壁垒与渠道深耕]** -> [药品业务稳健]: 作为国家药监局批准的首个抗肝纤维化药物，软肝片营收2.88亿，保持抗肝纤维化第一品牌地位。
- **[管理式医疗战略深化]** -> [“产品+服务”协同]: 整合器械、药品、互联网医院，提供肝病全程管理，提升患者依从性与终端销量，加速从产品向服务转型。
- **[研发投入聚焦AI与适应症拓展]** -> [技术护城河加固]: 研发投入1.72亿(占营收10.76%)，重点开发AI辅助诊断、第四代FibroScan®及心衰等新适应症，巩固全球领先地位。
- **[全球化布局与药企合作]** -> [商业应用边界拓宽]: 与勃林格殷格翰等全球药企合作，推动VCTE™测量作为MASH药物临床试验替代终点，打开新增长空间。

## 风险警告
**核心风险在于子公司Echosens的单一依赖与潜在诉讼。** 公司超70%营收与几乎全部利润增量来自法国子公司Echosens，其经营受汇率波动、海外监管及专利诉讼影响巨大。当前Echosens面临约1200万欧元的商业纠纷诉讼，虽公司认为赔付可能性低，但结果不确定性高，一旦败诉将直接冲击利润。

**第二重风险来自国内业务增长乏力与监管处罚。** 国内药品业务营收增速仅0.58%，医疗服务虽增长58.88%但基数小且毛利率低。公司因境外子公司内控不完善、收入核算不规范，已被内蒙古证监局采取责令改正措施，暴露了跨国治理的薄弱环节，可能影响H股发行进程与市场信心。
