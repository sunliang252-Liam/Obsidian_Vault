# 600104.SH 深度透视

## 因果逻辑链
- **[自主品牌与新能源车销量高增]** -> [营收与利润大幅反弹]: 自主品牌销量占比达65%，新能源车销量增33.1%，推动整体销量增12.3%，带动营收增4.6%，归母净利润暴增506.5%。
- **[上汽通用2024年大额资产减值导致低基数]** -> [2025年利润同比暴增]: 2024年因上汽通用计提大额减值导致归母净利润仅16.7亿，2025年该影响消除，利润恢复至101亿。
- **[“整零同”“产融合”战略与成本控制]** -> [毛利率提升]: 整车与零部件业务毛利率分别提升0.44和1.24个百分点，成本费用得到有效控制。
- **[金融资产公允价值变动与投资收益增加]** -> [非经常性损益贡献利润]: 公允价值变动收益同比增180%，对联营/合营企业投资收益同比增87%，合计贡献超200亿利润。
- **[上汽财务公司汽车金融贷款规模变动]** -> [经营性现金流大幅减少]: 尽管制造业务现金流改善，但财务公司贷款业务规模变动导致经营活动现金流净额同比减少50.5%。
- **[与华为合作推出“尚界”品牌]** -> [快速切入主流市场]: 尚界H5上市后迅速跻身15-20万元级主流产品阵营，为自主品牌注入新增长极。
- **[海外市场销量增长与结构优化]** -> [海外业务毛利率提升]: 海外收入增15.6%，毛利率提升1.61个百分点，MG品牌在欧洲销量超30万辆，成为最畅销中国品牌。
- **[上汽红岩司法重整与亏损企业缩减]** -> [资产质量优化]: 通过“减亏损”、“去风险”措施，持续缩减亏损企业数量，上汽红岩重整方案获批，减轻历史包袱。

## 风险警告
**核心风险在于合资业务的持续萎缩与自主品牌盈利能力的不足。** 上汽大众与上汽通用两大合资支柱销量持续下滑，产能利用率分别仅为55%和37%，传统燃油车资产面临持续减值压力。尽管自主品牌销量占比提升至65%，但核心盈利来源仍高度依赖华域汽车、上汽财务公司等子公司，以及金融资产公允价值变动等非经常性损益。智己汽车、上汽大通等自主品牌仍处于巨额亏损状态，自主造血能力远未形成。

**另一重大风险是海外经营面临的地缘政治与贸易壁垒升级。** 公司海外销量占比已达23.8%，但美欧等主要市场对中国车企加征关税、实施最低价格等限制措施，直接威胁MG品牌在欧洲等核心市场的增长。同时，海外本地化生产布局尚在初期，若贸易摩擦持续恶化，海外业务的高增长与高毛利率将难以维持。此外，国内车市“内卷式”竞争加剧，价格战持续侵蚀行业利润，公司整车业务4.3%的毛利率极其脆弱，任何成本波动都可能引发亏损。
