# 300008.SZ 深度透视

## 因果逻辑链
- **市场/政策驱动（美国关税、301调查、港口费预期）** -> 2025年全球新船订单量下降27%（按CGT计）: 贸易壁垒增加海运需求不确定性，抑制船东投资意愿
- **IMO净零框架投票延期、替代燃料经济性问题** -> 市场观望情绪，全球订单下滑: 绿色技术前景不明，船东推迟新船投资决策
- **中国造船完工量/新接/手持订单全球份额高（56.1%/69%/66.8%）** -> 公司船海工程设计建造总承包业务收入同比增长15.41%: 行业高景气带动公司订单执行与收入确认
- **公司“设计-建造-监理”一体化模式及“四基地一配套两中心”产能布局** -> 船海工程业务收入与毛利率双增（毛利率提升5.08个百分点）: 设计引领降本增效，标准化模块化生产提升效率
- **公司调整防务装备业务结构，从集成项目转向自主研发生产** -> 防务装备业务营收下降19.75%，但毛利率提升8.70个百分点: 主动压缩低毛利集成业务，聚焦高附加值自主研发产品
- **国家政策支持（海洋强国、十五五规划、国防支出增长6.9%）** -> 公司在手订单充足（设计2.18亿、监理0.59亿、建造约149亿）: 政策利好下游需求，公司凭借技术与资质优势承接订单
- **公司研发投入与技术创新（近600项知识产权、专精特新等）** -> 核心竞争力保持行业前三，设计业务收入增长20.05%: 技术领先带来新船型开发和订单获取能力
- **新能源船舶政策规范推进（甲醇/纯电池动力船舶技术规则）** -> 公司能源业务收入增长5.45%，新能源船舶试航加注等业务量提升: 政策出台促进新能源船舶配套基础设施合规化，带动加注等服务需求

## 风险警告
深度风险总结：1）全球贸易摩擦与地缘政治风险持续影响海运需求，美国301调查及港口费政策可能抑制船东下单意愿；2）替代燃料路径不确定性（IMO框架延期、经济性不足）导致市场观望，订单增长承压；3）造船业务面临钢材、汇率、劳动力短缺及人工成本上涨等压力，毛利率提升可持续性存疑；4）防务装备业务调整期营收下滑，新业务放量节奏不确定；5）新能源船舶基础设施尚不完善，成本与安全挑战可能制约业务规模。
