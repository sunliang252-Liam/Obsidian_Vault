# 601788.SH 深度透视

## 因果逻辑链
- **市场交投活跃度提升** -> **经纪业务收入增长33%**: 2025年A股日均成交额1.73万亿元，客户总数增至716.5万户，带动代理买卖证券净收入市场份额提升。
- **融资融券余额扩张** -> **利息净收入增长11%**: 两融余额543.86亿元，同比+31.71%，驱动融资融券利息收入增加。
- **债券承销规模扩大** -> **投行业务收入稳定**: 债券承销金额4,154.79亿元，资产支持证券排名第8，弥补了股权融资承销下滑的影响。
- **资管业务结构优化** -> **资管及基金管理收入增长14%**: 光证资管回归私募业务，光大保德信新发基金募集39.35亿元，推动管理费收入增长。
- **权益自营策略调整** -> **投资交易收入增长18%**: 权益自营坚持绝对收益导向，多元资产配置，实现业绩同比改善。
- **客户资金大幅流入** -> **代理买卖证券款增长47%**: 市场回暖带动客户保证金增加，为公司提供低成本资金来源。
- **信用减值损失增加** -> **利润侵蚀风险**: 信用减值损失1.63亿元，同比由负转正，主要系其他应收款减值，需关注资产质量。

## 风险警告
**核心风险在于历史包袱与合规诉讼。** MPS事件余波未平，光大资本净资产为-11.24亿元，持续拖累并表利润。金通灵证券虚假陈述案涉及4.3万名投资者，索赔金额7.75亿元，公司作为中介机构面临连带赔偿责任，最终涉诉金额存在重大不确定性，可能对利润造成一次性冲击。

**业务结构依赖市场贝塔，盈利波动性大。** 财富管理（55%）和投资交易（12%）收入与市场行情高度相关，2025年业绩增长主要受益于A股和港股市场活跃。若市场情绪逆转，经纪、两融及自营收入将同步承压。同时，信用减值损失由负转正，显示资产质量压力边际上升。
