# 300115.SZ 深度透视

## 因果逻辑链
- **[AI硬件迭代加速]** -> [消费电子业务稳健]: 公司紧抓AI PC、可穿戴设备结构件轻量化、高强度需求，成功量产重点项目，抵消了传统消费电子增长放缓的影响。
- **[新能源产能释放]** -> [新能源业务高增31.61%]: 宁德、溧阳、宜宾等五大基地产能爬坡，规模效应显现，推动新能源零部件营收达68.62亿元。
- **[人形机器人量产突破]** -> [开辟第二增长曲线]: 2025年交付约69万件精密零组件，实现营收1亿元，从技术储备进入小批量量产阶段，海外客户占比80%。
- **[收购威线科]** -> [补齐AI算力硬件版图]: 收购高速铜连接模组公司51%股权，快速切入AI服务器内部高速连接器及线缆组件市场，已向头部客户送样。
- **[全球化基地建设]** -> [增强供应链韧性]: 匈牙利启动建设、墨西哥量产、越南爬坡，形成覆盖中、越、墨、欧的产能网络，应对地缘政治与关税风险。
- **[扣非净利润增长7.3%]** -> [盈利能力持续改善]: 在营收增长11.13%的背景下，通过全流程降本增效，核心业务利润实现正增长，经营质量优化。
- **[客户集中度高]** -> [业绩依赖核心大客户]: 前五大客户销售额占比64.6%，其中第一大客户占比23.75%，公司业绩与核心客户的终端产品销量高度绑定。

## 风险警告
**核心风险在于经营现金流与利润严重背离，且财务杠杆急剧攀升。** 2025年公司扣非净利润增长7.3%，但经营活动现金流净额却骤降75.13%至5.6亿元，主要因购买商品、支付工资等现金支出大幅增加。与此同时，公司为支撑产能扩张和营运资金，短期借款激增87%至59亿元，长期借款也增加45%至17亿元，导致资产负债率显著上升。这种“增收不增现、扩张靠举债”的模式，在利率上行或下游回款放缓时，将带来巨大的流动性压力。

**另一重大风险是新能源业务“增收不增利”的困境。** 尽管新能源业务营收增长31.61%，但毛利率却同比下降1.39个百分点至14.32%，远低于消费电子业务的21.53%。核心子公司临港长盈（新能源业务主体）亏损1.55亿元，表明该板块仍处于产能爬坡与价格竞争的“烧钱”阶段。若新能源行业竞争进一步加剧或下游客户压价，该业务可能持续侵蚀公司整体利润，成为业绩的拖累项。
