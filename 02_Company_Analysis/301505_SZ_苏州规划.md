# 301505.SZ 深度透视

## 因果逻辑链
- **[传统规划设计业务萎缩]** -> [营收与利润双降]: 行业竞争加剧、客户业务量下降，导致公司2025年营收同比-12.04%，扣非净利润同比-31.23%。
- **[智慧城市业务高增长]** -> [结构优化]: 智慧城市业务营收同比+53.86%，成为唯一正增长板块，但体量尚小（占营收3.69%），未能对冲传统业务下滑。
- **[经营现金流大幅改善]** -> [回款能力增强]: 经营活动现金流净额同比+122.76%，主因项目回款增加及薪酬支付减少，显示公司加强了应收账款管理。
- **[信用减值损失扩大]** -> [利润侵蚀]: 信用减值损失高达2106万元，占利润总额的88.45%，主要来自应收账款坏账准备，是利润下滑的核心拖累项。
- **[省外业务大幅收缩]** -> [区域依赖风险]: 江苏省外营收同比-56.88%，占比降至4.81%，表明跨区域扩张战略受阻，业绩高度依赖苏州本地市场。
- **[投资性房地产激增]** -> [资产结构转变]: 在建工程完工转入，投资性房地产占总资产比例从0.16%飙升至18.35%，公司资产从轻资产向重资产模式倾斜。
- **[股权激励与股份回购]** -> [股东回报与治理]: 实施限制性股票激励计划并回购股份，旨在绑定核心人才、提振市场信心，但短期内增加了财务费用和资本公积消耗。

## 风险警告
**核心风险在于传统业务的持续萎缩与新兴业务的青黄不接。** 规划设计业务作为公司营收主力（占比53.59%），营收同比下滑26.02%，且行业竞争加剧、政府预算紧缩的趋势未见逆转。尽管智慧城市业务增长迅猛，但体量极小，短期内无法弥补传统业务的下滑缺口。同时，高达2106万元的信用减值损失（占利润总额88.45%）揭示了公司客户（主要为地方政府及平台公司）回款困难，坏账风险高企，严重侵蚀利润。

**区域集中度过高与跨区域扩张失败是另一大隐患。** 公司95%以上的营收来自江苏省内，省外业务同比腰斩，表明其“深圳-苏州”双中心战略执行不力。一旦苏州本地市场出现政策或经济波动，公司将缺乏缓冲地带。此外，公司资产结构正从轻资产向重资产转变（投资性房地产占比激增至18.35%），可能降低资产周转效率，并增加对房地产市场的间接敞口。
