- **[东方财富证券经纪业务股基交易额达38.46万亿元]** -> [证券服务收入占比提升至78.02%]: 零售经纪业务是公司最核心的收入来源，其增长直接拉动整体营收。
- **[天天基金权益类基金保有规模达4,456.17亿元]** -> [金融电子商务服务收入同比增长11.99%]: 尽管基金销售费率下行，但保有规模的增长支撑了基金销售收入的正增长。
- **[妙想大模型全面融入产品生态]** -> [研发费用同比下降6.66%]: 公司研发投入资本化率为0，费用下降或反映前期AI基础设施投入进入稳定应用期，而非技术投入缩减。
- **[公司发行债券收到的现金同比增加]** -> [筹资活动现金流净额同比增长91.50%]: 公司通过发行债券（应付短期融资券和应付债券大幅增加）积极补充资本，以支持两融和自营业务扩张。
- **[为交易目的而持有的金融资产净增加额同比增加]** -> [经营活动现金流净额为-102.22亿元]: 公司自营投资规模扩大，导致经营活动现金大量流出，与净利润产生巨大背离。
- **[融出资金规模同比增长37.36%]** -> [利息净收入同比增长44.26%]: 两融业务规模随市场行情扩张，成为公司除经纪业务外的第二大利润增长引擎。

## 风险警告
公司业绩与资本市场景气度高度正相关，2025年A股成交额创历史新高是业绩爆发的核心驱动力。一旦市场进入下行周期或成交量萎缩，证券经纪、两融及基金销售收入将面临同步下滑的风险，业绩波动性极大。

公司经营活动现金流净额为-102.22亿元，与120.85亿元的净利润严重背离。这主要源于自营投资和两融业务的资金占用，本质上是将利润转化为金融资产。若市场出现极端下跌，公司持有的交易性金融资产（1095亿元）和融出资金（808亿元）将面临巨大的减值风险，可能侵蚀利润并引发流动性压力。
