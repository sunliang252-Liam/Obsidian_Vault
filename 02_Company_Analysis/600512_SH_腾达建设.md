# 600512.SH 深度透视

## 因果逻辑链
- **[施工收入大幅增长]** -> [营收增长30.33%]: 工程施工业务收入同比增长34.84%，驱动总营收从37.18亿增至48.45亿。
- **[云南子公司巨额减值]** -> [营业利润暴跌55.83%]: 云南腾达运通置业计提投资性房地产和开发产品减值准备1.995亿元，直接吞噬施工主业利润。
- **[施工收入增长与减值对冲]** -> [归母净利润仅微增18.21%]: 施工利润增长被地产减值大幅抵消，最终归母净利润仅从2600万增至3074万。
- **[经营现金流由负转正]** -> [现金流改善]: 业务回款增加，经营活动现金流净额从-9115万大幅转正至1.61亿元。
- **[新签合同额大幅下滑]** -> [未来收入增长承压]: 报告期内新签合同仅10个、金额15.36亿元，远低于在手订单237.36亿元规模，预示后续增长乏力。
- **[研发投入持续加大]** -> [技术壁垒构建]: 研发费用增长27.3%至1.89亿元，聚焦超大直径盾构、智能建造等，巩固民营建筑企业技术领先地位。
- **[钱江四桥经营权摊销]** -> [稳定现金流来源]: 桥梁经营业务毛利率43.64%，提供稳定利润，但经营权将于2025年11月到期，持续性存疑。

## 风险警告
**核心风险在于地产减值“黑洞”与主业增长“天花板”的双重挤压。** 云南子公司近2亿元的资产减值，直接暴露了公司早年地产投资决策的失误，且该子公司净资产已为-9.38亿元，资不抵债，后续可能持续拖累合并报表。同时，公司新签合同额断崖式下滑至15.36亿元，仅为在手订单的6.5%，表明市场开拓遭遇瓶颈，未来收入增长缺乏新项目支撑。

**财务健康度存在隐忧。** 尽管经营现金流改善，但应收账款激增93.51%至7.1亿元，远超营收增速，回款压力巨大。此外，公司利润极度微薄（净利率仅0.06%），对减值、信用损失等非经营性项目高度敏感。实际控制人持股比例仅8.28%，股权结构分散，存在治理层面的潜在不稳定性。
