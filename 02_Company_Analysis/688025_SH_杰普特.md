# 688025.SH 深度透视

## 因果逻辑链
- **[光通信业务爆发]** -> [光纤器件收入增长560%]: 公司抓住AI算力需求驱动的数据中心光连接市场机遇，MPO/FAU产品快速放量。
- **[消费级激光器市场突破]** -> [激光器收入增长44%]: 公司MOPA脉冲光纤激光器成功切入消费级激光雕刻机市场，替代传统CO2激光器，打开新增长极。
- **[动力电池客户扩产]** -> [激光器国产替代深化]: 公司持续配合宁德时代、比亚迪等头部客户新工艺需求，激光器在电池极片切割、清洗、焊接等环节实现规模化替代。
- **[规模化效应显现]** -> [净利润增速（+110%）远超营收增速（+43%）]: 激光器、光纤器件等产品线产量提升，固定成本摊薄，叠加严格的预算管控，盈利能力显著增强。
- **[经营现金流大幅改善]** -> [现金流净额增长669%]: 营收增长带来销售回款增加，同时公司加强应收账款管理，现金循环效率提升。
- **[大客户深度绑定模式]** -> [智能装备收入增长16%]: 公司通过参与A公司、M公司等头部客户早期研发，提供定制化检测/加工设备，形成技术锁定和持续订单。
- **[新产品储备丰富]** -> [未来增长点明确]: FPCB激光钻孔机、MLCC高速测试分选机、硅光晶圆测试系统等新品在头部客户验证或获得订单，有望接力成为新增长引擎。

## 风险警告
**核心风险在于大客户依赖与收入结构波动。** 公司智能装备业务高度绑定A公司等消费电子巨头，单一品类订单受客户产品周期影响极大，历史上收入波动剧烈。光通信业务虽爆发式增长，但同样依赖少数头部云服务商资本开支节奏，若AI算力投资放缓，该业务增速可能骤降。

**另一重大风险是技术迭代与市场竞争。** 激光器行业竞争激烈，公司面临IPG、锐科等国内外对手的价格战压力，激光器毛利率存在持续下滑风险。同时，公司在光通信、半导体检测等新领域的拓展，需面对已有强势玩家的竞争，新业务市场拓展存在不确定性。此外，部分核心原材料（特种光纤、芯片）依赖境外采购，国际贸易摩擦可能推高成本或影响供应链安全。
