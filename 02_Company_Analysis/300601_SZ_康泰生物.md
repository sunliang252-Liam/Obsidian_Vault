# 300601.SZ 深度透视

## 因果逻辑链
- **[四联苗受免疫程序调整冲击]** -> [核心产品销量暴跌]: 2025年国家调整百白破免疫程序，导致公司四联苗批签发量同比骤降85.06%，直接拖累整体营收增长停滞（仅+0.81%）。
- **[营业成本大幅上升]** -> [毛利率显著下滑]: 营业成本同比增长41.72%，远超营收增速，导致生物制品毛利率从82.92%降至75.93%，侵蚀利润空间。
- **[研发投入持续高增]** -> [短期利润承压]: 研发投入同比增长11.25%至6.33亿元，资本化率仅14.19%，大部分费用化处理，直接压缩当期净利润。
- **[海外业务爆发式增长]** -> [第二增长曲线初现]: 海外疫苗产品收入同比增长859.40%至9883.53万元，国际化战略进入收获期，有效对冲国内业务下滑。
- **[新产品准入加速]** -> [未来增长注入新动能]: 人二倍体狂犬疫苗、水痘疫苗、Sabin株脊灰灭活疫苗等新产品快速完成多省准入，为后续放量奠定基础。
- **[资产减值损失大幅计提]** -> [净利润雪上加霜]: 计提存货资产减值1.34亿元，占利润总额的-294.37%，反映部分产品市场需求或价格不及预期。
- **[税收政策重大调整]** -> [2026年利润将受显著冲击]: 自2026年起增值税由3%简易征收转为13%一般计税，因进项抵扣少，将直接导致税负大幅上升，压缩利润空间。

## 风险警告
**核心风险：业绩双杀与政策冲击。** 公司2025年净利润同比暴跌65.12%，核心原因在于“量价齐跌”：四联苗受国家免疫程序调整冲击，批签发量近乎腰斩，而营业成本因产能利用率下降、固定成本分摊增加而大幅上升，导致毛利率显著下滑。更严峻的是，2026年增值税政策调整（3%→13%）将直接侵蚀利润，叠加新生儿数量持续下降对婴幼儿疫苗市场的长期压制，公司短期业绩反转难度极大。

**关键风险：研发管线的不确定性。** 公司研发投入巨大，但核心在研品种如五联苗、20价肺炎疫苗等均处于临床阶段，距离商业化仍有较长周期。同时，公司已计提大额存货减值，若未来市场需求或竞争格局进一步恶化，可能面临更多资产减值风险。海外业务虽增速亮眼，但基数极低，且面临地缘政治、汇率波动及当地监管变化等不确定性，能否持续高增长并成为真正的业绩支柱尚待观察。
