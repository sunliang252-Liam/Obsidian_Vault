# 601969.SH 深度透视

## 因果逻辑链
- **油气产量同比增长60.5%** -> 油气业务收入同比增长32.92%: 产量大幅提升直接拉动收入增长
- **阿曼油田并表及八角场气田增产** -> 油气产量同比增长60.5%: 并购和增产是产量增长的主要驱动
- **油气产量增长** -> 油气营业成本同比增长54.97%: 产量增加带动生产成本和摊销费上升
- **油气营业成本增幅超过收入增幅** -> 油气业务毛利率同比下降11.43个百分点: 成本增速高于收入导致毛利率下降
- **铁矿石价格下跌** -> 铁矿石业务收入同比下降10.52%: 价格下跌拖累收入
- **铁矿石价格下跌** -> 铁矿石业务毛利率同比下降5.33个百分点: 收入降幅大于成本降幅导致毛利率下降
- **锂资源业务投产并销售** -> 归母净利润下降幅度小于收入增长对利润的贡献: 新业务贡献收入但初期利润有限
- **并购贷款增加** -> 财务费用同比增长68.67%: 贷款规模上升导致利息支出增加
- **油气业务毛利率下降** -> 归母净利润同比下降38.99%: 毛利率下降是净利润下滑的主因
- **锂资源业务投产** -> 综合毛利率同比下降8.95个百分点: 低毛利新业务拉低整体毛利率

## 风险警告
公司2025年归母净利润同比大幅下降38.99%，核心原因是油气和铁矿石两大主力产品价格下跌或成本攀升导致毛利率显著下滑。油气业务虽产量大增，但并购带来的高摊销及政府分成比例提高使毛利率下降11.43个百分点；铁矿石业务受价格拖累毛利率下降5.33个百分点。同时，新投产的锂资源业务尚处爬坡期，盈利能力不足。财务费用因并购贷款增加而大幅上升，进一步侵蚀利润。公司业绩对大宗商品价格和并购整合效果高度敏感，若未来油气价格持续低迷或锂资源市场开拓不及预期，利润可能继续承压。
