# 601011.SH 深度透视

## 因果逻辑链
- **[焦炉停产检修]** -> [焦炭及化工品产销量归零]: 公司158万吨/年焦炭产能全年停产，导致焦炭收入同比减少8.22亿元，粗苯、焦油、甲醇收入合计减少1.92亿元，主营业务收入腰斩。
- **[业务结构切换至自产煤炭]** -> [毛利率大幅改善]: 公司从依赖外购原料的焦炭生产，转向销售自有煤矿开采的原煤、精煤，原煤毛利率高达36.62%，推动整体销售毛利从-1.37亿元扭转为+0.43亿元。
- **[出售子公司股权]** -> [非经常性收益掩盖经营亏损]: 出售鸡西宝泰隆投资55%股权确认投资收益1.32亿元，使归母净利润亏损从扣非后的-4.02亿元收窄至-3.21亿元。
- **[自有煤矿逐步投产]** -> [原料自给率提升，成本可控]: 宝泰隆一矿等三座矿井转为正式生产，合计新增产能150万吨/年，为未来降低原材料成本、稳定利润提供基础。
- **[财务费用激增]** -> [侵蚀利润]: 因控股孙公司诉讼计提资金占用利息，财务费用同比大增59.12%至2.10亿元，成为亏损扩大的重要推手。
- **[长期资产减值与递延所得税转回]** -> [四季度亏损加剧]: 第四季度计提长期资产减值0.72亿元，叠加部分子公司递延所得税资产转回0.7亿元，导致单季归母净亏损达3.71亿元。
- **[循环经济产业链优势]** -> [综合成本降低]: 公司通过煤-焦-化-电-热-新材料一体化模式，利用副产品发电、供热，有效降低了传统煤化工业务的综合生产成本。

## 风险警告
公司当前最大的风险是**核心业务停摆与巨额债务的双重挤压**。焦炉停产导致焦炭及化工品收入归零，公司完全依赖煤炭开采业务维持现金流，但煤炭业务体量（原煤112万吨）远不足以弥补焦化板块的利润缺口。与此同时，公司短期借款激增51%至15.39亿元，一年内到期的非流动负债仍有2.22亿元，财务费用高企，偿债压力巨大。

其次，**转型前景高度不确定**。公司押注的石墨烯、合成氨、醋酸等新材料项目尚处于研发或建设初期，短期内无法贡献利润。而密林石墨矿虽已取得采矿证，但大规模开采和下游应用落地仍需时间和巨额资本投入。在主营业务持续亏损、现金流紧张的背景下，这些转型项目可能面临资金断流风险，公司“转型升级”战略的兑现存在重大不确定性。
