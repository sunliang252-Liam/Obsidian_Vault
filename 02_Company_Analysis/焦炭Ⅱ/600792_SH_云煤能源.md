# 600792.SH 深度透视

## 因果逻辑链
- **[焦化行业产能过剩与下游钢铁需求走弱]** -> [公司连续两年巨亏]: 焦炭产能过剩导致议价能力弱，钢铁行业“减量发展”压缩焦炭需求，公司2025年归母净利润-4.86亿元，连续第二年亏损。
- **[师宗焦化基地煤焦价格倒挂]** -> [核心子公司亏损]: 师宗焦化受区域内供需两端市场挤压，原料煤成本高于焦炭售价，全年无边际贡献，净利润-2.16亿元。
- **[重装集团业务量萎缩、产能利用率低]** -> [重型机械板块严重拖累]: 钢铁行业深度调整导致检修、技改项目缩减，重装集团订单不足，毛利率骤降20个百分点至-44%，净利润-2.01亿元。
- **[安宁分公司闲置资产溢价处置]** -> [非经常性收益缓解亏损]: 通过公开挂牌转让老区资产，溢价超5000万元，贡献资产处置收益4849万元，成为减亏关键。
- **[融资规模与成本双降]** -> [财务费用大幅减少]: 公司主动压减金融负债4.32亿元，叠加利率下行，财务费用同比减少44.86%，从1.29亿降至0.71亿。
- **[对武昆股份的销售依赖度极高]** -> [客户集中风险显著]: 前五大客户销售额占比91.89%，其中对关联方武昆股份的销售占比高达74.22%，公司经营高度依赖单一客户。
- **[母公司未分配利润巨额亏损]** -> [分红能力丧失]: 截至2025年末，母公司未分配利润为-10.39亿元，连续两年不满足分红条件，无法进行现金分红。

## 风险警告
公司面临的核心风险是**行业性亏损与客户高度集中的双重夹击**。焦化行业产能过剩、下游钢铁需求长期走弱的基本面未变，公司两大核心业务——师宗焦化（煤焦价格倒挂）和重装集团（订单萎缩）——均处于深度亏损状态，仅靠安宁基地的满产和资产处置难以扭转颓势。更关键的是，公司74%的营收依赖关联方武昆股份，一旦其经营或采购策略变化，公司收入将遭受毁灭性打击。

财务风险同样严峻。公司已连续两年巨额亏损，母公司未分配利润赤字高达10.39亿元，彻底丧失分红能力。同时，公司总资产中受限资产高达18.88亿元（主要为融资租赁和抵押资产），且重装集团净资产已为负值，表明公司资产质量和流动性承压，融资空间受限。在行业寒冬中，公司“活下去”的保卫战仍面临巨大挑战。

> 云南煤业能源股份有限公司(以下简称“云煤能源”或“公司”)目前为云南省大型焦化企业之一,公司于2011年11月完成借壳上市,成功登陆资本市场,公司股票代码为600792。其前身是始建于1969年的昆钢焦化厂,公司从事冶金焦炭及焦化产品的生产50余年,为云南省钢铁生产和煤焦化工生产的配套完善和发展奠定了坚实的基础。公司主营煤焦化和重型装备制造板块。煤焦化板块现拥有7.6米大型焦炉2座、5.5米捣固焦炉2座,2套与焦炉配套的煤气净化装置,3套140吨/小时干熄焦装置,10万吨/年的甲醇装置,150万吨/年洗煤厂,拥有年产焦炭300万吨、甲醇10万吨生产能力。重型装备制造板块坚持“制造+服务”产业模式。产品结构涵盖机械、电气、液压、工程无损检测等领域。主要产品包括钢铁冶炼设备、轧制设备、起重运输机械设备(包含设计、制造、改造、检修维保)、钛及钛合金等难熔有色金属冶炼(包含制粉)设备、轧辊制造及功能承包、耐磨材料制造及功能承包、矿山、水电、风电、水泥设备等共计百余个品种,千余种规格。
