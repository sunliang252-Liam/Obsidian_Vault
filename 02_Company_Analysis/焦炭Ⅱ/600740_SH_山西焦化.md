# 600740.SH 深度透视

## 因果逻辑链
- **[焦炭价格持续走弱]** -> [营收下降17.70%]: 焦化行业“供强需弱”，焦炭价格下跌直接拖累公司主营业务收入。
- **[中煤华晋投资收益大幅下滑]** -> [归母净利润骤降68.40%]: 公司利润高度依赖参股公司中煤华晋，其因煤价下跌导致盈利减少，公司确认的投资收益从23.15亿降至13.98亿。
- **[原材料成本同步下降]** -> [毛利率改善6.17个百分点]: 洗精煤采购价同比下降28.80%，成本降幅（-22.08%）大于收入降幅（-17.72%），焦化业务毛利率由负转正改善。
- **[主业经营亏损，依赖投资收益]** -> [扣非净利润仅4376万]: 剔除中煤华晋分红等非经常性损益后，公司主业实际盈利能力极弱，扣非净利润同比暴跌81.67%。
- **[现金流持续为负]** -> [经营压力巨大]: 经营活动现金流净额连续三年为负（-17.92亿），表明公司主业造血能力严重不足，依赖融资和投资分红维持运营。
- **[关联采购高度集中]** -> [成本控制受制于人]: 前五大供应商采购额占总额73.83%，其中关联方山西焦化集团占比高达63.62%，公司议价能力受限。
- **[环保政策趋严]** -> [资本支出与运营成本增加]: 新国标《炼焦化学工业大气污染物排放标准》实施，公司需持续投入超低排放改造，增加未来成本。

## 风险警告
公司本质是一个“利润空心化”的焦化企业。主业焦炭在行业产能过剩、下游钢铁需求疲软的双重挤压下持续亏损，2025年扣非净利润仅4376万元，经营现金流连续三年为负，造血能力几近枯竭。公司全部利润几乎都来自对中煤华晋49%股权的投资收益，一旦煤价进入下行周期或中煤华晋盈利波动，公司业绩将面临断崖式下跌。2025年投资收益已同比下滑近40%，这是最核心的业绩风险。

此外，公司对控股股东山西焦化集团的原材料采购依赖度极高（超63%），关联交易定价的独立性存疑，且同业竞争问题（山西焦煤集团旗下其他焦化资产）的整合承诺迟迟未能兑现。同时，焦化行业环保与能耗标准持续收紧，未来资本开支压力巨大，将进一步侵蚀本已脆弱的现金流。公司当前的高分红（77%）更像是“吃老本”，可持续性存疑。
