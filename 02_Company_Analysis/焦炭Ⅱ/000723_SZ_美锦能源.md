# 000723.SZ 深度透视

## 因果逻辑链
- **[焦炭产能扩张与价格下行]** -> [营收与利润承压]: 焦炭产量同比增19.97%，但下游钢铁需求疲软、煤焦价格下跌，导致营收同比降5.58%，净利润连续第二年亏损。
- **[“煤-焦-气-化-氢”一体化]** -> [低成本氢源护城河]: 依托千万吨焦炭产能，从焦炉煤气中提取低成本副产氢，为氢能业务提供难以复制的成本优势。
- **[氢能全产业链闭环]** -> [内部协同降本]: “制-储-运-加-用”闭环模式降低了各环节运营与交易成本，但氢能业务仍处商业化初期，毛利率为-31.44%。
- **[燃料电池汽车示范城市群政策到期]** -> [氢能业务收入锐减]: 2025年示范期结束，政策衔接空窗导致新能源车辆及运营收入同比大降48.42%。
- **[原材料价格下跌]** -> [经营性现金流改善]: 主要原材料市场价格下跌，支付材料款减少，使经营活动现金流净额同比大增63.63%。
- **[氢能核心技术国产化突破]** -> [降低“卡脖子”风险]: 与院士团队合作解决膜电极、碳纸等关键技术难题，提升供应链自主可控能力。
- **[贵州煤焦氢项目投产]** -> [区域布局与产能释放]: 贵州华宇项目一期稳定投产、二期烘炉，完善“煤—焦—氢”一体化布局，但初期拖累整体盈利。

## 风险警告
**核心风险在于传统煤焦主业持续亏损与氢能新业务商业化不及预期的双重挤压。** 2025年公司连续第二年录得归母净亏损11.23亿元，焦化业务毛利率仅6.32%，氢能业务毛利率更是深陷-31.44%的泥潭。公司总资产缩水6.34%，净资产下滑9.42%，财务杠杆高企，短期借款同比大增45%，偿债压力不容忽视。

**氢能业务面临政策退坡与市场培育的双重不确定性。** 燃料电池汽车示范城市群政策于2025年正式期满，导致氢能收入腰斩。尽管公司布局了全产业链，但氢车推广仍高度依赖补贴，商业化运营尚未跑通。核心零部件供应链虽在突破，但仍存在对少数供应商的依赖，且技术路线快速迭代，前期重资产投入存在减值风险。
