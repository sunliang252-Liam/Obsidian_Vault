# 688156.SH 深度透视

## 因果逻辑链
- **[白酒糟生物发酵饲料产能快速扩张]** -> [营收增长36.95%]: 金沙、遵义、亳州、永乐等新厂投产，销量18.41万吨（+63.47%），推动生物饲料收入2.83亿元（+30.50%）。
- **[下游养殖景气度偏弱，饲料议价能力下降]** -> [生物饲料毛利率下降7.59个百分点]: 终端需求走淡，产品售价走低，而新厂产能爬坡期固定成本未摊薄，综合导致毛利率降至14.44%。
- **[新厂集中投产，固定资产折旧与利息费用化激增]** -> [财务费用增长124.05%]: 遵义、亳州、永乐等项目投产后，借款利息费用化列支，叠加附回购条款的权益融资计提利息，财务费用达2179.65万元。
- **[无机固废客户支付能力下降，回款放缓]** -> [信用减值损失大幅增加]: 应收账款账龄拉长，全年计提坏账准备2853.61万元，成为净利润亏损的核心拖累之一。
- **[工程泥浆处理业务量大幅增长]** -> [子公司绍兴路德净利润812.86万元]: 收纳泥浆量126.12万立方米（+53.96%），贡献显著利润，但公司持股51%，少数股东损益摊薄归母净利润。
- **[酒糟原料库容合计达80万吨]** -> [原料供应壁垒与成本优势]: 在酱酒核心产区多点布局，与大型酒企签订长期协议，保障了原料稳定供应与成本可控。
- **[合成生物学技术储备取得阶段性成果]** -> [未来高附加值产品拓展]: γ-氨基丁酸（GABA）项目完成中试验证，为向功能性食品、化妆品原料等新领域延伸奠定基础。

## 风险警告
**核心风险在于“增收不增利”的困境短期难以扭转。** 公司营收高速增长（+36.95%），但归母净利润亏损扩大至-7010万元。主因是新产能集中投产带来的折旧、利息费用化等刚性成本激增，叠加下游养殖业低迷导致产品售价承压，毛利率大幅下滑。这种“量增价跌、成本刚性”的结构性矛盾，在产能利用率未达满产前将持续侵蚀利润。

**第二大风险是应收账款与资产减值。** 无机固废处理业务客户支付能力下降，导致应收账款账龄拉长，全年计提坏账准备2853.61万元，成为亏损的重要推手。虽然公司已建立专项清收机制，但宏观环境若未改善，坏账风险可能持续暴露，对现金流和利润形成双重压力。此外，公司资产负债率因借款扩张而上升，短期借款同比增加48.60%，财务费用高企的态势在短期内难以缓解。
