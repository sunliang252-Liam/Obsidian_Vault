# 600228.SH 深度透视

## 因果逻辑链
- **[营收激增但亏损扩大]** -> [净利润-6333万]: 营收+126.76%至5.53亿，但销售费用暴涨294.46%至2.55亿，市场投放成本吞噬利润。
- **[导购业务扩张]** -> [导购收入+113.50%]: 加大市场推广和用户激励，交易额提升，但毛利率下降8.45个百分点至34.89%。
- **[广告业务爆发]** -> [广告收入+339.79%]: 聚焦效果营销，客户结构优化，毛利率飙升32.97个百分点至91.47%。
- **[电商零售业务起步]** -> [其他收入+5321.78%]: 为争取政府补贴资质，采取低价策略快速起量，毛利率仅0.63%。
- **[母公司历史亏损]** -> [无法分红]: 原昌九生化遗留大额未弥补亏损（-6.94亿），导致母公司层面不满足分红条件。
- **[金融资产减值]** -> [公允价值变动损失-1133万]: 私募基金及参股公司乐享似锦估值下降，拖累利润。
- **[经营现金流恶化]** -> [经营活动现金流-1.33亿]: 收入增长伴随大量市场费用支付，现金回款滞后，现金流大幅转负。

## 风险警告
**核心风险：增收不增利，现金流急剧恶化。** 公司营收翻倍增长，但净利润亏损扩大至-6333万，经营现金流更是从-219万骤降至-1.33亿。这揭示了一个危险的信号：公司为获取收入增长，不惜以高昂的市场费用（销售费用占营收46%）为代价，且现金回收效率极低。这种“烧钱换增长”的模式若无法快速转向盈利，将严重侵蚀公司本就脆弱的净资产（已降至3.96亿）。

**结构性风险：母公司“历史包袱”与业务“低毛利”双重压制。** 母公司层面高达-6.94亿的未弥补亏损，意味着公司在中短期内无法通过分红回报股东，资本运作空间受限。同时，新增长的电商零售业务毛利率仅0.63%，导购业务毛利率也在下降，整体盈利质量堪忧。公司虽已申请撤销退市风险警示，但若无法证明其增长具备可持续的盈利能力和健康的现金流，市场信心难以修复。
