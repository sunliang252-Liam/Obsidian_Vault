# 600961.SH 深度透视

## 因果逻辑链
- **[贵金属价格飙升]** -> **净利润暴增43%**: 金、银价格创历史新高，带动金锭及金硫精矿收入增长60.15%、银锭收入增长37.19%，成为利润核心引擎。
- **[锌精矿加工费修复]** -> **冶炼利润改善**: 全球锌矿供应转向宽松，加工费大幅反弹，叠加硫酸价格暴涨104%，显著修复了锌冶炼端的盈利能力。
- **[自有矿山原料保障]** -> **成本优势与业绩承诺兑现**: 自有矿山提供稳定原料，水口山铅锌矿三年累计扣非净利润达19.18亿元，超额完成8.34亿元的业绩承诺。
- **[套保业务巨亏]** -> **非经常性损益大幅侵蚀利润**: 期货套保产生公允价值变动损失3.66亿元，导致扣非净利润（14.57亿）远高于归母净利润（11.25亿）。
- **[融资成本下降]** -> **财务费用锐减49%**: 通过优化债务结构，利息支出大幅减少，直接增厚了利润。
- **[“快产快销”运营策略]** -> **经营现金流强劲增长66%**: 坚持低库存、低敞口策略，加快资金周转，经营活动现金流净额达18.4亿元，远超净利润。
- **[铅冶炼业务结构调整]** -> **毛利率逆势提升**: 增加自产原料比例，有效对冲了铅价下跌的影响，铅及铅合金毛利率提升2.95个百分点。

## 风险警告
**核心风险在于业绩对金价的高度依赖与套保业务的巨大波动性。** 2025年利润暴增的核心驱动力是金银价格的史诗级上涨，而非冶炼主业的根本性改善。一旦金价回调，公司业绩将面临断崖式下跌风险。同时，公司期货套保业务产生3.66亿元巨额亏损，暴露出其风险管理能力存在严重缺陷，这种“现货赚、期货亏”的模式并非可持续的盈利路径。

**公司长期积累的财务“暗伤”仍未解决。** 尽管2025年实现巨额盈利，但母公司及合并报表层面未分配利润仍为巨额负数（母公司-30.45亿元），导致公司连续多年无法分红。这反映出历史亏损包袱沉重，股东回报能力严重受限。此外，控股股东变更后，与金信铅业、黄沙坪矿业的同业竞争问题承诺解决期限将至，若无法妥善处理，将构成重大治理风险。
