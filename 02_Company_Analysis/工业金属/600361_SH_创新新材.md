# 600361.SH 深度透视

## 因果逻辑链
- **[产品结构“高端化”调整]** -> [营收下降4.82%]: 主动对低毛利的棒材、板带箔进行战略“瘦身”，销量分别下降11.75%和39.27%，导致整体收入规模收缩。
- **[高端产品放量，结构优化]** -> [型材销量增长31.40%，毛利率提升2.44个百分点]: 3C消费电子和汽车轻量化型材业务高速增长，高附加值产品占比提升，对冲了基础产品下滑的影响。
- **[产能扩张与资本开支增加]** -> [归母净利润下降22.25%]: 越南项目投产、募投项目结项导致固定资产折旧增加，同时为应对铝价攀升和回款周期延长，借款增加导致利息费用上升，侵蚀利润。
- **[再生铝与绿色能源布局]** -> [构建低碳壁垒，巩固核心客户关系]: 综合循环利用再生铝119.62万吨，云南水电铝产能达60万吨，满足苹果等头部客户对供应链的ESG要求，强化长期合作粘性。
- **[全球化产能布局]** -> [规避单一市场关税风险]: 越南、墨西哥、沙特项目有序推进，形成覆盖东南亚、中东、北美的产能网络，有效对冲中美贸易摩擦及出口退税取消的冲击。
- **[“铝基准价+加工费”模式]** -> [盈利核心为加工费，受铝价波动影响有限]: 公司盈利主要来自加工环节，铝原材料成本主要由下游客户承担，但加工费因行业“内卷”而承压。
- **[现金流大幅恶化]** -> [经营活动现金流净额-10.74亿元，同比-170.83%]: 销量减少导致存货占用资金增加，同时支付的其他经营保证金增加，现金循环周期显著拉长。

## 风险警告
**核心风险在于行业“内卷”加剧与公司盈利能力的持续下滑。** 报告期内，铝加工行业营收利润率已降至历史低位2.0%，公司虽通过产品结构升级对冲，但整体毛利率仍微降0.29个百分点。更关键的是，公司归母净利润同比下降22.25%，扣非净利润降幅达28.41%，显示出主营业务的造血能力正在被行业性产能过剩和加工费下行所侵蚀。若“内卷”态势延续，公司高端化转型的成效可能被行业整体利润率的压缩所抵消。

**财务风险显著上升，现金流状况恶化是最大警报。** 公司经营活动现金流净额由正转负，从上年15.17亿元骤降至-10.74亿元，降幅高达170.83%。与此同时，存货激增30.57%，应收账款增长18%，而短期借款也增加了14.65%。这种“增收不增现、利润变存货”的循环，叠加资本开支（越南、墨西哥、沙特项目）的持续投入，将严重考验公司的资金链和债务管理能力。若回款或存货周转不能改善，公司可能面临流动性压力。
