# 000807.SZ 深度透视

## 因果逻辑链
- **[绿色能源优势]** -> [成本护城河]: 依托云南水电等清洁能源（占比87.5%），碳排放仅为煤电铝的20%，在碳关税和碳交易背景下形成长期低成本竞争优势。
- **[铝价高位+供给紧平衡]** -> [量价齐升]: 国内电解铝产能受限，新能源需求拉动，铝价维持高位，公司满产满销，铝商品销量同比增长6.47%。
- **[全产业链一体化]** -> [利润截留]: 从铝土矿、氧化铝到电解铝、铝加工的全产业链布局，减少中间环节成本，有效抵御上游原料价格波动。
- **[收购少数股权]** -> [归母净利润增厚]: 收购云铝涌鑫、润鑫等子公司少数股权，提升电解铝权益产能15万吨以上，直接增厚归属于母公司股东的净利润。
- **[极致经营与降本]** -> [毛利率提升]: 电解铝和铝加工毛利率分别同比提升4.92和1.82个百分点，得益于极致控废、全要素对标和精细化管理。
- **[财务费用转负]** -> [利润释放]: 货币资金增加、带息负债减少，利息收入超过利息支出，财务费用同比大幅下降226.27%，直接增厚利润。
- **[中铝集团协同]** -> [供应链优势]: 共享中铝集采、金融、技术资源，前五大供应商采购占比80.55%，其中关联方采购占46.53%，增强议价能力和保供能力。

## 风险警告
**核心风险在于电价与铝价的双重波动。** 公司电力成本占总成本约33.62%，虽然依托云南水电，但来水的不确定性可能导致电力供应紧张或电价上调，直接侵蚀利润。同时，铝价受宏观经济、地缘政治影响呈周期性波动，若需求走弱或供给过剩，价格下跌将直接冲击公司盈利能力。公司虽通过市场化交易和长协合同对冲，但无法完全消除风险。

**同业竞争与关联交易风险不可忽视。** 控股股东中国铝业与公司在氧化铝、电解铝业务上存在同业竞争，虽承诺在2028年底前解决，但时间跨度长，执行存在不确定性。此外，公司与中铝集团及其下属企业存在大量关联交易（销售占比32.18%，采购占比46.53%），交易定价的公允性及对公司独立性的潜在影响，是投资者需持续关注的治理风险。

**公司简介（F10 原文）**

> 云南铝业股份有限公司(简称“云铝股份”)前身为云南铝厂,始建于1970年,1998年改制上市,2018年加入中铝集团,是中铝股份旗下电解铝规模最大的生产性企业。经过多年发展,云铝股份构建了集“铝土矿—氧化铝—炭素制品—电解铝—铝合金及加工—资源综合利用”为一体的绿色产业链,是全国有色行业唯一一家“国家环境友好企业”、首批国家级绿色工厂、国内首家全产业链通过ASI“双认证”的铝企业,自2005年以来蝉联历届全国文明单位。近年来,云铝股份深入贯彻落实国家“双碳”目标,依托云南省及周边丰富的绿色能源和铝土矿资源优势,按照中铝集团对云铝股份的战略定位,加快建设高端化、智能化、绿色化铝产业体系,打造世界级绿色铝一流企业标杆。
