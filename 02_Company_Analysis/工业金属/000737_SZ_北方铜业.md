# 000737.SZ 深度透视

## 因果逻辑链
- **[铜价创历史新高]** -> [营收与利润双增]: 2025年铜价强势上涨至12960美元/吨，公司阴极铜销售均价随之提升，直接拉动营收增长15.8%，归母净利润增长29.01%。
- **[铜精矿加工费跌至负值]** -> [外购原料冶炼利润承压]: 现货TC跌至-40美元/吨以下，公司外购铜原料冶炼的利润来源（加工费）被严重压缩，但通过长单合同（占比85%）部分对冲了风险。
- **[自有矿山低成本优势]** -> [盈利韧性]: 铜矿峪矿采用自然崩落法，开采成本接近露天开采，自产铜（4.3万吨）利润不受加工费影响，成为公司抵御行业周期波动的核心压舱石。
- **[深部找矿取得重大突破]** -> [资源保障能力跃升]: 探获新增铜矿石资源量1.04亿吨，金属量86.96万吨，资源储量大幅增长，为公司长期发展及产业链延伸提供了坚实的资源基础。
- **[侯马北铜冶炼产能释放]** -> [规模效应与综合回收]: 侯马北铜“三连炉”工艺实现19个月长周期稳定运行，公司冶炼产能达32万吨，规模效应摊薄固定成本，并综合回收金、银等贵金属，增厚利润。
- **[十八河尾矿库闭库完工]** -> [消除重大环保隐患]: 作为黄河流域生态保护的政治任务，该工程按期完工并销号，消除了公司最大的环保合规风险，为后续生产经营扫清障碍。
- **[公允价值变动损益大幅亏损]** -> [利润表波动加剧]: 因采购及销售延迟定价条款的公允价值变动，产生-8.9亿元的巨额非现金损失，虽不影响现金流，但显著扭曲了当期利润表，凸显套期会计的复杂性。

## 风险警告
**核心风险在于铜精矿加工费（TC/RC）持续为负的结构性困境。** 全球矿端供应紧张与国内冶炼产能过剩的矛盾短期难以缓解，公司外购铜原料冶炼业务（占营收主体）的利润空间被极度压缩。虽然自有矿山提供了安全垫，但若加工费长期维持低位甚至进一步恶化，将严重侵蚀公司冶炼环节的盈利能力，这是行业性的系统性风险。

**铜价高位回落风险不容忽视。** 公司利润对铜价高度敏感，2025年铜价已创历史新高。若全球经济衰退或下游需求（尤其是新能源领域）不及预期，铜价大幅回调将直接冲击公司自产铜的利润和存货价值。同时，公司为对冲风险持有大量衍生品，公允价值变动剧烈（-8.9亿），若市场反向波动，可能引发更大的非经营性亏损。
