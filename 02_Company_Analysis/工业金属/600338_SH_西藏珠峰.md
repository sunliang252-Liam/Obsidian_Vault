## 因果逻辑链
- **[产量恢复与销量增长]** -> [营收增长48.22%]: 塔中矿业采矿量同比增34.30%，铅锌铜银金属产量同比增23.06%，量价齐升驱动营收从16.39亿跃升至24.30亿元。
- **[贵金属价格上涨]** -> [毛利率提升6.71个百分点]: 白银价格领涨大宗商品，铅精矿（含银）毛利率达66.94%，铜精矿（含银）毛利率达82.96%，高毛利产品占比提升优化盈利结构。
- **[成本管控与合同重构]** -> [营业成本增速低于营收]: 采掘综合单价下调、高值耗材“自购直采”、选矿结算从“以量计酬”转为“质效双控”，成本仅增29.77%，远低于营收增速。
- **[偿还借款与汇率变动]** -> [财务费用大幅减少404.18%]: 偿还到期有息负债降低利息支出，叠加美元/索莫尼汇率变动形成汇兑收益，财务费用由正转负至-8069万元。
- **[塔国税收政策调整]** -> [税金及附加激增210%]: 塔吉克斯坦税收政策调整导致税金及附加从1.64亿增至5.10亿元，成为利润侵蚀最大单项，但被收入增长覆盖。
- **[点价结算与套期保值]** -> [公允价值变动收益8042万元]: 销售合同点价机制及衍生金融工具运用，在金属价格波动中产生公允价值变动收益，增厚当期利润。
- **[阿根廷盐湖项目持续投入]** -> [珠峰香港亏损1.57亿元]: 安赫莱斯项目尚未投产，建设期费用及融资成本导致控股子公司珠峰香港持续亏损，拖累合并净利润。

## 风险警告
**核心风险在于阿根廷锂盐湖项目的“黑洞”效应与流动性困局。** 珠峰香港2025年亏损1.57亿元，安赫莱斯3万吨项目进展缓慢，RIGI申报尚在初期，项目投产时间与融资方案高度不确定。与此同时，公司货币资金仅2036万元，短期借款降至2652万元，但控股股东借款余额达1.24亿元，且存在大量资产抵押（固定资产抵押9.84亿、塔中矿业股权质押7.88亿），财务弹性极低。若锂项目持续无法贡献现金流，公司可能面临“主业输血副业”的流动性陷阱。

**地缘政治与监管合规风险不容忽视。** 公司近三年累计收到20余次监管处罚，涉及信息披露、内控缺陷、控股股东违规等，2026年初控股股东再被罚款300万元，治理瑕疵暴露了内部制衡机制的薄弱。塔吉克斯坦税收政策突变（税金同比增210%）与索莫尼汇率波动（Q4单季汇兑损失显著）表明海外运营的国别风险正在加剧。阿根廷RIGI政策能否落地、比索贬值压力、以及中阿关系波动，均可能使锂项目陷入“投入无产出、退出无通道”的僵局。
