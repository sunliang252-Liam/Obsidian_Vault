## 因果逻辑链
- **[南非奥尼金矿产能释放]** -> [黄金收入暴增120,107.72%]: 矿山完成采矿量42.4万吨（+38.5%），西选厂首条生产线稳定运行，黄金产量达1,311千克，实现从0到1的规模化突破。
- **[黄金、硫酸、氢氧化钴量价齐升]** -> [营业收入同比增长81.94%]: 黄金、硫酸、氢氧化钴收入分别增长8.25亿、3.99亿、2.16亿元，叠加金价、钴价处于历史高位，驱动营收大幅增长。
- **[黄金、硫酸毛利大幅增加]** -> [归母净利润扭亏为盈至2.25亿元]: 黄金业务毛利增加2.59亿元，硫酸业务毛利增加2.04亿元，是公司从亏损3.22亿到盈利2.25亿的核心驱动力。
- **[刚果(金)铜钴矿稳产增效]** -> [阴极铜产量同比增长5.3%，氢氧化钴销量暴增394.4%]: 通过稳定供应商和电力供应，实现阴极铜产量2.77万吨，并抓住钴价反弹契机，大幅去库存。
- **[套期保值业务规模扩大]** -> [衍生金融负债激增3,197.87%]: 为对冲铜、金等价格波动风险，公司大量使用期货合约，导致衍生金融负债从355万激增至1.17亿元，形成潜在现金流压力。
- **[贸易业务模式创新]** -> [贸易收入同比增长410.30%]: 成功落地新模式，拓展融资渠道，引入优质客户，实现贸易阴极铜收入从71万增至5,185万元。
- **[处置金融资产高位退出]** -> [投资活动现金净流出3.86亿元]: 虽处置思泉新材等股票回流资金，但南非金矿开发投入2.78亿元，导致整体投资活动现金为净流出。
- **[业绩承诺补偿争议诉讼]** -> [公司通过诉讼追索约4.3亿元补偿款及2.2亿股]: 因宁波天弘未完成2018-2024年累计业绩承诺，交易对方姜照柏、姜雷需补偿，公司已提起诉讼。

## 风险警告
**核心风险在于业绩补偿的巨额不确定性及衍生品交易的高杠杆风险。** 公司因收购宁波天弘的业绩承诺未达标，已向实控人姜照柏、姜雷提起诉讼，追索约4.3亿元现金及2.2亿股股份。此案虽已立案，但结果高度不确定，若无法顺利执行，将对公司资产和股东权益造成重大冲击。同时，公司为对冲价格风险，衍生金融负债从355万元飙升至1.17亿元，表明套保头寸巨大，一旦市场出现极端反向波动，可能引发追加保证金甚至穿仓风险，侵蚀主业利润。

**海外运营与资产结构风险同样不容忽视。** 公司87.87%的资产位于南非和刚果（金），面临地缘政治动荡、政策突变（如刚果金钴出口禁令）、基础设施薄弱及汇率波动（兰特、刚果法郎）等多重风险。此外，核心子公司希图鲁矿业（SMCO）净资产为-9亿元，已资不抵债，主要依赖内部借款维持运营；南非CAPM净资产也为-4.3亿元。这种高杠杆、高依赖的海外资产结构，使得公司整体财务韧性较弱，任何单一矿山的运营中断都可能引发连锁反应。
