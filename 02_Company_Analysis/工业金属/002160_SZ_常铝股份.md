# 002160.SZ 深度透视

## 因果逻辑链
- **[新能源业务扩张]** -> [营收增长但利润承压]: 新能源电池壳业务（山东新合源）营收增长3.22%，但竞争加剧导致净利润下降25.19%，拖累整体盈利。
- **[原材料价格波动与下游压价]** -> [毛利率下滑]: 铝锭价格中枢上升，叠加下游汽车、空调行业价格战，铝箔制品毛利率同比下降1.16个百分点至10.91%。
- **[新能源客户信用期延长]** -> [经营现金流大幅恶化]: 新能源客户销售占比提升，其信用期长于传统客户，导致经营活动现金流净额由正转负，为-3.2亿元。
- **[新项目投产爬坡]** -> [短期亏损与长期产能释放]: 年产3万吨电池箔、10万吨再生铝等项目进入试产/量产爬坡，但电池箔因坯料质量不稳定未达产，子公司常铝新能源亏损6396万元。
- **[商用车新能源化提速]** -> [热管理业务增长]: 泰安鼎鑫抓住新能源重卡渗透率提升机遇，新能源热管理收入增速远超行业平均，净利润8443万元，成为重要利润来源。
- **[产业链一体化布局]** -> [成本控制与协同效应]: 从上游铝加工（包头常铝）到下游精密结构件（山东新合源）的垂直整合，部分对冲了加工费下滑的影响，但包头常铝仍亏损7364万元。
- **[降本增效与费用管控]** -> [费用率下降]: 管理费用、销售费用、财务费用及研发费用占营收比例均同比下降，体现成本领先策略的执行效果。

## 风险警告
公司面临的核心风险是**增收不增利与现金流恶化**的双重困境。营收增长7.93%但净利润仅微增7.01%，毛利率全面下滑，而经营现金流由正转负至-3.2亿元，显示盈利质量堪忧。新能源业务虽为增长引擎，但竞争加剧导致利润被侵蚀，且长账期客户占比提升进一步加剧了资金压力。

其次，**新项目达产不及预期**构成重大风险。电池箔项目因上游坯料质量不稳定，实际产出与设计产能差距巨大，导致子公司常铝新能源巨额亏损。若技术瓶颈无法突破，前期巨额投资将面临减值风险，并拖累公司向新能源高端转型的战略节奏。同时，控股股东齐鲁财金所持股份存在高比例质押（50%）及冻结，也需关注其潜在的流动性风险传导。
