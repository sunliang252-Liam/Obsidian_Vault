# 300337.SZ 深度透视

## 因果逻辑链
- **[营收增长但利润下滑]** -> 增收不增利: 营收增长19.48%至63.95亿，但归母净利润下降19.81%至4626万，主因信用减值损失激增至6591万（同比+26.6%）及财务费用因可转债利息增加25.6%。
- **[“铝锭+加工费”定价模式]** -> 利润受铝价波动侵蚀: 铝锭成本占生产成本超80%，采购与销售定价时间差导致铝价下跌时利润承压，2025年毛利率仅9.88%，同比微降0.46%。
- **[新能源车热管理需求爆发]** -> 驱动铝热传输材料增长: 新能源车单车用铝量从10KG提升至20-25KG，公司铝基系列产品收入增长21.63%，占营收94.03%，成为核心增长引擎。
- **[淮北新产能投产]** -> 短期拖累现金流与利润: 年产35万吨项目（一期）进入试生产，在建工程激增87%，导致存货增加24.8%至19.84亿，经营活动现金流净流出5.04亿（同比扩大21.2%）。
- **[可转债发行与转股]** -> 缓解资金压力但增加财务成本: 2025年1月发行7.85亿可转债，募集资金用于新项目，但利息费用增加导致财务费用同比上升25.6%，且转股后股本微增。
- **[研发投入大幅增长]** -> 短期压制利润，长期构筑壁垒: 研发费用同比大增44.19%至3.06亿，占营收4.78%，聚焦新能源冷却板、钛铝复合材料等，但尚未转化为当期利润。
- **[出口业务增长]** -> 对冲国内华南市场下滑: 出口收入增长28.33%至14.39亿，占比提升至22.5%，弥补了华南地区收入下降22.97%的缺口，但汇率波动带来汇兑风险。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司营收增长近20%，但扣非净利润暴跌56.36%至仅1924万，经营性现金流净流出5.04亿。这背后是信用减值损失（6591万）、财务费用（1.22亿）和研发费用（3.06亿）的三重挤压。更危险的是，存货激增至19.84亿（占总资产30%），若铝价下跌，将面临巨额跌价损失，进一步吞噬本已微薄的利润。

**淮北新项目是“双刃剑”。** 年产35万吨项目是未来增长的关键，但当前试生产阶段已导致现金流大幅失血。项目能否在2026年如期达产、达产后能否快速消化产能并实现盈利，存在重大不确定性。若市场增速放缓或客户开拓不及预期，巨额资本开支将转化为沉重的折旧和财务负担，公司资产负债率已高达73.91%。
