- **新能源汽车与锂电池需求高速增长** -> 锂电池结构件及电池箔收入大幅增长: 2025年动力电池销量同比增长51.8%，储能电池销量同比增长101.3%，带动锂电池结构件用铝板带收入同比增长52.83%，动力电池箔收入同比增长58.45%。
- **锂电池等高端产品需求旺盛** -> 公司产品结构优化，锂电池和电子电器收入占比提升至81.49%: 下游锂电池、电子电器等领域需求增长，公司加大高端产品研发和市场开拓，使得高附加值产品收入占比提高。
- **产品结构优化及产销量增长** -> 归母净利润同比增长30%，毛利率提升: 高端产品占比提升带动综合毛利率上升，同时产销规模扩大带来规模效益，使得利润增速高于收入增速。
- **贸易摩擦及境外需求下降** -> 境外业务收入同比下降38.21%: 美国加征关税、多国发起贸易摩擦案件，加上铝材出口退税取消，导致出口承压；公司优先保障国内大客户，主动减少出口。
- **国内订单充足，产能紧张** -> 公司优先保供国内客户，境外收入大幅下滑: 下游需求旺盛，公司产能利用率高，为满足国内大客户订单，主动压缩出口业务。
- **IPO募集资金及现金流改善** -> 短期借款大幅减少，财务费用下降93.78%: 公司上市募集资金到位，经营活动现金流净额大幅增加，用于偿还银行贷款，导致利息支出减少。
- **研发投入增加** -> 新产品产业化成功，高端产品收入增长: 公司持续加大研发投入（同比增21.01%），成功量产高强电池箔、液冷板等新产品，获得头部客户认可，推动收入增长。
- **数智化转型** -> 生产效率提升，成本控制改善: 公司应用AI、数字孪生等技术，实现生产计划、质量检测等环节的智能化，提升质检效率和工艺参数优化，降低能耗和原材料浪费。
- **再生铝使用及绿色能源应用** -> 成本优化与可持续发展能力增强: 公司推进废铝保级回收、建设光伏电站，降低原材料成本和碳排放，提升长期竞争力。

## 风险警告

> 永杰新材料股份有限公司(简称“永杰新材”)设立于2003年,是一家国家重点高新技术企业,主要从事铝及铝合金新材料的研发、生产与销售,产品主要应用于新能源、AI人工智能、轻量化、热管理等战略性新兴产业领域,为客户提供全方位的铝材解决方案。公司坐落于杭州市钱塘区,下辖浙江永杰铝业有限公司、浙江南杰实业有限公司、杭州中成铝业有限公司、香港南杰资源有限公司等多家全资子公司。二十余载匠心耕耘,永杰新材于2025年3月11日在上交所上市(股票代码:603271),先后获中国驰名商标、“中国铝板带材十强企业”、制造业单项冠军产品、国家级绿色工厂等荣誉。公司技术支撑全面,与中南大学、北京科技大学、浙江大学、中国科学院金属研究所等国内知名院校科研机构合作,拥有国家级博士后科研工作站、省级企业研究院和CNAS认证实验室。公司同时拥有热连轧和铸轧全工艺链生产线,具有行业领先技术水平的现代铝轧制生产系统,深耕高强高导高韧铝镁锰新材料的研发与制造,推进智能制造升级,强化绿电铝、再生铝等低碳铝应用,践行绿色发展,加快发展新质生产力,努力将公司打造成为世界级新能源铝合金引领者。
