# 300057.SZ 深度透视

## 因果逻辑链
- **[国内外铝价倒挂 + 出口退税取消]** -> [铝加工毛利承压]: 国内外价差侵蚀利润，退税取消直接增加出口成本，导致铝加工业务虽量增但利薄。
- **[行业加工费内卷]** -> [铝箔业务盈利恶化]: 行业竞争激烈，加工费持续走低，即使电池铝箔销量提升，也无法弥补单位利润下滑。
- **[功能性薄膜产销规模有限]** -> [单位固定成本高企]: 产能利用率不足，折旧等固定成本无法有效摊薄，导致该业务毛利率为-55.23%，严重拖累整体业绩。
- **[计提大额资产减值]** -> [净利润亏损加剧]: 报告期计提资产减值准备9192万元，占利润总额的-54.62%，是亏损扩大的直接财务原因。
- **[铝加工业务量增9.97%]** -> [营收结构优化]: 铝加工营收占比从71.93%提升至89.77%，成为公司核心收入支柱，但未能扭转整体亏损。
- **[出售子公司股权]** -> [非经常性收益增厚业绩]: 出售深圳宇锵等子公司获得约2420万元收益，使归母净利润减亏4.05%，掩盖了主营业务的真实恶化程度。
- **[高附加值产品突破]** -> [纸包装毛利率提升]: 高附加值专版转移纸销量增长，带动纸包装业务毛利率逆势提升2.11%，成为少数亮点。

## 风险警告
**核心风险在于铝加工主业的“增收不增利”困境。** 尽管营收增长近10%，但国内外铝价倒挂、出口退税取消及行业加工费内卷三重压力叠加，导致该业务毛利水平持续承压。公司通过海外收购（欧箔卢森堡）试图规避贸易壁垒，但整合效果及海外市场风险尚待验证。同时，安徽中基10万吨电池箔项目延期至2026年9月，新增产能的消化与盈利前景存在重大不确定性，若市场供需逆转，将面临巨额折旧摊销压力。

**第二重风险来自功能性薄膜业务的持续失血与资产减值隐患。** 该业务毛利率为-55.23%，产销规模萎缩，短期内难以扭亏。此外，公司参股的世优科技业绩承诺未完成（完成率-84.25%），已触发补偿与回购义务，但补偿义务人尚未履行，存在款项无法收回的风险。叠加公司对外担保余额占净资产比例高达82.50%，若被担保方出现违约，将直接冲击公司财务安全。
