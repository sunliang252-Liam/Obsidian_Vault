# 300328.SZ 深度透视

## 因果逻辑链
- **[营收微增但利润巨亏]** -> 净利润-1763.73万元，同比暴跌1854.10%: 营收增长4.47%未能覆盖信用减值、存货跌价及汇兑损失等非经营性成本的大幅增加。
- **[核心业务结构失衡]** -> 铝制品收入增36.13%，镁制品收入降12.80%: 公司主动调整产品结构，铝制品放量弥补镁制品下滑，但毛利率更低的铝制品占比提升拖累整体盈利。
- **[非晶合金业务萎缩]** -> 液态金属收入同比骤降52.02%: 折叠屏铰链等核心应用领域竞争加剧，或面临客户订单波动与技术替代风险，高附加值产品收入大幅缩水。
- **[研发投入资本化率下降]** -> 资本化研发支出占净利润比重从86.74%降至10.75%: 研发项目进入后期，资本化条件减弱，更多研发费用当期费用化，直接侵蚀利润。
- **[现金流恶化]** -> 经营活动现金流净额同比锐减76.74%: 购买商品、接受劳务支付的现金大幅增加，反映公司对上游议价能力弱或存货积压，现金循环周期拉长。
- **[应收账款高企]** -> 应收账款占总资产19.65%，且信用减值损失增加: 下游客户（尤其是新能源汽车）回款周期长，坏账风险持续累积，是利润下滑的直接推手。
- **[汇率波动冲击]** -> 人民币升值导致汇兑损失增加，财务费用同比增46.86%: 公司出口业务占比28.56%，以美元定价，汇率波动直接侵蚀出口利润，且对冲工具运用效果有限。
- **[生物可降解镁骨钉注册推进]** -> 产品注册申请已获受理，进入最后审批阶段: 这是公司未来最大的潜在增长点，一旦获批将开辟全新市场，但当前仍处于投入期，无收入贡献。

## 风险警告
**核心风险在于盈利能力的持续恶化与现金流的双重压力。** 公司已连续三年扣非净利润为负，2025年归母净利润也转负，表明主营业务造血能力严重不足。利润下滑的直接原因（信用减值、存货跌价、汇兑损失）并非偶发，而是公司商业模式（长回款周期、高出口占比）与行业竞争加剧的必然结果。若不能有效改善应收账款周转率或提升高毛利产品（如非晶合金）的销售占比，公司可能陷入“增收不增利”甚至“减收减利”的恶性循环。

**战略风险在于新业务（生物可降解镁骨钉）的落地不确定性。** 该产品虽已进入注册审批最后阶段，但后续商业化推广、市场接受度、医保准入及竞争对手跟进速度均存在重大变数。公司为此已投入大量研发资源，若产品上市后销售不及预期，将无法弥补现有业务的下滑，且持续的研发与市场拓展费用会进一步加剧财务压力。同时，非晶合金业务在折叠屏铰链领域的收入骤降，表明其技术壁垒可能正在被竞争对手突破，核心增长引擎面临熄火风险。

> 东莞宜安科技股份有限公司成立于1993年5月,经过二十余年的学习研究以及发展,成为国内领先的新材料公司。宜安科技是一家集轻合金材料研发、生产、营销为一体的国家火炬计划重点高新技术企业,液态金属、生物可降解医用镁合金、镁铝合金汽车产品为公司三大重点板块业务。产品范围包括消费电子、高端LED幕墙、医疗器械、汽车配件、通讯设备、大型结构件(车门、电视幕墙等)等。公司不断加快科技创新的步伐,大力开展新技术﹑新产品的研发。公司先后建有“宜安科技-中科院金属所非晶态材料研究联合实验室”、“国家博士后科研工作站”、“广东省轻合金工程技术研究开发中心”、“省企业技术中心”、“广东省院士专家工作站”、“广东省企业重点试验室”、“国际科技合作基地”等多个科研机构。公司目前正致力于液态金属材料、镁合金医用材料及器械、汽车轻量化工程的研究与开发,努力为本地区技术进步和产业升级做出更大贡献,争取成为新兴材料业的领先企业。
