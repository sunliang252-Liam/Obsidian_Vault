# 002379.SZ 深度透视

## 因果逻辑链
- **[产能天花板与供需缺口]** -> [高盈利]: 国内电解铝产能逼近4500万吨天花板，而新能源需求持续增长，供给缺口支撑铝价高位，公司作为全球最大电解铝生产商之一直接受益。
- **[全产业链一体化布局]** -> [成本优势]: “氧化铝-电解铝-铝深加工”一体化，自产氧化铝规避原料价格波动，铝水直供下游降低再熔成本，形成显著成本护城河。
- **[云南水电铝产能转移]** -> [绿色溢价]: 将217.6万吨产能转移至云南，利用水电降低能源成本与碳排放，满足下游对绿色铝的需求，获得政策与市场双重红利。
- **[重大资产重组完成]** -> [规模跃升]: 发行股份收购宏拓实业100%股权，实现从单一铝加工向全产业链“链主”转型，总资产、营收、净利润实现数量级增长。
- **[稳定的铝土矿供应]** -> [原料安全]: 控股股东通过参股几内亚项目锁定上游资源，保障了公司氧化铝生产所需铝土矿的稳定供应，抵御国际市场价格波动风险。
- **[技术领先与能效领跑]** -> [降本增效]: 拥有全球首条600kA特大型电解槽，连续多年被评为电解铝行业能效领跑者，低电耗直接转化为成本优势。
- **[下游客户集聚效应]** -> [高周转]: 凭借稳定电解铝供应，吸引创新集团、万通金属等下游企业集聚，实现铝水就地转化，降低物流成本，提升资产周转效率。

## 风险警告
**核心风险在于铝价周期性波动与成本端双重挤压。** 公司2025年扣非净利润为-3.69亿元，盈利高度依赖铝价高位与氧化铝自产。若宏观经济下行导致下游需求萎缩，或电解铝产能天花板被突破，铝价下跌将直接侵蚀利润。同时，电力成本占电解铝总成本超30%，若煤炭价格反弹或云南水电电价上涨，将严重削弱成本优势。

**关联交易与同业竞争风险不容忽视。** 公司前五大供应商中关联方采购占比高达55.03%，包括向中国宏桥采购铝土矿、向关联电厂采购电力等，定价公允性需持续关注。此外，实际控制人控制的印尼宏发韦立（200万吨氧化铝产能）与公司存在潜在同业竞争，虽目前销售区域不同，但未来若市场变化，可能引发利益冲突。
