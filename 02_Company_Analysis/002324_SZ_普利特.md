# 002324.SZ 深度透视

## 因果逻辑链
- **[新能源汽车渗透率提升+国产汽车品牌崛起]** -> [改性材料业务满产满销]: 公司作为头部主机厂核心供应商，受益于下游需求结构性增长，全年产能利用率达96.08%。
- **[LCP薄膜通过消费电子头部客户验证并批量供货]** -> [ICT材料业务实现从0到1突破]: 打破国外垄断，为后续在6G、AI服务器、脑机接口等高频高速场景放量奠定基础。
- **[储能市场需求旺盛+珠海/启东基地产能释放]** -> [新能源电池收入同比+65.56%]: 方形314Ah电芯全年交付超300万支，储能业务成为新能源板块核心增长点。
- **[钠离子电池产业化落地+战略融资]** -> [钠电出货量跻身全球第二]: 聚阴离子体系技术领先，斩获海外1GWh及南网科技30MWh等重大订单，开辟第二增长曲线。
- **[强化营运资本管控+优化供应链付款]** -> [经营活动现金流净额同比+678%]: 精细化运营提升周转效率，经营现金流从-1.97亿大幅改善至+11.38亿，远超净利润。
- **[改性材料非汽车业务拓展]** -> [非汽车材料销售收入同比+132%]: 成功切入储能系统、家电、电动工具、二轮车等新市场，降低对单一汽车行业的依赖。
- **[海四达电源圆柱业务受关税影响+战略聚焦调整]** -> [新能源板块未能扭亏]: 主动关闭部分产品线、出售非核心资产，叠加钠电尚处亏损期，拖累整体盈利能力。

## 风险警告
**新能源业务盈利拐点不确定性高。** 尽管储能收入暴增，但海四达电源仍未扭亏。圆柱业务受关税冲击，钠电业务尚处投入期，公司虽给出2026年扭亏指引，但行业竞争激烈、价格战持续，兑现存在风险。同时，公司主动收缩产品线、出售资产，短期对利润表造成一次性冲击。

**新兴业务验证与放量节奏存在重大不确定性。** LCP薄膜虽实现手机终端突破，但当前体量极小；脑机接口、低轨卫星、6G等应用尚处验证或临床阶段，商业化路径漫长。机器人、低空经济等改性材料新场景同样面临认证周期长、被替代的风险。这些高预期业务若进展不及预期，将导致估值回调。
