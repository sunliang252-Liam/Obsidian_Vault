# 002662.SZ 深度透视

## 因果逻辑链
- **下游客户订单结构调整** -> [营收下降5.93%]: 传统合资品牌客户份额下滑，公司外饰件销量同比下降4.48%，导致主营业务收入减少。
- **研发费用大幅增长26.64%** -> [净利润下降29.69%]: 公司为布局锂电池新赛道及工艺升级，研发投入占营收比升至8.09%，侵蚀当期利润。
- **财务费用飙升682.87%** -> [利润承压]: 贷款规模扩大及外币贷款汇兑损失，导致利息费用和汇兑损失大幅增加。
- **投资收益下降** -> [净利润进一步下滑]: 合营企业贡献减少，叠加非经常性损益波动，加剧了利润端的收缩。
- **新设能源科技子公司** -> [开辟第二增长曲线]: 投资设立北京峰璟能源科技及孙公司，进军锂电池（动力/储能）领域，但尚处投入期，未贡献利润。
- **竞拍南京整车厂资产** -> [资本开支大幅增加]: 投资4.09亿元竞拍南京工业4.0整车厂，计划改造形成30万台年产能，导致在建工程同比激增164%。
- **境外业务增长16.22%** -> [收入结构优化]: 境外地区营收占比提升至7.99%，成为对冲境内市场下滑的少数亮点。

## 风险警告
**核心风险在于双主业转型的“青黄不接”。** 传统汽车零部件主业受合资品牌客户份额下滑及价格战传导影响，营收与利润持续承压。公司重金押注的锂电池项目虽已完成1GWh产线建设，但尚未实现批量销售，南京整车厂资产改造也需大量资金投入。在主营业务造血能力减弱、财务费用飙升的背景下，新业务能否如期贡献利润存在巨大不确定性，公司面临“旧力已衰、新力未生”的阶段性困境。

**另一重大风险是客户集中度过高与应收账款坏账风险。** 前五大客户销售额占比高达54.72%，高度依赖一汽大众、北京奔驰等传统合资巨头。随着自主品牌崛起和新能源车企更迭，若主要客户需求萎缩或转向其他供应商，将对公司经营造成致命打击。同时，新客户拓展可能引入信用风险，新能源造车新势力的经营波动可能带来应收账款坏账损失。
