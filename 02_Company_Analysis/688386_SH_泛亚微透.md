# 688386.SH 深度透视

## 因果逻辑链
- **[增资控股凌天达]** -> [营收与总资产暴增]: 2025年7月将凌天达纳入合并报表，直接贡献高性能线束收入1.35亿元，并驱动总资产从10.89亿跃升至19.24亿（+76.73%）。
- **[ePTFE微透产品持续进口替代]** -> [核心业务稳健增长]: 凭借自主可控的ePTFE膜工艺，在汽车、消费电子领域替代美国戈尔份额，实现营收2.09亿元（+28.56%），毛利率维持71.30%高位。
- **[CMD产品颠覆传统车灯方案]** -> [第二增长曲线成型]: 独创的凝露控制方案（100%国产化）被星宇股份、华域视觉等头部客户采用，CMD产品营收1.60亿元（+12.72%），毛利率提升至66.00%。
- **[定增募资6.71亿元]** -> [资本结构优化与产能扩张]: 募集资金投向CMD技改扩产、低介电FCCL及研发中心，为未来3-5年增长提供资金与产能储备，同时引入专业投资者优化治理。
- **[车规级线束业务尚处初期]** -> [拖累净利润增速]: 子公司泛亚电子亏损2,212万元，车规级线束规模效应未显现，导致归母净利润增速（+9.49%）远低于营收增速（+40.40%）。
- **[参股公司源氢新能源土地退赔]** -> [四季度利润大幅下滑]: 源氢新能源因退还储备土地缴纳违约金1,503万元，导致四季度归母净利润同比骤降45.67%，侵蚀全年利润。
- **[研发投入持续加大]** -> [技术壁垒加固]: 研发费用3,867万元（+35.04%），重点突破机器人电子皮肤基膜、高耐弯折线缆（>3500万次循环）、低介电FCCL等前沿技术，巩固“工艺+设备”双重护城河。

## 风险警告
**核心风险在于“增收不增利”的结构性矛盾。** 营收40%的高增长主要依赖外延并购（凌天达并表），而非内生盈利能力的同步提升。车规级线束业务（泛亚电子）持续大额亏损，叠加参股公司源氢新能源的意外损失，导致净利润增速严重落后。若新业务无法在1-2年内实现盈亏平衡，高额的折旧与费用将长期侵蚀股东回报。

**商誉与资产减值风险不容忽视。** 报告期末商誉账面价值高达1.19亿元，主要来自收购大音希声与控股凌天达。大音希声此前已计提4,572万元减值，若其气凝胶业务或凌天达的高性能线束业务未来业绩不及预期，将面临进一步减值风险。同时，应收账款（+67%）与存货（+95%）增速远超营收，需警惕坏账与跌价风险。
