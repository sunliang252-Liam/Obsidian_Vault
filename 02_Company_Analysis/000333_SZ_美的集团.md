# 000333.SZ 深度透视

## 因果逻辑链
- **[海外OBM优先战略]** -> [海外收入增长16%]: 自营分公司覆盖国家从27个增至50个，OBM收入占智能家居海外收入45%以上，驱动海外收入达1,959亿元。
- **[ToB第二曲线构建]** -> [ToB收入增长17.5%]: 通过收购Arbonia、东芝电梯中国、锐珂医疗等，楼宇科技、新能源等业务形成增长接力，ToB收入达1,228亿元。
- **[全价值链数字化]** -> [运营效率提升]: 自研Data Agent覆盖40+场景，全年提效超1,500万小时、降本7亿元，库存周转率提升10%，客户库存周转效率改善10%以上。
- **[双高端品牌战略]** -> [品牌溢价与结构升级]: COLMO+东芝双高端品牌零售额实现双位数增长，COLMO品牌店超1,600家，东芝冰箱国内零售额同比增长20%。
- **[全球研发网络]** -> [产品差异化创新]: 全球41个研发中心、2.3万研发人员，研发投入178亿元，支撑MDV9多联机、美罗人形机器人等领先产品推出。
- **[AI与智能化投入]** -> [智能家居生态壁垒]: 超400人AI团队，年度数字化与AI投入超30亿元，美居APP注册用户超8,800万，日均交互近3,000万次。
- **[全球制造布局]** -> [供应链韧性]: 海外43个主要制造基地，泰国罗勇工厂年产能60万台，墨西哥基地投产，有效对冲关税与地缘风险。

## 风险警告
**核心风险在于国内家电市场的结构性萎缩与竞争加剧。** 2025年国内家电零售规模同比下滑4.3%，奥维云网预测2026年将继续下滑6.7%。美的国内收入占比仍高达57%，在“以旧换新”政策前置需求后，国内增长动能面临断档风险。同时，行业价格战持续，空调均价下降约5%，冰箱、厨卫等品类均呈下行趋势，毛利率承压。

**海外业务面临的地缘政治与关税风险不可忽视。** 海外收入占比已达42.93%，但全球贸易保护主义抬头、关税政策反复变化，叠加汇率波动，对海外经营形成持续挑战。虽然公司通过本地化制造布局对冲部分风险，但若主要市场（如北美、欧洲）贸易壁垒进一步升级，将直接影响海外OBM业务的盈利能力和增长持续性。
