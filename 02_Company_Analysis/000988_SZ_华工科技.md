# 000988.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [联接业务营收增长53.39%]: 公司800G/1.6T光模块产品精准卡位全球AI数据中心建设浪潮，实现规模化交付，驱动光电器件业务成为最大增长极。
- **[新能源汽车渗透率提升]** -> [感知业务营收增长9.78%]: 公司温度、压力传感器在新能源车市场占有率提升至70%，热管理集成模块获主机厂定点，受益于汽车电动化对传感与控制元件的刚性需求。
- **[全球化产能布局与客户拓展]** -> [海外营收增长45.52%]: 泰国、越南等海外基地投产，叠加“全球研发、全球制造、全球服务”战略转型，海外收入突破20亿元，有效对冲国内竞争压力。
- **[研发投入资本化率提升]** -> [研发费用率下降但研发投入强度不减]: 研发投入资本化率从11.60%升至18.96%，表明公司对下一代技术（如3.2T光引擎、硅光芯片）的投入进入成果转化阶段，短期费用压力缓解。
- **[存货与应收账款管理优化]** -> [经营性现金流净额增长66.83%]: 应收账款同比下降11.4%，同时销售回款大幅增加，现金流质量显著改善，为后续资本开支提供支撑。
- **[“博士500”计划与中央研究院建设]** -> [技术创新壁垒加固]: 公司通过引进高端人才、联合高校实验室，在硅光芯片、薄膜铌酸锂、三维五轴激光装备等“卡脖子”领域实现突破，巩固行业领先地位。
- **[智能制造向高价值场景延伸]** -> [激光装备业务稳健增长4.13%]: 从传统切割向焊接、清洗、淬火等高附加值工艺拓展，在船舶、新能源汽车行业订单同比增长超20%，提升单客户价值量。

## 风险警告
**1. 地缘政治与供应链风险：** 公司海外营收占比快速提升至14%，且核心客户集中于全球顶级云服务商。中美贸易摩擦升级可能导致关税成本激增、出口管制收紧，直接影响光模块产品的利润率和交付稳定性。同时，关键原材料（如高端光芯片）的进口依赖仍存，供应链“卡脖子”风险未完全消除。

**2. 技术迭代与竞争加剧风险：** 光模块行业正从800G向1.6T、3.2T乃至CPO技术快速演进，技术路线存在不确定性（如硅光、LPO、CPO并行）。若公司在下一代技术（如3.2T CPO）的研发或量产进度落后于竞争对手（如中际旭创、新易盛），将面临市场份额被蚕食的风险。此外，传感器和激光装备领域竞争激烈，价格战可能侵蚀毛利率。
