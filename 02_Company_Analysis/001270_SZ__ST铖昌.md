# 001270.SZ 深度透视

## 因果逻辑链
- **[下游需求恢复与订单落地]** -> [营收同比+91.28%]: 星载遥感卫星项目进入批量交付，机载通信项目量产，推动T/R芯片销量同比+110.34%。
- **[规模效应释放]** -> [毛利率提升至72.68%]: 营收大幅增长摊薄固定成本，叠加产品结构优化，毛利率同比+8.78个百分点。
- **[研发投入持续高增]** -> [技术壁垒加固]: 研发费用同比+66.14%至1.46亿元，聚焦高集成度、硅基/氮化镓等前沿方向，新研制芯片300余款。
- **[客户高度集中]** -> [经营依赖性强]: 前五大客户销售额占比94.36%，其中第一大客户占比37.14%，业务稳定性与客户项目进度深度绑定。
- **[应收账款管理改善]** -> [资产质量优化]: 累计收回现款及票据3.36亿元，应收账款余额净增12,625万元，增幅远低于营收增幅（25.33% vs 91.28%）。
- **[经营活动现金流持续为负]** -> [资金周转压力]: 净利润1.17亿元，但经营性现金流净额为-4,736万元，主因下游客户付款周期长，回款滞后于收入确认。
- **[扭亏为盈并摘星]** -> [退市风险解除]: 2024年因净利润为负且营收低于3亿被*ST，2025年净利润1.17亿、营收4.05亿，已申请撤销退市风险警示。

## 风险警告
**现金流与回款风险是核心隐忧。** 公司净利润1.17亿元，但经营活动现金流净额连续两年为负（-4,736万元），主因下游军工/科研院所客户付款周期长。应收账款余额高达5.65亿元，占总资产34.57%，若客户采购计划延迟或财政拨款放缓，将严重挤压公司营运资金，甚至影响持续经营能力。

**客户与供应商双集中风险。** 前五大客户销售额占比94.36%，前五大供应商采购额占比85.45%，且存在关联采购（占比7.03%）。这种“两头在外”的格局使公司议价能力受限，一旦核心客户流失或关键晶圆供应商断供，业绩将遭受重大冲击。此外，公司产品主要应用于国防与卫星领域，订单受国家项目进度影响大，存在周期性波动风险。
