# 688313.SH 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [数通市场光芯片及器件营收暴增162%]: 公司AWG组件、MT-FA、FAU等产品直接受益于800G/1.6T光模块需求，境外收入增长300%。
- **[IDM全流程自主可控]** -> [产品良率与成本优势]: 覆盖芯片设计、晶圆制造、封装测试的全产业链模式，实现快速迭代与成本控制，毛利率提升6.7个百分点。
- **[“无源+有源”双芯片平台]** -> [客户粘性与产品组合壁垒]: 同时提供PLC/AWG无源芯片与DFB/EML有源芯片，满足光模块厂商一站式采购需求，前五大客户销售额占比55.8%。
- **[硅光与CPO技术前瞻布局]** -> [下一代增长极]: CWDFB激光器、高通道FAU产品已小批量出货，卡位硅光/CPO技术路线，为1.6T/3.2T时代储备动能。
- **[全球化产能与市场布局]** -> [对冲贸易风险与扩大份额]: 泰国子公司已实现营收1.95亿元，新加坡子公司设立优化全球供应链，海外收入占比升至52.7%。
- **[研发投入全部费用化]** -> [当期利润质量高]: 1.33亿元研发投入未资本化，表明利润增长主要来自主营业务规模效应，而非会计处理美化。

## 风险警告
**核心风险在于技术迭代与竞争加剧的“双杀”效应。** 光通信行业正从分立器件向硅光、CPO等集成化方案快速演进，公司若在高速EML芯片、硅光CW光源等前沿领域研发进度落后，现有AWG/DFB产品可能面临被替代风险。同时，国内光芯片行业新进入者增多，成熟产品（如PLC分路器）价格战压力持续，可能侵蚀毛利率。

**财务层面，经营现金流与净利润严重背离（净利润3.72亿 vs 经营现金流0.75亿），** 主要因营收翻倍增长导致应收账款和存货大幅增加。若下游客户资本开支放缓或进入库存调整周期，将面临坏账和存货跌价风险。此外，公司正推进重大资产重组，若整合不及预期，将消耗管理资源并带来商誉减值隐患。
