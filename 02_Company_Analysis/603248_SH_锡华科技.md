# 603248.SH 深度透视

## 因果逻辑链
- **[风电行业高景气度]** -> [营收增长32.28%]: 2025年“十四五”收官叠加2024年风电主机厂中标量暴增89.41%，下游需求旺盛直接拉动公司风电齿轮箱部件销售。
- **[大兆瓦产品结构优化]** -> [毛利率提升]: 风机大型化趋势下，公司大兆瓦产品收入占比提高，叠加机械加工深度提升，推动整体毛利率同比增加1.08个百分点。
- **[机械加工产能释放]** -> [净利润增长41.85%]: 公司扩充机械加工产能，前端铸造与后端加工协同效应显现，规模效应与降本增效共同推动利润增速超越营收增速。
- **[IPO募资9.26亿元]** -> [净资产增长96.20%]: 2025年12月首发上市，募集资金净额大幅增厚公司资本实力，为后续产能扩张提供资金保障。
- **[客户深度绑定]** -> [收入确定性高]: 与南高齿、弗兰德、采埃孚等全球龙头合作超十年，前五大客户收入占比88.42%，稳定的供应关系保障了订单的持续性与可预见性。
- **[全工序服务能力]** -> [客户粘性增强]: 国内少数可提供从毛坯铸造到成品加工全工序服务的企业，帮助客户精简供应链、降低成本，形成差异化竞争优势。
- **[原材料价格传导机制]** -> [成本风险部分对冲]: 当生铁、废钢等原材料价格波动达一定幅度时，公司与客户协商调价，一定程度上缓解了成本端压力。
- **[经营性现金流为负]** -> [扩张期资金压力]: 为提产增效储备人才及业务规模扩大导致税费增加，经营活动现金流净额同比下降112.95%，显示高速扩张对流动性的消耗。

## 风险警告
**客户与行业双重集中风险。** 公司超80%收入来自风电齿轮箱部件，前五大客户收入占比高达88.42%，业绩高度依赖南高齿、弗兰德等少数核心客户的风电装机节奏。若下游风电政策支持力度减弱或客户采购策略生变，将对公司营收造成剧烈冲击，单一客户流失即可能导致业绩大幅滑坡。

**现金流恶化与产能消化风险。** 2025年经营活动现金流由正转负至-8202万元，与净利润2.01亿元严重背离，主要系人员扩张与税费增加所致，反映高速扩张期对现金流的巨大消耗。同时，IPO募投项目（风电核心装备产业化项目）预计2027年投产，若未来风电装机增速放缓或大兆瓦技术路线发生偏移，新增产能存在无法及时消化的风险，将拖累资产回报率。
