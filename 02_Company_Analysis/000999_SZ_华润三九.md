# 000999.SZ 深度透视

## 因果逻辑链
- **[并购天士力]** -> [营收增长14.43%]: 天士力并表贡献处方药收入翻倍（+101.38%），但CHC业务因呼吸道疾病发病率降低而下滑14.67%，导致营收增利不增。
- **[“一体两翼”业务布局]** -> [净利润仅增1.58%]: 天士力并表带来营收规模扩张，但并购整合初期费用（销售费用+25.88%、研发费用+58.16%）及财务费用激增，侵蚀利润弹性。
- **[品牌壁垒与渠道掌控]** -> [CHC业务韧性]: 尽管行业零售端客流下降，999感冒灵连续12年蝉联品类第一，45个过亿品种支撑基本盘，线上B2C/O2O渠道增长29%提供结构性增量。
- **[研发投入资本化率提升]** -> [创新管线加速]: 研发投入17.34亿元（+81.9%），资本化率从15.87%升至27.07%，7个经典名方获批、203项在研项目，但资本化处理可能平滑未来利润波动。
- **[集采与价格治理]** -> [处方药毛利率提升11.3%]: 天士力高毛利创新中药并表拉高整体毛利率，但集采常态化对仿制药及中成药价格形成长期压制，需关注后续影响。
- **[中药注射剂再评价]** -> [存量业务风险]: 政策要求对已上市中药注射剂开展上市后研究和评价，公司参附注射液、华蟾素等品种面临说明书修订或暂停销售风险。
- **[并购整合“3-4-3”模式]** -> [协同效能释放]: 昆药集团（血塞通）与天士力（复方丹参滴丸）的整合路径清晰，但同业竞争承诺（5年内解决）及文化融合仍是关键变量。

## 风险警告
**1. 并购整合不及预期与商誉减值风险。** 天士力并表后总资产激增46.71%，商誉及无形资产规模显著扩大。尽管公司提出“3-4-3”整合模式，但天士力与华润三九在处方药与CHC业务的文化、渠道、管理体系差异巨大，若协同效应无法如期兑现，或面临商誉减值风险，直接冲击利润表。

**2. 政策与市场双重挤压下的盈利可持续性风险。** 药品价格治理、集采扩面及中药注射剂再评价政策持续深化，公司核心品种（如999感冒灵、参附注射液）面临价格下行压力。同时，CHC业务受呼吸道疾病发病率波动影响显著，2025年已现下滑，未来若缺乏新品接力，增长动能可能减弱。研发投入资本化率偏高（27.07%），若后续研发失败或商业化不及预期，将反向侵蚀利润。
