# 688802.SH 深度透视

## 因果逻辑链
- **[国产替代政策红利与地缘政治催化]** -> [营收爆发式增长121.26%]: 美国GPU出口管制加速国内智算中心自主可控采购，公司产品作为国产替代主力，出货量显著增长。
- **[持续高强度研发投入（占营收62.49%）]** -> [技术壁垒与产品迭代]: 5年内完成3颗主力芯片量产，自研MXMACA生态兼容CUDA，曦云C600实现全国产工艺，构建了“量产一代、在研一代、规划一代”的护城河。
- **[产品规模化落地与客户验证]** -> [亏损大幅收窄43.97%]: 累计销量超55,000颗，部署于10余个智算集群，规模效应摊薄固定成本，带动毛利率提升3个百分点。
- **[上市融资与股权激励]** -> [净资产暴增1017%]: 科创板IPO及前期融资大幅补充资本，但股份支付费用仍对利润构成较大压力。
- **[“1+6+X”生态与商业布局]** -> [市场地位巩固]: 覆盖教科研、金融、能源等六大行业及具身智能等前沿方向，构建了从芯片到集群的完整解决方案能力。
- **[DeepSeek等开源模型推动“算力平权”]** -> [推理算力需求爆发]: 杰文斯悖论下，训练成本降低反而刺激了推理和应用端对GPU的更大需求，公司推理产品线（曦思N系列）销量同比增长866%。

## 风险警告
**核心风险在于持续亏损与现金流压力。** 公司虽营收高速增长，但净利润仍亏损7.89亿元，且经营活动现金流净额为-12.6亿元。高额的研发投入（10.27亿）、战略备货导致的存货激增（14.96亿）以及大额预付款（8.34亿）持续消耗现金。若未来营收增速放缓或客户回款不及预期，公司可能面临营运资金周转困难，高度依赖外部融资输血。

**供应链安全是悬顶之剑。** 尽管曦云C600实现了全国产工艺，但公司在先进制程晶圆代工、HBM存储、EDA工具等核心环节仍受制于境外供应商。中美科技博弈升级可能导致供应链中断或成本急剧上升，对公司产品交付和竞争力构成实质性威胁。同时，公司对前五大供应商采购额占比高达82.34%，集中度风险显著。
