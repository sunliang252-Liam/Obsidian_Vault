# 603119.SH 深度透视

## 因果逻辑链
- **[新能源车热失控防护需求增长]** -> [新能源产品收入增长19.77%]: 全球及中国对动力电池安全法规趋严，推动公司核心云母绝缘件产品在新能源汽车领域渗透率提升。
- **[收购狄兹精密，切入精密结构件]** -> [新增精密结构件收入8967万元]: 通过外延并购快速进入机器人、智能装备零部件领域，构建第二增长曲线，实现业务多元化。
- **[交互式研发模式与头部客户深度绑定]** -> [客户粘性强，前五客户销售占比42.53%]: 公司融入客户供应链，共同开发定制化产品，形成稳固合作关系，降低客户流失风险。
- **[精益制造与信息化投入]** -> [毛利率维持34.15%]: 柔性化产线、智能揉单及全流程追溯系统提升生产效率，在原材料价格波动下有效控制成本。
- **[全球化产能与营销网络布局]** -> [外销收入占比42.02%]: 在泰国、墨西哥等地建设生产基地，并在欧美搭建本地化销售网络，提升全球供应与响应能力。
- **[H股上市筹备]** -> [拓宽融资渠道，优化资本结构]: 计划发行H股，募集资金用于产能提升、研发及战略收购，为长期增长储备资金。
- **[员工持股计划与持续分红]** -> [激励核心团队，提升股东回报]: 2025年实施员工持股计划，且连续三年分红比例超30%，绑定员工与股东利益。

## 风险警告
**核心风险在于第二增长曲线的兑现不确定性。** 公司通过收购狄兹精密切入机器人精密结构件领域，但该业务2025年贡献收入仅占6.5%，且业绩承诺首年（2025年）扣非净利润仅完成921万元，虽完成当年目标，但距离三年累计7000万元的承诺仍有巨大差距。若后续两年无法实现爆发式增长，将面临商誉减值风险（当前商誉已达1.49亿元），直接冲击利润表。

**另一重大风险是下游技术路线变革。** 公司核心业务高度依赖新能源汽车电池热失控防护方案。若未来固态电池、CTC/CTB等新技术大幅降低对云母绝缘材料的需求，或出现替代性材料（如气凝胶、陶瓷纤维），公司将面临市场份额萎缩和产品被替代的风险。此外，公司前五大客户集中度较高（42.53%），且与头部车企深度绑定，若主要客户切换供应商或自研替代方案，将对营收造成重大冲击。
