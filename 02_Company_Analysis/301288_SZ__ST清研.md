# 301288.SZ 深度透视

## 因果逻辑链
- **[“新合伙人”战略驱动的外延并购]** -> [营收暴增143.61%]: 通过收购通海镍业（固废资源化）和自贡正鼎（油气田废水），新增资源化产品业务，贡献41.85%营收，彻底改变收入结构。
- **[高毛利水处理业务被低毛利资源化业务稀释]** -> [综合毛利率骤降33.24%]: 资源化产品毛利率仅4.98%，远低于水处理业务，拉低整体盈利水平，导致营收翻倍但亏损扩大。
- **[并购整合与项目扩张]** -> [经营现金流持续为负且恶化]: 销售回款速度远低于因并购和项目投入导致的经营性现金支出，现金流缺口扩大至-4693万元，显示“纸面繁荣”。
- **[应收账款与资产减值激增]** -> [归母净利润亏损扩大22.23%]: 基于谨慎性原则计提大额资产减值（-2334万元），吞噬了并购带来的营收增量，是亏损扩大的直接原因。
- **[核心技术RPIR获国际金奖]** -> [巩固市政水处理技术壁垒]: 技术权威性提升，为存量市场提标改造和全球代理商招募提供核心竞争力背书。
- **[从市政向工业/固废/油气田转型]** -> [业务结构发生质变]: 公司从单一轻资产的水处理技术商，转变为重资产、多赛道的环保资源化综合服务商，风险与机遇并存。
- **[股权激励绑定核心团队]** -> [驱动未来业绩增长]: 设定2025-2027年营收和净利润考核目标，将管理层利益与公司战略转型成果深度绑定。

## 风险警告
公司正经历一场激进的战略转型，其核心风险在于**并购整合与现金流管理**。通过收购通海镍业和自贡正鼎，公司营收规模实现跨越式增长，但代价是毛利率断崖式下滑（从约50%降至18%）和经营现金流持续失血。新并购的固废资源化业务（通海镍业）毛利率极低（4.98%），且报告期内亏损，其盈利能力高度依赖镍价波动和原料供应稳定性。同时，公司应收账款和合同资产高企，叠加并购带来的管理复杂度，资产减值风险是未来利润的最大威胁。

另一个关键风险是**新赛道的竞争与运营风险**。公司从熟悉的市政水处理领域跨界进入固废资源化和油气田环保，这两个领域均属于资本密集、技术壁垒高、且由国企主导的市场。公司作为新进入者，能否在“国企主导、民企配套”的格局中站稳脚跟，并实现“废水+油泥”协同的盈利模式，存在巨大不确定性。此外，油气田业务涉及易燃易爆等安全生产风险，任何事故都可能对公司造成毁灭性打击。公司目前仍处于亏损状态，若新业务不能快速贡献利润，将面临持续的财务压力。
