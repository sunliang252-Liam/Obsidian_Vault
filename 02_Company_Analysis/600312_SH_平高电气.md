# 600312.SH 深度透视

## 因果逻辑链
- **[特高压工程密集落地]** -> [高压板块毛利率提升2.23个百分点]: 2025年特高压工程进入密集建设期，公司作为核心供应商交付1100kV GIS等高毛利产品，优化了产品结构，带动整体盈利水平提升。
- **[国家电网投资持续增长]** -> [营收微增0.93%至125.17亿元]: 2025年国网输变电设备集招金额同比增长约26%，公司中标合同规模持续增长，但收入确认节奏导致营收增速远低于招标增速。
- **[履行社会责任，缩短付款账期]** -> [经营现金流净额骤降73%至8.1亿元]: 为保障中小企业利益，公司主动缩短付款周期并提高现金支付比例，导致经营性现金流出大幅增加，严重侵蚀了现金流。
- **[国际业务项目推进不及预期]** -> [国际板块亏损，毛利率为-24.39%]: 受国际政治经济形势影响，存量项目成本超支，叠加汇率波动，导致国际工程子公司亏损1.94亿元，严重拖累整体业绩。
- **[研发投入持续加大]** -> [巩固技术领先优势]: 公司研发投入同比增长14.27%，成功研制国际首台800kV 80kA断路器等产品，为未来市场竞争构筑了技术壁垒。
- **[深化“两金”管控]** -> [应收账款净值同比压降1.93亿元]: 严格执行应收账款“136”清收机制，有效控制了信用风险，但效果被现金流恶化所抵消。
- **[新设子公司优化产业布局]** -> [巩固传统产业优势]: 成立平高智慧开关、平高智电，旨在将核心资源集中于优势业务，提升运营效率和盈利能力。

## 风险警告
**核心风险在于盈利质量与现金流的严重背离。** 公司2025年净利润同比增长9.45%，但经营活动现金流净额却暴跌73%。这种“纸面富贵”源于公司为响应政策而主动缩短供应商付款周期，导致现金大量流出。若该趋势延续，公司将面临营运资金紧张、财务灵活性下降的风险，高额分红（40%派息率）的可持续性存疑。

**国际业务与客户集中度构成双重脆弱性。** 国际工程子公司亏损近2亿元，暴露出公司在海外项目执行和风险管控上的短板。同时，公司超过64%的营收依赖国家电网，客户高度集中。一旦电网投资节奏放缓或招标规则变化，将对公司业绩产生巨大冲击。虽然“十五五”电网投资规划宏大，但转化为公司订单和利润的过程充满不确定性。
