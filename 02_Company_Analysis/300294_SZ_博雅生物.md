# 300294.SZ 深度透视

## 因果逻辑链
- **[格林克产品市场下行]** -> [巨额商誉及无形资产减值]: 格林克特许经销权及商誉减值3.08亿元，直接导致归母净利润暴跌71.61%。
- **[并购绿十字产生的评估增值摊销]** -> [利润持续承压]: 并购绿十字形成的无形资产评估增值在报告期内持续摊销，叠加商誉减值，严重侵蚀利润。
- **[血制品业务毛利率下降]** -> [核心主业盈利能力恶化]: 受集采、DRG/DIP改革、医保控费及市场竞争加剧影响，血制品毛利率同比下降11.48个百分点。
- **[采浆量创历史新高]** -> [原料供应基础稳固]: 全年采浆662.31吨（+5.03%），为未来产能释放和收入增长提供原料保障。
- **[10%静丙及破伤风免疫球蛋白获批上市]** -> [产品管线丰富与吨浆产值提升]: 新产品获批上市，优化产品结构，有望提升血浆综合利用率与盈利能力。
- **[智能工厂建设接近尾声]** -> [产能瓶颈即将突破]: 年处理1200吨血浆的智能工厂预计2026年6月建成，将打破现有产能天花板，支撑规模扩张。
- **[转让博雅欣和80%股权]** -> [聚焦主业，剥离亏损资产]: 剥离持续亏损的化学药业务，集中资源发展血液制品核心主业，优化资产结构。
- **[控股股东增持完成]** -> [彰显发展信心]: 华润医药控股完成增持计划，累计增持1.2%股份，体现控股股东对公司长期价值的认可。

## 风险警告
**核心风险在于业绩“失速”与资产“暴雷”的双重打击。** 2025年归母净利润同比暴跌71.61%，扣非净利润更是转为亏损，主因是格林克业务市场下行导致的3.08亿元商誉及无形资产减值。这暴露了公司并购整合与资产质量管理的脆弱性。血制品主业毛利率在集采、医保控费等政策压力下持续下滑，核心盈利能力正在恶化，而新获批的10%静丙等产品能否在激烈的市场竞争中快速放量并弥补毛利损失，存在巨大不确定性。

**第二重风险来自未来产能释放与市场消化能力的错配。** 智能工厂预计2026年建成，产能将大幅提升，但当前行业已出现白蛋白、静丙等产品供大于求的局面。若市场需求增长不及预期，或公司营销能力无法匹配产能扩张，新增产能将转化为高昂的折旧与固定成本，进一步拖累利润。此外，绿十字的商誉减值风险并未完全消除，若其经营状况未能持续改善，未来仍可能对业绩造成冲击。
