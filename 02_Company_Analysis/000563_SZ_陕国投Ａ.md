# 000563.SZ 深度透视

## 因果逻辑链
- **[信托业务结构优化]** -> [营收微增0.85%]: 资产管理信托（标品）规模与收益双增，弥补了传统融资类信托的收缩，但整体增长乏力。
- **[固有业务配置调整]** -> [投资收益提升]: 增加证券、资管产品投资比重，分散风险，提升了固有业务的投资收益贡献。
- **[发放贷款及垫款大幅增加]** -> [经营活动现金流净额转负]: 报告期发放贷款支出增加，导致经营活动现金流净额同比骤降147.55%，与净利润严重背离。
- **[启动不超过38亿元定增]** -> [资本实力预期增强]: 定增计划旨在补充资本金，为抢抓战略机遇、拓展业务提供资本支撑，但尚需监管审批。
- **[不良资产原值下降]** -> [信用风险边际改善]: 通过设立破产服务信托等方式处置风险项目，不良资产原值同比下降，但净值不良率仍处1.08%水平。
- **[信托管理规模增长8.01%]** -> [行业地位巩固]: 管理规模达6245.85亿元，稳居行业第一梯队，但规模增长并未有效转化为营收高增长。
- **[研发投入增加]** -> [数字化转型加速]: 研发人员数量翻倍，投入增加，旨在通过科技赋能提升运营效率和产品竞争力，但短期效果未显。

## 风险警告
**核心风险在于转型阵痛与盈利增长瓶颈。** 公司营收增速仅0.85%，远低于信托管理规模8.01%的增速，表明新业务（如标品信托、服务信托）的报酬率远低于传统融资类业务，盈利模式转换尚未成功。同时，经营活动现金流净额大幅转负，与净利润持续增长形成巨大反差，揭示了公司为维持规模增长而大量投放贷款，可能面临资产质量恶化和流动性压力。

**另一重大风险是定增的不确定性与市场风险。** 38亿元定增计划是公司未来发展的关键，但尚需深交所审核及证监会注册，存在审批不通过或发行失败的风险。此外，公司大量配置交易性金融资产和债权投资，市场波动（利率、股价）将直接冲击其公允价值变动损益和投资收益，在低利率和资本市场震荡环境下，业绩波动性显著增加。
