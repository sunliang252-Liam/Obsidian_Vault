# 600995.SH 深度透视

## 因果逻辑链
- **[来水超预期]** -> [调峰水电利润暴增]: 2025年流域来水极佳，调峰水电发电量同比+49.13%，推动该板块收入+42.23%，毛利率提升9.3个百分点，成为利润弹性最大来源。
- **[抽蓄新机组投产]** -> [抽蓄收入与利润双增]: 梅蓄二期、南宁抽蓄共240万千瓦投产，叠加梅蓄一期参与现货市场收入增加，抽蓄板块收入+9.31%，贡献核心增量。
- **[新型储能规模化]** -> [收入增长但盈利承压]: 云南丘北等储能项目投产，新型储能收入+28.65%，但成本增速（+29.02%）略高于收入，毛利率微降，仍处于规模扩张期。
- **[电价政策红利]** -> [抽蓄盈利模式稳定]: 依托633号文及现货市场，抽蓄电站获得稳定容量电费及市场化电量收益，上网电价同比大幅提升至448元/兆瓦时（+35%）。
- **[降本增效显效]** -> [成本费用率下降]: 公司将标准成本管理融入运检全过程，管理费用同比-9.13%，成本费用占收入比例下降5.22个百分点，直接增厚利润。
- **[市场化交易扩大]** -> [收入结构优化]: 新增1座抽蓄、1座新型储能电站入市交易，市场化交易总电量同比+472%，推动收入来源多元化，减少对单一计划电价的依赖。
- **[“科改”驱动创新]** -> [研发投入与成果转化]: 研发费用同比+45.51%，研发人员+54%，科技成果转化收入突破1.1亿元，为“第二增长曲线”提供技术储备。
- **[少数股东注资]** -> [资本结构优化]: 引入战投资金超19亿元，吸收投资现金同比+389%，有效支撑在建项目资本金需求，降低财务杠杆压力。

## 风险警告
**核心风险在于政策与来水的双重不确定性。** 2026年114号文对抽水蓄能和新型储能价格机制作出原则性调整，但具体落地细则尚未明确，若省级电价政策低于预期，将直接冲击公司核心业务的盈利模型。同时，2025年调峰水电的超高利润建立在罕见的丰水年基础上，来水回归均值将导致该板块利润大幅回落，业绩波动性极大。

**成长性面临资本开支与回报周期的错配压力。** 公司8座在建抽蓄电站（960万千瓦）及新型储能项目处于投资高峰期，2025年资本性支出达73.65亿元，资产负债率升至54.61%。巨额资本开支转化为折旧和财务费用，而新项目从投产到满发、盈利爬坡需要时间，短期内可能侵蚀报表利润。此外，公司96%收入依赖南方电网单一客户，关联交易集中度高，市场化议价空间有限。
