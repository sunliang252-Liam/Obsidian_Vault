# 000756.SZ 深度透视

## 因果逻辑链
- **[国家集采常态化导致制剂价格承压]** -> [制剂毛利率下降10.22个百分点]: 集采中标品种收入占比提升，但以价换量导致整体盈利空间被压缩。
- **[原料药及制剂出口竞争加剧]** -> [美洲/欧洲收入分别下降19.09%/10.72%]: 海外市场需求疲软及价格竞争，拖累传统出口业务表现。
- **[医药中间体及其他业务放量]** -> [该板块收入增长28.07%]: 依托产业链配套优势，中间体业务成为收入增长的主要驱动力。
- **[销售费用大幅压降]** -> [销售费用同比下降41.67%]: 集采常态化下，市场推广及终端销售费用随中标品种增加而自然减少。
- **[汇率波动导致汇兑收益减少]** -> [财务费用同比上升184.77%]: 人民币汇率波动直接侵蚀了公司的汇兑损益，增加了财务成本。
- **[部分产品主动降价以巩固市场份额]** -> [净利润同比下降38.32%]: 公司为应对激烈竞争，牺牲短期利润以维持和扩大市场占有率。
- **[研发投入持续高企]** -> [研发费用占营收4.34%]: 公司加速仿制药批件获取及创新药临床推进，研发支出维持高位，短期压制利润。
- **[加强应收账款及存货管理]** -> [经营活动现金流净额同比大增45.19%]: 营运效率提升，现金回收能力增强，现金流状况显著改善。

## 风险警告
**核心风险在于盈利能力持续恶化。** 公司2025年归母净利润同比暴跌38.32%，制剂毛利率骤降10.22个百分点，显示在集采和市场竞争的双重挤压下，核心业务的定价权和盈利空间正被系统性削弱。尽管收入微增3.41%，但“增收不增利”的困境加剧，若产品价格下行趋势延续，公司利润可能进一步探底。

**另一重大风险是海外市场的不确定性。** 美洲和欧洲两大传统出口市场收入分别下滑19.09%和10.72%，叠加汇率波动对财务费用的负面影响，公司国际化战略面临严峻挑战。欧美医药产业链的重塑趋势，可能长期压制公司原料药出口的量和价，而新兴市场的开拓尚需时日，短期难以弥补缺口。
