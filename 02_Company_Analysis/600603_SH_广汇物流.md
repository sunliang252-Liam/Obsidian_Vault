# 600603.SH 深度透视

## 因果逻辑链
- **[红淖铁路运量创历史新高]** -> [能源物流收入占比提升至82.69%]: 红淖铁路全年运量2,872万吨（+27%），叠加“将-淖-红”及“红淖-临哈”双通道贯通，推动能源物流主业规模扩张，收入占比同比提升13个百分点。
- **[房地产板块全面进入尾盘销售]** -> [营业收入同比下降27.53%]: 公司主动收缩房地产业务，商品房销售收入同比大降63.81%，导致整体营收从37.37亿降至27.08亿，但毛利率因低基数反而提升23个百分点。
- **[将淖铁路增资导致股权被动稀释]** -> [长期股权投资归零，产生非经常性损益]: 因将淖铁路增资，公司失去董事会席位，原长期股权投资转为交易性金融资产，贡献公允价值变动收益约6,058万元，成为利润的重要补充。
- **[红淖铁路电气化改造完成]** -> [运能提升与成本优化]: 电气化改造于2024年10月完成，2025年全年受益，铁路周转效率提升，为运量增长27%提供基础，同时降低单位运输成本。
- **[收购红淖铁路剩余股权支付现金]** -> [投资活动现金流大幅流出]: 支付收购红淖铁路股权款导致投资活动净现金流为-16.66亿元，同比多流出4.42亿元，但此举强化了对核心资产的控制权。
- **[新增融资增加]** -> [筹资活动现金流由负转正]: 筹资活动净现金流从-13.20亿元转为+3.59亿元，主要系新增借款增加，缓解了收购股权带来的资金压力，但推高了长期借款至33.16亿元。
- **[关联交易高度集中]** -> [经营独立性风险]: 前五大客户销售额占比72.79%，其中客户1（关联方广汇能源）占比48.80%；前五大供应商采购额占比63.21%，公司业务对关联方依赖度极高。

## 风险警告
**核心风险在于关联交易依赖与主业盈利质量下滑。** 公司近一半收入来自关联方广汇能源，前五大客户销售占比超70%，业务独立性存疑。同时，能源物流服务毛利率同比大幅下降12.87个百分点至32.44%，表明在运量增长的同时，盈利能力并未同步提升，可能存在价格让利或成本刚性上涨的压力。

**财务风险不容忽视。** 公司总负债135.68亿元，资产负债率63.45%，其中一年内到期的非流动负债16.32亿元，短期借款12.14亿元，而货币资金仅1.04亿元，短期偿债压力巨大。此外，公司连续三年未进行现金分红，且因信息披露违规曾被证监会立案处罚，公司治理与股东回报机制存在明显短板。
