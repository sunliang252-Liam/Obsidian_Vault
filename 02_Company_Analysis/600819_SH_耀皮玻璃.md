# 600819.SH 深度透视

## 因果逻辑链
- **浮法玻璃行业供需矛盾，库存高企，价格持续下行** -> 浮法玻璃板块收入同比下降8.45%: 直接原因：行业产能过剩、需求萎缩，导致量价齐跌
- **浮法玻璃板块优化产品结构，提升隐私玻璃、在线LOW-E汽车玻璃等高附加值产品占比** -> 浮法玻璃板块毛利率同比提升3.79个百分点: 直接原因：高附加值产品收入增长，同时原燃料采购价格下降，共同提升毛利率
- **原燃料采购价格下降** -> 浮法玻璃板块毛利率提升: 直接原因：成本端下降利好盈利
- **房地产竣工面积下滑，传统工程玻璃需求萎缩** -> 建筑加工玻璃板块收入同比下降12.37%: 直接原因：下游房地产需求疲软，竞争激烈，量价齐降
- **建筑加工玻璃板块贯彻差异化战略，提升三银玻璃、BIPV等差异化产品占比** -> 建筑加工玻璃板块毛利率同比提升0.10个百分点: 直接原因：高附加值产品占比提升，抵消收入下降影响，实现毛利率微增
- **新能源汽车产销高速增长，渗透率突破50%** -> 汽车加工玻璃板块收入同比增长23.99%: 直接原因：新能源汽车市场快速发展，带动汽车玻璃需求大幅增长
- **汽车玻璃板块优化产品结构，提升夹层前挡、夹层天窗等高附加值产品收入** -> 汽车加工玻璃板块毛利率同比提升0.16个百分点: 直接原因：高附加值产品收入增长，同时材料国产化及科学降本，抵消价格年降的不利因素
- **公司完成定向增发，融资近3亿元** -> 筹资活动现金流净额由负转正，为3.65亿元: 直接原因：定向增发募集资金增加筹资流入
- **公司持续加大在建工程投入（天津、大连等冷修技改项目）** -> 投资活动现金流净额为-7.13亿元，同比大幅流出: 直接原因：固定资产投资增加导致现金流出
- **主要原材料采购价格下降，成本管控见效** -> 主营业务毛利率同比提升1.09个百分点: 直接原因：成本端下降，叠加产品结构优化，提升整体毛利率

## 风险警告
公司面临浮法玻璃及建筑加工玻璃下游需求持续疲软的风险，尤其是房地产行业竣工面积下滑对建筑玻璃的拖累。同时，浮法玻璃产能过剩、库存高企导致价格低位运行，行业亏损面扩大。汽车玻璃虽受益于新能源增长，但2026年汽车消费有透支风险，增长可能放缓。此外，公司资本开支较大，投资活动现金流持续为负，若未来盈利不及预期，可能带来流动性压力。
