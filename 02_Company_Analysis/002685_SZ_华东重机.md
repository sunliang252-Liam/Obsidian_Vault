# 002685.SZ 深度透视

## 因果逻辑链
- **[全球港口智能化升级与船舶大型化]** -> [集装箱装卸设备需求爆发]: 港口竞相升级自动化设施以提升效率、争取大船挂靠，直接拉动公司岸桥、轨道吊等核心装备订单与出货量。
- **[公司聚焦主业、剥离亏损资产]** -> [扣非净利润扭亏为盈]: 2024年底剥离数控机床（润星科技），2025年中光伏子公司破产出表，业务重心回归高景气港机，实现扣非净利润57.8百万元。
- **[港机在手订单创历史新高]** -> [未来收入确定性增强]: 截至报告期末，公司在手订单充裕，尤其与PSA等国际巨头签订大额合同，为未来年度业绩提供坚实支撑。
- **[海外市场占有率持续提升]** -> [收入结构优化与毛利率改善]: 国外销售收入同比增长262%，占比升至78%，且海外业务毛利率（26.65%）高于国内，带动整体毛利率提升。
- **[光伏业务破产重整出表]** -> [消除重大亏损源与不确定性]: 光伏子公司因行业产能过剩陷入亏损，被申请破产重整后不再并表，上市公司卸下沉重包袱，财务风险显著降低。
- **[收购锐信图芯切入GPU芯片]** -> [培育第二增长曲线但短期承压]: 公司布局信创GPU芯片，但2025年业绩承诺未完成（亏损1570万元），且计提5000万元商誉减值，新业务尚处培育期。
- **[经营活动现金流净额为负]** -> [订单增长带来的资金占用压力]: 为履行创历史新高的在手订单，公司大量支付供应商货款，导致经营活动现金流净额为-56.8百万元，与净利润背离。

## 风险警告
**核心主业客户集中度极高，单一客户依赖风险突出。** 公司前五大客户销售额占比高达92.09%，其中第一大客户（PSA集团）贡献了72.34%的收入。这种高度集中的客户结构意味着，一旦主要客户减少采购、延迟项目验收或转向竞争对手，将对公司经营产生毁灭性打击。尽管公司凭借技术优势维持了深度合作，但议价能力和业务稳定性均存在隐患。

**新业务（GPU芯片）培育不及预期，商誉减值风险高悬。** 子公司锐信图芯2025年业绩承诺完成率仅为-74.8%，已计提5000万元商誉减值。国产GPU市场竞争激烈，信创市场拓展存在不确定性，若未来两年业绩持续不达预期，剩余商誉（约1.39亿元）面临进一步减值风险，将直接侵蚀公司利润。

**光伏业务重整结果尚不明朗，上市公司作为重要债权人的回收存在不确定性。** 虽然光伏子公司已出表，但上市公司是其重要债权人之一（关联债权约4.08亿元）。重整计划能否顺利通过并执行，债权回收比例如何，均存在重大不确定性，可能对公司未来财务状况产生潜在负面影响。
