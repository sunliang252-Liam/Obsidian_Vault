# 301408.SZ 深度透视

## 因果逻辑链
- **[“四位一体”全产业链生态]** -> **营收与利润双增**: 医药零售、营销、集采、研发四大板块协同，2025年营收54.87亿元(+21.07%)，归母净利润1.91亿元(+38.96%)，扣非净利润1.85亿元(+43.67%)。
- **[门店网络扩张与并购整合]** -> **零售收入增长22.50%**: 门店从1,774家增至2,296家，通过并购切入浙江、福建市场，线下收入38.57亿元，新零售收入7.68亿元。
- **[自有品牌与产品矩阵]** -> **毛利率提升与差异化竞争**: 依托神华药业与正药科技，构建“正远”“克安舒”等自有品牌，降低外部采购依赖，提升终端毛利率。
- **[AI数智化深度应用]** -> **运营效率与会员粘性提升**: 自主研发锐思AI大模型，智能补货降低缺货率，会员超1,300万（净增300万），人效、坪效优化。
- **[终端集采平台转型]** -> **下沉市场渗透与增长新引擎**: 全方药业从区域集采商转型全国性赋能平台，省级锐盟模式在河北、山东验证，B2B平台支撑全国化。
- **[研发管线推进与成果转化]** -> **长期增长蓄能**: 45个在研项目，硫酸氨基葡萄糖胶囊获批，5个产品处于审评阶段，研发投入3,278万元，构筑产品壁垒。
- **[经营活动现金流大幅改善]** -> **盈利质量提升**: 经营活动现金流净额8.37亿元(+46.42%)，远超净利润，反映回款能力增强与供应链效率优化。

## 风险警告
**商誉减值风险高企。** 截至2025年末，公司商誉高达12.82亿元，占总资产23.37%，主要系近年频繁并购（福建扬祖、海华医药、杭州国胜等）形成。报告期内资产减值损失达7,974万元，若被并购标的未来业绩不达预期，将面临大规模商誉减值风险，直接冲击利润表。

**行业政策与竞争加剧双重挤压。** 药品集采常态化持续压缩普药利润空间，全国药店数量已现拐点（同比减少3.1%），行业进入存量博弈。公司虽通过自有品牌与专业服务应对，但若门诊统筹、医保监管等政策调整导致客流与品类结构变化，或区域竞争加剧导致门店盈利周期延长，将影响整体毛利率与扩张节奏。
