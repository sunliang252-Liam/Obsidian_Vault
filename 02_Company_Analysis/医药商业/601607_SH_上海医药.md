# 601607.SH 深度透视

## 因果逻辑链
- **[收购上海和黄药业并表]** -> [归母净利润同比+25.74%]: 收购和黄药业10%股权后，对原持有的50%股权按公允价值重新计量，产生约31.9亿元的非经常性投资收益，是利润暴增的核心来源。
- **[创新药获批上市]** -> [工业板块长期增长潜力]: 1类新药苹果酸司妥吉仑片获批，为超3亿高血压患者提供新方案，标志着公司创新转型取得标志性成果，有望打开工业收入天花板。
- **[中药板块高增长]** -> [工业收入结构优化]: 中药板块收入同比+15.97%至111亿元，麝香保心丸等大品种循证医学成果显著，成为工业增长的核心驱动力。
- **[商业CSO业务突破百亿]** -> [商业板块盈利改善]: 商业CSO业务规模突破百亿，叠加创新药全生命周期服务（销售537亿元），推动商业从纯分销向高附加值服务转型，提升利润率。
- **[工业降本增效]** -> [对冲集采降价压力]: 实施“六大降本举措”，推动156个精益项目，降本超4000万元，同时中药材联合采购成本下降约8%，在集采降价背景下维持工业毛利率。
- **[扣非净利润下滑]** -> [真实盈利能力承压]: 扣非归母净利润同比-26.68%，剔除并表一次性收益后，核心业务利润同比下降5.56%，显示工业与商业主业面临增长瓶颈。
- **[云南白药战略投资解禁]** -> [股权结构稳定风险]: 云南白药持有的6.66亿股（占比17.95%）于2025年4月解禁，虽未减持，但大规模解禁对股价构成潜在压制。

## 风险警告
**核心风险在于利润质量与增长可持续性。** 2025年归母净利润57.25亿元看似亮眼，但扣除收购和黄药业产生的31.9亿元非经常性收益后，核心业务利润同比下降5.56%。扣非净利润仅29.8亿元，同比大降26.68%，表明公司医药工业和商业的主营业务盈利能力正在恶化，而非改善。工业板块中，抗肿瘤和免疫调节剂收入因集采丢标暴跌48.68%，全身性抗感染收入下降40.10%，显示核心产品正面临严峻的竞争与降价压力。

**另一重大风险是资产减值与现金流压力。** 报告期内资产减值损失同比暴增65.79%，信用减值损失同比暴增154.11%，合计超过15.9亿元，侵蚀了大量利润。同时，投资活动现金流净流出39.82亿元（去年同期为净流入4.16亿元），筹资活动现金流净流出56.52亿元，公司正通过大量金融资产投资和偿还债务消耗现金，财务弹性正在收紧。此外，商誉减值风险持续存在，若未来被并购标的业绩不及预期，将面临进一步的减值冲击。
