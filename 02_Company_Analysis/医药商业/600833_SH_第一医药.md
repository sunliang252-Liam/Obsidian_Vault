# 600833.SH 深度透视

## 因果逻辑链
- **[动迁补偿款大幅减少]** -> [归母净利润暴跌64.59%]: 2025年资产处置收益仅5018万元，较2024年的1.69亿元骤降70%，导致净利润从1.63亿断崖式回落至5775万。
- **[实体药店市场持续萎缩]** -> [零售业务增长承压]: 全国药店零售市场规模同比下降2.1%，公司零售收入仅增长8.43%，增速远低于批发业务，且毛利率微降0.41个百分点。
- **[线上业务高速增长]** -> [对冲线下客流下滑]: 线上板块（不含跨境）销售额4.1亿元，同比增长28.2%，O2O业务增长35%，成为零售端核心增量来源。
- **[批发业务转型见效]** -> [批发收入增长15.56%]: 深海医药SPD、医疗器械直配、中药代煎等新业务同比增长125%，驱动批发板块收入突破8亿元。
- **[医保门店覆盖率提升]** -> [提升客流与合规门槛]: 医保门店净增27家，覆盖率近71%，受益于门诊统筹政策，但同时也面临医保价格治理和追溯码采集带来的运营压力。
- **[自有品牌与跨境业务发力]** -> [提升毛利率与收入]: 自有品牌销售额同比增长39%，一医香港跨境销售2.3亿元，同比增长27.8%，成为利润新增长点。
- **[扣非净利润微增]** -> [主业盈利能力基本稳定]: 剔除动迁补偿等非经常性损益后，扣非净利润714.5万元，同比增长3.94%，表明核心经营业务并未恶化。

## 风险警告
**核心风险在于业绩对非经常性损益的极度依赖与主业增长乏力之间的矛盾。** 2025年归母净利润的暴跌并非主业恶化，而是动迁补偿这一“一次性收益”的退潮。扣非净利润仅714万元，对应2.13亿营收，净利率不足0.4%，显示公司核心盈利能力极其薄弱。未来若无新的资产处置或大额政府补助，公司盈利将面临巨大压力。

**行业竞争与政策风险持续加剧。** 全国药店数量连续四个季度负增长，行业进入存量淘汰赛。医保价格治理（“上网店，查药价”）、追溯码强制采集、门诊统筹控费等政策，将持续压缩药品流通环节的利润空间。公司作为区域性老牌药企，面对国大药房、益丰等全国性连锁及京东健康等互联网巨头的竞争，市场份额和议价能力均面临挑战。线上业务虽增长迅速，但毛利率通常低于线下，且需持续投入流量成本，能否成为可持续的利润引擎尚待观察。
