# 603883.SH 深度透视

## 因果逻辑链
- **[行业出清加速，头部集中]** -> [营收持平，利润下滑]: 2025年全国药店净减少2.2万家，中小药店加速退出，但公司营收仅微降0.54%，归母净利润却因计提商誉及土地减值2.38亿元而大降26.44%，显示行业阵痛期利润端承压。
- **[医保个账改革与门诊统筹]** -> [低毛利板块占比提升，毛利率下降]: DTP新特药及线上零售销售增长较快，导致低毛利板块占比增加，综合毛利率同比下降0.87个百分点至32.30%。
- **[门店网络广而深，下沉市场渗透]** -> [加盟业务逆势增长]: 公司门店总数达14,975家，覆盖18省，地级市及以下门店占比78%。2025年新增门店875家中，加盟店占791家，加盟配送销售额同比增长6%。
- **[线上渠道高增长]** -> [新零售业务成为增长引擎]: 线上渠道销售总额突破31.2亿元，同比增长26.3%，O2O外卖服务门店达12,352家，私域小程序用户超3000万，有效对冲线下客流下滑。
- **[商采改革与库存管控]** -> [经营现金流大幅改善]: 通过统采占比提升至75.9%、智能请货等精细化管理，商品存货周转天数降至88天（同比-6天），经营性现金流净额达31.4亿元，同比增长55.08%。
- **[商誉减值风险释放]** -> [核心利润降幅收窄]: 剔除商誉和土地减值影响后，归母净利润同比下降仅1.0%，且经营质量逐季提升（Q3归母净利润同比转正），显示主营业务韧性。
- **[高比例现金分红]** -> [股东回报意愿强烈]: 2025年度拟现金分红合计3.11亿元，占归母净利润比例高达81.48%，远超50%的承诺下限，彰显公司回馈股东的决心。

## 风险警告
**核心风险在于商誉减值与并购整合的不确定性。** 公司历史上通过大量并购实现扩张，截至2025年末账面商誉规模依然庞大。2025年已计提1.5亿元商誉减值及0.88亿元土地减值，直接导致归母净利润暴跌26.44%。若未来并购标的经营持续不达预期，或行业政策变化导致盈利恶化，公司将面临持续的减值压力，严重侵蚀利润。

**另一重大风险是行业政策与竞争格局的剧烈变化。** 医保个账改革、门诊统筹政策虽长期利好，但短期导致客流从药店回流医院，叠加线上平台（O2O/B2C）的激烈价格战，公司线下门店坪效承压。2025年公司直营门店净减少249家，且整体毛利率下滑，表明存量竞争异常残酷。若公司无法有效提升门店专业服务能力与差异化商品竞争力，市场份额可能被蚕食。
