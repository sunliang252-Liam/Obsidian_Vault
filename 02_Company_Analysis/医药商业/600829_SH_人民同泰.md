# 600829.SH 深度透视

## 因果逻辑链
- **[集采政策持续深化]** -> [毛利率下降]: 带量采购常态化压缩药品购销差价，批发业务毛利率下降0.60个百分点，零售业务毛利率下降0.84个百分点。
- **[DTP业务与处方外流承接]** -> [零售收入增长21.04%]: 公司积极布局DTP专业药房和院边店，承接处方外流，驱动零售板块收入同比增加3.56亿元。
- **[应收账款坏账准备增加]** -> [净利润下降37.24%]: 依据应收账款账龄变化，计提信用减值损失5,971万元，同比大幅增加，直接侵蚀利润。
- **[批发业务强化回款考核]** -> [经营性现金流净额大增159.86%]: 公司加强催收力度，销售回款增加，叠加零售业务现款结算占比高，现金流显著改善。
- **[零售业务销售结构变化]** -> [零售毛利率下降]: DTP品种（低毛利）销售占比提升，拉低零售业务综合毛利率0.84个百分点。
- **[银行存款利率降低]** -> [财务费用增加13.88%]: 利息收入减少，导致财务费用同比增加363万元。
- **[新零售与电商业务发展]** -> [销售费用增加7.06%]: 线上线下融合及常态化直播等新零售模式，导致电商平台手续费及人员薪酬增加。

## 风险警告
**核心风险：政策压缩与利润侵蚀。** 公司作为区域性医药流通龙头，深度依赖黑龙江省内市场，受国家药品集中带量采购政策冲击显著。报告期内，批发与零售业务毛利率双双下滑，叠加信用减值损失大幅增加，导致净利润暴跌37.24%，盈利能力持续承压。若集采政策进一步扩围或医保控费趋严，公司毛利空间可能被进一步压缩，利润增长面临严峻挑战。

**财务风险：应收账款与资金压力。** 医药流通行业资金密集，公司应收账款余额高达38.54亿元，占总资产53.7%。尽管报告期现金流改善，但信用减值损失激增表明回款风险正在暴露。若下游医疗机构回款周期继续延长或出现坏账，将对公司现金流和经营稳定性构成重大威胁。公司2025年未进行现金分红，也侧面反映了资金需求压力。
