# 603233.SH 深度透视

## 因果逻辑链
- **[战略转型：从全国扩张到省内加密]** -> [盈利能力显著提升]: 公司停止进入新省份，聚焦已覆盖省份的门店加密和精细化运营，避免了新并购标的低毛利拉低整体盈利，叠加整合完成后的规模效应释放，推动净利率同比提升1.24个百分点。
- **[精细化管理与数字化降本]** -> [费用率下降，利润弹性释放]: 通过自研POS系统、AI智能补货、数字化促销模型等工具，在收入仅增长3.8%的情况下，销售费用和管理费用分别同比下降2.81%和2.9%，驱动归母净利润同比增长35.04%。
- **[行业出清与合规趋严]** -> [头部集中度加速提升]: 药品追溯码全面落地、医保飞行检查常态化，导致大量不合规的中小连锁及单体药店关闭（2025年净关店21,925家），为具备合规优势和管理能力的头部企业创造了抢占市场份额的窗口期。
- **[处方外流与医保资质布局]** -> [院外市场增长确定性]: 公司积极对接处方流转平台，加密“双通道”及门诊统筹定点门店（统筹定点3,429家），承接公立医院流出的处方药需求，零售药店终端药品销售额同比增长2.4%，成为三大终端中唯一正增长渠道。
- **[自有品牌与供应链整合]** -> [零售业务毛利率提升0.34个百分点]: 公司通过扩大自有品牌销售占比、优化采购谈判（仓仓比价模型）、精简低效SKU等措施，在零售收入仅增长2.05%的情况下，实现毛利率逆势提升，增厚了利润空间。
- **[直营式加盟模式]** -> [规模快速扩张与品牌下沉]: 公司首创“七统一”直营式加盟，在弱势区域快速吸纳中小连锁翻牌加盟（净增1,240家），加盟及分销业务收入同比增长13.58%，既贡献了利润，又反哺了直营业务的规模优势。

## 风险警告
**核心风险在于行业政策与监管的持续高压。** 药品追溯码全链条监管已于2026年1月1日全面落地，医保基金监管的“飞行检查”已成常态。公司虽为头部企业，合规成本较高，但若任何一家加盟门店出现违规操作（如串换药品、回流药），将对“大参林”品牌造成严重冲击，并可能面临医保暂停结算等实质性处罚。此外，公司实际控制人之一柯金龙所持股份仍有较高比例质押（29,600,000股），需关注其个人层面的财务风险是否会对公司控制权稳定性产生潜在影响。

**另一风险来自宏观经济对可选消费的压制。** 公司中参药材及非药品（保健品、器械等）收入在2025年分别同比下降9.08%和3.13%，尽管毛利率有所提升，但收入端的下滑反映出居民消费力疲软对非刚性需求的抑制。若宏观经济复苏不及预期，公司通过“非药调改”门店、拓展药妆等高毛利品类的战略将面临阻力，可能拖累整体营收增速和坪效提升。
