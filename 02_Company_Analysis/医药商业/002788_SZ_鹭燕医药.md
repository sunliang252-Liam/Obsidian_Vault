# 002788.SZ 深度透视

## 因果逻辑链
- **[集采扩围与医保控费]** -> [净利润下降18.74%]: 药品/耗材带量采购常态化导致价格承压，叠加DRG/DIP支付改革倒逼医院控费，公司批发业务毛利率被压缩，利润增速显著低于收入增速。
- **[应收账款高企与资金占用]** -> [财务费用高企]: 主要客户为公立医院，账期长且回款慢，应收账款占总资产47.5%，导致公司需大量举债维持运营，财务费用达1.84亿元，侵蚀利润。
- **[零售业务快速扩张]** -> [收入增长但成本高企]: 零售收入同比增27.14%，但营业成本同步增31.54%，毛利率承压，反映新店扩张期投入大、盈利爬坡慢。
- **[中药饮片业务下滑]** -> [拖累整体利润]: 中药饮片收入同比降8.88%，成本降13.33%，受全国联采及竞争加剧影响，该板块未能成为利润增长点。
- **[经营现金流改善]** -> [应收账款管理加强]: 经营活动现金流净额同比增19.21%至6.88亿元，主因公司加强回款管理，但净利润与现金流背离，显示利润质量仍存隐忧。
- **[收购前遗留担保诉讼]** -> [潜在巨额损失风险]: 子公司成都禾创因收购前原股东隐瞒的对外担保事项被追索，涉案金额超2亿元，虽在推进抵押物变现，但若无法全额追偿，将直接冲击利润。

## 风险警告
**核心风险：利润持续承压与隐性债务炸弹。** 公司净利润已连续两年下滑（2024年降5%，2025年降18.7%），集采常态化下批发业务毛利率仅6%，盈利空间极度狭窄。更致命的是，子公司成都禾创因收购前原股东恶意隐瞒的2.18亿元担保诉讼仍在执行中，虽已推动抵押物拍卖，但最终损失金额不确定，一旦无法足额追偿，将直接吞噬当年利润。

**流动性风险：高杠杆运营下的脆弱平衡。** 公司资产负债率高达75.3%，短期借款40.88亿元，而货币资金仅6.17亿元（含受限资金2.72亿元），自由现金流极度紧张。应收账款占资产近半，若医保直接结算推进不及预期或医院回款进一步延迟，公司可能面临流动性危机。此外，对外担保余额占净资产比例高达139.5%，风险敞口巨大。
