# 000951.SZ 深度透视

## 因果逻辑链
- **[国四及以下老旧营运货车以旧换新补贴政策]** -> [重卡销量同比增长30.77%]: 政策直接刺激了存量更新需求，带动公司整车销量大幅提升。
- **[海外基础设施建设提速与大宗商品需求旺盛]** -> [出口持续强劲]: 海外市场需求稳步上升，公司连续二十一年位居国内重卡行业出口首位，有效对冲了国内竞争压力。
- **[新能源重卡销量同比大涨192%]** -> [公司新能源业务提速发展]: 行业电动化转型加速，公司优化新能源销售架构，实现新能源销量和市场占有率快速增长，贡献收入约81亿元。
- **[配件销售同比增长46.20%]** -> [收入结构优化]: 配件业务增速远超整车（24.14%），且毛利率更高（10.89% vs 6.73%），成为利润增长的重要补充。
- **[以票据方式回款增加]** -> [经营活动现金流净额同比大幅下降89.34%]: 尽管净利润增长，但回款方式变化导致现金流入滞后，经营现金流与净利润严重背离。
- **[理财等投资支出增加]** -> [投资活动现金流净额大幅流出]: 公司利用闲置资金进行理财投资，导致投资活动现金净流出同比扩大114.28%。
- **[关联交易占比极高]** -> [经营独立性风险]: 向最终控股公司山东重工的销售占营收55.46%，采购占47.59%，公司深度嵌入集团内部供应链，议价能力与经营自主性受限。

## 风险警告
**1. 经营现金流与利润严重背离，盈利质量堪忧。** 2025年归母净利润增长12.58%，但经营活动现金流净额却暴跌89.34%至5.63亿元，主因是以票据方式回款增加。这意味着公司账面利润并未转化为真实现金，应收账款和应收款项融资合计从年初的11.98亿元飙升至20.26亿元，大幅侵蚀了现金回收能力。若下游客户或关联方付款周期进一步拉长，公司可能面临流动性压力。

**2. 高度依赖关联交易与政策驱动，内生增长动力存疑。** 公司超55%的销售和近48%的采购均来自最终控股股东山东重工及其关联方，这种“左手倒右手”的商业模式使其盈利的真实性和可持续性难以独立验证。同时，2025年的高增长高度依赖“以旧换新”补贴政策，该政策具有时效性，一旦退出或力度减弱，销量增速可能迅速回落。此外，实际控制人山东重工关于解决同业竞争的承诺仍在履行中，潜在的内部利益冲突是长期隐患。
