# 300433.SZ 深度透视

## 因果逻辑链
- **AI智能终端（手机/电脑）结构升级** -> **营收稳健增长**: 产品向高端折叠屏UTG、钛金属中框等高价值量产品聚集，推动智能手机与电脑类业务营收同比增长5.94%，毛利率提升0.3个百分点。
- **具身智能业务规模化量产** -> **新增长极确立**: 人形机器人和四足机器狗全年出货量过万台，蓝思智能营收超10亿元，成功切入全球头部客户供应链，成为全球最大具身智能硬件制造平台之一。
- **AI服务器全链条布局** -> **切入顶级算力供应链**: 通过战略并购与自研，构建“结构件+液冷散热+SSD存储”产品矩阵，SSD固态硬盘已批量出货，为切入全球顶级AI算力硬件供应链奠定基础。
- **A+H双资本平台搭建** -> **全球化与新兴赛道资本赋能**: 港股IPO募资54亿港元，为全球化产能布局（泰国、越南、墨西哥）及具身智能、AI服务器等新兴赛道扩张提供强劲资本动能。
- **智能制造与精益管理深化** -> **运营效率提升**: 事业部制改革与数字化流程优化，使管理费用率同比下降0.16个百分点，销售费用率下降0.22个百分点，有效对冲了原材料及汇率波动压力。
- **客户高度集中与深度绑定** -> **业绩基石稳固但风险集中**: 前五大客户销售额占比高达81.64%，其中第一大客户占比45.01%，深度绑定全球头部品牌，保障订单稳定，但也带来单一客户依赖风险。
- **新兴赛道研发高强度投入** -> **技术壁垒构建**: 研发费用达28.71亿元，同比增长3.08%，重点投向航天级UTG、TGV玻璃基板、光波导镜片等前沿领域，为未来3-5年增长储备核心技术。

## 风险警告
**核心风险在于客户与业务的双重集中。** 前五大客户贡献超81%营收，且第一大客户占比近半，任何主要客户的产品迭代放缓、供应链策略调整或终端需求波动，都将直接冲击公司业绩基本盘。同时，公司正全力押注具身智能、AI服务器、商业航天三大新兴赛道，这些领域技术迭代极快、商业模式尚未成熟，前期巨额资本开支与研发投入存在回报不及预期的风险。

**汇率与宏观经济的双重夹击不容忽视。** 公司超55%收入来自海外并以美元结算，人民币汇率大幅波动将显著影响利润。此外，下游消费电子与智能汽车市场受宏观经济和消费者偏好影响大，存储芯片等关键组件价格快速上涨已对2026年市场整体需求构成压力，可能抑制中低端产品需求，进而传导至公司订单。
