# 600765.SH 深度透视

## 因果逻辑链
- **[支付结算方式改变]** -> [经营现金流大幅恶化]: 为响应政策提前兑付未到期票据，导致经营活动现金净流出11.67亿元，同比恶化超10亿元。
- **[美元汇率波动]** -> [财务费用激增]: 汇兑损失导致财务费用同比飙升103.89%，从3.36亿增至6.86亿，严重侵蚀利润。
- **[“两金”占比持续攀高]** -> [信用减值损失扩大]: 应收账款与存货高企，导致信用减值损失达1.1亿元，成为扣非净利润下降13.72%的主因之一。
- **[重点型号市场份额提升]** -> [核心业务韧性]: 飞机/发动机锻铸件市场份额提升5个百分点，批产交付量增长15%，对冲了整体营收下滑压力。
- **[商用航空与国际化突破]** -> [新增长极形成]: C919锻件配套占比提升、国际转包收入增长13%，商用业务收入11.67亿元，新增订单13.7亿元。
- **[大国防领域扩张]** -> [业务结构优化]: 航天订单同比增长112%，船舶订单增长62.5%，成功将航空锻造能力跨行业迁移，降低单一市场依赖。
- **[成本管控与材料再生]** -> [毛利率改善]: 供应链成本压降8.1%，钛合金循环料再生技术突破，推动锻铸业务毛利率同比提升5.73个百分点。
- **[募投项目产能释放滞后]** -> [短期业绩承压]: 航空精密模锻项目仍处试运行，特种材料等温锻造项目建设周期递延，新增产能尚未贡献利润。

## 风险警告
**现金流断裂风险是当前最紧迫的威胁。** 公司经营现金流净流出11.67亿元，与净利润严重背离，主要因提前兑付票据和“两金”高企。若这一趋势持续，将迫使公司增加有息负债（短期借款已增长53%），进一步推高财务费用，形成恶性循环。投资者需密切关注2026年现金流能否转正，这是判断公司经营质量的关键分水岭。

**成长性面临“青黄不接”的尴尬期。** 传统重点型号业务受制于主机厂降价压力，利润空间持续压缩；而寄予厚望的商用航空、大国防等新业务尚处放量初期，体量不足以弥补传统业务缺口。同时，多个大型募投项目（如特种材料等温锻造）建设周期延长，产能释放存在不确定性，导致公司短期内缺乏明确的业绩增长催化剂。
