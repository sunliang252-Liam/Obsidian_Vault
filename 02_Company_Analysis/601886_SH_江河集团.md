# 601886.SH 深度透视

## 因果逻辑链
- **[海外订单爆发式增长]** -> [扣非净利润逆势增长42%]: 海外订单同比增长84%，高毛利海外项目逐步转化，抵消了国内业务下滑和信用减值损失增加的影响。
- **[“现金为王”战略]** -> [经营现金流持续强劲]: 严控垫资、狠抓回款，2025年收现比达104.45%，每股经营净现金流1.36元，远高于每股收益0.54元，财务根基稳健。
- **[高分红承诺]** -> [股东回报确定性增强]: 发布三年股东回报规划，承诺每年分红不低于归母净利润80%或每股0.45元孰高者，2024/2025年平均分红比例达93%，吸引长期价值投资者。
- **[平台化模式出海]** -> [打开全球市场新边界]: 从“EPC工程”转向“设计+产品供应”平台化模式，幕墙产品供货订单同比增长897%，BIPV异型组件启动全球销售，突破传统工程模式增长天花板。
- **[行业马太效应]** -> [龙头地位持续巩固]: 行业出清加速，公司新增订单总量蝉联行业榜首，中标全球最高楼吉达塔，品牌壁垒与资源虹吸效应强化。
- **[在手订单结构优化]** -> [未来盈利弹性可期]: 在手订单376亿元，海外占比41%且毛利率更高，随着订单逐步转化为产值，将驱动整体盈利水平提升。
- **[组织变革与成本革命]** -> [运营效率提升]: 推进“颠覆式成本革命”与组织重构，管理费用同比下降5.01%，建筑装饰毛利率提升1.27个百分点，经营质量改善。

## 风险警告
**核心风险在于信用减值与资产减值的持续侵蚀。** 2025年信用减值损失高达3.89亿元，资产减值损失2.09亿元，合计近6亿元，是吞噬利润的最大黑洞。这反映出建筑装饰行业下游客户（尤其是地产相关）回款困难、项目纠纷频发的现实。尽管公司经营现金流强劲，但大量利润被坏账计提所抵消，若宏观经济持续低迷，减值压力可能进一步加大，导致“纸面富贵”。

**海外扩张的“双刃剑”效应不容忽视。** 海外订单虽高增长且毛利更优，但公司业务已深入中东、东南亚等政治经济波动较大的区域，面临地缘政治、汇率波动（2025年财务费用因汇兑损失大增76%）及跨国法律诉讼等复杂风险。同时，海外业务从订单到产值转化存在时间差，若管理能力跟不上扩张速度，可能导致项目亏损或现金流压力。此外，公司担保总额占净资产比例高达195%，财务杠杆风险需警惕。
