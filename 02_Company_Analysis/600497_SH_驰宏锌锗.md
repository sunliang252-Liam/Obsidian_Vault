# 600497.SH 深度透视

## 因果逻辑链
- **[锌加工费回升]** -> [冶炼利润改善]: 2025年国产锌精矿加工费同比上涨21.12%，直接提升冶炼环节盈利能力，驱动锌产品产量同比增长8.16%。
- **[高品位矿山成本优势]** -> [盈利韧性]: 会泽、彝良两座世界级高品位矿山（品位27%/20%）使铅锌精矿完全成本远低于行业均值，在铅锌价格下行周期中仍保持盈利。
- **[矿冶一体化布局]** -> [抗周期能力]: 每座冶炼基地配备1-2座自有矿山，原料自给率稳定，有效对冲外购原料成本波动风险，保障生产连续性。
- **[乌蒙矿业风险勘探突破]** -> [低成本资源增储]: 首创“央地共赢”模式，以行业新低的直接成本探获铅锌金属232.02万吨，显著增强资源储备。
- **[锗产业股权重组]** -> [聚焦核心主业]: 将驰宏锗业100%股权注入中铝乾星（持股20%），剥离非核心冶炼资产，集中资源发展铅锌主业并分享下游高附加值收益。
- **[注销式股份回购]** -> [股东回报增厚]: 以2.68亿元回购注销5091万股，叠加高比例现金分红（74.54%），提升每股收益与股东价值。
- **[冶炼技术突破]** -> [综合回收率提升]: 烟化炉全冷料富氧分段吹炼等技术使锌、锗、银回收率创历史最优，增加副产品收益贡献。

## 风险警告
**核心风险在于利润对加工费的过度依赖与资产减值压力。** 2025年净利润同比下降19.91%，主要因第四季度锌加工费骤降导致单季亏损2.88亿元。公司盈利高度依赖锌加工费水平，一旦加工费回落，冶炼利润将迅速收窄。同时，呼伦贝尔驰宏（亏损1.46亿）与荣达矿业（亏损2.74亿）持续拖累业绩，固定资产报废与存货减值合计2.04亿元，资产质量承压。

**同业竞争解决的不确定性是长期隐患。** 控股股东承诺将金鼎锌业、云铜锌业注入上市公司的期限已延至2029年，但标的资产合规问题（如金鼎锌业公益诉讼）尚未完全解决。若注入延迟或条件不达预期，将制约公司资源整合与规模扩张，并可能引发市场对治理效率的担忧。
