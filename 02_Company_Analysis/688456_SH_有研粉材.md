# 688456.SH 深度透视

## 因果逻辑链
- **[AI算力与新能源需求爆发]** -> [高端铜粉（散热铜粉、氧化铜粉）批量销售]: 公司抓住AI服务器散热和新能源电子元器件升级机遇，将技术储备转化为高附加值产品订单。
- **[“原材料价格+加工费”定价模式]** -> [收入随铜、锡价格上涨而增长]: 原材料价格上涨直接推高产品售价，但加工费相对稳定，导致收入增长快于销量增长，毛利率承压。
- **[3D打印下游应用深化]** -> [3D打印粉体销量增长69%]: 商业航天、直接制造等高端领域需求扩张，公司凭借技术优势与成本控制，成功切入并实现境外市场突破。
- **[电子浆料国产替代加速]** -> [电子浆料收入同比增长93.45%]: 公司突破微纳粉体技术，产品通过客户验证并小批量销售，切入光伏、MLCC等国产替代关键领域。
- **[泰国基地投产与海外布局]** -> [境外收入同比增长39.66%]: 泰国基地形成稳定批量供货能力，叠加英国Makin的渠道优势，有效规避贸易摩擦，拓展欧洲及东南亚市场。
- **[应收账款与存货资金占用增加]** -> [经营活动现金流净额为-9446万元]: 订单增长及原材料价格上涨导致应收账款和存货规模扩大，现金循环周期拉长，对运营资金形成巨大压力。
- **[套期保值操作]** -> [非经常性损益亏损1007万元]: 为对冲金属价格波动风险而进行的期货交易产生公允价值变动损失，侵蚀了部分主营利润。

## 风险警告
**现金流恶化与运营资金压力是当前最突出的风险。** 公司营收增长20.89%，但经营活动现金流净额却从-281万骤降至-9446万元，降幅高达3257%。核心原因是原材料价格上涨和订单增长共同推高了应收账款和存货规模，导致运营资金被大量占用。这种“增收不增现”的状况若持续，将严重考验公司的资金链和债务偿付能力，尤其是在公司已大幅增加借款（筹资活动现金流净额同比增984%）的背景下。

**原材料价格波动与套保的双刃剑效应不容忽视。** 公司采用“原材料价格+加工费”模式，虽能转嫁部分风险，但金属价格大幅上涨会推高营运资金需求，并导致毛利率承压。同时，公司为对冲风险进行的套期保值操作，在2025年产生了1007万元的公允价值变动损失，直接计入非经常性损益。这表明，在极端行情下，套保策略本身可能成为利润的拖累，而非稳定的保障。
