# 300996.SZ 深度透视

## 因果逻辑链
- **[研发费用大幅增长]** -> [净利润下降38.99%]: 研发费用同比+55.24%，重点投向信创ERP和云湖平台，但研发投入对业绩释放具有滞后性，当期侵蚀利润。
- **[新客户拓展与项目交付延迟]** -> [收入持平但毛利率下降]: 新中标央企项目处于交付期，部分客户预算收紧导致验收延后，收入仅微降1.34%，但毛利率下降2.94个百分点。
- **[客户集中度高]** -> [业绩波动风险]: 前八大央企客户收入占比约63%，客户采购策略变化或合作关系变动将直接冲击公司经营。
- **[信创替代进入关键期]** -> [新增长动能]: 公司信创ERP、EPM、EAM产品在央企落地，成功中标中国五矿、中广核等项目，信创业务成为重要增长点。
- **[AI技术赋能]** -> [产品竞争力提升]: 推出智能体开发平台、ChatBI等，将AI融入产品研发与交付，提升开发效率与产品智能化水平。
- **[季节性收入特征]** -> [前三季度亏损]: 主要客户项目验收集中在第四季度，导致前三季度净利润为负，全年业绩高度依赖Q4。
- **[子公司亏损拖累]** -> [整体盈利承压]: 控股子公司北京思源、北京联方合计亏损超1000万元，对合并净利润产生负面影响。

## 风险警告
**客户集中与项目交付风险**：公司前八大央企客户收入占比高达63%，客户集中度极高。若主要客户采购策略变化或项目验收持续延迟，将直接导致收入确认不及预期。2025年部分项目已因客户预算收紧而延后，该风险需持续关注。

**研发投入与盈利错配风险**：公司研发费用同比暴增55.24%，资本化率下降，导致当期净利润大幅下滑38.99%。虽然研发投入是长期竞争力的基础，但短期内对利润的侵蚀效应显著，且若新产品市场推广不及预期，将面临投入产出失衡的风险。
