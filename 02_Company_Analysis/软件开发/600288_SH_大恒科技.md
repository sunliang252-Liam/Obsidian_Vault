# 600288.SH 深度透视

## 因果逻辑链
- **[降本增效与资产优化]** -> [净利润扭亏为盈]: 通过优化人员结构、关停剥离非核心业务（如大恒星图），大幅削减管理费用（-19.2%）和研发费用（-11.2%），叠加信用减值损失因回款好转而冲回，推动归母净利润从-3201万跃升至1.04亿。
- **[机器视觉业务盈利能力提升]** -> [核心主业利润增长]: 机器视觉及信息技术板块收入增长10.38%，毛利率提升1.77个百分点，带动该板块经常性净利润同比大增327.86%，成为业绩反转的核心驱动力。
- **[电视系统板块回款改善]** -> [扭亏为盈]: 电视数字网络编辑及播放系统板块通过加大长账龄应收款回收力度，信用减值损失转回，推动该板块净利润同比提升136.15%，实现扭亏。
- **[持有南网储能股票公允价值变动]** -> [非经常性收益大增]: 控股子公司中科大洋持有的南网储能股票公允价值上升，产生变动损益及分红合计2226万元，同比增加1885万元，显著增厚当期利润。
- **[原控股股东股份被司法拍卖]** -> [公司变更为无实控人状态]: 原实控人郑素贞所持全部股份被司法拍卖并完成过户，公司股权结构分散，变更为无控股股东、无实际控制人，治理结构面临重塑。
- **[剥离亏损资产]** -> [减轻业绩拖累]: 出售持续亏损的子公司大恒星图全部股权，并关停照明事业部，光机电一体化板块在收入下降36.3%的情况下，净利润反而增长345.09%。

## 风险警告
公司最大的风险在于治理结构的不确定性。原控股股东股份被司法拍卖后，公司已变更为无控股股东、无实际控制人状态，第一大股东及一致行动人持股仅9.26%。这种高度分散的股权结构可能导致决策效率低下、战略方向摇摆，甚至引发潜在的控股权争夺，对长期经营稳定性构成根本性威胁。

其次，公司业绩改善高度依赖“降本增效”和“资产处置”等一次性或非持续性手段。核心主业中，机器视觉业务虽增长，但面临行业价格战加剧的宏观风险；电视系统业务收入仍在萎缩。同时，公司持有大量存货（4.89亿）和应收账款（5.61亿），若下游需求再度疲软或客户经营恶化，资产及信用减值风险将重新暴露，侵蚀来之不易的利润。
