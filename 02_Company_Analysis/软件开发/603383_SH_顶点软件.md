# 603383.SH 深度透视

## 因果逻辑链
- **[客户IT投入谨慎]** -> [收入下滑12.38%]: 上游金融行业客户因市场环境影响，项目立项、实施及验收周期拉长，导致公司金融IT业务收入同比减少。
- **[A5信创核心交易系统持续落地]** -> [巩固行业领先地位]: A5系统已覆盖11家券商，其中6家全面实现Oracle数据库下架，树立信创标杆，驱动核心交易业务护城河加深。
- **[HTS系列极速交易系统拓展]** -> [打开专业交易新市场]: 推出HTS3.0、UTS等新品，覆盖自营、QFII、MOM等新领域，实现产品创新与市场拓展新突破。
- **[C6财富管理平台升级]** -> [推动买方投顾转型]: 从“以产品销售为核心”转向“以客户为中心”，深化账户诊断、基金投顾等场景，成功在头部券商落地。
- **[IBLive资管平台架构跃迁]** -> [抢占资管数字化高地]: 完成向开放原生平台升级，实现全资产类别管理与AI原生融合，MOM系统在十余家客户签约或落地。
- **[AI全面融入业务与研发]** -> [降本增效与产品智能化]: 推出LiveAgent智能体工场，赋能财富、运营、风控等全链条；AI辅助代码生成与测试，提升研发效率。
- **[新签合同金额同比增加]** -> [对冲收入下滑压力]: 尽管收入确认延迟，但公司加强新品拓展，新签合同增长为未来收入提供储备。
- **[大力推行降本提质增效]** -> [利润降幅小于收入降幅]: 管理费用、研发费用等期间费用显著降低，使归母净利润仅下降8.14%，优于收入12.38%的降幅。

## 风险警告
**核心风险在于收入增长停滞与客户IT支出周期的不确定性。** 2025年营收同比下降12.38%，主要因金融客户IT投入整体偏谨慎，项目周期拉长。若资本市场持续低迷或监管政策收紧，下游客户削减IT预算，公司业绩将面临持续压力。尽管新签合同增长，但转化为收入的时间存在不确定性，短期业绩承压明显。

**竞争加剧与技术迭代风险并存。** 金融IT行业竞争激烈，恒生电子等老牌对手及新兴科技公司持续投入。公司虽在信创核心交易系统（A5）上领先，但若不能持续跟踪AI、低延时等前沿技术并快速产品化，可能丧失已有优势。此外，公司近50%总资产为理财产品，投资收益对利润贡献较大，需关注其波动性。
