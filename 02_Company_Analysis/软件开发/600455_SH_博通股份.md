# 600455.SH 深度透视

## 因果逻辑链
- **[学费增长+在校生增加]** -> [高等教育收入增长4.91%]: 2025年秋季新生学费上涨，且招生人数多于毕业人数，直接推动学费及住宿费收入增加。
- **[成本控制]** -> [高等教育毛利率提升3.62个百分点]: 通过控制后勤保障、科研等支出，在收入增长的同时实现营业成本下降2.87%，盈利能力显著增强。
- **[城市学院净利润增长35.50%]** -> [归母净利润增长36.43%]: 公司99%以上收入来自控股70%的西安交通大学城市学院，其业绩增长是上市公司利润增长的核心引擎。
- **[校园二期建设投入增加]** -> [在建工程增长70.30%]: 为满足独立学院转设条件，城市学院持续投入图书馆、宿舍建设，导致在建工程从2.85亿增至4.85亿。
- **[二期建设资金需求]** -> [筹资活动现金流净额增长188%]: 为支撑校园建设，城市学院大幅增加银行贷款，筹资活动现金流入从4375万增至1.35亿。
- **[母公司持续亏损]** -> [无法进行现金分红]: 母公司计算机业务萎缩，累计未分配利润为-1.65亿元，导致公司连续多年无法向股东分红。
- **[关联方历史借款]** -> [其他应付款高企]: 城市学院对第一大股东经发集团的借款本息合计3.2亿元，构成重大关联债务，持续占用公司资金。

## 风险警告
公司本质上是“一所大学”的上市载体，核心资产西安交通大学城市学院面临独立学院转设、营利性/非营利性选择登记两大政策不确定性。转设进度缓慢，登记选择将根本性改变办学模式和利润分配机制，是悬在头顶的达摩克利斯之剑。

母公司计算机业务已名存实亡，完全依赖城市学院输血。然而，城市学院自身背负对关联方经发集团3.2亿元的历史借款，且校园二期建设需持续投入1.5亿元，资金链紧绷。更关键的是，城市学院近年未向上市公司分红，导致母公司报表巨亏，投资者无法获得任何现金回报，公司治理结构存在重大缺陷。
