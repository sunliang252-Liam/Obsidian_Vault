# 300235.SZ 深度透视

## 因果逻辑链
- **执象科技收购并表** -> **净利润增长27.85%**: 2025年11月完成对执象科技100%股权收购，其12月单月贡献净利润803万元，占全年净利润43.21%，直接拉动归母净利润从1454万增至1859万。
- **自主产品收入微增2.05%** -> **核心业务基本盘稳固**: 尽管总营收下滑1.41%，但核心自主产品收入逆势增长至7077万元，占比提升至77.9%，显示教材配套软件业务在教材更新周期中保持韧性。
- **研发费用率维持23.92%** -> **短期利润承压，长期技术壁垒构建**: 研发投入2173万元，占营收比连续三年提升（18.6%→22.99%→23.92%），全部费用化，压制当期利润，但支撑AIGC平台、AI硬件等新产品线落地。
- **征订渠道收入下降18.79%** -> **传统业务模式面临转型压力**: 作为核心收入来源的征订渠道收入从4431万降至3599万，反映传统光盘/软件征订模式受数字化冲击，倒逼公司向互联网渠道和代理渠道转型。
- **代理渠道收入暴增330.75%** -> **渠道结构剧烈调整**: 代理渠道收入从308万跃升至1325万，主要系执象科技并表带来的新渠道（如青海省教育局项目），但该渠道毛利率仅45.74%，显著低于直销和互联网渠道。
- **经营活动现金流净额2.2亿元** -> **盈利质量健康**: 净利润1859万，但经营性现金流净额2.2亿，远超净利润，主因理财到期收回及预收款增加，表明公司实际现金创造能力强于账面利润。
- **投资活动现金净流出1.02亿元** -> **战略扩张消耗现金储备**: 支付执象科技收购款1.16亿元，导致货币资金从1.64亿骤降至7500万，现金储备大幅消耗，但为获取未来增长引擎。

## 风险警告
**核心风险在于收购整合与现金流压力。** 公司以1.16亿元现金收购执象科技，直接导致货币资金腰斩至7500万。执象科技2025年扣非净利润962万元，虽完成首年业绩承诺，但未来三年累计承诺4660万元，压力逐年递增。若执象科技增长不及预期，不仅商誉存在减值风险，公司现金流也将持续承压，限制后续研发和市场投入。

**传统业务萎缩与新产品放量不确定性并存。** 征订渠道收入连续下滑，占营收比从48%降至40%，传统教材配套业务正被数字化浪潮侵蚀。虽然公司推出了阳仔AI陪伴机、开口喵等新产品，但AI数字化产品收入同比暴跌70.28%，仅308万元，新产品尚未形成规模收入。公司正处于“老业务下滑、新业务未起”的尴尬转型期，业绩增长高度依赖并购标的的持续兑现。
