# 300465.SZ 深度透视

## 因果逻辑链
- **[银行业客户科技预算向大行集中]** -> [收入与毛利率双降]: 大型银行利用规模优势压低采购价格，公司被动裁汰低毛利项目，导致软件开发及服务收入同比-3.48%，毛利率降至19.88%。
- **[主动收缩低毛利系统集成业务]** -> [收入骤降84.86%]: 面对国产设备直采趋势，公司放弃低利润份额并改用净额法确认收入，系统集成收入从1.28亿骤降至1943万，但毛利率提升38.92个百分点。
- **[持续降本增效]** -> [费用压缩释放利润空间]: 销售、管理、研发、财务费用合计同比减少2806万元，其中研发费用因裁汰旧项目同比-33.04%，为AI新方向投入腾出空间。
- **[经营性现金流连续三年为正]** -> [财务稳健性提升]: 尽管收入下滑，公司通过强化回款管理实现经营性净现金流4872万元，为业务转型提供安全垫。
- **[AI产品研发落地]** -> [开辟第二增长曲线]: 智能催收、智能授信、智能运维等AI产品已完成研发并在客户投产，标志着公司从传统外包向“产品+服务”模式升级。
- **[子公司仲裁案悬而未决]** -> [潜在利润侵蚀风险]: 全资子公司上海睿民涉及5366万元仲裁案，已计提540万元预计负债，若败诉将对利润表造成重大冲击。

## 风险警告
**核心风险在于子公司仲裁败诉与商誉减值。** 上海睿民仲裁案涉案金额高达5366万元，占2025年归母净利润的187%，且已导致943万元资金被冻结。若最终败诉，将直接侵蚀公司微薄的利润基础，甚至导致全年由盈转亏。同时，账面仍存4378万元商誉，若被收购资产组经营恶化，减值风险不容忽视。

**行业结构性压力与人才流失风险并存。** 银行业IT投入向大行集中、压低采购价格的趋势短期内难以逆转，公司议价能力持续承压。作为人力密集型企业，核心技术人员流失将直接削弱项目交付能力和AI转型进度。2025年研发人员已减少30%，薪酬竞争力不足可能进一步加剧人才流失。
