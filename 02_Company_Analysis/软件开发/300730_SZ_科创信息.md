# 300730.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧+市场需求降低]** -> [营收下降20.91%]: 项目实施及验收周期加长，导致收入确认不及预期。
- **[营收下降+毛利率下滑]** -> [净利润亏损1.38亿]: 收入无法覆盖成本及费用，盈利能力恶化。
- **[谨慎性原则计提减值]** -> [资产减值损失4,481万]: 对广西项目其他流动资产等计提大额减值，加剧亏损。
- **[智慧企业收入骤降53.95%]** -> [整体营收结构恶化]: 智慧企业板块大幅萎缩，数字政府收入仅微增1.49%，增长引擎失速。
- **[研发人员锐减45.85%]** -> [研发费用下降33.59%]: 为控制成本大幅削减研发团队，可能削弱长期技术竞争力。
- **[经营活动现金流持续为负]** -> [流动性压力]: 连续两年经营性现金流净流出，营运资金高度依赖短期借款（余额2.24亿）。
- **[区域集中度高]** -> [增长天花板]: 华中地区收入占比77.77%，业务高度依赖湖南本省，抗区域风险能力弱。
- **[信息披露违规被立案]** -> [声誉与合规风险]: 因涉嫌信披违法违规被证监会立案并收到《行政处罚事先告知书》，面临罚款及市场信任危机。

## 风险警告
公司连续两年巨额亏损（2025年归母净利-1.38亿），且亏损幅度同比扩大116%，净资产收益率跌至-57.05%。核心问题是营收下滑与成本刚性之间的矛盾：智慧企业业务收入腰斩，而管理费用、销售费用并未同步缩减，导致经营杠杆严重负向。更关键的是，公司为保现金流大幅削减研发人员（-45.85%），在AI技术快速迭代的行业背景下，此举可能动摇其“AI+数据”战略的技术根基。

财务质量堪忧。经营活动现金流连续两年净流出，应收账款与存货合计高达3.07亿，占流动资产的59%。公司已因信息披露违规被证监会立案并拟处罚，内控有效性存疑。此外，广西项目高达9,438万的其他流动资产已计提4,322万减值，若后续项目无法顺利推进，存在进一步减值风险，将对本已脆弱的资产负债表造成更大冲击。
