# 603990.SH 深度透视

## 因果逻辑链
- **[剥离亏损光伏业务]** -> [扭亏为盈]: 2025年1月完成光伏资产出售，彻底消除光伏业务巨额亏损，公司归母净利润从-2.79亿元转为+0.39亿元。
- **[聚焦医疗信息化主业]** -> [营收结构重塑]: 剥离光伏后，营收下降35.04%，但核心医疗信息化业务收入同比增长4.50%，毛利率67.31%，成为利润支柱。
- **[AI大模型与临床系统融合]** -> [产品智能化升级]: 推出麻醉AI助手、重症AI机器人等，将AI嵌入术前评估、风险预警、病历生成等全流程，提升产品壁垒与客单价。
- **[信创国产化适配]** -> [拓展市场空间]: 完成麻醉、重症系统对华为鲲鹏、统信UOS及国产数据库的适配，满足国家信创要求，打开党政军及关键基础设施医院市场。
- **[康养机器人布局]** -> [探索第二增长曲线]: 发布优麦康养陪伴机器人v1.0，与多家养老机构合作，但截至报告期末尚未规模交付，处于早期投入阶段。
- **[辅助生殖纳入医保]** -> [医疗服务收入承压]: 海南省将辅助生殖纳入医保，导致单个治疗周期价格下降，玛丽医院收入同比降5.72%，毛利率降7.80个百分点。
- **[处置光伏回收现金]** -> [现金流大幅改善]: 收到光伏股权转让款约3.1亿元，经营活动现金流净额从-0.11亿元转为+0.65亿元，偿债能力显著提升。

## 风险警告
公司最大的风险在于**新业务落地的不确定性**。AI医疗、康养机器人等创新业务尚处于研发与试点阶段，未形成规模收入，而研发投入资本化比例高达43.07%，若商业化不及预期，将面临资产减值与持续亏损的双重压力。同时，母公司未分配利润仍为-1.72亿元，短期不具备分红能力，投资者需警惕“概念先行、业绩滞后”的估值风险。

其次，**医疗信息化主业增长乏力**。剔除光伏剥离影响后，核心业务收入仅增长4.50%，且毛利率下滑5.19个百分点。辅助生殖业务受医保控价影响，量价承压。公司虽在AI领域积极布局，但行业竞争激烈，若不能快速将技术优势转化为订单增长，主业可能陷入“增收不增利”的困境。
