# 688296.SH 深度透视

## 因果逻辑链
- **[地方水务企业资金紧张]** -> [新项目立项迟滞、在建项目延后]: 下游客户因财政压力缩减资本开支，导致公司订单获取与项目交付双重受阻，收入锐减35.88%。
- **[收入大幅下滑]** -> [规模效应减弱，固定成本分摊上升]: 营业收入从4.79亿降至3.07亿，但管理费用、销售费用等刚性支出未同步缩减，导致亏损加剧。
- **[部分项目施工条件恶劣]** -> [实施周期拉长，投入成本高企]: 特定地理环境下的项目交付难度超预期，侵蚀了项目毛利率，整体毛利率同比下降3.65个百分点。
- **[合同履约成本减值损失增加]** -> [资产减值损失扩大]: 对执行中的未验收项目进行审慎评估，计提了更多减值准备，进一步拖累净利润。
- **[理财收益及政府补助减少]** -> [非经常性损益贡献下降]: 公司投资收益与补贴收入较上年同期减少，削弱了利润缓冲垫。
- **[应收账款高企且账龄拉长]** -> [坏账风险与现金流压力并存]: 期末应收账款3.29亿元，1年以上账龄占比高达69.78%，回款困难导致经营性现金流净额为负。
- **[研发投入逆势增长]** -> [短期利润承压，长期技术壁垒加固]: 研发费用占收入比提升至18.15%，重点投入AI与物联网平台，虽加剧当期亏损，但为“AI+水务”战略储备核心能力。

## 风险警告
**核心风险在于下游客户支付能力恶化与公司自身造血能力不足的恶性循环。** 公司收入高度依赖地方水务企业的财政预算，在宏观经济承压背景下，客户资金紧张导致新项目延迟、在建项目停滞，直接引发营收断崖式下滑。更严峻的是，应收账款高企且账龄结构恶化，1年以上应收占比近70%，坏账计提压力持续存在，而经营性现金流已连续两年为负，公司缺乏内生“造血”能力来缓冲外部冲击。

**第二重风险是竞争格局恶化与转型不确定性。** 华为、腾讯等科技巨头正加速进入智慧水务领域，凭借其强大的平台与资本优势，可能挤压公司作为垂直领域集成商的生存空间。公司虽押注“AI+水务”战略，但研发投入转化为可观的商业化收入尚需时日，在亏损状态下能否维持高强度研发投入，以及新产品能否在巨头环伺下打开市场，存在重大不确定性。
