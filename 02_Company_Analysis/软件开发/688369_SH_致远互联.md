# 688369.SH 深度透视

## 因果逻辑链
- **[信创政策红利 + AI技术赋能]** -> [营收增长6.69%]: 公司积极把握信创国产替代机遇，并推出AI智能体产品线CoMi，有效提升市场占有率，推动营业收入增长。
- **[客户需求复杂度提升]** -> [毛利率下降7.4个百分点]: 项目交付周期变长，导致外包服务及员工薪酬等交付成本大幅增加（+28.77%），侵蚀了毛利空间。
- **[持续高研发投入]** -> [连续三年亏损]: 公司为保持技术领先，研发费用率维持在20%以上，叠加销售费用高企，导致净利润持续为负，但亏损额同比略有收窄。
- **[AI关联业务规模化落地]** -> [AI合同订单达2.07亿元]: 公司AI-COP平台及CoMi智能体产品获得市场认可，AI能力从技术布局进入实际价值兑现阶段，成为新增长极。
- **[信创合同金额增长42%]** -> [政务业务成增长核心动力]: 政务直销合同金额同比增长35%，信创产品合同金额同比增长264%，信创成为拉动业绩的核心引擎。
- **[加强现金流管理]** -> [经营现金流净流出大幅改善]: 通过加强回款，销售商品收到的现金增加，使经营活动现金流净额从-9897万元改善至-2055万元。
- **[央国企市场深耕]** -> [央国企客户合同金额增长13.6%]: 聚焦穿透式监管与集团一体化运营，成功新增航发集团、中海油等战略客户，巩固了高端市场地位。
- **[子公司薪事力持续亏损]** -> [拖累整体净利润]: 子公司致远薪事力（HR SaaS）报告期内亏损4001万元，成为公司整体亏损的重要来源之一。

## 风险警告
公司连续三年亏损，累计亏损额巨大，且母公司未分配利润为负，不具备分红条件。核心风险在于，尽管营收增长，但项目交付成本激增导致毛利率大幅下滑，盈利能力未见根本性改善。若AI创新业务成长不及预期或市场竞争加剧，公司存在持续亏损风险，将不断消耗净资产，影响长期财务健康。

另一重大风险是技术迭代与市场竞争的双重挤压。协同管理软件行业正被AI原生应用企业冲击，公司需持续高投入以维持技术领先，但研发投入的资本化率极低，若不能将AI技术优势有效转化为可持续的盈利增长，高昂的研发与销售费用将始终是利润的沉重负担。此外，公司经营业绩存在显著的季节性波动，上半年通常亏损，对现金流管理构成挑战。
