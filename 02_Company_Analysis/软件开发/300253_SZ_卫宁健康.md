# 300253.SZ 深度透视

## 因果逻辑链
- **[WiNEX产品升级替换期]** -> [收入下降]: 新一代产品WiNEX在推广中尚未转化为规模收入，导致核心软件及服务收入同比下降19.39%。
- **[互联网医疗健康业务优化]** -> [收入与利润双重承压]: 公司主动关停或剥离部分互联网医疗健康业务，导致该板块收入骤降46.93%，并产生一次性损失。
- **[人工等固定成本刚性]** -> [利润大幅下滑]: 收入下降24.30%，但人工等相对固定支出无法同比例减少，导致利润端出现亏损。
- **[计提大额减值准备]** -> [净利润由盈转亏]: 报告期内计提信用减值损失1.11亿元及资产减值损失（含商誉）1.41亿元，合计约2.52亿元，是导致净利润亏损3.74亿元的核心因素。
- **[补缴税款及滞纳金]** -> [非经常性损益拖累]: 补缴过往税款及滞纳金，计入营业外支出，进一步加剧了当期亏损。
- **[AI大模型WiNGPT落地]** -> [长期竞争力构建]: 公司自主研发的医疗大模型WiNGPT及智能助手WiNEX Copilot已在多家医院部署，为未来AI驱动的收入增长奠定基础。
- **[经营活动现金流净额增长]** -> [运营质量改善]: 尽管利润亏损，但通过加强收款管理，经营活动现金流净额同比增长36.28%至5.55亿元，显示公司回款能力增强。

## 风险警告
**核心风险在于“新旧动能转换”的阵痛期过长。** 公司正经历从传统软件销售向“WiNEX+AI”新架构的艰难转型，但新产品尚未形成规模收入，而旧有业务因竞争加剧和需求波动而萎缩。同时，公司为转型付出了高昂的代价：大规模计提减值（商誉、信用、资产）和补缴税款，直接导致2025年巨亏。若WiNEX及AI产品的商业化进程持续慢于预期，公司可能面临收入持续下滑与利润长期承压的双重困境。

**治理与合规风险是另一大隐患。** 公司原董事长周炜因涉及子公司单位行贿案被判刑，暴露出公司在高速扩张期对子公司管控及合规经营方面的漏洞。这不仅对公司声誉造成负面影响，也可能影响未来获取政府及公立医院订单的能力。此外，公司研发投入资本化率仍处于高位（36.86%），若未来项目收益不及预期，存在无形资产减值风险。
