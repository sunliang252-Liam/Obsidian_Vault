# 300047.SZ 深度透视

## 因果逻辑链
- **[ICT分销业务高增长]** -> [营收增长15%]: 子公司金华威作为华为/超聚变/大疆总经销商，ICT产品销售同比增长20.87%，贡献82%营收，是收入增长绝对主力。
- **[运营商资本开支压降]** -> [通信业务收入下滑7.54%]: 三大运营商连续三年缩减IT投资，公司传统BSS业务承压，但AI/算力相关新业务投入增加。
- **[维恩贝特业绩下滑]** -> [计提商誉减值4981万元]: 金融信创改造进入尾声，大客户预算收紧，导致子公司维恩贝特收入利润下降，触发商誉减值，侵蚀归母净利润。
- **[收购金华威剩余股权并表]** -> [归母净利润同比增3928万元]: 2024年9月完成对金华威45%少数股权的收购，2025年全年并表，直接增厚归母净利润。
- **[AI研发投入资本化]** -> [研发费用率下降至3.41%]: 研发投入3.2亿元，其中30.99%资本化，资本化研发支出占净利润比重高达227%，压低当期费用，虚增利润。
- **[董事长被留置]** -> [治理风险显著]: 公司董事长陈友于2025年12月被景德镇乐平市监察委留置，至今未结案，构成重大不确定性。
- **[低毛利分销业务占比过高]** -> [整体净利率极低]: ICT分销业务毛利率仅4.85%，占营收82%，导致公司整体归母净利率仅0.33%，盈利能力脆弱。

## 风险警告
**核心风险：治理与盈利双重困境。** 董事长陈友被留置事件悬而未决，公司治理稳定性存疑，可能影响重大决策与客户信任。同时，公司归母净利润仅3070万元，净利率不足0.4%，剔除商誉减值影响后也仅8051万元，盈利能力极其薄弱。高达227%的研发支出资本化率，存在通过会计手段调节利润的嫌疑，若未来资本化项目不及预期，将面临集中减值风险。

**业务风险：低毛利分销业务依赖与核心软件业务萎缩。** 公司82%的收入来自毛利率不足5%的ICT分销，该业务受上游厂商政策及下游客户预算影响大，利润空间微薄。而高毛利的软件与技术服务收入同比下降11.79%，核心主业增长乏力。运营商资本开支持续压降，金融信创红利消退，公司面临“增收不增利”的结构性困境，第二增长曲线（AI）尚未形成规模贡献。
