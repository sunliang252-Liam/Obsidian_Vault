# 300468.SZ 深度透视

## 因果逻辑链
- **[战略收缩，聚焦高利润]** -> [营收下降14.76%，但净利润增长10.30%]: 公司主动退出低利润业务，将资源集中于海外市场和高利润率的创新业务（如Web3、AI），导致收入规模缩减，但整体毛利率从33.09%提升至38.58%，实现了“以退为进”的利润增长。
- **[境外业务占比首超八成]** -> [营收结构发生质变]: 境外收入同比增长13.92%至5.09亿元，占比从60.31%跃升至80.61%，公司已从一家“内外兼修”的金融科技公司，彻底转型为以香港为核心的离岸金融科技服务商。
- **[深度绑定香港金融基建]** -> [获得高粘性、高价值订单]: 公司全程参与mBridge、Project Ensemble、数码港元等香港金管局核心项目，成为其“技术合伙人”。这种从基建层面切入的合作模式，构筑了极高的客户壁垒和业务护城河。
- **[合规Web3与AI技术先发]** -> [开辟第二增长曲线]: 公司通过FINNOSafe（Web3平台）和FINNOSmart（AI平台）在合规代币化货币、RWA、生成式AI沙盒等前沿领域取得先发优势，成功将技术储备转化为可交付的商业项目，为未来增长奠定基础。
- **[客户高度集中]** -> [经营风险与议价能力并存]: 前五大客户销售额占比高达80.56%，其中单一客户占比52.74%。这种高度依赖少数头部客户（主要是香港大型银行）的模式，虽能带来稳定收入，但也使公司面临客户流失或压价的巨大风险。
- **[零有息负债的“轻装上阵”]** -> [财务稳健，抗风险能力强]: 公司资产负债率仅7.05%，流动比率高达11.79，且没有任何有息负债。这为公司应对行业周期波动、进行技术研发投入和潜在并购提供了坚实的财务基础。

## 风险警告
**核心风险在于客户与市场的双重集中。** 公司超过80%的收入来自境外，且前五大客户贡献了超过80%的营收，其中单一客户占比过半。这种“鸡蛋放在一个篮子里”的格局，使其业绩高度依赖于香港金融市场的景气度、主要客户的IT预算以及双方合作关系的稳定性。一旦香港经济或金融政策出现波动，或核心客户转向自研或更换供应商，将对公司造成毁灭性打击。同时，公司正计划发行H股，这虽能拓宽融资渠道，但也将摊薄现有股东权益，并引入新的市场风险。

**技术转型的投入产出存在巨大不确定性。** 公司正全力押注Web3和生成式AI，但这两个领域技术迭代极快、监管政策尚不明朗、商业化路径仍在探索中。公司在年报中也坦承“研发投入无法产生回报的风险”。目前，公司的利润增长主要源于“节流”（退出低利润业务），而非“开源”（新业务大规模创收）。若Web3和AI业务无法在短期内形成可观的收入贡献，而传统业务又因战略收缩而持续萎缩，公司将面临增长乏力的困境。
