# 300075.SZ 深度透视

## 因果逻辑链
- **[地方财政紧缩]** -> **收入确认延迟**: 客户资金紧张导致项目取消、招标滞后、验收普遍延迟，直接造成2025年营收同比下降15.64%。
- **[高研发投入维持]** -> **成本费用承压**: 在业绩困难下仍全力保证技术研发、工程服务和本地化营销团队投入，导致成本费用端承压较重，加剧亏损。
- **[运营服务类业务萎缩]** -> **营收结构恶化**: 运营服务类业务收入同比下降27.68%，毛利率降至0.47%，成为拖累整体业绩的核心板块。
- **[资产减值与信用减值]** -> **巨额亏损**: 计提存货跌价准备及商誉减值准备2.38亿元，信用减值损失0.75亿元，合计占利润总额的77.48%，是亏损的直接财务原因。
- **[城市更新政策红利]** -> **战略转型方向**: “十五五”期间地下管网改造投资需求超5万亿元，公司聚焦“工程+软件+机制”模式，将城市生命线业务作为核心增长点。
- **[AI大模型与低空经济]** -> **新业务布局**: 推出“人和大模型2.0”和“星揆计划”，在智能政务、低空巡检等场景落地，但合同额仅1500万元，尚处早期培育阶段。
- **[商河项目中标]** -> **模式验证**: 中标1.09亿元商河智慧水务项目，落地“工程+数字化+机制”三合一模式，标志着业务从地市向区县下沉，具备可复制性。
- **[员工股权激励]** -> **业绩目标锚定**: 2026年2月发布股权激励计划，明确2026年扭亏为盈及未来三年业绩重回快速增长轨道的经营目标，形成短期业绩底线。

## 风险警告
**核心风险在于地方财政紧缩的持续性。** 公司传统智慧城市业务高度依赖政府信息化预算，2025年营收下滑15.64%已充分暴露这一脆弱性。尽管城市更新领域有5万亿政策预期，但资金落地节奏、项目回款周期仍存在巨大不确定性。公司运营服务类业务毛利率已降至0.47%，几乎无利润空间，若财政压力持续，该板块可能进一步恶化。

**资产质量风险不容忽视。** 应收账款账面余额高达15.43亿元，坏账准备4.96亿元，信用减值损失持续扩大。商誉虽已计提2.1亿元减值，但剩余商誉仍存在进一步减值风险。公司连续两年亏损，净资产已从40.6亿元缩水至31.6亿元，若转型不及预期，资产减值压力将持续侵蚀股东权益。
