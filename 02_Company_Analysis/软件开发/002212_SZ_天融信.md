# 002212.SZ 深度透视

## 因果逻辑链
- **[AI+安全产品创新]** -> [营收结构优化]: 首发大模型安全网关、API安全审计等AI安全新品，带动智算云业务收入同比增长57.95%，占总营收比重提升至15.70%，对冲传统网络安全产品收入下滑。
- **[政府行业预算收紧]** -> [整体营收下滑8.81%]: 政府及事业单位客户受宏观环境影响，采购预算收缩，该板块收入同比下降23.24%，是拖累总营收的核心因素。
- **[成本管控与人员优化]** -> [毛利率提升5.27个百分点]: 通过控费增效、优化人员结构，网络安全业务毛利率增长7.57个百分点，智算云毛利率增长2.18个百分点，盈利质量显著改善。
- **[股份支付费用增加]** -> [净利润下滑10.59%]: 管理费用因股份支付费用增加同比上升37.05%，导致归母净利润同比下降10.59%；但扣除股份支付影响后，净利润同比增长234.93%。
- **[下游客户采购季节性]** -> [业绩季度波动剧烈]: 客户预算管理制度导致第四季度营收占全年53.25%，而前三季度持续亏损，经营现金流也呈现显著季节性波动。
- **[信创与国产化替代]** -> [巩固行业壁垒]: 深耕国产化二十余年，累计发布350款信创安全产品型号，取得3900余项兼容性认证，在政府、运营商等关键行业形成难以替代的护城河。
- **[智算云战略升级]** -> [开辟第二增长曲线]: 云计算业务升级为智算云，发布“融算一体”太行云5.0，智算一体机超额完成年度销量目标，成为公司未来增长的核心引擎。

## 风险警告
**核心风险在于营收增长失速与对政府客户的过度依赖。** 公司2025年营收同比下降8.81%，主要因政府行业收入骤降23.24%，而该板块仍占公司总营收近40%。若宏观经济持续低迷或政府IT预算进一步收紧，公司营收可能继续承压。同时，公司客户集中度较高，前五大客户销售额占比达43.55%，单一客户A占比高达28.13%，存在大客户依赖风险。

**商誉减值风险高悬。** 截至2025年末，公司商誉高达41.45亿元，占总资产的36.92%。该商誉主要源于2016年收购天融信科技。若未来网络安全或智算云业务经营不及预期，或行业竞争加剧导致盈利能力下滑，将面临巨额商誉减值风险，直接侵蚀净利润。此外，公司研发投入资本化率高达35.68%，若研发项目商业化不及预期，也存在资产减值风险。
