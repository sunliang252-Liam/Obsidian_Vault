# 688318.SH 深度透视

## 因果逻辑链
- **[机构客户需求减少]** -> [软件销售收入下降28.39%]: 公司超70%收入来自券商，存量客户饱和，新增需求放缓直接冲击核心业务。
- **[证券信息服务用户数增加]** -> [证券信息服务收入增长15.85%，但成本激增30.55%]: 用户扩张带来收入增量，但信息费和托管费同步攀升，导致该业务毛利率下降6.26个百分点。
- **[公允价值变动收益大增]** -> [归母净利润增长3.77%]: 报告期末交易性金融资产公允价值增加3910万元，是净利润正增长的核心非经常性因素。
- **[研发投入持续高企]** -> [扣非净利润下降8.97%]: 研发费用占营收23.25%，但收入下滑，导致核心盈利能力承压，扣非利润显著低于归母利润。
- **[AI技术投入与产品迭代]** -> [“问小达”智能体准确率提升至88%]: 公司持续加码AI，将智能问答升级为证券智能体，为未来产品差异化奠定基础。
- **[客户黏性高]** -> [软件服务收入稳定增长6.64%]: 券商对通达信系统的替换成本高，维护服务收入成为公司业绩的“压舱石”。
- **[客户结构单一]** -> [收入增长天花板明显]: 公司已覆盖国内90%以上券商，新增机构客户空间有限，增长高度依赖存量客户增值服务及个人用户拓展。

## 风险警告
**核心风险在于“增长失速”与“盈利质量下降”的双重困境。** 公司收入高度依赖券商客户（超70%），在券商IT预算收紧、自身客户覆盖率已超90%的背景下，软件销售收入同比大幅下滑28.39%，显示出明显的增长天花板。更值得警惕的是，扣非净利润同比下降8.97%，而归母净利润却因3.91亿元的公允价值变动收益（主要来自理财投资）实现正增长，这种“非经常性损益粉饰”的盈利结构极不稳定，一旦市场波动，利润将面临巨大回撤风险。

**第二重风险来自成本失控与战略转型的不确定性。** 公司大力发展的证券信息服务业务，虽然收入增长15.85%，但成本增速（30.55%）远超收入，导致该业务毛利率骤降6.26个百分点。这表明公司在争夺个人用户时，付出了高昂的获客与数据成本，盈利模式尚未跑通。同时，公司账面持有超15亿交易性金融资产，并涉足大量私募基金、信托等高风险理财，存在1亿元已逾期未收回的投资，资产质量与资金安全需高度警惕。
