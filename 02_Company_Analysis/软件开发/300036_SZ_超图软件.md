# 300036.SZ 深度透视

## 因果逻辑链
- **[AI技术突破与产品化]** -> [AI业务规模倍增]: 公司推出SuperMap AIF技术底座和空间智能体服务平台，实现从技术研发到政务级项目规模化落地，AI成为核心增长引擎。
- **[经营管控提质增效]** -> [扭亏为盈]: 通过升级IPD研发流程、优化矩阵管理、整合产品线及办公区，大幅降低管理费用23.41%，人效提升，实现净利润从-1.71亿到0.47亿的逆转。
- **[国际业务“平台+应用”双轮驱动]** -> [海外合同同比增长130%]: 在东南亚、中东等市场实现国家级项目突破（如沙特、马来西亚），从单纯卖软件转向提供解决方案，海外收入增长294.61%。
- **[信创替代政策红利]** -> [基础软件业务稳健增长]: 公司作为全栈信创GIS厂商，深度参与上海、天津等城市信创项目，巩固了国产替代基本盘，支撑基础软件业务延续增势。
- **[自然资源信息化市场领先]** -> [行业应用业务护城河加固]: 公司深度参与国家级平台建设，中标南通、山西、云南等重大项目，市场份额压制性领先，形成“领先-赢单-份额再提升”的正向循环。
- **[应收账款与商誉高企]** -> [资产减值损失侵蚀利润]: 报告期信用减值损失达9009万元，资产减值损失345万元，合计占利润总额的193%，是净利润绝对值远低于营收增长的核心拖累。

## 风险警告
**核心风险在于资产质量与盈利转化效率。** 公司营收微增0.75%，但净利润仅4685万元，主要被高达9354万元的资产减值（信用+资产）所吞噬。应收账款净额达8.92亿元，占总资产22.85%，且客户多为政府，回款周期长，坏账风险是悬在利润之上的达摩克利斯之剑。同时，3.66亿元的商誉（占净资产13.69%）若未来子公司业绩不达预期，减值风险将直接冲击利润表。

**第二增长曲线尚在培育期，业绩波动性大。** 公司业务高度依赖政府客户，导致收入确认呈现显著的“前低后高”季节性特征，上半年亏损已成常态。虽然AI和国际化业务增速亮眼（合同增长130%），但绝对体量尚小（国际收入仅占1.13%），短期内难以对冲传统业务波动和坏账风险。若AI项目落地或海外市场拓展不及预期，公司可能重回亏损泥潭。
