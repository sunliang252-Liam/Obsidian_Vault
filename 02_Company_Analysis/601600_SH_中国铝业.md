# 601600.SH 深度透视

## 因果逻辑链
- **[原铝价格上涨]** -> [原铝板块利润暴增]: 2025年SHFE铝均价同比上涨4.0%，叠加原燃材料成本下降，原铝板块税前利润从89.66亿元飙升至205.99亿元，成为公司最大利润引擎。
- **[极致经营与全要素对标]** -> [成本下降与效率提升]: 通过压降低毛利贸易业务、压缩带息债务规模、优化融资成本，营业成本同比下降1.06%，财务费用下降19.30%，经营性净现金流创历史新高。
- **[氧化铝价格暴跌]** -> [氧化铝板块利润大幅缩水]: 氧化铝现货均价同比下跌21.1%，导致氧化铝板块税前利润从116.84亿元骤降至47.75亿元，拖累整体业绩。
- **[电解铝产能触及天花板]** -> [供需紧平衡支撑铝价]: 国内电解铝建成产能仅4,483万吨/年，增速极低，而需求端（新能源、电力等）持续增长，全球供需紧平衡格局为铝价高位运行提供支撑。
- **[资产减值损失增加]** -> [侵蚀部分利润]: 公司积极优化产业布局，对效益不佳、停用淘汰的资产计提减值，资产减值损失从27.53亿元增至35.25亿元，对净利润形成拖累。
- **[研发投入大幅增加]** -> [驱动未来技术壁垒]: 研发费用同比增长27.63%至39.12亿元，聚焦绿色低碳、数智化、高端新材料等领域，旨在构建长期技术护城河。
- **[海外资源布局深化]** -> [提升供应链韧性]: 拟收购巴西铝业，叠加几内亚博法矿持续运营，多元化海外资源布局旨在对冲国内铝土矿供应刚性及地缘政治风险，保障原料供应安全。

## 风险警告
**核心风险在于氧化铝产能过剩与价格下行周期。** 2025年国内氧化铝市场已转为供大于求，新增产能持续释放，而下游电解铝需求增速放缓，价格中枢大幅下移。公司氧化铝板块利润同比暴跌近60%，若此趋势延续，将严重侵蚀公司整体盈利。公司虽通过原铝板块对冲，但原铝价格受宏观及贸易战影响波动剧烈，单一板块的强势难以完全弥补氧化铝的颓势。

**国际化经营与资产减值风险不容忽视。** 公司海外资产占比近10%，且正推进巴西铝业重大收购，面临地缘政治、汇率波动及当地政策不确定性。同时，公司2025年计提了35.25亿元的大额资产减值，显示部分存量资产效益不佳。若未来市场环境恶化或项目投资回报不及预期，持续的资产减值将直接冲击利润表，并考验公司现金流。
