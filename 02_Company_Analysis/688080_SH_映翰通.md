# 688080.SH 深度透视

## 因果逻辑链
- **[海外市场高质量增长]** -> [营收与利润双增]: 海外收入同比增长59.66%，占比提升至56.38%，成为公司最重要的增长引擎，驱动整体营收增长27.01%。
- **[智能售货控制系统重点项目规模化落地]** -> [板块收入翻倍]: 某重点合作项目大额订单顺利执行，带动该板块收入同比增长228.97%，但低毛利率特性拖累综合毛利率下降3.24个百分点。
- **[数字配电网业务国内项目节奏调整]** -> [阶段性收入拖累]: 国内部分电网客户招投标与建设节奏后移，导致数字配电网产品收入同比下降27.90%，但公司已完成产品迭代，为“十五五”配网投资大周期蓄力。
- **[产品结构调整]** -> [综合毛利率承压]: 低毛利率的智能售货控制系统产品收入占比上升，是2025年度综合毛利率下降3.24个百分点的主要原因。
- **[研发投入持续增加]** -> [AI能力加速落地]: 研发费用同比增长5.46%，推动AI边缘计算机、AI原生路由器、车载AI算法等新产品与AI能力加速落地，构建中长期竞争力。
- **[“亚太—北美”双区域供应链协同]** -> [增强全球供应链韧性]: 扩大加拿大生产制造中心规模，形成双区域协同格局，有效提升对北美市场的本地化响应能力和应对贸易政策变化的韧性。

## 风险警告
公司面临的核心风险在于**产品结构变化对盈利能力的侵蚀**。智能售货控制系统业务的爆发式增长虽然拉动了营收，但其极低的毛利率（19.48%）显著拉低了公司整体毛利率水平。若该业务持续高速扩张而高毛利的工业物联网、数字配电网业务增长不及预期，公司盈利能力将持续承压，存在“增收不增利”的风险。

此外，**海外业务占比过半（56.38%）带来的地缘政治与汇率风险不容忽视**。公司业务高度依赖北美、欧洲市场，中美贸易摩擦、关税政策变化、人民币汇率波动均可能对海外业务成本和盈利能力产生直接冲击。同时，数字配电网业务高度依赖国内电网投资节奏，若“十五五”配电网投资落地不及预期，该板块收入可能持续低迷。
