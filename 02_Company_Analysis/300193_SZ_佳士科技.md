# 300193.SZ 深度透视

## 因果逻辑链
- **海外销售占比高（48.27%）且以美元结算** -> **净利润下降22.38%**: 美元汇率波动导致汇兑损失大幅增加，同时定期存款利息收入减少，财务费用同比飙升74.87%，严重侵蚀利润。
- **国内销售增长11.28%** -> **营收微增0.88%**: 国内市场的强劲增长（经销模式+4.82%）几乎完全对冲了出口销售7.91%的下滑，使总收入勉强维持正增长。
- **销售费用增长30.68%** -> **利润承压**: 为应对国内市场竞争和渠道拓展，公司加大广告宣传和人员投入，销售费用增速远超营收增速，直接压缩了利润空间。
- **研发费用增长16.25%** -> **产品数字化升级**: 持续投入EVO20、EVOLVE、手持激光焊等系列研发，推动产品向数字化、智能化转型，是维持核心竞争力的关键。
- **惠州亿沃工业园项目基本完工** -> **固定资产增加**: 在建工程转固导致固定资产同比增长56.7%，为未来产能扩张奠定基础，但短期内增加了折旧压力。
- **注销回购股份17,348,862股** -> **每股收益增厚**: 通过减少总股本，在净利润下滑的情况下，部分缓解了每股收益的下降幅度（从0.54元降至0.42元）。
- **资金收益减少** -> **非经常性损益波动**: 公允价值变动收益（+1988万）和委托理财收益（+246万）虽为正，但无法弥补主营业务利润的下滑，导致扣非净利润降幅（-28.62%）大于净利润降幅。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司营收几乎原地踏步，但利润却大幅倒退，根源在于对海外美元收入的高度依赖。2025年财务费用从-7866万骤降至-1977万，意味着汇率波动和利息收入减少直接吞噬了超过5800万的利润，这是公司无法通过内部经营快速弥补的“硬伤”。若美元进入贬值周期或利率环境持续变化，公司业绩将面临持续且不可控的冲击。

**另一大风险是行业竞争加剧与转型阵痛。** 焊割设备行业已进入存量竞争时代，公司为保住市场份额，不得不加大销售费用投入（+30.68%），同时为向高端工业焊机领域突破，研发支出也在持续增长（+16.25%）。这种“烧钱”换市场的策略能否在未来转化为收入和利润的增长，存在巨大不确定性。若高端化转型不及预期，公司可能陷入“投入增加、利润下滑、竞争加剧”的恶性循环。
