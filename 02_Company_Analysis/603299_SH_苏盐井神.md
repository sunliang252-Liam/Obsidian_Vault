# 603299.SH 深度透视

## 因果逻辑链
- **[纯碱行业供过于求，价格跌至近五年低位]** -> [营收与利润双降]: 天然碱产能快速释放，行业供需矛盾加剧，公司纯碱产品价格大幅下滑，导致营收同比下降15.68%，归母净利润同比下降32.11%。
- **[煤炭等大宗原料价格下行]** -> [营业成本同比下降14.35%]: 公司主要能源煤炭采购价格下降，有效对冲了部分产品售价下跌带来的利润侵蚀，但降幅小于收入降幅。
- **[盐化产品产销量创历史新高]** -> [以量补价，稳定基本盘]: 公司通过优化生产调度和高质量营销，实现盐化产品产销量同比增长4.01%，部分抵消了价格下跌对收入的负面影响。
- **[张兴储气库实现产业化运营]** -> [开辟第二增长曲线]: 储气库项目累计注气2.95亿方，采气1.1亿方，标志着公司“盐+储能”战略从工程化实践迈入产业化运营，储气业务进入利润释放期。
- **[国信苏盐600MW压气储能项目并网]** -> [抢占新型储能先机]: 项目1、2号机组完成满负荷试运行，公司率先在长时、大容量储能领域实现商业化突破，为未来能源转型业务奠定基础。
- **[循环经济与成本优势]** -> [维持行业领先毛利率]: 公司独创的“井下循环制碱”工艺，实现资源梯次利用与成本协同，在行业普遍亏损背景下，盐类产品毛利率仍高达43.16%，展现出强大的成本护城河。
- **[加大资本开支，推进项目建设]** -> [投资活动现金流大幅流出]: 为推进储气库、压气储能、卤水制盐等重大项目，公司购建长期资产支出增加，导致投资活动现金净流出14.07亿元，同比大幅增加。

## 风险警告
公司当前面临的核心风险是**纯碱行业的周期性低谷**。2025年纯碱价格已跌至近五年最低，行业普遍亏损，且2026年预计新增产能将持续释放，天然碱占比提升将进一步拉低行业成本曲线。公司纯碱业务毛利率已从高位骤降至12.97%，若下游光伏、浮法玻璃需求持续疲软，该业务可能面临亏损，成为拖累整体业绩的最大变量。

此外，公司正处于**资本开支高峰期**。张兴储气库、卤水制盐综合利用工程等重大项目投资巨大，导致2025年投资活动现金净流出14亿元，同时短期借款和长期借款分别大幅增长87.87%和138.82%。若项目未来收益不及预期或资金回收周期拉长，将显著增加公司的财务杠杆和偿债压力，侵蚀现金流稳定性。
