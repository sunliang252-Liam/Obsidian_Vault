# 000822.SZ 深度透视

## 因果逻辑链
- **行业产能扩张（全国纯碱有效产能增至4078万吨，同比增长2.72%）** -> 纯碱市场供应充裕，价格下滑（全年均价同比下降32%）: 产能增加导致市场供应过剩，供过于求推动价格下跌。
- **下游需求回落（浮法+光伏玻璃日熔量下降，表观需求量从3710万吨降至3570万吨）** -> 纯碱价格下滑: 下游玻璃行业需求减少，直接降低了纯碱需求，导致价格承压。
- **纯碱价格下滑（全年均价同比下降32%）** -> 公司营业收入下降（同比下降21.07%）: 纯碱是公司主导产品，占营收67.82%，价格大幅下跌直接导致总收入减少。
- **纯碱价格下滑** -> 公司净利润亏损13.88亿元: 收入下降叠加成本相对刚性（原材料和能源成本下降幅度小于收入降幅），导致毛利润大幅缩减；同时计提资产减值损失。
- **对部分固定资产计提减值准备** -> 公司净利润亏损: 资产减值损失直接减少当期利润。
- **纯碱价格下滑** -> 经营活动现金流净额转负（-1.04亿元，同比减少106.27%）: 收入减少导致现金流入下降，同时为维持生产可能增加采购支出，造成现金流净流出。
- **公司进行大规模股权投资（取得中盐碱业29%股权，投资23.2亿元）** -> 投资活动现金流大幅净流出（-22.28亿元，同比减少737.81%）: 对外投资支付大量现金，导致投资活动现金流显著恶化。
- **经营活动现金流失 + 投资活动现金流失** -> 公司增加银行借款（短期借款从0增至13.91亿元）: 为弥补经营和投资活动的现金缺口，公司通过借款筹资。
- **下游需求回落（玻璃日熔量下降）** -> 纯碱库存减少（期末库存同比减少76.58%）: 需求不足导致销售困难，但公司主动减产或调整库存策略，库存量大幅下降。
- **纯碱价格低位运行** -> 公司开展套期保值操作: 为对冲价格风险，公司利用期货锁定销售价格。

## 风险警告
核心风险：1）纯碱行业产能持续扩张与下游需求（尤其玻璃行业）疲软导致的供需失衡，使纯碱价格长期承压，公司主营盈利空间被严重压缩。2）公司为向产业链上游延伸投资天然碱项目（中盐碱业），短期内大幅增加投资支出和借款，导致现金流紧张，财务费用上升。3）若纯碱价格持续低迷，公司可能面临更大的资产减值压力（已计提固定资产减值）。4）公司对控股股东采购依赖度高（关联采购占采购总额69%），存在供应链集中风险。
