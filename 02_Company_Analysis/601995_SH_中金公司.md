# 601995.SH 深度透视

## 因果逻辑链
- **[A股日均成交额同比+63%至1.73万亿元]** -> [经纪及财富管理收入大增]: 市场交投极度活跃，直接驱动佣金及手续费收入增长。
- **[中资企业全球IPO融资规模同比+226%]** -> [投行业务收入同比+78%]: 公司作为中资企业全球IPO市场第一，直接受益于港股IPO热潮。
- **[权益市场大幅回暖（上证+18%，创业板+50%）]** -> [股票业务投资收益净额同比+101%]: 场外衍生品对冲持仓及自营权益投资公允价值大幅上升。
- **[美元资产安全性受质疑，中国资产重估]** -> [跨境业务收入同比+58%]: 国际资本流入A股/港股，公司QFII业务连续22年第一，跨境固收及股票业务受益。
- **[居民存款“搬家”与买方投顾转型]** -> [财富管理产品保有规模连续6年正增长]: 客户从储蓄转向金融资产，公司“中国50”等买方投顾产品规模超1300亿，盈利账户占比超99%。
- **[公司积极推进吸收合并东兴证券、信达证券]** -> [规模效应与协同预期]: 通过换股吸收合并，整合客户、网络与资本，旨在实现“1+2>3”的规模与协同效应。
- **[债券市场高波动震荡]** -> [固定收益业务收入同比-17%]: 利率上行与信用利差波动导致债券投资收益净额同比大幅下降68%。

## 风险警告
**核心风险在于对市场行情的强依赖性。** 2025年业绩暴增（净利润+72%）主要由A股日均成交额创历史新高（+63%）和权益市场大幅上涨驱动。一旦市场活跃度回落或出现趋势性下跌，经纪、股票投资、财富管理等核心收入将同步承压，业绩弹性极大，周期性特征显著。

**吸收合并整合风险不容忽视。** 公司正在推进吸收合并东兴证券、信达证券，涉及组织架构、文化、系统及人员的深度整合。若整合不及预期，可能拖累短期盈利能力，并带来商誉减值风险。同时，合并后净资本消耗加速，杠杆率已升至5.35倍，需关注监管指标压力。
