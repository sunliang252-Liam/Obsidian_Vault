# 300517.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧与项目定价下行]** -> [营业收入同比-44.29%]: 公司为保障经营稳健性，在利润与付款条件间审慎权衡，主动缩减合同承接，导致产量下降。
- **[产量不饱和与固定成本分摊]** -> [净利润同比-92.26%]: 产能较大但订单不足，固定成本无法有效摊薄，严重挤压利润空间。
- **[已完工项目工程款支付滞后]** -> [现金流管理压力增大]: 行业资金紧张导致应收账款回收周期拉长，公司被迫加强回款管理以维持经营。
- **[经营性现金流持续为正]** -> [短期生存能力尚可]: 尽管利润暴跌，但公司通过强化应收款管理，2025年经营活动现金流净额达2.06亿元，同比+57.03%。
- **[桥梁钢结构主业收入占比99.03%]** -> [业务高度集中，抗周期能力弱]: 公司收入几乎全部依赖单一业务，受行业景气度下行冲击直接且剧烈。
- **[毛利率持续下滑至11.82%]** -> [盈利基础被侵蚀]: 从2023年的20.83%降至2025年的11.82%，价格战与成本刚性共同导致盈利能力恶化。
- **[积极尝试多元化业务探索]** -> [寻求第二增长曲线]: 公司意识到主业天花板，开始在国家支持行业中寻找新赛道，但尚未形成实质贡献。

## 风险警告
**核心风险在于行业周期下行与公司业务单一性的致命叠加。** 传统基建投资放缓，行业产能过剩、价格战激烈，公司作为第二梯队的民营企业，在资金、资质上无法与国企第一梯队抗衡，只能被动接受低毛利、高垫资的项目。2025年营收腰斩、扣非净利润为负，已清晰表明其主业已进入“保生存”阶段，而非“谋发展”。

**应收账款回收是悬在头顶的达摩克利斯之剑。** 公司应收账款高达3.42亿元，占总资产24%，且已发生多起重大诉讼追讨工程款（如中铁五局、华川集团等）。虽然经营性现金流为正，但这建立在加强催收的基础上，一旦主要客户（前五大客户占收入66%）出现信用恶化或破产重整（如华川集团），将直接导致大额坏账，吞噬本已微薄的利润。
