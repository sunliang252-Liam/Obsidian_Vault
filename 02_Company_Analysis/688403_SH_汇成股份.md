# 688403.SH 深度透视

## 因果逻辑链
- **[可转债募投项目产能释放]** -> [营收增长18.79%]: 新扩产能逐步释放，客户订单增加，出货量提升，直接推动营收创历史新高。
- **[“两免三减半”税收优惠到期]** -> [净利润同比下降3.15%]: 自2025年起按12.50%税率缴纳所得税，叠加可转债利息计提导致财务费用激增160.86%，侵蚀了营收增长带来的利润。
- **[产品组合优化与结构调整]** -> [毛利率微降1.01个百分点]: 主动拓展大尺寸面板及OLED驱动芯片等高毛利产品，但新增设备折旧摊提进度快于产能爬坡，固定成本上升拖累毛利率。
- **[战略投资鑫丰科技]** -> [切入DRAM封测赛道]: 通过股权投资布局存储芯片封测，形成“显示+存储”双轮驱动格局，旨在打造第二增长曲线。
- **[研发投入首次破亿]** -> [巩固技术壁垒]: 研发费用同比增长31.63%，重点投向铜镍金/钯金新型凸块制程及车规级芯片封测，以应对金价上涨和客户降本需求。
- **[客户集中度仍高]** -> [经营依赖风险]: 前五大客户销售额占比68.87%，虽同比下降，但单一客户订单波动仍可能对公司业绩产生重大影响。
- **[经营现金流大幅改善]** -> [营运效率提升]: 经营活动现金流净额同比增长38.25%，主要得益于营收扩大及增加票据结算方式，优化了现金流管理。

## 风险警告
公司面临“增收不增利”的窘境，核心矛盾在于产能扩张带来的折旧压力与税收优惠到期。可转债募投项目转固后，2025年折旧费用增加约4836万元，而产能利用率尚未完全匹配，导致毛利率承压。同时，2025年起所得税率从0%跳升至12.5%，直接吞噬了利润增长空间。未来若下游需求放缓或竞争加剧导致价格战，利润可能进一步被压缩。

公司战略转型存在不确定性。通过投资切入存储封测领域，但该领域技术壁垒高、竞争格局由长电、通富微电等龙头主导，公司作为新进入者，技术储备和客户导入均需时间，短期内难以贡献业绩。此外，公司超过60%的收入来自境外客户（以中国台湾地区为主），且核心设备和材料依赖日本进口，地缘政治风险和汇率波动是持续的潜在威胁。
