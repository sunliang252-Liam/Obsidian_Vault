# 688788.SH 深度透视

## 因果逻辑链
- **[营收增长但持续巨亏]** -> [净利润-2.91亿]: 营收同比+21.17%，但研发费用率高达96.79%（2.76亿），管理费用、销售费用同步增长，叠加毛利率下降及资产减值，导致亏损扩大8.56%。
- **[研发投入吞噬利润]** -> [侵蚀盈利能力]: 公司维持高强度研发（芯片、智能无人系统），研发费用2.76亿远超营收2.85亿，是连续三年亏损的核心原因。
- **[客户高度集中]** -> [经营依赖风险]: 前五大客户（汇总口径）销售额占主营收入85.79%，且主要为军工集团，订单受最终用户年度采购计划波动影响显著。
- **[产品结构变化导致毛利率承压]** -> [综合毛利率下降]: 指挥控制及软件雷达产品订单增长，但细分产品结构变化（如增加元器件筛选费用）导致毛利率分别下降7.03和19.86个百分点。
- **[经营活动现金流大幅恶化]** -> [现金流风险]: 经营性现金流净额-2.11亿，同比-199.69%，主因采购支出、薪酬增加及回款下降，显示公司造血能力严重不足。
- **[芯片业务尚处投入期]** -> [短期无法贡献利润]: 子公司高芯思通亏损7649万元，新一代芯片虽完成调测但未形成规模收入，是拖累整体业绩的重要因素。
- **[在手订单支撑有限]** -> [未来收入不确定性]: 截至报告日，在手订单及备产通知约2.3亿元，但公司年营收已达2.85亿，订单覆盖度不足一年，后续增长动力存疑。

## 风险警告
科思科技面临的核心风险是**“研发投入黑洞”与“商业化变现困境”的恶性循环**。公司研发费用率连续三年超100%，2025年高达96.79%，但巨额投入并未转化为利润，反而导致连续三年巨亏且亏损额逐年扩大。芯片、智能无人等新业务尚处投入期，短期内无法贡献正向现金流，而传统主业（指挥控制、软件雷达）虽营收增长，但毛利率下滑，盈利能力减弱。若未来研发成果无法快速实现规模化销售，公司将面临持续“失血”的风险。

其次，公司经营高度依赖军工客户，前五大客户集中度超85%，订单受国家年度采购计划影响极大，业绩波动性高。同时，经营活动现金流净额大幅恶化至-2.11亿，而公司总资产仅20.2亿，若回款持续不畅，可能引发流动性危机。此外，公司应收账款高达8亿，占总资产近40%，尽管客户信用较好，但“同比例支付”结算条款可能导致回款周期延长，坏账风险不容忽视。
