# 000715.SZ 深度透视

## 因果逻辑链
- **[费用管控优化]** -> [净利润逆势增长13.77%]: 在营收下降2.26%的背景下，通过大幅压缩销售费用（-22.90%）和管理费用（-8.63%），实现利润增长。
- **[投资收益与公允价值变动]** -> [非经常性损益贡献利润]: 理财产品和永续债等金融资产贡献投资收益1667万元及公允价值变动收益298万元，成为利润的重要补充。
- **[百货业态高毛利]** -> [服务收入稳定盈利]: 服务业（物业租赁等）毛利率高达94.36%，以12.76%的收入占比贡献了稳定的利润来源，对冲零售主业下滑风险。
- **[核心商圈自有物业]** -> [低运营成本与资产安全垫]: 主力门店“中兴总店”为自有物业（21.84万平米），免除了高昂租金压力，资产价值稳固，是公司长期经营的基石。
- **[会员体系与数字化]** -> [精准营销与客户粘性]: 拥有超110万会员，通过CRM系统进行分层精准触达，有效提升复购率和消费转化，对抗线上分流。
- **[方大集团管理赋能]** -> [市场化机制提升效率]: 融入方大集团“变、干、实”文化，推行竞争和激励机制，精细化管理水平提升，是费用管控和效率提升的核心驱动力。
- **[消费渠道分流与竞争加剧]** -> [零售主业收入承压]: 线上消费渗透率提升及区域商业竞争加剧，导致公司百货零售收入同比下降2.92%，超市收入下降23.44%。

## 风险警告
**核心风险在于区域市场饱和与增长天花板。** 公司99.71%的收入集中于辽宁省，尤其是沈阳核心商圈，业务高度集中。在线上零售持续冲击和本地商业体量放大的背景下，公司百货零售收入已连续两年下滑，超市业态更是陷入亏损。公司2026年经营目标仅设定2.64%的增长，反映出管理层对区域市场增长乏力的清醒认知，缺乏外延式扩张的明确路径。

**第二大风险是控股股东的同业竞争承诺延期。** 控股股东方大集团旗下的一商集团在天津从事商业业务，与公司存在潜在同业竞争。该问题的解决承诺已延期至2028年，资产注入前景不明。若承诺无法履行，不仅存在监管风险，更可能限制公司未来的战略发展空间，尤其是在跨区域扩张方面。此外，公司大量资金用于购买理财产品，主业投资意愿不强，也侧面印证了扩张瓶颈。
