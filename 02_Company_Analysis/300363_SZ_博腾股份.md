# 300363.SZ 深度透视

## 因果逻辑链
- **[收入恢复增长]** -> [扭亏为盈]: 2025年营收34.20亿元，同比增长13.54%，规模化效应显现，带动整体毛利率提升约5个百分点至近30%，实现归母净利润9,634万元，成功扭亏。
- **[小分子原料药核心业务驱动]** -> [业绩基本盘稳固]: 小分子原料药收入30.92亿元，占比90%，同比增长约13%，是公司收入增长的主要来源，毛利率提升5.65个百分点至38.39%。
- **[新业务高速增长]** -> [第二增长曲线初现]: 新分子业务收入同比增长224%，细胞与基因治疗业务同比增长36%，合计收入占比提升至约9%，成为未来增长的重要驱动力。
- **[降本增效与费用管控]** -> [利润改善]: 在收入增长的同时，公司压实降本增效举措，四大费用合计同比下降约3%，研发费用同比下降20.95%，有效支撑了利润端的扭亏。
- **[国内市场高增长]** -> [市场结构优化]: 中国市场收入同比增长38.68%，收入占比提升至32%，毛利率提升14.14个百分点至6.43%，显示国内创新药市场回暖对公司业务的积极影响。
- **[新业务仍处亏损期]** -> [拖累整体盈利]: 小分子制剂、细胞与基因治疗、新分子三大新业务合计亏损约2.08亿元，虽同比减亏，但仍显著侵蚀公司整体利润，是盈利能力低于核心业务水平的主要原因。
- **[经营性现金流大幅改善]** -> [财务健康度提升]: 经营活动现金流量净额达7.57亿元，同比增长86.67%，远超净利润，表明公司收入质量高，回款能力增强，财务基础更加稳健。

## 风险警告
**核心风险在于新业务持续亏损与产能折旧的双重压力。** 尽管公司整体扭亏，但新业务（小分子制剂、CGT、新分子）合计亏损约2.08亿元，且新分子业务亏损同比扩大，主要系上海奉贤及外高桥基地新增折旧约1,467万元所致。公司固定资产账面价值高达28.91亿元，年折旧3.40亿元，若新业务市场开发不及预期，产能利用率不足，将导致运营成本增加和利润持续承压。

**另一重大风险是地缘政治与供应链重构带来的海外市场不确定性。** 公司海外业务收入占比约68%，且主要市场美国收入增长21%，但欧洲市场同比下降12%。全球宏观形势的不确定性、供应链本地化趋势以及潜在的贸易制裁，可能对公司以海外为主的业务模式造成冲击。此外，公司海外运营基地的全球化布局也增加了运营复杂性和合规成本。
