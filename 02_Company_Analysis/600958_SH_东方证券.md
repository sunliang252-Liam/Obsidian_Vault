# 600958.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度提升]** -> [财富管理收入增长]: 2025年A股日均成交额同比+62.69%，驱动公司经纪业务手续费及佣金净收入、融资融券利息收入大幅增长。
- **[自营投资策略成功]** -> [投资收益大幅增加]: 公司坚持“景气价值”与“多资产、多策略”思路，有效抓住权益市场上涨与债券市场波段机会，投资收益同比+38.08%。
- **[资管品牌效应与产品创新]** -> [资管规模与收入双升]: 东证资管“东方红”品牌及汇添富基金凭借优异业绩和爆款产品（如东方红盈丰FOF），推动管理规模同比+32.43%，贡献稳定收入。
- **[投行项目储备与执行能力]** -> [投行业务收入增长]: 公司完成国泰海通吸收合并等标杆性并购项目，股权融资主承销金额位列行业第11，债券承销总规模位列行业第8，驱动投行收入增长。
- **[期货业务领先地位]** -> [期货业务贡献稳定]: 东证期货代理成交量市占率和客户权益规模均位居行业前三，为集团贡献了稳定的收入和利润。
- **[客需业务转型深化]** -> [机构业务收入提升]: 场外衍生品业务实现月度盈利，FICC代客业务规模增长，做市业务收入同比增长超50%，共同推动机构及销售交易板块收入增长46%。
- **[信用减值损失减少]** -> [利润增厚]: 股票质押业务风险持续出清，根据预期信用损失模型计提的减值准备同比减少38.52%，直接增厚了净利润。

## 风险警告
公司业绩高度依赖市场行情，具有显著的周期性。2025年业绩爆发式增长（归母净利润+68.16%）主要得益于A股市场交投活跃和指数上涨。一旦市场转弱，交易量萎缩或出现大幅下跌，公司的经纪、自营、资管等核心业务收入将面临同步下滑的风险，业绩波动性极大。

信用风险是公司面临的另一大挑战。尽管报告期内股票质押业务风险有所出清，但公司融出资金余额同比+39.20%，规模快速扩张。若宏观经济下行或市场出现极端波动，融资客户的违约风险可能集中暴露，导致信用减值损失重新扩大，侵蚀利润。此外，衍生金融资产和负债规模同比暴增超过300%，虽然部分用于对冲，但复杂的金融工具本身也蕴含了模型风险和交易对手风险。
