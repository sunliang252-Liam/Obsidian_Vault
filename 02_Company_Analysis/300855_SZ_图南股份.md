# 300855.SZ 深度透视

## 因果逻辑链
- **[下游客户需求波动]** -> [铸造高温合金收入下降35.58%]: 核心军品客户采购节奏调整，直接拖累高毛利产品营收。
- **[子公司图南智能产能爬坡]** -> [净利润下降41.84%]: 中小零部件产线处于规模化转产初期，收入确认周期长，但运营成本（人员、折旧）已大幅增加，导致阶段性亏损。
- **[子公司图南智能备货与建设]** -> [经营活动现金流暴跌97.52%]: 为满足在手订单大量采购原材料，叠加资本开支持续投入，现金大量消耗。
- **[产业链延伸至中小零部件]** -> [全产业链优势巩固]: 从原材料熔炼到零部件加工的全流程覆盖，增强了客户粘性与配套能力。
- **[“两机专项”政策驱动]** -> [长期需求确定性高]: 国家政策支持航空发动机与燃气轮机国产化，为高温合金及零部件业务提供持续增长空间。
- **[军品定价机制]** -> [收入与业绩波动风险]: 部分合同采用暂定价格，最终审定价与暂定价的差异可能导致未来收入与利润的追溯调整。
- **[原材料价格波动]** -> [毛利率承压]: 电解镍、金属钴等主要原材料价格波动，若无法及时向下游传导，将侵蚀产品毛利率。

## 风险警告
**核心风险在于子公司图南智能的“成长阵痛”。** 公司2025年业绩大幅下滑，主因是子公司图南智能处于产能爬坡期，收入规模尚无法覆盖高昂的运营成本（人员、折旧），导致亏损并拖累合并报表。同时，为满足其订单需求，公司存货激增105%、经营活动现金流近乎枯竭，财务压力显著加大。若下游订单释放或收入确认节奏不及预期，公司可能面临持续的现金流紧张与盈利压力。

**另一关键风险是军品业务的波动性与定价不确定性。** 公司核心收入来源（铸造高温合金）受下游客户需求波动影响显著，2025年收入大幅下滑。同时，军品合同普遍采用暂定价格，最终审价结果存在不确定性，可能导致未来业绩出现非预期的调整。公司客户高度集中（前五大客户占58%），单一客户需求变化即可对公司经营产生重大影响。
