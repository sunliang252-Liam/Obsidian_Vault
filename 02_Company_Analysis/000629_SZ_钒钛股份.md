# 000629.SZ 深度透视

## 因果逻辑链
- **[钒钛产品价格大幅下跌]** -> [营收与净利润双降]: 2025年钒、钛产品平均价格同比分别下滑7.2%和11.7%，直接导致公司营业收入同比下降32.69%，归母净利润由盈转亏至-0.93亿元。
- **[钛白粉行业产能过剩与反倾销]** -> [钛产品板块业绩承压]: 国内钛白粉产能利用率仅77.3%，叠加欧亚、欧盟等地区反倾销导致出口量首次下滑，公司钛产品收入同比大降42.87%。
- **[业务经营模式调整]** -> [营收规模收缩]: 公司部分业务调整经营模式，叠加钛精矿代理销售规模变化，导致钛精矿收入同比骤降91.85%，显著拉低整体营收。
- **[资产减值损失激增]** -> [侵蚀利润]: 报告期内计提资产减值损失3.21亿元，较上年的0.48亿元大幅增加，是导致净利润由盈转亏的关键非经营性因素。
- **[控股股东提供稳定原料保障]** -> [成本与供应优势]: 控股股东攀钢集团掌控攀西两大矿区，为公司提供稳定的钛精矿和粗钒渣，确保生产连续性并部分对冲市场价格波动风险。
- **[全钒液流电池储能需求增长]** -> [新兴增长极]: 2025年储能领域对钒的需求增长迅速，公司与大连融科签订年度2万吨储能用钒原料供应框架协议，为钒产品开辟“能源金属”新赛道。
- **[研发投入聚焦降本与新品]** -> [长期竞争力构建]: 研发费用虽同比下降35.81%，但重点投向钙法提钒增效、高纯氧化钒降本及油墨专用钛白粉开发，旨在提升现有产品竞争力和优化产品结构。

## 风险警告
公司当前面临的核心风险是**周期性与结构性双重压力**。钒、钛产品价格与宏观经济及下游钢铁、房地产行业景气度高度相关，2025年价格大幅下跌已导致公司陷入亏损。更严峻的是，钛白粉行业产能过剩格局短期难以逆转，海外反倾销壁垒持续，公司钛产品板块的盈利能力面临长期挑战。此外，高达3.21亿元的资产减值损失暴露了公司在市场下行周期中的库存与资产价值风险。

另一个关键风险在于**对关联方的高度依赖与治理结构**。公司原料（钛精矿、粗钒渣）几乎全部来自控股股东攀钢集团，前五大供应商中关联方采购额占比高达68.81%，前五大客户中关联方销售额占比34.03%。这种深度捆绑虽保障了原料稳定，但也使公司在定价、经营决策上独立性受限，关联交易公允性需持续关注。同时，公司未分配利润为负且连续亏损，已无法进行现金分红，对股东回报构成实质性制约。
