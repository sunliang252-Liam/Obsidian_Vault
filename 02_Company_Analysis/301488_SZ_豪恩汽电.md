# 301488.SZ 深度透视

## 因果逻辑链
- **营收增长26.26%** -> **净利润下降24.68%**: 收入规模扩张，但毛利率下滑（汽车电子毛利率-4.54%）及费用激增（研发费用+43.95%，管理费用+34.14%）侵蚀利润。
- **研发费用增长43.95%** -> **短期利润承压**: 公司为布局智能驾驶、机器人、低空经济三大赛道，大幅增加研发人员（+28.77%）和项目投入，导致当期费用率上升。
- **存货激增165.35%** -> **资产减值风险**: 为应对订单增长大幅备货，但存货周转效率下降，导致计提存货跌价准备2101万元，成为利润最大拖累项（占利润总额-29.37%）。
- **经营活动现金流净额下降58.17%** -> **营运资金压力**: 营收增长伴随应收账款和存货大幅增加，购买商品支付的现金增速（+27.9%）远超营收增速，导致经营性现金流与净利润严重背离。
- **境内收入增长32.15%** -> **毛利率下降7.96%**: 国内汽车市场竞争加剧，公司为获取订单可能让利，导致境内业务毛利率显著下滑，而境外业务毛利率反而提升3.85%。
- **前五大客户集中度56.41%** -> **客户依赖风险**: 第一大客户贡献26.83%营收，公司业绩高度依赖少数核心整车厂，议价能力受限且面临单一客户订单波动风险。
- **机器人/低空经济业务起步** -> **第二增长曲线**: 公司已获得机器人感知产品量产交付和低空飞行器项目定点，但当前收入贡献极小，未来增长需验证。

## 风险警告
**增收不增利的盈利困境。** 2025年营收增长26.26%，但归母净利润却下滑24.68%，核心原因是毛利率承压（境内业务毛利率下降近8个百分点）和费用失控（研发费用增速44%，管理费用增速34%）。更危险的是，存货激增165%至5.9亿元，已导致2100万元的资产减值损失，若下游需求不及预期，减值风险将进一步放大。公司正处于“以利润换规模”的扩张期，但盈利能力恶化速度远超收入增速。

**现金流恶化与客户集中度双重风险。** 经营活动现金流净额仅3134万元，同比暴跌58%，与净利润严重背离，表明公司回款能力或营运效率出现问题。同时，前五大客户贡献56.41%营收，第一大客户占比26.83%，公司对核心客户的议价能力较弱，一旦主要客户切换供应商或自身销量下滑，将直接冲击公司业绩。在汽车行业价格战持续的背景下，这种“高依赖、低议价”的商业模式风险尤为突出。
