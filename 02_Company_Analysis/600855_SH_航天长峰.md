# 600855.SH 深度透视

## 因果逻辑链
- **[公共安全业务转型见效]** -> [营收增长7.74%，减亏0.74亿元]: 长峰科技边海空防业务新签合同额同比增长11%，实现扭亏为盈，拉动整体营收。
- **[红外光电与高端医疗装备收入下滑]** -> [整体盈利能力改善有限]: 军工电子红外光电业务受下游批产项目需求不足影响，高端医疗装备因ECMO取证延迟、市场开拓不及预期，新签合同额下降。
- **[ECMO产品注册取证延迟至2026年]** -> [高端医疗装备业务亏损扩大]: 核心产品ECMO未能按期上市销售，导致该板块收入为负（-865万元），成为最大拖累项。
- **[子公司航天柏克连续亏损]** -> [启动股权挂牌转让，聚焦主业]: 公司为回归航天防务主航道，剥离亏损的储能电源业务，终止相关募投项目。
- **[研发投入减少25.36%]** -> [短期费用压力缓解，但长期竞争力存疑]: 研发项目减少导致费用下降，但可能影响红外、电源、医疗等核心技术的迭代速度。
- **[信用减值损失与资产减值损失合计7.78亿元]** -> [持续侵蚀利润]: 应收账款坏账准备及合同资产减值准备计提规模巨大，反映下游客户回款困难及项目风险。
- **[母公司未分配利润为负]** -> [连续三年无法分红]: 2025年归母净利润-1.72亿元，母公司报表未分配利润-1.5亿元，不具备分红条件。

## 风险警告
**核心风险在于业务结构失衡与盈利能力的脆弱性。** 公司依赖公共安全业务（营收占比56.69%）的单一增长拉动整体，而军工电子（红外光电）和高端医疗装备两大板块同时陷入低迷，尤其是高端医疗装备收入为负，表明核心产品ECMO的产业化进程严重不及预期。这种“一荣不能遮百丑”的结构，使得公司整体抗风险能力极低，任何单一板块的波动都可能导致亏损加剧。

**财务风险高企，现金流与资产质量堪忧。** 公司连续三年巨额亏损，经营活动现金流持续为负（-0.15亿元），且应收账款与合同资产合计超10亿元，计提的信用及资产减值损失高达7.78亿元，表明下游客户（尤其是政府、军方）付款周期长、坏账风险高。同时，募集资金账户因合同纠纷被冻结，进一步暴露了公司在合同履约与资金管理上的内控短板。
