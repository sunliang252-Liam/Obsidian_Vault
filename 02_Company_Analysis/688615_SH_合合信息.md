# 688615.SH 深度透视

## 因果逻辑链
- **[C端产品MAU增长至1.9亿]** -> [C端收入同比增长28.11%]: 扫描全能王等核心产品用户基数扩大与付费转化率提升（累计付费用户同比+32.78%），直接驱动C端订阅收入增长。
- **[AI技术持续迭代（扫描全能王7.0、INTSIG DocFlow）]** -> [产品竞争力与客单价提升]: 多模态大模型、AIAgent等新技术赋能产品功能（如AI拍图翻译、文档处理Agent），增强了用户粘性与B端客户付费意愿。
- **[海外商业化布局深化]** -> [境外收入同比增长34.11%]: 针对海外市场优化产品功能（如电子签名、本地化证件扫描），推动海外用户增长与变现效率提升。
- **[销售费用同比增长37.88%]** -> [营收增长25.83%，但利润增速放缓]: 公司为抢占市场份额，大幅增加营销推广投入，导致销售费用增速显著高于营收增速，侵蚀了部分利润。
- **[研发投入持续高企（占营收29.17%）]** -> [维持技术领先与产品创新]: 高强度的研发投入（+19.64%）是公司保持多模态文本智能、知识图谱等核心技术优势的基础，但短期内对净利润形成压力。
- **[B端产品标准化能力提升]** -> [B端收入同比增长14.56%]: TextIn与启信慧眼等标准化产品覆盖超170家世界500强客户，通过“智能识别-规则校验-自动化处理”模式，实现跨行业复用，驱动B端业务稳健增长。
- **[高毛利商业模式（C端近90%，B端近70%）]** -> [经营活动现金流净额同比增长33.10%]: 轻资产的订阅制与标准化产品模式，带来强劲的现金流生成能力，为持续研发与市场扩张提供资金支持。

## 风险警告
**核心风险在于增长质量与盈利能力的背离。** 公司营收增长25.83%，但归母净利润仅增长13.39%，扣非净利润增速更是降至9.60%。核心原因是销售费用率大幅攀升（同比+37.88%），远超营收增速，表明公司为维持用户增长和市场份额，正付出高昂的获客成本。若未来竞争加剧导致获客效率持续下降，将严重侵蚀公司盈利空间，高毛利下的“增收不增利”趋势值得警惕。

**技术迭代与行业竞争风险是长期悬顶之剑。** AI行业技术更新极快，大模型、AIAgent等新范式层出不穷。公司虽在OCR和文本智能领域有深厚积累，但面临OpenAI、Google等巨头以及众多创业公司的激烈竞争。若公司未能持续引领技术方向，或新产品（如AIAgent）商业化不及预期，其技术壁垒和市场份额可能被快速削弱。此外，海外业务面临地缘政治、数据合规等多重宏观风险，任何重大变化都可能影响其全球化战略的推进。
