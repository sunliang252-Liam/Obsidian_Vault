# 920415.BJ 深度透视

## 因果逻辑链
- **[民航业复苏与国产化替代]** -> [营收结构优化]: 民航业持续复苏，叠加国产化替代政策，公司核心产品（如机组排班3.0）落地，推动系统集成业务收入增长13.26%，毛利率提升8.93个百分点。
- **[低空经济战略布局]** -> [新增长极初现]: 公司从“概念验证”到“订单落地”，推出低空起降场智能管控设备等产品，中标多个平台项目，为未来规模化商业落地奠定基础。
- **[AI大模型赋能]** -> [产品智能化升级]: 公司推出“智小*”系列智能体产品，构建“平台+智能体”新模式，提升产品竞争力，带动研发费用增长36.52%。
- **[亿迅信息业绩对赌失败]** -> [非经常性损益大增]: 亿迅信息未完成2025年业绩承诺，公司计提业绩承诺补偿款1,617.53万元，导致公允价值变动收益同比大增127.34%，归母净利润增长43.48%，但扣非净利润下降8.92%。
- **[毛利率持续提升]** -> [盈利能力增强]: 通过提升产品成熟度和可复用度，公司整体毛利率从2023年的38.51%提升至2025年的47.04%，连续两年改善。
- **[客户高度集中]** -> [经营依赖性强]: 前五大客户销售额占比59.94%，其中中国航空油料集团和中国航空集团合计占比超42%，客户集中度高，存在依赖风险。
- **[现金流稳健]** -> [财务安全性高]: 经营活动现金流净额连续两年超4,000万元，与净利润匹配良好，且期末货币资金大幅增加至2.29亿元，无短期借款，财务结构健康。

## 风险警告
**核心风险在于业绩的“含金量”问题。** 2025年归母净利润看似增长43.48%，但扣非净利润却同比下降8.92%，核心盈利能力的改善被非经常性损益（主要是亿迅信息业绩对赌补偿款）所掩盖。亿迅信息连续两年未完成业绩承诺，不仅导致公司计提大额长期股权投资减值，也使得其作为“多行业创收”战略布局的价值存疑，未来能否实现协同效应存在重大不确定性。

**另一重大风险是客户高度集中与行业依赖性。** 公司近60%的收入来自前五大客户，且高度依赖民航业。虽然民航业复苏为公司带来机遇，但行业成本压力（油价、地缘政治）、高铁竞争以及AI大模型在核心场景落地的挑战，都可能影响客户IT预算，导致公司收入波动。此外，低空经济作为新业务，尚处于商业化初期，其规模化落地速度和盈利能力仍需时间验证。
