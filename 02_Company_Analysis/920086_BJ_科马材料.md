# 920086.BJ 深度透视

## 因果逻辑链
- **[商用车市场回暖]** -> [营收增长10.93%]: 商用车产销同比增长超10%，带动公司核心客户订单量稳步提升，境内收入增长11.28%。
- **[T2干式挤浸工艺优化]** -> [毛利率提升至50.11%]: 高附加值T2产品稳定供应，叠加生产效率优化与单位能耗下降，毛利率同比提升2.72个百分点。
- **[产品结构向高端倾斜]** -> [净利润增速远超营收]: 高端材质干式摩擦片销售占比提升，叠加规模效应，归母净利润同比增长25.42%，显著高于营收增速。
- **[自由现金管理策略]** -> [投资收益大幅增长121.79%]: 利用闲置资金存入大额存单，利息收入增加，推动投资收益从159万增至352万。
- **[境外客户外汇管制风险]** -> [信用减值损失激增243%]: 部分境外客户因外汇管制预计无法回款，单项计提坏账，导致信用减值损失从78万升至269万。
- **[原材料预付款增加]** -> [预付款项飙升128.89%]: 橡胶、铜丝等大宗原材料采购增加，为锁定价格支付更多预付款，占用部分营运资金。
- **[上市服务费计提]** -> [其他应付款暴增1575%]: 2025年末计提券商、律师、会计师等上市服务费，导致其他应付款从74万升至1245万。

## 风险警告
**核心风险在于境外信用风险与单一产品依赖。** 公司信用减值损失同比暴增243%，根源在于部分境外客户因外汇管制无法回款。伊朗、俄罗斯等高风险地区出口占比近18%，若地缘政治或制裁升级，坏账风险可能持续扩大，侵蚀利润。同时，公司超93%收入依赖干式摩擦片，湿式纸基摩擦片尚处亏损爬坡期，若商用车技术路线突变或混合动力增速放缓，业绩将受重大冲击。

**成本端压力与增长可持续性存疑。** 直接材料成本占比超50%，铜丝、橡胶等价格波动无法完全转嫁客户。2025年营收增长10.93%主要依赖商用车周期性回暖，而非市场份额的显著提升。募投项目“干式挤浸技改”和“研发中心升级”尚未贡献增量，第二增长曲线（湿式摩擦片）仍处于小批量验证阶段，短期难以形成规模利润。
