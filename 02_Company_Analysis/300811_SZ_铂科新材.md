# 300811.SZ 深度透视

## 因果逻辑链
- **[AI算力爆发驱动芯片电感需求]** -> [第二增长曲线成型]: AI服务器GPU/ASIC芯片供电需求爆发，公司芯片电感产品凭借小型化、耐大电流优势，成功切入MPS、伟创力等头部客户，实现从材料商向泛半导体元件商的跨越。
- **[金属软磁粉芯稳健增长]** -> [基本盘稳固]: 通讯电源、UPS及新能源汽车领域受益于全球数据中心建设和新能源车渗透率提升，收入高速增长，抵消了主动放弃低价空调市场的负面影响。
- **[金属软磁粉末进口替代]** -> [打开新增长空间]: 自主研发的铁硅铬粉通过头部客户认证，凭借高Bs和防锈性能实现进口替代，非晶纳米晶粉末进入量产放量阶段，拓宽高频应用市场。
- **[“梧桐树”平台化战略]** -> [技术复用与产品衍生]: 以金属软磁粉末制备平台为“沃土”，向下游衍生出粉芯、芯片电感、轴向磁通电机磁芯等多条产品线，实现从材料到元器件的全链条覆盖。
- **[全球化布局加速]** -> [海外收入爆发]: 设立泰国子公司、香港合资公司，2025年海外收入同比增长221.3%，有效分散单一市场风险，并捕捉全球AI与新能源机遇。
- **[人效提升与组织变革]** -> [经营效率优化]: 推行“人效提升年”，打通生产、财务、人力数据联动，管理费用同比下降7.99%，销售费用同比下降6.16%，在营收增长下实现费用管控。
- **[研发投入高强度]** -> [技术壁垒持续加高]: 研发费用同比增长29.38%，聚焦宽温域高Bs、高频低损材料，以及TLVR电感、集成式电感等新品，为未来3-5年技术迭代储备动能。

## 风险警告
**1. 下游需求波动与客户集中风险。** 公司营收43.67%来自前五大客户，且芯片电感业务高度依赖AI服务器资本开支。若全球AI算力投资放缓、或主要客户（如MPS、伟创力）切换供应商，将对公司业绩造成剧烈冲击。光储业务虽保持高市占率，但行业已进入价格竞争阶段，毛利率承压。

**2. 产能扩张与全球化管理风险。** 公司正处于新型高端一体成型电感、泰国工厂、新粉体工厂的密集建设期，资本开支大幅增加（投资活动现金净流出3.71亿元）。若产能爬坡不及预期、良率提升受阻，或海外团队搭建与跨文化管理出现摩擦，将导致交付延迟和成本失控，侵蚀利润。
