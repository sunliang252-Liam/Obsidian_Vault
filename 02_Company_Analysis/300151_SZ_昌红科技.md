# 300151.SZ 深度透视

## 因果逻辑链
- **[医疗耗材大客户项目落地]** -> [收入增长]: 罗氏、西门子等全球龙头订单放量，驱动医疗板块收入同比增长4.47%，成为唯一正增长主业。
- **[智能制造主业下滑]** -> [整体营收承压]: 智能制造产品收入同比-8.48%，拖累总营收下降4.34%，显示传统OA业务增长乏力。
- **[新产能爬坡与费用前置]** -> [净利润大幅下滑]: 浙江柏明胜、鼎龙蔚柏等新基地处于投产初期，管理费用同比+23.63%，侵蚀利润，归母净利润同比-36.66%。
- **[半导体耗材突破]** -> [打开第二增长曲线]: FOUP产品获国内主流晶圆厂批量订单，鼎龙蔚柏进入主流供应链，半导体业务从0到1。
- **[全球化产能布局]** -> [抵御地缘风险]: 越南二厂建设推进，计划3-5年建欧美基地，以本地化生产对冲关税与供应链风险。
- **[“一站式”解决方案能力]** -> [客户粘性增强]: 从模具到自动化产线到注塑的全链条服务，是进入罗氏、西门子等19家全球巨头供应链的核心壁垒。
- **[研发投入资本化率为零]** -> [财务稳健]: 研发投入全部费用化，不虚增利润，体现审慎会计原则，但短期压制利润表现。

## 风险警告
**核心风险在于新业务放量不及预期与费用侵蚀。** 公司正处于从传统OA模具向高壁垒医疗耗材、半导体载具转型的关键期。浙江柏明胜、鼎龙蔚柏等新基地尚在产能爬坡，管理费用、折旧摊销大幅增加，是2025年利润下滑36.66%的主因。若医疗大客户（如西门子）项目量产进度或订单规模低于预期，半导体FOUP产品验证周期过长，公司可能面临“增收不增利”甚至利润持续承压的局面。

**客户集中度与汇率波动构成双重外部风险。** 前五大客户销售占比高达60.65%，且以海外巨头为主，单一客户订单波动将显著影响业绩。同时，公司76%收入来自境外（以美元、欧元结算），人民币汇率升值将直接冲击毛利率与汇兑损益。尽管公司开展远期结售汇，但无法完全对冲波动风险。
