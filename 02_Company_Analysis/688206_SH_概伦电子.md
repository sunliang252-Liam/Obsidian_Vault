# 688206.SH 深度透视

## 因果逻辑链
- **[EDA产品竞争力提升]** -> [收入增长15.41%]: 设计类EDA收入同比+29.78%，制造类EDA收入同比+11.71%，驱动主营业务收入增至4.76亿元。
- **[非经常性损益大幅增加]** -> [净利润扭亏为盈]: 公允价值变动收益、政府补助及投资收益合计约1.04亿元，使归母净利润从-9597万转为+3424万。
- **[扣非净利润持续亏损]** -> [核心盈利能力仍弱]: 剔除股份支付后扣非净利润仍为-5373万元，表明主营业务的盈利造血能力尚未根本性改善。
- **[高研发投入与股份支付]** -> [压制当期利润]: 研发费用占营收67.48%，叠加股权激励摊销，是导致扣非净利润持续为负的核心原因。
- **[“EDA+IP”并购战略]** -> [重塑业务模式]: 拟收购锐成芯微100%股权，旨在构建“EDA工具+半导体IP”双引擎，从工具商向平台商转型。
- **[境内市场增长强劲]** -> [国产替代逻辑兑现]: 境内主营业务收入同比+19.38%，占比达76.24%，显示国内客户导入加速。
- **[经营活动现金流大幅转正]** -> [收入质量改善]: 经营现金流净额从-4652万跃升至+1.38亿元，主要系销售回款增加，表明收入变现能力增强。

## 风险警告
**核心风险在于盈利的“虚胖”与“实亏”并存。** 公司2025年净利润虽扭亏，但完全依赖非经常性损益（公允价值变动、政府补助等），扣除非经常性损益后仍亏损超5900万元。这表明公司主营的EDA业务尚未形成可持续的盈利闭环，高额的研发投入（占收入67.48%）和股份支付费用持续侵蚀利润，若未来非经常性损益波动或减少，公司将重回亏损状态。

**另一重大风险是并购整合的不确定性。** 公司正通过发行股份收购锐成芯微，向“EDA+IP”平台转型。但EDA与IP的协同效应能否如期实现、整合过程中的管理成本与文化冲突、以及标的资产的估值与业绩承诺风险，均存在较大不确定性。若整合失败，不仅无法带来预期增量，反而可能拖累现有业务，并形成新的商誉减值风险。
