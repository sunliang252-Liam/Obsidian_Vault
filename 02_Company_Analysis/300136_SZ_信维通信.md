# 300136.SZ 深度透视

## 因果逻辑链
- **[产品结构优化，淘汰低毛利产品]** -> [毛利率提升至22.79%]: 公司主动淘汰低毛利率产品，扩大高附加值新产品营收占比，推动整体盈利水平提升。
- **[第二增长曲线业务规模化落地]** -> [新兴业务收入快速增长]: 商业卫星通信、智能汽车、AI终端等新赛道业务进入量产阶段，成功切入全球低轨卫星产业链高价值环节，成为重要增量引擎。
- **[全球大客户平台与深度绑定]** -> [营收稳健增长1.90%]: 凭借稳定的品质与有竞争力的产品，与北美大客户等全球头部企业保持深度合作，持续导入新项目，支撑收入规模。
- **[基础材料与基础技术的高强度研发投入]** -> [技术护城河与产品领先]: 持续投入LCP薄膜、磁性材料、陶瓷材料等核心材料研发，构建“材料-零部件-模组”一站式能力，形成差异化竞争优势。
- **[全球化产能与研发布局]** -> [对冲贸易风险与提升响应速度]: 越南、墨西哥等海外生产基地扩建，深圳新总部建设，有效应对国际贸易不确定性，并为全球客户提供高效服务。
- **[精益运营与现金流管理]** -> [经营性现金流大幅增长57.01%]: 公司致力于提升精益运营能力，营运资金使用效率提升，销售回款增加，现金流质量显著改善。
- **[高端MLCC与被动元件国产替代]** -> [填补国内技术空白]: 针对AI服务器等场景完成高端MLCC系列化布局，多款产品通过大客户认证并实现量产，受益于国产替代政策。

## 风险警告
**核心风险在于客户集中度与行业技术迭代的双重压力。** 公司前五大客户销售额占比高达50.03%，对全球头部消费电子及通信厂商依赖度极高。任何大客户订单波动、产品切换或供应链调整，都将对营收和利润产生剧烈冲击。同时，射频通信行业技术迭代极快（5G-A/6G、卫星通信等），若公司在新材料、新工艺上的研发投入不能及时转化为量产产品，或无法跟上客户下一代产品需求，将面临竞争力弱化与市场份额下滑的风险。

**第二增长曲线的不确定性是另一大隐患。** 尽管商业卫星通信、智能汽车等新业务已实现突破，但规模化放量仍需时间，且面临来自国际巨头（如村田、TDK）的激烈竞争。公司海外收入占比高达65.27%，汇率波动（尤其是美元/人民币）对毛利率和净利润的侵蚀风险不可忽视。此外，公司资产负债率虽降至41.43%，但短期借款与长期借款合计仍超21.5亿元，持续的资本开支（在建工程增加）和研发投入对现金流构成长期压力。
