# 002820.SZ 深度透视

## 因果逻辑链
- **[消费需求疲软与行业竞争加剧]** -> [直营与经销渠道收入双降]: 消费者购买力不足及休闲食品行业低价内卷，导致公司核心的天津地区直营店客单价与客流量下滑，经销渠道亦受冲击。
- **[电商渠道高增长但无法弥补传统渠道缺口]** -> [整体营收下降4.93%]: 线上直销收入虽同比增长54.26%，但体量较小，无法对冲占收入86%的天津地区线下渠道8.64%的降幅。
- **[电商与品牌投入激增]** -> [销售费用率大幅攀升]: 为抢占线上份额和提升品牌声量，电商运营服务费及推广费同比暴增113.61%，广告设计费亦持续投入，侵蚀利润。
- **[新增固定资产折旧及信息化摊销]** -> [管理费用刚性增长]: 2024年末购置的综合楼及新建办公楼带来的折旧、房产税，叠加SAP系统服务费，导致管理费用同比增长24.24%。
- **[收入下降与费用刚性增长的双重挤压]** -> [净利润由盈转亏]: 营收下滑叠加费用率显著上升，导致2025年归母净利润亏损2452.53万元，同比由盈转亏。
- **[产品结构变化与成本分摊]** -> [毛利率微降]: 销量下降导致单位固定成本上升，同时高毛利的礼品类产品收入占比下降，共同拖累整体毛利率同比下降1.03个百分点。
- **[海外业务尚处投入期]** -> [短期无法贡献利润]: 海外事业部设立、HALAL认证及前期市场拓展费用已产生，但业务尚未形成规模收入，对当期业绩构成负向拖累。

## 风险警告
**核心风险在于“单一市场依赖”与“投入产出错配”的恶性循环。** 公司超80%收入依赖天津市场，本地消费疲软直接导致基本盘动摇。为突破地域限制，公司被迫加大电商、品牌及全国化布局投入，但这些战略性投入（如SAP系统、新办公楼折旧、海外拓展）在短期内无法转化为有效收入，反而因刚性费用激增，在营收下滑时对利润造成毁灭性打击，形成“越投入、越亏损”的困局。

**另一重大风险是“老字号”品牌在渠道变革中的边缘化。** 面对零食量贩店等新业态的冲击，公司直营店模式（高租金、高人工）成本劣势凸显。尽管电商增长迅猛，但高额的流量成本与低价竞争使其盈利能力存疑。若公司无法在“质价比”和“年轻化”上实现有效突破，其传统特产礼品属性将难以支撑未来增长，市场份额可能被更灵活、更具价格优势的新兴品牌持续蚕食。
