# 600793.SH 深度透视

## 因果逻辑链
- **[收购醋纤公司67%股权]** -> [归母净利润扭亏为盈]: 醋纤公司2025年实现净利润2.22亿元，超额完成业绩承诺（1.55亿元），成为公司核心利润来源，直接驱动归母净利润从-1.28亿转为+0.27亿。
- **[新增瓦楞纸箱业务]** -> [收入结构多元化]: 金竹新材料贡献营收2.60亿元、归母净利润0.32亿元，开辟了传统造纸外的第二增长曲线。
- **[全链条降本增效]** -> [毛利率显著提升]: 纸制品毛利率从-0.73%提升至9.93%（+10.64pct），化学纤维毛利率从32.45%提升至40.70%（+8.25pct），有效对冲了纸价低位运行的压力。
- **[醋纤公司收回关联方资金]** -> [经营现金流大幅改善]: 经营活动现金流净额同比+41.44%至5.19亿元，主要系收回存放于原股东普什集团的资金集中管理款。
- **[母公司持续亏损]** -> [无法进行现金分红]: 母公司未分配利润为-4.15亿元，尽管合并层面盈利，但母公司层面存在巨额未弥补亏损，限制了分红能力。
- **[竹基新材料与醋纤新材料双轮驱动]** -> [战略转型路径清晰]: 公司明确从传统竹浆造纸向绿碳特种生物基新材料产业集团转型，莱赛尔纤维、竹浆模塑等项目取得阶段性进展。

## 风险警告
**核心风险在于母公司造血能力严重不足，盈利高度依赖子公司。** 母公司2025年净利润为-1.36亿元，且累计未分配利润达-4.15亿元，表明传统造纸主业在行业“量增利减”的背景下持续承压。公司整体盈利几乎完全依赖醋纤公司（净利润2.22亿）和金竹新材料（净利润0.53亿），一旦子公司业绩波动或关联交易条款变化，公司盈利根基将面临动摇。

**业绩承诺到期与高负债运营构成双重压力。** 醋纤公司2025-2027年业绩承诺期后，若行业竞争加剧或下游需求（如香烟过滤嘴市场）萎缩，其高利润贡献的可持续性存疑。同时，公司总负债30.57亿元，资产负债率高达86.3%，短期借款同比+173.85%，在建工程同比+2942.50%，表明公司正通过高杠杆进行产能扩张，财务费用和偿债压力将持续侵蚀利润。
