# 002428.SZ 深度透视

## 因果逻辑链
- **[锗价高位震荡回落，成本增速超过售价]** -> **增收不增利**: 2025年国内锗价回调，但全年均价仍高于上年，推动营收增长38.89%；然而，原料成本上涨更快，导致综合毛利率下降，归母净利润同比下滑62.06%。
- **[低轨卫星星座密集部署]** -> **光伏级锗产品爆发**: 受益于中美等国低轨卫星组网需求，太阳能电池用锗晶片销量同比大增75.04%，成为营收增长的核心驱动力。
- **[AI算力与数据中心建设]** -> **光纤与化合物半导体需求回暖**: AI算力建设拉动光纤用四氯化锗销量增长49.50%；光通信市场景气度提升，推动磷化铟晶片销量同比大增73.77%。
- **[锗价上涨引发材料替代]** -> **红外级锗产品销量萎缩**: 锗价高位运行加速了硫系玻璃等替代材料在红外中低端市场的渗透，导致红外级锗产品（毛坯及镀膜镜片）销量同比下降22.77%。
- **[子公司少数股东权益存在回购义务]** -> **财务费用激增**: 对子公司云南鑫耀的少数股东权益确认金融负债，本期摊销未确认融资费用2,564万元，导致财务费用同比大增65.67%，严重侵蚀利润。
- **[研发投入持续高增]** -> **短期利润承压，长期技术储备**: 研发费用同比增加36.50%，主要用于大尺寸磷化铟、砷化镓等新产品开发，虽短期拖累业绩，但为未来高端化转型奠定基础。
- **[应收账款与存货双增]** -> **经营现金流大幅恶化**: 营收增长导致应收账款增加，同时为应对订单增加备货，存货上升，共同导致经营活动现金流净额为-1.87亿元，同比恶化501.02%。

## 风险警告
公司面临“增收不增利”的典型困境。核心风险在于成本端失控：锗原料价格高企导致成本增速远超售价，严重挤压毛利率。同时，子公司少数股东权益的或有回购义务带来巨额财务费用，是吞噬利润的“黑洞”。若锗价持续回调而成本无法同步下降，公司盈利能力将进一步承压。

另一个重大风险是需求结构失衡与替代威胁。虽然光伏和光纤需求强劲，但红外这一传统主力市场正因材料替代而萎缩，公司对新兴领域的依赖度急剧升高。此外，化合物半导体材料面临国际巨头和国内新进入者的双重竞争，产品认证周期长，市场开拓存在不确定性。公司现金流已亮红灯，高额的资本开支和运营资金需求可能加剧财务压力。
