# 000514.SZ 深度透视

## 因果逻辑链
- **[房地产结转规模大幅增加]** -> [营业收入同比增长87.34%]: 回兴缘香醍三期竣工交付及贯金和府一期大宗资产包销售，推动住宅销售收入同比暴增171.08%。
- **[转让朗福公司1%股权丧失控制权]** -> [确认非经常性投资收益2.45亿元]: 子公司转为联营企业，剩余股权按公允价值重新计量，形成巨额一次性收益，是公司扭亏为盈的核心驱动力。
- **[根据税收新规计提土地增值税]** -> [税金及附加同比暴增447.60%]: 一次性补提土地增值税1.01亿元，严重侵蚀主营业务利润，导致扣非净利润仍为负值。
- **[计提存货跌价准备]** -> [资产减值损失1.01亿元]: 房地产市场持续低迷，公司对存量项目计提大额减值，反映项目去化压力和资产价值缩水风险。
- **[石黄隧道收费权2026年7月到期]** -> [未来每年将减少约5200万元稳定收入]: 该业务年均贡献稳定现金流，到期后将对公司营业收入和利润构成直接且重大的负面影响。
- **[销售回款增加]** -> [经营活动现金流净额同比大增150.20%]: 得益于房地产项目集中交付和销售回款，公司现金流状况显著改善，但可持续性存疑。
- **[向控股股东重庆城投借款]** -> [维持资金周转]: 公司频繁向控股股东借款（报告期末余额5亿元），依赖关联方输血以缓解资金压力，财务独立性存疑。

## 风险警告
公司2025年账面净利润扭亏为盈，但核心驱动力是转让子公司股权产生的2.45亿元非经常性收益。剔除该收益后，扣非净利润仍亏损1.36亿元，主营业务（房地产开发）在计提大额土地增值税和存货跌价准备后，实际盈利能力堪忧。更严峻的是，贡献稳定现金流的石黄隧道收费权将于2026年7月到期，届时公司将永久失去每年约5200万元的收入来源，对基本盘构成重大打击。

公司高度依赖控股股东重庆城投的借款维持运营，报告期末借款余额达5亿元，财务独立性较弱。同时，公司存量土地储备（计容面积23.93万㎡）和在建项目规模有限，在重庆房地产市场持续低迷（2025年成交面积同比下跌21%）的背景下，未来收入增长缺乏明确支撑。公司正推进向特定对象发行股票，但方案历经多次修订，能否成功落地及何时落地存在重大不确定性。
