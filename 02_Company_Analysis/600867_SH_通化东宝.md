# 600867.SH 深度透视

## 因果逻辑链
- **[胰岛素集采续约A类中标]** -> [营收增长46.66%]: 公司全线胰岛素产品以A/A1类中选，获得更高采购量分配，推动胰岛素类似物销量同比增幅超100%，产品结构升级。
- **[转让特宝生物股份]** -> [净利润暴增至12.19亿]: 出售特宝生物5.70%股权，确认投资收益约10.99亿元，是归母净利润扭亏为盈的核心非经常性因素。
- **[集采降价压力]** -> [毛利率下降]: 尽管销量大增，但集采导致产品销售单价降低，生物制品毛利率同比下降4.26个百分点，扣非净利润仅3.75亿元。
- **[研发管线推进]** -> [研发费用增长68.29%]: 司美格鲁肽、德谷胰岛素利拉鲁肽等进入III期临床，GLP-1/GIP双靶点创新药进入II期，研发投入总额占营收17.16%。
- **[海外市场拓展]** -> [海外收入增长97%]: 门冬胰岛素美国BLA获FDA受理、欧盟MAA获EMA受理，利拉鲁肽在秘鲁获批，海外业务成为重要增长极。
- **[员工持股计划]** -> [绑定核心团队]: 2025年推出两期员工持股计划，将核心团队利益与公司长期发展绑定，激发积极性。

## 风险警告
**核心风险在于业绩的可持续性。** 2025年归母净利润暴增主要依赖出售特宝生物股份的一次性收益（约11亿元），扣除非经常性损益后净利润仅为3.75亿元，且毛利率因集采持续承压。公司真实盈利能力并未同步改善，未来若无新的重磅产品放量或资产出售，业绩将面临大幅回落压力。

**集采政策与研发不确定性并存。** 胰岛素集采续约价格下降已对毛利率造成侵蚀，未来若集采规则进一步趋严或公司未能持续中标，将对收入构成重大威胁。同时，公司研发管线虽丰富，但GLP-1/GIP双靶点、口服小分子等创新药均处于早期临床阶段，研发失败或上市后竞争格局恶化的风险不容忽视。
