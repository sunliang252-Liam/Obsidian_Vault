# 600259.SH 深度透视

## 因果逻辑链
- **[稀土价格中枢上移]** -> [扭亏为盈]: 氧化镨钕全年均价同比上涨25%，公司抓住市场机遇，实现归母净利润1.28亿元，同比增加4.26亿元。
- **[贸易业务战略性收缩]** -> [营收大幅下降]: 主动缩减低毛利率大宗金属贸易规模，商业收入同比下降66.33%，导致总营收下降53.80%。
- **[大宝山矿投资收益增加]** -> [利润核心支撑]: 参股企业大宝山矿稳产高产，按权益法确认投资收益约2.7亿元，成为公司利润的主要来源。
- **[存货跌价损失减少]** -> [扣非净利润转正]: 稀土价格上涨使存货跌价准备大幅减少，叠加销售毛利增加，扣非净利润从-3.12亿元转为+1.59亿元。
- **[法人压减与亏损治理]** -> [资产结构优化]: 完成嘉禾、大埔等公司吸收合并，石人嶂、福益乐进入破产重整，有效遏制“失血点”，减轻历史包袱。
- **[磁材产能爬坡与降本]** -> [减亏显著]: 晟源公司毛坯产量同比增长223%，毛坯成本同比下降41%，全年利润总额同比减亏超3000万元。
- **[现金流大幅改善]** -> [经营质量提升]: 加大存货销售收款并强化票据结算，经营活动现金流净额从-0.05亿元跃升至9.27亿元。

## 风险警告
**核心风险在于对稀土价格的高度依赖与参股企业利润的不可持续性。** 公司2025年扭亏主要得益于稀土价格中枢上移，而非自身主业的内生性增长。一旦稀土价格回调，公司盈利能力将迅速承压。同时，公司约2.7亿元的投资收益来自参股的大宝山矿，占利润总额比例极高，若该矿产量或价格出现波动，将对公司业绩造成重大冲击。

**资产质量与历史包袱仍是长期隐患。** 尽管公司通过破产重整等方式处置石人嶂、福益乐等亏损子公司，但和利公司仍处于停产状态，新丰公司净资产为负，晟源公司虽减亏但仍未盈利。此外，公司因历史遗留问题面临多起诉讼，涉及金额较大，存在潜在的资产减值与赔偿风险。
