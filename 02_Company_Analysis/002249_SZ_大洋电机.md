# 002249.SZ 深度透视

## 因果逻辑链
- **[全球化产能布局]** -> [对冲贸易壁垒风险]: 在墨西哥、越南、泰国、摩洛哥等地设立工厂，灵活调配产能以应对不同区域关税政策，保障海外业务稳定性。
- **[家电“以旧换新”政策]** -> [BHM业务收入稳定]: 政策刺激空调等品类更新换代需求，抵消了行业整体零售下滑对上游电机业务的冲击。
- **[新能源汽车渗透率突破50%]** -> [动力总成业务增长]: 新能源车销量持续增长，带动公司电驱动总成及增程器发电机等产品需求，2025年该业务收入同比增长4.35%。
- **[车辆旋转电器业务协同]** -> [业绩创历史新高]: 佩特来与杰诺瑞深化研发、制造、市场端整合，并通过精益生产和自动化降本增效，实现收入与利润双增长。
- **[持续股权激励与员工持股]** -> [核心人才稳定与创新]: 针对核心研发人员推出“领航计划”等激励，绑定长期利益，支撑新能源汽车及氢能等前沿技术研发。
- **[研发投入聚焦高效与新兴领域]** -> [产品竞争力提升]: 研发投入同比增长17.44%，重点投向800V碳化硅控制器、扁线电机、具身智能关节模组等，推动产品向高附加值升级。
- **[H股上市推进]** -> [国际化资本运作平台]: 申请香港联交所主板上市，旨在增强境外融资能力，提升治理透明度，为全球化战略提供资本支持。

## 风险警告
**核心风险在于新业务拓展的不确定性与国际化管理挑战。** 公司前瞻布局的氢燃料电池（PEMFC、SOC）及具身智能机器人业务仍处于研发或早期验证阶段，尚未形成销售收入。这些领域技术路线尚未完全成熟，产业化周期长，且高度依赖政策支持与产业链协同，未来能否成功商业化并贡献业绩存在重大不确定性，短期内将持续消耗公司现金流。

**另一重大风险是国际贸易环境恶化与商誉减值。** 公司海外收入占比近46%，且在美国、欧洲等地有重要布局。全球贸易保护主义抬头、地缘政治冲突及汇率剧烈波动，可能直接冲击公司成本控制、市场准入和利润稳定性。此外，过往并购（如上海电驱动）积累的较大规模商誉，若未来宏观经济或行业竞争加剧导致并购标的业绩不达预期，将面临商誉减值风险，直接侵蚀利润。
