# 603887.SH 深度透视

## 因果逻辑链
- **[IDC综合解决方案订单集中交付]** -> [营收暴增138%]: 2025年公司完成大量IDC系统集成项目（如河南空港、安徽芜湖、宁夏中卫等），推动营收从16.2亿飙升至38.6亿，但低毛利项目占比高，导致毛利率下滑4个百分点。
- **[AI算力需求爆发驱动智算中心建设]** -> [IDC业务订单激增]: AI大模型训练需求推动运营商及互联网企业大规模投建智算中心，公司作为全产业链服务商，新签中国移动呼和浩特、沪太智慧云谷等重大合同，在手订单超百亿。
- **[传统桩基业务收缩与应收账款清收]** -> [资产结构优化与现金流改善]: 公司停止新签桩基业务，通过诉讼等手段回收应收账款2.62亿元，存量应收净值降至1.17亿元，释放了被占用的资金，经营活动现金流净额增至3.76亿元。
- **[高杠杆扩张与财务费用压力]** -> [侵蚀利润]: 为支撑IDC项目投资，公司大幅增加长期借款（+164%），资产负债率升至71%，全年利息费用高达1.27亿元，是导致合并报表亏损的核心原因之一。
- **[可转债摘牌与会计估计变更]** -> [财务费用下降]: 2024年末可转债摘牌，2025年起不再计提相关利息，财务费用同比下降16.4%；同时公司将部分设备折旧年限从10年调整为10-15年，缓解了当期利润压力。
- **[大额资产减值与信用减值]** -> [持续亏损]: 尽管IDC主业盈利，但公司仍需计提1.08亿信用减值损失和0.56亿资产减值损失（主要为应收账款和合同资产），合计1.64亿，导致全年归母净利润仍为-0.67亿。
- **[客户高度集中与议价能力弱]** -> [毛利率承压]: 公司业务高度依赖三大运营商，前五名客户销售额占比高达73.38%，在项目承接中议价能力较弱，导致IDC综合解决方案毛利率同比下降4个百分点。

## 风险警告
**核心风险在于高杠杆下的流动性危机与盈利能力的严重错配。** 公司资产负债率已飙升至71%，长期借款一年内暴增164%，利息支出高达1.27亿元，远超IDC主业贡献的利润。这种“以债养建”的模式极度脆弱，一旦融资环境收紧或项目回款不及预期，公司将面临巨大的偿债压力。虽然营收暴增，但增收不增利，毛利率持续下滑，说明公司并未建立起可持续的盈利护城河。

**第二大风险是客户集中度过高带来的经营脆弱性。** 公司严重依赖三大运营商，前五大客户销售额占比超73%，且合同中公司往往难以主张单方面终止合作的违约权利。这种“大客户依赖症”不仅压制了议价能力和毛利率，更使得公司业绩高度受制于下游客户的资本开支节奏。若运营商因自身战略调整或AI投资回报不及预期而缩减开支，公司订单将面临断崖式下跌。此外，大量在手合同（如呼和浩特项目）尚未实施，未来收入确认存在不确定性。
