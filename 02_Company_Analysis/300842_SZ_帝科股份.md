# 300842.SZ 深度透视

## 因果逻辑链
- **[白银价格大幅上涨]** -> [归母净利润巨亏2.76亿]: 公司为对冲银价风险持有白银期货和租赁，银点快速上涨导致公允价值变动损失4.4亿元，完全吞噬主业利润。
- **[N型TOPCon电池技术领先]** -> [光伏浆料收入增长15.56%]: 公司作为TOPCon激光增强烧结金属化浆料龙头，持续引领技术迭代，出货量行业领先。
- **[收购浙江索特（原杜邦Solamet®）]** -> [强化研发与全球化布局]: 并购带来294项授权发明专利、全球化产能和客户资源，巩固技术护城河。
- **[收购江苏晶凯]** -> [开辟存储芯片第二主业]: 实现“应用性开发设计—晶圆测试—封测”一体化，切入高景气DRAM市场，收入同比增长574.63%。
- **[银粉采购全额预付+客户银票回款]** -> [经营现金流承压]: 销售回款滞后于采购付款，导致经营现金流净额6.68亿，远低于扣非净利润1.63亿。
- **[光伏行业产能过剩与价格战]** -> [毛利率下滑]: 下游电池片厂商降本压力传导，光伏材料毛利率同比下降2.05个百分点至8.57%。
- **[白银期货/租赁对冲]** -> [非经常性损益剧烈波动]: 套期保值业务本身导致公允价值变动损益-4.11亿，成为净利润最大扰动项。

## 风险警告
**核心风险在于白银价格剧烈波动对利润表的侵蚀。** 公司为锁定银粉成本而持有大量白银期货和租赁头寸，2025年银价快速上涨导致公允价值变动损失4.11亿元，叠加平仓亏损，非经常性损益合计-4.4亿元，直接导致归母净利润由盈转亏。这种“主业赚钱、金融亏钱”的模式具有高度不确定性，若银价持续高位或大幅震荡，公司净利润将持续承压，投资者需警惕套期保值策略失效或成本失控的风险。

**其次，光伏行业产能过剩与价格战风险并未消除。** 尽管公司技术领先，但下游电池片环节持续亏损，降本压力向上游传导，光伏材料毛利率已降至8.57%。若行业竞争进一步加剧，公司产品售价和市场份额可能双降。同时，公司应收账款高达43亿元，占总资产38.4%，且客户以银票回款为主，若下游客户经营恶化，坏账风险将显著放大。
