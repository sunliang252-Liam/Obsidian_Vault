# 605166.SH 深度透视

## 因果逻辑链
- **[行业产能集中释放，供过于求]** -> [产品价格与加工费大幅下降]: 2025年国内PA6产能突破850万吨，下游需求疲软，导致切片市场报价逐季下降，行业利润被严重挤压。
- **[上游己内酰胺价格波动与成本承压]** -> [公司盈利能力显著下滑]: 己内酰胺占原材料采购总额超95%，其价格波动直接传导至成本端，叠加加工费收窄，导致净利润同比减少51.77%。
- **[下游纺服消费放缓与出口节奏放缓]** -> [核心产品纤维级切片需求失速]: 传统优势的民用纤维级切片受双重影响，采购支撑力减弱，是公司营收下滑22.94%的主要原因。
- **[海外老旧产能退出与公司规模化优势]** -> [海外业务收入逆势增长41%]: 海外部分装置因成本压力退出市场，公司凭借成本与规模优势，外销收入占比从5.65%提升至10.34%。
- **[“延链补链强链”战略与基地布局]** -> [产能规模与成本优势巩固]: 通过贴近上游原料（己内酰胺、己二腈）布局山东、湖南基地，降低运输成本并保障原料供应，形成一体化降本增效。
- **[募投项目从尼龙6转向高附加值产品]** -> [产品结构向多元化、高端化升级]: 将原“年产12.4万吨尼龙6”项目变更为聚焦共聚、改性、尼龙66等高端产品的“年产5.08万吨”项目，提升抗风险能力。
- **[行业“磨底”阶段与产能消化压力]** -> [2026年经营仍面临挑战]: 行业进入反复“磨底”阶段，消化现有大规模产能是当务之急，公司预计将继续面临价格竞争和利润压力。

## 风险警告
**核心风险在于行业供需格局的持续恶化。** 2025年尼龙6切片行业产能集中释放导致严重供过于求，产品价格与加工费创历史新低，全行业普遍亏损。公司净利润同比腰斩（-51.77%），且这一趋势在2026年预计仍将持续，行业将进入反复“磨底”阶段。公司虽通过海外业务增长和产品结构调整对冲，但国内产能消化仍是最大挑战，若下游需求无法有效复苏，公司盈利能力可能进一步承压。

**另一重大风险是原材料价格波动与地缘政治扰动。** 公司核心原材料己内酰胺价格受石油、煤炭价格及地缘政治影响巨大，且占成本超95%。2026年地缘变局可能带来成本扰动与外部不确定性，直接影响公司库存管理和产品定价。此外，公司海外业务（占比10.34%）以美元结算，人民币汇率波动也会对收入和利润产生直接影响。
