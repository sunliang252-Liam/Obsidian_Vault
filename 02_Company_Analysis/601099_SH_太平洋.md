# 601099.SH 深度透视

## 因果逻辑链
- **[A股日均成交额创历史新高]** -> [经纪业务收入增长28.3%]: 市场交投活跃度提升直接带动通道业务佣金及手续费收入大幅增加。
- **[债券市场利率低位宽幅震荡]** -> [固定收益投资业绩小幅增长]: 公司通过研判市场波动，把握可转债等品种的交易机会，实现了正收益。
- **[区域资本市场容量限制]** -> [投行业务收入骤降56.59%]: 公司债券承销业务在云南本地市场份额回归常态，叠加多重因素，导致整体投行收入大幅下滑。
- **[信用减值损失由负转正]** -> [营业成本上升3.17%]: 本期计提债权投资减值损失增加，导致信用减值损失从去年的-2205万元变为今年的2466万元，侵蚀了利润。
- **[权益类投资持仓策略不足]** -> [投资收益同比下降]: 面对极致分化的结构性行情，公司权益投资未能有效应对市场波动，导致收益下滑。
- **[融资融券市场余额增长36.26%]** -> [信用业务规模扩张]: 公司两融业务余额增长25.23%，新开信用账户增幅34.09%，成为利息净收入的主要支撑。
- **[母公司未分配利润为负]** -> [连续三年无法分红]: 截至2025年末，母公司未分配利润为-4.44亿元，不符合分红条件，公司连续三年不进行利润分配。

## 风险警告
**核心风险在于公司治理与股东结构的不确定性。** 第一大股东嘉裕投资所持10.92%股份已被司法拍卖并由华创证券竞得，但该股东变更申请尚待证监会核准，最终结果存在重大不确定性。这导致公司第四届董事会自2019年起超期服役，治理结构长期处于不稳定状态，可能影响公司战略执行的连续性与重大决策的效率。

**盈利结构脆弱且高度依赖市场行情。** 公司2025年净利润仅2.1亿元，ROE仅为2.15%，盈利能力在行业中处于较低水平。业绩增长主要依赖经纪业务和固定收益投资，而这两者均与市场成交量和利率走势高度相关。投行业务收入骤降56.59%，权益投资表现不佳，显示公司缺乏稳定的核心利润来源，业绩波动性极大。
