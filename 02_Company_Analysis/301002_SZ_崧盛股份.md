# 301002.SZ 深度透视

## 因果逻辑链
- **[储能业务研发高投入与规模化初期]** -> [归母净利润亏损396万元]: 储能子公司研发费用同比增20%至4081万元，占其收入50%，导致子公司亏损2500万元，拖累整体盈利。
- **[可转债存续期财务费用]** -> [侵蚀利润1766万元]: 存续可转债计提利息费用，直接减少当期利润，是亏损的第二大原因。
- **[海外贸易壁垒与地缘冲突]** -> [LED驱动电源业务不及预期]: 北美市场需求因关税大幅下滑，植物照明复苏延迟，导致公司LED电源收入同比微降0.53%。
- **[工商业照明与欧亚市场结构性增长]** -> [部分对冲LED业务下滑]: 工商业LED电源收入同比增17%，欧亚市场外销占比达58.9%，成为稳定基本盘的关键。
- **[中山数字化智能制造基地投产]** -> [毛利率稳定在25.28%]: 自动化产线及智能仓储降低单位人工与制费，在均价下滑背景下维持了LED电源业务盈利水平。
- **[储能业务从0到1商业化落地]** -> [收入暴增876%至8090万元]: 储能逆变器出货量同比增长620%，验证了第二增长曲线的商业模式，但尚未盈利。
- **[可转债强赎完成]** -> [未来财务费用大幅改善]: 2026年2月完成摘牌，公司资产负债率降至约30%，将显著减轻长期财务负担。
- **[战略投资布局新赛道]** -> [打开远期成长空间]: 收购芯神科技补足智能控制短板，投资崧盛亿麦切入AI服务器电源，布局谐波减速器进入机器人领域。

## 风险警告
公司当前核心风险在于储能业务“增收不增利”的困境。储能子公司研发投入占收入比重高达50%，且行业竞争激烈，产品认证与市场开拓仍需大量资金，若后续规模化放量不及预期或价格战加剧，将持续拖累合并报表利润，甚至导致公司连续亏损。此外，LED主业面临全球贸易格局重构的长期挑战，北美市场因关税壁垒萎缩，行业均价持续下行，公司虽通过欧亚市场对冲，但整体增长动能偏弱。

第二重风险来自多元化战略的执行不确定性。公司同时布局储能、智能控制、AI服务器电源、机器人谐波减速器等多个新领域，管理半径与资源分散风险显著。新业务均处于投入期或初创期，短期内难以贡献利润，且各赛道均面临强劲竞争对手。若任一业务推进不达预期，不仅造成投资损失，更可能动摇市场对公司战略聚焦能力的信心。
