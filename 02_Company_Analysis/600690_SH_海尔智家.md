# 600690.SH 深度透视

## 因果逻辑链
- **[全球本土化运营与高端品牌矩阵]** -> [收入突破3000亿，利润增长4.39%]: 通过多品牌（卡萨帝、GEA、Candy等）和本土化研发制造，在欧美成熟市场巩固份额，在新兴市场（南亚、东南亚）实现超24%增长，对冲了国内地产下行和关税冲击。
- **[用户共创爆款机制]** -> [Leader品牌收入首破百亿，同比增长30%]: 将用户从被动接受者转为产品共创者（如“懒人三筒洗衣机”），实现从痛点识别到产品上市的快速闭环，在存量竞争中创造增量。
- **[数字库存与统仓TC模式变革]** -> [国内收入逆势增长3.1%，运营效率提升]: 通过“统仓直配到用户”模式，缩短交易链路，降低经销商库存压力，提升配送效率（24小时覆盖区县达1944个），在行业下滑中实现份额提升。
- **[大暖通产业战略整合]** -> [暖通业务收入增长10%，成为新增长极]: 整合家用空调、智慧楼宇、水联网，提供“从空气到用水”的全屋方案，并在数据中心冷却、商用制冷（CCR）等B端领域取得突破。
- **[AI技术全面应用]** -> [提升产品溢价与运营效率]: “AI之眼”等技术赋能高端产品（卡萨帝鉴赏家套系），同时AI在研发、营销、客服等环节降本增效（如空调研发周期缩短54%）。
- **[全球化供应链韧性]** -> [应对关税与地缘政治风险]: 通过“1+1+N”全球供应模式（本土+区域+全球协同），灵活调整产能布局（如泰国工厂投产），保障了海外市场的稳定供应和成本控制。
- **[高比例分红与股东回报规划]** -> [增强投资者信心]: 2025年分红比例提升至55%，并承诺未来三年逐步提升至60%以上，体现了公司对现金流和未来发展的信心。

## 风险警告
**核心风险在于全球宏观经济与地缘政治的不确定性。** 美国关税政策反复、欧洲经济复苏缓慢、以及新兴市场货币波动，将持续侵蚀海外业务的毛利率（2025年海外毛利率已同比下降0.82个百分点）。公司虽通过本土化供应链对冲，但若贸易摩擦升级或全球消费需求进一步萎缩，海外收入增长和盈利改善将面临巨大压力。

**国内市场存量竞争加剧，价格战风险不容忽视。** 尽管公司通过高端化和爆款策略维持了份额，但行业整体零售额同比下降4.3%，且原材料价格上涨（铜、钢等）与竞争白热化导致国内毛利率承压。若“以旧换新”政策红利消退后需求进一步疲软，公司可能被迫卷入价格战，从而损害品牌溢价和盈利能力。
