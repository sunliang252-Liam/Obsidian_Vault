# 688399.SH 深度透视

## 因果逻辑链
- **[新冠业务退潮]** -> [营收与利润双降]: 疫情相关检测需求消失，公司营收连续三年下滑，2025年归母净亏损扩大至-4108万元。
- **[应收款项减值转回减少]** -> [利润亏损加剧]: 往期疫情防控应收款回款高峰已过，2025年减值准备转回大幅减少，直接导致利润总额同比暴跌865.61%。
- **[政府补助锐减]** -> [非经常性损益收缩]: 2025年计入当期损益的政府补助从5140万元骤降至981万元，进一步拖累净利润表现。
- **[研发投入高企但聚焦不足]** -> [短期盈利承压]: 研发费用率仍达23.22%（7872万元），但营收规模仅3.39亿，高研发投入未能转化为等量收入增长，持续侵蚀利润。
- **[核心产品依赖疾控与筛查]** -> [增长天花板显现]: 传染病检测与HPV两癌筛查业务成熟，市场渗透率较高，营收增速乏力（-3.02%），新增长点（NGS、POCT）尚未放量。
- **[国际化业务增长]** -> [对冲国内下滑]: 境外收入同比增长13.08%，产品进入耶鲁、哈佛等顶尖高校及WHO应急清单，成为少数亮点，但体量较小（境外收入占比约4%）。
- **[现金分红与回购]** -> [消耗大量现金]: 2025年中期分红2.85亿元，叠加回购注销，导致筹资现金流净流出1.62亿元，货币资金减少40.32%，削弱了抗风险能力。

## 风险警告
**核心风险在于“后疫情时代”的业绩断崖与转型阵痛。** 公司营收已从2020年疫情高峰的23.5亿跌至2025年的3.39亿，降幅超85%，且仍未触底。扣非净利润连续三年亏损，2025年亏损扩大至-1.03亿元，表明主营业务已丧失造血能力。公司高度依赖的政府补助和应收款减值转回等非经常性损益，在2025年大幅缩减，导致真实盈利状况暴露。若未来无法快速找到替代新冠业务的新增长极，公司可能陷入长期微利或亏损的困境。

**第二增长曲线尚未形成，研发投入存在“打水漂”风险。** 公司战略聚焦NGS、POCT、肿瘤早筛等前沿领域，但相关产品仍处于研发或市场导入期，短期内难以贡献显著收入。研发费用率虽高（23.22%），但研发人员数量同比减少8.3%，且研发投入资本化率为0，表明项目推进效率及商业化前景存疑。在集采常态化、行业竞争加剧的背景下，若新产品无法在临床价值或成本上建立优势，巨额的研发投入可能无法转化为有效产出，进一步拖累现金流。
