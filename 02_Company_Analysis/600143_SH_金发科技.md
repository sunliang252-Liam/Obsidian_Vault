# 600143.SH 深度透视

## 因果逻辑链
- **[改性塑料销量增长与结构优化]** -> [归母净利润+39.44%]: 改性塑料销量295.06万吨（+15.64%），工程塑料占比提升，叠加原材料价格下行，毛利率提升2.36个百分点，核心主业量利齐升。
- **[特种工程塑料抢占AI与新能源高地]** -> [新材料板块销量+20.25%]: 特种工程塑料销量3.41万吨（+42.68%），在AI服务器高速连接器、新能源汽车三电系统等高端领域实现进口替代，驱动板块毛利率提升4.76个百分点。
- **[海外基地产能释放与本地化服务]** -> [海外收入+18.26%]: 海外基地产成品销量29.75万吨（+27.41%），西班牙、印尼工厂投产，全球化协同网络完善，有效对冲国内石化周期下行压力。
- **[绿色石化板块一体化协同降本]** -> [石化产品毛利率+1.06个百分点]: 宁波金发、辽宁金发推进“合成-改性”一体化，PP专用料占比突破50%，技改降本，部分对冲行业供需失衡带来的亏损。
- **[供应链结算优化与现金流管控]** -> [经营活动现金流净额+107.52%]: 优化采购端结算安排，经营性现金流净额达59.04亿元，显著改善财务健康度，为资本开支提供支撑。
- **[医疗健康板块手套放量]** -> [医疗健康收入+85.44%]: 丁腈手套销量93.90亿只（+99.19%），海外占比75%，规模效应与工艺优化驱动成本下降，板块实现扭亏为盈。
- **[生物降解塑料全产业链贯通]** -> [金发生物扭亏为盈]: 年产1万吨生物基BDO投产，打通“生物基单体-聚酯-改性”全链条，推出高速3D打印等高端产品，突破应用瓶颈。

## 风险警告
**核心风险在于绿色石化板块的持续亏损与巨额资本开支压力。** 宁波金发（亏损10.17亿）和辽宁金发（亏损12.86亿）合计亏损超23亿元，严重侵蚀改性塑料与新材料板块的利润。120万吨/年PTPE项目转固后折旧激增，叠加PDH、ABS行业产能严重过剩，该板块短期内难以扭亏，构成公司最大的利润拖累。

**第二重风险是海外扩张与产能建设带来的高负债与现金流压力。** 公司总负债413.78亿元，资产负债率约64.6%，在建工程虽因项目转固大幅下降，但仍有26.85亿元。海外基地（波兰、墨西哥）及新材料产能持续投入，若下游需求不及预期或地缘政治风险加剧，可能引发资产减值与流动性紧张。此外，公司贸易业务收入112.65亿元，占比17.2%，其价格波动风险不可忽视。
