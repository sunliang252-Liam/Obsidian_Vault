# 600007.SH 深度透视

## 因果逻辑链
- **[北京CBD核心区位优势]** -> [高出租率与租金韧性]: 尽管市场整体下行，公司凭借不可复制的地段和品牌，写字楼、商城、公寓出租率仍维持在90%以上，租金降幅远低于市场平均水平。
- **[写字楼市场需求疲弱]** -> [营业收入下降3.63%]: 企业租赁决策谨慎，以性价比为导向的搬迁需求主导，导致写字楼租金同比下降4.7%，出租率下滑1.3个百分点，成为收入下滑主因。
- **[商城业态分化加剧]** -> [租金与出租率双降]: 国际精品品牌拓店谨慎，叠加新增供应竞争，商城平均租金同比下降0.7%，出租率下滑1个百分点，收入贡献减少。
- **[酒店经营承压]** -> [酒店收入下降5.98%]: 政商活动减少、企业差旅预算压缩，导致客房、宴会及餐饮收入全面下滑，酒店业务毛利率仅为5.17%，盈利能力薄弱。
- **[偿还大额债务]** -> [财务费用大幅减少174.83%]: 报告期内偿还银行借款本金8.85亿元，利息支出显著降低，财务费用由正转负，对利润形成正向支撑。
- **[高比例现金分红]** -> [股东回报稳定]: 2025年拟每10股派发现金红利10.7元，分红比例高达90%，连续多年维持高分红政策，吸引红利型投资者。
- **[信用减值损失激增]** -> [利润侵蚀]: 计提应收账款坏账准备增加，信用减值损失同比暴增4204%，反映出在经济下行周期中，租户回款风险上升。

## 风险警告
**核心风险在于核心资产（写字楼）的租金下行趋势难以逆转。** 2026年CBD区域将迎来近年新增供应高峰，去化压力显著加大，租金水平预计将持续下行。公司写字楼收入占比近38%，是利润的绝对支柱，其持续承压将直接拖累整体业绩。管理层给出的2026年利润总额预算（14.5亿元）同比下降约10%，已提前反映了这一悲观预期。

**次要风险来自经营层面的脆弱性与外部不确定性。** 酒店业务毛利率极低（5.17%），对整体利润贡献有限，且面临激烈的市场竞争。同时，宏观经济的复杂严峻形势、外部贸易环境动荡以及国内消费动力不足，都可能进一步抑制商业活动与租赁需求，导致公司“稳租户、稳收入”的经营计划面临挑战。此外，作为超大型地标建筑综合体，公司在消防、治安和反恐方面面临的管理压力与潜在风险不容忽视。

**公司简介（F10 原文）**

> 中国国际贸易中心股份有限公司(简称“国贸中心”)于1985年2月注册成立,是经国务院批准成立的大型中外合资企业。中外方股东分别为中国世贸投资有限公司和嘉里兴业有限公司。国贸中心位于中国(北京)自由贸易试验区国际商务服务片区北京商务中心区核心地段,总建筑规模112万平方米,由写字楼、商城、酒店、公寓和会展等国际化商业服务设施组成,是首都地标性建筑群,是众多跨国公司和国际商社进驻北京的首选之地,也是目前中国乃至全球规模最大、功能最齐全的综合性高档商务服务企业之一。1990年8月30日,建筑规模42万平方米的国贸一期全面开业,云集了众多国际知名跨国公司、商社和国际顶级零售店,并承接多项国际、国内重大会议及大型商务活动,接待了许多国家元首、政府首脑、重要国际组织负责人以及国内外商界领导人和社会知名人士等,取得了良好的经济效益和社会效益。  随着国贸二期工程于1999年的建成投入运营,国贸中心总建筑规模达到56万平方米,服务设施和管理水平得到了进一步提升,国贸中心已成为京城高档物业、酒店行业的“晴雨表”和“风向标”。  2005年6月,国贸三期工程动工兴建,国贸中心步入了新的发展阶段。项目规划总建设规模为54万平方米,国贸三期A阶段已于2010年8月30日建成并投入运营,建筑规模近30万平方米。其中高度为330米的国贸大厦A座包含了国际水准的甲级写字楼和超豪华五星级国贸大酒店;裙楼为新扩建的国贸商城北区西段。国贸三期B阶段于2017年4月起陆续投入使用,建筑规模逾23万平方米。其中高度为296米的国贸大厦B座包含写字楼和新国贸饭店。裙楼为新扩建的国贸商城北区东段,增加了更多餐饮、购物体验和文化休闲娱乐业态。 经过近四十年的建设与发展,国贸中心已成为国际一流水准的现代化商务中心,是展示中国对外开放政策和从事国际交流活动的重要窗口。以国贸中心为中心的CBD地区,已经形成了一个极具活力的经济商圈,辐射带动了周边经济的快速发展。其独具特色的国贸发展模式和品牌成长经历,成为中国大型商务服务企业成功的典范。  国贸中心将继续秉承“争中国第一、创世界一流、铸国贸辉煌”的发展理念,锐意进取、铸就非凡,以国际一流水准的硬件设施和软件管理,为国内外宾客提供优质、高效、满意的服务,不断强化国贸中心的品牌价值,进一步提升国贸中心在全球商贸领域的地位。
