# 600162.SH 深度透视

## 因果逻辑链
- **[商品房交付规模骤减]** -> [营业收入暴跌61.6%]: 报告期内商品房交付结转收入较上年同期减少约20亿元，导致营收从37.6亿骤降至14.4亿。
- **[营收大幅下滑]** -> [归母净利润由盈转亏]: 商品房销售业务收入大幅减少，导致归属于上市公司股东的净利润亏损8830万元，同比减少242.89%。
- **[新项目开发投入大]** -> [经营活动现金流净流出]: 新楼盘前期投入较大，而销售回款减少，导致经营活动现金流净额为-1.54亿元，同比减少153.21%。
- **[处置长期资产]** -> [非经常性损益支撑利润]: 非流动性资产处置收益达1.64亿元，是公司避免更大亏损的关键，扣非后净利润亏损2.14亿元。
- **[房地产行业深度调整]** -> [存货去化周期延长]: 受市场行情影响，公司存货去化周期较长，导致商品房销售业务收入大幅下滑。
- **[商贸流通运营稳定]** -> [对冲地产下行风险]: 商贸流通运营板块收入7.25亿元，毛利率高达52.84%，成为公司稳定的利润来源，部分缓冲了地产板块的冲击。
- **[高负债运营]** -> [财务费用侵蚀利润]: 公司负债水平较高，利息支出2.09亿元，对利润形成较大压力。

## 风险警告
香江控股正经历房地产行业深度调整带来的剧烈阵痛。核心风险在于**主营业务收入断崖式下滑**，商品房销售业务收入锐减82%，导致公司整体由盈转亏。虽然通过处置资产获得了1.64亿元的非经常性收益，但扣非净利润亏损高达2.14亿元，表明其**核心造血能力已严重受损**。公司存货高达93.8亿元，占总资产58%，在行业下行周期中，存货跌价风险持续存在，审计报告亦将此列为关键审计事项。

此外，公司**现金流状况急剧恶化**。经营活动现金流净流出1.54亿元，而公司同时面临高额的利息支出（2.09亿元）和短期偿债压力（短期借款及一年内到期非流动负债合计14.16亿元）。尽管公司账面货币资金尚有7.87亿元，但其中1.21亿元受限，且筹资活动现金流持续净流出，表明外部融资环境趋紧。在销售回款不畅、新项目仍需持续投入的背景下，公司**资金链的平衡能力面临严峻考验**。
