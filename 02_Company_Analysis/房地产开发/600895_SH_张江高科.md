# 600895.SH 深度透视

## 因果逻辑链
- **[产业空间载体销售激增]** -> [营收暴增110.85%]: 本期产业空间载体销售收入大幅增加，直接驱动总营收从19.83亿跃升至41.82亿。
- **[产业空间载体销售成本同步攀升]** -> [毛利率承压]: 销售成本增速（+223.21%）与收入增速（+228.30%）基本同步，但租赁业务成本增速（+64.38%）远超收入增速（+11.49%），导致整体毛利率下降7.88个百分点。
- **[公允价值变动收益大幅下滑]** -> [扣非净利润微降]: 持有的金融资产公允价值本期下降（-3.35亿），而上年同期为上升（+8.04亿），此非经常性损益波动是扣非净利润同比下降2.20%的主因。
- **[合营企业金融资产公允价值上升]** -> [投资收益大幅增长]: 下属合营企业持有的金融资产公允价值本期上升，使公司按权益法确认的投资收益同比增加218.73%，部分对冲了自身公允价值变动损失。
- **[产业空间载体销售回款增加]** -> [经营现金流大幅转正]: 销售收到的现金及税费返还大幅增加，使经营活动现金流净额从-24.01亿转为+3.97亿，改善显著。
- **[短期借款激增]** -> [流动性风险上升]: 短期借款期末余额较期初暴增254.65%至86.09亿，流动比率从1.39降至0.91，短期偿债压力显著增大。
- **[累计投资规模106亿，撬动585亿资金]** -> [产业投资杠杆效应显著]: 以53亿自有资金认缴31支基金，撬动585亿社会资本，放大倍数超11倍，强化了产业生态构建能力。

## 风险警告
**核心风险在于资产结构失衡与短期流动性压力。** 公司营收高度依赖产业空间载体销售（占营收71.5%），该业务具有强周期性和不可持续性。同时，短期借款激增至86.09亿，而货币资金仅38.56亿，流动比率降至0.91，短期偿债能力脆弱。若市场租金下行或销售不畅，公司将面临严峻的现金流考验。

**公允价值变动是利润的“放大器”与“粉碎机”。** 公司持有超100亿以公允价值计量的金融资产（交易性金融资产+其他非流动金融资产），其价值波动直接且剧烈地影响净利润。2025年公允价值变动损失3.35亿，而上年同期为收益8.04亿，这种大幅波动使公司盈利质量极不稳定，投资者难以基于历史业绩线性外推。
