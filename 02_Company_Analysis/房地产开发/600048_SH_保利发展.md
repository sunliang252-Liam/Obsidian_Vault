# 600048.SH 深度透视

## 因果逻辑链
- **[行业下行与资产减值]** -> [归母净利润暴跌79.31%]: 全国商品房销售面积/金额持续下滑，公司计提大量资产减值，导致利润被严重侵蚀。
- **[“以销定产”与现金流管控]** -> [经营现金流净额大增142.74%]: 公司严格根据销售回款调整开工和建安支出，减少土地款支出，实现连续8年经营现金流为正。
- **[核心城市深耕]** -> [销售规模行业第一]: 聚焦一二线城市，核心城市销售贡献占比92%，市占率提升至7.9%，以高权益比（79%）维持销售领先地位。
- **[融资创新与债务优化]** -> [综合融资成本降至2.72%]: 成功发行国内首单现金类定向可转债，并利用低利率窗口发行中票、公司债，优化债务结构，降低利息支出。
- **[“三好房子”产品战略]** -> [产品力行业第二]: 构建“好产品、好服务、好生活”价值闭环，提升产品品质与客户满意度（87%），在弱市中维持项目去化能力。
- **[存量资源盘活]** -> [释放资产价值]: 通过“老盘新做”、土地盘活、转经营等方式，全年盘活资源181亿元，缓解了存量项目去化压力。
- **[三大主业协同]** -> [构建新发展模式]: 明确不动产投资开发、经营、综合服务三大主业，推动保利物业收入增长，并推进商业REITs打通“投融管退”闭环。

## 风险警告
**核心风险在于利润端的急剧恶化与资产质量的持续承压。** 2025年归母净利润同比暴跌79.31%，扣非净利润更是下降84.52%，盈利能力已降至历史冰点。尽管公司通过“以销定产”和融资优化维持了现金流安全，但利润的大幅下滑直接侵蚀了净资产（ROE仅0.54%），并导致分红能力极度萎缩（每10股仅派0.35元）。这反映出在行业深度调整期，公司过去高价获取的存量土地项目正在集中释放亏损压力。

**另一重大风险是市场筑底的不确定性与资产减值风险。** 虽然公司销售金额连续三年行业第一，但全国房地产市场仍处于筑底阶段，销售面积和金额仍在下降。公司待售面积高达5654万平方米，其中存量项目占比超80%。若市场持续低迷，这些存量项目的去化速度和售价可能进一步低于预期，导致未来仍需计提大额资产减值，持续压制利润表现。同时，公司受限资产（存货、投资性房地产等抵押）规模高达1109亿元，财务弹性空间正在收窄。
