# 000573.SZ 深度透视

## 因果逻辑链
- **[转让煤矿股权]** -> [净利润暴增243.85%]: 2025年转让贵州宏途鑫业（核桃坪煤矿）股权及债权，确认投资收益约1.17亿元，是净利润由亏转盈的核心驱动力。
- **[再生铅业务毛利率极低]** -> [扣非净利润持续为负]: 再生铅业务收入占88.92%，但毛利率仅0.97%，成本刚性（废电瓶供应偏紧）与售价波动导致主业亏损，扣非净利润已连续三年为负。
- **[房地产行业深度调整]** -> [自营项目销售低迷]: 东莞市场商品房销售面积同比下降31.4%，公司自营项目（帝庭山、雍雅台）销售贡献有限，库存去化压力大。
- **[合作项目进入尾盘]** -> [投资收益贡献有限]: 与万科等合作开发的多个项目（如瑧湾汇花园）已进入中后期，本期结算金额虽大，但公司仅占10%权益，且后续可结算资源减少。
- **[废电瓶回收体系不健全]** -> [再生铅产能利用率下降]: 废铅酸蓄电池回收处置开工率下降，全年生产天数同比减少，制约了再生铅业务的规模效应和盈利修复。
- **[终止重大资产重组]** -> [转型路径受阻]: 收购博创智能（注塑机）约60%股份的计划因核心条款未达成一致而终止，公司构建“第二增长曲线”的努力受挫。
- **[工业区厂房出租率高]** -> [提供稳定现金流]: 南城宏远工业区及虎门华远厂房出租率接近100%，年租金收入约3520万元，为公司提供了相对稳定的基础现金流。

## 风险警告
**核心风险在于主业造血能力枯竭。** 公司扣非净利润已连续三年为负，再生铅业务毛利率不足1%，在废电瓶供应持续偏紧和铅价波动的双重挤压下，盈利改善遥遥无期。房地产自营项目库存高企（帝庭山、昆山项目），在东莞楼市持续调整的背景下，去化速度和价格均面临巨大压力，资产减值风险犹存。

**转型前景高度不确定。** 公司已无煤矿业务，但收购博创智能的尝试失败，目前缺乏清晰的第二增长曲线。账面虽有5.25亿现金，但大部分来自资产处置所得，而非经营积累。若不能找到可持续的新主业，公司可能沦为“现金壳”，面临长期价值损耗。此外，对柳向阳的应收款（约2890万元）因采矿权司法拍卖流拍，回收风险显著增加。
