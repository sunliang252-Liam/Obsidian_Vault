# 600773.SH 深度透视

## 因果逻辑链
- **[房地产市场下行]** -> [营业收入下降22.34%]: 行业深度调整，公司房地产销售收入从11.83亿降至7.32亿，直接拖累整体营收。
- **[项目竣工/暂缓，利息费用化]** -> [财务费用激增47.92%]: 部分项目完工或暂停，导致大量借款利息无法资本化，费用化利息大幅增加。
- **[存货减值计提]** -> [资产减值损失3.92亿]: 基于市场环境对部分项目计提大额减值，是导致全年巨亏的核心原因。
- **[房地产销售萎缩]** -> [经营活动现金流净流出4.11亿]: 销售回款大幅减少，而刚性支出持续，导致经营现金流持续为负。
- **[上年度定增募资]** -> [筹资活动现金流由正转负]: 2024年完成定增带来大量现金，2025年无此事项，且需偿还债务，导致筹资现金流净流出。
- **[盐湖锂业布局]** -> [第二增长曲线培育]: 公司正全力推进龙木错、结则茶卡盐湖提锂项目，试图摆脱对单一房地产业务的依赖。
- **[发行新债偿还旧债]** -> [应付债券余额暴增796%]: 公司发行8亿公司债用于偿还到期债券，债务结构发生变化，但总负债率微升至61.22%。

## 风险警告
**核心风险在于房地产主业深度衰退与转型业务远未成熟之间的巨大鸿沟。** 公司2025年归母净利润巨亏5.53亿元，核心原因是房地产销售腰斩叠加巨额存货减值。经营现金流连续三年为负，造血能力严重不足，流动性高度依赖融资和股东借款。尽管控股股东提供了14亿借款，但公司短期偿债压力依然巨大，货币资金已从9.7亿骤降至2.77亿。

**转型新能源的赌注充满不确定性。** 公司寄望于盐湖提锂成为第二增长曲线，但参股的国能矿业持续亏损，自主开发的碳酸锂项目仍处于环评、中试和基地建设阶段，距离规模化量产和贡献利润尚需时日。在锂价高波动的背景下，矿业投资的高投入、长周期和技术风险，可能进一步加剧公司的财务困境。
