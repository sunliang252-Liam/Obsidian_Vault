# 000965.SZ 深度透视

## 因果逻辑链
- **[土增税清算冲回]** -> [税金及附加为-1.10亿元]: 报告期内土地增值税清算冲回税金及附加，导致税金及附加大幅减少，直接增厚利润。
- **[存货跌价准备计提减少]** -> [资产减值损失减少82.73%]: 房地产市场企稳，部分项目可变现净值回升，减值压力减轻，对利润的侵蚀大幅收窄。
- **[满足结转条件的项目增加]** -> [营业收入增长10.79%]: 报告期内多个在建项目达到交付条件，推动房地产销售收入确认增加。
- **[销售服务费增加]** -> [销售费用增长44.56%]: 为应对市场下行压力，公司加大营销推广投入，导致销售费用率上升。
- **[购买商品、接受劳务支付的现金增加]** -> [经营活动现金流净额为-13.95亿元]: 为推进在建项目开发，公司大幅增加工程款等支出，导致经营性现金流转为大幅净流出。
- **[偿还债务支付的现金减少]** -> [筹资活动现金流净额增长2984.43%]: 公司债务到期偿还规模同比减少，使得筹资活动现金净流入大幅增加。
- **[天津滨海新区市场占有率提升]** -> [住宅销售合同额25.41亿元]: 公司在区域市场逆势发力，通过热销项目（天成燕居、意境元启等）实现销售领跑，巩固了区域龙头地位。

## 风险警告
公司核心风险在于经营现金流极度恶化与区域市场高度集中。报告期内，经营活动现金流净额由正转负，大幅流出13.95亿元，远超净利润水平，表明公司为维持项目开发而大量消耗现金，财务弹性显著下降。同时，公司业务100%集中于天津，且主要依赖住宅开发，区域房地产市场复苏的可持续性及政策变动将直接决定公司业绩表现，抗风险能力较弱。

此外，公司盈利质量堪忧。扣除非经常性损益后的净利润仅为35万元，几乎处于盈亏平衡点，真实盈利能力极弱。利润主要依赖土地增值税清算冲回、资产减值损失减少等非经常性及会计估计因素，缺乏可持续性。在行业整体“弱复苏”背景下，公司高企的存货（占总资产74%）仍面临进一步减值的风险。
