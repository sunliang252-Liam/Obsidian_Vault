# 600325.SH 深度透视

## 因果逻辑链
- **[行业深度调整与资产减值]** -> [归母净利润巨亏94.96亿元]: 市场下行导致毛利率下降，公司主动计提大额资产减值及投资性房地产公允价值变动损失，是上市20年来首次年度亏损。
- **[主动盘活存量资产]** -> [经营性现金流净额198.89亿元]: 通过政府收储、商改住等方式盘活滞重资产，回笼资金57亿元，叠加狠抓销售回款，连续两年销售回款率超100%，现金流安全垫增厚。
- **[聚焦核心城市与产品力]** -> [销售规模稳居行业前列]: 81%销售额来自一线及强二线城市，成都锦宸院、南京金陵月华等“科技+”好房子项目成为区域销冠，支撑785.6亿元销售额。
- **[组织架构“瘦身健体”]** -> [管理费用率降至1.46%]: 撤销大区建制、精简总部部门、压减编制，管理费用连续三年同比下降，降本增效成果显著。
- **[多元融资与国资信用]** -> [综合融资成本降至4.88%]: 成功发行低利率定向可转债、公司债，获AAA评级，融资成本创近五年新低，在行业信用分化中保持优势。
- **[“三驾马车”战略转型]** -> [商业与物业成为新增长极]: 商业租金收入同比增长11.9%，深圳冰雪世界开业3个月营收超1.6亿；物业营收增长15.4%，在管面积近6000万平米。
- **[前瞻布局城市更新]** -> [形成差异化竞争优势]: 创新“地产+文保”模式，成功打造上海静安里、武汉咸安坊等标杆，为获取核心城市优质存量土地开辟新路径。

## 风险警告
**核心风险在于资产减值与盈利能力的持续恶化。** 公司2025年归母净利润巨亏95亿元，主要源于毛利率大幅下滑和巨额资产减值。虽然公司解释为“轻装上阵”的战略选择，但这暴露了其在行业下行周期中，过往高价拿地项目的利润空间被严重压缩。若市场修复不及预期，未来仍有继续计提减值的风险，这将持续侵蚀净资产，导致净资产从197亿骤降至94亿，财务根基动摇。

**第二重风险是转型阵痛与现金流压力。** 公司正从重资产开发转向“地产+商业+物业”的轻资产运营，但新业务（冰雪、康养、代建）尚在培育期，短期内难以弥补地产主业的利润缺口。同时，公司总负债规模依然庞大（超3500亿），短期借款激增216%，虽然经营性现金流为正，但筹资活动现金流净流出102.7亿元，显示外部融资环境收紧。若销售回款放缓或融资渠道受阻，流动性压力将显著上升。
