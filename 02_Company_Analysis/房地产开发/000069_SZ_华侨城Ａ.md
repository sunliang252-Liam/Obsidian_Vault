# 000069.SZ 深度透视

## 因果逻辑链
- **[房地产行业下行与主动去化]** -> [营收与利润大幅下滑]: 公司主动适应市场，通过资产转让等方式全力推动存量销售去化与现金流改善，但相关交易形成亏损，叠加项目结转收入金额和毛利率同比下降，导致营收下降42.32%，归母净亏损扩大至144.96亿元。
- **[资产减值损失]** -> [巨额亏损核心来源]: 报告期内计提资产减值损失86.37亿元，信用减值损失13.40亿元，合计近100亿元，是导致公司巨额亏损的最直接财务原因。
- **[经营性现金流改善]** -> [财务安全垫增厚]: 通过加速销售回款和降本增效，经营活动净现金流达125.01亿元，同比增长133.13%，连续三年为正，有效对冲了巨额亏损对现金流的冲击。
- **[有息负债规模控制与结构优化]** -> [融资成本下降]: 在控制总负债规模的同时，把握融资窗口期，中长期借款占比提升至69%，平均融资成本呈逐年下降趋势，降低了财务风险。
- **[文旅业务稳健]** -> [业绩缓冲垫]: 文旅业务营收213.72亿元，虽同比下降21.71%，但降幅远小于房地产业务（-63.41%），接待游客7,970万人次，成为公司收入的基本盘和转型方向。
- **[房地产业务聚焦核心城市]** -> [去化压力与区域分化]: 公司聚焦核心城市，但大量项目位于武汉、成都、西安等非一线城市，面临区域市场下行压力，导致销售面积同比下降30.29%，销售金额下降，去化难度加大。
- **[资产转让形成亏损]** -> [短期阵痛换取长期流动性]: 公司通过资产转让等方式全力推动存量业务销售去化与现金流改善，相关交易形成亏损，是增亏的重要原因，但换来了宝贵的现金流，是“以空间换时间”的策略。

## 风险警告
**核心风险在于资产减值与流动性陷阱的恶性循环。** 公司2025年归母净亏损144.96亿元，连续三年巨额亏损，净资产已从2023年的619.5亿骤降至387.2亿，降幅达37.5%。高达86.37亿元的资产减值损失和13.40亿元的信用减值损失，揭示了公司大量存货和应收款项面临严重的价值缩水风险。若房地产市场持续低迷，资产减值压力将持续存在，进一步侵蚀净资产，甚至可能触及财务安全底线。

**债务结构虽优化，但偿债压力依然巨大。** 尽管经营性现金流大幅改善，但公司总负债仍高达2259.76亿元，资产负债率攀升至80.60%。短期借款与一年内到期的非流动负债合计约378.4亿元，而账面货币资金仅231.9亿元，存在明显的短期偿债缺口。公司依赖“借新还旧”维持流动性，一旦融资环境收紧或销售回款不及预期，将面临严峻的流动性危机。
