# 600515.SH 深度透视

## 因果逻辑链
- **[非经常性损益依赖]** -> 净利润虚高: 归母净利润2.19亿，但扣非净利润-3.03亿，核心盈利严重依赖资产处置（4.18亿）和债务重组（0.64亿）等非经常性项目。
- **[营业成本飙升侵蚀毛利]** -> 毛利率恶化: 营收微增1.19%至44.2亿，但营业成本激增22.37%至31.39亿，导致毛利率从41.3%骤降至29.0%，主因机场折旧摊销增加及低毛利地产项目结转。
- **[地产项目结转结构恶化]** -> 房地产业务毛利暴跌: 房地产业务收入增25.8%至11.53亿，但成本暴增612.85%，毛利率从88%断崖式降至45%，因高毛利项目结转完毕，低毛利项目（如翰林府）成为主力。
- **[收购美兰空港并表]** -> 资产规模膨胀但短期拖累利润: 以23.39亿收购美兰空港50.19%股权，总资产增11.23%至597亿，但美兰空港2025年亏损2.75亿，并表后直接拉低整体利润。
- **[免税业务承压]** -> 收入下滑: 免税与商业业务收入1.93亿，同比降14.63%，反映海南离岛免税销售金额同比下降1.8%的市场疲软态势。
- **[处置子公司贡献一次性收益]** -> 粉饰当期利润: 出售天羽飞训（1.99亿）和三亚临空（2.11亿）股权，合计贡献4.1亿利润，是当期净利润的主要来源，掩盖了主业亏损。
- **[现金流改善]** -> 经营现金流由负转正: 经营现金流净额从-7.82亿大幅转正至1.11亿，主因上期支付大额土地款，本期无新增土地储备，并非经营效率提升。

## 风险警告
**核心风险在于盈利能力的根本性恶化。** 公司扣非净利润已连续两年为负（-2.61亿、-3.03亿），且亏损幅度扩大。主业机场管理业务毛利率下降近8个百分点，房地产业务毛利率断崖式下跌，免税业务收入下滑，表明公司核心资产运营效率低下，缺乏可持续的利润增长点。当前盈利高度依赖资产处置和债务重组等一次性收益，模式不可持续。

**财务健康度存在隐患。** 公司资产负债率从52.17%升至54.60%，有息债务总额增加47亿元至221.23亿元。同时，高达311.18亿元的资产（占总资产52%）处于受限状态（抵押、质押），严重限制了财务灵活性。此外，控股股东海航基础控股集团所持19.69%股份全部质押，且前十大股东中存在大量冻结股份，股权结构稳定性存疑。
