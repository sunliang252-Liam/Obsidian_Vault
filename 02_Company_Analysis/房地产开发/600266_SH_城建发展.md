# 600266.SH 深度透视

## 因果逻辑链
- **[行业深度调整，去库存压力巨大]** -> [归母净利润连续两年亏损]: 市场下行导致项目去化困难，公司被迫计提34.05亿元巨额存货跌价准备，直接侵蚀利润。
- **[项目集中结转，收入规模扩大]** -> [营业收入同比增长19.02%]: 公司加速项目交付，推动房地产结转收入增加至296.22亿元，但毛利率提升未能覆盖减值损失。
- **[持有国信证券等金融资产]** -> [非经常性损益支撑业绩]: 报告期内金融资产公允价值变动及处置收益达3.08亿元，成为避免亏损进一步扩大的关键缓冲垫。
- **[销售回款大幅减少]** -> [经营活动现金流净额骤降88.83%]: 市场销售遇冷，销售商品、提供劳务收到的现金减少，导致经营性现金流从55.75亿元锐减至6.23亿元。
- **[高库存与低周转并存]** -> [资产减值风险持续暴露]: 期末存货高达623.45亿元，但销售面积仅47.8万平米，高库存低周转迫使公司连续两年大额计提减值。
- **[融资成本优化，但债务规模高企]** -> [财务费用增长23.45%]: 尽管综合融资成本降至2.99%，但长期借款增加64.3%导致利息支出总额上升，财务压力未减。
- **[依赖关联方采购与托管]** -> [经营独立性存疑]: 前五名供应商采购额中关联方占比高达68.89%，且通过托管控股股东旗下同业公司解决竞争问题，治理结构复杂。

## 风险警告
公司当前最核心的风险在于**存货减值与现金流枯竭的恶性循环**。2025年计提34亿元存货跌价准备后，存货账面价值仍高达623亿元，占资产总额的60%。在房地产市场持续底部调整的背景下，若销售去化无法提速，未来仍有大规模减值风险，将直接冲击净资产。同时，经营活动现金流净额从上年55.7亿骤降至6.2亿，造血能力严重恶化，公司高度依赖再融资维持流动性。

第二大风险是**永续债的“债务陷阱”与股东回报的背离**。公司账面仍有23亿元永续债，每年需支付高额利息（计入权益但实质为刚性成本），导致归母净利润在扣除永续债利息后亏损更深。尽管母公司报表盈利7.65亿元，但合并报表巨亏，公司仍坚持分红，这种“借债分红”的模式不可持续，且永续债若到期不赎回将面临利率跳升，进一步加重财务负担。
