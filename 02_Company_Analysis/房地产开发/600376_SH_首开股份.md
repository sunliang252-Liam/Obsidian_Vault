# 600376.SH 深度透视

## 因果逻辑链
- **[行业下行与资产减值]** -> [连续三年巨额亏损]: 房地产市场持续调整，公司项目去化压力大，导致对存货、联合营企业投资等计提大规模资产减值，是连续亏损的直接原因。
- **[北京区域项目集中交付]** -> [营收增长24.3%]: 报告期内北京地区多个项目进入结算期，北京地区收入同比暴增172.81%，拉动整体营收逆势增长。
- **[京外项目亏损拖累]** -> [整体毛利率改善有限]: 京外地区毛利率仅1.18%，远低于北京地区的19.29%，严重侵蚀了北京项目带来的利润改善。
- **[压降有息负债]** -> [筹资活动现金流大幅流出]: 公司主动降杠杆，全年带息负债减少103亿元，导致筹资活动现金净流出116.7亿元，但有助于降低未来财务风险。
- **[控股股东资金支持]** -> [维持流动性安全]: 首开集团提供多笔借款及推动30亿元永续债落地，是公司在巨额亏损下仍能维持经营现金流为正的关键外部支撑。
- **[组织架构“瘦身健体”]** -> [管理费用下降]: 实施大规模区域整合重组，将二层级单位压缩至9个大区和1个商管平台，有效控制了人员及管理成本。
- **[永续债发行]** -> [侵蚀归母净利润]: 报告期内新增30亿元永续债，导致需支付2.19亿元利息，直接扣减归属于上市公司股东的净利润，加剧了普通股股东的亏损。

## 风险警告
首开股份当前最核心的风险在于**资产质量持续恶化与净资产快速消耗**。公司已连续三年巨亏，2025年归母净利润亏损66.25亿元，导致净资产从135.72亿元骤降至99.11亿元，降幅达27%。加权平均净资产收益率已跌至-105.77%，意味着股东权益正在被快速侵蚀。若亏损态势延续，公司可能面临净资产为负的极端风险。同时，母公司未分配利润为负，已不具备分红条件，普通股东回报前景黯淡。

其次，**高负债与现金流错配风险**依然突出。尽管公司努力压降有息负债，但期末融资总额仍高达983亿元，且一年内到期的非流动负债激增至224亿元，短期偿债压力巨大。公司经营现金流虽为正，但主要依靠收缩拿地和控制支出实现，而非来自销售回款的强劲增长。一旦市场销售持续低迷或融资环境收紧，公司可能面临流动性危机。此外，大量存货（124亿元）和投资性房地产（30亿元）已被用于抵押融资，进一步限制了财务灵活性。
