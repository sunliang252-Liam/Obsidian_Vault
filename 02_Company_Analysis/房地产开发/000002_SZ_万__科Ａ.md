# 000002.SZ 深度透视

## 因果逻辑链
- **[高地价项目进入结算周期]** -> [巨额亏损]: 2023-2024年销售的高地价项目在2025年集中结算，售价与成本倒挂，导致开发业务结算毛利率仅8.1%，毛利总额大幅萎缩。
- **[市场下行与流动性危机]** -> [大规模资产减值]: 房价持续下跌及公司流动性压力加大，迫使公司对存货和应收款计提减值损失219.3亿元，同比暴增206%。
- **[债务集中到期与展期]** -> [信用风险暴露]: 为应对332.1亿元公开债偿付，公司启动中期票据和公司债展期，导致融资成本上升，信用评级承压。
- **[经营现金流由正转负]** -> [造血能力衰竭]: 销售规模腰斩（-45.5%）叠加保交房支出，经营活动现金流净额由2024年的38亿元转为-9.9亿元，内生现金流枯竭。
- **[资产处置与业务收缩]** -> [非经常性损失]: 为回笼资金，公司以低于账面值的价格完成113亿元大宗资产交易，并退出冰雪业务，产生资产处置亏损。
- **[大股东输血与政策支持]** -> [短期流动性托底]: 深铁集团累计提供335.2亿元股东借款，叠加专项债收储等政策，是公司避免债务违约的关键支撑。
- **[经营服务业务稳健]** -> [结构性缓冲]: 万物云、泊寓、物流等业务贡献580.1亿元收入，虽整体微利，但为开发业务巨亏提供了有限的业绩缓冲。

## 风险警告
**核心风险在于流动性危机已从“压力”演变为“生存”问题。** 公司一年内到期有息负债高达1,605.6亿元，而账面货币资金仅672.4亿元，且其中大部分为受限或预售监管资金。即便有大股东借款和资产处置，公司仍不得不对公开债进行展期，这标志着其信用体系已实质性破裂。若2026年销售无法企稳或融资渠道进一步收窄，公司将面临更广泛的债务违约风险。

**资产质量恶化与持续亏损形成负向螺旋。** 存货跌价准备余额已达266.4亿元，但现房库存仍高达1,144.5亿元，在房价下行周期中，这部分资产存在进一步减值的巨大风险。连续两年巨亏（2024年-495亿，2025年-886亿）已导致净资产缩水42%，母公司存在未弥补亏损，未来分红能力被彻底剥夺。这种“亏损-减值-净资产缩水-融资更难”的循环，是公司走出困境的最大障碍。
