# 600622.SH 深度透视

## 因果逻辑链
- **[住宅开发业务萎缩]** -> [营业收入下降31.68%]: 公司转型多年未新增住宅土地储备，可结转资源持续减少，导致房地产开发收入大幅下滑。
- **[并表基金项目财务亏损]** -> [归母净利润亏损13.91亿元]: 并表基金项目虽经营稳定，但高额财务费用和折旧导致项目层面持续亏损，拖累整体利润。
- **[不动产资产估值下降]** -> [投资亏损扩大]: 市场环境波动导致公司持有的不动产基金LP份额和债权投资公允价值下降，产生大额投资收益损失。
- **[商誉减值]** -> [资产减值损失激增]: 光大安石平台资产管理业务未来经营预期不及预期，公司计提约1.82亿元商誉减值损失。
- **[财务资助可回收性下降]** -> [信用减值损失]: 中关村项目估值下降，公司对其提供的财务资助可回收金额减少，计提约2.42亿元信用减值损失。
- **[非经常性收益支撑]** -> [缓解亏损幅度]: 物业征收补偿收益和租赁纠纷和解补偿等非经常性收益合计约1.32亿元，部分对冲了主营业务的亏损。
- **[关联方借款增加]** -> [流动性风险缓解]: 公司通过向关联方上海安瑰新增借款，补充了流动性，但同时也增加了财务杠杆和关联交易风险。

## 风险警告
公司已连续三年巨额亏损，净资产从48.73亿元骤降至21.11亿元，净资产收益率（-49.63%）显示股东价值正在被快速侵蚀。核心问题在于，公司转型后的不动产资管业务（轻资产）无法覆盖并表基金项目（重资产）的财务成本和资产减值损失，形成了“重资产拖累轻资产”的恶性循环。母公司未分配利润为-9.3亿元，已不具备分红能力，且面临持续的经营性现金流压力。

最大的风险在于商誉和资产估值的持续减值。公司账面仍有5.08亿元商誉，若不动产资管业务未来经营继续不及预期，将进一步计提减值。同时，公司大量资产（如光大安石中心、虹桥中心、朝天门项目等）已用于借款抵押，且对关联方借款依赖度高（其他应付款同比大增41.5%），资产流动性和再融资能力受限。一旦市场环境持续恶化，资产价格继续下行，公司将面临严峻的流动性危机和偿债压力。
