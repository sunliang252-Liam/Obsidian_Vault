# 002016.SZ 深度透视

## 因果逻辑链
- **[房地产收入确认]** -> [营收增长61.12%]: 暻观花园等主力项目竣备交付，大量预收房款结转收入，带动房地产板块收入同比增236.61%。
- **[投资收益贡献]** -> [净利润增长267.19%]: 参股公司玉柴船动受益于造船业回暖，实现大额盈利，按权益法确认投资收益9,701万元，占净利润62.26%。
- **[国资入主赋能]** -> [融资能力提升]: 控股股东变更为珠海大横琴安居后，公司融资渠道拓宽，银行借款大幅增加，筹资现金流净额同比增54.11%。
- **[土地储备成本优势]** -> [毛利率承压]: 早期低成本土地储备虽提供安全垫，但本期结转项目毛利率同比下降13.36%，反映行业整体降价去化压力。
- **[集中供热业务]** -> [多元收入稳定器]: 子公司江西锋源热能依托赣锋锂业产业链，提供稳定供热收入，全年贡献收入2.4亿元，净利润4,236万元。
- **[信用减值损失]** -> [利润侵蚀]: 因商贸业务应收账款单项计提坏账准备，信用减值损失达2,965万元，对利润形成显著拖累。
- **[存货跌价损失]** -> [资产质量风险]: 计提存货跌价损失3,779万元，反映部分项目去化不及预期或成本上升，资产价值面临重估压力。

## 风险警告
**核心风险在于区域集中度过高与行业下行周期的叠加。** 公司土地储备和项目开发高度集中于珠海市斗门区，区域市场供需变化、政策调整将直接冲击业绩。尽管国资入主带来了融资便利，但房地产销售端“止跌回稳”尚需时间，公司毛利率持续下滑，存货跌价风险未消，主业盈利能力的根本性改善仍不确定。

**第二重风险来自非主业业务的信用与法律风险。** 商贸业务应收账款坏账计提已暴露其风控短板，未来若继续扩张可能引发更大损失。同时，公司对原股东梁家荣的海外诉讼虽一审胜诉，但执行难度大、周期长，最终结果及对财务的影响高度不确定，构成潜在的长期或有负债。
