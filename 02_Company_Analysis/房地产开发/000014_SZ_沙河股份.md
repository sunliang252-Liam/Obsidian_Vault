# 000014.SZ 深度透视

## 因果逻辑链
- **长沙房地产市场承压** -> 长沙深业置业净利润亏损1.12亿元: 长沙市场2025年新建商品房成交面积回落，高库存与购买力制约导致去化困难，公司长沙项目销售单价同比下降且计提存货跌价准备，导致子公司亏损。
- **房地产销售单价下降及计提存货跌价准备** -> 公司整体净利润为负: 销售单价下降和存货跌价准备计提导致营业收入同比下降13.35%，房地产销售毛利率由正转负（-1.10%），致使净利润为负。
- **销售佣金增加及关联方借款利息支出增加** -> 期间费用率上升: 销售费用因佣金随销售额增加而增长46.82%，财务费用因关联方借款利息增加而大幅上升132.80%，导致期间费用率提升，进一步侵蚀利润。
- **房地产销售现金流入增加** -> 经营活动现金流净额转正: 2025年房地产销售面积同比增加352.49%，销售回款增加，使得经营活动现金流入大幅增长127.06%，现金流净额由负转正。
- **土地储备不足** -> 公司面临可持续发展压力: 公司仅在郑州荥阳持有2.54万平方米土地储备，远不能满足后续开发需求，迫使公司寻求并购转型，但转型存在不确定性。
- **并购转型计划** -> 公司未来发展战略: 为应对主业萎缩和土地储备不足，公司计划通过并购深圳晶华显示电子进入先进制造业，实现业务转型。

## 风险警告
公司目前深度依赖长沙房地产市场，该市场2025年承压明显，高库存和购买力不足导致去化困难，叠加销售单价下行和存货减值，公司短期盈利能力堪忧。同时，土地储备极度匮乏（仅2.54万平），后续开发能力有限；而并购转型（收购晶华显示）尚在推进中，存在整合风险与不确定性。此外，关联方借款利息增加推高财务费用，流动性虽因销售回款改善，但预售监管资金受限（1.48亿元）和司法冻结资金（1569万元）构成潜在资金压力。

> 沙河实业股份有限公司是由深业沙河(集团)有限公司控股的国内公众上市公司,是深圳市政府在香港的窗口企业--深业集团成员企业之一。公司成立于1992年4月21日,主要从事房地产开发与经营、现代服务型产业用房运营与管理,成功开发深圳荔园新村、祥祺花园、鹿鸣园、宝瑞轩、世纪村、世纪假日广场,新乡世纪村、新乡世纪新城,长沙沙河城、长沙深业中心等10多个住宅、商业项目。曾在全国率先实行住宅质量保证书和住宅使用说明制度,连续多年被深圳权威资信机构评为“AAA”级信誉企业和深圳市守法纳税大户。在深圳世纪村项目开发中首创“国际文明居住标准”理念,获得“全国人居优秀推荐楼”、建设部颁发的“AAA级高尚住宅”“首届中国(深圳)十大著名社区”等荣誉。长沙沙河城项目获“长沙标志性楼盘”“湖湘地产最值得期待的名盘”“长沙房地产别墅代表作”等奖项。新乡世纪村、世纪新城项目先后获“河南省园林小区”“河南省结构中州杯工程”“中原地产最宜居楼盘奖”“新乡市城市建设推动楼盘奖”“最佳品质楼盘奖”等荣誉。公司一方面以深圳本土为依托,参与深业沙河(集团)有限公司城市更新项目的代建;另一方面致力于寻求对外扩张的发展道路,整体确定了以深圳、湖南长沙、河南郑州等三个全国一、二线核心城市为支点的战略布局。
