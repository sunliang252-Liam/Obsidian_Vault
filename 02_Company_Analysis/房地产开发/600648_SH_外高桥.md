# 600648.SH 深度透视

## 因果逻辑链
- **[持有型不动产ABS发行]** -> [归母净利润虚高]: 通过出售子公司股权实现大额非经常性损益（9.47亿），掩盖了扣非净利润暴跌80.75%的惨淡现实。
- **[房产销售断崖式下滑]** -> [营收与毛利双杀]: 无新住宅项目交付，房产销售收入同比骤降84.66%，导致总营收下降17.42%，主营业务造血能力严重萎缩。
- **[定增募资24.75亿]** -> [净资产增厚22.35%]: 成功引入战略投资者，大幅扩充资本实力，但稀释了每股收益（基本EPS下降13.10%）。
- **[产业物业出租率82.3%]** -> [稳定现金流压舱石]: 近445万平米物业租赁贡献稳定收入（19.89亿），是公司在房产销售低迷期维持经营的基本盘。
- **[招商引资与产业集聚]** -> [区域经济活力与长期租金潜力]: 落地108个项目，新增12家总部，聚焦生物医药、脑机接口等新赛道，为未来物业去化和产业服务收入增长奠定基础。
- **[融资成本下降与债务结构优化]** -> [财务费用减少11.81%]: 通过发行低息公司债、中票替换高息贷款，整体平均融资成本降至2.45%，有效缓解了利润压力。
- **[森兰区域开发与运营]** -> [城市更新品牌价值提升]: 森兰商办出租率提升至84.51%，品牌活动引流，但住宅项目（海天名筑、航荟名庭）销售缓慢，成为去化难点。

## 风险警告
**核心风险在于主业空心化与利润对非经常性损益的严重依赖。** 扣非净利润仅6845万元，同比暴跌80.75%，表明公司核心的房产开发和贸易服务业务已陷入困境。房产销售因市场下行和项目定位问题（如航荟名庭、海天名筑）几乎停滞，而贸易服务毛利率低且面临地缘政治风险。公司2025年9.35亿的归母净利润，几乎完全依赖发行持有型不动产ABS产生的9.47亿投资收益，这种“卖资产”换利润的模式不可持续。

**资产质量与现金流风险不容忽视。** 尽管账面净资产因定增增厚，但公司经营活动现金流净额为-7641万元，显示主营业务自身造血能力不足。同时，募投项目（如D1C-108#~116#通用厂房）出租率仅8%，远低于预期，存在资产减值风险。此外，公司存货中24.06亿用于抵押借款，且住宅项目去化缓慢，若市场持续低迷，将面临较大的资产减值和资金周转压力。
