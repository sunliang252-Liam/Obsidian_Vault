# 002594.SZ 深度透视

## 因果逻辑链
- **[技术研发高投入]** -> [产品竞争力持续领先]: 年研发投入634亿元（同比+17%），支撑“超级e平台”、“天神之眼”等技术迭代，巩固全球新能源汽车销量冠军地位。
- **[全球化战略加速]** -> [海外收入高增长]: 整车出口突破百万辆（同比+1.4倍），海外收入达3107亿元（同比+40%），成为新增长引擎。
- **[多品牌高端化突破]** -> [产品结构优化]: 仰望、腾势、方程豹合计销量同比翻倍，提升单车均价与品牌溢价，对冲大众市场价格战压力。
- **[垂直整合供应链]** -> [成本控制与交付保障]: 自研电池、电机、电控及芯片，应付账款周转天数行业较低，在价格战中维持相对韧性。
- **[“全民智驾”战略]** -> [智能化普及与数据壁垒]: 将“天神之眼”覆盖全系车型，辅助驾驶数据日增1.6亿公里，加速算法迭代，构建数据飞轮。
- **[第二代刀片电池+闪充技术]** -> [解决核心用户痛点]: 实现“5分钟充70%”，攻克“充电慢”与“低温充电难”，巩固电动化技术护城河。
- **[储能业务爆发]** -> [第二增长曲线成型]: 全球储能系统出货量超60GWh，位列全球第一，并与沙特签署12.5GWh大单，打开新成长空间。

## 风险警告
**盈利质量显著下滑与现金流恶化。** 2025年归母净利润同比下降18.97%，扣非净利润下降20.38%，而营收仅微增3.46%。更关键的是，经营活动现金流净额骤降55.69%至591亿元，远低于净利润。这主要源于购买商品、支付劳务的现金大幅增加，暗示公司可能在激烈价格战中通过牺牲利润和账期来保销量，盈利的“含金量”正在下降。

**国内价格战白热化与海外地缘风险。** 年报明确承认“价格竞争加剧，产业盈利空间受到挤压”。公司毛利率（尤其是汽车业务）同比下滑，且国内收入同比下降11.17%，显示国内市场增长已遇瓶颈。同时，海外业务虽高速增长，但面临贸易壁垒、地缘政治紧张及汇率波动风险，海外工厂的本地化运营与盈利爬坡仍需时间验证。
