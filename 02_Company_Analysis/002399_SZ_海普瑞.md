# 002399.SZ 深度透视

## 因果逻辑链
- **[制剂业务全球销量两位数增长]** -> [营收增长3.75%]: 制剂收入35.09亿元（+17.52%），占总收入64.05%，成为核心增长引擎，抵消了原料药业务下滑的影响。
- **[原料药出口价格持续低位运行]** -> [原料药收入下降25.24%]: 肝素原料药行业竞争加剧，价格处于周期低位，导致该板块收入仅7.99亿元，毛利率降至15.72%。
- **[2024年同期大额一次性投资收益]** -> [归母净利润同比下降45.96%]: 2024年因处置资产等产生非经常性收益，2025年无此项目，导致归母净利润从6.47亿降至3.49亿。
- **[扣非净利润同比上升66.11%]** -> [主业盈利能力显著改善]: 剔除一次性因素后，核心业务利润从2.54亿增至4.21亿，显示制剂和CDMO业务的实际经营质量提升。
- **[坪山新产线投产与欧洲GMP认证]** -> [产能与质量壁垒提升]: 年产5.5亿支制剂产能落地，且获得欧盟生产批准，为全球市场扩张提供了坚实的供应保障和合规基础。
- **[全球贸易保护主义与关税壁垒]** -> [美国市场经营承压]: 美国关税政策变化对业务产生影响，公司通过战略性价格调整和“自营+代理”模式应对，但市场环境仍具挑战。
- **[创新药管线临床推进]** -> [长期价值储备]: 自研H1710进入I期临床，多个引进项目（Oregovomab、AR-301）处于III期或后续开发阶段，但均面临临床失败或进度不及预期的风险。

## 风险警告
**核心风险在于肝素原料药业务的持续低迷与创新药管线的高不确定性。** 原料药价格处于周期低位且竞争加剧，该板块收入与毛利率双降，短期内难以贡献利润，反而可能成为拖累。同时，公司重金投入的创新药管线（如Oregovomab、AR-301）已有多个项目未达临床终点，后续开发路径不明，存在大额资产减值或投资损失的风险，对利润表构成潜在冲击。

**财务风险体现在资产减值与公允价值变动对利润的侵蚀。** 报告期内，公司确认了高达2.18亿元的资产及信用减值损失，以及0.77亿元的公允价值变动损失，合计近3亿元，直接吞噬了主业利润。此外，公司持有大量金融资产（交易性金融资产、其他非流动金融资产等），其价值波动将显著影响净利润的稳定性，投资者需警惕市场波动带来的非经常性损益冲击。
