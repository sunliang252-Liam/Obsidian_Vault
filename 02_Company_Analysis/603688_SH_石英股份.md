# 603688.SH 深度透视

## 因果逻辑链
- **[光伏行业产能过剩与供需错配]** -> [营收与利润大幅下滑]: 光伏业务收入同比减少40.46%，拖累整体营收下降16.71%，净利润下降54.03%，核心盈利来源受行业周期重创。
- **[半导体业务逆势增长]** -> [结构优化与长期增长引擎]: 光纤半导体业务收入同比增长3.24%，占比升至53.61%，成为公司唯一增长板块，对冲光伏业务下滑，奠定未来增长基础。
- **[高纯石英砂自用比例提升]** -> [产业链垂直整合优势]: 石英砂产量增长46.67%，但外销仅3606吨，自用7293吨，表明公司正将核心原料优势内化为下游高端制品的成本与品质壁垒。
- **[非经常性损益支撑利润]** -> [盈利质量显著下降]: 扣非净利润同比暴跌71.70%，而公允价值变动收益（理财）达5571万元，占归母净利润36%，主业盈利能力严重弱化。
- **[经营活动现金流由正转负]** -> [营运资金压力骤增]: 经营性现金流净额为-5983万元，与净利润严重背离，主因销售回款减少，反映下游客户付款能力恶化或公司放宽信用政策。
- **[产能扩张与项目建设]** -> [未来折旧与资本开支压力]: 天水、包头、马来西亚等项目推进，固定资产同比增25%，在建工程转固，未来折旧费用将侵蚀利润，若产能消化不及预期，风险显著。
- **[商誉减值]** -> [并购整合风险暴露]: 强邦石英商誉减值56.16%，表明前期并购标的经营不及预期，需警惕其他子公司潜在减值风险。

## 风险警告
**核心风险在于光伏业务深度衰退与盈利质量坍塌。** 公司营收与利润高度依赖光伏行业，而该行业正处于严重的产能出清周期，导致公司核心业务收入锐减、毛利率暴跌。更危险的是，扣非净利润仅占归母净利润的50%，大量利润来自理财收益等非经常性损益，表明主业已失去造血能力。同时，经营性现金流由正转负，显示回款困难，财务健康度恶化。

**产能扩张与商誉减值构成双重隐患。** 公司在行业低谷期逆势扩张，天水、包头、马来西亚等项目将带来大量新增折旧，若半导体等新业务无法快速放量，将加剧盈利压力。此外，强邦石英商誉已减值过半，需警惕其他子公司（如上海泛石持续亏损）的潜在减值风险，这可能在利润表上形成“二次打击”。
