# 300184.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [营收增长13.37%]: AI服务器、光模块、数据中心电源等需求井喷，带动公司代理分销业务收入增长。
- **[半导体行业景气度回升]** -> [净利润增长74.69%]: 行业上行周期叠加公司积极布局，规模效应显现，利润弹性远超营收增速。
- **[下游多领域需求共振]** -> [代理分销业务收入增长13.15%]: 工业及新能源（3D打印、光储充）、安防（海外备货）、消费电子（补贴政策）等多领域需求同步回暖。
- **[自研MCU芯片起量]** -> [自研芯片业务收入增长]: 前期研发的MCU新产品量产，并获下游客户订单，推动“代理+自研”双轮战略落地。
- **[智能电网业务承压]** -> [电力产品业务收入下降]: 国网新标准电表招标流标、金额同比大降57.6%，公司相关业务受冲击。
- **[经营现金流为负]** -> [现金流与净利润严重背离]: 分销业务“先款后货”模式导致采购付款与销售回款周期错配，本期采购增加致现金流净流出9085万元。
- **[研发投入阶段性缩减]** -> [研发费用同比下降33.85%]: 部分研发项目完工，短期费用减少，但长期技术储备需持续关注。

## 风险警告
**核心风险在于经营现金流持续为负与存货高企的双重压力。** 公司2025年经营现金流净额为-9085万元，与1.72亿元的净利润严重背离，主因是分销业务垫资模式导致采购付款与回款周期错配。同时，存货高达19.81亿元，占总资产28.44%，且计提了6942万元的资产减值损失。若下游需求不及预期或上游涨价潮传导不畅，公司将面临巨大的存货跌价和资金周转压力。

**另一重大风险是国际贸易关税与汇率波动。** 公司境外子公司销售占比40.38%，且主要供应商以美元结算，持有大量美元负债。美国“对等关税”政策加剧供应链不确定性，而人民币汇率短期大幅波动将直接导致汇兑损失，侵蚀本已微薄的利润（2025年财务费用中汇兑收益仅198万元）。此外，公司并购形成的商誉虽未减值，但若被并购子公司（如帕太集团）盈利不及预期，商誉减值风险始终悬顶。
