# 688276.SH 深度透视

## 因果逻辑链
- **[带状疱疹疫苗退货及降价]** -> [营收暴跌50.77%]: 部分已确认收入的带状疱疹疫苗到效期未接种发生退货，叠加主动降价推行惠民项目，导致该产品收入为负（-2.05亿元），直接拖垮整体营收。
- **[新生儿出生率下降+水痘疫苗竞争加剧]** -> [水痘疫苗销量下滑23.2%]: 目标人群持续萎缩，叠加同类产品厂家增多、部分地区纳入免疫规划降价，导致核心儿童疫苗收入承压。
- **[带状疱疹疫苗退货量大于正向销量]** -> [该产品营业成本为负]: 退货冲减了已结转的成本，导致带状疱疹疫苗营业成本为-127万元，毛利率异常虚高至99.38%。
- **[营收腰斩但研发投入不减反增]** -> [研发费用率飙升至41.13%]: 在收入大幅下滑背景下，公司仍加速推进液体鼻喷流感疫苗扩龄、百白破（三组分）III期等临床项目，研发投入同比增长59.37%。
- **[销售费用率畸高]** -> [侵蚀利润]: 销售费用占营收比例高达64.35%，尽管绝对值同比下降18%，但收入降幅更大，导致费用率失控，是亏损的重要原因。
- **[对传信生物追加投资]** -> [产生大额投资亏损]: 因增资后持股比例达33.32%并派驻董事，由金融资产转为长期股权投资按权益法核算，确认约-3,400万元的投资收益损失。
- **[带状疱疹及液体流感疫苗计提减值]** -> [资产减值损失扩大]: 报告期内资产减值损失达7,167万元，同比增加79.4%，主要系对带状疱疹疫苗及液体流感疫苗产品计提跌价准备。

## 风险警告
百克生物正面临核心产品“双杀”的严峻局面。带状疱疹疫苗作为公司寄予厚望的成人疫苗增长极，不仅未能放量，反而因终端接种意愿不足导致大规模退货和被迫降价，直接导致该产品收入为负，彻底颠覆了其利润支柱的定位。同时，水痘疫苗作为基本盘，正遭受新生儿数量持续下降（2025年全国出生人口下降约17%）和市场竞争加剧的双重挤压，销量持续萎缩。两大核心产品同时失速，公司短期业绩反转缺乏明确支撑。

公司为应对困境，大幅增加研发投入（研发费用率41.13%）以布局未来管线，但高昂的销售费用率（64.35%）显示现有营销体系效率低下，未能有效转化为销售增长。同时，应收账款高达9.37亿元，占流动资产65.84%，回款压力巨大。在营收锐减、持续亏损的背景下，公司现金流虽暂时为正，但若核心产品销售无法企稳，高额的研发与销售投入将构成持续的财务压力，存在流动性风险。
