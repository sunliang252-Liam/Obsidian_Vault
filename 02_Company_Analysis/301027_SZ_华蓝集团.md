# 301027.SZ 深度透视

## 因果逻辑链
- **[光伏电站并网]** -> [营收增长19.53%]: 光伏发电收入同比翻倍至6991万元，拉动整体营收增长，但增量利润被减值吞噬。
- **[应收账款高企与坏账计提]** -> [净利润亏损3512万元]: 信用减值损失高达1.55亿元，同比增长16.65%，直接导致增收不增利。
- **[未决诉讼计提预计负债]** -> [营业外支出激增]: 因诉讼新增预计负债1108万元，进一步拖累利润，成为亏损扩大的次要原因。
- **[传统设计业务萎缩]** -> [研发人员优化35%]: 受房地产下行与财政收紧影响，公司主动优化人员结构，研发人员从313人降至203人。
- **[化债政策推动回款]** -> [经营性现金流为正]: 政府化债措施推进，公司经营活动现金流净额6658万元，虽同比下降但保持正向。
- **[新能源业务培育]** -> [第二增长曲线初现]: 华蓝能源电费收入6991万元，并拓展分布式光伏EPC，形成“投资+设计+总包”全链条能力。
- **[控制权变更]** -> [管理层大换血]: 2026年初栩桐投资入主，原董事长、总经理、财务总监等核心高管离任，新团队到位。

## 风险警告
**核心风险在于应收账款“堰塞湖”与利润质量严重脱节。** 公司应收账款高达7.9亿元，占总资产36.45%，且信用减值损失1.55亿元已超过营收增幅带来的毛利增量。尽管政府化债推动经营性现金流为正，但坏账计提仍在加速，若回款不及预期，利润将持续被侵蚀，甚至引发流动性危机。

**第二增长曲线尚在培育期，无法对冲主业下行。** 光伏发电虽翻倍增长，但毛利率下降3.21%，且高度依赖融资租赁（长期应付款增至9645万元），财务费用同比暴增134%。传统工程设计业务收入增长15.42%，但毛利率下滑3.5%，行业竞争加剧与项目小型化趋势下，主业盈利能力持续承压。
