# 000919.SZ 深度透视

## 因果逻辑链
- **[医疗服务板块亏损]** -> [归母净利润增长33.42%]: 2024年因同一控制下企业合并（梅山医院）产生大额非经常性损益（-6173万元），2025年该影响消除，导致归母净利润同比大幅增长，但扣非净利润下降28.45%。
- **[销售费用激增]** -> [扣非净利润下降28.45%]: 销售费用同比大增62.71%，主要用于产品营销和市场推广，侵蚀了主营业务利润，导致扣非净利润显著下滑。
- **[商誉减值]** -> [资产减值损失扩大]: 计提商誉减值损失1804.58万元，是资产减值损失（-1906.5万元）的主要构成，直接冲减当期利润。
- **[医疗服务收入下降]** -> [整体营收微降2.56%]: 医疗服务收入同比下降5.22%，拖累整体营收表现，尽管药品生产销售板块收入持平，但未能完全抵消医疗服务板块的下滑。
- **[投资收益贡献]** -> [非经常性损益支撑利润]: 投资收益（含理财产品收益2182.45万元）占利润总额的46.32%，成为公司利润的重要补充，但该收益不具有可持续性。
- **[核心产品稳定]** -> [药品制造板块基本盘稳固]: 脉络宁注射液、琥珀酸亚铁片等核心产品凭借品牌和基药目录优势，销售平稳，为业绩提供稳定支撑。
- **[老龄化需求]** -> [医康养护业务长期逻辑]: 人口老龄化加深（60岁以上人口占比23%），为公司医康养护业务（医院+养老机构）提供了持续扩容的市场需求。

## 风险警告
**核心风险在于医疗服务板块的持续亏损与商誉减值压力。** 公司旗下宿迁医院、安庆医院等主要医疗机构均出现亏损，医疗服务整体毛利率仅5.73%，且同比下降2.16个百分点。这直接导致公司对相关资产组计提了1804.58万元的商誉减值。若未来医保控费、医疗反腐等政策持续加压，或医院运营效率无法改善，商誉减值风险将进一步释放，对利润造成重大冲击。

**第二重风险是盈利能力的结构性恶化。** 公司扣非净利润同比下降28.45%，而销售费用却激增62.71%，表明公司为维持药品销售增长付出了高昂的营销成本，主营业务的内生增长动力不足。同时，利润高度依赖理财产品收益等非经常性损益，这种盈利模式在利率下行周期中面临挑战。此外，两大募投项目（合肥养老项目、原料药平台项目）进度严重滞后，投资进度分别仅为0.06%和2.76%，未来项目能否顺利推进及达产存在重大不确定性。
