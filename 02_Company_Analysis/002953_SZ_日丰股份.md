# 002953.SZ 深度透视

## 因果逻辑链
- **[新能源电缆爆发式增长]** -> [营收结构优化]: 新能源电缆收入同比增长36.33%，成为业绩增长最快引擎，推动公司从传统家电线缆向高附加值领域转型。
- **[通信装备组件受益AI算力基建]** -> [营收高速增长]: 通信装备组件收入同比增长26.11%，受益于5G规模化与AI数据中心建设，成为第二大增长极。
- **[海外市场拓展]** -> [出口业务稳健增长]: 出口收入同比增长22%，海外销售团队与渠道建设成效显现，有效对冲内销市场增速放缓风险。
- **[“成本+目标毛利”定价模式]** -> [毛利率相对稳定]: 尽管铜价波动，但该定价模式将原材料价格风险部分转移至下游，使综合毛利率仅微降0.73个百分点。
- **[向特定对象发行股票募资]** -> [资本结构优化]: 募资2.26亿元补充流动资金，净资产增长18.36%，资产负债率下降，财务风险降低。
- **[经营活动现金流大幅改善]** -> [盈利质量提升]: 经营现金流净额同比增长121.57%，主要得益于营收增长与应收账款周转率提升，现金流与净利润匹配度显著改善。
- **[子公司安徽日丰清算注销]** -> [管理效率提升]: 处置低效资产产生资产处置收益1413万元，优化管理架构，降低运营成本。

## 风险警告
**核心风险在于原材料价格波动与毛利率下行压力。** 铜材占产品成本比例极高，尽管公司采用“成本+目标毛利”定价模式，但2025年新能源电缆、外销业务毛利率分别下降2.53和1.74个百分点，显示成本传导并不完全。若铜价持续高位或剧烈波动，将直接侵蚀公司利润空间，并加大营运资金压力。

**其次，市场竞争加剧与应收账款风险不容忽视。** 线缆行业中低端同质化严重，价格战激烈，公司需持续投入研发以维持高端市场优势。同时，应收账款余额高达12.26亿元，占营收比重约27%，且信用减值损失同比大幅增加至1614万元，若下游客户（尤其是工程机械、新能源领域）经营恶化，坏账风险将显著冲击业绩。
