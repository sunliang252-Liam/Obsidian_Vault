# 301235.SZ 深度透视

## 因果逻辑链
- **[电子洁净业务从零到一突破]** -> 营收增长33.87%: 2024年成立电子洁净事业部，2025年交付多个标杆项目，形成“医疗专项-实验室-电子洁净”三足鼎立格局，驱动第二增长曲线。
- **[战略聚焦“三主三副”业务布局]** -> 净利润增长76.39%: 医疗专项巩固基本盘，实验室攻坚标杆项目，电子洁净实现跨越式突破，三大主业协同发展，带动利润弹性释放。
- **[可转换公司债券利息费用增加]** -> 财务费用增长79.05%: 2025年1月发行可转债，导致利息支出大幅增加，对净利润形成一定侵蚀。
- **[股权激励及咨询服务费用增长]** -> 管理费用增长46.08%: 报告期内新增股权激励费用，叠加资质办理、咨询服务等支出，管理费用率显著上升。
- **[电子洁净业务开拓期垫资增加]** -> 经营现金流净额-9,627万元: 新业务处于投入期，购买商品、接受劳务支付的现金增幅远超销售回款，导致经营活动现金流净额由正转负。
- **[应收账款余额持续攀升]** -> 信用减值损失-8,728万元: 业务规模扩大叠加公立医院客户回款周期长，应收账款同比增长14.6%，导致信用减值损失大幅增加，占利润总额61.62%。
- **[在手订单37.42亿元]** -> 未来收入确定性增强: 截至报告期末，在手订单中医疗专项23.73亿、实验室6.62亿、电子洁净2.99亿，为未来2-3年业绩提供坚实支撑。

## 风险警告
**现金流与应收账款的双重压力是核心风险。** 公司经营活动现金流净额为-9,627万元，同比下降165.24%，主要因电子洁净业务开拓期垫资增加。同时，应收账款高达18.76亿元，占总资产43.67%，信用减值损失达8,728万元，占利润总额61.62%。公司客户以公立医院为主，回款受财政资金安排影响，实际回款周期长于合同约定，若地方政府财政持续紧张，坏账风险将显著放大。

**新业务扩张带来的管理挑战不容忽视。** 公司从医疗专项向电子半导体、实验室、海外业务全面拓展，管理费用同比增长46.08%，研发费用增长38.51%。新业务领域竞争激烈，技术门槛高，若项目交付质量不达预期或市场拓展受阻，将拖累整体盈利水平。此外，海外业务面临地缘政治、法律合规等不确定性，出海战略的落地效果尚需验证。
