# 601218.SH 深度透视

## 因果逻辑链
- **[政策驱动装机放量]** -> [铸造业务营收增长17.24%]: “136号文”推动风电项目加速落地，前期订单集中释放，公司订单量增加。
- **[原材料价格回落+规模效应]** -> [铸造业务毛利率提升4.85个百分点]: 生铁、废钢等成本端减压，叠加产量增加摊薄固定成本，利润弹性释放。
- **[风况改善+电力交易增收]** -> [风电业务营收增长5.67%]: 利用小时数提升至2,436小时，且市场化交易较保障性电价增收293万元。
- **[销售费用大幅压降]** -> [期间费用率显著下降]: 去年同期支付Vernova售后服务费导致高基数，本期无此一次性支出，费用管控见效。
- **[增值税优惠政策红利]** -> [其他收益同比增长226%]: 报告期内享受的增值税即征即退等优惠金额大幅增加。
- **[权益法下投资收益增加]** -> [非经常性损益贡献利润]: 对联营企业确认的投资收益同比增长近一倍，增厚净利润。
- **[收购新能轴承]** -> [完善风电产业链布局]: 从单一铸件供应商向“铸件+轴承”一站式零部件供应商转型，提升客户粘性与产品价值。

## 风险警告
**核心风险在于铸造主业毛利率极低且行业竞争持续恶化。** 尽管2025年毛利率因成本回落和规模效应有所修复，但仅10.66%，仍处于微利状态。报告明确指出“铸件产能仍然处于严重过剩状态，未来几年都将面临激烈竞争并加速淘汰”，这意味着公司主业盈利能力极其脆弱，对原材料价格和下游整机厂商压价高度敏感，一旦成本端反弹或需求回落，利润将迅速被侵蚀。

**第二重风险来自政策与税收的负面冲击。** 陆上风电增值税即征即退50%政策已于2025年11月终止，这将直接减少公司未来的其他收益。同时，盐山宏润发电的所得税优惠政策到期，导致2025年所得税费用同比暴增478%，未来税负压力将持续。此外，电价市场化改革虽短期带来交易收益，但长期电价中枢下移将压缩风电运营业务的利润空间。
