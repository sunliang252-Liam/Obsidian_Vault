# 300249.SZ 深度透视

## 因果逻辑链
- **[AI算力基建爆发]** -> [精密温控设备收入+57.87%]: 全球AI数据中心建设井喷，高密度机柜散热需求刚性增长，公司风墙、液冷等核心产品订单激增。
- **[聚焦战略剥离环保]** -> [毛利率+3.48pct]: 剥离低毛利环保业务后，资源集中于信息数据领域，产品结构优化，整体盈利质量提升。
- **[风墙产品跻身第一梯队]** -> [市场份额TOP3]: 动态双冷源风墙成为行业主流方案，累计发货折合IT功率超600兆瓦，巩固国内龙头地位。
- **[海外本地化运营落地]** -> [海外订单+182.62%]: 马来西亚子公司及东南亚服务中心建成，从“跟随出海”转向“主动拓展”，产品批量落地标杆项目。
- **[产能翻倍+液冷产线投产]** -> [设备月均产出+49%]: 新建万级洁净室及液冷专用产线，风墙、CDU等战略新品实现规模化量产与准时交付。
- **[员工持股计划落地]** -> [核心团队绑定]: 39名骨干认购245万股，形成“利益共享、风险共担”长效机制，提升组织战斗力与稳定性。

## 风险警告
**盈利质量与现金流背离风险**：公司2025年归母净利润扭亏为盈至3059万元，但经营活动现金流净额同比下降31.57%至7059万元，且净利润与现金流净额差异达4亿元。主要因生产规模扩大导致存货增加及经营性应收项目大幅增长，若下游客户回款周期延长或订单增速放缓，可能引发现金流紧张，侵蚀盈利改善成果。

**历史包袱与资产减值风险**：截至报告期末，合并报表未分配利润仍为-2亿元，母公司未弥补亏损-1.26亿元，多年亏损积累尚未消化。同时，公司计提信用减值损失1972万元、资产减值923万元，且存在多起未结诉讼（涉案金额超亿元），历史项目坏账及法律纠纷可能持续拖累利润表，制约分红与再融资能力。
