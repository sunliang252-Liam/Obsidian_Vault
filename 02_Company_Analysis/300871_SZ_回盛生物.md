# 300871.SZ 深度透视

## 因果逻辑链
- **[原料-制剂一体化 + 产品价格上行]** -> [原料药毛利率飙升33.46%]: 自产大环内酯类原料药（泰万菌素市占率超50%）成本优化，叠加下游需求回暖价格上行，驱动原料药业务收入增长81.73%，毛利率从个位数跃升至39.25%。
- **[可转债提前赎回]** -> [财务费用锐减68.10%]: 2025年5月完成“回盛转债”强制赎回，可转债利息支出消失，财务费用同比减少2765万元，直接增厚净利润。
- **[下游生猪养殖景气度回升]** -> [化药制剂收入增长24.72%]: 自2024年二季度猪价回暖，养殖企业盈利改善，兽药需求增加，公司集团客户基本盘稳中有进。
- **[海外市场爆发]** -> [出口收入同比增长152.26%]: 原料药出口超2亿元，销售网络扩展至30多国，越南基地投产，海外成为第二增长极。
- **[研发投入持续加码]** -> [新兽药证书与产品线扩充]: 研发费用增长43.05%，取得7个新兽药证书，宠物药销售额同比增长186.02%，为长期增长储备弹药。
- **[子公司湖北回盛贡献核心利润]** -> [净利润扭亏为盈]: 湖北回盛（原料药生产基地）实现净利润2.5亿元，占合并净利润的98.8%，是公司盈利反转的绝对主力。

## 风险警告
**核心风险：业绩高度依赖单一产品与单一子公司。** 公司利润几乎全部来自湖北回盛的原料药业务（泰万菌素等大环内酯类），化药制剂毛利率仅24.6%，盈利能力薄弱。一旦原料药价格周期下行或竞争加剧，业绩将剧烈波动。2024年亏损、2025年暴赚的极端波动已充分暴露这一脆弱性。

**次要风险：下游猪周期依赖与应收账款隐患。** 公司95%收入来自兽药，终端与生猪养殖景气度强相关，猪价下行将直接压缩需求与利润空间。同时，集团客户“先货后款”模式导致应收账款达3.95亿元，若养殖企业再度陷入财务困境，坏账风险不可忽视。
