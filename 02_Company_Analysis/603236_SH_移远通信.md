# 603236.SH 深度透视

## 因果逻辑链
- **[物联网市场需求持续释放]** -> [营收增长30.83%]: 5G、车载、智能模组等核心业务量价齐升，叠加ODM、天线等衍生业务规模扩张，共同推动营收突破243亿元。
- **[“模组+AI+方案”商业模式升维]** -> [净利润增长42.30%]: 从单一硬件销售转向“卖方案、卖服务”，AI玩具、机器人、智能座舱等高附加值解决方案落地，提升整体盈利质量。
- **[原材料紧缺与价格持续上涨]** -> [经营活动现金流净流出6.58亿]: 为保障供应链安全，公司提前备货并预付货款，导致存货及预付款项大幅增加，现金循环周期拉长。
- **[向特定对象发行股票募资22.2亿]** -> [净资产增长69.74%]: 定增资金到位，显著增强资本实力，为5G、AI等前沿技术研发及全球市场拓展提供资金保障。
- **[全球化研发与制造布局]** -> [境外收入占比52.8%]: 八大研发中心与全球多地工厂形成弹性供应体系，实现“以本地化服务全球化”，有效贴近客户并提升供应链韧性。
- **[端侧AI商业化落地]** -> [开辟第二增长曲线]: 推出“模组+AI大模型+算法+平台”整体方案，在AI玩具、机器人、智慧零售等场景打造标杆案例，实现从技术突破到收入贡献的转化。
- **[车载业务全域布局]** -> [深度绑定全球超40家车企]: 从通信模组延伸至智能座舱、C-V2X、高精度定位等六大场景，形成“舱泊一体”“舱联融合”域控解决方案，锁定高价值汽车市场。
- **[管理费用同比增长52.29%]** -> [运营效率短期承压]: 运营类人员增加及业务拓展差旅费上升，导致管理费用增速显著高于营收增速，对利润端形成一定侵蚀。

## 风险警告
**核心风险在于供应链与现金流的双重挤压。** 报告期内，公司经营活动现金流净额由正转负，骤降至-6.58亿元，直接原因是原材料紧缺与涨价引发的激进备货。这暴露了公司对上游芯片等核心原材料的议价能力有限，且成本传导机制存在时滞。若原材料价格持续高位或供应紧张加剧，公司毛利率将进一步承压，现金流恶化可能限制其后续研发投入与业务扩张。

**另一重大风险是海外专利诉讼的不确定性。** 公司正面临飞利浦在美国和欧洲发起的多起专利侵权诉讼，尽管公司此前在ITC调查中胜诉，但诉讼周期长、成本高，且可能面临禁令或高额赔偿风险。这不仅会直接侵蚀利润，更可能扰乱公司在欧美核心市场的销售节奏与客户关系，对全球化战略构成实质性威胁。
