# 300886.SZ 深度透视

## 因果逻辑链
- **内酯香料细分龙头地位** -> 营收增长7.83%: 公司专注于丙位、丁位内酯系列香料，凭借技术、规模与客户优势，在细分领域占据领先地位，驱动收入稳健增长。
- **深化与国际十大香精公司合作** -> 净利润增长36.79%: 与奇华顿、IFF等国际巨头建立稳固关系，提升订单稳定性与产品溢价，叠加成本优化，利润增速远超营收。
- **合肥基地产能扩张** -> 在建工程激增至7154万元: 年产1300吨香料生产装置建设接近尾声，为未来业绩增长提供新引擎，但短期带来资本开支压力。
- **原材料采购策略优化** -> 毛利率提升1个百分点: 通过询比价采购和价格联动机制，有效控制正辛醇、正己醇等主要原料成本，成为直接盈利增长点。
- **研发驱动产品升级** -> 新产品中试取得突破: 持续投入研发（占营收4.97%），优化丙位内酯工艺、开发大环内酯等新产品，丰富产品线并提升附加值。
- **出口占比高（56.89%）** -> 财务费用因汇率波动转正: 外销为主的结构使公司暴露于汇率风险，2025年汇兑损失增加导致财务费用同比大幅增长115.96%。
- **股权激励归属条件成就** -> 管理费用增加: 2022年限制性股票激励计划第二个归属期条件达成，确认股份支付费用，对当期管理费用产生一定影响。

## 风险警告
**核心风险在于产能扩张与下游需求匹配的不确定性。** 公司合肥基地1300吨香料项目即将投产，但若全球宏观经济下行或下游食品、日化行业需求增速放缓，新增产能可能无法被市场充分消化，导致产能利用率下降、折旧成本上升，侵蚀利润。此外，公司约60%收入来自海外，国际贸易摩擦、地缘政治风险及汇率大幅波动（2025年财务费用已因汇兑损失转正）将持续构成经营挑战。

**另一关键风险是原材料价格波动与行业竞争加剧。** 公司主要原料（正辛醇、正己醇等）为石油化工衍生品，价格与国际油价高度相关。若原材料价格大幅上涨，公司向下游传导成本的能力有限，将直接压缩毛利率。同时，国内香精香料行业集中度较低，中小企业众多，若行业整合加速或国际巨头加大本土化布局，公司可能面临市场份额被蚕食、产品价格承压的风险。
