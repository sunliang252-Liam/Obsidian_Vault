# 600397.SH 深度透视

## 因果逻辑链
- **重大资产重组：置出亏损煤炭业务，置入盈利磁选装备业务** -> 主营业务由煤炭采选变更为磁选装备研发生产销售: 通过资产置换实现业务转型
- **主营业务变更** -> 营业收入大幅下降（-56.26%）: 置出煤炭业务规模较大（上年营收占比高），置入磁选业务营收规模较小，导致并表后总营收下滑
- **主营业务变更** -> 期间费用大幅下降（-45.01%）: 置出煤炭业务相关费用（销售、管理、财务等）不再并表
- **主营业务变更** -> 资产规模大幅缩减（总资产-87.28%，净资产-60.50%）: 置出煤炭业务资产（如矿井、铁路等重资产），置入磁选装备业务资产规模较小
- **置入磁选装备业务** -> 净利润亏损（-29,133.69万元）但亏损幅度仅减少20.56%: 置入业务盈利（金环磁选净利润5,091.60万元），但置出煤炭业务在置出前发生大额亏损，拖累整体业绩
- **煤炭业务置出前大额亏损** -> 经营活动现金流净额为负（-92,506,125.93元）: 置出前煤炭业务持续亏损，经营性现金流恶化
- **资产置换导致的现金收付** -> 投资活动现金流净额为负（-353,884,431.38元）: 置出子公司收到的现金净额小于置入支付或其他投资支出
- **磁选装备产品结构向大型化调整** -> 磁选装备产销量下降（生产量-27.84%，销售量-22.05%）: 大型化设备单位价值高，但台套数减少
- **磁选装备行业需求增长（全球磁选机市场CAGR 6.40%）** -> 公司未来营收和盈利有望改善: 新主营所处行业景气度上升，且公司为行业龙头（SLon系列全球标杆）

## 风险警告
公司通过资产置换转型磁选装备业务，实现了业务根本性变化，但存在以下风险：1）新旧业务规模差距大，置入的磁选装备业务营收（4.07亿元）远小于置出的煤炭业务（20.86亿元），总营收短期内大幅萎缩；2）置入业务盈利能力虽优于煤炭业务，但净利润贡献尚不足以弥补置出前煤炭亏损，2025年仍亏损2.91亿元；3）磁选装备业务对单一客户依赖度较高（前五客户占营收54.89%），且贸易业务（煤炭及焦炭贸易）仍占营收较大比重，需关注其可持续性；4）重组后公司资产规模大幅缩小，抗风险能力有待观察；5）研发投入占营收比例仅0.53%，需关注创新投入能否支撑技术领先地位。
