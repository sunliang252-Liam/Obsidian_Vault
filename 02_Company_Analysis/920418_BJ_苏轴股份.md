# 920418.BJ 深度透视

## 因果逻辑链
- **公司主动调整产品结构，向高技术、高附加值领域转型** -> 营业成本增速高于营收增速: 高端产品对材料、工艺和质量控制要求更高，导致单位成本上升
- **研发投入加大** -> 净利润增速放缓: 研发费用增长18.69%（4556.59万元，占营收6.28%），对利润形成压力
- **政府补助增加** -> 净利润保持稳定: 其他收益增长219.99%（增加893.04万元），抵补了成本上升和研发投入
- **销售回款增加及政府补助到账** -> 经营活动现金流量净额大幅增长: 现金流入增加，现金流出相对稳定
- **公司前瞻性布局人形机器人、航空航天、低空经济等新兴领域** -> 研发费用增加: 新领域研发投入加大，研发项目数量及深度提升
- **下游新能源汽车、工业机器人等领域需求爆发** -> 公司营收增长: 公司产品高度契合下游升级方向，高端订单持续放量
- **行业集中度提升，中小微企业逐步出清** -> 公司市场份额有望扩大: 头部企业竞争优势凸显，公司作为专精特新小巨人受益
- **应收账款增加** -> 信用减值损失增加: 应收账款增加导致按比例计提的坏账准备增加

## 风险警告
公司面临多重风险：1. 营业成本增速持续高于营收增速，若高端产品结构转型未能有效提升毛利率，盈利能力可能承压；2. 研发投入持续扩大（占营收6.28%），若新品产业化不及预期，将拖累利润；3. 政府补助占净利润比例较高（其他收益1299万元，占净利润8.6%），存在政策依赖风险；4. 下游客户账期延长导致应收账款增长18.68%，信用减值损失增加，资金周转压力上升；5. 海外市场受地缘政治和关税壁垒影响，增长存在不确定性。
