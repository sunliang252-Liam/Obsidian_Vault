# 002285.SZ 深度透视

## 因果逻辑链
- **[房地产市场持续调整，交易量萎缩]** -> [大交易业务收入下降27.48%]: 全国商品房销售面积和金额双降，导致公司案场代理、分销等核心业务规模同步收缩。
- **[主动优化区域布局，退出低效市场]** -> [大交易业务收入与毛利双降]: 公司战略性收缩C类公司，关停亏损项目，虽改善结构但短期牺牲了营收与利润。
- **[计提大额信用及资产减值损失]** -> [净利润亏损扩大至-6.5亿元]: 应收账款回收困难、房产及商誉减值测试导致减值损失同比增加1.28亿元，严重侵蚀利润。
- **[金融资产公允价值大幅下跌]** -> [非经常性损益亏损加剧]: 持有的其他非流动金融资产公允价值变动损失达-1.44亿元，同比扩大324.86%，成为亏损主因之一。
- **[分销业务调整垫佣政策，转向客户预付模式]** -> [分销业务收入骤降34.44%]: 为控制信用风险，主动放弃部分需垫资的项目，短期内牺牲了业务规模与市场份额。
- **[物业及综合设施管理业务新签项目增加]** -> [在管面积与项目数双增]: 新签约38个项目，在管面积增至1095万平米，但新项目爬坡期及出租率下降导致收入仅降9.56%。
- **[公寓运营业务聚焦人才公寓，优化亏损项目]** -> [毛利亏损大幅收窄83.7%]: 通过重组减亏项目、提升运营效率，公寓业务毛利从-639万缩至-104万，经营质量改善。

## 风险警告
**核心风险在于主业持续萎缩与资产质量恶化形成的负向螺旋。** 大交易业务收入连续三年两位数下滑（-15.4%、-34.71%、-27.48%），且毛利率从20%以上骤降至个位数，显示传统代理分销模式在行业下行期已丧失定价权与规模效应。更严峻的是，公司为控制风险主动收缩分销业务，进一步削弱了收入底盘，而新探索的“商播+全链路”模式尚处早期，无法对冲传统业务的下滑。

**财务风险集中体现在现金流恶化与巨额减值。** 经营活动现金流由正转负（-2253万元），主要因利润亏损及辞退补偿增加。同时，应收账款、其他非流动金融资产、商誉等科目合计计提超3亿元的减值损失，反映出公司历史积累的资产泡沫正在加速出清。若房地产市场持续低迷，公司可能面临进一步的大额减值压力，净资产存在持续缩水的风险。
