# 002760.SZ 深度透视

## 因果逻辑链
- **[船电系统解决方案及特种电机业务爆发式增长]** -> [营收与利润双增]: 船电业务收入同比+50.38%，毛利率提升12.03个百分点，成为公司扭亏为盈的核心驱动力。
- **[高铬耐磨产品价格承压但成本控制有效]** -> [毛利率基本稳定]: 矿山/水泥行业需求疲软，产品收入同比-6.77%，但通过工艺升级与精益管理，毛利率仅微降1个百分点。
- **[海外市场高速扩张]** -> [收入结构优化]: 国外销售收入同比+96.44%，占比从6.59%提升至12.02%，有效对冲国内需求下滑。
- **[经营现金流大幅改善]** -> [盈利质量提升]: 经营活动现金流净额同比+60.53%至7,198万元，远超净利润，反映回款能力与运营效率增强。
- **[非经常性损益贡献显著]** -> [净利润扭亏]: 其他收益（政府补助+递延收益摊销）达2,895万元，占利润总额131.67%，是净利润转正的关键支撑。
- **[子公司康富科技盈利强劲]** -> [集团业绩基石]: 康富科技净利润1,358.5万元，占合并净利润67.3%，船电业务已成为公司最优质的利润来源。

## 风险警告
**1. 主业双线承压，增长持续性存疑。** 耐磨材料业务受下游矿山、水泥行业资本开支谨慎及轧球工艺替代冲击，收入持续萎缩；船电业务虽爆发式增长，但高度依赖造船业景气周期，且库存量同比+78.65%，需警惕下游订单回落导致的库存积压风险。

**2. 盈利高度依赖非经常性损益与政府补助。** 扣非净利润仅1,098万元，而政府补助及递延收益摊销等非经常性收益高达2,895万元，是利润总额的1.3倍。若补助政策变动或递延收益摊销完毕，公司真实盈利能力将面临严峻考验。
