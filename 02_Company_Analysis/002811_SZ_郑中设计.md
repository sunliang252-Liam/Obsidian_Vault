# 002811.SZ 深度透视

## 因果逻辑链
- **[设计品牌溢价与客户拓展]** -> [设计业务收入增长31.07%]: 公司作为全球酒店设计龙头，凭借品牌优势持续获取高端酒店及多业态客户订单，设计业务收入占比提升至68.50%。
- **[软装业务规模化扩张]** -> [软装收入增长40.21%]: 依托设计业务导流与供应链整合，软装业务实现高速增长，新签订单金额同比大增89.37%。
- **[新签订单高增驱动未来收入]** -> [设计+软装新签订单合计23.76亿元，同比+52.89%]: 强劲的订单增长为未来1-2年收入确认提供了坚实基础，预示业绩增长可持续。
- **[科技平台赋能设计效率]** -> [子公司犀照科技收入增长107.23%]: “IDEAFUSION兆材云库”与“TRANSFUSION AI”双平台投入使用，提升设计选材与方案生成效率，并开始贡献收入。
- **[可转债到期偿还]** -> [财务费用大幅下降67.73%]: 2025年可转债到期偿还，利息支出显著减少，直接增厚当期净利润。
- **[资产减值损失转回]** -> [信用减值损失-1.1亿元]: 前期计提的坏账准备因收款或结算转回，对利润表产生正向贡献，但反映历史应收款管理压力。
- **[国际化布局加速]** -> [海外子公司设立与项目签约]: 在伦敦、迪拜、澳大利亚新设子公司，并签约东京丽思卡尔顿等海外项目，拓展全球市场版图。

## 风险警告
**核心风险在于装饰工程业务的持续萎缩与亏损。** 装饰工程业务收入同比骤降77.53%，毛利率为-146.70%，表明该板块已陷入严重亏损，成为公司利润的显著拖累。公司主动收缩工程业务、聚焦设计与软装的战略虽已明确，但工程业务的历史包袱（如未决诉讼、应收款回收）仍可能持续侵蚀利润。

**第二风险是应收款与合同资产的减值压力。** 尽管2025年因回款转回部分减值，但公司应收账款与合同资产合计规模仍高达约6亿元，且装饰工程业务客户多为房地产相关企业，行业信用风险并未完全出清。未来若宏观经济或下游客户经营状况恶化，大额减值风险可能重新暴露，对净利润造成剧烈冲击。
