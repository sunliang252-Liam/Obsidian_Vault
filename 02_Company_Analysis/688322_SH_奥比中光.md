# 688322.SH 深度透视

## 因果逻辑链
- **[机器人业务爆发]** -> [营收增长66.66%]: 国内机器人业务翻倍增长，带动3D视觉传感器及消费级应用设备在服务/人形/工业机器人场景大规模落地。
- **[“碰一下”支付设备放量]** -> [消费级应用设备营收+97%]: 与蚂蚁集团合作，支付宝新型支付终端整机设备在零售场景快速铺开，成为第二大收入引擎。
- **[三维扫描业务高增]** -> [消费级应用设备营收+97%]: 与创想三维合作推出多款消费级/工业级3D扫描仪，产品线覆盖千元至工业级，市场渗透加速。
- **[规模效应与费用管控]** -> [实现扭亏为盈]: 营收增长66.66%的同时，销售/管理费用同比下降，研发费用微降，经营杠杆显现，归母净利润1.28亿。
- **[全栈技术+全领域路线]** -> [技术护城河与客户黏性]: 自研深度引擎芯片、iToF/dToF感光芯片，覆盖六大技术路线，客户适配后形成高切换成本。
- **[融入国际巨头生态]** -> [海外市场拓展与品牌背书]: 产品适配英伟达Jetson/Isaac、英特尔、微软、AMD等平台，成为全球机器人视觉标准件。
- **[表决权差异安排]** -> [创始人控制权稳定]: 黄源浩持27.15%股份但拥有60.18%表决权，确保长期战略执行，但存在治理风险。

## 风险警告
**客户集中度与关联交易风险**：前五大客户销售额占比高达63.92%，其中第二大客户为关联方蚂蚁集团（占比26.84%）。公司对“碰一下”支付设备和刷脸支付业务的增长高度依赖蚂蚁生态，若合作关系或政策变化，将对营收造成重大冲击。

**技术迭代与商业化不确定性**：3D视觉感知行业技术路线（结构光、iToF、dToF、Lidar）并行发展，下游机器人、具身智能等场景尚处早期爆发阶段。公司需持续高研发投入（21.53%营收占比）以保持领先，若技术方向判断失误或商业化速度不及预期，将面临研发投入无法收回的风险。

**存货与毛利率双重压力**：存货账面价值1.86亿元，消费级应用设备库存量同比暴增181%。随着产品放量，毛利率已承压（消费级应用设备毛利率37.81%），未来若市场竞争加剧或产品降价，存在大幅计提存货跌价准备及毛利率持续下滑的风险。
