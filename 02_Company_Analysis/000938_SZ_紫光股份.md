# 000938.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [ICT基础设施与服务收入增长41.11%]: 子公司新华三精准卡位智算中心建设，国内政企业务收入同比增长48.84%，成为核心增长引擎。
- **[“算力×联接”战略]** -> [全栈智算解决方案竞争力提升]: 从高速无损网络、AI服务器到算力调度平台，形成一体化交付能力，在运营商、金融等行业实现规模落地。
- **[国产化替代机遇]** -> [自主可控产品矩阵扩张]: 推出基于国产芯片的200G/400G/800G交换机，在政府、电力能源等关键行业实现规模发货，抢占信创市场。
- **[海外渠道深耕]** -> [国际业务收入增长58.45%]: 海外子公司达22个，合作伙伴近3800家，自主渠道成为海外增长核心引擎，产品在亚欧非拉多国实现战略项目落地。
- **[图灵小镇模式创新]** -> [政企合作算力运营新路径]: 联合地方政府打造“算力运营+产业孵化”模式，已扩展至8个小镇，探索可持续的算力变现模式。
- **[新华三核心地位]** -> [归母净利润增长7.19%]: 新华三贡献营收759.81亿元（占公司总营收78.5%），其利润增长12.30%是公司整体盈利提升的主要来源。
- **[存货高企与减值风险]** -> [资产减值损失达8.75亿元]: 存货规模增至435.68亿元（占总资产45.23%），导致计提大额存货减值损失，侵蚀利润。

## 风险警告
**核心风险在于新华三的单一依赖与毛利率持续承压。** 新华三贡献了公司近80%的营收和几乎全部的利润，其业绩波动将直接决定公司整体表现。同时，ICT基础设施与服务业务毛利率同比下降5.72个百分点至16.51%，显示在智算市场快速扩张的同时，价格竞争激烈，成本压力（尤其是芯片等关键部件）正在侵蚀盈利空间。

**存货高企与现金流压力不容忽视。** 公司存货规模高达435.68亿元，占总资产45.23%，且计提了8.75亿元的资产减值损失。虽然经营性现金流净额同比大幅改善至34.87亿元，但存货周转效率仍是潜在隐患，若下游需求或技术路线发生变化，可能面临更大的减值风险。此外，公司总担保余额占净资产比例高达222%，财务杠杆风险较高。
