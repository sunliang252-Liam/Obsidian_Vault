# 603353.SH 深度透视

## 因果逻辑链
- **新能源车渗透率突破50%** -> 成品油需求萎缩，加油站销量下滑: 新能源汽车替代燃油车，直接减少汽油、柴油消费
- **国际原油价格下行** -> 国内成品油出厂价及零售价累计大幅下调: 国际原油成本下降传导至国内成品油价格，发改委多次下调零售价
- **成品油需求萎缩及价格下行** -> 加油站行业竞争加剧，促销战激烈: 需求不足导致各加油站通过价格优惠及非油服务争夺客户
- **加油站行业竞争加剧** -> 公司零售毛利率下降: 激烈竞争压缩零售利润空间
- **国际原油价格下行** -> 公司批发毛利率下降: 原油价格下跌导致批发售价下降，毛利率承压
- **成品油销量相对稳定（零售+批发合计增长0.85%）** -> 营业收入同比下降8.15%: 销量微增但销售单价大幅下降，量升价跌导致收入减少
- **销售单价下降幅度大于成本下降幅度** -> 公司净利润为负（亏损2,161.63万元）: 收入降幅（-8.15%）大于成本降幅（-5.10%），毛利收窄，叠加期间费用刚性，导致亏损
- **成品油行业结构性下行** -> 公司启动向半导体行业转型（拟收购奎芯科技）: 传统主业长期承压，公司为寻找新增长点而跨界转型
- **公司拟收购半导体公司（奎芯科技）** -> 存在收购整合风险: 公司无半导体行业管理经验，整合能力面临考验

## 风险警告
核心风险在于成品油行业量价齐跌导致主业亏损，而转型半导体面临跨界整合不确定性，且新能源替代加速可能进一步侵蚀传统业务，需警惕转型期间业绩双重承压。
