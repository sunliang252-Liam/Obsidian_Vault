# 001316.SZ 深度透视

## 因果逻辑链
- **[航空运输业强劲复苏]** -> [营收增长33.81%]: 全球及中国民航旅客运输量、机队规模持续增长，直接拉动公司航材分销与自研产品的市场需求。
- **[“分销+自研”双轮驱动]** -> [净利润暴增107.72%]: 分销业务稳健增长提供基本盘，高毛利的自研产品（毛利率55.83%）营收增长33.96%，显著提升整体盈利水平。
- **[航材国产化替代加速]** -> [自研产品竞争力提升]: 国家政策支持与客户降本需求，推动公司超3200个自研件号获民航局批准，部分写入商飞手册，打开国产替代市场空间。
- **[供应链管理与客户粘性]** -> [经营现金流大幅改善]: 精细化的库存管理和超70人的专业销售团队，保障了客户需求响应，加速回款，使经营现金流净额暴增377.8%至2.21亿元。
- **[上游供应商高度集中]** -> [成本控制风险]: 前五大供应商采购额占比68.13%，其中单一供应商占比超51%，议价能力弱，存在上游涨价侵蚀利润的风险。
- **[外汇衍生品对冲]** -> [财务费用波动]: 公司以美元采购为主，通过远期购汇等衍生品对冲汇率风险，但报告期内衍生品公允价值变动亏损622.45万元，导致财务费用波动。
- **[拓展飞机全生命周期管理]** -> [新增长曲线探索]: 公司拟开展飞机租赁、拆解及航材再循环业务，旨在横向拓展产业链，但新业务存在投入大、回报周期长、折旧压力等不确定性。

## 风险警告
**核心风险在于上游供应链的极度依赖与下游客户的高度集中。** 公司第一大供应商采购额占比超过51%，分销业务本质是“买断式”贸易，对上游原厂（如埃克森美孚、3M）的授权与定价几乎没有议价权。同时，前五大客户销售额占比高达63.93%，客户集中度高，若主要客户流失或压价，将对营收造成重大冲击。这种“两头在外”的商业模式，使其利润空间极易被上下游挤压。

**新业务拓展与国产化研发的不确定性是长期隐忧。** 公司计划大举进入飞机全生命周期管理（租赁、拆解）这一重资产、高杠杆领域，与现有轻资产分销模式差异巨大，可能带来高额折旧与财务风险。此外，国产化自研虽增速快，但研发投入仅占营收1.24%，且研发人员同比减少21%，技术突破与适航认证的难度不容小觑，能否持续转化为业绩增长尚需验证。
