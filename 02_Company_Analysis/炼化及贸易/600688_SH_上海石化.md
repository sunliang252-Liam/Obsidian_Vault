# 600688.SH 深度透视

## 因果逻辑链
- **[原油价格下跌与加工量减少]** -> [营收与利润双降]: 2025年国际原油价格震荡下跌，公司原油加工量同比下降5.49%，导致炼油产品销量和单价分别下降9.62%和8.31%，营业收入同比减少13.28%。
- **[炼油装置大修]** -> [炼油板块由盈转亏]: 炼油装置大修导致产量下降，炼油产品分部营业利润从上年盈利13.19亿元转为亏损3.51亿元，是公司整体亏损的核心原因。
- **[化工产品价格承压]** -> [化工板块亏损扩大]: 化工产品成本端支撑减弱叠加售价下跌，分部营业亏损从13.07亿元扩大至17.16亿元，亏损增加4.09亿元。
- **[高关联交易依赖]** -> [经营独立性受限]: 向最大客户（中石化集团）销售额占全年营业额72.00%，向最大供应商采购额占49.63%，公司经营高度依赖控股股东体系，议价能力与利润空间受制。
- **[大额资本开支与转型投入]** -> [现金流承压]: 2025年资本开支32.32亿元（同比+82.91%），2026年计划60亿元，全面技术改造和碳纤维项目持续消耗现金，经营活动现金流净额同比大幅下降74.25%。
- **[存货跌价准备增加]** -> [资产减值损失扩大]: 石油化工产品毛利下降，存货跌价准备计提增加，资产减值损失同比上升37.33%，进一步侵蚀利润。
- **[H股回购与注销]** -> [每股净资产边际改善]: 公司持续回购并注销H股，总股本减少，归属于母公司股东的每股净资产从2.346元降至2.194元（主要因亏损），但回购行为对每股指标有边际支撑。

## 风险警告
**核心风险在于炼化一体化业务的双重挤压与转型阵痛。** 公司炼油与化工两大主业同时承压：炼油端受制于原油价格波动、政府定价管制及装置检修，盈利极不稳定；化工端面临行业产能过剩、产品价格持续下跌的困境，亏损已成常态。2025年公司净亏损14.33亿元，加权平均净资产收益率降至-5.95%，盈利能力已跌至冰点。

**更大的风险来自激进的资本开支计划与脆弱的现金流之间的错配。** 公司计划投资196亿元进行全面技术改造，2026年资本开支预计高达60亿元，而经营活动现金流净额已从2024年的77.4亿元骤降至19.93亿元。若转型项目不能如期投产或市场环境持续恶化，公司将面临严重的流动性压力，甚至可能需要大规模外部融资，进一步推高资产负债率（已从37.1%升至41.74%）。此外，高达73%的关联采购与74.5%的关联销售比例，使公司利润空间被控股股东体系深度锁定，独立经营与市场化定价能力存疑。
