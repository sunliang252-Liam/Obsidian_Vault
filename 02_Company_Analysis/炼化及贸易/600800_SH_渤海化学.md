# 600800.SH 深度透视

## 因果逻辑链
- **[丙烯行业全面过剩]** -> [公司核心产品丙烯价格中枢下移]: 2025年丙烯市场从“紧平衡”进入“全面过剩”，供需剪刀差扩大，全行业盈利遭遇严峻挑战。
- **[丙烷采购成本高企]** -> [PDH装置盈利空间被严重挤压]: 中东货源贴水走高、美国货源加征关税，导致丙烷到岸成本大幅抬升，而丙烯价格低迷，形成“高成本、低售价”的剪刀差。
- **[下游需求疲软与负反馈]** -> [丙烯销量与价格双重承压]: 聚丙烯(PP)等主要下游长期亏损，开工率低于10%，环氧丙烷、辛醇等利润大幅下滑，下游承受能力已近极限，形成负反馈循环。
- **[营收下降30.39%]** -> [经营现金流大幅转负]: 产销减少导致收入下降，同时上年期末丙烷赊购额度较大而本期不存在，共同导致经营活动现金流净额从+0.43亿骤降至-6.71亿。
- **[在建工程大幅投入]** -> [债务规模与财务费用激增]: 丙烯酸酯及高吸水性树脂新材料项目（募投项目）建设投入增加，导致在建工程增长1186.55%，公司通过增加借款筹资，财务费用同比增加34.48%。
- **[资产处置收益支撑利润]** -> [扣非净利润亏损更深]: 2025年通过向关联方转让房产实现资产处置收益约9790万元，使得归母净利润亏损6.46亿，但扣非净利润亏损高达7.75亿，显示主业亏损更为严重。
- **[连续三年巨额亏损]** -> [净资产持续被侵蚀]: 2023-2025年归母净利润连续亏损，期末未分配利润达-22.77亿元，归属于母公司净资产从23.92亿缩水至11.20亿，降幅达53.2%。

## 风险警告
**核心风险在于行业供需格局的长期恶化与公司单一产品结构的脆弱性。** 丙烯市场已正式进入“全面过剩”阶段，产能惯性释放与下游需求增长乏力形成巨大剪刀差，价格中枢显著下移。公司核心PDH装置（60万吨/年）高度依赖丙烯单一产品，在行业性亏损周期中缺乏对冲手段，导致连续三年巨额亏损，净资产持续被侵蚀。2025年扣非净利润亏损高达7.75亿元，主业造血能力已基本丧失。

**财务风险与经营风险相互叠加，现金流极度紧张。** 公司为推进丙烯酸酯新材料项目（预计2026年6月完工）大量举债，导致短期借款增长59.58%、长期借款增长1533.24%，财务费用同比上升34.48%。与此同时，经营活动现金流净额由正转负，骤降至-6.71亿元，表明公司已无法通过主业产生现金来覆盖运营和投资需求，高度依赖外部融资维持运转。若新项目投产后的盈利不及预期，公司将面临严峻的偿债压力和流动性危机。
