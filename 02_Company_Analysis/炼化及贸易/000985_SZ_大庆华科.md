# 000985.SZ 深度透视

## 因果逻辑链
- **[化工行业景气周期低谷]** -> [净利润大幅下滑49.81%]: 行业供需宽松、毛利收窄，公司营收下降6.27%，但净利润降幅远超营收，反映盈利能力脆弱。
- **[原材料价格波动]** -> [毛利率承压]: 裂解碳五、碳九等主要原材料价格下跌，但产品售价同步下滑，C5馏分产品毛利率为负（-1.65%）。
- **[高度依赖关联方采购]** -> [成本控制能力弱]: 92.82%的采购来自同一最终控制方（中石油大庆石化），议价空间极小，供应链风险高度集中。
- **[研发投入骤降94.91%]** -> [长期竞争力存疑]: 研发费用从1906万降至97万，仅6名研发人员且均为40岁以上，技术迭代能力堪忧。
- **[产能利用率不足]** -> [资产效率低下]: 聚丙烯产能利用率仅75.45%，碳五系列产品79.08%，均未满产，固定成本摊薄压力大。
- **[投资活动现金大幅流出]** -> [现金流结构恶化]: 投资活动现金净流出2.67亿元（同比+319.81%），主要因存入定期存款2.2亿元，而非生产性投资。
- **[第四季度亏损]** -> [经营季节性疲软]: 第四季度净利润-579.9万元，经营活动现金流-5735.7万元，显示年末回款压力及成本刚性。

## 风险警告
**核心风险：深度绑定中石油体系，缺乏独立生存能力。** 公司55.03%股权由中石油大庆石化持有，92.82%的原材料采购来自同一体系，销售也高度依赖关联方。这种“温室模式”导致公司完全暴露于中石油内部定价策略和原料供应波动之下，自身议价能力和成本控制形同虚设。一旦关联交易政策调整或原料价格剧烈波动，公司利润将遭受毁灭性打击。

**成长性风险：研发投入断崖式下跌，技术护城河正在干涸。** 2025年研发投入仅97万元，同比暴跌94.91%，研发人员仅6人且全部超过40岁。在化工行业技术迭代加速、高端化转型迫在眉睫的背景下，公司几乎停止了新产品、新工艺的探索。现有产品（聚丙烯粉料、普通石油树脂）技术门槛低、同质化严重，未来只能陷入价格战泥潭，毫无差异化竞争优势。
