# 600506.SH 深度透视

## 因果逻辑链
- **[原材料成本下降]** -> [毛利率稳定]: 基础油等主要原材料采购成本同比下降，抵消了产品结构调整带来的毛利率压力。
- **[财务费用大幅下降]** -> [净利润为正]: 偿还银行并购贷款及股东借款，利息支出同比减少52.77%，是公司扭亏为盈的关键。
- **[子公司增资扩股]** -> [降低负债率]: 引入柯桥领途4亿元增资，优化资本结构，总负债率从77.30%降至55.73%。
- **[传统润滑油销量增长]** -> [营收微增4.2%]: 通过市场拓展和产品结构优化，润滑油脂销量增长4.3%，带动整体营收小幅增长。
- **[新能源液冷产品布局]** -> [第二增长曲线]: 针对储能、数据中心、超充桩等场景推出液冷产品，虽尚未贡献主要利润，但已获头部客户验证。
- **[销售费用增长]** -> [侵蚀利润]: 为提升市场份额，加大营销投入，销售费用同比增长12.17%，是利润下滑的主因之一。
- **[非经常性损益减少]** -> [净利润下滑]: 2025年非经常性损益同比减少63%，导致归母净利润同比下降58.34%。

## 风险警告
**核心风险在于利润的脆弱性与转型的不确定性。** 公司2025年归母净利润仅1307万元，扣非后净利润857万元，盈利能力极其薄弱。利润主要依赖财务费用下降这一一次性因素，而非主营业务的强劲增长。同时，公司营收仅微增4.2%，销售费用却增长12.17%，显示市场拓展成本高企，增长质量存疑。若原材料价格反弹或财务费用节约效应消退，公司极易重回亏损。

**新能源转型是希望，但短期难以成为利润支柱。** 公司大力布局液冷等新能源业务，但该领域竞争激烈，且从产品验证到规模化放量需要时间。2025年新能源业务尚未在财报中体现显著利润贡献，而传统润滑油业务面临国产替代和价格战的双重压力。公司能否在新能源赛道实现“第二曲线”的实质性突破，是未来价值判断的关键，但当前存在较大不确定性。
