# 600256.SH 深度透视

## 因果逻辑链
- **[能源产品价格全面下跌]** -> [营收与利润大幅下滑]: 2025年煤炭、LNG、甲醇、乙二醇等主营产品价格同比下跌6%-18%，导致营收下降16.47%，归母净利润暴跌54.46%。
- **[主动缩减LNG进口贸易规模]** -> [天然气销量骤降26%]: 进口LNG价格持续倒挂，公司为规避风险主动收缩外购气业务，天然气销量从408,564万方降至301,566万方。
- **[煤炭板块“以量补价”]** -> [煤炭营收仅降7.88%]: 原煤产量同比大增22.78%至4,890万吨，销量增长12.21%，部分对冲了煤价下跌18%的冲击，成为业绩核心支撑。
- **[煤化工产业链延伸显效]** -> [乙二醇产量增长15%]: 荒煤气制乙二醇项目持续放量，产量达17.95万吨，但受制于行业供需宽松，价格同比下跌5.4%，未能贡献显著利润增量。
- **[财务费用大幅下降24%]** -> [缓解利润下滑压力]: 公司主动归还有息负债，财务费用从9.71亿降至7.39亿，在收入端承压时对利润形成一定缓冲。
- **[马朗煤矿投产在即]** -> [未来煤炭增量可期]: 马朗煤矿已取得环评、水保等关键批复，作为新的优质产能，有望在2026年贡献显著产量增量，接替白石湖煤矿。
- **[“两个耦合”战略落地]** -> [氢能全流程贯通]: 绿电制氢与氢能一体化示范项目实现“绿电-绿氢-氢能重卡”全流程贯通，但尚处示范阶段，短期无实质利润贡献。

## 风险警告
**核心风险在于业绩对产品价格的极端敏感性。** 2025年归母净利润腰斩，根源并非销量崩塌，而是煤炭、LNG、甲醇等核心产品价格全面下跌。公司“以量补价”策略在煤价下行周期中效果有限，煤炭毛利率已从23%骤降至15%。若2026年能源价格继续承压，即便产量再创新高，利润也难以修复。

**第二大风险是资本开支与债务压力。** 公司总资产缩水10.5%，货币资金骤降57%至18.7亿元，同时短期借款高达76亿元，一年内到期负债近40亿元。尽管财务费用下降，但筹资活动现金流净流出87亿元，显示公司正处“去杠杆”阵痛期。马朗煤矿、斋桑油田、1500万吨分质分级项目等均需大量资金，现金流紧绷可能制约后续发展。

**公司简介（F10 原文）**

> 广汇能源股份有限公司创始于1994年,2000年5月在上海证券交易所上市,2012年转型为专业化的能源开发企业,是目前在国内外同时拥有“煤、油、气”三种资源的民营企业。公司依托丰富的天然气、煤炭和石油资源,建成了以液化天然气(LNG)、甲醇、煤炭、煤焦油、乙二醇为主要产品,以煤化工产业链为核心,以能源物流为支撑的综合能源产业体系,并形成了天然气、清洁能源(氢能)、碳捕集与利用、煤化工、煤炭协同发展的五大产业格局。近年来,公司围绕国家“一带一路”经济合作、新疆“八大产业集群”和“三基地一通道”等建设,重点开发天然气、煤炭、石油三种资源,打造新疆煤炭清洁高效利用转化基地,打通出疆能源物流通道、中哈跨境天然气管道和启东海运油气接收通道。充分利用国内外两个市场、两种资源,积极参与国际能源合作,不断满足国内日益增长的绿色能源需求,保障国家能源安全。公司先后荣获中国能源行业“一带一路”领跑者企业奖、中国上市公司实业贡献奖、中国主板上市公司投资者关系最佳董事会奖、中国煤炭企业50强等多项荣誉称号。目前,公司启动了以“绿色革命”为主题的第二次战略转型升级,围绕现有产业发展格局,集中优势力量,在清洁能源(氢能)和二氧化碳捕集与利用产业,着力打造产业链、价值链、供应链相互融合的生态体系,并致力于转型成为传统化石能源与绿色新型能源相结合的能源综合开发企业。
