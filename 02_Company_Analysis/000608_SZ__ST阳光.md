# 000608.SZ 深度透视

## 因果逻辑链
- **[投资性房地产公允价值下降]** -> [归母净利润亏损2.18亿元]: 核心资产（投资性房地产）评估减值约1亿元，直接吞噬利润，是亏损主因。
- **[商业地产行业“以价换量”]** -> [物业租赁收入下降12%]: 市场租金下行、租户退租或提前解约，导致核心租赁业务收入承压。
- **[写字楼市场低迷]** -> [写字楼租赁收入下降31.72%]: 北京、成都、深圳等核心城市写字楼租金持续下跌，公司写字楼项目出租率及租金下滑。
- **[新增写字楼大宗销售]** -> [房产销售收入增长5%]: 通过销售成都锦尚项目商办写字楼，部分对冲了租赁业务的下滑。
- **[高杠杆与关联方借款]** -> [财务费用高企（8637万元）]: 向控股股东京基集团的大额借款（年化利率3.5%-5%）及保理融资，导致利息支出沉重。
- **[控制权变更]** -> [同业竞争承诺终止]: 2026年初控股股东由京基集团变更为刘丹，原京基集团解决同业竞争的资产注入承诺随之终止，不确定性增加。
- **[应收账款清缴专项]** -> [经营性现金流净额1.65亿元]: 尽管亏损，但通过强化租金收缴，实际收缴率超99%，保障了正向现金流，与净利润背离。

## 风险警告
公司核心风险在于资产价值持续缩水与盈利能力枯竭。投资性房地产占总资产近68%，其公允价值变动对利润表具有决定性影响。在商业地产租金下行周期中，公司缺乏有效的业绩增长点，连续三年扣非净利润为负，已陷入“资产减值-亏损-净资产减少”的恶性循环。新控股股东刘丹的入主虽带来短期想象空间，但其承诺的“财务支持”仅限一年，且缺乏明确的资产注入或业务转型计划，公司基本面改善的路径尚不清晰。

财务风险同样严峻。公司背负高额有息负债（银行贷款及保理融资），且与前任控股股东京基集团的关联借款余额巨大（约2.6亿元），财务费用持续侵蚀微薄的经营利润。虽然经营性现金流为正，但主要依赖租金收缴管理，而非业务增长。一旦市场环境恶化导致出租率或租金进一步下滑，现金流将面临断裂风险，公司持续经营能力存在重大不确定性。
