# 300355.SZ 深度透视

## 因果逻辑链
- **[“三北”工程国家战略]** -> [生态修复业务收入增长21.44%]: 国家“三北”工程攻坚战带来大量生态修复订单，直接拉动公司营收增长。
- **[PPP项目债务重组与提前终止]** -> [净利润下降42.59%]: 为加速现金回流，集中推进PPP项目债务重组，导致长期应收款转应收账款，计提信用减值损失1.71亿元（同比+130.22%），并产生债务重组损失4,576万元。
- **[草种业“卡脖子”政策红利]** -> [草种及肥料销售爆发式增长]: 国家推动草种业自主可控，公司草种销售增长40.67%，肥料销售增长69,720.67%，成为新增长极。
- **[牵头建设国家草业技术创新中心]** -> [巩固行业技术壁垒]: 获批牵头建设国创中心，强化在草种业科技、生态修复领域的技术优势，提升长期竞争力。
- **[存量PPP项目回款依赖地方财政]** -> [应收账款高企（43.84亿元）]: 公司大量PPP项目回款来自地方政府，财政支付能力波动直接影响回款速度和资产质量。
- **[财务费用大幅下降63.60%]** -> [缓解利润压力]: 偿还高息融资及PPP项目利息调整，财务费用从1.64亿降至0.60亿，部分对冲了信用减值损失对利润的侵蚀。
- **[内蒙古区内业务集中度提升]** -> [区域依赖风险加剧]: 区内收入占比从82.90%升至89.71%，区外业务收缩26.92%，公司业绩与内蒙古地方经济及政策绑定更深。

## 风险警告
**核心风险：PPP项目应收账款回收与信用减值失控。** 公司应收账款高达43.84亿元，占总资产28.38%，且同比大幅增长。为换取现金回流而进行的PPP项目债务重组，虽优化了资产结构，但短期内导致信用减值损失和债务重组损失激增，严重侵蚀净利润。若地方政府财政持续紧张，未来减值压力仍将是业绩最大拖累。

**次要风险：经营现金流急剧恶化与区域集中度过高。** 尽管营收增长，但经营活动现金流净额同比骤降79.64%至3.21亿元，主因是“三北”工程业务垫资增加。同时，公司89.71%的收入来自内蒙古自治区，高度依赖单一区域的政策和财政状况，一旦地方政策或经济环境变化，业绩将面临巨大波动。
