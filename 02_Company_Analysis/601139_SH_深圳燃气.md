# 601139.SH 深度透视

## 因果逻辑链
- **[天然气批发业务量价齐升]** -> [燃气资源板块收入增长101%]: 公司利用国际LNG采购窗口期，大幅扩大批发规模，同时毛利率提升17.6个百分点，成为营收增长的核心引擎。
- **[燃气发电新机组投产]** -> [发电业务收入增长41%]: 第二台9F级机组投运，装机规模突破1,300兆瓦，叠加优化运行策略，发电利润创历史新高。
- **[光伏胶膜“以量换价”]** -> [收入下降3.33%，但销量增长21%]: 行业产能过剩、价格内卷，公司通过降价抢占市场份额，维持全球第二地位，但盈利能力承压。
- **[深圳“瓶改管”工程收官]** -> [智慧服务收入骤降33%]: 燃气设备销售减少，导致该板块收入大幅下滑，拖累归母净利润同比下降3.37%。
- **[计提商誉减值]** -> [资产减值损失同比增加94%]: 对斯威克（光伏胶膜）和电站相关商誉计提减值3.36亿元，直接侵蚀利润。
- **[研发投入激增]** -> [研发费用同比增加31%]: 公司加大在鸿蒙系统、深燃机、光伏胶膜新产品等领域的研发，费用率达4.08%，短期压制利润。
- **[融资结构优化]** -> [短期借款减少40%，应付债券增加79%]: 公司以长期中期票据置换短期借款，降低流动性风险，但增加了利息支出。

## 风险警告
**核心风险在于光伏胶膜业务的持续亏损与商誉减值压力。** 子公司斯威克虽销量增长，但行业产能过剩、价格战激烈，导致其全年亏损5,734万元。公司已因此计提商誉减值，若行业“反内卷”进程不及预期，或出口退税取消等政策冲击加剧，该业务可能继续拖累整体利润，并引发进一步的资产减值。

**第二大风险是天然气价格波动与顺价机制不畅。** 公司部分终端气价受政府管制，若上游国际气价因地缘政治等因素大幅上涨，而下游价格联动机制执行滞后，将严重挤压城市燃气业务的毛利率。此外，电厂客户受容量电价政策影响，用气需求存在不确定性，可能影响公司核心业务的增长稳定性。
