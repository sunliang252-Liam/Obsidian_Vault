# 603162.SH 深度透视

## 因果逻辑链
- **[运力规模扩张]** -> [营收增长21.43%]: 公司通过新购和光租新增18艘运力，控制运力达502万载重吨，直接推动主营业务收入增长。
- **[BDI指数下半年走强]** -> [境外业务收入增长21.81%]: 2025年下半年干散货航运市场租金大幅攀升，公司抓住机遇优化全球航线布局，实现境外营收增长。
- **[灵活摆位与精细管理]** -> [TCE持续跑赢市场]: 超灵便型船日均TCE 13,985美元，较市场均值溢价14.25%，体现公司航线选择和运营效率的竞争优势。
- **[外租船业务扩张]** -> [营收增长但毛利率承压]: 外租船业务增加带动收入，但外租成本同步上升，导致整体毛利率下降2.42个百分点。
- **[船队规模扩大与坞修增加]** -> [营业成本增长24.21%]: 船队扩张导致折旧、船员工资、物料备件及维修成本全面上升，成本增速超过收入增速。
- **[售后回租与抵押贷款增加]** -> [财务费用激增211%]: 为扩充运力，公司新增银行及金融租赁融资，利息支出大幅增加，侵蚀利润。
- **[股权激励计划持续实施]** -> [管理费用与库存股增加]: 2025年新授予限制性股票和股票期权，确认股份支付费用，同时库存股因回购义务增加237.72%。
- **[“百船计划”与重吊船布局]** -> [第二增长曲线初现]: 公司购入4艘多用途重吊船并拟新造3艘，旨在拓展高端设备海运市场，形成新的利润增长点。

## 风险警告
**核心风险在于“增收不增利”的剪刀差。** 公司营收增长21.43%，但归母净利润却下降15.30%。成本端（折旧、租金、人工、财务费用）的刚性增长远超收入弹性，尤其是财务费用同比暴增211%，显示激进扩张带来的财务杠杆正在快速侵蚀利润。若BDI指数回落或运价不及预期，高额的固定成本将导致业绩大幅下滑。

**行业周期性波动与地缘政治风险是悬顶之剑。** 干散货航运与全球宏观经济、大宗商品贸易高度相关。美国关税政策、地缘冲突等外部冲击可能随时逆转航运需求。公司境外资产占比高达82.22%，汇率波动、贸易摩擦及环保新规（如EU ETS）均可能对经营造成重大冲击。此外，报告期内一笔境外港口误操作罚款高达609.90万元，凸显海外运营的合规风险。
