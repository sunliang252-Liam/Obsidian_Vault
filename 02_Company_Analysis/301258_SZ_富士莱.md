# 301258.SZ 深度透视

## 因果逻辑链
- **[核心产品价格持续承压]** -> [扣非净利润连续两年为负]: 硫辛酸等主要产品价格同比下降12%-27%，导致主营业务毛利率下滑，扣非净利润-326.9万元，主业实际亏损。
- **[金融投资收益大幅增长]** -> [归母净利润同比+291.89%]: 2025年公允价值变动损益+投资收益合计约7.85亿元，占利润总额105%，是净利润扭亏为盈的唯一来源。
- **[降本增效与资产减值减少]** -> [扣非亏损收窄63.37%]: 通过工艺优化、期间费用率下降及资产减值损失显著减少，使主业亏损从-892.5万收窄至-326.9万。
- **[山东新基地建设接近竣工]** -> [未来产能释放与产品管线拓展]: 山东项目一期10条生产线基本建成，为CMO/CDMO业务和新产品商业化提供产能基础。
- **[硫辛酸制剂获批上市]** -> [垂直一体化战略落地]: 2025年12月取得硫辛酸片剂注册证书，从原料药向制剂延伸，有望提升硫辛酸整体盈利能力。
- **[单一产品依赖度仍高]** -> [业绩波动风险持续]: 硫辛酸系列收入占比63.36%，价格竞争加剧导致收入同比下降2.10%，公司对单一产品依赖未根本改善。
- **[研发投入聚焦特色原料药]** -> [长期产品管线储备]: 2025年研发投入3580万元，重点推进甲磺酸阿帕替尼、艾瑞昔布等特色原料药，为摆脱单一依赖做准备。

## 风险警告
**主业持续亏损，盈利依赖金融投资不可持续。** 公司扣非净利润已连续两年为负（2024年-892.5万，2025年-326.9万），核心产品硫辛酸系列因产能过剩、价格持续下滑，毛利率同比下降3.06%。2025年归母净利润6,429万元中，金融资产公允价值变动及投资收益贡献了约7,852万元，占利润总额的105%。若金融市场波动或投资规模收缩，公司将立即陷入全面亏损。

**单一产品依赖与产能扩张的错配风险。** 硫辛酸系列收入占比超63%，但该产品价格已连续两年下降（2025年颗粒硫辛酸价格同比-12.29%）。与此同时，公司通过募投项目大幅扩张产能（山东基地新增10条生产线），在行业供给过剩、需求疲软的背景下，新增产能可能进一步压低价格，导致“增产不增收”甚至“增产反亏”的局面。山东项目能否如期达产并实现预期效益，存在重大不确定性。
