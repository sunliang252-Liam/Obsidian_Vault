# 688079.SH 深度透视

## 因果逻辑链
- **[半导体封测与声光学业务放量]** -> [营收增长36.72%]: 半导体封测与声光学业务收入分别增长140.66%和68.68%，合计贡献增量约1.8亿元，成为营收增长的核心引擎。
- **[固定资产大规模投产]** -> [折旧费用激增]: 2025年固定资产折旧2.15亿元，同比增加6,480万元，直接侵蚀利润，是亏损扩大的首要原因。
- **[股权激励费用大幅增加]** -> [管理费用飙升]: 2025年确认股份支付费用4,314万元，同比增加3,798万元，显著加重了期间费用负担。
- **[产能利用率处于爬坡期]** -> [毛利率下滑]: 尽管营收增长，但整体毛利率从上年同期下降4.56个百分点至13.35%，反映新产能尚未充分释放规模效应。
- **[半导体封测业务毛利率为负]** -> [整体盈利承压]: 半导体封测业务毛利率为-5.16%，收入占比虽高但自身亏损，拖累公司整体盈利表现。
- **[研发投入持续高企]** -> [费用刚性增长]: 研发费用1.37亿元，占营收20.58%，虽比例略降但绝对额增加2,887万元，构成固定成本压力。
- **[借款规模扩大]** -> [财务费用激增]: 利息费用4,059万元，同比增加1,396万元，反映公司为支撑固定资产投资而大幅增加债务融资。
- **[新工艺/新产品认证周期长]** -> [收入与产能错配]: 部分项目虽已量产，但整体产能利用率仍低，导致收入增长无法覆盖折旧、人工等固定成本的快速增加。

## 风险警告
公司当前面临的核心风险是**“增收不增利”的恶性循环**。营收高速增长（+36.72%）未能转化为利润，反而因固定资产折旧（+6,480万）、股权激励（+3,798万）、人工成本（+3,590万）和利息支出（+1,396万）的刚性增长，导致亏损扩大至1.57亿元。这种“收入增长-资本开支-折旧/费用增加-亏损扩大”的模式，若产能利用率无法快速提升，将形成持续的财务失血。

其次，**半导体封测业务的结构性亏损**是重大隐患。该业务作为营收增长主力（+140.66%），毛利率却为-5.16%，意味着每多接一单都在亏损。这反映出公司在扩张期可能牺牲了定价或成本控制，一旦下游需求波动，该业务将迅速放大亏损。此外，公司资产负债率已攀升，长期应付款（明股实债）同比大增67%，财务杠杆风险显著上升。
