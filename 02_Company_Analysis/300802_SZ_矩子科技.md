# 300802.SZ 深度透视

## 因果逻辑链
- **[AI算法全面导入机器视觉设备]** -> [产品竞争力提升与销量增长]: AI算法显著提升复杂缺陷识别能力、降低误判率，并实现“免调参”自适应，极大缩短客户产线部署时间，直接推动AOI等核心设备销量增长39.53%。
- **[机器视觉设备业务高增长]** -> [整体营收与利润大幅提升]: 机器视觉设备收入同比增长39.53%，毛利率提升4.82个百分点，成为驱动公司营收增长16.84%、扣非净利润增长46.68%的核心引擎。
- **[半导体封测设备获头部客户复购]** -> [打开第二增长曲线]: 公司半导体AOI及点胶设备凭借技术迭代，获得知名IGBT及封测企业持续复购订单，市场认可度提升，为未来增长提供新支撑。
- **[海外市场拓展与本地化布局]** -> [境外收入高速增长]: 马来西亚生产基地投产及全球服务网络完善，使境外收入同比增长52.08%，有效对冲国内市场竞争，并提升供应链韧性。
- **[控制线缆组件业务稳健增长]** -> [提供稳定现金流与客户基础]: 该业务收入同比增长7.36%，主要受益于半导体设备客户采购额提升，为公司整体业绩提供稳定基本盘。
- **[持续高研发投入]** -> [巩固技术护城河]: 研发费用占营收9.38%，重点投入AI、3D检测及X射线技术，确保产品性能国际领先，维持对海外品牌的进口替代优势。
- **[客户集中度较高]** -> [经营业绩存在依赖风险]: 前五大客户销售额占比39.60%，若主要客户经营波动，将对公司业绩产生显著影响。

## 风险警告
**核心风险在于客户集中与市场竞争的双重挤压。** 公司前五大客户销售额占比近40%，且深度绑定苹果、华为、比亚迪等头部企业及其代工厂，客户集中度极高。一旦核心客户需求放缓或转向竞争对手，将直接冲击公司营收。同时，机器视觉行业技术迭代快，海内外竞争者众多，公司虽在3D AOI领域有先发优势，但若不能持续领先，将面临价格战和市场份额流失的风险。

**另一重大风险是汇率波动与全球供应链重构的不确定性。** 公司境外收入占比已超34%，主要以美元结算，人民币汇率波动将直接影响利润。同时，全球供应链区域化、本地化趋势加速，公司虽已在马来西亚等地布局，但海外生产基地的产能爬坡、管理效率及地缘政治风险，都可能成为业绩的潜在拖累，考验公司的全球化运营能力。
