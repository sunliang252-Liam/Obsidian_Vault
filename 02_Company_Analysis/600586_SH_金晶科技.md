# 600586.SH 深度透视

## 因果逻辑链
- **[房地产需求萎缩]** -> [营收与利润暴跌]: 下游房地产新开工、竣工面积持续下降，导致浮法玻璃需求萎缩、价格低迷，公司营收下降29.94%，归母净利润由盈转亏至-5.85亿元。
- **[纯碱行业供需失衡]** -> [化工板块亏损]: 纯碱产能过剩、库存高企、价格持续走低，公司氨碱法工艺成本承压，化工板块毛利率下降11.44个百分点，子公司海天生物亏损6725万元。
- **[光伏玻璃产能过剩]** -> [马来西亚基地由盈转亏]: 全球光伏玻璃阶段性供给过剩，叠加美国补贴政策影响，马来西亚基地背板玻璃销量大幅收缩，全年亏损4088万林吉特。
- **[玻璃生产线冷修]** -> [管理费用增加]: 公司对多条浮法及光伏玻璃产线进行停产冷修或改造升级，相关折旧计入当期损益，导致管理费用同比增长10.91%。
- **[产品价格跌幅大于成本降幅]** -> [毛利率全面恶化]: 尽管原材料和能源成本有所下降，但主要产品（建筑玻璃、技术玻璃、光伏玻璃、纯碱）售价下跌幅度更大，导致各板块毛利率均出现显著下滑。
- **[Low-E节能玻璃逆势增长]** -> [结构性亮点]: 在“双碳”政策驱动下，Low-E节能玻璃作为高附加值产品，销量同比增长18.66%，毛利率提升至19.11%，成为公司为数不多的盈利增长点。
- **[TCO玻璃技术突破]** -> [未来增长潜力]: 公司与钙钛矿头部企业合作，实现2.1mm超薄玻璃基片TCO产品关键突破，维持了钙钛矿用TCO的事实标准，为未来绿色能源赛道布局奠定基础。

## 风险警告
公司面临的核心风险是**下游需求持续萎缩与行业产能过剩的双重挤压**。浮法玻璃和纯碱两大主营板块均处于供需失衡的深度调整期，房地产竣工面积预计2026年继续下滑7%-10%，纯碱新增产能仍在释放，产品价格大概率延续弱势。公司2025年已出现巨额亏损，若行业景气度无法回升，经营压力将持续加大。

**资产减值与现金流恶化风险**不容忽视。报告期内公司计提存货跌价准备及资产减值损失近9000万元，多条产线停产冷修导致资产效能下降。经营活动现金流净额同比腰斩至2.99亿元，筹资活动现金流净流出6.68亿元，显示公司造血能力减弱且面临较大的偿债压力。一年内到期的非流动负债激增51.89%至8.03亿元，短期流动性风险上升。
