# 300604.SZ 深度透视

## 因果逻辑链
- **[国产替代加速 + 高端产品突破]** -> **营收与利润爆发式增长**: 公司抓住半导体行业复苏和国产化替代机遇，D9000系列数字测试机、三温分选机等高端新品放量，推动营收同比增长45.31%，归母净利润同比暴增190.42%。
- **[持续高研发投入]** -> **构筑高端产品护城河**: 研发投入占营收23.97%（12.68亿元），重点攻关数字测试机、探针台等高端设备，已拥有超1400项专利，支撑产品从模拟/功率向SoC/逻辑等高端领域拓展。
- **[并购整合STI与EXIS]** -> **实现产品线全覆盖与海外渠道协同**: 收购STI（AOI检测）和EXIS（转塔式分选机），补齐了光学检测和转塔式分选机短板，实现“测试机+分选机+探针台+AOI”全产品线布局，并借助其海外客户网络进入国际供应链。
- **[大客户战略深化]** -> **市场份额与品牌效应提升**: 深度绑定长电科技、华天科技、通富微电等国内封测龙头，前五大客户销售占比达57.66%，客户粘性高，为业绩增长提供稳定基本盘。
- **[高端智能制造基地投产]** -> **突破产能瓶颈**: 集成电路高端智能制造基地于2025年5月正式投入使用，解决了此前产能不足的制约，为订单交付和规模扩张提供了物理基础。
- **[产品结构优化]** -> **毛利率维持高位**: 高毛利的测试机（62.25%）营收占比提升至60.53%，带动整体毛利率稳定在55.05%，显示出产品升级带来的盈利能力提升。

## 风险警告
**核心风险在于高端市场突破的不确定性与高研发投入的持续压力。** 公司虽在模拟/功率测试领域实现国产替代，但在SoC、数字测试等高端市场，仍面临泰瑞达、爱德万等国际巨头的技术封锁和品牌壁垒。公司研发投入资本化率从5.63%骤升至26.18%，若高端新品（如探针台、高端数字测试机）商业化不及预期，将面临巨额研发费用摊销和资产减值风险，侵蚀利润。

**财务风险方面，经营现金流与净利润严重背离。** 2025年净利润13.3亿元，但经营性现金流仅5.6亿元，同比下降10.1%，主要因存货和应收账款大幅增加（存货35.6亿元，应收账款19.9亿元）。公司处于高速扩张期，大量资金沉淀于营运环节，叠加短期借款（6.8亿）和长期借款（10.8亿）攀升，财务费用同比暴增1110%，需警惕现金流恶化及债务偿付压力。
