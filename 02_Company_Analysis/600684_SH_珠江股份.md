# 600684.SH 深度透视

## 因果逻辑链
- **控股股东定向增发7.33亿元** -> **财务费用下降28.78%**: 募集资金偿还借款，债务规模显著下降，利息支出减少。
- **处置广州中侨债权资产3.34亿元** -> **投资活动现金流净额由负转正**: 非公开协议转让给控股股东子公司，回笼大额资金。
- **A股市场回暖+出售全部股票资产** -> **非经常性损益大幅增加**: 公允价值变动收益及处置收益合计约978.82万元，叠加股票资产已全部处置。
- **“城市服务+文体运营”双主业协同** -> **营收结构优化，文体运营毛利率提升2.19个百分点**: 基础服务稳盘，增值服务增效，内容运营破局，文体运营收入增长10.54%。
- **珠江城服业绩承诺达标** -> **归母净利润增长375.15%**: 置入资产珠江城服2025年扣非净利润8,099.12万元，完成业绩承诺（7,900万元）。
- **上年计提大额减值准备，本期未新增** -> **归母净利润同比大幅增长**: 2024年对广州中侨、东湛公司计提其他应收款减值准备，本期无新增。
- **经营活动现金流净额下降75.49%** -> **上年收回坑口保证金及前期经费1.93亿元**: 本期无此非经常性现金流入，导致经营性现金流大幅减少。

## 风险警告
**核心风险在于盈利的可持续性。** 2025年归母净利润暴增375.15%，主要依赖非经常性损益（处置股票资产、债权资产）以及上年同期的高基数减值损失。扣非净利润仅增长99.43%，且经营性现金流净额同比大幅下降75.49%，显示主业造血能力并未同步改善。公司母公司未分配利润仍为-5.79亿元，不具备分红条件，股东回报能力薄弱。

**双主业面临结构性挑战。** 城市服务板块面临物业费限价政策与用工成本上升的双重挤压，毛利率下滑2.83个百分点；文体运营板块高度依赖居民消费意愿，宏观经济波动可能导致赛事、演艺需求萎缩。此外，公司仍有大量历史遗留诉讼（如东湛公司、盛唐公司等）处于执行阶段，相关债权减值风险尚未完全出清。
