# 600649.SH 深度透视

## 因果逻辑链
- **[房产项目竣工交付结转增加]** -> [营业收入同比+53.27%]: 2025年露香园、青溪云邸等核心项目集中交付，推动营收从94.3亿跃升至144.6亿。
- **[项目竣工后利息支出停止资本化]** -> [财务费用同比+35.12%]: 大量项目转入竣工阶段，利息费用从资本化转为费用化，财务费用增至8.71亿元，侵蚀利润。
- **[扣非净利润大增212.15%]** -> [主业盈利能力实质性改善]: 剔除证券公允价值波动干扰后，核心房地产业务贡献净利3.31亿元，显示开发主业已从低谷反弹。
- **[“城投宽庭”租赁社区规模扩张]** -> [投资性房地产同比+34.40%]: 新增徐汇社区等租赁房项目入账，在管房源达1.7万套，年租金超6亿，形成稳定现金流压舱石。
- **[REITs平台实现“投融管退”闭环]** -> [存量资产盘活与资本循环]: 徐汇社区通过Pre-REITs收购后开业，浦江、九星社区推进扩募，金融工具打通资产退出通道。
- **[上海核心区土地储备聚焦]** -> [抗周期波动能力]: 持有黄浦区露香园、小东门等高价值地块，以及杜行、诸翟城中村改造项目，保障未来3-5年开发资源。
- **[证券投资公允价值波动]** -> [非经常性损益大幅减少]: 2025年公允价值变动收益仅-0.11亿（2024年为+1.61亿），导致归母净利润增速（+19.19%）远低于扣非增速。

## 风险警告
**核心风险在于高杠杆与低周转的错配。** 公司总资产815亿，资产负债率73.15%，有息负债高达421.83亿元，而净资产仅218.86亿。2025年经营活动现金流净额同比-20.05%至21.24亿，筹资活动净流出25.16亿，表明公司正面临“销售回款放缓+融资净偿还”的双重压力。利息保障倍数仅0.93，已处于“赚的钱不够付利息”的危险边缘，任何销售不及预期或融资环境收紧都可能引发流动性危机。

**另一个重大风险是利润对项目交付节奏的极度依赖。** 2025年营收暴增53%完全依赖露香园、青溪云邸等少数高端项目的集中交付，这种脉冲式收入不可持续。2026年若无同等量级项目入市，营收和利润将面临断崖式回落。同时，公司持有大量投资性房地产（102亿）和金融资产（9.1亿），其公允价值变动对利润影响巨大，市场下行周期中可能成为利润的“隐形杀手”。
