# 688109.SH 深度透视

## 因果逻辑链
- **[房建市场持续萎缩]** -> [营收微降2.29%]: 房建投资下滑导致客户对传统工具软件新购需求下降，建筑信息化软件和智慧工地业务均受拖累。
- **[聚焦央国企与基建转型]** -> [智慧工地业务基本持平]: 主动将资源向能源、水利等高增长基建领域倾斜，成功对冲房建业务下滑，业务结构持续优化。
- **[“提质增效、精兵强将”经营方针]** -> [净利润大增48.15%]: 通过优化人员结构、严控费用，销售、管理、研发三项费用合计同比下降2038万元，驱动利润弹性释放。
- **[加强应收账款回收]** -> [经营现金流净额增长15%]: 强化订单质量管控与历史账款回收，销售商品收到的现金同比增加2755万元，现金流质量显著改善。
- **[AI技术驱动产品升级]** -> [品茗晓筑等AI产品客户覆盖率增长30%]: 将AI融入方案审查、智能组价、工地巡检等场景，形成差异化竞争力，客户粘性增强。
- **[BIM三维图形平台自主研发]** -> [突破国产替代瓶颈]: 方舟图形平台完成WASM三维引擎全栈开发，解决超大型模型加载问题，实现信创环境适配，降低对Autodesk依赖。
- **[水利/能源政策红利]** -> [基建业务成为新增长极]: 水利部推进数字孪生建设，公司成功参与雅江水电站等标杆项目，在抽水蓄能、核电等高技术门槛领域建立优势。

## 风险警告
**核心风险在于“AI转型”的宏大叙事与“房建萎缩”的残酷现实之间的巨大鸿沟。** 公司营收已连续两年停滞在4.4亿左右，净利润增长完全依赖“降本增效”而非“增收”，这种内生性改善的可持续性存疑。董事长提出“2027年AI产值占比超30%”的目标，但当前AI业务仍处于起步阶段，且面临通用大模型厂商降维打击的风险。若基建业务增长无法加速填补房建下滑的缺口，公司可能陷入“增收无望、降本见顶”的困境。

**另一重大风险是技术依赖与客户集中度。** 公司核心BIM产品HiBIM仍依赖美国Autodesk的Revit平台，中美贸易政策变化可能直接导致研发停滞。同时，公司营收高度集中于浙江地区（约45%），且前五大客户销售额占比超21%，区域经济波动或大客户流失将对业绩造成显著冲击。此外，高达92%的现金分红比例虽彰显回报诚意，但也可能削弱公司应对行业寒冬的财务缓冲能力。
