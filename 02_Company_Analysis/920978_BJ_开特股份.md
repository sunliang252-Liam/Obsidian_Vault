# 920978.BJ 深度透视

## 因果逻辑链
- **[汽车行业景气度提升]** -> [营收增长36.68%]: 2025年国内汽车产销量同比增长超9%，新能源汽车渗透率突破47.9%，直接拉动公司传感器、控制器、执行器三大产品线同步放量。
- **[执行器类新产品持续量产]** -> [营收结构优化]: 执行器类产品收入同比大增50.87%，超越传感器成为第一大收入来源，标志着公司从传统传感器向高价值执行器系统集成商转型成功。
- **[境外客户拓展成效显著]** -> [毛利率结构性改善]: 境外收入同比大增89.20%，且境外毛利率（42.96%）显著高于境内（30.68%），尤其控制器类境外销售占比从14.49%提升至26.19%，带动该品类毛利率提升9.93个百分点。
- **[储能CCS产品实现批量订单]** -> [开辟第二增长曲线]: 储能领域CCS产品从0到1突破，其他类产品收入同比暴增405%，验证了“汽车主业+新赛道”双轮驱动战略的初步成效。
- **[股权激励费用与人员扩张]** -> [管理费用率承压]: 管理费用同比增长37.83%，主要系管理人员增加、新办公楼折旧及股权激励费用，增速略超营收增速，对净利润率形成一定侵蚀。
- **[应收账款规模随营收扩张]** -> [营运资金占用加剧]: 应收账款账面价值达5.33亿元，占总资产36.52%，且客户通过迪链凭证结算导致回款周期较长，经营活动现金流虽改善但远低于净利润水平。
- **[政府补助大幅减少]** -> [非经常性损益波动]: 其他收益同比减少53.98%（减少909.79万元），导致净利润增速（25.62%）显著低于扣非净利润增速（32.85%），盈利质量实际在提升。

## 风险警告
**核心风险在于应收账款高企与客户集中度带来的现金流压力。** 公司应收账款占总资产比例高达36.52%，且主要通过迪链数字信用凭证结算，回款周期长、回收进度存在不确定性。尽管营收高速增长，但经营性现金流净额（1.67亿）仅为净利润（1.73亿）的96%，若下游整车厂价格战加剧导致付款条件恶化，公司可能面临流动性紧张与坏账损失的双重压力。此外，第一大客户A公司销售占比28.12%，客户集中度风险不容忽视。

**新业务拓展存在较大不确定性，可能成为业绩拖累。** 公司积极布局储能、数据中心、具身智能等新兴领域，但这些业务尚处于早期投入阶段：储能CCS产品毛利率较低，具身智能合资公司（开特具身智能）报告期内亏损，对豪特节能的战略投资及私募基金投资均需时间验证。若新赛道拓展进度不及预期，前期资本开支和研发投入将无法有效转化为利润，反而会侵蚀公司ROE。
