# 300246.SZ 深度透视

## 因果逻辑链
- **[血透耗材集采降价]** -> [毛利率下降]: 部分血透耗材产品集采导致销售价格同比下降，叠加原材料成本上涨，整体毛利率承压。
- **[美元兑人民币汇率下行]** -> [汇兑损失]: 美元存款产生汇兑损失，叠加可转债摊销费用高企，对净利润构成重大拖累。
- **[产品价格下降触发减值]** -> [资产减值损失]: 基于销售价格下降，公司对存货及部分生产设备计提资产减值准备，进一步侵蚀利润。
- **[肾病医疗板块收入增长5.17%]** -> [营收微增3.29%]: 血透产品销量提升带动板块收入增长，但监护仪板块收入下滑2.25%，整体营收仅小幅增长。
- **[经营活动现金流大幅改善]** -> [现金流转正]: 销售回款增加，经营活动现金流净额从-8636万元大幅转正至9044万元，显示运营质量改善。
- **[可转换债券即将到期]** -> [负债结构变化]: 应付债券重分类至一年内到期的非流动负债，短期偿债压力显著增加。
- **[血透设备受益于医保新规]** -> [产品竞争力提升]: D800系列设备内置血温、血压等监测功能，满足医保新规要求，无需额外模块，形成差异化优势。
- **[苏州君康持续亏损]** -> [拖累整体利润]: 子公司苏州君康（血透器）亏损667万元，显示耗材产能爬坡与盈利尚需时日。

## 风险警告
公司连续三年扣非净利润为负，核心盈利能力尚未恢复。主要风险在于：血透耗材集采降价趋势持续，虽“以价换量”但毛利率承压；可转换债券即将到期（约2.64亿元重分类至一年内非流动负债），短期偿债压力陡增，财务费用高企；子公司苏州君康持续亏损，血透器产能释放与盈利拐点不确定。

此外，海外市场面临美国关税政策不确定性与中东地缘冲突风险，可能影响出口业务稳定性。公司虽在血透全产业链布局，但行业竞争加剧，若无法通过产品升级与成本控制对冲集采降价，盈利改善将面临较大挑战。
