# 600617.SH 深度透视

## 因果逻辑链
- **[终端需求疲软]** -> [天然气销售量下降]: 2025年采暖季偏暖、房地产调整拖累工业用气，导致公司天然气销售量减少，营业收入同比下降4.86%。
- **[财务费用大幅减少]** -> [利润总额扭亏]: 公司通过提前偿还高息贷款、高息贷款置换，优化财务结构，财务费用同比下降25.60%，是利润总额由负转正的核心驱动。
- **[会计估计变更（延长管道折旧年限）]** -> [营业成本减少]: 公司将天然气长输管道折旧年限从30年延长至40年，直接减少营业成本约7,629万元，增厚利润总额约7,472万元。
- **[投资收益增加]** -> [净利润改善]: 对联营企业和合营企业的投资亏损收窄，投资收益同比增加，助力归属于上市公司股东的净利润减亏16.24%。
- **[关联交易依赖度高]** -> [经营独立性风险]: 前五名客户销售额中关联方占比高达46.00%，前五名供应商采购额中关联方占比19.72%，公司经营深度绑定控股股东华新燃气集团。
- **[高财务杠杆与利息负担]** -> [持续侵蚀利润]: 尽管财务费用下降，但公司合并报表有息债务余额仍高达158.52亿元，利息支出5.48亿元，是扣非净利润持续为负的根本原因。
- **[政府补助依赖]** -> [非经常性损益支撑]: 计入当期损益的政府补助高达2.77亿元，是公司实现利润总额为正的关键，扣非净利润-5.09亿元，真实盈利能力堪忧。

## 风险警告
**核心风险在于“账面盈利，实质亏损”的财务困境。** 公司2025年利润总额为正，但扣非净利润连续两年巨亏（-5.09亿元），盈利完全依赖财务费用削减、会计估计变更（延长折旧年限）和巨额政府补助。公司资产负债率高达81.37%，有息负债超158亿元，沉重的利息负担持续侵蚀主业现金流，造血能力严重不足。

**经营层面，公司面临量价双杀与关联依赖的双重压力。** 终端需求疲软导致天然气销售量下滑，而省内城燃业务毛利率为负（-0.73%），CNG/LNG业务毛利率也为负（-3.09%），主业盈利能力堪忧。同时，公司对控股股东华新燃气集团的关联交易依赖度极高（销售占比46%），同业竞争问题尚未彻底解决，经营独立性和市场化竞争能力存疑。
