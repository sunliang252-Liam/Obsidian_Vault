# 603191.SH 深度透视

## 因果逻辑链
- **[110kV及以上高电压等级变压器收入增长74.39%]** -> [输配电业务收入增长29.90%]: 公司主动优化产品结构，聚焦高附加值的高电压等级产品，使其占输配电收入比重从44%跃升至60%，成为核心增长引擎。
- **[取向硅钢价格下滑299元/吨]** -> [硅钢业务收入下降4.22%]: 尽管产能利用率达103.71%且满产满销，但行业供需转向结构性过剩，单位售价下跌直接侵蚀了收入规模。
- **[收购云变电气获得500kV级生产资质]** -> [高端市场突破]: 公司借此切入超高压领域，并在铁路牵引变压器（市占率30%+）和高原特种变压器等细分赛道建立龙头地位。
- **[成功攻克075牌号高磁感取向硅钢技术]** -> [缩小与头部企业技术差距]: 突破高端材料壁垒，为后续提升高牌号产品占比、优化硅钢业务盈利结构奠定基础。
- **[携手华为成为重卡兆瓦超充生态核心伙伴]** -> [开辟第二增长曲线]: 依托自产智能变充一体机，切入电动重卡超充蓝海市场，探索“设备+运营”一体化模式，形成新业务极。
- **[经营活动现金流净额同比大增1012.51%]** -> [盈利质量显著改善]: 扣非净利润增长79.38%，核心业务造血能力增强，经营拐点确立，扭转了此前增收不增利的局面。
- **[全产业链“以材补器、以器促材”]** -> [成本与供应稳定性优势]: 国内唯一实现取向硅钢到变压器全产业链布局的企业，上游材料自给有效对冲原材料价格波动风险，并保障高端变压器供应链安全。

## 风险警告
**核心风险在于取向硅钢业务的盈利压力与重卡超充业务的不确定性。** 公司硅钢业务虽满产满销，但行业产能过剩（2025年全国产量增14.3%至337万吨）导致价格承压，该板块毛利率仅8.40%，显著低于输配电业务的13.22%。若价格战持续或高牌号产品量产不及预期，硅钢业务可能持续拖累整体利润。同时，重卡超充作为全新业务，计划投资5.4亿元建设近100座站，目前仅1号站投运，规模化运营尚需验证，存在投资回报周期长、竞争格局恶化的风险。

**财务结构上，高杠杆与应收账款风险并存。** 公司总资产72.58亿元，但资产负债率较高，长期借款同比大增38.43%至15.28亿元，且1年内需偿还的有息负债达6.13亿元。同时，应收账款账面价值高达19.70亿元，占总资产27.14%。若下游客户（尤其是央国企）回款周期延长或出现信用风险，将显著影响公司现金流和资产质量，叠加高额利息支出（财务费用同比增168.50%），财务脆弱性不容忽视。
