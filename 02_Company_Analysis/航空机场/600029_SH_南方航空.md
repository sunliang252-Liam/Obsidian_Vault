# 600029.SH 深度透视

## 因果逻辑链
- **国际航线运力扩张** -> **营收增长**: 国际航线ASK同比增长18.46%，带动总营收增长4.61%，弥补国内票价下行压力。
- **航油成本下降** -> **利润扭亏**: 航油成本同比减少4.48%，叠加营收增长，推动归母净利润从亏损16.96亿转为盈利8.57亿。
- **客座率提升** -> **单位成本摊薄**: 平均客座率提升1.36个百分点至85.74%，每可用吨公里主营业务成本同比下降3.26%。
- **汇兑收益增加** -> **财务费用减少**: 人民币兑美元汇率波动带来汇兑收益3.45亿元，使财务费用同比减少24.05%。
- **高负债率与资本开支** -> **现金流压力**: 资产负债率84.27%，2025年筹资活动现金净流出同比增加95.46%，主要因偿还债务增加。
- **货运业务高毛利** -> **利润稳定器**: 货运及邮运业务毛利率30.10%，贡献稳定利润，对冲客运业务波动风险。
- **母公司未弥补亏损** -> **分红受限**: 母公司累计未弥补亏损508.55亿元，导致公司连续三年不满足分红条件。

## 风险警告
**核心风险在于高财务杠杆与汇率、油价的“双杀”效应。** 公司资产负债率高达84.27%，且大量债务以外币（尤其是美元）计价。人民币兑美元每贬值1%，将导致净利润减少约2.26亿元。同时，航油成本占营业成本超32%，油价每上升10%，成本将增加约52.53亿元。在盈利微薄（归母净利仅8.57亿）的背景下，任何汇率或油价的剧烈波动都可能将公司重新拖入亏损泥潭。

**其次，公司内生造血能力仍显脆弱。** 尽管2025年扭亏，但扣非净利润仅为1.45亿元，盈利高度依赖非经常性损益（7.12亿）和成本端的被动改善（油价下跌）。客运主业每收费客公里收益同比下降4.17%，显示票价竞争激烈，提价能力不足。叠加未来三年高达800亿的飞机资本开支承诺，公司面临“增收不增利”和持续现金流压力的困境。
