# 300683.SZ 深度透视

## 因果逻辑链
- **[原料药行业竞争加剧，订单不足]** -> [原料药及中间体业务持续亏损]: 子公司荆门汉瑞因市场供需逆转，收入不达预期，叠加固定资产折旧摊销压力，导致该业务板块亏损，并对存货计提减值1193万元。
- **[CRO行业政策与市场环境变化]** -> [子公司天津汉康营收下滑]: 受政策调控及市场环境影响，天津汉康当期营收下滑，导致公司对其形成的商誉计提8500万元减值准备。
- **[参股公司持续亏损]** -> [长期股权投资减值]: 参股公司西威埃医药技术(上海)有限公司连续亏损，公司计提长期股权投资减值1498.59万元。
- **[核心创新药沙艾特纳入医保]** -> [注射用埃普奈明销量爆发]: 沙艾特（注射用埃普奈明）纳入国家医保后，市场需求快速攀升，销售量同比暴增1190.89%，收入同比增长290.42%，成为公司核心增长引擎。
- **[金路捷市场趋于稳定]** -> [成熟产品收入基本持平]: 注射用鼠神经生长因子（金路捷）市场规模降幅放缓，销量趋于稳定，收入同比仅下降4.40%，为公司提供稳定的现金流基础。
- **[医药技术服务收入大幅下滑]** -> [公司整体营收下降]: 占营收比重最大的医药技术服务收入同比下降41.22%，直接导致公司总营收同比下降16.57%。
- **[非经常性损益贡献]** -> [部分对冲经营亏损]: 报告期内非经常性损益（主要为投资收益和政府补助）对净利润的影响额为2342.06万元，部分缓解了主营业务的亏损压力。

## 风险警告
公司当前面临的最大风险是**资产减值风险**。原料药业务因行业竞争加剧持续亏损，导致存货和固定资产存在进一步减值可能；CRO业务受政策环境影响，子公司天津汉康营收下滑，已计提大额商誉减值，若市场环境持续恶化，剩余商誉（约1.79亿元）仍面临减值压力。此外，参股公司连续亏损也造成了长期股权投资减值，资产质量承压。

其次，**新药商业化与产能扩张的不确定性**是另一核心风险。核心产品沙艾特虽销量爆发，但现有产能已无法满足需求，公司正推进新增产能建设。若新增产能无法及时投产或市场推广不及预期，将面临产能闲置和折旧增加的双重压力。同时，公司在研管线（如重组人神经生长因子滴眼液）仍处于临床早期，研发周期长、投入大，存在研发失败或上市后不被市场接受的风险。
