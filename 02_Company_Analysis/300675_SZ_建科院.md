# 300675.SZ 深度透视

## 因果逻辑链
- **市场需求结构性萎缩与竞争加剧** -> **营收与利润双降**: 常规业务（城市规划、建筑设计、检测）订单下滑，叠加客户资金紧张、结算周期延长，导致全年营收同比下滑31.47%，上市以来首次亏损。
- **业务模式主动转型** -> **短期业绩承压**: 公司主动收缩非核心区域低价值散单，集中资源投入“场景创新服务”等系统解决方案，导致其他技术服务收入骤降54.34%，但新签合同质量提升（“三重专项”占比达60%）。
- **长账龄应收款增加** -> **坏账计提压力激增**: 尽管客户资质优良（67%为政府/国企），但回款周期拉长，导致信用减值损失达1584万元，成为亏损的重要推手。
- **投资性房地产公允价值下降** -> **非经常性亏损**: 未来大厦入驻率不足，公允价值变动损失1273万元，直接侵蚀利润。
- **研发投入维持高位** -> **短期利润承压，长期技术储备**: 研发费用占营收14.62%，虽压缩当期利润，但巩固了“光储直柔”、绿建鸿蒙等核心技术壁垒。
- **“城市客户”经营模式深化** -> **新业务韧性显现**: 场景创新服务（总师制、智库）营收同比持平，证明高附加值系统解决方案在逆境中具备抗周期性。
- **现金流管理优于利润表现** -> **经营安全边际**: 全年回款2.92亿元高于营收，经营性现金流净流出虽扩大，但通过强力清收和融资调整，保障了转型期的资金链安全。

## 风险警告
公司面临的核心风险是**战略转型的“青黄不接”**。传统单点技术服务业务（占营收近24%）快速萎缩，而作为第二增长曲线的“场景创新服务”和“战略孵化服务”虽展现韧性，但体量尚小，不足以弥补下滑缺口。若转型速度不及预期，或新业务规模化受阻，公司可能陷入持续亏损的困境。

另一重大风险是**现金流与资产质量的持续恶化**。尽管回款力度加大，但长账龄应收款规模仍高达6.6亿元，且客户资金普遍紧张，坏账风险并未出清。同时，核心资产“未来大厦”运营压力巨大（入驻率不足），其公允价值波动和运营收入不达预期，将持续对利润表和资产负债表构成双重压力。
