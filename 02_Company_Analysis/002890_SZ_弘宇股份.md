# 002890.SZ 深度透视

## 因果逻辑链
- **[农机行业景气度]** -> [营收增长]: 国家农业机械化政策推动拖拉机需求，带动公司产品销量提升。
- **[原材料价格波动]** -> [毛利率波动]: 钢材等成本占比较高，价格上行直接压缩利润空间。
- **[客户集中度高]** -> [经营风险]: 前五大客户收入占比超70%，单一客户流失将严重冲击业绩。
- **[产品结构单一]** -> [增长天花板]: 主要依赖拖拉机液压提升器，缺乏多元化收入来源。
- **[研发投入不足]** -> [技术壁垒低]: 研发费用率低于行业均值，难以形成差异化竞争优势。
- **[产能利用率]** -> [规模效应]: 产能利用率提升可摊薄固定成本，反之则拖累盈利能力。
- **[应收账款周转]** -> [现金流压力]: 回款周期延长导致经营性现金流紧张，影响运营效率。

## 风险警告
核心风险在于客户与产品的高度集中。公司对前五大客户依赖度过高，且产品仅聚焦拖拉机液压提升器，一旦下游农机行业景气度下行或主要客户转向其他供应商，营收将面临断崖式下跌。同时，原材料成本波动直接侵蚀本已微薄的毛利率，缺乏定价权使其难以转嫁压力。

此外，研发投入长期不足，导致技术迭代缓慢，在行业向智能化、高端化转型的背景下，公司可能被竞争对手拉开差距。产能利用率波动与应收账款周转问题进一步加剧了经营脆弱性，整体抗风险能力较弱。
