# 600115.SH 深度透视

## 因果逻辑链
- **[国际航线扩张]** -> [收入结构优化]: 国际航线ASK同比增长18.45%，国际旅客周转量同比增长22.69%，带动国际收入同比增长20.82%，有效对冲国内航线收入下滑。
- **[航油成本下降]** -> [毛利率改善]: 平均航空油价同比下降8.20%，减少航油成本39.03亿元，是营业成本增速（4.87%）低于收入增速（5.92%）的核心原因。
- **[财务费用缩减]** -> [利润扭亏为盈]: 利息支出同比减少9.63亿元（-18.71%），叠加汇兑收益2.05亿元（去年同期损失7.63亿元），财务费用同比下降32.14%，是利润总额从-39亿转为+2.74亿的关键。
- **[客座率提升]** -> [单位成本摊薄]: 整体客座率同比提升3.04个百分点至85.86%，固定成本（折旧、人工）被更多旅客分摊，座公里成本下降。
- **[债务结构优化]** -> [融资成本降低]: 增加人民币债务占比（87.34%），减少美元债务（11.11%），并发行低成本超短融和中期票据，降低利率和汇率风险敞口。
- **[枢纽市场份额提升]** -> [网络效应增强]: 上海市场份额升至43%，经上海中转旅客同比增长17.5%，枢纽航班波效应提升中转效率和客源质量。
- **[非经常性收益增厚]** -> [净利润减亏]: 收购STARCO股权重估利得及处置其他投资，贡献投资收益9.00亿元（同比+191.26%），掩盖了主业扣非后仍亏损29.49亿元的事实。

## 风险警告
**核心风险在于高杠杆与持续亏损的恶性循环。** 公司资产负债率高达86.69%，带息债务总额1,819亿元，每年利息支出超40亿元。尽管2025年实现利润总额扭亏，但扣非净利润仍亏损29.49亿元，主业造血能力并未根本性恢复。母公司累计可供分配利润为负，已连续多年无法分红，股东回报严重缺失。若未来航油价格反弹或人民币贬值，微薄的利润将迅速被吞噬，财务脆弱性极高。

**第二重风险是行业竞争与需求的不确定性。** 国内航空市场“内卷式”竞争加剧，国内航线客运人公里收益同比下降5.03%，票价承压。国际航线虽量增，但收益同比下降1.22%，增量不增价。同时，高铁网络的持续扩张对中短途航线形成替代压力。公司未来三年仍有617亿元资本开支计划，在自身造血不足的情况下，将进一步推高负债，考验融资能力和现金流管理。
