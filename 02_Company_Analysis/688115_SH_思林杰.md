# 688115.SH 深度透视

## 因果逻辑链
- **[产品覆盖拓展]** -> [营收增长39.25%]: 嵌入式智能仪器模块及自动化生产测试设备品类丰富，应用场景从消费电子延伸至半导体、新能源等领域，驱动主营业务收入大幅增长。
- **[股份支付费用激增]** -> [净利润亏损1000万元]: 2024年员工持股计划导致约3300万元股份支付费用计入当期损益，直接侵蚀利润，导致归母净利润由盈转亏。
- **[高研发投入维持技术壁垒]** -> [研发费用率26.35%]: 持续高研发投入（同比+38.12%）巩固模块化仪器核心技术，但短期内对利润形成压力，是“以利润换空间”的战略选择。
- **[苹果产业链深度绑定]** -> [客户集中度高]: 前五大客户销售额占比60.29%，第一大客户占比25.56%，终端需求高度依赖苹果公司，业绩波动与消费电子周期强相关。
- **[模块化替代传统仪器]** -> [毛利率提升至58.19%]: 公司以嵌入式智能仪器模块替代传统标准仪器，通过定制化裁量功能、减少冗余硬件，实现成本优化与毛利率同比提升1.37个百分点。
- **[应收账款高企]** -> [信用减值损失扩大]: 期末应收账款账面余额2.6亿元，同比增长，部分客户资金紧张导致回款慢，信用减值损失同比增加189.94%，成为利润拖累项。
- **[募投项目转固]** -> [固定资产激增2837%]: 募投项目工程完工转固，固定资产从1026万元跃升至3.01亿元，后续折旧费用将增加，对盈利能力构成长期考验。

## 风险警告
**核心风险在于“增收不增利”的结构性矛盾。** 公司营收增长39%但净利润转亏，主因是股份支付费用的一次性冲击。然而，更深层风险在于：高研发投入（26.35%）与高管理费用（+52.41%）的刚性增长，叠加应收账款坏账风险（2.6亿元余额）和存货跌价风险（6160万元余额），将持续侵蚀现金流与利润。若未来股份支付费用摊销完毕，但营收增速放缓或毛利率下滑，公司可能陷入“增长陷阱”。

**客户集中度与行业周期风险是悬顶之剑。** 公司深度嵌入苹果产业链，前五大客户占比超60%，终端需求高度依赖单一消费电子巨头。若苹果产品迭代放缓、订单转移或中美贸易摩擦加剧，公司将面临订单骤减风险。同时，模块化检测仪器领域竞争加剧（普源精电、鼎阳科技等布局），若公司不能持续领先，市场份额可能被蚕食。此外，公司2025年因信息披露违规被监管处罚，治理规范性存疑，需警惕合规风险对估值的影响。
