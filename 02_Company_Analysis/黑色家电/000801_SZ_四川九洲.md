# 000801.SZ 深度透视

## 因果逻辑链
- **[空管业务受益于国防装备升级与低空经济]** -> 收入增长10.21%: 公司作为国内空管系统龙头，受益于“十五五”国防装备扩张周期及低空基础设施建设，机载防撞系统、客舱广播内话等核心产品需求旺盛，国际市场新开拓3个用户国家。
- **[智能终端业务受海外需求萎缩拖累]** -> 收入下降5.38%: 境外收入同比大幅下滑53.60%，主要系拉美、东南亚等传统市场订单减少，导致整体智能终端业务规模收缩，但国内运营商及广电市场占有率保持稳定。
- **[经营性现金流大幅改善]** -> 净额达3.83亿元，同比+473.69%: 主要系销售商品、提供劳务收到的现金增加，表明公司回款能力增强，应收账款管理取得成效，经营质量有所提升。
- **[扣非净利润下滑幅度大于归母净利润]** -> 扣非净利润同比-20.57%: 非经常性损益（如政府补助、债务重组收益、应收款减值转回）合计约7978万元，占归母净利润的44.5%，表明核心业务盈利能力承压。
- **[研发投入维持高位但资本化率为零]** -> 研发费用3.64亿元，占营收8.86%: 公司持续高强度投入空管、微波射频及智能终端新技术研发，但全部费用化处理，未形成无形资产，短期压制利润，长期构筑技术壁垒。
- **[微波射频业务毛利率下滑]** -> 毛利率同比-5.15个百分点至32.76%: 在巩固传统配套的同时，向相控阵、卫星通信等新领域拓展，新项目初期成本较高，叠加市场竞争加剧，导致盈利能力阶段性下降。
- **[关联交易占比高]** -> 前五大客户中关联方九洲电器销售额占比12.30%: 公司对控股股东九洲集团的依赖度较高，关联销售规模达5.06亿元，存在业务独立性与定价公允性风险。
- **[存货大幅增加]** -> 存货同比+52.0%至10.07亿元: 主要系应对供应链涨价而储备原材料，但若下游需求不及预期，将面临存货跌价风险，已计提减值准备1575万元。

## 风险警告
**核心风险在于业绩增长依赖非经常性损益与关联交易。** 公司2025年归母净利润1.79亿元，但扣非净利润仅0.99亿元，同比下滑20.57%，非经常性损益占比高达44.5%。其中，政府补助、债务重组收益及应收款减值转回等一次性收益贡献显著，掩盖了主业盈利能力的真实疲软。此外，前五大客户中关联方九洲电器销售额占比12.30%，业务独立性存疑，若关联交易定价不公允或政策变化，将直接冲击利润。

**应收账款与存货双高构成资产负债表核心风险。** 应收账款余额高达32.21亿元，占总资产41.6%，虽坏账准备计提充分，但回款周期长（尤其防务业务）及部分客户（如广电）付款能力下降，仍存在减值风险。同时，存货同比暴增52%至10.07亿元，主要系主动囤货应对供应链涨价，但若下游订单不及预期或产品降价，将面临大规模跌价损失。两者合计占流动资产的比重极高，严重占用营运资金。
