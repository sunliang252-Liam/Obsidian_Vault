# 600478.SH 深度透视

## 因果逻辑链
- **[储能业务爆发式增长]** -> [营收与利润双增]: 储能产品营收同比暴增1669%，成为公司增长核心引擎，推动总营收增长45.89%，扣非净利润增长1516.64%。
- **[大储能生态创新联合体模式]** -> [项目规模化落地]: 联合体模式打通“资源-技术-项目-产品-运营-资本”闭环，推动全国储能项目开工规模突破4GWh，并网运营1.8GWh。
- **[碳酸锂价格波动与自有矿供给]** -> [锂电材料板块亏损]: 锂电材料营收同比下降55.28%，毛利率为-14.80%，主要受碳酸锂价格波动及自有矿供给率不足影响。
- **[HEV镍氢动力电池基本盘稳固]** -> [传统业务提供稳定现金流]: 受益于丰田等核心客户销量增加，动力电池及极片业务营收增长6.76%，毛利率提升5.97个百分点，为转型提供资金支撑。
- **[产融结合与储能基金]** -> [项目资金闭环]: 凯博储能产业基金规模达14.02亿元，为独立储能电站提供资金赋能，实现“投建运”一体化。
- **[应收账款与合同资产激增]** -> [信用与资产减值风险上升]: 储能业务扩张导致应收账款增长127.23%，合同资产增长566.50%，相应计提信用减值损失5830万元，资产减值损失4011万元。
- **[资产负债率大幅攀升]** -> [财务杠杆与偿债压力加大]: 资产负债率从64.41%升至72.82%，短期借款与长期借款均大幅增加，财务费用增长42.44%，利息支出压力显著。

## 风险警告
公司最大的风险在于储能业务高速扩张带来的现金流与资产质量压力。应收账款和合同资产同比暴增，导致信用与资产减值损失合计近亿元，侵蚀利润。同时，资产负债率攀升至72.82%，有息负债规模扩大，财务费用增长42.44%，若融资环境收紧或项目回款不及预期，将面临流动性风险。

其次，锂电材料板块（碳酸锂）持续亏损，毛利率为-14.80%，严重拖累整体业绩。该板块高度依赖自有矿山供给及碳酸锂价格走势，而矿山产能爬坡与技术革新存在不确定性，若价格持续低迷或成本控制不力，将继续成为业绩的“出血点”。此外，公司对单一客户（丰田产业链）的依赖度依然较高，HEV业务虽为压舱石，但面临电动化转型的长期替代风险。
