# 002908.SZ 深度透视

## 因果逻辑链
- **[传统社保卡发卡业务萎缩]** -> [营收下降14.85%]: 一卡通应用产品销量同比下降26.39%，直接导致该板块收入下滑22.05%，拖累整体营收。
- **[AI及运营服务转型见效]** -> [综合毛利率提升2.02%]: 高毛利的人社运营及大数据服务收入逆势增长6.33%，且毛利率提升5.15%，推动整体盈利结构优化。
- **[战略转型期高投入]** -> [净利润骤降56.13%]: 公司处于AI技术赋能业务的加速拓展阶段，研发与市场投入尚未充分释放经济效益，叠加传统业务下滑，导致利润大幅承压。
- **[“就医无感支付”规模化]** -> [医疗支付场景卡位成功]: 该服务已覆盖广州超290家医院，签约用户超450万，并成功向东莞、清远等城市复制，形成可推广的“广州模式”。
- **[政务Agent落地多省]** -> [AI政务窗口形成闭环]: 自研“知纬解语”大模型驱动的政务Agent已在广东、湖北等省份落地，实现从“智能问答”到“直达办事”的闭环，咨询准确率达99%。
- **[就业AI产品快速渗透]** -> [人岗匹配效率提升60%]: “就业辅导员”AI Agent落地多地招聘场景，累计服务超20万人次，精准匹配能力成为公司就业服务业务的核心竞争力。
- **[数据运营生态初成]** -> [区域数据交易规模突破14亿元]: 通过“德生赋能+联盟发展”模式，助力天河区数据交易规模突破14亿元，验证了数据运营服务的商业化潜力。

## 风险警告
**核心风险在于战略转型的“青黄不接”。** 公司传统社保卡发卡业务（一卡通应用）收入同比下滑22.05%，是营收萎缩的主因。虽然AI和运营服务（人社运营及大数据服务）收入增长6.33%，但其体量（1.77亿）尚不足以完全对冲传统业务下滑（4.91亿降至3.83亿）带来的缺口。公司正处于从“卖卡”到“卖服务”的艰难换挡期，新业务能否快速规模化放量，是决定公司未来业绩拐点的关键。

**盈利质量与现金流同步恶化。** 净利润同比腰斩（-56.13%），同时经营活动现金流净额也大幅下降49.83%。更值得警惕的是，应收账款高达3.96亿元，占总资产26.97%，且被审计机构列为关键审计事项。高额的应收账款不仅占用大量资金，其坏账风险也对利润构成持续威胁。在转型期，若新业务回款周期长，将进一步加剧现金流压力。
