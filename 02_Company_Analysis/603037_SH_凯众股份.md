# 603037.SH 深度透视

## 因果逻辑链
- **[新项目量产与市场开拓]** -> [营收增长10.03%]: 2025年新获项目价值约5.2亿元，新产品实现营收约2亿元，驱动总收入增至8.24亿元。
- **[原材料成本上升与产品结构变化]** -> [毛利率下降]: 营业成本增速（18.18%）远超营收增速（10.03%），导致减震元件和踏板总成毛利率分别下降4.7和6.98个百分点。
- **[可转债利息与汇兑损失]** -> [财务费用激增331.95%]: 发行可转债产生利息费用，叠加汇率波动，财务费用从-178万增至413万元，严重侵蚀利润。
- **[股权激励费用下降]** -> [管理费用减少6.35%]: 2024年股权激励费用较高，2025年相关费用下降，部分对冲了利润下滑压力。
- **[新业务（硬泡聚氨酯缓冲垫）从0到1]** -> [打开第二增长曲线]: 新能源电池包辅材业务实现规模化量产，年销售102万件，成功进入头部电池包企业供应链。
- **[海外布局加速（墨西哥、摩洛哥）]** -> [全球化战略落地]: 墨西哥工厂通过客户审核并交付项目，摩洛哥子公司设立并筹建工厂，为国际市场份额翻番目标奠定基础。
- **[研发投入持续加大]** -> [技术壁垒强化]: 研发费用增长16.14%至5929万元，完成线控制动踏板DV实验、MDI材料10万公里路试，巩固材料配方与系统设计优势。

## 风险警告
**核心风险在于“增收不增利”的困境持续恶化。** 2025年营收增长10%，但归母净利润却下滑18.6%，毛利率全面承压。这并非短期波动，而是行业竞争加剧、整车厂降价压力传导与原材料成本刚性上涨共同作用的结果。若公司无法通过技术降本或产品结构升级扭转这一趋势，盈利能力将持续被侵蚀。

**另一重大风险是激进的资本运作与海外扩张带来的不确定性。** 公司刚完成可转债发行，又启动重大资产重组（收购安徽拓盛），同时加速墨西哥、摩洛哥建厂。多线并进对现金流和管理层精力构成巨大考验。海外子公司所在国的政治、法律、汇率风险，以及并购整合的协同效应能否实现，均存在重大不确定性。一旦某个环节失速，将严重拖累公司整体表现。
