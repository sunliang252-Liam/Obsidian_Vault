# 300939.SZ 深度透视

## 因果逻辑链
- **[电容式触摸屏销量大增]** -> [营收增长19.10%]: 电容式触摸屏收入同比增长34.82%，成为营收增长的核心驱动力，拉动整体营收突破12.9亿元。
- **[订单结构变化与成本上升]** -> [净利润下降12.04%]: 营收增长但毛利率下降1.93%，叠加研发投入增加17.07%、汇兑损失扩大及员工持股计划确认股份支付费用，导致增收不增利。
- **[研发投入持续高增]** -> [电子纸等新产品取得突破]: 研发费用占营收7.28%，推动电子纸实现小批量出货、家庭储能模组进入市场推广，为未来增长储备新动能。
- **[海外产能建设加速]** -> [在建工程大幅增长]: 泰国生产基地及深圳产业基地投入增加，在建工程同比增长222%，反映公司国际化战略进入实质性建设阶段。
- **[技术服务商模式收缩]** -> [直销模式占比提升]: 技术服务商收入同比下降9.73%，终端产品生产厂商收入增长34.05%，销售模式向终端客户倾斜，增强对下游需求的直接掌控。
- **[汇率波动与汇兑损失]** -> [财务费用大幅增加]: 财务费用从-969万升至-108万，主要系汇率波动导致汇兑损失增加，外销占比近40%的公司业绩受汇率影响显著。
- **[员工持股计划实施]** -> [股份支付费用侵蚀利润]: 2025年员工持股计划摊销费用约460万元，直接减少当期净利润，但有助于绑定核心团队利益。

## 风险警告
**增收不增利与成本传导风险。** 公司2025年营收增长19.10%，但净利润下降12.04%，核心原因在于毛利率下滑（-1.93%）和费用刚性增长。电容式触摸屏作为增长主力，其毛利率同比下降2.55%，显示成本端压力未能有效传导至下游。若原材料（TFT屏、芯片）价格持续上涨或下游客户压价，公司盈利能力可能进一步承压。

**汇率波动与海外经营风险。** 公司外销收入占比39.77%，主要以美元结算。2025年财务费用因汇率波动大幅增加，直接冲击利润。同时，泰国生产基地尚处于建设期，报告期内亏损249万元，海外产能的爬坡效率、当地政策及供应链稳定性均存在不确定性，可能影响公司国际化战略的落地节奏与回报。
