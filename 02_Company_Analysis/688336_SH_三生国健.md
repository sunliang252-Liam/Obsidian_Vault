# 688336.SH 深度透视

## 因果逻辑链
- **[与辉瑞达成707项目全球授权合作]** -> [营收暴增251.81%]: 收到辉瑞首付款约28亿元并确认收入，直接推动全年营收从11.9亿飙升至42.0亿，净利润增长311.49%。
- **[益赛普纳入20余省区域集采]** -> [核心产品收入承压]: 产品均价显著下降，尽管销量增长，但不足以抵消价格下滑，导致医药制造收入同比下降8.01%。
- **[研发管线高效推进，多项目进入NDA/III期]** -> [研发投入持续增长但占比稀释]: 研发费用同比增长22.01%至4.35亿元，但因营收基数大幅扩大，研发投入占营收比从45.29%骤降至13.06%。
- **[健尼哌精准市场策略]** -> [抗排异产品实现高增长]: 受益于造血干细胞移植数量增长及有效推广，健尼哌在2025年实现快速增长，成为已上市产品中的亮点。
- **[赛普汀面临医保控费与竞争加剧]** -> [HER2靶向药销售规模回落]: 医院端控费压力、医药反腐及市场竞争白热化，导致赛普汀全年销售规模有所下降。
- **[BD能力验证，开启全球化路径]** -> [公司价值获全球认可]: 与辉瑞的超60亿美元交易创下中国创新药首付款纪录，证明公司源头创新能力，并为后续管线出海奠定基础。
- **[自免管线密集上市]** -> [第二增长曲线逐步兑现]: 益赛拓（IL-17A）获批，IL-1β、IL-4Rα已申报NDA，2026-2028年将迎来产品上市高峰期，形成多增长引擎。

## 风险警告
**核心风险在于业绩对一次性BD收入的极度依赖与核心产品集采降价的持续冲击。** 2025年营收和利润的爆发式增长几乎完全由辉瑞首付款驱动（授权许可收入31.13亿元，占总营收74%），剔除该影响后，公司医药制造收入同比下降8.01%，显示核心商业化能力面临严峻挑战。益赛普作为基石产品，集采扩面导致均价持续下行，销量增长难以对冲，未来若集采范围进一步扩大或价格降幅超预期，将对公司现金流和估值基础造成根本性动摇。

**研发投入的高昂成本与商业化变现的不确定性构成另一重大风险。** 公司研发投入持续增长（2025年5.48亿元），且多个在研项目（如IL-4Rα、IL-5等）处于III期临床或NDA阶段，未来资本化支出和费用化投入仍将维持高位。新产品（如益赛拓）上市后，面临与诺华、礼来等跨国巨头及众多国产竞品的激烈竞争，市场推广和销售放量存在巨大不确定性。若新产品商业化不及预期，而老产品收入持续萎缩，公司将面临“青黄不接”的盈利压力。
