# 000155.SZ 深度透视

## 因果逻辑链
- **[风电光伏发电量下降]** -> [归母净利润同比-30.87%]: 电网改造送出受限及停电检修导致结算电量减少20.46%，叠加电价市场化改革下行，高持股比例的风光发电业务利润大幅收缩。
- **[李家沟锂矿达产]** -> [锂电业务收入同比+197.10%]: 105万吨/年采选项目于2025年9月全面满负荷运行，锂精矿产销量同比暴增161%和1039%，驱动锂电板块成为收入第一大来源。
- **[锂产品价格回升]** -> [下半年利润环比改善]: 下半年锂市场价格回暖，叠加德阿锂业3万吨锂盐项目碳酸锂产线于10月达标达产，锂电业务利润环比显著增加。
- **[会计估计变更]** -> [信用减值损失增加3286万元]: 将应收国网电费及政府机构款项从“无风险组合”调整为“低风险组合”，按1.5%计提坏账，减少归母净利润2635万元。
- **[在建项目持续投入]** -> [资本开支高企，自由现金流为负]: 在建风电光伏装机167.785万千瓦，投资活动现金净流出20.72亿元，主要依赖项目贷款和筹资活动支撑。
- **[控股股东战略重组]** -> [资源获取协同优势]: 四川能投与川投合并新设四川能源发展集团，公司作为旗下新能源核心平台，在多能互补资源获取和产业投资上获得更强支持。
- **[新能源全面入市]** -> [电价下行风险加剧]: 发改价格〔2025〕136号文推动风光电量全面市场化交易，存量项目稳收益，增量项目直面竞争，公司平均上网电价同比下降。

## 风险警告
**核心风险在于“风光利润塌陷”与“锂电盈利脆弱”的结构性失衡。** 公司归母净利润同比下降30.87%，主因是持股比例高的风光发电业务受电网送出受限和电价市场化改革双重冲击，发电量下降20.46%，电价承压。而作为收入增长引擎的锂电业务，虽营收暴增197%，但持股比例较低，且高度依赖锂产品价格波动——2025年利润改善主要靠下半年价格回升，持续性存疑。若锂价再次下行，公司将面临风光降量、锂电降价的“双杀”局面。

**财务风险在于高资本开支与债务扩张的匹配压力。** 公司总资产同比增长10.58%至279亿元，主要靠长期借款（+24.2%）和在建工程（+75.5%）驱动。投资活动现金净流出20.72亿元，而经营活动现金流虽改善至23亿元，但自由现金流仍为负。若在建的167.785万千瓦风光项目投产后电价持续走低，或锂矿锂盐产能利用率不及预期，高杠杆下的偿债能力和投资回报率将面临严峻考验。
