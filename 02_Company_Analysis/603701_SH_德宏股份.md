# 603701.SH 深度透视

## 因果逻辑链
- **[储能业务爆发式增长]** -> [营收创历史新高]: 储能业务营收同比增长265.69%，带动总营收增长30.36%至9.22亿元。
- **[非经常性损益大幅减少]** -> [归母净利润暴跌75%]: 上年同期因土地征迁补偿及股权回购产生约4000万非经常性收益，本期无此项目。
- **[核心主业扣非利润改善]** -> [经营质量提升]: 扣非净利润同比增长21.16%，显示汽车零部件主业盈利能力在营收扩张下实质性好转。
- **[应收账款激增]** -> [经营现金流大幅转负]: 营收扩张导致应收账款增加42.14%，经营活动现金流净额从+6742万骤降至-8142万。
- **[原材料成本高企]** -> [毛利率承压]: 铜材等原材料占成本超90%，发电机毛利率仅8.60%，价格联动机制尚未完全对冲波动风险。
- **[电子真空泵持续放量]** -> [新能源配套地位巩固]: 电子真空泵销量同比增长35.31%，子公司普来恩中力贡献净利润3350万元，成为利润核心支柱。
- **[集团化架构与注册地变更]** -> [战略整合启动]: 注册地迁至宁波，取消监事会，推行集团化管控，旨在提升管理效能与资源协同。

## 风险警告
**现金流断裂风险是当前最紧迫的威胁。** 营收高速增长的同时，应收账款激增至3.49亿元，占总资产23.35%，导致经营活动现金流净流出8142万元。公司被迫大幅增加银行借款（短期借款+68.94%，长期借款新增4900万）来弥补营运资金缺口，财务费用由负转正至309万元。若下游客户（尤其是商用车客户）回款持续恶化，公司将面临流动性危机。

**储能业务的高增长可持续性存疑。** 虽然储能营收暴增265.69%，但该业务毛利率仅13.29%，且子公司镇能科技净资产仅1166万元，净资产收益率极低。公司已取消原计划投资4000万元的翔丰华储能电站项目，显示该业务面临电价政策调整、市场竞争加剧等现实阻力。储能作为第二增长极，目前仍处于“增收不增利”的烧钱阶段，尚未形成稳定盈利模式。
