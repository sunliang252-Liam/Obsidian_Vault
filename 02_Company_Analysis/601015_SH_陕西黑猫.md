# 601015.SH 深度透视

## 因果逻辑链
- **[下游钢铁行业需求疲软]** -> [焦炭价格下跌，公司核心产品毛利率为负]: 下游钢厂利润被压缩，向上游挤压焦化企业利润空间，导致焦炭毛利率降至-18.32%。
- **[原料煤价格下降]** -> [焦炭营业成本同比下降31.60%]: 成本端压力有所缓解，但降幅小于收入降幅（-32.30%），未能扭转亏损。
- **[行业产能过剩，供需失衡]** -> [BDO、精煤等化工产品毛利率大幅下滑]: BDO毛利率从-24.40%骤降至-64.80%，精煤毛利率从18.60%转为-8.54%，显示化工板块全面承压。
- **[公司本部焦炉停产]** -> [焦炭产销量同比下降超10%]: 主动减产以应对市场低迷，但导致固定成本分摊增加，单位成本上升。
- **[出售宏能煤业等资产]** -> [投资活动现金流净额由负转正，缓解资金压力]: 通过出售子公司股权及债权获得约15.77亿元现金，为在建项目及日常运营提供资金。
- **[以建新煤化49%股权融资]** -> [获得14.5亿元现金，增加长期借款]: 通过股权盘活获取资金，但导致长期借款同比增加63.40%，财务费用上升。
- **[内蒙古黑猫LNG项目投产]** -> [LNG产销量同比增长，毛利率提升]: 新项目贡献增量，LNG毛利率逆势提升5.31个百分点，成为少数亮点。

## 风险警告
公司已连续两年巨亏，2025年归母净利润-11.77亿元，且经营活动现金流净额为-5.34亿元，造血能力严重不足。核心风险在于**焦炭主业深陷上下游“双重挤压”**：下游钢铁行业需求长期疲软，焦炭价格持续低迷，而公司作为中间加工环节议价能力极弱，导致焦炭毛利率为负，卖得越多亏得越多。尽管公司通过出售资产和股权融资暂时缓解了流动性危机，但这是以牺牲未来产能和投资收益为代价的“断臂求生”，不可持续。

更深层的风险在于**财务结构恶化与在建项目的不确定性**。公司期末货币资金仅10.07亿元，其中受限资金高达9.90亿元，而短期有息负债（短期借款+一年内到期非流动负债）高达32.37亿元，短期偿债压力巨大。同时，公司寄予厚望的阳霞矿业（原煤120万吨/年）预计2026年6月才试生产，且存在业绩承诺（累计净利润不低于3.63亿元），若项目延期或投产不及预期，将无法弥补主业亏损，公司可能面临更严重的流动性危机。
