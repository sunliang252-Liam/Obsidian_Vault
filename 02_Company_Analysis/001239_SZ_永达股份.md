# 001239.SZ 深度透视

## 因果逻辑链
- **[收购金源装备并表]** -> [营收暴增140%，但净利润下降40%]: 2024年10月收购的金源装备在2025年贡献全年收入，推动总营收从8.49亿跃升至20.40亿；但高额的并购整合成本、财务费用及资产减值，导致归母净利润反而从7908万降至4753万。
- **[风电行业高景气]** -> [风电业务收入占比跃升至73.85%]: 受益于“双碳”目标及海上风电大兆瓦机型放量，公司风电结构件及锻件收入从4.17亿暴增至15.06亿，成为绝对收入支柱。
- **[金源装备旧厂拆迁]** -> [非经常性收益掩盖主业疲软]: 子公司旧厂区拆迁完成，确认资产处置收益约3849万元，占利润总额的32.68%，扣非后净利润仅2314万元，同比下滑43.91%，揭示核心盈利能力恶化。
- **[隧道掘进业务萎缩]** -> [传统优势业务大幅下滑]: 隧道掘进结构件收入从1.97亿骤降至0.67亿，同比降幅65.93%，主要因下游客户需求下滑，公司传统优势领域承压。
- **[财务费用激增]** -> [高杠杆侵蚀利润]: 为收购金源装备及补充营运资金，公司借款增加，财务费用从1207万翻倍至2239万，增幅85.47%，显著拖累净利润。
- **[存货与应收账款高企]** -> [营运资金压力巨大]: 存货增至8.37亿，应收账款8.37亿，合计占总资产41.7%，且存货周转放缓，计提减值损失3003万元，现金流风险突出。

## 风险警告
**核心风险在于“增收不增利”与“并购后遗症”的叠加。** 公司通过收购金源装备实现了营收规模的跨越式增长，但净利润却反向大幅下滑，扣非净利润更是腰斩。这暴露出并购整合成本高昂、财务杠杆急剧攀升（长期借款增至7.17亿）以及资产减值损失扩大等问题。若金源装备未来业绩承诺不达预期，商誉减值风险将直接冲击利润表。

**第二大风险是业务结构失衡与客户集中度。** 公司收入高度依赖风电行业（占比73.85%），且前五大客户销售额占比高达64.28%，其中单一客户占比近44%。风电行业政策周期波动及主要客户订单变化，将直接导致公司业绩剧烈震荡。同时，传统优势的隧道掘进业务大幅萎缩，显示公司缺乏新的增长引擎来对冲单一行业风险。
