# 300777.SZ 深度透视

## 因果逻辑链
- **[航空航天高端碳纤维核心供应商地位]** -> [营收增长4.14%]: 公司深度绑定航空航天型号，主力产品ZT7系列稳定批量供货，但受价格调整影响，营收增速放缓。
- **[产品结构向高附加值织物倾斜]** -> [织物收入增长54.60%]: 公司主动调整产品结构，碳纤维织物收入占比从32%提升至47.57%，拉动整体毛利率提升1.73个百分点。
- **[研发投入大幅增加37%]** -> [净利润下降11.65%]: 为突破T1100级、高模ZM40X等关键技术，研发费用增至1.18亿元，叠加产品价格因素，导致增收不增利。
- **[客户付款方式变更]** -> [经营现金流暴增342%]: 四季度客户付款由航信转为电汇，回款现金大幅增加，经营活动现金流净额达8.8亿元，远超净利润。
- **[引入战略投资者中石化资本]** -> [治理结构优化]: 中石化资本持股5.09%，带来产业链协同资源，公司完成董事会换届，进入无实控人状态下的新发展阶段。
- **[四期项目建设推进]** -> [在建工程增加98%]: 年产2000吨高性能碳纤维项目投入建设，在建工程增至6.15亿元，为未来产能扩张奠定基础。
- **[向下游结构功能材料延伸]** -> [设立常宏功能材料]: 出资9000万元设立子公司，切入预浸料及功能材料领域，从材料供应商向系统解决方案提供商转型。
- **[终止股权激励+启动员工持股]** -> [绑定核心团队]: 终止2022年限制性股票激励计划，推出2025年员工持股计划，以0.80%的股份覆盖103名核心骨干，建立长效激励机制。

## 风险警告
**核心风险在于“增收不增利”的盈利质量恶化趋势。** 营收增长4.14%的同时，净利润却下降11.65%，主因是产品价格承压和研发费用激增。更值得警惕的是，公司对个别待安装设备计提了1707万元的资产减值，且内控审计报告指出存在“少量账外资金入账不及时”的重要缺陷，这暴露了公司在高速扩张期的管理漏洞。若产品价格持续下行或新产能消化不及预期，毛利率将进一步承压。

**客户高度集中与股权分散构成双重脆弱性。** 前五大客户销售占比高达99.42%，其中单一客户A占比87.49%，这种极度依赖单一客户的模式，使公司经营业绩极易受该客户采购计划波动的影响。同时，公司处于无实际控制人状态，第一大股东仅持股8.71%，虽然引入了中石化资本，但股权结构依然分散。历史上董事温月芳多次对多项议案提出反对意见，内部治理的稳定性存在隐忧，一旦股东间出现重大分歧，可能影响公司战略执行的连贯性。

> 中简科技股份有限公司是专业从事高性能碳纤维及相关产品研发、生产、销售和技术服务的高新技术企业,是具有完全自主知识产权的国产高性能碳纤维及相关产品研发制造商,具备高强型ZT7系列(高于T700级)、ZT8系列(T800级)、ZT9系列(T1000/T1100级)和高模型ZM40J(M40J级)石墨纤维工程产业化能力,并已成为国内航空航天领域ZT7系列(高于T700级)碳纤维产品的批量稳定供应商。公司经过长期自主研发并生产的国产ZT7系列(高于T700级)碳纤维产品打破了发达国家对宇航级碳纤维的技术装备封锁,各项技术指标达到国际同类型产品先进水平,经过严格的产品验证,已被批量稳定应用于我国航空航天八大型号,优先满足了国家战略需求,实现军民深度融合。公司自成立以来,始终坚持以“技术领先,专注应用,技术向纵深发展,应用向纵横发展”为战略目标,致力于建设国产可定制、柔性化、智能化生产线在技术等级、盈利能力、应用水平和装备水平等方面,具备较强的国际竞争力。
