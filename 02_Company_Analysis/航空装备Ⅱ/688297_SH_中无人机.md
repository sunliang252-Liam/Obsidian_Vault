# 688297.SH 深度透视

## 因果逻辑链
- **[产品交付量激增]** -> [营收暴增340%]: 公司紧抓国内外市场需求，产品交付数量显著增长，驱动营收从6.85亿跃升至30.16亿。
- **[营收规模效应显现]** -> [扭亏为盈]: 营收大幅增长覆盖了固定成本，叠加部分研发项目进入资本化阶段，使净利润从-5392万转为8857万。
- **[研发投入资本化]** -> [利润质量改善]: 部分研发项目达到资本化条件，费用化研发投入减少29.69%，直接增厚当期利润，但需关注资本化率从22%升至56%的合理性。
- **[客户回款周期调整]** -> [现金流急剧恶化]: 尽管营收大增，但客户回款安排调整导致经营性现金流净额从+1.4亿骤降至-13.88亿，现金循环周期拉长。
- **[存货持续高企]** -> [资金占用压力]: 为保障后续交付，存货规模维持在27.9亿高位，叠加应收账款激增至27.5亿，对流动资金形成巨大占用。
- **[产品交付结构变化]** -> [毛利率大幅下滑]: 不同市场（国内/军贸）交付占比变化，导致整体毛利率从32.04%骤降至11.23%，盈利能力承压。
- **[军贸与国内双轮驱动]** -> [市场地位巩固]: 翼龙系列出口十余国，国内应急、气象等民用场景持续突破，形成“国内国际双循环”格局。
- **[“一总部、一基地、多中心”布局成型]** -> [产能与协同效应释放]: 年产200架无人机能力基本形成，产业创新中心投用，为规模化交付提供基础。

## 风险警告
**核心风险在于“增收不增利”与“现金流枯竭”的背离。** 营收暴增340%但毛利率骤降20个百分点至11.23%，净利润率仅2.9%，显示产品结构向低毛利市场倾斜或成本控制失效。更严重的是，经营性现金流净流出高达13.88亿，与利润严重倒挂，应收账款和存货合计超55亿，占流动资产的绝大部分，公司实际造血能力堪忧，高度依赖外部融资或股东支持。

**技术迭代与市场竞争风险不容忽视。** 军用无人机领域，美、以等国技术领先，国内竞争加剧；民用领域，低空经济政策驱动下，大量企业涌入。公司若不能在智能化、协同化等关键技术领域保持领先，现有产品优势可能被快速超越。同时，民用适航取证进展缓慢，可能制约其在低空经济市场的拓展速度。
