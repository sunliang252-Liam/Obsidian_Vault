# 603261.SH 深度透视

## 因果逻辑链
- **[军品审价大幅调减]** -> [净利润巨亏]: 以往年度已确认收入的产品被军方审价调减，冲减本期营业收入1.12亿元，直接导致净利润减少约9624万元，是亏损主因。
- **[营收增长但成本失控]** -> [毛利率暴跌至-24%]: 营业收入同比增长18.89%至3.45亿元，但营业成本同比激增57.25%，导致整体毛利率由正转负，从约6%骤降至-24.06%。
- **[大额资产减值与信用减值]** -> [利润进一步承压]: 计提资产减值损失5835万元及信用减值损失889万元，合计约6725万元，反映出存货和应收账款质量恶化。
- **[核心产品毛利率崩塌]** -> [业务结构恶化]: 占营收52%的“飞机地面保障设备及工艺装备”毛利率从11.4%暴跌至-49.18%，成本增速（94.59%）远超收入增速（15.64%），成为亏损重灾区。
- **[经营活动现金流转正]** -> [造血能力边际改善]: 尽管巨额亏损，但经营活动现金流净额由负转正至361万元，主要得益于销售回款增加，显示运营层面有所好转。
- **[大客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比高达76.81%，对航空工业集团下属单位依赖度极高，客户需求波动将直接冲击公司业绩。
- **[董事长被留置]** -> [治理风险暴露]: 报告期内，公司实际控制人、董事长刘随阳被监察机关立案调查并实施留置，虽已解除，但暴露了公司治理层面的重大不确定性风险。

## 风险警告
公司面临的核心风险是**军品审价机制带来的业绩剧烈波动**。2025年因审价调减导致巨额亏损，且未来仍有大量按暂定价确认收入的项目，一旦最终审定价大幅低于暂定价，将再次引发业绩“爆雷”。这种非经营性、不可预测的利润侵蚀，使公司基本面难以评估，投资者面临巨大的“黑天鹅”风险。

其次，**主营业务已陷入严重亏损状态**。剔除审价影响后，公司毛利率仍为负值，核心产品“飞机地面保障设备”成本失控，表明公司缺乏成本转嫁能力和定价权。连续三年亏损且亏损额逐年扩大，净资产已从8.16亿缩水至5.12亿，若无法在短期内实现盈利反转，公司持续经营能力将面临重大挑战。
