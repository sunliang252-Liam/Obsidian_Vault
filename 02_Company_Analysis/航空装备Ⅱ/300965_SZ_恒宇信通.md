# 300965.SZ 深度透视

## 因果逻辑链
- **[信用减值损失大幅减少]** -> [净利润增长34.87%]: 2025年信用减值损失较上年减少1417万元，是净利润增长的核心驱动力，而非主营业务的显著改善。
- **[技术服务收入爆发式增长]** -> [营收结构优化]: 技术服务收入同比增长96.82%，占比从10.78%提升至19.05%，成为第二大收入来源，但毛利率骤降57.56个百分点至11.29%，显示该业务盈利能力较弱。
- **[高可靠性专用电子模块放量]** -> [产品多元化]: 该模块收入同比增长34.68%，销量增长48.66%，表明公司正从核心显控产品向模块化、标准化产品拓展，但毛利率下降19.91个百分点，竞争加剧或成本上升。
- **[经营活动现金流大幅转正]** -> [现金流改善]: 经营活动现金流净额从-3616万元大幅转正至6193万元，主要系销售回款增加，改善了公司现金流状况，降低了财务风险。
- **[研发投入持续高企]** -> [技术壁垒构建]: 研发投入占营收比例高达29.65%，且全部费用化，显示公司为维持技术领先地位和拓展新业务（如低空经济）进行高强度投入，短期压制利润。
- **[客户高度集中]** -> [经营风险集中]: 前五大客户销售额占比高达98.51%，其中航空工业集团下属单位占73.26%，公司业绩高度依赖单一客户群体，议价能力和抗风险能力较弱。
- **[募投项目多次延期]** -> [产能扩张不及预期]: 核心募投项目“新一代航电系统设备产业化建设项目”已多次延期至2027年底，且部分资金被变更用于低空经济等新项目，显示原定产能扩张计划受阻。

## 风险警告
公司最大的风险在于**业绩增长高度依赖非经常性损益和信用减值损失的转回，而非主营业务的强劲增长**。2025年净利润增长34.87%，但扣非净利润仅增长40.54%，且绝对值仍较低（2086万元）。同时，技术服务收入虽爆发式增长，但毛利率骤降，表明该业务可能以低价策略换取规模，盈利能力存疑。若未来信用减值损失恢复常态，公司业绩将面临显著下滑压力。

其次，**客户集中度极高（前五客户占比98.51%）和军品审价的不确定性构成核心经营风险**。公司深度绑定航空工业集团，议价能力弱，且军品审价机制可能导致已确认收入被追溯调整，对利润造成冲击。此外，募投项目多次延期、研发投入全部费用化且转化效率不明，均指向公司未来增长路径存在较大不确定性，新业务（如低空经济）能否成为第二增长曲线尚待验证。
