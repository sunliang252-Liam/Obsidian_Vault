# 605123.SH 深度透视

## 因果逻辑链
- **[风电订单放量]** -> [营收增长10.28%]: 电力用锻件收入同比增长25.37%，成为营收增长的核心驱动力，但毛利率仅提升1.55个百分点，增量不增利。
- **[原材料成本上涨]** -> [毛利率下降3.53个百分点]: 直接材料成本同比上升20.70%，远超营收增速，导致主营业务毛利率从20.06%降至16.53%，利润空间被严重挤压。
- **[航空航天业务结构恶化]** -> [毛利率骤降9.64个百分点]: 航空航天用锻件收入增长7.60%，但成本激增23.36%，毛利率从34.16%跌至24.52%，高毛利业务盈利能力显著下滑。
- **[长账龄存货增加]** -> [资产减值损失扩大31.63%]: 计提资产减值损失3973万元，主要源于长账龄存货积压，反映部分下游需求疲软或订单交付延迟。
- **[汇兑收益增加]** -> [财务费用大幅下降]: 财务费用为-3748万元，同比减少282.65%，主要受益于人民币贬值带来的汇兑收益，对利润形成正向支撑。
- **[政府补助大幅增加]** -> [非经常性损益贡献利润]: 其他收益（主要为政府补助）同比增长96.96%至5804万元，是扣非净利润同比下降13.13%而净利润仅下降4.37%的主要原因。
- **[募投项目持续转固]** -> [固定资产与在建工程双增]: 固定资产同比增长30.34%，在建工程同比增长73.75%，表明公司正处于产能扩张期，未来折旧压力将显著增加。

## 风险警告
**核心风险在于“增收不增利”的结构性恶化。** 公司营收增长10.28%，但扣非净利润却下降13.13%，主因是成本端失控。直接材料成本增速（20.70%）远超营收增速，叠加航空航天高毛利业务毛利率骤降近10个百分点，表明公司对上游原材料涨价和下游客户议价的能力均较弱。若原材料价格持续高位，利润将进一步被侵蚀。

**产能扩张带来的折旧与减值风险不容忽视。** 公司固定资产和在建工程合计超20亿元，募投项目陆续转固将带来大量折旧。同时，存货同比增长20.78%，且长账龄存货导致的资产减值损失已扩大至3973万元。若风电、石化等下游需求不及预期，产能利用率不足将导致资产减值风险加剧，进一步拖累利润。
