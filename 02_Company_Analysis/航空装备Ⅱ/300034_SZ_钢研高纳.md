# 300034.SZ 深度透视

## 因果逻辑链
- **航空航天产业快速发展** -> 高端和新型高温合金需求增加: 航空航天发动机热端部件对高温合金的需求占比高（40%-60%），装备自主保障要求推动国产替代。
- **燃气轮机与核电产业发展** -> 高温合金需求增加: 新型电力系统建设和双碳目标加速燃气轮机本土化，核电复兴拉动国产高温合金需求。
- **“一带一路”战略机遇** -> 高温合金需求增加: 新兴国家基础设施建设带动石化、冶金等基础工业产品出口，从而带动高温合金需求。
- **研发投入与技术突破** -> 核心竞争力提升: 公司持续研发投入（7.41%营收），在粉末高温合金、3D打印、Ti2AlNb合金等关键技术取得突破，增强技术壁垒。
- **行业地位与客户关系** -> 市场拓展与收入增长: 作为中国航发战略供应商及国内高温合金品种最齐全企业之一，稳定客户关系推动收入增长（同比+4.91%）。
- **原材料价格波动** -> 毛利率下降: 镍、铬、钴等原材料占成本约60-70%，价格上涨直接挤压利润空间，导致毛利率下降（整体毛利率23.77%，同比下降7.89个百分点）。
- **产品阶梯降价要求** -> 毛利率下降: 批产阶段客户要求阶梯降价，新订单价格降低影响利润，而成本下降空间有限，导致毛利率承压。
- **国外市场拓展** -> 收入增长与毛利率压力: 国外营业收入同比增长50.53%，但毛利率仅为42.11%，低于国内（尽管国外毛利率较高，但成本增长更快导致毛利率同比下降8.65个百分点），拉低整体毛利率。
- **存货与资产减值** -> 净利润波动: 计提存货等资产减值6235万元（占利润总额-25.49%），直接减少净利润，使得净利润增幅低于收入增幅。
- **组织变革与员工优化** -> 运营效率提升: 2025年策划组织变革及员工结构优化，直接创造价值员工占比及素质提升，助力降本增效，管理费用率下降（7.66% vs 7.58%）。
- **定向增发与现金流改善** -> 资本结构与投资能力优化: 定向增发收到现金2.75亿元，经营活动现金流净额大幅提升（3.74亿元，同比+2246%），增强公司资本实力和抗风险能力。

## 风险警告
公司面临原材料价格波动（镍、铬、钴成本占比高，波动大）和产品阶梯降价的双重毛利率压力，2025年整体毛利率下滑至23.77%（同比降7.89pct）。此外，存货和资产减值达6235万元，占利润总额25.49%，对净利润侵蚀明显。航空航天产业依赖度高（60%以上收入来自该领域），行业政策波动可能影响业绩。同时，市场竞争加剧、技术外泄或核心人员流失风险亦需关注。

> 北京钢研高纳科技股份有限公司成立于2002年11月8日,2009年12月在深圳证券交易所创业板上市,成为创业板第二批上市企业之一。2018年8月入选国企改革“双百行动”企业名单。公司及其前身钢铁研究总院高温材料研究室,是我国高温合金领域的缔造者之一,拥有雄厚的技术储备和强大的研发实力。公司先后通过了ISO9001质量管理体系、AS9100质量管理体系、环境管理体系、职业健康安全管理体系等多项认证。钢研高纳聚焦服务国家战略需求,已形成北京为总部的“七市十厂”产业布局。公司承担着国家多项重点型号亟需金属材料的研发攻关任务,着力解决关键核心材料“卡脖子”问题,现主要从事高温合金、铝镁钛轻质合金、耐蚀合金和金属间化合物等高端金属材料的研发、生产和销售,产品广泛用于航空、航天、舰船、核电、燃气轮机、石化、冶金建材等行业,制备工艺涵盖精密铸造、模锻与环轧、粉末冶金、精细制造、机械合金化、离心铸造、增材制造、盘轴零件精密加工等领域,是推动国家高温合金领域重要战略使命任务落地的“主力军”“国家队”。公司始终坚持“以客户为中心”的经营理念,致力于成为世界一流的高端装备制造业所需金属新材料与制品供应商,全面助力高端装备新材料产业的高质量发展。公司控股股东中国钢研科技集团有限公司,是国务院国资委直接管理的的重点大型科技企业,是我国金属新材料及冶金领域实力最强的综合性研发机构和产业化基地、重大关键与共性技术的创新基地、国家冶金分析测试技术的权威机构,拥有两院院士9人、2个一级学科博士学位授权点和5个一级学科硕士学位授权点,为钢研高纳的后续发展提供了强有力的后盾。
