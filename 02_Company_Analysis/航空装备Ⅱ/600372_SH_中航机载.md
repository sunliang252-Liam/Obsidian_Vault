# 600372.SH 深度透视

## 因果逻辑链
- **[航空防务装备交付与保障]** -> [营收微增1.39%]: 公司作为航空机载系统“链主”，完成“十四五”收官交付，但受制于军品定价周期和供应链长，收入增长缓慢。
- **[汽车座椅等民品业务放量]** -> [汽车制造业收入增长35.48%]: 子公司精机科技等抓住新能源汽车配套机遇，汽车座椅调节装置等产品大规模配套，成为第二增长曲线。
- **[财务费用激增99.23%]** -> [利润总额增长10.77%但扣非净利润仅增5.91%]: 借款增加及利息收入减少导致财务费用翻倍，侵蚀了主业利润，使得利润增长远低于收入增长。
- **[经营活动现金流由负转正]** -> [现金流净额2.83亿元]: 公司加强回款管理，经营性现金流较上年同期大幅改善22.71亿元，缓解了现金流压力。
- **[研发投入维持高位]** -> [研发费用占营收11.36%]: 公司持续投入航空机载核心技术研发，以保持技术领先和应对“无人区”挑战，但短期内对利润形成压力。
- **[客户高度集中]** -> [前五大客户销售占比67.65%]: 公司严重依赖航空工业集团及其下属单位，其中单一客户占比超53%，议价能力受限，应收账款高企。
- **[募投项目持续投入]** -> [在建工程增长34.83%]: 公司利用募集资金推进航空引气、液压作动等产能提升项目，为未来产能扩张奠定基础，但项目多次延期。

## 风险警告
**核心风险在于“大而不强”的盈利困境与高度依赖单一客户的脆弱性。** 公司营收242亿，但扣非净利润仅8.8亿，净利率不足4%。财务费用因借款激增而翻倍，严重侵蚀利润。更关键的是，公司超过53%的收入来自同一最终控制方，这种“单一大客户”模式导致公司在定价、回款上缺乏主动权，应收账款高达249亿，占营收比例超100%，现金流虽有改善但依然紧绷。

**另一大风险是募投项目多次延期与内部治理的隐忧。** 多个核心产能提升项目（如航空引气、液压作动系统）的预定可使用状态日期被推迟至2026年底甚至2027年，表明产能扩张不及预期。同时，公司董事长、总会计师等核心高管在报告期内频繁变动，且多名董事因“公务原因”缺席董事会，这增加了战略执行的不确定性，也反映出国企治理中可能存在的效率问题。
