# 000738.SZ 深度透视

## 因果逻辑链
- **[产品价税改革]** -> [营收下降5.64%，净利润暴跌55.43%]: 核心主业航空发动机控制系统产品因价税改革导致收入确认减少，而成本刚性（人工、折旧）未同步下降，毛利率大幅压缩，利润弹性被严重侵蚀。
- **[客户高度集中]** -> [业绩高度依赖单一集团]: 前五大客户销售占比90.30%，其中中国航发系统内单位占77.22%，客户集中度极高，议价能力弱，任何客户采购政策或定价调整都将直接冲击公司业绩。
- **[销售回款改善]** -> [经营现金流大幅转正]: 尽管利润下滑，但公司加强催收，销售商品收到的现金同比增加14.73亿元，经营活动现金流净额从-2.62亿元大幅改善至9.44亿元，现金流质量显著优于利润表现。
- **[研发投入资本化率为零]** -> [当期利润未因研发而虚增]: 公司研发投入5.16亿元（占营收9.99%），全部费用化处理，无资本化，表明会计处理谨慎，但高额研发投入持续压制短期利润。
- **[存货跌价准备增加]** -> [资产减值损失扩大]: 计提存货跌价准备增加，导致资产减值损失同比上升16.01%，反映部分产品可能面临技术迭代或订单变更带来的减值风险。
- **[利息收入下降与汇兑损失增加]** -> [财务费用大幅上升]: 财务费用从-8069万元升至-2465万元，主要因利息收入下降及汇兑损失增加，表明公司资金管理效率下降或面临汇率波动风险。
- **[募投项目接近尾声]** -> [资本开支高峰已过]: 2021年非公开发行募投项目累计投入进度达85.63%，投资活动现金流出减少，未来折旧压力有望逐步稳定。

## 风险警告
**核心风险：定价权缺失与利润塌方。** 2025年净利润暴跌55.43%，直接原因是“产品价税改革”，这本质上暴露了公司作为军工配套企业，在产业链中议价能力极弱。客户高度集中于中国航发系统（销售占比77%），公司缺乏自主定价权，任何政策性价格调整都将直接转化为利润的剧烈波动。这种“增收不增利”甚至“减收更减利”的脆弱盈利模式，是投资该公司的最大不确定性。

**次要风险：高研发投入与低资本化率的持续压制。** 公司研发投入占营收近10%，且全部费用化，这虽然体现了会计的谨慎性，但也意味着每年数亿元的利润被直接吞噬。在价税改革导致毛利率下滑的背景下，研发费用的刚性支出将进一步压缩利润空间。若未来技术转化不及预期，高额的沉没成本将长期拖累净资产收益率（ROE已从6.21%降至2.70%）。
