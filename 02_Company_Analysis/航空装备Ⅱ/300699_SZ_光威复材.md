# 300699.SZ 深度透视

## 因果逻辑链
- **[风电碳梁业务爆发]** -> [营收增长16.72%]: 碳梁收入同比+75.84%，成为最大增量引擎，抵消了碳纤维板块增速放缓的影响。
- **[T800级碳纤维量产放量]** -> [碳纤维业务稳健]: 新型号应用扩大，成为碳纤维板块核心驱动力，弥补了气瓶等业务下滑。
- **[包头基地拖累业绩]** -> [净利润下降18.59%]: 内蒙古光威因市场竞争及开工不足亏损1.75亿元，严重侵蚀利润。
- **[航空业务收入下降]** -> [业务结构优化]: 航空收入占比降至38.46%，对单一军品依赖度降低，新能源（风电）占比升至37.86%。
- **[研发投入持续加大]** -> [高端产品储备]: 研发费用2.20亿元（+27.10%），T1100级、T1200级等高端碳纤维研制推进，巩固技术护城河。
- **[原辅料票据支付增加]** -> [经营现金流大增50%]: 经营活动现金流净额达12.95亿元，远高于净利润，现金流质量优异。
- **[碳梁客户结构优化]** -> [抗风险能力提升]: 新客户批产放量，客户集中度风险降低，业务发展态势良好。
- **[全产业链协同优势]** -> [综合解决方案能力]: 从原丝到复材制品全布局，增强了客户粘性和成本控制能力。

## 风险警告
**核心风险在于“增收不增利”的结构性矛盾。** 营收增长16.72%的同时，净利润却下滑18.59%，主因是子公司内蒙古光威亏损1.75亿元。该基地作为公司民品产能扩张的关键，其开工不足和市场竞争加剧，直接拖累了整体盈利水平。若该基地产能利用率无法提升，将持续成为利润黑洞。

**另一大风险是军品业务的波动性与民品价格战的双重挤压。** 航空业务收入同比下降6.18%，且军品订单具有不可预见性和年度执行率不确定性，易造成业绩季度间大幅波动。同时，民品领域（尤其是工业级碳纤维和碳梁）面临激烈的价格竞争，产品售价存在持续下降风险，将直接压缩毛利率。公司需在“保军”与“拓民”之间找到更优的平衡点。
