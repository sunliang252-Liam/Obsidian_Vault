# 000697.SZ 深度透视

## 因果逻辑链
- **[核心客户空客订单增长]** -> [营收增长7.08%]: 全球航空业复苏，空客交付量提升，带动Gardner收入增至17.23亿英镑。
- **[营业成本增速超过收入]** -> [毛利率大幅下滑]: 原材料、人工成本分别增长12.05%和10.07%，导致商用航空部件毛利率从6.19%骤降至3.09%。
- **[商誉减值与递延所得税资产减记]** -> [净利润巨亏5.18亿]: 计提商誉减值及减记递延所得税资产合计约2.26亿元，是亏损扩大的主因。
- **[破产重整完成]** -> [资产负债率大幅下降]: 通过债转股和引入重整投资人，负债从33.06亿降至12.57亿，净资产从1亿暴增至33.44亿。
- **[重整投资人注资]** -> [现金流大幅改善]: 收到12.38亿元重整投资款，货币资金从1.13亿激增至13.60亿，短期偿债风险解除。
- **[成都航宇进入放量期]** -> [国内业务高速增长]: 国内收入增长31.77%，成都航宇营收增长27.07%，成为新的增长极。
- **[Gardner持续亏损]** -> [核心子公司拖累整体业绩]: 尽管营收增长，但成本控制不力及减值，Gardner净亏损扩大至2.16亿英镑。

## 风险警告
**核心风险在于“止血”与“造血”的赛跑。** 公司虽通过破产重整实现“轻装上阵”，但核心子公司Gardner的盈利能力并未改善，反而因成本失控和商誉减值导致亏损加剧。2025年Gardner净亏损高达2.16亿英镑，是公司整体亏损的绝对主力。若无法通过涨价谈判、成本转移等措施扭转Gardner的亏损局面，重整带来的财务改善将只是“一次性”的，公司仍将面临持续亏损的风险。

**单一客户依赖与汇率波动是悬在头顶的达摩克利斯之剑。** 公司61.29%的收入来自空客，客户集中度极高，任何空客减产或更换供应商的行为都将对公司造成毁灭性打击。同时，公司主要业务在境外，英镑、欧元等汇率波动不仅影响Gardner的汇兑损益，还会在合并报表时产生巨大的外币折算差额，2025年汇率变动对现金的影响就高达-5566万元，加剧了业绩的不确定性。
