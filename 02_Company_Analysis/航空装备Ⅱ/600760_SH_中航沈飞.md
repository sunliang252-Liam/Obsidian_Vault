## 因果逻辑链
- **[国防采购计划]** -> [营收增长4.25%]: 公司核心收入来自特定用户的航空防务装备订单，需求刚性，但增速受限于国家军费预算和装备列装节奏。
- **[产品结构升级与转代更迭]** -> [毛利率提升1.23个百分点]: 新型号装备（如舰载机）占比提升，其技术附加值更高，带动航空制造业整体毛利率改善。
- **[研发投入激增50.80%]** -> [压制短期利润释放]: 为应对“新一代装备”技术突破和产品迭代，公司大幅增加费用化研发投入，是净利润增速（3.65%）低于营收增速（4.25%）的主因。
- **[应收账款激增55.22%]** -> [经营活动现金流持续为负]: 客户（特定用户）回款周期长，导致应收账款规模远超营收增速，占压大量营运资金，是现金流长期为负的根本原因。
- **[供应链高度集中]** -> [成本控制与交付风险并存]: 前五名供应商采购额占比74.48%，且46.27%来自关联方（航空工业集团内部），议价能力受限，且单一环节断供将影响整机交付。
- **[沈飞新厂区建设]** -> [资本开支与产能扩张预期]: 局部搬迁项目进入实质建设阶段，在建工程同比大增123.23%，预示未来产能瓶颈有望缓解，但短期带来折旧和资金压力。
- **[定增募资40亿元]** -> [优化资本结构，支撑产业布局]: 成功向特定对象发行股票，补充流动资金并投向沈飞搬迁、复合材料/钛合金产线及飞机维修项目，为“十五五”产能扩张和维修业务“第二曲线”奠定基础。
- **[股权激励解锁]** -> [绑定核心团队，激发经营活力]: 第二期限制性股票激励计划第一个解锁期达成，将管理层利益与公司长期市值和业绩增长深度绑定。

## 风险警告
**核心风险在于现金流与客户依赖。** 公司经营活动现金流净额连续三年为负（2025年-22.86亿元），根本原因是应收账款（38.51%的总资产占比）和合同资产（7.09%）高企，回款严重依赖单一特定用户。这种“高利润、低现金”的财务结构，在军费增速放缓或装备采购付款节奏调整时，将直接冲击公司运营效率和分红能力。

**另一大风险是供应链“卡脖子”与成本刚性。** 公司对航空工业集团内部供应商的采购依赖度极高（占采购总额46.27%），且主要原材料价格受国家规定，成本端缺乏弹性。若上游核心部件（如发动机、机载系统）交付延迟或涨价，将直接导致公司生产计划受阻、毛利率承压。同时，研发费用（+50.80%）和管理费用（+14.53%）的刚性增长，将持续侵蚀利润空间。
