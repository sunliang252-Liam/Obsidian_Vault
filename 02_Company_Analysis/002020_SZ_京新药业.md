# 002020.SZ 深度透视

## 因果逻辑链
- **集中采购模式下，与关键原材料及设备供应商签订长期协议** -> 供应链连续性与稳定性增强，成本可控: 长期协议确保关键物资供应稳定，降低采购风险与成本波动
- **原料药-制剂一体化产业链** -> 成本优势与市场竞争力: 原料药自产为制剂提供稳定低价原料，同时带动原料药销售，形成协同
- **创新药地达西尼纳入医保目录** -> 创新药商业化加速，销售额增长: 医保准入降低患者支付门槛，促进医院覆盖和处方量提升
- **成品药内销模式调整为经销为主（经销占比从40.87%升至66.21%）** -> 成品药收入同比下降2.11%，但扣非净利润增长10.06%: 经销模式下渠道下沉与费用管控优化，以价换量初显成效，利润弹性释放
- **研发聚焦精神神经与心脑血管领域，多管线推进** -> 创新药梯队形成，持续贡献未来收入: 前瞻布局填补临床空白，差异化品种获批/申报NDA，支撑长期增长
- **原料药板块工艺优化与成本管控** -> 原料药收入下降7.09%但毛利率提升: 通过工艺优化、成本管控应对行业下行，维持盈利水平
- **医疗器械子公司深圳巨烽通过FDA现场检查** -> 拓展国际大客户，收入稳健增长: 国际质量认证增强客户信任，深化与GE、飞利浦等合作，争取项目创新高
- **销售费用同比下降13.21%** -> 归母净利润同比增6.46%: 费用管控直接提升利润水平

## 风险警告
深度风险总结：1. 行业政策风险：带量采购深化、医保控费持续，核心仿制药面临降价压力，可能压缩利润空间。2. 研发风险：创新药研发周期长、投入大，存在临床失败或上市后销售不及预期风险。3. 环保风险：原料药生产受环保监管趋严，合规成本上升。4. 汇兑风险：财务费用中汇兑损失增加，海外业务受汇率波动影响。5. 人才风险：创新转型需要高端人才，储备不足可能制约发展。
