# 600848.SH 深度透视

## 因果逻辑链
- **[园区销售收入大幅下滑]** -> [营收同比下降29.66%]: 面对经济周期调整和行业环境变化，产业客户投资审慎、交易周期拉长，导致园区物业销售去化困难，收入从112.85亿骤降至79.37亿。
- **[“由重转轻”战略转型]** -> [扣非净利润同比下降28.32%]: 公司主动降低重资产开发速度，控制销售节奏，导致短期利润承压；同时，运营服务和产业投资等轻资产收入尚未完全弥补销售缺口。
- **[土地收储回笼资金]** -> [经营性现金流显著改善]: 配合政府完成地块收储，回笼资金约26.25亿元，使经营性现金流净额从-49亿大幅收窄至-9.5亿，缓解了现金流压力。
- **[REITs扩募盘活存量]** -> [资产周转效率提升]: 将康桥园区资产注入REITs平台，实现资产出表，获得投资收益并回笼资金，优化了资产结构，为后续轻资产运营奠定基础。
- **[产业投资与基金布局]** -> [投资收益成为利润重要补充]: 通过参与人工智能母基金、直投壁仞科技等，公允价值变动及投资收益达8822万元，对冲了部分主业下滑压力，强化了“产业+投资”双轮驱动。
- **[融资成本优化]** -> [财务费用控制有效]: 综合融资成本降至2.99%，低于行业平均，在债务规模扩大的背景下，财务费用同比仅微降2.68%，有效支撑了大规模开发与投资。
- **[园区租赁业务稳健]** -> [收入基本盘稳定]: 租赁收入29.08亿元，同比仅下降4.35%，毛利率高达63.36%，成为公司业绩的“压舱石”，体现了成熟园区资产的抗周期能力。

## 风险警告
**核心风险在于转型阵痛与资产减值。** 公司正从重资产销售向轻资产运营服务转型，但园区销售收入骤降40.49%，是业绩下滑的直接原因。若宏观经济持续低迷，产业客户投资意愿恢复不及预期，园区销售去化将进一步承压，可能导致存货（账面价值38.8亿）和投资性房地产（账面价值51.6亿）面临减值风险，侵蚀利润。

**财务杠杆高企与现金流压力不容忽视。** 公司资产负债率已升至66.96%，有息负债总额达382亿元，且一年内到期的非流动负债激增107%至54.89亿元，短期偿债压力巨大。尽管经营性现金流有所改善，但依然为负，表明主业造血能力尚未恢复，高度依赖融资和资产处置维持流动性，存在一定的资金链风险。
