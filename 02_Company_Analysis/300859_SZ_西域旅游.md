# 300859.SZ 深度透视

## 因果逻辑链
- **[核心景区特许经营权垄断]** -> [营收增长7.32%]: 依托天山天池景区道路、索道、湖面30年独家经营权，旅游客运、索道、游船三大核心业务贡献88.5%营收，构成业绩基本盘。
- **[新项目投入期拖累利润]** -> [净利润下降13.68%]: “遇见喀什”、“遇见赛湖”两大沉浸式演艺项目2025年投入运营，新增折旧摊销及贷款利息，导致营业成本中固定费用同比暴增78.21%，财务费用飙升380.72%。
- **[旅游客运业务成本刚性]** -> [毛利率承压]: 客运收入仅增1.52%，但直接人工成本增5.41%，折旧摊销增16.03%，显示该业务已进入成熟期，成本刚性增长侵蚀利润空间。
- **[沉浸式演艺开辟第二曲线]** -> [收入结构多元化]: 沉浸式演艺业务从零起步，贡献营收1397万元（占比4.29%），标志着公司从单一景区交通服务商向文旅内容运营商转型。
- **[季节性波动显著]** -> [现金流集中释放]: 第三季度营收1.73亿元（占全年53%），经营现金流1.15亿元，而Q1和Q4均为亏损，反映天山天池景区旅游旺季高度集中于暑期。
- **[债转股优化资本结构]** -> [降低财务风险]: 以债转股方式向古海温泉、演艺公司增资合计9950万元，将债权转为股权，降低子公司负债率，改善合并报表资产负债结构。
- **[关联采购集中度高]** -> [供应链依赖风险]: 向关联方北京昱鉴采购“遇见喀什”项目设备及创编导服务2304万元，占年度采购总额19.03%，存在单一供应商依赖及关联交易定价公允性风险。

## 风险警告
**核心风险在于新项目盈利不及预期与成本刚性上涨的双重挤压。** 2025年营收增长7.32%，但净利润反降13.68%，主因“遇见喀什”、“遇见赛湖”两大沉浸式演艺项目尚处爬坡期，新增折旧摊销（固定费用同比+78%）和贷款利息（财务费用+381%）直接吞噬利润。若新项目客流培育慢于预期，将导致资产回报率持续走低，拖累整体ROE。

**业务高度集中于天山天池单一景区，且受季节性波动影响极大。** 公司核心收入（客运、索道、游船）均依赖天池景区特许经营权，Q3单季贡献全年53%营收，Q1和Q4均为亏损。一旦出现极端天气、疫情反复或景区政策调整等不可抗力，业绩将剧烈波动。同时，与北京昱鉴的关联采购占比近20%，存在供应链集中风险及潜在利益输送争议。
