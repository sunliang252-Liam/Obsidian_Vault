# 603090.SH 深度透视

## 因果逻辑链
- **[热管理核心业务增长]** -> [净利润同比+66.91%]: 换热器及热管理系统收入增长7.78%，叠加产品结构优化与规模效应，驱动利润弹性远超收入增速。
- **[产品模块化与“铝代铜”创新]** -> [新能源及数据中心业务放量]: 针对风电、大型柴油发电机组等赛道开发高效轻量化方案，实现批量供货，开辟第二增长曲线。
- **[海外产能布局落地]** -> [北美工厂投运、欧洲工厂接近完工]: 贴近市场布局降低贸易风险与物流成本，提升海外响应速度，为国际业务扩张奠定基础。
- **[联营企业投资收益大增]** -> [投资收益同比+2843%]: 参股公司和宏智贡献显著利润，成为非经常性损益外的利润补充。
- **[信用与资产减值损失大幅减少]** -> [利润增厚约1400万元]: 坏账准备与存货跌价计提同比显著下降，反映资产质量改善与风险出清。
- **[锂电池PACK业务主动收缩]** -> [营收同比-3.21%，亏损收窄]: 战略性优化业务结构，聚焦工商业与动力储能，逐步向盈亏平衡靠拢。
- **[远期结汇合约公允价值变动]** -> [公允价值变动收益+263万元]: 有效管理汇率风险，对冲部分海外收入因人民币波动带来的潜在损失。

## 风险警告
**核心风险在于海外业务的高度依赖与国际化扩张的短期阵痛。** 公司境外收入占比约60%，且北美、欧洲工厂尚处投运初期，北美子公司报告期内亏损1140万元。若主要出口地经济放缓、贸易摩擦升级（如关税壁垒），或海外工厂产能爬坡不及预期，将直接冲击营收与利润。同时，铝材占成本约50%，铝价大幅上涨而无法有效传导时，毛利率将承压。

**新业务拓展与内部治理结构变动构成潜在不确定性。** 公司正全力切入数据中心液冷、储能热管理等高增长赛道，但面临技术迭代快、客户认证周期长、竞争激烈的挑战。此外，报告期内公司取消监事会、调整多名核心高管（总经理、副总经理、董事），治理结构处于过渡期，需关注内部管理协同与战略执行稳定性。
