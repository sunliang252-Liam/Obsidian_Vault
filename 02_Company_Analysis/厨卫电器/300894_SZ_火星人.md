# 300894.SZ 深度透视

## 因果逻辑链
- **[房地产深度调整]** -> [营收暴跌44%]: 集成灶作为前装产品，与新房交付高度绑定，新房销售面积同比下降9.2%，直接导致公司集成灶业务订单锐减。
- **[费用刚性 + 收入骤降]** -> [净利润巨亏2.96亿]: 公司为维持品牌声量和市场份额，销售费用率被动攀升；同时人力成本维持高位，收入下滑时费用无法同比例削减，导致利润被严重侵蚀。
- **[行业竞争加剧 + 渠道分流]** -> [线下收入降幅大于线上]: 传统建材市场流量被京东Mall、抖音等新兴渠道分流，而公司加盟商多为家庭式运营，转型能力弱，导致线下收入同比下滑45.83%，高于线上的40.71%。
- **[品牌升级与品类拓展]** -> [战略转型对冲单一品类风险]: 公司从“火星人集成灶”更名为“火星人集成厨电”，推出“空间魔法师”套系，试图从单一集成灶向全场景厨电解决方案转型，以摆脱对单一品类的依赖。
- **[研发投入逆势加码]** -> [技术壁垒持续加固]: 在营收下滑44%的背景下，研发费用率提升至10.55%，推出“无界平台”和M80系列，强化智能化和模块化技术优势，为行业复苏储备产品力。
- **[现金流由正转负]** -> [经营造血能力严重受损]: 经营活动现金流净额为-2.01亿元，系销售回款大幅减少所致，公司虽持有3.85亿现金储备，但若亏损持续，流动性压力将逐步显现。

## 风险警告
**核心风险：房地产下行周期与费用刚性形成的“剪刀差”困境。** 公司营收高度依赖新房交付，而房地产深度调整短期难见拐点。与此同时，为维持高端品牌定位和市场份额，销售、管理、研发等费用难以大幅削减，导致收入降幅远超成本降幅，形成巨额亏损。若行业需求持续低迷，公司可能面临“增收无望、减费困难”的持续失血局面。

**次要风险：战略转型的不确定性与现金流压力。** 公司从“集成灶”向“集成厨电”的战略升级，虽方向正确，但需要大量资金投入品牌建设、渠道拓展和新品研发。在主营业务亏损、经营现金流为负的背景下，若新业务无法快速贡献利润，将加速消耗公司有限的现金储备（3.85亿），并可能引发可转债（“火星转债”）的转股压力或回售风险。
