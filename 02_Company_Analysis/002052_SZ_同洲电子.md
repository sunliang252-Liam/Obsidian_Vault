# 002052.SZ 深度透视

## 因果逻辑链
- **[电源产品出口爆发]** -> [营收增长15.27%]: 电源产品收入6.12亿元，占营收88.62%，同比增长29.07%，成为唯一增长引擎，完全依赖单一业务。
- **[高毛利电源业务占比提升]** -> [净利润暴增158.90%]: 电源产品毛利率43.35%，远高于其他业务，其占比从79%升至89%，结构性拉高整体盈利水平。
- **[新能源与ICT业务大幅萎缩]** -> [拖累整体表现]: 电池产品收入下降46%，机顶盒收入下降87%，传统业务基本停滞，公司转型为纯电源企业。
- **[前五大客户高度集中]** -> [经营风险极高]: 前五大客户销售额占88.62%，全部为电源业务客户，公司对少数大客户形成严重依赖。
- **[经营活动现金流为负]** -> [盈利质量存疑]: 净利润1.8亿，但经营现金流为-987万，主因支付上期大额采购款，利润增长未转化为现金。
- **[公允价值变动大幅亏损]** -> [侵蚀利润]: 其他非流动金融资产公允价值变动损失2555万元，占利润总额14.57%，非主业投资拖累业绩。
- **[子公司停产]** -> [新能源业务崩溃]: 电池生产工厂自2024年三季度停产，2025年未恢复，导致新能源业务产销量暴跌超90%。

## 风险警告
**单一业务依赖与客户集中风险**：公司已从多元化电子企业蜕变为纯电源出口商，电源产品贡献88.6%营收，且前五大客户（均为电源客户）集中度高达88.62%。一旦主要客户流失或电源行业需求波动，公司将遭受毁灭性打击，缺乏任何业务缓冲。

**现金流枯竭与资产质量恶化**：尽管账面净利润暴增，但经营活动现金流净额为负，盈利质量极差。同时，总资产从12.4亿骤降至5.58亿（-55%），应收账款从4.56亿降至0.49亿（收回后未形成新业务），存货从2.27亿降至0.21亿（出售后未补货），显示公司业务规模在急剧收缩，而非扩张。大量资产被冻结或受限（投资性房地产、金融资产等），流动性风险极高。
