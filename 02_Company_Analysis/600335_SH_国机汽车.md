# 600335.SH 深度透视

## 因果逻辑链
- **[汽车工程海外业务扩张]** -> [利润增长]: 海外新签合同额占比超40%，带动工程业务收入增长14.46%，成为利润核心支柱。
- **[汽车流通业务主动收缩]** -> [营收下降但毛利率提升]: 主动压缩低毛利进口车贸易规模，营收降29.33%，但毛利率提升1.47个百分点，实现“以退为进”。
- **[汽车租赁业务规模扩张]** -> [收入与现金流双增]: 车辆购置规模增加，收入增长24.14%，同时处置旧车回笼现金，支撑经营现金流大增82%。
- **[财务费用大幅缩减]** -> [利润增厚]: 票据贴现费用减少及汇兑收益增加，财务费用从1.14亿降至0.22亿，直接贡献利润弹性。
- **[信用减值损失转回]** -> [利润增厚]: 应收账款减值损失同比减少，信用减值损失从-1.21亿转为+0.41亿，显著改善利润表。
- **[央企平台与全链布局]** -> [抗周期能力]: 工程、流通、租赁三大业务形成对冲，进口车市场收缩时，工程和出口业务弥补缺口，维持整体盈利稳定。
- **[高分红与股份回购]** -> [市值管理]: 分红比例提升至归母净利润的39.71%，并首次实施股份回购，强化投资者回报预期。

## 风险警告
**最大风险在于参股公司国机智骏的破产重整不确定性。** 公司已对其全额计提减值，但重整进程多次延期，若最终重整失败，可能产生额外的资产处置损失或连带责任，对利润表造成一次性冲击。这是公司当前最明确的“黑天鹅”事件。

**第二大风险是汽车流通业务的长期结构性萎缩。** 进口车市场受国产新能源挤压，年销量已同比下滑32.4%，公司虽主动收缩规模，但该业务收入仍占总营收过半。若进口车市场持续萎缩，且出口及国产业务无法快速弥补缺口，公司营收规模可能进一步承压，增长天花板明显。
