# 002891.SZ 深度透视

## 因果逻辑链
- **[自主品牌高速增长]** -> [营收结构优化]: 境内收入同比增长32.44%，直销模式收入暴增65.27%，主粮收入增长40.39%，显示品牌溢价能力提升。
- **[销售费用激增]** -> [净利润下滑]: 销售费用同比增长42.09%至7.03亿元，远超营收增速，导致归母净利润同比下降7.28%，增收不增利。
- **[全球化产能布局]** -> [抗风险能力增强]: 在美、加、墨、柬、新6国设厂，有效对冲中美贸易摩擦关税风险，保障海外供应链稳定。
- **[代工业务稳健]** -> [业绩基本盘稳固]: OEM/ODM收入28.75亿元，同比增长9.9%，毛利率微增0.39%，海外大客户粘性强，提供稳定现金流。
- **[研发投入加大]** -> [产品力提升]: 研发费用同比增长45.30%至1.06亿元，推动鲜肉粮、烘焙粮等高端新品迭代，支撑品牌高端化战略。
- **[原材料价格波动]** -> [成本控制压力]: 鸡肉等主要原料成本占比较高，虽建立战略储备制度，但价格传导存在滞后，短期毛利率承压。
- **[可转债转股]** -> [股本扩张与财务结构改善]: 报告期内“中宠转2”大量转股，总股本增加，同时降低负债率，但稀释每股收益。

## 风险警告
**核心风险在于“增收不增利”的恶性循环。** 公司为抢占国内自主品牌市场，销售费用率飙升至13.5%，远超营收增速，直接侵蚀利润。若品牌竞争持续白热化，费用投入无法有效转化为市场份额与复购率，净利润可能进一步承压。同时，宠物主粮毛利率同比微降0.45%，显示价格战已波及核心品类。

**外部风险高度集中。** 公司境外收入占比仍高达64%，中美贸易摩擦升级将直接冲击OEM业务。尽管有海外工厂对冲，但关税成本与供应链调整压力不可忽视。此外，鸡肉等原材料价格波动剧烈，若进入上行周期，将严重挤压本已微薄的利润空间。
