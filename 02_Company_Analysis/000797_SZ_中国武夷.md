# 000797.SZ 深度透视

## 因果逻辑链
- **[房地产项目毛利率大幅下滑]** -> [净利润巨亏4.5亿元]: 房地产业务毛利率同比骤降13.51个百分点，收入增长但利润被侵蚀，是亏损主因。
- **[计提大额资产及信用减值损失]** -> [净利润转负]: 基于市场状况，对地产项目计提存货减值3.42亿元，叠加应收账款坏账0.75亿元，合计4.17亿元，直接吞噬利润。
- **[国际工程新签合同额创历史新高]** -> [未来收入增长潜力]: 新签合同额43.69亿元，同比大增62.84%，为未来工程承包业务收入提供强劲储备。
- **[房地产项目结转导致合同负债骤降]** -> [当期收入确认]: 合同负债从21.86亿元降至6.65亿元，降幅69.57%，表明大量预售房完成交付并确认为收入。
- **[经营活动现金流净额转正]** -> [现金流改善]: 通过加大存量房产去化回笼资金，经营性现金流从-0.48亿元大幅转正至4.48亿元，缓解了资金压力。
- **[财务费用大幅增长]** -> [侵蚀利润]: 地产项目相继竣工，借款利息停止资本化，导致财务费用同比增加45.87%，进一步加重了亏损。
- **[商业贸易业务收入萎缩]** -> [收入结构变化]: 贸易业务收入同比下降31.15%，占比从27.71%降至18.18%，显示该板块增长乏力。

## 风险警告
公司2025年由盈转亏，核心风险在于其房地产业务的深度调整。尽管营收增长，但毛利率大幅下滑，叠加对存货和应收款的大额减值计提，导致净利润巨亏4.5亿元。这表明公司核心资产（尤其是北京、福建等地的房地产项目）面临严峻的市场价格下行和去化压力，资产质量存在持续恶化的风险。未来若房地产市场未能企稳，公司可能面临进一步的减值压力。

此外，公司国际工程业务虽新签合同额创新高，但海外经营环境复杂，地缘政治冲突、汇率波动及部分项目回款不及预期，导致信用减值损失增加。同时，公司资产负债率高企，短期偿债压力较大（一年内到期非流动负债激增81.85%），财务费用因利息资本化停止而大幅攀升，对现金流和盈利能力构成持续挑战。
