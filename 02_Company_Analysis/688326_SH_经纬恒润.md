# 688326.SH 深度透视

## 因果逻辑链
- **[前期高强度研发投入成果释放]** -> [净利润扭亏为盈]: 2025年归母净利润10,024万元，较上年同期增长6.5亿元，核心驱动力来自域控制器、智能驾驶等前期研发投入的产品进入量产放量阶段。
- **[域控制器等新产品阵营收入快速放量]** -> [营收增长23.59%]: 电子产品业务收入同比增长31.17%，ZCU产品累计出货超200万套，成为收入增长的核心引擎。
- **[AI工具应用与精细化管理降本]** -> [研发费用率下降6.91个百分点]: 研发费用同比下降20.20%，研发费用率从22.36%降至15.45%，AI赋能研发效率提升是费用控制的关键。
- **[规模效应显现与产品结构优化]** -> [毛利率提升1.78个百分点]: 电子产品业务毛利率提升2.52个百分点，带动整体毛利率改善，盈利能力修复。
- **[销售回款增加]** -> [经营现金流由负转正]: 经营活动现金流量净额从-5.38亿元转为0.55亿元，现金流状况显著改善，经营质量提升。
- **[多业务协同布局]** -> [场景化解决方案能力增强]: 智能运输、大总成及特种载具等新业务在智慧港口、无人运输等场景实现突破，形成“车-路-网-云-图”一体化交付优势。
- **[海外市场拓展与属地化服务]** -> [国际客户群体扩大]: 海外收入同比增长24.05%，客户覆盖Stellantis、Scania、大众、丰田等，全球化布局加速。

## 风险警告
**客户集中度与供应链依赖风险**：公司前五大客户收入占比超50%，客户集中度较高，若主要客户战略调整或订单转移，将对业绩产生重大不利影响。同时，公司产品生产依赖车规级芯片等关键元器件，供应链紧张或价格波动可能影响交付进度与成本控制，国产替代进程存在不确定性。

**技术迭代与竞争加剧风险**：汽车电子行业技术路线迭代快，智能驾驶、域控制器等赛道竞争激烈，价格战与技术竞赛并行。公司需持续高研发投入以保持技术领先，若研发方向失误或产品竞争力下降，可能面临市场份额流失与盈利能力承压的风险。此外，公司存货中合同履约成本占比高（45.32%），项目验收周期长，存在跌价风险。
