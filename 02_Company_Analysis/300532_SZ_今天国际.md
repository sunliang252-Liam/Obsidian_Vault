# 300532.SZ 深度透视

## 因果逻辑链
- **[行业竞争加剧]** -> [毛利率持续下滑]: 2023-2025年综合毛利率从27.39%降至24.36%，因原材料、薪酬、投标竞争及低毛利项目占比增加。
- **[新能源行业订单爆发]** -> [新增订单大幅增长]: 2025年新增订单36.46亿元，同比增长43.64%，主要得益于新能源头部企业信赖，但收入确认滞后。
- **[大项目收入确认波动]** -> [季度业绩剧烈波动]: 单个项目金额高、周期长，导致Q3营收仅2.97亿，而Q1、Q2均超7亿，季度间业绩极不稳定。
- **[分阶段收款模式]** -> [应收账款高企]: 项目终验后仍有20-30%款项待收，加上质保金，导致应收账款（含合同资产）占总资产28.82%，回收周期长。
- **[海外市场拓展]** -> [海外收入激增]: 2025年海外收入7257万元，同比增长31,784%，得益于海外订单落地，但基数极低，尚处起步阶段。
- **[研发投入资本化率为零]** -> [利润质量较高]: 研发投入全部费用化，2025年研发费用1.49亿元，占营收6.33%，无资本化粉饰利润。
- **[股权激励实施完毕]** -> [核心团队利益绑定]: 2021年限制性股票激励计划全部归属完毕，管理层与股东利益深度绑定，激发内生动力。

## 风险警告
**核心风险在于毛利率的持续下行与经营业绩的剧烈波动。** 公司综合毛利率已从2023年的27.39%下滑至2025年的24.36%，且年报明确指出行业竞争加剧及低毛利项目占比增加将导致毛利率进一步承压。同时，公司项目制业务模式导致季度间收入确认极不均衡，2025年第三季度营收仅2.97亿元，而第一、二季度均超7亿元，投资者难以基于单季度业绩判断全年趋势。

**另一重大风险是控股股东邵健伟被立案留置，控制权变更悬而未决。** 自2023年10月被福建省三明市监察委员会留置以来，邵健伟至今未恢复自由。公司虽已推出协议转让暨控制权变更方案，但截至年报披露日仍在推进中，这一重大不确定性事件对公司治理、战略执行及市场信心构成持续压制。此外，应收账款（含合同资产）余额高达13.83亿元，占总资产近29%，尽管客户多为知名企业，但账期延长和坏账风险不可忽视。
