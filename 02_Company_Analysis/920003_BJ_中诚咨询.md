# 920003.BJ 深度透视

## 因果逻辑链
- **[国内固定资产投资规模下降]** -> [营收与净利润下滑]: 2025年全国固定资产投资下降3.8%，江苏省下降12.7%，直接导致公司营收同比-6.61%，净利润-3.70%。
- **[业务高度集中于江苏省内]** -> [区域经济下行风险敞口大]: 省内收入占比98.09%，江苏省固定资产投资大幅下滑12.7%，公司业绩与单一区域经济周期深度绑定。
- **[数字化转型投入]** -> [毛利率逆势提升]: 研发投入占营收4.68%，数字化系统（造价、监理、BIM）提升效率与质量，推动综合毛利率从46.39%提升至49.59%。
- **[应收账款高企与坏账计提增加]** -> [侵蚀利润]: 应收账款账面价值2.02亿元，占营收54.70%，信用减值损失同比增加29.31%，成为利润的主要拖累项。
- **[北交所上市募资]** -> [资产结构优化与扩张弹药储备]: 募资净额1.73亿元，总资产增长41.18%，净资产增长75.44%，为全国化网点建设和研发信息化提供资金。
- **[关联交易依赖]** -> [收入稳定性存疑]: 前两大客户均为关联方（苏州元脉、苏高新集团），合计贡献营收15.83%，业务独立性及可持续性需关注。
- **[工程监理及管理业务增长]** -> [业务结构优化]: 该板块营收同比增长21.35%，成为对冲造价业务下滑（-13.17%）的主要力量，体现全过程咨询战略初步成效。

## 风险警告
**核心风险在于区域经济依赖与应收账款回收。** 公司98%收入来自江苏省，而该省2025年固投下降12.7%，业绩与区域经济周期高度共振。更严峻的是，应收账款高达2.02亿元（占营收55%），且账龄老化导致坏账计提同比大增29%，若地方政府或关联方客户付款能力恶化，将直接冲击现金流与利润。

**第二重风险是关联交易集中与扩张不确定性。** 前两大客户均为关联方（合计占营收15.8%），业务真实性及定价公允性需持续审视。公司计划用1.07亿募资全国化扩张，但省外收入仅占1.9%，且面临地方保护、人才不足等挑战，并购整合亦存难度，募投项目存在不及预期风险。
