# 002671.SZ 深度透视

## 因果逻辑链
- **[收购南通阀门]** -> [营收增长27%，但归母净利润下降28%]: 收购南电阀门贡献2.4亿营收和2632万净利润，但PCCP主业利润下滑及大额资产减值（-8917万）拖累整体盈利。
- **[PCCP订单释放]** -> [建材收入增长13%]: 依托前期大型引水工程订单储备，PCCP管道业务实现业绩释放，但分子公司间分化严重（江苏龙泉亏损2229万）。
- **[金属管件业务萎缩]** -> [收入下降31%]: 石化领域需求低迷，新峰管业营收1.06亿，净利润亏损1815万，非核领域竞争力不足。
- **[大额资产减值]** -> [侵蚀利润]: 计提商誉、固定资产、合同资产等减值损失8917万元，占利润总额的99%，是净利润下滑的核心原因。
- **[现金流大幅改善]** -> [经营净现金流增长163%]: 加大应收账款清收力度，回款增加，经营活动现金流净额达3.28亿元，远超净利润。
- **[客户集中度高]** -> [经营波动风险]: 前五大客户销售占比62.34%，最大客户占26%，业绩高度依赖大型水利工程项目的释放节奏。
- **[母公司巨额亏损]** -> [无法分红]: 母公司净利润-2.03亿元，合并报表未分配利润-3.14亿元，连续亏损导致无法实施现金分红。

## 风险警告
**核心风险在于资产质量恶化与主业盈利能力的结构性下滑。** 公司2025年净利润表面增长，但扣非净利润同比暴跌45%，主要依赖收购南电阀门的并表贡献。更严重的是，公司计提了高达8917万元的资产减值损失，其中商誉减值风险尤为突出——账面仍有1.09亿商誉，若新峰管业等子公司持续亏损，减值压力将进一步爆发。母公司层面亏损2.03亿元，合并报表未分配利润为-3.14亿元，表明核心PCCP业务造血能力不足。

**业务结构失衡与客户依赖构成第二重风险。** PCCP业务收入占比75%，但分子公司严重分化，江苏龙泉、淄博龙泉等多家子公司亏损。金属管件业务收入下滑31%，新峰管业竞争力下滑。同时，前五大客户销售占比超62%，业绩高度依赖大型水利项目的招标节奏和施工进度，一旦项目延迟或竞争加剧，订单获取将面临重大不确定性。公司虽通过收购切入电站阀门赛道，但火电市场持续性存疑，第二增长曲线尚未稳固。
