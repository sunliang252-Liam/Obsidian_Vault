# 300649.SZ 深度透视

## 因果逻辑链
- **[行业周期下行与地方财政收紧]** -> [营收与利润双降]: 全国园林绿化投资总额2024年同比下降33.17%，公司订单规模萎缩，2025年营收同比下滑32.25%，归母净利润连续第二年亏损。
- **[EPC业务收缩]** -> [收入结构恶化]: 工程总承包业务收入同比暴跌70.55%，占营收比重从20%降至8.7%，公司被迫退回设计主业，增长引擎熄火。
- **[政府客户结算滞后]** -> [应收账款与合同资产高企]: 截至2025年末，应收账款+合同资产合计占总资产46.47%，地方政府财政预算紧张导致回款周期拉长，坏账风险持续累积。
- **[参股公司经营不及预期]** -> [长期股权投资减值]: 基于谨慎性原则，对部分参股公司计提长期股权投资减值准备，成为拖累当期利润的重要因素之一。
- **[经营活动现金流大幅转负]** -> [流动性承压]: 经营活动现金流净额从2024年的+7177万元骤降至2025年的-1.12亿元，主要系收款与付款时间差，公司被迫新增4930万元短期借款以补充流动性。
- **[多元化探索尚在早期]** -> [新业务未形成规模]: 公司布局AI研究中心、城市更新、酒店运营（曼俪酒店、悦庭居）、酒旅抖音代运营（信志源文化）等，但新业务体量极小，尚无法对冲主业下滑。
- **[核心设计人才流失]** -> [研发能力削弱]: 研发人员数量从49人降至39人，同比下降20.41%，研发投入同比减少35.03%，长期可能侵蚀公司核心设计竞争力。

## 风险警告
公司面临的核心风险是**行业景气度与地方财政的双重挤压**。中国城镇化进入存量提质阶段，园林绿化投资总额已连续两年大幅下滑，公司主要客户为地方政府及平台，其支付能力受制于财政预算与债务约束。这导致公司营收持续萎缩、应收账款与合同资产合计近4亿元且回收缓慢，经营活动现金流已大幅转负，公司不得不举债经营，流动性压力显著。

其次，**战略转型存在高度不确定性**。公司试图通过AI、城市更新、酒店运营、抖音代运营等多元化业务寻找第二增长曲线，但这些新业务与主业协同性有限，且均处于极早期投入阶段，尚未贡献实质性利润。同时，公司因信息披露、内控等问题被浙江证监局出具警示函，暴露出内部治理短板，在转型期可能放大经营风险。
