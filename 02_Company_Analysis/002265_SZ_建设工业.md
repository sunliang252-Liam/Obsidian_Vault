# 002265.SZ 深度透视

## 因果逻辑链
- **[军品订单交付]** -> [营收增长3.57%]: 特品科研生产任务高质量完成，驱动主营业务收入增长4.02%。
- **[扣非净利润增长]** -> [盈利能力改善]: 剔除2024年医保政策调整的非经常性损益影响后，核心经营利润同比增长10.23%。
- **[研发投入加大]** -> [新域新质装备突破]: 研发费用同比增长20.92%，推动无人化、智能化装备研发取得标志性进展。
- **[汽车零部件销量增长]** -> [民品业务稳定]: 汽车零部件销量同比增长16.30%，支撑民品板块基本盘。
- **[军贸业务增长]** -> [境外收入提升]: 境外收入同比增长37.53%，军贸出口处于窗口期，成为新增长点。
- **[应收账款质押融资]** -> [现金流压力]: 应收账款质押规模达12.58亿元，反映回款周期长，经营活动现金流承压。
- **[投资活动现金流出增加]** -> [资产配置调整]: 增加定期存款投资，导致投资活动现金流净额减少88.06%。

## 风险警告
**核心风险在于军品业务的高集中度与回款不确定性。** 前五大客户销售占比高达48.02%，其中第一大客户占比29.27%，客户集中度极高，单一客户订单波动将直接冲击业绩。同时，公司大量应收账款（12.58亿元）被用于质押融资，表明军品回款周期长，现金流对运营的支撑存在潜在压力。

**重组与转型的不确定性是另一大隐患。** 控股股东兵器装备集团正在进行分立重组，其汽车业务板块将剥离，这可能导致公司未来战略协同、资源支持等方面出现变数。此外，公司向新能源汽车零部件、低空经济等战略性新兴产业的转型尚处早期，新能源电机轴等新业务营收占比还较小，新增长极的培育存在失败风险。
