# 603568.SH 深度透视

## 因果逻辑链
- **[设备订单执行节奏波动]** -> [营收与利润双降]: 2025年设备、EPC及服务收入同比骤降43.44%，导致总营收下降13.04%，归母净利润下降18.14%，核心原因是订单交付进度不达预期。
- **[环保项目稳健运营]** -> [业绩基本盘稳固]: 项目运营收入同比增长8.21%，毛利率提升至62.53%，垃圾入库量、上网电量等核心运营指标持续增长，为公司提供了稳定的现金流和利润基石。
- **[印尼高冰镍项目投产]** -> [开辟第二增长曲线]: 嘉曼公司年产4万吨冰镍项目一期投产并实现5.29亿元营收，标志着公司从环保向新能源材料领域的战略转型取得实质性突破。
- **[经营活动现金流大幅改善]** -> [财务质量提升]: 经营性现金流净额同比增长32.57%至32.22亿元，主要得益于运营收入现金流入增加及采购支出减少，显示出核心业务造血能力强劲。
- **[高分红与转增]** -> [强化股东回报]: 拟每股派现0.60元并每10股转增2股，现金分红比例高达46.36%，彰显公司对股东回报的重视及对未来发展的信心。
- **[装备制造获新订单]** -> [未来收入蓄力]: 新增设备订单总额约46.35亿元，并拓展重要战略客户，为2026年及以后的设备收入恢复增长提供了订单储备。
- **[新材料业务亏损]** -> [短期拖累整体盈利]: 新材料产品毛利率仅15.84%，远低于运营业务，且伟明盛青公司（未并表）仍在产能爬坡期，对整体盈利能力和ROE形成拖累。

## 风险警告
公司面临的核心风险在于新材料业务的不确定性。印尼高冰镍项目及国内锂电池材料项目均处于产能爬坡初期，面临工艺技术、原材料价格波动、海外运营及地缘政治等多重挑战。该业务目前毛利率较低，若未来镍价或锂电材料价格持续低迷，或产能释放不及预期，将显著拖累公司整体盈利水平，并可能引发资产减值风险。

此外，公司传统环保业务虽稳健，但行业已进入成熟期，国内新增项目减少、国补退坡是长期趋势。公司未来增长高度依赖海外市场拓展（如印尼巴厘岛项目）和存量项目提效，但海外项目面临技术标准、文化差异及政策变动等风险。同时，公司实际控制人持股比例较高，存在一定的治理风险，需关注其决策对中小股东利益的影响。
