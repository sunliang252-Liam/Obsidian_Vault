# 301056.SZ 深度透视

## 因果逻辑链
- **[房地产下行与新增需求承压]** -> [营收下降22.38%]: 传统商品房配套新梯需求下滑，公司国内收入同比减少26.35%，拖累整体业绩。
- **[存量市场与海外市场对冲]** -> [利润降幅小于营收]: 海外收入仅降10.07%，毛利率高达45.57%；旧梯更新、加装等存量业务部分弥补了新梯缺口。
- **[直销模式收缩]** -> [直销收入骤降50.06%]: 公司主动调整销售结构，减少高风险直销项目，转向更稳健的经销商模式（经销收入仅降5.83%）。
- **[智慧工厂与精益生产]** -> [毛利率基本稳定]: 尽管营收下滑，但通过智能制造降本增效，电梯行业整体毛利率仅微降0.14个百分点至32.72%。
- **[高毛利海外业务支撑]** -> [净利润率提升]: 海外业务占比提升至25.92%，其高毛利特征（45.57%）有效缓冲了国内低毛利业务下滑对利润率的冲击。
- **[现金流优于净利润]** -> [经营现金流净额9,656万]: 公司加强回款管理，经营活动现金流净额显著高于净利润（7,494万），财务质量稳健。
- **[政策红利驱动]** -> [存量业务成增长点]: 《住宅项目规范》强制4层及以上装电梯、超长期特别国债支持老旧电梯更新，为公司打开新增长空间。

## 风险警告
**核心风险在于对房地产周期的深度依赖与转型阵痛。** 公司2025年营收与净利润双降超22%，直接原因是国内新梯市场受房地产深度调整拖累。尽管海外和存量业务有所对冲，但直销收入腰斩（-50.06%）表明公司正主动收缩高风险业务，这一结构调整期将持续压制短期业绩。若国内房地产市场复苏不及预期，公司营收可能进一步承压。

**另一重大风险是原材料成本与应收账款坏账的叠加。** 材料成本占整梯生产成本90%，钢材等价格波动将直接侵蚀利润。同时，下游客户（尤其是房地产公司）回款周期长，公司应收账款余额高达1.33亿元，已计提坏账准备4,411万元。若经济环境恶化导致客户违约，将产生大额信用减值损失，对净利润造成重大冲击。
