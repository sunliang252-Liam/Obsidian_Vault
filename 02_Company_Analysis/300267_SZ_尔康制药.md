# 300267.SZ 深度透视

## 因果逻辑链
- **[新能源材料业务爆发]** -> [营收结构质变]: 新能源板块营收同比增长2034.56%，占比从0.88%跃升至18.29%，成为第二增长曲线，对冲了传统医药业务的萎缩。
- **[产能利用率不足引发巨额减值]** -> [连续三年巨亏]: 基于谨慎性原则，对低效资产和存货计提3.58亿元减值损失，导致归母净利润亏损3.80亿元，连续第三年亏损。
- **[成品药业务大幅收缩]** -> [营收结构恶化]: 成品药营收同比下降58.88%，中成药销量锐减，拖累整体医药业务收入下滑16.98%，传统业务承压。
- **[辅料业务稳中有升]** -> [核心主业韧性]: 辅料业务营收7.55亿元，毛利率提升2.73个百分点，依托127个品种和3000+客户，在行业调整中保持基本盘稳定。
- **[非洲市场战略布局]** -> [未来增长预期]: 在坦桑尼亚和尼日利亚投资建设制剂生产项目，瞄准当地缺医少药的市场空白，旨在开辟新的海外增长极。
- **[经营活动现金流大幅改善]** -> [财务安全垫增厚]: 经营活动现金流净额同比增长54.59%至2.58亿元，现金充裕，资产负债率低，为业务转型和海外扩张提供资金保障。

## 风险警告
公司连续三年巨额亏损，核心原因并非经营恶化，而是对历史投资形成的过剩产能进行“财务洗澡”。2025年计提3.58亿元资产减值，表明公司过去在柬埔寨等地的产能扩张已沦为沉重负担，短期内难以恢复。虽然新能源业务和非洲项目带来新希望，但前者尚处产能爬坡期，后者仍在建设阶段，均无法快速弥补传统业务的失血。

公司面临的核心风险是战略转型的“青黄不接”。传统医药主业（成品药）大幅下滑，新业务（新能源）虽增长迅猛但体量尚小，且高度依赖海外锂矿资源，面临地缘政治、汇率波动和原材料价格三重风险。此外，控股股东帅放文几乎全部股份（97.8%）已被质押，若股价持续低迷，可能引发控制权不稳的连锁反应。
