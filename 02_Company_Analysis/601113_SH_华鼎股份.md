# 601113.SH 深度透视

## 因果逻辑链
- **锦纶行业产能扩张，常规产品同质化竞争加剧** -> 锦纶板块产品市场均价下行: 供给端扩产导致供需宽松，压低产品价格
- **上游原材料价格波动** -> 锦纶板块产品价格同步下行: 切片等原料价格下降，传导至下游产品降价
- **锦纶板块产品价格下行** -> 营业收入同比减少37.16%: 量价齐跌导致营收下滑
- **完成跨境电商板块处置** -> 营业收入同比减少37.16%: 剥离非核心业务，合并范围减少，营收规模收缩
- **锦纶板块产品价格下行** -> 归属上市公司股东净利润同比减少54.26%: 营收下降叠加毛利下滑，导致利润大幅减少
- **行业产能扩张，常规产品同质化竞争加剧** -> 公司锦纶丝库存量同比增加63.43%: 供给过剩而需求增速放缓，导致库存积压
- **公司锦纶丝库存量同比增加63.43%** -> 存货减值损失增加: 库存积压导致计提存货跌价准备增加
- **下游需求增速放缓，行业开工率波动** -> 公司产销量同比小幅下降: 需求不足导致销售减少，生产相应调整
- **控股股东增持股权（真爱集团及一致行动人持股比例从15.81%提升至25.08%）** -> 公司治理效能提升: 股权集中有利于战略引领和决策效率
- **公司投资建设20万吨PA6功能性锦纶长丝项目** -> 未来高端产能提升，市场占有率有望扩大: 产能扩张为未来业绩增长奠定基础
- **公司拟向真爱集团定增募集不超过7.075亿元用于年产6.5万吨高品质差别化锦纶PA6长丝项目** -> 资本结构优化，增强财务稳健性: 股权融资降低杠杆，补充发展资金

## 风险警告
锦纶行业产能过剩导致常规产品价格竞争激烈，公司虽为头部企业但仍面临毛利率下滑风险；原材料价格波动直接影响公司盈利能力；库存高企可能进一步挤压现金流，且存货减值风险加大。
