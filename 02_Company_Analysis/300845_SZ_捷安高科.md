# 300845.SZ 深度透视

## 因果逻辑链
- **[政策驱动职业教育投资]** -> [营收依赖政策周期]: 公司下游客户（院校、铁路局）的采购预算受国家职业教育经费（如“提升计划资金”年均增长8.9%）和“新双高”政策直接驱动，导致业绩与政策节点高度关联。
- **[客户预算制度导致季节性]** -> [Q4收入占比极高]: 客户（院校、国企）遵循“年初预算、年底验收”的流程，导致2025年Q4单季收入2.03亿元，占全年56.4%，而Q1仅0.25亿元，上半年亏损。
- **[行业竞争加剧与项目延迟]** -> [营收与利润双降]: 2025年营收同比下降6.41%，归母净利润同比下降26.70%。核心原因是市场竞争激烈导致低价抢单，以及部分中标项目交付延后至Q4，未能确认收入。
- **[核心业务轨道交通承压]** -> [增长依赖新业务]: 核心产品“轨道交通仿真实训系统”收入同比下降11.45%，而“安全作业仿真实训”和“船舶装备”业务分别增长16.23%和7.67%，显示公司正通过“同心多元”战略寻找新增长点。
- **[研发投入资本化]** -> [短期利润粉饰]: 2025年首次将研发支出资本化（4,179,588元，占净利润10.08%），若剔除该影响，扣非净利润降幅更大（-29.64%），暗示公司通过会计手段平滑利润。
- **[应收账款高企与回款放缓]** -> [现金流恶化]: 经营活动现金流净额同比下降43.65%，远低于净利润。应收账款余额高达2.25亿元，且账龄拉长，客户回款周期受宏观和流程影响，构成核心财务风险。
- **[AI+职业教育政策红利]** -> [未来增长预期]: 国家“人工智能+”、“技能照亮前程”等政策明确支持虚拟仿真实训和AI考评，公司已布局“AI职教平台”和“AI智能考试系统”，有望受益于行业数字化转型。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收下滑6.41%，但净利润暴跌26.70%，扣非净利润降幅接近30%。更危险的是，经营活动现金流净额骤降43.65%至3084万元，远低于4027万元的净利润。这直接指向应收账款回收困难——2.25亿的应收账款和1.72亿的存货，占用了大量资金，客户（院校、国企）的预算审批流程拉长正在侵蚀公司的造血能力。

**竞争加剧与研发资本化构成双重隐患。** 行业竞争导致毛利率承压，公司被迫通过“AI+实物设备”等创新维持竞争力，但研发投入资本化（首次出现）可能是在粉饰短期业绩。此外，收入高度集中于第四季度（占比56%），使得公司全年经营节奏极不稳定，任何项目交付的延迟都将对全年业绩造成致命打击。
