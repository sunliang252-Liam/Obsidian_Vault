# 300127.SZ 深度透视

## 因果逻辑链
- **[销量与均价双升]** -> [营收增长7.38%]: 2025年稀土永磁体销量3,519吨（+5.11%），叠加金属镨钕均价同比上涨23.8%带动产品售价提升，量价齐升驱动收入增长。
- **[毛利率提升]** -> [净利润增长20.75%]: 在原材料成本控制（优化配方、自动化提效）下，综合毛利率从2024年32.22%提升至35.16%，利润弹性显著高于收入弹性。
- **[汽车与节能电机需求]** -> [核心主业粘结磁体增长5.66%]: 汽车微电机、节能家电、智能机器人等下游领域需求增长，支撑占营收88.88%的粘结磁体业务稳中有升。
- **[热压磁体放量]** -> [第二增长曲线成型]: 热压磁体收入增长18.79%，受益于伺服电机、数控机床等高效节能电机领域渗透，成为公司增长最快的产品线。
- **[稀土价格回升]** -> [库存价值与售价联动受益]: 2025年金属镨钕均价同比上升23.8%，公司库存原材料及产成品价值提升，同时向下游传导成本，增厚利润。
- **[全资子公司产能扩张]** -> [规模效应与成本分摊]: 银磁材料二期厂房进入收尾阶段，塑磁和磁粉产能增加，支撑营收增长的同时分摊固定成本，提升整体盈利能力。
- **[研发投入聚焦降本增效]** -> [成本优势持续巩固]: 研发费用5,013万元（占营收5.84%），重点投向低成本组装技术、废料回收利用及自动化系统，直接降低制造成本。

## 风险警告
**核心风险在于稀土价格波动与下游需求结构变化的双重挤压。** 公司原材料成本占比高达72%，而稀土价格受国家出口管制、战略收储及供需博弈影响剧烈（2020-2025年金属镨钕价格从36万/吨暴涨至138万/吨后暴跌至55万/吨，2025年又回升至60-75万/吨）。这种剧烈波动导致公司库存管理难度极大，且与客户的价格调整机制存在滞后性，毛利率稳定性面临持续挑战。2025年毛利率提升部分受益于稀土涨价周期，若价格回落，利润将直接承压。

**此外，公司面临关税与出口管制带来的市场准入风险。** 虽然公司声称90%以上产品不含出口管制稀土元素，但2025年4月商务部对7类中重稀土实施出口管制，叠加国际贸易摩擦加剧，可能直接或间接影响海外客户采购意愿。公司外销占比25.43%，且以美元结算，汇率波动（2025年汇兑净收益减少）与海外市场不确定性叠加，构成对业绩的潜在冲击。同时，公司无控股股东和实际控制人，股权结构分散（前两大股东持股30.52%和29.80%），在重大战略决策（如2025年终止的资产收购）上可能存在协调难度。
