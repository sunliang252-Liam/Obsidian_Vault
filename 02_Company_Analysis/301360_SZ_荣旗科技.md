# 301360.SZ 深度透视

## 因果逻辑链
- **[AI视觉检测技术突破]** -> [营收增长13.97%]: 公司基于自研AI算法和光学系统，成功切入苹果VC均热板检测、META智能眼镜组装等新业务，驱动订单增长。
- **[新业务拓展初期投入高]** -> [扣非净利润下降20.73%]: 为抢占智能眼镜、钙钛矿等新兴市场，研发费用同比增长11.61%，叠加股份支付费用增加，侵蚀了当期利润。
- **[下游客户高度集中]** -> [经营依赖大客户创新周期]: 苹果、宁德时代等头部客户贡献主要收入，其新产品迭代直接决定公司设备采购规模，导致业绩波动性大。
- **[“以销定产”模式]** -> [存货激增与现金流承压]: 订单增加导致生产量和库存量大幅上升（智能装备库存增116%），同时支付供应商货款增加，使经营活动现金流净额下降36.72%。
- **[消费电子轻薄化趋势]** -> [智能组装装备需求爆发]: 智能眼镜、VC均热板等精密零部件组装难度提升，推动公司智能组装装备收入同比增长30.88%。
- **[新能源扩产与新技术路线]** -> [打开第二增长曲线]: 锂电池排产上行带动AI质检设备订单高增，同时前瞻布局固态电池检测和钙钛矿AOI设备，为长期增长储备动能。
- **[产学研协同创新]** -> [巩固技术壁垒]: 与复旦、上交大联合发布Real-IAD工业异常检测数据集，提升公司在工业AI视觉领域的学术影响力和技术领导力。

## 风险警告
**核心风险在于对苹果产业链的深度依赖与下游创新节奏的绑定。** 公司营收高度集中于苹果、META等消费电子巨头，其产品创新周期直接决定设备采购规模。一旦大客户技术路线变更或产能转移至东南亚，公司面临订单骤降与毛利率下滑的双重压力。虽然公司已布局新能源领域，但新业务尚处爬坡期，短期难以完全对冲消费电子业务波动。

**另一重大风险是盈利质量与现金流的持续背离。** 公司营收增长但扣非净利润下滑，且存货激增116%、应收账款周转天数长达216天，导致经营性现金流大幅萎缩。这反映出公司“以销定产”模式下，收入确认与现金回收存在严重时间错配。若下游客户付款周期进一步拉长或产品验收延迟，公司可能面临流动性紧张和坏账风险。
