# 603712.SH 深度透视

## 因果逻辑链
- **[特殊机构用户需求阶段性波动]** -> [营收收缩]: 订单结构优化调整，部分型号订单延迟、交付放缓，新拓展领域尚未形成规模订货，导致2025年营收同比微降0.27%。
- **[研发投入持续高增长但未转化为收入]** -> [净利润承压]: 研发费用占营收比例高达32.05%，但高投入未在当期形成有效收入转化，直接侵蚀利润。
- **[订单放缓与客户需求变化]** -> [资产减值损失激增]: 计提存货跌价准备同比增加，销售回款周期拉长、回款规模未达预期，导致信用减值损失同比增加，合计减值损失超2.5亿元。
- **[递延所得税资产确认减少]** -> [亏损扩大]: 本期确认递延所得税资产金额减少，导致所得税费用为负值但对净利润的正面贡献减弱，进一步加剧了归属于母公司股东的净亏损（-4.92亿元）。
- **[传统领域份额稳中有升与新领域突破]** -> [长期增长潜力]: 在航空通信、地面通信等领域中标多个重点项目（如蜂群数据链、舰载数据链），为未来五到十年装备需求储备技术，但短期难以贡献业绩。
- **[民用5G-R产品研发与市场拓展]** -> [巩固行业地位]: 完成5G CIR研发及现场实验，中标多个城市轨道交通项目，在铁路和城轨通信领域保持第一梯队，为后续规模化收入奠定基础。
- **[收购方州科技]** -> [拓展业务边界]: 以3.39亿元收购方州科技52.46%股权，布局计算机仿真平台领域，旨在打造一体化解决方案，但存在整合与业绩承诺不及预期的风险。

## 风险警告
公司当前面临的核心风险是“研发投入高企与收入转化脱节”导致的持续亏损。2025年研发费用率高达32.05%，但营收几乎零增长，导致净利润连续两年为负且亏损额扩大至-4.92亿元。这种“高投入、低产出”的模式若无法在“十五五”期间通过新订单放量扭转，将严重侵蚀公司现金流和净资产，并可能触发退市风险警示。

此外，公司经营现金流净额为-4.98亿元，同比大幅恶化，主要因销售回款减少。同时，应收账款和存货合计占总资产比重超过66%，且减值准备计提压力巨大。若下游客户付款周期进一步拉长或产品交付持续放缓，公司流动性将面临严峻考验，财务风险显著上升。
