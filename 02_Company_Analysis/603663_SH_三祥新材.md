# 603663.SH 深度透视

## 因果逻辑链
- **[核级海绵锆量产与出口突破]** -> [净利润同比+55.15%]: 子公司辽宁华锆1300吨核级锆项目投产，产品成功出口法马通并签订三年期框架合同，成为业绩增长新引擎。
- **[海绵锆销量突破3000吨]** -> [市占率超50%]: 公司已成为国内乃至亚洲最大的工业级海绵锆生产商之一，规模效应与成本优势进一步巩固行业主导地位。
- **[电熔氧化锆成本高企]** -> [毛利率承压]: 上游锆英砂进口价格高位运行，导致电熔锆产品成本居高不下，传统市场竞争激烈。
- **[氧氯化锆主动技改减产]** -> [短期销量下滑]: 公司为优化产品结构、提升核心竞争力，主动推进技术改革与产品迭代，调整产量，为后续高端应用领域（如固态电池电解质）布局。
- **[固态电池材料研发突破]** -> [开辟新增长空间]: 公司以自产氯化锆为原料，成功开发锆基氯化物固态电解质，并已向下游固态电池工厂小批量供货，切入新能源新兴赛道。
- **[锆铪分离技术产业化]** -> [打破国外垄断]: 公司引进并转化“盐酸体系下锆铪分离技术”，预计2026年实现核级原料批量供应，为核级海绵锆和半导体前驱体材料提供关键原料。
- **[一体化产业链协同]** -> [成本与质量优势]: 公司自建水电站提供低成本电力，母公司向子公司辽宁华锆供应核心原材料电熔氧化锆，形成上下游协同，有效控制成本并保障质量稳定性。

## 风险警告
**核心风险在于原材料价格波动与下游需求的不确定性。** 公司锆系产品核心原材料锆英砂高度依赖进口，且全球供应集中于三大巨头，价格高位运行且波动剧烈。若原材料成本压力无法有效向下游传导，将直接侵蚀公司利润。同时，传统电熔锆下游市场（如耐火材料、陶瓷色釉料）需求无明显改善，行业竞争激烈，产品价格承压。

**新产品市场拓展与子公司经营风险不容忽视。** 公司布局的固态电池电解质、核级锆铪等新产品虽前景广阔，但市场推广、客户认证及规模化生产均存在不及预期的风险。此外，控股子公司辽宁华祥（主营氧氯化锆）报告期内亏损严重，净资产为负，其技改效果及未来盈利能力存在较大不确定性，可能拖累整体业绩。
