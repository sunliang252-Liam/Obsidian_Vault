# 600375.SH 深度透视

## 因果逻辑链
- **[全面停产燃油车，聚焦新能源]** -> [营收增长55.2%]: 公司于2025年底全面停产燃油车，全力转向甲醇电动和纯电动重卡，新能源重卡销量同比大增38.22%，直接驱动营收从42.2亿跃升至65.5亿。
- **[深度绑定吉利系关联交易]** -> [营收依赖与利润风险]: 对关联方（浙江远程等）的销售额占年度总营收的69.97%，采购额占38.02%，公司已成为吉利商用车体系内的核心生产环节，但议价能力和独立性受限。
- **[债务重组收益消失]** -> [净利润暴跌69.7%]: 2024年因破产重整确认了11.86亿的债务重组收益，2025年该项收益归零，导致归母净利润从1.57亿骤降至0.48亿，扣非净利润仍为-0.69亿，主业尚未盈利。
- **[产能利用率不足50%]** -> [固定成本摊销压力大]: 报告期内中重卡产能利用率仅为46.62%，大量固定资产折旧和无形资产摊销持续侵蚀利润，是公司难以实现稳定盈利的根本原因之一。
- **[巨额历史亏损与坏账]** -> [分红能力长期缺失]: 截至2025年末，公司未分配利润为-45.39亿元，母公司未分配利润为-27.95亿元，巨额历史亏损使得公司未来数年都无法进行现金分红。
- **[融资租赁业务扩张]** -> [现金流与风险敞口]: 长期应收款同比大增127.85%至7.02亿元，公司通过融资租赁促进销售，虽然增加了收入，但也占用了大量现金，并积累了潜在的信用风险。

## 风险警告
**核心风险在于“伪盈利”与“高依赖”。** 公司2025年净利润仅为0.48亿，且完全依赖非经常性损益（如坏账转回0.55亿），扣非净利润仍亏损0.69亿，表明新能源转型尚未带来可持续的造血能力。同时，公司营收高度依赖吉利系关联交易（占比近70%），实质上已沦为吉利商用车集团的代工厂，若关联交易定价或规模发生变化，公司业绩将面临剧烈波动。

**其次，历史包袱沉重，资产质量堪忧。** 公司仍有高达45.39亿元的未弥补亏损，且应收账款坏账准备余额高达17.83亿元，存货跌价准备1.09亿元，固定资产及无形资产减值准备合计超5.5亿元。这些历史遗留问题将持续压制公司净资产收益率和估值水平，并构成潜在的“爆雷”风险。产能利用率不足50%也意味着大量资产处于闲置或低效状态。
