# 000957.SZ 深度透视

## 因果逻辑链
- **[海外市场高增长]** -> [营收与利润双创新高]: 海外营收同比增长33.95%，占比升至58.71%，成为核心增长引擎，驱动总收入增长27.82%，净利润增长44.18%。
- **[新能源客车爆发]** -> [产品结构优化]: 新能源客车营收同比暴增113.12%，占比从29.88%提升至49.82%，成功对冲传统客车下滑，实现“收入增幅高于销量增幅”。
- **[经销模式扩张]** -> [海外市场渗透加速]: 经销收入同比激增202.26%，占比从22.26%升至52.65%，表明公司正借助经销商网络快速打开海外市场。
- **[规模效应与成本控制]** -> [利润增幅高于收入增幅]: 在原材料及人工成本上涨背景下，通过集约化采购和设计优化，实现利润增速（44.18%）远超收入增速（27.82%）。
- **[研发投入聚焦]** -> [技术壁垒构建]: 研发投入2.55亿元，聚焦安全、节能、智能化，开发智能驻车、整车热管理等系统，为产品竞争力提供核心技术基础。
- **[关联交易协同]** -> [供应链成本优势]: 与控股股东山东重工集团旗下企业（潍柴、中国重汽）的关联采购额达5.55亿元，依托集团资源获取稳定且具成本优势的零部件供应。

## 风险警告
**核心风险在于海外业务的高波动性与巨大的客户信用敞口。** 公司营收近六成来自海外，但地缘政治冲突、汇率波动及贸易政策变化（如欧美关税壁垒）将直接冲击收入和利润。同时，公司为客户购车提供高达171.19亿元的回购担保责任余额，远超全年净利润，一旦海外客户违约潮出现，将引发巨额或有负债，严重侵蚀利润表。

**国内市场的结构性替代风险与同业竞争问题尚未解决。** 高铁、私家车等出行方式持续分流客运需求，国内客车市场复苏动力不足。此外，公司与实际控制人山东重工旗下的扬州亚星客车存在同业竞争，虽承诺5年内解决，但具体方案和时间表不明，构成潜在的治理与利益冲突风险。
