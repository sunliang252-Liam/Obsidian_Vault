# 600686.SH 深度透视

## 因果逻辑链
- **海外市场高增长** -> **归母净利润暴增197%**: 出口3.03万辆（+34.47%），海外收入占比提升至55.7%，且海外毛利率（16.69%）远高于国内（6.42%），高毛利海外业务占比提升直接拉动整体盈利。
- **扣非净利润扭亏为盈** -> **主业造血能力质变**: 扣非净利润从-1.58亿跃升至+1.99亿，表明剔除政府补助、金融资产收益等非经常性项目后，客车主业已实现根本性盈利改善。
- **财务费用大幅下降** -> **利润增厚**: 财务费用从+1.12亿转为-0.10亿，主要得益于汇兑收益增加及利息支出减少，直接贡献利润约1.2亿元。
- **信用减值损失激增** -> **利润侵蚀**: 信用减值损失从+0.39亿转为-1.59亿，主要是预计担保损失及坏账准备计提增加，对利润形成显著拖累。
- **研发投入持续高企** -> **技术护城河**: 研发费用9.16亿元（+11.3%），聚焦线控底盘、燃料电池、智能驾驶及碳化硅电控，为未来产品竞争力奠定基础。
- **供应链集中采购** -> **毛利率提升**: 通过集团集采平台整合动力电池、发动机等大宗物资，营业成本增速（3.89%）低于收入增速（6.89%），推动整体毛利率提升2.49个百分点。
- **国内公交市场萎缩** -> **业务结构转型**: 国内大中型客车销量下滑10%，但公司通过海外出口和轻型客车（+4.67%）弥补，实现总销量增长2.29%，对冲了国内需求疲软。

## 风险警告
**核心风险在于信用减值损失的失控与海外市场的不确定性。** 2025年信用减值损失高达1.59亿元，主要源于预计担保损失和应收账款坏账。公司为购车客户提供按揭担保余额巨大（超44亿元），一旦经济下行或客户违约，担保损失将直接吞噬利润。同时，海外业务虽贡献主要增量，但面临地缘政治冲突、贸易壁垒（如欧盟碳边境调节机制）、汇率波动等多重风险，高增长持续性存疑。

**国内市场的结构性困境不容忽视。** 国内客车市场已进入存量竞争，公交需求受地方财政压力及前期透支影响持续走弱，公路客运受高铁、网约车挤压。公司国内业务毛利率仅6.42%，几乎处于盈亏平衡边缘。若海外市场增速放缓，公司业绩将面临巨大压力。此外，核心零部件（电池95.82%、变速器91.40%）高度依赖少数供应商，供应链集中风险可能随时影响生产连续性和成本控制。
