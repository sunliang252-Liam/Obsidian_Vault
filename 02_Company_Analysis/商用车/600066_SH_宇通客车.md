# 600066.SH 深度透视

## 因果逻辑链
- **[海外市场持续开拓]** -> [营收与利润双增]: 海外营收同比增长38.87%，毛利率高达29.62%，远超国内，成为利润增长的核心引擎。
- **[新能源客车出口高增]** -> [产品结构优化]: 海外新能源客车出口量同比增长31.95%，带动整体销售结构向高附加值产品倾斜，提升综合毛利率。
- **[“以旧换新”政策延续]** -> [国内公交市场稳定]: 政策补贴延续并提升标准，支撑国内公交客车销量同比增长4.81%，对冲了旅游市场需求回落的影响。
- **[高研发投入与技术创新]** -> [产品竞争力领先]: 研发支出18.08亿元，占营收4.36%，聚焦“车电同寿”电池、智能网联等核心技术，巩固行业龙头地位。
- **[“直销、直服”模式深化]** -> [海外市场品牌与渠道壁垒]: 通过70余家海外子公司/办事处及400余家服务网点，构建了难以复制的本地化服务与品牌优势。
- **[非经常性损益贡献]** -> [净利润放大]: 公允价值变动损益及资产处置收益等非经常性损益高达9.74亿元，占净利润的17.5%，显著增厚了当期利润。
- **[现金流大幅下降]** -> [营运资金压力显现]: 经营活动现金流净额同比减少55.67%，主因是支付原材料采购款增加，显示营收增长伴随营运资金占用加剧。

## 风险警告
**核心风险在于海外市场的高依赖性与地缘政治不确定性。** 公司净利润增长高度依赖海外市场（营收占比超57%），而全球贸易摩擦（如对等关税）、地缘政治紧张及部分市场政策变动，可能直接抑制海外需求或增加贸易壁垒，导致出口业务波动。同时，公司经营活动现金流净额大幅下降，与利润高增长形成背离，提示营收扩张可能伴随着应收账款和存货的资金占用增加，需警惕营运资金周转压力。

**国内市场需求的结构性风险不容忽视。** 尽管“以旧换新”政策短期托底，但地方财政紧平衡下公交企业经营未见好转，国内公交市场长期需求动力不足。同时，旅游市场在2023-2024年爆发后进入平稳期，需求同比下降。国内市场竞争加剧，公司大中型客车市场占有率同比下降2.46个百分点，龙头地位虽稳固但份额承压。
