# 301039.SZ 深度透视

## 因果逻辑链
- **[“星链计划”重塑生产组织]** -> [中国市场半挂车销量同比+15%，毛利率+3.3%]: 通过LTP中心产线升级、集采比例提升至80%以上、工时节降30%-40%，将规模优势转化为成本与效率壁垒，在行业产能过剩中实现“反内卷”。
- **[北美货运市场深度衰退]** -> [北美市场营收同比-29.53%，毛利率-5.06%]: 美国半挂车产量连续八个季度下滑（同比-16.5%），叠加关税与双反调查，导致公司北美业务量、收、利同步承压。
- **[全球南方市场属地化深耕]** -> [全球南方市场营收同比+17.7%，销量+29.1%]: 针对东南亚、中东、非洲等50个国家制定属地化增长策略与模块化车型，把握新兴市场基建与物流红利，实现规模与盈利双增。
- **[新能源重卡渗透率跃升至29%]** -> [EV-DTB产品销量同比+100%，超1.1万台]: 国内新能源重卡销量从22.3万辆快速攀升，公司为头部主机厂配套上装，深度绑定“好马配好鞍”商业模式，实现销量与利润大幅提升。
- **[“星辰计划”启动与EV-RT生态圈构建]** -> [公司战略从“制造”向“制造+服务+能源管理”转型]: 在星链计划基础上，向全价值链运营者升级，通过EV-RT头挂列车、生产性服务、二手车等增量业务，开辟第二增长曲线。
- **[GB7258修订与EBS强制安装]** -> [行业技术门槛提升，利好龙头]: 新规将挂车定义调整为“不能依靠自身驱动力”，为电动挂车合法化铺路；EBS强制安装推高行业成本，公司凭借模块化研发与集采保供体系，将合规压力转化为成本与效率优势。

## 风险警告
**北美业务持续承压是最大短期风险。** 美国货运市场深度衰退、行业库存高企、客户采购收缩，已导致北美营收同比下滑近30%。叠加美国关税政策与“双反”调查推高供应链成本，北美业务盈利修复高度依赖市场复苏节奏，若2026年需求回暖不及预期，将继续拖累整体业绩。

**欧洲业务盈利韧性不足，战略转型存在不确定性。** 欧洲半挂车市场受经济增长乏力、货运周转量走低影响，SDC和LAG两家公司“销量持平、盈利承压”。公司计划择机启动“欧洲半挂车星链计划”，但欧洲市场法规、客户需求与竞争格局与中国差异显著，跨区域复制成功经验面临较高执行风险与整合成本。
