# 688389.SH 深度透视

## 因果逻辑链
- **[营收结构变化]** -> [利润大幅下滑]: 体外诊断业务受集采降价及需求减少影响，收入同比下降14.67%，拖累整体营收下降9.6%；同时公司逆势加大研发（+13.45%）和销售（+21.96%）投入，导致利润降幅（-46.66%）远超收入降幅。
- **[消费者健康业务爆发]** -> [收入结构优化]: 家用产品收入同比增长150.26%，成为公司新的增长极，部分对冲了体外诊断业务的下滑，并推动直销收入占比提升。
- **[海外市场扩张]** -> [对冲国内下行风险]: 境外收入同比增长16.93%，占总收入比例提升至42.86%，有效弥补了国内收入23.56%的下滑，体现了全球化布局的战略价值。
- **[电化学发光全系列布局完成]** -> [巩固IVD核心竞争力]: 推出从低速到超高速的全系列分析仪及107项配套试剂，形成完整产品矩阵，为在集采环境下争夺市场份额奠定基础。
- **[AI技术融合]** -> [产品差异化升级]: “血红蛋白智能分析仪”入选国家级揭榜挂帅项目，将AI用于变异体识别和色谱图解读，推动产品从“检测工具”向“智能诊断系统”跨越，提升产品附加值。
- **[四大业务板块确立]** -> [平台化抗风险能力增强]: 正式确立体外诊断、临床医疗、皮肤医美、消费者健康四大板块，形成专业医疗与消费医疗协同格局，分散单一业务周期波动风险。
- **[研发投入强度大幅提升]** -> [长期技术壁垒构建]: 研发费用率从17.55%提升至22.03%，重点投入电化学发光、AI、能量医美等领域，虽短期侵蚀利润，但为未来产品迭代和国际化竞争储备技术势能。

## 风险警告
**核心风险在于营收与利润的剪刀差持续扩大。** 体外诊断业务作为基本盘（占收入77%），在集采常态化下价格承压，收入下滑14.67%；而公司为应对竞争和布局未来，选择大幅增加研发和销售投入，导致费用率飙升，净利润暴跌46.66%。若体外诊断业务不能通过“以量补价”或新产品放量企稳，而费用端继续刚性增长，公司盈利能力将持续承压。

**新业务放量存在不确定性，且商誉减值风险已暴露。** 消费者健康业务虽增长迅猛（+150%），但基数尚小，能否成为稳定增长极仍需验证。同时，公司已对重庆京渝及深圳辉迈计提商誉减值，表明部分收购标的经营不及预期，若皮肤医美等新业务拓展受阻，可能面临进一步的资产减值风险。
