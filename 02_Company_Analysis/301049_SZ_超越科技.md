# 301049.SZ 深度透视

## 因果逻辑链
- **[安徽省危废处置产能5年扩张3.7倍]** -> [行业价格战与量价齐跌]: 产能从53.36万吨飙升至195.47万吨，供过于求导致焚烧、填埋处置价格持续下跌，公司处置量同步萎缩。
- **[填埋业务处置量骤降68.71%]** -> [危废业务毛利转负]: 应急业务结束及客户结构调整，叠加高固定成本，填埋业务收入锐减5963万元，毛利下降4956万元。
- **[家电拆解基金补贴政策调整]** -> [电子废物业务利润空间压缩]: 从“基金补贴”转为“以奖代补”，2026年专项资金下降9.25%，拆解量虽增65.7%但利润贡献有限。
- **[汽车拆解业务产能利用率极低]** -> [子公司德慧绿色持续大额亏损]: 主动收缩业务，拆解量仅7021台（含5647台电瓶车），高折旧摊销（1092万）与利息（373万）导致亏损1899万元。
- **[锂电池业务产能爬坡缓慢]** -> [子公司惠宏科技亏损]: 模组组装量仅3362组，产能利用率低，收入下降74.4%，亏损1194万元。
- **[固定资产与存货减值计提]** -> [直接侵蚀利润]: 对低效资产计提减值279.56万元，存货跌价损失847.90万元，合计1127万元。
- **[经营性现金流为正但净利润巨亏]** -> [账面亏损源于非现金成本]: 现金流净额2717万元，主要因固定资产折旧6589万元、资产减值1138万元等非付现成本导致净利润-14118万元。

## 风险警告
**核心风险在于行业供需格局的持续恶化与公司多元化扩张的失败。** 安徽省危废处置产能已严重过剩，价格战短期内无缓解迹象，公司焚烧、填埋两大核心业务毛利率均已转负，且填埋业务量因客户结构变化出现断崖式下滑，显示其区域龙头地位正被侵蚀。同时，汽车拆解与锂电池两大新业务投入巨大但产出极低，子公司持续大额亏损，成为吞噬利润的“出血点”，多元化战略已陷入泥潭。

**财务风险同样严峻。** 公司已连续三年亏损，累计未分配利润达-1.35亿元，母公司报表亦存在未弥补亏损，已不具备分红能力。实际控制人高德堃所持股份已全部质押，叠加公司资产负债率上升、短期借款增加，若经营状况无法改善，流动性压力与股权质押风险可能形成负反馈循环。
