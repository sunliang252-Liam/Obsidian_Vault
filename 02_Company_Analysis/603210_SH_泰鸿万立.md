# 603210.SH 深度透视

## 因果逻辑链
- **[下游新能源汽车渗透率提升]** -> [营收增长35.81%]: 新能源车型订单释放，带动公司结构件、功能件销量大幅增长。
- **[IPO募集资金到位]** -> [净资产增长78.83%]: 2025年4月上市募资约11.5亿元，大幅增厚资本实力。
- **[新基地建设与产能扩张]** -> [在建工程与固定资产双增]: 苏州、天津、沈阳等新设子公司，在建工程转固，固定资产增66.63%。
- **[客户集中度高]** -> [前五大客户销售额占比84.35%]: 深度绑定吉利、长城、小米等头部车企，但单一客户依赖风险显著。
- **[原材料成本压力]** -> [毛利率下降1.33个百分点]: 直接材料占成本68.64%，钢材、铝材价格上涨侵蚀利润空间。
- **[研发投入加大]** -> [研发费用增长45.93%]: 聚焦电动化、模块总成、智能化，研发费用增至7774万元。
- **[经营现金流恶化]** -> [经营活动现金流净额下降56.41%]: 营收增长但回款放缓，购买商品支付现金大幅增加，现金流与利润背离。

## 风险警告
**客户集中与车型依赖风险**：公司前五大客户销售额占比高达84.35%，深度绑定吉利、长城、小米等少数头部车企。一旦主要客户因行业竞争加剧、自身销量下滑或更换供应商，将对公司营收造成致命打击。同时，公司为小米SU7、YU7等“爆款”车型投入大量前期资本，若车型生命周期销量不及预期，前期投资将面临减值风险。

**现金流恶化与资本开支压力**：2025年经营活动现金流净额同比骤降56.41%至9140万元，与净利润（2.01亿元）严重背离，显示回款能力恶化。与此同时，公司正大规模投资苏州、天津等新基地，资本开支巨大，未来若融资渠道不畅或客户回款持续恶化，可能引发流动性危机。
