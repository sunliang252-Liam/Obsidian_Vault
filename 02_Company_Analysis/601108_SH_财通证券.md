# 601108.SH 深度透视

## 因果逻辑链
- **[市场交投活跃度大幅提升]** -> [财富管理业务收入增长27.11%]: 2025年A股日均成交额同比增61.9%，公司服务居民资产规模突破1万亿元，驱动经纪及代销收入显著提升。
- **[融资融券余额创历史新高]** -> [证券信用业务收入增长23.60%]: 全市场两融余额同比增36.26%，公司融出资金规模达280亿元，同比增长超30%，利息净收入随之增加。
- **[“投资+投行+投研”三投联动模式]** -> [私募股权投资业务规模跃升]: 财通资本服务与管理基金规模突破1,300亿元，同比增长46%，投资项目覆盖航天卫星、具身智能等战略性新兴产业。
- **[获批银行间市场债务融资工具一般主承销商资格]** -> [投行业务牌照壁垒增强]: 公司债（企业债）承销规模连续两年省内第一，科创债承销金额同比激增近三倍，综合服务能力提升。
- **[深化“以客户为中心”重大改革]** -> [财富管理转型成效显现]: 首创“基石客户经理制度”，推动买方投顾转型，连续两年获“基金投顾机构金牛奖”，客户资产规模突破1.4万亿元。
- **[AI赋能投资决策与风险管控]** -> [自营投资业务稳健增长]: 自营投资规模超600亿元，同比涨幅超40%，年化资金收益率大幅跑赢对标指数，投资收益及公允价值变动收益合计24.74亿元。
- **[浙江省属券商区位优势]** -> [业务深度绑定区域经济]: 与省内11个地级市、61个区县政府建立战略合作，服务浙商浙企超1.2万家，直接融资超1660亿元，形成差异化竞争壁垒。

## 风险警告
财通证券的业绩高度依赖A股市场活跃度与融资融券规模。2025年营收与利润双增，核心驱动力是市场日均成交额同比增61.9%及两融余额创历史新高。一旦市场情绪逆转、成交量萎缩或监管收紧杠杆，财富管理及信用业务收入将面临显著下滑风险。公司自营投资规模超600亿元，虽强调“去方向性”，但公允价值变动收益仍为-4.2亿元，市场波动对利润表的冲击不可忽视。

信用减值损失同比激增3017.68%，主要源于融出资金减值损失计提增加。在宏观经济承压背景下，股票质押及融资融券业务的客户违约风险可能持续暴露。同时，公司资产负债率（扣除代理买卖证券款后）达70.27%，且卖出回购金融资产款同比增52.57%，对融资渠道稳定性及利率变动较为敏感，需警惕流动性风险在极端市场环境下的放大效应。
