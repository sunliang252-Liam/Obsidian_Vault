# 300491.SZ 深度透视

## 因果逻辑链
- **[新能源重卡销量爆发式增长]** -> [热管理电源业务收入提升]: 2025年国内电动重卡销量同比增182%，带动公司热管理电源（DC-DC转换器）作为核心部件需求激增，公司凭借先发优势占据较高市场份额。
- **[航空航天领域需求回暖]** -> [定制类电源及检测业务收入大增82.57%]: 2025年作为“十四五”收官年，前期积压的军工订单加速释放，子公司霍威电源抓住机遇，实现营收大幅提升。
- **[充电模块产品持续迭代]** -> [新能源功率变换产品收入增长28.05%]: 公司推出太行、昆仑系列及80kW大功率模块，以高功率密度、高性价比满足超充趋势，巩固了市场领先地位并带动销量增长。
- **[储能赛道战略性布局]** -> [开辟新增长曲线]: 公司依托电力电子技术积淀，推出储能一体柜、PCS等产品，从设备商向解决方案服务商转型，为未来收入增长奠定基础。
- **[HVDC产品切入AI数据中心]** -> [智能电网业务打开新空间]: AI算力爆发推动HVDC方案渗透率提升，公司推出多电压等级HVDC产品，参与行业标准制定，在数据中心供配电领域取得初步规模。
- **[研发投入持续高增]** -> [产品竞争力与毛利率承压]: 2025年研发投入1.38亿元（同比+22.12%），虽巩固技术优势，但新能源行业竞争激烈导致毛利率下降5.17个百分点，侵蚀部分利润。
- **[应收账款与存货同步增长]** -> [现金流与资产质量风险累积]: 营收增长带动应收账款（+30.4%）和存货（+24.2%）大幅增加，经营性现金流净额虽改善但仍低于净利润，回款压力与存货跌价风险并存。

## 风险警告
**核心风险在于“增收不增利”的结构性困境。** 公司2025年营收增长28.78%，但归母净利润仅增长67.72%至4015万元，扣非净利润率仅2.2%。新能源业务（占收入70%）毛利率同比下降5.17个百分点至17.21%，是利润被侵蚀的主因。充电模块行业竞争白热化，价格战持续，公司虽通过产品迭代维持份额，但成本端（原材料、研发）刚性增长，利润空间被严重挤压。若行业价格战加剧或原材料价格反弹，公司盈利能力可能进一步恶化。

**财务健康度面临严峻考验。** 应收账款高达9.52亿元（占总资产37.5%），同比增长30.4%，远超营收增速；存货3.28亿元，同比增长24.2%。两者合计占总资产近50%，且公司已计提大额减值（资产减值损失1745万元，信用减值损失1567万元）。下游客户（充电运营商、电网）回款周期长，若宏观经济波动或客户信用恶化，坏账风险将直接冲击利润表。同时，公司资产负债率已攀升至52.5%，有息负债增加，财务费用同比增长37%，财务杠杆风险上升。
