# 688248.SH 深度透视

## 因果逻辑链
- **[新型储能规模化建设政策驱动]** -> [储能系统技术服务收入同比+58.84%]: 国家政策明确2027年装机目标，公司承接多个大型EPC项目完工验收，推动营收高速增长。
- **[非南网市场突破]** -> [省外收入占比提升至42.53%，同比+27.94%]: 公司打破区域壁垒，储能、智能配用电等产品打入国网江苏、甘肃等市场，非南网营收占比近六成。
- **[“丝路”操作系统规模化推广]** -> [智能配用电设备收入同比+21.43%]: 基于自研操作系统的核心板、负荷管理装置等产品推广超2000万只，并首次进入国网和蒙西电网。
- **[AI与机器人技术产业化]** -> [机器人及无人机收入同比+26.87%]: “擎天”具身机器人、“慧眼”无人机产品矩阵完善，在电网、交警等领域规模化应用，并输出至海外。
- **[电源侧改造与新能源检测需求增长]** -> [试验检测及调试服务收入同比+20.06%]: 煤电“三改联动”政策推动火电灵活性改造，叠加海上风电并网检测需求，带动业务增长。
- **[研发投入持续高增]** -> [核心技术壁垒与新产品突破]: 研发投入同比+25.18%，新增IEC国际标准2项、中国专利金奖，完成2.5MW构网型变流器等硬核产品研发。
- **[经营现金流改善]** -> [现金流增速(31.68%)高于营收增速(22.27%)]: 公司加大现金统筹管理，发力回收长账龄款项，资金回收情况向好。

## 风险警告
**核心风险在于对南方电网的深度依赖与关联交易集中度。** 公司第一大客户南方电网收入占比42.26%，且广东省内收入占比57.47%。尽管公司正积极拓展省外及海外市场，但短期内若南方电网投资节奏放缓或招标政策变化，将直接冲击公司业绩稳定性。此外，储能EPC项目毛利率仅9.90%，且同比下滑4.21个百分点，反映该业务“增收不增利”的隐忧，需警惕大型项目利润侵蚀。

**技术迭代与市场竞争加剧是另一关键风险。** 储能、智能配用电、机器人等领域竞争者众多，技术路线快速演进。公司若不能持续保持技术领先（如构网型变流器、具身机器人等），可能面临市场份额被蚕食的风险。同时，应收账款同比增长28.25%至6.56亿元，存货达8.10亿元，若下游客户回款周期延长或市场需求变化，将带来坏账与存货减值压力。
