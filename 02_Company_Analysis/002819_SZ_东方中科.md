# 002819.SZ 深度透视

## 因果逻辑链
- **[新能源汽车测试业务高增长]** -> [营收增长19.03%]: 公司抓住新能源汽车主导时代机遇，凭借头部车企合作关系和全产业链测试服务能力，市场份额持续提升。
- **[数字安全与数智应用板块亏损缩窄]** -> [归母净利润减亏30.22%]: 通过成本控制和降本增效措施，该板块亏损持续收窄，带动整体利润改善。
- **[政务集成业务扩张]** -> [营收增长21.95%]: 受益于信创产业“2+8+N”推进节奏，公司凭借全栈式信创集成能力，在党政和国企市场获取更多项目。
- **[数智应用业务爆发]** -> [营收增长65.84%]: 公安系统预算向“实战化、智能化”倾斜，公司智能辅助决策平台精准契合客户核心需求，实现高增长。
- **[安全保密业务承压]** -> [营收下降38.02%]: 地方财政“过紧日子”导致政务信息化项目预算审批趋严、资金拨付流程延长，项目周期拉长。
- **[经营活动现金流大幅改善]** -> [净额增长379.82%]: 公司加强应收账款管理和采购支付控制，购买商品、接受劳务支付的现金同比减少。
- **[资产减值损失高企]** -> [利润总额被侵蚀70.65%]: 应收款项、存货及商誉计提大额减值，成为拖累利润的主要非经常性因素。

## 风险警告
**核心风险在于数字安全板块的持续亏损与资产减值压力。** 尽管该板块亏损缩窄，但安全保密业务收入同比大幅下滑38%，政务集成毛利率下降近5个百分点，显示行业竞争加剧和财政预算收紧的双重压力。同时，公司计提1.22亿元资产减值损失，占利润总额的70%以上，反映出应收账款回收风险和商誉减值隐患，若下游客户付款能力持续恶化，减值风险将进一步侵蚀利润。

**第二重风险来自测试业务的毛利率下行趋势。** 通用测试业务毛利率下降1.7个百分点，（新能源）汽车测试业务毛利率下降1.5个百分点，行业“内卷式竞争”和价格敏感性提高正在压缩利润空间。公司对前五大供应商采购集中度高达32%，尤其是对Keysight、福禄克等外资品牌的依赖，在贸易摩擦和出口管制背景下，供应链稳定性存在潜在风险。
