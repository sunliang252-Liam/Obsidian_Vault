# 002644.SZ 深度透视

## 因果逻辑链
- **[营收下滑]** -> [净利润下降18.08%]: 营业收入同比减少6.60%，叠加信用减值损失大幅增加至5665万元，导致归母净利润从6007万降至4921万。
- **[成本控制改善]** -> [毛利率提升3.51个百分点]: 营业成本同比下降11.33%，降幅大于营收降幅，主要得益于原药材采购成本下降及能耗优化。
- **[现金流大幅改善]** -> [经营现金流净额增长371.85%]: 销售回款增加18.79%，同时采购支出减少15.19%，实现经营现金流1.84亿元。
- **[信用减值损失激增]** -> [侵蚀利润]: 应收账款坏账准备计提5665万元，同比增加68%，是扣非净利润下降37.54%的核心原因。
- **[大健康业务拓展]** -> [培育新增长点]: 开设10家佛慈茶馆，推出46款大健康新品，食品保健品收入增长50.66%，但体量尚小。
- **[核药赛道布局]** -> [长期战略投资]: 出资2000万元参股科近泰基新技术有限公司，切入核药新赛道，但短期无收益贡献。
- **[国际业务稳健]** -> [海外收入增长4%]: 完成89个产品国际注册，印尼清真认证，国际市场收入1.11亿元，同比增长4%，毛利率高达43.77%。

## 风险警告
**核心风险在于应收账款质量恶化。** 公司2025年信用减值损失高达5665万元，占营业利润的85.8%，应收账款余额4.23亿元，坏账准备1.21亿元。这表明下游客户回款能力持续恶化，尤其是医药流通环节的资金压力正在向公司传导。若该趋势延续，将进一步侵蚀本已微薄的利润空间。

**成长性面临双重压力。** 一方面，营收连续两年下滑（2024年-15.7%，2025年-6.6%），核心中成药业务增长乏力；另一方面，实际控制人甘肃国投集团承诺5年内解决与陇神戎发的同业竞争问题，但截至报告期末尚未有实质性整合方案，潜在的资产重组不确定性构成长期隐忧。此外，研发投入同比下降16.15%，创新动能不足。
