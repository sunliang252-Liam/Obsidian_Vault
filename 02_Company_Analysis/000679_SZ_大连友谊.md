# 000679.SZ 深度透视

## 因果逻辑链
- **[新零售业务扩张]** -> [营收增长13.09%]: 线上新零售收入同比大增116.14%，占总营收53.72%，成为收入增长核心引擎，但毛利率下降2.33%。
- **[线上推广费用激增]** -> [销售费用同比+109.30%]: 为抢占市场份额，平台佣金和推广费用大幅增加，直接侵蚀利润，是亏损扩大的主因。
- **[关联方借款增加]** -> [财务费用同比+23.43%]: 外部有息负债本金增加导致利息支出上升，进一步加重财务负担。
- **[子公司土增税清算]** -> [经营活动现金流净额-1.7亿]: 控股子公司江苏合升补缴土地增值税，导致经营性现金净流出同比扩大75.98%。
- **[传统百货业态萎缩]** -> [大连/武汉地区收入下滑]: 线下百货店收入同比下降9.22%，传统零售模式面临客流分流和成本高企的双重压力。
- **[金石谷项目停滞]** -> [资产减值损失-845万]: 在建工程（金石谷项目）计提减值准备，反映房地产业务转型困难，资产价值持续缩水。
- **[关联方借款展期降息]** -> [缓解短期流动性压力]: 将高息借款（8.6%/12%）展期并统一降至7%，降低融资成本，但债务规模仍在扩大。

## 风险警告
公司连续三年亏损且亏损额逐年扩大（-0.37亿→-0.78亿→-0.97亿），净资产已从3.32亿骤降至1.57亿。核心问题是新零售业务“增收不增利”，销售费用率从10.3%飙升至19.1%，而毛利率仅17.14%，远不足以覆盖高昂的获客成本。同时，关联方借款本息合计超6.3亿元，占负债总额的67%，公司经营高度依赖关联方输血，若未来资金支持中断，将面临严重的流动性危机。

金石谷房地产项目长期停滞，每年持续产生资产减值和管理费用，成为业绩的“出血点”。公司试图通过海外设子公司（俄罗斯、乌兹别克斯坦、巴西）寻求转型，但境外业务尚处起步阶段，且面临地缘政治和汇率波动风险。在主营业务造血能力不足、债务高企、转型前景不明的情况下，公司持续经营能力存在重大不确定性。
