# 300561.SZ *ST汇科 深度透视

## 因果逻辑链
- **收购壹证通并表** -> **营收增长但净利润仍为负**: 收购带来323万元收入增量，但标的公司业绩未达预期，导致商誉减值444万元，拖累整体利润。
- **商誉减值与信用减值损失增加** -> **净利润持续亏损**: 收购壹证通产生商誉，因业绩不达标计提减值；同时并表后应收账款规模扩大，信用减值损失同比增加，共同导致报告期净利润为-1528.73万元。
- **内控缺陷整改完成** -> **撤销退市风险警示申请**: 公司完成2024年度否定意见内控审计报告涉及缺陷的整改，致同所出具标准无保留意见内控审计报告，为申请撤销*ST奠定基础。
- **加大市场营拓力度** -> **营业收入同比增长24.77%**: 公司整合营销资源、调整策略，推动银行现金及重控物品管理解决方案收入增长43.11%，带动整体营收提升。
- **客户集中度高** -> **经营依赖大客户**: 前五名客户销售额占比72.80%，其中广电运通、农业银行、中国银行三家合计占比55.48%，单一客户流失风险显著。
- **壹证通业绩承诺未达标** -> **触发补偿条款与估值调整**: 2025年壹证通营收、净利润均未完成承诺，触发股权及现金补偿机制，并需对标的公司进行估值下调。
- **投资者索赔与行政处罚** -> **增加营业外支出与法律风险**: 因信息披露违规被处罚，并面临投资者诉讼，报告期计提预计负债238.6万元，对公司声誉及财务造成持续压力。

## 风险警告
公司当前最核心的风险是**退市风险**。尽管2025年营收增长、亏损收窄，且内控缺陷已整改，但公司股票仍处于*ST状态。申请撤销风险警示能否获批存在重大不确定性，若被否决，将面临直接退市。投资者需密切关注深交所的审核结果，这将是决定公司存续的关键节点。

其次，**收购整合与商誉减值风险**不容忽视。收购壹证通首年即未完成业绩承诺，导致商誉减值，且其核心业务受数据源供应商变化影响，未来盈利能力存疑。若后续经营持续恶化，可能引发进一步的商誉减值及业绩补偿纠纷，对公司现金流和利润造成二次冲击。同时，公司正面临投资者索赔诉讼，法律风险敞口持续存在。
