# 002496.SZ 深度透视

## 因果逻辑链
- **[生物农业转型（小分子功能肥）]** -> [营收增长17.39%]: 小分子肥特肥收入同比暴增160.89%，成为营收增长的核心驱动力，抵消了传统农药业务的萎缩。
- **[联营企业安道麦辉丰扭亏为盈]** -> [投资收益大幅改善]: 权益法核算的联营企业投资收益达6,232万元，是公司减亏的关键非经常性收益来源。
- **[持有金融资产公允价值大幅缩水]** -> [净利润巨额亏损]: 交易性金融资产公允价值变动损失高达1.05亿元，是导致归母净利润亏损2.14亿元的首要原因。
- **[石化供应链业务扩张]** -> [收入结构优化]: 油品、化学、仓储及贸易收入同比增长47.83%，占总营收比例提升至37.37%，成为第二增长曲线。
- **[子公司破产清算与股权纠纷]** -> [资产减值损失]: 对石家庄瑞凯等子公司的破产清算及股权纠纷，导致资产减值损失6,984万元，严重侵蚀利润。
- **[仲裁与诉讼和解]** -> [非经常性损益转回]: 与安道麦的仲裁案达成和解，转回了约2,053万元的坏账准备，对利润产生正面影响。
- **[研发投入大幅削减]** -> [长期竞争力隐忧]: 研发费用同比减少25.27%，研发人员数量下降42.86%，可能削弱未来产品创新和差异化优势。

## 风险警告
公司当前最大的风险在于**持续经营能力与退市风险**。尽管营收增长，但归母净利润已连续三年巨额亏损，且2025年亏损额进一步扩大至2.14亿元。公司股票已被实施退市风险警示（*ST），若2026年无法实现盈利或满足其他财务指标，将面临强制退市。核心矛盾在于，生物农业转型尚处市场培育期，小分子肥虽增长迅猛但体量尚小，无法覆盖传统业务萎缩和金融资产减值带来的巨额窟窿。

其次，**资产质量与法律纠纷风险**高企。公司持有大量交易性金融资产（4.21亿元），其公允价值波动对利润影响巨大且不可控，构成业绩的“定时炸弹”。同时，与安道麦、石家庄瑞凯等公司的重大诉讼和仲裁虽部分和解，但历史遗留的股权纠纷、业绩补偿承诺（农一北京）及资产出售尾款回收问题仍未彻底解决，持续消耗公司资源和管理层精力，并可能引发新的资产减值。
