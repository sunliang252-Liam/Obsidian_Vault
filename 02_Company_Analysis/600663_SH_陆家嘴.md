# 600663.SH 深度透视

## 因果逻辑链
- **[住宅销售回款大幅增加]** -> [经营活动现金流净额暴增695%]: 2025年住宅销售现金流入107.91亿元，主要来自陆家嘴太古源源邸、川沙锦绣云澜等高端项目，推动经营性现金流从13.16亿飙升至104.59亿。
- **[办公楼租赁市场租金承压]** -> [办公物业租赁现金流入同比下降17%]: 上海甲级写字楼平均租金下降5.9%，公司成熟写字楼出租率78%，租赁现金流入从31.53亿降至26.06亿，核心资产收益承压。
- **[金融板块加大固收投资]** -> [债权投资与交易性金融资产大幅增长]: 爱建证券、陆家嘴信托增加债券及买入返售金融资产投资，债权投资从24.34亿增至45.84亿，交易性金融资产从33.84亿增至46.71亿。
- **[房地产项目计提存货跌价准备]** -> [资产减值损失同比扩大445%]: 公司对部分房地产项目计提存货跌价准备9.78亿元，较2024年的1.79亿元大幅增加，直接侵蚀利润。
- **[高端住宅项目热销]** -> [住宅销售毛利率维持30%]: 世纪前滩·天御/天汇、陆家嘴太古源源邸等高端项目去化率94%，支撑房地产业务收入增长37.38%，但成本端因土地成本较高导致毛利率下降9.1个百分点。
- **[投资性房地产摊销]** -> [非现金成本持续侵蚀利润]: 2025年摊销投资性房地产10.78亿元，作为非现金支出，持续压低账面利润，但实际现金流未受影响。
- **[绿岸项目土地污染]** -> [苏州土地储备暂停开发]: 绿岸公司名下土地存在污染，相关开发、建设、销售工作暂停，涉及土地面积36.22万平方米，构成重大资产风险敞口。

## 风险警告
**核心风险在于资产减值与信用风险的集中暴露。** 2025年公司计提资产减值损失9.78亿元（主要为存货跌价准备），信用减值损失3.05亿元，合计12.83亿元，占归母净利润的104.7%。这意味着主业经营利润几乎被减值吞噬。上海办公楼市场租金持续下行（成熟写字楼出租率仅78%），叠加未来两年大量新增供应入市，核心办公物业的估值与租金收入面临进一步下行压力，可能引发更多资产减值。

**绿岸项目污染事件是悬而未决的重大隐患。** 虽然土壤治理工作已完成，但项目已暂停开发、建设、销售，涉及苏州地区36.22万平方米土地储备。后续的法律责任、赔偿金额及资产处置方式仍存在重大不确定性，可能对公司造成一次性巨额损失。此外，公司有息负债余额高达703.4亿元，占总资产42%，在利率下行周期中财务费用仍达13.95亿元，高杠杆运营的财务弹性有限。
