# 301103.SZ 深度透视

## 因果逻辑链
- **[屈光手术业务量价齐升]** -> [净利润扭亏为盈]: 全飞秒VISUMAX 800等先进设备引入及AI辅助个性化方案，驱动手术量与收入双增，成为业绩回升核心引擎。
- **[白内障业务主动转型]** -> [收入降幅显著收窄]: 面对医保控费与集采压力，推广高端功能性人工晶体，降低医保依赖，推动业务从“数量型”向“视觉质量型”转型。
- **[视光业务“医疗+消费”双属性]** -> [构建差异化竞争壁垒]: 依托30年眼科积淀与医疗级质量管控，提供全生命周期标准化服务，增强客户黏性，抵御消费疲软。
- **[轻资产加盟连锁模式]** -> [低成本全国扩张]: 通过“品牌授权+标准化运营+供应链赋能”模式，报告期新增签约加盟店35家，累计61家，加速市场下沉与网络布局。
- **[集团统一采购与数字化供应链]** -> [成本管控与效率提升]: 发挥规模议价能力，结合AI智能分析优化采购流程，有效降低药品、器械及视光材料成本。
- **[“国际+再生医疗”战略布局]** -> [抢占前沿技术先机]: 投资日本医道医疗，整合再生医疗技术，巩固眼科干细胞研究先发优势，为国际化与长期增长蓄力。
- **[AI与数字化技术深度赋能]** -> [提升诊疗精准度与运营效率]: 将AI融入三级眼健康服务体系，辅助精准诊疗、优化流程，并推动数据资产化，实现从支撑到价值创造的转型。

## 风险警告
**核心风险在于区域集中度过高与医保政策持续施压。** 公司94%以上收入来自辽宁省内，业务高度依赖单一区域市场，抗风险能力弱。同时，白内障等核心业务深度受医保支付改革与人工晶体集采常态化影响，若无法持续通过高端产品结构升级对冲降价压力，收入与利润将面临持续侵蚀。

**其次，行业竞争加剧与创新投入回报不确定性并存。** 民营眼科赛道竞争白热化，头部连锁加速扩张，中小机构面临洗牌。公司虽在视光加盟与数字化方面有所布局，但“国际+再生医疗”等前沿领域投入大、周期长，短期内难以贡献利润，若技术转化或市场拓展不及预期，将拖累整体盈利能力。
