# 920006.BJ 深度透视

## 因果逻辑链
- **[军品审价基数效应消除]** -> [营收与毛利率大幅反弹]: 2024年因与客户签署差价补充协议，核减历史暂定价收入6762.86万元，导致营收与毛利率基数极低；2025年审价调整金额极小，营收同比+51.29%，毛利率从9.99%修复至49.35%。
- **[航空机械产品稳定贡献]** -> [核心利润来源]: 航空机械产品营收8252.63万元，占比73.4%，毛利率58.80%，是公司最稳定、盈利能力最强的业务板块。
- **[综合电源业务扭亏]** -> [利润弹性释放]: 综合电源业务毛利率从2024年的-208.35%大幅回升至24.48%，营收同比+194.98%，是公司扭亏为盈的关键增量。
- **[募投项目转固]** -> [资产结构变化]: 2023年IPO募投项目“智能特种装备扩产项目”部分完工，固定资产同比+54.31%，在建工程同比-91.52%，产能扩张进入新阶段。
- **[加大研发投入]** -> [技术储备与未来增长]: 研发费用同比+67.50%，重点投向电机、航空混合动力系统等新方向，为未来产品迭代与市场拓展奠定基础。
- **[应收账款高企与信用减值]** -> [利润侵蚀]: 应收账款余额高达2.05亿元，占总资产33.39%，信用减值损失达691.76万元，严重侵蚀当期利润。
- **[客户高度集中]** -> [经营风险]: 前五大客户销售占比88.78%，其中第一大客户A单位占比59.99%，公司业绩高度依赖少数核心客户。

## 风险警告
**军品审价与业绩波动风险是最大隐患。** 公司仍有5.03亿元历史累计收入尚未完成军方审价，若未来审定价格低于暂定价格，将直接导致收入与利润大幅调减。2024年因审价调整导致巨亏的教训深刻，这一机制性风险并未消除，只是暂时缓和。

**客户集中度过高与应收账款坏账风险并存。** 对第一大客户依赖度接近60%，一旦该客户采购策略或预算变化，公司业绩将遭受重大冲击。同时，应收账款周转率仅0.53，账龄较长，信用减值损失持续高企，现金流压力与坏账风险是公司长期面临的财务困境。
