# 002410.SZ 深度透视

## 因果逻辑链
- **[数字成本业务SaaS续费率稳中有升]** -> [营收基本盘稳固]: 造价软件刚需属性强，客户粘性高，即使房建投资下降，续费率仍保持稳定，支撑了60.68亿营收的基本盘。
- **[数字施工业务战略聚焦与成本优化]** -> [毛利率大幅提升22.46个百分点]: 聚焦核心区域和重点客户，优化产品与成本结构，使施工业务毛利率从35.87%跃升至58.33%，显著改善盈利能力。
- **[AI与数据产品价值突破]** -> [净利润同比增长61.77%]: AI算量、AI组价、工程数据等高价值产品规模化推广，带动整体盈利能力提升，归母净利润达4.05亿。
- **[内部精细化管理与费用控制]** -> [管理费用率下降2.39个百分点]: 通过流程化建设和数字化赋能，优化资源配置，严格控制非核心支出，提升了人均收入和利润。
- **[“新清单”政策驱动]** -> [数字成本业务新增长点]: 2025年9月实施的造价市场化改革政策，将刺激客户对市场化数据和服务（如指标网、清标软件）的需求，为成本业务打开增量空间。
- **[自主图形平台与AECOS平台技术壁垒]** -> [构建长期护城河]: 完全自主知识产权的三维图形平台和产业业务平台，是公司产品一体化和AI化的技术底座，保障了核心技术自主可控与生态竞争力。
- **[海外业务加速拓展]** -> [收入规模快速增长18.18%]: 在东南亚、欧洲等市场突破核心客户，MagiCAD、CubiCost等产品验证价值，海外收入达2.4亿元，成为新增长极。

## 风险警告
**核心风险在于房建市场持续低迷对基本盘的侵蚀。** 公司数字成本业务（占总营收78.75%）高度依赖房建领域，2025年该业务收入已同比下降4.16%。若房地产市场“增量转存量”调整周期超预期，中小客户需求持续萎缩，将直接冲击公司最核心的收入来源和利润基石，SaaS续费率稳中有升的趋势可能面临挑战。

**第二重风险是AI与新产品投入的回报不确定性。** 公司正全力押注“All in AI”和设计、施工一体化转型，研发投入占营收比高达26.77%，且资本化开发支出达4.47亿元。若AI产品（如Concetto、AI算量）无法在短期内形成规模化收入，或数字设计、施工业务无法实现盈利拐点，高昂的研发投入将持续压制利润，并带来商誉减值风险（当前商誉余额8.4亿元）。
