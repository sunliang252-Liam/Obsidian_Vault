# 002422.SZ 深度透视

## 因果逻辑链
- **[终端需求下降]** -> [输液销量-8.31%，收入-16.02%]: 流感等传染性疾病发病率下降及医保控费，导致输液市场整体需求回落。
- **[集采降价与未中标]** -> [非输液制剂收入-3.20%]: 仿制药集采常态化，部分产品（如氯化钾水针）未中标，导致销量与价格承压。
- **[青霉素价格下跌]** -> [抗生素中间体收入-23.20%]: 川宁生物核心产品青霉素市场需求波动，量价齐跌，拖累板块利润。
- **[授权及里程碑收入减少]** -> [科伦博泰利润同比下降]: 创新药产品销售收入虽大幅增长，但无法弥补前期高额海外授权收入的一次性减少。
- **[研发费用持续高企]** -> [科伦博泰利润同比下降]: 为推进ADC等创新管线，研发投入维持高位（22亿元），侵蚀当期利润。
- **[联营企业盈利减少]** -> [投资收益同比减少]: 参股公司经营波动，导致公司投资收益下降，进一步拖累归母净利润。
- **[创新药获批与医保准入]** -> [创新药商业化起步]: 芦康沙妥珠单抗等4款创新药获批上市并进入医保，实现销售5.43亿元，开启第二增长曲线。
- **[合成生物学产品落地]** -> [生物制造新增长点]: 红没药醇等产品入选工信部名单，川宁生物从“规模优势”向“技术引领”转型。

## 风险警告
**核心风险：传统业务失速与创新药放量不及预期的双重挤压。** 输液和抗生素中间体两大现金牛业务同步下滑，归母净利润同比暴跌42%。输液需求受宏观环境影响持续疲软，集采对仿制药的冲击仍在深化，而川宁生物的青霉素价格波动具有周期性，短期难以逆转。若传统业务无法企稳，公司将面临现金流承压的严峻挑战。

**关键风险：创新药商业化能否兑现高估值。** 科伦博泰的ADC管线虽技术领先，但商业化尚处早期，2025年创新药收入仅5.43亿元，远不能覆盖22亿元的研发投入。医保谈判后产品价格可能进一步下降，且面临默沙东等国际巨头的全球竞争。若后续适应症拓展或海外授权不及预期，高额的研发投入将持续侵蚀利润，导致估值泡沫风险。
