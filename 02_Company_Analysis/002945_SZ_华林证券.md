# 002945.SZ 深度透视

## 因果逻辑链
- **[科技金融战略深化]** -> [财富管理业务收入增长28%]: 公司持续投入AI技术，推动线上化、智能化服务，机构交易量暴增128%，带动经纪业务手续费净收入增长35%。
- **[市场交投活跃]** -> [手续费及佣金净收入增长35%]: 2025年A股日均交易量达2.05万亿元，市场活跃度提升直接增厚公司经纪业务收入。
- **[权益自营策略调整]** -> [自营业务收入下降28%]: 市场风格转向科技成长，公司坚守的低估值高股息策略跑输大盘，导致权益类自营收入波动。
- **[资管产品规模收缩]** -> [资管业务收入下降47%]: 公司主动收缩资管产品规模，管理费收入相应减少，业务处于战略调整期。
- **[另类投资公允价值变动]** -> [其他业务收入暴增1164%]: 子公司华林创新所投项目公允价值大幅增加，成为利润增长的重要补充。
- **[审慎信用策略]** -> [信用风险可控]: 公司坚持“稳健增长、风险可控”原则，两融余额增长10.5%至57亿，维持担保比例277.78%，且无自有资金出资的股票质押存量业务。
- **[信息技术投入加大]** -> [电子设备运转费增长69%]: 公司为推进科技金融战略，大幅增加AI、大数据等信息技术投入，导致费用端承压。

## 风险警告
华林证券业绩高度依赖市场行情，2025年净利润增长43%主要得益于A股市场活跃度提升，一旦市场转冷，经纪业务收入将面临剧烈波动。公司自营业务收入同比下降28%，暴露了其在权益投资策略上的脆弱性，低估值高股息策略在科技牛市中明显跑输，投资能力有待验证。

公司资管业务收入连续两年大幅下滑（2025年下降47%），且资产管理业务营业利润率为-245.86%，显示该业务线处于严重亏损状态。同时，公司信息技术投入激增69%，若科技金融转型未能有效转化为持续的收入增长，高昂的研发投入将成为利润的沉重负担。此外，公司仍存在2.58亿元的预计负债（红博会展仲裁案），潜在的法律风险尚未完全出清。
