# 601216.SH 深度透视

## 因果逻辑链
- **[一体化循环经济产业链]** -> **成本优势与抗周期能力**: 公司依托“煤-电-氯碱化工”和“煤焦化-甲醇-BDO-PTMEG”纵向一体化布局，主要原料自给率高，有效对冲了2025年大宗商品价格波动，在行业普遍亏损时仍实现18%的净利润增长。
- **[原材料价格大幅下降]** -> **毛利率显著提升**: 报告期兰炭、炼焦用煤、动力煤等主要原材料采购价格同比大幅下降（-23.85%至-31.51%），直接驱动基本化学原料制造业毛利率同比增加5.64个百分点，焦化行业毛利率同比增加19.44个百分点。
- **[新产能释放与高附加值产品放量]** -> **产品结构优化**: BDO（+40.46%）、PTMEG（+294.49%）等新项目产能释放，高附加值产品产销量大幅增长，PTMEG毛利率同比增加16.37个百分点，成为新的利润增长点。
- **[化工物流全球化布局与运力扩张]** -> **稳定收入与市场份额**: 公司作为全球第三大集装罐物流商和中国最大液体化学品船东，通过新船投运和“内外贸兼营”模式，在行业运价承压下仍保持货量增长（+2.9%），巩固了行业龙头地位。
- **[销售回款中票据贴现增加]** -> **经营性现金流大幅改善**: 报告期经营活动现金流净额同比暴增110.97%至51.72亿元，主要源于银行承兑汇票贴现增加及原材料采购支出减少，现金流质量显著提升。
- **[金融机构借款减少]** -> **筹资活动现金流净流出**: 筹资活动现金流净额由正转负，同比减少843.87%，显示公司主动降低杠杆，减少外部融资依赖。

## 风险警告
**核心风险在于周期性行业深度下行与产能过剩的双重挤压。** 公司主营的PVC、硅铁、焦炭、BDO等产品均处于供过于求的行业低谷，价格中枢持续下移。尽管一体化产业链提供了成本缓冲，但若宏观经济复苏不及预期，下游需求持续疲软，公司仍面临盈利能力被进一步压缩的风险。特别是BDO和PTMEG行业产能仍在扩张，价格战可能长期持续。

**另一重大风险是地缘政治与贸易保护主义对化工物流板块的冲击。** 公司约22%的资产在境外，红海危机、中美贸易关税升级（部分品类达25-30%）以及欧盟碳关税（CBAM）2026年全面实施，将直接推高运营成本、扰乱航线布局。此外，公司与神华合资的煤矿采矿权历史遗留诉讼悬而未决，若败诉可能影响上游资源保障。
