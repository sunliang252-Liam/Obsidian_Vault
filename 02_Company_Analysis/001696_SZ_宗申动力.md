# 001696.SZ 深度透视

## 因果逻辑链
- **[通用机械与摩托车发动机主业量价齐升]** -> [营收增长18.55%]: 通用机械收入增15.11%，发动机收入增20.30%，两大核心主业均实现销量与收入双增长，奠定业绩基本盘。
- **[产品结构向高端化、高附加值升级]** -> [净利润增长44.25%]: 越野动力、大排量动力等高毛利产品销量占比提升，带动整体盈利能力增强，净利润增速显著高于营收增速。
- **[海外市场拓展与自主品牌突破]** -> [外销毛利率提升5.69个百分点]: 在欧洲、东南亚等区域实现自主品牌从探索到落地的关键跨越，叠加高毛利产品出口，海外业务盈利能力大幅改善。
- **[新能源业务（储能、电驱动）规模化放量]** -> [新能源产品收入增长36.77%]: 储能、电驱动等第二增长曲线业务进入快速成长期，收入占比提升至6.43%，成为新的增长极。
- **[航空动力适航认证取得里程碑突破]** -> [打开通航有人机市场]: CA500型发动机获民航局适航批准，实现国产航空活塞发动机在轻型运动飞机领域的首次商业化交付，为低空经济业务奠定基础。
- **[数智化改革与智能制造升级]** -> [运营效率提升，成本控制优化]: 智能工厂、5G工厂建设及供应链数智化转型，推动通用机械产品合格率超99%，有效对冲原材料及人力成本上涨压力。
- **[与隆鑫通用的资产置换]** -> [解决同业竞争，整合通用机械业务]: 拟置入隆鑫通用通用机械业务资产，实现产能互补与市场叠加，进一步巩固行业龙头地位。

## 风险警告
**核心风险在于与隆鑫通用的资产置换方案尚未最终确定，交易存在重大不确定性。** 公司拟将摩托车发动机业务资产与隆鑫通用的通用机械业务资产进行置换，以解决同业竞争问题。但截至年报披露日，交易标的范围、价格等核心要素均未敲定，双方尚未签署任何协议。若交易失败或方案不及预期，将直接影响公司业务聚焦战略和估值逻辑。

**业绩承诺完成率下滑与商誉减值风险不容忽视。** 子公司东莞锂智慧2025年扣非净利润5,308.88万元，仅完成业绩承诺的96.53%，连续两年未达标（2023年完成率仅68.30%）。尽管本期商誉减值测试未发现减值，但若未来业绩持续不达预期，将面临商誉减值风险，直接侵蚀利润。此外，公司第四季度归母净利润亏损9,218万元，需警惕季节性经营波动或一次性费用集中确认的风险。
