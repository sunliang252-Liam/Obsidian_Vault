- **[光伏产业链价格持续下行]** -> [公司毛利率下降，净利润亏损]: 行业供需失衡导致公司产品加工费下跌，成本降幅不及收入降幅，毛利率由正转负。
- **[越南基地满产及海外市场拓展]** -> [境外收入同比暴增312.51%]: 越南18万吨产能于2025年8月满产，锚定美国、印度等高加工费市场，境外毛利率9.60%显著高于境内-0.38%。
- **[收购捷诺威获取扁挤压技术]** -> [开辟第二增长曲线]: 掌握稀缺的扁挤压核心技术，切入新能源汽车电池托盘及液冷系统等高附加值赛道，降低对单一光伏边框业务的依赖。
- **[产能规模扩张至76万吨]** -> [规模优势与议价能力提升]: 滁州、芜湖、越南三大基地协同，总产能达76万吨，在铝价波动和下游降价压力下，展现出更强的供应链议价与成本分摊能力。
- **[再生铝产能达43万吨]** -> [构建循环经济成本优势]: 再生铝生产能耗仅为原生铝的3%，显著降低原材料采购成本，同时契合“双碳”目标，形成绿色壁垒。
- **[融资规模增加导致利息支出激增]** -> [财务费用同比暴增154.43%]: 为支撑产能扩张和日常运营，公司大幅增加有息负债，利息支出从0.77亿跃升至1.96亿，严重侵蚀利润。
- **[存货及固定资产计提大额减值]** -> [资产减值损失同比暴增714%]: 光伏产业链价格下行导致公司存货和固定资产出现减值迹象，计提减值损失8053万元，进一步拖累业绩。

## 风险警告
**核心风险在于光伏行业深度“内卷”导致的盈利崩塌。** 2025年公司归母净利润由盈转亏至-2.21亿元，毛利率从5.32%骤降至2.10%，境内业务甚至出现-0.38%的负毛利。公司高度依赖单一光伏边框业务（收入占比超98%），在产业链价格持续承压、下游组件厂商极致压价的背景下，公司议价能力薄弱，盈利空间被严重挤压。即便越南基地贡献高毛利，也难以弥补国内业务的巨额亏损，行业出清前公司基本面难言改善。

**财务风险急剧放大，现金流与偿债压力巨大。** 公司经营活动现金流净额为-28.83亿元，连续两年大额净流出，与收入增长严重背离，主要系销售回款中票据占比高及存货/应收账款占用资金。同时，财务费用因融资规模扩张同比暴增154%至1.96亿元，担保总额占净资产比例高达73.81%，杠杆率已处于高位。若行业低迷持续，公司可能面临流动性紧张和债务偿付风险。
