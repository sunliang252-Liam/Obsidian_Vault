# 002979.SZ 深度透视

## 因果逻辑链
- **[机器人核心部件业务爆发]** -> [营收与利润加速增长]: 无框力矩电机交付超12万台，20倍增长，成功开辟第二增长曲线，驱动Q4营收同比增长33.6%。
- **[“经销为主”渠道策略深化]** -> [营收结构优化与增长]: 引入超300家渠道伙伴，经销收入同比增长30.51%，占比提升至53.32%，成为营收加速增长的核心引擎。
- **[深耕大行业与爆品战略]** -> [伺服系统高增长]: 聚焦半导体、机床等战略行业，L7/L8系列伺服性能对标海外，实现进口替代，伺服系统收入同比增长30.03%。
- **[研发投入持续高企]** -> [产品竞争力与国产替代]: 研发投入占比12.63%，成功量产26位光编编码器、推出S系列PLC等，技术突破支撑高端市场拓展。
- **[股权激励凝聚人才]** -> [短期利润承压但长期动能增强]: 2025年计提股份支付成本5507万元，但扣除后净利润同比增长31.9%，激励计划绑定核心团队，驱动未来增长。
- **[管理变革与三线协同]** -> [运营效率提升与现金流改善]: “区域线、行业线、产品线”协同作战，优化供应链管理，经营活动现金流净额同比增长34.88%，达2.85亿元。
- **[人形机器人产业风口]** -> [打开万亿级增长空间]: 产品进入国内80%主流人形机器人厂商供应链，行星/谐波模组及灵巧手开始规模化供货，抢占未来产业制高点。

## 风险警告
**核心风险在于人形机器人业务的高预期与商业化落地的不确定性。** 公司无框力矩电机业务虽爆发式增长，但人形机器人产业仍处早期，规模化应用、成本下降及客户需求均存在巨大变数。若下游客户量产进度不及预期或技术路线发生变更，公司为机器人业务建设的年产200万台产能可能面临利用率不足的风险，导致资产减值。

**其次，公司面临行业竞争加剧与成本压力。** 尽管公司通过进口替代提升份额，但工控行业竞争激烈，尤其在中低端市场。若未来原材料价格上涨或产品价格战加剧，可能侵蚀公司毛利率。此外，2025年股权激励带来的股份支付费用（预计2025-2028年合计超1.5亿元）将持续对短期利润表构成压力，需关注其能否被业绩增长有效对冲。
