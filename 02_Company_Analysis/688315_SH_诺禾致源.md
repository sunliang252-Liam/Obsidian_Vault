# 688315.SH 深度透视

## 因果逻辑链
- **[全球本地化实验室部署]** -> [海外收入稳健增长]: 在美国、德国、日本等地新建实验室，贴近客户实现快速响应，推动港澳台及海外收入同比增长4.69%，占总收入近半。
- **[主动增加安全库存]** -> [经营性现金流大幅下滑43.73%]: 为应对地缘政治与贸易摩擦不确定性，公司主动囤积原材料，导致现金流出显著增加，掩盖了实际经营造血能力。
- **[应收账款账龄迁徙]** -> [净利润同比下降15.16%]: 客户回款周期拉长，导致信用减值损失计提增加，直接侵蚀利润，这是利润下滑的核心财务原因。
- **[柔性智能交付系统(Falcon)全球部署]** -> [测序数据量产量同比提升33.19%]: 自动化产线提升产能与交付效率，支撑了营收增长，但并未有效转化为利润增长。
- **[AI4S科研助手平台与多组学技术研发]** -> [研发费用同比增长21.67%]: 公司主动加大AI及前沿技术投入，研发费用率提升至7.65%，旨在构建长期技术壁垒，但短期压制利润。
- **[上游测序仪器依赖Illumina/Thermo Fisher]** -> [供应链集中风险]: 前五大供应商采购额占比高达62.91%，其中单一供应商占比47.28%，核心设备与试剂依赖少数海外厂商，构成潜在“卡脖子”风险。
- **[肿瘤基因检测试剂盒入院与mNGS产品推广]** -> [临床业务协同增长]: 基于已获批的III类医疗器械，拓展肿瘤、遗传、感染等临床检测赛道，实现样本量翻倍增长，开辟第二增长曲线。

## 风险警告
**核心风险在于“增收不增利”与现金流恶化。** 公司营收增长4.66%，但净利润与扣非净利润分别下滑15.16%和24.20%，主因是应收账款信用减值激增。更关键的是，经营性现金流净额暴跌43.73%，公司解释为“主动增加安全库存”，这实质上是将供应链风险转嫁为财务压力，若地缘冲突缓和，库存减值风险将暴露。利润与现金流的背离，表明公司当前增长质量堪忧。

**供应链“卡脖子”风险是长期隐患。** 公司核心测序仪器与试剂高度依赖Illumina等少数海外供应商，前五大供应商采购额占比超62%。在全球科技博弈加剧的背景下，若出口管制升级或供应链中断，公司全球实验室的运营将面临重大不确定性。尽管公司提及引入国内供应商，但短期内替代难度极大，这是悬在商业模式上的达摩克利斯之剑。
