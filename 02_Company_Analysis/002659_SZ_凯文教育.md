# 002659.SZ 深度透视

## 因果逻辑链
- **[AI+教育战略布局]** -> [利润总额扭亏为盈]: 2025年9月与智谱华章合资成立智启文华，切入AI教育赛道，带动利润总额从-1640万转为+118万，标志战略拐点。
- **[K12学校在校生规模增长]** -> [教育服务收入增长9.81%]: 两所凯文学校在校生数量有序增长，直接驱动教育服务收入从2.60亿增至2.85亿，是营收增长的核心引擎。
- **[轻资产运营模式转型]** -> [经营现金流大幅改善]: 通过向第三方学校输出运营管理服务，减少重资产投入，经营活动现金流净额从5583万激增至1.23亿，增幅121%。
- **[前期固定资产高投入]** -> [折旧摊销持续拖累净利润]: 学校建设投入规模大，年折旧摊销约1.09亿元，导致公司虽利润总额转正，但归母净利润仍亏损1704万。
- **[海淀区国资委背景]** -> [资源整合与品牌背书]: 实控人为海淀区国资委，使公司能深度对接海淀优质教育、科技资源，为AI+教育、职业教育业务拓展提供独特竞争优势。
- **[产教融合产业学院扩张]** -> [职业教育业务规模化]: 已在5个省份与多所院校共建产业学院，新生报到率稳定在95%以上，2022届毕业生就业率高达95%，形成稳定的收入来源。
- **[智启教育智能体平台试用]** -> [AI+教育商业化验证]: 产品已在海淀区几十所学校试用，覆盖小学至高中，获得正向反馈，为2026年大规模推广奠定基础。

## 风险警告
**核心风险在于资产过重与盈利能力的长期错配。** 公司持有两所凯文学校办学场地，投资性房地产高达18.11亿元，占总资产61%，每年约1.09亿元的折旧摊销是导致公司连续多年亏损的根本原因。尽管利润总额已转正，但归母净利润仍为-1704万，且母公司未分配利润为-3619万，短期内不具备现金分红能力。若无法通过轻资产运营或资产盘活有效降低折旧负担，盈利拐点将难以真正到来。

**第二重风险是AI+教育业务的不确定性。** 公司新设立的智启文华虽背靠智谱华章的技术和海量教育资源，但AI教育赛道已涌入大量科技巨头和教培企业，市场竞争极为激烈。产品目前仅处于试用阶段，尚未形成规模化收入，未来可能面临市场开拓不及预期、技术迭代落后、经营管理磨合等风险。此外，公司前五大客户销售占比高达73.1%，其中关联方占比70.88%，客户集中度过高，存在对单一客户的重大依赖风险。
