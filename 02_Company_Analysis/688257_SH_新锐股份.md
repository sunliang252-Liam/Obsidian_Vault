# 688257.SH 深度透视

## 因果逻辑链
- **[产业链一体化与并购整合]** -> [营收利润双增]: 公司通过收购智利Drillco、DrillersWorld等，补齐凿岩工具全品类，实现“硬质合金+工具+综合服务”上下游贯通，带动营收增长33.89%，扣非净利润增长39.53%。
- **[海外矿山综合服务能力]** -> [境外收入高增]: 依托澳洲AMS等子公司，为必和必拓、FMG等全球矿企提供“产品+配套+技术”一站式服务，境外收入同比增长35.85%，成为增长核心引擎。
- **[原材料成本传导与结构优化]** -> [毛利率提升]: 面对碳化钨粉涨价，公司通过价格传导、优化采购模式及提升高毛利新品占比，硬质合金板块毛利率同比提升7.47个百分点，综合毛利率升至33.51%。
- **[切削工具第二曲线]** -> [板块高速增长]: 通过并购株洲韦凯、锑玛工具等，形成数控刀片、整硬刀具、齿轮刀具等全场景产品矩阵，切削工具收入同比增长48.34%，成为新增长极。
- **[研发驱动与协同创新]** -> [技术壁垒加固]: 研发投入同比增长49.25%，聚焦超粗晶合金、金属陶瓷、潜孔钻具等核心技术，累计专利491项，支撑产品向高端化、差异化演进。
- **[全球化渠道与品牌建设]** -> [市场覆盖扩大]: 产品销往60多国，通过海外子公司整合销售网络，参与国际展会，品牌“Shareate”在澳洲矿用牙轮钻头市场位列前三，直销收入占比提升至68.95%。

## 风险警告
**商誉减值与并购整合风险**：公司商誉高达2.66亿元，主要来自近年密集并购（智利Drillco、DrillersWorld等）。若海外子公司因地缘政治、汇率波动或矿山需求下行导致经营不及预期，将面临大规模商誉减值，直接冲击利润表。当前境外资产占总资产22.93%，管理半径与跨文化整合难度不容忽视。

**原材料价格与下游周期双重挤压**：碳化钨粉成本占硬质合金生产成本70%以上，价格波动剧烈。若公司无法及时向下游传导成本，毛利率将承压。同时，下游矿山开采、机械加工、油气服务均为强周期性行业，铁矿石、油价等大宗商品价格低迷将直接抑制客户采购意愿，导致订单萎缩与库存积压（存货11.22亿元，占流动资产34.97%）。
