# 605086.SH 深度透视

## 因果逻辑链
- **[下游陶瓷需求萎缩]** -> [营收与净利润双降]: 国际市场需求疲软、国内陶瓷行业竞争加剧，导致公司产品销量下滑，2025年营收同比下降10.06%，归母净利润同比下降5.22%。
- **[战略投资者紫金矿业入股]** -> [公司战略转型加速]: 紫金矿业集团南方投资有限公司成为第二大股东（持股20%），推动公司从单一高岭土矿种向萤石、高纯石英等多矿种战略转型，并启动外延并购。
- **[降本增效措施落地]** -> [成本有效控制，毛利率提升]: 通过优化选矿工艺、招标竞价、供应链管理，选矿厂生产成本同比显著下降14.64%，整体可控运营成本下降6.97%，高岭土开采加工行业毛利率同比提升0.33个百分点。
- **[产品结构分化]** -> [原矿销售稳定，综合利用产品承压]: 原矿销售额同比微增1.92%，而受房地产行业影响，下游建筑陶瓷需求萎缩，综合利用产品销售额同比大幅下降33.11%。
- **[金融资产收益贡献显著]** -> [非经常性损益支撑利润]: 报告期内，公司通过理财产品、私募基金等金融资产获得投资收益及公允价值变动收益合计约2,640万元，占利润总额的18.4%，成为利润的重要补充。
- **[参股公司盛龙股份上市]** -> [长期股权投资价值重估]: 参股的洛阳盛龙矿业集团股份有限公司于2026年3月成功在深交所上市，为公司带来显著的资产增值潜力和投资收益。
- **[研发聚焦高附加值领域]** -> [培育新增长点]: 公司成功转化“扫选底流分离除杂技术”，实现高岭土扫选底流提锂的稳定量产，并积极布局高纯石英矿等战略性矿种的技术储备。

## 风险警告
**核心风险在于下游需求的结构性萎缩与公司单一资源依赖的叠加。** 公司业绩高度依赖东宫下单一矿区，且下游陶瓷行业（尤其是建筑陶瓷）受房地产周期影响持续低迷，导致综合利用产品销量锐减。尽管公司通过降本增效和金融投资收益对冲了部分压力，但若下游需求持续疲软，公司主营业务的盈利能力和现金流将面临进一步下滑的风险。

**战略转型的执行风险不容忽视。** 公司正从单一高岭土矿企向多矿种、多主业转型，重点关注萤石、高纯石英等战略性矿种。然而，新矿种的资源获取、开发及产业化周期长、不确定性高，且面临激烈的市场竞争。若外延并购项目落地不及预期，或新业务无法快速贡献利润，公司将面临“旧业承压、新业未立”的尴尬局面，增长前景将大打折扣。
