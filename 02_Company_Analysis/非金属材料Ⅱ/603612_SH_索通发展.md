# 603612.SH 深度透视

## 因果逻辑链
- **[预焙阳极价格与销量双升]** -> [营收增长28.68%]: 原铝产业链高景气推动预焙阳极价格同比上涨34.76%，叠加索通创新二期、陇西索通等新增产能释放，产销量同比增长6%，量价齐升驱动营收突破177亿元。
- **[石油焦智能集采与混配系统]** -> [毛利率提升4.36个百分点]: 公司依托全球最大石油焦采购商地位，通过数字化系统实现多品种原料精准混配与低价采购，在原材料价格上涨背景下有效控制成本，预焙阳极毛利率逆势提升。
- **[产能出海与合资建厂模式]** -> [锁定下游需求，规避产能过剩风险]: 与EGA、华阳新材料、吉利百矿等合资建设新项目，以股权绑定核心客户，确保新增产能的消化渠道，降低市场波动风险。
- **[负极材料业务量增价跌]** -> [板块持续亏损]: 锂电负极销量虽增长73.52%，但行业产能过剩导致产品价格大幅下跌，该板块毛利率为-5.09%，子公司甘肃索通盛源亏损1.22亿元，拖累整体盈利。
- **[数字化智能化转型]** -> [降本增效，净利润增长174%]: 公司被评为国家级智能工厂，通过智能排产、自动化设备升级重构业务流程，在产能扩张的同时实现运营效率提升，归母净利润从2.72亿元跃升至7.47亿元。
- **[财务费用激增53.68%]** -> [侵蚀利润]: 利率下降导致利息收入减少，叠加汇率波动产生汇兑损失，财务费用从1.62亿元增至2.48亿元，成为利润增长的主要抵减项。
- **[资产减值损失翻倍]** -> [反映负极业务困境]: 计提存货跌价准备及固定资产减值准备1.97亿元，主要来自负极材料产线，显示该业务资产质量承压。

## 风险警告
**核心风险在于负极材料业务的持续失血与资产减值风险。** 尽管预焙阳极主业强劲，但锂电负极板块连续三年亏损，2025年毛利率仍为负（-5.09%），子公司累计亏损超2亿元。行业产能过剩格局短期难改，若价格无法回升，该业务将继续拖累合并报表利润，并可能引发进一步的商誉及固定资产减值。

**财务杠杆高企与现金流压力不容忽视。** 公司资产负债率高达60.6%，担保总额占净资产比例达129%，财务费用因汇兑损失和利息收入减少而大幅攀升。同时，存货因原材料涨价和产能释放激增52%，占流动资产的42.6%，若价格回落将面临巨大跌价风险。海外项目（阿联酋、广西）持续投入，对现金流形成长期考验。
