# 300403.SZ 深度透视

## 因果逻辑链
- **[全球家电产量稳定增长]** -> [排水泵需求稳健]: 洗衣机、洗碗机产量同比增长4.80%和5.83%，直接拉动公司核心排水泵产品销量增长0.38%。
- **[泰国子公司产能扩张]** -> [海外业务布局深化]: 泰国子公司营收2.83亿元，净利润996.78万元，成为公司海外增长的重要支点。
- **[新业务板块持续拓展]** -> [培育第二增长曲线]: 电子水泵销量同比增长69.92%，充电桩项目稳步推进，新业务正逐步贡献增量。
- **[全自动化生产与精益管理]** -> [成本优势与毛利率稳定]: 先进的生产技术和供应链管理有效控制成本，使产品毛利率基本稳定在33.63%。
- **[与全球知名家电品牌深度绑定]** -> [客户壁垒与先发优势]: 与惠而浦、海尔、美的等前五大客户形成长期稳定合作，贡献64.96%的营收，构筑了稳固的市场地位。
- **[持续研发投入与专利积累]** -> [技术护城河]: 拥有642项授权专利，研发投入占营收3.26%，确保公司在排水泵细分领域的技术领先。
- **[远期外汇合约套期保值]** -> [对冲汇率风险]: 通过远期结汇等工具管理汇率波动，报告期内公允价值变动收益520.5万元，有效平滑了汇兑损益影响。

## 风险警告
**核心风险在于增长停滞与第二曲线不确定性。** 公司营收与净利润增速已显著放缓至3%和0.85%，扣非净利润甚至下滑5.02%，显示传统排水泵业务已进入成熟期，增长天花板隐现。新业务如智能水疗马桶和新能源汽车配件虽在推广，但体量尚小，尚未能成为驱动业绩增长的核心引擎，存在市场推广不及预期的风险。

**成本费用上升与资产利用效率风险不容忽视。** 公司管理费用同比增长22.41%，主要因厂房折旧计入，而子公司甜的电器和汉宇电器存在部分厂房暂时未能充分利用的风险，这将持续侵蚀利润。同时，原材料价格波动和劳动力成本上升，可能进一步压缩本已承压的毛利率。
