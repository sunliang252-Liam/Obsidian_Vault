# 000922.SZ 深度透视

## 因果逻辑链
- **[核电产品放量]** -> [营收微增0.42%]: 核电产品收入增长14.80%，弥补了传统电动机及服务收入下滑1.96%的缺口，稳住营收基本盘。
- **[传统行业需求萎缩]** -> [净利润下滑0.94%]: 钢铁、石化等传统行业新增项目减少，低价竞争加剧，导致公司盈利能力承压，扣非净利润下降1.74%。
- **[资产减值大幅计提]** -> [侵蚀利润]: 2025年计提资产减值损失1.34亿元（占利润总额35.15%），主要来自存货跌价准备，是利润下滑的核心拖累项。
- **[定向增发完成]** -> [净资产大增38.15%]: 向控股股东哈电集团募资11.1亿元，使归属于上市公司股东的净资产从33.36亿元跃升至46.09亿元，显著增厚资本实力。
- **[核电资质壁垒]** -> [高毛利核电产品]: 公司是国内唯一同时具备轴封型主泵和屏蔽式主泵电机设计、制造、试验一体化能力的企业，核电产品毛利率高达38.08%，显著高于传统电机。
- **[数智化转型]** -> [降本增效]: 低压电机数字化装配线、RPA“数字员工”等项目投产，提升生产效率，部分对冲了人力成本上升（职工薪酬同比+22%）的压力。
- **[偿还短期借款]** -> [财务费用大幅下降]: 2025年财务费用仅1357万元，同比减少67.42%，主要系偿还短期借款所致，改善了利润表结构。

## 风险警告
**1. 传统主业增长乏力与竞争加剧风险。** 公司核心收入来源“电动机及服务”收入同比下降1.96%，传统下游行业（钢铁、石化）需求持续萎缩，低价中标现象普遍。在营收基本持平的情况下，公司通过大幅计提资产减值（1.34亿）才勉强维持利润，反映出传统业务盈利质量正在恶化。若核电等高毛利业务增速放缓，公司整体业绩将面临较大下行压力。

**2. 经营现金流大幅恶化与资产减值风险。** 2025年经营活动现金流净额仅2.97亿元，同比骤降35.40%，远低于净利润水平。同时，公司存货高达17.63亿元，且计提了1.64亿元跌价准备。在行业竞争加剧、下游回款周期拉长的背景下，存货跌价风险与应收账款坏账风险可能持续暴露，进一步侵蚀未来利润。
