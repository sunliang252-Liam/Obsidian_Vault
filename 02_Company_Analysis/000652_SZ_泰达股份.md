# 000652.SZ 深度透视

## 因果逻辑链
- **[能源贸易毛利率极低]** -> [整体盈利脆弱]: 批发业收入占79.52%，但毛利率仅0.65%，微利业务规模巨大，任何价格波动或成本上升都直接侵蚀利润。
- **[区域开发收入暴增但毛利下降]** -> [增收不增利]: 区域开发业收入同比+229%，但毛利率从31.4%降至22.1%，成本增速（+273.6%）远超收入，说明土地出让成本大幅攀升。
- **[环保主业增收但利润下滑]** -> [核心业务承压]: 环境管理业收入+36.09%，但毛利率下降6.24个百分点，主因国补退坡、环保标准提高导致运营成本增加。
- **[巨额资产减值与营业外支出]** -> [净利润由盈转亏]: 计提存货跌价、长期股权投资减值2.54亿元，叠加税收滞纳金及违约利息1.41亿元，合计近4亿元非经常性损失，直接导致归母净利润亏损2.86亿元。
- **[财务费用高企且持续增长]** -> [侵蚀经营成果]: 财务费用8.82亿元，同比+29.79%，占营业利润的-295%，高负债运营模式使利息支出成为利润最大拖累项。
- **[经营活动现金流持续为负]** -> [造血能力不足]: 连续两年经营现金流净流出，2025年净流出1.66亿元，表明主营业务无法产生正向现金流，依赖融资和资产处置维持。
- **[剥离非主业资产]** -> [聚焦环保战略]: 转让扬州万运100%股权，确认投资收益1,741万元，体现公司主动收缩区域开发业务，向生态环保主业集中的战略意图。

## 风险警告
**核心风险在于主业盈利模式脆弱与巨额财务成本的双重挤压。** 公司近80%收入来自毛利率不足1%的能源贸易，该业务对价格波动极度敏感，且客户与供应商高度集中（前五名客户/供应商占比均超60%），一旦市场环境变化或供应链中断，将直接冲击现金流。同时，环保主业面临国补退坡和运营成本上升的双重压力，盈利能力持续下滑，而高达8.82亿元的财务费用（同比+30%）如同“吸血泵”，持续吞噬微薄的经营利润，导致公司陷入“增收不增利、增利不增现”的困境。

**资产减值与合规风险构成利润的“定时炸弹”。** 2025年公司因补缴税款及滞纳金、计提存货和长期股权投资减值，合计造成近4亿元的非经常性损失，直接导致巨额亏损。这暴露出公司在历史税务合规、投资决策及房地产存货管理方面存在重大隐患。区域开发板块的南京新城净资产已为负值（-10.59亿元），若房地产市场持续低迷，后续减值风险不可小觑。此外，公司资产负债率高企，短期借款94.3亿元，长期借款77.6亿元，偿债压力巨大，任何融资渠道收紧都可能引发流动性危机。
