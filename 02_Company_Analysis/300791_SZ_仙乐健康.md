# 300791.SZ 深度透视

## 因果逻辑链
- **[个人护理业务（PC公司）经营恶化及资产减值]** -> [净利润暴跌58%]: 非核心个人护理业务因客户需求下降、成本上升及团队变动陷入亏损，公司决定关停并计提1.95亿元资产减值损失，直接导致归母净利润从3.25亿骤降至1.37亿。
- **[聚焦营养健康食品主业]** -> [营收微增1.23%]: 剥离亏损业务后，公司核心主业（营养健康食品解决方案）保持增长，但被非核心业务拖累，整体营收仅实现42.63亿元，同比微增。
- **[新消费赛道转型成功]** -> [中国区营收结构优化]: 中国区新消费赛道业务收入同比增速超50%，占比从30%提升至近50%，MCN客户和私域客户营收均实现约50%增长，弥补了传统渠道增长放缓。
- **[全球化布局与协同]** -> [欧洲区营收增长24.95%]: 欧洲区通过落地RTG/IPD产品、深耕大客户及药店渠道，实现7.55亿元营收，成为增长最快的区域；德国工厂接近满产。
- **[战略咨询与前瞻性投入]** -> [短期费用侵蚀利润]: 为提升核心竞争力，公司启动战略咨询项目，并前瞻布局精准营养、宠物营养等赛道，产生较高的一次性咨询费用和前期投入，短期内未产生效益。
- **[BestFormulations整合与运营改善]** -> [美洲区营收下降6.90%]: 美国子公司BestFormulations虽委派中国团队加强管理，但受贸易政策不确定性和运营改善尚需时间影响，美洲区营收同比下降，且该子公司全年净亏损4.06亿元。
- **[AI与数字化赋能]** -> [研发效率提升]: 公司落地AI配方匹配系统，研发提效达40%；软胶囊AI辅助设计工具投入应用，加速产品创新周期，为“又好又快”的研发交付提供支撑。

## 风险警告
**核心风险在于商誉减值与跨境整合的不确定性。** 公司账面商誉高达4.27亿元，主要来自收购德国SirioGermany和美国BestFormulations。尽管公司宣称整合顺利，但BestFormulations在2025年录得巨额亏损（-4.06亿元），且美洲区业务受关税和运营挑战影响持续承压。若未来海外子公司经营不能实现预期收益，将面临重大商誉减值风险，对利润表造成二次冲击。

**次要风险来自行业竞争加剧与原材料价格波动。** 营养健康食品行业格局日趋复杂，新进入者、新渠道、新模式层出不穷，公司需持续投入以维持其“全球第三、中国第一”的市场地位。同时，鱼油、明胶等核心原料价格受全球市场影响波动较大，若无法有效传导成本或保障供应，将直接侵蚀毛利率。此外，公司约60%收入来自境外，汇率波动和国际贸易保护主义（如对等关税）是持续存在的经营变量。
