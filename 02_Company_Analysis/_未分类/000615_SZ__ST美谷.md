# 000615.SZ 深度透视

## 因果逻辑链
- **[司法重整成功]** -> [归母净资产由负转正至18.59亿元]: 重整引入15.88亿元投资及以股抵债，彻底化解债务危机，资产负债率从102.72%骤降至39.51%。
- **[剥离生物基纤维亏损资产]** -> [聚焦医美主业]: 2026年初完成金环新材料、金环绿纤剥离，甩掉持续亏损的化纤包袱，集中资源发展高毛利医美服务。
- **[控股股东变更为九州通]** -> [获得千亿级产业生态赋能]: 九州通作为国内最大民营医药流通企业，其医美供应链、12,246家合作机构网络及“投资+BD”上游布局，为美谷提供全链路资源。
- **[医美业务营收下滑9.79%]** -> [净利润承压]: 行业监管趋严、市场竞争加剧及消费降级，导致医美服务收入从6.24亿降至5.63亿，利润空间受挤压。
- **[确认债务重组收益6.02亿元]** -> [非经常性损益扭亏]: 重整计划执行完毕，确认大额债务重组收益，掩盖了扣非后净亏损6.24亿元的经营困境。
- **[计提大额信用减值损失5.67亿元]** -> [吞噬利润]: 因原控股股东关联方担保事项，确认对外承担连带担保责任损失，导致信用减值损失激增。
- **[“三年三步走”战略]** -> [医美全产业链转型]: 2026年聚焦旗舰店运营，2027年向全国核心城市扩张，2028年建成“产品+服务+数字化”全链路生态。

## 风险警告
**核心风险：重整后经营基本面未实质改善。** 公司2025年扣非净利润巨亏6.24亿元，医美主业营收下滑近10%，生物基纤维业务虽已剥离但历史亏损已造成巨大拖累。重整带来的净资产转正和债务重组收益均为一次性非经常性损益，公司持续盈利能力尚未得到验证，若医美业务无法实现增长，将再次陷入亏损泥潭。

**退市风险与历史担保余波。** 公司虽已申请撤销退市风险警示，但能否获批存在不确定性。更关键的是，原控股股东关联方京汉置业定向融资计划仍有未决诉讼，若公司最终需承担担保责任，将形成新的非经营性资金占用，可能触发新的合规风险。此外，公司因信披违规被证监会处罚，治理层信誉受损，后续监管压力不容忽视。
