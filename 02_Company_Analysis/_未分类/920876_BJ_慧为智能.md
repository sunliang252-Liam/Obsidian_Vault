# 920876.BJ 深度透视

## 因果逻辑链
- **[5G云电脑与信创终端进入运营商体系]** -> [营收增长26.34%]: 公司首个展锐5G平台项目规模化量产，云电脑、信创终端产品进入国内头部运营商供应链，带动国内销售增长18.19%，成为营收核心增量。
- **[策略性备货应对原材料涨价]** -> [经营性现金流大幅转负]: 预期存储芯片、内存等核心元器件价格持续上行，公司主动加大关键原材料采购备货力度，导致购买商品支付的现金同比显著增加，经营活动现金流净额由正转负至-1,629万元。
- **[会计估计变更（调低坏账计提比例）]** -> [信用减值损失大幅减少，净利润虚增]: 将0-6个月应收账款预期信用损失率从5%调低至1.5%，导致当期信用减值损失同比减少182.72%，是净利润从154万跳升至653万的关键非经营性因素。
- **[募投项目“研发生产基地”转固投产]** -> [固定资产暴增1033%，长期借款激增785%]: 江门新基地完工，固定资产从674万增至7,642万；为项目建设新增项目借款4,084.6万元，长期借款从520万增至4,608万，资产负债率升至39.81%。
- **[消费电子类产品收入增长40.44%]** -> [整体毛利率微降]: 消费电子类产品（平板、笔记本）收入占比提升，但其毛利率仅9.17%，拉低了公司整体毛利率从14.79%降至14.24%。
- **[海外市场收入增长36.37%]** -> [境外业务未受关税重大影响]: 公司通过优化客户结构与产品组合，积极推动自有品牌建设，在巩固ODM业务的同时，有效降低了单一市场波动风险。
- **[原材料涨价向终端传导存在时差]** -> [2026年经营面临不确定性]: 2025年四季度终端产品售价上调已开始压制消费电子需求，而主要零部件涨价态势尚未缓解，预计将持续对公司2026年经营产生影响。

## 风险警告
**核心风险在于利润质量的严重失真与现金流枯竭。** 公司2025年净利润653万元，但扣非净利润仅472万元，且其中包含了因会计估计变更（调低坏账计提比例）带来的约250万元信用减值损失“回拨”。剔除这一会计粉饰，公司实际经营利润微薄。更严峻的是，经营性现金流净额为-1,629万元，与净利润严重背离，表明公司为应对原材料涨价而进行的策略性备货正大量吞噬现金，盈利的“含金量”极低。

**第二大风险是原材料价格暴涨对商业模式的根本性冲击。** 存储芯片、内存等核心元器件价格大幅上涨，公司毛利率已从15.21%降至14.24%。由于ODM模式定价存在滞后性，成本上涨无法立即传导给客户，导致毛利被持续挤压。公司通过加大备货来对冲，但这又加剧了现金流压力。若2026年涨价持续，公司可能面临“增收不增利”甚至亏损的困境，同时高库存将带来巨大的跌价风险。
