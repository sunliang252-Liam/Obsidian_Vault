# 920030.BJ 深度透视

## 因果逻辑链
- **[行业价格战加剧]** -> [毛利率骤降]: 2025年燃油车价格战持续，新车成交价下探，公司综合毛利率从7.93%降至6.07%，毛利润减少4367万元，直接导致由盈转亏。
- **[新能源战略投入期错配]** -> [当期利润承压]: 公司重金布局AITO问界、智界等新能源品牌，前期建店、运营等战略性投入计入当期损益，而新店营收尚处爬坡期，形成显著的“投入-产出”周期错配。
- **[燃油车业务收缩]** -> [资产减值损失增加]: 传统燃油车市场萎缩，公司关停部分效益不佳的4S店，并计提存货跌价准备，资产减值损失同比增加35.4%。
- **[循环经济项目资本开支]** -> [在建工程激增]: 动力电池综合利用项目（金瑞项目）一期主体完工，设备安装中，导致在建工程同比暴增152.22%，占用大量资金。
- **[融资结构依赖短期借款]** -> [财务费用刚性]: 公司营运资金高度依赖短期借款和厂商金融，期末短期借款达4.76亿元，虽利率下行，但财务费用仍达2080万元，侵蚀利润。
- **[区域市场集中]** -> [抗风险能力弱]: 业务高度集中于湖南、贵州三四线城市，区域市场波动直接冲击公司整体业绩，缺乏全国性分散风险的能力。
- **[前期会计差错更正]** -> [合规成本增加]: 因收入确认、费用核算等会计差错被监管责令整改，追溯调整财报，增加管理成本并影响市场信心。

## 风险警告
**核心风险：行业价格战与战略转型的“双重绞杀”。** 公司传统燃油车业务是利润基石，但正被行业价格战持续削弱，毛利率已降至6.07%的极低水平。同时，公司重仓新能源转型，但新店前期投入巨大且盈利周期长，导致当前处于“旧业务失血、新业务输血”的尴尬阶段，2025年巨亏3129万元即是明证。若价格战持续或新能源业务爬坡不及预期，公司可能陷入持续亏损。

**财务风险：高杠杆与资金占用。** 公司资产负债率高达70.06%，短期借款超4.7亿元，且大量资产（存货、固定资产、无形资产）已被抵押用于融资，流动性空间逼仄。更需警惕的是，报告期内存在控股股东资金占用问题（单日最高占用265万元），虽已追回，但暴露出内控漏洞。在盈利恶化背景下，任何融资渠道收紧都可能引发流动性危机。
