# 920001.BJ 深度透视

## 因果逻辑链
- **[三期项目投产，产能爬坡]** -> [毛利率暴跌至12.60%]: 新增产线折旧摊销与人工成本激增，但产能未完全释放，单位成本大幅上升，吞噬利润。
- **[市场竞争加剧，产品降价]** -> [营收微降2.28%，但毛利锐减]: 销量增长无法弥补售价下跌，偏光片收入同比下降4.02%，直接导致主营业务盈利能力恶化。
- **[产品售价下降 + 单位成本上升]** -> [计提巨额存货跌价准备1538万元]: 成本与售价倒挂，导致资产减值损失同比暴增151.57%，成为亏损核心推手。
- **[研发投入持续加大]** -> [研发费用同比增长28.59%]: 为保持车载、OLED等高端领域技术优势，研发费用率提升至9.27%，短期侵蚀利润。
- **[联营公司立原新材亏损扩大]** -> [投资收益损失496万元]: 上游原材料布局尚处投入期，核心产品未量产，拖累公司整体业绩。
- **[防雾膜工艺改进，订单增长]** -> [防雾膜收入同比增长17.67%]: 产品结构优化初见成效，高毛利防雾膜成为少数增长亮点。
- **[募投项目结项，产能释放期来临]** -> [固定资产暴增153.93%]: 公司从建设期迈入产能释放期，未来销量增长是扭亏关键。

## 风险警告
**核心风险：产能释放与市场需求错配导致的“增产不增利”。** 公司三期项目投产，固定资产暴增154%，但产能爬坡期成本刚性上升，叠加行业竞争加剧导致产品售价下降，毛利率从28.49%断崖式下滑至12.60%。若下游需求（尤其是车载显示）增速不及预期，或公司无法快速提升良率与稼动率以摊薄固定成本，公司将持续面临巨额存货跌价与亏损压力。

**结构性风险：产品单一与原材料依赖。** 偏光片收入占比超91%，且核心原材料TAC膜超70%依赖进口。一旦地缘政治或贸易摩擦导致供应链中断，或OLED技术加速替代LCD（OLED仅需一层偏光片），公司经营将遭受致命打击。此外，联营公司立原新材持续大额亏损，向上游延伸的战略短期内仍是利润拖累。
