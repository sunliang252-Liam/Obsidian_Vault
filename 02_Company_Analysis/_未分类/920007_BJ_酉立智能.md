# 920007.BJ 深度透视

## 因果逻辑链
- **[全球光伏装机高增长 + 跟踪支架渗透率提升]** -> [营收增长41.47%]: 下游客户需求旺盛，公司作为跟踪支架核心零部件供应商，订单量随行业扩容而大幅增加。
- **[客户高度集中（前五大客户占95%）]** -> [营收高增长但利润增速极低（+1.51%）]: 对单一大客户A（占比62%）依赖极强，议价能力弱，收入增长未能有效转化为利润增长。
- **[外销收入占比88% + 人民币升值]** -> [财务费用由负转正，同比+91.43%]: 汇兑收益大幅减少，侵蚀了部分利润空间，是利润增速远低于营收增速的核心原因之一。
- **[原材料（钢材）成本上涨 + 成本传导时滞]** -> [毛利率从18.42%降至15.16%]: 营业成本增速（+47.12%）显著高于营收增速（+41.47%），成本压力未能及时、充分向下游传导。
- **[营收大幅增长 + 信用政策放宽]** -> [应收账款增长66.31%，信用减值损失暴增508.6%]: 为维持高增长，公司可能放宽了回款条件，导致坏账风险显著上升，进一步拖累利润。
- **[北交所上市募资2.79亿元]** -> [货币资金暴增617.78%，净资产翻倍]: 上市极大改善了资产负债表，为后续产能扩张和全球化布局提供了资金弹药。
- **[股权激励（35.97元/股）]** -> [管理费用增长41.98%]: 股份支付费用计入管理费用，是管理费用增速远高于营收增速的重要原因，短期压制了利润表现。
- **[子公司安徽寅天贡献主要利润]** -> [合并净利润结构单一]: 安徽寅天净利润约1,435万元，是合并报表利润的重要来源，其经营状况对整体业绩影响较大。

## 风险警告
**核心风险：增收不增利的“虚假繁荣”。** 公司营收增长41.47%，但扣非净利润同比下滑0.53%，毛利率大幅下滑3.26个百分点。这背后是客户集中度极高（前五大客户占95%，单一大客户A占62%）、原材料成本传导不畅、人民币升值侵蚀利润、以及信用减值损失暴增等多重负面因素的叠加。公司本质上是一个“代工”角色，缺乏定价权，规模扩张并未带来相应的利润增长，反而放大了经营杠杆的负面效应。

**关键风险：单一大客户依赖与汇率波动。** 对客户A的依赖度超过60%，任何合作关系变动都将对公司造成毁灭性打击。同时，公司88%的收入来自境外，以美元计价，人民币升值将直接导致汇兑损失和产品竞争力下降。尽管公司使用外汇期权进行套保，但2025年财务费用的大幅转正已表明，套保效果有限，汇率风险是悬在利润头上的达摩克利斯之剑。
