# 000795.SZ 深度透视

## 因果逻辑链
- **[稀土原材料价格回升]** -> [磁材业务毛利率微增]: 稀土价格带动钕铁硼售价上涨，但成本端通过配方优化和战略采购有效对冲，毛利率仅提升0.6个百分点。
- **[新能源汽车/节能家电需求增长]** -> [磁材销量微增0.91%]: 下游应用领域稳定增长，但出口管制政策导致部分产品延缓发货，库存激增51.14%。
- **[越南生产基地投产]** -> [全球化布局落地]: 越南工厂已实现多款电机量产并发货，通过十余批次国际客户审核，承接海外订单。
- **[健康器材业务海外库存消化+国内消费疲软]** -> [电动轮椅及代步车收入下降11.45%]: 海外市场去库存、国内消费复苏缓慢及行业价格战，导致该板块量价齐跌，毛利率下滑6.05个百分点。
- **[音响扬声器业务放量]** -> [收入增长36.55%]: 受益于客户订单增长，该板块成为唯一逆势高增长的细分业务，但成本同步上升30.78%。
- **[政府补助大幅增加]** -> [归母净利润微增0.93%]: 扣非净利润同比下降14.07%，政府补助从3682万增至7934万，成为利润增长的主要驱动力。
- **[经营性现金流净额下降41.5%]** -> [盈利质量承压]: 销售回款减少幅度大于采购支出减少幅度，现金循环效率恶化，净利润含金量降低。

## 风险警告
**核心风险：扣非净利润持续下滑与现金流恶化。** 2025年扣非净利润同比下降14.07%，连续两年下滑，且经营性现金流净额骤降41.5%至3.42亿元，远低于净利润。公司盈利质量显著恶化，利润增长高度依赖非经常性损益（政府补助），主业造血能力正在减弱。

**结构性风险：健康器材业务陷入量价齐跌困境。** 该板块收入下降11.45%，毛利率骤降6.05个百分点，库存虽主动去化但销量下滑23.9%，显示市场需求疲软与竞争加剧。若海外去库存周期延长或国内消费复苏不及预期，该业务可能持续拖累整体业绩。同时，钕铁硼库存激增51.14%，若稀土价格回调，将面临较大存货减值风险。
