# 605158.SH 深度透视

## 因果逻辑链
- **宏观经济下行，下游建筑、机械需求增速放缓** -> 公司产销量增速放缓，营业收入仅增长1%: 下游需求不足直接抑制公司产品销量增长
- **市场价格持续低迷，前期库存成本较高** -> 毛利率同比下降（金属制品业毛利率降2.24个百分点）: 售价无法覆盖前期高价库存成本，导致毛利空间收窄
- **毛利率下降** -> 净利润同比大幅下降71.54%: 毛利额减少直接侵蚀净利润，叠加费用刚性，利润弹性放大
- **南通项目建设进展顺利，部分设备投产** -> 固定资产大幅增加（+240%）及存货增加（+69%）: 项目转固及备货导致资产规模扩张
- **南通项目投产及新产能释放** -> 产销量同比增长（热镀锌板产量+13%，彩涂板销量+4.39%）: 新增产能转化为实际产量和销量
- **公司产品出口增长（境外销售同比+60%）** -> 应收账款增加（+124%）: 外销客户回款周期较长，导致应收款增加
- **原材料热轧卷价格波动下跌** -> 公司采取定额采购与临时采购结合模式，控制采购成本: 公司利用价格下跌时机灵活备货，但前期库存成本较高
- **公司加大研发投入（研发费用2.13亿，占收入3.05%）** -> 新产品开发成功（净化白、有花镀锌等），获得专利15项: 持续研发投入推动产品创新和技术升级
- **票据支付结算增加** -> 经营活动现金流净额大幅改善（从-23.6亿转正至5.30亿）: 采购端更多使用票据支付，减少现金流出
- **支付到期已贴现票据增加** -> 筹资活动现金流净额大幅流出（-19.4亿）: 票据到期兑付导致现金大量流出

## 风险警告
多重风险叠加：1）盈利风险：毛利率持续承压，净利润大幅下滑，若原材料价格与产品售价倒挂持续，盈利能力恐进一步恶化；2）资产质量风险：存货同比大增近70%至17.6亿元，若下游需求持续疲软，存在跌价风险；应收账款激增124%，回款不确定性增加；3）流动性风险：短期偿债压力大，应付票据32.8亿（占总资产39%），且货币资金30.4亿受限，实际可动用资金有限；4）行业风险：供强需弱格局加剧，出口面临反倾销贸易壁垒，汇率波动风险。
