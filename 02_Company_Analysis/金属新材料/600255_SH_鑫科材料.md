# 600255.SH 深度透视

## 因果逻辑链
- **[铜价上涨及销量增加]** -> [营收增长20%]: 铜基合金产销量增加叠加铜价上涨，推动营业收入从39.58亿增至47.51亿。
- **[江西鑫科产能爬坡]** -> [净利润下降50%]: 控股子公司江西鑫科投产转固后尚处产能爬坡阶段，成本偏高，叠加出口退税政策调整，严重侵蚀利润。
- **[产品结构调整]** -> [毛利率承压]: 公司主动“扩高铜、减黄铜”，但高附加值产品放量尚需时间，整体毛利率从8.65%降至7.28%。
- **[出口退税取消]** -> [境外业务利润下滑]: 铜材出口退税政策调整，直接导致境外业务毛利率下降3.08个百分点，且收到的税费返还同比减少74.8%。
- **[经营性现金流恶化]** -> [资金链紧张]: 经营性现金流净额为-9287万元，主要系经营性应收项目增加及票据保证金大幅波动，显示运营效率下降。
- **[有息负债激增]** -> [财务费用上升]: 合并口径有息债务余额从7.55亿增至14.17亿，同比增87.68%，导致财务费用同比增26.83%。
- **[高速铜连接布局]** -> [未来增长点]: 已实现800G小批量供货、1.6T产品开发成功，但尚处客户验证阶段，未形成规模收入，短期无法贡献利润。

## 风险警告
**核心风险在于盈利能力的急剧恶化与现金流的高度紧张。** 公司营收增长20%但净利润腰斩，扣非净利润更是暴跌67.52%，显示主业盈利质量极差。江西鑫科作为未来重要产能，其持续亏损和产能爬坡的不确定性是最大拖累。同时，经营性现金流连续两年为负，且缺口扩大，表明公司“增收不增利，增利不增现”，运营效率堪忧。

**财务杠杆风险急剧放大。** 公司有息负债一年内从7.55亿翻倍至14.17亿，资产负债率升至59%，且担保总额占净资产比例高达159%。在盈利能力下滑、现金流紧张的背景下，高企的债务负担将严重侵蚀利润，并可能引发流动性危机。母公司累计未分配利润仍为-19.67亿，长期无法分红，股东回报前景黯淡。
