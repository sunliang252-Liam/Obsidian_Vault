# 601086.SH 深度透视

## 因果逻辑链
- **[门店调改升级与场景化改造]** -> [营收增长5.71%]: 主力店兰州国芳百货“超级百货”转型，引入249家新品牌（含64家区域首店），通过空间重构和业态创新拉动客流与销售。
- **[金融资产公允价值变动]** -> [净利润增长21.16%]: 持有吉林奥来德股票公允价值上升2,510万元，贡献非经常性损益，是净利润增速远超扣非净利润的核心原因。
- **[经销模式毛利率大幅下滑]** -> [主业毛利率下降4.08个百分点]: 百货经销毛利率从12.23%骤降至5.25%，成本增速（9.75%）远超收入增速（2.62%），侵蚀核心盈利能力。
- **[投资理财与合伙企业增加]** -> [投资活动现金流净流出增长620.83%]: 购买理财产品、投资御道数科等合伙企业，导致投资现金净流出从-2,602万扩大至-1.88亿。
- **[供应商结款及费用增加]** -> [经营活动现金流净额下降38.49%]: 尽管营收增长，但支付供应商款项和期间费用增加，导致经营性现金流从2.55亿降至1.57亿。
- **[餐饮业务新布局]** -> [新增收入4332万元]: 投资“海底捞”等餐饮品牌，开辟新收入来源，但毛利率仅26.01%，低于百货主业。
- **[线上渠道高速增长]** -> [抖音团券销售增长285.2%]: 抖音本地生活团券销售额4,043万元，带动线下销售6,702万元，线上成为线下引流的重要引擎。

## 风险警告
**核心风险在于主业盈利能力持续恶化与金融资产依赖。** 扣非净利润同比下降30.27%，经销毛利率从12.23%暴跌至5.25%，显示核心零售业务在激烈竞争与成本压力下，盈利空间被严重挤压。公司净利润高度依赖吉林奥来德等金融资产的公允价值变动，该收益具有极大不确定性和不可持续性，一旦市场波动，利润将面临剧烈下滑风险。

**经营与扩张风险不容忽视。** 公司经营区域高度集中于甘青宁地区，且对兰州国芳百货单一门店依赖度较高。同时，公司正大规模进行门店改造、投资餐饮及合伙企业，导致投资活动现金净流出激增，而经营活动现金流却在下滑。若调改效果不及预期或新业务培育周期过长，将加剧现金流压力，并可能拖累整体业绩。
