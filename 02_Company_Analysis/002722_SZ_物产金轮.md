# 002722.SZ 深度透视

## 因果逻辑链
- **[不锈钢装饰板业务承压]** -> [整体营收与利润下滑]: 下游电梯、家电行业需求疲软，导致不锈钢板收入同比下降11.22%，子公司森达装饰净利润同比腰斩48.93%，拖累整体业绩。
- **[纺织梳理器材业务增长]** -> [对冲部分下滑]: 子公司金轮针布通过产品结构优化与市场拓展，营收增长5.82%，净利润大增24.79%，成为业绩稳定器。
- **[参股公司会计核算方法变更]** -> [非经常性损益暴增]: 对上海鲲华失去重大影响，长期股权投资转为金融资产，产生1.1亿元非经常性收益，掩盖了主营业务扣非净利润同比暴跌60.77%的真相。
- **[经营现金流大幅恶化]** -> [盈利质量显著下降]: 经营性现金流净额同比骤降75.03%，主因存货和应收款项增加，表明公司利润转化为现金的能力严重削弱。
- **[原材料价格波动]** -> [成本控制风险]: 不锈钢、特种钢等原材料成本占比高，价格波动直接影响毛利率，公司虽采用期现结合工具对冲，但效果存在不确定性。
- **[可转债到期转股]** -> [股本扩张与债务结构优化]: 报告期内“金轮转债”基本完成转股，总股本增加，同时消除了潜在的偿债压力，降低了财务费用。
- **[高端特种钢丝项目延期]** -> [未来增长点兑现存疑]: 募投项目“高端特种钢丝项目”再次延期至2026年底，表明公司在新业务拓展上趋于谨慎，短期难以贡献业绩。

## 风险警告
**核心风险在于主营业务盈利能力的急剧恶化与现金流危机。** 公司扣非净利润同比暴跌60.77%，而经营现金流净额更是骤降75.03%，两者均指向公司核心业务（尤其是不锈钢装饰板）正面临严峻的行业逆风。利润增长完全依赖1.1亿的非经常性损益，这种“虚胖”的增长不可持续，一旦失去此类收益，公司真实盈利将大幅缩水。

**第二大风险是资产减值，尤其是商誉。** 公司收购的森达装饰（不锈钢业务主体）净利润已腰斩，经营持续恶化，这直接触发了商誉减值的警报。年报已明确提示此风险，若未来行业景气度无法回升，大额商誉减值将直接冲击利润表，造成业绩“双杀”。此外，原材料价格波动和人力资源风险也是长期悬在头顶的达摩克利斯之剑。
