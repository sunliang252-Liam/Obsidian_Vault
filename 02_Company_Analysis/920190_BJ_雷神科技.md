# 920190.BJ 深度透视

## 因果逻辑链
- **[“电竞+信创”双轮驱动战略]** -> [营收微增1.95%]: 境内信创业务与电竞PC新品拉动境内收入增长17.65%，但境外收入因大额定制订单完成及市场调整骤降36%，整体营收仅小幅增长。
- **[核心原材料（CPU/内存/存储）价格持续上涨]** -> [存货激增89.57%]: 公司为锁定成本、对冲涨价风险，主动大规模备货CPU、内存等关键原材料及产成品，导致存货从3.9亿飙升至7.4亿。
- **[海外大额应收账款到期回款]** -> [信用减值损失转回1429万]: 2024年形成的大额海外应收款在2025年集中收回，坏账准备大幅转回，成为利润增长的关键非经营性贡献。
- **[美元汇率波动与借款增加]** -> [财务费用激增54%]: 以美元结算的采购成本受汇率波动影响产生汇兑损失，同时为备货增加银行借款导致利息支出上升，侵蚀利润。
- **[研发投入加大]** -> [研发费用增长26.66%]: 为应对AI PC趋势和产品迭代，公司推出RTX50系列新品及AI眼镜等，设计开发费用显著增加。
- **[向海尔集团关联销售]** -> [营收占比21.89%]: 公司向实际控制人海尔集团销售PC及外设产品6.6亿元，构成最大单一客户，关联交易依赖度较高。
- **[购置自用办公楼]** -> [在建工程激增与投资现金流出]: 公司购入海尔路办公楼并启动装修，导致在建工程从13.7万暴增至8566万，投资活动现金净流出8417万。

## 风险警告
**核心风险在于存货高企与毛利率微薄的双重挤压。** 公司为应对原材料涨价而将存货推高至7.4亿元（占总资产43.6%），但自身毛利率仅7.97%，净利率不足1%。一旦PC市场需求因内存涨价而下滑（Omdia预测2026年全球PC出货量下降12%），或原材料价格进入下行周期，公司将面临巨大的存货跌价风险，微薄的利润将难以覆盖减值损失。

**第二重风险是严重的关联交易依赖与境外业务的不确定性。** 公司21.89%的营收来自关联方海尔集团，独立性存疑。同时，境外业务收入同比骤降36%，且受国际贸易环境、汇率波动及地缘政治影响巨大。公司虽开展外汇套期保值，但财务费用已因汇率波动激增54%，显示其抗风险能力脆弱。信创“第二曲线”虽在推进，但尚未能弥补海外业务的失速。
