# 603281.SH 深度透视

## 因果逻辑链
- **[功能性硅烷价格持续下跌]** -> [营收与利润双降]: 行业“内卷”导致产品价格触底，公司营收同比下降16.14%，净利润同比下降30.54%，但降幅远低于行业平均水平。
- **[“反内卷”政策与国内需求韧性]** -> [内贸销量创历史新高]: 国内经济结构调整与扩大内需政策见效，内贸销量逆势增长超8%至6.8万吨，部分对冲了外贸下滑。
- **[欧美贸易保护与“去风险化”]** -> [外贸销量同比下滑15%]: 欧美客户采购策略调整，拖累出口业务，但东南亚、韩国市场实现10%以上增长，填补部分缺口。
- **[硅基新材料绿色循环产业园一期投产]** -> [关键原料自主供应能力增强]: 6万吨三氯氢硅产线顺利投产，夯实了从原材料到终端产品的绿色循环产业链，提升成本控制与供应链安全。
- **[研发投入聚焦高端与电子级产品]** -> [高附加值产品占比保持高位]: 全年研发开支6175万元，14个新产品完成小试，9N级正硅酸乙酯项目切入半导体赛道，巩固技术护城河。
- **[高分红与股份回购]** -> [股东回报稳定]: 拟每股派现1元（含税）并转增0.4股，现金分红比例高达86.85%，同时实施2-4亿元股份回购，彰显信心。
- **[原材料价格波动与成本控制]** -> [毛利率承压]: 主要原材料价格波动，但公司通过优化采购、降本增效（吨产品用水同比下降47.35%），部分抵消了成本压力。

## 风险警告
**核心风险在于行业供需格局恶化与出口市场的不确定性。** 功能性硅烷行业产能持续扩张，通用型产品同质化竞争激烈，价格已触底但反弹力度存疑。公司虽为全球龙头，但若下游需求复苏不及预期或“反内卷”效果有限，毛利率可能进一步承压。同时，欧美贸易保护主义及地缘政治风险持续，外贸业务面临客户采购策略调整与关税壁垒的长期挑战，出口收入占比近半，波动风险显著。

**财务风险集中于应收账款回收与汇率波动。** 期末应收账款余额达2.3亿元，若客户因宏观经济下行或信用环境收紧而无法按期偿付，将产生坏账风险。此外，公司出口收入占比高，人民币汇率若出现大幅升值，将直接导致汇兑损失，侵蚀利润。公司虽通过套期保值对冲，但无法完全消除风险。
