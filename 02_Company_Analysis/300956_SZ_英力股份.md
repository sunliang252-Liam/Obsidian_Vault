# 300956.SZ 深度透视

## 因果逻辑链
- **[AI PC换机周期与消费电子复苏]** -> [营收增长20.83%]: 2025年全球PC出货量增长9.1%，公司作为联想、戴尔等品牌的上游结构件供应商，直接受益于行业回暖。
- **[客户高度集中（前五大客户占89.25%）]** -> [业绩稳定性与议价权受限]: 对联宝（49.52%）、华勤、纬创等代工厂的深度依赖，使公司营收随大客户订单波动，缺乏定价弹性。
- **[外销占比超72%与美元结算周期错配]** -> [财务费用激增281.59%]: 美元销售收入信用期（120天）长于采购信用期（60天），人民币汇率波动导致汇兑净损失大幅增加。
- **[光伏业务战略收缩]** -> [营收下降29.16%，亏损收窄]: 公司主动减少光伏组件代工，转向自投分布式电站收取电费，并明确“不再单独开展光伏业务”，以控制亏损。
- **[收购佛山智强与拟并购优特利]** -> [补链强链，切入新客户与电池模组]: 通过收购进入北美品牌商供应链，并计划将电池模组导入现有客户体系，提升单机价值量。
- **[海外产能布局（美国、沙特）]** -> [规避贸易风险，拓展新业务]: 在美国购置厂房切入AI服务器机柜，在沙特设厂服务中东、非洲市场并作为转口基地，应对地缘政治风险。
- **[劳务外包依赖度高]** -> [成本结构固化，管理风险上升]: 劳务外包报酬3.3亿元，占营业成本比重高，劳动密集型属性使公司面临用工成本上涨和人员管理挑战。

## 风险警告
**核心风险在于客户集中度过高与汇率波动双重挤压利润。** 前五大客户贡献近九成营收，对联宝一家依赖度近50%，公司议价能力弱。同时，超七成收入为美元结算，但账期长于采购端，导致2025年财务费用因汇兑损失暴增近3倍，直接侵蚀了本已微薄的净利润（净利率仅0.6%）。这种“增收不增利”的结构性矛盾是公司当前最大的财务脆弱性。

**第二重风险来自转型的不确定性。** 公司正从单一的结构件厂商向“结构件+电池模组+服务器结构件”多元化转型，但收购优特利（电池）尚在推进中，美国AI服务器机柜业务也处于起步阶段。光伏业务已明确收缩，但前期投入的资产减值风险仍在（2025年资产减值损失2352万元）。新业务能否在短期内形成利润支柱，存在较大不确定性，而主业增长已显疲态。
