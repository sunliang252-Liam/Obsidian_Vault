# 002799.SZ 深度透视

## 因果逻辑链
- **[互联网数字营销业务缩停]** -> [营收暴跌42.15%]: 主动停止领凯科技新业务，导致该板块收入从5.02亿骤降至0.72亿，成为营收腰斩主因。
- **[核心主业承压]** -> [连续三年亏损]: 医药包装板块受行业调整、新工厂投产固定成本增加及竞争加剧影响，毛利率下降7.24%，导致归母净利润-2200万。
- **[新产能爬坡缓慢]** -> [资本回报率低下]: 凌峰环球智能工厂已投产但尚未满产，2025年仍亏损1381万，拖累整体盈利。
- **[应收账款暴雷]** -> [资产减值侵蚀利润]: 子公司领凯科技对“头脑风暴”的应收账款累计计提坏账3.33亿（计提比例96.58%），是近年巨额亏损的核心来源。
- **[供应链业务韧性]** -> [利润稳定器]: 北京金印联贡献净利润1346万，毛利率逆势提升6.63%，成为公司当前最稳定的利润来源。
- **[参股公司贡献]** -> [投资收益缓冲]: 西安德宝（铝管包装）贡献投资收益821万，占利润总额的40.59%，有效对冲主业亏损。
- **[聚焦主业战略]** -> [资源再配置]: 缩停互联网业务、变更募投项目（节余4575万补流），将资源集中于医药及消费品包装智能制造。

## 风险警告
**最大风险：互联网数字营销业务遗留的“黑洞”尚未填平。** 领凯科技对“头脑风暴”的3.33亿应收账款坏账几乎全额计提，且公司已为其逾期贷款垫付1.54亿元。该业务虽已缩停，但存量诉讼、担保责任及潜在的进一步资产减值，仍可能持续侵蚀公司现金流和利润。

**核心主业增长乏力，新产能释放不及预期。** 医药包装行业竞争加剧，公司核心产品毛利率下滑。凌峰环球智能工厂投资巨大（募投项目延期至2027年），但当前仍处亏损状态，产能利用率不足。若下游需求持续疲软，巨额固定资产折旧将长期压制利润，公司面临“转型期阵痛”与“存量业务失血”的双重压力。
