# 002233.SZ 深度透视

## 因果逻辑链
- **[煤炭等原燃料价格下降 + 极致降本]** -> [水泥毛利率提升2.37个百分点]: 成本端降幅（-8.28%）大于售价降幅（-4.25%），推动主业盈利改善。
- **[区域气候好转 + 上年低基数]** -> [水泥销量逆势增长1.14%]: 在广东水泥消费量下降5.98%的背景下，公司凭借区域优势与灵活营销巩固了市场份额。
- **[资本市场回暖]** -> [公允价值变动收益与投资收益大增]: 非经常性损益同比增加6亿元，成为净利润增长17.87%的核心增量来源。
- **[关停鑫达旋窑5000t/d生产线]** -> [四季度计提资产减值与辞退福利]: 产能优化导致短期利润承压，但长期有利于提升整体运营效率。
- **[固废处置量同比+57.57%]** -> [环保业务营收增长13.01%]: 蕉岭30万吨固废项目投运，但竞争加剧导致处置价格下降，营收增幅远低于量增。
- **[房地产投资持续深度调整]** -> [混凝土销量同比-24.49%]: 下游需求疲软，公司混凝土业务承压，营收下降29.01%。
- **[高分红政策]** -> [增强股东回报预期]: 2025年拟每10股派4.80元，叠加回购，现金分红总额占净利润比例高，体现公司对股东回报的重视。

## 风险警告
**核心风险在于水泥主业需求长期下行与区域竞争加剧。** 2025年全国水泥产量创2010年新低，广东市场受房地产投资持续探底、基建投资放缓及外省低价水泥冲击，供需矛盾愈发尖锐。公司虽通过降本增效和区域优势实现销量微增，但水泥价格持续走弱，主业盈利改善高度依赖成本控制，缺乏需求端的根本支撑。若2026年基建投资未能有效对冲房地产下滑，公司“量价齐跌”的风险将显著放大。

**第二增长曲线尚在培育期，业绩波动性大。** 公司净利润增长高度依赖非经常性损益（证券投资、公允价值变动），主业盈利贡献有限。环保固废业务虽量增迅速，但价格战导致毛利率骤降31.62%，盈利能力存疑。光伏、新能源等新业务体量极小，尚无法对冲水泥主业的周期性波动。此外，公司持有大量金融资产，资本市场波动将直接冲击利润表，业绩稳定性较差。
