# 002008.SZ 深度透视

## 因果逻辑链
- **[AI算力需求爆发]** -> [PCB设备业务营收暴增72.68%]: AI服务器、高速交换机等基础设施投资高涨，直接拉动高多层板、HDI板等高端PCB需求，公司作为核心设备供应商，订单与营收同步大幅增长。
- **[消费电子创新周期]** -> [消费电子设备业务营收增长15.33%]: 手机、智能眼镜等终端硬件加速创新，公司深度参与北美大客户新产品开发，在散热、光学组件、3D打印等环节提供解决方案，带动设备需求。
- **[新能源全球化扩产]** -> [锂电设备业务营收增长49.65%]: 国内头部电池企业启动新一轮扩产，叠加海外建厂需求，公司配合大客户“国内+海外”双线布局，设备订单显著增长。
- **[扣非净利润大增82.28%]** -> [核心主业盈利能力实质性改善]: 剔除2024年大额资产处置收益后，2025年扣非净利润达8.1亿元，显示PCB、锂电等核心主业的内生增长动能强劲。
- **[研发投入持续高企]** -> [技术壁垒与产品竞争力强化]: 研发费用20.65亿元，占营收11.11%，支撑公司在AI服务器PCB钻孔、3D打印、半导体切割等前沿领域保持技术领先，巩固垂直一体化优势。
- **[经营活动现金流净额增长30.48%]** -> [收入质量与回款能力提升]: 营收增长的同时，公司加强应收款项回收，经营现金流净额达14.69亿元，现金流状况健康，为后续扩张提供资金保障。
- **[全球化布局加速]** -> [海外收入持续增长与供应链韧性增强]: 公司计划在东南亚设立海外运营中心和生产基地，配合客户供应链多元化战略，以属地化团队规避贸易壁垒，提升海外市场响应速度与份额。

## 风险警告
**核心风险在于归母净利润与扣非净利润的严重背离。** 2025年归母净利润同比下降29.77%，主因是2024年公司通过出售资产获得了高达10.6亿元的非流动性资产处置收益，而2025年此类收益近乎归零。这揭示了公司过往利润对非经常性损益的高度依赖，投资者需警惕其盈利的可持续性，并关注扣非净利润增长能否持续对冲非经常性损益的波动。

**第二大风险是下游行业周期性波动与市场竞争加剧。** 公司业务横跨消费电子、新能源、半导体等多个领域，虽能平滑单一行业周期，但任一领域的资本开支放缓（如消费电子创新不及预期、锂电扩产潮退去）都将直接冲击设备订单。同时，智能制造装备行业参与者众多，若公司不能在技术迭代中持续领先，将面临市场份额被侵蚀、毛利率承压的风险。此外，光伏设备业务仍处于行业调整期，盈利贡献尚不稳定。
