# 002759.SZ 深度透视

## 因果逻辑链
- **[六氟磷酸锂Q4价格触底反转]** -> [全年扭亏为盈]: 前三季度行业下行亏损，Q4价格快速上涨，单季实现净利润1.84亿元，覆盖前三季度亏损并实现全年盈利。
- **[储能与新能源汽车行业高景气]** -> [六氟磷酸锂量价齐升]: 2025年全球储能电池出货量同比增76.2%，带动公司六氟磷酸锂销量同比增55.84%，收入同比增60.52%。
- **[产能规模行业前三]** -> [成本优势与市场份额]: 已建成3.7万吨/年产能（行业前三），满负荷生产（产能利用率106.94%），规模效应降低单位成本，巩固头部地位。
- **[原材料价格波动]** -> [经营现金流承压]: 碳酸锂、氟化锂价格上半年下跌、下半年回升，公司为保市占率持续供货，前三季度现金流出大，全年经营现金流净流出3亿元。
- **[新特化工未完成业绩承诺]** -> [商誉减值与补偿款]: 因下游需求放缓、竞争加剧，新特化工2025年净利润仅2,579万元，远低于承诺的5,500万元，计提商誉减值及确认补偿款。
- **[江西氟化锂项目投产]** -> [产业链纵向延伸]: 年产6000吨氟化锂项目投产，自产氟化锂替代部分外购，降低六氟磷酸锂原材料成本，但产能爬坡期仍亏损34.85万元。
- **[研发投入大幅增长]** -> [技术储备与新产品布局]: 研发费用同比增49.14%，重点投向六氟磷酸锂工艺优化、双氟磺酰亚胺锂、电池级硫化锂等，为未来产品迭代储备技术。

## 风险警告
**核心风险：立案调查与财务合规隐患。** 公司因涉嫌信息披露违法违规被证监会立案调查，审计报告被出具带强调事项段的无保留意见。此前因商誉减值测试不规范、财务核算不准确等问题已被广东证监局出具警示函。立案调查结果存在重大不确定性，可能涉及历史财务数据追溯调整、行政处罚甚至投资者索赔，对公司声誉和融资能力构成直接威胁。

**行业周期与现金流双重压力。** 六氟磷酸锂价格波动剧烈，2025年Q4反转虽带来盈利，但前三季度持续亏损导致全年经营现金流净流出3亿元，且应收账款同比增42.5%至7.73亿元。公司高度依赖外部融资（短期借款同比增56%），若行业再次进入下行周期，高负债率下的现金流断裂风险不可忽视。此外，7.05亿元商誉余额悬顶，新特化工业绩对赌期已结束，未来若磷化工业务持续低迷，商誉减值将再次冲击利润表。
