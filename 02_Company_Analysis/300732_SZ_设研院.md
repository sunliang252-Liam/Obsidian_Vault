# 300732.SZ 深度透视

## 因果逻辑链
- **[传统基建投资增速放缓]** -> [营收未达预期]: 外部投资环境变化导致在手项目推进不及预期，公司营业收入增长乏力。
- **[应收账款计提大额信用减值]** -> [净利润大幅亏损]: 客户回款困难，公司计提3.31亿元资产减值损失，直接侵蚀利润，是亏损主因。
- **[可转债转股完成]** -> [财务结构优化]: 3.73亿元债券转为股本，资产负债率从58.90%降至53.56%，降低财务风险。
- **[经营活动现金流大幅改善]** -> [现金流净额转正]: 通过加强回款攻坚和成本控制，经营性现金流净额同比增长193.76%至1.8亿元，但净利润仍为负。
- **[“三综一甲”资质壁垒]** -> [业务多元化拓展]: 拥有工程设计、勘察、咨询综合甲级资质，支撑公司从单一交通向交通、城建、水利、矿山等“6+2”综合业务群转型。
- **[钢结构桥梁装配业务爆发]** -> [营收结构变化]: 该业务收入同比增长98.12%，成为新的增长点，但毛利率较低，拉低了整体盈利水平。
- **[省外及海外市场拓展]** -> [收入区域结构优化]: 华东、西北、海外地区收入分别增长61.56%、42.65%、244.17%，降低了对河南单一市场的依赖。

## 风险警告
**核心风险在于资产减值损失的持续侵蚀。** 公司应收账款及合同资产账面余额高达43亿元，坏账准备余额12.8亿元。尽管2025年减值损失已导致巨额亏损，但若下游地方政府及平台公司财政状况持续恶化，回款周期进一步拉长，未来仍有继续计提大额减值的风险，这将持续压制公司利润表，甚至可能引发流动性危机。

**第二重风险是传统主业增长乏力与转型的不确定性。** 公司核心的工程设计咨询业务收入仅增长6.72%，毛利率虽有提升但整体盈利能力下滑。虽然钢结构桥梁装配业务增长迅猛，但其毛利率远低于传统设计业务，且市场竞争激烈。公司向数字智慧、绿色低碳等新兴领域的转型尚处于投入期，能否在短期内形成稳定且高毛利的利润来源，存在较大不确定性。
