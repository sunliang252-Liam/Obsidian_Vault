# 920166.BJ 深度透视

## 因果逻辑链
- **研发投入增加（研发费用增长20.67%，研发人员增加）** -> 新产品推出（如可视双腔支气管插管套件、病人监护仪等）: 研发投入增加直接推动新产品研发进程，产品注册证取得和转产上市增强了产品竞争力。
- **监护类耗材收入增长25.25%** -> 营业收入增长13.68%: 监护类耗材收入增速远超整体营收增速，成为营收增长的主要驱动力。
- **规模效应显现（生产自动化、库存控制）** -> 毛利率稳定（52.01% vs 52.09%）: 规模效应和自动化改造帮助控制成本，使得在原材料等成本上升的情况下毛利率基本维持。
- **应收账款增加（同比增长40.25%）** -> 信用减值损失增加（同比增长310.96%）: 应收账款规模扩大导致预期信用损失相应增加。
- **在建工程增加（同比增长56.07%）** -> 总资产增长（同比20.25%）: 在建工程大幅增长是总资产增长的重要构成之一。
- **政府补助增加（其他收益增长78.67%）** -> 净利润增长（21.01%）: 政府补助增加直接贡献利润增长。

## 风险警告
主要风险包括：1）集采政策对麻醉耗材价格的潜在冲击，公司主要产品如麻醉面罩等已纳入多省联盟集采；2）应收账款增长较快（+40%）导致信用减值损失激增，需关注回款情况；3）研发项目仍处投入期，短期内可能影响利润，且新产品市场推广存在不确定性；4）境外业务以OEM为主，自主品牌建设薄弱，受汇率和贸易政策影响较大。
