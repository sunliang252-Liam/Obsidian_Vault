# 002767.SZ 深度透视

## 因果逻辑链
- **[政策驱动]** -> [营收增长14.64%]: 国家大规模设备更新和城市生命线工程政策，直接拉动智能燃气表及安全监测产品需求。
- **[产品结构升级]** -> [毛利率承压]: 物联网智能燃气表收入占比提升至82.65%，但该产品毛利率同比下降2.02%，拉低整体毛利率1.70个百分点。
- **[规模效应与控费]** -> [扣非净利润大增41.29%]: 营收增长14.64%的同时，管理费用同比下降3.02%，带动扣非净利润增速远超营收。
- **[中融信托暴雷]** -> [公允价值变动损失861.6万]: 9000万元到期未兑付信托产品计提公允价值变动损失，侵蚀利润，占利润总额-29.72%。
- **[下游回款改善]** -> [经营现金流大增85.85%]: 销售商品收到的现金增加，经营活动现金流净额达8713万元，显著高于净利润2779万元。
- **[研发投入加码]** -> [巩固技术壁垒]: 研发费用同比增长13.72%，聚焦超声波燃气表、AI大模型平台等前沿领域，强化行业标准制定话语权。
- **[新设子公司]** -> [拓展安全监测赛道]: 设立先锋智能，专注燃气报警器及安全监测，与主业形成互补，开辟第二增长曲线。

## 风险警告
**核心风险在于9,000万元中融信托产品到期未兑付。** 公司已计提5,400万元公允价值变动损失，但剩余3,600万元账面价值仍面临全额损失风险。若最终无法收回，将直接冲击公司净资产和利润，对市值不足20亿的小盘股而言是重大打击。

**行业竞争加剧与毛利率下行趋势不容忽视。** 物联网智能燃气表虽放量，但价格竞争导致毛利率持续下滑。公司应收账款高达4.34亿元，占营收61%，回款压力巨大。若宏观经济波动或下游燃气公司资金紧张，坏账风险将显著上升。
