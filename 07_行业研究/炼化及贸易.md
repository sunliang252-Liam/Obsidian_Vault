# 🛢️ 炼化及贸易（申万 L2 · 801963.SI）

> 上游总览：[[00_行业景气度总览]]
> **本行业含自选股：[[000703_SZ_恒逸石化]]**

## 🎯 一句话结论

**CR5 高达 93% 的极端集中行业 —— 但集中度来自「两桶油」，不代表全行业结构好。**
2026Q2 净利同比 **+44.5%**，毛利率 **14.6%**（一年前 11.4%），
驱动力更接近**成本端改善（油价回落）** 而非需求扩张。
⚠️ **[[000703_SZ_恒逸石化]] 不在前五** —— 行业指标对它几乎没有代表性。

| 问题 | 判断 |

| 需求还是供给驱动？ | **成本端** —— 营收仅 +3.2% 而毛利率跳升，是原料价格回落 |
| 周期什么位置？ | 底部回升（毛利率回到 14.6%，但仍低于 2024Q1 的 11.3% 之上水平需谨慎解读） |
| 资本开支？ | 民营大炼化前期扩产集中，产能释放期 + 需求平淡 = **加工价差承压** |

## 🔗 对 [[000703_SZ_恒逸石化]] 的提示

1. **不要用行业净利同比 +44.5% 推断恒逸的业绩** —— 该数字主要由两桶油决定
2. 恒逸属于**民营炼化 + 聚酯（PTA/涤纶）**产业链，其盈利更取决于**PX-石脑油价差**与**涤纶长丝价差**
3. 要看恒逸，应**单独查它的财务**（`income_statement` / `fina_indicator`），并与荣盛、恒力、东方盛虹做同业对比，而不是与两桶油比
