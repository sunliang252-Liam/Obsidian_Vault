# 🍶 白酒Ⅱ（申万 L2 · 801125.SI）

> 上游总览：[[00_行业景气度总览]]

## 🎯 一句话结论

**全库最清晰的单向下行样本** —— **八期毛利率无一次回升**（73.8% → **67.4%**，-6.4pp），
营收连续四期**双位数负增长**（2026Q2 **-18.1%**），净利同比 **-22.8%**。
这不是周期波动，是**需求端的结构性走弱**。

**关键观察（四个恶化信号同时出现）**：
1. **毛利率单调下滑**：73.8 → 73.2 → 73.6 → 73.1 → 71.0 → 69.1 → 67.6 → **67.4**
   → **连高端白酒的定价权都松动了**，这是最重的信号
2. **营收连续四期双位数负增长**（-5.8% / -18.3% / -13.6% / -18.1%）
3. **净利同比持续为负**（-6.9% / -24.1% / -17.9% / -22.8%）
4. **ROE 从 16.3% 掉到 4.90%** —— 资本回报水平近乎腰斩再腰斩

> ⚠️ 但要注意：**毛利率 67.4% 仍是全库最高之一**。白酒的问题不是「不赚钱」，
> 而是「**不再增长，且赚钱能力在退坡**」。这与 [[养殖业]] 的亏损性质不同。

## 🧭 周期位置判断

| 问题 | 判断 |
|---|---|
| 需求还是供给驱动？ | **需求端** —— 营收下滑 + 毛利率下滑 = 量价双杀，不是供给问题 |
| 周期什么位置？ | **下行中段**（尚未见到毛利率企稳的任何迹象） |
| 资本开支？ | 白酒资本开支主要是产能与渠道，行业下行期通常会收缩 |

> **观察拐点的关键指标**：**毛利率何时止跌**。只要毛利率还在降，就说明渠道价格体系仍未修复。

## ⚠️ 数据边界

- **茅台占营收 46%**，行业均值反映的是头部而非全行业；中小酒企的真实压力更大
- 白酒的「营收」含渠道打款（预收/合同负债调节），财报营收 ≠ 终端动销 ——
  可结合 `annual_report_supplements.contract_liab_end`（合同负债）交叉验证渠道压力
- 估值 PE 24.8 是**下滑后的估值**，不构成「便宜」
- 前瞻期同比为空（8 期窗口起点限制）
